**Premise correction:** This repository does not define a GraphQL schema for a public API. Instead, it uses Protocol Buffers (protobuf) for its public API schema.

**Actual API surface:** The public API schema is defined in Protocol Buffer files (`.proto` files) located at:

- **Main API definitions:** `/bench/repo/proto/api/v1/` containing service definitions:
  - `memo_service.proto` — Memo CRUD operations
  - `user_service.proto` — User management
  - `auth_service.proto` — Authentication
  - `attachment_service.proto` — Attachment handling
  - `instance_service.proto` — Instance configuration
  - `shortcut_service.proto` — Keyboard shortcuts
  - `ai_service.proto` — AI features
  - `idp_service.proto` — Identity provider configuration
  - `common.proto` — Shared message types

These proto files follow Google API Improvement Proposals (AIPs) guidelines and are compiled to generate REST API endpoints (as seen in the HTTP annotations like `post: "/api/v1/memos"`). An OpenAPI schema is generated from these proto definitions and is available at `/bench/repo/proto/gen/openapi.yaml`.
