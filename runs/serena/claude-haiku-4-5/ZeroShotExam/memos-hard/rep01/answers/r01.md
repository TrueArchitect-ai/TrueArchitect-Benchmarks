**Premise Correction:** The question assumes Redis is the cache layer, but it is not.

**Actual Mechanism:**

The Redis connection is **not configured** because this application uses an **in-memory cache**, not Redis.

The cache layer is configured in `/bench/repo/store/store.go:40-45` where the Store is instantiated:

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```

User entries use the `userCache` field (defined at `/bench/repo/store/store.go:28`), which is initialized as `cache.New(cacheConfig)` at line 52. The implementation is in `/bench/repo/store/cache/cache.go` - a thread-safe, in-memory cache using `sync.Map`.

**TTL for user entries:** **10 minutes** (configured via `DefaultTTL: 10 * time.Minute` in `/bench/repo/store/store.go:41`). User entries are cached via `s.userCache.Set(ctx, userCacheKey(user.ID), user)` in `/bench/repo/store/user.go` (lines 98, 122, 132, 143, 167), which applies the default TTL of 10 minutes.
