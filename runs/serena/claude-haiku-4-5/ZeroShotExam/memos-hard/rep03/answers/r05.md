**Premise correction:** This repository does not use GraphQL. The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL.

**Actual API surface:**

The GraphQL schema question is based on a false premise. The actual public API is defined in:

1. **Protocol Buffer definitions** in `/bench/repo/proto/api/v1/`:
   - `memo_service.proto` — memo CRUD, comments, reactions
   - `user_service.proto` — user management and auth
   - `auth_service.proto` — authentication operations
   - `attachment_service.proto` — attachment handling
   - `instance_service.proto` — instance configuration
   - Plus: `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `common.proto`

2. **Generated OpenAPI specification** at `/bench/repo/proto/gen/openapi.yaml` — the REST/HTTP surface derived from the protobuf definitions

The API is REST-based with `/api/v1/` endpoints, not GraphQL-based.
