**Computation site:** The memo's derived metadata (Property) is computed in the Go markdown service at `/bench/repo/internal/markdown/markdown.go` (specifically in the `ExtractProperties()` method at lines 193-241 and the `ExtractAll()` method at lines 356-421).

**Triggers for recomputation:** The computation is triggered during:
1. **Memo creation** (`CreateMemo` in `/bench/repo/server/router/api/v1/memo_service.go`): calls `memopayload.RebuildMemoPayload()` which invokes `ExtractAll()`
2. **Memo content update** (`UpdateMemo` in same file): when the "content" field is updated, `RebuildMemoPayload()` is called
3. **Manual batch rebuild** via the `RunOnce()` runner in `/bench/repo/server/runner/memopayload/runner.go` (processes all memos in batches of 100)

**Extracted properties** (from the `Memo.Property` message defined in `/bench/repo/proto/api/v1/memo_service.proto` lines 272-279):
- `has_link` (bool): whether the content contains any links
- `has_task_list` (bool): whether the content contains task list items
- `has_code` (bool): whether the content contains code blocks or inline code spans  
- `has_incomplete_tasks` (bool): whether the content contains unchecked task list items
- `title` (string): the text of the first H1 heading, if present

These are extracted by parsing the markdown AST and walking its nodes, detecting specific node types (links, code blocks, task checkboxes, H1 headings).
