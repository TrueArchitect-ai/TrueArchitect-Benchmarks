Based on my investigation of this repository, **there is no GraphQL schema defined**. This is not a GraphQL-based API project.

The public API for Memos is defined using **Protocol Buffers (gRPC)** instead. The API schema is located in:

**`/bench/repo/proto/api/v1/`**

This directory contains the following `.proto` service definitions:
- `memo_service.proto` — Memo operations (create, read, update, delete memos)
- `user_service.proto` — User management and authentication
- `auth_service.proto` — Authentication endpoints
- `attachment_service.proto` — Attachment handling
- `shortcut_service.proto` — Shortcut management
- `instance_service.proto` — Instance configuration
- `idp_service.proto` — Identity provider integration
- `ai_service.proto` — AI features
- `common.proto` — Shared definitions

The README states the project exposes "full REST and gRPC APIs" but these are derived from the Protocol Buffer definitions in `proto/api/v1/`, not from GraphQL.
