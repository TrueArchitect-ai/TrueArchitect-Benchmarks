There is **no GraphQL schema** for the public API in this repository. 

**Premise correction:** This is a misconception — Memos does not expose a GraphQL API.

**Actual API surface:** Memos exposes:
- **gRPC API** — Defined in protobuf files at `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/attachment_service.proto`, etc.)
- **REST API** — Auto-generated from the gRPC definitions and documented in `proto/gen/openapi.yaml`

The README explicitly states "full REST and gRPC APIs," and there are no `.graphql` schema files anywhere in the codebase. The generated OpenAPI specification at `proto/gen/openapi.yaml` provides the OpenAPI documentation for the REST API surface.
