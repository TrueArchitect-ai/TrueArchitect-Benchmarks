**Answer:** `github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`

**Explanation:**

The abstraction package is `internal/idp` (at `/bench/repo/internal/idp/idp.go`), which defines the `IdentityProviderUserInfo` struct that represents the abstract user information model returned by any identity provider. This serves as the common interface contract for IDP implementations.

The concrete protocol implementation is `internal/idp/oauth2` (at `/bench/repo/internal/idp/oauth2/oauth2.go`), which implements OAuth2 identity provider integration. The `oauth2.IdentityProvider` struct provides the concrete implementation with methods:
- `ExchangeToken()` - exchanges authorization code for access token
- `UserInfo()` - retrieves and maps user information from the OAuth2 provider's userinfo endpoint

This is used in `server/router/api/v1/auth_service_sso.go` where `oauth2.NewIdentityProvider()` is called to handle OAuth2-based authentication through third-party identity providers.
