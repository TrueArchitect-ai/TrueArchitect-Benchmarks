**Premise correction + actual API surface:**

The repository does **not** use GraphQL. Instead, it uses **Protocol Buffers (protobuf)** with gRPC/Connect for its public API.

The public API schema is defined in **proto files** located at:
- **Primary location:** `/bench/repo/proto/api/v1/` directory

Key schema files include:
- `memo_service.proto` — Memo operations (create, list, update, delete)
- `user_service.proto` — User operations
- `auth_service.proto` — Authentication operations
- `attachment_service.proto` — Attachment/file operations
- `ai_service.proto` — AI-related operations
- `shortcut_service.proto` — Shortcut operations
- `instance_service.proto` — Instance configuration
- `idp_service.proto` — Identity provider operations
- `common.proto` — Shared data types

The API follows **Google API Improvement Proposals (AIPs)** guidelines (as noted in `/bench/repo/proto/api/v1/README.md`). These protobuf definitions are compiled to Go code (located in `/bench/repo/proto/gen/api/v1/`) and served via a Connect/gRPC gateway at `/api/v1/` endpoints using HTTP (as seen in `/bench/repo/server/router/api/v1/v1.go`).
