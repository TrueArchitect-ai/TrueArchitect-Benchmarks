**Premise correction:** This repository does not use Redis. There is no external Redis connection configured.

**Actual mechanism:** The cache layer is implemented as an in-memory cache in `/bench/repo/store/cache/cache.go`. 

User entries are cached in `/bench/repo/store/user.go` using an instance of this in-memory cache (`userCache`). The TTL is configured in `/bench/repo/store/store.go`:

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
}
```

**User entry TTL: 10 minutes.** This TTL is hardcoded and not configurable via environment variables. The cache automatically removes expired entries every 5 minutes via a background cleanup routine.
