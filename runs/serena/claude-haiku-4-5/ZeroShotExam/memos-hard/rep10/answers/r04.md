The webhook delivery workers use **neither NATS nor RabbitMQ**. They consume from an in-process buffered Go channel instead.

**Queue declaration location**: `/bench/repo/internal/webhook/webhook.go` lines 39-55

The queue is declared as:
```go
var asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

With 4 concurrent worker goroutines created in the `init()` function that consume from this channel and perform synchronous HTTP POST deliveries. This is a lightweight in-process async queue pattern, not an external message broker architecture.
