**Premise correction:** This repository does not use GraphQL for its public API.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) in the `/bench/repo/proto/api/v1/` directory. The API services are defined in individual `.proto` files:

- `proto/api/v1/memo_service.proto` — MemoService (create, list, get, update, delete memos)
- `proto/api/v1/user_service.proto` — UserService (user management)
- `proto/api/v1/auth_service.proto` — AuthService (authentication, sign in/out, token refresh)
- `proto/api/v1/attachment_service.proto` — AttachmentService (attachment management)
- `proto/api/v1/shortcut_service.proto` — ShortcutService (shortcuts)
- `proto/api/v1/instance_service.proto` — InstanceService (instance configuration)
- `proto/api/v1/idp_service.proto` — IdentityProviderService (IDP configuration)
- `proto/api/v1/ai_service.proto` — AIService (AI operations like transcription)

The proto files follow Google API Improvement Proposals (AIPs) guidelines and use `google.api.http` annotations to map RPCs to HTTP endpoints under `/api/v1/`.
