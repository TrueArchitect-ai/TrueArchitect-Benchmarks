**Premise correction:** This repository does not use GraphQL. The public API is defined using Protocol Buffers (protobuf) with gRPC and REST (gRPC-Gateway).

**Actual API surface:**

The public API schema is defined through:

1. **Proto source files** (proto definitions) — `/bench/repo/proto/api/v1/*.proto`
   - `memo_service.proto`
   - `user_service.proto`
   - `attachment_service.proto`
   - `auth_service.proto`
   - `ai_service.proto`
   - `idp_service.proto`
   - `instance_service.proto`
   - `shortcut_service.proto`
   - `common.proto`

2. **Generated OpenAPI schema** — `/bench/repo/proto/gen/openapi.yaml`
   - This is the compiled, canonical public API specification generated from the proto definitions (4,057 lines)
   - Defines REST endpoints, request/response schemas, and OpenAPI 3.0.3 specification for the public API

3. **Generated code** — `/bench/repo/proto/gen/api/v1/`
   - Language-specific generated bindings (TypeScript, Go, etc.)

4. **API handlers** — `/bench/repo/server/router/api/v1/`
   - Implementation of the API endpoints (e.g., `memo_service.go`, `user_service.go`, etc.)
