**Premise Correction:** This repository does not use GraphQL for its public API.

**Actual API Surface:**

The public API is defined using **Protocol Buffers and OpenAPI**:

1. **Protocol Buffer Service Definitions** (`/bench/repo/proto/api/v1/`):
   - `ai_service.proto`
   - `attachment_service.proto`
   - `auth_service.proto`
   - `common.proto`
   - `idp_service.proto`
   - `instance_service.proto`
   - `memo_service.proto`
   - `shortcut_service.proto`
   - `user_service.proto`

2. **Generated OpenAPI Specification**: `/bench/repo/proto/gen/openapi.yaml`
   - Auto-generated from proto definitions using `protoc-gen-openapi`
   - Embedded in the Go binary via `/bench/repo/proto/openapi_embed.go`

3. **API Implementation**: `/bench/repo/server/router/api/v1/`

The architecture uses a single-source-of-truth approach where proto files define service contracts, `buf generate` produces the OpenAPI YAML and language bindings, and handlers implement the services.
