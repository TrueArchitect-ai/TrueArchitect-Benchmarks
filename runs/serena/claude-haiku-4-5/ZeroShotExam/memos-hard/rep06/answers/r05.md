**Premise correction:** This repository does not use GraphQL. It uses **Protocol Buffers (protobuf)** for its public API schema.

**Actual API surface:**

The public API is defined in `/bench/repo/proto/api/v1/`, which contains nine proto service files:

1. **memo_service.proto** — Core memo CRUD operations, attachments, relations, comments, reactions, shares
2. **user_service.proto** — User management, authentication, settings, personal access tokens, webhooks
3. **auth_service.proto** — Authentication (SignIn, SignOut, RefreshToken, GetCurrentUser)
4. **attachment_service.proto** — File attachment operations
5. **instance_service.proto** — Instance configuration and management
6. **idp_service.proto** — Identity provider management
7. **shortcut_service.proto** — User shortcuts
8. **ai_service.proto** — AI transcription
9. **common.proto** — Shared enums and message types

The API follows **Google API Improvement Proposals (AIPs)** standards and is exposed as a REST API at `/api/v1/*` endpoints using Google API annotations for HTTP mappings. Generated OpenAPI/Swagger documentation is available at `/bench/repo/proto/gen/openapi.yaml`.
