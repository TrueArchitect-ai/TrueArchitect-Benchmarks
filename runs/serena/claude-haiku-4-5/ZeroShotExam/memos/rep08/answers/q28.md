q28.

The server starts the following background worker(s):

**S3 Presign Runner** — 12-hour timer interval (runs every 12 hours via `time.NewTicker`), plus one-time execution on startup. This runner checks and presigns S3 attachment URLs that are expiring.

**Unused Infrastructure:**

The `internal/scheduler` package provides a full production-ready cron job scheduler with standard cron syntax, timezone support, middleware pattern, and graceful shutdown capabilities. However, **this scheduler infrastructure is not instantiated or used by the server** — only in its own test files (`example_test.go`, `integration_test.go`).
