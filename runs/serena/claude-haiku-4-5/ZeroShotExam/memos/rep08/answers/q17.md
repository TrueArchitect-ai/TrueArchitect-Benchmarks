The memo CRUD mutations and queries are contained in the frontend module at **web/src/hooks/useMemoQueries.ts**, and it uses the **memoServiceClient** (imported on line 5 from "@/connect").

The module exports the following CRUD operations:
- **Queries**: `useMemos()`, `useInfiniteMemos()`, `useMemo()`, `useMemoComments()`, `useInfiniteMemoComments()`, `useLinkMetadata()`
- **Mutations**: `useCreateMemo()`, `useUpdateMemo()`, `useDeleteMemo()`

All of these use the `memoServiceClient` which is a generated service client created from `MemoService` (imported from "./types/proto/api/v1/memo_service_pb").
