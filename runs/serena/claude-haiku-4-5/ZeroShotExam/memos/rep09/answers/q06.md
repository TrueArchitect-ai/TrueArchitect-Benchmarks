The database table that stores links between one memo and another related memo is **`memo_relation`**.

This table is defined in both the PostgreSQL and SQLite schema files at:
- `/bench/repo/store/migration/postgres/LATEST.sql` (lines 45-51)
- `/bench/repo/store/migration/sqlite/LATEST.sql` (lines 46-52)

The `memo_relation` table has three columns:
- `memo_id` - references the primary memo
- `related_memo_id` - references the related memo
- `type` - specifies the type of relationship

There is a UNIQUE constraint on the combination of `(memo_id, related_memo_id, type)` to ensure each relationship is stored only once.
