The memo lifecycle events that dispatch webhooks are:

**Dispatch Functions:**
- `memos.memo.created`: DispatchMemoCreatedWebhook
- `memos.memo.updated`: DispatchMemoUpdatedWebhook
- `memos.memo.deleted`: DispatchMemoDeletedWebhook
- `memos.memo.comment.created`: DispatchMemoCommentCreatedWebhook

**Delivery Convergence:**
All webhook dispatches converge through the `webhook.PostAsync()` function in `/bench/repo/internal/webhook/webhook.go` (line 184). This function enqueues payloads to an async queue that's processed by 4 worker goroutines spawned during `init()` (lines 42-55), which each call the synchronous `Post()` function (line 46) for actual HTTP delivery.

The delivery execution happens in `/bench/repo/internal/webhook/webhook.go:Post()` (line 120), which performs the actual HTTP POST request with optional HMAC-SHA256 signing.
