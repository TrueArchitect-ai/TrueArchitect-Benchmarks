**Frontend API Authentication:**

**Interceptor path:** `web/src/connect.ts` (lines 156-178)
- The `authInterceptor` is a Connect RPC interceptor that handles token management for all API requests

**Token kinds managed:**
1. **Access Token (JWT)** - Short-lived tokens (15 minutes) for normal API access, stored in `web/src/auth-state.ts`
2. **Personal Access Token (PAT)** - Long-lived tokens for programmatic access
3. **Refresh Token** - Stored in an HTTP-only cookie for token refresh operations

**Backend validation package:** `server/auth` (specifically `server/auth/authenticator.go`)

The `Authenticator` type in `server/auth/authenticator.go` validates:
- **AccessTokenV2** via `AuthenticateByAccessTokenV2()` - stateless JWT validation
- **Personal Access Tokens** via `AuthenticateByPAT()` - stored in database with revocation and expiry checks
- **Refresh Tokens** via `AuthenticateByRefreshToken()` - database-backed token validation

The frontend interceptor sets an `Authorization: Bearer {token}` header (line 99 in `connect.ts`), which the backend's `Authenticator` extracts and validates.
