The **CEL-Go** engine parses ListMemos filter expressions; it lives in `/bench/repo/internal/filter/engine.go` (line 9 imports `"github.com/google/cel-go/cel"`). The filter becomes SQL via a dialect-agnostic condition tree: `Engine.Compile()` parses the CEL expression into an AST, `buildCondition()` converts it to a `Condition` tree, and `Program.Render()` walks the tree with a `renderer` that emits dialect-specific SQL for each database (SQLite, Postgres, MySQL) by selecting appropriate functions and operators per dialect (e.g., `JSON_EXTRACT` for SQLite/MySQL vs `->` operators for Postgres, `ILIKE` vs `LIKE` for case-insensitivity).
