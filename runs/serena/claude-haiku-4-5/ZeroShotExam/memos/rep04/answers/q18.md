The three database driver interface implementations and their entry files are:

1. **store/db/sqlite/sqlite.go** — SQLite implementation (type `DB`)
2. **store/db/mysql/mysql.go** — MySQL implementation (type `DB`)
3. **store/db/postgres/postgres.go** — PostgreSQL implementation (type `DB`)

The factory function that selects between them at startup:

**NewDBDriver** — **store/db/db.go**

This function uses a switch statement on `profile.Driver` to select which implementation to instantiate, calling either `sqlite.NewDB()`, `mysql.NewDB()`, or `postgres.NewDB()` based on the configuration.
