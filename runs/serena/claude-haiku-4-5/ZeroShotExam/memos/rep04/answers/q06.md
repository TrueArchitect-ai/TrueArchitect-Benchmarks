The database table that stores links between one memo and another related memo is **memo_relation**.

This table has the following structure:
- **memo_id**: References the source memo
- **related_memo_id**: References the related/destination memo
- **type**: The relationship type (e.g., REFERENCE, COMMENT)

The table is defined in the schema files at `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql` and in the LATEST.sql files for all database backends (SQLite, PostgreSQL, and MySQL).
