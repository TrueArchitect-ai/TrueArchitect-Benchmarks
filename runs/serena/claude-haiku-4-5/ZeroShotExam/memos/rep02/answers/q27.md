**Mechanism:** Go's `embed` package (static file embedding)

**File:** `/bench/repo/server/router/frontend/frontend.go`

The React frontend is compiled to `/server/router/frontend/dist` (line 11 of web/package.json's release script), then embedded into the binary using Go's `//go:embed dist/*` directive at line 20 of frontend.go. The `FrontendService.Serve()` method (line 41) registers an Echo middleware that serves these embedded files as static assets, with a fallback to `index.html` for SPA routing (lines 59-79).
