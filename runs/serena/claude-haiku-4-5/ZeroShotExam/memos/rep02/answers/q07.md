The ConnectRPC service clients are created in this file using the `createClient` function from `@connectrpc/connect`. The file creates and exports multiple service clients including:

- authServiceClient
- userServiceClient
- memoServiceClient
- attachmentServiceClient
- aiServiceClient
- shortcutServiceClient
