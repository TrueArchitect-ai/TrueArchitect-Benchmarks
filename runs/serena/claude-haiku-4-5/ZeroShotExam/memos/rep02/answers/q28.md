q28.

The server actually starts **one background worker**:

**s3presign runner** — triggered by a time-based ticker that fires every 12 hours (runnerInterval = 12h). The runner executes immediately upon startup (via RunOnce), then continuously runs on the 12-hour schedule in the Run() method.

**Unused scheduling infrastructure:**

The `internal/scheduler` package provides a GitHub Actions-inspired cron job scheduler with support for standard 5-field and 6-field cron expressions, custom timezones, and middleware support. However, this entire scheduler infrastructure is **NOT used by the server** — no jobs are registered with it, and it is never instantiated or started. The scheduler exists in the codebase but is completely unused.

Additionally, the `server/runner/memopayload` package defines a Runner with a RunOnce() method, but it is also **NOT started** by the server during initialization.

See:
- /bench/repo/server/server.go:153-174 (startBackgroundRunners method - shows only s3presign runner is started)
- /bench/repo/server/runner/s3presign/runner.go:26-40 (12-hour scheduling via time.Ticker)
- /bench/repo/internal/scheduler/scheduler.go (unused scheduler package)
