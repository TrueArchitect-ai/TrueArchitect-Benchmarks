q27. Go's `embed` package (//go:embed directive); `/bench/repo/server/router/frontend/frontend.go`

The mechanism is Go's built-in `embed` package, which embeds the compiled React frontend from the `dist/` directory directly into the binary at compile time (line 20: `//go:embed dist/*`). The embedded filesystem is then served through Echo middleware using `StaticConfig` (line 54) with SPA fallback routing. This is wired in `/bench/repo/server/router/frontend/frontend.go`.
