**Engine + Path:** CEL (Common Expression Language) engine via Google's `cel-go` library; lives in `/bench/repo/internal/filter/`

**Mechanism:** The filter is parsed by cel-go into a CEL AST, then converted to a dialect-agnostic condition tree (in `/bench/repo/internal/filter/parser.go` via `buildCondition()` → intermediate representation types in `ir.go`), then rendered to SQL for each dialect (sqlite, mysql, postgres) by the renderer in `/bench/repo/internal/filter/render.go` using dialect-specific column qualifiers, JSON accessors, and timestamp conversion expressions defined in the schema (`schema.go`).
