**Engine + Path:** CEL (Common Expression Language, via `cel-go` library) + `/bench/repo/internal/filter/`

**Mechanism:** The filter engine parses CEL expressions into a dialect-agnostic intermediate representation (IR) tree, then renders the IR to SQL using a renderer that generates dialect-specific fragments for SQLite, MySQL, and Postgres by switching on `DialectName` enum values (see `/bench/repo/internal/filter/render.go`).
