Based on my analysis of the codebase, the server starts the following background worker:

**S3 Presign Runner** — time.Ticker with 12-hour interval (runs every 12 hours)

The runner is started in `server/server.go:153-171` in the `startBackgroundRunners()` method. It performs initial run via `RunOnce()` at startup, then enters a continuous loop via `Run()` that uses a time.NewTicker with a 12-hour interval to periodically check S3 attachments and refresh their presigned URLs.

**Unused Infrastructure Note:**
The codebase contains a complete scheduler framework in `internal/scheduler/` that supports cron-expression-based job scheduling (with timezone support, middleware, etc.), but it is NOT used by the server. The scheduler package is only present in tests and documentation examples. The server instead implements scheduling directly via the s3presign runner's time.Ticker approach.
