q29.

**Interceptor path:** `/bench/repo/web/src/connect.ts` (lines 156-178, the `authInterceptor` constant)

**Token kinds:** 
- Access Token (JWT, short-lived, 15 minutes) - sent as `Bearer` token in Authorization header
- Personal Access Token (PAT) - sent as `Bearer` token with `memos_pat_` prefix
- Refresh Token - stored as a cookie (used for obtaining new access tokens)

**Backend package path:** `/bench/repo/server/auth` (specifically `authenticator.go` which contains the `Authenticator` struct that validates tokens)

The auth interceptor in `connect.ts` intercepts frontend API requests, retrieves an access token via `getRequestToken()`, and adds it as a `Bearer` token in the Authorization header. The backend's `server/auth/authenticator.go` validates these tokens through:
- `AuthenticateByAccessTokenV2()` for JWT access tokens (stateless validation)
- `AuthenticateByPAT()` for Personal Access Tokens
- `AuthenticateByRefreshToken()` for refresh tokens (with database revocation check)
