The interceptor (`authInterceptor`) manages the Authorization header with Bearer tokens. It handles:
- Setting access tokens on outgoing requests (line 159)
- Proactive token refresh before expiry (lines 140-147)
- Reactive token refresh on 401 responses (lines 163-176)
- Token refresh via BroadcastChannel for multi-tab synchronization (auth-state.ts)

The backend validates tokens in the `server/auth` package (`server/auth/authenticator.go`, `server/auth/token.go`), which provides:
