**CEL (Common Expression Language) via cel-go; `/bench/repo/internal/filter/`**

**Mechanism**: The filter string is parsed by cel-go into an AST, then transformed by `buildCondition()` in `parser.go` into a database-agnostic IR (Condition tree), which `renderer.Render()` converts to dialect-specific SQL via methods like `renderComparison()`, `renderListComprehension()`, etc. that emit SQLite/MySQL/PostgreSQL syntax with parameterized arguments.
