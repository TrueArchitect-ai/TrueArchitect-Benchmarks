**Mechanism**: Embedded filesystem (Go `//go:embed` directive)

**File**: `/bench/repo/server/router/frontend/frontend.go`

The compiled React frontend is embedded directly into the Go binary using Go's `//go:embed dist/*` directive (line 20), which embeds the built frontend files from the `dist/` directory. This embedded filesystem is then served via Echo middleware (lines 54-59) using Echo's `StaticWithConfig` middleware, which handles serving static assets with appropriate cache headers. When a request for a non-API path results in a 404, the SPA fallback middleware (line 59) serves `index.html` to enable client-side routing.
