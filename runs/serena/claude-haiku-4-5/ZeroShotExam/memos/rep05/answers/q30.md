The memo lifecycle events that dispatch webhooks are:

**Event: Dispatch Function**
- `memos.memo.created`: DispatchMemoCreatedWebhook
- `memos.memo.updated`: DispatchMemoUpdatedWebhook
- `memos.memo.deleted`: DispatchMemoDeletedWebhook
- `memos.memo.comment.created`: DispatchMemoCommentCreatedWebhook

**Delivery Convergence Point**

All webhook dispatches converge at the `webhook.PostAsync()` function located in `/bench/repo/internal/webhook/webhook.go:184`. This function enqueues payloads to `asyncPostQueue` (line 39), a buffered channel with 4 worker goroutines (lines 43-55) that consume from the queue and call `Post()` (line 46) to deliver the webhooks. The `Post()` function (line 120) handles the actual HTTP delivery with HMAC-SHA256 signing and SSRF protection.
