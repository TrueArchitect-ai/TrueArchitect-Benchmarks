**Mechanism:** Go's `embed` directive with `StaticWithConfig` middleware in Echo framework

**Path:** `server/router/frontend/frontend.go`

The compiled React frontend is embedded directly into the Go binary at build time using Go's `//go:embed dist/*` directive (line 20), which packages all files from the `dist/` directory (the compiled React output from Vite). In production, the Echo HTTP server serves these embedded files using the `StaticWithConfig` middleware (line 54-57), which also includes a SPA fallback middleware (line 59) that routes unmatched paths to `index.html` for client-side routing.
