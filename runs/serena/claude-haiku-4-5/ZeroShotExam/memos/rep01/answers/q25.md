**Engine + Path:** CEL (Common Expression Language) engine via `google.golang.org/genproto/googleapis/api/expr/v1alpha1` + `internal/filter/`

**Mechanism:** The CEL engine parses filter expressions into an AST, which is converted to a dialect-agnostic condition tree (in `/bench/repo/internal/filter/engine.go`), then the `Render()` method walks the condition tree and generates dialect-specific SQL by switching on the `DialectName` enum (SQLite/MySQL/Postgres) to emit appropriate SQL syntax and functions for each dialect (`/bench/repo/internal/filter/render.go`).
