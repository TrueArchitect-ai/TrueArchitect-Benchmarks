The server uses Server-Sent Events (SSE) to push live events to browsers. The hub is implemented in `/bench/repo/server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through it are: CreateMemo, UpdateMemo (via dispatchMemoUpdatedSideEffects), DeleteMemo, CreateMemoComment, UpsertMemoReaction, and DeleteMemoReaction.
