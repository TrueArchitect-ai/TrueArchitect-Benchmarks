Go's embed directive with Echo middleware; /bench/repo/server/router/frontend/frontend.go

The compiled React frontend is served using Go's `embed` directive (line 20: `//go:embed dist/*`) which embeds the built frontend files into the binary. These are then served through Echo middleware (`middleware.StaticWithConfig`) with an SPA fallback (routes without file extensions fall back to `index.html`). The mechanism is wired in `/bench/repo/server/server.go` where `FrontendService.Serve()` is called during server initialization.
