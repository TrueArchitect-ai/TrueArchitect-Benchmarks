CEL (Common Expression Language) — internal/filter/engine.go; The filter engine compiles CEL expressions to a dialect-agnostic condition tree, then renders it to dialect-specific SQL (SQLite, MySQL, PostgreSQL) with appropriate functions and placeholder syntax via the renderer with a DialectName parameter.

**Source:**
- **Engine:** `internal/filter/engine.go` uses `cel-go` (google/cel-go) to parse CEL expressions
- **Mechanism:** CEL expressions are compiled to a `Condition` tree via `Engine.Compile()`, then the `renderer` in `internal/filter/render.go` converts the condition tree to dialect-specific SQL (SQLite, MySQL, PostgreSQL) by selecting appropriate SQL functions and syntax based on the `DialectName` parameter (defined in `internal/filter/schema.go`)
- **Usage:** Each dialect's `ListMemos` implementation (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`) calls `filter.AppendConditions()` with its `DialectSQLite` or `DialectPostgres` constant to generate the appropriate SQL WHERE clause
