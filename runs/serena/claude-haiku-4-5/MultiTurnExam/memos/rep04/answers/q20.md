The server uses **Server-Sent Events (SSE)** to push live events to browsers. The mechanism is implemented in the **SSEHub** class in `/bench/repo/server/router/api/v1/sse_hub.go` (with supporting code in sse_event_helpers.go and sse_handler.go).

The memo handlers that broadcast through the hub are:
1. **CreateMemo** (line 163 in memo_service.go) - broadcasts `memo.created` event
2. **UpdateMemo** (via dispatchMemoUpdatedSideEffects in memo_update_helpers.go:71) - broadcasts `memo.updated` event  
3. **DeleteMemo** (line 585 in memo_service.go) - broadcasts `memo.deleted` event
4. **CreateMemoComment** (line 126 in memo_service_comments.go) - broadcasts `memo.comment.created` event
