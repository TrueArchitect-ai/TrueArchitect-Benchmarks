Frontend API requests are authenticated using:
- **Auth interceptor**: defined in `/bench/repo/web/src/connect.ts` (lines 156-178), which adds Bearer token authorization headers and handles 401 responses with token refresh
- **Token kinds managed**: 
  - Access tokens (short-lived JWT tokens, 15-minute duration, stored in memory/localStorage)
  - Refresh tokens (long-lived JWT tokens, 30-day duration, stored in HttpOnly cookies)
  - Personal Access Tokens (PATs) for programmatic access
- **Backend validation package**: `/bench/repo/server/auth` which provides JWT token validation, token generation, and authentication context management (as documented in `/bench/repo/server/auth/token.go`)
