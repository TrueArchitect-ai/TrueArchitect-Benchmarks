The compiled React frontend is served using **Go's embed package** (`embed.FS`), which embeds the built frontend files at compile time. The mechanism is implemented in `/bench/repo/server/router/frontend/frontend.go`:
- Line 20: `//go:embed dist/*` embeds the `dist` directory containing the compiled React build
- Lines 54-57: Echo's `middleware.StaticWithConfig` serves the embedded files
- Line 59: An SPA fallback middleware catches unmatched routes and serves `index.html` for client-side routing
- This service is wired into the main server in `/bench/repo/server/server.go:72` where `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` is called
