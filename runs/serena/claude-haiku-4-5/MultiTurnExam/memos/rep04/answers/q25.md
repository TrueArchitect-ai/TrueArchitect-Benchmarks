CEL (Common Expression Language) — /bench/repo/internal/filter/engine.go; Each database dialect implements its own SQL renderer that transforms the CEL-compiled condition tree into dialect-specific SQL via the `RenderOptions` and `Dialect` parameter, called from each driver's ListMemos method (e.g., `/bench/repo/store/db/sqlite/memo.go:61` uses `filter.AppendConditions` with `DialectSQLite`).

The ListMemos filter works as follows:
- **Engine**: CEL (Common Expression Language) from `google/cel-go` located in `/bench/repo/internal/filter/engine.go`
- **Parsing**: The `Engine.CompileToStatement` method (line 74) parses CEL expressions into a dialect-agnostic condition tree
- **SQL conversion**: The `Program.Render` method (line 96) converts the condition tree to dialect-specific SQL using a `Renderer` that respects the `RenderOptions.Dialect` parameter (SQLite, PostgreSQL, or MySQL)
- **Application**: Each dialect driver calls `filter.AppendConditions` (from `/bench/repo/internal/filter/helpers.go:9`) with its dialect, which compiles the filter strings and injects the resulting SQL WHERE clauses and args into the query
