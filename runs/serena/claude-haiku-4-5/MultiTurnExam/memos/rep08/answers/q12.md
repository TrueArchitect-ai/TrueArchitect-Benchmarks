The request flow: `useMemos` hook calls `memoServiceClient.listMemos` (created in `connect.ts`), which invokes the `ListMemos` RPC defined in `memo_service.proto`, handled by `APIV1Service.ListMemos` in `memo_service.go`, which calls `Store.ListMemos` (defined in `driver.go`), with a SQLite implementation in `sqlite/memo.go` (similarly for PostgreSQL and MySQL).
