q29. **/bench/repo/web/src/connect.ts (authInterceptor at line 156); access tokens and refresh tokens; /bench/repo/server/auth**

Frontend API requests are authenticated through the `authInterceptor` defined in `/bench/repo/web/src/connect.ts` (line 156). The interceptor manages two token kinds:
1. **Access tokens** - short-lived JWT tokens (15 minutes) sent in the Authorization header
2. **Refresh tokens** - stored as HttpOnly cookies, used to obtain new access tokens

These tokens are validated by the backend `auth` package (`/bench/repo/server/auth`), specifically through the `Authenticator` struct (in `/bench/repo/server/auth/authenticator.go`), which provides stateless validation for access tokens and handles refresh token verification.
