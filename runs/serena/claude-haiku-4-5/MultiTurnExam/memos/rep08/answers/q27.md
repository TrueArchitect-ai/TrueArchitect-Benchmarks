q27. **Embedded filesystem (Go embed directive); /bench/repo/server/router/frontend/frontend.go**

The compiled React frontend is served in production using Go's `embed` package. The compiled frontend assets are embedded at compile-time via the `//go:embed dist/*` directive (line 20) in `/bench/repo/server/router/frontend/frontend.go`. This embeds the built React application (from the `dist` directory) directly into the binary. The `FrontendService.Serve()` method (line 41) then configures the Echo HTTP server to serve these embedded files with appropriate cache headers and SPA fallback routing (serving `index.html` for all routes without extensions).
