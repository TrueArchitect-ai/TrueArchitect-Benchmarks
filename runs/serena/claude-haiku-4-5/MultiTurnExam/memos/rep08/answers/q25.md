q25. **CEL (Common Expression Language) engine — /bench/repo/internal/filter/engine.go; The filter string is parsed into a dialect-agnostic condition tree by the CEL engine, then rendered to SQL-specific WHERE clauses and placeholders for each dialect via the AppendConditions helper which calls CompileToStatement with the appropriate dialect.**

The ListMemos RPC accepts CEL filter expressions. The CEL engine lives in `/bench/repo/internal/filter/engine.go` (using google/cel-go library). The filter expression is compiled into a dialect-agnostic condition tree, then passed to the database driver (e.g., `/bench/repo/store/db/postgres/memo.go` line 58), which calls `filter.AppendConditions()` to render it to SQL-specific WHERE clauses and parameter placeholders based on the dialect (PostgreSQL, MySQL, or SQLite).
