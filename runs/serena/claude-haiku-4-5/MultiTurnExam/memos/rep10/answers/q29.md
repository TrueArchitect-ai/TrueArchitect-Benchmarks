Frontend API requests are authenticated via the `authInterceptor` defined in `/bench/repo/web/src/connect.ts` (line 156). The interceptor manages the access token (stored in localStorage) and refresh token (sent as a cookie). On 401 responses, it automatically refreshes the access token via the AuthService's RefreshToken RPC. The backend validates tokens using the `Authenticator` package in `/bench/repo/server/auth`, which provides stateless JWT access token validation and Personal Access Token (PAT) verification.
