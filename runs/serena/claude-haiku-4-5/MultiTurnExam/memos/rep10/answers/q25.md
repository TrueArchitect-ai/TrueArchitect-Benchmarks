CEL (Common Expression Language) with google/cel-go — /bench/repo/internal/filter/engine.go; the Engine parses CEL expressions into a dialect-agnostic condition tree, then the Renderer converts that tree to dialect-specific SQL using a map of SQL functions per dialect (see schema.go).

The ListMemos RPC accepts a CEL expression filter. The CEL engine and parser are in `/bench/repo/internal/filter/engine.go` (using google/cel-go library). Each dialect implementation (sqlite, postgres, mysql) calls `filter.AppendConditions()` with its dialect constant (DialectSQLite, DialectPostgres, DialectMySQL), which uses the renderer to compile the CEL expression into dialect-specific SQL with placeholders for query arguments. The dialect-specific SQL functions are defined in `/bench/repo/internal/filter/schema.go` as a map that translates function calls like `CONCAT` to the appropriate SQL syntax per database.
