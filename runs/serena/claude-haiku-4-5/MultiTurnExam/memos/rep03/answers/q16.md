Looking at the Store.DeleteMemo method in `/bench/repo/store/memo.go`, I can see exactly what gets deleted before the memo row itself:

1. **memo_relation records** - where the memo is the source (MemoID) 
2. **memo_relation records** - where the memo is the target (RelatedMemoID)
3. **attachments** - all attachments linked to the memo

The API layer also deletes memo comments (which are memos themselves with a relation type), but that happens in the API handler before calling Store.DeleteMemo, not within the store layer itself.
