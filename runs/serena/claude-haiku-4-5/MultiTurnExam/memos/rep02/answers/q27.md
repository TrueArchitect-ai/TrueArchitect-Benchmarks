q27. Embedded filesystem (Go embed); server/router/frontend/frontend.go

The compiled React frontend is served via Go's `embed` directive (line 20: `//go:embed dist/*`), which embeds the built frontend files directly into the binary. The `FrontendService.Serve` function in `server/router/frontend/frontend.go` wires this up using Echo's static middleware to serve assets from the embedded filesystem, with a SPA fallback middleware that serves `index.html` for all non-asset routes (lines 54-59, 63-79).
