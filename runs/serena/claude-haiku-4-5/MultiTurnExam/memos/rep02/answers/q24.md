The complete call chain for creating a memo is: (1) frontend mutation hook `useCreateMemo` in `web/src/hooks/useMemoQueries.ts`, (2) generated client `memoServiceClient` from `web/src/connect.ts`, (3) proto RPC `CreateMemo` defined in `proto/api/v1/memo_service.proto`, (4) backend handler `APIV1Service.CreateMemo` in `server/router/api/v1/memo_service.go`, (5) store method `Store.CreateMemo` in `store/memo.go`, (6) SQLite driver implementation `DB.CreateMemo` in `store/db/sqlite/memo.go` which executes the SQL INSERT.
