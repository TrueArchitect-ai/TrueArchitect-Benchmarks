q29. web/src/connect.ts; access tokens (JWT, 15-minute duration) and refresh tokens (JWT, 30-day duration, stored in httpOnly cookie); server/auth

Frontend API requests are authenticated through the `authInterceptor` in `web/src/connect.ts` (lines 156-178), which manages two token kinds: short-lived JWT access tokens (15-minute duration) and long-lived JWT refresh tokens (30-day duration, stored in httpOnly cookies). Token validation is performed by the `server/auth` package (specifically `authenticator.go` and `token.go`), which handles both access token validation and refresh token validation against the database.
