q20. Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The hub is implemented in `server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through the SSE hub are: `CreateMemo` (line 163), `UpdateMemo` (dispatched via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go`), and `DeleteMemo` (line 585).
