**Premise correction:** There is no GraphQL schema. The API is not GraphQL-based.

**Actual API surface:** The public API is defined using Protocol Buffers (gRPC), not GraphQL. The API schemas are located in `/bench/repo/proto/api/v1/` with the following service definitions:

- `memo_service.proto` — Memo operations (create, read, update, delete)
- `attachment_service.proto` — Attachment management
- `user_service.proto` — User management
- `auth_service.proto` — Authentication and authorization
- `instance_service.proto` — Instance configuration and settings
- `shortcut_service.proto` — Shortcut operations
- `ai_service.proto` — AI/LLM integrations
- `idp_service.proto` — Identity provider configuration
- `common.proto` — Common types and messages

The API is exposed via:
1. **gRPC-Gateway** (REST over HTTP/JSON) — registered in `/bench/repo/server/router/api/v1/v1.go:99-122`
2. **Connect RPC** (gRPC over HTTP/1.1 or HTTP/2) — registered in `/bench/repo/server/router/api/v1/v1.go:139-144`

Both are generated from the `.proto` definitions in the `proto/api/v1/` directory.
