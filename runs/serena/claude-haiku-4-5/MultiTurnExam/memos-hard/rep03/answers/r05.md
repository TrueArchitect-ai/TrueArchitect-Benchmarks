**Premise correction:** GraphQL is not used. The public API is gRPC with Protocol Buffers.

**Actual API surface:** gRPC API defined in `/bench/repo/proto/api/v1/` with 9 service definitions (MemoService, UserService, AuthService, InstanceService, AttachmentService, AIService, ShortcutService, IdentityProviderService). The API is exposed via three HTTP transports: (1) **gRPC-Gateway** at `/api/v1/*` (REST over HTTP/1.1), (2) **Connect Protocol** at `/memos.api.v1.*` (browser-native gRPC alternative over HTTP/1.1 or HTTP/2), and (3) **MCP Service** at `/mcp/*` (OpenAPI-driven endpoint). Service implementations are in `/bench/repo/server/router/api/v1/`, and the gateway/server setup is in `/bench/repo/server/server.go` and `/bench/repo/server/router/api/v1/v1.go`.
