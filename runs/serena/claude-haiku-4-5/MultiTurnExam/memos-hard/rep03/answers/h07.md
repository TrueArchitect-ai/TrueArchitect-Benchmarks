The browser request to `GET /file/users/:identifier/avatar` hits `serveUserAvatar()`, which calls `getUserByUsername()` to look up the user. This delegates to the store layer's `GetUser()`, which calls `ListUsers()` to retrieve user data from the database driver. The database driver's `ListUsers()` executes a SQL query that selects the `avatar_url` column (a base64 data URI). Finally, `parseDataURI()` extracts the MIME type and binary image data for the HTTP response.
