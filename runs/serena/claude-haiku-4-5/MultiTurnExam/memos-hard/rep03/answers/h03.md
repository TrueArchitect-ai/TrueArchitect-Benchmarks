**Abstraction package:** internal/idp; **Implementation package:** internal/idp/oauth2

The abstraction is defined in `internal/idp` with a minimal `IdentityProviderUserInfo` struct in `internal/idp/idp.go` that provides the common interface for extracting user information (identifier, display name, email, avatar URL). The concrete implementation shipped is OAuth2 in `internal/idp/oauth2`, which implements the `ExchangeToken()` and `UserInfo()` methods to handle authorization code exchange with PKCE support and user info retrieval.
