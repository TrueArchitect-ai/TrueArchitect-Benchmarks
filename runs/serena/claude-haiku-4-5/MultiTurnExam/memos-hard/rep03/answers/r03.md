**Premise correction:** There is no nightly database-cleanup job scheduled in a cron scheduler. The codebase includes a production-ready cron scheduler implementation at `internal/scheduler/` (scheduler.go, job.go, parser.go) with timezone-aware cron expression support, but it is not integrated into the running server—it exists only in tests and examples. The application uses only one active background runner: the S3 Presign Runner (`server/runner/s3presign/runner.go`) on a simple 12-hour `time.Ticker` interval, not a cron schedule. No database cleanup, token expiration, or other maintenance jobs are scheduled.
