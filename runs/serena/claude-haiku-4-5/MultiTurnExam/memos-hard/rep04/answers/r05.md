**Premise correction:** There is NO GraphQL schema or API in this repository. GraphQL is not used.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) in `/bench/repo/proto/api/v1/` with the following services:
- `memo_service.proto` (memo operations)
- `user_service.proto` (user operations)
- `attachment_service.proto` (attachment operations)
- `auth_service.proto` (authentication)
- `instance_service.proto` (instance configuration)
- `idp_service.proto` (identity provider management)
- `shortcut_service.proto` (shortcut management)
- `ai_service.proto` (AI integration)

These are exposed via **gRPC-Gateway** (which translates HTTP/REST to gRPC) and **Connect** (a modern gRPC alternative over HTTP/JSON), as seen in `/bench/repo/server/server.go:88` and `/bench/repo/server/router/api/v1/v1.go`.
