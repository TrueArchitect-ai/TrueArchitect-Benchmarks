**Abstraction package:** `github.com/usememos/memos/internal/idp` (defines the `IdentityProviderUserInfo` struct that represents the common user information contract)

**Implementation package:** `github.com/usememos/memos/internal/idp/oauth2` (provides the OAuth2 concrete implementation via the `IdentityProvider` type with `ExchangeToken` and `UserInfo` methods)

The abstraction is lightweight—the `idp` package defines `IdentityProviderUserInfo` as the user information schema, and the `oauth2` package provides the concrete OAuth2 protocol implementation with methods to exchange authorization codes for tokens and fetch user information.
