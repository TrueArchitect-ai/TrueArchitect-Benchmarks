Memo visibility is enforced across at least seven distinct server surfaces: (1) API endpoints via `checkMemoReadAccess()` for individual memo access and visibility filtering in `ListMemos()` (server/router/api/v1/memo_service.go); (2) RSS feeds restricting to public memos (server/router/rss/rss.go:90, 141); (3) file server attachment downloads via `checkAttachmentPermission()` (server/router/fileserver/fileserver.go:674-703); (4) XML sitemap generation limiting to public memos (server/router/frontend/frontend.go:150); (5) memo comments restricting private memos to creator (server/router/api/v1/memo_service_comments.go:41-43); (6) reactions service checks (server/router/api/v1/reaction_service.go:29-41, 82-85); (7) attachment access (server/router/api/v1/attachment_service.go:255-260).
