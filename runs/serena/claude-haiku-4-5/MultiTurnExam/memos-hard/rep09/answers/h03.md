**internal/idp** — abstraction package; **internal/idp/oauth2** — implementation package

The abstraction is defined in `internal/idp` (with core types like `IdentityProviderUserInfo` in `/bench/repo/internal/idp/idp.go`), and the concrete OAuth2 protocol implementation ships in `internal/idp/oauth2` (with implementation in `/bench/repo/internal/idp/oauth2/oauth2.go`).
