Premise correction: No GraphQL schema exists. The API uses Protocol Buffers with gRPC, not GraphQL.

Actual API surface: Protocol Buffer service definitions are located at `/bench/repo/proto/api/v1/` (memo_service.proto, user_service.proto, auth_service.proto, instance_service.proto, attachment_service.proto, ai_service.proto, shortcut_service.proto, idp_service.proto). The protobuf definitions use `google.api.http` annotations for HTTP/REST mapping. Three protocol layers expose this service: (1) gRPC-Gateway generates HTTP/REST handlers at `/api/v1/*` endpoints (server/router/api/v1/v1.go); (2) Connect protocol handlers at `/memos.api.v1.*` for browser-first gRPC (server/router/api/v1/connect_handler.go); (3) native gRPC over HTTP/2. OpenAPI spec is generated at `/bench/repo/proto/gen/openapi.yaml` from the proto definitions.
