**Premise Correction:** There is no Redis connection configured. The cache layer does not use Redis.

**Actual Mechanism:** The cache layer uses an in-memory cache implemented in Go with TTL-based expiration. User cache is configured in **store/store.go:38-61** via `cache.New(cacheConfig)`, where `cacheConfig` defines `DefaultTTL: 10 * time.Minute` (line 41). This in-memory cache is implemented in **store/cache/cache.go** as a thread-safe cache using `sync.Map` with background cleanup goroutines that remove expired entries every `CleanupInterval` (5 minutes, line 42). All cache instances (userCache, instanceSettingCache, userSettingCache) use the same configuration with a **10-minute TTL** for user entries.
