**internal/idp**; **internal/idp/oauth2**

The `internal/idp` package defines the provider abstraction through the `IdentityProviderUserInfo` struct (internal/idp/idp.go), which represents the user information returned by any identity provider. The only concrete protocol implementation that ships is OAuth2, defined in the `internal/idp/oauth2` package (internal/idp/oauth2/oauth2.go), which implements the `IdentityProvider` type with `ExchangeToken` and `UserInfo` methods for OAuth2 token exchange and user information retrieval.
