**Premise Correction:** There is no GraphQL schema for the public API. The premise of the question is incorrect.

**Actual API Surface:** The public API is defined using **Protocol Buffers (gRPC)** and **Connect**, not GraphQL. The API surface is defined in proto files located in **proto/api/v1/** directory, including:
- **memo_service.proto** — Memo operations
- **attachment_service.proto** — Attachment operations  
- **auth_service.proto** — Authentication
- **user_service.proto** — User management
- **instance_service.proto** — Instance configuration
- **idp_service.proto** — Identity provider configuration
- **ai_service.proto** — AI/LLM operations
- **shortcut_service.proto** — Shortcut management
- **common.proto** — Common types

These proto definitions are compiled to Go code and served via:
1. **gRPC** (server/router/api/v1/v1.go)
2. **gRPC-Gateway** for JSON/HTTP (server/router/api/v1/v1.go)
3. **Connect protocol** (server/router/api/v1/v1.go)
4. **MCP (Model Context Protocol)** via OpenAPI (server/router/mcp/service.go, which uses embedded OpenAPI spec from proto definitions)
