h03. internal/idp (defines the abstraction via IdentityProviderUserInfo data structure); internal/idp/oauth2 (concrete OAuth2 protocol implementation)

The `internal/idp` package defines the provider abstraction with the `IdentityProviderUserInfo` struct (internal/idp/idp.go) representing the common user information format. The `internal/idp/oauth2` package provides the concrete OAuth2 protocol implementation with its `IdentityProvider` type that implements `ExchangeToken()` and `UserInfo()` methods (internal/idp/oauth2/oauth2.go).
