r05. **Premise correction:** There is no GraphQL schema for the public API. **Actual API surface:** The public API is defined via gRPC Protocol Buffers (.proto files) located in `/bench/repo/proto/api/v1/` directory, including: memo_service.proto, user_service.proto, auth_service.proto, attachment_service.proto, instance_service.proto, shortcut_service.proto, idp_service.proto, and ai_service.proto. These gRPC services are exposed via the gRPC-Gateway for REST/JSON access and registered in `server/router/api/v1/v1.go`.
