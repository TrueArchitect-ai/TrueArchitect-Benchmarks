**Premise correction:** There is no GraphQL schema for the public API. The premise is incorrect.

**Actual API surface:** The public API is defined using **Protocol Buffers (gRPC + gRPC-Gateway)**, not GraphQL.

**Schema definitions:** Proto files in /bench/repo/proto/api/v1/:
- memo_service.proto — Memo CRUD operations
- user_service.proto — User management
- attachment_service.proto — File attachments
- auth_service.proto — Authentication
- instance_service.proto — Instance configuration
- idp_service.proto — Identity providers
- ai_service.proto — AI features
- shortcut_service.proto — Shortcuts
- common.proto — Common types

The API is served via two mechanisms (both generated from the same proto files):
1. **gRPC-Gateway** — HTTP/JSON REST API at /api/v1/*
2. **Connect RPC** — Alternative gRPC transport over HTTP/2

The generated OpenAPI/Swagger spec is at proto/gen/openapi.yaml (referenced in server/router/mcp/service.go:78).

There is no GraphQL layer; the API is purely gRPC + REST via proto-defined services.
