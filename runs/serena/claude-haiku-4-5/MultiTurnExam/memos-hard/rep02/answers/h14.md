**Extracted properties:** The ExtractedData structure contains:
- **Tags** — all #hashtags found in the content (array of strings)
- **Mentions** — all @mentions found in the content (array of strings)  
- **Property** (MemoPayload_Property) — computed boolean properties and metadata:
  - `has_link` — whether content contains links
  - `has_code` — whether content contains code blocks or code spans
  - `has_task_list` — whether content contains task list checkboxes
  - `has_incomplete_tasks` — whether content contains unchecked task items
  - `title` — the text of the first H1 heading if present

These derived properties are used for list views, previews, and searching without re-parsing the content on every read.
