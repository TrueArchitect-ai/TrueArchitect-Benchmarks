**Premise correction**: There is no GraphQL schema. The public API is not built on GraphQL.

**Actual API surface**: The public API is defined using **Protocol Buffers (protobuf) and gRPC**, not GraphQL. The API specification is spread across multiple `.proto` files located in `/bench/repo/proto/api/v1/`:

- `/bench/repo/proto/api/v1/memo_service.proto` — memo CRUD operations
- `/bench/repo/proto/api/v1/user_service.proto` — user management
- `/bench/repo/proto/api/v1/auth_service.proto` — authentication
- `/bench/repo/proto/api/v1/attachment_service.proto` — attachments
- `/bench/repo/proto/api/v1/instance_service.proto` — instance configuration
- `/bench/repo/proto/api/v1/idp_service.proto` — identity provider management
- `/bench/repo/proto/api/v1/ai_service.proto` — AI features
- `/bench/repo/proto/api/v1/shortcut_service.proto` — shortcuts
- `/bench/repo/proto/api/v1/common.proto` — shared types

The `.proto` files define RPC services and are compiled to both gRPC services and HTTP endpoints via the `google.api.http` annotations. The generated code is available in `/bench/repo/proto/gen/api/v1/`.
