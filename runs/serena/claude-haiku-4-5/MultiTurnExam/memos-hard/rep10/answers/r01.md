**Premise correction**: There is no Redis connection for the cache layer in this repository.

**Actual mechanism**: The cache is an in-memory implementation using Go's `sync.Map` in `/bench/repo/store/cache/cache.go`. User entries (and all cached entries) are configured in `/bench/repo/store/store.go:40-45` with a **DefaultTTL of 10 minutes** (10 * time.Minute). This configuration is applied to all three caches: `instanceSettingCache`, `userCache`, and `userSettingCache`, which are initialized at `/bench/repo/store/store.go:51-53` using `cache.New(cacheConfig)`.
