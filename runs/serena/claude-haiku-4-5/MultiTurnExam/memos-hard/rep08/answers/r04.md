**Premise correction:** The repository does not use NATS or RabbitMQ for webhook delivery workers.

**Actual mechanism:** Webhook delivery uses an in-memory Go channel-based queue with background goroutines. The implementation is in `/bench/repo/internal/webhook/webhook.go`:

- **Queue declaration:** `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` at line 39 — a buffered Go channel with capacity of 128 messages
- **Workers:** 4 background goroutines spawned in `init()` at lines 43-54 that consume from the queue and call `Post()` to deliver webhooks
- **Enqueue mechanism:** `PostAsync()` function at line 184 sends payloads to the channel
- **No external broker:** There are no imports of NATS, RabbitMQ, or any message broker libraries — only standard library imports (`net`, `context`, `log/slog`, etc.)

This is a simple, in-process asynchronous dispatch mechanism without external message broker dependencies.
