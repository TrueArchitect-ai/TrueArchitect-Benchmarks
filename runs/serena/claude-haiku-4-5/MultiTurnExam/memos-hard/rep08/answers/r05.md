**Premise correction:** There is no GraphQL schema for the public API. The repository does not use GraphQL.

**Actual API surface:** The public API is defined using **gRPC protocol buffers** (.proto files), located in `/bench/repo/proto/api/v1/`:

- **Service definitions:** Multiple gRPC services defined in proto files:
  - `memo_service.proto` — Memo operations (create, list, get, update, delete)
  - `user_service.proto` — User management operations
  - `attachment_service.proto` — Attachment handling
  - `auth_service.proto` — Authentication operations
  - `instance_service.proto` — Instance configuration
  - `ai_service.proto` — AI integration
  - `idp_service.proto` — Identity provider management
  - `shortcut_service.proto` — Shortcut management
  - `common.proto` — Shared types

- **HTTP binding:** The proto files use `google.api.http` annotations to expose gRPC services as HTTP/REST endpoints via gRPC-Gateway (e.g., `POST /api/v1/memos` for CreateMemo)

- **Transport:** Served as HTTP/REST via gRPC-Gateway at `/bench/repo/server/router/api/v1/v1.go:96` with Connect protocol support
