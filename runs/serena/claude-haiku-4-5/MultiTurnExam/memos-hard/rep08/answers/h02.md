**Delivery function:** `Post()` — `/bench/repo/internal/webhook/webhook.go:120`

**Protection mechanism:** `safeDialContext()` function combined with `isReservedIP()` check — `/bench/repo/internal/webhook/webhook.go:59` (safeDialContext) and `/bench/repo/internal/webhook/validate.go:44` (isReservedIP)

The `Post()` function executes outbound webhook delivery. It uses a shared `safeClient` HTTP client whose Transport is configured with a custom `safeDialContext` that:
1. Resolves the target hostname to IP addresses
2. Blocks connections to reserved/private IP ranges (loopback 127.0.0.0/8, RFC-1918 private ranges, link-local 169.254.0.0/16, and IPv6 equivalents)
3. This defeats both direct IP targeting and DNS rebinding attacks

The same IP validation logic is also performed at webhook creation/update time via `ValidateURL()` in `/bench/repo/internal/webhook/validate.go:62`, providing defense-in-depth against SSRF.
