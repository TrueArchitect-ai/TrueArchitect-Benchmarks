**Abstraction package:** `idp` — `internal/idp/` (`internal/idp/idp.go`), which defines the shared provider contract via the common `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) returned by each provider's `UserInfo`.

**Implementation package:** `oauth2` — `internal/idp/oauth2/` (`internal/idp/oauth2/oauth2.go`), providing `NewIdentityProvider(*storepb.OAuth2Config)` with `ExchangeToken` / `UserInfo`. It's the only concrete protocol that ships — the store enum (`proto/gen/store/idp.pb.go`) defines only `TYPE_UNSPECIFIED` and `OAUTH2`, and SSO dispatch in `server/router/api/v1/auth_service_sso.go` handles only the OAuth2 case. No OIDC or SAML implementation exists.
