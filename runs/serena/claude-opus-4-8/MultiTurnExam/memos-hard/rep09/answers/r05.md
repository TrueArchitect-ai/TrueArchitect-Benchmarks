**Premise correction:** There is no GraphQL API. A repo-wide search finds no GraphQL usage whatsoever — no `graphql`/`gqlgen` imports, no `.graphql` schema files, no resolvers. So there is no GraphQL schema to locate.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **gRPC / Connect** with a **gRPC-Gateway** REST/JSON layer:
- The schema (service + message definitions) lives in `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. (Store-side messages are under `proto/store/`.)
- Generated Go code is in `proto/gen/api/v1/` (including the `*.pb.gw.go` gRPC-Gateway stubs).
- These services are wired up and served in `server/router/api/v1/v1.go` — the Connect handlers are registered with interceptors (`v1.go:133-141`) and the gRPC-Gateway mux provides the REST mapping (`v1.go:95-97`). Handlers implement the RPC methods in `server/router/api/v1/*_service.go`.

So the API is proto-defined gRPC/Connect + REST-via-gateway, not GraphQL.
