**1st: `store.User` (~7 external packages); 2nd: `store.Memo` (~6 external packages)**

Among the persistent entity types defined in the data layer (`store/`) — `User`, `Memo`, `Attachment`, `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `UserIdentity`, `UserSetting`, `InstanceSetting`, `IdentityProvider` — I counted the distinct packages **outside the `store/` tree** that reference each type (excluding the drivers under `store/db/*` and `store/test`, which are part of the data layer itself).

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.
- Next: `store.Attachment` (~4), then `MemoShare`/`MemoRelation`/`Inbox` (~3).

(Counts are grep-based and approximate; if test packages are excluded the figures drop to ~6 for User and ~5 for Memo, but the ranking is unchanged — `User` is referenced from the most external packages, `Memo` second. Types defined in `store/*.go`, e.g. `store/user.go`, `store/memo.go`.)
