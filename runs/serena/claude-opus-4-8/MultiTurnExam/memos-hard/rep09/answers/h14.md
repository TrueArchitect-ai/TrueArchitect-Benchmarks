h14.

**Computation site:** the memo `Payload` (its `Tags` + `Property`) is the derived metadata. It's computed by `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which calls the markdown service's `ExtractAll` — `internal/markdown/markdown.go:356`. `RebuildMemoPayload` copies `data.Tags` and `data.Property` onto `memo.Payload` (runner.go:85-86).

**Triggers (recomputation):**
- **Memo creation** — `CreateMemo` at `server/router/api/v1/memo_service.go:108`.
- **Memo content update** — `UpdateMemo`, only when the `content` field is being changed, at `server/router/api/v1/memo_service.go:447` (guarded by the `memo.Content = request.Memo.Content` branch at :446).
- (Bulk backfill of all memos exists via `memopayload.Runner.RunOnce` → `RebuildMemoPayload` at runner.go:52, but that `Runner` is never constructed in production — see h08; the live triggers are Create/Update.)

**Extracted properties** (from `ExtractAll`, single AST walk over the content):
- `Tags` — all `#tags`, deduplicated preserving case (`markdown.go:377`, `:418`).
- `Property.Title` — text of the first block if it's an H1 heading (`markdown.go:386-387`).
- `Property.HasLink` — content contains a link (`markdown.go:394`).
- `Property.HasCode` — content contains a code block/fenced block/inline code span (`markdown.go:397`).
- `Property.HasTaskList` — content contains a task checkbox (`markdown.go:400`).
- `Property.HasIncompleteTasks` — at least one task checkbox is unchecked (`markdown.go:403`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload used for lists/previews.)
