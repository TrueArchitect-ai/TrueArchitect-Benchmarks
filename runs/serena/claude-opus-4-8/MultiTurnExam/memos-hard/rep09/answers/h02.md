**Protection mechanism:** SSRF is blocked at dial time by the `safeClient`'s custom transport dialer, `safeDialContext` — `internal/webhook/webhook.go:59`. It resolves the target host (`net.DefaultResolver.LookupHost`, `webhook.go:65`) and refuses the connection if any resolved IP is in a reserved/private range via `isReservedIP` (`webhook.go:70-73`). Because this check runs on every dial (not just at config time), it also defeats DNS-rebinding.

- Escape hatch `AllowPrivateIPs` (`validate.go:41`) short-circuits `isReservedIP`, disabling the guard for intentional local-network targets.
