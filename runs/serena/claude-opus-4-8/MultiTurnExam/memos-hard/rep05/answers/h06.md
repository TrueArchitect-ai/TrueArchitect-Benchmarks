**Convergence function before delivery: `webhook.PostAsync` — `internal/webhook/webhook.go:176`.**

All the per-activity dispatch helpers (`dispatchMemoRelatedWebhook` at `memo_service_webhooks.go:48` for created/updated/deleted, and `DispatchMemoCommentCreatedWebhook` at `memo_service_webhooks.go:30`) build the payload with `hook.Url`/`hook.SigningSecret` and funnel into the single call `webhook.PostAsync(payload)` (`memo_service_webhooks.go:43` and `:71`). `PostAsync` enqueues onto the async queue, whose worker goroutines perform the actual outbound HTTP delivery in `webhook.Post` (`internal/webhook/webhook.go:119`, via `safeClient.Do`). So `PostAsync` is the single point where all handler paths converge just before delivery; `Post` is where the request physically leaves.
