**Premise correction:** There is no GraphQL schema anywhere in this repository. A search for `graphql`/`gqlgen`/`.graphql`/`schema.graphql` in the source returns nothing — the public API is not GraphQL.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **Connect / gRPC** with a REST/HTTP (grpc-gateway) mapping. The schema lives in the `.proto` files under `proto/api/v1/`:
- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`.

These generate Go code under `proto/gen/api/v1/` (including `*.pb.go`, Connect handlers, and `*.pb.gw.go` REST gateways). The services are registered/served in `server/router/api/v1/` — e.g. Connect handlers wired with interceptors at `server/router/api/v1/v1.go:133–141`, and the concrete RPC handlers implemented across `server/router/api/v1/*_service.go`. HTTP/REST paths come from `google.api.http` annotations in the `.proto` files, exposed via the generated gateway.
