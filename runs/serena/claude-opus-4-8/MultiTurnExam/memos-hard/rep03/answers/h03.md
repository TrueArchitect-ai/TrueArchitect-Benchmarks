**Abstraction package** — `internal/idp` (`internal/idp/idp.go`). It defines the provider-agnostic abstraction, e.g. the `IdentityProviderUserInfo` struct that concrete providers return.

**Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`). Its package doc reads "Package oauth2 implements the OAuth2 identity provider integration," and it provides the concrete `IdentityProvider` type backed by `storepb.OAuth2Config`. OAuth2 is the only concrete protocol implementation that ships under `internal/idp/`.
