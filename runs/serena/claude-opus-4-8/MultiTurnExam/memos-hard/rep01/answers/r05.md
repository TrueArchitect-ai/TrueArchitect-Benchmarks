**Premise correction: there is no GraphQL schema or GraphQL API in this project.** A repo-wide search for `graphql`, `gqlgen`, `graph-gophers`, or any `.graphql`/`.gql` schema file returns nothing, and `go.mod` declares no GraphQL dependency.

**Actual API surface:** The public API is defined with **Protocol Buffers (gRPC)**, served over both Connect and a REST/JSON gRPC-Gateway. The schema is the set of `.proto` service definitions under `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto` (`proto/api/v1/`).

These are compiled via `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`) into Go code under `proto/gen/` (including gRPC stubs, gRPC-Gateway REST handlers `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`), with an OpenAPI embed at `proto/openapi_embed.go`. At runtime these services are registered as Connect interceptored handlers and a gRPC-Gateway mux in `server/router/api/v1/v1.go`. So the API contract is proto/gRPC + generated REST, not GraphQL.
