**Computation site** — `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates the actual content analysis to the goldmark-backed `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`). The result is written into the memo's `Payload` (a `storepb.MemoPayload`): `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). This payload is stored as JSON on the memo row, separate from user-set fields.

**Triggers (recomputation):**
- **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Memo content update** — `UpdateMemo`, when the `content` field is being changed, calls it at `server/router/api/v1/memo_service.go:447` (right after setting `memo.Content = request.Memo.Content`).
- **Bulk rebuild** — `memopayload.Runner.RunOnce` re-derives the payload for every memo in batches (`server/runner/memopayload/runner.go:52`), followed by an `UpdateMemo`. (Note: this bulk runner is defined but not wired into production startup — see the codebase's runner registration — so at runtime the live triggers are memo create and content-update.)

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356-421`), stored into the payload:
- **Tags** — all `#tag` nodes, deduplicated with case preserved (`markdown.go:377,418`).
- **Property.Title** — text of a leading H1 heading, if the document's first block is one (`markdown.go:384-388`).
- **Property.HasLink** — true if any link node is present (`markdown.go:393-394`).
- **Property.HasCode** — true for any code block / fenced code / inline code span (`markdown.go:396-397`).
- **Property.HasTaskList** — true if any task-list checkbox exists; and **Property.HasIncompleteTasks** — true if any checkbox is unchecked (`markdown.go:399-405`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload.)
