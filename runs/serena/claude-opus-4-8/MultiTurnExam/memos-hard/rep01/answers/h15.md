Distinct memo-visibility (view/read) enforcement sites:

- `APIV1Service.checkMemoReadAccess` (gRPC MemoService — single-memo read, e.g. GetMemo): denies non-public memos to anonymous/non-owner viewers — `server/router/api/v1/memo_service.go:55-66`
- `APIV1Service.ListMemos` visibility filtering (gRPC memo listing): constrains `VisibilityList`/adds a `creator_id … || visibility in [...]` filter based on the caller — `server/router/api/v1/memo_service.go:219,225`
- `SSEClient.canReceive` (server-sent-events live delivery): filters which memo-change events a connected client may receive by visibility — `server/router/api/v1/sse_hub.go:135-143`
- `FileServerService.checkAttachmentPermission` (HTTP file server serving attachment bytes): gates attachment access on the owning memo's visibility (with share-token fallback) — `server/router/fileserver/fileserver.go:677,699`
- `APIV1Service.checkAttachmentAccess` (gRPC AttachmentService, e.g. GetAttachment): gates attachment access on the owning memo's visibility — `server/router/api/v1/attachment_service.go:445,451`
- `APIV1Service.ListMemoReactions` / reaction access (gRPC ReactionService): non-public memos require an authenticated, permitted viewer before reactions are exposed/allowed — `server/router/api/v1/reaction_service.go:30,38,83`
- `APIV1Service.SetMemoAttachments` / memo-attachment access (gRPC): visibility check before exposing/altering a memo's attachments — `server/router/api/v1/memo_attachment_service.go:214,222`
- `APIV1Service.CreateMemoComment`/comment listing (gRPC): private related-memo restricted to owner/superuser — `server/router/api/v1/memo_service_comments.go:41`
- RSS feed generation (public HTTP feed): restricts feed to `store.Public` memos only — `server/router/rss/rss.go:90,141`
- Frontend sitemap generation (`FrontendService.getSitemapXML`): lists only `store.Public` memos — `server/router/frontend/frontend.go:150`

The first five (single-memo read check, list filtering, SSE delivery, and the two attachment-permission checks) are the core independent view-enforcement surfaces; the remainder apply the same visibility rules on adjacent read surfaces (reactions, comments, attachment sets, RSS, sitemap).
