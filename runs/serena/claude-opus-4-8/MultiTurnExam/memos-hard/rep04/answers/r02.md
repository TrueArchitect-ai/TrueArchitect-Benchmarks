**Premise correction:** This repository has no per-user API rate-limiting middleware — so there is nowhere it is "registered," and there are no request limits to report.

Evidence:
- A repo-wide search for rate-limiting terms (`rate limit`, `ratelimit`, `throttle`, `golang.org/x/time/rate`, `StatusTooManyRequests`/`429`) in Go source finds only a single, unrelated doc comment: an aspirational security bullet "Rate limit email sending to prevent abuse" in `internal/email/doc.go:86`. None of these performs rate limiting, and there is no `golang.org/x/time/rate` (or equivalent) dependency in use.

Conclusion: no per-user (or global) API rate limiter exists in the codebase; the question's premise does not hold.
