h03.

The provider abstraction is defined in the `idp` package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` type used by all providers. The one concrete protocol implementation that ships is the OAuth2 provider in the `oauth2` package (`internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type implements OAuth2-based authentication.

abstraction package: `internal/idp` (internal/idp/idp.go); implementation package: `internal/idp/oauth2` (internal/idp/oauth2/oauth2.go)
