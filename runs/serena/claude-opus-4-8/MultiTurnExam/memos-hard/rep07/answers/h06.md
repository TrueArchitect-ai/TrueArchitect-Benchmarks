Note: the comment path (`CreateMemoComment` → `DispatchMemoCommentCreatedWebhook`, `memo_service_webhooks.go:30`) is a sibling that calls `webhook.PostAsync` directly rather than routing through `dispatchMemoRelatedWebhook`. If "single function where paths converge before delivery" must include the comment path too, then the true common convergence point is the transport-layer sender itself: `Post` in `internal/webhook/webhook.go:120` (invoked via `PostAsync`/its queue workers), where the actual HTTP request executes. But among the memo create/update/delete handlers, the convergence function is `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`).
