**1st: `store.User` (~5 external packages); 2nd: `store.Memo` (~4 external packages).**

Method: I enumerated the persistent entity types in the data layer (`store/*.go` — `User`, `Memo`, `Attachment`, `Reaction`, `Inbox`, `IdentityProvider`, `MemoRelation`, `UserSetting`, `MemoShare`, etc.) and counted the distinct non-test packages *outside the data layer* (excluding `store/` and its DB drivers `store/db/{sqlite,postgres,mysql}`) that reference each via `store.<Type>`.

- **`store.User`** — referenced from **5** outside-the-data-layer packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` (files at e.g. `server/auth/token.go`, `server/router/fileserver/fileserver.go:716`, `server/router/rss/rss.go`, `server/notification/*.go`).
- **`store.Memo`** — referenced from **4**: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

Every other entity type trails these (`Attachment` next at ~3 external packages: `server/router/api/v1`, `server/router/fileserver`, `server/runner/s3presign`). Note: if you additionally count the three `store/db/*` driver packages as "outside the `store` package" (they still belong to the data layer conceptually), the raw totals rise to `User` ≈ 8 and `Memo` ≈ 7, but the top-two ranking — User then Memo — is unchanged either way.
