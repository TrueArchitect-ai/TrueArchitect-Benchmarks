**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll(memo.Content)` and writes the results into the memo's stored payload: `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:80-86`). The actual extraction logic lives in the markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`).

**Triggers (operations that cause recomputation):**
- **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Memo content update** — `UpdateMemo` recomputes only when the `content` field is in the update mask, at `server/router/api/v1/memo_service.go:447` (guarded by the `path == "content"` check).
- **Bulk backfill / migration** — `memopayload.Runner.RunOnce` rebuilds the payload for every memo in batches (`server/runner/memopayload/runner.go:27-72`). (Note: `RunOnce` itself is not wired into startup — see h08 — so in practice the live triggers are create and content-update.)

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go:356-422`), a single goldmark AST pass produces:
- **Tags** — the set of `#tags` in the content (deduplicated, case preserved) → `Payload.Tags`.
- **Property** (`storepb.MemoPayload_Property`) → `Payload.Property`:
  - `Title` — text of the first block if it's an H1 heading.
  - `HasLink` — content contains a link.
  - `HasCode` — content contains a code block/fenced code/code span.
  - `HasTaskList` — content contains a task checkbox.
  - `HasIncompleteTasks` — at least one task checkbox is unchecked.

(Mentions are also extracted by `ExtractAll` into `ExtractedData.Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload.)
