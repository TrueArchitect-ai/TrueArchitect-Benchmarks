**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual `resp, err := safeClient.Do(req)` outbound call is at `webhook.go:152`). Webhooks are usually dispatched via `PostAsync` (`webhook.go:184`), whose background workers ultimately call `Post`.

**Protection mechanism:** SSRF guarding at dial time via the shared `safeClient` whose `Transport.DialContext` is `safeDialContext` — `internal/webhook/webhook.go:32` (client) / `webhook.go:59` (dialer). `safeDialContext` resolves the target hostname and rejects any address in a reserved/private range using `isReservedIP` — `internal/webhook/validate.go:44`. Because the check happens at connection dial time (after DNS resolution), it also defeats DNS-rebinding attacks.
