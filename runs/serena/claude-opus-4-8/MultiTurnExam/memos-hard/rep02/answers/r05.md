**Premise correction:** There is no GraphQL schema anywhere in this repository. The Go source has no GraphQL/gqlgen/graph-gophers references and `go.mod` pulls in no GraphQL library, so there is no schema to point to.

**Actual API surface:** The public API is defined with **Protocol Buffers (gRPC)** and served over Connect RPC plus a grpc-gateway REST/HTTP mapping — not GraphQL.

- Schema/IDL: `.proto` service definitions under `proto/api/v1/` — e.g. `MemoService` (`proto/api/v1/memo_service.proto:17`), `UserService` (`user_service.proto:17`), `AuthService` (`auth_service.proto:13`), `AttachmentService`, `IdentityProviderService`, `InstanceService`, `ShortcutService`, `AIService`. Generated Go code lives in `proto/gen/api/v1/` (including Connect stubs in `proto/gen/api/v1/apiv1connect/`).
- Transport wiring in `server/router/api/v1/v1.go`: Connect handlers via `connectrpc.com/connect` (`v1.go:7`, registered at `RegisterConnectHandlers`, `v1.go:141`) and a REST gateway via `grpc-gateway` `runtime.NewServeMux` (`v1.go:96`) with `Register…ServiceHandlerServer` calls (`v1.go:99` onward).
- Additional surfaces: an RSS feed (`server/router/rss/`) and an MCP endpoint that re-exposes a curated subset of these same operations (`server/router/mcp/`). None of these is GraphQL.
