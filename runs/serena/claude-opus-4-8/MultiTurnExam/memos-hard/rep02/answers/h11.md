h11.

**1st: `store.User`; 2nd: `store.Memo`**

Counting distinct packages *outside* the data layer (excluding `store/`, the `store/db/*` driver implementations, and test packages) that reference each persistent entity type via `store.<Type>`:

- **`User` — 5 external packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss`.
- **`Memo` — 4 external packages:** `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

`Attachment` is next with 3 external packages (`server/router/api/v1`, `server/router/fileserver`, `server/router/rss`). The ranking holds the same way even if you count the `store/db/*` driver packages: `User` (8 total dirs) > `Memo` (7) > `Attachment` (6).
