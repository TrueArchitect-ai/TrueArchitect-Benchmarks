**Premise correction: there is no nightly database-cleanup job scheduled in this codebase, so there is no run time to report.**

Details of what actually exists:
- A cron scheduler package does exist — `internal/scheduler` (a "GitHub Actions-inspired cron job scheduler", `internal/scheduler/doc.go`, with `New`/`Register`/`Start` in `internal/scheduler/scheduler.go`). But it is **never used**: no file outside the `internal/scheduler/` package itself imports it (a search for `internal/scheduler` imports returns nothing). No jobs are registered with it, and it is not started anywhere in server startup.
- The `"0 2 * * *" // 2 AM daily "daily-cleanup"` you may be thinking of appears only as an **illustrative example in the package doc comment** (`internal/scheduler/doc.go`), not as a real registered job.
- The server's only actual background work is started in `startBackgroundRunners` (`server/server.go:153-174`), and it consists of a single runner: the **S3 presign runner**, which runs on a 12-hour `time.Ticker` (not cron, not nightly) — `server/runner/s3presign/runner.go:27`. The only other runner package, `server/runner/memopayload`, is not wired into startup at all.

So no cron-scheduled nightly database cleanup runs; there is no such job to have a scheduled time.
