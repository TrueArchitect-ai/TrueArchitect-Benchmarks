**Premise correction: there is no GraphQL API in this project — no GraphQL schema exists.** A repo-wide search of the Go sources for `graphql`/`gqlgen`/`.graphql`/`schema.graphql` returns nothing; there is no GraphQL server, resolver, or schema file.

**Actual API surface — Protocol Buffers + Connect/gRPC, with a REST (gRPC-Gateway) façade:**
- The API is defined as **Protobuf service definitions** under `proto/api/v1/*.proto` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`. This is the source of truth for the public API surface.
- Generated Go code lives under `proto/gen/api/v1/` (message/service stubs and the gRPC-Gateway `*.pb.gw.go` files).
- At runtime the server exposes these via **Connect/gRPC handlers plus a gRPC-Gateway REST mux**, wired in `server/router/api/v1/v1.go` (Connect handlers registered at `v1.go:133-141`; gRPC-Gateway registration via `RegisterGateway`, invoked from `server/server.go:88`). An SSE endpoint and an MCP endpoint are also mounted (`server/server.go:96`), but there is no GraphQL endpoint.

So the "public API" is the Protobuf-defined Connect/gRPC + REST-gateway surface (`proto/api/v1/*.proto`), not GraphQL.
