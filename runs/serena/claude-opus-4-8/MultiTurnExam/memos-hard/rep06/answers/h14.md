**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass extractor `(*service).ExtractAll` (`internal/markdown/markdown.go`), then writes the results onto the memo's stored `Payload`: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`server/runner/memopayload/runner.go:85-86`). (The heavy lifting — walking the goldmark AST — happens in `ExtractAll`.)

**Triggers (operations that recompute it):**
- **Create memo** — `CreateMemo` calls `RebuildMemoPayload(ctx, create, ...)` before insert (`server/router/api/v1/memo_service.go:108`).
- **Update memo (content change)** — `UpdateMemo`'s content-update branch calls `RebuildMemoPayload(ctx, memo, ...)` when `request.Memo.Content` is set (`server/router/api/v1/memo_service.go:447`).
- **Bulk rebuild** — `memopayload.Runner.RunOnce` re-derives the payload for every memo in batches (`server/runner/memopayload/runner.go:52`); this is a maintenance/backfill path (the `Runner` type is not wired into production startup, per the codebase, but the same function is the recompute primitive).

**Extracted properties (what the derived payload holds):** from `ExtractAll` (`internal/markdown/markdown.go`):
- **`Tags`** — the set of `#tags` in the content, deduplicated with original case preserved.
- **`Property.Title`** — text of a leading level-1 (`# `) heading, if the document's first block is an H1.
- **`Property.HasLink`** — content contains a link.
- **`Property.HasCode`** — content contains a code block, fenced code block, or inline code span.
- **`Property.HasTaskList`** — content contains a task-list checkbox.
- **`Property.HasIncompleteTasks`** — at least one task checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` does not store those in the payload — mentions are used for notifications elsewhere; the persisted derived metadata used for lists/previews is `Tags` + `Property`.)
