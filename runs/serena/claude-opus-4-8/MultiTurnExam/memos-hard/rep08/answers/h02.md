**Delivery function:** `Post` in `internal/webhook/webhook.go` — this is where the outbound HTTP POST actually executes (`resp, err := safeClient.Do(req)`). It's driven by `PostAsync`, which enqueues onto a bounded channel drained by four worker goroutines that each call `Post` (see the `init()` workers in the same file).

**Protection mechanism:** `safeDialContext` in `internal/webhook/webhook.go`, installed as the `DialContext` of the shared `safeClient`'s `http.Transport`. At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go`), which checks the parsed `reservedNetworks` CIDR list (loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents). Because the check happens on the actual resolved IP at connection time, it also defeats DNS-rebinding attacks that would slip past the earlier best-effort `ValidateURL` check (`internal/webhook/validate.go`) performed when the webhook is configured. The guard can be disabled via the `AllowPrivateIPs` flag for self-hosted deployments.
