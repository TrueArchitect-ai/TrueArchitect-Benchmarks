**Premise correction: there is no GraphQL schema in this repository. The public API is not GraphQL.** A search for `graphql`, `gqlgen`, `graph-gophers`, and any `*.graphql` files across the Go code and `go.mod` returns nothing.

**Actual API surface:** The public API is defined as **Protobuf/gRPC services**, exposed over **Connect + gRPC-gateway (REST/JSON)**. The schema of record is the set of `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`.

These are compiled via Buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into Go stubs under `proto/gen/api/v1/` — including gRPC (`*_grpc.pb.go`), Connect (`apiv1connect/*.connect.go`), and grpc-gateway REST handlers (`*.pb.gw.go`) — and an OpenAPI document (via the gnostic-openapi plugin). TypeScript clients are generated for the web frontend (`web/src/types/proto`).

At runtime the services are served as Connect/gRPC handlers, registered in `server/router/api/v1/v1.go:139-144` (`connectHandler.RegisterConnectHandlers(...)`, mounted at the `/memos.api.v1.*` route). So the "public API schema" lives in the `proto/api/v1/*.proto` definitions, not a GraphQL schema.
