**Convergence function before delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go`. Every one of the dispatch paths above (the `dispatchMemoRelatedWebhook` loop and the `DispatchMemoCommentCreatedWebhook` loop, both in `server/router/api/v1/memo_service_webhooks.go:43,71`) ends by calling `webhook.PostAsync(payload)`. `PostAsync` enqueues onto the shared async queue whose worker goroutines invoke `Post` (`internal/webhook/webhook.go`), which performs the actual `safeClient.Do(req)` outbound request.
