The provider abstraction lives in the **`internal/idp`** package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type used across providers. The one concrete protocol implementation that ships is **`internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`), an OAuth2 `IdentityProvider` that exchanges the auth code and fetches user info.

- abstraction package — `internal/idp` (`internal/idp/idp.go`)
- implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)
