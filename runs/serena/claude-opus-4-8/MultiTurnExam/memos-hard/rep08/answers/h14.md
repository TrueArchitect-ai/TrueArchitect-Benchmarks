**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go` — it calls `markdownService.ExtractAll([]byte(memo.Content))` and writes the result into `memo.Payload.Tags` and `memo.Payload.Property`. The actual extraction logic lives in `(*service).ExtractAll` in `internal/markdown/markdown.go`, which walks the goldmark AST of the content. This is derived metadata (`storepb.MemoPayload`), computed from content, not user-set.

**Triggers (recomputation):**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108`
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:447`
- The batch backfill `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:52` (rebuilds payload for all memos; not wired into production startup, per earlier finding).

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go`):
- `Tags` — all `#tags` found in the content, deduplicated while preserving case (`memo.Payload.Tags`).
- `Property.Title` — text of the document's first block if it is an H1 heading.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block/fenced code/code span is present.
- `Property.HasTaskList` — true if any task checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` onto the memo payload.)
