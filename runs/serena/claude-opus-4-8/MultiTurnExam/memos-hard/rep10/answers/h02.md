h02.

**Delivery function** — `Post` in `internal/webhook/webhook.go:120` executes the outbound HTTP POST via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. (Deliveries are typically enqueued through `PostAsync` at line 184, whose worker goroutines call `Post` at line 46.)

**Protection mechanism** — SSRF guard at dial time. The shared `safeClient` uses a custom `Transport` with `safeDialContext` (`internal/webhook/webhook.go:59`), which resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/webhook.go:70-74`). Because the check happens on the resolved IP at connection time, it also defeats DNS-rebinding. The `isReservedIP` helper lives in `internal/webhook/validate.go`.
