**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (defined at line 156, attached to the main transport at line 188). Supporting token state lives in `web/src/auth-state.ts`.

**Token kinds it manages:**
- **Access token** — short-lived JWT sent in the `Authorization: Bearer <token>` header (managed in-memory via `getAccessToken`/`setAccessToken`).
- **Refresh token** — carried in an HTTP-only cookie (`credentials: "include"`); the interceptor uses the `AuthService.RefreshToken` RPC to mint a new access token (reactively on 401 and proactively before expiry). PATs (personal access tokens) are also accepted by the backend.

**Backend validation package:** `server/auth/` (`Authenticator` in `server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`; token parsing in `server/auth/token.go`).
