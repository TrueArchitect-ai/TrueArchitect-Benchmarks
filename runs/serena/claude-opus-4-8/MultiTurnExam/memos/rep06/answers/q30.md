Memo lifecycle events that dispatch webhooks (all in `server/router/api/v1/memo_service_webhooks.go`):

- memo created (`memos.memo.created`): `DispatchMemoCreatedWebhook`
- memo updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook`
- memo deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook`
- memo comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook`

**Convergence for delivery:** The first three funnel through the private helper `dispatchMemoRelatedWebhook` (same file); it and `DispatchMemoCommentCreatedWebhook` both end at **`webhook.PostAsync(payload)`** in the `internal/webhook` package (`internal/webhook/webhook.go`, which wraps `webhook.Post`).
