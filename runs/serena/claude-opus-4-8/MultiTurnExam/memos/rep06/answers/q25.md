**Engine:** Google CEL (`google/cel-go`), wrapped by the project's own filter engine in **`internal/filter/`** (CEL env in `internal/filter/schema.go`, parsing in `parser.go`, an intermediate representation in `ir.go`, and dialect-aware SQL rendering in `render.go`).

**Mechanism:** The filter string is a CEL expression that the filter engine parses into a dialect-agnostic condition IR, then each dialect driver (`store/db/{sqlite,postgres,mysql}/memo.go`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect{SQLite|Postgres|MySQL}, &where, &args)`, whose renderer emits the correct WHERE-clause SQL and bound args for that dialect (`internal/filter/render.go`, e.g. lines 231–237, 365–402).
