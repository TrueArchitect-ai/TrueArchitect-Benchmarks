**memo, memo_relation, attachment**

When `DeleteMemo` runs, the explicit cascade code (`Store.DeleteMemo`, store/memo.go:140-159, plus the handler in server/router/api/v1/memo_service.go:567-580) affects:

- **memo** — the memo row itself, plus any comment memos (the handler recursively deletes comment memos found via `memo_relation` of type comment)
- **memo_relation** — rows where the memo is the source (`memo_id`) or target (`related_memo_id`)
- **attachment** — attachments linked to the memo (removed via `DeleteAttachment`)

(Reactions are read for the webhook payload but are not deleted by explicit code in this path.)
