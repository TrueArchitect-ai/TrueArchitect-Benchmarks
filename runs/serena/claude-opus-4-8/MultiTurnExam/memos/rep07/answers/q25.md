- **Engine:** Google CEL (`github.com/google/cel-go`) wrapped by the project's `internal/filter` package — the engine is in `internal/filter/engine.go` (`Engine`/`NewEngine` builds a `cel.Env`; `Compile`/`CompileToStatement` parse the filter). The store-facing wiring lives in `server/router/api/v1/memo_service.go` (which sets `memoFind.Filters`).
- **Mechanism:** The CEL filter string is parsed/compiled into an intermediate condition tree (`internal/filter/ir.go`, `parser.go`), then `internal/filter/render.go` renders it into a dialect-specific SQL `WHERE` clause with parameter placeholders — selected via the `DialectName`/`Dialect` render option (sqlite/postgres/mysql) so each database gets the correct placeholder style and SQL.
