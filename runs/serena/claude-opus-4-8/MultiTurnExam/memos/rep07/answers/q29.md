- **Interceptor path:** `web/src/connect.ts` — `authInterceptor` (defined at line 156, registered in the transport at line 188). It attaches the access token as an `Authorization: Bearer …` header and refreshes it on expiry/401.
- **Token kinds:** a short-lived JWT **access token** (sent in the Authorization header) and a **refresh token** (stored in an HTTP cookie, used via `AuthService.refreshToken` to mint new access tokens). Access-token state is managed in `web/src/auth-state.ts`.
