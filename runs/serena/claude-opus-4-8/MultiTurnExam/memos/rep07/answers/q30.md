Memo lifecycle events that dispatch webhooks (all in `server/router/api/v1/memo_service_webhooks.go`):

- created (`memos.memo.created`): `APIV1Service.DispatchMemoCreatedWebhook`
- updated (`memos.memo.updated`): `APIV1Service.DispatchMemoUpdatedWebhook`
- deleted (`memos.memo.deleted`): `APIV1Service.DispatchMemoDeletedWebhook`
- comment created (`memos.memo.comment.created`): `APIV1Service.DispatchMemoCommentCreatedWebhook`

The first three converge in the helper `APIV1Service.dispatchMemoRelatedWebhook`; that helper and the comment dispatcher both ultimately converge on **`webhook.PostAsync`** in the **`internal/webhook`** package (`internal/webhook/webhook.go`, which calls `Post` for the actual HTTP delivery).
