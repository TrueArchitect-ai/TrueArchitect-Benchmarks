Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140`) deletes:

- **memo_relation records** where this memo is the source (`MemoID`)
- **memo_relation records** where this memo is the target (`RelatedMemoID`)
- **attachments** linked to this memo (found via `ListAttachments` with `MemoID`, then `DeleteAttachment` for each)

Then it calls `s.driver.DeleteMemo` to delete the memo row.
