Tables affected by explicit code when `DeleteMemo` runs:

- **memo** — the memo row itself, plus child comment memos (deleted recursively by the API handler at `server/router/api/v1/memo_service.go:573-577`)
- **memo_relation** — rows where the memo is source (`MemoID`) and where it is target (`RelatedMemoID`), plus the same cleanup for each deleted comment memo (`store/memo.go:141-147`)
- **attachment** — attachments linked to the memo (and its comments) are deleted (`store/memo.go:148-157`; `store/attachment.go:132`); this also removes the underlying stored file, not another table

Not affected by explicit cascade code: the `reaction` table — the API handler lists reactions only to build the webhook payload (`server/router/api/v1/memo_service.go:545-550`) but does not delete them.
