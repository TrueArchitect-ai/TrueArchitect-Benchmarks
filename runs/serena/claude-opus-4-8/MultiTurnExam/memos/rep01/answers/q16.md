Within `Store.DeleteMemo` (`store/memo.go:140-159`), before deleting the memo row itself it deletes:

- **memo_relation records where this memo is the source** (`MemoID` = memo)
- **memo_relation records where this memo is the target** (`RelatedMemoID` = memo)
- **attachments linked to this memo** (each removed via `DeleteAttachment`)

Then it deletes the memo row via `driver.DeleteMemo`.

(Note: at the API layer, `APIV1Service.DeleteMemo` in `server/router/api/v1/memo_service.go:567-577` additionally deletes child comment memos first — each of which recursively goes through the same store-layer cleanup.)
