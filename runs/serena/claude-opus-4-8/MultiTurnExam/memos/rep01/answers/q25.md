**Engine:** Google CEL (Common Expression Language), via `github.com/google/cel-go`, wrapped by the project's `internal/filter` package — the `Engine` type in `internal/filter/engine.go` (schema at `internal/filter/schema.go`, IR at `internal/filter/ir.go`, dialect rendering at `internal/filter/render.go`).

**Mechanism:** The CEL filter string is parsed into a dialect-agnostic condition/IR tree by the `internal/filter` `Engine`, which each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`, plus the postgres/mysql equivalents) then renders into a parameterized SQL `WHERE` clause via `filter.AppendConditions` with the appropriate `DialectSQLite`/`DialectPostgres`/`DialectMySQL` selector (`internal/filter/render.go` switches on the dialect to emit dialect-specific SQL).
