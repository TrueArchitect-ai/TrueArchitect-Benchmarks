**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (defined at line 156, registered on the main transport at line 188). It uses `web/src/auth-state.ts` for token storage/refresh.

**Token kinds:**
- **Access token** — short-lived JWT held in memory (client-side), attached to each request as an `Authorization: Bearer <token>` header; refreshed proactively/on 401.
- **Refresh token** — longer-lived JWT delivered/stored as an HTTP-only cookie (set via `Set-Cookie` in `server/router/api/v1/auth_service_session.go`), exchanged for a new access token via the `AuthService.RefreshToken` RPC.

**Backend validation package:** `server/auth` — the `Authenticator` and token helpers in `server/auth/authenticator.go` and `server/auth/token.go` validate/parse access and refresh tokens (`GenerateRefreshToken`, `ParseRefreshToken`, bearer resolution).
