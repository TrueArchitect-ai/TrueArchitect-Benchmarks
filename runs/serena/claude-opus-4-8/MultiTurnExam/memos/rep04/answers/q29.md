- **Interceptor path:** `web/src/connect.ts` — a ConnectRPC `Interceptor` that sets the `Authorization: Bearer <token>` header, backed by token storage/refresh in `web/src/auth-state.ts` (and the refresh client hitting `AuthService.refreshToken`).
- **Token kinds it manages:** short-lived **JWT access tokens** (held in `auth-state`, sent as Bearer) and **JWT refresh tokens** (used to obtain new access tokens via the refresh endpoint). The backend additionally supports **Personal Access Tokens (PAT)** for programmatic access.
- **Backend validation package:** `server/auth/` (JWT/PAT validation in `server/auth/authenticator.go` and `server/auth/token.go`).
