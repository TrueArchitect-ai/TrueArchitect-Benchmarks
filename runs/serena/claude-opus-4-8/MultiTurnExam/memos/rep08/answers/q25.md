**Engine:** Google CEL (Common Expression Language, via `github.com/google/cel-go`), living in the `internal/filter` package — `internal/filter/engine.go` (parses the CEL filter using `cel.NewEnv` with the schema in `internal/filter/schema.go`), producing an intermediate representation (`internal/filter/ir.go`, `parser.go`).

**Mechanism:** The parsed CEL expression is lowered to an IR and then rendered to dialect-specific SQL by the renderer in `internal/filter/render.go`, which holds a `DialectName` (SQLite/Postgres/MySQL) and emits per-dialect SQL (e.g. the `switch r.dialect` producing `strftime(...)` for SQLite, native functions for Postgres, and function calls for MySQL, with dialect-appropriate placeholders).
