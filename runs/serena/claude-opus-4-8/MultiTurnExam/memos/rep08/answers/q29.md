- **Interceptor path:** `web/src/connect.ts` — an `authInterceptor` that sets the `Authorization: Bearer <token>` header (`setAuthorizationHeader`, line 97), reactively refreshes on 401, and coordinates refresh via the token-refresh manager. Token storage/state lives in `web/src/auth-state.ts` (`getAccessToken`/`setAccessToken`).

- **Token kinds:** short-lived **JWT access tokens** (~15 min, held in memory/`auth-state`) and **refresh tokens** (used via `AuthService.RefreshToken` to mint new access tokens); the backend additionally supports long-lived **Personal Access Tokens (PAT)** for programmatic access.

- **Backend validation package:** `server/auth` (the `Authenticator` in `server/auth/authenticator.go`, with token parsing in `server/auth/token.go`), used by the gRPC/Connect interceptors and file server.
