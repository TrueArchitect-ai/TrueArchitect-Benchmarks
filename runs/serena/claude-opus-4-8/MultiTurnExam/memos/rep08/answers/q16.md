In the store layer (`store/memo.go:140-159`, `Store.DeleteMemo`), before deleting the memo row itself it deletes:

1. **memo_relation records** where the memo is the source (`MemoID`)
2. **memo_relation records** where the memo is the target (`RelatedMemoID`)
3. **attachments** linked to the memo (each removed via `DeleteAttachment`)

Then finally the memo row (`driver.DeleteMemo`).

(Separately, at the API layer in `server/router/api/v1/memo_service.go:567-577`, comment memos are deleted first — each of which recursively goes through the same store cleanup.)
