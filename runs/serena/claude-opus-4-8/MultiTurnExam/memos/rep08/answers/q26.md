`memo`, `memo_relation`, `attachment`

When `DeleteMemo` runs (`store/memo.go:140-159`, plus the API handler in `server/router/api/v1/memo_service.go`):
- **memo_relation** — rows where the memo is source (`MemoID`) or target (`RelatedMemoID`) are deleted
- **attachment** — rows linked to the memo are deleted (via `DeleteAttachment`, `DELETE FROM attachment`)
- **memo** — the memo row itself, and any comment memos (child rows in the same table) deleted recursively by the API handler

Reactions are listed only to build the webhook payload; there is no explicit code deleting `reaction` rows, so that table is not affected by this path.
