In `store.DeleteMemo` (`store/memo.go:140-158`), before deleting the memo row it deletes:

- **memo_relation** records where this memo is the source (`MemoID`)
- **memo_relation** records where this memo is the target (`RelatedMemoID`)
- **attachment** records linked to the memo (via `DeleteAttachment` for each)

Then it deletes the memo row itself (`s.driver.DeleteMemo`).

(At the API handler layer in `server/router/api/v1/memo_service.go:567-577`, comment memos are also deleted first, each of which runs the same store-level cleanup.)
