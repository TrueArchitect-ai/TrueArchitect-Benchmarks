**memo, memo_relation, attachment, memo_share**

- **memo** — the memo row itself is deleted (`store/memo.go:158`), plus any comment memo rows deleted recursively by the handler (`server/router/api/v1/memo_service.go:573-577`).
- **memo_relation** — explicitly deleted in both directions by `Store.DeleteMemo` (`store/memo.go:142`, `:145`).
- **attachment** — explicitly deleted for each linked attachment (`store/memo.go:149-157`).
- **memo_share** — removed via the SQL foreign-key cascade `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/sqlite/LATEST.sql:109`).

Note: the `reaction` table references memos by a text `content_id` with no FK to `memo(id)` and no explicit deletion, so reactions are **not** cleaned up by DeleteMemo.
