**User-configured URL source:** Webhook targets are set by users via the `CreateUserWebhook` / `UpdateUserWebhook` RPCs, which store an arbitrary URL (`server/router/api/v1/user_service_webhooks.go`).

**RPC handler methods that transitively trigger an outbound HTTP request to that URL** (all in `server/router/api/v1/`):

1. `CreateMemo` — `memo_service.go:70`, calls `DispatchMemoCreatedWebhook` at `memo_service.go:157`
2. `UpdateMemo` — `memo_service.go:401`, via `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`)
3. `DeleteMemo` — `memo_service.go:518`, calls `DispatchMemoDeletedWebhook` at `memo_service.go:562`
4. `CreateMemoComment` — `memo_service_comments.go:20`, calls `DispatchMemoCommentCreatedWebhook` at `memo_service_comments.go:119`

Handlers 1–3 route through `dispatchMemoRelatedWebhook`, and all four ultimately call `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43,71`), which enqueues onto `asyncPostQueue`; the four background workers started in `init()` drain that queue by calling `Post`.

**Convergence function — path:** `Post` — `internal/webhook/webhook.go:120` (the single function where every path builds the request and issues `safeClient.Do(req)` at line 152 for actual delivery).
