**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

The data layer is the `store` package, which defines the persistent entity types in `store/*.go` (e.g. `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, etc.). Counting distinct packages *outside* the `store/` tree that reference each entity as `store.<Type>`:

| Type | Packages outside store |
|------|------|
| `store.User` | 7 |
| `store.Memo` | 6 |
| `store.Attachment` | 4 |
| `store.MemoRelation` / `store.MemoShare` / `store.Inbox` | 3 each |
| others | ≤2 |

**`store.User`** (defined in `store/user.go`) is referenced from 7 external packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.

**`store.Memo`** (defined in `store/memo.go`) is referenced from 6: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.

The ranking holds regardless of whether the DB driver subpackages (`store/db/mysql`, `store/db/postgres`, `store/db/sqlite`) are treated as inside the data layer — with them included the counts are 11 vs 10, still User then Memo.
