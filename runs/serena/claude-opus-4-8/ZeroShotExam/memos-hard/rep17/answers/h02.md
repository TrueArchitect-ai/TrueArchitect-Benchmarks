**Delivery function** — `Post()` in `internal/webhook/webhook.go` is where the outbound HTTP request to the external webhook URL actually executes. It builds the `POST` to the configured URL (optionally adding Standard Webhooks HMAC-SHA256 signature headers) and fires it through a shared `safeClient.Do(req)`. Delivery is fed by `PostAsync` (bounded queue) and drained by worker goroutines started in `init()`, all in the same file.

**Protection mechanism** — SSRF protection is enforced at two layers, both built on the `isReservedIP()` predicate in `internal/webhook/validate.go`:

- **Dial-time (primary):** `safeDialContext()` in `internal/webhook/webhook.go` is installed as the `DialContext` on `safeClient`'s transport. It resolves the host at connection time and refuses any address where `isReservedIP` is true — because this runs on every dial, it also defeats DNS-rebinding/TOCTOU attacks.
- **Registration-time (secondary):** `ValidateURL()` in `internal/webhook/validate.go` restricts the scheme to `http`/`https` and rejects URLs that resolve to reserved/private IPs.

`isReservedIP()` (in `internal/webhook/validate.go`) is the shared check, blocking loopback, RFC-1918 private ranges, link-local (incl. `169.254.169.254` cloud metadata), and their IPv6 equivalents. Note there's an `AllowPrivateIPs` escape hatch that disables this for self-hosted setups, and the design is denylist-based (no allowlist).

Summary in the requested format:
- delivery function — `internal/webhook/webhook.go` (`Post`, via `safeClient.Do`)
- protection mechanism — `internal/webhook/webhook.go` (`safeDialContext`) + `internal/webhook/validate.go` (`isReservedIP`, used by `safeDialContext` and `ValidateURL`)
