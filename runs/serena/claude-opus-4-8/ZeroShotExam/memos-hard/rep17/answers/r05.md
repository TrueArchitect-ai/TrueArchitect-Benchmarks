**Premise correction:** There is no GraphQL schema in this repository. Memos (usememos) does not expose a GraphQL API. A full search for `.graphql`/`.gql` files and any `graphql` string references returned zero results, and the README explicitly states the project provides "full REST and gRPC APIs" (`README.md`), not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC) with a REST gateway**, not GraphQL. The schema lives in the `proto/` directory:

- **Public API service definitions:** `proto/api/v1/` — one `.proto` file per service, including:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/common.proto`
- **Internal store schemas** (persistence layer, not the public API): `proto/store/*.proto`
- **Build config / codegen:** `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`, with generated code under `proto/gen/`.

These proto files are the source of truth: they generate the gRPC services and, via grpc-gateway, the REST endpoints. An OpenAPI/REST surface is also derived from them (see `proto/openapi_embed.go`). So the correct answer to "where is the API schema defined" is `proto/api/v1/*.proto` — a gRPC + REST surface, with no GraphQL layer anywhere in the repo.
