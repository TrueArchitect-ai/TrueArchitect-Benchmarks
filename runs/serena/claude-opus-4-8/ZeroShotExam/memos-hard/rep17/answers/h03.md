h03.

Users authenticate through third-party identity providers via the code under `internal/idp`.

- **Abstraction package:** `internal/idp` — `internal/idp/idp.go` defines the shared identity-provider contract (`IdentityProviderUserInfo`) that every provider implementation returns.
- **Implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go` implements the OAuth2 identity provider (`IdentityProvider` built from `storepb.OAuth2Config`, with `ExchangeToken`/`UserInfo`). It's the only concrete protocol that ships (confirmed by `proto/gen/store/idp.pb.go`, whose `IdentityProvider_Type` enum has only `TYPE_UNSPECIFIED` and `OAUTH2`). Wired in `server/router/api/v1/auth_service_sso.go`.

Answer: `internal/idp`; `internal/idp/oauth2`
