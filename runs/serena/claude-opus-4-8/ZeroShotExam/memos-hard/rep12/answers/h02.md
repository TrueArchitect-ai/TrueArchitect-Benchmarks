It relies on the blocklist predicate `isReservedIP` and CIDR set (loopback, RFC-1918, link-local/IMDS `169.254.169.254`, IPv6 equivalents) in `internal/webhook/validate.go` (lines 14–23, 44), which is also enforced upfront via `ValidateURL` (line 62) on webhook create/update.

Note: `internal/webhook/validate.go` exposes a global `AllowPrivateIPs` kill-switch (line 41) — when true, `isReservedIP` always returns false, disabling this SSRF protection entirely.
