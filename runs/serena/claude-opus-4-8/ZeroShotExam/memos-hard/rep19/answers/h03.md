h03. The provider abstraction is defined in the `internal/idp` package (`internal/idp/idp.go`, module path `github.com/usememos/memos/internal/idp`), which declares the protocol-neutral `IdentityProviderUserInfo` contract that every provider returns. The concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — it implements the OAuth2 flow (with PKCE), returns `*idp.IdentityProviderUserInfo`, and is wired in at `server/router/api/v1/auth_service_sso.go`. OAuth2 is currently the only concrete implementation (no separate SAML/OIDC package).

Answer: `internal/idp`; `internal/idp/oauth2`
