**Computation site.** The derived metadata is the memo's `Payload.Property`, built by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls the goldmark markdown service's `ExtractAll`. The actual extraction logic (a single AST walk) lives in `internal/markdown/markdown.go:355-409` (`ExtractAll`, populating `*storepb.MemoPayload_Property`). `RebuildMemoPayload` assigns both `memo.Payload.Tags` and `memo.Payload.Property` from the parsed result.

**Triggers (recomputation).**
- **Create memo** — `server/router/api/v1/memo_service.go:108` (in `CreateMemo`).
- **Update memo content** — `server/router/api/v1/memo_service.go:447` (the `content` field branch of `UpdateMemo`; only when content changes).
- **Bulk rebuild** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) re-derives the payload for all memos in batches (backfill/migration pass).

**Extracted properties.** From `ExtractAll` (`internal/markdown/markdown.go:387-404`), the `MemoPayload_Property` fields:
- `Title` — text of the document's first block if it is an H1 heading (`markdown.go:384-388`).
- `HasLink` — a `KindLink` node exists (`:393-394`).
- `HasCode` — any code block / fenced code / code span (`:396-397`).
- `HasTaskList` — a task checkbox exists (`:399-400`).
- `HasIncompleteTasks` — at least one unchecked task checkbox (`:401-404`).

(These property fields are what the converter surfaces to the API at `server/router/api/v1/memo_service_converter.go:315-324` and are consumed for filtering/stats, e.g. `internal/filter/schema.go` and `server/router/api/v1/user_service_stats.go`. Tags are extracted in the same pass but are a separate field, not part of `Property`.)
