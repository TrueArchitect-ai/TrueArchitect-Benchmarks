**Convergence function — path:** `dispatchMemoRelatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:48`

All four `DispatchMemo*Webhook` variants funnel into `dispatchMemoRelatedWebhook`, which loads the creator's webhooks, sets `payload.URL = hook.Url` (the user-configured URL), and calls `webhook.PostAsync` (line 71). From there delivery proceeds through `webhook.PostAsync` → `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual HTTP POST. So the single application-level function where every handler path converges before delivery is `dispatchMemoRelatedWebhook`; if you want the last common function inside the webhook package that performs the delivery itself, that is `webhook.Post`.
