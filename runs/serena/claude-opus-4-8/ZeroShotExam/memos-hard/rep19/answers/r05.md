**Premise correction:** There is no GraphQL schema in this repository — public or otherwise. A search for `.graphql`/`.gql` files, `type Query`, `buildSchema`, `makeExecutableSchema`, Apollo, gqlgen, and related keywords across the Go, TS/JS, Vue, and config files (excluding `node_modules`) returns zero matches. This is **Memos** (`github.com/usememos/memos`, per `/bench/repo/go.mod`), a self-hosted Go note-taking app, and it does not use GraphQL anywhere.

**Actual API surface:** The public API is defined in **Protocol Buffers** and exposed as **gRPC + REST + Connect RPC**, all generated from a single schema source of truth.

- **Schema definition (source of truth):** `.proto` files in `/bench/repo/proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `common.proto`. Design conventions are documented in `/bench/repo/proto/api/v1/README.md` (Google AIP style).
- **Generated code:** `/bench/repo/proto/gen/api/` and `/bench/repo/proto/gen/store/`.
- **Server wiring:** `/bench/repo/server/router/api/v1/v1.go` — `RegisterGateway` (`v1.go:65`) mounts a REST/JSON API via grpc-gateway under `/api/v1` (e.g. `RegisterMemoServiceHandlerServer`, `v1.go:99-120`) and Connect/gRPC handlers under `/memos.api.v1.*` (`v1.go:139-144`), plus an SSE endpoint (`v1.go:125`). Top-level HTTP server is set up in `/bench/repo/server/server.go` (Echo v5).

Auxiliary HTTP interfaces (also not GraphQL): RSS feed (`server/router/rss/rss.go`), an MCP server (`server/router/mcp/`), a file server for attachments (`server/router/fileserver/fileserver.go`), and static frontend serving (`server/router/frontend/frontend.go`). The `cmd/memos/main.go` cobra CLI is a server launcher, not the API itself.

So: instead of a GraphQL schema, look at the Protobuf definitions under `proto/api/v1/`, which generate the gRPC + REST + Connect API served at `/api/v1` and `/memos.api.v1.*`.
