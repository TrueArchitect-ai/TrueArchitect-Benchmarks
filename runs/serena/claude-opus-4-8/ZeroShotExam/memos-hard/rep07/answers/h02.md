**delivery function** — `Post` in `internal/webhook/webhook.go` (defined at line 120; it marshals the payload, builds the request, and executes it via `safeClient.Do(req)` at line 152). Async delivery is queued through `PostAsync`, but the actual outbound HTTP send happens inside `Post`.

**protection mechanism** — SSRF is blocked at dial time by `safeDialContext` in `internal/webhook/webhook.go` (line 59), wired into the shared `safeClient`'s `http.Transport.DialContext` (lines 32–37). It resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP` in `internal/webhook/validate.go` (line 44), which checks against `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, plus IPv6 equivalents; `internal/webhook/validate.go:14`). Because the check happens on the resolved IP at connection time, it also defeats DNS-rebinding. There's an additional up-front check, `ValidateURL` (`internal/webhook/validate.go:62`), enforcing http/https scheme and the same reserved-IP rule when a webhook is created. Both can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted setups.
