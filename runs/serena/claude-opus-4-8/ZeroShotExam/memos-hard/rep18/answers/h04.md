Evidence:

- Other call sites that could produce a MySQL driver (e.g. `store/test/store.go:28` and `:50`, and `server/router/api/v1/test/memo_service_benchmark_test.go:70`) go through the factory `db.NewDBDriver`, not the MySQL driver directly, and only build a MySQL driver if the test profile is configured for it.
