**Premise correction:** This repository (Memos) does **not** expose a GraphQL API, and no GraphQL schema exists anywhere in it. There is no `.graphql` schema file, no schema-definition-language string, and no GraphQL server/resolver code — a full-repo search for "graphql" returns zero matches in Go, proto, or TypeScript sources.

**Actual API surface:** Memos serves a **gRPC + REST (gRPC-gateway) API defined via Protocol Buffers**, not GraphQL. The public API "schema" is the set of `.proto` service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These are compiled with `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`; see `proto/README.md`), with generated code in `proto/gen/`. Storage-layer protos live in `proto/store/`. The REST surface is produced from the same protos via gRPC-gateway annotations, and an OpenAPI document is embedded through `proto/openapi_embed.go`. The README confirms this: Memos offers "full REST and gRPC APIs" — no GraphQL.
