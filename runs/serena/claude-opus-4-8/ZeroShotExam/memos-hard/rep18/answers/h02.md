**delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). It builds the outgoing `POST` request and executes it at line 152 via `safeClient.Do(req)`. (`PostAsync` at line 184 just enqueues onto a worker pool whose goroutines call `Post`.)

**protection mechanism** — `internal/webhook/webhook.go`: the shared `safeClient` (line 32) uses a custom `Transport` whose `DialContext` is `safeDialContext` (line 59). At dial time it resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP` — enforced at connection time, so it also defeats DNS‑rebinding. The reserved ranges and `isReservedIP` live in `internal/webhook/validate.go` (lines 14–54): loopback, RFC‑1918 private, link‑local/cloud IMDS (169.254.169.254), and their IPv6 equivalents. A second, earlier check `ValidateURL` (`internal/webhook/validate.go`, line 62) validates scheme and resolved IP when the webhook URL is configured. Note both checks can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go`, line 41) for self-hosted/local-network deployments.
