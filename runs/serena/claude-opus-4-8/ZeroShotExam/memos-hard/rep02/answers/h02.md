delivery function — `Post` at `internal/webhook/webhook.go` (the async wrapper `PostAsync` in the same file enqueues to workers that call `Post`; the outbound request executes at `safeClient.Do(req)`, ~line 152); protection mechanism — dial-time reserved/private-IP blocking via `safeDialContext` in `internal/webhook/webhook.go`, backed by the CIDR denylist `reservedCIDRs` and `isReservedIP` in `internal/webhook/validate.go` (with an up-front `ValidateURL` check in the same file).

Notes:
- The SSRF guard is enforced at **dial time** (`safeClient`'s custom `Transport.DialContext = safeDialContext`), so it also resists DNS-rebinding, not just at webhook-creation time.
- The denylist covers IPv4 loopback/RFC-1918/link-local (incl. `169.254.0.0/16` cloud metadata) and IPv6 loopback/unique-local/link-local.
- There is an escape hatch: the package flag `AllowPrivateIPs` (`internal/webhook/validate.go`) disables the check for self-hosted deployments that intentionally target internal services.
