**delivery function** — `Post` at `internal/webhook/webhook.go:120` (specifically the `safeClient.Do(req)` call at line 152 performs the actual outbound HTTP request). Async dispatch is queued via `PostAsync` and drained by worker goroutines in `init` (line 42), all funneling through `Post`.

**protection mechanism** — SSRF is blocked at dial time by `safeDialContext` at `internal/webhook/webhook.go:59`, which is wired into the shared `safeClient`'s `Transport.DialContext` (lines 32–37). It resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), checked against the CIDR blocklist `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents) at `internal/webhook/validate.go:14`. Because the check happens on the resolved IP at connection time, it also defeats DNS-rebinding. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) pre-validates URLs (scheme + resolved-IP check) when webhooks are configured. Note the guard can be globally disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
