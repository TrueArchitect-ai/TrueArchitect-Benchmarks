**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package:** `internal/idp` — defines the shared, protocol-agnostic identity-provider seam, notably the `IdentityProviderUserInfo` type in `internal/idp/idp.go` that every concrete provider must produce. The persistence/config side is backed by `store/idp.go` and the provider `Type` enum in `proto/store/idp.proto` (currently only `OAUTH2`).
- **Concrete implementation package:** `internal/idp/oauth2` — ships the **OAuth2** protocol implementation in `internal/idp/oauth2/oauth2.go` (`IdentityProvider` struct, `NewIdentityProvider`, `ExchangeToken`, `UserInfo`).

The two are wired together in `server/router/api/v1/auth_service_sso.go:121`, which calls `oauth2.NewIdentityProvider(...)` during the SSO login callback. OAuth2 is the only protocol implemented so far.
