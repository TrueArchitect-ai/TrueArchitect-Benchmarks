**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual content parsing to the goldmark-backed `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356`. The extracted values are stored into `memo.Payload.Property` (and `.Tags`) at `runner.go:85-86`. The result lives in the memo's `Payload.Property` (`proto/gen/store` `MemoPayload_Property`), distinct from user-set fields.

**Triggers (recomputation):**
- **Create** — `CreateMemo` calls `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Update (content change)** — `UpdateMemo` calls it at `server/router/api/v1/memo_service.go:447`, but only when the `content` field is in the update mask (`if path == "content"`). Non-content updates (e.g. visibility) do not recompute it.
- **Bulk backfill** — the `Runner.RunOnce` job at `server/runner/memopayload/runner.go:27` walks every memo in batches of 100 and rebuilds each payload, then persists via `UpdateMemo`.

**Extracted properties** (in `ExtractAll`, `internal/markdown/markdown.go:383-408`), computed from a single AST walk of the memo content:
- `Title` — text of the document's first block-level child if it is an H1 heading (`markdown.go:384-388`).
- `HasLink` — true if any link node is present (`KindLink`).
- `HasCode` — true if any code block, fenced code block, or inline code span is present.
- `HasTaskList` — true if any task checkbox is present; and `HasIncompleteTasks` — true if any task checkbox is unchecked (`markdown.go:399-405`).

(`Tags` are also extracted in the same pass and stored on the payload, but tags come from `#tag` nodes rather than the `Property` struct.)
