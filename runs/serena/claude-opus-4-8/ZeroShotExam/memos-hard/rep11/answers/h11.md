**1st: `store.User`; 2nd: `store.Memo`**

The data layer is the `store` package (`/bench/repo/store`), where persistent entity types are defined as structs — `Memo`, `User`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `IdentityProvider`, `UserSetting`, `InstanceSetting`, `UserIdentity`, `MemoShare` (e.g. `store/user.go`, `store/memo.go`).

Counting distinct Go packages **outside the `store/` tree** that reference each type (`store.<Type>`):

- **1st: `User` — ~7 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **2nd: `Memo` — ~6 packages**: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

(The ranking is unchanged if the data-layer's own driver subpackages `store/db/{sqlite,mysql,postgres}` and `store/test` are also counted — then User ≈ 11 and Memo ≈ 10.)

Next closest is `Attachment` (~4 packages), so User and Memo are the clear top two.
