**Delivery function** — `Post` in `internal/webhook/webhook.go` (the outbound POST actually executes at line 152, `safeClient.Do(req)`). Payloads may also be enqueued via `PostAsync` and drained by worker goroutines that call `Post`.

**Protection mechanism** — `internal/webhook/webhook.go` (the `safeClient` HTTP client whose `Transport.DialContext` is `safeDialContext`), backed by `isReservedIP` in `internal/webhook/validate.go`.

The real enforcement is dial-time: `safeDialContext` (webhook.go:59) resolves the target host and rejects the connection if any resolved IP is a reserved/private address per `isReservedIP` (validate.go:44), which checks against loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents. Because the check runs on the actually-resolved IPs at connection time, it also defeats DNS-rebinding. A second, config-time layer exists in `ValidateURL` (validate.go:62), and an `AllowPrivateIPs` flag (validate.go:41) can disable the checks for self-hosted setups.

Answer: delivery function `Post` — `internal/webhook/webhook.go`; protection mechanism `safeDialContext`/`safeClient` with `isReservedIP` reserved-IP blocking — `internal/webhook/webhook.go` and `internal/webhook/validate.go`.
