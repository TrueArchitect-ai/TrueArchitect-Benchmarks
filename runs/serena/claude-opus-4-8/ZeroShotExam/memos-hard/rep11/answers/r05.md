**Premise correction:** This repository (Memos) does **not** define a GraphQL schema for its public API — there is no GraphQL anywhere in the codebase. The README itself states Memos offers "full REST and gRPC APIs" (`README.md`), not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC service definitions** in `proto/api/v1/`, which are also exposed as a REST API via grpc-gateway and documented with OpenAPI. Specifically:

- **Schema/service definitions** (`.proto` files) in `proto/api/v1/`:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/common.proto`
- **Generated code** lives in `proto/gen/`, with build configuration in `proto/buf.yaml` and `proto/buf.gen.yaml`.
- Internal store-layer protobufs (not the public API) are in `proto/store/`.
- An embedded OpenAPI document is referenced via `proto/openapi_embed.go`, reflecting the REST surface generated from these gRPC definitions.

So the correct answer to "where is the API schema defined" is `proto/api/v1/*.proto` (gRPC + REST), not a GraphQL schema.
