**`internal/idp`; `internal/idp/oauth2`**

Users authenticate through third-party identity providers via the SSO flow in this Go codebase (usememos/memos):

- **Abstraction package: `internal/idp`** — `internal/idp/idp.go` defines the shared, protocol-agnostic contract that every provider implementation returns, `IdentityProviderUserInfo` (with `Identifier`, `DisplayName`, `Email`, `AvatarURL`). Concrete providers live under this package and produce this neutral type.

- **Concrete implementation package: `internal/idp/oauth2`** — `internal/idp/oauth2/oauth2.go` (doc comment: "Package oauth2 implements the OAuth2 identity provider integration") ships the OAuth2 protocol implementation: `type IdentityProvider struct`, `NewIdentityProvider`, `ExchangeToken` (with PKCE), and `UserInfo` (mapping claims into `idp.IdentityProviderUserInfo`).

Wiring: `server/router/api/v1/auth_service_sso.go` imports `internal/idp/oauth2` and calls `oauth2.NewIdentityProvider(...)` in `resolveSSOIdentity`. OAuth2 is currently the only shipped protocol — there is no OIDC/SAML/LDAP subpackage.
