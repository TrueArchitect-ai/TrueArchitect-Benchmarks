**delivery function** — `Post` in `internal/webhook/webhook.go:120` (invoked from the async worker pool in `init()` at `internal/webhook/webhook.go:42-55` via `PostAsync`). The actual outbound HTTP request executes at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).

**protection mechanism** — The request goes through `safeClient`, whose transport uses `safeDialContext` (`internal/webhook/webhook.go:59-77`). At dial time it resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, ranges defined at `internal/webhook/validate.go:14-23`). Doing the check at dial time — on the actually-resolved IPs — is what defeats DNS rebinding, since the create-time `ValidateURL` check (`internal/webhook/validate.go:62`) could otherwise be bypassed. This SSRF guard can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
