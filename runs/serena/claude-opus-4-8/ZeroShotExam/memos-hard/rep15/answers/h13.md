**Markdown processing sits behind the `markdown.Service` interface** (`internal/markdown/markdown.go:31`), whose methods are `ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, `RenameTag`.

**impl —** There is exactly one concrete runtime implementation: the unexported struct `service` (`internal/markdown/markdown.go:57-60`), which wraps a `goldmark.Markdown`. It is returned as `Service` from `NewService`, which builds a goldmark instance and does `return &service{md: md}` (`internal/markdown/markdown.go:85-113`). (An internal helper `renderer.MarkdownRenderer` at `internal/markdown/renderer/markdown_renderer.go:20` is used *inside* `service.RenderMarkdown`/`RenameTag`, but it sits behind `service`, not behind the `Service` interface.)

**construction —** The single production instance is built by `NewAPIV1Service` via `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` at `server/router/api/v1/v1.go:48-51`, and stored in `APIV1Service.MarkdownService`. That same instance is then handed to the RSS service in `server/server.go:85` (`rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`). Other `markdown.NewService(...)` calls exist only in tests (`server/router/api/v1/test/test_helper.go:44`, `server/router/rss/rss_test.go:54`, `server/router/fileserver/fileserver_test.go:427`, and `internal/markdown/markdown_test.go`).

**holders —** Components that hold the `markdown.Service` interface (as a field / constructor param):
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35`. Used in `memo_service.go:108,447`, `memo_mention_helpers.go:32`, `memo_service_webhooks.go:85`.
- `RSSService.MarkdownService` — `server/router/rss/rss.go:45` (ctor `NewRSSService`, `rss.go:58`); used at `rss.go:339` (`RenderHTML`).
- `memopayload.Runner.MarkdownService` — `server/runner/memopayload/runner.go:16` (ctor `NewRunner`, `runner.go:19`); plus the free function `RebuildMemoPayload(_, memo, markdownService markdown.Service)` at `runner.go:74`, which is called with `s.MarkdownService` from `memo_service.go:108,447`. (Note: `NewRunner` itself has no production caller — only `RebuildMemoPayload` is used in production.)

Net: one concrete type (`*markdown.service`), constructed once in production at `v1.go:48` and shared into the RSS service; the interface is held by `APIV1Service`, `RSSService`, and the memopayload `Runner`/`RebuildMemoPayload` path.
