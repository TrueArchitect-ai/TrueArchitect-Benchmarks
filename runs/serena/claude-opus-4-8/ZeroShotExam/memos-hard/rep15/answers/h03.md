**abstraction: `internal/idp`; implementation: `internal/idp/oauth2`**

The provider abstraction lives in the `idp` package at `internal/idp/idp.go`, which defines the provider-neutral `IdentityProviderUserInfo` type used across identity-provider integrations.

The concrete protocol implementation that ships is the OAuth2 package at `internal/idp/oauth2/oauth2.go` — its header comment reads `// Package oauth2 implements the OAuth2 identity provider integration`, and it provides `IdentityProvider` / `NewIdentityProvider` backed by `golang.org/x/oauth2` and a `storepb.OAuth2Config`. This is the only concrete protocol implementation under `internal/idp/`.
