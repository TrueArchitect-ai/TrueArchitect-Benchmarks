**delivery function** — `Post` (and its async wrapper `PostAsync`) in `internal/webhook/webhook.go`. `Post` marshals the payload, builds the POST request, and executes it via `safeClient.Do(req)` (webhook.go:152); `PostAsync` enqueues onto a bounded channel drained by worker goroutines that call `Post`.

**protection mechanism** — SSRF protection via `safeDialContext` in `internal/webhook/webhook.go:59`, which is wired into the shared `safeClient`'s `http.Transport.DialContext` (webhook.go:32-37). At dial time it resolves the target host and rejects any address in a reserved/private range using `isReservedIP` — `internal/webhook/validate.go:44` — backed by the `reservedCIDRs` list (loopback, RFC-1918, link-local/cloud IMDS 169.254.0.0/16, and IPv6 equivalents) at `internal/webhook/validate.go:14`. Because the check happens at the actual dial (post-DNS-resolution), it also defeats DNS-rebinding. There is a secondary pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62`), used when webhooks are configured. Both can be disabled via the `AllowPrivateIPs` flag (validate.go:41) for self-hosted local-network use.
