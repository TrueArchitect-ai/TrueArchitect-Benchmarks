delivery function — `Post` (executed by `safeClient.Do(req)`) in `internal/webhook/webhook.go`; protection mechanism — `safeDialContext` / `isReservedIP` in `internal/webhook/webhook.go` and `internal/webhook/validate.go`

Details:

- **Where delivery executes:** `Post()` at `internal/webhook/webhook.go:120` builds and sends the outbound POST via the shared `safeClient.Do(req)` (line 152). Deliveries are triggered asynchronously through `PostAsync` → a bounded queue whose workers call `Post` (`internal/webhook/webhook.go:42-55`, `184`).

- **What protects it from internal addresses (SSRF):** Two layers, both keyed on `isReservedIP` in `internal/webhook/validate.go:44`, which checks the resolved IP against a list of reserved/private CIDRs (`127.0.0.0/8`, RFC-1918 ranges, `169.254.0.0/16` incl. cloud IMDS, and IPv6 loopback/ULA/link-local — `validate.go:14-23`):
  1. **Dial-time enforcement** — the `safeClient` transport uses `safeDialContext` (`internal/webhook/webhook.go:59-77`), which resolves the host at connection time and refuses any address in a reserved range. Because the check happens at dial time on the actually-resolved IP, it also defeats DNS-rebinding.
  2. **Input validation** — `ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and hostnames that resolve to reserved IPs when a webhook is created/updated.

Note: this can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted setups that intentionally target local services.
