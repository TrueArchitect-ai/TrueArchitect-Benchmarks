**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this repository. The question's premise is false on two counts.

1. **The cron scheduler is an unused library, not a running scheduler with registered jobs.** The package `internal/scheduler/` implements a generic cron scheduler, but it is never imported or instantiated by any application code — a search for `internal/scheduler` across all non-test Go files returns nothing, and no server startup path registers any job with it. So no job of any kind is actually scheduled to run.

2. **The only "cleanup" jobs that exist are illustrative examples in documentation, and none is a "database-cleanup" job.** They appear in:
   - `internal/scheduler/README.md:34-35` — a `"daily-cleanup"` example with `Schedule: "0 2 * * *"` ("2 AM daily").
   - `internal/scheduler/README.md:241-244` — a `"stale-session-cleanup"` example with `Schedule: "0 3 * * *"` (3 AM).
   - `internal/scheduler/doc.go:15` — a `"daily-cleanup"` example in a doc comment (no schedule shown).
   - `internal/scheduler/README.md:233` — `"user-cleanup-job"` mentioned only as a naming-convention example.

These are teaching examples for the scheduler API; they are not wired into the application and none is described as cleaning a database. If you were looking for the closest documented example, the README's generic `"daily-cleanup"` is set to `"0 2 * * *"` (2 AM) — but that is example documentation, not an actual scheduled database-cleanup job.
