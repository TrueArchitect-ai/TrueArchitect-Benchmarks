**Premise correction:** This repository (**Memos**, `usememos/memos`) does **not** define or expose a GraphQL API at all. There is no GraphQL schema anywhere in the codebase — no `.graphql`/`.gql` files, and no `graphql` references in any Go, TypeScript, or JSON source. The question's premise is mistaken.

**Actual API surface:** The public API is defined via **Protocol Buffers (gRPC + REST)**, not GraphQL:

- **Schema/service definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, and shared types in `proto/api/v1/common.proto`.
- **Generated code:** `proto/gen/api/v1/` (and `proto/gen/store/` for the internal store schema).
- **Storage-layer protos:** `proto/store/`.

The README (`README.md`) itself states the project offers "full **REST and gRPC** APIs" — the REST surface is produced from the same `.proto` definitions via gRPC-gateway. So the correct place to look for the public API "schema" is the protobuf definitions under `proto/api/v1/`, not a GraphQL schema.
