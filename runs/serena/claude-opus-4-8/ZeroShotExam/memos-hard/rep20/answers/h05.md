**Mechanism: by explicit Go code** (two separate explicit `DELETE FROM reaction` statements run inside the delete-user transaction). There is **no** database-level cascade — the `reaction` table has no foreign key or `ON DELETE CASCADE`.

**Evidence:**

1. **The explicit deletion happens in the per-driver `DeleteUser` implementations.** In `deleteUserTargetsTx`, two reaction deletes are invoked before the user row is removed:
   - `store/db/sqlite/user_delete.go:96` — `deleteReactionsByContentIDsTx` (reactions *on* the deleted user's memos, keyed by `content_id`)
   - `store/db/sqlite/user_delete.go:102` — `deleteReactionsByCreatorTx` (reactions *authored by* the user, keyed by `creator_id`)

   The functions themselves:
   - `store/db/sqlite/user_delete.go` — `deleteReactionsByContentIDsTx` runs `DELETE FROM reaction WHERE content_id IN (...)`; `deleteReactionsByCreatorTx` runs `DELETE FROM reaction WHERE creator_id = ?`.
   - `store/db/postgres/user_delete.go` — same two functions and the same call sites in `deleteUserTargetsTx` (lines ~96 and ~102).
   - `store/db/mysql/user_delete.go` — present in the same set of files (mysql driver mirrors the others).

2. **No DB-level rule.** The `reaction` table definitions carry only a plain `creator_id INTEGER NOT NULL` column and a `UNIQUE(creator_id, content_id, reaction_type)` constraint — no foreign key, no `ON DELETE` action:
   - `store/migration/sqlite/LATEST.sql:92-99`
   - `store/migration/postgres/LATEST.sql:91-98`
   - (mysql `LATEST.sql` matches; `content_id` is a string reference like `memos/<uid>`, not an FK, which is why creator-authored reactions need the separate `creator_id` delete.)

**What I checked:** grepped for reaction/user-delete Go files and all `*.sql` migrations; read `store/db/sqlite/user_delete.go` and `store/db/postgres/user_delete.go` in full (both call the two reaction-delete helpers inside the transaction); and inspected the `CREATE TABLE reaction` blocks in the sqlite/postgres/mysql `LATEST.sql` schemas to confirm the absence of any cascade constraint.
