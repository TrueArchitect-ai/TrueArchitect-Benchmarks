**Delivery function** — `Post` in `/bench/repo/internal/webhook/webhook.go` (the outbound HTTP request fires at line 152 via `safeClient.Do(req)`; content-change code calls `PostAsync`, whose background workers invoke `Post`).

**Protection mechanism** — `isReservedIP` in `/bench/repo/internal/webhook/validate.go`, enforced at two points that both key on it:
- **Dial-time guard** (the real protection against DNS rebinding): `safeDialContext` in `/bench/repo/internal/webhook/webhook.go` rejects any resolved address matching `isReservedIP`, wired into `safeClient`'s `Transport.DialContext`, so it runs on every actual delivery.
- **Registration-time validator**: `ValidateURL` in `/bench/repo/internal/webhook/validate.go` blocks reserved/private IPs when a webhook URL is created/updated.

The blocked ranges (`reservedCIDRs`, validate.go) cover loopback (`127.0.0.0/8`), RFC-1918 private ranges, link-local/cloud-metadata (`169.254.0.0/16`, i.e. `169.254.169.254`), and IPv6 equivalents.

Caveat: an `AllowPrivateIPs` flag (from the `allow-private-webhooks` config option, `cmd/memos/main.go`) short-circuits `isReservedIP` to always return false, disabling both guards.
