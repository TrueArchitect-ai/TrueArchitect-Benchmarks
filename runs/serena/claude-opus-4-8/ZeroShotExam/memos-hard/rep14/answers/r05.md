**Premise correction:** There is no GraphQL schema in this repository. The question's premise is mistaken — this project (Memos) does not use GraphQL anywhere. There are no `*.graphql`/`*.gql` files, and no references to `graphql`, `typeDefs`, `buildSchema`, Apollo, urql, or Relay in any source, config, or lockfile. (The only substring matches — "relayout" in `web/src/components/ColumnGrid/ColumnGrid.tsx` and "relay" in `web/pnpm-lock.yaml` — are false positives unrelated to GraphQL.)

**Actual API surface:** The public API is **Protobuf-first**, defined in `.proto` service files and exposed over multiple protocols via code generation.

- **Source of truth — Protobuf service definitions** in `proto/api/v1/`:
  - `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`
  - Each RPC carries a `google.api.http` annotation defining its REST mapping (e.g. `GET /api/v1/memos`, `POST /api/v1/auth/signin`). Design follows Google AIP guidelines (`proto/api/v1/README.md`). Codegen is driven by `buf` (`proto/buf.yaml`, `proto/buf.gen.yaml`).

- **Generated code** in `proto/gen/`:
  - gRPC + gRPC-Gateway stubs: `proto/gen/api/v1/*_grpc.pb.go`, `*.pb.gw.go`
  - Connect-RPC handlers: `proto/gen/api/v1/apiv1connect/*.connect.go`
  - **OpenAPI 3.0 spec**: `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`

- **Handler implementations & HTTP wiring**: `server/router/api/v1/` (e.g. `v1.go`, `connect_handler.go`), mounted on an Echo server in `server/server.go`.

The API is exposed over four coordinated surfaces — native **gRPC**, **Connect-RPC**, **RESTful JSON** at `/api/v1/...` (via gRPC-Gateway), and a generated **OpenAPI 3.0** spec — plus **RSS** feeds (`server/router/rss/`) and an **MCP** endpoint at `/mcp` (`server/router/mcp/`) that reuses the REST API. There is no GraphQL, no tRPC, and no hand-written Swagger.
