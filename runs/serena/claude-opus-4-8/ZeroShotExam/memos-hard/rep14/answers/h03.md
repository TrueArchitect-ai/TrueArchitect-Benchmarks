The `internal/idp` package defines the provider abstraction — the neutral `IdentityProviderUserInfo` type (`internal/idp/idp.go`) that every concrete provider returns. The only concrete protocol implementation that ships is **OAuth2** in `internal/idp/oauth2/oauth2.go`, which provides `NewIdentityProvider`, `ExchangeToken` (with PKCE), and `UserInfo`. This is confirmed by the proto enum at `proto/store/idp.proto:11` defining only `OAUTH2 = 1`, and the consumer `server/router/api/v1/auth_service_sso.go` dispatching solely on `IdentityProvider_OAUTH2`. No OIDC/SAML/LDAP implementations exist.
