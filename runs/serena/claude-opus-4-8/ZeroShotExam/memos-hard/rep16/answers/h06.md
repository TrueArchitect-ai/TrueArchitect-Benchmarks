**Convergence function — path:** `webhook.PostAsync` — `internal/webhook/webhook.go:184`

Every handler path funnels into `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; the queue workers then call `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual `safeClient.Do` HTTP request. So `PostAsync` is the single point where the paths converge before delivery, and `Post` is the function that performs the send.
