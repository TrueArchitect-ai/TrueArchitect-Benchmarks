The question's premise is incorrect: there is **no nightly database-cleanup job scheduled in the cron scheduler** in this repository.

Details:

- The repo does contain a cron scheduler package (`internal/scheduler/`), which parses standard 5/6-field cron expressions (`internal/scheduler/scheduler.go`, `internal/scheduler/parser.go`). However, it is **never imported or used anywhere outside its own package** — a search for `internal/scheduler` across all non-package `.go` files returns nothing. No real jobs are registered with it.

- The only thing resembling a "daily cleanup at a specific time" is a **documentation example** in `internal/scheduler/doc.go:14-20`, which shows a hypothetical job named `"daily-cleanup"` with schedule `"0 2 * * *"` (2 AM daily). This is illustrative package-usage docs, not an actual scheduled job.

- The server's actual background work does **not** use the cron scheduler at all. `server/server.go:153-174` (`startBackgroundRunners`) starts only the S3 presign runner (`server/runner/s3presign/runner.go`), which is **interval-based, not cron/nightly** — it runs once at startup and then every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`). It is not a database-cleanup job and has no wall-clock "nightly" time.

So there is no nightly database-cleanup cron job to assign a run time to; the closest match is a "2 AM daily" value that appears only in an example comment.
