**Determination method:**

The store layer is driver-agnostic. `(*store.Store).CreateMemo` (`store/memo.go:109`) just delegates: `return s.driver.CreateMemo(ctx, create)` (`store/memo.go:113`). So `s.driver` — the concrete `store.Driver` implementation — decides which of the three candidate `CreateMemo` methods runs (`store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`).

That driver is selected in `NewDBDriver` (`store/db/db.go:14`) by a `switch profile.Driver` (line 18): `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`.

`profile.Driver` defaults to `"sqlite"` when no database flags are passed, set in two places in `cmd/memos/main.go`:
- `viper.SetDefault("driver", "sqlite")` (line 122)
- the flag definition `rootCmd.PersistentFlags().String("driver", "sqlite", "database driver")` (line 130)

With no `--driver`/env override, `profile.Driver == "sqlite"`, so the switch selects the sqlite driver and `(*sqlite.DB).CreateMemo` is the concrete code that runs the INSERT. (`internal/profile/profile.go:110` further confirms sqlite is the default path — it fills in a default DSN only for the sqlite driver.)
