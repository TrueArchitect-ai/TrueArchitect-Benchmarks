— Premise is wrong: there is no GraphQL schema and no GraphQL server (no `graphql`/`gqlgen` anywhere). The public API surface is Protobuf-defined gRPC/Connect + REST (`proto/`, served under `server/router/api/v1`), complemented by RSS feeds (`server/router/rss`) and an MCP adapter (`server/router/mcp`) that re-dispatches into the same v1 API.
