**Driver — `store/driver.go`** (defined at `store/driver.go:10`).

The `Driver` interface in package `store` declares all methods a database backend must implement ("It contains all methods that store database driver should implement"). The three backends — SQLite, MySQL, and Postgres — each implement it under `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres`, selected in `store/db/db.go`.
