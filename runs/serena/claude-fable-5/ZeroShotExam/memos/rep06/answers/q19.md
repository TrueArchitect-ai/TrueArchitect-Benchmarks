MemoService is exposed via:

1. **Connect RPC (ConnectRPC)** — registered in `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` inside `RegisterConnectHandlers`). The per-method Connect request/response wrapping for MemoService lives in `server/router/api/v1/connect_services.go` (section starting at line 304).

2. **REST/HTTP via gRPC-Gateway** — registered in `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)`), which mounts the JSON/HTTP gateway mux under `/api/v1/*` on the Echo server.

There is no native gRPC server registration for MemoService anywhere in the repo (`RegisterMemoServiceServer` is never called outside the generated code), so the two serving protocols are Connect and the gRPC-Gateway REST/HTTP API. Generated support code for each protocol is in `proto/gen/api/v1/apiv1connect/memo_service.connect.go` (Connect) and `proto/gen/api/v1/memo_service.pb.gw.go` (gateway).
