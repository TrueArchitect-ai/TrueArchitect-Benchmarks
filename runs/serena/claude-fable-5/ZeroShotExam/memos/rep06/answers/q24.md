- `web/src/connect.ts` — defines `memoServiceClient = createClient(MemoService, transport)` (line 197)

- `server/router/api/v1/memo_service.go` — `func (s *APIV1Service) CreateMemo(...)` handler (line 70), which calls the store
- `store/memo.go` — `func (s *Store) CreateMemo(...)` (line 109), which delegates to the configured driver
- `store/db/sqlite/memo.go` — `func (d *DB) CreateMemo(...)` (line 16) builds and executes the `INSERT INTO memo (...)` SQL
