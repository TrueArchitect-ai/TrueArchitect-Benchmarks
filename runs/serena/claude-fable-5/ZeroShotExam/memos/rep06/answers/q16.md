When `Store.DeleteMemo` runs (invoked by the API when a memo is deleted), the store layer cleans up these records before deleting the memo row itself (`store/memo.go:140-159`):

- **Memo relation records** — deleted twice via `driver.DeleteMemoRelation`: once where the memo is the source (`MemoID`) and once where it is the target (`RelatedMemoID`) of the relation (`store/memo.go:142-147`, types in `store/memo_relation.go`).
- **Attachment records** — it lists attachments linked to the memo with `ListAttachments` and deletes each via `DeleteAttachment` (`store/memo.go:149-157`).

Only after that does it call `driver.DeleteMemo`, which deletes just the memo row (e.g. `store/db/sqlite/memo.go:237`).
