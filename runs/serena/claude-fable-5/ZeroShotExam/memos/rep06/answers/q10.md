`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) SQLite database, the migrator applies this single file containing the full current schema instead of running the incremental version-numbered migrations (`store/migration/sqlite/0.2/` … `0.30/`). This is documented in `store/migrator.go` (lines 27 and 42: "LATEST.sql: Full schema for new installations (faster than incremental migrations)") and verified by `store/test/migrator_test.go` (`TestFreshInstall`).
