The `Driver` interface is defined in `store/driver.go`, and its three implementations live under `store/db/`, each with an entry file that defines the driver struct and its `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite implementation
- `store/db/mysql/mysql.go` — MySQL implementation
- `store/db/postgres/postgres.go` — PostgreSQL implementation

**NewDBDriver — `store/db/db.go`** is the factory that selects between them at startup: it switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and calls the matching package's `NewDB`, returning an error for any unknown driver (`store/db/db.go:14-32`).
