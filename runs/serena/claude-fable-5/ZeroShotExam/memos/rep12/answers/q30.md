The memo webhook dispatchers all live in `/bench/repo/server/router/api/v1/memo_service_webhooks.go`:

- memo created (`memos.memo.created`): `DispatchMemoCreatedWebhook`
- memo updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook`
- memo deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook`
- memo comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook`

The created/updated/deleted functions are thin wrappers around the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), while the comment dispatcher loops over the related memo owner's webhooks itself. All four converge on the same delivery path: `webhook.PostAsync` in `/bench/repo/internal/webhook/webhook.go` (line 184), which enqueues the payload on a bounded async queue whose worker performs the actual HTTP delivery via `webhook.Post` (line 120).
