The memo CRUD mutations/queries live in `web/src/hooks/useMemoQueries.ts`. That module defines TanStack Query hooks — `useQuery` hooks for listing/getting memos (`memoServiceClient.listMemos`, `getMemo`, `getLinkMetadata`) and `useMutation` hooks for `createMemo`, `updateMemo` (and delete) with cache invalidation/optimistic patching.

It uses the generated **`memoServiceClient`**, imported from `web/src/connect.ts`, where it is created via `createClient(MemoService, transport)` (Connect-RPC client for the `MemoService` defined in `web/src/types/proto/api/v1/memo_service_pb.ts`).
