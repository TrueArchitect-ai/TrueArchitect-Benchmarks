When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go:157` calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)`. That method (defined in `server/router/api/v1/memo_service_webhooks.go:15`) delegates to `dispatchMemoRelatedWebhook` with activity type `memos.memo.created`, which looks up the creator's webhooks via `s.Store.GetUserWebhooks` and fires each one asynchronously with `webhook.PostAsync(payload)`.

The HTTP delivery is performed by the `internal/webhook` package (`github.com/usememos/memos/internal/webhook`, in `/bench/repo/internal/webhook/webhook.go`): `PostAsync` → `Post`, which JSON-marshals the payload and POSTs it with an SSRF-safe HTTP client.

Requests are signed per the **Standard Webhooks** scheme: an HMAC-SHA256 over `msgID + "." + timestamp + "." + body` using the webhook's signing secret (`whsec_`-prefixed base64 keys are decoded via `resolveSigningKey`), sent as the headers `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 HMAC>` (`internal/webhook/webhook.go:133-150`).
