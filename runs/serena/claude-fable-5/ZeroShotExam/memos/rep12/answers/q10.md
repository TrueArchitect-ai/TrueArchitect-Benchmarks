`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from a single `LATEST.sql` file instead of running incremental migrations — the SQLite version lives at `store/migration/sqlite/LATEST.sql`. This is documented in `store/migrator.go` (comments at lines 27 and 42, and the `LatestSchemaFileName = "LATEST.sql"` constant at line 56: "LATEST.sql: Full schema for new installations (faster than incremental migrations)").
