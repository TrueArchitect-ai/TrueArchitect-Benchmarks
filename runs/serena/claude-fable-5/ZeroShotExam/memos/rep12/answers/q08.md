**Driver — store/driver.go**

The `Driver` interface is defined at `/bench/repo/store/driver.go:10` and declares all the methods a database backend must implement (attachment, memo, user CRUD, etc.). The three backends — SQLite, MySQL, and PostgreSQL — each implement it in `/bench/repo/store/db/sqlite`, `/bench/repo/store/db/mysql`, and `/bench/repo/store/db/postgres`, selected via `/bench/repo/store/db/db.go`.
