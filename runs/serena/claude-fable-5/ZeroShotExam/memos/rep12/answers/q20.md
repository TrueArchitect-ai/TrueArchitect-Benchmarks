**Mechanism:** Server-Sent Events (SSE). The server exposes a `GET /api/v1/sse` endpoint that streams `text/event-stream` with 30-second heartbeats (`server/router/api/v1/sse_handler.go`), and the web client consumes it with an `Accept: text/event-stream` fetch in `web/src/hooks/useLiveMemoRefresh.ts`.

**Hub:** `SSEHub` is implemented in `server/router/api/v1/sse_hub.go` (clients subscribe/unsubscribe per user in `sse_handler.go`; events are fanned out via `SSEHub.Broadcast`).

**Memo handlers that broadcast through it:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:163`
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
- `UpdateMemo` — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:71`, called at `memo_service.go:513`)
- `SetMemoRelations` — via the same helper (`server/router/api/v1/memo_relation_service.go:48`)
- `SetMemoAttachments` — via the same helper (`server/router/api/v1/memo_attachment_service.go:48`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126`
- (Additionally, reaction handlers `UpsertMemoReaction`/`DeleteMemoReaction` broadcast memo-reaction events from `server/router/api/v1/reaction_service.go:106,161`.)
