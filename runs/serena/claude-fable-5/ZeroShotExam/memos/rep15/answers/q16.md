When the API deletes a memo, the store layer's `Store.DeleteMemo` (`store/memo.go:140-159`) removes these records before deleting the memo row itself:

- **Memo relation records** (`memo_relation`) — deleted twice: once where the memo is the source (`MemoID`) and once where it is the target (`RelatedMemoID`) of the relation (`store/memo.go:142-147`).
- **Attachment records** linked to the memo — listed via `ListAttachments` and deleted one by one with `DeleteAttachment` (`store/memo.go:149-157`).

Only after those cleanups does it call `s.driver.DeleteMemo` to delete the memo row (e.g. `store/db/sqlite/memo.go:237`).
