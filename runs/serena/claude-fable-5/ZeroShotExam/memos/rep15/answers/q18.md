The database driver interface is `store.Driver` (defined in `store/driver.go`), and it has three implementations, each with an entry file that defines its `DB` type and `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite implementation
- `store/db/mysql/mysql.go` — MySQL implementation
- `store/db/postgres/postgres.go` — PostgreSQL implementation

The factory that selects between them at startup is:

**NewDBDriver** — `store/db/db.go` (lines 14–32). It switches on `profile.Driver` ("sqlite" / "mysql" / "postgres") and calls the corresponding package's `NewDB`, returning an error for any unknown driver.
