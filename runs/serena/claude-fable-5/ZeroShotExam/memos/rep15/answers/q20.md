**Mechanism:** Server-Sent Events (SSE). The server streams `text/event-stream` change events (`memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`) to browsers, consumed on the frontend by `web/src/hooks/useLiveMemoRefresh.ts`.

**Hub:** `server/router/api/v1/sse_hub.go` — the `SSEHub` type manages `SSEClient` connections and fans out events via `Broadcast` (the HTTP endpoint side lives in `server/router/api/v1/sse_handler.go`).

**Memo handlers that broadcast through it** (each calls `s.SSEHub.Broadcast(...)` directly or via the `dispatchMemoUpdatedSideEffects` helper in `server/router/api/v1/memo_update_helpers.go:71`):

- `CreateMemo` — `server/router/api/v1/memo_service.go:163`
- `UpdateMemo` — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_service.go:513`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126`
- `SetMemoRelations` — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_relation_service.go:48`)
- `SetMemoAttachments` — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_attachment_service.go:48`)
- `UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161` (reaction handlers, but they broadcast memo-scoped events)
