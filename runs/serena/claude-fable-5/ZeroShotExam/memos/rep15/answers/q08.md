**Driver — store/driver.go**

The `Driver` interface is defined in `store/driver.go:10`. Its doc comment says it "contains all methods that store database driver should implement" — CRUD methods for every model (memos, users, attachments, etc.) plus lifecycle methods like `GetDB()`, `Close()`, and `IsInitialized()`. Each database backend (SQLite, MySQL, PostgreSQL under `store/db/`) implements this interface.
