`APIV1Service.SignIn` — `server/router/api/v1/auth_service.go` (defined at line 51).

This is the method that implements the SignIn RPC of the AuthService: it validates the username/password (or handles the password-auth-disallowed case), then calls the shared `doSignIn` helper in `server/router/api/v1/auth_service_session.go` to create the session. Note there is also a thin Connect-RPC adapter, `ConnectServiceHandler.SignIn` in `server/router/api/v1/connect_services.go:78`, but it just unwraps the Connect request and delegates to `APIV1Service.SignIn`, which holds the actual logic.
