**Runner started by the server** (in `startBackgroundRunners`, `server/server.go`):

- `s3presign` runner (`server/runner/s3presign/runner.go`) — triggered once immediately at startup via `RunOnce(ctx)`, then run continuously in a goroutine whose scheduling is a plain `time.Ticker` firing every 12 hours (`runnerInterval = time.Hour * 12`), stopping on context cancellation.

That is the only background runner the server starts.

**Present but NOT started by the server:**

- `memopayload` runner (`server/runner/memopayload/runner.go`) — its `Runner`/`NewRunner`/`RunOnce` are never instantiated or scheduled anywhere. Only its package-level helper `memopayload.RebuildMemoPayload` is called synchronously from API handlers in `server/router/api/v1/memo_service.go` (memo create/update), not as a background job.
- `internal/scheduler` package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, etc.) — a full cron-style scheduling library with tests, but nothing outside the package imports it. The server's only scheduling mechanism is the raw `time.Ticker` in the s3presign runner; this scheduler infrastructure is entirely unused by the server.
