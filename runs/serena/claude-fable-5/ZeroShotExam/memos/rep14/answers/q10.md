**`store/migration/sqlite/LATEST.sql`**

For a fresh (uninitialized) database, the migrator applies the full current schema from a single file rather than replaying incremental migrations. This is documented and implemented in `store/migrator.go`: the constant `LatestSchemaFileName = "LATEST.sql"` (line 56), and `preMigrate` (around lines 210–229) reads `migration/<driver>/LATEST.sql` from the embedded FS when the DB is not yet initialized — for SQLite that resolves to `store/migration/sqlite/LATEST.sql`. The versioned directories (`0.2` … `0.30`) hold only incremental migrations for existing installs.
