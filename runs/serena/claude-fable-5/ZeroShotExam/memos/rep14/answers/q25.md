**Engine + path:** CEL (Common Expression Language, via `github.com/google/cel-go` — see `go.mod:13`), implemented in the in-repo package `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `schema.go`, `render.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:211-215`) validates the filter and passes it into `MemoFind.Filters`; the `filter.Engine` compiles the string in a CEL environment built from a field schema (`internal/filter/schema.go`'s `NewSchema`), converts the CEL AST into a dialect-agnostic condition tree/IR (`internal/filter/engine.go`, `parser.go`, `ir.go`), and a renderer then walks that tree to emit parameterized SQL with per-dialect branches for `DialectSQLite`, `DialectMySQL`, and `DialectPostgres` (`internal/filter/render.go`) — each store driver invokes this with its own dialect, e.g. `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` in `store/db/sqlite/memo.go:57-61`, with equivalents in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`.
