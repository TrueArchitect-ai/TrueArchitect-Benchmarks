MemoService is exposed via two protocols:

1. **Connect RPC** — `server/router/api/v1/connect_handler.go`: `RegisterConnectHandlers` mounts `apiv1connect.NewMemoServiceHandler(s, ...)` on an `http.ServeMux` (line 40), with the wrapping done by the `ConnectServiceHandler` struct in the same file (which embeds `*APIV1Service`; the Connect-shaped method adapters live in `server/router/api/v1/connect_services.go`, "MemoService" section around line 304).

2. **REST/HTTP JSON via gRPC-Gateway** — `server/router/api/v1/v1.go`: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (line 108) registers the service on a `runtime.NewServeMux` gateway mux, which is then mounted on Echo at `/api/v1/*`.

Note there is no native gRPC server registration (`RegisterMemoServiceServer` / `grpc.NewServer` appear nowhere outside generated code in `proto/gen/`), so Connect and gRPC-Gateway REST are the two serving paths.
