q18.

The three database driver implementations (each implementing the `store.Driver` interface defined in `store/driver.go`), with their entry files:

1. SQLite — `store/db/sqlite/sqlite.go`
2. MySQL — `store/db/mysql/mysql.go`
3. PostgreSQL — `store/db/postgres/postgres.go`

Each package's entry file defines a `DB` struct and a `NewDB(profile)` constructor; the remaining interface methods live in sibling files of the same package.

Factory: **NewDBDriver** — `store/db/db.go`. It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`, from the `--driver` flag via viper) and returns the matching implementation. It's called at startup from `cmd/memos/main.go` (around line 57), which then passes the driver into `store.New`.
