**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` and contains all methods a database backend must implement (attachment, memo, user CRUD, etc.). All three backends implement it: SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql/mysql.go`), and PostgreSQL (`store/db/postgres/postgres.go`), selected via the factory in `store/db/db.go`.
