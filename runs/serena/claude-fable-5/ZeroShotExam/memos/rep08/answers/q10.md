**`store/migration/sqlite/LATEST.sql`**

For a fresh (uninitialized) database, the migrator applies the full current schema from a single file rather than running incremental migrations. This is documented in `store/migrator.go`, which states "preMigrate: Check if DB is initialized. If not, apply LATEST.sql" and "LATEST.sql: Full schema for new installations (faster than incremental migrations)", with the constant `LatestSchemaFileName = "LATEST.sql"` (store/migrator.go:27,42,56). The SQLite version of that file lives at `store/migration/sqlite/LATEST.sql`, alongside the versioned incremental migration directories (`0.2` … `0.30`) used only for upgrades of existing installs.
