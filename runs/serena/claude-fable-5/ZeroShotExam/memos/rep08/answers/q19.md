MemoService is exposed over (1) REST/HTTP-JSON via the gRPC-Gateway and (2) Connect RPC (the Connect protocol for browser clients, which replaced grpc-web). There is no standalone `grpc.NewServer` registration — those are the two serving paths.

- **REST / gRPC-Gateway** — `server/router/api/v1/v1.go` (`v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` at `server/router/api/v1/v1.go:108`, mounted under `/api/v1/*`)
- **Connect RPC** — `server/router/api/v1/connect_handler.go` (`wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` at `server/router/api/v1/connect_handler.go:40`, using generated handlers from `proto/gen/api/v1/apiv1connect/memo_service.connect.go`)

Both wrap the same `APIV1Service` implementation defined in `server/router/api/v1/v1.go`.
