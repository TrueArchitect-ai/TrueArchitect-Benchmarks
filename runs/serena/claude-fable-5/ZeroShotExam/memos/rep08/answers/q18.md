The `store.Driver` interface (defined in `store/driver.go`) has three implementations, one per supported database, each with an entry file defining a `NewDB` constructor that returns `store.Driver`:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

The factory that selects between them at startup is **`NewDBDriver`** — `store/db/db.go`. It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and is called from `cmd/memos/main.go:57` during server startup.
