The compiled React frontend (the Vite build output copied into `server/router/frontend/dist/`) is **embedded into the Go binary with Go's `embed` package (`//go:embed dist/*` into an `embed.FS`) and served by the Echo web server's static middleware, with an SPA fallback to `index.html`**. This is wired in `server/router/frontend/frontend.go`:

- Line 20–21: `//go:embed dist/*` populates `embeddedFiles embed.FS`.
- `Serve()` (line 41) mounts `middleware.StaticWithConfig` over that filesystem (via `fs.Sub` on `dist`) and adds `spaFallbackMiddleware` that serves `index.html` for unmatched non-API routes, skipping `/api`, `/file`, and gRPC-gateway paths.

The `FrontendService` is hooked into the server in `server/server.go` (`frontend.NewFrontendService(...).Serve(ctx, e)`).

Answer: Go `embed.FS` (`//go:embed dist/*`) served via Echo static middleware + SPA fallback; `server/router/frontend/frontend.go`
