MemoService is exposed via **Connect RPC** and via **HTTP/REST through gRPC-Gateway**:

1. **Connect RPC** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` mounts the generated Connect handler on the mux), with the per-method wrapping implemented in `server/router/api/v1/connect_services.go` (the `// MemoService` section starting around line 304, delegating to `APIV1Service`).

2. **REST (gRPC-Gateway HTTP/JSON)** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` registers it on the gateway `runtime.ServeMux`, which is then served under `/api/v1/*` via Echo).

The generated code backing each lives in `proto/gen/api/v1/apiv1connect/memo_service.connect.go` (Connect) and `proto/gen/api/v1/memo_service.pb.gw.go` (gateway).
