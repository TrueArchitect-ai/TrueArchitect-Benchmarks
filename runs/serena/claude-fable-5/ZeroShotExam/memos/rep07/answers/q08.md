**Driver — store/driver.go**

The `Driver` interface is defined in `/bench/repo/store/driver.go` (line 10). Its doc comment states it "contains all methods that store database driver should implement" — every database backend (e.g. SQLite, MySQL, PostgreSQL under `store/db/`) implements this interface, which covers connection management (`GetDB`, `Close`), initialization checks, and CRUD methods for all models (memos, users, attachments, reactions, etc.).
