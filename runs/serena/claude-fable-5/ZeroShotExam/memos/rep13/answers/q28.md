**s3presign runner** (`server/runner/s3presign/runner.go`) — the only background runner the server starts, in `startBackgroundRunners` at `server/server.go:153-174`. Trigger: an immediate `RunOnce(ctx)` at startup, then a goroutine running `Run(ctx)` which loops on a `time.NewTicker` with `runnerInterval = 12 * time.Hour` (`server/runner/s3presign/runner.go:27-40`), cancelled via a per-runner context on shutdown.

Unused scheduling infrastructure:

- **`internal/scheduler`** — a complete GitHub-Actions-style cron scheduler package (cron expression parser, jobs, middleware; see `internal/scheduler/doc.go`, `scheduler.go`, `parser.go`) is present but never imported by any non-test code outside its own package. The server does not use it; the s3presign runner uses a plain `time.Ticker` instead.
- **`server/runner/memopayload`** — a second "runner" package exists (`server/runner/memopayload/runner.go` with `NewRunner`/`RunOnce`) but is never instantiated or started by the server.
