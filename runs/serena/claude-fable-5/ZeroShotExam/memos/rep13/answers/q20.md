**Mechanism:** Server-Sent Events (SSE). The HTTP handler at `server/router/api/v1/sse_handler.go` sets `Content-Type: text/event-stream` and streams events to connected browsers.

**Hub:** `server/router/api/v1/sse_hub.go` — `SSEHub` manages client connections and its `Broadcast` method fans events out to all clients (with a small per-client buffer so a slow client doesn't block broadcasting).

**Memo handlers that broadcast through it:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (skipped when suppressed via the `suppressSSE` context key)
- `UpdateMemo` — via `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go:71`, called at `memo_service.go:513`
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (broadcasts a `memo.comment.created` event for the parent memo)
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` (through the same `dispatchMemoUpdatedSideEffects` helper)
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` (same helper)

Additionally, the reaction handlers `UpsertMemoReaction` and `DeleteMemoReaction` in `server/router/api/v1/reaction_service.go:106,161` broadcast memo-scoped SSE events (`reaction.upserted` / `reaction.deleted`), since reactions belong to memos.
