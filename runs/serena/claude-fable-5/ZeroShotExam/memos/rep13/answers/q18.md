The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with an entry file exposing a `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

Factory: **NewDBDriver** — `store/db/db.go` (line 14). It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) at startup and returns the matching driver, erroring on any unknown value.
