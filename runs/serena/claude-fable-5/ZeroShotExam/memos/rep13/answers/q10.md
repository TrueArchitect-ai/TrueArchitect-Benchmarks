`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) SQLite database, the migrator applies this single file containing the full current schema instead of running the incremental migrations. This is documented in `store/migrator.go` (lines 27 and 42: "LATEST.sql: Full schema for new installations") and verified by `TestFreshInstall` in `store/test/migrator_test.go`.
