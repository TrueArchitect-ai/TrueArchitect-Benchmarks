**`Driver` — `store/driver.go`**

All database backends implement the `Driver` interface, defined in `store/driver.go:10`. Its doc comment says it "contains all methods that store database driver should implement" — covering DB access, initialization, and CRUD methods for all models (memos, users, attachments, reactions, etc.). The three backends that implement it live in `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres` (instantiated via `store/db/db.go`).
