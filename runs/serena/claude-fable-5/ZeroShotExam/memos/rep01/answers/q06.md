**`memo_relation`**

This table links one memo to another via `memo_id` and `related_memo_id` columns (plus a `type` column). It's defined in the schema migrations, e.g. `store/migration/sqlite/LATEST.sql` (also in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, originally added in `store/migration/sqlite/0.13/00__memo_relation.sql`), with store-layer access code in `store/memo_relation.go` and driver implementations like `store/db/sqlite/memo_relation.go`.
