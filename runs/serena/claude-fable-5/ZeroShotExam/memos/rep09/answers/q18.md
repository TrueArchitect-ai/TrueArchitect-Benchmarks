The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with an entry file that defines its `NewDB` constructor:

- SQLite — `store/db/sqlite/sqlite.go`
- MySQL — `store/db/mysql/mysql.go`
- PostgreSQL — `store/db/postgres/postgres.go`

The factory that selects between them at startup is **`NewDBDriver`** — `store/db/db.go`. It switches on `profile.Driver` ("sqlite" / "mysql" / "postgres") and returns the corresponding driver, erroring on anything else.
