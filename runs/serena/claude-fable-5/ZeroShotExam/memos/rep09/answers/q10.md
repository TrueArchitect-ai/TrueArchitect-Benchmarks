`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` in the driver-specific migration directory instead of running incremental migrations — see the comments in `store/migrator.go:27` and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"), with `LatestSchemaFileName = "LATEST.sql"` defined at `store/migrator.go:56`. For SQLite that file is `store/migration/sqlite/LATEST.sql`, and `store/test/migrator_test.go:18` confirms it applies correctly on a fresh database.
