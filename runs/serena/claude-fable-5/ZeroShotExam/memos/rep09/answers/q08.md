**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` in the `store` package, documented as containing "all methods that store database driver should implement" (e.g. `GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`). All three database backends — SQLite, MySQL, and PostgreSQL under `store/db/` — implement it; `store/db/db.go:14` (`NewDBDriver`) selects and returns the appropriate `store.Driver` implementation based on the configured database type.
