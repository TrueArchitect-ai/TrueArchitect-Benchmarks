MemoService is exposed over two protocols:

1. **Connect RPC** — `server/router/api/v1/connect_handler.go`, where `RegisterConnectHandlers` calls `apiv1connect.NewMemoServiceHandler(s, opts...)` (line 40) and mounts it on an `http.ServeMux`. (The generated Connect wrapper itself lives in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.)

2. **REST/HTTP JSON via grpc-gateway** — `server/router/api/v1/v1.go`, where `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (line 108) registers the service on the gateway's `runtime.NewServeMux`. (Generated gateway code: `proto/gen/api/v1/memo_service.pb.gw.go`.)

There is no plain gRPC server registration (`RegisterMemoServiceServer` is never called in server code) — only these two.
