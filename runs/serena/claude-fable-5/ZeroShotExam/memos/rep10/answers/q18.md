The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with an entry file that defines its `DB` struct and `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

**NewDBDriver — `store/db/db.go`** is the factory that selects between them at startup, switching on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and returning the matching `store.Driver` (store/db/db.go:14).
