**`store/migration/sqlite/LATEST.sql`**

For a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` instead of running incremental migrations — see `store/migrator.go:27` ("Check if DB is initialized. If not, apply LATEST.sql") and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"). The SQLite variant lives at `store/migration/sqlite/LATEST.sql`, alongside the versioned migration directories (`0.2` … `0.30`). This behavior is also verified by `TestFreshInstall` in `store/test/migrator_test.go:18`.
