The derived metadata is the memo's stored payload — `Payload.Tags` plus `Payload.Property` (`MemoPayload_Property` in `proto/gen/store/memo.pb.go`).

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual extraction to the markdown service's single-pass AST walk in `ExtractAll` at `internal/markdown/markdown.go:356`. The result is copied onto the memo at `runner.go:85-86` (`memo.Payload.Tags = data.Tags; memo.Payload.Property = data.Property`).

**Triggers:**
- **CreateMemo** — `server/router/api/v1/memo_service.go:108` rebuilds the payload before the memo is inserted (this path also covers comment creation, which goes through memo creation).
- **UpdateMemo with `content` in the update mask** — `server/router/api/v1/memo_service.go:447` rebuilds the payload whenever the content field is updated, storing the new payload alongside the new content.
- **Bulk rebuild** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` re-derives the payload for all memos in batches of 100 (a maintenance/migration path; note it isn't currently wired into `server/server.go`, which only invokes the `s3presign` runner).

**Extracted properties** (from the goldmark AST walk in `ExtractAll`):
- `Tags` — all hashtag nodes, deduplicated case-preservingly (`markdown.go:377`, `418`)
- `Property.Title` — text of the first block-level H1 heading of the document (`markdown.go:383-389`)
- `Property.HasLink` — presence of any link node (`markdown.go:393-394`)
- `Property.HasCode` — presence of code blocks, fenced code blocks, or code spans (`markdown.go:396-397`)
- `Property.HasTaskList` and `Property.HasIncompleteTasks` — presence of task checkboxes, and whether any is unchecked (`markdown.go:399-405`)
- (`Mentions` are also extracted in the same pass but aren't stored on the payload by `RebuildMemoPayload`.)

This metadata backs list/preview features — e.g. `memo_service_converter.go:48-49` surfaces `Tags` and `Property` on the API memo, while the content `Snippet` is computed separately at read time (`memo_service_converter.go:76-80`), not stored.
