The outbound HTTP path is Memos' webhook system, and I've traced it end to end.

h06.

**Outbound HTTP mechanism.** User-configured webhook URLs (stored per user, `hook.Url`) are POSTed to by `webhook.Post` in `internal/webhook/webhook.go:120`, which issues the actual request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. Handlers never call `Post` directly — they call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; four worker goroutines (started in `init`, line 42) drain that queue and each calls `Post`.

**Convergence function.** Every dispatch path funnels through a single delivery function: `webhook.Post` — `internal/webhook/webhook.go:120` (the `PostAsync` enqueue funnel at line 184 is the API-layer chokepoint; both worker goroutines and any direct caller reach delivery only through `Post`).
