**Answer: `internal/idp` (abstraction); `internal/idp/oauth2` (implementation)**

This is the memos repository (`github.com/usememos/memos`). Third-party sign-in works like this:

- **Abstraction:** the `idp` package at `/bench/repo/internal/idp/idp.go` defines the provider-agnostic shape — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider must yield.
- **Implementation:** the only concrete protocol shipped is OAuth 2.0, in `/bench/repo/internal/idp/oauth2/oauth2.go` (package comment: "Package oauth2 implements the OAuth2 identity provider integration"). Its `IdentityProvider` wraps a `storepb.OAuth2Config` and uses `golang.org/x/oauth2` to exchange tokens and fetch user info, which the SSO flow consumes in `/bench/repo/server/router/api/v1/auth_service_sso.go`.

`internal/idp` contains no other protocol subpackages, so OAuth2 is the sole concrete implementation.
