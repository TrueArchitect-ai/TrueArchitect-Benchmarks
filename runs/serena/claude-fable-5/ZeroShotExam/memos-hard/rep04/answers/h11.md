**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

The data layer is the `store` package (plus its `store/db/*` drivers), which defines the persistent entities in files like `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/idp.go`, etc.

Counting distinct Go packages outside the `store/` tree that reference each entity struct:

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

The rest trail behind: `Attachment` (4), `Inbox`/`MemoRelation`/`MemoShare` (3 each), `Reaction`/`UserIdentity` (2), and `IdentityProvider`/`InstanceSetting`/`UserSetting` (1 each). The ordering holds even if you fold the `api/v1/test` package into `api/v1` (User 6 vs. Memo 5).
