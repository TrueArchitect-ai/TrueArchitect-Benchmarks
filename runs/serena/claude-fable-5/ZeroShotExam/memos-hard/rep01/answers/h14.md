Each memo's `Payload` (tags plus a `Property` message used for list/preview features) is derived from the memo's markdown content, not set by the user.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It calls the markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`), which parses the content once with goldmark and walks the AST in a single pass, then stores the result into `memo.Payload.Tags` and `memo.Payload.Property` (the `MemoPayload_Property` proto in `proto/gen/store/memo.pb.go`).

**Triggers:**
- Memo creation — `CreateMemo` calls `memopayload.RebuildMemoPayload` before persisting (`server/router/api/v1/memo_service.go:108`).
- Memo update, only when the update mask includes the `content` path — `UpdateMemo` rebuilds the payload after replacing the content (`server/router/api/v1/memo_service.go:447`).
- A batch maintenance runner, `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`), which rebuilds payloads for all memos in batches of 100. Note this runner is defined but not currently wired into server startup — `server/server.go` only invokes the `s3presign` runner (`server/server.go:163`).

**Extracted properties** (from the single AST walk in `ExtractAll`):
- `Tags` — all `#tag` nodes, deduplicated case-preservingly (tags inside links are skipped).
- `Property.Title` — the text of the document's first block-level child if it is an H1 heading.
- `Property.HasLink` — true if any link node exists.
- `Property.HasCode` — true for code blocks, fenced code blocks, or inline code spans.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the payload; `Payload.Location` is set separately from user input, not derived.)
