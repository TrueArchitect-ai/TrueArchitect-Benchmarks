**Premise correction:** This repository has no GraphQL API. A search for "graphql" across the codebase returns zero matches — there is no schema file, no GraphQL server, and no GraphQL dependencies.

**Actual API surface:** The public API is defined with Protocol Buffers and served over gRPC/Connect (with a REST/HTTP mapping), not GraphQL:

- **Schema definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus internal storage messages under `proto/store/`. Code is generated with `buf` (`proto/buf.gen.yaml`, per `proto/README.md`).
- **Generated artifacts:** `proto/gen/`, including an OpenAPI spec (`proto/gen/openapi.yaml`) that is embedded into the binary via `proto/openapi_embed.go`.
- **Server implementation:** ConnectRPC handlers under `server/router/api/v1/` (e.g. `server/router/api/v1/v1.go`, `connect_services.go`, `connect_interceptors.go`).

So the closest analog to "the GraphQL schema" here is the set of `.proto` files in `proto/api/v1/`, which are the source of truth for the public API contract.
