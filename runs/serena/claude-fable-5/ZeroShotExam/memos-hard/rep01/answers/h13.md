**Impl — construction — holders**

- **Impl:** The single concrete implementation is the unexported `service` struct in `internal/markdown/markdown.go:58`, which wraps a `goldmark.Markdown` instance. It implements the `markdown.Service` interface (`internal/markdown/markdown.go:31`), which covers extraction (`ExtractAll`, `ExtractTags`, `ExtractProperties`), rendering (`RenderMarkdown` via the custom renderer in `internal/markdown/renderer/markdown_renderer.go`, `RenderHTML` for RSS), snippets, validation, and tag renaming. No other implementation of this interface exists in the codebase.

- **Construction:** `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) is the only factory. At runtime it is called exactly once, in `NewAPIV1Service` at `server/router/api/v1/v1.go:48`, with `markdown.WithTagExtension()` and `markdown.WithMentionExtension()` enabled. That single instance is then shared: `server/server.go:85` passes `apiV1Service.MarkdownService` into `rss.NewRSSService`. (A separate construction in `server/router/api/v1/test/test_helper.go:44` is test-only.)

- **Holders of the interface:**
  - `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35` (used throughout memo handling, e.g. `server/router/api/v1/memo_service.go`, `memo_mention_helpers.go`, `memo_service_webhooks.go`)
  - `RSSService.MarkdownService` — `server/router/rss/rss.go:45` (uses `RenderHTML` for feeds)

(Frontend HTML rendering is separate: it uses `react-markdown`/remark in `web/src/components/MemoContent/MemoMarkdownRenderer.tsx`, not this interface.)
