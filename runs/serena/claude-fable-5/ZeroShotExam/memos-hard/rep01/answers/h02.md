delivery function — `Post` (with `PostAsync` enqueuing to a bounded worker queue) in `internal/webhook/webhook.go`; protection mechanism — dial-time SSRF blocking via `safeDialContext`/`isReservedIP` in `internal/webhook/webhook.go` and `internal/webhook/validate.go`

Details: outbound webhook delivery executes in `Post()` (`internal/webhook/webhook.go:120`), which sends the JSON payload through the shared `safeClient` HTTP client. That client's transport uses `safeDialContext` (`internal/webhook/webhook.go:59`), which resolves the target host at dial time and refuses any address in a reserved/private range — this also defeats DNS-rebinding tricks. The range check `isReservedIP` and the CIDR list (loopback, RFC-1918, link-local/IMDS 169.254.0.0/16, IPv6 equivalents) live in `internal/webhook/validate.go`, which also provides `ValidateURL` for an up-front check when a webhook URL is registered (scheme must be http/https, hostname must not resolve to a reserved IP). The `AllowPrivateIPs` flag in `validate.go` can disable the protection for self-hosted deployments.
