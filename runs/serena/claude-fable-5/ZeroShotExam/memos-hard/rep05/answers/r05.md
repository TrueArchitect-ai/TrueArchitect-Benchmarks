**Premise correction:** There is no GraphQL API in this repository — no GraphQL schema, resolvers, or dependencies exist anywhere in the codebase.

**Actual API surface:** The public API is defined as gRPC services using Protocol Buffers, with the schema files living in `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus shared types in `proto/api/v1/common.proto`). Protos are managed with Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).

From those definitions, the project generates:
- gRPC server/client stubs in `proto/gen/api/v1/*_grpc.pb.go`
- A RESTful HTTP/JSON facade via grpc-gateway (`proto/gen/api/v1/*.pb.gw.go`, using `github.com/grpc-ecosystem/grpc-gateway/v2` per `go.mod`), which is what external HTTP clients hit
- An OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)

There are also internal (non-public) storage-layer protos under `proto/store/`. So if you're looking for "the schema," the `.proto` files in `proto/api/v1/` are the source of truth, and the REST surface is described by the generated `proto/gen/openapi.yaml`.
