**RPC handlers that can transitively trigger an outbound HTTP request to a user-configured URL** (all in `server/router/api/v1/`, on `APIV1Service`):

Each `Dispatch*Webhook` method (`memo_service_webhooks.go`) loads the caller's webhooks via `Store.GetUserWebhooks`, copies the user-supplied `hook.Url` (set through `CreateUserWebhook`, `user_service_webhooks.go:94`) into the payload, and calls `webhook.PostAsync`.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. This is the single function where all paths meet before delivery: `PostAsync` (`webhook.go:184`) just enqueues onto `asyncPostQueue`, whose worker goroutines (`init`, `webhook.go:42-55`) call `Post`, which builds the request to `requestPayload.URL` and issues it via `safeClient.Do` (`webhook.go:152`). So: `webhook.Post` — `internal/webhook/webhook.go`.
