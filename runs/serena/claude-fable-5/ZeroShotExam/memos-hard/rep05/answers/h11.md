The data layer is the `store` package (`/bench/repo/store`), which defines the persistent entities: `User` (store/user.go), `Memo` (store/memo.go), `Attachment` (store/attachment.go), `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`.

Counting distinct Go packages outside the data layer (i.e., excluding `store`, `store/db/*`, `store/test`, and the generated `proto/gen/store`) that reference each `store.X` type:

**1st: `store.User` — ~7 packages** (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)

**2nd: `store.Memo` — ~6 packages** (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

The ranking holds even if test packages are excluded (User: 6, Memo: 5). The next closest are `Attachment` and `MemoShare`/`MemoRelation` at ~3–4 packages each.
