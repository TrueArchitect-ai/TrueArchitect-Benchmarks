**Premise correction:** There is no Redis in this repository. Nothing configures a Redis connection anywhere — no Redis client library, no connection string, no `redis` reference in the codebase.

**Actual mechanism:** The cache layer is a purely in-memory, in-process cache implemented in `store/cache/cache.go` (a `sync.Map`-based store with per-item expiration and a background cleanup goroutine). It is configured in `store/store.go:38-58`, where `New()` creates three caches (`instanceSettingCache`, `userCache`, `userSettingCache`) with a shared `cache.Config` of:

- `DefaultTTL: 10 * time.Minute`
- `CleanupInterval: 5 * time.Minute`
- `MaxItems: 1000`

User entries are written via `s.userCache.Set(...)` in `store/user.go` (e.g. lines 98, 122, 132, 143, 167), which uses the default TTL rather than a custom one — so **user cache entries live for 10 minutes**, with expired items swept every 5 minutes. (The same 10-minute default also appears in `cache.DefaultConfig()` in `store/cache/cache.go`.)
