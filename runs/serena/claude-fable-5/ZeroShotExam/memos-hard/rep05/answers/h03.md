The provider abstraction lives in `internal/idp` — the `idp` package defines the shared identity-provider types such as `IdentityProviderUserInfo` (`/bench/repo/internal/idp/idp.go`). The only concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2` (`/bench/repo/internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type wraps a `storepb.OAuth2Config` and handles the token exchange and user-info fetch.
