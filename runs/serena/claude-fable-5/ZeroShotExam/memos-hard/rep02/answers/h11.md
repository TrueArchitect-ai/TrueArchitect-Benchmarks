The data layer here is the `store` package (`/bench/repo/store/`), which defines the persistent entity structs: `User` (store/user.go), `Memo` (store/memo.go), `Attachment` (store/attachment.go), `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserIdentity`, `UserSetting`, `InstanceSetting`, `IdentityProvider`.

Counting distinct Go packages outside the data layer (excluding `store/`, its `store/db/*` drivers, and `store/test`) that reference each entity type (`store.<Type>`):

**1st: `store.User` — ~7 packages**; **2nd: `store.Memo` — ~6 packages**

- `User` is referenced from `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` (7).
- `Memo` is referenced from `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` (6).

For comparison, the next tier is `Attachment` at 4 packages (`api/v1`, its test package, `fileserver`, `rss`), then `Inbox`/`MemoRelation`/`MemoShare` at 3 each. The ranking holds whether or not you count test packages (excluding them: User 6, Memo 5).
