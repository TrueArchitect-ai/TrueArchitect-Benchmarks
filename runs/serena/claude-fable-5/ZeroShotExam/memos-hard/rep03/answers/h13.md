**impl** — The interface is `markdown.Service` (`internal/markdown/markdown.go:31`). The only concrete implementation is the unexported struct `service` (`internal/markdown/markdown.go:57-60`), which wraps a `goldmark.Markdown` instance configured with GFM plus the project's custom Tag and Mention extensions (`internal/markdown/extensions/`). That single implementation is what executes at runtime — there is no alternative impl in production code.

**construction** — `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) is the factory. At runtime it is called exactly once, by `NewAPIV1Service` in `server/router/api/v1/v1.go:48`, with `markdown.WithTagExtension()` and `markdown.WithMentionExtension()`. (`server/router/api/v1/test/test_helper.go:44` also calls it, but only for tests.) The server then shares that one instance: `server/server.go:85` passes `apiV1Service.MarkdownService` into `rss.NewRSSService`.

**holders** — Components holding a `markdown.Service` field:
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35` (used throughout memo handling, e.g. `memo_service.go`, webhooks, mention helpers)
- `RSSService.MarkdownService` — `server/router/rss/rss.go:45` (server-side HTML rendering for RSS feeds; receives the same instance from `server.go`)
- `memopayload.Runner.MarkdownService` — `server/runner/memopayload/runner.go:16`. Note: `memopayload.NewRunner` is defined but never invoked anywhere in the repo, so this holder is not instantiated at runtime; instead the package-level function `memopayload.RebuildMemoPayload` takes the interface as a parameter and is called from `server/router/api/v1/memo_service.go:108` and `:447` with the API service's instance.

So the runtime picture: one goldmark-backed `*markdown.service`, built once in `NewAPIV1Service`, held by `APIV1Service` and shared with `RSSService` (and passed by value into `memopayload.RebuildMemoPayload`). Note the interface deliberately covers metadata extraction plus limited rendering — routine HTML rendering for display is done on the frontend (react-markdown/remark in `web/src/components/MemoContent/`), while the backend `RenderHTML` serves RSS.
