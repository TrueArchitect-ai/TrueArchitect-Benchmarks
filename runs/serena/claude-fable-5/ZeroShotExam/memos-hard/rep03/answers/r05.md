**Premise correction:** This repository has no GraphQL API at all — there is no GraphQL schema, no `.graphql` files, and no GraphQL dependency anywhere in the codebase (verified with a repo-wide search).

**Actual API surface:** The public API is defined with Protocol Buffers and served over gRPC plus a REST/HTTP gateway:

- **Schema definitions:** `proto/api/v1/*.proto` — service definitions such as `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/shortcut_service.proto`, and `proto/api/v1/ai_service.proto`, managed with Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).
- **Generated code:** `proto/gen/api/v1/` contains the gRPC stubs (`*_grpc.pb.go`) and grpc-gateway REST bindings (`*.pb.gw.go`); `go.mod` pulls in `google.golang.org/grpc`, `github.com/grpc-ecosystem/grpc-gateway/v2`, and `connectrpc.com/connect`.
- **REST/OpenAPI description:** a generated OpenAPI spec lives at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`), which documents the HTTP-facing surface of those same services.
- **Server wiring:** the services are hosted from `server/server.go` and `server/router/`.

There are also internal storage-layer protos in `proto/store/`, but the public v1 API surface is the `proto/api/v1/` set.
