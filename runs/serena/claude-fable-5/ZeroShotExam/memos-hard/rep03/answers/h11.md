**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package, which defines the persistent entities (`store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/idp.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/user_setting.go`, `store/user_identity.go`, `store/instance_setting.go`).

Counting distinct packages outside `store/` that reference each type (`store.<Type>`):

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Trailing behind: `Attachment` (4), then `Inbox`/`MemoRelation`/`MemoShare` (3 each). The ranking holds even if you exclude the test package (User 6, Memo 5).
