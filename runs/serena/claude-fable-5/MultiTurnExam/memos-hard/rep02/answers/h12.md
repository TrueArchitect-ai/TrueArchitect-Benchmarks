There are three candidate implementations of `CreateMemo` (`store/db/sqlite/memo.go:16`, `store/db/mysql/memo.go:16`, `store/db/postgres/memo.go:16`), all satisfying the `store.Driver` interface; `Store.CreateMemo` (`store/memo.go:109`) calls through that interface, so the concrete target is decided at startup, not at the call site.
2. The concrete driver is chosen by the `switch profile.Driver` in the factory `NewDBDriver` (`store/db/db.go:17-25`): `"sqlite"` → `sqlite.NewDB`.
3. With no database flags, `profile.Driver` is `"sqlite"`: the entrypoint sets both `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the flag default `--driver "sqlite"` (`cmd/memos/main.go:130`), and the profile is built from `viper.GetString("driver")` (`cmd/memos/main.go:43`). `internal/profile/profile.go:110` further confirms sqlite-with-empty-DSN is the expected default path (it synthesizes the SQLite file DSN).
