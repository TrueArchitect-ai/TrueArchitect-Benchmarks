**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` (package `idp`) defines the provider abstraction — the `IdentityProviderUserInfo` struct that any provider must produce (identifier, display name, email, avatar URL).
- `internal/idp/oauth2/oauth2.go` (package `oauth2`) is the one concrete protocol implementation that ships: an OAuth 2.0 `IdentityProvider` built from a `storepb.OAuth2Config`, with `ExchangeToken` (authorization-code + PKCE exchange) and `UserInfo` (fetches and maps claims into `idp.IdentityProviderUserInfo`). It's consumed by the API layer in `server/router/api/v1/idp_service.go` and `server/router/api/v1/user_service_identities.go`.
