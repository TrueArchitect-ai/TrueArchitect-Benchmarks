**Premise correction: this project has no GraphQL API — no schema, resolvers, or GraphQL library exists anywhere in the repo** (a grep for "graphql" across Go, TypeScript, and config files returns nothing).

**Actual API surface:** the public API is **gRPC defined in Protocol Buffers**, served over multiple transports:

- **Schema definition:** `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated Go code in `proto/gen/`.
- **Transports:** the services are exposed as REST/JSON via gRPC-Gateway and as Connect-RPC, both registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`) and `server/router/api/v1/connect_services.go`, mounted on the Echo server in `server/server.go`.
- Additional non-RPC HTTP surfaces: the file server for attachments/avatars (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), an SSE event stream (`server/router/api/v1/sse_hub.go`), and the frontend/static router (`server/router/frontend/frontend.go`).
