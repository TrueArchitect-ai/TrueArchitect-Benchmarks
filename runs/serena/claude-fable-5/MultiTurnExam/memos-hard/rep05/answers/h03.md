**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider abstraction — the `idp` package with the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that any protocol implementation maps provider responses into.
- `internal/idp/oauth2/oauth2.go` is the one concrete protocol implementation that ships: an OAuth 2.0 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config`, with `ExchangeToken` (including PKCE support) and user-info fetching that maps claims via the configured field mapping into `idp.IdentityProviderUserInfo`. It's consumed by the SSO auth flow in `server/router/api/v1/auth_service_sso.go`.
