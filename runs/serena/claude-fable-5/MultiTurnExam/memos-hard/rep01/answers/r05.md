**Premise correction:** there is no GraphQL schema in this repository — no `.graphql`/`.gql` files, no GraphQL server library, and no references to GraphQL anywhere in `proto/`, `server/`, `internal/`, or the web frontend.

**Actual API surface:** the public API is gRPC-based, defined in Protocol Buffer files under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`), with generated code in `proto/gen/`. That single definition is exposed over three transports, all wired in `server/router/api/v1/v1.go`: (1) a grpc-gateway RESTful JSON mapping (`server/router/api/v1/v1.go:8,97`), (2) ConnectRPC handlers for browser clients, replacing grpc-web (`server/router/api/v1/v1.go:131-139`), and (3) native gRPC. Additional non-RPC surfaces are the RSS feeds (`server/router/rss/`), the file server (`server/router/fileserver/`), and an MCP endpoint (`server/router/mcp/`).
