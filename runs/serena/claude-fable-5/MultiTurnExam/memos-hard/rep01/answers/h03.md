**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation maps its user data into.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the one concrete protocol implementation that ships: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and used by the API layer in `server/router/api/v1/idp_service.go`.
