**Delivery function:** `Post` in `internal/webhook/webhook.go:120` — it marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 signature headers, and sends the HTTP POST. Asynchronous dispatch goes through `PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded channel drained by 4 worker goroutines that each call `Post`.

**Protection mechanism:** SSRF guarding via `safeDialContext` — path `internal/webhook/webhook.go:59`. All webhook requests go through a shared `safeClient` whose `http.Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37`). At dial time it resolves the hostname and rejects any IP falling in a reserved/private range, which also defeats DNS-rebinding tricks. The range list and check live in `internal/webhook/validate.go` — `reservedCIDRs` (`internal/webhook/validate.go:14`, covering loopback, RFC-1918, link-local/IMDS, and IPv6 equivalents) and `isReservedIP` (`internal/webhook/validate.go:44`). A complementary create/update-time check, `ValidateURL` (`internal/webhook/validate.go:62`), enforces http/https scheme and rejects URLs resolving to reserved IPs; an `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) can disable the protection for self-hosted deployments.
