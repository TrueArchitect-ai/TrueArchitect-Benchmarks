**Abstraction package:** `internal/idp` — the file `internal/idp/idp.go` defines the provider-neutral abstraction, the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any concrete provider must produce.

**Implementation package:** `internal/idp/oauth2` — the only concrete protocol implementation that ships, in `internal/idp/oauth2/oauth2.go`. Its `IdentityProvider` type wraps a `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and implements the OAuth2 flow, returning user info mapped into the `idp` package's struct. It's consumed by the auth/IdP endpoints in `server/router/api/v1/idp_service.go` and related handlers.
