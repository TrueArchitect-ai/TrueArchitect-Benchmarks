**Premise correction: there is no GraphQL API in this repository** — a search for "graphql" across the Go and TypeScript source finds nothing (the only hit is an incidental mention in `README.md` context, not code), and there is no schema file, resolver, or GraphQL dependency.

**Actual API surface:** the public API is defined with Protocol Buffers and served as gRPC/Connect with a REST mapping:

- **Schema definitions:** `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Generated code lives in `proto/gen/`.
- **REST/HTTP mapping:** each RPC carries `google.api.http` annotations (e.g., `GET /api/v1/memos` at `proto/api/v1/memo_service.proto:30`), exposed via grpc-gateway.
- **Serving:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64-140`) wires both the grpc-gateway HTTP handlers and ConnectRPC handlers (`connectrpc.com/connect`, with the Connect mux built via `NewConnectServiceHandler` in `server/router/api/v1/connect_handler.go`) into the Echo server.

Additional non-RPC HTTP surfaces are the file server (`server/router/fileserver/fileserver.go`) and RSS feeds (`server/router/rss/rss.go`) — still no GraphQL anywhere.
