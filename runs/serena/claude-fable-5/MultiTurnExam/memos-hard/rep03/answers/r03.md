The only recurring "cleanup" in the codebase is the in-memory cache's expired-entry sweep every 5 minutes (`store/store.go:42`, `store/cache/cache.go`), which is not a database job and has no clock-time schedule.

So there is no scheduled time to report — the premise doesn't match the codebase.
