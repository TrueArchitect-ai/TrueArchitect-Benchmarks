The call chain from the API is `APIV1Service.CreateMemo` → `Store.CreateMemo` (`store/memo.go:109`) → `s.driver.CreateMemo(ctx, create)` (`store/memo.go:113`), where `driver` is the `store.Driver` interface (`store/driver.go:29`). Three concrete implementations exist: `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go` — so the source alone doesn't pick one.
2. Which one is bound is decided by the factory `NewDBDriver` in `store/db/db.go:14-27`, which switches on `profile.Driver`: `"sqlite"` → `sqlite.NewDB(profile)`.
3. With no database flags, `profile.Driver` defaults to `"sqlite"`: `cmd/memos/main.go:122` (`viper.SetDefault("driver", "sqlite")`) and the flag default at `cmd/memos/main.go:130` (`rootCmd.PersistentFlags().String("driver", "sqlite", ...)`), which is read into the profile at `cmd/memos/main.go:43`. `internal/profile/profile.go:110` additionally fills in a default SQLite DSN when none is given.

Therefore, in a default installation the interface call at `store/memo.go:113` dispatches to the SQLite implementation, and the actual SQL INSERT runs in `store/db/sqlite/memo.go:41-46`.
