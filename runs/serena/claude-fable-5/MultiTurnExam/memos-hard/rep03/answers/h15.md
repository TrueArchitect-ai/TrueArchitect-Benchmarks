Distinct enforcement sites for memo visibility:

- **gRPC/Connect API — single-memo read check:** `APIV1Service.checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39` (non-public requires auth; `Private` only for the creator). Applied in `GetMemo` (`memo_service.go:356`), parent-memo access (`memo_service.go:367`), and `ListMemoComments` (`server/router/api/v1/memo_service_comments.go:148`).
- **gRPC/Connect API — list-query filtering:** `ListMemos` constrains the store query's `VisibilityList` based on the viewer (anonymous → `Public` only; other users → `Public`+`Protected`) — `server/router/api/v1/memo_service.go:219-225`.
- **gRPC/Connect API — user stats:** same `VisibilityList` narrowing when computing another user's memo stats — `server/router/api/v1/user_service_stats.go:84-90` and `:218-220`.
- **File server (attachment downloads):** `FileServerService.checkAttachmentPermission` looks up the owning memo and enforces its visibility before serving bytes — anonymous only for `Public` on instances allowing anonymous access, share-token fallback, and `Private` restricted to creator/admin — `server/router/fileserver/fileserver.go:660-705` (key checks at `:677` and `:699`).
- **RSS feeds:** feed queries are hard-limited to `VisibilityList: []store.Visibility{store.Public}` — `server/router/rss/rss.go:90` and `:141`.
- **SSE (server-sent events) delivery:** `SSEClient.canReceive` filters real-time memo events per subscriber — `Private` events delivered only to the creator or an admin — `server/router/api/v1/sse_hub.go:134-144` (visibility attached to events in `server/router/api/v1/sse_event_helpers.go:29-37`).
