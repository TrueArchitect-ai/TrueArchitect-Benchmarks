**Delivery function:** `Post` in `/bench/repo/internal/webhook/webhook.go` (webhook.go:120) — it marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 signature headers, and executes the HTTP POST via `safeClient.Do(req)` (webhook.go:152). Asynchronous dispatch goes through `PostAsync` (webhook.go:184), which enqueues onto a bounded channel drained by four worker goroutines that call `Post`.

**Protection mechanism:** SSRF guarding at dial time. The shared `safeClient` uses a custom transport whose `DialContext` is `safeDialContext` (webhook.go:59): it resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP`, defined in `/bench/repo/internal/webhook/validate.go` (validate.go:44) against the `reservedCIDRs` list (loopback, RFC-1918, link-local/IMDS, and IPv6 equivalents; validate.go:14-23). Because the check happens inside the dialer rather than only at URL-save time, it also defeats DNS-rebinding. There's an additional first line of defense at registration: `ValidateURL` (validate.go:62) rejects webhook URLs that resolve to reserved IPs, and an `AllowPrivateIPs` escape hatch (validate.go:41) exists for self-hosted deployments.
