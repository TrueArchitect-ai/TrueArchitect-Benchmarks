**Premise correction:** there is no nightly database-cleanup job, and no cron job is ever scheduled. Two facts:

1. The repo does contain a cron-capable scheduler package — `internal/scheduler/` (`scheduler.go`, `parser.go` with `ParseCronExpression`, etc.) — but **no production code uses it**: a repo-wide grep shows it is imported by nothing outside its own package and tests. No job, cleanup or otherwise, is registered with it.
2. The only recurring background work the server actually runs is the **S3 presign refresher**, which is not cron-based and not database cleanup: it's a plain 12-hour `time.Ticker` (`server/runner/s3presign/runner.go:27-41`) started from `startBackgroundRunners` in `server/server.go:162-171`. There's no scheduled time-of-day — it fires every 12 hours from server start.

Database cleanup, where it happens at all, is inline rather than scheduled: e.g., user deletion cascades handled explicitly in `store/db/*/user_delete.go`, and the in-memory cache's 5-minute cleanup sweep (`store/store.go:42`). So there is no "time it runs" to report — the premise (a nightly DB-cleanup cron job) doesn't match the codebase.
