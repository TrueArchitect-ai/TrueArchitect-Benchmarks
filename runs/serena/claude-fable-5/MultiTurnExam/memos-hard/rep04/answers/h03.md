- **Abstraction package:** `github.com/usememos/memos/internal/idp` — `/bench/repo/internal/idp/idp.go` defines the provider-agnostic `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that concrete providers map their user data into.
- **Implementation package:** `github.com/usememos/memos/internal/idp/oauth2` — `/bench/repo/internal/idp/oauth2/oauth2.go` ships the sole concrete protocol implementation, an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client id/secret, token URL, userinfo URL, field mapping). It's the only subdirectory under `internal/idp/`, so OAuth2 is the one protocol shipped; it's consumed by the auth flow in `server/router/api/v1/auth_service.go` and `idp_service.go`.
