**Engine:** CEL (Common Expression Language), parsed with `github.com/google/cel-go`, implemented in the in-repo filter engine at `internal/filter/` (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`).

**Mechanism:** The filter string is parsed as CEL and validated against a memo-specific schema (`internal/filter/schema.go`), normalized into a dialect-agnostic intermediate representation (`internal/filter/ir.go`, `internal/filter/parser.go`), and then rendered into a SQL fragment with placeholder arguments by `internal/filter/render.go`, which encapsulates per-dialect differences (placeholders `?` vs `$n`, JSON access via `JSON_EXTRACT`/`->>`/`JSON_CONTAINS`/`@>`, LIKE semantics) for SQLite, MySQL, and Postgres; each dialect driver invokes it via `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` when building the ListMemos query (e.g. `store/db/sqlite/memo.go:57-61`).
