Tables affected when a memo is deleted:

- **memo** — the memo row itself via `driver.DeleteMemo` (`store/memo.go:158`), and additionally any comment memos, which the API handler deletes first through recursive `Store.DeleteMemo` calls (`server/router/api/v1/memo_service.go:566-577`)
- **memo_relation** — explicit cascade code deletes rows where the memo is source or target (`store/memo.go:142-147`)
- **attachment** — explicit cascade code lists and deletes linked attachments (rows plus their stored files) (`store/memo.go:148-157`, `store/attachment.go:132-149`)
- **memo_share** — removed by the database itself via `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/sqlite/LATEST.sql:109`)

Notably, `reaction` rows are only listed for the deletion webhook payload, not deleted by this path (`server/router/api/v1/memo_service.go:545`).
