**Mechanism:** The compiled frontend (`web` build output copied to `server/router/frontend/dist/`) is embedded into the Go binary with `go:embed` and served via Echo's static middleware with SPA fallback to `index.html`.

**File:** server/router/frontend/frontend.go

Specifically, `//go:embed dist/*` (line 20) embeds the built assets into `embeddedFiles embed.FS`; `getFileSystem("dist")` (lines 42, 116) wraps it with `fs.Sub`, and it's mounted using `middleware.StaticWithConfig` (line 54) with an HTML5-style fallback so non-API, not-found paths serve the SPA's `index.html`. API and file routes are excluded via `shouldSkipFrontendStatic` (line 82).
