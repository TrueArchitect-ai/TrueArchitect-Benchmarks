The server starts exactly one background runner, in `startBackgroundRunners` (server/server.go:129, 153-174):

- **s3presign runner** (server/runner/s3presign/runner.go) — runs `RunOnce` immediately at startup (server/server.go:163), then a goroutine runs `Run`, driven by a `time.Ticker` firing every 12 hours (`runnerInterval = time.Hour * 12`, s3presign/runner.go:26-30), cancelled via a per-runner context on shutdown.

**Unused scheduling infrastructure:** the **memopayload runner** (server/runner/memopayload/runner.go) has a full `Runner` type with `NewRunner` and a batch-processing `RunOnce` that rebuilds all memo payloads, but the server never instantiates or schedules it — only its standalone helper `RebuildMemoPayload` is called inline from the API handlers (server/router/api/v1/memo_service.go:108, 447). No cron library is involved; the only scheduling mechanism actually used is the s3presign ticker.
