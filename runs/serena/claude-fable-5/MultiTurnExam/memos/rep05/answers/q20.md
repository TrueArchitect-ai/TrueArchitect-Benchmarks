**Mechanism:** Server-Sent Events (SSE). The hub is implemented in **`server/router/api/v1/sse_hub.go`** (with the HTTP endpoint in `server/router/api/v1/sse_handler.go`, registered via `RegisterSSERoutes` in `server/router/api/v1/v1.go`, and event builders in `server/router/api/v1/sse_event_helpers.go`). On the browser side it's consumed by `web/src/hooks/useLiveMemoRefresh.ts`.

**Memo handlers that broadcast through `SSEHub.Broadcast`:**

- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (memo-created event, suppressed when called from CreateMemoComment)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (memo-deleted event)
- `UpdateMemo` — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:71`), called at `memo_service.go:513`
- `SetMemoAttachments` — via the same helper, `server/router/api/v1/memo_attachment_service.go:48`
- `SetMemoRelations` — via the same helper, `server/router/api/v1/memo_relation_service.go:48`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126`
- `UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161` (reaction events tied to a memo)
