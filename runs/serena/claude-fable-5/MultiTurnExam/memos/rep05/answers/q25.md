**Engine: CEL (Common Expression Language), parsed with `cel-go` — `internal/filter/`** (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`; documented in `internal/filter/README.md`).

**Mechanism:** The filter string is parsed and validated by `cel-go` against a memo-specific schema (`internal/filter/schema.go`), lowered by `internal/filter/parser.go` into a dialect-agnostic intermediate representation (`internal/filter/ir.go`), and then rendered by `internal/filter/render.go` into a parameterized SQL fragment tailored to the target dialect (`DialectSQLite`/`DialectMySQL`/`DialectPostgres` — handling placeholder style `?` vs `$n`, JSON access via `json_extract` vs `->>`, LIKE semantics, etc.), which each dialect driver appends to its ListMemos WHERE clause via `filter.AppendConditions` (e.g. `store/db/sqlite/memo.go:57-61`).
