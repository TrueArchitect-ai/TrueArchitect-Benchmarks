Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140-159`) deletes:

1. **Memo relation records** — two `DeleteMemoRelation` calls remove `memo_relation` rows where the memo is the source (`MemoID`) and where it is the target (`RelatedMemoID`) (lines 142–147).
2. **Attachments linked to the memo** — it lists attachments with `MemoID` set and deletes each one via `DeleteAttachment` (lines 149–157).

Only then does it call `s.driver.DeleteMemo` to remove the `memo` row (the dialect driver, e.g. `store/db/sqlite/memo.go:237`, just issues the single `DELETE FROM memo`).
