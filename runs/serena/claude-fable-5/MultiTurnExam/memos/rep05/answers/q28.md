The server starts exactly one background runner, in `Server.startBackgroundRunners` (`server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`, `server/server.go:163`), then driven by a `time.Ticker` firing every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-30`) inside a goroutine with its own cancellable context.

**Unused scheduling infrastructure:** the **memopayload runner** (`server/runner/memopayload/runner.go`) defines `NewRunner`/`RunOnce` machinery, but the server never instantiates or starts it — there are no callers of `memopayload.NewRunner` anywhere. Only its standalone helper function `RebuildMemoPayload` is used, called synchronously from the API handlers (`server/router/api/v1/memo_service.go:108` and `:447`), not as a scheduled worker.
