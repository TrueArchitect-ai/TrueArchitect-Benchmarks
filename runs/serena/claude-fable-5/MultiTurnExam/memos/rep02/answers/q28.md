Runners the server actually starts (in `Server.startBackgroundRunners`, `server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once at startup via `RunOnce(ctx)`, then continuously in a goroutine whose `Run` loop is driven by a `time.Ticker` with `runnerInterval = 12 hours` (`server/runner/s3presign/runner.go:27-35`). It re-signs S3 presigned URLs and is stopped via a per-runner cancelable context on shutdown.

That is the **only** background runner the server starts.

**Unused scheduling infrastructure:** the memopayload runner (`server/runner/memopayload/runner.go`) defines a `Runner` with `NewRunner`/`RunOnce`, but the server never instantiates or starts it — `NewRunner` has no callers outside the package. Only its package-level helper `memopayload.RebuildMemoPayload` is used, called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108,447`), not on any schedule.
