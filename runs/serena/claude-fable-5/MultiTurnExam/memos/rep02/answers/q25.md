**Engine:** CEL (Common Expression Language), parsed with `github.com/google/cel-go`, in the in-repo filter engine at `internal/filter/` (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`).

**Mechanism:** The engine runs a three-phase pipeline — the CEL expression is parsed with cel-go and validated against the memo field schema (`internal/filter/schema.go` + `parser.go`), normalized into a dialect-agnostic intermediate representation (`internal/filter/ir.go`), and then rendered by `internal/filter/render.go` into a SQL WHERE fragment plus placeholder args for the target dialect (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`, handling differences like JSON access, placeholders, and LIKE vs ILIKE); each dialect's `ListMemos` calls it via `filter.AppendConditions(...)` (e.g. `store/db/sqlite/memo.go:57-61`), with the filter arriving from the handler in `server/router/api/v1/memo_service.go`.
