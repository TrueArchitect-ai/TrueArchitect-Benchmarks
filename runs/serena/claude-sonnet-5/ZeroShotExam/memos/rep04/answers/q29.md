Interceptor path: `web/src/connect.ts` — the `authInterceptor` (lines ~156–178) attaches an `Authorization: Bearer <token>` header to every outgoing Connect-RPC request, refreshing on `Code.Unauthenticated` and retrying once. Token state lives in `web/src/auth-state.ts`.

Token kinds:
- Access token — short-lived (15 min) JWT, kept in memory/localStorage (`memos_access_token`), sent as `Authorization: Bearer <token>`.
- Refresh token — 30-day, sent as an httpOnly cookie (`memos_refresh`), used only to call `AuthService.refreshToken`.
- Personal Access Tokens (`memos_pat_` prefix, SHA-256 hashed) as an alternate credential.

Backend package path: `server/auth/` — `authenticator.go` (`Authenticator.Authenticate`/`AuthenticateToUser` validates the bearer token, falling back to the refresh-token cookie), `token.go` (JWT generation/parsing for access/refresh/PAT tokens), and `extract.go` (`ExtractBearerToken`, `ExtractRefreshTokenFromCookie`). It's wired into request handling via `server/router/api/v1/connect_interceptors.go` (`auth.ApplyToContext`).
