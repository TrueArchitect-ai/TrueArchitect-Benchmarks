q17. web/src/hooks/useMemoQueries.ts; memoServiceClient

The mutations/queries hooks in `web/src/hooks/useMemoQueries.ts` (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useListMemos`, etc.) call `memoServiceClient`, which is imported from `web/src/connect.ts`. There, `memoServiceClient` is created via `createClient(MemoService, transport)`, where `MemoService` is the generated Connect/protobuf-es service definition from `web/src/types/proto/api/v1/memo_service_pb.ts`.
