- `dispatchMemoRelatedWebhook` (and thus the "updated" event) is also triggered from `SetMemoRelations` (memo_relation_service.go:48) and `SetMemoAttachments` (memo_attachment_service.go:48), not just direct `UpdateMemo` calls — both route through `dispatchMemoUpdatedSideEffects` in memo_update_helpers.go.

The core convergence point stands as stated: `webhook.PostAsync` → `asyncPostQueue` → worker → `webhook.Post` (internal/webhook/webhook.go:120), which performs the actual HTTP send via `safeClient.Do(req)` at webhook.go:152.
