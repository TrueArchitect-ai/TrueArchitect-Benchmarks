Before deleting the memo row itself, the store layer (`Store.DeleteMemo` in `/bench/repo/store/memo.go:140-159`) deletes:

1. **Memo relations** where the memo is the source (`memo_relation` rows via `DeleteMemoRelation{MemoID: &delete.ID}`)
2. **Memo relations** where the memo is the target (`memo_relation` rows via `DeleteMemoRelation{RelatedMemoID: &delete.ID}`)
3. **Attachments** linked to the memo (fetched via `ListAttachments{MemoID: &delete.ID}`, then each deleted individually with `DeleteAttachment`)

Only after these are removed does it call `s.driver.DeleteMemo(ctx, delete)`, which issues the actual `DELETE FROM memo WHERE id = ?` (confirmed in `/bench/repo/store/db/sqlite/memo.go:237-248`, which does nothing but delete the memo row itself).
