**Engine**: A CEL (Common Expression Language, `github.com/google/cel-go`) based filter engine at `internal/filter/` (`engine.go`, `schema.go`, `render.go`, `ir.go`, `parser.go`).

**Mechanism**: `ListMemos`'s `filter` field flows from the store layer (e.g. `store/db/sqlite/memo.go:57-61`, and the equivalent MySQL/Postgres `memo.go` files) into `filter.DefaultEngine()`/`filter.AppendConditions`, which uses `cel.Env.Compile` to parse the CEL expression into a CEL AST (`internal/filter/engine.go`), converts it into a dialect-agnostic `Condition` tree (`internal/filter/ir.go`), and then a `renderer` (`internal/filter/render.go`) walks that tree emitting parameterized SQL fragments + args, using a per-field `Schema` (`internal/filter/schema.go`) that maps each filterable field to dialect-specific column expressions (`Expressions map[DialectName]string` for `DialectSQLite`/`DialectMySQL`/`DialectPostgres`) so the same filter compiles to different SQL per database.
