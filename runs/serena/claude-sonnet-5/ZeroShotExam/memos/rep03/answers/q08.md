**Driver — `store/driver.go`**

The `Driver` interface is defined in `/bench/repo/store/driver.go:10-86`. It declares all the methods a database backend must implement (attachment, memo, user, identity provider, inbox, reaction, etc.). It's implemented by each backend driver: `store/db/mysql/mysql.go`, `store/db/postgres/postgres.go`, and `store/db/sqlite/sqlite.go` (referenced/used via `store/db/db.go`).
