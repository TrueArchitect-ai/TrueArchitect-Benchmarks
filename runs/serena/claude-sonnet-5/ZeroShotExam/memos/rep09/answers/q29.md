q29. Frontend API requests are authenticated via a Connect-RPC interceptor (`authInterceptor`) that is attached to the shared client transport used by all generated service clients.

- interceptor path: `web/src/connect.ts` (works with token state in `web/src/auth-state.ts`)
- token kinds: short-lived JWT **access token** (attached as `Authorization: Bearer <token>`, cached in-memory/`localStorage`, auto-refreshed on 401/expiry/tab focus) plus an HttpOnly **refresh token** cookie sent automatically via `credentials: "include"`; the backend also supports long-lived **Personal Access Tokens (PATs)**
- backend package path: `server/auth` (`server/auth/authenticator.go`, e.g. `Authenticator.AuthenticateByAccessTokenV2` / `AuthenticateByRefreshToken`), invoked from the Connect/gRPC interceptors and `server/router/api/v1/authz.go`
