Engine: CEL (Common Expression Language, via `github.com/google/cel-go`), wrapped in this repo's own filter package at `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`).

Mechanism: `s.validateFilter`/`ListMemos` in `server/router/api/v1/memo_service.go` appends the raw CEL `filter` string (plus a synthesized visibility/creator CEL expression) to `store.FindMemo.Filters`; each per-dialect store implementation (e.g. `store/db/sqlite/memo.go:57-61`, and the postgres/mysql equivalents) obtains the process-wide `filter.DefaultEngine()`, which compiles the CEL string into an AST (`Engine.Compile` in `internal/filter/engine.go`) and converts it into a dialect-agnostic `Condition` tree (`buildCondition` in `internal/filter/ir.go`/`parser.go`), then a dialect-specific `renderer` (`internal/filter/render.go`) walks that tree via `filter.AppendConditions`/`Program.Render` to emit parameterized SQL (`WHERE` fragment + args) tailored to `filter.DialectSQLite`, `DialectPostgres`, or `DialectMySQL`.
