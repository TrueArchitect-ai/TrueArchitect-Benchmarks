- **Interceptor:** `web/src/connect.ts` — the `authInterceptor` (ConnectRPC/gRPC-web transport interceptor) attaches `Authorization: Bearer <token>` to outgoing requests and, on a `Code.Unauthenticated` response, refreshes and retries once (token storage/refresh logic lives in `web/src/auth-state.ts`).
- **Token kinds:** short-lived JWT **access token** (kept in memory + `localStorage`, synced across tabs via `BroadcastChannel`) and a JWT **refresh token** (stored as an httpOnly cookie, never touched by JS); also supports long-lived **Personal Access Tokens (PATs)**.
- **Backend package:** `server/auth/` — `token.go` (JWT issuance/validation, `AccessTokenDuration`=15m, `RefreshTokenDuration`=30d, PAT support), `authenticator.go` (interceptor validating requests), `extract.go` (pulls Bearer header/cookie), `context.go` (stores authenticated user in request context).
