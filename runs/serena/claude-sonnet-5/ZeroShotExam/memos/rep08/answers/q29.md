**Interceptor path:** `web/src/connect.ts` — defines `authInterceptor`, a Connect-RPC `Interceptor` (this codebase uses Connect-RPC, not axios/REST) attached to the transport via `createConnectTransport({ interceptors: [authInterceptor] })`. It sets `Authorization: Bearer <token>` on outgoing requests and retries with a refreshed token on auth failure. Token storage/lifecycle helpers live alongside it in `web/src/auth-state.ts` (`localStorage` key `memos_access_token`).

**Token kinds:**
- **Access token** (JWT, "Access Token V2") — 15 min TTL, sent as `Authorization: Bearer <token>` by the interceptor.
- **Refresh token** (JWT) — 30 day TTL, sent as an HttpOnly cookie (`memos_refresh`), used only to mint new access tokens.
- **Personal Access Token (PAT)** — long-lived, prefix `memos_pat_`, also sent via `Authorization: Bearer <token>` for programmatic API use.

**Backend validation package:** `server/auth/` (`authenticator.go`, `token.go`, `extract.go`, `context.go`) — the `Authenticator` type validates all three token kinds (`AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`). It's invoked per-request by `server/router/api/v1/connect_interceptors.go` (`AuthInterceptor.WrapUnary`), and also used by `server/router/fileserver/fileserver.go` and `server/router/api/v1/sse_handler.go`.
