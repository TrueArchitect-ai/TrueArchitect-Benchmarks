**Driver** — `store/driver.go`

The `Driver` interface (defined in `store/driver.go:10`) is implemented by all database backends (SQLite, MySQL, PostgreSQL), which live in `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go` respectively, and are wired up via `store/db/db.go`.
