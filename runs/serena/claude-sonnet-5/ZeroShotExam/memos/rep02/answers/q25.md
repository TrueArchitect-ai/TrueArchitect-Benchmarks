**Engine + path:** Filters are CEL (Common Expression Language, via `github.com/google/cel-go`), implemented by an in-house package at `internal/filter/` (`engine.go`, `schema.go`, `ir.go`, `render.go`, `parser.go`, `helpers.go`). `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) validates `request.Filter` via `s.validateFilter` and appends it to `store.FindMemo.Filters`.

**Mechanism:** `filter.Engine.Compile` (`internal/filter/engine.go:47`) parses the CEL expression with a `cel.Env` built from a field `Schema`, converts the resulting AST into a dialect-agnostic `Condition` tree (`buildCondition` in `ir.go`); then a per-call `renderer` (`internal/filter/render.go`) walks that tree and, via `switch r.dialect` branches for `DialectSQLite`/`DialectMySQL`/`DialectPostgres`, emits the equivalent SQL fragment plus bound args (`Statement{SQL, Args}`), which the per-dialect store code (e.g. `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`) splices into its `WHERE` clause via `engine.CompileToStatement(...)`.
