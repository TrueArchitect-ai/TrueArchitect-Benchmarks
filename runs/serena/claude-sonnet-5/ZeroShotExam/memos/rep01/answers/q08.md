**Driver** — `store/driver.go` (package `store`, declared at `store/driver.go:10`)

This interface defines all the methods (attachments, memos, users, settings, identity providers, inbox, reactions, etc.) that each database backend must implement. It's satisfied by the SQLite, PostgreSQL, and MySQL drivers found in `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, and wired up generically in `store/db/db.go`.
