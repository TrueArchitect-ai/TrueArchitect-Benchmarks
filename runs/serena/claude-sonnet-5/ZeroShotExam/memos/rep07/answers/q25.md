**Engine + path:** Google's CEL (Common Expression Language) via `github.com/google/cel-go`, wrapped in the internal package `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:178`) validates the `filter` string via `validateFilter` (`server/router/api/v1/shortcut_service.go:336`) and passes it through unparsed to the store layer, where each dialect-specific driver (`store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`) calls `filter.AppendConditions`, which compiles the CEL expression against a schema-defined `cel.Env` (`internal/filter/schema.go`), normalizes the AST into a dialect-agnostic IR (`internal/filter/parser.go` + `ir.go`), and finally renders that IR into dialect-specific SQL fragments and args (`internal/filter/render.go`) — e.g. `?` placeholders + `json_extract`/`LIKE` for SQLite, `?` + `JSON_CONTAINS` for MySQL, and `$n` placeholders + `->`/`@>` for Postgres — which get appended to each driver's hand-built `WHERE` clause.
