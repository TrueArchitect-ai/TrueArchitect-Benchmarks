- **Delivery function** — `Post` in `internal/webhook/webhook.go:120` (invoked asynchronously via `PostAsync`, `internal/webhook/webhook.go:184`, which queues to a worker pool that calls `Post`). The actual HTTP request is sent via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.
- **Protection mechanism** — a custom `DialContext`, `safeDialContext` in `internal/webhook/webhook.go:59`, installed on `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname at dial time and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` in `internal/webhook/validate.go:44`, which checks against `reservedNetworks`/`reservedCIDRs` (loopback, RFC-1918 private ranges, link-local/cloud metadata `169.254.0.0/16`, and IPv6 equivalents) defined in `internal/webhook/validate.go:14-23`. Dialing at request time (rather than only validating the URL up front) defeats DNS-rebinding attacks. A separate pre-save check, `ValidateURL` (`internal/webhook/validate.go:62`), performs the same reserved-IP check when a webhook URL is created/updated, using the same `isReservedIP` logic (toggleable via `AllowPrivateIPs`, `internal/webhook/validate.go:41`).
