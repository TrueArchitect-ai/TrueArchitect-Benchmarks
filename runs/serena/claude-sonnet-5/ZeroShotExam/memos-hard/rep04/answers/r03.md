r03. Premise correction: there is no nightly database-cleanup job actually scheduled in this repository. The `internal/scheduler` package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`) is a standalone, self-contained cron-scheduling library — nothing in the actual server code imports or registers jobs with it (confirmed via `grep -rln "internal/scheduler"` outside that directory, which returns no results). The `"0 2 * * *"` (2 AM) "daily-cleanup" job you may be thinking of appears only as sample/illustrative code in `internal/scheduler/README.md:33-40`, not as a real, running job.
