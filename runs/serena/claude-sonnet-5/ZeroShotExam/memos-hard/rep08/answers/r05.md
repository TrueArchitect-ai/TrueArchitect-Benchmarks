Premise correction: this repository has no GraphQL API — there is no `.graphql` schema file or GraphQL server/library anywhere in the codebase (confirmed via repo-wide search).

Actual API surface: this is [usememos/memos](https://github.com/usememos/memos), and its public API is defined via **Protocol Buffers**, generating both gRPC and REST (gRPC-Gateway) endpoints:

- Proto service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`)
- Generated Go code: `proto/gen/api/`
- README confirms: "full REST and gRPC APIs for integration" (`README.md:22`)

So if you're looking to consume or extend the public API, the proto files under `proto/api/v1/` are the schema source of truth, not a GraphQL SDL file.
