Premise correction: this repository has no GraphQL schema — there's no `.graphql` file, no `graphql` package, and no GraphQL server code anywhere in the tree.

Actual API surface: the public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/*.proto`), which generates gRPC/gRPC-Gateway code into `proto/gen/api/`. The HTTP-facing REST-style API is exposed through `server/router` on top of that generated gRPC-Gateway code — that's the closest analogue to a "public API schema" in this codebase.
