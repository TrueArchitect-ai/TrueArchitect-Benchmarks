- Dial-time guard: `safeDialContext` in `internal/webhook/webhook.go:59-77`, used by the shared `safeClient` (lines 32-37). It resolves the hostname at actual connection time and rejects any resolved IP flagged by `isReservedIP`, which defeats DNS-rebinding/TOCTOU bypasses.

The dial-time check in `safeDialContext` is the actual enforcement point since it re-resolves at connection time; `ValidateURL` is a fast-fail check at configuration time only.
