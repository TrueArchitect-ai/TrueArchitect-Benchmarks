The data layer is the `store` package (`store/*.go`), which defines the persistent entity structs backed by the DB drivers in `store/db/{mysql,postgres,sqlite}`: `User`, `Memo`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`.

Counting distinct Go packages outside `store/` that reference each type (`store.<Type>` usages via `grep -rl`):

- `store.User`: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` → **7 packages**
- `store.Memo`: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` → **6 packages**
- `store.Attachment`: 4 packages, next closest.

**1st: `User` (store/user.go:29); 2nd: `Memo` (store/memo.go:35)** — roughly 7 vs 6 external packages. `User` edges out `Memo` because it's additionally used by `server/auth` (for authentication/session context), a package `Memo` never touches.
