**Premise correction:** This repository (this looks like the "memos" project) does not have a GraphQL API — there is no `.graphql`/`.gql` schema file and no reference to "graphql" anywhere in the codebase.

**Actual API surface:** The public API is defined as **Protocol Buffers**, under `proto/api/` (with generated code in `proto/gen/`), which is served over gRPC and a REST/gRPC-gateway interface (see `server/router` for the HTTP routing layer, and `cmd/memos` for server bootstrap). If you're looking for the schema of the public API, look at the `.proto` service/message definitions in `proto/api/` rather than a GraphQL schema.
