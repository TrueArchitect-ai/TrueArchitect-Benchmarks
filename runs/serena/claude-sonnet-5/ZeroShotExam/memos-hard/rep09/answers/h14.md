**Computation site:**
- `internal/markdown/markdown.go` — `service.ExtractAll()` (and its lower-level sibling `ExtractProperties()`) does a single goldmark AST walk over the memo's markdown content and builds `*storepb.MemoPayload_Property` plus a tag list. This is invoked by `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which writes the results into `memo.Payload.Property` / `memo.Payload.Tags` (persisted to the DB).
- `internal/markdown/markdown.go` — `service.GenerateSnippet(content, 64)` does a separate AST walk to build a plain-text preview. It's called on-demand (not persisted) via `getMemoContentSnippet()` in `server/router/api/v1/memo_service_webhooks.go:83`, and set on the response in `convertMemoFromStoreWithCreators()` (`server/router/api/v1/memo_service_converter.go:76`), plus in `batchConvertMemoRelations` (same file, lines 225/248), `memo_relation_service.go:154/162`, and `user_service_notifications.go:323`.

**Triggers for recomputation:**
- Persisted `Property`/`Tags`: recomputed whenever a memo is created (`memo_service.go:108`, `CreateMemo`) or whenever its `content` field is updated (`memo_service.go:447`, `UpdateMemo` when `content` is in the update mask). There's also a batch `Runner.RunOnce()` (`server/runner/memopayload/runner.go:27`) that walks all memos and rebuilds their payloads, but it isn't wired into `server.go`'s startup/scheduled jobs (unlike e.g. the s3presign runner) — it appears intended for a one-off/manual rebuild rather than being scheduled.
- `Snippet`: recomputed on every read/serialization of a memo into the API response (list views, memo relations, notification messages) — it is not stored, so it's derived fresh each time from `memo.Content`.

**Extracted properties:**
- `Property.Title` — text of the first block-level node if it's an H1 heading.
- `Property.HasLink` — true if any markdown link node exists.
- `Property.HasCode` — true if any code block, fenced code block, or inline code span exists.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
- `Tags` — all `#tag` nodes found in the content.
- `Snippet` — a plain-text preview (max 64 chars, truncated at a word boundary), built from paragraph/heading/list/table text and autolink URLs, explicitly skipping code block contents.
