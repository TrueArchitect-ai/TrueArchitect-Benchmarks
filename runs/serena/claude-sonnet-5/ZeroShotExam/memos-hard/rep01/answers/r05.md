**Premise correction:** This repository (Memos) has no GraphQL API — there is no `.graphql`/`.gql` schema anywhere in the codebase, and no `graphql` dependency in `web/package.json` or elsewhere.

**Actual API surface:** The public API is defined as Protobuf service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`), documented in `proto/api/v1/README.md`. These are compiled to Go/TS bindings in `proto/gen/`, and served as gRPC with a grpc-gateway REST/JSON transcoding layer wired up in `server/router`.
