**Premise correction:** This repository (memos) has no GraphQL API — there's no `.graphql`/`.gql` schema file or GraphQL server/client dependency anywhere in the codebase.

**Actual API surface:** The public API is defined via Protocol Buffers and exposed as gRPC/Connect-RPC (with a REST/OpenAPI gateway), not GraphQL:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`)
- Internal storage schema: `proto/store/*.proto`
- Codegen config: `proto/buf.gen.yaml`, `proto/buf.yaml`, `proto/buf.lock`
- Generated code lives under `proto/gen`
- OpenAPI docs embedding: `proto/openapi_embed.go`
- The web frontend (`web/`) talks to the backend using `@connectrpc/connect` / `@connectrpc/connect-web`, consistent with a Connect/gRPC API rather than GraphQL.
