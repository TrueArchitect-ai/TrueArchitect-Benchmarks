Actual API surface: the public API is defined via **Protocol Buffers**, not GraphQL, under `proto/api/` (service/message definitions), configured by `proto/buf.yaml` and `proto/buf.gen.yaml`, with generated code in `proto/gen/`. This is exposed as both gRPC and a REST/OpenAPI surface (via grpc-gateway), with the OpenAPI spec embedded through `proto/openapi_embed.go`.
