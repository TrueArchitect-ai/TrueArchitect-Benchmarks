**Premise correction:** There is no GraphQL schema in this repository. This is the `usememos/memos` project, and its public API is defined using **Protocol Buffers**, not GraphQL — a repo-wide search for GraphQL artifacts (`.graphql`/`.gql` files, `GraphQLSchema`, `apollo-server`, `graphql` npm/go dependencies) turns up nothing.

**Actual API surface:**
- Proto service definitions live under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `common.proto`), documented in `proto/api/v1/README.md`.
- Internal storage-layer protos are in `proto/store/` (e.g. `memo.proto`, `inbox.proto`, `idp.proto`).
- These are compiled to Go bindings in `proto/gen/api/v1` and `proto/gen/store/`.
- A REST surface is generated from the same protos via gRPC-Gateway, with the resulting OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).
- `README.md:22` explicitly advertises "full REST and gRPC APIs for integration" — confirming GraphQL is not part of the public API.
