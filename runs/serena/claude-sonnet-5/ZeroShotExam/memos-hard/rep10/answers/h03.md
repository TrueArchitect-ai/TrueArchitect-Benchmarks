h03. `github.com/usememos/memos/internal/idp` (`internal/idp/idp.go`); `github.com/usememos/memos/internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)

- Abstraction: `internal/idp/idp.go` defines the `idp` package, which holds the shared `IdentityProviderUserInfo` type used across all identity-provider integrations.
- Concrete implementation: `internal/idp/oauth2/oauth2.go` — the only protocol implementation subpackage — provides `oauth2.IdentityProvider`, built on `golang.org/x/oauth2`, configured via `storepb.OAuth2Config` and used to authenticate users through generic OAuth2 identity providers (`server/router/api/v1/auth_service_sso.go`, `server/router/api/v1/idp_service.go` wire it up).
