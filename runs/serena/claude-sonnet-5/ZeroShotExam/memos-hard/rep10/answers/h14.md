**Extracted properties:**
- `Snippet` — plain-text preview stripped of markdown formatting (skips code blocks; joins paragraphs/headings/list items/table cells; keeps `#tag` text and autolink URLs), truncated to 64 chars at a word boundary.
- `Title` — text of the first H1 heading, only if it's the very first block in the document.
- `HasLink` — whether any markdown link exists.
- `HasCode` — whether any code block/fenced block/code span exists.
- `HasTaskList` / `HasIncompleteTasks` — whether task checkboxes exist / any are unchecked.
- `Tags` — all `#tag` occurrences (deduplicated, case-preserving).
- `Mentions` — `@username` mentions extracted in-memory for notification resolution, not persisted to `MemoPayload`.
