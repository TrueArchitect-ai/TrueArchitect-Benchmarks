r05. Premise correction: this repository does not expose a GraphQL API — there is no GraphQL schema anywhere in the codebase (no `.graphql`/`.gql` files, no `graphql` string matches).

Actual API surface: the public API is defined via Protocol Buffers / gRPC, using [buf](https://buf.build):
- Proto definitions: `/bench/repo/proto/api/v1/` (service/message definitions) and `/bench/repo/proto/store/` (internal store protos)
- Buf config: `/bench/repo/proto/buf.yaml`, `/bench/repo/proto/buf.gen.yaml`, `/bench/repo/proto/buf.lock`
- Generated code: `/bench/repo/proto/gen/api/`, `/bench/repo/proto/gen/store/`
- A generated OpenAPI (REST gateway) spec derived from the same protos: `/bench/repo/proto/gen/openapi.yaml`, embedded via `/bench/repo/proto/openapi_embed.go`
- Overview: `/bench/repo/proto/README.md`

So instead of a GraphQL schema, look at the `.proto` files under `proto/api/v1/` for the public API contract, and `proto/gen/openapi.yaml` for its REST/OpenAPI representation.
