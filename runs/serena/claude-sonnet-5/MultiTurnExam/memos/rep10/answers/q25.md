q25. CEL (Common Expression Language), engine at `internal/filter/engine.go`

The filter engine (`internal/filter/`) parses the CEL filter string into an AST/condition tree (`Engine.Compile` in `engine.go`, using `parser.go`/`ir.go`), then `render.go`'s `renderer` (dialect-aware, `DialectName` in {SQLite, Postgres, MySQL}) walks that condition tree and emits dialect-specific SQL fragments/placeholders (e.g. different JSON extraction and timestamp accessor expressions per dialect) that are appended to the store layer's WHERE clause.
