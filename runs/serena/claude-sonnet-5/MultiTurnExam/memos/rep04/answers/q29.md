Token kinds:
- **Access token** — short-lived JWT, kept in memory + `localStorage` (`memos_access_token`/`memos_access_token_expires_at`), attached as `Authorization: Bearer <token>` on each request, refreshed proactively before expiry or reactively on a 401.
- **Refresh token** — issued as an HttpOnly cookie (sent automatically via `credentials: "include"`, not directly accessible/managed by JS), used by the `AuthService.RefreshToken` RPC to mint new access tokens.

Backend validation package: `server/auth` (server/auth/authenticator.go, server/auth/token.go, server/auth/extract.go).
