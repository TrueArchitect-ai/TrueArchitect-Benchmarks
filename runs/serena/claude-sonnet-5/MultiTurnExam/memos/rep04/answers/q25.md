q25. Engine: CEL (Common Expression Language, via `github.com/google/cel-go`), implemented in `internal/filter/engine.go` (`Engine.Compile`).

Mechanism: `Engine.Compile` parses the CEL filter string into a dialect-agnostic AST/condition tree using a schema (internal/filter/schema.go), then each store dialect driver (e.g. store/db/postgres/memo.go, store/db/sqlite/memo.go, store/db/mysql/memo.go) calls `filter.AppendConditions(..., filter.DialectPostgres/SQLite/MySQL, ...)`, which renders that condition tree into dialect-specific SQL WHERE clauses and bind args via `internal/filter/render.go` (e.g. different JSON-extract/timestamp/string-length expressions per `DialectName`).
