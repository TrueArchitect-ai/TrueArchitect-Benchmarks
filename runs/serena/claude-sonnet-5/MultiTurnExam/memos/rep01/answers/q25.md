q25. Engine: **CEL (Common Expression Language)**, via `google/cel-go`, implemented in `internal/filter/engine.go` (compiles filter strings into a dialect-agnostic condition tree/AST).

Mechanism: each dialect driver (e.g. `store/db/postgres/memo.go:54-58`) calls `filter.DefaultEngine()` and `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectPostgres, &where, &args)`, which compiles the CEL expression to a `Program`/condition tree and then renders it (in `internal/filter/render.go`, switching on `DialectSQLite`/`DialectMySQL`/`DialectPostgres`) into dialect-specific SQL fragments and parameterized args appended to the query's `WHERE` clause.
