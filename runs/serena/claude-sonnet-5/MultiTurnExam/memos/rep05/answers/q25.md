q25. Engine: **CEL (Common Expression Language, via `cel-go`)**, implemented in `internal/filter/engine.go` (parsing/environment) and `internal/filter/schema.go` (field schema).

Mechanism: the CEL filter string is parsed/compiled into an AST by `filter.DefaultEngine()`, then each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`, and equivalents in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)`, which walks the parsed expression and translates it into dialect-specific SQL `WHERE` clause fragments and bound arguments.
