q25. Engine: CEL (Common Expression Language, via `cel-go`) — implemented in `/bench/repo/internal/filter/engine.go` (`Engine.Compile`) with translation logic in `/bench/repo/internal/filter/render.go`.

Mechanism: the ListMemos filter string is CEL-parsed into a `Program`/condition tree by `Engine.Compile`, then `Program.Render`/`render.go`'s renderer walks that tree emitting parameterized SQL fragments per-`DialectName` (SQLite/Postgres/MySQL branches, e.g. for JSON extraction, string length, and timestamp accessors), which each dialect's memo store method (e.g. `store/db/postgres/memo.go:54-58`, calling `filter.DefaultEngine()` and `filter.AppendConditions(..., filter.DialectPostgres, ...)`) appends to its `WHERE` clause and argument list.
