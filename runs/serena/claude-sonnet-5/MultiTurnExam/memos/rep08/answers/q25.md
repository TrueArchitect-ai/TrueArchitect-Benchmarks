q25. Engine: Google's CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/engine.go` (`Engine.Compile`/`CompileToStatement`) with the field schema in `internal/filter/schema.go`.

Mechanism: `AppendConditions` (internal/filter/helpers.go) compiles each filter string with the CEL engine into an AST, then `Program.Render` walks it with a per-dialect `RenderOptions.Dialect` (sqlite/mysql/postgres) to emit dialect-specific SQL fragments — e.g. field expressions differ per dialect (`DialectName`/`Expressions` map in schema.go, such as `UNIX_TIMESTAMP(%s)` for MySQL vs plain `%s` for Postgres/SQLite) — producing parameterized WHERE clauses appended by each store driver.
