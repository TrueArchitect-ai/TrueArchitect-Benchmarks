q25. **Engine**: CEL (Common Expression Language, via `google/cel-go`), implemented in `internal/filter/engine.go` (`Engine.Compile` parses the filter string into a dialect-agnostic condition tree via `internal/filter/parser.go`/`ir.go`).

**Mechanism**: The store's `ListMemos`/dialect driver (e.g. `store/db/sqlite/memo.go:57-61`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, ...)`, which compiles each CEL filter string into a `Condition` tree and then uses the dialect-aware `renderer` in `internal/filter/render.go` (switching on `DialectSQLite`/`DialectPostgres`/`DialectMySQL`) to emit the appropriate parameterized `WHERE` clause SQL and arguments for that specific database.
