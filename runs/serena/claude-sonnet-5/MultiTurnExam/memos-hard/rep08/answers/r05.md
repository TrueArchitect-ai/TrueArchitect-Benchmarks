**Premise correction:** There is no GraphQL schema in this repository — no `.graphql`/`.gql` files, no GraphQL library dependency, and no reference to "graphql" anywhere in the Go source.

**Actual API surface:** The public API is defined with Protocol Buffers under `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto` (and persistence-layer messages under `proto/store/`). These are compiled to Go (`proto/gen/api/v1/`) and served over gRPC, Connect (connectrpc.com/connect), and a gRPC-Gateway REST/JSON transcoding layer, registered via `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64-...`).
