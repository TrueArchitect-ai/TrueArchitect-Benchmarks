**Premise correction:** There is no Redis in this codebase — a repo-wide search finds zero references to Redis anywhere in the Go code. The cache layer is a self-contained, in-process, in-memory cache; no external cache backend is configured or dialed anywhere in `store/`.

**Actual mechanism:** `store.Store` holds three in-memory `*cache.Cache` instances (`instanceSettingCache`, `userCache`, `userSettingCache`), constructed in `store.New` — `store/store.go:38-58`. The cache implementation itself lives at `store/cache/cache.go:66-90` (`Cache` struct backed by `sync.Map`, with a background `cleanupLoop` goroutine).

The user cache is created with:
```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
}
userCache: cache.New(cacheConfig)
```
