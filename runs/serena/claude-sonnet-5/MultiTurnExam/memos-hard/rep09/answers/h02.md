**Protection mechanism:** the `safeClient`'s custom `Transport.DialContext` — `safeDialContext` at `internal/webhook/webhook.go:59`, which resolves the target hostname and rejects any resolved IP falling in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go`, checked against `reservedNetworks`/`reservedCIDRs` covering loopback, RFC-1918 private ranges, and link-local/cloud-metadata `169.254.0.0/16`). This dial-time check (rather than a pre-request URL check) also defeats DNS-rebinding attacks. A complementary pre-flight check, `ValidateURL` (`internal/webhook/validate.go`), performs the same reserved-IP validation when a webhook URL is configured/saved.
