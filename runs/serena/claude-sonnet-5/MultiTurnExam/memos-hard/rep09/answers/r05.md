**Premise correction:** There is no GraphQL schema in this codebase — I found zero references to "graphql" anywhere in the Go source or `go.mod`.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`. These are compiled to Go bindings under `proto/gen/api/v1/` and served two ways:
- gRPC / Connect-RPC handlers (`apiv1connect` generated package, implemented by `APIV1Service` in `server/router/api/v1/`)
- A REST/JSON gateway via `grpc-ecosystem/grpc-gateway`, registered in `RegisterGateway` (`server/router/api/v1/v1.go:65`)

So the schema/contract equivalent to what you'd expect from GraphQL lives in these `.proto` files, not a GraphQL SDL file.
