**Premise correction:** There is no GraphQL schema anywhere in this codebase — the premise is false. An exhaustive search (`grep -ril "graphql"`, `"gqlgen"`, `find -iname "*.graphql"`) across the repo and `go.mod` found zero matches; no GraphQL library is a dependency.

**Actual API surface:** The public API is protobuf-first, defined as `.proto` service/message definitions under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc.) plus internal storage types under `proto/store/*.proto`, managed via `buf` (`proto/buf.yaml`, `proto/buf.gen.yaml`). These are compiled into:
- gRPC service stubs and Connect-RPC handlers (`proto/gen/api/v1/*_grpc.pb.go`, `proto/gen/api/v1/apiv1connect/*.connect.go`)
- a REST/JSON gateway via grpc-gateway (`proto/gen/api/v1/*.pb.gw.go`)
- an auto-derived OpenAPI 3.0 spec (`proto/gen/openapi.yaml`)

All three transports (grpc-gateway REST, Connect-RPC, native gRPC) are registered on the same Echo HTTP server in `server/router/api/v1/v1.go`.
