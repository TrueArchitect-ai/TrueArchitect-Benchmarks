**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll` (`internal/markdown/markdown.go:356-422`, a single-pass goldmark AST walk) and copies the results into `memo.Payload`.

**Triggers:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (always, on every new memo).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447` (only inside the update-mask loop's `content` branch, i.e. only when the memo's content is being changed).
No other handler (`SetMemoAttachments`, `SetMemoRelations`, `CreateMemoComment`, `RenameTag`, reads) triggers it. A batch `Runner.RunOnce` exists (`runner.go:27-72`) that rebuilds all memos, but it's dead code — never wired into server startup.

**Extracted properties** (set on `memo.Payload`):
- `Tags` — all `#tag` nodes found in content, deduped (`markdown.go:376-378,418`).
- `Property.Title` — text of a leading H1 heading, if present (`markdown.go:383-389`).
- `Property.HasLink` — true if any link node exists (`markdown.go:393-394`).
- `Property.HasCode` — true if any code block/span exists (`markdown.go:396-397`).
- `Property.HasTaskList` — true if any task checkbox exists (`markdown.go:399-400`).
- `Property.HasIncompleteTasks` — true if any unchecked task checkbox exists (`markdown.go:401-404`).

(Note: `ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` currently discards it — not copied into the payload. Snippet/preview text is computed separately and live, not stored in the payload.)
