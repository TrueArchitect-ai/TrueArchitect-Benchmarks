**Premise correction:** This API isn't GraphQL — there is no GraphQL schema anywhere in the repository. A search for "graphql" and `.graphql` schema files across the codebase returns nothing.

**Actual API surface:** The public API is defined as Protocol Buffers gRPC services under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to generated Go code under `proto/gen/api/v1/` and served over both gRPC and HTTP/JSON via grpc-gateway/Connect, wired up in `server/router/api/v1/v1.go` (`RegisterGateway`).
