**Extracted properties** (via a single AST walk in `ExtractAll`, `internal/markdown/markdown.go:355-416`):
- `Tags` — all `#tag` occurrences (deduplicated, case-preserving)
- `Property.Title` — text of a leading H1 heading, if the first top-level block is one
- `Property.HasLink` — set if any link node is present
- `Property.HasCode` — set on code blocks/fenced code blocks/inline code spans
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set on task-list checkboxes (incomplete if any checkbox is unchecked)

(`ExtractAll` also extracts `Mentions`, but `RebuildMemoPayload` does not persist those into `memo.Payload` — they're used elsewhere, e.g. `server/router/api/v1/memo_mention_helpers.go`, not for the list/preview payload.)
