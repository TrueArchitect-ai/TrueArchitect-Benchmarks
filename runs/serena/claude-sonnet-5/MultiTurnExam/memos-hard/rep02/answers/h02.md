**Delivery function:** `Post` in `internal/webhook/webhook.go:120-180`, which sends the request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. It's invoked asynchronously through `PostAsync` (`internal/webhook/webhook.go:184-196`, queue drained by workers started in `init()` at `webhook.go:42-55`), called from memo create/update/delete handlers at `server/router/api/v1/memo_service_webhooks.go:43` and `:71`.

**Protection mechanism:** Two layers, both in `internal/webhook`:
- Dial-time enforcement: `safeDialContext` (`internal/webhook/webhook.go:59-77`), wired as the `DialContext` of `safeClient`'s `http.Transport` (`webhook.go:32-37`) — re-resolves the host and rejects any IP in a reserved range on every actual connection, which also defeats DNS-rebinding TOCTOU bypass.
- Registration-time validation: `ValidateURL` (`internal/webhook/validate.go:62-83`), called when webhooks are created/updated (`server/router/api/v1/user_service_webhooks.go:74,161,182`).

Both rely on `isReservedIP` (`internal/webhook/validate.go:44-54`) checking against `reservedNetworks`/`reservedCIDRs` (`validate.go:14-23`) covering loopback, RFC-1918 private ranges, and link-local/cloud-metadata `169.254.0.0/16` (plus IPv6 equivalents). Note: a package-level `AllowPrivateIPs` flag (`validate.go:41`) can disable this protection entirely, but no non-test code was found that sets it to `true`.
