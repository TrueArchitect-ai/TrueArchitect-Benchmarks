**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` type used across identity-provider integrations.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete protocol implementation shipped, implementing OAuth2-based identity provider login (`IdentityProvider` struct, `NewIdentityProvider`, etc.). No other protocol implementation (e.g., SAML, OIDC-specific) exists under `internal/idp`.
