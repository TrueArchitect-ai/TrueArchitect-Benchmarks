Handlers whose RPC path transitively triggers an outbound HTTP request to a user-configured (webhook) URL:

- `CreateMemo` — `server/router/api/v1/memo_service.go:70` (calls `DispatchMemoCreatedWebhook` at `memo_service.go:157`)
- `UpdateMemo` — `server/router/api/v1/memo_service.go:401` (via `memo_update_helpers.go:67` → `DispatchMemoUpdatedWebhook`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:518` (calls `DispatchMemoDeletedWebhook` at `memo_service.go:562`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` (calls `DispatchMemoCommentCreatedWebhook` at `memo_service_comments.go:119`)

All of these dispatch functions (`server/router/api/v1/memo_service_webhooks.go`) call `webhook.PostAsync(payload)`, which enqueues onto the async queue drained by worker goroutines that call `Post`.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120-180` (the outbound call itself is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`). Every one of the above RPC paths ultimately funnels through this single function before an HTTP request actually leaves the process.
