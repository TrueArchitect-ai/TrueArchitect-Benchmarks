**Premise correction:** This repository has no GraphQL API. There is no `.graphql`/`.gql` schema file anywhere in the tree, and a repo-wide search for "graphql" (source and `go.mod`) returns zero hits — no GraphQL server library, resolver, or dependency exists.

**Actual API surface:** The public API is defined as Protocol Buffers under `proto/api/v1/` — `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto` — which declare gRPC services and messages (AIP-compliant). These are compiled into generated Go bindings under `proto/gen/api/v1/` (including `*.pb.gw.go` gRPC-Gateway files, seen earlier in r01-r04 investigation), and exposed over gRPC plus a REST/JSON surface via grpc-gateway, registered in `server/router/api/v1/v1.go` (`RegisterGateway`).
