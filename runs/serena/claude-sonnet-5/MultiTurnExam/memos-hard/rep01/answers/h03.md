**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic type `IdentityProviderUserInfo`.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — implements the OAuth2 identity provider protocol (`IdentityProvider` struct, `NewIdentityProvider`, `ExchangeToken`, etc.), and is the only concrete protocol implementation shipped in this repo.
