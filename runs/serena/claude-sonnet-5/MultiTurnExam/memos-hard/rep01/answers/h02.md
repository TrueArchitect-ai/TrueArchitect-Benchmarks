**Delivery function:** `Post` in `internal/webhook/webhook.go` (executes the outbound HTTP POST via `safeClient.Do(req)`, called synchronously by `Post` and asynchronously via `PostAsync`, which enqueues onto `asyncPostQueue` for 4 worker goroutines started in `webhook.go`'s `init()`).

**Protection mechanism:** `safeDialContext` in `internal/webhook/webhook.go` — a custom `net.Dialer.DialContext` replacement wired into `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go`, `safeClient` var block). It resolves the target hostname at dial time and rejects any resolved IP that falls within a reserved/private range via `isReservedIP` (defined in `internal/webhook/validate.go`, checked against `reservedNetworks`/`reservedCIDRs` covering loopback, RFC-1918, and link-local/cloud-IMDS ranges), which also defeats DNS-rebinding since the check happens per-dial rather than at URL-validation time. A complementary but separate check, `ValidateURL` in `internal/webhook/validate.go`, does an upfront `net.LookupHost` + `isReservedIP` validation when a webhook URL is configured.
