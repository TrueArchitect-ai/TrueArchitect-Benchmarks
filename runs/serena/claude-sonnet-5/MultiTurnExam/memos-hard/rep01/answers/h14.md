**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(memo.Content)` (`internal/markdown/markdown.go:356`, the `*service` implementation from h13) and assigns the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every new memo.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes the `content` path (`memo_service.go:436-449`).
- (Also reachable via `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27-72`, a batch backfill over all memos — but per h08 this runner is never wired into production startup, so in practice only the two RPC paths above trigger it.)

**Extracted properties** (via a single AST walk in `(*service).ExtractAll`, `internal/markdown/markdown.go:356-419`):
- `Tags` — all `#tag` occurrences (deduplicated, case-preserved) — stored into `memo.Payload.Tags`.
- `Property.Title` — text of a leading H1 heading, if the document's first block is one.
- `Property.HasLink` — set if any link node is present.
- `Property.HasCode` — set if any code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set from task-list checkbox nodes.
- (`Mentions` is also computed by `ExtractAll` but is *not* persisted by `RebuildMemoPayload` — only `Tags` and `Property` are written to the memo's payload.)
