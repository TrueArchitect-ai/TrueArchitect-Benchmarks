**Premise correction:** There is no per-user API rate-limiting middleware in this codebase. A repo-wide search for "rate limit", "ratelimit", "throttle", and the standard `golang.org/x/time/rate` package (in both source files and `go.mod`/`go.sum`) turns up zero matches — the dependency isn't even vendored.

The closest things that exist are unrelated concurrency *caps* (not rate limits): a `semaphore.Weighted` limiting concurrent thumbnail/image-processing work (`server/router/api/v1/v1.go:39-41`, `server/router/fileserver/fileserver.go:107,116` — `maxConcurrentThumbnails = 3`), and a bounded async webhook dispatch queue (`internal/webhook/webhook.go:39`, capacity 128). Neither restricts how many requests a given user can make over time.
