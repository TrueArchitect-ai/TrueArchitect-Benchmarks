**Premise correction:** There is no GraphQL schema in this codebase — a repo-wide search for "graphql" (case-insensitive) across all Go files returns zero matches, and there's no `.graphql` schema file anywhere.

**Actual API surface:** The public API is defined via Protocol Buffers / gRPC, exposed through a grpc-gateway/Connect HTTP bridge. Service definitions live under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/ai_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/shortcut_service.proto`, plus shared types in `proto/api/v1/common.proto`), with the persistence-layer message shapes under `proto/store/`. These are compiled to Go (`proto/gen/api/v1`, imported as `v1pb`) and served over both gRPC and HTTP/JSON via grpc-gateway, wired up in `server/router/api/v1/v1.go` (`APIV1Service.RegisterGateway`).
