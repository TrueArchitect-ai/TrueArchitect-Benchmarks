**Premise correction:** There is no GraphQL API in this repository — no `.graphql` schema files exist, and a search for "graphql" across all Go and proto files returns nothing.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, etc.), served as gRPC/Connect services with generated code in `proto/gen/api/v1/`. A REST/JSON gateway is also generated from the same proto definitions (the `*.pb.gw.go` files, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`), giving HTTP+JSON access without any GraphQL layer.
