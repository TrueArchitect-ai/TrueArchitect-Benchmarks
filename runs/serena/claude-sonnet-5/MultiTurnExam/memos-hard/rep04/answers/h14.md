h14.
**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88` — calls `markdownService.ExtractAll(memo.Content)` (the concrete implementation is `(*service).ExtractAll` in `internal/markdown/markdown.go:356-422`), then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (every new memo)
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the `content` field is included in the update mask
- Also `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`), a batch job that rebuilds the payload for all memos — but as established earlier, this `Runner` is never actually constructed/wired at startup, so in practice only the create/update RPC paths trigger it.

**Extracted properties** (via a single AST walk over the markdown content, `internal/markdown/markdown.go:371-411`):
- `Tags` — `#tag`-style tag nodes, deduplicated case-preserving
- `Mentions` — `@username` mentions (lowercased, deduplicated) — collected in `ExtractedData` but only `Tags`/`Property` are persisted onto `memo.Payload`
- `Property.Title` — text of a leading H1 heading, if the document's first block is one
- `Property.HasLink` — whether any link node exists
- `Property.HasCode` — whether any code block/fenced code block/code span exists
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether a task checkbox list exists / has unchecked items
