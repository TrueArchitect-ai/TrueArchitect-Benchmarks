**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` DTO; each protocol package implements the convention of an `IdentityProvider` struct with `ExchangeToken` and `UserInfo` methods, selected via the `storepb.IdentityProvider_Type` enum.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol shipped, implementing a generic OAuth2 authorization-code exchange plus userinfo-endpoint fetch with configurable claim field mapping (uses `golang.org/x/oauth2`). No LDAP/SAML/dedicated-OIDC implementation exists.
