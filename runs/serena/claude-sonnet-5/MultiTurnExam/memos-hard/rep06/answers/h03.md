**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` type used across identity-provider implementations.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — "Package oauth2 implements the OAuth2 identity provider integration," providing `IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, etc. It is the sole concrete protocol implementation shipped in the repo.
