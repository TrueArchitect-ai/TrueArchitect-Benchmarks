**Delivery function:** `Post` in `internal/webhook/webhook.go:120-180` (invoked synchronously, or queued via `PostAsync` at `internal/webhook/webhook.go:184-196` and dispatched by worker goroutines started in `init()`, `internal/webhook/webhook.go:42-55`) — it builds the HTTP request and sends it via the package's shared `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).

**Protection mechanism:** SSRF protection is enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59-77`), wired as the `Transport.DialContext` of `safeClient` (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any resolved IP matching `isReservedIP` (loopback/RFC-1918/link-local/cloud IMDS/IPv6 equivalents), defined in `internal/webhook/validate.go:14-54`, which defeats DNS-rebinding since the check runs against the actual dialed address rather than the URL host. A pre-flight version of the same check, `ValidateURL` (`internal/webhook/validate.go:62-83`), is also available for validating webhook URLs at registration time, and can be globally disabled via `AllowPrivateIPs` (`internal/webhook/validate.go:41`).
