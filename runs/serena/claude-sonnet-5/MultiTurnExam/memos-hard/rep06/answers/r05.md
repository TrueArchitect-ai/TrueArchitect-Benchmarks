**Premise correction:** This repository does not expose a GraphQL API and contains no GraphQL schema — a search of all `.go` files, `go.mod`, and for `.graphql`/`.gql` files found zero references anywhere.

**Actual API surface:** The public API is defined via **Protobuf** service definitions under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`), compiled via `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`) into generated Go code under `proto/gen/`. It's served over two protocols simultaneously — native gRPC/Connect (`proto/gen/api/v1/apiv1connect/`) and a REST/JSON gateway (`*.pb.gw.go` files, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`), with an embedded OpenAPI spec (`proto/openapi_embed.go`) rather than a GraphQL schema.
