**Premise correction:** There is no GraphQL API in this repository — no GraphQL dependency in `go.mod`, no `.graphql` schema files, and no reference to "graphql" anywhere in the Go source.

**Actual API surface:** The public API is defined via Protocol Buffers, under `proto/api/v1/*.proto` (service definitions like `memo_service.proto`, `user_service.proto`, etc., alongside `proto/store/*.proto` for internal storage messages). These are compiled (via `buf`, configured in `proto/buf.yaml` / `proto/buf.gen.yaml`) into generated Go code under `proto/gen/api/v1/` and served three ways simultaneously: gRPC/Connect handlers (`proto/gen/api/v1/apiv1connect/`), a gRPC-Gateway REST/JSON transcoding layer (`*.pb.gw.go` files, e.g. `proto/gen/api/v1/user_service.pb.gw.go`), and an OpenAPI/Swagger document generated to `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`). These are registered onto the server in `server/router/api/v1/connect_services.go` and `server/router/api/v1/v1.go`.
