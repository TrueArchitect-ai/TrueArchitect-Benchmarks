Data-layer entity types are those defined in the `store` package (`store/*.go`): `User`, `Memo`, `Attachment`, `Reaction`, `MemoRelation`, `MemoShare`, `UserIdentity`, `UserSetting`, `Inbox`, `InstanceSetting`, `IdentityProvider`. Counting distinct packages outside `store` (excluding the `store/db/{sqlite,postgres,mysql}` driver implementations, which are part of that same data layer) that reference each type via `store.<Type>`:

**1st: `store.User`** — referenced from 6 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`

**2nd: `store.Memo`** — referenced from 4 packages: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`

For comparison, the next-widest types trail further behind: `store.Attachment` (3 packages: `server/router/api/v1`, `server/router/fileserver`, `server/router/rss`), and the rest (`Reaction`, `MemoRelation`, `UserIdentity`, `MemoShare`, `Inbox`, `UserSetting`, `InstanceSetting`, `IdentityProvider`) at 1–2 packages each.
