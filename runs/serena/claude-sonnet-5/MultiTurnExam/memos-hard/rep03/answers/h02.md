**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (invoked synchronously, or asynchronously via `PostAsync` at `internal/webhook/webhook.go:184`, which enqueues onto `asyncPostQueue` consumed by worker goroutines started in `init()` at `internal/webhook/webhook.go:42-55`). The actual outbound HTTP request executes via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**Protection mechanism:** SSRF protection is enforced at dial time by `safeDialContext` — `internal/webhook/webhook.go:59-77`, which is installed as the `http.Transport.DialContext` on the shared `safeClient` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname and rejects any resolved IP that falls within a reserved/private range via `isReservedIP` in `internal/webhook/validate.go:44-54`, checked against `reservedNetworks`/`reservedCIDRs` (loopback, RFC-1918 private ranges, link-local/cloud IMDS, and IPv6 equivalents) defined in `internal/webhook/validate.go:14-23`. This dial-time check (rather than a one-time DNS check at URL-registration time via `ValidateURL` in `internal/webhook/validate.go:62-83`) also defeats DNS-rebinding attacks.
