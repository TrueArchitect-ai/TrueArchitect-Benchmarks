Premise correction — there is no GraphQL schema anywhere in this repository; a search for "graphql" (case-insensitive) across `.go` and `.proto` files, and for `.graphql`/schema files, returns nothing.

Actual API surface — the public API is defined as Protocol Buffers/gRPC services under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are exposed over gRPC and, via gRPC-Gateway/Connect, as a REST/JSON-over-HTTP surface — wired up in `server/router/api/v1/v1.go` (`RegisterGateway`, `server/router/api/v1/v1.go:64` onward), not GraphQL.
