The premise is incorrect — there is no Redis connection. The cache layer is a **purely in-memory implementation** (`store/cache/cache.go`), not backed by Redis or any external store. It is a thread-safe in-memory map with TTL-based expiration.

The default TTL for all cache entries (including user entries) is **10 minutes**, set at `store/cache/cache.go:59` (`DefaultTTL: 10 * time.Minute`). The `Store` creates three `Cache` instances (for instance settings, users, and user settings) all using this same default config (`store/store.go:51–53`).
