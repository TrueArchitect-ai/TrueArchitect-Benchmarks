The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** and served over both **gRPC-Gateway** (REST) and **Connect** (gRPC-compatible). The protobuf service definitions live under `proto/`, with generated Go code in `proto/gen/api/v1/` (e.g., `memo_service.pb.go`, `user_service.pb.go`). The API handlers are implemented in `server/router/api/v1/`, and the gateway and Connect services are registered in `server/router/api/v1/v1.go`.
