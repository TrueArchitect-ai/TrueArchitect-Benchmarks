**Handlers (≥3):**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go` (dispatches `memos.memo.created`)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go` (dispatches `memos.memo.updated`)
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go` (dispatches `memos.memo.deleted`)
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go` (dispatches `memos.memo.comment.created`, and also triggers `memos.memo.created` via its internal `CreateMemo` call)
5. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go` (dispatches `memos.memo.updated`)
6. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go` (dispatches `memos.memo.updated`)

**Convergence function** — `webhook.Post` — `internal/webhook/webhook.go` (line ~120). All paths feed through `webhook.PostAsync` (same file), which enqueues onto a channel drained by worker goroutines that each call `Post` to execute the actual outbound HTTP POST to the user-configured URL.
