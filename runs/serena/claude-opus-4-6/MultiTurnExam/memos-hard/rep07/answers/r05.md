The premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers (gRPC) with gRPC-Gateway for REST/JSON mapping**.

The protobuf service definitions live in `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with REST endpoints declared via `google.api.http` annotations. Generated Go code (gRPC stubs and gateway reverse proxies) is in `proto/gen/api/v1/`. The RPC handlers are implemented in `server/router/api/v1/`.
