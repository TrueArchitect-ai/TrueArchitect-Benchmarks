Memo visibility is enforced at numerous distinct sites across the server:

1. **`checkMemoReadAccess` (single-memo gate)** — `server/router/api/v1/memo_service.go:39` (used by `GetMemo`, `ListMemoComments`)
2. **`ListMemos` query filtering** — `server/router/api/v1/memo_service.go:218` (visibility list / CEL filter based on auth state)
3. **RSS feed generation** — `server/router/rss/rss.go:90,141` (both explore and per-user RSS restrict to `Public` only)
4. **File server attachment access** — `server/router/fileserver/fileserver.go:650` (`checkAttachmentPermission` — gates based on linked memo's visibility)
5. **Sitemap generation** — `server/router/frontend/frontend.go:150` (only `Public` memos appear)
6. **`GetAttachment` API access check** — `server/router/api/v1/attachment_service.go:422` (`checkAttachmentAccess`)
7. **Reaction service (list + upsert)** — `server/router/api/v1/reaction_service.go:29,82`
8. **`ListMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:213`
9. **Comment service (create + list)** — `server/router/api/v1/memo_service_comments.go:33,148`
10. **`ListMemoRelations`** — `server/router/api/v1/memo_relation_service.go:107`
11. **Batch relation converter** — `server/router/api/v1/memo_service_converter.go:182`
12. **SSE event delivery** — `server/router/api/v1/sse_hub.go:134` (`canReceive` filters per subscriber)
13. **User stats** — `server/router/api/v1/user_service_stats.go:83,217`
14. **Notification filtering** — `server/router/api/v1/user_service_notifications.go:302` and `server/notification/email.go:306` (`canViewerAccessMemo`)
15. **Mention inbox suppression** — `server/router/api/v1/memo_mention_helpers.go:56` (`canUserAccessMentionContext`)
