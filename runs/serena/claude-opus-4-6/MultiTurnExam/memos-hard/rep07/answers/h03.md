**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` struct that all providers must return.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete implementation, providing OAuth2 token exchange and user-info fetching.

OAuth2 is the only protocol that ships; the protobuf enum (`IdentityProvider.Type` in `proto/store/idp.proto`) has only `OAUTH2` beyond the unspecified default, and the config `oneof` in `IdentityProviderConfig` contains only `oauth2_config`.
