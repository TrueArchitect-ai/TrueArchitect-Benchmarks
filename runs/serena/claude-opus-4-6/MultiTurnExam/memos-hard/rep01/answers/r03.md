The question's premise is incorrect. There is no nightly database-cleanup cron job in this codebase. The `internal/scheduler` package exists as a general-purpose scheduling library, but it is not used anywhere in the server or command code — no scheduled jobs are registered at startup. The only background runners are the S3 presign runner (12-hour interval) and the in-memory cache cleanup goroutine (5-minute interval); neither performs database cleanup.
