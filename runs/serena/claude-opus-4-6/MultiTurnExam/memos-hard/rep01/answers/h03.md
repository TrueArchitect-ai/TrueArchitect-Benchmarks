**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` struct that every provider implementation must return.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete implementation that ships, providing an OAuth2 identity provider with `ExchangeToken` and `UserInfo` methods.

The protobuf layer (`proto/store/idp.proto`) reinforces this structure with a `oneof config` in `IdentityProviderConfig` whose sole variant is `OAuth2Config`, and the server dispatches to the OAuth2 implementation via a type switch in `server/router/api/v1/auth_service_sso.go`.
