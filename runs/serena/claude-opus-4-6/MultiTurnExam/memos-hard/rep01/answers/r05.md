The question's premise is incorrect. There is no GraphQL schema in this codebase. The public API is defined using **Protocol Buffers (protobuf)** and served as a **gRPC** API with an HTTP/JSON gateway.

The API surface is defined in `.proto` files under `proto/api/v1/`, including services like:
- `MemoService` — `proto/api/v1/memo_service.proto`
- `UserService` — `proto/api/v1/user_service.proto`
- `AttachmentService` — `proto/api/v1/attachment_service.proto`
- `AuthService` — `proto/api/v1/auth_service.proto`
- `IdentityProviderService` — `proto/api/v1/idp_service.proto`
- `InstanceService` — `proto/api/v1/instance_service.proto`

These are implemented as gRPC service handlers in `server/router/api/v1/` and exposed over HTTP via a gRPC-Gateway (registered in `server/server.go`). Additional native HTTP routes exist for file serving (`server/router/fileserver/`) and RSS feeds (`server/router/rss/`).
