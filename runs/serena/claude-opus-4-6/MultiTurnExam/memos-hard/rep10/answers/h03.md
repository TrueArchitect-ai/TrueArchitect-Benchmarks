**Abstraction package:** `internal/idp` — defines the shared `IdentityProviderUserInfo` struct in `internal/idp/idp.go`, which serves as the common contract all providers must produce.

**Implementation package:** `internal/idp/oauth2` — the only concrete protocol that ships is **OAuth2**, implemented in `internal/idp/oauth2/oauth2.go`. It provides `ExchangeToken` (with PKCE support) and `UserInfo` methods, mapping provider responses to the common `IdentityProviderUserInfo` via configurable field mappings.

The extensibility point is the `IdentityProvider.Type` enum and `oneof config` in `proto/store/idp.proto`, which currently only defines `OAUTH2 = 1`. The dispatch happens via a type switch in `server/router/api/v1/auth_service_sso.go`.
