The principal distinct enforcement sites for memo visibility:

1. **`checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39` (central reusable gate: archived → creator-only; non-PUBLIC → requires auth; PRIVATE → creator-only)
2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go:218–227` (anonymous → PUBLIC only; authenticated viewing others → PUBLIC+PROTECTED; own memos → all)
3. **`ListMemoComments` query-level filtering** — `server/router/api/v1/memo_service_comments.go:148,157–160` (calls `checkMemoReadAccess` on parent, then applies visibility filter on child comments)
4. **`CreateMemoComment` inline check** — `server/router/api/v1/memo_service_comments.go:41` (PRIVATE parent → only creator/superuser may comment)
5. **`ListMemoReactions` inline check** — `server/router/api/v1/reaction_service.go:30–41` (non-PUBLIC requires auth; PRIVATE → creator/superuser only)
6. **`UpsertMemoReaction` inline check** — `server/router/api/v1/reaction_service.go:83` (PRIVATE → creator/superuser only)
7. **`ListMemoAttachments` inline check** — `server/router/api/v1/memo_attachment_service.go:214–224`
8. **`checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go:422` (delegates to parent memo's visibility for linked attachments)
9. **`checkAttachmentPermission` (file server)** — `server/router/fileserver/fileserver.go:649` (HTTP file-serving layer; also supports share-token bypass)
10. **`ListMemoRelations` query-level filtering** — `server/router/api/v1/memo_relation_service.go:108–112` (CEL filter on visibility)
11. **RSS feeds** — `server/router/rss/rss.go:90,141` (`VisibilityList = [Public]` for both global and per-user feeds)
12. **Sitemap** — `server/router/frontend/frontend.go:150` (`VisibilityList = [Public]`)
13. **SSE event delivery (`canReceive`)** — `server/router/api/v1/sse_hub.go:134` (PRIVATE events only delivered to creator/admin)
14. **Notification visibility gate (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go:302` and duplicated in `server/notification/email.go:306`
15. **Mention notification filtering (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go:56`
16. **Stats query filtering** — `server/router/api/v1/user_service_stats.go:84,218`
