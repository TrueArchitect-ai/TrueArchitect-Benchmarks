The premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (REST). The `.proto` service definitions live under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server exposes both gRPC and REST (via gRPC-Gateway) endpoints, plus a **Connect** protocol surface, all registered in `server/router/api/v1/v1.go`.
