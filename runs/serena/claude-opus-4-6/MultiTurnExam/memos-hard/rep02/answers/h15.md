Memo visibility is enforced at these distinct sites:

1. **`checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39` — gRPC-level guard used by `GetMemo` and related RPC handlers; blocks non-public memos for unauthenticated users and private memos for non-owners.

2. **`ListMemos` query filtering** — `server/router/api/v1/memo_service.go:218–227` — restricts the `VisibilityList` on the query itself so unauthenticated users only see `Public` and non-owner authenticated users see `Public`+`Protected`.

3. **`ListMemoReactions`** — `server/router/api/v1/reaction_service.go:29–41` — checks memo visibility before listing reactions on a memo.

4. **`UpsertMemoReaction`** — `server/router/api/v1/reaction_service.go:82–85` — checks memo visibility before allowing a reaction to be created.

5. **`ListMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:213–225` — checks memo visibility before listing a memo's attachments.

6. **`checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go:422` — enforces memo visibility when accessing a linked attachment via the gRPC attachment service.

7. **`checkAttachmentPermission`** (file server) — `server/router/fileserver/fileserver.go:650` — enforces memo visibility for HTTP file serving of attachment binaries, including share-token fallback.

8. **RSS feed** — `server/router/rss/rss.go:90` — restricts feed queries to `Public`-only memos.

9. **Sitemap** — `server/router/frontend/frontend.go:150` — restricts sitemap to `Public`-only memos.

10. **User stats query filtering** — `server/router/api/v1/user_service_stats.go:84,90,218,220` — restricts stats queries by visibility based on the requesting user's identity.
