The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase.

The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, with definitions in `proto/api/v1/`. Key service definitions include:

- `proto/api/v1/memo_service.proto` — memo CRUD operations
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/auth_service.proto` — authentication
- `proto/api/v1/attachment_service.proto` — attachments
- `proto/api/v1/idp_service.proto` — identity providers
- `proto/api/v1/instance_service.proto` — instance settings

These protos are compiled into Go code under `proto/gen/api/v1/`. The server also exposes a **gRPC-Gateway** REST/JSON interface (generated `*.pb.gw.go` files) and **Connect** endpoints (generated under `proto/gen/api/v1/apiv1connect/`), making the API accessible over both gRPC and HTTP/JSON. Additionally, native HTTP routes are used for file serving (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), and the frontend/sitemap (`server/router/frontend/`).
