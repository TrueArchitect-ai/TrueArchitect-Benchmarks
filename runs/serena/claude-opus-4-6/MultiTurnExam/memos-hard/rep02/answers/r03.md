There is no nightly database-cleanup cron job. The only scheduled background runner is the S3 presign runner (`server/runner/s3presign/runner.go`), which refreshes presigned URLs every 12 hours. The only "cleanup" in the codebase is the in-memory cache eviction loop (`store/cache/cache.go:200`), which runs every 5 minutes to remove expired cache entries — not a database cleanup. The project includes a scheduler package (`internal/scheduler/`) but it is not used for any database maintenance tasks.
