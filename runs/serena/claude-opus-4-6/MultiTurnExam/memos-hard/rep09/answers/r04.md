The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. Webhook delivery uses a plain Go buffered channel (`asyncPostQueue`) declared in `internal/webhook/webhook.go` (around line 40). Four goroutines are started in an `init()` function (same file, lines 42–55) to drain this channel, each calling the `Post` function synchronously. Payloads are enqueued via `PostAsync` (line 184), which does a non-blocking send on the channel (capacity 128), dropping events if the queue is full. The entire mechanism is in-process with no external messaging infrastructure.
