The premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers / gRPC** with an HTTP/JSON gateway. The protobuf service definitions live in `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `idp_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server exposes both a gRPC interface (via Connect in `server/router/api/v1/v1.go`) and an HTTP REST gateway (registered via `RegisterGateway` in `server/server.go:88`).
