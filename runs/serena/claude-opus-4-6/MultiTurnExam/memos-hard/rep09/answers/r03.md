The premise is incorrect — there is no nightly database-cleanup job in this codebase. While an `internal/scheduler` package exists (`internal/scheduler/doc.go`), it is a general-purpose cron scheduler library and is never instantiated or used by the server. The doc comments reference a `"daily-cleanup"` example, but that is only illustrative documentation, not actual application code. The server's only background tasks are the S3 presign runner (`server/runner/s3presign/`) and the memo payload runner (`server/runner/memopayload/`), neither of which performs database cleanup.
