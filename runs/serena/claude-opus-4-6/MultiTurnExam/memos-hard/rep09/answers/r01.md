The premise is incorrect — there is no Redis connection in this codebase. The cache layer is an in-memory implementation using a custom `Cache` struct defined in `store/cache/cache.go`. It uses a Go `sync.Map` with a TTL-based eviction goroutine.

The user cache is instantiated in `store/store.go` (around line 29) via `cache.NewCache()`. The TTL for user entries is configured as `10 * time.Minute` with a max of 1000 entries, as set in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, etc.) anywhere in the project.
