The question's premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed cache in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, or otherwise).

The `Cache` struct (line 67) uses Go's `sync.Map` for storage with TTL-based expiration. The default TTL for all cache entries (including user entries) is **10 minutes**, set in `DefaultConfig()` at `store/cache/cache.go:59`. The `Store` creates its caches (including `userCache`) using `cache.NewDefault()` which applies this default config (`store/store.go`). Cleanup of expired entries runs every 5 minutes (line 60), and the cache holds at most 1000 items (line 61).
