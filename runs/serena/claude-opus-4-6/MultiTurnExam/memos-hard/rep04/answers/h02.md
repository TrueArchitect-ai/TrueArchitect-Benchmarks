**Protection mechanism** — A two-layer SSRF guard using reserved-IP blocking in `internal/webhook/validate.go`:

1. **At registration time**: `ValidateURL()` (`internal/webhook/validate.go:62`) resolves the hostname and rejects any URL whose IPs fall within reserved CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents — lines 14–23).
2. **At dial time**: `safeDialContext()` (`internal/webhook/webhook.go:59`) re-resolves the hostname and checks resolved IPs against the same `isReservedIP()` function (`validate.go:44`), defeating DNS rebinding attacks where a name resolves to a public IP at registration but a private IP later. The `safeClient` HTTP client (`webhook.go:32`) uses this as its transport dialer.
