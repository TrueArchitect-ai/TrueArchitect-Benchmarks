The question's premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (HTTP/REST transcoding).

The API surface is defined in proto files under `proto/api/v1/`, for example:
- `proto/api/v1/memo_service.proto` — memo CRUD operations
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/auth_service.proto` — authentication
- `proto/api/v1/idp_service.proto` — identity providers
- `proto/api/v1/attachment_service.proto` — attachments

Generated Go code lives in `proto/gen/api/v1/`. The gRPC services are registered and served with HTTP bindings in `server/router/api/v1/v1.go`. Additionally, the server exposes plain HTTP routes for file serving (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and frontend assets (`server/router/frontend/frontend.go`).
