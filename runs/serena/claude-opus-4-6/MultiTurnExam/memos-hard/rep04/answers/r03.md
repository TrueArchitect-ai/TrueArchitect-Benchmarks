The question's premise is incorrect — there is no nightly database-cleanup cron job in this codebase. While an `internal/scheduler` package exists (`internal/scheduler/scheduler.go`), it is never imported or used by any production code — it only appears in its own tests and examples. The server's only scheduled background tasks are the S3 presign runner (every 12 hours via a simple `time.Ticker`, in `server/runner/s3presign/runner.go`) and an in-memory cache cleanup (every 5 minutes, in `store/cache/cache.go`). Neither is a database-cleanup job, and neither uses cron scheduling.
