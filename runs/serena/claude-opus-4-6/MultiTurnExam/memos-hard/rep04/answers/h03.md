**Abstraction package:** `internal/idp` — defines the `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that all concrete providers must return.

**Implementation package:** `internal/idp/oauth2` — the only concrete protocol implementation that ships, providing OAuth2 token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`). No OIDC, SAML, or LDAP implementations exist in the codebase.
