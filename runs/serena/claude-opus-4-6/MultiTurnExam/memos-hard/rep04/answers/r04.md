The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. Webhook delivery uses a plain Go buffered channel as its in-process queue, not an external message broker.

The queue is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in `init()` (lines 42–55) to consume from this channel and call `Post()` for each payload. `PostAsync()` (line 184) enqueues payloads onto this channel. The entire mechanism is in-memory within the server process — no external broker is involved.
