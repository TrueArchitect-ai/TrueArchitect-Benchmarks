The premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed via both gRPC-native and REST (gRPC-Gateway) endpoints.

The API service definitions are in `proto/api/v1/`, with key files including:
- `proto/api/v1/memo_service.proto` — memo CRUD operations
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/idp_service.proto` — identity provider management
- `proto/api/v1/attachment_service.proto` — attachment operations

Generated Go code (gRPC stubs, gateway handlers, and Connect handlers) lives under `proto/gen/api/v1/`. The gRPC-Gateway provides a REST/JSON surface at `/api/v1/...`, and Connect handlers are registered alongside in `server/router/api/v1/v1.go`.
