The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), not an external message queue.

The channel is declared in `internal/webhook/webhook.go` as a `chan *WebhookRequestPayload` with a capacity of 128. Worker goroutines are started in an `init()` function in the same file (lines 42–55), which spawns 4 goroutines that drain the channel and call `Post` for each payload. Producers enqueue payloads via `PostAsync` (lines 182–196), which sends to the channel in a non-blocking select.
