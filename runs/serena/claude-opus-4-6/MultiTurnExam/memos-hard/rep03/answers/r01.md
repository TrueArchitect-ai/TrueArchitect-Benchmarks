The premise is incorrect — there is no Redis connection. The cache layer is a **pure in-memory implementation** using `sync.Map` with TTL-based expiration, defined in `store/cache/cache.go`. There is no Redis (or any external cache) anywhere in the codebase.

The user cache is constructed in `store/store.go:52` with `cache.New(cacheConfig)`, where `cacheConfig` (lines 40–45) sets a **`DefaultTTL` of 10 minutes**. This same TTL applies to user entries — when `Store.GetUser` or `Store.ListUsers` stores a user in the cache (`store/user.go:151,167,143`), it calls `Set()` which uses the default TTL (`store/cache/cache.go:94`).
