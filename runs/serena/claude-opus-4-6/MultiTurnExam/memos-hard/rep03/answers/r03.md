The premise is incorrect — there is no nightly database-cleanup cron job. While the codebase includes a cron scheduler package (`internal/scheduler/`), it is not used for any database cleanup task. The only scheduled background runner related to maintenance is the S3 presign runner (`server/runner/s3presign/runner.go`), which runs on a 12-hour `time.Ticker`, not a cron schedule, and refreshes presigned URLs rather than cleaning up the database. The cache layer has its own in-memory cleanup loop (`store/cache/cache.go:200`), but that is purely for evicting expired cache entries, not database rows.
