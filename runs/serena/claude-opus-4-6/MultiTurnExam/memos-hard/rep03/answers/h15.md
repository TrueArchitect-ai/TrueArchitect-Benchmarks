Memo visibility is enforced at these distinct sites:

1. **`checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39` — used by `GetMemo` (line 356) and `ListMemoComments`; checks visibility for individual memo retrieval in the gRPC API.

2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go:218–227` — restricts the query's `VisibilityList`/filter based on whether the caller is anonymous, viewing their own memos, or viewing another user's memos.

3. **`checkAttachmentPermission`** (file server) — `server/router/fileserver/fileserver.go:650` — enforces memo visibility when serving attachment files over HTTP (lines 677, 699).

4. **`checkAttachmentAccess`** (gRPC API) — `server/router/api/v1/attachment_service.go:422` — enforces memo visibility for gRPC attachment access (lines 445, 451).

5. **`ListMemoReactions` / `UpsertMemoReaction`** inline checks — `server/router/api/v1/reaction_service.go:30–41` and `server/router/api/v1/reaction_service.go:82–85` — check memo visibility before listing or creating reactions.

6. **`ListMemoAttachments`** inline check — `server/router/api/v1/memo_attachment_service.go:214–225` — checks memo visibility before listing a memo's attachments.

7. **RSS feed** — `server/router/rss/rss.go:90` — restricts to `store.Public` only when building the RSS feed.
