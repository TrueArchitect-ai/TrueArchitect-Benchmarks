The premise is incorrect — there is no nightly database-cleanup job in this codebase. The `internal/scheduler/` package exists but is not used for any database maintenance tasks. The only background runners wired into server startup are the S3 presign runner (refreshes pre-signed URLs every 12 hours, `server/runner/s3presign/runner.go`) and the memo payload runner (`server/runner/memopayload/runner.go`). The only "cleanup" activity is the in-memory cache eviction loop in `store/cache/cache.go`, which removes expired entries every 5 minutes — this is purely in-process cache maintenance, not a database cleanup job.
