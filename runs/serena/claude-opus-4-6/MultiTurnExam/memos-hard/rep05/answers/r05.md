The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** and served over **gRPC** (with a gRPC-Gateway for REST/HTTP and Connect-RPC support).

The API surface is defined in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, etc.). Generated Go code lives in `proto/gen/api/v1/`. The gRPC services are registered and served via `server/router/api/v1/v1.go`, which wires up both the Connect-RPC handlers and the gRPC-Gateway HTTP mux.
