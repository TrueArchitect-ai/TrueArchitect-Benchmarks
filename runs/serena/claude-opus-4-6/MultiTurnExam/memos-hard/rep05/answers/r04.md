The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel**, not an external message queue.

The "queue" is declared in `internal/webhook/webhook.go` as `asyncPostQueue` — a `chan *WebhookRequestPayload` with a buffer capacity of 128. Four goroutines are launched in `init()` (same file) to drain the channel and call `Post()` for each payload. `PostAsync` enqueues payloads into this channel. There are no external broker dependencies in `go.mod` and no broker-related code anywhere in the repository.
