The major distinct enforcement sites for memo visibility, grouped by server surface:

**gRPC API — memo access:**
- `checkMemoReadAccess` (reusable gate for GetMemo/ListMemoComments) — `server/router/api/v1/memo_service.go:39`
- `ListMemos` query-time visibility filtering — `server/router/api/v1/memo_service.go:218–227`
- `CreateMemoComment` private-memo gate — `server/router/api/v1/memo_service_comments.go:41`
- `ListMemoComments` memo filter — `server/router/api/v1/memo_service_comments.go:157–161`

**gRPC API — related entities:**
- `ListMemoReactions` / `UpsertMemoReaction` visibility check — `server/router/api/v1/reaction_service.go:29–41, 82–85`
- `ListMemoAttachments` visibility check — `server/router/api/v1/memo_attachment_service.go:213–225`
- `checkAttachmentAccess` (gRPC GetAttachment) — `server/router/api/v1/attachment_service.go:419–455`
- `ListMemoRelations` memo filter — `server/router/api/v1/memo_relation_service.go:107–112`
- Relation batch conversion filter — `server/router/api/v1/memo_service_converter.go:182–187`

**File server:**
- `checkAttachmentPermission` (HTTP binary serving, incl. share-token fallback) — `server/router/fileserver/fileserver.go:649–704`

**RSS:**
- Public-only filtering in `GetRSS` and `GetUserRSS` — `server/router/rss/rss.go:90, 141`

**Sitemap:**
- Public-only filtering — `server/router/frontend/frontend.go:150`

**SSE (Server-Sent Events):**
- `canReceive` delivery filter — `server/router/api/v1/sse_hub.go:134–144`

**Stats:**
- Visibility filtering in `ListAllUserStats` / `GetUserStats` — `server/router/api/v1/user_service_stats.go:83–91, 217–221`

**Notifications:**
- `canViewerAccessMemo` in notification payloads — `server/router/api/v1/user_service_notifications.go:302–316`
- `canViewerAccessMemo` in email — `server/notification/email.go:306–320`
- `canUserAccessMentionContext` for @-mention gating — `server/router/api/v1/memo_mention_helpers.go:56–71`
