The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (gRPC)** with a gRPC-Gateway REST translation layer. The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, etc.), code is generated into `proto/gen/api/v1/`, and the gRPC services are registered and served via the API layer in `server/router/api/v1/`. An OpenAPI spec is also generated and embedded at `proto/openapi_embed.go`.
