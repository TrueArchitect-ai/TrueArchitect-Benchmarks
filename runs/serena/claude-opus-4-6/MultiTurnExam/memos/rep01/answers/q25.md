CEL (Common Expression Language) engine, implemented in `internal/filter/` (parser in `internal/filter/engine.go` using `github.com/google/cel-go/cel`).

The engine parses the filter string into a dialect-agnostic intermediate representation (IR), then `AppendConditions` (`internal/filter/helpers.go`) calls the SQL renderer (`internal/filter/render.go`) which switches on the dialect (DialectSQLite, DialectPostgres, DialectMySQL) to emit the appropriate SQL WHERE clauses and bind arguments, which each driver passes in — e.g., `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` in `store/db/sqlite/memo.go`.
