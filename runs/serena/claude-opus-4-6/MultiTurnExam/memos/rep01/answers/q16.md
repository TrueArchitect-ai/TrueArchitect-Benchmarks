When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` rows where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — `attachment` rows linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo, each of which triggers the same relation and attachment cleanup.
