Interceptor: `web/src/connect.ts` — the `authInterceptor` attaches a `Bearer` token via the `Authorization` header on every request and handles transparent refresh on `Unauthenticated` errors.

Token kinds: **access tokens** (short-lived JWTs, stored in-memory and localStorage), **refresh tokens** (longer-lived, sent via cookie with `credentials: include`), and **personal access tokens** (PATs, prefixed string-based tokens).

Backend validation package: `server/auth/` — `authenticator.go` provides `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT` to validate each token type.
