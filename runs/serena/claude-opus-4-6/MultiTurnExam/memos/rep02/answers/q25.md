Engine: **CEL (Common Expression Language)** via `cel-go`, implemented in `internal/filter/engine.go` (parser) with the condition tree defined in `internal/filter/ir.go` and SQL rendering in `internal/filter/render.go`.

The CEL filter string is parsed into an AST, then converted into a dialect-agnostic condition tree (`Condition`); the renderer (`internal/filter/render.go`) translates that tree into SQL WHERE clauses with dialect-specific branches (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`), which each dialect driver invokes via `filter.AppendConditions()` (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`).
