When a memo is deleted, the store layer (`store/memo.go:140-159`) deletes these records before the memo row itself:

1. **Memo relations** (where the memo is the source `memo_id`) — via `DeleteMemoRelation`
2. **Memo relations** (where the memo is the target `related_memo_id`) — via `DeleteMemoRelation`
3. **Attachments** linked to the memo — via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (child memos related via `MemoRelationComment`) are recursively deleted before the parent memo itself, and each of those comment deletions triggers the same store-layer cleanup of relations and attachments.
