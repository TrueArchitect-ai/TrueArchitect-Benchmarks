The following tables are affected when `DeleteMemo` runs:

- **memo_relation** — explicitly deleted in `store/memo.go` (both source and target sides)
- **attachment** — explicitly deleted in `store/memo.go` (via `Store.DeleteAttachment`)
- **memo_share** — deleted by SQL `ON DELETE CASCADE` foreign key on `memo_id` (defined in `store/migration/sqlite/LATEST.sql`)
- **memo** — the memo row itself, deleted last in `store/memo.go`

Additionally, at the API layer (`server/router/api/v1/memo_service.go`), comment memos (related via `memo_relation` with type `Comment`) are recursively deleted before the parent memo, which triggers the same cascade for each comment.
