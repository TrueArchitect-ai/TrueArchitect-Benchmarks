Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/engine.go` (the `Engine` struct wrapping a `cel.Env`).

The CEL filter string is parsed into an AST by the engine, then converted to a dialect-agnostic IR (`internal/filter/ir.go`), and rendered into dialect-specific SQL WHERE clauses by `internal/filter/render.go` using a `DialectName` parameter (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`). Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with its dialect constant — e.g. `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` in `store/db/sqlite/memo.go` — which parses the CEL expressions, renders them to the target SQL dialect, and appends the resulting conditions and bind arguments to the query's WHERE clause.
