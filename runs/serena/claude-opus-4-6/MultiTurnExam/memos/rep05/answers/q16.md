Before deleting the memo row itself, the store layer (`store/memo.go:140-159`) deletes:

1. **Memo relations** where this memo is the source (`MemoID`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **memo comments** (memos related via `MemoRelationComment`) are recursively deleted before calling `Store.DeleteMemo`.
