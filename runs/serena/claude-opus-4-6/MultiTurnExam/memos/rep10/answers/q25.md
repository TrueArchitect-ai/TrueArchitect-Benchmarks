CEL (Common Expression Language) via `github.com/google/cel-go` — engine in `internal/filter/engine.go`, parser in `internal/filter/parser.go`.

The filter string is compiled by the CEL engine into a dialect-agnostic IR (`internal/filter/ir.go`), then `AppendConditions` (`internal/filter/helpers.go`) calls `Engine.CompileToStatement` which renders the IR into dialect-specific SQL WHERE clauses and parameterized args using `internal/filter/render.go`, which switches on `DialectSQLite`, `DialectPostgres`, or `DialectMySQL` to emit the correct SQL syntax for each backend.
