Before deleting the memo row itself, the store layer (`store/memo.go:140-159`) deletes:

1. **memo relations** (where the memo is the source — `memo_relation.memo_id`)
2. **memo relations** (where the memo is the target — `memo_relation.related_memo_id`)
3. **attachments** linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo's `Store.DeleteMemo` call. The database schema also cascades deletion to **memo_share** rows via a `ON DELETE CASCADE` foreign key constraint (`store/migration/sqlite/LATEST.sql`).
