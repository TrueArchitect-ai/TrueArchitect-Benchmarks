The store layer's `DeleteMemo` method (`store/memo.go:140`) deletes the following records before the memo row itself:

1. **memo relations** (where the memo is the source) — via `DeleteMemoRelation` with `MemoID`
2. **memo relations** (where the memo is the target) — via `DeleteMemoRelation` with `RelatedMemoID`
3. **attachments** linked to the memo — via `DeleteAttachment` for each attachment

Additionally, at the API handler level (`server/router/api/v1/memo_service.go:567–577`), **memo comments** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo itself.
