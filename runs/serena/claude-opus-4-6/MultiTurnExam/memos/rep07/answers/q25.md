**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/engine.go` (the `Engine` struct parses CEL filter strings into a dialect-agnostic condition tree).

**Mechanism:** Each dialect driver (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (defined in `internal/filter/helpers.go`) passing the parsed filter expressions, the engine, and a dialect identifier (e.g. `filter.DialectSQLite`, `filter.DialectPostgres`, `filter.DialectMySQL`). The renderer in `internal/filter/render.go` walks the parsed CEL AST and emits dialect-specific SQL WHERE clauses with parameterized arguments, switching on the dialect name to handle syntax differences (e.g. quoting, string functions, JSON operators) between SQLite, PostgreSQL, and MySQL.
