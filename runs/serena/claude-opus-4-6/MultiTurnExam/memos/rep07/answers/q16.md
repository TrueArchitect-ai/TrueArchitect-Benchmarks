When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **memo_relation** records — where the memo is the source (`memo_id`)
2. **memo_relation** records — where the memo is the target (`related_memo_id`)
3. **attachments** linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via a `Comment`-type relation) are recursively deleted before the parent memo, and each of those deletions triggers the same store-level cleanup.
