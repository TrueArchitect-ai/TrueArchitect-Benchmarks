Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/engine.go`.

The CEL engine parses the filter string into a parsed expression AST (`engine.go`), which is then converted into a dialect-agnostic intermediate representation (`internal/filter/ir.go`). The `AppendConditions` function (`internal/filter/helpers.go`) drives rendering, and a dialect-aware SQL renderer (`internal/filter/render.go`) translates the IR into SQL WHERE clauses with dialect-specific variations (SQLite, MySQL, PostgreSQL), using the `DialectName` passed by each driver (e.g., `filter.DialectSQLite` in `store/db/sqlite/memo.go`).
