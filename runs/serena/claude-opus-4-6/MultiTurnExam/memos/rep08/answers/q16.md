When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` rows where the memo is either the source (`memo_id`) or the target (`related_memo_id`)
2. **Attachments** — `attachment` rows linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (child memos linked via a `Comment`-type relation) are recursively deleted before the parent memo, which in turn triggers the same relation and attachment cleanup for each comment.
