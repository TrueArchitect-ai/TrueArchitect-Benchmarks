When a memo is deleted, the store layer (in `store/memo.go`, `DeleteMemo` at line 140) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` records where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go`, line 567–577), **comment memos** (child memos linked via `MemoRelationComment`) are recursively deleted before the parent memo, and each of those deletions triggers the same store-level cleanup of relations and attachments.
