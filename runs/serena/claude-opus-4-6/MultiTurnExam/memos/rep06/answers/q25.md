The filter uses **CEL (Common Expression Language)** parsed by `github.com/google/cel-go/cel`, wrapped in a custom `Engine` at `internal/filter/engine.go`.

Each dialect driver (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with its respective dialect name (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`), which compiles the CEL expression into a dialect-agnostic condition tree (IR in `internal/filter/ir.go`), then renders it into dialect-specific SQL WHERE clauses via the renderer in `internal/filter/render.go`, using per-field/per-dialect expression mappings defined in the schema (`internal/filter/schema.go`).
