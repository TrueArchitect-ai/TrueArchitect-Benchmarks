Before deleting the memo row itself, the store layer (`store/memo.go:140-158`) deletes:

1. **Memo relations** — `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`)
2. **Attachments** — `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo, and each of those recursive deletions also cleans up its own relations and attachments through the same store method.
