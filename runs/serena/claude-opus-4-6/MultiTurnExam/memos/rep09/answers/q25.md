Engine: CEL (Common Expression Language) via `cel-go`, implemented in `internal/filter/` (entry point `engine.go`, parser in `parser.go`, IR in `ir.go`, schema in `schema.go`, SQL renderer in `render.go`).

The filter string is parsed as a CEL expression against a memo-specific schema, normalized into a dialect-agnostic intermediate representation (IR), then rendered into a SQL WHERE-clause fragment with dialect-specific placeholders and syntax by `render.go`; each dialect driver calls `filter.AppendConditions()` passing its dialect constant (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`) to produce the appropriate SQL (e.g., `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`).
