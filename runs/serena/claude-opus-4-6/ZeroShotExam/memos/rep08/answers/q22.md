When a memo is created, the handler `CreateMemo` in `server/router/api/v1/memo_service.go` calls **`DispatchMemoCreatedWebhook`** — defined in **`server/router/api/v1/memo_service_webhooks.go`** — which delegates to `dispatchMemoRelatedWebhook` in the same file. That helper fetches the creator's webhooks from the store and calls `webhook.PostAsync` to enqueue each delivery.

The HTTP delivery is performed by the **`internal/webhook`** package (`internal/webhook/webhook.go`), which posts the JSON payload via `Post`.

The signing mechanism is **HMAC-SHA256** following the Standard Webhooks specification: the signing key is derived from a `whsec_`-prefixed base64 secret (or a raw string), and the HMAC is computed over `msgID + "." + timestamp + "." + body`. Three headers are set: `webhook-id`, `webhook-timestamp`, and `webhook-signature` (prefixed `v1,` with the base64-encoded digest).
