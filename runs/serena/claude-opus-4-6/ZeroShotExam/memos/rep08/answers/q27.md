The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built assets (from `web/` → `server/router/frontend/dist/`) directly into the Go binary at compile time. At runtime, the embedded filesystem is served through Echo's static file middleware with an SPA fallback for client-side routing.

**Mechanism:** `//go:embed` (Go embed); **File:** `server/router/frontend/frontend.go`
