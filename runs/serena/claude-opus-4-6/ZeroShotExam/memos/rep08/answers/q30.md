Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **created**: `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
- **updated**: `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
- **deleted**: `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
- **comment created**: `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)

The first three delegate to a shared private helper `dispatchMemoRelatedWebhook` in the same file; `DispatchMemoCommentCreatedWebhook` has its own implementation but follows the same pattern.

All four converge for delivery at **`webhook.PostAsync`** in `internal/webhook/webhook.go`. `PostAsync` enqueues the payload onto a buffered channel (`asyncPostQueue`, capacity 128), which is drained by 4 goroutine workers started in `init()`. Each worker calls `webhook.Post` (same file), which marshals the payload to JSON, optionally signs it with HMAC-SHA256, and sends it as an HTTP POST via a safe HTTP client.
