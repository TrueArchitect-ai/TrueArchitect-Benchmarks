Four memo lifecycle events dispatch webhooks, all with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to the private helper `dispatchMemoRelatedWebhook` (same file), which resolves the memo creator's webhooks and enqueues them. `DispatchMemoCommentCreatedWebhook` handles its own webhook lookup inline but follows the same enqueue path.

All four converge for delivery at **`Post`** in `internal/webhook/webhook.go`. Specifically, every dispatch calls `webhook.PostAsync()` (line 184), which enqueues the payload onto a buffered channel. Worker goroutines drain that channel and call `webhook.Post()` (line 120), which performs the actual HTTP POST delivery (including HMAC-SHA256 signing if a secret is configured).
