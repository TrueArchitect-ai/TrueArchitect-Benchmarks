`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines the core memo CRUD mutations and queries (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemo`, `useMemos`, `useInfiniteMemos`, etc.) using TanStack React Query hooks. It imports and calls `memoServiceClient` from `web/src/connect.ts`, which is a Connect-RPC client created via `createClient(MemoService, transport)` against the generated `MemoService` descriptor in `web/src/types/proto/api/v1/memo_service_pb.ts`.
