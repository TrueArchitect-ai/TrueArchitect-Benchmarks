Here is the complete call chain for creating a memo, one hop per line:

1. **Frontend mutation hook:** `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` (uses `useMutation`, calls `memoServiceClient.createMemo(...)`)
2. **Client (Connect-RPC transport):** `web/src/connect.ts` — `memoServiceClient` created via `createClient(MemoService, transport)`
3. **Proto RPC definition:** `proto/api/v1/memo_service.proto` — `service MemoService { rpc CreateMemo(CreateMemoRequest) returns (Memo) }`
4. **Server handler:** `server/router/api/v1/memo_service.go` — `(*APIV1Service).CreateMemo()`, which calls `s.Store.CreateMemo(ctx, create)`
5. **Store method:** `store/memo.go` — `(*Store).CreateMemo()`, which delegates to `s.driver.CreateMemo(ctx, create)` (interface defined in `store/driver.go`)
6. **Dialect driver (e.g. PostgreSQL):** `store/db/postgres/memo.go` — `(*DB).CreateMemo()`, which executes `INSERT INTO memo (uid, creator_id, content, visibility, payload, ...) VALUES ($1, $2, ...) RETURNING id, created_ts, updated_ts, row_status`

(SQLite and MySQL drivers exist at `store/db/sqlite/memo.go` and `store/db/mysql/memo.go` respectively.)
