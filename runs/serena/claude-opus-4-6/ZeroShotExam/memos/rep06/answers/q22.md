When a memo is created, the handler `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which is defined in `server/router/api/v1/memo_service_webhooks.go`. This function delegates to `dispatchMemoRelatedWebhook` (same file), which fetches the creator's webhooks and calls `webhook.PostAsync` for each one.

**`DispatchMemoCreatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go`; delivery package: **`net/http`** (Go standard library, via a custom `http.Client` in `internal/webhook/webhook.go`); signing mechanism: **HMAC-SHA256** following the Standard Webhooks spec (signature sent in a `webhook-signature` header as `v1,<base64-hmac>`, computed over `msgID.timestamp.body`, with the key derived from a `whsec_`-prefixed secret).
