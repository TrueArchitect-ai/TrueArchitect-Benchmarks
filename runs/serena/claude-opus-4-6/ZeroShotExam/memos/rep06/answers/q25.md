**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

**Mechanism:** `Engine.Compile()` parses the filter string into a CEL AST, `buildCondition()` (`internal/filter/parser.go`) converts that AST into an intermediate `Condition` tree (`internal/filter/ir.go`), and `renderer.Render()` (`internal/filter/render.go`) walks the IR to emit dialect-specific SQL (SQLite, PostgreSQL, MySQL) with appropriate placeholder styles, JSON operators, and function calls — invoked per-driver via `filter.AppendConditions()` in each dialect's `ListMemos` implementation (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`).
