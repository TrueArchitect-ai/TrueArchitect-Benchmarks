The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built `dist/` directory into the Go binary at compile time. This is wired in `server/router/frontend/frontend.go`, where `var embeddedFiles embed.FS` holds the embedded files (line 21) and they are served as static assets through Echo's `StaticDirectoryHandler` with an SPA fallback middleware that routes unmatched paths to `index.html`.
