Four memo lifecycle events dispatch webhooks, each with a dedicated dispatch function defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to a shared private helper `dispatchMemoRelatedWebhook` (also in `memo_service_webhooks.go`), while `DispatchMemoCommentCreatedWebhook` handles its own webhook resolution but follows the same pattern.

All four converge on **`webhook.Post`** in `internal/webhook/webhook.go` for delivery. Specifically, each dispatch function calls **`webhook.PostAsync`** (`internal/webhook/webhook.go:184`), which enqueues the payload onto a buffered async channel (`asyncPostQueue`). Worker goroutines (spawned in `init()`) drain the queue and call **`webhook.Post`** (`internal/webhook/webhook.go:120`), which performs the actual HTTP POST with JSON payload and optional HMAC-SHA256 signing.
