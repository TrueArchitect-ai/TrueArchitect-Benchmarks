`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all core memo CRUD hooks (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemo`, `useMemos`, etc.) using `@tanstack/react-query`. Each hook delegates to `memoServiceClient`, which is a Connect-RPC client created in `web/src/connect.ts` via `createClient(MemoService, transport)` where `MemoService` is the generated protobuf service descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
