The compiled React frontend is served via **Go's `//go:embed` directive**, which embeds the `dist/` directory (built by Vite) directly into the Go binary at compile time. At runtime, Echo's `middleware.StaticWithConfig` serves these embedded files, with a custom SPA fallback middleware for client-side routing.

**Mechanism:** `//go:embed`; **File:** `server/router/frontend/frontend.go`
