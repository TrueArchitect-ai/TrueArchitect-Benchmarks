The compiled React frontend is served in production via Go's `embed.FS` directive, which embeds the `dist/` directory directly into the Go binary at compile time. The embedded files are then served using Echo's `middleware.StaticWithConfig` along with an SPA fallback middleware.

**Mechanism:** `go:embed` (with `embed.FS`)  
**File:** `server/router/frontend/frontend.go`

In that file, `//go:embed dist/*` (line ~20) embeds the built frontend assets, and the `Serve` method wires up Echo's static middleware to serve them. The frontend service is registered on the server in `server/server.go` (line ~72).
