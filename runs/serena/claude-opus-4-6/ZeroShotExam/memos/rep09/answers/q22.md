When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to the private helper `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`. This helper fetches the creator's webhooks from the store, builds a payload for each, and calls `webhook.PostAsync` from the `internal/webhook` package.

**`dispatchMemoRelatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go`; delivery package **`internal/webhook`** (`webhook.Post` / `webhook.PostAsync`); signing mechanism: **HMAC-SHA256 following the Standard Webhooks spec** (signed content is `msgID.timestamp.body`, with headers `webhook-id`, `webhook-timestamp`, and `webhook-signature` set to `v1,<base64-HMAC>`; secrets use the `whsec_<base64>` format).
