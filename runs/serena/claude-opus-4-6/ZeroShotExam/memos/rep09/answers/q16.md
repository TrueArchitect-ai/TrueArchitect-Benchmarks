When a memo is deleted through the API, the store layer (`store/memo.go:140-158`) deletes the following kinds of records before the memo row itself:

1. **Memo relations** — `MemoRelation` records where the memo is the source (`MemoID`), via `DeleteMemoRelation` (line 142)
2. **Memo relations** — `MemoRelation` records where the memo is the target (`RelatedMemoID`), via `DeleteMemoRelation` (line 145)
3. **Attachments** — all `Attachment` records linked to the memo, found via `ListAttachments` and deleted individually via `DeleteAttachment` (lines 149–157)
