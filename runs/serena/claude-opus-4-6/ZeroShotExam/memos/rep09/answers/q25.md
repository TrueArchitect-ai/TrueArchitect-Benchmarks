**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`; **path:** `internal/filter/engine.go` (with parser in `internal/filter/parser.go`, IR types in `internal/filter/ir.go`, schema in `internal/filter/schema.go`, and renderer in `internal/filter/render.go`).

**Mechanism:** The `Engine.CompileToStatement()` method compiles the filter string through `cel.Env.Compile()`, converts the CEL AST into a dialect-agnostic IR condition tree via `buildCondition()` (`internal/filter/parser.go`), then a `renderer` (`internal/filter/render.go`) walks that IR and emits dialect-specific SQL fragments (with appropriate placeholder styles, JSON operators, and function calls for SQLite/PostgreSQL/MySQL), which `filter.AppendConditions()` (`internal/filter/helpers.go`) appends as parameterized WHERE clauses in each database driver's `ListMemos` implementation (`store/db/{sqlite,postgres,mysql}/memo.go`).
