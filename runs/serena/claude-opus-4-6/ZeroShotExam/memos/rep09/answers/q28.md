**Background workers/runners the server starts:**

- **S3 Presign Runner** (`server/runner/s3presign/runner.go`) — 12-hour `time.NewTicker` (plus an immediate `RunOnce` at startup); re-presigns S3 attachment URLs nearing expiry. Started explicitly in `server/server.go:startBackgroundRunners`.
- **Async Email Workers (×2)** (`internal/email/email.go`) — channel-driven (`init()` spawns 2 goroutines consuming from a buffered channel); process emails enqueued via `SendAsync()`.
- **Async Webhook Workers (×4)** (`internal/webhook/webhook.go`) — channel-driven (`init()` spawns 4 goroutines consuming from a buffered channel); POST webhook payloads enqueued via `PostAsync()`.
- **Cache Cleanup** (`store/cache/cache.go`) — `time.NewTicker` at a configurable interval (default 5 minutes); evicts expired/over-capacity entries.

**Scheduling infrastructure present but NOT used by the server:**

- **`internal/scheduler/` package** — A fully-featured cron-expression-based job scheduler with middleware support (recovery, logging, timeout), timezone awareness, and graceful shutdown. It is **never imported** outside its own directory; zero references from `server/`, `cmd/`, or any other package. It is entirely dead code.
- **`server/runner/memopayload/Runner` struct** (`server/runner/memopayload/runner.go`) — Defines a `Runner` with a `RunOnce()` method for batch-rebuilding all memo payloads, but the `Runner` is **never instantiated**. Only the standalone function `RebuildMemoPayload()` from the same package is used (called inline during memo create/update in `server/router/api/v1/memo_service.go`).
