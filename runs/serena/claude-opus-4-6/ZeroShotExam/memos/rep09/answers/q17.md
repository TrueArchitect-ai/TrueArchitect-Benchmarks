`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This module defines all memo CRUD React Query hooks (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemo`, `useMemos`). It uses the generated ConnectRPC client `memoServiceClient`, which is created in `web/src/connect.ts` via `createClient(MemoService, transport)` against the `MemoService` descriptor generated from the protobuf definition at `web/src/types/proto/api/v1/memo_service_pb.ts`.
