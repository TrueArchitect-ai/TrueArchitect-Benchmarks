Four memo lifecycle events dispatch webhooks, all with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to a shared helper `dispatchMemoRelatedWebhook` (same file), which builds the payload and calls `webhook.PostAsync`. `DispatchMemoCommentCreatedWebhook` follows the same pattern but resolves the related memo's creator separately before also calling `webhook.PostAsync`.

All four converge for delivery at **`internal/webhook/webhook.go`** — specifically the `Post` function (line ~120), which performs the actual HTTP POST with optional HMAC-SHA256 signing. `PostAsync` (line ~184) enqueues payloads onto a buffered channel (`asyncPostQueue`), and background goroutines consume from that channel and call `Post` for synchronous HTTP delivery.
