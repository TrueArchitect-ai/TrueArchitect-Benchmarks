The compiled React frontend is served via Go's **`embed.FS`** — the Vite build output is placed into `server/router/frontend/dist/` (via `pnpm release`), and a `//go:embed dist/*` directive in `server/router/frontend/frontend.go` bakes those files into the binary. At runtime, Echo's `middleware.StaticWithConfig` serves assets from the embedded filesystem, with an SPA fallback middleware to return `index.html` for client-side routes.
