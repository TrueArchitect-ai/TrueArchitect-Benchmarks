The filter engine is **CEL (Common Expression Language)**, powered by `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`. The `Engine.Compile` method parses the CEL filter string into a dialect-agnostic `Condition` IR tree (built in `internal/filter/parser.go` via `buildCondition`), and then `Program.Render` (in `internal/filter/render.go`) walks that tree with a `renderer` that switches on a `DialectName` (`sqlite`, `mysql`, `postgres`) to emit dialect-specific SQL fragments and placeholder args — each per-dialect store (e.g. `store/db/sqlite/memo.go`) calls `filter.AppendConditions` passing its dialect constant (e.g. `filter.DialectSQLite`) so the renderer produces the correct SQL.

**Engine:** CEL (`google/cel-go`); **Path:** `internal/filter/` (engine in `engine.go`, parser in `parser.go`, renderer in `render.go`). **Mechanism:** The engine compiles a CEL expression into a dialect-agnostic condition IR tree, then `render.go` switches on the `DialectName` (`sqlite`/`mysql`/`postgres`) to emit dialect-appropriate SQL fragments with placeholders, invoked per-store via `filter.AppendConditions` (in `helpers.go`).
