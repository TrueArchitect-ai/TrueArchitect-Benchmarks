Four memo lifecycle events dispatch webhooks, all with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three converge through a shared private method `dispatchMemoRelatedWebhook` (also in `memo_service_webhooks.go`), which resolves the memo creator's webhooks, builds payloads via `convertMemoToWebhookPayload`, and calls `webhook.PostAsync()`. The comment-created dispatcher loops over webhooks directly but also calls `webhook.PostAsync()`.

All four ultimately converge for delivery at **`Post()` in `internal/webhook/webhook.go`**. The path is:

1. `webhook.PostAsync()` (line ~184) enqueues the payload onto a buffered channel (`asyncPostQueue`, capacity 128).
2. A pool of 4 goroutine workers (started in `init()`, line ~42) dequeue from that channel and call `webhook.Post()` (line ~120), which performs the actual HTTP POST delivery (with HMAC-SHA256 signing and SSRF-safe transport).
