This file contains all the core memo CRUD hooks (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemo`, `useMemos`, etc.), each calling `memoServiceClient` — a Connect RPC client instantiated in `web/src/connect.ts` via `createClient(MemoService, transport)`, where `MemoService` is the generated service descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
