**Engine:** CEL (Common Expression Language), parsed by `github.com/google/cel-go/cel`.

**Path:** `internal/filter/engine.go` (the `Engine` struct and `Compile` method), with the parser in `internal/filter/parser.go` and the SQL renderer in `internal/filter/render.go`; schema/dialect definitions live in `internal/filter/schema.go`.

**Mechanism:** The `Engine.Compile` method uses the CEL environment (`cel.Env`) to parse and compile the filter string into a CEL AST, then `buildCondition` (`internal/filter/parser.go`) walks the `exprv1.Expr` AST to produce a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`), and finally the `renderer.Render` method (`internal/filter/render.go`) traverses that condition tree and emits dialect-specific SQL (with per-dialect branches for SQLite, MySQL, and PostgreSQL as defined by the `DialectName` enum in `internal/filter/schema.go`) for constructs like JSON array access, timestamp extraction, regex, and text matching.
