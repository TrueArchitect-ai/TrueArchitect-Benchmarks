Four memo lifecycle events dispatch webhooks, with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
- **memo updated**: `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
- **memo deleted**: `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
- **memo comment created**: `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)

All four public dispatch functions call a shared private helper `dispatchMemoRelatedWebhook` (same file), which in turn calls `webhook.PostAsync()` in `internal/webhook/webhook.go`.

**Delivery convergence point:** All webhooks converge at `PostAsync` (`internal/webhook/webhook.go`), which enqueues payloads onto a buffered channel. Background worker goroutines drain that channel and call `Post` (`internal/webhook/webhook.go`) to perform the actual HTTP POST delivery (with optional HMAC-SHA256 signing).
