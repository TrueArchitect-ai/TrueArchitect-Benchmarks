**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`; **path:** `internal/filter/engine.go`.

**Mechanism:** The engine compiles the CEL filter string into a CEL AST, converts it to a protobuf `ParsedExpr`, then `buildCondition` in `internal/filter/parser.go` walks that expression tree to produce a dialect-agnostic IR (defined in `internal/filter/ir.go`), which the `renderer` in `internal/filter/render.go` walks again to emit dialect-specific SQL (placeholders, JSON operators, text-matching functions, etc.) for SQLite, MySQL, or Postgres—selected by the dialect constant passed from each store driver (e.g. `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`) through `filter.AppendConditions` in `internal/filter/helpers.go`.
