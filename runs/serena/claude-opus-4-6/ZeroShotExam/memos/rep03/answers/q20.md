The mechanism is **SSE (Server-Sent Events)**. The hub is implemented at `server/router/api/v1/sse_hub.go` (with the HTTP handler in `sse_handler.go` and helpers in `sse_event_helpers.go`). The `APIV1Service` holds the hub instance, wired in `server/router/api/v1/v1.go`.

The memo handlers that broadcast through the hub are:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` |
| `UpsertMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.upserted` |
| `DeleteMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.deleted` |

**SSE; `server/router/api/v1/sse_hub.go`; `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`, `UpsertMemoReaction`, `DeleteMemoReaction`**
