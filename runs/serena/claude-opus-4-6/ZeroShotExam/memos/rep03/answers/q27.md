The compiled React frontend is served via Go's **`//go:embed`** directive. In `server/router/frontend/frontend.go`, the built assets (output by `pnpm release` into `server/router/frontend/dist/`) are embedded into the Go binary at compile time:

```go
//go:embed dist/*
var embeddedFiles embed.FS
```

The `FrontendService.Serve()` method then uses Echo's `StaticWithConfig` middleware to serve the embedded filesystem, with an SPA fallback middleware for client-side routing.

**Mechanism:** `//go:embed`; **File:** `server/router/frontend/frontend.go`
