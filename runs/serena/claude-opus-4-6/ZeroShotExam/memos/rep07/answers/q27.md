The compiled React frontend is served via Go's `//go:embed` directive. The Vite build outputs into `server/router/frontend/dist/`, and that directory is embedded into the Go binary at compile time with `//go:embed dist/*`. At runtime, the embedded filesystem is served using Echo's static middleware with an SPA fallback that serves `index.html` for non-API, non-file routes.
