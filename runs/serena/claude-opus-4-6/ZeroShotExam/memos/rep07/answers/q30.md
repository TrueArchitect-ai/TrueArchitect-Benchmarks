Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three share a private helper `dispatchMemoRelatedWebhook` (same file, line 48) that resolves the memo creator and iterates over their webhooks. The comment variant does its own creator lookup but follows the same pattern.

All four converge on **`webhook.PostAsync`** in `internal/webhook/webhook.go` (line 184), which enqueues the payload onto a buffered channel (`asyncPostQueue`). Worker goroutines drain that channel and call **`Post`** (line 120 in the same file), which performs the actual HTTP POST delivery (with optional HMAC-SHA256 signing via the Standard Webhooks format).
