**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) (`github.com/google/cel-go`), wrapped by a project-local package at `internal/filter/` — the core entry point is `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile()` method uses `cel.Env.Compile()` to parse the filter string into a CEL AST, then `buildCondition()` in `internal/filter/parser.go` walks that AST into a dialect-agnostic Condition IR tree (types in `internal/filter/ir.go`), and finally `renderer.Render()` in `internal/filter/render.go` walks the IR and emits dialect-specific SQL (parameterized by `DialectSQLite`, `DialectPostgres`, or `DialectMySQL`), with each store driver (`store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calling the shared `filter.AppendConditions()` helper from `internal/filter/helpers.go` passing its dialect constant to inject the resulting SQL fragments into the WHERE clause.
