When a memo is created, the handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to `dispatchMemoRelatedWebhook` — both defined in `server/router/api/v1/memo_service_webhooks.go`. This builds a payload for each of the creator's webhooks and enqueues it via `webhook.PostAsync`.

**Dispatcher** — `DispatchMemoCreatedWebhook` (via `dispatchMemoRelatedWebhook`); `server/router/api/v1/memo_service_webhooks.go`

**Delivery package** — `internal/webhook` (specifically `webhook.Post` / `webhook.PostAsync` in `internal/webhook/webhook.go`)

**Signing mechanism** — HMAC-SHA256 following the Standard Webhooks spec: the signature is computed over `msgID + "." + timestamp + "." + body`, base64-encoded, and sent as `webhook-signature: v1,<base64>` along with `webhook-id` and `webhook-timestamp` headers. Secrets use a `whsec_`-prefixed base64 format.
