When `DeleteMemo` runs, the following database tables are affected:

1. **`memo`** — the memo row itself is deleted (`store/db/sqlite/memo.go:239`)
2. **`memo_relation`** — all relation rows where the memo is either `memo_id` or `related_memo_id` are deleted (`store/db/sqlite/memo_relation.go:148-150`), called from `store/memo.go:142-147`
3. **`attachment`** — all attachments linked to the memo are deleted (`store/db/sqlite/attachment.go:212`), called from `store/memo.go:149-157`

At the service layer (`server/router/api/v1/memo_service.go:567-581`), comment memos (related via `MemoRelationComment`) are also recursively deleted via `Store.DeleteMemo`, which cascades the same three tables for each comment memo.
