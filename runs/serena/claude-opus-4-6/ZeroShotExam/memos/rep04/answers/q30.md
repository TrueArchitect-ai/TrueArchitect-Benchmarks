Four memo lifecycle events dispatch webhooks, all with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to the private helper `dispatchMemoRelatedWebhook` (same file, line 48). All four ultimately call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues payloads onto a buffered channel (`asyncPostQueue`). Worker goroutines drain that channel and converge on the synchronous delivery function `Post` (`internal/webhook/webhook.go:120`), which performs the actual HTTP POST to the target URL.
