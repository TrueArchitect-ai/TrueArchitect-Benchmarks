**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (a ConnectRPC `Interceptor`) attaches an `Authorization: Bearer <token>` header to every outgoing RPC call, handles `Unauthenticated` errors by refreshing and retrying once, and proactively refreshes tokens before they expire.

**Token kinds:**
- **Access token** — short-lived (15 min), stored in-memory and in `localStorage` (`memos_access_token`), sent as a Bearer token on every request.
- **Refresh token** — long-lived (30 days), stored as an HTTP-only cookie (`memos_refresh`); the frontend never reads it directly but sends it implicitly via `credentials: "include"` when calling the `RefreshToken` RPC.

**Backend validation package:** `server/auth` — specifically `server/auth/token.go` (JWT generation/parsing with `golang-jwt/jwt/v5`), `server/auth/authenticator.go` (the `Authenticator` that resolves Bearer tokens via `Authenticate()`), and `server/auth/extract.go` (extracts tokens from headers/cookies). The Connect RPC auth guard that calls into this package lives at `server/router/api/v1/connect_interceptors.go` (`AuthInterceptor`).
