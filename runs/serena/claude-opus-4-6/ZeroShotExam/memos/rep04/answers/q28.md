**Background workers/runners the server actually starts, and their scheduling:**

- **S3 Presign Runner** — `time.NewTicker` every 12 hours (also runs once synchronously at startup). Refreshes presigned URLs for S3-stored attachments. Started explicitly in `server/server.go:153-173` via `startBackgroundRunners()`.
- **Webhook Dispatch Workers (x4)** — channel-driven worker pool consuming from a buffered channel (cap 128), started via `init()` in `internal/webhook/webhook.go:42-55`. Triggered on-demand when `PostAsync()` enqueues a payload.
- **Email Dispatch Workers (x2)** — channel-driven worker pool consuming from a buffered channel (cap 128), started via `init()` in `internal/email/email.go:14-36`. Triggered on-demand when `SendAsync()` enqueues a mail request.
- **Cache Cleanup Goroutines (x3)** — `time.NewTicker` every 5 minutes, one per cache instance created in `store/store.go:51-53` (`instanceSettingCache`, `userCache`, `userSettingCache`). Sweeps expired entries from in-memory caches.
