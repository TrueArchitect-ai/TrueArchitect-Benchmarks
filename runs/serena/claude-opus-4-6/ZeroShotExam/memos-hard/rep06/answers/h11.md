The data layer is the `store` package (`store/*.go`), which defines persistent entity types such as `User`, `Memo`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `IdentityProvider`, and `InstanceSetting`.

Counting the number of distinct packages **outside** `store/` that reference each entity type (including its associated helper types like `FindUser`, `UpdateMemo`, etc.):

1. **1st: `User`** — referenced from ~7 packages (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)
2. **2nd: `Memo`** — referenced from ~7 packages (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

Both are referenced from 7 packages, but `User` edges out as the most broadly referenced entity by file count (43 files vs. 31 files for `Memo`), largely because `User` is needed in authentication and authorization paths (`server/auth`) that `Memo` is not.
