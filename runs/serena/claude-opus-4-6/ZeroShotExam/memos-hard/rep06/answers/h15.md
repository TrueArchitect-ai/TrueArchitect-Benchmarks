Here are the distinct memo visibility enforcement sites:

1. **Single-memo read access gate (`checkMemoReadAccess`)** — `server/router/api/v1/memo_service.go`
2. **List memos query-time filtering (`ListMemos`)** — `server/router/api/v1/memo_service.go`
3. **Comment creation visibility check (`CreateMemoComment`)** — `server/router/api/v1/memo_service_comments.go`
4. **Comment listing visibility filter (`ListMemoComments`)** — `server/router/api/v1/memo_service_comments.go`
5. **Memo relation listing visibility filter (`ListMemoRelations`)** — `server/router/api/v1/memo_relation_service.go`
6. **Batch relation conversion visibility filter (`batchConvertMemoRelations`)** — `server/router/api/v1/memo_service_converter.go`
7. **Reaction listing/upserting visibility check (`ListMemoReactions`, `UpsertMemoReaction`)** — `server/router/api/v1/reaction_service.go`
8. **Memo attachment listing visibility check (`ListMemoAttachments`)** — `server/router/api/v1/memo_attachment_service.go`
9. **Attachment access check in API layer (`checkAttachmentAccess`)** — `server/router/api/v1/attachment_service.go`
10. **Attachment access check in file server (`checkAttachmentPermission`)** — `server/router/fileserver/fileserver.go`
11. **Share-token–based access bypass (`GetMemoByShare`)** — `server/router/api/v1/memo_share_service.go`
12. **User stats visibility filtering (`ListAllUserStats`, `GetUserStats`)** — `server/router/api/v1/user_service_stats.go`
13. **RSS feed visibility filtering (`GetExploreRSS`, `GetUserRSS`)** — `server/router/rss/rss.go`
14. **SSE event delivery filtering (`canReceive`)** — `server/router/api/v1/sse_hub.go`
15. **Database-level SQL `WHERE visibility IN (...)` clause** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
16. **Update memo visibility constraint (comment forced to parent visibility)** — `server/router/api/v1/memo_service.go`
