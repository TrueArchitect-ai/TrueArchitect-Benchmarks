**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` implemented in `internal/markdown/markdown.go:356`. The `ExtractAll` method parses the memo's markdown content into a goldmark AST and walks it in a single pass to populate a `storepb.MemoPayload_Property` struct. The snippet (a separate derived field) is computed by `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83`, which calls `markdownService.GenerateSnippet()` at `internal/markdown/markdown.go:264`.

**Triggers (operations that cause recomputation):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting a new memo.
2. **UpdateMemo** (when the `"content"` path is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` after the content changes.
3. **RunOnce** (batch rebuild) — `server/runner/memopayload/runner.go:27` iterates over all memos in batches and calls `RebuildMemoPayload` on each, then persists the updated payload via `Store.UpdateMemo`.

**Extracted properties** (defined in `proto/store/memo.proto:15-22` and `proto/api/v1/memo_service.proto:272-279`):
- `has_link` (bool) — whether the content contains any markdown link (`KindLink`)

- `has_code` (bool) — whether the content contains code blocks or code spans (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
