The premise is incorrect — this repository (Memos) does **not** have a GraphQL API. There is no GraphQL schema anywhere in the codebase.

The actual API surface is **gRPC + REST (via grpc-gateway)**, defined in **Protocol Buffer (`.proto`) files** under `proto/api/v1/`. The service definitions are:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto` (shared types)

Each `.proto` file uses `google.api.http` annotations to expose RESTful HTTP endpoints (e.g., `GET /api/v1/memos`, `POST /api/v1/memos`). Code generation is driven by `proto/buf.gen.yaml` using Buf, which produces:

1. **Go gRPC server/client stubs** (`*_grpc.pb.go`)
2. **grpc-gateway reverse proxies** (`*.pb.gw.go`) that translate REST/JSON to gRPC
3. **Connect-RPC** Go code (`apiv1connect/`)
4. **OpenAPI specs** (via `google-gnostic-openapi`)
5. **TypeScript types** for the frontend (`web/src/types/proto/`)
