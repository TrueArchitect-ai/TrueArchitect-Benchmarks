Here are the distinct enforcement sites for memo visibility:

1. **Individual memo read access gate** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`)
2. **Memo listing (ListMemos) visibility filtering** — `server/router/api/v1/memo_service.go` (`ListMemos`)
3. **Comment listing visibility filtering** — `server/router/api/v1/memo_service_comments.go` (`ListMemoComments`)
4. **Comment creation access check** — `server/router/api/v1/memo_service_comments.go` (`CreateMemoComment`)
5. **Reaction listing/upserting access check** — `server/router/api/v1/reaction_service.go` (`ListMemoReactions`, `UpsertMemoReaction`)
6. **Memo attachment listing access check** — `server/router/api/v1/memo_attachment_service.go` (`ListMemoAttachments`)
7. **Attachment access via memo visibility (API layer)** — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess`)
8. **File server attachment permission check** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission`)
9. **SSE event delivery filtering** — `server/router/api/v1/sse_hub.go` (`canReceive`)
10. **Relation listing visibility filtering** — `server/router/api/v1/memo_relation_service.go` (`ListMemoRelations`)
11. **Batch relation conversion filtering** — `server/router/api/v1/memo_service_converter.go` (`batchConvertMemoRelations`)
12. **RSS feed (public-only)** — `server/router/rss/rss.go` (`GetRSS`, `GetUserRSS`)
13. **Sitemap (public-only)** — `server/router/frontend/frontend.go` (`getSitemapXML`)
14. **User stats visibility filtering** — `server/router/api/v1/user_service_stats.go` (`ListAllUserStats`, `GetUserStats`)
15. **Notification payload suppression (API)** — `server/router/api/v1/user_service_notifications.go` (`canViewerAccessMemo`)
16. **Notification payload suppression (email)** — `server/notification/email.go` (`canViewerAccessMemo`)
17. **Mention notification access check** — `server/router/api/v1/memo_mention_helpers.go` (`canUserAccessMentionContext`, `shouldSkipMentionInbox`)
18. **Share-based memo access (bypasses normal visibility)** — `server/router/api/v1/memo_share_service.go` (`GetMemoByShare`)
19. **Database-level visibility filter (SQLite/Postgres/MySQL)** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
