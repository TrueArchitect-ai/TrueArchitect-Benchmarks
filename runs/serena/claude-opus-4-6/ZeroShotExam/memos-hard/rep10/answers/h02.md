The outbound webhook delivery executes in the `Post` function at `internal/webhook/webhook.go` (with `PostAsync` feeding payloads into a buffered channel drained by worker goroutines that call `Post`). `Post` builds an HTTP POST request and sends it via a custom `safeClient`.

Protection against SSRF (targeting internal network addresses) is implemented in `internal/webhook/validate.go`, which provides two layers:

1. **Static URL validation at registration time** — `ValidateURL` (`internal/webhook/validate.go`) DNS-resolves the webhook hostname and checks every returned IP against `isReservedIP`, which tests against a list of reserved CIDRs (loopback, RFC-1918 private ranges, link-local/169.254, IPv6 loopback/ULA/link-local) defined in the `reservedCIDRs` variable in the same file.

2. **Runtime dial-time check** — The `safeClient` in `internal/webhook/webhook.go` uses a custom `safeDialContext` that re-resolves DNS and re-checks every IP against `isReservedIP` at connection time, defeating DNS rebinding attacks where a hostname resolves to a public IP during validation but a private IP during delivery.

**delivery function** — `Post` in `internal/webhook/webhook.go`; **protection mechanism** — SSRF guard via `isReservedIP`/`reservedCIDRs`/`safeDialContext` in `internal/webhook/validate.go` (and the runtime dial hook in `internal/webhook/webhook.go`)
