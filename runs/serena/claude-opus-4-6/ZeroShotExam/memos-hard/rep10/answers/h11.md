The data/persistence layer is the `store` package (`store/`). The persistent entity types defined there (the primary structs, not the Find/Update/Delete query helpers) are: `User`, `Memo`, `Attachment`, `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`, and `UserSetting`.

Counting distinct Go packages outside `store/` that reference each `store.<Type>`:

1. **`User`** — referenced from **7 packages** (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)
2. **`Memo`** — referenced from **6 packages** (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

**1st: User (~7 packages); 2nd: Memo (~6 packages)**
