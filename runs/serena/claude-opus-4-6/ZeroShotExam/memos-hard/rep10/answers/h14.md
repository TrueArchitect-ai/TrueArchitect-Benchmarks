**Extracted properties:** The `Property` object (stored in `MemoPayload.Property`) extracts: `HasLink` (whether content contains links), `HasTaskList` (whether content contains task checkboxes), `HasCode` (whether content contains code blocks/spans), `HasIncompleteTasks` (whether any task checkbox is unchecked), and `Title` (text from the first H1 heading if the first block-level element is an H1). Additionally, `Tags` (all `#tag` occurrences, deduplicated) are extracted and stored in `MemoPayload.Tags`. The `Snippet` (a plain-text summary of the content, truncated to 64 characters) is computed at read time rather than stored.
