The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package is a **general-purpose cron scheduling library** — it does not define any actual application jobs. The "cleanup" references are only illustrative **examples** in documentation and test files:

- `internal/scheduler/doc.go` shows a `"daily-cleanup"` job with schedule `"0 2 * * *"` as a **doc comment example** of how to use the API.
- `internal/scheduler/example_test.go` registers a `"cleanup"` job scheduled at `"0 2 * * *"` as a **test example** demonstrating multiple job registration.

Neither of these is an actual scheduled database-cleanup job — they are sample code showing how the scheduler library works. No real database-cleanup job is scheduled anywhere in this codebase.
