The outbound delivery executes in the `Post` function (with `PostAsync` for async dispatch via a buffered channel) — `internal/webhook/webhook.go`.

SSRF protection is a two-layer mechanism in the same package:

1. **Registration-time URL validation** — `ValidateURL` in `internal/webhook/validate.go` resolves the hostname and checks every IP against a list of reserved CIDRs (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local) defined in `reservedCIDRs` in the same file.
2. **Dial-time IP validation** — `safeDialContext` in `internal/webhook/webhook.go` re-resolves and re-checks IPs at connection time (via a custom `DialContext` on the `http.Transport`), defeating DNS-rebinding attacks where a name resolves to a public IP at registration but a private IP at request time.

**delivery function** — `internal/webhook/webhook.go`; **protection mechanism** — `internal/webhook/validate.go` (with a dial-time complement in `internal/webhook/webhook.go`)
