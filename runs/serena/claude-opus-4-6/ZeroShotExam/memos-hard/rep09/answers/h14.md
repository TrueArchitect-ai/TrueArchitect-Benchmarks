**Triggers:**
1. **Memo creation** — called in `CreateMemo` at `server/router/api/v1/memo_service.go:108`.
2. **Memo update (content change)** — called in `UpdateMemo` at `server/router/api/v1/memo_service.go:447`, only when `"content"` is in the update field mask.
3. **Batch rebuild** — `RunOnce` in the same runner file iterates all memos in batches of 100 and recomputes payloads (a migration/repair path, not automatic on startup).

**Extracted properties** (stored in `MemoPayload.Property`, defined in `proto/store/memo.proto`):
- **`title`** (string) — extracted from the first child node of the document only if it is an H1 heading, with inline formatting stripped to plain text.
- **`has_link`** (bool) — whether any link node exists.
- **`has_code`** (bool) — whether any code block, fenced code block, or inline code span exists.
- **`has_task_list`** (bool) — whether any GFM task checkbox exists.
- **`has_incomplete_tasks`** (bool) — whether any unchecked (`- [ ]`) task checkbox exists.
- **`tags`** ([]string) — all `#tag` occurrences (excluding those inside links/images), deduplicated.

Additionally, a **`snippet`** is computed on-the-fly at read time (not stored) in `server/router/api/v1/memo_service_converter.go:76` via `GenerateSnippet` — a plain-text truncation of the content (max 64 chars, word-boundary-aware, with ` ...` appended if truncated).
