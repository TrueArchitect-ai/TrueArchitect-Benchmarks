The premise is incorrect — there is **no GraphQL schema** in this repository. The public API is defined using **Protocol Buffers (protobuf) with gRPC and REST** (via `google.api.http` annotations for REST/JSON transcoding).

The API surface is defined by the `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These proto definitions are used to generate both gRPC stubs and an **OpenAPI 3.0 spec** at `proto/gen/openapi.yaml` (produced by `protoc-gen-openapi`). The `buf.gen.yaml` and `buf.yaml` files in `proto/` configure the Buf toolchain for code generation. As the `README.md` states, the project provides "full REST and gRPC APIs for integration."
