**Premise correction:** Memos does **not** have a GraphQL API. There is no GraphQL schema anywhere in the repository.

**Actual API surface:** The public API is defined as **gRPC services with REST/HTTP transcoding** (via grpc-gateway), specified in **Protocol Buffer (`.proto`) files** under `proto/api/v1/`. The service definitions are:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared types)

These `.proto` files use `google.api.http` annotations to map gRPC methods to REST endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). Code generation is configured in `proto/buf.gen.yaml` using Buf, which produces Go gRPC stubs, grpc-gateway reverse proxies, and an OpenAPI spec (`proto/gen/openapi.yaml`), plus TypeScript types for the web frontend. The README confirms the API surface: *"full REST and gRPC APIs for integration."*
