The provider abstraction is defined in the `internal/idp` package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all concrete providers return. The concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements the OAuth2 authorization-code flow (with PKCE support).

**Answer:** `internal/idp`; `internal/idp/oauth2`
