Here are the distinct memo visibility enforcement sites on the server:

1. **Core visibility check function** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`)
2. **GetMemo handler** — `server/router/api/v1/memo_service.go` (calls `checkMemoReadAccess` on memo and parent)
3. **ListMemos handler (query-level filtering)** — `server/router/api/v1/memo_service.go` (sets `VisibilityList` / `Filters` based on caller auth)
4. **ListMemoComments** — `server/router/api/v1/memo_service_comments.go` (calls `checkMemoReadAccess` on parent + visibility filter on comments)
5. **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (blocks commenting on private memos by non-creators)
6. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (inline visibility check)
7. **GetAttachment / checkAttachmentAccess** — `server/router/api/v1/attachment_service.go` (checks visibility of linked memo)
8. **File server (HTTP binary serving)** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission` — independent HTTP-layer enforcement with share-token fallback)
9. **ListMemoReactions** — `server/router/api/v1/reaction_service.go` (inline visibility check)
10. **UpsertMemoReaction** — `server/router/api/v1/reaction_service.go` (blocks reacting to private memos)
11. **ListMemoRelations** — `server/router/api/v1/memo_relation_service.go` (visibility-scoped `memoFilter`)
12. **batchConvertMemoRelations** — `server/router/api/v1/memo_service_converter.go` (constructs visibility-scoped filter for related memos)
13. **GetMemoByShare** — `server/router/api/v1/memo_share_service.go` (token-based access; archived memos excluded)
14. **RSS feeds** — `server/router/rss/rss.go` (queries with `VisibilityList = [Public]` only)
15. **Sitemap generation** — `server/router/frontend/frontend.go` (`getSitemapXML` filters to public memos only)
16. **SSE event delivery** — `server/router/api/v1/sse_hub.go` (`canReceive` filters live-update events by visibility)
17. **User stats (GetUserStats / ListAllUserStats)** — `server/router/api/v1/user_service_stats.go` (visibility-scoped query filtering)
18. **Notification visibility** — `server/router/api/v1/user_service_notifications.go` (`canViewerAccessMemo` hides inaccessible memo content)
19. **Email notification visibility** — `server/notification/email.go` (`canViewerAccessMemo` — duplicate check for email dispatch)
20. **Mention notification filtering** — `server/router/api/v1/memo_mention_helpers.go` (`canUserAccessMentionContext` skips notifications for private memos)
21. **Store/DB layer** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go` (translate `VisibilityList` and CEL filters into SQL `WHERE` clauses)
