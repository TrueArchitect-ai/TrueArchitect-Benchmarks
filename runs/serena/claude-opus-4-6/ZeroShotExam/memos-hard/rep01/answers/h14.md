The derived metadata is computed in `server/runner/memopayload/runner.go` (function `RebuildMemoPayload`, line 74), which delegates to `internal/markdown/markdown.go` (`ExtractAll`, line 268) for a single-pass AST walk over the memo's markdown content. A separate on-the-fly snippet is produced by `GenerateSnippet` in the same markdown package (line 229) and attached during API response conversion in `server/router/api/v1/memo_service_converter.go` (`convertMemoFromStoreWithCreators`, ~line 76).

**Triggers for recomputation:**
- **CreateMemo** (`server/router/api/v1/memo_service.go`, line 108) — called on every new memo (including comments).
- **UpdateMemo** (`server/router/api/v1/memo_service.go`, line 447) — called when the `content` field is in the update mask.
- **Batch rebuild** via `Runner.RunOnce` (`server/runner/memopayload/runner.go`, line 27) — processes all memos in batches of 100 (for migration/repair).
- **Snippet** is not persisted; it is recomputed on every API response that serializes a memo.

**Extracted properties** (persisted in `MemoPayload`, defined in `proto/store/memo.proto`):
- **`tags`** — all `#tag` tokens, deduplicated.
- **`property.has_link`** — whether the content contains any markdown links.
- **`property.has_task_list`** — whether the content contains task-list checkboxes.
- **`property.has_code`** — whether the content contains code blocks or inline code.
- **`property.has_incomplete_tasks`** — whether any task checkboxes are unchecked.
- **`property.title`** — text of the first `# H1` heading if it is the very first block element.

Additionally, **`snippet`** (a plain-text preview of up to 64 characters, truncated at a word boundary with `" ..."`) is computed on-the-fly via `GenerateSnippet` and served as an `OUTPUT_ONLY` field in the API response (`proto/api/v1/memo_service.proto`, line 265–266).
