The premise is incorrect — this repository has no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf) + gRPC with gRPC-Gateway REST transcoding**, not GraphQL.

The API surface is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared message types)

These proto definitions use `google.api.http` annotations to expose RESTful HTTP/JSON endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`) via gRPC-Gateway. Generated Go code (gRPC stubs, gateway bindings) lives in `proto/gen/api/v1/`, and a generated OpenAPI spec is at `proto/gen/openapi.yaml`.
