The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all identity provider implementations must return. The only concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), a generic OAuth2 provider.
