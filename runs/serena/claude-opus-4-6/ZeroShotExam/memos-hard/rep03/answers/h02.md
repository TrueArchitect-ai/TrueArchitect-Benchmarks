The outbound webhook delivery executes in `Post()` at `internal/webhook/webhook.go` (line ~120), which sends the HTTP POST. The async path most callers use is `PostAsync()` (same file, line ~184), which enqueues payloads into a buffered channel drained by worker goroutines that each call `Post()`.

SSRF protection lives in `internal/webhook/validate.go`. Two layers work together:

1. **Registration-time validation** — `ValidateURL()` (`internal/webhook/validate.go`, line ~62) DNS-resolves the hostname and checks every resolved IP against `isReservedIP()`, which blocks RFC-1918 ranges, loopback, link-local (including `169.254.0.0/16` for cloud metadata), and IPv6 equivalents. This is called when webhooks are created/updated in `server/router/api/v1/user_service_webhooks.go`.

2. **Dial-time validation** — `safeDialContext()` (`internal/webhook/webhook.go`, line ~59) is wired into the HTTP transport's `DialContext`. It re-resolves the hostname and re-checks against `isReservedIP()` at connection time, defeating DNS rebinding attacks where a name resolves to a public IP at registration but a private IP at delivery.

**delivery function** — `Post` / `PostAsync` in `internal/webhook/webhook.go`; **protection mechanism** — `isReservedIP` + `ValidateURL` in `internal/webhook/validate.go` and `safeDialContext` in `internal/webhook/webhook.go`
