Here are the distinct enforcement sites for memo visibility, grouped by server surface:

1. **Single-memo read gate (`checkMemoReadAccess`)** — `server/router/api/v1/memo_service.go`
2. **Memo listing query filter (`ListMemos`)** — `server/router/api/v1/memo_service.go`
3. **Comment creation visibility check (`CreateMemoComment`)** — `server/router/api/v1/memo_service_comments.go`
4. **Comment listing visibility filter (`ListMemoComments`)** — `server/router/api/v1/memo_service_comments.go`
5. **Reaction access checks (`ListMemoReactions`, `UpsertMemoReaction`)** — `server/router/api/v1/reaction_service.go`
6. **Attachment access gate (`checkAttachmentAccess` / `GetAttachment`)** — `server/router/api/v1/attachment_service.go`
7. **Attachment listing visibility check (`ListMemoAttachments`)** — `server/router/api/v1/memo_attachment_service.go`
8. **HTTP file server attachment access** — `server/router/fileserver/fileserver.go`
9. **Memo relations visibility filter (`ListMemoRelations`)** — `server/router/api/v1/memo_relation_service.go`
10. **Memo relation conversion filter (`batchConvertMemoRelations`)** — `server/router/api/v1/memo_service_converter.go`
11. **RSS feed (PUBLIC-only filter)** — `server/router/rss/rss.go`
12. **Sitemap generation (PUBLIC-only filter)** — `server/router/frontend/frontend.go`
13. **SSE event delivery filter (`canReceive`)** — `server/router/api/v1/sse_hub.go`
14. **User stats visibility filter** — `server/router/api/v1/user_service_stats.go`
15. **Email notification access check (`canViewerAccessMemo`)** — `server/notification/email.go`
16. **API notification conversion access check (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go`
17. **Mention notification filtering (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go`
18. **Share token bypass (`GetMemoByShare`)** — `server/router/api/v1/memo_share_service.go`
19. **Visibility inheritance on update (comment must match parent)** — `server/router/api/v1/memo_service.go`
20. **Store-level SQL `WHERE` clause (`VisibilityList`)** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
