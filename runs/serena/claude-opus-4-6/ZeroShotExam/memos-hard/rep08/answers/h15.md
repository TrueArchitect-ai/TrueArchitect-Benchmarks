Here are the distinct enforcement sites for memo visibility:

1. **Single-memo access check (`checkMemoReadAccess`)** — `server/router/api/v1/memo_service.go`
2. **ListMemos pre-query visibility filtering** — `server/router/api/v1/memo_service.go`
3. **User stats visibility filtering (`ListAllUserStats`, `GetUserStats`)** — `server/router/api/v1/user_service_stats.go`
4. **SQL store-level `VisibilityList` WHERE clause** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
5. **Memo relation filtering via `MemoFilter` subquery** — `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, `store/db/mysql/memo_relation.go`
6. **ListMemoRelations visibility filter** — `server/router/api/v1/memo_relation_service.go`
7. **Batch relation conversion visibility filter** — `server/router/api/v1/memo_service_converter.go`
8. **ListMemoComments / CreateMemoComment visibility checks** — `server/router/api/v1/memo_service_comments.go`
9. **Attachment access check (`checkAttachmentAccess`)** — `server/router/api/v1/attachment_service.go`
10. **ListMemoAttachments visibility check** — `server/router/api/v1/memo_attachment_service.go`
11. **File server attachment serving** — `server/router/fileserver/fileserver.go`
12. **Reaction visibility checks (`ListMemoReactions`, `UpsertMemoReaction`)** — `server/router/api/v1/reaction_service.go`
13. **SSE event delivery filtering (`canReceive`)** — `server/router/api/v1/sse_hub.go`
14. **RSS feed (PUBLIC-only)** — `server/router/rss/rss.go`
15. **Sitemap generation (PUBLIC-only)** — `server/router/frontend/frontend.go`
16. **Mention/inbox notification suppression (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go`
17. **User notification rendering (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go`
18. **Email notification rendering (`canViewerAccessMemo`)** — `server/notification/email.go`
