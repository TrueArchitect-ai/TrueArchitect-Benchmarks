The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all identity provider implementations must return. The sole concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements OAuth2 token exchange and user-info retrieval.

**`internal/idp`; `internal/idp/oauth2`**
