The premise is incorrect — this repository has **no GraphQL API**. There are zero `.graphql`/`.gql` files, no GraphQL libraries in `go.mod` or `package.json`, and no mentions of "graphql" anywhere in the codebase.

The actual public API is defined using **gRPC with REST bindings auto-generated via grpc-gateway**, all driven from **Protocol Buffer service definitions** in `proto/api/v1/`. Key service protos include:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`

Generated Go gRPC stubs and gateway code live in `proto/gen/api/v1/`, and an auto-generated **OpenAPI 3.0.3** spec is produced at `proto/gen/openapi.yaml` (~4,000 lines documenting ~40 REST endpoints under `/api/v1/`).
