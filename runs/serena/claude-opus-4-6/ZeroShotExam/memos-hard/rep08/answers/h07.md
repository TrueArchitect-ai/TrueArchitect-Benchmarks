The route `GET /file/users/:identifier/avatar` is registered in `server/router/fileserver/fileserver.go` within `RegisterRoutes`. The handler `serveUserAvatar` (line ~168) extracts the username, calls `getUserByUsername` (line ~716 in the same file), which calls `Store.GetUser` (`store/user.go:148`). `GetUser` checks an in-memory user cache, then delegates to `Store.ListUsers` (`store/user.go:138`), which calls `driver.ListUsers` (`store/driver.go:47` interface) — implemented in `store/db/sqlite/user.go`, `store/db/postgres/user.go`, or `store/db/mysql/user.go`, each querying `SELECT ... avatar_url ... FROM user`. The avatar is stored as a base64 data URI directly in the `avatar_url` column. Back in the handler, `parseDataURI` (line ~737) decodes it and `c.Blob` sends the raw image bytes to the browser.
