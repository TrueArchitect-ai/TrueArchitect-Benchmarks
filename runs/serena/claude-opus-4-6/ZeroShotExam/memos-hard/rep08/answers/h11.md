1st: **User** (~7 packages); 2nd: **Memo** (~7 packages)

The persistent entity types are defined as Go structs in the `store/` package (the data layer). Counting distinct packages outside `store/` that reference each:

- **`store.User`** (`store/user.go`) is referenced from **7 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.

- **`store.Memo`** (`store/memo.go`) is referenced from **~7 packages** (6–7 depending on whether you count all Memo-related query types like `FindMemo`): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.

User edges ahead slightly because the primary `store.User` struct itself appears in 7 packages vs. 6 for the primary `store.Memo` struct. The next closest entities (`store.Attachment` at ~4 packages, `store.MemoRelation`/`store.MemoShare`/`store.Inbox` at ~3 each) trail significantly.
