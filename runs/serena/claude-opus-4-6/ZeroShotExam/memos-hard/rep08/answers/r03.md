The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/doc.go`) is a **generic cron scheduling library** — it provides the infrastructure to register and run cron jobs, but it does not define any specific "database-cleanup" job.

The doc comment in `internal/scheduler/doc.go:17–19` shows a `"daily-cleanup"` job with a `"0 2 * * *"` schedule, and `internal/scheduler/example_test.go:98–106` shows a `"cleanup"` job also at `"0 2 * * *"` — but both of these are **illustrative examples** in documentation and test code, not actual application jobs. Neither is named "database-cleanup," and neither is wired into the application's runtime. No production code in the repository registers a database-cleanup (or any cleanup) job with this scheduler.
