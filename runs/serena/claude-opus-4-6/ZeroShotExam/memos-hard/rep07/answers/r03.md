The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in the cron scheduler. The repository contains a general-purpose cron scheduler library (`internal/scheduler/`) but it does not define any production job registrations for database cleanup. The only "cleanup" job that appears is in **`internal/scheduler/example_test.go:97-106`**, which is an illustrative **example/test** (inside `Example_multipleJobs()`) — not an actual scheduled production job. That example registers a job named `"cleanup"` with schedule `"0 2 * * *"` (2:00 AM) that simply prints "Cleaning up old data…" and is not connected to any database. Similarly, the `README.md` references like `"daily-cleanup"` and `"stale-session-cleanup"` are documentation examples, not real configured jobs.
