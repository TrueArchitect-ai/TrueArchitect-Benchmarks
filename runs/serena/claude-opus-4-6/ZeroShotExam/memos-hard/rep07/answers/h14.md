**Computation site:** `server/runner/memopayload/runner.go` — the function `RebuildMemoPayload` calls `markdownService.ExtractAll()` (implemented in `internal/markdown/markdown.go`, the `ExtractAll` method) to walk the memo's Markdown AST in a single pass and populate `memo.Payload`.

**Triggers:**
1. **CreateMemo** — called before persisting at `server/router/api/v1/memo_service.go:108`.
2. **UpdateMemo when content changes** — called at `server/router/api/v1/memo_service.go:436–451` only when the update mask includes `"content"`.
3. **Bulk runner** (`Runner.RunOnce` in `server/runner/memopayload/runner.go:27–72`) — iterates all memos in batches of 100 and rebuilds each payload (available for manual/migration use, not wired into server startup).

**Extracted properties** (persisted in `MemoPayload.Property`, defined in `proto/store/memo.proto`):
- **`tags`** (`[]string`) — all `#tag` tokens found in the AST, deduplicated.
- **`has_link`** (`bool`) — whether the content contains any link node.
- **`has_code`** (`bool`) — whether the content contains a code block, fenced code block, or code span.
- **`has_task_list`** (`bool`) — whether the content contains any task checkbox.
- **`has_incomplete_tasks`** (`bool`) — whether any task checkbox is unchecked.
- **`title`** (`string`) — plain text of the first block-level child if it is an H1 heading (inline formatting stripped); empty otherwise.

Additionally, **`snippet`** (a ≤64-character plain-text summary) is computed on the fly — not persisted — by `GenerateSnippet()` in `internal/markdown/markdown.go:264–346` each time a memo is converted to an API response (`server/router/api/v1/memo_service_converter.go:76–80`). It is marked `OUTPUT_ONLY` in `proto/api/v1/memo_service.proto:265`.
