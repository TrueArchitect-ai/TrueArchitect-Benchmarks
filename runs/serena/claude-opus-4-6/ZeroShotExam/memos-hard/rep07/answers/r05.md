The premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf) + gRPC**, not GraphQL.

The API surface is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/common.proto` — Shared types

These proto definitions use `google.api.http` annotations to expose RESTful HTTP/JSON endpoints (e.g., `GET /api/v1/memos`, `POST /api/v1/memos`) alongside gRPC. Code is generated via Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`) into `proto/gen/`, and the Go server implementation lives in `server/router/api/v1/`.
