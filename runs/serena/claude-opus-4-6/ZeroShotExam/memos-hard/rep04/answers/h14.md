**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go` (line ~74), which calls `markdownService.ExtractAll()` from `internal/markdown/markdown.go` (line ~356). The snippet is computed separately via `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go` (line ~83), which calls `markdownService.GenerateSnippet()` from `internal/markdown/markdown.go` (line ~264).

**Triggers:** Recomputation is triggered on **memo create** (`server/router/api/v1/memo_service.go`, line ~108) and **memo update** when the update mask includes `"content"` (`memo_service.go`, line ~447). The `snippet` field is additionally computed on the fly every time a memo is converted to its API representation for reads (`memo_service_converter.go`, line ~76).

**Extracted properties** (defined in `proto/store/memo.proto` as `MemoPayload.Property` and exposed as `OUTPUT_ONLY` fields in `proto/api/v1/memo_service.proto`):

- **`tags`** (`repeated string`) — `#tag` tokens extracted from the markdown content
- **`has_link`** (`bool`) — whether the content contains any link nodes
- **`has_task_list`** (`bool`) — whether the content contains task list checkboxes
- **`has_code`** (`bool`) — whether the content contains code blocks or code spans
- **`has_incomplete_tasks`** (`bool`) — whether any unchecked task checkboxes exist
- **`title`** (`string`) — text of the first H1 heading if it is the first block-level element
- **`snippet`** (`string`) — a plain-text summary of the content, max 64 characters, truncated at a word boundary (computed on read, not persisted)
