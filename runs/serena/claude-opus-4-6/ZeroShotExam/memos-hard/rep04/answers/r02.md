The premise of the question is incorrect. This repository does not contain any per-user API rate-limiting middleware. There is no rate-limiting package in `go.mod`, no rate-limiting middleware registered in `server/server.go`, and no files anywhere in the codebase that implement or reference API rate limiting. The `server/` directory contains authentication and CORS middleware but nothing related to request rate limits. The `internal/scheduler/middleware.go` file relates to a task scheduler, not API rate limiting.
