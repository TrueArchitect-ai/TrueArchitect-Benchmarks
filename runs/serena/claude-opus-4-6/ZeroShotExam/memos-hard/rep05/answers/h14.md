**Computation site:** `server/runner/memopayload/runner.go` in `RebuildMemoPayload`, which delegates to `internal/markdown/markdown.go` — specifically `ExtractAll()` (single-pass AST walk using goldmark) for the persisted payload, and `GenerateSnippet()` for on-the-fly snippet generation in `server/router/api/v1/memo_service_converter.go` (`convertMemoFromStoreWithCreators`).

**Triggers:**
1. **Memo creation** — `CreateMemo` in `server/router/api/v1/memo_service.go` (~line 108) calls `RebuildMemoPayload` before persisting.
2. **Memo content update** — `UpdateMemo` in the same file (~lines 435–451), only when `"content"` appears in the update field mask.
3. **Batch rebuild** — `Runner.RunOnce()` in `server/runner/memopayload/runner.go` iterates all memos in batches of 100 and rebuilds each payload (a migration/repair path, not run at startup).
4. **Every API read** (snippet only) — `convertMemoFromStoreWithCreators` in `memo_service_converter.go` calls `GenerateSnippet` on every memo-to-API conversion.

**Extracted properties** (persisted in `MemoPayload`, defined in `proto/store/memo.proto`):
- **`tags`** — deduplicated `#tag` tokens (case-preserved)
- **`property.has_link`** — whether the content contains markdown links
- **`property.has_code`** — whether it contains code blocks or inline code
- **`property.has_task_list`** — whether it contains GFM task-list checkboxes
- **`property.has_incomplete_tasks`** — whether any task checkbox is unchecked
- **`property.title`** — plain text of the first H1 heading (only if it is the document's first block element)

Additionally, `ExtractAll()` extracts **mentions** (`@username` tokens, lowercased/deduplicated) used for inbox notifications, and `GenerateSnippet()` produces a **snippet** (plain-text content summary, max 64 chars, truncated at word boundary) that is computed on the fly rather than stored.
