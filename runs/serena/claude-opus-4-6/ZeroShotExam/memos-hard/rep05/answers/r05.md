The premise is incorrect — there is no GraphQL schema in this repository. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed as a REST-compatible API via **grpc-gateway**.

The API service definitions live as `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared types)

Each proto file defines a gRPC `service` with `rpc` methods annotated with `google.api.http` options (e.g., `post: "/api/v1/memos"`), which grpc-gateway (`github.com/grpc-ecosystem/grpc-gateway/v2` in `go.mod`) uses to generate a RESTful HTTP/JSON gateway. The generated Go code and an OpenAPI spec are output to `proto/gen/` (notably `proto/gen/openapi.yaml`).
