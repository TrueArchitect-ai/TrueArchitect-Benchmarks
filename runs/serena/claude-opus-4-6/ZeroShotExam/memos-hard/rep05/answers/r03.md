The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in the cron scheduler. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/doc.go`, `internal/scheduler/example_test.go`) is a general-purpose cron scheduling library — it does not define any production jobs itself. The examples in `doc.go` and `example_test.go` show illustrative/demo jobs (e.g., a `"daily-cleanup"` at `0 2 * * *` and a `"cleanup"` at `0 2 * * *`), but these are documentation examples and test fixtures, not actual scheduled database-cleanup jobs wired into the application. No file in the repository registers a real "database-cleanup" job in the scheduler.
