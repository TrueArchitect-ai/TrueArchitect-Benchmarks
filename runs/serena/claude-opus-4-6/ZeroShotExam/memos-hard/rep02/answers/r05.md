The premise is incorrect — this repository (Memos) does not use GraphQL at all. The public API is defined as a **gRPC + REST (gRPC-Gateway)** service using **Protocol Buffers**.

The API surface is defined by the `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These proto definitions use `google.api.http` annotations to expose RESTful HTTP endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`) via gRPC-Gateway. Code generation is managed by Buf (`proto/buf.gen.yaml`), which produces Go gRPC/Connect stubs, gRPC-Gateway reverse proxies, TypeScript client types, and an OpenAPI 3.0 spec at `proto/gen/openapi.yaml`.
