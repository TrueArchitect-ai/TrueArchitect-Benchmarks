The provider abstraction is defined in `internal/idp` (`idp.go` declares the `IdentityProviderUserInfo` struct that all providers must produce), and the sole concrete protocol implementation that ships is `internal/idp/oauth2` (implements OAuth2 token exchange and user-info retrieval).

**abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**
