The premise of this question is incorrect. This repository (Memos) does not have a per-user API rate-limiting middleware. There is no rate-limiting package in `go.mod`, no rate-limiter middleware registered in `server/server.go`, and no files containing "ratelimit", "rate_limit", or "rate-limit" logic anywhere in the codebase. The only mention of "rate limit" is a comment in `internal/email/doc.go` describing a future aspiration for email sending — it is not implemented. The server's middleware stack (visible in `server/server.go` and `server/cors.go`) handles CORS and authentication but includes no request-rate throttling.
