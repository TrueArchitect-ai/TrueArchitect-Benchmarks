The route is `GET /file/users/:identifier/avatar` (registered at `fileserver.go:124`). The handler `serveUserAvatar` calls `getUserByUsername`, which calls `Store.GetUser`, which calls `Store.ListUsers`, which calls `driver.ListUsers` — the concrete SQLite implementation queries `SELECT ... avatar_url ... FROM user WHERE username = ?`. The avatar is stored as a `data:image/<type>;base64,...` URI directly in the database column. Back in the handler, `parseDataURI` extracts the MIME type and decodes the base64 payload, and the raw image bytes are returned via `c.Blob()`.
