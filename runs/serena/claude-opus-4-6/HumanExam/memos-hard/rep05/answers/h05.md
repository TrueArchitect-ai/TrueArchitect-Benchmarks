By explicit Go code. Each database driver's `DeleteUser` implementation explicitly deletes reactions in two steps: (1) `DELETE FROM reaction WHERE content_id IN ...` (reactions on the user's memos) and (2) `DELETE FROM reaction WHERE creator_id = ?` (reactions created by the user). Evidence: `store/db/sqlite/user_delete.go:383,401`; `store/db/postgres/user_delete.go:383,401`; `store/db/mysql/user_delete.go:420,438`. The `reaction` table has no foreign key on `creator_id` (only `UNIQUE(creator_id, content_id, reaction_type)`, see `store/migration/sqlite/LATEST.sql:92-99`).
