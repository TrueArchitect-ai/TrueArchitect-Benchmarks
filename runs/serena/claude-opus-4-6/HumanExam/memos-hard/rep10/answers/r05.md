False premise. There is no GraphQL schema. The public API is defined using Protocol Buffers (protobuf) with gRPC + gRPC-Gateway for REST/HTTP. Proto service definitions are in `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`), with generated Go code in `proto/gen/api/v1/`. An embedded OpenAPI spec is also generated (`proto/openapi_embed.go`).
