CEL (Common Expression Language) engine, powered by `cel-go`; lives in `internal/filter/` (engine at `internal/filter/engine.go`). The filter string is compiled into a CEL AST, converted to a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then rendered into dialect-specific SQL via `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions()` with its dialect name (DialectSQLite/DialectPostgres/DialectMySQL), and the renderer adapts SQL functions accordingly (e.g. `strftime` for SQLite, `EXTRACT` for Postgres, `YEAR()`/`CHAR_LENGTH()` for MySQL).
