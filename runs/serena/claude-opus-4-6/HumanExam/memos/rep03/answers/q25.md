CEL (Common Expression Language) via `github.com/google/cel-go`; the engine lives at `internal/filter/engine.go`. The CEL expression is compiled to an AST, converted to a dialect-agnostic condition tree (IR in `internal/filter/ir.go`), then rendered to SQL by `internal/filter/render.go` which switches on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` for dialect-specific SQL fragments. Each driver calls `filter.AppendConditions(ctx, engine, filters, dialect, &where, &args)` from `internal/filter/helpers.go:9`.
