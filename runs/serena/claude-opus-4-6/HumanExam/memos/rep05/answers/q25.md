—
    - Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`
    - Mechanism: The CEL expression is parsed into a dialect-agnostic condition tree (IR), then rendered into SQL via `Engine.CompileToStatement()` which calls `Program.Render()` with dialect-specific `RenderOptions` (e.g. `filter.DialectSQLite`). Each DB driver calls `filter.AppendConditions()` or `engine.CompileToStatement()` with its own dialect to produce SQL WHERE clauses.
