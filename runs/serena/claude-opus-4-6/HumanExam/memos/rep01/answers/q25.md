Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/engine.go`
The filter string is parsed by a CEL `Engine` into a dialect-agnostic IR, then rendered to SQL via `AppendConditions` (in `internal/filter/render.go`) using a `Dialect` parameter (DialectSQLite, DialectPostgres, DialectMySQL) that generates the appropriate SQL WHERE clause for each backend.
