Before deleting the memo row itself, the store layer deletes:
- Memo relations (where the memo is source, via `DeleteMemoRelation` with `MemoID`)
- Memo relations (where the memo is target, via `DeleteMemoRelation` with `RelatedMemoID`)
- Attachments linked to the memo

Additionally, at the API handler layer before calling `Store.DeleteMemo`, comment memos (child memos linked by comment relations) are deleted first.
