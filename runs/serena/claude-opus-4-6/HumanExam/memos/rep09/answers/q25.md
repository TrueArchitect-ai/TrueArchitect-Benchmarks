- Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`
- Mechanism: The CEL filter string is parsed by the `Engine` into a dialect-agnostic condition IR (`internal/filter/parser.go`, `internal/filter/ir.go`), then rendered to SQL via `internal/filter/render.go`. Each database driver calls `filter.AppendConditions()` or `engine.CompileToStatement()` with a dialect flag (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`) that produces the appropriate SQL WHERE clauses with dialect-specific syntax.
