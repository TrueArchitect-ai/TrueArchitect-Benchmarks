Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/engine.go` (`Engine` struct).
The filter string is compiled by `Engine.CompileToStatement` into a dialect-agnostic IR (condition tree), then rendered to SQL via `internal/filter/render.go` using a `DialectName` parameter (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`). Each dialect driver calls `filter.AppendConditions` with its dialect, which compiles each filter string and appends the resulting SQL clause and args to the query's WHERE conditions.
