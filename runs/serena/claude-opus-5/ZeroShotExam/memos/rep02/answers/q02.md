**MySQL, PostgreSQL, SQLite**

The migration files live under `/bench/repo/store/migration/`, which contains exactly three dialect subdirectories:

- `store/migration/mysql/` — versioned dirs (`0.17` … `0.30`) plus `LATEST.sql`
- `store/migration/postgres/`
- `store/migration/sqlite/`

This matches the three database drivers implemented in `store/db/` (`store/db/mysql/mysql.go`, `store/db/postgres/`, `store/db/sqlite/`), selected via `store/db/db.go`.
