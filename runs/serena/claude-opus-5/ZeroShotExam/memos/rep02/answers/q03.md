**`DB` — `store/db/postgres/postgres.go`**

The `postgres.DB` struct (`store/db/postgres/postgres.go:16`) holds a `*sql.DB` plus the `*profile.Profile`, and is constructed by `postgres.NewDB()`, which returns it as a `store.Driver` (using the `github.com/lib/pq` driver registered under the name `"postgres"`).

Supporting detail:
- The `store.Driver` interface methods are implemented across the package's other files — `store/db/postgres/memo.go`, `user.go`, `attachment.go`, `idp.go`, etc. — all with receiver `(d *DB)`.
- It's wired up in `store/db/db.go:22` via the `case "postgres": driver, err = postgres.NewDB(profile)` branch of `NewDBDriver`.

Note that the same struct name `DB` is used by the sibling drivers in `store/db/sqlite/` and `store/db/mysql/`, so the package path is what disambiguates it.
