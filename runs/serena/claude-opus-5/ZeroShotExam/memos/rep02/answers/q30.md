**Convergence for delivery:**

The first three funnel through the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator and loads `Store.GetUserWebhooks`. The comment-created one skips that helper (it targets the *related* memo's owner, not the comment creator) but does the same per-hook payload build.

All four then converge on `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning when full). Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single function that actually marshals the payload, adds the Standard Webhooks HMAC-SHA256 headers when a signing secret is set, and issues the POST via the SSRF-guarded `safeClient`.
