**Convergence / delivery**

The first three are thin wrappers over the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator and fans out over `Store.GetUserWebhooks`. The comment event bypasses that helper (it targets the *parent* memo's owner rather than the comment creator) but builds the same payload.

All four converge on `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning if full). Four worker goroutines started in `init()` (`webhook.go:42-55`) drain that queue and call the actual delivery function `webhook.Post` (`internal/webhook/webhook.go:120`), which marshals the payload, adds Standard Webhooks HMAC headers when a signing secret is set, and POSTs via the SSRF-guarded `safeClient`.
