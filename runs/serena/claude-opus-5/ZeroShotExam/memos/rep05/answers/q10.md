**`store/migration/sqlite/LATEST.sql`**

For a fresh install (database not yet initialized), `preMigrate` in `store/migrator.go:211-235` detects the uninitialized DB and executes the single `LATEST.sql` file from the driver-specific migration base path (`migration/sqlite/` for SQLite) in one transaction, rather than replaying the incremental `0.x/` migration directories. The constant is defined at `store/migrator.go:56` (`LatestSchemaFileName = "LATEST.sql"`), and the design intent is documented in the file header comment at `store/migrator.go:42`: "LATEST.sql: Full schema for new installations (faster than incremental migrations)".
