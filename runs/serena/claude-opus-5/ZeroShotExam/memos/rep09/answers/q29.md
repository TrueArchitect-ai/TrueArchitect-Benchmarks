`web/src/connect.ts` (authInterceptor, token storage in `web/src/auth-state.ts`); JWT access token (Bearer, 15 min) + refresh token (httpOnly `memos_refresh` cookie, 30 days), plus Personal Access Tokens (`memos_pat_` prefix) for programmatic clients; `server/auth`

**Details**

- **Interceptor** — `authInterceptor` at `web/src/connect.ts:156`, installed on the Connect-Web transport at `web/src/connect.ts:184-189`. It calls `getRequestToken()` and sets `Authorization: Bearer <token>` (`web/src/connect.ts:97-100`), retries once on `Code.Unauthenticated` after refreshing, and redirects on failure (`web/src/connect.ts:161-177`). A second, interceptor-free transport (`web/src/connect.ts:65-72`) issues `AuthService.refreshToken` so refreshes can't recurse; all fetches use `credentials: "include"` so the refresh cookie rides along.

- **Tokens managed client-side** — access token + expiry cached in memory and `localStorage` (`memos_access_token` / `memos_token_expires_at`) in `web/src/auth-state.ts:1-97`, with cross-tab sync over a `BroadcastChannel`. Refresh is both preflight (expiry buffer, `web/src/connect.ts:140`) and reactive on 401, deduplicated by `tokenRefreshManager` (`web/src/connect.ts:30-51`); `web/src/hooks/useTokenRefreshOnFocus.ts` refreshes on tab focus. The refresh token itself is never touched by JS — it's a server-set cookie (`server/router/api/v1/auth_service_session.go:224`).

- **Backend validation** — package `server/auth`: `Authenticator.Authenticate` / `AuthenticateToUser` (`server/auth/authenticator.go:190-224`) resolve a Bearer token as either an Access Token V2 (stateless JWT verify, `ParseAccessTokenV2` in `server/auth/token.go:220`) or a PAT (SHA-256 hash lookup, `server/auth/authenticator.go:102`), falling back to the refresh cookie which is checked against the DB for revocation/expiry (`server/auth/authenticator.go:61`). It's wired in via the Connect `AuthInterceptor` at `server/router/api/v1/connect_interceptors.go:206-231` (through `Authorizer` in `server/router/api/v1/authz.go`), and reused by the gRPC path (`server/router/api/v1/v1.go:78`), SSE handler, and file server. Constants (15 min access, 30 day refresh, `memos_refresh`, `memos_pat_`) are in `server/auth/token.go:25-52`.
