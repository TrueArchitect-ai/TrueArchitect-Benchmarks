**`memo_relation`**

Schema (`store/migration/sqlite/LATEST.sql`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The same table is defined for the other drivers in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, originally added in `store/migration/sqlite/0.13/00__memo_relation.sql`. Store-layer access lives in `store/memo_relation.go` with per-driver implementations in `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
