**Storage drivers — highest-risk, they map struct fields to SQL columns**
```
store/db/sqlite/memo.go
store/db/postgres/memo.go
store/db/mysql/memo.go
```
Each builds the INSERT/UPDATE column list and `rows.Scan(...)` in field order (e.g. `store/db/sqlite/memo.go:172` scans `memo.ParentUID`, `:184` unmarshals `memo.Payload`), so any added/removed/renamed field must be changed in all three.
