**Convergence for delivery:**

The three non-comment events funnel through the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator and loads their webhooks. `DispatchMemoCommentCreatedWebhook` bypasses that helper (it targets the *related* memo's owner, not the comment creator) but builds the same payload.

All four then converge on `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning when full). Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42`) drain that queue and call `webhook.Post` (`internal/webhook/webhook.go:120`), which does the actual HTTP POST — optional HMAC-SHA256 Standard Webhooks signing, then `safeClient.Do` with the SSRF-guarding `safeDialContext` transport.
