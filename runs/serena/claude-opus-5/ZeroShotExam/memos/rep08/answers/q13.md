Notes for scoping the review:
- The sibling types in `store/memo.go` (`FindMemo`, `UpdateMemo`, `DeleteMemo`) usually change together — the same file set covers them.
- `Payload *storepb.MemoPayload` (`store/memo.go:51`) is defined in `proto/gen/store` (generated from `proto/store/memo.proto`); a change to that field pulls in the proto definitions too.
- API-facing field changes also surface in the converter `server/router/api/v1/memo_service_converter.go`, which maps `store.Memo` → `v1pb.Memo` (`proto/gen/api/v1/memo_service.pb.go:219`).
