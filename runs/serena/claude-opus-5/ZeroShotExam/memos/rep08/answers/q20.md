**Mechanism:** Server-Sent Events (SSE) over a long-lived HTTP GET at `/api/v1/sse` (`Content-Type: text/event-stream`, 30s heartbeat pings, `X-Accel-Buffering: no`). Auth is via `Authorization: Bearer <token>`, so the browser client uses `fetch` + a `ReadableStream` reader rather than `EventSource` (`web/src/hooks/useLiveMemoRefresh.ts:203`), and events are turned into React Query cache invalidations.

**Hub:** `server/router/api/v1/sse_hub.go` — `SSEHub` (`NewSSEHub`, `Subscribe`, `Unsubscribe`, `Broadcast`, `Close`), holding a mutex-guarded `map[*SSEClient]struct{}`; `Broadcast` filters per-client by memo `Visibility`/`CreatorID` and client role. Wiring: connection handler `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes`/`handleSSE`), constructed and registered in `server/router/api/v1/v1.go:57,125`, shut down in `server/server.go:205`. Event types and payload struct are in `sse_hub.go` (`memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`); event-construction helpers in `server/router/api/v1/sse_event_helpers.go`.
