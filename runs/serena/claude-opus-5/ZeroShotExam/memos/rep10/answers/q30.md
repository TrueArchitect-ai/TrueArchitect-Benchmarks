**Convergence for delivery:**

- The first three funnel through the shared private helper `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), which resolves the memo creator and loads their webhooks. `DispatchMemoCommentCreatedWebhook` bypasses that helper (it targets the *related* memo owner's webhooks, not the comment creator's), but builds the same payload inline.
- All four then converge on `webhook.PostAsync(payload)` (`internal/webhook/webhook.go:184`), which enqueues onto the bounded `asyncPostQueue` (cap 128, dropping with a warning when full). Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain the queue and call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single function that actually performs the HTTP POST, adding Standard Webhooks HMAC-SHA256 signature headers when a signing secret is set, via the SSRF-guarded `safeClient`.
