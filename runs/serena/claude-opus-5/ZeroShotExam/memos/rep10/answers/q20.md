**Mechanism:** Server-Sent Events (SSE) over HTTP — `GET /api/v1/sse` with `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no` (`server/router/api/v1/sse_handler.go:47-51`). Auth is a Bearer token in the `Authorization` header (`sse_handler.go:36-44`). The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which reconnects with exponential backoff (1s → 30s) and invalidates React Query caches on each event.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`) with `NewSSEHub`/`Subscribe`/`Unsubscribe`/`Broadcast`/`Close`. Each client has a 32-event buffered channel; events are dropped rather than blocking on a slow client (`sse_hub.go:118-131`). `canReceive` (`sse_hub.go:133-144`) filters private-visibility events to the creator or an admin. The hub is constructed in `server/router/api/v1/v1.go:57`, routed at `v1.go:125` via `RegisterSSERoutes`, and closed on shutdown at `server/server.go:205-206`.

Reaction events are built by `buildMemoReactionSSEEvent` in `server/router/api/v1/sse_event_helpers.go`, which resolves the parent memo's `CreatorID` for comments so private parent-memo events stay scoped to the parent owner.
