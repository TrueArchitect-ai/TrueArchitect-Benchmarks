**`store/migration/sqlite/LATEST.sql`**

That single file contains the full current schema for new SQLite installations. The mechanism is in `store/migrator.go`:

- `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`)
- `preMigrate()` detects an uninitialized database and reads `s.getMigrationBasePath() + LatestSchemaFileName` — which for SQLite resolves to `migration/sqlite/LATEST.sql` — applying it in one shot instead of replaying the incremental `0.x/*.sql` migrations (`store/migrator.go:210-219`, comment at `store/migrator.go:42`).

Covered by `store/test/migrator_test.go:18` (`TestFreshInstall`).
