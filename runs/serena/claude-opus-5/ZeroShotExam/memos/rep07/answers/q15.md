There's no ORM/tag-based mapping in this repo — the store layer uses hand-written SQL per driver, so the mapping is by convention: the domain struct in `store/` is read/written by the driver files of the same name under `store/db/{sqlite,postgres,mysql}/`.

- **user**: `User` — `store/user.go:29` (SQL in `store/db/sqlite/user.go`, `store/db/postgres/user.go`, `store/db/mysql/user.go`)
- **attachment**: `Attachment` — `store/attachment.go:16` (SQL in `store/db/sqlite/attachment.go` and the postgres/mysql equivalents)
- **reaction**: `Reaction` — `store/reaction.go:7` (SQL in `store/db/sqlite/reaction.go` and the postgres/mysql equivalents)

Table schemas confirming the column sets live in `store/migration/*/LATEST.sql` per dialect.
