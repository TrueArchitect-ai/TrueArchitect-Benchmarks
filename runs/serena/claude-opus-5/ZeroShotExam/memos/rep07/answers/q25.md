**Engine: Google CEL (`cel-go`), wrapped by the in-repo filter engine at `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`).**

**Mechanism:** `ListMemos` validates `request.Filter` via `s.validateFilter` and appends it to `memoFind.Filters` (`server/router/api/v1/memo_service.go:211-215`); each store dialect then calls `filter.DefaultEngine()` + `filter.AppendConditions(..., filter.DialectSQLite|DialectMySQL|DialectPostgres, &where, &args)` (`store/db/sqlite/memo.go:54-60`, `store/db/postgres/memo.go:51-57`, `store/db/mysql/memo.go:65`), which runs a three-phase pipeline — `cel-go` compiles the expression against the memo-specific CEL env declared in `internal/filter/schema.go`, `parser.go` normalizes the CEL AST into a dialect-agnostic IR (`ir.go`), and `render.go` walks that IR emitting a dialect-specific SQL fragment plus bound args that get AND-ed into the query's WHERE clause.

Supporting detail:

- Entry point: `Engine.Compile` / `Engine.CompileToStatement` in `internal/filter/engine.go:91-79`; `Program.Render` builds a `renderer` from `RenderOptions{Dialect, PlaceholderOffset, DisableNullChecks}`.
- Dialect divergence lives entirely in `render.go`: placeholders (`$n` for Postgres vs `?` otherwise, `addArg` at `internal/filter/render.go:842`), JSON access (`json_extract` / `JSON_EXTRACT` / `->`,`->>`), boolean coercion, `LIKE` vs `ILIKE`, tag membership (SQLite `LIKE`, MySQL `JSON_CONTAINS`, Postgres `@>`), and per-field SQL templates in `Schema.Expressions map[DialectName]string` (`internal/filter/schema.go:104-148`).
- `PlaceholderOffset` (set from `len(*args)` in `internal/filter/helpers.go:9-24`) lets rendered fragments compose with the query's pre-existing args. Trivial conditions render to `""` (skipped); unsatisfiable ones render to `1 = 0`.
- Time fields (`created_ts`, `updated_ts`) accept `now`, `duration(...)`, `timestamp(...)` and fold to epoch seconds at compile time, with `now` frozen once per compile via the engine's `nowFunc`.
- Same engine serves attachments (`DefaultAttachmentEngine`) and shortcut filter validation (`server/router/api/v1/shortcut_service.go:336-358`). Design notes are in `internal/filter/README.md`.
