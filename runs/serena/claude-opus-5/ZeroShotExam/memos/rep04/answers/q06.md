**`memo_relation`**

The table stores memo-to-memo links with three columns and a uniqueness constraint over all of them:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```
