**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

- `web/src/hooks/useMemoQueries.ts` holds the memo CRUD React Query hooks: `useMemos` / `useInfiniteMemos` (list), `useMemo` (get), `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, plus `useMemoComments` / `useInfiniteMemoComments` and `useLinkMetadata`, alongside the `memoKeys` query-key factory and cache-patching helpers.
- It imports `memoServiceClient` from `web/src/connect.ts:197`, which is `createClient(MemoService, transport)` over the generated `MemoService` from `web/src/types/proto/api/v1/memo_service_pb.ts` (a Connect-ES client). Calls used: `listMemos`, `getMemo`, `createMemo`, `updateMemo`, `deleteMemo`, `listMemoComments`, `getLinkMetadata`.

Related but separate: memo sharing lives in `web/src/hooks/useMemoShareQueries.ts`.
