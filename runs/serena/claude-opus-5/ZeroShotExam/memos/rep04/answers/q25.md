**Engine:** Google CEL (`github.com/google/cel-go` v0.28.1, `go.mod:13`) — filters are standard CEL expressions, compiled by the in-repo filter engine at **`/bench/repo/internal/filter/`** (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`; docs in `internal/filter/README.md`).

**Mechanism (one sentence):** `filter.DefaultEngine()` compiles the CEL string against a memo-specific `cel.Env` whose declared variables/columns come from `NewSchema()` (`internal/filter/schema.go`), `parser.go` normalizes the CEL AST into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), and `render.go` walks that IR to emit a parameterized SQL fragment + args for the target `DialectName` (`sqlite`/`mysql`/`postgres`), which the store appends to its WHERE clause via `filter.AppendConditions` (`internal/filter/helpers.go`).

Concrete path through the code:

- `ListMemos` validates the filter with `s.validateFilter(ctx, request.Filter)` and stashes it in `memoFind.Filters` — `server/router/api/v1/memo_service.go:211-216`; it also appends a synthesized CEL visibility filter for the current user (`memo_service.go:222`).
- `validateFilter` picks the dialect from `s.Profile.Driver` and does a trial `engine.CompileToStatement` — `server/router/api/v1/shortcut_service.go:336-361`.
- Compile pipeline: `env.Compile` → `cel.AstToParsedExpr` → `buildCondition(...)` → `Program{condition}`; `Render` builds a `Statement{SQL, Args}` — `internal/filter/engine.go:57-107`.
- Per-dialect execution: each driver calls `filter.AppendConditions(ctx, engine, find.Filters, <dialect>, &where, &args)` — `store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69` (same for `memo_relation.go` in each driver).
- Dialect differences live in `render.go`/`schema.go`: placeholders (`?` vs `$n` via `PlaceholderOffset`), JSON access (`json_extract` vs `JSON_EXTRACT` vs `->>`), tag membership (`LIKE` / `JSON_CONTAINS` / `@>` at `render.go:451-512`), timestamp parts (`render.go:219-241`), and `LIKE` vs `ILIKE` (`render.go:577-584`). Time values (`now`, `duration(...)`, `timestamp(...)`) fold to epoch seconds at compile time, with `now` frozen once per compile (`engine.go:16-20`).
