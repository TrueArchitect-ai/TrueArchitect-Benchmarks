There is no ORM/tag-based mapping in this repo — the store layer uses hand-written SQL per driver (`store/db/sqlite`, `store/db/postgres`, `store/db/mysql`), and each table's rows are scanned into a plain Go struct in the `store` package:

- **user**: `User` — `store/user.go:29` (SQL: `store/db/sqlite/user.go:17,164`, `store/db/postgres/user.go:61,155`)
- **attachment**: `Attachment` — `store/attachment.go:16` (SQL: `store/db/sqlite/attachment.go:34,109`)
- **reaction**: `Reaction` — `store/reaction.go:7` (SQL: `store/db/sqlite/reaction.go:60,113`)

Each file also holds companion param structs (`UpdateUser`, `FindUser`, `FindAttachment`, `FindReaction`, etc.) that aren't row mappings but query/update descriptors.
