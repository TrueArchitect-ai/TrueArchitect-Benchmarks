**Engine + path:** Google CEL (Common Expression Language), via `github.com/google/cel-go` (`go.mod:13`), wrapped by the in-repo filter engine at `internal/filter/` — `engine.go` (entry point / `DefaultEngine()`), `schema.go` (CEL env + field metadata), `parser.go` (CEL AST → IR), `ir.go` (dialect-agnostic condition tree), `render.go` (IR → SQL), `helpers.go` (store glue).

**Mechanism (one sentence):** `Engine.Compile` type-checks the CEL string against a memo-specific env whose only identifiers are the schema's declared fields (`internal/filter/engine.go:47-68`), converts the CEL AST into a dialect-agnostic IR condition tree via `buildCondition` (`internal/filter/parser.go`), and then `Program.Render` walks that IR with a dialect-parameterized renderer (`internal/filter/render.go`) that emits a parameterized SQL fragment plus args — `?` placeholders for SQLite/MySQL vs `$n` for Postgres, and per-field/per-dialect column expressions from `Field.Expressions` / `columnExpr` (`internal/filter/schema.go:321-330`), e.g. `('users/' || …)` vs `CONCAT('users/', …)`, plus dialect-specific JSON/tag handling (`LIKE` vs `JSON_CONTAINS` vs `@>`).

**Wiring for ListMemos specifically:**
- `ListMemos` validates `request.Filter` at `server/router/api/v1/memo_service.go:211-216` via `validateFilter` (`server/router/api/v1/shortcut_service.go:336-360`), which compiles it against the dialect implied by `s.Profile.Driver`; it then appends the raw filter string (plus a synthesized visibility/creator filter, lines 222-228) to `memoFind.Filters`.
- The store drivers each call `filter.AppendConditions(ctx, engine, find.Filters, <dialect>, &where, &args)` with their own dialect and a `PlaceholderOffset` of `len(args)` so fragments compose with pre-existing args: `store/db/sqlite/memo.go:57-62` (`DialectSQLite`), `store/db/postgres/memo.go:54-59` (`DialectPostgres`), `store/db/mysql/memo.go:65-70` (`DialectMySQL`); each fragment is wrapped in parens and ANDed into the WHERE clause (`internal/filter/helpers.go:9-25`).

Notes: the engine is a compile-time constant-folder for time (`now` frozen once per compile, `duration()`/`timestamp()` folded to epoch seconds), and rendering can short-circuit to `1 = 0` (unsatisfiable) or `""` (trivial, skipped) — `internal/filter/engine.go:90-96`, `render.go:31-57`. There's a parallel `DefaultAttachmentEngine()` with its own schema for attachment filters. The design is documented in `internal/filter/README.md`.
