**Convergence / delivery path**

The first three are thin wrappers over the shared helper `dispatchMemoRelatedWebhook` (memo_service_webhooks.go:48), which differs only by the `activityType` string. The comment-created one does not go through that helper — it resolves webhooks for the *related memo's* creator (`relatedMemoCreatorID`) rather than the comment memo's own creator, so it builds the payload itself.

All four converge one level lower, at `webhook.PostAsync` (`internal/webhook/webhook.go:184`) — called at memo_service_webhooks.go:71 for the helper and memo_service_webhooks.go:43 for comments. `PostAsync` enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning when full), which four goroutines started in `init()` (webhook.go:42) drain by calling `webhook.Post` (`internal/webhook/webhook.go:120`) — the actual HTTP delivery, including optional Standard-Webhooks HMAC signing and the SSRF-guarded `safeClient`.
