**Computation site; triggers; extracted properties**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` is the single entry point. It lazily initializes `memo.Payload` and assigns `Payload.Tags` and `Payload.Property` from one markdown pass.
- The actual extraction is `service.ExtractAll` in `internal/markdown/markdown.go` (goldmark AST walk, single pass; the same logic also exists standalone as `ExtractProperties`). The stored shape is `MemoPayload.Property` in `proto/store/memo.proto:15-22`, surfaced to the API by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`) into `Memo.Property`, which is `OUTPUT_ONLY` (`proto/api/v1/memo_service.proto:256`).

**Triggers (recomputation)**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the memo is persisted.
- `UpdateMemo`, only when the update mask contains `content` — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`).
- Bulk backfill: `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) walks all memos in batches of 100, rebuilding and `UpdateMemo`-ing each. Note this runner is not currently wired into `server/server.go` (unlike `s3presign`, which is invoked at `server/server.go:163`), so it's an available maintenance path rather than an active trigger.
- Not triggered by visibility/pinned/state/timestamp updates — those paths skip the rebuild.

**Extracted properties**
From `ExtractAll` / `ExtractProperties` (`internal/markdown/markdown.go`):
- `Title` — text of the first block-level node of the document if it is an H1 heading (`extractHeadingText`).
- `HasLink` — any `KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any GFM `TaskCheckBox`.
- `HasIncompleteTasks` — at least one task checkbox with `IsChecked == false`.

Alongside `Property`, the same pass also derives `Payload.Tags` (`#tag` nodes, deduped case-preserving, ignoring tags inside links/images) and mentions (mentions are used by `server/router/api/v1/memo_mention_helpers.go:32`, not stored in the payload).

One related-but-separate piece: the list/preview `snippet` is **not** stored in the payload — it's computed at read time per request via `getMemoContentSnippet` → `GenerateSnippet` in `server/router/api/v1/memo_service_converter.go:76,225,248`.
