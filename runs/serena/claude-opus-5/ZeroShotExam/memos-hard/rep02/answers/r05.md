**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for "graphql" across all Go, TypeScript, JSON, and Markdown sources returns zero hits. Memos does not expose a GraphQL API.

**Actual API surface: Protocol Buffers → gRPC / Connect / REST**

The public API is defined as protobuf service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

`AGENTS.md:67` labels `proto/api/v1/` as "Public API service definitions."

**How the surface is generated and served**

- `proto/buf.gen.yaml` drives codegen via `buf`, emitting Go protobuf/gRPC/Connect/grpc-gateway stubs into `proto/gen/`, a gnostic-generated OpenAPI spec at `proto/gen/openapi.yaml`, and TypeScript clients into `web/src/types/proto`.
- REST routes come from `google.api.http` annotations on each RPC — e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and line 35 maps `GetMemo` to `GET /api/v1/{name=memos/*}`.
- Handlers live in `server/router/api/v1/`, with Connect wiring in `connect_services.go` and `connect_handler.go`; public/unauthenticated routes are declared in `server/router/api/v1/acl_config.go` (`AGENTS.md:21`).
- The generated OpenAPI spec is embedded into the binary by `proto/openapi_embed.go`.

`proto/store/` holds internal storage-layer messages, not public API surface. The README describes the project as offering "full REST and gRPC APIs"; there is also an MCP router at `server/router/mcp/` and an RSS router at `server/router/rss/`.
