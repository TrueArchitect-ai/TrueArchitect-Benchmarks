**Premise correction: there is no nightly database-cleanup job registered in this repository's cron scheduler.** The scheduler exists, but nothing — cleanup or otherwise — is registered with it in production code.

What's actually there:

- `internal/scheduler/` is a self-contained, GitHub-Actions-inspired cron library (`scheduler.go`, `job.go`, `parser.go`, `middleware.go`). It supports 5- and 6-field cron expressions and timezones, but it is **not wired into the application**: the only files importing `github.com/usememos/memos/internal/scheduler` are its own tests — `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. No `cmd/` or `server/` code registers a job.

- The "2 AM daily cleanup" you may be thinking of appears only in **documentation and example code**, never as a live job:
  - `internal/scheduler/doc.go:14-20` — package doc snippet, `Name: "daily-cleanup"`, `Schedule: "0 2 * * *"`
  - `internal/scheduler/README.md:34-35` — same illustrative snippet
  - `internal/scheduler/example_test.go:97-100` — `Name: "cleanup"`, `Schedule: "0 2 * * *"` in a runnable example
  - `internal/scheduler/README.md:241-245` — a different illustrative `"stale-session-cleanup"` at `0 3 * * *`

- The only real recurring background work in the app is not cron-based at all: `server/runner/s3presign/runner.go:27` uses a plain `time.Ticker` at a 12-hour interval to re-presign S3 object URLs — not a database cleanup.

So if you need a nightly DB-cleanup job, it would have to be added; the schedule you'd find by grepping today is example text, not configuration.
