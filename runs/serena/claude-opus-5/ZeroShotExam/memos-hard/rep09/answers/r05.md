**Premise correction:** There is no GraphQL schema in this repository. A search for `*.graphql`/`*.gql` files and for the string `graphql` across Go, TS, JSON, and Markdown sources returns nothing. Memos does not expose a GraphQL API.

**The actual public API surface** is defined in **Protocol Buffers**, with REST and gRPC/Connect served from the same definitions:

**Source of truth — `proto/api/v1/*.proto`:**
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

The design convention is documented in `proto/api/v1/README.md`, which follows the [Google API Improvement Proposals](https://google.aip.dev/). (`proto/store/*.proto` is separate — internal persistence types, not public API.)

**Code generation — `proto/buf.gen.yaml`** runs buf with plugins for Go, gRPC-Go, Connect-Go, grpc-gateway, gnostic-openapi, and `bufbuild/es` (TypeScript output into `web/src/types/proto`). Regenerate with `buf generate` per `proto/README.md`. Generated artifacts land in `proto/gen/`.

**Generated REST description — `proto/gen/openapi.yaml`**, an OpenAPI 3.0.3 spec. It's embedded into the binary via `proto/openapi_embed.go` and consumed by the MCP router (`server/router/mcp/openapi.go`, `server/router/mcp/catalog_test.go:40`).

**Serving:**
- REST is served by grpc-gateway, registered in `server/router/api/v1/v1.go:65` (`RegisterGateway`), wired up from `server/server.go:88`. Paths are `/api/v1/...`.
- gRPC/Connect handlers live in `server/router/api/v1/connect_handler.go` and `connect_services.go`.
- Service implementations are in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`).

The README confirms this at the feature level: "MIT-licensed with full REST and gRPC APIs for integration."
