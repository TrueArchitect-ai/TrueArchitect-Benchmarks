**delivery function — `internal/webhook/webhook.go:120` (`Post`), invoked asynchronously via `PostAsync` at `internal/webhook/webhook.go:184`; protection mechanism — `safeDialContext` / `safeClient` at `internal/webhook/webhook.go:59` and `webhook.go:32`, backed by `isReservedIP` in `internal/webhook/validate.go:44`**

Details:

**Where delivery executes**
- Callers: `server/router/api/v1/memo_service_webhooks.go:43` and `:71` build a `WebhookRequestPayload` per registered user webhook (memo created/updated/deleted, comment created) and call `webhook.PostAsync`.
- `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto a bounded 128-slot channel `asyncPostQueue`; a pool of 4 goroutines started in `init()` (`webhook.go:42-55`) drains it. Overflow is dropped with a warning rather than blocking the request.
- The actual HTTP work is `Post` (`internal/webhook/webhook.go:120`): marshals JSON, optionally adds Standard-Webhooks HMAC-SHA256 headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`), sends via `safeClient.Do`, and reads at most 1 MiB of the response.

**What protects it from internal addresses**
- Primary, at delivery time: the shared `safeClient` (`webhook.go:32-37`) uses a `http.Transport` whose `DialContext` is `safeDialContext` (`webhook.go:59-77`). It resolves the host itself and rejects the dial if *any* resolved IP is reserved. Because the check happens at dial time on every connection, it also defeats DNS rebinding and redirect-based bypasses.
- The blocklist lives in `internal/webhook/validate.go:14-23` (`reservedCIDRs`: loopback, RFC-1918, 169.254.0.0/16 incl. cloud IMDS, and IPv6 `::1`, `fc00::/7`, `fe80::/10`), parsed once at startup and tested by `isReservedIP` (`validate.go:44`).
- Secondary, at configuration time: `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is called when a user saves a webhook URL — `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. It enforces http/https scheme and rejects hostnames resolving to reserved IPs. This is a UX-level early rejection only; the dial-time check is what actually holds.
- Escape hatch: the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) short-circuits `isReservedIP`, disabling SSRF protection for self-hosted deployments targeting LAN services. Note that nothing in the non-test Go source sets it — it stays `false` unless wired up elsewhere.
