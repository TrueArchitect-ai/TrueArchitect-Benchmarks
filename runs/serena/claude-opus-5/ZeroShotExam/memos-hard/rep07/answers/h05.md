**Mechanism: explicit Go code** — reactions are deleted by hand-written `DELETE FROM reaction` statements inside the user-deletion transaction. There is no database-level cascade: the `reaction` table has no foreign key on `creator_id` (or on `content_id`) in any of the three dialects.

**Two explicit deletes run, covering both directions:**

1. `deleteReactionsByContentIDsTx` — removes *all* reactions (from anyone) on the deleted user's memos, keyed by `content_id` built as `"memos/" + memo.UID` from the recursive memo tree (`memoContentIDsFromRefs`).
2. `deleteReactionsByCreatorTx` — removes the deleted user's own reactions on *other* people's memos, via `DELETE FROM reaction WHERE creator_id = ?`.

Both are invoked from `deleteUserTargetsTx`, which runs in the single transaction opened by the driver's `DeleteUser`.
