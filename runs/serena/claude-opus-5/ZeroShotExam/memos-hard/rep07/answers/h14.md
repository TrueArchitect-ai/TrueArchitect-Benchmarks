- Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives payload for every memo in batches of 100 and calls `Store.UpdateMemo`. **What is extracted** (`ExtractedData` at `internal/markdown/markdown.go:21`; `MemoPayload.Property` at `proto/store/memo.proto:15-22`)
- `Tags` — every `#tag` node, deduplicated preserving original case (`uniquePreserveCase`).
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (markdown.go:383-389).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox; `Property.HasIncompleteTasks` — any unchecked checkbox.
- `ExtractedData.Mentions` is also collected in the same walk but is *not* stored in the payload by `RebuildMemoPayload` — only tags and property are.
