h03.

**`github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`**

- **Abstraction package** — `internal/idp/idp.go`: package `idp` defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider maps its claims into.
- **Implementation package** — `internal/idp/oauth2/oauth2.go`: package `oauth2` ("implements the OAuth2 identity provider integration") provides `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (including PKCE `code_verifier` support), and `UserInfo`, which fetches the userinfo endpoint and maps claims via the configured `FieldMapping`.

OAuth2 is the only concrete protocol that ships — `internal/idp/` contains just `idp.go` and the `oauth2/` subpackage. It's wired into the API at `server/router/api/v1/auth_service_sso.go:121`, where `resolveSSOIdentity` constructs the provider from `identityProvider.Config.GetOauth2Config()`.
