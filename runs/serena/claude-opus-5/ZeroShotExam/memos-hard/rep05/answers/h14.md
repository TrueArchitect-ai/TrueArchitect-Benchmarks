**Computation site; triggers; extracted properties**

**Computation site**

- `internal/markdown/markdown.go:356` — `service.ExtractAll(content)` does one goldmark AST walk and fills `ExtractedData{Tags, Mentions, Property}` (`markdown.go:371-411`). A standalone `service.ExtractProperties` (`markdown.go:193`) contains the same property-walk logic for property-only use.
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` is the wrapper actually called by the API: it ensures `memo.Payload != nil`, calls `ExtractAll([]byte(memo.Content))`, then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`.
- Shape defined in `proto/store/memo.proto:14-22` (`MemoPayload.Property`, "The calculated properties from the memo content"); exposed over the API via `convertMemoPropertyFromStore` in `server/router/api/v1/memo_service_converter.go:315` (wired at `memo_service_converter.go:49`).

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`). Other mask paths (visibility, pinned, state, timestamps) do not recompute it.
- Bulk backfill — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds every memo in batches of 100 and persists via `UpdateMemo`. Note this runner is not currently wired into `server/server.go` (unlike the s3presign runner at `server/server.go:163`), so it's a migration/backfill path rather than something running on boot.

**Extracted properties** (`storepb.MemoPayload_Property`)

- `Title` — text of the first H1 heading, only if the document's first block-level child is a level-1 heading (`markdown.go:384-389`, via `extractHeadingText`/`extractTextFromNode` at `markdown.go:182`).
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any `east.KindTaskCheckBox` node.
- `HasIncompleteTasks` — any task checkbox with `IsChecked == false`.

The same walk also derives `Payload.Tags` (deduped, case preserved) and mentions, which are stored/used alongside the property. These flags back the memo list filters (`web/src/hooks/useMemoFilters.ts:73-77`, `property.hasLink` / `hasTaskList` / `hasCode`) and user stats aggregation (`server/router/api/v1/user_service_stats.go:141-151`, `:257-267`).
