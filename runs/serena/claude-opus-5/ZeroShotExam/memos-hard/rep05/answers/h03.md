**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider-agnostic `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that all IdP integrations normalize to.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the only concrete protocol implementation that ships. Its doc comment reads "Package oauth2 implements the OAuth2 identity provider integration." It provides `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (including PKCE `codeVerifier` support), and user-info retrieval via configurable field mapping.

Wiring: `server/router/api/v1/auth_service_sso.go:121` calls `oauth2.NewIdentityProvider(identityProvider.Config.GetOauth2Config())` and returns results as `*idp.IdentityProviderUserInfo` (`auth_service_sso.go:19,104,119`).
