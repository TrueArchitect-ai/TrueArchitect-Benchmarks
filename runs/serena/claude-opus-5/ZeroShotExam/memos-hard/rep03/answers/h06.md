**Convergence function — `webhook.Post` at `internal/webhook/webhook.go:120`**

Every dispatcher calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the four `init()` worker goroutines drain that queue into `Post`, which builds the `POST` request, optionally HMAC-signs it, and issues the actual outbound call at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). `safeClient`'s transport uses `safeDialContext` to reject reserved/private IPs (SSRF guard).

If you want the single function *before* the async hop rather than the one performing delivery, that's `webhook.PostAsync`; the HTTP request itself is only ever made in `Post`.

Note: one other user-configurable outbound URL exists — `internal/idp/oauth2/oauth2.go:85` fetches `UserInfoUrl` from an admin-created identity provider — but that path is reached via OAuth sign-in, not these memo handlers, and does not go through `webhook.Post`.
