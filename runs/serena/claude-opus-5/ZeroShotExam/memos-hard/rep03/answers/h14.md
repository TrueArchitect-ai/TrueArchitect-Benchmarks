h14.

**`memopayload.RebuildMemoPayload` → `markdown.Service.ExtractAll`; memo create + content-changing update (plus a batch backfill runner); tags + the calculated `Property` fields (title, has_link, has_code, has_task_list, has_incomplete_tasks).**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`).
- The actual extraction is `internal/markdown/markdown.go:359` (`ExtractAll`): one goldmark parse + single AST walk. Equivalent single-purpose methods exist (`ExtractTags` at `markdown.go:126`, `ExtractProperties` at `markdown.go:193`), but the payload path uses `ExtractAll` for a single pass.

**Triggers**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo` (user-set `Location` is layered onto the payload afterwards at :110-112, i.e. not derived).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `content` update-mask branch; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`). Other mask paths (visibility, pinned, state, timestamps) don't recompute.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:29`) rebuilds and persists payloads for all memos in batches of 100. Note this runner is only constructed in tests; no production call site of `memopayload.NewRunner` exists in the repo today.

**What's extracted** (`internal/markdown/markdown.go:359-437`, stored shape in `proto/store/memo.proto:8-22`)
- `Tags` — `#tag` nodes, skipping tag nodes nested inside links/images (`asMemoTagNode`, `markdown.go:118`), deduplicated case-preserving via `uniquePreserveCase`.
- `Property.Title` — text of the first block-level child of the document if it's an H1 heading.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — any GFM task checkbox; the latter when at least one checkbox is unchecked.
- `ExtractAll` also returns `Mentions` (lowercased `@user`), but `RebuildMemoPayload` does not persist them.

**Consumers** — `convertMemoFromStoreWithCreators` copies `Tags`/`Property` onto the API memo (`server/router/api/v1/memo_service_converter.go:48-49`, `:315`), and user stats aggregate them (`server/router/api/v1/user_service_stats.go:138-152`).

One nuance worth flagging: the list/preview `snippet` is *not* part of this stored payload — it's computed per-request from content at 64 chars via `GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`, called from `memo_service_converter.go:76`, `:225`, `:248`).
