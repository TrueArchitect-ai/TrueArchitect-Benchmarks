**Computation site; triggers; extracted properties**

**Computation site**

- Core extraction: `internal/markdown/markdown.go:356` — `service.ExtractAll(content)` does a single goldmark AST walk and fills `data.Property` (`markdown.go:383-408`). A standalone equivalent, `service.ExtractProperties`, exists at `markdown.go:193` (same logic, properties only) but is not the path used by the write flow.
- Wrapper actually called by the API: `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` calls `ExtractAll` and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`.
- Shape defined in `proto/store/memo.proto:15-23` (`MemoPayload.Property`, commented "The calculated properties from the memo content"); surfaced to the API in `server/router/api/v1/memo_service_converter.go:315` (`convertMemoPropertyFromStore`), attached to each memo at `memo_service_converter.go:49`.

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the payload is then written via `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, create_time…) do not recompute.
- Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds every memo in batches of 100 and re-saves it. Note this runner is currently not wired up — `memopayload.NewRunner` has no callers, and `server/server.go` only starts the s3presign runner (`server.go:163`).

**Extracted properties** (all derived from the parsed markdown AST, never user-set)

- `title` — text of the first block-level child of the document if it is an H1 heading (`markdown.go:384-389`, via `extractHeadingText`).
- `has_link` — any `gast.KindLink` node.
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — any `east.KindTaskCheckBox`.
- `has_incomplete_tasks` — any task checkbox with `IsChecked == false`.

The same pass also collects `payload.Tags` and mentions (deduplicated, case-preserving for tags; mentions lowercased) — sibling derived data, not part of `Property`.

Consumers: user stats aggregation (`server/router/api/v1/user_service_stats.go:141-152`, `:257-268`) and the CEL filter schema, which maps `has_link`/`has_code`/etc. to the JSON path `property.hasLink` (`internal/filter/schema.go:197-243`).
