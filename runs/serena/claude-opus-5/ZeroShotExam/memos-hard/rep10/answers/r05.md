**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive grep for `graphql` across the whole tree (excluding `node_modules`/`.git`) returns zero matches, and there are no `.graphql`/`.gql` files. Memos does not expose a GraphQL API.

**Actual API surface: Protocol Buffers**, served over Connect RPC / gRPC / REST.

**Schema definition (source of truth) — `proto/api/v1/*.proto`:**
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Internal storage-layer messages (not part of the public API) live separately in `proto/store/*.proto`.

**REST mapping:** each RPC carries a `google.api.http` annotation that defines its REST route — e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and line 35 maps `GetMemo` to `GET /api/v1/{name=memos/*}`.

**Generation pipeline** (`proto/buf.gen.yaml`, run via `cd proto && buf generate`):
- Go types + gRPC + Connect + grpc-gateway → `proto/gen/api/v1/`
- OpenAPI 3.0.3 spec → `proto/gen/openapi.yaml` (4057 lines; embedded via `proto/openapi_embed.go`)
- TypeScript client types → `web/src/types/proto/`

**Server implementation:** `server/router/api/v1/` — service logic in files like `memo_service.go`, Connect handlers delegating to the gRPC impls in `connect_services.go`, and the public-endpoint allowlist in `acl_config.go`.

The generated files under `proto/gen/` and `web/src/types/proto/` should not be hand-edited (`AGENTS.md`); edit the `.proto` files and regenerate. The closest thing to a machine-readable "schema" for external consumers is `proto/gen/openapi.yaml`, but it is derived output, not the definition.
