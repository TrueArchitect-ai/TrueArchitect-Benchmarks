`internal/idp`; `internal/idp/oauth2`

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any identity provider implementation must produce.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the only concrete protocol implementation. Its `IdentityProvider` wraps a `storepb.OAuth2Config` and provides `NewIdentityProvider`, `ExchangeToken` (with PKCE `code_verifier` support), and `UserInfo`.

Supporting evidence:
- `server/router/api/v1/auth_service_sso.go:120-133` is the only consumer: it branches on `identityProvider.Type == storepb.IdentityProvider_OAUTH2` and calls `oauth2.NewIdentityProvider(...)` — no other branch exists.
- `proto/store/idp.proto:11-13` and `proto/api/v1/idp_service.proto:76-79` declare the provider `Type` enum with `OAUTH2 = 1` as the sole non-unspecified value, confirming OAuth2 is the only shipped protocol.
