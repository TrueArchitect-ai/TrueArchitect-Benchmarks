**Premise correction: there is no nightly database-cleanup job in this repository's cron scheduler.** The scheduler package exists, but nothing in the application registers a database-cleanup job with it — in fact, nothing in production code registers *any* job with it.

What's actually there:

- `internal/scheduler/` is a standalone, self-contained cron scheduler library (`scheduler.go`, `parser.go`, `job.go`, `middleware.go`). Grepping for imports of `github.com/usememos/memos/internal/scheduler` outside the package itself turns up only its own `example_test.go:10` and `integration_test.go:13`. No `cmd/`, `server/`, or `store/` code imports it, and there are no `scheduler.New(...)` / `s.Register(...)` calls outside tests and doc comments.

- The "2 AM cleanup" you may be thinking of appears only in **documentation and example code**, not in a wired-up job:
  - `internal/scheduler/example_test.go:97-99` — `// Cleanup old data every night at 2 AM`, `Name: "cleanup"`, `Schedule: "0 2 * * *"` (a runnable `Example_multipleJobs` for godoc).
  - `internal/scheduler/README.md:34-36` — `Name: "daily-cleanup"`, `Schedule: "0 2 * * *", // 2 AM daily`.
  - `internal/scheduler/doc.go:15` — same `daily-cleanup` snippet in the package doc comment.
  - `internal/scheduler/README.md:241-245` — a separate best-practices example, `stale-session-cleanup` at `0 3 * * *`.

  These are illustrative; the handlers just print strings.

- The real background work in this codebase is **ticker-based, not cron-scheduled**:
  - `server/runner/s3presign/runner.go:26` — re-presigns S3 URLs every 12 hours (`runnerInterval = time.Hour * 12`), started from an interval ticker, not a wall-clock time.
  - `server/runner/memopayload/runner.go` — one-shot migration-style runner.
  - `store/cache/cache.go:60,201` — in-memory cache expiry sweep every 5 minutes (`CleanupInterval`), which is cache eviction, not database cleanup.

So if you're looking for where a nightly DB cleanup runs, it doesn't exist yet — the `0 2 * * *` figure comes from example code only.
