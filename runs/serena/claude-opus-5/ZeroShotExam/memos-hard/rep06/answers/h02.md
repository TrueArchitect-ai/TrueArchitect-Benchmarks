**Where delivery executes**

- `webhook.Post()` (`internal/webhook/webhook.go:120`) is the only place the outbound HTTP request is actually made: it marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), then calls `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.
- Callers don't invoke `Post` directly. `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto a buffered channel (`asyncPostQueue`, cap 128, drops + logs when full), drained by 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) that call `Post`. So delivery runs off-request on those workers.
- Trigger points are `server/router/api/v1/memo_service_webhooks.go:43` and `:71` — memo created/updated/deleted and comment-created events, fanned out over each user's stored webhooks.

**What protects it from internal addresses**

Two layers, both keyed on `isReservedIP` (`internal/webhook/validate.go:44`), which tests against a prebuilt list of reserved CIDRs — IPv4 loopback, RFC-1918, 169.254.0.0/16 (cloud IMDS), plus `::1/128`, `fc00::/7`, `fe80::/10` (`internal/webhook/validate.go:14-23`):

1. **Dial-time enforcement (the real guard).** `safeClient`'s `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37`, `:59-77`). It splits host/port, resolves the host itself, and refuses to dial if *any* resolved IP is reserved. Because this runs at connection time rather than at save time, it also defeats DNS rebinding.
2. **Admission-time validation.** `ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and reserved-resolving hostnames when a webhook is created or updated — called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`.

Two caveats worth knowing:

- There's an escape hatch, `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`), which disables both layers when true. Nothing in the non-test codebase ever sets it — no flag or config wires it up — so it is effectively hardcoded to `false` today.
- `safeDialContext` resolves the host and then dials `host:port` by name (`internal/webhook/webhook.go:76`), so the dialer re-resolves; the check isn't pinned to the vetted IP. Between the two lookups a TOCTOU window exists, though it's much narrower than validate-on-save alone.
