**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive grep for `graphql` across the entire repo (excluding `.git`/`node_modules`) returns zero matches — no `.graphql` files, no schema definitions, no resolvers, no GraphQL server dependency in `go.mod`.

**Actual API surface:** Memos defines its public API with **Protocol Buffers**, in `proto/api/v1/`. Those `.proto` files are the single source of truth; everything else is generated from them.

**Schema definition files** (`proto/api/v1/`) — eight services:

| File | Service |
| --- | --- |
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto` | `AIService` |

Shared types live in `proto/api/v1/common.proto`. The design follows Google's API Improvement Proposals, per `proto/api/v1/README.md`.

**Generated artifacts** — driven by `proto/buf.gen.yaml` via `cd proto && buf generate`:
- `proto/gen/api/v1/*.pb.go` — Go message types
- `proto/gen/api/v1/*_grpc.pb.go` and `*connect/` — gRPC and Connect RPC handlers
- `proto/gen/api/v1/*.pb.gw.go` — gRPC-Gateway REST transcoding
- `proto/gen/openapi.yaml` — OpenAPI 3.0.3 spec (the closest analogue to a "public schema" document), embedded via `proto/openapi_embed.go`
- `web/src/types/proto/` — TypeScript client types

**Server implementation:** `server/router/api/v1/` — each `*_service.go` implements a service, with `connect_services.go` wiring Connect handlers over the gRPC implementations. Public (unauthenticated) endpoints are declared in `server/router/api/v1/acl_config.go`, which its own comment calls the "SINGLE SOURCE OF TRUTH for public endpoints."

Additional non-proto routers exist under `server/router/`: `rss/`, `mcp/`, `fileserver/`, and SSE streaming (`server/router/api/v1/sse_handler.go`).

Note that generated files must not be hand-edited — change the `.proto` and re-run `buf generate` (`AGENTS.md`).
