**Computation site**

- `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74` is the single entry point. It ensures `memo.Payload` exists, calls the markdown service, and assigns `memo.Payload.Tags` and `memo.Payload.Property`.
- The actual extraction is `(*service).ExtractAll()` in `internal/markdown/markdown.go:356` — one goldmark parse plus a single `gast.Walk` over the AST. (A narrower `ExtractProperties()` at `internal/markdown/markdown.go:193` does the same property logic; `ExtractAll` is what the payload rebuild uses.)
- Stored as `MemoPayload.Property` (`proto/store/memo.proto:15`), surfaced to the API as the OUTPUT_ONLY `Memo.property` (`proto/api/v1/memo_service.proto:256,272`) via `convertMemoPropertyFromStore()` in `server/router/api/v1/memo_service_converter.go:315`.

**Triggers**

- Memo creation — `server/router/api/v1/memo_service.go:108` (in `CreateMemo`, before the store write; note the user-supplied `Location` is applied *after* the rebuild, so it isn't clobbered).
- Memo update, only when the update mask includes `content` — `server/router/api/v1/memo_service.go:447`; the recomputed payload is written along with the content via `update.Payload`.
- Bulk backfill — `(*Runner).RunOnce()` at `server/runner/memopayload/runner.go:27` walks all memos in batches of 100, rebuilding and persisting each payload. Note this runner is *not* currently wired into `server/server.go` (only `s3presign` is, at `server/server.go:163`), so it's a manual/backfill path rather than a scheduled one.

No other path recomputes it — the store layer just persists the payload blob.

**Extracted properties** (`MemoPayload_Property`)

- `has_link` — any `gast.KindLink` node (markdown.go:393).
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan` (markdown.go:396).
- `has_task_list` — any `east.KindTaskCheckBox` (markdown.go:399).
- `has_incomplete_tasks` — a task checkbox with `IsChecked == false` (markdown.go:401-405).
- `title` — plain text of the document's **first block-level child if and only if it is an H1** heading; gathered by `extractHeadingText()`/`extractTextFromNode()` (markdown.go:173-190), which recursively concatenates `gast.Text` segments so inline markup is stripped. The `firstBlockChecked` flag (markdown.go:368, 384-389) means an H1 further down the document does not set the title.

The same walk also fills `Payload.Tags` (deduped, case-preserving) and `Mentions`, so tags are refreshed by the same triggers. Separately, the list/preview `snippet` field is *not* stored — it's computed per-response by `getMemoContentSnippet()` at request time (`server/router/api/v1/memo_service_converter.go:76,225,248`).
