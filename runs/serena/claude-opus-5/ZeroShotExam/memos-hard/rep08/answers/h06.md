**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`**

All six paths call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (line 42–55) call `Post`, which is the sole place the request is built and sent (`safeClient.Do(req)` at line 152). `safeClient`'s `safeDialContext` (line 59) is the SSRF guard — it resolves the host and rejects reserved/private IPs at dial time.

Note on a separate family: `GetLinkMetadata` / `BatchGetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go`) also make outbound requests, converging on `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go`), but those URLs come in per-request rather than being user-configured/stored, so they're a distinct path from the webhook one above.
