**h11.**

**1st: `store.User`; 2nd: `store.Memo`** — 7 vs. 6 external packages.

**The data layer** is the `store` package (`store/*.go`), whose persistent entity types are `Memo` (`store/memo.go:35`), `User` (`store/user.go:29`), `Attachment` (`store/attachment.go:16`), `Inbox` (`store/inbox.go:24`), `MemoRelation` (`store/memo_relation.go:16`), `MemoShare` (`store/memo_share.go:6`), `Reaction` (`store/reaction.go:7`), `UserIdentity` (`store/user_identity.go:8`), `UserSetting` (`store/user_setting.go:13`), `IdentityProvider` (`store/idp.go:12`), and `InstanceSetting` (`store/instance_setting.go:14`).

Counting distinct Go packages outside `store/` (so excluding the driver packages `store/db/{sqlite,postgres,mysql}` and `store/test`, which are part of the layer):

| Type | Ext. packages | Ext. references | Packages |
|---|---|---|---|
| **User** | **7** | ~99 | `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/auth`, `server/notification`, `server/router/rss`, `server/router/frontend` |
| **Memo** | **6** | ~73 | `server/router/api/v1`, `server/notification`, `server/router/api/v1/test`, `server/router/rss`, `server/router/frontend`, `server/runner/memopayload` |
| Attachment | 4 | ~43 | api/v1, api/v1/test, fileserver, rss |
| MemoShare / MemoRelation / Inbox | 3 each | — | — |

`User` edges ahead of `Memo` because it additionally reaches `server/auth` (session/token handling) and `server/router/fileserver` (avatar + attachment access control), while `Memo` picks up only `server/runner/memopayload`. Both are dominated by `server/router/api/v1`, which alone accounts for ~62 `store.User` and ~46 `store.Memo` references.

Two notes on the counting: the ranking is unchanged if you drop the `_test` package (`server/router/api/v1/test`) — User 6, Memo 5. And `UserSetting`, `InstanceSetting`, and `IdentityProvider` show near-zero external use of the *store* struct because callers consume the generated protobuf types in `proto/gen/store` (`storepb.UserSetting`, etc.) that those store structs wrap.
