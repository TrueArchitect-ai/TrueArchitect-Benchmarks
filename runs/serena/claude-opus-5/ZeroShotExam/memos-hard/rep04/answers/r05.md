**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive grep for `graphql` across the entire tree (excluding `node_modules`/`.git`) returns zero hits, and there are no `.graphql`/`.gql` files or GraphQL dependencies in any manifest. Memos does not expose a GraphQL API.

**Actual API surface: Protocol Buffers (gRPC / Connect / gRPC-Gateway REST)**

The public API is defined in `.proto` files under `proto/api/v1/`, one file per service:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto` | `AIService` |
| `proto/api/v1/common.proto` | shared enums/messages |

Key details:

- **REST mapping** comes from `google.api.http` annotations on each RPC, e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and `:35` maps `GetMemo` to `GET /api/v1/{name=memos/*}`. The design follows Google AIPs (`proto/api/v1/README.md`).
- **Code generation** is driven by `proto/buf.gen.yaml` — it emits Go protobuf/gRPC/Connect/grpc-gateway stubs into `proto/gen/`, an OpenAPI document at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`), and TypeScript clients into `web/src/types/proto/`. Regenerate with `cd proto && buf generate`.
- **Server implementations** live in `server/router/api/v1/` (e.g. `memo_service.go`, `auth_service.go`), with Connect handlers wired up in `server/router/api/v1/connect_services.go` and `connect_handler.go`. Public/unauthenticated routes are listed in `server/router/api/v1/acl_config.go`.
- `proto/store/*.proto` is separate — internal storage messages, not the public API.

This matches the README's own description: "full REST and gRPC APIs." Other non-proto surfaces exist alongside it under `server/router/`: `rss/`, `mcp/`, `fileserver/`.
