**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider integration must produce. The provider record/config shape is declared alongside it in `proto/store/idp.proto` (`IdentityProvider`, `IdentityProviderConfig` oneof, `FieldMapping`).

- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): "Package oauth2 implements the OAuth2 identity provider integration." It provides `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with PKCE `code_verifier` support), and `UserInfo`, mapping raw claims to `idp.IdentityProviderUserInfo` via the configured field mapping.

OAuth2 is the only concrete protocol that ships: `proto/store/idp.proto` declares exactly one enum value beyond unspecified (`IdentityProvider.Type.OAUTH2`) and a single-member config oneof (`oauth2_config`), and the SSO login path in `server/router/api/v1/auth_service_sso.go:119-134` branches only on `storepb.IdentityProvider_OAUTH2`. There is no OIDC-specific or SAML package.
