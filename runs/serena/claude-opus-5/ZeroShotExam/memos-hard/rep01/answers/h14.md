**Computation site; triggers; extracted properties**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` overwrites `memo.Payload.Tags` and `memo.Payload.Property` from the memo's content.
- The actual parsing lives in `internal/markdown/markdown.go` — `service.ExtractAll` (single goldmark parse + one AST walk); the equivalent per-field logic is in `ExtractTags` and `ExtractProperties` in the same file.
- Storage shape is `MemoPayload.Property` in `proto/store/memo.proto:15` ("The calculated properties from the memo content"), surfaced to the API as `Memo.property`, an `OUTPUT_ONLY` field (`proto/api/v1/memo_service.proto:256`) via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:49`).

**Triggers (recomputation)**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes `content`; the rebuilt payload is written via `update.Payload = memo.Payload` (line 451). Other mask paths (visibility, pinned, state, timestamps) don't trigger it; the `location` path sets `Payload.Location` separately (line 484), which is user-set, not derived.
- Bulk backfill: `Runner.RunOnce` (`server/runner/memopayload/runner.go:29`) rebuilds every memo in batches of 100. Note this runner is not currently wired into `startBackgroundRunners` (`server/server.go:153` registers only the s3presign runner), so it's a migration/backfill path rather than an automatic one.

**Extracted properties**
From `ExtractAll` / `ExtractProperties`:
- `tags` — all `#tag` nodes, excluding tags nested inside links/images (`asMemoTagNode`), deduplicated preserving case.
- `property.title` — plain text of the first block-level child of the document if it is an H1 heading.
- `property.has_link` — any `KindLink` node.
- `property.has_code` — any code block, fenced code block, or inline code span.
- `property.has_task_list` — any GFM task checkbox.
- `property.has_incomplete_tasks` — any task checkbox that is unchecked.

`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` does not persist them into the payload.

Related but computed on read rather than stored: the list/preview `snippet` is generated per-response by `MarkdownService.GenerateSnippet(content, 64)` in `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), called from the converter at `memo_service_converter.go:76` and `:225`.
