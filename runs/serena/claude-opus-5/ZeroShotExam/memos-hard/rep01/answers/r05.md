**Premise correction:** This repository (usememos/memos) has no GraphQL API. There are no `.graphql`/`.gql` files, no schema-definition code, and no GraphQL client or server library in either the Go module (`go.mod`) or the web app (`web/package.json`). A case-insensitive grep across the tree turns up nothing.

**Actual API surface: Protocol Buffers (gRPC / Connect / REST gateway)**

The public API contract is defined as `.proto` service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — `MemoService`
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared types

Separately, `proto/store/*.proto` defines internal persistence-layer messages, not the public API.

**Codegen** is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`; regenerate with `buf generate` per `proto/README.md`). It emits, from the same protos:
- Go message/gRPC/Connect/grpc-gateway stubs into `proto/gen/api/v1/`
- An OpenAPI 3.0.3 document at `proto/gen/openapi.yaml` (via gnostic), embedded through `proto/openapi_embed.go`
- TypeScript client types into `web/src/types/proto/`

**Serving:** `server/router/api/v1/v1.go` implements the services on `APIV1Service` and its `RegisterGateway` registers both the grpc-gateway REST handlers (paths like `/api/v1/...`) and the Connect handlers on the Echo server. The README's claim of "full REST and gRPC APIs" refers to these — the REST surface is the gateway projection of the protos, not a hand-written or GraphQL schema.

There is also an MCP server surface at `server/router/mcp/` (which builds its tool catalog from the OpenAPI doc, see `server/router/mcp/openapi.go`) and an RSS endpoint at `server/router/rss/rss.go`.
