**Mechanism: the Vite build output is embedded into the Go binary with `//go:embed` and served by an Echo static-file middleware (with SPA fallback to `index.html`); path: `server/router/frontend/frontend.go`**

Specifics:
- `//go:embed dist/*` → `var embeddedFiles embed.FS` at `/bench/repo/server/router/frontend/frontend.go:20-21`; the build artifacts live in `server/router/frontend/dist/` (a placeholder `index.html` is checked in; the real bundle is copied there at build time).
- `FrontendService.Serve` (line 40) mounts `middleware.StaticWithConfig` over `getFileSystem("dist")` (which is `fs.Sub(embeddedFiles, "dist")`, line 116), then adds `spaFallbackMiddleware`, which converts a 404 on an HTML-ish route into `c.FileFS("index.html", frontendFS)` so client-side routing works.
- Cache headers are set per request type: `no-cache…` for HTML, `public, max-age=3600` for static assets, and `…immutable` for hashed assets (lines 23–26, `setFrontendCacheHeaders`). API/SSE paths are excluded via `shouldSkipFrontendStatic`.
