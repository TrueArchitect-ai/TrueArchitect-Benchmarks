**Go `embed.FS` — the built Vite bundle is compiled into the binary and served by Echo static middleware with an SPA fallback; server/router/frontend/frontend.go**

- `//go:embed dist/*` embeds `server/router/frontend/dist` into the binary (`server/router/frontend/frontend.go:20-21`); the build copies the Vite output there (`web/` → `dist`).
- `FrontendService.Serve` mounts it via `middleware.StaticWithConfig{Filesystem: getFileSystem("dist")}` (`server/router/frontend/frontend.go:41-57`), with `getFileSystem` doing `fs.Sub(embeddedFiles, path)` (`:116`).
- Client-side routes are handled by `spaFallbackMiddleware`, which serves `index.html` on a 404 for HTML-ish paths (`server/router/frontend/frontend.go:63-80`), skipping API/asset paths via `shouldSkipFrontendStatic` (`:82`). Cache headers differ for HTML vs hashed assets (`:24-26`, `setFrontendCacheHeaders` at `:100`).
