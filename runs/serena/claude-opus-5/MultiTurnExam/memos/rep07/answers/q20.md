**Mechanism:** Server-Sent Events (SSE) — `text/event-stream` over plain HTTP, not WebSockets (`server/router/api/v1/sse_handler.go:48`).

**Hub:** `server/router/api/v1/sse_hub.go` — `SSEHub` with `NewSSEHub` (`:63`), `Subscribe` (`:71`), `Unsubscribe` (`:89`), `Broadcast` (`:115`), and per-client visibility filtering in `SSEClient.canReceive` (`:134`). The HTTP endpoint is in `sse_handler.go` (`RegisterSSERoutes` `:25`, `handleSSE` `:34`), mounted alongside the API in `server/router/api/v1/v1.go:124`. Event payload helpers are in `sse_event_helpers.go`.

**Handlers that broadcast:**
- `APIV1Service.CreateMemo` — `memo_service.go:163` (`memo.created`)
- `APIV1Service.DeleteMemo` — `memo_service.go:585` (`memo.deleted`)
- `APIV1Service.CreateMemoComment` — `memo_service_comments.go:126` (`memo.comment.created`)
- `APIV1Service.UpsertMemoReaction` — `reaction_service.go:106` (`reaction.upserted`)
- `APIV1Service.DeleteMemoReaction` — `reaction_service.go:161` (`reaction.deleted`)
