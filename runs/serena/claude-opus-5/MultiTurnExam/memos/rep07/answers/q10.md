**store/migration/sqlite/LATEST.sql**

`preMigrate` in `store/migrator.go` detects an uninitialized database and applies the full schema from `getMigrationBasePath() + LatestSchemaFileName` (`store/migrator.go:218-219`), where the base path resolves to `migration/sqlite/` for the SQLite driver and `LatestSchemaFileName` is `"LATEST.sql"` (`store/migrator.go:56`). The directory is embedded into the binary via `//go:embed migration` (`store/migrator.go:44-45`), so fresh installs skip the incremental version folders entirely.
