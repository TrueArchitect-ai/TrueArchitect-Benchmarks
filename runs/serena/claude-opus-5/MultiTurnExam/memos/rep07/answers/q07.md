**web/src/connect.ts**

All eight service clients are created there via `createClient(...)` against a shared `createConnectTransport` (`web/src/connect.ts:184-203`): `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`.

The same file also defines the auth interceptor and a separate interceptor-free `refreshTransport` with its own `refreshAuthClient` (`web/src/connect.ts:65-72`) used only for token refresh, to avoid recursion.
