**Unused scheduling infrastructure:** `server/runner/memopayload` ships a full `Runner` type with `NewRunner` (:19) and `RunOnce` (:27) that backfills memo payloads across all memos, but **nothing in the server ever constructs or starts it** — the only importer is `server/router/api/v1/memo_service.go:18`, which calls the package-level `memopayload.RebuildMemoPayload` inline during memo create (:108) and update (:447).
