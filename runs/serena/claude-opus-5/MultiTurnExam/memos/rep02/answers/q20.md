**Server-Sent Events (SSE), over `GET /api/v1/sse` with `Content-Type: text/event-stream`; server/router/api/v1/sse_hub.go; CreateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction, and (via `dispatchMemoUpdatedSideEffects`) UpdateMemo, SetMemoRelations, SetMemoAttachments**

Mechanism and hub: `SSEHub` (`server/router/api/v1/sse_hub.go:56`) keeps a set of subscribed `SSEClient`s with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close` (lines 71, 89, 115, 99); `SSEClient.canReceive` (:134) filters each event by the subscriber's user ID and role so private/protected memos aren't leaked. The endpoint is registered by `RegisterSSERoutes` at `server/router/api/v1/sse_handler.go:25` (route `/api/v1/sse`, :27) and streamed by `handleSSE` (:34, headers at :48), authenticated via Bearer token. `RegisterSSERoutes` is called during gateway setup in `server/router/api/v1/v1.go`.
