**Engine: Google CEL (`github.com/google/cel-go`), wrapped by the `internal/filter` package — `/bench/repo/internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`)**

**Mechanism:** the CEL expression is compiled to a CEL AST, lowered into a dialect-independent condition IR, and then rendered per dialect into a parameterized SQL `WHERE` fragment plus args, which each driver appends to its query.

Concretely:

- `filter.Engine` (`/bench/repo/internal/filter/engine.go:14`) builds a CEL environment from a `Schema`; `NewSchema()` (`schema.go:89`) declares the memo-filter variables, and `DefaultEngine()` (`engine.go:111`) is the memo instance (`DefaultAttachmentEngine()` at line 119 serves attachments).
- `Engine.Compile` (`engine.go:48`) parses/checks the CEL source, and `parser.go` converts the AST into the IR in `/bench/repo/internal/filter/ir.go` (`LogicalCondition`, `ComparisonCondition`, `InCondition`, `TextMatchCondition`, `RegexCondition`, …) — SQL-agnostic at this point.
- `Program.Render` / `Engine.CompileToStatement` (`engine.go:96`, `:74`) run the `renderer` in `/bench/repo/internal/filter/render.go`, which takes `RenderOptions` carrying a `DialectName` — `DialectSQLite`, `DialectMySQL`, `DialectPostgres` (`schema.go:13-16`). Dialect differences are handled there and in `Field.columnExpr` (`schema.go:321`): JSON payload access, boolean encoding (`renderJSONBoolComparison`, `render.go:357`), string length (`stringLengthExpr`, `render.go:297`), placeholder style, etc. The result is a `Statement` with a SQL string and bound args — values are parameterized, not interpolated.
- Drivers call in at query time: `/bench/repo/store/db/sqlite/memo.go:57-61` gets `filter.DefaultEngine()` and calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)`; `/bench/repo/store/db/postgres/memo.go` and `/bench/repo/store/db/mysql/memo.go` do the same with their own dialect constants.

Background docs for the package live in `/bench/repo/internal/filter/README.md` and `MAINTENANCE.md`.
