That is the only background worker the server starts. `Server.startBackgroundRunners` (`/bench/repo/server/server.go:153-174`) creates it with `s3presign.NewRunner(s.Store)`, calls `RunOnce(ctx)` inline (line 163), then runs `Run(s3Context)` in a goroutine tracked by a `WaitGroup` with its own cancel func for clean shutdown. The cadence is `runnerInterval = time.Hour * 12` driving a `time.NewTicker` (`/bench/repo/server/runner/s3presign/runner.go:27-30`); each pass, `CheckAndPresign` (line 47) re-signs S3 attachment URLs whose `LastPresignedTime` is older than ~4 days (line 88).

**Unused / not-a-runner note:**

- `server/runner/memopayload` sits in the `runner` directory but is **not** a scheduled runner and is never started by the server. `RebuildMemoPayload` (`/bench/repo/server/runner/memopayload/runner.go:74`) is called synchronously from the request path, in `APIV1Service.CreateMemo` (`/bench/repo/server/router/api/v1/memo_service.go:108`) and `UpdateMemo` (line 447).
- There is no cron/scheduler library in use — no periodic job for the memo-related work you might expect (e.g. no sweeper for orphaned `reaction` rows or expired `memo_share` grants); the only recurring timer in the server is the s3presign ticker.
