**sqlite, mysql, postgres**

The embedded migration filesystem (`//go:embed migration` in `store/migrator.go:44`) contains exactly three dialect directories:

- `store/migration/sqlite/` (with `LATEST.sql` + versioned dirs)
- `store/migration/mysql/`
- `store/migration/postgres/`

Each holds a `LATEST.sql` plus versioned subdirectories (0.17 … 0.30) of incremental migration files.
