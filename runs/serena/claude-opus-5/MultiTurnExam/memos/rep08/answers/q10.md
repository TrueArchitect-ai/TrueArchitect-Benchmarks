**store/migration/sqlite/LATEST.sql**

On a fresh install `preMigrate` detects an uninitialized DB and executes `getMigrationBasePath() + LatestSchemaFileName` (`store/migrator.go:218`), where the base path is `migration/<driver>/` (`store/migrator.go:254-255`) and the constant is `LATEST.sql` (`store/migrator.go:56`). With `driver = sqlite` that resolves to the embedded `store/migration/sqlite/LATEST.sql`, which contains the full current schema — used instead of replaying the incremental 0.17→0.30 migrations.
