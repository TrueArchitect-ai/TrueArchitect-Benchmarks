**Server-Sent Events (SSE), over `GET /api/v1/sse`; hub: `server/router/api/v1/sse_hub.go`**

- **Mechanism:** SSE. `SSEHub` (`server/router/api/v1/sse_hub.go:56`) keeps per-client channels with `Subscribe` (:71), `Unsubscribe` (:89), `Close` (:99) and `Broadcast` (:115). The HTTP endpoint is registered by `RegisterSSERoutes` (`server/router/api/v1/sse_handler.go:25`, wired in `server/router/api/v1/v1.go:125`) and served by `handleSSE` (`sse_handler.go:34`), authenticated via Bearer token. Event types are `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted` (`sse_hub.go:15-20`).

- **Memo handlers that broadcast** (all methods on `APIV1Service`):

  - `DeleteMemo` — `server/router/api/v1/memo_service.go:518`, broadcast at :585
  - `UpdateMemo` — `server/router/api/v1/memo_service.go:401`, via `dispatchMemoUpdatedSideEffects` (:513)
  - `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:16`, via the same helper (:48)

Note `CreateMemoComment` calls `CreateMemo` with SSE suppressed (`withSuppressSSE`, `memo_service_comments.go:56`) so only the comment-created event fires.
