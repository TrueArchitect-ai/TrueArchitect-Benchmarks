**Driver — store/driver.go**

The `store.Driver` interface is declared at `store/driver.go:10`. It covers connection lifecycle (`GetDB`, `Close`), `IsInitialized`, `GetDatabaseSize`, and the per-model CRUD methods (attachments, memos, users, etc.). The three backends implement it as a `DB` struct in each dialect package — `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go` — selected by `store/db/db.go`.
