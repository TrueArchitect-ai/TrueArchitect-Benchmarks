**Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoRelations, SetMemoAttachments, UpsertMemoReaction, DeleteMemoReaction**

**Mechanism** — SSE over a plain HTTP endpoint, not WebSockets. The route is mounted alongside the rest of `/api/v1` at `server/router/api/v1/v1.go:125` (`RegisterSSERoutes`), with the streaming handler in `server/router/api/v1/sse_handler.go`.

**Hub** — `SSEHub` at `server/router/api/v1/sse_hub.go:56`, with `NewSSEHub` (`:63`), `Subscribe`/`Unsubscribe` (`:71`, `:89`), `Close` (`:99`), and `Broadcast` (`:115`). Subscriptions carry the user ID and role so events can be filtered by memo visibility. Event types are declared at `sse_hub.go:15-20`: `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`.
