**store/migration/sqlite/LATEST.sql**

On a fresh install `preMigrate` detects an uninitialized DB and applies the single latest-schema file rather than replaying incremental migrations. The path is built as `getMigrationBasePath() + LatestSchemaFileName` (`store/migrator.go:218`), where the base path is `migration/<driver>/` (`store/migrator.go:254-256`) and the filename constant is `LATEST.sql` (`store/migrator.go:56`) — resolving to `migration/sqlite/LATEST.sql` within the embedded FS (`//go:embed migration`, `store/migrator.go:44-45`), i.e. `store/migration/sqlite/LATEST.sql` on disk.
