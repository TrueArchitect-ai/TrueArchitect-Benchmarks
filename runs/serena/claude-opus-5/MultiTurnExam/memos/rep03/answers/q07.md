**web/src/connect.ts**

All the ConnectRPC clients are created and exported there (`web/src/connect.ts:192-203`) from a shared `transport`: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. The same file also defines the transport and interceptors, plus a separate `refreshAuthClient` on a dedicated `refreshTransport` (`web/src/connect.ts:72`) used for token refresh.
