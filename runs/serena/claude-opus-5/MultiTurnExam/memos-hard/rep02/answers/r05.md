**Premise correction: there is no GraphQL in this repository. No schema file, no server library, no client.** A case-insensitive grep for `graphql`, `gqlgen`, and `apollo` across Go sources, `go.mod`, `package.json`, and the TypeScript frontend returns zero hits, and `find` locates no `.graphql` or `.gql` files anywhere.

**Actual API surface: Protobuf-defined RPCs, served over three transports.**

**Schema definition** — `proto/api/v1/*.proto`, eight services:

| service | file |
|---|---|
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `AIService` | `proto/api/v1/ai_service.proto:11` |

RPCs carry `google.api.http` annotations, so each method also has a REST binding — e.g. `MemoService` declares `CreateMemo`, `ListMemos`, `GetMemo`, `UpdateMemo`, `DeleteMemo`, comments, reactions, shares, and link metadata (`proto/api/v1/memo_service.proto:21-143`).

**Code generation** is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`), emitting Go into `proto/gen/api/v1/` — message types, gRPC stubs, Connect handlers (`proto/gen/api/v1/apiv1connect/`), and gRPC-Gateway REST shims (`*.pb.gw.go`) — plus TypeScript clients under `web/src/types/proto/`.

**Transports** the server actually exposes:

- **Connect RPC** — registered in `server/router/api/v1/connect_services.go`, with interceptors in `server/router/api/v1/connect_interceptors.go`
- **REST via gRPC-Gateway** — `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:64` onward
- **MCP** — `server/router/mcp/`, exposing a curated subset (e.g. `MemoService_ListMemos`, `MemoService_GetMemo` at `server/router/mcp/catalog.go:12-14`)

**The closest analogue to "a schema for the public API"** is the generated **OpenAPI** document: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` and exposed by `OpenAPIYAML()` in `proto/openapi_embed.go`. If you were looking for a machine-readable contract to hand to API consumers, that file — not a GraphQL SDL — is it.
