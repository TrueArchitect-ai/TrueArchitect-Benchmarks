**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`; Triggers: `CreateMemo` (always) and `UpdateMemo` (only when the update mask includes `content`); Extracted: `Tags []string` plus `Property{HasLink, HasCode, HasTaskList, HasIncompleteTasks, Title}`**

**Where it's computed.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`) initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns exactly two fields back onto the memo:

```go
memo.Payload.Tags = data.Tags        // server/runner/memopayload/runner.go:85
memo.Payload.Property = data.Property // :86
```

Those two lines are the only assignments to `Payload.Tags` / `Payload.Property` anywhere in the backend, so this function is the single source of derived memo metadata.

**Triggers (both in the memo RPC handlers):**

- **Create** — `server/router/api/v1/memo_service.go:108`, inside `CreateMemo`, after the content-length check and before `Store.CreateMemo`. Unconditional for every new memo.
- **Update** — `server/router/api/v1/memo_service.go:447`, inside `UpdateMemo`'s update-mask loop, guarded by `if path == "content"` (`memo_service.go:436`). The rebuilt payload is then attached to the update via `update.Payload = memo.Payload` (`:452`). Changing visibility, pinned state, location, etc. does **not** recompute it.

Note `Payload.Location` is set separately from user input (`memo_service.go:111`) and is not derived — and because `RebuildMemoPayload` overwrites only `Tags` and `Property`, that user-set field survives recomputation.

**What `ExtractAll` extracts** (single goldmark AST walk, `internal/markdown/markdown.go:356-420`):

- **`Tags`** — text of every custom `MemoTagNode` (`#tag`), deduplicated with original case preserved via `uniquePreserveCase`.
- **`Property.Title`** — text of the first H1, but only if the document's *first* block-level child is a level-1 heading (`markdown.go:383-389`).
- **`Property.HasLink`** — any `gast.KindLink` node.
- **`Property.HasCode`** — any code block, fenced code block, or inline code span.
- **`Property.HasTaskList`** — any GFM task checkbox; **`Property.HasIncompleteTasks`** — set additionally when a checkbox is unchecked (`markdown.go:398-405`).

The proto definition of these fields is `proto/store/memo.proto:15-22`. `ExtractedData` also carries `Mentions` (`markdown.go:379-381`), but `RebuildMemoPayload` discards it — mentions are consumed separately by `server/router/api/v1/memo_mention_helpers.go:32` for inbox notifications rather than stored on the payload.

One dangling path worth flagging: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) is a batch backfill that would rebuild payloads for all memos, but it has no caller in the tree — so there is no mechanism that recomputes existing memos' metadata after, say, a markdown-extraction change; only create and content-update do.
