**Premise correction: there is no GraphQL anywhere in this repository.** A case-insensitive search across Go, TypeScript, JSON, and `go.mod` for `graphql`, `gqlgen`, `.graphql`, and `schema.gql` returns zero hits — no schema file, no resolvers, no dependency.

**Actual API surface: Protobuf/gRPC service definitions, exposed over three transports.**

**Schema of record** — `.proto` files in `proto/api/v1/`:
`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `common.proto`. A parallel `proto/store/` tree defines persisted payload messages (e.g. `proto/store/memo.proto:15-22` for memo properties).

**Code generation** — `proto/buf.gen.yaml` runs buf with plugins for Go structs, gRPC, Connect, grpc-gateway, gnostic-OpenAPI, and TypeScript (`target=ts`, output `web/src/types/proto`). Generated Go lands in `proto/gen/`.

**How clients reach it** (all registered in `server/router/api/v1/v1.go`):

1. **REST/JSON via grpc-gateway** — each service registered at `v1.go:96-122`, served under `/api/v1/*` and `/file/*` (`v1.go:128-129`).
2. **Connect RPC** (replaces grpc-web for browsers) — `v1.go:139-145`, served under `/memos.api.v1.*` with the metadata/logging/recovery/auth interceptor chain.
3. **Server-Sent Events** — `RegisterSSERoutes(gwGroup, s.SSEHub, ...)` at `v1.go:125`.

**Machine-readable description** — an OpenAPI (not GraphQL) spec is generated to `proto/gen/openapi.yaml` and embedded into the binary via `proto/openapi_embed.go:5-11`; it backs the MCP tool catalog in `server/router/mcp/`.

**Non-RPC HTTP surfaces** outside the proto schema: the file server (`/file/attachments/...`, `/file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:123-124`), RSS feeds (`server/router/rss/rss.go`), and the SPA/sitemap frontend routes (`server/router/frontend/frontend.go`).
