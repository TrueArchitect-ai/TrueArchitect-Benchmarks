**Premise correction: there is no GraphQL in this repository.** No `.graphql`/`.gql` files exist, `go.mod` has no `gqlgen`/`graphql-go`, and a grep across Go, TypeScript, and JSON sources for `graphql` returns zero hits. There is no schema, resolver, or `/graphql` endpoint to point at.

**Actual API surface: Protocol Buffers, exposed three ways from one definition.**

**Schema source of truth** — 9 `.proto` files under `proto/api/v1/`:
`instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared `common.proto`. (A parallel `proto/store/` tree defines persisted payload types, not the public API.)

**Code generation** is driven by buf (`proto/buf.gen.yaml`), which fans the same schema out to five targets: protobuf Go types, gRPC stubs, Connect handlers, a gRPC-Gateway (proto → REST/JSON), and an OpenAPI spec — all into `proto/gen/` — plus TypeScript clients emitted directly into `web/src/types/proto`.

**Runtime surfaces**, wired in `server/router/api/v1/v1.go`:

1. **gRPC-Gateway REST/JSON** — `runtime.NewServeMux` with an auth middleware, then `RegisterInstanceServiceHandlerServer`, `RegisterAuthServiceHandlerServer`, `RegisterUserServiceHandlerServer`, `RegisterMemoServiceHandlerServer`, `RegisterAttachmentServiceHandlerServer`, `RegisterAIServiceHandlerServer`, `RegisterShortcutServiceHandlerServer`, `RegisterIdentityProviderServiceHandlerServer` (`server/router/api/v1/v1.go:96-120`).
2. **Connect RPC** — `ConnectServiceHandler` implements the same methods over connect-go (`server/router/api/v1/connect_services.go`), sharing the identical authorizer.
3. **OpenAPI descriptor** — generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed`, served through `proto.OpenAPIYAML()` (`proto/openapi_embed.go:5-11`).

Two additional non-proto HTTP surfaces exist alongside the API: the file server at `/file/...` (`server/router/fileserver/fileserver.go:121-125`) and RSS feeds (`server/router/rss/rss.go`).

If the question behind this was "how do I query the public API," the answer is REST/JSON (or Connect) against the generated endpoints, with the OpenAPI spec as the reference — the closest analogue to a schema document here is `proto/gen/openapi.yaml`, derived from `proto/api/v1/*.proto`.
