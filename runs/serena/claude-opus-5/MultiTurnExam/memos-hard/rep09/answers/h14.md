**Computation site: `memopayload.RebuildMemoPayload` → `markdown.Service.ExtractAll`; Triggers: memo create, memo content update (and the comment path, via create); Extracted: `Tags` + `Property{Title, HasLink, HasCode, HasTaskList, HasIncompleteTasks}`**

**Where it's computed.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`) is the single entry point. It ensures `memo.Payload` is non-nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns the results onto the payload:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

The real work happens in `(*service).ExtractAll` (`internal/markdown/markdown.go:356-421`), which parses the content once with goldmark and does a **single AST walk** — the comment at `:79` notes this is deliberately one pass rather than separate extraction calls.

**Triggers — 2 production call sites, both in the memo service:**

| Trigger | Path |
|---|---|
| `CreateMemo` — before `Store.CreateMemo` | `server/router/api/v1/memo_service.go:108` |
| `UpdateMemo` — only when the update mask contains `content` | `server/router/api/v1/memo_service.go:447` |

The update case is guarded by `if path == "content"` (`memo_service.go:436`), so changing visibility, pinning, etc. does not recompute. `CreateMemoComment` also gets fresh metadata, but indirectly — it delegates to `s.CreateMemo` at `server/router/api/v1/memo_service_comments.go:56`. A third, dead trigger exists: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) would rebuild every memo in batches of 100, but nothing constructs that runner.

**What's extracted** (into `storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-95`):

- **`Tags`** — from custom `MemoTagNode`s, deduplicated preserving original case via `uniquePreserveCase` (`internal/markdown/markdown.go:377`, `:417`).
- **`Title`** — text of the first block-level child *only if* it's an H1 heading (`:383-389`).
- **`HasLink`** — any `KindLink` node (`:393-394`).
- **`HasCode`** — any code block, fenced code block, or inline code span (`:396-397`).
- **`HasTaskList`** — any GFM task checkbox (`:399-400`).
- **`HasIncompleteTasks`** — set when some checkbox has `IsChecked == false` (`:401-405`).

Note that `ExtractAll` also collects `Mentions` (lowercased, deduped — `:379-380`), but `RebuildMemoPayload` does not persist them; mentions are consumed separately for notifications rather than stored on the memo payload.
