**Convergence.** All four `Dispatch*Webhook` methods (`server/router/api/v1/memo_service_webhooks.go:15,20,25,30`) load the target user's webhooks via `s.Store.GetUserWebhooks` and call `webhook.PostAsync` — at `memo_service_webhooks.go:43` for the comment case and `:71` inside the shared `dispatchMemoRelatedWebhook` for create/update/delete. `PostAsync` (`internal/webhook/webhook.go:184`) is the single function every path passes through; it enqueues onto a 128-slot channel drained by four goroutines from `init()` (`internal/webhook/webhook.go:39-55`).

If you want the point where delivery itself happens rather than the last synchronous convergence, that's `webhook.Post` (`internal/webhook/webhook.go:120`), issuing `safeClient.Do` at `:152`. The URL is user-configured per-user webhook data from the store, which is why it's guarded by `ValidateURL` at registration and `safeDialContext` at dial time.
