**`(*sqlite.DB).CreateMemo` — `store/db/sqlite/memo.go:16` (the `INSERT INTO \`memo\` …` at `store/db/sqlite/memo.go:41`); determination: traced the runtime driver-selection chain from the CLI default through the factory, rather than reading the call site**

**Why this one, out of three identical candidates.** The interface method `CreateMemo` has three implementations — `store/db/sqlite/memo.go:16`, `store/db/postgres/memo.go:16`, `store/db/mysql/memo.go:16`. The call site itself can't tell you which runs: `Store.CreateMemo` validates the UID and then dispatches through the `Driver` interface at `store/memo.go:113` (`s.driver.CreateMemo(ctx, create)`), against the interface method declared at `store/driver.go:29`. So the answer is decided by which concrete value is in `s.driver`, which is fixed at startup.

**The chain I followed:**

1. **Default flag value.** `cmd/memos/main.go:122` sets `viper.SetDefault("driver", "sqlite")`, and the flag itself also defaults to `sqlite` (`cmd/memos/main.go:130`). With no flags and no env override, `viper.GetString("driver")` yields `"sqlite"`.
2. **Into the profile.** That value is copied to `Profile.Driver` at `cmd/memos/main.go:43`. `Profile.Validate` then fills in a default SQLite DSN under the data directory when none is given (`internal/profile/profile.go:108`), which matters because `sqlite.NewDB` hard-fails on an empty DSN (`store/db/sqlite/sqlite.go:25-27`).
3. **Factory selection.** `cmd/memos/main.go:58` calls `db.NewDBDriver(instanceProfile)`, whose `switch profile.Driver` takes the `"sqlite"` branch and returns `sqlite.NewDB(profile)` (`store/db/db.go:19-20`).
4. **Bound into the store.** The returned `store.Driver` is handed to `store.New(dbDriver, instanceProfile)` at `cmd/memos/main.go:64`, so `s.driver` is a `*sqlite.DB` for the process lifetime.

**Corroborating that no other path can rebind it:** `store/db/db.go` is the only file in the repo that imports any of the three driver packages (`grep -rn "usememos/memos/store/db/mysql"` and siblings return just `store/db/db.go:8-10`), and every production construction of a store goes through `db.NewDBDriver`. So on a default install the SQLite implementation is the only reachable one.
