**Premise correction: this project has no GraphQL API.** A search for `graphql`/`.graphql`/`.gql` across the Go sources, `go.mod`, and `package.json` returns zero hits — there is no schema file, no resolver layer, and no GraphQL dependency.

**Actual API surface: Protobuf/gRPC service definitions, exposed over three transports.**

- **Schema location** — `proto/api/v1/*.proto`. Eight services: `instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared types in `common.proto`. Persistence-layer messages live separately under `proto/store/`.

- **Code generation** — `proto/buf.gen.yaml` drives buf with five plugins: `protocolbuffers/go` and `grpc/go` (Go types and service stubs), `connectrpc/go` (Connect handlers), `grpc-ecosystem/gateway` (REST/JSON transcoding), and `community/google-gnostic-openapi` (OpenAPI spec). A sixth plugin, `bufbuild/es`, emits TypeScript into `web/src/types/proto` for the frontend. Generated Go lands in `proto/gen/`.

- **How it's served** — `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`) registers all eight services on a gRPC-Gateway mux (`:98-121`) and mounts it at `/api/v1/*` and `/file/*` (`:127-128`), wrapped in a request-size limit. A parallel Connect handler serves browser clients (`:131`+, with `NewConnectServiceHandler` and the interceptor chain in `server/router/api/v1/connect_interceptors.go`; per-method wiring in `server/router/api/v1/connect_services.go`). Server-sent events are registered alongside at `:124`.

So the closest analogue to "the schema for the public API" is the `.proto` files in `proto/api/v1/`, with an OpenAPI document generated from them (embedded via `proto/openapi_embed.go`) rather than a GraphQL SDL.

Non-gRPC HTTP surfaces exist too and are defined in Go rather than proto: the file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), MCP (`server/router/mcp/`), and the SPA frontend (`server/router/frontend/frontend.go`).
