**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `markdown.(*service).ExtractAll` — `internal/markdown/markdown.go:356`. Triggers: `CreateMemo` and `UpdateMemo` (only when the `content` field is in the update mask). Extracted: `Tags` plus a `Property` message — `HasLink`, `HasTaskList`, `HasCode`, `HasIncompleteTasks`, and `Title`.**

**Where it's computed.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-89`) initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, then assigns exactly two fields: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`. The real work is `ExtractAll` (`internal/markdown/markdown.go:356-420`), which does a single goldmark AST walk rather than one pass per attribute.

**Triggers — two, both in the memo service:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:107-109`, after the content-length check and before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the `if path == "content"` branch of the update-mask loop; the result is assigned to `update.Payload` at `:451`. Updates that only touch `visibility`, `pinned`, etc. do **not** recompute it, so the stored payload can only drift if content changes by some other route.

There is also a batch backfill path, `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`), which walks all memos in batches of 100 and rebuilds each — but as noted, `memopayload.NewRunner` is never called, so it doesn't run in production.

**What's extracted** (`internal/markdown/markdown.go:371-419`):

| Field | Derivation |
|---|---|
| `Tags` | `#tag` nodes via the custom tag extension, deduplicated with `uniquePreserveCase` |
| `Property.HasLink` | any `gast.KindLink` node |
| `Property.HasCode` | any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan` |
| `Property.HasTaskList` | any `east.KindTaskCheckBox` |
| `Property.HasIncompleteTasks` | a task checkbox with `IsChecked == false` |
| `Property.Title` | text of the first block-level child of the document, only if it's an H1 heading |

Schema: `proto/store/memo.proto:15-22`, generated as `MemoPayload_Property` at `proto/gen/store/memo.pb.go:85-95`.

Two things `ExtractAll` computes that are *not* persisted this way: `Mentions` (collected during the same walk but dropped by `RebuildMemoPayload`, handled separately by the mention helpers), and the preview `Snippet`, which is generated on read rather than stored — `getMemoContentSnippet` → `GenerateSnippet(content, 64)` at `server/router/api/v1/memo_service_webhooks.go:83-85`, called during conversion at `memo_service_converter.go:76` and `:225`.
