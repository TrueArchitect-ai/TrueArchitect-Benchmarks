**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74` — which delegates the parse to `(*service).ExtractAll` — `internal/markdown/markdown.go:356`.**

**Triggers (recomputation happens on exactly two paths):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the row is inserted. This also covers `CreateMemoComment`, which delegates to `CreateMemo` at `server/router/api/v1/memo_service_comments.go:55`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but **only inside the `if path == "content"` branch** (`:440-451`). Updating visibility, pinned state, location, etc. leaves the stored payload untouched.
- A third, currently unreachable trigger: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) would rebuild every memo in batches of 100 — but nothing constructs that runner, so it never executes.

**What the computation extracts** (single AST walk over the goldmark tree):

- **`Tags`** — `#tag` nodes, deduplicated with original case preserved (`internal/markdown/markdown.go:377-379`, `:415`, helper at `:456`). Tags inside links/images are deliberately skipped via `asMemoTagNode` (`internal/markdown/markdown.go:135-141`).
- **`Property.Title`** — text of the first H1, but only if the document's *first* block-level child is a level-1 heading (`internal/markdown/markdown.go:384-390`).
- **`Property.HasLink`** — any link node (`:394-395`).
- **`Property.HasCode`** — any code block, fenced code block, or inline code span (`:397-398`).
- **`Property.HasTaskList`** — any task checkbox (`:400-401`).
- **`Property.HasIncompleteTasks`** — at least one unchecked checkbox (`:402-405`).

These land on `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:85-86`) and are persisted as the JSON `payload` column (schema defined at `proto/store/memo.proto:7-22`).

Two notes on scope: `ExtractAll` also collects **`Mentions`** (lowercased, `internal/markdown/markdown.go:380-382`), but `RebuildMemoPayload` discards them — they're used for notifications, not stored on the memo. And the list **snippet** is *not* part of this stored payload; it's generated per-request from content via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83-90`).
