**Premise correction: this project has no GraphQL. There is no schema file, no resolver layer, and no GraphQL dependency** — searching `graphql`, `gqlgen`, `apollo` across Go, TS/TSX, JSON, `.proto`, and `go.mod` returns zero matches, and `find` for `*.graphql`/`*.gql` finds nothing.

**Actual API surface: Protobuf/gRPC service definitions, exposed over three transports plus a generated OpenAPI document.**

**Schema source of truth** — `.proto` files in `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`

Persistence-side messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`).

**Code generation** — driven by buf, `proto/buf.gen.yaml`, which runs five plugins: protobuf-go and grpc-go (`proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`), connectrpc-go (`proto/gen/api/v1/apiv1connect/`), grpc-gateway (`*.pb.gw.go`), and google-gnostic-openapi producing `proto/gen/openapi.yaml`. It also emits TypeScript clients straight into `web/src/types/proto` for the frontend.

**Runtime exposure** — in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`):
- **REST/JSON via grpc-gateway**: handlers registered at `server/router/api/v1/v1.go:98-121`, mounted on `/api/v1/*` and `/file/*` at `:127-128`, wrapped with a max-body limit and the auth middleware built at `:95-97`.
- **Connect RPC**: the `apiv1connect` handlers, wired in `server/router/api/v1/connect_services.go`.
- **SSE** for live updates: `RegisterSSERoutes(gwGroup, s.SSEHub, …)` at `server/router/api/v1/v1.go:124`.

**OpenAPI spec** — the generated `proto/gen/openapi.yaml` is embedded into the binary via `//go:embed` and returned by `proto.OpenAPIYAML()` (`proto/openapi_embed.go:5-11`). Its one consumer is the MCP service, which unmarshals it to build its tool catalog (`server/router/mcp/service.go:78`, types in `server/router/mcp/openapi.go`).

Non-protobuf HTTP surfaces exist alongside this — the file server (`server/router/fileserver/fileserver.go:121-124`), RSS feeds (`server/router/rss/rss.go:67`), the MCP endpoint (`server/router/mcp/service.go:108`), and frontend static/SPA routes — none of which are GraphQL either.
