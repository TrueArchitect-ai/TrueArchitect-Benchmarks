**Premise correction: this project has no GraphQL. Zero hits for `graphql`, `gqlgen`, `.graphql`, or `apollo` anywhere in the tree (including `web/`), so there is no schema file to cite.**

**Actual API surface — Protobuf/gRPC service definitions, exposed three ways:**

**Schema of record: `.proto` files in `proto/api/v1/`**
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`
- Generated Go lands in `proto/gen/api/v1/` (plus `proto/gen/store/` for persisted payload types); codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`).

**Three runtime transports, all backed by the single `APIV1Service` implementation** (`server/router/api/v1/v1.go:22-45`, which embeds the eight `Unimplemented*Server` types):

1. **REST via grpc-gateway** — services registered onto `gwMux` at `server/router/api/v1/v1.go:96-119`, mounted on `/api/v1/*` and `/file/*` at `:126-127`. This is the "public API" in the conventional sense.
2. **Connect RPC** (for the browser client, replacing grpc-web) — `server/router/api/v1/v1.go:139-144`, mounted at `/memos.api.v1.*`; handlers in `server/router/api/v1/connect_services.go`.
3. **Server-Sent Events** for live updates — `RegisterSSERoutes` at `server/router/api/v1/v1.go:123`.

**Machine-readable spec:** an OpenAPI 3 document generated from the protos, `proto/gen/openapi.yaml`, embedded into the binary via `proto/openapi_embed.go:5-11`.

Both HTTP surfaces share one auth path — `NewAuthorizer` feeds the gateway middleware (`v1.go:68-93`) and the Connect interceptor chain (`v1.go:133-137`) — with the endpoint policy in `server/router/api/v1/acl_config.go`. Separately, `server/router/mcp/` exposes a subset of these same RPCs (e.g. `MemoService_ListMemos`, `MemoService_GetMemo` in `server/router/mcp/catalog.go:12,14`) over MCP, and `server/router/fileserver/` serves binary content over plain HTTP.
