**Convergence.** All six `Dispatch*Webhook` methods (`server/router/api/v1/memo_service_webhooks.go:15-46`) build a payload per registered hook and call `webhook.PostAsync` — either at `memo_service_webhooks.go:71` (the shared `dispatchMemoRelatedWebhook`) or `:43` (the comment variant). `PostAsync` (`internal/webhook/webhook.go:184`) is the single chokepoint before delivery: it enqueues onto a 128-slot channel drained by four worker goroutines (`webhook.go:42-55`), each of which calls `Post` (`webhook.go:120`) — where the actual HTTP request goes out through the SSRF-guarded `safeClient`.

Note `dispatchMemoRelatedWebhook` is *not* the answer: the comment path bypasses it and calls `PostAsync` directly.

**One other outbound-HTTP path, excluded deliberately:** `GetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:46`, via the `fetchHTMLMeta` → `httpgetter.GetHTMLMeta` indirection declared at `memo_service.go:28`) also fetches an arbitrary user-supplied URL — but that URL comes in on the request, it isn't a stored per-user configuration, and it doesn't pass through `PostAsync`.
