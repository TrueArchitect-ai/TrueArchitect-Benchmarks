The first five funnel through `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`); the comment path has its own loop (`memo_service_webhooks.go:30`). Both loop over `Store.GetUserWebhooks` and end at `webhook.PostAsync` (`memo_service_webhooks.go:71` and `:43`) — that is the single point every path passes through. `PostAsync` only enqueues onto a 128-slot channel, so the HTTP call happens later on one of four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), inside `Post` at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). The URL comes from the per-user webhook config the user set via `CreateUserWebhook`/`UpdateUserWebhook` (`user_service_webhooks.go:74`, `:161`, `:182`).

One adjacent path worth separating out: `GetLinkMetadata` / `BatchGetLinkMetadata` (`memo_service_link_metadata.go:14`, `:19`) also make outbound HTTP via `getLinkMetadata` (line 41), but to a URL supplied in the request rather than a stored user-configured webhook target, and they don't pass through `PostAsync`.
