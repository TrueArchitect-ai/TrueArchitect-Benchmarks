**Premise correction: there is no GraphQL in this repository. A case-insensitive search for `graphql`, `gqlgen`, and `.graphql` across the entire repo (excluding `node_modules` and `.git`) returns zero files — no schema, no resolvers, no dependency, no `/graphql` endpoint.**

**Actual API surface: Protocol Buffers / gRPC service definitions, exposed over three transports.**

**Schema (the equivalent of what you were looking for):** `proto/api/v1/*.proto` — nine files defining the public API: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, and shared types in `common.proto`. Internal persistence messages live separately under `proto/store/` (e.g. `proto/store/memo.proto`). Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`.

Each RPC carries its REST mapping inline via `google.api.http` annotations — e.g. `CreateMemo` → `POST /api/v1/memos` and `ListMemos` → `GET /api/v1/memos` (`proto/api/v1/memo_service.proto:21-30`).

**Three ways clients reach it, all registered at startup:**

1. **Connect RPC** — `ConnectServiceHandler.RegisterConnectHandlers` mounts eight service handlers from the generated `apiv1connect` package (`server/router/api/v1/connect_handler.go:31-44`).
2. **REST via gRPC-Gateway** — `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`), wired from `server/server.go:88`, translating the `google.api.http` annotations into the `/api/v1/...` routes.
3. **OpenAPI document** — the generated spec `proto/gen/openapi.yaml`, embedded and served via `proto.OpenAPIYAML()` (`proto/openapi_embed.go:5-11`). This is the closest thing to a published, introspectable schema for the HTTP API.

Non-RPC HTTP surfaces exist alongside these but aren't part of the proto API: the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), MCP (`server/server.go:92-95`), and `/healthz` (`server/server.go:67`).
