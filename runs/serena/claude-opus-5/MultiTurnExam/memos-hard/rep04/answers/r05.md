**Premise correction: there is no GraphQL anywhere in this repository.** Greps for `graphql`, `gqlgen`, and `.graphql` across Go sources, `go.mod`, JSON, and TypeScript return zero hits — no schema file, no resolver layer, no GraphQL dependency on either the server or the web client.

**Actual API surface — Protobuf/gRPC definitions, exposed three ways:**

**Schema of record: `.proto` files in `proto/api/v1/`** — nine service definitions:
`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`. Persistence-layer messages live separately in `proto/store/`. Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`. The design convention is documented in `proto/api/v1/README.md` (Google AIPs).

**Three transports, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):**

1. **REST via grpc-gateway** — each service is bound to a `runtime.ServeMux` at `server/router/api/v1/v1.go:99-124`, then mounted on Echo at `gwGroup.Any("/api/v1/*", handler)` (`:130`), with a request-size cap (`http.MaxBytesHandler(..., maxAPIRequestBytes)`, `:128`). This is the "public API" in the conventional sense — the HTTP paths come from `google.api.http` annotations in the `.proto` files.
2. **Connect RPC** — used by the browser client (replacing grpc-web); handler built at `server/router/api/v1/v1.go:141` via `NewConnectServiceHandler` (`server/router/api/v1/connect_services.go`), with the interceptor chain at `:136-140`. Generated client stubs live in `web/src/types/proto/api/v1/*_pb.ts`.
3. **OpenAPI spec** — generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:5`, surfaced by `OpenAPIYAML()` (`:9`). The MCP service consumes it to build its tool catalog (`server/router/mcp/catalog.go`).

**Non-proto HTTP endpoints alongside the API:** the file server (`/file/attachments/...`, `/file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go:67`), the MCP endpoint (`server/router/mcp/service.go:108`), SSE streaming (`RegisterSSERoutes`, `server/router/api/v1/v1.go:126`), and `/healthz` (`server/server.go:67`).
