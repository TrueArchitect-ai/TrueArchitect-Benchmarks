**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`.**

**Triggers: `CreateMemo` (`server/router/api/v1/memo_service.go:108`), `CreateMemoComment` (via `s.CreateMemo` at `server/router/api/v1/memo_service_comments.go:56`), and `UpdateMemo` — but only when the update mask contains `content` (`server/router/api/v1/memo_service.go:436-451`, rebuild at `:447`).**

**Extracted properties: `tags` plus the five `MemoPayload.Property` fields — `has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks`, `title` (`proto/store/memo.proto:15-22`).**

How the pieces fit:

- `RebuildMemoPayload` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `Payload.Tags` and `Payload.Property` (`server/runner/memopayload/runner.go:74-88`). It deliberately leaves `Payload.Location` alone — that's user-supplied and is set separately at `memo_service.go:110-112`.
- `ExtractAll` does a single goldmark AST walk (`internal/markdown/markdown.go:356-420`):
  - `Tags` — from custom `MemoTagNode`s, deduplicated with case preserved via `uniquePreserveCase`.
  - `Property.Title` — text of the document's first block-level child **only if** it's an H1 (`markdown.go:383-388`).
  - `Property.HasLink` — any `gast.KindLink`.
  - `Property.HasCode` — code block, fenced code block, or code span.
  - `Property.HasTaskList` — any `east.KindTaskCheckBox`; and `Property.HasIncompleteTasks` when such a checkbox is unchecked.
  - (It also returns `Mentions`, but `RebuildMemoPayload` doesn't persist those — they're consumed for notifications at `server/router/api/v1/memo_mention_helpers.go:32`.)
- On update, the recompute is gated on `path == "content"`; the fresh payload is written back through `update.Payload = memo.Payload` (`memo_service.go:450`). Changing visibility, pinning, etc. does not recompute.
- Consumers: list/preview conversion (`memo_service_converter.go:48-49`) and user stats aggregation (`user_service_stats.go:138-151`, `:254-267`).
- Two related things that are *not* this metadata: the `Snippet` field is computed on read, per request, via `getMemoContentSnippet` (`memo_service_converter.go:76-80`) rather than stored; and `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) would rebuild payloads for all memos in batches, but as established it's never constructed or called in production.
