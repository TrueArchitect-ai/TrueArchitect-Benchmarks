**Premise correction: there is no Redis anywhere in this repository.** A repo-wide grep for `redis` (Go sources, `go.mod`, YAML, docs) returns zero hits — no client dependency, no config flag, no connection string. The cache layer is a hand-rolled, process-local in-memory cache.

**Actual mechanism:**

- **Implementation** — `store/cache/cache.go`: a `Cache` struct backed by a `sync.Map` with an atomic item counter (`store/cache/cache.go:66`), created by `cache.New(config)` (`:75`), which spawns a background `cleanupLoop` goroutine. It satisfies the local `cache.Interface` (`store/cache/cache.go:11`). Being in-process, nothing is shared across instances — a multi-replica deployment would have independent, potentially divergent caches.
- **Configuration site** — `store.New` in `store/store.go:38-45`. There's no external config: the `cache.Config` is a hardcoded literal with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`, `OnEviction: nil`. The same config value is handed to all three caches created at `store/store.go:50-52`: `instanceSettingCache`, `userCache`, `userSettingCache`. (An identical default lives in `cache.DefaultConfig()` at `store/cache/cache.go:57`, but `store.New` doesn't call it.)
- **TTL for user entries — 10 minutes.** User entries are written with `s.userCache.Set(ctx, userCacheKey(user.ID), user)` (`store/user.go:143`, `:167`), and `Set` applies the cache's `DefaultTTL` (`store/cache/cache.go:90-92`). Nothing calls `SetWithTTL` for users, so there is no per-user override. Expiry is stamped at write time (`expiration: time.Now().Add(ttl)`, `store/cache/cache.go:110`); entries are also evicted early if the 1000-item cap is exceeded (`cleanupOldest`, `store/cache/cache.go:116-118`).
- **Lookup semantics worth knowing** — `Store.GetUser` only consults the cache when finding by ID (`store/user.go:149-156`); lookups by username or email always hit the database. Explicit invalidation happens on delete via `deleteUserCache` (`store/user_delete.go:38`).
- **Shutdown** — the three caches' cleanup goroutines are stopped by `Store.Close` (`store/store.go:74-76`), reached from `Server.Shutdown` (`server/server.go:146`).
