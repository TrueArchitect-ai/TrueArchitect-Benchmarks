Engine: CEL (Google Common Expression Language, via `cel-go`) compiled by the memo filter engine in `internal/filter` — entry `filter.DefaultEngine()` in `internal/filter/engine.go`, schema `internal/filter/schema.go`, CEL→IR in `internal/filter/parser.go`, IR→SQL in `internal/filter/render.go`, store glue `internal/filter/helpers.go`. Mechanism: the handler passes the filter string into `store.FindMemo.Filters` (`server/router/api/v1/memo_service_filter.go`, `server/router/api/v1/memo_service.go:178+`), and each dialect driver calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite|DialectPostgres|DialectMySQL, &where, &args)` (e.g. `store/db/sqlite/memo.go:57-61`), so the renderer emits a dialect-specific SQL fragment plus args (`?` vs `$n` placeholders, `LIKE` vs `ILIKE`, `json_extract`/`->>`/`JSON_CONTAINS`/`@>`) that is ANDed into the `WHERE` clause.
