Engine: CEL (google/cel-go) wrapped by the in-repo filter engine at `internal/filter/` (entry `filter.DefaultEngine()` — `internal/filter/engine.go:111`; docs `internal/filter/README.md`). Mechanism: CEL text is compiled against the memo schema (`schema.go`), normalized into a dialect-agnostic IR (`parser.go`/`ir.go`), then rendered to a SQL fragment plus args for the target dialect by `render.go`, which each driver invokes via `filter.AppendConditions(..., filter.DialectSQLite|DialectMySQL|DialectPostgres, ...)` in `store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69`. The API validates the expression first in `APIV1Service.validateFilter` (`server/router/api/v1/shortcut_service.go:336`, called from `memo_service.go:207`).
