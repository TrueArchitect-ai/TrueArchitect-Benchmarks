Engine: Google CEL (`github.com/google/cel-go`) wrapped by the in-house `filter` package — `internal/filter/` (`engine.go` compiles CEL to a dialect-agnostic condition tree via `schema.go`/`ir.go`; `render.go` renders that tree to SQL). Mechanism: `ListMemos` passes filter strings down to each dialect's `ListMemos`, which calls `filter.DefaultEngine()` and `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite|DialectMySQL|DialectPostgres, &where, &args)` (`internal/filter/helpers.go:9`, `store/db/sqlite/memo.go:57-61`), so the renderer emits dialect-specific SQL fragments + placeholders (per-dialect expressions in `internal/filter/schema.go:104-148`) that are ANDed into the WHERE clause.
