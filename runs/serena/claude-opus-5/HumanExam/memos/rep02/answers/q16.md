`Store.DeleteMemo` (`store/memo.go:140-158`) deletes, before the memo row:
- `memo_relation` rows where the memo is the source (`MemoID`) and where it is the target (`RelatedMemoID`)
- all attachments linked to the memo (via `ListAttachments` + `DeleteAttachment`, incl. storage file removal)

The API handler (`server/router/api/v1/memo_service.go:568-577`) additionally deletes all comment memos first (each recursing through the same cleanup).
