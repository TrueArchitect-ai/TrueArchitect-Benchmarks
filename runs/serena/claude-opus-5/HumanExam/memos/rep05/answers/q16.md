Before deleting the memo row, `Store.DeleteMemo` (store/memo.go) deletes:
1. `memo_relation` rows where the memo is the source (`MemoID`)
2. `memo_relation` rows where the memo is the target (`RelatedMemoID`)
3. all attachments linked to the memo (`store.DeleteAttachment` per attachment, which also removes the stored file)

Additionally, the API handler first deletes all comment memos (each via `Store.DeleteMemo`, so their relations/attachments too) — server/router/api/v1/memo_service.go:569-577.
