— Premise is wrong: there is **no GraphQL schema or server** in this repository. The public API is defined in Protocol Buffers under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1/` and exposed three ways: Connect RPC handlers (`proto/gen/api/v1/apiv1connect/`, registered in `server/router/api/v1/connect_services.go`), a grpc-gateway REST/JSON surface (`APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:64`, wired at `server/server.go:88`), and OpenAPI (`proto/openapi_embed.go`). Non-RPC HTTP surfaces are the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go:67`), and MCP (`server/router/mcp/service.go`).
