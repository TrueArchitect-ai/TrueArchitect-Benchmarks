— Premise is wrong: **there is no GraphQL schema or GraphQL server** in this repo (no `graphql` string in any `.go` file or in `go.mod`). The public API is defined by **Protocol Buffers** under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto` — with Go code generated into `proto/gen/api/v1` (and Connect stubs in `proto/gen/api/v1/apiv1connect`). It is exposed over Connect RPC + gRPC‑Gateway REST, registered by `(*APIV1Service).RegisterGateway` (`server/router/api/v1/v1.go:65`, wired at `server/server.go:89`). Additional non-RPC surfaces: HTTP file serving under `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), an MCP server with an OpenAPI description (`server/router/mcp/`, incl. `openapi.go`), and `/healthz` (`server/server.go:63`).
