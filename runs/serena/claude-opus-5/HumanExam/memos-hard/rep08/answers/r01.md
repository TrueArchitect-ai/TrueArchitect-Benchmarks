— Premise is wrong on both counts: there is no Redis anywhere in the repo (no `redis` string in any `.go` file or in `go.mod`). Caching is a hand-rolled **in-process, in-memory** cache: `store/cache/cache.go` (`sync.Map` + TTL + a `cleanupLoop` goroutine, `cache.go:66-90`). The store creates three of them — `instanceSettingCache`, `userCache`, `userSettingCache` — in `store.New` at `store/store.go:38-58`, all with the same config: **DefaultTTL = 10 minutes**, CleanupInterval 5 min, MaxItems 1000 (`store/store.go:40-45`; same defaults in `cache.DefaultConfig()`, `store/cache/cache.go:57-64`). So user entries live 10 minutes; they are populated in `ListUsers`/`GetUser` (`store/user.go:143,167`) and explicitly invalidated on delete/update via `deleteUserCache` (`store/user_delete.go:39-47`).
