— Premise is wrong: there is no GraphQL schema, server, or dependency in the repo. The public API is defined as **Protocol Buffers** under `proto/api/v1/*.proto` (generated Go in `proto/gen/api/v1/`), exposed three ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64+`): Connect RPC handlers (`server/router/api/v1/connect_handler.go:31+`, `connect_services.go`), a gRPC-Gateway JSON/REST mapping, plus an SSE stream (`sse_handler.go`). Alongside it are non-RPC HTTP surfaces: the file server `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), the MCP server (`server/router/mcp/service.go`, registered `server/server.go:92-96`), and `/healthz` (`server/server.go:67`).
