— Premise is wrong: there is no Redis anywhere in the repo (no redis import, dependency, or config; grep over Go sources and `go.mod` returns nothing). Caching is an in-process, per-instance map cache: `store/cache/cache.go` (`Cache` with `sync.Map`, TTL sweep goroutine `cleanupLoop`, `store/cache/cache.go:66-89`). `Store` holds three of them — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:26-29`) — all built with the same config in `store.New`: **DefaultTTL 10 minutes**, CleanupInterval 5 minutes, MaxItems 1000 (`store/store.go:38-43`). So user entries expire 10 minutes after write; they are also written on create/update/list/get (`store/user.go:91,122,132,143,166`) and explicitly evicted on delete (`store/user_delete.go:39-47`).
