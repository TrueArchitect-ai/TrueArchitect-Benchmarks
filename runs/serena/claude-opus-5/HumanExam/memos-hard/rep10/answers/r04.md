— Premise is wrong: there is no message broker at all — neither NATS nor RabbitMQ (nor AMQP/Kafka/Redis) appears in the Go sources or `go.mod`. Webhook delivery is in-process: a buffered Go channel `asyncPostQueue` with capacity 128 (`internal/webhook/webhook.go:39`), drained by 4 worker goroutines started in `func init()` (`internal/webhook/webhook.go:42-55`), each calling `Post` (`:120`). Producers call `PostAsync` (`:184`), which drops the event with a warning when the buffer is full (`:189-195`) — so delivery is best-effort, not durable, and the queue does not survive a restart.
