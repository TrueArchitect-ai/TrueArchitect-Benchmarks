— Premise is wrong: there is no GraphQL schema, server, or dependency in this repo (no `.graphql`/`.gql` files, no `graphql` import or `go.mod` entry). The public API is Protobuf-defined and served three ways from `proto/api/v1/*.proto` (`ai_service`, `attachment_service`, `auth_service`, `idp_service`, `instance_service`, `memo_service`, `shortcut_service`, `user_service`, `common`): Connect RPC handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`), a gRPC-Gateway REST/JSON layer registered by `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`, generated `proto/gen/api/v1/*.pb.gw.go`), and generated Connect stubs in `proto/gen/api/v1/apiv1connect`. Additional non-RPC surfaces: SSE (`server/router/api/v1/sse_handler.go`), an MCP endpoint (`server/router/mcp/`), RSS (`server/router/rss/rss.go`), the HTTP file server (`server/router/fileserver/fileserver.go`), and `/healthz` (`server/server.go:67`).
