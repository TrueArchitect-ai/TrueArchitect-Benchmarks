— Premise is wrong: there is no per-user (or any) rate-limiting middleware in this codebase. The only Echo middleware registered is `middleware.Recover()` and the CORS middleware (`server/server.go:51-52`), plus auth middleware/interceptors in `server/router/api/v1/v1.go:68+`. No `golang.org/x/time/rate`, no limiter/throttle code, and nothing in `go.mod`. The closest things are *concurrency* limits, not rate limits: `semaphore.NewWeighted(3)`/`(2)` for thumbnail and image processing (`server/router/api/v1/v1.go:59-60`), `maxConcurrentThumbnails` in the file server (`server/router/fileserver/fileserver.go:116`), a 128-slot webhook dispatch queue (`internal/webhook/webhook.go:39`), and a `maxAPIRequestBytes` body cap (`server/router/api/v1/v1.go:20`).
