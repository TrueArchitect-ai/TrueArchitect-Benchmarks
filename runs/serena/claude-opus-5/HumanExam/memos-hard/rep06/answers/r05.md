— False premise: **there is no GraphQL schema or GraphQL endpoint** (no `graphql` reference in any Go file, `go.mod`, or the web `package.json`). The public API is Protobuf/gRPC-defined: service definitions in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), exposed over HTTP two ways — a gRPC-Gateway REST surface plus Connect RPC handlers (`APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65`; `ConnectServiceHandler.RegisterConnectHandlers`, `server/router/api/v1/connect_handler.go:31`), registered at `server/server.go:88`. Additional non-gRPC surfaces: RSS (`server/router/rss/rss.go:68-69`), the HTTP file server (`server/router/fileserver/fileserver.go:122-124`), MCP (`server/router/mcp`, `server/server.go:92-96`), and `/healthz` (`server/server.go:67`).
