— Premise is wrong: there is no GraphQL schema or GraphQL server anywhere (no matches for `graphql` in Go sources or `go.mod`). The public API is Protobuf/gRPC-defined: service definitions live in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1`, and exposed over HTTP via grpc-gateway plus Connect RPC handlers (`server/router/api/v1/v1.go:64-141`). Additional non-gRPC surfaces: the HTTP file server (`server/router/fileserver/fileserver.go:121`), RSS (`server/router/rss/rss.go`), and MCP (`server/router/mcp/service.go`).
