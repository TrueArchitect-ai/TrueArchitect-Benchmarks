— Premise is wrong: there is no rate-limiting middleware, per-user or otherwise. Repo-wide search for `ratelimit`/`RateLimiter`/`golang.org/x/time/rate` returns nothing. The only Echo middleware registered is `middleware.Recover()` and the CORS middleware (`server/server.go:51-52`), plus static/SPA middleware in the frontend router (`server/router/frontend/frontend.go:54,59`). The only concurrency limits are `semaphore.NewWeighted(3)` for thumbnails and `NewWeighted(2)` for image processing (`server/router/api/v1/v1.go:59-60`), and a 256 MiB request-body cap (`server/router/api/v1/v1.go:20`) — resource guards, not rate limits.
