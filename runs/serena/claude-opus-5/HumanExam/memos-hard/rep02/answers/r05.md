— Premise is wrong: there is no GraphQL schema, server, or dependency (no `gqlgen`/`graphql` in `go.mod` or any source file). The public API is **protobuf/gRPC-based**, exposed three ways over a single Echo HTTP server:
- Connect-RPC handlers — `server/router/api/v1/connect_handler.go`, `connect_services.go`, generated stubs in `proto/gen/api/v1/apiv1connect/`
- gRPC-Gateway REST/JSON transcoding — registered by `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:64+`, generated `*.pb.gw.go` under `proto/gen/api/v1/`
- Service definitions in `proto/api/v1/*.proto` (memo, user, auth, attachment, instance, shortcut, idp, ai)

Plus non-RPC surfaces: `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), MCP (`server/router/mcp/`), and `/healthz` (`server/server.go:64`).
