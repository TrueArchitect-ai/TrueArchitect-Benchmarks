— Premise is wrong: neither. There is no message broker in this project — no NATS, no RabbitMQ, no queue declaration, no such dependency in `go.mod`. Webhook delivery is entirely in-process: a buffered Go channel `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` — `internal/webhook/webhook.go:38` — drained by 4 goroutines started in `init()` — `internal/webhook/webhook.go:41-53`. Producers call `webhook.PostAsync` (`:184`), which does a non-blocking send and **drops** the event with a warning when the buffer is full (`:190-195`); each worker calls `webhook.Post` (`:120`) to do the HTTP POST. Delivery is best-effort — nothing is persisted and there are no retries.
