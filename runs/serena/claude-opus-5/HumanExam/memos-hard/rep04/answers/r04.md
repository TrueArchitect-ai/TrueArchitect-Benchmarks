**Premise is wrong: there is no message broker — neither NATS nor RabbitMQ (nor Kafka/AMQP) appears anywhere** in the Go sources or `go.mod`. Webhook delivery uses an in-process buffered Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` — `internal/webhook/webhook.go:39` — drained by 4 goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), each calling `Post` (`internal/webhook/webhook.go:120`). Producers call `PostAsync` (`internal/webhook/webhook.go:184`), which drops the payload with a warning if the queue is full (`:189-195`). The queue is unbounded-durability-free: it lives only in the server process and is lost on restart.
