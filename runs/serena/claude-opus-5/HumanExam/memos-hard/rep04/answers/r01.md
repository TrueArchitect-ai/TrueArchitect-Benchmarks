**Premise is wrong: there is no Redis anywhere in this codebase** (repo-wide grep for `redis` in Go sources returns nothing; `go.mod` has no Redis client). The cache layer is a process-local in-memory cache: `store/cache/cache.go` (`Cache` backed by `sync.Map`, `store/cache/cache.go:65-72`). The store creates three of them — `instanceSettingCache`, `userCache`, `userSettingCache` — with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000` at `store/store.go:40-53`. So the answer for "TTL for user entries" is **10 minutes**, from that in-memory config, not Redis. Entries are also invalidated explicitly on user delete (`store/user_delete.go:39-47`).
