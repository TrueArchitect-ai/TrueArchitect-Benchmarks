**Premise is wrong: there is no GraphQL schema or GraphQL server in this project** (no `graphql` hit in any Go/TS source, none in `go.mod`). The public API surface is:

- **gRPC service definitions in Protocol Buffers** — `proto/api/v1/*.proto`, generated to `proto/gen/api/v1/*.pb.go` / `*_grpc.pb.go`.
- **REST/JSON via gRPC-Gateway** — `*.pb.gw.go` files, registered by `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`, called at `server/server.go:87`).
- **Connect-RPC handlers** — `proto/gen/api/v1/apiv1connect`, wired in `server/router/api/v1/connect_handler.go` / `connect_services.go`.
- **OpenAPI spec** — `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` and consumed by the MCP service (`server/router/mcp/openapi.go`, `server/router/mcp/service.go:27`).
- Plus non-RPC HTTP surfaces: file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE, and the MCP endpoint `/mcp` (`server/router/mcp/service.go:108-116`).
