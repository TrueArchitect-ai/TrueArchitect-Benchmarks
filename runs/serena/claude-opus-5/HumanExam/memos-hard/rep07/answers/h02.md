Delivery function: `webhook.Post` — `internal/webhook/webhook.go:120`; the actual HTTP call is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. It runs on 4 worker goroutines draining `asyncPostQueue` (`internal/webhook/webhook.go:39-55`), fed by `PostAsync` (`:184`).
Protection (SSRF, two layers):
- Dial-time: `safeClient`'s transport uses `safeDialContext` (`internal/webhook/webhook.go:29-37`, `:59-77`), which resolves the host and rejects reserved/private IPs via `isReservedIP` (`internal/webhook/validate.go:240`) against `reservedCIDRs` (loopback, RFC-1918, 169.254.0.0/16 IMDS, IPv6 equivalents — `internal/webhook/validate.go:210-219`). This also defeats DNS rebinding.
- Config-time: `webhook.ValidateURL` (`internal/webhook/validate.go:258`) enforces http/https + non-reserved IP when webhooks are created/updated (`server/router/api/v1/user_service_webhooks.go:74,161,182`).
- Escape hatch: `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:237`), set from the `--allow-private-webhooks` flag (`cmd/memos/main.go:47`).
