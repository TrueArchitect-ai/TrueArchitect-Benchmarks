Premise is wrong: there is no Redis anywhere in this repo (no `redis` match in any `.go` file or in `go.mod`). Caching is an in-process, in-memory cache: `store/cache/cache.go` (`Cache`, `New` at `:76`). The store creates three of them — `instanceSettingCache`, `userCache`, `userSettingCache` — in `store.New` (`store/store.go:26-28`, `:48-50`) with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5m`, `MaxItems: 1000` (`store/store.go:39-43`; same defaults in `store/cache/cache.go:59`). So user entries expire after **10 minutes**, and are also invalidated explicitly on delete (`store/user_delete.go:39-47`).
