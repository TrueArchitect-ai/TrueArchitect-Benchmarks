Premise is wrong: there is no GraphQL schema or GraphQL server in this repo (no `graphql` match in Go sources or `go.mod`). The public API is gRPC/Protobuf defined under `proto/api/v1/*.proto`, generated into `proto/gen/api/v1/`, and exposed over HTTP three ways: gRPC-Gateway REST (`server/router/api/v1/v1.go` `RegisterGateway`, `proto/gen/api/v1/*.pb.gw.go`), Connect RPC handlers (`server/router/api/v1/connect_services.go`, `proto/gen/api/v1/apiv1connect/`), plus an OpenAPI document (`proto/openapi_embed.go`) and an MCP surface (`server/router/mcp/`). Non-RPC HTTP surfaces are the file server (`server/router/fileserver/fileserver.go:121-125`) and RSS (`server/router/rss/rss.go`).
