**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` that attaches a `Bearer` access token to every request via the `Authorization` header, and handles transparent token refresh on `Unauthenticated` errors. Token state is managed in `web/src/auth-state.ts`.

**Token kinds:**
- **Access token** (short-lived JWT) — stored in memory and localStorage, sent as `Bearer <token>` on each request
- **Refresh token** (longer-lived) — sent via HTTP cookie (`credentials: "include"`) to obtain new access tokens via `AuthService.RefreshToken`
- **Personal Access Token (PAT)** — also accepted as a bearer token on the backend

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`), all resolved through `Authenticate` / `resolveBearer`.
