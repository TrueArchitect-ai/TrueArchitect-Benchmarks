**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `google/cel-go`, wrapped in a custom `filter.Engine` at `internal/filter/engine.go`.

**Mechanism:** The handler passes the filter string (stored in `FindMemo.Filters`) down to each dialect's `ListMemos` implementation, which calls `filter.AppendConditions()` (`internal/filter/helpers.go`). This function compiles each CEL expression into a dialect-agnostic condition tree via the `Engine` (`internal/filter/parser.go`), then renders it into parameterized SQL using a dialect-aware renderer (`internal/filter/render.go`) that accepts `filter.DialectSQLite`, `filter.DialectMySQL`, or `filter.DialectPostgres` to produce the correct placeholder style and SQL syntax for each backend (e.g., `store/db/sqlite/memo.go:61`, `store/db/mysql/memo.go:69`, `store/db/postgres/memo.go:58`).
