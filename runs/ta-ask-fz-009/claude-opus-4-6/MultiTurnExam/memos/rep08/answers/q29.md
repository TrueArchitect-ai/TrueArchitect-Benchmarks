**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` that attaches an `Authorization: Bearer <accessToken>` header to every outgoing request. It proactively refreshes expired access tokens and reactively retries on 401 responses using a refresh token (sent via HttpOnly cookie).

**Token kinds managed:**
- **Access tokens** (short-lived JWTs, ~15 minutes) — stored in-memory on the frontend, sent as `Bearer` in the `Authorization` header
- **Refresh tokens** — stored as an HttpOnly cookie, used to obtain new access tokens via `AuthService.RefreshToken`
- **Personal Access Tokens (PAT)** — long-lived tokens for programmatic access

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates both JWT access tokens (statelessly) and PATs, and is used by both the Connect interceptor and gRPC-Gateway interceptor.
