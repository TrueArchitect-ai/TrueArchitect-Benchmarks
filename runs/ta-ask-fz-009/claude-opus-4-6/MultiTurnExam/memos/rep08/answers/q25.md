**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `google/cel-go` — the filter engine lives in `internal/filter/engine.go` (the `Engine` struct).

**Mechanism:** The CEL filter string is parsed and compiled into a dialect-agnostic condition tree (`Engine.Compile` in `internal/filter/engine.go`), then rendered into dialect-specific SQL via `Program.Render` (`internal/filter/render.go`), which accepts a `DialectName` (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`). Each database driver calls `filter.AppendConditions` with its respective dialect constant (e.g. `filter.DialectMySQL` in `store/db/mysql/memo.go:69`, `filter.DialectPostgres` in `store/db/postgres/memo.go:58`, `filter.DialectSQLite` in `store/db/sqlite/memo.go`) to compile the CEL expression into a SQL `WHERE` clause fragment with parameterized arguments appropriate for that dialect.
