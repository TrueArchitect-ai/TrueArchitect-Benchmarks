**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) — the filter engine lives in `internal/filter/` (entry point: `internal/filter/engine.go`, which wraps `cel-go`).

**Mechanism:** Each dialect driver (e.g. `store/db/sqlite/memo.go:57–61`) calls `filter.DefaultEngine()` to obtain a shared CEL `Engine`, then calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`) passing the filter strings, a dialect constant (e.g. `filter.DialectSQLite`, `filter.DialectMySQL`, `filter.DialectPostgres`), and pointers to the `WHERE` clause and args slices. The engine compiles the CEL expression into a dialect-agnostic condition tree (`internal/filter/parser.go` → `internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) walks that tree and emits dialect-specific SQL fragments with parameterized placeholders, switching on the dialect for syntax differences (placeholder style, JSON operators, date functions, etc.).
