**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` registered on the transport (line 188).

**Token kinds:** The interceptor manages two token types:
- **Access token** (short-lived JWT) — attached as a `Bearer` token in the `Authorization` header on every request. Managed via `web/src/auth-state.ts` (`getAccessToken`, `setAccessToken`, `isTokenExpired`).
- **Refresh token** (sent as an HTTP-only cookie via `credentials: "include"`) — used to obtain a new access token when the current one expires or a 401 is received, by calling `AuthService.refreshToken`.

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens / PATs (`AuthenticateByPAT`).
