**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) — the filter engine lives in `internal/filter/` (core in `internal/filter/engine.go`, schema declarations in `internal/filter/schema.go`).

**Mechanism:** The handler at `server/router/api/v1/memo_service.go` passes the raw filter string into `memoFind.Filters`. Each dialect driver (e.g. `store/db/sqlite/memo.go`) calls `filter.DefaultEngine()` to create a CEL engine, then calls `filter.AppendConditions()` (`internal/filter/helpers.go`) which compiles each CEL filter expression via `Engine.CompileToStatement()` with a dialect-specific `RenderOptions{Dialect: DialectSQLite|DialectMySQL|DialectPostgres}`, producing a `Statement` containing dialect-appropriate SQL fragments and parameterized args that are appended to the query's `WHERE` clause.
