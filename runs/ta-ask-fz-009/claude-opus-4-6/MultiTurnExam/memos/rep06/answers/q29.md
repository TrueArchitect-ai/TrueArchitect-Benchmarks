**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` that attaches a `Bearer` access token to every request's `Authorization` header, handles proactive token refresh before expiry, and reactively refreshes on `Unauthenticated` (401) errors.

**Token kinds managed:**
- **Access token** (short-lived JWT, sent as `Bearer` in the `Authorization` header)
- **Refresh token** (sent via HTTP cookie with `credentials: "include"`, used to obtain new access tokens via `AuthService.RefreshToken`)
- **Personal Access Token (PAT)** (also accepted as a `Bearer` token on the backend)

**Backend validation package:** `server/auth` — the `Authenticator` struct in `server/auth/authenticator.go` validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`).
