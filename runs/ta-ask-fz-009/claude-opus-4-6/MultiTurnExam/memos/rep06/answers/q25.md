**Engine:** A CEL (Common Expression Language) engine, powered by `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

**Mechanism:** The filter string is parsed/compiled by the CEL `Engine` into a dialect-agnostic condition tree (IR in `internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) translates that tree into SQL via `filter.AppendConditions`, which each dialect driver calls with its own dialect constant:

- SQLite: `filter.DialectSQLite` (`store/db/sqlite/memo.go:61`)
- MySQL: `filter.DialectMySQL` (`store/db/mysql/memo.go:69`)
- PostgreSQL: `filter.DialectPostgres` (`store/db/postgres/memo.go:58`)

The renderer emits dialect-specific SQL (e.g., different placeholder styles, JSON extraction syntax, and date/time functions) so each driver receives SQL appropriate to its database.
