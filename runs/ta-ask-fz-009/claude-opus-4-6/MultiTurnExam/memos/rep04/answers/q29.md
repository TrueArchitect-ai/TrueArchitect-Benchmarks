**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` attached to the transport. It sets the `Authorization: Bearer <token>` header on every request, and handles automatic token refresh on 401/Unauthenticated errors.

**Token kinds managed:**
- **Access token** (short-lived JWT) — stored in memory and localStorage (`web/src/auth-state.ts`), sent as a `Bearer` token in the `Authorization` header.
- **Refresh token** (HTTP-only cookie) — sent implicitly via `credentials: "include"` on fetch; used to obtain new access tokens via `AuthService.RefreshToken`.

**Backend validation package:** `server/auth` — contains the `Authenticator` (`server/auth/authenticator.go`) which resolves bearer tokens and validates refresh tokens, and `server/auth/token.go` which handles JWT token creation and verification.
