**Engine:** A CEL (Common Expression Language) engine, powered by `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go` (the `Engine` struct).

**Mechanism:** The filter string is compiled by the CEL engine (`Engine.Compile` in `internal/filter/engine.go`) into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), which is then rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`. Each DB driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect constant (`DialectSQLite`, `DialectMySQL`, or `DialectPostgres`), and the renderer switches on the dialect to emit the correct SQL syntax (placeholders, JSON operators, string functions, etc.) for that backend.
