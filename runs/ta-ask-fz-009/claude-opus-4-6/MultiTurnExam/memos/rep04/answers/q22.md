**Dispatcher:** `APIV1Service.DispatchMemoCreatedWebhook` (which delegates to `APIV1Service.dispatchMemoRelatedWebhook`) — `server/router/api/v1/memo_service_webhooks.go`

**Delivery package:** `internal/webhook` — the `Post` / `PostAsync` functions in `internal/webhook/webhook.go` perform the HTTP POST delivery.

**Signing mechanism:** HMAC-SHA256 following the [Standard Webhooks](https://www.standardwebhooks.com/) convention. The signing secret uses the `whsec_<base64>` format; the signature is computed as `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)` and sent via `webhook-id`, `webhook-timestamp`, and `webhook-signature` headers (`internal/webhook/webhook.go:139–149`).
