**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` attached to the shared transport. It reads the in-memory access token (via `getAccessToken()` from `web/src/auth-state.ts`), sets an `Authorization: Bearer <token>` header on every outgoing request, and handles automatic refresh on 401.

**Token kinds managed:**
- **Access token** — short-lived JWT sent as a `Bearer` token in the `Authorization` header.
- **Refresh token** — used (via `AuthService.RefreshToken` RPC, sent with `credentials: "include"` i.e. cookies) to obtain a new access token when the current one expires or a 401 is received.
- **Personal Access Token (PAT)** — also accepted as a Bearer token on the backend.

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`).
