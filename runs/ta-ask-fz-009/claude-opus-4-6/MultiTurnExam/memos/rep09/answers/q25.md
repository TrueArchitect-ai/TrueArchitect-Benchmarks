**Engine:** CEL (Common Expression Language) via `google/cel-go`, wrapped in the project's own `filter.Engine` — `internal/filter/engine.go`.

**Mechanism:** The handler (`server/router/api/v1/memo_service.go`) passes the filter string into `memoFind.Filters`. Each dialect driver (e.g. `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`) calls `filter.DefaultEngine()` to get a shared `Engine` instance, then calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with a dialect constant (`DialectSQLite`, `DialectMySQL`, or `DialectPostgres` — defined in `internal/filter/schema.go`). This compiles the CEL expression into a dialect-agnostic condition tree (`internal/filter/ir.go` / `internal/filter/parser.go`), then renders it into a dialect-specific SQL `WHERE` fragment with parameterised args (`internal/filter/render.go`), which is appended to the query's `WHERE` clause.
