**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` that attaches to all service client transports.

**Token kinds managed:**
1. **JWT access tokens** — short-lived (15 min), stored in memory/localStorage (`web/src/auth-state.ts`), sent as `Bearer` tokens in the `Authorization` header.
2. **Refresh tokens** — sent via HTTP cookie (`credentials: "include"`) to obtain new access tokens via `AuthService.RefreshToken`.
3. **Personal Access Tokens (PATs)** — long-lived tokens for API/script access, also validated as Bearer tokens on the backend.

**Backend validation package:** `server/auth` — the `Authenticator` struct (`server/auth/authenticator.go`, line 26) validates all three token types via methods like `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT`. It is used by gRPC interceptors, Connect interceptors, and the file server.
