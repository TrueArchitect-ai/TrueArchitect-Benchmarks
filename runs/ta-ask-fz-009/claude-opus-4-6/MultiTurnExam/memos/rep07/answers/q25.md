**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go` — the filter engine is `filter.Engine` in `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile` method parses the CEL filter string into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`, built by the parser in `internal/filter/parser.go`). That condition tree is then rendered into dialect-specific SQL by `Program.Render`, which delegates to a `renderer` (`internal/filter/render.go`) that accepts a `DialectName` via `RenderOptions.Dialect` and emits a parameterized SQL fragment (`Statement`) with dialect-appropriate placeholder syntax — so the same parsed IR produces correct SQL for SQLite, MySQL, and PostgreSQL without each dialect needing its own filter parser.
