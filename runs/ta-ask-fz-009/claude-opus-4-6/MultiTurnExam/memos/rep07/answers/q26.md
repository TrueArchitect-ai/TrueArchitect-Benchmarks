When `Store.DeleteMemo` runs (`store/memo.go`, lines 140–159), the following tables are affected:

1. **memo_relation** — rows where the memo is either source (`MemoID`) or target (`RelatedMemoID`) are explicitly deleted via `Driver.DeleteMemoRelation`
2. **attachment** — all attachments linked to the memo are listed and individually deleted via `Store.DeleteAttachment` (which also calls `Driver.DeleteAttachment`)
3. **memo** — the memo row itself is deleted last via `Driver.DeleteMemo`
