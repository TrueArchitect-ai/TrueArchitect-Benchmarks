**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` that attaches a `Bearer` access token to every request via the `Authorization` header, and handles automatic refresh on 401/expiry.

**Token kinds managed:**
- **Access token** (short-lived JWT, sent as `Bearer` in the `Authorization` header)
- **Refresh token** (used via `AuthService.RefreshToken` to obtain a new access token; sent as an HTTP cookie with `credentials: "include"`)
- **Personal Access Token (PAT)** (also accepted as a `Bearer` token)

**Backend validation package:** `server/auth/` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`), with the main entry point `Authenticate` resolving the `Authorization` header into an authenticated user.
