The question's premise is incorrect — **there is no GraphQL schema**. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, served over three transports:

1. **Proto definitions** — `proto/api/v1/*.proto` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.)
2. **gRPC handlers** — generated into `proto/gen/api/v1/` (e.g., `*_grpc.pb.go`) and implemented in `server/router/api/v1/`
3. **Connect (gRPC-compatible HTTP)** — generated handlers in `proto/gen/api/v1/apiv1connect/` (e.g., `memo_service.connect.go`)
4. **gRPC-Gateway (REST)** — generated reverse-proxy handlers in `proto/gen/api/v1/*.pb.gw.go`
