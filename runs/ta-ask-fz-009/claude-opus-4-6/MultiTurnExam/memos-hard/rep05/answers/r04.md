The question's premise is incorrect — **there is no message broker**. Webhook delivery does not use NATS, RabbitMQ, or any external queue. The "queue" is a plain Go buffered channel:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

declared at `internal/webhook/webhook.go:39`. Four goroutine workers are spun up in an `init()` function (same file, lines 42–55) that consume from this channel and call `Post()` synchronously. The entire mechanism is in-process with no external broker dependency.
