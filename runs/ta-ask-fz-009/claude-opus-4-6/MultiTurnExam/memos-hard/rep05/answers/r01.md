The question's premise is incorrect — **there is no Redis connection**. The cache layer is entirely **in-memory**, implemented as `cache.Cache` (`store/cache/cache.go:67`), a `sync.Map`-backed struct with TTL expiration and periodic cleanup. There is no Redis dependency anywhere in the codebase.

User entries use the **default TTL of 10 minutes** — `store.Store` creates its `userCache` via `cache.NewDefault()` (which calls `DefaultConfig()` at `store/cache/cache.go:57–64`, setting `DefaultTTL: 10 * time.Minute`), and `Store.GetUser` / `Store.ListUsers` call `cache.Set()` (`store/user.go:143`, `:150–167`), which applies the default TTL.
