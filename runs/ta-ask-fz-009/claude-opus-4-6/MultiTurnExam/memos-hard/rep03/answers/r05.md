**The premise is incorrect — there is no GraphQL schema.** The public API is defined using **Protocol Buffers (protobuf)** with gRPC, not GraphQL.

The API surface is defined in `.proto` files under `proto/api/v1/` (e.g., `memo_service`, `user_service`, `auth_service`, `attachment_service`, etc.), which generate:

- **gRPC server/client stubs** — e.g., `proto/gen/api/v1/memo_service_grpc.pb.go`, `proto/gen/api/v1/user_service_grpc.pb.go`
- **gRPC-Gateway HTTP bindings** — e.g., `proto/gen/api/v1/memo_service.pb.gw.go`, registered at `server/router/api/v1/v1.go` via `RegisterGateway`
- **Connect RPC handlers** — e.g., `proto/gen/api/v1/apiv1connect/memo_service.connect.go`, providing a second HTTP-based transport

The server exposes these APIs through both a gRPC-Gateway (REST-style HTTP endpoints under `/api/v1/`) and Connect RPC, wired in `server/server.go:88` and the Connect service handler at `server/router/api/v1/connect_services.go`.
