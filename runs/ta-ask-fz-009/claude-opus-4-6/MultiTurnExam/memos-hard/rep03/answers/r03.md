**The premise is incorrect — there is no nightly database-cleanup job.** The `internal/scheduler` package (`internal/scheduler/scheduler.go`) is a general-purpose cron scheduler library, but it is never instantiated or used in production server code. All references to `scheduler.New()` and `scheduler.Register()` appear exclusively in documentation comments (`internal/scheduler/doc.go`), example tests (`internal/scheduler/example_test.go`), and integration tests (`internal/scheduler/integration_test.go`). The "daily-cleanup" at 2 AM is just an illustrative example in the doc comments (line 15) and example tests (line 98), not a registered production job.

The only background task wired into the server is the S3 presign runner (`server/runner/s3presign/runner.go`), which uses a simple `time.Ticker` (every 12 hours), not the scheduler package, and it refreshes presigned URLs — not database cleanup.
