**The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ).** The webhook delivery workers consume from a plain in-process Go buffered channel, not an external message broker.

The "queue" is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in `init()` (`internal/webhook/webhook.go:42–55`) that range over this channel, each calling `Post()` synchronously for every payload received. Callers enqueue payloads via `PostAsync()` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the payload with a warning log if the channel is full.
