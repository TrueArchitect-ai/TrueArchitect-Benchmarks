The premise is incorrect — **there is no GraphQL schema**. The public API is not defined using GraphQL.

The API surface is defined using **Protocol Buffers (protobuf)** with **gRPC**, plus HTTP/JSON bindings via **gRPC-Gateway** and **Connect**. The proto definitions live under `proto/` (e.g., `proto/gen/api/v1/memo_service.pb.go`, `proto/gen/api/v1/user_service.pb.go`, etc.), with Connect service handlers wired in `server/router/api/v1/connect_services.go` and gRPC-Gateway handlers in the `*.pb.gw.go` generated files. The server exposes both gRPC and REST-style HTTP endpoints from these definitions.
