The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) anywhere in this codebase.

The webhook delivery workers consume from a **plain Go buffered channel** (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutines are spawned in an `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel and call `webhook.Post` for each payload. Callers enqueue work via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the payload with a warning log if the channel is full. The entire mechanism is in-process with no external infrastructure.
