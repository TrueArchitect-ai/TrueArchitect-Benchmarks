**Delivery function** — `webhook.Post` (`internal/webhook/webhook.go:120`). It JSON-marshals the payload, optionally HMAC-signs it (Standard Webhooks headers), and sends the POST via `safeClient`. Callers can also use `webhook.PostAsync` (line 184), which enqueues onto a buffered channel drained by 4 goroutines (lines 42–55), each of which calls `Post`.

**Protection mechanism** — SSRF guard with two layers, both in `internal/webhook/`:

1. **At registration/save time**: `ValidateURL` (`internal/webhook/validate.go:62`) resolves the hostname and rejects any URL whose DNS resolves to a reserved/private IP (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents — CIDRs listed at `validate.go:14–23`), checked via `isReservedIP` (`validate.go:44`).

2. **At connection time**: the `safeClient` HTTP client (`internal/webhook/webhook.go:32–37`) uses a custom `Transport` whose `DialContext` is `safeDialContext` (`webhook.go:59`). This function re-resolves the hostname immediately before dialing and rejects connections to any reserved IP range — defeating DNS rebinding attacks that might return a safe IP at validation time but a private IP later.

The guard can be bypassed for self-hosted environments via the `--allow-private-webhooks` CLI flag (`cmd/memos/main.go:133`), which sets `webhook.AllowPrivateIPs = true` (`cmd/memos/main.go:49`).
