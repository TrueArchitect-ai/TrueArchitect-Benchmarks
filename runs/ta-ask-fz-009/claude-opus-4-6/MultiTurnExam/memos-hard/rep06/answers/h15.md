Memo visibility is enforced at these distinct sites:

1. **`APIV1Service.checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39` — Central gRPC-layer gate used by `GetMemo` (line 356), `ListMemoComments` (line 148 of `memo_service_comments.go`), and checks comment parent access. Blocks unauthenticated users from non-PUBLIC memos; blocks non-creators from PRIVATE memos.

2. **`APIV1Service.ListMemos` query-level visibility filtering** — `server/router/api/v1/memo_service.go:218–227` — Injects SQL-level filters so anonymous users only see PUBLIC memos, authenticated users see their own + PUBLIC + PROTECTED, and viewing another user's memos restricts to PUBLIC + PROTECTED.

3. **`APIV1Service.checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go:422` — Enforces the linked memo's visibility when accessing an attachment via the gRPC attachment endpoint. PUBLIC = open, PRIVATE = creator/admin only.

4. **`FileServerService.checkAttachmentPermission`** — `server/router/fileserver/fileserver.go:650` — Enforces memo visibility on the HTTP file-serving path (`/file/attachments/…`). Checks memo visibility, share tokens, and instance-level anonymous access.

5. **`APIV1Service.CreateMemoComment` visibility check** — `server/router/api/v1/memo_service_comments.go:41` — Blocks commenting on a PRIVATE memo unless the user is the creator or a super-user.

6. **`APIV1Service.ListMemoComments` / `ListMemoRelations` query-level filtering** — `server/router/api/v1/memo_service_comments.go:156–161` and `server/router/api/v1/memo_relation_service.go:108–112` — Filters related/comment memos by visibility in SQL (anonymous → PUBLIC only; authenticated → own + PUBLIC + PROTECTED).

7. **`SSEClient.canReceive`** — `server/router/api/v1/sse_hub.go:134` — Filters real-time SSE event delivery: PRIVATE events are delivered only to the creator or admins.

8. **RSS feed query-level filtering** — `server/router/rss/rss.go:90, 141` — Only PUBLIC memos are included in RSS feeds (`VisibilityList: []store.Visibility{store.Public}`).

9. **`canViewerAccessMemo` (email notifications)** — `server/notification/email.go:306` — Gates whether email notification content is visible to the receiver based on visibility (PRIVATE → creator only, PROTECTED → authenticated users).
