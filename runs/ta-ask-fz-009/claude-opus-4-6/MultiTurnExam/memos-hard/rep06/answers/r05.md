The premise is incorrect — there is no GraphQL schema in this codebase.

The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (REST/JSON). The API surface is specified in `.proto` files under `proto/api/v1/`, with generated Go code in `proto/gen/api/v1/` (gRPC stubs like `*_grpc.pb.go`, HTTP gateway handlers like `*_pb.gw.go`). Additionally, the server exposes a **Connect RPC** interface via generated code in `proto/gen/api/v1/apiv1connect/` (e.g., `memo_service.connect.go`, `user_service.connect.go`). The gRPC-Gateway registers REST endpoints mapped from the proto definitions in `server/router/api/v1/` (wired via `APIV1Service.RegisterGateway` in `server/server.go:88`).
