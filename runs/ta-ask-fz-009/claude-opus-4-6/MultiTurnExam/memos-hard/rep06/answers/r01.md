The premise is incorrect — there is no Redis connection anywhere in this codebase. The string "redis" does not appear in any source file (confirmed by grep across all 343 Go files).

The cache layer is a **pure in-memory implementation** (`store/cache/cache.go`), built on `sync.Map` with TTL-based expiration. There is no external cache service involved.

User entries are cached using the **default cache configuration** (`DefaultConfig()` at `store/cache/cache.go:57–64`), which sets a TTL of **10 minutes** (`DefaultTTL: 10 * time.Minute`). The user cache is instantiated via `cache.NewDefault()` in the store constructor (`store/store.go`), so user entries expire after 10 minutes and are cleaned up every 5 minutes by a background goroutine.
