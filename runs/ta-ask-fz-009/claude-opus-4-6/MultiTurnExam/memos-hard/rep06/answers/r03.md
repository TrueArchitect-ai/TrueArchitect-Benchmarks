The premise is incorrect — there is no nightly database-cleanup job scheduled in this codebase. The `internal/scheduler` package (`internal/scheduler/`) is a general-purpose cron scheduler library, but it is never instantiated or used by the server's production code. The "daily-cleanup" job at "2 AM" appearing in the code is only an **illustrative example** in doc comments (`internal/scheduler/doc.go:15–16`) and example tests (`internal/scheduler/example_test.go:97–100`), not an actual registered job.

The server's only background runners are the S3 presign runner (every 12 hours) and potentially the memo payload runner — neither is a database cleanup job, and neither uses the scheduler package.
