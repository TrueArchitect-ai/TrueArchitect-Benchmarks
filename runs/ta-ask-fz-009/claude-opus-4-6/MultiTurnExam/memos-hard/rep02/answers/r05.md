**The premise is incorrect — there is no GraphQL schema.** The public API is defined using **Protocol Buffers (protobuf)** with gRPC, served through both a gRPC-Gateway (REST/JSON) and Connect-RPC surface. The proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/` and generated TypeScript types in `web/src/types/proto/api/v1/`. The gateway and Connect handlers are registered in `server/router/api/v1/v1.go` via `APIV1Service.RegisterGateway`. Additionally, a native HTTP file-serving surface is registered in `server/router/fileserver/fileserver.go` and an RSS surface in `server/router/rss/rss.go`.
