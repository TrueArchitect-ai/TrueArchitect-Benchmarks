**The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ).** The webhook delivery workers consume from a plain in-process Go buffered channel (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutines are spawned in `init()` (`internal/webhook/webhook.go:42–55`) to drain this channel and call `webhook.Post` for each payload. Callers enqueue work via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which does a non-blocking send to the channel (dropping the event if the buffer is full). There is no external message broker involved anywhere in the codebase.
