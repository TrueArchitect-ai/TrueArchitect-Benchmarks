**Protection mechanism — `safeDialContext` + `isReservedIP`** (`internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`). SSRF protection is implemented at **two layers**:

1. **At registration time:** `ValidateURL` (`internal/webhook/validate.go:62`) resolves the hostname and rejects URLs whose IPs fall within reserved CIDRs.
2. **At dial time (the actual guard):** The shared `safeClient` uses a custom `http.Transport` whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:34-36`). This function resolves the target host and checks every resolved IP against `reservedNetworks` — a list of private/reserved CIDRs (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) parsed at init from `reservedCIDRs` (`internal/webhook/validate.go:14-23`). This dial-time check defeats DNS rebinding attacks because it validates the IP the connection will actually use, not just what was resolved during registration.

The protection can be explicitly disabled via the `--allow-private-webhooks` CLI flag (`cmd/memos/main.go:133`), which sets `webhook.AllowPrivateIPs = true` (`cmd/memos/main.go:49`) for self-hosted deployments that need to target local services.
