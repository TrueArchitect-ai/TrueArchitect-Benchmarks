**The premise is incorrect — there is no nightly database-cleanup job.** While an `internal/scheduler` package exists (`internal/scheduler/doc.go`), it is a general-purpose cron library with no production usage — it is never instantiated or registered with any jobs in the server or command code. No database-cleanup job (nightly or otherwise) is scheduled anywhere in the codebase. The only background runners are the S3 presign runner (every 12 hours, `server/runner/s3presign/runner.go`) and the memo payload runner (not wired into production startup, `server/runner/memopayload/runner.go`).
