**Premise correction:** There is no message broker — neither NATS nor RabbitMQ is used anywhere in this codebase.

**Actual mechanism:** Webhook delivery workers consume from a plain, in-process Go buffered channel. The queue is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) to drain this channel. `webhook.PostAsync` (`internal/webhook/webhook.go:184`) enqueues payloads onto the channel with a non-blocking send (dropping if the buffer is full). Each worker calls `webhook.Post` (line 46), which performs the outbound HTTP request synchronously via the SSRF-guarded `safeClient`. There is no external broker, no persistent queue, and no cross-process messaging.
