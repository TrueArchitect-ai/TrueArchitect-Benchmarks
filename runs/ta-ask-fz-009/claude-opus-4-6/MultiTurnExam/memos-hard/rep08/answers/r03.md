**Premise correction:** There is no nightly database-cleanup job. The `internal/scheduler` package exists as a general-purpose cron scheduler library, but it is never instantiated or used by the server or any production code — it only appears in its own package-level tests and doc examples (`internal/scheduler/example_test.go`, `internal/scheduler/doc.go`).
