**Premise correction:** There is no GraphQL schema in this codebase. The public API is not defined using GraphQL.

**Actual API surface:** The API is defined using **Protocol Buffers (protobuf)** with gRPC, served via three transports:

1. **Protobuf service definitions** — `proto/api/v1/*.proto` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc.) define the RPC methods and message types.
2. **gRPC-Gateway** — generated reverse-proxy handlers in `proto/gen/api/v1/*.pb.gw.go` expose the gRPC services as a RESTful JSON API.
3. **Connect** — generated handlers in `proto/gen/api/v1/apiv1connect/*.connect.go` provide an additional HTTP-based RPC transport.

The server wires all three in `server/router/api/v1/v1.go`, registering gRPC servers, gRPC-Gateway handlers, and Connect service handlers on the Echo HTTP server.
