**Computation site:** `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which calls `markdownService.ExtractAll` (`internal/markdown/markdown.go:356`) to parse the memo content in a single goldmark AST walk.

**Triggers (operations that call `RebuildMemoPayload`):**
1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:108` — on memo creation
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:447` — on memo content update

(The batch runner `memopayload.Runner.RunOnce` at `server/runner/memopayload/runner.go:27` also calls it for every memo, but is not wired into production startup.)

**Extracted properties** (populated onto `memo.Payload`):
- **Tags** (`[]string`) — all `#tag` nodes found in the markdown, deduplicated case-insensitively (`runner.go:85`, `markdown.go:377`)
- **Property.Title** (`string`) — text of the first block-level H1 heading, if present (`markdown.go:387`)
- **Property.HasLink** (`bool`) — whether the content contains any markdown links (`markdown.go:394`)
- **Property.HasCode** (`bool`) — whether the content contains code blocks or code spans (`markdown.go:397`)
- **Property.HasTaskList** (`bool`) — whether the content contains task checkboxes (`markdown.go:400`)
- **Property.HasIncompleteTasks** (`bool`) — whether any task checkbox is unchecked (`markdown.go:403`)

These are stored in the protobuf `MemoPayload` (`memo.Payload.Tags` and `memo.Payload.Property`) and persisted alongside the memo for use in filtering, listing, and previews without re-parsing.
