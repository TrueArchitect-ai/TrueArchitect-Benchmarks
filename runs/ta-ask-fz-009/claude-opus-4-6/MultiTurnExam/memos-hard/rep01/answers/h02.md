**Delivery function** — `webhook.Post` (`internal/webhook/webhook.go:120`). It JSON-marshals the payload, builds a signed HTTP POST request, and executes it via the package-level `safeClient`. **Protection mechanism** — SSRF guard via `safeDialContext` + `isReservedIP` (`internal/webhook/webhook.go:59`; `internal/webhook/validate.go:44`). The `safeClient`'s custom `Transport` resolves the target hostname at dial time and rejects any IP that falls within a reserved/private CIDR (loopback, RFC-1918, link-local/cloud IMDS `169.254.0.0/16`, IPv6 equivalents — defined in `reservedCIDRs`, `internal/webhook/validate.go:14`). This blocks DNS-rebinding as well because the check happens after resolution, immediately before connecting. The same `isReservedIP` check is also enforced at webhook URL registration time via `ValidateURL` (`internal/webhook/validate.go:62`), giving defense in depth at both write-time and send-time.
