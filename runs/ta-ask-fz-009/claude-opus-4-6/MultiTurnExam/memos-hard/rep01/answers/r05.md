The premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed via both a **gRPC-Gateway** (REST/JSON over HTTP) and **Connect** handlers. The `.proto` service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), and the generated Go code is in `proto/gen/api/v1/` (gRPC stubs, gateway handlers) and `proto/gen/api/v1/apiv1connect/` (Connect handlers). The gateway and Connect services are registered in `server/router/api/v1/v1.go` via `APIV1Service.RegisterGateway`.
