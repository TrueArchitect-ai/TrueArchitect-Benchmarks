The question's premise is incorrect — **there is no message broker (neither NATS nor RabbitMQ)**. The webhook delivery workers consume from a plain **in-memory Go buffered channel**:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Declared at `internal/webhook/webhook.go:39`. Four goroutine workers are spawned in `init()` (`internal/webhook/webhook.go:42–55`) that range over this channel, calling `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send and drops the payload if the 128-slot buffer is full.
