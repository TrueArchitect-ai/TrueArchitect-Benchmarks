**Delivery function — `webhook.Post`** (`internal/webhook/webhook.go:120`). It serialises the payload to JSON, optionally signs it with HMAC-SHA256 (Standard Webhooks headers), and sends it via `safeClient.Do()`. An async variant, `PostAsync` (line 184), enqueues payloads to a buffered channel consumed by 4 goroutine workers that call `Post`.

**Protection mechanism — `safeDialContext` + `isReservedIP`** (`internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`). SSRF protection is enforced at two layers:

1. **At connection time (dial-level):** The `safeClient` HTTP client uses a custom `Transport` whose `DialContext` is `safeDialContext` (line 35). This function resolves the target hostname via DNS and checks every resolved IP against `reservedNetworks` — a list of parsed CIDRs covering loopback, RFC-1918 private, link-local/cloud IMDS, and IPv6 equivalents (`internal/webhook/validate.go:14–23`). If any IP is reserved, the connection is refused. This also defeats DNS rebinding because the check happens at the moment the socket is opened.

2. **At URL registration time:** `ValidateURL` (`internal/webhook/validate.go:62`) performs the same DNS-resolve-and-check when a webhook URL is created or updated, rejecting it early with a gRPC `InvalidArgument` error.

Both checks respect the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`), which defaults to `false` and can be enabled via `--allow-private-webhooks` (`cmd/memos/main.go:133`) for self-hosted deployments that need to target local-network services.
