The question's premise is incorrect — **there is no GraphQL schema**. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, plus HTTP/JSON gateway bindings. The API surface is declared in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/` (gRPC stubs like `*_grpc.pb.go`, gateway bindings like `*_gw.go`) and Connect-RPC handlers in `proto/gen/api/v1/apiv1connect/` (`*_service.connect.go`). The server exposes both gRPC and REST-style HTTP endpoints via the gRPC-Gateway and Connect protocol.
