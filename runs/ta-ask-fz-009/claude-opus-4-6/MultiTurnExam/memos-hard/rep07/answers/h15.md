Memo visibility is enforced at these distinct sites:

1. **`GetMemo` access check** — `server/router/api/v1/memo_service.go:55–66` — single-memo retrieval; rejects unauthenticated users for non-public memos, and non-owner users for private memos.

2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go:218–227` — applies visibility filters to the DB query: anonymous → PUBLIC only; authenticated viewing others → PUBLIC + PROTECTED; own memos → unfiltered.

3. **`ListAllUserStats` query-level filtering** — `server/router/api/v1/user_service_stats.go:83–91` — same visibility-scoped filter pattern applied when computing user statistics.

4. **`CreateMemoComment` access check** — `server/router/api/v1/memo_service_comments.go:33–43` — prevents commenting on a private memo the user doesn't own.

5. **`ListMemoComments` / `batchConvertMemoRelations` query-level filtering** — `server/router/api/v1/memo_service_converter.go:182–186` and `server/router/api/v1/memo_service_comments.go:158–160` — filters related/comment memos by visibility when resolving relations.

6. **`ListMemoRelations` query-level filtering** — `server/router/api/v1/memo_relation_service.go:108–112` — visibility filter on related memos.

7. **`ListMemoReactions` access check** — `server/router/api/v1/reaction_service.go:29–41` — checks memo visibility before returning reactions.

8. **`UpsertMemoReaction` access check** — `server/router/api/v1/reaction_service.go:82–85` — prevents reactions on private memos not owned by the user.

9. **`ListMemoAttachments` access check** — `server/router/api/v1/memo_attachment_service.go:213–225` — checks memo visibility before listing memo attachments.

10. **`checkAttachmentAccess` (gRPC attachment service)** — `server/router/api/v1/attachment_service.go:422–455` — enforces memo visibility when accessing linked attachments via the gRPC API.

11. **`FileServerService.checkAttachmentPermission` (HTTP file server)** — `server/router/fileserver/fileserver.go:650–704` — enforces memo visibility for attachment binary downloads, including share-token fallback.

12. **RSS feed generation** — `server/router/rss/rss.go:90,141` — hard-filters to `store.Public` only when generating RSS feeds.

13. **Email notification dispatcher (`canViewerAccessMemo`)** — `server/notification/email.go:306–319` — suppresses email notifications for memos the receiver cannot access per visibility rules.

14. **In-app notification service (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go:302–316` — filters notifications by memo visibility before delivering them.

15. **Mention notification gating (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go:56–72` — prevents mention inbox/notification creation when the target user cannot see the private memo.
