**The premise is incorrect — there is no GraphQL schema.** The public API is defined using **Protocol Buffers (protobuf)** and exposed over **gRPC** and **Connect (gRPC-compatible HTTP)**. The proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/` (gRPC stubs like `memo_service_grpc.pb.go`) and `proto/gen/api/v1/apiv1connect/` (Connect handlers like `memo_service.connect.go`). Additionally, gRPC-Gateway reverse proxies are generated (e.g., `proto/gen/api/v1/memo_service.pb.gw.go`) to expose REST-style HTTP/JSON endpoints. There is also a native HTTP file-serving surface registered via Echo in `server/router/fileserver/fileserver.go`.
