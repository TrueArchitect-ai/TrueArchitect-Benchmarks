**The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ).** The webhook delivery workers consume from a plain in-process Go buffered channel:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Declared at `internal/webhook/webhook.go:39`. Four goroutines are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) to read from this channel and call `webhook.Post` for each payload. Producers enqueue via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which does a non-blocking send to the same channel. There is no external message broker involved.
