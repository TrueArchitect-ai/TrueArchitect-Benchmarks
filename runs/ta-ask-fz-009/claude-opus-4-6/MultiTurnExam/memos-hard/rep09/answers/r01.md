The question's premise is incorrect — **there is no Redis connection**. The cache layer does not use Redis at all.

The cache is an **in-process, in-memory implementation** (`store/cache/cache.go`) backed by a `sync.Map` with TTL-based expiration and a cleanup goroutine. It is constructed in `store/store.go:51–53` via `cache.New(cacheConfig)`.

The user cache (`userCache`) shares the same default `Config` as all other caches, configured at `store/store.go:40–45`:

- **DefaultTTL:** 10 minutes
- **CleanupInterval:** 5 minutes
- **MaxItems:** 1000

No external cache service (Redis or otherwise) is referenced anywhere in the codebase.
