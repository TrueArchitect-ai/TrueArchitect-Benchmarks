The question's premise is incorrect — **there is no nightly database-cleanup job or cron scheduler wired into the server**. While an `internal/scheduler` package exists (`internal/scheduler/doc.go`), it is a general-purpose cron library used only in its own tests and examples. It is never imported or instantiated by any server code. No database cleanup job — nightly or otherwise — is registered anywhere in the codebase.
