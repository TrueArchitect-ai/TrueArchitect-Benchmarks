Memo visibility is enforced at these distinct sites:

1. **`APIV1Service.checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39`
   Per-memo gate used by `GetMemo` (line 356) and `ListMemoComments` (`memo_service_comments.go:148`). Rejects unauthenticated access to non-PUBLIC memos and forbids non-creators from seeing PRIVATE memos.

2. **`ListMemos` query-level filter** — `server/router/api/v1/memo_service.go:218–227`
   Scopes the listing query: anonymous users see only PUBLIC; authenticated users see their own + PUBLIC + PROTECTED; viewing another creator's memos restricts to PUBLIC/PROTECTED.

3. **`ListMemoComments` query-level filter** — `server/router/api/v1/memo_service_comments.go:157–161`
   Same pattern: anonymous → `visibility == "PUBLIC"`, authenticated → `creator_id == N || visibility in ["PUBLIC", "PROTECTED"]`.

4. **`ListMemoRelations` query-level filter** — `server/router/api/v1/memo_relation_service.go:107–112`
   Filters the related memos returned via `MemoFilter` so that related memos the caller cannot see are excluded.

5. **Memo relation loading in converter** — `server/router/api/v1/memo_service_converter.go:182–187`
   When hydrating outgoing relations for a batch of memos, applies the same visibility filter to prevent leaking references to inaccessible memos.

6. **`FileServerService.checkAttachmentPermission`** — `server/router/fileserver/fileserver.go:650`
   When serving attachment files, looks up the parent memo's visibility (line 677, 699): PUBLIC memos' attachments are served anonymously only on public instances; PRIVATE memo attachments require the creator or admin; share-token fallback is checked for shared memos.

7. **RSS feed queries** — `server/router/rss/rss.go:90, 141`
   Both system-wide and per-user RSS feeds hard-code `VisibilityList: []store.Visibility{store.Public}`, exposing only PUBLIC memos to the feed.

8. **`SSEClient.canReceive`** — `server/router/api/v1/sse_hub.go:134`
   Server-Sent Events delivery filtering: PRIVATE events are delivered only to the creator (or admin); PUBLIC/PROTECTED events are delivered to all connected clients.
