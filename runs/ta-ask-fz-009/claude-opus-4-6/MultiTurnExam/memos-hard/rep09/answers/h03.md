**Abstraction package:** `internal/idp` — defines the `IdentityProviderUserInfo` struct that all providers return (`internal/idp/idp.go`).

**Implementation package:** `internal/idp/oauth2` — the sole concrete protocol implementation that ships, providing an OAuth 2 identity provider (`internal/idp/oauth2/oauth2.go`). It implements token exchange (`ExchangeToken`) and user-info retrieval (`UserInfo`), returning the common `idp.IdentityProviderUserInfo`.
