The question's premise is incorrect — **there is no message broker (neither NATS nor RabbitMQ)**. The webhook delivery workers consume from a plain **in-process Go channel**, not an external message queue.

The "queue" is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

It is a buffered channel with capacity 128. Four goroutine workers are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel and call `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send and drops the event if the channel is full.
