The question's premise is incorrect — **there is no GraphQL schema**. The public API is not built with GraphQL.

The API surface is defined using **Protocol Buffers (protobuf)** with gRPC, served over both gRPC and Connect (HTTP/JSON). The proto definitions live under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, etc.). Generated Go code is output to `proto/gen/api/v1/` and `proto/gen/api/v1/apiv1connect/`. The server also includes a gRPC-Gateway layer for REST-style access (generated `*.pb.gw.go` files in `proto/gen/api/v1/`), and a Connect-based handler surface (`proto/gen/api/v1/apiv1connect/`). RPC handlers are implemented in `server/router/api/v1/`.
