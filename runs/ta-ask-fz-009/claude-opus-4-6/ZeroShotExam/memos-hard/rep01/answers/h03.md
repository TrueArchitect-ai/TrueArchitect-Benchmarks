The abstraction package is `internal/idp` — it defines the `IdentityProviderUserInfo` struct (`internal/idp/idp.go`), which is the shared data contract for user info returned by any provider.

The concrete protocol implementation is `internal/idp/oauth2` — it ships an OAuth2 identity provider (`oauth2.IdentityProvider` in `internal/idp/oauth2/oauth2.go`), the only concrete implementation in the tree.
