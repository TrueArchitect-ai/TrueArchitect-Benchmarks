**Detail per hop:**

- **Hop 1** (`serveUserAvatar`, `server/router/fileserver/fileserver.go:168`): The route handler. Optionally authenticates the caller via `getCurrentUser` on private instances (line 173). Extracts the `:identifier` path param as a username.

- **Hop 3** (`Store.GetUser`, `store/user.go:148`): Checks the in-memory user cache (`userCache`) by ID (cache miss here since lookup is by username), then delegates to `Store.ListUsers`.
- **Hop 4** (`Store.ListUsers`, `store/user.go:136`): Calls `s.driver.ListUsers(ctx, find)` through the `Driver` interface, then populates the cache for every returned user.
- **Hop 5** (`Driver.ListUsers`, `store/driver.go:47`): Interface method on the `Driver` interface, implemented by `sqlite.DB`, `postgres.DB`, and `mysql.DB`.
- **Hop 6** (`DB.ListUsers`, e.g. `store/db/sqlite/user.go:88`): Builds a SQL query with a `WHERE username = ?` clause and queries the database. The returned `User.AvatarURL` field carries a base64 data-URI of the image.
