**Premise correction:** There is no GraphQL schema in this repository. Memos does not use GraphQL at all.

**Actual API surface:** The public API is defined as **gRPC services using Protocol Buffers**, with an HTTP/JSON gateway generated via **grpc-gateway**. The source-of-truth definitions are the `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared types)

These proto definitions are code-generated into Go gRPC stubs and grpc-gateway reverse-proxy handlers under `proto/gen/api/v1/` (e.g., `*.pb.gw.go` files), which expose the API as RESTful HTTP endpoints at `/api/v1/...`. The full surface is 81 REST endpoints (GET/POST/PATCH/DELETE), plus a handful of non-gRPC routes for file serving, RSS, SSE, sitemap, and health checks defined in `server/router/`.
