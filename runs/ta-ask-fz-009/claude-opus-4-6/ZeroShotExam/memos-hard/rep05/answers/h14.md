**Computation site:** `server/runner/memopayload/runner.go` — the function `RebuildMemoPayload` (line 74) calls `markdownService.ExtractAll()` (defined in `internal/markdown/markdown.go:356`) which does a single goldmark AST walk to extract both the `Property` struct and tags. The **snippet** is computed separately by `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83`, which calls `markdownService.GenerateSnippet()` (`internal/markdown/markdown.go:264`); it is produced at response-conversion time in `server/router/api/v1/memo_service_converter.go:76–80` (not persisted, computed on every API read).

**Triggers (three):**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before the memo is stored.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `"content"` field is in the update mask.
3. **`Runner.RunOnce`** (batch rebuild) — `server/runner/memopayload/runner.go:27` iterates every memo in the database and calls `RebuildMemoPayload` + `Store.UpdateMemo` on each, used for migration/reindexing.

(The snippet is also recomputed on every `convertMemoFromStore` call, i.e., every API response that returns a memo.)
