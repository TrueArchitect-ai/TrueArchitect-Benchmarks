**Premise correction:** This repository has no GraphQL schema. The public API is **not** GraphQL — it is a **gRPC + REST (gRPC-Gateway)** API defined via **Protocol Buffers**.

**Actual API surface:**

The API schema is defined as `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memos CRUD, comments, reactions, shares, relations
- `proto/api/v1/user_service.proto` — Users, settings, tokens, webhooks, notifications, linked identities
- `proto/api/v1/auth_service.proto` — Sign-in, sign-out, token refresh, current user
- `proto/api/v1/attachment_service.proto` — Attachment CRUD
- `proto/api/v1/instance_service.proto` — Instance profile, settings, stats
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — User shortcuts
- `proto/api/v1/ai_service.proto` — AI transcription
- `proto/api/v1/common.proto` — Shared types

These `.proto` files are compiled into Go code under `proto/gen/api/v1/`, which includes:
- gRPC server/client stubs (`*_grpc.pb.go`)
- gRPC-Gateway reverse-proxy handlers (`*.pb.gw.go`) that expose the gRPC services as a RESTful HTTP API under `/api/v1/...`

The full HTTP surface comprises **81 REST endpoints** (all under `/api/v1/`) plus a handful of file-serving and auxiliary routes (`/healthz`, `/attachments/...`, RSS feeds, etc.). There is zero GraphQL involvement anywhere in the codebase — the `[ArchMap query]` macro returned a certified miss across all 7,293 indexed symbols, and grep only found transitive lock-file references from unrelated npm packages.
