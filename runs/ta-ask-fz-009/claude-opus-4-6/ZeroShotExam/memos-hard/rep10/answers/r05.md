**Premise correction:** There is no GraphQL schema in this repository. The public API is not GraphQL — it is a **gRPC API with an HTTP/REST gateway**, defined via **Protocol Buffers (protobuf)**.

**Actual API surface:**

The API is defined as protobuf service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD, comments, reactions, shares, relations, attachments
- `proto/api/v1/user_service.proto` — User management, settings, webhooks, access tokens, notifications, linked identities
- `proto/api/v1/auth_service.proto` — Sign-in, sign-out, token refresh, current user
- `proto/api/v1/attachment_service.proto` — Attachment CRUD
- `proto/api/v1/instance_service.proto` — Instance profile, settings, stats
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — User shortcuts
- `proto/api/v1/ai_service.proto` — AI transcription
- `proto/api/v1/common.proto` — Shared types

These `.proto` files are compiled into:
- **Go gRPC server stubs** and **gRPC-Gateway HTTP reverse-proxy handlers** in `proto/gen/api/v1/` (e.g., `*.pb.gw.go` files), which expose RESTful HTTP endpoints under `/api/v1/`.
- All 81 HTTP endpoints are REST-style (GET/POST/PATCH/DELETE), served via gRPC-Gateway — not GraphQL.

Additionally, a few non-gRPC HTTP routes exist: SSE (`server/router/api/v1/sse_handler.go`), file serving (`server/router/fileserver/`), RSS (`server/router/rss/`), frontend assets, and a `/healthz` health check (`server/server.go`).
