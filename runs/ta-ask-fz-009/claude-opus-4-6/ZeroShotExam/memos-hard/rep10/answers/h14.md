**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74–88`. It delegates to `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356–422`), which parses the memo's markdown content with goldmark in a single AST walk.

**Triggers (three operations):**

1. **CreateMemo** — called at `server/router/api/v1/memo_service.go:108` before persisting a new memo.
2. **UpdateMemo** — called at `server/router/api/v1/memo_service.go:447` when the `content` field is in the update mask.
3. **Runner.RunOnce** (batch rebuild) — `server/runner/memopayload/runner.go:27–72` iterates every memo in the database in batches of 100, recomputing and persisting the payload for each.

Additionally, the **`snippet`** field is computed at *read time* (not stored) by `getMemoContentSnippet` → `markdown.Service.GenerateSnippet` during conversion to the API response (`server/router/api/v1/memo_service_converter.go:76–80`).

**Extracted properties** (stored in `MemoPayload.Property`, defined in `proto/store/memo.proto:15–22`):

| Property | What it detects |
|---|---|
| `has_link` (bool) | Memo contains a markdown link |
| `has_code` (bool) | Memo contains a code block, fenced code block, or inline code span |
| `has_task_list` (bool) | Memo contains GFM task checkboxes |
| `has_incomplete_tasks` (bool) | At least one task checkbox is unchecked |
| `title` (string) | Plain text of the first H1 heading (if the document starts with one) |

In addition to `Property`, `RebuildMemoPayload` also extracts and stores **`tags`** (deduplicated `#tag` values) into `MemoPayload.Tags` (`runner.go:85`).

The `snippet` (a truncated plain-text summary, max 64 chars for webhooks / 200 for API responses) is derived on-the-fly rather than persisted.
