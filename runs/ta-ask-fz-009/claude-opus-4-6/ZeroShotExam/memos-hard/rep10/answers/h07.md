**How it works:** The handler resolves the `:identifier` path param to a username, calls `getUserByUsername` which delegates to `Store.GetUser`. `GetUser` checks an in-memory user cache (`store/cache/cache.go`); on miss it calls `Store.ListUsers`, which delegates to the concrete DB driver's `ListUsers` (the `Driver` interface is implemented by `sqlite.DB`, `mysql.DB`, `postgres.DB`). The driver queries the `user` table and hydrates a `store.User` including its `AvatarURL` field. Back in the handler, `parseDataURI` (`fileserver.go:737`) extracts the MIME type and base64-decodes the image bytes from the data-URI string stored in `AvatarURL`. The decoded bytes are served via `echo.Blob`.
