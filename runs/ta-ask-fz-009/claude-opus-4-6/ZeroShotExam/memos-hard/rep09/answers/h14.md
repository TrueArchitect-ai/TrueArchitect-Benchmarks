**Computation site:** Two distinct mechanisms, both in the backend:

1. **Payload metadata** (tags + properties) — computed in `memopayload.RebuildMemoPayload()` (`server/runner/memopayload/runner.go:74`), which delegates to `markdown.Service.ExtractAll()` (`internal/markdown/markdown.go:356`). This performs a single goldmark AST walk over the memo content.

2. **Snippet** — computed at read/conversion time in `APIV1Service.getMemoContentSnippet()` (`server/router/api/v1/memo_service_webhooks.go:83`), which delegates to `markdown.Service.GenerateSnippet()` (`internal/markdown/markdown.go:264`). This is called from `convertMemoFromStoreWithCreators()` (`server/router/api/v1/memo_service_converter.go:76`) every time a memo is serialized for the API response.

**Triggers:**

- **`CreateMemo`** (`server/router/api/v1/memo_service.go:108`) — calls `RebuildMemoPayload` before persisting.
- **`UpdateMemo`** (`server/router/api/v1/memo_service.go:447`) — calls `RebuildMemoPayload` when the `content` field is in the update mask.
- **`Runner.RunOnce`** (`server/runner/memopayload/runner.go:27`) — batch-reprocesses all memos (migration/repair path), calling `RebuildMemoPayload` for each.
- **Every API read** — the snippet is recomputed on the fly during memo-to-protobuf conversion (not persisted).

**Extracted properties** (from `ExtractAll` → stored in `MemoPayload`):

| Property | Source in AST | Location |
|---|---|---|
| `Tags` (`[]string`) | `#tag` nodes | `markdown.go:377` |
| `Mentions` (`[]string`) | `@mention` nodes | `markdown.go:379–380` |
| `Property.HasLink` (`bool`) | `Link` nodes | `markdown.go:394` |
| `Property.HasCode` (`bool`) | `CodeBlock` / `FencedCodeBlock` / `CodeSpan` nodes | `markdown.go:396–397` |
| `Property.HasTaskList` (`bool`) | `TaskCheckBox` nodes | `markdown.go:399–400` |
| `Property.HasIncompleteTasks` (`bool`) | Unchecked `TaskCheckBox` | `markdown.go:401–404` |
| `Property.Title` (`string`) | First block child of document if it is an H1 heading | `markdown.go:384–388` |

Additionally, the **`Snippet`** (a plain-text summary truncated at 64 characters, word-boundary aware) is generated from `GenerateSnippet` (`internal/markdown/markdown.go:264`) by walking the AST and collecting visible text while skipping code blocks. This is **not** persisted — it is computed on the fly during the converter step (`memo_service_converter.go:76–80`) and placed on the API response's `Snippet` field (`proto/gen/api/v1/memo_service.pb.go:257`).
