**Premise correction:** There is no GraphQL schema in this repository. The public API is not GraphQL — it is a **gRPC API with an HTTP/JSON gateway**, defined entirely in **Protocol Buffer (`.proto`) files**.

**Actual API surface:**

The API is defined as gRPC services in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD, comments, reactions, shares, relations
- `proto/api/v1/user_service.proto` — User management, settings, webhooks, access tokens, notifications
- `proto/api/v1/auth_service.proto` — Sign-in, sign-out, token refresh, current user
- `proto/api/v1/attachment_service.proto` — File attachments
- `proto/api/v1/instance_service.proto` — Instance profile, settings, stats
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — User shortcuts
- `proto/api/v1/ai_service.proto` — AI transcription
- `proto/api/v1/common.proto` — Shared types

These `.proto` files are code-generated into Go gRPC stubs and **grpc-gateway** reverse-proxy handlers (e.g., `proto/gen/api/v1/memo_service.pb.gw.go`), which expose the services as a RESTful HTTP API under `/api/v1/...`. The full surface is 81 HTTP endpoints (GET/POST/PATCH/DELETE) plus a handful of non-gRPC routes for RSS, file serving, SSE, and health checks.
