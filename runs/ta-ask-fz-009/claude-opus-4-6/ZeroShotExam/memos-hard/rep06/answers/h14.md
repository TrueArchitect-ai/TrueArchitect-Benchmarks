**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74–88`. It calls `markdown.Service.ExtractAll()` (`internal/markdown/markdown.go:356–422`), which parses the memo's markdown content with goldmark in a single AST walk. Additionally, `snippet` is computed at read/response time by `APIV1Service.getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83–90`), which delegates to `markdown.Service.GenerateSnippet` (`internal/markdown/markdown.go:263–346`).

**Triggers (three):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting.
2. **UpdateMemo** (when `content` is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` and writes the new payload to the store.
3. **Batch rebuild** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27–72`) iterates all memos in batches of 100, calling `RebuildMemoPayload` + `Store.UpdateMemo` for each (though this runner is not currently wired into server startup).
4. **Every API read** — `snippet` is not stored; it is regenerated on the fly each time a memo is converted to its API response via `getMemoContentSnippet` (called from `memo_service_converter.go:76`, `:225`, `:248`, and `memo_relation_service.go:154`/`:162`).

**Extracted properties (stored in `MemoPayload`, defined in `proto/store/memo.proto:7–22`):**
- **`tags`** (`[]string`) — deduplicated `#tag` values found in the content.
- **`property.has_link`** (`bool`) — true if the content contains any markdown link.
- **`property.has_task_list`** (`bool`) — true if the content contains any GFM task checkbox.
- **`property.has_code`** (`bool`) — true if the content contains a code block, fenced code block, or inline code span.
- **`property.has_incomplete_tasks`** (`bool`) — true if any task checkbox is unchecked.
- **`property.title`** (`string`) — plain text of the first H1 heading, if the document starts with one.
- **`snippet`** (API-only, not persisted) — a plain-text summary truncated at 64 characters on a word boundary, with code blocks stripped. Computed by `GenerateSnippet` (`internal/markdown/markdown.go:263`).
