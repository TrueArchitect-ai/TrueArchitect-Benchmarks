The outbound HTTP request to a user-configured webhook URL is ultimately made by **`webhook.Post`** (`internal/webhook/webhook.go:120`), which performs the `safeClient.Do(req)` call. All RPC handler paths converge into a single intermediary before reaching `Post`: **`webhook.PostAsync`** (`internal/webhook/webhook.go:184`), which enqueues the payload onto `asyncPostQueue`; the `init()` goroutines drain that queue and call `Post`.

However, the more meaningful architectural convergence point—the one where all *handler-level* paths merge before building the payload and calling `PostAsync`—is **`dispatchMemoRelatedWebhook`** (`server/router/api/v1/memo_service_webhooks.go:48`). Three of the four dispatch methods delegate directly to it (the fourth, `DispatchMemoCommentCreatedWebhook`, inlines the same logic but for a different user's webhooks).
