`internal/idp` (package `idp`) defines the provider abstraction — specifically the `IdentityProviderUserInfo` struct (`internal/idp/idp.go`), which is the common return type all identity providers produce.

`internal/idp/oauth2` (package `oauth2`) is the concrete protocol implementation that ships. It implements an OAuth 2 identity provider (`internal/idp/oauth2/oauth2.go`) with `ExchangeToken` and `UserInfo` methods, importing and returning the shared `idp.IdentityProviderUserInfo` type.
