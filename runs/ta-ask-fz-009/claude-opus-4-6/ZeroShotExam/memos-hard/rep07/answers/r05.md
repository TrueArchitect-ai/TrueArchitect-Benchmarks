**Actual API surface:** The public API is a **gRPC + REST (gRPC-Gateway)** service, defined in **Protocol Buffer (`.proto`) files** under `proto/api/v1/`:

| Proto file | Service |
|---|---|
| `proto/api/v1/ai_service.proto` | AI (transcription) |
| `proto/api/v1/attachment_service.proto` | Attachment CRUD |
| `proto/api/v1/auth_service.proto` | Auth (sign-in/out, token refresh) |
| `proto/api/v1/memo_service.proto` | Memo CRUD, comments, reactions, relations, shares |
| `proto/api/v1/user_service.proto` | User management, settings, webhooks, access tokens |
| `proto/api/v1/instance_service.proto` | Instance profile, settings, stats |
| `proto/api/v1/idp_service.proto` | Identity providers |
| `proto/api/v1/shortcut_service.proto` | User shortcuts |
| `proto/api/v1/common.proto` | Shared types |

These `.proto` definitions are compiled into Go code under `proto/gen/api/v1/`, which includes both gRPC stubs (`*.pb.go`, `*_grpc.pb.go`) and gRPC-Gateway reverse-proxy handlers (`*.pb.gw.go`) that expose 81 REST endpoints under the `/api/v1/` prefix. A few additional non-gRPC routes exist for file serving (`/attachments/`, `/users/`), RSS feeds, SSE, frontend assets, and a health check (`/healthz`), registered directly in Go (see `server/router/`).
