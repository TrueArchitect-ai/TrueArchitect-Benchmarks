### 2. Read-time snippet — `getMemoContentSnippet`

**Computation site:** `server/router/api/v1/memo_service_webhooks.go:83–86` — delegates to `MarkdownService.GenerateSnippet(content, 64)` (`internal/markdown/markdown.go:263–345`).

**Triggers:** computed on every API read — when converting a `store.Memo` to its protobuf API response (`memo_service_converter.go:76`), when building relation responses (`memo_relation_service.go:154, 162`), and when composing notification payloads (`user_service_notifications.go:323`). It is **not** persisted; `store.Memo` has no `Snippet` field — it's set only on the API-layer `Memo.Snippet` (`proto/api/v1/memo_service.proto:256`, marked `OUTPUT_ONLY`).

**What it extracts:** a plain-text summary ≤ 64 characters, produced by walking the AST, collecting text nodes (skipping code blocks), inserting spaces between block elements, and truncating at a word boundary.
