h03.

The abstraction lives in package `internal/idp` (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` struct used across identity-provider implementations.

The sole concrete protocol implementation that ships is the **OAuth2** provider in package `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements the `IdentityProvider` struct backed by `golang.org/x/oauth2`.
