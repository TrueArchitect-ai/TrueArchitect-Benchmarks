There are **two layers** of derived metadata, computed at different times:

---

### 1. Payload metadata (persisted) — `RebuildMemoPayload`

**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74–88`. It delegates to `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:355–418`), which parses the memo's markdown content via goldmark in a single AST walk.

**Triggers (three operations):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108`
2. **UpdateMemo** (when content changes) — `server/router/api/v1/memo_service.go:447`
3. **Runner.RunOnce** (batch rebuild of all memos at startup/migration) — `server/runner/memopayload/runner.go:27–72`

**Extracted properties** (stored in `MemoPayload`, defined in `proto/gen/store/memo.pb.go:85–95`):
- `Tags` (`[]string`) — `#tag` nodes found in content (`runner.go:85`)
- `Property.HasLink` (`bool`) — whether content contains a markdown link
- `Property.HasTaskList` (`bool`) — whether content contains task checkboxes
- `Property.HasCode` (`bool`) — whether content contains code blocks/spans
- `Property.HasIncompleteTasks` (`bool`) — whether any task checkbox is unchecked
- `Property.Title` (`string`) — text of the first H1 heading, if present
- `Mentions` (`[]string`) — `@username` references (extracted but stored on `ExtractedData`, used for notifications rather than persisted in the payload)

---

### 2. Snippet (computed on read, not persisted)

**Computation site:** `APIV1Service.getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83–88`, which calls `markdown.Service.GenerateSnippet` (`internal/markdown/markdown.go:263–345`).

**Triggers:** Every time a memo is converted to its API representation for a response — `convertMemoFromStore` (`server/router/api/v1/memo_service_converter.go:76–80`) and batch listing (`memo_service_converter.go:221–252`).

**What it extracts:** A plain-text summary of the markdown content, truncated at word boundary to **64 characters** (the `maxLength` argument at `memo_service_webhooks.go:85`). The snippet strips formatting, skips code blocks, and collapses whitespace. This populates the `Snippet` field on the API-level `Memo` protobuf message (`proto/gen/api/v1/memo_service.pb.go:257`), used for list/preview display.
