**Premise correction:** There is no GraphQL schema in this repository. The public API is not GraphQL — it is a **gRPC API with HTTP/JSON gateway** (gRPC-Gateway), defined via **Protocol Buffers**.

**Actual API surface:**

The API schema is defined as `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD, comments, reactions, shares, relations
- `proto/api/v1/user_service.proto` — User management, settings, webhooks, access tokens, notifications
- `proto/api/v1/auth_service.proto` — Sign-in, sign-out, token refresh, current user
- `proto/api/v1/attachment_service.proto` — Attachment CRUD
- `proto/api/v1/instance_service.proto` — Instance profile, stats, settings
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — User shortcuts
- `proto/api/v1/ai_service.proto` — AI transcription
- `proto/api/v1/common.proto` — Shared types

These `.proto` definitions are code-generated into Go via `protoc` into `proto/gen/api/v1/` — producing both gRPC stubs (`*.pb.go`, `*_grpc.pb.go`) and gRPC-Gateway reverse-proxy handlers (`*.pb.gw.go`) that expose the services as a RESTful HTTP/JSON API under `/api/v1/`. There are 81 HTTP endpoints total, plus supplementary file-serving, RSS, and frontend routes defined directly in Go under `server/router/`.
