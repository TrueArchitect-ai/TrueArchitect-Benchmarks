**Premise correction:** There is no GraphQL schema in this repository. The public API is not GraphQL — it is a **gRPC + REST (gRPC-Gateway)** API defined in **Protocol Buffers**.

**Actual API surface:**

The API schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memos CRUD, comments, reactions, shares, relations
- `proto/api/v1/user_service.proto` — Users, settings, webhooks, access tokens, linked identities, notifications
- `proto/api/v1/auth_service.proto` — Sign in/out, token refresh, current user
- `proto/api/v1/attachment_service.proto` — Attachment CRUD
- `proto/api/v1/instance_service.proto` — Instance profile, stats, settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — User shortcuts
- `proto/api/v1/ai_service.proto` — AI transcription
- `proto/api/v1/common.proto` — Shared types

These `.proto` files are compiled into:
1. **gRPC service stubs** (Go code in `proto/gen/api/v1/*.pb.go`)
2. **gRPC-Gateway reverse proxies** (REST endpoints in `proto/gen/api/v1/*.pb.gw.go`)

The resulting REST surface is 81 endpoints under `/api/v1/`, plus a handful of non-gRPC routes for SSE (`server/router/api/v1/sse_handler.go`), file serving (`server/router/fileserver/`), RSS (`server/router/rss/`), and frontend assets (`server/router/frontend/`).
