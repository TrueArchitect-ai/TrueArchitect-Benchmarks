**Premise correction: neither NATS nor RabbitMQ is used.** There is no message broker at all.

Webhook delivery workers consume from a **plain Go buffered channel**, not from any external message broker. The "queue" is declared in `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`). Each goroutine ranges over `asyncPostQueue` and calls `Post()` to perform the HTTP delivery synchronously within that worker. The `PostAsync` function (`internal/webhook/webhook.go:184`) does a non-blocking send into the channel, dropping the payload with a warning log if the 128-slot buffer is full.

There is no dependency on NATS, RabbitMQ, or any other message broker anywhere in the codebase for webhook delivery — it is entirely in-process.
