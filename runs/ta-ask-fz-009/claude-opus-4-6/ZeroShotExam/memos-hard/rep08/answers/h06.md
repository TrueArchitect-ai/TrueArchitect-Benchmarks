The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

**Handlers (≥3):**

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go:70`) — calls `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`
2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go:401`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`
3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go:518`) — calls `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:20`) — calls both `DispatchMemoCreatedWebhook` (via `CreateMemo`) and `DispatchMemoCommentCreatedWebhook`, both routing through `dispatchMemoRelatedWebhook` / `PostAsync`
5. **`SetMemoAttachments`** (`server/router/api/v1/memo_attachment_service.go:16`) and **`SetMemoRelations`** (`server/router/api/v1/memo_relation_service.go:16`) — both call `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`

**Convergence function:** **`dispatchMemoRelatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go:48`

This is the single function where all paths converge before delivery. It resolves the memo creator, fetches their configured webhooks from the store (`Store.GetUserWebhooks`), builds a `WebhookRequestPayload` (including the user-configured `hook.Url` and `hook.SigningSecret`), and enqueues it via `webhook.PostAsync`. The `PostAsync` function feeds an async worker pool that ultimately calls `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual outbound `HTTP POST` to the user-configured URL using a SSRF-guarded `safeClient`.

(The one exception is `DispatchMemoCommentCreatedWebhook` at line 30, which has its own inline loop that calls `PostAsync` directly — but it mirrors the same pattern and exists only because it resolves the *related memo owner* rather than the memo's own creator.)
