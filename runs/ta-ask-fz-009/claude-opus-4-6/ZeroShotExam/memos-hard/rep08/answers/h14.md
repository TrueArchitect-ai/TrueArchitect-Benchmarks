**Computation site:** Two related sites, both in the markdown service (`internal/markdown/markdown.go`):

1. **`MemoPayload_Property` (persisted)** — computed by `service.ExtractAll()` (`internal/markdown/markdown.go:355`) which walks the goldmark AST in a single pass. This is invoked through `memopayload.RebuildMemoPayload()` (`server/runner/memopayload/runner.go:74`), which writes the result into `memo.Payload.Property`.

2. **`Snippet` (computed on-the-fly at read time)** — computed by `service.GenerateSnippet()` (`internal/markdown/markdown.go:264`), called via `APIV1Service.getMemoContentSnippet()` (`server/router/api/v1/memo_service_webhooks.go:83`), which truncates plain-text to 64 chars. This is set on the API response during conversion (`server/router/api/v1/memo_service_converter.go:76–80`) and is **not** stored in the DB.

**Triggers:**

- **`CreateMemo`** (`server/router/api/v1/memo_service.go:108`) — calls `RebuildMemoPayload` before persisting.
- **`UpdateMemo`** (`server/router/api/v1/memo_service.go:447`) — calls `RebuildMemoPayload` when the `content` field is updated.
- **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go`) — indirectly triggers via `CreateMemo`.
- **`Runner.RunOnce`** (`server/runner/memopayload/runner.go:27`) — a batch job that iterates all memos in pages of 100 and rebuilds every payload (migration/repair path).
- **Every read/list/get** — the `snippet` field is recomputed from content at response-conversion time (not persisted).

**Extracted properties** (from the AST walk at `internal/markdown/markdown.go:370–411`, stored in `MemoPayload_Property` per `proto/gen/store/memo.pb.go:85–95`):

| Property | What it detects |
|---|---|
| `HasLink` (bool) | Any markdown link node (`gast.KindLink`) |
| `HasTaskList` (bool) | Any task checkbox (`east.KindTaskCheckBox`) |
| `HasCode` (bool) | Code blocks or inline code spans (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`) |
| `HasIncompleteTasks` (bool) | Unchecked task checkboxes (`!checkBox.IsChecked`) |
| `Title` (string) | Text of the first block-level H1 heading in the document |
| `Snippet` (string, API-only) | Plain-text summary up to 64 characters, generated by stripping markup and truncating at a word boundary |

Additionally, `ExtractAll` also extracts `Tags` (hashtags) and `Mentions` (@-mentions) from the same single-pass walk, and `Tags` are persisted into `memo.Payload.Tags` alongside the property (`server/runner/memopayload/runner.go:85`).
