When a memo is deleted via `Store.DeleteMemo` (`store/memo.go:140–159`), the store layer deletes the following kinds of records before the memo row itself:

1. **Memo relations** (where the memo is the *source*) — `DeleteMemoRelation` with `MemoID` (`store/memo.go:142`)
2. **Memo relations** (where the memo is the *related/target*) — `DeleteMemoRelation` with `RelatedMemoID` (`store/memo.go:145`)
3. **Attachments** — lists all attachments linked to the memo, then deletes each one via `DeleteAttachment` (`store/memo.go:149–156`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos linked via `MemoRelationComment`) are recursively deleted before the parent memo's `Store.DeleteMemo` call, meaning each comment goes through the same store-level cleanup.
