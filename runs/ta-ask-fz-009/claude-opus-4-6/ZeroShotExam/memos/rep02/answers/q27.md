The compiled React frontend is served via **Go's `embed.FS`** (`//go:embed dist/*` directive on line 20–21), which embeds the built `dist/` directory into the Go binary at compile time. At runtime, the embedded filesystem is mounted as Echo static middleware (`middleware.StaticWithConfig`) with an SPA fallback that serves `index.html` for unmatched routes.

**Mechanism:** `//go:embed` (embedded filesystem) served through Echo's `StaticWithConfig` middleware  
**File:** `server/router/frontend/frontend.go`
