The compiled React frontend is served via **Go's `embed` directive** (`//go:embed dist/*` on line 20), which bakes the built `dist/` tree into the Go binary at compile time. At runtime, `FrontendService.Serve` registers Echo's `middleware.StaticWithConfig` (line 54) backed by the embedded filesystem to serve those assets, with an SPA fallback middleware that returns `index.html` for unmatched routes.
