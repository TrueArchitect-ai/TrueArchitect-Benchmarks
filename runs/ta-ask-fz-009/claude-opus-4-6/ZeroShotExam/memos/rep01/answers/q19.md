MemoService is served over two protocols:

1. **gRPC-Gateway (REST/HTTP)** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)`). This registers the service with the gRPC-Gateway mux, which translates RESTful HTTP/JSON requests into gRPC-style calls based on the generated gateway code in `proto/gen/api/v1/memo_service.pb.gw.go`.

2. **Connect (ConnectRPC)** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))`). This registers the service as a Connect handler on an `http.ServeMux`, using the generated Connect handler from `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.

Both protocols share the same underlying `APIV1Service` implementation (`server/router/api/v1/v1.go`), with the Connect path going through a thin `ConnectServiceHandler` adapter wrapper.
