`store/migration/sqlite/LATEST.sql`

This is the single file that provides the complete current schema for a fresh SQLite install. It contains all the `CREATE TABLE` statements needed, mirroring the pattern used by the MySQL and Postgres variants (`store/migration/mysql/LATEST.sql`, `store/migration/postgres/LATEST.sql`). The numbered subdirectories (e.g., `0.28/`, `0.30/`) hold incremental migrations for upgrades, but `LATEST.sql` is the consolidated schema applied on a fresh install.
