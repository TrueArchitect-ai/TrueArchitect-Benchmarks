**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `google/cel-go`, wrapped in a custom `filter.Engine` at **`internal/filter/engine.go`**.

**Mechanism:** The `Engine.Compile()` method parses the CEL filter string into a CEL AST (`cel.Env.Compile`), then `buildCondition()` (`internal/filter/parser.go`) walks that AST to produce a dialect-agnostic `Condition` IR tree (`internal/filter/ir.go`); `Program.Render()` feeds the IR to a `renderer` (`internal/filter/render.go`) that pattern-matches each `Condition` node and emits dialect-specific SQL fragments (SQLite, Postgres, MySQL) selected by `RenderOptions.Dialect`, with per-dialect branching for JSON operators, timestamp accessors, placeholder syntax, and string functions.
