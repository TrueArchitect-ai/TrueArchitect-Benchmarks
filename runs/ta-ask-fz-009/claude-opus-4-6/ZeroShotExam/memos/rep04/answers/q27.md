Go's `//go:embed` directive embeds the compiled SPA (built into `server/router/frontend/dist/`) directly into the server binary at compile time. At runtime, `FrontendService.Serve` exposes those embedded files via Echo's `middleware.StaticWithConfig` (with an SPA fallback middleware that serves `index.html` for unmatched routes).
