`store/migration/sqlite/LATEST.sql`

This is the single file that provides the complete current schema for a fresh SQLite install. It follows the same convention as the MySQL and Postgres directories, where `LATEST.sql` contains all the `CREATE TABLE` statements representing the current schema, while the versioned subdirectories (e.g., `0.2/`, `0.10/`, `0.28/`, etc.) contain incremental migrations.
