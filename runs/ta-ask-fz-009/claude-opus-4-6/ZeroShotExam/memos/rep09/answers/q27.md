The compiled React frontend is served via **Go's `embed.FS`** (`//go:embed dist/*`). The built frontend assets are embedded into the Go binary at compile time, then exposed at runtime through Echo's `middleware.StaticWithConfig` (with an SPA fallback that serves `index.html` for unmatched routes).

**`embed.FS` + Echo static middleware; `server/router/frontend/frontend.go`**

Key details:
- **Line 20–21**: `//go:embed dist/*` embeds the entire `dist/` directory (the Vite/React build output) into the `embeddedFiles` variable.
- **Line 54–57**: `middleware.StaticWithConfig` serves those embedded files as static assets.
- **Line 59**: `spaFallbackMiddleware` catches 404s for client-side routes and returns `index.html` from the embedded filesystem, enabling SPA routing.
