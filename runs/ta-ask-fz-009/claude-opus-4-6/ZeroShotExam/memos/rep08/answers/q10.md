q10. `store/migration/sqlite/LATEST.sql`

This file contains the complete current schema for a fresh SQLite install, with all `CREATE TABLE` statements representing the latest version of every table. The numerous versioned migration files (e.g., `0.2/`, `0.3/`, … `0.30/`) are for incremental upgrades of existing databases, while `LATEST.sql` is the single file applied on a brand-new installation.
