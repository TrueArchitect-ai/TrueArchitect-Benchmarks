**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `github.com/google/cel-go/cel`, wrapped in a custom `filter.Engine` at `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile` method parses the CEL filter string into a CEL AST, converts it to a dialect-agnostic `Condition` tree (`internal/filter/ir.go`), and `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) that walks it and emits dialect-specific SQL fragments (with parameterized args) by switching on `RenderOptions.Dialect` (sqlite / postgres / mysql) — for example, producing `strftime` for SQLite, `EXTRACT` for Postgres, and MySQL-native functions for MySQL in timestamp expressions, and dialect-appropriate JSON operators/placeholders throughout.
