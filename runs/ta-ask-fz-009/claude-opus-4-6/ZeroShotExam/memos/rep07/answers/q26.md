The following tables are affected when `DeleteMemo` runs:

1. **`memo`** — the memo row itself is deleted (`DELETE FROM memo WHERE id = ?`) via `store.Driver.DeleteMemo` (e.g. `store/db/sqlite/memo.go:239`)
2. **`memo_relation`** — explicitly deleted twice in `store.Store.DeleteMemo` (`store/memo.go:142–147`) by calling `DeleteMemoRelation` — once for `memo_id` match and once for `related_memo_id` match (e.g. `store/db/sqlite/memo_relation.go:148–150`)
3. **`attachment`** — explicitly deleted in `store.Store.DeleteMemo` (`store/memo.go:149–157`) via a loop calling `DeleteAttachment` for each attachment linked to the memo (e.g. `store/db/sqlite/attachment.go:212`)
4. **`memo_share`** — deleted by SQL-level `ON DELETE CASCADE` on `FOREIGN KEY (memo_id) REFERENCES memo(id)` (`store/migration/sqlite/LATEST.sql:109`)
