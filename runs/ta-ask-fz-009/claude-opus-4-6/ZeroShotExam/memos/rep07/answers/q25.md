**Engine:** [Google CEL (Common Expression Language)](https://github.com/google/cel-go) via `cel-go`, wrapped in a custom `filter.Engine` at **`internal/filter/engine.go`**.

**Mechanism:** The `Engine.Compile` method parses the filter string with `cel.Env.Compile`, converts the CEL AST into a dialect-agnostic `Condition` tree (`internal/filter/parser.go` → `buildCondition`), and then `Program.Render` (`internal/filter/render.go`) walks that tree with a `renderer` that switches on `DialectName` (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`) to emit dialect-specific SQL fragments and placeholder args — invoked per-database-driver via the helper `filter.AppendConditions` (`internal/filter/helpers.go`), which each dialect's `ListMemos` calls with its own dialect constant (e.g., `store/db/sqlite/memo.go:61`, `store/db/mysql/memo.go:69`, `store/db/postgres/memo.go:58`).
