q07. `web/src/connect.ts`

This file creates all ConnectRPC service clients (e.g., `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient`) using `createClient` from `@connectrpc/connect` over a transport created with `createConnectTransport` from `@connectrpc/connect-web`.
