The engine is a CEL (Common Expression Language) parser at `internal/filter/engine.go` (type `Engine`). The engine compiles filter strings into a dialect-agnostic condition tree (IR), which is then rendered into SQL for each dialect (SQLite, PostgreSQL, MySQL) by the renderer at `internal/filter/render.go`, with per-dialect SQL generation (placeholders, JSON operators, LIKE/ILIKE, etc.).
