- Engine: CEL (Common Expression Language) parser, `internal/filter/engine.go`
- Mechanism: The CEL expression is compiled into an AST, then lowered to a dialect-agnostic condition tree (`internal/filter/parser.go`), and rendered to dialect-specific SQL via `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions()` / `engine.CompileToStatement()` with the appropriate `DialectName` (SQLite, Postgres, MySQL) to produce parameterized SQL WHERE clauses.
