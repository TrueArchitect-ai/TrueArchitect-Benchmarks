Before the memo row itself, `Store.DeleteMemo` (store/memo.go:140–158) deletes:
1. `memo_relation` rows (where memo is source — MemoID)
2. `memo_relation` rows (where memo is target — RelatedMemoID)
3. `attachment` rows linked to the memo

Additionally, the API handler (`APIV1Service.DeleteMemo`, server/router/api/v1/memo_service.go:567–577) first deletes comment memos (child memos linked via COMMENT relation, which recursively triggers the store cleanup for each comment).
