The filter engine is a CEL (Common Expression Language) parser in `internal/filter/engine.go` (`filter.Engine` struct, uses `github.com/google/cel-go/cel`). Filter expressions are parsed by CEL into an AST, then compiled to a dialect-agnostic condition tree (`filter.Condition`). Each database dialect driver calls `filter.AppendConditions()` (internal/filter/helpers.go:9) which compiles the filter and then calls `Program.Render(RenderOptions{Dialect: ...})` (internal/filter/engine.go:96) to produce dialect-specific SQL fragments (SQLite, Postgres, MySQL) via the renderer in `internal/filter/render.go`.
