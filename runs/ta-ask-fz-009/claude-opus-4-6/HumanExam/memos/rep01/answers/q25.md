Engine: CEL (Common Expression Language) parser/compiler, implemented in `internal/filter/engine.go` (`Engine` struct using `github.com/google/cel-go/cel`).
Mechanism: The CEL filter expression is parsed and compiled into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then rendered into dialect-specific SQL (SQLite/PostgreSQL/MySQL) by `internal/filter/render.go`, which generates the appropriate SQL WHERE clauses with dialect-specific JSON extraction, string matching, and placeholder syntax for each backend.
