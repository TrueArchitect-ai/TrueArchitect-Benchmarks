Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go` (type Engine struct, line 14)
Mechanism: The filter string is compiled by the CEL engine into a dialect-agnostic condition tree (IR), which is then rendered into dialect-specific SQL (SQLite/PostgreSQL/MySQL) by `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions()` with its dialect name, which compiles + renders the CEL expression into parameterized SQL WHERE clauses appended to the query.
