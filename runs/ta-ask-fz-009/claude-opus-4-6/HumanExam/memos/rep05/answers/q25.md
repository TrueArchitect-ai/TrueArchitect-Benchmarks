Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/engine.go` (`Engine` struct using `cel.NewEnv`).
The engine compiles a CEL filter expression into a dialect-agnostic IR condition tree (`Condition`), which is then rendered to SQL by `internal/filter/render.go` using per-dialect column expressions and placeholders (the `DialectName` enum in `internal/filter/schema.go` covers sqlite, mysql, postgres). Each DB driver calls `filter.AppendConditions()` from `internal/filter/helpers.go`, passing its dialect, to append the generated WHERE clauses to its query.
