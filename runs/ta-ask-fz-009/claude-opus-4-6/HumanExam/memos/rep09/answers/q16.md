Before deleting the memo row itself, `Store.DeleteMemo` (store/memo.go:140) deletes:
1. memo_relation records (where memo is source)
2. memo_relation records (where memo is related/target)
3. attachments linked to this memo

Additionally, the API handler (`APIV1Service.DeleteMemo`, server/router/api/v1/memo_service.go:518) first deletes comment memos (child memos linked via `COMMENT` relation), each of which triggers the same store-level cleanup.
