Engine: CEL (Common Expression Language) via google/cel-go, implemented in `internal/filter/engine.go` (Engine struct, line 14).
Mechanism: Each dialect driver (e.g. store/db/sqlite/memo.go:57) calls `filter.DefaultEngine()` to get a CEL engine, then `filter.AppendConditions()` (internal/filter/helpers.go:9) compiles the CEL filter string into a dialect-agnostic condition tree (IR), then renders it to dialect-specific SQL via `internal/filter/render.go`, which switches on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` to produce the appropriate SQL fragments and placeholders.
