Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`
The `Engine` (internal/filter/engine.go:14) parses a CEL filter string into a dialect-agnostic IR condition tree (parser.go → ir.go), then the `renderer` (internal/filter/render.go) translates that IR into dialect-specific SQL (SQLite, PostgreSQL, MySQL) with parameterized placeholders, called at query time from each driver's `ListMemos` (e.g., `store/db/sqlite/memo.go:57–61` via `filter.AppendConditions`).
