When a memo is deleted, `Store.DeleteMemo` (store/memo.go:140) deletes before the memo row:
- `memo_relation` records (where the memo is source or target) — via `DeleteMemoRelation`
- `attachment` records linked to the memo — via `DeleteAttachment`

Additionally, the API handler (`APIV1Service.DeleteMemo`, server/router/api/v1/memo_service.go:518) first deletes **comment memos** (child memos linked via `memo_relation` of type `comment`), each of which triggers its own `Store.DeleteMemo` cascade (deleting their relations and attachments).
