Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/engine.go` (the `Engine` struct, using `cel.NewEnv`).
Mechanism: The CEL filter string is compiled into a dialect-agnostic condition tree by `Engine.Compile`, then each dialect driver calls `filter.AppendConditions` (internal/filter/helpers.go:9) with its dialect name (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`), which renders the condition tree into parameterized SQL via `internal/filter/render.go`.
