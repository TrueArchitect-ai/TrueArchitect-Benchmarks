Engine: CEL (Common Expression Language) filter engine, implemented at `internal/filter/engine.go` (type `Engine`, using `github.com/google/cel-go/cel`).
Mechanism: The CEL expression is compiled into an AST, then parsed into a dialect-agnostic condition tree (IR) by `internal/filter/parser.go`. The `internal/filter/render.go` renderer takes this condition tree and a `DialectName` (sqlite/postgres/mysql) and produces a parameterized SQL WHERE clause with dialect-specific syntax (e.g., `json_each` for SQLite, `jsonb_array_elements_text` for Postgres, `JSON_TABLE` for MySQL).
