Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140–158`) deletes:
- `memo_relation` records (where this memo is `memo_id`)
- `memo_relation` records (where this memo is `related_memo_id`)
- `attachment` records linked to this memo (plus their external storage files)

Additionally, at the API layer (`memo_service.go:567–577`), the handler also deletes comment memos (child memos linked via `COMMENT`-type memo_relation) before calling `Store.DeleteMemo`.
