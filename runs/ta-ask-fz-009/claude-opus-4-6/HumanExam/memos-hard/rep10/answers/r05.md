False premise. There is no GraphQL schema. The public API is a gRPC API (protobuf-defined under `proto/api/v1/`) exposed via gRPC-Gateway as a REST/JSON HTTP API, plus Connect-RPC. An OpenAPI spec is generated at `proto/gen/openapi.yaml`. The API is surfaced via `APIV1Service.RegisterGateway` at `server/server.go:88`.
