False premise. There is no GraphQL schema. The public API is defined as **gRPC services with Protocol Buffers** (proto definitions under `proto/api/v1/` and `proto/store/`), exposed via a **gRPC-Gateway** REST/JSON mapping (generated `.pb.gw.go` files) and **Connect-RPC** (generated `.connect.go` files). An OpenAPI spec is also generated at `proto/gen/openapi.yaml`.
