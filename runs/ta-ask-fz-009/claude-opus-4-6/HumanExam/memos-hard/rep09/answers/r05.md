False premise. There is no GraphQL schema or GraphQL API. The public API is gRPC + gRPC-Gateway (REST/JSON) defined via Protocol Buffers in `proto/api/v1/*.proto`, with an OpenAPI spec generated at `proto/gen/openapi.yaml`. A Connect (connectrpc) transport is also registered for browser clients (`server/router/api/v1/v1.go:139–144`).
