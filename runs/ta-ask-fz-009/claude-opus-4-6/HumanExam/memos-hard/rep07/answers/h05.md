Reactions are removed by explicit Go code when a user is deleted. The `deleteUserTargetsTx` function in each driver's `user_delete.go` calls:
1. `deleteReactionsByContentIDsTx` — deletes reactions whose `content_id` matches the user's memos (`store/db/sqlite/user_delete.go:96`, also `383`)
2. `deleteReactionsByCreatorTx` — deletes reactions where `creator_id` matches the deleted user (`store/db/sqlite/user_delete.go:102`, also `400-402`)

Equivalent code exists in the MySQL and PostgreSQL drivers. There is no database-level CASCADE rule for reactions — explicit Go code handles it.

**mechanism: explicit Go code; evidence locations: store/db/sqlite/user_delete.go:96 (deleteReactionsByContentIDsTx) and :102 (deleteReactionsByCreatorTx)**
