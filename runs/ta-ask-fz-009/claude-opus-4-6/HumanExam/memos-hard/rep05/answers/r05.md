False premise. There is no GraphQL schema or GraphQL API (zero matches across the codebase). The public API surface is gRPC + gRPC-Gateway (REST/JSON) defined via Protocol Buffers in `proto/api/v1/`, with generated Go code in `proto/gen/api/v1/`. An OpenAPI spec is also generated at `proto/gen/openapi.yaml`. Additionally, Connect RPC handlers are registered alongside the gRPC-Gateway.
