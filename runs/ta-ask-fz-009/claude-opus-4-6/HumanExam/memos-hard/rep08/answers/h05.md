Explicit Go code. When a user is deleted, reactions are removed by two explicit DELETE statements in the transaction:
1. `deleteReactionsByContentIDsTx` — deletes reactions whose `content_id` matches the user's memo UIDs (`store/db/sqlite/user_delete.go:380-388`)
2. `deleteReactionsByCreatorTx` — deletes reactions created by the user (`store/db/sqlite/user_delete.go:400-402`)
Both are called from `deleteUserTargetsTx` (`store/db/sqlite/user_delete.go:96,102`). Same pattern exists in `store/db/mysql/user_delete.go` and `store/db/postgres/user_delete.go`. No foreign key CASCADE constraints on the reaction table in migration schemas.
