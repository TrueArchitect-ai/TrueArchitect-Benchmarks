Before deleting the memo row itself, the store layer (store/memo.go:140 `Store.DeleteMemo`) deletes:
- memo_relation records where the memo is the source (`MemoID`)
- memo_relation records where the memo is the target (`RelatedMemoID`)
- attachment records linked to the memo (via `DeleteAttachment` for each)

(At the API-handler layer, server/router/api/v1/memo_service.go:518 `DeleteMemo` additionally deletes child comment memos first, each going through the same store.DeleteMemo cascade, and dispatches a webhook and lists reactions before deletion — reactions themselves are not explicitly deleted in code shown, only listed.)
