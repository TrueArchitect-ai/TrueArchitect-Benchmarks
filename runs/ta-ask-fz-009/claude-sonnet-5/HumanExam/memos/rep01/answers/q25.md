Engine: custom filter/CEL-like expression engine in `internal/filter` (internal/filter/engine.go, parser.go, render.go). It parses the CEL-style filter string (`filter.DefaultEngine()`), builds an IR, then `filter.AppendConditions`/`engine.CompileToStatement` renders dialect-specific SQL WHERE clauses per `filter.Dialect{MySQL,Postgres,SQLite}` (used in store/db/{mysql,postgres,sqlite}/memo.go).
