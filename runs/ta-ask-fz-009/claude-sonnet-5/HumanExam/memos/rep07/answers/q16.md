Before deleting the memo row, `store.Store.DeleteMemo` (store/memo.go:140) deletes:
1. memo_relation rows where the memo is the source (`MemoID`)
2. memo_relation rows where the memo is the target (`RelatedMemoID`)
3. attachments linked to the memo (via `DeleteAttachment` for each)
(Note: at the API layer, memo comments — child memos linked via `memo_relation` type COMMENT — are deleted first as separate `DeleteMemo` calls; see server/router/api/v1/memo_service.go:567-577. Reactions are listed but not explicitly deleted in this code path.)
