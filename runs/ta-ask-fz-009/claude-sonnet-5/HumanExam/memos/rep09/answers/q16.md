`store.Store.DeleteMemo` (`store/memo.go:140-159`) deletes, before the memo row:
- memo_relation rows where memo is the source (`DeleteMemoRelation{MemoID}`)
- memo_relation rows where memo is the target (`DeleteMemoRelation{RelatedMemoID}`)
- attachments linked to the memo (via `s.DeleteAttachment`)
(memo_share rows are removed via `ON DELETE CASCADE` FK, not explicit store code — see q26)
