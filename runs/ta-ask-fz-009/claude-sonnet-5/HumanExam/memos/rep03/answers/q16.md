Before deleting the memo row itself, `Store.DeleteMemo` (store/memo.go:140) deletes:
- memo_relation rows where the memo is the source (`DeleteMemoRelation{MemoID}`)
- memo_relation rows where the memo is the target (`DeleteMemoRelation{RelatedMemoID}`)
- attachments linked to the memo (via `DeleteAttachment` for each)
Additionally, at the API layer (server/router/api/v1/memo_service.go:567-577), memo *comments* (which are themselves memo rows linked via `memo_relation` type Comment) are deleted first by recursive calls to `Store.DeleteMemo`.
