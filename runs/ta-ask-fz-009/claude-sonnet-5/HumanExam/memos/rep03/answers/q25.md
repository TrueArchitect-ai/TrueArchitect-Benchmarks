Engine: a custom CEL-based filter engine in `internal/filter` (internal/filter/engine.go, parser.go, render.go, schema.go). Mechanism: request filter strings (AIP-160 style CEL expressions, e.g. from `ListMemosRequest.Filter`) are validated/compiled by `filter.DefaultEngine()` and then rendered per-dialect: each dialect's store code (e.g. store/db/sqlite/memo.go:57-61, and equivalent mysql/postgres files) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite/DialectMySQL/DialectPostgres, &where, &args)`, which compiles the CEL AST into dialect-specific SQL WHERE fragments and bound args.
