Mechanism: filter strings are parsed/compiled into a `Program`/`Condition` tree by `Engine.Compile` (internal/filter/engine.go:48), then rendered per-dialect into SQL fragments by `Program.Render`/`Engine.CompileToStatement` (engine.go:74,96) using `filter.RenderOptions{Dialect: ...}`; each dialect's `ListMemos` (store/db/{mysql,postgres,sqlite}/memo.go) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectX, &where, &args)` to append the resulting WHERE conditions and args.
