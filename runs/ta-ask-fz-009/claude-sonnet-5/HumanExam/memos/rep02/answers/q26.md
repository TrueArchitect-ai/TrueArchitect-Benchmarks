Directly deleted by store code: `memo` (the row itself), `memo_relation` (both `memo_id` and `related_memo_id` sides), `attachment` (rows linked to the memo). By explicit FK `ON DELETE CASCADE` in the schema: `memo_share` (`FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE`, e.g. `store/migration/sqlite/LATEST.sql:109`). Note: `reaction` has no FK to memo in the schema (content_id is a loose string reference), so reaction rows are not cascade-deleted.
