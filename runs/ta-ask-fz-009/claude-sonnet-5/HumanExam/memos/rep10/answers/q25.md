Engine: Google `cel-go` CEL expression engine, wrapped in `internal/filter/engine.go` (`Engine`, `NewEngine`, `Compile`). Mechanism: each dialect driver calls `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)` (e.g. store/db/sqlite/memo.go:57-61, store/db/postgres/memo.go:54-58, store/db/mysql/memo.go:65-69); `internal/filter/render.go` renders the parsed CEL condition tree into dialect-specific SQL fragments via per-`Dialect` switch cases (SQLite/MySQL/Postgres).
