Premise is wrong — memos has no message broker at all (no NATS, no RabbitMQ; grep for both across 343 Go files: zero hits). Webhook "delivery workers" are 4 in-process goroutines reading from a Go channel `asyncPostQueue` (buffered, size 128), started in `internal/webhook/webhook.go:42-55`, which each call `Post()` (webhook.go:120) directly over HTTP — there is no queue system, just an in-memory channel.
