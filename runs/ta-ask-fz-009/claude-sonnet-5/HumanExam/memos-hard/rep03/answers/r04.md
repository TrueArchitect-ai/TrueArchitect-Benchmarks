— Premise correction: webhook delivery uses neither NATS nor RabbitMQ — there is no message broker at all. Actual mechanism: an in-process, buffered Go channel `asyncPostQueue := make(chan *WebhookRequestPayload, 128)` (internal/webhook/webhook.go:39), drained by 4 fixed goroutines started in `init()` (webhook.go:42-55) that call `Post` (webhook.go:120) for each dequeued payload. `PostAsync` (webhook.go:184-196) enqueues (dropping and logging a warning if the channel is full) — there's no external queue declaration anywhere in the repo.
