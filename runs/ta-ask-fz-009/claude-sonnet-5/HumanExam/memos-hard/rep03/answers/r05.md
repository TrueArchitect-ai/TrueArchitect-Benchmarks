— Premise correction: there is no GraphQL schema or endpoint. `[ArchMap query]` returns a certified miss across all 7293 indexed symbols. The actual public API surface (confirmed via `[ArchMap query]`) is a Protocol-Buffers-defined gRPC service set (proto/store, proto/api/v1) exposed two ways: native gRPC/Connect RPCs, and a REST-JSON facade generated by `grpc-gateway` — e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{memo.name=memos/*}`, etc. (proto/gen/api/v1/memo_service.pb.gw.go:1745 and siblings), plus a handful of hand-written Echo routes (file server, RSS, SSE, robots.txt/sitemap.xml, `/healthz`).
