— Premise is wrong: there is no Redis. The cache layer is an in-process, in-memory cache (`store/cache/cache.go`, a `sync.Map`-backed `Cache` with a background TTL-eviction goroutine, cache.go:66-90). It is instantiated inside `store.New` (store/store.go:38-61) with `DefaultTTL: 10 * time.Minute` (store.go:41), used for three named caches: `instanceSettingCache`, `userCache`, `userSettingCache` (store.go:27-29). So: user entries get a 10-minute TTL, and there is no Redis connection anywhere in the codebase to configure.
