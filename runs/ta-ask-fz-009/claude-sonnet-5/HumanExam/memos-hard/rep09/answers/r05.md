— Premise is false: there is no GraphQL schema (`grep` for "graphql" across the repo returns zero matches). The public API surface is a set of gRPC/Connect services defined via Protobuf under `proto/api/v1/` and exposed as REST via grpc-gateway plus native Connect/gRPC, confirmed by `[ArchMap query]` — e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, etc. (proto/gen/api/v1/*.pb.gw.go), alongside a handful of plain Echo HTTP routes (file serving, RSS, frontend) in `server/router/`.
