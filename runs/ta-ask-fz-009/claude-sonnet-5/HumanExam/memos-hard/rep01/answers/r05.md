— Premise is wrong: memos exposes no GraphQL API (`grep` for "graphql" across the whole repo finds zero matches). The public API surface is **gRPC + gRPC-Gateway/REST**, defined via protobuf under `proto/api/v1/*.proto` and generated into `proto/gen/api/v1/`; confirmed by `[ArchMap query]`, which lists ~70 REST routes (e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, etc., served via `*.pb.gw.go` gateway files) plus a handful of native Echo routes (`/healthz`, `/file/...`, `/explore/rss.xml`, MCP endpoints). There is no `openapi`/GraphQL schema file beyond the generated `proto/gen/openapi.yaml` for the REST surface.
