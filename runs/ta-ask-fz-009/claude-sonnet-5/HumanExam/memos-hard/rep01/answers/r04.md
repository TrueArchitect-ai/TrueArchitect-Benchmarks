— Premise is wrong: memos has no message broker at all — no NATS, no RabbitMQ (`grep` for "nats"/"rabbitmq"/"amqp"/"broker" across the codebase and `go.mod` dependencies finds none). Webhook delivery is a simple **in-process buffered Go channel**: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`), drained by 4 goroutines started in `init()` (webhook.go:42-55) that call `webhook.Post` directly over HTTP — there is no external queueing system.
