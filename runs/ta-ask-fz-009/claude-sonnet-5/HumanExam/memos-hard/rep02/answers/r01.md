— Premise is false: there is no Redis cache in this codebase. The "cache layer" is an in-process, in-memory `sync.Map`-backed cache (`store/cache/cache.go`), instantiated per-`Store` in `store/store.go:38-60`. User entries (`userCache`) use the default TTL of **10 minutes** (`DefaultTTL: 10*time.Minute`, store/store.go:41, used to construct `userCache` at store/store.go:52), with a 5-minute cleanup sweep interval and a 1000-item cap.
