— The S3 presign runner (`s3presign.Runner`) refreshes presigned S3 attachment URLs before they expire, on a **12-hour ticker** (`runnerInterval = 12h`, `server/runner/s3presign/runner.go:27-41`), skipping any object whose presigned URL is still valid for the next 4 days. It's wired into startup in `server/server.go:162-163` (`startBackgroundRunners`), which also runs it once synchronously before starting the ticking goroutine (`server/server.go:169`).
