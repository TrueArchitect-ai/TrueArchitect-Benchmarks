**Premise correction:** There is no GraphQL schema in this repository — this codebase (usememos/memos) doesn't expose a GraphQL API at all. Both the code-graph's API surface extraction and a direct text search for `graphql`/`type Query`/`type Mutation` across the whole repo (1042 files scanned) came back empty.

**Actual API surface:** The public API is defined via **Protocol Buffers + gRPC, exposed over REST through grpc-gateway**:

- Proto service definitions live under `proto/` (compiled into `proto/gen/api/v1/*.pb.go` and gateway handlers in `proto/gen/api/v1/*.pb.gw.go`), covering services like `MemoService`, `UserService`, `AuthService`, `AttachmentService`, `IdentityProviderService`, `InstanceService`, `ShortcutService`.
- These generate the REST-style JSON endpoints under `/api/v1/...` (e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, etc.), registered via the `.pb.gw.go` gateway files — e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `proto/gen/api/v1/user_service.pb.gw.go:2301`, `proto/gen/api/v1/auth_service.pb.gw.go:331`.
- A few hand-written routes sit alongside these in `server/router/` (SSE at `server/router/api/v1/sse_handler.go:25`, RSS in `server/router/rss/rss.go`, file/avatar serving in `server/router/fileserver/fileserver.go`, frontend static routes in `server/router/frontend/frontend.go`).

So if you're looking for the schema contract, look at the `.proto` source files (likely under `proto/api/v1/` — the source for the generated `proto/gen/api/v1/` files) rather than any GraphQL SDL file.
