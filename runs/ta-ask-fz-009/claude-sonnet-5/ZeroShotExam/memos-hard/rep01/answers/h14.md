**Computation site:** `internal/markdown/markdown.go` — `service.ExtractProperties` (and the combined `ExtractAll`, which also runs `ExtractTags`) walks the goldmark AST of the memo's Markdown `Content` and builds a `storepb.MemoPayload_Property`. This is invoked via `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which stores the result on `memo.Payload.Property` (and `memo.Payload.Tags`).

**Triggers (recomputation):**
- On memo creation: `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` right after building the new `store.Memo` from `request.Memo.Content`.
- On memo update, only when the `content` field is in the update mask: `server/router/api/v1/memo_service.go:447` (inside the `path == "content"` branch of `UpdateMemo`) — i.e. it's not recomputed for visibility/pin/other field-only updates.
- Via a background batch job: `server/runner/memopayload/runner.go` `Runner.RunOnce` lists all memos in pages of 100 and calls `RebuildMemoPayload` for each, persisting via `Store.UpdateMemo` — used to backfill/rebuild payloads for existing memos (e.g. on migrations/maintenance).

**Extracted properties** (`storepb.MemoPayload_Property`, defined in `proto/gen/store/memo.pb.go:85-95`), computed in `ExtractProperties` (`internal/markdown/markdown.go:192-229`):
- `HasLink` — set when an AST `Link` node is found.
- `HasCode` — set when a code block, fenced code block, or code span node is found.
- `HasTaskList` — set when a task checkbox node is found.
- `HasIncompleteTasks` — set when a found task checkbox is unchecked.
- `Title` — text of the first H1 heading, if it is the document's first block-level child.

Additionally, `ExtractAll`/`ExtractTags` (same file) walks the AST for `#tag` nodes to populate `memo.Payload.Tags`, which is set alongside `Property` in `RebuildMemoPayload`.
