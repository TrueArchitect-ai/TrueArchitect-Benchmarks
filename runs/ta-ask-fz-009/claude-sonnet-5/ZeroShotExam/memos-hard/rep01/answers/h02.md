delivery function — `Post` (dispatched synchronously by `PostAsync` via a bounded worker queue) in `internal/webhook/webhook.go:120` (async wrapper at `internal/webhook/webhook.go:184`). `Post` builds the signed HTTP request and executes it through the package-level `safeClient` (`internal/webhook/webhook.go:32`).

protection mechanism — `internal/webhook/webhook.go:59` (`safeDialContext`), installed as `safeClient`'s `Transport.DialContext`, resolves the target host at dial time and rejects any resolved IP that falls in a reserved/private range (defeating DNS-rebinding attempts to bypass URL-time checks). The actual reserved-range check is `isReservedIP` in `internal/webhook/validate.go:44`, which tests against `reservedCIDRs`/`reservedNetworks` (loopback, RFC-1918 private ranges, link-local/cloud IMDS 169.254.169.254, and IPv6 equivalents) defined at `internal/webhook/validate.go:14-26`. The same check also gates webhook creation up front via `ValidateURL` (`internal/webhook/validate.go:62`), and can be disabled for self-hosted setups via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
