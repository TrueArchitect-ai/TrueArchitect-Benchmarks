Premise correction: there is no GraphQL schema in this repository — the public API surface is not GraphQL at all. A repo-wide search for "graphql" returns zero matches across 1042 files, and the code-graph's API surface extraction (`[ArchMap query]`) shows no GraphQL server, resolver, or schema symbols.

Actual API surface: this is a **gRPC + gRPC-Gateway (REST/JSON) API**, defined via Protocol Buffers:

- **Proto service definitions** live under `proto/` (source `.proto` files), compiled into Go bindings in `proto/gen/api/v1/` — e.g. `memo_service.pb.gw.go`, `user_service.pb.gw.go`, `attachment_service.pb.gw.go`, `auth_service.pb.gw.go`, `idp_service.pb.gw.go`, `instance_service.pb.gw.go`, `shortcut_service.pb.gw.go`.
- These generate the REST gateway routes exposed at `/api/v1/...` (e.g. `POST /api/v1/memos`, `GET /api/v1/users`, `PATCH /api/v1/{name=memos/*}`), registered via the `.pb.gw.go` gateway files (e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`).
- Additional non-gRPC HTTP routes are hand-written in `server/router/`: SSE at `server/router/api/v1/sse_handler.go:25`, file serving in `server/router/fileserver/fileserver.go`, frontend/robots/sitemap in `server/router/frontend/frontend.go`, RSS feeds in `server/router/rss/rss.go`, and health check in `server/server.go:44`.

So "the GraphQL schema" doesn't exist here — the public API contract is expressed as Protobuf service definitions (`.proto` → `proto/gen/api/v1/*.pb.gw.go`) fronting a gRPC-Gateway, not a GraphQL schema.
