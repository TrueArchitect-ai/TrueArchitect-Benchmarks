h14. Derived memo metadata is computed by `internal/markdown` and written into `store.Memo.Payload` by `memopayload.RebuildMemoPayload`.

**Computation site**
- `internal/markdown/markdown.go:356` — `(*service).ExtractAll(content []byte)` parses the memo body once with the goldmark AST and returns tags, mentions, and a `storepb.MemoPayload_Property` struct.
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` calls `ExtractAll` on `memo.Content` and assigns the results to `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:79-87).

**Triggers (recomputation)**
- Memo creation: `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before the memo is persisted (`CreateMemo`).
- Memo update, but only when the content field is part of the update mask: `server/router/api/v1/memo_service.go:436-451` — inside `UpdateMemo`, the payload is only rebuilt if `path == "content"` (i.e. the body text actually changed), then `update.Payload = memo.Payload` is written back to the store.
- Bulk/backfill path: `server/runner/memopayload/runner.go:27-71` — `Runner.RunOnce` walks all memos in batches of 100 via `Store.ListMemos` and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each. Note this runner exists (added in the same commit, `runner.go` is 88 lines, all new) but is not currently wired into `startBackgroundRunners` in `server/server.go:153-174` — only the S3 presign runner is started there — so today the runner is invoked exclusively via the create/update request paths above, and `RunOnce`/batch rebuild has no wired caller found in the codebase.

**Extracted properties** (single AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-419`):
- `Tags` — collected from `#tag` nodes, deduplicated case-preserving.
- `Mentions` — collected from `@username` mention nodes, lowercased and deduplicated.
- `Property.Title` — text of the first block-level child if it's an H1 heading.
- `Property.HasLink` — set if any `KindLink` node is present.
- `Property.HasCode` — set if any code block/fenced code block/code span node is present.
- `Property.HasTaskList` — set if any task checkbox node is present.
- `Property.HasIncompleteTasks` — set if any task checkbox is unchecked.

These derived fields live in `storepb.MemoPayload` / `MemoPayload_Property` (`proto/gen/store/memo.pb.go:24-160`) and are exposed to clients via `Memo_Property` (`proto/gen/api/v1/memo_service.pb.go:2182` and the converter `convertMemoPropertyFromStore`, `server/router/api/v1/memo_service_converter.go:315`), used for list/preview rendering.
