Each of these dispatch helpers builds a `webhook.WebhookRequestPayload{URL: hook.Url, ...}` from the user's stored webhook configuration (`store.WebhooksUserSetting_Webhook.Url`) and hands it to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues it on `asyncPostQueue`; four background goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`.

**Convergence function — path:** `webhook.Post` — `internal/webhook/webhook.go:120` (issues the actual outbound request via `safeClient.Do(req)` at line 152, against `requestPayload.URL`, i.e. the user-configured webhook URL). All four handler paths above funnel through this single function before any byte leaves the process.
