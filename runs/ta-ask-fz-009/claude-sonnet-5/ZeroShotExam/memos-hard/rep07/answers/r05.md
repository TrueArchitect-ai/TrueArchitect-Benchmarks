**Premise correction:** This repo (memos, `github.com/usememos/memos`) has no GraphQL API — there's no `.graphql`/`.gql` schema, no `type Query`/`type Mutation` root, and no GraphQL server/resolver wiring anywhere in the codebase. The public-API surface confirmed by the code graph is entirely **gRPC + gRPC-Gateway (REST/JSON) + OpenAPI**, not GraphQL:

- **Protobuf service definitions** (the actual API contract, analogous to a schema) live under `proto/` and get compiled into `proto/gen/api/v1/*.pb.go` and `*.pb.gw.go` — e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`, `attachment_service.pb.gw.go:571`, `auth_service.pb.gw.go:331`, `instance_service.pb.gw.go:525`, `idp_service.pb.gw.go:493`, `shortcut_service.pb.gw.go:529`.
- These generate the REST surface at `/api/v1/...` (memos, users, attachments, auth, instance settings, identity providers, shortcuts, etc.) per `[ArchMap query]`.
- There's also an **OpenAPI/JSON-schema layer for MCP tooling** at `server/router/mcp/openapi.go` and `server/router/mcp/catalog.go` (functions like `inputSchemaForOperation`, `requestBodySchema`, `okSchema`), which builds JSON schemas from the OpenAPI spec for MCP tool exposure — again not GraphQL.
- Additional non-API-schema `Schema` types exist in `internal/filter/schema.go` (`NewSchema`, `NewAttachmentSchema`), but these are filter/query schemas, unrelated to GraphQL.

If you're looking for the source-of-truth API contract, it's the `.proto` files in `proto/` (not shown in this result set but the origin of the generated `proto/gen/api/v1/*` files), not a GraphQL SDL file.
