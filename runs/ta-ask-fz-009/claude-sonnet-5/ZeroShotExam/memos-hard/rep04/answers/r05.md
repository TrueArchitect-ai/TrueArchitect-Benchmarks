**Premise correction:** There is no GraphQL schema in this repository. The `[ArchMap query]` map (81 endpoints, certain confidence) shows this is a **gRPC + gRPC-Gateway (REST/JSON) API**, not GraphQL — and `.graphql` file search returned zero matches.

**Actual API surface:**
- The API is defined as **Protocol Buffer service definitions** (e.g. `MemoService`, `UserService`, `AttachmentService`, `AuthService`, `InstanceService`, `IdentityProviderService`, `ShortcutService`), compiled to Go under `proto/gen/api/v1/` (e.g. `proto/gen/api/v1/memo_service.pb.gw.go`, `user_service.pb.gw.go`, `attachment_service.pb.gw.go`, etc.).
- Each service's gRPC-Gateway (`*.pb.gw.go`) file registers REST routes under `/api/v1/...` (e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`), translating HTTP/JSON to gRPC calls — this is the public API surface a client actually talks to.
- A handful of non-gRPC routes exist alongside it: `server/router/api/v1/sse_handler.go:25` (SSE), `server/router/fileserver/fileserver.go` (attachment/avatar static serving), `server/router/frontend/frontend.go` (robots.txt/sitemap), `server/router/rss/rss.go` (RSS feeds), and a health check in `server/server.go:44`.

If you're looking for the source `.proto` files themselves (rather than the generated Go), they'd live under a `proto/` directory outside `proto/gen/` — I did not locate them in this pass, but the generated bindings above confirm the API contract is Protobuf/gRPC, not GraphQL.
