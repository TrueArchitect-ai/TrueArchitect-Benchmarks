**Convergence function — path:**
`webhook.Post` — `internal/webhook/webhook.go:120`

All the dispatch paths above call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which simply enqueues the payload onto `asyncPostQueue`. The queue is drained by four worker goroutines spawned in `webhook.init` (`webhook.go:42-55`), each of which calls `Post(payload)` — the single function that marshals the payload, builds the `http.Request` to `requestPayload.URL`, and executes it via `safeClient.Do(req)` (`webhook.go:152`). That's where every one of these handler paths actually converges before the outbound request leaves the process.
