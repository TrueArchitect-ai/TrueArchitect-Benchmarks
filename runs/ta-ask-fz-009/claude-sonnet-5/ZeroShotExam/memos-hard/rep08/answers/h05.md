**Mechanism: explicit Go code (not a DB-level cascade/trigger).** When a user is deleted, the store layer explicitly deletes their emoji reactions in two ways within the same transaction:

1. **Reactions on the deleted user's own memos** — `deleteReactionsByContentIDsTx` runs `DELETE FROM reaction WHERE content_id IN (...)` for the content IDs of all memos owned by the user (mysql: `store/db/mysql/user_delete.go:417`; equivalent functions exist for postgres `store/db/postgres/user_delete.go:380` and sqlite `store/db/sqlite/user_delete.go:380`).
2. **Reactions the deleted user made on any memo** — `deleteReactionsByCreatorTx` runs `DELETE FROM reaction WHERE creator_id = ?` (mysql: `store/db/mysql/user_delete.go:437`; postgres: `store/db/postgres/user_delete.go:400`; sqlite: `store/db/sqlite/user_delete.go:400`).

Evidence checked:
- Traced the call chain from `DeleteUser` to reaction-deletion helpers via `ArchMap query` `[ArchMap query]`, confirming for all three backends: `mysql.DB.DeleteUser` → `deleteUserTargetsTx` → `deleteReactionsByContentIDsTx` / `deleteReactionsByCreatorTx` (`store/db/mysql/user_delete.go:29,92,417,437`), same pattern for `postgres.DB.DeleteUser` (`store/db/postgres/user_delete.go:29,92,380,400`) and `sqlite.DB.DeleteUser` (`store/db/sqlite/user_delete.go:29,92,380,400`).
- Read `store/db/mysql/user_delete.go:1-100` and `:400-460` directly, confirming `DeleteUser` opens a transaction, calls `deleteUserTargetsTx` (line 92-98) which invokes `deleteReactionsByContentIDsTx` first, and separately `deleteReactionsByCreatorTx` (line 437-440) issues its own raw `DELETE FROM reaction ...` SQL statement inside the same transaction — i.e., ordinary application-level DELETE statements executed by Go code, not a foreign-key `ON DELETE CASCADE` or database trigger.

No evidence of a DB-level cascade rule was found for this path — the deletions are performed by hand-written SQL in the store package, batched (`deleteUserBatchSize = 500`) and executed as part of the same `tx` used for the rest of the user-deletion cleanup.
