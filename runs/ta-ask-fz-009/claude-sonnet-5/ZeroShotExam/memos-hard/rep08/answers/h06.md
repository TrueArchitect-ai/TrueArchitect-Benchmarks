(The gRPC/Connect-wrapped variants `ConnectServiceHandler.CreateMemo`/`DeleteMemo` in `server/router/api/v1/connect_services.go:306,338` reach the same paths.)

Each of these sets `payload.URL = hook.Url` (a user-controlled webhook URL stored per-user) and calls `webhook.PostAsync(payload)`, which enqueues onto `asyncPostQueue` (`internal/webhook/webhook.go:39`). The queue is drained by worker goroutines started in `webhook.init` (`internal/webhook/webhook.go:42-55`), each of which calls `webhook.Post`.

**Convergence function — path:** `webhook.Post` — `internal/webhook/webhook.go:120` (the actual outbound request is issued at `safeClient.Do(req)`, line 152). Every dispatch path above funnels into this single function before any bytes leave the process.
