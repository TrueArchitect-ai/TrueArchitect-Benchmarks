Memo-visibility enforcement is duplicated across at least seven distinct server surfaces, each with its own independent check rather than a single shared gate:

- gRPC/Connect API read-access gate (`checkMemoReadAccess`, used by `GetMemo` and `ListMemoComments`) — server/router/api/v1/memo_service.go:39-68
- Memo listing query-level visibility filter (`ListMemos` restricts `VisibilityList`/filter for anonymous vs. non-owner callers) — server/router/api/v1/memo_service.go:218-227
- Memo attachment access check (`ListMemoAttachments`) — server/router/api/v1/memo_attachment_service.go:213-225
- Generic attachment-download access check (`canAccessAttachment`-style linked-memo check) — server/router/api/v1/attachment_service.go:436-454
- Memo reaction access check (`ListMemoReactions` and the reaction-upsert path) — server/router/api/v1/reaction_service.go:29-41, :83
- Comment creation visibility check (`CreateMemoComment`) — server/router/api/v1/memo_service_comments.go:33-43
- Mention-notification visibility checks — server/router/api/v1/memo_mention_helpers.go:62-84 and server/router/api/v1/user_service_notifications.go:309-312
- Realtime SSE broadcast filter (`SSEClient.canReceive`) — server/router/api/v1/sse_hub.go:134-144
- Static attachment fileserver HTTP handler (share-token + visibility check) — server/router/fileserver/fileserver.go:674-701
- RSS feed generator (hard-restricted to `store.Public` only) — server/router/rss/rss.go:88-93, :141
- Frontend sitemap generator (hard-restricted to `store.Public` only) — server/router/frontend/frontend.go:143-151

The first six re-implement the same "public → anyone; protected → any authed user; private → creator or super-user" logic independently in Go source rather than calling a single shared authorization function (only `checkMemoReadAccess` is actually reused, and only by two callers). The SSE hub, fileserver, RSS, and frontend sitemap are separate transport surfaces (websocket/SSE push, raw HTTP file serving, XML feeds) that each re-derive visibility rules from `store.Visibility` values directly.
