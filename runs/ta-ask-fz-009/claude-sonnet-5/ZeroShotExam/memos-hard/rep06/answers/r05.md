**Premise correction:** There is no GraphQL schema in this repository — this codebase (usememos/memos) does not expose a GraphQL API at all.

**Actual API surface:** The public API is a gRPC service layer exposed over HTTP via a gRPC-Gateway REST transcoding layer. Concretely:

- The API is defined via Protobuf service definitions (proto/gen/api/v1/*.proto, compiled into Go), covering services like `AttachmentService`, `AuthService`, `IdentityProviderService`, `InstanceService`, `MemoService`, `ShortcutService`, and `UserService`.
- Each service has a generated gateway file (e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `proto/gen/api/v1/user_service.pb.gw.go:2301`, `proto/gen/api/v1/attachment_service.pb.gw.go:571`, `proto/gen/api/v1/auth_service.pb.gw.go:331`, `proto/gen/api/v1/idp_service.pb.gw.go:493`, `proto/gen/api/v1/instance_service.pb.gw.go:525`, `proto/gen/api/v1/shortcut_service.pb.gw.go:529`) that maps REST-style routes like `GET /api/v1/memos`, `POST /api/v1/users`, `PATCH /api/v1/{name=memos/*}` etc. onto the gRPC handlers.
- A few additional plain HTTP handlers exist outside the gateway: `v1.RegisterSSERoutes` (server/router/api/v1/sse_handler.go:25), the file server (server/router/fileserver/fileserver.go), the frontend/robots/sitemap routes (server/router/frontend/frontend.go), and RSS feeds (server/router/rss/rss.go).

A repo-wide search for GraphQL markers (`graphql`, `.graphql` schema files, `type Query`, `gql\`` tagged templates) across 1042 files returned no matches, confirming there's no GraphQL layer to point to.
