The **S3 presign runner** (`s3presign.Runner` in `server/runner/s3presign/runner.go`) keeps externally-stored attachment links (S3 object references) from going stale by periodically re-generating presigned URLs for attachments whose current presigned URL is nearing expiry (it skips re-signing if the existing URL is still valid for the next 4 days — `server/runner/s3presign/runner.go:86`).

- **Component**: `s3presign.Runner` (`CheckAndPresign` / `RunOnce` / `Run`) — `server/runner/s3presign/runner.go:16-127`
- **Schedule**: every 12 hours, via `time.NewTicker(runnerInterval)` where `runnerInterval = time.Hour * 12` — `server/runner/s3presign/runner.go:27,30`
- **Wiring site**: `server/server.go:161-171` — inside `Server.startBackgroundRunners`, it constructs the runner (`s3presign.NewRunner(s.Store)`), runs it once immediately (`s3presignRunner.RunOnce(ctx)` at `server/server.go:163`), then launches it as a goroutine on a cancellable context (`s3presignRunner.Run(s3Context)` at `server/server.go:169`).
