- delivery function — `Post` in `internal/webhook/webhook.go:120` (invoked synchronously, or asynchronously via `PostAsync`/the worker pool at `internal/webhook/webhook.go:184` and `internal/webhook/webhook.go:42-55`). It marshals the payload, optionally signs it (HMAC-SHA256, Standard Webhooks style), and issues the actual `http.Client.Do` call.
- protection mechanism — `internal/webhook/validate.go`: the shared `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-37,59-77`), which resolves the target host and calls `isReservedIP` (`internal/webhook/validate.go:44`) against a table of reserved/private CIDRs (loopback, RFC-1918, link-local/cloud-IMDS 169.254.169.254, and IPv6 equivalents, `validate.go:14-23`) before dialing — blocking SSRF at connection time (defeating DNS-rebinding too, since resolution happens right before dial). The same check is applied earlier at request-creation time via `ValidateURL` (`validate.go:62-83`). This protection can be disabled per-deployment via the `AllowPrivateIPs` flag (`validate.go:41`).
