**Premise correction:** There is no GraphQL schema in this repository. This project (usememos/memos) exposes its public API as a **gRPC + gRPC-Gateway (REST/JSON)** API, not GraphQL — the query for GraphQL identifiers (`type Query`, `type Mutation`, `.graphql` schema files, `gql`) turned up nothing but unrelated lockfile hash strings in `web/pnpm-lock.yaml`, and the architecture map's endpoint surface confirms all public API doors are REST-over-gRPC-gateway routes, not a GraphQL endpoint.

**Actual API surface:**
- The service contracts are defined as **Protobuf** definitions (`.proto` files, compiled into `proto/gen/api/v1/*.pb.go` and `*.pb.gw.go`), e.g. `proto/gen/api/v1/memo_service.pb.gw.go`, `proto/gen/api/v1/user_service.pb.gw.go`, `proto/gen/api/v1/attachment_service.pb.gw.go`, `proto/gen/api/v1/auth_service.pb.gw.go`, `proto/gen/api/v1/idp_service.pb.gw.go`, `proto/gen/api/v1/instance_service.pb.gw.go`, `proto/gen/api/v1/shortcut_service.pb.gw.go`.
- These are exposed publicly as REST endpoints under `/api/v1/...` via grpc-gateway (e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{name=memos/*}`, etc.), plus a handful of hand-written routes: SSE at `server/router/api/v1/sse_handler.go:25`, file serving in `server/router/fileserver/fileserver.go`, RSS in `server/router/rss/rss.go`, frontend routes in `server/router/frontend/frontend.go`, and health check in `server/server.go:44`.

So if you're looking for "the schema," it's the `.proto` files under `proto/` (compiled to `proto/gen/api/v1/`), not a GraphQL SDL file.
