**Premise correction:** There is no GraphQL schema in this codebase — the platform (memos, `github.com/usememos/memos`) doesn't expose a GraphQL API at all. A grep across all 1042 tracked files for `graphql`, `typeDefs`, or `gql\`` returned zero matches, and the certified API-surface map (`[ArchMap query]`) lists only REST/gRPC-gateway endpoints — no GraphQL resolver or schema file exists to point to.

**Actual API surface:** The public API is defined via Protobuf service definitions compiled into a gRPC-Gateway REST layer. Concretely:

- Proto-generated gateway handlers live under `proto/gen/api/v1/*.pb.gw.go` (e.g. `memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`, `attachment_service.pb.gw.go:571`, `auth_service.pb.gw.go:331`, `idp_service.pb.gw.go:493`, `instance_service.pb.gw.go:525`, `shortcut_service.pb.gw.go:529`) — these register the `/api/v1/...` REST routes (memos, users, attachments, auth, identity providers, instance settings, shortcuts, etc.) by translating HTTP/JSON to gRPC calls.
- Additional custom routes are registered directly in Go, e.g. SSE at `server/router/api/v1/sse_handler.go:25`, health check in `server/server.go:44`, plus file-serving, frontend, and RSS routes under `server/router/{fileserver,frontend,rss}/`.

So if you're looking for "the schema," it's the `.proto` source files (compiled into `proto/gen/api/v1/`) that define the service contracts — not a GraphQL SDL file.
