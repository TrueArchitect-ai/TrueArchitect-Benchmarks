- **SSRF protection**: the shared `safeClient` (`internal/webhook/webhook.go:32`) uses a custom `Transport.DialContext` set to `safeDialContext` (`internal/webhook/webhook.go:59`). On every dial it resolves the target host via `net.DefaultResolver.LookupHost`, then checks each resolved IP with `isReservedIP` (defined in `internal/webhook/validate.go:44`) and refuses the connection if any address falls in a reserved/private range — this runs at dial time (post-DNS-resolution), which also blocks DNS-rebinding attempts, not just a pre-check on the literal URL.
