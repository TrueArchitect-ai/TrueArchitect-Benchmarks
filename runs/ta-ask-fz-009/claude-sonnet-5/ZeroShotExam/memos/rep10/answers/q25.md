**Engine:** CEL (Google's Common Expression Language), via `github.com/google/cel-go` — the engine lives in `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`).

**Mechanism:** `ListMemos`'s filter string is parsed and type-checked by `cel-go` against a memo-specific CEL environment (`internal/filter/schema.go`), converted by `parser.go` into a dialect-agnostic intermediate representation (`ir.go`) — cel-go itself never evaluates the expression — and then `render.go` walks that IR to emit dialect-specific SQL `WHERE` fragments and placeholder args for SQLite, MySQL, or Postgres (per `filter.RenderOptions{Dialect: ...}`), which are appended to the store query via `helpers.go`'s `AppendConditions` (per `internal/filter/README.md:1-105`).
