`store/migration/sqlite/LATEST.sql`

This file contains the complete, current set of `CREATE TABLE` statements (e.g., `system_setting`, `user`, and the rest of the schema) and is used to initialize a fresh SQLite database, as opposed to the incremental version-numbered migration files (e.g., `store/migration/sqlite/0.30/00__user_tag_setting.sql`) which only apply diffs for upgrades.
