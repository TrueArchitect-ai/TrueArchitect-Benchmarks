In `store.Store.DeleteMemo` (store/memo.go:140-159), before deleting the memo row itself (`s.driver.DeleteMemo`), the store layer deletes:

1. **Memo relation records** — where the memo is the source (`DeleteMemoRelation{MemoID: &delete.ID}`) and where it's the target (`DeleteMemoRelation{RelatedMemoID: &delete.ID}`), store/memo.go:142-147.
2. **Attachments** — all attachments linked to the memo are looked up via `ListAttachments` and each is removed with `s.DeleteAttachment`, store/memo.go:149-157 (which internally is `store.Store.DeleteAttachment`, store/attachment.go:132).

Only after these cleanups does it call `s.driver.DeleteMemo(ctx, delete)` to remove the memo row itself (store/memo.go:158).
