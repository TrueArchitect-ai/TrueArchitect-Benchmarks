**Engine + path**: A CEL (Common Expression Language, `github.com/google/cel-go`) filter engine that lives entirely in `internal/filter/` — `engine.go` (compiles filters via `cel.NewEnv`/`env.Compile`), `schema.go` (defines the per-resource variable schema, e.g. `content`, `creator_id`, `tags`, `pinned`, `visibility`, `now` for memos), `ir.go` (dialect-agnostic condition tree via `buildCondition`), and `render.go` (SQL rendering).

**Mechanism**: `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) puts `request.Filter` into `store.FindMemo.Filters`; the store layer per-dialect (`store/db/{mysql,postgres,sqlite}/memo.go`) calls `filter.AppendConditions` (`internal/filter/helpers.go:9`), which for each filter string calls `Engine.CompileToStatement` (`internal/filter/engine.go:74`) — this parses the CEL expression into an AST (`env.Compile`), converts it to a dialect-agnostic `Condition` tree (`buildCondition`, `internal/filter/ir.go`), then a `renderer` (`internal/filter/render.go:24`, selected by `RenderOptions.Dialect` = `DialectSQLite`/`DialectMySQL`/`DialectPostgres`) walks that tree to emit dialect-specific SQL fragments and positional args (e.g. `LIKE`/`ILIKE`, `REGEXP`/`~`, `JSON_TABLE`/`jsonb_array_elements_text`/`json_each` for list membership), which are appended as a parenthesized `WHERE` clause with bound args.
