q08. **Driver — `store/driver.go`** (interface defined at line 10)

This interface enumerates all the database operations (attachments, memos, users, settings, identity providers, reactions, etc.) that a concrete backend must satisfy. It is implemented by each backend driver in `store/db/mysql/mysql.go`, `store/db/postgres/postgres.go`, and `store/db/sqlite/sqlite.go`, with the shared model/CRUD methods split across the sibling files in those same package directories (e.g. `store/db/mysql/memo.go`, `store/db/postgres/user.go`, `store/db/sqlite/reaction.go`, etc.).
