q29. Frontend requests are authenticated via a Connect-RPC client interceptor: `authInterceptor` in `web/src/connect.ts:156` (registered on the `transport` at `web/src/connect.ts:184-189`). It attaches the access token as `Authorization: Bearer <token>` (`setAuthorizationHeader`, `web/src/connect.ts:97-99`), reactively refreshes it on a `Unauthenticated` (401) response and retries once (`web/src/connect.ts:161-177`), and redirects the user on refresh failure via `redirectOnAuthFailure`. Token storage/lifecycle (in-memory + `localStorage`, cross-tab sync via `BroadcastChannel`) lives in `web/src/auth-state.ts`.

Tokens managed:
- **Access token** — short-lived JWT (15 min), sent as the Bearer header on every request; stored/refreshed client-side (`web/src/auth-state.ts`).
- **Refresh token** — long-lived JWT (30 days), sent via HTTP-only cookie (`memos_refresh`) and used to mint new access tokens through `AuthService.refreshToken` (`web/src/connect.ts:65-83`).
- (Server-side there's also a **Personal Access Token (PAT)** kind for programmatic access, though the browser interceptor itself only handles access/refresh tokens.)

Backend package that validates them: `server/auth` (e.g. `server/auth/token.go`, `server/auth/authenticator.go`) — it defines `AccessTokenClaims`/`RefreshTokenClaims`, `ParseAccessTokenV2`/`ParseRefreshToken`, and `Authenticator.Authenticate`/`AuthenticateByAccessTokenV2`/`AuthenticateByRefreshToken`/`AuthenticateByPAT`. This is invoked from `server/router/api/v1/connect_interceptors.go:222` (`AuthInterceptor.WrapUnary` → `in.authorizer.Authenticate(ctx, authHeader)`, via `server/router/api/v1/authz.go:44`), which is the Connect-RPC interceptor wired server-side to enforce auth on incoming requests.

**Answer format:** `web/src/connect.ts:156` (authInterceptor); access token (short-lived JWT, Bearer header) + refresh token (long-lived JWT, HTTP-only cookie) — plus PAT supported server-side; backend validation package `server/auth` (invoked from `server/router/api/v1/connect_interceptors.go` and `server/router/api/v1/authz.go`).
