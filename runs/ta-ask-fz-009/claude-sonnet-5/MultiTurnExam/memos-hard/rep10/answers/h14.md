**Extracted properties** (populated onto `store.Memo.Payload`, a `storepb.MemoPayload`):
- `Tags` — `#tag` occurrences found via `mast`/tag AST nodes, deduplicated case-preservingly (`internal/markdown/markdown.go:377,417`)
- `Mentions` — `@mention` occurrences, lowercased (`markdown.go:379-380`) — collected in `ExtractedData` but not stored on `Payload` directly by `RebuildMemoPayload` (only `Tags`/`Property` are assigned, `runner.go:85-86`)
- `Property.Title` — text of a leading H1 heading, if the first top-level block is one (`markdown.go:384-388`)
- `Property.HasLink` — set when any link node is present (`markdown.go:393-394`)
- `Property.HasCode` — set for code blocks/fenced code blocks/inline code spans (`markdown.go:396-397`)
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set for task-list checkboxes, with the latter flagging any unchecked box (`markdown.go:399-405`)
