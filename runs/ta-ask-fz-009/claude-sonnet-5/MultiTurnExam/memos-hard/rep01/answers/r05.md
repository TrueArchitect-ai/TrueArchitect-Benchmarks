**Premise correction**: There is no GraphQL schema anywhere in this codebase — a search for "graphql" (case-insensitive) across all 1042 files returns zero matches.

**Actual API surface**: The public API is defined via Protocol Buffers under `proto/api/v1/` — service definitions like `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and shared types in `common.proto`. These generate both gRPC and gRPC-Gateway (REST/JSON) handlers under `proto/gen/api/v1/` (e.g. `*_grpc.pb.go`, `*.pb.gw.go`) plus Connect-RPC handlers under `proto/gen/api/v1/apiv1connect/`, giving three transports (gRPC, REST via gateway, Connect) over the same proto-defined API surface — no GraphQL layer exists.
