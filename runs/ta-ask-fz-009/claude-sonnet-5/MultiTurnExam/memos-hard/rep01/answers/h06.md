**Convergence function**: `webhook.Post` — `internal/webhook/webhook.go:120`

All of these paths — direct calls and the async-queued ones (`webhook.PostAsync` → `asyncPostQueue` → worker goroutines started in `webhook.init`, `internal/webhook/webhook.go:42-55`) — ultimately execute the actual outbound HTTP request to the user-configured URL inside `webhook.Post`, which builds the request and performs `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).
