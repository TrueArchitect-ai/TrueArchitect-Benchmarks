**Delivery function**: `webhook.Post` — `internal/webhook/webhook.go:120` (the actual outbound HTTP dispatch: builds the request, optionally signs it via HMAC-SHA256, and executes it with `safeClient.Do(req)`). It's invoked directly, or queued for background dispatch via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which feeds a bounded channel drained by four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) that call `Post` for each queued payload.

**SSRF protection**: the shared `safeClient` (`internal/webhook/webhook.go:32-37`) uses a custom `http.Transport` whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:59-77`). That function resolves the target hostname via `net.DefaultResolver.LookupHost`, then checks each resolved IP with `isReservedIP` and rejects the dial if any address falls in a reserved/private range — enforced at actual dial time (post-DNS-resolution), which also blocks DNS-rebinding attempts to redirect a validated hostname to an internal address.
