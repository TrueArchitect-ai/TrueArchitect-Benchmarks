r05. **Premise correction:** There is no GraphQL schema anywhere in this codebase — a repo-wide search for "graphql" returns zero matches across all 1042 files. This is not a GraphQL API.

**Actual API surface:** The public API is a **Protobuf-defined gRPC/Connect service**, exposed over REST via grpc-gateway and Connect-RPC:

- **Schema source of truth:** the `.proto` service definitions (compiled into `proto/gen/api/v1/*.pb.go` and the Connect bindings in `proto/gen/api/v1/apiv1connect/*.connect.go`) — e.g. `MemoService`, `UserService`, `AttachmentService`, `IdentityProviderService`, `InstanceService`, `ShortcutService`, `AuthService`, `AIService`.
- **REST route table** is generated grpc-gateway code, e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745` (memo endpoints like `GET /api/v1/{name=memos/*}`, `POST /api/v1/memos`), `proto/gen/api/v1/user_service.pb.gw.go:2301` (user endpoints), `proto/gen/api/v1/attachment_service.pb.gw.go:571`, `proto/gen/api/v1/idp_service.pb.gw.go:493`, `proto/gen/api/v1/instance_service.pb.gw.go:525`, `proto/gen/api/v1/shortcut_service.pb.gw.go:525`, `proto/gen/api/v1/auth_service.pb.gw.go:331`, `proto/gen/api/v1/ai_service.pb.gw.go:151`.
- **Handler implementations** live in `server/router/api/v1/*.go` (e.g. `memo_service.go`, `user_service.go`, `attachment_service.go`).
- A few auxiliary non-proto HTTP endpoints exist alongside it: SSE (`server/router/api/v1/sse_handler.go:25`), file/avatar serving (`server/router/fileserver/fileserver.go:132,168`), RSS feeds (`server/router/rss/rss.go:72,111`), frontend static files (`server/router/frontend/frontend.go:128,143`), and a health check (`server/server.go:44`).

So the "schema" for this API is the Protobuf `.proto` definitions (compiled to the `proto/gen/api/v1/` Go packages), not a GraphQL SDL file.
