Premise correction: there is no GraphQL schema anywhere in this repository — a full-text search for "graphql" returns zero matches across all 1042 files.

Actual API surface: the public API is defined as Protocol Buffers services under `proto/api/v1/` (per `proto/README.md`, `proto/buf.yaml`, `proto/buf.gen.yaml`), compiled via `buf` into generated Go code in `proto/gen/api/v1/` (e.g. `memo_service.pb.go`, `user_service.pb.go`, `attachment_service.pb.go`, etc.). These are served two ways:
- As gRPC/Connect RPCs via the `apiv1connect` handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`), wired up in `server/router/api/v1/connect_services.go`.
- As a REST/JSON surface through a generated gRPC-Gateway (`*.pb.gw.go` files, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`), with an accompanying OpenAPI description embedded via `proto/openapi_embed.go`.

So the schema-equivalent artifact for this API is the `.proto` service/message definitions in `proto/api/v1/`, not a GraphQL schema.
