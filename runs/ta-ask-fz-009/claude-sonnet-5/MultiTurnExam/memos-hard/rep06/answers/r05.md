**Premise correction:** There is no GraphQL schema or GraphQL API in this codebase — no `.graphql`/`.gql` files, no `graphql` imports, and a repo-wide grep for "graphql" across all Go files returns zero matches.

**Actual API surface:** The public API is defined via Protocol Buffers and served through gRPC-Gateway + Connect-RPC, not GraphQL. The `.proto` service definitions live under `proto/api/v1/` (generated Go code in `proto/gen/api/v1/`), covering services like `MemoService`, `UserService`, `AttachmentService`, `InstanceService`, `IdentityProviderService`, `ShortcutService`, and `AuthService`. These are exposed as a REST-style JSON API under `/api/v1/...` (e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{memo.name=memos/*}`, etc. — generated gateway routes in `proto/gen/api/v1/memo_service.pb.gw.go:1745` and siblings), plus a Connect-RPC transport for the same services, registered in `server/router/api/v1/v1.go`. There's also a handful of non-proto HTTP endpoints for file/asset serving (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go:25`), and a health check (`server/server.go:44`).
