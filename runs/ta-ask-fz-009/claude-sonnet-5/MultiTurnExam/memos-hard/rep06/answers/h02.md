**Delivery function:** `webhook.Post` in `internal/webhook/webhook.go:120-180` (invoked synchronously, or queued for background dispatch via `webhook.PostAsync` at `internal/webhook/webhook.go:184`, which is drained by 4 worker goroutines started in `init()` at `internal/webhook/webhook.go:42-55`). The actual outbound HTTP call happens at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`.

**Protection mechanism:** The shared `safeClient`'s `http.Transport` is wired to a custom `DialContext: safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59-77`) resolves the target hostname itself and rejects the dial if any resolved IP is reserved/private per `isReservedIP` (`internal/webhook/validate.go:43-`), which checks against a blocklist of loopback, RFC-1918 private, link-local/cloud-IMDS, and IPv6-equivalent CIDR ranges defined at `internal/webhook/validate.go:12-22`. Because the check happens at dial time against the resolved IP (not the pre-DNS hostname), it also defeats DNS-rebinding attacks — this guard can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`), used only in tests.
