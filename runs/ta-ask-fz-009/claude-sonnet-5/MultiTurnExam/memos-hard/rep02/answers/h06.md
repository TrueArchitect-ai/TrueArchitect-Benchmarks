**Handlers whose paths transitively cause an outbound HTTP request to a user-configured URL:**

- `APIV1Service.UpdateMemo` (`server/router/api/v1/memo_service.go:401`) — via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook`

- `APIV1Service.CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:20`) — calls `DispatchMemoCommentCreatedWebhook`
- (also `SetMemoAttachments` and `SetMemoRelations` reach the same side-effect dispatcher and thus the same webhook path)

All of these funnel through `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), which every `DispatchMemo*Webhook` method calls to build/enqueue the payload.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120` (also reachable via the async wrapper `webhook.PostAsync`, `internal/webhook/webhook.go:184`, whose worker goroutines call `Post` at `internal/webhook/webhook.go:46`) — this is the single point where the actual outbound `safeClient.Do(req)` HTTP request against the user-configured webhook URL executes (`internal/webhook/webhook.go:152`).
