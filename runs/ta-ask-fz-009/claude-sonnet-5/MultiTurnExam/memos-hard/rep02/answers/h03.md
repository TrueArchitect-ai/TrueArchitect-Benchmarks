**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared identity-provider data contract (`IdentityProviderUserInfo`).

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol shipped, implementing generic OAuth2 (`IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, `UserInfo`). No other protocol implementation (e.g., SAML/OIDC-specific) exists under `internal/idp`.
