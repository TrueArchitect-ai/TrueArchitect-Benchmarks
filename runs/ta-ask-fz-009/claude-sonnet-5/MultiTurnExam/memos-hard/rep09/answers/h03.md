**Abstraction package** — `internal/idp` (`internal/idp/idp.go`), which defines the common `IdentityProviderUserInfo` result type shared across identity-provider implementations.

**Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements the OAuth2 protocol: `IdentityProvider` struct backed by an `*storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (authorization-code exchange, with PKCE support), and `UserInfo` (fetches and maps claims into `idp.IdentityProviderUserInfo`). This is currently the only concrete protocol implementation that ships — the `store`/`apiv1` `IdentityProvider_Type` enum only defines `OAUTH2` (`proto/gen/store/idp.pb.go:26`, `proto/gen/api/v1/idp_service.pb.go:29`), consistent with no other `internal/idp/<protocol>` package existing.
