**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88` — which calls `markdownService.ExtractAll(memo.Content)`, whose actual extraction logic lives in `(*service).ExtractAll` — `internal/markdown/markdown.go:356-422`. `RebuildMemoPayload` copies the extracted `Tags` and `Property` into `memo.Payload.Tags` / `memo.Payload.Property` (runner.go:85-86), which is then persisted to the `memo.payload` column.

**Triggers (operations that cause recomputation):**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108` (every new memo has its payload built from content on create)
- `APIV1Service.UpdateMemo`, specifically when the `content` field is part of the update mask — `server/router/api/v1/memo_service.go:447` (payload is rebuilt only when `content` changes, not on every update)
- Also `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) can bulk-rebuild payloads for all memos, but per h08 this runner is currently unwired/unused in production — it's not invoked from server startup or anywhere else, so it's not an active trigger today.

**Extracted properties** (via a single AST walk in `ExtractAll`, `internal/markdown/markdown.go:371-411`):
- `Tags` — all `#tag` occurrences (deduplicated, case-preserved), excluding tags inside links/images
- `Mentions` — all `@username` mentions (lowercased, deduplicated)
- `Property.Title` — text of the first block-level node if it's an H1 heading
- `Property.HasLink` — whether any link node is present
- `Property.HasCode` — whether any code block/fenced code block/code span is present
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether task-list checkboxes exist, and whether any are unchecked
