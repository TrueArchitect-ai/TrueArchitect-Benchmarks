r05. **Premise correction:** there is no GraphQL schema in this repository — a case-insensitive search for "graphql" across all 1042 scanned files returns zero matches, and a glob for `*.graphql` files finds none.

**Actual API surface:** the public API is defined via Protocol Buffers and exposed over gRPC / gRPC-Gateway / Connect (JSON-over-HTTP), not GraphQL. Service definitions live under `proto/` (e.g. `proto/gen/api/v1/memo_service.pb.go`, `attachment_service.pb.go`, `user_service.pb.go`, `idp_service.pb.go`, etc.), with generated gRPC server/client stubs (`*_grpc.pb.go`), Connect handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`), and gRPC-Gateway REST/JSON mappings (`*.pb.gw.go`, e.g. `attachment_service.pb.gw.go:571` for `GET /api/v1/{name=attachments/*}`). The actual RPC method implementations are wired up in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`), registered through `APIV1Service.RegisterGateway` in `server/router/api/v1/v1.go:65`.
