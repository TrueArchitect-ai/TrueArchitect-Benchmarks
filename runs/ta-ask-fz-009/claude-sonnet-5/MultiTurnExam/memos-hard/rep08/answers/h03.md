**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` type that concrete providers return.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — implements the OAuth2 identity provider integration (`oauth2.IdentityProvider` struct, `NewIdentityProvider`, `ExchangeToken`, `UserInfo`), built on `golang.org/x/oauth2`. This is the only concrete protocol implementation shipped under `internal/idp/`.
