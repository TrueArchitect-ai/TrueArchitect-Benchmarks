**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (invoked either directly or asynchronously via `PostAsync`/`asyncPostQueue`, `internal/webhook/webhook.go:184` and `39`). It marshals the payload, optionally HMAC-signs it, and executes the outbound POST through `safeClient.Do(req)` (`webhook.go:152`).

**Protection mechanism:** The `safeClient`'s custom `http.Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`, function at `webhook.go:59-77`) resolves the target hostname at dial time and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, checked against `reservedNetworks`/`reservedCIDRs` covering loopback, RFC-1918, and link-local/cloud-IMDS ranges, `validate.go:14-23`). This blocks both static private-IP targets and DNS-rebinding attempts (dial-time check, not just at validation time). A separate pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), performs the same reserved-IP check when a webhook URL is first saved. Both checks can be disabled via the `AllowPrivateIPs` flag (`validate.go:41`), settable through the `--allow-private-webhooks` CLI flag wired in `cmd/memos/main.go:49,133`.
