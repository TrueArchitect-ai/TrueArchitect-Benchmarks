**Premise correction:** there is no GraphQL schema in this codebase — a repo-wide search for "graphql" (case-insensitive, 1042 files) returned zero matches. The public API is not GraphQL.

**Actual API surface:** it's a Protobuf-defined gRPC API (Connect/gRPC-Gateway), exposed as REST-style JSON over HTTP. The schema lives as `.proto`-generated definitions under `proto/gen/api/v1/` (e.g. `attachment_service.pb.go`, `memo_service.pb.go`, `user_service.pb.go`, `auth_service.pb.go`, `idp_service.pb.go`, `instance_service.pb.go`, `shortcut_service.pb.go`), with the HTTP route mappings declared in the corresponding `*.pb.gw.go` gateway files (e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`). These are wired into the Echo HTTP server via `APIV1Service.RegisterGateway` in `server/router/api/v1/v1.go:65-97`. Additional non-gRPC surfaces (file serving, RSS, frontend static routes, SSE, health check) are registered separately, as listed in the `[ArchMap query]` results (e.g. `server/router/fileserver/fileserver.go:132,168`, `server/router/rss/rss.go:72,111`, `server/router/frontend/frontend.go:128,143`, `server/server.go:44`).
