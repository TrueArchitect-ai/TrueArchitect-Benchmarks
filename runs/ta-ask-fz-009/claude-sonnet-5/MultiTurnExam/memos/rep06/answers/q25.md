q25. Engine: a CEL (Common Expression Language, via `github.com/google/cel-go`) based filter engine, living in internal/filter/ (parser.go, engine.go, ir.go, render.go, schema.go).

Mechanism in one sentence: `internal/filter/parser.go` parses the CEL filter string from `ListMemosRequest.filter` into an intermediate `Condition` AST (internal/filter/ir.go), and `internal/filter/render.go`'s `renderer` (dialect-aware, keyed by `DialectName` in schema.go: sqlite/mysql/postgres) walks that AST to emit dialect-specific SQL fragments and bound args — e.g. using SQLite's `strftime`/`JSON_EXTRACT`-style expressions vs. Postgres's `EXTRACT(... AT TIME ZONE 'UTC')`/`->>` JSON operators vs. MySQL's own functions (render.go:222-244, 928-976) — which get spliced into the `WHERE` clause of each driver's `ListMemos` query.
