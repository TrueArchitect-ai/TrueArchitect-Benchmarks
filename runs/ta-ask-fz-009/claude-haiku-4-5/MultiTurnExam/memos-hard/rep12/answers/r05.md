**Premise correction:** There is no GraphQL schema for the public API. The codebase does not use GraphQL.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** service definitions:

The API is composed of multiple proto files located in `proto/api/v1/`:
1. `auth_service.proto` — Authentication (SignIn, RefreshToken, etc.)
2. `user_service.proto` — User management operations
3. `memo_service.proto` — Memo CRUD and listing operations
4. `instance_service.proto` — Instance configuration and settings
5. `attachment_service.proto` — Attachment upload and management
6. `idp_service.proto` — Identity provider configuration
7. `ai_service.proto` — AI/transcription services
8. `shortcut_service.proto` — Shortcut management
9. `common.proto` — Shared types

These proto files define **gRPC services** with **HTTP JSON/REST bindings** (via `google.api.http` annotations) that expose the services both as:
- **gRPC-Gateway** endpoints at `/api/v1/*`
- **Connect** (gRPC for browsers) endpoints at `/memos.api.v1.*`

The services are implemented in `server/router/api/v1/` (e.g., `memo_service.go`, `user_service.go`, etc.) and registered via the `RegisterGateway()` method at `server/router/api/v1/v1.go:65`.
