**Actual API surface:**

The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL. The schema definitions are located in:

- **proto/api/v1/** directory with service definitions in `.proto` files:
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/auth_service.proto`
  - And others for user, memo, instance, idp, and shortcut services

The protobuf definitions are compiled to gRPC/Connect handlers and exposed via a gRPC-Gateway HTTP endpoint (as confirmed by the earlier API surface query showing routes like `POST /api/v1/memos`, `GET /api/v1/users/*`, etc.). There is no GraphQL API in this system.
