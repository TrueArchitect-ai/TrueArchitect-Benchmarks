**Premise correction:** There is **no GraphQL schema** in this repository. The public API is **not GraphQL-based**.

**Actual API surface:**

The API is defined using **Protocol Buffers (protobuf)** with the following structure:

- **Service definitions:** `proto/api/v1/*.proto` files, including:
  - `proto/api/v1/ai_service.proto` — AIService
  - `proto/api/v1/attachment_service.proto` — AttachmentService
  - `proto/api/v1/auth_service.proto` — AuthService
  - `proto/api/v1/idp_service.proto` — IdentityProviderService
  - `proto/api/v1/instance_service.proto` — InstanceService
  - `proto/api/v1/memo_service.proto` — MemoService
  - `proto/api/v1/shortcut_service.proto` — ShortcutService
  - `proto/api/v1/user_service.proto` — UserService

- **Transport layers:**
  - **Connect RPC** (HTTP/2) — code-generated in `proto/gen/api/v1/apiv1connect/`
  - **gRPC-Gateway** (JSON-REST over HTTP/1.1) — generated routes in `proto/gen/api/v1/*.pb.gw.go`

- **Generated HTTP endpoints:** 81 total REST endpoints via gRPC-Gateway serving `/api/v1/*` paths (POST, GET, PATCH, DELETE verbs for CRUD operations on memos, users, attachments, webhooks, etc.)

The API is served through `server/router/api/v1/` with Connect and gRPC-Gateway handlers, NOT through GraphQL.
