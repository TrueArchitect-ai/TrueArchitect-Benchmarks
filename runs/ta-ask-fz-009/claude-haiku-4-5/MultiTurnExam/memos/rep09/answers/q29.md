Frontend API requests are authenticated through:

1. **Interceptor location**: `web/src/connect.ts` (lines 156-178) — the `authInterceptor` is a Connect interceptor that handles token attachment and refresh logic

2. **Token kinds managed**: 
   - **JWT access tokens** (short-lived, 15 minutes) — stored in localStorage and attached as `Authorization: Bearer` headers
   - **Personal Access Tokens (PAT)** (long-lived) — for programmatic access

3. **Backend validation package**: `server/auth` — the `Authenticator` package (at `server/auth/authenticator.go`) validates both token types:
   - `AuthenticateByAccessTokenV2()` for JWT access tokens (stateless validation using the server secret)
   - `AuthenticateByPAT()` for Personal Access Tokens (database lookup)

The frontend interceptor also handles token refresh via `refreshToken()` when a 401 response is received, and uses preflight refresh to avoid sending expired tokens to public endpoints.
