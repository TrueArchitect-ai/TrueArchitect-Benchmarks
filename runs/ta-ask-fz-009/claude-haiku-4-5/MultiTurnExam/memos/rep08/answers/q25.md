The flow is:
1. **Engine**: **CEL (Common Expression Language)** defined in `internal/filter/engine.go` (which uses `github.com/google/cel-go/cel`)
2. **Parsing**: The filter string is compiled into a CEL AST (Abstract Syntax Tree), then converted to a condition tree (lines 48-65 in engine.go)
3. **SQL Conversion**: For each dialect, the condition tree is rendered to SQL using `filter.AppendConditions()` (called from store/db/mysql/memo.go:69, and similarly in postgres and sqlite drivers), which generates dialect-specific SQL WHERE clauses
