Go embed package with Echo's static middleware; server/router/frontend/frontend.go

The compiled React frontend is served using Go's `embed` directive (`//go:embed dist/*` at line 20) which embeds the compiled `dist/` directory at build time, combined with Echo's `StaticWithConfig` middleware (line 54) that serves these files with appropriate cache control headers. The mechanism includes an SPA fallback middleware (lines 63-80) that serves `index.html` for client-side routes that don't match static assets, all wired in `server/router/frontend/frontend.go`.
