Frontend API requests are authenticated through the `authInterceptor` defined in `web/src/connect.ts` (line 156), which manages two token kinds:
1. **Access tokens** - Short-lived JWT tokens (15 minutes) sent in the `Authorization: Bearer` header for API requests
2. **Refresh tokens** - Long-lived JWT tokens (30 days) stored in HttpOnly cookies for obtaining new access tokens

The backend validation is performed by the `server/auth` package (specifically `server/auth/authenticator.go`), which provides:
- `AuthenticateByAccessTokenV2()` - Validates short-lived access tokens (stateless)
- `AuthenticateByRefreshToken()` - Validates refresh tokens against the database (revocation check)
- Support for Personal Access Tokens (PAT) for programmatic access
