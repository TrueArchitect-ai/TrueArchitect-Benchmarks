- **Frontend auth interceptor**: Defined in `web/src/connect.ts` (lines 156-178) as `authInterceptor`, which is a ConnectRPC `Interceptor` that:

- **Token kinds managed in frontend**:
  - **Access Token**: JWT-based, short-lived (15 minutes), stored in localStorage (`memos_access_token`)
  - **Refresh Token**: Cookie-based, long-lived, managed server-side
  
- **Backend auth validation package**: `server/auth/` package (files: `authenticator.go`, `token.go`) which provides:
  - `AuthenticateByAccessTokenV2()` - validates JWT access tokens (stateless)
  - `AuthenticateByRefreshToken()` - validates refresh tokens against database (revocation check)
  - `AuthenticateByPAT()` - validates Personal Access Tokens for programmatic access
  - `resolveBearer()` - dispatcher that validates Bearer tokens from Authorization header
