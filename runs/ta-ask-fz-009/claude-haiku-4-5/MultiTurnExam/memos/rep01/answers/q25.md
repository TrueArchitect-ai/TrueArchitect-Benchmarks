CEL (Common Expression Language) — internal/filter/engine.go; The Engine parses CEL expressions into a dialect-agnostic intermediate representation (IR), which is then rendered into SQL fragments by a renderer that generates dialect-specific SQL for SQLite, MySQL, or PostgreSQL with appropriate placeholder syntax and operators.

**Citation:**
- **Engine syntax/parser**: CEL (Common Expression Language) using the `cel-go` library, implemented in `internal/filter/engine.go` (lines 13-34)
- **Package location**: `internal/filter/` package containing:
  - `engine.go` - parses CEL expressions
  - `parser.go` - converts AST to intermediate representation (IR)
  - `render.go` - converts IR to dialect-specific SQL
  
- **Mechanism**: Three-phase pipeline (from `internal/filter/README.md`):
  1. **Parsing** (`engine.go`): CEL expressions parsed with `cel-go`
  2. **Normalization** (`parser.go`): Raw CEL AST converted to dialect-agnostic IR defined in `ir.go`
  3. **Rendering** (`render.go`): IR walked and converted to SQL fragments tailored to target dialect (SQLite, MySQL, PostgreSQL) via `filter.AppendConditions()` called from each dialect's implementation (e.g., `store/db/sqlite/memo.go:61`)
