— GraphQL public API schema definition:
- **Premise correction**: No GraphQL API exists. The public API is gRPC with HTTP/REST transcoding via gRPC-Gateway. The API surface is defined in `proto/api/v1/*.proto` files (message and service definitions), compiled to `proto/gen/api/v1/*` Go code, and registered in `server/router/api/v1/connect_services.go`. OpenAPI/Swagger documentation is generated from the proto definitions, not GraphQL.
