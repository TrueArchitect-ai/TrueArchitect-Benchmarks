Redis cache configuration and TTL
**Correction**: This codebase does **not** use Redis. The cache layer is implemented as an **in-memory cache** (store/cache/cache.go) with configurable TTL and cleanup intervals. There is no Redis configuration.

**Actual mechanism**: 
- Cache: **store/cache/Cache** struct (store/cache/cache.go:67)
- Default TTL: **10 minutes** (store/cache/cache.go:59)
- Cleanup interval: **5 minutes** (store/cache/cache.go:60)
- Caches are: instanceSettingCache, userCache, userSettingCache
