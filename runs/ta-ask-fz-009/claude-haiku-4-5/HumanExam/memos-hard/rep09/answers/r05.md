GraphQL schema definition
**Correction**: This codebase does **not** use GraphQL. The public API is defined via **gRPC with REST Gateway** using Protocol Buffers.

**Actual API surface**: 
- **gRPC service definitions**: proto/api/v1/*.proto (e.g., memo_service.proto, user_service.proto)
- **Generated gateway routes**: server/router/api/v1/ (with gRPC-Gateway JSON REST translation)
- **OpenAPI/Swagger schema**: Generated at proto/gen/openapi.yaml (from buf generate)
