Webhook outbound delivery
The **Post** function in **internal/webhook/webhook.go:120** executes the actual outbound delivery via HTTP POST. 

Protection against SSRF/internal network addresses is enforced by **safeDialContext** (internal/webhook/webhook.go:59) which:
1. Resolves the hostname
2. Checks each resolved IP against `isReservedIP()` 
3. Rejects any reserved/private IP ranges before allowing the connection
