**Premise correction:** This codebase does not use GraphQL for its public API. The API is defined in **Protocol Buffers (protobuf)**, not GraphQL.

**Actual API surface:** The public API is defined in protobuf service definitions located in `proto/api/v1/` directory:

- **Core service definitions (**.proto files):
  - `proto/api/v1/ai_service.proto` — AI/transcription operations
  - `proto/api/v1/attachment_service.proto` — File attachment operations
  - `proto/api/v1/auth_service.proto` — Authentication endpoints
  - `proto/api/v1/idp_service.proto` — Identity provider configuration
  - `proto/api/v1/instance_service.proto` — Instance settings and stats
  - `proto/api/v1/memo_service.proto` — Memo CRUD, comments, reactions, shares
  - `proto/api/v1/shortcut_service.proto` — User shortcuts
  - `proto/api/v1/user_service.proto` — User management
  - `proto/api/v1/common.proto` — Shared types

The protobuf definitions are compiled to gRPC and REST endpoints via gRPC-Gateway (endpoints visible in generated `proto/gen/api/v1/*_service.pb.gw.go` files). The REST routes follow `/api/v1/` pattern with resource names as paths.
