**Premise correction:** This repository uses Protocol Buffers (protobuf), not GraphQL, for its public API schema definition.

**Actual API surface:** The public API is defined through Protocol Buffer service definitions. The compiled API endpoint patterns are generated in:

- `proto/gen/api/v1/` directory — containing generated `.pb.gw.go` gateway files for all services:
  - `ai_service.pb.gw.go` (AI transcription)
  - `attachment_service.pb.gw.go` (Attachment management)
  - `auth_service.pb.gw.go` (Authentication)
  - `idp_service.pb.gw.go` (Identity Provider)
  - `instance_service.pb.gw.go` (Instance settings)
  - `memo_service.pb.gw.go` (Memo CRUD and interactions)
  - `user_service.pb.gw.go` (User management)
  - `shortcut_service.pb.gw.go` (User shortcuts)

The primary API endpoints follow REST conventions (e.g., `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, `PATCH /api/v1/{memo.name=memos/*}`). The underlying `.proto` files (the canonical schema definitions) are in the `proto/` directory, but the compiled protobuf gateway definitions in `proto/gen/api/v1/` are the contract-enforcing layer for the public REST API.
