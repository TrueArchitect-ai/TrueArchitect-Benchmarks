**PREMISE CORRECTION:**

There is no GraphQL schema. This project uses **Protocol Buffers (protobuf)**, not GraphQL.

**ACTUAL API SURFACE:**

The public API is defined in **protocol buffer service definitions** located in `proto/api/v1/`. The main service definitions are:

- `proto/api/v1/ai_service.proto` — AI transcription service
- `proto/api/v1/attachment_service.proto` — Attachment management
- `proto/api/v1/auth_service.proto` — Authentication (sign in/out, token refresh)
- `proto/api/v1/memo_service.proto` — Memo CRUD and relations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/instance_service.proto` — Instance settings and stats
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — User shortcuts

These `.proto` files are compiled to gRPC-Gateway routes that expose REST/HTTP endpoints at `api/v1/`. The generated route handlers are located in `proto/gen/api/v1/*.pb.gw.go` (e.g., `proto/gen/api/v1/memo_service.pb.gw.go`, `proto/gen/api/v1/user_service.pb.gw.go`).

The API follows [Google API Improvement Proposals (AIPs)](https://google.aip.dev/) design guidelines, as documented in `proto/api/v1/README.md`.
