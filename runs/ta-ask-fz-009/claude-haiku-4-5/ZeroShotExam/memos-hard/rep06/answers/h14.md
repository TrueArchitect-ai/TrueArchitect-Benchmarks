**Computation site:** `server/runner/memopayload/runner.go:74-88`, function `RebuildMemoPayload()`. The actual metadata extraction occurs in `internal/markdown/markdown.go:356-410`, method `ExtractAll()` which parses markdown using goldmark and walks the AST in a single pass.

**Triggers:** Recomputation occurs in three scenarios:
1. **Memo creation**: `server/router/api/v1/memo_service.go:108` — called immediately after `CreateMemo` request validation, before storage
2. **Memo content update**: `server/router/api/v1/memo_service.go:447` — called when the `content` path is patched in `UpdateMemo`, only if content actually changes
3. **Batch background rebuild**: `server/runner/memopayload/runner.go:52` — `RunOnce()` iterates all memos in batches of 100 and rebuilds their payloads (used for migrations or maintenance)

**Extracted properties:** The payload (`storepb.MemoPayload`) extracts and stores:
- **Tags**: Deduplicated `#tag` tokens from markdown (case-preserved), collected via custom tag extension
- **Mentions**: Deduplicated `@username` tokens (lowercased for canonical matching), collected via custom mention extension  
- **Property** (nested struct):
  - `HasLink` — boolean, set if any markdown link exists
  - `HasCode` — boolean, set if any code block or inline code exists
  - `HasTaskList` — boolean, set if markdown task list checkboxes exist
  - `HasIncompleteTasks` — boolean, set if any task is unchecked
  - `Title` — string, extracted from first H1 heading if present (empty otherwise)
- **Location** — optional user-provided location data (computed separately, not extracted from content)

The payload is persisted in the store as a protobuf JSON blob and drives list/preview UI — users do not set these fields directly.
