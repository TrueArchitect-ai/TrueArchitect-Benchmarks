**Premise Correction**: This repository does not use GraphQL. It uses **Protocol Buffers (protobuf)** for the public API.

**Actual API Surface**: The public API schema is defined in the `proto/api/v1/` directory:
- **`proto/api/v1/ai_service.proto`** — AI transcription service
- **`proto/api/v1/attachment_service.proto`** — Attachment management
- **`proto/api/v1/auth_service.proto`** — Authentication (signin, signout, refresh, current user)
- **`proto/api/v1/common.proto`** — Shared data types
- **`proto/api/v1/idp_service.proto`** — Identity provider management
- **`proto/api/v1/instance_service.proto`** — Instance settings and configuration
- **`proto/api/v1/memo_service.proto`** — Memo CRUD, sharing, comments, reactions, relations
- **`proto/api/v1/shortcut_service.proto`** — User shortcut management
- **`proto/api/v1/user_service.proto`** — User management, linked identities, webhooks, tokens

These proto files are compiled to gRPC service definitions and exposed as REST endpoints via gRPC-Gateway (evidenced by the generated `.pb.gw.go` files). The API surface includes 81 REST endpoints following the `/api/v1/` pattern, as shown by the `[ArchMap query]` results above.
