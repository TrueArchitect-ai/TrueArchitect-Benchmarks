**Premise correction:** This project uses **gRPC + protobuf, not GraphQL**. There is no GraphQL schema in this repository.

**Actual API surface:** The public API is defined in **protobuf (`.proto`) files** located at:

- **Primary API definitions:** `proto/api/v1/` directory
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/common.proto`

These `.proto` files define gRPC services that are compiled via `buf` (configured in `proto/buf.yaml` and `proto/buf.gen.yaml`) into Go code in `proto/gen/api/v1/` with HTTP gateway bindings (`.pb.gw.go` files) that expose the services as a **REST API** at `/api/v1/`.

Additionally, an **OpenAPI specification** is generated at `proto/gen/openapi.yaml` for documentation of the HTTP surface.
