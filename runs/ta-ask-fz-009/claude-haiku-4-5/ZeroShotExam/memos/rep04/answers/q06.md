**memo_relation**

This table stores links between one memo and another related memo. It contains three columns:
- `memo_id`: the ID of the source memo
- `related_memo_id`: the ID of the related memo  
- `type`: the type of relationship between the memos

The table is defined with a UNIQUE constraint on the combination of these three columns.
