**Mechanism:** Server-Sent Events (SSE) via HTTP text/event-stream protocol with Bearer token authentication. The server broadcasts JSON-serialized events through an in-memory hub with per-client buffered channels (32-event capacity) and heartbeat pings every 30 seconds.

**Hub path:** `server/router/api/v1/sse_hub.go` (type `SSEHub`, methods `Subscribe()`, `Broadcast()`, `Unsubscribe()`, `Close()`)

**Handler names (memo service methods that broadcast through the hub):**

All broadcasts are filtered server-side by visibility (Private events visible only to creator/admin) before being sent to subscribers. The endpoint is at `/api/v1/sse`.
