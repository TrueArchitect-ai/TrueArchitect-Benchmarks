**Engine + Path:** CEL (Common Expression Language) parsed by `cel-go`; lives in `internal/filter/engine.go`.

**Mechanism:** The filter expression is validated at the API layer (`server/router/api/v1/shortcut_service.go:validateFilter`), then compiled via `filter.DefaultEngine().CompileToStatement()` which parses the CEL string into a dialect-agnostic IR tree (parser.go), then renders that tree to SQL with dialect-specific syntax (`render.go`) for each of MySQL, Postgres, and SQLite, with placeholder arguments tracked per dialect.
