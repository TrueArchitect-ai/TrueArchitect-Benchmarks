When a memo is created, user webhooks are notified through the following chain:

1. **Dispatch function**: `v1.APIV1Service.dispatchMemoRelatedWebhook` — called from the handler `v1.APIV1Service.DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go:15`

3. **Request-signing mechanism**: HMAC-SHA256 using the Standard Webhooks signature format (`whsec_<base64>` secrets). The signing process (in `internal/webhook/webhook.go:133–150`) creates:
   - A message ID header (`webhook-id`)
   - A timestamp header (`webhook-timestamp`) 
   - A signature header (`webhook-signature`) computed as HMAC-SHA256 over the message ID, timestamp, and body

The actual HTTP dispatch is performed by `webhook.Post()` (called from `webhook.PostAsync()` on async workers), which uses an SSRF-protected HTTP client and signs the request with HMAC-SHA256 if a `SigningSecret` is provided on the payload.
