**Details**:

The server uses **Server-Sent Events (SSE)** to push live events to browsers via the `/api/v1/sse` endpoint (server/router/api/v1/sse_handler.go:25). Clients subscribe with authentication and maintain a persistent HTTP connection.

The **SSEHub** (server/router/api/v1/sse_hub.go:56) manages client connections and broadcasts events. It uses a map to track connected clients, with each client receiving events through a buffered channel (32-event buffer). The `Broadcast` method sends events to all connected clients with visibility-based filtering (Private events only go to the creator or admins; Public/Protected events go to all).

The **six memo handlers** that broadcast events are:
- **CreateMemo** (server/router/api/v1/memo_service.go:70) — broadcasts `SSEEventMemoCreated`
- **CreateMemoComment** (server/router/api/v1/memo_service_comments.go:20) — broadcasts `SSEEventMemoCommentCreated`
- **UpdateMemo** (server/router/api/v1/memo_service.go:401) — broadcasts `SSEEventMemoUpdated` via `dispatchMemoUpdatedSideEffects`
- **DeleteMemo** (server/router/api/v1/memo_service.go:518) — broadcasts `SSEEventMemoDeleted`
- **UpsertMemoReaction** (server/router/api/v1/reaction_service.go:60) — broadcasts `SSEEventReactionUpserted`
- **DeleteMemoReaction** (server/router/api/v1/reaction_service.go:111) — broadcasts `SSEEventReactionDeleted`
