q25. **CEL (Common Expression Language) via `cel-go`** at `internal/filter/engine.go`; the filter expression is parsed into a dialect-agnostic intermediate representation (IR), then `render.go` walks the IR and emits SQL tailored to the target dialect (SQLite, MySQL, or Postgres) with dialect-specific handling for JSON extraction, placeholders (`?` for SQLite/MySQL, `$n` for Postgres), and operators.

**Path:** `internal/filter/` (engine.go, render.go, parser.go)  
**Mechanism:** `Engine.CompileToStatement()` parses CEL via cel-go, converts to dialect-agnostic IR, then `Render()` produces dialect-specific SQL fragments that are appended to the WHERE clause via `filter.AppendConditions()` (helpers.go:9) called from each database driver (mysql/memo.go:69, postgres/memo.go, sqlite/memo.go).
