**Mechanism:** Go's `embed` package (static file embedding at compile time)

**Path:** `server/router/frontend/frontend.go`

The compiled React frontend is served using Go's `embed` directive. At line 20 of `server/router/frontend/frontend.go`, the line `//go:embed dist/*` embeds all files from the `server/router/frontend/dist` directory (containing the compiled React build) directly into the binary at compile time.

During the build process, the frontend React build (`pnpm release` in `web/package.json`) outputs compiled assets to `server/router/frontend/dist`, which are then embedded into the Go binary via the `embed.FS` variable `embeddedFiles` (line 21). These embedded files are served by the `FrontendService.Serve()` method (line 41-61), which registers Echo middleware to serve static assets and provides SPA fallback routing (sending non-file requests to `index.html`).
