**Dispatcher function and file:** `DispatchMemoCreatedWebhook` called from `server/router/api/v1/memo_service.go:157` (within the `CreateMemo` handler)

**Delivery package:** `github.com/usememos/memos/internal/webhook` — specifically the `PostAsync()` function which asynchronously enqueues webhook payloads for HTTP delivery

**Request-signing mechanism:** HMAC-SHA256 using the Standard Webhooks specification:
- The signing secret (in `whsec_<base64>` format) is decoded to a raw 32-byte key
- An HMAC-SHA256 signature is computed over the message string `msgID.timestamp.` concatenated with the JSON body
- Three headers are set on the outgoing request:
  - `webhook-id`: `msg_<UUID>`
  - `webhook-timestamp`: Unix timestamp
  - `webhook-signature`: `v1,<base64-encoded signature>`
