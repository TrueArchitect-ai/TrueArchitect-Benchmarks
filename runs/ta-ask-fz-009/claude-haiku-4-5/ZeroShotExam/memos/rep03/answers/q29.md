**Interceptor path:** `web/src/connect.ts` (lines 156-178, function `authInterceptor`)

**Token kinds managed:** 
1. **Access Token V2** (short-lived JWT, ~15 minutes) — managed by `authInterceptor` which calls `getRequestToken()` 
2. **Refresh Token** (long-lived, stored in HTTP-only cookie) — used for token refresh via `refreshAccessToken()` / `doRefreshAccessToken()`
3. **Personal Access Token (PAT)** (long-lived for programmatic access) — mentioned in backend but not used by the frontend interceptor

**Backend validation package:** `server/auth` (path: `server/auth/authenticator.go`)

The backend package exports `Authenticator` which:
- Validates Access Token V2 via `AuthenticateByAccessTokenV2()` 
- Validates Refresh Tokens via `AuthenticateByRefreshToken()`
- Validates PATs via `AuthenticateByPAT()`
