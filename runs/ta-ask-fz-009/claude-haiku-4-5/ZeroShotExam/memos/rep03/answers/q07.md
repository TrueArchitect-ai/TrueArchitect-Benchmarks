q07.

The ConnectRPC service clients are created in the frontend source file **`web/src/connect.ts`**.

This file imports `createClient` from `@connectrpc/connect` and uses it to create multiple service clients including:
- `instanceServiceClient`
- `authServiceClient`
- `userServiceClient`
- `memoServiceClient`
- `attachmentServiceClient`
- `aiServiceClient`
- `shortcutServiceClient`
- `identityProviderServiceClient`
