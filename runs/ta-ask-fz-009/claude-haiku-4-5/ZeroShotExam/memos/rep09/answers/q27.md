**Mechanism:** Go `embed` filesystem (embedded files at compile time) served via Echo middleware  
**Path:** `server/router/frontend/frontend.go`

The compiled React frontend is served using Go's `embed` package (line 20-21 in `frontend.go`):

```go
//go:embed dist/*
var embeddedFiles embed.FS
```

The embedding directive `//go:embed dist/*` at compile time includes all files from the `server/router/frontend/dist/` directory (which contains the compiled React build) into the binary.

The mechanism is then wired in `server/server.go` at line 72:

```go
frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)
```

This calls the `Serve()` method in `frontend.go` (lines 41-61), which:
1. Extracts the embedded filesystem via `getFileSystem("dist")`
2. Registers Echo's `StaticWithConfig` middleware (line 54-57) to serve static assets with proper cache headers
3. Adds a SPA fallback middleware (line 59) that routes unmatched paths back to `index.html` for client-side routing

The compiled frontend is thus embedded directly into the Go binary and served as static files during production runtime.
