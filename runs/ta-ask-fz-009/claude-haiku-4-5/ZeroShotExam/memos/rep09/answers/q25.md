**Engine + Path:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

**Mechanism:** The filter parser (`internal/filter/parser.go`) converts CEL expressions into a dialect-agnostic intermediate representation (IR), which the renderer (`internal/filter/render.go`) translates into SQL fragments with parameterized arguments—one fragment per target dialect (SQLite, MySQL, Postgres). At the RPC handler level (`server/router/api/v1/memo_service.go:212`), `validateFilter()` calls `engine.CompileToStatement(ctx, filterStr, filter.RenderOptions{Dialect: dialect})` to validate and compile; the compiled statement is stored in `memoFind.Filters`, then at the driver layer (e.g., `store/db/mysql/memo.go:69`), `filter.AppendConditions()` applies `CompileToStatement` again to render the filter into the final WHERE clause using the database's dialect (MySQL uses `?` placeholders, Postgres uses `$n`, SQLite uses `?`).
