**Token Kinds Managed:**
1. **Access tokens** — short-lived JWT tokens (15-minute lifetime) stored in localStorage, sent via Bearer Authorization header; validated via signature only
2. **Refresh tokens** — long-lived JWT tokens (30-day lifetime) stored as HTTP-only cookies; used to obtain new access tokens
3. **Personal Access Tokens (PAT)** — long-lived tokens (prefix `memos_pat_`) for programmatic access

  - `server/auth/authenticator.go` — provides the `Authenticator` type that validates access tokens and refresh tokens
