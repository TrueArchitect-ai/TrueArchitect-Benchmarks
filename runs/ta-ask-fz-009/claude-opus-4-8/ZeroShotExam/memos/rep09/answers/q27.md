**Go `embed.FS` compile-time embedding, served over Echo's static-file middleware (with SPA fallback to `index.html`); `server/router/frontend/frontend.go`.**

How it wires together:

- The compiled React bundle in `dist/` is baked into the Go binary at build time via the `//go:embed dist/*` directive on `embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`).
- `FrontendService.Serve` mounts that embedded filesystem (via `fs.Sub(embeddedFiles, "dist")`) into Echo using `middleware.StaticWithConfig{Filesystem: frontendFS, ...}` (`frontend.go:41-57`), which serves the static assets.
- A `spaFallbackMiddleware` catches 404s on non-API, extension-less paths and returns `index.html` from the same FS, giving client-side routing (`frontend.go:63-80`, `77`).
- A skipper excludes `/api`, `/file`, and the gRPC/`memos.api.v1` paths so backend routes aren't shadowed by the static handler (`frontend.go:82-90`).

This is the memos project's frontend service.
