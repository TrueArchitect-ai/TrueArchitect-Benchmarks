**Engine + path:** A CEL (Google Common Expression Language, via `github.com/google/cel-go/cel`) filter engine, defined in `internal/filter/engine.go` (`Engine`, backed by a `cel.Env` built from a `Schema`). The default memo engine is `filter.DefaultEngine()` at `internal/filter/engine.go:110`.

**Mechanism (one sentence):** `Engine.Compile` uses `cel-go` to parse/type-check the CEL expression into an AST, `buildCondition` (`internal/filter/parser.go`) lowers that AST into a dialect-agnostic condition tree (`internal/filter/ir.go`), and `Program.Render` (`internal/filter/render.go`) walks the tree with a `RenderOptions.Dialect` (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`), `switch`ing on that dialect to emit dialect-specific SQL fragments with placeholders/args (e.g. render.go:230–238, 364–406) that the store layer's `ListMemos` (`store/db/{sqlite,postgres,mysql}/memo.go`) splices into its WHERE clause.
