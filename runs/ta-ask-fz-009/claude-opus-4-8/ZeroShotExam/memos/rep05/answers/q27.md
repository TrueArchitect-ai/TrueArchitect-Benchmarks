**Mechanism:** Go's `//go:embed dist/*` compiles the built React frontend into the binary as an `embed.FS`, and an Echo static-file middleware serves it (with a SPA fallback to `index.html`); `server/router/frontend/frontend.go`

The wiring:
- `//go:embed dist/*` embeds the compiled frontend at build time into `embeddedFiles` (`frontend.go:20–21`).
- `FrontendService.Serve` mounts it via `fs.Sub(embeddedFiles, "dist")` and registers `middleware.StaticWithConfig` to serve those assets over HTTP (`frontend.go:41–57`).
- `spaFallbackMiddleware` catches 404s on non-API paths and returns `index.html` so client-side routing works (`frontend.go:63–80`).
- API/file paths (`/api`, `/file`, `/memos.api.v1*`) are skipped so they don't get intercepted (`frontend.go:82–90`).

So there is no separate static web server — the compiled `dist/` bundle ships inside the Go binary and is served by the same Echo server that handles the API.
