**Mechanism:** The compiled React frontend is compiled into the Go binary via a `//go:embed dist/*` directive (`embed.FS`), then served over Echo's static-file middleware (`middleware.StaticWithConfig`), with a SPA fallback that returns `index.html` on any 404 for an HTML-shaped path.

**Path:** `server/router/frontend/frontend.go`

Details, all anchored in that file:
- `//go:embed dist/*` embeds the built assets into `embeddedFiles` (line 20–21) — the frontend build output lives in `dist/` next to this file.
- `FrontendService.Serve` wires it up: it wraps the embedded FS via `getFileSystem("dist")` (line 42) and installs `middleware.StaticWithConfig` to serve the static assets (lines 54–57).
- `spaFallbackMiddleware` (lines 63–80) serves `index.html` via `c.FileFS("index.html", frontendFS)` when a request 404s on an HTML route, so client-side routing works.

So there is no separate web server for the frontend in production — it ships inside the Go server binary and is served by the Echo router.
