`store/migration/sqlite/LATEST.sql`

This is the single file that defines the complete current schema for a fresh SQLite install. It contains the full set of `CREATE TABLE` statements (system_setting, user, user_setting, …) rather than incremental changes — the versioned files under `store/migration/sqlite/0.x/` are per-version migrations applied to upgrade existing databases, whereas `LATEST.sql` is the consolidated schema seeded on a new install.
