**Mechanism:** The compiled React bundle is embedded into the Go binary via a `//go:embed dist/*` directive and served through Echo's static-file middleware, with a SPA fallback that returns `index.html` for unmatched non-API routes.

**Path:** `server/router/frontend/frontend.go`

Details, all anchored in that file:
- Line 20–21: `//go:embed dist/*` compiles the built frontend (`dist/`) directly into the binary as `embeddedFiles embed.FS`.
- Line 42 / 115–121: `getFileSystem("dist")` sub-roots that embedded FS.
- Line 54–57: `middleware.StaticWithConfig(...)` serves the assets over that filesystem.
- Line 59, 63–80: `spaFallbackMiddleware` catches 404s on HTML-style routes and serves `index.html` from the embedded FS (`c.FileFS("index.html", frontendFS)`), giving the SPA client-side routing.

So no external web server or separate static host is involved in production — the frontend ships inside the Go server binary and is served by the Echo router wired in `FrontendService.Serve`.
