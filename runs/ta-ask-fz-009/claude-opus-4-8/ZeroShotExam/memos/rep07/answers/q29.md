**Token kinds:** Three, all managed around this interceptor:
- **Access token (JWT, short-lived)** — held in memory + persisted (`web/src/auth-state.ts`, key `memos_access_token`), attached as `Authorization: Bearer <token>` (`connect.ts:99`). Backend calls this "Access Token V2."

- **Personal Access Token (PAT)** — long-lived, also carried in the `Authorization: Bearer` header; distinct from JWTs, validated server-side alongside them.
