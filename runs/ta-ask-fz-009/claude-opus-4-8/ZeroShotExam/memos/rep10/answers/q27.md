**Go `embed.FS` — the compiled frontend is baked into the server binary at build time and served over Echo's static middleware; `server/router/frontend/frontend.go`**

The mechanism, as wired in that file:

- **`//go:embed dist/*`** (line 20) embeds the compiled React build output (the `dist/` directory) into the binary as `embeddedFiles embed.FS` (line 21) — no separate web server or filesystem is needed in production.
- **`FrontendService.Serve`** (line 41) mounts it: it wraps the embedded FS via `getFileSystem("dist")` and registers Echo's `middleware.StaticWithConfig` (lines 54–57) to serve the static assets.
- **SPA fallback** (`spaFallbackMiddleware`, lines 63–80) catches 404s on non-asset paths and returns `index.html` from the embedded FS (`c.FileFS("index.html", frontendFS)`, line 77), so client-side routes resolve.

Cache headers differentiate HTML (`no-cache`), plain static assets (`max-age=3600`), and hashed assets under `/assets/` (`immutable`) — lines 24–26, 92–105.
