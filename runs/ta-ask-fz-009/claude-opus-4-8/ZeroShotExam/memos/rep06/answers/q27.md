**Mechanism:** Go `embed.FS` — the compiled frontend is baked into the server binary via a `//go:embed dist/*` directive and served over HTTP by Echo's `middleware.StaticWithConfig` static file handler, with an SPA fallback that returns `index.html` on 404 for non-asset paths.

**Path:** `server/router/frontend/frontend.go`

Key wiring in that file:
- `//go:embed dist/*` → `var embeddedFiles embed.FS` (line 20–21) embeds the built React output at compile time.
- `FrontendService.Serve` (line 41) mounts the embedded `dist` filesystem via `e.Use(middleware.StaticWithConfig(...))` (line 54–57).
- `spaFallbackMiddleware` (line 63) serves `index.html` for client-side routes that 404, making it a single-page-app fallback (line 77).

So in production there is no separate web server for the frontend — the compiled assets ship inside the Go binary and Echo serves them directly.
