**Go `//go:embed` — the compiled frontend is embedded into the server binary and served over Echo's static-file middleware; `server/router/frontend/frontend.go`.**

How it's wired:

- **Embedding** — `//go:embed dist/*` compiles the built React bundle (`dist/`) into the Go binary as `embeddedFiles embed.FS` (`frontend.go:20-21`). This is what makes it "production" serving: no separate web server, the assets ship inside the binary.
- **Serving** — `FrontendService.Serve` (`frontend.go:41`) subroots the embed FS to `dist` via `fs.Sub` (`getFileSystem`, line 115) and registers it as an Echo middleware: `middleware.StaticWithConfig(middleware.StaticConfig{Filesystem: frontendFS, ...})` (lines 54-57).
- **SPA fallback** — `spaFallbackMiddleware` (line 63) catches 404s on extension-less paths and serves `index.html` from the same FS (line 77), so client-side routes resolve.

The static middleware skips `/api`, `/file`, and the gRPC paths (`shouldSkipFrontendStatic`, line 82) so it doesn't shadow the backend.
