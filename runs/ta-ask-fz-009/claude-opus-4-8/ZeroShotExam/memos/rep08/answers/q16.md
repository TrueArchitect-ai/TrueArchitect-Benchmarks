Before deleting the memo row itself, `store.Store.DeleteMemo` (store/memo.go:140–159) deletes:

- **`memo_relation` records** — where this memo is the source (`MemoID`), via `DeleteMemoRelation` (store/memo.go:142)
- **`memo_relation` records** — where this memo is the target (`RelatedMemoID`), via a second `DeleteMemoRelation` (store/memo.go:145)
- **Attachments linked to the memo** — each row returned by `ListAttachments(MemoID)` is removed via `DeleteAttachment` (store/memo.go:149–157)

Only after these does it call `s.driver.DeleteMemo` to remove the `memo` row (store/memo.go:158), which issues the `DELETE FROM memo` statement (e.g. store/db/sqlite/memo.go:237–248).
