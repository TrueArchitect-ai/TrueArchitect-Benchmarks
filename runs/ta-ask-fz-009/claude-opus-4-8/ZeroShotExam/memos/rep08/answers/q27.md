**Go `//go:embed` of the compiled `dist/` bundle, served over Echo's static-file middleware with an SPA fallback; server/router/frontend/frontend.go**

The compiled React output is baked into the Go binary at build time via the directive `//go:embed dist/*` into an `embed.FS` (`frontend.go:20-21`). At runtime, `FrontendService.Serve` (`frontend.go:41`) sub-roots that filesystem to `dist` (`getFileSystem`, line 42/115) and wires two things:

- `middleware.StaticWithConfig{Filesystem: frontendFS}` (line 54) serves the static assets, skipping `/api`, `/file`, and the Connect RPC prefixes (`shouldSkipFrontendStatic`, line 82).
- `spaFallbackMiddleware` (line 59/63) catches 404s on extensionless/HTML paths and returns `index.html` from the embedded FS (line 77), giving the single-page app its client-side routing fallback.

So in production there is no separate static file server or CDN — the frontend ships *inside* the Go binary and is served by the same Echo instance.
