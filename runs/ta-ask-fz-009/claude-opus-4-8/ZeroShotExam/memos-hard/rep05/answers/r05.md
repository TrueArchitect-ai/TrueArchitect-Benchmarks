**Premise correction:** This repository (memos) has no GraphQL API — there is no GraphQL schema. A content search across 1042 files for `graphql`/`gqlgen`/`schema.graphql` returned zero matches, and no `*.graphql` files exist. There is nothing GraphQL to point you to.

**Actual API surface:** The public API is defined as **gRPC services in Protocol Buffers**, exposed over HTTP via a grpc-gateway. The contracts live in `.proto` files; the HTTP surface is generated into `proto/gen/api/v1/*.pb.gw.go`. Every door is under `/api/v1/...`:

- **MemoService** — `proto/gen/api/v1/memo_service.pb.gw.go` — CRUD on memos plus comments, reactions, relations, shares, attachments, link metadata (`GET/POST/PATCH/DELETE /api/v1/memos...`).
- **UserService** — `proto/gen/api/v1/user_service.pb.gw.go` — users, settings, webhooks, personal access tokens, linked identities, notifications, stats.
- **AuthService** — `proto/gen/api/v1/auth_service.pb.gw.go` — `signin`, `signout`, `refresh`, `auth/me`.
- **AttachmentService** — `proto/gen/api/v1/attachment_service.pb.gw.go`.
- **InstanceService** — `proto/gen/api/v1/instance_service.pb.gw.go` — profile, stats, settings.
- **IdentityProviderService** — `proto/gen/api/v1/idp_service.pb.gw.go`.
- **ShortcutService** — `proto/gen/api/v1/shortcut_service.pb.gw.go`.
- **AIService** — `proto/gen/api/v1/ai_service.pb.gw.go` (`POST /api/v1/ai:transcribe`).

Alongside the generated gateway there are a few hand-written HTTP routes: SSE (`server/router/api/v1/sse_handler.go:25`), a file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), frontend `robots.txt`/`sitemap.xml` (`server/router/frontend/frontend.go`), and a `/healthz` check (`server/server.go:44`).

So the schema you're looking for is the **protobuf service definitions** (the `proto/` tree), not GraphQL.
