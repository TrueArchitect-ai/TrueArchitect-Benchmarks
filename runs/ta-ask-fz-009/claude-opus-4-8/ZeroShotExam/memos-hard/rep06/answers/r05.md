**Premise correction:** This repository (`github.com/usememos/memos`) has no GraphQL schema. There is no `.graphql`/`.graphqls` schema file, no GraphQL server, and no resolver layer. The public API is not GraphQL.

**Actual API surface:** The public API is a **gRPC service surface with a REST/HTTP transcoding gateway**, defined in Protocol Buffers.

- **Schema/contract definition:** the `.proto` files under `proto/api/v1/` are the source of truth. The generated gateway code confirms the services: `AIService`, `AttachmentService`, `AuthService`, `IdentityProviderService`, `InstanceService`, `MemoService`, `ShortcutService`, `UserService` — each generated into `proto/gen/api/v1/*_service.pb.gw.go` (e.g. `proto/gen/api/v1/memo_service.pb.gw.go`, `proto/gen/api/v1/user_service.pb.gw.go`).
- **HTTP surface:** all these services are exposed as REST under `/api/v1/...` via grpc-gateway (72 generated routes, e.g. `GET /api/v1/memos`, `POST /api/v1/auth/signin`, `PATCH /api/v1/{memo.name=memos/*}`).
- **Hand-written HTTP handlers** live in `server/router/`: SSE (`server/router/api/v1/sse_handler.go:25`), file serving (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), frontend/robots/sitemap (`server/router/frontend/frontend.go`), and `GET /healthz` (`server/server.go:44`).

If you want the exact request/response field definitions, those are the `.proto` files in `proto/api/v1/` — I can list them if you'd like the specific filenames.
