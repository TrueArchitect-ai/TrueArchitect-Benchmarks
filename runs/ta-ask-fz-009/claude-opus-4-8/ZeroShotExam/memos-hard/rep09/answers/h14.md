**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`). This metadata is what the API converter copies onto the response for lists/previews (`server/router/api/v1/memo_service_converter.go:48–49`).

**Triggers (what causes recomputation)** — three call sites, all confirmed via the caller graph:
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:70` (recompute on memo creation)
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:401` (recompute when content changes)
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27` (batch backfill that rebuilds the payload of all existing memos, 100 at a time)

So it is recomputed on every create and update, plus a bulk migration/backfill pass.

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go:356–419`):
- **Tags** — collected from memo-tag AST nodes, deduplicated preserving case → `Payload.Tags`.
- **Property.Title** — text of the document's first block if it is an H1 heading.
- **Property.HasLink** — true if any link node is present.
- **Property.HasCode** — true if any code block, fenced code block, or inline code span is present.
- **Property.HasTaskList** — true if any task checkbox is present.
- **Property.HasIncompleteTasks** — true if any task checkbox is unchecked.

(`ExtractAll` also gathers `Mentions`, but the runner only persists `Tags` and `Property` onto the payload.)
