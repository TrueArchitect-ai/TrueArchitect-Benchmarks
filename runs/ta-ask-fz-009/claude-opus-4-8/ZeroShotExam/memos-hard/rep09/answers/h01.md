The last time an object was presigned is tracked on the attachment payload — `AttachmentPayload_S3Object.LastPresignedTime` (`proto/gen/store/attachment.pb.go:336-338`, whose comment states it's "used to determine if the presigned URL is still valid"). Without refresh, the stored link would go stale.

- **The schedule.** `const runnerInterval = time.Hour * 12` (`server/runner/s3presign/runner.go:26-27`), driven by `time.NewTicker(runnerInterval)` at line 30. Twelve-hour cadence against a five-day URL lifetime leaves ample refresh margin.

- **The wiring.** In `Server.startBackgroundRunners` (`server/server.go:153`): the runner is constructed at line 162, run once synchronously at line 163 (`RunOnce`, so links are fresh right after boot), then started as a continuous goroutine at lines 166-170 (`s3presignRunner.Run(s3Context)`). `startBackgroundRunners` is called from server start at `server/server.go:129`.
