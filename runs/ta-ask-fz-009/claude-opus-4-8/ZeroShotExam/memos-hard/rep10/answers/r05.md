**Actual API surface:** The public API is a **gRPC-first / REST-gateway** design defined by Protobuf, not GraphQL.

- The contract (schema) lives in the **`.proto` definitions** under `proto/`, compiled into generated Go under `proto/gen/api/v1/`.
- REST is exposed via grpc-gateway HTTP mappings — e.g. the `*.pb.gw.go` files register routes like `GET /api/v1/memos` (`proto/gen/api/v1/memo_service.pb.gw.go:1745`), `GET /api/v1/users` (`proto/gen/api/v1/user_service.pb.gw.go:2301`), and the auth/attachment/instance/identity-provider/shortcut services alongside.
- A few non-generated routes exist too: SSE (`server/router/api/v1/sse_handler.go:25`), file serving (`server/router/fileserver/fileserver.go`), RSS (`server/router/rss/rss.go`), frontend/sitemap (`server/router/frontend/frontend.go`), and `GET /healthz` (`server/server.go:44`).

So if you're looking for the "schema" that defines the public API, it's the Protobuf service definitions in `proto/` (generated into `proto/gen/api/v1/`), not any GraphQL SDL file.
