**Computation site**

The derived metadata is the memo's `Payload` (`storepb.MemoPayload`, defined at `store/memo.go:51`). It is computed by `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates the actual content analysis to the Markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`). `RebuildMemoPayload` runs `ExtractAll` over `memo.Content` and assigns the result into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The extraction is a single goldmark AST walk (`markdown.go:371-411`).

**Triggers (recomputation)**

Three call sites drive recomputation:
1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every new memo.
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only inside the `path == "content"` branch of the update mask (`memo_service.go:436-449`), i.e. only when the content field is actually being changed.
3. `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:52`, a background batch runner that walks all memos in pages of 100 and rebuilds+persists each payload (a bulk backfill/migration pass).

**Extracted properties**

`ExtractAll` collects (via the AST walk, `markdown.go:376-419`):
- **Tags** — every memo tag node, deduplicated with original case preserved (`markdown.go:377,418`).
- **Property** (`storepb.MemoPayload_Property`, populated at `markdown.go:383-408`):
  - `Title` — text of the first block if it is an H1 heading.
  - `HasLink` — true if any link node is present.
  - `HasCode` — true if any code block, fenced code block, or inline code span is present.
  - `HasTaskList` — true if any task checkbox is present.
  - `HasIncompleteTasks` — true if any task checkbox is unchecked.

Note: `ExtractAll` also computes `Mentions` (`markdown.go:379-380`), but `RebuildMemoPayload` does **not** copy `Mentions` into the persisted payload — only `Tags` and `Property` are stored (`runner.go:85-86`).
