**Premise correction:** There is no GraphQL schema in this repository. This is the [memos](https://github.com/usememos/memos) codebase, and its public API is **gRPC + REST (gRPC-Gateway)**, not GraphQL. A fuzzy search across all 7,293 symbols for "graphql" returned a certified miss — the term does not appear as an identifier anywhere in the server-side code.

**Actual API surface:** The API is defined as Protobuf services and exposed over HTTP `/api/v1/...` via generated gRPC-Gateway handlers under `proto/gen/api/v1/`. The `.proto` definitions are the source of truth; the `*.pb.gw.go` files are the generated HTTP surface. The services are:

- **MemoService** — `proto/gen/api/v1/memo_service.pb.gw.go` (memos, comments, reactions, relations, shares, link metadata)
- **UserService** — `proto/gen/api/v1/user_service.pb.gw.go` (users, settings, webhooks, PATs, linked identities, notifications)
- **AttachmentService** — `proto/gen/api/v1/attachment_service.pb.gw.go`
- **AuthService** — `proto/gen/api/v1/auth_service.pb.gw.go` (`/api/v1/auth/signin`, `/signout`, `/refresh`, `/me`)
- **InstanceService** — `proto/gen/api/v1/instance_service.pb.gw.go`
- **IdentityProviderService** — `proto/gen/api/v1/idp_service.pb.gw.go`
- **ShortcutService** — `proto/gen/api/v1/shortcut_service.pb.gw.go`
- **AIService** — `proto/gen/api/v1/ai_service.pb.gw.go`

Plus hand-written HTTP routes outside the generated gateway: SSE at `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go:25`), a file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and frontend/health routes (`server/router/frontend/frontend.go`, `server/server.go:44`).

If you're looking for the schema definitions themselves, they live as `.proto` files in `proto/api/v1/` (the generated Go in `proto/gen/api/v1/` is derived from those).
