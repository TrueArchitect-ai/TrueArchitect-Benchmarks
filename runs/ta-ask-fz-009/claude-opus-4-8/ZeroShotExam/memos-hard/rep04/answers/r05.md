**Premise correction:** This repository (the Memos server, `github.com/usememos/memos`) has no GraphQL schema. A content search across 1,042 files for GraphQL markers (`graphql`, `gqlgen`, `.graphql`, `type Query`, `type Mutation`) returned zero matches. There is no public GraphQL API to point you at.

**Actual API surface:** The public API is **gRPC defined via Protocol Buffers, exposed over HTTP through a grpc-gateway**. The contract lives in the `.proto` service definitions under `proto/api/v1/`, and the HTTP↔gRPC bindings are generated into `proto/gen/api/v1/*.pb.gw.go`. All REST routes are mounted under `/api/v1/` from these generated gateway files. The services are:

- **AuthService** — `proto/gen/api/v1/auth_service.pb.gw.go` (signin/signout/refresh, `GET /api/v1/auth/me`)
- **MemoService** — `memo_service.pb.gw.go` (memos CRUD, comments, reactions, relations, shares, attachments)
- **UserService** — `user_service.pb.gw.go` (users, settings, webhooks, PATs, notifications, linked identities)
- **AttachmentService** — `attachment_service.pb.gw.go`
- **IdentityProviderService** — `idp_service.pb.gw.go`
- **InstanceService** — `instance_service.pb.gw.go` (profile, stats, settings)
- **ShortcutService** — `shortcut_service.pb.gw.go`
- **AIService** — `ai_service.pb.gw.go` (`POST /api/v1/ai:transcribe`)

Non-gateway HTTP routes are hand-registered in the router layer: SSE at `server/router/api/v1/sse_handler.go:25`, file serving in `server/router/fileserver/fileserver.go`, RSS in `server/router/rss/rss.go`, sitemap/robots in `server/router/frontend/frontend.go`, and `GET /healthz` in `server/server.go:44`.

So if you're looking for "the schema for the public API," the authoritative source is the **`.proto` files in `proto/api/v1/`** — not a GraphQL SDL.
