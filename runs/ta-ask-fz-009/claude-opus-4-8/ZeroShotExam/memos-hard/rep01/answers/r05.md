**Premise correction:** This repo (memos) has no GraphQL schema. `[ArchMap query]` is a **certified miss** across all 7,293 symbols — no GraphQL type, resolver, or schema exists anywhere in the codebase. The premise that the public API is GraphQL is false.

**Actual API surface:** The public API is a **gRPC service defined in Protocol Buffers**, exposed over HTTP via a grpc-gateway. The schema of record is the `.proto` files under `proto/api/v1/`; the HTTP surface is the generated gateway code under `proto/gen/api/v1/*.pb.gw.go`. Every route lives at `/api/v1/...` and maps to a proto-defined RPC method. The services are:

- **MemoService** — `proto/gen/api/v1/memo_service.pb.gw.go` (memos, comments, reactions, relations, shares, link metadata)
- **UserService** — `proto/gen/api/v1/user_service.pb.gw.go` (users, webhooks, PATs, notifications, settings, linked identities)
- **AuthService** — `proto/gen/api/v1/auth_service.pb.gw.go` (`/api/v1/auth/signin`, `/signout`, `/refresh`, `/me`)
- **AttachmentService** — `proto/gen/api/v1/attachment_service.pb.gw.go`
- **InstanceService** — `proto/gen/api/v1/instance_service.pb.gw.go`
- **IdentityProviderService** — `proto/gen/api/v1/idp_service.pb.gw.go`
- **ShortcutService** — `proto/gen/api/v1/shortcut_service.pb.gw.go`
- **AIService** — `proto/gen/api/v1/ai_service.pb.gw.go`

Alongside the gRPC/REST gateway there are a handful of **hand-written Go HTTP handlers** (not proto-generated):
- SSE stream — `server/router/api/v1/sse_handler.go:25` (`GET /api/v1/sse`)
- File serving — `server/router/fileserver/fileserver.go` (attachments, avatars)
- RSS feeds — `server/router/rss/rss.go` (`/explore/rss.xml`, `/u/:username/rss.xml`)
- Frontend/SEO — `server/router/frontend/frontend.go` (`robots.txt`, `sitemap.xml`)
- Health — `server/server.go:44` (`GET /healthz`)
