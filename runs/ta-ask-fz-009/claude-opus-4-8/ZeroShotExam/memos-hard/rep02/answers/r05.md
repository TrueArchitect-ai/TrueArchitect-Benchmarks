**Actual API surface:** This is the Memos project (`github.com/usememos/memos`), and its public API is **gRPC + REST via gRPC-Gateway defined in Protocol Buffers**, not GraphQL.

- **Schema source of truth:** `.proto` files under `proto/api/v1/` — one per service (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, etc.).
- **Generated code:** `proto/gen/api/v1/` — the `*.pb.go` messages/services and the `*.pb.gw.go` gateway files that map HTTP routes onto the gRPC handlers.
- **HTTP exposure:** REST endpoints under `/api/v1/...`, generated from the proto `google.api.http` annotations. Examples: `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, `POST /api/v1/auth/signin`, `GET /api/v1/users` (see `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `auth_service.pb.gw.go:331`, `user_service.pb.gw.go:2301`).
- **Non-generated handlers** rounding out the surface: SSE (`server/router/api/v1/sse_handler.go:25`), file serving (`server/router/fileserver/fileserver.go`), RSS (`server/router/rss/rss.go`), frontend/robots/sitemap (`server/router/frontend/frontend.go`), and health (`server/server.go:44`).

If you want the canonical "schema" to point someone at, it's the `.proto` files in `proto/api/v1/` — that's the contract the rest of the API is generated from.
