**Premise correction:** There is no GraphQL schema in this repository — the "public API" is not GraphQL. The `pnpm-lock.yaml` hits are the only matches for `graphql`, and those are unrelated npm integrity hashes (base64 blobs), not GraphQL usage. The map's `[ArchMap query]` returns 81 endpoints and every one of them is REST/HTTP, with no GraphQL door.

**Actual API surface:** This is [memos](https://github.com/usememos/memos), a Go backend whose public API is a **gRPC service set exposed as REST via grpc-gateway**. The contract is defined in Protocol Buffers, not GraphQL/SDL:

- **Schema source of truth:** `.proto` service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, etc.).
- **Generated gateway (the REST surface):** `proto/gen/api/v1/*.pb.gw.go` — these `pattern_*` route variables map HTTP verbs/paths onto the gRPC handlers. For example:
  - `MemoService` → `proto/gen/api/v1/memo_service.pb.gw.go:1745` (`GET/POST/PATCH/DELETE /api/v1/memos...`)
  - `UserService` → `proto/gen/api/v1/user_service.pb.gw.go:2301` (`/api/v1/users...`)
  - `AuthService` → `proto/gen/api/v1/auth_service.pb.gw.go:331` (`/api/v1/auth/...`)
  - `AttachmentService`, `InstanceService`, `IdentityProviderService`, `ShortcutService`, `AIService`.

There are also a few hand-written non-gRPC HTTP routes outside the gateway: SSE (`server/router/api/v1/sse_handler.go:25`), file serving (`server/router/fileserver/fileserver.go`), RSS (`server/router/rss/rss.go`), frontend `robots.txt`/`sitemap.xml` (`server/router/frontend/frontend.go`), and `/healthz` (`server/server.go:44`).

So the answer to "where is the GraphQL schema" is: **it doesn't exist**. If you want the equivalent public-API contract, look at the `.proto` files in `proto/api/v1/` (the schema) and their generated gateways in `proto/gen/api/v1/*.pb.gw.go` (the wired REST surface).
