**Computation site.** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` computes the derived metadata into `memo.Payload` (`store.Memo.Payload`, a `*storepb.MemoPayload`). It delegates the actual parsing to the Goldmark-based `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`), which walks the parsed markdown AST in a single pass. `RebuildMemoPayload` then copies `data.Tags` and `data.Property` onto the payload (`runner.go:85-86`).

**Triggers (what causes recomputation).**
- **Memo creation** — `CreateMemo` calls it on the new memo before persisting (`server/router/api/v1/memo_service.go:108`).
- **Content update** — `UpdateMemo` calls it only when the `content` field is in the update mask (`server/router/api/v1/memo_service.go:447`, inside the `path == "content"` branch); the recomputed payload is written via `update.Payload` (`memo_service.go:451`). Non-content updates (e.g. `visibility`) do not re-derive it.
- **Bulk backfill** — the runner's `RunOnce` (`server/runner/memopayload/runner.go:27`) walks all memos in batches of 100 and rebuilds each payload, persisting via `Store.UpdateMemo`.

**Extracted properties.** From the memo content (markdown), `ExtractAll` derives:
- `Tags` — list of `#tag` values found in the content (`markdown.go:377`).
- `Property.Title` — text of the document's first block if it is an H1 heading (`markdown.go:384-388`).
- `Property.HasLink` — true if any link node is present (`markdown.go:394`).
- `Property.HasCode` — true for any code block, fenced code block, or inline code span (`markdown.go:397`).
- `Property.HasTaskList` — true if any task checkbox exists (`markdown.go:400`).
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (`markdown.go:403`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` persists only `Tags` and `Property` into the memo payload — mentions are not written there.)

These payload fields are what the API converter surfaces to clients for list/preview purposes: `memo_service_converter.go:48-49` maps `Payload.Tags` and `Payload.Property` onto the API `Memo` message.
