**Premise correction:** This repository (the Memos project) does not define a GraphQL schema, and it does not expose a public GraphQL API. The `.graphql` glob matched zero files, and the only `graphql`-ish grep hits are unrelated base64 integrity hashes in `web/pnpm-lock.yaml` — not a schema. There is no GraphQL server, resolver, or type-definition surface here.

**Actual API surface:** The public API is **gRPC with an HTTP/JSON (grpc-gateway) transport**, defined by Protobuf, not GraphQL:

- **Schema source of truth:** Protobuf service/message definitions under `proto/api/v1/` (the `.proto` files), compiled into Go stubs in `proto/gen/api/v1/`.
- **HTTP/JSON edge:** REST-style routes are generated into the `*.pb.gw.go` gateway files, all mounted under `/api/v1/`. For example:
  - `MemoService` → `proto/gen/api/v1/memo_service.pb.gw.go:1745` (e.g. `GET/POST /api/v1/memos`)
  - `UserService` → `proto/gen/api/v1/user_service.pb.gw.go:2301`
  - `AuthService` → `proto/gen/api/v1/auth_service.pb.gw.go:331` (`/api/v1/auth/*`)
  - plus `Attachment`, `IdentityProvider`, `Instance`, `Shortcut`, and `AIService`.
- **Non-gRPC HTTP routes** (hand-written, not part of the RPC surface): SSE at `server/router/api/v1/sse_handler.go:25`, file serving in `server/router/fileserver/fileserver.go`, RSS in `server/router/rss/rss.go`, and the frontend/health routes in `server/router/frontend/frontend.go` and `server/server.go:44`.

So the "GraphQL schema" you're looking for doesn't exist. The equivalent artifact — the contract that defines the public API — is the Protobuf definitions in `proto/api/v1/`, surfaced over HTTP via the generated gateway code in `proto/gen/api/v1/`.
