**Abstraction package** — `internal/idp` (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type used across providers.

**Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), the one concrete protocol implementation that ships: an OAuth2 `IdentityProvider` with `ExchangeToken` and `UserInfo` methods. It is the only subpackage under `internal/idp/` — no other protocol (e.g. SAML/LDAP) implementation is present.
