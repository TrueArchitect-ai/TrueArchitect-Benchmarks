**Delivery function** — `webhook.Post` in `internal/webhook/webhook.go:120` performs the actual outbound HTTP dispatch (marshals the payload, builds the signed request, and calls `safeClient.Do` around line 152). It's invoked directly and also drained asynchronously by the worker pool started in `init()` (`internal/webhook/webhook.go:42-55`, reading `asyncPostQueue`).

**Protection mechanism** — SSRF is blocked at dial time by `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the `DialContext` of the shared `safeClient.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any address falling in a reserved/private range via `isReservedIP`, which checks the `reservedCIDRs` list defined in `internal/webhook/validate.go:11-32` (loopback, RFC-1918, link-local incl. cloud IMDS 169.254.169.254, etc.). Because the check runs at connection time after DNS resolution, it also defeats DNS-rebinding. 

Two notes: there's a second, earlier guard — `webhook.ValidateURL` in `internal/webhook/validate.go` (scheme + resolved-IP check at configuration time) — and both guards can be disabled by the `webhook.AllowPrivateIPs` flag, wired to the `--allow-private-webhooks` CLI flag (default `false`) at `cmd/memos/main.go:49,133`.
