This is the memo **payload** (`store.MemoPayload`, `proto/gen/store/memo.pb.go:24`) — server-derived metadata computed from the memo's markdown content, not user-set, and used for list/preview flags and filtering.

**Computation site** — `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It runs the content through the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:356`, backed by goldmark) and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`).

**Triggers (operations that cause recomputation):**
- **Memo create** — `CreateMemo` calls `memopayload.RebuildMemoPayload` before insert (`server/router/api/v1/memo_service.go:108`).
- **Memo content update** — `UpdateMemo` recomputes, but only inside the `path == "content"` branch of the update mask (`server/router/api/v1/memo_service.go:447`); a visibility-only or other field update does *not* recompute (`memo_service.go:436-451`). It then persists via `update.Payload = memo.Payload` (`:451`).
- **Bulk backfill** — the batch runner `memopayload.Runner.RunOnce` rebuilds the payload for every memo and saves it (`server/runner/memopayload/runner.go:27-72`). (Per h08, this `Runner` type is not wired into production startup, so in a running server the live triggers are create and content-update; the batch path is a maintenance/backfill entry point.)

**Extracted properties** (what the computation produces from content):
- **`Tags`** — `[]string` of hashtags parsed from the content (`runner.go:85`, `ExtractedData.Tags` at `internal/markdown/markdown.go:22`).
- **`Property`** — boolean/scalar flags in `MemoPayload_Property` (`proto/gen/store/memo.pb.go:85`):
  - `HasLink` — content contains a link (`memo.pb.go:127`)
  - `HasTaskList` — content contains a task list (`:134`)
  - `HasCode` — content contains a code block (`:141`)
  - `HasIncompleteTasks` — has unchecked task items (`:148`)
  - `Title` — derived title, e.g. first heading (`:155`)

(Note: `MemoPayload` also has a `Location` field, but that is user-supplied, not derived from content — the content-derived output is exactly `Tags` + `Property`, as set in `RebuildMemoPayload`.)
