**Protection against internal/SSRF targets:** two layers, both keyed on `isReservedIP` (`internal/webhook/validate.go:44`):

1. **Dial-time block — the real enforcement:** `safeClient` uses a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32–37`). `safeDialContext` resolves the host and rejects any address in a reserved/private range at connection time (`internal/webhook/webhook.go:59–77`). The private-IP ranges come from `reservedNetworks`/`reservedCIDRs` (`internal/webhook/validate.go:11–32`), and both checks can be disabled for self-hosted setups via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:38–47`), wired to the `--allow-private-webhooks` CLI flag in `cmd/memos/main.go:49,133`.
