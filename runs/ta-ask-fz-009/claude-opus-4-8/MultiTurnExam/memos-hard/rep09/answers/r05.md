**Premise correction:** There is no GraphQL schema in this project. A full-text search for `graphql`/`gqlgen` across all 343 Go files returns zero matches, and there are no `.graphql`/`.gql` schema files anywhere in the tree. The public API is not GraphQL, so there is no GraphQL schema to locate.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC service definitions**, served over **Connect RPC + gRPC-Gateway (REST/JSON)**. The schema lives in the `.proto` files under `proto/api/v1/`:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These compile to generated Go in `proto/gen/api/v1/` (message types, gRPC stubs, Connect handlers in `proto/gen/api/v1/apiv1connect/`, and gateway REST bindings in the `*.pb.gw.go` files). The handlers are implemented by `APIV1Service` in `server/router/api/v1/` and registered — with Connect interceptors and a gRPC-Gateway mux — in `server/router/api/v1/v1.go` (Connect handler registration at `v1.go:141`, gateway mux at `v1.go:96`). So the "schema" for the public API is the protobuf service/message definitions in `proto/api/v1/`, exposed as RPC and REST — not GraphQL.
