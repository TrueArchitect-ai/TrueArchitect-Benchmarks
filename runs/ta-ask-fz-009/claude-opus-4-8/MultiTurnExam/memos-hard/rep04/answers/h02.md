**Delivery function**: `webhook.Post` — `internal/webhook/webhook.go:120`. This is where the outbound HTTP request actually executes: it marshals the payload, builds a `POST` to the user-supplied `requestPayload.URL`, optionally adds an HMAC-SHA256 `webhook-signature` header, and fires it via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. (`PostAsync` at line 184 just enqueues onto a bounded channel drained by worker goroutines that call `Post`.)

**Protection mechanism**: SSRF is blocked at dial time by `safeDialContext` — `internal/webhook/webhook.go:59`. The shared `safeClient` (lines 32–37) installs it as the transport's `DialContext`. On every connection it resolves the target host (`net.DefaultResolver.LookupHost`, line 65) and rejects the dial if *any* resolved IP falls in a reserved/private range — `isReservedIP(ip)` at line 71, defined in `internal/webhook/validate.go:44`. Because the check runs against the post-resolution IPs at dial time (not against the URL string), it also defeats DNS-rebinding attempts, as the comment at lines 30–31 notes.

So a webhook cannot be pointed at internal/private network addresses: the request is constructed and sent in `Post`, but the connection is refused before any bytes leave if the resolved address is reserved.
