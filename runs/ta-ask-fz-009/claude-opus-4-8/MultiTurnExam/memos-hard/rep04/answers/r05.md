**Premise correction: there is no GraphQL schema — this project has no GraphQL API at all. A search across 1042 files for `graphql|gqlgen|.graphql|schema.gql|apollo` returned zero matches, and there is no GraphQL server library in the dependencies. So there is no GraphQL schema file to point to.**

**Actual API surface**: the public API is defined with **Protocol Buffers**, served over **gRPC / Connect (and a gRPC-Gateway REST bridge)** — not GraphQL. The schema of record is the set of `.proto` service definitions under `proto/api/v1/`:

- proto/api/v1/memo_service.proto
- proto/api/v1/user_service.proto
- proto/api/v1/attachment_service.proto
- proto/api/v1/auth_service.proto
- proto/api/v1/instance_service.proto
- proto/api/v1/idp_service.proto
- proto/api/v1/shortcut_service.proto
- proto/api/v1/ai_service.proto
- proto/api/v1/common.proto

These compile to generated Go under `proto/gen/api/v1/` — including the Connect handlers in `proto/gen/api/v1/apiv1connect/*.connect.go` and the gRPC-Gateway REST mappings in the `*.pb.gw.go` files (e.g. `proto/gen/api/v1/memo_service.pb.gw.go`, which carries the HTTP route annotations like `POST /api/v1/...`). The generated TypeScript client the web app consumes lives at `web/src/types/proto/api/v1/`.

At runtime these services are registered on the server through the Connect/gateway wiring in `server/router/api/v1/` (e.g. `RegisterGateway` in server/router/api/v1/v1.go and the Connect interceptor chain in server/router/api/v1/connect_interceptors.go).

So if you're looking for "the schema for the public API," the equivalent of a GraphQL SDL here is the `.proto` files in `proto/api/v1/` — that's where request/response shapes and RPC methods are declared. There is simply no GraphQL layer.
