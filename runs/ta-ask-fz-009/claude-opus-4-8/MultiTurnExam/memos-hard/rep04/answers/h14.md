**Computation site**: `memopayload.RebuildMemoPayload` — server/runner/memopayload/runner.go:74. It takes the memo's raw `Content`, runs a single-pass markdown parse via `markdownService.ExtractAll([]byte(memo.Content))` (line 80), and writes the results into the memo's derived `Payload`: `memo.Payload.Tags` and `memo.Payload.Property` (lines 85–86). The actual extraction logic lives in the markdown service, `(*service).ExtractAll` at internal/markdown/markdown.go:356, which walks the goldmark AST. This payload is stored on the memo (in the `payload` DB column) and is what lists/previews read, rather than anything the user sets directly.

**Triggers** (production callers that cause recomputation — from `[ArchMap query]`):
- `APIV1Service.CreateMemo` — server/router/api/v1/memo_service.go:70 (invoked at :108) — recomputed when a memo is created.
- `APIV1Service.UpdateMemo` — server/router/api/v1/memo_service.go:401 (invoked at :447) — recomputed when a memo's content is updated.
- `memopayload.Runner.RunOnce` — server/runner/memopayload/runner.go:27 — a batch backfill that rebuilds every memo's payload. (As established earlier, this `Runner` is never wired up in production, so in practice only create and update trigger recomputation at runtime; the batch path is dead code.)

**Extracted properties** (what the computation pulls from content — `ExtractedData` at internal/markdown/markdown.go:21 and the `MemoPayload_Property` it fills, internal/markdown/markdown.go:356–420):
- **Tags** — every `#tag` in the content, deduplicated preserving case (markdown.go:377, 418) → stored as `Payload.Tags`.
- **Property.Title** — the text of a level-1 heading if it's the first block (markdown.go:386–387).
- **Property.HasLink** — true if the content contains any link (markdown.go:394).
- **Property.HasCode** — true if any code block, fenced code, or inline code span is present (markdown.go:396–397).
- **Property.HasTaskList** — true if any task checkbox exists (markdown.go:399–400).
- **Property.HasIncompleteTasks** — true if any task checkbox is unchecked (markdown.go:402–403).

(`ExtractAll` also collects `Mentions`, markdown.go:379, but `RebuildMemoPayload` only persists `Tags` and `Property` to the memo payload — mentions are not copied into the stored derived metadata.)

So: content → `ExtractAll` markdown parse → `Tags` + a `Property` struct (Title, HasLink, HasCode, HasTaskList, HasIncompleteTasks) → saved on the memo's payload, recomputed on create and update.
