**Premise correction:** There is no GraphQL API, and therefore no GraphQL schema. A case-insensitive search for `graphql`, `gqlgen`, `graph-gophers`, and `schema.graphql` across all 343 Go files returns zero matches, and there are no `.graphql` files anywhere in the repo. So there is nothing to point to.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **gRPC + Connect + a REST/HTTP gateway** — not GraphQL. The schema lives in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- plus `proto/api/v1/common.proto`

These generate the Go types and service stubs under `proto/gen/api/v1/` in three flavors seen throughout the codebase: the gRPC servers (`*_grpc.pb.go`), the Connect handlers/clients (`apiv1connect/*.connect.go`), and the grpc-gateway REST bindings (`*.pb.gw.go`, which carry the `GET/POST /api/v1/...` route annotations). Concrete endpoint handlers are implemented in `server/router/api/v1/`.

So if you're looking for the API contract, read the `proto/api/v1/*.proto` service definitions (and their `google.api.http` annotations for the REST paths) — that is this project's equivalent of a schema; there is no GraphQL layer to define one.
