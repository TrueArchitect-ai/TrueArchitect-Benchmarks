How it works:

- **Where delivery executes.** `Post` marshals the payload, builds the `POST` request, optionally attaches a Standard-Webhooks HMAC-SHA256 signature, and performs the actual outbound call at `safeClient.Do(req)` (`webhook.go:152`). `PostAsync` (`webhook.go:184`) just enqueues onto a bounded channel drained by four worker goroutines started in `init()` (`webhook.go:42–55`), which invoke `Post`. So all real HTTP egress funnels through `Post`.

- **What stops it hitting internal addresses.** The delivery uses a single shared `safeClient` whose `Transport.DialContext` is `safeDialContext` (`webhook.go:32–37`). At dial time `safeDialContext` (`webhook.go:59`) resolves the target host itself via `net.DefaultResolver.LookupHost` and, for every resolved IP, calls `isReservedIP`; if any resolved address is reserved/private it refuses the connection with *"connection to reserved/private IP address is not allowed"* (`webhook.go:70–74`). Because the guard runs on the *resolved* IPs at dial time rather than on the URL string, it also defeats DNS-rebinding.

- **The range check.** `isReservedIP` (`internal/webhook/validate.go:44`) tests the IP against a set of `reservedNetworks`, and is short-circuited by an `AllowPrivateIPs` escape hatch (`validate.go:45`) for deployments that intentionally allow private targets.
