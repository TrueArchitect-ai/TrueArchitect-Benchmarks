**Extracted properties** (from `ExtractAll` → `ExtractedData`, `internal/markdown/markdown.go:21`, materialized into the payload):
- **Tags** — the hashtags parsed from content (`memo.Payload.Tags`).
- **Property** (`store.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`), a set of content-derived flags/values used for list/preview rendering:
  - `HasLink` — content contains a link
  - `HasTaskList` — content contains a task/checkbox list
  - `HasCode` — content contains code
  - `HasIncompleteTasks` — has unchecked task items
  - `Title` — text of the first H1 heading, if any

(Note: `ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the derived payload — mentions are consumed separately by the mention-handling path, e.g. `server/router/api/v1/memo_mention_helpers.go`.)
