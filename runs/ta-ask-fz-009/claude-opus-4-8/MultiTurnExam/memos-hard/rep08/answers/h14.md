The derived metadata is the memo's **`Payload`** (`storepb.MemoPayload`), computed from `memo.Content` rather than user-set — the proto even labels `MemoPayload_Property` as "The calculated properties from the memo content" (`proto/gen/store/memo.pb.go:84`).

**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass `ExtractAll([]byte(memo.Content))` (`:80`, implemented at `internal/markdown/markdown.go:356`), then writes `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`:85–86`). So the actual metadata *extraction* is delegated to `markdown.service.ExtractAll`; `RebuildMemoPayload` is the assembly/write point.

**Triggers (what causes recomputation):** per the caller graph of `RebuildMemoPayload`:
- `v1.APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:70` (memo creation)
- `v1.APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:401` (content edit)
- `v1.APIV1Service.CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` (transitively, via `CreateMemo`)
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27` (a batch backfill that rebuilds every memo's payload and persists via `Store.UpdateMemo`). Note from h08: this `RunOnce` has no production caller — the runner is wired to nothing at startup, so in practice recomputation is driven by the create/update RPC paths, not the batch runner.

**Extracted properties:** `ExtractAll` returns an `ExtractedData` (`internal/markdown/markdown.go:21`) with `Tags`, `Mentions`, and `Property`. `RebuildMemoPayload` persists two of these into the payload:
- **`Tags`** — the list of `#hashtags` parsed from content.
- **`Property`** (`MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`) — the boolean/preview flags computed from content: `HasLink`, `HasTaskList`, `HasCode`, `HasIncompleteTasks`, and the `Title` (extracted from the first H1 heading).

(`Mentions` is also produced by `ExtractAll` but is not copied into the memo payload by `RebuildMemoPayload` — only `Tags` and `Property` are written.)
