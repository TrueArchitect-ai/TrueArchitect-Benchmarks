h14.

**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It takes the memo and the markdown service, calls `markdownService.ExtractAll([]byte(memo.Content))` (the goldmark `ExtractAll` in `internal/markdown/markdown.go:356`), and writes the result into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:85‑86`). This is the derived, content-computed metadata (the `store.Memo.Payload` / `MemoPayload`), distinct from user-set fields.

**Triggers (operations that force recomputation):**
- **`CreateMemo`** — `server/router/api/v1/memo_service.go:108` (always rebuilt at creation).
- **`UpdateMemo`**, but only when the content field changes — `server/router/api/v1/memo_service.go:447`, inside the branch that sets `memo.Content = request.Memo.Content` (`:446`). Updates that don't touch content don't recompute.
- **Bulk backfill** via the offline `memopayload.Runner.RunOnce` loop, which re-derives every memo's payload — `server/runner/memopayload/runner.go:52`. (Note: as established, this runner has no production caller wiring in `server/server.go`; it's a maintenance/backfill path, not part of the normal request flow.)

**Extracted properties** (from `markdown.ExtractAll`, populated into `ExtractedData` and thence the payload):
- **`Tags`** — deduplicated list of `#tags` parsed from content (`internal/markdown/markdown.go:376‑377,418`); stored in `Payload.Tags`.
- **`Property`** (`storepb.MemoPayload_Property`), stored in `Payload.Property`:
  - **`Title`** — text of a leading H1 heading, if the first block is one (`internal/markdown/markdown.go:384‑388`).
  - **`HasLink`** — content contains a link (`:393‑394`).
  - **`HasCode`** — content contains a code block/fenced block/code span (`:396‑397`).
  - **`HasTaskList`** — content contains a task checkbox (`:399‑400`).
  - **`HasIncompleteTasks`** — at least one unchecked task (`:401‑404`).

(`ExtractAll` also computes `Mentions` — deduplicated `@username` references, `internal/markdown/markdown.go:379‑380` — but `RebuildMemoPayload` only copies `Tags` and `Property` into the stored payload; mentions are consumed separately by the mention/notification path rather than persisted in `MemoPayload`.)
