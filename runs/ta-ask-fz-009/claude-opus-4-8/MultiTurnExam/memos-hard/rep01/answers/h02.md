**Delivery function:** `webhook.Post` — `internal/webhook/webhook.go:120`. This is where the outbound HTTP POST actually executes: it marshals the payload, builds the request, optionally HMAC-signs it (Standard Webhooks headers), and fires it via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. (Async dispatch goes through `PostAsync` → a worker queue that ultimately calls `Post` — `webhook.go:184` and `webhook.go:42–55`.)

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`, installed as the `DialContext` on the shared `safeClient`'s transport (`webhook.go:32–37`). It defends against SSRF at *dial time*: it resolves the target hostname with `net.DefaultResolver.LookupHost` and rejects the connection if **any** resolved IP falls in a reserved/private range (`webhook.go:65–74`). Because the check happens on the resolved IPs at dial time, it also defeats DNS-rebinding. The range test is `isReservedIP` — `internal/webhook/validate.go:44` — which checks the IP against `reservedNetworks` (and can be bypassed only via the explicit `AllowPrivateIPs` escape hatch, `validate.go:45`).
