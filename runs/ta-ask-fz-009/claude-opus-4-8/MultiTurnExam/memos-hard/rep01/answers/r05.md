**Premise correction: there is no GraphQL in this project — no schema, no server, no dependency.** A case-insensitive search across all 343 Go files for `graphql`, `gqlgen`, `graphene`, and `schema.graphql` returns zero matches, and a glob for `**/*.graphql` finds no files. So there is no GraphQL schema to point at.

**Actual API surface:** The public API is a **Protocol Buffers–defined, Connect/gRPC service, also exposed as a REST/JSON HTTP API via grpc-gateway.** The contract ("schema") lives in the `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These generate the Go handlers/clients and the HTTP-gateway route tables in `proto/gen/api/v1/` (e.g. `*.pb.gw.go`). The resulting public HTTP surface is a conventional REST-style API under `/api/v1/...` — 74 gateway-mapped endpoints plus a few hand-registered routes. Examples:

- `POST /api/v1/memos`, `GET /api/v1/memos`, `GET /api/v1/{name=memos/*}`, `PATCH /api/v1/{memo.name=memos/*}` (memo CRUD) — routed at `proto/gen/api/v1/memo_service.pb.gw.go:1745`.
- `POST /api/v1/auth/signin`, `GET /api/v1/auth/me` (`proto/gen/api/v1/auth_service.pb.gw.go:331`).
- `GET /api/v1/users`, `GET /api/v1/{name=users/*}`, plus user webhooks/tokens (`proto/gen/api/v1/user_service.pb.gw.go:2301`).
- Non-gateway routes: SSE at `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go:25`), the file server (`/attachments/...`, `/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:132,168`), RSS (`server/router/rss/rss.go:72,111`), and `GET /healthz` (`server/server.go:44`).

There is no single GraphQL SDL document; the authoritative schema is the set of protobuf service/message definitions in `proto/api/v1/*.proto`, and querying is done over REST/JSON (grpc-gateway) or Connect/gRPC — not GraphQL.
