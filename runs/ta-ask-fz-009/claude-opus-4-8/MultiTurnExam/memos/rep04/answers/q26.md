`Store.DeleteMemo` (store/memo.go:140) explicitly deletes:
- **memo_relation** — `driver.DeleteMemoRelation` for both `MemoID` and `RelatedMemoID` → `DELETE FROM memo_relation` (store/db/sqlite/memo_relation.go:137)

- **memo** — `driver.DeleteMemo` → `DELETE FROM memo` (store/db/sqlite/memo.go:237)

The API handler also recursively deletes comment memos, which run the same three-table cascade for each comment. Note: `reaction` rows are **not** removed by explicit cascade code — the handler lists reactions (for the webhook payload) but never deletes them, and there's no `DeleteReaction` call in the delete path (any reaction cleanup would depend on a DB-level FK cascade, which the DELETE statements above don't invoke).
