Interceptor path: web/src/connect.ts (the auth `Interceptor` that sets `Authorization: Bearer <token>`, line 97-100; with reactive refresh on 401/Unauthenticated, lines 102-120; token state in `web/src/auth-state.ts`).

Token kinds: a short-lived **JWT access token** (sent as `Bearer` in the `Authorization` header, ~15 min) and a **refresh token** (HTTP-only cookie, used via `AuthService.refreshToken` with `credentials: "include"` to mint new access tokens). The backend also accepts **Personal Access Tokens (PATs)** as bearer tokens on the same header.

Backend package path: `server/auth` (`server/auth/authenticator.go`) — `Authenticator.AuthenticateToUser` resolves the bearer (access token via `AuthenticateByAccessTokenV2`, or PAT via `AuthenticateByPAT`) and falls back to the refresh-token cookie (`AuthenticateByRefreshToken`).
