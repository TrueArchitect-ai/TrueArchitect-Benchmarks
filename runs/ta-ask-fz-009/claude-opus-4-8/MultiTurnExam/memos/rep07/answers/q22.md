- **Dispatcher:** `APIV1Service.DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:15` (called from `CreateMemo`; it delegates to `dispatchMemoRelatedWebhook` with activity type `"memos.memo.created"`, which fetches the creator's webhooks via `Store.GetUserWebhooks` and calls `webhook.PostAsync` per hook)
- **Delivery package:** `internal/webhook` (`internal/webhook/webhook.go` — `PostAsync` / `Post` perform the HTTP POST)
- **Signing mechanism:** Standard Webhooks-style HMAC-SHA256. For each request with a signing secret, `Post` computes `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)`, base64-encodes it, and sends it as the `webhook-signature` header (prefixed `v1,`) alongside `webhook-id` (`msg_<uuid>`) and `webhook-timestamp` (`internal/webhook/webhook.go:133–145`). Secrets in the `whsec_<base64>` form are base64-decoded to the raw key via `resolveSigningKey` (`webhook.go:97`); no secret means no signature headers.
