Engine: Google CEL (`github.com/google/cel-go`) via the `internal/filter` package — the `Engine` type in `internal/filter/engine.go` (parser at `internal/filter/parser.go`, renderer at `internal/filter/render.go`).

Mechanism: The filter string is parsed as a CEL expression into a dialect-agnostic condition/IR tree (`internal/filter/ir.go`), then `Engine.CompileToStatement` (`internal/filter/engine.go:74`) renders that IR to a SQL `Statement` for the target dialect — selected via `RenderOptions.Dialect` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`, chosen from the active `Profile.Driver`) — so each backend gets dialect-specific SQL from the same parsed filter.
