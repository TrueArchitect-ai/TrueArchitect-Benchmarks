mechanism — The CEL filter expression is compiled once by the `filter.Engine` and then rendered to a dialect-specific SQL fragment + bind args by `Engine.CompileToStatement` / `filter.AppendConditions`, which each dialect's driver (`store/db/{sqlite,postgres,mysql}/memo.go`) calls with the matching `RenderOptions.Dialect` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) so the same expression emits e.g. `ILIKE $1` for Postgres, `LIKE ?` for MySQL, and `REGEXP ?`/`strftime(...)` for SQLite (render logic in `internal/filter/render.go`).
