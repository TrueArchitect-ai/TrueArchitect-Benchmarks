Engine: CEL (Google Common Expression Language, via `cel-go`) — `internal/filter/` (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`)

Mechanism: The CEL filter string is parsed and schema-validated against the memo environment (`parser.go`/`schema.go`), normalized into a dialect-agnostic IR (`ir.go`), then the renderer (`render.go`) walks the IR to emit a dialect-specific SQL fragment plus placeholder args — the `DialectName` (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`), chosen from `Profile.Driver`, controls dialect differences like JSON access, placeholders, and `LIKE` vs `ILIKE`.
