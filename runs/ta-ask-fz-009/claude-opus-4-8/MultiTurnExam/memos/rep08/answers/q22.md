Flow:

- HTTP delivery is performed by the **`internal/webhook`** package (`webhook.PostAsync` → the sender in `internal/webhook/webhook.go`).
- Signing: **HMAC-SHA256** over `msgID + "." + timestamp + "." + body`, keyed by the per-hook signing secret (whsec_-prefixed secrets are base64-decoded to raw key bytes). The result is sent as Standard-Webhooks headers `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64>` (`internal/webhook/webhook.go:142-149`). If no secret is set, no signature headers are added.
