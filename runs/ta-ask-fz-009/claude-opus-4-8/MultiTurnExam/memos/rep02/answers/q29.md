Token kinds:
- **Access Token (V2)** — short-lived JWT, sent as `Bearer` in the `Authorization` header (frontend `getAccessToken`; backend "AccessTokenV2")
- **Refresh Token** — long-lived, carried in an HTTP-only cookie (`credentials: "include"`), used to mint new access tokens via `AuthService.refreshToken`
- **Personal Access Token (PAT)** — long-lived programmatic token, also sent as `Bearer` (prefix-detected on the backend)
