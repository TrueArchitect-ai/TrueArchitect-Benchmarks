Engine: Google CEL (Common Expression Language), via `github.com/google/cel-go`, wrapped in the project's `internal/filter` package (engine at `internal/filter/engine.go:9,25`; CEL schema/env in `internal/filter/schema.go`; parser and dialect-aware SQL renderer in `internal/filter/parser.go` and `internal/filter/render.go`).

Mechanism: The RPC handler validates the CEL filter string (`server/router/api/v1/memo_service.go:211-215`) and stores it in `FindMemo.Filters`; each dialect driver then calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect{MySQL|Postgres|SQLite}, &where, &args)` (e.g. `store/db/mysql/memo.go:65-69`), where `internal/filter/render.go` compiles the parsed CEL AST into a dialect-specific parameterized `WHERE` clause plus bind args.
