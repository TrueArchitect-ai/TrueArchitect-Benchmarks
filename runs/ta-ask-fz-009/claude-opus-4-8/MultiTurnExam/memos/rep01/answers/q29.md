- Interceptor path: `web/src/connect.ts` — `authInterceptor` (defined line 156), applied to the shared Connect transport (line 188).
- Token kinds it manages: a short-lived **access token** (JWT) attached as `Authorization: Bearer <token>`, and a **refresh token** used to re-mint the access token on 401 / preflight expiry (via `refreshAuthClient.refreshToken` → `doRefreshAccessToken`, `web/src/connect.ts:74-83`). The refresh token itself is delivered as an HTTP cookie (`credentials: "include"`, line 60).
- Backend validation package: `server/auth` — the `Authenticator` (`server/auth/authenticator.go`), which validates Access Token V2 JWTs via `ParseAccessTokenV2` (`server/auth/token.go:220`), refresh tokens via `AuthenticateByRefreshToken`, and also `memos_pat_`-prefixed Personal Access Tokens (`AuthenticateByPAT`, hashed with `HashPersonalAccessToken`).
