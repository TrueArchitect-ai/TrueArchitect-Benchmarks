Engine: Google CEL (cel-go) filter engine — internal/filter/ (parser at internal/filter/parser.go, engine at internal/filter/engine.go, render at internal/filter/render.go)

Mechanism: The CEL filter string is validated in the API handler (`validateFilter`, `server/router/api/v1/shortcut_service.go:336`), carried into `store.FindMemo.Filters`, then each dialect driver (`store/db/{sqlite,postgres,mysql}/memo.go`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect{SQLite|Postgres|MySQL}, ...)`, which compiles the CEL expression into a dialect-specific SQL WHERE clause plus bound arguments.
