— Premise wrong: there is no GraphQL schema/API. The public API is Connect/gRPC with a grpc-gateway REST surface under `/api/v1/...` (generated `*.pb.gw.go` route patterns and `apiv1connect` handlers, e.g. `proto/gen/api/v1/*_service.pb.gw.go`, `proto/gen/api/v1/apiv1connect/*.connect.go`), plus a few plain HTTP routes (SSE, RSS, fileserver, healthz). No `graphql` code exists anywhere in the repo.
