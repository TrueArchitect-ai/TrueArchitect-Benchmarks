Premise correction: there is no Redis connection or Redis-backed cache. The cache layer is an in-process, `sync.Map`-based `cache.Cache` (`store/cache/cache.go:67-84`), instantiated for users by `store.New` (`store/store.go:37-53`). User entries are written with `userCache.Set` (`store/user.go:98,122,132,143,167`), which applies the configured default TTL of **10 minutes** (`store/cache/cache.go:92-95`; configuration at `store/store.go:40-43`).
