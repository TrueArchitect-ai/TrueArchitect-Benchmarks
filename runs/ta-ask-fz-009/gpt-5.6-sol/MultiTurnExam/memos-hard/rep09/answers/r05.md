There is no GraphQL schema or GraphQL API. The public API contract is defined with Protocol Buffers under `proto/api/v1/`; RPC methods carry `google.api.http` annotations that expose REST-style `/api/v1` routes—for example, `MemoService` in `proto/api/v1/memo_service.proto:17-49`. The server publishes these through gRPC-Gateway and Connect handlers in `server/router/api/v1/v1.go:64-98`.
