Premise correction: there is no GraphQL schema or GraphQL API. The public API contract is defined with Protocol Buffers under `proto/api/v1/*.proto`; RPCs use `google.api.http` annotations to expose REST endpoints—for example, `MemoService` in `proto/api/v1/memo_service.proto:17-45`. The server registers these services through gRPC-Gateway at `/api/v1/*` and also exposes Connect RPC handlers (`server/router/api/v1/v1.go:95-145`).
