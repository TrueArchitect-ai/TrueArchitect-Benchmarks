Premise correction: this repository does **not** register per-user API rate-limiting middleware, so there are no per-user request limits.

- Global Echo middleware includes only recovery and CORS (`server/server.go:50-52`).
- The API gateway registers authentication middleware, not rate limiting (`server/router/api/v1/v1.go:64-98`).
- Connect handlers use metadata, logging, recovery, and authorization interceptors only (`server/router/api/v1/v1.go:131-144`).

The rate-limiting example in `internal/email/README.md:286-295` is documentation for email abuse prevention, not registered API middleware.
