**Premise correction:** There is no GraphQL schema or GraphQL API in this repository.

**Actual API surface:** The public API is defined as protobuf/gRPC services under `proto/api/v1/*.proto`, with `google.api.http` annotations exposing REST/JSON endpoints under `/api/v1`. For example:

- `proto/api/v1/memo_service.proto:17-35` defines `MemoService` and routes such as `POST /api/v1/memos` and `GET /api/v1/memos`.
- `proto/api/v1/auth_service.proto:13-44` defines authentication routes.
- Other service contracts are in `proto/api/v1/ai_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, and `user_service.proto`.

The generated HTTP gateway bindings live in `proto/gen/api/v1/*.pb.gw.go`. There are also non-protobuf HTTP routes, including SSE at `server/router/api/v1/sse_handler.go:25`.
