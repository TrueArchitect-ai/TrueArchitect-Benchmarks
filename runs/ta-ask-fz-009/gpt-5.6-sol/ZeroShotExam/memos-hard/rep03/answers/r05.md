**Premise correction:** There is no GraphQL schema or GraphQL API in this repository; no GraphQL definitions were found.

**Actual API surface:** The public API is a protobuf-defined gRPC service surface exposed as REST/JSON through Google HTTP annotations and generated gateway code. Its source contracts are under `proto/api/v1/*.proto`. For example, `MemoService` is defined in `proto/api/v1/memo_service.proto:17`, with REST routes attached to RPCs via `google.api.http`, such as `POST /api/v1/memos` at `proto/api/v1/memo_service.proto:21-25` and `GET /api/v1/memos` at `proto/api/v1/memo_service.proto:29-31`. Generated gateway bindings live under `proto/gen/api/v1/*.pb.gw.go`.
