**Premise correction:** The cache layer does not use Redis, so there is no Redis connection to configure.

**Actual mechanism:** `Store.New` creates process-local, in-memory caches—including `userCache`—with `cache.New(cacheConfig)` (`store/store.go:37-53`). The implementation is backed by Go’s `sync.Map` (`store/cache/cache.go:66-73`).

User entries are written with `Set`, which applies the configured default TTL (`store/user.go:92-99`, `store/cache/cache.go:92-95`). That TTL is **10 minutes** (`store/store.go:39-45`).
