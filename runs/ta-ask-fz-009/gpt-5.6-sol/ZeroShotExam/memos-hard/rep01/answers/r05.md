**Premise correction:** The public API is not GraphQL, so there is no GraphQL schema defining it.

**Actual API surface:** It is a protobuf-defined API exposed as HTTP/JSON through gRPC-Gateway. Service contracts, messages, and `google.api.http` route mappings live in `proto/api/v1/*.proto`, including:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`

The generated HTTP gateway bindings are under `proto/gen/api/v1/*_service.pb.gw.go`. There is also a separate SSE endpoint registered in `server/router/api/v1/sse_handler.go:25`.
