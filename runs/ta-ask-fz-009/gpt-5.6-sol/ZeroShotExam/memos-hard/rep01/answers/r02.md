**Premise correction:** This repository does not register per-user API rate-limiting middleware, so there are no per-user request limits.

The global Echo middleware only registers recovery and CORS (`server/server.go:50-52`). API v1 registers authentication middleware/interceptors, request-body size limits, logging, and recovery—but no rate limiter (`server/router/api/v1/v1.go:95-98`, `server/router/api/v1/v1.go:126-144`). The `256 MiB` value there is a maximum request-body size, not a request-rate limit (`server/router/api/v1/v1.go:20`).
