**Premise correction:** There is no Redis connection for the cache layer. The store creates an in-process, thread-safe memory cache backed by `sync.Map` (`store/cache/cache.go:66-73`), instantiated for users in `Store.New` (`store/store.go:37-53`).

**Actual mechanism:** User records are inserted with `userCache.Set` (`store/user.go:92-99`), which applies the cache’s default TTL (`store/cache/cache.go:92-95`). That TTL is configured as **10 minutes** in `store/store.go:39-45`; entries expire at insertion time plus that duration (`store/cache/cache.go:97-114`).
