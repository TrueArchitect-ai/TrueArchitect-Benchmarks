**Premise correction:** This repository does not define a GraphQL schema. Its public API is protobuf/gRPC-based and exposed as REST through `google.api.http` annotations.

**Actual API surface:** The source definitions are the service `.proto` files under `proto/api/v1/`, including `memo_service.proto`, `user_service.proto`, `auth_service.proto`, and the other `*_service.proto` files. For example, `MemoService` and its REST routes are defined in `proto/api/v1/memo_service.proto:17-48`. Generated HTTP gateway bindings live under `proto/gen/api/v1/*.pb.gw.go`. Additional non-protobuf HTTP routes are registered in files such as `server/router/api/v1/sse_handler.go:25`, `server/router/rss/rss.go:72`, and `server/server.go:44`.
