**Premise correction:** this repository does not register per-user API rate-limiting middleware, so there are no per-user request-count limits.

The global Echo middleware only registers recovery and CORS (`server/server.go:50-52`). API v1 registers authentication middleware/interceptors, logging, and recovery—no rate limiter (`server/router/api/v1/v1.go:64-98`, `server/router/api/v1/v1.go:131-144`).

The API does enforce a **256 MiB maximum request-body size**, but that is a payload-size limit, not a request-rate limit (`server/router/api/v1/v1.go:20`, `server/router/api/v1/v1.go:126-144`). The “10 emails per second” limiter is only documentation example code, not registered middleware (`internal/email/README.md:286-296`).
