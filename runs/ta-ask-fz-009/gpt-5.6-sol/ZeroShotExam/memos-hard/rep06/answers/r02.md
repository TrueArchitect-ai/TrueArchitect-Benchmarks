Premise correction: this repository does **not register per-user API rate-limiting middleware**, so there are no per-user request-count or time-window limits to report.

The global Echo stack registers only recovery and CORS middleware (`server/server.go:50-52`). The API gateway registers authentication middleware (`server/router/api/v1/v1.go:64-98`), while Connect registers metadata, logging, recovery, and authentication interceptors (`server/router/api/v1/v1.go:131-138`).

There is a **request-size limit**, not a rate limit: API requests are capped at **256 MiB** via `maxAPIRequestBytes` (`server/router/api/v1/v1.go:20`, `server/router/api/v1/v1.go:126-144`).
