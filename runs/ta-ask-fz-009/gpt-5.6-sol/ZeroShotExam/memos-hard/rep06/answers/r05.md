**Premise correction:** There is no GraphQL schema or GraphQL API in this repository; `GraphQL` is a certified miss across the indexed codebase.

**Actual API surface:** The public API is a protobuf-defined gRPC API exposed as REST/JSON through grpc-gateway. Its source contracts are under `proto/api/v1/*.proto`, with HTTP routes declared using `google.api.http` annotations—for example `proto/api/v1/attachment_service.proto:16-26` and `proto/api/v1/auth_service.proto:17-26`. Generated gateway bindings live under `proto/gen/api/v1/*.pb.gw.go`. Additional public HTTP routes include SSE at `server/router/api/v1/sse_handler.go:25` and RSS at `server/router/rss/rss.go:72,111`.
