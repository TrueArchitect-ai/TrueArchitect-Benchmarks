**Premise correction:** There is no GraphQL schema or GraphQL API in this repository; the code graph has a certified miss for “GraphQL.”

**Actual API surface:** The public API is gRPC/Protocol Buffers exposed as REST/JSON through Google HTTP annotations. Its source definitions are the service files under `proto/api/v1/*.proto`, for example:

- Memo API: `proto/api/v1/memo_service.proto`
- User API: `proto/api/v1/user_service.proto`
- Auth API: `proto/api/v1/auth_service.proto`
- Attachment API: `proto/api/v1/attachment_service.proto`
- Shared messages: `proto/api/v1/common.proto`

For example, REST bindings are declared directly with `google.api.http` in `proto/api/v1/attachment_service.proto:15-20` and `proto/api/v1/auth_service.proto:13-18`. Generated gateway routing lives under `proto/gen/api/v1/*.pb.gw.go`. Additional non-Protobuf HTTP endpoints include SSE (`server/router/api/v1/sse_handler.go:25`), RSS (`server/router/rss/rss.go:72`), and health (`server/server.go:44`).
