**Premise correction:** there is no Redis connection to configure. The cache layer is an in-process, thread-safe memory cache backed by `sync.Map` (`store/cache/cache.go:66-73`), and the store creates separate instances for users and settings (`store/store.go:47-53`).

**Actual mechanism:** user records are written through `userCache.Set(...)` (`store/user.go:98`, `store/user.go:122`, `store/user.go:132`, `store/user.go:143`, `store/user.go:167`). `Set` applies the configured default TTL (`store/cache/cache.go:92-95`), which is **10 minutes** in the store configuration (`store/store.go:39-45`). Expired entries are rejected on read and periodically cleaned every five minutes (`store/cache/cache.go:123-146`, `store/store.go:42`).
