**Premise correction:** This repository does not register per-user API rate-limiting middleware, so there are no per-user request limits.

The server globally registers only recovery and CORS middleware (`server/server.go:50-52`). The API gateway adds authentication middleware, while Connect registers metadata, logging, recovery, and authentication interceptors—none implement rate limiting (`server/router/api/v1/v1.go:64-98`, `server/router/api/v1/v1.go:131-141`).
