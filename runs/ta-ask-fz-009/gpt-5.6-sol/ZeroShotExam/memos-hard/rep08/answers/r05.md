**Premise correction:** There is no GraphQL schema or GraphQL API in this repository; the code graph has a certified miss for “GraphQL.”

**Actual API surface:** The public API is protobuf/gRPC-defined and exposed as REST/JSON through `google.api.http` annotations and generated gateway bindings. Source definitions live under `proto/api/v1/*.proto`; for example, `AIService` and its REST route are defined in `proto/api/v1/ai_service.proto:11-16`, while attachment endpoints begin in `proto/api/v1/attachment_service.proto:15-20`. Generated HTTP bindings are under `proto/gen/api/v1/*.pb.gw.go`.

Additional non-protobuf HTTP routes include SSE (`server/router/api/v1/sse_handler.go:25`), RSS (`server/router/rss/rss.go:72`, `server/router/rss/rss.go:111`), file/avatar serving (`server/router/fileserver/fileserver.go:132`, `server/router/fileserver/fileserver.go:168`), and health (`server/server.go:44`).
