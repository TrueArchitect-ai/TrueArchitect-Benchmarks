Premise correction: there is no GraphQL schema or GraphQL API in this repository.

The public API is defined as protobuf/gRPC services in `proto/api/v1/*.proto`, with REST endpoints declared through `google.api.http` annotations. For example, `MemoService` and its `/api/v1/memos` routes are defined in `proto/api/v1/memo_service.proto:17-48`. The generated HTTP gateway is under `proto/gen/api/v1/*.pb.gw.go`; non-generated routes include SSE in `server/router/api/v1/sse_handler.go:25`.

So the actual public API surface is a REST/JSON API under `/api/v1`, generated from protobuf service definitions—not GraphQL.
