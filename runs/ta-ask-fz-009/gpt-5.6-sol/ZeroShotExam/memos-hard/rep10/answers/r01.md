**Premise correction:** There is no Redis connection for the cache layer. The store uses process-local, thread-safe memory caches backed by `sync.Map` (`store/cache/cache.go:66-73`).

**Actual mechanism:** `store.New` constructs the user cache with a default TTL of **10 minutes** (`store/store.go:37-53`). User writes call `userCache.Set(...)` (`store/user.go:92-99`, `126-144`), which applies that default TTL (`store/cache/cache.go:92-95`). Thus, user entries expire **10 minutes after being cached**.
