**Premise correction:** This repository does not define a GraphQL schema; the code map has a certified miss for GraphQL symbols.

**Actual API surface:** The public API is defined as Protocol Buffers services under `proto/api/v1/*.proto`. RPC methods use `google.api.http` annotations to expose REST/JSON endpoints—for example, `MemoService` and `/api/v1/memos` in `proto/api/v1/memo_service.proto:17-30`, and authentication endpoints in `proto/api/v1/auth_service.proto:13-42`.

These definitions generate Go/gRPC, Connect, gRPC-Gateway, OpenAPI, and TypeScript artifacts via `proto/buf.gen.yaml:10-29`. Additional hand-written HTTP surfaces include SSE (`server/router/api/v1/sse_handler.go:25`), RSS (`server/router/rss/rss.go:72`), file serving (`server/router/fileserver/fileserver.go:132`), and health checks (`server/server.go:44`).
