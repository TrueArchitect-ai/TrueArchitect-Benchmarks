**Premise correction:** There is no Redis connection for the cache layer. The store constructs process-local, thread-safe memory caches backed by `sync.Map` (`store/cache/cache.go:66-73`); the user cache is instantiated in `Store.New` (`store/store.go:37-53`).

**Actual mechanism:** User records are inserted with `userCache.Set(...)` (`store/user.go:92-99`), which applies the cache’s default TTL (`store/cache/cache.go:92-95`).
