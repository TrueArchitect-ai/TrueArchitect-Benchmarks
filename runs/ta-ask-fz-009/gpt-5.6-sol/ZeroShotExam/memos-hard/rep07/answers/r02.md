Premise correction: this repository does **not** register per-user API rate-limiting middleware, so it defines no per-user request-count or time-window limits.

The global Echo middleware registered in `server.NewServer` is only recovery and CORS (`server/server.go:50-53`). API gateway middleware handles authentication/authorization (`server/router/api/v1/v1.go:64-98`), while Connect uses metadata, logging, recovery, and auth interceptors (`server/router/api/v1/v1.go:131-138`).

The only API-wide “limit” is request **body size**, not request rate: `maxAPIRequestBytes = 256 << 20` (256 MiB), applied to Gateway and Connect handlers (`server/router/api/v1/v1.go:20`, `server/router/api/v1/v1.go:126-144`).
