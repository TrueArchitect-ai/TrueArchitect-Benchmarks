Premise incorrect: there is no GraphQL public API schema. The public API is protobuf-defined gRPC/Connect plus gRPC-Gateway HTTP routes: services are registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64-122`), with HTTP route mappings generated from the API protobufs (for example, memo routes at `proto/gen/api/v1/memo_service.pb.gw.go:1745`).
