There is no Redis connection or Redis configuration in this cache layer. It is a process-local, `sync.Map`-backed cache (`store/cache/cache.go:66-84`), instantiated for users by `Store.New` (`store/store.go:37-53`).

User entries use the cache’s default **10-minute TTL**: `userCache.Set(...)` uses `Cache.Set`, which applies `Config.DefaultTTL` (`store/user.go:98,122,132,143,167`; `store/cache/cache.go:92-95`); `Store.New` sets that TTL to `10 * time.Minute` (`store/store.go:40-45`). Expired entries are removed on read or by a five-minute cleanup loop (`store/cache/cache.go:135-146,199-215`).
