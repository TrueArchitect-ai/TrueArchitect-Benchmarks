There is no GraphQL schema in this repository. The public API is protobuf-defined gRPC services, exposed as REST through the gRPC-Gateway and as Connect RPC for browser clients: the gateway registers the API v1 service handlers and mounts them at `/api/v1/*` in `server/router/api/v1/v1.go:95-129`; Connect handlers are mounted at `/memos.api.v1.*` in `server/router/api/v1/v1.go:131-145`. Generated REST route definitions are in `proto/gen/api/v1/*_service.pb.gw.go` (for example, memo routes in `proto/gen/api/v1/memo_service.pb.gw.go`).
