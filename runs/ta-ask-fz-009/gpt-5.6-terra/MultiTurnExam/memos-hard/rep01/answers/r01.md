There is no Redis connection to configure: the cache layer is an in-process, `sync.Map`-backed memory cache (`store/cache/cache.go:66-85`), instantiated three times by `store.New` (`store/store.go:37-60`).

User entries use the shared default TTL of **10 minutes**: user writes call `userCache.Set` without an override (`store/user.go:92-99,126-145`), `Set` applies `config.DefaultTTL` (`store/cache/cache.go:92-95`), and the store config sets that to 10 minutes (`store/store.go:39-45`).
