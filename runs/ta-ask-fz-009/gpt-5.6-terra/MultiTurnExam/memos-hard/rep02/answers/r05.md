There is **no GraphQL schema** in this repository. The public API is defined as Protocol Buffer service contracts under `proto/api/v1/`—for example, `proto/api/v1/memo_service.proto:17` defines `MemoService` and its HTTP mappings such as `POST /api/v1/memos` at `proto/api/v1/memo_service.proto:21`–`25`.
