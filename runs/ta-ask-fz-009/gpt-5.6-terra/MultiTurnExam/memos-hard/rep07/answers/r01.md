There is **no Redis connection** to configure: the cache layer is an in-process `sync.Map` cache, created with `cache.New`, not a Redis client (`store/cache/cache.go:66-85`). No Redis dependency is declared in `go.mod`.

Actual mechanism: `Store.New` constructs `userCache` with `cache.Config{DefaultTTL: 10 * time.Minute, CleanupInterval: 5 * time.Minute}` (`store/store.go:37-53`). User entries are inserted through `userCache.Set`, which applies that default TTL (`store/user.go:98,122,132,143,167`; `store/cache/cache.go:92-114`). Thus user entries have a **10-minute TTL**; expired entries are rejected on read and are also periodically cleaned every five minutes (`store/cache/cache.go:122-146,199-249`).
