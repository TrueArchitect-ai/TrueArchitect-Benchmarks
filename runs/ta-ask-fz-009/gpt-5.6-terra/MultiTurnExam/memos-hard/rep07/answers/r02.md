There is **no per-user API rate-limiting middleware registered**, so this repository defines no per-user request-rate or burst limits. The server’s global Echo middleware chain registers only recovery and CORS (`server/server.go:50-53`); API registration adds authorization middleware and request-body-size limits, not rate limiting (`server/router/api/v1/v1.go:64-128,139-145`).

The relevant configured limits are **request size**, not rate:
- gRPC-Gateway requests are wrapped with `http.MaxBytesHandler` (`server/router/api/v1/v1.go:126-128`).
- Connect requests use `connect.WithReadMaxBytes` and `http.MaxBytesHandler` (`server/router/api/v1/v1.go:139-145`).
- Attachment upload size is governed by the instance storage setting, defaulting to a 32 MiB in-memory buffer when unset (`server/router/api/v1/attachment_service.go:24-27,119-125`).
