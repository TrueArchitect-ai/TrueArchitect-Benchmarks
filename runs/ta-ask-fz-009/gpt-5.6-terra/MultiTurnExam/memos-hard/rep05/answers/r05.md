There is **no GraphQL schema or GraphQL public API** in this repository. The public API is protobuf-defined gRPC services exposed through gRPC-Gateway/Connect: the server registers the gateway and generated service handlers in `server/router/api/v1/v1.go:64-115`, and the resulting REST surface is under `/api/v1` (for example, memo endpoints in `proto/gen/api/v1/memo_service.pb.gw.go:1745`).
