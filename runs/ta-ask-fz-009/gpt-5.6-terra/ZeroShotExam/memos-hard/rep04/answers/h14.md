**computation site;** `memopayload.RebuildMemoPayload` parses `memo.Content` through `MarkdownService.ExtractAll`, then writes the derived tag list and property object into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:74-87`). The extractor itself is `markdown.service.ExtractAll` (`internal/markdown/markdown.go:355-421`).

**triggers;** memo creation always rebuilds the payload before persistence (`server/router/api/v1/memo_service.go:70-115`); memo update rebuilds it only when the update mask includes `content` (`server/router/api/v1/memo_service.go:435-451`); and the payload runner’s `RunOnce` batch-rebuilds every stored memo, then persists each payload (`server/runner/memopayload/runner.go:26-72`).

**extracted properties;** tags (deduplicated, case preserved) and mentions (deduplicated, normalized lowercase), plus list/preview properties: whether the content contains links, code blocks/fenced code/inline code, task checkboxes, and unchecked tasks; and the title when the first document-level block is an H1 (`internal/markdown/markdown.go:376-421`).
