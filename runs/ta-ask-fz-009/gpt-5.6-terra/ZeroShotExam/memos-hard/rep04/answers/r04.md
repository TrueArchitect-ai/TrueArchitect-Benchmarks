**Premise correction:** webhook delivery workers consume from neither NATS nor RabbitMQ. There is no external message-broker boundary here.

**Actual mechanism:** `internal/webhook/webhook.go:39` declares an in-process buffered Go channel:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

The package `init` starts four goroutines that consume that channel and invoke `Post` for each payload (`internal/webhook/webhook.go:42-54`). `PostAsync` enqueues payloads non-blockingly (`internal/webhook/webhook.go:182-195`), dropping them when the 128-item buffer is full.
