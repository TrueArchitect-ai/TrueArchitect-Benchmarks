**Premise correction:** the public API is not defined as a GraphQL schema. This repository exposes a versioned REST/HTTP API generated from Protocol Buffer service contracts.

**Actual API surface:** the source-of-truth contracts are the `.proto` files under `proto/api/v1/`, where each RPC carries a `google.api.http` mapping—for example, `AttachmentService` in `proto/api/v1/attachment_service.proto:15` maps operations such as `GET /api/v1/attachments` (`:25-26`), and `MemoService` is defined in `proto/api/v1/memo_service.proto:17` with mappings such as `GET /api/v1/memos` (`:28-30`).

The generated HTTP gateway bindings are in `proto/gen/api/v1/*.pb.gw.go` (for example, memo routes in `proto/gen/api/v1/memo_service.pb.gw.go:1745`).
