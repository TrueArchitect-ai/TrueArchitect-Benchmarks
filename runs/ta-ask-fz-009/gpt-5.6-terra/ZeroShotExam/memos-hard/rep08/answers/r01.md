**Premise correction:** there is no Redis connection or Redis-backed cache layer configured in this repository. The cache boundary is process-local, implemented with `sync.Map` in `store/cache/cache.go` (the cache is explicitly described as in-memory at `store/cache/cache.go:66`).

**Actual mechanism:** `store.New` creates the user cache with an in-memory `cache.Config` in `store/store.go:37-53`. User entries are written through `s.userCache.Set(...)` (for example, `store/user.go:98`) and therefore use the configured default TTL: **10 minutes** (`store/store.go:40-45`; equivalently the cache default in `store/cache/cache.go:56-63`). Each entry’s expiration is set to `time.Now().Add(ttl)` in `store/cache/cache.go:97-114`.
