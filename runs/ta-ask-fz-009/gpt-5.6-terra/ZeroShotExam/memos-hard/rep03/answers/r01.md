**Premise correction:** this cache layer does **not** configure or connect to Redis. It is an in-process, thread-safe memory cache backed by `sync.Map` (`store/cache/cache.go:66-73`), so there is no Redis connection string, client, or external cache endpoint to configure.

**Actual mechanism:** `store.New` constructs the user cache from a shared `cache.Config` in `store/store.go:37-53`. That configuration sets `DefaultTTL` to **10 minutes** (`store/store.go:40-45`), and user records are inserted through `userCache.Set(...)` (`store/user.go:98`, `store/user.go:122`, `store/user.go:132`, `store/user.go:143`, `store/user.go:167`). `Set` applies the configured default TTL (`store/cache/cache.go:92-95`), so user entries expire **10 minutes after insertion**.
