Explicit Go code; user-owned emoji reactions are deleted within the user-deletion transaction.

Evidence locations: `store/db/mysql/user_delete.go:92` (`deleteUserTargetsTx`) explicitly calls `deleteReactionsByCreatorTx`; the same deletion boundary also removes reactions on content being deleted via `deleteReactionsByContentIDsTx`. The equivalent PostgreSQL and SQLite implementations make the same explicit calls in `store/db/postgres/user_delete.go:92` and `store/db/sqlite/user_delete.go:92`, respectively. This is invoked by each driver’s `DB.DeleteUser` implementation (for example, `store/db/mysql/user_delete.go:29`), not established as a database-level cascade rule.
