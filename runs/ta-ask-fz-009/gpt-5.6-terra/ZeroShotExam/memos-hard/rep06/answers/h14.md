**computation site:** `memopayload.RebuildMemoPayload` parses `memo.Content` through `MarkdownService.ExtractAll` and stores the resulting tags and property object in `memo.Payload` (`server/runner/memopayload/runner.go:74-87`). This is derived server-side payload, not user-set fields.

**triggers:** It runs when a memo is created (`server/router/api/v1/memo_service.go:101-115`), when an update includes the `content` field (`server/router/api/v1/memo_service.go:435-451`), and during the payload runner’s full batched rebuild of existing memos (`server/runner/memopayload/runner.go:26-72`).

**extracted properties:** The Markdown extractor produces deduplicated `#tags` (excluding tags inside links/images) (`internal/markdown/markdown.go:142-169`) plus properties: first H1 heading text as `Title`, presence of links, code (blocks/fenced blocks/inline spans), task lists, and incomplete tasks (`internal/markdown/markdown.go:192-240`).
