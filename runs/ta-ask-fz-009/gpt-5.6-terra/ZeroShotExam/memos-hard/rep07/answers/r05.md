**Premise correction:** this repository does not define a GraphQL schema for its public API. The public contract is REST/HTTP generated from Protocol Buffer service definitions; a repository-wide `graphql` search found no matches.

**Actual API surface:** versioned `/api/v1` HTTP endpoints are generated into `proto/gen/api/v1/*_service.pb.gw.go` (for example, memo routes in `proto/gen/api/v1/memo_service.pb.gw.go:1745` and user routes in `proto/gen/api/v1/user_service.pb.gw.go:2301`). Their source-of-truth service contracts are the `.proto` files under `proto/api/v1/`, including:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`

Additional public HTTP surfaces include SSE at `GET /api/v1/sse` in `server/router/api/v1/sse_handler.go:25`, plus RSS, file, and health endpoints.
