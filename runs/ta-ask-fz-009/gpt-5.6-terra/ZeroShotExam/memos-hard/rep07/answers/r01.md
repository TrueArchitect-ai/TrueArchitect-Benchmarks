**Premise correction:** this repository does not configure a Redis connection for its cache layer. The cache boundary is process-local, in-memory Go state; no Redis dependency or connection configuration is present.

**Actual mechanism:** `Store.New` constructs `userCache` with `cache.New(cacheConfig)` in `store/store.go:37-53`. The cache uses `sync.Map` rather than a network client (`store/cache/cache.go:66-73`) and applies its configured default TTL when `Set` is called (`store/cache/cache.go:92-95`). User entries are written with that default setter in `store/user.go:98`, `store/user.go:122`, and `store/user.go:167`.

The user-entry TTL is **10 minutes**, configured in `store/store.go:40-45` (also the cache package default in `store/cache/cache.go:56-64`).
