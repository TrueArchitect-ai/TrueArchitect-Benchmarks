**computation site:** `memopayload.RebuildMemoPayload` parses `memo.Content` through `MarkdownService.ExtractAll` and writes the derived values into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:74-87`). The extractor is `internal/markdown.(*service).ExtractAll` (`internal/markdown/markdown.go:355-421`).

**triggers:** Memo creation invokes the rebuild before persistence (`server/router/api/v1/memo_service.go:84-115`); an update invokes it only when the update mask includes `content` (`server/router/api/v1/memo_service.go:433-451`); and the payload runner can rebuild every stored memo in batches, then persist each payload (`server/runner/memopayload/runner.go:26-72`).

**extracted properties:** It stores deduplicated `#tags` (excluding tags inside links/images) and a property record: title from the first top-level H1; whether the content has links, code blocks/fenced blocks/inline code, a task list, or incomplete tasks (`internal/markdown/markdown.go:376-419`). `ExtractAll` also derives normalized, deduplicated `@mentions`, but `RebuildMemoPayload` does **not** store those in the memo payload (`internal/markdown/markdown.go:379-380`, `server/runner/memopayload/runner.go:85-86`).
