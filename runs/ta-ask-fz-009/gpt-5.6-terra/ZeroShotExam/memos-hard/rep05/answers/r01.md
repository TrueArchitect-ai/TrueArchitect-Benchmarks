**Premise correction:** this repository does **not** configure a Redis connection for its cache layer. Redis is not a dependency or cache implementation here.

**Actual mechanism:** user records use the process-local, thread-safe `cache.Cache`, backed by `sync.Map`, initialized with the default cache configuration. `store.User` operations insert and refresh entries through `s.userCache.Set(...)` in `store/user.go:92-168`; reads by user ID consult that cache first at `store/user.go:148-156`.

The default TTL is **10 minutes**: `cache.DefaultConfig()` sets `DefaultTTL: 10 * time.Minute` in `store/cache/cache.go:56-64`, and `Cache.Set` applies that TTL via `SetWithTTL` in `store/cache/cache.go:92-95`. Cache entries expire at `time.Now().Add(ttL)` in `store/cache/cache.go:97-114`.
