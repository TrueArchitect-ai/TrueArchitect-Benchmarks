**Premise correction:** this repository does not define a public GraphQL schema. Its public API boundary is REST/HTTP, generated from Protocol Buffer service contracts.

**Actual API surface:** the `/api/v1` services are defined in `proto/api/v1/*.proto`, including `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, and related service contracts. The generated HTTP gateway exposes them as REST routes in `proto/gen/api/v1/*_service.pb.gw.go`—for example, memo endpoints are generated in `proto/gen/api/v1/memo_service.pb.gw.go:1745`, user endpoints in `proto/gen/api/v1/user_service.pb.gw.go:2301`, and authentication endpoints in `proto/gen/api/v1/auth_service.pb.gw.go:331`.
