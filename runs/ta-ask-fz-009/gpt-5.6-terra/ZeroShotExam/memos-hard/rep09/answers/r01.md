**Premise correction:** this repository does not configure a Redis connection for its cache layer. The cache implementation is an in-process, thread-safe memory cache (`store/cache/cache.go`), instantiated by `store.New` rather than backed by Redis.

**Actual mechanism:** `store.New` defines a shared `cache.Config` and creates `userCache` with it (`store/store.go:40-53`). Its `DefaultTTL` is **10 minutes** (`store/store.go:41`). User entries written through the cache’s normal `Set` path receive that configured default TTL (`store/cache/cache.go:92-94`).
