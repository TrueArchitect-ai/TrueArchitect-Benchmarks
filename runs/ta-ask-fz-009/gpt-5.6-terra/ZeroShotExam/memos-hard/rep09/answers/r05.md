**Premise correction:** this repository does not define a GraphQL schema for its public API. No GraphQL files were found, and “graphql” has no matches in the repository.

**Actual API surface:** the public API is a REST/HTTP API under `/api/v1`, generated from Protocol Buffer service contracts in `proto/api/v1/`—for example, `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, and `proto/api/v1/auth_service.proto`. The corresponding HTTP gateway bindings are generated in `proto/gen/api/v1/*.pb.gw.go` (for example, `proto/gen/api/v1/memo_service.pb.gw.go:1745`), exposing routes such as `GET/POST /api/v1/memos` and `POST /api/v1/auth/signin`.
