**Premise correction:** this repository does **not** configure a Redis connection for its cache layer. The cache is an in-process, thread-safe memory cache backed by `sync.Map`; there is no Redis dependency or Redis configuration present.

**Actual mechanism:** `store.New` constructs `userCache` with `cache.New(cacheConfig)` in `store/store.go:37-53`. The cache implementation stores items in `sync.Map` and calculates expiration locally as `time.Now().Add(ttl)` in `store/cache/cache.go:66-73` and `store/cache/cache.go:98-114`.

User entries are written through `userCache.Set(...)` (for example, `store/user.go:92-99` and `store/user.go:126-145`). `Set` applies the configured default TTL (`store/cache/cache.go:92-95`), which is **10 minutes** for the store cache configuration (`store/store.go:39-45`).
