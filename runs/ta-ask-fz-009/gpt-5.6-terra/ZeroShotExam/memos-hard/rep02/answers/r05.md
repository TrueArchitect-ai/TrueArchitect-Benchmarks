**Premise correction:** this repository’s public API is not defined by a GraphQL schema. It exposes a REST/HTTP API, with generated gateway routes under `/api/v1`; the route surface includes operations such as `GET/POST /api/v1/memos`, `GET /api/v1/users`, and auth endpoints. Generated route bindings are in `proto/gen/api/v1/*.pb.gw.go` (for example, `proto/gen/api/v1/memo_service.pb.gw.go:1745`).

**Actual API surface:** the public API contract is defined as Protocol Buffer service schemas in `proto/api/v1/`, including:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
