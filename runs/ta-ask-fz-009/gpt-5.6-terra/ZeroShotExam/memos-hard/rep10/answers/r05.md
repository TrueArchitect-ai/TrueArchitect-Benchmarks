**Premise correction:** this repository does not define a GraphQL public API schema. The public API is a versioned REST surface generated from Protocol Buffers, not GraphQL.

**Actual API surface:** service contracts and HTTP mappings are defined in `proto/api/v1/*.proto`, using `service`/`rpc` declarations and `google.api.http` options—for example, `MemoService` begins at `proto/api/v1/memo_service.proto:17` and maps `CreateMemo` to `POST /api/v1/memos` at `proto/api/v1/memo_service.proto:21-25`. The generated REST gateway is under `proto/gen/api/v1/*.pb.gw.go` (for example, memo routes at `proto/gen/api/v1/memo_service.pb.gw.go:1745`).
