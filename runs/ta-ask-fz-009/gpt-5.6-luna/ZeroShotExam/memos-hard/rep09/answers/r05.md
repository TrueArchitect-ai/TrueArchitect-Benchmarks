**Premise correction:** This repository does not define a GraphQL schema. The GraphQL search is a certified miss. The public API is defined as Protocol Buffer services with HTTP bindings in:

- `proto/api/v1/*.proto`
- For example, `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, and `proto/api/v1/auth_service.proto`

**Actual API surface:** The `.proto` files define the service and RPC contracts, using `google.api.http` annotations for REST routes. Those bindings are generated into:

- `proto/gen/api/v1/*.pb.gw.go`

The primary public API is the REST-style `/api/v1/...` surface—for example, memo, user, authentication, attachment, and instance endpoints. Additional public routes include:

- SSE: `server/router/api/v1/sse_handler.go`
- RSS: `server/router/rss/rss.go`
- Health check: `server/server.go`
