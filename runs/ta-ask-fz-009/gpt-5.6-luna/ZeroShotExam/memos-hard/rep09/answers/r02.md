**Premise correction:** No per-user API rate-limiting middleware is registered in this repository, so there are no per-user request limits to report.

The registered HTTP middleware is limited to:

- `middleware.Recover()` and CORS in `server/server.go:50-52`.
- Authentication/authorization middleware for the gRPC-Gateway in `server/router/api/v1/v1.go:68-98`.
- Authentication interceptors for Connect handlers in `server/router/api/v1/v1.go:131-144`.

The API does enforce a maximum request **body size** via `maxAPIRequestBytes` in `server/router/api/v1/v1.go:126-129` and `141-144`, but that is not request-rate limiting.
