**Premise correction:** The cache layer is not backed by Redis; no Redis connection is configured in this repository.

**Actual mechanism:** `store.New` creates three process-local in-memory caches with `cache.New(cacheConfig)`—including `userCache`—in `store/store.go:37-53`. The cache implementation uses a `sync.Map` and per-entry expiration timestamps in `store/cache/cache.go:34-38,66-73`.

User entries use the default TTL of **10 minutes**, configured in `store/store.go:39-45` and applied by `Cache.Set` in `store/cache/cache.go:92-95`. User records are stored in that cache on create, update, list, and lookup paths in `store/user.go:92-99,126-133,136-145,148-168`.
