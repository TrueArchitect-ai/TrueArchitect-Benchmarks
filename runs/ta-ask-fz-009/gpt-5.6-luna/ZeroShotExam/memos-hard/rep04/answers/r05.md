**Premise correction:** There is no GraphQL schema for the public API in this repository. The repository contains no GraphQL files or references (`GraphQL` search: no matches).

**Actual API surface:** The public API is a REST/HTTP API generated from Protocol Buffer service definitions:

- Schema/contracts: `proto/api/v1/*.proto`
- Generated HTTP gateway routes: `proto/gen/api/v1/*_service.pb.gw.go`
- Routes are exposed under `/api/v1/...`; for example, the API surface includes `GET /api/v1/memos`, `POST /api/v1/memos`, and authentication routes such as `POST /api/v1/auth/signin`.
- Additional public routes include `GET /api/v1/sse` in `server/router/api/v1/sse_handler.go:25` and `GET /healthz` in `server/server.go:44`.
