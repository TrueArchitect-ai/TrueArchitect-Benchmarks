**Premise correction:** This repository does not define a GraphQL schema for its public API. No GraphQL, `.graphql`, or `.gql` schema files or references were found.

**Actual API surface:** The public API is defined as **Protocol Buffer services with Google API HTTP annotations**, primarily under:

- `proto/api/v1/*.proto`
- Example: `proto/api/v1/memo_service.proto:17-35`, where `MemoService` RPCs map to REST endpoints such as `POST /api/v1/memos` and `GET /api/v1/{name=memos/*}`.
- The generated HTTP gateway surface is under `proto/gen/api/v1/*_service.pb.gw.go`; for example, the endpoint registrations for `MemoService` are in `proto/gen/api/v1/memo_service.pb.gw.go:1745`.

The repository’s API therefore uses a generated REST/HTTP gateway over protobuf contracts, not GraphQL.
