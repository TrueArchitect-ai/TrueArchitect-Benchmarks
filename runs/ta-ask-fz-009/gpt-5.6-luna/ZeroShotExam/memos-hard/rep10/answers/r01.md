**Premise correction:** The cache layer does not use Redis. It is an in-memory cache backed by Go’s `sync.Map` in `store/cache/cache.go:66-73`.

**Actual mechanism:** `store.New` configures a shared cache with `DefaultTTL: 10 * time.Minute` and creates `userCache` using that configuration in `store/store.go:37-53`. User entries are written through `s.userCache.Set(...)` in `store/user.go:98-99`, and `Set` applies the configured default TTL via `SetWithTTL` in `store/cache/cache.go:92-98`.

Therefore, user cache entries have a **10-minute TTL** unless explicitly written with a custom TTL.
