**Premise correction:** There is no per-user API rate-limiting middleware registered in this repository, so there are no per-user request-rate limits to report.

The registered HTTP middleware is:

- `middleware.Recover()` and CORS in `server/server.go:50-53`.
- Authentication/authorization middleware for the gRPC-Gateway in `server/router/api/v1/v1.go:69-93`, registered at `server/router/api/v1/v1.go:95-98`.
- Connect authentication/recovery interceptors in `server/router/api/v1/v1.go:131-141`.

The API does have a **request-body size limit**, not a rate limit: `maxAPIRequestBytes = 256 << 20` (256 MiB) in `server/router/api/v1/v1.go:20`, applied to the gateway and Connect handlers at `server/router/api/v1/v1.go:126` and `server/router/api/v1/v1.go:144`.
