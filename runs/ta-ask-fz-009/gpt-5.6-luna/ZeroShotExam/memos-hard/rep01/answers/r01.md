**Premise correction:** The cache layer does not use Redis. There is no Redis connection configured for it; the cache is an in-process, thread-safe memory cache (`store/cache/cache.go:66-73`).

**Actual mechanism:** `Store.New` creates `userCache` with an in-memory `cache.Config` (`store/store.go:37-53`). User entries are written through `s.userCache.Set(...)` (`store/user.go:92-99`), which applies the configured default TTL. The TTL is **10 minutes** (`store/store.go:40-44`; also the cache default in `store/cache/cache.go:56-64`).
