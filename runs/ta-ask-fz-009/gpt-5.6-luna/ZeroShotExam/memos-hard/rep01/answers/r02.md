Premise correction: no per-user API rate-limiting middleware is registered in this repository, so there are no per-user request-rate limits to report.

The registered API middleware is authentication/authorization middleware in `server/router/api/v1/v1.go:66-98`, applied to the gRPC-Gateway mux, while the Echo server registers only recovery and CORS middleware in `server/server.go:50-52`. The API does impose a body-size limit of **256 MiB** via `http.MaxBytesHandler` in `server/router/api/v1/v1.go:126-129`, but that is a payload limit, not rate limiting.
