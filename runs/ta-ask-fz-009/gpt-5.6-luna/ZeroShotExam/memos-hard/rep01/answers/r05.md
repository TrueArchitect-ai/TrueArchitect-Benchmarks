**Premise correction:** There is no GraphQL schema in this repository. The GraphQL search returned a certified miss, and the public API is not GraphQL-based.

**Actual API surface:** The public API is defined with Protocol Buffers under `proto/api/v1/`, where services and HTTP routes are declared using `google.api.http` annotations—for example, `MemoService` and its `/api/v1/memos` routes in `proto/api/v1/memo_service.proto:17-32`. The generated OpenAPI description is `proto/gen/openapi.yaml`. Runtime handlers are implemented in `server/router/api/v1/`, and the complete discovered HTTP surface is primarily `/api/v1/...` endpoints generated from those protobuf definitions.
