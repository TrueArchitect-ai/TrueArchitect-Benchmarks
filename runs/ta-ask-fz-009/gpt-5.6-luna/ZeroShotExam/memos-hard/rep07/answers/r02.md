**Premise correction:** No per-user API rate-limiting middleware is registered in this repository, so there are no per-user request limits to report.

The registered middleware is authentication/authorization middleware, not rate limiting:

- gRPC-Gateway: `server/router/api/v1/v1.go:69-97`
- Connect: `server/router/api/v1/v1.go:131-144`
- Server-wide middleware: recovery and CORS in `server/server.go:50-52`

The API does impose a **request-body size limit** of `256 << 20` bytes (256 MiB), not a request-rate limit, via `http.MaxBytesHandler` at `server/router/api/v1/v1.go:20,126,144`.
