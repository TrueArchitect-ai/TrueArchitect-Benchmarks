**Premise correction:** This repository does not define a GraphQL schema for its public API. The API surface is REST, exposed through protobuf/gRPC-Gateway route bindings.

**Actual API surface:** The public endpoints are defined by generated gateway code under `proto/gen/api/v1/*_service.pb.gw.go`, including routes such as:

- `POST /api/v1/auth/signin` — `proto/gen/api/v1/auth_service.pb.gw.go:331`
- `GET /api/v1/memos` — `proto/gen/api/v1/memo_service.pb.gw.go:1745`
- `GET /api/v1/users` — `proto/gen/api/v1/user_service.pb.gw.go:2301`
- `GET /api/v1/sse` — `server/router/api/v1/sse_handler.go:25`

So the API contract is the protobuf service definitions and their generated HTTP gateway bindings, not a GraphQL schema.
