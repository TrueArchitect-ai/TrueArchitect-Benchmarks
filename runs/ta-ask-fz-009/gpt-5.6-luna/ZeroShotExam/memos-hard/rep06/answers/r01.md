**Premise correction:** The cache layer does **not** use Redis; no Redis connection is configured in this repository.

**Actual mechanism:** `store.New` creates three process-local in-memory caches using `cache.New(cacheConfig)`, including `userCache`, configured with a **10-minute default TTL** and a **5-minute cleanup interval** (`store/store.go:37-53`). The implementation stores entries in a Go `sync.Map` and assigns expiration with `time.Now().Add(ttl)` (`store/cache/cache.go:66-84`, `store/cache/cache.go:97-114`). User entries are written through `userCache.Set`, so they receive the default **10-minute TTL** (`store/user.go:132-145`, `store/user.go:148-168`).
