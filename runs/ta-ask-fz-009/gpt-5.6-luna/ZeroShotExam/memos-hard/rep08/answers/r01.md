r01.

**Premise correction:** There is no Redis connection for the cache layer in this repository. The cache is process-local and in-memory: `store/cache/cache.go` defines `Cache` using `sync.Map` and TTL-based expiration (`store/cache/cache.go:66-73`, `store/cache/cache.go:122-146`).

**Actual mechanism:** `store.New` configures all caches—including `userCache`—with:

- **Default TTL:** `10 * time.Minute`
- **Cleanup interval:** `5 * time.Minute`
- **Maximum entries:** `1000`

This is configured in `store/store.go:37-53`. User entries use the default TTL because user operations call `s.userCache.Set(...)` rather than `SetWithTTL`, for example in `store/user.go:92-99` and `store/user.go:148-168`. Therefore, user entries expire after **10 minutes**, unless explicitly deleted earlier, such as through `store/user_delete.go:39-40`.
