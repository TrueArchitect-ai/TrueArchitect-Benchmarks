**Premise correction:** There is no GraphQL schema in this repository; the GraphQL search is a certified miss, and no `*graphql*` files exist.

**Actual API surface:** The public API is a **Protocol Buffers-defined REST API exposed through gRPC-Gateway**:

- Service and message contracts are defined under `proto/api/v1/*.proto`, for example:
  - `proto/api/v1/memo_service.proto:17` defines `MemoService`.
  - `proto/api/v1/auth_service.proto:13` defines `AuthService`.
- HTTP routes are declared inline with `google.api.http` annotations, e.g.:
  - `proto/api/v1/memo_service.proto:21-25` maps `CreateMemo` to `POST /api/v1/memos`.
  - `proto/api/v1/auth_service.proto:17-19` maps `GetCurrentUser` to `GET /api/v1/auth/me`.
- The generated gateway is registered by `server/server.go:87-90` through `apiV1Service.RegisterGateway(...)`.

So the actual public API schema is the set of `.proto` contracts in `proto/api/v1/`, not a GraphQL schema.
