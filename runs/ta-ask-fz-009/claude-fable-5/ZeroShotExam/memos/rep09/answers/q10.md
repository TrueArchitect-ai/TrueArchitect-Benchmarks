`store/migration/sqlite/LATEST.sql`

For a fresh SQLite install, the migrator applies the single consolidated schema file `store/migration/sqlite/LATEST.sql` (~3.7 KB, defining all 11 tables) rather than replaying the versioned migration directories (`0.2/` … `0.30/`), which exist only for upgrading existing databases. The same `LATEST.sql` convention holds for the MySQL and Postgres dialects under `store/migration/mysql/` and `store/migration/postgres/`.
