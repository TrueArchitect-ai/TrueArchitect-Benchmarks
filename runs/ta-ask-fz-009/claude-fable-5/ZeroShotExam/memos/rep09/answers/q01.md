**POST /api/v1/memos**

The mapping is declared in the proto HTTP annotation: `proto/api/v1/memo_service.proto:21-25` — the `CreateMemo` RPC carries `option (google.api.http) = { post: "/api/v1/memos" body: "memo" }`, so the REST gateway exposes it as a POST to `/api/v1/memos` with the `memo` field as the request body.
