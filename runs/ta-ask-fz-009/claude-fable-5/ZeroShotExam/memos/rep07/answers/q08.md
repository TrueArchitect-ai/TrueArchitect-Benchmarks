**Driver — store/driver.go**

The `Driver` interface is defined in `store/driver.go` (line 10), documented as "an interface for store driver. It contains all methods that store database driver should implement." All three database backends implement it: `sqlite.DB`, `mysql.DB`, and `postgres.DB` (constructed via `db.NewDBDriver` and the per-backend `NewDB` factories).
