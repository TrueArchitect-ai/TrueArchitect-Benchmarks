`store/migration/sqlite/LATEST.sql`

For a fresh install, the migrator applies the consolidated `LATEST.sql` schema file rather than replaying incremental migrations. The versioned directories (`store/migration/sqlite/0.2/` … `0.30/`) hold incremental migration scripts used only when upgrading an existing database; `LATEST.sql` is the single file containing the complete current SQLite schema. (Parallel `LATEST.sql` files exist for the other dialects under `store/migration/mysql/` and `store/migration/postgres/`.)
