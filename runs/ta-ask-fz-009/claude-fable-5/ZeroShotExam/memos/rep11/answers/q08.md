**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` with the doc comment "Driver is an interface for store driver. It contains all methods that store database driver should implement." It declares ~48 methods (CRUD for memos, users, attachments, etc.), and all three database backends implement it:

- `sqlite.DB` (store/db/sqlite)
- `mysql.DB` (store/db/mysql)
- `postgres.DB` (store/db/postgres)

Each backend's `NewDB` constructor returns a `Driver`, and `db.NewDBDriver` selects among them; the `store.Store` holds it as a field.
