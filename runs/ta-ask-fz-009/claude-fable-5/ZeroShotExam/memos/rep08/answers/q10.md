q10.
`store/migration/sqlite/LATEST.sql`

On a fresh SQLite install, the migrator doesn't replay the versioned migration folders (`store/migration/sqlite/0.2/` … `0.30/`); it applies the consolidated schema in `store/migration/sqlite/LATEST.sql`, which contains the complete current schema in one file. The versioned `NN__*.sql` files are only for upgrading existing databases between releases (parallel layouts exist for MySQL and Postgres under `store/migration/mysql/` and `store/migration/postgres/`).
