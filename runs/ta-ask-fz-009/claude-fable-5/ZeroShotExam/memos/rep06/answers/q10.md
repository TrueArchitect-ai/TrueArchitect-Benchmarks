`store/migration/sqlite/LATEST.sql`

A fresh SQLite install doesn't replay the versioned migration folders (`0.4/` … `0.30/`); instead the full current schema is applied in one shot from `LATEST.sql`, which sits at the root of the SQLite migration directory (`store/migration/sqlite/`) alongside the incremental migration subdirectories. The same convention exists for the other dialects (`store/migration/mysql/LATEST.sql`, `store/migration/postgres/LATEST.sql`).
