**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It delegates the actual parsing to `markdownService.ExtractAll` (`internal/markdown/markdown.go:356`), which does a single goldmark parse of the memo's content and populates `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85–86). This is the derived-metadata blob defined as `MemoPayload` in `proto/store/memo.proto` ("The calculated properties from the memo content", line 14).

**Triggers (three call sites):**
1. **Memo creation** — `CreateMemo` in `server/router/api/v1/memo_service.go:108`, after content-length validation.
2. **Content update** — `UpdateMemo` in `server/router/api/v1/memo_service.go:447`, but only when `"content"` is in the update mask (`contentUpdated` branch, lines 435–451); visibility/pinned-only updates do not recompute.
3. **Bulk rebuild** — `(*Runner).RunOnce` in `server/runner/memopayload/runner.go:27`, which pages through all memos in batches of 100 and rebuilds + persists each payload (a maintenance/backfill pass).

**Extracted properties** (per `internal/markdown/markdown.go` `ExtractAll` and `proto/store/memo.proto:15–21`):
- **Tags** — all `#tags` found in the content (skipping tags inside links, per the tests in `internal/markdown/markdown_test.go:352`)
- **Property.Title** — text of the first H1 heading, if it's the document's first block (markdown.go:384–388)
- **Property.HasLink** — any link node (markdown.go:394)
- **Property.HasCode** — code blocks, fenced code blocks, or code spans (markdown.go:396–397)
- **Property.HasTaskList** / **Property.HasIncompleteTasks** — task checkboxes, with the incomplete flag set when any box is unchecked (markdown.go:399–404)

One distinction worth noting: the memo **snippet** shown in lists is *not* part of this stored payload — it's computed on the fly at API-response conversion time via `getMemoContentSnippet`/`GenerateSnippet` (`server/router/api/v1/memo_service_converter.go:76`, `internal/markdown/markdown.go:264`). The persisted derived metadata is the tags + boolean/title property set above.
