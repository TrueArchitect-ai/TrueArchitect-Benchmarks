**Premise correction:** There is no GraphQL schema in this repository — the public API is not GraphQL. A fuzzy search across all 7,293 indexed symbols (exact, prefix, substring, qname, and doc-text tiers) returned a certified miss for "graphql," so this is verified absence, not just a failed grep.

**Actual API surface:** The public API is **gRPC with a grpc-gateway REST/JSON transcoding layer**, and its schema is defined in **Protocol Buffer (`.proto`) contracts**, not GraphQL SDL:

- **Schema definitions:** proto contracts under `proto/api/v1/` (e.g., memo, user, auth, attachment, instance, identity-provider, shortcut, and AI services), with generated Go bindings in `proto/gen/api/v1/` — for example `proto/gen/api/v1/memo_service.pb.gw.go`, `proto/gen/api/v1/user_service.pb.gw.go`, `proto/gen/api/v1/auth_service.pb.gw.go`.
- **REST surface:** the gateway exposes ~74 generated HTTP routes under `/api/v1/...` (e.g., `POST /api/v1/memos`, `GET /api/v1/users`, `POST /api/v1/auth/signin`), all anchored in the `*.pb.gw.go` gateway files above.
- **Hand-written non-gRPC endpoints:** a small set outside the proto contract — SSE at `server/router/api/v1/sse_handler.go:25` (`GET /api/v1/sse`), file serving at `server/router/fileserver/fileserver.go:132,168`, RSS at `server/router/rss/rss.go:72,111`, and `GET /healthz` in `server/server.go:44`.

So if you're looking for the API's source-of-truth schema, edit the `.proto` files in `proto/api/v1/` — the REST routes and Go types are generated from them.
