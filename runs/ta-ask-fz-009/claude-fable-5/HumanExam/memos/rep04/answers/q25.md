CEL (Common Expression Language, google/cel-go) — engine in `internal/filter` (internal/filter/engine.go:13–27). The engine parses the CEL filter into a dialect-agnostic condition tree (internal/filter/ir.go), which is then rendered to dialect-specific SQL WHERE clauses via `filter.AppendConditions`/`engine.CompileToStatement` with `filter.DialectSQLite/MySQL/Postgres` at each driver's call site (e.g. store/db/mysql/memo.go:65–69, store/db/postgres/memo.go:54–58; rendering in internal/filter/render.go)
