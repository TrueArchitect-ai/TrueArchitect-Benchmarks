**Engine: CEL (Common Expression Language, google/cel-go) — internal/filter/**

The filter is CEL syntax. `Engine` in `internal/filter/engine.go:13-34` builds a `cel.Env` from a schema of typed variables (`content`, `creator_id`, `tag`, `pinned`, etc. — `internal/filter/schema.go:232+`), compiles the expression (`Engine.Compile`, engine.go:48), and lowers the CEL AST into a **dialect-agnostic condition tree** (`internal/filter/parser.go` / `ir.go`).

**Mechanism:** the condition tree is then rendered to parameterized SQL per dialect by the renderer in `internal/filter/render.go`, which switches on `DialectName` (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`, e.g. render.go:231-237, with dialect-specific JSON accessors and function expressions) — so each driver's `ListMemos` gets WHERE clauses in its own dialect from one shared filter AST.
