Runners the server actually starts (`Server.startBackgroundRunners`, `server/server.go:153`):

- **s3presign.Runner — a `time.Ticker` every 12 hours** (`runnerInterval = time.Hour * 12`, ticker loop in `Run`, `server/runner/s3presign/runner.go:27-41`), plus one immediate `RunOnce` at startup (`server/server.go:163`). It re-presigns S3 attachment URLs.

That is the **only** background runner the server starts.

**Unused-as-background infrastructure:** `server/runner/memopayload` (`server/runner/memopayload/runner.go`) has runner scaffolding — `NewRunner` and a batch `RunOnce` that rebuilds all memo payloads — but the server never starts it as a background worker (no reference in `server/server.go`). Its `NewRunner`/`RunOnce` are unused by the server; only the package's helper `RebuildMemoPayload` is called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108,447`). There is no cron library in play; the sole scheduling mechanism is the s3presign ticker.
