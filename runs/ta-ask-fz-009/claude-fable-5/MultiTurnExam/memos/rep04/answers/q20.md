**Mechanism:** Server-Sent Events (SSE) — an Echo endpoint registered by `RegisterSSERoutes` (`server/router/api/v1/sse_handler.go:25`) streams events to browsers.

**Hub:** `SSEHub` — `server/router/api/v1/sse_hub.go:56` ("manages SSE client connections and broadcasts events; safe for concurrent use").

**Memo handlers that broadcast through it:**
- `APIV1Service.CreateMemo` — `memo.created` event (`server/router/api/v1/memo_service.go:163`, unless suppressed)
- `APIV1Service.UpdateMemo` — `memo.updated` via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:71`)
- `APIV1Service.DeleteMemo` — `memo.deleted` (`server/router/api/v1/memo_service.go:585`)
- `APIV1Service.CreateMemoComment` — `memo.comment.created` (`server/router/api/v1/memo_service_comments.go:126`; it suppresses the generic created event via `withSuppressSSE`)

(Related but reaction-scoped: `UpsertMemoReaction`/`DeleteMemoReaction` in `server/router/api/v1/reaction_service.go:106,161` also broadcast memo reaction events.)
