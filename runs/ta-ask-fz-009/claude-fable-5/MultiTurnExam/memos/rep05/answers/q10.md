**store/migration/sqlite/LATEST.sql**

Each dialect directory under `store/migration/` ships a `LATEST.sql` containing the complete current schema (e.g., the `memo_relation` table at `store/migration/sqlite/LATEST.sql:47`); for a fresh SQLite install the migrator applies that single file instead of replaying the versioned migrations in `store/migration/sqlite/0.*/`.
