**Mechanism:** the compiled frontend (`dist/`) is embedded into the Go binary via `go:embed` and served by Echo's static middleware with an SPA fallback; **wired in `server/router/frontend/frontend.go`**.

Specifics: `//go:embed dist/*` (`frontend.go:20-21`) bundles the built React app into the binary; `FrontendService.Serve` (`frontend.go:41-60`) mounts `middleware.StaticWithConfig` over that embedded filesystem, sets cache headers per asset type, and adds `spaFallbackMiddleware` so client-side routes fall back to `index.html`.
