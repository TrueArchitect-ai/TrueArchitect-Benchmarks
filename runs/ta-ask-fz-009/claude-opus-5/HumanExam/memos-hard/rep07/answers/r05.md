— Premise wrong: there is no GraphQL schema — no `graphql`/`gqlgen` match in any Go file and no GraphQL dependency. The public API surface is protobuf/gRPC-defined and exposed three ways from the same service implementations in `server/router/api/v1`:
- Connect RPC handlers — generated `proto/gen/api/v1/apiv1connect/*.connect.go`, procedures like `/memos.api.v1.MemoService/CreateMemo`; server wiring in server/router/api/v1/connect_services.go and `RegisterGateway` (server/router/api/v1/v1.go:65-99).
- REST/JSON via grpc-gateway — routes in `proto/gen/api/v1/*.pb.gw.go` (e.g. `POST /api/v1/{parent=memos/*}/shares`, `GET /api/v1/shares/{share_id}`); ~68 gateway routes across user/memo/attachment/instance/idp/shortcut/auth/ai services.
- Plain Echo HTTP routes: `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (server/router/fileserver/fileserver.go:123-124), RSS (server/router/rss/rss.go), SSE (server/router/api/v1/sse_handler.go), MCP (server/router/mcp), `/healthz` (server/server.go:67), frontend static (server/router/frontend/frontend.go).
Schema source of truth is the `.proto` set under `proto/` (generated Go in proto/gen, TS in web/src/types/proto).
