No GraphQL schema, server, or dependency exists in the repo. The public API surface is **Protobuf-defined RPC exposed two ways**: Connect/gRPC handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`; service impls in `server/router/api/v1`, e.g. `ConnectServiceHandler` `server/router/api/v1/connect_services.go`), and a gRPC-Gateway REST/JSON mapping under `/api/v1/...` registered by `apiV1Service.RegisterGateway` (`server/server.go:88`) — 74 gateway routes, e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{memo.name=memos/*}`, `GET /api/v1/users/{...}` (`proto/gen/api/v1/memo_service.pb.gw.go:1745`, `proto/gen/api/v1/user_service.pb.gw.go:2301`). Plus non-RPC Echo surfaces: `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go:25`), file serving `GET /file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), RSS (`server/router/rss/rss.go:72`, `:111`), `GET /healthz` (`server/server.go:67`), and an MCP endpoint (`server/server.go:92-96`).
