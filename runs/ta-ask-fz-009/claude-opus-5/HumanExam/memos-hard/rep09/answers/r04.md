— Premise is wrong: there is no message broker — neither NATS nor RabbitMQ appears in `go.mod` or any source file, and no queue is declared in any infrastructure sense. Webhook delivery is in-process: a buffered Go channel `asyncPostQueue` with capacity 128 (`internal/webhook/webhook.go:39`) drained by 4 goroutine workers started in `init()` (`internal/webhook/webhook.go:42-55`), each calling `Post` (`:46`); producers use `PostAsync`, which drops the event with a warning when the buffer is full (`internal/webhook/webhook.go:184-196`).
