— Premise is wrong: there is no GraphQL schema or server (no `graphql` match in the repo; no GraphQL dependency in `go.mod`). The public API is protobuf-defined gRPC exposed two ways: Connect RPC handlers for browsers (`server/router/api/v1/connect_services.go`, registered at `server/router/api/v1/v1.go:139-141`) and a gRPC-Gateway REST/JSON surface under `/api/v1/...` (~77 generated routes, e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, `PATCH /api/v1/{user.name=users/*}` — `proto/gen/api/v1/*.pb.gw.go`, registered at `server/router/api/v1/v1.go:96` / `server/server.go:88`). Non-RPC HTTP doors: `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go:25`), `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), RSS `/explore/rss.xml`, `/u/:username/rss.xml` (`server/router/rss/rss.go:72,111`), `/robots.txt`, `/sitemap.xml` (`server/router/frontend/frontend.go:128,143`), `/healthz` (`server/server.go:67`), and the MCP service (`server/router/mcp`, registered `server/server.go:96`). Proto sources of truth live in `proto/api/v1/`.
