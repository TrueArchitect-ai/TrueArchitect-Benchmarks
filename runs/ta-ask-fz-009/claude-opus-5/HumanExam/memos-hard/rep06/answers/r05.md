— Premise wrong: there is no GraphQL schema or server. The public API is Protobuf/gRPC-defined (`proto/api/v1/*.proto` — ai, attachment, auth, common, idp, instance, memo, shortcut, user services) exposed three ways: gRPC-Gateway REST under `/api/v1/*` (74 generated routes, e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, proto/gen/api/v1/memo_service.pb.gw.go:1745; registered at server/router/api/v1/v1.go:99-128), Connect-RPC under `/memos.api.v1.*` (v1.go:139-144), and SSE at `GET /api/v1/sse` (server/router/api/v1/sse_handler.go:25). Non-gRPC surfaces: file server `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (server/router/fileserver/fileserver.go:123-124), RSS `/explore/rss.xml` and `/u/:username/rss.xml` (server/router/rss/rss.go:72,111), MCP `/mcp` (server/router/mcp/service.go:109), `/healthz` (server/server.go:67), `robots.txt`/`sitemap.xml` (server/router/frontend/frontend.go:128,143).
