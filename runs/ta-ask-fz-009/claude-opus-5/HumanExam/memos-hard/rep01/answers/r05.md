— Premise wrong: there is no GraphQL schema or GraphQL server (no `.graphql`/`.gql` files in the repo; no GraphQL dependency in go.mod). The public API is protobuf-defined gRPC exposed three ways: Connect-RPC and gRPC-Gateway REST under `/api/v1/...` (registered by `APIV1Service.RegisterGateway`, server/router/api/v1/v1.go:65–97; wired at server/server.go:88), generated route patterns in proto/gen/api/v1/*.pb.gw.go (e.g. `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}` — proto/gen/api/v1/memo_service.pb.gw.go:1745), plus non-gRPC HTTP surfaces: SSE `GET /api/v1/sse` (server/router/api/v1/sse_handler.go:25), file server `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (server/router/fileserver/fileserver.go:123–124), RSS `/explore/rss.xml`, `/u/:username/rss.xml` (server/router/rss/rss.go:72,111), MCP routes (server/router/mcp, wired server/server.go:92–96), and `/healthz` (server/server.go:67). Schema source of truth: the `proto/` .proto definitions.
