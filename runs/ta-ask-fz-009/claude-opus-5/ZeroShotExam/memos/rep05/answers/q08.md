**Driver — `store/driver.go` (defined at line 10, package `store`)**

It's the single contract every database backend satisfies, declaring the full persistence surface: connection lifecycle (`GetDB`, `Close`), bootstrap/introspection (`IsInitialized`, `GetDatabaseSize`), and per-model CRUD groups (Attachment, Memo, MemoRelation, InstanceSetting, …) — `store/driver.go:11-40+`.

Three implementations exist, one per backend:
- `mysql.DB` — `store/db/mysql/mysql.go:14`
- `postgres.DB` — `store/db/postgres/postgres.go:16`
- `sqlite.DB` — `store/db/sqlite/sqlite.go:16`

Because the interface enumerates every model operation rather than exposing a generic query primitive, each new store method must be added in all three drivers — that's the maintenance cost this boundary imposes.
