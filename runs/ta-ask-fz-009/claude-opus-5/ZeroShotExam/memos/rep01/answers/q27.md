**Go `embed.FS` (`//go:embed dist/*`) served through Echo's static middleware + SPA fallback; `server/router/frontend/frontend.go`**

The mechanism, hop by hop:

- **Build step** — `web/package.json:11` (`pnpm release`) runs `vite build --outDir=../server/router/frontend/dist`, dropping the compiled SPA next to the Go package (documented in `AGENTS.md:46`).
- **Embed** — `server/router/frontend/frontend.go:20-21` declares `//go:embed dist/*` into `embeddedFiles embed.FS`; `getFileSystem("dist")` (`frontend.go:115`) subs it into the `fs.FS` actually served. So the assets ship *inside* the binary — no external web root in production.
- **Wiring** — `FrontendService.Serve` (`frontend.go:41`) installs `middleware.StaticWithConfig` with `Filesystem: frontendFS` (`frontend.go:54-57`), plus `spaFallbackMiddleware` (`frontend.go:59`, defined at `:63`) which converts a 404 on an extension-less path into `c.FileFS("index.html", frontendFS)` — the standard client-side-routing fallback.
- **Boundary guard** — `shouldSkipFrontendStatic` (`frontend.go:82`) keeps the static layer off API surface: `/api`, `/file`, `/memos.api.v1*`, and the server-rendered `robots.txt` / `sitemap.xml` / `rss.xml` routes.
- **Call site** — `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`, registered before `rootGroup` so gRPC/Connect and file routes still win via the skipper.

Cache contract worth noting: HTML is `no-cache, no-store, must-revalidate` while `/assets/` (Vite's content-hashed output) gets `immutable` — `frontend.go:92-105`.
