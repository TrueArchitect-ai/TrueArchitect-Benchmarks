`web/src/connect.ts`

All the ConnectRPC service clients are created there from a single shared `createConnectTransport` instance (`web/src/connect.ts:184`), then exported as module-level singletons — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient` (lines 192–203). There is one extra client, `refreshAuthClient` (line 72), built on a separate `refreshTransport` (line 65) so token-refresh calls bypass the auth interceptor.
