**q20.**

**Server-Sent Events (SSE)** over a plain Echo `GET /api/v1/sse` endpoint (`Content-Type: text/event-stream`, 30s heartbeat) — not WebSockets; **hub:** `server/router/api/v1/sse_hub.go`; **broadcasting handlers:** `CreateMemo`, `UpdateMemo` (via `dispatchMemoUpdatedSideEffects`), `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, `DeleteMemoReaction`.

Details:

**Mechanism.** `SSEHub` (`sse_hub.go:56`) holds a `map[*SSEClient]struct{}` under an `RWMutex`; each client is a buffered `chan []byte` (32 events). `Broadcast` (`sse_hub.go:115`) marshals the event to JSON and non-blockingly fans it out, dropping events for slow clients rather than blocking the writer. Delivery is permission-filtered in `canReceive` (`sse_hub.go:134`): private-visibility events reach only the creator or an admin. Transport and auth live in `server/router/api/v1/sse_handler.go` — `RegisterSSERoutes` mounts `GET /api/v1/sse` (line 27) and authenticates via Bearer token, then `Subscribe`s the connection to the hub (line 60).

**Event types** (`sse_hub.go:14-21`): `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`.
