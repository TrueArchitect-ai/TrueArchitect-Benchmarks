**Engine: Google CEL (`cel-go`), wrapped by the in-repo filter engine at `internal/filter/`** — `internal/filter/engine.go` (`Engine`, `NewEngine`, `DefaultEngine`), with `schema.go`, `parser.go`, `ir.go`, `render.go` around it. Documented in `internal/filter/README.md:1-20`.

**Mechanism (one sentence):** the CEL string is compiled against a memo-specific `cel.Env` built from the field schema (`internal/filter/engine.go:53`, options from `internal/filter/schema.go:232+`), normalized into a dialect-agnostic condition IR (`buildCondition` → `internal/filter/ir.go`, `parser.go`), then walked by a dialect-parameterized renderer that emits a `Statement{SQL, Args}` fragment (`internal/filter/render.go`, `newRenderer` + `RenderOptions{Dialect, PlaceholderOffset}`), which each store driver splices into its `WHERE` clause.

Supporting detail:

- **RPC → store:** `APIV1Service.ListMemos` validates the expression up-front via `validateFilter` (which itself calls `filter.DefaultEngine()`, `server/router/api/v1/shortcut_service.go:336-342`) and pushes it into `store.FindMemo.Filters` (`server/router/api/v1/memo_service.go:211-216`); note it also *appends a synthesized CEL filter* for visibility scoping (`memo_service.go:222`).
- **Per-dialect entry:** each driver's `ListMemos` calls `filter.DefaultEngine()` then `filter.AppendConditions(...)` with its own dialect constant — `store/db/sqlite/memo.go:57-61` (`DialectSQLite`), `store/db/mysql/memo.go:65-69` (`DialectMySQL`), `store/db/postgres/memo.go:54-58` (`DialectPostgres`). `AppendConditions` (`internal/filter/helpers.go:9-25`) compiles each filter and appends `(sql)` to `where` plus its args, threading `PlaceholderOffset: len(*args)` so Postgres `$n` numbering stays consistent.
- **Dialect constants:** `DialectName` with `sqlite`/`mysql`/`postgres` at `internal/filter/schema.go:11-16`; dialect switches live in the renderer (e.g. timestamp accessors `render.go:222-248`, JSON bool `render.go:357+`, regex `REGEXP` vs `~` `render.go:558-570`, `LIKE`/`ILIKE` folding `render.go:578+`).
