**Go `embed.FS` (compile-time embedding) served by Echo's static middleware with an SPA fallback; `server/router/frontend/frontend.go`**

How the pieces fit:

- **Embedding** — `//go:embed dist/*` at `server/router/frontend/frontend.go:20-21` compiles everything under `server/router/frontend/dist/` into the binary as `embeddedFiles embed.FS`. `getFileSystem("dist")` (`frontend.go:115-121`) roots a sub-FS at that directory, so no filesystem dependency exists at runtime.
- **Serving** — `FrontendService.Serve` installs `middleware.StaticWithConfig` over that FS (`frontend.go:54-57`), with a skipper that bypasses backend paths (`/api`, `/file`, `/memos.api.v1*`, `robots.txt`, `sitemap.xml`, `*/rss.xml` — see `shouldSkipFrontendStatic`, `frontend.go:82-90`) and sets cache headers per asset class (`frontend.go:92-105`: no-store for HTML, `max-age=3600, immutable` for hashed `/assets/`).
- **SPA routing** — `spaFallbackMiddleware` (`frontend.go:63-80`) catches a 404 from downstream and rewrites extensionless paths to `index.html` via `c.FileFS`, so client-side routes resolve. Missing real assets (paths with an extension) still 404 — asserted by `TestFrontendService_MissingAssetDoesNotFallbackToIndex` (`server/router/frontend/frontend_test.go:125`).
- **Wiring into the server** — the single call site is `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
- **Build step** — `web && pnpm release` builds the SPA into `server/router/frontend/dist` (documented at `AGENTS.md:46`); the checked-in `dist/index.html` is a placeholder reading "No embeddable frontend found." so the Go build succeeds before the frontend is built.
