**`memo_relation`**

It holds `memo_id`, `related_memo_id`, and `type` (e.g. `COMMENT`, `REFERENCE`) — the link row between one memo and another.

- Schema defined per dialect under `store/migration/{sqlite,postgres,mysql}/`
- Store access layer: `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go:14`, `store/db/mysql/memo_relation.go:13`
- Used for comment threading via joins, e.g. `store/db/postgres/memo.go:135-136` (`LEFT JOIN memo_relation ON memo.id = memo_relation.memo_id AND memo_relation.type = 'COMMENT'`)
