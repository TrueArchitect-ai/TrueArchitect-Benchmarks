**store.Driver — `store/driver.go:10`**

It's the single interface every database backend satisfies, declared as "an interface for store driver… contains all methods that store database driver should implement" (`store/driver.go:8-10`). Beyond `GetDB()`, `Close()`, `IsInitialized()`, and `GetDatabaseSize()`, it enumerates the full per-model CRUD surface (attachments, memos, and so on), so the interface *is* the store's persistence contract, not a thin connection abstraction.

Three concrete implementations exist, one per dialect:

- `mysql.DB` — `store/db/mysql/mysql.go:14`
- `postgres.DB` — `store/db/postgres/postgres.go:16`
- `sqlite.DB` — `store/db/sqlite/sqlite.go:16`
