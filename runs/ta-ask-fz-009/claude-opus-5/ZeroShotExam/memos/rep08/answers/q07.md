`web/src/connect.ts`

All ConnectRPC service clients are constructed there from a single shared `createConnectTransport` instance (`web/src/connect.ts:184`), then exported as module-level singletons — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient` (`web/src/connect.ts:192–203`). The file also holds a separate `refreshTransport`/`refreshAuthClient` pair (`web/src/connect.ts:65–72`) used by the token-refresh interceptor path, kept off the main transport to avoid interceptor recursion.
