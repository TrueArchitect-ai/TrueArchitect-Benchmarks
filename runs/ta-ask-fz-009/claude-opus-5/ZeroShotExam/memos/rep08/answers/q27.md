**Go `embed` of the Vite build output, served by Echo's static middleware plus an SPA `index.html` fallback; `server/router/frontend/frontend.go` (wired into the server at `server/server.go:72`).**

How it works:

- **Embedding** — `//go:embed dist/*` compiles `server/router/frontend/dist` (the `web` build output) into the binary as `embeddedFiles`, exposed as an `fs.FS` via `getFileSystem("dist")` (`server/router/frontend/frontend.go:20-21`, `:42`, `:115-121`). The build step that fills that directory is documented in `AGENTS.md:46` — `cd web && pnpm release` → `server/router/frontend/dist`.
- **Static serving** — `middleware.StaticWithConfig` is installed with `Filesystem: frontendFS` (`frontend.go:54-57`), so any request whose path maps to an embedded asset is served straight from the binary.
- **SPA fallback** — `spaFallbackMiddleware` wraps the chain: when downstream returns a 404 and the path looks like an app route (`"/"`, `"/index.html"`, or extensionless — `shouldServeFrontendHTML`, `frontend.go:107-109`), it serves `index.html` from the embedded FS (`frontend.go:63-80`), which is what makes client-side routing work on deep links.
- **Exclusions** — `shouldSkipFrontendStatic` keeps backend surfaces out of the static/fallback path: `/api/*`, `/file/*`, Connect RPC prefixes `/memos.api.v1*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` (`frontend.go:82-90`). The first two of those are instead handled by `registerRoutes` (`frontend.go:123-126`).
- **Cache policy** — `setFrontendCacheHeaders` sends `no-cache, no-store, must-revalidate` for HTML, `public, max-age=3600, immutable` for hashed `/assets/*`, and plain `max-age=3600` otherwise (`frontend.go:92-105`).

Wiring point: `server/server.go:71-72` calls `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` from `NewServer`.
