**Go `embed`ded static assets served by Echo's static middleware (with an SPA `index.html` fallback); `server/router/frontend/frontend.go`**

How it's wired:

- **Embedding:** `//go:embed dist/*` compiles the Vite build output into the binary as `embeddedFiles`, exposed as an `fs.FS` rooted at `dist` via `getFileSystem("dist")` — `server/router/frontend/frontend.go:20-21`, `:115-121`. The build step that populates that directory is `cd web && pnpm release` → `server/router/frontend/dist` (`AGENTS.md:46`).
- **Serving:** `FrontendService.Serve` installs `middleware.StaticWithConfig` with `Filesystem: frontendFS` (`frontend.go:54-57`), plus a `spaFallbackMiddleware` that catches 404s on extension-less paths and returns `index.html` so client-side routes resolve (`frontend.go:59`, `:63-80`, `:107-109`).
- **Skips and caching:** API/RPC/file paths (`/api`, `/file`, `/memos.api.v1.*`) and `robots.txt`/`sitemap.xml`/`rss.xml` bypass static handling (`frontend.go:82-90`); HTML gets `no-cache`, `/assets/*` hashed files get `immutable` 1-hour caching (`frontend.go:23-27`, `:92-105`).
- **Mount point:** the service is attached to the Echo server during startup at `server/server.go:72` — `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
