**Notes on the boundaries:**

- The Connect stub layer is the transport seam: the browser client is a generated `createClient(MemoService, transport)` (typed from `web/src/types/proto/api/v1/memo_service_pb.ts`), and the server side implements the generated `apiv1connect.MemoServiceHandler` interface. `ConnectServiceHandler` is a thin adapter — it only unwraps `req.Msg` and maps errors via `convertGRPCError` (`server/router/api/v1/connect_handler.go:65`).
- `store/memo.go` enforces the UID invariant (`base.UIDMatcher`) before delegating, so the driver never sees an invalid UID.
- The dialect fan-out from `Driver.CreateMemo` has three implementations: `store/db/sqlite/memo.go:16`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`. SQLite/Postgres use `QueryRowContext ...
