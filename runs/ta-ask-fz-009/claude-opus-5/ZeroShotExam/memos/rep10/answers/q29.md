**Frontend flow** (`web/src/connect.ts`)
- `authInterceptor` runs on every Connect-RPC request: calls `getRequestToken()` and sets `Authorization: Bearer <token>` (`setAuthorizationHeader`, line 97).
- Preflight refresh — if `isTokenExpired(REQUEST_TOKEN_EXPIRY_BUFFER_MS)` it refreshes *before* sending, specifically so an expired token isn't silently downgraded to anonymous on public endpoints (`connect.ts:136-147`).
- Reactive retry — on `Code.Unauthenticated` and not already a retry, it refreshes, re-signs the request, marks `X-Retry: true`, and replays once; a second failure calls `redirectOnAuthFailure()` (`connect.ts:161-177`).
- Recursion guard: refresh goes through a *separate* transport with `interceptors: []` (`connect.ts:65-72`), and concurrent refreshes are deduplicated by `tokenRefreshManager` (line 30) so proactive focus-refresh and 401-refresh don't race server-side token rotation.
- The transport uses `credentials: "include"` (`fetchWithCredentials`, line 57) — that's what carries the refresh cookie; the interceptor never touches the refresh token itself.

**Token kinds** (`server/auth/token.go:25-53`)
- Access token — JWT, aud `user.access-token`, 15 min (`AccessTokenDuration`). Stored client-side in `web/src/auth-state.ts` under `memos_access_token`.
- Refresh token — JWT, aud `user.refresh-token`, 30 days, cookie `memos_refresh`.
- Personal Access Token — prefix `memos_pat_`, for programmatic clients.

**Backend validation** — `server/auth`
- `Authenticator.AuthenticateByAccessTokenV2` (`server/auth/authenticator.go:41`) is stateless JWT parsing (no DB hit); `AuthenticateByRefreshToken` (line 61) parses *and* checks `GetUserRefreshTokenByID` for revocation (line 73).
- Entry point for RPCs is `AuthInterceptor.WrapUnary` (`server/router/api/v1/connect_interceptors.go:217`): reads the `Authorization` header, delegates to `Authorizer.Authenticate` + `CheckAccess`, then `auth.ApplyToContext`. Role/admin checks stay in the service layer (comment at line 205).
- Refresh endpoint: `APIV1Service.RefreshToken` (`server/router/api/v1/auth_service_session.go:113`), exposed as `POST /api/v1/auth/refresh`; cookie built by `buildRefreshTokenCookie` (line 224). `server/auth` is also shared with `server/router/fileserver` (`server/auth/token.go:4-5`).
