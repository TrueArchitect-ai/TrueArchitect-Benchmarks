**Go `embed.FS` — the built SPA is compiled into the server binary and served by Echo's static middleware with an SPA index.html fallback; `server/router/frontend/frontend.go`**

How the pieces fit:

1. **Build step** — `web/package.json:11`: `pnpm release` runs `vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir`, so Vite's output lands *inside the Go package directory*.
2. **Embedding** — `server/router/frontend/frontend.go:20-21`: `//go:embed dist/*` / `var embeddedFiles embed.FS`. `getFileSystem("dist")` (line 115) re-roots it via `fs.Sub` so URLs map to `dist/` contents without the prefix. No filesystem dependency at runtime — the assets ship in the binary.
3. **Serving** — `FrontendService.Serve` (line 41) installs `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` at line 54, then `spaFallbackMiddleware(frontendFS)` at line 59, which converts a 404 from the static handler into `c.FileFS("index.html", frontendFS)` (line 77) — client-side routing support for extensionless paths (`shouldServeFrontendHTML`, line 107).
4. **Boundary guard** — `shouldSkipFrontendStatic` (line 82) excludes `/api`, `/file`, `/memos.api.v1*`, plus `/robots.txt`, `/sitemap.xml`, `*/rss.xml`, so the static layer never shadows the API/gRPC surface or the server-rendered SEO routes registered in `registerRoutes` (line 123).
5. **Wiring point** — `server/server.go:71-72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`, mounted before `rootGroup` and the API routers.

Cache policy is set in the same file (lines 23-27, 92-105): HTML is `no-store`, hashed `/assets/*` are `immutable`, other static files get `max-age=3600`.
