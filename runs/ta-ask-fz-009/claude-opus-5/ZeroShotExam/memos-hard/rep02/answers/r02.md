**Premise correction: there is no per-user API rate-limiting middleware in this repository — so there is nothing registered and no request limits to report.**

What the middleware/interceptor chain actually contains:

- **Echo-level middleware** (`server/server.go:50-52`) — exactly two: `middleware.Recover()` and `newCORSMiddleware(profile)` (defined at `server/cors.go:13`). No limiter.
- **Connect RPC interceptors** (`server/router/api/v1/v1.go:133-138`) — four, in order: `NewMetadataInterceptor()` (HTTP headers → gRPC metadata), `NewLoggingInterceptor(logStacktraces)`, `NewRecoveryInterceptor(logStacktraces)`, `NewAuthInterceptor(authorizer)`. All defined in `server/router/api/v1/connect_interceptors.go` (lines 22, 98, 165, 208). Auth/authz only — no quota or throttling stage.
- **Frontend middleware** (`server/router/frontend/frontend.go:54-59`) — static file serving and SPA fallback.
