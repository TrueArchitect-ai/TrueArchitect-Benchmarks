Memo read-visibility is enforced at multiple independent points — there is no single chokepoint. Distinct enforcement sites:

`checkMemoReadAccess` (shared gRPC helper; archived + PRIVATE/PROTECTED check, used by `GetMemo` and `ListMemoComments`) — server/router/api/v1/memo_service.go:39-68
`ListMemos` query-level visibility scoping (`VisibilityList` / `creator_id == N || visibility in [...]` filter) — server/router/api/v1/memo_service.go:218-227
User-stats listing visibility scoping (`ListAllUserStats` and per-user stats) — server/router/api/v1/user_service_stats.go:83-91, 218-220
`checkAttachmentAccess` (attachment gated by owning memo's visibility) — server/router/api/v1/attachment_service.go:422-455
`ListMemoAttachments` inline visibility check — server/router/api/v1/memo_attachment_service.go:213-225
Reaction surfaces: list reactions and upsert reaction inline checks — server/router/api/v1/reaction_service.go:29-41 and :83
`CreateMemoComment` parent-memo visibility check — server/router/api/v1/memo_service_comments.go:41
`checkAttachmentPermission` on the raw file-serving HTTP route (includes anonymous-instance and `share_token` bypass paths) — server/router/fileserver/fileserver.go:650-704
SSE delivery filter `SSEClient.canReceive` (drops PRIVATE events for non-owner/non-admin) — server/router/api/v1/sse_hub.go:134-144
Share-token path `GetMemoByShare` / `getActiveMemoShare` (deliberate visibility bypass, gated on a valid non-expired token and non-archived memo) — server/router/api/v1/memo_share_service.go:153-208
RSS feeds restricted to `store.Public` — server/router/rss/rss.go:90, :141
Sitemap XML restricted to `store.Public` — server/router/frontend/frontend.go:149-151
Notification-payload visibility gate `canViewerAccessMemo` (in-app notifications) — server/router/api/v1/user_service_notifications.go:302-316
Notification-email visibility gate `canViewerAccessMemo` (duplicate implementation) — server/notification/email.go:306-320
Mention-notification eligibility (PRIVATE memo excludes non-creator targets) — server/router/api/v1/memo_mention_helpers.go:62-84
Store/SQL layer that materializes `FindMemo.VisibilityList` into the WHERE clause (per dialect) — store/db/sqlite/memo.go:96, store/db/postgres/memo.go:89, store/db/mysql/memo.go:104 (field declared at store/memo.go:69)

Notable: the PRIVATE/PROTECTED predicate is copy-pasted in at least five API-layer sites (memo_service.go, memo_attachment_service.go, attachment_service.go, reaction_service.go, memo_service_comments.go) plus a separate echo-layer variant in fileserver.go and two identical `canViewerAccessMemo` copies — the invariant is duplicated rather than centralized, so a rule change has to be applied in every one of those files.
