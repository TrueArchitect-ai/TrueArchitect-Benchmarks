**Convergence function: `webhook.Post` — `internal/webhook/webhook.go:120`**, which builds the request against `payload.URL` and issues it via the SSRF-guarded `safeClient.Do` (`webhook.go:152`).

Mechanics worth knowing: every handler above reaches `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto a bounded 128-slot channel (`asyncPostQueue`, `webhook.go:39`); four `init()` goroutines (`webhook.go:42–55`) drain that queue and call `Post`. So `PostAsync` is the enqueue chokepoint, `Post` is the single place delivery actually happens. The URL and HMAC secret come straight from stored per-user config — `hook.Url` / `hook.SigningSecret` from `s.Store.GetUserWebhooks` (`memo_service_webhooks.go:57`, `:31`) — and the only egress restriction is `safeDialContext` rejecting reserved/private IPs at dial time (`webhook.go:59`).
