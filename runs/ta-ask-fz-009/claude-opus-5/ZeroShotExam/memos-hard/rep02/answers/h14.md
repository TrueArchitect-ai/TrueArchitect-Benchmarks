**Computation site** — `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74-88`. It ensures `memo.Payload` exists, then delegates the actual derivation to the markdown service in one AST pass: `markdownService.ExtractAll(...)` in `internal/markdown/markdown.go:356-422`, assigning `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:85-86). **Triggers** (the only three callers of `RebuildMemoPayload`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before persisting (user-supplied `Location` is layered on afterwards at :111-112, so it is not derived).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:435-451`, only when `"content"` is in the update mask; the rebuilt payload is then written through `update.Payload = memo.Payload`. Visibility/pin/other mask paths do not recompute.
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27-72`, a batch backfill (100 memos at a time) that rebuilds and `UpdateMemo`s every memo. Note: `memopayload.NewRunner` has **no callers** in the repo (certified zero from the code graph; `grep` for `memopayload.` finds only the two service call sites and the runner file itself), so this path is currently a backfill utility, not a live scheduled job — unlike `s3presign.Runner`, which is wired in `server/server.go:162-166`.

**Extracted properties** (single `gast.Walk` in `internal/markdown/markdown.go:371-419`):
- `Tags` — every `#tag` inline node, deduplicated preserving original case (`:376-378, 418`).
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (`:384-389`), the field used for list titles/previews.
- `Property.HasLink` — any `KindLink` node (`:393-394`).
- `Property.HasCode` — any code block, fenced code block, or code span (`:396-397`).
- `Property.HasTaskList` — any task checkbox (`:399-400`).
- `Property.HasIncompleteTasks` — a task checkbox that is unchecked (`:401-405`).
- `Mentions` (lowercased, deduped, `:379-381, 419`) is extracted in the same pass but **not** persisted by `RebuildMemoPayload`; it is consumed separately at `server/router/api/v1/memo_mention_helpers.go:32-44`.
