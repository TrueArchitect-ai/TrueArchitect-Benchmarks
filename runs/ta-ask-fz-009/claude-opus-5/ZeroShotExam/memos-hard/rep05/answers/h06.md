**Handlers that can transitively trigger an outbound HTTP POST to a user-configured webhook URL** (all on `MemoService`, exposed via `ConnectServiceHandler` in `server/router/api/v1/connect_services.go`):

| RPC handler | Path to dispatch |
|---|---|
| `CreateMemo` — `server/router/api/v1/memo_service.go:70` | → `DispatchMemoCreatedWebhook` (`memo_service.go:157`) → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` |
| `UpdateMemo` — `server/router/api/v1/memo_service.go:401` | → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`) → `PostAsync` |
| `DeleteMemo` — `server/router/api/v1/memo_service.go:518` | → `DispatchMemoDeletedWebhook` (`memo_service.go:562`) → `PostAsync` |
| `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` | → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`, dispatches to the *parent* memo owner's hooks, `memo_service_webhooks.go:30`) |
| `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:16` | → `dispatchMemoUpdatedSideEffects` → updated webhook |
| `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:16` | → `dispatchMemoUpdatedSideEffects` → updated webhook |

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. Every path above funnels through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`webhook.go:42-55`) call `Post`, and `Post` is the sole place the request is built and issued (`safeClient.Do(req)` at `webhook.go:152`).

Two details worth noting since they live in that one function: the target URL and signing secret come straight from stored per-user hooks (`hook.Url`, `hook.SigningSecret` at `memo_service_webhooks.go:41-42, 67-68`), and SSRF protection is enforced at dial time by `safeDialContext` (`webhook.go:59`) on the shared `safeClient` transport — so it applies to all six handler paths by construction, not per call site.
