r04.

**Premise correction: neither.** There is no message broker in this repository — no NATS, no RabbitMQ, no Kafka/Redis/asynq. A grep of `go.mod` for `nats|amqp|rabbit|kafka|asynq|redis` returns zero matches, so there is no broker client dependency at all. There are also no "webhook delivery workers" as a separate service; delivery happens in-process inside the Go server.

**Actual mechanism — a bounded in-process Go channel with a fixed goroutine pool**, all in `internal/webhook/webhook.go`:

1. **The "queue" is a buffered channel**, declared as a package-level var: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`). Capacity 128, process-local, non-durable — it dies with the process.
2. **The "workers" are 4 goroutines started in `init()`** (`internal/webhook/webhook.go:42-55`). Each ranges over the channel and calls `Post(payload)`, logging a warning on failure. No retry, no dead-letter, no ack.
3. **Enqueue is non-blocking with drop-on-full**: `PostAsync` (`internal/webhook/webhook.go:184-196`) does a `select` with a `default:` branch that logs "Dropped webhook dispatch because the async queue is full" and returns. Nil payloads are also dropped (`:185-188`).
4. **Delivery itself** is plain HTTP POST via a shared `safeClient` with a 30s timeout (`internal/webhook/webhook.go:27-37`), whose `DialContext` is `safeDialContext` (`:59-77`) — it resolves the host and rejects reserved/private IPs (SSRF / DNS-rebinding guard). Payloads are optionally signed per the Standard Webhooks scheme: `webhook-id`, `webhook-timestamp`, `webhook-signature: v1,<HMAC-SHA256>` (`:133-150`).

Architectural consequence worth naming: because the queue is an unpersisted in-memory channel with a drop-on-full policy, webhook delivery is **best-effort only** — a full buffer, a failed POST, or a process restart silently loses events. Any at-least-once guarantee you were assuming from a broker does not exist here.

The webhook-related names elsewhere (`proto/gen/api/v1/user_service*.go`, `server/router/api/v1/resource_name.go:16`, `web/src/components/Settings/WebhookSection.tsx`) are CRUD for webhook *registrations*, not delivery transport.
