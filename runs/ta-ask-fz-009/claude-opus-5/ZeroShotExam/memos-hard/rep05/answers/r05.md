**Premise correction: there is no GraphQL schema in this repository.** A fuzzy search across all 7,293 indexed symbols for "graphql" returned a certified miss, and there are no `.graphql`/`.gql`/`.graphqls` files anywhere in the tree. No schema, no resolvers, no GraphQL server.

**The actual API surface is gRPC + Protobuf, exposed over HTTP by grpc-gateway.**

**1. Contract source of truth — `proto/api/v1/*.proto`**

Nine service definitions:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

REST paths are declared inline as `google.api.http` annotations on each RPC — e.g. `proto/api/v1/memo_service.proto:30` (`get: "/api/v1/memos"`), `:35` (`get: "/api/v1/{name=memos/*}"`), `:48` (`delete: "/api/v1/{name=memos/*}"`). This annotation is the closest analogue to what you were looking for: it's where the API shape is *declared* rather than implemented.

**2. Generated transport — `proto/gen/api/v1/*.pb.gw.go`**

grpc-gateway codegen turns those annotations into an HTTP router. 76 of the 81 HTTP doors in the system come from these files, following Google AIP resource-name conventions (`{name=memos/*}`, `:batchGet`, `:getStats`):
- `proto/gen/api/v1/memo_service.pb.gw.go` — memos, comments, reactions, relations, shares, link metadata
- `proto/gen/api/v1/user_service.pb.gw.go` — users, settings, webhooks, personal access tokens, linked identities, notifications
- `proto/gen/api/v1/auth_service.pb.gw.go` — `/api/v1/auth/signin`, `/signout`, `/refresh`, `/me`
- plus attachment, instance, shortcut, idp, and ai gateways

**3. Wiring — `server/router/api/v1/v1.go`**

The gateway mux is constructed at `server/router/api/v1/v1.go:96` (`runtime.NewServeMux`) and each service registers into it, e.g. `RegisterMemoServiceHandlerServer` at `server/router/api/v1/v1.go:108`.

**4. Hand-written routes outside the proto contract**

Five endpoints are not generated:
- `GET /api/v1/sse` — `server/router/api/v1/sse_handler.go:25`
- `GET /attachments/:uid/:filename` and `GET /users/:identifier/avatar` — `server/router/fileserver/fileserver.go:132`, `:168`
- `GET /explore/rss.xml` and `GET /u/:username/rss.xml` — `server/router/rss/rss.go:72`, `:111`
- `GET /robots.txt`, `GET /sitemap.xml` — `server/router/frontend/frontend.go:128`, `:143`
- `GET /healthz` — `server/server.go:44`

So if you're looking for "where the public API is defined," edit the `.proto` files — `proto/gen/` is generated output and changes there will be overwritten.
