## The actual API surface: Protobuf + gRPC, with a REST gateway

The public contract is defined in **`.proto` files**, not GraphQL:

**Schema of record — `proto/api/v1/`** (package `memos.api.v1`):
- `memo_service.proto` — `service MemoService` at line 17, with HTTP bindings declared inline via `option (google.api.http)` (e.g. line 30: `get: "/api/v1/memos"`)
- `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`

**Codegen fan-out — `proto/buf.gen.yaml`** turns those protos into four surfaces:
- Go message/gRPC/Connect stubs → `proto/gen/`
- grpc-gateway REST handlers → `proto/gen/api/v1/*.pb.gw.go`
- OpenAPI spec (gnostic-openapi plugin, `enum_type=string`)
- TypeScript client types → `web/src/types/proto` (bufbuild/es)

So the "public API" is **gRPC + JSON/REST over `/api/v1`**, with 77 generated route patterns. Representative anchors:
- `POST /api/v1/memos`, `GET /api/v1/{name=memos/*}`, `PATCH /api/v1/{memo.name=memos/*}` — `proto/gen/api/v1/memo_service.pb.gw.go:1745`
- `POST /api/v1/auth/signin`, `GET /api/v1/auth/me` — `proto/gen/api/v1/auth_service.pb.gw.go:331`
- `GET /api/v1/users`, `POST /api/v1/users:batchDelete`-style custom verbs — `proto/gen/api/v1/user_service.pb.gw.go:2301`
