**Convergence — `webhook.PostAsync` — `internal/webhook/webhook.go:184`**

Every dispatch path narrows through `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` (memo_service_webhooks.go:48, :30), which read the user's stored hooks (`Store.GetUserWebhooks`), set `payload.URL = hook.Url` and `payload.SigningSecret = hook.SigningSecret`, then hand off to `webhook.PostAsync`. `PostAsync` only enqueues onto the bounded `asyncPostQueue` (webhook.go:39); the actual outbound `POST` is issued by the single function `webhook.Post` (webhook.go:120), called from the 4 queue workers in `init` (webhook.go:42–55) — so `Post` is the only place `safeClient.Do(req)` runs (webhook.go:152).

Note on the boundary: the URL is user-supplied but not unrestricted — `safeClient`'s transport uses `safeDialContext` (webhook.go:59) to resolve the host and reject reserved/private IPs at dial time, which is the SSRF guard on this egress path.
