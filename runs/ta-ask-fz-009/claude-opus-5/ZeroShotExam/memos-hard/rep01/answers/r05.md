**Premise correction: there is no GraphQL in this repository.** The public API is gRPC + protobuf, exposed over HTTP via grpc-gateway/Connect, with an OpenAPI spec as the published schema artifact. Text search for `graphql`/`gql`/`typeDefs` found zero matches across all 343 Go files and all 15 `.proto` files, and no GraphQL client (`apollo`/`urql`/`relay`) in `web/package.json`.

**Where the API surface actually is defined:**

1. **Source of truth — protobuf service definitions** in `proto/api/v1/`:
   - `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`
   - REST shape is declared inline with `google.api.http` annotations — e.g. `rpc CreateMemo` → `post: "/api/v1/memos"` (`proto/api/v1/memo_service.proto:21-27`), `rpc GetMemo` → `get: "/api/v1/{name=memos/*}"` (line 34-37).

2. **Generated bindings** in `proto/gen/api/v1/` — protobuf-go, gRPC, Connect, and grpc-gateway stubs. The concrete HTTP route table lives in the `*.pb.gw.go` files (e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`), all under `/api/v1/...`.

3. **The published "schema" document is OpenAPI, not GraphQL** — generated by the `google-gnostic-openapi` plugin (`proto/buf.gen.yaml:23-25`) into `proto/gen/openapi.yaml` and embedded into the binary via `proto/openapi_embed.go:5-11`.

4. **Handler implementations** live in `server/router/api/v1/` (e.g. `server/router/api/v1/sse_handler.go:25` registers `GET /api/v1/sse`). Non-gRPC HTTP doors outside the generated surface: `server/router/fileserver/fileserver.go:132,168` (attachment/avatar serving), `server/router/rss/rss.go:72,111` (RSS feeds), `server/router/frontend/frontend.go:128,143` (robots.txt, sitemap.xml), and `GET /healthz` at `server/server.go:44`.

5. **Frontend consumes the same protos as TypeScript**, generated to `web/src/types/proto` (`proto/buf.gen.yaml:26-30`) — so the client is typed off protobuf, again no GraphQL layer.
