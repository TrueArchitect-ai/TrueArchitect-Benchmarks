**Premise correction: there is no GraphQL anywhere in this repository.** No `.graphql`/`.gql` schema files exist, and a content search for `graphql|gqlgen|apollo` across 1042 files returned zero matches. ## The actual public API surface: gRPC + Protobuf, with REST transcoding

**Schema of record — `proto/api/v1/*.proto`** (hand-written source of truth):
- `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`
- Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`

**Generated artifacts — `proto/gen/`**:
- Go message/service stubs and grpc-gateway shims, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`, `user_service.pb.gw.go`
- `proto/gen/openapi.yaml` — the OpenAPI (not GraphQL) description of the public surface

**Runtime wiring**: the gateway is mounted in `server/server.go:87` ("Register gRPC gateway as api v1"), which produces the REST surface under `/api/v1/...`. Roughly 76 transcoded routes are registered, following Google AIP resource-name conventions rather than a single graph endpoint:
- Memos: `GET/POST /api/v1/memos`, `GET/PATCH/DELETE /api/v1/{name=memos/*}`, plus sub-collections `/comments`, `/reactions`, `/relations`, `/attachments`, `/shares` (`proto/gen/api/v1/memo_service.pb.gw.go:1745`)
- Users: `/api/v1/users`, `/api/v1/{name=users/*}`, and nested `settings`, `webhooks`, `personalAccessTokens`, `linkedIdentities`, `notifications`, `shortcuts` (`proto/gen/api/v1/user_service.pb.gw.go:2301`, `shortcut_service.pb.gw.go:529`)
- Auth: `/api/v1/auth/signin|signout|refresh|me` (`proto/gen/api/v1/auth_service.pb.gw.go:331`)
- Instance/IdP/Attachments/AI: `instance_service.pb.gw.go:525`, `idp_service.pb.gw.go:493`, `attachment_service.pb.gw.go:571`, `ai_service.pb.gw.go:151`
- Custom methods use the AIP colon form rather than GraphQL-style arguments: `POST /api/v1/users:batchGet`, `GET /api/v1/{name=users/*}:getStats`, `POST /api/v1/attachments:batchDelete`

**Non-gateway HTTP handlers** (hand-written, outside the proto schema):
- SSE stream: `GET /api/v1/sse` — `server/router/api/v1/sse_handler.go:25`
- File serving: `GET /attachments/:uid/:filename`, `GET /users/:identifier/avatar` — `server/router/fileserver/fileserver.go:132,168`
- RSS: `GET /explore/rss.xml`, `GET /u/:username/rss.xml` — `server/router/rss/rss.go:72,111`
- SEO/health: `/robots.txt`, `/sitemap.xml` (`server/router/frontend/frontend.go:128,143`), `/healthz` (`server/server.go:44`)

So if you're looking for "where the API contract is defined," the answer is `proto/api/v1/` — edit the `.proto` files and regenerate; never edit `proto/gen/`.
