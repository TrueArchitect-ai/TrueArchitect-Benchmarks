**Computation site** — `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:80-86). The actual parsing lives in the goldmark-backed service: `internal/markdown/markdown.go:356-422` (`ExtractAll`, one AST walk).

**Triggers** — three call sites (`[ArchMap query]`, all direct):
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check, before persisting. Comment creation goes through this same path (`CreateMemoComment` delegates to `s.CreateMemo`, `server/router/api/v1/memo_service_comments.go:56`), so comments get payloads too.
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:447`, **only inside the `path == "content"` branch of the update mask** (lines 436-451); the rebuilt payload is written via `update.Payload = memo.Payload`. Visibility/pin/etc. updates do not recompute it.
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27-72`, a batch backfill (100 memos at a time) that rebuilds and `UpdateMemo`s every memo. Note: `memopayload.NewRunner` has **certified-zero callers** in the indexed graph, and `memopayload` is imported only by `memo_service.go` — so this backfill runner is defined but not currently wired into server startup (contrast `s3presign.NewRunner` at `server/server.go:162`).

**Extracted properties** — into `storepb.MemoPayload`:
- `Tags` — `#tag` nodes from the custom tag extension, deduplicated preserving case (`markdown.go:376-378, 418`); tags inside links are skipped.
- `Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-92`, documented "The calculated properties from the memo content"):
  - `HasLink` — any link node (`markdown.go:393-394`)
  - `HasCode` — code block, fenced code block, or inline code span (`markdown.go:396-397`)
  - `HasTaskList` — any task checkbox (`markdown.go:399-400`)
  - `HasIncompleteTasks` — any unchecked checkbox (`markdown.go:401-405`)
  - `Title` — text of the first block-level child if it is an H1 heading (`markdown.go:383-389`, via `extractHeadingText`)

`ExtractAll` also returns `Mentions` (lowercased, deduped), but `RebuildMemoPayload` does **not** store them; mentions are resolved separately in `server/router/api/v1/memo_mention_helpers.go:32`.

Consumers: the API converter copies both onto the wire memo — `memoMessage.Tags` / `Property` at `server/router/api/v1/memo_service_converter.go:48-49` — and stats aggregate them (`server/router/api/v1/user_service_stats.go:137-144, 253-260`). The list/preview **snippet** is a separate, non-persisted derivation computed per-response via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-87`), not part of the payload.
