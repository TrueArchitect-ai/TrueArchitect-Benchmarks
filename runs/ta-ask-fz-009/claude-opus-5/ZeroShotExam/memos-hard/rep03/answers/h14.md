**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:371-419`):
- `Tags` — every `#tag` node, deduplicated preserving original case (`:376-378`, `:418`).
- `Mentions` — `@username` nodes, lowercased and deduped (`:379-381`, `:419`) — returned in `ExtractedData` and used by mention notifications (`server/router/api/v1/memo_mention_helpers.go:32`), but *not* stored in the payload by `RebuildMemoPayload`.
- `Property.Title` — text of the document's first block if it is an H1 heading (`:384-389`, via `extractHeadingText`, `:173-179`).
- `Property.HasLink` — any link node (`:393-394`).
- `Property.HasCode` — code block, fenced code block, or inline code span (`:396-397`).
- `Property.HasTaskList` — any task checkbox (`:399-400`).
- `Property.HasIncompleteTasks` — a task checkbox that is unchecked (`:401-404`).
