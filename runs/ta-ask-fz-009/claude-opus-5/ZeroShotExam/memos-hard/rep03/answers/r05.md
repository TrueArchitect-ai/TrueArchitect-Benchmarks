**Premise correction:** there is no GraphQL schema in this repository. The map's fuzzy search over all 7,293 symbols returned a certified miss for "graphql" (all tiers probed), and a text search for `graphql|GraphQL|apollo|gqlgen` across 1,042 files found nothing. There are also no `.graphql`/`.gql`/`.graphqls` files anywhere in the tree.

**Actual API surface — Protobuf/gRPC with a generated REST gateway:**

1. **Schema of record: `.proto` files in `proto/api/v1/`** — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared `common.proto`. HTTP mapping is declared inline via `option (google.api.http)` annotations (e.g. `proto/api/v1/memo_service.proto:30` → `get: "/api/v1/memos"`).

2. **Generated code: `proto/gen/api/v1/`** — pb types plus grpc-gateway `*.pb.gw.go` files that materialize the REST routes (e.g. `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`).

3. **Hand-written HTTP routes outside the gateway:**
   - SSE stream — `GET /api/v1/sse`, `server/router/api/v1/sse_handler.go:25`
   - File serving — `GET /attachments/:uid/:filename` and `GET /users/:identifier/avatar`, `server/router/fileserver/fileserver.go:132,168`
   - RSS — `GET /explore/rss.xml`, `GET /u/:username/rss.xml`, `server/router/rss/rss.go:72,111`
   - Frontend/SEO — `GET /robots.txt`, `GET /sitemap.xml`, `server/router/frontend/frontend.go:128,143`
   - Health — `GET /healthz`, `server/server.go:44`

4. **The public API description artifact is OpenAPI, not GraphQL SDL:** `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` and consumed by the MCP router (`server/router/mcp/openapi.go`).

So if you're looking for "the schema for the public API," the file set you want is `proto/api/v1/*.proto` (authoritative), with `proto/gen/openapi.yaml` as its generated REST-facing description.
