**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`.**

How the funnel works:

- Both dispatchers (`dispatchMemoRelatedWebhook`, memo_service_webhooks.go:48; `DispatchMemoCommentCreatedWebhook`, :30) load the user's registered hooks via `s.Store.GetUserWebhooks` and set `payload.URL = hook.Url` — that is the user-configured URL (registered through `CreateUserWebhook`/`UpdateUserWebhook` on `UserService`).
- Both then call `webhook.PostAsync` (internal/webhook/webhook.go:184), which only enqueues onto the bounded `asyncPostQueue` (cap 128, webhook.go:39).
- Four worker goroutines started in `init()` (webhook.go:42–55) drain that queue and call `Post` — so `Post` is the single place the outbound request is actually built and executed (`http.NewRequest` at :126, `safeClient.Do` at :152), including HMAC signing at :133–150.
- Egress is guarded there too: `safeClient`'s transport uses `safeDialContext` (webhook.go:59), which resolves the host and rejects reserved/private IPs, defeating SSRF/DNS-rebinding.
