**h02.**

**delivery function — `webhook.Post` at `internal/webhook/webhook.go:120`** (fires `safeClient.Do(req)` at line 152); **protection mechanism — `safeDialContext` + `isReservedIP` at `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`**.

How the pieces fit:

- **Dispatch path.** Memo events call `PostAsync` (`internal/webhook/webhook.go:184`) from `server/router/api/v1/memo_service_webhooks.go:30` / `:48`, which enqueues onto a bounded 128-slot channel drained by 4 worker goroutines started in `init()` (lines 39–55). Each worker calls `Post`, so `Post` is the single place the outbound HTTP request actually executes — HMAC signing (Standard Webhooks `webhook-id`/`webhook-timestamp`/`webhook-signature` headers, lines 133–150) and the response read happen there too.

- **SSRF guard at the transport layer.** The shared `safeClient` (`internal/webhook/webhook.go:32`) installs `safeDialContext` as its `DialContext`. On every dial it re-resolves the host via `net.DefaultResolver.LookupHost` and rejects the connection if *any* returned address satisfies `isReservedIP` (`internal/webhook/webhook.go:65-74`). Because the check runs at dial time rather than at URL-registration time, it also defeats DNS rebinding.

- **Reserved-range definition.** `internal/webhook/validate.go:14-36` parses a fixed CIDR list once at startup: IPv4 loopback, all three RFC-1918 blocks, link-local `169.254.0.0/16` (cloud IMDS), plus IPv6 loopback, unique-local and link-local.

- **Second, earlier layer.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) enforces scheme ∈ {http, https} and the same reserved-IP check at configuration time, called from `CreateUserWebhook`/`UpdateUserWebhook` (`server/router/api/v1/user_service_webhooks.go:53`, `:106`). That's defense-in-depth for user feedback; the dial-time check is the actual enforcement point.

- **Escape hatch.** Both layers short-circuit when `webhook.AllowPrivateIPs` is true (`internal/webhook/validate.go:45`), set from the `allow-private-webhooks` flag in `cmd/memos/main.go:49` — for self-hosted deployments targeting LAN services.
