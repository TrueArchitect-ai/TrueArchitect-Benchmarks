**Premise correction: there is no GraphQL in this repository.** No schema file, no resolvers, no GraphQL server or client dependency. The code graph returns a *certified miss* for "graphql" across all 7,293 indexed server symbols, and `web/package.json` has no GraphQL dependency. The public API is defined in **Protocol Buffers**, and exposed as REST + Connect/gRPC.

**Actual API surface**

1. **Schema of record — `.proto` files** (`proto/api/v1/`): the single source of truth for the public API contract:
   - `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`
   - Generation is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).

2. **Generated Go bindings** — `proto/gen/api/v1/*.pb.go` plus grpc-gateway shims `*.pb.gw.go`. The REST paths are *derived* from `google.api.http` annotations in the protos, not hand-written routers; e.g. `GET /api/v1/memos` and `PATCH /api/v1/{memo.name=memos/*}` land at `proto/gen/api/v1/memo_service.pb.gw.go:1745`.

3. **Wiring** — `server/router/api/v1/v1.go:65` `RegisterGateway` builds one grpc-gateway mux with a shared authorizer (`v1.go:96-122`, registering all eight services), mounts it at `/api/v1/*` and `/file/*` (`v1.go:128-129`), and additionally serves **Connect** handlers for browser clients (`v1.go:131-139`) — Connect replaced grpc-web here.

4. **Non-proto doors** (hand-written, outside the generated surface):
   - SSE: `GET /api/v1/sse` — `server/router/api/v1/sse_handler.go:25`
   - Files: `GET /attachments/:uid/:filename`, `GET /users/:identifier/avatar` — `server/router/fileserver/fileserver.go:132,168`
   - RSS: `GET /explore/rss.xml`, `GET /u/:username/rss.xml` — `server/router/rss/rss.go:72,111`
   - Frontend/meta: `/robots.txt`, `/sitemap.xml` — `server/router/frontend/frontend.go:128,143`; `GET /healthz` — `server/server.go:44`

5. **If you're after a browsable schema document**, the closest analogue to a GraphQL SDL file is the generated OpenAPI spec at **`proto/gen/openapi.yaml`** — but edit the `.proto` files, not that.
