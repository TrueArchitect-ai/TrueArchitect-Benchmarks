**Extracted properties** (`internal/markdown/markdown.go:371-419`, stored shape at `proto/store/memo.proto:12-21`, API shape at `proto/api/v1/memo_service.proto:241,271-279`):
- `Tags` — every memo-tag AST node, deduplicated by `uniquePreserveCase` (original case kept).
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`), otherwise empty.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any task checkbox; plus `Property.HasIncompleteTasks` when at least one checkbox is unchecked.
- `Mentions` is also produced by `ExtractAll` (lowercased, deduped) but is **not** copied into the payload by `RebuildMemoPayload`; mention resolution happens separately in `server/router/api/v1/memo_mention_helpers.go:34-44`.

Two related-but-different derived values, so you don't conflate them: `Property` is persisted in the memo payload (and is what `user_service_stats.go:141-153` and the `has_link`/`has_code`/`has_task_list` store filters read), whereas `Memo.Snippet` is computed fresh on every response in `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76-80` → `getMemoContentSnippet`, 64 chars, `server/router/api/v1/memo_service_webhooks.go:83-88`) and is never stored.
