**Premise correction:** there is no Redis in this repository. A case-insensitive search for `redis` across 1042 files returned zero matches, and the cache layer is a hand-rolled, in-process implementation with no network client, no connection string, and no external store. Nothing to configure — there is no connection.

**Actual mechanism**

*The cache layer* is `store/cache` — a thread-safe in-memory cache over `sync.Map`:

- `cache.Interface` (`store/cache/cache.go:11`) defines `Set` / `SetWithTTL` / `Get` / `Delete` / `Clear` / `Size` / `Close`.
- `cache.Cache` (`store/cache/cache.go:67`) holds `data sync.Map` plus an atomic item counter; entries are `item{value, expiration, size}` (`store/cache/cache.go:35`). Expiry is enforced lazily on `Get` plus a background `cleanupLoop` goroutine (`store/cache/cache.go:200`), with `cleanupOldest` (`store/cache/cache.go:253`) trimming when `MaxItems` is exceeded.
- Because it lives in the process heap, it is per-instance and non-shared — the invariant to keep in mind if you ever run more than one server replica.

*Where it's "configured":* `store.New` in `store/store.go:38-58`, inline in code (not env vars, not a config file):

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```

The same config instantiates three caches: `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:51-53`), all closed on `Store.Close` (`store/store.go:74-76`). `cache.DefaultConfig()` (`store/cache/cache.go:57`) carries identical values.

*TTL for user entries:* **10 minutes**, inherited from `DefaultTTL`. Every user write path calls plain `Set` (not `SetWithTTL`), which delegates to the default TTL at `store/cache/cache.go:93-95`: keys are `userCacheKey(user.ID)` (`store/user.go:88`), populated at `store/user.go:98, 122, 132, 143, 167` and read at `store/user.go:150`. Invalidation on delete is explicit via `deleteUserCache` (`store/user_delete.go:39-45`), which drops the user key and its user-setting keys.

For contrast, the one place with a distinct TTL is instance stats: `instanceStatsCacheTTL = 60 * time.Second` (`server/router/api/v1/instance_stats.go:21`), a separate ad-hoc cache, not `store/cache`.
