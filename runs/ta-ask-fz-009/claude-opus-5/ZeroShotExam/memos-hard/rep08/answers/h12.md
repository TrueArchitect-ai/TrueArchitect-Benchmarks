## Why that one and not the other two

There are three sibling implementations of the same method — `store/db/sqlite/memo.go:16`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go` — so the answer is a dispatch question, not a search question. I resolved it by walking the call chain from the API surface down to the point where the concrete type is chosen:

1. **API handler → store facade**: `server/router/api/v1/memo_service.go:115` calls `s.Store.CreateMemo(ctx, create)`.
2. **Store facade → interface**: `store/memo.go:109-114` validates the UID and then delegates to `s.driver.CreateMemo(ctx, create)` — `driver` is the `store.Driver` interface (declared in `store/driver.go`), so the concrete method is invisible at this hop. Nothing in the store layer picks a dialect.
3. **Interface → concrete type, at the factory**: `store/db/db.go:14-27`, `NewDBDriver`, switches on `profile.Driver`: `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`, and errors out on anything else. This is the single place the binding happens — the only production caller is `cmd/memos/main.go:57` (the other callers are test helpers: `store/test/store.go:28,50`, `server/router/api/v1/test/memo_service_benchmark_test.go:70`).
4. **What `profile.Driver` holds with no flags**: `cmd/memos/main.go:43` fills it from `viper.GetString("driver")`; the default is set twice — `viper.SetDefault("driver", "sqlite")` at `cmd/memos/main.go:122` and the flag default `"sqlite"` at line 130. With no `--driver` and no `MEMOS_DRIVER` env var (env binding via `SetEnvPrefix("memos")` + `AutomaticEnv()`, `cmd/memos/main.go:167-169`), the value is `"sqlite"`. `internal/profile/profile.go:110` corroborates that sqlite is the self-contained default: when `Driver == "sqlite"` and `DSN == ""` it synthesizes a DSN inside the data directory, so no external DB is required.

So the determination method was: **interface-dispatch resolution via the factory** — find the single construction site of the `store.Driver` interface, then evaluate its switch key under default configuration. Grepping for `CreateMemo` alone gives you three equally plausible hits (`store/db/{mysql,postgres,sqlite}/memo.go`) and cannot discriminate between them; only the `profile.Driver` default does.
