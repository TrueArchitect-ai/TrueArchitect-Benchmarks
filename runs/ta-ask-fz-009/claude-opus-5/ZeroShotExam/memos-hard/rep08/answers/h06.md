**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`** (the outbound request is issued at line 152, `safeClient.Do(req)`).

How the funnel works: both dispatch sites read the user-configured targets from `s.Store.GetUserWebhooks(...)` and set `payload.URL = hook.Url` (`memo_service_webhooks.go:41`, `:67`), then hand off to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto the bounded `asyncPostQueue`. Four worker goroutines started in `init()` (`webhook.go:42-55`) drain that queue and call `Post` — so `Post` is the single chokepoint where every handler path becomes an actual HTTP POST. It is also where HMAC signing (`webhook-signature` headers) and the SSRF guard apply: `safeClient`'s transport uses `safeDialContext` (`webhook.go:59`), which rejects reserved/private IPs at dial time.
