**Premise correction:** neither. There is no message broker in this repository. RabbitMQ is a certified miss across all 7,293 indexed symbols, and `go.mod` contains no AMQP, NATS, Kafka, Redis, or task-queue client dependency at all. So there is no queue *declaration* in the broker sense — no exchange, no subject, no durable stream to point at.

**Actual mechanism:** webhook delivery is an in-process buffered Go channel with a fixed pool of goroutines, all inside `internal/webhook/webhook.go`.

The "queue" is a package-level channel:

- `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` — `internal/webhook/webhook.go:39`, declared in the same `var` block as the shared HTTP client.

The "workers" are four goroutines started from the package `init()`, each ranging over that channel and calling `Post` for every payload, logging a warning on failure — `internal/webhook/webhook.go:42-55`.

Enqueue is non-blocking and lossy by design: `PostAsync` does a `select` with a `default` branch, so when the 128-slot buffer is full the payload is **dropped** with a `"Dropped webhook dispatch because the async queue is full"` warning — `internal/webhook/webhook.go:184-196`.

Callers into this path are the memo webhook dispatchers, `DispatchMemoCommentCreatedWebhook` and `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go:30,48`.

Actual delivery is a plain `http.POST` in `Post` (`internal/webhook/webhook.go:120`), with a 30s timeout, optional HMAC-SHA256 signing via `webhook-id`/`webhook-timestamp`/`webhook-signature` headers, and an SSRF guard at dial time (`safeDialContext`, `internal/webhook/webhook.go:59`, backed by the reserved-CIDR checks in `internal/webhook/validate.go`).

**Architectural consequence worth naming:** because the queue lives in process memory, it has no durability and no cross-instance semantics — a restart loses in-flight payloads, delivery is at-most-once with no retry or dead-letter path, and the whole thing does not survive horizontal scaling as a shared work queue. That's the gap a real broker would close.
