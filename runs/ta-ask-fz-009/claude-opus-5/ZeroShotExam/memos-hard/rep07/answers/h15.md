h15.

Memo visibility is enforced at many independent points — the rule (`PUBLIC` → anyone, `PROTECTED` → any authenticated user, `PRIVATE` → creator/admin) is re-implemented per surface rather than centralized. Distinct enforcement sites:

**Single-memo read guard (Connect/gRPC API)** — `server/router/api/v1/memo_service.go:39-68` (`checkMemoReadAccess`, called by `GetMemo` at :341 and `ListMemoComments` in `memo_service_comments.go:136`)

**List-query filter injection (ListMemos)** — `server/router/api/v1/memo_service.go:218-227` (anonymous → `VisibilityList=[PUBLIC]`; authenticated → CEL filter `creator_id == N || visibility in ["PUBLIC","PROTECTED"]`)

**Relation/comment/converter list filters** — `server/router/api/v1/memo_relation_service.go:107-112`, `server/router/api/v1/memo_service_comments.go:156-160`, `server/router/api/v1/memo_service_converter.go:182-187`

**Comment creation guard** — `server/router/api/v1/memo_service_comments.go:41-43`

**Reaction surfaces (list + upsert)** — `server/router/api/v1/reaction_service.go:29-41` and `:81-85`

**Memo-attachment listing** — `server/router/api/v1/memo_attachment_service.go:212-225`

**Attachment access via API** — `server/router/api/v1/attachment_service.go:419-455` (`checkAttachmentAccess`)

**Attachment access via raw HTTP file server** — `server/router/fileserver/fileserver.go:649-701` (`checkAttachmentPermission`; adds anonymous-instance and `share_token` allowances)

**SSE event delivery filter** — `server/router/api/v1/sse_hub.go:134-143` (`SSEClient.canReceive`)

**User stats aggregation** — `server/router/api/v1/user_service_stats.go:82-92` and `:216-221`

**Notification/inbox visibility** — `server/router/api/v1/user_service_notifications.go:302-315` (`canViewerAccessMemo`) and a second, near-duplicate copy in `server/notification/email.go:306-319`

**Mention-notification eligibility** — `server/router/api/v1/memo_mention_helpers.go:62-84`

**RSS feeds** — `server/router/rss/rss.go:90` and `:141` (`VisibilityList=[PUBLIC]`)

**Frontend SEO/metadata prerender** — `server/router/frontend/frontend.go:150`

One deliberate bypass worth flagging: `GetMemoByShare` in `server/router/api/v1/memo_share_service.go:153-192` performs **no** visibility check — a valid, unexpired share token grants read access regardless of visibility (only archived/missing memos are refused), and `fileserver.go:684-689` mirrors that bypass for attachments.
