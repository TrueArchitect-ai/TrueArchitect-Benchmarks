**mysql, postgres, sqlite**

`store/migration/` contains exactly three dialect directories — `store/migration/mysql/`, `store/migration/postgres/`, `store/migration/sqlite/` — each with per-version migration folders plus a `LATEST.sql` schema snapshot (e.g. `store/migration/postgres/LATEST.sql`).

This matches the driver layer, which has one implementation per dialect: `store/db/mysql/`, `store/db/postgres/`, `store/db/sqlite/` (e.g. `store/db/sqlite/memo.go:16`).

Note the dialects are not at equal migration depth: sqlite carries history from `0.2` onward, postgres only from `0.19` — sqlite is the original store, the other two were added later with a baseline schema.
