**memo_relation**

A pure join table — no surrogate key, just the edge itself (`store/migration/sqlite/LATEST.sql:47-52`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The `type` column makes it a typed edge (it carries the REFERENCE vs. COMMENT distinction), and the composite `UNIQUE` on all three columns is the invariant: one relation of a given type per ordered memo pair.

Defined identically for all three dialects — `store/migration/mysql/LATEST.sql:46`, `store/migration/postgres/LATEST.sql:46`, `store/migration/sqlite/LATEST.sql:47` — and introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`.
