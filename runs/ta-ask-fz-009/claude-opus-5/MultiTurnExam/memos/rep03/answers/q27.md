**Mechanism: the Vite build output is compiled into the Go binary via `//go:embed` and served as static files by Echo middleware, with an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

How it's wired:

- **Embed.** `//go:embed dist/*` → `var embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`), so `web/`'s production build is shipped inside the binary — no external web root at runtime.
- **Static serving.** `FrontendService.Serve` derives the FS with `getFileSystem("dist")` (:42) and installs `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` (:54-57).
- **SPA fallback.** `spaFallbackMiddleware` (:63) catches a downstream 404 and returns `c.FileFS("index.html", frontendFS)` (:77) — that's what makes client-side routes like `/memos/publicmemo` work on a hard refresh.
- **Startup call site.** `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` at `server/server.go:72`, registered *before* the API groups.

Two boundary rules worth knowing, since ordering middleware here is easy to get wrong:

- **Backend paths are explicitly excluded** by `shouldSkipFrontendStatic` (:82-90): `/api/*`, `/file/*`, the Connect prefixes `/memos.api.v1` and `/memos.api.v1.*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` — the last three are server-rendered by `registerRoutes` (:60) rather than served from `dist`.
- **Cache policy is path-derived** (`setFrontendCacheHeaders`, :92-105): HTML gets `no-cache, no-store, must-revalidate` + `Pragma`/`Expires`; content-hashed `/assets/*` gets `max-age=3600, immutable`; other static files get plain `max-age=3600`. Enforced by tests in `server/router/frontend/frontend_test.go`.
