**`web/src/connect.ts`**

That single module is the frontend's transport boundary. All eight service clients are instantiated there against one shared `createConnectTransport` (`web/src/connect.ts:184`) and exported as singletons:

- `instanceServiceClient` (line 192), `authServiceClient` (193), `userServiceClient` (194), `memoServiceClient` (197), `attachmentServiceClient` (198), `aiServiceClient` (199), `shortcutServiceClient` (200), `identityProviderServiceClient` (203)

One exception to the shared transport: a separate `refreshTransport` (line 65) backs a dedicated `refreshAuthClient` (line 72) — kept off the main transport so token refresh can't recurse through the interceptor chain that triggers it.
