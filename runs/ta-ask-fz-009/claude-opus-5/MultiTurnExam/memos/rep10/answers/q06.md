**`memo_relation`**

A pure join table — three columns, no surrogate key, uniqueness on the whole triple:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Defined identically in all three dialects: `store/migration/postgres/LATEST.sql:46`, `store/migration/sqlite/LATEST.sql:47`, `store/migration/mysql/LATEST.sql:46`. It was introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`.

The `type` column makes it a typed edge (the relation kind, e.g. reference vs. comment), so one memo pair can carry more than one relationship.
