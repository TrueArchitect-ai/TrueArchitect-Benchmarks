**`store/migration/sqlite/LATEST.sql`**

The migrator's fresh-install path is explicit about this: in `preMigrate`, if `driver.IsInitialized()` returns false, it reads `getMigrationBasePath() + LatestSchemaFileName` and applies it in a single transaction (`store/migrator.go:217-224`). `LatestSchemaFileName = "LATEST.sql"` is defined at `store/migrator.go:56`, and the base path is dialect-scoped — so SQLite resolves to `migration/sqlite/LATEST.sql` inside the embedded FS (`//go:embed migration`, `store/migrator.go:44`).

Design intent, per the header comment at `store/migrator.go:42`: full schema for new installations, faster than replaying the incremental migrations. `store/test/migrator_test.go:18-26` covers that path.
