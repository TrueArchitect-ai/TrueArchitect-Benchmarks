**Mechanism: the Vite build output is compiled into the Go binary via `//go:embed dist/*` and served by Echo's static middleware with an SPA fallback; `server/router/frontend/frontend.go`.**

The wiring, in `FrontendService.Serve` (`server/router/frontend/frontend.go:41-61`):

- `//go:embed dist/*` → `embeddedFiles embed.FS` (lines 20-21), unwrapped to a sub-FS by `getFileSystem("dist")` (line 42). No filesystem dependency at runtime — one self-contained binary.
- `middleware.StaticWithConfig` serves matching asset paths (lines 54-57).
- `spaFallbackMiddleware` (line 59) catches 404s from downstream and returns `index.html` (line 77), which is what makes client-side routing work on deep links.
- A skipper carves out the non-frontend surface so API traffic never falls through to the SPA: `/api`, `/file`, `/memos.api.v1*` (the Connect prefix), plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` (`shouldSkipFrontendStatic`, lines 82-90).
- Cache policy is split by asset type: HTML gets `no-cache, no-store, must-revalidate` + `Pragma`/`Expires` (lines 24, 92-97), plain static assets `max-age=3600`, content-hashed assets `max-age=3600, immutable` (lines 25-26).

`server/router/frontend/dist/` is the build target — produced by `cd web && pnpm build` per `AGENTS.md:85`.
