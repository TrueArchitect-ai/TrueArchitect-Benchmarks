q02. **mysql, postgres, sqlite**

`store/migration/` contains exactly three dialect directories — `store/migration/mysql/`, `store/migration/postgres/`, `store/migration/sqlite/` — each with versioned migration files (e.g. `store/migration/mysql/0.30/00__user_tag_setting.sql`, `store/migration/postgres/0.30/00__user_tag_setting.sql`, `store/migration/sqlite/0.30/00__user_tag_setting.sql`) plus a `LATEST.sql` baseline schema per dialect.

This matches the driver layer, which has one implementation per dialect: `store/db/mysql/`, `store/db/postgres/`, `store/db/sqlite/` (all satisfying `store.Driver`, `store/driver.go`). Note the dialects differ in migration depth — sqlite carries history from 0.2, mysql from 0.17, postgres from 0.19.
