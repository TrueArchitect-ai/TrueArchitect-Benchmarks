q27. **Go `embed.FS` — the Vite build output (`web/dist`) is compiled into the binary and served by the frontend router; server/router/frontend/frontend.go**

The wiring: `//go:embed dist/*` binds the built assets to `embeddedFiles` (`server/router/frontend/frontend.go:20-21`), and `getFileSystem` narrows that into a sub-filesystem with `fs.Sub` for serving (`:115-121`). So production needs no external web server or asset directory — the whole SPA ships inside the single Go binary.

The router also differentiates cache policy per asset class (`server/router/frontend/frontend.go:24-26`):

- HTML — `no-cache, no-store, must-revalidate`, so a new deploy is picked up immediately
- hashed assets — `public, max-age=3600, immutable`
- other static assets — `public, max-age=3600`

`hasPathPrefix` (`:111`) is used to separate frontend routes from API paths, which is what lets client-side routing coexist with the `/api/v1` surface.
