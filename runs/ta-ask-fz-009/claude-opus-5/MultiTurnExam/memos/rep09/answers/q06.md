```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The `type` column is part of the uniqueness constraint, so the same memo pair can be linked more than once under different relation types (this is what backs both generic references and comment threading).
