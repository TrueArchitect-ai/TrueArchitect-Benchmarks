q02. **mysql, postgres, sqlite**

Each is a top-level directory under `store/migration/` (`store/migration/mysql`, `store/migration/postgres`, `store/migration/sqlite`), and each ships versioned migration folders plus a `LATEST.sql` baseline schema (e.g. `store/migration/postgres/LATEST.sql`).

The same three-way split appears in the driver layer — `store/db/mysql/`, `store/db/postgres/`, `store/db/sqlite/` — each implementing the `store.Driver` interface (`store/driver.go`).
