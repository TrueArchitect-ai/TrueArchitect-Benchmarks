Two things to weigh before changing this signature:

- **`fetchCurrentUser` is the widest amplifier.** It's the per-request identity lookup used across the API layer, so a behavioral change (not just signature) at `Store.GetUser` propagates to essentially every authenticated handler — the compiler will only flag the one call site at `auth_service_session.go:251`.
- **One caller is inside `store` itself.** `Store.GetUserByPATHash` (`store/user_setting.go:135`) calls `GetUser` internally, so the change isn't confined to consumers of the package.

Note that `store/db/mysql/user.go:77` calls `d.GetUser` — that's the *driver* method on `mysql.DB`, a different symbol from `Store.GetUser`. It only needs updating if you also change the `store.Driver` interface (`store/driver.go`), which would then require matching edits in the postgres and sqlite drivers.
