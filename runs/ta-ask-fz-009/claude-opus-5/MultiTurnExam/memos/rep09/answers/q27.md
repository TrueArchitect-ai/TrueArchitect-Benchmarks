q27. **Go `embed.FS` — the Vite `dist/` build is compiled into the binary and served by Echo static middleware with SPA fallback; server/router/frontend/frontend.go**

Mechanics:

- **Embedding:** `//go:embed dist/*` → `var embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`). The build output must be present at `server/router/frontend/dist/` at compile time, so there's no runtime filesystem dependency — one self-contained binary.
- **Wiring:** `FrontendService.Serve` (`:41`) roots the FS via `getFileSystem("dist")` (:42) and installs `middleware.StaticWithConfig` (:54-57), then `spaFallbackMiddleware` (:59) and `s.registerRoutes(e)` (:60).
- **SPA fallback:** the fallback middleware (:63-79) intercepts only 404s for extension-less paths and serves `index.html` from the embedded FS (:77) — so client-side routes resolve, while a genuinely missing hashed asset still 404s (`shouldServeFrontendHTML` :107-108; pinned by `TestFrontendService_MissingAssetDoesNotFallbackToIndex`, `frontend_test.go:125`).
- **Backend paths are excluded** by `shouldSkipFrontendStatic` (:82-90): `/api`, `/file`, the Connect prefixes `/memos.api.v1*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml`, which are dynamically generated instead.
- **Cache policy** is set in `setFrontendCacheHeaders` (:92-105): HTML gets `no-cache, no-store, must-revalidate` so deploys are picked up immediately, `/assets/*` (content-hashed) gets `max-age=3600, immutable`, other root assets `max-age=3600`.
