**store/migration/sqlite/LATEST.sql**

The migrator resolves it by convention: migration files live at `store/migration/{driver}/{version}/NN__description.sql`, and `LATEST.sql` is documented as the "Full schema for new installations (faster than incremental migrations)" — `store/migrator.go:39-42`, with the constant `LatestSchemaFileName = "LATEST.sql"` at `store/migrator.go:56`. For the sqlite driver that resolves to `store/migration/sqlite/LATEST.sql`.

The trigger is `preMigrate`, which checks whether the DB is initialized and applies `LATEST.sql` if not (`store/migrator.go:27`); the whole `migration` tree is compiled into the binary via `//go:embed migration` at `store/migrator.go:44`, so no external file is needed at runtime. `TestFreshInstall` in `store/test/migrator_test.go:20` covers exactly this path.
