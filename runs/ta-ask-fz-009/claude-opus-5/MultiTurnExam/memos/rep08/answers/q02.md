**sqlite, mysql, postgres**

Migrations live under `store/migration/`, one directory per dialect — `store/migration/sqlite/`, `store/migration/mysql/`, `store/migration/postgres/` — each with versioned subdirectories plus a `LATEST.sql` baseline schema (e.g. `store/migration/sqlite/LATEST.sql`, `store/migration/mysql/LATEST.sql`, `store/migration/postgres/LATEST.sql`). These are the only three directories present, and they line up with the three driver implementations at `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`.

Note the coverage differs by dialect: sqlite has history back to 0.2, mysql from 0.17, postgres from 0.19 — older dialects were added later and start from a `LATEST.sql` baseline.
