The naming convention is consistent across the store package: singular Go struct in `store/<table>.go`, one file per table, with the dialect SQL for each living in the parallel `store/db/{sqlite,mysql,postgres}/<table>.go` files. Table DDL for all three is in the per-dialect baselines, e.g. `store/migration/sqlite/LATEST.sql` (`attachment` at line 55).

Note `attachment` was formerly `resource` — see the rename migrations at `store/migration/sqlite/0.26/00__rename_resource_to_attachment.sql` (and the mysql/postgres equivalents), so older references to a `Resource` struct are historical.
