**Mechanism:** Server-Sent Events (SSE) over plain HTTP — the stream endpoint sets `Content-Type: text/event-stream` at `server/router/api/v1/sse_handler.go:48`. Not WebSockets.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` with `Broadcast(event *SSEEvent)` at line 115, documented as "sends an event to all connected clients." Per-client fan-out is non-blocking (a slow client must not stall the broadcaster — asserted by `TestSSEHub_Broadcast*` in `server/router/api/v1/sse_hub_test.go`, notably the "must not block" case at :178). The HTTP-side subscriber/stream endpoint is `server/router/api/v1/sse_handler.go`.

**Handlers that broadcast through it** (all on `*APIV1Service`, reached via `s.SSEHub.Broadcast`):

| Handler | Broadcast site |
|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go:163` — guarded, skipped when invoked from `CreateMemoComment` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go:585` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go:126` — emits the parent-memo comment event |
| `UpdateMemo` (indirect) | via `dispatchMemoUpdatedSideEffects` → `server/router/api/v1/memo_update_helpers.go:71`, called from `UpdateMemo` at `memo_service.go:513` |
| `UpsertMemoReaction` | `server/router/api/v1/reaction_service.go:106` — `SSEEventReactionUpserted` |
| `DeleteMemoReaction` | `server/router/api/v1/reaction_service.go:161` — `SSEEventReactionDeleted` |

The de-duplication invariant is worth noting: comment creation calls `CreateMemo` with a `withSuppressSSE` context (`memo_service_comments.go:56`) so exactly one event fires — `memo.comment.created` for the parent instead of a generic `memo.created`. That contract is pinned by `TestCreateMemoComment_NoDuplicateSSEBroadcast` and `TestCreateMemoWithAttachment_NoDuplicateUpdatedSSEBroadcast` in `server/router/api/v1/sse_service_test.go`. Event payload construction (visibility, creator ID, parent resolution) is factored into `server/router/api/v1/sse_event_helpers.go`, which is what enforces visibility scoping on delivery.
