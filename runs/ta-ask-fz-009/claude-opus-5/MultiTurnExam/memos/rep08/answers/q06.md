**memo_relation**

A pure join table — no surrogate key, three columns, uniqueness on the whole triple:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

— `store/migration/sqlite/LATEST.sql:47-52`. Defined identically for all three dialects: `store/migration/mysql/LATEST.sql:46` and `store/migration/postgres/LATEST.sql:46`. The `type` column is what distinguishes a plain reference from a comment link, which is how `ListMemoComments`/`CreateMemoComment` (`proto/api/v1/memo_service.proto:82`) are backed. Store-layer access lives in `store/memo_relation.go`.
