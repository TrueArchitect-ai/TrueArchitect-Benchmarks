**Server-Sent Events (SSE) over HTTP; server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction**

Mechanism and topology:
- The hub is an in-process fan-out: `SSEHub` with `Subscribe(userID, role)` and `Broadcast(event *SSEEvent)` (`server/router/api/v1/sse_hub.go:115`). Events serialize to JSON and are dropped for clients whose buffer is full rather than blocking the broadcaster (`server/router/api/v1/sse_hub.go:113-117`) — availability over delivery guarantees. Being in-process, it does not fan out across multiple server instances.
- The endpoint is registered outside the gateway/Connect handlers, via `RegisterSSERoutes(gwGroup, s.SSEHub, s.Store, s.Secret)` (`server/router/api/v1/v1.go:125`), implemented in `server/router/api/v1/sse_handler.go`. The hub instance is created per service in `NewAPIV1Service` (`server/router/api/v1/v1.go:57`).

Broadcast sites:

| Handler | Event | Anchor |
|---|---|---|
| `CreateMemo` | `SSEEventMemoCreated` | `server/router/api/v1/memo_service.go:163` |
| `UpdateMemo` (via `dispatchMemoUpdatedSideEffects`) | `SSEEventMemoUpdated` | `server/router/api/v1/memo_update_helpers.go:71` |
| `DeleteMemo` | `SSEEventMemoDeleted` | `server/router/api/v1/memo_service.go:585` |
| `CreateMemoComment` | `SSEEventMemoCommentCreated` (on the *parent*) | `server/router/api/v1/memo_service_comments.go:126` |
| `UpsertMemoReaction` | `SSEEventReactionUpserted` | `server/router/api/v1/reaction_service.go:106` |
| `DeleteMemoReaction` | `SSEEventReactionDeleted` | `server/router/api/v1/reaction_service.go:161` |

One deliberate invariant: comments must emit exactly one event. `CreateMemoComment` calls `CreateMemo` under `withSuppressSSE(ctx)` (`server/router/api/v1/memo_service_comments.go:56`), and `CreateMemo` honors that with an `isSSESuppressed(ctx)` guard (`server/router/api/v1/memo_service.go:162`) so the generic `memo.created` is skipped in favor of `memo.comment.created`. Regression tests cover both that and the attachment path: `server/router/api/v1/sse_service_test.go:71,116`. Event construction helpers live in `server/router/api/v1/sse_event_helpers.go` (e.g. `buildMemoReactionSSEEvent`), which also resolves visibility/creator so the hub can filter per subscriber.
