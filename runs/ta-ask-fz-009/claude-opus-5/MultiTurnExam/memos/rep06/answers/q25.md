q25. **CEL (Common Expression Language, `github.com/google/cel-go`) — internal/filter/; the engine compiles the CEL string into a dialect-agnostic condition tree, then a per-dialect renderer emits a parameterized SQL `WHERE` fragment plus args that each driver appends to its query.**

The two-stage split is the key design point:

**Stage 1 — parse (dialect-free).** `Engine.Compile` (`internal/filter/engine.go:48`) runs the string through a CEL environment built from a schema of allowed fields (`internal/filter/schema.go`, via `NewSchema()`), converts the AST to a parsed expression, and lowers it into a `Condition` tree by `buildCondition` (`internal/filter/parser.go`). Two process-wide singletons exist: `DefaultEngine()` for memos and `DefaultAttachmentEngine()` for attachments (`internal/filter/engine.go:111,119`). Note `now` is frozen once per compile so one filter sees a single instant (`:17-20`).

**Stage 2 — render (dialect-specific).** `Program.Render` (`:96`) hands the tree to `newRenderer(schema, opts)` (`internal/filter/render.go`) with `RenderOptions{Dialect, PlaceholderOffset, DisableNullChecks}` (`:83`), returning a `Statement{SQL, Args}` (`:90`). The `PlaceholderOffset` is what lets Postgres-style `$N` numbering line up with args already accumulated by the caller.

**Wiring into the drivers.** Each dialect's `ListMemos` calls `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)` — `store/db/sqlite/memo.go:57,61` with `filter.DialectSQLite`, and the same pattern in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`. `AppendConditions` (`internal/filter/helpers.go:9-24`) wraps each fragment in parentheses and appends it to the driver's `where` slice, so filters AND together with the struct-field predicates (`ID`, `IDList`, etc.) — always as bound parameters, never string-interpolated values.

The same filter grammar is reused by `ShortcutService`: a shortcut stores a CEL filter string meant to be passed straight to `ListMemos` (`proto/api/v1/shortcut_service.proto:15-17,69-70`). Tests covering the grammar live in `internal/filter/functions_test.go` and `store/test/memo_filter_test.go`.
