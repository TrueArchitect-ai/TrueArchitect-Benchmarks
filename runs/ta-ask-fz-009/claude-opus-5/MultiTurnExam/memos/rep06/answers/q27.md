q27. **Go `embed` of the Vite build output (`dist/*`), served by Echo's static middleware with an SPA fallback to `index.html`; server/router/frontend/frontend.go**

How it's wired:

- **Embedding:** `//go:embed dist/*` → `var embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`), re-rooted via `fs.Sub(embeddedFiles, "dist")` in `getFileSystem` (`:115-117`). The compiled React bundle is baked into the binary at build time — no external web root at runtime.
- **Registration:** `FrontendService.Serve` (`:41`) installs `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` (`:54-57`) plus `spaFallbackMiddleware(frontendFS)` (`:59`) on the Echo instance, then `s.registerRoutes(e)`.
- **SPA fallback:** on a 404 for an extensionless path, the middleware serves `index.html` from the embedded FS (`:63-78`, `shouldServeFrontendHTML` at `:107-108`) so client-side routes like `/memos/xxx` resolve.
- **Boundary guard:** `shouldSkipFrontendStatic` (`:82-90`) excludes `/api/*`, `/file/*`, Connect's `/memos.api.v1.*` procedure paths, and `robots.txt`/`sitemap.xml`/`*/rss.xml` — so the static handler never shadows the API surface or the server-rendered SEO routes.
- **Caching contract:** HTML is `no-cache, no-store, must-revalidate`; hashed assets under `/assets/` get `max-age=3600, immutable`; other root assets get plain `max-age=3600` (`:23-27`, `setFrontendCacheHeaders` `:92-105`), with tests at `server/router/frontend/frontend_test.go:74`.

One consequence worth naming: because `dist/` must exist at Go compile time, the frontend build (`web/`) is a prerequisite of the server build.
