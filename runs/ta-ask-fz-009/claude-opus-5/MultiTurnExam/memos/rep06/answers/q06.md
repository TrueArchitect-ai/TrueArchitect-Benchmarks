q06. **memo_relation**

A join table keyed on `(memo_id, related_memo_id, type)` — the triple is the uniqueness invariant, so the same pair can be linked under different relation types (e.g. reference vs. comment). Defined identically in all three dialects: `store/migration/sqlite/LATEST.sql:47`, `store/migration/mysql/LATEST.sql:46`, `store/migration/postgres/LATEST.sql:46`; originally introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`.
