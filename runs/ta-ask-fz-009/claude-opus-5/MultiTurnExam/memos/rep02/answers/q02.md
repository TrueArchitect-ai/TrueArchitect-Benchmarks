q02. **MySQL, PostgreSQL, SQLite**

Migrations live in three dialect-scoped directories under `store/migration/`, each with versioned migration steps plus a `LATEST.sql` baseline:

- `store/migration/mysql/` (through `0.30/00__user_tag_setting.sql`, plus `LATEST.sql`)
- `store/migration/postgres/` (through `0.30/00__user_tag_setting.sql`, plus `LATEST.sql`)
- `store/migration/sqlite/` (oldest history, from `0.2/` onward, plus `LATEST.sql`)

The code graph confirms the same three-way split: table declarations group into exactly `store/migration/mysql`, `store/migration/postgres`, `store/migration/sqlite` — 11 tables each, so the schemas are kept in parity across dialects.
