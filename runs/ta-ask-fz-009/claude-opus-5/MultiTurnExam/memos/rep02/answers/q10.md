q10. **store/migration/sqlite/LATEST.sql**

The migrator embeds the whole `migration` tree (`store/migrator.go:44`) and, for an uninitialized database, applies the single full-schema file named by `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`) from the driver-specific directory — path layout `store/migration/{driver}/...` per `store/migrator.go:39`. For SQLite that resolves to `store/migration/sqlite/LATEST.sql`, which contains the current `CREATE TABLE` set (e.g. `memo_relation` at line 47).

Incremental files under `store/migration/sqlite/0.x/` are only applied on upgrade paths, not fresh installs (`store/migrator.go:27`, `:42`).
