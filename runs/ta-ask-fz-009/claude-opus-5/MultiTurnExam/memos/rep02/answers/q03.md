q03. **DB (`postgres.DB`) — `store/db/postgres/postgres.go:16`**

It's one of three concrete implementations of the store's `Driver` interface, alongside `mysql.DB` (`store/db/mysql/mysql.go:14`) and `sqlite.DB` (`store/db/sqlite/sqlite.go:16`). Note the struct name is just `DB` in each dialect package — the package path is what distinguishes them, so refer to it as `postgres.DB` to avoid ambiguity.
