q27. **Mechanism: Go `embed` — the built Vite bundle is compiled into the binary as `embed.FS` and served as static files by Echo, with SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

The wiring:

- `//go:embed dist/*` over `var embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`) — the compiled frontend must exist at `server/router/frontend/dist/` at build time, so the whole app ships as one self-contained binary with no external web server.
- `getFileSystem("dist")` roots a sub-FS on that embed (`:115-121`), and `FrontendService.Serve` mounts it via Echo static middleware (`:41-42`).
- **SPA fallback**: `spaFallbackMiddleware` intercepts a downstream 404 and returns `index.html` (`:63-77`) — but only for extension-less paths, `/` or `/index.html` (`shouldServeFrontendHTML`, `:107-108`). A missing hashed asset like `/assets/missing.js` still 404s rather than silently returning HTML (test pins this: `frontend_test.go:125-137`).
- **Boundary carve-outs**: `shouldSkipFrontendStatic` (`:82-90`) excludes `/api/*`, `/file/*`, the Connect prefixes `/memos.api.v1*`, and `/robots.txt`, `/sitemap.xml`, `*/rss.xml` — so the static handler never shadows the RPC or file-server routes.
- **Caching policy**: HTML is `no-cache, no-store, must-revalidate` plus `Pragma`/`Expires` (`:24`, `:92-97`), `/assets/*` (content-hashed) gets `max-age=3600, immutable` (`:26`, `:101-102`), other statics `max-age=3600` (`:25`).

The service also owns two dynamic SEO routes registered alongside — `GET /robots.txt` and `GET /sitemap.xml` (`:123-126`).
