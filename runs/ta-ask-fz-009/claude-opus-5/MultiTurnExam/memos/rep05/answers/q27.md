q27. **Go `embed.FS` — the Vite build output is compiled into the binary and served by Echo static middleware with SPA fallback; `server/router/frontend/frontend.go`**

The build artifacts are embedded at compile time via `//go:embed dist/*` into `embeddedFiles` (`server/router/frontend/frontend.go:20-21`), so the production binary is self-contained — no external web server or filesystem dependency. The `dist/` directory sits right next to the Go file (`server/router/frontend/dist`).

Wiring happens in `FrontendService.Serve` (`server/router/frontend/frontend.go:41`):

1. `getFileSystem("dist")` roots the embedded FS (line 42), then `middleware.StaticWithConfig` serves assets from it (lines 54-57).
2. `spaFallbackMiddleware(frontendFS)` (line 59) handles client-side routing: on a downstream 404 for an HTML-ish path it returns `c.FileFS("index.html", frontendFS)` (line 77) instead of the error — that's what makes deep links like `/u/alice` work.
3. A `Skipper` (lines 43-51) protects backend routes from being swallowed by the static handler. `shouldSkipFrontendStatic` (line 82) excludes `/api`, `/file`, `/memos.api.v1`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` — the last three because those are server-generated, not static assets.

Cache policy is deliberate (`setFrontendCacheHeaders`, line 49; constants at lines 24-26): `index.html` is `no-cache, no-store, must-revalidate` with `Pragma`/`Expires` belt-and-braces (lines 94-96), content-hashed files under `/assets/` get `max-age=3600, immutable` (lines 101-102), and other root assets get plain `max-age=3600`. Pinned by `TestFrontendService_StaticCacheHeaders` (`server/router/frontend/frontend_test.go:74`).
