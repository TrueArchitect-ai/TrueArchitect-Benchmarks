The factory switches on `profile.Driver` — a string from config — dispatching to `sqlite.NewDB`, `mysql.NewDB`, or `postgres.NewDB` (`store/db/db.go:18-27`), with an unknown value failing fast via `errors.New("unknown db driver")`.

The boundary is clean: `NewDBDriver` returns `store.Driver` (the interface at `store/driver.go:10`), and each per-dialect constructor does the same — e.g. `postgres.NewDB(profile) (store.Driver, error)` at `store/db/postgres/postgres.go:21`. So `store/db` is the only package that knows all three dialects exist; everything above it holds the interface. The per-entity method bodies live in sibling files within each dialect package (`store/db/postgres/memo.go`, etc.), which is why the SQL text differs per dialect while the contract doesn't.
