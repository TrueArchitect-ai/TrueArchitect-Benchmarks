q20. **Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction**

**Mechanism.** SSE over HTTP, not WebSockets. The hub is a fan-out registry of per-connection clients: `SSEHub` at `server/router/api/v1/sse_hub.go:56` ("manages SSE client connections and broadcasts events", line 54), built by `NewSSEHub()` (line 63), with `Subscribe(userID, role)` (line 71), `Unsubscribe` (line 89), `Close` (line 99), and `Broadcast(event *SSEEvent)` (line 115). The transport endpoint is separate: `RegisterSSERoutes` (`server/router/api/v1/sse_handler.go:25`) and `handleSSE` (`sse_handler.go:34`), wired into the CORS-enabled group next to the gRPC gateway (`server/server.go:87`).

**Broadcast sites.**

Direct `SSEHub.Broadcast` calls:
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (guarded; skipped when invoked via `CreateMemoComment`, per the comment at line 161)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (broadcasts for the *parent* memo so subscribers see the new comment)
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106`
- `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:161`

Indirect, via the shared helper `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66`, which broadcasts at line 71):
- `UpdateMemo` — `server/router/api/v1/memo_service.go:513`
- attachment mutation — `server/router/api/v1/memo_attachment_service.go:48`
- relation mutation — `server/router/api/v1/memo_relation_service.go:48`

**One invariant worth knowing:** broadcast is not unconditional fan-out — visibility is enforced at delivery. `Subscribe` records `userID` and `role`, and `TestSSEHub_PrivateEventsAreScoped` (`server/router/api/v1/sse_hub_test.go:119`) pins that private-memo events reach only entitled subscribers. Event kinds are constants like `SSEEventMemoCreated`, `SSEEventReactionUpserted`, `SSEEventReactionDeleted`; payload construction is factored into `server/router/api/v1/sse_event_helpers.go` (e.g. `buildMemoReactionSSEEvent`).
