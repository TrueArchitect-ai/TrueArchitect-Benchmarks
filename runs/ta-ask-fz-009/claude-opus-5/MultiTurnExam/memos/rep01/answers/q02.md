q02. **MySQL, PostgreSQL, SQLite**

Migrations live under three sibling dialect directories, each with per-version scripts plus a `LATEST.sql` baseline:

- `store/migration/mysql/` (0.17 → 0.30, `store/migration/mysql/LATEST.sql`)
- `store/migration/postgres/` (0.19 → 0.30, `store/migration/postgres/LATEST.sql`)
- `store/migration/sqlite/` (0.2 → 0.30, `store/migration/sqlite/LATEST.sql`)

The code graph confirms the same three-way split at the schema grain — 11 tables defined in each dialect's schema, no fourth dialect.
