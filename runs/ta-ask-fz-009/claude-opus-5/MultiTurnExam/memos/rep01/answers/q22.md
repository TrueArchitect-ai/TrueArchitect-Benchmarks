The chain:

1. **Handler → dispatcher.** `APIV1Service.CreateMemo` calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)` best-effort — a failure is logged, not returned (`server/router/api/v1/memo_service.go:156-159`).
2. **Dispatcher.** `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15`) is a thin wrapper over `dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.created")` (`:48`), which resolves the memo creator, loads that user's webhooks, and builds the payload via `convertMemoToWebhookPayload` (`:76`). Siblings share the same path with different activity types: `memos.memo.updated` (`:20`), `memos.memo.deleted` (`:25`), plus `DispatchMemoCommentCreatedWebhook` (`:30`), which targets the *parent* memo's owner instead.
3. **Delivery.** `internal/webhook` — `webhook.Post` does the JSON POST (`internal/webhook/webhook.go:126-152`) through a `safeClient` with an SSRF guard that blocks private IPs unless `AllowPrivateIPs` is set (`internal/webhook/validate.go`, exercised at `internal/webhook/webhook_test.go:90-92`).
4. **Signing.** Only when a signing secret is configured (`internal/webhook/webhook.go:133`): HMAC-SHA256 over `msgID + "." + timestamp + "." + body`, base64-encoded, emitted as three headers — `webhook-id` (`msg_<uuid>`), `webhook-timestamp` (unix seconds), and `webhook-signature` = `"v1," + signature` (`internal/webhook/webhook.go:139-149`). Secrets in the Standard Webhooks `whsec_<base64>` form are base64-decoded to raw key bytes; anything else is used verbatim, and a malformed `whsec_` secret fails loudly rather than signing with the wrong key (`resolveSigningKey`, `internal/webhook/webhook.go:97-102`). Without a secret, no signature headers are sent at all (`internal/webhook/webhook_test.go:140-160`).

One security invariant worth noting: the secret is stored on the user setting but never returned in list/create/update responses — it's revealed only through the dedicated `GetUserWebhookSigningSecret` endpoint, gated to the owner or an admin (`server/router/api/v1/user_service_webhooks.go:250-253`, guarded by `server/router/api/v1/user_webhook_test.go:17-20`).
