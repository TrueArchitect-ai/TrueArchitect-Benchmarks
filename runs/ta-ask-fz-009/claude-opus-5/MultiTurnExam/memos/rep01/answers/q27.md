q27. **Go `embed.FS` — the Vite build output is compiled into the binary and served as static files by Echo middleware, with SPA fallback to `index.html`; server/router/frontend/frontend.go**

How it's wired:

- **Embedding**: `//go:embed dist/*` → `var embeddedFiles embed.FS` (`server/router/frontend/frontend.go:20-21`). The React build must be present at `server/router/frontend/dist/` at compile time, so the frontend ships inside the single Go binary — no separate web server or volume mount.
- **Static serving**: `FrontendService.Serve` resolves the sub-filesystem via `getFileSystem("dist")` and installs `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` (`:42`, `:54-57`).
- **SPA fallback**: `spaFallbackMiddleware` catches 404s for extension-less paths and returns `index.html` so client-side routes resolve (`:63-80`, `:107-108`).
- **Boundary guard**: the skipper excludes backend territory from static handling — `/api/*`, `/file/*`, Connect's `/memos.api.v1.*` paths, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml`, which have their own handlers (`:82-90`).
- **Cache policy**: HTML is `no-cache, no-store, must-revalidate`; hashed assets under `/assets/` are `immutable`; other static files get `max-age=3600` (`:24-26`, `:92-105`), verified in `server/router/frontend/frontend_test.go:44-71`.
