**MySQL, PostgreSQL, SQLite**

Each dialect has its own migration tree under `store/migration/`, with a per-version directory sequence plus a `LATEST.sql` schema snapshot:

- `store/migration/mysql/` (0.17 → 0.30, `store/migration/mysql/LATEST.sql`)
- `store/migration/postgres/` (0.19 → 0.30, `store/migration/postgres/LATEST.sql`)
- `store/migration/sqlite/` (0.2 → 0.30, `store/migration/sqlite/LATEST.sql`) — the oldest and deepest history, since SQLite was the original driver

The code graph confirms the same three-way split at the schema level: table declarations group into exactly those three modules, 11 tables each (`[ArchMap query]`), so the dialects are kept at schema parity.
