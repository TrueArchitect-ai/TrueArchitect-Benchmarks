**memo_relation**

Defined in all three dialect schemas at parity: `store/migration/sqlite/LATEST.sql:47`, `store/migration/postgres/LATEST.sql:46`, `store/migration/mysql/LATEST.sql:46`.

It's a pure join table — no surrogate key, three columns:

- `memo_id` — the source memo
- `related_memo_id` — the target memo
- `type` — the relation kind (this is what distinguishes a `REFERENCE` link from a `COMMENT` parent-child link)
- `UNIQUE(memo_id, related_memo_id, type)` is the only constraint, so the same pair may be linked more than once under different types

Note there are no foreign keys declared here — referential integrity for these edges is enforced in the store layer, not the schema. The Go access methods live at e.g. `store/db/postgres/memo_relation.go` (`ListMemoRelations` at line 41, `DeleteMemoRelation` at line 153).
