**Driver — store/driver.go:10**

`store.Driver` is the single storage contract, spanning `store/driver.go:10` and roughly 76 lines, with **48 methods** — it's a wide, non-segregated interface covering every entity (memos, users, attachments, inboxes, IdPs, shares, reactions, settings) plus lifecycle/introspection (`Close`, `GetDB`, `GetDatabaseSize`).

Exactly three implementations satisfy it, one per dialect:
- `mysql.DB`
- `postgres.DB` (`store/db/postgres/postgres.go:16`)
- `sqlite.DB`

Wiring: `db.NewDBDriver` selects among the three per-dialect `NewDB` constructors (all return `store.Driver`), and `store.New` takes the interface as a parameter, holding it as a field on `store.Store` and re-exposing it via `store.Store.GetDriver`. So the interface is the only seam between the service layer and any specific database — adding a fourth backend means implementing all 48 methods.
