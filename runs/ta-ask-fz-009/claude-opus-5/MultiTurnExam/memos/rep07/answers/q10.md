**store/migration/sqlite/LATEST.sql**

The migrator resolves it by driver: migration files live at `store/migration/{driver}/...` and the full-schema file is named by the constant `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`). For an uninitialized database, `preMigrate` applies `LATEST.sql` rather than replaying the incremental version directories — explicitly for speed (`store/migrator.go:27`, `store/migrator.go:42`). The whole `migration` tree is embedded into the binary via `//go:embed migration` (`store/migrator.go:44`), so no external file needs shipping.

That file is the one containing the current table set — e.g. `memo_relation` at `store/migration/sqlite/LATEST.sql:47`. `store/test/migrator_test.go:20` (`TestFreshInstall`) is the test that pins this fresh-install path.
