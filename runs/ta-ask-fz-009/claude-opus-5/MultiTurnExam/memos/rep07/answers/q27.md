**Go `embed.FS` — the Vite build output is compiled into the binary and served as static files by Echo middleware; server/router/frontend/frontend.go**

How it's wired:

- `//go:embed dist/*` → `var embeddedFiles embed.FS` (`frontend.go:20–21`) bakes `server/router/frontend/dist/` — the built React bundle — into the executable, so production ships one binary with no external web root.
- `getFileSystem("dist")` (`:115–121`) unwraps it with `fs.Sub` into the `fs.FS` handed to `middleware.StaticWithConfig{Filesystem: frontendFS}` in `FrontendService.Serve` (`:41–57`).
- SPA client-side routing is handled by `spaFallbackMiddleware` (`:63–80`): on a 404 for an extension-less path it serves `index.html` from the embedded FS (`:77`), so deep links like `/u/alice` resolve to the React router.

Two boundary details worth knowing:

- `shouldSkipFrontendStatic` (`:82–90`) carves the API out of the static/fallback path — `/api/*`, `/file/*`, the Connect prefixes `/memos.api.v1*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` (those last three are server-rendered by `registerRoutes` at `:123–126` and the RSS service).
- Caching is deliberately tiered (`setFrontendCacheHeaders`, `:92–105`): HTML is `no-cache, no-store, must-revalidate`, hashed `/assets/*` are `immutable`, other static files get `max-age=3600` — verified by `server/router/frontend/frontend_test.go:74`.
