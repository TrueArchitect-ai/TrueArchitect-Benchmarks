**Premise correction: there is no GraphQL in this repository.** A case-insensitive search for `graphql|gqlgen|.graphql|apollo` across 1,042 files returns zero matches, and a glob for `**/*.{graphql,gql}` finds no schema files. No resolver layer, no schema-first tooling, no client library.

**Actual API surface — Protobuf-defined RPC, exposed three ways:**

**Schema of record**: `.proto` files under `proto/api/v1/` —
`ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`.

Everything else is generated from those into `proto/gen/` (Go server/client stubs, gRPC-Gateway bindings) and `web/src/types/proto/` (TypeScript types).

**Three protocol surfaces over the same service definitions:**

1. **Connect RPC** — the primary path the web client uses. Handlers in `server/router/api/v1/connect_services.go` (e.g. `CreateMemo` at `:306`), procedure constants in `proto/gen/api/v1/apiv1connect/*.connect.go`, wired via interceptors in `server/router/api/v1/connect_interceptors.go`.
2. **REST via gRPC-Gateway** — HTTP/JSON mappings declared as `google.api.http` annotations in the `.proto` files, compiled into `proto/gen/api/v1/*.pb.gw.go`. This yields the resource-oriented AIP-style routes, e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{memo.name=memos/*}`, `GET /api/v1/{name=users/*}`, `POST /api/v1/auth/signin` (route table anchored at `proto/gen/api/v1/memo_service.pb.gw.go:1745`, `user_service.pb.gw.go:2301`, `auth_service.pb.gw.go:331`).
3. **gRPC proper** — `proto/gen/api/v1/*_grpc.pb.go`.

**Non-RPC HTTP routes** exist alongside, registered directly on Echo rather than generated:
- File serving — `GET /file/attachments/:uid/:filename` and `GET /file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`)
- SSE stream — `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go:25`)
- RSS — `GET /explore/rss.xml`, `GET /u/:username/rss.xml` (`server/router/rss/rss.go:72,111`)
- Frontend/SEO — `GET /robots.txt`, `GET /sitemap.xml` (`server/router/frontend/frontend.go:128,143`)
- Health — `GET /healthz` (`server/server.go:44`)

The querying flexibility you might expect from GraphQL is instead provided by a CEL-based filter expression language on list endpoints — see `internal/filter/` (schema at `internal/filter/schema.go`, SQL rendering at `internal/filter/render.go`), used by `ListMemos` (`server/router/api/v1/memo_service.go:215`).
