**`webhook.Post` — `internal/webhook/webhook.go:120` (the actual `safeClient.Do` at `:152`); protection = a dial-time SSRF guard, `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`, with an admission-time check `webhook.ValidateURL` — `internal/webhook/validate.go:62`.**

How the pieces fit:

- **Delivery**: `Post` marshals the payload, builds the POST, optionally signs it with Standard Webhooks headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`, HMAC-SHA256, `webhook.go:133-150`), then executes via the shared `safeClient` (`webhook.go:152`). Response body is capped at 1 MiB (`webhook.go:158`) and non-2xx or non-zero `code` is an error (`webhook.go:163-177`).
- **Async path**: callers in the memo service use `PostAsync` (`webhook.go:184`) — `DispatchMemoCommentCreatedWebhook` and `dispatchMemoRelatedWebhook` at `server/router/api/v1/memo_service_webhooks.go:30,48` — which enqueues onto a bounded 128-slot channel drained by 4 worker goroutines that call `Post` (`webhook.go:39-55`). Overflow is dropped with a warning, so delivery is best-effort, not durable.
- **Protection, two layers**:
  1. *Dial time (the real defense)*: `safeDialContext` re-resolves the host and refuses to connect if any resolved IP is reserved (`webhook.go:59-77`). Because the check happens at dial, it also defeats DNS rebinding — the comment at `webhook.go:30-31` states exactly this intent.
  2. *Admission time*: `ValidateURL` rejects non-http(s) schemes and private-resolving hosts when webhooks are created/updated — `CreateUserWebhook`/`UpdateUserWebhook` (`server/router/api/v1/user_service_webhooks.go:53,106`).
- **Blocked ranges**: loopback, RFC-1918, link-local incl. cloud IMDS 169.254.169.254, plus IPv6 equivalents (`internal/webhook/validate.go:14-23`).
- **Escape hatch**: `webhook.AllowPrivateIPs` short-circuits `isReservedIP` (`validate.go:41-47`), set from the `--allow-private-webhooks` flag (default `false`) at `cmd/memos/main.go:49` and `:133`. Enabling it disables both layers at once.
