**`s3presign.Runner` (`server/runner/s3presign/runner.go:16`) — one immediate pass at startup, then every 12 hours — wired at `server/server.go:162-171` inside `startBackgroundRunners`, itself called from `Server.Start` at `server/server.go:129`.**

**What it does.** Attachments stored in S3 keep their public link in `Attachment.Reference` as a presigned URL. Presigned URLs expire, so the reference goes stale unless something re-signs it. The runner pages through S3-backed attachments in batches of 100 (`store.FindAttachment` with `StorageType: S3`, `GetBlob: false` — `server/runner/s3presign/runner.go:58-65`), and for each one:

- reads `payload.GetS3Object().LastPresignedTime`, and **skips** anything signed less than 4 days ago — presigned URLs are issued with a 5-day expiry (`internal/storage/s3/s3.go:77`), so this leaves a 1-day safety margin (`runner.go:85-91`);
- otherwise re-signs via `s3.Client.PresignGetObject` (`internal/storage/s3/s3.go:71`), using the attachment's own `S3Config` if present, else the instance storage setting (`runner.go:93-108`);
- writes back the new URL as `Reference` plus a refreshed `LastPresignedTime` through `Store.UpdateAttachment` (`runner.go:114-123`).

**Schedule.** `runnerInterval = time.Hour * 12` (`server/runner/s3presign/runner.go:27`); `Run` is a plain `time.Ticker` loop that exits on `ctx.Done()` (`runner.go:29-41`). Note the startup call is `RunOnce(ctx)` at `server/server.go:163` — **synchronous, on the caller's goroutine**, so a large S3 attachment table delays `Server.Start` returning. The ticker loop then runs in a goroutine under a dedicated cancellable context (`s3Context`, `server/server.go:156`) tracked in `backgroundRunnerCancels`/`backgroundRunnerWG` so `Shutdown` can cancel and wait on it (`server/server.go:140-143`).

One consistency note worth flagging: the 4-day skip threshold in the runner and the 5-day expiry in `internal/storage/s3/s3.go:77` are independent literals in different packages. Changing the expiry without changing the threshold silently removes the refresh margin — there's no shared constant binding them.
