**Premise correction: there is no GraphQL in this project.** A case-insensitive search for `graphql|gqlgen|\.graphqls|schema\.graphql` across all 1,042 files returns zero matches — no schema files, no resolver layer, no GraphQL dependency in `go.mod`.

**Actual API surface: Protobuf/gRPC service definitions, exposed over two HTTP transports.**

The schema of record is the `.proto` files in `proto/api/v1/`:

| Proto file | Service |
|---|---|
| `proto/api/v1/instance_service.proto` | InstanceService |
| `proto/api/v1/auth_service.proto` | AuthService |
| `proto/api/v1/user_service.proto` | UserService |
| `proto/api/v1/memo_service.proto` | MemoService |
| `proto/api/v1/attachment_service.proto` | AttachmentService |
| `proto/api/v1/ai_service.proto` | AIService |
| `proto/api/v1/shortcut_service.proto` | ShortcutService |
| `proto/api/v1/idp_service.proto` | IdentityProviderService |
| `proto/api/v1/common.proto` | shared types |

Generated Go bindings live in `proto/gen/api/v1/` (message/service stubs, e.g. `proto/gen/api/v1/memo_service.pb.go`, `..._grpc.pb.go`) with Connect handlers in `proto/gen/api/v1/apiv1connect/`. The TypeScript client types are generated into `web/src/types/proto/api/v1/` (e.g. `attachment_service_pb.ts`), so the proto files are the single contract shared by both sides.

Serving is wired in `APIV1Service.RegisterGateway` — `server/router/api/v1/v1.go:65`:

- **gRPC-Gateway** (REST/JSON transcoding): a `runtime.NewServeMux` at `:96`, with each of the eight services registered at `:99-122`, mounted on an Echo group at `:123`.
- **Connect protocol**: handlers from `apiv1connect`, wrapped by the Connect interceptor — the wrapper methods are in `server/router/api/v1/connect_services.go` (e.g. `CreateMemo` at `:306`, `UpdateMemo` at `:330`).

Two non-proto HTTP surfaces exist alongside it, and these are hand-rolled Echo routes rather than generated: the file server (`GET /file/attachments/:uid/:filename` and `GET /file/users/:identifier/avatar`, registered at `server/router/fileserver/fileserver.go:123-124`) and the RSS feeds (`server/router/rss/rss.go`).

Authorization is uniform across both RPC transports by design: a single `authorizer` built at `server/router/api/v1/v1.go:68` backs the gateway middleware (`:69-93`) and the Connect interceptor, with the method-level policy table in `server/router/api/v1/acl_config.go`.
