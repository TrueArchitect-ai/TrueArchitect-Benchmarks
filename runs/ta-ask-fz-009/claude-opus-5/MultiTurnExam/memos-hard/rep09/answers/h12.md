**Caveat on "default installation"**

`"sqlite"` is the default only in the absence of overrides. Viper also reads env vars and config files, so a Docker image or compose file setting `MEMOS_DRIVER=postgres` would bind `postgres.DB.CreateMemo` (`store/db/postgres/memo.go`) instead — with `$N` placeholders rather than `?`. The determination above holds for a bare `./memos` invocation with no configuration present.
