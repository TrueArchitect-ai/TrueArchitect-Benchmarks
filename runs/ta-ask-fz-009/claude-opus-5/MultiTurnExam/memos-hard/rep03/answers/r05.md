**Premise correction: there is no GraphQL. The API is defined in Protocol Buffers (`proto/api/v1/*.proto`), exposed as gRPC + Connect RPC + a REST/JSON gateway.**

### GraphQL does not exist here
Grepping `graphql|gqlgen|\.graphqls|type Query|type Mutation|apollo` across all **1042 files** returns zero matches, and a glob for `**/*.{graphql,graphqls,gql}` finds no schema files. There is no resolver layer, no schema-first SDL, no `/graphql` endpoint — nothing to point you at.

### The actual contract: 9 proto files
The schema of record lives in `proto/api/v1/`:
`ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`.

These are the hand-authored source; everything under `proto/gen/` is generated output. Store-side messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, seen earlier defining `MemoPayload.Property`).

### Three surfaces generated from one definition
1. **gRPC** — service descriptors in `proto/gen/api/v1/*_grpc.pb.go` (e.g. `apiv1.MemoService_ServiceDesc`).
2. **Connect RPC** — `proto/gen/api/v1/apiv1connect/*.connect.go`, with procedure constants like `AttachmentServiceCreateAttachmentProcedure` (`attachment_service.connect.go:36`). This is what the web client uses (`web/src/connect.ts`).
3. **REST/JSON gateway** — grpc-gateway bindings in `proto/gen/api/v1/*.pb.gw.go`, registered via `RegisterGateway` (`server/router/api/v1/v1.go:65`).

The gateway yields **75 REST endpoints** under `/api/v1/`, following Google AIP resource-name conventions rather than GraphQL's single-endpoint model — e.g. `GET /api/v1/memos`, `POST /api/v1/memos`, `PATCH /api/v1/{memo.name=memos/*}`, `DELETE /api/v1/{name=memos/*/reactions/*}`, `POST /api/v1/users:batchGet`. Seven services are exposed: AI, Attachment, Auth, IdentityProvider, Instance, Memo, Shortcut, User.

One consequence of the proto-first design: you don't edit the Go structs to change the API. You edit the `.proto` and regenerate, which is why `proto/gen/` shows up so heavily in reference counts.
