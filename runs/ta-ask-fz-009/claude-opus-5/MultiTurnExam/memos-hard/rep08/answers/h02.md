The delivery path:

- **`Post`** (`internal/webhook/webhook.go:120-180`) marshals the payload, builds the POST, optionally signs it with Standard-Webhooks HMAC-SHA256 headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`, lines 133-150), and executes via the package-level `safeClient` at line 152. Responses are read under a 1 MiB `LimitReader` (line 158).
- **`PostAsync`** (line 184) is the non-blocking entry point: it enqueues onto a bounded 128-slot channel (`asyncPostQueue`, line 39), drained by 4 worker goroutines started in `init()` (lines 42-55) that call `Post`. So outbound HTTP always executes inside `Post`, whether invoked directly or from a worker; a full queue drops the dispatch with a warning (lines 191-195).

The protection — two layers, one authoritative:

1. **Dial-time enforcement (the real guard).** `safeClient`'s `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37, 59-77`). It splits the target address, resolves the host itself, and rejects the connection if *any* returned IP is reserved. Because the check happens at connect time rather than at configuration time, it also defeats DNS rebinding — the comment at lines 30-31 states this intent explicitly.
2. **Admission-time validation.** `webhook.ValidateURL` (`internal/webhook/validate.go:62-83`) rejects non-`http`/`https` schemes and reserved-resolving hostnames when a webhook is created/updated, returning a gRPC `InvalidArgument`.

Both share `isReservedIP` (`internal/webhook/validate.go:44-54`), which tests against `reservedCIDRs` (lines 14-23): IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` — explicitly covering the cloud IMDS address `169.254.169.254` — plus IPv6 loopback, unique-local, and link-local. The CIDRs are parsed once into `reservedNetworks` in `init()` (lines 28-36), panicking on a malformed entry.

**Escape hatch:** the guard is globally disableable via `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`), which short-circuits `isReservedIP` to `false` (lines 45-47) and therefore switches off *both* layers at once. It is bound to the `--allow-private-webhooks` flag, default `false`, set at `cmd/memos/main.go:49` and declared at `cmd/memos/main.go:133`.
