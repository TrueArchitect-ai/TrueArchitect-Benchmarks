Engine: CEL (Common Expression Language, via `google/cel-go`) — internal/filter/engine.go

Mechanism: `internal/filter/engine.go` compiles the CEL filter string into a dialect-agnostic `Condition` tree (parsed/typed via `internal/filter/parser.go` and `ir.go` against a `Schema`), and `internal/filter/render.go`'s `renderer` (parameterized by `DialectName`, e.g. sqlite/mysql/postgres from `internal/filter/schema.go`) walks that tree to emit dialect-specific SQL fragments and placeholder args, which each store dialect implementation then splices into its `WHERE` clause.
