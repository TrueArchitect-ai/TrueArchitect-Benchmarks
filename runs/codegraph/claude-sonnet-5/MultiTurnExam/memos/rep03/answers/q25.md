Engine: CEL (Common Expression Language, via `google/cel-go`) — internal/filter/engine.go

Mechanism: the `Engine` (internal/filter/engine.go) compiles the filter string with a CEL environment into a CEL AST, which `internal/filter/ir.go`/`parser.go` convert into a dialect-agnostic `Condition` tree, and `internal/filter/render.go` walks that tree to render dialect-specific SQL (using per-dialect tokens, e.g. for date-part/timestamp expressions, keyed by `DialectName` in `internal/filter/schema.go`).
