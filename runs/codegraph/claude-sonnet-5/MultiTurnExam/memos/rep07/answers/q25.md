Engine: CEL (Common Expression Language, via `google/cel-go`) — internal/filter/engine.go

Mechanism: `filter.Engine` (internal/filter/engine.go) compiles the CEL filter string into a dialect-agnostic `Condition` tree via `Compile`, and `internal/filter/render.go` walks that tree to render a SQL WHERE clause, using each `Field`'s per-dialect `Expressions` map (defined in internal/filter/schema.go, keyed by `DialectSQLite`/`DialectMySQL`/`DialectPostgres`) to substitute the correct column expression/SQL syntax for the active database driver.
