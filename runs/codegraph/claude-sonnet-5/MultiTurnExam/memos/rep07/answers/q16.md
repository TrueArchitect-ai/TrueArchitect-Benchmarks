Within `Store.DeleteMemo` (store/memo.go:140), before deleting the memo row itself, the store layer deletes:
- memo_relation records where the memo is the source (`DeleteMemoRelation{MemoID: ...}`)
- memo_relation records where the memo is the target (`DeleteMemoRelation{RelatedMemoID: ...}`)
- attachments linked to the memo (`DeleteAttachment` for each attachment found via `ListAttachments`)

Additionally, at the API handler level (server/router/api/v1/memo_service.go:518-582), before calling `Store.DeleteMemo` on the memo itself, it first deletes any comment memos (via `store.MemoRelationComment` relations), each of which triggers the same relation/attachment cleanup recursively.
