q25. Engine: Google's CEL (Common Expression Language) via `cel-go`, wrapped in a custom filter engine at internal/filter/engine.go (`filter.Engine`, `NewEngine`).

Mechanism: `internal/filter/parser.go` compiles the CEL filter string into a dialect-agnostic `Condition` intermediate representation (internal/filter/ir.go), and `internal/filter/render.go` walks that IR with a `DialectName` (`sqlite`/`mysql`/`postgres`, defined in internal/filter/schema.go:14-16) to emit the appropriate SQL fragment/placeholders for each database, using per-dialect string templates registered in the schema (e.g. `DialectMySQL: "UNIX_TIMESTAMP(%s)"` vs `DialectPostgres: "%s"`).
