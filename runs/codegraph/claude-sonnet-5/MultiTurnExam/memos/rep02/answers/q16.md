Before deleting the memo row itself, `Store.DeleteMemo` (store/memo.go:140-158) deletes:
1. memo_relation records where this memo is the source (`MemoID`)
2. memo_relation records where this memo is the target (`RelatedMemoID`)
3. attachments linked to the memo (via `DeleteAttachment` for each)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), comment-type memos related to it are recursively deleted (each via `Store.DeleteMemo`) before the parent memo is deleted.
