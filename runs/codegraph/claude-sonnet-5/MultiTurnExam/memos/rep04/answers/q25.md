**Engine:** CEL (Common Expression Language, via `google/cel-go`) — `internal/filter/engine.go` (`Engine.Compile`/`CompileToStatement`, using `cel.Env`)

**Mechanism:** The CEL filter string is compiled into a dialect-agnostic `Condition` tree (`internal/filter/engine.go`), which a `renderer` (`internal/filter/render.go`) then walks and translates into dialect-specific SQL fragments by switching on `DialectName` (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`, defined in `internal/filter/schema.go`) at each comparison/function node, producing per-dialect SQL text and args in the returned `Statement`.
