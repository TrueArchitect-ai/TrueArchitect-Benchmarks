Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter` (`internal/filter/engine.go`, `internal/filter/parser.go`, `internal/filter/ir.go`, `internal/filter/render.go`, `internal/filter/schema.go`)

Mechanism: `Engine.Compile` (parser.go) parses the CEL filter string into a dialect-agnostic `Condition` IR tree, and a per-dialect `renderer` (render.go), parameterized by a `DialectName` (schema.go — e.g. SQLite/MySQL/Postgres), walks that tree to emit the appropriate SQL fragment (handling dialect-specific quirks like JSON boolean columns, string length functions, and LIKE escaping) which the store layer then embeds into the `ListMemos` query.
