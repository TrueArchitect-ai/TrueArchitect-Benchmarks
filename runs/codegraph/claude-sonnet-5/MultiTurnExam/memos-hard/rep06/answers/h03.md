**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic `IdentityProviderUserInfo` struct that any protocol implementation returns.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the concrete (and only) protocol implementation, `IdentityProvider`, implementing OAuth2 token exchange (`ExchangeToken`) and user-info retrieval (`UserInfo`), used by `server/router/api/v1/auth_service_sso.go`.
