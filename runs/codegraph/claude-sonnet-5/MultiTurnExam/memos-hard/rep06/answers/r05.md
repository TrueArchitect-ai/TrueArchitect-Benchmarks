**Premise correction:** There is no GraphQL schema anywhere in this repository — no `.graphql`/`.gql` files and no `graphql` references in any Go or proto source (`grep -rli "graphql" --include=*.go --include=*.proto .` and a filesystem search for `*.graphql`/`*.gql` both return nothing).

**Actual API surface:** The public API is defined via **Protocol Buffers** and exposed as gRPC + gRPC-Gateway (REST/JSON) + Connect:
- Proto service definitions live under `proto/` (source `.proto` files, e.g. `api/v1/memo_service.proto`, `api/v1/user_service.proto`, `api/v1/idp_service.proto`, etc., with generated code in `proto/gen/api/v1/`).
- Each service has a generated gRPC server interface (e.g. `proto/gen/api/v1/memo_service_grpc.pb.go`), a gRPC-Gateway REST shim (`proto/gen/api/v1/memo_service.pb.gw.go`) mapping HTTP routes like `/api/v1/{name=memos/*}` to RPCs, and a Connect handler (`proto/gen/api/v1/apiv1connect/`) for browser clients.
- These are all registered together in `server/router/api/v1/v1.go` (`APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65-147`), which wires the gRPC-Gateway mux and Connect handlers onto the Echo server.
- There's also an OpenAPI-driven MCP tool surface (`server/router/mcp/`), derived from the same proto-generated OpenAPI spec — not GraphQL either.

So the schema/contract equivalent to what was asked about is the `.proto` files under `proto/`, not a GraphQL SDL file.
