**Delivery function** — `Post` (`internal/webhook/webhook.go:120`), which builds and sends the outbound HTTP POST via `safeClient.Do(req)` (line 152); `PostAsync` (`internal/webhook/webhook.go:184`) queues calls to `Post` for async dispatch by worker goroutines started in `init()` (lines 42-55).

**Protection mechanism** — `safeDialContext` (`internal/webhook/webhook.go:59`), installed as the `DialContext` of the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname at dial time and rejects any resolved IP for which `isReservedIP` (`internal/webhook/validate.go:44`) returns true (loopback, RFC-1918 private, link-local/cloud-IMDS, and IPv6 equivalents defined in `reservedNetworks`, `internal/webhook/validate.go:14-26`) — this defeats DNS-rebinding since the check runs against the actual dial address rather than the original hostname. A separate pre-flight check, `webhook.ValidateURL` (`internal/webhook/validate.go:62`), performs the same reserved-IP validation at webhook create/update time (`server/router/api/v1/user_service_webhooks.go:74,161,182`).
