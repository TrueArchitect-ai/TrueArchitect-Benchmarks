**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which calls `markdownService.ExtractAll(content)` — the concrete implementation is `(*service).ExtractAll` in `internal/markdown/markdown.go:356`, a single goldmark AST walk over the memo's markdown content.

**Triggers** — recomputation happens whenever memo content is written:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before insert.
- `UpdateMemo`, only when the `content` path is present in the update mask — `server/router/api/v1/memo_service.go:447` recomputes and reassigns `memo.Payload` before the store write.

(A batch-recompute path also exists via `memopayload.Runner.RunOnce`/`RebuildMemoPayload` per-memo in `server/runner/memopayload/runner.go:27-72`, but per h08 that runner is never actually constructed or invoked in production — only the two call sites above run.)

**Extracted properties** — persisted into `Memo.Payload` (`storepb.MemoPayload`) and surfaced to clients as `Memo.Tags` and `Memo.Property` (`proto/gen/api/v1/memo_service.pb.go:242,252`):
- `Tags []string` — `#tag` occurrences (deduplicated, case-preserved), skipping tags inside links/images.
- `Property.Title` — text of a leading H1 heading, if the document's first block is one.
- `Property.HasLink` — any markdown link present.
- `Property.HasCode` — any code block/fenced code block/code span present.
- `Property.HasTaskList` — any task checkbox present.
- `Property.HasIncompleteTasks` — any unchecked task checkbox present.
- (Also `Mentions []string` extracted in the same pass, used for `@mention` resolution rather than list/preview display.)

Separately, the preview **snippet** (plain-text summary) is *not* stored in the payload — it's computed on demand via `MarkdownService.GenerateSnippet` at read/serialization time (e.g. `server/router/api/v1/memo_service_webhooks.go:85`, and comment/relation conversion in `memo_service_converter.go`), not cached alongside the memo.
