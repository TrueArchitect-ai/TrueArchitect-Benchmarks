**Premise correction:** There is no GraphQL API in this codebase. A repo-wide search for "graphql" across `.go` files and `go.mod` returns zero matches.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (`ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`), generated into `proto/gen/api/v1/`. It's served three ways simultaneously:
- **gRPC** — native gRPC service registration (`*_grpc.pb.go` files).
- **gRPC-Gateway** — REST/JSON transcoding (`*.pb.gw.go` files), wired via `RegisterGateway` in `server/router/api/v1/v1.go:65`.
- **Connect** (connectrpc.com/connect) — an additional HTTP/JSON+binary protocol (`proto/gen/api/v1/apiv1connect/*.connect.go`).

On top of that, there's also an MCP (Model Context Protocol) tool surface built from the same API, driven by an embedded OpenAPI spec (`server/router/mcp/openapi.go`, `server/router/mcp/service.go`), not GraphQL.
