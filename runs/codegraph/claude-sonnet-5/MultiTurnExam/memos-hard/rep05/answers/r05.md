**Premise correction:** There is no GraphQL schema anywhere in this repository — a search for `graphql`/`GraphQL` across the codebase returns zero hits.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC) service definitions** under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. These are compiled to Go bindings under `proto/gen/api/v1/` (gRPC server/client stubs, e.g. `proto/gen/api/v1/user_service_grpc.pb.go`) and exposed over HTTP via a gRPC-Gateway/Connect layer (`proto/gen/api/v1/apiv1connect/`, `*.pb.gw.go` files), registered in `server/router/api/v1/v1.go`. There's also a separate MCP (Model Context Protocol) surface with an OpenAPI-derived schema layer under `server/router/mcp/` (`openapi.go`, `catalog.go`), but that's OpenAPI/JSON-schema-based tool definitions for MCP, not GraphQL.
