computation site — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which calls `markdownService.ExtractAll(...)` — the actual extraction logic lives in `(*service).ExtractAll` in `internal/markdown/markdown.go:356-422` (a single goldmark AST walk).

triggers — recomputed whenever memo content is set or changed:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (payload rebuilt right after the memo is constructed, before insert).
- `UpdateMemo`, specifically when the `content` field is included in the update mask — `server/router/api/v1/memo_service.go:447`.
(It is not recomputed on operations that don't touch content, e.g. pin/visibility-only updates.)

extracted properties — set on `memo.Payload` (`storepb.MemoPayload`):
- `Tags` — collected from memo-tag nodes (`data.Tags`), deduplicated case-preserving.
- `Property.Title` — text of a leading H1 heading, if the document's first block is one.
- `Property.HasLink` — true if any Markdown link node is present.
- `Property.HasCode` — true if any code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — true if any task checkbox exists / if any checkbox is unchecked.
(Mentions are extracted in the same walk into `ExtractedData.Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property` onto the memo — see `server/runner/memopayload/runner.go:85-86`.)
