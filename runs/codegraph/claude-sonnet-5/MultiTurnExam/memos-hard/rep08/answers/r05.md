Premise correction — there is no GraphQL schema in this repository. A search for "graphql" across all `.go` and `.proto` files finds zero matches.

Actual API surface — the public API is defined as **Protocol Buffers / gRPC service definitions** under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to Go code under `proto/gen/api/v1/` and exposed over the wire in two ways simultaneously: as gRPC-Gateway-generated REST/JSON HTTP handlers (the `*.pb.gw.go` files, e.g. `proto/gen/api/v1/user_service.pb.gw.go`, wired via `RegisterUserServiceHandlerServer`) and as Connect-RPC handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`), both backed by the same `APIV1Service` implementation in `server/router/api/v1/`.
