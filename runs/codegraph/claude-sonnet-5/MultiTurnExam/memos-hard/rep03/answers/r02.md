**Premise correction:** There is no per-user API rate-limiting middleware in this codebase. A repo-wide search for "ratelimit"/"rate limit"/"throttle" across the Go source turns up only a single doc comment — `internal/email/doc.go:86` — which merely *suggests* as a design note that email sending "should" be rate-limited to prevent abuse. It is not backed by any actual implementation (no token bucket, no request counter, no middleware registration in `server/server.go` or the Echo middleware chain).

The request-handling middleware that *is* registered (in `server/server.go` / `server/router/api/v1/v1.go`) covers CORS, auth/authorization, logging, and recovery — none of it does request-count or rate-based throttling per user or otherwise.
