**Premise correction:** There's no GraphQL anywhere in this codebase — no schema files, no `graphql` imports, nothing.

**Actual API surface:** The public API is defined as **Protocol Buffers**, under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `webhook`-related messages, etc.), compiled into generated Go (`proto/gen/api/v1/`) and TypeScript (`web/src/types/proto/api/v1/`) code. It's served three ways from the same service definitions:
- **gRPC** (via generated `*_grpc.pb.go` servers)
- **gRPC-Gateway / REST-JSON** (`proto/gen/api/v1/*.pb.gw.go`, registered in `server/router/api/v1/v1.go:99-122` via `v1pb.Register*ServiceHandlerServer`)
- **Connect** (browser-friendly RPC, `proto/gen/api/v1/apiv1connect/`, registered at `server/router/api/v1/v1.go:139-144`)

There's also a curated OpenAPI-driven MCP surface (`server/router/mcp/`), but that's a tool-calling layer on top of the same REST/Connect endpoints, not GraphQL.
