**Protection mechanism:** the shared `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-37`, function defined at `internal/webhook/webhook.go:59-77`), which resolves the target host and rejects any IP matching `isReservedIP` — backed by `reservedNetworks`/`reservedCIDRs` in `internal/webhook/validate.go:14-54`. This blocks connections to loopback, RFC-1918 private ranges, and link-local/cloud-metadata addresses at dial time (defeating DNS rebinding too). A pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), applies the same `isReservedIP` logic when a webhook URL is created/updated in `server/router/api/v1/user_service_webhooks.go`.
