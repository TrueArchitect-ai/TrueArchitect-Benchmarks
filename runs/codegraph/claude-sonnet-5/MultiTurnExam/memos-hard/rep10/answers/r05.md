**Premise correction:** There is no GraphQL schema anywhere in this repository — `grep -ri graphql` across all `.go` files returns nothing, and there are no `.graphql`/`.gql` files.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), plus internal storage messages under `proto/store/`. These `.proto` definitions are compiled to Go (`proto/gen/api/v1/...`) and served over:
- **gRPC** and **gRPC-Gateway** (REST/JSON transcoding) — wired up via `apiV1Service.RegisterGateway(ctx, echoServer)` in `server/server.go:88`
- **Connect RPC** (`proto/gen/api/v1/apiv1connect/`)

There's also a separate MCP (Model Context Protocol) tool surface, described via JSON Schema (not GraphQL) in `server/router/mcp/openapi.go` (`jsonSchema`, `okSchema` etc.), used to expose API operations as MCP tools — but that's schema-for-tool-calling, not a GraphQL API.
