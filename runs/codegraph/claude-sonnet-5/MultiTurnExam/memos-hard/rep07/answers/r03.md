**Premise correction**: There is no nightly database-cleanup job actually scheduled anywhere in this application. The repository does contain a generic, reusable cron scheduler library at `internal/scheduler/` (`scheduler.go`, `parser.go`, `job.go`), but nothing outside that package's own tests ever calls `scheduler.New()` or `Register()` — a repo-wide search confirms it's never wired into `server/server.go` or `cmd/memos/main.go`.

The `"0 2 * * *"` / "2 AM daily" you may be thinking of is only a **documentation example**, in `internal/scheduler/doc.go:11-21`, showing hypothetical usage with a job named `"daily-cleanup"` and a placeholder `// Your cleanup logic here` handler — it is illustrative code in a package comment, not a real registered job, and no such job runs in the actual server. (The only real recurring background job in the server is the S3 presign refresher, which runs every 12 hours via its own ad hoc ticker — see `server/runner/s3presign/runner.go` — not this scheduler package.)
