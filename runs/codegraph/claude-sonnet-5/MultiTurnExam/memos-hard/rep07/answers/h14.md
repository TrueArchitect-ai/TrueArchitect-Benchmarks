**Computation site**: `internal/markdown/markdown.go` — the `markdown.Service` implementation's `ExtractAll` method (`internal/markdown/markdown.go:356-422`), invoked through `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which stores the result into `memo.Payload.Tags` / `memo.Payload.Property`. A related but separate computation, `GenerateSnippet` (`internal/markdown/markdown.go:264-346`), produces the plain-text preview snippet on demand via `(*APIV1Service).getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83-90`).

**Triggers** (recomputation of `Payload.Tags`/`Payload.Property` via `RebuildMemoPayload`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, run on every new memo before it's persisted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, run only when the update mask includes the `content` path.

(The snippet, by contrast, is recomputed on read/serialization — e.g. in `convertMemoFromStore`/list conversion at `server/router/api/v1/memo_service_converter.go:76,225,248`, in comment-relation building at `memo_relation_service.go:154,162`, and in notification building at `user_service_notifications.go:323` — not persisted, just generated fresh each time a `Memo` message is built.)

**Extracted properties** (from `ExtractedData` / `MemoPayload_Property`, `internal/markdown/markdown.go:21-25`, `193-241`):
- `Tags []string` — all `#tag` occurrences (deduplicated, case-preserved), excluding tags inside links/images.
- `Mentions []string` — all `@mention` occurrences (lower-cased, deduplicated) — extracted by `ExtractAll` but not stored in `Payload`; used separately by mention-notification logic (`server/router/api/v1/memo_mention_helpers.go:32`).
- `Property.Title` — text of the content's leading H1 heading, if the first block is one.
- `Property.HasLink` — true if any Markdown link is present.
- `Property.HasCode` — true if any code block/span is present.
- `Property.HasTaskList` — true if any task checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
