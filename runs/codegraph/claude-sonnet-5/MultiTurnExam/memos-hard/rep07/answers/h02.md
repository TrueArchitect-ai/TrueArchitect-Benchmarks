**Protection mechanism**: `safeDialContext` — `internal/webhook/webhook.go:59`, used as the `DialContext` of `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any resolved IP for which `isReservedIP` (`internal/webhook/validate.go:44`) returns true — blocking loopback, RFC-1918 private ranges, and link-local/cloud-metadata addresses (`reservedCIDRs`, `internal/webhook/validate.go:14-23`) — which also defeats DNS-rebinding since the check happens at actual dial time against the resolved IP, not just the hostname. (A companion pre-flight check, `ValidateURL` at `internal/webhook/validate.go:62`, performs the same reserved-IP check when a webhook URL is created/updated via `server/router/api/v1/user_service_webhooks.go`.)
