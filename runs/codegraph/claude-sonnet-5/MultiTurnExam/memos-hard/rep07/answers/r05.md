**Premise correction**: There is no GraphQL schema anywhere in this repository — a search for `.graphql`/`.gql` files and any `graphql` reference across the codebase returns nothing. This API is not GraphQL-based.

**Actual API surface**: The public API is defined as Protocol Buffers under `proto/api/v1/` (`auth_service.proto`, `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`), plus internal persistence messages under `proto/store/`. These are compiled to Go/TypeScript bindings in `proto/gen/`, and served three ways at runtime:
- **gRPC** directly (service implementations in `server/router/api/v1/*.go`, e.g. `APIV1Service`).
- **gRPC-Gateway** (REST/JSON over HTTP), registered via `apiV1Service.RegisterGateway` in `server/router/api/v1/v1.go:65-146`, using the generated `*.pb.gw.go` files.
- **Connect** protocol (for browser/web clients), registered in the same `RegisterGateway` method via `NewConnectServiceHandler`/`RegisterConnectHandlers` (`server/router/api/v1/v1.go:139-141`), using `proto/gen/api/v1/apiv1connect/`.

There's also a small OpenAPI-driven surface for MCP tool integration (`server/router/mcp/openapi.go`), but that's a wrapper over the same gRPC-Gateway routes, not a separate GraphQL layer.
