**Premise correction**: There is no per-user API rate-limiting middleware in this codebase. A repo-wide search for `rate limit`/`ratelimit`/`throttle`/`limiter` across all Go files turns up exactly one hit, and it's not an implementation — it's a doc-comment bullet point in `internal/email/doc.go:86` ("Rate limit email sending to prevent abuse") listed as a *security consideration* for callers of the email package, with no corresponding code.

**Actual mechanism**: Looking at the Echo server setup in `server/server.go` (`NewServer`, lines 44-99), the only middleware registered is `middleware.Recover()` and a CORS middleware (`newCORSMiddleware`) — no rate-limiting middleware (Echo's built-in `middleware.RateLimiter` or any custom equivalent) is wired in anywhere. Auth/permission enforcement exists (see the authorizer in `server/router/api/v1/v1.go`), but request-volume throttling per user does not.
