**Triggers (recomputation):**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108` — calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before the memo is first persisted.
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:447` — when the update mask includes the `content` path, it sets `memo.Content = request.Memo.Content` then calls `memopayload.RebuildMemoPayload(ctx, memo, s.MarkdownService)` to recompute before writing the update.

(The standalone `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27-72`, would bulk-recompute this for every memo, but per earlier analysis it is never constructed/invoked in production — only `RebuildMemoPayload` itself is used, directly from the two call sites above.)

**Extracted properties** (per `ExtractedData`, `internal/markdown/markdown.go:21-25`, and `storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-95`):
- `Tags` — all `#tag` nodes found in the content (deduplicated, case-preserved).
- `Mentions` — all `@mention` usernames found (lowercased, deduplicated) — used elsewhere for mention notifications, not stored directly in `Property`.
- `Property.Title` — text of the first H1 heading, if the document's first block-level child is one.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block/fenced code block/code span is present.
- `Property.HasTaskList` — true if any task checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
