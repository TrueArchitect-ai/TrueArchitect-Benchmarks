**Premise correction:** There is no GraphQL API in this repository — `grep -rli "graphql"` across all Go files returns nothing, and there are no `.graphql`/`.gql` schema files anywhere in the codebase.

**Actual API surface:** The public API is defined via Protobuf and served through gRPC + Connect + a gRPC-Gateway REST translation layer:
- Schema source: `.proto` files under `proto/` (e.g. `proto/api/v1/*.proto` — memo, user, attachment, auth, idp, ai, shortcut services), compiled into `proto/gen/api/v1/*.pb.go`.
- Server wiring: `APIV1Service` (`server/router/api/v1/v1.go`) implements the generated `*ServiceServer`/`*ServiceHandler` interfaces for each service.
- `RegisterGateway` (`server/router/api/v1/v1.go` / called from `server/server.go:88`) registers both the gRPC-Gateway (REST/JSON over HTTP, via `proto/gen/api/v1/*.pb.gw.go`) and Connect handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`, wired in `server/router/api/v1/connect_handler.go` / `connect_services.go`) on the same Echo server.
- There's additionally an MCP (Model Context Protocol) tool surface auto-derived from an OpenAPI-style schema (`server/router/mcp/openapi.go`, `catalog.go`) — also not GraphQL, but worth noting since it's the only other schema-driven API layer in the repo.
