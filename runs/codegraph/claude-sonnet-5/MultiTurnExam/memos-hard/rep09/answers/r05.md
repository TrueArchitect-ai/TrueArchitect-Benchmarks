**Premise correction**: this API is not GraphQL — there is no `graphql` reference anywhere in `go.mod` or the Go/TS source, and no `.graphql`/schema files in the repo.

**Actual API surface**: the public API is defined as Protocol Buffers under `proto/api/v1/*.proto` (service definitions like `memo_service.proto`, `user_service.proto`, etc.), compiled via `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`, `proto/buf.lock`) into generated Go/TS code in `proto/gen/`. From that single proto source, the server exposes three concrete surfaces: gRPC directly, a REST/JSON surface via grpc-gateway (`proto/gen/api/v1/*.pb.gw.go`, registered in `server/router/api/v1/v1.go`'s `RegisterGateway`), and Connect-RPC handlers for browser clients (`proto/gen/api/v1/apiv1connect/`). There's also an OpenAPI-derived schema (`proto/openapi_embed.go`) used by the MCP tool layer (`server/router/mcp/openapi.go`, `server/router/mcp/catalog.go`) to expose the same API as MCP tools.
