**Extracted properties** (from `internal/markdown/markdown.go` `ExtractedData`/`MemoPayload_Property`, via `service.ExtractAll`):
- `Tags` — all `#tag` nodes found in the content (deduplicated, case-preserved).
- `Mentions` — all `@mention` usernames (lowercased, deduplicated) — collected in `ExtractedData` but only `Tags`/`Property` are persisted onto `memo.Payload` by `RebuildMemoPayload`.
- `Property.Title` — text of a leading H1 heading, if the first block is one.
- `Property.HasLink` — whether the content contains a markdown link.
- `Property.HasCode` — whether it contains a code block/span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — presence of task-list checkboxes and whether any are unchecked.
