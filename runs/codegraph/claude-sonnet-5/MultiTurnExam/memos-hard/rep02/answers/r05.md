**Premise correction:** There is no GraphQL schema in this codebase — `grep -rli "graphql"` across the repo returns zero hits.

**Actual API surface:** The public API is defined as Protocol Buffers / gRPC service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), compiled to Go bindings in `proto/gen/api/v1/`. It's exposed over gRPC and, via grpc-gateway, as a REST/JSON HTTP surface — registered in `server/server.go:88` (`apiV1Service.RegisterGateway(ctx, echoServer)`), implemented by `APIV1Service` in `server/router/api/v1/`. There's also a separate MCP (Model Context Protocol) tool surface built from the same API in `server/router/mcp/` (using OpenAPI-derived JSON schemas, e.g. `server/router/mcp/openapi.go`), but that's OpenAPI/JSON-Schema-based tooling for MCP, not GraphQL either.
