- `Property.HasLink` — set if any Markdown link is present.
- `Property.HasCode` — set if any code block/fenced code block/code span is present.
- `Property.HasTaskList` — set if any task-list checkbox is present.
- `Property.HasIncompleteTasks` — set if any task-list checkbox is unchecked.
