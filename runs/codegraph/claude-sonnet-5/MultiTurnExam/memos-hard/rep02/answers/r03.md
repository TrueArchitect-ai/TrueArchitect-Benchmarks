**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this codebase. The `internal/scheduler` package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`) exists and supports cron-style job registration, but `scheduler.New`/`scheduler.Register` are never called from production code — the only usage is the illustrative example in `internal/scheduler/doc.go`, plus the package's own tests (`internal/scheduler/*_test.go`). No `*Scheduler` instance is ever constructed or started from `cmd/memos/main.go` or `server/server.go`.

The two background jobs that actually run in production are unrelated and don't use this scheduler at all:
- `s3presign.Runner.Run` (`server/runner/s3presign/runner.go:29-41`) — a plain `time.Ticker` firing every 12 hours, wired in at `server/server.go:161-171`, which re-presigns S3 attachment URLs (not a DB cleanup).
- The in-process cache's own `cleanupLoop` (`store/cache/cache.go:200-215`), which runs every 5 minutes (`CleanupInterval`, `store/store.go:42`) to evict expired in-memory cache entries — also not a database operation.

There is no cron expression, no "nightly" schedule, and no DB-cleanup job in the codebase.
