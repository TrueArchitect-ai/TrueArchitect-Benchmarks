**Premise correction:** There is no Redis anywhere in this codebase — `grep -rli "redis" --include=*.go .` returns zero hits. There's no external cache server or Redis client dependency at all.

**Actual mechanism:** Caching is an in-process, in-memory cache implemented in `store/cache/cache.go` (type `Cache`). It's constructed inside `store.New` at `store/store.go:38-61`, with a shared `cache.Config` (`store/store.go:40-45`):
```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```
The `Store` holds three such caches — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:27-29`). User entries (`store.User`) are cached in `userCache` (set/read in `Store.CreateUser`, `Store.UpdateUser`, `Store.ListUsers`, `Store.GetUser` in `store/user.go`), and since it uses the shared `cacheConfig`, the TTL applied to user entries is **10 minutes** (`DefaultTTL`).
