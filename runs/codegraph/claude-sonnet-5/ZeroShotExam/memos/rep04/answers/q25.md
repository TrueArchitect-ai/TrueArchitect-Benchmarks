**Engine + path:** Google's CEL (Common Expression Language, `github.com/google/cel-go/cel`), wrapped by memos' own filter engine in `internal/filter/` (key files: `engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`, `helpers.go`).

**Mechanism:** `server/router/api/v1/memo_service.go`'s `ListMemos` passes `request.Filter` through to `store.FindMemo.Filters`, which each dialect's `ListMemos` (`store/db/{mysql,postgres,sqlite}/memo.go`) hands to `filter.AppendConditions` → `Engine.CompileToStatement` (`internal/filter/engine.go`): CEL's `cel.Env.Compile` parses the string into a CEL AST, `buildCondition`/`buildCallCondition` in `internal/filter/parser.go` walk that AST against a `Schema` (`schema.go`) to build a dialect-agnostic `Condition` tree (`ir.go`), and finally `renderer.Render` in `render.go` walks that tree to emit a parameterized SQL WHERE fragment (with `?`/`$N` placeholders) tailored to the target `DialectName` (sqlite/mysql/postgres).
