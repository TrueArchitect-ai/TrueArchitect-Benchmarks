Mechanism: Server-Sent Events (SSE) over `GET /api/v1/sse` (client subscribes via `fetch`/`ReadableStream` in `web/src/hooks/useLiveMemoRefresh.ts`).

Hub path: `server/router/api/v1/sse_hub.go` — defines `SSEHub` (client registry + `Broadcast`/`Subscribe`/`Unsubscribe`), wired to the endpoint in `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes`/`handleSSE`).

Handlers that broadcast through it (all call `s.SSEHub.Broadcast(...)`):
- `CreateMemo` (server/router/api/v1/memo_service.go) — `memo.created`
- `DeleteMemo` (server/router/api/v1/memo_service.go:585) — `memo.deleted`
- `dispatchMemoUpdatedSideEffects` (server/router/api/v1/memo_update_helpers.go) — `memo.updated`
- `CreateMemoComment` (server/router/api/v1/memo_service_comments.go) — `memo.comment.created`
- `UpsertMemoReaction` / `DeleteMemoReaction` (server/router/api/v1/reaction_service.go) — `reaction.upserted` / `reaction.deleted`
