**Engine + path:** Google's CEL (Common Expression Language, via `github.com/google/cel-go`) is used as the filter syntax, wrapped by a custom filter engine at `internal/filter/` (`engine.go`, `parser.go`, `render.go`, `schema.go`).

**Mechanism:** `ListMemos` passes the request's `Filter` string (`server/router/api/v1/memo_service.go:211-216`) into `store.FindMemo.Filters`, and each dialect's store (`store/db/{mysql,postgres,sqlite}/memo.go`) calls `filter.DefaultEngine()` + `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect{MySQL,Postgres,SQLite}, &where, &args)`, where `Engine.Compile` (`internal/filter/engine.go:48`) compiles the CEL expression to an AST and `parser.go`'s `buildCondition` walks it into a dialect-agnostic `Condition` tree, which `render.go`'s `renderer.Render`/`renderCondition` (`internal/filter/render.go:32-89`) then converts into dialect-specific SQL fragments and args by switching on `DialectName` (`sqlite`/`mysql`/`postgres`, defined in `internal/filter/schema.go:11-17`) for things like column quoting/placeholders and dialect-specific SQL functions.
