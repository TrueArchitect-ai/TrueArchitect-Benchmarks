**Memo lifecycle events → dispatch functions** (all in `server/router/api/v1/memo_service_webhooks.go`, methods on `APIV1Service`):

- memo created: `DispatchMemoCreatedWebhook` (memo_service_webhooks.go:15) → activity type `memos.memo.created`
- memo updated: `DispatchMemoUpdatedWebhook` (memo_service_webhooks.go:20) → activity type `memos.memo.updated`, called from `server/router/api/v1/memo_update_helpers.go`
- memo deleted: `DispatchMemoDeletedWebhook` (memo_service_webhooks.go:25) → activity type `memos.memo.deleted`, called from `server/router/api/v1/memo_service.go`
- memo comment created: `DispatchMemoCommentCreatedWebhook` (memo_service_webhooks.go:30) → activity type `memos.memo.comment.created`, called from `CreateMemoComment` (`server/router/api/v1/memo_service.go`)

All four converge through the shared helper `dispatchMemoRelatedWebhook` (memo_service_webhooks.go:48, used by the created/updated/deleted variants — the comment variant inlines the same pattern), which builds a `webhook.WebhookRequestPayload` and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`).

**Delivery**: `webhook.PostAsync` enqueues the payload onto a bounded channel `asyncPostQueue` (`internal/webhook/webhook.go:39`); 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain the queue and call `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual signed HTTP POST to the webhook URL via `safeClient`.
