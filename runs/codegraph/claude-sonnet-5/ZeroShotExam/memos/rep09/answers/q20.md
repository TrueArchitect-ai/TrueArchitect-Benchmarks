q20. mechanism; hub path; handler names

**Mechanism:** Server-Sent Events (SSE) — an in-process pub/sub hub streams JSON `SSEEvent`s to browsers over a long-lived `text/event-stream` HTTP response (`GET /api/v1/sse`), with the client reconnecting via exponential backoff (`web/src/hooks/useLiveMemoRefresh.ts`).

**Hub path:** `server/router/api/v1/sse_hub.go` — defines `SSEHub` (client registry + `Broadcast`/`Subscribe`/`Unsubscribe`), wired up via `NewSSEHub` in `server/router/api/v1/v1.go` and served by `handleSSE` in `server/router/api/v1/sse_handler.go`.

**Handlers that broadcast through it** (all call `s.SSEHub.Broadcast(...)` in `server/router/api/v1/*.go`):
- `CreateMemo` (memo_service.go:163)
- `DeleteMemo` (memo_service.go:585)
- `UpdateMemo`, via `dispatchMemoUpdatedSideEffects` (memo_update_helpers.go:71)
- `CreateMemoComment` (memo_service_comments.go:126)
- `UpsertMemoReaction` (reaction_service.go:106)
- `DeleteMemoReaction` (reaction_service.go:161)
