Engine: **CEL (Common Expression Language)**, via `github.com/google/cel-go/cel`, wrapped by memos's own `internal/filter` package (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`, `helpers.go`).

Mechanism: `Engine.Compile` (internal/filter/engine.go:48) parses the filter string with a `cel.Env` into a CEL AST, then `buildCondition` (internal/filter/parser.go:18) walks the AST into a dialect-agnostic `Condition` IR tree (internal/filter/ir.go); `Program.Render` (internal/filter/engine.go:96) hands that tree to a `renderer` (internal/filter/render.go) whose `renderCondition`/`renderComparison`/etc. methods emit dialect-specific SQL + args based on a `RenderOptions.Dialect` (`sqlite`/`mysql`/`postgres`, internal/filter/schema.go:11-17), and `AppendConditions` (internal/filter/helpers.go:9) is called from each store backend's `ListMemos` (e.g. `store/db/{mysql,postgres,sqlite}/memo.go`) to splice the resulting WHERE fragment into the hand-built SQL query.
