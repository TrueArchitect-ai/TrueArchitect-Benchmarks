MemoService is served over two protocols:

1. **gRPC-Gateway (REST/JSON over HTTP, transcoded to gRPC)** — registered via `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` in `server/router/api/v1/v1.go:108` (inside `RegisterGateway`), which wires the generated handler defined in `proto/gen/api/v1/memo_service.pb.gw.go:961`.

2. **Connect protocol (Connect/gRPC-Web for browser clients)** — registered via `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` in `server/router/api/v1/connect_handler.go:40` (inside `RegisterConnectHandlers`), called from `RegisterGateway` at `server/router/api/v1/v1.go:141`.

Both registrations wrap the same `*APIV1Service` (`server/router/api/v1/v1.go:22`), which implements `MemoServiceServer`, so a single implementation backs both protocols.
