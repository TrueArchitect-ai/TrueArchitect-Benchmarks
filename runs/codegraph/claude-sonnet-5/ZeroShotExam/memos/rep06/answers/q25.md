**Engine + path:** Google's [cel-go](https://github.com/google/cel-go) CEL (Common Expression Language) library, wrapped by Memos' own filter engine in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`, `helpers.go`).

**Mechanism:** `Engine.Compile` (internal/filter/engine.go:48) uses a `cel.Env` (built from a `Schema`, e.g. `NewSchema()`) to parse and type-check the filter string into a CEL AST, then `buildCondition`/`buildCallCondition` (internal/filter/parser.go:18,48) walk that AST and translate it into a dialect-agnostic `Condition`/`ValueExpr` IR tree (internal/filter/ir.go); `Program.Render` (internal/filter/engine.go:96) hands that IR to a `renderer` (internal/filter/render.go) which, driven by `RenderOptions.Dialect` (`DialectMySQL`/`DialectSQLite`/`DialectPostgres`, schema.go), walks the tree via `renderCondition`/`renderFieldPredicate`/etc. to emit dialect-specific SQL fragments and args (`Statement{SQL, Args}`), which `filter.AppendConditions` then splices into the `WHERE` clause built by each dialect's `store/db/{mysql,sqlite,postgres}/memo.go` `ListMemos`.
