MemoService is served over two protocols, both wired up in `RegisterGateway` (`server/router/api/v1/v1.go`):

- **gRPC-Gateway (REST/JSON over HTTP)** — registered via `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` in `server/router/api/v1/v1.go:108`, whose generated handler code lives in `proto/gen/api/v1/memo_service.pb.gw.go` (`RegisterMemoServiceHandlerServer`, line 961), mounted at `/api/v1/*`.
- **Connect protocol (Connect/gRPC/gRPC-Web)** — registered via `apiv1connect.NewMemoServiceHandler(s, opts...)` inside `RegisterConnectHandlers` in `server/router/api/v1/connect_handler.go:40`, whose generated handler code lives in `proto/gen/api/v1/apiv1connect/memo_service.connect.go` (`NewMemoServiceHandler`, line 461), mounted at `/memos.api.v1.*`.

Both registrations are invoked from `RegisterGateway` in `server/router/api/v1/v1.go` (lines 108 and 140-141 respectively), called from `NewServer` in `server/server.go:88`. Note there is no separate native gRPC server (`grpc.NewServer`) in this codebase — both wrappers ride on the same Echo HTTP server, differentiated by URL path.
