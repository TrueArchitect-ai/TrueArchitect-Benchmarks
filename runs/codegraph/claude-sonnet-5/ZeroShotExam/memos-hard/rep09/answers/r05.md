**Premise correction:** This repository has no GraphQL schema — there is no `.graphql` file, no `graphql` package/import, and no GraphQL server code anywhere in the codebase. The public API is built on **Protocol Buffers / gRPC** instead.

**Actual API surface:**
- Service and message definitions live in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), with internal storage types in `proto/store/*.proto`.
- These are served over gRPC (and gRPC-Gateway/Connect for HTTP+JSON REST access), with generated Go/TS bindings consumed by the `server/` and `web/` directories.
- There is also a separate MCP (Model Context Protocol) surface with its own JSON-Schema/OpenAPI-style generation in `server/router/mcp/openapi.go` (functions `jsonSchema`, `okSchema`) and `server/router/mcp/catalog.go` — this is OpenAPI/JSON Schema, not GraphQL, and is used for the MCP tool catalog rather than the general public API.

So no GraphQL schema exists to point to; the closest analogous "public API schema" artifacts are the `.proto` files under `proto/api/v1/`.
