**Computation site:**
- Tags & Property (structured metadata persisted in `MemoPayload`): `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdownService.ExtractAll()` (interface in `internal/markdown/markdown.go:33`, impl at `internal/markdown/markdown.go:356-422`).

**Triggers (recomputation):**
- `CreateMemo` (`server/router/api/v1/memo_service.go:108`) — calls `memopayload.RebuildMemoPayload` before persisting a new memo.
- `UpdateMemo` when the `content` field is in the update mask (`server/router/api/v1/memo_service.go:436-451`) — recomputes and overwrites `memo.Payload.Tags`/`Property`, persisted via `store.UpdateMemo`.
- Batch backfill job: `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72` — pages through all memos and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each (used to reprocess existing memos, e.g. after logic changes).
- Snippet is recomputed on *every* read/response conversion (`convertMemoFromStoreWithCreators`), not cached — so it's effectively derived on each API response rather than stored/triggered by writes.

**Extracted properties:**
- From `ExtractAll` (single goldmark AST walk) → `ExtractedData{Tags, Mentions, Property}` (`internal/markdown/markdown.go:20-25`):
  - `Tags`: deduplicated `#tag` occurrences.
  - `Mentions`: deduplicated `@username` mentions (lowercased) — extracted but not stored in `MemoPayload` (only `Tags`/`Property` are copied onto the memo in `RebuildMemoPayload`, `runner.go:85-86`).
  - `Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-95`): `HasLink` (any markdown link), `HasCode` (code block/span/fenced block), `HasTaskList`/`HasIncompleteTasks` (task checkboxes, unchecked ones), `Title` (text of a leading H1 heading, if the document's first block is one).
- From `GenerateSnippet`: a plain-text truncated summary of the content (code blocks skipped, tags rendered as `#tag`, truncated to `maxLength` at a word boundary).
