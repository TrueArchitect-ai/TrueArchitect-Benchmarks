No; the internal `store/db/mysql` package is imported in exactly one place in the whole codebase — `store/db/db.go:8`, inside `NewDBDriver`, which is the driver-selection factory (`store/db/db.go:14-32`, `case "mysql": driver, err = mysql.NewDB(profile)`). `grep -rn "store/db/mysql\"" ` confirms no other file imports that package, so `mysql.NewDB`/`mysql.DB{}` is never constructed elsewhere.
