delivery function — `Post` (and its async wrapper `PostAsync`) in `internal/webhook/webhook.go:120` (`internal/webhook/webhook.go:184`), which performs the actual outbound `http.Client.Do` call via the shared `safeClient`.

protection mechanism — `safeDialContext` in `internal/webhook/webhook.go:59`, installed as the `DialContext` on `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname and rejects the dial if any resolved IP is reserved/private, using `isReservedIP`/`reservedNetworks` defined in `internal/webhook/validate.go:14-54`. This guards against DNS-rebinding since the check runs at actual dial time, not just at URL-registration time. A secondary check, `ValidateURL` in `internal/webhook/validate.go:62`, runs earlier when a webhook is created/updated (`server/router/api/v1/user_service_webhooks.go:74,161,182`) to reject URLs that resolve to reserved/private IPs up front, but the dial-time check in `safeDialContext` is what actually protects the delivery path itself.
