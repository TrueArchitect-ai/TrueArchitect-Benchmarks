**Data layer:** the `store/` package (`store/*.go`) defines the persistent entity types (`User`, `Memo`, `Attachment`, `MemoShare`, `MemoRelation`, `Inbox`, `Reaction`, `IdentityProvider`, `InstanceSetting`, `UserSetting`, `UserIdentity`), each backed by SQL tables via `store/db/{mysql,postgres,sqlite}`.

Counting distinct Go packages outside `store/` (and outside `proto/`) that reference `store.<Type>`:

- `store.User`: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` → 7 packages
- `store.Memo`: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` → 6 packages
- `store.Attachment`: 4 packages; `store.MemoShare`/`MemoRelation`/`Inbox`: 3 packages each — the rest trail further behind.

**Answer:** 1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)

`User` is referenced one package wider than `Memo` mainly because of `server/auth`, which only needs user/session data and never touches memos.
