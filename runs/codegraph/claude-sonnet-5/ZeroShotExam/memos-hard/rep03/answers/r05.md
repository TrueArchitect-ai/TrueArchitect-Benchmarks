**Premise correction:** This repository (memos) does not use GraphQL anywhere — there's no `.graphql`/`.gql` file and no `graphql` reference in the Go or TypeScript source. There is no GraphQL schema for the public API to point to.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto`). These define gRPC services that are also exposed as a REST/JSON API via a gRPC-gateway, and there's a separate OpenAPI/JSON-schema layer for MCP tooling at `server/router/mcp/openapi.go` (`jsonSchema`, `okSchema`). Persistence-layer message types live under `proto/store/` (e.g. `memo.proto`, `attachment.proto`, `inbox.proto`).
