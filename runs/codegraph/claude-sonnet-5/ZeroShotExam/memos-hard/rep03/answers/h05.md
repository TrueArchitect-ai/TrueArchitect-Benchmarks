**Evidence:**

This is identical, hand-written logic duplicated across all three DB backends (mysql/postgres/sqlite) — there is no `ON DELETE CASCADE` or trigger involved; the reaction table's foreign keys are enforced by application code performing explicit `DELETE FROM reaction ...` statements before the user row is removed.
