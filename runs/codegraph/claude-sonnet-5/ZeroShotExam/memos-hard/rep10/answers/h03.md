h03. `internal/idp`; `internal/idp/oauth2`

The `internal/idp` package defines the provider abstraction — `IdentityProviderUserInfo` (`internal/idp/idp.go:3`), the common user-info struct returned by any identity provider implementation. The only concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go:1-2`, `// Package oauth2 implements the OAuth2 identity provider integration.`), which provides `IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, and `UserInfo` methods.
