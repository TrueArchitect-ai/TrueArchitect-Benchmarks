**Handlers (RPC methods) that can transitively trigger an outbound HTTP request to a user-configured URL** (the URL comes from `WebhooksUserSetting_Webhook.Url`, which a user sets via `CreateUserWebhook`/`UpdateUserWebhook`):

- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`
- `APIV1Service.UpdateMemo` — via `server/router/api/v1/memo_update_helpers.go:67` calls `DispatchMemoUpdatedWebhook`
- `APIV1Service.DeleteMemo` — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`
- `APIV1Service.CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`

Each of these `Dispatch*Webhook` methods (`server/router/api/v1/memo_service_webhooks.go:15-46`) fetches the calling user's stored webhooks (`s.Store.GetUserWebhooks`), builds a `webhook.WebhookRequestPayload{URL: hook.Url, ...}`, and calls `webhook.PostAsync(payload)` — which enqueues onto `asyncPostQueue`, consumed by worker goroutines that call `Post`.

**Convergence function**: `Post` — `internal/webhook/webhook.go:120` (the actual delivery/dial happens at `safeClient.Do(req)`, line 152). Both the synchronous `Post` and the asynchronous `PostAsync` (`internal/webhook/webhook.go:184`, whose worker loop in `init()` at line 46 calls `Post`) funnel into this single function before the request is sent over the network.
