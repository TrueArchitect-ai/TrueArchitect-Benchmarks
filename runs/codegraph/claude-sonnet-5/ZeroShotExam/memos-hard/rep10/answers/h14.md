**Computation site:** `internal/markdown/markdown.go:356` (`service.ExtractAll`), invoked via `server/runner/memopayload/runner.go:74` (`RebuildMemoPayload`), which stores the result into `store.Memo.Payload.{Tags,Property}` (a `storepb.MemoPayload`, mirrored to the API as `Memo.tags` / `Memo.property` — see `proto/gen/api/v1/memo_service.pb.go:242,252` and `proto/gen/store/memo.pb.go:24-31`). `ExtractAll` does a single goldmark AST walk over the memo's markdown content (also exposed standalone as `ExtractTags`/`ExtractProperties`, markdown.go:143 and :193, but the production path uses the combined `ExtractAll` for efficiency).

**Triggers:**
- `CreateMemo` (server/router/api/v1/memo_service.go:108) — calls `memopayload.RebuildMemoPayload` before persisting a new memo.
- `UpdateMemo` (server/router/api/v1/memo_service.go, confirmed via call graph `UpdateMemo → RebuildMemoPayload`) — recomputes on every memo update (content edits go through this path).
- `Runner.RunOnce` (server/runner/memopayload/runner.go:27-71) — a background batch job that lists all memos in pages of 100 and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each; started at server boot via `startBackgroundRunners` (server/server.go).

**Extracted properties** (populated into `MemoPayload_Property` / `Memo_Property`, plus top-level `Tags`):
- `Tags` — all `#tag` nodes found in the content (from `TagNode`s, deduplicated case-preserving).
- `Property.Title` — text of the content's first block if it's an H1 heading.
- `Property.HasLink` — set when a `Link` AST node is present.
- `Property.HasCode` — set when a code block, fenced code block, or code span is present.
- `Property.HasTaskList` — set when a task checkbox (GFM task list item) is present.
- `Property.HasIncompleteTasks` — set when any task checkbox is unchecked.
- (Also `Mentions` is extracted in the same pass, from `MentionNode`s, though it's used for mention notifications rather than list/preview metadata.)
