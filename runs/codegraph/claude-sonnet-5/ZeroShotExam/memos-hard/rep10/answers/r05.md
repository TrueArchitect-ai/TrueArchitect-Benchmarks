**Premise correction:** This repository (Memos) does not use GraphQL anywhere — no `.graphql`/`.gql` files, no GraphQL server/client libraries, and a repo-wide search for "graphql" returns zero hits.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + gRPC-Gateway/REST), under `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, and shared types in `proto/api/v1/common.proto`. There's also an internal storage schema under `proto/store/*.proto`, and a separately hand-defined OpenAPI/JSON-schema layer for MCP tooling in `server/router/mcp/openapi.go`.
