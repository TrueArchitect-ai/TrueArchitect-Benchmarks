**Computation site**

Two distinct pieces of derived metadata, computed in different places:

1. **`Payload.Tags` and `Payload.Property`** (persisted) — computed in `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which calls `MarkdownService.ExtractAll` (interface: `internal/markdown/markdown.go:33`, impl: `internal/markdown/markdown.go:356`). The extraction logic that builds the `Property` booleans lives in `internal/markdown/markdown.go:192-226` (mirrored inline inside `ExtractAll` around lines 365-403).
2. **`Snippet`** (not persisted, computed on read) — computed by `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`internal/markdown/markdown.go:264-346`), called from `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76-80`) and from `batchConvertMemoRelations` (`memo_service_converter.go:221-252`) when building API responses.

**Triggers**

- `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:108`) — calls `memopayload.RebuildMemoPayload` when a memo is created.
- `APIV1Service.UpdateMemo` (`server/router/api/v1/memo_service.go:447`) — calls `RebuildMemoPayload` only when the `content` path is in the update mask (i.e., only if the content actually changed).
- `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) — a batch/backfill job that walks all memos and re-runs `RebuildMemoPayload` on each, persisting via `Store.UpdateMemo`; used to rebuild payloads en masse (e.g., after a markdown-extraction logic change/migration).
- `Snippet` is recomputed on every read/conversion to the API `Memo` message — i.e., every list/get response goes through `convertMemoFromStore*`, so it's not cached/triggered by writes at all, just derived fresh each time content is served.

**Extracted properties**

- From `ExtractAll`/`ExtractProperties` (parses the markdown once via goldmark):
  - `Tags` — all `#tag` occurrences (`ExtractTags`, markdown.go:36/143)
  - `Property.HasLink` — content contains a link (markdown.go:217/394)
  - `Property.HasCode` — content contains code block/span (markdown.go:220/397)
  - `Property.HasTaskList` — content contains a task list (markdown.go:223/400)
  - `Property.HasIncompleteTasks` — task list has unchecked items (markdown.go:226/403)
- From `GenerateSnippet`: a plain-text, code-block-stripped, word-boundary-truncated summary of the content (markdown.go:264-346), used for list/preview display and for related-memo previews.
