**Premise correction:** There is no GraphQL schema in this repository — no `.graphql`/`.graphqls` files, no `graphql` references in Go or TypeScript source (checked via repo-wide grep), and no GraphQL server library in `go.mod`/`package.json`.

**Actual API surface:** The public API is defined via **Protocol Buffers / gRPC**, not GraphQL:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Storage-layer messages: `proto/store/*.proto`
- Generated code lives in `proto/gen/`
- These gRPC services are exposed over HTTP via grpc-gateway/routing in `server/router/` (there's also a separate MCP/OpenAPI adapter under `server/router/mcp/openapi.go` for Model Context Protocol tooling, which is unrelated to GraphQL)

If you're looking for a GraphQL schema, it isn't part of this project — the API contract is proto-first (gRPC + REST gateway).
