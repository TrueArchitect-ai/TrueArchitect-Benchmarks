Premise correction: there is no GraphQL schema in this repository — the public API is not GraphQL at all.

Actual API surface: it's defined via Protocol Buffers under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), which are compiled to gRPC + REST (via grpc-gateway) handlers. A generated OpenAPI/Swagger description of the resulting REST surface lives at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`, and consumed by `server/router/mcp/openapi.go` for the MCP tool catalog (`server/router/mcp/catalog.go`).
