**Computation site**

Two separate derived-metadata computations, both backed by `internal/markdown/markdown.go`'s goldmark-based `Service`:

1. **Stored payload properties** — `memopayload.RebuildMemoPayload()` (`server/runner/memopayload/runner.go:74`), which calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356`) and writes the result into `memo.Payload.Tags` / `memo.Payload.Property` (persisted as JSON in the `memo.payload` column, e.g. `store/db/postgres/memo.go:16-49`, `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`).
2. **Snippet (not persisted, computed per-response)** — `APIV1Service.getMemoContentSnippet()` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `markdownService.GenerateSnippet()` (`internal/markdown/markdown.go:264`), invoked from `convertMemoFromStoreWithCreators()` (`server/router/api/v1/memo_service_converter.go:76-80`) every time a store `Memo` is converted to the API `Memo` message.

**Triggers**

- `RebuildMemoPayload` runs on: `CreateMemo` (`server/router/api/v1/memo_service.go:108`), `UpdateMemo` when the `content` field is in the update mask (`server/router/api/v1/memo_service.go:437-451`), and in bulk via the `memopayload.Runner.RunOnce` background job (`server/runner/memopayload/runner.go:27-71`), which re-processes every memo in batches (used for backfills/migrations).
- `getMemoContentSnippet`/`GenerateSnippet` runs on every store→API conversion (`convertMemoFromStoreWithCreators`), i.e. whenever a memo is returned from `CreateMemo`, `UpdateMemo`, `GetMemo`, `ListMemos`, etc. — it's recomputed from `memo.Content` on read, not cached in the payload.

**Extracted properties**

From `ExtractAll`/`ExtractProperties` (single goldmark AST walk, `internal/markdown/markdown.go:193-241` and `356-422`):
- `Tags` — all `#tag` nodes (deduplicated, case-preserved)
- `Mentions` — `@username` mention nodes (used internally, not stored in `MemoPayload`)
- `Property.HasLink` — presence of a markdown link
- `Property.HasCode` — presence of code block/fenced code block/code span
- `Property.HasTaskList` — presence of a GFM task checkbox
- `Property.HasIncompleteTasks` — an unchecked task checkbox exists
- `Property.Title` — text of the first-child H1 heading, if the document's first block is an H1

From `GenerateSnippet` (`internal/markdown/markdown.go:264-346`): a truncated (word-boundary-safe) plain-text summary of the content, skipping code blocks, used for list/preview display (`Memo.Snippet` in `proto/gen/api/v1/memo_service.pb.go:257`).
