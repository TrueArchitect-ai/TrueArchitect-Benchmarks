- **Wiring into server startup**: `server/server.go:153-174` (`startBackgroundRunners`) constructs it via `s3presign.NewRunner(s.Store)` (server.go:162), calls `RunOnce` immediately (server.go:163), then launches `Run` in a goroutine (server.go:169). `startBackgroundRunners(ctx)` itself is invoked from `Server.Start` at `server/server.go:129`.
