**Premise correction:** There is no GraphQL schema in this repository — a repo-wide search (`grep -ril graphql`, `find -iname *graphql*`) turns up zero matches. The public API is not GraphQL-based.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + gRPC-Gateway/REST), under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. These are compiled to generated code under `proto/gen/`, including a REST-facing description at `proto/gen/openapi.yaml` (with an embed shim at `proto/openapi_embed.go`). Separately, `server/router/mcp/openapi.go` builds an OpenAPI/JSON-schema representation for MCP tool integration, not a public GraphQL surface.
