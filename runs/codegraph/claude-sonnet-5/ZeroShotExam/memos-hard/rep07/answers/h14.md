**Computation site:**
- Persisted metadata (`tags`, `property` — `HasLink`, `HasCode`, `HasTaskList`, `HasIncompleteTasks`, `Title`) is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(memo.Content)` and stores the result into `memo.Payload.Tags` / `memo.Payload.Property`.
- The actual extraction logic lives in `internal/markdown/markdown.go`: `(*service).ExtractAll` (lines 356-422) does a single goldmark AST walk, extracting tags/mentions/properties together. (Equivalent standalone extractors `ExtractTags`, lines 143-170, and `ExtractProperties`, lines 192-241, exist but `ExtractAll` is what production code uses.)
- Separately, the `snippet` field is *not* persisted — it's recomputed on every read/conversion by `(*APIV1Service).convertMemoFromStoreWithCreators` in `server/router/api/v1/memo_service_converter.go:76-80`, via `getMemoContentSnippet` → `(*service).GenerateSnippet` (`internal/markdown/markdown.go:264-346`), which walks the AST to build a plain-text summary, truncated at a word boundary.

**Triggers for recomputation (persisted tags/property):**
1. `CreateMemo` (`server/router/api/v1/memo_service.go:108`) — always calls `RebuildMemoPayload` when a memo is created.
2. `UpdateMemo` (`server/router/api/v1/memo_service.go:447`) — only when the `content` path is present in the request's `UpdateMask` (i.e., the memo content itself changed), not on other field updates like visibility/pinned/state.
3. `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) — a batch job that lists all memos in pages of 100 and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each, used to backfill/rebuild payloads for existing memos (e.g., after a schema/extraction-logic change).

The `snippet` field recomputes on every conversion from store to API response (any read path that calls `convertMemoFromStore`/`convertMemoFromStoreWithCreators`), not just on writes.

**Extracted properties:**
- `Tags` — `#tag` nodes found in the content (deduplicated, case-preserved, tags inside links/images excluded).
- `Mentions` — `@username` mention nodes (lowercased, deduplicated) — used internally for notification dispatch, not stored in `Payload`.
- `Property.Title` — text of the content's first-block H1 heading, if present.
- `Property.HasLink` — whether any Markdown link node exists.
- `Property.HasCode` — whether any code block/fenced code block/code span exists.
- `Property.HasTaskList` — whether any task checkbox exists.
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked.
- (Separately, `Snippet` — plain-text excerpt of content, code blocks skipped, truncated to a max length — computed live, not stored.)
