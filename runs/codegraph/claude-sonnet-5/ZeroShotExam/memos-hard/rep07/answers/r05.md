**Premise correction:** This repository (Memos) has no GraphQL schema — there's no GraphQL server, resolver, or `.graphql`/`.gql` schema file anywhere in the codebase (confirmed via a repo-wide search for "graphql").

**Actual API surface:** The public API is defined via **Protocol Buffers** and exposed as gRPC + gRPC-Gateway (REST), not GraphQL:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`)
- Store-level messages: `proto/store/*.proto`
- Generated Go/OpenAPI artifacts: `proto/gen/api/v1/`, `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- Server-side routing/handling of these RPCs: `server/router/` (including an MCP/OpenAPI adapter layer at `server/router/mcp/openapi.go`, `server/router/mcp/catalog.go`)

So the "schema" equivalent for this public API is the `.proto` files under `proto/api/v1/`, with the REST surface auto-derived into `proto/gen/openapi.yaml`.
