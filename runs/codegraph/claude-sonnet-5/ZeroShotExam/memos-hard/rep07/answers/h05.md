**Mechanism:** Explicit Go code (not a DB-level cascade/trigger). When a user is deleted, the store driver runs `deleteUserTargetsTx`, which explicitly deletes the user's emoji reactions in two passes before removing the user row: reactions on the user's own memos (by content ID) and reactions the user personally created on any memo.
