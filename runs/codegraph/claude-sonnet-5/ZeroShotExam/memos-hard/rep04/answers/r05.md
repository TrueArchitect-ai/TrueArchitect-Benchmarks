**Premise correction:** There is no GraphQL schema in this repository — a repo-wide search for "graphql" across Go/TS/TSX/proto sources returns zero hits. This codebase does not use GraphQL anywhere.

**Actual API surface:** The public API is defined using **Protocol Buffers (gRPC)**, generated via `buf`:

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Internal store models: `proto/store/*.proto` (e.g. `memo.proto`, `attachment.proto`, `inbox.proto`, `idp.proto`, `user_setting.proto`, `instance_setting.proto`)
- Build/codegen config: `proto/buf.yaml` and `proto/buf.gen.yaml`

Additionally, there's a REST-style surface via an OpenAPI/MCP layer at `server/router/mcp/openapi.go` (schema helpers like `jsonSchema`/`okSchema`), which appears to expose/describe parts of the API for MCP tooling rather than a GraphQL schema.
