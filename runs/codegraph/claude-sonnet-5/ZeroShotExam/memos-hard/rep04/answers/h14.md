h14.

**Computation site:** `internal/markdown/markdown.go:356` — `(*service).ExtractAll`, invoked via the wrapper `server/runner/memopayload/runner.go:74` (`RebuildMemoPayload`), which writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (a single-pass goldmark AST walk; `ExtractProperties` at `internal/markdown/markdown.go:193` is the equivalent standalone version used elsewhere).

**Triggers (recomputation):**
- `CreateMemo` (`server/router/api/v1/memo_service.go:108`) — always, on every new memo.
- `UpdateMemo` (`server/router/api/v1/memo_service.go:447`) — only when the update mask includes the `content` path (i.e., only if the memo body actually changes).
- `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-71`) — a batch job that walks every memo via `ListMemos`/`UpdateMemo` and rebuilds the payload for all of them (a backfill/repair runner, not an event-driven trigger).

**Extracted properties** (`storepb.MemoPayload` / `MemoPayload_Property`, `internal/markdown/markdown.go:362-421`):
- `Tags` — all `#tag` nodes in the content (deduplicated, case-preserving).
- `Property.Title` — text of the H1 heading, if the first block-level node in the document is an H1.
- `Property.HasLink` — set if any Markdown link node is present.
- `Property.HasCode` — set if any code block, fenced code block, or inline code span is present.
- `Property.HasTaskList` — set if any task checkbox exists.
- `Property.HasIncompleteTasks` — set if any task checkbox is unchecked.
- (`ExtractAll` also collects `Mentions` — `@username` nodes — but these are used for mention notifications, not stored on `Payload`.)
