The data layer is the `store` package (Go, this is the Memos backend). It defines persistent entity types as structs in `store/*.go` (e.g. `store/user.go:29 User`, `store/memo.go:35 Memo`, `store/attachment.go:16 Attachment`, `store/inbox.go:24 Inbox`, `store/memo_relation.go:16 MemoRelation`, `store/memo_share.go:6 MemoShare`, etc.), consumed elsewhere via the `store.<Type>` qualifier.
