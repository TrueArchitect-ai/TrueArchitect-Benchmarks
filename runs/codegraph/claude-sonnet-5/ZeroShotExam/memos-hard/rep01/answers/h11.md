h11.

The persistent entity types are the Go structs defined in the `store` package (the data layer), e.g. `store/memo.go`, `store/user.go`, `store/attachment.go`, `store/reaction.go`, `store/inbox.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/user_identity.go`, etc.
