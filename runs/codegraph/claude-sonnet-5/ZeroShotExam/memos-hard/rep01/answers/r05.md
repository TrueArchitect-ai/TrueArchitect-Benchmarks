**Premise correction:** There is no GraphQL schema in this repository — a search for `graphql`/`.graphql`/`.gql` across the codebase returns nothing.

**Actual API surface:** The public API is defined using Protocol Buffers (gRPC + gRPC-Gateway/REST), under `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/ai_service.proto`, and shared types in `proto/api/v1/common.proto`. Internal storage messages live separately under `proto/store/*.proto`. Generated code is emitted to `proto/gen/api`, and the HTTP-facing router lives in `server/router/api`. Additionally, an OpenAPI/JSON-schema surface for MCP tooling exists at `server/router/mcp/openapi.go` (used by `server/router/mcp/catalog.go`), which is the closest thing to a "schema" file but is OpenAPI-based, not GraphQL.
