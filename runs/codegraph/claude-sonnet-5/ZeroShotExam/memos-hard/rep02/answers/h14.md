**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356-422`, implementing the `Service.ExtractAll` interface method declared at `internal/markdown/markdown.go:33`). This does a single goldmark AST walk over `memo.Content` and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-95`).

**Triggers (recomputation call sites):**
- `CreateMemo` (`server/router/api/v1/memo_service.go:108`) — always, on every new memo.
- `UpdateMemo` (`server/router/api/v1/memo_service.go:447`) — only when `"content"` is present in the request's `update_mask` (i.e. content is actually being changed), inside the `path == "content"` branch (`server/router/api/v1/memo_service.go:436-451`).
- `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) — a batch migration/backfill job that pages through all memos (`ListMemos`) and rebuilds+persists every memo's payload via `Store.UpdateMemo`, independent of any user edit.

**Extracted properties** (single AST walk, per `ExtractAll`/`ExtractProperties` in `internal/markdown/markdown.go`):
- `Tags` — all `#tag` nodes found in the content (deduplicated, case-preserved).
- `Mentions` — `@mention` nodes (used for mention resolution, not persisted into `Payload.Property`).
- `Property.Title` — text of the first block-level child if it's an H1 heading.
- `Property.HasLink` — set if any `Link` AST node is present.
- `Property.HasCode` — set if any code block/fenced code block/code span is present.
- `Property.HasTaskList` — set if any GFM task checkbox is present.
- `Property.HasIncompleteTasks` — set if any task checkbox is unchecked.

Note: a related but separately-computed field, `Memo.snippet` (plain-text preview), is generated on-demand at read/response time via `MarkdownService.GenerateSnippet` (`internal/markdown/markdown.go:264-346`), called from `getMemoContentSnippet`/`convertMemoFromStore` in `server/router/api/v1/memo_service_converter.go:76-80,225-252` — it is not persisted in `Payload` and is recomputed on every list/read rather than on write.
