There is no GraphQL schema in this repository — a repo-wide search for `.graphql`/`.gql` files and any "graphql" references (Go, TS/TSX, proto) returns nothing.

This is the Memos project, and its public API is defined via **Protocol Buffers**, not GraphQL:

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Internal storage schema: `proto/store/*.proto` (e.g. `memo.proto`, `attachment.proto`, `inbox.proto`, `idp.proto`, `user_setting.proto`, `instance_setting.proto`)

These proto definitions are served as gRPC and exposed as REST/JSON via a grpc-gateway, and additionally surfaced to LLM tooling through an OpenAPI/JSON-Schema layer at `server/router/mcp/openapi.go` (`jsonSchema`, `okSchema`) and `server/router/mcp/catalog.go`, used by the MCP router — again JSON-Schema/OpenAPI, not GraphQL.

If you were expecting a GraphQL API specifically, it doesn't exist in this codebase — the equivalent "schema" artifacts are the `.proto` files above.
