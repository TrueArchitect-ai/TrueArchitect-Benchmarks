The premise that there is a GraphQL schema is incorrect — this project does not use GraphQL. The public API is defined as a REST API using protocol buffers and gRPC-gateway.

The API surface is defined in:

- **Protocol Buffer definitions**: `proto/api/v1/*.proto` — these `.proto` files define the API service methods and message types (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, etc.)
- **Generated Go gRPC/REST code**: `proto/gen/api/v1/` — auto-generated from the proto definitions
- **OpenAPI spec**: `proto/gen/apidocs.swagger.yaml` — the generated OpenAPI/Swagger documentation for the REST API
- **Server route registration**: `server/router/` — where the gRPC-gateway handlers are mounted, including `server/router/mcp/` for the MCP (Model Context Protocol) adapter that exposes the API as MCP tools using OpenAPI schemas (`server/router/mcp/openapi.go`)
