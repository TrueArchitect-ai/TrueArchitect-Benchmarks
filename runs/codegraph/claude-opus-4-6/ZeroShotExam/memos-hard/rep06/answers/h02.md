**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). This is the function that marshals the payload, constructs the HTTP POST request, and sends it via `safeClient.Do()`. Asynchronous callers go through `PostAsync` (same file, line 184), which enqueues onto `asyncPostQueue`; worker goroutines (started in `init()`, line 42) drain that queue by calling `Post`.

**Protection mechanism** — SSRF protection lives in `internal/webhook/validate.go` and `internal/webhook/webhook.go`, applied at two layers:

1. **At registration time**: `ValidateURL` (`internal/webhook/validate.go:62`) resolves the webhook URL's hostname and checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), which matches against a list of reserved CIDRs (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) defined in `reservedNetworks` (`internal/webhook/validate.go:14–23`). This blocks users from registering webhooks that point at internal addresses.

2. **At delivery time** (defeating DNS rebinding): `safeDialContext` (`internal/webhook/webhook.go:59`) is wired as the `DialContext` on the `safeClient`'s transport. It re-resolves the hostname at connection time and rejects any IP that `isReservedIP` flags, so even if DNS answers change between registration and delivery, connections to private IPs are blocked.
