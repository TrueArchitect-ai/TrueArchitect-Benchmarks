The `internal/idp` package (`internal/idp/idp.go`) defines the provider abstraction — it declares the `IdentityProviderUserInfo` struct that all providers return. The `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`) ships the concrete OAuth2 protocol implementation.

**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**
