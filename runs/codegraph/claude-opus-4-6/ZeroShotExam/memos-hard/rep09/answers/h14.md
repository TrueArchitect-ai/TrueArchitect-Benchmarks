**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`. It delegates to `markdownService.ExtractAll()` (`internal/markdown/markdown.go:355-422`), which parses the memo's Markdown content via goldmark in a single AST walk and populates the payload.

**Triggers (operations that call `RebuildMemoPayload`):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108`, called before persisting a new memo.
2. **UpdateMemo** (content path) — `server/router/api/v1/memo_service.go:447`, called when the `"content"` field is in the update mask.
3. **Runner.RunOnce** (batch rebuild) — `server/runner/memopayload/runner.go:52`, iterates all memos in batches and rebuilds every payload (bulk recomputation on startup/migration).

**Extracted properties** (stored in `memo.Payload` as `storepb.MemoPayload`):
- **Tags** (`[]string`) — all `#tag` occurrences, deduplicated preserving case (`runner.go:85`, `markdown.go:376-378`).
- **Property.HasLink** (`bool`) — whether the content contains any Markdown link (`markdown.go:393-394`).
- **Property.HasCode** (`bool`) — whether the content contains a code block, fenced code block, or code span (`markdown.go:396-397`).
- **Property.HasTaskList** (`bool`) — whether the content contains a task checkbox (`markdown.go:399-400`).
- **Property.HasIncompleteTasks** (`bool`) — whether any unchecked task checkbox exists (`markdown.go:401-405`).
- **Property.Title** (`string`) — text of the first block-level H1 heading, if present (`markdown.go:384-388`).

Additionally, a **Snippet** (plain-text summary, max 64 chars) is computed at API response time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83-89`) via `GenerateSnippet`, called during `convertMemoFromStoreWithCreators` (`memo_service_converter.go:76-80`). Unlike the payload properties, the snippet is not persisted — it is derived on every read.
