**Premise correction:** This repository has no GraphQL schema whatsoever — zero `.graphql`/`.gql` files and zero references to "graphql" in the codebase.

**Actual API surface:** The public API is defined as a **gRPC API using Protocol Buffers**, with service definitions in `proto/api/v1/*.proto` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.). These are compiled via `buf` (configured in `proto/buf.yaml` / `proto/buf.gen.yaml`) into generated Go code at `proto/gen/api/v1/` and TypeScript types at `web/src/types/proto/api/v1/`. The gRPC services are exposed over HTTP via Connect (see `server/router/api/v1/connect_handler.go`). Additionally, an OpenAPI spec is embedded (`proto/openapi_embed.go`) and there is an MCP adapter layer at `server/router/mcp/` that maps the API to MCP tool schemas using OpenAPI introspection.
