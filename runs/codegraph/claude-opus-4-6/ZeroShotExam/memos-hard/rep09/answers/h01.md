**S3 presign runner** (`server/runner/s3presign/runner.go`) — refreshes pre-signed URLs for S3-stored attachments every **12 hours** (`runnerInterval = time.Hour * 12`, line 27) — wired into server startup at `server/server.go:153` in the `startBackgroundRunners` method (the runner is created at line 162, run once immediately at line 163, then launched as a continuous goroutine at line 169 via `s3presignRunner.Run`; `startBackgroundRunners` itself is called from `Server.Start` at line 129).

The runner iterates all S3-type attachments in batches, checks whether each presigned URL will expire within the next day (presigned URLs last 5 days; it re-signs any older than 4 days), generates a fresh presigned URL via `s3.Client.PresignGetObject`, and writes the new URL and timestamp back to the attachment record.
