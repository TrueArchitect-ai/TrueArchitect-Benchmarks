The `internal/idp` package (`internal/idp/idp.go`) defines the provider abstraction — it declares `IdentityProviderUserInfo`, the common struct returned by any identity provider. The `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`) ships the concrete OAuth2 protocol implementation, providing `IdentityProvider` which exchanges tokens and fetches user info via the OAuth 2.0 flow.
