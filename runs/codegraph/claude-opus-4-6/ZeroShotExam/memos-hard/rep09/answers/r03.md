The premise of the question is incorrect. There is no "nightly database-cleanup job" defined in the cron scheduler. The scheduler package (`internal/scheduler/`) is a general-purpose cron scheduling library. Its documentation and examples reference generic jobs like `"daily-cleanup"`, `"stale-session-cleanup"`, and `"cleanup"` as illustrative examples, but none of these are a "nightly database-cleanup" job, and none are actually registered or scheduled in the application code. The scheduler defines the infrastructure for scheduling jobs — it does not itself configure a specific database-cleanup job at any time.
