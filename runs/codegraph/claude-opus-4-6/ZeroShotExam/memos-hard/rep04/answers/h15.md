Memo visibility is enforced at the following distinct server surfaces:

1. **`checkMemoReadAccess` (GetMemo / individual memo reads)** — `server/router/api/v1/memo_service.go` (lines 39–68). Central helper that gates single-memo access: archived memos only visible to creator; non-public memos require authentication; private memos restricted to creator only.

2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go` (lines 218–227). Unauthenticated users see only PUBLIC; authenticated users see own + PUBLIC + PROTECTED; viewing another user's memos excludes PRIVATE.

3. **`CreateMemoComment` (commenting on a memo)** — `server/router/api/v1/memo_service_comments.go` (line 41). Private memos can only be commented on by their creator or an admin.

4. **Reaction service (UpsertMemoReaction / DeleteMemoReaction)** — `server/router/api/v1/reaction_service.go` (lines 30–38, 82–83). Both endpoints check memo visibility before allowing reaction creation or deletion.

5. **Attachment service (`checkAttachmentAccess`)** — `server/router/api/v1/attachment_service.go` (lines 445–451). Enforces memo visibility when accessing linked attachments via the attachment API.

6. **Memo attachment service (`GetMemoAttachment`)** — `server/router/api/v1/memo_attachment_service.go` (lines 214–222). Enforces visibility when serving attachments through the memo-scoped attachment endpoint.

7. **File server (direct file serving)** — `server/router/fileserver/fileserver.go` (lines 677, 699). Checks memo visibility when serving attachment files directly; private memos restricted to creator/admin.

8. **Frontend router (OpenGraph metadata)** — `server/router/frontend/frontend.go` (line 150). Only PUBLIC memos are queried for generating OG meta tags.

9. **User stats service** — `server/router/api/v1/user_service_stats.go` (lines 84–90, 218–220). Stats endpoints filter memos by visibility based on the requesting user's identity.

10. **SSE hub (live event delivery)** — `server/router/api/v1/sse_hub.go` (lines 135–141). Filters SSE event delivery based on memo visibility so private/protected events aren't broadcast to unauthorized clients.
