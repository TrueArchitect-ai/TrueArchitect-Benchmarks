**Premise correction:** This project does not use GraphQL at all. There is no GraphQL schema.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC/Connect, exposed as a RESTful API via gRPC-Gateway annotations. The schema is defined in `.proto` files under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, etc.). These proto definitions are compiled into Go code in `proto/gen/` and an OpenAPI spec at `proto/gen/openapi.yaml`. The server-side handlers implementing these services live in `server/router/api/v1/`.
