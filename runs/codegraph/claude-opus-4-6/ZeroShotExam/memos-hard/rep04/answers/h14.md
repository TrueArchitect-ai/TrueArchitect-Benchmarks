**Computation site:** `server/runner/memopayload/runner.go:74` — the `RebuildMemoPayload` function. It delegates to `markdown.Service.ExtractAll()` (`internal/markdown/markdown.go:356`), which parses the memo's markdown content in a single goldmark AST walk and extracts all derived metadata at once. A separate derived field, `snippet`, is computed at conversion time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`) calling `markdown.Service.GenerateSnippet()` (`internal/markdown/markdown.go:264`).

**Triggers (operations that cause recomputation):**
1. **Memo creation** — `CreateMemo` in `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting.
2. **Memo update (content change)** — `UpdateMemo` in `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `content` field is in the update mask.
3. **Batch rebuild at startup/migration** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) iterates all memos in batches and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each, recomputing every memo's payload.
4. **Snippet** is recomputed on every API read via `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76`).

**Extracted properties (from `ExtractAll` / `ExtractProperties`):**
- `Tags` — all `#tag` values found in content (deduplicated, case-preserved) → stored in `memo.Payload.Tags`
- `Property.Title` — text of the first block-level H1 heading (if present)
- `Property.HasLink` — whether the content contains any markdown links
- `Property.HasCode` — whether the content contains code blocks or code spans
- `Property.HasTaskList` — whether the content contains task checkboxes
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked
- `Snippet` — a plain-text summary (max 64 chars) generated from the markdown AST, skipping code blocks, truncated at a word boundary (computed at read time, not persisted in the payload)
