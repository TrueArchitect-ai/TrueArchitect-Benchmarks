There is no "nightly database-cleanup job" in this repository's cron scheduler. The scheduler code in `internal/scheduler/` defines a generic scheduling framework (`Schedule`, `Scheduler`, `Job` types in `internal/scheduler/parser.go`, `scheduler.go`, and `job.go`), but it does not contain any predefined job named "database-cleanup" or any nightly cleanup task. The scheduler is a library for registering and running arbitrary jobs on cron schedules — it does not ship with a built-in database-cleanup job.
