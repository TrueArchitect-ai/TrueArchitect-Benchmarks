**Computation site:** `internal/markdown/markdown.go` — two functions perform the extraction: `ExtractProperties` (line 192, standalone property extraction) and `ExtractAll` (line 355, combined extraction of tags, mentions, and properties in a single AST walk). Both parse the memo's Markdown content into a goldmark AST and walk it to detect node types. The results are assembled into a `storepb.MemoPayload_Property` struct. The `snippet` field is computed separately by `GenerateSnippet` (`internal/markdown/markdown.go:264`), which walks the AST to produce a plain-text summary (max 64 chars), called via `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`).

**Triggers (operations that cause recomputation):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` after creating the memo store object.
2. **UpdateMemo** — `server/router/api/v1/memo_service.go:447` calls `memopayload.RebuildMemoPayload` when the memo's `content` field is updated.
3. **Batch rebuild on startup** — `server/runner/memopayload/runner.go:27` (`RunOnce`) iterates all memos in batches and calls `RebuildMemoPayload` for each, used for migration/consistency.
4. **Snippet** is recomputed at read time during `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76`) every time a memo is converted to its API representation.

**Extracted properties** (stored in `MemoPayload_Property` / `Memo_Property`):
- `HasLink` (bool) — whether content contains a Markdown link (`gast.KindLink`)
- `HasTaskList` (bool) — whether content contains task checkboxes (`east.KindTaskCheckBox`)
- `HasCode` (bool) — whether content contains code blocks or inline code spans (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
- `HasIncompleteTasks` (bool) — whether any task checkbox is unchecked
- `Title` (string) — text of the first block-level H1 heading, if one exists
- `Tags` ([]string) — hashtags extracted from `#tag` nodes (stored on `MemoPayload.Tags`, not on `Property`)
- `Snippet` (string) — plain-text summary truncated to 64 characters at a word boundary, computed at read time (stored on the API `Memo.Snippet` field, not persisted in the payload)
