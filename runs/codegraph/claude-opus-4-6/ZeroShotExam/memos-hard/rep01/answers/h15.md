Memo visibility is enforced at these distinct server surfaces:

1. **GetMemo / checkMemoReadAccess** — `server/router/api/v1/memo_service.go` (line 39–67: rejects non-public memos for unauthenticated users; rejects private memos for non-creators)
2. **ListMemos** — `server/router/api/v1/memo_service.go` (lines 218–227: filters `VisibilityList` so unauthenticated users see only PUBLIC, other users see only PUBLIC+PROTECTED for others' memos)
3. **ListMemoReactions** — `server/router/api/v1/reaction_service.go` (line 30–41: checks memo visibility before listing reactions)
4. **UpsertMemoReaction** — `server/router/api/v1/reaction_service.go` (line 82–85: checks memo visibility before allowing a reaction)
5. **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (line 41: rejects commenting on private memos the user doesn't own)
6. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (line 222: checks memo visibility before listing its attachments)
7. **GetAttachment / checkAttachmentAccess** — `server/router/api/v1/attachment_service.go` (lines 422–455: enforces linked memo's visibility when accessing an attachment directly)
8. **File server (HTTP resource serving)** — `server/router/fileserver/fileserver.go` (line 699: enforces memo visibility when serving attachment files over HTTP, with share-token fallback at line 684)
9. **GetUserStats** — `server/router/api/v1/user_service_stats.go` (lines 84–91: filters memo visibility when computing per-user stats)
10. **GetUserStatsByDay** — `server/router/api/v1/user_service_stats.go` (lines 217–221: filters memo visibility for daily stats)
11. **Frontend sitemap/RSS** — `server/router/frontend/frontend.go` (line 150: only lists PUBLIC memos for sitemap generation)
12. **Mention/notification helpers** — `server/router/api/v1/memo_mention_helpers.go` (lines 62, 67: skips notifications for private memos the target user doesn't own)
