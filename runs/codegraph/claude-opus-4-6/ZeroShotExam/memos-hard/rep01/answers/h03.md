The provider abstraction is defined in `internal/idp` (file `internal/idp/idp.go`), which declares the `IdentityProviderUserInfo` struct used as the common return type. The concrete protocol implementation that ships is `internal/idp/oauth2` (file `internal/idp/oauth2/oauth2.go`), which implements the OAuth2 protocol — handling token exchange and user-info retrieval.
