The premise is incorrect — this project does not use GraphQL at all. The public API is defined as **Protocol Buffers (protobuf) + gRPC with gRPC-Gateway** (REST transcoding). The schema is defined in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.). These proto definitions are compiled into Go code in `proto/gen/api/v1/` (including `*.pb.go`, `*_grpc.pb.go`, and `*.pb.gw.go` for the HTTP/REST gateway). The server-side implementations live in `server/router/api/v1/`. Additionally, the project exposes an **MCP (Model Context Protocol)** adapter in `server/router/mcp/` and an **RSS** feed in `server/router/rss/`.
