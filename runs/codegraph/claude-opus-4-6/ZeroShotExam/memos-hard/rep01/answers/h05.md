Emoji reactions are removed by **explicit Go code**, not by a database-level rule. Two dedicated functions handle this within the user-deletion transaction (`deleteUserTargetsTx`):

1. **`deleteReactionsByContentIDsTx`** — deletes all reactions on the user's memos (`DELETE FROM reaction WHERE content_id IN ...`), covering reactions left by *any* user on content the deleted user owned.
2. **`deleteReactionsByCreatorTx`** — deletes all reactions the user themselves created on *any* content (`DELETE FROM reaction WHERE creator_id = ...`).

Both are called inside `deleteUserTargetsTx` (within a transaction) before memos and the user row are removed. This is identical across all three database drivers:

- `store/db/mysql/user_delete.go:96–103` (calls), `:420` and `:438` (SQL)
- `store/db/postgres/user_delete.go:96–103` (calls), `:383` and `:401` (SQL)
- `store/db/sqlite/user_delete.go:96–103` (calls), `:383` and `:401` (SQL)
