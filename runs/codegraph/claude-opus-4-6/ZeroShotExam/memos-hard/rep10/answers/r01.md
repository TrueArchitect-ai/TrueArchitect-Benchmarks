There is no Redis in this project. The cache layer is a **custom in-memory cache** implemented in `store/cache/cache.go` using Go's `sync.Map` with TTL-based expiration and a background cleanup goroutine.

The `userCache` is configured in `store/store.go:40-45` with the same `cache.Config` shared by all three caches (`instanceSettingCache`, `userCache`, `userSettingCache`):

- **DefaultTTL**: `10 * time.Minute` — user entries expire after 10 minutes
- **CleanupInterval**: `5 * time.Minute` — expired entries are swept every 5 minutes
- **MaxItems**: `1000` — if exceeded, the oldest 20% of items are evicted

No external cache service (Redis, Memcached, etc.) is used anywhere in the repository.
