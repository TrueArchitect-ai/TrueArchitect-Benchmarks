The premise of the question is incorrect. This repository (Memos) does not implement per-user API rate-limiting middleware. There is no rate-limiting interceptor, middleware, or throttling mechanism registered in the server's request pipeline. The server's gRPC/Connect interceptors (`server/router/api/v1/connect_interceptors.go`) handle authentication and authorization but not rate limiting. The only mention of "rate limit" in the codebase is a comment in `internal/email/doc.go` describing a future aspiration for email sending, not an implemented middleware. The `limit` references elsewhere in the code relate to pagination (`PageSize`/`Limit`), not request rate limiting.
