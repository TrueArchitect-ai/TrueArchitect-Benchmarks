**Computation site:** `server/runner/memopayload/runner.go:74` — the `RebuildMemoPayload` function. It calls `markdownService.ExtractAll()` (defined at `internal/markdown/markdown.go:356`) which parses the memo's Markdown content in a single AST walk and populates a `MemoPayload_Property` struct (defined at `proto/gen/store/memo.pb.go:85`). The snippet is computed separately at read time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `markdownService.GenerateSnippet()` (`internal/markdown/markdown.go:264`).

**Triggers:** `RebuildMemoPayload` is called on (1) **memo creation** (`server/router/api/v1/memo_service.go:108`) and (2) **memo update when the `content` field changes** (`server/router/api/v1/memo_service.go:447`, guarded by `path == "content"`). There is also a batch runner (`server/runner/memopayload/runner.go:27`, `RunOnce`) that iterates all memos and rebuilds their payloads (used for migration/reindexing). The snippet is computed on every API read (in the converter at `server/router/api/v1/memo_service_converter.go:76`), not persisted.

**Extracted properties:** From `ExtractAll`, stored in `memo.Payload`:
- `Tags` — deduplicated `#tag` strings extracted from the content
- `Property.HasLink` — whether the content contains a Markdown link
- `Property.HasTaskList` — whether the content contains task checkboxes
- `Property.HasCode` — whether the content contains code blocks or code spans
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked
- `Property.Title` — plain text of the first H1 heading, if present

Additionally, `Snippet` (a plain-text summary truncated to 64 characters at word boundary, with code blocks stripped) is computed on the fly at read time via `GenerateSnippet`, not stored in the payload.
