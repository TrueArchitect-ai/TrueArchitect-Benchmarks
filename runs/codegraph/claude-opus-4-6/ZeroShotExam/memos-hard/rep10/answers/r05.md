This repository does not use GraphQL. There is no GraphQL schema defined anywhere in the codebase. The public API is a REST API defined in Go using protocol buffers and an OpenAPI-derived surface.

The API is defined across these layers:

- **Protocol buffer definitions** in `proto/api/v1/*.proto` — these define the service RPCs and message types (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, etc.).
- **Generated Go code** from those protos lands in `proto/gen/api/v1/`.
- **HTTP routing** is wired up via gRPC-Gateway in `server/router/` (e.g., `server/router/v1/memo_service.go`, `server/router/v1/user_service.go`), which exposes the gRPC services as a RESTful JSON API.
- **An MCP (Model Context Protocol) adapter** in `server/router/mcp/` provides an additional machine-oriented surface, with its own OpenAPI-to-JSON-Schema conversion logic (`server/router/mcp/openapi.go`).

The premise that a GraphQL schema exists is incorrect; the actual public API surface is protobuf-defined REST (via gRPC-Gateway).
