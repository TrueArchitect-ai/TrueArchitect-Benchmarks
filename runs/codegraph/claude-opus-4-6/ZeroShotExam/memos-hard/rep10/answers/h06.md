1. **`CreateMemo`** (`server/router/api/v1/memo_service.go:70`) — calls `DispatchMemoCreatedWebhook` (line 157)

3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go:518`) — calls `DispatchMemoDeletedWebhook` (line 562)
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:20`) — calls `DispatchMemoCommentCreatedWebhook` (line 119)

All four paths converge on the single function **`webhook.Post`** (`internal/webhook/webhook.go:120`). The three `DispatchMemo*Webhook` helpers and `DispatchMemoCommentCreatedWebhook` all enqueue payloads via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which feeds the `asyncPostQueue` channel. The `init()` goroutines drain that channel and call `webhook.Post`, which is the single point where the actual outbound `HTTP POST` to the user-configured URL is executed (line 152: `safeClient.Do(req)`).
