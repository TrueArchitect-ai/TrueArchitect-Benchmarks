**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). It JSON-marshals the payload, builds an HTTP POST request (with optional HMAC-SHA256 signing), and sends it via `safeClient.Do()`. Asynchronous callers use `PostAsync` (line 184), which enqueues the payload onto a buffered channel consumed by 4 goroutine workers that each call `Post`.

**Protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go` (line 59) combined with `isReservedIP` / `ValidateURL` in `internal/webhook/validate.go`. Two layers defend against SSRF:

1. **At webhook registration time**: `ValidateURL` (`internal/webhook/validate.go:62`) resolves the URL's hostname and rejects it if any resolved IP falls within a reserved/private CIDR range (loopback, RFC-1918, link-local/cloud IMDS, IPv6 ULA and link-local — defined in `reservedCIDRs` at line 14).

2. **At delivery time** (defeating DNS rebinding): the `safeClient` HTTP client uses a custom `Transport` whose `DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:35`). This function re-resolves the hostname at dial time and checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), rejecting connections to any reserved/private address before a TCP connection is established.
