**Premise correction:** This project does not use GraphQL at all. There are no `.graphql`/`.gql` schema files and no GraphQL references anywhere in the codebase.

**Actual API surface:** The public API is defined as a **gRPC + REST (gRPC-Gateway)** service using **Protocol Buffers**. The `.proto` service definitions live in `proto/api/v1/` — including `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, and `ai_service.proto`. These are compiled (via `buf`, configured in `proto/buf.yaml` and `proto/buf.gen.yaml`) into Go code under `proto/gen/api/v1/`. An OpenAPI spec is also generated at `proto/gen/openapi.yaml`. The REST API is served through gRPC-Gateway in `server/router/api/v1/`.
