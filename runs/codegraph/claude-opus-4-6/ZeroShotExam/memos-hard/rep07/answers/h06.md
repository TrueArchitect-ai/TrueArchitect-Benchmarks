The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go:70`) — calls `DispatchMemoCreatedWebhook` at line 157
2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go:401`) — calls `DispatchMemoUpdatedWebhook` via `memo_update_helpers.go:67`
3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go:518`) — calls `DispatchMemoDeletedWebhook` at line 562
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:20`) — calls `DispatchMemoCommentCreatedWebhook` at line 119

All four paths converge on the single function **`webhook.Post`** (`internal/webhook/webhook.go:120`). The dispatch helpers (`DispatchMemoCreatedWebhook`, `DispatchMemoUpdatedWebhook`, `DispatchMemoDeletedWebhook`, `DispatchMemoCommentCreatedWebhook`) all call `webhook.PostAsync`, which enqueues the payload onto `asyncPostQueue`, and the `init()` goroutines drain that queue by calling `Post`. `Post` is where the actual `http.NewRequest` + `safeClient.Do` happens — it is the single convergence point before the outbound HTTP request is delivered to the user-configured URL.
