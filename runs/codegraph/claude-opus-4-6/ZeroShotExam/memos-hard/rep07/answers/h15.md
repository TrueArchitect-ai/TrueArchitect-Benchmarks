Memo visibility is enforced at the following distinct server surfaces:

1. **GetMemo / ListMemoComments (`checkMemoReadAccess` helper)** — `server/router/api/v1/memo_service.go` (line 39–68; called at lines 356, 367 for GetMemo, and line 148 in comments)
2. **ListMemos (query-level visibility filtering)** — `server/router/api/v1/memo_service.go` (lines 218–227, filters VisibilityList based on current user)
3. **CreateMemoComment (parent memo visibility check)** — `server/router/api/v1/memo_service_comments.go` (line 41, blocks commenting on private memos by non-creators)
4. **CreateReaction / DeleteReaction** — `server/router/api/v1/reaction_service.go` (lines 30–38 for create, line 83 for delete)
5. **RSS feed** — `server/router/rss/rss.go` (lines 90, 141 — only queries `store.Public` memos)
6. **Attachment download (`getAttachmentContent`)** — `server/router/api/v1/attachment_service.go` (lines 445–451, checks memo visibility before serving attachment bytes)
7. **SSE event delivery (`canReceive`)** — `server/router/api/v1/sse_hub.go` (lines 135–141, filters private events to creator only)
8. **User stats (GetUserStats / GetUserHeatmap)** — `server/router/api/v1/user_service_stats.go` (lines 84–90, 218–220, scopes memo counts by visibility)
9. **Frontend OpenGraph metadata** — `server/router/frontend/frontend.go` (line 150, only fetches public memos for `<meta>` tags)
10. **File server (shared memo file serving)** — `server/router/fileserver/fileserver.go` (lines 677, 699, checks visibility before serving files for shared memos)
11. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (lines 214–222, checks visibility before listing a memo's attachments)
12. **Mention notifications (suppression)** — `server/router/api/v1/memo_mention_helpers.go` (lines 62–67, suppresses notifications for private memos to non-creators)
