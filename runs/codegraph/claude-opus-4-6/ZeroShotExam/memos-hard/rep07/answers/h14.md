**Computation site:** `server/runner/memopayload/runner.go:74` — the `RebuildMemoPayload` function. It calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356`), which parses the memo's markdown content in a single goldmark AST walk and populates `memo.Payload.Tags` and `memo.Payload.Property`. The snippet (`Memo.Snippet`) is computed separately at response time in `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76`), which calls `getMemoContentSnippet` → `GenerateSnippet` (`internal/markdown/markdown.go:264`).

**Triggers:**
1. **Memo creation** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting the new memo.
2. **Memo update (content field)** — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `content` path is in the update mask.
3. **Batch rebuild on startup** — `server/runner/memopayload/runner.go:27` (`RunOnce`) iterates all memos in batches and rebuilds every payload, used for migration/re-indexing.
4. **Snippet** is recomputed on every read (each `convertMemoFromStoreWithCreators` call), not persisted in the store.

**Extracted properties:**
- `Tags` — all `#tag` tokens found in the content (`[]string`).
- `Property.HasLink` — whether the content contains a markdown link.
- `Property.HasCode` — whether the content contains a code block or code span.
- `Property.HasTaskList` — whether the content contains task checkboxes.
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked.
- `Property.Title` — text of the first H1 heading, if the document starts with one.
- `Snippet` (not stored, computed at read time) — a plain-text summary of the content, truncated to 64 characters at a word boundary, skipping code blocks.
