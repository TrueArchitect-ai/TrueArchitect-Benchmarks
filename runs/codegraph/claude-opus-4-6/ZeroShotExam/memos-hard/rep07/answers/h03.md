The `internal/idp` package defines the provider abstraction — it contains the `IdentityProviderUserInfo` struct that all provider implementations return (`internal/idp/idp.go`). The concrete protocol implementation that ships is in `internal/idp/oauth2`, which implements OAuth2-based identity provider logic (`internal/idp/oauth2/oauth2.go`).

**Abstraction package:** `internal/idp`; **Implementation package:** `internal/idp/oauth2`
