The `internal/idp` package defines the provider abstraction — it contains the `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that serves as the common contract for identity provider results. The concrete protocol implementation ships in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements an OAuth2 identity provider with token exchange and user-info retrieval.
