**Premise correction:** This project does not use GraphQL at all. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed as a REST-compatible API via gRPC-Gateway and documented with OpenAPI.

**Actual API surface:**

- **Protobuf service definitions** are in `proto/api/v1/*.proto` — these are the authoritative schema files. Key services include `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, and `ai_service.proto`.
- **Generated Go code** from those protos lives in `proto/gen/`.
- **OpenAPI spec** is generated from the protobuf definitions and embedded via `proto/openapi_embed.go`, with the MCP adapter layer in `server/router/mcp/openapi.go` consuming the OpenAPI schema to build its catalog.
- **Buf configuration** (`proto/buf.yaml`, `proto/buf.gen.yaml`) manages protobuf compilation and code generation.
- **HTTP handlers** are registered in `server/router/api/v1/`, which wire the gRPC services to RESTful HTTP endpoints.
