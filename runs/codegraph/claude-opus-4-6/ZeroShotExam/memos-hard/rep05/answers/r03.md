The premise of the question is incorrect. There is no "database-cleanup" job in the cron scheduler. The scheduler package contains only illustrative examples — such as a `"cleanup"` job in `internal/scheduler/example_test.go:99` (scheduled at `0 2 * * *`, i.e., 2:00 AM) and a `"daily-cleanup"` example in `internal/scheduler/doc.go` and `README.md`. These are generic documentation/test examples for how to use the scheduler library, not actual application jobs. There is no configured nightly "database-cleanup" job in this codebase.
