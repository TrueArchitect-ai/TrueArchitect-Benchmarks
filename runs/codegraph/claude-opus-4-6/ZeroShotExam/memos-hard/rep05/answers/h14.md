**Computation site:** The derived metadata is computed in two related places:
1. `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload()` calls `markdownService.ExtractAll()` which parses the memo's markdown content and extracts both tags and the `Property` struct in a single pass.
2. `internal/markdown/markdown.go:193` — `ExtractProperties()` is the core extraction logic that walks the goldmark AST to compute the property fields.

Additionally, a **snippet** (plain-text preview) is computed at conversion time in `server/router/api/v1/memo_service_converter.go:76` via `getMemoContentSnippet()` → `MarkdownService.GenerateSnippet()` (`internal/markdown/markdown.go:48`), which truncates to 64 characters.

**Triggers (operations that cause recomputation):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting.
2. **UpdateMemo** (when the `content` field is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` and writes the new payload to the store.
3. **Bulk rebuild on startup** — `server/runner/memopayload/runner.go:27` (`RunOnce`) iterates all memos in batches and rebuilds every payload (used for migrations/schema changes).

**Extracted properties** (stored in `MemoPayload_Property` / `Memo_Property`):
- `HasLink` (bool) — whether the content contains any markdown link (`gast.KindLink`)
- `HasTaskList` (bool) — whether the content contains any task checkbox (`east.KindTaskCheckBox`)
- `HasCode` (bool) — whether the content contains a code block or code span (`gast.KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
- `HasIncompleteTasks` (bool) — whether any task checkbox is unchecked
- `Title` (string) — text extracted from the first block-level H1 heading, if present
- `Tags` ([]string) — tags extracted from the content (via `ExtractAll`)
- `Snippet` (string) — a plain-text preview truncated to 64 characters, computed at API response time (not persisted in the payload)
