There is no GraphQL schema in this project. The public API is defined as a **gRPC API with REST/HTTP bindings** using Protocol Buffers, located in `proto/api/v1/`. The key service definitions include:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — File attachments
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/ai_service.proto` — AI features

These `.proto` files are compiled (via `buf.gen.yaml`) into Go server stubs in `proto/gen/` and TypeScript clients for the web frontend. HTTP/JSON endpoints are exposed through gRPC-Gateway annotations (`google.api.http` options in the proto files), making the API accessible as a conventional REST API as well.
