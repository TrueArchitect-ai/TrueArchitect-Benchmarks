Memo visibility is enforced at these distinct server surfaces:

1. **GetMemo / checkMemoReadAccess** — `server/router/api/v1/memo_service.go` (line 39–68, called at line 356)
2. **ListMemos query-level filtering** — `server/router/api/v1/memo_service.go` (lines 218–227, filters by VisibilityList/Filters based on current user)
3. **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (line 41, blocks commenting on private memos by non-creators)
4. **ListMemoComments** — `server/router/api/v1/memo_service_comments.go` (lines 158–160, visibility filter on comment listing)
5. **ListReactions (for a memo)** — `server/router/api/v1/reaction_service.go` (lines 29–38, checks memo visibility before returning reactions)
6. **UpsertReaction** — `server/router/api/v1/reaction_service.go` (lines 82–83, checks memo visibility before allowing reaction creation)
7. **GetMemoAttachment** — `server/router/api/v1/memo_attachment_service.go` (lines 213–222, checks memo visibility before serving attachment)
8. **GetAttachment (linked to memo)** — `server/router/api/v1/attachment_service.go` (lines 436–451, checks linked memo's visibility when serving attachment content)
9. **SSE event delivery filtering** — `server/router/api/v1/sse_hub.go` (lines 134–141, `canReceive` filters events by visibility per-client)
10. **GetUserMemosStats / ListUserStats** — `server/router/api/v1/user_service_stats.go` (lines 84–90, 218–220, visibility filtering on stat queries)
11. **ListMemoRelations** — `server/router/api/v1/memo_relation_service.go` (lines 109–111, visibility filter on related memos)
12. **convertMemoFromStore (referenced memos)** — `server/router/api/v1/memo_service_converter.go` (lines 184–186, visibility filter when resolving referenced memos in content)
