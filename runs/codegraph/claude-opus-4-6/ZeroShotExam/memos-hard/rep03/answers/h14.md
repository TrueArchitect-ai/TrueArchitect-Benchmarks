**Computation site:** `server/runner/memopayload/runner.go:74` — the `RebuildMemoPayload` function. It delegates to `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`) which parses the memo's markdown content in a single AST walk and returns an `ExtractedData` struct. The results are written to `memo.Payload.Tags` and `memo.Payload.Property`. A separate derived field, `snippet`, is computed at read time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`) which calls `markdown.Service.GenerateSnippet` (`internal/markdown/markdown.go:264`).

**Triggers (operations that cause recomputation):**
1. **Memo creation** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting.
2. **Memo update** (when `content` is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` and saves the new payload.
3. **Batch rebuild on startup** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) iterates all memos in batches and rebuilds every payload (migration/consistency path).
4. **Snippet generation at read time** — `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76`) calls `getMemoContentSnippet` every time a memo is converted for an API response.

**Extracted properties (from `ExtractAll` / `ExtractProperties`):**
- `Tags` — all `#tag` strings found in the content (deduplicated, case-preserved)
- `Property.HasLink` — whether the content contains any markdown links
- `Property.HasCode` — whether the content contains code blocks or code spans
- `Property.HasTaskList` — whether the content contains task checkboxes
- `Property.HasIncompleteTasks` — whether any task checkboxes are unchecked
- `Property.Title` — text of the first block-level H1 heading (if present)
- `Snippet` (computed at read time, not persisted in payload) — a plain-text summary truncated to 64 characters, derived by walking the AST and extracting text nodes while skipping code blocks
