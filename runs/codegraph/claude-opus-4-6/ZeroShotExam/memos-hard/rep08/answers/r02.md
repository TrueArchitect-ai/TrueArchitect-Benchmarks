The premise of the question is incorrect. This repository does not implement per-user API rate-limiting middleware. There is no rate-limiting middleware registered anywhere in the codebase. The only mention of "rate limit" is a documentation comment in `internal/email/doc.go` describing a hypothetical goal for email sending — it is not an implementation.
