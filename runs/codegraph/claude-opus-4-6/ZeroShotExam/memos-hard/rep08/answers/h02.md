**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). **Protection mechanism** — SSRF protection is implemented in `internal/webhook/validate.go` via two layers:

1. **At webhook creation/update time**: `ValidateURL` (line 62) resolves the webhook URL's hostname and checks every resulting IP against `isReservedIP` (line 44), which matches against a list of reserved CIDRs (`reservedCIDRs`, line 14) covering loopback, RFC-1918 private ranges, link-local/cloud IMDS (`169.254.0.0/16`), and IPv6 equivalents. URLs resolving to any of these are rejected with a gRPC `InvalidArgument` error.

2. **At delivery time (defeating DNS rebinding)**: The `safeClient` HTTP client (line 32 in `webhook.go`) uses a custom `Transport` with `safeDialContext` (line 59) as the dialer. This function re-resolves the hostname at connection time and checks the resolved IPs against the same `isReservedIP` function, blocking connections to reserved/private addresses even if DNS answers change between validation and delivery.
