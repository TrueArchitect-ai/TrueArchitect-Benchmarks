The premise that there is a GraphQL schema is incorrect — this project does not use GraphQL. The public API is defined as a REST API using Protocol Buffers and gRPC with an HTTP gateway.

The API surface is defined in:

- **Protocol Buffer definitions**: `proto/api/v1/*.proto` files define the service RPCs and message types (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/workspace_service.proto`, etc.)
- **OpenAPI spec** (generated from protobuf): `proto/gen/apidocs/apidocs.swagger.yaml`
- **Go server implementation**: `server/router/api/v1/` contains the gRPC service implementations
- **gRPC-Gateway HTTP routing**: configured via `google.api.http` annotations in the `.proto` files, which map gRPC methods to REST endpoints
