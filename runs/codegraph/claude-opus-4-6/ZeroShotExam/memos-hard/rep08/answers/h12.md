**Determination method:** The application uses a `store.Driver` interface (`store/driver.go:10`) with three implementations — `sqlite`, `mysql`, and `postgres` — each in `store/db/<driver>/memo.go`. The driver is selected at startup via `db.NewDBDriver` (`store/db/db.go:14`), which switches on `profile.Driver`. In `cmd/memos/main.go:122,130`, the default for the `driver` flag is `"sqlite"`. So with no database flags, `profile.Driver` is `"sqlite"`, causing `NewDBDriver` to call `sqlite.NewDB` (`store/db/sqlite/sqlite.go:24`), which returns the SQLite `*DB`. When a memo is saved, the gRPC service (`server/router/api/v1/memo_service.go:115`) calls `s.Store.CreateMemo`, which delegates via `s.driver.CreateMemo` (`store/memo.go:113`) to the SQLite implementation at `store/db/sqlite/memo.go:16`.
