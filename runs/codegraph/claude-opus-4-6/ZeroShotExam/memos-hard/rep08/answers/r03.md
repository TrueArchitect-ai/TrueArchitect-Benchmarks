The premise of the question is incorrect. There is no "nightly database-cleanup job" defined in the cron scheduler. The scheduler package (`internal/scheduler/`) is a general-purpose cron scheduling library — it does not define any specific application jobs. The references to cleanup jobs in the codebase are only illustrative examples in documentation and test files (`internal/scheduler/README.md`, `internal/scheduler/example_test.go`, `internal/scheduler/doc.go`), such as a "cleanup" example scheduled at 2 AM and a "daily-cleanup" example. None of these are actual scheduled jobs, and none reference "database-cleanup" specifically.
