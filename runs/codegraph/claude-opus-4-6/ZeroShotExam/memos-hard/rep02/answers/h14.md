**Computation site:** `internal/markdown/markdown.go` — two methods handle this: `ExtractAll` (line 356, single-pass extraction used in practice) and `ExtractProperties` (line 192, standalone). Both parse the memo's Markdown content via goldmark and walk the AST. The results are assembled in `server/runner/memopayload/runner.go:RebuildMemoPayload` (line 74), which calls `ExtractAll` and writes the extracted `Property` (and `Tags`) back into `memo.Payload`.

**Triggers (operations that cause recomputation):**
1. **Memo creation** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting the new memo.
2. **Memo update (content change)** — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `content` field is in the update mask.
3. **Batch rebuild on startup** — `server/runner/memopayload/runner.go:RunOnce` (line 27) iterates all memos in batches and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each, rebuilding every memo's payload.

**Extracted properties** (stored in `MemoPayload_Property`, defined in `proto/gen/store/memo.pb.go` and converted via `convertMemoPropertyFromStore` at `server/router/api/v1/memo_service_converter.go:315`):
- **`HasLink`** — whether the content contains any Markdown link (`[text](url)`).
- **`HasCode`** — whether the content contains code blocks or inline code spans.
- **`HasTaskList`** — whether the content contains task checkboxes (`- [ ]` / `- [x]`).
- **`HasIncompleteTasks`** — whether any of those checkboxes are unchecked.
- **`Title`** — the text of the first block-level H1 heading, if the memo starts with one.

Additionally, `ExtractAll` also extracts **`Tags`** (hashtag nodes) and **`Snippet`** (computed separately by `GenerateSnippet` at `internal/markdown/markdown.go:264`, called from `convertMemoFromStoreWithCreators` at `server/router/api/v1/memo_service_converter.go:76`) — a plain-text summary of up to 64 characters used for previews in relations/webhooks/notifications.
