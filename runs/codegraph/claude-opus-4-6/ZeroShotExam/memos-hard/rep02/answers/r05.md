The API schema is defined via **Protocol Buffer `.proto` files** in `proto/api/v1/`. Key service definitions include:

- `proto/api/v1/memo_service.proto` — the core Memo CRUD service
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/auth_service.proto` — authentication
- `proto/api/v1/attachment_service.proto` — file attachments
- `proto/api/v1/instance_service.proto` — instance/server settings
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/idp_service.proto` — identity provider configuration
- `proto/api/v1/shortcut_service.proto` — shortcuts
- `proto/api/v1/common.proto` — shared message types

These `.proto` files are compiled into Go server stubs (in `proto/gen/api/v1/`) and TypeScript client types (in `web/src/types/proto/`), with HTTP/REST bindings provided via gRPC-Gateway annotations (`google.api.http` options in the proto files). There is no GraphQL layer.
