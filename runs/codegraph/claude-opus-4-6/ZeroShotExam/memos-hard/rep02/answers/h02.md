**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). This is where the outbound HTTP POST to the webhook endpoint actually executes. Asynchronous dispatch goes through `PostAsync` (line 184), which enqueues payloads onto a buffered channel consumed by goroutines that call `Post`.

**Protection mechanism** — SSRF protection is implemented in two layers, both in `internal/webhook/validate.go`:

1. **At registration time**: `ValidateURL` (line 62) resolves the webhook URL's hostname and checks every resolved IP against `isReservedIP` (line 44), which tests against a list of reserved CIDRs (`reservedCIDRs`, line 14) covering loopback, RFC-1918 private ranges, link-local/cloud IMDS (`169.254.0.0/16`), and IPv6 equivalents. This prevents users from registering webhooks pointing at internal addresses.

2. **At delivery time**: `safeDialContext` in `internal/webhook/webhook.go` (line 59) is wired into the `safeClient`'s HTTP transport (line 32). It re-resolves the hostname at dial time and rejects connections to any reserved/private IP via the same `isReservedIP` check — this defeats DNS rebinding attacks where a hostname resolves to a public IP at registration but a private IP at delivery time.
