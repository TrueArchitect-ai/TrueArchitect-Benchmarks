The premise is incorrect: this repository does not use Redis at all. There is no Redis connection, client, or dependency anywhere in the codebase.

Caching is implemented entirely with **in-process Go data structures** (maps guarded by mutexes), in two places:

1. **RSS feed cache** (`server/router/rss/rss.go`): A `map[string]*cacheEntry` protected by `sync.RWMutex` (lines 48–49), with a `defaultCacheDuration` of **1 hour** (line 25) and a `maxCacheSize` of 50 entries (line 26). User RSS feeds are keyed as `"user:<username>"` (line 114). Expired entries are evicted on read when `time.Since(entry.createdAt) > defaultCacheDuration` (line 357).

2. **Instance stats cache** (`server/router/api/v1/instance_stats.go`): A single-value `instanceStatsCache` struct with a mutex (line 24), using a TTL of **60 seconds** (`instanceStatsCacheTTL`, line 21).

There is no per-user TTL distinct from the general RSS cache TTL — user feed entries use the same 1-hour `defaultCacheDuration` as all other RSS cache entries.
