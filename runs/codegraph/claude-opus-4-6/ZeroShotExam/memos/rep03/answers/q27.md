Go's `embed.FS` (`//go:embed dist/*`) embeds the compiled React build output into the server binary at compile time. At startup, `FrontendService.Serve` extracts the embedded filesystem and registers it as Echo middleware via `middleware.StaticWithConfig`, with an SPA fallback that serves `index.html` for unmatched routes.
