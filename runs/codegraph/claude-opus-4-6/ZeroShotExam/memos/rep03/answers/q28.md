**Runner — Trigger:**

- **s3presign.Runner** — `time.Ticker` at a 12-hour interval (`runnerInterval = time.Hour * 12`). Started in `server/server.go:153` (`startBackgroundRunners`): runs `RunOnce` immediately at boot, then continuously via `Run()` which ticks every 12 hours. Re-presigns S3 attachment URLs.

That is the **only** background runner the server actually starts. The `memopayload.Runner` exists in `server/runner/memopayload/runner.go` but is **never instantiated or started** by the server — it is not imported in `server/server.go` and has no `Run` (loop) method, only a one-shot `RunOnce`.

**Unused scheduling infrastructure:** The `internal/scheduler` package (`internal/scheduler/scheduler.go`, `internal/scheduler/parser.go`) implements a full cron-expression-based job scheduler (`Scheduler`, `Register`, `Start`, `ParseCronExpression`, `Schedule.Next`). It is **not used by the server** — it is only referenced in its own test files (`example_test.go`, `integration_test.go`). No production code imports it.
