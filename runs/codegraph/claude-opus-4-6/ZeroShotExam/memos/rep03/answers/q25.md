The filter expression is parsed by a custom recursive-descent parser (the `Engine` struct) living in **`internal/filter/engine.go`**. The engine tokenizes and parses the filter string into an internal expression tree (`parseContext` in `internal/filter/parser.go`), then renders it to SQL via dialect-aware helpers in **`internal/filter/render.go`** that switch on `DialectName` (defined in `internal/filter/schema.go`) to emit the correct SQL syntax (e.g., SQLite vs. PostgreSQL) for each predicate.

**Engine + path:** custom recursive-descent engine at `internal/filter/engine.go`; the parsed expression is converted to a SQL `WHERE` clause by `internal/filter/render.go`, which branches on the `DialectName` constant to produce dialect-specific SQL fragments.
