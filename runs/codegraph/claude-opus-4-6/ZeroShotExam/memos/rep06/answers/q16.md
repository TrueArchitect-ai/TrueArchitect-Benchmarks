When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes these kinds of records before the memo row itself:

1. **Memo relations** (where the memo is the **source**) — `DeleteMemoRelation` with `MemoID` set to the memo's ID (line 142)
2. **Memo relations** (where the memo is the **target**) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (line 145)
3. **Attachments** — lists all attachments linked to the memo, then deletes each one individually via `DeleteAttachment` (lines 149–157)
