Four memo lifecycle events dispatch webhooks:

- **memos.memo.created**: `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15`)
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:20`)
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service_webhooks.go:25`)
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:30`)

The first three converge through the shared private method `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), which resolves the memo creator, fetches their webhooks, builds the payload via `convertMemoToWebhookPayload`, and enqueues via `webhook.PostAsync`. `DispatchMemoCommentCreatedWebhook` skips `dispatchMemoRelatedWebhook` (it looks up the *related memo owner's* webhooks directly) but still calls `convertMemoToWebhookPayload` and `webhook.PostAsync`.

All four ultimately converge at `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto `asyncPostQueue`. Worker goroutines (spawned in `init()`, line 42) dequeue and call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single HTTP delivery function that marshals the payload, signs it (if a secret is configured), and POSTs it to the endpoint.
