When a memo is created, the handler `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook` defined in `server/router/api/v1/memo_service_webhooks.go`. This method delegates to `dispatchMemoRelatedWebhook` (same file), which looks up the creator's webhooks and calls `webhook.PostAsync` for each one.

The HTTP delivery is performed by the `internal/webhook` package (`internal/webhook/webhook.go`). `PostAsync` enqueues the payload onto a buffered channel; background goroutines dequeue it and call `Post`, which uses `net/http` to send the request.

The request-signing mechanism is **HMAC-SHA256** following the **Standard Webhooks** convention. When a signing secret is configured, `Post` computes `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)`, base64-encodes it, and sets three headers: `webhook-id`, `webhook-timestamp`, and `webhook-signature` (prefixed `v1,`). Secrets in `whsec_<base64>` form are base64-decoded to derive the raw key; plain strings are used as-is.

**dispatcher** — `DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`; **delivery package** — `internal/webhook`; **signing mechanism** — HMAC-SHA256 with Standard Webhooks headers (`webhook-id`, `webhook-timestamp`, `webhook-signature v1,<base64>`).
