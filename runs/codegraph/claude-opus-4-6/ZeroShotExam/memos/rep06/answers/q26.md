When `DeleteMemo` runs, the following database tables are affected (traced through both the API service layer in `server/router/api/v1/memo_service.go` and the store layer in `store/memo.go`):

Each of those recursive calls repeats the same cascade above (deleting that comment's `memo_relation` rows, `attachment` rows, and the `memo` row).
