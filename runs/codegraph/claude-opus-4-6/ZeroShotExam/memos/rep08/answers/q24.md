Complete call chain for creating a memo, one hop per line:

1. `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` mutation hook calls `memoServiceClient.createMemo()`
2. `web/src/connect.ts` — `memoServiceClient` created via `createClient(MemoService, transport)` (Connect-RPC client over HTTP)
3. `proto/gen/api/v1/apiv1connect/memo_service.connect.go` — `memoServiceClient.CreateMemo()` receives the Connect-RPC request server-side and dispatches to the handler
4. `server/router/api/v1/memo_service.go` — `APIV1Service.CreateMemo()` (the RPC handler) validates, builds `store.Memo`, calls `s.Store.CreateMemo()`
5. `store/memo.go` — `Store.CreateMemo()` validates the UID, then delegates to `s.driver.CreateMemo()`
6. `store/driver.go` — `Driver` interface declares `CreateMemo()` (line 29); dispatches to the active dialect implementation
7. `store/db/sqlite/memo.go` (or `store/db/postgres/memo.go` or `store/db/mysql/memo.go`) — `DB.CreateMemo()` builds and executes the SQL `INSERT INTO memo (...)` statement
