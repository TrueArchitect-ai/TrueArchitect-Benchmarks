**Mechanism:** Server-Sent Events (SSE). The server streams events over a long-lived HTTP connection at `/api/v1/sse` using the standard `text/event-stream` content type with `data:` frames and `:` comment heartbeats (`server/router/api/v1/sse_handler.go`).

**Hub path:** `server/router/api/v1/sse_hub.go` — the `SSEHub` struct manages client connections (Subscribe/Unsubscribe) and fans out events via its `Broadcast` method.

**Memo handlers that broadcast through it:**

1. `CreateMemo` — broadcasts `memo.created` (`server/router/api/v1/memo_service.go`)
2. `DeleteMemo` — broadcasts `memo.deleted` (`server/router/api/v1/memo_service.go`)
3. `CreateMemoComment` — broadcasts `memo.comment.created` (`server/router/api/v1/memo_service_comments.go`)
4. `dispatchMemoUpdatedSideEffects` — broadcasts `memo.updated` (`server/router/api/v1/memo_update_helpers.go`)
5. `UpsertMemoReaction` — broadcasts `reaction.upserted` (`server/router/api/v1/reaction_service.go`)
6. `DeleteMemoReaction` — broadcasts `reaction.deleted` (`server/router/api/v1/reaction_service.go`)
