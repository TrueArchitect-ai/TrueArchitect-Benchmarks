When a memo is deleted through the API, the store layer (`Store.DeleteMemo` in `store/memo.go:140-158`) deletes the following kinds of records before the memo row itself:

- **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID` set to the memo's ID (`store/memo.go:142`)
- **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (`store/memo.go:145`)
- **Attachments** — lists all attachments linked to the memo via `ListAttachments`, then deletes each one individually via `DeleteAttachment` (`store/memo.go:149-157`)

After these three kinds of records are cleaned up, the store calls `driver.DeleteMemo` to delete the memo row itself (`store/memo.go:158`).
