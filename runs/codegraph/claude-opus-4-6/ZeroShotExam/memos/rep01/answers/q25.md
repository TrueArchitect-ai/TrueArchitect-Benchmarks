The filter expression is parsed by a custom recursive-descent parser (the `Engine` struct) living in `internal/filter/engine.go`. The engine tokenizes the filter string into an AST of `parseContext` nodes (`internal/filter/parser.go`), then `internal/filter/render.go` walks that AST and emits dialect-specific SQL via helpers in `internal/filter/helpers.go` that switch on `DialectName` (`internal/filter/schema.go`) to produce the correct SQL fragments (e.g., quoting, function names) for each supported database dialect.
