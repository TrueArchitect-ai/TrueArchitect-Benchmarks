**Background runners the server actually starts:**

- **s3presign runner** — `time.Ticker` every 12 hours (`runnerInterval = time.Hour * 12`), plus one immediate `RunOnce` call at startup. It refreshes presigned URLs for S3 attachments. Started in `server/server.go:153-174` via `startBackgroundRunners`, which calls `s3presign.NewRunner` and launches `s3presignRunner.Run` in a goroutine.

That is the **only** background runner started by the server.

**Unused scheduling infrastructure:**

- **`server/runner/memopayload`** (`server/runner/memopayload/runner.go`) — This package defines a `Runner` struct with a `RunOnce` method that rebuilds payloads for all memos, but the server's `startBackgroundRunners` method (`server/server.go:153`) never instantiates or invokes it. The `memopayload` package is **not imported** by `server/server.go` (only `s3presign` is imported at line 26). The `memopayload.Runner` has no `Run` loop either — only `RunOnce` — so it lacks continuous scheduling even as a design. It is present in the codebase but completely unused by the running server.
