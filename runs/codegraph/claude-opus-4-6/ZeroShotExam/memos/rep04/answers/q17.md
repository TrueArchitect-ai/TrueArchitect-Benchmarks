The frontend module containing memo CRUD mutations/queries is `web/src/hooks/useMemoQueries.ts`. It exports hooks like `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`, etc., all of which call `memoServiceClient` — an instance created in `web/src/connect.ts` via `createClient(MemoService, transport)`, where `MemoService` is imported from `web/src/types/proto/api/v1/memo_service_pb`.
