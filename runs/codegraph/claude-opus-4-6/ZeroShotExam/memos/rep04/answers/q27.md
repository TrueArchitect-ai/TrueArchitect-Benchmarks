The compiled React frontend is served in production via Go's `embed` package (`//go:embed dist/*` directive), which embeds the built `dist/` directory into the Go binary at compile time. The embedded filesystem is then served as static files using Echo's `middleware.StaticWithConfig` with an SPA fallback middleware. This is wired in `server/router/frontend/frontend.go`.
