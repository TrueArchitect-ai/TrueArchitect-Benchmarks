The filter expression is parsed by a custom recursive-descent parser (the `Engine` struct) located at `internal/filter/engine.go`. The engine tokenizes and parses the filter string into an internal expression tree (`parseContext` in `internal/filter/parser.go`), then renders it to SQL via dialect-aware helpers in `internal/filter/render.go` that switch on `DialectName` (SQLite vs. MySQL/PostgreSQL) defined in `internal/filter/schema.go`, translating each parsed filter node into the appropriate SQL `WHERE` clause fragments for the target database dialect.
