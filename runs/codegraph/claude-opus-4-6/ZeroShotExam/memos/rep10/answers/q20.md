**Mechanism:** Server-Sent Events (SSE). The server streams events over a persistent HTTP connection at `/api/v1/sse` using the `text/event-stream` content type, with heartbeat comments every 30 seconds to keep the connection alive.

**Hub path:** `server/router/api/v1/sse_hub.go` — the `SSEHub` struct manages client connections and the `Broadcast` method fans events to all subscribed SSE clients (with visibility-based filtering via `canReceive`). The SSE HTTP handler is in `server/router/api/v1/sse_handler.go`.
