Go's `embed.FS` (`//go:embed dist/*`) is used to embed the compiled React build output into the Go binary at compile time. The embedded filesystem is then served via Echo's `StaticWithConfig` middleware with an SPA fallback. This is wired in `server/router/frontend/frontend.go` (line 20–21 for the embed directive, line 41–61 for the `Serve` method that registers the middleware).
