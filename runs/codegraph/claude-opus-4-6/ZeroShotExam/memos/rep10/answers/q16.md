When a memo is deleted through the store layer (`store/memo.go:140–158`), the following kinds of records are deleted before the memo row itself:

1. **Memo relations (source)** — `DeleteMemoRelation` where the memo is the **source** (`MemoID` = memo's ID) (`store/memo.go:142`)
2. **Memo relations (target)** — `DeleteMemoRelation` where the memo is the **related/target** (`RelatedMemoID` = memo's ID) (`store/memo.go:145`)
3. **Attachments** — all attachments linked to the memo are listed and individually deleted via `DeleteAttachment` (`store/memo.go:149–156`)

Additionally, at the API service layer (`server/router/api/v1/memo_service.go:568–577`), **comment memos** (child memos related via `MemoRelationComment`) are recursively deleted before the parent memo itself — each comment deletion in turn triggers the same store-layer cleanup of its own relations and attachments.
