The compiled React frontend is served in production via Go's `embed` package (`//go:embed dist/*` directive), which embeds the built frontend assets into the Go binary at compile time. The `FrontendService.Serve` method then exposes them through Echo's `StaticWithConfig` middleware using the embedded filesystem, with an SPA fallback middleware for client-side routing.
