When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls **`DispatchMemoCreatedWebhook`** in `server/router/api/v1/memo_service_webhooks.go`. This method delegates to `dispatchMemoRelatedWebhook` (same file), which looks up the creator's webhooks, builds a `WebhookRequestPayload`, and enqueues it via `webhook.PostAsync`.

- **Dispatcher** — `DispatchMemoCreatedWebhook` (which calls `dispatchMemoRelatedWebhook`) in `server/router/api/v1/memo_service_webhooks.go`
- **Delivery package** — `internal/webhook` (the `Post` function in `internal/webhook/webhook.go` performs the HTTP POST using a `net/http` client)
- **Signing mechanism** — HMAC-SHA256 following the Standard Webhooks scheme: the payload is signed with `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, and the signature is sent as a `webhook-signature: v1,<base64>` header alongside `webhook-id` and `webhook-timestamp` headers. Secrets use the `whsec_<base64>` format (`internal/webhook/webhook.go:97-106`, `139-149`).
