**Background runners the server actually starts:**

- **s3presign runner** (`server/runner/s3presign/runner.go`) — driven by a `time.Ticker` with a 12-hour interval (`runnerInterval = time.Hour * 12`). It also runs once synchronously at startup via `RunOnce()` before the ticker loop begins. Started in `server/server.go:153` (`startBackgroundRunners`).

**Scheduling infrastructure present but NOT used by the server:**

- **`internal/scheduler/`** — A full cron-based scheduler package (`Scheduler`, `Job`, `Schedule`, `ParseCronExpression`, middleware support). It supports 5- and 6-field cron expressions, timezone configuration, middleware chaining, and graceful shutdown. However, it is never imported or instantiated anywhere outside its own package and tests. The server does not use it; no `scheduler.New()`, `Register()`, or `Start()` call exists outside `internal/scheduler/` itself.

- **`server/runner/memopayload/`** — Contains a `Runner` struct with `NewRunner`, `Run`, and `RunOnce` methods (same pattern as s3presign), but it is **not started** as a background runner. Its `RebuildMemoPayload` function is called inline from `memo_service.go` during memo create/update RPCs, but the runner's ticker-based `Run` loop is never launched by the server.
