The filter expression is parsed by a custom recursive-descent parser in `internal/filter/engine.go` (the `Engine` struct at line 14, with parsing logic in `internal/filter/parser.go`). The engine parses the filter string into an internal expression tree, then `internal/filter/render.go` walks that tree and renders it into a SQL `WHERE` clause, switching on `DialectName` (defined in `internal/filter/schema.go`) to emit dialect-specific SQL (e.g., SQLite vs. PostgreSQL) for operators like time comparisons and string matching.
