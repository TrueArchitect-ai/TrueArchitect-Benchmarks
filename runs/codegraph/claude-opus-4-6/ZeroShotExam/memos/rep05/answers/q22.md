The HTTP delivery is performed by the **`internal/webhook`** package (`internal/webhook/webhook.go`). `PostAsync` enqueues the payload onto a buffered channel; background goroutines drain it by calling `Post`, which uses `net/http` (via a safe SSRF-guarded client) to send the POST request.

The request-signing mechanism is **HMAC-SHA256** following the Standard Webhooks convention. When a `SigningSecret` is present, `Post` generates a `webhook-id` (UUID), a `webhook-timestamp` (Unix seconds), computes `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)`, and sets the `webhook-signature` header to `"v1," + base64(mac)`. Secrets prefixed with `whsec_` are base64-decoded to derive the raw key.
