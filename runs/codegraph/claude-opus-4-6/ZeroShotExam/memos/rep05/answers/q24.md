Complete call chain for creating a memo:

1. `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` mutation hook calls `memoServiceClient.createMemo()`
2. `web/src/connect.ts` — `memoServiceClient` created via `createClient(MemoService, transport)` (Connect-ES client)
3. `proto/gen/api/v1/apiv1connect/memo_service.connect.go` — `MemoServiceHandler.CreateMemo` interface / Connect RPC handler definition
4. `server/router/api/v1/memo_service.go` — `APIV1Service.CreateMemo()` handler implementation; calls `s.Store.CreateMemo(ctx, create)`
5. `store/memo.go` — `Store.CreateMemo()` validates UID, delegates to `s.driver.CreateMemo(ctx, create)`
6. `store/db/sqlite/memo.go` — `DB.CreateMemo()` builds and executes `INSERT INTO memo (...) VALUES (...) RETURNING id, created_ts, updated_ts, row_status` (SQLite dialect; MySQL equivalent at `store/db/mysql/memo.go`, Postgres at `store/db/postgres/memo.go`)
