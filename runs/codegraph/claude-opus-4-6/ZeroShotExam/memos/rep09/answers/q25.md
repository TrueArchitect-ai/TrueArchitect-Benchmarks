The filter expression is parsed by a custom recursive-descent parser (the `Engine` struct) living in `internal/filter/engine.go`. The engine tokenizes and parses the filter string into an internal expression tree (`parseContext` in `internal/filter/parser.go`), then renders that tree into SQL via dialect-aware helpers in `internal/filter/render.go`, which switch on `DialectName` (defined in `internal/filter/schema.go`) to emit the correct SQL syntax (e.g., SQLite vs. PostgreSQL) for each predicate.
