Go's `//go:embed` directive embeds the compiled React build (`dist/*`) into the Go binary at compile time. At startup, the `FrontendService.Serve` method registers Echo's `StaticWithConfig` middleware to serve these embedded files as static assets, with an SPA fallback middleware that serves `index.html` for unmatched routes.
