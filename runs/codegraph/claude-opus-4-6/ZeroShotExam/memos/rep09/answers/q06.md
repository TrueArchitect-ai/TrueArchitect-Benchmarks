The database table that stores links between one memo and another related memo is `memo_relation`. This is defined in migration files such as `store/migration/sqlite/0.13/00__memo_relation.sql` and referenced across the store layer in files like `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
