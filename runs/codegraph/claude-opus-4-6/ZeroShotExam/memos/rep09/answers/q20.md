**Mechanism:** Server-Sent Events (SSE). The server streams events over a long-lived HTTP connection at `/api/v1/sse` using the standard `text/event-stream` content type with `data:` frames and heartbeat comments.

**Hub path:** `server/router/api/v1/sse_hub.go` — the `SSEHub` struct manages client subscriptions and broadcasts via its `Broadcast` method. The SSE HTTP handler is in `server/router/api/v1/sse_handler.go`.

**Memo handlers that broadcast through it:**

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go:163`) — broadcasts `memo.created`
2. **`DeleteMemo`** (`server/router/api/v1/memo_service.go:585`) — broadcasts `memo.deleted`
3. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:126`) — broadcasts `memo.comment.created`
4. **`dispatchMemoUpdatedSideEffects`** (`server/router/api/v1/memo_update_helpers.go:71`) — broadcasts `memo.updated` (called from `UpdateMemo`)
5. **`UpsertMemoReaction`** (`server/router/api/v1/reaction_service.go:106`) — broadcasts `reaction.upserted`
6. **`DeleteMemoReaction`** (`server/router/api/v1/reaction_service.go:161`) — broadcasts `reaction.deleted`
