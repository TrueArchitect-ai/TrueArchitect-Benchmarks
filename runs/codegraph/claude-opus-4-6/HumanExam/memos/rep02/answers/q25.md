CEL (Common Expression Language) via `github.com/google/cel-go`; engine at `internal/filter/engine.go`. The engine compiles CEL filter strings into a dialect-agnostic condition tree (`internal/filter/parser.go`), then `AppendConditions` (`internal/filter/helpers.go`) renders the tree to SQL via a dialect-specific renderer (`internal/filter/render.go`), accepting `DialectSQLite`, `DialectPostgres`, or `DialectMySQL` (`internal/filter/schema.go:14-16`) — each DB driver passes its own dialect constant.
