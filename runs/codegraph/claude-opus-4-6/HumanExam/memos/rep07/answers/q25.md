Engine: CEL (Common Expression Language) via `github.com/google/cel-go/cel`, at `internal/filter/engine.go`
Mechanism: The handler passes filter strings to `memoFind.Filters`. Each dialect driver calls `filter.AppendConditions()` with its dialect constant (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`). The engine compiles the CEL expression into an IR condition tree, then renders it into dialect-specific SQL using per-field column expressions from the schema (`internal/filter/schema.go`).
