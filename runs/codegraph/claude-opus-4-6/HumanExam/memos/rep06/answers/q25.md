engine: CEL (Common Expression Language) via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`
mechanism: The `Engine.Compile` method parses the CEL filter string into a dialect-agnostic IR condition tree (internal/filter/ir.go, internal/filter/parser.go), then `renderer.Render` in internal/filter/render.go converts it into dialect-specific SQL WHERE clauses with parameterized placeholders for SQLite, PostgreSQL, or MySQL; per-dialect drivers call `filter.AppendConditions()` (internal/filter/helpers.go) passing the dialect name.
