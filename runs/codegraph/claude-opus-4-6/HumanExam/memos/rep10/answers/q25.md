- Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`
- Mechanism: Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) which compiles the CEL expression to an AST, lowers it to an IR condition tree via `buildCondition`, then renders dialect-specific SQL (sqlite/mysql/postgres) via `renderer.Render()` (`internal/filter/render.go`) using the target `DialectName`.
