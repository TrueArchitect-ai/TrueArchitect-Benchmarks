The store layer (`store/memo.go:140-158`) deletes before the memo row:
- Memo relations (where memo is source, via `DeleteMemoRelation` with `MemoID`)
- Memo relations (where memo is target, via `DeleteMemoRelation` with `RelatedMemoID`)
- Attachments linked to the memo (via `DeleteAttachment`)

Additionally, at the API handler level (`memo_service.go:567-577`), comment memos are deleted first. And `memo_share` rows are cascade-deleted via the SQL `ON DELETE CASCADE` foreign key.
