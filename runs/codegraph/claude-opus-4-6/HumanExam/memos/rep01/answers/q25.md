CEL (Common Expression Language) engine in `internal/filter/engine.go`; the engine uses `cel-go` to compile filter strings into a dialect-agnostic condition IR (`internal/filter/parser.go`), then a renderer (`internal/filter/render.go`) converts the IR into SQL WHERE clauses using dialect-specific placeholders and functions (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`), called via `filter.AppendConditions()` in each driver's `ListMemos`.
