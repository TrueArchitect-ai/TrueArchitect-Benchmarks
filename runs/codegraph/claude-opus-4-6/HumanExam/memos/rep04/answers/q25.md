CEL (Common Expression Language) via `github.com/google/cel-go`, in `internal/filter/engine.go`. The engine compiles the CEL filter string into a dialect-agnostic IR tree of `Condition` nodes (`internal/filter/parser.go`), then renders it to SQL via `internal/filter/render.go` using per-dialect column expressions and placeholder syntax from the schema (`internal/filter/schema.go`). Each DB driver calls `filter.AppendConditions()` with its own dialect constant (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`), producing the appropriate SQL WHERE fragment.
