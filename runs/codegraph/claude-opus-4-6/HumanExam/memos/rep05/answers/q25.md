- Engine: CEL (Common Expression Language) via `google/cel-go`, wrapped in `Engine` at `internal/filter/engine.go`
- The Engine compiles a CEL filter string into a parsed AST, converts it into a dialect-agnostic `Condition` tree (`internal/filter/parser.go`), then renders it into SQL via a dialect-aware renderer (`internal/filter/render.go`) that switches on dialect name (SQLite/MySQL/Postgres defined in `internal/filter/schema.go`). Each DB driver calls the filter to get WHERE clauses and args.
