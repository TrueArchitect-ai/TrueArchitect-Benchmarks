q26. memo_relation, attachment, memo

Specifically, `Store.DeleteMemo` (`store/memo.go:140-158`) explicitly deletes from:
1. **memo_relation** — removes rows where the memo is source or target
2. **attachment** — removes all attachments linked to the memo
3. **memo** — deletes the memo row itself

Additionally, the API handler (`server/router/api/v1/memo_service.go:567-577`) first recursively deletes comment memos (which themselves trigger the same cascade on memo_relation, attachment, and memo for each comment).
