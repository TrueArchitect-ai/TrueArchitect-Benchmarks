CEL (Common Expression Language) engine — `internal/filter/engine.go` (parser) + `internal/filter/parser.go` + `internal/filter/render.go`; the engine parses the filter string into a CEL AST, converts it to a dialect-agnostic condition tree, then the renderer in `internal/filter/render.go` walks that tree and emits a SQL `Statement` (clause + args) using dialect-specific column mappings and functions defined in the `Schema` (`internal/filter/schema.go`), which carries per-dialect settings (SQLite, PostgreSQL, MySQL).
