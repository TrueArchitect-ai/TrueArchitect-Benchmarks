q25. The filter engine uses **CEL (Common Expression Language)** via `google/cel-go`, implemented in `internal/filter/engine.go`. The engine parses the CEL filter expression into a dialect-agnostic condition tree, then the renderer (`internal/filter/render.go`) translates that tree into a SQL `Statement` using dialect-specific schema definitions (`internal/filter/schema.go`) that account for each dialect's SQL syntax (SQLite, PostgreSQL, MySQL).
