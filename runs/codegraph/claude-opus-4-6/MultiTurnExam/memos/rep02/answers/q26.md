q26. The following tables are affected when DeleteMemo runs:

1. **memo_relation** — explicitly deleted in `store/memo.go` (both as source and target)
2. **attachment** — explicitly deleted in `store/memo.go`
3. **memo** — the memo row itself, plus comment memos (which are also memos) are recursively deleted first in the API handler (`server/router/api/v1/memo_service.go`)
4. **memo_share** — via SQL `ON DELETE CASCADE` foreign key on `memo_id` (`store/migration/sqlite/LATEST.sql`)
