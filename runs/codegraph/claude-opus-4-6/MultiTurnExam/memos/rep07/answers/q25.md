Engine: CEL (Common Expression Language) via `cel-go`, implemented in `internal/filter/engine.go` (the `Engine` struct parses filter strings using `cel.NewEnv`).

The engine compiles the CEL expression into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), which is then rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`, using the dialect name (sqlite/mysql/postgres) from the schema (`internal/filter/schema.go`) to emit the correct placeholder syntax and SQL functions for each backend.
