Engine: CEL (Common Expression Language) via `cel-go`, implemented in `internal/filter/engine.go` (parser in `internal/filter/parser.go`).

The `Engine` compiles the CEL filter expression into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`), which is then rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`, using schema mappings from `internal/filter/schema.go` that map CEL field names to SQL columns and handle placeholder syntax differences per dialect (SQLite, MySQL, PostgreSQL).
