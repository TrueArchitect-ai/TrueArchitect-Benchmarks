The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain Go buffered channel, entirely in-process.

The queue is declared in `internal/webhook/webhook.go` at the `PostAsync` function (line 184), which sends webhook payloads into a buffered channel. Four goroutine workers read from that channel and call `Post` (line 120) to execute the outbound HTTP request. The channel and workers are initialized on first use within the same process — no external broker infrastructure is involved.
