**Delivery function:** `Post` (`internal/webhook/webhook.go:120`) — serializes the payload to JSON, signs it with HMAC-SHA256 if a signing secret is configured, and sends an HTTP POST to the webhook URL. Asynchronous dispatch goes through `PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto a buffered channel consumed by 4 background goroutines that each call `Post`.

**Protection mechanism:** `safeDialContext` (`internal/webhook/webhook.go:59`) — a custom `DialContext` function wired into the `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:35`). It resolves the target hostname via DNS, then checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), which rejects any address in a reserved/private IP range (loopback, RFC 1918, link-local, etc.). This blocks SSRF and defeats DNS rebinding because the check happens after resolution but before the connection is established.
