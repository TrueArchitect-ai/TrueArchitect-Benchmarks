The premise is incorrect — there is no per-user API rate-limiting middleware in this codebase. No rate limiter is registered in the server's middleware chain.

The Echo router is configured in `server/router/router.go`, and the Connect/gRPC API services are registered in `server/router/api/v1/v1.go`. Neither registers any rate-limiting middleware. A grep for "rate" or "limiter" or "throttle" across the server code yields no relevant hits. The middleware that does exist handles concerns like CORS, authentication (ACL interceptor in `server/router/api/v1/acl_interceptor.go`), and static file serving — but not request rate limiting.
