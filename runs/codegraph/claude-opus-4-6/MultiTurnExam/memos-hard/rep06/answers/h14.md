**Extracted properties** (stored in `MemoPayload`, defined at `proto/gen/store/memo.pb.go:24`):

- **`Tags`** (`[]string`) — all `#tag` references found in the content (deduplicated, case-preserving)
- **`Property.Title`** (`string`) — text of the first H1 heading, if the first block-level element is one
- **`Property.HasLink`** (`bool`) — whether the content contains any markdown links
- **`Property.HasCode`** (`bool`) — whether the content contains code blocks or code spans
- **`Property.HasTaskList`** (`bool`) — whether the content contains GFM task checkboxes
- **`Property.HasIncompleteTasks`** (`bool`) — whether any task checkboxes are unchecked
