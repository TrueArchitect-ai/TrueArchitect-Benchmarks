The premise is incorrect — there is no nightly database-cleanup job. The cron scheduler infrastructure exists in `internal/scheduler/scheduler.go` (a generic `Scheduler` that can run `Job` instances on cron `Schedule` expressions parsed in `internal/scheduler/parser.go`), but no database-cleanup job is registered anywhere in the production code.

The only background runner wired into server startup is the S3 presign refresher (`server/runner/s3presign/runner.go`), which uses its own ticker loop (every 12 hours) rather than the cron scheduler. The `memopayload.Runner` in `server/runner/memopayload/runner.go` also exists but has no production callers. Neither is a database-cleanup job, and neither uses the cron scheduler. The scheduler package is exercised only in its own tests (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`, etc.).
