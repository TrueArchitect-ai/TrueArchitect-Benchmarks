The premise is incorrect — there is no GraphQL schema. The public API is defined using Protocol Buffers and served over Connect (compatible with gRPC and gRPC-Web).

The API surface is defined in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The services are registered as Connect handlers in `server/router/api/v1/v1.go`, mounted on the Echo HTTP router in `server/router/router.go`. Additionally, a secondary surface exists as an MCP (Model Context Protocol) adapter in `server/router/mcp/`, which exposes a JSON-Schema-based tool interface — but that's JSON Schema for MCP tool definitions, not GraphQL.
