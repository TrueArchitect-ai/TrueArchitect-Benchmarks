**Delivery function** — `Post` (`internal/webhook/webhook.go:120`) executes the outbound HTTP POST. Asynchronous dispatch goes through `PostAsync` (same file, line 184), which enqueues payloads to a buffered channel consumed by 4 goroutine workers (lines 43–55) that each call `Post`.

**Protection mechanism** — `safeDialContext` (`internal/webhook/webhook.go:59`) and `isReservedIP` / `ValidateURL` (`internal/webhook/validate.go:44` / `validate.go:62`). The `safeClient` HTTP transport uses `safeDialContext` as its dialer, which resolves the target hostname via DNS and rejects any IP in a reserved/private CIDR range (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents — listed in `validate.go:14–23`). This blocks SSRF at both registration time (`ValidateURL`) and at dial time (defeating DNS rebinding).
