There is no GraphQL schema. The public API is defined using Protocol Buffers (protobuf) and served over gRPC / Connect / gRPC-Gateway (REST). The `.proto` service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server also exposes an OpenAPI spec (embedded via `proto/gen/apidocs.swagger.yaml` or similar) which is consumed by the MCP service layer (`server/router/mcp/`) to provide tool-based access. Additionally, an RSS feed is served from `server/router/rss/rss.go`. No GraphQL layer exists anywhere in the codebase.
