The premise is incorrect — there is no Redis. The cache layer is purely in-memory, implemented in `store/cache/cache.go`. All caches (including the user cache) are instantiated in `store/store.go:40–52` with `cache.New(cacheConfig)`, where `cacheConfig` sets a `DefaultTTL` of **10 minutes** (line 41). There is no external cache service — entries live in a Go map with a background goroutine for expiry cleanup.
