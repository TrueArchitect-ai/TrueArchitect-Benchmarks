Neither NATS nor RabbitMQ. There is no external message broker. The webhook delivery workers consume from a plain Go buffered channel (`asyncPostQueue`, declared at `internal/webhook/webhook.go:39` as `make(chan *WebhookRequestPayload, 128)`). Four goroutines are spawned in an `init()` function (lines 43–55) that range over this channel and call `Post` for each payload. Producers enqueue via `PostAsync` (line 184), which does a non-blocking send and drops the payload if the channel is full.
