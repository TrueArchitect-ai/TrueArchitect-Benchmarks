**Premise correction:** There is no GraphQL schema. The public API does not use GraphQL.

**Actual API surface:** The API is defined using Protocol Buffers (protobuf) and served over gRPC/Connect. The proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server exposes these services via Connect (connectrpc) handlers registered in `server/router/api/v1/connect_services.go`, and additionally provides a gRPC-Gateway REST proxy. An OpenAPI spec is also embedded (`proto/gen/apidocs.swagger.yaml` / `proto/raw/api.yaml`) and used to power the MCP endpoint (`server/router/mcp/`).
