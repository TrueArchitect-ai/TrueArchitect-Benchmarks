**Protection mechanism** — `safeDialContext` — `internal/webhook/webhook.go:59`, backed by `isReservedIP` and `ValidateURL` in `internal/webhook/validate.go`. The `safeClient` HTTP transport replaces the default dialer with `safeDialContext`, which resolves the target hostname and rejects any IP falling within reserved/private CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) defined in `internal/webhook/validate.go:14–23`. This runs at dial time, defeating DNS rebinding. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same check at webhook registration time (scheme must be http/https, hostname must not resolve to a reserved IP).
