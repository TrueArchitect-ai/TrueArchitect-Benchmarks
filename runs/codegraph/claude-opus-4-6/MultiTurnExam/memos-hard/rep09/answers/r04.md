**Premise correction:** Neither NATS nor RabbitMQ. There is no external message broker involved in webhook delivery.

**Actual mechanism:** The webhook delivery workers consume from a plain in-process Go buffered channel. The queue is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) to drain this channel, each calling `Post()` synchronously. Callers enqueue payloads via `PostAsync()` (line 184), which does a non-blocking send and drops the event if the 128-slot buffer is full.
