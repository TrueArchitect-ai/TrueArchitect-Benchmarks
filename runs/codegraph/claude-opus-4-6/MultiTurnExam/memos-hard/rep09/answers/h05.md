Explicit Go code. Reactions are removed in two ways within the `deleteUserTargetsTx` function during the user-deletion transaction:

1. **`deleteReactionsByContentIDsTx`** — deletes all reactions on the user's memos (by content ID), e.g. `store/db/mysql/user_delete.go:96`, `store/db/mysql/user_delete.go:417` (`DELETE FROM reaction WHERE content_id IN ...`).
2. **`deleteReactionsByCreatorTx`** — deletes all reactions *created by* the user (on anyone's memos), e.g. `store/db/mysql/user_delete.go:102`, `store/db/mysql/user_delete.go:437` (`DELETE FROM reaction WHERE creator_id = ...`).

Both are called from `deleteUserTargetsTx` (lines 96 and 102 in each driver) inside the same transaction that deletes the user. This pattern is identical across all three database drivers:

- `store/db/mysql/user_delete.go:96,102` (calls) / `:417,437` (implementations)
- `store/db/postgres/user_delete.go:96,102` / `:380,400`
- `store/db/sqlite/user_delete.go:96,102` / `:380,400`
