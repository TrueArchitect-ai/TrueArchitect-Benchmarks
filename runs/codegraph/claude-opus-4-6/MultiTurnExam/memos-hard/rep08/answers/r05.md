**Premise correction:** There is no GraphQL schema. The public API is not GraphQL-based.

**Actual API surface:** The API is defined using **Protocol Buffers (protobuf)** with gRPC, served over three transports:

1. **gRPC** — proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`), with generated Go code in `proto/gen/api/v1/`
2. **Connect (gRPC-Web compatible)** — generated Connect handlers in `proto/gen/api/v1/apiv1connect/`, registered in `server/router/api/v1/v1.go`
3. **REST/JSON via gRPC-Gateway** — HTTP transcoding registered via `RegisterGateway` in `server/router/api/v1/v1.go:65`, with generated gateway code in `proto/gen/api/v1/*_service.pb.gw.go`

Additionally, an **MCP (Model Context Protocol)** endpoint at `/mcp` is derived from an embedded OpenAPI spec (`server/router/mcp/service.go`).
