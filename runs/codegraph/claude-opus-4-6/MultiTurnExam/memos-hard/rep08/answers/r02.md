**Premise correction:** There is no per-user API rate-limiting middleware in this codebase. The server does not implement request rate limiting of any kind. The only concurrency controls present are a semaphore limiting concurrent thumbnail generation (`server/router/fileserver/fileserver.go`) and a semaphore limiting concurrent image processing for EXIF stripping (`server/router/api/v1/attachment_service.go`), but these are resource-protection mechanisms, not per-user API rate limits.
