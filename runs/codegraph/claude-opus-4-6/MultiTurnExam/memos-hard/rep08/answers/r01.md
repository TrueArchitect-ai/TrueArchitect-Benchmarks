**Premise correction:** There is no Redis connection. The cache layer is entirely in-process, not backed by Redis or any external store.

**Actual mechanism:** The cache is implemented as a generic in-memory store in `store/cache/cache.go`. It is configured in `store.New` (`store/store.go:38-51`), where a `cache.Config` is created with a **`DefaultTTL` of 10 minutes**, a `CleanupInterval` of 5 minutes, and a `MaxItems` of 1000. Three separate `cache.Cache` instances are created with this same config — one for instance settings, one for users (`userCache`), and one for user settings. So user entries have a **10-minute TTL**, enforced by the in-memory cache's cleanup goroutine.
