**Mechanism:** Explicit Go code — reactions are removed by two dedicated functions called within the `deleteUserTargetsTx` transaction.

**Evidence locations:**

1. `deleteReactionsByContentIDsTx` — deletes reactions whose `content_id` matches the user's deleted memos (e.g., `store/db/sqlite/user_delete.go:380`, `store/db/mysql/user_delete.go:417`, `store/db/postgres/user_delete.go:380`). Each executes `DELETE FROM reaction WHERE content_id IN (...)`.

2. `deleteReactionsByCreatorTx` — deletes reactions created by the deleted user regardless of which memo they're on (e.g., `store/db/sqlite/user_delete.go:400`, `store/db/mysql/user_delete.go:437`, `store/db/postgres/user_delete.go:401`). Each executes `DELETE FROM reaction WHERE creator_id = ?`.

Both are called from `deleteUserTargetsTx` (e.g., `store/db/mysql/user_delete.go:96` and `:102`) inside the same transaction that deletes the user, across all three driver implementations (SQLite, MySQL, PostgreSQL).
