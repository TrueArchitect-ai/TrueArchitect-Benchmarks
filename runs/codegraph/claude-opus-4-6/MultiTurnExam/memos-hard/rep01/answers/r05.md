**Premise correction:** There is no GraphQL schema or GraphQL endpoint anywhere in this codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC, served via **gRPC-Gateway** (REST/JSON) and **Connect protocol**. The proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`), and generated Go code is in `proto/gen/api/v1/`. The gateway is wired up in `server/router/api/v1/v1.go` where `APIV1Service` registers both gRPC-Gateway HTTP handlers and Connect handlers. Additionally, the server exposes an **MCP (Model Context Protocol)** adapter at `server/router/mcp/` that translates a subset of the API into MCP tool calls, with its own OpenAPI-derived JSON schema definitions in `server/router/mcp/openapi.go`.
