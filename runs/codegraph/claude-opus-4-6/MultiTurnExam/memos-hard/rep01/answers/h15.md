Memo visibility is enforced at these distinct sites:

1. **GetMemo RPC** (single-memo fetch gate) — `server/router/api/v1/memo_service.go:55-65`. Non-public memos require authentication; private memos are restricted to the creator.

2. **ListMemos RPC** (list query filter) — `server/router/api/v1/memo_service.go:218-227`. Unauthenticated callers see only `Public`; authenticated callers viewing another user's memos see `Public`+`Protected`; own memos are unfiltered.

3. **CreateMemoComment RPC** (comment on a memo) — `server/router/api/v1/memo_service_comments.go:41`. Private memo rejects comments from non-creator, non-superusers.

4. **ListReactions / UpsertReaction RPCs** (reaction access) — `server/router/api/v1/reaction_service.go:30-38` (list) and `:83` (upsert). Both check visibility before allowing reaction read/write.

5. **ListMemoAttachments RPC** (memo-scoped attachment listing) — `server/router/api/v1/memo_attachment_service.go:214-224`. Non-public memos require auth; private restricted to creator/superuser.

6. **GetAttachment RPC** (individual attachment download) — `server/router/api/v1/attachment_service.go:445-451`. Public memos pass; private restricted to creator/superuser.

7. **File server** (HTTP attachment/resource serving) — `server/router/fileserver/fileserver.go:677-701`. Public memos served to anonymous visitors only when `AllowAnonymous()`; private restricted to creator/admin. Also supports share-token fallback.

8. **SSE hub** (real-time event delivery) — `server/router/api/v1/sse_hub.go:134-143`. `canReceive` restricts private-visibility events to the creator or admins.

9. **User stats RPCs** — `server/router/api/v1/user_service_stats.go:84-91` (ListAllUserStats) and `:218-220` (GetUserStats). Both filter memos by visibility the same way as ListMemos.

10. **Notification eligibility** — `server/router/api/v1/user_service_notifications.go:309-314`. Suppresses notifications for private/protected memos when the viewer lacks access.

11. **Mention notification filter** — `server/router/api/v1/memo_mention_helpers.go:62-68`. `canUserAccessMentionContext` blocks mention inbox items when the memo or its parent is private and the target is not the creator.

12. **RSS feed** — `server/router/rss/rss.go:90`. Hardcodes `VisibilityList: {Public}`, exposing only public memos.

13. **Sitemap generation** — `server/router/frontend/frontend.go:150`. Hardcodes `VisibilityList: {Public}`, listing only public memos.
