**Protection mechanism** — `safeDialContext` — `internal/webhook/webhook.go:59`, backed by `isReservedIP` — `internal/webhook/validate.go:44`. The `safeClient` HTTP client (line 32) uses a custom `Transport` whose `DialContext` is `safeDialContext`. This function resolves the target hostname via DNS, then checks every resolved IP against a list of reserved/private CIDR ranges (`reservedNetworks`, parsed from `reservedCIDRs` at `internal/webhook/validate.go:14–23` — covering loopback, RFC-1918, link-local/cloud IMDS, and IPv6 equivalents). If any resolved IP is reserved, the dial is rejected, which also defeats DNS rebinding. The same check is applied at webhook creation time via `ValidateURL` (`internal/webhook/validate.go:62`).
