Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct used as the common return type across providers.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — ships a concrete OAuth2 protocol implementation via the `IdentityProvider` struct, which exchanges authorization codes for tokens and fetches user info from the configured OAuth2 endpoints.
