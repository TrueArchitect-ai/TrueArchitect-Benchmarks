The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed struct in `store/cache/cache.go:67`. There is no external cache service (Redis, Memcached, or otherwise) anywhere in the codebase.

User entries are cached with the default `Cache` configuration. The `Store` creates its `userCache` using `cache.NewDefault()` (which calls `DefaultConfig()` at `store/cache/cache.go:57`), giving user entries a **TTL of 10 minutes** (`DefaultTTL: 10 * time.Minute`, line 59), with cleanup running every 5 minutes and a max of 1000 items.
