Delivery function — `Post` in `internal/webhook/webhook.go:120` (called asynchronously via `PostAsync` at line 184, which enqueues to a buffered channel consumed by 4 goroutine workers started in `init()`). The actual HTTP request is executed by `safeClient.Do(req)` at line 152.

Protection mechanism — `safeDialContext` (`internal/webhook/webhook.go:59`) combined with `isReservedIP` (`internal/webhook/validate.go:44`). The `safeClient` HTTP transport uses `safeDialContext` as its dialer, which resolves the target hostname via DNS and rejects any IP in a reserved/private CIDR range (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) defined in `reservedCIDRs` (`internal/webhook/validate.go:14`). This check runs at dial time, which also defeats DNS rebinding. A second layer validates the URL at webhook creation/update time via `ValidateURL` (`internal/webhook/validate.go:62`), performing the same reserved-IP check at registration time.
