By explicit Go code. Reactions are removed in two ways within the `deleteUserTargetsTx` function (called in all three drivers):

1. **`deleteReactionsByContentIDsTx`** — deletes all reactions on the user's memos (by `content_id`), e.g. `store/db/mysql/user_delete.go:96`, `store/db/mysql/user_delete.go:420` (`DELETE FROM reaction WHERE content_id IN ...`).
2. **`deleteReactionsByCreatorTx`** — deletes all reactions the user themselves created on any memo (by `creator_id`), e.g. `store/db/mysql/user_delete.go:102`, `store/db/mysql/user_delete.go:438` (`DELETE FROM reaction WHERE creator_id = ?`).

All three database drivers follow the same pattern — explicit SQL `DELETE FROM reaction` statements executed within the user-deletion transaction, not database-level foreign key cascades.
