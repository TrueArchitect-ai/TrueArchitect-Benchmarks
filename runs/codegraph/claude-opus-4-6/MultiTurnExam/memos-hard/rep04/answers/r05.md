The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** and served over three protocols:

1. **gRPC** — generated server stubs in `proto/gen/api/v1/*_grpc.pb.go`
2. **gRPC-Gateway (REST/JSON)** — generated HTTP reverse-proxy handlers in `proto/gen/api/v1/*_pb.gw.go`, registered at `server/router/api/v1/v1.go:65` via `RegisterGateway`
3. **Connect (gRPC-Web)** — generated handlers in `proto/gen/api/v1/apiv1connect/*.connect.go`

The protobuf source definitions live under `proto/api/v1/*.proto`. An embedded OpenAPI spec (`proto/gen/apidocs.swagger.yaml` / loaded via `proto.OpenAPIYAML()`) is also used to power the MCP endpoint at `server/router/mcp/service.go:78`.
