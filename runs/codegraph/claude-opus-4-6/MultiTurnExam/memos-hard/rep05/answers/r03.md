**Premise correction:** There is no nightly database-cleanup job.

The codebase includes a cron scheduler framework (`internal/scheduler/`) but it is a general-purpose library — no database-cleanup job is registered anywhere. The only recurring background tasks in the server are the S3 presign runner (`server/runner/s3presign/runner.go`, every 12 hours via its own `time.Ticker`, not the cron scheduler) and the memo payload runner (`server/runner/memopayload/runner.go`, which has a `RunOnce` method but is not wired into production startup). No job performs database cleanup, vacuuming, or row pruning on any schedule.
