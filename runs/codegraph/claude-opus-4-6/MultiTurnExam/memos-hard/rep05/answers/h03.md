**Abstraction package** — `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct that all providers return.

**Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — ships a concrete OAuth2 implementation (`IdentityProvider`) that handles token exchange and user-info retrieval against any generic OAuth2 provider.
