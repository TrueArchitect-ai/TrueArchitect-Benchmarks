**Delivery function** — `Post` (`internal/webhook/webhook.go:120`) executes the outbound HTTP POST. Asynchronous dispatch goes through `PostAsync` (same file, line 184), which enqueues onto a buffered channel consumed by 4 goroutine workers (line 43–55) that each call `Post`.

**Protection mechanism** — SSRF protection via `safeDialContext` (`internal/webhook/webhook.go:59`) and `isReservedIP` / `ValidateURL` (`internal/webhook/validate.go`). The `safeClient` HTTP transport uses a custom `DialContext` that resolves the target hostname and rejects any IP in reserved/private CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) — blocking both direct private-IP targets and DNS rebinding attacks. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same reserved-IP check at webhook creation time.
