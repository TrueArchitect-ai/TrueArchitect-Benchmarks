**Premise correction:** There is no GraphQL schema. The project does not use GraphQL.

**Actual API surface:** The public API is defined via Protocol Buffers (protobuf) with gRPC and gRPC-Gateway. The `.proto` definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server exposes three protocol surfaces from these definitions:

- **gRPC** — registered via `_grpc.pb.go` service descriptors
- **REST/JSON** — via gRPC-Gateway (`_service.pb.gw.go` handlers), registered at `server/router/api/v1/v1.go:65`
- **Connect** (connectrpc) — via `apiv1connect/` generated handlers, registered alongside gRPC in `server/router/api/v1/connect_services.go`

Additionally, an **MCP (Model Context Protocol)** endpoint is served at `/mcp`, driven by the embedded OpenAPI spec (`server/router/mcp/service.go`).
