**Mechanism: explicit Go code.** Reactions are removed by two explicit SQL `DELETE` statements executed within the user-deletion transaction, not by database-level cascades.

**Evidence locations:**

1. **`deleteReactionsByContentIDsTx`** — deletes all reactions on the user's memo content (`DELETE FROM reaction WHERE content_id IN ...`):
   - `store/db/sqlite/user_delete.go:380`
   - `store/db/mysql/user_delete.go:417`
   - `store/db/postgres/user_delete.go:380`

2. **`deleteReactionsByCreatorTx`** — deletes all reactions *created by* the user on any content (`DELETE FROM reaction WHERE creator_id = ...`):
   - `store/db/sqlite/user_delete.go:400`
   - `store/db/mysql/user_delete.go:437`
   - `store/db/postgres/user_delete.go:400`

Both are called from `deleteUserTargetsTx` (lines 96 and 102 in each driver's `user_delete.go`), which runs inside the `DeleteUser` transaction. This covers both directions: reactions others left on the deleted user's memos, and reactions the deleted user left on anyone's memos.
