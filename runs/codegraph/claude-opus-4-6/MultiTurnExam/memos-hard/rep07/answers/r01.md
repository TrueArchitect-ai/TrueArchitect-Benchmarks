**Premise correction:** There is no Redis connection in this codebase. The cache layer does not use Redis or any external cache store.

**Actual mechanism:** The cache is a purely in-memory implementation built on `sync.Map`, defined in `store/cache/cache.go`. It is constructed in `store.New()` at `store/store.go:38` with a default configuration of:

- **DefaultTTL: 10 minutes** (`store/store.go:41`)
- **CleanupInterval: 5 minutes** (`store/store.go:42`)
- **MaxItems: 1000** (`store/store.go:43`)

The same configuration and TTL applies to all three cache instances, including the user cache (`s.userCache` at `store/store.go:52`).
