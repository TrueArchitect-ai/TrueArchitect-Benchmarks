**Premise correction:** There is no nightly database-cleanup job in this codebase. The cron scheduler (`internal/scheduler/`) is a general-purpose library but no database-cleanup job is registered anywhere in the server.

The only scheduled background tasks are:
- The **S3 presign runner** (`server/runner/s3presign/runner.go`), which uses a `time.Ticker` every 12 hours (not the cron scheduler) to refresh presigned URLs.
- The **memopayload runner** (`server/runner/memopayload/runner.go`), which has a `RunOnce` method for batch payload recomputation but is not wired into server startup at all.

The scheduler package itself is fully implemented and tested, but no production code calls `scheduler.Register()` with any job — including any database-cleanup job. There is no automated database cleanup, vacuuming, or pruning at the application level.
