**Premise correction:** Neither NATS nor RabbitMQ is used. There is no external message broker in this codebase.

**Actual mechanism:** Webhook delivery uses a plain Go buffered channel as an in-process async queue, declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four worker goroutines are spawned in `init()` (`internal/webhook/webhook.go:42-55`) that consume from this channel and call `Post()` to deliver each webhook. Callers enqueue work via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send — if the 128-slot buffer is full, the webhook is dropped with a warning log rather than blocking the caller. There are no external dependencies, no broker connections, and no durable queue — pending webhooks are lost if the process exits.
