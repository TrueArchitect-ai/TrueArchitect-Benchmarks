**Premise correction:** There is no GraphQL schema or GraphQL API in this codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with three transport layers:

1. **gRPC** — service definitions in `proto/api/v1/*.proto`, with generated Go server/client code in `proto/gen/api/v1/*_grpc.pb.go`
2. **gRPC-Gateway (REST/JSON)** — HTTP transcoding via generated gateway handlers in `proto/gen/api/v1/*_pb.gw.go`, registered at `server/router/api/v1/v1.go:65` (`RegisterGateway`), exposing REST endpoints under `/api/v1/`
3. **Connect (gRPC-Web)** — generated Connect handlers in `proto/gen/api/v1/apiv1connect/*_service.connect.go`, registered at `server/router/api/v1/connect_services.go`

Additionally, an **MCP (Model Context Protocol)** endpoint at `/mcp` (`server/router/mcp/service.go:109`) exposes a curated subset of the API as tool calls, driven by an embedded **OpenAPI spec** (`proto/gen/apidocs.swagger.yaml` via `proto/embed.go`).
