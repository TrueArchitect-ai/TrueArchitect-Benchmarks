**Protection mechanism** — `safeDialContext` (`internal/webhook/webhook.go:59`) combined with `isReservedIP` / `reservedNetworks` (`internal/webhook/validate.go:44` and `:14`). The `safeClient` HTTP client uses a custom `Transport` whose `DialContext` is set to `safeDialContext` (line 35). At dial time, `safeDialContext` resolves the target hostname via `net.DefaultResolver.LookupHost` and rejects the connection if any resolved IP falls within a reserved/private CIDR (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents). This defeats both direct private-IP targets and DNS rebinding. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same reserved-IP check at webhook creation/update time, providing defense-in-depth.
