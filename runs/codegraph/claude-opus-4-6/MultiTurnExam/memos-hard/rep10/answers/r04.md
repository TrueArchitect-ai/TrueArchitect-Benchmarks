The premise is incorrect — there is no external message broker (neither NATS nor RabbitMQ). Webhook delivery uses a plain **Go buffered channel** as its in-process queue.

The queue is declared at `internal/webhook/webhook.go:39`:
```
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four worker goroutines are spawned in `init()` at line 42-55 of the same file. They consume from this channel and call `Post()` to deliver each webhook over HTTP. `PostAsync()` (line 184) enqueues payloads into the channel with a non-blocking send, dropping the message if the channel is full (capacity 128). There is no persistence, no external broker, and no retry mechanism — if the server restarts, any queued but undelivered webhooks are lost.
