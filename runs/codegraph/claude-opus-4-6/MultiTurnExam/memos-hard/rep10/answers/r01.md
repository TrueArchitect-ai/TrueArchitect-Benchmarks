The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a Go `sync.Map` with TTL-based expiration in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, etc.) anywhere in the codebase.

User entries use the **default cache configuration**: a TTL of **10 minutes**, as set by `DefaultConfig()` at `store/cache/cache.go:58`. The user cache is created in `store/store.go` using this default config (via `cache.NewDefault()` or equivalent), and `Store.GetUser` (`store/user.go:148`) checks and populates it with the default TTL on every read.
