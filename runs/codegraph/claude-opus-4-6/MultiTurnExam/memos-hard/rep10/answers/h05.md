Explicit Go code. Reactions are removed by two dedicated functions called within the `deleteUserTargetsTx` transaction:

1. **`deleteReactionsByContentIDsTx`** — deletes reactions whose `content_id` matches the user's memos (e.g., `store/db/mysql/user_delete.go:417`, `store/db/postgres/user_delete.go:380`, `store/db/sqlite/user_delete.go:380`)
2. **`deleteReactionsByCreatorTx`** — deletes reactions where `creator_id` matches the deleted user (e.g., `store/db/mysql/user_delete.go:437`, `store/db/postgres/user_delete.go:400`, `store/db/sqlite/user_delete.go:400`)

Both are called from `deleteUserTargetsTx` inside the same transaction as the rest of the user deletion (e.g., `store/db/mysql/user_delete.go:96,102`). This pattern is consistent across all three database drivers (MySQL, PostgreSQL, SQLite).
