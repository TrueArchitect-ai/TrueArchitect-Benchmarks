The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase.

The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed through three transport layers:

1. **gRPC** — service definitions in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`), with generated Go server/client code in `proto/gen/api/v1/*_grpc.pb.go`
2. **gRPC-Gateway (REST/JSON)** — HTTP transcoding generated into `proto/gen/api/v1/*_service.pb.gw.go`, registered in `server/router/api/v1/v1.go:65`
3. **Connect (connect-go)** — an alternative RPC protocol with handlers generated in `proto/gen/api/v1/apiv1connect/*_service.connect.go`, registered via `server/router/api/v1/connect_handler.go`

Additionally, an **MCP (Model Context Protocol)** endpoint is served at `/mcp`, backed by an embedded **OpenAPI spec** (`server/router/mcp/service.go:78`) that exposes a curated subset of the API as tool calls.
