r02.

There is no per-user API rate-limiting middleware in this codebase. No rate limiter, token bucket, or request-throttling middleware is registered anywhere in the server. The server uses authentication and authorization checks (via `server/router/api/v1/acl_config.go` and interceptors in `server/router/api/v1/connect_interceptors.go`), but these enforce identity and permissions, not request rates.
