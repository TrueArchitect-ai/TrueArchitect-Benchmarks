There is no Redis connection. The premise is incorrect — the cache layer is entirely in-memory, not backed by Redis.

The cache is implemented as a generic in-memory `Cache` struct in `store/cache/cache.go`. User entries are cached in `Store.userCache`, initialized in `store/store.go`. The cache uses a simple map with no TTL-based expiration — entries are stored indefinitely and only evicted by explicit invalidation (e.g., on user update/delete) or when the process restarts.
