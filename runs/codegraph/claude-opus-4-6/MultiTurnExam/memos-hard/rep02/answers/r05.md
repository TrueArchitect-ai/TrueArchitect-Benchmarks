There is no GraphQL schema. The public API is defined using Protocol Buffers (protobuf) with gRPC and Connect, plus a gRPC-Gateway for REST/JSON. The proto definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`), with generated Go code in `proto/gen/api/v1/`. The server exposes both gRPC (via `proto/gen/api/v1/*_grpc.pb.go`) and Connect-RPC (via `proto/gen/api/v1/apiv1connect/*.connect.go`) handlers, along with an HTTP/JSON gateway (`proto/gen/api/v1/*_service.pb.gw.go`). There is also an MCP endpoint at `/mcp` backed by an embedded OpenAPI spec (`server/router/mcp/`).
