**Premise correction: there is no GraphQL anywhere in this repository — no schema files, no resolvers, no dependency. Searching for `graphql` across Go, TypeScript, and JSON sources returns zero hits, and `find` for `*.graphql`/`*.gql` finds nothing.**

**Actual API surface: Protocol Buffers, compiled by `buf` into gRPC + Connect + a gRPC-Gateway REST/JSON layer, with OpenAPI as the generated spec.**

**Schema definition** — nine `.proto` files under `proto/api/v1/`: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and `common.proto`. Store-internal messages live in `proto/store/`. This is the single source of truth — the equivalent of what you were looking for in a GraphQL SDL file.

**Code generation** — `proto/buf.gen.yaml` runs six plugins over those files:
- `protocolbuffers/go` → message types in `proto/gen/`
- `grpc/go` → gRPC service stubs
- `connectrpc/go` → Connect handlers (`proto/gen/api/v1/apiv1connect/`)
- `grpc-ecosystem/gateway` → REST/JSON transcoding (`*.pb.gw.go`)
- `community/google-gnostic-openapi` → `proto/gen/openapi.yaml`
- `bufbuild/es` → TypeScript clients for the web app, emitted to `web/src/types/proto`

**Runtime registration** — `apiV1Service.RegisterGateway(ctx, echoServer)` (`server/server.go:87`, implementation at `server/router/api/v1/v1.go:65`) mounts both the gRPC-Gateway and the Connect handlers behind a shared authorizer. Alongside it the server registers plain HTTP surfaces: `/healthz` (`server/server.go:67`), the file server at `/file/...` (`server/server.go:81-82`), RSS (`server/server.go:85`), the frontend (`server/server.go:72`), and an MCP service (`server/server.go:91-96`).

**The OpenAPI spec is embedded and served** — `proto/gen/openapi.yaml` is compiled into the binary via `//go:embed` in `proto/openapi_embed.go:5` and exposed through `proto.OpenAPIYAML()`. That's the document to consult for the public HTTP API; `server/router/mcp/openapi.go` builds JSON Schemas from the same surface for MCP tool definitions.
