Distinct enforcement sites, grouped by surface:

**gRPC/Connect API (`server/router/api/v1`)**
- `checkMemoReadAccess` — the single-memo read gate used by `GetMemo`, parent-memo checks, and `ListMemoComments` — `server/router/api/v1/memo_service.go:39-76` (callers at `memo_service.go:356,367` and `memo_service_comments.go:148`)
- `ListMemos` query-scoping — injects `VisibilityList`/a `creator_id == N || visibility in [...]` filter so non-visible memos never leave the DB — `server/router/api/v1/memo_service.go:217-227`
- `CreateMemoComment` — blocks commenting on someone else's private memo — `server/router/api/v1/memo_service_comments.go:41` (and the comment's own visibility check at `:100`)
- `ReactionService` — `UpsertMemoReaction`/`ListMemoReactions` visibility gate — `server/router/api/v1/reaction_service.go:30-40` and `:83`
- `AttachmentService.GetAttachmentBinary` permission check — `server/router/api/v1/attachment_service.go:445-453`
- `SetMemoAttachments`/attachment access helper — `server/router/api/v1/memo_attachment_service.go:214-224`
- `GetUserStats` / memo-stat aggregation — restricts counted memos by visibility — `server/router/api/v1/user_service_stats.go:84-90` and `:218-220`
- SSE fan-out filter `(*SSEClient).canReceive` — private events go only to the creator or an admin — `server/router/api/v1/sse_hub.go:134-143` (event visibility populated at `sse_event_helpers.go:29-37`)
- Mention/notification targeting — suppresses notifications to users who couldn't see the memo — `server/router/api/v1/memo_mention_helpers.go:62,67,84` and `server/router/api/v1/user_service_notifications.go:309-312`

**Raw file server (`server/router/fileserver`)**
- `checkAttachmentPermission` — public + anonymous-allowed short-circuit, share-token fallback, then private/creator/admin check — `server/router/fileserver/fileserver.go:677`, `:684-689`, `:699`

**Public/unauthenticated surfaces**
- RSS feeds — instance and per-user feeds query `VisibilityList: {Public}` only — `server/router/rss/rss.go:90` and `:141`
- Sitemap (`/sitemap.xml`) — public memos only — `server/router/frontend/frontend.go:150`

**Email notifications (`server/notification`)**
- Comment/mention email gating on memo visibility — `server/notification/email.go:313-316`

Two notes from tracing this: the memo-share token path is an intentional bypass of the visibility check, honored only in the file server (`server/router/fileserver/fileserver.go:684-689`); and enforcement is split between *filtering at query time* (ListMemos, stats, RSS, sitemap) and *checking after fetch* (checkMemoReadAccess, reactions, attachments, file server) — there is no single central authorizer for memo visibility.
