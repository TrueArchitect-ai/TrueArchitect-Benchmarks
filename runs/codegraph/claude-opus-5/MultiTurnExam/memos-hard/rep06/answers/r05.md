**Premise correction: there is no GraphQL anywhere in this repository** — no schema file, no resolver, no `gqlgen`/`graphql-go` dependency, no `/graphql` route. A case-insensitive grep for `graphql`, `gqlgen`, and `.graphql` across the Go sources, `go.mod`, and the web `.ts`/`.tsx`/`.json` files returns zero hits.

**Actual API surface — Protobuf/gRPC, exposed three ways:**

- **Schema of record**: `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, plus `common.proto`. Store-side messages live in `proto/store/` (e.g. `proto/store/memo.proto`). Codegen is driven by `proto/buf.gen.yaml` into `proto/gen/` (Go, gRPC, Connect, grpc-gateway) and into `web/src/types/proto` for the frontend.

- **Three runtime surfaces**, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:88-146`):
  1. **REST/JSON via grpc-gateway** — handlers registered at `server/router/api/v1/v1.go:99-122`, mounted on `/api/v1/*` and `/file/*` at `:128-129`. HTTP↔RPC mapping comes from the `google.api.http` annotations in the `.proto` files.
  2. **Connect RPC** (replaces grpc-web for browser clients) — `server/router/api/v1/v1.go:139-144`, mounted at `/memos.api.v1.*`, with the metadata/logging/recovery/auth interceptor chain at `:133-138`.
  3. **Server-Sent Events** for live updates — `RegisterSSERoutes` at `server/router/api/v1/v1.go:124`.

- **The published spec is OpenAPI, not GraphQL**: `proto/gen/openapi.yaml`, generated by the gnostic-openapi plugin (`proto/buf.gen.yaml`) and embedded into the binary via `proto/openapi_embed.go`. It's consumed by the MCP service, which derives its tool catalog and JSON Schemas from it (`server/router/mcp/openapi.go`, `server/router/mcp/catalog.go`) — that MCP endpoint (`server/router/mcp/service.go`, mounted at `server/server.go:96`) is the fourth, AI-facing view of the same RPC surface.

Additional non-RPC HTTP endpoints exist outside the proto contract: raw file serving at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), RSS feeds (`server/router/rss/rss.go`), and `/healthz` (`server/server.go:67`).
