**Extracted properties** — `RebuildMemoPayload` calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns exactly two fields onto `memo.Payload` (`runner.go:85-86`):

1. `Payload.Tags` — `#tag` nodes collected during the goldmark AST walk, deduplicated case-preservingly (`internal/markdown/markdown.go:377-379`, `:417`).
2. `Payload.Property` (`proto/store/memo.proto:15-22`):
   - `has_link` — a `KindLink` node exists
   - `has_code` — any code block, fenced code block, or code span
   - `has_task_list` — any task checkbox
   - `has_incomplete_tasks` — a task checkbox that is unchecked
   - `title` — text of the first H1 heading, only if it is the document's first block-level child (`markdown.go:386-392`)

Two things it does *not* touch: `Payload.Location` is user-set and assigned separately right after the rebuild (`memo_service.go:111-113`), and `ExtractedData.Mentions` — although `ExtractAll` collects @mentions (`markdown.go:380-382`), `RebuildMemoPayload` discards them; mentions are handled separately via `s.MarkdownService.ExtractAll` in `server/router/api/v1/memo_mention_helpers.go:32`.
