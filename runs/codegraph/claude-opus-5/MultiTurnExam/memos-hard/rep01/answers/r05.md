**Premise correction: there is no GraphQL anywhere in this repository. A case-insensitive grep for `graphql|gqlgen|.graphql|apollo` across all Go, TypeScript/TSX, JSON, and `go.mod` files returns zero hits — no schema files, no server library, no client. The public API is Protocol Buffers / gRPC, exposed over Connect and a gRPC-Gateway REST mapping.**

**Actual API surface**

**1. Schema definition — protobuf, not GraphQL:** `proto/api/v1/` holds the service and message definitions:
- `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`
- Persistence-side messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, seen earlier for `MemoPayload`).
- Generated Go lands in `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go` for the gateway, and `apiv1connect/*.connect.go` for Connect).

**2. Transports — three, all wired in `server/router/api/v1/v1.go` and `server/server.go`:**
- **Connect RPC** (browser clients): handlers registered on `connectMux` and mounted at the `/memos.api.v1.*` path prefix — `server/router/api/v1/v1.go:139-145`. The interceptor chain (metadata → logging → recovery → auth) is at `v1.go:133-137`, with a body cap via `connect.WithReadMaxBytes(maxAPIRequestBytes)`.
- **gRPC-Gateway REST**: `RegisterGateway` mounts the transcoded HTTP API at `/api/v1/*` (and `/file/*`) — `server/router/api/v1/v1.go:128-129`, invoked from `server/server.go:88`.
- **Native HTTP file server**, registered *before* the gateway so Safari range requests work: `GET /file/attachments/:uid/:filename` and `GET /file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:121-124`, wired at `server/server.go:81-82`.

**3. Non-RPC HTTP surfaces:**
- `/healthz` — `server/server.go:67`
- RSS feeds — `server/router/rss/rss.go` (`GetExploreRSS`, `GetUserRSS`), registered at `server/server.go:85`
- Frontend static assets, SPA fallback, and sitemap — `server/router/frontend/frontend.go`
- MCP (Model Context Protocol) endpoints — `server/router/mcp/`, registered at `server/server.go:92-96`; the tool schemas there are JSON Schema (`server/router/mcp/openapi.go`), which is the closest thing to a "schema for the public API" outside protobuf.
