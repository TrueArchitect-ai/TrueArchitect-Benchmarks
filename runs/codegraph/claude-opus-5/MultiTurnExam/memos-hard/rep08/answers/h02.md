h02.

**`webhook.Post` — `internal/webhook/webhook.go:120` (dispatched asynchronously via `PostAsync`, `internal/webhook/webhook.go:184`); dial-time reserved-IP blocking in `safeDialContext`/`isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`**

Details:

**Where delivery executes**
- `Post` (`internal/webhook/webhook.go:120`) marshals the `WebhookRequestPayload`, builds the `POST`, optionally adds Standard Webhooks HMAC headers (`webhook-id` / `webhook-timestamp` / `webhook-signature`, lines 133-150), and performs the actual network call at `internal/webhook/webhook.go:152` via `safeClient.Do(req)`. The response body is read under a 1 MiB `io.LimitReader` (line 158).
- Callers don't normally block on it: `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto a bounded 128-slot channel (`asyncPostQueue`, line 39), drained by 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), which is where `Post` actually runs. Trigger sites are in `server/router/api/v1/memo_service_webhooks.go`.

**What protects it**

Two layers, both keyed off `isReservedIP` (`internal/webhook/validate.go:44`):

1. **Dial-time enforcement (the real protection).** `safeClient` is an `http.Client` whose `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59-77`) resolves the target host itself and refuses to dial if *any* resolved address falls in a reserved range. Because the check happens at connection time rather than at config time, it also defeats DNS rebinding (comment at `webhook.go:30-31`).
2. **Admission-time validation.** `ValidateURL` (`internal/webhook/validate.go:62`) requires an absolute `http`/`https` URL and rejects hostnames resolving to reserved IPs; it's called when webhooks are created/updated in `server/router/api/v1/user_service_webhooks.go`.

The blocked ranges are the parsed `reservedCIDRs` list (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 blocks, `169.254.0.0/16` (link-local / cloud IMDS), and the IPv6 loopback/ULA/link-local equivalents. A package-level escape hatch, `AllowPrivateIPs` (`internal/webhook/validate.go:41`), disables both layers when true — intended for self-hosted deployments targeting LAN services.
