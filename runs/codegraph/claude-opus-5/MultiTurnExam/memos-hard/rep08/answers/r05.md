**Premise correction: there is no GraphQL anywhere in this repository. A case-insensitive search for "graphql" across every file (excluding `node_modules` and `.git`) returns zero matches — no schema files, no resolver code, no client or server library in `go.mod` or `package.json`.**

The actual API surface is **Protobuf/gRPC, exposed over HTTP three ways**:

**1. Schema definitions — `proto/api/v1/`.** The public API is defined in nine `.proto` files: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto` (plus `proto/api/v1/README.md`). Internal storage messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, which defines `MemoPayload`). Generated Go code lands in `proto/gen/api/v1/` and `proto/gen/store/`; generated TypeScript for the web client in `web/src/types/proto/`.

**2. Service implementations — `server/router/api/v1/`.** `APIV1Service` (`server/router/api/v1/v1.go:24-45`) embeds the generated `Unimplemented*ServiceServer` structs and implements the handlers (`memo_service.go`, `user_service.go`, `attachment_service.go`, …).

**3. Transports.** `RegisterGateway` (`server/router/api/v1/v1.go:65`) mounts both a **gRPC-Gateway** REST/JSON mux (built at `v1.go:95`, giving conventional `/api/v1/...` HTTP routes from the `google.api.http` annotations in the protos) and **Connect** handlers with the interceptor chain at `v1.go:133-141`. It's wired into the server at `server/server.go:88`.

Three additional non-gRPC HTTP surfaces sit alongside it:
- **Native file serving** — `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), registered *before* the gateway so Safari range requests work.
- **RSS** — `server/router/rss/rss.go`, registered at `server/server.go:85`.
- **MCP** (Model Context Protocol) — `server/router/mcp/`, registered at `server/server.go:92-96`. This is likely the source of the GraphQL-shaped intuition: it publishes **JSON Schema** tool definitions derived from the API (`server/router/mcp/openapi.go`, `server/router/mcp/catalog.go`) — a schema-driven surface, but JSON Schema over MCP, not GraphQL.

There's also a `/healthz` endpoint at `server/server.go:67`.
