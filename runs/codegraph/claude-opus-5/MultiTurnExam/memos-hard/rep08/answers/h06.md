**Convergence.** All four `Dispatch*Webhook` entry points live in `server/router/api/v1/memo_service_webhooks.go`. Three of them (`Created`/`Updated`/`Deleted`, lines 15/20/25) delegate to the shared `dispatchMemoRelatedWebhook` (line 48); `DispatchMemoCommentCreatedWebhook` (line 29) builds its payload inline instead — so those two branches only meet one level down. Both look up the target URLs with `s.Store.GetUserWebhooks(...)`, set `payload.URL = hook.Url` and `payload.SigningSecret = hook.SigningSecret`, and call `webhook.PostAsync(payload)` (`memo_service_webhooks.go:43` and `:71`). `PostAsync` enqueues onto the bounded `asyncPostQueue`, whose worker goroutines (`internal/webhook/webhook.go:42-55`) invoke **`webhook.Post` (`internal/webhook/webhook.go:120`)** — the sole place the outbound request is actually issued, at `internal/webhook/webhook.go:152` via `safeClient.Do(req)`.

The user-configured URL originates from `WebhooksUserSetting_Webhook.Url`, written by the `CreateUserWebhook`/`UpdateUserWebhook` handlers in `server/router/api/v1/user_service_webhooks.go`. Those handlers do a DNS resolution through `webhook.ValidateURL` (`internal/webhook/validate.go:62`) but issue no HTTP request themselves, so I've excluded them from the list above.
