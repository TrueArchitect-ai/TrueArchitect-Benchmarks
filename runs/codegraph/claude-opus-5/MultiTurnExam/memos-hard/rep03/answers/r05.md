**Premise correction: there is no GraphQL anywhere in this repository. Grepping `graphql|gqlgen|\.graphql` across all Go, TypeScript, `go.mod`, and JSON files returns zero hits — no schema file, no resolver layer, no client. The public API is Protobuf/gRPC-defined and exposed over Connect + a gRPC-Gateway REST mapping, with a generated OpenAPI spec.**

Actual API surface:

- **Schema of record — Protobuf** in `proto/api/v1/`, one file per service, 8 services total:
  - `memo_service.proto:17` (`MemoService`), `user_service.proto:17` (`UserService`), `auth_service.proto:13` (`AuthService`), `attachment_service.proto:15` (`AttachmentService`), `instance_service.proto:17` (`InstanceService`), `idp_service.proto:14` (`IdentityProviderService`), `shortcut_service.proto:14` (`ShortcutService`), `ai_service.proto:11` (`AIService`)
  - Shared types in `proto/api/v1/common.proto`; persistence-side messages in `proto/store/`. Codegen is driven by `proto/buf.gen.yaml` / `proto/buf.yaml`.
- **Generated code** in `proto/gen/api/v1/` — gRPC stubs (`*_grpc.pb.go`), Connect handlers (`apiv1connect/*.connect.go`), and gRPC-Gateway REST shims (`*.pb.gw.go`).
- **Transports**, both registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):
  - **Connect RPC** (browser client path) — handlers mounted on `/memos.api.v1.*` at `server/router/api/v1/v1.go:141,144`, wrapped by the metadata/logging/recovery/auth interceptors (`v1.go:133-138`).
  - **gRPC-Gateway REST** — `/api/v1/*` (and `/file/*`) at `server/router/api/v1/v1.go:128-129`, with paths derived from `google.api.http` annotations in the protos.
- **OpenAPI, not GraphQL, is the published schema artifact**: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go` and returned by `proto.OpenAPIYAML()`.
- **Non-RPC HTTP surfaces** alongside the API: the file server (`/file/attachments/...`, `/file/users/:identifier/avatar`, `server/router/fileserver/fileserver.go:123-124`), RSS feeds (`server/router/rss/rss.go`), SSE streaming (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`), and an MCP endpoint (`server/router/mcp/`, which exposes tools described by JSON Schema derived from the same OpenAPI spec — `server/router/mcp/openapi.go`).

If the mention of GraphQL came from seeing schema-shaped JSON in `server/router/mcp/openapi.go` (`jsonSchema`, `okSchema`), that's MCP tool-descriptor JSON Schema, unrelated to GraphQL.
