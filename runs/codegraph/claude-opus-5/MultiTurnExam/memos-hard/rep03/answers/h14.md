**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74` — which delegates to the goldmark single-pass walk `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`; Triggers: memo create and content-updating edits; Extracted: `Tags` plus the `Property` struct — `title`, `has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks` (with `Mentions` computed but discarded here)**

**Where it's computed.** `RebuildMemoPayload` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`server/runner/memopayload/runner.go:74-87`). The payload is persisted as the `payload` JSON column (e.g. `store/db/sqlite/memo.go:17-26`), so it's stored derived state, not recomputed per read.

**Triggers (recomputation).** All go through `RebuildMemoPayload`:

- **Create** — `APIV1Service.CreateMemo`, `server/router/api/v1/memo_service.go:108`, before `s.Store.CreateMemo` at line 115.
- **Update with `content` in the field mask** — `APIV1Service.UpdateMemo`, `server/router/api/v1/memo_service.go:447`, inside the `if path == "content"` branch; the rebuilt payload is put on `update.Payload` (line 452). Updates that touch only `visibility`, `pinned`, etc. do *not* recompute.
- **Backfill runner** — `memopayload.Runner.RunOnce` rebuilds every memo in batches of 100 (`server/runner/memopayload/runner.go:27-72`). Note this is dead code in production: nothing constructs `memopayload.Runner` (see h08), so only the two API paths run today.
