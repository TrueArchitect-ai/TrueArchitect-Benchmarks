**`internal/idp` (`github.com/usememos/memos/internal/idp`); `internal/idp/oauth2` (OAuth2 — the only concrete implementation)**

Details:

- **Abstraction**: `internal/idp/idp.go` is the whole package — it defines only the provider-neutral result type `IdentityProviderUserInfo` (Identifier, DisplayName, Email, AvatarURL) at `internal/idp/idp.go:3`. Note there is no Go `interface` here; the "abstraction" is this shared user-info struct plus the `IdentityProvider` proto enum/config (`storepb.IdentityProvider_OAUTH2`, stored via `store/idp.go`).
- **Implementation**: `internal/idp/oauth2/oauth2.go` — package comment "implements the OAuth2 identity provider integration" (`oauth2.go:1`). It provides `NewIdentityProvider` (validates clientId/clientSecret/tokenUrl/userInfoUrl/fieldMapping.identifier, `oauth2.go:27`), `ExchangeToken` with optional PKCE `code_verifier` (`oauth2.go:47`), and `UserInfo`, which GETs the userinfo URL with a bearer token and maps claims through the configured field mapping (`oauth2.go:83`).
- **Dispatch site**: `resolveSSOIdentity` in `server/router/api/v1/auth_service_sso.go:104` branches on `identityProvider.Type == storepb.IdentityProvider_OAUTH2` (line 120) and is the sole consumer. That `if` has no `else` and no other provider type is handled anywhere, so OAuth2 (including OIDC-style providers configured as generic OAuth2) is the only protocol that ships. Management CRUD lives in `server/router/api/v1/idp_service.go`, persistence in `store/idp.go`.
