**`internal/idp` (`github.com/usememos/memos/internal/idp`); `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`) — OAuth 2.0 is the only concrete protocol that ships.**

Details:

- **Abstraction** — `internal/idp/idp.go` is the whole package: it defines `IdentityProviderUserInfo` (`Identifier`, `DisplayName`, `Email`, `AvatarURL`), the normalized shape every provider must produce. Note it's a shared data contract, not a Go `interface` — there is no `IdentityProvider` interface type; the coupling is that implementations return `*idp.IdentityProviderUserInfo`.
- **Implementation** — `internal/idp/oauth2/oauth2.go` provides `IdentityProvider` backed by `golang.org/x/oauth2`, with `NewIdentityProvider` (line 27, validating clientId/clientSecret/tokenUrl/userInfoUrl/fieldMapping.identifier), `ExchangeToken` (line 47, including PKCE `code_verifier` support), and `UserInfo` (line 83, which fetches the userinfo endpoint and maps arbitrary claims onto `idp.IdentityProviderUserInfo` via the configured `FieldMapping`).
- **Wiring** — `server/router/api/v1/auth_service_sso.go:119-134`: `resolveSSOIdentity` switches on `identityProvider.Type` and only handles `storepb.IdentityProvider_OAUTH2`. The store enum (`proto/gen/store`, from `proto/store/idp.proto`) likewise defines only `OAUTH2` alongside the unspecified zero value, confirming no OIDC/SAML/LDAP implementation exists in the tree. Because the type switch has no `else`, a non-OAuth2 type would leave `userInfo` nil.
