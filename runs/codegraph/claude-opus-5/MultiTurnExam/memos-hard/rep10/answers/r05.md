**Premise correction: there is no GraphQL anywhere in this repository — no schema file, no resolvers, no GraphQL server or client dependency. A case-insensitive search for "graphql" across all Go, TypeScript, JSON, `.graphql`, and `go.mod` files (excluding `node_modules`) returns zero hits. The public API is defined in Protocol Buffers and exposed as gRPC / Connect / REST-via-gateway, with a generated OpenAPI spec.**

**Actual API surface:**

- **Schema source of truth**: `.proto` files under `proto/api/v1/` — `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared `common.proto`. Eight services, ~73 RPCs total (largest: `UserService` 26, `MemoService` 20). Persistence-side messages live in `proto/store/` (`memo.proto`, `user_setting.proto`, `attachment.proto`, `idp.proto`, `inbox.proto`, `instance_setting.proto`). REST paths come from `google.api.http` annotations on each RPC (e.g. `/api/v1/{name=users/*}` for `GetUser`).
- **Codegen**: driven by buf — `proto/buf.gen.yaml` runs `protocolbuffers/go`, `grpc/go`, `connectrpc/go`, `grpc-ecosystem/gateway`, `community/google-gnostic-openapi`, and `bufbuild/es`. Output lands in `proto/gen/` (Go: `*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, `apiv1connect/*.connect.go`) and `web/src/types/proto/` (TypeScript for the frontend).
- **OpenAPI, not GraphQL introspection**: the generated spec is `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-5` and served through `proto.OpenAPIYAML()`.
- **Runtime wiring**: `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) mounts both transports on the Echo server — the grpc-gateway REST mux (handlers registered by `RegisterUserServiceHandlerServer` and siblings in `proto/gen/api/v1/*.pb.gw.go`) and the Connect handlers with interceptors `NewMetadataInterceptor`, `NewLoggingInterceptor`, `NewRecoveryInterceptor`, `NewAuthInterceptor` (`v1.go:133-141`). `NewAPIV1Service` is constructed at `server/server.go:76`.
- **Non-gRPC HTTP surfaces** alongside it: file serving at `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), the frontend/static + sitemap routes (`server/router/frontend/frontend.go`), an MCP endpoint (`server/router/mcp/`, which does expose JSON Schema tool definitions — `server/router/mcp/openapi.go`), and `/healthz` (`server/server.go:67`).

If something referred to a "GraphQL schema", the closest real artifacts are the `.proto` definitions in `proto/api/v1/` (the actual schema) and `proto/gen/openapi.yaml` (the published API description).
