**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which delegates to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`.**

**Triggers (recomputation happens only on content writes):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the row is inserted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but *only* inside the `if path == "content"` branch of the update-mask loop (`memo_service.go:435-451`). Changing visibility, pinned state, etc. leaves the stored payload untouched.
- `CreateMemoComment` — indirectly, since it delegates to `s.CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
- `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) would rebuild every memo in batches, but as noted earlier that runner is never instantiated in production — it's dead code, not a live trigger.

**What gets extracted** — one goldmark AST walk produces `ExtractedData` (`internal/markdown/markdown.go:21`), of which `RebuildMemoPayload` persists two fields into `memo.Payload` (`runner.go:85-86`):

- **`Tags`** — every `#tag` node, excluding tags nested inside links/images (`asMemoTagNode`, `markdown.go:135`), deduplicated with original case preserved (`markdown.go:417`).
- **`Property`** (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
  - `Title` — text of the first H1 heading, only when it's the document's first block-level child (`markdown.go:383-389`)
  - `HasLink` — any link node
  - `HasCode` — any code block, fenced code block, or code span
  - `HasTaskList` — any task checkbox
  - `HasIncompleteTasks` — at least one unchecked checkbox (`markdown.go:391-406`)

`ExtractAll` also collects `Mentions` (lowercased `@username` nodes), but `RebuildMemoPayload` does not store them — mentions are consumed separately at request time for notifications (`server/router/api/v1/memo_mention_helpers.go:32`).

One related-but-distinct piece of derived metadata: the list/preview **snippet** is *not* stored on the memo. It's computed on every read in `convertMemoFromStore` via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_converter.go:76-80`, `server/router/api/v1/memo_service_webhooks.go:83-85`), so it needs no recomputation trigger.
