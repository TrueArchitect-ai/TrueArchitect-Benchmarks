**Premise correction: this project has no GraphQL API — there is no schema, no resolver, and no GraphQL dependency.** A case-insensitive search for `graphql` across the entire tree (excluding `node_modules`/`.git`) returns zero files. There is nothing to point to.

**Actual API surface — Protocol Buffers / gRPC, exposed three ways:**

- **Schema definition**: `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto` (package `memos.api.v1`). Persistence-side messages live in `proto/store/`. Generated Go lands in `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, plus Connect stubs in `proto/gen/api/v1/apiv1connect/`), and the TypeScript client types in `web/src/types/proto/api/v1/`.
- **REST/JSON**: each RPC carries a `google.api.http` annotation — e.g. `post: "/api/v1/memos"` and `get: "/api/v1/memos"` on `CreateMemo`/`ListMemos` (`proto/api/v1/memo_service.proto:20-30`). These are served by the grpc-gateway mux registered at `server/router/api/v1/v1.go:126-129` (`/api/v1/*` and `/file/*`).
- **Connect-RPC**: the browser client's transport, mounted at `/memos.api.v1.*` with the interceptor chain at `server/router/api/v1/v1.go:133-144`.
- **OpenAPI, not GraphQL, is the published schema document**: `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`, with MCP tool schemas derived from it in `server/router/mcp/openapi.go`.

Non-gRPC HTTP surfaces exist alongside this — the file server (`/file/attachments/...`, `/file/users/:identifier/avatar`, `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), SSE, and the MCP endpoint (`server/router/mcp/`) — but all of them are REST/streaming HTTP, not GraphQL.
