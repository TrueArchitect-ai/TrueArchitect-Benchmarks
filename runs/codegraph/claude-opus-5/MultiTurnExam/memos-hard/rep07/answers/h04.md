- `store/db/mysql/mysql.go:17,30,73` reference `mysql.Config` / `mysql.ParseDSN` — that's the third-party `github.com/go-sql-driver/mysql` DSN parser, used *inside* the driver package itself.
- `store/test/containers.go:101-131` calls `mysql.Run(...)` — that's `testcontainers-go/modules/mysql` spinning up a MySQL *container*; it produces a DSN that is then fed to `db.NewDBDriver`, and the file imports the raw SQL driver as `mysqldriver` (`containers.go:16`) purely for `sql.Open("mysql", dsn)` health checks (`containers.go:145`).
