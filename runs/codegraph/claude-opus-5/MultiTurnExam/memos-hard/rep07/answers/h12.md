How I determined it — the call site alone can't tell you, because `Store.CreateMemo` (`store/memo.go:109`) just forwards to `s.driver.CreateMemo` on the `store.Driver` interface (`store/driver.go`), which has three implementations (`store/db/sqlite/memo.go:16`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`). So I resolved which implementation gets bound at startup:

1. **Find where the interface value is chosen.** `db.NewDBDriver` switches on `profile.Driver` — `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB` (`store/db/db.go:18-26`). As established earlier, that switch is the *only* construction site for any driver.
2. **Find what fills `profile.Driver` with no flags.** `cmd/memos/main.go:43` reads `viper.GetString("driver")`; the flag defaults to `"sqlite"` in both places that set it — `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the `--driver` flag definition (`cmd/memos/main.go:130`). With no `--driver` flag and no `MEMOS_DRIVER` env var (env prefix set at `cmd/memos/main.go:167-168`), the value is `"sqlite"`.
3. **Confirm the wiring reaches the store.** `main.go:57` calls `db.NewDBDriver(instanceProfile)`, and the resulting driver is handed to `store.New(dbDriver, instanceProfile)` at `main.go:64` — so `s.driver` is `*sqlite.DB` for a default install.
4. **Sanity check the default is self-consistent.** `Profile.Validate` only synthesizes a DSN when `p.Driver == "sqlite"` and `DSN` is empty, defaulting to `<data>/memos_prod.db` (`internal/profile/profile.go:110-118`) — the config path assumes SQLite when nothing is specified, which corroborates step 2.
