**Premise correction: there is no GraphQL anywhere in this repository.** A case-insensitive grep for `graphql|gqlgen|\.graphql` across Go sources, `go.mod`, TypeScript, and JSON returns zero hits — no schema file, no resolver layer, no client library.

**The actual API surface is Protobuf/gRPC, exposed over three transports.**

**Schema definition** — `.proto` files under `proto/api/v1/`:
`instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared `common.proto`. Generated Go lands in `proto/gen/api/v1/`, driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`). Store-internal message types live separately in `proto/store/`.

**Transports**, all wired in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65-146`):

1. **REST via gRPC-Gateway** — the eight services are registered on a `runtime.NewServeMux` (`v1.go:99-121`) and mounted at `/api/v1/*` and `/file/*` (`v1.go:127-128`), wrapped in `http.MaxBytesHandler`.
2. **Connect RPC** — for browser clients, replacing grpc-web; handlers registered at `v1.go:139` and mounted on the path prefix `/memos.api.v1.*` (`v1.go:143`).
3. **SSE** — a streaming endpoint registered alongside the gateway group (`RegisterSSERoutes`, `v1.go:124`).

Both transports share one `Authorizer` (`v1.go:68`), applied as gateway middleware (`v1.go:69-93`) and as a Connect interceptor (`v1.go:135`).

**The nearest thing to a queryable schema document** is the generated OpenAPI spec — `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` at `proto/openapi_embed.go:5` and exposed through `proto.OpenAPIYAML()`. It's also consumed by the MCP service to build tool definitions (`server/router/mcp/openapi.go`).

Non-RPC HTTP surfaces exist too: static file serving at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), and `/healthz` (`server/server.go:67`).
