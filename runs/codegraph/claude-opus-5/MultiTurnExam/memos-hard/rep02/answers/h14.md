**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `(*service).ExtractAll` — `internal/markdown/markdown.go:356`. Triggers: memo creation and content-changing updates. Extracted: tags plus five derived `Property` fields.**

**Where it's computed.** `RebuildMemoPayload(ctx, memo, markdownService)` (`server/runner/memopayload/runner.go:74-88`) ensures `memo.Payload` is non-nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns the results:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

The actual work is one goldmark AST walk in `(*service).ExtractAll` (`internal/markdown/markdown.go:356-421`) — deliberately a single pass rather than separate `ExtractTags`/`ExtractProperties` calls.

**Triggers (production).** Only two call sites, both in the memo service:

1. `CreateMemo` — `server/router/api/v1/memo_service.go:107-109`, before `s.Store.CreateMemo`. This also covers `CreateMemoComment`, which delegates to `s.CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but **only inside the `if path == "content"` branch** of the update-mask loop (`memo_service.go:435-451`). Updating visibility, pinned state, attachments, or relations does not recompute the payload; the recomputed value is threaded into the update via `update.Payload = memo.Payload` (`memo_service.go:451`).

A third, non-production trigger exists: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) rebuilds every memo in batches — but that runner is never constructed anywhere (see h08), so it never fires.

**What's extracted** (into `storepb.MemoPayload`, schema at `proto/store/memo.proto:15-22`):

- **`Tags`** — every `#tag` node, deduplicated with original case preserved via `uniquePreserveCase` (`markdown.go:417`). Requires the tag extension, enabled in production at `server/router/api/v1/v1.go:49`.
- **`Property.Title`** — text of the first block-level child if it's an H1 heading (`markdown.go:383-389`).
- **`Property.HasLink`** — any `gast.KindLink` node (`markdown.go:392-394`).
- **`Property.HasCode`** — any code block, fenced code block, or inline code span (`markdown.go:395-397`).
- **`Property.HasTaskList`** — any GFM task checkbox (`markdown.go:398-400`).
- **`Property.HasIncompleteTasks`** — true if any checkbox is unchecked (`markdown.go:401-404`).

`ExtractAll` also collects `Mentions` (lowercased, `markdown.go:379-381`), but `RebuildMemoPayload` does not persist them — they're used separately for mention notifications (`server/router/api/v1/memo_mention_helpers.go:32`).
