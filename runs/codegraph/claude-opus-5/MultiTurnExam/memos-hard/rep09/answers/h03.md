**`internal/idp` (package `idp`, `internal/idp/idp.go`); `internal/idp/oauth2` (package `oauth2`, `internal/idp/oauth2/oauth2.go`) — OAuth2 is the only protocol implementation that ships.**

Details:

- **Abstraction** — `internal/idp/idp.go` is a single-file package defining just `IdentityProviderUserInfo` (identifier, display name, email, avatar URL) as the normalized shape every provider must produce. It's a shared-type contract rather than a Go interface; there is no `Provider` interface, so `resolveSSOIdentity` dispatches on the stored enum instead of polymorphically (`server/router/api/v1/auth_service_sso.go:120`).
- **Implementation** — `internal/idp/oauth2/oauth2.go` provides `IdentityProvider` with `NewIdentityProvider` (validates required config fields, line 27), `ExchangeToken` (authorization-code exchange with optional PKCE `code_verifier`, line 47), and `UserInfo` (bearer GET against `UserInfoUrl`, JSON claims mapped through the configured `FieldMapping`, line 83).
- **Only one type exists** — the store enum has just `IdentityProvider_OAUTH2`, and `auth_service_sso.go:120` gates the whole SSO flow on it; `internal/idp/` contains only `idp.go` and the `oauth2/` subdirectory. OIDC/SAML are not implemented (an OIDC provider would be configured as generic OAuth2).
