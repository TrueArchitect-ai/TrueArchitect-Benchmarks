**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`.

**Triggers (recomputation happens exactly twice in production):**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`, so the payload is persisted with the row.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but **only** inside the `if path == "content"` branch of the update-mask loop; the rebuilt payload is then attached to the update (`update.Payload = memo.Payload`, line 452) and written at line 496. Updates that only touch `visibility`, `pinned`, `state`, `create_time`, etc. do not recompute.
- Not triggered: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) exists as a bulk backfill that would rebuild every memo's payload, but nothing constructs or calls it (see h08). `SetMemoAttachments` / `SetMemoRelations` refresh the memo state and fire the updated-webhook/SSE, but never re-derive the payload since content is unchanged.

**What it extracts** — one goldmark AST walk fills `storepb.MemoPayload` (`proto/gen/store/memo.pb.go:24`), of which two fields are derived:

- `Tags []string` — every `#tag` node, deduplicated with original case preserved (`uniquePreserveCase`).
- `Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
  - `Title` — text of the first H1 heading, only if it is the document's first block-level child (`markdown.go:383-388`)
  - `HasLink` — any `gast.KindLink` node
  - `HasCode` — any code block, fenced code block, or code span
  - `HasTaskList` — any task checkbox
  - `HasIncompleteTasks` — any task checkbox that is unchecked

`ExtractAll` also returns `Mentions` (lowercased `@username` nodes), but `RebuildMemoPayload` assigns only `Tags` and `Property` (`runner.go:85-86`) — mentions are consumed separately for notifications via `server/router/api/v1/memo_mention_helpers.go:32`. `Payload.Location` is user-set, not derived, and is applied after the rebuild (`memo_service.go:112`).

**Where it's used for lists/previews:** `convertMemoFromStore` copies `memo.Payload.Tags` to `memoMessage.Tags` and maps the property struct via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:48-49`, `:315`). Note the list `Snippet` is *not* part of this stored payload — it is generated per-response by `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`, called from `memo_service_converter.go:76`).
