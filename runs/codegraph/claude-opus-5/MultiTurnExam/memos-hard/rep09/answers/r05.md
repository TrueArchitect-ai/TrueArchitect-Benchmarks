**Premise correction: this project has no GraphQL. A repository-wide case-insensitive search for "graphql" across Go, TypeScript, JSON, and `.graphql` files returns zero hits — there is no schema file, resolver, or GraphQL dependency.**

**Actual API surface — Protocol Buffers / gRPC, exposed over three HTTP transports:**

**Schema definition:** `.proto` files in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `common.proto` (see `proto/api/v1/README.md`). Generated Go bindings live in `proto/gen/api/v1/`, and generated TypeScript for the web client in `web/src/types/proto/api/v1/`. Persistence-layer messages have their own schemas under `proto/store/` → `proto/gen/store/`.

**Transports, all wired in `RegisterGateway` (`server/router/api/v1/v1.go:96-145`):**

1. **REST/JSON via grpc-gateway** — service handlers are registered on a `runtime.ServeMux` (`v1.go:102-122`) and mounted at `/api/v1/*` (and `/file/*`) at `v1.go:128-129`. HTTP verb/path mappings come from `google.api.http` annotations in the `.proto` files. This is the "public API" a third-party client would use.
2. **Connect protocol** — for browser clients, replacing grpc-web: `NewConnectServiceHandler(s)` registers on its own mux (`v1.go:139-141`), mounted at `/memos.api.v1.*` (`v1.go:144`). Interceptor chain: metadata → logging → recovery → auth (`v1.go:133-138`).
3. **MCP (Model Context Protocol)** — a separate tool-facing surface under `server/router/mcp/`, which derives JSON Schema/OpenAPI descriptors for its tools (`server/router/mcp/openapi.go`, `catalog.go`), registered at `server/server.go:96`.

**Non-RPC HTTP surfaces** alongside these: the file server at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:122-125`), RSS feeds (`server/router/rss/rss.go`), SSE streaming (`RegisterSSERoutes`, `v1.go:124`), and `/healthz` (`server/server.go:66`).

So the closest analogue to "the schema" is the `proto/api/v1/*.proto` set — that is the single source of truth from which both the Go server stubs and the TypeScript client types are generated.
