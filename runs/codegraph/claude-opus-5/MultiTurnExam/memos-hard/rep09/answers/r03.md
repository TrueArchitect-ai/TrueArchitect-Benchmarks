**Premise correction: there is no nightly database-cleanup job, and the cron scheduler package is not used by the server at all — so there is no scheduled time to report.**

Evidence:

1. **The cron scheduler is never instantiated in production.** `internal/scheduler/` provides a full cron implementation (`scheduler.New`, `Register`, `ParseCronExpression`, middleware like `Recovery`/`Logging`/`Timeout` — `internal/scheduler/scheduler.go:54`, `:70`, `internal/scheduler/parser.go`). But every reference to the package from outside it comes from its own test files (`internal/scheduler/integration_test.go`, `example_test.go`, etc.). No file under `cmd/`, `server/`, or `store/` imports `internal/scheduler`, so no job of any kind — cleanup or otherwise — is registered with it.
2. **The only scheduled background work is the S3 presign refresher**, and it uses a plain `time.Ticker`, not cron: `s3presign.Runner.Run` on a 12-hour interval, started at `server/server.go:162-171` (see h01). That is the entire contents of `startBackgroundRunners`.
3. **No database-cleanup routine exists.** Grepping for `cleanup|vacuum|purge` across `server/`, `store/`, and `cmd/` turns up only: the in-memory cache's expiry sweeper (`store/cache/cache.go:199-218`, a 5-minute ticker over `sync.Map` entries — memory, not the database), a test teardown helper (`server/router/api/v1/test/test_helper.go:65`), and a local variable name in user deletion (`server/router/api/v1/user_service.go:421`). There is no SQLite `VACUUM`, no orphaned-row sweep, and no retention/expiry job.
4. **Deletion is synchronous and event-driven, not batched overnight.** Cascading data removal happens inline inside the user-delete transaction (`store/db/{sqlite,postgres,mysql}/user_delete.go`), and expired memo shares are checked at read time via `isMemoShareExpired` rather than being reaped by a job.

So if you need periodic database maintenance, it would have to be added — the `internal/scheduler` package is available and unused, making it the natural place to wire one up.
