`store/migration/sqlite/LATEST.sql`

`preMigrate` (`store/migrator.go:211`) checks `IsInitialized`, and for an uninitialized DB reads `getMigrationBasePath() + LatestSchemaFileName` — i.e. `migration/<driver>/LATEST.sql` from the embedded FS (`store/migrator.go:218`, path built at `store/migrator.go:254-256`, constant at line 56) — and executes it in a single transaction, then stamps the current schema version. New installs skip the incremental per-version migrations entirely.
