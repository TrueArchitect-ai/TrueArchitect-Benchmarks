**Runners the server explicitly starts** — all in `Server.startBackgroundRunners` (`server/server.go:153-174`), called from `Server.Start` (line 129):

- **`s3presign.Runner`** — `server/runner/s3presign/runner.go`. Started twice-over: one immediate `RunOnce(ctx)` at boot (line 163), then a goroutine running `Run(s3Context)`, which is a plain `time.Ticker` loop firing every **12 hours** (`runnerInterval`, `runner.go:27-40`). It re-presigns expiring S3 attachment URLs in batches of 100. Cancelled via its own context on shutdown (`stopBackgroundRunners`/`waitBackgroundRunners`).

That is the **only** entry in `startBackgroundRunners`. Other long-lived goroutines exist but are started elsewhere, not by that function:

- **Webhook dispatch workers** — `internal/webhook/webhook.go:42`: a package `init()` spawns **4 goroutines** draining a 128-slot `asyncPostQueue`; triggered per-event by `webhook.PostAsync`, not on a schedule.
- **SSE hub / per-client streams** — `server/router/api/v1/sse_hub.go` + `sse_handler.go`: each connected browser holds a goroutine driven by broadcast events plus a heartbeat `time.Ticker` (`sse_handler.go:63-64`). Closed at shutdown via `closeLongLivedConnections`.
- **HTTP serve loop** — `server/server.go:124`.
