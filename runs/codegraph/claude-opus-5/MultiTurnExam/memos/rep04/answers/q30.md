All four then converge on **`webhook.PostAsync`** — `internal/webhook/webhook.go:184` — which enqueues onto a bounded channel drained by 4 worker goroutines that call **`webhook.Post`** (`internal/webhook/webhook.go:120`) for the actual signed HTTP POST.
