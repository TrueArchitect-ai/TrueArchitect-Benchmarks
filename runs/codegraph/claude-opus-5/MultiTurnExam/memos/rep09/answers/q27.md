**Mechanism: the Vite build output is compiled into `server/router/frontend/dist/` and embedded in the Go binary via `//go:embed dist/*`, then served as static files by Echo middleware with an SPA `index.html` fallback; path: `server/router/frontend/frontend.go`**

How it's wired:

- `//go:embed dist/*` into `embeddedFiles` at `server/router/frontend/frontend.go:20-21` — no external web root, the assets ship inside the binary.
- `FrontendService.Serve` (`:41`) resolves the sub-FS with `getFileSystem("dist")` and installs `middleware.StaticWithConfig` over it (`:53-56`).
- `spaFallbackMiddleware` (`:62`) catches 404s on extension-less paths and returns `index.html` (`:76`), so client-side routes resolve.
- `shouldSkipFrontendStatic` (`:80`) excludes the API surfaces — `/api`, `/file`, `/memos.api.v1.*` — plus `robots.txt`, `sitemap.xml`, and `rss.xml`.
- Cache headers are set by `setFrontendCacheHeaders` (`:90`): no-store for HTML, `max-age=3600` for static assets, and `immutable` for hash-named files under `/assets/`.

`Serve` is invoked from `server/server.go`, and the build step that populates `dist/` is defined in `web/vite.config.ts` (with the copy/build wiring in the project's Makefile/Dockerfile).
