**Mechanism:** the Vite build output is compiled into `server/router/frontend/dist/` and baked into the Go binary with `//go:embed dist/*`, then served as static files by Echo's `middleware.StaticWithConfig` over that embedded FS, with an SPA fallback that returns `index.html` on any 404.

**Path:** `server/router/frontend/frontend.go` — embed directive at line 20-21, wiring in `FrontendService.Serve` (:41-59), fallback in `spaFallbackMiddleware` (:62). `Serve` is invoked from `server/server.go`.

Requests under `/api`, `/file`, `/memos.api.v1*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` are excluded from static handling (`shouldSkipFrontendStatic`, :80). Cache-Control differs per asset class — `no-cache` for HTML, `max-age=3600` for static assets, and `immutable` for hash-named ones (:23-26).
