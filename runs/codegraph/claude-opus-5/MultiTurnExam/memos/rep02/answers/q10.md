`store/migration/sqlite/LATEST.sql`

On a fresh install `preMigrate` detects an uninitialized DB and applies the file at `s.getMigrationBasePath() + LatestSchemaFileName` (`store/migrator.go:218`, constant at line 56), where the base path is dialect-specific — `migration/sqlite/` for SQLite. It's served from the `//go:embed migration` FS (`store/migrator.go:44-45`), and the comment at `store/migrator.go:42` states LATEST.sql is the full schema for new installations, used instead of replaying incremental migrations.
