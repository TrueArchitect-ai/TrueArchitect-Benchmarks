`Store.DeleteMemo` (`store/memo.go:140-159`) deletes, in order, before the memo row:

1. **`memo_relation` rows where the memo is the source** — `DeleteMemoRelation{MemoID: &delete.ID}` (line 142)

3. **Attachments linked to the memo** — lists via `FindAttachment{MemoID}` then `DeleteAttachment` per row (lines 149-157)

Then `s.driver.DeleteMemo(ctx, delete)` removes the memo row (line 158).

Above that, the API handler `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`) first deletes each **comment memo** — every memo related to this one with type `MemoRelationComment` — via its own `Store.DeleteMemo` call, so each comment's relations and attachments are cleaned up too.
