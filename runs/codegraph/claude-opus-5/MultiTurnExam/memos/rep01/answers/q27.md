**Go `embed` of the Vite build output, served by Echo static middleware with SPA fallback; server/router/frontend/frontend.go**

- `//go:embed dist/*` compiles `server/router/frontend/dist` (the built React bundle copied from `web/dist`) into the binary as `embeddedFiles` (`server/router/frontend/frontend.go:20-21`).

- `spaFallbackMiddleware` (line 62) turns a 404 on a non-API path into `index.html` so client-side routes resolve.
