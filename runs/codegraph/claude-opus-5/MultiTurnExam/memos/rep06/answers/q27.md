**Go `embed` of the built `dist/` bundle, served by Echo static middleware with SPA fallback; server/router/frontend/frontend.go**

- `//go:embed dist/*` embeds the compiled Vite output into the binary (`server/router/frontend/frontend.go:20-21`); the build copies `web/dist` there (see the frontend build step in the `Dockerfile` / build scripts).
- `FrontendService.Serve` mounts it via `middleware.StaticWithConfig{Filesystem: getFileSystem("dist")}` (`:41-56`), sets cache headers (`no-cache` for HTML, `max-age=3600[, immutable]` for assets, `:23-26`), and skips `/api`, `/file`, Connect paths (`/memos.api.v1.*`), `robots.txt`, `sitemap.xml`, `rss.xml` (`:80-88`).
- `spaFallbackMiddleware` (`:62-78`) serves `index.html` on 404s so client-side routes resolve.
- It's wired into the server in `server/server.go`, which calls `frontend.NewFrontendService(...).Serve(ctx, echoServer)`.
