**Mechanism** — Server-Sent Events (SSE) over HTTP: `GET /api/v1/sse`, `Content-Type: text/event-stream` (`server/router/api/v1/sse_handler.go:25-48`, registered from `server/router/api/v1/v1.go:124` via `RegisterSSERoutes`). The browser side consumes it in `web/src/` (EventSource-based hook feeding query invalidation).

**Hub** — `server/router/api/v1/sse_hub.go`: defines `SSEEventType` constants (`memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`), the `SSEEvent` payload, and the `SSEHub` with client registration and `Broadcast` (per-client filtering by visibility/creator). Event construction helpers are in `server/router/api/v1/sse_event_helpers.go`.

**Handlers that broadcast:**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`)
- `APIV1Service.DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `APIV1Service.UpdateMemo`, via `dispatchMemoUpdatedSideEffects` — `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`)
- `APIV1Service.CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
- `APIV1Service.UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161` (`reaction.upserted` / `reaction.deleted`)

Note `CreateMemoComment` calls `CreateMemo` with SSE suppressed (`withSuppressSSE`, `server/router/api/v1/memo_service_comments.go:56`) so the comment emits only the `memo.comment.created` event.
