**Mechanism:** CEL compiles the filter string into an AST, which `internal/filter/parser.go` lowers into a dialect-agnostic condition tree (`internal/filter/ir.go`), and `internal/filter/render.go` then renders that tree into a SQL fragment plus bound args for a specific `DialectName` — `sqlite`, `mysql`, or `postgres` (`internal/filter/schema.go:14-17`) — which each driver splices into its `WHERE` clause.
