**Mechanism: Server-Sent Events (SSE)** — a plain HTTP streaming endpoint, not WebSockets. The route is registered by `RegisterSSERoutes` (`server/router/api/v1/sse_handler.go:25`), wired into the API group in `server/router/api/v1/v1.go:124`.

**Hub path: `server/router/api/v1/sse_hub.go`** — defines `SSEHub` with `NewSSEHub` (`:63`) and `Broadcast(event *SSEEvent)` (`:115`), plus the event types `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted` (`:14-21`). `SSEEvent` carries `Visibility`/`CreatorID` for server-side delivery filtering (`:24-33`). Event construction helpers are in `server/router/api/v1/sse_event_helpers.go`.
