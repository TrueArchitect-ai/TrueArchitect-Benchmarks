Details: `SSEHub` (`sse_hub.go:56`) keeps a set of subscribed `SSEClient`s with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close` (lines 71-115), and events carry type, resource name, visibility, and creator ID so the hub can filter per subscriber's user ID and role. The route is registered by `RegisterSSERoutes` (`sse_handler.go:25`) — called from `server/router/api/v1/v1.go` alongside the gateway mux — and authenticates via a Bearer token. On the browser side it's consumed by `web/src/hooks/useLiveMemoRefresh.ts`.

Note that `CreateMemo`'s broadcast is suppressed when it's invoked as the comment path — `CreateMemoComment` wraps the call in `withSuppressSSE` (`memo_service_comments.go:56`) and emits `memo.comment.created` for the parent instead.
