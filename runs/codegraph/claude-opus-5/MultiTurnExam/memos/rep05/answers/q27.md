**Mechanism: the Vite build output is compiled into the Go binary with `//go:embed` and served by Echo static middleware with SPA fallback; wired in `server/router/frontend/frontend.go`**

- `//go:embed dist/*` at `server/router/frontend/frontend.go:20-21` bakes `server/router/frontend/dist` (the copied `web/dist` build) into `embeddedFiles`; `getFileSystem("dist")` (:115) exposes it as an `fs.FS`.
- `FrontendService.Serve` (:41) mounts it via `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` (:54), then adds `spaFallbackMiddleware` (:59-80) which turns a 404 on any extension-less path into `index.html` so client-side routes resolve.
- The skipper (`shouldSkipFrontendStatic`, :82) keeps `/api/*`, `/file/*`, the Connect paths `/memos.api.v1.*`, plus `robots.txt`, `sitemap.xml`, and `*/rss.xml` out of the static handler.
- Cache headers are set per request kind (`setFrontendCacheHeaders`, :92): `no-cache` for HTML, `max-age=3600` for static assets, and `immutable` for hash-named files under `/assets/`.
- `Serve` is invoked from `server/server.go`, and `registerRoutes` (:123) adds the remaining frontend-owned endpoints.
