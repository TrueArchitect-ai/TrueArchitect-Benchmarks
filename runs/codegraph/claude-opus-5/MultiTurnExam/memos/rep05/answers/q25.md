**Engine: Google CEL (`github.com/google/cel-go`), wrapped by the `internal/filter` package — `internal/filter/engine.go` (compile), `internal/filter/parser.go` + `ir.go` (AST → condition tree), `internal/filter/schema.go` (field metadata), `internal/filter/render.go` (tree → SQL)**

**Mechanism, in one sentence:** the filter string is compiled by a CEL environment into a dialect-agnostic condition tree (IR), and each dialect driver then renders that same tree into a parameterised `WHERE` fragment plus args through `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)`, with the renderer switching on `DialectName` wherever the SQL must differ.

Details:
- `Engine.Compile` (`internal/filter/engine.go:47`) runs `env.Compile` over the CEL expression and converts the AST into a `Condition` tree via the parser; the `now` variable is frozen per compile so one filter sees a single instant.
- `Schema` (`internal/filter/schema.go`) declares which identifiers are exposed and how each is stored — `FieldKind` covers plain columns, bool columns, JSON booleans, JSON lists (tags), and virtual aliases — plus per-dialect expression overrides via `Expressions map[DialectName]string`.
- `renderer` (`internal/filter/render.go`) walks the tree and branches on `DialectSQLite` / `DialectMySQL` / `DialectPostgres` exactly where the dialects diverge: timestamp accessors (:231-237), string length (`LENGTH` vs `CHAR_LENGTH`, :297), JSON boolean extraction (:365-402), and tag/list membership (:452-464, :502).
- The call sites are the three `ListMemos` implementations — `store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69` — each obtaining `filter.DefaultEngine()` and passing its own `DialectName`. Values go out as bound placeholders (`PlaceholderOffset` in `internal/filter/helpers.go:13` keeps postgres `$n` numbering correct), so no user input is interpolated into SQL.

The package also carries its own `README.md` and `MAINTENANCE.md` under `internal/filter/` describing the supported filter grammar.
