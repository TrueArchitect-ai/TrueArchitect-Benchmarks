**Mechanism:** The filter string is CEL-compiled once into a dialect-agnostic condition tree, then each dialect driver — `store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69` — calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect{SQLite|Postgres|MySQL}, &where, &args)`, which renders that tree into parameterized `WHERE` fragments plus bind args using per-dialect expression templates (e.g. `('users/' || %s)` for SQLite/Postgres vs `CONCAT('users/', %s)` for MySQL, `UNIX_TIMESTAMP(%s)` for MySQL timestamps, and dialect-specific JSON/tag operators in `internal/filter/render.go`).
