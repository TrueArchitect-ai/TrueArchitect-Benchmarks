Premise is wrong: there is no GraphQL schema or server (no `graphql`/`gqlgen` dependency or code). The public API is gRPC/Protobuf defined in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1/`), exposed over HTTP two ways — grpc-gateway REST transcoding and Connect handlers, both registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:66+`, service wiring `server/router/api/v1/connect_services.go`) from `server/server.go:88`. Additional non-gRPC surfaces: the file server (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), and MCP (`server/server.go:92-96`).
