Premise is wrong: there is no message broker — neither NATS nor RabbitMQ appears in the code or `go.mod`, and no queue is declared. Webhook delivery uses an in-process buffered Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`), drained by 4 goroutines started in `init()` (`:42-55`), each calling `Post` (`:120`); when the buffer is full, the event is dropped with a warning (`PostAsync`, `:184-196`). Nothing survives a restart.
