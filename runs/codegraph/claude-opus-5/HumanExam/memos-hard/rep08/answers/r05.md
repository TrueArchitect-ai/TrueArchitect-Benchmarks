Premise is wrong: there is no GraphQL schema or GraphQL server in this codebase (no `graphql` reference in any `.go` or `.proto` file, none in `go.mod`). The public API is Protobuf/gRPC-defined: service definitions live in `proto/api/v1/*.proto` with generated code in `proto/gen/api/v1/`. It is exposed two ways over the same Echo HTTP server — Connect RPC handlers (`server/router/api/v1/connect_handler.go:31-45`, for `InstanceService`, `AuthService`, `UserService`, `MemoService`, `AttachmentService`, `AIService`, `ShortcutService`, `IdentityProviderService`) and a gRPC-Gateway REST mux (`server/router/api/v1/v1.go:95-120`). Additional non-RPC surfaces: the file server (`server/router/fileserver/fileserver.go:122-125`) and RSS (`server/router/rss/rss.go`).
