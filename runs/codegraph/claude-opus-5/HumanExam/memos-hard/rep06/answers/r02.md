Premise is wrong: there is **no per-user API rate-limiting middleware** in this codebase, and therefore no request limits. Grep for `ratelimit`/`rate_limit`/`rate limit` across all Go files yields exactly one hit — an aspirational comment in `internal/email/doc.go:86` ("Rate limit email sending to prevent abuse"). The API middleware chain is authentication/authorization and CORS only: `server/router/api/v1/v1.go:64+` (`NewAuthorizer`, gateway auth middleware, Connect interceptors in `server/router/api/v1/connect_interceptors.go`, ACL config in `server/router/api/v1/acl_config.go`). Concurrency limiters exist but are not rate limits: `semaphore.NewWeighted(3)` / `(2)` for thumbnails and image processing (`server/router/api/v1/v1.go:60-61`).
