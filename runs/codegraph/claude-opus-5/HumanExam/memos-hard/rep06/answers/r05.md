Premise is wrong: **there is no GraphQL schema or GraphQL server** — no `graphql` reference in any Go file, `go.mod`, or `web/src`. The public API is **Protobuf/gRPC-defined**, in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`), generated into `proto/gen/api/v1/` (gRPC + Connect stubs in `proto/gen/api/v1/apiv1connect/`). It is served as gRPC, Connect, and a gRPC-Gateway REST/JSON surface registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:63`). Non-RPC HTTP surfaces are `/file/...` (`server/router/fileserver/fileserver.go:120-125`) and RSS (`server/router/rss/rss.go`).
