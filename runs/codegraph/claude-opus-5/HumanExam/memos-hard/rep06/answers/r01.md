Premise is wrong: there is **no Redis** anywhere in this repo (no `redis` import, dependency, or config; grep across Go/TS/YAML returns nothing). Caching is a purely in-process implementation: `store/cache/cache.go` (`Cache` type, `Close` at `:187`), instantiated as `Store.instanceSettingCache`, `Store.userCache`, `Store.userSettingCache` (`store/store.go:74-76`). User entries have **no TTL** — they are written on read/create/update (`store/user.go:98,122,132,143,167`) and removed explicitly on delete via `deleteUserCache` (`store/user_delete.go:39-46`). The only TTL-style expiry in the server is the unrelated `instanceStatsCache` (`server/router/api/v1/v1.go:47`, `instanceStatsCacheTTL`).
