— Premise is wrong: there is **no Redis** anywhere in the repo (no `redis` import in `go.mod` or any `.go` file). Caching is an in-process, in-memory implementation: `store/cache/cache.go` (`Interface` at `:10`, `Cache.Close` at `:187`). The store creates three of them — `instanceSettingCache`, `userCache`, `userSettingCache` — in `store.New` at `store/store.go:51-53`, all sharing one config built at `store/store.go:39-44`: `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`. So user entries expire after **10 minutes**, and the cache is keyed by user ID only (`store/user.go:88,150`) — username lookups miss it entirely.
