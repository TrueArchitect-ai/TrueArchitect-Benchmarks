— Premise is wrong: there is **no GraphQL schema** — no `graphql` dependency, schema file, or resolver in the repo. The public API is **gRPC defined in Protocol Buffers** under `proto/api/v1` (generated to `proto/gen/api/v1`), exposed over HTTP two ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`): a grpc-gateway REST/JSON mux (handlers registered at `server/router/api/v1/v1.go:96-120` for Instance, Auth, User, Memo, Attachment, AI, Shortcut, IdentityProvider services) and Connect handlers. Alongside it are plain HTTP surfaces: the file server (`server/router/fileserver/fileserver.go:121`), RSS (`server/router/rss/rss.go`), SSE, and MCP (`server/server.go:92-96`).
