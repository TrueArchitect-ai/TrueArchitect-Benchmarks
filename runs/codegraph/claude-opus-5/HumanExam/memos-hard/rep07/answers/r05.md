Actual API surface: Protobuf/gRPC definitions under `proto/api/v1`, generated into `proto/gen/api/v1`, exposed over HTTP two ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) — a grpc-gateway REST/JSON transcoding layer, and Connect RPC handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`, generated clients in `proto/gen/api/v1/apiv1connect/`). Alongside that: an SSE stream (`server/router/api/v1/sse_handler.go`), a plain-HTTP file server (`server/router/fileserver/fileserver.go:124`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/server.go:92-96`), and `/healthz` (`server/server.go:67`).
