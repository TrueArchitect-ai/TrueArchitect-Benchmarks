— Premise is wrong: there is no GraphQL schema or GraphQL server anywhere (no `graphql` reference in any Go file or in `go.mod`). The public API is gRPC/Connect defined by Protocol Buffers under `proto/api/v1/` (generated Go in `proto/gen/api/v1/`), exposed over HTTP two ways: Connect handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`) and a gRPC-Gateway REST/JSON transcoding layer registered by `APIV1Service.RegisterGateway` (`server/server.go:88`, `server/router/api/v1/v1.go:95`). Additional non-gRPC HTTP surfaces: the file server (`server/router/fileserver/fileserver.go:124`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), and MCP (`server/server.go:92-96`).
