— False premise: there is no GraphQL schema or GraphQL server in this codebase.

Actual API surface: Protobuf/gRPC defined under `proto/api/v1/*.proto` (generated to `proto/gen/api/v1/`), served over **Connect RPC** plus a **gRPC-gateway REST/JSON transcoding** layer registered at `apiV1Service.RegisterGateway(ctx, echoServer)` (`server/server.go:88`); handler wiring in `server/router/api/v1/connect_handler.go` and `connect_services.go`. Alongside it are plain HTTP routes: `/file/...` (`server/router/fileserver/fileserver.go:122-124`), RSS (`server/router/rss/rss.go`), an SSE endpoint (`server/router/api/v1/sse_handler.go`), MCP (`server/router/mcp`), and `/healthz` (`server/server.go:67`).
