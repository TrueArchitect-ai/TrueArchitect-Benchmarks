— False premise: there is no rate-limiting middleware in this codebase, per-user or otherwise.

No rate-limit/throttle middleware is registered. Echo middleware on the server is only `middleware.Recover()` and a CORS middleware (`server/server.go:51-52`); the Connect/gRPC interceptor chain (`server/router/api/v1/connect_interceptors.go`) does auth and logging, not throttling. The only occurrence of the phrase in Go source is an aspirational doc comment, `internal/email/doc.go:86` ("Rate limit email sending to prevent abuse"). The one bounded-throughput mechanism that exists is unrelated to API requests: a `semaphore.Weighted` capping concurrent thumbnail generation (`server/router/fileserver/fileserver.go:107`).
