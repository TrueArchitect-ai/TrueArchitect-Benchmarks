— Webhook delivery
**Delivery function:** `webhook.Post` — `internal/webhook/webhook.go:120`; the actual HTTP call is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. It is fed asynchronously by `PostAsync` (`internal/webhook/webhook.go:184`) → 128-slot channel + 4 worker goroutines (`internal/webhook/webhook.go:39,41-53`).
**Protection:** SSRF guard at dial time — `safeDialContext` on the shared client's Transport (`internal/webhook/webhook.go:33-35,59-77`), which resolves the host and rejects reserved/private IPs via `isReservedIP`/`reservedCIDRs` (`internal/webhook/validate.go:14-53`); this also defeats DNS rebinding. Config-time check: `webhook.ValidateURL` (`internal/webhook/validate.go:64`), called at `server/router/api/v1/user_service_webhooks.go:74,161,182`. Escape hatch: `AllowPrivateIPs` (`internal/webhook/validate.go:42`).
