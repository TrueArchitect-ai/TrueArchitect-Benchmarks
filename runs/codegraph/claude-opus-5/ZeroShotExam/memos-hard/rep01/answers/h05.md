**Mechanism: explicit Go code, in two passes, inside the delete transaction — not a database rule.** There is no foreign key or `ON DELETE CASCADE` on the `reaction` table in any driver.

**Evidence**

Deletion orchestration — `deleteUserTargetsTx` calls both reaction deletes before the user row is removed (identical in all three drivers, `store/db/{sqlite,postgres,mysql}/user_delete.go:92-127`):

```go
if err := deleteReactionsByContentIDsTx(ctx, tx, contentIDs); err != nil { ... }  // :96
...
if err := deleteReactionsByCreatorTx(ctx, tx, userID); err != nil { ... }        // :102
```

The two passes cover different things:
- `deleteReactionsByCreatorTx` — `DELETE FROM reaction WHERE creator_id = ?`: reactions the deleted user *made*, anywhere. (`sqlite/user_delete.go:400`, `postgres/user_delete.go:400`, `mysql/user_delete.go:437`)
- `deleteReactionsByContentIDsTx` — `DELETE FROM reaction WHERE content_id IN (...)` batched at 500: reactions *others* left on the deleted user's memos. `content_id` is built as `"memos/"+memo.UID` by `memoContentIDsFromRefs` (`sqlite/user_delete.go:512-518`), over the memo tree collected by `listDeleteUserMemoTreeIterative` (`:133`), which walks `COMMENT` relations so descendant comment memos are included too. (`sqlite/user_delete.go:380`, `postgres/user_delete.go:380`, `mysql/user_delete.go:417`)

Schema — the `reaction` table has no FK at all in any dialect; the only cascade in these files is on `memo_share.memo_id`:
- `store/migration/sqlite/LATEST.sql:92-99`
- `store/migration/postgres/LATEST.sql:91-98`
- `store/migration/mysql/LATEST.sql:91-98`
- `grep` for `FOREIGN KEY|REFERENCES|ON DELETE` across all three `LATEST.sql` returns only `memo_share.memo_id → memo(id) ON DELETE CASCADE` (line ~108 in each); the same grep across every `store/migration/**/*.sql` returns no hit mentioning `reaction`.

Wrapper path: `store.DeleteUser` (`store/user.go:171-172`) just delegates to `s.driver.DeleteUser`, so the driver-level transaction above is the whole mechanism. The work is committed atomically — `tx.Commit()` at `sqlite/user_delete.go:51` and its peers.
