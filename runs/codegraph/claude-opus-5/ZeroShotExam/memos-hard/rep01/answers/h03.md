h03.
`internal/idp`; `internal/idp/oauth2`

- **Abstraction package — `github.com/usememos/memos/internal/idp`** (`internal/idp/idp.go`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider must produce.
- **Implementation package — `github.com/usememos/memos/internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): "Package oauth2 implements the OAuth2 identity provider integration" — `IdentityProvider` wrapping `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (incl. PKCE `codeVerifier`), and user-info fetch/field-mapping.

OAuth2 is the only concrete protocol that ships: the proto enum `IdentityProvider.Type` has just `OAUTH2 = 1` (`proto/api/v1/idp_service.proto:79`, `proto/store/idp.proto:13`), and the SSO login path in `server/router/api/v1/auth_service_sso.go:121` dispatches solely to `oauth2.NewIdentityProvider`. The web UI's presets (GitHub, GitLab, Google, Custom) are all OAuth2 templates (`web/src/components/CreateIdentityProviderDialog.tsx:27-124`).
