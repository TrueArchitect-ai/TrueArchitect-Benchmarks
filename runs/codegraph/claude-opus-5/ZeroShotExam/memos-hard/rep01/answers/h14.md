### Computation site
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:80-86). One parse per memo, single AST walk.
- The actual derivation is `internal/markdown/markdown.go:356` (`ExtractAll`), which walks the parsed goldmark AST once. (`ExtractProperties`, `internal/markdown/markdown.go:193`, contains the identical property logic but is only exercised by tests/benchmarks — the payload path uses `ExtractAll`.)

### Triggers
1. **Create memo** — `server/router/api/v1/memo_service.go:108`, in `CreateMemo` before `Store.CreateMemo`.
2. **Update memo, content path only** — `server/router/api/v1/memo_service.go:447`, inside the `UpdateMemo` update-mask loop when `path == "content"`; the rebuilt payload is attached via `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, timestamps) do not recompute it.
3. **Bulk backfill** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) pages through all memos in batches of 100, rebuilding and persisting each payload. Note `NewRunner`/`RunOnce` currently have no callers in the server startup path (only the package's `RebuildMemoPayload` is imported, by `memo_service.go`), so it's a migration/backfill entry point rather than a live trigger.

### Extracted properties
From `ExtractAll` (`internal/markdown/markdown.go:379-406`), into `storepb.MemoPayload_Property`:
- `Title` — text of the document's **first block-level child if it is an H1 heading** (via `extractHeadingText`, markdown.go:383-389).
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any `east.KindTaskCheckBox`.
- `HasIncompleteTasks` — a task checkbox with `IsChecked == false`.
- Alongside these, `data.Tags` (deduped, case-preserving) and `data.Mentions` come from the same walk; only Tags and Property are written to the payload.
