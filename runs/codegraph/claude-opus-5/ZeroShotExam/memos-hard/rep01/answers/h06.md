**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`

Every path calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`:41-52`) each call `Post`, which is the single place the request is built (`http.NewRequest("POST", requestPayload.URL, ...)`), HMAC-signed with the Standard Webhooks headers, and actually sent via `safeClient.Do(req)` — the shared client whose `safeDialContext` (`:57`) blocks reserved/private IPs for SSRF protection.
