**Premise correction:** There is no GraphQL anywhere in this repository. A case-insensitive search for `graphql` across the whole tree (excluding `node_modules`/`.git`) returns zero hits — no schema files, no resolvers, no server or client library.

**Actual API surface — Protocol Buffers, exposed over Connect/gRPC + a REST gateway:**

- **Schema source of truth:** `proto/api/v1/*.proto` — eight services: `AIService` (`ai_service.proto:11`), `AuthService` (`auth_service.proto:13`), `IdentityProviderService` (`idp_service.proto:14`), `UserService` (`user_service.proto:17`), `MemoService` (`memo_service.proto:17`), `InstanceService` (`instance_service.proto:17`), `ShortcutService` (`shortcut_service.proto:14`), `AttachmentService` (`attachment_service.proto:15`). Shared types in `proto/api/v1/common.proto`; storage-layer protos in `proto/store/`.
- **Codegen:** driven by buf — `proto/buf.gen.yaml` (+ `buf.yaml`, `buf.lock`), generating Go message/gRPC/Connect stubs and grpc-gateway bindings into `proto/gen/api/v1/` (Connect handlers under `proto/gen/api/v1/apiv1connect/`), plus TypeScript clients into `web/src/types/proto/`. Regenerate with `buf generate` (`proto/README.md`).
- **REST/OpenAPI:** the gnostic plugin emits `proto/gen/openapi.yaml` (paths like `/api/v1/ai:transcribe`), embedded and served via `proto/openapi_embed.go`. HTTP annotations in the `.proto` files drive the grpc-gateway routes.
- **Serving:** `server/router/api/v1/v1.go:65` `RegisterGateway` mounts both the grpc-gateway mux (`v1.go:96`) and the Connect mux (`v1.go:139`) onto Echo; called from `server/server.go:88`. Handler implementations live on `APIV1Service` (`server/router/api/v1/v1.go:22`), with Connect adapters in `connect_handler.go` / `connect_services.go`.
- **Other surfaces:** an MCP server at `server/router/mcp/` (which derives its tool catalog/JSON Schemas from the same OpenAPI spec) and an RSS endpoint at `server/router/rss/`.
