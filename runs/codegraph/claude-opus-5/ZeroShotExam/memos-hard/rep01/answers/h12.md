**How I determined it among the three candidates**

There are three sibling implementations of the same `store.Driver` method, all with an `INSERT INTO memo`:

- `store/db/sqlite/memo.go:41` — `INSERT ... RETURNING ...`
- `store/db/postgres/memo.go:38` — `INSERT ... RETURNING ...` (`$n` placeholders)
- `store/db/mysql/memo.go:41` — plain `INSERT`, then `LastInsertId()` + re-`GetMemo`

Selection is runtime data, not a compile-time type, so I traced the value that gets bound into the interface:

1. **Call chain to the interface.** `Store.CreateMemo` (`store/memo.go:109-114`) validates the UID and delegates to `s.driver.CreateMemo(ctx, create)`. `s.driver` is a `store.Driver` interface field (`store/store.go:15`), assigned once in `store.New` (`store/store.go:38-58`) from whatever is passed in — no decorator or caching wrapper around it, so the concrete driver is exactly the one constructed at startup.
2. **The single dispatch point.** `NewDBDriver` (`store/db/db.go:14-31`) is the only place the concrete type is chosen: a `switch profile.Driver` over `"sqlite"` / `"mysql"` / `"postgres"`, with `default:` returning `errors.New("unknown db driver")` — meaning the field must be one of the three, never empty.
3. **What `profile.Driver` is with no flags.** In `cmd/memos/main.go`, the profile is built from viper (`Driver: viper.GetString("driver")`, line 43), and the default is set in two places: `viper.SetDefault("driver", "sqlite")` (line 122) and the flag default `rootCmd.PersistentFlags().String("driver", "sqlite", "database driver")` (line 130), bound at line 151. So with no `--driver`/`MEMOS_DRIVER`, the value is `"sqlite"`, and `main.go:60` passes that driver straight into `store.New` (line 64).
4. **Corroboration.** `internal/profile/profile.go:110` special-cases `p.Driver == "sqlite" && p.DSN == ""` to synthesize the default local DB file path — the only driver given a zero-config fallback, consistent with it being the default-install path.

So the mysql and postgres `CreateMemo` bodies are dead code in a default install; only the sqlite one runs.
