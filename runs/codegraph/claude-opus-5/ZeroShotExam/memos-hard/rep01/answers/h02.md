**delivery function** — `webhook.Post` at `internal/webhook/webhook.go:120` (the actual outbound `POST`; `safeClient.Do(req)` at `internal/webhook/webhook.go:152`). It is normally reached asynchronously: memo events call `webhook.PostAsync` (`internal/webhook/webhook.go:184`) from `server/router/api/v1/memo_service_webhooks.go:43,71`, which enqueues onto a bounded 128-slot channel drained by 4 goroutines started in `init()` (`internal/webhook/webhook.go:39-55`), each calling `Post`.

**protection mechanism** — two layers, both keyed on `isReservedIP` in `internal/webhook/validate.go:44`:

1. **Dial-time SSRF guard (the one that actually protects delivery)** — `safeDialContext` at `internal/webhook/webhook.go:59-77`, installed as the `Transport.DialContext` of the shared `safeClient` (`internal/webhook/webhook.go:32-37`). It splits host/port, resolves the host with `net.DefaultResolver.LookupHost`, and refuses to dial if any resolved IP is reserved. Because the check happens at connection time rather than at save time, it also defeats DNS rebinding.
2. **Registration-time validation** — `webhook.ValidateURL` at `internal/webhook/validate.go:62-83`, called when a user creates or updates a webhook (`server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`). It enforces an absolute `http`/`https` URL and rejects hostnames resolving to reserved ranges, returning a gRPC `InvalidArgument`.

The blocked ranges are the parsed `reservedCIDRs` list at `internal/webhook/validate.go:14-23` — IPv4 loopback, RFC-1918 10/8, 172.16/12, 192.168/16, link-local 169.254/16 (cloud IMDS), plus `::1/128`, `fc00::/7`, `fe80::/10`. Both layers are disabled together by the `webhook.AllowPrivateIPs` escape hatch (`internal/webhook/validate.go:41,45`), intended for self-hosted LAN targets; outside tests nothing in the Go code assigns it, so it defaults to `false` (protection on).

Secondary hardening on the same path: 30s client timeout (`internal/webhook/webhook.go:27`), a 1 MiB response read cap (`internal/webhook/webhook.go:158`), and HMAC-SHA256 Standard-Webhooks signing headers (`internal/webhook/webhook.go:133-150`).
