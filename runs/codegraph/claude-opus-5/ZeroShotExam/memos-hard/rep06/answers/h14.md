**Computation site**: `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-based markdown service `(*service).ExtractAll` in `internal/markdown/markdown.go:355-422`. The result is written into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:85-86`) and persisted with the memo row.

**Triggers**:
- Memo creation — `CreateMemo` calls it on the new memo before insert (`server/router/api/v1/memo_service.go:108`). A user-supplied `location` is layered onto the rebuilt payload afterwards (`:111-113`).
- Memo content update — inside `UpdateMemo`'s update-mask loop, only when the `content` path is present; the new content is assigned and the payload rebuilt, then both are put on the store update (`server/router/api/v1/memo_service.go:436-451`). Other mask paths (`visibility`, `pinned`, `state`, timestamps, `location`, `attachments`, `relations`) do **not** recompute it — `location` only mutates `Payload.Location` in place (`:481-484`).
- Bulk backfill — `Runner.RunOnce` re-derives the payload for every memo in batches of 100 and writes it back (`server/runner/memopayload/runner.go:26-72`). Note this runner is defined but not wired into startup: `server/server.go:162-169` only starts the `s3presign` runner, so today it's an unused backfill path.

**Extracted properties** (single AST walk in `ExtractAll`):
- `Tags` — every `#tag` node, deduplicated with original case preserved (`markdown.go:376-378, 418`).
- `Property.Title` — text of the document's first block-level child if it is an H1 heading (`markdown.go:383-389`; proto field `proto/store/memo.proto:20-21`).
- `Property.HasLink` — any link node (`markdown.go:393-394`).
- `Property.HasCode` — any code block, fenced code block, or code span (`:396-397`).
- `Property.HasTaskList` — any GFM task checkbox; `Property.HasIncompleteTasks` — at least one unchecked checkbox (`:399-405`).
- (`ExtractedData.Mentions` is also collected in the same pass but is not stored on the payload — `runner.go` copies only `Tags` and `Property`.)

Related but separate: the list/preview `snippet` is *not* stored — it's generated per-response at conversion time via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-90`, called from `server/router/api/v1/memo_service_converter.go:76`).
