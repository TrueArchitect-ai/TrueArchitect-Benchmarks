**Premise correction: there is no GraphQL in this repository.** A repo-wide search for `graphql` / `gqlgen` / `apollo` / `graphene` across Go, TypeScript, proto, YAML, JSON, and Markdown returns zero matches — no `.graphql`/`.gqls` schema files, no GraphQL dependency in `go.mod`, and none in `web/package.json`. Memos' public API is **Protocol Buffers–defined, served over Connect/gRPC + REST**.

## Actual API surface

**Schema of record — `.proto` files in `proto/api/v1/`:**

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

(`proto/store/*.proto` are internal persistence types, not part of the public API.)

**Codegen pipeline — `proto/buf.gen.yaml`** runs `buf generate` (per `proto/README.md`) and emits, all into `proto/gen/`:
- protobuf Go types + gRPC stubs + **Connect** handlers (`proto/gen/api/v1/apiv1connect/`)
- grpc-gateway REST bindings (`*.pb.gw.go`)
- **`proto/gen/openapi.yaml`** — a 4057-line OpenAPI 3.0.3 spec generated by gnostic; this is the closest thing to a "schema document" for the public HTTP API, and it's embedded into the binary via `proto/openapi_embed.go` (`OpenAPIYAML()`)
- TypeScript client types into `web/src/types/proto` (buf `es` plugin)

**Serving layer:**
- `server/router/api/v1/connect_handler.go:37-44` mounts the eight Connect service handlers; `connect_services.go` delegates each method to the gRPC implementation in `server/router/api/v1/*_service.go`.
- REST paths are the gateway annotations, e.g. `/api/v1/memos`, `/api/v1/attachments`, `/api/v1/ai:transcribe` (visible in `proto/gen/openapi.yaml`).
- Additional non-proto surfaces: `server/router/mcp/` (an MCP server that reads the embedded OpenAPI spec — `server/router/mcp/openapi.go` parses it into tool schemas), plus `server/router/rss/`, `server/router/fileserver/`, and SSE endpoints (`server/router/api/v1/sse_handler.go`).

If you're looking for where to change the public API contract, edit the `.proto` files in `proto/api/v1/` and re-run `buf generate`.
