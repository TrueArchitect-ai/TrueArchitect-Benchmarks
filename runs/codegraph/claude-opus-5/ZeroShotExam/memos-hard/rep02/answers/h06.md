**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`

The chain: each dispatcher in `server/router/api/v1/memo_service_webhooks.go` looks up the creator's configured hooks via `s.Store.GetUserWebhooks`, builds a `WebhookRequestPayload` with `payload.URL = hook.Url` (`memo_service_webhooks.go:40,68`), and calls `webhook.PostAsync` (line 184), which enqueues onto `asyncPostQueue`. Four worker goroutines started in `init()` (webhook.go:42-55) drain the queue and call `Post`, the single place that builds the `http.NewRequest("POST", requestPayload.URL, …)`, HMAC-signs it, and issues `safeClient.Do(req)` (webhook.go:126-152). `PostAsync` is the convergence point on the API side, but `Post` is where every path — sync worker or direct — actually performs the outbound request.

Note: the webhook URL is validated at configuration time (`webhook.ValidateURL` in `CreateUserWebhook`/`UpdateUserWebhook`, `server/router/api/v1/user_service_webhooks.go`), and `safeClient`'s `safeDialContext` (webhook.go:59) blocks reserved/private IPs at dial time.

Separately, `GetLinkMetadata`/`BatchGetLinkMetadata` fetch a *per-request* user-supplied URL via `internal/httpgetter` — outbound HTTP, but not a stored/configured URL and not routed through `webhook.Post`.
