**Computation site.** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-backed markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk; heading text via `extractHeadingText`, `internal/markdown/markdown.go:173`). The result is written onto `memo.Payload` (`storepb.MemoPayload.Property`, `proto/store/memo.proto`) and surfaced on the API as `Memo.property` by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`), matching the `Memo.Property` message declared OUTPUT_ONLY at `proto/api/v1/memo_service.proto:256,272`.

**Triggers.**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert. Comment creation goes through this same path (`server/router/api/v1/memo_service_comments.go:56`).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask contains `content`; the rebuilt payload is then written along with the new content. Other mask paths (visibility, pinned, state, …) don't recompute.
- Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives payloads for every memo in batches of 100. Note this runner is not currently wired up — `server/server.go:162` only constructs the `s3presign` runner, and there are no other callers of `memopayload.NewRunner`.

**Extracted properties.** From one walk of the parsed markdown (`internal/markdown/markdown.go:371-421`):
- `HasLink` — any `KindLink` node (includes images/autolinks parsed as links).
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any GFM `TaskCheckBox` node.
- `HasIncompleteTasks` — at least one task checkbox with `IsChecked == false`.
- `Title` — plain text of an H1, but only if that heading is the *first* block-level child of the document; otherwise empty (`internal/markdown/markdown_test.go:309-341` covers "h1 first node" / "no h1" / "h1 not first").
- Alongside the property, the same call sets `Payload.Tags` (deduplicated, original case preserved).

The equivalent standalone helper `(*service).ExtractProperties` (`internal/markdown/markdown.go:193`) applies the identical rules. Separately, the list/preview `snippet` field is *not* part of this payload — it's computed per-response by `getMemoContentSnippet` during conversion (`server/router/api/v1/memo_service_converter.go:76`).
