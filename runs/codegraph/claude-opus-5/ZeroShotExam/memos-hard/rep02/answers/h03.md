**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` — package `idp` defines the shared abstraction: the `IdentityProviderUserInfo` struct (Identifier, DisplayName, Email, AvatarURL) that every provider implementation must produce.
- `internal/idp/oauth2/oauth2.go` — the only concrete protocol implementation ("Package oauth2 implements the OAuth2 identity provider integration"), exposing `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with PKCE `code_verifier` support), and `UserInfo`.

Corroborating evidence:
- `proto/store/idp.proto:11-15` — the `IdentityProvider.Type` enum has exactly one non-unspecified value, `OAUTH2 = 1`.
- `server/router/api/v1/auth_service_sso.go:119-133` — `resolveSSOIdentity` branches only on `storepb.IdentityProvider_OAUTH2`, constructing `oauth2.NewIdentityProvider(...)` and returning an `*idp.IdentityProviderUserInfo`.

No SAML, OIDC, or LDAP implementation ships.
