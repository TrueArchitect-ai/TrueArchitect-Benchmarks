**Premise correction:** There is no GraphQL schema anywhere in this repository. A case-insensitive search for `graphql` across the entire tree returns **zero** matches — no `.graphql`/`.gql` files, no schema-first SDL, no resolvers, and no GraphQL server dependency in `go.mod`. Memos does not expose a GraphQL API.

**The actual API surface: Protobuf/gRPC, with the `.proto` files as the schema of record.**

The public API contract is defined in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — `MemoService`
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared types

(`proto/store/*.proto` are internal persistence messages, not public API.)

**How the schema becomes wire protocols** — `proto/buf.gen.yaml` drives codegen into `proto/gen/` and `web/src/types/proto`, producing four surfaces from the one schema:

1. **REST/JSON** — each RPC carries a `google.api.http` annotation (e.g. `proto/api/v1/memo_service.proto:35` maps `GetMemo` to `GET /api/v1/{name=memos/*}`). grpc-gateway serves these; the mux is built and all eight services registered in `server/router/api/v1/v1.go:96-128`, mounted at `/api/v1/*` and `/file/*` (`v1.go:126-127`).
2. **Connect RPC** — for browser clients (replaces grpc-web), mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:143`).
3. **gRPC** — standard `protoc-gen-go-grpc` stubs in `proto/gen/api/v1/`.
4. **OpenAPI 3.0.3** — `proto/gen/openapi.yaml` (4057 lines), generated from the protos via the gnostic plugin. This is the closest thing to a "public API schema document," but it is a *generated artifact*, not a source of truth — edit the `.proto` files and regenerate.

The service implementations live in `server/router/api/v1/`, with `APIV1Service` embedding each generated `Unimplemented*ServiceServer` (`server/router/api/v1/v1.go:22-31`).

Two adjacent non-gRPC surfaces exist as well: an MCP server under `server/router/mcp/` (which builds JSON Schema tool definitions in `server/router/mcp/openapi.go` — likely what a `graphql`-adjacent search would surface as "schema") and an RSS feed at `server/router/rss/rss.go`.
