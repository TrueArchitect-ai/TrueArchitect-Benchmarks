Counting distinct Go packages *outside* `store/...` (i.e. excluding `store/db/{sqlite,mysql,postgres}` and `store/test`, which are part of the data layer itself) that reference each type:

By raw reference count `Memo` and `User` are close (31 vs 36 file hits), but `User` reaches one extra package — it's the only entity touched by `server/auth` (`server/auth/*.go`), since authentication resolves the current user, while `Memo` is the only one touched by `server/runner/memopayload`.

For context, the full set of packages importing `github.com/usememos/memos/store` outside the data layer is 10: `server`, `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`, `server/runner/s3presign`. Note that if you collapse `server/router/api/v1` and its `test` subpackage into one, the counts become User 6 / Memo 5 — the ranking is unchanged.
