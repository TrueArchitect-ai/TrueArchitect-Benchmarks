**Path:** each `Dispatch*Webhook` in `server/router/api/v1/memo_service_webhooks.go` loads the target user's webhooks via `s.Store.GetUserWebhooks`, builds a `WebhookRequestPayload` with `payload.URL = hook.Url` (the user-configured URL, set through `CreateUserWebhook`/`UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`), and calls `webhook.PostAsync` (`memo_service_webhooks.go:43`, `:71`). `PostAsync` only enqueues onto `asyncPostQueue`; four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain it.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. It is the single place the request is built and sent (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`), where HMAC signing headers are added and where the SSRF guard applies (`safeDialContext`, `internal/webhook/webhook.go:59`, rejecting reserved/private IPs at dial time).
