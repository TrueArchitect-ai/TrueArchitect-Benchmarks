**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-based markdown service `ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk). The result is written onto `memo.Payload.Tags` / `memo.Payload.Property` (`runner.go:85-86`) and persisted with the memo row.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is put on `update.Payload`. Other field updates (visibility, pinned, state, times) do not recompute it.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) walks every memo in batches of 100, rebuilds, and writes back the payload. (Note: this runner is defined but not currently wired into `server/server.go`, which only starts the s3presign runner at line 163.)

**Extracted properties:** from one AST walk of the memo content —
- `Tags` — all `#tag` nodes (excluding tags inside links/images), deduplicated, case preserved.
- `Property.Title` — text of the first block if it is an H1 heading.
- `Property.HasLink` — any link node.
- `Property.HasCode` — code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox; `Property.HasIncompleteTasks` — any unchecked checkbox.
- (`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` doesn't store them in the payload.)

These surface to clients via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`, plus `memoMessage.Tags` at line 48) and are consumed by filters (`internal/filter/schema.go`, `store/memo.go`) and user stats (`server/router/api/v1/user_service_stats.go:141`).

A second, non-persisted derived field for previews is `Memo.Snippet`: computed per response in `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76-80`) via `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`) → `GenerateSnippet(content, 64)` (`internal/markdown/markdown.go:264`), which flattens markdown to plain text (skipping code blocks) and truncates at a word boundary to 64 characters.
