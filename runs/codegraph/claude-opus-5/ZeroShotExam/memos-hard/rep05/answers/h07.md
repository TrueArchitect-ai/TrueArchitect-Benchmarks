Notes:
- The service is wired up in `server/server.go:81-82`, registered before the gRPC-gateway.
- `Store.GetUser` only short-circuits on its user cache when looked up by ID; this path looks up by username, so it always goes through `ListUsers` to the DB driver (the result is then cached by ID at store/user.go:143,167).
- Avatars are stored as base64 data URIs in the `user.avatar_url` column — not on disk or S3 — so the data layer here is the user table, not the attachment/file storage used by `serveAttachmentFile`.
