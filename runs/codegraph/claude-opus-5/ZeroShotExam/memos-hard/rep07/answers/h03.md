h03.
`internal/idp`; `internal/idp/oauth2`

- **Abstraction package:** `internal/idp` (`/bench/home/work/internal/idp/idp.go`) — package `idp` defines the shared `IdentityProviderUserInfo` type (Identifier, DisplayName, Email, AvatarURL) that any provider implementation returns.
- **Implementation package:** `internal/idp/oauth2` (`/bench/home/work/internal/idp/oauth2/oauth2.go`) — "Package oauth2 implements the OAuth2 identity provider integration", providing `IdentityProvider` with `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with PKCE support), and user-info retrieval. It is the only concrete protocol implementation under `internal/idp/`.

Wiring: `server/router/api/v1/auth_service_sso.go` and `server/router/api/v1/idp_service.go` construct the OAuth2 provider from stored config (`store/idp.go`, `proto/gen/store/idp.pb.go` — `IdentityProviderConfig` carries an `OAuth2Config`).
