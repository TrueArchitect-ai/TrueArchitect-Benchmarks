**Computation site; triggers; extracted properties**

**Computation site**

- `RebuildMemoPayload(ctx, memo, markdownService)` — `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags` and `memo.Payload.Property` (stored as `storepb.MemoPayload` in the memo row).
- The actual extraction is `(*service).ExtractAll` — `internal/markdown/markdown.go:356`, a single goldmark AST walk (the same logic exists standalone in `ExtractProperties`, `internal/markdown/markdown.go:193`).
- On the read path the stored property is surfaced by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`) into `Memo.Property`.

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (before the store insert).
- `UpdateMemo`, only when the update mask contains `content` — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`).
- Bulk backfill: `Runner.RunOnce` — `server/runner/memopayload/runner.go:27` walks all memos in batches of 100, rebuilds each payload and persists it via `Store.UpdateMemo`. Note: I found no call site for `memopayload.NewRunner`/`RunOnce` anywhere in the Go sources, so this batch rebuild is currently only invocable programmatically, not wired into server startup.

**Extracted properties**

From `ExtractedData` (`internal/markdown/markdown.go:20`), `RebuildMemoPayload` keeps two fields:

- `Tags` — every `#tag` node, deduplicated preserving case (`Mentions` is also extracted in the same pass but is *not* stored on the payload).
- `Property` (`MemoPayload_Property`, mirrored to `Memo_Property`):
  - `Title` — text of the first block-level child of the document if it is an H1 heading (`markdown.go:384-389`).
  - `HasLink` — any `KindLink` node.
  - `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
  - `HasTaskList` — any `east.KindTaskCheckBox`.
  - `HasIncompleteTasks` — a task checkbox with `IsChecked == false`.

Related but distinct: the `Memo.snippet` used for previews/relation cards is **not** stored — it is generated per response at convert time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`, called from `memo_service_converter.go:76` and `:225`/`:248`), which calls `MarkdownService.GenerateSnippet(content, 64)` (`internal/markdown/markdown.go:264`) to render plain text with code blocks skipped, truncated at a word boundary.
