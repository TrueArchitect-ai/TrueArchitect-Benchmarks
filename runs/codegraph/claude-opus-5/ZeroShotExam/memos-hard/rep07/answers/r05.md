**Premise correction:** There is no GraphQL schema in this repository. A repo-wide search for `graphql` (Go, TS/TSX, proto, JSON, Markdown) returns zero matches. The public API is not GraphQL — it is **Protobuf/gRPC-defined**, exposed over Connect-RPC, gRPC-Gateway REST, and MCP.

**Actual API surface — where it's defined**

The single source of truth is the `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — `MemoService` (memos, comments, reactions, relations, attachments, shares, link metadata)
- `proto/api/v1/user_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`

Each RPC carries its own REST mapping via `google.api.http` annotations, e.g. `proto/api/v1/memo_service.proto:30` → `get: "/api/v1/memos"`, `:35` → `get: "/api/v1/{name=memos/*}"`. Internal storage-only messages live in `proto/store/*.proto` and are not part of the public API.

**Codegen** (`proto/buf.gen.yaml`) fans that one definition out to every surface:
- Go structs + gRPC + Connect + grpc-gateway stubs → `proto/gen/api/v1/`
- OpenAPI spec (via the gnostic plugin) → `proto/gen/openapi.yaml`, embedded into the binary by `proto/openapi_embed.go`
- TypeScript client types → `web/src/types/proto/`

**Runtime wiring**
- REST (`/api/v1/...`): `server/router/api/v1/v1.go:65` — `RegisterGateway` builds a grpc-gateway mux with an auth middleware and registers each service handler.
- Connect-RPC (`/memos.api.v1.<Service>/<Method>`): `server/router/api/v1/connect_handler.go:31` — `RegisterConnectHandlers`. This is what the web client uses (`web/src/connect.ts`).
- MCP (`/mcp`): `server/router/mcp/service.go:26,108` — parses the embedded `openapi.yaml` and turns a curated subset of operations into MCP tools (`server/router/mcp/catalog.go`).
- Non-proto HTTP extras: file serving at `/file/...` (`server/router/fileserver/fileserver.go:121`) and RSS (`server/router/rss/`).

So: to change the public API, edit the `.proto` files in `proto/api/v1/` and run `buf generate` (`proto/README.md`).
