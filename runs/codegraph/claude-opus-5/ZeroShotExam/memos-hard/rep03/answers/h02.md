**Delivery function — `Post` in `internal/webhook/webhook.go:120`; protection mechanism — dial-time reserved-IP blocking via `safeDialContext`/`isReservedIP` in `internal/webhook/webhook.go:59` + `internal/webhook/validate.go:44`, plus admission-time `webhook.ValidateURL` (`internal/webhook/validate.go:62`).**

How it fits together:

**Where delivery executes**
- Memo create/update/delete/comment events call `DispatchMemo*Webhook` → `dispatchMemoRelatedWebhook`, which loads the creator's webhooks and calls `webhook.PostAsync(payload)` (`server/router/api/v1/memo_service_webhooks.go:15-74`).
- `PostAsync` (`internal/webhook/webhook.go:184`) is non-blocking: it enqueues onto a buffered channel `asyncPostQueue` (cap 128), dropping with a warning if full.
- Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`.
- `Post` (`internal/webhook/webhook.go:120-180`) is where the actual HTTP call happens: it marshals the payload, optionally adds Standard Webhooks HMAC headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`), and issues `safeClient.Do(req)` at `internal/webhook/webhook.go:152`, then reads a capped 1 MiB response body.

**What protects against internal targets**
1. **At dial time (the real defense).** `safeClient` is an `http.Client` whose `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59-77`) splits host/port, resolves the host itself, and refuses to connect if *any* resolved address is reserved — so it also covers redirects and DNS-rebinding, which a URL-only check cannot.
2. **At admission time.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is applied when a user creates/updates a webhook (`server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`): it requires an absolute `http`/`https` URL and rejects hostnames resolving into reserved ranges — a friendly gRPC `InvalidArgument` rather than a silent later failure.
3. **The blocklist itself.** `reservedCIDRs` / `isReservedIP` (`internal/webhook/validate.go:14-54`) covers IPv4 loopback, RFC-1918 ranges, link-local incl. cloud IMDS `169.254.0.0/16`, and IPv6 `::1/128`, `fc00::/7`, `fe80::/10`.

**One caveat worth flagging:** the escape hatch `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` and thus disables both layers, but grep shows it is never assigned outside the package or its tests — there is no flag/env wiring for it, so self-hosters can't currently opt in without a code change.
