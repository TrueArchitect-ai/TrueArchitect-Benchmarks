   Since no other file in the repo imports `github.com/usememos/memos/store/db/mysql`, no external package can construct it even in principle. CodeGraph's blast-radius agrees: `NewDB (store/db/mysql/mysql.go:20) — 1 caller in store/db/db.go`.
