**Premise correction:** There is no GraphQL in this repository. A case-insensitive search for `graphql` across all Go, TypeScript, JSON, and YAML sources returns zero hits — no schema files, no resolvers, no GraphQL server dependency. The public API is defined in **Protocol Buffers**, not GraphQL.

## Actual API surface

**Source of truth: `proto/api/v1/*.proto`**

The public API is a set of proto3 service definitions in `proto/api/v1/`:

- `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`
- Store-internal (non-public) protos live separately in `proto/store/`

Each RPC carries a `google.api.http` annotation that pins its REST shape. For example, in `proto/api/v1/memo_service.proto:20-33`:

```proto
rpc CreateMemo(CreateMemoRequest) returns (Memo) {
  option (google.api.http) = { post: "/api/v1/memos" body: "memo" };
}
rpc ListMemos(ListMemosRequest) returns (ListMemosResponse) {
  option (google.api.http) = {get: "/api/v1/memos"};
}
```

**Code generation: `proto/buf.gen.yaml`**

`buf generate` fans the protos out to five targets:

| Plugin | Output |
|---|---|
| `protocolbuffers/go` | `proto/gen/api/v1/*.pb.go` — Go message types |
| `grpc/go` | `proto/gen/api/v1/*_grpc.pb.go` |
| `connectrpc/go` | `proto/gen/api/v1/apiv1connect/*.connect.go` |
| `grpc-ecosystem/gateway` | REST gateway bindings |
| `community/google-gnostic-openapi` | `proto/gen/openapi.yaml` |
| `bufbuild/es` | `web/src/types/proto/` — TypeScript client types |

**Runtime wiring**

- Handlers are registered as **Connect RPC** services in `server/router/api/v1/connect_handler.go:31-48` (`RegisterConnectHandlers`), covering Instance, Auth, User, Memo, Attachment, AI, Shortcut, and IdentityProvider.
- Business logic implementations sit alongside in `server/router/api/v1/` (`memo_service.go`, `user_service.go`, etc.), with `connect_services.go` binding them to the generated interfaces.
- Non-proto HTTP surfaces exist under `server/router/`: `fileserver/`, `rss/`, `frontend/`.

**Derived OpenAPI spec**

The generated `proto/gen/openapi.yaml` is embedded into the binary via `proto/openapi_embed.go:5-11` (`//go:embed gen/openapi.yaml`), and consumed by the MCP server at `server/router/mcp/openapi.go` (`loadOpenAPISpec`, `buildOperationRegistry`) to derive MCP tool schemas. So the closest thing to a "schema for the public API" is this OpenAPI document — but it is a generated artifact, not hand-authored. Edit the `.proto` files and re-run `buf generate` (see `proto/README.md`).
