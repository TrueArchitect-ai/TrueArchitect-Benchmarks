The browser never fetches a separate blob file — an avatar is a base64 data URI stored in the `user.avatar_url` column, and the API rewrites it to a `/file/...` URL so responses stay small.

2. `UserAvatar` (browser `<img src={avatarUrl}>`) — web/src/components/UserAvatar.tsx:14
3. `RegisterRoutes` — route `GET /file/users/:identifier/avatar` — server/router/fileserver/fileserver.go:121-125 (wired in server/server.go:81)
4. `serveUserAvatar` (the serving handler) — server/router/fileserver/fileserver.go:168
