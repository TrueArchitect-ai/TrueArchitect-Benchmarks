**Premise correction:** There is no GraphQL anywhere in this repository. A case-insensitive grep for `graphql` across the whole tree (Go, TS/TSX, JSON, YAML, Markdown, proto) returns zero hits. There is no schema file, no resolver layer, and no GraphQL dependency in `go.mod` or `web/package.json`.

**Actual API surface — Protobuf/gRPC is the single source of truth**

The public API is defined as Protocol Buffers service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, plus `common.proto`
- `proto/api/v1/README.md` states the design follows the [Google AIPs](https://google.aip.dev/); REST paths come from `google.api.http` annotations on each RPC (e.g. `proto/api/v1/memo_service.proto:30` → `get: "/api/v1/memos"`)

**Code generation** is driven by `proto/buf.gen.yaml` (buf v2), emitting:

| Output | Destination |
|---|---|
| Go message/gRPC/Connect stubs | `proto/gen/api/v1/`, `proto/gen/api/v1/apiv1connect/` |
| grpc-gateway REST shims | `proto/gen/api/v1/*.pb.gw.go` |
| OpenAPI 3.0 spec (gnostic) | `proto/gen/openapi.yaml` |
| TypeScript client types | `web/src/types/proto/` |

**How it's served** — `server/router/api/v1/v1.go:65` (`APIV1Service.RegisterGateway`) wires three protocols onto one Echo server:

- **REST/JSON** via grpc-gateway at `/api/v1/*` and `/file/*` (`v1.go:128-129`)
- **Connect RPC** (browser clients, replaced grpc-web) at `/memos.api.v1.*` (`v1.go:144`, handlers in `server/router/api/v1/connect_handler.go:31`)
- **SSE** at `/api/v1/sse` (`server/router/api/v1/sse_handler.go:25`)

Service implementations live in `server/router/api/v1/*_service.go`, shared by both the gateway and Connect paths.

**Adjacent non-proto surfaces:**
- `proto/gen/openapi.yaml` is the generated (not hand-written) OpenAPI doc, embedded via `proto/openapi_embed.go`
- `server/router/mcp/` serves an MCP endpoint at `/mcp`, deriving its toolset from that embedded OpenAPI spec and dispatching in-process to `/api/v1/...` (`server/router/mcp/README.md`)
- `server/router/rss/rss.go` (RSS feeds) and `server/router/fileserver/fileserver.go` (attachments/avatars/thumbnails) are hand-written Echo routes outside the proto surface

If you want to change or extend the public API, edit the `.proto` files in `proto/api/v1/` and run `buf generate` from `proto/`.
