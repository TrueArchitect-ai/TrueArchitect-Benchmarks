**delivery function — `Post` in `internal/webhook/webhook.go:120`** (with `PostAsync`, `internal/webhook/webhook.go:184`, enqueueing onto a bounded 128-slot channel drained by 4 worker goroutines started in `init`, `internal/webhook/webhook.go:42`); **protection mechanism — `safeDialContext` in `internal/webhook/webhook.go:59`, backed by `isReservedIP`/`reservedCIDRs` in `internal/webhook/validate.go:14-54`.**

How it fits together:

- Triggers: `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go:30-74` load the creator's webhooks from the store, build a `WebhookRequestPayload` per hook, and call `webhook.PostAsync`.
- Actual outbound HTTP: `Post` marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id` / `webhook-timestamp` / `webhook-signature`), and issues the request via the shared `safeClient` (`internal/webhook/webhook.go:32-37`, 30s timeout, response body capped at 1 MiB by `io.LimitReader`).
- Dial-time SSRF guard: `safeClient`'s `http.Transport.DialContext` is `safeDialContext`, which splits host/port, resolves the host with `net.DefaultResolver.LookupHost`, and refuses the connection if *any* resolved IP is reserved. Because this happens at dial time rather than at save time, it also defeats DNS rebinding (a hostname that validated as public at creation and later flips to 127.0.0.1 is blocked on the dial).
- Second, earlier layer: `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is called when webhooks are created/updated — `server/router/api/v1/user_service_webhooks.go:74,161,182` — enforcing absolute URL, http/https scheme only, and no resolution into a reserved range. This is defense-in-depth/UX; the dial-time check is the one that actually protects delivery.
- Blocked ranges (`internal/webhook/validate.go:14-23`): 127.0.0.0/8, 10/8, 172.16/12, 192.168/16, 169.254/16 (cloud IMDS), ::1/128, fc00::/7, fe80::/10.
- Escape hatch: the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) short-circuits `isReservedIP`, disabling both layers for self-hosted deployments. Note it is declared but never assigned anywhere in the repo outside tests — no CLI flag, env var, or profile field wires it up — so in practice it is always `false`.
