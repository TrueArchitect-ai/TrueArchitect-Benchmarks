**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across all Go, TypeScript, JSON, proto, and YAML sources returns zero matches. Memos has never had a GraphQL API.

**Actual API surface — Protocol Buffers (gRPC) as the single source of truth**

The public API is defined in **`proto/api/v1/*.proto`**, with eight services:

| Service | File |
|---|---|
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `AIService` | `proto/api/v1/ai_service.proto:11` |

Shared messages live in `proto/api/v1/common.proto`.

**Three wire protocols, all generated from those protos** (codegen config: `proto/buf.gen.yaml`):

1. **REST/JSON** — each RPC carries a `google.api.http` annotation defining its path, e.g. `post: "/api/v1/memos"`, `get: "/api/v1/{name=memos/*}"` (`proto/api/v1/memo_service.proto:22-49`). Served by grpc-gateway (`*.pb.gw.go` files) mounted at `/api/v1/*` in `server/router/api/v1/v1.go:128`.
2. **gRPC** — `*_grpc.pb.go`, service names like `/memos.api.v1.AIService/Transcribe`.
3. **Connect RPC** — handlers in `proto/gen/api/v1/apiv1connect`, registered in `server/router/api/v1/connect_handler.go:31-50`.

**Schema documents that do exist** (both generated, not hand-written):
- **OpenAPI/Swagger** — `proto/gen/openapi.yaml`, produced by the gnostic-openapi buf plugin and embedded into the binary via `proto/openapi_embed.go`.
- **JSON Schema** — hand-built for the MCP tool surface in `server/router/mcp/openapi.go` (`jsonSchema`, `okSchema`), which exposes API operations as MCP tools.

TypeScript client types are generated from the same protos into `web/src/types/proto` (see the `bufbuild/es` plugin in `proto/buf.gen.yaml`).
