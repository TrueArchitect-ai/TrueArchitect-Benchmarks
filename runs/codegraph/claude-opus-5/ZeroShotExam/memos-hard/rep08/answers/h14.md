**Computation site;** **triggers;** **extracted properties**

**Computation site**
- `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` — the single entry point. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:85-86).
- The actual extraction lives in `internal/markdown/markdown.go:356` (`(*service).ExtractAll`) — one goldmark parse + single `gast.Walk` over the AST. A standalone `ExtractProperties` (markdown.go:193) does the same property walk without tags/mentions.
- Storage shape: `MemoPayload.Property` in `proto/store/memo.proto:15-22`; exposed to the API as `Memo.Property` (OUTPUT_ONLY, `proto/api/v1/memo_service.proto:256`) via `convertMemoPropertyFromStore` in `server/router/api/v1/memo_service_converter.go:315`.

**Triggers (recomputation)**
- **CreateMemo** — `server/router/api/v1/memo_service.go:108`, before the store write.
- **UpdateMemo** — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the result is written through `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, …) do not recompute.
- **Batch backfill** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds payloads for all memos in batches of 100 and persists each via `Store.UpdateMemo`. Note: `memopayload.NewRunner` has no caller in the repo today (grep for `memopayload` only hits `memo_service.go` and the runner itself), so this path is currently unwired — unlike e.g. `s3presignRunner.RunOnce` at `server/server.go:163`.

**Extracted properties** (markdown.go:383-408)
- `Title` — plain text of the first block-level child of the document only if it's an H1 heading (`extractHeadingText`, markdown.go:173).
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any `east.KindTaskCheckBox` node.
- `HasIncompleteTasks` — a task checkbox with `IsChecked == false`.
- Alongside these, the same pass fills `Payload.Tags` (deduped, case preserved) and `Mentions` (lowercased; used by `server/router/api/v1/memo_mention_helpers.go:32`, not stored in the payload).

Related but distinct: `Memo.Snippet` is derived from content too, but at response-conversion time rather than being stored — `getMemoContentSnippet` in `server/router/api/v1/memo_service_converter.go:76` and `:225`. The stored booleans are what backs list filtering (`web/src/hooks/useMemoFilters.ts:73-77`, `web/src/components/MemoFilters.tsx:45-53`) and the `property.has*` filter factors in `internal/filter/schema.go`.
