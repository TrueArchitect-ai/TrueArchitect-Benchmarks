No caching decorator intercepts memos — `Store`'s caches are only for instance settings, users, and user settings (`store/store.go:26-28`), so the driver call is unconditional.

2. **Where the field is populated.** `store.New(dbDriver, instanceProfile)` in `cmd/memos/main.go:64` — the value comes from `db.NewDBDriver(instanceProfile)` at `cmd/memos/main.go:57`. That's the single production construction site.

3. **The switch.** `NewDBDriver` selects on `profile.Driver` (`store/db/db.go:18-27`): `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`, anything else → error. So the string decides it.

4. **The default string.** `Profile.Driver` is `viper.GetString("driver")` (`cmd/memos/main.go:43`), and with no flag, env var, or config file the value is `"sqlite"` — set in two places that agree: `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the persistent flag default `rootCmd.PersistentFlags().String("driver", "sqlite", ...)` bound via `viper.BindPFlag` (`cmd/memos/main.go:130,151`).
