**Premise correction:** there is no GraphQL schema in this repository. A case-insensitive grep for `graphql` across the whole tree (excluding `node_modules`/`.git`) returns zero hits — no `.graphql`/`.gql` files, no schema builder, no GraphQL server or client dependency. The public API is **Protobuf-defined, served over Connect/gRPC + a REST/JSON gateway**.

**Actual API surface**

1. **Source of truth — Protobuf service definitions:** `proto/api/v1/*.proto`
   - `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`
   - Design conventions documented in `proto/api/v1/README.md` (follows Google AIPs).

2. **Codegen:** `proto/buf.gen.yaml` (buf v2) runs plugins for Go protobuf, gRPC, **connect-go**, **grpc-gateway**, **gnostic-openapi**, and **protobuf-es** (TS). Outputs land in `proto/gen/api/...` (Go) and `web/src/types/proto` (TypeScript client types). Regenerate with `buf generate` from `proto/` (`proto/README.md`).

3. **Server implementation:** `server/router/api/v1/` — the gRPC service impls (`memo_service.go`, `auth_service.go`, …) are wrapped for Connect by `server/router/api/v1/connect_handler.go` (`RegisterConnectHandlers`) and `connect_services.go`. Cross-cutting auth/ACL live in `authz.go`, `acl_config.go`, `connect_interceptors.go`.

4. **The closest thing to a "schema document" for the public API:** the generated OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml` (4057 lines, generated by protoc-gen-openapi; REST paths like `/api/v1/memos`, `/api/v1/ai:transcribe`). It is embedded into the binary via `proto/openapi_embed.go` (`proto.OpenAPIYAML()`).

5. **Downstream consumer of that spec:** the MCP endpoint at `/mcp` — `server/router/mcp/service.go` parses the embedded OpenAPI (`loadMCPServiceOpenAPISpec`), `server/router/mcp/openapi.go` builds an operation registry and resolves JSON Schemas, and `server/router/mcp/catalog.go` exposes a curated allowlist of operations (`curatedOperationIDs`) as MCP tools.
