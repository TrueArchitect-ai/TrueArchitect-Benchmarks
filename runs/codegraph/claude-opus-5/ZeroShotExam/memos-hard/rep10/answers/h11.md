**1st: `store.User` — referenced from ~7 packages outside the store layer; 2nd: `store.Memo` — ~6 packages.**

The data layer is the Go `store` package (`/bench/home/work/store`), whose persistent entity types are `User`, `Memo`, `Attachment`, `MemoRelation`, `MemoShare`, `Inbox`, `Reaction`, `UserIdentity`, `UserSetting`, `InstanceSetting`, `IdentityProvider` (each defined in its own file, e.g. `store/user.go`, `store/memo.go`, `store/attachment.go`).

Counting distinct Go packages *outside* the `store/` tree (i.e. excluding `store/db/{sqlite,postgres,mysql}` and `store/test`, which are part of the data layer itself) that reference each type:

**1. `store.User` — 7 packages, ~36 reference sites**
- `server/auth` — `server/auth/authenticator.go`, `server/auth/context.go`
- `server/notification` — `server/notification/email.go`
- `server/router/api/v1` — many, e.g. `user_service.go`, `memo_service_converter.go`, `auth_service_sso.go`, `memo_mention_helpers.go`
- `server/router/api/v1/test` — e.g. `test/test_helper.go`
- `server/router/fileserver` — `server/router/fileserver/fileserver.go`
- `server/router/frontend` — `server/router/frontend/frontend_test.go`
- `server/router/rss` — `server/router/rss/rss.go`

**2. `store.Memo` — 6 packages, ~31 reference sites**
- `server/router/api/v1` (`memo_service.go`, `memo_service_converter.go`, `memo_update_helpers.go`, …), `server/router/api/v1/test`, `server/notification` (`email.go`), `server/router/frontend`, `server/router/rss` (`rss.go`), `server/runner/memopayload` (`runner.go`)

Runner-up for reference: `store.Attachment` at 4 external packages (`server/router/api/v1`, `.../api/v1/test`, `server/router/fileserver`, `server/router/rss`). `UserSetting`, `InstanceSetting`, and `IdentityProvider` are effectively confined to the store layer plus their generated proto counterparts in `proto/gen/store`.
