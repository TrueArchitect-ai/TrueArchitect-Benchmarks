**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation must produce.
- **Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol implementation that ships. It provides `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (authorization-code exchange with optional PKCE `code_verifier`, via `golang.org/x/oauth2`), and `UserInfo` (bearer-token call to `UserInfoUrl`, claims mapped through `FieldMapping` into `idp.IdentityProviderUserInfo`).

Wiring: `server/router/api/v1/auth_service_sso.go` calls `oauth2.NewIdentityProvider` (6 call sites) to resolve SSO identities; tests live in `internal/idp/oauth2/oauth2_test.go`.
