**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual analysis to the goldmark markdown service — `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk; the equivalent standalone `ExtractProperties` lives at `internal/markdown/markdown.go:193`). The result is stored on the memo's `Payload` (`storepb.MemoPayload.Tags` + `MemoPayload_Property`, `proto/gen/store/memo.pb.go:24,85`) and surfaced to the API by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`) into `Memo.Property`/`Memo.Tags` (`server/router/api/v1/memo_service_converter.go:47-50`).

**Triggers (recomputation happens only when content is written):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only inside the `path == "content"` branch of the update mask; the payload is then attached via `update.Payload = memo.Payload` (line 451). Other mask paths (`visibility`, `pinned`, `location`, `attachments`, `relations`, timestamps) do not recompute it — the `location` branch reuses the existing payload and only swaps `Payload.Location` (lines 481-484).
- A batch backfill runner `(*Runner).RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds the payload for all memos in batches of 100 and persists each via `UpdateMemo`. Note this runner is currently not wired into startup — `memopayload.NewRunner` has no caller anywhere in the repo (only `s3presign` is started in `server/server.go:163`), so in practice only create/content-update recompute.

**Extracted properties** (`internal/markdown/markdown.go:376-408`):
- `Tags` — text of every memo tag node, deduplicated preserving original case (`uniquePreserveCase`).
- `Property.Title` — text of the document's first block-level child if it is an H1 heading (`extractHeadingText`).
- `Property.HasLink` — true if any `gast.KindLink` node exists.
- `Property.HasCode` — true for any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — true if any task checkbox node exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
- (`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property`; mentions are used separately in `server/router/api/v1/memo_mention_helpers.go:32`.)

Note on previews: the API's `Memo.Snippet` is *not* part of this stored payload — it's generated per-response by `getMemoContentSnippet` → `GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`, `internal/markdown/markdown.go:264`), applied in `server/router/api/v1/memo_service_converter.go:76-80`.
