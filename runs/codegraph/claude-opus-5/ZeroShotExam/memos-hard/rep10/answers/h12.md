3. **Call chain to the interface.** Saving a memo goes `APIV1Service.CreateMemo` → `s.Store.CreateMemo` (`server/router/api/v1/memo_service.go:115`) → `store/memo.go:113`, which does a UID validity check and then delegates straight to `s.driver.CreateMemo(ctx, create)` — no other write path and no decorator/caching wrapper around the driver (the caches in `store/store.go` cover instance settings, users and user settings only).
4. **Ruled out compile-time variation.** `grep '//go:build'` over `store/db/` returns nothing, so there are no build-tag variants swapping implementations; all three are compiled in and the selection is purely the runtime `switch`.
