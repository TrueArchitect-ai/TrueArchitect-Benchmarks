**Mechanism: by explicit Go code, inside the `DeleteUser` transaction — not by any database-level rule.**

## What happens

`deleteUserTargetsTx` issues two separate `DELETE FROM reaction` statements, covering both directions of the relationship:

1. **Reactions *on* the deleted user's memos** (left by anyone) — `deleteReactionsByContentIDsTx`, keyed by the memo `content_id`s (`uid`s) collected from the user's memo tree.
2. **Reactions *by* the deleted user** (on anyone's memos) — `deleteReactionsByCreatorTx`, `DELETE FROM reaction WHERE creator_id = ?`.

Both run before the memo and user rows are deleted, in the same transaction.

## Evidence

**Explicit Go code** — identical logic replicated per dialect:
- `store/db/sqlite/user_delete.go:96` and `:102` (the two calls in `deleteUserTargetsTx`); SQL bodies at `:380-388` (`deleteReactionsByContentIDsTx`) and `:400-403` (`deleteReactionsByCreatorTx`)
- `store/db/postgres/user_delete.go:96,102` — same structure
- `store/db/mysql/user_delete.go:96,102` — same structure
- Entry points: `store/user.go:171` (`Store.DeleteUser` → driver) ← `server/router/api/v1/user_service.go:414`

**No database-level rule** — the `reaction` table has *no* foreign keys at all in any dialect:
- `store/migration/sqlite/LATEST.sql:92-99`, `store/migration/postgres/LATEST.sql:91-98`, `store/migration/mysql/LATEST.sql:91-98` — columns `creator_id` / `content_id` are plain `INTEGER`/`TEXT` with only a `UNIQUE(creator_id, content_id, reaction_type)` constraint
- Original creation migration `store/migration/sqlite/0.20/00__reaction.sql` — no FK either; `store/migration/*/0.23/00__reactions.sql` only rewrites `reaction_type` values to emoji
- A repo-wide grep for `FOREIGN KEY` / `ON DELETE` across `store/migration/` returns hits only for `memo_share`, `user_setting`, `memo_resource`, etc. — never `reaction`. (Note `content_id` is a memo *uid* string, so an FK cascade from `memo` wouldn't apply here anyway.)

**Test coverage:** `store/test/user_delete_test.go` exercises this — it creates reactions by the deleted user and a peer's reaction on a peer memo (`:97-112`), then asserts the peer's unrelated reaction survives while the rest are gone (`:217-220`).
