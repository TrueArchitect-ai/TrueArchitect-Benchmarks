**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which delegates the actual parse to the goldmark-based markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356-421`. Rebuild writes the results onto `memo.Payload.Tags` and `memo.Payload.Property` (`storepb.MemoPayload`, defined in `proto/store/memo.proto`), so the derived data is persisted alongside the memo rather than recomputed on read.

**Triggers** (the only three callers):
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, run on the `store.Memo` before insert (so comments and any other memo created through this RPC included).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the recomputed payload is then written via `update.Payload = memo.Payload` (`:451`). Updates that touch only visibility/pinned/state/timestamps do not recompute.
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27-72`, a batch backfill that walks all memos in pages of 100 and re-persists each payload. Note: nothing currently constructs this runner — `NewRunner` has no callers in the repo, so it is effectively a dormant migration/backfill path.

**Extracted properties** — one AST walk over the parsed content yields:
- `Tags` — every `#tag` node (memo tag extension), deduplicated with original case preserved via `uniquePreserveCase`.
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (`markdown.go:383-389`).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any GFM task checkbox; and `Property.HasIncompleteTasks` when at least one checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` discards that field — it isn't part of the stored payload.)

Consumers: `convertMemoFromStore` copies these to the API message (`server/router/api/v1/memo_service_converter.go:48-49`, `convertMemoPropertyFromStore` at `:315`), and user stats aggregate them (`server/router/api/v1/user_service_stats.go:138-151`). The list/preview `snippet` is a separate, non-persisted value generated per-request by `GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`).
