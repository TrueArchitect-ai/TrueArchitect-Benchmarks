**Path shape:**
- The three `Dispatch*Webhook` wrappers and `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15-73`) load the target user's webhooks with `s.Store.GetUserWebhooks`, copy `hook.Url` / `hook.SigningSecret` into a `WebhookRequestPayload`, and call `webhook.PostAsync` (`internal/webhook/webhook.go:184`).
- `PostAsync` only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) call `Post`, which builds the request, adds the Standard Webhooks HMAC headers, and issues it through `safeClient`. So `PostAsync` is the common enqueue funnel, but `Post` is the single function where every path converges before actual delivery.

The URL is user-configured through `CreateUserWebhook` / `UpdateUserWebhook` (`server/router/api/v1/user_service_webhooks.go:53`, `:106`), which validate it with `webhook.ValidateURL` (`internal/webhook/validate.go`); `safeDialContext` (`internal/webhook/webhook.go:59`) blocks reserved/private IPs at dial time as an SSRF guard.
