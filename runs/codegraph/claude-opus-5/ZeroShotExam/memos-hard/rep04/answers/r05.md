**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for "graphql" across the entire tree (excluding `.git`/`node_modules`) returns zero matches — no `.graphql`/`.gql` files, no schema-definition code, no GraphQL server or client dependency. The public API is **Protobuf/gRPC-first**, exposed over HTTP as REST (gRPC-Gateway) and Connect RPC.

**Actual API surface:**

1. **Source of truth — Protobuf service definitions** in `proto/api/v1/` (package `memos.api.v1`):
   - `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`.
   - REST mapping lives inline as `google.api.http` annotations, e.g. `proto/api/v1/memo_service.proto:22-25` (`post: "/api/v1/memos"`), `:35` (`get: "/api/v1/{name=memos/*}"`).
   - Store-layer protos are separate, in `proto/store/`.

2. **Code generation** — `proto/buf.gen.yaml` runs `buf generate` with plugins for Go protobuf, gRPC, Connect, gRPC-Gateway, gnostic-OpenAPI, and `bufbuild/es` emitting TypeScript into `web/src/types/proto`. Outputs land in `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`. See `proto/README.md` for the workflow.

3. **Generated schema document** — the closest analogue to "the schema for the public API" is the OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml` (generated by protoc-gen-openapi, header at lines 1-8). It is embedded into the binary via `proto/openapi_embed.go` and consumed by the MCP server (`server/router/mcp/openapi.go`, `server/router/mcp/service.go`) to build tools from operations.

4. **Server wiring** — `server/router/api/v1/v1.go`: `APIV1Service` embeds the generated `Unimplemented*ServiceServer` types (lines 22-30) and `RegisterGateway` (line 65) mounts the gRPC-Gateway mux at `/api/v1/*` and `/file/*` (lines 128-129) plus Connect handlers at `/memos.api.v1.*` (line 144). There is also an SSE endpoint registered at line 125.
