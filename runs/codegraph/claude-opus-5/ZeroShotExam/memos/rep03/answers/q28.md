**Runners the server actually starts**

- **s3presign runner (`RunOnce`, one-shot at startup)** — called synchronously from `Server.startBackgroundRunners`, so it runs once immediately on `Server.Start` (`server/server.go:162-163`, `server/runner/s3presign/runner.go:43`).
- **s3presign runner (`Run`, continuous)** — `time.NewTicker` on the package constant `runnerInterval = 12h`; loops until its own `context.CancelFunc` (stored in `backgroundRunnerCancels`) fires on shutdown (`server/server.go:156-171`, `server/runner/s3presign/runner.go:27-41`). This is the *only* thing registered on `backgroundRunnerWG` / the cancel list.
- **HTTP serve goroutine** — started in `Server.Start`; driven by incoming connections, stopped by `httpServer.Shutdown` (`server/server.go:124-128`).
- **Cache cleanup loops (3, one per store cache)** — started implicitly by `cache.New` inside `store.New`; `time.NewTicker(CleanupInterval)` with `CleanupInterval = 5m`, stopped via `stopChan` when `Store.Close` closes the caches (`store/cache/cache.go:76-84,199-215`, `store/store.go:40-53,74-78`).
- **Async email workers (2)** — `func init()` in `internal/email/email.go:15-18`; not time-driven, they block on the `asyncEmailQueue` channel (buffer 128).
- **Async webhook dispatch workers (4)** — `func init()` in `internal/webhook/webhook.go:41-44`; drain `asyncPostQueue` (buffer 128), event-driven only.
- **Per-connection SSE heartbeat** — created per request in `handleSSE`, `time.NewTicker(sseHeartbeatInterval)` with `sseHeartbeatInterval = 30s`; lives for the request's lifetime (`server/router/api/v1/sse_handler.go:16-17,64`).
- **PAT last-used recorder** — fire-and-forget `go func()` per authenticated PAT request, no schedule (`server/auth/authenticator.go:180`).
- **Signal-handling goroutine** — `cmd/memos/main.go:99`, waits on OS signals to trigger `Server.Shutdown`.

**Unused scheduling infrastructure**

- `internal/scheduler/` — a full cron-style scheduler (`scheduler.go`, `job.go`, `parser.go` with `ParseCronExpression`, `middleware.go`) is present but **never imported by the server or any non-test code**. Its only importers are `internal/scheduler/example_test.go` and `internal/scheduler/integration_test.go`. The server hand-rolls its one periodic job with a `time.Ticker` instead.
- `server/runner/memopayload.Runner` — the type, `NewRunner`, and its batch `RunOnce` exist (`server/runner/memopayload/runner.go`) but are **never instantiated**; `startBackgroundRunners` doesn't reference the package. Only the free function `memopayload.RebuildMemoPayload` is used, called inline on memo create/update in `server/router/api/v1/memo_service.go:108,447`.
