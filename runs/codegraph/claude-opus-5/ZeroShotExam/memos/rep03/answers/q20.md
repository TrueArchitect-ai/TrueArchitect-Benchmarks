**Server-Sent Events (SSE) over `GET /api/v1/sse`; `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction (plus SetMemoRelations / SetMemoAttachments, which reach the hub via the shared `dispatchMemoUpdatedSideEffects` helper).**

Details:

**Mechanism** — HTTP SSE (`Content-Type: text/event-stream`), not WebSockets. The endpoint is registered by `RegisterSSERoutes` and served by `handleSSE` in `server/router/api/v1/sse_handler.go:25-110`: it authenticates a Bearer token, sets SSE headers (`no-cache`, `keep-alive`, `X-Accel-Buffering: no`), writes `: connected`, then streams `data: <json>\n\n` frames with a 30s `: heartbeat` comment. The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which reads the stream with `fetch` + a `ReadableStream` reader (so it can send an `Authorization` header) and invalidates React Query caches, reconnecting with exponential backoff.

**Hub** — `server/router/api/v1/sse_hub.go`. `SSEHub` (line 56) holds a mutex-guarded set of `*SSEClient`, each with a 32-slot buffered `chan []byte`. `Subscribe`/`Unsubscribe`/`Close` manage membership; `Broadcast` (line 115) marshals the event and does a non-blocking send per client, dropping events for slow clients. Delivery is filtered by `canReceive` (line 134) — private memos only go to the creator or an admin. Event types are `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted` (lines 14-21).

**Broadcast call sites** (all via `s.SSEHub.Broadcast`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `dispatchMemoUpdatedSideEffects` — `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`), the shared helper called by `UpdateMemo` (`memo_service.go:513`), `SetMemoRelations` (`memo_relation_service.go:48`), and `SetMemoAttachments` (`memo_attachment_service.go:48`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `DeleteMemoReaction` — `:161`, both building the event via `buildMemoReactionSSEEvent` in `server/router/api/v1/sse_event_helpers.go:24`

Note `memo_service.go:30-37`: a `withSuppressSSE` context flag lets internal call paths skip broadcasting.
