**Server-Sent Events (SSE) over HTTP; `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction (plus SetMemoAttachments and SetMemoRelations, which broadcast `memo.updated` via the shared `dispatchMemoUpdatedSideEffects` helper).**

Details:

- **Mechanism** — plain SSE (`text/event-stream`), not WebSockets. Endpoint `GET /api/v1/sse`, registered in `server/router/api/v1/v1.go:125` (`RegisterSSERoutes(gwGroup, s.SSEHub, s.Store, s.Secret)`). The connection handler `handleSSE` in `server/router/api/v1/sse_handler.go:34` authenticates via a Bearer token, sets `Content-Type: text/event-stream` / `X-Accel-Buffering: no`, sends `: connected`, then streams `data: <json>\n\n` frames with a 30s `: heartbeat` keepalive. The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which reads the stream with `fetch` + a reader (not `EventSource`, so it can send the auth header), reconnects with exponential backoff, and invalidates React Query caches per event type.

- **Hub** — `server/router/api/v1/sse_hub.go`: `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`), `NewSSEHub`, `Subscribe`/`Unsubscribe`/`Close`, and `Broadcast` (sse_hub.go:115), which marshals the event and does a non-blocking send to each client's 32-buffered channel, dropping events for slow clients. Delivery filtering is in `SSEClient.canReceive` (sse_hub.go:134): private-visibility events go only to the creator or an admin. Instantiated at `server/router/api/v1/v1.go:57`, held by the server at `server/server.go:38`/`:77` for shutdown.

- **Broadcast call sites (memo handlers):**
  - `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`)
  - `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
  - `UpdateMemo` — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` at `server/router/api/v1/memo_update_helpers.go:66-71` (`memo.updated`)
  - `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
  - `UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161`, via `buildMemoReactionSSEEvent` in `server/router/api/v1/sse_event_helpers.go`
  - Also through the same `dispatchMemoUpdatedSideEffects` helper: `SetMemoAttachments` (`memo_attachment_service.go:48`) and `SetMemoRelations` (`memo_relation_service.go:48`)
