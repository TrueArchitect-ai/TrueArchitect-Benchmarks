**Engine:** Google's **CEL** (Common Expression Language) via `github.com/google/cel-go`, wrapped by the in-repo filter package at **`internal/filter/`** (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`; design notes in `internal/filter/README.md`).

**Mechanism (one sentence):** `Engine.Compile` type-checks the CEL string against a memo-specific `cel.Env` built from `NewSchema()` (`internal/filter/schema.go:60`), `buildCondition` in `internal/filter/parser.go` normalizes the CEL AST into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), and `Program.Render` (`internal/filter/engine.go:96`) walks that IR with the dialect-aware renderer in `internal/filter/render.go` to emit a parameterized SQL fragment + args for `DialectSQLite` / `DialectMySQL` / `DialectPostgres`.

**Wiring:**
- `ListMemos` RPC takes `request.Filter`, validates it (`validateFilter`, `server/router/api/v1/shortcut_service.go:336`), and appends it to `memoFind.Filters` — `server/router/api/v1/memo_service.go:211-216`. Visibility scoping is itself injected as a CEL filter string (`memo_service.go:222`).
- Each store driver calls `filter.DefaultEngine()` then `filter.AppendConditions(...)` with its own dialect constant, which wraps each rendered fragment in parens and appends into the `WHERE` list and arg slice (`internal/filter/helpers.go:9`):
  - `store/db/sqlite/memo.go:57-63` → `filter.DialectSQLite`
  - `store/db/mysql/memo.go:65-71` → `filter.DialectMySQL`
  - `store/db/postgres/memo.go:54-58` → `filter.DialectPostgres`

**Dialect differences handled in `render.go`:** placeholders (`?` vs `$n`, with `PlaceholderOffset` so fragments compose with pre-existing args), JSON access (`json_extract` / `JSON_EXTRACT` / `->`/`->>`), tag membership (`LIKE` / `JSON_CONTAINS` / `@>`), `LIKE` vs `ILIKE`, regex (`REGEXP` vs `~`, with SQLite's `regexp` registered in `store/db/sqlite/functions.go`), and date-part extraction (`strftime` / `EXTRACT` / `YEAR()`). Time expressions (`now`, `duration(...)`, `timestamp(...)`) constant-fold to epoch seconds at compile time, with `now` frozen once per compile (`engine.go:20`, `engine.go:62`).
