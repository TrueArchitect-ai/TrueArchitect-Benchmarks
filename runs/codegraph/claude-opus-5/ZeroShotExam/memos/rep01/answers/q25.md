**Engine:** Google CEL (`github.com/google/cel-go`), wrapped by the in-repo filter engine at `internal/filter/` — `engine.go` (`Engine`, `Compile`, `CompileToStatement`, `DefaultEngine`), `schema.go` (field/dialect metadata + CEL env), `parser.go` (CEL AST → IR), `ir.go` (IR nodes), `render.go` (IR → SQL), `helpers.go` (`AppendConditions`).

**Mechanism (one sentence):** `Engine.Compile` type-checks the CEL expression against a memo-specific `cel.Env` declared in `internal/filter/schema.go`, `buildCondition` (`internal/filter/parser.go:62` call site in `engine.go`) normalizes the CEL AST into a dialect-agnostic condition tree (`internal/filter/ir.go`), and `renderer.Render` (`internal/filter/render.go:32`) walks that tree emitting a parameterized SQL fragment whose per-dialect differences (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`) come from `switch r.dialect` branches plus the `Expressions map[DialectName]string` on each schema field — placeholders `?` vs `$n`, `json_extract`/`JSON_CONTAINS`/`@>`, `LIKE`/`ILIKE`, `REGEXP`/`~`, etc.

**Wiring:**
- `ListMemos` validates the filter via `s.validateFilter` (`server/router/api/v1/shortcut_service.go:336`, which picks the dialect from `s.Profile.Driver`) and appends it to `memoFind.Filters` — `server/router/api/v1/memo_service.go:211-216`, plus a synthetic visibility filter at line 222.
- Each store driver then calls `filter.DefaultEngine()` + `filter.AppendConditions(ctx, engine, find.Filters, <dialect>, &where, &args)`, which wraps each rendered fragment in parens and appends its args to the `WHERE` clause: `store/db/sqlite/memo.go:57-63`, `store/db/mysql/memo.go:65-71`, `store/db/postgres/memo.go:54-60`.
- `RenderOptions.PlaceholderOffset` (`internal/filter/helpers.go:13`) keeps Postgres `$n` numbering aligned with pre-existing args; a trivially-true filter renders to `""` (skipped) and an unsatisfiable one to `1 = 0` (`internal/filter/render.go:42-58`).

Design notes and the supported surface (tags, timestamp accessors, `sets.*`, regex caveats) are documented in `internal/filter/README.md`.
