**Server-Sent Events (SSE) over `GET /api/v1/sse`; `server/router/api/v1/sse_hub.go`; `CreateMemo`, `UpdateMemo` (via `dispatchMemoUpdatedSideEffects`, also reached from `SetMemoAttachments` and `SetMemoRelations`), `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, `DeleteMemoReaction`**

Details:

**Mechanism** — plain HTTP SSE (`text/event-stream`), not WebSockets. The endpoint is registered in `server/router/api/v1/sse_handler.go:25` (`RegisterSSERoutes` → `GET /api/v1/sse`); `handleSSE` authenticates via `Authorization: Bearer`, sets `Cache-Control: no-cache`/`X-Accel-Buffering: no`, writes `data: %s\n\n` frames, and sends `: heartbeat` comments every 30s. The browser side is `web/src/hooks/useLiveMemoRefresh.ts` — it uses `fetch` + a `ReadableStream` reader (not `EventSource`, so it can send the bearer token), parses `data:` lines, and invalidates React Query caches, with exponential-backoff reconnect and a full resync on reconnect.

**Hub** — `server/router/api/v1/sse_hub.go`. `SSEHub` (line 56) holds a `map[*SSEClient]struct{}` under an `RWMutex`; `Subscribe`/`Unsubscribe`/`Close` manage clients, each with a 32-event buffered channel. `Broadcast` (line 115) marshals the event once and drops it for clients whose buffer is full rather than blocking. `canReceive` (line 134) filters private memos to the creator or an admin. The hub instance is held on the server at `server/server.go:38`/`:77`.

**Broadcasting handlers** (all on `APIV1Service`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `dispatchMemoUpdatedSideEffects` — `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`), called from `UpdateMemo` (`memo_service.go:513`), `SetMemoAttachments` (`memo_attachment_service.go:48`), and `SetMemoRelations` (`memo_relation_service.go:48`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106` (`reaction.upserted`)
- `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:161` (`reaction.deleted`)

The reaction events are built by `buildMemoReactionSSEEvent` in `server/router/api/v1/sse_event_helpers.go`.
