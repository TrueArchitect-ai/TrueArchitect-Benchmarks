**`memo_relation`**

Schema (`store/migration/sqlite/LATEST.sql:47-52`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Each row links a source memo (`memo_id`) to a related memo (`related_memo_id`) with a relation `type` (e.g. `REFERENCE`, `COMMENT`).
