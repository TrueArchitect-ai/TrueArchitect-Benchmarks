`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, `store/migrator.go` skips the incremental version directories and applies the full schema in one shot:

- `store/migrator.go:56` — `LatestSchemaFileName = "LATEST.sql"`
- `store/migrator.go:218` — builds `s.getMigrationBasePath() + LatestSchemaFileName`, where `getMigrationBasePath()` (`store/migrator.go:254`) resolves to `migration/<driver>/`, i.e. `migration/sqlite/` for the SQLite driver
- `store/migrator.go:42` — comment: "LATEST.sql: Full schema for new installations (faster than incremental migrations)"

The per-version files under `store/migration/sqlite/0.x/` are only for upgrading existing databases.
