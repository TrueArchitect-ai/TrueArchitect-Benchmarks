**Server-Sent Events (SSE) over `GET /api/v1/sse`; hub at `server/router/api/v1/sse_hub.go` (`SSEHub`); handlers: `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`, `UpsertMemoReaction`, `DeleteMemoReaction`.**

Details:

**Mechanism** — plain HTTP SSE (not WebSocket). The endpoint is registered in `server/router/api/v1/sse_handler.go:25` (`RegisterSSERoutes`) and served by `handleSSE`, which sets `Content-Type: text/event-stream`, `X-Accel-Buffering: no`, writes `data: <json>\n\n` frames, and emits a `: heartbeat` comment every 30s (`sseHeartbeatInterval`). Auth is a Bearer token on the request header. The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which uses `fetch` + a `ReadableStream` reader (not `EventSource`, so it can send the `Authorization` header) with exponential-backoff reconnect, and invalidates React Query caches per event type.

**Hub** — `server/router/api/v1/sse_hub.go`: `SSEHub` holds a mutex-guarded `map[*SSEClient]struct{}`; `Subscribe`/`Unsubscribe`/`Close`/`Broadcast`. Each client has a 32-buffered channel and events are dropped rather than blocking on a slow client (`sse_hub.go:126-130`). `canReceive` (`sse_hub.go:134`) filters private-memo events to the creator or an admin.

**Broadcast call sites** (event types in `sse_hub.go:14-21`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` → `memo.created`
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` → `memo.deleted`
- `UpdateMemo` — `server/router/api/v1/memo_service.go:513`, via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66-71`) → `memo.updated`
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48`, same helper → `memo.updated`
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48`, same helper → `memo.updated`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` → `memo.comment.created`
- `UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161`, via `buildMemoReactionSSEEvent` (`server/router/api/v1/sse_event_helpers.go:24`) → `reaction.upserted` / `reaction.deleted`
