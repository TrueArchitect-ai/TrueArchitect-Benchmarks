`web/src/connect.ts`

All ConnectRPC service clients are created there (`web/src/connect.ts:184-203`): a shared `createConnectTransport` with an auth interceptor, then `createClient(...)` exports for `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. The file also defines a separate interceptor-free `refreshTransport`/`refreshAuthClient` pair (lines 65-72) used solely for token refresh, to avoid recursion.
