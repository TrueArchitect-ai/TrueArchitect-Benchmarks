**`web/src/connect.ts`; short-lived JWT access token (Bearer, localStorage) + HttpOnly `memos_refresh` refresh-token cookie (plus `memos_pat_` personal access tokens as an alternative bearer credential); `server/auth`**

**Frontend** — `web/src/connect.ts:156-178` defines `authInterceptor`, a Connect-RPC `Interceptor` registered on the transport at `web/src/connect.ts:184-189` that backs every service client (memo, user, auth, attachment, …). On each request it:
- calls `getRequestToken()` (`web/src/connect.ts:124`) and sets `Authorization: Bearer <token>`;
- pre-emptively refreshes when the token is within 30s of expiry (`REQUEST_TOKEN_EXPIRY_BUFFER_MS`);
- on a `Code.Unauthenticated` reply, refreshes once, re-sends with an `X-Retry: true` marker to prevent loops, and calls `redirectOnAuthFailure()` if that fails.

Refresh goes through a *separate* transport with no interceptors (`web/src/connect.ts:65-83`) to avoid recursion, calling `AuthService.RefreshToken` with `credentials: "include"` so the refresh cookie is sent.

**Token storage** — `web/src/auth-state.ts`: access token + expiry in `localStorage` under `memos_access_token` / `memos_token_expires_at`, mirrored in memory and synced across tabs via a `memos_token_sync` `BroadcastChannel`. The refresh token itself is never visible to JS — it's the cookie.

**Backend** — package `server/auth`:
- `server/auth/authenticator.go` — `Authenticator.Authenticate` validates the Bearer credential: stateless JWT access token (`AuthenticateByAccessTokenV2`) or DB-backed PAT (`AuthenticateByPAT`, records last-used); `AuthenticateByRefreshToken` validates the cookie token with a DB revocation/expiry check.
- `server/auth/extract.go` — `ExtractBearerToken` / `ExtractRefreshTokenFromCookie`.
- `server/auth/token.go` — constants: access token 15 min, refresh token 30 days, cookie `memos_refresh`, PAT prefix `memos_pat_`.

It's wired into requests by `AuthInterceptor.WrapUnary` (`server/router/api/v1/connect_interceptors.go:217-231`), which delegates to the shared `Authorizer` (`server/router/api/v1/authz.go`) for authentication + anonymous-access policy, then stashes the result via `auth.ApplyToContext`.
