**`Driver` — `store/driver.go`** (declared at `store/driver.go:10`)

It's the interface every store backend implements, documented in-file as "an interface for store driver. It contains all methods that store database driver should implement." It covers connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus all per-model CRUD methods (attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, user identities).
