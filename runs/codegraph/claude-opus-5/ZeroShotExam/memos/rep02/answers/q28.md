**Runners the server actually starts**

- **s3presign runner (`RunOnce`)** — one synchronous pass at startup, called directly from `startBackgroundRunners` (`server/server.go:163`), before the goroutine is launched.
- **s3presign runner (`Run` loop)** — `time.NewTicker` on a hardcoded 12-hour interval (`server/runner/s3presign/runner.go:27,29-41`); goroutine launched at `server/server.go:166-171`, tracked by `backgroundRunnerWG`, stopped by its own `context.CancelFunc` on `Shutdown` (`server/server.go:156-159,176-182`).
- **Store cache cleanup loops (×3)** — `go c.cleanupLoop()` in `store/cache/cache.go:83`, driven by a `time.NewTicker(CleanupInterval)` = 5 minutes (`store/cache/cache.go:201`, config at `store/store.go:40-53`). Started implicitly by `store.New` for `instanceSettingCache`, `userCache`, `userSettingCache`; stopped via `Cache.Close`.
- **Async email workers (×2)** — package `init()` in `internal/email/email.go:15-18`; not scheduled at all, they block on the `asyncEmailQueue` channel (event-driven, capacity 128).
- **Async webhook workers (×4)** — package `init()` in `internal/webhook/webhook.go:41-44`; block on the `asyncPostQueue` channel (event-driven, capacity 128).
- **HTTP serve goroutine** — `go s.httpServer.Serve(listener)` (`server/server.go:124-128`); request-driven, not scheduled.
- **Signal/shutdown goroutine** — `cmd/memos/main.go:99-103`; waits on SIGINT/SIGTERM.

Per-request tickers that are *not* background runners: the SSE heartbeat `time.NewTicker(sseHeartbeatInterval)` lives inside each SSE request handler (`server/router/api/v1/sse_handler.go:64`), and PAT last-used updates are one-shot fire-and-forget goroutines (`server/auth/authenticator.go:180`).

**Unused scheduling infrastructure**

- **`internal/scheduler` — a full cron scheduler (parser for 5/6-field expressions, `Job` registration, `Scheduler.Start/Stop`, middleware) is completely unused by the server.** The only importers are its own tests (`internal/scheduler/example_test.go:10`, `internal/scheduler/integration_test.go:13`); no production code registers a job. `server/server.go` imports only `server/runner/s3presign` and schedules with a raw ticker instead.
- **`server/runner/memopayload.Runner` is dead as a runner** — `NewRunner`/`RunOnce` (`server/runner/memopayload/runner.go:19,27`) have no callers; only the plain function `memopayload.RebuildMemoPayload` is used, inline on the request path in `server/router/api/v1/memo_service.go:108,447`.
