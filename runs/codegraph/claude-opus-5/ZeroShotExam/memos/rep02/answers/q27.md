**Go `embed` (`//go:embed dist/*`) served by Echo's static middleware from the embedded FS, with SPA fallback to `index.html`; `server/router/frontend/frontend.go`**

How it fits together:

- **Build**: `web/package.json:11` — `pnpm release` runs `vite build --outDir=../server/router/frontend/dist --emptyOutDir`, so the compiled SPA lands inside the Go package directory (also documented at `AGENTS.md:46`, and uploaded/restored as a CI artifact at that path in `.github/workflows/release.yml` and `build-canary-image.yml`).
- **Embed**: `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` / `var embeddedFiles embed.FS` compiles the whole `dist` tree into the binary. `getFileSystem("dist")` (`frontend.go:115-121`) sub-roots it.
- **Serve**: `FrontendService.Serve` (`frontend.go:41-61`) registers `middleware.StaticWithConfig{Filesystem: frontendFS}` on the Echo instance, with a skipper that bypasses `/api`, `/file`, `/memos.api.v1*`, `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` (`frontend.go:82-90`) and otherwise sets cache headers (`frontend.go:92-105`).
- **SPA routing**: `spaFallbackMiddleware` (`frontend.go:63-80`) catches 404s on extensionless paths and returns `index.html` from the same embedded FS, so client-side routes resolve.

`Serve` is wired into the server in `server/server.go` (via `NewFrontendService(profile, store)`).
