**Engine + path:** Google's **CEL** (`github.com/google/cel-go`), wrapped by the repo's own three-phase filter engine in **`internal/filter/`** — `engine.go` (Engine/Program/`DefaultEngine`), `schema.go` (CEL env + field metadata + `DialectName`), `parser.go` (CEL AST → IR), `ir.go` (dialect-agnostic condition tree), `render.go` (IR → SQL), `helpers.go` (`AppendConditions`). Package docs: `internal/filter/README.md`.

**Mechanism (one sentence):** `Engine.Compile` type-checks the filter string against a memo-specific CEL environment (`cel.NewEnv(schema.EnvOptions...)`, `internal/filter/engine.go:53`) and lowers the CEL AST into a dialect-agnostic IR condition tree via `buildCondition` (`internal/filter/parser.go`), then `Program.Render` walks that IR with a dialect-parameterized renderer (`internal/filter/render.go`, switching on `DialectSQLite`/`DialectMySQL`/`DialectPostgres` for JSON access, tag containment, regex, date-part extraction, and `?` vs `$n` placeholders in `addArg`, render.go:842) to emit a `Statement{SQL, Args}` fragment.

**Wiring for ListMemos:**
