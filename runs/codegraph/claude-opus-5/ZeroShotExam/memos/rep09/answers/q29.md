**`web/src/connect.ts` (authInterceptor, with token storage in `web/src/auth-state.ts`); JWT access token (Bearer, in-memory + localStorage) + HttpOnly `memos_refresh` refresh-token cookie (plus `memos_pat_*` personal access tokens for programmatic callers); `server/auth`**

How it works:

- **Interceptor** — `web/src/connect.ts` defines `authInterceptor`, registered on the Connect-Web transport (`createConnectTransport({ ..., interceptors: [authInterceptor] })`) that backs every service client (`memoServiceClient`, `userServiceClient`, etc.). It calls `getRequestToken()` and sets `Authorization: Bearer <token>`. On a `Code.Unauthenticated` response it refreshes once, retries with an `X-Retry: true` marker to prevent loops, and on failure calls `redirectOnAuthFailure()` (`web/src/utils/auth-redirect.ts`).
- **Tokens the frontend manages** — `web/src/auth-state.ts` holds the short-lived JWT **access token** in memory and mirrors it to `localStorage` under `memos_access_token` / `memos_token_expires_at`, with a 30 s preflight-expiry buffer (`REQUEST_TOKEN_EXPIRY_BUFFER_MS`) and a 2 min focus buffer, plus a `BroadcastChannel` ("memos_token_sync") so tabs share refreshed tokens. The **refresh token** is never touched by JS — it rides as an HttpOnly cookie via `fetch(..., { credentials: "include" })`, and refresh goes through a separate interceptor-free transport calling `AuthService.RefreshToken` (avoiding recursion), deduplicated by `tokenRefreshManager`.
- **Backend validation** — `server/auth` (`authenticator.go`, `token.go`, `extract.go`): `Authenticator.Authenticate` parses the bearer value, validating either a JWT access token (`AuthenticateByAccessTokenV2`, 15 min, audience `user.access-token`) or a Personal Access Token prefixed `memos_pat_` (DB-backed); refresh tokens (30 d, cookie `memos_refresh`) are validated by `AuthenticateByRefreshToken` with a DB revocation check. It's wired in via `server/router/api/v1/authz.go` (`Authorizer` → `auth.NewAuthenticator`) and consumed by the server-side `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go:217`.
