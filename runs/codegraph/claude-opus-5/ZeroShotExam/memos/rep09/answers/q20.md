**Mechanism:** Server-Sent Events (SSE) over plain HTTP — a `text/event-stream` response at `GET /api/v1/sse`, with `data: <json>\n\n` frames and `: heartbeat` comments every 30s.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`) with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`. Each client gets a 32-slot buffered channel; events are dropped rather than blocking a slow client, and `canReceive` (sse_hub.go:134) filters private memos to the creator or an admin.

**Supporting wiring:** endpoint registration and auth in `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes`, `handleSSE`, Bearer-token auth); shutdown drain in `server/server.go:203` (`closeLongLivedConnections` → `sseHub.Close()`); browser consumer in `web/src/hooks/useLiveMemoRefresh.ts`, which reads the stream with `fetch` (not `EventSource`, so it can send an `Authorization` header) and invalidates React Query caches, reconnecting with exponential backoff.
