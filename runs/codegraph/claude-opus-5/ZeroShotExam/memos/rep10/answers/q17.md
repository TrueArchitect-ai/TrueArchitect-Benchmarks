**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

Details:

- **Module:** `web/src/hooks/useMemoQueries.ts` — holds the memo query-key factory (`memoKeys`) plus the React Query hooks for memo CRUD: `useMemos` / `useInfiniteMemos` (list), `useMemo` (get), `useLinkMetadata`, `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, and `useMemoComments` / `useInfiniteMemoComments`.
- **Client:** `memoServiceClient`, imported from `@/connect` (`web/src/connect.ts:197`), created via `createClient(MemoService, transport)` from `@connectrpc/connect` over the generated Connect-ES stub `MemoService` in `web/src/types/proto/api/v1/memo_service_pb.ts`.

Related callers of the same client live in `web/src/components/MemoEditor/services/memoService.ts` and `web/src/hooks/useMemoShareQueries.ts`, but the CRUD mutations/queries themselves are in `useMemoQueries.ts`.
