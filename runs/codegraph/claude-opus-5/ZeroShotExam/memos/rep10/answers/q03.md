**DB — `store/db/postgres/postgres.go`**

The PostgreSQL implementation of the `store.Driver` interface (defined in `store/driver.go:10`) is the struct `DB` in package `postgres`:

```go
// store/db/postgres/postgres.go:16
type DB struct {
	db      *sql.DB
	profile *profile.Profile
}
```

It's constructed by `NewDB(profile)` at `store/db/postgres/postgres.go:21`, which opens `sql.Open("postgres", profile.DSN)` (with `github.com/lib/pq` blank-imported) and returns it as a `store.Driver`. The rest of the interface methods are spread across the sibling files in `store/db/postgres/` (`memo.go`, `user.go`, `attachment.go`, etc.), all as methods on `*DB`.

Note the same struct name `DB` is used for the MySQL (`store/db/mysql/mysql.go:14`) and SQLite (`store/db/sqlite/sqlite.go:16`) drivers — they're distinguished by package, and dispatched in `store/db/db.go`.
