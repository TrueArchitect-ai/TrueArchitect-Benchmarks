**Mechanism:** Server-Sent Events (SSE) over a plain HTTP streaming endpoint — `GET /api/v1/sse`, `Content-Type: text/event-stream`, `data: <json>\n\n` frames plus `: heartbeat` comments every 30s (`server/router/api/v1/sse_handler.go:34`). Not WebSockets. The browser consumes it with `fetch` + a stream reader (not `EventSource`, so it can send a Bearer token) in `web/src/hooks/useLiveMemoRefresh.ts`, invalidating React Query caches per event.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`) with `NewSSEHub`, `Subscribe`, `Unsubscribe`, `Close`, and `Broadcast`. Each client has a 32-event buffered channel; events are dropped for slow clients rather than blocking, and `canReceive` (sse_hub.go:134) filters private memos to the creator or admins. Routes are wired in `server/router/api/v1/sse_handler.go:25` (`RegisterSSERoutes`), and the hub is created/closed by the server (`server/server.go`).

**Handlers that broadcast:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `dispatchMemoUpdatedSideEffects` — `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`); shared helper called by `UpdateMemo` (memo_service.go:513), `SetMemoAttachments` (memo_attachment_service.go:48), and `SetMemoRelations` (memo_relation_service.go:48)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106` (`reaction.upserted`)
- `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:161` (`reaction.deleted`)

Reaction events are built via `buildMemoReactionSSEEvent` in `server/router/api/v1/sse_event_helpers.go`.
