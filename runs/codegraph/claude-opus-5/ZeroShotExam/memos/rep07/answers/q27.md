**Go `embed.FS` — the Vite build output is compiled into the binary and served by Echo's static middleware (plus an SPA `index.html` fallback); `server/router/frontend/frontend.go`**

How it's wired:

- `web/package.json:11` — the `release` script runs `vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir`, so the compiled React bundle lands in `server/router/frontend/dist`.
- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` embeds that directory into the Go binary as `embeddedFiles`.
- `server/router/frontend/frontend.go:41-61` — `FrontendService.Serve` takes `fs.Sub(embeddedFiles, "dist")` and registers `middleware.StaticWithConfig` over it, with a skipper that bypasses `/api`, `/file`, gRPC-gateway (`/memos.api.v1*`), `robots.txt`, `sitemap.xml`, and `rss.xml` paths, and sets cache headers (`no-cache` for HTML, `immutable` for `/assets/`).
- `server/router/frontend/frontend.go:63-80` — `spaFallbackMiddleware` catches 404s on extensionless paths and serves `index.html` from the embedded FS, giving client-side routing.
- `server/server.go:71-72` — the hookup point: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.

CI restores the built `dist` into `server/router/frontend/dist` before the Go build (e.g. `.github/workflows/release.yml:107-108`).
