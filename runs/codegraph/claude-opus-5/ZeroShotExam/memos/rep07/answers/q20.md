**Server-Sent Events (SSE) over `GET /api/v1/sse`; `server/router/api/v1/sse_hub.go`; `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoRelations`, `SetMemoAttachments` (the last three via `dispatchMemoUpdatedSideEffects`), plus `UpsertMemoReaction` / `DeleteMemoReaction`**

Details:

**Mechanism** — SSE, not WebSockets. The endpoint is registered in `server/router/api/v1/sse_handler.go:25-29` (`RegisterSSERoutes` → `GET /api/v1/sse`), wired at `server/router/api/v1/v1.go:125`. `handleSSE` authenticates via Bearer token, sets `text/event-stream` / `no-cache` / `X-Accel-Buffering: no`, and sends a heartbeat every 30s (`sseHeartbeatInterval`). The browser side connects with a `fetch`-based stream reader at `web/src/hooks/useLiveMemoRefresh.ts:203`.

**Hub** — `server/router/api/v1/sse_hub.go`. `SSEHub` holds a mutex-guarded `map[*SSEClient]struct{}`; `Subscribe`/`Unsubscribe`/`Close`/`Broadcast`. Each client has a 32-event buffered channel and events are dropped rather than blocking a slow client. `SSEClient.canReceive` filters private-visibility events to the creator or admins. Constructed at `v1.go:57`, closed on shutdown at `server/server.go:205-206`.

**Broadcasting handlers** (all methods on `APIV1Service`):

| Handler | Location | Event |
|---|---|---|
| `CreateMemo` | `memo_service.go:163` | `memo.created` (skipped when `isSSESuppressed(ctx)`, i.e. called from `CreateMemoComment`) |
| `DeleteMemo` | `memo_service.go:585` | `memo.deleted` |
| `UpdateMemo` | `memo_service.go:513` → `memo_update_helpers.go:71` | `memo.updated` |
| `SetMemoRelations` | `memo_relation_service.go:48` → same helper | `memo.updated` |
| `SetMemoAttachments` | `memo_attachment_service.go:48` → same helper | `memo.updated` |
| `CreateMemoComment` | `memo_service_comments.go:126` | `memo.comment.created` (broadcast under the parent memo's name/visibility) |
| `UpsertMemoReaction` | `reaction_service.go:106` | `reaction.upserted` |
| `DeleteMemoReaction` | `reaction_service.go:161` | `reaction.deleted` |

The three `memo.updated` sites share `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66`); the reaction sites share `buildMemoReactionSSEEvent` (`server/router/api/v1/sse_event_helpers.go`), which resolves the creator ID to the *parent* memo's owner when the target is a comment.
