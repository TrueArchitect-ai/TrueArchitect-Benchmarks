**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (line 156), which sets `Authorization: Bearer <token>` and, on a 401, calls `refreshAccessToken()` and retries. (Token storage/expiry helpers live in `web/src/auth-state.ts`.)

**Token kinds:** a short-lived **access token** (JWT, sent as `Authorization: Bearer …`) and a **refresh token** (delivered as an HTTP-only cookie via `credentials: "include"`, exchanged through `AuthService.RefreshToken` for a new access token).

**Backend validating package:** `server/auth` (`server/auth/authenticator.go` — validates the JWT access token / resolves the user; wired into the API via the authz interceptor at `server/router/api/v1/authz.go`).
