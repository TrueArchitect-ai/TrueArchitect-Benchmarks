**Engine:** Google CEL (Common Expression Language, `github.com/google/cel-go`), wrapped by the project's `filter.Engine` — `internal/filter/engine.go` (with schema in `internal/filter/schema.go`, condition IR in `internal/filter/ir.go`, and SQL rendering in `internal/filter/render.go`).

**Mechanism:** The `Engine.Compile` parses the CEL filter string into a dialect-agnostic condition/IR tree (`engine.go`/`ir.go`), and a `renderer` (`render.go`) then walks that tree emitting dialect-specific SQL plus placeholder args based on the target `DialectName` (`sqlite`/`mysql`/`postgres` from `schema.go`, e.g. using `||` vs `CONCAT` per dialect).
