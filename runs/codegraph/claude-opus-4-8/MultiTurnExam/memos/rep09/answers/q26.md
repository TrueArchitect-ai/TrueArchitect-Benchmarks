Tables affected when `DeleteMemo` runs (via the API handler in `server/router/api/v1/memo_service.go:518` and the store cascade in `store/memo.go:140`):

- **memo** — the target memo row is deleted; any comment memos are also deleted first (each comment is itself a `memo` row), recursively via `store.DeleteMemo`
- **memo_relation** — relations where the memo is the source (`memo_id`) or target (`related_memo_id`) are deleted
- **attachment** — attachments linked to the memo (by `memo_id`) are deleted (plus their backing storage files, which are not a DB table)

(Reactions on the memo are only read to build the webhook payload — they are **not** deleted by this code.)
