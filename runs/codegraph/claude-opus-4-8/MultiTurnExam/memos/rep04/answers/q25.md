**engine + path:** Google CEL (Common Expression Language, via `github.com/google/cel-go`), implemented in the `internal/filter` package — the parser/compiler `Engine` lives in `internal/filter/engine.go`, the CEL environment and per-dialect field metadata in `internal/filter/schema.go`, and SQL rendering in `internal/filter/render.go`.

**mechanism:** The `Engine` compiles the CEL filter string into a dialect-agnostic condition tree, which the renderer then walks to emit a parameterized SQL `WHERE` fragment, substituting each field's dialect-specific expression template (e.g. `UNIX_TIMESTAMP(%s)` for MySQL vs. raw `%s` for SQLite/Postgres, and `?` vs `$n` placeholders) based on the `DialectName` (sqlite/mysql/postgres).
