Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140-158`) deletes:

- **memo_relation records** where the memo is the source (`MemoID`)
- **memo_relation records** where the memo is the target (`RelatedMemoID`)
- **attachments** linked to the memo (each removed via `DeleteAttachment`)

Then it calls `driver.DeleteMemo` to remove the memo row.

(Note: at the API layer in `server/router/api/v1/memo_service.go:518`, comment memos are also deleted first via recursive `Store.DeleteMemo` calls, but within the store layer itself the pre-deletions are memo relations and attachments.)
