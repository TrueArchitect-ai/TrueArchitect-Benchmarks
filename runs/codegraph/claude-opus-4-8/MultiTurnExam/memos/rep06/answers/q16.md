Before deleting the memo row itself, `store.DeleteMemo` (`store/memo.go:140`) deletes:

- **memo_relation records** where the memo is the source (`MemoID`)
- **memo_relation records** where the memo is the target (`RelatedMemoID`)
- **attachments** linked to the memo (each removed via `DeleteAttachment`)

Then it deletes the memo row (`s.driver.DeleteMemo`).

(Note: at the API layer, `APIV1Service.DeleteMemo` additionally deletes comment memos first — each of which routes back through this same `store.DeleteMemo` cleanup.)
