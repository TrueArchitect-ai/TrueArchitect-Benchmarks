Memo lifecycle events that dispatch webhooks (all in `server/router/api/v1/memo_service_webhooks.go`):

- memo created: `DispatchMemoCreatedWebhook` (`memos.memo.created`)
- memo updated: `DispatchMemoUpdatedWebhook` (`memos.memo.updated`)
- memo deleted: `DispatchMemoDeletedWebhook` (`memos.memo.deleted`)
- comment created: `DispatchMemoCommentCreatedWebhook` (`memos.memo.comment.created`)

The first three funnel through the private helper `dispatchMemoRelatedWebhook` (memo_service_webhooks.go:48); the comment one builds its payload inline. All four converge on **`webhook.PostAsync(payload)`** in the **`internal/webhook`** package (`internal/webhook/webhook.go` — `PostAsync`, which wraps the signing + HTTP `Post` delivery).
