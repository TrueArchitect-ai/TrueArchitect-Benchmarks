**engine + path**: Google CEL (Common Expression Language, via `github.com/google/cel-go`) — the filter engine lives in `internal/filter/` (`internal/filter/engine.go`, with parsing in `parser.go`, schema in `schema.go`, and SQL rendering in `render.go`).

**mechanism**: The `Engine` (`internal/filter/engine.go:14`) compiles the CEL filter string into a dialect-agnostic condition tree, and `render.go`'s renderer walks that tree, emitting dialect-specific SQL WHERE clauses and placeholders by switching on the dialect (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`) — which each dialect's `ListMemos` driver then splices into its query.
