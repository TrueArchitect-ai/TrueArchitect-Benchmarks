Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140`) deletes:

- **memo_relation records where this memo is the source** (`MemoID`)
- **memo_relation records where this memo is the target** (`RelatedMemoID`)
- **attachments linked to this memo** (each removed via `DeleteAttachment`)

Then it calls `driver.DeleteMemo` to remove the memo row.

(Additionally, at the API layer in `server/router/api/v1/memo_service.go:568-577`, comment memos are deleted first — each of which recurses through this same store cleanup.)
