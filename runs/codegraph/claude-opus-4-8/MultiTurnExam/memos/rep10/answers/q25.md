**engine + path:** Google CEL (Common Expression Language, via `github.com/google/cel-go`) — the filter engine lives in the `internal/filter` package (`internal/filter/engine.go`, with `NewEngine`/`Engine`).

**mechanism:** The `Engine` parses the CEL filter string into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`, `parser.go`), and a dialect-aware `renderer` (`internal/filter/render.go`) walks that tree to emit SQL with the correct per-dialect placeholders and functions (branching on `DialectSQLite`, `DialectPostgres`, `DialectMySQL`) which the store's dialect drivers splice into their `WHERE` clause.
