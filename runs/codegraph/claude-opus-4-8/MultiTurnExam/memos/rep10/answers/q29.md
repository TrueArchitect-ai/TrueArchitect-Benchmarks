**interceptor path:** `web/src/connect.ts` — the auth `Interceptor` attaches `Authorization: Bearer <token>` to each request and reactively refreshes on 401 (helper token state in `web/src/auth-state.ts`, refresh via `AuthService.refreshToken`).

**token kinds:** a short-lived **JWT access token** (sent as a `Bearer` header, ~15 min) and a **refresh token** (stored in an HTTP-only cookie, sent via `credentials: "include"`, used to mint new access tokens). The backend also accepts long-lived **Personal Access Tokens (PATs)** as Bearer tokens.

**backend package path:** `server/auth` (the `Authenticator` in `server/auth/authenticator.go`, with token parsing in `server/auth/*.go`), invoked from the Connect/gateway authz layer (`server/router/api/v1/authz.go`).
