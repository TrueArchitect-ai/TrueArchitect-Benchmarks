Token kinds: short-lived JWT **access tokens** (sent as `Authorization: Bearer <token>`, ~15 min), **refresh tokens** (HTTP-only cookie, exchanged via `AuthService.refreshToken` to mint new access tokens), and **personal access tokens** (also validated as Bearer tokens)

Backend package path: server/auth (`server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `resolveBearer` for access/personal tokens)

The frontend `authInterceptor` attaches the stored access token as a Bearer header, proactively/reactively refreshes it (on expiry or 401) via `refreshAccessToken` → `AuthService.refreshToken` using the refresh-token cookie, and the backend `server/auth` package validates these tokens (wired into the API via `server/router/api/v1/authz.go`'s `Authenticate` and the Connect/gateway interceptors).
