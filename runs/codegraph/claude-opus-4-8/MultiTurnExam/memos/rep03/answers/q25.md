**Engine: Google CEL (Common Expression Language, via `github.com/google/cel-go`) — `internal/filter/` (engine in `internal/filter/engine.go`).**

Mechanism: The `filter/Engine` compiles the CEL filter string against a schema into a dialect-agnostic condition/IR tree (`internal/filter/engine.go`, `internal/filter/ir.go`), and a `renderer` (`internal/filter/render.go`) then walks that tree and emits parameterized SQL specialized per `DialectName` (`DialectSQLite`, `DialectPostgres`, `DialectMySQL` — see `internal/filter/schema.go` and the dialect `switch` statements in `render.go`), which the store dialect drivers splice into the `ListMemos` query's WHERE clause.
