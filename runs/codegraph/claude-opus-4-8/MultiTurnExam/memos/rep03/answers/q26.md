When `DeleteMemo` runs, the explicitly affected tables (via `(*APIV1Service).DeleteMemo` at `server/router/api/v1/memo_service.go:544-582` and `(*Store).DeleteMemo` at `store/memo.go:140`) are:

- **memo** — the memo row itself, plus its comment memos (deleted recursively)
- **memo_relation** — rows where the memo is the source (`memo_id`) or target (`related_memo_id`), including comment relations
- **attachment** — attachments linked to the memo (`memo_id`), via `DeleteAttachment`

Note: reactions are only *listed* (to build the webhook payload), not deleted by explicit cascade code, so the `reaction` table is not touched by this path.
