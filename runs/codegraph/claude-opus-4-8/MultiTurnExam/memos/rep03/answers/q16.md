When a memo is deleted via `(*Store).DeleteMemo` (`store/memo.go:140`), the store layer deletes these records **before** the memo row itself:

1. **`memo_relation` records where the memo is the source** (`MemoID` = deleted memo) — via `DeleteMemoRelation`
2. **`memo_relation` records where the memo is the target** (`RelatedMemoID` = deleted memo) — via `DeleteMemoRelation`
3. **Attachments linked to the memo** — it lists attachments with `MemoID` = deleted memo and calls `DeleteAttachment` on each

Only after these does it call `s.driver.DeleteMemo` to delete the `memo` row itself.
