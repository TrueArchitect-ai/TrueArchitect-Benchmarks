**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual HTTP call is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`; async dispatch enqueues to `PostAsync`/the worker pool, but every send funnels through `Post`).

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`, installed as the `DialContext` of the shared `safeClient`'s transport (`internal/webhook/webhook.go:32-37`). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` — `internal/webhook/validate.go:44` (ranges defined in `reservedCIDRs`, `internal/webhook/validate.go:14`). Because the check happens at the moment of connection on the resolved IP, it also defeats DNS-rebinding.

Supplementary (not the delivery-time guard): webhook URLs are also validated up front when registered, via `ValidateURL` — `internal/webhook/validate.go:62`, which performs the same `isReservedIP` check. Both guards can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted setups targeting local services.
