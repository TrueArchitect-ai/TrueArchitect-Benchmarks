Markdown processing sits behind the `markdown.Service` interface (`internal/markdown/markdown.go:31`), which declares `ExtractAll`, `ExtractTags`, `RenderHTML`, `GenerateSnippet`, `RenameTag`, etc.

**Implementation (runtime):** There is exactly **one** concrete implementation — the unexported `service` struct wrapping a `goldmark.Markdown` (`internal/markdown/markdown.go:58`). `NewService` returns `&service{md: md}` (`internal/markdown/markdown.go:110`), so this goldmark-backed type is the only thing that ever executes at runtime.

**Construction:** `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())`. The single production construction site is `NewAPIV1Service` at `server/router/api/v1/v1.go:48` (the only other `NewService` call is `server/router/api/v1/test/test_helper.go:44`, a test). The instance is stored in `APIV1Service.MarkdownService`.

**Holders (components with a `markdown.Service` field/param):**
- **`APIV1Service`** — field `MarkdownService markdown.Service` (`server/router/api/v1/v1.go:35`); it constructs and owns the instance. Used e.g. in memo create/update and snippet generation.
- **`RSSService`** — field `MarkdownService markdown.Service` (`server/router/rss/rss.go:45`); it does **not** construct its own — it receives `APIV1Service`'s instance, passed at `server/server.go:85` (`rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`). Same object.
- **`memopayload`** — field `Runner.MarkdownService markdown.Service` (`server/runner/memopayload/runner.go:16`) and the free function `RebuildMemoPayload(_, memo, markdownService)` (`:74`). In production the `Runner` itself is never instantiated (no non-test caller of `memopayload.NewRunner`, consistent with its dead `RunOnce`), but `RebuildMemoPayload` is invoked with `APIV1Service`'s instance from `server/router/api/v1/memo_service.go:108` and `:447`.

**Answer:** impl — the goldmark-backed `service` struct (`internal/markdown/markdown.go:58`, the sole implementer of `markdown.Service`); construction — `markdown.NewService(WithTagExtension, WithMentionExtension)` in `NewAPIV1Service` (`server/router/api/v1/v1.go:48`); holders — `APIV1Service.MarkdownService` (owner, `server/router/api/v1/v1.go:35`), `RSSService.MarkdownService` (same instance injected at `server/server.go:85`, field `server/router/rss/rss.go:45`), and `memopayload` (`server/runner/memopayload/runner.go:16`/`RebuildMemoPayload` param, called with the APIV1Service instance).
