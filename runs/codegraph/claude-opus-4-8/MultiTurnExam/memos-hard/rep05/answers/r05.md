**Premise correction:** There is no GraphQL schema in this repository. A repo-wide search for `graphql`, `gqlgen`, `graphene`, or `.graphql` files returns zero hits in Go source and no GraphQL dependency in `go.mod`. The public API is not GraphQL, so there is no GraphQL schema to locate.

**Actual API surface:** The public API is defined with **Protocol Buffers** and exposed as **gRPC + gRPC-Gateway (REST/JSON) + Connect**, with an OpenAPI spec for the MCP layer:
- Schema/IDL: the `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`.
- Generated code lives in `proto/gen/api/v1/` (gRPC stubs `*_grpc.pb.go`, gateway `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`).
- The services are implemented in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`) on `APIV1Service`, and wired at startup via `apiV1Service.RegisterGateway(ctx, echoServer)` (`server/server.go:88`, defined in `server/router/api/v1/v1.go`).
- There is also an OpenAPI-driven **MCP** endpoint (`/mcp`) built from an embedded OpenAPI spec (`server/router/mcp/service.go`), and RSS routes — but no GraphQL anywhere.

**Answer:** No GraphQL schema exists; the public API is a Protobuf-defined gRPC/gRPC-Gateway/Connect surface, with the IDL in `proto/api/v1/*.proto` (generated code in `proto/gen/api/v1/`, implementations in `server/router/api/v1/`).
