A browser requesting another user's avatar hits `GET /file/users/:identifier/avatar`, served by the native HTTP file server (not the gRPC path). The avatar bytes are stored inline as a base64 `data:` URI in the user row's `avatar_url` column, so the trace ends at the user table read.

- concrete driver `(*DB).ListUsers` — e.g. store/db/sqlite/user.go (also store/db/postgres/user.go, store/db/mysql/user.go) — SELECTs the user row including `avatar_url`
