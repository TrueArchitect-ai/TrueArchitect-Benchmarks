h14.
The derived, content-computed metadata is the memo's **payload** (`store.Memo.Payload` → `storepb.MemoPayload`), specifically its `Tags` list and `Property` sub-message. It's not user-set; it's recomputed from `memo.Content`.

**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass extractor `markdownService.ExtractAll([]byte(memo.Content))` (`internal/markdown/markdown.go:356`, interface at `:33`) and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`. (There's also a bulk rebuilder `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27`, that would re-run this over every memo, but it has no production caller.)

**Triggers (recomputation):**
- **Memo create** — `APIV1Service.CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` at `server/router/api/v1/memo_service.go:108`.
- **Memo update, when content changes** — `APIV1Service.UpdateMemo` calls `memopayload.RebuildMemoPayload(ctx, memo, s.MarkdownService)` inside the `path == "content"` branch at `server/router/api/v1/memo_service.go:447` (then persists the new `Payload`).

**What the computation extracts** (via `ExtractAll`, walking the goldmark AST):
- **Tags** — all `#tags` (deduplicated, case-preserved; tags inside links/images excluded) → `memo.Payload.Tags`.
- **Property** (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
  - `HasLink` — content contains a link
  - `HasCode` — contains a code block/fenced block/code span
  - `HasTaskList` — contains a task checkbox
  - `HasIncompleteTasks` — contains an unchecked task checkbox
  - `Title` — text of the first block if it's an H1 heading

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property` into the persisted payload; mentions are consumed separately for notifications.)

**Answer:** computation site — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) via `markdown.service.ExtractAll` (`internal/markdown/markdown.go:356`); triggers — `CreateMemo` (`server/router/api/v1/memo_service.go:108`) and content-changing `UpdateMemo` (`server/router/api/v1/memo_service.go:447`); extracted — deduped `Tags` plus `Property{HasLink, HasCode, HasTaskList, HasIncompleteTasks, Title(first H1)}`.
