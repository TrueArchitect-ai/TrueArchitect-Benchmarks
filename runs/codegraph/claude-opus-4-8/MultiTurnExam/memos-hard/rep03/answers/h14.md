The derived metadata is the memo's **`Payload`** — specifically `MemoPayload.Tags` and the computed `MemoPayload.Property` (`proto/gen/store/memo.pb.go:85`), which back list/preview features. It is computed from the memo content, not set by the user.

**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass `ExtractAll` (interface `internal/markdown/markdown.go:33`, impl `internal/markdown/markdown.go:356`) and writes the results onto the memo: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`server/runner/memopayload/runner.go:85-86`).

**Triggers (recomputation):**
- **Create** — `CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before insert — `server/router/api/v1/memo_service.go:108`.
- **Update (content change)** — `UpdateMemo` rebuilds the payload only when the `content` field is in the update mask — `server/router/api/v1/memo_service.go:447` (inside the `path == "content"` branch, `:436-451`).
- (The batch backfill method `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27`, would also recompute for all memos, but it is dead code — never instantiated in production.)

**What the computation extracts** (`ExtractAll`, `internal/markdown/markdown.go:356-422`, persisted into the payload):
- **Tags** — every `#tag` node (excluding tags inside links/images), deduplicated preserving case (`data.Tags`).
- **Property** (`MemoPayload_Property`, fields at `proto/gen/store/memo.pb.go:85-92`):
  - `HasLink` — content contains a link (`markdown.go:393`).
  - `HasCode` — content contains a code block, fenced code block, or inline code span (`:396`).
  - `HasTaskList` — content contains a task checkbox (`:399`).
  - `HasIncompleteTasks` — content has at least one unchecked task checkbox (`:401-404`).
  - `Title` — text of the first-block H1 heading, if the document begins with one (`:384-388`).

(`ExtractAll` also collects `Mentions`, but those are consumed separately for mention notifications — `server/router/api/v1/memo_mention_helpers.go:32` — and are not stored in the persisted payload by `RebuildMemoPayload`.)

Answer: computation site = `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`, via `markdown.ExtractAll` `internal/markdown/markdown.go:356`); triggers = `CreateMemo` (`memo_service.go:108`) and `UpdateMemo` when `content` changes (`memo_service.go:447`); extracted = deduped `#tags` plus the `Property` set `{HasLink, HasCode, HasTaskList, HasIncompleteTasks, Title(first H1)}`.
