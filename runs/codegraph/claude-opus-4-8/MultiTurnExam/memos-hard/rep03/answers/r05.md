**Premise correction:** There is no GraphQL API — and therefore no GraphQL schema — anywhere in this repository. Searching all `.go` files for `graphql`/`gqlgen` and searching for `*.graphql`/`*.graphqls` schema files both return **no matches**. The public API is not GraphQL.

**Actual API surface:** the public API is defined as **Protocol Buffers / gRPC**, exposed over REST (gRPC-Gateway) and Connect:
- The schema/service contracts live in `.proto` files under `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto` (with HTTP/REST annotations via `google.api.http`).
- These generate Go stubs under `proto/gen/api/v1/` (`*.pb.go`, gRPC `*_grpc.pb.go`, gateway `*.pb.gw.go`, and Connect `apiv1connect/*.connect.go`).
- At runtime the services are registered in `server/router/api/v1/v1.go` (gRPC-Gateway mux + Connect handlers/interceptors, e.g. `v1.go:95`, `:133`–`:141`) and wired into the HTTP server via `apiV1Service.RegisterGateway(...)` in `server/server.go:88`. There is also an MCP surface (`server/router/mcp/`) and an RSS feed (`server/router/rss/`), but no GraphQL endpoint.

So: the correct location to look for the "public API schema" is the protobuf definitions in `proto/api/v1/*.proto` (served as gRPC/REST/Connect), not a GraphQL schema.
