**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual outbound request fires at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`). `PostAsync` (webhook.go:184) just enqueues onto a bounded channel drained by worker goroutines (started in `init`, webhook.go:42) that call `Post`.

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`. It is installed as the `DialContext` of the shared `safeClient` transport (webhook.go:32–37), so at connect time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`). Because the check happens at dial time on the resolved IP, it also defeats DNS-rebinding. The reserved ranges (loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents) are defined in `internal/webhook/validate.go:14-23`, and can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).

A complementary check, `ValidateURL` (`internal/webhook/validate.go:62`), runs when a webhook is created/updated (called from `server/router/api/v1/user_service_webhooks.go`) to reject private-resolving or non-http(s) URLs up front — but the runtime guard on the actual delivery is `safeDialContext`.
