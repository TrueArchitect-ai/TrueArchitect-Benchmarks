**Premise correction:** There is no GraphQL API in this repository, so there is no GraphQL schema to locate. A search of the source, `go.mod`, and schema files for `graphql`, `gqlgen`, `graph-gophers`, and `.graphql` returns zero matches — no GraphQL server, resolver, or SDL exists.

**Actual API surface:** the public API is defined as **Protocol Buffers / gRPC services**, exposed over both Connect-RPC and a gRPC-Gateway REST/JSON transcoding layer.
- Schema (source of truth): `.proto` service definitions in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`.
- Generated Go stubs live in `proto/gen/api/v1/` (e.g. `*.pb.go`, gRPC-Gateway `*.pb.gw.go`).
- Server wiring: handlers/interceptors and the gateway+Connect mux are registered in `server/router/api/v1/v1.go` (Connect interceptors at `v1.go:133-141`, gateway registration in `RegisterGateway`).
- Additional non-GraphQL surfaces: an **MCP** server under `server/router/mcp/` (which generates JSON-Schema/OpenAPI-style tool descriptors, `server/router/mcp/openapi.go`), an **RSS** feed under `server/router/rss/`, and a static **fileserver** under `server/router/fileserver/`.

Answer: **No GraphQL schema exists. The public API is Protobuf/gRPC defined in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1/`), served via Connect + gRPC-Gateway wired in `server/router/api/v1/v1.go`, alongside MCP (`server/router/mcp/`) and RSS (`server/router/rss/`) surfaces.**
