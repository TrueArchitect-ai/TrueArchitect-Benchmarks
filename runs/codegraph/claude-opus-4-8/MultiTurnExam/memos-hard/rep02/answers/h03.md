**Abstraction package — `internal/idp`; implementation package — `internal/idp/oauth2`**

Details:

- **Abstraction:** The provider abstraction lives in the `internal/idp` package. The OAuth2 implementation imports it (`"github.com/usememos/memos/internal/idp"`, internal/idp/oauth2/oauth2.go:15) and returns its shared type `idp.IdentityProviderUserInfo` from `UserInfo` (e.g. internal/idp/oauth2/oauth2.go:83, 114), which is the neutral user-info type the abstraction defines for any provider.

- **Concrete protocol implementation:** Only one protocol ships — OAuth2 — in `internal/idp/oauth2` (internal/idp/oauth2/oauth2.go:1, `// Package oauth2 implements the OAuth2 identity provider integration.`). Its `IdentityProvider` struct wraps a `storepb.OAuth2Config` and implements `ExchangeToken` (with optional PKCE) and `UserInfo`, backed by `golang.org/x/oauth2`. It's constructed via `NewIdentityProvider` (internal/idp/oauth2/oauth2.go:27), called from the SSO auth flow in `server/router/api/v1/auth_service_sso.go`.
