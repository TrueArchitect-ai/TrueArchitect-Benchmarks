**Delivery function — `Post` (internal/webhook/webhook.go:120), specifically the `safeClient.Do(req)` call at internal/webhook/webhook.go:152. Protection mechanism — `safeDialContext` (internal/webhook/webhook.go:59), the custom `DialContext` on the shared `safeClient` transport, which rejects reserved/private IPs via `isReservedIP` (internal/webhook/validate.go:44).**

Details:

- **Where delivery executes:** `webhook.Post` marshals the `WebhookRequestPayload`, builds the POST request (optionally adding Standard-Webhooks HMAC signature headers), and fires it via the shared `safeClient.Do(req)` at internal/webhook/webhook.go:152. Callers reach this synchronously through `Post`, or asynchronously via `PostAsync` (internal/webhook/webhook.go:184) which enqueues onto `asyncPostQueue`, drained by worker goroutines started in `init` (internal/webhook/webhook.go:42-55) that themselves call `Post`. The memo-side triggers live in server/router/api/v1/memo_service_webhooks.go (`DispatchMemoCreatedWebhook` etc.).

- **What protects it from internal addresses:** `safeClient` is configured with a `Transport` whose `DialContext` is `safeDialContext` (internal/webhook/webhook.go:32-37). At dial time, `safeDialContext` resolves the target host and rejects any address in a reserved/private range (internal/webhook/webhook.go:59-77). The range check is `isReservedIP` in internal/webhook/validate.go:44, backed by `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents) at internal/webhook/validate.go:14-23. Because the check happens at connection time on the resolved IP, it also defeats DNS-rebinding. It can be globally disabled via the `AllowPrivateIPs` flag (internal/webhook/validate.go:41-47).

- **Secondary (create-time) guard:** `ValidateURL` (internal/webhook/validate.go:62) enforces http/https scheme and the same reserved-IP check when a webhook URL is registered (called from server/router/api/v1/user_service_webhooks.go), but the enforcement that actually protects each outbound delivery is the dial-time `safeDialContext`.
