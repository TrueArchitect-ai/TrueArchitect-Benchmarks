**Computation site — `RebuildMemoPayload` (server/runner/memopayload/runner.go:74), which delegates the parse to the markdown service's `ExtractAll` (internal/markdown/markdown.go, `(*service).ExtractAll`). It assigns the results onto the memo's payload at server/runner/memopayload/runner.go:85-86 (`memo.Payload.Tags = data.Tags`; `memo.Payload.Property = data.Property`).**

**Triggers (operations that recompute):**

- **`CreateMemo`** — server/router/api/v1/memo_service.go:108 (`memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)`), before the row is inserted.
- **`UpdateMemo`, only when the `content` field is in the update mask** — server/router/api/v1/memo_service.go:447, inside the `path == "content"` branch; the rebuilt payload is written via `update.Payload = memo.Payload`.

(There is also a batch `memopayload.Runner.RunOnce` that would rebuild every memo, but per h08 it has no production caller, so it does not run at runtime.)

**Extracted properties (what `ExtractAll` derives from the content via a single goldmark AST walk):**

- **`Tags`** — the set of `#tags` found in the content, deduplicated while preserving case (persisted to `MemoPayload.Tags`, proto/gen/store/memo.pb.go:28).
- **`Property`** (`MemoPayload_Property`, proto/gen/store/memo.pb.go:85):
  - **`Title`** — text of a leading H1 heading, if the first block is `# ...`.
  - **`HasLink`** — true if any link node exists.
  - **`HasCode`** — true if any code block/fenced block/code span exists.
  - **`HasTaskList`** — true if any task-list checkbox exists.
  - **`HasIncompleteTasks`** — true if any task checkbox is unchecked.

Note: `ExtractAll` also collects `Mentions` (@username) and computes them, but `RebuildMemoPayload` persists only `Tags` and `Property` into the memo payload; mentions are used separately (notifications). The derived payload is what the list/preview paths read (tags for filtering, `Property` flags and `Title` for previews).
