The pluggable identity-provider layer lives under `internal/idp`.

**Abstraction package**: `internal/idp` — defines the provider abstraction, including the `IdentityProviderUserInfo` type (and the provider interface/shared types) that concrete providers implement/return. The OAuth2 implementation imports it as `github.com/usememos/memos/internal/idp` (see `internal/idp/oauth2/oauth2.go:15,83,114`).

**Implementation package**: `internal/idp/oauth2` — the one concrete protocol implementation that ships (`internal/idp/oauth2/oauth2.go`, package comment: "Package oauth2 implements the OAuth2 identity provider integration"). It provides `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and `UserInfo`, built on `golang.org/x/oauth2`.
