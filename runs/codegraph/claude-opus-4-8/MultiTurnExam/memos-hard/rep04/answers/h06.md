**Convergence function before delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go:184`. Every dispatch path enqueues here; its async worker goroutines then invoke `webhook.Post` (`internal/webhook/webhook.go:120`), which is where the outbound HTTP request is actually executed (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`).

So: all handler paths converge at **`webhook.PostAsync` (`internal/webhook/webhook.go:184`)**, and the single delivery function they feed is `webhook.Post` (`internal/webhook/webhook.go:120`).
