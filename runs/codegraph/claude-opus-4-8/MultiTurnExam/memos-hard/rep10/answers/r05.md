**Premise correction: there is no GraphQL schema anywhere in this repository — the public API is not GraphQL.** A repo-wide search for `graphql`/`.graphql`/`.gql` across Go and schema files returns zero matches; there is no GraphQL server, resolver, or schema definition.

**Actual API surface: a Protocol Buffers–defined gRPC / Connect / gRPC-Gateway (REST) API.** The public API is declared as `.proto` service definitions under `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus shared `common.proto`.

These compile to generated Go in `proto/gen/api/v1/` (message/gRPC/gateway stubs) and Connect handlers in `proto/gen/api/v1/apiv1connect/`. The server wires them up in `server/router/api/v1/` (e.g. `APIV1Service` and `RegisterGateway` in `server/router/api/v1/v1.go`), serving:
- **gRPC / Connect RPC** (via the connectrpc handlers and interceptors in `server/router/api/v1/connect_*.go`), and
- **RESTful HTTP** via gRPC-Gateway (the `*.pb.gw.go` files, mounted through `RegisterGateway`).

Additionally, an OpenAPI spec is generated/embedded and reused to drive the MCP endpoint (`server/router/mcp/`, e.g. `loadMCPServiceOpenAPISpec` reading `memosproto.OpenAPIYAML()`). So the "schema" for the public API is the set of protobuf service definitions in `proto/api/v1/*.proto` — not GraphQL.
