**abstraction package — `internal/idp` (`internal/idp/idp.go`, defining the `IdentityProviderUserInfo` provider abstraction); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`, the OAuth2 concrete protocol implementation)**

- `internal/idp/idp.go` declares package `idp`, holding the provider-neutral `IdentityProviderUserInfo` abstraction shared across identity providers.
- `internal/idp/oauth2/oauth2.go` declares package `oauth2` ("implements the OAuth2 identity provider integration"), the one concrete protocol implementation that ships — its `IdentityProvider` type wraps a `storepb.OAuth2Config` and produces `idp.IdentityProviderUserInfo`.
