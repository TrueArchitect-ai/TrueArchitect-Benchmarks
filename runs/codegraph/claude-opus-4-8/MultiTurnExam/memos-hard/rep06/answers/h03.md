**abstraction package: `internal/idp`** (`internal/idp/idp.go`) — defines the provider abstraction shared across implementations, notably the `IdentityProviderUserInfo` result type that every provider returns.

**implementation package: `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`) — the one concrete protocol implementation that ships: OAuth2. Its `IdentityProvider` struct implements the token exchange and user-info flow (`NewIdentityProvider`, `ExchangeToken`, `UserInfo`) and returns `*idp.IdentityProviderUserInfo`.

Note: the abstraction here is expressed primarily as a shared user-info type plus a common method shape rather than a named Go `interface` in `internal/idp` — the OAuth2 package is the sole provider that ships, wired in at `server/router/api/v1/auth_service_sso.go`.
