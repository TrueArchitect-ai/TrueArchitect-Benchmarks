**Handlers (RPC methods that can transitively trigger an outbound HTTP request to a user-configured webhook URL):**

1. `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`.
2. `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.
3. `APIV1Service.DeleteMemo` — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`.
4. `APIV1Service.CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`.
5. (also) `SetMemoRelations` (`server/router/api/v1/memo_relation_service.go:48`) and `SetMemoAttachments` (`server/router/api/v1/memo_attachment_service.go:48`), both via `dispatchMemoUpdatedSideEffects`.

All of these reach the user-configured URL because the dispatch helpers load the creator's webhooks (`s.Store.GetUserWebhooks`) and set `payload.URL = hook.Url` (`server/router/api/v1/memo_service_webhooks.go`).

**Convergence function before delivery:** `webhook.Post` — `internal/webhook/webhook.go:120`.

The paths converge in two steps: every handler funnels into `webhook.PostAsync` (`internal/webhook/webhook.go:184`) — either through `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:71`) or `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:43`). `PostAsync` enqueues onto `asyncPostQueue`, whose worker pool (`init`, `internal/webhook/webhook.go:42-55`) invokes the single delivery function `webhook.Post`, where the actual `safeClient.Do(req)` HTTP call to the user URL executes (`internal/webhook/webhook.go:152`).
