**Premise correction:** There is no GraphQL schema in this repository, and no GraphQL API. A repo-wide search for `graphql`, `gqlgen`, and `graph-gophers` across the Go sources, `go.mod`, and the tree returns zero matches. There is no `.graphql`/`.gqls` schema file and no GraphQL server/resolver code. So the premise's "GraphQL schema for the public API" does not exist.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC services**, exposed over HTTP via gRPC-Gateway (REST) and Connect. The schema lives in the `.proto` files under `proto/api/v1/`:

- `proto/api/v1/auth_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/common.proto`

Generated Go bindings (messages, gRPC stubs, gateway, and Connect handlers) are in `proto/gen/api/v1/` (e.g. `*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, and `apiv1connect/*.connect.go`). At runtime these services are registered and served in `server/router/api/v1/v1.go` — gRPC-Gateway REST handlers via `RegisterGateway` (`server/router/api/v1/v1.go:65`) and Connect handlers via `RegisterConnectHandlers` (`server/router/api/v1/connect_handler.go:31`), with interceptors wired at `server/router/api/v1/v1.go:133-141`. There is additionally an MCP (Model Context Protocol) HTTP surface with an OpenAPI-style JSON schema catalog under `server/router/mcp/`, but still no GraphQL.
