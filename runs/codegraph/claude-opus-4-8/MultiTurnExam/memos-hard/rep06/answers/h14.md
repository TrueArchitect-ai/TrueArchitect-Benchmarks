**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It parses the memo's content through the markdown service (`markdownService.ExtractAll`) and writes the results onto `memo.Payload` (`Payload.Tags` and `Payload.Property`). The actual content walk/extraction lives in the goldmark implementation `(*service).ExtractAll` — `internal/markdown/markdown.go:356`.

**Triggers (operations that recompute it):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (recomputed on the new memo before insert).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the `"content"` update-mask branch, so it recomputes only when the content field changes.
- Batch rebuild across all memos: `memopayload.Runner.RunOnce` → `RebuildMemoPayload` at `server/runner/memopayload/runner.go:52`. (Note: this `Runner` is never constructed in production — `memopayload.NewRunner` has no non-test caller — so in a running server the live triggers are the two API handlers above.)

**Extracted properties (derived from content, stored in `MemoPayload`):**
- `Tags` — the deduplicated list of `#tags` found in the content (case preserved), assigned to `memo.Payload.Tags`.
- `Property` (`storepb.MemoPayload_Property`), computed in `ExtractAll` (`internal/markdown/markdown.go:356-424`):
  - `Title` — text of the first block if it is a top-level H1 heading.
  - `HasLink` — true if any link node is present.
  - `HasCode` — true if any code block/fenced code/inline code span is present.
  - `HasTaskList` — true if any task-checkbox is present.
  - `HasIncompleteTasks` — true if any task checkbox is unchecked.

(`ExtractAll` also collects `Mentions` from `@username` tokens, but `RebuildMemoPayload` only persists `Tags` and `Property` onto the memo; mentions are used separately for notifications, not stored as list/preview metadata.)
