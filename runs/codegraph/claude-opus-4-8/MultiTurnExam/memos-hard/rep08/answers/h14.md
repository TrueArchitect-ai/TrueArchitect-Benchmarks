**Computation site:** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates the single-pass extraction to the markdown service's `(*service).ExtractAll` (`internal/markdown/markdown.go:356`). It writes the results into the memo's `Payload.Tags` and `Payload.Property` (`server/runner/memopayload/runner.go:85-86`). This derived metadata is stored on the memo (the `MemoPayload_Property` proto, `proto/gen/store/memo.pb.go:85`) and surfaced to the API as `Memo_Property` for list/preview rendering.

**Triggers (recomputation):** the two memo write paths in the API service call `RebuildMemoPayload` before persisting:
- **CreateMemo** — `server/router/api/v1/memo_service.go:108` (recomputed on every new memo).
- **UpdateMemo**, but only when the `content` field is in the update mask — `server/router/api/v1/memo_service.go:447` (inside the `path == "content"` branch). Non-content updates (visibility, pin, etc.) don't recompute it.

(There is also a bulk `memopayload.Runner.RunOnce` that would recompute every memo's payload — `server/runner/memopayload/runner.go:52` — but per h08 that Runner is never constructed in production, so it isn't a live trigger.)

**What the computation extracts** (from `ExtractAll`, one goldmark AST walk):
- **Tags** — all `#tag` nodes (excluding tags inside links/images), deduplicated preserving case → stored in `Payload.Tags` (`internal/markdown/markdown.go:376-378`, `:418`).
- **Property** (`MemoPayload_Property`) boolean/derived flags → stored in `Payload.Property`:
  - `HasLink` — content contains a link (`internal/markdown/markdown.go:393-394`)
  - `HasCode` — code block, fenced code block, or inline code span (`:396-397`)
  - `HasTaskList` — contains a task checkbox (`:399-400`)
  - `HasIncompleteTasks` — at least one unchecked task checkbox (`:401-404`)
  - `Title` — text of the first block if it's an H1 heading (`:384-388`)
- (`ExtractAll` also computes `Mentions` — lowercased `@username`s — but `RebuildMemoPayload` uses only `Tags` and `Property`; mentions feed a separate notification path, not the stored payload.)

Definitions confirmed at `proto/gen/store/memo.pb.go:85-95` (`MemoPayload_Property` fields: `HasLink`, `HasTaskList`, `HasCode`, `HasIncompleteTasks`, `Title`).
