**Abstraction package — `internal/idp` (`github.com/usememos/memos/internal/idp`); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

Details:

- **Abstraction:** the `internal/idp` package defines the provider-neutral types the concrete implementation depends on — e.g. `idp.IdentityProviderUserInfo` (the normalized user record returned by any provider), which `oauth2.UserInfo` constructs and returns (`internal/idp/oauth2/oauth2.go:83`, `:114`). The oauth2 package imports it at `internal/idp/oauth2/oauth2.go:15`.

- **Implementation:** `internal/idp/oauth2` is the one concrete protocol implementation that ships. Its file header states "Package oauth2 implements the OAuth2 identity provider integration" (`internal/idp/oauth2/oauth2.go:1-2`), and it provides the OAuth2 `IdentityProvider` struct with `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and `UserInfo` (`internal/idp/oauth2/oauth2.go:20-141`). It's wired into sign-in via `server/router/api/v1/auth_service_sso.go`.
