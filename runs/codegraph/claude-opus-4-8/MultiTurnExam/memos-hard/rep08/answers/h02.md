**delivery function — `Post`, `internal/webhook/webhook.go:120` (the actual HTTP send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`); protection mechanism — `safeDialContext`, `internal/webhook/webhook.go:59`**

Details:

- **Where delivery executes:** `Post` in `internal/webhook/webhook.go:120` marshals the payload, builds the `POST` request (optionally HMAC-signing it), and dispatches it via the shared `safeClient.Do(req)` call at `internal/webhook/webhook.go:152`. Content-change events reach it through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded channel drained by worker goroutines started in `init` (`internal/webhook/webhook.go:42`) that call `Post`. Those dispatches originate from `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go` (e.g. line 71, 43) on memo create/update/delete/comment.

- **What protects it from internal addresses:** the shared `safeClient` is configured with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59`) resolves the target host at dial time and rejects the connection if any resolved IP `isReservedIP` (reserved/private range) — returning `"connection to reserved/private IP address is not allowed"` (`internal/webhook/webhook.go:70-73`). Because the check happens on the post-resolution IP at dial time, it also defeats DNS-rebinding attempts. (`isReservedIP` lives in the same `internal/webhook` package.)
