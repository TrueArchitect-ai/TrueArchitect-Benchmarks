Note: the comment path (`DispatchMemoCommentCreatedWebhook`) reaches `webhook.PostAsync` directly rather than through `dispatchMemoRelatedWebhook`, so if you include it the single common convergence point becomes `webhook.PostAsync` → `webhook.Post` (internal/webhook/webhook.go:184/120), where the actual HTTP request is issued. But for the three memo lifecycle handlers, the shared convergence function is `dispatchMemoRelatedWebhook`.
