**Premise correction:** There is no GraphQL schema in this project. The public API is not GraphQL — a search of `go.mod` and all sources for `graphql`, `gqlgen`, or `.graphql` files returns nothing. So there is no GraphQL schema location to point to.

**Actual API surface:** The public API is a **Protocol Buffers / gRPC API** exposed over HTTP via gRPC-Gateway and Connect. The schema (the service and message definitions) is defined in `.proto` files under `proto/api/v1/`, including:
- proto/api/v1/memo_service.proto
- proto/api/v1/user_service.proto
- proto/api/v1/auth_service.proto
- proto/api/v1/attachment_service.proto
- proto/api/v1/idp_service.proto
- proto/api/v1/instance_service.proto
- proto/api/v1/shortcut_service.proto
- proto/api/v1/ai_service.proto
- proto/api/v1/common.proto

These are compiled into Go under `proto/gen/api/v1/` (gRPC stubs, gRPC-Gateway `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`). The server wires them up as HTTP routes in `APIV1Service.RegisterGateway` (called from server/server.go:88), which registers the gRPC-Gateway `HandlerServer`s (e.g. `RegisterMemoServiceHandlerServer`) and Connect handlers. There is also an embedded **OpenAPI** spec (`memosproto.OpenAPIYAML()`, consumed by the MCP service at server/router/mcp/service.go:78) describing the same REST surface — but again, no GraphQL.
