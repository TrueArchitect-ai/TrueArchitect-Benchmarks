**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`.**

All four dispatch paths hand their payload to `webhook.PostAsync` (`webhook.go:184`), which enqueues onto `asyncPostQueue`; the background workers started in `init` (line 42-55) then call the single function **`Post`**, which marshals the body, builds the request, and issues the actual outbound HTTP request via `safeClient.Do(req)` (`webhook.go:152`). So `PostAsync` is the shared enqueue entry point, and `Post` is the one function where every path converges to perform delivery.
