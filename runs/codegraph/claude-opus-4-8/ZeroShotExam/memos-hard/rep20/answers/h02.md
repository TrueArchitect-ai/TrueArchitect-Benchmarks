**delivery function** — `Post` in `internal/webhook/webhook.go:120` (the actual outbound HTTP request executes at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`; `PostAsync` at line 184 just enqueues onto a worker pool that calls `Post`).

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (`internal/webhook/webhook.go:32-37`). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), which checks against `reservedCIDRs`/`reservedNetworks` (`internal/webhook/validate.go:14-36`) covering loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents. Because the check runs at dial time (post-resolution), it also defeats DNS-rebinding, and it can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).

A secondary, create-time guard exists in `ValidateURL` (`internal/webhook/validate.go:62`), called when webhooks are created/updated, but the dial-time `safeDialContext` is the definitive protection on the delivery path.
