Outbound webhook delivery actually executes in the `Post` function, which builds the HTTP request, signs it, and fires it via `safeClient.Do(req)`. The async path (`PostAsync`) just enqueues onto a bounded channel whose worker goroutines call `Post`.

- **delivery function** — `Post` at `internal/webhook/webhook.go:120` (the actual send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`)

The SSRF protection is a custom dialer wired into the shared `safeClient`'s `http.Transport.DialContext`. At dial time, `safeDialContext` resolves the target hostname and rejects the connection if any resolved IP is a reserved/private address (`isReservedIP`), which also defeats DNS-rebinding since the check happens on the actual resolved IPs at connect time.

- **protection mechanism** — `safeDialContext` at `internal/webhook/webhook.go:59` (wired into `safeClient` at `internal/webhook/webhook.go:32`, using the `isReservedIP` check at line 71)
