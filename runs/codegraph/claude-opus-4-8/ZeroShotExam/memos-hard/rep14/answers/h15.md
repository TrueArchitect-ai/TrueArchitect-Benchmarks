h15.

Memo visibility (who may view a memo) is enforced at several independent server surfaces, all in the Go backend. The distinct enforcement sites:

**Single-memo read gate (`checkMemoReadAccess`)** — `server/router/api/v1/memo_service.go:39-68`
The central helper: non-public memos require an authenticated user; PRIVATE memos require the requester to be the creator; archived memos are creator-only. Invoked by `GetMemo` (`memo_service.go:356`, also re-checked on the parent memo at `:367`) and by `ListMemoComments` (`memo_service_comments.go:148`).

**List-memos visibility filter (`ListMemos`)** — `server/router/api/v1/memo_service.go:178` (filter built at `:218-227`)
Anonymous callers are restricted to `VisibilityList = [PUBLIC]`; authenticated callers get a filter `creator_id == <me> || visibility in ["PUBLIC","PROTECTED"]`; listing another user's memos is capped to PUBLIC/PROTECTED. Archived state is creator-only (`:188-195`).

**Comment-list visibility filter (`ListMemoComments`)** — `server/router/api/v1/memo_service_comments.go:136` (filter at `:156-161`)
Beyond the `checkMemoReadAccess` gate on the parent, it applies its own per-comment memo filter (`visibility == "PUBLIC"` for anonymous, else `creator_id == <me> || visibility in ["PUBLIC","PROTECTED"]`) so private comments by others are excluded.

**Attachment-list visibility check (`ListMemoAttachments`)** — `server/router/api/v1/memo_attachment_service.go:200` (check at `:213-225`)
Inline check mirroring `checkMemoReadAccess`: non-public memo requires auth; PRIVATE requires creator (or super-user).

**RSS feeds** — `server/router/rss/rss.go` — `GetExploreRSS` (`:72`, `VisibilityList=[PUBLIC]` at `:90`) and `GetUserRSS` (`:111`, at `:141`)
Both feed endpoints hard-restrict to PUBLIC memos only.

Enforcement site — path (one per line):
- checkMemoReadAccess (single-memo read gate; used by GetMemo and ListMemoComments) — server/router/api/v1/memo_service.go:39
- ListMemos visibility filter (list results) — server/router/api/v1/memo_service.go:178
- ListMemoComments comment-visibility filter — server/router/api/v1/memo_service_comments.go:136
- ListMemoAttachments inline visibility check — server/router/api/v1/memo_attachment_service.go:200
- RSS feeds restricted to PUBLIC (GetExploreRSS / GetUserRSS) — server/router/rss/rss.go:72 and server/router/rss/rss.go:111
