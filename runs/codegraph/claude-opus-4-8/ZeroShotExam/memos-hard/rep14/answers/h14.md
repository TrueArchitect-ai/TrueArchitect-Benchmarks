**Computation site.** The derived metadata is the memo's `Payload.Property` (and `Payload.Tags`), computed in `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`. That function delegates the actual extraction to the goldmark-based markdown service's `ExtractAll`, implemented at `internal/markdown/markdown.go:356` (the property-extraction logic also exists standalone in `ExtractProperties` at `internal/markdown/markdown.go:193`). It parses the content into an AST once and walks it, writing results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`).

**Triggers (operations that cause recomputation).** `RebuildMemoPayload` is invoked whenever content is written:
- **Create** — `CreateMemo` calls it before persisting, at `server/router/api/v1/memo_service.go:108`.
- **Update** — the memo update path calls it (via `UpdateMemo` in `server/router/api/v1/memo_service.go` / `memo_update_helpers.go`) so a content edit re-derives the property.
- **Bulk backfill** — the background runner `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds the payload for every memo in batches (100 at a time) and writes it back via `Store.UpdateMemo`.

**Extracted properties.** From walking the markdown AST (`ExtractAll` / `ExtractProperties`), into `MemoPayload_Property` (defined at `proto/gen/store/memo.pb.go:85`):
- `HasLink` — true if any link node is present (`gast.KindLink`).
- `HasCode` — true for any code block, fenced code block, or inline code span.
- `HasTaskList` — true if any task-checkbox node exists.
- `HasIncompleteTasks` — true if any task checkbox is unchecked.
- `Title` — the plain text of the document's first block if it is an H1 heading.
- Alongside the property, `Tags` — the deduplicated `#tags` (case preserved), stored in `Payload.Tags`.

These are the fields consumed for lists/previews (`Memo_Property` mirror in `proto/gen/api/v1/memo_service.pb.go:2222+`).
