**RPC handler methods** that can transitively trigger an outbound HTTP request to a user-configured webhook URL (from `WebhooksUserSetting_Webhook.Url`, set via `CreateUserWebhook`/`UpdateUserWebhook`):

- `CreateMemo` — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook`
- `DeleteMemo` — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook`
- `UpdateMemo` — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook`
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → …
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → …
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`

All of these build a `WebhookRequestPayload` and hand it to `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43,71`), which enqueues onto `asyncPostQueue`; the queue's worker goroutines then call `Post`.

**Convergence function — `webhook.Post`** at `internal/webhook/webhook.go:120`. Every path (async via `PostAsync`/the worker pool, or a direct call) funnels through `Post`, which is the single place that constructs the HTTP request to `requestPayload.URL` and issues it via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).
