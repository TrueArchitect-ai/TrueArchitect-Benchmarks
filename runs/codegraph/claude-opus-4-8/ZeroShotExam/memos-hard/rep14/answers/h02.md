The server delivers webhooks when memos change (created/updated/deleted/comment-created). The dispatch entry points in `server/router/api/v1/memo_service_webhooks.go` build a payload and call `webhook.PostAsync`, which enqueues onto a bounded channel drained by worker goroutines that call `Post`.

**Delivery function** — `Post` in `internal/webhook/webhook.go:120`. The outbound HTTP request actually executes at line 152 (`safeClient.Do(req)`), where `safeClient` is the package-level `http.Client`.

**Protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go:32-37`). Before each connection it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (line 71). Because the check happens at dial time on the resolved IPs, it blocks pointing a webhook at internal addresses and also defeats DNS-rebinding (a hostname that resolves to a private IP is refused).
