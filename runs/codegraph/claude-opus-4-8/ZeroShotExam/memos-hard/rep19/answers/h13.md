**impl — construction — holders**

**impl:** The Go interface is `markdown.Service` (`internal/markdown/markdown.go:31`). The single concrete implementation that executes at runtime is the unexported `service` struct (`internal/markdown/markdown.go:58`), which wraps a `goldmark.Markdown` and implements `ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, and `RenameTag`.

(Note: the frontend does its own markdown rendering separately via React — `web/src/components/MemoContent/MemoMarkdownRenderer.tsx` using `react-markdown` — but that is not behind the `markdown.Service` interface. The interface in question is the Go backend one.)

**construction:** Built by the factory `markdown.NewService(opts ...Option)` (`internal/markdown/markdown.go:85`), which returns `&service{md: ...}`. In production it is constructed exactly once, in `NewAPIV1Service` (`server/router/api/v1/v1.go:48-51`) with `markdown.WithTagExtension()` and `markdown.WithMentionExtension()`, and stored on `APIV1Service.MarkdownService`. (A second construction exists only in test helpers: `server/router/api/v1/test/test_helper.go:44`.)

**holders:** The interface value is held as a field by these components:
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35` (the owner that constructs it; used directly, e.g. `memopayload.RebuildMemoPayload(ctx, ..., s.MarkdownService)` at `server/router/api/v1/memo_service.go:108` and `:447`).
- `rss.RSSService.MarkdownService` — `server/router/rss/rss.go:45`, injected via `NewRSSService(...)` (`rss.go:58`) which is passed `apiV1Service.MarkdownService` in `server/server.go:85`; used for `RenderHTML` at `rss.go:339`.
- `memopayload.Runner.MarkdownService` — `server/runner/memopayload/runner.go:16`, set by `NewRunner(...)` (`runner.go:19`). (This struct field is a holder, though at runtime the payload rebuild path calls the standalone `RebuildMemoPayload(_, memo, markdownService)` (`runner.go:74`) with the API service's instance rather than going through a constructed `Runner`.)

Summary: `service` (impl) — `markdown.NewService`, called in `NewAPIV1Service` — held by `APIV1Service`, `rss.RSSService`, and `memopayload.Runner`.
