**RPC handler methods** that can transitively cause an outbound HTTP request to a user-configured webhook URL (the URL comes from `WebhooksUserSetting_Webhook.Url`, set via the webhook CRUD APIs):

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects`
6. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects`

Each of the four `Dispatch…Webhook` methods (`server/router/api/v1/memo_service_webhooks.go`) loads the creator's configured webhooks, builds a `WebhookRequestPayload` with `payload.URL = hook.Url`, and calls `webhook.PostAsync` (which enqueues onto `asyncPostQueue`, drained by the `init()` worker goroutines).

**Convergence function — path:** `webhook.Post` — `internal/webhook/webhook.go:120`. Every dispatch path funnels through `PostAsync` → the queue → `Post`, and `Post` is where the actual outbound request is issued via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`) to `requestPayload.URL`. (`PostAsync` only enqueues; the real HTTP delivery happens in `Post`.)
