**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark-based markdown service `ExtractAll` in `internal/markdown/markdown.go:356` (the property-extraction logic mirrored in `ExtractProperties`, `markdown.go:193`). It walks the parsed markdown AST in a single pass and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The property struct is `MemoPayload_Property` (`proto/gen/store/memo.pb.go:85`), surfaced to clients as `Memo.Property` / `Memo.Tags` (marked "Output only" in `proto/gen/api/v1/memo_service.pb.go:241,251`).

**Triggers (recomputation):** `RebuildMemoPayload` has three callers —
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`
- `UpdateMemo` — `server/router/api/v1/memo_service.go` (rebuilds when content changes)
- The `memopayload.Runner.RunOnce` batch job — `server/runner/memopayload/runner.go:52`, which re-derives the payload for all existing memos (100 at a time) and persists via `Store.UpdateMemo`.

So it's recomputed whenever a memo's content is created or updated, plus the bulk backfill runner.

**Extracted properties (from `ExtractAll` / `ExtractProperties`):**
- `Tags` — all `#tags` from tag AST nodes (excluding ones inside links/images), deduplicated preserving case (`markdown.go:376-378, 418`)
- `Property.HasLink` — true if any `KindLink` node is present (`markdown.go:393`)
- `Property.HasCode` — true if any code block / fenced code block / inline code span (`markdown.go:396`)
- `Property.HasTaskList` — true if any task checkbox node (`markdown.go:399`)
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (`markdown.go:401-404`)
- `Property.Title` — text of the document's first block if it is an H1 heading (`markdown.go:384-388`)

(Note: `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property` into the memo payload.)
