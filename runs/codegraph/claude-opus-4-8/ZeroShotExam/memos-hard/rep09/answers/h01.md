**Details:** Attachments with `StorageType_S3` store their content in external S3-compatible object storage and expose it through presigned GET URLs that expire (5-day lifetime). The runner's `CheckAndPresign` (`server/runner/s3presign/runner.go:47`) lists S3 attachments in batches, and for any whose presigned URL is within 1 day of expiring (`LastPresignedTime + 4 days`), it re-signs the object and updates the attachment's `Reference`/payload — so the stored links never go stale.
