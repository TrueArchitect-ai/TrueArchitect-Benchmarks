The outbound HTTP delivery executes in the `Post` function, which marshals the payload, builds the POST request, signs it, and actually sends it via `safeClient.Do(req)`. Async dispatch (`PostAsync`) just enqueues onto a bounded channel whose worker goroutines call `Post`.

What stops it from hitting internal addresses is the shared `safeClient`'s custom transport `DialContext: safeDialContext`. At dial time, `safeDialContext` resolves the target host and rejects any resolved IP that falls in a reserved/private range (`isReservedIP`), which also defeats DNS-rebinding since the check happens on the actual dialed address rather than pre-validating the URL string.
