Each of these builds a `WebhookRequestPayload` (whose `URL` comes from the user's configured `WebhooksUserSetting_Webhook.Url`) and hands it to `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; the worker goroutines then call the delivery function.

**Convergence function — `webhook.Post`** at `internal/webhook/webhook.go:120`. This is the single function where every path converges and where the actual outbound HTTP request is issued (`safeClient.Do(req)` at line 152, building `http.NewRequest("POST", requestPayload.URL, …)`). `PostAsync` (line 184) is the shared enqueue point, and its queue-worker goroutines (the `init` at line 42) all invoke `Post`, so `Post` is the sole point of delivery.
