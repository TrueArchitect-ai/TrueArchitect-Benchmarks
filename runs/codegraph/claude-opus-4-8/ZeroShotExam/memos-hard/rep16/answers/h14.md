**Computation site**

The derived metadata is the memo's `Payload` — specifically `Payload.Tags` and `Payload.Property` (`MemoPayload_Property`). It is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll` — the single-pass extractor in `internal/markdown/markdown.go:356` (`service.ExtractAll`). `ExtractAll` parses the content into a goldmark AST and walks it once, filling an `ExtractedData` struct (`internal/markdown/markdown.go:21`). `RebuildMemoPayload` then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:85-86). (An equivalent standalone `ExtractProperties` exists at markdown.go:193, but the payload path uses `ExtractAll`.)

**Triggers (what causes recomputation)**

`RebuildMemoPayload` is invoked whenever content is written or migrated:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the memo is stored.
- `UpdateMemo` — via `RebuildMemoPayload` in the update path (`server/router/api/v1/memo_service.go` / `memo_update_helpers.go`, listed as a caller).
- `Runner.RunOnce` — `server/runner/memopayload/runner.go:27`, a background batch job (started from `server.go`) that re-derives the payload for all existing memos in batches of 100 and writes it back via `Store.UpdateMemo`.

It is recomputed from scratch each time — the walk always parses the current `memo.Content`.

**Extracted properties**

From the AST walk in `ExtractAll` (markdown.go:371-419), stored into `MemoPayload_Property` (`proto/gen/store/memo.pb.go:85`):
- `Tags` — all `#tag` nodes (deduplicated, case preserved), excluding tags inside links/images.
- `HasLink` — true if any `KindLink` node exists.
- `HasCode` — true if any code block, fenced code block, or inline code span exists.
- `HasTaskList` — true if any task checkbox exists.
- `HasIncompleteTasks` — true if any task checkbox is unchecked.
- `Title` — the plain text of the document's first block-level child when it is an H1 heading.

(`ExtractAll` also collects `Mentions`, but that isn't part of the stored `Property`. The `Snippet` field surfaced in list/preview responses is produced separately by `GenerateSnippet`, markdown.go:264, not by this property computation.)

The final `Property` is exposed on the API `Memo` as the "Output only. computed properties" field (`proto/gen/api/v1/memo_service.pb.go:251`), used for list/preview rendering.
