The provider abstraction is defined in the **`internal/idp`** package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` type used across all providers. The concrete protocol implementation that ships is the **`internal/idp/oauth2`** package (`internal/idp/oauth2/oauth2.go`), whose package comment reads "Package oauth2 implements the OAuth2 identity provider integration" and provides `IdentityProvider`, `NewIdentityProvider`, `ExchangeToken`, and `UserInfo`.

This is confirmed by `server/router/api/v1/auth_service_sso.go` (lines 12–13), which imports both packages, and its `resolveSSOIdentity` (line 104) dispatches on `storepb.IdentityProvider_OAUTH2` — the only provider type wired up — calling `oauth2.NewIdentityProvider`.
