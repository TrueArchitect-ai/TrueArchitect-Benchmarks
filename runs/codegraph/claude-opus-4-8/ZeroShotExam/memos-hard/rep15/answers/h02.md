**Delivery function** — `Post` in `internal/webhook/webhook.go:120`. This is where the outbound HTTP POST actually executes: it marshals the payload, builds the request, adds the optional HMAC signature headers, and fires it with `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. **Protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go:32-37`). Before dialing, it resolves the target hostname via `net.DefaultResolver.LookupHost` and rejects the connection if any resolved IP is in a reserved/private range (`isReservedIP`), returning `"webhook: connection to reserved/private IP address is not allowed"`. Because the check happens at dial time on the actually-resolved IPs, it also defeats DNS-rebinding attempts to reach internal addresses.
