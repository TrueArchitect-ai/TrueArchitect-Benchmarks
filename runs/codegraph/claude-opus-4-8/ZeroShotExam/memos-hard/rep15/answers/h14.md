**Computation site**

`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` populates the derived metadata by calling `markdownService.ExtractAll([]byte(memo.Content))` and assigning the result onto the memo's payload:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

The actual extraction happens in `service.ExtractAll` in `internal/markdown/markdown.go:356`, which does a single goldmark AST walk over the memo content.

**Triggers (operations that recompute it)**

`RebuildMemoPayload` has three callers (all in `server/router/api/v1/memo_service.go` and the runner itself):
- `CreateMemo` — on memo creation
- `UpdateMemo` — on memo update (content change)
- `RunOnce` (`server/runner/memopayload/runner.go:27`) — a batch runner that rebuilds the payload of *all* memos (100 at a time), used for backfill/migration after logic changes.

**Extracted properties**

Written into `MemoPayload` (`proto/gen/store/memo.pb.go`):
- `Tags` — deduplicated `#tag` list (case preserved)
- `Property` (`MemoPayload_Property`), computed during the AST walk in `ExtractAll`:
  - `Title` — text of the first block if it's a level-1 (H1) heading (`markdown.go:387`)
  - `HasLink` — true if any link node exists (`KindLink`)
  - `HasCode` — true for code block / fenced code block / code span
  - `HasTaskList` — true if any task checkbox exists
  - `HasIncompleteTasks` — true if any task checkbox is unchecked

(Note: `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` onto the payload.)
