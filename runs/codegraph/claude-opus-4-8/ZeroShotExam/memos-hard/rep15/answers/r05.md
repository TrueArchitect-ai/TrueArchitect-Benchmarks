**Premise correction:** This repository (Memos) has **no GraphQL schema** — there is no GraphQL server, SDL/`.graphql` file, or GraphQL dependency anywhere in the tree. `grep` for `graphql` returns nothing in the Go/TS sources or `go.mod`. The public API is **not** GraphQL.

**Actual API surface — Protocol Buffers / gRPC (with a REST gateway):**

The public API "schema" is defined as protobuf service definitions in `proto/api/v1/`:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Supporting pieces:
- `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock` — buf config that generates code from those protos into `proto/gen/`.
- These are served as **gRPC + gRPC-gateway (JSON/REST)**, wired up in `server/server.go` and `server/router/api/v1/v1.go`.
- An **OpenAPI** document is also generated/embedded (`proto/openapi_embed.go`) and there's an **MCP** adapter with its own OpenAPI/JSON-schema layer under `server/router/mcp/` (e.g. `server/router/mcp/openapi.go`).

So the closest thing to a "public API schema" lives in the `.proto` files under `proto/api/v1/`, exposed over gRPC and a REST gateway — never GraphQL.
