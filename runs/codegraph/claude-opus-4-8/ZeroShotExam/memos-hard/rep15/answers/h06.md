**RPC handler methods that can transitively trigger an outbound webhook HTTP request to a user-configured URL** (all in `server/router/api/v1/memo_service.go` / `memo_service_comments.go`):

- `APIV1Service.CreateMemo` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook`
- `APIV1Service.UpdateMemo` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service.go:513`)
- `APIV1Service.DeleteMemo` → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service.go:562`)
- `APIV1Service.CreateMemoComment` → `DispatchMemoCommentCreatedWebhook` (in `memo_service_comments.go`)

Each dispatch reads the target URLs from the user's configured webhooks (`GetUserWebhooks`) and builds a `WebhookRequestPayload{URL: ...}`.

**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

All of those paths funnel through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto `asyncPostQueue`; the pool of worker goroutines started in `init` (line 42–55) then calls `Post`, and `Post` is the single function that marshals the payload, constructs the `POST` request to `requestPayload.URL`, and issues the actual outbound HTTP call via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).

So: the API-layer choke point is `webhook.PostAsync`, and the function where every path converges immediately before the network delivery is `webhook.Post` (`internal/webhook/webhook.go:120`).
