**delivery function** — `Post` in `internal/webhook/webhook.go` (the actual outbound HTTP request executes at `internal/webhook/webhook.go:152` via `safeClient.Do(req)`). This is invoked from a pool of async worker goroutines fed by `PostAsync` (`internal/webhook/webhook.go:184`), which the memo dispatch handlers in `server/router/api/v1/memo_service_webhooks.go` call when memos are created/updated/deleted or commented on.

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59` (wired into the shared `safeClient`'s `http.Transport.DialContext` at `internal/webhook/webhook.go:32-37`). At dial time it resolves the target hostname and rejects any resolved address that falls in a reserved/private IP range via `isReservedIP` (`internal/webhook/webhook.go:70-74`). Because the check happens on the actually-resolved IPs at connection time rather than on the URL string, it also defeats DNS-rebinding attempts to reach internal addresses.
