delivery function — `Post` at `internal/webhook/webhook.go:120` (it builds the POST request and executes it via `safeClient.Do(req)` at line 152; `PostAsync` at line 184 enqueues onto a bounded queue whose worker goroutines call `Post`).

protection mechanism — the shared `safeClient`'s custom transport dialer `safeDialContext` at `internal/webhook/webhook.go:59`, which resolves the target hostname and rejects any resolved address in a reserved/private range via `isReservedIP` (`internal/webhook/webhook.go:70-74`). Because the check runs at dial time on the actually-resolved IPs, it also defeats DNS-rebinding attempts.

Note: this guards only the network connection. The URL string itself is validated at webhook-registration time in `server/router/api/v1/user_service_webhooks.go` (`CreateUserWebhook`/`UpdateUserWebhook`), but the dial-time `safeDialContext` is what actually prevents delivery to internal addresses.
