delivery function — `Post` in `internal/webhook/webhook.go:120` (the actual outbound send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`); protection mechanism — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go:32-37`)

The webhook payload's target URL comes from user-configured webhooks and is POSTed by `Post` (invoked synchronously, or asynchronously via `PostAsync` → the `asyncPostQueue` worker goroutines in `init`). Rather than validating the URL string up front, protection happens at dial time: `safeDialContext` resolves the hostname with `net.DefaultResolver.LookupHost` and rejects the connection if any resolved IP satisfies `isReservedIP` (a reserved/private range). Because the check runs on the *resolved* address at connect time, it also defeats DNS-rebinding attacks that a one-time URL parse would miss.
