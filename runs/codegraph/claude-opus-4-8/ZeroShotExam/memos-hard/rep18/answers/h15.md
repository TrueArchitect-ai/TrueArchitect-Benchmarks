Memo visibility (who may view a memo) is enforced at these distinct server surfaces:

`checkMemoReadAccess` (single-memo view gate: NotFound for archived non-owner, Unauthenticated/PermissionDenied for protected/private) — `server/router/api/v1/memo_service.go` (lines 39–68; called by `GetMemo` and the comment-parent check)

`ListMemos` (constrains the list query's `VisibilityList`/filter: anonymous → PUBLIC only; authenticated non-owner → PUBLIC+PROTECTED, own → all) — `server/router/api/v1/memo_service.go` (lines 218–227)

`ListMemoComments` (builds a `memoFilter` so returned comment memos are restricted by viewer: anonymous → PUBLIC, authenticated → own or PUBLIC/PROTECTED) — `server/router/api/v1/memo_service_comments.go` (lines 156–161; also gated by `checkMemoReadAccess` on the parent at line 148)

RSS feed (lists only PUBLIC memos via `VisibilityList: [store.Public]`) — `server/router/rss/rss.go` (lines 90, 141)

Frontend sitemap (lists only PUBLIC memos via `VisibilityList: [store.Public]`) — `server/router/frontend/frontend.go` (line 150)
