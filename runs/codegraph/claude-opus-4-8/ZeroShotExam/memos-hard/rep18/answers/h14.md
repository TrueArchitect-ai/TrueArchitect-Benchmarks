**Computation site:** The derived metadata (the memo's `Payload`) is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual content analysis to the goldmark-based `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356`. `RebuildMemoPayload` writes the result into `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85–86).

**Triggers (operations that recompute it):**
- **Memo creation** — `CreateMemo` calls `memopayload.RebuildMemoPayload` before persisting (`server/router/api/v1/memo_service.go:108`).
- **Memo update** — the update path invokes `RebuildMemoPayload` when content changes (the call graph shows `UpdateMemo → RebuildMemoPayload`, via `server/router/api/v1/memo_update_helpers.go` / `memo_service.go`).
- **Bulk backfill/migration** — the `memopayload.Runner.RunOnce` batch job re-runs `RebuildMemoPayload` over all memos and writes the payload back via `UpdateMemo` (`server/runner/memopayload/runner.go:27–71`).

So recomputation is content-driven: any create/update of a memo's content, plus the one-shot rebuild runner.

**Extracted properties** (from `ExtractAll`, single AST walk, `internal/markdown/markdown.go:356–422`):
- `Tags` — all `#tags`, deduplicated preserving case (also collects `Mentions` internally).
- `Property.Title` — text of the document's first block if it is an H1 heading.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block / fenced code block / inline code span is present.
- `Property.HasTaskList` — true if any task checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

These live on the `MemoPayload_Property` message (`proto/gen/store/memo.pb.go`) and are what lists/previews read.
