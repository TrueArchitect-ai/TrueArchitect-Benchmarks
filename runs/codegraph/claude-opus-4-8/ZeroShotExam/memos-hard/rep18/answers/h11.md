## How I determined this

The data layer is the `store/` package (`/bench/home/work/store/`), where the persistent entity types are defined — e.g. `Memo` (`store/memo.go`), `User` (`store/user.go`), `Attachment` (`store/attachment.go`), `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `InstanceSetting`, `IdentityProvider`.

Counting distinct Go packages **outside the `store/` tree** that reference each type (`store.<Type>`):

| Rank | Type | Packages |
|------|------|----------|
| 1 | `User` | ~7 |
| 2 | `Memo` | ~6 |
| | Attachment | ~4 |

`store.User` is referenced from `server/auth`, `server/notification`, `server/router/api/v1` (+ its `test`), `server/router/fileserver`, `server/router/frontend`, and `server/router/rss` — **7 packages**.

`store.Memo` is referenced from `server/notification`, `server/router/api/v1` (+ `test`), `server/router/frontend`, `server/router/rss`, and `server/runner/memopayload` — **6 packages**.

(The ordering is stable regardless of whether you also count the in-layer DB-driver subpackages under `store/db/*`: including them gives User = 11, Memo = 10, still User then Memo.)

**Answer: 1st: User (~7 packages); 2nd: Memo (~6 packages).**
