**Delivery function** — `Post` at `internal/webhook/webhook.go:120`. This is where the outbound HTTP request is actually built and sent: it marshals the payload, constructs the `POST`, adds the optional HMAC-SHA256 signature headers, and executes the request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. Callers live in `server/router/api/v1/memo_service_webhooks.go`.)

**Protection mechanism** — `safeDialContext` at `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go:32-37`). At dial time it splits the address, resolves the hostname via `net.DefaultResolver.LookupHost`, and rejects the connection if any resolved IP is a reserved/private address per `isReservedIP` (`internal/webhook/webhook.go:71`). Because the check runs on the *resolved* IPs at dial time rather than on the URL string, it also defeats DNS-rebinding attempts. A blocked target returns `"webhook: connection to reserved/private IP address is not allowed"`.

So: delivery function — `Post`, `internal/webhook/webhook.go:120` (send at line 152); protection mechanism — `safeDialContext`/`isReservedIP` installed on `safeClient`'s transport, `internal/webhook/webhook.go:59` (and 32-37).
