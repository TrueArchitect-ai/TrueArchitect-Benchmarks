**Computation site**

`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, then calls `markdownService.ExtractAll([]byte(memo.Content))` (goldmark-based markdown service, `internal/markdown/markdown.go`) to parse the content in a single pass and writes the results into the store-layer `MemoPayload` (`memo.Payload.Tags` and `memo.Payload.Property`). This is the derived metadata stored in the `payload` DB column (`proto/gen/store/memo.pb.go`, `MemoPayload_Property`) and surfaced to the API as `Memo.Property` for lists/previews.

**Triggers (operations that recompute it)**

- **Create** — `APIV1Service.CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before persisting (`server/router/api/v1/memo_service.go:108`).
- **Update** — the update path invokes `RebuildMemoPayload` when content changes (`UpdateMemo → RebuildMemoPayload` in `server/router/api/v1/memo_service.go` / `server/router/api/v1/memo_update_helpers.go`), then writes `Payload` via `store.UpdateMemo`.
- **Bulk backfill** — the background runner `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) iterates all memos in batches of 100, calls `RebuildMemoPayload` for each, and persists the new payload with `Store.UpdateMemo`.

Persistence of the recomputed payload happens through `store.UpdateMemo` / `CreateMemo`, which marshal `Payload` into the `payload` column in each driver (`store/db/{sqlite,postgres,mysql}/memo.go`).

**Extracted properties**

`ExtractAll` returns `ExtractedData` whose fields become:
- `Payload.Tags` — the list of `#tags` found in the content.
- `Payload.Property` (`MemoPayload_Property`), the boolean flags computed from the content AST: `HasLink`, `HasTaskList`, `HasCode`, and `HasIncompleteTasks` (see `proto/gen/store/memo.pb.go:127-149` and the mirrored API `Memo_Property` in `proto/gen/api/v1/memo_service.pb.go:2222-2244`).
