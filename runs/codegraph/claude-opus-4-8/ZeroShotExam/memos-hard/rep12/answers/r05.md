**Premise correction:** This repository (Memos) does **not** define a GraphQL schema at all — there is no GraphQL server, resolver, `.graphql` file, or `graphql` dependency anywhere in the codebase (a repo-wide search for "graphql" in Go/TS sources returns nothing). The public API is not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC service definitions** under `proto/api/v1/`, compiled by [Buf](https://buf.build):

- **Schema source of truth** — `proto/api/v1/*.proto`, one file per service:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/common.proto`
  - (plus `proto/store/*.proto` for internal storage types, not the public API)

- **Build config** — `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`.

- **Generated code** driven by `proto/buf.gen.yaml`:
  - Go gRPC/Connect stubs and a **grpc-gateway REST/HTTP interface** → `proto/gen/`
  - An **OpenAPI (Swagger) document** via the gnostic-openapi plugin (the only "schema document" the public API exposes, the GraphQL-equivalent artifact)
  - TypeScript client types → `web/src/types/proto/`

So the transport is **gRPC + Connect + a grpc-gateway REST façade**, described by OpenAPI — defined in the `.proto` files under `proto/api/v1/`, not GraphQL. (Separately, `server/router/mcp/openapi.go` builds JSON Schemas for the MCP tool endpoints — also not GraphQL.)
