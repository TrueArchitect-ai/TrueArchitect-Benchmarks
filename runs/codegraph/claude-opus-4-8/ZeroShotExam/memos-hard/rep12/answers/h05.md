**Mechanism: by explicit Go code.** When a user is deleted, their emoji reactions are removed by explicit `DELETE FROM reaction` statements inside the delete-user transaction — there is no database-level cascade rule (the `reaction` table has no foreign key on `creator_id`/`content_id`).

Two explicit deletes run in `deleteUserTargetsTx` for each DB backend:
- **Reactions on the user's memos** — `deleteReactionsByContentIDsTx`, which runs `DELETE FROM reaction WHERE content_id IN (...)` for the content IDs of the user's (recursively collected) memo tree.
- **Reactions authored by the user** — `deleteReactionsByCreatorTx`, which runs `DELETE FROM reaction WHERE creator_id = ?`.

Both happen inside the single `DeleteUser` transaction, so they commit atomically with the rest of the user deletion.
