## Interface
`markdown.Service` (`internal/markdown/markdown.go:31`) — a Go interface abstracting markdown parsing/extraction/rendering (ExtractAll, ExtractTags, ExtractProperties, RenderMarkdown, RenderHTML, GenerateSnippet, ValidateContent, RenameTag).

## Concrete implementation (executes at runtime)
There is exactly **one** implementation: the unexported `service` struct (`internal/markdown/markdown.go:58`), which wraps a `goldmark.Markdown` engine. All methods (e.g. `ExtractTags`, `parse`) hang off `*service` (`internal/markdown/markdown.go:116-170`). It is configured with GFM plus custom inline parsers — `tagParser`/`mentionParser` (`internal/markdown/parser/tag.go:19`, `internal/markdown/parser/mention.go:19`) — enabled via `WithTagExtension`/`WithMentionExtension`.

(The frontend does its own markdown handling with `mdast`/`micromark` in `web/src/utils/markdown-task-actions.ts`, but that is separate JS, not this Go interface.)

## Construction
- **Sole production constructor:** `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) returns `&service{...}`. It is called once in `NewAPIV1Service` (`server/router/api/v1/v1.go:48`) with `WithTagExtension()` + `WithMentionExtension()`. That single instance is the runtime implementation for the whole server.
- **Test constructor:** `markdown.NewService(...)` is also called in `server/router/api/v1/test/test_helper.go:44`.
- The RSS holder does **not** construct its own — it receives the shared instance: `rss.NewRSSService(..., apiV1Service.MarkdownService)` in `server/server.go:85`.

## Holders (components holding the interface)
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — primary holder; used in `memo_service.go:108,447`, `memo_service_webhooks.go:85`, `memo_mention_helpers.go:32`.
- `RSSService.MarkdownService` (`server/router/rss/rss.go:45`, ctor `:58`) — used at `rss.go:339` for `RenderHTML`; holds the same instance passed from the API service.
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`, ctor `NewRunner` `:19`) — a runner type that stores the interface; note `memopayload.NewRunner` has no production caller, but the package's `RebuildMemoPayload(ctx, memo, markdown.Service)` function (`runner.go:74`) takes the interface as a parameter and is invoked with `s.MarkdownService` from the API service (`memo_service.go:108,447`).

Net: one goldmark-backed `service` instance, built by `NewService` inside `NewAPIV1Service`, held by `APIV1Service`, and shared into `RSSService` (and passed into the `memopayload` rebuild path).
