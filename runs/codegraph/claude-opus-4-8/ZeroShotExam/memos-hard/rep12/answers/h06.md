## Answer

**RPC handler methods** (all in `server/router/api/v1/`) that can transitively trigger an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`)
3. **`DeleteMemo`** — `memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoRelations`** — `memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. **`SetMemoAttachments`** — `memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

**How they converge:** Each dispatch helper (`dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`) loads the user's configured webhooks via `Store.GetUserWebhooks`, sets `payload.URL = hook.Url`, and calls `webhook.PostAsync`. `PostAsync` enqueues onto `asyncPostQueue`, whose worker goroutines (started in `init`) all invoke the same delivery function.

**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

This is the single point where every path funnels before the network call: it marshals the payload, builds the `POST` to `requestPayload.URL`, optionally HMAC-signs it, and issues the actual outbound request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

(If you count "before delivery" as the pre-network enqueue point rather than the send itself, that shared point is `webhook.PostAsync` at `internal/webhook/webhook.go:184`; the function that actually performs delivery is `Post`.)
