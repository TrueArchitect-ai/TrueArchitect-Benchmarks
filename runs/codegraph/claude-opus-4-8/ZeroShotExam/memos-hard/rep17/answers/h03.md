The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type returned by any provider. The one concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), whose file header comment reads "Package oauth2 implements the OAuth2 identity provider integration" and provides `NewIdentityProvider`, `ExchangeToken`, and `UserInfo`.

**Answer:** `internal/idp` (abstraction); `internal/idp/oauth2` (implementation)

Note: OAuth2 is the sole implementation — the OIDC/Google/GitHub/GitLab options in the UI (`web/src/components/CreateIdentityProviderDialog.tsx`) are all just OAuth2 config templates, not separate provider packages.
