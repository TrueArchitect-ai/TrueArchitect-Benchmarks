A browser requesting another user's profile image hits the native file-serving route `GET /file/users/:identifier/avatar`. The handler loads the target user by username through the store, which reads the `avatar_url` column (a data URI holding the image bytes) from the `user` table via the DB driver, then decodes and streams it back.
