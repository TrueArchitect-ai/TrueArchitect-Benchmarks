**Computation site**

The derived metadata is the memo's `Payload` — specifically `MemoPayload.Tags` and `MemoPayload.Property` (the store proto). It is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`). `RebuildMemoPayload` parses the memo content and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:85-86). `ExtractAll` does a single goldmark AST walk to populate both.

**Triggers (recomputation)**

- **Create:** `CreateMemo` calls `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Update:** `UpdateMemo` calls it at `server/router/api/v1/memo_service.go:447` — only inside the branch where the memo's content changes (content is reassigned at line 446, then the payload is rebuilt).
- **Batch backfill:** the `Runner.RunOnce` job (`server/runner/memopayload/runner.go:27-72`) rebuilds the payload for *all* memos in batches of 100, persisting each via `UpdateMemo`.

The API layer then surfaces this stored payload to clients in `convertMemoFromStore`, copying `memo.Payload.Tags` and converting `memo.Payload.Property` (`server/router/api/v1/memo_service_converter.go:48-49`).

**Extracted properties**

From `ExtractAll` (`internal/markdown/markdown.go:376-419`):
- `Tags` — deduplicated list of memo tag names (`#tag` nodes).
- `Property.Title` — text of the document's leading H1 heading, if the first block is an H1.
- `Property.HasLink` — true if any link node exists.
- `Property.HasCode` — true if any code block, fenced code block, or inline code span exists.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but those are not stored on the payload; only `Tags` and `Property` are written by `RebuildMemoPayload`.)
