**Convergence function — where every path converges before the actual outbound request:**

`webhook.Post` — `internal/webhook/webhook.go:120`

Every handler path calls `PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the background workers started in `init` (line 42–55) drain that queue and call `Post`, which is the sole place the request is actually delivered via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

So: the paths converge at `webhook.PostAsync` (the shared enqueue point) and the single delivery function is `webhook.Post` — `internal/webhook/webhook.go:120`.
