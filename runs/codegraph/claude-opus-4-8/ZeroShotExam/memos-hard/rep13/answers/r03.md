**Premise correction: there is no nightly database-cleanup job in this codebase.** The question assumes one exists in "the cron scheduler," but no such job is scheduled anywhere.

What actually exists:

- `internal/scheduler/` is a **generic, standalone cron-scheduler library** (`Scheduler`, `Job`, `ParseCronExpression`, etc.). It is never imported, instantiated, or registered against by any production code — `grep` for `scheduler.New` / `.Register` outside the package and its tests returns nothing (the only `internal/scheduler` importers are the package's own test files). It is not wired into `server/server.go` or anywhere else.

- The only place a "2 AM" cleanup appears is **illustrative example code, not a real job**:
  - `internal/scheduler/doc.go:15-16` — a doc-comment example: `Name: "daily-cleanup"`, `Schedule: "0 2 * * *", // 2 AM daily`
  - `internal/scheduler/example_test.go:97-100` — an example test: `Name: "cleanup"`, `Schedule: "0 2 * * *"` ("Cleanup old data every night at 2 AM")

So if the "2 AM" figure is what prompted the question, note that it comes from documentation/test examples of the library's API — not from a registered database-cleanup job running in a scheduler.

(Separately, the only real recurring cleanup in the codebase is the in-memory cache's `cleanupLoop` in `store/cache/cache.go:200`, which runs on a `time.Ticker` at `config.CleanupInterval` — an interval, not a cron time, and unrelated to any database or the cron scheduler.)
