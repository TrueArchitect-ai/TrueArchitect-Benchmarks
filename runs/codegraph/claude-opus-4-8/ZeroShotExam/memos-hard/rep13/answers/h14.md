**Computation site**

`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`). `RebuildMemoPayload` copies the extracted data onto the memo's stored payload:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

This populates the memo's output-only `Tags` and `Property` fields (`proto/gen/api/v1/memo_service.pb.go:242,252`), which lists/previews consume — e.g. the snippet/preview rendering. The actual extraction logic (the single AST walk) lives in `ExtractAll` at `internal/markdown/markdown.go:356-422`.

**Triggers (operations that cause recomputation)**

Everything runs `ExtractAll` against `memo.Content`, so the payload is recomputed whenever content is (re)written:

- **Create** — `APIV1Service.CreateMemo` calls `memopayload.RebuildMemoPayload(...)` at `server/router/api/v1/memo_service.go:108` (comments go through the same path).
- **Update** — `APIV1Service.UpdateMemo` calls `RebuildMemoPayload` when content changes (in the memo-update flow, `server/router/api/v1/memo_service.go` / `memo_update_helpers.go`).
- **Bulk backfill** — the `memopayload.Runner.RunOnce` batch job (`server/runner/memopayload/runner.go:27`) rebuilds the payload of all memos in batches of 100 and writes each back via `Store.UpdateMemo`.

**Extracted properties**

From the single AST walk in `ExtractAll` (`internal/markdown/markdown.go:356-422`):

- `Tags` — all `#tag` nodes (excluding tags inside links/images), deduplicated while preserving case (`internal/markdown/markdown.go:376-378,418`).
- `Property` (`Memo_Property`, `proto/gen/api/v1/memo_service.pb.go:2180`):
  - `Title` — plain text of the first block if it is an H1 heading (`markdown.go:384-388`).
  - `HasLink` — true if any link node is present (`KindLink`).
  - `HasCode` — true for any code block, fenced code block, or inline code span.
  - `HasTaskList` — true if any task checkbox exists.
  - `HasIncompleteTasks` — true if any task checkbox is unchecked (`markdown.go:399-405`).

(`ExtractAll` also collects `Mentions`, but that is used for mention notifications, not stored in the memo payload — only `Tags` and `Property` are assigned in `RebuildMemoPayload`.)
