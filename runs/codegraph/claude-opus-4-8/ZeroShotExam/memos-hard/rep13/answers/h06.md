**RPC handlers (all on `MemoService`) that can transitively trigger an outbound HTTP request to a user-configured webhook URL:**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` (activity `memos.memo.created`).
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` (`memos.memo.updated`).
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` (`memos.memo.deleted`).
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook` (`memos.memo.comments.created`).

The URLs come from each user's `WebhooksUserSetting_Webhook.Url` (`proto/gen/store/user_setting.pb.go:917`), loaded via `GetUserWebhooks` inside the dispatch helpers in `server/router/api/v1/memo_service_webhooks.go`.

**Convergence function — `Post`, `internal/webhook/webhook.go:120`**

All four paths call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the four background workers started in `init` each pull from that queue and call **`Post`**, which is the single function that marshals the payload, signs it, and issues the actual outbound request via `safeClient.Do(req)` (`webhook.go:152`) to `requestPayload.URL`.

So: paths converge at `webhook.PostAsync` (shared enqueue) and then at `webhook.Post` (`internal/webhook/webhook.go`), where the HTTP request is actually sent.
