**impl — construction — holders**

**The interface**
`markdown.Service` (`internal/markdown/markdown.go:31-55`) is the abstraction for backend markdown processing (`ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, `RenameTag`).

**Concrete implementation(s) at runtime**
- `*service` (`internal/markdown/markdown.go:57-60`) is the sole concrete implementation. It wraps a configured `goldmark.Markdown` (`md goldmark.Markdown`) and satisfies every `Service` method (e.g. `RenderHTML` at line 255 calls `s.md.Convert`; `ExtractTags` at line 143 walks the goldmark AST).
- Internally `*service` drives helper types that are **not** themselves behind the interface: the goldmark AST-back-to-markdown `renderer.MarkdownRenderer` (`internal/markdown/renderer/markdown_renderer.go:15`, created via `NewMarkdownRenderer`) used by `RenderMarkdown`/`RenameTag`, plus the custom inline parsers `tagParser` and `mentionParser` (`internal/markdown/parser/tag.go:19`, `internal/markdown/parser/mention.go:19`) wired in through the Tag/Mention extensions.

**Construction**
- `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) builds and returns a `*service`.
- The only production caller is `NewAPIV1Service` (`server/router/api/v1/v1.go:48-51`), which constructs it once with `markdown.WithTagExtension()` and `markdown.WithMentionExtension()` and stores it in `APIV1Service.MarkdownService`.
- Tests construct it separately in `server/router/api/v1/test/test_helper.go:44`.

**Holders (components holding the interface)**
- `APIV1Service.MarkdownService markdown.Service` (`server/router/api/v1/v1.go:35`) — the owner; used throughout the API layer (e.g. `memo_mention_helpers.go:32`, `memo_service_webhooks.go:85`, and passed into `memopayload.RebuildMemoPayload` at `memo_service.go:108,447`).
- `rss.RSSService.MarkdownService markdown.Service` (`server/router/rss/rss.go:45`) — constructed in `server/server.go:85` by passing `apiV1Service.MarkdownService` into `NewRSSService`; used for RSS HTML rendering (`rss.go:339`).
- `memopayload.Runner.MarkdownService markdown.Service` (`server/runner/memopayload/runner.go:16`) — a struct field set via `NewRunner`; note the runner's `RebuildMemoPayload` is in practice invoked as a free function with `s.MarkdownService` passed in, and I found no production call to `memopayload.NewRunner`, so this holder exists in code but the runtime path flows through the function-argument form.

Net: the single live instance is one `*service` created in `NewAPIV1Service`, shared by `APIV1Service` and (via `server.go`) the `RSSService`.
