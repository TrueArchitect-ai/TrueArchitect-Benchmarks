h15.

Memo visibility (who may view a memo) is enforced at multiple distinct server surfaces. The distinct enforcement sites:

GetMemo single-read access check (`checkMemoReadAccess`, private→creator-only, protected→auth required) — server/router/api/v1/memo_service.go:39
ListMemos visibility filtering (injects `visibility in ["PUBLIC","PROTECTED"]` / `VisibilityList` per current user) — server/router/api/v1/memo_service.go:218
Memo comments access check (blocks commenting/viewing on a private related memo) — server/router/api/v1/memo_service_comments.go:41
File/attachment server permission check (private memo attachment → creator/admin only) — server/router/fileserver/fileserver.go:699
RSS feed generation (restricts to `VisibilityList: [Public]`) — server/router/rss/rss.go:90

The first four are the primary access-control enforcement points; the RSS feed is a further surface that only ever emits public memos.
