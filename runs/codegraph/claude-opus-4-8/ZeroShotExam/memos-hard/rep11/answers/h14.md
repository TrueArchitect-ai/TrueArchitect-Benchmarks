**Computation site**

The derived metadata is the memo's `Property` (`MemoPayload_Property`) plus `Tags`, stored on the memo's payload. It is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark-based markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`). `RebuildMemoPayload` assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (lines 85-86). `ExtractAll` does a single AST walk and sets the fields based on node kinds (`internal/markdown/markdown.go:371-411`).

**Triggers (operations that recompute)**

1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` before storing.
2. **UpdateMemo** — `server/router/api/v1/memo_service.go:447` calls it, but only when the `content` field is in the update mask (`contentUpdated` branch, lines 436-451). Non-content updates (visibility, pinned, etc.) do not recompute the property.
3. **The memopayload runner's `RunOnce`** — `server/runner/memopayload/runner.go:27` — a batch backfill that rebuilds the payload for all existing memos (e.g. on migration/startup), calling `RebuildMemoPayload` then `UpdateMemo` per memo.

**Extracted properties**

From `ExtractAll` (`internal/markdown/markdown.go`):
- `Tags` — all `#tag` nodes (`data.Tags`, line 377).
- `Property.HasLink` — true if any `KindLink` node exists (line 394).
- `Property.HasCode` — true if any code block / fenced code block / inline code span exists (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`, line 397).
- `Property.HasTaskList` — true if any task checkbox exists (`KindTaskCheckBox`, line 400).
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (lines 401-404).
- `Property.Title` — text of the first block-level child if it is an H1 heading (`extractHeadingText`, lines 383-388).

(`ExtractAll` also collects `Mentions`, but that is used for mention-notification resolution rather than being stored in the payload property.)

The property fields are defined in `proto/gen/store/memo.pb.go:85` (`MemoPayload_Property`: `HasLink`, `HasTaskList`, `HasCode`, `HasIncompleteTasks`, `Title`) and surfaced to the API as `Memo_Property`, which the frontend uses for list rendering/previews.
