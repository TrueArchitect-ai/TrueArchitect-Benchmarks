**1st: User** (~7 outside packages); **2nd: Memo** (~6 outside packages)

Of the persistent entity types defined in the data layer (`store/` package — e.g. `User`, `Memo`, `Attachment`, `MemoRelation`, `MemoShare`, `Reaction`, `Inbox`, `IdentityProvider`, `InstanceSetting`, etc., defined in files like `store/user.go:29`, `store/memo.go:35`, `store/attachment.go:16`), `store.User` is referenced from the most packages outside the store layer, followed by `store.Memo`.

Excluding the data layer itself (`store/`, including `store/db/{sqlite,postgres,mysql}` and `store/test`), the distinct referencing packages are:

- **`store.User` — ~7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — ~6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

(`store.Attachment` is next at ~5 packages.) User leads because, beyond the API/RSS/frontend paths that also touch Memo, it is additionally consumed by the auth and fileserver packages.
