**No.** The MySQL driver constructor `mysql.NewDB` is called in exactly one place, the driver-selection factory itself.

Evidence:
- `store/db/db.go:14` defines the factory `NewDBDriver`, which switches on `profile.Driver` and calls `mysql.NewDB(profile)` at `store/db/db.go:22` for the `"mysql"` case.
- The constructor itself is `mysql.NewDB` at `store/db/mysql/mysql.go:20`.
- A repository-wide grep for `mysql.NewDB` and imports of `store/db/mysql` returns only `store/db/db.go` (the import on line 8 and the call on line 22) — including test files, there are no other matches. By contrast, `sqlite.NewDB` is constructed directly outside the factory (e.g. `store/demo_seed_test.go:24`, `store/deployment_config_test.go:416`), but MySQL is not.

So outside `NewDBDriver`, the MySQL driver is never constructed directly anywhere in the codebase.
