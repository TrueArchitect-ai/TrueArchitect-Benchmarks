**Convergence function — where every path converges before the actual HTTP delivery:**

`webhook.Post` — **`internal/webhook/webhook.go:120`**

This is the single function that marshals the payload, builds the `POST` request to the user-configured `payload.URL`, signs it, and issues the outbound request via `safeClient.Do(req)` (line 152). The async worker goroutines started in `init()` (`webhook.go:42–55`) drain the queue by calling `Post`, so both the synchronous and asynchronous paths terminate there.
