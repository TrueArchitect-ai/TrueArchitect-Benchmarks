**Premise correction: this project has no GraphQL API.** There is no GraphQL schema file, no GraphQL library in `go.mod` or `web/package.json`, and no mention of GraphQL anywhere in the source tree.

**Actual API surface:** the public API is **gRPC-defined with an HTTP/JSON gateway**:

- The schema equivalent lives in Protocol Buffer service definitions under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated Go stubs in `proto/gen/api/v1/` and TypeScript client types in `web/src/types/proto/api/v1/`.
- The handlers implementing those services are in `server/router/api/v1/` (`APIV1Service`), exposed to browsers as REST-style JSON via gRPC-Gateway, registered in `NewServer` at `server/server.go:88` (`apiV1Service.RegisterGateway(...)`), plus Connect-protocol handlers in `server/router/api/v1/connect_services.go`.
- Additional non-gRPC surfaces: an SSE stream (`server/router/api/v1/sse_hub.go`), native file serving at `/file/...` (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/`), and a `/healthz` check (`server/server.go:67`).
