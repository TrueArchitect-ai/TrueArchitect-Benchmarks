**Convergence function:** all of these paths funnel through the memo dispatch helpers (`dispatchMemoRelatedWebhook` at `memo_service_webhooks.go:48` and the comment variant at `:30`), each of which calls the single delivery entry point **`webhook.PostAsync`** — `internal/webhook/webhook.go:184`. `PostAsync` enqueues onto the async queue drained by worker goroutines that call `webhook.Post` (`internal/webhook/webhook.go:120`), where the actual outbound HTTP POST to the user-configured URL executes.

If the intended "single convergence function before delivery" is the one where every path meets, that is `webhook.PostAsync` (`internal/webhook/webhook.go:184`); the actual network send happens one hop later in `webhook.Post` (`internal/webhook/webhook.go:120`).
