**Premise correction: there is no nightly database-cleanup job, and the cron scheduler isn't even wired into the server.**

Two separate corrections:

1. **No database-cleanup job exists.** Nothing in the codebase schedules a periodic database cleanup/vacuum/purge. The only recurring background work the server starts is the S3 presign refresher, which runs every 12 hours on a plain `time.Ticker` (`server/runner/s3presign/runner.go:27-41`, started from `server/server.go:153-174`) — no cron expression and no fixed time of day. The only other periodic activity is the in-memory cache's expired-entry sweep every 5 minutes (`store/cache/cache.go`, config at `store/store.go:42`), which is cache housekeeping, not database cleanup.

2. **The cron scheduler is unused in production.** The repository does contain a full cron scheduler package (`internal/scheduler/scheduler.go`, with cron parsing in `internal/scheduler/parser.go`), but the only files importing it are its own tests and examples (`internal/scheduler/integration_test.go`, `internal/scheduler/example_test.go`). No server code registers any job with it, so no job — cleanup or otherwise — has a scheduled run time.
