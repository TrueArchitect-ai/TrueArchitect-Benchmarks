h15.

Memo visibility (Public / Protected / Private) is enforced at many independent surfaces. The distinct enforcement sites:

- **Single memo read (GetMemo / gRPC-API)** — `checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39` (rejects non-public memos for anonymous users, and Private memos for non-creators).
- **Memo list query (ListMemos)** — visibility-scoped query construction — `server/router/api/v1/memo_service.go:217-225` (anonymous → `VisibilityList = [PUBLIC]`; authenticated → CEL filter `creator_id == N || visibility in ["PUBLIC","PROTECTED"]`).
- **SSE real-time event delivery** — `SSEClient.canReceive` — `server/router/api/v1/sse_hub.go:134` (Private events only go to the creator or an admin), with the event's visibility populated in `server/router/api/v1/sse_event_helpers.go:29`.
- **Attachment binary serving (native file server)** — `checkAttachmentPermission` — `server/router/fileserver/fileserver.go:650` (checks `memo.Visibility` at lines 677 and 699).
- **Attachment access via API** — `checkAttachmentAccess` — `server/router/api/v1/attachment_service.go:422` (Private check at line 451).
- **Reactions** — `server/router/api/v1/reaction_service.go:38` (list) and `:83` (upsert): Private memos' reactions restricted to creator/superuser.
- **Comment creation** — `server/router/api/v1/memo_service_comments.go:41` (can't comment on another user's Private memo).
- **Set memo attachments** — `server/router/api/v1/memo_attachment_service.go:222`.
- **RSS feeds** — `server/router/rss/rss.go:90` and `:141` (feeds include only `store.Public`).
- **Frontend SSR / sitemap** — `server/router/frontend/frontend.go:150` (`VisibilityList: [store.Public]`).
- **Mention / notification eligibility** — `canViewerAccessMemo` — `server/router/api/v1/user_service_notifications.go:302`; `canUserAccessMentionContext` — `server/router/api/v1/memo_mention_helpers.go:56` (`:62`, `:67`); and email dispatch gating in `server/notification/email.go:313-316`.

The three core "who may view a memo" surfaces are the single-read check (`memo_service.go:39`), the list-query scoping (`memo_service.go:217`), and the SSE delivery filter (`sse_hub.go:134`); the attachment, reaction, comment, RSS, frontend, and notification sites extend the same rules to their respective surfaces.
