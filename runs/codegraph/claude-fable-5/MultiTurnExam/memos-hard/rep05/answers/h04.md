**No.** The MySQL driver is only ever constructed inside the driver-selection factory.

Evidence:

- The driver's only constructor is `NewDB` in `store/db/mysql/mysql.go:20`, which returns a `store.Driver`.
- A repo-wide search for callers of `mysql.NewDB` finds exactly one call site: the factory `NewDBDriver` in `store/db/db.go:22`, inside the `case "mysql":` branch of its driver switch.
- More conclusively, `store/db/db.go:8` is the **only file in the entire codebase that imports `github.com/usememos/memos/store/db/mysql`** (outside the package's own files). Since Go requires an import to reference the package, no other code — including tests — can construct the MySQL driver directly. Everything else works through the `store.Driver` interface returned by the factory.
