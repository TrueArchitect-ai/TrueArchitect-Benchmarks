**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp` (`internal/idp/idp.go`) defines the provider abstraction — the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that any provider integration normalizes user data into.
- `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) is the one concrete protocol implementation that ships: an OAuth 2.0 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and returning the `idp.IdentityProviderUserInfo` from the abstraction package. It's the only subpackage under `internal/idp` — no SAML/LDAP or other protocol implementations exist in the repo.
