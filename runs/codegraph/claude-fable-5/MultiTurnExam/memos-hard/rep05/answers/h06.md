**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. Every dispatch path calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto the async queue drained by worker goroutines that all call `Post`; `Post` is the single function that marshals the payload and actually executes the outbound HTTP request (`safeClient.Do`) to the user-configured hook URL.
