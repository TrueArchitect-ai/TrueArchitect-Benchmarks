All these paths build a `webhook.WebhookRequestPayload` with the user-configured webhook URL (fetched from `Store.GetUserWebhooks` in `server/router/api/v1/memo_service_webhooks.go`) and hand it to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded channel. The worker goroutines started in the package `init` drain that queue and every payload — regardless of which handler produced it — is delivered by the single function `webhook.Post` (`internal/webhook/webhook.go:120`), which signs the request and sends it through the SSRF-guarded `safeClient`.
