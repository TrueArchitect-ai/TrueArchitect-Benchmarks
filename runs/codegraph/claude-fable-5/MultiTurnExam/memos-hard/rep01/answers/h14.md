**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74` — which delegates the actual parsing to `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`), a single goldmark AST walk. The result is stored in the memo's `Payload` (`memo.Payload.Tags` and `memo.Payload.Property`, persisted as JSON in the `memo.payload` column).

**Triggers (recomputation happens whenever content is written):**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (before the initial insert); comment creation goes through the same path since `CreateMemoComment` creates a memo.
- `UpdateMemo`, but only when the update mask includes `content` — `server/router/api/v1/memo_service.go:447` (the rebuilt payload is written together with the new content).
- A batch backfill exists in `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`), which rebuilds payloads for all memos — but it is not invoked from production code.

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356-422`):

- `Tags` — all `#tag` occurrences, deduplicated case-preservingly
- `Mentions` — all `@username` mentions, lowercased and deduplicated (returned in `ExtractedData`; used for mention notifications)
- `Property.Title` — the text of an H1 heading if it is the document's first block
- `Property.HasLink` — any markdown link present
- `Property.HasCode` — any code block, fenced code block, or code span
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — task checkboxes present / any unchecked checkbox

(Field definitions: `storepb.MemoPayload_Property` in `proto/gen/store/memo.pb.go:87-92`.) These power list filtering and previews (e.g., filter expressions over `tags`, `has_link`, etc., and title/snippet display).
