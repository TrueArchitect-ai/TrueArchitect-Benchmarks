**Impl:** The interface is `markdown.Service` (`internal/markdown/markdown.go:31`). Exactly one concrete implementation exists and executes at runtime: the unexported `service` struct (`internal/markdown/markdown.go:58`), which wraps a `goldmark.Markdown` parser configured with GFM plus optional tag/mention extensions.

**Construction:** Only `markdown.NewService` (`internal/markdown/markdown.go:85`) creates it. In production it is constructed once, in `NewAPIV1Service` at `server/router/api/v1/v1.go:48`, with `WithTagExtension()` and `WithMentionExtension()` enabled. (The test helper `server/router/api/v1/test/test_helper.go:44` constructs it the same way for tests.)

**Holders of the interface:**
