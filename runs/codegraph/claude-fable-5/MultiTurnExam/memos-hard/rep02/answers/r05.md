**Premise correction: this project has no GraphQL API — no schema, resolvers, or GraphQL dependency exists anywhere** (grep for "graphql" across `server/`, `internal/`, `proto/`, `store/`, `web/src/`, `go.mod`, and `web/package.json` returns nothing).

Actual API surface:

- **The public API contract is defined in Protocol Buffers**, under `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), with generated code in `proto/gen/`.
- These services are served as **gRPC/Connect RPCs plus a JSON/REST mapping via gRPC-Gateway**, wired in `server/router/api/v1/v1.go` (Connect handlers with interceptors at lines ~133-141, gateway mux around line 95).
- Additional non-RPC HTTP surfaces registered in `server/server.go`: the binary file server (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), an MCP endpoint (`server/router/mcp/`), server-sent events (`server/router/api/v1/sse_hub.go`), and the embedded frontend (`server/router/frontend/`).
