**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider abstraction — the `idp` package with the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that any provider implementation returns.
- `internal/idp/oauth2/oauth2.go` is the one concrete protocol implementation that ships: an OAuth 2.0 identity provider client (used by the auth flow in the API layer, and configured through the SSO settings UI, e.g. `web/src/components/CreateIdentityProviderDialog.tsx`).
