This is the memo **payload** — `Tags` plus a `Property` message stored alongside the memo and used by list views/previews.

**Computation site**: `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll` (implemented at `internal/markdown/markdown.go:356`), which parses the content once with goldmark and fills `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`).

**Triggers**:
- Memo creation — `CreateMemo` handler calls it before insert (`server/router/api/v1/memo_service.go:108`); comment creation flows through the same path.
- Content update — `UpdateMemo` re-runs it whenever the `content` field is in the update mask (`server/router/api/v1/memo_service.go:447`).
- There is also a batch rebuilder, `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`), that would recompute all memos' payloads, but it isn't wired into production startup.

**Extracted properties** (per `internal/markdown/markdown.go:355-418` and `proto/store/memo.proto:15-22`):
- `Tags` — all `#tag` occurrences, deduplicated case-preservingly (`uniquePreserveCase`, markdown.go:418)
- `Property.Title` — text of the first H1 heading (markdown.go:387)
- `Property.HasLink` (markdown.go:394)
- `Property.HasCode` (markdown.go:397)
- `Property.HasTaskList` (markdown.go:400)
- `Property.HasIncompleteTasks` (markdown.go:403)
