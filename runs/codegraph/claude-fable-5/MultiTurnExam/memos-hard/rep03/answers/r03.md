**Premise correction: there is no nightly database-cleanup cron job — and in fact the cron scheduler is never used in production at all.** So there is no scheduled time to report.

What I checked:
- A cron scheduler package does exist (`internal/scheduler/`, with `New`, `Register`, cron parsing, etc.), but no non-test file anywhere in the repository imports it: a search for imports of `usememos/memos/internal/scheduler` returns nothing outside the package itself and its tests. The only references to `scheduler.New()`/`scheduler.Register(&scheduler.Job{...})` are in its own documentation (`internal/scheduler/doc.go`) and unit tests. It is never instantiated by the server.
- No database-cleanup job is registered anywhere. The only "cleanup" that runs is unrelated to a cron schedule: the in-memory cache's `CleanupInterval` (every 5 minutes, `store/store.go:42`) and inline attachment/relation cleanup during memo/user deletion (`server/router/api/v1/memo_service.go:579`, `server/router/api/v1/user_service.go:421-447`).

The server's only actual background job is the S3 presign runner, which runs every 12 hours on an interval (not a nightly clock time) — see `server/runner/s3presign/runner.go:27` and its wiring in `server/server.go:162-171`.
