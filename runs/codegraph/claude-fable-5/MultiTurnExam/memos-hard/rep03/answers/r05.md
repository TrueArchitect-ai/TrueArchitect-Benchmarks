**Premise correction: there is no GraphQL API in this codebase.** No GraphQL schema, library, or endpoint exists — `go.mod`, `web/package.json`, the server routers, and the docs contain no GraphQL references at all.

**Actual API surface**: the public API is **gRPC-based, defined with Protocol Buffers** and exposed over HTTP in two ways:

- **Schema definition**: `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto` (generated code in `proto/gen/`).
- **Transport/wiring**: `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) registers both a **gRPC-Gateway** (RESTful JSON mapping of the gRPC services) and **ConnectRPC** handlers (`server/router/api/v1/v1.go:133-141`) on the Echo server (mounted from `server/server.go:88`).

Additional non-gRPC HTTP surfaces exist for specific needs: the file server for attachments/avatars (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), and an MCP endpoint (`server/router/mcp/`) — but the primary public API is the proto-defined gRPC/Connect/REST-gateway one, not GraphQL.
