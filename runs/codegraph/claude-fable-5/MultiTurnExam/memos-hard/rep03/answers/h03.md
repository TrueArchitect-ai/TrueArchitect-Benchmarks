**Abstraction package**: `internal/idp` — the file `internal/idp/idp.go` defines the provider-neutral abstraction, notably `IdentityProviderUserInfo` (identifier, display name, email, avatar URL), the normalized user record any provider implementation must produce.

**Implementation package**: `internal/idp/oauth2` — the single concrete protocol implementation that ships, in `internal/idp/oauth2/oauth2.go` (with tests in `oauth2_test.go`), implementing the OAuth 2.0 flow used for third-party sign-in (wired up through the auth API and configured via the SSO settings UI, e.g. `web/src/components/Settings/SSOSection.tsx`).
