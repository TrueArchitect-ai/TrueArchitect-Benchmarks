Engine: CEL (Common Expression Language) via google/cel-go, wrapped by the `Engine` in internal/filter (`internal/filter/engine.go:14`); mechanism: the engine compiles the CEL expression into a dialect-agnostic condition tree (IR), which a per-dialect renderer turns into parameterized SQL WHERE fragments.

Details: `Engine` builds a `cel.Env` from a `Schema` (`internal/filter/schema.go`) and parses filters into the IR in `internal/filter/parser.go`/`ir.go`. The `renderer` in `internal/filter/render.go` walks that condition tree and emits SQL with placeholders for a given `DialectName` (`DialectSQLite`, MySQL, Postgres — declared in `schema.go`). Each dialect driver invokes this at query-build time — e.g. `store/db/sqlite/memo.go:57-61` calls `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` to append the rendered conditions to the memo query; the handler passes the request's filter string through `APIV1Service.ListMemos` (`server/router/api/v1/memo_service.go:178`) into `FindMemo.Filters`.
