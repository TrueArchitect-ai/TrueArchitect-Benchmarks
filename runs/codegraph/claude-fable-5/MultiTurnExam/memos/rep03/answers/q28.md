Runners the server actually starts (`Server.startBackgroundRunners`, `server/server.go:153-174`):

- s3presign runner (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`, `server/server.go:163`), then continuously on a `time.Ticker` every 12 hours (`runnerInterval = time.Hour * 12`, `runner.go:27-41`), cancelled via per-runner context on shutdown.

That is the only background runner the server starts. Two other pieces of infrastructure exist but are not driven by the server's scheduler:

- The memopayload runner (`server/runner/memopayload/runner.go`) is never started as a background worker — `server/server.go` only creates the s3presign runner. Its logic is instead invoked synchronously from request handlers via `memopayload.RebuildMemoPayload` (`server/router/api/v1/memo_service.go:108,447`).
- **Unused scheduling infrastructure:** the full cron-style scheduler package `internal/scheduler/` (scheduler.go, job.go, parser.go, middleware.go, plus docs and tests) is not imported by any code outside its own package — no file in `server/` or elsewhere references it, so the server uses a plain `time.Ticker` rather than this scheduler.
