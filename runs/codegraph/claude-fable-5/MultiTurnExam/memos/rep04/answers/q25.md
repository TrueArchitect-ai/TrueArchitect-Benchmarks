**Engine: CEL (Common Expression Language, via `github.com/google/cel-go`) — `internal/filter/`** (`internal/filter/engine.go:14` defines the `Engine`; `parser.go`, `ir.go`, `render.go`, `schema.go` complete the package).

**Mechanism:** The engine compiles the CEL filter expression into a dialect-agnostic condition tree (IR), and a renderer (`internal/filter/render.go`) then converts that tree into a parameterized SQL WHERE clause for the requested `DialectName` (sqlite/mysql/postgres, `internal/filter/schema.go:14-16`), using per-dialect SQL expression templates in the schema (e.g. `'users/' || %s` for SQLite vs `CONCAT('users/', %s)` for MySQL) — each dialect driver invokes it via `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` when building the ListMemos query (e.g. `store/db/sqlite/memo.go:57-61`).
