Runners actually started by the server (`Server.startBackgroundRunners`, `server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — runs once immediately at startup (`RunOnce` at `server/server.go:163`), then continuously in a goroutine driven by a plain `time.Ticker` firing every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-40`), cancelled via per-runner context on shutdown.

That is the **only** background runner the server starts. The other runner package, `server/runner/memopayload/runner.go`, is never started as a background worker — only its helper `memopayload.RebuildMemoPayload` is called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108,447`).

**Unused scheduling infrastructure:** the repo contains a full cron-style scheduler package at `internal/scheduler/` (`scheduler.go`, `parser.go` with cron-expression `Schedule`/field matching), but no code outside that package imports it — the server does not use it; the s3presign runner uses a raw `time.Ticker` instead.
