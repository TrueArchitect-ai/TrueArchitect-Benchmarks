Mechanism: the `Engine` (`internal/filter/engine.go:14`) compiles the CEL filter string against a field schema into a dialect-agnostic condition tree (IR), and each database driver then calls `filter.AppendConditions(...)` with its `DialectName` (e.g. `filter.DialectSQLite` at `store/db/sqlite/memo.go:57-61`), which walks that tree with the `renderer` in `internal/filter/render.go` to emit dialect-specific SQL fragments and placeholder args (switching on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` for syntax differences) that are appended to the query's WHERE clause.
