store/migration/sqlite/LATEST.sql

This file contains the full current schema (all `CREATE TABLE` statements — `migration_history`, `instance_setting`, `user`, `memo`, `memo_relation`, `attachment`, etc.), and the migrator in `store/migrator.go` applies the dialect's `LATEST.sql` in one shot on a fresh database instead of replaying the versioned migrations in `store/migration/sqlite/<version>/`.
