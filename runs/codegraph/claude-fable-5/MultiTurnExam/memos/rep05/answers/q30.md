All four dispatchers live in `server/router/api/v1/memo_service_webhooks.go`:

- memo created (`memos.memo.created`): DispatchMemoCreatedWebhook
- memo updated (`memos.memo.updated`): DispatchMemoUpdatedWebhook
- memo deleted (`memos.memo.deleted`): DispatchMemoDeletedWebhook
- comment created (`memos.memo.comment.created`): DispatchMemoCommentCreatedWebhook

Delivery convergence: the first three funnel through the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), and all four ultimately hand each per-hook payload to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which wraps `Post` (`internal/webhook/webhook.go:120`) — the single function that marshals the payload, signs it (HMAC-SHA256 Standard Webhooks headers when a signing secret is set), and performs the HTTP POST.
