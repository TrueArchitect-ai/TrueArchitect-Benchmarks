Mechanism: the built frontend (`dist/`) is compiled into the Go binary with `go:embed` and served by Echo static-file middleware with an SPA fallback to `index.html`; path: server/router/frontend/frontend.go

Specifically, `//go:embed dist/*` at `server/router/frontend/frontend.go:20-21` embeds the compiled assets into the binary; `FrontendService.Serve` (line 41) mounts them via `middleware.StaticWithConfig` over that embedded filesystem, and `spaFallbackMiddleware` (line 63) rewrites 404s on app routes to `index.html` so client-side routing works. The service is wired into the server in `server/server.go`.
