- **s3presign runner** (`server/runner/s3presign/runner.go`) — the only background runner the server actually starts, in `Server.startBackgroundRunners` (`server/server.go:153-173`): it calls `RunOnce` immediately at startup, then `Run` loops on a `time.Ticker` with a 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-41`), until its per-runner context is cancelled on shutdown.

Not started by the server:

- **memopayload runner** (`server/runner/memopayload/runner.go`) — a `Runner` type exists but is never constructed or started anywhere; only the package's `RebuildMemoPayload` function is used, called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108, 447`), not as a background job.
