**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10`, described in its doc comment as containing "all methods that store database driver should implement" (CRUD methods for memos, users, attachments, settings, etc.). All three database backends implement it, each returning `store.Driver` from their `NewDB` constructors:

- SQLite: `store/db/sqlite/sqlite.go`
- MySQL: `store/db/mysql/mysql.go`
- PostgreSQL: `store/db/postgres/postgres.go`

The factory `NewDBDriver` in `store/db/db.go` selects among them based on the configured driver name.
