`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` instead of running incremental migrations. This is confirmed in `store/migrator.go`, which defines `LatestSchemaFileName = "LATEST.sql"` (line 56) and documents it as the "Full schema for new installations (faster than incremental migrations)" (line 42); the versioned directories like `store/migration/sqlite/0.24/` hold only the incremental migrations for upgrades.
