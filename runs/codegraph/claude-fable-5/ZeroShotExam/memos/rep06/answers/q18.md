The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with its entry file:

- SQLite — `store/db/sqlite/sqlite.go`
- MySQL — `store/db/mysql/mysql.go`
- PostgreSQL — `store/db/postgres/postgres.go`

Each implements the interface via a `DB` struct constructed by that file's `NewDB` function.

Factory: **NewDBDriver — `store/db/db.go`**. It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and calls the matching package's `NewDB` to select the driver at startup, returning an error for any unknown driver name.
