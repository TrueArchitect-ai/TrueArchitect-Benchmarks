The compiled React frontend (the `web/` build output copied into `server/router/frontend/dist/`) is embedded into the Go binary with `//go:embed dist/*` (`embed.FS`) and served via Echo's static-file middleware plus an SPA fallback to `index.html`. This is wired in `server/router/frontend/frontend.go`:

- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` embeds the compiled assets into `embeddedFiles embed.FS`.
- `server/router/frontend/frontend.go:41-61` — `Serve` mounts `middleware.StaticWithConfig` over an `fs.Sub` of the embedded FS (via `getFileSystem("dist")`, line 115) and adds `spaFallbackMiddleware` (line 63) which serves `index.html` for unmatched client-side routes, skipping `/api`, `/file`, and gRPC paths.

The service itself is registered on the Echo server from `server/server.go` (`NewFrontendService(...).Serve(...)`).

**Answer:** Go `embed.FS` (`//go:embed dist/*`) served through Echo static middleware with SPA `index.html` fallback; `server/router/frontend/frontend.go`
