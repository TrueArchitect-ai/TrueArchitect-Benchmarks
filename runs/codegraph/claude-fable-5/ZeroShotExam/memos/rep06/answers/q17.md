`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This module holds the memo CRUD hooks — `useMemos`, `useInfiniteMemos`, `useMemo` (queries) and `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo` (mutations), plus comment/link-metadata queries — built on TanStack Query. They all call `memoServiceClient`, the generated Connect-RPC service client created in `web/src/connect.ts:197` via `createClient(MemoService, transport)` (imported into the hooks module as `import { memoServiceClient } from "@/connect"`).
