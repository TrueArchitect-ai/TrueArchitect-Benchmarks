`web/src/connect.ts`

This file imports `createClient` from `@connectrpc/connect` and a Connect transport from `@connectrpc/connect-web`, then creates the clients for all the API services (`AIService`, `AttachmentService`, `AuthService`, `IdentityProviderService`, `InstanceService`, `MemoService`, `ShortcutService`, `UserService`). It is the only frontend source file containing ConnectRPC client creation calls.
