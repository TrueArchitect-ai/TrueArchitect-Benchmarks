**`memo_relation`**

The table is defined in the schema files for all three supported databases — e.g. `store/migration/sqlite/LATEST.sql:47`, plus `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql` (introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`). It links memos to each other via `memo_id` and `related_memo_id` columns along with a relation `type`.
