**Runners the server actually starts** (`server/server.go:153`, `startBackgroundRunners`, called from `Server.Start`):

- **S3 presign runner** (`server/runner/s3presign/runner.go`) — the only background runner started. It gets an immediate `RunOnce(ctx)` at server startup, then runs continuously in a goroutine driven by a plain `time.Ticker` with `runnerInterval = 12 * time.Hour` (`server/runner/s3presign/runner.go:27-41`), stopped via per-runner `context.CancelFunc` on shutdown (`server/server.go:176`).

That's it — no other runner is launched by the server.

**Infrastructure present but NOT used by the server:**

- `internal/scheduler/` — a full GitHub-Actions-inspired cron scheduler package (cron expression parser, job runner, middleware, docs, tests). Nothing outside its own package and tests imports it; the server's only periodic task uses a raw `time.Ticker` instead. It is dead/unused infrastructure from the server's perspective.
- `server/runner/memopayload/` — a second "runner" package exists, but the server never starts it as a background worker. Its `Runner.RunOnce` (rebuild all memo payloads) has no caller in the server; only the standalone helper `memopayload.RebuildMemoPayload` is invoked synchronously from the memo API handlers (`server/router/api/v1/memo_service.go:108,447`), not on any schedule.
