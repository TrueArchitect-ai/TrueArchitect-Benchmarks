This method implements the `SignIn` RPC of the `AuthService`: it handles both password-based authentication (bcrypt comparison, checking the `DisallowPasswordAuth` setting) and SSO/OAuth2 credentials, then issues the access token via `doSignIn`.

Supporting detail: the Connect transport layer wraps it in `ConnectServiceHandler.SignIn` (`server/router/api/v1/connect_services.go:78`), which just injects a header carrier and delegates to `APIV1Service.SignIn`.
