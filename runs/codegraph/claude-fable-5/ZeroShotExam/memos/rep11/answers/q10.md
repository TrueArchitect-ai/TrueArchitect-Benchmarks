`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from a single `LATEST.sql` file instead of running incremental migrations — see `store/migrator.go:27` ("Check if DB is initialized. If not, apply LATEST.sql") and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"). For the SQLite driver that file is `store/migration/sqlite/LATEST.sql`.
