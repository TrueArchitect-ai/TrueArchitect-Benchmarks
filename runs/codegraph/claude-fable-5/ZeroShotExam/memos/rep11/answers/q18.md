The `store.Driver` interface is defined in `store/driver.go:10`, and it has three implementations, each with its entry file where the driver's `DB` struct and `NewDB` constructor live:

- `store/db/sqlite/sqlite.go` — SQLite
- `store/db/mysql/mysql.go` — MySQL
- `store/db/postgres/postgres.go` — PostgreSQL

The factory that selects between them at startup is **`NewDBDriver`** — `store/db/db.go` (line 14). It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) and calls the corresponding package's `NewDB`, returning an error for any unknown driver.
