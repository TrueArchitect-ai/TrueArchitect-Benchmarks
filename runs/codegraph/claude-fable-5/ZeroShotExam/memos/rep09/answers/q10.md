`store/migration/sqlite/LATEST.sql`

On a fresh (uninitialized) database, the migrator applies this single file containing the full current schema instead of running incremental migrations — see the comments in `store/migrator.go:27` and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"), with the filename constant `LatestSchemaFileName = "LATEST.sql"` at `store/migrator.go:56`. This is verified by `store/test/migrator_test.go:18` (`TestFreshInstall`). Equivalent files exist for the other drivers (`store/migration/mysql/LATEST.sql`, `store/migration/postgres/LATEST.sql`), but for SQLite the answer is `store/migration/sqlite/LATEST.sql`.
