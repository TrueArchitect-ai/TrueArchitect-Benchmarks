**`APIV1Service.SignIn` — `server/router/api/v1/auth_service.go`** (defined at line 51)

This method contains the actual business logic for the SignIn RPC: it looks up the user by username, verifies the password with bcrypt (or handles SSO/OAuth2 credentials), checks whether password auth is allowed, and issues the access token and refresh-token cookie.

For completeness, the Connect transport layer wraps it in `ConnectServiceHandler.SignIn` at `server/router/api/v1/connect_services.go:78`, which just injects a header carrier and delegates to `APIV1Service.SignIn`.
