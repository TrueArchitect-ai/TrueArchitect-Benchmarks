**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` with the doc comment "Driver is an interface for store driver. It contains all methods that store database driver should implement." It declares all storage operations (memos, users, attachments, settings, etc.), and each database backend implements it via its `DB` struct:

- SQLite: `store/db/sqlite/sqlite.go` (`NewDB` returns `store.Driver`)
- MySQL: `store/db/mysql/mysql.go`
