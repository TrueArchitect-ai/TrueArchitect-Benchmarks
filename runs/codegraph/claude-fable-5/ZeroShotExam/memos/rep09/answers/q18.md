The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with its entry file:

1. SQLite — `store/db/sqlite/sqlite.go`
2. MySQL — `store/db/mysql/mysql.go`
3. PostgreSQL — `store/db/postgres/postgres.go`

Each entry file defines a `DB` struct and a `NewDB(profile)` constructor returning `store.Driver`.

Factory: **NewDBDriver** — `store/db/db.go` (line 14). It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) at startup and calls the matching package's `NewDB`, returning an error for any unknown driver.
