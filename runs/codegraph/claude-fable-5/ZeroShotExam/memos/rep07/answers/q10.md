`store/migration/sqlite/LATEST.sql`

On a fresh install the migrator detects an uninitialized database and applies this single file rather than replaying incremental migrations. This is documented in `store/migrator.go` — the comments state "Check if DB is initialized. If not, apply LATEST.sql" and "LATEST.sql: Full schema for new installations (faster than incremental migrations)", with the constant `LatestSchemaFileName = "LATEST.sql"` at `store/migrator.go:56`. The versioned directories under `store/migration/sqlite/` (e.g. `0.24/`) are only for upgrading existing databases.
