The database driver interface is `store.Driver` (`store/driver.go`), with three implementations and a startup factory:

- `store/db/sqlite/sqlite.go` — SQLite implementation (`sqlite.NewDB`)
- `store/db/mysql/mysql.go` — MySQL implementation (`mysql.NewDB`)
- `store/db/postgres/postgres.go` — PostgreSQL implementation (`postgres.NewDB`)

`NewDBDriver` — `store/db/db.go` (line 14). It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) to construct the matching driver at startup, returning an error for unknown driver names.
