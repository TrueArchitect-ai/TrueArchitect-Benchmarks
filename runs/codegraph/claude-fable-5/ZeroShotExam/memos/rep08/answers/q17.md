**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

The memo CRUD hooks all live in `web/src/hooks/useMemoQueries.ts` — queries (`useMemos`, `useInfiniteMemos`, `useMemo`, `useMemoComments`, `useLinkMetadata`) and mutations (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`), along with the `memoKeys` query-key factory and optimistic-update cache helpers.

Every one of them calls `memoServiceClient` (e.g. `memoServiceClient.createMemo(...)` at `web/src/hooks/useMemoQueries.ts:183`, `updateMemo` at line 202, `deleteMemo` at line 258), imported from `@/connect` (`web/src/connect`). That client is the generated Connect-RPC client for `MemoService`, whose generated code is in `proto/gen/api/v1/apiv1connect/memo_service.connect.go` (Go side) / `web/src/types/proto/api/v1/memo_service_pb` (TypeScript types).
