**Mechanism:** Server-Sent Events (SSE); **hub path:** `server/router/api/v1/sse_hub.go`; **handler names:** `CreateMemo`, `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, `DeleteMemoReaction`, plus `UpdateMemo` indirectly via `dispatchMemoUpdatedSideEffects`.

Details:

- The server streams live change events to browsers over SSE. The hub (`SSEHub` in `server/router/api/v1/sse_hub.go`) keeps a set of `SSEClient` connections, each with a buffered channel, and its `Broadcast` method (line 115) fans out JSON-encoded `SSEEvent`s (`memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`), applying visibility filtering per client via `canReceive` and dropping events for slow clients. The HTTP endpoint itself is served by `handleSSE` in `server/router/api/v1/sse_handler.go` (registered through `RegisterSSERoutes`), with a heartbeat interval.
- Callers of `Broadcast`: `CreateMemo` and `DeleteMemo` in `server/router/api/v1/memo_service.go`; `CreateMemoComment` in `server/router/api/v1/memo_service_comments.go`; `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go` (the path used by `UpdateMemo`); and `UpsertMemoReaction` / `DeleteMemoReaction` in `server/router/api/v1/reaction_service.go`.
