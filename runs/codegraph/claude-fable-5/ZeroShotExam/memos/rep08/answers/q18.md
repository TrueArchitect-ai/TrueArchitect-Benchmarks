The `store.Driver` interface is defined in `store/driver.go`, and it has three implementations, one per supported database, each with its `DB` struct and `NewDB` constructor in the package's entry file:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

The factory that selects between them at startup is **`NewDBDriver` — `store/db/db.go`** (line 14). It switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and calls the corresponding package's `NewDB`, returning an error for any unknown driver name.
