The compiled frontend (the Vite build output in `dist/`) is embedded directly into the Go binary via `go:embed` and served by Echo's static middleware, with an SPA fallback to `index.html`.

In `server/router/frontend/frontend.go`: the `//go:embed dist/*` directive (line 20) bundles the build into `embeddedFiles`, and `Serve` (line 41) wires it up with `middleware.StaticWithConfig` over an `fs.Sub` of that embedded FS, plus `spaFallbackMiddleware` which serves `index.html` for HTML routes that 404. It is registered from `server/server.go` (which calls `Serve`).

**Answer:** Go `embed` of `dist/*` served via Echo static middleware with SPA fallback; `server/router/frontend/frontend.go`
