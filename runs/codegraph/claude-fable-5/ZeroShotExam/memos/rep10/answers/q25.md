**Engine:** Google CEL (Common Expression Language), via the `github.com/google/cel-go` library, wrapped by a custom filter engine living in **`internal/filter/`** (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:211`) validates the filter string and passes it via `store.FindMemo.Filters` to each database driver, which calls `filter.DefaultEngine()`; the engine compiles the string with a `cel.Env` (`Engine.Compile`, `internal/filter/engine.go:48`), then `buildCondition` (`internal/filter/parser.go`) walks the CEL parsed expression into a dialect-agnostic `Condition` IR tree (`internal/filter/ir.go`), and a `renderer` (`internal/filter/render.go`) walks that tree with a `DialectName` option to emit dialect-specific SQL fragments plus bound args — each store passes its own dialect constant: `filter.DialectSQLite` in `store/db/sqlite/memo.go:61`, `filter.DialectMySQL` in `store/db/mysql/memo.go:69`, and `filter.DialectPostgres` in `store/db/postgres/memo.go:58` (which also handles `$n` placeholder numbering via `PlaceholderOffset`).
