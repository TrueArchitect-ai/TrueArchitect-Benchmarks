MemoService is exposed over Connect RPC (which itself speaks gRPC/gRPC-Web/Connect over HTTP) and over a plain HTTP/JSON REST API via grpc-gateway:

- **Connect RPC** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` mounts the Connect handler on the Echo server; the generated handler code lives in `proto/gen/api/v1/apiv1connect/`)
- **HTTP/REST (grpc-gateway)** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` inside `RegisterGateway`; the generated gateway code is `proto/gen/api/v1/memo_service.pb.gw.go`)

Both registrations wrap the same `APIV1Service` implementation (`server/router/api/v1/v1.go`), which embeds `v1pb.UnimplementedMemoServiceServer`.
