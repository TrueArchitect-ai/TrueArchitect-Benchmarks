The `store.Driver` interface (`store/driver.go:10`) has three implementations, each with its entry file defining the driver's `DB` struct and `NewDB` constructor:

- SQLite — `store/db/sqlite/sqlite.go`
- MySQL — `store/db/mysql/mysql.go`
- PostgreSQL — `store/db/postgres/postgres.go`

The factory that selects between them at startup is **NewDBDriver** — `store/db/db.go` (line 14). It switches on `profile.Driver` ("sqlite" / "mysql" / "postgres") and calls the corresponding package's `NewDB`, returning an error for any unknown driver value.
