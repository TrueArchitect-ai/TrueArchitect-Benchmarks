**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` with the comment "Driver is an interface for store driver. It contains all methods that store database driver should implement." It declares all storage methods (memos, users, attachments, settings, etc.), and each of the three database backends implements it — their `NewDB` constructors return `store.Driver`:

- SQLite: `store/db/sqlite/sqlite.go`
- MySQL: `store/db/mysql/mysql.go`
- PostgreSQL: `store/db/postgres/postgres.go`
