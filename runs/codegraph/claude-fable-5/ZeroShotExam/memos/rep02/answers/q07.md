`web/src/connect.ts`

This file imports `createClient` from `@connectrpc/connect` and `createConnectTransport` from `@connectrpc/connect-web`, and instantiates the clients for all API services (`AIService`, `AttachmentService`, `AuthService`, `IdentityProviderService`, `InstanceService`, `MemoService`, `ShortcutService`, `UserService`). It's the only file in `web/src` that calls `createClient`.
