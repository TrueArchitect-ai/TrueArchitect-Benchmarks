**Answer**

The "user-configured URL" here is the webhook endpoint: users register webhooks (stored per-user, retrieved via `Store.GetUserWebhooks`, delivered to `hook.Url`). Several `MemoService` RPC handlers transitively trigger a POST to those URLs.

**RPC handlers (≥3):**
- `CreateMemo` — calls `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service.go`)
- `UpdateMemo` — calls `DispatchMemoUpdatedWebhook` via `server/router/api/v1/memo_update_helpers.go`
- `DeleteMemo` — calls `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service.go`)
- `CreateMemoComment` — calls `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_comments.go`)

Each dispatcher builds a `WebhookRequestPayload`, sets `payload.URL = hook.Url` from the user's configured webhooks, and enqueues it via `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:15-74`). The created/updated/deleted paths share the internal helper `dispatchMemoRelatedWebhook`; the comment path has its own loop but funnels to the same `PostAsync`.

**Convergence function — path:** `webhook.Post` at `internal/webhook/webhook.go:120`. This is the single function where every path converges and the actual outbound HTTP request is made (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`). All four handlers reach it through the async queue: `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto `asyncPostQueue`, and the worker goroutines started in `init` (line 46) call `Post` for each payload.

So: handler → `Dispatch…Webhook` → `webhook.PostAsync` → (async worker) → **`webhook.Post`** → `safeClient.Do`.

(Note: `GetLinkMetadata` / `BatchGetLinkMetadata` also make outbound HTTP requests via `internal/httpgetter`, but to URLs supplied in the request rather than a user-*configured* endpoint, so they're a separate path from the webhook convergence above.)
