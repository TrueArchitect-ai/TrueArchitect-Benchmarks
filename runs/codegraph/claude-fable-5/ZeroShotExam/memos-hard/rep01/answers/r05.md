**Premise correction:** There is no GraphQL schema in this repository — a repo-wide search for "graphql" turns up nothing. The public API is not GraphQL.

**Actual API surface:** The API is defined with Protocol Buffers and served over gRPC/Connect with an HTTP/JSON gateway:

- **Schema definitions:** `proto/api/v1/*.proto` — one file per service, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, plus `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, and shared types in `common.proto`.
- **Code generation:** `proto/buf.gen.yaml` configures buf to generate Go protobuf/gRPC/ConnectRPC stubs and grpc-gateway REST bindings into `proto/gen/`, TypeScript client types into `web/src/types/proto`, and an OpenAPI document at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).
- **Server-side implementation:** `server/router/api` (with additional surfaces under `server/router/mcp`, `server/router/rss`, etc.).

So if you're looking for the "public API schema," the `.proto` files under `proto/api/v1/` are the source of truth, and `proto/gen/openapi.yaml` is the generated REST/OpenAPI description.
