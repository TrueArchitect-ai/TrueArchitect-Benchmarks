**`internal/idp`; `internal/idp/oauth2`**

The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type that any provider implementation returns after authenticating a user. The one concrete protocol implementation that ships is OAuth2, in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`) — its `IdentityProvider` type wraps a `storepb.OAuth2Config` and implements `ExchangeToken` (with PKCE support) and `UserInfo`, mapping provider claims back to `idp.IdentityProviderUserInfo`. It's wired into sign-in via `server/router/api/v1/auth_service_sso.go`, and the web UI ships OAuth2 templates for GitHub, GitLab, and Google in `web/src/components/CreateIdentityProviderDialog.tsx`.
