A browser loads the avatar via the URL `/file/{users/username}/avatar` (that URL is what the API embeds for `AvatarUrl` — `server/router/api/v1/user_service_converters.go:36`). That path is served by the Echo file server, not the gRPC gateway. The avatar bytes are stored inline as a base64 data URI in the `user.avatar_url` column, so the "data layer" hop is a `SELECT ... avatar_url FROM user`.
