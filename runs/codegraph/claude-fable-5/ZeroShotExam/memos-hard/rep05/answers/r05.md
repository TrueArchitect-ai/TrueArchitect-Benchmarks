**Premise correction:** This repository has no GraphQL API and no GraphQL schema — a repo-wide search for "graphql" turns up nothing. The public API is not GraphQL-based.

**Actual API surface:** The public API is defined with Protocol Buffers (gRPC) and exposed over both gRPC and REST via grpc-gateway annotations:

- **Schema definitions:** `proto/api/v1/` contains the `.proto` service definitions — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`. Codegen is managed by Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`), with generated code in `proto/gen/`.
- **Server implementations:** `server/router/api/v1/` implements these services in Go (e.g. `memo_service.go`, `auth_service.go`).
- **REST/OpenAPI:** A generated OpenAPI spec (`proto/gen/openapi.yaml`) is embedded and served via `proto/openapi_embed.go`, describing the HTTP/JSON form of the same API.
- **Other surfaces:** Additional routers exist for MCP (`server/router/mcp/`), RSS (`server/router/rss/`), and static file serving — none of them GraphQL.
