The webhook URL is user-configured through `WebhooksUserSetting_Webhook.Url` (`proto/gen/store/user_setting.pb.go:917`), managed by the `UserService.CreateUserWebhook`/`UpdateUserWebhook` handlers (`server/router/api/v1/user_service_webhooks.go`).

**Convergence function — path:**

`webhook.Post` — `internal/webhook/webhook.go:120`

All four dispatch paths funnel through `dispatchMemoRelatedWebhook`/`DispatchMemoCommentCreatedWebhook`, which build a `WebhookRequestPayload` (with `URL = hook.Url`) and call `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` enqueues onto `asyncPostQueue`; the pool of goroutines started in `init` (`webhook.go:42`) drains that queue and calls `Post`, which is the single function that actually constructs and issues the HTTP request (`req, _ := http.NewRequest("POST", requestPayload.URL, …)` then `safeClient.Do(req)` at `webhook.go:126`/`152`).

So: the paths converge at `webhook.PostAsync` (the enqueue chokepoint shared by every handler) and then at `webhook.Post`, which performs the actual outbound delivery. If you want the single function where the HTTP request is emitted, it is `webhook.Post` (`internal/webhook/webhook.go:120`); if you want the single synchronous call site every handler funnels through, it is `webhook.PostAsync` (`internal/webhook/webhook.go:184`).
