The data layer is the `store` package, which defines the persistent entity structs (`store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/idp.go`, `store/instance_setting.go`, `store/user_setting.go`, `store/user_identity.go`).

Counting distinct Go packages outside `store/` (and its `store/db/*`, `store/test` subpackages) that reference each entity type:

- **`store.User`** — 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo`** — 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Next closest is `store.Attachment` with 4; all others (Inbox, MemoRelation, MemoShare, Reaction, UserIdentity, etc.) have 3 or fewer.

**Answer — 1st: `User` (~7 packages); 2nd: `Memo` (~6 packages).** The ranking holds even if test packages are excluded (User 6, Memo 5).
