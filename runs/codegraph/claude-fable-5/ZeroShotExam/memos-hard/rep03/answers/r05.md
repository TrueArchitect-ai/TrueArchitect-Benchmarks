**Premise correction:** There is no GraphQL schema in this repository — the public API is not GraphQL at all. A repo-wide search for "graphql" turns up nothing in the Go server, web frontend, or proto definitions.

**Actual API surface:** The public API is defined as Protocol Buffers (gRPC-style services following Google AIP conventions), located in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto` (design notes in `proto/api/v1/README.md`).

Code generation is configured in `proto/buf.gen.yaml`, which produces ConnectRPC Go handlers (`buf.build/connectrpc/go`), grpc-gateway bindings, and an OpenAPI spec (embedded via `proto/openapi_embed.go`). The services are wired up server-side in `server/router/api/v1/` (e.g., `server/router/api/v1/connect_handler.go` and `v1.go`), so the API is exposed over ConnectRPC/gRPC with HTTP/JSON compatibility — with an additional MCP surface under `server/router/mcp/` — rather than GraphQL.
