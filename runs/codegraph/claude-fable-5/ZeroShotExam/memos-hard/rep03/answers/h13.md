**impl** — The interface is `markdown.Service` (`internal/markdown/markdown.go:31`). The only concrete implementation is the unexported `service` struct (`internal/markdown/markdown.go:58`), which wraps a configured `goldmark.Markdown` instance. That single implementation is what executes at runtime; there are no alternative implementations in production code.

**construction** — `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) builds it. The one production call site is `NewAPIV1Service` in `server/router/api/v1/v1.go:47-51`, which calls `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` — enabling the custom `#tag` and `@mention` goldmark extensions on top of GFM. `NewServer` (`server/server.go:76,85`) then shares that same instance with the RSS service via `rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`. (Tests construct their own instances via `NewService`, e.g. `server/router/api/v1/test/test_helper.go`.)

**holders** — Three components hold the `markdown.Service` interface as a field or parameter:
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — used by the memo handlers, e.g. `memopayload.RebuildMemoPayload(ctx, ..., s.MarkdownService)` in `server/router/api/v1/memo_service.go:108,447`.
- `RSSService.MarkdownService` (`server/router/rss/rss.go:45`) — used for server-side HTML rendering of feed items (`rss.go:339`).
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) — the batch-rebuild runner also holds the interface (and `RebuildMemoPayload` at `runner.go:74` takes it as a parameter), though the server's `startBackgroundRunners` currently only starts the s3presign runner, so at runtime the memopayload path is exercised through the API service's held instance rather than the runner.

So: `service` (goldmark-backed, sole impl) — constructed once by `NewAPIV1Service` via `markdown.NewService` with tag + mention extensions, shared to RSS in `server/server.go` — held by `APIV1Service`, `RSSService`, and `memopayload.Runner`/`RebuildMemoPayload`.
