The derived metadata is the memo's **payload** (`MemoPayload` with `tags` and a `property` block), stored alongside the memo and exposed on the API `Memo` as `tags`/`property` for lists and previews.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll(memo.Content)`, whose implementation is `internal/markdown/markdown.go` (`ExtractAll`, around lines 355–422) — a single goldmark AST walk over the memo's markdown content. The results are written into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation):**
- Memo creation — `CreateMemo` in `server/router/api/v1/memo_service.go:108` rebuilds the payload before storing the memo.
- Memo update, but only when the update mask includes the `content` path — `UpdateMemo` in `server/router/api/v1/memo_service.go:447`.
- A bulk maintenance runner, `(*Runner).RunOnce` in `server/runner/memopayload/runner.go:27`, which rebuilds payloads for all memos in batches of 100 (defined for full rebuilds; it isn't referenced anywhere else in the Go code besides its own package and the two API call sites above).

**What it extracts** (from the AST walk in `ExtractAll`):
- `Tags` — every `#tag` node, deduplicated case-preservingly.
- `Property.Title` — the text of an H1 heading if it is the first block-level element of the document.
- `Property.HasLink` — presence of any link node.
- `Property.HasCode` — presence of code blocks, fenced code blocks, or inline code spans.
- `Property.HasTaskList` — presence of any task checkbox.
- `Property.HasIncompleteTasks` — at least one unchecked task checkbox.

(`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the payload.)
