The provider abstraction is defined in `internal/idp` (package `idp`, file `internal/idp/idp.go`, which declares `IdentityProviderUserInfo` — the common user-info shape all providers map into). The one concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2` (package `oauth2`, file `internal/idp/oauth2/oauth2.go`, whose header comment reads "Package oauth2 implements the OAuth2 identity provider integration"). It provides `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and `UserInfo`, which returns the abstraction's `idp.IdentityProviderUserInfo`; the server wires it up in `server/router/api/v1/auth_service_sso.go`.

Answer: `internal/idp`; `internal/idp/oauth2`
