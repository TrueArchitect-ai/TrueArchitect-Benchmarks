**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the Go `store` package (`store/`), whose persistent entity types are the structs in files like `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/idp.go`, etc. Counting distinct Go packages outside `store/` (excluding its `db/` drivers and `test/` subpackages, which are part of the data layer) that reference each `store.<Type>`:

- **`store.User`** (`store/user.go:29`) — 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo`** (`store/memo.go:35`) — 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Runners-up for context: `Attachment` (4), `Inbox`, `MemoShare`, and `MemoRelation` (3 each), with the settings/config types (`InstanceSetting`, `UserSetting`, `IdentityProvider`) referenced from only 1 package each (`server/router/api/v1`).
