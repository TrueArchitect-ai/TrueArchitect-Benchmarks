The derived metadata is the memo's `Payload.Property` (plus tags), stored in `MemoPayload` (`proto/gen/store/memo.pb.go:24`) and exposed to the frontend as `Memo.Property` for lists/previews.

**Computation site:** `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates to the markdown service's single-pass AST walk `ExtractAll` in `internal/markdown/markdown.go:356` (goldmark parse + `gast.Walk`).

**Triggers:**
- `CreateMemo` in `server/router/api/v1/memo_service.go:108` (which also covers comment creation, since comments are created as memos);
- `UpdateMemo` in `server/router/api/v1/memo_service.go:447`, but only when the update mask includes the `content` path (e.g. editing text or toggling a task checkbox from the UI, which sends a content update);
- a bulk backfill: `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` rebuilds payloads for all memos in batches of 100 (a maintenance/migration runner; it isn't wired into the normal server start loop in `server/server.go`).

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:371-418`):
- `Tags` — all `#tags` in the content, deduplicated case-preservingly (stored on the payload alongside Property);
- `Property.Title` — the text of an H1 heading only if it is the first block-level element of the document;
- `Property.HasLink` — any link node present;
- `Property.HasCode` — any code block, fenced code block, or inline code span;
- `Property.HasTaskList` — any task checkbox;
- `Property.HasIncompleteTasks` — at least one unchecked task checkbox.

(The walk also collects `Mentions`, but only `Tags` and `Property` are written back to the memo payload in `RebuildMemoPayload`.)
