Protection mechanism — dial-time SSRF guard `safeDialContext` in `internal/webhook/webhook.go:59`, which resolves the target host and rejects any address matching the reserved/private ranges defined in `internal/webhook/validate.go` (`reservedCIDRs`/`isReservedIP`, lines 14–54). Because it runs at connection time inside the shared client's `http.Transport`, it also defeats DNS-rebinding. A complementary registration-time check, `ValidateURL` (`internal/webhook/validate.go:62`), rejects webhook URLs that resolve to reserved IPs when they're created/updated via `server/router/api/v1/user_service_webhooks.go`. The guard can be explicitly disabled for self-hosted setups via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
