**Premise correction:** There is no GraphQL schema in this repository. A repo-wide search for "graphql" turns up nothing — the project does not use GraphQL at all.

**Actual API surface:** The public API is defined with Protocol Buffers (gRPC) and exposed over HTTP via grpc-gateway:

- **Schema definitions:** `proto/api/v1/*.proto` — one file per service, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus shared types in `proto/api/v1/common.proto`.
- **Code generation:** configured in `proto/buf.gen.yaml` (Buf), which generates Go/TypeScript stubs into `proto/gen/`, the grpc-gateway REST bindings (`buf.build/grpc-ecosystem/gateway` plugin), and an OpenAPI spec (`proto/gen/openapi.yaml` via the gnostic-openapi plugin, embedded through `proto/openapi_embed.go`).
- **Server-side implementation:** `server/router/api/` (with additional non-gRPC surfaces under `server/router/mcp/` and `server/router/rss/`).

So if you're looking for the API contract, the `.proto` files under `proto/api/v1/` are the equivalent of what a GraphQL schema would be, with `proto/gen/openapi.yaml` as the generated REST/OpenAPI description.
