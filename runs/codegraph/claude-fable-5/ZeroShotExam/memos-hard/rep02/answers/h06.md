**Handlers (RPC methods on `APIV1Service` that transitively trigger an outbound HTTP POST to a user-configured webhook URL):**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`.
5. Also **`SetMemoRelations`** (`memo_relation_service.go:48`) and **`SetMemoAttachments`** (`memo_attachment_service.go:48`), both via `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.

**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

Every one of the dispatch helpers (`DispatchMemoCreatedWebhook`, `DispatchMemoUpdatedWebhook`, `DispatchMemoDeletedWebhook` all funnel through `dispatchMemoRelatedWebhook`, and `DispatchMemoCommentCreatedWebhook`) builds a `WebhookRequestPayload` whose `URL` is set to the user-configured `hook.Url` (`GetUserWebhooks`), then calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` enqueues onto `asyncPostQueue`, whose worker goroutines all invoke the single function **`Post`**, where the actual outbound request is made via `safeClient.Do(req)` against `requestPayload.URL` (`internal/webhook/webhook.go:126`–`152`).

So `webhook.PostAsync` is the shared enqueue point and **`webhook.Post`** is the single function where all paths converge to perform the outbound HTTP delivery.
