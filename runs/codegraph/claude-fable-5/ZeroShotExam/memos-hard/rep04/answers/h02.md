The outbound notifications are webhooks fired when memos change.

- **Delivery function** — `Post` in `internal/webhook/webhook.go:120` (sends the HTTP POST via the shared `safeClient`; `PostAsync` at `internal/webhook/webhook.go:184` enqueues payloads to a bounded queue drained by worker goroutines that call `Post`). Dispatch is triggered from `server/router/api/v1/memo_service_webhooks.go` (`dispatchMemoRelatedWebhook` → `webhook.PostAsync`).

- **Protection mechanism** — dial-time SSRF blocking: `safeDialContext` in `internal/webhook/webhook.go:59` is installed as the HTTP transport's `DialContext`; it resolves the hostname and rejects any address matching the reserved/private ranges (`isReservedIP` / `reservedNetworks` in `internal/webhook/validate.go`, covering loopback, RFC-1918, link-local/IMDS, and IPv6 equivalents). Because the check runs at dial time on every connection, it also defeats DNS-rebinding. A second, earlier layer is `ValidateURL` in `internal/webhook/validate.go:62`, which rejects reserved-IP URLs when a webhook is registered (called from `server/router/api/v1/user_service_webhooks.go`). The `AllowPrivateIPs` flag in `validate.go` can disable the check for self-hosted deployments.
