**impl — construction — holders**

- **Impl:** the unexported `service` struct in `internal/markdown/markdown.go:58` is the only concrete implementation of the `markdown.Service` interface (`internal/markdown/markdown.go:31`). It wraps a `goldmark.Markdown` instance and delegates to helpers such as `internal/markdown/renderer/markdown_renderer.go` (`MarkdownRenderer`) and the custom tag/mention parsers in `internal/markdown/parser/`.

- **Construction:** `markdown.NewService(opts...)` (`internal/markdown/markdown.go:85`) is the factory. The single production call site is `NewAPIV1Service` in `server/router/api/v1/v1.go:48`, which builds it with `markdown.WithTagExtension()` and `markdown.WithMentionExtension()`. (A second call in `server/router/api/v1/test/test_helper.go:44` is test-only.)

- **Holders of the interface:**
  - `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — the primary holder; e.g. `memo_service.go` passes `s.MarkdownService` into `memopayload.RebuildMemoPayload` (`server/router/api/v1/memo_service.go:108`).
  - `RSSService.MarkdownService` (`server/router/rss/rss.go:45`) — receives the same instance from the API service via `rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)` in `server/server.go:85`, used for server-side HTML rendering in RSS feeds.
  - `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) — declares the field and a `NewRunner` constructor, but nothing in production code calls `NewRunner`; at runtime only the package-level function `RebuildMemoPayload(ctx, memo, markdownService)` is used, with the service passed as an argument.

One clarification worth noting: the frontend renders markdown to HTML with `react-markdown` in `web/src/components/MemoContent/MemoMarkdownRenderer.tsx`, but that path is not behind this interface — the `Service` interface exists on the Go backend for tag/property extraction, snippets, markdown re-rendering (tag renames), and HTML for RSS, as the comment at `internal/markdown/markdown.go:28-30` states.
