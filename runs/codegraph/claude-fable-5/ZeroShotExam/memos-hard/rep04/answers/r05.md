**Premise correction:** This repository has no GraphQL API. A repo-wide search for "graphql" returns zero hits — there is no schema file (`.graphql`/SDL), no resolvers, and no GraphQL server library anywhere in the codebase.

**Actual API surface:** The public API is defined in Protocol Buffers and served over gRPC/Connect with a REST mapping:

- **Schema definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus `common.proto` and services for AI, IdP, instance, and shortcuts.
- **Code generation:** configured in `proto/buf.gen.yaml`, which generates Go gRPC stubs, ConnectRPC handlers, grpc-gateway REST bindings, an OpenAPI spec, and TypeScript client types (emitted to `web/src/types/proto`) into `proto/gen`.
- **Server implementation:** `server/router/api/v1/` — service implementations (`memo_service.go`, `auth_service.go`, etc.), with `server/router/api/v1/connect_handler.go` registering the Connect handlers (`RegisterConnectHandlers` at line 31) onto the HTTP mux.
- Additional non-GraphQL surfaces live alongside it: an MCP endpoint in `server/router/mcp/` and RSS in `server/router/rss/`.

So anything you'd expect from a GraphQL schema (types, operations) is instead expressed as protobuf messages and RPC service definitions under `proto/api/v1/`.
