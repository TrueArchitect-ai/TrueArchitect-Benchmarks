**RPC handler methods that can trigger an outbound HTTP request to a user-configured webhook URL:**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go`, calls `DispatchMemoCreatedWebhook`.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513`, via `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562`, calls `DispatchMemoDeletedWebhook`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119`, calls `DispatchMemoCommentCreatedWebhook`.
5. (Also **`SetMemoAttachments`** and **`SetMemoRelations`** — both go through `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`, per `server/router/api/v1/memo_update_helpers.go:66`.)

Each `Dispatch*` method reads the creator's configured webhooks (`WebhooksUserSetting_Webhook.Url`, a user-supplied URL) and enqueues a payload. All of these paths converge on a single enqueue/dispatch function before the request is actually sent.

**Convergence function:** `webhook.PostAsync` — `internal/webhook/webhook.go:184`. Every dispatcher (`dispatchMemoRelatedWebhook` at line 71 and `DispatchMemoCommentCreatedWebhook` at line 43) hands its `WebhookRequestPayload` to `PostAsync`, which enqueues it onto `asyncPostQueue`; the worker goroutines then call `webhook.Post` (`internal/webhook/webhook.go:120`), which builds the `POST` and performs the actual delivery via `safeClient.Do`.

So: convergence at `webhook.PostAsync`, with delivery performed by `webhook.Post` — path e.g. `CreateMemo` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → (`asyncPostQueue`) → `webhook.Post` → `safeClient.Do`.
