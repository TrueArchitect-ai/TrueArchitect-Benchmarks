The derived metadata is the memo's `Payload` — the extracted `Tags` list and the computed `Property` — stored per-memo and marked "Output only. The computed properties of the memo" in the API type (`proto/gen/api/v1/memo_service.pb.go`, `proto/gen/store/memo.pb.go`).

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the markdown service's `ExtractAll` in `internal/markdown/markdown.go:356`. `ExtractAll` does a single goldmark AST walk over the memo content and fills `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers:**
1. **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` before storing (`server/router/api/v1/memo_service.go:108`).
2. **Content update** — `UpdateMemo` calls it when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:447`).
3. **Bulk rebuild** — the `memopayload` runner's `RunOnce` iterates all memos in batches of 100 and rebuilds + persists each payload (`server/runner/memopayload/runner.go:27`). (In this tree it's defined but I found no startup wiring calling `NewRunner`/`RunOnce` outside the package itself.)

**Extracted properties** (from the single AST walk in `ExtractAll`):
- `Tags` — all `#tags` found in content, deduplicated case-preservingly
- `Property.Title` — text of an H1 heading, only if it's the first block-level element of the document
- `Property.HasLink` — any link node present
- `Property.HasCode` — any code block, fenced code block, or code span
- `Property.HasTaskList` — any task checkbox
- `Property.HasIncompleteTasks` — any unchecked task checkbox

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the payload.)
