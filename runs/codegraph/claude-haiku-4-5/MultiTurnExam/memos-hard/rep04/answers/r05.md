**Premise Correction**: The question assumes there is a GraphQL schema for the public API. This is incorrect.

**Actual API Surface**: The Memos application does **not use GraphQL**. Instead, it uses a **gRPC + gRPC-Gateway API** with **Protocol Buffer (protobuf) schemas**.

The public API surface is defined through:

1. **gRPC Protocol Buffers** — API service definitions are in `.proto` files (e.g., `proto/gen/api/v1/`) that define RPC methods and message types
2. **gRPC-Gateway** — Automatically generates HTTP/JSON endpoints from the gRPC definitions, registered in `server/router/api/v1/` (as seen in `server/router/api/v1/memo_service.go:88` calling `apiV1Service.RegisterGateway()`)
3. **OpenAPI/JSON Schema** — HTTP metadata and validation schemas are generated from the gRPC definitions, visible in `server/router/mcp/openapi.go` and `server/router/mcp/catalog.go`

There is **no GraphQL schema** in this codebase. The API is entirely gRPC-based with automatic HTTP/JSON translation via gRPC-Gateway, not GraphQL.
