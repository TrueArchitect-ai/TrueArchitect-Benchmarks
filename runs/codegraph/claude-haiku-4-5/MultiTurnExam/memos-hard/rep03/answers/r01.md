**Premise correction**: There is no Redis connection. The question assumes Redis is used, but it is not.

**Actual mechanism**: The cache layer uses an in-memory cache implemented in `store/cache/cache.go`. The cache configuration is set in `store/store.go:40-45` where the default TTL for all cache entries (including user entries) is **10 minutes** (`DefaultTTL: 10 * time.Minute`). User entries are cached using the `userCache` field which is instantiated with this configuration at line 52. The cache is a thread-safe in-memory implementation with a cleanup loop that runs every 5 minutes to expire old entries, not a Redis-based distributed cache.
