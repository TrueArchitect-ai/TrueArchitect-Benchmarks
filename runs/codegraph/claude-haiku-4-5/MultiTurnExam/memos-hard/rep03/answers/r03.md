**Premise correction**: There is no nightly database-cleanup job scheduled in the cron scheduler. The codebase does not implement any scheduled database cleanup job. The only background runners registered in the server startup (`server/server.go:153-174`) are:
1. S3 presign runner - runs on a 12-hour schedule
2. Memopayload runner - defined but not actively registered in production startup

Database cleanup functionality exists in the cache layer (`store/cache/cache.go:cleanupLoop`), which runs independently on a cleanup interval (5 minutes by default), but this is not part of a cron scheduler—it's an internal goroutine timer within the cache implementation itself.
