**Premise correction**: There is no GraphQL schema. The API does not use GraphQL.

**Actual API surface**: The public API is defined using **Protocol Buffer (protobuf) schemas** located in `/bench/home/work/proto/api/v1/`. The API is implemented as a **gRPC service** with **Connect protocol** support (for HTTP/JSON compatibility), not GraphQL. 

The service definitions are in proto files:
- `memo_service.proto` - Memo operations
- `auth_service.proto` - Authentication
- `user_service.proto` - User management  
- `attachment_service.proto` - Attachment handling
- `instance_service.proto` - Instance configuration
- `ai_service.proto` - AI features
- `idp_service.proto` - Identity provider configuration
- `shortcut_service.proto` - Shortcuts
- `common.proto` - Common types

These are compiled to Go code and served via the gRPC-Gateway at `/api/v1/` endpoints (`server/router/api/v1/v1.go`), which also exposes the API as HTTP/JSON for web clients.
