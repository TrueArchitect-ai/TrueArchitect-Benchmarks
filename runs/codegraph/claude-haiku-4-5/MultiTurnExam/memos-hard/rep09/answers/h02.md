**Delivery function — `Post`** — **internal/webhook/webhook.go:120**; **Protection mechanism — `safeDialContext`** — **internal/webhook/webhook.go:59 (and `isReservedIP` in internal/webhook/validate.go:44)**

The outbound webhook delivery executes in the `Post` function (internal/webhook/webhook.go:120), which sends HTTP POST requests to configured webhook URLs. Protection against SSRF (Server-Side Request Forgery) attacks is implemented through a custom `safeDialContext` function (internal/webhook/webhook.go:59) that:

1. Resolves the target hostname to IP addresses
2. Checks each resolved IP against `isReservedIP` (internal/webhook/validate.go:44), which blocks connections to reserved/private IP ranges (loopback, RFC-1918, link-local, IPv6 equivalents)
3. Rejects the connection if any reserved IP is detected

This protection is applied at dial time via a custom HTTP Transport used by a global `safeClient` (internal/webhook/webhook.go:32–37), preventing DNS rebinding attacks. The `ValidateURL` function (internal/webhook/validate.go:62) provides an additional validation layer when webhook URLs are created/updated.
