**Abstraction package: `internal/idp`; Implementation package: `internal/idp/oauth2`**

The `internal/idp` package defines the identity provider abstraction with the `IdentityProviderUserInfo` struct (internal/idp/idp.go:3), which represents the common data structure returned by any identity provider. The concrete OAuth2 protocol implementation ships in `internal/idp/oauth2` (internal/idp/oauth2/oauth2.go), which implements an `IdentityProvider` struct with methods `ExchangeToken()` and `UserInfo()` that handle OAuth2-specific token exchange and user information retrieval. This is the only identity provider implementation included in the codebase.
