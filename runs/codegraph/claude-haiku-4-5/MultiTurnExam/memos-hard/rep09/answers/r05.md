**Premise correction:** This codebase does not use GraphQL. The public API is defined using Protocol Buffers (protobuf).

**Actual API surface:** The API is defined in proto files located at proto/api/v1/ and is served via:

1. **gRPC** (Connect RPC protocol) 
2. **gRPC-Gateway** (REST/HTTP)

**API Definition files (proto/api/v1/):**
- memo_service.proto — Memo CRUD operations (CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo, etc.)
- user_service.proto — User management
- auth_service.proto — Authentication (login, logout, refresh tokens, etc.)
- attachment_service.proto — File attachment operations
- instance_service.proto — Server instance settings
- ai_service.proto — AI-powered features
- shortcut_service.proto — Shortcut management
- idp_service.proto — Identity provider configuration
- common.proto — Shared message types

**Generated code:** The proto files are compiled to Go code in proto/gen/api/v1/, generating:
- *_pb.go (protobuf messages)
- *_grpc.pb.go (gRPC service definitions)
- *_pb.gw.go (gRPC-Gateway HTTP mappings)
- apiv1connect/ (Connect RPC bindings)

The API follows [Google API Improvement Proposals (AIPs)](https://google.aip.dev/) design guidelines as documented in proto/api/v1/README.md.
