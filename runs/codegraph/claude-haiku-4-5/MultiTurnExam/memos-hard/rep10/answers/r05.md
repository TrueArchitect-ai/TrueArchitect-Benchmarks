Premise correction: There is no GraphQL schema. The public API does not use GraphQL.

Actual API surface: The API is defined using **Protocol Buffers (protobuf)** with **gRPC and Connect protocol**:

1. **Proto definitions** — `proto/gen/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`)
2. **Generated code** — `proto/gen/api/v1/` and `proto/gen/api/v1/apiv1connect/` (gRPC stubs and Connect handlers)
3. **OpenAPI documentation** — Embedded in `proto/` and exposed via:
   - MCP service: `server/router/mcp/service.go` loads OpenAPI spec at runtime
   - OpenAPI spec location: `server/router/mcp/openapi.go:76` loads embedded YAML from `proto/`
   - Exposed at: `/mcp` endpoint (Model Context Protocol)

The API uses **Connect protocol** (gRPC-compatible HTTP/2) registered in `server/router/api/v1/v1.go`, not GraphQL.
