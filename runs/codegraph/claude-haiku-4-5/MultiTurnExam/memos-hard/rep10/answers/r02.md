Premise correction: There is no per-user API rate-limiting middleware registered in the codebase. The server does not implement per-user request rate limits.

The middleware registered in `server/server.go` and related files includes CORS middleware, authentication/authorization, and recovery middleware, but no rate-limiting layer. API access is controlled through authentication (session tokens, PATs, SSO) and authorization (permission checks per resource), but there are no configured rate limits on a per-user basis.
