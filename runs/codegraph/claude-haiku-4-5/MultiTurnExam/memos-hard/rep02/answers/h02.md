**Details:**
- **Delivery function:** `Post()` (internal/webhook/webhook.go:120-180) executes the outbound HTTP delivery by:
  - Marshaling the request payload to JSON
  - Constructing an HTTP POST request with HMAC-SHA256 signature headers (for webhook authentication)
  - Using a `safeClient` with a protected Transport
  - Reading and validating the response

- **Protection mechanism:** `safeDialContext()` (internal/webhook/webhook.go:59-77) prevents SSRF attacks by:
  - Resolving the hostname to all IP addresses
  - Checking each resolved IP against `isReservedIP()` to block connections to reserved/private IP ranges
  - Rejecting the connection if any IP is reserved/private
  - This defeats both direct SSRF and DNS rebinding attacks

- **Integration:** The `safeClient` (lines 32-37) uses this protected `DialContext` in its `http.Transport`, ensuring all webhook POST requests are routed through SSRF protection.
