Memo visibility is enforced in more than one server surface:

1. **ListMemos RPC Handler** — `server/router/api/v1/memo_service.go:218-227` — Applies visibility filter at query construction: anonymous users get only PUBLIC memos; authenticated users get their own memos plus PUBLIC/PROTECTED from others (via filter construction at lines 222-223)

2. **GetMemo RPC Handler** — `server/router/api/v1/memo_service.go:39-68, 356` — Calls `checkMemoReadAccess()` to enforce visibility: public memos accessible to all, non-public memos require authentication and membership checks (archived only to creator, private only to creator)

3. **Explore RSS Feed** — `server/router/rss/rss.go:72-109` — Enforces visibility via `FindMemo` with `VisibilityList: []store.Visibility{store.Public}` at line 90; only PUBLIC memos appear in explore RSS

4. **User RSS Feed** — `server/router/rss/rss.go:111-160` — Enforces visibility via `FindMemo` with `VisibilityList: []store.Visibility{store.Public}` at line 141; only PUBLIC memos from the specified user appear in their RSS feed
