**Premise correction:** There is no GraphQL schema defined in the Memos codebase. GraphQL is not used for the public API.

**Actual API surface:** The public API is built on **Protocol Buffers (protobuf)** with three transport layers:

1. **gRPC services** — defined in `proto/gen/api/v1/*.proto` files (generated code in `proto/gen/api/v1/`)
2. **gRPC-Gateway** — provides HTTP/JSON transport at `server/router/api/v1/v1.go:65-146` (RegisterGateway method) mapping gRPC to REST endpoints
3. **Connect RPC** — provides browser-native RPC at `server/router/api/v1/v1.go:139-144` (Connect interceptors registered)

The RPC services are defined as Protocol Buffer message types and services:
- `MemoService` (memo CRUD operations)
- `UserService` (user management)
- `AuthService` (authentication)
- `InstanceService` (server configuration)
- `AIService` (AI/transcription)
- `IdentityProviderService` (SSO providers)
- `AttachmentService` (file handling)

All service implementations are in `server/router/api/v1/` with handlers like `CreateMemo()`, `ListMemos()`, `GetUser()`, etc. calling business logic from the store layer. No GraphQL introspection, schema stitching, or GraphQL execution layer exists.
