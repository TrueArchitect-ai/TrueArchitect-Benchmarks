**Premise correction:** There is no nightly database-cleanup job scheduled in the cron scheduler in this codebase.

**Evidence:**
- The `internal/scheduler` package is defined with full cron scheduling capabilities (`internal/scheduler/scheduler.go`, `internal/scheduler/parser.go`, `internal/scheduler/job.go`), but it is not actually used anywhere in the production code
- No scheduler is instantiated or jobs are registered in the server initialization code (`server/server.go`)
- No references to scheduler usage exist outside of the scheduler package itself and its test files
- The scheduler documentation (`internal/scheduler/doc.go`) shows an example of how it *could* be used (including a "daily-cleanup" example at 2 AM), but this is purely illustrative documentation, not actual production code
- The only background runner jobs that actually execute in production are the S3 presign refresh runner (`server/runner/s3presign`) and the memo payload rebuild runner (`server/runner/memopayload`), neither of which are database-cleanup jobs

The scheduler infrastructure exists but is unused in the current codebase.
