**Delivery function:** `Post()` — `internal/webhook/webhook.go:120`

**Protection mechanism:** `safeDialContext()` and `isReservedIP()` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`

The outbound webhook delivery executes in the `Post()` function which uses a `safeClient` HTTP client with a custom `safeDialContext` dialer. This dialer:
1. Resolves the target hostname via DNS
2. Checks each resolved IP address using `isReservedIP()` (defined in `internal/webhook/validate.go:44`)
3. Rejects any IPs falling within reserved/private ranges (loopback, RFC-1918, link-local, IPv6 equivalents)
4. Only proceeds with the connection if all IPs pass the checks

Additionally, `ValidateURL()` in `internal/webhook/validate.go:62` performs DNS resolution validation at webhook creation/update time to prevent SSRF before webhooks are registered.
