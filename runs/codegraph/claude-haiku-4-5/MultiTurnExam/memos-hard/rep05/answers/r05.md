**Premise correction:** There is no GraphQL schema for the public API. The Memos public API does not use GraphQL.

**Actual API surface:**
- **API type:** REST API (via gRPC-Gateway) and Connect protocol (both wrapping gRPC services)
- **Schema definition location:** `proto/gen/openapi.yaml` (auto-generated from `.proto` files)
- **Source definition:** Protocol Buffer files at `proto/api/v1/` (e.g., `auth_service.proto`, `memo_service.proto`, `instance_service.proto`, etc.)
- **Schema generation:** The OpenAPI schema is generated by `protoc-gen-openapi` from the `.proto` definitions and embedded into the binary at `proto/openapi_embed.go:6`
- **Loading:** `server/router/mcp/service.go:76` loads the embedded OpenAPI spec via `loadOpenAPISpec()`
- **Serving:** The OpenAPI spec is served via HTTP at `/openapi.yaml` (used by MCP tools to discover available operations)

The public API consists of 8 gRPC services defined in protobuf, wrapped with both gRPC-Gateway (REST) and Connect protocol handlers. There is no GraphQL implementation—this is a fully gRPC/REST-based API architecture with OpenAPI documentation.
