**Premise correction:** There is NO GraphQL schema for the public API. The API is defined using **gRPC/Protobuf**, not GraphQL.

**Actual API surface:**
- **API definition format:** Protocol Buffers (proto3) and gRPC service definitions
- **Location:** `proto/api/v1/` directory with service definitions:
  - `proto/api/v1/memo_service.proto` - MemoService RPC definitions
  - `proto/api/v1/user_service.proto` - UserService RPC definitions
  - `proto/api/v1/auth_service.proto` - AuthService RPC definitions
  - `proto/api/v1/instance_service.proto` - InstanceService RPC definitions
  - `proto/api/v1/attachment_service.proto` - AttachmentService RPC definitions
  - `proto/api/v1/ai_service.proto` - AIService RPC definitions
  - `proto/api/v1/shortcut_service.proto` - ShortcutService RPC definitions
  - `proto/api/v1/idp_service.proto` - IdentityProviderService RPC definitions

- **HTTP transport:** gRPC-Gateway (converts gRPC to REST HTTP endpoints) and Connect Protocol (for browser clients)
- **Example endpoint mapping:** CreateMemo RPC maps to `POST /api/v1/memos` via `google.api.http` annotations in the proto files

The API is a standard gRPC service with HTTP transcoding via gRPC-Gateway and Connect, not a GraphQL API.
