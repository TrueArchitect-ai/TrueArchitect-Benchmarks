**Premise correction: There is no GraphQL schema. The API is defined using Protocol Buffers (protobuf), not GraphQL.**

**Actual API surface: The public API is defined across multiple protobuf service definitions in proto/api/v1/ directory:**
- **proto/api/v1/memo_service.proto** — MemoService with CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo, CreateMemoShare, GetMemoByShare, and reaction/attachment/relation operations
- **proto/api/v1/user_service.proto** — UserService for user management
- **proto/api/v1/auth_service.proto** — AuthService for authentication
- **proto/api/v1/attachment_service.proto** — AttachmentService
- **proto/api/v1/instance_service.proto** — InstanceService
- **proto/api/v1/idp_service.proto** — IdentityProviderService
- **proto/api/v1/ai_service.proto** — AIService
- **proto/api/v1/shortcut_service.proto** — ShortcutService

These protobuf definitions are compiled to both gRPC and Connect protocol implementations, and exposed via gRPC-Gateway for REST HTTP access (server/router/api/v1/v1.go registers the gateway middleware).
