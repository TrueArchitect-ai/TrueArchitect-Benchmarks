**Premise correction: Neither NATS nor RabbitMQ is used. The webhook delivery system uses an in-memory buffered Go channel as its queue.**

**Actual mechanism: The queue is declared as `asyncPostQueue` (internal/webhook/webhook.go:39) — a buffered channel with capacity 128 (`make(chan *WebhookRequestPayload, 128)`). Four worker goroutines are spawned at package initialization (internal/webhook/webhook.go:43-54) that consume from this queue and execute webhook delivery via the Post function. PostAsync (line 184) enqueues requests to this channel, with dropped messages when the queue is full.**
