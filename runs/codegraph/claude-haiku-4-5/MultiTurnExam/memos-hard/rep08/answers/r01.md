**Premise correction: There is no Redis connection. The codebase uses an in-memory cache, not Redis.**

**Actual mechanism: The cache layer is implemented as a thread-safe in-memory cache (store/cache/cache.go) that is initialized in store/store.go:40-45. User entries are cached in the userCache field (store/store.go:52) with a default TTL of 10 minutes and a cleanup interval of 5 minutes. The cache configuration is set at store initialization with DefaultTTL: 10 * time.Minute (store/store.go:41) and applies to all cache instances including userCache.**
