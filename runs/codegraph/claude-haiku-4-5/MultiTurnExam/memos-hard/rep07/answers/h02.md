The `Post` function (at line 120) executes the outbound webhook delivery by making HTTP POST requests. It uses a custom `safeClient` HTTP client (defined at line 32) whose Transport uses `safeDialContext` as a replacement for the standard dial context.

The `safeDialContext` function (at line 59) protects against SSRF attacks by:
1. Parsing the target hostname and port
2. Resolving the hostname using DNS
3. Checking each resolved IP address with `isReservedIP(ip)` to reject any addresses in reserved/private IP ranges (line 71)
4. Only allowing the connection if no reserved/private IPs were found

This protection defeats both direct SSRF attacks and DNS rebinding attacks, as the validation happens at dial time after DNS resolution completes.
