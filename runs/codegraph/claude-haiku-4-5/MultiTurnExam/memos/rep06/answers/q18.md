Based on my earlier exploration of the codebase, I can provide this answer directly:

The three database driver implementations are in:
1. `store/db/mysql/mysql.go` - contains the MySQL driver implementation
2. `store/db/postgres/postgres.go` - contains the PostgreSQL driver implementation  
3. `store/db/sqlite/sqlite.go` - contains the SQLite driver implementation

The factory function that selects between them at startup is `NewDBDriver` located in `store/db/db.go` (which I reviewed earlier and showed the switch statement that routes to the correct driver based on the profile configuration).
