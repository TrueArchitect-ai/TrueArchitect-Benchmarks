Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo

The server uses Server-Sent Events (SSE) as the mechanism for pushing live events to browsers. The SSE hub is implemented in `server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through this hub are `CreateMemo` (broadcasts SSEEventMemoCreated), `UpdateMemo` (broadcasts SSEEventMemoUpdated), and `DeleteMemo` (broadcasts SSEEventMemoDeleted).
