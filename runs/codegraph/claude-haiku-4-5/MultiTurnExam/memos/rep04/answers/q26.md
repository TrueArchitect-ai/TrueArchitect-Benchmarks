When DeleteMemo runs, it affects these tables:
1. **memo_relation** — explicitly deleted where MemoID matches (memo as source of relation)
2. **memo_relation** — explicitly deleted where RelatedMemoID matches (memo as target of relation)
3. **attachment** — explicitly deleted for all attachments linked to the memo
4. **memo** — the memo row itself is deleted

The store.DeleteMemo function in store/memo.go:140-159 performs these cascading deletes in order before deleting the memo row itself.
