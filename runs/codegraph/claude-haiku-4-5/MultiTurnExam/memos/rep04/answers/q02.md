**MySQL, PostgreSQL, SQLite**

The project ships migrations for three SQL dialects, as evidenced by:
1. The migration directory structure at `store/migration/` which contains subdirectories for each dialect: `mysql`, `postgres`, and `sqlite` (confirmed by directory listing)
2. The dialect constants defined in `internal/filter/schema.go:14-16` which enumerate the three supported dialects: `DialectSQLite`, `DialectMySQL`, and `DialectPostgres`
3. The migration loader in `store/migrator.go:255` which constructs the migration path using `fmt.Sprintf("migration/%s/", s.profile.Driver)`
