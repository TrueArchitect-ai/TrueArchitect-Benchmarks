MemoService is served over both gRPC (the native gRPC protocol with generated server interface and handler code) and Connect (a protocol that wraps gRPC services for HTTP). The gRPC protocol is defined in the generated protobuf file `memo_service_grpc.pb.go`, while the Connect protocol wrapping and registration happens in `connect_handler.go` where the `ConnectServiceHandler` is registered with the HTTP mux via `RegisterConnectHandlers`.
