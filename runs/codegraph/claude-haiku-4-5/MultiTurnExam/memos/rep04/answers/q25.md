CEL (Common Expression Language) — internal/filter/engine.go; the filter expression is parsed by a CEL engine, then rendered to SQL for each dialect (SQLite, MySQL, PostgreSQL) using dialect-specific SQL generation functions in internal/filter/render.go.

The ListMemos RPC accepts filter expressions that follow CEL syntax, which are parsed by the engine in `internal/filter/engine.go`, and then converted to dialect-specific SQL through the renderer functions in `internal/filter/render.go` that handle the differences between SQLite, MySQL, and PostgreSQL SQL syntax.
