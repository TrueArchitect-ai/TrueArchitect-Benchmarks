**Driver — store/driver.go**

The `Driver` interface is the Go interface that all database backends implement. It's defined in `store/driver.go` and contains methods like `GetDB()`, `Close()`, `IsInitialized()`, and all the CRUD operations for the various data models. Each database backend (PostgreSQL, MySQL, and SQLite) implements this interface with their own `DB` struct in their respective packages (`store/db/postgres/`, `store/db/mysql/`, and `store/db/sqlite/`).
