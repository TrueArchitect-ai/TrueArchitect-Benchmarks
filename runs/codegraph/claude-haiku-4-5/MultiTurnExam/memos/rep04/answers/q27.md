Go embed (//go:embed); server/router/frontend/frontend.go

The compiled React frontend is served in production using Go's `embed` package, which embeds the compiled frontend files (in the `dist/` directory) directly into the binary. This is wired in `server/router/frontend/frontend.go` where the `FrontendService.Serve()` method serves the embedded files via HTTP middleware that handles static assets, SPA fallback to index.html, and cache headers.
