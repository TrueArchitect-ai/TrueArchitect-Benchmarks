When a memo is deleted through the API, the `Store.DeleteMemo` function in `store/memo.go:140-159` performs cascading deletes in this order:
1. First, it deletes all `memo_relation` records where the memo is the source (MemoID)
2. Then, it deletes all `memo_relation` records where the memo is the target (RelatedMemoID)
3. Next, it fetches and deletes all `attachment` records linked to this memo
4. Finally, it deletes the memo row itself

This ensures referential integrity by cleaning up all related records before removing the memo.
