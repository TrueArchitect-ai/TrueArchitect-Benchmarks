web/src/connect.ts; access tokens and refresh tokens; server/router/api/v1

The auth interceptor lives in `web/src/connect.ts`, where the `authInterceptor` function manages access tokens (for authenticated requests) and refresh tokens (for token renewal when access tokens expire). The backend validates these tokens through the `server/router/api/v1` package, specifically in the `connect_interceptors.go` and `authz.go` files where the `Authenticate` function validates the bearer token from the Authorization header.
