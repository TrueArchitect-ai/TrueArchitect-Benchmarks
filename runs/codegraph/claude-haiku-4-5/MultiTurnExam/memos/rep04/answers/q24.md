The complete call chain for creating a memo flows through these files:
1. Frontend mutation hook in `useMemoQueries.ts` calls the memo service client
2. Service client created in `connect.ts` invokes the CreateMemo RPC
3. RPC defined in `memo_service.proto` routes to the backend handler
4. Handler `APIV1Service.CreateMemo` in `memo_service.go` calls the store method
5. `Store.CreateMemo` in `store/memo.go` delegates to the database driver
6. SQLite driver `DB.CreateMemo` in `store/db/sqlite/memo.go` executes the SQL INSERT
