web/src/hooks/useMemoQueries.ts; memoServiceClient

The `web/src/hooks/useMemoQueries.ts` module contains the memo CRUD mutations and queries (hooks like `useMemos`, `useInfiniteMemos`, and others for creating, updating, and deleting memos). It uses the `memoServiceClient` generated service client, which is created in `web/src/connect.ts` and imported into this hook file.
