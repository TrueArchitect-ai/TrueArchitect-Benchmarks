memo, memo_relation, attachment, memo_share

When DeleteMemo runs, the following database tables are affected:

1. **memo** - the memo row itself is deleted
2. **memo_relation** - explicitly deleted in code where this memo is either the source (memo_id) or target (related_memo_id)
3. **attachment** - explicitly deleted in code by iterating through and deleting each attachment linked to the memo
4. **memo_share** - automatically cascaded by the database's ON DELETE CASCADE foreign key constraint (memo_share.memo_id → memo.id)
