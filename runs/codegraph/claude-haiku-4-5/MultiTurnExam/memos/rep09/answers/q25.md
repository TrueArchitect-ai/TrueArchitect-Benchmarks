CEL (Common Expression Language) engine — internal/filter/engine.go; The filter package parses CEL expressions into an intermediate representation (IR), then renders the IR into dialect-specific SQL (SQLite, MySQL, PostgreSQL) with appropriate placeholders and JSON access patterns via the AppendConditions helper called from each database driver.

The ListMemos RPC accepts a **CEL (Common Expression Language)** filter syntax, parsed by the **engine in `internal/filter/engine.go`**. The mechanism works in three phases: (1) CEL parsing validates against memo schema, (2) normalization converts to dialect-agnostic IR, (3) rendering converts IR to dialect-specific SQL with placeholders and handling JSON fields in memo.payload via `AppendConditions()` helper called from each database driver (sqlite/mysql/postgres).
