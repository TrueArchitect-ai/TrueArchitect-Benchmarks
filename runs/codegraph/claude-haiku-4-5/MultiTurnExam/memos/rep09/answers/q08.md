The Go interface is named `Driver` and is defined in `store/driver.go` (lines 10-86). This interface contains all methods that database drivers must implement, including `GetDB()`, `Close()`, `IsInitialized()`, and methods for managing attachments, memos, users, settings, identity providers, inboxes, reactions, memo shares, and user identities. All database backends (MySQL, PostgreSQL, SQLite) implement this interface with their respective `DB` struct types.
