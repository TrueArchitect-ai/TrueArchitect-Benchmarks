Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, DeleteMemo, CreateMemoComment, dispatchMemoUpdatedSideEffects

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The SSE hub is implemented in `server/router/api/v1/sse_hub.go`. The memo-related handlers that broadcast through it are:
1. `CreateMemo` - broadcasts when a memo is created
2. `DeleteMemo` - broadcasts when a memo is deleted
3. `CreateMemoComment` - broadcasts when a comment is created
4. `dispatchMemoUpdatedSideEffects` - broadcasts when a memo is updated
