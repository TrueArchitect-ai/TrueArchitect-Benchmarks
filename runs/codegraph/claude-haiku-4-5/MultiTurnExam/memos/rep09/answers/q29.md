web/src/connect.ts; access tokens and refresh tokens; server/auth

Frontend API requests are authenticated via:
1. **Auth interceptor** - Located in `web/src/connect.ts` (lines 156-178), the `authInterceptor` attaches the access token to each request via the Authorization header
2. **Token kinds** - The interceptor manages:
   - **Access tokens** (short-lived JWT tokens, ~15 minutes) for API requests
   - **Refresh tokens** (stored as HttpOnly cookies) for obtaining new access tokens when expired
3. **Backend validation** - The `server/auth` package validates both token types, providing methods like `AuthenticateByAccessTokenV2()` and `AuthenticateByRefreshToken()` in `server/auth/authenticator.go`
