memo_relation records (where the memo is either the source or target), attachments

When a memo is deleted through the API, the store layer (in store/memo.go:140-158) deletes the following records before the memo row itself:

1. **MemoRelation** records where the memo is the source (memo_id)
2. **MemoRelation** records where the memo is the target (related_memo_id)
3. **Attachments** linked to the memo (by iterating and deleting each one)

Only after these cleanup operations does it delete the memo row itself.
