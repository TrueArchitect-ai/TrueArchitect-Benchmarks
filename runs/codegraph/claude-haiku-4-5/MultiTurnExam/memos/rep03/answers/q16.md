**Memo relations, Attachments**

When a memo is deleted through the API, the store layer deletes:
1. **Memo relations** (where the memo is either the source or target) - via `DeleteMemoRelation`
2. **Attachments** (linked to the memo) - via `DeleteAttachment`

These are cleaned up before the memo row itself is deleted. Additionally, at the API layer, memo comments (which are related memos) are also deleted first before calling the store's `DeleteMemo`.
