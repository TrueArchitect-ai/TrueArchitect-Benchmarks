**web/src/connect.ts; access tokens (JWT, short-lived) and refresh tokens; server/auth**

Frontend API requests are authenticated through:
- **Interceptor location**: `web/src/connect.ts` (lines 156-178 define `authInterceptor`)
- **Token kinds**: 
  - Access tokens (short-lived JWT, 15 minutes)
  - Refresh tokens (long-lived, stored server-side for revocation)
  - Personal Access Tokens (PATs) for programmatic access
- **Backend validation package**: `server/auth` (Authenticator struct in `server/auth/authenticator.go` validates tokens and provides shared authentication logic used by all API endpoints)
