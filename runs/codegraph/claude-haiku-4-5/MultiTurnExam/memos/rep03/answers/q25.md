**CEL (Common Expression Language) — internal/filter/engine.go; The filter string is parsed by a CEL engine, compiled into a condition tree, then rendered into dialect-specific SQL by the `AppendConditions` function which generates placeholder-aware WHERE clauses for each SQL dialect.**

The flow is:
- CEL parsing engine in `internal/filter/engine.go` parses the filter expression
- Each SQL dialect (SQLite, MySQL, PostgreSQL) has a `DialectName` constant in `internal/filter/schema.go`
- The `AppendConditions` function in `internal/filter/` renders the compiled condition tree into SQL using the appropriate dialect renderer (e.g., `filter.DialectSQLite`) which generates WHERE clause fragments with dialect-specific placeholders
