**S3 presign runner — 12-hour ticker interval (internal/scheduler infrastructure present but NOT used by the server)**

The server starts one background worker:
- **S3 presign runner** (server/runner/s3presign/runner.go) — Scheduled to run every 12 hours via a time.Ticker to refresh presigned URLs for S3-backed attachments

**Unused infrastructure note:** The codebase contains scheduling infrastructure in `internal/scheduler/scheduler.go` (a general-purpose job scheduler), but the server does not instantiate or use it. The S3 presign runner uses direct time-based scheduling with `time.Ticker` rather than the scheduler package.
