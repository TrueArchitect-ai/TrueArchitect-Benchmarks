**Go embed filesystem; server/router/frontend/frontend.go**

The compiled React frontend is served in production using Go's `embed` package (line 20: `//go:embed dist/*`) which embeds the pre-built `dist/` directory into the binary. The `FrontendService` in `server/router/frontend/frontend.go` serves these embedded files using Echo's static middleware with SPA fallback routing, allowing the frontend to serve both static assets and handle client-side routing by falling back to `index.html` for unknown paths.
