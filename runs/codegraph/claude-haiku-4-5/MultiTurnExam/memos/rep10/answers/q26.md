Based on the code analysis, when DeleteMemo runs, the following tables are affected through explicit cascade code in store/memo.go:

1. `memo` - the main memo record is deleted
2. `memo_relation` - all relations where this memo is source or target
3. `attachment` - all attachments linked to this memo
