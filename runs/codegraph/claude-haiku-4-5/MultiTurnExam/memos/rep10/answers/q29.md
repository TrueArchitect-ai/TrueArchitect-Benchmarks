server/router/api/v1/connect_interceptors.go; Access Tokens (JWT, short-lived), Personal Access Tokens (PAT, long-lived), Refresh Tokens; server/auth

The `NewAuthInterceptor` extracts the Authorization header and delegates to `Authorizer.Authenticate` which uses the `Authenticator` in `server/auth/authenticator.go` to validate Bearer tokens (either Access Token V2 for stateless validation or PAT for long-lived API access), with an optional fallback to refresh token cookies for session management.
