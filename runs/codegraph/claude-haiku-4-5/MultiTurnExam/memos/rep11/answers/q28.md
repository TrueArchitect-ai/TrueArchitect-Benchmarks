S3 Presign Runner — 12-hour interval ticker (server/runner/s3presign/runner.go:27, triggered via time.Ticker)

Note: The `internal/scheduler` package exists in the codebase but is NOT used by the server. It provides a general-purpose job scheduling infrastructure (defined in `internal/scheduler/scheduler.go` and `internal/scheduler/job.go`) that is currently unused.

The server starts only one background worker: the S3 Presign Runner, which periodically (every 12 hours) refreshes presigned URLs for S3 attachments. It runs as a continuous loop in `server/server.go:startBackgroundRunners()` using a time-based ticker. The runner can be cleanly shut down via context cancellation.
