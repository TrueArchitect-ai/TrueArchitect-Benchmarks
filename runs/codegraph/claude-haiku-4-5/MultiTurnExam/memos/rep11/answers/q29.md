The frontend authentication works through:
1. **Interceptor location**: `web/src/connect.ts` (the `authInterceptor` at line 156) which attaches authorization headers to all requests
2. **Token types managed**: 
   - Access tokens (short-lived JWT tokens, 15 minutes)
   - Refresh tokens (stored in HttpOnly cookies for token refresh)
   - Personal Access Tokens (PAT, long-lived tokens for programmatic access)
3. **Backend validation package**: `server/auth/` which contains the `Authenticator` that validates tokens using stateless JWT verification (`AuthenticateByAccessTokenV2` at line 39 of `authenticator.go`) and Personal Access Token validation via database lookup
