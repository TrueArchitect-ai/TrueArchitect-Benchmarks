CEL (Common Expression Language) engine — internal/filter/; the engine parses CEL expressions through a three-phase pipeline (parsing with cel-go, normalizing to dialect-agnostic IR, rendering to SQL fragments with dialect-specific handlers for JSON access, placeholders, and operators).

The ListMemos RPC filter uses:
- **Engine**: CEL (Common Expression Language) with a custom filter engine in `internal/filter/`
- **Mechanism**: The engine implements a three-phase pipeline: CEL expressions are parsed with `cel-go` and validated against the memo schema, converted to a dialect-agnostic intermediate representation (IR) in `ir.go`, then rendered by `render.go` into SQL fragments tailored to each dialect (SQLite/MySQL/PostgreSQL) with dialect-specific handling for JSON access, placeholders, boolean coercion, and operators.
