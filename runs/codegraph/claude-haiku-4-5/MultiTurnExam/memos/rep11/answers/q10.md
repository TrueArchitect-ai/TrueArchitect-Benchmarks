For a fresh SQLite install, the complete current schema is provided by the `LATEST.sql` file. As shown in the migration code (`store/migrator.go:54-56`), this file is used to initialize fresh installations with the current schema, which is faster than applying incremental migrations. For SQLite specifically, the path is `store/migration/sqlite/LATEST.sql`.
