NewDBDriver — store/db/db.go

The three implementations of the database driver interface are located in:
- `store/db/mysql/mysql.go` (MySQL implementation)
- `store/db/postgres/postgres.go` (PostgreSQL implementation)
- `store/db/sqlite/sqlite.go` (SQLite implementation)

The factory function that selects between them at startup is `NewDBDriver` defined in `store/db/db.go` at line 14, which switches on the `profile.Driver` field and calls the appropriate `NewDB()` function for each database dialect.
