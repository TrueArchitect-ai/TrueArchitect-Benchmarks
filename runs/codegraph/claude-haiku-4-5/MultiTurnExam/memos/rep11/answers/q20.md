Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, DeleteMemo, CreateMemoComment, dispatchMemoUpdatedSideEffects

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The hub is implemented in `server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through it are:
1. `CreateMemo` (broadcasts SSEEventMemoCreated)
2. `DeleteMemo` (broadcasts SSEEventMemoDeleted)
3. `CreateMemoComment` (broadcasts SSEEventMemoCommentCreated)
4. `dispatchMemoUpdatedSideEffects` (broadcasts SSEEventMemoUpdated)
