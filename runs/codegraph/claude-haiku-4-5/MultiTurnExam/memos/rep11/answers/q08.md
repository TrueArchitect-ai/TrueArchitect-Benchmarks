Driver — store/driver.go

The Go interface that all database backends implement is `Driver`, defined in `/bench/home/work/store/driver.go` starting at line 10. This interface defines all the methods that each database driver must implement, including `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, and various CRUD operations for different models (memos, attachments, users, etc.). Each of the three database backends (MySQL, PostgreSQL, SQLite) implements this interface with their own `DB` struct.
