The identity provider abstraction is defined in the `internal/idp` package (file: `internal/idp/idp.go`), which defines the `IdentityProviderUserInfo` type that serves as the interface contract for user information returned by identity providers.

The concrete protocol implementation that ships is OAuth2, defined in the `internal/idp/oauth2` package (file: `internal/idp/oauth2/oauth2.go`), which implements the `IdentityProvider` type with methods like `ExchangeToken` and `UserInfo` that handle the OAuth2 protocol flow.
