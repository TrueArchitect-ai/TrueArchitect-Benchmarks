The `Post` function at line 120 executes the outbound HTTP delivery by constructing an HTTP request and sending it via `safeClient.Do(req)` at line 152. The `safeClient` is a shared HTTP client initialized at lines 32–37 with a custom `Transport` that uses `safeDialContext` as its dialer.

The `safeDialContext` function (lines 59–77) protects against SSRF by resolving the target hostname, parsing each IP address it resolves to, and checking if it falls within a reserved/private IP range using `isReservedIP(ip)` at line 71. If any IP is reserved/private, the connection is rejected with an error message: "webhook: connection to reserved/private IP address is not allowed" (line 72). This defeats both direct internal IP targeting and DNS rebinding attacks, since the resolution and IP range check happen at dial time.
