**Premise correction:** This repository does not use GraphQL for its public API. It uses OpenAPI/REST instead.

**Actual API surface:**

The public API is defined via an **OpenAPI specification** (not GraphQL):

1. **OpenAPI YAML definition**: The OpenAPI schema is embedded in `proto/openapi_embed.go:6` as a generated file `gen/openapi.yaml`

2. **OpenAPI structure**: The schema is loaded and processed in `server/router/mcp/openapi.go` via:
   - `loadOpenAPISpec()` function that reads the YAML file
   - `buildOperationRegistry()` that parses operations from the spec
   - `openAPISpec` struct (lines 13-17) that defines the structure with `Paths`, `Components`, and `Schemas`

3. **Public endpoints**: The actual public API endpoints are defined as gRPC services in `server/router/api/v1/acl_config.go` in the `PublicMethods` map (lines 11-41), which specifies which gRPC procedures don't require authentication (e.g., `/memos.api.v1.AuthService/SignIn`, `/memos.api.v1.MemoService/GetMemo`, etc.)

The API is served as both gRPC (with Connect protocol) and REST (via gRPC-Gateway) using the embedded OpenAPI specification for documentation and validation.
