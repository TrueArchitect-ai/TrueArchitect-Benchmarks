1. **Payload extraction (tags and properties):** `internal/markdown/markdown.go` - specifically in the `Service.ExtractAll()` method (lines 356-422) which parses markdown content using the goldmark parser and walks the AST to extract metadata.

2. **Snippet generation:** `server/router/api/v1/memo_service_webhooks.go` - in the `getMemoContentSnippet()` method which calls `MarkdownService.GenerateSnippet()` (lines 264-346 of `internal/markdown/markdown.go`).

**Triggers for recomputation:**

- **On memo creation:** `server/router/api/v1/memo_service.go:108` - `CreateMemo()` calls `memopayload.RebuildMemoPayload()` before storing the memo
- **On content update:** `server/router/api/v1/memo_service.go:447` - `UpdateMemo()` calls `memopayload.RebuildMemoPayload()` when the "content" path is updated
- **Batch payload rebuild:** `server/runner/memopayload/runner.go:52` - `RebuildMemoPayload()` is called during batch processing (used for retroactive computation)

**Extracted properties:**

From `internal/markdown/markdown.go:ExtractedData`:
- **Tags** (`[]string`): Deduplicated #hashtags extracted from content, preserving case
- **Property** (`storepb.MemoPayload_Property`):
  - `Title` (string): Text of the first H1 heading, if present
  - `HasLink` (bool): Whether content contains any links
  - `HasCode` (bool): Whether content contains code blocks or inline code spans  
  - `HasTaskList` (bool): Whether content contains task list items
  - `HasIncompleteTasks` (bool): Whether there are unchecked task items
- **Snippet** (string): Plain text summary of up to 64 characters (computed from markdown), excluding code blocks, truncated at word boundaries
