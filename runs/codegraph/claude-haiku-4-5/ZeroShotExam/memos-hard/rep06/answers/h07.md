2. `serveUserAvatar` handler retrieves the username and calls `getUserByUsername` which queries the store
3. `Store.GetUser` calls `Store.ListUsers` to fetch the user record
4. `ListUsers` delegates to the driver's `ListUsers` (implementation in postgres/mysql/sqlite)
5. Database executes SQL `SELECT avatar_url ... FROM "user" WHERE username = ...`
6. User record with `AvatarURL` field returns to handler
