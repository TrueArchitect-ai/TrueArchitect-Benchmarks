The three distinct enforcement sites are:

- **Direct read access**: `checkMemoReadAccess()` function (server/router/api/v1/memo_service.go:39-68) which enforces visibility rules in GetMemo and validates archived/visibility status
- **List filtering**: Visibility filtering logic in ListMemos (server/router/api/v1/memo_service.go:219-226) which filters results based on user permissions and visibility levels
- **Comment creation**: Visibility check in CreateMemoComment (server/router/api/v1/memo_service_comments.go:41-42) which prevents non-owners from commenting on private memos
- **Memo share access**: GetMemoByShare (server/router/api/v1/memo_share_service.go:153-192) which enforces share token-based access control
