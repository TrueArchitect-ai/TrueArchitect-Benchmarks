**Premise correction:** This repository does not have a GraphQL schema for a public API. The API is built using **OpenAPI/REST** specification and **Protocol Buffers**, not GraphQL.

**Actual API surface:**

The public API is defined through:

1. **OpenAPI Specification** — `proto/gen/openapi.yaml` (embedded in `proto/openapi_embed.go:5-6`)
   - Loaded and parsed in `server/router/mcp/openapi.go:57-71`
   - Contains operation definitions, request/response schemas, and components

2. **gRPC/Protocol Buffers** — The API services are defined as gRPC services:
   - `memos.api.v1.AuthService` (SignIn, RefreshToken)
   - `memos.api.v1.InstanceService` (GetInstanceProfile, GetInstanceSetting, etc.)
   - `memos.api.v1.UserService` (CreateUser, GetUser, etc.)
   - `memos.api.v1.MemoService` (GetMemo, ListMemos, CreateMemo, etc.)
   - Defined in `.proto` files and generated TypeScript types in `web/src/types/proto/`

3. **Public Method Access Control** — `server/router/api/v1/acl_config.go:11-41`
   - Maps which gRPC procedures are publicly accessible without authentication
   - The "SINGLE SOURCE OF TRUTH" for public endpoints as documented in the file

The API uses OpenAPI for HTTP documentation/tooling and Protocol Buffers for the underlying gRPC service contracts.
