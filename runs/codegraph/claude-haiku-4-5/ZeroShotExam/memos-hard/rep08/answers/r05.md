**Premise correction:** This repository does not use GraphQL. It uses a gRPC API with an OpenAPI (REST) specification, not GraphQL.

**Actual API surface:**

The public API schema is defined in an **embedded OpenAPI YAML specification**:

1. **Location:** `proto/openapi_embed.go:5-6` — The OpenAPI spec is embedded as `gen/openapi.yaml`
   
2. **Generated from:** The spec is generated (likely from proto definitions) and embedded at build time via Go's `//go:embed` directive

3. **Loaded at runtime:** `server/router/mcp/openapi.go:57-71` — The spec is loaded and parsed via `loadOpenAPISpec()`, which deserializes the YAML into OpenAPI operation structures

4. **API operations defined in:** `server/router/mcp/openapi.go:73-103` — The `buildOperationRegistry()` function builds a registry of all operations from the embedded spec, keyed by `operationId`

5. **Public endpoints defined in:** `server/router/api/v1/acl_config.go:11-41` — The `PublicMethods` map explicitly lists all gRPC procedures that don't require authentication (e.g., `/memos.api.v1.AuthService/SignIn`, `/memos.api.v1.MemoService/GetMemo`, etc.)

The actual schema components are stored in `Components.Schemas` within the OpenAPI spec and resolved via schema references during runtime.
