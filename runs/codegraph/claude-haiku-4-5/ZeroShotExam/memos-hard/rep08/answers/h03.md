Based on the codebase, the provider abstraction and concrete protocol implementation are:

**Abstraction package:** `internal/idp` — This package defines the `IdentityProviderUserInfo` type (internal/idp/idp.go:3-8) which represents the abstraction for identity provider capabilities.

**Implementation package:** `internal/idp/oauth2` — This package provides the concrete OAuth2 protocol implementation via the `IdentityProvider` struct (internal/idp/oauth2/oauth2.go:20-22) which implements token exchange and user information retrieval methods (`ExchangeToken` and `UserInfo`).

The OAuth2 implementation is the concrete protocol shipped with the system, as evidenced by the template configurations in `web/src/components/CreateIdentityProviderDialog.tsx` showing GitHub, GitLab, Google, and Custom OAuth2 providers.
