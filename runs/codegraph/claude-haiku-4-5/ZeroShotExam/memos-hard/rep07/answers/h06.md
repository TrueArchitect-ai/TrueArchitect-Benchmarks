**Explanation:**

The three memo-related RPC handlers (`CreateMemo`, `UpdateMemo`, `DeleteMemo` in `server/router/api/v1/memo_service.go`) can transitively cause outbound HTTP requests to user-configured URLs:

1. **CreateMemo** → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`
2. **UpdateMemo** → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`  
3. **DeleteMemo** → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`

All three paths converge at **`webhook.Post`** (`internal/webhook/webhook.go:120`), where:
- Line 126 constructs the HTTP request: `http.NewRequest("POST", requestPayload.URL, ...)`
- Line 152 delivers it: `safeClient.Do(req)`

The `requestPayload.URL` comes from user-configured webhook URLs stored via `CreateUserWebhook`, making this the single function where all outbound HTTP requests to user-configured URLs are executed before delivery.
