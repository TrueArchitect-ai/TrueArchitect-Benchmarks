The markdown processing architecture has two separate implementations serving different concerns:

**Backend (Go):**
- **Impl:** `service` (concrete struct implementing `markdown.Service` interface) — `internal/markdown/markdown.go:58`
- **Construction:** `NewService()` factory function — `internal/markdown/markdown.go:85`

**Frontend (React/TypeScript):**
- **Impl:** `ReactMarkdown` component from react-markdown library (third-party, wraps react-markdown)
- **Construction:** Instantiated directly in `MemoMarkdownRenderer` — `web/src/components/MemoContent/MemoMarkdownRenderer.tsx:144`
- **Interface holder:** Custom component map (`Components` type from react-markdown) consumed by `MemoMarkdownRenderer` — `web/src/components/MemoContent/MemoMarkdownRenderer.tsx:56–166`

The backend uses goldmark for markdown parsing and AST manipulation (extracting tags, properties, rendering HTML). The frontend uses react-markdown with custom remark/rehype plugins for client-side rendering, delegating to components like `Heading`, `Paragraph`, `CodeBlock`, etc.
