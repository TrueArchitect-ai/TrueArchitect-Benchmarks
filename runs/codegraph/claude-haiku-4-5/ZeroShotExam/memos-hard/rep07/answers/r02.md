The per-user API rate-limiting middleware is **not registered** in this repository.

**Premise correction**: There is currently no per-user API rate-limiting middleware or request limits implemented in the codebase.

The API gateway setup in `server/router/api/v1/v1.go` (lines 64-147) registers four Connect interceptors: MetadataInterceptor, LoggingInterceptor, RecoveryInterceptor, and AuthInterceptor (as seen in `server/router/api/v1/connect_interceptors.go`), but none of these implement rate-limiting. The gRPC-Gateway and Connect handlers are configured without any rate-limiting middleware, and no per-user request limits are defined anywhere in the codebase.
