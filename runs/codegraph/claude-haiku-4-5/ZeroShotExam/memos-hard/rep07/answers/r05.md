**Premise correction:** This repository does not use GraphQL. The codebase uses gRPC with Protocol Buffers (Proto) as its API definition mechanism, along with OpenAPI specifications for HTTP/REST interfaces.

**Actual API surface:**

The public API is defined through:

1. **gRPC services** — Defined in Protocol Buffer files (`.proto`), which specify the service methods and message types. The gRPC-generated services include:
   - `AuthService` 
   - `UserService`
   - `MemoService`
   - `InstanceService`
   - `IdentityProviderService`
   - And others

2. **OpenAPI specification** — Embedded in `proto/openapi_embed.go:5-10` as `gen/openapi.yaml`, which provides REST/HTTP API documentation. This is loaded and parsed by `server/router/mcp/openapi.go` to build the operation registry.

3. **Public API access control** — Defined in `server/router/api/v1/acl_config.go:11-41`, where `PublicMethods` maps the gRPC procedure paths that don't require authentication (e.g., `/memos.api.v1.AuthService/SignIn`, `/memos.api.v1.MemoService/GetMemo`).

There is no GraphQL schema in this repository.
