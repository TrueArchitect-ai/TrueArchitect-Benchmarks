The RPC handler methods that can transitively cause outbound HTTP requests to user-configured URLs are:

1. **CreateMemo** — calls `DispatchMemoCreatedWebhook` (server/router/api/v1/memo_service.go:157)
2. **UpdateMemo** — calls `dispatchMemoUpdatedSideEffects` which calls `DispatchMemoUpdatedWebhook` (server/router/api/v1/memo_service.go:513)
3. **DeleteMemo** — calls `DispatchMemoDeletedWebhook` (server/router/api/v1/memo_service.go:562)
4. **CreateMemoComment** — calls `DispatchMemoCommentCreatedWebhook` (implicitly, via comment creation side effects)

All of these paths converge before delivery at the **Post function** (internal/webhook/webhook.go:120), which constructs an HTTP POST request and sends it to the user-configured webhook URL using a secure HTTP client (`safeClient`) that blocks connections to reserved/private IP addresses. The webhook URL is obtained from the user's stored webhooks (retrieved via `s.Store.GetUserWebhooks`) and is passed as `payload.URL` to the webhook dispatch functions, which ultimately call either `webhook.Post()` for synchronous delivery or `webhook.PostAsync()` for asynchronous delivery.
