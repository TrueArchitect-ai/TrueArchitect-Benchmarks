**Premise correction:** This is not a GraphQL API — it's a **gRPC + OpenAPI (REST) API**. The project uses protobuf-based gRPC services with an OpenAPI specification for REST access.

**Actual API surface definition:**

The public API schema is defined in **`proto/openapi_embed.go`** which embeds the generated OpenAPI specification:

```
proto/openapi_embed.go:5 — //go:embed gen/openapi.yaml
proto/openapi_embed.go:9 — OpenAPIYAML() returns the embedded generated OpenAPI specification
```

The OpenAPI schema is generated from protobuf definitions and is embedded as `gen/openapi.yaml`. This YAML file is:
1. **Loaded and parsed** in `server/router/mcp/openapi.go:57` via `loadOpenAPISpec()`
2. **Built into an operation registry** in `server/router/mcp/openapi.go:73` via `buildOperationRegistry()`
3. **Used by MCP service** in `server/router/mcp/catalog.go` to build tools from OpenAPI operations
4. **Accessed via REST gateway** for the public HTTP API

The gRPC service definitions themselves are in the `proto/` directory (referenced by the memos.api.v1 service paths like `/memos.api.v1.AuthService/SignIn`), and public endpoints are explicitly enumerated in **`server/router/api/v1/acl_config.go:11`** in the `PublicMethods` map.
