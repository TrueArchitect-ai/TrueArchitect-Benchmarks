The `Post` function (line 120) executes the actual outbound HTTP delivery by constructing and sending the webhook request. It uses a shared `safeClient` (line 32) configured with a custom `DialContext` that intercepts all network connections.

The protection against internal network addresses is implemented in `safeDialContext` (line 57), which:
1. Resolves the target hostname to IP addresses (line 65)
2. Validates each IP address against reserved/private ranges using `isReservedIP` (line 71)
3. Rejects any connection attempt to internal network addresses with an explicit error (line 72)

This protection runs at dial time before any connection is established, defeating both direct connections to private IPs and DNS rebinding attacks.
