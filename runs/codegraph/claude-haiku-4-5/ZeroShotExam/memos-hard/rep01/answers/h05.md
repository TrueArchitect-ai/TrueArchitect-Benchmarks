**Mechanism: Explicit Go code**

When a user is deleted, their emoji reactions are removed by **explicit Go code** through two separate DELETE statements executed within a database transaction:

1. **Reactions on the deleted user's own memos** are deleted via `deleteReactionsByContentIDsTx()` — which deletes all reactions where `content_id` matches the user's memos (line 96 in `store/db/mysql/user_delete.go`)

2. **Reactions created by the deleted user** are deleted via `deleteReactionsByCreatorTx()` — which deletes all reactions where `creator_id = userID` (line 102 in `store/db/mysql/user_delete.go`)
