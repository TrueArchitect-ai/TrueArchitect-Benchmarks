**Premise Correction:** This repository does not define a GraphQL schema for a public API. Instead, it defines a REST API using the OpenAPI specification format.

**Actual API Surface:**

The OpenAPI schema is defined in **`proto/gen/openapi.yaml`** (embedded as a binary resource in `proto/openapi_embed.go` at line 5-6).

The schema is:
1. **Embedded in the binary** via `//go:embed gen/openapi.yaml` in `proto/openapi_embed.go:5`
2. **Loaded and parsed** by `loadOpenAPISpec()` in `server/router/mcp/openapi.go:57`
3. **Describes REST endpoints** via OpenAPI 3.0 specification format with:
   - Paths and HTTP methods (`server/router/mcp/openapi.go:15`)
   - Request/response schemas in JSON Schema format (`server/router/mcp/openapi.go:13-21`)
   - Components defining reusable schema definitions

The public API surface is controlled by **ACL definitions** in `server/router/api/v1/acl_config.go:11-41` (the `PublicMethods` map), which specifies which gRPC procedures are accessible without authentication, including endpoints like:
- `/memos.api.v1.AuthService/SignIn`
- `/memos.api.v1.MemoService/GetMemo`
- `/memos.api.v1.MemoService/ListMemos`
