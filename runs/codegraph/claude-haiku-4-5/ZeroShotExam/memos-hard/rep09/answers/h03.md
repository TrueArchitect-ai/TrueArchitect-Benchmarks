Based on the codebase exploration, I found the identity provider architecture:

**Abstraction package**: `internal/idp`

This defines the abstraction with `IdentityProviderUserInfo` struct in `internal/idp/idp.go:3`, which represents the user information returned by identity providers.

**Concrete protocol implementation**: `internal/idp/oauth2`

This package implements the OAuth2 identity provider integration, as stated in its package comment at `internal/idp/oauth2/oauth2.go:1-2`. The `IdentityProvider` struct at line 20 is the concrete implementation that provides `ExchangeToken()` and `UserInfo()` methods to handle OAuth2 token exchange and user information retrieval.

The implementation is used throughout the codebase, with the web UI in `web/src/components/CreateIdentityProviderDialog.tsx` providing templates for GitHub, GitLab, Google, and custom OAuth2 providers.
