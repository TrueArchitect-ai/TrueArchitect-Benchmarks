- **Worker initialization** (lines 42–55): The `init()` function spawns 4 goroutines that consume from `asyncPostQueue` and execute webhook POST requests synchronously via the `Post()` function

The queue is a simple in-memory channel, not an external message broker. Webhook payloads are enqueued by the API layer (`server/router/api/v1/memo_service_webhooks.go:71` via `webhook.PostAsync(payload)`) and consumed by the 4 worker goroutines running in the same process.
