**Premise correction:** This repository does not have a GraphQL schema for a public API. Instead, it uses Protocol Buffers (protobuf) for its API definition.

**Actual API surface:** The public API is defined through:

1. **Proto files** (source schema definitions):
   - `proto/api/v1/*.proto` — these are the source files defining the gRPC service definitions and message types (e.g., `ai_service.proto`, `attachment_service.proto`, etc.)

2. **Generated Go bindings** from proto definitions:
   - `proto/gen/api/v1/*_pb.go` — generated Protocol Buffer message definitions
   - `proto/gen/api/v1/apiv1connect/*.connect.go` — generated Connect (gRPC-compatible HTTP) service definitions
   - `proto/gen/api/v1/*_grpc.pb.go` — generated gRPC service definitions

3. **OpenAPI specification** (derived from the gRPC services):
   - `proto/gen/openapi.yaml` — generated OpenAPI/Swagger spec (embedded in `proto/openapi_embed.go`)
   - This spec is processed and served via `server/router/mcp/openapi.go`

4. **Access control definitions**:
   - `server/router/api/v1/acl_config.go` — defines which endpoints require authentication (PublicMethods, AuthBootstrapMethods)

The API is served via both gRPC and Connect (HTTP protocol), not GraphQL. The OpenAPI spec in `proto/gen/openapi.yaml` provides the HTTP API surface and is used by the MCP (Model Context Protocol) tool catalog.
