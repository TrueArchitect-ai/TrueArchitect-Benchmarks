**Premise correction**: This repository does not have a GraphQL public API. The public API is defined using OpenAPI/REST, not GraphQL.

**Actual API surface**: The public API is defined by an embedded OpenAPI specification at `proto/gen/openapi.yaml`, loaded and exposed via:

- **OpenAPI specification file**: `proto/gen/openapi.yaml` (embedded in `proto/openapi_embed.go`)
- **Loader**: `server/router/mcp/openapi.go:57` (`loadOpenAPISpec`) loads the YAML file
- **Schema handling**: The OpenAPI spec is parsed into operations and schemas in `server/router/mcp/openapi.go` and used by the MCP (Model Context Protocol) service in `server/router/mcp/catalog.go` to build tools
- **Public endpoints**: Defined in `server/router/api/v1/acl_config.go:11` (`PublicMethods` map) which lists gRPC procedure paths that are publicly accessible without authentication
