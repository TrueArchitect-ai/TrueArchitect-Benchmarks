**Premise correction:** This repository does not use GraphQL. The API is defined using **OpenAPI/REST** (not GraphQL), with the schema specification in YAML format.

**Actual API surface:**

The GraphQL schema question contains a false premise. The public API is defined as an OpenAPI specification in:

- **`proto/openapi_embed.go`** — Contains an embedded OpenAPI YAML specification (`gen/openapi.yaml`) that is loaded at runtime via `OpenAPIYAML()`.
- **`server/router/mcp/openapi.go`** — Parses and processes the OpenAPI specification, resolving schema references and building an operation registry from the embedded YAML.
- **`server/router/mcp/catalog.go`** — Converts OpenAPI operations into MCP tools, building the curated tool catalog from the OpenAPI spec.

The actual OpenAPI specification file is at `proto/gen/openapi.yaml` (embedded and served by `OpenAPIYAML()` from `proto/openapi_embed.go:6`).

The API endpoints and their access control are documented in **`server/router/api/v1/acl_config.go`**, which defines `PublicMethods` (endpoints accessible without authentication) and uses gRPC procedure paths like `/memos.api.v1.AuthService/SignIn`.
