**Computation site:** `internal/markdown/markdown.go` — the `ExtractAll()` method (line 356) and supporting `ExtractProperties()` method (line 193), which parse markdown content using the goldmark library.

**Triggers:** Metadata recomputation is triggered by:
1. **Memo creation** — `server/router/api/v1/memo_service.go`: when `CreateMemo()` is called, `RebuildMemoPayload()` is invoked
2. **Memo update** — `server/router/api/v1/memo_service.go`: when content is patched via `UpdateMemo()`, `RebuildMemoPayload()` is invoked
3. **Batch recomputation** — `server/runner/memopayload/runner.go`: `RunOnce()` rebuilds all memo payloads in batches of 100

**Extracted properties** (defined in `proto/store/memo.proto` as `MemoPayload_Property`):
- `title` — plain text extracted from the first H1 heading in the memo, if present
- `has_link` — boolean flag, true if any markdown links are present
- `has_code` — boolean flag, true if code blocks or inline code spans are present
- `has_task_list` — boolean flag, true if GFM task list checkboxes are present
- `has_incomplete_tasks` — boolean flag, true if any unchecked task list items exist

Additionally, `ExtractAll()` also extracts:
- `tags` — array of all #hashtags found (deduplicated, case-preserved)
- `mentions` — array of all @username mentions found (deduplicated, lowercased) — used for mention notifications in `memo_mention_helpers.go` but not persisted to `MemoPayload`
