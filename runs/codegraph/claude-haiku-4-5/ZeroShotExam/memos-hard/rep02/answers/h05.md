**Evidence locations:**

When a user is deleted, emoji reactions are removed by explicit Go code through the `deleteReactionsByCreatorTx` function called during user deletion.

The evidence is in three database implementation files:

1. **`store/db/mysql/user_delete.go:437-440`** — The `deleteReactionsByCreatorTx` function executes a SQL DELETE statement: `DELETE FROM reaction WHERE creator_id = ?`

2. **`store/db/postgres/user_delete.go:400-403`** — Identical implementation with the same logic

3. **`store/db/sqlite/user_delete.go:400-403`** — Identical implementation with the same logic

Additionally, in the `deleteUserTargetsTx` function (called at line 43 of the DeleteUser flow), there are two explicit deletion calls for reactions:
- **Line 96** (MySQL/Postgres/SQLite): `deleteReactionsByContentIDsTx` — deletes reactions on memos the user created (by content_id)
- **Line 102** (MySQL/Postgres/SQLite): `deleteReactionsByCreatorTx` — deletes reactions created by the user (by creator_id)

This is a two-part cleanup: it removes both reactions the deleted user made and reactions on the user's own memos.
