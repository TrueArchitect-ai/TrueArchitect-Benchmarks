**Premise correction:** This is not a GraphQL API — it's a gRPC/REST API with OpenAPI specification and MCP (Model Context Protocol) integration.

**Actual API surface:**

The public API is defined through an **OpenAPI specification** rather than GraphQL:

1. **OpenAPI Specification File**: `proto/gen/openapi.yaml` — embedded at `proto/openapi_embed.go:5` via `//go:embed gen/openapi.yaml`. The `OpenAPIYAML()` function at `proto/openapi_embed.go:9` returns this embedded spec.

2. **OpenAPI Parsing & Registry**: 
   - `server/router/mcp/openapi.go` defines the OpenAPI spec structures and parsing logic
   - `loadOpenAPISpec()` reads the YAML file and parses it (`server/router/mcp/openapi.go:57`)
   - `buildOperationRegistry()` builds a registry of OpenAPI operations with their request/response schemas (`server/router/mcp/openapi.go:73`)

3. **gRPC Service Definitions**: The API is gRPC-based with services like:
   - `memos.api.v1.AuthService` (SignIn, RefreshToken)
   - `memos.api.v1.MemoService` (GetMemo, ListMemos, etc.)
   - `memos.api.v1.UserService`, `InstanceService`, `IdentityProviderService`
   - Full procedure paths defined at `server/router/api/v1/acl_config.go:11` in the `PublicMethods` map

4. **MCP Tool Generation**: The OpenAPI spec is converted to MCP tools via `server/router/mcp/catalog.go:47` (`buildCuratedTools()`), which exposes curated operations as tools with input/output schemas derived from the OpenAPI specification.

**In summary:** The GraphQL schema does not exist — this is a **gRPC API with OpenAPI specification** at `proto/gen/openapi.yaml`, with public endpoints listed in `server/router/api/v1/acl_config.go`.
