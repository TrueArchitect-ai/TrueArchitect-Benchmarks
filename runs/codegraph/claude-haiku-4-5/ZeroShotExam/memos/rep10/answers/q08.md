**Driver** — `store/driver.go`

The Go interface that all database backends implement is named `Driver`, defined at `store/driver.go:10`. It specifies all methods that store database drivers must implement, including `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, and various model-related CRUD operations. The implementations for SQLite, MySQL, and PostgreSQL backends all implement this interface.
