**Engine + path:** The `Engine` struct lives in `internal/filter/engine.go:14`. It uses CEL (Common Expression Language) from Google's `cel-go` library to parse filter expressions.

**Mechanism in one sentence:** The filter expression is parsed by CEL into an AST, converted to a `Condition` tree (dialect-agnostic intermediate representation), then rendered to SQL via a `renderer` that generates dialect-specific SQL (with placeholders) for each supported dialect (SQLite, MySQL, PostgreSQL) by walking the condition tree and calling `renderCondition()` for each condition type, which dispatches to dialect-specific methods that use the `DialectName` parameter to emit the correct SQL syntax.
