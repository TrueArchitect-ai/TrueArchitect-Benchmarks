q26.

When DeleteMemo runs, the following database tables are directly or by explicit cascade code affected:

1. **memo_relation** — Deleted twice: once for relations where the memo is the source (MemoID), once where it is the target (RelatedMemoID). See `store/memo.go:142-146`

2. **attachment** — All attachments linked to the memo are deleted. See `store/memo.go:149-157` which calls `DeleteAttachment` for each attachment found

3. **memo** — The memo record itself is deleted. See `store/db/mysql/memo.go:259-270` and `store/db/postgres/memo.go:244-255`

Additionally, if the memo has comments (which are memos with a parent-child relation), those comment memos are recursively deleted via the same DeleteMemo call. See `server/router/api/v1/memo_service.go:568-577`.

**Answer: memo, memo_relation, attachment**
