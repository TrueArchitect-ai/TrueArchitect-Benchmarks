When a memo is deleted through the API, the store layer deletes the following kinds of records before the memo row itself:

1. **Memo relations** (where the memo is the source) - via `DeleteMemoRelation` with `MemoID` filter (line 142)
2. **Memo relations** (where the memo is the target) - via `DeleteMemoRelation` with `RelatedMemoID` filter (line 145)
3. **Attachments** - all attachments linked to the memo are deleted (lines 149-157)

This is shown in `store/memo.go:140-158` in the `DeleteMemo` method, which performs these deletions in order before finally calling `s.driver.DeleteMemo(ctx, delete)` to delete the memo row itself.
