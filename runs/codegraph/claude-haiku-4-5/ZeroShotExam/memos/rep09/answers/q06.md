**memo_relation**

The database table that stores links between one memo and another related memo is **`memo_relation`**. This table contains three columns:
- `memo_id`: The ID of the source memo
- `related_memo_id`: The ID of the related/target memo  
- `type`: The type of relation (e.g., "REFERENCE", "COMMENT")

It has a UNIQUE constraint on the combination of (memo_id, related_memo_id, type) to prevent duplicate relations.
