The server starts the following background runners:

1. **S3 presign runner** — triggered by a 12-hour timer interval (`server/runner/s3presign/runner.go:27`, constant `runnerInterval = time.Hour * 12`). Started in `server/server.go:162-171` with an initial `RunOnce(ctx)` call and then continuous running via `Run(s3Context)`.

**Unused scheduling infrastructure:**

The codebase contains a general-purpose `Scheduler` package (`internal/scheduler/scheduler.go`) with cron expression parsing (`ParseCronExpression`) and job scheduling capabilities. However, **this Scheduler is NOT used by the server**. The server only uses the S3 presign runner with a hardcoded 12-hour interval timer, not the flexible cron-based scheduler infrastructure.

There is also a `memopayload` runner (`server/runner/memopayload/runner.go`) defined, but it is **NOT started by the server** — only its `RunOnce` method exists and is not invoked in `startBackgroundRunners()`.
