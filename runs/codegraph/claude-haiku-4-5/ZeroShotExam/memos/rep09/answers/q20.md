**Mechanism**: Server-Sent Events (SSE) via HTTP; clients connect to `/api/v1/sse` endpoint with `Accept: text/event-stream` header and receive JSON messages in SSE format.

**Hub path**: `server/router/api/v1/sse_hub.go` — contains `SSEHub` struct that manages client connections, `SSEEvent` struct for the event payload, and methods `Subscribe()`, `Unsubscribe()`, `Close()`, and `Broadcast()`. Events are filtered by visibility (Private events only sent to creator or admin).

**Memo handlers that broadcast through it**:
1. `CreateMemo` (server/router/api/v1/memo_service.go:163) — broadcasts `SSEEventMemoCreated`
2. `dispatchMemoUpdatedSideEffects` (server/router/api/v1/memo_update_helpers.go:71) — broadcasts `SSEEventMemoUpdated` (called by UpdateMemo, SetMemoAttachments, SetMemoRelations)
3. `DeleteMemo` (server/router/api/v1/memo_service.go) — broadcasts `SSEEventMemoDeleted`
4. `CreateMemoComment` (server/router/api/v1/memo_service_comments.go) — broadcasts `SSEEventMemoCommentCreated`
5. `UpsertMemoReaction` (server/router/api/v1/reaction_service.go) — broadcasts `SSEEventReactionUpserted`
6. `DeleteMemoReaction` (server/router/api/v1/reaction_service.go) — broadcasts `SSEEventReactionDeleted`

The client-side handler is in `web/src/hooks/useLiveMemoRefresh.ts`, which parses incoming SSE messages and invalidates React Query cache entries to trigger UI updates.
