The ConnectRPC service clients are created in **web/src/connect.ts**. This file creates a transport using `createConnectTransport` from `@connectrpc/connect-web` and then uses `createClient` to instantiate all the service clients:

- `instanceServiceClient`
- `authServiceClient`
- `userServiceClient`
- `memoServiceClient`
- `attachmentServiceClient`
- `aiServiceClient`
- `shortcutServiceClient`
- `identityProviderServiceClient`

These clients are exported and used throughout the frontend application to communicate with the backend services via the ConnectRPC protocol.
