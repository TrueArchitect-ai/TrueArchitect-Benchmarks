The ConnectRPC service clients are created in **`web/src/connect.ts`** (lines 192-203). This file creates all the service clients using the `createClient` function from `@connectrpc/connect`, including:
- `instanceServiceClient` (line 192)
- `authServiceClient` (line 193)
- `userServiceClient` (line 194)
- `memoServiceClient` (line 197)
- `attachmentServiceClient` (line 198)
- `aiServiceClient` (line 199)
- `shortcutServiceClient` (line 200)
- `identityProviderServiceClient` (line 203)

All clients are instantiated with a shared `transport` (lines 184-189) that's configured with the Connect protocol, binary Protobuf codec, and an authentication interceptor.
