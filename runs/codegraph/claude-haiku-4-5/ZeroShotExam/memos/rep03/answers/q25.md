q25.

**CEL (Common Expression Language) engine** located at `internal/filter/engine.go`; the filter is parsed via CEL's compiler into an AST, then transformed into a dialect-agnostic condition tree in `internal/filter/parser.go`, and finally rendered to dialect-specific SQL (MySQL, PostgreSQL, SQLite) via `internal/filter/render.go` using a renderer that walks the condition tree and emits appropriate SQL fragments for each dialect.
