The compiled React frontend is served using Go's **`embed` filesystem + Echo middleware**. The mechanism uses:

1. **Embedded filesystem**: The compiled React app is embedded at build time using Go's `//go:embed dist/*` directive (line 20-21 of `server/router/frontend/frontend.go`), making the built frontend files available as `embeddedFiles`.

2. **Static file serving**: The `Serve()` method (line 41) in `server/router/frontend/frontend.go` configures Echo's `StaticWithConfig` middleware to serve these embedded files with proper cache headers.

3. **SPA fallback**: A custom middleware (`spaFallbackMiddleware`, line 63) catches 404s and serves `index.html` for non-API routes, enabling client-side routing.
