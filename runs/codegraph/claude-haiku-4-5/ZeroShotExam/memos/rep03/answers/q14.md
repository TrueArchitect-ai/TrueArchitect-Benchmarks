The ShortcutService has the following RPCs:

1. **ListShortcuts** - returns a user's saved shortcuts
2. **GetShortcut** - gets a shortcut by name
3. **CreateShortcut** - creates a new shortcut for a user
4. **UpdateShortcut** - updates a shortcut for a user
5. **DeleteShortcut** - deletes a shortcut for a user

The backend implementation file is: **`server/router/api/v1/shortcut_service.go`**

All five RPC methods are implemented in this single file with the following method signatures:
- `ListShortcuts()` at line 49
- `GetShortcut()` at line 95
- `CreateShortcut()` at line 135
- `UpdateShortcut()` at line 211
- `DeleteShortcut()` at line 284
