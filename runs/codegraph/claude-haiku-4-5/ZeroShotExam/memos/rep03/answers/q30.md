All webhook dispatches converge at `webhook.PostAsync()` in `internal/webhook/webhook.go:184`. This function enqueues requests to `asyncPostQueue`, which is a buffered channel (capacity 128) that is serviced by 4 goroutines initialized in the `webhook` package's `init()` function. Each goroutine consumes from the queue and calls `webhook.Post()` (line 120) for actual delivery. The `Post()` function handles the synchronous HTTP request delivery with HMAC-SHA256 signing, retry logic, and SSRF protection via `safeDialContext`.
