The **CEL (Common Expression Language)** engine parses filter expressions, located in `internal/filter/engine.go`. The filter becomes SQL through a two-step process: the CEL AST is converted into a dialect-agnostic condition tree (`Condition` interface in `internal/filter/ir.go`), and then a `renderer` in `internal/filter/render.go` walks that tree to emit database-specific SQL with placeholder parameters based on the target dialect (MySQL, SQLite, PostgreSQL) while managing parameter offsets per dialect's syntax conventions.
