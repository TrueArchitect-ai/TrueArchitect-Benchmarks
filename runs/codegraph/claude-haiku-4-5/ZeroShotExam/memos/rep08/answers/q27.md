The compiled React frontend is served in production using Go's **embed directive** (go:embed) combined with **Echo's StaticWithConfig middleware**. The mechanism wires the compiled frontend files that are embedded at build time into the Echo HTTP server as a static file system.

The implementation is wired in **server/server.go** at line 72, where:
1. A `FrontendService` is created with `frontend.NewFrontendService(profile, store)`
2. Its `Serve()` method is called, which registers the embedded files via Echo's middleware

The key file where this is implemented is **server/router/frontend/frontend.go**:
- Line 20-21: The `//go:embed dist/*` directive embeds the compiled React build output
- Line 42: `getFileSystem("dist")` extracts the embedded filesystem
- Lines 54-57: `middleware.StaticWithConfig()` registers the static file middleware with Echo
- Line 59: `spaFallbackMiddleware()` provides SPA routing (fallback to index.html for client-side routes)
