q06. memo_relation

The database table that stores links between one memo and another related memo is `memo_relation`. This table is defined in `/bench/home/work/store/migration/sqlite/0.13/00__memo_relation.sql` and contains the following columns:
- `memo_id`: the ID of the source memo
- `related_memo_id`: the ID of the related/linked memo  
- `type`: the type of relationship (e.g., REFERENCE or COMMENT)
