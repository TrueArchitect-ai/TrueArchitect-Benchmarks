The ConnectRPC service clients are created in `web/src/connect.ts`. This file uses the `createClient` function from the `@connectrpc/connect` library to instantiate the service clients (like `memoServiceClient`, `authServiceClient`, etc.) on lines 192-203. The clients are created with a shared transport that is configured with authentication interceptors and credentials.
