**Convergence for delivery:**

All webhook dispatches converge through `webhook.PostAsync()` located in `internal/webhook/webhook.go:184`. This function enqueues webhook payloads to an async queue (`asyncPostQueue` at line 39) that is processed by 4 concurrent worker goroutines (initialized in the `init()` function at lines 42-55). Each worker calls `webhook.Post()` (line 46) to perform the actual HTTP delivery.

The delivery happens synchronously in `webhook.Post()` (`internal/webhook/webhook.go:120`), which handles HMAC-SHA256 signing, constructs the HTTP request with proper headers, and sends it to the webhook URL defined in the payload.
