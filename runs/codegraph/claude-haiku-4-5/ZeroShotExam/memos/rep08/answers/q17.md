The frontend module containing the memo CRUD mutations/queries is **`web/src/hooks/useMemoQueries.ts`**, and it uses the **`memoServiceClient`** generated service client.

The file contains the following CRUD operations:
- `useMemos()` - read list (query)
- `useInfiniteMemos()` - read list with pagination (query)
- `useMemo()` - read detail (query)
- `useCreateMemo()` - create (mutation)
- `useUpdateMemo()` - update (mutation)
- `useDeleteMemo()` - delete (mutation)

All of these operations use `memoServiceClient` imported from `@/connect` (line 116, 126, 146, 183, 202, 258, etc.).
