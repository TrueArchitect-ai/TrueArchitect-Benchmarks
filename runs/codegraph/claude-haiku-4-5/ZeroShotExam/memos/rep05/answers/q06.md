The database table that stores links between one memo and another related memo is **memo_relation**.

This table is defined in `/bench/home/work/store/migration/sqlite/0.13/00__memo_relation.sql` and contains the following columns:
- `memo_id`: The ID of the source memo
- `related_memo_id`: The ID of the related/linked memo
- `type`: The type of relation (e.g., "REFERENCE" or "COMMENT")

The table has a unique constraint on (memo_id, related_memo_id, type) to prevent duplicate relations.
