This project ships migrations for three SQL dialects: **sqlite, mysql, postgres**

These are defined as constants in `internal/filter/schema.go:14-16` and correspond to migration directories under `store/migration/`:
- `store/migration/sqlite/`
- `store/migration/mysql/`
- `store/migration/postgres/`

The migration system uses these dialect names via the `s.profile.Driver` field (referenced in `store/migrator.go:255`) to load the appropriate migration files for the configured database.
