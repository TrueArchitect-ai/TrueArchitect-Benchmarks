**Interceptor path:** `web/src/connect.ts` (lines 156–178, the `authInterceptor` function)

**Token kinds:** 
- Access Token V2 (JWT access tokens, short-lived ~15 minutes)
- Personal Access Tokens (PAT) (long-lived tokens for programmatic access)
- Refresh Token (stored in HttpOnly cookie)

**Backend package path:** `server/auth` (specifically `server/auth/authenticator.go`, the `Authenticator` struct and its methods including `Authenticate`, `AuthenticateByAccessTokenV2`, and `AuthenticateByPAT`)

The frontend's `authInterceptor` extracts the bearer token from the Authorization header (set via `setAuthorizationHeader` at line 99) and attaches it to each request. The backend's `server/auth.Authenticator` validates these tokens: it performs stateless validation of JWT access tokens via `AuthenticateByAccessTokenV2`, validates Personal Access Tokens via `AuthenticateByPAT` with database lookup, and falls back to refresh token validation via `AuthenticateByRefreshToken`.
