For a fresh SQLite install, the complete current schema is provided by the single file:

**store/migration/sqlite/LATEST.sql**

This file contains all the `CREATE TABLE` statements and indexes needed to set up a fresh SQLite database from scratch, including tables for system_setting, user, user_setting, memo, memo_relation, attachment, idp, inbox, reaction, memo_share, and user_identity.
