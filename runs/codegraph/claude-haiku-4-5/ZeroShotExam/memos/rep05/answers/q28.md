The server starts **ONE** background worker:

- **S3 presign runner** — triggered by a 12-hour interval timer (`time.NewTicker(runnerInterval)` where `runnerInterval = time.Hour * 12` in `server/runner/s3presign/runner.go:27, 30`)

**Unused scheduling infrastructure:**

The codebase contains a `Scheduler` infrastructure in `internal/scheduler/scheduler.go` that supports cron-based job scheduling with timezone and middleware support. However, this scheduler is **NOT used by the server** — the server does not instantiate or invoke it. The scheduler is defined and ready to manage registered jobs via cron expressions (see `Scheduler.Register()` and `Scheduler.Start()`), but no jobs are registered with it in the server initialization flow.

Additionally, there is an unused `memopayload/runner.go` package with a `Runner` that can rebuild memo payloads via `RunOnce()`, but it is never instantiated or started by the server.
