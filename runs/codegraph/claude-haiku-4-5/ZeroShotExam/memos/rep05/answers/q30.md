**Memo lifecycle webhook events and dispatch functions:**

- memos.memo.created: DispatchMemoCreatedWebhook
- memos.memo.updated: DispatchMemoUpdatedWebhook
- memos.memo.deleted: DispatchMemoDeletedWebhook
- memos.memo.comment.created: DispatchMemoCommentCreatedWebhook

**Convergence for delivery:**
All webhook events converge at `webhook.PostAsync()` in `internal/webhook/webhook.go:184`, which enqueues payloads to an asynchronous dispatch queue. The actual delivery happens in `webhook.Post()` in `internal/webhook/webhook.go:120`, which constructs the HTTP request with HMAC-SHA256 signing and executes the POST to the webhook URL.

The dispatch flow:
1. Event-specific functions (`DispatchMemoCreatedWebhook`, etc.) call `dispatchMemoRelatedWebhook` or handle dispatch directly (for comments)
2. These build a `WebhookRequestPayload` via `convertMemoToWebhookPayload`
3. All paths call `webhook.PostAsync()` to queue for async delivery
4. 4 goroutines consume from `asyncPostQueue` and call `webhook.Post()` to deliver
