**Mechanism:** Server-Sent Events (SSE)

**Hub path:** `server/router/api/v1/sse_hub.go`

**Handler names that broadcast through it:** 
- `CreateMemo` 
- `DeleteMemo`
- `CreateMemoComment`
- `dispatchMemoUpdatedSideEffects`
- `UpsertMemoReaction`
- `DeleteMemoReaction`

The SSE hub is implemented in `server/router/api/v1/sse_hub.go` with the `SSEHub` struct managing client connections. Clients subscribe via `hub.Subscribe()` at the `/api/v1/sse` endpoint (registered in `server/router/api/v1/sse_handler.go`). The hub's `Broadcast()` method (line 115) sends events to all connected clients, filtering by visibility/permissions via `canReceive()`. On the client side, `web/src/hooks/useLiveMemoRefresh.ts` establishes the SSE connection and invalidates React Query caches based on event types received.
