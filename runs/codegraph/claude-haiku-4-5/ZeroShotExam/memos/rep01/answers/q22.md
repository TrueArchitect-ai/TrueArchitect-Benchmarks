When a memo is created, user webhooks are notified through the following:

- **Dispatcher function and file**: `DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go:15`, which calls the internal dispatcher `dispatchMemoRelatedWebhook` (same file, line 48)
- **Delivery package**: `webhook` (package at `internal/webhook/webhook.go`)
- **Request-signing mechanism**: HMAC-SHA256 using the `Post` function in `internal/webhook/webhook.go:120`, which signs requests with:
  - A message ID (`msg_` + UUID)
  - A Unix timestamp
  - HMAC-SHA256 signature of the combined message ID, timestamp, and request body
  - Headers set: `webhook-id`, `webhook-timestamp`, and `webhook-signature` (format: `v1,<base64-encoded-signature>`)

The signing secret supports Standard Webhooks format (`whsec_` prefix with base64-decoded key) or raw string secrets, handled by `resolveSigningKey` function (line 97).
