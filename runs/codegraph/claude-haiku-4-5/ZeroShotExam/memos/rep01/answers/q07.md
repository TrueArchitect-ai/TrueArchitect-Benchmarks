The ConnectRPC service clients are created in the frontend source file **`web/src/connect.ts`**. 

This file uses the `createClient` function from `@connectrpc/connect` to instantiate service clients for various services including:
- `authServiceClient` (line 193)
- `userServiceClient` (line 194)
- `memoServiceClient` (line 197)
- `aiServiceClient` (line 199)
- And several other service clients

The clients are created with a transport configured with authentication interceptors and credentials handling.
