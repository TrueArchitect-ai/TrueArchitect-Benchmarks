The frontend module containing the memo CRUD mutations/queries is **`web/src/hooks/useMemoQueries.ts`**, and it uses the generated service client **`memoServiceClient`** (imported from `@/connect`).

The file contains:
- **Create**: `useCreateMemo()` → calls `memoServiceClient.createMemo()`
- **Read**: `useMemos()`, `useInfiniteMemos()`, `useMemo()` → call `memoServiceClient.listMemos()`, `memoServiceClient.getMemo()`
- **Update**: `useUpdateMemo()` → calls `memoServiceClient.updateMemo()`
- **Delete**: `useDeleteMemo()` → calls `memoServiceClient.deleteMemo()`

The `memoServiceClient` is a generated service client from the protobuf definitions (referenced in `web/src/types/proto/api/v1/memo_service_pb.ts`).
