All of them converge for delivery through:
1. **`dispatchMemoRelatedWebhook`** (server/router/api/v1/memo_service_webhooks.go:48) — the internal function that handles the first three events
2. **`webhook.PostAsync`** (internal/webhook/webhook.go:184) — the final delivery function where all payloads are enqueued for asynchronous dispatch

The `PostAsync` function enqueues requests into an `asyncPostQueue` channel (line 39), which is consumed by 4 worker goroutines initialized in the `init()` function (lines 42-55) that call `Post()` for actual HTTP delivery.
