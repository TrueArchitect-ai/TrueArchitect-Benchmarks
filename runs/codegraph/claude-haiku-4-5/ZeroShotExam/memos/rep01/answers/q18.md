The three implementations of the database driver interface are:

1. **store/db/sqlite/sqlite.go** — SQLite implementation
2. **store/db/mysql/mysql.go** — MySQL implementation
3. **store/db/postgres/postgres.go** — PostgreSQL implementation

The factory function that selects between them at startup is:

**NewDBDriver** — **store/db/db.go**

This function (at line 14 in store/db/db.go) uses a switch statement on `profile.Driver` to call the appropriate `NewDB` function for sqlite, mysql, or postgres based on the configuration.
