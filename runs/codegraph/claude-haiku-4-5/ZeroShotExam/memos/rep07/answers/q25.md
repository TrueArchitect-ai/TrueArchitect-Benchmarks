**CEL (Common Expression Language)**; **`internal/filter/engine.go`**

The filter parsing engine uses CEL (via the `google/cel-go` library) to compile filter expressions into an executable program (`Program` struct). During compilation, the CEL-parsed expression tree is converted into a dialect-agnostic `Condition` object via `buildCondition()`, then rendered into SQL for the target dialect (SQLite, PostgreSQL, or MySQL) via `program.Render(opts)`, which dispatches to dialect-specific SQL generators in `internal/filter/render.go` that handle case-insensitivity, array operations, and placeholder formatting for each database's syntax.
