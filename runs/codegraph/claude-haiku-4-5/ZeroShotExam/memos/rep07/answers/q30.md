**Convergence for delivery:**

All webhook dispatches converge at two functions in `internal/webhook/webhook.go`:

1. **dispatchMemoRelatedWebhook** (server/router/api/v1/memo_service_webhooks.go:48) — the internal dispatch handler that calls `webhook.PostAsync()` for the first three events
2. **webhook.PostAsync** (internal/webhook/webhook.go:184) — the unified delivery function that enqueues webhooks to `asyncPostQueue` for asynchronous dispatch
3. **webhook.Post** (internal/webhook/webhook.go:120) — the actual HTTP delivery function that sends the webhook request with optional HMAC-SHA256 signing

The async queue has 4 worker goroutines (initialized in internal/webhook/webhook.go:43-54) that continuously consume from `asyncPostQueue` and call `Post()` for actual delivery. For the comment webhook, it directly calls `webhook.PostAsync()` without going through `dispatchMemoRelatedWebhook`.
