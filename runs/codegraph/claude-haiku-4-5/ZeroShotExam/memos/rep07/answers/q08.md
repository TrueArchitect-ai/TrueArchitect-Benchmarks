**Driver** — `store/driver.go:10`

The Go interface that all database backends implement is named `Driver`. It is defined at line 10 in `store/driver.go`. The interface specifies all methods that store database drivers must implement, including `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, and various CRUD operations for different model types (Attachment, Memo, MemoRelation, InstanceSetting, User, etc.).
