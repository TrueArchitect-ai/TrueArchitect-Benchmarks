**Driver** — `store/driver.go`

The `Driver` interface is defined at line 10 in `store/driver.go` and contains all methods that store database drivers should implement. All database backends (SQLite, MySQL, PostgreSQL) implement this interface, as evidenced by the `DB` structs in `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go` that each implement the `store.Driver` interface.
