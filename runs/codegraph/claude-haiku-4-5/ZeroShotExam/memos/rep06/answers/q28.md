The server actually starts ONE background worker:

**S3 presign runner** — triggered by time.Ticker every 12 hours (server/server.go:153-174, server/runner/s3presign/runner.go:27)

**Unused scheduling infrastructure:**

The `internal/scheduler/scheduler.go` package provides a general-purpose cron-based job scheduler with support for:
- Job registration via `Register()`
- Arbitrary cron expressions (5 or 6-field format with timezone support)
- Middleware support
- Graceful start/stop

However, this scheduler infrastructure is **NOT used by the server**. The server does not instantiate a Scheduler, register any jobs, or call Start(). Instead, the server implements background runners directly with hardcoded timing (the s3presign runner uses a simple 12-hour ticker). The scheduler package exists in the codebase but remains unused for server-side background work.
