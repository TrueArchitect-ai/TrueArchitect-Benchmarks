The memo lifecycle events that dispatch webhooks are:

**Dispatch Functions and Their Events:**
- memos.memo.created: DispatchMemoCreatedWebhook
- memos.memo.updated: DispatchMemoUpdatedWebhook
- memos.memo.deleted: DispatchMemoDeletedWebhook
- memos.memo.comment.created: DispatchMemoCommentCreatedWebhook

**Convergence for Delivery:**
All four dispatch functions converge at `webhook.PostAsync()` (internal/webhook/webhook.go:184) for asynchronous delivery.

The delivery mechanism in `webhook.PostAsync()` enqueues the `WebhookRequestPayload` to an `asyncPostQueue` channel. At initialization, 4 goroutines are spawned (internal/webhook/webhook.go:42-55) that consume from this queue and call `webhook.Post()` (internal/webhook/webhook.go:120) for actual HTTP delivery, which:
- Constructs an HTTP POST request with the webhook payload as JSON
- Signs it with HMAC-SHA256 if a signing secret is configured
- Sends the request to the webhook URL via a safe HTTP client that blocks SSRF attacks
- Validates the response

The delivery function path: `PostAsync → asyncPostQueue → goroutine workers → Post → safeClient.Do()`
