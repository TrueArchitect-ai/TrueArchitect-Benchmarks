**Mechanism:** Embedded filesystem with middleware static serving and SPA fallback; **Path:** `server/router/frontend/frontend.go`

The compiled React frontend is served in production using Go's `embed` directive. At line 20-21 of `server/router/frontend/frontend.go`, the `dist/*` directory (containing the compiled React build) is embedded as `embeddedFiles`. The `Serve` method (line 41) then:

1. Extracts the embedded filesystem via `getFileSystem("dist")` (line 42)
2. Registers Echo middleware `middleware.StaticWithConfig` (line 54) to serve static assets directly from the embedded filesystem
3. Adds a SPA fallback middleware (line 59, `spaFallbackMiddleware`) that serves `index.html` for routes that don't match static files, enabling client-side routing

This setup allows the production binary to contain and serve the entire compiled frontend without requiring separate file distribution.
