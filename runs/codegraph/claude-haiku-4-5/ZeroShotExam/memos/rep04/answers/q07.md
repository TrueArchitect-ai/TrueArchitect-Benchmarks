The ConnectRPC service clients are created in the frontend source file **`web/src/connect.ts`**.

In this file, the service clients (including `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, etc.) are created using the `createClient` function from `@connectrpc/connect` (lines 192-203). The clients are initialized with the transport configuration that includes authentication interceptors and are then exported for use throughout the frontend application.
