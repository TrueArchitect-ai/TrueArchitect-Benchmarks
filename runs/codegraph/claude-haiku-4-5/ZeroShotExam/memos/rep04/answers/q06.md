**memo_relation**

The database table that stores links between one memo and another related memo is `memo_relation`. This table contains:
- `memo_id`: the ID of the memo
- `related_memo_id`: the ID of the related memo
- `type`: the type of relation (e.g., "REFERENCE", "COMMENT")

This is defined in the database migration file at `/bench/home/work/store/migration/sqlite/0.13/00__memo_relation.sql` and is also visible in the schema files for MySQL and PostgreSQL.
