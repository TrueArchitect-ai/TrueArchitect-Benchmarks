**Driver — store/driver.go**

The Go interface that all database backends implement is named `Driver` and is defined at `store/driver.go:10-86`. All database backend implementations (SQLite, MySQL, PostgreSQL) in the `store/db/` subdirectories implement this interface, as evidenced by their `DB` struct types that implement all the required methods like `GetDB()`, `Close()`, `IsInitialized()`, and `GetDatabaseSize()`.
