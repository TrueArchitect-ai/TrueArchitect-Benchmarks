Perfect! I found the answer. According to the code in `store/migrator.go`, the file path is constructed as:
- `getMigrationBasePath()` returns `"migration/%s/"` where `%s` is the driver (e.g., "sqlite")
- `LatestSchemaFileName` is `"LATEST.sql"`

So the complete path for SQLite would be `migration/sqlite/LATEST.sql`.
