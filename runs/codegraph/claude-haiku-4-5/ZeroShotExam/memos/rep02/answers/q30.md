The memo lifecycle events that dispatch webhooks and their dispatch function names are:

**Memo Lifecycle Events:**
- `memos.memo.created`: DispatchMemoCreatedWebhook
- `memos.memo.updated`: DispatchMemoUpdatedWebhook
- `memos.memo.deleted`: DispatchMemoDeletedWebhook
- `memos.memo.comment.created`: DispatchMemoCommentCreatedWebhook

**Convergence Point:**
All webhook dispatches converge at `webhook.PostAsync()` in `internal/webhook/webhook.go:184`. This function enqueues payloads to an `asyncPostQueue` channel (128-item bounded queue), which is processed by 4 goroutines initialized at package init time. Each goroutine calls `webhook.Post()` to execute the actual HTTP delivery.

The delivery path is:
- Event dispatch functions → `dispatchMemoRelatedWebhook` (or direct call for comments) → `webhook.PostAsync()` → `asyncPostQueue` → `webhook.Post()` (HTTP delivery)

**File locations:**
- Dispatch functions: `server/router/api/v1/memo_service_webhooks.go:15-46`
- Convergence point: `internal/webhook/webhook.go:184` (PostAsync)
- Final delivery: `internal/webhook/webhook.go:120` (Post)
