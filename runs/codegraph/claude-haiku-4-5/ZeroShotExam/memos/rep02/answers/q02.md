q02. SQLite, MySQL, Postgres

This project ships migrations for three SQL dialects, each with its own migration directory (`store/migration/sqlite/`, `store/migration/mysql/`, `store/migration/postgres/`). This is confirmed by the dialect constants defined in `internal/filter/schema.go:14-16` (DialectSQLite, DialectMySQL, DialectPostgres) and the migration loader in `store/migrator.go:255` which constructs paths based on the configured driver.
