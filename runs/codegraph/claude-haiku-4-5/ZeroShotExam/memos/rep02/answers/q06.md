The database table that stores links between one memo and another related memo is **memo_relation**.

This table stores the relationship between two memos with the following schema (from `store/migration/sqlite/0.13/00__memo_relation.sql`):
- `memo_id`: The ID of the first memo
- `related_memo_id`: The ID of the related memo
- `type`: The type of relation (either "REFERENCE" or "COMMENT" as defined in `store/memo_relation.go`)
