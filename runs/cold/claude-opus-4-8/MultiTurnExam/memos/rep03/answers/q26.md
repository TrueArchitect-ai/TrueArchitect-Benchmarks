**memo, memo_relation, attachment**

`Store.DeleteMemo` (`store/memo.go:140`) explicitly deletes `memo_relation` rows (both source `MemoID` and target `RelatedMemoID`) and `attachment` rows (via `DeleteAttachment`, `store/db/sqlite/attachment.go:211` — deletes only from `attachment`, plus filesystem storage), then deletes the `memo` row itself (`store/db/sqlite/memo.go:237`). The API handler additionally recurses into comment memos (`server/router/api/v1/memo_service.go:573-577`), but those touch the same three tables. Reactions are listed for the webhook payload but are **not** deleted.
