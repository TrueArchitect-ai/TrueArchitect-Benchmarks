**Engine:** Google CEL (Common Expression Language, via `github.com/google/cel-go`) — `internal/filter/` (parsing/compilation in `internal/filter/engine.go`, `parser.go`).

**Mechanism:** The CEL filter string is compiled into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`), then rendered to a parameterized SQL `WHERE` clause per dialect via `render.go` (a `DialectName` in `RenderOptions` selects dialect-specific column qualification/placeholder syntax for sqlite/postgres/mysql).
