**Interceptor path:** `web/src/connect.ts` — the Connect auth interceptor that attaches `Authorization: Bearer <token>` and reactively refreshes on 401 (helper token state in `web/src/auth-state.ts`).

**Token kinds it manages:** short-lived **JWT access tokens** (~15 min, sent in the `Authorization` header) and **refresh tokens** (sent via credentialed cookie, `credentials: "include"`, used by `refreshToken` to mint new access tokens). The backend also supports **Personal Access Tokens (PAT)** for programmatic access.

**Backend validating package:** `server/auth` (e.g. `authenticator.go` / `token.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`).
