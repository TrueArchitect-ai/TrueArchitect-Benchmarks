**memo, memo_relation, attachment**

When `DeleteMemo` runs, `Store.DeleteMemo` (store/memo.go:140) explicitly deletes from `memo_relation` (both source and target links) and `attachment` (linked attachments), then deletes the row from `memo` (store/db/sqlite/memo.go:237). The API handler also recursively deletes comment memos, but each goes through the same path, so the same three tables are affected. Reactions are only *listed* (for the webhook payload) — there is no explicit reaction-row deletion in this path (server/router/api/v1/memo_service.go:518-581).
