`memo`, `memo_relation`, `attachment`

When `DeleteMemo` runs:
- `memo` — the memo row itself, plus any comment memos are deleted (`server/router/api/v1/memo_service.go:573-580`; `store/memo.go:158`)
- `memo_relation` — rows where the memo is source or target are deleted (`store/memo.go:142-146`)
- `attachment` — attachments linked to the memo are deleted (`store/memo.go:148-157`, via `Store.DeleteAttachment` in `store/attachment.go:132`; this also removes non-DB file storage)

Note: reactions are listed in the API handler (`memo_service.go:545`) only to build the webhook payload — there is **no** explicit code deleting `reaction` rows, so the `reaction` table is not affected by this path.
