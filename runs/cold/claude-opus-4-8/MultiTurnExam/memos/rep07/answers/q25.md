**Engine:** Google CEL (Common Expression Language), via `github.com/google/cel-go` — wrapped by the project's own `filter` package in `internal/filter/` (`engine.go`, `parser.go`, `render.go`, `schema.go`, `ir.go`).

**Mechanism:** The `Engine` compiles the CEL filter string into a dialect-agnostic condition tree / IR (`Engine.Compile` in `internal/filter/engine.go`, using `cel.NewEnv`), which is then rendered into a dialect-specific SQL `WHERE` fragment plus bound args by `Program.Render` / `AppendConditions` using the target `DialectName` (`sqlite`/`mysql`/`postgres`, defined in `internal/filter/schema.go`) whose per-dialect SQL templates come from the schema's `Expressions` map (`internal/filter/render.go`, `internal/filter/helpers.go`).
