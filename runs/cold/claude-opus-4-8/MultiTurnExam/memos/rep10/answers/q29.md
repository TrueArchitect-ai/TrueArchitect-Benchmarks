**Interceptor path:** `web/src/connect.ts` — `authInterceptor` (line 156), registered on the transport (line 188); token state lives in `web/src/auth-state.ts` and refresh logic (`refreshAccessToken`, `refreshTransport` with `credentials: "include"`) is in the same `connect.ts`.

**Token kinds it manages:**
- **Access token** — a JWT sent in the `Authorization: Bearer <token>` header (set at `connect.ts:97-99`), held in `auth-state`.
- **Refresh token** — an HTTP-only cookie (sent via `credentials: "include"`), exchanged through the `AuthService.RefreshToken` RPC for a new access token (`connect.ts:75-82`) on 401 / expiry.

**Backend validation package:** `server/auth/` — `Authenticator` validates the JWT access token, with `ExtractBearerToken` / `ExtractRefreshTokenFromCookie` in `server/auth/extract.go` and token logic in `server/auth/token.go`.
