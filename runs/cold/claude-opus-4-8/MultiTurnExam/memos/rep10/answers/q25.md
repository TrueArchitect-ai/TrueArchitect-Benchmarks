**Engine:** Google CEL (`cel-go`), wrapped by the project's own filter package at `internal/filter/` (parser at `internal/filter/parser.go`, engine at `internal/filter/engine.go` using `cel.NewEnv` / `cel.AstToParsedExpr`).

**Mechanism:** The CEL filter string is compiled to an AST, lowered into a dialect-independent intermediate condition tree (`internal/filter/ir.go`), then `internal/filter/render.go` renders that tree to a parameterized SQL `WHERE` `Statement` for the requested `RenderOptions.Dialect` (`DialectSQLite` / `DialectPostgres` / `DialectMySQL`), emitting dialect-specific SQL (e.g. `strftime('%Y', …)` for SQLite vs `EXTRACT(YEAR FROM to_timestamp(…))` for Postgres).
