In the store layer's `Store.DeleteMemo` (`store/memo.go:140-158`), before deleting the memo row it deletes:

- **memo_relation records** — where the memo is the source (`MemoID`) and where it is the target (`RelatedMemoID`)
- **attachments** — all attachments linked to the memo (via `DeleteAttachment`)

Then it calls `s.driver.DeleteMemo` to remove the memo row itself.

(Note: at the API layer, `APIV1Service.DeleteMemo` in `server/router/api/v1/memo_service.go:567-577` additionally deletes comment memos first, each of which goes through the same store-layer cleanup.)
