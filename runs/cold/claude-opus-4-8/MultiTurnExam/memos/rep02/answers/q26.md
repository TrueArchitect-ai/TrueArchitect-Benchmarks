**memo, memo_relation, attachment**

`Store.DeleteMemo` (`store/memo.go:140`) explicitly deletes, in order:
- **memo_relation** — rows where the memo is source (`MemoID`) or target (`RelatedMemoID`) (lines 142, 145)
- **attachment** — each attachment linked to the memo via `DeleteAttachment` (lines 149-157; `store/attachment.go:132` also removes the backing file storage, not a table)
- **memo** — the memo row itself (line 158)

(The API handler at `server/router/api/v1/memo_service.go:518` additionally recurses into comment memos, but that still touches only these same three tables. Notably `reaction` rows are listed for the webhook payload but are **not** deleted by this path.)
