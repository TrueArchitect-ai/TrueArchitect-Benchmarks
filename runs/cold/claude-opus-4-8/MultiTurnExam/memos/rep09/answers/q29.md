**Interceptor path:** `web/src/connect.ts` — the ConnectRPC auth `Interceptor` sets `Authorization: Bearer <token>` (line 99) and handles proactive/reactive token refresh; supporting token state lives in `web/src/auth-state.ts`.

**Token kinds:** a short-lived **access token** (a JWT sent as `Bearer` in the `Authorization` header, held in memory / storage) and a **refresh token** used via the `AuthService.RefreshToken` RPC (`doRefreshAccessToken`, connect.ts:74–82) to rotate/obtain new access tokens.

**Backend validating package:** `server/auth` — `auth.Authenticator` (`server/auth/authenticator.go`, with token logic in `server/auth/token.go`), invoked by the Connect `NewAuthInterceptor` (`server/router/api/v1/connect_interceptors.go:213`).
