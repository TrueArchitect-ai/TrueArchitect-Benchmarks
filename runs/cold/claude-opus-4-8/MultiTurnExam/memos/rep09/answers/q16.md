Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go`) removes:

- **memo_relation records** where the memo is the source (`MemoID`)
- **memo_relation records** where the memo is the target (`RelatedMemoID`)
- **attachments linked to the memo** (each attachment found via `ListAttachments` with the memo's ID is deleted)

Only after these does it call `s.driver.DeleteMemo(ctx, delete)` to delete the memo row.
