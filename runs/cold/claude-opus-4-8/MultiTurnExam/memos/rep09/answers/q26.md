`DeleteMemo` (`store/memo.go`) explicitly touches these tables:

- **memo_relation** — deleted where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
- **attachment** — each attachment linked to the memo is deleted (`ListAttachments` → `DeleteAttachment`; note `DeleteAttachment` also removes the underlying storage/blob, but that's not a DB table)
- **memo** — the memo row itself, deleted last

No further tables are cascaded in code (`DeleteAttachment` in `store/attachment.go` deletes only the attachment row plus its storage), and DB-level foreign-key cascades were removed by earlier migrations.
