**Engine:** CEL (Google's Common Expression Language, via `cel-go`) — `internal/filter/` (engine in `internal/filter/engine.go`, SQL rendering in `internal/filter/render.go`).

**Mechanism:** The `Engine` compiles the CEL filter string into a dialect-agnostic condition/IR tree (`engine.go`, `ir.go`), then `Render`/`CompileToStatement` emits a dialect-specific SQL fragment + args by switching on `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) in `internal/filter/render.go`, which the store's memo query splices into the WHERE clause.
