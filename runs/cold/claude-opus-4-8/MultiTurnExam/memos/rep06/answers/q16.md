In `store/memo.go`, `Store.DeleteMemo` deletes the following before the memo row itself:

- **memo_relation records where the memo is the source** (`DeleteMemoRelation{MemoID}`)
- **memo_relation records where the memo is the target/related memo** (`DeleteMemoRelation{RelatedMemoID}`)
- **attachments linked to the memo** (each `Attachment` via `DeleteAttachment`)

Then it calls `driver.DeleteMemo` to delete the memo row (`store/memo.go`, `Store.DeleteMemo`).

(Note: reactions and comment memos are handled one level up in the API handler `server/router/api/v1/memo_service.go:518`, not inside the store's `DeleteMemo`.)
