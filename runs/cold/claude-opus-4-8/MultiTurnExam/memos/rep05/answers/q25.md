**Engine:** Google CEL (Common Expression Language) via `github.com/google/cel-go`, wrapped by the project's own filter package at `internal/filter/` (`engine.go`, plus `schema.go`, `helpers.go`).

**Mechanism:** The filter string is compiled by `filter.Engine` (`internal/filter/engine.go`) — CEL parses/compiles it into an AST/`Program`, and `CompileToStatement`/`Render` walks that expression tree with a `RenderOptions{Dialect: ...}` (e.g. `DialectSQLite`, `DialectPostgres`, `DialectMySQL`) to emit a parameterized SQL `WHERE` fragment plus args, which each dialect driver appends to its query via `filter.AppendConditions` (`internal/filter/helpers.go:9`) — e.g. `store/db/sqlite/memo.go:61` passes `filter.DialectSQLite`.
