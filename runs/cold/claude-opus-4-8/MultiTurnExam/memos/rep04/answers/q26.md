**memo, memo_relation, attachment**

When `DeleteMemo` runs, the explicit cascade code (`store/memo.go:140-158`) deletes:
- **memo_relation** rows where the memo is source or target (lines 142, 145)
- **attachment** rows linked to the memo (lines 149-157; each `DeleteAttachment` also removes the underlying storage blob, but that's not a table)
- **memo** row(s) itself — including comment memos, which are also `memo` rows deleted recursively via the handler (server/router/api/v1/memo_service.go:573-580)

Note: `reaction` rows are listed (for the webhook payload) but **not** deleted by this path — no explicit reaction cleanup exists in the DeleteMemo code.
