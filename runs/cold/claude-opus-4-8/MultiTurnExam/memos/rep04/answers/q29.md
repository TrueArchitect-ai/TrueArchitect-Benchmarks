**Interceptor path:** `web/src/connect.ts` (`authInterceptor`, line 156) — it attaches `Authorization: Bearer <accessToken>` on each request (helper `setAuthorizationHeader`, line 97) and reactively refreshes on 401 (token state lives in `web/src/auth-state.ts`).

**Token kinds:** a short-lived **access token** (JWT, kept client-side and sent as a Bearer header) and a **refresh token** (managed via the `RefreshToken` RPC with `credentials: "include"`, i.e. an HTTP cookie the browser sends automatically). The backend additionally supports **personal access tokens** for non-browser API clients.

**Backend package:** `server/auth` — JWTs are generated/validated here using `golang-jwt/jwt/v5` (`server/auth/token.go`, e.g. `GenerateAccessToken` at line 96; validation in `server/auth/authenticator.go`).
