**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`). It calls the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:356`), then writes the results into the memo's stored `Payload`: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`server/runner/memopayload/runner.go:85-86`). The actual extraction walks the goldmark AST in `service.ExtractAll`.

**Triggers (operations that recompute it):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (always, before insert).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the update mask includes `"content"` (gated by `contentUpdated`/the `path == "content"` branch at `:436-446`); non-content updates don't recompute.
- Bulk backfill via `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:52` (batch rebuild of all memos). Note this `Runner` isn't wired into startup in production, so in practice recomputation happens on memo create and content-updating edits.

**What the computation extracts** (`internal/markdown/markdown.go:356-...`, into `MemoPayload` / `MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
- `Tags` — the list of `#tags` found in content (deduplicated, case preserved).
- `Property.Title` — text of the document's first block if it's an H1 heading.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains a code block/fence/inline code span.
- `Property.HasTaskList` — content contains task checkboxes.
- `Property.HasIncompleteTasks` — at least one unchecked task checkbox.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property`.)
