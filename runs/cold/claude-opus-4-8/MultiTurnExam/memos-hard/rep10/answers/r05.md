**Premise correction:** There is no GraphQL API in this repository — no schema, no GraphQL server, no resolver code. A search for `graphql`/`gqlgen` returns zero matches in Go code, and `go.mod` has no GraphQL dependency. So there is no GraphQL schema file to point to.

**Actual API surface:** The public API is defined as **Protocol Buffers services** served over **gRPC / Connect (with an HTTP/REST + gRPC-gateway mapping)**:
- The schema/source of truth is the `.proto` service definitions in `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, plus `common.proto` (configured via `proto/buf.yaml` / `proto/buf.gen.yaml`).
- Generated Go code lives under `proto/gen/api/v1/` (including `*.pb.go`, gRPC-gateway `*.pb.gw.go`, and Connect `apiv1connect/*.connect.go`).
- An OpenAPI document is embedded via `proto/openapi_embed.go`.
- The services are implemented and registered in `server/router/api/v1/` (`APIV1Service`, wired in `v1.go` / `connect_services.go`) and mounted by the server in `server/server.go`.

Answer: **No GraphQL schema exists; the public API is defined by Protobuf service definitions in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1/`), served over gRPC/Connect + REST gateway and implemented in `server/router/api/v1/`.**
