**Premise correction:** There is no GraphQL schema in this repository. Searches for `graphql`/`gqlgen` in the Go code and for any `*.graphql`/`*.gql` schema files return zero results. The public API is not GraphQL.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **gRPC / Connect + gRPC-Gateway (REST/JSON)**. The schema lives in the `.proto` service definitions under `proto/api/v1/`, e.g.:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`

These compile to generated Go in `proto/gen/api/v1/` (including Connect handlers under `proto/gen/api/v1/apiv1connect/` and gRPC-Gateway `*.pb.gw.go`). The server wires them up in `server/router/api/v1/` — the Connect service handler and gRPC-Gateway mux are registered in `server/router/api/v1/v1.go` (see the gateway/interceptor setup around lines 67-97). So the "schema" you'd be looking for is the protobuf definitions in `proto/api/v1/`, not a GraphQL SDL.
