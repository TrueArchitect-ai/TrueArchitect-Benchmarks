**Abstraction package**: `internal/idp` (`github.com/usememos/memos/internal/idp`) — defines the provider abstraction, e.g. the shared `IdentityProviderUserInfo` type in `internal/idp/idp.go`.

**Implementation package**: `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`) — the concrete OAuth2 protocol implementation in `internal/idp/oauth2/oauth2.go` (its `IdentityProvider` type wraps `storepb.OAuth2Config` and uses `golang.org/x/oauth2`). It's the only concrete provider that ships (`internal/idp/oauth2` is the sole subpackage of `internal/idp`).
