**Delivery function**: `Post` in `internal/webhook/webhook.go` — the outbound HTTP request actually executes at `internal/webhook/webhook.go:152` (`safeClient.Do(req)`). **Protection mechanism**: SSRF guarding at dial time via `safeDialContext` → `isReservedIP`. `safeClient` is configured with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`, `59-77`). `safeDialContext` resolves the target hostname and rejects the connection if any resolved IP is in a reserved/private range (`isReservedIP`), which also defeats DNS-rebinding since the check happens at connect time. `isReservedIP` is defined at `internal/webhook/validate.go:44`, and the same check is applied up front by `ValidateURL` at `internal/webhook/validate.go:62-88` when a webhook URL is configured.
