**Computation site — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates the parse to `(*markdown.service).ExtractAll` (`internal/markdown/markdown.go:356`); triggers — memo create and memo content-update (plus a bulk backfill runner); extracted — tags + a derived `Property` struct (title, has_link, has_code, has_task_list, has_incomplete_tasks).**

Details:

- **Where computed:** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) calls `markdownService.ExtractAll([]byte(memo.Content))` and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The actual extraction is a single goldmark AST walk in `ExtractAll` (`internal/markdown/markdown.go:356`). This is server-derived from content, not user-supplied.

- **Which operations trigger recomputation:**
  1. `CreateMemo` — `server/router/api/v1/memo_service.go:70`, computed at `memo_service.go:108` (every new memo).
  2. `UpdateMemo` — `server/router/api/v1/memo_service.go:401`, computed at `memo_service.go:447`, but only inside the `content` field-mask branch (`memo.Content = request.Memo.Content` at `:446`), i.e. only when the content actually changes — visibility/pinned/other updates don't recompute it.
  3. Bulk backfill: `memopayload.Runner.RunOnce` loops all memos calling `RebuildMemoPayload` (`server/runner/memopayload/runner.go:52`) — a rebuild-all path (note: this `Runner` isn't wired into startup, so it isn't triggered in the default running server; the two API operations above are the live triggers).

- **What the computation extracts** (into `storepb.MemoPayload`, fields defined in `proto/gen/store/memo.pb.go:85`):
  - **Tags** — deduplicated tag names from `#tag` nodes (`markdown.go:376-378`, `Payload.Tags`).
  - **Property.Title** — text of a leading H1 heading, if the first block is one (`markdown.go:383-388`, `memo.pb.go:92`).
  - **Property.HasLink** — any link node present (`markdown.go:392`).
  - **Property.HasCode** — any code block/fenced/inline code (`markdown.go:394`).
  - **Property.HasTaskList** — any task checkbox (`markdown.go:396`).
  - **Property.HasIncompleteTasks** — an unchecked task checkbox exists (`markdown.go:398-399`).

  (`ExtractAll` also gathers `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload.) These derived fields are what power list/preview rendering without re-parsing content.
