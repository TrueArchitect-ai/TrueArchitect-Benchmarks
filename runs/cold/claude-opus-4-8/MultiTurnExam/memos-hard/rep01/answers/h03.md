h03.

**Abstraction package — `internal/idp` (`internal/idp/idp.go`); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`).**

Details:

- The provider abstraction lives in package `idp` at `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that concrete providers return.

- The one concrete protocol implementation that ships is OAuth2, in package `oauth2` at `internal/idp/oauth2/oauth2.go` — its doc comment states "Package oauth2 implements the OAuth2 identity provider integration," and it defines an `IdentityProvider` backed by `storepb.OAuth2Config`, using `golang.org/x/oauth2` to exchange the code and fetch user info, returning an `idp.IdentityProviderUserInfo`. It's the only subpackage under `internal/idp`.
