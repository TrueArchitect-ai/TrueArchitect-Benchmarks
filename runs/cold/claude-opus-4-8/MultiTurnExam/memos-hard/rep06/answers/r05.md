**Premise correction:** There is no GraphQL API in this repository — no GraphQL schema exists to point to. A repo-wide grep for `graphql|gqlgen|.graphql|resolver` finds no GraphQL code (the only `graphql`-adjacent hits are false positives — `LookupHost`/`LookupIPAddr` DNS calls in `internal/webhook/webhook.go:65` and `internal/httpgetter/html_meta.go:23`). There is no `.graphql` schema file, no schema-definition-language file, and no GraphQL server dependency.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC service definitions** under `proto/api/v1/`, exposed at runtime over **Connect (gRPC-compatible) plus a gRPC-Gateway REST/JSON mux**. The service contracts are the `.proto` files:
- `proto/api/v1/auth_service.proto` (`service AuthService`)
- `proto/api/v1/user_service.proto` (`service UserService`)
- `proto/api/v1/memo_service.proto` (`service MemoService`)
- `proto/api/v1/attachment_service.proto` (`service AttachmentService`)
- `proto/api/v1/shortcut_service.proto` (`service ShortcutService`)
- `proto/api/v1/idp_service.proto` (`service IdentityProviderService`)
- `proto/api/v1/instance_service.proto` (`service InstanceService`)
- `proto/api/v1/ai_service.proto` (`service AIService`)
- plus `common.proto`

These compile to generated Go stubs in `proto/gen/api/v1/`, and the handlers are wired up in `server/router/api/v1/v1.go` (Connect interceptors + gRPC-Gateway middleware). So the schema/contract for the public API is the protobuf definitions in `proto/api/v1/`, not a GraphQL schema.
