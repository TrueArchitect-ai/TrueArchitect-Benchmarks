**Abstraction package: `internal/idp` (`internal/idp/idp.go`); Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

The `internal/idp` package defines the shared provider abstraction — the common `IdentityProviderUserInfo` data contract (`internal/idp/idp.go`) that every provider constructor returns. The only concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2/oauth2.go` (its `IdentityProvider` type wraps `storepb.OAuth2Config` and implements `ExchangeToken`/`UserInfo`, with PKCE support). No OIDC or SAML packages exist under `internal/idp/`. The dispatcher at `server/router/api/v1/auth_service_sso.go` switches only on `storepb.IdentityProvider_OAUTH2`, confirming OAuth2 is the sole shipped provider.
