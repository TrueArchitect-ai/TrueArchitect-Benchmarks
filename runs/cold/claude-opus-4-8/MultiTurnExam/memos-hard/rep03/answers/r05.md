**Premise correction:** There is no GraphQL schema in this repository, and the public API is not GraphQL. `go.mod` declares no GraphQL library (no `graphql`, `gqlgen`, etc.), there are no `.graphql`/`.gql` schema files, and no Go source references GraphQL at all.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC services**, exposed over both Connect-RPC and a gRPC-Gateway REST interface. The schema lives in the `.proto` files under `proto/api/v1/`, which declare these services:
- `AuthService` — `proto/api/v1/auth_service.proto`
- `UserService` — `proto/api/v1/user_service.proto`
- `MemoService` — `proto/api/v1/memo_service.proto`
- `AttachmentService` — `proto/api/v1/attachment_service.proto`
- `ShortcutService` — `proto/api/v1/shortcut_service.proto`
- `IdentityProviderService` — `proto/api/v1/idp_service.proto`
- `InstanceService` — `proto/api/v1/instance_service.proto`
- `AIService` — `proto/api/v1/ai_service.proto`
(plus shared types in `proto/api/v1/common.proto`)

These are served in `server/router/api/v1/v1.go`: Connect handlers are registered via `RegisterConnectHandlers` and routed under `/memos.api.v1.*` (`v1.go:141-144`), alongside a gRPC-Gateway REST mux (`runtime.NewServeMux`, `v1.go:96`). Generated Go bindings live under `proto/gen/api/v1/`. So the API surface is proto-defined gRPC/Connect + REST, not GraphQL.
