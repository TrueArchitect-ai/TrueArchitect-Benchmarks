**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates the actual extraction to the markdown service's single-pass `service.ExtractAll` (`internal/markdown/markdown.go:356`). The result is written into the memo's `Payload` — `Payload.Tags` and `Payload.Property` (`server/runner/memopayload/runner.go:85-86`), i.e. the derived metadata on `storepb.MemoPayload` (`proto/gen/store/memo.pb.go:26,28,85`), not user-set fields.

**Triggers (recomputation):**
- **Create memo** — `CreateMemo` calls it on the new content: `server/router/api/v1/memo_service.go:108`.
- **Update memo (content change)** — `UpdateMemo` calls it when the `content` field is updated: `server/router/api/v1/memo_service.go:447` (inside the `content` update branch, guarded by `memo.Content = request.Memo.Content`).
- **Bulk backfill** — `memopayload.Runner.RunOnce` rebuilds the payload for every memo in batches (`server/runner/memopayload/runner.go:27-72`), calling `RebuildMemoPayload` + `UpdateMemo` per memo (note: this Runner is not wired into server startup — see it has no caller — so at runtime the create/update RPC paths are what actually trigger it).

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356+`):
- **`Tags`** — hashtags collected from `#tag` nodes.
- **`Property.Title`** — text of a leading H1 heading, if the document's first block is one.
- **`Property.HasLink`** — true if any link node is present.
- **`Property.HasCode`** — true for any code block / fenced code / inline code span.
- **`Property.HasTaskList`** — true if any task checkbox exists, and **`Property.HasIncompleteTasks`** — true if any checkbox is unchecked.

(Field definitions: `proto/gen/store/memo.pb.go:87-89` for `HasLink`/`HasTaskList`/`HasCode`, plus `Title`/`HasIncompleteTasks` on the same `MemoPayload_Property`. The walk also gathers `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property`.)
