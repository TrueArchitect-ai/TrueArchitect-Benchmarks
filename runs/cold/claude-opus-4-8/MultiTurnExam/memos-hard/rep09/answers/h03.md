**Abstraction package — `internal/idp` (`internal/idp/idp.go`); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`).**

- `internal/idp/idp.go` defines the provider abstraction, notably the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar URL) that all providers return.
- `internal/idp/oauth2/oauth2.go` is the concrete protocol implementation that ships — an OAuth2 identity provider (`IdentityProvider` struct with `NewIdentityProvider`, backed by `golang.org/x/oauth2` and `storepb.OAuth2Config`). It's the only concrete implementation present under `internal/idp/`.
