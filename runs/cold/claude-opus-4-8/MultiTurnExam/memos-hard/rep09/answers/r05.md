**Premise correction:** There is no GraphQL schema in this repository. A repo-wide search finds no `graphql`/`gqlgen` code references, no `.graphql`/`.gql` schema files, and no GraphQL dependency in `go.mod`. So there is no GraphQL schema to locate.

**Actual API surface:** The public API is defined with **Protocol Buffers (gRPC), exposed over Connect and gRPC-Gateway (REST/JSON)**:

- The schema/service definitions are `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. Codegen is driven by `proto/buf.yaml` / `proto/buf.gen.yaml`.
- Generated Go lives in `proto/gen/api/v1/` (message/service stubs, gRPC-Gateway `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`).
- The server wires these up in `server/router/api/v1/` — Connect service handlers (`connect_services.go`, `connect_handler.go`) and interceptors — with the concrete RPC method implementations (e.g. `memo_service.go`, `user_service.go`).
- A machine-readable REST description is published as OpenAPI, embedded via `proto/openapi_embed.go` — this (not GraphQL) is the closest thing to a "schema for the public API."

So the public API is gRPC/Connect + REST generated from protobuf definitions in `proto/api/v1/`, not GraphQL.
