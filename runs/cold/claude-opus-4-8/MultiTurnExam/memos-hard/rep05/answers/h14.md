**computation site — `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates to `(*service).ExtractAll` (`internal/markdown/markdown.go:356`); triggers — memo create and memo content-update; extracted properties — tags plus the boolean/title content flags in `MemoPayload.Property`.**

Details:

- **Where it's computed.** The derived metadata is the memo's `Payload` (`storepb.MemoPayload` — `Tags` and `Property`). `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) runs the content through `markdownService.ExtractAll([]byte(memo.Content))` and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:80-86`). The actual extraction is a single goldmark AST walk in `(*service).ExtractAll` (`internal/markdown/markdown.go:356-422`).

- **Triggers (operations that recompute it).**
  - `CreateMemo` — `server/router/api/v1/memo_service.go:108` (always, on the new content).
  - `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only inside the `"content"` field-mask branch, i.e. when the content actually changes (`memo_service.go:446-451`); updates to visibility/pinned/etc. do not recompute it.
  - It's also recomputed in bulk by the (currently uninstantiated) `memopayload.Runner.RunOnce` batch job over all memos (`server/runner/memopayload/runner.go:52`).

- **What the computation extracts** (into `data`/`Property` during the AST walk, `internal/markdown/markdown.go:376-419`):
  - **Tags** — every `#tag` node, deduplicated preserving case (`:377`, `:418`) → `Payload.Tags`.
  - **`Property.Title`** — text of a leading H1 heading, if the first block is one (`:383-388`).
  - **`Property.HasLink`** — a link node present (`:393-394`).
  - **`Property.HasCode`** — code block / fenced code / inline code span present (`:396-397`).
  - **`Property.HasTaskList`** and **`Property.HasIncompleteTasks`** — a task checkbox present, and whether any is unchecked (`:399-404`).

  (`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only stores `Tags` and `Property`; mentions are used separately for notifications.)
