**abstraction package — `internal/idp` (`internal/idp/idp.go`); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

- The provider abstraction lives in package `idp` at `internal/idp/idp.go`, which defines the `IdentityProviderUserInfo` type (the normalized user-info shape — identifier, display name, email, avatar — that any provider maps into).
- The one concrete protocol implementation that ships is package `oauth2` at `internal/idp/oauth2/oauth2.go`, whose file comment reads "Package oauth2 implements the OAuth2 identity provider integration." Its `IdentityProvider` struct is built from a `storepb.OAuth2Config` (`internal/idp/oauth2/oauth2.go:19-27`). It is the only subpackage under `internal/idp/`.
