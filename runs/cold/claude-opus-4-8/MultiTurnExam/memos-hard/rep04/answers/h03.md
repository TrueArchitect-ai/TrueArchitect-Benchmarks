Third-party (SSO) authentication is built around an identity-provider abstraction with a single concrete protocol implementation.

- **Abstraction package** — `internal/idp` (`internal/idp/idp.go`), which defines the provider-neutral `IdentityProviderUserInfo` type used across implementations.
- **Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), the OAuth2 identity provider integration (`IdentityProvider` backed by `storepb.OAuth2Config`). It is the only concrete protocol implementation that ships.

`internal/idp; internal/idp/oauth2`
