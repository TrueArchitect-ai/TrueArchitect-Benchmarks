The derived metadata is the memo **payload** (`memo.Payload.Tags` and `memo.Payload.Property`), stored in the `payload` column and used for list/preview rendering — computed from the memo's content, not set by the user.

**Computation site** — `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns the results to `memo.Payload.Tags` and `memo.Payload.Property`. The actual extraction logic is in the markdown service: `(*service).ExtractAll` at `internal/markdown/markdown.go:356` (single goldmark AST walk).

**Triggers (operations that recompute it):**
- **Create** — `CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` at `server/router/api/v1/memo_service.go:108`.
- **Update** — `UpdateMemo` recomputes when the content field changes, at `server/router/api/v1/memo_service.go:447`.
- **Bulk backfill** — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) re-runs `RebuildMemoPayload` over all memos in batches (note: this runner isn't wired into production startup — see it's never constructed — so it's an available maintenance path rather than an active runtime trigger).

**Extracted properties** (from `ExtractAll` / `internal/markdown/markdown.go:356-` and mirrored in `ExtractProperties`):
- `Tags` — the list of `#tags` found in the content.
- `Property.Title` — text of a leading H1 heading, if the first block is one.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains code (code block, fenced block, or inline code span).
- `Property.HasTaskList` — content contains a task-list checkbox.
- `Property.HasIncompleteTasks` — at least one task checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` persists only `Tags` and `Property` into the derived payload.)
