**Extracted properties** (populated by `ExtractAll`, `internal/markdown/markdown.go:356-420`, stored into `MemoPayload`):
- `Tags` — the set of `#tag`s in the content, deduplicated with original case preserved.
- `Property.Title` — text of the document's first block if it is an H1 heading.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains a code block/fenced code/code span.
- `Property.HasTaskList` — content contains a task-list checkbox.
- `Property.HasIncompleteTasks` — at least one task checkbox is unchecked.

(`ExtractAll` also collects `Mentions` in the same walk, but `RebuildMemoPayload` only persists `Tags` and `Property` onto the memo.)
