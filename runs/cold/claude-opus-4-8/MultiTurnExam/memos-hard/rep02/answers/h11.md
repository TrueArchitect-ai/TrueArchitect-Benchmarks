**1st: `store.User` (≈6 packages); 2nd: `store.Memo` (≈4 packages)**

The persistent entity types are defined in the `store` package (`store/*.go`): `User`, `Memo`, `Attachment`, `Reaction`, `Inbox`, `UserSetting`, `MemoRelation`, `MemoShare`, `UserIdentity`, `IdentityProvider`, etc. Counting distinct non-test packages *outside* the data layer (`store/…`) that reference each type as `store.<Type>`:

- **`store.User` — 6 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`. (5 if you exclude the `.../v1/test` helper package.)
- **`store.Memo` — 4 packages**: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

Runner-up for reference: `store.Attachment` at 3 packages (`server/router/api/v1`, `server/router/fileserver`, `server/router/rss`).

Method: `grep -rln "store\.<Type>\b"` over `server/ internal/ cmd/` excluding `_test.go`, then reducing matched files to distinct directories (packages). `User` leads, followed by `Memo`.
