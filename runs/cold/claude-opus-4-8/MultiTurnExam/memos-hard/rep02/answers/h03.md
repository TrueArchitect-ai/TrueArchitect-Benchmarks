**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

- The provider abstraction lives in package `idp` at `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type used across identity providers.
- The one concrete protocol implementation that ships is package `oauth2` at `internal/idp/oauth2/oauth2.go` — "Package oauth2 implements the OAuth2 identity provider integration," providing `IdentityProvider` (wrapping `storepb.OAuth2Config`) and `NewIdentityProvider`. It's the only subpackage under `internal/idp/`.
