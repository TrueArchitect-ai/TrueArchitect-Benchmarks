**Abstraction package** — `internal/idp` (`internal/idp/idp.go`), which defines the provider-agnostic `IdentityProviderUserInfo` type used as the common abstraction returned by identity providers.

**Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), the concrete OAuth2 protocol implementation (`IdentityProvider` / `NewIdentityProvider`), which is the only shipped provider implementation.

Format: `internal/idp`; `internal/idp/oauth2`
