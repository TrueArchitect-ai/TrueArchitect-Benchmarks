**Premise correction:** There is no GraphQL schema in this project. A search for `graphql`/`gqlgen` in Go source returns nothing, there are no `.graphql`/`.graphqls` schema files, and there is no GraphQL dependency. The public API is **not** GraphQL.

**Actual API surface:** The API is defined as **Protocol Buffers / gRPC services**, exposed over REST (gRPC-Gateway) and Connect (for browser clients):
- The schema/IDL lives in `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`.
- Generated Go code (protobuf messages, gRPC stubs, gateway REST bindings, and Connect handlers) is under `proto/gen/api/v1/` (e.g. `*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, and the `apiv1connect` package).
- Serving is wired in `server/router/api/v1/v1.go`: `RegisterGateway` sets up the gRPC-Gateway REST mux (`runtime.NewServeMux`, `v1.go:96`) and the Connect handlers (`v1.go:131-141`), using `connectrpc.com/connect` and `grpc-ecosystem/grpc-gateway/v2` (imports at `v1.go:7-8`).

So the correct answer is: the API "schema" is the set of protobuf service definitions in `proto/api/v1/*.proto` (with generated code in `proto/gen/api/v1/`), served via gRPC-Gateway REST + Connect — not GraphQL.
