**DB — store/db/postgres/postgres.go**

The PostgreSQL database driver is implemented by the struct `DB`, defined at `store/db/postgres/postgres.go:16`. It lives in the `postgres` package and implements the `store.Driver` interface: `NewDB(...)` constructs `&DB{...}` and returns it as a `store.Driver`, using `sql.Open("postgres", ...)` with the `github.com/lib/pq` driver. (The SQLite and MySQL backends follow the same pattern, each defining its own `DB` struct under `store/db/sqlite/` and `store/db/mysql/`.)
