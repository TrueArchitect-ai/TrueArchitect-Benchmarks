q02.
mysql, postgres, sqlite

The project ships migrations under `store/migration/`, organized into one subdirectory per dialect: `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/`. Each contains versioned `.sql` migration files plus a `LATEST.sql` full schema. The migrator selects the directory per driver at runtime (`store/migrator.go:255`), and matching DB drivers exist for exactly these three dialects (`store/db/mysql/`, `store/db/postgres/`, `store/db/sqlite/`).
