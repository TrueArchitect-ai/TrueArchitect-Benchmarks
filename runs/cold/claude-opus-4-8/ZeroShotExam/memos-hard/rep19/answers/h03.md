h03. `internal/idp` (`github.com/usememos/memos/internal/idp`); `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`)

The abstraction is defined in `internal/idp/idp.go`, which declares the protocol-agnostic `IdentityProviderUserInfo` struct that every provider normalizes to (the stored config schema lives in `proto/store/idp.proto`). The single concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2/oauth2.go` — its header states "Package oauth2 implements the OAuth2 identity provider integration," and it's wired up in `server/router/api/v1/auth_service_sso.go:121`. No OIDC or SAML implementation is present.
