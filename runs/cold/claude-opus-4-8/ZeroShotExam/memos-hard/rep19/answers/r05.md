**Premise correction:** This repository has **no GraphQL schema at all.** There is zero GraphQL anywhere — no `.graphql`/`.gql` files, no `graphql` dependency, and no `typeDefs`/`buildSchema`/`type Query` references in any Go, TypeScript, or config file. The project is **Memos** (`github.com/usememos/memos`), a self-hosted Go Markdown note-taking application, whose README explicitly advertises "full REST and gRPC APIs" — not GraphQL.

**Actual API surface:** The public API is defined in **Protocol Buffers**, which serve as the single source of truth and are transcoded into gRPC, Connect-RPC, and REST (via grpc-gateway).

- **Schema definitions (source of truth):** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/ai_service.proto`, `proto/api/v1/common.proto`. Codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`.
- **REST contract (auto-generated OpenAPI):** `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- **Generated transport code:** `proto/gen/api/v1/*_grpc.pb.go` (gRPC), `proto/gen/api/v1/*.pb.gw.go` (REST gateway), `proto/gen/api/v1/apiv1connect/*.connect.go` (Connect-RPC).
- **Handler implementations:** `server/router/api/v1/` (e.g. `memo_service.go`, `auth_service.go`), wired up in `server/server.go` (Echo v5).
- **Other public surfaces:** MCP server at `server/router/mcp/`, RSS feed at `server/router/rss/rss.go`.

So if you're looking for where to change the API schema, edit the `.proto` files under `proto/api/v1/` and regenerate — there is no GraphQL SDL to define.
