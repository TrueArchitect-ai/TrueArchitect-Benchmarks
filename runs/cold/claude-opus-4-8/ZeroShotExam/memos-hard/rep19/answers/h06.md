**Feature: outbound webhooks.** The user-configured URL comes from per-user webhook settings (`hook.Url`), stored via the webhook APIs and read back through `s.Store.GetUserWebhooks(...)`.

**RPC handler methods** (all on `APIV1Service`) that transitively trigger an outbound webhook POST:

- **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` → `DispatchMemoCreatedWebhook` (called at line 157)
- **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` → `dispatchMemoUpdatedSideEffects` (line 513) → `DispatchMemoUpdatedWebhook`
- **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` → `DispatchMemoDeletedWebhook` (line 562)
- **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (line 119)
- **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:16` → `dispatchMemoUpdatedSideEffects` (line 48) → `DispatchMemoUpdatedWebhook`
- **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:16` → `dispatchMemoUpdatedSideEffects` (line 48) → `DispatchMemoUpdatedWebhook`

Each `Dispatch*Webhook` method (`server/router/api/v1/memo_service_webhooks.go`) loads the creator's webhooks, sets `payload.URL = hook.Url`, and calls `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; the queue's worker goroutines (`init()`) all invoke `Post`.

**Convergence function — `webhook.Post` at `internal/webhook/webhook.go:120`**, where the request is built and sent via `safeClient.Do(req)` (line 152). Every dispatch path funnels through the shared enqueue `webhook.PostAsync` (line 184) and then into this single `Post` function before the HTTP request actually goes out. (`Post` also guards against SSRF via `safeDialContext`, blocking reserved/private IPs.)
