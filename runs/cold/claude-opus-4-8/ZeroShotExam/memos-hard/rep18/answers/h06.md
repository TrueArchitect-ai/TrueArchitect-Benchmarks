**Handlers** (gRPC RPC methods on `APIV1Service`, all in `server/router/api/v1/`) that can transitively trigger an outbound HTTP POST to a user-configured webhook URL:

4. **`CreateMemoComment`** — `memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)
5. **`SetMemoAttachments`** — `memo_attachment_service.go:16` → `dispatchMemoUpdatedSideEffects` (`memo_attachment_service.go:48`)
6. **`SetMemoRelations`** — `memo_relation_service.go:16` → `dispatchMemoUpdatedSideEffects` (`memo_relation_service.go:48`)

All of these load the memo owner's configured webhooks (`Store.GetUserWebhooks`), set `payload.URL = hook.Url` (the user-configured URL), and enqueue via `webhook.PostAsync` in `server/router/api/v1/memo_service_webhooks.go`.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. Both the synchronous path and the async queue (`PostAsync` → `asyncPostQueue` worker at `internal/webhook/webhook.go:46`) funnel into `Post`, which is the single place that builds and issues the actual `http.NewRequest("POST", ...)` / `safeClient.Do(req)` to the user's URL.
