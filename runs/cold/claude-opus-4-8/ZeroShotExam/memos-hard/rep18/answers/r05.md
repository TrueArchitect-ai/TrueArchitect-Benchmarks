**Premise correction:** There is no GraphQL in this repository. This is the Memos project (Go backend + React frontend), and it uses **no GraphQL** at all — zero `.graphql`/`.gql` files, and no GraphQL dependencies in `go.mod` or `web/package.json`.

**Actual API surface:** The public API is defined with **Protocol Buffers / gRPC**, exposed over REST via grpc-gateway and Connect.

- **Source-of-truth definitions (Protobuf):** `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`. Design notes in `proto/api/v1/README.md` (follows Google AIP guidelines).
- **Codegen config:** `proto/buf.yaml`, `proto/buf.gen.yaml`.
- **Generated artifacts:** Go stubs in `proto/gen/api/...`; TypeScript client types in `web/src/types/proto/api/...`; an auto-generated **OpenAPI** spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).
- **HTTP wiring:** `server/router/api/v1/v1.go` mounts the services using grpc-gateway (`runtime.NewServeMux`) to expose REST/JSON under `/api/v1/...`, plus Connect handlers for browser clients.

Bottom line: the public API is Protobuf-defined under `proto/api/v1/`, served as gRPC + REST + Connect — not GraphQL.
