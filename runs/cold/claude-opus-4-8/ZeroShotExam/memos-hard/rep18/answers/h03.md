**`internal/idp`; `internal/idp/oauth2`**

Users authenticate through third-party identity providers (SSO) in this Memos repo via an "Identity Provider" abstraction:

- **Abstraction package:** `internal/idp` — `/bench/repo/internal/idp/idp.go` defines the shared contract type `IdentityProviderUserInfo` (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every concrete provider returns.
- **Concrete protocol implementation package:** `internal/idp/oauth2` — `/bench/repo/internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration"), exposing `NewIdentityProvider`, `ExchangeToken`, and `UserInfo(...) (*idp.IdentityProviderUserInfo, error)`. OAuth2 is the only concrete implementation that ships (no SAML/OIDC/LDAP subpackage exists).

The two are wired together in `/bench/repo/server/router/api/v1/auth_service_sso.go`, which switches on `storepb.IdentityProvider_OAUTH2` and constructs the oauth2 provider.
