**Mechanism: by explicit Go code.** When a user is deleted, their emoji reactions are removed explicitly in the delete transaction — there is no database-level cascade rule, and it is not left uncleaned.

**Evidence:**

1. **The reaction table has no foreign key / cascade.** In all three DB schemas, `reaction.creator_id` is a plain `INTEGER NOT NULL` with no FK to `user` and no `ON DELETE CASCADE`:
   - `store/migration/postgres/LATEST.sql:91-98`
   - `store/migration/mysql/LATEST.sql:91-98`
   - `store/migration/sqlite/LATEST.sql:92-99`

   So the database will not remove reactions on its own.

2. **Explicit Go deletion in the user-delete transaction.** `deleteUserTargetsTx` calls two reaction-cleanup helpers before deleting the user row:
   - `store/db/postgres/user_delete.go:96` → `deleteReactionsByContentIDsTx` (removes reactions *on* the deleted user's memos)
   - `store/db/postgres/user_delete.go:102` → `deleteReactionsByCreatorTx` (removes reactions the user *authored*)

   The helper bodies (postgres):
   - `deleteReactionsByContentIDsTx` — `DELETE FROM reaction WHERE content_id IN (...)` at `store/db/postgres/user_delete.go:380-388`
   - `deleteReactionsByCreatorTx` — `DELETE FROM reaction WHERE creator_id = $1` at `store/db/postgres/user_delete.go:400-403`

3. **Same logic mirrored across all drivers:**
   - MySQL: calls at `store/db/mysql/user_delete.go:96,102`; helpers at `:417` and `:437`
   - SQLite: calls at `store/db/sqlite/user_delete.go:96,102`; helpers at `:380` and `:400`

4. **Entry points:** `store.DeleteUser` (`store/user.go:171`) delegates to the driver `DeleteUser` (e.g. `store/db/postgres/user_delete.go:29`), which runs everything in one transaction. A test asserting this cleanup exists at `store/test/user_delete_test.go:13` (`TestDeleteUserCleansRelatedData`).

**Note on scope:** the user's *own* emoji reactions are the `deleteReactionsByCreatorTx` (`creator_id = userID`) call — so yes, their emoji reactions are removed by explicit Go code, both the ones they created and any reactions attached to their deleted memos.
