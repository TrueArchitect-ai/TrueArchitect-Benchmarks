**protection mechanism** — `internal/webhook/webhook.go`

Two layers guard against being pointed at internal addresses, both keyed off `isReservedIP` (`internal/webhook/validate.go:44`, which matches an IP against the reserved CIDR list — loopback, RFC-1918 private ranges, 169.254.0.0/16 link-local/cloud-metadata, IPv6 ULA/link-local):

- **Dial-time enforcement (the real SSRF/DNS-rebinding guard)** — `safeDialContext` at `internal/webhook/webhook.go:59`, wired into `safeClient`'s `http.Transport.DialContext` (lines 32–37). On every dial it resolves the host and refuses to connect if any resolved IP `isReservedIP`.
- **Input validation (early rejection)** — `ValidateURL` at `internal/webhook/validate.go:62`, called from the webhook-management API (e.g. `server/router/api/v1/user_service_webhooks.go`). It enforces http/https, resolves the hostname, and rejects reserved IPs with an `InvalidArgument` error.

Note: a global `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) can disable both checks for self-hosted deployments that intentionally target local services.
