**Delivery function** — `Post` at `internal/webhook/webhook.go:120` (the outbound request actually fires at `webhook.go:152` via `resp, err := safeClient.Do(req)`). It's fed by `PostAsync` (`webhook.go:184`), which queues payloads to worker goroutines that call `Post`; callers are the memo webhook handlers in `server/router/api/v1/memo_service_webhooks.go`.

**Protection mechanism** — `safeDialContext` at `internal/webhook/webhook.go:59-77`, installed as the `DialContext` of the shared `safeClient` (`webhook.go:32-37`). On every outbound connection it resolves the host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`), backed by the `reservedCIDRs` block-list (`validate.go:14-23`: loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, IPv6 loopback/ULA/link-local). Because the check runs at dial time after DNS resolution, it also defeats DNS-rebinding. A second up-front layer, `ValidateURL` (`internal/webhook/validate.go:62-83`), applies the same `isReservedIP` check when webhook URLs are registered/updated (called from `server/router/api/v1/user_service_webhooks.go`). Both can be disabled by the package-level `AllowPrivateIPs` flag (`validate.go:41`), which defaults to `false` and is not set anywhere in the repo.
