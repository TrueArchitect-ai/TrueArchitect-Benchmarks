**Premise correction:** There is no GraphQL schema in this repository. Searches for `*.graphql`/`*.gql` files and for GraphQL constructs (`type Query`, `gql\`\``, `ApolloServer`, `makeExecutableSchema`, `buildSchema`, `typeDefs`) return nothing, and there are no GraphQL packages in `go.mod` or `web/package.json`. This is the **Memos** project, and its public API is not GraphQL.

**Actual API surface:** The public API is defined in **Protocol Buffer (`.proto`) files**, then exposed as **gRPC + REST (gRPC-Gateway) + Connect**, with a generated OpenAPI document.

- **Schema source of truth** — `proto/api/v1/*.proto`, one per service:
  - `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `common.proto`
  - `proto/store/*.proto` holds internal storage message types (not part of the public surface).
- **Codegen config** — `proto/buf.gen.yaml` compiles the protos into Go structs, gRPC servers, Connect handlers, a gRPC-Gateway REST layer, an OpenAPI spec, and TS client types.
- **Generated code** — `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`).
- **Generated OpenAPI spec** — `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` (this is the closest thing to a "public API schema" document, but it's derived from the protos).
- **Where it's served/wired up** — `server/router/api/v1/v1.go` (`APIV1Service` implements the generated service interfaces and `RegisterGateway` mounts the REST + Connect handlers on Echo), with per-service implementations alongside it in `server/router/api/v1/`.

Confirming dependencies in `go.mod`: `connectrpc.com/connect`, `github.com/grpc-ecosystem/grpc-gateway/v2`, `google.golang.org/grpc`, `github.com/labstack/echo/v5` — no GraphQL, no tRPC.
