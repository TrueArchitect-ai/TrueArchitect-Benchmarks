**impl — construction — holders**

**Implementation (runtime):** A single concrete type, the `service` struct (`internal/markdown/markdown.go:57-59`), which wraps a `goldmark.Markdown`. It's the sole runtime implementation of the `markdown.Service` interface (`internal/markdown/markdown.go:31-55`) — there is no mock/fake/noop; even tests use the real one. (Internally it uses a non-interface helper `MarkdownRenderer` from `internal/markdown/renderer/markdown_renderer.go:15` to render the AST back to markdown, but that isn't behind the interface.)

**Construction:** Built by the factory `NewService(opts ...Option) Service` (`internal/markdown/markdown.go:85-113`, returns `&service{md: md}` at :110). The single production instance is created in `NewAPIV1Service` at `server/router/api/v1/v1.go:48-51` (`markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())`). Top-level wiring is `server/server.go:76` (`NewAPIV1Service`) and `server/server.go:85`, where that same instance is passed into `rss.NewRSSService`. (Test-only construction: `server/router/rss/rss_test.go:54`, `server/router/fileserver/fileserver_test.go:427`, `server/router/api/v1/test/test_helper.go:44`.)

**Holders (depend on `markdown.Service`):**
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35` (primary consumer; used in `memo_service.go:108/:447`, `memo_mention_helpers.go:32`, `memo_service_webhooks.go:85`).
- `RSSService.MarkdownService` — `server/router/rss/rss.go:45` (uses `RenderHTML` for server-side RSS at `rss.go:339`); shares the API service's instance.
- `memopayload.Runner.MarkdownService` — `server/runner/memopayload/runner.go:16`. Note: at runtime the payload path actually flows through the package-level `RebuildMemoPayload(ctx, memo, markdownService)` (`server/runner/memopayload/runner.go:74`), which takes the interface as a parameter from the memo service; the `Runner` struct itself appears unused in production.

Runtime chain: `server/server.go` → `NewAPIV1Service` builds the one `service` → held by `APIV1Service` → shared into `RSSService` → passed into `RebuildMemoPayload`.

(Separately, the frontend uses its own remark/markdown-it pipeline under `web/src/` — not behind this Go interface.)
