h03.
The provider abstraction is defined in the **`internal/idp`** package (`github.com/usememos/memos/internal/idp`), whose `internal/idp/idp.go` declares the provider-agnostic `IdentityProviderUserInfo` contract that all concrete providers return.

The concrete protocol implementation that ships is the **`internal/idp/oauth2`** package (`github.com/usememos/memos/internal/idp/oauth2`); `internal/idp/oauth2/oauth2.go` is documented as "Package oauth2 implements the OAuth2 identity provider integration" and provides the OAuth2 `IdentityProvider` type (using `storepb.OAuth2Config`). It is the only concrete protocol package under `internal/idp`.

Answer: `github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`
