**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store/` package (usememos/memos, a Go project with no ORM — plain structs + hand-written SQL behind a `Driver` interface). It defines 11 persistent entity types, each mapped to a DB table: `Memo`, `MemoRelation`, `MemoShare`, `User`, `UserSetting`, `UserIdentity`, `Attachment`, `Inbox`, `Reaction`, `IdentityProvider`, `InstanceSetting` (defined in `store/user.go`, `store/memo.go`, etc.).

Counting distinct packages **outside** the `store/` tree (excluding the in-layer DB drivers `store/db/{sqlite,mysql,postgres}` and `store/test`) that reference each type via `store.<Type>`:

- **`User` — 7 packages** (`store/user.go`): `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`Memo` — 6 packages** (`store/memo.go`): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

(Next closest is `Attachment` at ~4 packages.)
