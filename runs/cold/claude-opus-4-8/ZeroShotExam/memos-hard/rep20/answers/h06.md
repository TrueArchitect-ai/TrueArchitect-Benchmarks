**Convergence function — `PostAsync` at `internal/webhook/webhook.go:184`.**

Every path calls `webhook.PostAsync`, which enqueues onto the bounded `asyncPostQueue` channel (line 190). Four worker goroutines started in `init()` (lines 42–55) drain that queue and call `Post` (`internal/webhook/webhook.go:120`), which builds the `http.NewRequest("POST", requestPayload.URL, …)` and executes it via the SSRF-guarded `safeClient.Do(req)` (line 152) — the actual outbound HTTP delivery.

So: convergence-before-delivery = `webhook.PostAsync` (`internal/webhook/webhook.go:184`); the raw delivery one hop later is `webhook.Post` (`internal/webhook/webhook.go:120`).
