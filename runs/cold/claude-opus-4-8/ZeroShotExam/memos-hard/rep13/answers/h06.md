**RPC handler methods that can transitively trigger an outbound HTTP request to a user-configured webhook URL** (the URL comes from `hook.Url`, stored per-user via the `CreateUserWebhook` RPC and read back with `Store.GetUserWebhooks`):

1. `CreateMemo` — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go:67`)
3. `DeleteMemo` — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
5. `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → update webhook
6. `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → update webhook

**Convergence function before delivery:** all of these funnel into `webhook.PostAsync` (which enqueues onto `asyncPostQueue`), and the async workers hand each payload to the single delivery function **`Post`** — `internal/webhook/webhook.go` (line ~120). `Post` is where every path converges to build and send the actual outbound HTTP request via `safeClient.Do` (with the SSRF-guarding `safeDialContext`).

So: **handlers** = `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment` (plus `SetMemoAttachments`, `SetMemoRelations`); **convergence function** = `webhook.Post` — `internal/webhook/webhook.go`.
