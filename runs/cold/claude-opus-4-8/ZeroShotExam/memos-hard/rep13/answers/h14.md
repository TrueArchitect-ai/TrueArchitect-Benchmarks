h14. computation site; triggers; extracted properties

**Computation site.** The derived metadata is rebuilt in `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates to the goldmark-based markdown parser `(*service).ExtractAll` at `internal/markdown/markdown.go:356` (a single AST walk). `RebuildMemoPayload` copies the results onto the memo's `Payload.Tags` and `Payload.Property` (runner.go:85-86). The property-specific extraction logic also exists standalone in `(*service).ExtractProperties` at `internal/markdown/markdown.go:193`.

**Triggers.**
- **CreateMemo** — `server/router/api/v1/memo_service.go:108`.
- **UpdateMemo**, but only when the `content` field is in the update mask — `server/router/api/v1/memo_service.go:446-447`.
- **Backfill/migration runner** — `Runner.RunOnce` re-derives the payload for all memos in batches (`server/runner/memopayload/runner.go:27`, calling `RebuildMemoPayload` at line 52).

**Extracted properties** (from the AST walk in `ExtractAll`, `internal/markdown/markdown.go:371-408`, stored in `MemoPayload`):
- `Tags` — collected from `#tag` nodes, deduplicated preserving case (lines 376-377, 418).
- `Property.Title` — text of the H1 heading if it is the document's first block-level child (lines 384-388).
- `Property.HasLink` — true if any link node is present (line 393-394).
- `Property.HasCode` — true for any code block, fenced code block, or inline code span (lines 396-397).
- `Property.HasTaskList` — true if any task-checkbox is present (lines 399-400).
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (lines 401-404).

(`ExtractAll` also collects `Mentions`, but that field isn't propagated into the memo payload by `RebuildMemoPayload`.)
