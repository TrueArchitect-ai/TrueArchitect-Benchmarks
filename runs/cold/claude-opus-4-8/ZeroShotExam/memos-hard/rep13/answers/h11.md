**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package (`/bench/repo/store/`), where the persistent entity structs are defined — `User` in `store/user.go`, `Memo` in `store/memo.go`, plus `Attachment`, `Inbox`, `MemoRelation`, `MemoShare`, `Reaction`, `IdentityProvider`, `InstanceSetting`, `UserIdentity`, `UserSetting`.

Counting distinct packages **outside** the `store/` tree that reference each type (excluding `store/db/*` and `store/test`, which are part of the data layer itself):

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

All other entity types are referenced from 4 or fewer external packages (e.g. `Attachment` = 4, `Inbox`/`MemoRelation`/`MemoShare` = 3).
