**Premise correction:** This repository (the **Memos** note-taking app) has **no GraphQL schema at all** — there are no `.graphql`/`.gql` files, no GraphQL server libraries (Apollo, graphql-yoga, etc.), and no `graphql` dependency in either `go.mod` or `web/package.json`. The premise that the public API is defined by a GraphQL schema is incorrect.

**Actual API surface:** The public API is defined once in **Protocol Buffers** and exposed over three compatible transports — raw gRPC, Connect-RPC, and gRPC-Gateway (REST/JSON) — with an OpenAPI spec generated for documentation.

- **Source of truth (proto definitions):** `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `common.proto`. Codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`.
- **Generated Go stubs:** `proto/gen/api/v1/` — `*_grpc.pb.go` (gRPC), `*.pb.gw.go` (gRPC-Gateway REST transcoding), `apiv1connect/*.connect.go` (Connect handlers).
- **OpenAPI schema (the closest thing to a "public API schema"):** `proto/gen/openapi.yaml` (OpenAPI 3.0.3, auto-generated), embedded via `proto/openapi_embed.go`.
- **Server wiring:** `server/server.go` mounts gRPC-Gateway at `/api/v1` (lines ~87–89); `server/router/api/v1/connect_handler.go` registers the Connect service handlers; implementations live in `server/router/api/v1/` (`memo_service.go`, `auth_service.go`, etc.).
- **Frontend** consumes it via Connect, not GraphQL: `web/package.json` uses `@connectrpc/connect`, `@connectrpc/connect-web`, `@bufbuild/protobuf`.

Additional public endpoints (also non-GraphQL): RSS feeds under `server/router/rss/` and an MCP server under `server/router/mcp/`. The `README.md` describes this as "full REST and gRPC APIs for integration."
