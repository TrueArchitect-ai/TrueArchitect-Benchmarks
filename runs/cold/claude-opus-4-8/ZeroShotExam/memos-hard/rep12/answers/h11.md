The ranking is stable. `store.User` is referenced from the most external packages, followed by `store.Memo`.

h11.

**1st: User** (~6 packages); **2nd: Memo** (~4 packages)

The data layer is the `store` package (`store/*.go`), which defines the persistent entity types — `User` (`store/user.go`), `Memo` (`store/memo.go`), `Attachment`, `Inbox`, `IdentityProvider`, `UserSetting`, `UserIdentity`, `MemoRelation`, `MemoShare`, `Reaction`, `InstanceSetting`.

Counting distinct packages *outside* the data layer (excluding `store/` and its `store/db/*` drivers) that reference each type as `store.<Type>`:

- **`store.User`** — referenced from ~6 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`.
- **`store.Memo`** — referenced from ~4 packages: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

(Third would be `store.Attachment` at ~3 packages.) The `User`-then-`Memo` ordering holds whether or not the `store/db/*` driver packages are counted.
