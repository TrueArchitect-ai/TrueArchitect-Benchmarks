**`internal/idp`; `internal/idp/oauth2`**

Users authenticate through third-party identity providers via the SSO support in the Memos codebase:

- **Provider abstraction:** `internal/idp` (`github.com/usememos/memos/internal/idp`) — defined in `internal/idp/idp.go`. It provides the shared contract every provider produces (the `IdentityProviderUserInfo` type returned by each provider's `UserInfo(...)` method), with the structural config abstraction declared in `proto/store/idp.proto` (`IdentityProvider`, `IdentityProviderConfig` `oneof`).

- **Concrete protocol implementation:** `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`) — defined in `internal/idp/oauth2/oauth2.go`, whose doc comment reads *"Package oauth2 implements the OAuth2 identity provider integration."* This is the only protocol that ships (no SAML or OIDC implementation exists; the config `oneof` in `proto/store/idp.proto` contains only `OAuth2Config`).

The two are wired together in `server/router/api/v1/auth_service_sso.go`, which calls `oauth2.NewIdentityProvider(...)` and passes the resulting `*idp.IdentityProviderUserInfo` to `resolveSSOUser`.
