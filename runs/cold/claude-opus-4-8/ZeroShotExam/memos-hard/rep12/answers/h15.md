h15.

Memo visibility is enforced at many independent server surfaces. Each re-checks visibility itself; the store just applies whatever `VisibilityList`/CEL-filter the caller supplies. Distinct enforcement sites, by group:

Core / canonical:
- `checkMemoReadAccess` (single-memo read gate; backs `GetMemo`, `UpdateMemo` parent check, `ListMemoComments`) — server/router/api/v1/memo_service.go:39-68
- `ListMemos` visibility filter injection — server/router/api/v1/memo_service.go:218-227
- Store-level SQL translation of `VisibilityList`/`Filters` into an `IN`/WHERE clause — store/db/sqlite/memo.go, store/db/postgres/memo.go, store/db/mysql/memo.go (e.g. store/db/mysql/memo.go:104-110)

Per-surface re-checks:
- `CreateMemoComment` / `ListMemoComments` comment filter — server/router/api/v1/memo_service_comments.go:41, 157-161
- Reactions (`ListMemoReactions` / `UpsertMemoReaction`) — server/router/api/v1/reaction_service.go:30-40, 83
- `ListMemoAttachments` — server/router/api/v1/memo_attachment_service.go:214-222
- Attachment access (`checkAttachmentAccess`, gRPC/Connect) — server/router/api/v1/attachment_service.go:445-453
- `ListMemoRelations` relation filter (+ store counterpart store/db/*/memo_relation.go) — server/router/api/v1/memo_relation_service.go:107-117
- User memo stats scoping — server/router/api/v1/user_service_stats.go:83-91, 218-220

Alternate serving / streaming surfaces:
- File server raw-attachment endpoint (`checkAttachmentPermission`, incl. share-token fallback) — server/router/fileserver/fileserver.go:677-701
- RSS feeds (explore + per-user; restricted to PUBLIC) — server/router/rss/rss.go:90, 141
- Sitemap XML (PUBLIC only) — server/router/frontend/frontend.go:~149-151
- SSE real-time delivery filter (`SSEClient.canReceive`) — server/router/api/v1/sse_hub.go:134-144

Notification/mention gating (visibility governs who is told a memo exists):
- Mention inbox/context access — server/router/api/v1/memo_mention_helpers.go:~56-89
- Email notification gating — server/router/api/v1/user_service_notifications.go:~309-312 and server/notification/email.go:~313-316

The three primary/canonical layers are the first group (`checkMemoReadAccess`, the `ListMemos` filter, and the store-level SQL translation); the remaining entries are the additional distinct surfaces that independently re-enforce the same PUBLIC/PROTECTED/PRIVATE rules (combined with the `isSuperUser` and `AllowAnonymous` predicates).
