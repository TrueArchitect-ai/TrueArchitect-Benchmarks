**abstraction package: `internal/idp` (Go package `idp`); implementation package: `internal/idp/oauth2` (Go package `oauth2`, OAuth2)**

- The abstraction lives in `/bench/repo/internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that concrete providers return.
- The one concrete protocol implementation ships in `/bench/repo/internal/idp/oauth2/oauth2.go` — package doc: `// Package oauth2 implements the OAuth2 identity provider integration.` It defines the `IdentityProvider` struct and `NewIdentityProvider(...)` / `ExchangeToken(...)`, built on `golang.org/x/oauth2`, and imports `github.com/usememos/memos/internal/idp`. OAuth2 is the only protocol subpackage under `internal/idp/` (no SAML/OIDC/LDAP); the config type is `storepb.OAuth2Config`.
