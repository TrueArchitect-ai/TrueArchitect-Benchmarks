**No.** Outside the driver-selection factory, the MySQL driver is never constructed directly.

Evidence:

- The driver-selection factory is `NewDBDriver` in `store/db/db.go:14`, which `switch`es on `profile.Driver` and calls `mysql.NewDB(profile)` at `store/db/db.go:22`.
- The MySQL driver's only constructor is `mysql.NewDB` (`store/db/mysql/mysql.go`), returning `&DB{profile: profile}`.
- A repo-wide grep for MySQL driver construction (`mysql.NewDB`, `&mysql.DB`, `mysql.DB{`) across all `*.go` files returns exactly one hit — `store/db/db.go:22`, which is inside the factory. There are no other production or test call sites.
- The one apparent lookalike, `mysql.*` calls in `store/test/containers.go`, is a different `mysql` — the aliased testcontainers module (`github.com/testcontainers/testcontainers-go/modules/mysql`), which spins up a Docker container, not the `store/db/mysql` driver. Tests reach the driver only indirectly via `NewDBDriver`.
