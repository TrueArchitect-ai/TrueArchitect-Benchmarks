All dispatchers build a payload and call `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43,71`), which enqueues onto an async queue whose worker goroutines all invoke the same delivery function.

**Convergence function — `webhook.Post`** at `internal/webhook/webhook.go:120` (the `http.NewRequest("POST", requestPayload.URL, …)` + `safeClient.Do(req)` at lines 126/153 is where every path lands before the request goes out; `PostAsync` at `:184` and the `init()` worker at `:42` funnel into it).

The URL is user-configured and validated in the `CreateUserWebhook` / `UpdateUserWebhook` handlers (`server/router/api/v1/user_service_webhooks.go`) via `webhook.ValidateURL`, and stored per-user.
