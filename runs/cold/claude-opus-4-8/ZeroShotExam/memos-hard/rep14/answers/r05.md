**Premise correction:** This repository (the **Memos** project — Go backend + React frontend) does **not** define a GraphQL schema anywhere. There are no `*.graphql`/`*.gql` files, no `graphql`/`apollo`/`type-graphql` dependencies, no `gql` tags or `buildSchema` calls, and no tRPC either. The question's premise that the public API is GraphQL is incorrect.

**Actual API surface:** The public API is defined via **Protocol Buffers**, and exposed three ways from a single set of `.proto` service definitions — gRPC, gRPC-Gateway (RESTful JSON), and Connect-RPC.

- **Schema source of truth** — proto service definitions in `proto/api/v1/`:
  - `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `common.proto`
  - Each RPC carries `google.api.http` annotations defining the REST surface (base path `/api/v1`), e.g. in `proto/api/v1/memo_service.proto`: `rpc CreateMemo(...) { option (google.api.http) = { post: "/api/v1/memos" ... }; }`

- **Generated code:**
  - `proto/gen/api/v1/` — `*.pb.go` (messages), `*_grpc.pb.go` (gRPC), `*.pb.gw.go` (gRPC-Gateway REST)
  - `proto/gen/api/v1/apiv1connect/` — `*.connect.go` (Connect-RPC)
  - `proto/gen/openapi.yaml` — OpenAPI spec auto-generated from the protos (embedded via `proto/openapi_embed.go`); this is the closest thing to a "schema document," but it's a byproduct of the protos, served for MCP (`server/router/mcp/openapi.go`).

- **Server implementations / wiring:**
  - Handlers: `server/router/api/v1/` (`memo_service.go`, `user_service.go`, etc.)
  - Registration: `server/router/api/v1/v1.go` (`RegisterGateway`) and `server/router/api/v1/connect_handler.go` (`RegisterConnectHandlers`), mounted in `server/server.go`

- **Frontend confirmation:** `web/` uses Connect-RPC (`web/package.json` depends on `@connectrpc/connect`/`@connectrpc/connect-web`; typed clients created in `web/src/connect.ts`) — no GraphQL client.

**Bottom line:** There is no GraphQL schema. The public API is a Protobuf-defined surface (8 v1 services) in `proto/api/v1/`, exposed as gRPC + REST + Connect-RPC, with an auto-generated OpenAPI spec at `proto/gen/openapi.yaml`.
