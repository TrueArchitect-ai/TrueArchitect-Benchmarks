h03.

**abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp` (`internal/idp/idp.go`) defines the provider abstraction — the shared, protocol-agnostic `IdentityProviderUserInfo` type that every concrete provider returns.
- `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) is the one concrete protocol implementation that ships: OAuth2. Its header reads `// Package oauth2 implements the OAuth2 identity provider integration`, and it imports `internal/idp`, returning `*idp.IdentityProviderUserInfo` from its `UserInfo` method.

No SAML or LDAP implementation exists in the repo — OAuth2 is the only shipped protocol.
