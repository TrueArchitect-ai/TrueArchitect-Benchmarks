**Computation site:** The extraction runs in `internal/markdown/markdown.go` — `ExtractAll(content)` (lines ~356–422), which walks the goldmark AST in one pass. This is orchestrated by `RebuildMemoPayload(...)` in `server/runner/memopayload/runner.go` (lines 74–88), which copies the extracted data onto `memo.Payload.Tags` and `memo.Payload.Property` (`storepb.MemoPayload`, defined in `proto/gen/store/memo.pb.go`).

**Triggers (operations that recompute):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before storing.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the update mask includes `content` (i.e., content actually changed).
- Batch backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go` (lines 27–72), a startup/migration job that rebuilds the payload for all memos in batches.

**Extracted properties** (from the AST walk, written into `MemoPayload`):
- `Tags` — collected from tag nodes, deduped.
- `Property.Title` — text of the first block, only if it's an H1 heading.
- `Property.HasLink` — true if any link node exists.
- `Property.HasCode` — true for code block / fenced code block / code span.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(Note: `Mentions` are also extracted by `ExtractAll` but not stored on the payload, and the list "snippet"/preview is computed separately on read via `getMemoContentSnippet` → `GenerateSnippet`, not stored on the payload.)
