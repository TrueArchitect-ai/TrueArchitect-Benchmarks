**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

The data layer is the `store/` package (`/bench/repo/store/`), where persistent entity types are defined — `Attachment`, `IdentityProvider`, `Inbox`, `InstanceSetting`, `Memo`, `MemoRelation`, `MemoShare`, `Reaction`, `User`, `UserIdentity`, `UserSetting` (see `store/user.go`, `store/memo.go`, etc.).

Counting distinct packages *outside* the `store/` tree (excluding its DB drivers and test helpers) that reference each type as `store.<Type>`:

**`User` — 7 packages:**
- `server/auth`
- `server/notification`
- `server/router/api/v1`
- `server/router/api/v1/test`
- `server/router/fileserver`
- `server/router/frontend`
- `server/router/rss`

**`Memo` — 6 packages:**
- `server/notification`
- `server/router/api/v1`
- `server/router/api/v1/test`
- `server/router/frontend`
- `server/router/rss`
- `server/runner/memopayload`

`User` edges out `Memo` mainly because it's additionally consumed by the auth (`server/auth/user.go`) and file-serving (`server/router/fileserver`) packages.
