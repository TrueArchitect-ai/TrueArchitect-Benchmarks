## Answer

This is **Memos** (a self-hosted note-taking app in Go). Its RPC handlers are `*APIV1Service` methods exposed as gRPC/Connect services. The "user-configured URL" feature is **per-user webhooks** (`store.GetUserWebhooks` → `hook.Url`): memo-lifecycle RPCs dispatch payloads to those URLs, and every dispatch ultimately funnels through one delivery function.

### RPC handler methods (≥3)

Each of these transitively dispatches a webhook to the user-configured `hook.Url`:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` (→ `DispatchMemoCreatedWebhook`)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` (→ `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`)
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` (→ `DispatchMemoDeletedWebhook`)
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` (→ `DispatchMemoCommentCreatedWebhook`)
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:16` and **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:16` (both → `dispatchMemoUpdatedSideEffects`)

### Convergence function — path

**`Post`** — `internal/webhook/webhook.go:120`

Every handler above builds a `WebhookRequestPayload` (with `URL = hook.Url`), enqueues it via `webhook.PostAsync` (`webhook.go:184`), and the worker goroutines drain the queue and call `webhook.Post`. The actual outbound HTTP request is issued there at `internal/webhook/webhook.go:152` — `resp, err := safeClient.Do(req)` — the single point where all handler paths' outbound requests to the user-configured URL are delivered. (`safeClient` uses a `safeDialContext` SSRF guard that blocks private/reserved IPs, but all delivery still funnels through `Post`.)
