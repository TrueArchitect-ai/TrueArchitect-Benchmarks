**Premise correction:** This repository (the **memos** project — Go backend + a TypeScript `web/` frontend) has **no GraphQL at all**. There are no `*.graphql`/`*.gql` files and zero references to `graphql`, `apollo`, `type Query`, or `type Mutation` anywhere in the source. So there is no GraphQL schema to point to.

**Actual API surface:** The public API is defined in **Protocol Buffers** and served as gRPC + Connect RPC + a REST/JSON API via gRPC-Gateway, with a generated OpenAPI document.

- **Schema of record — the `.proto` files:** `proto/api/v1/`
  - `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, `common.proto`
  - Design notes: `proto/api/v1/README.md` (follows Google AIPs)
- **Codegen toolchain (`buf`):** `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`
  - Generated Go stubs: `proto/gen/api/v1/` — `*_grpc.pb.go` (gRPC), `*.pb.gw.go` (gRPC-Gateway → REST/HTTP JSON), and `proto/gen/api/v1/apiv1connect/*.connect.go` (Connect)
  - Generated OpenAPI spec: `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- **Server wiring:** `server/server.go` (registers the gRPC-Gateway as "api v1"); hand-written service implementations in `server/router/api/v1/` (`memo_service.go`, `user_service.go`, etc.), with Connect wiring in `connect_services.go`, `connect_handler.go`, `connect_interceptors.go` and authz in `authz.go` / `acl_config.go`
- **Additional non-gRPC surfaces** under `server/router/`: `mcp/` (Model Context Protocol), `rss/`, `fileserver/`, `frontend/`

In short: the authoritative "schema" for the public API is the set of `.proto` files in `proto/api/v1/` — not a GraphQL schema.
