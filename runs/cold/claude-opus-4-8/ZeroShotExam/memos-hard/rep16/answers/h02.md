**Delivery function** — `internal/webhook/webhook.go`: the outbound HTTP webhook request executes in the `Post` function, where it fires the request via the shared client (`resp, err := safeClient.Do(req)`, ~line 152). Async delivery goes through `PostAsync`, whose worker goroutines (started in `init`) ultimately call `Post` as well.

**Protection mechanism** — two layers, both keyed on `isReservedIP`:

- **Dial-time guard (primary, also defeats DNS rebinding)** — `internal/webhook/webhook.go`: `safeDialContext` is wired into `safeClient`'s `http.Transport.DialContext`. It re-resolves the target hostname at connection time and refuses to dial if any resolved address is a reserved/private IP. Because the check runs on the actual IP the connection uses, a hostname that passes up-front validation but later resolves to an internal address is still blocked.
- **Up-front URL validation** — `internal/webhook/validate.go`: `ValidateURL` enforces the http/https scheme and rejects hostnames resolving to reserved/private IPs, using `isReservedIP` against `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10`).

Note the escape hatch: the package var `AllowPrivateIPs` (validate.go) short-circuits `isReservedIP` to return `false`, disabling both layers of SSRF protection when a self-hosted deployment opts in.
