**Triggers (recomputation):**
- Memo create — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` on the new memo.
- Memo update (when content changes) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` after setting `memo.Content`.
- Bulk backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72` rebuilds the payload for every memo in batches.

**Extracted properties** (`storepb.MemoPayload_Property`, from the AST walk at `markdown.go:207-231`):
- `Title` — text of the document's first block if it is an H1 heading.
- `HasLink` — true if any `KindLink` node exists.
- `HasCode` — true if any code block/fenced code block/code span exists.
- `HasTaskList` — true if any task checkbox exists.
- `HasIncompleteTasks` — true if any task checkbox is unchecked.

These feed list/preview and filtering (e.g. `internal/filter/schema.go:191-224` maps `property.hasTaskList/hasLink/hasCode/hasIncompleteTasks`).
