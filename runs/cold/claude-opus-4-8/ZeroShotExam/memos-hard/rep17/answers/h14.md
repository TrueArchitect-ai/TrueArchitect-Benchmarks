**Computation site.** The persisted derived metadata lives in each memo's `Payload`, and is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark-based markdown service. The real work is the single-pass AST walk in `internal/markdown/markdown.go:356` — `(*service).ExtractAll(content []byte)` — which returns `ExtractedData{Tags, Mentions, Property}`; `RebuildMemoPayload` copies `data.Tags` and `data.Property` onto `memo.Payload`. (A second, non-persisted preview value, the `Snippet`, is generated at read time by `GenerateSnippet` in `internal/markdown/markdown.go:264`, called via `getMemoContentSnippet` during API-response conversion in `server/router/api/v1/memo_service_converter.go:76`.)

**Triggers.** There is no store/ORM hook; `RebuildMemoPayload` is called explicitly in the service layer before persisting:
- Create — always, `server/router/api/v1/memo_service.go:108`.
- Update — only when the `UpdateMask` includes `"content"` (`memo_service.go:436`, rebuild at line 447, assigned to `update.Payload`); other field updates (visibility, pinned, location, etc.) do not recompute.
- Bulk backfill — the payload runner `RunOnce` rebuilds all memos in batches of 100 (`server/runner/memopayload/runner.go:52`).

(The `Snippet` preview isn't triggered/stored — it's recomputed fresh on every read/conversion.)

**Extracted properties.** From `ExtractAll` into `Payload` (proto `proto/store/memo.proto:7-29`):
- `tags` — deduplicated `#tags`, case preserved (`markdown.go:376`).
- `property` (`MemoPayload_Property`): `title` (text of the first H1, only if it's the first block node, `markdown.go:384`), `has_link` (`:393`), `has_code` (code block/fenced/span, `:396`), `has_task_list` (`:399`), `has_incomplete_tasks` (any unchecked task, `:401`).

`ExtractAll` also computes `Mentions` (lowercased `@usernames`), but `RebuildMemoPayload` does not copy those into the payload. There is no `wordCount`; the list/preview excerpt is the on-the-fly `Snippet` (plain text, max 64 chars, truncated at a word boundary with a `" ..."` suffix, skipping code blocks).
