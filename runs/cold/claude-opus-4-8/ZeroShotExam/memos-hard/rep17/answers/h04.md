**Yes.** The MySQL driver (the `DB` struct in package `mysql`) is constructed directly outside the driver-selection factory in exactly one place — a test.

Evidence:

- **The MySQL driver type:** the `DB` struct in `store/db/mysql/mysql.go`, whose proper constructor is `mysql.NewDB`. Inside that constructor the struct is built once (`store/db/mysql/mysql.go:29`), which is not "outside" the intended path.

So the answer is yes, but the sole out-of-factory construction is an empty-struct literal in test code; production code always goes through `NewDBDriver` → `mysql.NewDB`.
