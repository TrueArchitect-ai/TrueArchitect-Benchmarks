**Premise correction:** There is no GraphQL schema anywhere in this repository. Zero `.graphql`/`.gql` files and zero references to `graphql`, `type Query`, `type Mutation`, Apollo, etc. (apparent "graph" hits are just substrings in `web/src/locales/*.json` translations). The frontend uses Connect RPC (`@connectrpc/connect`), not a GraphQL client.

**Actual public API surface — gRPC/Protobuf, exposed as REST (grpc-gateway) + Connect RPC:**

- **Contract / "schema" (source of truth):** `proto/api/v1/*.proto` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`. Codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`.
- **Generated transports:** `proto/gen/api/v1/` — `*_grpc.pb.go` (gRPC), `*.pb.gw.go` (grpc-gateway REST/JSON), `apiv1connect/*.connect.go` (Connect). Plus the generated OpenAPI spec `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- **Server implementations:** `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`, `v1.go`, `connect_services.go`), wired up in `server/server.go`.
- **Other HTTP surfaces:** `server/router/rss/`, `server/router/fileserver/`, and an MCP server at `server/router/mcp/`.

So the public API is defined by the Protobuf service definitions in `proto/api/v1/` — served as gRPC, REST/JSON, and Connect — not GraphQL.
