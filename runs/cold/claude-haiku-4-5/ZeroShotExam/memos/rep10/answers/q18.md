The three implementations of the database driver interface are:

1. **store/db/sqlite/sqlite.go** — SQLite implementation
2. **store/db/postgres/postgres.go** — PostgreSQL implementation
3. **store/db/mysql/mysql.go** — MySQL implementation

Factory function: **NewDBDriver** — **store/db/db.go**
