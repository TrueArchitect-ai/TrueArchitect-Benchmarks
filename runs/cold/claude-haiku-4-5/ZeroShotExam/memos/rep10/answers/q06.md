**Table name: `memo_relation`**

The `memo_relation` table (defined at `/bench/repo/store/migration/postgres/LATEST.sql`, lines 45-51) stores links between one memo and another related memo. It contains:
- `memo_id`: the source memo ID
- `related_memo_id`: the ID of the related memo
- `type`: the type of relationship

This structure allows storing bidirectional or typed relationships between memos.
