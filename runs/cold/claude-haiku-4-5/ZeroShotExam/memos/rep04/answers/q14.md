The ShortcutService has the following 5 RPCs:

1. **ListShortcuts** - returns a user's saved shortcuts
2. **GetShortcut** - retrieves a specific shortcut by name
3. **CreateShortcut** - creates a new shortcut for a user
4. **UpdateShortcut** - updates an existing shortcut
5. **DeleteShortcut** - deletes a shortcut
