**Mechanism:** Server-Sent Events (SSE)

**Hub path:** `/bench/repo/server/router/api/v1/sse_hub.go`

**Handler names:** `SSEEventMemoCreated`, `SSEEventMemoUpdated`, `SSEEventMemoDeleted`, `SSEEventMemoCommentCreated`, `SSEEventReactionUpserted`, `SSEEventReactionDeleted`

The server uses SSE for real-time event broadcasting. The hub is implemented in `sse_hub.go` with thread-safe connection management. Broadcasting occurs from multiple service methods:
- `memo_service.go`: `CreateMemo()` and `DeleteMemo()` 
- `memo_service_comments.go`: `CreateMemoComment()`
- `memo_update_helpers.go`: `dispatchMemoUpdatedSideEffects()`
- `reaction_service.go`: `UpsertMemoReaction()` and `DeleteMemoReaction()`

The client-side hook at `/bench/repo/web/src/hooks/useLiveMemoRefresh.ts` handles SSE connections and invalidates React Query caches based on received events.
