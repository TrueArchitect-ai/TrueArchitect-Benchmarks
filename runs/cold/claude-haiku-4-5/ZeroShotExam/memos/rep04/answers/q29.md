**Frontend Auth Interceptor:** `/bench/repo/web/src/connect.ts`  
**Tokens Managed:** JWT access tokens (15-min), HTTP-only refresh token cookies (30-day), Personal Access Tokens (PAT)  
**Backend Validation Package:** `/bench/repo/server/auth/`

The frontend interceptor in `connect.ts` adds `Authorization: Bearer {token}` headers to all API requests. It manages JWT access tokens (stored in `localStorage` with expiration tracking) and implements proactive refresh (before expiry) plus reactive refresh (on 401). The backend `server/auth` package validates these tokens using `github.com/golang-jwt/jwt/v5`: access tokens are stateless (signature validation only, 15-min TTL), refresh tokens are stateful (database revocation check, 30-day TTL), and PATs are SHA-256-hashed strings looked up in the database.
