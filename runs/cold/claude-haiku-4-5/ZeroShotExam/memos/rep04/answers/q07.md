**web/src/connect.ts**

The ConnectRPC service clients are created in this file using the `createClient` function from `@connectrpc/connect`. The file instantiates multiple service clients including `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`.
