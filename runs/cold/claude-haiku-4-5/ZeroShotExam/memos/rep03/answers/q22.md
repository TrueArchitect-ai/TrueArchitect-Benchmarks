When a memo is created, user webhooks are notified through the following chain:

1. **Dispatcher function and file**: `DispatchMemoCreatedWebhook` is called from the CreateMemo handler in `/bench/repo/server/router/api/v1/memo_service.go`

2. **Package that performs HTTP delivery**: `webhook` package (located at `/bench/repo/internal/webhook/webhook.go`)

3. **Request-signing mechanism**: HMAC-SHA256 signature using the Standard Webhooks specification format with headers:
   - `webhook-id`: Message ID in format `msg_<uuid>`
   - `webhook-timestamp`: Unix timestamp
   - `webhook-signature`: Computed as `v1,<base64-encoded-signature>` where the signature is HMAC-SHA256 of `msgID.timestamp.<json-body>`

**Answer format**: `DispatchMemoCreatedWebhook` — `/bench/repo/server/router/api/v1/memo_service_webhooks.go`; `webhook` package; HMAC-SHA256 (Standard Webhooks format)
