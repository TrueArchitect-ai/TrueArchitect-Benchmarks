The `memo_relation` table stores links between one memo and another related memo.

**Citation:**
- `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql` - Table definition (migration file)
- `/bench/repo/store/memo_relation.go` - Go model implementation

The `memo_relation` table has this schema:
- `memo_id` - Source memo
- `related_memo_id` - Target/related memo  
- `type` - Relation type (REFERENCE or COMMENT)
