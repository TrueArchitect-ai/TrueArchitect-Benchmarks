**Background workers/runners the server actually STARTS:**

1. S3 Presign Runner — 12-hour ticker interval (`time.NewTicker`)
2. Email async sender — 2 worker goroutines with 128-item queue, triggered by inbox notifications
3. Webhook dispatcher — 4 worker goroutines with 128-item queue, triggered by memo events
4. Cache cleanup loop — 5-minute ticker interval for cache eviction
5. HTTP server listener — TCP or Unix socket listener (Echo framework)
6. Signal handler — OS signal monitoring for graceful shutdown
7. SSE (Server-Sent Events) hub — Manages live connections with per-client 30-second heartbeats
8. PAT usage recorder — Fire-and-forget async tasks (spawned per token use, not a persistent runner)

**Unused scheduling infrastructure:**

- **`memopayload.Runner`** — `/bench/repo/server/runner/memopayload/runner.go` defines this runner with only a `RunOnce()` method, but it is NEVER instantiated or started as a background worker. Only its `RebuildMemoPayload()` function is called inline during memo operations in `/bench/repo/server/router/api/v1/memo_service.go`, not as a scheduled task.

- **Internal scheduler package** — An unused cron-based job scheduler exists at `/bench/repo/internal/scheduler/scheduler.go` but is never instantiated in the server startup.
