The compiled React frontend is served using **Go's `embed` package** (file embedding mechanism). The compiled frontend assets are embedded at build time into the Go binary from the `dist/` directory and served by Echo middleware configured with `middleware.StaticWithConfig`. The mechanism is wired in **`/bench/repo/server/router/frontend/frontend.go`** (lines 20-21, 41-60).

Specifically:
- Line 20: `//go:embed dist/*` directive embeds the compiled frontend
- Line 21: `var embeddedFiles embed.FS` holds the embedded files
- Lines 54-57: `middleware.StaticWithConfig` serves static assets from the embedded filesystem
- Line 59: `spaFallbackMiddleware` handles SPA routing by falling back to `index.html` for non-existent routes
