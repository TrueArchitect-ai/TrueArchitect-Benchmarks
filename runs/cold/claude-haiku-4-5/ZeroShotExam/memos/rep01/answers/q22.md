When a memo is created, user webhooks are notified through the following mechanism:

**Dispatcher function and file:** `DispatchMemoCreatedWebhook` — `/bench/repo/server/router/api/v1/memo_service_webhooks.go:15`

**Delivery package:** `github.com/usememos/memos/internal/webhook` (specifically the `PostAsync` function)

**Request-signing mechanism:** HMAC-SHA256 with Standard Webhooks format (using `whsec_<base64>` encoded signing secrets; the signature includes a message ID, timestamp, and the request body, sent via `webhook-id`, `webhook-timestamp`, and `webhook-signature` headers with the format `v1,<signature>`)
