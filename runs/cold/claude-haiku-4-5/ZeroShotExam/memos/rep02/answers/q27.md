**Mechanism**: Go's `embed` package (embedded filesystem)

**File**: `/bench/repo/server/router/frontend/frontend.go`

The compiled React frontend is served in production through Go's `embed` package. At line 20-21, the frontend build artifacts are embedded directly into the Go binary:

```go
//go:embed dist/*
var embeddedFiles embed.FS
```

This embedded filesystem is then served via Echo middleware (line 54) using `middleware.StaticWithConfig()` which routes requests to the embedded `dist` directory. The frontend HTML is served with appropriate cache headers, and there's a SPA fallback middleware (line 59) that routes unknown paths back to `index.html` for client-side routing.
