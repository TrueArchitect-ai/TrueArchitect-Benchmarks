The ConnectRPC service clients are created in the frontend source file **web/src/connect.ts**.

This file imports `createClient` from "@connectrpc/connect" and uses it to create service clients like `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`.
