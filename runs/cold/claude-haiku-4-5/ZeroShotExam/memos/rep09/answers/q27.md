The mechanism is **Go binary embedding with Echo middleware serving**. The compiled React frontend is embedded into the Go binary using `//go:embed`, then served via static file middleware in the Echo web framework with SPA fallback routing.

**File where it is wired:** `/bench/repo/server/router/frontend/frontend.go`

The `FrontendService.Serve()` method (lines 41–80) registers the static file middleware and SPA fallback handler that serves the embedded frontend assets in production. The frontend is built by Vite to `/bench/repo/server/router/frontend/dist` and embedded at compile time via the `//go:embed dist/*` directive (line 20).
