Based on the codebase analysis, the memo CRUD mutations and queries are distributed across multiple frontend modules. However, the primary module is:

**Path**: `/bench/repo/web/src/hooks/useMemoQueries.ts`

**Generated Service Client**: `memoServiceClient`

This hook file contains the main CRUD operations:
- Create: `useCreateMemo()`
- Read: `useMemos()`, `useInfiniteMemos()`, `useMemo()`, `useMemoComments()`, `useInfiniteMemoComments()`
- Update: `useUpdateMemo()`
- Delete: `useDeleteMemo()`

The `memoServiceClient` is imported from `@/connect` and is a Connect RPC client generated from the `MemoService` protobuf definitions located in `/bench/repo/web/src/types/proto/api/v1/memo_service_pb.ts`.

Additional memo CRUD operations also exist in `/bench/repo/web/src/hooks/useMemoShareQueries.ts` (for memo shares) and `/bench/repo/web/src/components/MemoEditor/services/memoService.ts` (for memo and comment operations), all using the same `memoServiceClient`.
