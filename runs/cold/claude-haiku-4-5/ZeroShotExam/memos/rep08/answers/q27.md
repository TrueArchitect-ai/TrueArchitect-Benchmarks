**Mechanism:** Go's `embed` package (embedding compiled files)

**Path:** /bench/repo/server/router/frontend/frontend.go

The React frontend is compiled by Vite and output to `../server/router/frontend/dist` (line 11 of package.json). The compiled files are then embedded directly into the Go binary using Go's `//go:embed dist/*` directive (line 20 of frontend.go). The `FrontendService.Serve()` method (line 41) registers Echo middleware that serves these embedded files as static assets and falls back to `index.html` for SPA routing via the `spaFallbackMiddleware` (line 59).
