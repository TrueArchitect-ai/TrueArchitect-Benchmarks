**Engine + Path:** CEL (Common Expression Language) via `github.com/google/cel-go`; implementation in `/bench/repo/internal/filter/` with core components in `engine.go`, `schema.go`, `parser.go`, `ir.go`, and `render.go`.

**Mechanism:** ListMemos parses the CEL filter string via `filter.DefaultEngine().CompileToStatement(filter, dialect)`, which compiles the expression into a dialect-agnostic intermediate representation (Condition tree), then renders it to SQL-specific syntax via a renderer that generates dialect-appropriate SQL fragments (handling SQLite/MySQL/PostgreSQL differences in JSON operators, timestamp functions, and null checks).
