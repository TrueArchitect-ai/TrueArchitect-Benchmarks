**Premise correction:** This repository does not have a GraphQL API. 

**Actual API surface:** The Memos project uses a **gRPC API** instead of GraphQL. The API is defined through Protocol Buffer (protobuf) files located in `/bench/repo/proto/api/v1/`. The public API services are defined in files such as:
- `/bench/repo/proto/api/v1/memo_service.proto`
- `/bench/repo/proto/api/v1/user_service.proto`
- `/bench/repo/proto/api/v1/auth_service.proto`
- `/bench/repo/proto/api/v1/instance_service.proto`
- And other service definitions in the same directory

The README explicitly mentions "full REST and gRPC APIs" — GraphQL is not part of the public API surface.
