**Premise Correction:** This repository does not use GraphQL for its public API. 

**Actual API Surface:** The public API is defined using **Protocol Buffers (protobuf)** in the `/bench/repo/proto/api/v1/` directory. The schema is composed of multiple service definition files:

- `proto/api/v1/common.proto` — Common data structures
- `proto/api/v1/memo_service.proto` — Memo operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/attachment_service.proto` — File attachments
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI services
- `proto/api/v1/idp_service.proto` — Identity provider config
- `proto/api/v1/shortcut_service.proto` — Shortcut management

The API follows [Google API Improvement Proposals (AIPs)](https://google.aip.dev/) with REST endpoints generated from proto definitions using Google API annotations. Documentation is in `proto/api/v1/README.md` and `proto/README.md`.
