r05. The repository does not use GraphQL for its public API. Instead, it uses Protocol Buffers (proto3).

**Premise Correction:** The public API schema is not defined in GraphQL format.

**Actual API Surface:** The Protocol Buffer schema files are located in `/bench/repo/proto/api/v1/`, containing service definitions across multiple `.proto` files including:
- `ai_service.proto`
- `attachment_service.proto`
- `auth_service.proto`
- `common.proto`
- `idp_service.proto`
- `instance_service.proto`
- `memo_service.proto`
- `shortcut_service.proto`
- `user_service.proto`

The API is gRPC-based with HTTP/JSON transcoding enabled via Google API annotations, following Google API Improvement Proposals design guidelines.
