**Premise correction:** The repository uses a gRPC/protobuf-based API, not GraphQL.

**Actual API surface:** The public API is defined in Protocol Buffer service definitions located in `/bench/repo/proto/api/v1/`:
- `/bench/repo/proto/api/v1/memo_service.proto`
- `/bench/repo/proto/api/v1/user_service.proto`
- `/bench/repo/proto/api/v1/attachment_service.proto`
- `/bench/repo/proto/api/v1/auth_service.proto`
- `/bench/repo/proto/api/v1/instance_service.proto`
- `/bench/repo/proto/api/v1/idp_service.proto`
- `/bench/repo/proto/api/v1/shortcut_service.proto`
- `/bench/repo/proto/api/v1/ai_service.proto`
- `/bench/repo/proto/api/v1/common.proto`

These `.proto` files define the service methods and message types using gRPC with HTTP transcoding annotations (via `google.api.http`).
