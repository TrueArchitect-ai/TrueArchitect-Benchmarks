**Premise correction**: Neither NATS nor RabbitMQ is used for webhook delivery.

**Actual mechanism**: The webhook delivery workers consume from a **Go channel** (built-in async queue), not an external message broker.

**Queue declaration location**: `/bench/repo/internal/webhook/webhook.go:39`

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

This is a buffered channel with capacity of 128 messages. Four concurrent worker goroutines are spawned at package initialization (`internal/webhook/webhook.go:42-55`) that continuously consume from this channel. Webhooks are enqueued asynchronously via `PostAsync()` which performs a non-blocking send to the channel, dropping messages if the queue is full.
