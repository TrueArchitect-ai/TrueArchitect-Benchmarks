**Premise correction:** This repository does not use GraphQL for its public API. The public API is defined using **Protocol Buffers (Proto3)**, not GraphQL.

**Actual API surface:** The public API schema is defined in the proto files located at `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto` — Memo CRUD operations
- `user_service.proto` — User management
- `auth_service.proto` — Authentication
- `instance_service.proto` — Instance configuration
- `attachment_service.proto` — File attachments
- `ai_service.proto` — AI-related operations
- `idp_service.proto` — Identity provider operations
- `shortcut_service.proto` — Shortcut management

These proto definitions are compiled to gRPC services and exposed via gRPC-Gateway as REST endpoints under `/api/v1/`. The generated OpenAPI schema is available at `/bench/repo/proto/gen/openapi.yaml`.
