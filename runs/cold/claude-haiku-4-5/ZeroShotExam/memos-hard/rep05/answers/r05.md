**Premise correction:** This repository does not use GraphQL for its public API. It uses **Protocol Buffers (protobuf)** instead.

**Actual API surface:** The public API schema is defined in Protocol Buffer files located in `/bench/repo/proto/api/v1/`:

- `memo_service.proto` — Memo operations
- `user_service.proto` — User management
- `auth_service.proto` — Authentication
- `attachment_service.proto` — Attachment handling
- `instance_service.proto` — Instance management
- `shortcut_service.proto` — Shortcut operations
- `idp_service.proto` — Identity provider services
- `ai_service.proto` — AI services
- `common.proto` — Shared types

Additionally, an **OpenAPI/REST schema** is generated from these protobuf definitions at `/bench/repo/proto/gen/openapi.yaml`.

The project uses the Buf tool (`/bench/repo/proto/buf.yaml`, `/bench/repo/proto/buf.gen.yaml`) to manage protocol buffer code generation, following Google API Improvement Proposals (AIPs) standards.
