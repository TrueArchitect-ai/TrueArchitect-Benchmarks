r04. Neither NATS nor RabbitMQ. The webhook delivery workers consume from an **in-process Go channel**, not from an external message broker.

**Premise correction**: The question assumes the webhook workers use an external message broker (NATS or RabbitMQ), but they don't.

**Actual mechanism**: 
- **Queue type**: Go channel (`asyncPostQueue`)
- **Queue declaration location**: `/bench/repo/internal/webhook/webhook.go:39`
- **Implementation**: A buffered channel with capacity 128 that is created at package initialization (`asyncPostQueue = make(chan *WebhookRequestPayload, 128)`)
- **Worker pool**: Four goroutines spawned in the `init()` function (lines 42-55) that consume from this channel and execute webhook POSTs synchronously
