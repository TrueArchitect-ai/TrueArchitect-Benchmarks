The background agent has confirmed and expanded on my findings. To clarify my answer above with the additional detail discovered:

The repository's **public API schema is defined in `/bench/repo/proto/gen/openapi.yaml`** — an auto-generated OpenAPI 3.0.3 specification that documents the REST API surface.

The schema is derived from **Protocol Buffer service definitions** in `/bench/repo/proto/api/v1/` (memo_service.proto, user_service.proto, auth_service.proto, etc.), which are compiled with the `protoc-gen-openapi` plugin to generate the OpenAPI spec.

There is no GraphQL schema in this repository. The Memos project uses a **gRPC + REST API** architecture, not GraphQL.
