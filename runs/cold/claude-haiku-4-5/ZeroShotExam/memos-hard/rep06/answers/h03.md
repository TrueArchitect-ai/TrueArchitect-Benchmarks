**Abstraction package**: `github.com/usememos/memos/internal/idp`  
**Implementation package**: `github.com/usememos/memos/internal/idp/oauth2`

The abstraction is defined in `/bench/repo/internal/idp/idp.go` which exports `IdentityProviderUserInfo` (a struct with Identifier, DisplayName, Email, AvatarURL fields).

The concrete OAuth2 protocol implementation is in `/bench/repo/internal/idp/oauth2/oauth2.go` which provides the `IdentityProvider` struct with methods for token exchange (`ExchangeToken`) and user information retrieval (`UserInfo`). This wraps the standard `golang.org/x/oauth2` library and supports PKCE (RFC 7636).
