**Premise Correction:** The webhook delivery system does not use NATS or RabbitMQ. There is no external message broker.

**Actual Mechanism:** The webhook delivery workers consume from an in-process Go channel. The queue is declared in `/bench/repo/internal/webhook/webhook.go` at line 39:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four concurrent worker goroutines are launched in the `init()` function (lines 42-55 of the same file) that continuously receive from this buffered channel with capacity 128 and process webhook deliveries synchronously via the `Post()` function.
