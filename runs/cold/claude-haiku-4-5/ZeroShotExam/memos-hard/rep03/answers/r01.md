**Premise Correction:** This repository does not use Redis. It implements an in-memory cache layer instead.

**Actual Mechanism:**

The cache is configured in `/bench/repo/store/cache/cache.go` (lines 57-64) with the following default settings:

```go
func DefaultConfig() Config {
    return Config{
        DefaultTTL:      10 * time.Minute,
        CleanupInterval: 5 * time.Minute,
        MaxItems:        1000,
        OnEviction:      nil,
    }
}
```

This configuration is applied in `/bench/repo/store/store.go` (lines 40-45) where the Store initializes three separate caches, including `userCache` for user entries.

**User Entry TTL: 10 minutes** — all user cache entries (set via `s.userCache.Set()` in `/bench/repo/store/user.go`) use the default TTL of 10 minutes. The cache cleanup loop runs every 5 minutes to remove expired entries.
