**Premise correction:** This repository does not use GraphQL for its public API schema. It uses **Protocol Buffers (protobuf)** instead.

**Actual API surface:** The public API schema is defined in protobuf service files located in `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto` - Memo CRUD and operations
- `user_service.proto` - User management and authentication
- `auth_service.proto` - Authentication endpoints
- `attachment_service.proto` - File attachments
- `instance_service.proto` - Instance configuration
- `shortcut_service.proto` - Saved search filters
- `ai_service.proto` - AI features
- `idp_service.proto` - Identity provider config
- `common.proto` - Shared types

The API is implemented as a gRPC service with HTTP/REST bindings exposed at `/api/v1/` endpoints.
