**Premise correction**: This repository does not use GraphQL for its public API. Instead, it uses **gRPC with Protocol Buffers (protobuf)**.

**Actual API surface**: The public API schema is defined in `/bench/repo/proto/api/v1/` directory, containing the following protobuf service definitions:
- `memo_service.proto` - Memo operations
- `user_service.proto` - User operations
- `instance_service.proto` - Instance operations
- `attachment_service.proto` - Attachment operations
- `auth_service.proto` - Authentication operations
- `shortcut_service.proto` - Shortcut operations
- `idp_service.proto` - Identity provider operations
- `ai_service.proto` - AI operations
- `common.proto` - Common message types

The API follows Google API Improvement Proposals (AIPs) guidelines as noted in `/bench/repo/proto/api/v1/README.md`.
