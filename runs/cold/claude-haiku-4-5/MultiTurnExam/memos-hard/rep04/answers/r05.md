**Premise correction:** There is no GraphQL schema for the public API. The repository does not use GraphQL.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC services. The API schema is defined in proto files located in `/bench/repo/proto/api/v1/`:

- **memo_service.proto** — Memo operations (create, read, update, delete, list, reactions)
- **user_service.proto** — User management and authentication
- **attachment_service.proto** — File attachment handling
- **auth_service.proto** — Authentication flows (login, logout, session management)
- **instance_service.proto** — Instance/system settings and configuration
- **shortcut_service.proto** — Shortcut/alias management
- **ai_service.proto** — AI-related operations
- **idp_service.proto** — Identity provider configuration

These protobuf definitions are compiled to Go (proto/gen/api/v1/) and exposed via both gRPC and gRPC-Gateway (HTTP/REST) transports. The API is not GraphQL-based.
