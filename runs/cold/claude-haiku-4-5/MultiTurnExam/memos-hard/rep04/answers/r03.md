**Premise correction:** There is no nightly database-cleanup job scheduled to run in a cron scheduler. 

The repository contains a generic scheduler package (`internal/scheduler/`) that *provides* the capability to register cron jobs, but it is never actually instantiated or used anywhere in the codebase. No jobs are registered with it.

The only background cleanup operations that actually run are:
1. Cache cleanup goroutine (store/cache/cache.go) that runs on a 5-minute interval
2. S3 presign refresh runner (server/runner/s3presign/runner.go) that runs every 12 hours

Neither of these is a "nightly database-cleanup job" scheduled via a cron scheduler. The S3 presign runner is the closest to a scheduled background task and runs every 12 hours, not nightly.
