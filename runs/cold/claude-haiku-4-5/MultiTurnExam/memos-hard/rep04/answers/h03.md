**Abstraction package — github.com/usememos/memos/internal/idp; Implementation package — github.com/usememos/memos/internal/idp/oauth2**

The abstraction is defined in `/bench/repo/internal/idp/idp.go`, which defines the `IdentityProviderUserInfo` struct that represents the common interface for user information returned by identity providers.

The concrete protocol implementation that ships is OAuth2, located in `/bench/repo/internal/idp/oauth2/oauth2.go`, which implements an `IdentityProvider` type that handles OAuth2 token exchange and user info retrieval with configurable field mappings and PKCE support.
