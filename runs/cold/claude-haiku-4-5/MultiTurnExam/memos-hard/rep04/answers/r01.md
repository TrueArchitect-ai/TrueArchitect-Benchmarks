**Premise correction:** There is no Redis connection. The question assumes Redis is used, but the caching implementation is in-memory only.

**Actual mechanism:** The cache layer is implemented as an in-memory cache defined in `store/cache/cache.go`. It is configured in `store/store.go:40-45` with a default TTL of **10 minutes** (`DefaultTTL: 10 * time.Minute`) that applies uniformly to all cache entries including user entries (`userCache` at store/store.go:52). The cache is initialized with these settings in `store/store.go:51-52` for all three cache instances (instanceSettingCache, userCache, userSettingCache). There is no external cache backend; all caching is done in-process using Go's `sync.Map` with TTL-based expiration managed by a background cleanup goroutine (store/cache/cache.go:83).
