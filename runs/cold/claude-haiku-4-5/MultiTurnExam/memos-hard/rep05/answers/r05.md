r05. **Premise correction**: There is no GraphQL schema. The public API is NOT GraphQL-based.

**Actual API surface**: The public API is defined using **Protocol Buffers (gRPC)** with REST bindings via gRPC-Gateway.

**Definition location**: Proto files are located in `/bench/repo/proto/api/v1/`:
- `ai_service.proto` (AI services)
- `attachment_service.proto` (Attachment operations)
- `auth_service.proto` (Authentication)
- `common.proto` (Common types)
- `idp_service.proto` (Identity Provider)
- `instance_service.proto` (Instance management)
- `memo_service.proto` (Memo operations)
- `shortcut_service.proto` (Shortcuts)
- `user_service.proto` (User operations)

The API is served via:
1. **gRPC** (native Protocol Buffer RPC)
2. **REST** (via gRPC-Gateway at server/router/api/v1/v1.go:65)
3. **Connect** (alternative gRPC client library support at server/router/api/v1/v1.go)

This follows Google API Improvement Proposals (AIPs) as documented in proto/api/v1/README.md.
