**Premise correction:** There is no GraphQL schema for the public API in this repository. The API is defined using Protocol Buffers (protobuf), not GraphQL.

**Actual API surface:** 
The public API is defined through protobuf service definitions in proto/api/v1/:
- proto/api/v1/memo_service.proto
- proto/api/v1/user_service.proto
- proto/api/v1/auth_service.proto
- proto/api/v1/attachment_service.proto
- proto/api/v1/idp_service.proto
- proto/api/v1/ai_service.proto
- proto/api/v1/instance_service.proto
- proto/api/v1/shortcut_service.proto
- proto/api/v1/common.proto

These protobuf definitions are compiled to gRPC-Gateway handlers (registered in server/router/api/v1/v1.go) and Connect protocol handlers, exposing REST/JSON and gRPC APIs, but there is no GraphQL schema defined anywhere in the codebase.
