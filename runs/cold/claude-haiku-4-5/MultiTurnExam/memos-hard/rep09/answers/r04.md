**Premise correction:** There is no NATS or RabbitMQ message broker for webhook delivery. Webhook delivery workers consume from an in-memory Go channel, not an external message broker.

**Actual mechanism:** Webhooks use a simple buffered channel-based queue:
- **Queue declaration:** internal/webhook/webhook.go:39 — `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`
- **Worker pool:** internal/webhook/webhook.go:42-54 — 4 goroutines spawned on init that consume from this channel and execute Post() directly
- **Enqueue:** internal/webhook/webhook.go:184-196 — PostAsync() sends payloads to the in-memory queue with bounded capacity (128 items)

This is a simple, in-process implementation with no external message broker infrastructure.
