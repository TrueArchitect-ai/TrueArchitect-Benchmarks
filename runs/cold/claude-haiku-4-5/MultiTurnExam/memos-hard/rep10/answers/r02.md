**Premise correction:** Per-user API rate-limiting middleware is not implemented in the codebase. There is no rate-limiting middleware registered and no per-user request throttling mechanism. The application implements only global request size limiting (256 MB max body at `/bench/repo/server/router/api/v1/v1.go:20`), concurrent operation limits for resource-intensive tasks (3 concurrent thumbnails, 2 concurrent image processing operations at `/bench/repo/server/router/api/v1/v1.go:59-60`), and standard authentication/authorization via Connect interceptors at `/bench/repo/server/router/api/v1/connect_interceptors.go`. Rate limiting is not a feature of the Memos API itself; it is designed to be managed at the infrastructure/proxy level for self-hosted deployments.
