**`github.com/usememos/memos/internal/idp`** (abstraction package defining `IdentityProviderUserInfo`); **`github.com/usememos/memos/internal/idp/oauth2`** (OAuth2 implementation)

The abstraction is defined in `/bench/repo/internal/idp/idp.go` with a data structure `IdentityProviderUserInfo` containing common fields (`Identifier`, `DisplayName`, `Email`, `AvatarURL`). The concrete OAuth2 implementation is in `/bench/repo/internal/idp/oauth2/oauth2.go`, providing an `IdentityProvider` struct with `ExchangeToken()` and `UserInfo()` methods that support PKCE-protected authorization code flow. Currently, OAuth2 is the only protocol implementation shipped.
