GraphQL is not used. The premise is incorrect. The public API is defined using **Protocol Buffers (protobuf) with gRPC and Connect RPC**. Schema files are located in `/bench/repo/proto/api/v1/` as `.proto` files, including `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, and `idp_service.proto`. Generated gRPC stubs are in `/bench/repo/proto/gen/api/v1/`, and gRPC-Gateway HTTP mappings enable REST access. The server registers handlers via `apiV1Service.RegisterGateway()` in `/bench/repo/server/server.go:88`, with Connect protocol handlers in `/bench/repo/server/router/api/v1/v1.go:139-144`. The API surface supports three simultaneous protocols: gRPC (HTTP/2), Connect RPC (HTTP/1.1), and auto-generated REST endpoints on `/api/v1/*`.
