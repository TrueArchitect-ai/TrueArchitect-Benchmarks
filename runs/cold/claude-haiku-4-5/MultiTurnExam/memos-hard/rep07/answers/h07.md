The `serveUserAvatar` handler retrieves the requested user via `getUserByUsername`, which calls through the store layer (`Store.GetUser` → `Store.ListUsers` → `DB.ListUsers`) to fetch the user record including the `avatar_url` column from the database. The avatar is stored as a base64-encoded data URI string; `parseDataURI` decodes it and the handler serves it as a blob response.
