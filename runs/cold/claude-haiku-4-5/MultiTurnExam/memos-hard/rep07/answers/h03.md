h03.

`internal/idp`; `internal/idp/oauth2`

The abstraction package `internal/idp` defines the provider interface with the `IdentityProviderUserInfo` struct in `/bench/repo/internal/idp/idp.go`. The concrete implementation that ships is `internal/idp/oauth2` in `/bench/repo/internal/idp/oauth2/oauth2.go`, which implements generic OAuth2 protocol support that can connect to any OAuth2-compliant provider (configured via protobuf schema in `/bench/repo/proto/store/idp.proto`).
