**Premise correction**: There is no GraphQL schema for the public API. The API is defined using Protocol Buffers (protobuf), not GraphQL.

**Actual API surface**: The public API is defined in protobuf service definitions at `/bench/repo/proto/api/v1/`. The API consists of the following services, each with its own proto file:

1. **AuthService** — `/bench/repo/proto/api/v1/auth_service.proto`
2. **InstanceService** — `/bench/repo/proto/api/v1/instance_service.proto`
3. **UserService** — `/bench/repo/proto/api/v1/user_service.proto`
4. **MemoService** — `/bench/repo/proto/api/v1/memo_service.proto`
5. **AttachmentService** — `/bench/repo/proto/api/v1/attachment_service.proto`
6. **IdentityProviderService** — `/bench/repo/proto/api/v1/idp_service.proto`
7. **ShortcutService** — `/bench/repo/proto/api/v1/shortcut_service.proto`
8. **AIService** — `/bench/repo/proto/api/v1/ai_service.proto`

These protobuf definitions are transpiled to both gRPC and REST endpoints via the gRPC-Gateway and Connect protocols, as configured in the Google API annotations (e.g., `option (google.api.http) = {post: "/api/v1/memos"}`).
