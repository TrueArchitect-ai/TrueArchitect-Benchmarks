h03.

**Abstraction package**: `github.com/usememos/memos/internal/idp`

**Implementation package**: `github.com/usememos/memos/internal/idp/oauth2`

The abstraction is defined in the `idp` package, which defines the `IdentityProviderUserInfo` struct that represents user information returned by any identity provider. The concrete OAuth2 protocol implementation ships in the `idp/oauth2` subpackage, which provides the `IdentityProvider` type that implements token exchange and user info retrieval via OAuth2.
