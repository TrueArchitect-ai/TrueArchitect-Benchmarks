The browser requests `/file/users/{identifier}/avatar`, which invokes `serveUserAvatar`. This handler calls `getUserByUsername`, which delegates to `Store.GetUser`, which checks cache and calls `Store.ListUsers`, which finally delegates to the database driver's `ListUsers` method (implemented identically in SQLite, MySQL, and PostgreSQL drivers), executing a SELECT query against the `user` table to retrieve the user record including the `avatar_url` field from stored data.
