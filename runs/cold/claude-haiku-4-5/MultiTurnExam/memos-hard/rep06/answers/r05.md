**Premise correction:** There is no GraphQL schema defined in this repository. GraphQL is not used.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC services, exposed via:

1. **gRPC-Gateway (HTTP/JSON)** — REST API at `/api/v1/*`
2. **Connect RPC (browser clients)** — at `/memos.api.v1.*`

The API schema is defined in Protocol Buffer files (`.proto` files) located in `/bench/repo/proto/api/v1/`:
- `memo_service.proto` — Memo CRUD operations
- `attachment_service.proto` — Attachment management
- `auth_service.proto` — Authentication (sign in, sign up, etc.)
- `user_service.proto` — User management
- `instance_service.proto` — Instance configuration
- `ai_service.proto` — AI/transcription services
- `idp_service.proto` — Identity provider configuration
- `shortcut_service.proto` — Shortcut management

These `.proto` files are compiled to Go code in `/bench/repo/proto/gen/api/v1/` and served as both:
- **RESTful JSON API** via gRPC-Gateway middleware
- **Connect RPC protocol** for browser clients

There is no GraphQL implementation anywhere in the codebase.
