The frontend auth interceptor in connect.ts manages access tokens and refresh tokens, injecting them into the Authorization header on API requests. The backend validates tokens using the auth package, which implements JWT verification and token refresh logic used by the Connect interceptor at `/bench/repo/server/router/api/v1/connect_interceptors.go`.
