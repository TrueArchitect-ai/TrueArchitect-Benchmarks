q27. Go's `embed` directive (`//go:embed dist/*`) to embed compiled React frontend as static files; `/bench/repo/server/router/frontend/frontend.go`

The compiled React frontend is served in production using:

1. **Mechanism**: Go's native `embed` package (line 20 in frontend.go: `//go:embed dist/*`) which embeds the compiled React build output (`dist/*`) directly into the binary. The frontend is served via Echo middleware using `middleware.StaticWithConfig` with an SPA fallback (index.html) for client-side routing, with appropriate cache headers for HTML (no-cache) and hashed assets (immutable, 1 hour).

2. **Wiring file**: `/bench/repo/server/router/frontend/frontend.go` where the `FrontendService` is defined, and wired into the Echo server at `/bench/repo/server/server.go` (line 72).
