q06. memo_relation

The database table that stores links between one memo and another related memo is `memo_relation`, as defined in migration files across all supported SQL dialects:
- `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql`
- `/bench/repo/store/migration/postgres/LATEST.sql`
- `/bench/repo/store/migration/mysql/LATEST.sql`

The table contains `memo_id`, `related_memo_id`, and `type` columns to represent the relationship between memos.
