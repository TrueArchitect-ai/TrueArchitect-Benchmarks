Server-Sent Events (SSE); /bench/repo/server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The SSE hub is implemented in `/bench/repo/server/router/api/v1/sse_hub.go` and provides a `Broadcast()` method for sending events.

The following memo-related handlers broadcast SSE events through the hub:
1. **CreateMemo** (line 163 in memo_service.go) — broadcasts `SSEEventMemoCreated`
2. **UpdateMemo** (line 71 in memo_update_helpers.go) — broadcasts `SSEEventMemoUpdated`
3. **DeleteMemo** (line 585 in memo_service.go) — broadcasts `SSEEventMemoDeleted`
4. **CreateMemoComment** (line 126 in memo_service_comments.go) — broadcasts `SSEEventMemoCommentCreated`
5. **UpsertMemoReaction** (reaction_service.go) — broadcasts `SSEEventReactionUpserted`
6. **DeleteMemoReaction** (reaction_service.go) — broadcasts `SSEEventReactionDeleted`
