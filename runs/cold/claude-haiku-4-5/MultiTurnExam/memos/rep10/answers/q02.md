SQLite, MySQL, PostgreSQL

The project ships migrations for three SQL dialects. The migrations are organized in separate directories at `/bench/repo/store/migration/`:
- `/bench/repo/store/migration/sqlite/` - SQLite migrations
- `/bench/repo/store/migration/mysql/` - MySQL migrations
- `/bench/repo/store/migration/postgres/` - PostgreSQL migrations

Each dialect has its own versioned migration files adapted to that database's specific SQL syntax.
