/bench/repo/web/src/connect.ts; access tokens, refresh tokens; /bench/repo/server/auth

Frontend API requests are authenticated via:
1. **Auth interceptor location**: `/bench/repo/web/src/connect.ts` (lines 156-178) — the `authInterceptor` is defined and attached to the ConnectRPC transport
2. **Token kinds managed**: 
   - Access tokens (short-lived JWT, 15 minutes) — stored in localStorage and managed in `/bench/repo/web/src/auth-state.ts`
   - Refresh tokens (long-lived, stored as HTTP-only cookies) — handled via the `refreshAuthClient.refreshToken()` call
3. **Backend validation package**: `/bench/repo/server/auth` — the `Authenticator` struct (in `/bench/repo/server/auth/authenticator.go`) validates both access tokens via `AuthenticateByAccessTokenV2()` (stateless JWT validation) and refresh tokens via `AuthenticateByRefreshToken()` (database revocation check)
