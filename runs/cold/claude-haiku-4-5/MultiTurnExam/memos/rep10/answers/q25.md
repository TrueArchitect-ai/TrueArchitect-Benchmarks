CEL (Common Expression Language) — /bench/repo/internal/filter/engine.go; The filter engine parses the CEL expression into a dialect-agnostic condition tree, then the renderer converts it to dialect-specific SQL (SQLite, MySQL, PostgreSQL) using the appropriate placeholders and quoting conventions.

The ListMemos filter uses:
1. **Engine**: CEL (Common Expression Language) via the `google/cel-go` library, implemented in `/bench/repo/internal/filter/engine.go`
2. **Parsing mechanism**: The `Engine.CompileToStatement()` method (line 74) parses the filter string as CEL and compiles it into a dialect-agnostic condition tree
3. **SQL conversion**: The `renderer` (defined in `/bench/repo/internal/filter/render.go`) converts the condition tree to dialect-specific SQL. For each dialect (SQLite, MySQL, PostgreSQL), it uses appropriate placeholder styles (?, $1, etc.) and quoting conventions (backticks, quotes, or no quotes)
4. **Integration**: The helper function `AppendConditions()` in `/bench/repo/internal/filter/helpers.go` (line 9) applies these compiled filters by appending the SQL fragment and arguments to the WHERE clause for each database dialect
