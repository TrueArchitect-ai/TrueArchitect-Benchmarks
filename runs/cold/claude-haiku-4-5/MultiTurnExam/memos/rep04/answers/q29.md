Frontend API requests are authenticated via the `authInterceptor` (defined in `/bench/repo/web/src/connect.ts` at lines 156-178), which manages three types of tokens:
1. **Access tokens** (short-lived, 15 minutes) - sent in Authorization header as Bearer tokens
2. **Refresh tokens** (long-lived, 30 days) - used to obtain new access tokens via RefreshToken RPC
3. **Personal Access Tokens (PATs)** (long-lived) - for programmatic access

These tokens are validated by the backend `server/auth` package (`/bench/repo/server/auth/`), which provides JWT parsing and validation functions (`ParseAccessTokenV2`, `ParseRefreshToken`) and PAT hash validation via `GetUserByPATHash`.
