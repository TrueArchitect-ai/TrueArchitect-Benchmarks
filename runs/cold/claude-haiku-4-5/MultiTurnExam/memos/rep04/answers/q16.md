memo_relation records, attachments

When a memo is deleted through the API, the store layer deletes (in this order):
1. memo_relation records where the memo is the source (line 142)
2. memo_relation records where the memo is the target (line 145)
3. attachments linked to the memo (lines 149-157)

Then the memo row itself is deleted (line 158).

The code is in `/bench/repo/store/memo.go` lines 140-159 in the `DeleteMemo` method.
