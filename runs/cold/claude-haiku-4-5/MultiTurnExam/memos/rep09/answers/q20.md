The server uses **Server-Sent Events (SSE)** to push live events to browsers. The mechanism is implemented through:
- **Hub implementation**: `/bench/repo/server/router/api/v1/sse_hub.go` contains the `SSEHub` struct (line 56) which manages client subscriptions and broadcasts events
- **Memo handlers that broadcast**: Three memo RPC handlers broadcast through the SSE hub:
  1. **CreateMemo** (line 163 in `/bench/repo/server/router/api/v1/memo_service.go`) — broadcasts `SSEEventMemoCreated`
  2. **UpdateMemo** (indirectly via `dispatchMemoUpdatedSideEffects` called at line 513) — broadcasts `SSEEventMemoUpdated`
  3. **DeleteMemo** (line 585 in `/bench/repo/server/router/api/v1/memo_service.go`) — broadcasts `SSEEventMemoDeleted`
