q16. memo_relation (where the memo is either source or target), attachments

When a memo is deleted through the API, the store layer (`Store.DeleteMemo` in `/bench/repo/store/memo.go` at lines 140-159) deletes the following records **before** the memo row itself:

1. **memo_relation** records where the memo is the source (lines 142-143)
2. **memo_relation** records where the memo is the target (lines 145-146)
3. **attachments** linked to this memo (lines 149-157)

Only after these cleanup operations completes does the store layer delete the memo row itself (line 158).

Additionally, the API layer (in `/bench/repo/server/router/api/v1/memo_service.go`) deletes **memo comments** (which are memos with type `MemoRelationComment`) before calling `Store.DeleteMemo` (lines 567-577).
