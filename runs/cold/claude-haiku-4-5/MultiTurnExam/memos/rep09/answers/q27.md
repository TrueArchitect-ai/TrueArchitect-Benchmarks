q27. Go `embed` package (filesystem embedding); /bench/repo/server/router/frontend/frontend.go

The compiled React frontend is served in production using:

1. **Mechanism**: Go's built-in `embed` package — the compiled frontend assets from the `dist/` directory are embedded directly into the binary at compile time (line 20-21: `//go:embed dist/*` and `var embeddedFiles embed.FS`)

2. **File where it's wired**: `/bench/repo/server/router/frontend/frontend.go` — the `FrontendService.Serve()` method (line 41) uses Echo's `StaticWithConfig` middleware (line 54) to serve the embedded filesystem with:
   - Static asset serving from the embedded `dist/` filesystem
   - SPA fallback middleware (line 59) that serves `index.html` for all non-API paths (to handle client-side routing)
   - Cache headers configured by path (HTML gets no-cache, hashed assets get immutable cache)
