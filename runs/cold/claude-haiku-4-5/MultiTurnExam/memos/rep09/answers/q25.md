The ListMemos RPC accepts filter expressions using:

1. **Syntax/Engine**: **CEL (Common Expression Language)** from the `github.com/google/cel-go` library
2. **Engine location**: `/bench/repo/internal/filter/engine.go` — contains the `Engine` struct that parses CEL expressions (line 14) and the `DefaultEngine()` factory function (line 111)
3. **Mechanism**: The CEL filter is compiled into a dialect-agnostic `Condition` tree via `engine.Compile()`, then rendered into dialect-specific SQL using the `Render()` function in `/bench/repo/internal/filter/render.go` (line 32), which generates SQL fragments with appropriate placeholder syntax (e.g., `$1, $2` for PostgreSQL, `?` for MySQL/SQLite) via the `DialectName` parameter.
