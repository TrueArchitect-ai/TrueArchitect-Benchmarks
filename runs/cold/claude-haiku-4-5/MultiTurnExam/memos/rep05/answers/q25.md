CEL (Common Expression Language) — /bench/repo/internal/filter/engine.go; The filter string is parsed by a CEL-based Engine into a dialect-agnostic condition tree, then the Render method converts the condition tree to dialect-specific SQL via a renderer that handles placeholders and SQL escaping for SQLite, MySQL, and PostgreSQL.

The ListMemos RPC accepts filter expressions in **CEL (Common Expression Language)** syntax. The engine lives in `/bench/repo/internal/filter/engine.go` (the `Engine` type). The conversion mechanism works as follows:

1. The CEL filter string is parsed by `Engine.Compile()` into a dialect-agnostic condition tree
2. `Engine.CompileToStatement()` then renders the tree for a specific dialect (SQLite/MySQL/PostgreSQL) via `renderer.Render()` in `/bench/repo/internal/filter/render.go`
3. Each dialect's rendering is handled by the same renderer but with dialect-specific SQL generation (placeholders, functions, etc.) determined by the `DialectName` passed to `RenderOptions`
4. The renderer generates parameterized SQL fragments and args that are appended to the WHERE clause in each database driver's `ListMemos` implementation
