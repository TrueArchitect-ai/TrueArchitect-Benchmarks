/bench/repo/server/router/api/v1/connect_interceptors.go; Access Token V2 (JWT), Personal Access Tokens (PAT), Refresh Tokens (JWT); /bench/repo/server/auth

The AuthInterceptor in connect_interceptors.go uses the Authenticator from the auth package to validate three types of tokens: JWT Access Tokens (short-lived, 15 minutes), Personal Access Tokens (long-lived), and JWT Refresh Tokens (long-lived, 30 days). The auth package (/bench/repo/server/auth) handles token validation, parsing, and database checks.
