Go's embed package (compile-time embedding of the dist/ directory into the binary); /bench/repo/server/router/frontend/frontend.go

**Source:** The compiled React frontend is served in production using **Go's `embed` package** with the `//go:embed dist/*` directive (line 20-21 in `/bench/repo/server/router/frontend/frontend.go`). This embeds the entire `dist/` directory (containing the compiled React build artifacts) directly into the Go binary at compile time. The mechanism is wired in the `Serve()` method (lines 41-61) which:
1. Extracts the embedded filesystem using `getFileSystem("dist")` (line 42)
2. Registers an Echo middleware using `middleware.StaticWithConfig()` to serve static assets from the embedded filesystem (lines 54-57)
3. Registers a SPA fallback middleware (line 59) that serves `index.html` for all non-API routes to enable client-side routing
