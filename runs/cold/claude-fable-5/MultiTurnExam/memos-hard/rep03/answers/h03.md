**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider abstraction — the `idp` package with the shared `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation maps its user info into.
- `internal/idp/oauth2/oauth2.go` is the one concrete protocol implementation that ships: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, and a field mapping used to translate the provider's user-info response into `idp.IdentityProviderUserInfo`). It's the only subpackage under `internal/idp` — there is no LDAP/SAML implementation in the tree.
