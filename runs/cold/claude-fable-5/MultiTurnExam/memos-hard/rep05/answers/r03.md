What actually exists:

- A cron scheduler library lives at `internal/scheduler/` (parser, jobs, middleware), and its documentation shows an *example* job named `"daily-cleanup"` (`internal/scheduler/doc.go:15-18`) — but that's illustrative doc comment code, not a registered job. - The only recurring background work the server actually schedules is the S3 presign refresher, which runs on a simple `time.Ticker` every 12 hours — not cron, and not database cleanup (`server/runner/s3presign/runner.go:26-41`, started from `server/server.go:161-171`).
- Database cleanup as such doesn't exist as a scheduled task; deletions cascade inline within request handling (e.g. `store.DeleteMemo` handles relation/attachment cleanup, per `server/router/api/v1/memo_service.go:579`, and user deletion cleans up dependents transactionally in `store/db/*/user_delete.go`).

So there is no time to report: the premise (a scheduled nightly DB-cleanup cron job) doesn't match the repository.
