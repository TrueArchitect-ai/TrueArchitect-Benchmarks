**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-neutral `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation maps its user data into.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the one concrete protocol implementation that ships. Its `IdentityProvider` wraps a `storepb.OAuth2Config`, exchanges the authorization code for a token (`ExchangeToken`, with PKCE support), fetches user info, and maps it to the shared `idp.IdentityProviderUserInfo` type.

Both are consumed by the SSO sign-in flow in `server/router/api/v1/auth_service_sso.go:12-13`.
