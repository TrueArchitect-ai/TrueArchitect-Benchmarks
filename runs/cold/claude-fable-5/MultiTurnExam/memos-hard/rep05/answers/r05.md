**Premise correction: this project has no GraphQL API.** There is no GraphQL schema, resolver, or library anywhere in the repository (no hits for "graphql" in Go code, `go.mod`, or config).

**Actual API surface:** The public API is **gRPC-based, defined in Protocol Buffers**:

- Schema definitions live in `proto/api/v1/*.proto` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto` — with generated Go code under `proto/gen/` (managed via buf: `proto/buf.yaml`, `proto/buf.gen.yaml`).
- The services are exposed over HTTP through two stacks registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`, wired at `server/server.go:88`): a **gRPC-Gateway** REST/JSON transcoding layer and **Connect RPC** handlers (the buf config generates `connectrpc/go` bindings alongside grpc-go).
- Non-RPC HTTP surfaces are separate Echo routes: raw file serving (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), and the frontend/static router (`server/router/frontend/`).
