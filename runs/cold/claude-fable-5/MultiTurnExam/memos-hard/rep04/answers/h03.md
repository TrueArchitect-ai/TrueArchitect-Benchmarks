**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider abstraction — the shared `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any concrete provider returns for an authenticated user.
- `internal/idp/oauth2/oauth2.go` is the only concrete protocol implementation shipped: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and returning `idp.IdentityProviderUserInfo`.

The SSO login flow consumes these in `server/router/api/v1/auth_service_sso.go`.
