**Premise correction: there is no GraphQL API in this repository** — a repo-wide search for "graphql" finds nothing (no schema files, no resolver code, no GraphQL dependency).

Actual API surface: the public API is **gRPC-based, defined in Protocol Buffers**, and exposed over HTTP two ways:

- **Schema definitions:** `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Generated Go code lives in `proto/gen/api/v1/`.
- **Transports:** both are wired in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`):
  - a **gRPC-Gateway** REST/JSON mapping (`grpc-ecosystem/grpc-gateway`, the `*.pb.gw.go` files), registered with auth middleware around `v1.go:69-97`;
  - **Connect RPC** handlers for browser clients (`connectrpc.com/connect`, generated under `proto/gen/api/v1/apiv1connect`), registered at `v1.go:131-141` via `NewConnectServiceHandler` (`server/router/api/v1/connect_services.go`).

Additional non-GraphQL HTTP surfaces: the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), and the frontend/static router (`server/router/frontend/`).
