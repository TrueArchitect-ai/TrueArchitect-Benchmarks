**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- The abstraction lives in `internal/idp` (`internal/idp/idp.go`), which defines the provider-agnostic `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation returns.
- The one concrete protocol implementation that ships is OAuth 2.0, in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`). Its `IdentityProvider` type wraps a `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and performs the token exchange and user-info fetch, mapping the result into `idp.IdentityProviderUserInfo`. It's consumed by the SSO auth flow in `server/router/api/v1/auth_service_sso.go`.
