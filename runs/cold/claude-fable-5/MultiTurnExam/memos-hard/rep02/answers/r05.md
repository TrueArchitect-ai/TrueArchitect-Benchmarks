**Premise correction: there is no GraphQL API in this repository — no GraphQL schema, resolvers, or dependencies exist** (a repo-wide search for "graphql" finds nothing outside `node_modules`).

Actual API surface: the public API is **gRPC-based, defined in Protocol Buffers** and exposed over HTTP in two ways:

- **Schema definitions:** `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated Go code in `proto/gen/` (managed via `buf`, see `proto/buf.gen.yaml`).
- **Serving:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`) wires the handlers into Echo two ways: a **gRPC-Gateway** that translates RESTful JSON/HTTP requests to the gRPC services, and **ConnectRPC** handlers for browser clients (`server/router/api/v1/v1.go:131-139`, replacing grpc-web). An OpenAPI description is also embedded (`proto/openapi_embed.go`).
- Non-RPC HTTP surfaces are limited to the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), and the frontend/static routes (`server/router/frontend/`).
