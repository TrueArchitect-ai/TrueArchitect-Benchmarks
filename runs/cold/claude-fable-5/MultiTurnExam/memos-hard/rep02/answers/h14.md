**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual extraction to the markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`) — a single goldmark AST walk over the memo content that fills `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation):**

- **Memo creation** — `CreateMemo` calls `memopayload.RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`. This also covers comment creation, since `CreateMemoComment` delegates to `CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
- **Content update** — `UpdateMemo` recomputes it when the `content` field is in the update mask, at `server/router/api/v1/memo_service.go:447`.
- **Bulk rebuild** — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) can rebuild payloads for all memos in batches, though this runner is not currently constructed/wired in production code.

**Extracted properties** (stored in `storepb.MemoPayload`, see `proto/gen/store/memo.pb.go:85`):

- `Tags` — deduplicated hashtags from tag nodes (case-preserving dedup)
- `Property.Title` — text of the first H1 heading when it's the document's first block
- `Property.HasLink` — presence of any link node
- `Property.HasCode` — presence of code blocks, fenced code blocks, or code spans
- `Property.HasTaskList` — presence of task checkboxes
- `Property.HasIncompleteTasks` — any unchecked checkbox

(`ExtractAll` also collects `Mentions`, lowercased and deduplicated, but those drive mention notifications rather than being persisted into the memo payload by `RebuildMemoPayload`.)
