**Premise correction: there is no GraphQL API in this repository — no schema files (`.graphql`), no GraphQL libraries, and no GraphQL endpoint exist anywhere in the source.**

**Actual API surface:** the public API is **gRPC/Connect RPC defined with Protocol Buffers**, plus a few plain-HTTP routes:

- **Schema definitions:** Protobuf service definitions live in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Generated code is under `proto/gen/` (including `proto/gen/api/v1/apiv1connect/` for Connect handlers and `*.pb.gw.go` grpc-gateway REST bindings).
- **Serving layer:** the Connect RPC handlers wrapping the API implementation are in `server/router/api/v1/connect_services.go` (delegating to `APIV1Service` in `server/router/api/v1/`), wired into the Echo HTTP server in `server/server.go`.
- **Other HTTP surfaces:** a file server for attachments/avatars (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/`), and the frontend router (`server/router/frontend/`).

So the closest analog to "where the schema is defined" is the protobuf files in `proto/api/v1/` — not a GraphQL schema.
