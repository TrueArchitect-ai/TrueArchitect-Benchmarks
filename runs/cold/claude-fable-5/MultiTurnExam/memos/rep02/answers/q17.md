**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

This module contains the memo queries and CRUD mutations (`useMemos`, `useInfiniteMemos`, `useMemo`, `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemoComments`, etc.) built on TanStack Query. They all call `memoServiceClient`, the ConnectRPC client created in `web/src/connect.ts` for the generated `MemoService` definition (`web/src/types/proto/api/v1/memo_service_pb`).
