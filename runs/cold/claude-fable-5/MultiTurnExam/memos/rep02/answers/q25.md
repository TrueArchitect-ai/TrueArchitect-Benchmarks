**Engine: CEL (Common Expression Language, via `github.com/google/cel-go`) — `internal/filter/`** (parser/compiler in `internal/filter/engine.go` and `internal/filter/parser.go`, schema in `internal/filter/schema.go`).

**Mechanism:** The engine compiles the CEL filter expression into a dialect-agnostic condition tree/IR (`internal/filter/ir.go`), and each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`) calls `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)`, which runs the renderer in `internal/filter/render.go` to emit dialect-specific parameterized SQL — switching on `DialectSQLite` / `DialectMySQL` / `DialectPostgres` for placeholder style and function differences — that is appended to the query's WHERE clause and args.
