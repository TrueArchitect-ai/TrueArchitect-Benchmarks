- **Interceptor:** web/src/connect.ts — it defines the auth `Interceptor` for the ConnectRPC transport, attaching a Bearer access token to requests (token state managed via `web/src/auth-state.ts`) and handling refresh: it proactively refreshes near-expiry tokens and reactively refreshes on 401 using a dedicated `refreshTransport`/`refreshAuthClient` (no interceptors, to avoid recursion) with a dedup manager for concurrent refreshes.

- **Token kinds:** short-lived JWT **access tokens** (~15 min, sent as `Authorization: Bearer`), **refresh tokens** (validated against the database, used to mint new access tokens via the `RefreshToken` RPC), and long-lived **Personal Access Tokens (PATs)** for programmatic access.

- **Backend package:** server/auth (`server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`; token parsing in `server/auth/token.go`).
