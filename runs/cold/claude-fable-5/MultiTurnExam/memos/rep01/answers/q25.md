**Engine:** CEL (Common Expression Language), parsed with `cel-go` — the filter engine lives in **internal/filter/** (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`).

**Mechanism:** The engine runs a three-phase pipeline — the CEL expression is parsed and validated against a memo-specific schema (`internal/filter/schema.go`, `parser.go`), normalized into a dialect-agnostic IR (`internal/filter/ir.go`), and then rendered by `internal/filter/render.go` into a SQL WHERE fragment plus placeholder args tailored per dialect (`DialectSQLite`, `DialectMySQL`, `DialectPostgres` — handling differences like JSON access, placeholders, and LIKE vs ILIKE); each dialect driver invokes this via `filter.AppendConditions` in its `ListMemos`, e.g. `store/db/sqlite/memo.go:57-61`.
