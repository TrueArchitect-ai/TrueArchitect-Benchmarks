**Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`) — the filter engine lives in **`internal/filter/`** (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`).

**Mechanism:** The engine compiles the CEL filter string into a dialect-agnostic condition tree/IR (`internal/filter/engine.go`, `parser.go`, `ir.go`), and each database driver then renders that tree into parameterized SQL for its dialect by calling `filter.AppendConditions` with a dialect name — e.g. `filter.DialectSQLite` in `store/db/sqlite/memo.go:61` — where the renderer in `internal/filter/render.go` emits dialect-specific WHERE clauses and placeholder args appended to the memo list query.
