**memo_relation**

The `memo_relation` table stores links between one memo and another, with columns `memo_id`, `related_memo_id`, and `type`. It's defined in the schema for all three dialects, e.g. `store/migration/sqlite/LATEST.sql:46`, `store/migration/postgres/LATEST.sql:46`, and `store/migration/mysql/LATEST.sql:46` (originally introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`). The corresponding Go store code is `store/memo_relation.go`.
