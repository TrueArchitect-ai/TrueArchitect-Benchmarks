**Mechanism:** The compiled frontend build is embedded into the Go binary with `//go:embed dist/*` (Go `embed.FS`) and served by the Echo web server via static-file middleware plus an SPA fallback that returns `index.html` for extension-less routes.

**File:** `server/router/frontend/frontend.go` — the embed directive is at lines 20–21 (`//go:embed dist/*` over `server/router/frontend/dist/`), and `FrontendService.Serve` (line 41) wires it up using `middleware.StaticWithConfig` over the embedded filesystem plus `spaFallbackMiddleware`, skipping `/api`, `/file`, and Connect RPC paths, and setting cache headers (immutable for hashed `/assets/`, no-cache for HTML).
