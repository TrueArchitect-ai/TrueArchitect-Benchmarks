**store/migration/sqlite/LATEST.sql**

For a fresh SQLite install, the complete current schema comes from `store/migration/sqlite/LATEST.sql` — the same file I read earlier when locating the `memo_relation` table. Each dialect has its own `LATEST.sql` under `store/migration/<dialect>/`, applied by the migrator in `store/migrator.go` on a fresh database instead of replaying incremental version migrations.
