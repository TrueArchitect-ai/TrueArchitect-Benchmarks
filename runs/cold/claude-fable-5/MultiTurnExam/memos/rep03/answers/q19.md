MemoService is served over:

- **REST (gRPC-Gateway HTTP/JSON) — `server/router/api/v1/v1.go`**: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` at line 108 registers the service on a grpc-gateway `runtime.ServeMux`, which is mounted on the Echo server at `/api/v1/*` (using the `google.api.http` annotations from the proto, e.g. `POST /api/v1/memos`).

- **Connect (ConnectRPC) — `server/router/api/v1/connect_handler.go`**: `apiv1connect.NewMemoServiceHandler(s, opts...)` at line 40, registered via `RegisterConnectHandlers` on an `http.ServeMux`. The `ConnectServiceHandler` wrapper (with its per-RPC adapters in `server/router/api/v1/connect_services.go`) adapts the same `APIV1Service` implementation to Connect's request/response wrapper types — this is the protocol the web frontend uses via `@connectrpc/connect-web`.
