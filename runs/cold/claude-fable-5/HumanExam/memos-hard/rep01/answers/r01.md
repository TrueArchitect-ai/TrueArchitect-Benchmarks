— False premise: there is no Redis anywhere (`grep -ri redis` over all Go code, `go.mod`, `go.sum` returns zero hits). The cache is a hand-rolled in-process, `sync.Map`-based in-memory cache with TTL (`store/cache/cache.go:66`). User entries live in a dedicated `userCache` built at `store/store.go:51-53` with `DefaultTTL: 10 * time.Minute` (`store/store.go:41-45`; package default identical at `store/cache/cache.go:59`); `store/user.go` uses plain `Set`, so users get the 10-minute default TTL.
