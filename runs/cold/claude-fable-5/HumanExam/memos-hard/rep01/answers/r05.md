— False premise: there is no GraphQL schema anywhere (`grep -ril graphql` across the whole repo, including `go.mod` and `web/`, returns zero hits). The actual public API surface is Protobuf-defined RPC (`proto/api/v1/*.proto`) exposed two ways: gRPC-Gateway REST transcoding (`runtime.NewServeMux` and handler registrations at `server/router/api/v1/v1.go:96-120`) and Connect RPC handlers (`server/router/api/v1/v1.go:141`, `connect_services.go`), plus an SSE streaming endpoint (`server/router/api/v1/sse_handler.go`).
