The domain-model structs in the `store` package are what the SQL drivers (`store/db/sqlite`, `store/db/postgres`, `store/db/mysql`) read from and write to for these tables:

- `user`: `User` — `store/user.go` (defined at line 29; queried by e.g. the drivers under `store/db/`)
- `attachment`: `Attachment` — `store/attachment.go` (line 16)
- `reaction`: `Reaction` — `store/reaction.go` (line 7)

Note there are also identically named protobuf-generated API types (`proto/gen/api/v1/user_service.pb.go`, `attachment_service.pb.go`, `memo_service.pb.go`), but those are API messages, not the database-table mappings.
