`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` instead of running incremental migrations. This is confirmed in `store/migrator.go:27` ("Check if DB is initialized. If not, apply LATEST.sql") and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"), with the SQLite variant located at `store/migration/sqlite/LATEST.sql`.
