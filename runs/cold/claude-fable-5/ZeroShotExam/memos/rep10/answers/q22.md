When a memo is created, the `CreateMemo` handler (`server/router/api/v1/memo_service.go:157`) calls `DispatchMemoCreatedWebhook`, defined in `server/router/api/v1/memo_service_webhooks.go`. That function looks up the creator's webhooks via `s.Store.GetUserWebhooks` and, for each hook, enqueues the payload with `webhook.PostAsync` (a bounded async queue drained by worker goroutines that call `Post`).

The HTTP delivery is performed by the in-repo package `internal/webhook` (`internal/webhook/webhook.go`), which POSTs the JSON payload using an SSRF-guarded `http.Client`.

Requests are signed using the Standard Webhooks scheme: an HMAC-SHA256 over `msgID.timestamp.body` with a `whsec_`-prefixed base64 secret, sent as the `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 mac>` headers (`internal/webhook/webhook.go:133-150`).
