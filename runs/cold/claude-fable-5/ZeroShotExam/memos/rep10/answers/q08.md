**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` ("It contains all methods that store database driver should implement"). All three database backends implement it: SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql/mysql.go`), and PostgreSQL (`store/db/postgres/postgres.go`) — each backend's `NewDB` constructor returns a `store.Driver`.
