`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) SQLite database, the migrator applies this single file containing the full current schema instead of running incremental migrations. This is documented in `store/migrator.go` (see the comments at lines 27 and 42: "Check if DB is initialized. If not, apply LATEST.sql" and "LATEST.sql: Full schema for new installations (faster than incremental migrations)", with `LatestSchemaFileName = "LATEST.sql"` at line 56). The versioned directories alongside it (`store/migration/sqlite/0.2` … `0.30`) hold incremental migrations used only when upgrading an existing database.
