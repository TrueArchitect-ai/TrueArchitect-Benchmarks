**Driver — store/driver.go**

The `Driver` interface is defined in `/bench/repo/store/driver.go` (line 10). Its doc comment says it "contains all methods that store database driver should implement" — methods like `GetDB()`, `IsInitialized`, and CRUD operations for each model (attachments, memos, etc.). The three database backends that implement it live in `/bench/repo/store/db/sqlite`, `/bench/repo/store/db/mysql`, and `/bench/repo/store/db/postgres`, selected via `/bench/repo/store/db/db.go`.
