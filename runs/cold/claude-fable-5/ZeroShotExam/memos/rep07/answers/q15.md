The domain structs in the `store` package are the Go representations of these tables (the raw SQL in `store/db/*` reads/writes those tables into these structs):

- `user`: `User` — `store/user.go` (line 29)
- `attachment`: `Attachment` — `store/attachment.go` (line 16)
- `reaction`: `Reaction` — `store/reaction.go` (line 7)

There's no ORM/`TableName()` mapping; the link is via hand-written SQL in the driver files, e.g. `store/db/sqlite/user.go` (`INSERT INTO user ...`), `store/db/sqlite/reaction.go` (`FROM reaction`), and `store/db/sqlite/user_delete.go` (`FROM attachment`).
