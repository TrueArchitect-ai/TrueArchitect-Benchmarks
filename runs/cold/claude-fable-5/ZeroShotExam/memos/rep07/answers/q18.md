The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with an entry file that defines its `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

**NewDBDriver — store/db/db.go**

The factory function `NewDBDriver` switches on `profile.Driver` (`"sqlite"`, `"mysql"`, or `"postgres"`) and calls the matching package's `NewDB` to select the driver at startup (`store/db/db.go:14`).
