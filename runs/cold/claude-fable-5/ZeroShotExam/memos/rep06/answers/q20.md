**Server-Sent Events (SSE); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment (plus SetMemoAttachments and SetMemoRelations via the shared update helper).**

Details:

- **Mechanism:** Server-Sent Events. The HTTP endpoint is registered by `RegisterSSERoutes` in `server/router/api/v1/sse_handler.go`, with event serialization helpers in `server/router/api/v1/sse_event_helpers.go`. The server wires it up in `server/router/api/v1/v1.go:125` and closes the hub on shutdown in `server/server.go:205-206`.
- **Hub:** `SSEHub` in `server/router/api/v1/sse_hub.go` — manages client connections via `Subscribe`/`Unsubscribe` and pushes events to all connected clients through `Broadcast` (line 115).
- **Memo handlers that broadcast:**
  - `CreateMemo` — `server/router/api/v1/memo_service.go:163`
  - `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
  - `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (broadcasts a refresh for the parent memo)
  - `UpdateMemo`, `SetMemoAttachments`, and `SetMemoRelations` broadcast indirectly through `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go:71` (called from `memo_service.go:513`, `memo_attachment_service.go:48`, and `memo_relation_service.go:48`)

Additionally, the reaction handlers `UpsertMemoReaction` and `DeleteMemoReaction` (`server/router/api/v1/reaction_service.go:106,161`) broadcast memo-refresh events, since reactions belong to memos.
