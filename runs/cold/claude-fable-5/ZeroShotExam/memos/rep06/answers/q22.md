When `CreateMemo` in `server/router/api/v1/memo_service.go` (line 157) finishes creating a memo, it calls `DispatchMemoCreatedWebhook`, defined in `server/router/api/v1/memo_service_webhooks.go`. That function looks up the creator's webhooks via `s.Store.GetUserWebhooks` and enqueues one payload per hook with `webhook.PostAsync` (activity type `memos.memo.created`), which a pool of background workers drains by calling `webhook.Post`.

- **Dispatcher** — `DispatchMemoCreatedWebhook` (delegating to `dispatchMemoRelatedWebhook`) in `server/router/api/v1/memo_service_webhooks.go`
- **Delivery package** — `internal/webhook` (`github.com/usememos/memos/internal/webhook`, `webhook.go`), which POSTs the JSON payload using an SSRF-guarded shared HTTP client
- **Signing mechanism** — Standard Webhooks-style HMAC-SHA256: the secret (optionally `whsec_`-base64-encoded) keys an HMAC over `msgID.timestamp.body`, and the base64 signature is sent in the `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<sig>` headers (`internal/webhook/webhook.go:133-150`)
