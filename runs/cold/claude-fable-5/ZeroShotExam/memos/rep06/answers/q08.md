**Driver — store/driver.go**

The `Driver` interface is defined in `/bench/repo/store/driver.go` (line 10) in the `store` package, documented as containing "all methods that store database driver should implement" (e.g. `CreateAttachment`, `IsInitialized`, `GetDatabaseSize`). All three backends — SQLite, MySQL, and Postgres, under `/bench/repo/store/db/` — implement it, and `NewDBDriver` in `/bench/repo/store/db/db.go` returns a `store.Driver` for the configured backend.
