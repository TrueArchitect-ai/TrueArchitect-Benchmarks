**`memo_relation`**

This table stores links between one memo and another related memo, with columns `memo_id`, `related_memo_id`, and `type` (unique together). It's defined in the schema files `store/migration/sqlite/LATEST.sql`, `store/migration/postgres/LATEST.sql`, and `store/migration/mysql/LATEST.sql` (originally added in `store/migration/sqlite/0.13/00__memo_relation.sql`), with the corresponding store code in `store/memo_relation.go` and per-driver implementations like `store/db/sqlite/memo_relation.go`.
