**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` and contains all the methods a database driver must implement (attachment, memo, user CRUD, etc.). All three backends — SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql/mysql.go`), and PostgreSQL (`store/db/postgres/postgres.go`) — implement it, and `store/db/db.go`'s `NewDBDriver` returns the appropriate `store.Driver` based on the configured database type.
