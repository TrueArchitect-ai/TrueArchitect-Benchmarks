**Premise correction:** this repository has no per-user API rate-limiting middleware, so there is nothing registered anywhere and no request limits to report.

What is actually registered as HTTP middleware is in `server/server.go` (lines 51–52): only `middleware.Recover()` and a custom CORS middleware (`newCORSMiddleware`, defined in `server/cors.go`). The API layer in `server/router/api/v1/v1.go` additionally wires an authentication middleware (`gatewayAuthMiddleware`) into the gRPC-Gateway and a Connect interceptor — but none of these throttle requests.

The only rate-limiting references in the repo are non-operative: a suggestion in `internal/email/README.md` ("Implement Rate Limiting", showing an example `rate.NewLimiter(rate.Every(time.Second), 10)` for email sending) and a TODO-style note in `internal/email/doc.go:86` ("Rate limit email sending to prevent abuse"). These are documentation recommendations about email sending, not implemented API middleware.
