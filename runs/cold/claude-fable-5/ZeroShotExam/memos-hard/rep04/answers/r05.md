**Premise correction:** This repository has no GraphQL schema — there is no GraphQL anywhere in the codebase (no `.graphql`/`.gql` files, no GraphQL references in code or config).

**Actual API surface:** The public API is defined as **gRPC services in Protocol Buffers**, located in `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, etc.). These service definitions use `google.api.http` annotations, so the same protos also drive a RESTful HTTP/JSON API via grpc-gateway — the generated gateway code lives in `proto/gen/api/v1/` (e.g. `*.pb.gw.go`), and a generated OpenAPI spec is at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`). Code generation is managed with buf (`proto/buf.yaml`, `proto/buf.gen.yaml`), and the API is wired into the server under `server/router/api/`. There are also internal storage-layer protos in `proto/store/`, which are not part of the public API.
