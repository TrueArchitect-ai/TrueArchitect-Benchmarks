**The interface.** `internal/markdown/markdown.go:31-55` defines `markdown.Service` (ExtractAll, ExtractTags, ExtractProperties, RenderMarkdown, RenderHTML, GenerateSnippet, ValidateContent, RenameTag).

**The only concrete implementation.** The unexported `service` struct at `internal/markdown/markdown.go:57-60`, which wraps a `goldmark.Markdown` instance. There is no other implementation (no mocks or alternates in non-test code). It's configured with GFM plus the repo's custom Tag/Mention goldmark extensions (`internal/markdown/extensions/`), and delegates markdown re-rendering to `renderer.NewMarkdownRenderer()` (`internal/markdown/renderer/markdown_renderer.go`).

**Construction.** The single runtime construction site is `NewAPIV1Service` in `server/router/api/v1/v1.go:48-51`:

```go
markdownService := markdown.NewService(
    markdown.WithTagExtension(),
    markdown.WithMentionExtension(),
)
```

`markdown.NewService` (`internal/markdown/markdown.go:85-113`) is the factory that returns the `*service`. (A second construction exists only in tests: `server/router/api/v1/test/test_helper.go:44`.)

**Holders of the interface.**
