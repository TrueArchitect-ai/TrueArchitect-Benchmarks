The premise is incorrect: there is no nightly database-cleanup job scheduled in this repository. 

What actually exists:

- The repo contains a cron scheduler library at `internal/scheduler/` (`scheduler.go`, `job.go`, `parser.go`), but no code outside that package imports it — grepping for `internal/scheduler` imports across the codebase turns up nothing. It's an unused/standalone library, not wired into the server.
- The "cleanup" jobs you may have seen are only documentation examples, not real registrations:
  - `internal/scheduler/doc.go:15` — a `"daily-cleanup"` example job
  - `internal/scheduler/example_test.go:97-99` — an example `"cleanup"` job with schedule `"0 2 * * *"` (2 AM nightly), inside `Example_multipleJobs`
  - `internal/scheduler/README.md:34,241` — `"daily-cleanup"` and `"stale-session-cleanup"` examples
- The actual background work the server runs uses plain tickers, not the cron scheduler: `server/server.go:162-169` starts the `s3presign` runner (`server/runner/s3presign/runner.go`, every 12 hours via `runnerInterval = time.Hour * 12`), and there's a `memopayload` runner in `server/runner/memopayload/`. Neither is a database-cleanup job.

So if you're thinking of the "2 AM" cleanup, that's only illustrative example code in the scheduler package's tests/docs — no database-cleanup job is actually scheduled anywhere in the application.
