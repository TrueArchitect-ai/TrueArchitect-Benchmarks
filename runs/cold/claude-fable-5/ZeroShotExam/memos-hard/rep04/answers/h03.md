`internal/idp`; `internal/idp/oauth2`

The abstraction lives in the `internal/idp` package: `/bench/repo/internal/idp/idp.go` defines the shared `IdentityProviderUserInfo` type that any provider returns after authenticating a user. The one concrete protocol implementation that ships is OAuth2, in `/bench/repo/internal/idp/oauth2/oauth2.go` (package `oauth2`, whose doc comment reads "implements the OAuth2 identity provider integration"). It builds an `IdentityProvider` from a `storepb.OAuth2Config` and is used by the SSO flow in `server/router/api/v1/auth_service_sso.go`.
