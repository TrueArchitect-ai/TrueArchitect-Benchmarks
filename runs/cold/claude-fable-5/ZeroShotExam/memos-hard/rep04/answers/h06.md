The user-configured URLs are memo webhooks; every dispatch path funnels through one delivery function.

h06.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120` (the actual outbound HTTP happens at `safeClient.Do(req)`, line 152). Every webhook path reaches it: the dispatch helpers call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; four worker goroutines started in `init()` drain that queue and call `Post` for each payload. So `Post` is the single point where all webhook delivery converges before the request goes out to the user-configured URL (stored via `CreateUserWebhook`/`UpdateUserWebhook`).

**RPC handler methods that transitively reach it** (all in `server/router/api/v1/`, all `APIV1Service` gRPC/Connect handlers):

1. `CreateMemo` — `memo_service.go:157` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync`
2. `UpdateMemo` — `memo_service.go:513` → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync`
3. `DeleteMemo` — `memo_service.go:562` → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync`
4. `CreateMemoComment` — `memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:30`) → `PostAsync`
5. `SetMemoRelations` — `memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → … → `PostAsync`
6. `SetMemoAttachments` — `memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → … → `PostAsync`

The two low-level dispatchers that actually build the payload and call `PostAsync` are `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook`, both in `server/router/api/v1/memo_service_webhooks.go`.

**Answer:** handlers — `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoRelations`, `SetMemoAttachments` (≥3); convergence function — `Post` — `internal/webhook/webhook.go:120`.
