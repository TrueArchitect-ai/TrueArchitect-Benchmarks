**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package, where the persistent entities are defined (`store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/idp.go`, `store/reaction.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/user_identity.go`, `store/user_setting.go`, `store/instance_setting.go`). Counting distinct Go packages outside `store/` (i.e., excluding the `store/db/*` drivers and `store/test`, which are still part of the data layer) that reference each entity type by name (`store.<Type>`):

- **`store.User` — 7 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages**: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

The remaining types trail well behind: `Attachment` (4), `Inbox`/`MemoShare`/`MemoRelation` (3 each), and the rest at 1–2. If you exclude the test package `server/router/api/v1/test`, the counts are User 6 vs. Memo 5 — the ranking is unchanged.
