**Handlers (RPC methods) that can transitively cause an outbound HTTP request to a user-configured URL:**

All of these are gRPC handlers in `server/router/api/v1/` that dispatch to **user-configured webhook URLs** (the URL comes from `store.GetUserWebhooks` → `hook.Url`, which users register):

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` → calls `DispatchMemoCreatedWebhook` at line 157.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` → `dispatchMemoUpdatedSideEffects` (memo_service.go:513) → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`).
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`.

Each `Dispatch…Webhook` helper (in `server/router/api/v1/memo_service_webhooks.go`) builds a payload, sets `payload.URL = hook.Url`, and calls `webhook.PostAsync`, which enqueues onto `asyncPostQueue`. The queue workers drain it into the actual delivery function.

**Convergence function — `Post` at `internal/webhook/webhook.go:120`** (`func Post(requestPayload *WebhookRequestPayload) error`). This is the single point where every handler path converges to build and send the HTTP `POST` (`safeClient.Do(req)` at internal/webhook/webhook.go:150) to the user-configured URL. (`PostAsync`, internal/webhook/webhook.go:184, is the shared enqueue point feeding `Post` via the worker pool.)
