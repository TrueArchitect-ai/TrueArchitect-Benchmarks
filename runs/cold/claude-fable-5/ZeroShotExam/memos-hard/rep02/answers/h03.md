The provider abstraction lives in `internal/idp` (package `idp`), which defines the shared types for identity providers — e.g. `IdentityProviderUserInfo` in `internal/idp/idp.go`. The one concrete protocol implementation that ships is OAuth 2.0, in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type wraps an `OAuth2Config` and implements the OAuth2 flow used by the API layer (`server/router/api/v1`).

Answer: `internal/idp`; `internal/idp/oauth2`
