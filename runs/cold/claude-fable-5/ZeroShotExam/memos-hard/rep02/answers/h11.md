**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package (`store/*.go`), which defines the persistent entity structs `Memo`, `User`, `Attachment`, `Inbox`, `IdentityProvider`, `InstanceSetting`, `MemoRelation`, `UserIdentity`, `UserSetting`, `Reaction`, and `MemoShare` (e.g. `store/user.go`, `store/memo.go`). Counting distinct Go packages outside that layer (excluding `store/db/{sqlite,mysql,postgres}` and `store/test`, which are part of it, and excluding string-only matches in the generated `proto/gen/store` protobuf files):

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

For comparison, the next closest is `store.Attachment` at 4 packages (`server/router/api/v1`, its test package, `server/router/fileserver`, `server/router/rss`). The ranking holds even if test packages are excluded (User 6, Memo 5).
