The premise is incorrect: there is no nightly database-cleanup job scheduled in this repository. The cron scheduler package exists at `internal/scheduler/`, but nothing in the application actually uses it — no Go file outside `internal/scheduler/` imports the package, and no runner registers a cleanup job (the only background runners are `server/runner/memopayload` and `server/runner/s3presign`, neither of which is a database-cleanup cron job).

The likely source of the confusion is the package's own documentation, which uses a hypothetical cleanup job as an *example*: both `internal/scheduler/doc.go:15-16` and `internal/scheduler/README.md:34-35` show a sample job named `"daily-cleanup"` with schedule `"0 2 * * *"` (2 AM daily). That is illustrative example code only, not a real scheduled job in the application. The only real periodic cleanup in the codebase is the in-memory cache cleanup loop that runs every 5 minutes (`store/cache/cache.go:60`), which is not a cron job and not database cleanup.
