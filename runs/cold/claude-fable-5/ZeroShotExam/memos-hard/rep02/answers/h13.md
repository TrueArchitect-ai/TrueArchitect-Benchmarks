**impl — construction — holders**

**Impl:** The interface is `markdown.Service`, defined in `internal/markdown/markdown.go:31`. There is exactly one concrete implementation: the unexported `service` struct (`internal/markdown/markdown.go:58`), which wraps a `goldmark.Markdown` instance configured with GFM plus the repo's custom Tag/Mention extensions (`internal/markdown/extensions/`). Note the interface is for server-side metadata extraction and RSS rendering — HTML rendering for the UI happens separately in the frontend (react-markdown/remark in `web/src/components/MemoContent/`), as the interface's doc comment states.

**Construction:** The single runtime construction site is `NewAPIV1Service` in `server/router/api/v1/v1.go:48`, which calls `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())`. `NewService` (`internal/markdown/markdown.go:85`) is the factory that returns the `*service`. (A second call site exists only in tests: `server/router/api/v1/test/test_helper.go:44`.)

**Holders:**
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — the primary owner; used throughout the memo service (e.g., `server/router/api/v1/memo_service.go`, `memo_service_webhooks.go`).
- `RSSService.MarkdownService` (`server/router/rss/rss.go:45`) — receives the *same* instance, passed along in `server/server.go:85` via `rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`; used for `RenderHTML` in RSS feeds.
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) declares a field of the interface type, but `memopayload.NewRunner` is never called in production code — at runtime the package's free function `RebuildMemoPayload` is instead handed the interface as a parameter from `APIV1Service` (`server/router/api/v1/memo_service.go:108` and `:447`).

So at runtime a single `*markdown.service` instance, built once by `NewAPIV1Service`, is shared by the API v1 service and the RSS service (and passed by parameter into `memopayload.RebuildMemoPayload`).
