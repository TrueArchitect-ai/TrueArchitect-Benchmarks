**Premise correction:** This repository has no GraphQL API — there is no GraphQL schema anywhere in it (a repo-wide search for "graphql" returns zero hits).

**Actual API surface:** The public API is defined as Protocol Buffers and exposed as gRPC plus a grpc-gateway REST API (the README describes it as "full REST and gRPC APIs"):

- **API definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`
- **Generated code:** `proto/gen/api/v1/` — gRPC stubs (`*_grpc.pb.go`) and grpc-gateway REST handlers (`*.pb.gw.go`), built with Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`)
- **REST/OpenAPI spec:** `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- Internal (non-public) storage-layer messages live separately under `proto/store/`

So if you're looking for the schema of the public API, the closest equivalent to a GraphQL schema here is the set of `.proto` files under `proto/api/v1/`.
