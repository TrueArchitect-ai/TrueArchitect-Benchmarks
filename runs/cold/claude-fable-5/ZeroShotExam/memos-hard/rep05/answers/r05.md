**Premise correction:** This repository has no GraphQL schema — there is no GraphQL API at all. A repo-wide search turns up zero `.graphql`/`.gql` files and no GraphQL references in the code (the only hits for "gateway" are gRPC-Gateway, not a GraphQL gateway).

**Actual API surface:** This is Memos (usememos), and its public API is **gRPC with a REST/JSON gateway**, defined in Protocol Buffers rather than GraphQL:

- **Schema definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto`. Internal storage messages live separately under `proto/store/`.
- **Generated code:** `proto/gen/` (via Buf, configured in `proto/buf.gen.yaml` and `proto/buf.yaml`).
- **REST exposure:** the gRPC services are exposed as HTTP/JSON through grpc-gateway, wired up in `server/router/api/v1/v1.go`; an OpenAPI description is generated at `proto/gen/openapi.yaml` and embedded via `proto/openapi_embed.go`.
- Additional non-gRPC surfaces: an RSS router (`server/router/rss/`) and an MCP router (`server/router/mcp/`).

The README (`README.md`) confirms this: the project advertises "full REST and gRPC APIs for integration" — GraphQL is not part of the picture.
