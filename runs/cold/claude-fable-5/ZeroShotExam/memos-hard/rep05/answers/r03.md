The premise doesn't hold: there is no nightly database-cleanup job registered with the cron scheduler in this repository.

The cron scheduler (`internal/scheduler/`) exists as a standalone library, but nothing in the application actually uses it — grepping for imports of `internal/scheduler` outside the package itself finds no callers. The closest thing to what the question describes is a **documentation example**: `internal/scheduler/README.md:33-40` (and similarly `internal/scheduler/doc.go:15`) shows a sample job named `"daily-cleanup"` with schedule `"0 2 * * *"` (2 AM daily), but it's illustrative Quick Start code that just prints a message — it isn't a real database-cleanup job and isn't wired into the server.

The actual background jobs in the server don't use this scheduler at all: `server/runner/s3presign/runner.go:26-36` runs on a plain 12-hour `time.Ticker`, and `server/runner/memopayload/runner.go` is a run-once rebuild — neither is a database cleanup.

So if you've seen "2 AM" mentioned, that's the README example's schedule, not a configured job.
