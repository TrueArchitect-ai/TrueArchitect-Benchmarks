The abstraction lives in `internal/idp`, and the only concrete protocol implementation shipped is OAuth2 in `internal/idp/oauth2`.

- **Abstraction package:** `internal/idp` (Go package `idp`, i.e. `github.com/usememos/memos/internal/idp`) — `internal/idp/idp.go` defines the provider-neutral `IdentityProviderUserInfo` type that any provider returns.
- **Implementation package:** `internal/idp/oauth2` (Go package `oauth2`) — `internal/idp/oauth2/oauth2.go` states "Package oauth2 implements the OAuth2 identity provider integration," providing `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and user-info retrieval driven by `storepb.OAuth2Config`.
