**Premise correction:** This repository has no GraphQL schema — there are no `.graphql`/`.gql` files and no GraphQL references anywhere in the codebase. The question's premise is incorrect.

**Actual API surface:** The public API is a gRPC/Protobuf API with an HTTP/REST gateway, not GraphQL:

- **Schema definitions:** Protocol Buffer files in `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, etc.), plus internal storage messages in `proto/store/`.
- **Code generation:** Configured via `proto/buf.gen.yaml` using buf, which generates Connect RPC (`connectrpc/go`) and grpc-gateway bindings into `proto/gen/`.
- **REST/OpenAPI:** A generated OpenAPI spec at `proto/gen/openapi.yaml` is embedded into the binary via `proto/openapi_embed.go`, so the same services are exposed as RESTful HTTP endpoints through grpc-gateway.
- **Server wiring:** The API is served from `server/router/api/v1/`, alongside other routers (`mcp`, `rss`, `frontend`, `fileserver`) under `server/router/`.
