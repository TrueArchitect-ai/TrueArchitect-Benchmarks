The provider abstraction lives in `internal/idp` (package `idp`), which defines the shared identity-provider types — see `/bench/repo/internal/idp/idp.go` with `IdentityProviderUserInfo` (the normalized user info returned by any provider). The shipped concrete protocol implementation is `internal/idp/oauth2` (package `oauth2`), whose `/bench/repo/internal/idp/oauth2/oauth2.go` declares "Package oauth2 implements the OAuth2 identity provider integration," providing `NewIdentityProvider`, token exchange (including PKCE), and user-info fetching that maps into the `idp` types. The SSO login flow wires this up in `server/router/api/v1/auth_service_sso.go`.

Answer: `internal/idp`; `internal/idp/oauth2`
