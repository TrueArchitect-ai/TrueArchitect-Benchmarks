**impl** — The interface is `markdown.Service` (`internal/markdown/markdown.go:31-55`). The only concrete implementation is the unexported `service` struct in the same file (`internal/markdown/markdown.go:58-60`), which wraps a `goldmark.Markdown` instance (goldmark v1.8.2, `go.mod`). There are no test fakes or alternative implementations anywhere in the repo — tests use the real service too. (The `MarkdownRenderer` struct in `internal/markdown/renderer/markdown_renderer.go` is an internal AST→markdown helper, not a `Service` implementation.)

**construction** — There is no DI container; wiring is manual constructor injection. The single production construction site is `NewAPIV1Service` at `server/router/api/v1/v1.go:48-51`, which calls `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())`. That happens when `server/server.go:76` creates the API v1 service, and the **same instance** is then reused for RSS at `server/server.go:85` via `rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)` — so one shared goldmark-backed instance serves the whole runtime.

**holders** — Three components hold a field typed as the interface `markdown.Service`:
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — used for `ExtractAll` (mention handling, `memo_mention_helpers.go:32`), `GenerateSnippet` (webhooks, `memo_service_webhooks.go:85`), and passed to `memopayload.RebuildMemoPayload` on memo create/update (`memo_service.go:108`, `:447`).
- `RSSService.MarkdownService` (`server/router/rss/rss.go:45`, injected via `NewRSSService` at `rss.go:58`) — used for `RenderHTML` on feed item descriptions (`rss.go:339`).
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`, param at `runner.go:19`) — though `NewRunner` has no callers, so at runtime only the free function `RebuildMemoPayload(ctx, memo, markdownService markdown.Service)` (`runner.go:74`) actually receives the interface, as a parameter from `APIV1Service`.

The frontend renders markdown separately with `react-markdown` (`web/src/components/MemoContent/MemoMarkdownRenderer.tsx`) and does not go through this interface.
