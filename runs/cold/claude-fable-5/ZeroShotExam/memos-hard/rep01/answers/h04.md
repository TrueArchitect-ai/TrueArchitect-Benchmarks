- The driver-selection factory is `NewDBDriver` in `store/db/db.go` (lines 18–27), which calls `mysql.NewDB(profile)` at `store/db/db.go:22`. A repo-wide grep shows `store/db/db.go` is the **only** file that imports `github.com/usememos/memos/store/db/mysql`, so no other package ever calls `mysql.NewDB` or names the `mysql.DB` type.
- However, within the mysql package itself, the test `store/db/mysql/auth_config_test.go:12` constructs the driver struct directly with a zero-value literal: `db := &DB{}`, bypassing `NewDB`, to unit-test `IsRetryableAuthenticationMutationError` against `MySQLError` codes (1213, 1205, 1062).
- The only other struct-literal construction is `driver := DB{profile: profile}` at `store/db/mysql/mysql.go:29`, which is inside `NewDB` itself — i.e., part of the constructor the factory invokes, not an independent construction site.

So in production code the MySQL driver is constructed exclusively via the factory path (`db.NewDBDriver` → `mysql.NewDB`); the single direct construction outside that path is the in-package test `store/db/mysql/auth_config_test.go:12`.
