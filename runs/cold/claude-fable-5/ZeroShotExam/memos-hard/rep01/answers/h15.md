Memo visibility is checked independently at several server surfaces, not just in the main memo API:

1. **API v1 gRPC/Connect memo service (read path)** — `server/router/api/v1/memo_service.go` (the visibility check in the get path around lines 55–67: non-public requires auth, private requires creator; list endpoints add `VisibilityList`/CEL filters around lines 222–225). The same per-memo check is repeated for sibling API services: `server/router/api/v1/reaction_service.go` (lines 38, 83), `server/router/api/v1/attachment_service.go` (line 451), `server/router/api/v1/memo_attachment_service.go` (line 222), `server/router/api/v1/memo_service_comments.go` (line 41), `server/router/api/v1/memo_relation_service.go` (line 111), `server/router/api/v1/user_service_stats.go` (lines 87–90, 220).

2. **File server (attachment/blob downloads)** — `server/router/fileserver/fileserver.go` (~lines 666–703): before serving an attachment it loads the owning memo and enforces visibility (public + anonymous-allowed passes; otherwise requires a valid share token or an authenticated user, and private memos require creator or admin at line 699).

3. **RSS/feed router** — `server/router/rss/rss.go` (lines 90 and 141): feed queries are hard-restricted to `VisibilityList: []store.Visibility{store.Public}`.

4. **Frontend router (sitemap.xml)** — `server/router/frontend/frontend.go` (~lines 149–153): only `store.Public` memos are listed in the generated sitemap.

5. **SSE event delivery** — `server/router/api/v1/sse_hub.go` (`canReceive`, lines 134–144, fed by `server/router/api/v1/sse_event_helpers.go`): server-side filtering so private-memo events are delivered only to the creator or an admin.

6. **Email notification dispatcher** — `server/notification/email.go` (`canViewerAccessMemo`, ~lines 306–320): before emailing memo content/links, it re-checks that the recipient may view the memo (private → creator/admin only, protected → any authenticated user). Related in-app notification gating also exists in `server/router/api/v1/user_service_notifications.go` (lines 309–312) and `server/router/api/v1/memo_mention_helpers.go` (lines 62–84).
