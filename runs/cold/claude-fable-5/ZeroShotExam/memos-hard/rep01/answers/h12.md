**Concrete method:** `(*DB).CreateMemo` in the SQLite driver — `store/db/sqlite/memo.go:16`. This is the code that builds and executes the ``INSERT INTO memo (`uid`, `creator_id`, `content`, `visibility`, `payload`, ...)`` statement when a memo is saved under a default installation.

**Determination method:** There are three interchangeable candidates — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, and `store/db/postgres/memo.go` all define `CreateMemo` satisfying the `store.Driver` interface. Which one runs is decided at startup in `store/db/db.go` (`NewDBDriver`), which switches on `profile.Driver`. That value comes from the `--driver` flag / `MEMOS_DRIVER` config read in `cmd/memos/main.go:43`, whose default is `"sqlite"` — set both via `viper.SetDefault("driver", "sqlite")` at `cmd/memos/main.go:122` and as the flag default at `cmd/memos/main.go:130`. So with no database flags, `NewDBDriver` takes the `case "sqlite"` branch, and the `store.Store` created in `cmd/memos/main.go:64` dispatches `CreateMemo` calls to the SQLite driver's implementation.
