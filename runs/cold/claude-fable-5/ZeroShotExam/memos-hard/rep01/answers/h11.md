The data layer in this repo is the `store` package (`store/*.go`), whose persistent entity structs are `User` (store/user.go), `Memo` (store/memo.go), `Attachment` (store/attachment.go), `Inbox` (store/inbox.go), `MemoRelation`, `MemoShare`, `Reaction`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`, and `UserSetting`.

Counting distinct Go packages outside the `store/` tree (i.e., excluding the `store/db/*` drivers and `store/test`) that reference each type as `store.<Type>`:

**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

- `User` is referenced from `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, and `server/router/rss`.
- `Memo` is referenced from `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, and `server/runner/memopayload`.

The next closest is `Attachment` at ~4 packages; the ranking holds even if you exclude the test package (`server/router/api/v1/test`), which would make it User ~6 vs. Memo ~5.
