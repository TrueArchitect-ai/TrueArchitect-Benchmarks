**Premise correction:** This repository (usememos/memos) has no GraphQL API at all — a repo-wide search finds no GraphQL schema files (`.graphql`/`.gql`) or any mention of GraphQL in the code.

**Actual API surface:** The public API is defined as Protocol Buffers and served over gRPC / Connect RPC with a REST gateway:

- **Schema definitions:** `proto/api/v1/*.proto` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/instance_service.proto`, etc.
- **Code generation config:** `proto/buf.gen.yaml` (buf generates Go protobuf, gRPC, Connect RPC, grpc-gateway, and OpenAPI outputs into `proto/gen/`)
- **REST/OpenAPI spec:** generated at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)
- **Server implementation:** the API handlers live under `server/router/api/v1/`, wired up in `server/server.go`

So instead of a GraphQL schema, the source of truth for the public API is the protobuf files in `proto/api/v1/`.
