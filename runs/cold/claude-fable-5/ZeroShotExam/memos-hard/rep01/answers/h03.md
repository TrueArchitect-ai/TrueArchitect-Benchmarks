The `internal/idp` package defines the identity-provider abstraction, and `internal/idp/oauth2` is the concrete protocol implementation that ships.

- **Abstraction**: `internal/idp` (`/bench/repo/internal/idp/idp.go`) — package `idp` defines the shared `IdentityProviderUserInfo` type that provider implementations return.
- **Implementation**: `internal/idp/oauth2` (`/bench/repo/internal/idp/oauth2/oauth2.go`) — package `oauth2` implements the OAuth 2.0 identity provider integration (its `IdentityProvider` type wraps a `storepb.OAuth2Config` and returns `idp.IdentityProviderUserInfo`). It is the only concrete protocol under `internal/idp`.

Answer: `internal/idp`; `internal/idp/oauth2`
