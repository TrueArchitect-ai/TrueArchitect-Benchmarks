delivery function — `Post` in `internal/webhook/webhook.go` (the outbound HTTP POST executes at `internal/webhook/webhook.go:120`, called asynchronously via `PostAsync` and a worker-goroutine queue in the same file; memo events are dispatched into it from `server/router/api/v1/memo_service_webhooks.go`)

protection mechanism — dial-time SSRF blocking in `internal/webhook/webhook.go` plus the reserved-IP list in `internal/webhook/validate.go`. The shared `safeClient` uses `safeDialContext` (`internal/webhook/webhook.go:59`), which resolves the target host at connection time and refuses any address matching `isReservedIP`. The reserved ranges (loopback, RFC-1918 private, link-local/cloud IMDS, and IPv6 equivalents) are defined in `reservedCIDRs` in `internal/webhook/validate.go:14`. Because the check happens in the dialer rather than only at URL-save time, it also defeats DNS-rebinding attacks; `ValidateURL` in `internal/webhook/validate.go:62` additionally rejects private-resolving URLs up front when a webhook is configured. An escape hatch, `AllowPrivateIPs` (`internal/webhook/validate.go:41`), lets self-hosted deployments disable the restriction deliberately.
