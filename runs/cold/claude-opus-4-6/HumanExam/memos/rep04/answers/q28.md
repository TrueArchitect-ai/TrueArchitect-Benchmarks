`s3presign.Runner` — runs every 12 hours via `time.Ticker`, re-signs expiring S3 presigned URLs (`server/runner/s3presign/runner.go`)

The `internal/scheduler` package (a full cron-based scheduler) is present in the codebase but is NOT used by the server — no code in `server/` imports or references it. The `memopayload.Runner` exists in `server/runner/memopayload/` but is also NOT started as a background runner; its `RebuildMemoPayload` function is called inline during memo create/update, not on a schedule.
