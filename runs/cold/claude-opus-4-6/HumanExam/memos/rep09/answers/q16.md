Before deleting the memo row, the store layer deletes:
1. **Memo relations** (where memo is source or target) via `DeleteMemoRelation` (`store/memo.go:142-147`)
2. **Attachments** linked to the memo via `DeleteAttachment` (`store/memo.go:149-155`)

At the API handler level, **comment memos** (child memos linked via `MemoRelationComment`) are also recursively deleted first (`server/router/api/v1/memo_service.go:567-577`).
