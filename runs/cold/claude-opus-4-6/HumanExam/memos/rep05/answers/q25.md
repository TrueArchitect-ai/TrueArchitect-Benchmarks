Engine: CEL (Common Expression Language) via `google/cel-go`, in `internal/filter/engine.go`. The engine compiles CEL expressions into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), then `internal/filter/render.go` renders the tree into SQL for each dialect (SQLite, PostgreSQL, MySQL), handling placeholder style, JSON operators, case-insensitive matching, regex, and timestamp functions per dialect.
