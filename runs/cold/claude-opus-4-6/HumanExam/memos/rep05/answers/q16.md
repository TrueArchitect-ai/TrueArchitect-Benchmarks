Before the memo row itself, the store layer deletes:
1. `memo_relation` records where this memo is the source (MemoID)
2. `memo_relation` records where this memo is the target (RelatedMemoID)
3. `attachment` records linked to the memo (plus physical storage files)

At the API layer, comment memos (via COMMENT relation) are also recursively deleted before the parent memo, each triggering the same cascade.
