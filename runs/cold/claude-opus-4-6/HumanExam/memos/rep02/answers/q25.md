Engine: CEL (Common Expression Language) via `github.com/google/cel-go/cel`; engine lives at `internal/filter/engine.go` (`Engine` struct).
Mechanism: The CEL filter string is compiled into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then rendered into SQL WHERE clause fragments by a dialect-aware renderer (`internal/filter/render.go`). Each store driver calls `filter.AppendConditions()` with its dialect name (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`) to get dialect-specific SQL with proper placeholders, JSON extraction, and text-matching syntax.
