CEL (Common Expression Language) via `cel-go`; engine at `internal/filter/` (main files: `engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`). The filter string is compiled to a CEL AST, walked into a dialect-agnostic IR condition tree, then rendered to dialect-specific SQL by `render.go`. Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with its dialect constant (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`), and the renderer produces the appropriate SQL (different placeholders, JSON operators, regex syntax, timestamp functions, etc.).
