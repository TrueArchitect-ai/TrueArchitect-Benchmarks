Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`

`internal/idp/idp.go` defines `IdentityProviderUserInfo` — the shared return type for all identity providers. The only concrete protocol implementation is OAuth2, in `internal/idp/oauth2/oauth2.go`, which provides `ExchangeToken()` and `UserInfo()` methods.
