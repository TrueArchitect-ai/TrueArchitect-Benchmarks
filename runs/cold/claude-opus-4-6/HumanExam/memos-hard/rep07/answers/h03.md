Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`

The `internal/idp` package (`internal/idp/idp.go`) defines the `IdentityProviderUserInfo` struct — the common result type all providers must produce. The sole concrete protocol implementation is **OAuth2**, in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements `ExchangeToken` and `UserInfo` methods.
