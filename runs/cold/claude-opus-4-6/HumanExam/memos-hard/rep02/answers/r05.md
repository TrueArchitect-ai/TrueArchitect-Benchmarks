False premise. There is no GraphQL schema. The public API is gRPC + ConnectRPC (HTTP), defined via Protocol Buffers in `proto/api/v1/`. The generated Go stubs are in `proto/gen/api/v1/`. The server uses ConnectRPC (`connectrpc.com/connect`) to serve HTTP-accessible APIs, as seen in `server/router/api/v1/connect_services.go`.
