Engine: CEL (Common Expression Language) via the `cel-go` library, implemented in `internal/filter/engine.go` (the `Engine` struct wraps a `cel.Env`). The filter package lives at `internal/filter/` with supporting files `parser.go`, `ir.go`, `render.go`, `helpers.go`, and `schema.go`.

Mechanism: Each dialect driver (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` from `internal/filter/helpers.go`, passing a dialect identifier (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`); the engine compiles the CEL filter expression into a dialect-agnostic condition tree (IR), then `internal/filter/render.go` renders that tree into dialect-specific SQL WHERE clauses with parameterized arguments.
