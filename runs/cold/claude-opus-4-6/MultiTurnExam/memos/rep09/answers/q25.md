Engine: **CEL (Common Expression Language)** via the `google/cel-go` library, implemented in `internal/filter/engine.go` (the `Engine` struct wraps a `cel.Env`).

The filter string is parsed and compiled by the CEL engine into a dialect-agnostic condition tree (`internal/filter/ir.go`), which is then rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions()` passing its dialect constant (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`), which compiles the CEL expression into an IR condition tree and renders it into the appropriate SQL WHERE clause with dialect-specific placeholder syntax (e.g., `?` for SQLite/MySQL, `$N` for PostgreSQL).
