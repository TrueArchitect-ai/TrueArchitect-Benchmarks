`DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go` (which delegates to `dispatchMemoRelatedWebhook` in the same file, calling `webhook.PostAsync`)

Delivery package: `internal/webhook` (`internal/webhook/webhook.go`) — performs the HTTP POST via `Post()`/`PostAsync()`

Signing mechanism: **HMAC-SHA256** following the Standard Webhooks convention — the payload is signed with `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)`, and the signature is sent as `webhook-signature: v1,<base64>` along with `webhook-id` and `webhook-timestamp` headers. The signing key supports the `whsec_<base64>` format (Standard Webhooks spec) or a raw secret string.
