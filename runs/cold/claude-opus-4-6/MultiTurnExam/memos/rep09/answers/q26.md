The following tables are affected when `DeleteMemo` runs:

1. **memo_relation** — explicitly deleted in `store/memo.go` (lines 142–146) for both `memo_id` and `related_memo_id` sides
2. **attachment** — explicitly deleted in `store/memo.go` (lines 149–156) for attachments linked to the memo
3. **memo** — the memo row itself is deleted (line 158), plus at the API handler level (`server/router/api/v1/memo_service.go`, lines 567–577), comment memos are recursively deleted via `Store.DeleteMemo`, which triggers their own `memo_relation`, `attachment`, and `memo` deletions

So in total: `memo_relation`, `attachment`, `memo`.
