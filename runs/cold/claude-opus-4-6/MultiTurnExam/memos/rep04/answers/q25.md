Engine: CEL (Common Expression Language) via `github.com/google/cel-go` — `internal/filter/engine.go`

The CEL engine parses the filter string into an AST, which is then compiled into a dialect-specific SQL WHERE clause by the renderer in `internal/filter/render.go`, using per-dialect SQL generation (SQLite, PostgreSQL, MySQL) driven by field schemas with dialect-specific column expressions defined in `internal/filter/schema.go`. Each database driver (e.g., `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` from `internal/filter/helpers.go`, passing its dialect constant, to convert the filter strings into SQL conditions and bind arguments that are appended to the query's WHERE clause.
