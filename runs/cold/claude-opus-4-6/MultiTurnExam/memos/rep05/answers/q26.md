The following tables are affected when DeleteMemo runs:

- **memo_relation** — explicitly deleted by `Store.DeleteMemo` (both as source and target) in `store/memo.go`
- **attachment** — explicitly deleted by `Store.DeleteMemo` via `Store.DeleteAttachment` in `store/memo.go`
- **memo** — the memo row itself (and comment memos, recursively via the API handler in `server/router/api/v1/memo_service.go`)
- **memo_share** — deleted via `ON DELETE CASCADE` foreign key on `memo_id` referencing `memo(id)`, defined in `store/migration/sqlite/LATEST.sql`
