When a memo is deleted, the store layer (`store/memo.go:140–158`) deletes these records before the memo row itself:

1. **Memo relations** — deletes all `memo_relation` rows where the memo is the source (`MemoID`) or the target (`RelatedMemoID`)
2. **Attachments** — deletes all `attachment` rows linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (memos related via `MemoRelationComment`) are deleted before the parent memo — and each of those comment deletions also triggers the same store-layer cleanup of its own relations and attachments.
