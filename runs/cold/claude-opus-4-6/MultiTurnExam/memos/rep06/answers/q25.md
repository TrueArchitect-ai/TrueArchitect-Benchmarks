**Engine:** CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`

The CEL engine (`internal/filter/`) parses the filter string into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) translates that condition tree into SQL with dialect-specific placeholder styles and expressions based on a `DialectName` (`DialectSQLite`, `DialectMySQL`, `DialectPostgres` defined in `internal/filter/schema.go`). Each database driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with its dialect, which compiles the CEL filter, renders it to a SQL WHERE clause with the appropriate dialect, and appends the clause and arguments to the query — e.g., the SQLite driver passes `filter.DialectSQLite` at `store/db/sqlite/memo.go:61`.
