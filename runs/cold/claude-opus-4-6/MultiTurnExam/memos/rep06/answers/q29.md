**Interceptor path:** `web/src/connect.ts` (the `authInterceptor` defined at line 156)

**Token kinds:** The interceptor manages two token types:
- **Access tokens** (short-lived JWTs, sent as `Bearer` in the `Authorization` header, stored in localStorage via `web/src/auth-state.ts`)
- **Refresh tokens** (sent as HTTP-only cookies, used to obtain new access tokens via `AuthService.RefreshToken`)

The backend also supports **Personal Access Tokens (PATs)** as an alternative Bearer credential.

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and PATs (`AuthenticateByPAT`).
