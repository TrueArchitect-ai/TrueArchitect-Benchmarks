Delivery package: `internal/webhook` (`internal/webhook/webhook.go`) — performs the HTTP POST via `webhook.PostAsync` / `webhook.Post`

Signing mechanism: **HMAC-SHA256** following the Standard Webhooks convention — the payload is signed using `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, with the signature sent as a `webhook-signature: v1,<base64>` header alongside `webhook-id` and `webhook-timestamp` headers. Signing secrets use the `whsec_<base64>` format.
