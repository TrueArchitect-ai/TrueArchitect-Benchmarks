The following tables are affected when DeleteMemo runs:

- **memo_relation** — explicitly deleted by `Store.DeleteMemo` (both as source and target, `store/memo.go:142-146`)
- **attachment** — explicitly deleted by `Store.DeleteMemo` (`store/memo.go:149-156`)
- **memo** — the memo row itself is deleted last (`store/memo.go:158`)

Additionally, at the API handler level (`server/router/api/v1/memo_service.go:567-577`), comment memos are deleted first via recursive `Store.DeleteMemo` calls, which in turn cascade through the same cleanup for each comment (their `memo_relation`, `attachment`, and `memo` rows).

So the full list of directly affected tables: **memo**, **memo_relation**, **attachment**.
