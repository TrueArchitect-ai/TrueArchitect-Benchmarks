Engine: CEL (Common Expression Language) via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

The `Engine` parses CEL filter expressions into a dialect-agnostic AST/IR (`internal/filter/ir.go`), then `AppendConditions` (`internal/filter/helpers.go`) renders that IR into dialect-specific SQL WHERE clauses using `internal/filter/render.go`, which switches on the dialect (SQLite, Postgres, MySQL) to emit the correct SQL syntax and parameter placeholders. Each database driver calls `filter.AppendConditions` with its own dialect constant (e.g., `filter.DialectSQLite` in `store/db/sqlite/memo.go:61`).
