When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`), via `DeleteMemoRelation`
2. **Attachments** — `attachment` records linked to the memo, via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo itself, and each of those deletions triggers the same store-level cleanup of relations and attachments.
