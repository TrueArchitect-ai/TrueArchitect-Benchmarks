CEL (Common Expression Language) engine — `internal/filter/engine.go` (uses `github.com/google/cel-go/cel`); the parser in `internal/filter/parser.go` compiles CEL filter strings into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), then each dialect driver (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with its dialect name (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`), which renders the condition tree into dialect-specific SQL WHERE clauses with parameterized placeholders via the renderer in `internal/filter/render.go`.
