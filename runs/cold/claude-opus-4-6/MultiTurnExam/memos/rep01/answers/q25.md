CEL (Common Expression Language) engine — `internal/filter/engine.go` (uses `github.com/google/cel-go/cel`); the parser in `internal/filter/parser.go` compiles CEL filter expressions into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), which the renderer in `internal/filter/render.go` then translates into SQL fragments for each dialect (`DialectSQLite`, `DialectMySQL`, `DialectPostgres` defined in `internal/filter/schema.go`), with per-field dialect-specific SQL expressions configured in the schema. Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect name to append the generated SQL WHERE clauses and args (e.g., `store/db/postgres/memo.go:58`).
