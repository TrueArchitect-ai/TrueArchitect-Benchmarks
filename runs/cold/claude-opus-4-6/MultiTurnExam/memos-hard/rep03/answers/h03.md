**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` struct that every provider must produce.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete implementation, providing an OAuth2 identity provider with `ExchangeToken` and `UserInfo` methods. It is the only protocol implementation that ships; the protobuf enum in `proto/store/idp.proto` lists only `OAUTH2`, and the type-switch dispatch in `server/router/api/v1/auth_service_sso.go` handles only that branch.
