The premise is incorrect — there is no GraphQL schema or endpoint in this codebase. The public API is defined using **gRPC with Protocol Buffers**, with a REST/JSON gateway layer.

The protobuf service definitions live in `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.). Generated Go code is output to `proto/gen/api/v1/`. The gRPC services are exposed over HTTP via **gRPC-Gateway**, registered in `server/router/api/v1/v1.go`. There is also an **OpenAPI spec** generated from the proto definitions at `proto/gen/apidocs.swagger.yaml`, which is additionally consumed by the MCP server layer in `server/router/mcp/`.
