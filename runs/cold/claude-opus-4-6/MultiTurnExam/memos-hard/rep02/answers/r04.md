The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), declared in `internal/webhook/webhook.go`. The channel has a capacity of 128 (line ~38) and is drained by 4 goroutines started in an `init()` function (lines ~42–55) that each call `Post()` for every payload received. `PostAsync` simply sends the payload into this channel. There is no external queue infrastructure involved.
