The premise is incorrect — there is no GraphQL schema or API. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, served via **Connect** (gRPC-compatible HTTP). The `.proto` service definitions are in `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `idp_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The API is additionally exposed through a **gRPC-Gateway** REST layer, registered alongside Connect handlers in `server/router/api/v1/v1.go`.
