The premise is incorrect — there is no nightly database-cleanup cron job. While a generic `Scheduler` package exists at `internal/scheduler/scheduler.go` with cron-expression support, it is never instantiated or used anywhere in the server or application startup code. No jobs are registered with it in production. The only background runners are the S3 presign runner (12-hour ticker, `server/runner/s3presign/`) and the memo payload runner (`server/runner/memopayload/`), neither of which performs database cleanup.
