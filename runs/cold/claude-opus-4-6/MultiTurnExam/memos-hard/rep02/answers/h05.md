**Mechanism: explicit Go code**, executed within a database transaction during user deletion.

Each database driver has a `deleteReactionsByCreatorTx` function that runs `DELETE FROM reaction WHERE creator_id = ?` inside the user-deletion transaction:

- `store/db/sqlite/user_delete.go:400–401` (called at line 102)
- `store/db/postgres/user_delete.go:400–401` (called at line 102)
- `store/db/mysql/user_delete.go:437–438` (called at line 102)

There is no database-level `ON CASCADE DELETE` rule handling this — the cleanup is done explicitly in Go within the same transaction that deletes the user.
