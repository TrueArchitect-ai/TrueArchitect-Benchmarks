The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a Go `sync.Map`-based structure in `store/cache/cache.go`. There is no external cache service involved.

The user cache is configured in `store/store.go:40–44` with a **`DefaultTTL` of 10 minutes**, a cleanup interval of 5 minutes, and a max of 1000 items. All three caches (user, user setting, instance setting) share the same `cache.Config`.
