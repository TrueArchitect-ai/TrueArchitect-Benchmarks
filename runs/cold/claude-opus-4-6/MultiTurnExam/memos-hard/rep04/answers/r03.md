The question's premise is incorrect — there is no nightly database-cleanup job in this codebase. The `internal/scheduler` package defines a generic cron scheduler (`internal/scheduler/scheduler.go`), but it is never instantiated or used by the server or any command. No jobs are registered with it, and no database cleanup task exists. The only scheduled background runners are the S3 presign runner (every 12 hours) and in-memory cache cleanup (every 5 minutes) — neither is a database cleanup job, and neither uses the cron scheduler.
