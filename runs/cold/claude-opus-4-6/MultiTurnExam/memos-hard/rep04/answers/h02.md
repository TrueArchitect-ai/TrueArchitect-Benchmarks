**Delivery function** — `Post` (with async dispatch via `PostAsync`) — `internal/webhook/webhook.go:120`

**Protection mechanism** — `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`

The `Post` function (`internal/webhook/webhook.go:120`) performs the outbound HTTP POST using `safeClient.Do(req)` (line 152). Async callers use `PostAsync` (line 184), which enqueues payloads into a buffered channel drained by 4 goroutines that each call `Post`.

SSRF protection is two-layered:

1. **At registration time**: `ValidateURL` (`internal/webhook/validate.go:62`) resolves the hostname and rejects any IP in a reserved/private CIDR range.
2. **At connection time** (defeats DNS rebinding): `safeDialContext` (`internal/webhook/webhook.go:59`) is wired as the custom `DialContext` on the HTTP transport. It re-resolves the hostname at dial time and checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), which blocks loopback, RFC-1918, link-local/cloud IMDS, and IPv6 private ranges defined in `reservedCIDRs` (`internal/webhook/validate.go:14`).
