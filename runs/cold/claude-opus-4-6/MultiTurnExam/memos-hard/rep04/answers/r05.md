The question's premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC services, exposed via both gRPC (Connect) and REST (gRPC-Gateway). The proto definitions live under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The services are registered in `server/router/api/v1/v1.go` using both a gRPC-Gateway mux and Connect handlers, mounted onto the Echo HTTP server in `server/server.go`.
