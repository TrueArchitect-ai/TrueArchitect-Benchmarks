**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which delegates to `markdownService.ExtractAll` — `internal/markdown/markdown.go:356`. This performs a single AST walk over the memo's markdown content.

**Extracted properties** (stored into `memo.Payload`):
- **`Tags`** (`[]string`) — all `#tag` nodes found in the content (`markdown.go:376–377`)
- **`Property.Title`** (`string`) — text of the first block-level H1 heading, if present (`markdown.go:384–388`)
- **`Property.HasLink`** (`bool`) — whether the content contains any links (`markdown.go:393–394`)
- **`Property.HasCode`** (`bool`) — whether it contains code blocks or code spans (`markdown.go:396–397`)
- **`Property.HasTaskList`** (`bool`) — whether it contains task checkboxes (`markdown.go:399–400`)
- **`Property.HasIncompleteTasks`** (`bool`) — whether any task checkbox is unchecked (`markdown.go:401–404`)

Additionally, `Mentions` (`[]string`) are extracted (`markdown.go:379–380`) during the same walk but are used separately for @mention processing rather than stored in the payload.
