**Abstraction package**: `internal/idp` — defines `IdentityProviderUserInfo` (`internal/idp/idp.go`), the common return type all provider implementations must produce.

**Implementation package**: `internal/idp/oauth2` — the sole concrete implementation (`internal/idp/oauth2/oauth2.go`), providing an OAuth2 identity provider with `ExchangeToken` and `UserInfo` methods that produce the shared `idp.IdentityProviderUserInfo`.

The protobuf enum in `proto/store/idp.proto` confirms only one type beyond the zero value: `OAUTH2 = 1`, and the `IdentityProviderConfig` message's `oneof` has a single `oauth2_config` variant.
