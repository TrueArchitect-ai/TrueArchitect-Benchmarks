The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and REST (via gRPC-Gateway).

The API surface is defined in proto files under `proto/api/v1/`, including:
- `proto/api/v1/memo_service.proto` — memo CRUD
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/auth_service.proto` — authentication
- `proto/api/v1/attachment_service.proto` — attachments
- `proto/api/v1/idp_service.proto` — identity providers
- `proto/api/v1/inbox_service.proto` — inbox

These are implemented as gRPC services with HTTP/REST bindings (via `google.api.http` annotations), served by the `APIV1Service` in `server/router/api/v1/v1.go`.
