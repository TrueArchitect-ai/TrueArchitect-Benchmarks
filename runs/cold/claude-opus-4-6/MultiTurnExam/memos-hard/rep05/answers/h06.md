The RPC handlers that can transitively cause an outbound HTTP request to a user-configured webhook URL are:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects`, which calls `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go:67`)
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`

All four paths converge on **`webhook.Post`** at `internal/webhook/webhook.go:120`. The `Dispatch*` methods in `memo_service_webhooks.go` each call `webhook.PostAsync` (which enqueues to a channel drained by goroutines that call `Post`), so `Post` is the single function where all paths converge before the actual outbound HTTP delivery.

Handlers: `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`; convergence function — `Post` at `internal/webhook/webhook.go:120`
