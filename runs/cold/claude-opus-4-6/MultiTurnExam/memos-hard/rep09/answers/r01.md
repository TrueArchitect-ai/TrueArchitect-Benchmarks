The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed cache in `store/cache/cache.go`. It is constructed with `cache.New(config)` (line 76) using a `Config` struct, not an external store like Redis.

User entries use the **default configuration** (`DefaultConfig()` at `store/cache/cache.go:57`), which sets a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`, line 59). The user cache is instantiated in `store/store.go` via `cache.NewDefault()`, which calls `DefaultConfig()`. Expired entries are cleaned up by a background goroutine running every 5 minutes (`CleanupInterval: 5 * time.Minute`, line 60), and the cache holds at most 1000 items.
