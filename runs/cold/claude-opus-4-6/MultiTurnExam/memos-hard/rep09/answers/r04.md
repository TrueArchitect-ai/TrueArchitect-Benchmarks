The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). Webhook delivery uses a plain Go buffered channel, not an external queue.

In `internal/webhook/webhook.go`, the `init()` function (line 42) creates a buffered channel `asyncPostQueue` with capacity 128 and spawns 4 goroutines that drain it by calling `Post()` for each payload. The `PostAsync` function (line 184) simply sends the `WebhookRequestPayload` into this in-process channel. There is no external message broker, no queue declaration, and no broker connection anywhere in the codebase.
