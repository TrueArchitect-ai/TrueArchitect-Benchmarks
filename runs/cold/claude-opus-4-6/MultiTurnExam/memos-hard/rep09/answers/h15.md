Memo visibility is enforced across many server surfaces. Here are the distinct enforcement sites:

**gRPC memo API — per-memo gates:**
1. `checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39` (central gate, called from `GetMemo` and `ListMemoComments`)
2. `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:33` (blocks commenting on PRIVATE memos)

**gRPC memo API — query-level filtering:**
3. `ListMemos` — `server/router/api/v1/memo_service.go:218` (restricts query by visibility based on auth state)
4. `ListMemoComments` — `server/router/api/v1/memo_service_comments.go:157` (filters comment memos by visibility)

**Related-entity APIs — per-memo gates:**
5. `ListMemoReactions` — `server/router/api/v1/reaction_service.go:29`
6. `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:82`
7. `ListMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:213`
8. `checkAttachmentAccess` — `server/router/api/v1/attachment_service.go:436` (for `GetAttachment`)

**Related-entity APIs — query-level filtering:**
9. `batchConvertMemoRelations` — `server/router/api/v1/memo_service_converter.go:183`
10. `ListMemoRelations` — `server/router/api/v1/memo_relation_service.go:108`

**User stats — query-level filtering:**
11. `ListAllUserStats` — `server/router/api/v1/user_service_stats.go:83`
12. `GetUserStats` — `server/router/api/v1/user_service_stats.go:217`

**RSS feeds:**
13. `GetExploreRSS` — `server/router/rss/rss.go:90` (PUBLIC only)
14. `GetUserRSS` — `server/router/rss/rss.go:141` (PUBLIC only)

**File server:**
15. `checkAttachmentPermission` — `server/router/fileserver/fileserver.go:674` (enforces memo visibility for served files, including share-token bypass)

**SSE live updates:**
16. `canReceive` — `server/router/api/v1/sse_hub.go:135` (PRIVATE events only delivered to creator/admin)

**Notification filtering:**
17. `canViewerAccessMemo` — `server/router/api/v1/user_service_notifications.go:302` (filters notification payloads)
18. `canUserAccessMentionContext` — `server/router/api/v1/memo_mention_helpers.go:56` (gates mention notifications)
