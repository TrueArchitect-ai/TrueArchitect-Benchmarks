The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is built on **gRPC with Protocol Buffers**, with an HTTP/JSON gateway layer auto-generated via grpc-gateway.

- **Protobuf service definitions** are in `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc.)
- **Generated Go gRPC stubs and gateway code** are in `proto/gen/api/v1/` (e.g., `*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`)
- **gRPC service handlers** are implemented in `server/router/api/v1/`
- Additionally, an **HTTP REST-style layer** is provided via Echo routes in `server/router/fileserver/` and `server/router/rss/`
