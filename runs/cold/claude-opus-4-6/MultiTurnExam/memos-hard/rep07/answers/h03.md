**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that all providers must produce.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol implementation that ships. It provides `ExchangeToken` (authorization-code-for-token exchange, with PKCE support) and `UserInfo` (fetches user info from the provider and maps it to `idp.IdentityProviderUserInfo` via configurable field mappings). The protobuf enum in `proto/gen/store/idp.pb.go` confirms OAuth2 is the sole defined type.
