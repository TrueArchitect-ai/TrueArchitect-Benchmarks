The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (for REST/HTTP transcoding).

The proto service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), and generated Go code is in `proto/gen/api/v1/`. The gRPC services are registered in `server/router/api/v1/v1.go`, and the gRPC-Gateway HTTP handlers are registered via `RegisterGateway` in the same file. Additionally, a **Connect** (connect-go) protocol layer is wired up in `server/router/api/v1/connect_services.go`, providing another HTTP-based RPC surface from the same proto definitions.
