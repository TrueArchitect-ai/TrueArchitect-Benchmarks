The premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map` with TTL-based expiration in `store/cache/cache.go`.

User entries use the default cache configuration (`cache.DefaultConfig()` at `store/cache/cache.go:57-64`), which sets a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`). The `Store` creates its `userCache` via `cache.NewDefault()` at `store/store.go`, which calls `DefaultConfig()`. There is no external cache server (Redis, Memcached, or otherwise) involved.
