The premise is incorrect — there is no GraphQL schema in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, served via both a gRPC-Gateway (REST) and Connect handlers. The proto service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `idp_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The gateway and Connect handlers are registered in `server/router/api/v1/v1.go`.
