**Abstraction package:** `internal/idp` — defines the shared `IdentityProviderUserInfo` struct that all providers must produce (`internal/idp/idp.go`).

**Implementation package:** `internal/idp/oauth2` — the only concrete protocol implementation that ships, providing OAuth2 token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`).

The protobuf type system in `proto/store/idp.proto` reinforces this: the `IdentityProvider.Type` enum has only `OAUTH2 = 1`, and the `IdentityProviderConfig` oneof contains only `OAuth2Config`.
