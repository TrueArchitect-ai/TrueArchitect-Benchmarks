**Protection mechanism** — `safeDialContext` — `internal/webhook/webhook.go:59`
This is a custom `DialContext` wired into the `safeClient`'s HTTP transport. At connection time it resolves the target hostname and checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), which tests against a list of reserved CIDRs (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, IPv6 ULA and link-local) defined at `internal/webhook/validate.go:14-23`. This dial-time check defeats DNS rebinding attacks. A complementary registration-time check, `ValidateURL` (`internal/webhook/validate.go:62`), performs the same reserved-IP validation when a webhook is first created or updated.
