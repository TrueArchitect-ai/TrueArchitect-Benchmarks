The premise is incorrect — there is no GraphQL schema in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed as both gRPC and REST (via gRPC-Gateway). The API service definitions live in `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server registers these services in `server/router/api/v1/v1.go`.
