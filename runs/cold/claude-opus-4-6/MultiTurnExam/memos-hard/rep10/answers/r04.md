The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain in-memory Go buffered channel.

The queue is declared as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` at `internal/webhook/webhook.go:39`. Four goroutines are launched in `init()` at `internal/webhook/webhook.go:42–55` to consume from this channel and call `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send to the channel, dropping the event if the buffer is full. There is no external messaging infrastructure involved.
