The premise is incorrect — there is no Redis connection in this codebase. The cache layer is an in-memory implementation, not Redis-backed.

The cache is defined in `store/cache/cache.go` as a generic in-memory `Cache` struct using a `sync.Map` with a background cleanup goroutine. User entries are cached in `store/store.go` where `userCache` is constructed via `cache.NewCache()`. The TTL for all cache entries (including users) is hardcoded as `defaultExpiry = 5 * time.Minute` in `store/cache/cache.go`.
