The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **REST gateway**.

The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. REST endpoints are provided via gRPC-Gateway annotations in the proto files, and the server also exposes a **Connect** protocol handler (`server/router/api/v1/connect_services.go`). There is no GraphQL layer.
