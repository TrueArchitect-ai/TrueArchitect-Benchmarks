Memo visibility is enforced across many server surfaces. Here are the distinct enforcement sites:

1. **`checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39-68` — central gatekeeper: requires auth for non-Public memos, denies non-creator access to Private memos. Called from `GetMemo` (line 356) and `ListMemoComments` (`memo_service_comments.go:148`).

2. **`ListMemos` query-level filter** — `server/router/api/v1/memo_service.go:218-227` — restricts `VisibilityList` to `[Public]` for unauthenticated users, `[Public, Protected]` when viewing another user's memos.

3. **`CreateMemoComment` gate** — `server/router/api/v1/memo_service_comments.go:41` — blocks commenting on a Private memo unless commenter is the creator or super user.

4. **`ListMemoComments` query filter** — `server/router/api/v1/memo_service_comments.go:157-161` — filters comment memos by visibility for unauthenticated/authenticated users.

5. **`ListMemoReactions` visibility check** — `server/router/api/v1/reaction_service.go:30-41` — requires auth for non-Public, denies non-creator for Private.

6. **`UpsertMemoReaction` visibility check** — `server/router/api/v1/reaction_service.go:83` — blocks reactions on Private memos from non-creators.

7. **`GetAttachment` (gRPC) visibility check** — `server/router/api/v1/attachment_service.go:445-453` — gates attachment download based on linked memo visibility.

8. **`ListMemoAttachments` visibility check** — `server/router/api/v1/memo_attachment_service.go:214-225` — requires auth for non-Public, denies non-creator for Private.

9. **File server attachment access** — `server/router/fileserver/fileserver.go:677-701` — enforces visibility on the HTTP file-serving path (separate from gRPC), including share-token fallback.

10. **SSE event delivery filter (`canReceive`)** — `server/router/api/v1/sse_hub.go:134-143` — Private events only delivered to the creator's or admin's SSE client.

11. **RSS feeds — Public-only filter** — `server/router/rss/rss.go:90,141` — both global and per-user feeds restrict to `VisibilityList: [Public]`.

12. **Frontend sitemap — Public-only filter** — `server/router/frontend/frontend.go:150` — only Public memos included in the sitemap.

13. **User stats query filters** — `server/router/api/v1/user_service_stats.go:83-91,217-221` — `ListAllUserStats` and `GetUserStats` restrict visibility list based on authentication.

14. **Notification payload gating (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go:302-316` and `server/notification/email.go:306-320` — gates whether comment/mention notification payloads and emails include memo details.

15. **Mention notification gating** — `server/router/api/v1/memo_mention_helpers.go:56-72` — `canUserAccessMentionContext` blocks mention inbox creation when either the mentioning or related memo is Private and the target isn't the creator.
