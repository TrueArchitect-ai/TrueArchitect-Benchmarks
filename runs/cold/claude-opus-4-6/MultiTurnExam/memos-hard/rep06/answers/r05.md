The premise is incorrect — there is no GraphQL schema or GraphQL API anywhere in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC and gRPC-Gateway (REST). The service definitions live under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The server exposes both gRPC (via Connect) and REST (via gRPC-Gateway) endpoints, wired up in `server/router/api/v1/v1.go`.
