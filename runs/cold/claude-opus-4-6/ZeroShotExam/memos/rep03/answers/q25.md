The filter engine is **CEL (Common Expression Language)** via `github.com/google/cel-go`, and the custom filter engine lives at **`internal/filter/`** (entry point `engine.go`, CEL-AST-to-IR walker in `parser.go`, SQL emitter in `render.go`). The CEL expression is compiled and type-checked by `cel-go`, then walked by `buildCondition()` (`parser.go`) into a custom intermediate representation (`ir.go`), and finally the `renderer` (`render.go`) emits dialect-specific SQL (placeholders, JSON operators, text matching, timestamp functions, etc.) for SQLite, MySQL, and PostgreSQL — each store driver (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` passing its dialect constant, so the same IR is rendered with the appropriate SQL syntax per database.
