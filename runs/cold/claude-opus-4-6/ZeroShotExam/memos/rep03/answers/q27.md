The compiled React frontend is served via Go's `embed` package (`//go:embed dist/*`), which bakes the built frontend assets directly into the Go binary at compile time. The static file serving middleware and SPA fallback are wired up in `server/router/frontend/frontend.go`.

**Mechanism:** Go `embed.FS` (with Echo's `StaticWithConfig` middleware and a SPA fallback middleware); **File:** `server/router/frontend/frontend.go`
