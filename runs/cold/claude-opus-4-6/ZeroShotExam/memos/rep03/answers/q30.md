Four memo lifecycle events dispatch webhooks, with the following dispatch functions (all defined in `server/router/api/v1/memo_service_webhooks.go`):

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate through a shared private helper `dispatchMemoRelatedWebhook` (same file), which resolves the memo creator's webhooks.

All four converge for delivery at **`webhook.Post`** in `internal/webhook/webhook.go`. The dispatch functions call `webhook.PostAsync`, which enqueues the payload onto a buffered channel (`asyncPostQueue`). A pool of worker goroutines drains that channel and calls `webhook.Post`, which performs the actual HTTP POST delivery (with optional HMAC-SHA256 signing and SSRF-safe client).
