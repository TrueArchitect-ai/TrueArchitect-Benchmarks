The compiled React frontend is served via **Go's `embed` package** (`//go:embed dist/*`), which bakes the built frontend assets directly into the Go binary at compile time. At runtime, Echo's static-file middleware serves those embedded files (with an SPA fallback to `index.html` for client-side routing).

**`go:embed`; `server/router/frontend/frontend.go`**

This file declares `//go:embed dist/*` (line ~20) to embed the `dist/` directory, then registers Echo `middleware.StaticWithConfig` using the embedded filesystem and a `spaFallbackMiddleware` that serves `index.html` for unmatched routes. The frontend is wired into the server at `server/server.go` (line ~72) via `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
