**Memo lifecycle events that dispatch webhooks:**

- **memo created**: `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go`)
- **memo updated**: `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_service_webhooks.go`)
- **memo deleted**: `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service_webhooks.go`)
- **memo comment created**: `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go`)

The first three delegate to a shared helper `dispatchMemoRelatedWebhook` (same file), while the comment variant has its own inline implementation that resolves the related memo creator differently.

**All converge for delivery at:** `Post` in `internal/webhook/webhook.go` (line ~120). Every dispatch path calls `PostAsync` (line ~184), which enqueues payloads onto a buffered channel drained by worker goroutines that each call `Post` — the single function that JSON-marshals the payload, optionally HMAC-signs it, and issues the HTTP POST to the target URL.
