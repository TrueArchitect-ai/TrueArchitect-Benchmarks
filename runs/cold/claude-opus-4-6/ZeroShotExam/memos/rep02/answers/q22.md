When a memo is created, the handler `CreateMemo` in `server/router/api/v1/memo_service.go` (line 157) calls `DispatchMemoCreatedWebhook`. That function lives in `server/router/api/v1/memo_service_webhooks.go` and delegates to `dispatchMemoRelatedWebhook`, which fetches the creator's webhooks and calls `webhook.PostAsync` to enqueue each one.

HTTP delivery is performed by the `github.com/usememos/memos/internal/webhook` package (`internal/webhook/webhook.go`).

Signing uses **HMAC-SHA256** following the Standard Webhooks spec: the payload `msgID + "." + timestamp + "." + body` is signed with the key derived from the user's signing secret (optionally `whsec_`-prefixed base64), and the signature is sent as `"v1," + base64(hmac)` in the `webhook-signature` header alongside `webhook-id` and `webhook-timestamp` headers.
