The compiled React frontend is served via Go's `embed` package. The Vite build outputs into `server/router/frontend/dist/`, and in `server/router/frontend/frontend.go` an `//go:embed dist/*` directive bakes those assets into the Go binary as an embedded filesystem. The `Serve` method in that same file registers Echo's `middleware.StaticWithConfig` to serve the embedded files, plus an SPA fallback middleware that returns `index.html` for client-side routes.

**`go:embed`; `server/router/frontend/frontend.go`**
