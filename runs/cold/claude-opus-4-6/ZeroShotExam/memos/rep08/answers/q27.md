The compiled React frontend is served via Go's `//go:embed` directive, which embeds the `dist/` directory into the binary at compile time, combined with Echo's `middleware.StaticWithConfig` to serve those embedded assets as static files.

**Mechanism:** `//go:embed` (Go embed) + Echo static middleware  
**File:** `server/router/frontend/frontend.go`

In that file, `//go:embed dist/*` (line ~20) embeds the Vite-built frontend output, and the `Serve` method registers `middleware.StaticWithConfig` against the embedded filesystem along with an SPA fallback that serves `index.html` for client-side routes. The frontend service is wired into the server at `server/server.go` (line ~72).
