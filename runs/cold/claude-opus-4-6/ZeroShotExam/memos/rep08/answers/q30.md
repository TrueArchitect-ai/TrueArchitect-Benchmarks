All four converge for delivery at **`webhook.Post`** in `internal/webhook/webhook.go` (line 120). The path is:

1. Each dispatch function calls **`webhook.PostAsync`** (line 184), which enqueues the payload onto a buffered channel (`asyncPostQueue`, line 39).
2. Four worker goroutines (spawned in `init()`, line 42) drain that channel and call **`webhook.Post`** (line 120), which JSON-marshals the payload, optionally signs it with HMAC-SHA256, and performs the actual HTTP POST via `safeClient`.
