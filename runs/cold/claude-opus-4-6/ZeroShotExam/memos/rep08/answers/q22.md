When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to `dispatchMemoRelatedWebhook` — both defined in `server/router/api/v1/memo_service_webhooks.go`. That function iterates over the creator's webhooks and calls `webhook.PostAsync` to enqueue each delivery.

HTTP delivery is performed by the `internal/webhook` package (`internal/webhook/webhook.go`), which uses Go's standard-library `net/http` client.

Signing follows the **Standard Webhooks** scheme: an HMAC-SHA256 signature is computed over `{msgID}.{timestamp}.{body}` using the webhook's signing key (decoded from a `whsec_`-prefixed base64 secret), and attached via three headers (`webhook-id`, `webhook-timestamp`, `webhook-signature` with a `v1,` prefix).

**`DispatchMemoCreatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go`; `internal/webhook` (standard `net/http`); HMAC-SHA256 signing per the Standard Webhooks spec
