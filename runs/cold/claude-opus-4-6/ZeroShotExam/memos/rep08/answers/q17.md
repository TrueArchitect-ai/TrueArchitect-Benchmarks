`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD hooks (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`) using TanStack Query, and they all invoke methods on `memoServiceClient`, which is the generated Connect-Web client created in `web/src/connect.ts` via `createClient(MemoService, transport)` from the `@connectrpc/connect` library.
