When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to `dispatchMemoRelatedWebhook` — both defined in `server/router/api/v1/memo_service_webhooks.go`. That function fetches the creator's registered webhooks and calls `webhook.PostAsync` to enqueue delivery.

**`DispatchMemoCreatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go`; delivery package **`net/http`** (Go standard library, via a safe-dialing `http.Client` in `internal/webhook/webhook.go`); signing mechanism **HMAC-SHA256** following the Standard Webhooks spec (`webhook-id`, `webhook-timestamp`, `webhook-signature` headers, with the secret in `whsec_`-prefixed base64 format).
