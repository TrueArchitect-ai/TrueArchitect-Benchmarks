The compiled React frontend is served via Go's `embed.FS` (`//go:embed dist/*`) combined with Echo's `middleware.Static`. The Vite build outputs assets into `server/router/frontend/dist/`, which are embedded into the Go binary at compile time. The static middleware and an SPA fallback middleware serve those embedded files at runtime.

**Mechanism:** Go `embed.FS` + Echo static middleware; **File:** `server/router/frontend/frontend.go`
