Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to the private helper `dispatchMemoRelatedWebhook` (same file), while `DispatchMemoCommentCreatedWebhook` handles webhook lookup independently (it targets the parent memo creator's webhooks rather than the comment author's).

All four converge for delivery at **`webhook.Post`** in `internal/webhook/webhook.go`. Specifically, each dispatch function calls `webhook.PostAsync()` which enqueues the payload onto a buffered channel (`asyncPostQueue`), and background worker goroutines dequeue and call `webhook.Post()` to perform the actual HTTP POST delivery.
