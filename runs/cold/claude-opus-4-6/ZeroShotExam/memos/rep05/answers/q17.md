`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD operations as TanStack React Query hooks (`useCreateMemo`, `useMemo`/`useMemos`, `useUpdateMemo`, `useDeleteMemo`, etc.). It uses the `memoServiceClient` generated client, which is instantiated in `web/src/connect.ts` via `createClient(MemoService, transport)` using `@connectrpc/connect`, with the `MemoService` descriptor generated from `proto/api/v1/memo_service.proto`.
