When a memo is created, the handler `CreateMemo` in `server/router/api/v1/memo_service.go` calls **`DispatchMemoCreatedWebhook`** defined in `server/router/api/v1/memo_service_webhooks.go`. This in turn calls `dispatchMemoRelatedWebhook`, which gathers the creator's webhooks and enqueues each via `webhook.PostAsync`.

HTTP delivery is performed by the **`github.com/usememos/memos/internal/webhook`** package (`internal/webhook/webhook.go`), where `Post` does the actual `http.POST`.

Signing uses **HMAC-SHA256** following the Standard Webhooks spec: the signed content is `msgID + "." + timestamp + "." + body`, and the resulting digest is sent as header `webhook-signature: v1,<base64-HMAC-SHA256>`, alongside `webhook-id` and `webhook-timestamp` headers.

**`DispatchMemoCreatedWebhook`** — `server/router/api/v1/memo_service_webhooks.go`; `github.com/usememos/memos/internal/webhook`; HMAC-SHA256 (Standard Webhooks)
