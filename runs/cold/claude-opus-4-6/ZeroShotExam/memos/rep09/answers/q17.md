`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file contains all memo CRUD hooks (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`, etc.) built on TanStack Query. They all call through `memoServiceClient`, which is a Connect RPC client created in `web/src/connect.ts` via `createClient(MemoService, transport)` using the `@connectrpc/connect` library and the generated `MemoService` descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
