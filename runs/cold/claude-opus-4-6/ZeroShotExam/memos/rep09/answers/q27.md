The compiled React frontend is served via **Go's `embed.FS`** (`//go:embed dist/*`), which bakes the Vite build output into the Go binary at compile time. The embedded filesystem is then served using Echo's `middleware.StaticWithConfig` (with an SPA fallback middleware for client-side routing).
