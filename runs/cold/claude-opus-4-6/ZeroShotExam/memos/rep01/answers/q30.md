Four memo lifecycle events dispatch webhooks, all defined as methods on `*APIV1Service` in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to a shared private helper `dispatchMemoRelatedWebhook` (same file), which resolves the memo creator, fetches their webhooks, and calls `webhook.PostAsync`. The comment variant does this directly.

All four converge on **`PostAsync`** in `internal/webhook/webhook.go`, which enqueues payloads onto a buffered channel (`asyncPostQueue`). Worker goroutines drain that channel and call the synchronous **`Post`** function (`internal/webhook/webhook.go`), which performs the actual HTTP POST delivery (with HMAC-SHA256 signing and SSRF-safe dialing).
