The compiled React frontend is served via **Go's `embed` package** (`//go:embed dist/*`). The Vite build outputs compiled assets into `server/router/frontend/dist/`, and Go embeds them into the binary at compile time. At runtime, an Echo `StaticWithConfig` middleware serves these embedded files, with an SPA fallback middleware to support client-side routing.

**Mechanism:** Go `embed` (with Echo static middleware); **File:** `server/router/frontend/frontend.go`
