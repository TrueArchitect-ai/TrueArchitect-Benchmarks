**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `google/cel-go`, implemented in `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile` method parses the filter string into a CEL AST, converts it to a dialect-agnostic `Condition` tree (`internal/filter/parser.go` / `internal/filter/ir.go`), and then `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) that walks the conditions and emits parameterized SQL using per-dialect placeholder styles and per-field expression overrides (e.g. `UNIX_TIMESTAMP(%s)` for MySQL timestamps) defined in the `Schema` (`internal/filter/schema.go`).
