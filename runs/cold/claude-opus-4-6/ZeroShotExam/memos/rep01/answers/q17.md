`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This module exports all memo CRUD React Query hooks (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`). It uses the generated Connect-RPC service client `memoServiceClient`, which is created in `web/src/connect.ts` via `createClient(MemoService, transport)` where `MemoService` is the generated service descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
