**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (line 156) is a Connect RPC interceptor that attaches an `Authorization: Bearer <token>` header to every request, handles 401 retries with automatic token refresh, and deduplicates concurrent refresh calls via `tokenRefreshManager`.

**Token kinds:**
1. **JWT access token** — short-lived (15 min), stored in-memory and `localStorage`, sent as `Bearer` header, validated statelessly by signature.
2. **JWT refresh token** — long-lived (30 days), stored as an `HttpOnly` cookie named `memos_refresh`, validated against the database for revocation.
3. **Personal Access Token (PAT)** — prefixed `memos_pat_`, a random string stored as a SHA-256 hash in the database, used for programmatic access.

**Backend package:** `server/auth/` (particularly `server/auth/token.go` for JWT generation/parsing and `server/auth/authenticator.go` for the `Authenticate()` method that resolves Bearer tokens and PATs into user identities). The Connect-level auth interceptor that calls into this package lives at `server/router/api/v1/connect_interceptors.go`.
