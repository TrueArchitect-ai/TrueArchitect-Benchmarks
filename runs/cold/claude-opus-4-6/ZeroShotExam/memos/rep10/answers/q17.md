`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The file defines all memo CRUD operations as TanStack React Query hooks (`useCreateMemo`, `useMemo`/`useMemos`, `useUpdateMemo`, `useDeleteMemo`), and they all call `memoServiceClient` — a ConnectRPC client instantiated in `web/src/connect.ts` via `createClient(MemoService, transport)` from `@connectrpc/connect`.
