Four memo lifecycle events dispatch webhooks, each with a dedicated dispatch function in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three converge through the private helper `dispatchMemoRelatedWebhook` (same file), which resolves the memo creator's webhooks and posts each one. `DispatchMemoCommentCreatedWebhook` does equivalent work inline (using the *related* memo's creator ID instead).

All four ultimately converge on **`webhook.Post`** in `internal/webhook/webhook.go` for delivery — specifically via `webhook.PostAsync` (which enqueues onto a buffered channel drained by worker goroutines that each call `webhook.Post`). `Post` serializes the payload to JSON, optionally signs it with HMAC-SHA256, and sends an HTTP POST to the target URL.
