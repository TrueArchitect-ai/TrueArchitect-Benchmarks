The compiled React frontend is served via **Go's `embed` package** (`//go:embed dist/*`), which bakes the built assets into the Go binary at compile time. The embedded filesystem is then served using Echo's `StaticWithConfig` middleware (with an SPA fallback for client-side routing).

This is wired in **`server/router/frontend/frontend.go`**, which declares the embed directive (line ~20), registers the static-file middleware and SPA fallback in its `Serve` method (lines ~41–61), and is called from `server/server.go` (line ~72).
