The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built `dist/` directory directly into the Go binary at compile time. At runtime, Echo's `middleware.StaticWithConfig` serves those embedded assets, with an SPA fallback middleware that returns `index.html` for client-side routes.

**Mechanism:** `go:embed` (with Echo static file middleware); **File:** `server/router/frontend/frontend.go`
