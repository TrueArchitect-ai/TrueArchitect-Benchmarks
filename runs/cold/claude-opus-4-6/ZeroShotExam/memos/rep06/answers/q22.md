When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which is defined in `server/router/api/v1/memo_service_webhooks.go`. This delegates to `dispatchMemoRelatedWebhook` (same file), which iterates over the creator's webhooks and calls `webhook.PostAsync` for each one.

**Dispatcher** — `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`

**Delivery package** — `github.com/usememos/memos/internal/webhook` (an internal package in `internal/webhook/webhook.go` using Go's standard `net/http`; no external webhook library)

**Signing mechanism** — HMAC-SHA256 following the Standard Webhooks spec: the signature is computed over `msgID + "." + timestamp + "." + body`, base64-encoded, and sent as `webhook-signature: v1,<base64>` along with `webhook-id` and `webhook-timestamp` headers. Keys prefixed with `whsec_` are base64-decoded first.
