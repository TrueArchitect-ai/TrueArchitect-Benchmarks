CEL (Common Expression Language) via `google/cel-go`; engine at `internal/filter/engine.go`. The `Engine.Compile` method parses the CEL filter string into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then `Program.Render` walks that tree through a `renderer` (`internal/filter/render.go`) that switches on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) to emit the appropriate SQL fragment, placeholders, and JSON operators for each dialect.
