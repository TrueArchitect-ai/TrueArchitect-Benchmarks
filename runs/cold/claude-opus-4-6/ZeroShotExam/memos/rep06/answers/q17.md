`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file contains all memo CRUD queries and mutations (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`) implemented as React Query hooks. It uses the generated `memoServiceClient`, which is created in `web/src/connect.ts` via `createClient(MemoService, transport)` using the `MemoService` descriptor from the protobuf-generated `web/src/types/proto/api/v1/memo_service_pb.ts`.
