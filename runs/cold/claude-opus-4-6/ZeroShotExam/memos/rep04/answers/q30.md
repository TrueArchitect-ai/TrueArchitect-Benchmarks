**Memo lifecycle events that dispatch webhooks, with their dispatch function names:**

- **memo created:** `DispatchMemoCreatedWebhook`
- **memo updated:** `DispatchMemoUpdatedWebhook`
- **memo deleted:** `DispatchMemoDeletedWebhook`
- **memo comment created:** `DispatchMemoCommentCreatedWebhook`

All four are defined in `server/router/api/v1/memo_service_webhooks.go`. The first three delegate through a shared private helper `dispatchMemoRelatedWebhook` (same file), while `DispatchMemoCommentCreatedWebhook` builds its own payload (targeting the parent memo creator's webhooks).

**Convergence point for delivery:**

All dispatch functions converge on `webhook.PostAsync` in `internal/webhook/webhook.go`, which enqueues payloads onto a buffered channel (`asyncPostQueue`). A pool of goroutine workers drains that channel and calls `webhook.Post` (also in `internal/webhook/webhook.go`) to perform the actual HTTP POST delivery (with HMAC-SHA256 signing and SSRF-safe dialing).
