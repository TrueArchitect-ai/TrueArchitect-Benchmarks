The compiled React frontend is served via Go's **`//go:embed`** directive. The Vite build outputs compiled assets into `server/router/frontend/dist/`, and Go embeds them into the binary at compile time. The embedded filesystem is then served using Echo's `middleware.StaticWithConfig` with an SPA fallback middleware for client-side routing.

**Mechanism:** `//go:embed` (embedding the `dist/` directory into the Go binary, served via Echo static middleware)
**File:** `server/router/frontend/frontend.go`
