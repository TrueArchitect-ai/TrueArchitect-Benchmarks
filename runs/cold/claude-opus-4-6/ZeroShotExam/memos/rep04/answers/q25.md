**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`; **path:** `internal/filter/` (engine in `internal/filter/engine.go`, parser in `internal/filter/parser.go`, renderer in `internal/filter/render.go`).

**Mechanism:** The `Engine.Compile` method parses the filter string through the CEL environment into an AST, then `buildCondition` (`parser.go`) walks that AST to produce a dialect-agnostic IR condition tree (`ir.go`), and `Render` (`render.go`) walks the condition tree emitting dialect-specific SQL (placeholders, function names, casts, JSON operators) by switching on `DialectName` (`sqlite` / `mysql` / `postgres`) defined in `internal/filter/schema.go`.
