The premise of the question is incorrect. There is no "nightly database-cleanup" job in this repository's cron scheduler. The `internal/scheduler/` package is a general-purpose cron scheduling library, not a preconfigured application scheduler with a database-cleanup job.

The closest thing is an **example** in `internal/scheduler/example_test.go:97-106` — a test example called `"cleanup"` with the comment "Cleanup old data every night at 2 AM" and cron schedule `"0 2 * * *"`. However, this is illustrative example/test code demonstrating how to use the scheduler library, not an actual scheduled database-cleanup job configured to run in the application.
