**Convergence function:** **`webhook.Post`** in `internal/webhook/webhook.go`

All paths feed through `webhook.PostAsync` which enqueues work, and background goroutines drain that queue by calling `webhook.Post`. This single function constructs the `http.NewRequest` against the user-configured webhook URL, applies HMAC-SHA256 signing headers if a secret is set, and executes the outbound HTTP POST via a safe-dialing `http.Client` (with SSRF protections that block private/reserved IP ranges).
