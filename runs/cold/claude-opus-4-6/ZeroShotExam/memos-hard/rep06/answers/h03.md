The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all identity provider implementations must produce. The concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`).
