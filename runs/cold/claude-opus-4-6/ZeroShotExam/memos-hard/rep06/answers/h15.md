Here are the distinct memo visibility enforcement sites on the server:

1. **Memo read-access gate (GetMemo, per-object check)** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`, called from `GetMemo`)
2. **Memo listing query filter (ListMemos)** — `server/router/api/v1/memo_service.go` (`ListMemos` applies `VisibilityList`/CEL filters)
3. **Memo comments visibility** — `server/router/api/v1/memo_service_comments.go` (`ListMemoComments` and `CreateMemoComment` both check parent memo access)
4. **Memo relations visibility** — `server/router/api/v1/memo_relation_service.go` (visibility CEL filter on `ListMemoRelations`)
5. **Memo relations batch converter** — `server/router/api/v1/memo_service_converter.go` (`batchConvertMemoRelations` applies visibility filter)
6. **Reactions visibility** — `server/router/api/v1/reaction_service.go` (`ListMemoReactions` and `UpsertMemoReaction` check memo visibility)
7. **Attachment access check** — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess` enforces memo visibility on attachments)
8. **Memo attachment listing** — `server/router/api/v1/memo_attachment_service.go` (`ListMemoAttachments` checks memo visibility)
9. **File server (static file serving)** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission` enforces visibility when serving files over HTTP)
10. **SSE event delivery filtering** — `server/router/api/v1/sse_hub.go` (`canReceive` filters which SSE events reach which clients)
11. **User stats visibility** — `server/router/api/v1/user_service_stats.go` (`ListAllUserStats` and `GetUserStats` apply visibility filters)
12. **RSS feed** — `server/router/rss/rss.go` (both `GetExploreRSS` and `GetUserRSS` restrict to `Public` only)
13. **Sitemap generation** — `server/router/frontend/frontend.go` (`getSitemapXML` restricts to `Public` only)
14. **Notification/inbox access check** — `server/router/api/v1/user_service_notifications.go` (`canViewerAccessMemo` gates notification payloads)
15. **Email notification dispatcher** — `server/notification/email.go` (separate `canViewerAccessMemo` checks before sending email notifications)
16. **Mention notification suppression** — `server/router/api/v1/memo_mention_helpers.go` (`canUserAccessMentionContext` / `shouldSkipMentionInbox`)
17. **Share-token access** — `server/router/api/v1/memo_share_service.go` (`GetMemoByShare` grants access via valid share token, bypassing normal visibility)
18. **Instance-level anonymous access policy** — `server/router/api/v1/authz.go` (`CheckAccess` blocks unauthenticated users on private instances)
19. **Store/DB query-level enforcement** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go` (translate `VisibilityList` and CEL filters into SQL `WHERE` clauses)
