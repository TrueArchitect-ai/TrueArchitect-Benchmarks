**Premise correction:** This repository (Memos) does not have a GraphQL API. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** and exposed as both **gRPC** and **REST** (via grpc-gateway). The schema lives in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Code generation is configured in `proto/buf.gen.yaml`, which produces Go gRPC stubs, Connect-RPC stubs, grpc-gateway REST reverse proxies, an OpenAPI spec (`proto/gen/openapi.yaml`), and TypeScript types for the web frontend.
