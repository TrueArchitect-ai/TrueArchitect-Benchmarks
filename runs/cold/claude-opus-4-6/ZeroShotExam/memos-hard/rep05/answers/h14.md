**Computation site:** `server/runner/memopayload/runner.go:74-88` (`RebuildMemoPayload`), which calls `internal/markdown/markdown.go:355-422` (`ExtractAll`) — a single-pass goldmark AST walk over the memo's markdown content. Additionally, snippets are computed on-the-fly during API response conversion at `server/router/api/v1/memo_service_converter.go:76-80` via `GenerateSnippet` (`internal/markdown/markdown.go:263-346`).

**Triggers:** (1) memo creation (`server/router/api/v1/memo_service.go:108`), (2) memo content update (`server/router/api/v1/memo_service.go:447`, when the `"content"` field is in the update mask), and (3) a batch rebuild of all memos (`server/runner/memopayload/runner.go:52`, `RunOnce`, which iterates all memos in batches of 100).

**Extracted properties:** `ExtractAll` derives and persists in `memo.Payload`:
- **Tags** (`[]string`) — all `#tag` nodes, deduplicated
- **Property.Title** (`string`) — text of the first block-level H1 heading, if present
- **Property.HasLink** (`bool`) — whether any link nodes exist
- **Property.HasCode** (`bool`) — whether code blocks, fenced code blocks, or code spans exist
- **Property.HasTaskList** (`bool`) — whether any task checkboxes exist
- **Property.HasIncompleteTasks** (`bool`) — whether any unchecked task checkboxes exist

The **snippet** (a truncated 64-character plain-text summary) is computed on-the-fly per API response by `GenerateSnippet`, not persisted, and used for list previews, relation cards, notifications, and map pins.
