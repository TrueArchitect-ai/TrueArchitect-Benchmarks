The premise is incorrect — this repository does not have a GraphQL API. The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL.

The API schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared types)

The actual API surface is **gRPC + REST** (via grpc-gateway), powered by `connectrpc.com/connect`, `grpc-gateway/v2`, and `google.golang.org/grpc` (per `go.mod`). Generated Go code from these protos lives in `proto/gen/`, and the service implementations (route handlers) are in `server/router/api/v1/`.
