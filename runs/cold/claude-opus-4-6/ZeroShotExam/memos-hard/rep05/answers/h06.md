**Convergence function — path:** `Post` — `internal/webhook/webhook.go`

All six RPC handlers dispatch webhook activity types (`memos.memo.created`, `memos.memo.updated`, `memos.memo.deleted`, `memos.memo.comment.created`) through intermediate helpers in `server/router/api/v1/memo_service_webhooks.go` (primarily `dispatchMemoRelatedWebhook`), which call `webhook.PostAsync`. That enqueues onto a buffered channel consumed by background goroutines that call `Post` (`internal/webhook/webhook.go:120`), the single point where the outbound HTTP POST to the user-configured webhook URL is actually constructed and executed (including HMAC-SHA256 signing and SSRF-safe dialing).
