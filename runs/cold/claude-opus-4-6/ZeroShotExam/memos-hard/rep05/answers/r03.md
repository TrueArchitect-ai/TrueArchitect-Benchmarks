The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in the cron scheduler. The `internal/scheduler/` package (`internal/scheduler/README.md`, `internal/scheduler/doc.go`, `internal/scheduler/example_test.go`) is a general-purpose cron scheduling library — it contains only illustrative examples such as a `"daily-cleanup"` job at `"0 2 * * *"` (2 AM daily) in the README and a `"cleanup"` example in `example_test.go` with the comment "Cleanup old data every night at 2 AM." These are documentation/test examples showing how to use the scheduler, not actual application jobs. No real "database-cleanup" job is registered anywhere in the production codebase.
