The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in the cron scheduler. The `internal/scheduler/` package is a general-purpose cron scheduling library with no production jobs registered in it. The references to cleanup jobs exist only in **example/test code and documentation**:

- `internal/scheduler/example_test.go:97-106` — a test example named `"cleanup"` scheduled at `"0 2 * * *"` (2 AM) with the comment "Cleanup old data every night at 2 AM"
- `internal/scheduler/doc.go:15-21` — a doc comment example named `"daily-cleanup"` also using `"0 2 * * *"`

These are illustrative examples demonstrating how to use the scheduler library, not actual scheduled jobs in the application. No real database-cleanup cron job is registered anywhere in the codebase.
