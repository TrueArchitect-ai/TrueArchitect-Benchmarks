The premise is incorrect — there is no GraphQL schema in this repository. Memos has no GraphQL API at all.

The actual API surface is **protobuf/gRPC-first**, defined entirely in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`). These protobuf definitions are the single source of truth for the API contract.

From those protos, the `buf` code-generation pipeline (`proto/buf.gen.yaml`) produces two parallel HTTP transports that share the same Go service implementation (`server/router/api/v1/v1.go`):

1. **gRPC-Gateway (REST/JSON)** — mapped to `GET/POST/PATCH/DELETE /api/v1/*` endpoints via `google.api.http` annotations in the proto files, with a generated OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml`.
2. **Connect-RPC (binary protocol)** — served at `/memos.api.v1.*` paths, used by the web frontend via `@connectrpc/connect-web` (`web/src/connect.ts`).
