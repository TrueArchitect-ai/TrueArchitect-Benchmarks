The data layer is the `store` package (`store/`), which defines persistent entity types like `User`, `Memo`, `Attachment`, `MemoRelation`, `Inbox`, `Reaction`, etc.

**1st: Memo; 2nd: User** (~7 packages each)

Both are tied at 7 external packages:

- **Memo** is referenced from: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- **User** is referenced from: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`

The next closest entity is `Attachment` at ~5 packages.
