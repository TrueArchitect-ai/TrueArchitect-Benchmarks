**Computation site:** `server/runner/memopayload/runner.go` — the `RebuildMemoPayload` function (line 74) calls `markdownService.ExtractAll()` (defined in `internal/markdown/markdown.go`, line 33), which parses the memo's markdown content into an AST and walks it once to extract all derived metadata. **Triggers:** Recomputation is triggered on three operations:
1. **Memo creation** — `server/router/api/v1/memo_service.go:108`
2. **Memo content update** — `server/router/api/v1/memo_service.go:447`

**Extracted properties** (stored in `MemoPayload.Property`, defined in `proto/store/memo.proto`):
- `title` (string) — plain text of the first H1 heading, if the first block element is an `# ...` heading
- `has_link` (bool) — whether the content contains any markdown link
- `has_task_list` (bool) — whether the content contains GFM task list checkboxes
- `has_code` (bool) — whether the content contains code blocks or inline code
- `has_incomplete_tasks` (bool) — whether any task checkbox is unchecked
- `tags` (string array) — all `#tag` tokens extracted from content (stored in `MemoPayload.tags`)
- `snippet` (string, not stored, computed on-the-fly) — a plain-text preview truncated to 64 characters at a word boundary, generated by walking the AST and collecting text nodes while skipping code blocks
