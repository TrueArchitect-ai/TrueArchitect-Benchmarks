The provider abstraction is defined in package `internal/idp` (`internal/idp/idp.go`), which declares the common `IdentityProviderUserInfo` struct that all identity provider implementations return. The sole concrete protocol implementation that ships is OAuth2, in package `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`).
