The outbound webhook delivery executes in the **`Post`** function at `internal/webhook/webhook.go`, which marshals the payload, signs it (HMAC-SHA256 if a secret is configured), and sends the HTTP POST via a safe client. Production callers go through **`PostAsync`** (same file), which enqueues payloads into a buffered channel drained by background goroutines that each call `Post`.

SSRF protection is a two-layer check against reserved/private IP ranges:

1. **Registration-time validation** — `ValidateURL` in `internal/webhook/validate.go` DNS-resolves the webhook URL and rejects it if any resolved IP falls within `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local), checked by `isReservedIP` in the same file.
2. **Dial-time enforcement** — `safeDialContext` in `internal/webhook/webhook.go` re-resolves the hostname at connection time and repeats the `isReservedIP` check, defeating DNS rebinding attacks where a hostname resolves to a public IP at registration but a private IP at request time.

**delivery function — `internal/webhook/webhook.go`; protection mechanism — `internal/webhook/validate.go` (registration-time) and `internal/webhook/webhook.go` (`safeDialContext`, dial-time)**
