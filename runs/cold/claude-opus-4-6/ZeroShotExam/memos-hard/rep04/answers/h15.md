Every distinct server-side enforcement site for memo visibility:

1. `checkMemoReadAccess` (single-memo gate for GetMemo, comment parent check) — `server/router/api/v1/memo_service.go`
2. `ListMemos` visibility filtering (VisibilityList / CEL filter on listing queries) — `server/router/api/v1/memo_service.go`
3. `CreateMemoComment` visibility gate (private-memo commenting restriction) — `server/router/api/v1/memo_service_comments.go`
4. `ListMemoComments` MemoFilter (filters visible comments) — `server/router/api/v1/memo_service_comments.go`
5. `ListMemoRelations` MemoFilter (filters related memos by visibility) — `server/router/api/v1/memo_relation_service.go`
6. `batchConvertMemoRelations` MemoFilter (batch relation loading for responses) — `server/router/api/v1/memo_service_converter.go`
7. `ListMemoAttachments` visibility check — `server/router/api/v1/memo_attachment_service.go`
8. `checkAttachmentAccess` (gRPC API attachment access via memo visibility) — `server/router/api/v1/attachment_service.go`
9. `checkAttachmentPermission` (HTTP file-server binary serving) — `server/router/fileserver/fileserver.go`
10. `ListMemoReactions` / `UpsertMemoReaction` visibility checks — `server/router/api/v1/reaction_service.go`
11. SSE `canReceive` (real-time event delivery filtering by visibility) — `server/router/api/v1/sse_hub.go`
12. RSS feeds (public-only VisibilityList) — `server/router/rss/rss.go`
13. Sitemap generation (public-only VisibilityList) — `server/router/frontend/frontend.go`
14. `GetUserStats` / `ListAllUserStats` visibility filtering — `server/router/api/v1/user_service_stats.go`
15. `canUserAccessMentionContext` (mention notification filtering) — `server/router/api/v1/memo_mention_helpers.go`
16. Database-level SQL WHERE clauses (VisibilityList → `IN (...)` and CEL MemoFilter → subselect) — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
