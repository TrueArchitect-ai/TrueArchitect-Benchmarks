The premise is incorrect — this repository has **no GraphQL schema**. The public API is not built on GraphQL at all.

The actual API surface is **gRPC + ConnectRPC + gRPC-Gateway (REST)**, with the schema defined entirely in **Protocol Buffer `.proto` files** under `proto/api/v1/`. Key service definitions include:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`

Each `.proto` file defines a gRPC `service` with `rpc` methods annotated with `google.api.http` options for automatic REST/JSON transcoding. Code generation is driven by `proto/buf.gen.yaml` using Buf, which produces Go gRPC stubs, ConnectRPC handlers, gRPC-Gateway reverse proxies, TypeScript client types (into `web/src/types/proto/`), and an auto-generated OpenAPI 3.0 spec at `proto/gen/openapi.yaml`.
