The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`) is a general-purpose cron scheduling library — it provides the machinery to register and run cron jobs, but it does not itself define any specific jobs like a "database-cleanup" job.

The only references to cleanup jobs are illustrative examples in documentation and tests:
- `internal/scheduler/doc.go:17` shows a `"daily-cleanup"` example with schedule `"0 2 * * *"` (2 AM daily) as sample usage of the API.
- `internal/scheduler/example_test.go` has a `"cleanup"` job described as "Cleanup old data every night at 2 AM" — again, just a test example.

These are documentation/test examples demonstrating how to use the scheduler library, not actual application-configured jobs. No real database-cleanup job is scheduled anywhere in the codebase.
