**Triggers:** (1) memo creation (`server/router/api/v1/memo_service.go:108`), (2) memo update when the `content` field is in the update mask (`memo_service.go:447`), and (3) batch rebuild of all memos via `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`).

**Extracted properties:** The `ExtractAll` single-pass AST walk extracts:
- **`Tags`** — all `#tag` nodes, deduplicated
- **`Property.Title`** — plain text of the first block-level H1 heading (if present)
- **`Property.HasLink`** — whether any markdown link exists
- **`Property.HasCode`** — whether any code block, fenced code block, or code span exists
- **`Property.HasTaskList`** — whether any task checkbox exists
- **`Property.HasIncompleteTasks`** — whether any unchecked task checkbox exists

Additionally, at serving time (not persisted), `GenerateSnippet` (`internal/markdown/markdown.go:264-346`) produces a truncated plain-text **snippet** (max 64 chars) for list/preview display.
