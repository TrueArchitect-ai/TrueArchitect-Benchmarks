The premise is incorrect — there is no GraphQL schema in this repository. The public API is defined using **Protocol Buffers (protobuf)** with gRPC and REST (via `google.api.http` annotations), not GraphQL.

The API surface is defined by the `.proto` files in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/common.proto`

These proto definitions generate both gRPC stubs (in `proto/gen/api/`) and an OpenAPI spec (`proto/gen/openapi.yaml`). Each service uses `google.api.http` annotations to map RPCs to REST endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). The `buf.gen.yaml` file at `proto/buf.gen.yaml` configures the code generation pipeline.
