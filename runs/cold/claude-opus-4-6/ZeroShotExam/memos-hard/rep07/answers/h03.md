The provider abstraction is defined in the `internal/idp` package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all concrete providers must return. The only concrete protocol implementation that ships is OAuth2, in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`).

**Answer:** `internal/idp`; `internal/idp/oauth2`
