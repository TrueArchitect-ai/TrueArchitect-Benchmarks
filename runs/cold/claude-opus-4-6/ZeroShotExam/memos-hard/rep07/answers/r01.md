The premise is incorrect — this repository (usememos/memos) does not use Redis at all. There is no Redis connection anywhere in the codebase.

The cache layer is a **custom in-memory cache** implemented in pure Go using `sync.Map`, defined in `store/cache/cache.go`. It is not backed by any external store like Redis.

The cache is instantiated in `store/store.go:38-45`, where all three cache instances (including `userCache`) share the same default configuration:

- **DefaultTTL: 10 minutes** (`store/store.go:41`)
- CleanupInterval: 5 minutes (`store/store.go:42`)
- MaxItems: 1000 (`store/store.go:43`)

User entries specifically are cached via `s.userCache` (a `*cache.Cache` field on the `Store` struct, `store/store.go:28`) using `.Set(ctx, key, user)` which applies the default 10-minute TTL (`store/cache/cache.go:93-95`). The cache key for users is simply the user ID converted to a string (`store/user.go:88-90`).
