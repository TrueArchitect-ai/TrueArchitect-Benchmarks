**Computation site:** `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` defined in `internal/markdown/markdown.go:356`. This performs a single-pass AST walk over the memo's markdown content. Snippets are computed separately on the fly via `GenerateSnippet()` (`internal/markdown/markdown.go:264`).

**Triggers:** Two operations trigger recomputation of the stored payload properties:
1. **CreateMemo** — called at `server/router/api/v1/memo_service.go:108` before persisting.
2. **UpdateMemo** (when the `"content"` field is in the update mask) — called at `server/router/api/v1/memo_service.go:447` before persisting.

The `snippet` is not stored; it is computed at response time whenever a memo is converted to its API representation (in `convertMemoFromStoreWithCreators` in `memo_service_converter.go`).

**Extracted properties** (defined in `proto/store/memo.proto` as `MemoPayload.Property`):
- **`tags`** — all `#tag` tokens found in the content
- **`title`** — text of the first H1 heading (if the first block-level element is an H1)
- **`has_link`** — whether the content contains any links
- **`has_code`** — whether it contains code blocks or code spans
- **`has_task_list`** — whether it contains task checkboxes
- **`has_incomplete_tasks`** — whether any task checkboxes are unchecked
- **`snippet`** (derived on the fly, not stored) — a plain-text summary of the content, up to 64 characters, with markdown stripped and truncated at a word boundary
