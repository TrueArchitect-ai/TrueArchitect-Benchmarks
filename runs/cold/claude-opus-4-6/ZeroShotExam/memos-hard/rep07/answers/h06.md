The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` — dispatches `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` — dispatches `DispatchMemoUpdatedWebhook` via `dispatchMemoUpdatedSideEffects`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` — dispatches `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` — dispatches both `DispatchMemoCreatedWebhook` (by internally calling `CreateMemo`) and `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:16` — dispatches `DispatchMemoUpdatedWebhook` via `dispatchMemoUpdatedSideEffects`
6. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:16` — dispatches `DispatchMemoUpdatedWebhook` via `dispatchMemoUpdatedSideEffects`

**Convergence function:** All these paths converge at **`webhook.PostAsync`** — `internal/webhook/webhook.go:184`. Every dispatch method in `server/router/api/v1/memo_service_webhooks.go` calls `webhook.PostAsync()`, which enqueues the payload onto a buffered channel (`asyncPostQueue`). Four background goroutines drain that channel and call `webhook.Post()` (line 120), which performs the actual `http.Client.Do()` HTTP POST to the user-configured URL.
