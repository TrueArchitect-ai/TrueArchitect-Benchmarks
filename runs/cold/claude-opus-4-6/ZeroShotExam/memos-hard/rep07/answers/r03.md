The premise of the question is incorrect. There is no "nightly database-cleanup job" in this repository. The `internal/scheduler/` package is a **general-purpose cron scheduling library**, not an application-level job configuration. The examples that reference cleanup jobs (e.g., `"daily-cleanup"` at `0 2 * * *` in `internal/scheduler/doc.go:15` and `"cleanup"` at `0 2 * * *` in `internal/scheduler/example_test.go:99`) are **illustrative code samples** in documentation and test files demonstrating how to use the scheduler API — they are not actual scheduled jobs that run in the application. No real database-cleanup job is registered anywhere in the codebase.
