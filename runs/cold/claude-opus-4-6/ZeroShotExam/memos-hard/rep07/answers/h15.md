1. **`checkMemoReadAccess` (GetMemo, ListMemoComments)** — `server/router/api/v1/memo_service.go` — central gatekeeper checking archived status, authentication, and private-only-for-creator rules; called for `GetMemo` and as a guard in `ListMemoComments`.

2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go` — sets `VisibilityList` or CEL filter (`visibility in ["PUBLIC","PROTECTED"]`) before querying the store, so unauthorized memos are never fetched.

3. **`ListMemoComments` query-level filtering** — `server/router/api/v1/memo_service_comments.go` — builds a `memoFilter` restricting comment visibility based on auth status (public-only for anonymous, excludes others' private for authenticated).

4. **`batchConvertMemoRelations` (relation converter)** — `server/router/api/v1/memo_service_converter.go` — applies a visibility `memoFilter` when loading related memos so invisible memos are excluded from relation results.

5. **`ListMemoRelations`** — `server/router/api/v1/memo_relation_service.go` — constructs a `memoFilter` on visibility for both outgoing and incoming relation queries.

6. **`checkAttachmentAccess` (gRPC attachment endpoint)** — `server/router/api/v1/attachment_service.go` — checks the parent memo's visibility before serving an attachment via the API.

7. **`checkAttachmentPermission` (file server / HTTP download)** — `server/router/fileserver/fileserver.go` — separate HTTP handler that enforces memo visibility (including share-token fallback) when serving attachment file downloads.

8. **`canReceive` (SSE hub)** — `server/router/api/v1/sse_hub.go` — filters server-sent event delivery per client: private memo events only go to the creator/admin.

9. **`ListMemoReactions` / `UpsertMemoReaction`** — `server/router/api/v1/reaction_service.go` — checks memo visibility before listing or adding reactions.

10. **RSS feed generation** — `server/router/rss/rss.go` — restricts memo queries to `VisibilityList: [Public]` only.

11. **Sitemap generation** — `server/router/frontend/frontend.go` — restricts memo queries to `VisibilityList: [Public]` only.

12. **User stats (`ListAllUserStats` / `GetUserStats`)** — `server/router/api/v1/user_service_stats.go` — applies the same visibility list / CEL filter pattern so stats don't leak private memo counts.
