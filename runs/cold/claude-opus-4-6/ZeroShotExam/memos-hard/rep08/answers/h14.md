**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` in `internal/markdown/markdown.go:356`. The `snippet` is computed separately via `getMemoContentSnippet` → `markdownService.GenerateSnippet()` at serving time in `server/router/api/v1/memo_service_converter.go:76`.

**Triggers:** (1) `CreateMemo` — called at `server/router/api/v1/memo_service.go:108` before persisting a new memo; (2) `UpdateMemo` — called at `server/router/api/v1/memo_service.go:447` when the `content` field is in the update mask; (3) batch `RunOnce` in `server/runner/memopayload/runner.go:27` which rebuilds payloads for all memos. The `snippet` is recomputed on every API response (not persisted).

**Extracted properties:** `ExtractAll` walks the goldmark AST in a single pass and extracts:
- **`tags`** — `#tag` nodes (deduplicated, case-preserved)
- **`property.title`** — plain text of the first H1 heading
- **`property.hasLink`** — whether any link node exists
- **`property.hasCode`** — whether any code block/span exists
- **`property.hasTaskList`** — whether any task checkbox exists
- **`property.hasIncompleteTasks`** — whether any unchecked task checkbox exists
- **`snippet`** — a plain-text truncation of the content (max 64 chars, truncated at word boundary), computed at serving time by `GenerateSnippet` (`internal/markdown/markdown.go:264`)
