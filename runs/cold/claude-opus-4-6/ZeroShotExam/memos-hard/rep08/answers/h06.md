All outbound HTTP requests to user-configured webhook URLs converge through a single function: **`webhook.Post`** in `internal/webhook/webhook.go:120`. This function marshals the payload, constructs an `http.NewRequest("POST", requestPayload.URL, ...)`, optionally signs it with HMAC-SHA256, and sends it via `safeClient.Do(req)`.

The intermediate async wrapper `webhook.PostAsync` (same file, line 184) enqueues payloads on a buffered channel consumed by worker goroutines, each of which calls `Post`.

**RPC handler methods that transitively cause outbound HTTP to user-configured URLs:**

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go`) — calls `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`

2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`

3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go`) — calls `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post`

4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go`) — calls `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync` → `webhook.Post` (and also internally calls `CreateMemo`, triggering a second webhook)
