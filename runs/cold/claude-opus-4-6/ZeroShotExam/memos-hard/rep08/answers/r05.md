The premise is incorrect — there is no GraphQL schema in this repository. Memos has no GraphQL layer at all.

The actual public API is **protobuf-first**, defined entirely by Protocol Buffer service definitions in `proto/api/v1/*.proto` (8 service files: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`). These `.proto` files are the single source of truth and generate three interoperable API protocols:

1. **REST** — via gRPC-Gateway, with `google.api.http` annotations in the proto files mapping RPCs to HTTP endpoints under `/api/v1/*`. A generated OpenAPI 3.0.3 spec lives at `proto/gen/openapi.yaml`.
2. **gRPC** — native gRPC stubs generated into `proto/gen/api/v1/*_grpc.pb.go`, served by the `APIV1Service` in `server/router/api/v1/v1.go`.
3. **ConnectRPC** — browser-friendly RPC via `@connectrpc/connect`, registered at `/memos.api.v1.*` and handled in `server/router/api/v1/connect_handler.go`. This is what the React frontend uses.

Code generation is driven by `buf`, configured in `proto/buf.gen.yaml`.
