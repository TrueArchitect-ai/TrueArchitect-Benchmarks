The outbound delivery executes in the **`Post`** function at `internal/webhook/webhook.go` (line ~120), which builds an HTTP POST request and sends it via a custom `safeClient`. Asynchronous dispatch is handled by `PostAsync` (same file), which queues payloads for worker goroutines.

SSRF protection is a two-layer defense, both in `internal/webhook/`:

1. **Registration-time URL validation** — `ValidateURL` in `internal/webhook/validate.go` (line ~62) resolves the hostname and checks every resulting IP against `isReservedIP` (same file, line ~44), which blocks RFC-1918 private ranges, loopback, link-local (including the cloud metadata endpoint `169.254.169.254`), and IPv6 equivalents.

2. **Connection-time dial guard** — `safeDialContext` in `internal/webhook/webhook.go` (line ~59) re-resolves DNS at dial time and re-checks against `isReservedIP`, defeating DNS rebinding attacks where a hostname resolves to a safe IP at registration but a private IP at delivery time.
