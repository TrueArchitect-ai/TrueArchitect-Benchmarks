Every distinct enforcement site for memo visibility on the server, with files:

1. `GetMemo` / `checkMemoReadAccess` (single-memo read gate) — `server/router/api/v1/memo_service.go`
2. `ListMemos` (query-level `VisibilityList` filtering) — `server/router/api/v1/memo_service.go`
3. `CreateMemoComment` (private-memo comment guard + visibility inheritance) — `server/router/api/v1/memo_service_comments.go`
4. `ListMemoComments` (filter on comment visibility + `checkMemoReadAccess` on parent) — `server/router/api/v1/memo_service_comments.go`
5. `ListMemoRelations` (visibility filter on related memos) — `server/router/api/v1/memo_relation_service.go`
6. `buildRelationMapForMemos` (batch relation visibility filter) — `server/router/api/v1/memo_service_converter.go`
7. `ListMemoAttachments` (memo visibility check before listing attachments) — `server/router/api/v1/memo_attachment_service.go`
8. `ListMemoReactions` / `UpsertMemoReaction` (memo visibility check before listing/creating reactions) — `server/router/api/v1/reaction_service.go`
9. `checkAttachmentAccess` in `GetAttachment` (attachment access follows memo visibility) — `server/router/api/v1/attachment_service.go`
10. File server attachment serving (HTTP endpoint, separate from gRPC) — `server/router/fileserver/fileserver.go`
11. SSE event delivery filtering (`canReceive`) — `server/router/api/v1/sse_hub.go`
12. Mention/inbox notification guard (`canUserAccessMentionContext`) — `server/router/api/v1/memo_mention_helpers.go`
13. API notification rendering (`canViewerAccessMemo`) — `server/router/api/v1/user_service_notifications.go`
14. Email notification rendering (`canViewerAccessMemo`) — `server/notification/email.go`
15. RSS feed (public-only `VisibilityList`) — `server/router/rss/rss.go`
16. Sitemap generation (public-only `VisibilityList`) — `server/router/frontend/frontend.go`
17. User stats (query-level `VisibilityList` filtering) — `server/router/api/v1/user_service_stats.go`
18. `UpdateMemo` visibility inheritance for comments — `server/router/api/v1/memo_service.go`
