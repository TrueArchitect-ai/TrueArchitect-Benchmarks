**Go code (explicit deletion in two steps):**

The function `deleteUserTargetsTx` in each backend's `user_delete.go` runs two reaction-cleanup steps inside the same transaction:

1. **`deleteReactionsByContentIDsTx`** — deletes all reactions (by anyone) targeting the deleted user's memos via `DELETE FROM reaction WHERE content_id IN (...)`:
   - `store/db/sqlite/user_delete.go` ~lines 96–98 (call), ~lines 380–388 (implementation)
   - `store/db/postgres/user_delete.go` ~lines 96–98, ~lines 380–388
   - `store/db/mysql/user_delete.go` ~lines 96–98, ~lines 417–425

2. **`deleteReactionsByCreatorTx`** — deletes all reactions the deleted user placed on others' content via `DELETE FROM reaction WHERE creator_id = ?`:
   - `store/db/sqlite/user_delete.go` ~lines 102–104 (call), ~lines 400–403 (implementation)
