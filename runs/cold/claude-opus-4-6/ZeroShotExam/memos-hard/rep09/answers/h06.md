The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.created`
2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.updated`
3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.deleted`
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go`) — dispatches both `memos.memo.created` (via internal `CreateMemo` call) and `memos.memo.comment.created`
5. **`SetMemoAttachments`** (`server/router/api/v1/memo_attachment_service.go`) — dispatches `memos.memo.updated` via `dispatchMemoUpdatedSideEffects`
6. **`SetMemoRelations`** (`server/router/api/v1/memo_relation_service.go`) — dispatches `memos.memo.updated` via `dispatchMemoUpdatedSideEffects`

All paths converge on **`webhook.Post`** in `internal/webhook/webhook.go` (line ~120). This is the single function that constructs and executes the outbound `http.Request` to the user-configured URL (with optional HMAC-SHA256 signing). The async callers go through `webhook.PostAsync` (line ~184), which enqueues work onto a channel consumed by goroutines that each call `Post`.
