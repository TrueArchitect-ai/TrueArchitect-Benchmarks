**Computation site:** `server/runner/memopayload/runner.go` — the `RebuildMemoPayload` function calls `MarkdownService.ExtractAll()` (defined in `internal/markdown/markdown.go`) to parse the memo content via a goldmark AST walk and populate the memo's `Payload`.

**Triggers:** Recomputation is triggered on **memo create** (`server/router/api/v1/memo_service.go:108`) and **memo update** when the `"content"` field is in the update mask (`memo_service.go:~447`). A batch runner in `server/runner/memopayload/runner.go` (`Runner.RunOnce`) can also rebuild all memos in batches of 100 (for migration/repair). Additionally, the **snippet** is computed on-the-fly on every API response conversion (`memo_service_converter.go:~76`), not persisted.

**Extracted properties** (defined in `proto/store/memo.proto`, `MemoPayload.Property`):

- **`has_link`** (bool) — whether the content contains markdown links (`ast.KindLink`)
- **`has_task_list`** (bool) — whether the content contains task checkboxes (`east.KindTaskCheckBox`)
- **`has_code`** (bool) — whether the content contains code blocks or code spans
- **`has_incomplete_tasks`** (bool) — whether any task checkboxes are unchecked
- **`title`** (string) — text of the first heading if it is an H1
- **Tags** ([]string) — `#tag` nodes extracted via a custom `TagNode` AST type, deduplicated
- **Snippet** (string, computed on-the-fly) — plain-text summary truncated to 64 characters, generated by `GenerateSnippet` in `internal/markdown/markdown.go`
