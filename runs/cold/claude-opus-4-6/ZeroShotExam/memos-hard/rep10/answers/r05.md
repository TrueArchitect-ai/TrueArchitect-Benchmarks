There is no GraphQL schema in this repository. The premise is incorrect — the public API is not defined in GraphQL at all.

The API is defined using **Protocol Buffer (`.proto`) service definitions** in `proto/api/v1/`, with files such as `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, and others. Each service method carries `google.api.http` annotations that map RPCs to RESTful HTTP endpoints.

The actual API surface is exposed via three transports, all generated from those same `.proto` files:

1. **gRPC-Gateway (REST/JSON)** — registered at `/api/v1/*` in `server/router/api/v1/v1.go`, providing a conventional REST API for external consumers.
2. **Connect RPC** — registered at `/memos.api.v1.*` in the same file, used by the built-in web frontend (via `@connectrpc/connect-web`).
3. **gRPC stubs** — generated but not served on a separate listener; the service structs embed the `Unimplemented*Server` types.

Code generation is configured in `proto/buf.gen.yaml`, which drives Go gRPC stubs, Connect handlers, gRPC-Gateway REST handlers, OpenAPI spec generation, and TypeScript client types (output to `web/src/types/proto`).
