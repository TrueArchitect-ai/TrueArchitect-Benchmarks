The premise is incorrect — there is no Redis connection in this project. Memos uses a **pure in-memory cache** (`sync.Map`-based), not Redis.

The cache layer is implemented in `store/cache/cache.go` as a Go struct (`Cache`) backed by `sync.Map` with TTL-based expiration and a background cleanup goroutine. It is instantiated in `store/store.go:38-53`, where a single `cache.Config` is created and shared across three cache instances (`instanceSettingCache`, `userCache`, `userSettingCache`).

The **TTL for user entries is 10 minutes** — the same default applied to all three caches. This is set at `store/store.go:41`:

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
}
```

The `userCache` (`store/store.go:52`) is created with this config, giving user entries a 10-minute TTL. There is no Redis dependency anywhere in `go.mod` or the codebase.
