The package `internal/idp` (`internal/idp/idp.go`) defines the provider abstraction — it declares the `IdentityProviderUserInfo` struct that all identity provider implementations must produce. The concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements the OAuth2 flow with `ExchangeToken` and `UserInfo` methods.

**Answer:** `internal/idp`; `internal/idp/oauth2`
