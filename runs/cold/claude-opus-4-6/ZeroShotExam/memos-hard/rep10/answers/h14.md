**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go` (lines 74–88). It calls `markdownService.ExtractAll()` (defined in `internal/markdown/markdown.go`) to parse the memo content's markdown AST in a single pass and extract the derived metadata. The snippet is computed separately on-the-fly during API response conversion via `getMemoContentSnippet()` in `server/router/api/v1/memo_service_webhooks.go`.

**Triggers:** (1) **Memo creation** — called at `server/router/api/v1/memo_service.go:108`; (2) **Memo content update** — called at `server/router/api/v1/memo_service.go:447`; (3) **Batch rebuild on startup** — `Runner.RunOnce()` in `server/runner/memopayload/runner.go:27` iterates all memos in batches of 100 and rebuilds their payloads (a consistency/migration tool). The `snippet` is recomputed on every API read via the converter at `server/router/api/v1/memo_service_converter.go:76–80`.

**Extracted properties** (defined in `proto/store/memo.proto:15–22` as `MemoPayload.Property`):
- **`has_link`** (bool) — whether content contains markdown links
- **`has_task_list`** (bool) — whether content contains task checkboxes
- **`has_code`** (bool) — whether content contains code blocks or inline code spans
- **`has_incomplete_tasks`** (bool) — whether any task checkbox is unchecked
- **`title`** (string) — plain text of the first H1 heading, if the first block element is an `# H1`
- **`tags`** (string array) — `#tag` nodes extracted from the AST (stored in `MemoPayload.tags`)
- **`snippet`** (string, computed at read time) — a plain-text preview truncated to 64 characters at a word boundary, generated by `GenerateSnippet()` which strips markdown formatting
