Here are the distinct enforcement sites for memo visibility:

1. **GetMemo / single-memo read gate** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`, called by `GetMemo` and `ListMemoComments`)
2. **ListMemos query-level filtering** — `server/router/api/v1/memo_service.go` (visibility list / filter expression applied before DB query in `ListMemos`)
3. **ListMemoComments filtering** — `server/router/api/v1/memo_service_comments.go` (visibility filter on comment relations, plus `checkMemoReadAccess` on the parent)
4. **ListMemoRelations filtering** — `server/router/api/v1/memo_relation_service.go` (visibility filter when querying related memos)
5. **Batch memo-relation conversion filtering** — `server/router/api/v1/memo_service_converter.go` (`batchConvertMemoRelations` applies visibility filter)
6. **CreateMemoComment visibility check** — `server/router/api/v1/memo_service_comments.go` (checks parent memo visibility before allowing comment creation)
7. **ListMemoReactions / UpsertMemoReaction** — `server/router/api/v1/reaction_service.go` (inline visibility checks for listing and adding reactions)
8. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (visibility check before listing attachments)
9. **Attachment API access check** — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess` for linked attachments)
10. **File server attachment serving** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission` enforces visibility when serving files over HTTP)
11. **SSE event delivery filtering** — `server/router/api/v1/sse_hub.go` (`canReceive` filters which clients receive live memo events by visibility)
12. **Email notification guard** — `server/notification/email.go` (`canViewerAccessMemo` checks visibility before sending email notifications)
13. **Mention/inbox notification guard** — `server/router/api/v1/memo_mention_helpers.go` (`canUserAccessMentionContext` skips inbox items for private memos)
14. **User stats visibility filtering** — `server/router/api/v1/user_service_stats.go` (applies visibility list/filter in `ListAllUserStats` and `GetUserStats`)
15. **Database-level WHERE clause** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go` (SQL `WHERE memo.visibility IN (...)` when `VisibilityList` is set)
16. **Auth interceptor / ACL config** — `server/router/api/v1/acl_config.go` and `server/router/api/v1/authz.go` (controls which memo endpoints are reachable without authentication at all)
