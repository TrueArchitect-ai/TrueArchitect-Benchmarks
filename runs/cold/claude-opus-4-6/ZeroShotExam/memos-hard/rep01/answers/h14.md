**Computation site:** The core extraction happens in `internal/markdown/markdown.go` — specifically `ExtractAll()` (line 356), which parses memo content via goldmark, walks the AST in a single pass, and collects all derived properties. The rebuild is orchestrated by `RebuildMemoPayload()` in `server/runner/memopayload/runner.go` (line 74), which calls `ExtractAll()` and writes results back into `memo.Payload`. Additionally, `GenerateSnippet()` (`internal/markdown/markdown.go`, line 264) computes a plain-text snippet on-the-fly at API response time in `convertMemoFromStoreWithCreators()` (`server/router/api/v1/memo_service_converter.go`, line 76–82).

**Triggers:** Recomputation is triggered on two operations:
1. **CreateMemo** — `server/router/api/v1/memo_service.go`, line 108 calls `RebuildMemoPayload` before persisting.
2. **UpdateMemo** (when the `"content"` field is in the update mask) — same file, line 447.

A batch `RunOnce()` method in `server/runner/memopayload/runner.go` (line 27) exists for rebuilding all memos in bulk (migration/repair), but is not invoked at server startup.

**Extracted properties** (defined in `proto/store/memo.proto`, `MemoPayload.Property`):
- **`has_link`** (bool) — whether content contains any markdown link
- **`has_task_list`** (bool) — whether content contains GFM task checkboxes
- **`has_code`** (bool) — whether content contains code blocks or inline code
- **`has_incomplete_tasks`** (bool) — whether any task checkboxes are unchecked
- **`title`** (string) — plain text from the first block-level H1 heading (if the document starts with one)
- **`tags`** (repeated string) — all `#tag` occurrences extracted from content

Additionally, **`snippet`** (max 64 characters of plain text with markdown stripped) is computed on-the-fly per API response rather than persisted — generated by `GenerateSnippet()` and surfaced in lists, relation cards, and comment previews.
