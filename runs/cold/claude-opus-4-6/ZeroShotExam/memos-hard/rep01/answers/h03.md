The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all concrete implementations must produce. The concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), implementing the OAuth2 authorization-code flow (including PKCE support).
