The delivery function is **`Post`** in `internal/webhook/webhook.go` (lines ~120–179). It JSON-encodes the payload, builds an HTTP POST request (with optional HMAC-SHA256 signing), and sends it via a dedicated `safeClient`. The async path used by all call-sites is `PostAsync` (same file), which queues payloads into a buffered channel drained by background goroutines that call `Post`.

SSRF protection is a **two-layer defense** in `internal/webhook/validate.go` and `internal/webhook/webhook.go`:

1. **Registration-time URL validation** — `ValidateURL` in `internal/webhook/validate.go` resolves the hostname and checks every IP against a list of reserved/private CIDRs (loopback, RFC-1918, link-local/`169.254.0.0/16`, IPv6 ULA, etc.).
2. **Dial-time IP check** — `safeDialContext` in `internal/webhook/webhook.go` re-resolves the hostname at connection time and re-checks against the same reserved-IP list, defeating DNS-rebinding attacks.

**Delivery function — `internal/webhook/webhook.go`; protection mechanism — `internal/webhook/validate.go` (with dial-time enforcement in `internal/webhook/webhook.go`)**
