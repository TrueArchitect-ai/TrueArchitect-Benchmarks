— Premise is wrong: there is **no GraphQL schema** — no `graphql`/`gqlgen` dependency and no `.graphql`/schema definition anywhere in the repo. The actual public API surface is **Protobuf-defined RPC**, served two ways from the same `*APIV1Service` implementation:
- Schema source: `proto/api/v1/*.proto` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`; generated Go in `proto/gen/api/v1/` (Connect stubs in `proto/gen/api/v1/apiv1connect/`).
- Connect RPC handlers registered at `server/router/api/v1/connect_handler.go:31-45`; gRPC-Gateway REST/JSON transcoding registered by `(*APIV1Service).RegisterGateway` — `server/router/api/v1/v1.go:64` (via `*.pb.gw.go`), with an embedded OpenAPI doc (`proto/openapi_embed.go`).
- Non-RPC HTTP surfaces alongside it: the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), `/healthz` (`server/server.go:64`), and MCP (`server/router/mcp/service.go`, wired at `server/server.go:91-95`).
