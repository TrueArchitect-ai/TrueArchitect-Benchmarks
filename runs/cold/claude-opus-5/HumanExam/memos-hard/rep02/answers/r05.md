— Premise is wrong: there is no GraphQL schema or server in this repo (no `graphql` dependency, no `.graphql` files). The public API is Protobuf/gRPC-defined: schemas in `proto/api/v1/*.proto` with generated code in `proto/gen/api/v1/`. It is exposed over HTTP two ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`): grpc-gateway REST (`github.com/grpc-ecosystem/grpc-gateway/v2`) and Connect RPC (`connectrpc.com/connect`, `server/router/api/v1/connect_handler.go`, `connect_services.go`). Additional non-gRPC surfaces: `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss`), MCP (`server/router/mcp`), SSE, and `/healthz` (`server/server.go:65`).
