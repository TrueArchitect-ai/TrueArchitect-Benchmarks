— **False premise: there is no GraphQL schema or GraphQL endpoint** (no `graphql` dependency in `go.mod`, no match in Go sources or `web/`). The public API is Protobuf/Connect-RPC based: service definitions in `proto/api/v1/*.proto` with generated code in `proto/gen/api/v1` (+ `apiv1connect`), served by `APIV1Service` via Connect handlers and a gRPC-Gateway REST/JSON mapping registered in `RegisterGateway` (`server/router/api/v1/v1.go:64+`, `connect_handler.go`, `connect_services.go`). Additional non-RPC surfaces: HTTP file serving `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), MCP (`server/router/mcp/service.go`, registered `server/server.go:92-96`), and `/healthz` (`server/server.go:67`).
