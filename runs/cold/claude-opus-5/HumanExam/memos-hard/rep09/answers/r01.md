— Premise is wrong twice over: there is no Redis anywhere in the codebase (no `redis` import in go.mod or any `.go` file), and there is no per-entry TTL for users. The cache layer is an in-process map-based cache: `store/cache/cache.go` (`Cache.Close` at :187), configured in `store.New` — store/store.go:38-43 — with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`. Three instances exist: `instanceSettingCache`, `userCache`, `userSettingCache` (store/store.go:27-29). Users therefore get the shared 10-minute default TTL, not a Redis TTL; entries are written in `Store.ListUsers`/`GetUser` (store/user.go:143,167) and explicitly invalidated on delete via `deleteUserCache` (store/user_delete.go:39-46).
