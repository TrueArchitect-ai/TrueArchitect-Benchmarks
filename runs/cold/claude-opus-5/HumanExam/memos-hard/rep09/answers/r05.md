— Premise is wrong: there is no GraphQL schema or GraphQL server in this repo (no `.graphql`/`.graphqls` files, no gqlgen/graphql dependency in go.mod). The actual public API surface is Protobuf/gRPC-defined: service definitions in `proto/api/v1/*.proto` with generated code in `proto/gen/api/v1`, served over (a) Connect RPC handlers — server/router/api/v1/connect_handler.go, connect_services.go, and (b) a gRPC-Gateway REST/JSON mapping registered by `APIV1Service.RegisterGateway` (server/router/api/v1/v1.go:64+, wired at server/server.go:88). Additional non-gRPC surfaces: the HTTP file server `/file/...` (server/router/fileserver/fileserver.go:121-124), RSS feeds (server/router/rss/rss.go), an MCP endpoint (server/router/mcp/service.go, wired at server/server.go:92-96), and `/healthz` (server/server.go:67).
