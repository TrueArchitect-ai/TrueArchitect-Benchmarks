— **Premise is wrong: neither. There is no message broker** — no NATS, RabbitMQ, Kafka, or any broker client in `go.mod`, and no queue is declared anywhere. Webhook delivery uses an in-process Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`), drained by 4 goroutines started in the package `init()` (`internal/webhook/webhook.go:42-55`), each calling `webhook.Post` (`:120`). Producers call `webhook.PostAsync` (`:184`), which drops the event with a warning if the buffer is full (`:189-195`). The queue is unpersisted and in-memory, so pending deliveries are lost on restart.
