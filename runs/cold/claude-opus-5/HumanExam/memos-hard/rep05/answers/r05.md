— **Premise is wrong: there is no GraphQL schema or GraphQL server** in this repo (no `graphql` match in any Go file or in `go.mod`). The public API is **Protobuf/Connect-RPC**: service and message definitions live in `proto/api/v1/*.proto` with generated code in `proto/gen/api/v1/` and Connect handlers in `proto/gen/api/v1/apiv1connect/`. They are served three ways — Connect/gRPC handlers registered at `server/router/api/v1/connect_handler.go:37-44`, a gRPC-Gateway REST/JSON surface via `(*APIV1Service).RegisterGateway` (`server/router/api/v1/v1.go:64`, mounted at `server/server.go:88`), and an OpenAPI-derived MCP tool surface (`server/router/mcp/openapi.go`, `mcp.NewMCPService` at `server/server.go:92-96`). Additional non-RPC HTTP surfaces are the file server (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), and SSE (`server/router/api/v1/sse_handler.go`).
