False premise: there is no rate-limiting middleware in this codebase — no `golang.org/x/time/rate`, no `middleware.RateLimiter`, no per-user limiter, and no limits to report. The only Echo middleware registered is `middleware.Recover()` and the CORS middleware (`server/server.go:51-52`, `server/cors.go`). The Connect/gRPC chain is metadata → logging → recovery → auth only (`server/router/api/v1/v1.go:133-138`), with a request *size* cap (`connect.WithReadMaxBytes(maxAPIRequestBytes)`, `v1.go:141`) and concurrency semaphores for thumbnail/image work (`v1.go:59-60`, `server/router/fileserver/fileserver.go:117`) — none of which are rate limits.
