False premise: there is no GraphQL schema, server, or dependency in the repo (zero `graphql` hits). The public API surface is Protobuf-defined and served three ways: Connect RPC + gRPC-Gateway REST generated from `proto/api/v1/*.proto` (schemas in `proto/gen/api/v1`, wired in `server/router/api/v1/v1.go:95-141`, handlers in `server/router/api/v1/connect_services.go`), plus non-RPC HTTP surfaces — the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_hub.go`), an MCP endpoint (`server/router/mcp`), and `/healthz` (`server/server.go:65`). An OpenAPI document is embedded at `proto/openapi_embed.go`.
