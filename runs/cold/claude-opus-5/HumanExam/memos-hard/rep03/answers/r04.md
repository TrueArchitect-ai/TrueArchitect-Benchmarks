Premise is wrong: neither. No message broker of any kind is present (`grep -rni "nats|rabbitmq|amqp|kafka"` over Go files returns nothing; no broker dependency in `go.mod`). Webhook delivery uses an in-process buffered Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`), drained by 4 goroutines started in `init()` (`internal/webhook/webhook.go:42-53`) that call `Post` (`:120`). `PostAsync` (`:184`) does a non-blocking send and **drops** the event with a warning when the queue is full — there is no persistence, retry, or redelivery.
