Premise is wrong: there is no Redis anywhere in the repo (`grep -rni redis` over Go/config files returns nothing; no Redis client in `go.mod`). Caching is a process-local, in-memory `sync.Map`-backed cache — `store/cache/cache.go` (`Cache`, `Interface` at `:11`). The `Store` holds three instances: `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:26-30`), all built from one config with **DefaultTTL = 10 minutes**, CleanupInterval 5 minutes, MaxItems 1000 (`store/store.go:38-56`; identical defaults at `store/cache/cache.go:56-63`). User entries are set in `Store.ListUsers`/`GetUser` (`store/user.go:143,167`) and invalidated explicitly on delete (`store/user_delete.go:39-47`). Nothing survives a restart.
