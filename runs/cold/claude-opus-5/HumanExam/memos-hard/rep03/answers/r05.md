Premise is wrong: there is no GraphQL in this codebase (no schema files, no GraphQL dependency). The public API surface is:
- **gRPC/Connect + protobuf** — service definitions in `proto/api/v1/*.proto`, generated stubs in `proto/gen/api/v1/` and `proto/gen/api/v1/apiv1connect/`, handlers in `server/router/api/v1/` (registered via `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:64`; Connect wiring in `connect_handler.go`/`connect_services.go`).
- **REST/JSON via grpc-gateway** — `*.pb.gw.go` in `proto/gen/api/v1/`, plus an OpenAPI document (`proto/openapi_embed.go`).
- **Non-gRPC HTTP routes:** file server `/file/...` (`server/router/fileserver/fileserver.go:120-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), MCP (`server/router/mcp/`), and `/healthz` (`server/server.go:64`).
