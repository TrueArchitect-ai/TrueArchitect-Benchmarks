— Premise is wrong: there is no GraphQL schema or server in this repo (no `graphql` hits in Go, TS/TSX). The public API surface is Protobuf/gRPC-defined and served three ways from the same `APIV1Service`: (1) REST/JSON via grpc-gateway on `/api/v1/*` and `/file/*` (`server/router/api/v1/v1.go:96-129`), (2) Connect RPC on `/memos.api.v1.*` for browser clients (`server/router/api/v1/v1.go:139-144`), (3) generated code in `proto/gen/api/v1/` from the `.proto` definitions under `proto/api/v1/`. Non-RPC surfaces: SSE (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`), native file serving (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), MCP (`server/router/mcp/`), and `/healthz` (`server/server.go:64`).
