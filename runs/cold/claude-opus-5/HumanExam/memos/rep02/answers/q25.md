Engine: CEL (google/cel-go) via the in-repo memo filter engine in `internal/filter` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`; docs in `internal/filter/README.md`). Mechanism: the CEL expression is parsed and schema-validated, normalized into a dialect-agnostic IR, then rendered to a SQL fragment + args for a target dialect — the store drivers call `filter.DefaultEngine()` + `filter.AppendConditions(..., filter.DialectSQLite|DialectPostgres|DialectMySQL, &where, &args)` (`store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69`) so dialect differences (placeholders `?` vs `$n`, JSON access, `LIKE` vs `ILIKE`, tag containment) live in `internal/filter/render.go`.
