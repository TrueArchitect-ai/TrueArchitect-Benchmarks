`Store.DeleteMemo` (`store/memo.go:140-158`) deletes, before the memo row: memo_relation rows where the memo is the source (`MemoID`), memo_relation rows where it is the target (`RelatedMemoID`), and all attachments linked to the memo (row + underlying storage object via `Store.DeleteAttachment`, `store/attachment.go:132`). Additionally, the API handler first deletes all comment memos (`server/router/api/v1/memo_service.go:568-576`), each of which recurses through the same cleanup.
