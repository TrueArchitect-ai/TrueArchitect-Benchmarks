**Premise correction: there is no Redis anywhere in this repository.** A case-insensitive grep for `redis` across all Go sources, `go.mod`, `go.sum`, and YAML/JSON config returns zero hits — no client library, no connection string, no config key. The cache layer is a self-contained in-process implementation, so there is nothing to "configure a connection" for.

**Actual mechanism.** The cache is a thread-safe in-memory store built on `sync.Map`: `store/cache/cache.go`, type `Cache` (`store/cache/cache.go:66-72`) behind the `Interface` at `:11-32`. It holds `any` values keyed by string, with per-item expiration (`item` struct, `:35-39`), a background cleanup goroutine, and a `MaxItems` bound.

**Configuration site.** Not a connection — a `cache.Config` literal constructed in `store.New` (`store/store.go:39-44`):

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```

The same config value instantiates three independent caches at `store/store.go:51-53`: `instanceSettingCache`, `userCache`, `userSettingCache` (fields declared at `:27-29`). These are per-process, so in a multi-replica deployment each instance has its own unshared copy. `store/cache/cache.go:56-63` defines an identical `DefaultConfig()`, but `store.New` doesn't call it — it inlines the same values.

**TTL for user entries: 10 minutes.** Every write to `userCache` uses the plain `Set` — `store/user.go:98`, `:122`, `:132`, `:143`, `:167` — and `Set` forwards to `SetWithTTL` with `c.config.DefaultTTL` (`store/cache/cache.go:93-95`). No caller anywhere in the repo invokes `SetWithTTL` directly, so users get exactly the 10-minute default; expired entries are swept by the cleanup goroutine every 5 minutes.

Two related details on user caching: reads hit the cache only when the lookup is by `ID` (`store/user.go:149-156`), so a lookup by username always goes to the database, and user deletion explicitly invalidates the entry rather than waiting for TTL (`store/user_delete.go:40`).
