**Premise correction: there is no GraphQL in this repository.** Grepping every file (excluding `node_modules`) for `graphql`, `gqlgen`, `.graphqls`, or `schema.graphql` returns zero hits, and `find` turns up no `*.graphql*` files. There is no schema, no resolvers, and no GraphQL dependency in `go.mod` or the web app.

**Actual API surface: Protobuf/gRPC service definitions, exposed over three HTTP transports plus a generated OpenAPI spec.**

**Schema source of truth** — `.proto` files in `proto/api/v1/` (`proto/api/v1/README.md` documents them):
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`

Internal persistence messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`).

**Code generation** — driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`), which runs five plugins: protobuf-go, grpc-go, connect-go, grpc-gateway, and `google-gnostic-openapi`, plus `bufbuild/es` emitting TypeScript into `web/src/types/proto`. Output lands in `proto/gen/` (`proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, `apiv1connect/*.connect.go`).

**Runtime transports**, all wired in `server/router/api/v1/v1.go`:
1. **REST/JSON via grpc-gateway** — mux built at `:95-97`, handlers registered for all eight services at `:99-127`, mounted on `/api/v1/*` (and `/file/*`) at `:129-133`.
2. **Connect RPC** for browser clients (replacing grpc-web) — mux and handler at `:139-141`, mounted at `/memos.api.v1.*` (`:144`).
3. **SSE** for live updates — `RegisterSSERoutes(gwGroup, s.SSEHub, ...)` at `:125`.

**OpenAPI, not GraphQL, is the published API description**: generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` in `proto/openapi_embed.go`, exposed through `proto.OpenAPIYAML()`.

Two non-proto HTTP surfaces exist alongside this: the native file server (`server/router/fileserver/fileserver.go:121-125`, serving `/file/attachments/...` and `/file/users/:identifier/avatar`) and RSS feeds (`server/router/rss/rss.go`). There's also an MCP endpoint (`server/router/mcp`) that allowlists a subset of the same RPCs (`server/router/mcp/catalog.go`).
