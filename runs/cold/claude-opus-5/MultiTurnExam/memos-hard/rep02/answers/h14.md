**What's extracted.** `RebuildMemoPayload` calls `markdownService.ExtractAll(memo.Content)` and assigns two fields onto `memo.Payload` (`runner.go:80-87`):

- `Payload.Tags` — `#tag` names collected from `mast.TagNode`s, deduplicated with case preserved (`markdown.go:377-379`, `417`).
- `Payload.Property` (proto `memos.store.MemoPayload.Property`, `proto/store/memo.proto`):
  - `has_link` — a `gast.KindLink` node is present
  - `has_code` — any `CodeBlock`, `FencedCodeBlock`, or `CodeSpan`
  - `has_task_list` — any `TaskCheckBox`
  - `has_incomplete_tasks` — at least one unchecked `TaskCheckBox`
  - `title` — text of the first block-level child if it's an H1 heading (`markdown.go:383-389`)

All of it comes from a single goldmark AST walk. Two things `ExtractAll` computes are *not* persisted here: `Mentions` (returned in `ExtractedData` but dropped by `RebuildMemoPayload`, which is consumed separately at `server/router/api/v1/memo_mention_helpers.go:32`), and `Payload.Location`, which is user-supplied and set after the rebuild (`memo_service.go:111-112`) — worth noting because `RebuildMemoPayload` only overwrites `Tags` and `Property`, deliberately leaving the rest of an existing payload intact.
