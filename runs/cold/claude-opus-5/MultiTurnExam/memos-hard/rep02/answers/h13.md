**`*markdown.service` (the sole implementation) — constructed once by `NewAPIV1Service` via `markdown.NewService(WithTagExtension, WithMentionExtension)` — held by `APIV1Service`, `RSSService`, and (as a parameter) the memopayload helpers**

**Implementation.** The interface `markdown.Service` (`internal/markdown/markdown.go:31-56`) has exactly one implementer in the tree: the unexported `service` struct wrapping a `goldmark.Markdown` (`internal/markdown/markdown.go:58-61`). Because it's unexported and `NewService` returns the interface type (`internal/markdown/markdown.go:85-110`), no alternative implementation or mock can exist outside the package — there are no other declarers of `ExtractAll`/`GenerateSnippet`/`RenderHTML` etc. anywhere. Note the *configuration* differs by construction site even though the type doesn't: `NewService` conditionally appends `extensions.TagExtension` and `extensions.MentionExtension` on top of `extension.GFM`.

**Construction (production).** One call site: `NewAPIV1Service` at `server/router/api/v1/v1.go:48-51`, with both `markdown.WithTagExtension()` and `markdown.WithMentionExtension()` enabled, stored into `APIV1Service.MarkdownService` (`v1.go:56`). The same instance is then passed to the RSS service — `rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)` at `server/server.go:85` — so a default server runs a **single shared `*service`**. The other `markdown.NewService` calls are test-only: `server/router/api/v1/test/test_helper.go:44`, `server/router/fileserver/fileserver_test.go:427`, and `server/router/rss/rss_test.go:54` (that last one with *no* options, i.e. GFM only).

**Holders of the interface type:**
- `APIV1Service.MarkdownService markdown.Service` — `server/router/api/v1/v1.go:35`. Used for `ExtractAll` in mention handling (`memo_mention_helpers.go:32`), `GenerateSnippet` for webhook payload snippets (`memo_service_webhooks.go:85`), and passed into `memopayload.RebuildMemoPayload` on memo create/update (`memo_service.go:108,447`).
- `RSSService.MarkdownService markdown.Service` — `server/router/rss/rss.go:45`, injected via `NewRSSService` (`rss.go:58-62`), used for `RenderHTML` when building feed items (`rss.go:339`).
- `memopayload` holds it two ways — as a field on `Runner` (`server/runner/memopayload/runner.go:16`, set by `NewRunner` at line 19) and as a parameter to the package-level `RebuildMemoPayload` (`runner.go:74`). Only the parameter form is live: `memopayload.NewRunner` is never called in production code, so that `Runner` field is never populated.
