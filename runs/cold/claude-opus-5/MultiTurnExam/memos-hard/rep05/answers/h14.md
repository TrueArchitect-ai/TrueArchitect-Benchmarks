**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`. Triggers: `CreateMemo`, `UpdateMemo` (only when `content` is in the update mask), and `CreateMemoComment` (indirectly). Extracted: `Tags` plus the `Property` set — `HasLink`, `HasCode`, `HasTaskList`, `HasIncompleteTasks`, `Title`.**

**Where it's computed.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`) lazily allocates `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns exactly two fields: `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The payload is persisted as protojson in the memo row's `payload` column (see `store/db/sqlite/memo.go:20-26`). Note it deliberately does *not* touch `Payload.Location`, which is user-supplied and set separately at `server/router/api/v1/memo_service.go:112-114`.

The real work is `ExtractAll` (`internal/markdown/markdown.go:356-420`): a single goldmark AST walk that collects everything in one pass, then dedupes tags case-preservingly (`markdown.go:418-419`).

**Triggers (all in the API layer):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the `if path == "content"` branch of the update-mask loop (`:436`); the rebuilt payload is attached to the update at `:451`. Updating visibility, pinned state, etc. does **not** recompute.
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:56` calls `s.CreateMemo` internally, so comments get the same treatment.
- One dormant path: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) would rebuild payloads for all memos in batches of 100, but `NewRunner` has no callers, so it never executes.

**What's extracted** (`markdown.go:371-411`, property message defined at `proto/gen/store/memo.pb.go:85-95`):
- `Tags` — every `#tag` node, deduplicated with original case preserved.
- `Property.Title` — text of the first block-level child if it's an H1 heading (`markdown.go:384-388`).
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox; and `Property.HasIncompleteTasks` when at least one checkbox is unchecked (`markdown.go:399-404`).

`ExtractAll` also returns `Mentions` (lowercased `@username` nodes), but `RebuildMemoPayload` discards them — mentions are consumed separately for notifications via `server/router/api/v1/memo_mention_helpers.go:32`.

One related-but-distinct piece: the preview *snippet* is not stored. It's generated on demand by `GenerateSnippet` (`internal/markdown/markdown.go:264`), used only for webhook payloads at `server/router/api/v1/memo_service_webhooks.go:85` (64-char limit).
