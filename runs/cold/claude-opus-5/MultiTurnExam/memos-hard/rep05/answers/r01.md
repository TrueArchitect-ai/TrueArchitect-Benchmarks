**Premise correction: there is no Redis anywhere in this repository.** A case-insensitive search for "redis" across all Go sources, `go.mod`/`go.sum`, YAML, and docs returns zero hits. The cache layer is a hand-rolled, in-process, in-memory cache — nothing is externalized, and there is no connection to configure. Memos is designed as a single self-contained Go binary, so the cache lives in the server process and is lost on restart.

**Actual mechanism:**

- **Implementation** — `store/cache/cache.go`, a `Cache` type backed by `sync.Map` with per-item expiration (`item` struct at `cache.go:35-39`) behind an `Interface` (`cache.go:11-32`). A background goroutine sweeps expired entries and is shut down by `Close` (`cache.go:187`).

- **Configuration site** — `store.New` in `store/store.go:39-46`, which builds one `cache.Config` literal and shares it across all three caches:
  - `DefaultTTL: 10 * time.Minute`
  - `CleanupInterval: 5 * time.Minute`
  - `MaxItems: 1000`
  - `OnEviction: nil`

  There's an equivalent `cache.DefaultConfig()` at `store/cache/cache.go:57-61` with the same values, though `store.New` inlines its own copy rather than calling it. None of these are exposed as CLI flags or env vars — changing them requires a code edit.

- **The three caches** — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:27-29`), each constructed via `cache.New(cacheConfig)` at `store/store.go:51-53`.

**TTL for user entries: 10 minutes.** Every write to `userCache` uses the plain `Set` (`store/user.go:98, 122, 132, 143, 167`), and `Cache.Set` forwards to `SetWithTTL` with `c.config.DefaultTTL` (`store/cache/cache.go:93-95`) — no user-specific TTL override exists anywhere.

Two behavioral details worth knowing: the cache is only consulted for lookups **by ID** (`store/user.go:149-156`) — a lookup by username always hits the database — and entries are invalidated explicitly on user deletion via `s.userCache.Delete` (`store/user_delete.go:40`), so the 10-minute TTL is a staleness ceiling rather than the only eviction path.
