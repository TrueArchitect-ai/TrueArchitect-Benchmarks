**Premise correction: there is no GraphQL in this repository.** Searching every file (excluding `node_modules`) for `graphql`, `gqlgen`, `apollo`, and any `.graphql`/`.gql` file returns zero hits. No schema, no resolvers, no GraphQL dependency in `go.mod` or the web package.

**Actual API surface — Protobuf/gRPC, defined in `proto/api/v1/*.proto`:**

Eight services are declared in `.proto` files (the schema source of truth):

| Service | File |
|---|---|
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `AIService` | `proto/api/v1/ai_service.proto:11` |

Code generation is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/api/v1/` (Go structs, gRPC stubs, gateway handlers, and Connect handlers under `apiv1connect/`), plus TypeScript clients in `web/src/types/proto/`.

That one schema is exposed over **three wire protocols**, all wired in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65-144`):

1. **REST/JSON via gRPC-Gateway** — all eight services registered at `v1.go:95-122`, mounted on `/api/v1/*` and `/file/*` (`v1.go:128-129`), with auth middleware injected at `v1.go:96-98`.
2. **Connect RPC** — for browser clients, replacing grpc-web; handlers registered at `v1.go:139-144` on the path prefix `/memos.api.v1.*`, with metadata/logging/recovery/auth interceptors (`v1.go:133-138`).
3. **Server-Sent Events** — `RegisterSSERoutes` (`v1.go:125`) for live memo updates, backed by `SSEHub`.

The documented HTTP contract is an **OpenAPI 3 spec**, not a GraphQL schema: generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:5-11`.

There's also an **MCP** (Model Context Protocol) surface at `server/router/mcp/`, which adapts a curated subset of these same RPCs (e.g. `MemoService_ListMemos`, `server/router/mcp/catalog.go:12`) — again derived from the protobuf definitions, not a separate schema.
