**Premise correction: this project has no GraphQL API.** There is no schema file to point to — a search across the repo (excluding `node_modules`) finds zero `.graphql`/`.gql` files and zero references to `graphql`, `gqlgen`, or `apollo` in Go sources, `go.mod`, `package.json`, or the frontend. No resolvers, no schema-first SDL, no schema-stitching.

**Actual API surface — Protocol Buffers, exposed three ways:**

- **Schema definition (the real answer to "where is the schema"):** `proto/api/v1/*.proto` — eight service definitions: `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus `common.proto`. Internal persistence messages live separately under `proto/store/` (e.g. `proto/store/memo.proto`). Codegen is driven by `proto/buf.gen.yaml` / `proto/buf.yaml`, output into `proto/gen/`.

- **REST/JSON via gRPC-Gateway.** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) builds a `runtime.ServeMux` and registers all eight handlers (`v1.go:99-121`), mounted on an Echo group at `v1.go:123`. This is the `/api/v1/...` HTTP surface, with auth applied via `gatewayAuthMiddleware` (`v1.go:69`).

- **Connect RPC.** Generated clients/handlers in `proto/gen/api/v1/apiv1connect/*.connect.go`, with the server-side implementation in `server/router/api/v1/connect_services.go` (`ConnectServiceHandler`). This is what the web frontend uses.

- **OpenAPI, not GraphQL, is the published contract.** A spec is generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` at `proto/openapi_embed.go:4-11`, exposed through `proto.OpenAPIYAML()`. It's consumed internally by the MCP service to build its tool catalog (`server/router/mcp/service.go:78`, parsed with the types in `server/router/mcp/openapi.go`).

Three additional non-protobuf HTTP surfaces exist alongside: SSE (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`), the file server at `/file/*` (`server/router/fileserver/fileserver.go:121-125`), and RSS feeds (`server/router/rss/rss.go`).
