**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which delegates the parse to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`.

**Triggers:** two, both in the memo API:
- `CreateMemo` — `server/router/api/v1/memo_service.go:107` (after the content-length check, before `Store.CreateMemo`). This also covers `CreateMemoComment`, which creates its comment by calling `s.CreateMemo` at `server/router/api/v1/memo_service_comments.go:56`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but **only** when `"content"` is in the update mask (guarded by the `if path == "content"` branch at line 438); the recomputed `memo.Payload` is then assigned to `update.Payload` at line 451. Visibility-only, pinned-only, or location-only updates do not re-derive it.

There is a third, dormant path: `(*memopayload.Runner).RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds payloads for every memo in batches of 100 — but `memopayload.NewRunner` is never called anywhere, so it never executes.

**What it extracts** — written into `storepb.MemoPayload` (`proto/store/memo.proto:7`), assigned at `server/runner/memopayload/runner.go:85-86`:

- `Tags` (`payload.tags`, field 3) — every `#tag` node, deduplicated with original casing preserved via `uniquePreserveCase` (`internal/markdown/markdown.go:417`).
- `Property` (`payload.property`, field 1), a `MemoPayload.Property` with five derived fields (`proto/store/memo.proto:15-22`):
  - `has_link` — set on any `KindLink` node
  - `has_code` — set on `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`
  - `has_task_list` — set on any `KindTaskCheckBox`
  - `has_incomplete_tasks` — set when a task checkbox has `IsChecked == false`
  - `title` — text of the first block-level child *only if* it's an H1 heading (`internal/markdown/markdown.go:383-388`)

Note `ExtractAll` also collects `Mentions` (lowercased `@username` nodes) in its returned `ExtractedData`, but `RebuildMemoPayload` discards them — mentions are consumed separately for notifications at `server/router/api/v1/memo_mention_helpers.go:32`. The whole walk is a single AST pass, which is why `ExtractAll` exists alongside the narrower `ExtractTags`/`ExtractProperties` (`internal/markdown/markdown.go:143`, `:193`).

Also note `payload.Location` (field 2) lives in the same message but is *not* derived — it's set from user input at `server/router/api/v1/memo_service.go:111`, after the rebuild, precisely so the rebuild doesn't clobber it.
