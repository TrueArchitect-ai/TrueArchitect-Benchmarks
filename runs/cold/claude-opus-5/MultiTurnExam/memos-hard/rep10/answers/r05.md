**Premise correction: there is no GraphQL anywhere in this repository.** A case-insensitive search across all Go, TypeScript, JSON, and `go.mod` files for `graphql`, `gqlgen`, `.graphql`, and `resolver` returns only two hits, and both are false positives — `net.DefaultResolver` in `/bench/repo/internal/webhook/webhook.go:65` and `/bench/repo/internal/httpgetter/html_meta.go:23`. No schema file, no resolver layer, no GraphQL dependency.

**Actual API surface: Protocol Buffers / gRPC, exposed over three transports.**

**Schema definition** — `.proto` files under `/bench/repo/proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`

Internal persistence types live separately in `/bench/repo/proto/store/` (`memo.proto`, `user_setting.proto`, `idp.proto`, `inbox.proto`, `attachment.proto`, `instance_setting.proto`) — these are storage payloads, not API surface.

**Codegen** is driven by buf (`/bench/repo/proto/buf.yaml`, `/bench/repo/proto/buf.gen.yaml`), emitting into `/bench/repo/proto/gen/`:
- Go server stubs and gRPC-Gateway shims — `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`
- Connect handlers — `proto/gen/api/v1/apiv1connect/*.connect.go`
- TypeScript clients for the frontend — `web/src/types/proto/api/v1/*_pb.ts`
- An OpenAPI document embedded via `/bench/repo/proto/openapi_embed.go`

**Three transports, all registered in `APIV1Service.RegisterGateway` (`/bench/repo/server/router/api/v1/v1.go`):**

1. **REST/JSON via gRPC-Gateway** — handler mounted at `/api/v1/*` and `/file/*` (`v1.go:128-129`), with per-service `Register...HandlerServer` calls above (e.g. `v1.go:120`). This is the public HTTP API.
2. **Connect protocol** — for browser clients, replacing grpc-web; mounted at `/memos.api.v1.*` (`v1.go:144`) with the four interceptors at `v1.go:133-138`.
3. **Server-Sent Events** — `RegisterSSERoutes` (`v1.go:125`) for live memo updates, backed by `SSEHub`.

Alongside these, the server also exposes non-gRPC HTTP surfaces: the file server (`server/router/fileserver/fileserver.go:121`), RSS feeds (`server/router/rss/rss.go`), and an MCP endpoint (`server/router/mcp/`, registered at `server/server.go:96`).
