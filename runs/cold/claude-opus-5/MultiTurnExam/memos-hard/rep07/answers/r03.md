**Premise correction: there is no nightly database-cleanup job, and the cron scheduler is never instantiated by the server — so there is no scheduled time to report.**

Two separate corrections behind that:

1. **No job of any kind is registered with the scheduler.** `internal/scheduler` is a complete, tested cron package — `Scheduler.Register` (`internal/scheduler/scheduler.go:70`), `Scheduler.Start` (`internal/scheduler/scheduler.go`), cron-expression parsing (`internal/scheduler/parser.go`), middleware (`internal/scheduler/middleware.go`) — but it is **entirely unused by the application**. Searching for `scheduler.` outside `internal/scheduler` and outside tests returns nothing: `scheduler.New` is never called from `cmd/`, `server/`, or `store/`. The only non-test `.Register(` hit in the whole repo is inside a documentation comment, `internal/scheduler/doc.go:14`. Its ~12 `scheduler.New` call sites are all in `internal/scheduler/*_test.go` and `example_test.go`.

2. **The one real background job doesn't use cron and isn't a cleanup.** The server's only background runner is the S3 presign refresher, started in `startBackgroundRunners` (`server/server.go:153-174`). It runs on a fixed `time.Ticker` interval of 12 hours (`runnerInterval`, `server/runner/s3presign/runner.go:27`) plus one immediate pass at startup (`server/server.go:163`) — an interval, not a wall-clock time, so it has no "nightly" schedule; its phase depends on when the process started. And it refreshes presigned URLs rather than deleting anything.

For completeness, the deletion/cleanup work that does exist is all synchronous and request-driven, not scheduled: cascading deletes inside the `DeleteUser` transaction (`store/db/sqlite/user_delete.go:92-127`), attachment-storage cleanup on user delete (`server/router/api/v1/user_service.go:421-450`), and memo-delete cascades (`server/router/api/v1/memo_service.go:579`). The only genuinely periodic cleanup is in-memory, not database: the cache expiry sweep on a 5-minute `CleanupInterval` (`store/store.go:42`, loop at `store/cache/cache.go:83`).
