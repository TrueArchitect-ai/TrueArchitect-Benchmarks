**Premise correction: there is no GraphQL anywhere in this repository. Searching all Go, TypeScript, `go.mod`, and JSON files (excluding `node_modules`) for `graphql`, `gqlgen`, `.graphql`, and `apollo` returns zero hits — no schema file, no resolver layer, no client. The public API is Protobuf/gRPC-defined, exposed over three transports plus a generated OpenAPI document.**

**Actual API surface:**

- **Schema source of truth**: Protobuf service definitions in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. REST bindings are declared inline as `google.api.http` annotations (e.g. `proto/api/v1/memo_service.proto:30` → `get: "/api/v1/memos"`, `:35` → `get: "/api/v1/{name=memos/*}"`). Codegen is driven by `proto/buf.gen.yaml` / `proto/buf.yaml` into `proto/gen/`.

- **Transports**, all registered by `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):
  1. **gRPC-Gateway REST** — the `google.api.http` bindings served under `/api/v1/...` via the generated `proto/gen/api/v1/*.pb.gw.go`.
  2. **Connect RPC** — `connectMux` with `NewConnectServiceHandler(s)` (`server/router/api/v1/v1.go:139-141`), mounted on the path prefix `/memos.api.v1.*` (`:144`), with a request-size cap of `maxAPIRequestBytes`.
  3. **gRPC service definitions** themselves in `proto/gen/api/v1/*_grpc.pb.go` / `apiv1connect/`.

- **OpenAPI, not GraphQL, is the published schema document**: `proto/gen/openapi.yaml`, generated from the protos and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-6`, exposed through `OpenAPIYAML()` (`:9-11`).

- **Non-RPC HTTP surfaces** exist alongside: the file server (`/file/attachments/...`, `/file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:122-125`), RSS (`server/router/rss/rss.go`), the frontend/sitemap handler (`server/router/frontend/frontend.go`), `/healthz` (`server/server.go:67`), and an MCP endpoint (`server/router/mcp/service.go:107-108`) — the latter notably consuming the embedded OpenAPI spec at `server/router/mcp/service.go:78` to build its tool catalog.
