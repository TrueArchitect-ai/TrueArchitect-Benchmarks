The chain, with the resolution step in the middle:

1. **RPC → store facade**: `APIV1Service.CreateMemo` calls `s.Store.CreateMemo` at `server/router/api/v1/memo_service.go:115`.
2. **Facade → interface**: `Store.CreateMemo` validates the UID and delegates to `s.driver.CreateMemo` (`store/memo.go:109-114`). `driver` is the `store.Driver` interface, which declares `CreateMemo(ctx, *Memo) (*Memo, error)` at `store/driver.go:29`. This is the point where static reading alone can't tell you which of the three implementations runs — `store/db/sqlite/memo.go:16`, `store/db/postgres/memo.go`, and `store/db/mysql/memo.go` all satisfy it.
3. **Which implementation**: the interface value is whatever `db.NewDBDriver(profile)` returned (`cmd/memos/main.go:57`, passed into `store.New` at `:64`). That factory is a plain `switch profile.Driver` (`store/db/db.go:14-27`) — `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`.
4. **What `profile.Driver` is by default**: `Profile.Driver` is populated from `viper.GetString("driver")` at `cmd/memos/main.go:43`, and the default for that key is set explicitly: `viper.SetDefault("driver", "sqlite")` at `cmd/memos/main.go:122`. With no `--driver` flag and no `MEMOS_DRIVER` env var (env binding at `cmd/memos/main.go:167-169`), the value is `"sqlite"`. Corroborating: `Profile.Validate` special-cases exactly that default, synthesizing a DSN of `<data>/memos_prod.db` when `p.Driver == "sqlite" && p.DSN == ""` (`internal/profile/profile.go:110-116`) — so a flagless install is self-sufficient only on SQLite.
5. **Therefore** `sqlite.NewDB` (`store/db/sqlite/sqlite.go:24`) supplies the driver, and the concrete method that runs is `(*DB).CreateMemo` at `store/db/sqlite/memo.go:16`. It assembles the field/placeholder lists (`:17-39`), appends optional `created_ts`/`updated_ts`, and executes `INSERT INTO \`memo\` (…) VALUES (…) RETURNING \`id\`, \`created_ts\`, \`updated_ts\`, \`row_status\`` via `d.db.QueryRowContext` (`:41-42`), scanning the generated values back into the passed `*store.Memo`.

The underlying SQL engine is the pure-Go `modernc.org/sqlite`, registered via `functions.go` rather than a blank import (see the note at `store/db/sqlite/sqlite.go:9-10`).
