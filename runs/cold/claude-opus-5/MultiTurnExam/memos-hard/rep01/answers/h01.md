**s3presign background runner (`s3presign.Runner`, `server/runner/s3presign/runner.go:16`) — every 12 hours (plus one synchronous pass at startup) — wired in `server/server.go:162-171`, inside `startBackgroundRunners`, which is called from `Server.Start` at `server/server.go:129`.**

Details:

- **What it does** — `CheckAndPresign` (`server/runner/s3presign/runner.go:47`) pages through all attachments whose storage type is `S3` in batches of 100, re-signs each object with `s3Client.PresignGetObject`, and writes the fresh URL back as the attachment's `Reference` along with an updated `LastPresignedTime` (`runner.go:108-123`). That keeps stored S3 links from expiring.
- **Schedule** — `runnerInterval = time.Hour * 12` (`runner.go:27`); `Run` drives it off a `time.Ticker` and exits on context cancellation (`runner.go:29-41`). Startup also calls `RunOnce(ctx)` immediately before the loop goroutine starts (`server.go:163`).
- **Skip rule** — an attachment is skipped if its presigned URL is still valid for the next 4 days; URLs are issued with a 5-day expiry (`runner.go:85-91`).
- **Shutdown** — the runner gets its own cancelable context (`server.go:156`) whose cancel func is stored for `stopBackgroundRunners` (`server.go:159`, `176`), and the goroutine is tracked by `backgroundRunnerWG` so `waitBackgroundRunners` can join it (`server.go:166-171`, `184`).
