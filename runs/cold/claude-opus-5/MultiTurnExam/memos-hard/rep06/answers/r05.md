**Premise correction: there is no GraphQL anywhere in this repository — no `.graphql`/`.gql` schema files, no `gqlgen` or other GraphQL library in `go.mod` or the web `package.json`, and no occurrence of the string "graphql" in any Go or TypeScript source. The public API is defined by Protocol Buffers and exposed as REST + Connect/gRPC.**

The actual API surface:

- **Schema source of truth**: nine `.proto` service definitions under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Persistence-side message types live separately in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`).

- **REST mapping** comes from `google.api.http` annotations on each RPC, not a separate routing table — e.g. `post: "/api/v1/memos"`, `get: "/api/v1/memos"`, `get: "/api/v1/{name=memos/*}"`, `patch: "/api/v1/{memo.name=memos/*}"` (`proto/api/v1/memo_service.proto:22-43`). The API follows Google AIP resource-name conventions (`memos/{uid}`, `users/{user}`).

- **Code generation** is driven by buf (`proto/buf.gen.yaml`) with five backend plugins plus one frontend plugin: protobuf-go, gRPC-go, **connect-go**, **grpc-gateway**, **gnostic-openapi**, and `bufbuild/es` emitting TypeScript into `web/src/types/proto`. Output lands in `proto/gen/`.

- **Runtime wiring**: `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) builds a grpc-gateway `ServeMux` with a shared auth middleware and registers each service handler (`v1.go:99-110`, continuing for the rest). Connect handlers are registered alongside via `server/router/api/v1/connect_services.go` / `connect_handler.go`. All of it is mounted on Echo from `server/server.go:88`.

- **Machine-readable spec**: an OpenAPI document generated by the gnostic plugin, embedded into the binary at `proto/openapi_embed.go:5` (`//go:embed gen/openapi.yaml`) — this is the closest analogue to the "schema for the public API" the question asks about.

Non-protobuf HTTP surfaces served alongside it: `/healthz` (`server/server.go:67`), the file server at `/file/...` (`server/router/fileserver/fileserver.go:117-122`), RSS feeds (`server/router/rss/rss.go`), the MCP endpoint (`server/router/mcp`, registered at `server/server.go:96`), and the frontend static/sitemap routes (`server/router/frontend/frontend.go`).
