**Handlers: `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`; convergence function — `webhook.Post` at `internal/webhook/webhook.go:120` (the actual send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`)**

The six RPC handlers and their paths to delivery:

| RPC handler | Path |
|---|---|
| `CreateMemo` — `server/router/api/v1/memo_service.go:70` | → `DispatchMemoCreatedWebhook` (`memo_service.go:157`) |
| `UpdateMemo` — `server/router/api/v1/memo_service.go:401` | → `dispatchMemoUpdatedSideEffects` (`memo_service.go:513`) |
| `DeleteMemo` — `server/router/api/v1/memo_service.go:518` | → `DispatchMemoDeletedWebhook` (`memo_service.go:562`) |
| `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` | → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`) |
| `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:16` | → `dispatchMemoUpdatedSideEffects` (`memo_attachment_service.go:48`) |
| `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:16` | → `dispatchMemoUpdatedSideEffects` (`memo_relation_service.go:48`) |

The last two are the non-obvious ones: attaching a file or linking memos counts as an update, so both funnel through the shared `dispatchMemoUpdatedSideEffects` helper (`server/router/api/v1/memo_update_helpers.go:66-74`) and fire `memos.memo.updated` webhooks.

**Convergence.** All six reach `dispatchMemoRelatedWebhook` or `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48` and `:30`), which look up the target user's webhooks via `s.Store.GetUserWebhooks` — these are the user-configured URLs — and call `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` only enqueues onto a bounded channel (`internal/webhook/webhook.go:184-196`); the four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) all call **`webhook.Post`**, which is the single function where every path converges before an HTTP request leaves the process. `Post` marshals the payload, adds the HMAC signature headers, and issues the POST through the SSRF-guarded `safeClient`.

One adjacent path worth distinguishing: `GetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:46`) also makes an outbound request to a URL, but that URL comes from the request argument rather than stored user configuration, and it converges on `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go:136`) — a completely separate client with its own validation (`internal/httpgetter/html_meta.go:105`), not `webhook.Post`.
