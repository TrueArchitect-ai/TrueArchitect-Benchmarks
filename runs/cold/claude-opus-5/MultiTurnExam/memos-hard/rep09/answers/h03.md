**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction**: `internal/idp` (`internal/idp/idp.go`) — a minimal package defining the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation normalizes into. It's a shared data contract rather than a Go interface; there's no `Provider` interface type.
- **Implementation**: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol that ships. `NewIdentityProvider` validates the `storepb.OAuth2Config` (`oauth2.go:27`), `ExchangeToken` performs the authorization-code exchange with optional PKCE `code_verifier` (`oauth2.go:47`), and `UserInfo` fetches the userinfo endpoint and maps claims into `idp.IdentityProviderUserInfo` via the configured field mapping (`oauth2.go:83`).

Corroborating the "only one" claim: the store enum has exactly one non-unspecified member, `IdentityProvider_OAUTH2` (`proto/gen/store/idp.pb.go:27-28`, from `proto/store/idp.proto`), and the single consumer branches on just that value — `server/router/api/v1/auth_service_sso.go:120-130`.
