**web/src/connect.ts**

All eight service clients are created there with `createClient(...)` against a shared `createConnectTransport` (`web/src/connect.ts:184-203`): `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`.

The same file also holds the auth interceptor and token-refresh logic, plus a second, interceptor-free transport backing a private `refreshAuthClient` (line 72) — kept separate so the refresh call can't recurse through the 401-retry path.
