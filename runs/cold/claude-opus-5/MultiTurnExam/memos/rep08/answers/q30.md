**Convergence.** The created/updated/deleted three funnel through the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:47`), which resolves the memo's creator, loads `Store.GetUserWebhooks`, and calls `webhook.PostAsync` per hook. `DispatchMemoCommentCreatedWebhook` takes a slightly different route — it targets the *parent memo's* creator (`relatedMemoCreatorID`) rather than the comment author, so it builds its payload inline (lines 31-44) — but it lands on the same `webhook.PostAsync`.

`PostAsync` (`internal/webhook/webhook.go:184`) is a non-blocking enqueue onto `asyncPostQueue`; a full queue drops the event with a warning rather than blocking the request. Queue consumers call `Post` (line 120), which does the HMAC-SHA256 Standard Webhooks signing and the actual HTTP POST.
