- **ConnectRPC**: `ConnectServiceHandler.RegisterConnectHandlers` mounts `apiv1connect.NewMemoServiceHandler(s, opts...)` on the `http.ServeMux` (`server/router/api/v1/connect_handler.go:40`). The per-RPC method wrappers that adapt `connect.Request`/`connect.Response` to the plain `APIV1Service` methods live in `server/router/api/v1/connect_services.go` (e.g. `CreateMemo` at :306, `SignIn` at :78). This is the protocol the web client uses (`web/src/connect.ts`).
- **REST/JSON via grpc-gateway**: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (`server/router/api/v1/v1.go:108`) registers the same `APIV1Service` against a `runtime.ServeMux`, routed through Echo at `/api/v1/*` (`server/router/api/v1/v1.go:124-130`), wired up from `server/server.go:87-89`. URL paths come from the `google.api.http` annotations in `proto/api/v1/memo_service.proto`.

Both protocols share one implementation — the `APIV1Service` methods in `server/router/api/v1/memo_service.go`. Note the gateway uses `RegisterMemoServiceHandlerServer` (in-process, no gRPC socket), so there is no separately listening native gRPC server.
