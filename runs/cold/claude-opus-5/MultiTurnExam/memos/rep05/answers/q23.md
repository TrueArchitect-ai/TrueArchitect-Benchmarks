Two adjacent layers worth knowing about when changing the shape:
- The SQL schema exists per dialect — `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql` alongside the sqlite one, plus versioned migration files under `store/migration/<dialect>/<version>/`.
- The `Payload` field on the store model is its own proto (`proto/store/memo.proto` → `proto/gen/store/memo.pb.go`), not part of `message Memo` in the API proto.

Generated Go bindings for the API message live in `proto/gen/api/v1/memo_service.pb.go`; the TS file above is generated from the same proto, so both are regenerated rather than edited.
