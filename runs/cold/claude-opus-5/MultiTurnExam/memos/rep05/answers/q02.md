**sqlite, mysql, postgres**

- Migration directories: `store/migration/sqlite/`, `store/migration/mysql/`, `store/migration/postgres/` — each with versioned `<version>/NN__*.sql` files plus a `LATEST.sql` full schema.
- They're embedded and selected by driver at runtime in `store/migrator.go:44-45` (`//go:embed migration`) via `getMigrationBasePath()`, which keys off the configured driver.
