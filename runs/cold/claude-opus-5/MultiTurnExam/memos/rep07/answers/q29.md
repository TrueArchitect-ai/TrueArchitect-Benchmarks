**web/src/connect.ts; JWT access token (in-memory/localStorage) + JWT refresh token (HttpOnly `memos_refresh` cookie), with Personal Access Tokens as an alternative bearer credential; server/auth**

**Interceptor.** `authInterceptor` at `web/src/connect.ts:156-178`, installed on the shared Connect transport at `:184-189`. Per request it calls `getRequestToken()` (`:124`) and sets `Authorization: Bearer <token>`. On a `Code.Unauthenticated` response it refreshes once, retries with an `X-Retry: true` marker to prevent loops, and on failure calls `redirectOnAuthFailure()` (`:164-176`).

**Tokens it manages.**
- *Access token* — short-lived JWT, held client-side in `web/src/auth-state.ts` (`getAccessToken`/`setAccessToken`/`isTokenExpired`). The interceptor also refreshes *proactively* when the token is within 30 s of expiry (`REQUEST_TOKEN_EXPIRY_BUFFER_MS`, `auth-state.ts:18`), specifically so public endpoints like `ListMemos` don't silently return guest-scoped data (`connect.ts:136-147`).
- *Refresh token* — never touched by JS; it rides as an HttpOnly cookie, which is why every transport uses `fetch` with `credentials: "include"` (`connect.ts:57-62`). Refresh goes through `AuthService.RefreshToken` on a **separate interceptor-free transport** (`connect.ts:65-72`) to avoid recursion, and concurrent refreshes are deduplicated by `tokenRefreshManager` (`connect.ts:30-51`, `:89`).

**Backend validation.** Package `server/auth` — token minting/parsing constants and claims in `server/auth/token.go` (access token 15 min / `user.access-token`, refresh token 30 days / `user.refresh-token`, cookie `memos_refresh`, PAT prefix `memos_pat_`, lines 34-52), and verification in `server/auth/authenticator.go` (`AuthenticateToUser` resolves the `Authorization` header first — access token or PAT via `AuthenticateByPAT` at `:102` — then falls back to the refresh cookie). It's invoked from the Connect auth interceptor (`server/router/api/v1/connect_interceptors.go`, wired at `server/router/api/v1/v1.go:137`), the grpc-gateway middleware (`server/router/api/v1/v1.go:88`), and the file server.
