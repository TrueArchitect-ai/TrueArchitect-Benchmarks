**Runners actually started** (all in `Server.startBackgroundRunners`, `/bench/repo/server/server.go:150-171`):

```
s3presign.Runner — one immediate RunOnce at startup, then a 12-hour time.Ticker loop (server/runner/s3presign/runner.go)
```

That is the only background runner the server launches. Detail: `s3presignRunner.RunOnce(ctx)` fires synchronously at `server/server.go:159`, then `Run(s3Context)` loops on `time.NewTicker(runnerInterval)` with `runnerInterval = 12h` (`server/runner/s3presign/runner.go:26-40`), cancelled on shutdown via the stored `context.CancelFunc` (`server/server.go:173-179`).

Two related things that are *not* background runners:
- `server/runner/memopayload` — despite living under `server/runner/`, it has no loop; `RebuildMemoPayload` is called synchronously from the API handlers (`server/router/api/v1/memo_service.go:108` and `:447`).
- `apiv1.SSEHub` — a long-lived goroutine-backed hub (`server/router/api/v1/sse_hub.go`), started as part of `NewAPIV1Service` and event-driven, not scheduled.
