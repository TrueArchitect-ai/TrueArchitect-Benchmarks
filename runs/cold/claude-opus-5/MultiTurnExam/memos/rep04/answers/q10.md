**store/migration/sqlite/LATEST.sql**

On a fresh install `Store.preMigrate` sees `IsInitialized` return false and applies `getMigrationBasePath() + LatestSchemaFileName` — i.e. `migration/{driver}/LATEST.sql` from the embedded FS (`store/migrator.go:211-232`, with the path helper at line 254 and the constant at line 56). For `driver = sqlite` that resolves to `store/migration/sqlite/LATEST.sql`, which contains the full set of `CREATE TABLE` statements rather than the incremental per-version files.
