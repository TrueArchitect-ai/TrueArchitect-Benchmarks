**Engine: Google CEL (`github.com/google/cel-go`), wrapped by the in-repo `internal/filter` package — `internal/filter/engine.go`**

**Mechanism:** `Engine.Compile` type-checks the CEL expression against a field schema and lowers it to a dialect-agnostic condition tree (IR), which `CompileToStatement`/the renderer then emits as a parameterized SQL `WHERE` fragment for the requested `DialectName` (`sqlite` | `mysql` | `postgres`), so each driver gets dialect-correct SQL from one parse.
