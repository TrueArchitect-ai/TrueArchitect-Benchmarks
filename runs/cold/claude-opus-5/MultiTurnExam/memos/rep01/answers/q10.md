**store/migration/sqlite/LATEST.sql**

On a fresh install the migrator's `preMigrate` path reads `getMigrationBasePath() + LatestSchemaFileName` (`store/migrator.go:218`), where the base path is `migration/<driver>/` (`store/migrator.go:255`) and the filename constant is `LATEST.sql` (`store/migrator.go:56`) — so for `driver=sqlite` that resolves to the embedded `store/migration/sqlite/LATEST.sql`. This is documented in the migrator comments at `store/migrator.go:27` and `:42`, and covered by `TestFreshInstall` in `store/test/migrator_test.go:18`.
