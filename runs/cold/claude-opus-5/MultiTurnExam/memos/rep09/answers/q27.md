**Mechanism:** the Vite build output is compiled into `server/router/frontend/dist` and embedded into the Go binary with `//go:embed dist/*`, then served by Echo's static middleware with an SPA `index.html` fallback for unmatched routes.

**Path:** `/bench/repo/server/router/frontend/frontend.go` — `//go:embed dist/*` into `embeddedFiles` (lines 20-21); `FrontendService.Serve` mounts `middleware.StaticWithConfig` over the embedded FS (lines 41-57), adds `spaFallbackMiddleware` which returns `index.html` on 404s for HTML routes (lines 59, 63-80), and sets cache headers (`no-cache` for HTML, `max-age=3600`/`immutable` for hashed assets, lines 23-27).
