The Vite build output is compiled into the binary by `//go:embed dist/*` → `var embeddedFiles embed.FS` at `frontend.go:20-21`. `FrontendService.Serve` (line 40) turns that into an `fs.FS` via `getFileSystem("dist")` (helper at line 116, using `fs.Sub`) and registers `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` at line 54, so any request not claimed by the API routes is answered from the embedded assets. `spaFallbackMiddleware` (line 61) catches 404s on HTML-ish paths and serves `index.html` so client-side routes work on hard refresh.
