**MySQL, PostgreSQL, SQLite**

Migration files live under `store/migration/`, which has exactly three dialect directories, each with versioned subdirectories plus a `LATEST.sql`:

- `store/migration/mysql/` (0.17 → 0.30)
- `store/migration/postgres/` (0.19 → 0.30)
- `store/migration/sqlite/` (0.2 → 0.30)

These match the three driver implementations in `store/db/` (`mysql/`, `postgres/`, `sqlite/`). Note that seed data (`store/seed/`) is SQLite-only.
