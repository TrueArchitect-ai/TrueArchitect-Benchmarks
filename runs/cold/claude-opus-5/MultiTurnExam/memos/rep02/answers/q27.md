**Go `embed` of the built `dist/` bundle, served as static files by Echo middleware with an SPA fallback to `index.html`; server/router/frontend/frontend.go**

Specifics: `//go:embed dist/*` compiles the Vite build output into the binary (`server/router/frontend/frontend.go:20-21`), and `FrontendService.Serve` (:41) mounts it via `middleware.StaticWithConfig` over `fs.Sub(embeddedFiles, "dist")`. Any request that 404s and looks like a client route (path with no extension, or `/`) falls through `spaFallbackMiddleware` (:63) to `index.html`, which is what makes client-side routing work on deep links. API paths are excluded by `shouldSkipFrontendStatic` (:82), and cache headers differ between hashed `/assets/*` files and other static assets (:92-105). The same service also registers `/robots.txt` and `/sitemap.xml` (:123).
