The repo uses hand-written SQL per driver (no ORM tags); the store-layer structs are the table models.

| Table | Struct — path |
|---|---|
| `user` | `store.User` — `store/user.go:29` |
| `attachment` | `store.Attachment` — `store/attachment.go:16` |
| `reaction` | `store.Reaction` — `store/reaction.go:7` |

The table binding is in the driver SQL rather than struct tags — e.g. `INSERT INTO user (...)` in `store/db/sqlite/user.go:17`, ``INSERT INTO `attachment` `` in `store/db/sqlite/attachment.go:34`, and ``INSERT INTO `reaction` `` in `store/db/sqlite/reaction.go:16` (with parallel implementations under `store/db/postgres/` and `store/db/mysql/`).
