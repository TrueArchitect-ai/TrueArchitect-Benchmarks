**Mechanism:** Server-Sent Events (SSE) over a plain HTTP `GET /api/v1/sse` endpoint — `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `X-Accel-Buffering: no`, an initial `: connected` comment, a 30s `: heartbeat` comment ping, and `data: {json}\n\n` frames (`server/router/api/v1/sse_handler.go`). Auth is a Bearer token in the `Authorization` header, so the browser side uses a streaming `fetch` rather than `EventSource` (`web/src/hooks/useLiveMemoRefresh.ts:203`), and invalidates TanStack Query keys per event type.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`, 32-event buffered per-client channel, drops events for slow clients, `canReceive` filters `Private` memos to the creator or admins). Constructed at `server/router/api/v1/v1.go:57`, routed at `v1.go:125` via `RegisterSSERoutes`, and closed on shutdown at `server/server.go:205-206`.
