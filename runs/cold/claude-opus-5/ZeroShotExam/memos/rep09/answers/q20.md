**Server-Sent Events (SSE) over `GET /api/v1/sse`; hub at `server/router/api/v1/sse_hub.go` (`SSEHub`); broadcasting handlers: `CreateMemo`, `CreateMemoComment`, `DeleteMemo`, `UpsertMemoReaction`, `DeleteMemoReaction`, plus `UpdateMemo` / `SetMemoAttachments` / `SetMemoRelations` via the shared `dispatchMemoUpdatedSideEffects` helper.**

Details:

**Mechanism** — SSE (`text/event-stream`), not WebSockets. The endpoint handler is `server/router/api/v1/sse_handler.go`: it authenticates via a Bearer token (`auth.Authenticator`), sets `Content-Type: text/event-stream`, `Cache-Control: no-cache`, `X-Accel-Buffering: no`, writes an initial `: connected` comment, and sends `: heartbeat` comments every 30s (`sseHeartbeatInterval`). Routes are registered by `RegisterSSERoutes`, called from `server/router/api/v1/v1.go:125`. The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which consumes the stream and invalidates React Query caches (with exponential-backoff reconnect).

**Hub** — `server/router/api/v1/sse_hub.go`. `SSEHub` holds a mutex-guarded `map[*SSEClient]struct{}`; `Subscribe`/`Unsubscribe`/`Close`/`Broadcast`. Each client has a 32-event buffered channel, and `Broadcast` drops events for slow clients rather than blocking. Per-client filtering happens in `SSEClient.canReceive` — private memos only reach the creator or an admin. Event types (`sse_hub.go:15-21`): `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`. The hub is constructed in `v1.go:57` and closed on shutdown in `server/server.go:205`.

**Broadcast call sites** (`s.SSEHub.Broadcast(...)`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`; skipped when invoked from `CreateMemoComment` to avoid a duplicate)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created`)
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106` (`reaction.upserted`)
- `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:161` (`reaction.deleted`)
- `dispatchMemoUpdatedSideEffects` — `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`), the shared helper called by `UpdateMemo` (`memo_service.go:513`), `SetMemoRelations` (`memo_relation_service.go:48`), and `SetMemoAttachments` (`memo_attachment_service.go:48`)
