**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

This module holds the memo CRUD React Query hooks, all backed by `memoServiceClient`:

- `useMemoList` / `useInfiniteMemoList` → `memoServiceClient.listMemos` (`useMemoQueries.ts:113`, `:126`)
- `useMemo` (detail) → `memoServiceClient.getMemo` (`:146`)
- `useCreateMemo` → `createMemo` (`:183`)
- `useUpdateMemo` → `updateMemo` (`:202`, with optimistic cache patching + rollback)
- `useDeleteMemo` → `deleteMemo` (`:258`)
- plus `useMemoComments` → `listMemoComments` (`:276`, `:296`) and `useLinkMetadata` → `getLinkMetadata` (`:169`)

It also exports the `memoKeys` query-key factory (`:12`).

The client itself is a generated Connect-RPC client created in `web/src/connect.ts:197` — `createClient(MemoService, transport)`, where `MemoService` comes from the generated `web/src/types/proto/api/v1/memo_service_pb.ts` (`connect.ts:10`).
