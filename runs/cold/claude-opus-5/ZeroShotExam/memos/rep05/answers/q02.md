**SQLite, MySQL, PostgreSQL**

The embedded migration filesystem at `store/migration/` (`store/migrator.go:44-45`) has exactly three dialect subdirectories:

- `store/migration/sqlite/` — e.g. `LATEST.sql`, `0.30/00__user_tag_setting.sql`
- `store/migration/mysql/` — e.g. `LATEST.sql`, `0.27/04__memo_share.sql`
- `store/migration/postgres/` — e.g. `LATEST.sql`, `0.28/00__user_identity.sql`

The directory is selected at runtime by the configured driver: `store/migrator.go:254-256` builds the path as `migration/<profile.Driver>/`. Note that seed data (`store/seed/`) is SQLite-only — `store/migrator.go:266-268` explicitly skips seeding for other drivers.
