**DB — `store/db/postgres/postgres.go`**

The `postgres.DB` struct (`store/db/postgres/postgres.go:16-19`) implements the `store.Driver` interface for PostgreSQL. Details:

- `postgres.NewDB(profile)` opens a `database/sql` connection using the `github.com/lib/pq` driver and returns `&DB{...}` as a `store.Driver` (`store/db/postgres/postgres.go:21-39`).
- It's selected by driver name in the factory `NewDBDriver` at `store/db/db.go:15-32` (`case "postgres"`).
- The interface it satisfies is `store.Driver`, defined in `store/driver.go`; the rest of its methods are spread across the sibling files in `store/db/postgres/` (e.g. `memo.go`, `user.go`, `attachment.go`, `common.go`).

Note that the analogous structs for the other backends are also named `DB` — `store/db/sqlite/sqlite.go` and `store/db/mysql/mysql.go` — so the package qualifier matters here.
