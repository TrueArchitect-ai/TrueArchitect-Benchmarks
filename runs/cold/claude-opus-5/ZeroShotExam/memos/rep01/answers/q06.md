**`memo_relation`**

Defined in `store/migration/sqlite/LATEST.sql:47-52` (also `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, and introduced by `store/migration/sqlite/0.13/00__memo_relation.sql`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

`memo_id` is the source memo, `related_memo_id` the linked memo, and `type` distinguishes the kind of link (e.g. reference vs. comment).
