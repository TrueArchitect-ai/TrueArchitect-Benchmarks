`store.DeleteMemo` (`/bench/repo/store/memo.go:140-159`) cleans up two kinds of records before calling `s.driver.DeleteMemo` on the memo row:

1. **Memo relations** — deleted twice, once for rows where the memo is the source (`DeleteMemoRelation{MemoID: &delete.ID}`) and once where it is the target (`DeleteMemoRelation{RelatedMemoID: &delete.ID}`) — `store/memo.go:141-147`.
2. **Attachments linked to the memo** — listed via `ListAttachments(&FindAttachment{MemoID: &delete.ID})` and removed one by one with `s.DeleteAttachment` (`store/memo.go:148-157`), which also deletes the underlying stored file/blob before the DB row (`store/attachment.go:132-149`).

Then the memo row itself: `s.driver.DeleteMemo(ctx, delete)` → `DELETE FROM memo WHERE id = ?` (`store/db/sqlite/memo.go:237-248`).
