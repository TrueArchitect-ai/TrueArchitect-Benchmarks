**Engine:** Google CEL (`github.com/google/cel-go`, go.mod:13), wrapped by the in-repo package `internal/filter` — `internal/filter/engine.go` (compile), `schema.go` (CEL env + field metadata), `parser.go` (AST → IR), `ir.go` (condition tree), `render.go` (IR → SQL), `helpers.go` (`AppendConditions`). Docs: `internal/filter/README.md`, `internal/filter/MAINTENANCE.md`.

**Mechanism (one sentence):** `Engine.Compile` compiles the filter string with a CEL env declaring the allowed memo identifiers (`internal/filter/schema.go:NewSchema` — `content`, `creator`, `creator_id`, `created_ts`, `pinned`, `visibility`, `tags`, …), converts the CEL AST into a dialect-agnostic `Condition` tree (`parser.go`/`ir.go`), and then `Program.Render`/`CompileToStatement` walks that tree in `render.go` with a `RenderOptions{Dialect, PlaceholderOffset}` to emit a parameterized SQL fragment plus args, switching on `DialectSQLite`/`DialectMySQL`/`DialectPostgres` for per-dialect column expressions (e.g. `Field.Expressions`: `CONCAT('users/', %s)` on MySQL vs `('users/' || %s)` elsewhere; `UNIX_TIMESTAMP(%s)` for MySQL timestamps), JSON access, regex and boolean encoding, and placeholder style (`$N` for Postgres, `?` otherwise — `render.go:842`).

**Call path for ListMemos:**
- `server/router/api/v1/memo_service.go:211-215` — validates via `s.validateFilter` (`shortcut_service.go:336`, which compiles against the driver's dialect) and appends the raw filter string to `memoFind.Filters`; extra visibility filters are appended as CEL strings too (`memo_service.go:224`).
- Each store dialect then compiles it at query time: `store/db/sqlite/memo.go:57-62`, `store/db/mysql/memo.go:65-70`, `store/db/postgres/memo.go:54-59` all call `filter.DefaultEngine()` (process-wide singleton, `engine.go:111`) + `filter.AppendConditions(ctx, engine, find.Filters, <dialect>, &where, &args)` (`helpers.go:9`), which wraps each rendered fragment in parens and appends its args. An empty render (trivially-true filter) is skipped; an unsatisfiable one renders `1 = 0`.
