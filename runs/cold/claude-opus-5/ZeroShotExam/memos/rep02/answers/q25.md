**q25.**

**Engine + path:** Google CEL (Common Expression Language), via `github.com/google/cel-go`, wrapped by the in-repo memo filter engine in `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`; documented in `internal/filter/README.md`).

**Mechanism (one sentence):** `filter.DefaultEngine()` (`internal/filter/engine.go:110`) compiles the filter string with a CEL env restricted to the memo schema's declared variables (`internal/filter/schema.go:88` — `content`, `creator`, `creator_id`, `created_ts`, `pinned`, `tag`/`tags`, `visibility`, `has_task_list`, …, plus `now` and `ext.Sets()`), `parser.go` normalizes the CEL AST into a dialect-agnostic condition IR (`ir.go`) while enforcing schema/type/operator rules and folding `now`/`duration()`/`timestamp()` to epoch constants, and then `render.go` walks that IR to emit a parameterized SQL fragment for the target `DialectName` (`sqlite` | `mysql` | `postgres`), encapsulating per-dialect differences in helpers.

Supporting details:
- Call path: `ListMemos` (`server/router/api/v1/memo_service.go:178`) validates the filter via `validateFilter` (`server/router/api/v1/shortcut_service.go:336`, which compiles it against the driver's dialect) and pushes it into `memoFind.Filters`; each driver's `ListMemos` then calls `filter.AppendConditions(...)` — `store/db/sqlite/memo.go:57`, `store/db/postgres/memo.go:54`, `store/db/mysql/memo.go:65` — which appends `(<sql>)` to the WHERE list and its args (`internal/filter/helpers.go:9`). Note ListMemos also *injects* a server-side CEL filter for visibility (`creator_id == N || visibility in ["PUBLIC","PROTECTED"]`, `memo_service.go:222`).
- Dialect divergences in `render.go`: placeholders `?` vs `$n` with an offset for pre-existing args (`addArg`, `render.go:842`); JSON payload access via `json_extract` / `JSON_EXTRACT` / `->`,`->>` + boolean coercion (`renderJSONBoolComparison`, `render.go:357`); tag membership as `LIKE` (SQLite) / `JSON_CONTAINS` (MySQL) / `@>` (Postgres) (`renderTagInList`, `render.go:434`); `LIKE` vs `ILIKE` and regex `~*` vs `REGEXP` (`render.go:558`, `render.go:578`); timestamp columns wrapped in `UNIX_TIMESTAMP(%s)` for MySQL only, per-field `Expressions` maps in `schema.go`.
