`store/migration/sqlite/LATEST.sql`

**Why:** `store/migrator.go:42` documents it directly — *"LATEST.sql: Full schema for new installations (faster than incremental migrations)"* — and the filename constant is defined at `store/migrator.go:56` (`LatestSchemaFileName = "LATEST.sql"`). On startup, `Migrate` calls `preMigrate` (`store/migrator.go:101-102`), which detects an uninitialized DB and applies the latest schema file rather than replaying the per-version migrations in `store/migration/sqlite/0.x/*.sql` (`store/migrator.go:210-211`).

Note the related-but-different file `store/seed/sqlite/01__dump.sql`, which is demo seed data, not schema.
