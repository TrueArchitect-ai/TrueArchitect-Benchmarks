**Convergence for delivery:**

The three lifecycle events funnel through the unexported helper `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), which resolves the memo creator, loads their webhooks, and builds the payload. The comment event does its own webhook lookup (against the *related* memo's owner rather than the comment creator), so it bypasses that helper.

All four then converge on `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning when full). Four worker goroutines started in `init()` (webhook.go:42-55) drain the queue and call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single actual HTTP delivery point, which marshals the JSON body, adds Standard Webhooks HMAC-SHA256 signature headers when a signing secret is set, and posts via the SSRF-guarded `safeClient`.
