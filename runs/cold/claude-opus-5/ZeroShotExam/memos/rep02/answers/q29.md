**`web/src/connect.ts`; JWT access token (in-memory + localStorage, sent as `Authorization: Bearer`) and an httpOnly refresh-token cookie (`memos_refresh`), plus PATs supported server-side; `server/auth`**

**Frontend interceptor** — `authInterceptor` at `web/src/connect.ts:156`, registered on the Connect transport at `web/src/connect.ts:188` (all service clients — memo, user, auth, attachment, etc. — go through it). It:
- Calls `getRequestToken()` (`web/src/connect.ts:124`) to fetch the access token, doing a *preflight* refresh if it is within 30s of expiry, then sets `Authorization: Bearer <token>` (`connect.ts:97`).
- On a `Code.Unauthenticated` response, refreshes once and retries with an `X-Retry: true` header guard; if the refresh fails it calls `redirectOnAuthFailure()` (`connect.ts:161-177`).
- Refresh calls go through a separate transport with **no** interceptors to avoid recursion (`connect.ts:65-72`), hitting `AuthService.RefreshToken` with `credentials: "include"` so the refresh cookie is sent; concurrent refreshes are deduped by `tokenRefreshManager` (`connect.ts:30-51`).

**Token storage** — `web/src/auth-state.ts`: access token kept in memory and mirrored to `localStorage` under `memos_access_token` / `memos_token_expires_at`, with cross-tab sharing via a `memos_token_sync` `BroadcastChannel`. Proactive refresh on tab focus lives in `web/src/hooks/useTokenRefreshOnFocus.ts`.

**Backend validation** — package `server/auth` (`server/auth/token.go`, `authenticator.go`, `extract.go`, `context.go`). It defines the JWT scheme: 15-minute access tokens (`AccessTokenAudienceName = "user.access-token"`), 30-day refresh tokens (`RefreshTokenAudienceName`, cookie `memos_refresh`), and `memos_pat_`-prefixed Personal Access Tokens. `Authenticator.AuthenticateByAccessTokenV2` validates access tokens statelessly by signature; `AuthenticateByRefreshToken` additionally checks the DB for revocation.

The wiring into Connect RPCs is `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go:209-232`, which reads the `Authorization` header, delegates to the `Authorizer` (`server/router/api/v1/acl_config.go` holds the anonymous-access policy), and stores the result via `auth.ApplyToContext`. The static file server uses the same package at `server/router/fileserver/fileserver.go:709`.
