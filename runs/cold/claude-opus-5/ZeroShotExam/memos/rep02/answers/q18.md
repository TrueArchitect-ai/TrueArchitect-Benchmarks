The `store.Driver` interface is defined in `store/driver.go`. Three implementations, one per database backend:

- `store/db/sqlite/sqlite.go` — `sqlite.NewDB`
- `store/db/mysql/mysql.go` — `mysql.NewDB`
- `store/db/postgres/postgres.go` — `postgres.NewDB`

`NewDBDriver` — `store/db/db.go`

It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`), returning an error for anything else, and each package's `NewDB(profile)` returns a `store.Driver`.
