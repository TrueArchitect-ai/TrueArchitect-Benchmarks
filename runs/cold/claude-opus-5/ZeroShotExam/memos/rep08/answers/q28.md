**Workers the server actually starts**

- **S3 presign refresh runner** (`server/runner/s3presign/runner.go`) — started in `server/server.go:158-172`: one synchronous `RunOnce(ctx)` at startup, then a goroutine on a `time.NewTicker(12h)` loop (`runner.go:26-40`). Cancelled via its own `context.CancelFunc` and awaited on `backgroundRunnerWG` in `Shutdown` (`server/server.go:145-152, 174-206`).
- **HTTP serve goroutine** (`server/server.go:124-128`) — `http.Server.Serve(listener)`; runs until `Shutdown`. Event-driven, no schedule.
- **3× store cache cleanup loops** (`store/cache/cache.go:83`, loop at `:199-212`) — started implicitly by `store.New` → `cache.New` for `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:41-54`); driven by `CleanupInterval` ticker = **5 minutes** (`store/store.go:42`). Stopped by `Store.Close` (`store/store.go:72-79`).
- **4× webhook dispatch workers** (`internal/webhook/webhook.go:42-54`) — started in package `init()`, so they exist as soon as the binary links the package; driven by the buffered `asyncPostQueue` channel (cap 128), fed by `webhook.PostAsync` from memo create/update/delete (`server/router/api/v1/memo_service_webhooks.go:43,71`). Queue-driven, never timed; full queue drops the payload.
- **2× email send workers** (`internal/email/email.go:16-35`) — also package `init()`; driven by `asyncEmailQueue` (cap 128) fed via `email.SendAsync`, wired as the sender in `server/notification/email.go:30`.
- **Signal/shutdown goroutine** (`cmd/memos/main.go:96-100`) — triggered by SIGINT/SIGTERM.
- **Per-request fire-and-forget goroutine for PAT last-used timestamps** (`server/auth/authenticator.go:178-185`) — triggered per authenticated PAT request, not scheduled.
- **SSE**: no background worker. `SSEHub` (`server/router/api/v1/sse_hub.go`) is a pure mutex-guarded fan-out; the only loop is per-connection inside the request handler, driven by broadcast events plus a 30s heartbeat ticker (`server/router/api/v1/sse_handler.go:17,64`). The hub is only closed at shutdown (`server/server.go:208-213`).

**Unused scheduling infrastructure**

- **`internal/scheduler/`** — a complete cron scheduler (5/6-field parser, jobs, timezone handling, middleware, graceful stop; `scheduler.go`, `parser.go`, `job.go`, `middleware.go`, plus README/doc) is **never used by the server**. Its only importers are its own tests (`internal/scheduler/example_test.go:10`, `integration_test.go:13`). No job is ever registered and `scheduler.Start()` is never called in production code.
- **`server/runner/memopayload.Runner`** — `NewRunner`/`RunOnce` (`server/runner/memopayload/runner.go:19,27`) are never instantiated or started; `startBackgroundRunners` only wires s3presign. Only the free function `memopayload.RebuildMemoPayload` is used, called inline on the request path in `server/router/api/v1/memo_service.go:108,447`. So the memopayload backfill runner is dead scheduling infrastructure too.
