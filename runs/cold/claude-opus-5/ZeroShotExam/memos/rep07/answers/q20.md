**Mechanism:** Server-Sent Events (SSE) over a plain HTTP `GET /api/v1/sse` endpoint (`Content-Type: text/event-stream`, 30s heartbeat comments, Bearer-token auth), consumed in the browser by `EventSource`-style streaming in `web/src/hooks/useLiveMemoRefresh.ts` (which invalidates React Query caches on each event).

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`, a per-client buffered channel (32 events, dropped on overflow), and `SSEClient.canReceive` doing visibility filtering (private events only to the creator or admins). It's constructed in `server/router/api/v1/v1.go:57` (`NewSSEHub()`, field at `v1.go:36`), the route is registered at `v1.go:125` via `RegisterSSERoutes`, the HTTP handler lives in `server/router/api/v1/sse_handler.go`, event-construction helpers in `server/router/api/v1/sse_event_helpers.go`, and the server holds it at `server/server.go:38,77`.
