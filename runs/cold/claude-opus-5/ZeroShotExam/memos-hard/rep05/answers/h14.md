**Computation site**

- `memopayload.RebuildMemoPayload(ctx, memo, markdownService)` — `/bench/repo/server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, then calls the markdown service once and assigns `memo.Payload.Tags` and `memo.Payload.Property`.
- The actual extraction is `(*service).ExtractAll` in `/bench/repo/internal/markdown/markdown.go:356` — a single goldmark parse + one `ast.Walk` over the memo content. (`ExtractTags` at :137 and `ExtractProperties` at :193 are the same logic split into separate single-purpose passes.)
- The derived data is stored in the memo's payload blob (`MemoPayload.Property` / `tags`, `/bench/repo/proto/store/memo.proto:7-23`) and surfaced to clients via `convertMemoPropertyFromStore` (`/bench/repo/server/router/api/v1/memo_service_converter.go:315`) and `memoMessage.Tags` (same file, :48-49).

**Triggers**

1. `CreateMemo` — `/bench/repo/server/router/api/v1/memo_service.go:108`, on the `store.Memo` being created (before `Store.CreateMemo`); user-supplied `Location` is merged into the payload afterwards, at :112.
2. `UpdateMemo` — `/bench/repo/server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is written via `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, times) do not recompute it.
3. Batch backfill — `memopayload.Runner.RunOnce` (`runner.go:26-72`) walks all memos in batches of 100, rebuilds each payload and persists it with `Store.UpdateMemo`. Note: this runner is currently not wired into startup — `server/server.go:163` only invokes the s3presign runner, and `grep` finds no other reference to `memopayload.NewRunner`/`RunOnce`, so it's a dormant/maintenance path.

**Extracted properties**

From `ExtractAll` / `ExtractProperties`:
- `title` — text of the first block-level child of the document when it is an H1 heading (`extractHeadingText`, markdown.go:170).
- `has_link` — any `ast.KindLink` node.
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — any GFM `TaskCheckBox`.
- `has_incomplete_tasks` — a `TaskCheckBox` with `IsChecked == false`.

Alongside `Property`, the same pass yields `Tags` (`#tag` nodes, skipping tags nested in links/images via `asMemoTagNode`, deduped case-preserving) which is also stored on the payload; `Mentions` is extracted too but `RebuildMemoPayload` does not persist it (it's used by `memo_mention_helpers.go:32`).

One related but separate derived field: the list `snippet` is **not** stored — it's computed at read time per response by `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`memo_service_converter.go:76`, `:225`, `:248`).
