**Premise correction:** This repository (Memos, `github.com/usememos/memos`) has no GraphQL schema. There are zero GraphQL files, dependencies, or references anywhere in the tree — a case-insensitive search for "graphql" across all source, config, and docs returns nothing. The public API is not GraphQL.

**Actual API surface: Protocol Buffers → Connect RPC / gRPC-Gateway REST**

The schema of record is the `.proto` files in `proto/api/v1/`:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | MemoService |
| `proto/api/v1/user_service.proto` | UserService |
| `proto/api/v1/auth_service.proto` | AuthService |
| `proto/api/v1/attachment_service.proto` | AttachmentService |
| `proto/api/v1/instance_service.proto` | InstanceService |
| `proto/api/v1/shortcut_service.proto` | ShortcutService |
| `proto/api/v1/idp_service.proto` | IdpService |
| `proto/api/v1/ai_service.proto` | AiService |
| `proto/api/v1/common.proto` | Shared messages |

`proto/store/*.proto` holds internal storage messages — those are *not* public API.

**How it's defined and served**

- REST routes are declared inline on each RPC via `google.api.http` annotations. E.g. `proto/api/v1/memo_service.proto:22` maps `CreateMemo` to `POST /api/v1/memos`, and `ListMemos` to `GET /api/v1/memos`.
- Codegen is driven by `proto/buf.gen.yaml`, which runs protoc-gen-go, grpc-go, **connect-go**, **grpc-gateway**, gnostic-openapi, and buf's ES plugin. Outputs land in `proto/gen/` (Go + `proto/gen/openapi.yaml`) and `web/src/types/proto/` (TypeScript).
- The generated OpenAPI spec is embedded into the binary at `proto/openapi_embed.go` via `//go:embed gen/openapi.yaml` — that's the closest analogue to "a schema for the public API" you were probably looking for.
- Server wiring is in `server/router/api/v1/v1.go`: it builds a grpc-gateway mux (`runtime.NewServeMux`, line 96) and registers each service handler (e.g. `RegisterMemoServiceHandlerServer`, line 108). Public/unauthenticated routes are allowlisted in `server/router/api/v1/acl_config.go`.

Per `AGENTS.md` (lines 19, 67–68, 110–111): don't hand-edit generated output — change the `.proto` files and run `cd proto && buf generate`.

There's also a separate MCP server surface under `server/router/mcp/` (which derives its tool catalog from the same OpenAPI spec), plus an RSS router — but neither is GraphQL either.
