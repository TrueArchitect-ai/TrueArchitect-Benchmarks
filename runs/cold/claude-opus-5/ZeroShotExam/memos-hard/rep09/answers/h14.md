**Computation site; triggers; extracted properties**

**Computation site**

- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` sets `memo.Payload.Tags` and `memo.Payload.Property` from a single markdown parse.
- The actual extraction is `internal/markdown/markdown.go:356` — `(*service).ExtractAll(content)`, which parses the content once and walks the goldmark AST collecting everything in one pass.
- Shape of the derived data: `proto/store/memo.proto` → `MemoPayload.Property` (comment: "The calculated properties from the memo content"), generated as `proto/gen/store/memo.pb.go`.

**Triggers**

- **Memo creation** — `server/router/api/v1/memo_service.go:108` (in `CreateMemo`, before `Store.CreateMemo`; the user-supplied `location` is then merged onto the freshly built payload at line 112).
- **Content update** — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of `UpdateMemo`'s update mask; the rebuilt payload is written via `update.Payload = memo.Payload` (line 451). Other mask paths (visibility, pinned, state, timestamps, attachments, relations) do not recompute it; the `location` path (line 482) mutates the existing payload's location without re-deriving properties.
- **Bulk backfill** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds the payload for every memo in batches of 100 and persists each via `Store.UpdateMemo`. Note this runner is currently only defined, not invoked anywhere else in the tree (`server/server.go` wires only the `s3presign` runner).

**Extracted properties**

From `ExtractAll` (`internal/markdown/markdown.go:371-421`):

- `Tags` — text of every `TagNode` (`#tag`), deduplicated with case preserved.
- `Property.Title` — text of the first block-level child of the document *only if* it is an H1 heading (`markdown.go:384-389`).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `Property.HasTaskList` — any `east.KindTaskCheckBox`.
- `Property.HasIncompleteTasks` — a task checkbox with `IsChecked == false`.

(`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` does not store those — they're used for mention inboxes.)

These reach the API for list/preview rendering via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`) and `memoMessage.Tags` / `.Property` (lines 48-49). The list preview text itself (`Snippet`) is *not* part of the payload — it's computed on the fly per response by `getMemoContentSnippet` (converter lines 76-80, 221-252).
