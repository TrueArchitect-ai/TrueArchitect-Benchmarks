**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`**

The chain: handlers → `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:48` and `:30`), which read the target from `s.Store.GetUserWebhooks(...)` (`hook.Url`, `hook.SigningSecret`) → `webhook.PostAsync` (`webhook.go:184`, the shared enqueue point onto `asyncPostQueue`) → four background workers started in `init()` (`webhook.go:42-55`) call `webhook.Post`, which is the sole place the request is built and sent (`http.NewRequest("POST", requestPayload.URL, ...)` at `webhook.go:126`, `safeClient.Do(req)` at `webhook.go:152`).

Two related notes: `Post` is the only sender, and it goes through `safeClient`, whose `safeDialContext` (`webhook.go:59`) rejects reserved/private IPs at dial time as an SSRF guard; URLs are additionally validated on write by `webhook.ValidateURL` in the CRUD handlers (`user_service_webhooks.go:74,161,182`). Separately, `internal/idp/oauth2/oauth2.go:85` also fetches an admin-configured `UserInfoUrl`, but that is a different path and does not go through `webhook.Post`.
