**How I determined it among the three candidates**

There are three sibling implementations of `CreateMemo` — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`. Only one is reachable at runtime, chosen by config, not by build tags or interface dispatch on data:

1. **Call path is fixed and thin.** `server/router/api/v1/memo_service.go:115` calls `s.Store.CreateMemo(ctx, create)` → `store/memo.go:109-114`, which validates the UID and delegates straight to `s.driver.CreateMemo(ctx, create)`. `store.New` (`store/store.go:38-52`) stores the driver as-is — the caches there are for instance settings/users, so there is no decorator or fallback that could redirect the write.
2. **`s.driver` is picked by a single switch.** `store/db/db.go:14-30`: `switch profile.Driver { case "sqlite": sqlite.NewDB, case "mysql": ..., case "postgres": ..., default: error }`. So the answer reduces entirely to `profile.Driver`.
3. **Default value of `profile.Driver` is `"sqlite"`.** `cmd/memos/main.go:43` sets `Driver: viper.GetString("driver")`; the default is registered twice consistently — `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the flag default `rootCmd.PersistentFlags().String("driver", "sqlite", ...)` (`cmd/memos/main.go:130`), bound at line 151. With no `--driver` flag and no `MEMOS_DRIVER` env var, both resolve to `sqlite`. Corroborating: `internal/profile/profile.go:110` special-cases `Driver == "sqlite" && DSN == ""` to auto-derive `memos_prod.db` in the data dir — the only driver with a zero-config DSN path, which is what makes "no database flags" a working installation at all.
4. **Confirmed the concrete connection is SQLite**, not just the name: `sqlite.NewDB` opens `sql.Open("sqlite", profile.DSN+"?_pragma=...")` (`store/db/sqlite/sqlite.go:53`) against the `modernc.org/sqlite` driver registered in `store/db/sqlite/functions.go`.

Two secondary signals agreeing: the test helper `server/router/api/v1/test/test_helper.go:37` uses `Driver: "sqlite"` as its baseline, and `store/test/containers.go:304` sets `MEMOS_DRIVER=sqlite` for the default container config.
