**Computation site; triggers; extracted properties**

**Computation site**

- Orchestration: `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74` — ensures `memo.Payload` exists, calls the markdown service, and assigns `memo.Payload.Tags` and `memo.Payload.Property`.
- Actual extraction: `(*service).ExtractAll()` in `internal/markdown/markdown.go:356` — a single goldmark parse + one `gast.Walk` over the AST that collects everything in one pass. Heading text comes from `extractHeadingText()` / `extractTextFromNode()` (`internal/markdown/markdown.go:173-190`). A separate, equivalent single-purpose `ExtractProperties()` also exists at `internal/markdown/markdown.go:193` but nothing in the server currently calls it.
- Schema: `proto/store/memo.proto` — `MemoPayload.Property`, commented "The calculated properties from the memo content." Exposed to the API via `convertMemoPropertyFromStore()` in `server/router/api/v1/memo_service_converter.go:315` (used from the memo converter at line 49).

**Triggers (recomputation)**

1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`. This also covers `CreateMemoComment`, which delegates to `CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; other mask paths (visibility, pinned, location, etc.) leave the derived payload untouched.
3. Bulk rebuild: `Runner.RunOnce()` in `server/runner/memopayload/runner.go:27` walks every memo in batches of 100 and rewrites each payload. Note it appears to be dead code in the current tree — grep finds no construction of `memopayload.NewRunner` outside the package itself (`server/server.go:163` only starts the s3presign runner), so this path isn't wired into startup.

**Extracted properties**

From `ExtractAll` into `MemoPayload`:

- `Property.title` — plain text of the first H1, and only if that heading is the document's first block-level child (`markdown.go:383-388`); nested inline formatting is flattened to text.
- `Property.has_link` — any `gast.KindLink` node.
- `Property.has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `Property.has_task_list` — any `east.KindTaskCheckBox`.
- `Property.has_incomplete_tasks` — a task checkbox with `IsChecked == false`.
- `Payload.Tags` — memo tag nodes, deduplicated with original case preserved (`uniquePreserveCase`).

`ExtractAll` also returns `Mentions` (lowercased), but `RebuildMemoPayload` does not store those in the payload — they're used for mention notifications.

Consumers: the `has_*` flags back the list filters `property.hasLink` / `property.hasTaskList` / `property.hasCode` in `web/src/hooks/useMemoFilters.ts:73-77` and `web/src/components/MemoFilters.tsx:45-53`, and the user stats aggregation in `server/router/api/v1/user_service_stats.go:141-151`.
