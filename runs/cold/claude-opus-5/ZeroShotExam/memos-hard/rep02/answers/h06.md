**Path shape:** every handler above funnels into `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:30,48`), which reads the target from the user's stored webhook settings (`s.Store.GetUserWebhooks`), sets `payload.URL = hook.Url`, and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` only enqueues onto `asyncPostQueue`; four background workers started in `init()` (`internal/webhook/webhook.go:41-51`) drain that queue and call `Post`, so `Post` is the single point where the outbound request is built, HMAC-signed, and delivered.

The URL is user-configured through `CreateUserWebhook`/`UpdateUserWebhook` (`server/router/api/v1/user_service_webhooks.go`), which validate it with `webhook.ValidateURL` (`internal/webhook/validate.go`); at dial time `safeDialContext` (`internal/webhook/webhook.go:57`) additionally rejects reserved/private IPs.

Note: two other user/admin-configured-URL egress paths exist but converge elsewhere — the OAuth2 IdP `UserInfoUrl` fetch in `internal/idp/oauth2/oauth2.go:84-91`, and link-preview fetching in `internal/httpgetter/html_meta.go`. The webhook chain above is the one with a single shared delivery function.
