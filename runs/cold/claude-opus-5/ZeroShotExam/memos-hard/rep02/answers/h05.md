**Mechanism: explicit Go code** — reactions are deleted by hand-written `DELETE FROM reaction` statements inside each driver's `DeleteUser` transaction. There is no database-level cascade for reactions.

Two separate explicit deletes run per user deletion:
1. `deleteReactionsByContentIDsTx` — removes *all* reactions (including other users') on the deleted user's memos and their comment subtree, keyed by `content_id` = `"memos/" + memo.UID`.
2. `deleteReactionsByCreatorTx` — removes the deleted user's own reactions anywhere, keyed by `creator_id`.
