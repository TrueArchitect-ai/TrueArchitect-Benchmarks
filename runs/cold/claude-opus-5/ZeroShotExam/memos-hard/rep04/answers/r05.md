**Premise correction:** There is no GraphQL schema in this repository. Searching for `graphql` across all source, config, and doc files returns zero hits — Memos has no GraphQL server, no `.graphql`/SDL files, and no resolver layer. The README (`README.md:23`) states the integration surface plainly: "full REST and gRPC APIs."

**Actual API surface — Protocol Buffers, in `proto/api/v1/`**

The public API is defined as protobuf service definitions, one file per service:

| Service | File |
|---|---|
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `AIService` | `proto/api/v1/ai_service.proto:11` |

Shared types live in `proto/api/v1/common.proto`. Design conventions follow Google's AIPs (`proto/api/v1/README.md`). A separate `proto/store/*.proto` set defines internal persistence types, not the public API.

**How the surface is derived from the schema**

Codegen is driven by `buf` (`proto/buf.gen.yaml`), which emits four transports from the same `.proto` source into `proto/gen/`:

- **gRPC** — `*_grpc.pb.go`
- **Connect RPC** — handler implementations wired in `server/router/api/v1/connect_services.go`, mounted in `server/router/api/v1/connect_handler.go:48`
- **REST/JSON** — via grpc-gateway (`*.pb.gw.go`), registered in `server/router/api/v1/v1.go:96-126`. REST paths come from `option (google.api.http)` annotations on each RPC, e.g. `get: "/api/v1/memos"` at `proto/api/v1/memo_service.proto:30`.
- **TypeScript client** — generated into `web/src/types/proto` for the frontend

**The closest thing to a "schema document"** is the generated OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml` (4,057 lines), embedded into the binary by `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/openapi.go`.
