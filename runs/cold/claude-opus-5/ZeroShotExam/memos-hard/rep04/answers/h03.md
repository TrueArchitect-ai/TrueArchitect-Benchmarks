**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation maps its claims into.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the only concrete protocol implementation. It provides `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with optional PKCE `code_verifier`), and `UserInfo`, which fetches the userinfo endpoint and maps claims via the configured `FieldMapping` into `idp.IdentityProviderUserInfo`.

Wiring: `server/router/api/v1/auth_service_sso.go:120` branches on `storepb.IdentityProvider_OAUTH2` and constructs the OAuth2 provider — and OAuth2 is the sole value besides `TYPE_UNSPECIFIED` in the `IdentityProvider.Type` enum (`proto/store/idp.proto:11-13`), so no SAML/LDAP implementation ships.
