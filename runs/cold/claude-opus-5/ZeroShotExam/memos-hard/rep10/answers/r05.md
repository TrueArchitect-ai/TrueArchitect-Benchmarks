**Premise correction: there is no GraphQL schema in this repository.** A search for `*.graphql`/`*.gql` files, gqlgen configs, and any case-insensitive mention of "graphql" across Go, TS, Markdown, JSON, and YAML sources returns zero hits. Memos does not expose a GraphQL API.

**Actual API surface: Protobuf/gRPC, defined in `proto/api/v1/`.**

Schema definition (the hand-written source of truth):
- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`
- `proto/api/v1/README.md` states the design follows [Google AIPs](https://google.aip.dev/)
- Internal storage messages (not public API) live separately in `proto/store/`

Code generation — `proto/buf.gen.yaml` runs buf with plugins for: Go protobuf, gRPC, Connect, grpc-gateway, gnostic-openapi, and `bufbuild/es` emitting TypeScript clients into `web/src/types/proto`. Output lands in `proto/gen/`.

Three transports are served from one set of definitions, wired in `server/router/api/v1/v1.go:63` (`RegisterGateway`):
- **REST/JSON** via grpc-gateway, from `option (google.api.http)` annotations on each RPC (e.g. `proto/api/v1/memo_service.proto:30` → `GET /api/v1/memos`); mounted at `/api/v1/*` and `/file/*` (`v1.go:128-129`)
- **Connect RPC** for browser clients, mounted at `/memos.api.v1.*` (`v1.go:144`)
- **gRPC** proper, via the generated service servers embedded in `APIV1Service` (`v1.go:22-30`)

The generated OpenAPI spec at `proto/gen/openapi.yaml` is embedded via `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/service.go:78` to build its tool catalog.
