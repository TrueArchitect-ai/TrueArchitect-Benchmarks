**Premise correction:** Neither. This repo (memos) has no external message broker at all. There is no NATS, RabbitMQ, AMQP, Kafka, or Redis dependency — `go.mod`/`go.sum` contain no such client library, and the only `nats` substring anywhere in the tree is an accidental match inside Catalan words in `web/src/locales/ca.json` (e.g. "seleccionats", "Controla"). So there is no "queue declaration" in a broker sense — no exchange, subject, stream, or durable consumer is ever declared.

**Actual mechanism — an in-process buffered Go channel with a fixed worker pool:**

- **Queue declaration:** `internal/webhook/webhook.go:39` — `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`, a package-level buffered channel holding at most 128 pending payloads.
- **Workers:** `internal/webhook/webhook.go:42-55` — a package `init()` spawns exactly 4 goroutines, each ranging over `asyncPostQueue` and calling `Post(payload)`. Failures are logged via `slog.Warn` only; there is no retry, no ack, and no dead-letter path.
- **Producer:** `PostAsync` at `internal/webhook/webhook.go:184-196` does a non-blocking `select` send. When the buffer is full it hits the `default` branch and **drops the webhook**, logging "Dropped webhook dispatch because the async queue is full". A `nil` payload is likewise dropped.
- **Callers:** `server/router/api/v1/memo_service_webhooks.go:43` and `:71` fan out one `webhook.PostAsync` per registered user webhook for `memos.memo.created/updated/deleted` and `memos.memo.comment.created`.
- **Delivery itself** is a plain HTTP POST via a shared `http.Client` (`webhook.go:32-37`) whose transport uses `safeDialContext` (`webhook.go:59-77`) to block reserved/private IPs (SSRF/DNS-rebinding guard), with optional Standard Webhooks HMAC-SHA256 signing (`webhook-id` / `webhook-timestamp` / `webhook-signature` headers, `webhook.go:133-150`).

Practical consequence of there being no broker: the queue is per-process and purely in memory, so pending deliveries are lost on restart, are not shared across replicas, and are silently dropped under burst load past 128.
