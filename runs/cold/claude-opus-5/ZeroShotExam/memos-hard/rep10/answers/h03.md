**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — package `idp` defines the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any provider must produce.
- **Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — package `oauth2`, "implements the OAuth2 identity provider integration". It provides `IdentityProvider` built from `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (including PKCE `codeVerifier` support), and user-info retrieval via field mapping.

OAuth2 is the only concrete protocol that ships: the stored enum `IdentityProvider_Type` in `proto/gen/store/idp.pb.go:27-28` has just `TYPE_UNSPECIFIED = 0` and `OAUTH2 = 1`. The wiring lives in `server/router/api/v1/auth_service_sso.go`, where `resolveSSOIdentity` returns an `*idp.IdentityProviderUserInfo` produced by the oauth2 provider.
