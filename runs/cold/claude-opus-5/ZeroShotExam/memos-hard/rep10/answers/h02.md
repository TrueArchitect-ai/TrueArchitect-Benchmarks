**Where delivery executes**

- `webhook.Post` (`internal/webhook/webhook.go:120`) does the actual outbound HTTP POST: marshals the payload, optionally adds Standard-Webhooks HMAC headers (`webhook-id` / `webhook-timestamp` / `webhook-signature`), and calls `safeClient.Do(req)` at line 152.
- Callers never invoke `Post` directly — memo events call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded 128-slot channel drained by 4 worker goroutines started in `init()` (lines 42-55). Those workers are what actually run `Post`.
- Trigger points: `server/router/api/v1/memo_service_webhooks.go:43` (comment created) and `:71` (memo created/updated/deleted), which fan out over each of the creator's registered webhooks from `s.Store.GetUserWebhooks`.

**What protects it (SSRF)**

Two layers:

1. **Dial-time enforcement (the real guard)** — `safeClient` is built with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`:59`) re-resolves the hostname at connect time and rejects the dial if *any* resolved address is in a reserved range. Because the check happens at dial time rather than at save time, it also defeats DNS rebinding — the comment at lines 30-31 states this explicitly.
2. **Admission-time validation** — `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is called when a user creates/updates a webhook (`server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`). It enforces an absolute URL, an `http`/`https` scheme only, and that the hostname doesn't resolve to a reserved IP.

Both funnel through `isReservedIP` (`internal/webhook/validate.go:44`) against `reservedCIDRs` (`:14`): IPv4 loopback, all three RFC-1918 blocks, `169.254.0.0/16` (cloud IMDS, e.g. `169.254.169.254`), plus IPv6 loopback, ULA, and link-local. The CIDRs are parsed once into `reservedNetworks` in `init()` (`:28`), panicking on a malformed entry.

Two things worth flagging:

- There's an escape hatch: `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` to `false`, disabling both layers for self-hosted setups targeting LAN services. Grepping the tree, nothing outside `validate.go` ever assigns it — no flag, env var, or config wiring — so it is effectively hardcoded off unless a build patches it.
- The CIDR list is not exhaustive: `0.0.0.0/8`, CGNAT `100.64.0.0/10`, and IPv4-mapped IPv6 (`::ffff:127.0.0.1`, which `net.ParseIP` yields as a 16-byte form not matched by the IPv4 `net.IPNet` entries) aren't covered.

Response size is bounded separately via `io.LimitReader(resp.Body, 1<<20)` at `webhook.go:158`, with a 30s client timeout (`:27`).
