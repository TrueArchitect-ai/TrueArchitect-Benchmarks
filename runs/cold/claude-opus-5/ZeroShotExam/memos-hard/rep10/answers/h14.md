**Answer:** `memopayload.RebuildMemoPayload` (delegating to the markdown service's `ExtractAll`); triggered on memo create, on update when the mask includes `content`, and by the batch payload runner; extracts tags plus the property set `has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks`, and `title`.

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags` and `memo.Payload.Property` (leaving `Payload.Location`, which *is* user-set, untouched).
- The actual extraction is a single goldmark AST walk in `internal/markdown/markdown.go:356` (`ExtractAll`).
- Shape defined in `proto/store/memo.proto` — `MemoPayload.Property` is commented "The calculated properties from the memo content."

**Triggers**
1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the new payload is written via `update.Payload = memo.Payload` (line 451). Other mask paths (visibility, pinned, location, …) don't recompute; the `location` path only overwrites `Payload.Location` (line 482-484).
3. Bulk rebuild — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:28-70`) walks all memos in batches of 100, rebuilding and persisting each payload. Note: `NewRunner`/`RunOnce` for this runner is not referenced anywhere in the tree right now (only `s3presignRunner.RunOnce` is called in `server/server.go:163`), so today it's effectively a dormant/utility path.

**Extracted properties** (`internal/markdown/markdown.go:356-422`)
- `Tags` — every memo-tag node, deduplicated with original case preserved (`uniquePreserveCase`).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any task checkbox node.
- `Property.HasIncompleteTasks` — any task checkbox with `IsChecked == false`.
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading.
- (`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` does not store them in the payload.)

These reach the API in `server/router/api/v1/memo_service_converter.go:48-49` (`memoMessage.Tags` / `memoMessage.Property`) and are consumed for stats (`server/router/api/v1/user_service_stats.go:138-151`) and for the web filter chips `property.hasLink` / `property.hasTaskList` / `property.hasCode` (`web/src/contexts/MemoFilterContext.tsx:11-13`, `web/src/components/MemoFilters.tsx:45-53`). The list `snippet` is separate — computed per-request in the converter (`memo_service_converter.go:76`), not stored in the payload.
