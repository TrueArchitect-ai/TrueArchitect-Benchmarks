**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`

All six paths funnel through `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:43,71`), which only call `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` enqueues onto `asyncPostQueue`, and the four worker goroutines started in `init()` (`webhook.go:42-55`) call `Post`, which is the sole place the actual `http.NewRequest("POST", …)` + `safeClient.Do` happens (`webhook.go:126,152`), along with HMAC signing. Nothing else in the non-test code calls `Post` directly.

Note on scope: other outbound HTTP exists (`internal/idp/oauth2/oauth2.go:85` for admin-configured `UserInfoUrl`, `internal/httpgetter` for link previews, `internal/ai/stt` + `internal/ai/audiollm` for configured model endpoints), but those are separate delivery paths and don't pass through `webhook.Post`.
