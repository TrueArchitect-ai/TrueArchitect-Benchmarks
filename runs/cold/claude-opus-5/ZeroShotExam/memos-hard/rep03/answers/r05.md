**Premise correction:** There is no GraphQL schema in this repository. Memos does not expose a GraphQL API — a case-insensitive grep for `graphql` across the entire repo (excluding `.git`/`node_modules`) returns zero matches, and there are no `.graphql`/`.gql` files, no schema-definition code, and no GraphQL dependency in `go.mod` or `web/package.json`.

**Actual public API surface — Protocol Buffers:**

The public API is defined as `.proto` service definitions in **`proto/api/v1/`** (AGENTS.md itself labels this path "Public API service definitions"):

- `proto/api/v1/memo_service.proto` — `MemoService`
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared messages

(`proto/store/*.proto` is separate — internal storage messages, not public API.)

**How the schema becomes an API:**

- Codegen is driven by `proto/buf.gen.yaml` (`cd proto && buf generate`), emitting Go/Connect/gRPC-Gateway/OpenAPI into `proto/gen/` and TypeScript into `web/src/types/proto/`. Generated files must not be hand-edited.
- REST paths come from `google.api.http` annotations on each RPC — e.g. `post: "/api/v1/memos"` and `get: "/api/v1/{name=memos/*}"` in `proto/api/v1/memo_service.proto:20-35`.
- Three protocols over the same definitions: native gRPC, Connect RPC (`server/router/api/v1/connect_handler.go:30`, registering all eight service handlers), and gRPC-Gateway REST (`server/server.go:88`, `apiV1Service.RegisterGateway`).
- The nearest analogue to a "schema document" is the generated OpenAPI spec at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/service.go:78`.
- Design follows Google AIPs (`proto/api/v1/README.md`); handler implementations live in `server/router/api/v1/`, with unauthenticated route allowances in `server/router/api/v1/acl_config.go`.
