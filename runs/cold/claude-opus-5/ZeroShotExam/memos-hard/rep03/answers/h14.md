**Computation site**

- Core extraction: `internal/markdown/markdown.go` — `(*service).ExtractAll` (`markdown.go:356`), a single goldmark AST walk. A narrower `(*service).ExtractProperties` (`markdown.go:193`) does the property half only, but nothing in the memo write path calls it.
- Wrapper that writes the result onto the memo: `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)`, which sets `memo.Payload.Tags` and `memo.Payload.Property` from `ExtractAll` (`runner.go:85-86`).
- Storage shape: `proto/store/memo.proto:7-20` (`MemoPayload.Property`, commented "The calculated properties from the memo content"); surfaced to the API in `server/router/api/v1/memo_service_converter.go:47-50` and `convertMemoPropertyFromStore` (`memo_service_converter.go:315`).

**Triggers**

1. `CreateMemo` — `server/router/api/v1/memo_service.go:108` (inside `CreateMemo`, `memo_service.go:70`), before `Store.CreateMemo`.
2. `UpdateMemo` with `content` in the update mask — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is assigned to `update.Payload` at `:451`. Other update paths (visibility, pinned, state, times, attachments, relations) do not recompute; the `location` path only overwrites `Payload.Location` and leaves the derived fields alone (`:483-485`).
3. Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives the payload for every memo in batches of 100 and persists it. Note this runner is currently not constructed anywhere in the server — `grep` finds no `memopayload.NewRunner` call (`server/server.go` wires only `s3presign`), so in practice recomputation happens only on create and content-update.

**Extracted properties**

From the single AST walk (`markdown.go:369-410`, same logic as `ExtractProperties` at `markdown.go:200-240`):

- `Title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`); this is the preview/list title.
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any code block, fenced code block, or inline code span.
- `HasTaskList` — any `east.KindTaskCheckBox`.
- `HasIncompleteTasks` — any task checkbox with `IsChecked == false`.
- Alongside the property struct, `ExtractAll` also collects `Tags` (memo tag nodes, deduped, case preserved) and `Mentions` (lowercased usernames — used separately by `memo_mention_helpers.go:32`, not stored in the payload).

Consumers: filtering (`internal/filter/schema.go:224`, `web/src/hooks/useMemoFilters.ts:73-77`) and user stats (`server/router/api/v1/user_service_stats.go:141-152`). The per-memo `snippet` shown in lists is a separate, non-persisted value computed at conversion time (`memo_service_converter.go:76`).
