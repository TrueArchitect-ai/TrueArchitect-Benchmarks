**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the shared, protocol-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation normalizes to. It's the only type in the package — the abstraction is this common user-info contract rather than a Go interface.

- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the sole concrete protocol implementation, "Package oauth2 implements the OAuth2 identity provider integration." It wraps `storepb.OAuth2Config`, provides `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and user-info retrieval, returning `*idp.IdentityProviderUserInfo`.

Corroborating detail:
- `proto/proto/store/idp.proto` declares `IdentityProvider.Type` with only `TYPE_UNSPECIFIED` and `OAUTH2`, and `IdentityProviderConfig` is a `oneof` with a single `oauth2_config` member — so OAuth2 is the only shipped protocol.
- `server/router/api/v1/auth_service_sso.go:12-13` is the single consumer, importing both `internal/idp` and `internal/idp/oauth2` to resolve/provision SSO users.
