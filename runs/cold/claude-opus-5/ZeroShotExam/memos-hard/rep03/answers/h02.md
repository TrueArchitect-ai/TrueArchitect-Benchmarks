### Where delivery executes

- `webhook.Post()` (`internal/webhook/webhook.go:120`) is the only place an outbound HTTP request is actually made: it marshals the payload, optionally adds Standard-Webhooks HMAC headers (`webhook-id` / `webhook-timestamp` / `webhook-signature`), and calls `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.
- Callers never invoke it directly. `webhook.PostAsync()` (`internal/webhook/webhook.go:184`) enqueues onto a buffered channel (`asyncPostQueue`, capacity 128, drops with a warning when full), and a pool of 4 goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drains the queue by calling `Post`.
- The content-change triggers are in `server/router/api/v1/memo_service_webhooks.go` — `DispatchMemoCreatedWebhook` / `Updated` / `Deleted` via `dispatchMemoRelatedWebhook` (line 48), and `DispatchMemoCommentCreatedWebhook` (line 30). Each loads the user's hooks via `s.Store.GetUserWebhooks` and calls `webhook.PostAsync`.

### What protects it

Two layers, both keyed on the same predicate:

1. **Dial-time SSRF guard (the real protection).** `safeClient` is built with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59`) splits the address, resolves the host itself via `net.DefaultResolver.LookupHost`, and rejects the connection if *any* resolved IP is reserved. Because this runs at dial time rather than at save time, it also defeats DNS rebinding.
2. **Admission-time validation.** `webhook.ValidateURL()` (`internal/webhook/validate.go:62`) enforces absolute URL, `http`/`https` scheme only, and non-reserved resolution when a webhook is created or updated — called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`.

The blocklist itself is `reservedCIDRs` in `internal/webhook/validate.go:14-23` (IPv4 loopback, all three RFC-1918 ranges, `169.254.0.0/16` covering cloud IMDS at 169.254.169.254, plus `::1/128`, `fc00::/7`, `fe80::/10`), parsed once in `init()` and tested by `isReservedIP` (`internal/webhook/validate.go:44`).

Two things worth flagging:

- `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global kill switch that makes `isReservedIP` always return false, disabling *both* layers. Grepping the tree, it is never assigned anywhere outside its declaration — no flag, env var, or config wires it up, so it is effectively hardcoded `false` and the escape hatch for self-hosted local-network webhooks is unreachable today.
- The blocklist omits some ranges commonly included in SSRF filters — `0.0.0.0/8`, `100.64.0.0/10` (CGNAT), `192.0.0.0/24`, and IPv4-mapped IPv6 (`::ffff:127.0.0.1` parses to a 4-in-6 address; `net.IPNet.Contains` does normalize this, so `127.0.0.0/8` does catch it, but `::/128` and the mapped-address prefix aren't listed explicitly).
