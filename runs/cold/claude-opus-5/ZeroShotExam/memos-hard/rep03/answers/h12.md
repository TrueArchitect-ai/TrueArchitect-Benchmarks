2. **Dispatch point.** `profile.Driver` is read at `main.go:43` and passed to `db.NewDBDriver`, whose `switch profile.Driver` at `/bench/repo/store/db/db.go:18-27` returns `sqlite.NewDB(profile)` for `"sqlite"`. 3. **No decorator between store and driver.** `store.New(dbDriver, instanceProfile)` (`main.go:64`) stores the value verbatim (`/bench/repo/store/store.go:38,48`); there is no caching or wrapping implementation of `Driver` (`store/cache.go` only holds cache-key helpers).
