**Computation site** — `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parse to `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356` (single goldmark AST walk). The result is stored in `store.Memo.Payload` (`proto/store/memo.proto:6-25`) and surfaced to the API by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`).

**Triggers**
- Memo creation — `CreateMemo` calls it before `Store.CreateMemo` (`server/router/api/v1/memo_service.go:108`).
- Memo update — only when the update mask contains `content`; `UpdateMemo` reassigns `memo.Content` then rebuilds and writes both `update.Content` and `update.Payload` (`server/router/api/v1/memo_service.go:437-451`). Updates to visibility/pinned/state/timestamps do not recompute it.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:26`) re-derives the payload for every memo in batches of 100 and persists via `UpdateMemo`. Note this runner is currently not wired into `server/server.go` (only `s3presign.NewRunner` is registered there), so it's a rebuild utility rather than an active scheduled job.

**Extracted properties** — `ExtractAll` returns `ExtractedData{Tags, Mentions, Property}` (`internal/markdown/markdown.go:21-25`); `RebuildMemoPayload` persists `Payload.Tags` and `Payload.Property` (Mentions are not stored today). Concretely:
- `Tags` — every `#tag` node, deduplicated with original case preserved (`uniquePreserveCase`).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any `east.KindTaskCheckBox` node.
- `Property.HasIncompleteTasks` — a task checkbox with `IsChecked == false`.
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`).

These booleans drive the user stats aggregation in `server/router/api/v1/user_service_stats.go:141-153` and `:257-269`.

Separately, the list/preview `snippet` field is *not* part of this stored payload — it is computed per-response from content by `getMemoContentSnippet` / `GenerateSnippet` at conversion time (`server/router/api/v1/memo_service_converter.go:76`, `:225`).
