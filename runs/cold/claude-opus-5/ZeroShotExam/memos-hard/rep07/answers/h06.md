**Convergence function — `webhook.Post` at `internal/webhook/webhook.go:120`**

Path: each handler funnels through `dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go` (lines 48 and 30), which reads the user's saved webhooks via `s.Store.GetUserWebhooks`, sets `payload.URL = hook.Url`, and calls `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`webhook.go:42-55`) are the sole consumers and every one of them calls `Post`. `Post` is where the request is built (`http.NewRequest("POST", requestPayload.URL, ...)`, line 126), optionally HMAC-signed, and executed via `safeClient.Do(req)` (line 152).

Notes on the URL and its guards: the URL is user-configured through the webhook CRUD RPCs in `server/router/api/v1/user_service_webhooks.go`. `safeClient` uses a custom `safeDialContext` (`webhook.go:59`) that resolves the host and rejects reserved/private IPs at dial time as SSRF/DNS-rebinding protection.

Two other outbound-HTTP paths exist but do **not** pass through this function: `internal/idp/oauth2/oauth2.go:84-91` (admin-configured IdP `UserInfoUrl`, reached from the SSO sign-in path) and `internal/httpgetter/html_meta.go:31` (link-preview fetches). They each own their own `http.Client`, so `webhook.Post` is the convergence point only for the memo-webhook handlers above.
