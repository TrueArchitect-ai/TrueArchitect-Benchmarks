**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across the entire tree (excluding `.git`), including `go.mod` and `web/package.json`, returns zero matches. Memos does not expose a GraphQL API at all.

**Actual API surface: Protocol Buffers + gRPC, with REST and Connect RPC generated from the same `.proto` definitions.**

**Schema source of truth — `proto/api/v1/*.proto`:**

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Package is `memos.api.v1`. Design follows Google AIPs (`proto/api/v1/README.md`). REST routes are declared inline as `google.api.http` annotations on each RPC — e.g. `proto/api/v1/memo_service.proto:22-48` maps `CreateMemo` → `POST /api/v1/memos`, `GetMemo` → `GET /api/v1/{name=memos/*}`, `DeleteMemo` → `DELETE /api/v1/{name=memos/*}`.

**Code generation (`proto/buf.gen.yaml`)** — `cd proto && buf generate` produces:
- Go message/gRPC/Connect/gateway stubs → `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, `apiv1connect/`)
- OpenAPI spec → `proto/gen/openapi.yaml`, embedded into the binary via `proto/openapi_embed.go`
- TypeScript client types → `web/src/types/proto/`

Generated files must not be hand-edited (`AGENTS.md`).

**Serving (`server/router/api/v1/v1.go:65-146`, wired at `server/server.go:88`):**
- gRPC-Gateway mux handles REST at `/api/v1/*` and `/file/*` (`v1.go:128-129`)
- Connect RPC handlers for the browser client at `/memos.api.v1.*` (`v1.go:144`)
- Service implementations live in `server/router/api/v1/*_service.go`
- SSE streaming endpoints are registered separately (`server/router/api/v1/sse_handler.go`)
- Public/unauthenticated endpoints are enumerated in `server/router/api/v1/acl_config.go` — described there as the single source of truth, used by both the Connect interceptor and the gateway middleware
- An MCP server (`server/router/mcp/`) exposes a curated subset by reading `proto/gen/openapi.yaml`
