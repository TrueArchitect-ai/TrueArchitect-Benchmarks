### Concrete implementation
There is exactly one: the unexported `type service struct { md goldmark.Markdown }` (`internal/markdown/markdown.go:58-60`), wrapping goldmark. No mocks/fakes implement `Service` anywhere — `func (s *service) ExtractAll` at `internal/markdown/markdown.go:356` is the only implementation of the interface's methods in the repo, and tests use the real one. Internally it composes goldmark with `extension.GFM` plus the repo's own `extensions.TagExtension` / `extensions.MentionExtension` (`internal/markdown/extensions/{tag,mention}.go`), and delegates markdown-back-out to the concrete `renderer.NewMarkdownRenderer()` (`internal/markdown/renderer/markdown_renderer.go:20`), which is a plain struct, not behind an interface.
