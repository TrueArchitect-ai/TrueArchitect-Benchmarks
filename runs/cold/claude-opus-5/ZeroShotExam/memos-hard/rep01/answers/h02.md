## How it works

**Outbound delivery** happens in `webhook.Post` (`internal/webhook/webhook.go:120`). It marshals the payload to JSON, optionally attaches Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and issues the POST via the package-level `safeClient` (line 152). Callers don't invoke it directly — `PostAsync` (line 184) enqueues onto a bounded 128-slot channel drained by 4 worker goroutines started in `init()` (lines 42–55), so the actual HTTP call runs on a worker, not the request goroutine. The enqueue points are `server/router/api/v1/memo_service_webhooks.go:43` and `:71`, fired on memo created/updated/deleted and comment-created.

**SSRF protection is two-layered:**

1. **Dial-time enforcement (the real guard)** — `safeClient` is built with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (line 59) splits the address, resolves the host itself via `net.DefaultResolver.LookupHost`, and refuses the connection if *any* resolved IP is reserved. Because this runs at connection time rather than at save time, it also defeats DNS rebinding — the comment at lines 30-31 says so explicitly.

2. **Validation at configuration time** — `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and reserved-resolving hostnames when a user registers or updates a webhook, returning a gRPC `InvalidArgument`. Called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. This is UX/defense-in-depth; it's the dial-time check that's authoritative.

The blocklist is `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (explicitly covering the cloud IMDS endpoint `169.254.169.254`), plus IPv6 loopback, unique-local, and link-local. It's parsed once into `reservedNetworks` at package init, panicking on a malformed CIDR.

**Escape hatch:** `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` to `false`, disabling both layers. It's wired to the `--allow-private-webhooks` flag, default `false`, set in `cmd/memos/main.go:49` (flag declared at `:133`, bound to viper at `:160`) — intended for self-hosted deployments targeting LAN services.

One gap worth noting: `safeDialContext` validates the resolved IP set, then calls `Dialer.DialContext` with the *hostname* again (line 76), so the OS re-resolves independently. That's a narrow TOCTOU window — dialing the pre-validated IP directly would close it.
