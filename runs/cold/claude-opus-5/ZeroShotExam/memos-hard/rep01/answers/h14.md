**Computation site**

- `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, then assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (lines 85–86).
- The actual extraction is a single goldmark AST walk in `(*service).ExtractAll` — `internal/markdown/markdown.go:356-412` (an equivalent property-only walk exists as `ExtractProperties`, `internal/markdown/markdown.go:193`).
- Stored on the memo payload blob (`proto/store/memo.proto:15`, "The calculated properties from the memo content") and surfaced to the API as output-only `Memo.property` via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:49,315`; proto `proto/api/v1/memo_service.proto:255,271`).

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when `content` is in the update mask; the rebuilt payload is written via `update.Payload = memo.Payload` (line 451). Other mask paths (visibility, pinned, location, etc.) do not recompute it — the `location` path reuses the existing payload (line 482).
- Bulk backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27`, which pages all memos in batches of 100 and rewrites each payload. Note this runner is only constructed by `NewRunner` (line 19) and isn't wired up anywhere in `server/server.go` today, unlike `s3presign.NewRunner` (`server/server.go:162`) — so in practice it's dormant.

**Extracted properties**

From `ExtractAll` / `ExtractProperties`:
- `has_link` — any `gast.KindLink` node.
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — any GFM `east.KindTaskCheckBox`.
- `has_incomplete_tasks` — a task checkbox with `IsChecked == false`.
- `title` — text of the first block-level document child if it is an H1 heading (`extractHeadingText`).

Alongside these, the same pass fills `payload.tags` (deduped `#tag` nodes via `uniquePreserveCase`) and collects `@mentions` into `ExtractedData` (mentions aren't persisted in the payload).

Consumers: web filter factors `property.hasLink/hasTaskList/hasCode` (`web/src/hooks/useMemoFilters.ts:73-77`, `web/src/components/MemoFilters.tsx:45-53`) and user stats aggregation (`server/router/api/v1/user_service_stats.go:141-152`). The plain-text `snippet` field is a separate derivation (`markdown.GenerateSnippet`, used at `server/router/api/v1/memo_service_webhooks.go:85`), not part of the stored payload.
