**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go:1-8`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every IdP implementation normalizes to.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): "Package oauth2 implements the OAuth2 identity provider integration." Provides `IdentityProvider` over `storepb.OAuth2Config` with `NewIdentityProvider`, `ExchangeToken` (with PKCE `codeVerifier` support), and `UserInfo`.

OAuth2 is the only concrete protocol that ships — the store enum has just `TYPE_UNSPECIFIED` and `OAUTH2` (`proto/gen/store/idp.pb.go:27-28`), and the SSO login path in `server/router/api/v1/auth_service_sso.go:120-134` branches only on `storepb.IdentityProvider_OAUTH2`. No SAML or dedicated OIDC package exists (OIDC-style providers are configured as OAuth2 with a userinfo URL and field mapping).
