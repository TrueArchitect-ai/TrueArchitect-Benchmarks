## The actual public API surface: Protobuf / gRPC

The schema of record is a set of `.proto` files under `proto/api/v1/`, package `memos.api.v1`:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto` | `AIService` |
| `proto/api/v1/common.proto` | shared enums/messages |

There is a second, separate proto tree at `proto/store/*.proto` — those are internal persistence types, not the public API.

**How it's exposed.** Each RPC carries a `google.api.http` annotation that defines its REST mapping, e.g. `proto/api/v1/memo_service.proto:23` (`post: "/api/v1/memos"`), `:35` (`get: "/api/v1/{name=memos/*}"`). Three protocols are served off the same service implementation:

- **REST/JSON** via grpc-gateway, registered in `server/router/api/v1/v1.go` (`RegisterGateway`)
- **Connect RPC**, registered in `server/router/api/v1/connect_handler.go:31` (`RegisterConnectHandlers`), with method bodies in `server/router/api/v1/connect_services.go` delegating to the gRPC implementations
- **native gRPC** — `APIV1Service` in `server/router/api/v1/v1.go:22` embeds the generated `Unimplemented*Server` types

**Codegen.** `proto/buf.gen.yaml` drives `buf generate`, emitting Go into `proto/gen/`, an OpenAPI 3.0.3 spec to `proto/gen/openapi.yaml` (via the gnostic plugin), and TypeScript clients into `web/src/types/proto`. That OpenAPI spec is embedded into the binary (`proto/openapi_embed.go`) and reused to drive the MCP endpoint (`server/router/mcp/service.go:76`).

So if you're looking for "the schema," the authoritative source is `proto/api/v1/*.proto`, and the generated machine-readable description of the HTTP surface is `proto/gen/openapi.yaml`.
