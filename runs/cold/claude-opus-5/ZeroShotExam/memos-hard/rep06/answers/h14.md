**Computation site**

- `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, calls the markdown service, and assigns `memo.Payload.Tags` and `memo.Payload.Property`.
- The actual extraction is `service.ExtractAll` in `internal/markdown/markdown.go:356` — a single goldmark AST walk (there are also standalone `ExtractTags` / `ExtractProperties` at `markdown.go:138` / `markdown.go:181` doing the same work separately).

**Triggers (recomputation)**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert (location is then set separately on the payload at `:111`, since it's user-supplied, not derived).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is written via `update.Payload = memo.Payload` (`:451`). Updates that don't touch content (visibility, pinned, state, timestamps) don't recompute.
- Bulk backfill: `Runner.RunOnce` — `server/runner/memopayload/runner.go:27` rebuilds payloads for every memo in batches of 100 and persists each via `store.UpdateMemo`. Note it currently has no caller in the tree (`server/server.go:163` only runs the s3presign runner), so it's a migration/maintenance entry point rather than a live trigger.

**Extracted properties**

`ExtractedData` (`internal/markdown/markdown.go:21`) → persisted into `MemoPayload` (`proto/store/memo.proto:7`):

- `Tags` — every `#tag` node not nested in a link/image (`asMemoTagNode`, `markdown.go:131`), deduplicated preserving case.
- `Property.Title` — text of the first block-level child of the document if it's an H1 heading.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any GFM task checkbox; `Property.HasIncompleteTasks` — any unchecked checkbox.
- `Mentions` (lowercased `@user`) is also extracted by `ExtractAll`, but it is *not* stored in the payload — it's used transiently for notifications (`server/router/api/v1/memo_mention_helpers.go:32`).

These surface on the API as `Memo.Tags` / `Memo.Property` via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`).

Related but separate: the list/preview **snippet** is not stored on the memo — it's generated per-response at conversion time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `GenerateSnippet(content, 64)` (`internal/markdown/markdown.go:264`) to flatten markdown to plain text (skipping code blocks) truncated at a word boundary.
