## Method

The data layer is the `store/` package (`/bench/repo/store/`), which defines the persistent entity structs — `User` (`store/user.go:29`), `Memo` (`store/memo.go:35`), `Attachment` (`store/attachment.go:16`), `Reaction` (`store/reaction.go:7`), `Inbox` (`store/inbox.go:24`), `MemoRelation` (`store/memo_relation.go:16`), `MemoShare` (`store/memo_share.go:6`), `UserIdentity` (`store/user_identity.go:8`), `UserSetting` (`store/user_setting.go:13`), `IdentityProvider` (`store/idp.go:12`), `InstanceSetting` (`store/instance_setting.go:14`).

Counting distinct Go packages outside `store/` (and its sub-packages `store/db/*`, `store/test`) that qualify the type as `store.X`:

| Type | Packages | Where |
|---|---|---|
| **User** | **7** | `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` |
| **Memo** | **6** | `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` |
| Attachment | 4 | `server/router/api/v1`, `.../test`, `server/router/fileserver`, `server/router/rss` |
| Inbox / MemoRelation / MemoShare | 3 each | — |
| UserIdentity / Reaction | 2 each | — |

The ordering is stable if you drop the test package (`server/router/api/v1/test`): User 6, Memo 5. It also holds by raw reference count — `store.User` 99 occurrences vs `store.Memo` 73 vs `store.Attachment` 43.

Two notes on exclusions:
- `IdentityProvider`, `InstanceSetting`, and `UserSetting` appear to have hits in `proto/gen/store/*.pb.go`, but those are protobuf descriptor strings (e.g. `memos.store.IdentityProvider` at `proto/gen/store/idp.pb.go:432`), not Go references to the `store` package — they're false positives.
- `cmd/` and `internal/` contribute nothing: the only `store.` reference there is `store.New` in `cmd/memos/main.go:64`.

The gap between User and Memo is one package (`server/auth` and `server/router/fileserver` use `store.User` for identity/permission checks, while Memo picks up `server/runner/memopayload`), so the two are close — but User leads on both package spread and reference density.
