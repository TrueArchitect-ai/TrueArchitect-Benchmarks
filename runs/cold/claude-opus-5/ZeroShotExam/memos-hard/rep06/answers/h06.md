**The chain:** each handler → `s.dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which loads the user's stored webhook rows (`Store.GetUserWebhooks`), sets `payload.URL = hook.Url`, and calls `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto `asyncPostQueue`; four worker goroutines started in `init()` (`internal/webhook/webhook.go:44-52`) drain it.

**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`.** This is the only place the actual request is built and sent: `http.NewRequest("POST", requestPayload.URL, …)` at line 126, HMAC signing headers, then `safeClient.Do(req)` at line 154. The URL originates from user config written by `CreateUserWebhook`/`UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go` (validated at creation time by `webhook.ValidateURL`, `internal/webhook/validate.go`), with dial-time SSRF blocking via `safeDialContext` on `safeClient`.
