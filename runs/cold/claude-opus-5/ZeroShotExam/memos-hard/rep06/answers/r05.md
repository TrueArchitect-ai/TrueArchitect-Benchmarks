**Premise correction:** This repository (`usememos/memos`) has no GraphQL schema — there are no `.graphql`/`.gql` files, no schema-definition code, and no GraphQL server dependency anywhere in the tree (a case-insensitive grep for "graphql" across the whole repo, excluding `node_modules`, returns nothing).

**Actual API surface:** The public API is defined as **Protocol Buffers** service definitions under `proto/api/v1/`, following Google's AIP guidelines (`proto/api/v1/README.md`):

- `proto/api/v1/memo_service.proto` — `MemoService` (memos, comments, reactions, relations, attachments, shares, link metadata)
- `proto/api/v1/user_service.proto` — `UserService` (users, settings, PATs, webhooks, notifications, linked identities)
- `proto/api/v1/auth_service.proto` — `AuthService` (`SignIn`, `SignOut`, `RefreshToken`, `GetCurrentUser`)
- `proto/api/v1/attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`
- `proto/store/*.proto` holds internal storage message types, not the public API

How it's exposed:

- **Codegen** is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) producing Go stubs, gRPC, Connect, grpc-gateway, an OpenAPI spec, and TypeScript clients into `web/src/types/proto`. Generated output lives in `proto/gen/`.
- **REST/JSON** comes from `google.api.http` annotations on each RPC (e.g. `get: "/api/v1/{name=memos/*}"` at `proto/api/v1/memo_service.proto:35`), served via grpc-gateway registered in `server/router/api/v1/v1.go:96-128` under `/api/v1/*`.
- **Connect/gRPC** handlers are mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:139-144`).
- The generated **OpenAPI** spec is `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` and also consumed by the MCP router (`server/router/mcp/`).
