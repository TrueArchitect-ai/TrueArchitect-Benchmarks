**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` — the abstraction package. It's deliberately minimal, defining only the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every concrete provider must normalize its user data into.
- `internal/idp/oauth2/oauth2.go` — the single concrete protocol implementation that ships ("Package oauth2 implements the OAuth2 identity provider integration"). It defines `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider` validating required fields (`clientId`, `clientSecret`, `tokenUrl`, `userInfoUrl`, `fieldMapping.identifier`), `ExchangeToken` (supporting PKCE via `codeVerifier`), and user-info retrieval mapped through the configured `FieldMapping`.

OAuth2 is the only protocol implementation under `internal/idp/` — there is no SAML, LDAP, or OIDC-specific package. Tests live in `internal/idp/oauth2/oauth2_test.go`.
