**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-based markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk). It writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`), stored as the memo's `payload` JSON column (`proto/store/memo.proto:7-23`).

**Triggers** —
- `CreateMemo`: `server/router/api/v1/memo_service.go:108` (before the row is inserted; the user-set `location` is merged onto the payload afterwards at line 112).
- `UpdateMemo`, only when `content` is in the update mask: `server/router/api/v1/memo_service.go:447-451` — the new content is parsed and `update.Payload` is set alongside `update.Content`. Other mask paths (visibility, pinned, state, timestamps, location) do not recompute it.
- Bulk backfill: `Runner.RunOnce` in `server/runner/memopayload/runner.go:31` rebuilds the payload for all memos in batches of 100 and persists each via `store.UpdateMemo`. Note this runner is not currently wired into startup — `server/server.go:163` only invokes the s3presign runner — so in practice it's a migration/maintenance entry point.

**Extracted properties** —
- `tags`: `#tag` nodes (custom `TagNode`), skipping tags nested inside links/images (`isTagNodeInLinkOrImage`, `markdown.go:118`), deduplicated preserving original case.
- `property.has_link` — any `KindLink` node.
- `property.has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `property.has_task_list` — any GFM task checkbox; `property.has_incomplete_tasks` — at least one unchecked checkbox.
- `property.title` — text of the first block-level child of the document if it's an H1 heading.
(`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` ignores them; mentions are consumed separately in `server/router/api/v1/memo_mention_helpers.go:32`.)

Both are surfaced to clients in `convertMemoFromStore` — `memo.Payload.Tags` → `Memo.tags` and `convertMemoPropertyFromStore` → the OUTPUT_ONLY `Memo.property` (`server/router/api/v1/memo_service_converter.go:47-50`, `:315`). The list preview text (`Memo.snippet`) is a separate derived value computed on the fly per response, not stored: `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` in `server/router/api/v1/memo_service_webhooks.go:83`.
