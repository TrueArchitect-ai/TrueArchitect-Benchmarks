**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package: `internal/idp`** — `internal/idp/idp.go` defines the provider-neutral contract, the `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any IdP implementation must produce.
- **Implementation package: `internal/idp/oauth2`** — `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration") provides the concrete `IdentityProvider` type built on `golang.org/x/oauth2`, with `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (including PKCE `code_verifier` support), and `UserInfo`, which maps provider claims into `idp.IdentityProviderUserInfo` via the configured field mapping.

OAuth2 is the only concrete protocol that ships — no SAML/LDAP/other implementation exists. The single consumer is `server/router/api/v1/auth_service_sso.go:12-13`, which imports both packages; provider configuration is persisted via `store/idp.go`.
