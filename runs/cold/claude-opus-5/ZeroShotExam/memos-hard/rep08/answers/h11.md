Counting distinct Go packages *outside* the `store/` tree (so excluding the driver packages `store/db/{sqlite,postgres,mysql}` and `store/test`, which are part of the data layer itself) that reference each type:

One nuance worth flagging: by *raw reference count* rather than package spread, `Memo` leads (~141 mentions vs ~110 for `User`). `User` wins on breadth because it's the only entity touched by the auth and file-serving layers (`server/auth`, `server/router/fileserver`), whereas `Memo` is concentrated in the API service layer.
