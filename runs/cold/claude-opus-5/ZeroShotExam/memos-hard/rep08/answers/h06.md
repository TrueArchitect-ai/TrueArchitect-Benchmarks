**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`. Every handler goes through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`; the four background workers started in `init()` (`webhook.go:42-55`) all call `Post`, which is where the single `http.NewRequest("POST", requestPayload.URL, ...)` (`:126`) and `safeClient.Do(req)` (`:152`) live. Egress is filtered there by `safeDialContext`/`isReservedIP` (`webhook.go:59`, `internal/webhook/validate.go:43`).

Two notes on scope:
- `GetLinkMetadata` / `BatchGetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:14,19`) also make outbound HTTP requests via `fetchHTMLMeta` → `httpgetter.GetHTMLMeta`, but to a URL supplied in the request itself, not a stored user-configured one — and they do *not* pass through `webhook.Post`.
- `CreateUserWebhook`/`UpdateUserWebhook` touch the network only for DNS resolution in `webhook.ValidateURL` (`internal/webhook/validate.go:62`); no HTTP request is made there.
