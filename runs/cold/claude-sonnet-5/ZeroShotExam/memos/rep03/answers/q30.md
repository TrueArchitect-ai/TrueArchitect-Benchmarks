Note: the create/update/delete dispatchers all route through the shared private helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`); the comment dispatcher builds its payload inline but follows the same pattern. There is no separate "archived" event — archiving is folded into `memos.memo.updated`.

**Delivery convergence:** all four call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded channel drained by 4 worker goroutines (`internal/webhook/webhook.go:42-55`). Those workers call `Post` — `internal/webhook/webhook.go:120` — the single function that marshals the payload, optionally signs it (HMAC-SHA256, Standard Webhooks format), and performs the actual HTTP POST via the SSRF-guarded `safeClient`.
