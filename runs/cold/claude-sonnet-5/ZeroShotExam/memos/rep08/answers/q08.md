q08. **Driver** — `store/driver.go`

The `Driver` interface (declared at `store/driver.go:10`) defines all methods a store database driver must implement (`GetDB() *sql.DB`, `Close()`, CRUD methods for Memo, User, Attachment, etc.). It's implemented by each backend's `DB` struct: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, and selected at runtime in `store/db/db.go`'s `NewDBDriver`.
