- **Interceptor path:** `web/src/connect.ts` (`authInterceptor`, lines 156–178, registered into the Connect-RPC transport at line 188); token storage/refresh logic lives alongside it in `web/src/auth-state.ts`.
- **Token kinds:** JWT **access token** ("Access Token V2", 15 min TTL, kept in memory/localStorage, sent as `Authorization: Bearer <token>`); JWT **refresh token** (30-day TTL, stored as HTTP-only cookie `memos_refresh`, sent automatically via `credentials: "include"`); and **Personal Access Tokens** (`memos_pat_...` prefix) for programmatic API access, also sent as `Authorization: Bearer <PAT>`.
- **Backend validation package:** `server/auth/` (in particular `token.go` for JWT/PAT parsing and `authenticator.go`'s `Authenticate`/`AuthenticateByRefreshToken`), invoked from the Connect-RPC `AuthInterceptor.WrapUnary` in `server/router/api/v1/connect_interceptors.go` via the `Authorizer` in `server/router/api/v1/authz.go`.
