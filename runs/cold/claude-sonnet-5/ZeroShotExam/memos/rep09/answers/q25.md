**Engine + path:** Google's [cel-go](https://github.com/google/cel-go) (CEL — Common Expression Language), wrapped by this repo's own filter package at `internal/filter/` (`engine.go`, `ir.go`, `render.go`, `schema.go`, `parser.go`).

**Mechanism:** `ListMemos` (in `server/router/api/v1/memo_service.go:211-216`, via `validateFilter`) accepts the raw `filter` string and appends it to `store.FindMemo.Filters`; a shared `filter.Engine` (`internal/filter/engine.go`, built via `cel.NewEnv` over a `Schema` from `schema.go`) compiles that CEL expression into a CEL AST, then `buildCondition` (`ir.go`) walks the AST into a dialect-agnostic `Condition` tree, and finally `Program.Render`/`renderer` (`render.go`) walks that tree to emit dialect-specific SQL + args (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`), which each store backend (e.g. `store/db/sqlite/memo.go:61`, `store/db/mysql/memo.go:69`, `store/db/postgres/memo.go:58`) pulls in via `filter.AppendConditions` to build the `WHERE` clause for its dialect.
