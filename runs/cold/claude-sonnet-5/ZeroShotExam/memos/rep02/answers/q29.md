**Interceptor path:** `web/src/connect.ts` — defines `authInterceptor`, a Connect-RPC interceptor attached to `createConnectTransport`, which sets `Authorization: Bearer <token>` on outgoing requests and retries once after refreshing on an unauthenticated response. Token state is cached in `web/src/auth-state.ts`.

**Token kinds managed:**
- Access token (short-lived JWT, ~15 min) — attached as `Authorization: Bearer …`, cached in memory/`localStorage`.
- Refresh token (long-lived JWT, ~30 days) — sent as an HTTP-only cookie (`memos_refresh`) via `credentials: "include"`, not touched directly by JS.
- (Backend also accepts a Personal Access Token, prefix `memos_pat_`, for programmatic API access, though the frontend interceptor itself doesn't issue these.)

**Backend package path:** `server/auth/` — specifically `server/auth/authenticator.go` (`Authenticator.Authenticate*` methods), `server/auth/token.go` (JWT/PAT generation & parsing), `server/auth/extract.go` (Bearer/cookie extraction). It's wired into request handling via `server/router/api/v1/authz.go` (`Authorizer`).
