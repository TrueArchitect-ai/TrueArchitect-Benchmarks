- `user`: `User` — `store/user.go`
- `attachment`: `Attachment` — `store/attachment.go`
- `reaction`: `Reaction` — `store/reaction.go`

These are the domain structs in the `store` package that driver code (e.g. `store/db/sqlite/user.go`, `store/db/sqlite/attachment.go`, `store/db/sqlite/reaction.go`) scans query results into via raw SQL against the `user`, `attachment`, and `reaction` tables (e.g. `INSERT INTO user ...`, `FROM \`attachment\``, `FROM reaction`). This codebase (usememos/memos) doesn't use an ORM like xorm/gorm with `TableName()` methods — the mapping is done manually in the per-database driver files under `store/db/`.
