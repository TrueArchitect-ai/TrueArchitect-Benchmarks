**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (Connect-RPC interceptor, ~lines 156-178), attached to the shared `transport` used by all service clients. It reads/refreshes tokens via `web/src/auth-state.ts` and retries once on `Code.Unauthenticated`.

**Token kinds:**
- Access token — short-lived (15 min) JWT, sent as `Authorization: Bearer <token>`, stored in memory + `localStorage`.
- Refresh token — long-lived (30 days) JWT, stored only in an HttpOnly cookie `memos_refresh` (sent via `credentials: "include"`), never touched by JS.
- Personal Access Token (PAT) — long-lived, prefixed `memos_pat_`, also sent via `Authorization: Bearer`.

**Backend package that validates them:** `server/auth/` (core logic: `authenticator.go`, `token.go`, `extract.go`, `context.go`), wired into request handling by `server/router/api/v1/connect_interceptors.go` (`AuthInterceptor.WrapUnary`) and `server/router/api/v1/authz.go` (`Authorizer`).
