**Engine**: [CEL (Common Expression Language)](https://github.com/google/cel-go) via `cel-go`, implemented as a custom three-phase pipeline in `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`; see `internal/filter/README.md`).

**Mechanism**: `ListMemos` (`server/router/api/v1/memo_service.go:178`) appends the raw filter string to `store.FindMemo.Filters`; the CEL string is compiled/type-checked against a declared field schema (`schema.go`) into a dialect-agnostic IR (`parser.go`'s `buildCondition` walking the CEL `Expr` tree into `ir.go` node types), and a `renderer` (`render.go`) then walks that IR to emit SQL text + placeholder args, branching on `Dialect` (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`) at dozens of switch sites to handle placeholder style, JSON extraction/array ops, and regex syntax differences — invoked per store via `filter.AppendConditions(...)` in `store/db/sqlite/memo.go:55-63`, `store/db/mysql/memo.go:63-69`, and `store/db/postgres/memo.go:53-59`.
