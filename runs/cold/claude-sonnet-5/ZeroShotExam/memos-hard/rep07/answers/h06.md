Each `Dispatch*Webhook` wrapper (`server/router/api/v1/memo_service_webhooks.go:15-46`) funnels through the shared `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which loads the target user's stored webhook URLs and calls `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` just queues the payload for the async worker pool defined in `init()`, which itself calls `Post`.

Convergence function — `Post` in `internal/webhook/webhook.go:120` (`func Post(requestPayload *WebhookRequestPayload) error`). This is the single place that actually marshals the payload and issues the outbound `http.NewRequest("POST", requestPayload.URL, ...)` / `safeClient.Do(req)` call (webhook.go:126-155), guarded only by the SSRF-blocking `safeDialContext` transport.
