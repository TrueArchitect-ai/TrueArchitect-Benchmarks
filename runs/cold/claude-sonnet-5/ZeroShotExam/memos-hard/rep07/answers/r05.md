Premise correction: This repository has no GraphQL schema — there are zero references to "graphql" anywhere in the codebase (`grep -ril graphql /bench/repo` returns nothing), and no `.graphql`/`.gql` files exist.

Actual API surface: The public API is defined using **Protocol Buffers**, not GraphQL:
- Proto service/message definitions live under `proto/api` (source `.proto` files).
- Generated Go bindings are under `proto/gen/api`.
- An **OpenAPI/Swagger** spec (generated from the proto definitions, likely via `protoc-gen-openapi`/`buf`) is at `proto/gen/openapi.yaml`, with generation config in `proto/buf.gen.yaml` and an embedding helper at `proto/openapi_embed.go`.
- The HTTP/gRPC-gateway routing that exposes these APIs is wired up in `server/router/api`.

So if you're looking for "the schema of the public API," the closest equivalent to a GraphQL SDL file is the proto definitions in `proto/api/` (source of truth) or the generated `proto/gen/openapi.yaml` (REST/OpenAPI view of the same API).
