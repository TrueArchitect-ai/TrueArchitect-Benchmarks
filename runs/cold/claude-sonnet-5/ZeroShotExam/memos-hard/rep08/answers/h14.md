**h14.**

**Computation site:** `internal/markdown/markdown.go`'s `(*service).ExtractAll` (`/bench/repo/internal/markdown/markdown.go:356-422`) — a single goldmark AST walk over the memo's raw content — invoked via `RebuildMemoPayload` in `/bench/repo/server/runner/memopayload/runner.go:74-88`, which writes results into `memo.Payload.Tags` and `memo.Payload.Property`. Separately, `GenerateSnippet` (markdown.go:263-346) produces a plain-text excerpt, called from `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-90`.

**Triggers:**
- **Persisted fields** (`Payload.Tags`, `Payload.Property`) recompute on `CreateMemo` (`memo_service.go:108`) and on `UpdateMemo` only when the update mask includes `"content"` (`memo_service.go:435-448`) — other field updates (visibility, pinned, etc.) don't trigger it.
- A batch `Runner.RunOnce` exists (`runner.go:26-72`, pages through all memos and calls `RebuildMemoPayload`) but is not wired into any scheduler/CLI in the current codebase — dormant.
- **Snippet/preview** is not persisted; it's recomputed on every read, each time a memo row is converted to an API response (`memo_service_converter.go`, list/get/notification paths).

**Extracted properties:**
- `Tags []string` — `#tag` occurrences (deduped, case-preserved)
- `Property.Title` — text of the first block if it's an H1 heading
- `Property.HasLink` — any Markdown link node
- `Property.HasCode` — any code block/fenced block/code span
- `Property.HasTaskList` / `HasIncompleteTasks` — GFM task checkboxes, and whether any are unchecked
- `Snippet` — plain-text excerpt (max 64 chars, truncated at word boundary), computed on-demand, not stored

No word count or reading-time field exists anywhere in the repo.
