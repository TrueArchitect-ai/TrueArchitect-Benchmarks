**Premise correction:** There is no Redis anywhere in this repository (a `grep -ri redis` across the whole tree returns zero matches). This is the Memos app (Go backend + React frontend), and it has no external cache/session store dependency at all — no `redis`, `go-redis`, or similar in `go.mod` or elsewhere.

**Actual mechanism:** The "cache layer" for users is an in-process, in-memory Go cache (`sync.Map`-backed, not Redis), implemented at `store/cache/cache.go`. It's instantiated per `Store` in `store/store.go:38-61`:

- `userCache` is created via `cache.New(cacheConfig)` at `store/store.go:52`.
- The shared `cacheConfig` sets `DefaultTTL: 10 * time.Minute` (`store/store.go:41`), along with `CleanupInterval: 5 * time.Minute` and `MaxItems: 1000`.
- User entries are stored via the cache's `Set` method (e.g. `store/user.go:151` reads back via `cache.(*User)`), which applies that 10-minute default TTL (`store/cache/cache.go:92-95`) unless `SetWithTTL` is used to override it.

So: user cache entries expire after 10 minutes, held in-memory per server process, with no Redis (or any external cache backend) involved.
