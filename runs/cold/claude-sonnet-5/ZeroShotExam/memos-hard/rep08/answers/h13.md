The `markdown.Service` interface (`internal/markdown/markdown.go:31-55`) is Memos' abstraction for markdown parsing/rendering/extraction.

**Implementation** — `service` (`internal/markdown/markdown.go:58-60`), an unexported struct wrapping a `goldmark.Markdown` instance (goldmark + `extension.GFM`, plus optional custom `extensions.TagExtension`/`extensions.MentionExtension`). It's the only concrete type implementing `Service`. (Its `RenderMarkdown`/`RenameTag` methods internally use a second, unexported helper type, `renderer.MarkdownRenderer` in `internal/markdown/renderer/markdown_renderer.go`, to serialize the goldmark AST back to markdown text — but that type isn't itself an implementer of `Service`; it's a component `service` composes.)

**Construction** — via `markdown.NewService(...)` (`internal/markdown/markdown.go:85`):
- `server/router/api/v1/v1.go:48` — in `NewAPIV1Service`, with `WithTagExtension()` + `WithMentionExtension()` (the production instance).
- `server/router/api/v1/test/test_helper.go:44` — same options, for tests.
- Also directly in `rss_test.go` and `fileserver_test.go` for test setups.

**Holders of the interface** (fields typed `markdown.Service`, not the concrete type):
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35` (the source of the runtime instance; used e.g. in `memo_mention_helpers.go:32`, `memo_service_webhooks.go:85`, and passed into `memopayload.RebuildMemoPayload` from `memo_service.go:108,447`)
- `RSSService.MarkdownService` — `server/router/rss/rss.go:45` (constructed in `NewRSSService`, called from `server/server.go:85` with `apiV1Service.MarkdownService`, i.e. the same singleton instance is reused, not a new one)
- `Runner.MarkdownService` — `server/runner/memopayload/runner.go:16` (via `memopayload.NewRunner`); note this `Runner`/`NewRunner` isn't wired up anywhere in `server.go` — only the free function `memopayload.RebuildMemoPayload(ctx, memo, markdownService)` is actually called in production code, taking the interface as a plain parameter rather than through this struct.

So at runtime there is exactly one concrete implementation, `*service` (package `internal/markdown`), constructed once in `NewAPIV1Service` and shared by reference into `RSSService` and passed as a parameter to `memopayload.RebuildMemoPayload`.
