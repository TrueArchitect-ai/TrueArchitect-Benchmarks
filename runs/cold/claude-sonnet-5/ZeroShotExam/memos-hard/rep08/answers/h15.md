Confirmed — that's a genuinely separate enforcement site I'd missed. Here's the updated, complete answer incorporating it:

h15.
Memo visibility ("who may view") is re-implemented independently across many server surfaces rather than through a single shared gate. Confirmed enforcement sites:

enforcement site — path
`checkMemoReadAccess` (gates GetMemo and memo comment listing) — server/router/api/v1/memo_service.go
`ListMemos` query-level visibility filter (VisibilityList / creator-or-public-protected filter) — server/router/api/v1/memo_service.go
Store-layer SQL WHERE builder for `VisibilityList` (underlies both GetMemo and ListMemos) — store/db/sqlite/memo.go, store/db/postgres/memo.go, store/db/mysql/memo.go
`ListMemoRelations` visibility filter expression — server/router/api/v1/memo_relation_service.go, compiled to SQL in store/db/{sqlite,postgres,mysql}/memo_relation.go
`ListMemoReactions` / `UpsertMemoReaction` visibility checks — server/router/api/v1/reaction_service.go
`ListMemoAttachments` visibility check — server/router/api/v1/memo_attachment_service.go
`checkAttachmentAccess` (GetAttachment) — server/router/api/v1/attachment_service.go
`checkAttachmentPermission` (raw file-serving/download routes, incl. share-token bypass) — server/router/fileserver/fileserver.go
RSS feed generation (`GetExploreRSS`/`GetUserRSS`, public-only) — server/router/rss/rss.go
Sitemap.xml generation (public-only) — server/router/frontend/frontend.go
SSE real-time broadcast filtering (`canReceive`) — server/router/api/v1/sse_hub.go
In-app notification snippet access check (`canViewerAccessMemo`) — server/router/api/v1/user_service_notifications.go
Outbound notification **email** access check (separate duplicate `canViewerAccessMemo`) — server/notification/email.go
Mention-notification visibility check (`canUserAccessMentionContext`/`shouldSkipMentionInbox`) — server/router/api/v1/memo_mention_helpers.go
User stats visibility filter — server/router/api/v1/user_service_stats.go
`CreateMemoComment` inline check on the related/parent memo's visibility — server/router/api/v1/memo_service_comments.go

Note: `GetMemoByShare` (server/router/api/v1/memo_share_service.go) intentionally bypasses these checks for holders of a valid share token — it's a deliberate exception, not an enforcement site.
