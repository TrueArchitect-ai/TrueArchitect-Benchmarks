**Premise correction:** This repository (usememos/memos) does not have a GraphQL API — there's no GraphQL schema, resolver, or dependency anywhere in the codebase.

**Actual API surface:** The public API is defined via Protocol Buffers / gRPC, with REST exposed through gRPC-gateway:
- Proto service definitions: `/bench/repo/proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, etc.)
- Generated Go/OpenAPI code: `/bench/repo/proto/gen/api` and `/bench/repo/proto/gen/openapi.yaml` (the generated OpenAPI/Swagger spec, which is the closest analogue to a "public API schema")
- Build config: `/bench/repo/proto/buf.yaml`, `/bench/repo/proto/buf.gen.yaml` (buf-based codegen pipeline)

The README confirms this: "Open & Extensible — MIT-licensed with full REST and gRPC APIs for integration" — no mention of GraphQL.
