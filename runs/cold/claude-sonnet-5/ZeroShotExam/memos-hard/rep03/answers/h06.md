**RPC handlers (gRPC, `server/router/api/v1/`) that transitively cause an outbound HTTP request to a user-configured (webhook) URL:**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` → `DispatchMemoCreatedWebhook` (`memo_service_webhooks.go:15`) → `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`) → `webhook.PostAsync` (`memo_service_webhooks.go:71`)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook` (`memo_service_webhooks.go:20`) → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` → `DispatchMemoDeletedWebhook` (`memo_service_webhooks.go:25`) → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:30`) → `webhook.PostAsync`

In each chain, the webhook URL/secret is loaded from storage via `s.Store.GetUserWebhooks(ctx, userID)` (user-configured via `CreateUserWebhook`/`UpdateUserWebhook` in `user_service_webhooks.go`), placed into a `WebhookRequestPayload`, and handed to `webhook.PostAsync`, which enqueues it for a worker goroutine to call `webhook.Post`.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120`. All four paths (via `PostAsync`'s async queue) funnel into this one function, which builds the request and performs the actual delivery via `safeClient.Do(req)` (the SSRF-guarding client whose dialer, `safeDialContext` at `internal/webhook/webhook.go:59`, blocks reserved/private IPs at connect time).
