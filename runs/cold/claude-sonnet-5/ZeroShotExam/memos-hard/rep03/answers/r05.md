**Premise correction:** This repository (memos, a Go-based note-taking service) does not use GraphQL anywhere — a full-text search for "graphql" across the codebase returns no hits.

**Actual API surface:** The public API is defined via **Protocol Buffers / gRPC**, exposed as both gRPC and a REST/JSON gateway (grpc-gateway) plus an OpenAPI spec:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`)
- Generated Go code: `proto/gen/api/v1/`
- Generated OpenAPI/REST spec (for the HTTP surface): `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- Build/codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`

So there is no GraphQL schema to point to; the equivalent "public API schema" role is filled by the `.proto` files under `proto/api/v1/`.
