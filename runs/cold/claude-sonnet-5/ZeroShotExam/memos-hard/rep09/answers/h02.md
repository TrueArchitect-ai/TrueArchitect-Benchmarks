It resolves the target host via `net.DefaultResolver.LookupHost` and rejects the dial if any resolved IP is "reserved" per `isReservedIP` in `internal/webhook/validate.go:44`, which checks against `reservedNetworks` (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents) defined in `internal/webhook/validate.go:14-23`. Because the check happens at dial time against the actually-resolved IP (not the hostname), it also defeats DNS-rebinding. A companion pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62`), performs the same resolution/`isReservedIP` check when a webhook URL is first saved. Both checks can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments that want to target local-network services.
