**Premise correction:** This repository has no GraphQL API — there's no `.graphql`/`.gql` file, no `type Query`/`type Mutation` SDL, and no GraphQL library (Apollo, graphql-yoga, Pothos, etc.) anywhere in `go.mod`, `package.json`, or the codebase.

**Actual API surface:** This is the `usememos/memos` repo, whose public API is defined via **Protocol Buffers / gRPC**, exposed over HTTP through grpc-gateway with an OpenAPI spec:

- Service/message definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`) — `AGENTS.md:67` explicitly labels this directory "Public API service definitions."
- Generated code: `proto/gen/api/` (Go) and mirrored TypeScript stubs under `web/src/types/proto/api/`; a generated OpenAPI document at `proto/gen/openapi.yaml`.
- HTTP route handlers implementing these services: `server/router/api/v1/`.
- A separate MCP/OpenAPI layer (`server/router/mcp/openapi.go`, `server/router/mcp/catalog.go`) reuses the same OpenAPI spec as the single source of truth, per `server/router/mcp/README.md`.

So instead of a GraphQL schema, look at `proto/api/v1/*.proto` for the API contract.
