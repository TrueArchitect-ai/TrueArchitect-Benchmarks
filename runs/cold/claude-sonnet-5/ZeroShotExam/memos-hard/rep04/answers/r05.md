**Premise correction:** there is no GraphQL schema in this repository — this is [usememos/memos](https://github.com/usememos/memos), and its public API is defined via **Protocol Buffers**, not GraphQL.

**Actual API surface:**
- Service definitions live in `/bench/repo/proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`).
- These are compiled via `buf` (config in `/bench/repo/proto/buf.yaml`, `buf.gen.yaml`, `buf.lock`) into Go bindings under `/bench/repo/proto/gen/api/v1/`, including gRPC-Gateway files (`*_grpc.pb.go`, `*.pb.gw.go`) that expose the gRPC services as a REST/JSON HTTP API.
- An OpenAPI/Swagger description generated from the same protos is available at `/bench/repo/proto/gen/openapi.yaml`, which is effectively the public HTTP API schema (analogous to what a GraphQL SDL would provide in a GraphQL-based project).

So if you're looking for "the schema that defines the public API," the closest equivalents are the `.proto` files in `proto/api/v1/` and the generated `proto/gen/openapi.yaml`, not any GraphQL schema.
