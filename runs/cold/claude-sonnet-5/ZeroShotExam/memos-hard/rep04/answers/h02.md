**Delivery function** — `Post` (executes `safeClient.Do(req)`) in `internal/webhook/webhook.go:120-180`, invoked async via `PostAsync` (same file, lines 184-196), which is triggered by `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go` on memo create/update/delete/comment events.

**Protection mechanism** — SSRF is blocked in two layers:
- Registration-time: `ValidateURL` in `internal/webhook/validate.go:62-83`, which resolves the hostname via `net.LookupHost` and rejects reserved/private IPs.
- Dial-time (closes the DNS-rebinding gap): `safeDialContext` in `internal/webhook/webhook.go:59-77`, installed as the `DialContext` on the custom `http.Transport` used by `safeClient` — the actual client `Post()` calls — which re-resolves the host at connection time and rejects it if any IP falls in `isReservedIP`/`reservedCIDRs` (`internal/webhook/validate.go:44-54`, covering loopback, RFC1918 ranges, and link-local/169.254.169.254 metadata addresses).

Note: a package-level `AllowPrivateIPs` flag (`internal/webhook/webhook.go:41`) can disable this protection when enabled for self-hosted use cases.
