**Mechanism: explicit Go code (not a database-level cascade/rule).**

The `reaction` table's `creator_id` column has no foreign key constraint at all (no `ON DELETE CASCADE`/`SET NULL`/`RESTRICT`), in any of the three supported backends, from its original creation through the current schema:
- `store/migration/sqlite/0.20/00__reaction.sql`, `store/migration/postgres/0.20/00__reaction.sql`, `store/migration/mysql/0.20/00__reaction.sql`
- Current schema: `store/migration/sqlite/LATEST.sql:92-99`, `store/migration/postgres/LATEST.sql:91-98`, `store/migration/mysql/LATEST.sql:91-98`

```sql
CREATE TABLE reaction (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  created_ts BIGINT NOT NULL DEFAULT (strftime('%s', 'now')),
  creator_id INTEGER NOT NULL,
  content_id TEXT NOT NULL,
  reaction_type TEXT NOT NULL,
  UNIQUE(creator_id, content_id, reaction_type)
);
```

I also checked all `.sql` files for `TRIGGER` — the only ones that ever existed (`0.5`–`0.7`) maintained `modified_ts` columns and were later dropped; none touch `reaction`. So there is no DB-level rule/trigger involved either.

Instead, cleanup happens via explicit Go code in `store/db/{sqlite,postgres,mysql}/user_delete.go`, inside the transaction driving `DeleteUser` (orchestrated by `deleteUserTargetsTx`, e.g. `store/db/sqlite/user_delete.go:92-127`):

func deleteReactionsByCreatorTx(ctx context.Context, tx *sql.Tx, userID int32) error {
	_, err := tx.ExecContext(ctx, `DELETE FROM reaction WHERE creator_id = `+deleteUserPlaceholder(1), userID)

This runs before the memo rows and the `user` row itself are deleted, all within the same transaction, and is reached via `store/user.go:171-181` (`Store.DeleteUser`) called from the API handler `server/router/api/v1/user_service.go:393-455`.

So: reactions the deleted user created, and reactions others left on that user's memos/comment threads, are both explicitly deleted by Go code atomically with the rest of user deletion — enforcement relies entirely on this code path since the schema itself has no FK to fall back on.
