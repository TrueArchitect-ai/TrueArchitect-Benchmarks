**Premise correction:** This repo does not have a GraphQL API. A search for `.graphql`/`.gql` files and any `graphql` references across the codebase turns up nothing.

**Actual API surface:** Memos exposes its public API as Protobuf-defined gRPC services with a REST/OpenAPI gateway, generated via `buf`:
- Proto service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, etc.)
- Internal store-layer protos: `proto/store/*.proto`
- Generated Go/gRPC-gateway code: `proto/gen/api/`
- Generated OpenAPI spec (REST surface): `proto/gen/openapi.yaml`
- Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`
- `proto/README.md` documents the codegen workflow

So "the GraphQL schema" doesn't exist; the equivalent public API contract lives in `proto/api/v1/*.proto` (source of truth) and `proto/gen/openapi.yaml` (derived REST/OpenAPI schema).
