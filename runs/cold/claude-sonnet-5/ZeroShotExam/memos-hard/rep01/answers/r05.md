**Premise correction:** This repository (memos) has no GraphQL API, so there is no GraphQL schema to point to.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + gRPC-Gateway REST), not GraphQL:

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Generated Go code (gRPC servers/clients + REST gateway handlers): `proto/gen/api/v1/*.pb.go` and `*.pb.gw.go`
- Generated OpenAPI/REST spec derived from the same protos: `proto/gen/openapi.yaml`
- Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`
