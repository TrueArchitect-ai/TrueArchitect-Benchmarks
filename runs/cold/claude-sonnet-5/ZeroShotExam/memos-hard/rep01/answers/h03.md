**h03.** `internal/idp`; `internal/idp/oauth2`

The abstraction package `internal/idp` (internal/idp/idp.go) defines `IdentityProviderUserInfo`, the common type all provider implementations return. The concrete implementation package `internal/idp/oauth2` (internal/idp/oauth2/oauth2.go) implements the OAuth2 protocol via its `IdentityProvider` struct (`NewIdentityProvider`, `ExchangeToken`, `UserInfo`). The proto-level type system (`storepb.IdentityProvider_Type`) is structured to support additional protocols later, but OAuth2 is currently the only shipped implementation.
