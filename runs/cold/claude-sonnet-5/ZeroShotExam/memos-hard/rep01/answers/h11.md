**Data layer:** the `store` package (`store/*.go`), which defines the persistent entity structs — `Memo`, `User`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `InstanceSetting`, `IdentityProvider` (all under `store/`, including its `store/db/*` driver subpackages and `store/test`, which are implementation of the layer itself, not "outside" it).

Counting distinct Go packages outside `store/` that reference each type (`store.<Type>`):

- **`store.User`** → referenced from 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo`** → referenced from 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

All other entity types trail well behind (`Attachment` ~4, `Inbox`/`MemoRelation`/`MemoShare` ~3, `Reaction`/`UserIdentity` ~2, `UserSetting`/`InstanceSetting`/`IdentityProvider` ~0 real external usages — their apparent `proto/gen/store` hits are just string literals in generated protobuf descriptors, not code references).

**Answer:** 1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)
