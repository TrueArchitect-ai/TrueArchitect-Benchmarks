**Computation site:**
- `internal/markdown/markdown.go` — `ExtractAll` (lines 356-421, also `ExtractProperties` lines 192-241 and `ExtractTags` lines 142-170) walks the goldmark AST once to derive persisted properties; `GenerateSnippet` (lines 263-346) walks the AST to build an ephemeral preview.
- Persisted extraction is orchestrated by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `ExtractAll` and assigns the results to `memo.Payload.Tags` / `memo.Payload.Property`.
- Snippet extraction is invoked per-request via `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-89`, which calls `GenerateSnippet(content, 64)`.

**Triggers:**
- Persisted `Property`/`Tags`: recomputed via `RebuildMemoPayload` on `CreateMemo` (`server/router/api/v1/memo_service.go:108`) and on `UpdateMemo` only when the update mask includes the `content` field path (`server/router/api/v1/memo_service.go:436-447`). A standalone batch runner (`server/runner/memopayload/runner.go`, `RunOnce`) can also rebuild it for all memos in pages of 100, though it isn't currently wired into a scheduled/startup job in `server/server.go`. These fields are stored in the DB and are *not* recomputed on plain reads.
- Ephemeral `Snippet`: recomputed on every read/API conversion — in `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76-80`) for `GetMemo`/`ListMemos`, in `memo_relation_service.go:154,162` for related-memo previews, in batch relation conversion (`memo_service_converter.go:173-273`), and in notification payload building (`server/router/api/v1/user_service_notifications.go:318-391`). It is never persisted.

**Extracted properties:**
- `title` — text of the first block-level node if it's an H1 heading.
- `has_link` — presence of any link node.
- `has_code` — presence of code block/fenced code block/code span.
- `has_task_list` / `has_incomplete_tasks` — presence of GFM task checkboxes / unchecked ones.
- `tags` — all `#tag` occurrences (deduped, case-preserved, excluding tags inside links/images).
- (transient only, not persisted) `mentions` — `@username`s used for notification dispatch.
- `snippet` — ~64-char plain-text preview built by walking the AST (skipping code blocks), truncated at a word boundary; computed fresh per response, not stored.

Proto definition of the persisted fields: `proto/store/memo.proto`, `MemoPayload.Property` (`has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks`, `title`) plus `MemoPayload.tags`.
