Premise correction: This repository has no GraphQL schema — it doesn't use GraphQL at all. Memos' public API is defined via **Protocol Buffers**, which generate both a gRPC API and a REST/OpenAPI surface.

Actual API surface:
- Proto service definitions live under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`), with shared/internal store types in `proto/store/*.proto`.
- Codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`.
- Generated Go bindings: `proto/gen/api/v1/` and `proto/gen/store/`.
- Generated OpenAPI (REST) spec derived from the same protos: `proto/gen/openapi.yaml`, embedded at runtime via `proto/openapi_embed.go`.
- Server-side routing that exposes these as HTTP/gRPC endpoints: `server/router/api/`.

So "the GraphQL schema" doesn't exist here — the equivalent source of truth for the public API contract is the `.proto` files in `proto/api/v1/`.
