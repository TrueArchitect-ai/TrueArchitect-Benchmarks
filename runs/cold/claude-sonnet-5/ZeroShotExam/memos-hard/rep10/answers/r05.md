Premise correction: this repository (usememos/memos) has no GraphQL API — there is no GraphQL schema anywhere in the codebase (confirmed via repo-wide search; zero matches for "graphql").

Actual API surface: Memos exposes its public API via **Protocol Buffers / gRPC**, with a REST surface generated from the same proto definitions (grpc-gateway) plus an OpenAPI spec:
- Proto service/message definitions: `proto/api/` (source of truth for the API)
- Generated Go/gRPC-gateway code: `proto/gen/api/`
- Generated OpenAPI (Swagger) spec: `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- HTTP router wiring for the REST gateway: `server/router/api/`

So if you're looking for "the schema of the public API," the equivalent artifact is the `.proto` files under `proto/api/` (and the derived `openapi.yaml`), not a GraphQL SDL file.
