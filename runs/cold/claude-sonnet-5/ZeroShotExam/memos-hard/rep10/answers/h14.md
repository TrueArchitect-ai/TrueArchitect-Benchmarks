**Computation site:** `internal/markdown/markdown.go:355-421`, function `(s *service) ExtractAll(content []byte) (*ExtractedData, error)`. It runs a single goldmark AST walk over the memo's Markdown content and is invoked via `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (the persisted `MemoPayload` proto, `proto/gen/store/memo.pb.go`).

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, called on every new memo before it's persisted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes the `content` field (i.e., the memo's text actually changed).
- A batch backfill job, `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72`, which pages through all memos (100 at a time) and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each. Note: unlike the sibling `s3presign.Runner` (wired into `server/server.go:162-163` and ticker-scheduled), this `memopayload.Runner` is never instantiated/called anywhere in `server.go` or elsewhere in the codebase — it exists as standalone rebuild logic (e.g., for manual/ops use) but isn't currently triggered automatically by the running server.

**Extracted properties** (from `ExtractedData` / `MemoPayload_Property`, `internal/markdown/markdown.go:20-25` and `proto/gen/store/memo.pb.go:85-95`):
- `Tags` — all `#tag` occurrences (deduped, case preserved), stored on `memo.Payload.Tags`.
- `Property.Title` — text of the first H1 heading if it's the document's first block.
- `Property.HasLink` — whether any Markdown link node is present.
- `Property.HasCode` — whether any code block/fenced code block/code span is present.
- `Property.HasTaskList` — whether any task checkbox (`- [ ]`/`- [x]`) is present.
- `Property.HasIncompleteTasks` — whether any unchecked task checkbox is present.
- (Mentions (`@username`) are also extracted into `ExtractedData.Mentions` during the same walk, but `RebuildMemoPayload` does not persist them onto `memo.Payload` — mentions are instead consumed separately via `memo_mention_helpers.go:32`.)

Note: memo preview *snippets* (plain-text excerpts) are a separate, non-persisted computation — `GenerateSnippet` in `internal/markdown/markdown.go`, called on-the-fly at list/read time (e.g. `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-89`), not part of the stored `Payload`.
