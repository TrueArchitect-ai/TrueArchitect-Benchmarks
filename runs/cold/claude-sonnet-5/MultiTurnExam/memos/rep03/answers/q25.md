Engine: CEL (Common Expression Language, via `google/cel-go`) — internal/filter/engine.go (parsing/compilation) and internal/filter/schema.go (field/dialect schema), internal/filter/render.go (SQL rendering)

Mechanism: `ListMemos`'s filter string is parsed/compiled by the CEL engine into an internal IR (internal/filter/ir.go), which `render.go` then walks to emit dialect-specific SQL fragments (per-`DialectName` — sqlite/mysql/postgres — using per-field expression templates defined in `schema.go`, e.g. `UNIX_TIMESTAMP(%s)` for MySQL vs raw epoch columns for Postgres/SQLite) that get appended to the driver's WHERE clause.
