q25. Engine: CEL (Common Expression Language, via `google/cel-go`) — implemented in `internal/filter/` (`engine.go` defines `Engine`/`Compile`, with `ir.go`, `render.go`, `parser.go`, `schema.go` supporting it)

Mechanism: `ListMemos`'s `find.Filters` (raw CEL expression strings) are compiled by `filter.Engine.Compile` into a dialect-agnostic `Condition` tree (an intermediate representation, `internal/filter/ir.go`), which each store dialect driver (e.g. `store/db/postgres/memo.go:58`, calling `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectPostgres, &where, &args)`) then renders into dialect-specific SQL WHERE clauses and bound arguments via `render.go`, parameterized per the target SQL dialect (Postgres/MySQL/SQLite).
