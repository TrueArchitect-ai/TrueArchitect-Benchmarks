q25. Engine: CEL (Common Expression Language, via `google/cel-go`), implemented in `internal/filter/engine.go` (and schema in `internal/filter/schema.go`).

Mechanism: `ListMemos` stores the raw filter string on `store.FindMemo.Filters` (`store/memo.go:72`), and each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`) builds a `filter.Engine` via `filter.DefaultEngine()` and calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` to compile the CEL expression into a dialect-specific condition tree and append the corresponding `WHERE` clause/args to the SQL query (with a `DialectSQLite`/`DialectPostgres`/`DialectMySQL` per driver).
