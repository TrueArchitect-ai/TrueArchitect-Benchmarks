q29. Interceptor: `web/src/connect.ts` (`authInterceptor`, lines 156-178)

Token kinds it manages:
- **Access token** — short-lived JWT, held in memory/JS state (`getAccessToken`/`setAccessToken` from `web/src/auth-state`), attached as `Authorization: Bearer <token>` on each request
- **Refresh token** — sent automatically as an HttpOnly cookie (`credentials: "include"`), used to silently mint new access tokens via `AuthService.RefreshToken` when the access token is missing/expired or a request gets a 401

Backend validation package: `server/auth` (e.g. `AuthenticateByAccessTokenV2` and `AuthenticateByRefreshToken` in `server/auth/authenticator.go`)
