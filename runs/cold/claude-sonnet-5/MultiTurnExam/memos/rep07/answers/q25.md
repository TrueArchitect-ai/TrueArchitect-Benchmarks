Engine: CEL (Common Expression Language, via `google/cel-go`) — `internal/filter/engine.go` (parsing/compilation) together with `internal/filter/render.go` (SQL rendering)

Mechanism: `Engine.Compile` parses the filter string into a CEL AST/`Program` (`internal/filter/engine.go`), and `Program.Render`/the `render.go` renderer walks that condition tree to emit a parameterized `WHERE` clause, branching per `DialectName` (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`) to produce dialect-specific SQL fragments (e.g. different JSON/date-part functions) for each backend.
