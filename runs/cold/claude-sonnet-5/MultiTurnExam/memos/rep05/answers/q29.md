Token kinds managed: a short-lived JWT **access token** (kept in-memory, attached as `Authorization: Bearer <token>`) and a **refresh token** (stored as an httpOnly cookie, sent via `credentials: "include"` and used to mint new access tokens); also supports **Personal Access Tokens (PAT)** as an alternative credential.

Backend validation package: server/auth (server/auth/authenticator.go) — `Authenticator.AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT` validate these respectively, unified in `AuthenticateToUser`.
