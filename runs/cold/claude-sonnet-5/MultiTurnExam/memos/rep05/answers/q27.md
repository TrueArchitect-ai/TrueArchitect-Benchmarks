The compiled React app's static files are embedded into the Go binary using `//go:embed dist/*` (server/router/frontend/frontend.go:20-21), then served by `echo`'s `middleware.StaticWithConfig` plus an SPA-fallback middleware that serves `index.html` for unmatched routes — all wired up in `FrontendService.Serve` (server/router/frontend/frontend.go:40-59).
