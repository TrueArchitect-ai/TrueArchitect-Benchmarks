Token kinds: a short-lived **access token** (JWT, managed in-memory/JS state via `getAccessToken`/`setAccessToken` in `web/src/auth-state.ts`, sent as an `Authorization: Bearer` header) and a longer-lived **refresh token** (stored as an HttpOnly cookie, e.g. `memos_refresh`, used only to silently mint new access tokens via `AuthService.RefreshToken`).

Backend package that validates them: `server/auth` (e.g. `server/auth/authenticator.go`, `server/auth/token.go`).
