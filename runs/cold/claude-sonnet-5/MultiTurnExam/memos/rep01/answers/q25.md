q25. Engine: CEL (Common Expression Language, via `cel-go`) — `internal/filter/engine.go` (with `internal/filter/parser.go`, `ir.go`, `render.go`, `schema.go` supporting it).

Mechanism: `Engine.CompileToStatement` compiles the CEL filter string into a dialect-agnostic condition tree (`ir.go`) and then `render.go` walks that tree with a `RenderOptions{Dialect: ...}` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) to emit the appropriate parameterized SQL fragment and args for each database's syntax (e.g. SQLite's `json_each`/backticks vs. Postgres's `jsonb_array_elements_text`/`$1` placeholders vs. MySQL's `JSON_TABLE`/`?` placeholders), which callers like `store/db/{sqlite,postgres,mysql}/memo.go` splice into the `ListMemos` query via `AppendConditions` (`internal/filter/helpers.go:9`).
