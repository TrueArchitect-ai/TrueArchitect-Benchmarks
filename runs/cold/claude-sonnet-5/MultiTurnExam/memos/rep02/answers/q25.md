q25. **Engine**: CEL (Common Expression Language) via `google.golang.org/cel-go`, implemented in `internal/filter/engine.go` (with supporting files `internal/filter/ir.go`, `internal/filter/render.go`, `internal/filter/schema.go`).

**Mechanism**: The filter string is compiled by a CEL `cel.Env` into an AST (`Engine.Compile` in `engine.go`), converted into a dialect-agnostic `Condition` tree (`ir.go`), and then a `renderer` in `render.go` walks that tree and emits dialect-specific SQL (with the correct placeholder style and JSON/date functions) based on a `DialectName` (postgres/mysql/sqlite) passed via `RenderOptions`.
