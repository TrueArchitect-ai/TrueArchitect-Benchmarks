**Delivery function**: `Post` in `internal/webhook/webhook.go:120-180` (invoked synchronously, or asynchronously via `PostAsync`/`asyncPostQueue` at `internal/webhook/webhook.go:184-196`) — this is where the actual outbound HTTP POST to the external webhook URL is executed, via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**Protection mechanism**: SSRF protection is enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59-77`), which is wired in as the `DialContext` of the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname and rejects any resolved IP that falls in a reserved/private range (blocking DNS-rebinding attacks too), using `isReservedIP` defined in `internal/webhook/validate.go:44-54`, which checks against the `reservedCIDRs`/`reservedNetworks` list (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and their IPv6 equivalents) at `internal/webhook/validate.go:14-36`. There's also an upfront check, `ValidateURL` (`internal/webhook/validate.go:62-83`), used when a webhook URL is registered/saved, that performs the same reserved-IP validation before persisting the target.
