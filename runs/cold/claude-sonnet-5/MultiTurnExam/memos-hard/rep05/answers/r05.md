r05. **Premise correction**: There is no GraphQL schema or GraphQL API in this repository — no GraphQL dependency in `go.mod`/`go.sum`, and no `.graphql`/`.gql` schema files anywhere in the tree.

**Actual API surface**: The public API is defined via **Protocol Buffers** and served over gRPC / gRPC-Gateway / Connect. The `.proto` service definitions live under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`), with generated Go code in `proto/gen/api/v1/` (including `apiv1connect/` for Connect-RPC handlers and `.pb.gw.go` files for the REST/JSON gateway) and a generated OpenAPI description at `proto/gen/openapi.yaml`. Server-side, these services are implemented by `APIV1Service` in `server/router/api/v1/` and registered via `RegisterGateway`/`RegisterRoutes` (e.g. `server/router/api/v1/v1.go`), exposing both gRPC/Connect and gRPC-Gateway JSON/REST endpoints — not GraphQL.
