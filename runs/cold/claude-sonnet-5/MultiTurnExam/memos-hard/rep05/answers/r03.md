r03. **Premise correction**: There is no nightly database-cleanup job scheduled anywhere in this codebase — the premise doesn't hold.

The repo does contain a generic cron-scheduling library at `internal/scheduler/` (`scheduler.go`, `parser.go`, `job.go`, `middleware.go`), and its `doc.go` example even shows a `"daily-cleanup"` job name as a *usage illustration* (`internal/scheduler/doc.go:15-18`). But that's documentation only — no production code ever calls `scheduler.New`/`Register`/`Start`. The only files importing `internal/scheduler` are its own `example_test.go` and `integration_test.go`; `server/runner/` only contains two unrelated background jobs — `memopayload` (rebuilds memo tag/property metadata, invoked directly, not via this scheduler) and `s3presign` (refreshes S3 presigned URLs every 12 hours via a plain `time.Ticker`, not the scheduler package). Neither performs database cleanup, and neither runs "nightly." There's no vacuum/prune/cleanup cron job wired into server startup at all.
