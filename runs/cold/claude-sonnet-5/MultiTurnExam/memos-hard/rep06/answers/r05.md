**Premise correction:** This API is not GraphQL — there is no GraphQL schema, dependency, or reference anywhere in the repository (no `.graphql`/`.gql` files, no GraphQL library in `go.mod` or `web/package.json`).

**Actual API surface:** The public API is defined via Protocol Buffers, generated into gRPC/Connect and REST (gRPC-Gateway) surfaces. Service definitions live under `proto/` (e.g. `proto/api/v1/memo_service.proto`-style sources, generated into `proto/gen/api/v1/*.pb.go`, `proto/gen/api/v1/apiv1connect/*.connect.go`), and are registered/served in `server/router/api/v1/` — e.g. `v1.go` (`RegisterGateway`) wires up both the Connect handlers and the gRPC-Gateway REST reverse-proxy. So the API surface is gRPC + Connect-RPC + gRPC-Gateway-generated REST/JSON, not GraphQL.
