**Extracted properties** (via a single AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — all `#tag` occurrences (deduplicated, case-preserved).
- `Mentions` — all `@mention` usernames (lower-cased, deduplicated) — collected in `ExtractedData` but not persisted by `RebuildMemoPayload` (only `Tags`/`Property` are written to `memo.Payload`).
- `Property.Title` — text of a leading H1 heading, if the document's first block is one.
- `Property.HasLink` — whether the content contains a link.
- `Property.HasCode` — whether it contains a code block/span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether it contains task-list checkboxes, and whether any are unchecked.
