**Premise correction**: There is no GraphQL schema in this repository — a search for "graphql" across all `.go`/`.proto` files and `go.mod`, plus a filesystem search for `.graphql`/`.gql` files, returns zero results. This project does not expose a GraphQL API.

**Actual API surface**: The public API is defined via Protocol Buffers (gRPC + a REST/JSON gateway), in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), with generated Go bindings in `proto/gen/api/`. These are implemented by the handlers under `server/router/api/v1/*.go` and served over both gRPC and a REST gateway (grpc-gateway) from the same server process.
