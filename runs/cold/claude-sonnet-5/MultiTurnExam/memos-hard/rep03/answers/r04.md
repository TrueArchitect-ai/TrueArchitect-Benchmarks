**Premise correction**: There is no external message broker (neither NATS nor RabbitMQ) anywhere in this codebase — a search for "nats", "rabbitmq", and "amqp" across all `.go` files and `go.mod` returns zero hits.

**Actual mechanism**: Webhook delivery uses an in-process Go channel, not a broker. `internal/webhook/webhook.go` declares `asyncPostQueue` as a buffered Go channel (populated by `PostAsync`, line 184), and a fixed pool of 4 worker goroutines started in `init()` (lines 42-55) drain that channel and call `Post` (line 46 → `Post` defined at line 120) to perform the actual outbound HTTP delivery. This is entirely in-memory within the single server process — no queue is declared on any external broker.
