**Protection mechanism**: SSRF protection is enforced at dial time via a custom `DialContext` (`safeDialContext`, `internal/webhook/webhook.go:57-77`) wired into `safeClient`'s transport (lines 32–37). It resolves the target host and rejects the connection if any resolved IP is "reserved" per `isReservedIP` in `internal/webhook/validate.go:44-54`, which checks against a blocklist of loopback, RFC-1918 private, link-local/cloud-metadata, and IPv6 loopback/unique-local/link-local CIDR ranges (`reservedCIDRs`, `internal/webhook/validate.go:14-23`). Because validation happens against the IP actually dialed (not a separately-resolved one), this also closes the DNS-rebinding gap. A separate pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), runs the same `isReservedIP` logic at webhook registration time for defense-in-depth (a package-level `AllowPrivateIPs` flag at lines 38-41 can disable the checks for self-hosted deployments).
