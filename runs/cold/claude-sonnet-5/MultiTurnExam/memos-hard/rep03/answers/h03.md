**Abstraction package**: `internal/idp` (import path `github.com/usememos/memos/internal/idp`) — defines the shared `IdentityProviderUserInfo` type (`internal/idp/idp.go`) that all provider implementations return; the provider "interface" is structural (constructor + `ExchangeToken`/`UserInfo` methods) rather than a declared Go `interface`.

**Implementation package**: `internal/idp/oauth2` (import path `github.com/usememos/memos/internal/idp/oauth2`) — the sole concrete protocol implementation, providing an `IdentityProvider` struct with `NewIdentityProvider`, `ExchangeToken` (PKCE-aware), and `UserInfo` methods (`internal/idp/oauth2/oauth2.go`), wired in via `server/router/api/v1/auth_service_sso.go`.
