**Premise correction:** There is no GraphQL schema in this repository — a repo-wide, case-insensitive search for "graphql" (`.go` files) returns zero matches.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC**, in `.proto` service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`). These are compiled into generated Go code in `proto/gen/api/v1/` — gRPC server/client stubs (`*_grpc.pb.go`), message types (`*.pb.go`), a gRPC-Gateway REST/JSON transcoding layer (`*.pb.gw.go`, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`), and Connect-RPC bindings (`proto/gen/api/v1/apiv1connect/`). So the "schema" equivalent lives in the `.proto` files under `proto/api/v1/`, and the API is served as gRPC (with an HTTP/JSON gateway), not GraphQL.
