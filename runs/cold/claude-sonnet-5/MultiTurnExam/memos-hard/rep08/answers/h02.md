**Delivery function:** `Post(requestPayload *WebhookRequestPayload)` in `internal/webhook/webhook.go:120-180` — it marshals the payload, builds the POST request, optionally signs it, and sends it via the package's shared `safeClient` (`internal/webhook/webhook.go:32-37`). It's invoked synchronously by `Post`, or asynchronously via a bounded worker queue in `PostAsync` (`internal/webhook/webhook.go:184-196`), whose 4 background goroutines call `Post` (`internal/webhook/webhook.go:42-55`).

**Protection mechanism:** `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the custom `DialContext` on `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:34-36`). It resolves the target hostname at dial time and rejects the connection if any resolved IP falls within a reserved/private range, checked via `isReservedIP` in `internal/webhook/validate.go:44-54` against the CIDR list in `internal/webhook/validate.go:14-23` (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents). Dialing at request time (rather than only validating the URL upfront via `ValidateURL` in `internal/webhook/validate.go:62-83`) also defeats DNS-rebinding attacks. Protection can be disabled via the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments.
