**Premise correction:** There is no GraphQL schema in this repository — a search for "graphql" across all Go and TypeScript/TSX files returns zero hits.

**Actual API surface:** The public API is defined as Protocol Buffers under `proto/api/v1/` — one `.proto` file per resource/service: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`. These are compiled into generated Go code under `proto/gen/api/v1/` (gRPC service stubs, `grpc-gateway` HTTP/JSON reverse-proxy handlers `*.pb.gw.go`, and Connect-RPC handlers), and served over gRPC/Connect and a REST-ish gRPC-Gateway, wired up in `server/router/api/v1/v1.go` (`RegisterGateway`). So the API is gRPC + grpc-gateway/Connect, following the AIP (API Improvement Proposals) resource-oriented design style — not GraphQL.
