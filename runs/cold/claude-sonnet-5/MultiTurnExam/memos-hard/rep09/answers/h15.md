Memo visibility enforcement appears at multiple independent server surfaces:

1. **gRPC/Connect memo read access** — `(*APIV1Service).checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39-68` (gates `GetMemo` and other single-memo reads; denies Private memos to non-creators, Protected/Private to unauthenticated users)

2. **gRPC/Connect memo list filtering** — `server/router/api/v1/memo_service.go:219-225` (constrains `VisibilityList` on `ListMemos` based on the requester — anonymous callers get only `Public`, authenticated non-owners get `Public`+`Protected`)

3. **File server / attachment serving** — `(*FileServerService).checkAttachmentPermission` — `server/router/fileserver/fileserver.go:650-704` (checks the parent memo's visibility before streaming attachment bytes over `/file/attachments/...`)

4. **Reaction service** — `server/router/api/v1/reaction_service.go:30-38,83` (checks memo visibility/ownership before allowing reaction creation/listing/deletion on a memo)

5. **Attachment RPC service** — `server/router/api/v1/attachment_service.go:445-451` (checks memo visibility before returning/listing attachments via the API service, distinct from the file-serving path in #3)

6. **Memo comments service** — `server/router/api/v1/memo_service_comments.go:41,100` (checks the related memo's visibility/ownership before allowing comment creation)

7. **SSE real-time push** — `(*SSEClient).canReceive` — `server/router/api/v1/sse_hub.go:134-144` (filters which connected clients receive a live memo event based on the event's `Visibility` and `CreatorID`)

8. **RSS feed generation** — `server/router/rss/rss.go:90,141` (restricts feed contents to `store.Public` memos only)

9. **Sitemap generation** — `server/router/frontend/frontend.go:150` (restricts `sitemap.xml` to `store.Public` memos only)
