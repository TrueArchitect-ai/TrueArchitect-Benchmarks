- `Property.HasLink` — presence of any markdown link.
- `Property.HasCode` — presence of code blocks/fenced code blocks/inline code spans.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — presence of task checkboxes, and whether any are unchecked.
