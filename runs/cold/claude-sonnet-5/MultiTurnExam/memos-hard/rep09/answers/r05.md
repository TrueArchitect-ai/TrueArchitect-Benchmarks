**Premise correction:** There is no GraphQL schema anywhere in this repository — I found zero references to "graphql" across the Go backend or the TypeScript frontend.

**Actual API surface:** The public API is defined as Protocol Buffers under `proto/api/v1/` — separate `.proto` service files for each domain (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to generated Go code under `proto/gen/api/v1/` (referenced throughout `server/router/api/v1/` as `v1pb`), and served over gRPC together with a gRPC-Gateway/Connect-RPC bridge for HTTP/JSON access — wired up in `server/router/api/v1/v1.go` (`RegisterGateway`, `server/router/api/v1/v1.go:65`). There's no GraphQL layer alongside or instead of this gRPC/Connect API.
