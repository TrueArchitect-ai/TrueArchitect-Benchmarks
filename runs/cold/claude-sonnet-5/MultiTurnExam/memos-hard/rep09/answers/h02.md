**Delivery function:** `Post` (also queued/dispatched asynchronously via `PostAsync`) in `internal/webhook/webhook.go:120` — it builds the HTTP request and executes it via the shared `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**Protection mechanism:** SSRF protection is enforced at dial time by `safeDialContext`, the custom `DialContext` installed on `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`, function defined at `internal/webhook/webhook.go:59-77`). It resolves the target hostname and rejects any resolved IP that falls within a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, checked against `reservedNetworks`/`reservedCIDRs` covering loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents — `internal/webhook/validate.go:14-23`). Because the check happens at dial time against the actually-resolved IP (not just the hostname), it also defeats DNS-rebinding attacks. There's also a pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), used by callers before saving/using a webhook URL, applying the same `isReservedIP` logic.
