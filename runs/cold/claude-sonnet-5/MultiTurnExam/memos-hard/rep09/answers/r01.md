**Premise correction:** There is no Redis connection anywhere in this codebase — I grepped the entire repository (case-insensitive) for "redis" and got zero hits, in Go source or elsewhere. The cache layer is not backed by an external cache server at all.

**Actual mechanism:** Caching is done with an in-process, in-memory cache implemented in `store/cache/cache.go`. The `Store` struct holds three such caches — `instanceSettingCache`, `userCache`, and `userSettingCache` (`store/store.go:27-29`) — each constructed via `cache.New(cacheConfig)` in `(*Store) New` (`store/store.go:47-56`).

The TTL applied to user cache entries (as with the other two caches, since they share one `cacheConfig`) is the `DefaultTTL` set at `store/store.go:41`: **10 minutes** (`cache.Config{DefaultTTL: 10 * time.Minute, CleanupInterval: 5 * time.Minute, MaxItems: 1000, ...}`, `store/store.go:40-45`). Expired entries are purged by a background cleanup loop that runs every 5 minutes, per `CleanupInterval`.
