**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this codebase.

There is an `internal/scheduler` package (`internal/scheduler/scheduler.go`, with cron-expression parsing in `internal/scheduler/parser.go`) that implements a generic cron scheduler with `Register`/`Start`/`Stop` methods — but it is never imported or instantiated by any production code. Grepping the whole repo confirms the only files that reference `github.com/usememos/memos/internal/scheduler` are its own tests (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`); `server/` and `cmd/` never call `scheduler.New(...)`. It's dead/unused library code, not wired into the running server.

The only actual periodic background jobs in the server are the ones started in `startBackgroundRunners` (`server/server.go:153-174`) — the S3 presign runner (every 12 hours, see h01) — plus an in-memory cache cleanup loop (`store/cache/cache.go:200`, every `CleanupInterval` = 5 minutes, per r01) that purges expired cache *entries*, not database rows. Neither is a "nightly database cleanup" job, and neither runs on a fixed clock time (both are interval-based, not cron-scheduled) — so there's no cron schedule or specific time-of-day to report.
