h03.

**Abstraction package**: `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` type used across identity-provider implementations.

**Implementation package**: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the concrete OAuth2 `IdentityProvider` implementation (token exchange, user-info fetching) that ships in the repo.
