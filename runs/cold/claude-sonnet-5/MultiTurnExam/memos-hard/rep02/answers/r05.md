**Premise correction**: There is no GraphQL schema in this codebase — a full search for "graphql" (case-insensitive, across all Go files) and for `.graphql`/`.graphqls` schema files returns nothing.

**Actual API surface**: The public API is defined as Protocol Buffers / gRPC service definitions under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. These are compiled to Go (and a REST/JSON gateway) under `proto/gen/api/v1/`, and the gRPC/gRPC-Gateway handlers are implemented in `server/router/api/v1/`.
