**Premise correction:** There is no GraphQL schema anywhere in this repository. A search for `.graphql` files and for `graphql`/`gqlgen` in `go.mod` and across the codebase turns up nothing.

**Actual API surface:** The public API is defined with Protocol Buffers and served as gRPC / Connect-RPC (with a REST/JSON gRPC-Gateway and OpenAPI layer on top), not GraphQL. The `.proto` source definitions live under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), and are compiled (via `buf`, configured in `proto/buf.gen.yaml`/`proto/buf.yaml`/`proto/buf.lock`) into the generated Go code in `proto/gen/api/v1/` — including `*.pb.go` (protobuf messages), `*_grpc.pb.go` (gRPC service stubs), `*.pb.gw.go` (gRPC-Gateway REST handlers), and the `apiv1connect/` package (Connect-RPC handlers). An OpenAPI document is also embedded via `proto/openapi_embed.go`. These generated services are registered onto the HTTP server in `server/router/api/v1/v1.go` (`APIV1Service.RegisterGateway`).
