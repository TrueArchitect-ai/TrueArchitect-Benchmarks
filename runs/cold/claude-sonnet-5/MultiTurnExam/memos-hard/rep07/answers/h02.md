h02.

**Delivery function:** `Post` in `internal/webhook/webhook.go:120-180` (invoked synchronously, and also queued for async dispatch via `PostAsync`/`asyncPostQueue` at `internal/webhook/webhook.go:184-196`). It builds the HTTP request and sends it through the package's shared `safeClient` (`internal/webhook/webhook.go:32-37`).

**Protection mechanism:** SSRF protection is enforced at the network-dial layer, not just at validation time. The `safeClient`'s `http.Transport` uses `safeDialContext` (`internal/webhook/webhook.go:59-77`), which resolves the destination host and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` — defined in `internal/webhook/validate.go:44-54`, checking against `reservedCIDRs`/`reservedNetworks` (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents) at `internal/webhook/validate.go:14-36`. This defeats DNS-rebinding attacks since the check happens at actual dial time against the resolved IP, not just at URL-registration time. A separate, earlier check — `ValidateURL` in `internal/webhook/validate.go:62-83` — performs the same reserved-IP check up front when a webhook URL is registered/saved, using the same `isReservedIP` helper. Both can be disabled for self-hosted/local-network use via the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
