**Premise correction:** There is no GraphQL schema in this codebase — a full search for "graphql" across all Go source returns zero hits, and there are no `.graphql`/schema files anywhere in the repo.

**Actual API surface:** The public API is defined via **Protocol Buffers**, not GraphQL. Service definitions live under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `common.proto`), compiled via `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`) into generated Go code under `proto/gen/`. This is exposed to clients three ways:
- gRPC directly (generated `*_grpc.pb.go` / Connect handlers in `proto/gen/api/v1/apiv1connect/`)
- A REST/JSON gateway via grpc-gateway (`*.pb.gw.go` files, wired in `server/router/api/v1/v1.go`)
- A generated OpenAPI v3 spec, embedded and served at runtime via `proto/openapi_embed.go`, which `//go:embed`s `proto/gen/openapi.yaml`.

So if you're looking for the schema describing the public API surface, it's `proto/api/v1/*.proto` (source of truth) and `proto/gen/openapi.yaml` (generated OpenAPI description), not a GraphQL schema.
