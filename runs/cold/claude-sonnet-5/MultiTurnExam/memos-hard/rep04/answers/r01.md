r01.

**Premise correction:** There is no Redis anywhere in this repository — `go.mod`, source, and docs contain no Redis client or dependency. The cache layer is a self-contained, thread-safe **in-memory** cache (`sync.Map`-backed), not backed by any external store, so there's no "Redis connection" to configure.

**Actual mechanism:** The cache type is `Cache` in `store/cache/cache.go:67-72`, created via `cache.New(cacheConfig)`. The user cache specifically (`userCache *cache.Cache`, `store/store.go:28`) is constructed in `Store.New` at `store/store.go:52`, using the `cacheConfig` built at `store/store.go:38-43`:
```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```
So user entries get a **10-minute default TTL**, with a background cleanup sweep every 5 minutes (`store/cache/cache.go:57`/`DefaultConfig()` shows the same defaults). This is process-local memory, not a networked Redis instance — it's population happens in `Store.GetUser`/`Store.ListUsers` (`store/user.go:136-168`) and is cleared on `Store.Close` (`store/store.go:75`).
