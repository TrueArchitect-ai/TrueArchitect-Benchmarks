**Premise correction:** There is no GraphQL schema anywhere in this repository — no `.graphql`/`.gql` files, no GraphQL library in `go.mod`, and no hits for "graphql" in source or docs.

**Actual API surface:** The public API is defined with **Protocol Buffers / gRPC**, not GraphQL. Service definitions live as `.proto` files under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `attachment_service.proto`, `user_service.proto`, `auth_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`). These are compiled into generated Go code under `proto/gen/api/v1/` — plain gRPC server/client stubs (`*_grpc.pb.go`), gRPC-gateway REST transcoding (`*.pb.gw.go`), and Connect-protocol handlers (`proto/gen/api/v1/apiv1connect/`) — giving the API three concurrent transports (gRPC, REST via gateway, and Connect) all generated from the same `.proto` schema, wired up in `server/router/api/v1/v1.go`.
