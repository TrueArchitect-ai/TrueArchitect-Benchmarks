The `store.Driver` interface (`store/driver.go`) has three implementations, one per SQL backend:

- `store/db/sqlite/sqlite.go` — `DB` struct + `NewDB` (SQLite, via `modernc.org/sqlite`)
- `store/db/postgres/postgres.go` — `DB` struct + `NewDB` (PostgreSQL, via `github.com/lib/pq`)
- `store/db/mysql/mysql.go` — `DB` struct + `NewDB` (MySQL, via `github.com/go-sql-driver/mysql`)

Factory function that selects between them at startup:

`NewDBDriver` — `store/db/db.go`

It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) to call the corresponding package's `NewDB`, and is invoked from `cmd/memos/main.go` (line 57) during application startup.
