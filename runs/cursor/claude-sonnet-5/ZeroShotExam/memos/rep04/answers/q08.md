**Driver — `store/driver.go`**

The `Driver` interface (`store/driver.go:10-86`) defines all the methods that a store database backend must implement (attachments, memos, users, settings, identity providers, inbox, reactions, etc.). It's implemented by each supported database backend: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go` (wired together in `store/db/db.go`).
