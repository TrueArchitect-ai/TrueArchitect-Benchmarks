**Engine + path:** The `ListMemosRequest.filter` string is Google's [Common Expression Language (CEL)](https://github.com/google/cel-go), parsed by a custom filter engine that lives in `internal/filter` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`), which wraps the `cel-go` library (`github.com/google/cel-go/cel`).

**Mechanism (one sentence):** `filter.Engine.Compile` (`internal/filter/engine.go:48-71`) uses `cel.NewEnv`/`env.Compile` against the memo `Schema` (`internal/filter/schema.go`) to parse and type-check the filter string, `parser.go`'s `buildCondition` walks the resulting CEL AST into a dialect-agnostic IR `Condition` tree (`internal/filter/ir.go`), and then `render.go`'s renderer (invoked via `Program.Render`/`CompileToStatement`) walks that IR to emit a SQL fragment plus placeholder args tailored to `DialectSQLite`, `DialectMySQL`, or `DialectPostgres`; this is invoked per-store-dialect via `filter.AppendConditions` (`internal/filter/helpers.go`) from `store/db/{sqlite,mysql,postgres}/memo.go`, which is what backs `ListMemos`'s filter after `APIV1Service.ListMemos` (`server/router/api/v1/memo_service.go:211-216`) validates the raw request filter with `validateFilter` (`server/router/api/v1/shortcut_service.go:336`) and stores it on `store.FindMemo.Filters`.
