**Runners actually started by the server**

- `s3presign.Runner` — the only background job the server starts. `Server.startBackgroundRunners` (`server/server.go:153-174`) calls `s3presignRunner.RunOnce(ctx)` once immediately, then launches `s3presignRunner.Run(s3Context)` in a goroutine. Scheduling is done inside the runner itself with a plain `time.NewTicker(12 * time.Hour)` (`server/runner/s3presign/runner.go:26-41`) — i.e. a hard-coded 12‑hour interval, no cron/config-driven schedule.

**Present but NOT run as a scheduled/background worker**

- `memopayload.Runner` (`server/runner/memopayload/runner.go`) defines a `RunOnce` that batch-rebuilds every memo's payload, but `server/server.go` never constructs or calls it, and no other code does either. The only thing actually used from that package is the standalone `RebuildMemoPayload` helper, invoked synchronously inline inside the create/update memo request handlers (`server/router/api/v1/memo_service.go:108` and `:447`) — i.e. it runs per-request, not as a background job with any schedule.

**Unused scheduling infrastructure**

- `internal/scheduler` (`internal/scheduler/scheduler.go`, `parser.go`, `middleware.go`, `job.go`, `doc.go`, `README.md`) is a full-featured cron scheduler (5/6-field cron expressions, timezone support, middleware for logging/recovery/timeout, graceful shutdown) — but a repo-wide search shows it is imported nowhere outside its own test files. It is not wired into `server.go`, `main.go`, or any runner. This entire package is dead/unused infrastructure as far as the running server is concerned; the only thing actually driving any background execution in the server is the manual `time.Ticker` inside the s3presign runner.

(Minor aside, not a "runner": `store/cache/cache.go` starts its own internal `time.Ticker`-based cleanup goroutine per cache instance, used for the store's in-memory setting/user caches created in `store/store.go`. This is a generic TTL-eviction loop, not a scheduled job/worker in the sense the runner/scheduler packages imply.)
