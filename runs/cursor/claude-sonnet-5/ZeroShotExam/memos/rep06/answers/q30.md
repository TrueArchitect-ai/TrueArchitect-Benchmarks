All four dispatch functions build a `webhook.WebhookRequestPayload` per configured user webhook and hand it to `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43` and `:71`). That is the single convergence point for delivery: `PostAsync` (`internal/webhook/webhook.go:184`) enqueues the payload onto the package-level `asyncPostQueue` channel, which is drained by a fixed pool of 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`); each worker calls `Post(payload)` (`internal/webhook/webhook.go:120`), which is the function that actually builds and signs the HTTP request and performs the outbound `safeClient.Do(req)` delivery to the webhook URL.
