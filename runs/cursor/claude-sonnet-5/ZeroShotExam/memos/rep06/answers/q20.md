q20. Server-Sent Events (SSE) over an HTTP `text/event-stream` endpoint (`GET /api/v1/sse`, implemented in `handleSSE`).

- **Mechanism**: Server-Sent Events (SSE). The endpoint is registered by `RegisterSSERoutes` and served by `handleSSE` in `server/router/api/v1/sse_handler.go`, which streams `data: <json>\n\n` frames (plus periodic heartbeat comments) to each authenticated client over a long-lived HTTP connection.
- **Hub path**: `server/router/api/v1/sse_hub.go` — defines `SSEHub` (a `sync.RWMutex`-guarded registry of `*SSEClient` channels) with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close` methods, plus `SSEEvent`/`SSEEventType` and per-client visibility filtering (`canReceive`).
- **Handlers that broadcast through it** (all call `s.SSEHub.Broadcast(...)`):
  - `CreateMemo` — broadcasts `memo.created` (`server/router/api/v1/memo_service.go:163`)
  - `DeleteMemo` — broadcasts `memo.deleted` (`server/router/api/v1/memo_service.go:585`)
  - `dispatchMemoUpdatedSideEffects` (invoked from `UpdateMemo`) — broadcasts `memo.updated` (`server/router/api/v1/memo_update_helpers.go:71`)
  - `CreateMemoComment` — broadcasts `memo.comment.created` on the parent memo (`server/router/api/v1/memo_service_comments.go:126`)
  - `UpsertMemoReaction` — broadcasts `reaction.upserted` (`server/router/api/v1/reaction_service.go:106`)
  - `DeleteMemoReaction` — broadcasts `reaction.deleted` (`server/router/api/v1/reaction_service.go:161`)
