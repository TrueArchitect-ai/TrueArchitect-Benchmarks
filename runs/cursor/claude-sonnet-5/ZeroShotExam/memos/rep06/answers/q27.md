**Mechanism:** Go's `//go:embed` directive embeds the built frontend assets (Vite output copied into `server/router/frontend/dist/`) into the Go binary as an `embed.FS`, which is then served via Echo's static file middleware (`middleware.StaticWithConfig`) plus a SPA-fallback middleware that serves `index.html` for unmatched routes (404s) — all registered inside the `FrontendService.Serve` method.
