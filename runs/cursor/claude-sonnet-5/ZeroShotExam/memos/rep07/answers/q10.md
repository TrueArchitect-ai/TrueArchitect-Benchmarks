**`store/migration/sqlite/LATEST.sql`**

This file contains the complete, consolidated schema (all `CREATE TABLE`/`CREATE INDEX` statements) for a fresh SQLite database. It's applied by `preMigrate` in `store/migrator.go` (lines 210-229) whenever `driver.IsInitialized` returns false, i.e. on a brand-new install, via `s.getMigrationBasePath() + LatestSchemaFileName` where `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`). This is confirmed by the comment "LATEST.sql: Full schema for new installations (faster than incremental migrations)" (`store/migrator.go:42`) and by the test `TestFreshInstall` in `store/test/migrator_test.go`.
