`MemoService` is exposed over two HTTP-based protocols, both wired up in `RegisterGateway`:

- gRPC-Gateway (REST/JSON, HTTP+JSON transcoding to gRPC) — registration: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` in `server/router/api/v1/v1.go` (line 108, inside `RegisterGateway`)
- Connect protocol (Connect/gRPC-Web for browser clients) — wrapping/registration: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` in `server/router/api/v1/connect_handler.go` (line 40, inside `RegisterConnectHandlers`), which is invoked from `server/router/api/v1/v1.go` (`connectHandler.RegisterConnectHandlers(...)` at line 141)

Note: there is no separate native gRPC server registration (`RegisterMemoServiceServer`) anywhere in `server/` — only these two HTTP-facing protocols are wired up. The MemoService method implementations that the Connect handler delegates to are in `server/router/api/v1/connect_services.go` (lines 306-464), but that file doesn't perform registration itself.
