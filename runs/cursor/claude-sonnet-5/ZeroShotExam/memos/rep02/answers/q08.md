**Driver — `store/driver.go`**

The `Driver` interface is defined in `store/driver.go` (lines 10–86), and it specifies all the methods a database backend driver must implement (attachments, memos, users, settings, identity providers, etc.). Each backend implementation — `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go` — implements this `store.Driver` interface.
