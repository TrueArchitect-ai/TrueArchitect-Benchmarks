In the store layer, `Store.DeleteMemo` (`store/memo.go`) deletes the following records before deleting the `memo` row itself:

- **Memo relation records** where the memo is the source (`memo_relation` rows with `memo_id` matching the deleted memo), via `driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{MemoID: &delete.ID})`.
- **Memo relation records** where the memo is the target/related memo (`memo_relation` rows with `related_memo_id` matching the deleted memo), via `driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{RelatedMemoID: &delete.ID})`.
- **Attachments** linked to the memo: it lists all attachments for the memo (`ListAttachments` with `MemoID`) and deletes each one individually via `DeleteAttachment` (which also removes the attachment's underlying storage/blob, then its DB row).

Only after these deletions does it call `s.driver.DeleteMemo(ctx, delete)` to remove the memo row itself.

```140:159:/bench/repo/store/memo.go
func (s *Store) DeleteMemo(ctx context.Context, delete *DeleteMemo) error {
	// Clean up memo_relation records where this memo is either the source or target.
	if err := s.driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{MemoID: &delete.ID}); err != nil {
		return err
	}
	if err := s.driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{RelatedMemoID: &delete.ID}); err != nil {
		return err
	}
	// Clean up attachments linked to this memo.
	attachments, err := s.ListAttachments(ctx, &FindAttachment{MemoID: &delete.ID})
	if err != nil {
		return err
	}
	for _, attachment := range attachments {
		if err := s.DeleteAttachment(ctx, &DeleteAttachment{ID: attachment.ID}); err != nil {
			return err
		}
	}
	return s.driver.DeleteMemo(ctx, delete)
}
```
