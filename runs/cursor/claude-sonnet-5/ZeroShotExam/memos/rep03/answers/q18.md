The database driver interface is `store.Driver` (defined in `store/driver.go`). It has three implementations, each with an entry file that defines a `NewDB` constructor returning `store.Driver`:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

The factory function that selects between them at startup:

`NewDBDriver` — `store/db/db.go`

It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) to call the corresponding package's `NewDB`, and is invoked at startup from `cmd/memos/main.go:57`.
