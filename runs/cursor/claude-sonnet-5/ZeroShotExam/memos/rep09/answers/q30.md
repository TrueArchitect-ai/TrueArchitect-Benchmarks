**q30.**

Memo lifecycle events that dispatch webhooks, and their dispatch functions (all defined in `server/router/api/v1/memo_service_webhooks.go`):

- memo created: `DispatchMemoCreatedWebhook` (called from `CreateMemo` in `server/router/api/v1/memo_service.go:157`) → internally calls `dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.created")`
- memo updated: `DispatchMemoUpdatedWebhook` (called from `server/router/api/v1/memo_update_helpers.go:67`) → internally calls `dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.updated")`
- memo deleted: `DispatchMemoDeletedWebhook` (called from `DeleteMemo` in `server/router/api/v1/memo_service.go:562`) → internally calls `dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.deleted")`
- memo comment created: `DispatchMemoCommentCreatedWebhook` (called from `server/router/api/v1/memo_service_comments.go:119`) — this one does not go through `dispatchMemoRelatedWebhook`; it builds the payload and loop inline itself.

All four ultimately converge on the same delivery path: each constructs a `*webhook.WebhookRequestPayload` (via `convertMemoToWebhookPayload`, `memo_service_webhooks.go:76`) and hands it to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues it onto `asyncPostQueue`; a pool of 4 worker goroutines (started in `init()`, `internal/webhook/webhook.go:42-55`) reads from that queue and calls `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual signed HTTP POST to the webhook URL via `safeClient`.
