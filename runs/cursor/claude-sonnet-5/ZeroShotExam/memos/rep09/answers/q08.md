**Driver — `store/driver.go`**

The `Driver` interface (defined at `store/driver.go:10`) declares all the methods a database backend must implement (attachments, memos, users, settings, identity providers, etc.). It's implemented by each backend driver:

- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`
- `store/db/sqlite/sqlite.go`

with `store/db/db.go` acting as the factory that selects and returns the appropriate `store.Driver` implementation.
