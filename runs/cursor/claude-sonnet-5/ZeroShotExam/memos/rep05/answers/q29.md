Frontend API requests are authenticated by a Connect-RPC interceptor, `authInterceptor`, defined in `web/src/connect.ts` (lines 156–178). It's attached to the shared `createConnectTransport` used by all service clients (`web/src/connect.ts:184-189`). On each request it calls `getRequestToken()` to attach an `Authorization: Bearer <token>` header (`setAuthorizationHeader`, `web/src/connect.ts:97-99`), and on a `Code.Unauthenticated` response it triggers a token refresh (via `refreshAccessToken()`/`doRefreshAccessToken()`, which calls `AuthService.refreshToken`) and retries once before redirecting to login on failure (`redirectOnAuthFailure`).

The token it manages is a short-lived JWT **access token**, stored/tracked in `web/src/auth-state.ts` (kept in memory + `localStorage` under `memos_access_token`/`memos_token_expires_at`, and synced across tabs via a `BroadcastChannel`). The corresponding **refresh token** is not handled by JS/localStorage directly — it's an httpOnly cookie (`memos_refresh`) sent automatically via `credentials: "include"` (`fetchWithCredentials`, `web/src/connect.ts:57-62`) when hitting the refresh endpoint.

On the backend, these tokens are validated by the `auth` package at `server/auth/` (specifically `server/auth/authenticator.go` and `server/auth/token.go`), which defines the `Authenticator` type used by the API interceptors/middleware. It validates:
- JWT **access tokens** (`AccessTokenClaims`, "access", 15-min lifetime) — stateless signature/claims validation via `ParseAccessTokenV2`/`AuthenticateByAccessTokenV2`.
- JWT **refresh tokens** (`RefreshTokenClaims`, "refresh", 30-day lifetime, cookie `memos_refresh`) — validated via `ParseRefreshToken`/`AuthenticateByRefreshToken`, which also checks DB revocation via `store.GetUserRefreshTokenByID`.
- **Personal Access Tokens (PAT)** (prefix `memos_pat_`) — via `AuthenticateByPAT`, hashed and looked up in the store.

**Answer format:** `web/src/connect.ts` (authInterceptor, lines 156–178); JWT access token (`memos_access_token` in localStorage, ~15min) + JWT refresh token (`memos_refresh` httpOnly cookie, ~30 days) + Personal Access Tokens (backend-only, not managed by this interceptor); `server/auth` (`server/auth/authenticator.go`, `server/auth/token.go`)
