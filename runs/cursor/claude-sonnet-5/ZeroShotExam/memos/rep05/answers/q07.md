`web/src/connect.ts`

This file sets up the `ConnectTransport` and calls `createClient(...)` for each ConnectRPC service (e.g., `InstanceService`, `AuthService`, `UserService`, `MemoService`, `AttachmentService`, `AIService`, `ShortcutService`, `IdentityProviderService`), exporting the resulting service clients used throughout the frontend.
