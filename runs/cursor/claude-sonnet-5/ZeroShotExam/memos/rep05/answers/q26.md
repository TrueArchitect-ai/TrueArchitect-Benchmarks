q26. **Tables affected: `memo`, `memo_relation`, `attachment`, and `memo_share`.**

Call chain: the RPC handler `DeleteMemo` (`server/router/api/v1/memo_service.go:518-593`) first finds and deletes any comment memos (memos linked via a `Comment`-typed `memo_relation`) by calling `store.DeleteMemo` for each, then calls `store.DeleteMemo` once more for the target memo itself (`server/router/api/v1/memo_service.go:567-582`).

`Store.DeleteMemo` (`store/memo.go:140-159`) performs the following for every memo it deletes (each comment memo and the target memo):
- **`memo_relation`** – explicitly deletes rows where the memo is the source (`memo_id`) or the target (`related_memo_id`) via `driver.DeleteMemoRelation` (`store/memo.go:142-147`).
- **`attachment`** – explicitly lists and deletes all attachments whose `memo_id` matches, via `ListAttachments`/`DeleteAttachment` (`store/memo.go:148-157`).
- **`memo`** – finally deletes the memo row itself via `driver.DeleteMemo` (`store/memo.go:158`; concrete `DELETE FROM memo WHERE id = ...` in `store/db/postgres/memo.go:244-255`, `store/db/mysql/memo.go:259-270`, `store/db/sqlite/memo.go:237-248`).
- **`memo_share`** – not touched by any Go code, but the schema defines `memo_share.memo_id` with `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/postgres/LATEST.sql:100-109`, `store/migration/mysql/LATEST.sql:100-109`, `store/migration/sqlite/LATEST.sql:101-110`), so deleting the `memo` row cascades to delete its `memo_share` rows at the database level. Note: this cascade is only enforced on Postgres/MySQL — the SQLite driver opens its connection with `_pragma=foreign_keys(0)` (`store/db/sqlite/sqlite.go:53`), disabling FK enforcement, so on SQLite orphaned `memo_share` rows are not actually removed despite the schema's `ON DELETE CASCADE`.

Note: the handler also calls `ListReactions` (`server/router/api/v1/memo_service.go:545-550`) purely to build the webhook payload — it never deletes from the `reaction` table, so `reaction` rows for the memo are **not** removed by `DeleteMemo`.
