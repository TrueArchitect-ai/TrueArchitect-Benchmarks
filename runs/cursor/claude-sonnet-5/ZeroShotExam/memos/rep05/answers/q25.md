- **Engine + path**: The filter syntax is Google's [CEL](https://github.com/google/cel-go) (Common Expression Language), implemented by a custom wrapper engine at `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`).
- **Mechanism**: `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) puts the raw `request.Filter` string into `store.FindMemo.Filters` (after `validateFilter` in `server/router/api/v1/shortcut_service.go:336` pre-checks it via `filter.DefaultEngine().CompileToStatement`); each dialect-specific store driver (`store/db/sqlite/memo.go:57-61`, and the analogous code in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`) then calls `filter.DefaultEngine()` and `filter.AppendConditions(...)`, which parses the CEL expression into a CEL AST (`cel.NewEnv`/`env.Compile` in `internal/filter/engine.go`), normalizes it into a dialect-agnostic IR condition tree via the memo `Schema` (`internal/filter/parser.go`, `schema.go`), and finally renders that IR into a SQL fragment + args tailored to the given `DialectName` (SQLite/MySQL/Postgres) in `internal/filter/render.go`, which is appended to the query's `WHERE` clause.
