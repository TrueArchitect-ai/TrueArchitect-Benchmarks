**Interceptor path**: The frontend auth interceptor (`authInterceptor`) lives in `web/src/connect.ts` (lines 156–178). It's a Connect-RPC `Interceptor` attached to the `createConnectTransport` instance used by all service clients. It reads the access token via `getRequestToken()`, sets the `Authorization: Bearer <token>` header (`setAuthorizationHeader`), and on a `Code.Unauthenticated` response it triggers a token refresh and retries once (adding an `X-Retry` header to prevent infinite loops), redirecting to login (`redirectOnAuthFailure`, in `web/src/utils/auth-redirect.ts`) if the refresh also fails. Token state itself (storage, expiry checks, cross-tab sync via `BroadcastChannel`) is managed in `web/src/auth-state.ts`.

**Token kinds it manages**:
- **JWT access token** – short-lived, stored in `localStorage` (`memos_access_token` / `memos_token_expires_at`), sent as `Authorization: Bearer <token>` on every request.
- **JWT refresh token** – long-lived, kept as an HttpOnly cookie (not touched directly by JS); the interceptor calls `refreshAccessToken()` → `AuthService.refreshToken()` over a separate credentials-included transport (`fetchWithCredentials`, `credentials: "include"`) to mint a new access token when the current one is missing/expired or a request returns Unauthenticated.

**Backend package that validates them**: `server/auth` (see `server/auth/token.go` and `server/auth/authenticator.go`). This package defines the JWT claims/signing (`AccessTokenClaims`, `RefreshTokenClaims`, `ParseAccessTokenV2`, `ParseRefreshToken`) and the `Authenticator` type (`AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`, `AuthenticateToUser`) that the gRPC/Connect API interceptors and the file server use to validate Bearer access tokens, Personal Access Tokens (PAT), and the refresh-token cookie against the `store` package.

Answer format: `web/src/connect.ts` (`authInterceptor`, with token state in `web/src/auth-state.ts`); JWT access token (Bearer, 15 min) + JWT refresh token (HttpOnly cookie, 30 days) + Personal Access Token (PAT); `server/auth` (`server/auth/token.go`, `server/auth/authenticator.go`)
