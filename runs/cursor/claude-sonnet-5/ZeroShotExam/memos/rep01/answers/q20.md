- **Mechanism**: Server-Sent Events (SSE) over a single HTTP endpoint (`GET /api/v1/sse`), registered via `RegisterSSERoutes` and served by `handleSSE`, which streams `data: <json>\n\n` frames (plus periodic heartbeats) to each connected browser (`server/router/api/v1/sse_handler.go`).
- **Hub path**: `server/router/api/v1/sse_hub.go` — defines `SSEHub` (with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`) and `SSEEvent`/`SSEEventType`. It's instantiated once via `NewSSEHub()` and stored on the API service (`server/router/api/v1/v1.go:57`), then wired to the route in `v1.go:125`.
- **Memo handlers that broadcast through it** (all call `s.SSEHub.Broadcast(...)`, in `server/router/api/v1/`):
  - `CreateMemo` (`memo_service.go`, emits `memo.created`)
  - `DeleteMemo` (`memo_service.go`, emits `memo.deleted`)
  - `CreateMemoComment` (`memo_service_comments.go`, emits `memo.comment.created`)
  - `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go`, emits `memo.updated`) — invoked from `UpdateMemo` (`memo_service.go`), and from the attachment/relation update paths in `memo_attachment_service.go` and `memo_relation_service.go`
  - `UpsertMemoReaction` (`reaction_service.go`, emits `reaction.upserted`)
  - `DeleteMemoReaction` (`reaction_service.go`, emits `reaction.deleted`)
