**Driver — `store/driver.go`**

The `Driver` interface is defined in `store/driver.go` (package `store`), lines 10-86. It declares all the methods (e.g., `GetDB`, `Close`, `IsInitialized`, plus CRUD methods for attachments, memos, users, etc.) that a database backend must implement. The three backends — `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres` — each implement this interface, and `store/db/db.go` returns a `store.Driver` from `NewDBDriver` based on the configured `profile.Driver`.
