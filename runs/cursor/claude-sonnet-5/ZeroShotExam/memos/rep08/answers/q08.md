**Driver — `store/driver.go`**

The `Driver` interface is defined in `store/driver.go` (lines 10–86). Its doc comment states: "Driver is an interface for store driver. It contains all methods that store database driver should implement." The three database backends — SQLite (`store/db/sqlite/sqlite.go`), PostgreSQL (`store/db/postgres/postgres.go`), and MySQL (`store/db/mysql/mysql.go`) — each implement this `store.Driver` interface, and `store/db/db.go` uses it to construct the appropriate driver based on configuration.
