`store/migration/sqlite/LATEST.sql`

This is the file the migrator applies for fresh installations. In `store/migrator.go`, `preMigrate` (`store/migrator.go:210-218`) checks if the DB is uninitialized and, if so, loads `s.getMigrationBasePath() + LatestSchemaFileName`, where `getMigrationBasePath()` returns `migration/{driver}/` (`store/migrator.go:254-256`) and `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`). For the `sqlite` driver this resolves to `store/migration/sqlite/LATEST.sql`, which contains the complete current `CREATE TABLE` schema for a fresh SQLite install.
