- **Mechanism**: Server-Sent Events (SSE) over a long-lived HTTP endpoint (`GET /api/v1/sse`), streamed with `Content-Type: text/event-stream`.
- **Hub path**: `server/router/api/v1/sse_hub.go` (the `SSEHub` type, created via `NewSSEHub()`, with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close` methods managing per-client channels); the connection endpoint itself is registered/handled in `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes`, `handleSSE`).
- **Memo/reaction handlers that broadcast via `s.SSEHub.Broadcast(...)`**:
  - `CreateMemo` (`server/router/api/v1/memo_service.go`)
  - `DeleteMemo` (`server/router/api/v1/memo_service.go`)
  - `UpdateMemo` (`server/router/api/v1/memo_service.go`, via the shared helper `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go`)
  - `SetMemoAttachments` (`server/router/api/v1/memo_attachment_service.go`, also via `dispatchMemoUpdatedSideEffects`)
  - `SetMemoRelations` (`server/router/api/v1/memo_relation_service.go`, also via `dispatchMemoUpdatedSideEffects`)
  - `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go`)
  - `UpsertMemoReaction` (`server/router/api/v1/reaction_service.go`)
  - `DeleteMemoReaction` (`server/router/api/v1/reaction_service.go`)
