**Component:** The S3 presign runner, `Runner` in `server/runner/s3presign/runner.go`. It refreshes presigned URLs for S3-backed attachments (`storepb.AttachmentStorageType_S3`), re-signing any attachment whose `LastPresignedTime` is older than 4 days (since presigned URLs expire after 5 days), and stores the new URL/timestamp via `Store.UpdateAttachment` (`server/runner/s3presign/runner.go:85-123`).

**Schedule:** Runs once immediately on startup, then on a repeating `time.Ticker` every 12 hours (`runnerInterval = time.Hour * 12`) until its context is cancelled.

// Schedule runner every 12 hours.
const runnerInterval = time.Hour * 12

func (r *Runner) Run(ctx context.Context) {
	ticker := time.NewTicker(runnerInterval)
	defer ticker.Stop()

	for {
		select {
		case <-ticker.C:
			r.RunOnce(ctx)
		case <-ctx.Done():
			return
		}
	}
}
