- **Delivery function** — `Post` (dispatched via `PostAsync`, which enqueues into `asyncPostQueue` consumed by worker goroutines) in `internal/webhook/webhook.go` (see `Post` at lines 120‑180 and `PostAsync` at lines 184‑196). The actual outbound HTTP call happens at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).
- **Protection mechanism** — the outbound request goes through `safeClient`, a shared `http.Client` whose `Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-37, 59-77`). `safeDialContext` resolves the target hostname and, via `isReservedIP` (`internal/webhook/validate.go:44-54`) checking against `reservedNetworks`/`reservedCIDRs` (`internal/webhook/validate.go:14-36`), refuses to dial any address in loopback, RFC‑1918 private, or link‑local/cloud‑metadata ranges (also covering IPv6 equivalents) — this blocks SSRF at connect time (defeating DNS‑rebinding), independent of the separate `ValidateURL` pre-check (`internal/webhook/validate.go:62-83`) that performs the same reserved-IP check earlier, at webhook-URL-registration time.
