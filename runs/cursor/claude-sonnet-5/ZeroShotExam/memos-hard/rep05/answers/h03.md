The `internal/idp` package defines the identity-provider abstraction (the `IdentityProviderUserInfo` struct used across the codebase for representing a normalized user returned by any provider), and the concrete protocol implementation that ships is `internal/idp/oauth2`, which implements the OAuth2 identity-provider integration (token exchange, user info retrieval, etc., using `golang.org/x/oauth2` and configured via `storepb.OAuth2Config`).

- Abstraction: `internal/idp` (`internal/idp/idp.go`)
- Implementation: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`, package doc: "Package oauth2 implements the OAuth2 identity provider integration.")

**Answer: `internal/idp`; `internal/idp/oauth2`**
