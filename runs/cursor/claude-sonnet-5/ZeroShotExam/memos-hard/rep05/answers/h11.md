The persistent entity types are defined as structs in the `store` package (the data-access layer), e.g. in `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/reaction.go`, `store/inbox.go`, `store/memo_share.go`, `store/memo_relation.go`, `store/user_identity.go`, `store/idp.go`, `store/instance_setting.go`, `store/user_setting.go`.

Counting distinct Go packages outside `store/` that reference each type as `store.<Type>`:

- `store.User` → referenced from 7 packages: `server/auth` (`server/auth/authenticator.go`, `server/auth/context.go`), `server/notification`, `server/router/rss`, `server/router/fileserver`, `server/router/api/v1` (many files, e.g. `server/router/api/v1/user_service.go`), `server/router/api/v1/test`, and `server/router/frontend` (`server/router/frontend/frontend_test.go`).
- `store.Memo` → referenced from 5 packages: `server/notification`, `server/runner/memopayload`, `server/router/rss`, `server/router/api/v1`, and `server/router/frontend`.
- `store.Attachment` → referenced from 3 packages: `server/router/rss`, `server/router/fileserver`, `server/router/api/v1`.
- Others trail further behind (`Inbox`/`MemoShare`: 2 packages; `Reaction`/`MemoRelation`/`UserIdentity`: 1 package each; `IdentityProvider`/`InstanceSetting`/`UserSetting` are only touched via generated protobuf files, not from other Go packages directly).

**Answer:**
1st: `User` (~7 packages: `server/auth`, `server/notification`, `server/router/rss`, `server/router/fileserver`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`)
2nd: `Memo` (~5 packages: `server/notification`, `server/runner/memopayload`, `server/router/rss`, `server/router/api/v1`, `server/router/frontend`)
