Handlers whose execution can transitively trigger an outbound HTTP call to a user-configured URL (the per-user "webhook" URL stored via `CreateUserWebhook`/`UpdateUserWebhook`):

- `CreateMemo` — `server/router/api/v1/memo_service.go:70` → calls `DispatchMemoCreatedWebhook` (`memo_service.go:157`)
- `UpdateMemo` — `server/router/api/v1/memo_service.go:401` → calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`memo_service.go:513`, `memo_update_helpers.go:66-67`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:518` → calls `DispatchMemoDeletedWebhook` (`memo_service.go:562`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` → calls `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)
- (also) `SetMemoAttachments` (`memo_attachment_service.go:16,48`) and `SetMemoRelations` (`memo_relation_service.go:16,48`) → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

Each of these `Dispatch*Webhook` methods (in `server/router/api/v1/memo_service_webhooks.go`) builds a `webhook.WebhookRequestPayload{URL: hook.Url, ...}` from the user's stored webhook config and calls `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; a pool of worker goroutines (started in `webhook.go:42-55`) then calls `webhook.Post`.

Convergence function — `Post` in `internal/webhook/webhook.go:120` (specifically the `safeClient.Do(req)` call at `internal/webhook/webhook.go:152`). This is the single function through which every one of the above RPC paths must pass to actually perform the outbound HTTP request (using the SSRF-guarded `safeClient`/`safeDialContext` defined in the same file).
