Each `Dispatch*Webhook` method (`server/router/api/v1/memo_service_webhooks.go`) loads the user's stored webhook rows (`s.Store.GetUserWebhooks`, i.e. URLs the user configured in their webhook settings) and calls `webhook.PostAsync(payload)`, where `payload.URL = hook.Url`.

**Convergence function before delivery:**

`PostAsync` (`internal/webhook/webhook.go:184`) only enqueues the payload onto `asyncPostQueue`; the queue is drained by four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), each of which calls `Post`. `Post` is the single function that actually builds the request and performs the outbound call via `safeClient.Do(req)`.
