The provider abstraction (the `IdentityProviderUserInfo` type that concrete providers must produce) is defined in the `idp` package, and the only concrete protocol implementation shipped is the `oauth2` sub-package, which implements OAuth2 token exchange and user-info retrieval against that abstraction.

- Abstraction package: `github.com/usememos/memos/internal/idp` (`internal/idp/idp.go`)
- Implementation package: `github.com/usememos/memos/internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which imports `idp` and implements `NewIdentityProvider`, `ExchangeToken`, and `UserInfo` returning `*idp.IdentityProviderUserInfo`.

Answer: `github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`
