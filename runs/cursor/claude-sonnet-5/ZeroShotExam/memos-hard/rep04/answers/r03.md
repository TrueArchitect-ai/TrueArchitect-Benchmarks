Premise correction: There is no nightly "database-cleanup" job actually scheduled in this repository, so no run time exists to report.

What exists instead:
- `internal/scheduler/` (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`) is a generic, standalone cron scheduler library. It is only exercised by its own tests/examples (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`) and is never imported by the application's `server` or `cmd` packages — a repo-wide search for `internal/scheduler` usage outside the package itself returns nothing.
- The only mention of a "cleanup" cron job at all is an illustrative code sample in the package doc comment, `internal/scheduler/doc.go:14-21`, which registers a job named `"daily-cleanup"` with schedule `"0 2 * * *"` (2 AM) — but this is documentation/example code, not a real job wired into the running server.
- The application's actual background jobs, registered in `server/server.go` (`startBackgroundRunners`), are the S3 presign runner (`server/runner/s3presign`) and a memo-payload runner (`server/runner/memopayload`), neither of which does database cleanup or runs on a cron schedule — they run continuously/once at startup, not on a nightly timer.

So there's no real "nightly database-cleanup job" configured anywhere in this codebase to give a scheduled time for.
