**Premise correction:** There is no GraphQL schema in this repository — a repo-wide search for "graphql" (case-insensitive) returns zero hits. The public API is not GraphQL-based at all; it's defined using Protocol Buffers (gRPC + gRPC-Gateway/OpenAPI), managed via [buf](https://buf.build).

**Actual API surface:**
- Service definitions (the real schema-equivalent) live in `proto/api/v1/*.proto`, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`, plus shared types in `proto/api/v1/common.proto`.
- Internal storage-layer proto messages live separately under `proto/store/*.proto` (e.g. `proto/store/memo.proto`, `proto/store/user_setting.proto`).
- Build config for schema generation: `proto/buf.yaml` and `proto/buf.gen.yaml` (using `buf`, with deps on `buf.build/googleapis/googleapis` for gRPC-Gateway annotations).
- Generated Go/gRPC-Gateway code and a generated OpenAPI v3 spec (the closest artifact to a "public API schema" a client would consume) land in `proto/gen/`, including `proto/gen/openapi.yaml`, which is embedded into the Go binary via `proto/openapi_embed.go` and served at runtime.

So if you're looking for "the schema of the public API," the canonical source-of-truth is the `.proto` files in `proto/api/v1/`, and the derived/served artifact is `proto/gen/openapi.yaml`.
