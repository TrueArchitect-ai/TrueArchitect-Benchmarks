Outbound webhook delivery executes in the `Post` function (invoked synchronously or via `PostAsync`'s worker goroutines reading from `asyncPostQueue`) — `internal/webhook/webhook.go` (see `Post`, lines 120-180, and the async dispatch loop in `init`, lines 42-55).

It is protected against SSRF/internal-address targeting by a custom dialer, `safeDialContext`, installed as the `Transport.DialContext` on the shared `safeClient` used by `Post`. This dialer resolves the hostname and rejects any resolved IP that falls in a reserved/private range (checked via `isReservedIP`) before dialing — `internal/webhook/webhook.go` (lines 32-77) together with the reserved-range logic in `internal/webhook/validate.go` (`reservedCIDRs`/`isReservedIP`, lines 14-54). This dial-time check guards against DNS-rebinding bypasses of the separate `ValidateURL` check that runs when a webhook URL is first saved (`internal/webhook/validate.go`, lines 62-83).
