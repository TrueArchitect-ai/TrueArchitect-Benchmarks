**Impl — construction — holders:**

- **impl:** the single unexported `*service` struct (`internal/markdown/markdown.go:57-60`), which wraps a `goldmark.Markdown` instance (using `goldmark` + the repo's custom `extensions`/`renderer` packages for `#tag`/`@mention` parsing and markdown-to-markdown re-rendering). No other type implements `markdown.Service` at runtime (no mocks exist outside tests).

- **construction:** built exclusively by the exported factory `markdown.NewService(opts ...Option)` (`internal/markdown/markdown.go:85-113`). At real runtime it's constructed exactly once, in `apiv1.NewAPIV1Service` (`server/router/api/v1/v1.go:47-51`), with `WithTagExtension()` and `WithMentionExtension()` enabled. That single instance is then threaded into the RSS service in `server/server.go:85` (`rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`), so the whole app shares one `*service` instance. (Other `markdown.NewService(...)` calls only exist in test files: `server/router/rss/rss_test.go:54`, `server/router/fileserver/fileserver_test.go:427`, `server/router/api/v1/test/test_helper.go:44`.)
