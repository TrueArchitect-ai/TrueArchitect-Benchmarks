**Premise correction:** There is no GraphQL schema in this repository — the codebase (this appears to be the Memos project) does not use GraphQL at all. A repo-wide case-insensitive search for "graphql" returns zero hits.

**Actual API surface:** The public API is defined using Protocol Buffers (gRPC + gRPC-Gateway/OpenAPI), not GraphQL. The `.proto` service definitions live under `proto/api/v1/`, e.g.:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These are compiled via `buf` (config in `proto/buf.yaml` and `proto/buf.gen.yaml`) into generated Go/TS/OpenAPI code under `proto/gen/`, and `proto/api/openapi_embed.go` embeds a generated OpenAPI spec for HTTP/REST access to the same API surface (through `proto/api`, likely a gRPC-Gateway). So the closest equivalent to a "public API schema" here is the Protobuf/OpenAPI definitions in `proto/api/v1/`, not a GraphQL schema.
