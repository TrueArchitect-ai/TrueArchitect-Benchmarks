**Computation site**: `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74-88`, which delegates the actual extraction to the goldmark-based markdown service's `ExtractAll()` in `internal/markdown/markdown.go:356-422`. `ExtractAll` parses the memo's raw `Content` into an AST and, in a single walk, fills an `ExtractedData{Tags, Mentions, Property}` struct. `RebuildMemoPayload` then copies `data.Tags` and `data.Property` into `memo.Payload.Tags` / `memo.Payload.Property` (a `storepb.MemoPayload`, defined in `proto/store/memo.proto` / generated at `proto/gen/store/memo.pb.go:85-95`) — i.e. metadata stored alongside but derived from, not supplied by, the user.

**Triggers**: `RebuildMemoPayload` is invoked from two places in `server/router/api/v1/memo_service.go`:
- `CreateMemo` (line 108) — every time a new memo is created, right after content-length validation and before the row is persisted.
- `UpdateMemo` (line 447) — only when the update mask includes the `"content"` path, i.e. whenever a memo's content is edited (not on visibility/pinned/state-only updates).

There is also a standalone `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) that batches through *all* memos and calls `RebuildMemoPayload` for each, intended as a bulk backfill/migration mechanism — but it isn't currently wired up in `server/server.go` (unlike e.g. the `s3presign` runner), so today the two Create/Update call sites are the only active triggers.

**Extracted properties** (from the markdown AST, via `ExtractAll`/`ExtractProperties` in `internal/markdown/markdown.go:192-241,356-422`):
- `Tags` — all `#tag` nodes (deduplicated, case-preserved), used for tag lists/filters.
- `Property.Title` — text of the first H1 heading if it's the document's first block, used as a preview title.
- `Property.HasLink` — whether any Markdown link node exists.
- `Property.HasCode` — whether any code block/fenced code block/code span exists.
- `Property.HasTaskList` — whether any task checkbox exists.
- `Property.HasIncompleteTasks` — whether any unchecked task checkbox exists.
- (also `Mentions` — `@username` nodes — extracted by `ExtractAll` but not persisted into `MemoPayload` by `RebuildMemoPayload`.)

These derived fields (`store.Memo.Payload`, `store/memo.go:51`, and the corresponding `FindMemoPayload` filter fields at `store/memo.go:84-91`) power memo list filtering/searching (e.g. by tag or "has incomplete tasks") and preview rendering on the frontend (e.g. `web/src/hooks/useMemoFilters.ts`, `web/src/components/MemoFilters.tsx`).
