Handlers (RPC methods on `APIV1Service`, all in `server/router/api/v1/`) whose execution can transitively trigger an outbound HTTP call to a URL the user configured as their webhook endpoint:

- `CreateMemo` — `memo_service.go:70` → calls `DispatchMemoCreatedWebhook` (`memo_service.go:157` → `memo_service_webhooks.go:15-17`)
- `UpdateMemo` — `memo_service.go:401` → `dispatchMemoUpdatedSideEffects` (`memo_service.go:513`) → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:66-69`)
- `DeleteMemo` — `memo_service.go:518` → `DispatchMemoDeletedWebhook` (`memo_service.go:562` → `memo_service_webhooks.go:24-26`)
- `CreateMemoComment` — `memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119` → `memo_service_webhooks.go:29-46`)
- (also `SetMemoAttachments`/`SetMemoRelations`-type handlers via `memo_attachment_service.go:48` and `memo_relation_service.go:48`, which likewise call `dispatchMemoUpdatedSideEffects`)

Each of these looks up the target URL from the invoking user's own settings via `s.Store.GetUserWebhooks(ctx, creatorID)` (`store/user_setting.go:311-326`, backed by `AddUserWebhook`/`UpdateUserWebhook`), i.e. a URL the user configured themselves, then calls `webhook.PostAsync(payload)` (`internal/webhook/webhook.go:184-196`), which enqueues onto `asyncPostQueue`.

Convergence function — `Post` in `internal/webhook/webhook.go:120-180`

All four (and any other) webhook-dispatching RPC paths funnel through `webhook.PostAsync`'s queue, which is drained by the worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), each calling `Post(payload)`. `Post` is the single point that builds the HTTP request and performs the actual delivery via `safeClient.Do(req)` (`internal/webhook/webhook.go:126-156`) — this is where every one of those RPC-triggered paths converges immediately before the outbound request is sent.

(Note: there are other, separate convergence points for other kinds of user-configured URLs — e.g. `GetLinkMetadata`/`BatchGetLinkMetadata` in `memo_service_link_metadata.go:14-39` converge on `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go:136`), and SSO sign-in flows converge on `oauth2.IdentityProvider.UserInfo` (`internal/idp/oauth2/oauth2.go:83`) via `resolveSSOIdentity` in `auth_service_sso.go:104`. But for the webhook-URL case specifically — which best fits "user-configured URL" since each user sets their own webhook endpoint — the single convergence function is `Post` in `internal/webhook/webhook.go`.)
