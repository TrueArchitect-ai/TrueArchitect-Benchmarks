Memo visibility ("who may view a memo": `PUBLIC`/`PROTECTED`/`PRIVATE`, defined in `store/memo.go`) is independently re-implemented/enforced at each of the following server surfaces:

- gRPC MemoService read access (`GetMemo`, parent-memo lookup, `GetMemoComment`) — `checkMemoReadAccess` in `server/router/api/v1/memo_service.go` (lines 39‑68, called at 356/367)
- gRPC MemoService list filtering (`ListMemos` restricts results to own + `PUBLIC`/`PROTECTED` for others, or `PUBLIC` only when unauthenticated) — inline in `server/router/api/v1/memo_service.go` (lines 218‑227)
- gRPC AttachmentService read access (`GetAttachment`) — `checkAttachmentAccess` in `server/router/api/v1/attachment_service.go` (lines 419‑455)
- HTTP raw file server (`GET /file/attachments/:uid/:filename`) — `checkAttachmentPermission` in `server/router/fileserver/fileserver.go` (lines 649‑704)
- gRPC ReactionService (`ListMemoReactions`, `UpsertMemoReaction`) — inline visibility checks in `server/router/api/v1/reaction_service.go` (lines 15‑41, 60‑85)
- gRPC MemoService comment creation (`CreateMemoComment`, gating access to the related memo before allowing a comment) — inline check in `server/router/api/v1/memo_service_comments.go` (lines 33‑43)
- SSE real-time event delivery (`Broadcast`/`canReceive`, filters which connected clients receive a memo/reaction event) — `server/router/api/v1/sse_hub.go` (lines 134‑144)
- Notification/inbox payload conversion (mention & comment notifications) — `canViewerAccessMemo` in `server/router/api/v1/user_service_notifications.go` (lines 302‑316)
- Mention-notification dispatch (decides who gets notified of an @mention based on memo/related-memo visibility) — `canUserAccessMentionContext` in `server/router/api/v1/memo_mention_helpers.go` (lines 56‑72)
- RSS feed generation (`GetExploreRSS`, `GetUserRSS` — query-level restriction to `store.Public` only) — `server/router/rss/rss.go` (lines 86‑93, 136‑144)
- Frontend sitemap generation (`getSitemapXML` — query-level restriction to `store.Public` only) — `server/router/frontend/frontend.go` (lines 143‑151)

Note that `GetMemoByShare` (`server/router/api/v1/memo_share_service.go`, lines 153‑192) intentionally bypasses these checks — a valid share token substitutes for visibility, by design.
