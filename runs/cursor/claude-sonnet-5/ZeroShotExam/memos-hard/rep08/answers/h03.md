This is the `usememos/memos` repository. It defines an identity-provider abstraction and a single concrete OAuth2 protocol implementation.

- The abstraction (the `IdentityProviderUserInfo` type shared across provider implementations) lives in package `idp`, defined in `internal/idp/idp.go`.
- The concrete protocol implementation — an OAuth2-based identity provider (`IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, `UserInfo`, built on `golang.org/x/oauth2`) — lives in package `oauth2`, defined in `internal/idp/oauth2/oauth2.go`.

h03.
Abstraction package: `github.com/usememos/memos/internal/idp` (`internal/idp/idp.go`); implementation package: `github.com/usememos/memos/internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)
