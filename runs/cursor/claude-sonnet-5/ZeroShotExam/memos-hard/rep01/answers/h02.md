The outbound webhook delivery executes in the `Post` function in `internal/webhook/webhook.go` (also invoked asynchronously via a worker pool started in `init()`, fed by `PostAsync`, in the same file). It builds the HTTP request and sends it using the package's shared `safeClient`.

Protection against targeting internal/private network addresses is implemented in `internal/webhook/validate.go`:
- `isReservedIP`/`reservedNetworks` (built from `reservedCIDRs`, covering loopback, RFC‑1918 private ranges, link-local/cloud metadata `169.254.169.254`, and IPv6 equivalents) define what's disallowed.
- This is enforced at two points: `ValidateURL` performs an upfront DNS check when a webhook URL is configured/saved, and `safeDialContext` in `internal/webhook/webhook.go` (used as the `DialContext` for `safeClient`'s `http.Transport`) re-resolves the host and blocks the connection at actual dial time — which also defeats DNS-rebinding attacks that could slip past the earlier `ValidateURL` check.
