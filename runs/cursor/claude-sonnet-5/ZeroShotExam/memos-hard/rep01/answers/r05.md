**Premise correction:** The question assumes a GraphQL schema exists for the public API, but this repository does not use GraphQL at all. There are no `.graphql`/`.gql` files anywhere in the repo, and a full-text search for "graphql" across Go, Markdown, YAML, and JSON files returns zero matches.

**Actual API surface:** This is the [usememos/memos](https://github.com/usememos/memos) project, whose public API is defined using **Protocol Buffers** consumed over **Connect RPC** (with gRPC-Gateway/OpenAPI transcoding), not GraphQL:

- Public API service/message definitions live under `proto/api/v1/` (per `AGENTS.md`: "`proto/api/v1/` | Public API service definitions").
- Internal storage messages are separate, under `proto/store/`.
- Generated outputs are written to `proto/gen/` (Go server code + OpenAPI) and `web/src/types/proto/` (TypeScript client types), per `AGENTS.md`.
- The proto toolchain is [buf](https://buf.build): `cd proto && buf generate` / `buf lint` / `buf format -w`.
- On the server side, these proto-defined services are wired up as Connect/gRPC-Gateway handlers in `server/router/api/v1/`, with route ACL/auth configuration in `server/router/api/v1/acl_config.go`.

So if you're looking for "the schema of the public API," the equivalent artifact in this codebase is the `.proto` files in `proto/api/v1/`, not a GraphQL SDL file.
