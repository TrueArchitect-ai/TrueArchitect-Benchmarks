**Computation site:** Backend Go code, in `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which calls the markdown service's `ExtractAll` (implemented in `internal/markdown/markdown.go:355-422`, with the underlying per-property logic mirrored in `ExtractProperties` at `internal/markdown/markdown.go:193-241`). The result is written into `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`, schema defined in `proto/store/memo.proto:7-29`).

**Triggers (operations that cause recomputation):**
- Creating a memo: `CreateMemo` calls `memopayload.RebuildMemoPayload` before persisting (`server/router/api/v1/memo_service.go:108`).
- Updating a memo's content: `UpdateMemo` recomputes the payload only when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:436-451`) — i.e., editing content re-derives the metadata, but other field updates (visibility, pinned, state, etc.) do not.
- A background maintenance job: `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) batches through all memos and calls `RebuildMemoPayload` on each, used to backfill/rebuild payloads for existing memos (e.g., after logic changes).

**Extracted properties:** A single goldmark AST walk over the memo's markdown `Content` extracts:
- `Tags` — all `#tag` nodes found in the content (deduplicated, case preserved).
- `Property.Title` — text of the first block-level child if it's an H1 heading.
- `Property.HasLink` — true if any link node exists.
- `Property.HasCode` — true if any code block/fenced code block/code span exists.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

These derived fields (e.g. `hasLink`, `hasTaskList`, `hasCode`, tags) are then consumed on the frontend for filtering/list views, e.g. `web/src/components/MemoFilters.tsx:45-53` and `web/src/hooks/useMemoFilters.ts`.
