**Computation site:** `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356-422`) to parse the memo's markdown content via goldmark and populate `memo.Payload.Tags` and `memo.Payload.Property` (defined in `proto/store/memo.proto:7-22`, generated as `storepb.MemoPayload` / `MemoPayload_Property`).

**Triggers (recomputation):**
- `CreateMemo` — called once when building the new memo record, right after content-length validation (`server/router/api/v1/memo_service.go:108`).
- `UpdateMemo` — called only when the update mask includes the `content` path, i.e. whenever a memo's content is edited (`server/router/api/v1/memo_service.go:436-449`).
- There is also a batch/backfill path, `Runner.RunOnce()` in `server/runner/memopayload/runner.go:27-72`, which pages through all memos and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each — but unlike the `s3presign` runner (wired in `server/server.go:163`), this runner isn't currently invoked anywhere in `server.go`, so in the running app the only live triggers are memo create/update-with-content.

**Extracted properties** (single goldmark AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — all `#tag` nodes found in the content (deduplicated, case preserved).
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one.
- `Property.HasLink` — true if any Markdown link node exists.
- `Property.HasCode` — true if any code block/fenced code block/code span exists.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(It also collects `Mentions` from `@mention` nodes in the same pass, though those aren't stored into `memo.Payload` by `RebuildMemoPayload`, only `Tags` and `Property` are persisted.)
