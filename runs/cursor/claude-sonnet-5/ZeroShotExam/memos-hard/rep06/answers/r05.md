**Premise correction:** This repository does not use GraphQL anywhere — I searched the entire codebase (case-insensitively) for `graphql` and found zero matches. There is no GraphQL schema, resolver, or endpoint to point to.

**Actual API surface:** The public API is defined using **Protocol Buffers** (compiled with [buf](https://buf.build)), which generates both gRPC service code and a REST/JSON gateway (via grpc-gateway) plus an OpenAPI spec:

- Proto service/message definitions: `proto/api/v1/` (e.g. `*.proto` files under this directory), configured via `proto/buf.yaml`, `proto/buf.gen.yaml`, and `proto/buf.lock`
- Generated Go/gRPC-gateway code: `proto/gen/`
- Generated OpenAPI (REST) spec derived from the same proto definitions: `proto/gen/openapi.yaml`, embedded into the server via `proto/gen/openapi_embed.go`
- The HTTP/gRPC-gateway server wiring lives under `server/router/`

So instead of a GraphQL schema, the "schema" for this public API is the set of `.proto` files in `proto/api/v1/`, which serve as the single source of truth for both the gRPC API and the generated OpenAPI/REST surface.
