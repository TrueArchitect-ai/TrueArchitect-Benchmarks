**Computation site:** The derived metadata is computed in the markdown service's `ExtractAll` method, in `internal/markdown/markdown.go:356-422` (which internally reuses the same AST-walk logic as `ExtractProperties`, `internal/markdown/markdown.go:192-241`, and `ExtractTags`). This is invoked through the helper `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which stores the result into `memo.Payload.Tags` and `memo.Payload.Property` (the `storepb.MemoPayload` proto defined in `proto/store/memo.proto:7-22`).

**Triggers (recomputation):**
- `CreateMemo` — `RebuildMemoPayload` is called once when a new memo is created, right after building the `store.Memo` and before persisting it (`server/router/api/v1/memo_service.go:108`).
- `UpdateMemo` — only when the update mask includes the `content` path (i.e., the memo's content is actually being edited); the payload is rebuilt from the new content before saving (`server/router/api/v1/memo_service.go:436-451`). Other update paths (visibility, pinned, state, etc.) do not trigger recomputation.
- Bulk/background rebuild — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) batches through all memos via `Store.ListMemos` and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each, for mass regeneration (e.g., a migration/backfill task); it isn't wired into the create/update request path itself.

**Extracted properties** (all derived purely from parsing the memo's markdown content with goldmark, never set directly by the user):
- `Tags` — all `#tag` occurrences found in the content (deduplicated, case-preserved), from tag AST nodes (`internal/markdown/markdown.go:376-377`, dedup at `418`).
- `Property.Title` — text of the first block-level H1 heading in the document, if present (`internal/markdown/markdown.go:384-389`).
- `Property.HasLink` — true if any Markdown link node exists (`:393-394`).
- `Property.HasCode` — true if any code block, fenced code block, or inline code span exists (`:396-397`).
- `Property.HasTaskList` — true if any task-list checkbox exists (`:399-400`).
- `Property.HasIncompleteTasks` — true if any task-list checkbox is unchecked (`:401-405`).

(Separately, `GenerateSnippet`, `internal/markdown/markdown.go:264-346`, computes a plain-text preview snippet from the content, used for memo previews/webhooks, e.g. `server/router/api/v1/memo_service_webhooks.go:85` — but this snippet is generated on demand rather than persisted in the payload.)
