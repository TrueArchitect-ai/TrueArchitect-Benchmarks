Each of these `Dispatch*Webhook` functions loads the user's configured webhooks (`hook.Url`) and calls `webhook.PostAsync(payload)` (`server/router/api/v1/memo_service_webhooks.go:43,71`), which enqueues onto `asyncPostQueue`; the queue workers (started in `init()`) call `Post`.

Convergence function — `Post` in `internal/webhook/webhook.go` (lines 120‑180). This is the single place that builds the `http.Request` from `requestPayload.URL` and executes it via the package‑level `safeClient.Do(req)` (line 152), and it's the only call site of `safeClient.Do` in the codebase. All the RPC handlers above funnel through it (synchronously if called directly, or asynchronously via `PostAsync`'s worker goroutines).
