h02.

- Delivery function — `Post` in `internal/webhook/webhook.go` (invoked asynchronously via `PostAsync`, which enqueues onto `asyncPostQueue` and is drained by worker goroutines that call `Post`; `Post` builds the HTTP request and sends it with the package-level `safeClient`).
- Protection mechanism — the SSRF guard lives in `internal/webhook/webhook.go`'s `safeDialContext` (used as `safeClient`'s `http.Transport.DialContext`), which resolves the target host and rejects connections whose IPs fall in reserved/private ranges by calling `isReservedIP` from `internal/webhook/validate.go` (blocking loopback, RFC-1918 private ranges, link-local/cloud-metadata `169.254.0.0/16`, and their IPv6 equivalents, unless the `AllowPrivateIPs` override is set). A second, pre-flight check of the same reserved-IP list is done at webhook-creation time via `ValidateURL` in `internal/webhook/validate.go`, but the actual outbound POST's protection at dispatch time is the dial-time check in `safeDialContext`.
