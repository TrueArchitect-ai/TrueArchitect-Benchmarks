**Premise correction:** There is no GraphQL schema in this repository — this project does not expose a GraphQL API at all. A repo-wide search for `graphql`/`.graphql`/`.gql` files returns zero matches.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + gRPC-Gateway/REST), not GraphQL:

- Service definitions: `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`, plus shared types in `proto/api/v1/common.proto`)
- Build config: `proto/buf.yaml` and `proto/buf.gen.yaml` (using [buf](https://buf.build)) generate Go server/client code into `proto/gen/`
- A generated OpenAPI (Swagger) description of the resulting REST surface lives at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`

So the README's claim of "full REST and gRPC APIs" checks out (`proto/api/v1/*.proto` → gRPC + REST via grpc-gateway → OpenAPI doc), but there's no GraphQL schema anywhere to point to.
