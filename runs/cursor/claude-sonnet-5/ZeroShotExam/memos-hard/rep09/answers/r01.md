**Premise correction:** There is no Redis anywhere in this repository — a full case-insensitive search of the entire codebase (including `docs/`, `scripts/`, `README.md`) turns up zero matches for "redis". Memos does not use Redis for caching; its only supported storage backends are SQLite, MySQL, and PostgreSQL (per `AGENTS.md`), and the "cache layer" is an in-process, in-memory cache, not an external Redis connection.

**Actual mechanism:** The cache layer is a hand-rolled, thread-safe in-memory cache built on `sync.Map` with a background cleanup goroutine, defined in `store/cache/cache.go`. It's instantiated per-`Store` (not a shared external connection) in `store/store.go`:
