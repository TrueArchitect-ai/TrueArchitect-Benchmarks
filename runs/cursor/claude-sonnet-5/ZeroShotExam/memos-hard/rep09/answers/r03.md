Premise correction: There is no actual nightly database-cleanup job scheduled in this repository — that job doesn't exist as a running feature.

What does exist is `internal/scheduler`, a standalone, generic cron-scheduling library/plugin (see its README at `internal/scheduler/README.md` and package doc at `internal/scheduler/doc.go`). Its documentation and `doc.go` package comment use a `"daily-cleanup"` job with schedule `"0 2 * * *"` (2 AM) purely as an illustrative example of how to use the API — it is not a real, registered job.

I confirmed this package has no importers anywhere else in the codebase (`grep -rl "internal/scheduler" --include=*.go` outside the package itself returns nothing), and the only place jobs are actually registered/started in production is `server/server.go`'s `startBackgroundRunners`, which only starts an S3-presign runner (`server/runner/s3presign/runner.go`) — no database-cleanup runner exists there or in `server/runner/memopayload/runner.go`.

So there is no cron-scheduled nightly database-cleanup job in this repo to report a time for; the "2 AM" figure that appears is only sample/documentation code, not a configured production job.
