**Premise correction:** There is no GraphQL schema in this repository — Memos does not expose a GraphQL API. The premise of the question is incorrect.

**Actual API surface:** The public API is defined via Protocol Buffers (protobuf) and exposed as gRPC + REST/OpenAPI (via grpc-gateway), not GraphQL:

- Proto service/message definitions live under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, etc.), as referenced in `proto/README.md`.
- Code generation is configured via `proto/buf.yaml`, `proto/buf.gen.yaml`, and `proto/buf.lock` (using [buf](https://docs.buf.build/installation) to run `buf generate`).
- Generated Go/TS bindings land in `proto/gen`.
- An embedded OpenAPI/REST description is provided in `proto/openapi_embed.go`.
- The repo `README.md` explicitly describes the API as "full REST and gRPC APIs for integration" — no mention of GraphQL anywhere in the codebase (confirmed via a repo-wide search for `graphql`/`.graphql` files, which returned no matches).

So if you're looking to integrate with or extend the public API, the relevant schema definitions are the `.proto` files in `proto/api/v1/`, not a GraphQL schema.
