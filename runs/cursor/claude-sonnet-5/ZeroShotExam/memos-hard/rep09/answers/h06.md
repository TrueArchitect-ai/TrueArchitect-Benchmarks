Handlers (RPC methods on `APIV1Service` / `ConnectServiceHandler` in `server/router/api/v1/`) that transitively trigger an outbound HTTP call to a user-configured webhook URL:

1. `CreateMemo` — calls `s.DispatchMemoCreatedWebhook` at `server/router/api/v1/memo_service.go:157`
2. `UpdateMemo` (and the shared helper `dispatchMemoUpdatedSideEffects`, also reused by `SetMemoAttachments` and `SetMemoRelations`) — calls `s.DispatchMemoUpdatedWebhook` at `server/router/api/v1/memo_update_helpers.go:67`, invoked from `memo_service.go:513`, `memo_attachment_service.go:48`, and `memo_relation_service.go:48`
3. `DeleteMemo` — calls `s.DispatchMemoDeletedWebhook` at `server/router/api/v1/memo_service.go:562`
4. `CreateMemoComment` — calls `s.DispatchMemoCommentCreatedWebhook` at `server/router/api/v1/memo_service_comments.go:119`

Each of the four `Dispatch*Webhook` wrappers (`server/router/api/v1/memo_service_webhooks.go:15-46`) loads the receiving user's webhooks via `s.Store.GetUserWebhooks` and sets `payload.URL = hook.Url` — a URL the user configured themselves via the `CreateUserWebhook`/`UpdateUserWebhook` RPCs (`server/router/api/v1/user_service_webhooks.go`) — then calls `webhook.PostAsync(payload)`.

`PostAsync` (`internal/webhook/webhook.go:184-196`) only enqueues onto `asyncPostQueue`; the queue is drained by fixed worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), each of which calls `Post(payload)`.

Convergence function — `Post` in `internal/webhook/webhook.go:120-180`. This is the single place where the request is actually built (`http.NewRequest("POST", requestPayload.URL, ...)`) and delivered via the shared `safeClient.Do(req)` (`internal/webhook/webhook.go:32-37, 126-152`), regardless of which of the four dispatch paths (memo created/updated/deleted/comment-created) triggered it.

(Note: there is a second, unrelated outbound-HTTP convergence point, `httpgetter.GetHTMLMeta`/`GetImage` in `internal/httpgetter/`, used for link-preview metadata fetching, e.g. via `fetchHTMLMeta` in `server/router/api/v1/memo_service.go:28`. That path is independent of the webhook path above, so I've focused the answer on the webhook convergence since it's the one reached by the largest, clearest set of RPC handlers.)
