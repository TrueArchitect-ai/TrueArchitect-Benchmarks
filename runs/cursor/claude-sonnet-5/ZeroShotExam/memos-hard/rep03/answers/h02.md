The actual outbound HTTP delivery happens in the `Post` function, which builds the request and executes it via the shared `safeClient.Do(req)` call.

- delivery function — `Post` in `internal/webhook/webhook.go` (lines 120–180; dispatched either synchronously or via `PostAsync`'s worker goroutines at lines 42–55, which also call `Post`)

The SSRF protection is enforced at the transport/dial layer, not just at input validation: `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go`, lines 32–37, 57–77), which resolves the target hostname and rejects any request whose resolved IP falls in a reserved/private/link-local range (via `isReservedIP`, defined in `internal/webhook/validate.go`, lines 14–54) before the connection is dialed — this closes the DNS-rebinding gap that a pre-flight-only check (like `ValidateURL` in `internal/webhook/validate.go`, lines 62–83, used when a webhook is created/updated) would miss.

- protection mechanism — `safeDialContext` / `isReservedIP` in `internal/webhook/webhook.go` (dial-time enforcement) and `internal/webhook/validate.go` (reserved CIDR list + `isReservedIP`, lines 14–54), wired into the HTTP client used by `Post` via `safeClient.Transport.DialContext`
