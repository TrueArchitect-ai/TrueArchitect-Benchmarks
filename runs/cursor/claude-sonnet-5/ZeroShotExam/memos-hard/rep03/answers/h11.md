**1st: `store.User`** (`store/user.go`); **2nd: `store.Memo`** (`store/memo.go`) — roughly tied, each referenced from about 7 non-`store` packages.

I grepped every non-`store`, non-generated (`proto/gen/...` is excluded since those are just protobuf comments coincidentally named `memos.store.X`) Go package for both explicit `store.TypeName` references and calls to the corresponding CRUD store methods (e.g. `GetMemo`, `ListUsers`, ...), since some call sites (e.g. `attachment, err := s.Store.GetMemo(...)`) use type inference and never spell out the type name.
