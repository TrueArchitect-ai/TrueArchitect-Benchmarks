**Premise correction:** This repository has no GraphQL API — there is no `.graphql` schema file, no `graphql` string anywhere in the codebase (`git grep`/`grep -ri "graphql"` across the whole tree returns zero matches), and no GraphQL library in `go.mod`. So there's nothing to point to for "the GraphQL schema."

**Actual API surface:** This is the Memos server, and its public API is defined via **Protocol Buffers + gRPC/gRPC-Gateway (with generated OpenAPI)**, not GraphQL:

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`)
- Build config: `proto/buf.yaml` and `proto/buf.gen.yaml` (using [buf](https://docs.buf.build/)) — see `proto/README.md`
- Generated Go/gRPC-Gateway code: `proto/gen/api`
- Generated OpenAPI description (REST surface derived from the proto services): `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- There's also a separate `proto/store/*.proto` set (`memo.proto`, `inbox.proto`, `idp.proto`, `instance_setting.proto`, `attachment.proto`, `user_setting.proto`) defining internal storage message types, generated into `proto/gen/store`.

So if you're looking for "the schema for the public API," the equivalent artifact is `proto/api/v1/*.proto` (and its generated OpenAPI spec at `proto/gen/openapi.yaml`), not a GraphQL schema.
