It is actually computed by `markdownService.ExtractAll()` in `internal/markdown/markdown.go` (a single goldmark AST walk), invoked via the helper `RebuildMemoPayload` in `server/runner/memopayload/runner.go`:

```74:88:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	if memo.Payload == nil {
		memo.Payload = &storepb.MemoPayload{}
	}

	// Use goldmark service to extract all metadata in a single pass (more efficient)
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	if err != nil {
		return errors.Wrap(err, "failed to extract markdown metadata")
	}

	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

**Triggers (recomputation):**
- `CreateMemo` — every time a memo is created, `RebuildMemoPayload` is called right after the content is set (`server/router/api/v1/memo_service.go:108`).
- `UpdateMemo` — only when the `content` field is included in the update mask (i.e. the memo's text actually changes), `RebuildMemoPayload` is called again on the new content (`server/router/api/v1/memo_service.go:447`).
- Additionally, a maintenance batch job, `memopayload.Runner.RunOnce` in `server/runner/memopayload/runner.go`, walks all memos in the store and calls `RebuildMemoPayload` for each (used to backfill/rebuild payloads en masse), though it is not currently wired into `server/server.go`'s startup routines — only the analogous `s3presign` runner is invoked there.

**Extracted properties:** During the single AST walk in `ExtractAll` (`internal/markdown/markdown.go:356-419`):
- `title` — text of the first H1 heading, only if it's the very first block-level node in the document (`extractHeadingText`, lines 383-389).
- `has_link` — set when a `Link` AST node is encountered (line 393-394).
- `has_code` — set when a `CodeBlock`, `FencedCodeBlock`, or `CodeSpan` node is encountered (line 396-397).
- `has_task_list` / `has_incomplete_tasks` — set when a `TaskCheckBox` node is found; `has_incomplete_tasks` is additionally set if that checkbox is unchecked (lines 399-405).
- (Alongside `Property`, the same pass also collects `Tags` (`#tag` nodes) and `Mentions`, which are stored separately as `memo.Payload.Tags`.)

These booleans/title are what the frontend (e.g. `web/src/components/MemoFilters.tsx`, `web/src/hooks/useMemoFilters.ts`) uses to build memo list filters and previews (e.g. filtering for memos with links, code, or incomplete tasks) without the user ever setting them directly.
