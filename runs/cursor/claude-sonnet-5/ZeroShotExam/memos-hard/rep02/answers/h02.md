The outbound webhook delivery executes in the `Post` function (called both synchronously and from the async worker goroutines started in `init()`), which builds the HTTP request and sends it via the shared `safeClient`:

- delivery function — `Post` in `internal/webhook/webhook.go` (lines 120–180, dispatched via `PostAsync`/`asyncPostQueue` at lines 39–55, using the `safeClient` HTTP client defined at lines 29–37)

The SSRF protection is enforced at the network-dial layer of that same client: `safeClient`'s `Transport.DialContext` is set to `safeDialContext`, which resolves the target hostname and rejects any resolved IP that falls within a reserved/private range (via `isReservedIP`) before the TCP connection is made — this defeats DNS-rebinding bypasses of a simpler pre-check. There's also a complementary pre-flight check (`ValidateURL`) used when webhooks are created/updated, but the actual delivery-time enforcement is the dialer.

- protection mechanism — `safeDialContext` and `isReservedIP`/`reservedNetworks` in `internal/webhook/webhook.go` (lines 57–77) and `internal/webhook/validate.go` (lines 14–54, 62–83)
