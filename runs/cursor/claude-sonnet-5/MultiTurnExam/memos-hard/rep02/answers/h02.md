**Protection mechanism:** the shared `safeClient`'s `http.Transport` uses a custom `DialContext: safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59-77`) resolves the target host to IPs at dial time and rejects the connection if any resolved IP is reserved/private — checked via `isReservedIP` in `internal/webhook/validate.go:44-54`, which tests against the loopback/RFC-1918/link-local/cloud-IMDS/IPv6 CIDR ranges defined in `reservedCIDRs` (`internal/webhook/validate.go:14-23`). Because the check happens at dial time against the actually-resolved IP (not just at URL-validation time via `ValidateURL`, `internal/webhook/validate.go:62-83`), it also defeats DNS-rebinding attacks. Note the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) can disable this protection for self-hosted deployments that intentionally target local-network services.
