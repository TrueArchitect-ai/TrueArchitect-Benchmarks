h03.

**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared identity-provider abstraction, `IdentityProviderUserInfo`, used by concrete provider implementations to return normalized user info.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — ships the concrete OAuth2 protocol implementation, with `IdentityProvider` implementing `ExchangeToken` (authorization-code/PKCE token exchange) and `UserInfo` (fetching and mapping claims via the configured `FieldMapping` back into `idp.IdentityProviderUserInfo`).
