I now have full confirmation of the computation site, triggers, and extracted fields.

h14.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(...)` (interface method implemented in `internal/markdown/markdown.go:356`, `(*service).ExtractAll`) and writes the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (operations that cause recomputation):**
- **`CreateMemo`** — always rebuilds the payload for the newly-created content: `server/router/api/v1/memo_service.go:108`.
- **`UpdateMemo`**, but only when the request's update mask includes the `content` path — recomputation happens right after `memo.Content` is overwritten with the new content: `server/router/api/v1/memo_service.go:446-449`.

  (Other mutating operations like `SetMemoAttachments`/`SetMemoRelations` don't touch content, so they never call `RebuildMemoPayload` — they only trigger `dispatchMemoUpdatedSideEffects`/webhooks, not payload recomputation. There's also a batch `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27-72`, which would rebuild every memo's payload, but per earlier analysis that runner is never instantiated in production.)

**What the computation extracts** (inside `(*service).ExtractAll`, `internal/markdown/markdown.go:356-422`, via a single goldmark AST walk):
- `Tags` — all `#tag` occurrences found in the content (deduplicated, case-preserved).
- `Property.Title` — text of the first block if it's an H1 heading.
- `Property.HasLink` — whether the content contains a link node.
- `Property.HasCode` — whether it contains a code block/fenced code block/code span.
- `Property.HasTaskList` — whether it contains a task checkbox.
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked.

(A `Mentions` list is also computed by `ExtractAll` but is discarded by `RebuildMemoPayload` — only `Tags` and `Property` are persisted into the memo's payload for use in lists/previews.)
