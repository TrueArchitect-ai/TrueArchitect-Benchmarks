**Premise correction:** This repository has no GraphQL schema at all — a repo-wide search for "graphql" (across all `.go` files, `go.mod`, and for any `.graphql`/`.gql` files) returns zero matches. GraphQL is not part of this project's API surface.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`, plus shared types in `proto/api/v1/common.proto`), compiled (via `buf`, per `proto/buf.gen.yaml`) into generated Go code under `proto/gen/api/v1/`. This same schema is exposed over multiple transports simultaneously — gRPC, gRPC-Gateway/REST (`*.pb.gw.go` files), and Connect (`proto/gen/api/v1/apiv1connect/`) — wired up in `server/router/api/v1/connect_services.go` and `server/router/api/v1/v1.go`. There's a separate, internal-only proto namespace for persisted data models under `proto/store/` (e.g. `proto/store/memo.proto`), which is not the public API.
