**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic `IdentityProviderUserInfo` struct used across the SSO flow.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol implementation shipped, providing an `IdentityProvider` type that implements OAuth2 token exchange (`ExchangeToken`) and user-info retrieval against `storepb.OAuth2Config`. It's consumed by `server/router/api/v1/auth_service_sso.go` (e.g. `resolveSSOIdentity`, `resolveSSOUser`), which builds `idp.IdentityProviderUserInfo` values from the OAuth2 implementation.
