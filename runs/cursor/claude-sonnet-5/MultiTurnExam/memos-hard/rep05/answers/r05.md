**Premise correction:** There is no GraphQL schema anywhere in this repository. I searched for "graphql" across all Go files, and there's no `.graphql`/`.gql` schema file, and no GraphQL server library (e.g. `gqlgen`, `graphql-go`) in `go.mod`.

**Actual API surface:** The public API is defined via Protocol Buffers, not GraphQL, and served over gRPC/Connect (with a REST/JSON gateway), not GraphQL. The schema lives in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These `.proto` definitions are compiled into generated Go code under `proto/gen/api/v1/` (including `proto/gen/api/v1/apiv1connect/` for the Connect-RPC handlers and `*.pb.gw.go` files for the grpc-gateway REST/JSON transcoding), and the actual RPC method implementations are registered in `server/router/api/v1/` (e.g. `connect_services.go`, `memo_service.go`, `user_service.go`, etc.), which is what backs the "public API" for this project instead of GraphQL.
