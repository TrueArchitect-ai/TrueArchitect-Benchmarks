**RPC handlers that can transitively trigger an outbound HTTP request to a user-configured URL** (a webhook URL stored per-user):

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70`, calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)` at `server/router/api/v1/memo_service.go:157`.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401`, calls `s.dispatchMemoUpdatedSideEffects(...)` at `server/router/api/v1/memo_service.go:513`, which calls `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go:67`).
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518`, calls `s.DispatchMemoDeletedWebhook(ctx, memoMessage)` at `server/router/api/v1/memo_service.go:562`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20`, calls `s.DispatchMemoCommentCreatedWebhook(...)` at `server/router/api/v1/memo_service_comments.go:119`.
5. (bonus) **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:16`, also calls `s.dispatchMemoUpdatedSideEffects(...)` at `server/router/api/v1/memo_attachment_service.go:48`.
6. (bonus) **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:16`, also calls `s.dispatchMemoUpdatedSideEffects(...)` at `server/router/api/v1/memo_relation_service.go:48`.

All of these route through the `Dispatch*Webhook` helpers in `server/router/api/v1/memo_service_webhooks.go`, which fetch the target user's configured webhook URLs via `s.Store.GetUserWebhooks` and hand each payload (with `payload.URL = hook.Url`, a user-configured URL) to `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43,71`).

**Convergence function:** `Post` in `internal/webhook/webhook.go:120` — every dispatch path (synchronous or via the `PostAsync` queue/worker goroutines at `internal/webhook/webhook.go:39-54`) ultimately funnels into this single function, which performs the actual outbound call at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).
