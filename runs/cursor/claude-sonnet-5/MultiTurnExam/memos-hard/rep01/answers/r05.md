**Premise correction:** There is no GraphQL schema anywhere in this repository — a search for `graphql`, `.graphql` files, and `gqlgen` across all Go source, `go.mod`, and the filesystem returns zero matches. This project doesn't expose a GraphQL API.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC service definitions**, exposed simultaneously as gRPC, [Connect](https://connectrpc.com/) (Connect protocol/gRPC-Web), and a REST/JSON surface via grpc-gateway annotations. The schema files live under `proto/api/v1/`:

- `proto/api/v1/ai_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/common.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/user_service.proto`

These are compiled into generated Go code under `proto/gen/api/v1/` (including gRPC stubs, grpc-gateway REST handlers `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`), and are implemented by `APIV1Service` in `server/router/api/v1/` (see `server/router/api/v1/v1.go`), registered via `RegisterGateway` in `server/server.go`. There's also a separate internal store schema under `proto/store/` for persisted entities, but that's not the public API.
