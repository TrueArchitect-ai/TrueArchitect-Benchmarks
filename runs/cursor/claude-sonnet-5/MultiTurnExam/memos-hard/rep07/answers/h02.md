The outbound webhook delivery executes in `Post` (`internal/webhook/webhook.go:120-180`), which builds the HTTP request and sends it via the package-level `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). `PostAsync` (`internal/webhook/webhook.go:184-196`) just enqueues payloads onto `asyncPostQueue`, which four worker goroutines (started in `init`, `internal/webhook/webhook.go:42-55`) drain by calling `Post`.

The SSRF protection is `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the `DialContext` on the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). For every outbound connection it resolves the target host and rejects it if any resolved IP is in a reserved/private range, via `isReservedIP` (`internal/webhook/validate.go:44-54`) checked against `reservedNetworks`/`reservedCIDRs` (loopback, RFC-1918 private ranges, link-local/cloud metadata `169.254.0.0/16`, and IPv6 equivalents) defined in `internal/webhook/validate.go:14-36`. Because the check happens at dial time on the resolved IP (not just the pre-connect URL), it also defeats DNS-rebinding bypasses. A companion pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), applies the same `isReservedIP` logic when a webhook URL is registered/validated, and `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is the escape hatch that disables the restriction for self-hosted deployments.
