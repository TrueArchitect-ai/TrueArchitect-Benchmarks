**RPC handlers that transitively trigger an outbound HTTP request to a user-configured (webhook) URL:**

1. `CreateMemo` — `server/router/api/v1/memo_service.go:70` (calls `DispatchMemoCreatedWebhook` at line 157)

All of these `Dispatch*Webhook` helpers (`server/router/api/v1/memo_service_webhooks.go`) look up the target's stored webhook URL (`store.GetUserWebhooks`) and call `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; worker goroutines drain that queue by calling `webhook.Post`.

**Convergence function**: All of these paths converge in `Post` — `internal/webhook/webhook.go:120` — the single function that actually marshals the payload, signs it, and executes the outbound `safeClient.Do(req)` call (`internal/webhook/webhook.go:152`). (`PostAsync`, `internal/webhook/webhook.go:184`, is just a bounded-queue wrapper around the same `Post` call, used by every handler above.)
