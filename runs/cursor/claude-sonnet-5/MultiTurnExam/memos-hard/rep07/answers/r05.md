**Premise correction:** There is no GraphQL schema anywhere in this repository — a search for "graphql" (case-insensitive) across all Go files, and for `.graphql`/schema files in the whole tree, returns zero results. This project does not expose a GraphQL API.

**Actual API surface:** The public API is defined via **Protocol Buffers** in `proto/api/v1/` — service definitions such as `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, and `ai_service.proto` (plus shared types in `common.proto`). These are compiled into Go bindings under `proto/gen/api/v1/`.

From this single proto definition, the server exposes three concrete transports, all wired up in `server/router/api/v1/connect_services.go` / `connect_handler.go` and registered from `server/server.go`:
- **gRPC** service servers (`v1pb.UnimplementedMemoServiceServer` etc., embedded in `APIV1Service`, `server/router/api/v1/v1.go`)
- **Connect** protocol handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`)
- **gRPC-Gateway** REST/JSON transcoding (`proto/gen/api/v1/*.pb.gw.go`, e.g. `memo_service.pb.gw.go`, `attachment_service.pb.gw.go`)

So the "schema" analog for this API is the `.proto` files in `proto/api/v1/`, not a GraphQL schema.
