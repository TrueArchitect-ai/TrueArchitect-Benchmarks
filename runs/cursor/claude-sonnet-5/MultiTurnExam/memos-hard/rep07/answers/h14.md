```74:88:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	if memo.Payload == nil {
		memo.Payload = &storepb.MemoPayload{}
	}

	// Use goldmark service to extract all metadata in a single pass (more efficient)
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	if err != nil {
		return errors.Wrap(err, "failed to extract markdown metadata")
	}

	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

**What's extracted** (via `ExtractAll`, `internal/markdown/markdown.go:356-422`), all stored on `memo.Payload` (`storepb.MemoPayload`):
- `Tags` — every `#tag` found in the content (deduplicated case-preserving)
- `Mentions` — every `@mention` found (deduplicated, lowercased) — extracted by `ExtractAll` but not persisted onto `Payload` in `RebuildMemoPayload` (only `Tags`/`Property` are assigned)
- `Property` (`storepb.MemoPayload_Property`), derived from AST node kinds during the walk:
  - `Title` — text of a leading H1 heading, if the first block-level node in the document is an `H1`
  - `HasLink` — whether any link node appears
  - `HasCode` — whether any code block/fenced code block/code span appears
  - `HasTaskList` — whether any task checkbox appears
  - `HasIncompleteTasks` — whether any task checkbox is unchecked

These derived fields (tags, title, link/code/task-list flags) are what the UI's memo list/preview surfaces use, rather than anything the user explicitly sets.
