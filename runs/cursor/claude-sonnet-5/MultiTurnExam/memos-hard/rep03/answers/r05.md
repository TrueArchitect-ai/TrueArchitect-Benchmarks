**Premise correction:** There's no GraphQL schema in this repository — no `.graphql`/`.gql` files exist, and no GraphQL library (e.g. `gqlgen`, `graphql-go`) appears in `go.mod`.

**Actual API surface:** The public API is defined via Protocol Buffers and exposed as gRPC / [Connect](https://connectrpc.com/) / gRPC-Gateway (REST/JSON) endpoints, not GraphQL:

- Proto service definitions live under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`.
- Generated Go bindings (messages, gRPC server/client stubs, gRPC-Gateway REST handlers, and Connect handlers) live under `proto/gen/api/v1/` and `proto/gen/api/v1/apiv1connect/`.
- These generated services are implemented and wired up in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`, `attachment_service.go`, `auth_service.go`), with the gateway/Connect registration in `server/router/api/v1/v1.go` (`RegisterGateway`, `server/router/api/v1/v1.go:65-77`) and `server/router/api/v1/connect_services.go` / `connect_handler.go`.

So the dependencies (`connectrpc.com/connect`, `github.com/grpc-ecosystem/grpc-gateway/v2`) and the `proto/` directory confirm the public API surface is Protobuf-defined gRPC/Connect/REST, with no GraphQL layer anywhere in the codebase.
