**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this codebase, and no cron scheduler is actually wired into the running server.

What exists is a generic, standalone cron-scheduling library at `internal/scheduler/` (`scheduler.go`, `job.go`, `parser.go`, `middleware.go`) that implements cron-expression parsing and job registration/execution machinery. However:

- It is never imported or used by any production code — searching the whole repo for `internal/scheduler` imports outside the package itself returns zero results (no `cmd/`, `server/`, or `store/` file constructs a `scheduler.Scheduler` or registers a job).
- The only mention of a "daily-cleanup" job with a `0 2 * * *` (2 AM) schedule is a documentation example in `internal/scheduler/doc.go:11-24`, illustrating how a *hypothetical* consumer could use the library — it is not an actual registered job and has no effect at runtime.

The real background jobs that do run at startup are the two runners wired in `Server.startBackgroundRunners` (`server/server.go:153-174`): the S3 presign runner (`server/runner/s3presign`, ticking every 12 hours — see the earlier `h01` answer) and the unused `memopayload` runner (see `h08`) — neither of which is a database-cleanup job nor uses the `internal/scheduler` cron mechanism.
