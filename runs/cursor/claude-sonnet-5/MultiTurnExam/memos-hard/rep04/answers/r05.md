**Premise correction:** This project has no GraphQL API — there is no GraphQL schema anywhere in the repository. A search for `graphql` and for `.graphql`/`.gql` files across the entire codebase returns zero results.

**Actual API surface:** The public API is defined as Protocol Buffers, exposed simultaneously as gRPC, gRPC-Gateway (REST/JSON), and Connect (`connectrpc.com/connect`). The schema/service definitions live in `proto/api/v1/*.proto`:

- `proto/api/v1/ai_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/common.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/user_service.proto`

These compile to generated Go code under `proto/gen/api/v1/` (e.g. `*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`), which is then implemented by `APIV1Service` in `server/router/api/v1/` and registered for both gRPC-Gateway and Connect handling in `server/router/api/v1/v1.go`.
