**Component:** The S3 presign runner, `server/runner/s3presign.Runner` (`server/runner/s3presign/runner.go`). Its `CheckAndPresign`/`RunOnce` method (`server/runner/s3presign/runner.go:43-132`) lists all attachments whose storage type is S3, checks each `S3Object.LastPresignedTime`, and — if the previously-generated presigned URL is within 4 days of its 5-day expiry (`server/runner/s3presign/runner.go:85-91`, expiry itself set in `internal/storage/s3/s3.go:77-79`) — calls `s3Client.PresignGetObject` to mint a fresh presigned URL and writes it back as the attachment's `Reference`/`LastPresignedTime` via `Store.UpdateAttachment` (`server/runner/s3presign/runner.go:108-124`). This is what keeps externally-stored (S3) attachment links from going stale/expiring.

**Schedule:** Runs once immediately, then on a repeating `time.NewTicker` every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-40`).

**Wiring into server startup:** `Server.startBackgroundRunners` constructs the runner with `s3presign.NewRunner(s.Store)`, calls `RunOnce` synchronously once, then launches `Run` in a goroutine for the periodic ticking (`server/server.go:161-171`). `startBackgroundRunners` itself is invoked from `Server.Start` at `server/server.go:129`.
