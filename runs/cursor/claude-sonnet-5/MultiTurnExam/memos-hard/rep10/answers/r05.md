**Premise correction:** This repository has no GraphQL API — I searched all Go source, `.proto` files, and `go.mod`/`go.sum` (case-insensitive) for `graphql` and found zero matches. There is no GraphQL dependency, schema, or resolver anywhere in the codebase.

**Actual API surface:** The public API is defined via Protobuf service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`), which are code-generated into `proto/gen/api/v1/` (gRPC stubs, gRPC-Gateway reverse-proxy handlers `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`).

At runtime, these are served over HTTP through:
- **gRPC-Gateway**, registered in `server/router/api/v1/v1.go` (`RegisterGateway`, around `server/router/api/v1/v1.go:64` onward), which exposes REST/JSON endpoints derived from the proto definitions.
- **Connect RPC**, wired in `server/router/api/v1/connect_services.go` and `connect_interceptors.go`, exposing the same services over the Connect protocol (gRPC, gRPC-Web, and Connect's own JSON/binary protocol).

So the schema/contract for the "public API" lives in the `.proto` files under `proto/api/v1/`, not in any GraphQL SDL file.
