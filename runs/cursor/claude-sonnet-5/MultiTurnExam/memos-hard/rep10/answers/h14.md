**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll(memo.Content)` (the single-pass extractor implemented at `internal/markdown/markdown.go:356-422`) and writes the result onto the memo's stored payload:

```74:88:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	if memo.Payload == nil {
		memo.Payload = &storepb.MemoPayload{}
	}

	// Use goldmark service to extract all metadata in a single pass (more efficient)
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	if err != nil {
		return errors.Wrap(err, "failed to extract markdown metadata")
	}

	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

**Triggers** — this function is called (always via the `memopayload.RebuildMemoPayload` symbol) whenever memo content is set or changed:
- `CreateMemo` — every new memo, at `server/router/api/v1/memo_service.go:108`.
- `UpdateMemo` — only when the request's update mask includes the `content` path (i.e. the content actually changed), at `server/router/api/v1/memo_service.go:447`.
- Transitively, `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:56`) delegates to `CreateMemo`, so comments get the same treatment.
- (There is also a batch backfill path, `Runner.RunOnce`/`CheckAndPresign`-style loop in `server/runner/memopayload/runner.go:27-72`, which calls the same function over every memo in the store — but per my earlier findings this runner is never constructed/started from `server/server.go`, so it's not an active trigger at runtime.)

**Extracted properties** — from `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:355-422`), computed in a single AST walk over the content:
- `Tags` — every `#tag` found in the content (deduplicated, case-preserving), stored into `memo.Payload.Tags`.
- `Mentions` — every `@username` mention found (lowercased, deduplicated) — extracted by `ExtractAll` but not persisted onto `MemoPayload` by `RebuildMemoPayload` (only `Tags` and `Property` are copied over).
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one.
- `Property.HasLink` — whether any link node is present.
- `Property.HasCode` — whether any code block/fenced code block/code span is present.
- `Property.HasTaskList` — whether any task checkbox is present.
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked.

These derived `Tags`/`Property` values (not directly editable by the user) are what memo list/preview UI reads to show tags, titles, and content-type indicators without re-parsing markdown on every render.
