**Premise correction:** there is no GraphQL API in this codebase — no `.graphql` schema files, no `gqlgen`/GraphQL library dependency, and no mention of GraphQL anywhere in the Go source, `go.mod`, or docs (a repo-wide search returns zero hits).

**Actual API surface:** the public API is defined via Protocol Buffers as a gRPC service, exposed simultaneously over gRPC, [Connect](https://connectrpc.com/) (gRPC-Web/HTTP+JSON), and a REST-style gateway. The schema definitions live in `proto/api/v1/`:

```
proto/api/v1/ai_service.proto
proto/api/v1/attachment_service.proto
proto/api/v1/auth_service.proto
proto/api/v1/common.proto
proto/api/v1/idp_service.proto
proto/api/v1/instance_service.proto
proto/api/v1/memo_service.proto
proto/api/v1/shortcut_service.proto
proto/api/v1/user_service.proto
```

These `.proto` files are compiled into generated Go code under `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go` for the REST gateway, and `apiv1connect/*.connect.go` for Connect), and the concrete handlers implementing these services live in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`, `attachment_service.go`). There's also a separate MCP (Model Context Protocol) surface under `server/router/mcp/`, and an RSS feed under `server/router/rss/`, but none of these are GraphQL either.
