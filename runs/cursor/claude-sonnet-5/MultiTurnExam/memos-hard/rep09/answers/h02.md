**Protection mechanism:** a custom dial guard, `safeDialContext()` in `internal/webhook/webhook.go:57-77`, installed as the `DialContext` of the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:29-37`). Because this check happens at dial time (after DNS resolution), it also blocks DNS‑rebinding bypasses, not just the URL as originally entered. There's a complementary, earlier check — `ValidateURL()` in `internal/webhook/validate.go:62-83` — run at webhook create/update time (e.g. `server/router/api/v1/user_service_webhooks.go`), using the same `isReservedIP()` helper, but the guard that actually protects the delivery call itself is `safeDialContext`.
