h06.

Four RPC handler methods in `server/router/api/v1` transitively reach the webhook dispatcher, all converging on `webhook.Post()` (the function that actually issues the outbound HTTP request to the admin/user-configured webhook URL, `internal/webhook/webhook.go:119`) via `webhook.PostAsync()`:

**Handlers:**
1. `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:70`) → calls `s.DispatchMemoCreatedWebhook` at `memo_service.go:157` → `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`) → `webhook.PostAsync`.
2. `APIV1Service.UpdateMemo` (`server/router/api/v1/memo_service.go:401`) → `dispatchMemoUpdatedSideEffects` → `s.DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`) → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`.
3. `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`) → `s.DispatchMemoDeletedWebhook` at `memo_service.go:562` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync`.
4. `APIV1Service.CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:20`) → `s.DispatchMemoCommentCreatedWebhook` at `memo_service_comments.go:119` (`memo_service_webhooks.go:30`) → `webhook.PostAsync` directly.

Each of these builds a `webhook.WebhookRequestPayload` whose `URL` field is set to the user's stored webhook URL (`hook.Url`, from `s.Store.GetUserWebhooks`) and calls `webhook.PostAsync(payload)` (e.g. `memo_service_webhooks.go:71`), which enqueues the payload for the background workers that call `Post()`.

**Convergence function:** `Post()` — `internal/webhook/webhook.go:119` (invoked by the async worker pool started in `init()` at `webhook.go:42-55`, which drains the queue filled by `PostAsync()` at `webhook.go:182-196`; `Post()` performs the actual `safeClient.Do(req)` outbound call at `webhook.go:152`).
