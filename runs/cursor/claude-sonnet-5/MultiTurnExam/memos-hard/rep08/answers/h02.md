**Protection mechanism**: the shared `safeClient`'s custom `http.Transport.DialContext`, set to `safeDialContext` (`internal/webhook/webhook.go:32-77`). At dial time it resolves the target hostname and rejects the connection if any resolved IP falls in a reserved/private range (checked via `isReservedIP`, defined in `internal/webhook/validate.go:44-54`, against the `reservedCIDRs` list covering loopback, RFC‑1918 private ranges, link-local/cloud metadata address `169.254.169.254`, and IPv6 equivalents at `internal/webhook/validate.go:14-23`). Dialing at request time (rather than only validating the URL upfront) defeats DNS‑rebinding attacks. There's also an upfront check, `ValidateURL` (`internal/webhook/validate.go:62-83`), used when webhooks are registered/updated, which performs the same reserved-IP check via DNS lookup before a webhook URL is even saved.
