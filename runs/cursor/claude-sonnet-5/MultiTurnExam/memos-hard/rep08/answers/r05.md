**Premise correction**: This project does not expose a GraphQL API — there is no GraphQL schema anywhere in the repo (no `.graphql`/`.gql` files, and no GraphQL library in `go.mod`).

**Actual API surface**: The public API is defined as Protocol Buffers (gRPC/Connect-RPC) service definitions under `proto/api/v1/`, e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, and shared types in `common.proto`. These are compiled (via `buf`, configured in `proto/buf.gen.yaml`/`buf.yaml`) into Go code under `proto/gen/api/v1/` — including gRPC service stubs, a gRPC-Gateway (`*.pb.gw.go`) for REST/JSON access, and Connect-RPC handlers (`apiv1connect/`). An OpenAPI/Swagger description is also generated and embedded via `proto/openapi_embed.go`, and these services are registered onto the HTTP server in `server/router/api/v1/v1.go` (`RegisterGateway`).
