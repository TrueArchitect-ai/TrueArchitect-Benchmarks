**Mechanism:** Go's `embed` package — the built React static assets (`dist/`) are compiled directly into the Go binary and served via a filesystem HTTP handler.

**Wired in:** `server/router/frontend/frontend.go`

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

The frontend build output is placed in `server/router/frontend/dist`, embedded via `embed.FS`, and served through `getFileSystem("dist")` / `fs.Sub(embeddedFiles, path)` in that same file.
