Complete call chain for creating a memo, frontend hook → SQL `INSERT`:

1. **Frontend mutation hook** — `web/src/hooks/useMemoQueries.ts` (`useCreateMemo`, calls `memoServiceClient.createMemo(...)`)
2. **Generated client** — `web/src/connect.ts` (`memoServiceClient = createClient(MemoService, transport)`)
3. **Proto RPC definition** — `proto/api/v1/memo_service.proto` (`rpc CreateMemo(CreateMemoRequest) returns (Memo)`, `post: "/api/v1/memos"`)
4. **Backend handler** — `server/router/api/v1/memo_service.go` (`APIV1Service.CreateMemo`)
5. **Store method** — `store/memo.go` (`Store.CreateMemo`, delegates to `s.driver.CreateMemo`)
6. **Dialect driver (SQL INSERT)** — `store/db/sqlite/memo.go` (`DB.CreateMemo`, executes `INSERT INTO \`memo\` (...) VALUES (...) RETURNING ...`); equivalent implementations also exist in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`
