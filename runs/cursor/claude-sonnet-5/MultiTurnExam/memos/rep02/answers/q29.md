It manages two token kinds:
- **Access token** — a short-lived bearer token kept in memory/`localStorage` (`web/src/auth-state.ts`) and attached as `Authorization: Bearer <token>` on every Connect RPC request.
- **Refresh token** — an httpOnly cookie sent automatically via `credentials: "include"` (`fetchWithCredentials` in `connect.ts`), used to silently obtain a new access token through `AuthService.RefreshToken` when the access token is missing/expired or a request returns `Unauthenticated`.
