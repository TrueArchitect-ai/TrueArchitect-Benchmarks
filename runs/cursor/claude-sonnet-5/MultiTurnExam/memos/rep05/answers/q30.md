Memo lifecycle events that dispatch webhooks (all defined in `server/router/api/v1/memo_service_webhooks.go`, called from the handlers noted):

- created: `DispatchMemoCreatedWebhook` (called from `CreateMemo` in `server/router/api/v1/memo_service.go`)
- updated: `DispatchMemoUpdatedWebhook` (called from `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go`)
- deleted: `DispatchMemoDeletedWebhook` (called from `DeleteMemo` in `server/router/api/v1/memo_service.go`)
- comment created: `DispatchMemoCommentCreatedWebhook` (called from `CreateMemoComment` in `server/router/api/v1/memo_service_comments.go`)

**Convergence point for delivery:** All of these (except the comment-created one) funnel through the internal helper `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`; every path ultimately calls `webhook.PostAsync` in `internal/webhook/webhook.go`, which performs the actual signed HTTP delivery.
