**Engine:** CEL (Common Expression Language, via `cel-go`) — implemented in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`)

**Mechanism:** The `filter` package parses the CEL filter string with `cel-go` against a memo-specific schema (`internal/filter/schema.go`), normalizes it into a dialect-agnostic intermediate representation (`internal/filter/ir.go`), and then a per-dialect renderer (`internal/filter/render.go`, selected via `filter.DialectName`: `sqlite`, `mysql`, or `postgres`) walks that IR to emit a SQL `WHERE`-clause fragment plus placeholder arguments tailored to that dialect's syntax (e.g., JSON access, boolean semantics, `LIKE` vs `ILIKE`), which each dialect's `ListMemos` driver implementation then appends to its query.
