**Interceptor:** `web/src/connect.ts` (`authInterceptor`, a Connect `Interceptor` that attaches the `Authorization: Bearer <token>` header and handles 401-triggered token refresh/retry)

**Token kinds it manages:** short-lived JWT **access token** (kept in memory/JS state via `web/src/auth-state.ts`, sent as a Bearer header) and a **refresh token** (stored in an HTTP-only cookie, sent automatically via `credentials: "include"` and exchanged through `AuthService.refreshToken`). It also supports **Personal Access Tokens (PAT)** for non-browser API access.

**Backend package that validates them:** `server/auth` (e.g. `Authenticator.AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT` in `server/auth/authenticator.go`)
