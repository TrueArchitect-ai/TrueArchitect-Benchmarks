The server only actually starts **one** background runner, wired in `repo/server/server.go` (`startBackgroundRunners`):

- **s3presign runner** — `repo/server/runner/s3presign/runner.go`. Triggered by an internal `time.NewTicker(runnerInterval)` with `runnerInterval = time.Hour * 12` inside its own `Run(ctx)` loop; it's also run once synchronously at startup (`s3presignRunner.RunOnce(ctx)`) before the ticking goroutine is launched.

**Unused scheduling infrastructure:** `repo/server/runner/memopayload/runner.go` defines a `Runner` type with a `NewRunner` constructor and a `RunOnce` method that looks like a background job runner, but it is never instantiated or invoked anywhere (`memopayload.NewRunner`/`memopayload.Runner` has zero call sites). The package's only actively used function is the standalone `memopayload.RebuildMemoPayload` helper, called synchronously and inline from `repo/server/router/api/v1/memo_service.go` (in `CreateMemo` and `UpdateMemo`) — not from any scheduled runner.
