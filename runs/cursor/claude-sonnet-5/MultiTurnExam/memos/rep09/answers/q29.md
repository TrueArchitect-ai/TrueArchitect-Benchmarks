- **Interceptor path:** `web/src/connect.ts` (`authInterceptor`, applied to the Connect `transport` used to build all service clients)
- **Token kinds it manages:** JWT **access tokens** (short-lived, ~15 min, held in memory/localStorage via `web/src/auth-state.ts` and attached as `Authorization: Bearer <token>`) and JWT **refresh tokens** (long-lived, ~30 days, stored in an httpOnly cookie sent automatically via `credentials: "include"`, and exchanged through the `RefreshToken` RPC on 401 or proactive expiry checks)
- **Backend package that validates them:** `server/auth` (e.g. `server/auth/token.go`, `server/auth/authenticator.go`, `server/auth/extract.go`)
