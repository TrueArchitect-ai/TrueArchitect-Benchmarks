**Dispatcher — `APIV1Service.DispatchMemoCreatedWebhook`, `server/router/api/v1/memo_service_webhooks.go`**

Called from the `CreateMemo` handler (`server/router/api/v1/memo_service.go:157`), it delegates to `dispatchMemoRelatedWebhook`, which looks up the creator's registered webhooks and calls `webhook.PostAsync(payload)` for each.

**Delivery package — `internal/webhook`** (`internal/webhook/webhook.go`): `PostAsync` enqueues the payload onto a bounded channel consumed by worker goroutines that call `Post`, which builds and sends the actual `http.NewRequest("POST", ...)` via a shared, SSRF-hardened `http.Client`.

**Signing mechanism — HMAC-SHA256** (Standard Webhooks style): if a `SigningSecret` is set, `Post` computes `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, base64-encodes the digest, and sends it in the `webhook-signature: v1,<sig>` header alongside `webhook-id` and `webhook-timestamp` headers (see `internal/webhook/webhook.go:133-150`).
