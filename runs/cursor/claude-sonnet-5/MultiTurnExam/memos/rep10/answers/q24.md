Complete call chain for creating a memo, frontend to SQL:

1. **`web/src/hooks/useMemoQueries.ts`** — `useCreateMemo()` mutation (calls `memoServiceClient.createMemo({ memo: memoToCreate })`)
2. **`web/src/connect.ts`** — `memoServiceClient` (Connect client for `MemoService`)
3. **`proto/api/v1/memo_service.proto`** — `rpc CreateMemo(CreateMemoRequest) returns (Memo)` (`POST /api/v1/memos`)
4. **`server/router/api/v1/memo_service.go`** — `APIV1Service.CreateMemo(ctx, request)` handler
5. **`store/memo.go`** — `Store.CreateMemo(ctx, create)` → delegates to `s.driver.CreateMemo(ctx, create)`
6. **`store/db/postgres/memo.go`** — `DB.CreateMemo(ctx, create)`, which builds and executes `INSERT INTO memo (...) VALUES (...) RETURNING id, created_ts, updated_ts, row_status` (equivalent implementations also exist in `store/db/sqlite/memo.go` and `store/db/mysql/memo.go`)
