**Engine + path**: CEL (Common Expression Language) via `google.golang.org/cel-go`, wrapped in a custom `Engine` in `internal/filter/engine.go` (`NewEngine`/`Compile`, using `cel.NewEnv` + `cel.AstToParsedExpr`).

**Mechanism**: The CEL filter string is compiled into a dialect-agnostic `Condition` tree (`internal/filter/engine.go`, `Program.ConditionTree()`), and each store driver (`store/db/{postgres,mysql,sqlite}/memo.go`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectPostgres/DialectMySQL/DialectSQLite, &where, &args)` (`internal/filter/helpers.go`), which uses the dialect-specific rendering logic in `internal/filter/render.go` (branching on `DialectName` throughout, e.g. `LIKE`/`ILIKE`, `json_each`/`jsonb_array_elements_text`/`JSON_TABLE`, date functions, etc.) to translate the condition tree into the appropriate SQL `WHERE` clause fragments and bound arguments for that specific database.
