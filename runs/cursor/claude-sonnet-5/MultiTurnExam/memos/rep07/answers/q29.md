**Interceptor path:** `web/src/connect.ts` (`authInterceptor`, attached to the Connect transport)

**Token kinds it manages:**
- **Access token** — a short-lived bearer JWT, attached as an `Authorization: Bearer <token>` header on each request (managed via `web/src/auth-state.ts`, `getAccessToken`/`setAccessToken`)
- **Refresh token** — a separate long-lived token stored as an httpOnly cookie (sent automatically via `credentials: "include"`), used by the interceptor to silently refresh the access token on expiry/401 (`refreshAccessToken`/`doRefreshAccessToken` in `connect.ts`, calling `AuthService.RefreshToken`)

**Backend package that validates them:** `server/auth` (in particular `server/auth/authenticator.go`, with methods like `Authenticator.AuthenticateByAccessTokenV2`, `Authenticator.AuthenticateByRefreshToken`, `Authenticator.AuthenticateByPAT`, and `Authenticator.AuthenticateToUser`)
