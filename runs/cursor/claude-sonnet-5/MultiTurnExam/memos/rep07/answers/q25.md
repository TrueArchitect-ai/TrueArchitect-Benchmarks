**Engine + path:** [google/cel-go](https://github.com/google/cel-go) (CEL — Common Expression Language), wrapped by this repo's own `Engine`/`Program` in `internal/filter/engine.go` (with supporting logic in `internal/filter/parser.go`, `internal/filter/ir.go`, `internal/filter/schema.go`, and `internal/filter/render.go`).

**Mechanism:** The filter string is compiled by a CEL environment (`cel.NewEnv`/`env.Compile`) into a CEL AST, which `buildCondition` (in `internal/filter/ir.go`/`parser.go`) turns into a dialect-agnostic `Condition` tree; then `Program.Render(RenderOptions{Dialect: ...})` walks that tree with a per-dialect `renderer` (`internal/filter/render.go`) that emits the appropriate SQL fragment and positional placeholders/args for SQLite, MySQL, or PostgreSQL respectively.
