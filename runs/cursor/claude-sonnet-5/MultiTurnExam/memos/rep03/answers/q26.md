When `Store.DeleteMemo` runs, the following tables are affected:

- **`memo`** — the target row itself is deleted (`store/db/sqlite/memo.go`, `DELETE FROM memo WHERE id = ?`)
- **`memo_relation`** — explicitly deleted first, both where the memo is the source and the target (`store/memo.go`, `s.driver.DeleteMemoRelation`)
- **`attachment`** — explicitly deleted first via `ListAttachments`/`DeleteAttachment` for all attachments linked to the memo (`store/memo.go`)
- **`memo_share`** — removed via an explicit SQL-level `ON DELETE CASCADE` foreign key to `memo(id)`, not Go code (`store/migration/sqlite/LATEST.sql`)
