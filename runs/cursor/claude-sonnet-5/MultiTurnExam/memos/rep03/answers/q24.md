Full call chain for creating a memo:

1. `web/src/hooks/useMemoQueries.ts` — frontend mutation hook `useCreateMemo` (calls `memoServiceClient.createMemo(...)`)
2. `web/src/connect.ts` — ConnectRPC client (`memoServiceClient`, generated `MemoService` client)
3. `proto/api/v1/memo_service.proto` — proto RPC definition `rpc CreateMemo(CreateMemoRequest) returns (Memo)` (maps to `POST /api/v1/memos`)
4. `server/router/api/v1/memo_service.go` — backend handler `APIV1Service.CreateMemo`
5. `store/memo.go` — store method `Store.CreateMemo`
6. `store/db/sqlite/memo.go` — dialect driver `(*DB).CreateMemo` (issues the SQL `INSERT`; equivalent implementations also exist in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`)
