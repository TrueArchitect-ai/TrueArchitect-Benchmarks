q25. **Engine:** CEL (Common Expression Language), via `internal/filter/engine.go` (uses `cel.NewEnv`, `cel.AstToParsedExpr`, backed by `internal/filter/schema.go` for the memo variable schema and `internal/filter/parser.go`/`internal/filter/ir.go` for parsing into an intermediate representation).

**Mechanism:** `ListMemos`'s `filter` string is parsed by the CEL environment into an AST/parsed expression, converted into the engine's own `Condition` IR, and then `internal/filter/render.go`'s `renderer.Render` walks that IR to emit dialect-specific SQL fragments and placeholder args — branching on a `DialectName` enum (`DialectSQLite`, `DialectMySQL`, `DialectPostgres` defined in `internal/filter/schema.go`) to choose the correct SQL syntax for things like JSON extraction, string concatenation, and timestamp handling (e.g. `jsonExtractExpr`, `qualifyColumn`, `stringLengthExpr` in `internal/filter/render.go`) before the resulting `WHERE` clause is appended by each dialect's store driver (e.g. `store/db/postgres/memo.go`) when building the `ListMemos` query.
