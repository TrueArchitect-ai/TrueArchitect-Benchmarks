q02. SQLite, PostgreSQL, MySQL

The `store/migration` directory contains three subdirectories, one per SQL dialect:

- `/bench/repo/store/migration/sqlite`
- `/bench/repo/store/migration/postgres`
- `/bench/repo/store/migration/mysql`

This is corroborated by `store/db` also having matching driver subdirectories (`sqlite`, `postgres`, `mysql`).
