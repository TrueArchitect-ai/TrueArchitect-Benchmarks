There is no per-user API rate-limiting middleware and no request limits of that kind.

Registered server middleware is Echo `Recover` and CORS (`server/server.go`), plus Connect interceptors for metadata, logging, panic recovery, and auth (`server/router/api/v1/v1.go`). The only “rate limiter” mention is an optional email-send example in `internal/email/README.md`, not API middleware.
