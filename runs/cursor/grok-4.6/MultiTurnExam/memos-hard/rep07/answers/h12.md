`sqlite.DB.CreateMemo` — `store/db/sqlite/memo.go`; default `driver` is `"sqlite"` (`cmd/memos/main.go`), and `db.NewDBDriver` only then constructs `sqlite.NewDB` (`store/db/db.go`)

With no DB flags, viper/cobra default `driver` to `"sqlite"` (`cmd/memos/main.go:122`, `cmd/memos/main.go:130`). Startup calls `db.NewDBDriver`, whose switch uses `sqlite.NewDB` for that value (`store/db/db.go:18-20`). `store.Store.CreateMemo` (`store/memo.go`) forwards to `driver.CreateMemo`; the SQLite implementation issues `INSERT INTO memo` (`store/db/sqlite/memo.go:16`, `store/db/sqlite/memo.go:41`). The MySQL and Postgres `CreateMemo` methods are unused on that path.
