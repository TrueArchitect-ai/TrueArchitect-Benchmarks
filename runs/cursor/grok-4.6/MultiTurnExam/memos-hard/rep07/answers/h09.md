8; `store.Store` — `server/server.go`; `SSEHub` — `server/server.go`

Backend `Close` methods: `SSEHub` (`server/router/api/v1/sse_hub.go`), `cache.Cache` (`store/cache/cache.go`), `store.Store` (`store/store.go`), `sqlite.DB` / `mysql.DB` / `postgres.DB` (`store/db/{sqlite,mysql,postgres}`), plus test-only `MemoFilterTestContext` and `AttachmentFilterTestContext` (`store/test/filter_helpers_test.go`). `Driver` also names `Close` in `store/driver.go` but that is the interface, not another implementation.

Non-test server code calls `s.Store.Close()` from `Server.Shutdown` and `s.sseHub.Close()` from `closeLongLivedConnections` (`server/server.go`). `Store.Close` then closes the caches and `s.driver.Close()` (`store/store.go`); the three DB `Close` methods are not called from server code directly. `http.Server.Close` in `shutdownHTTPServer` is stdlib, not a repo declaration.
