h02.
`Post` — `internal/webhook/webhook.go`; `safeDialContext` / `isReservedIP` — `internal/webhook/webhook.go` and `internal/webhook/validate.go`

Outbound webhook HTTP POSTs run in `Post` (`internal/webhook/webhook.go`), which `PostAsync` workers call. Delivery uses `safeClient`, whose transport dials through `safeDialContext`; that resolver rejects reserved/private IPs via `isReservedIP` and `reservedCIDRs` in `internal/webhook/validate.go` (SSRF / DNS-rebinding guard). `ValidateURL` in the same file applies the same check when a webhook URL is registered.
