There is no nightly database-cleanup cron job and no scheduled cleanup time.

`internal/scheduler` is a library only; production never constructs or starts it (`server/server.go` runs `s3presign` every 12 hours instead). `"0 2 * * *"` / `"daily-cleanup"` appears only as a package example in `internal/scheduler/doc.go`, not as a registered DB job.
