There is no Redis cache. Caching is an in-process `store/cache.Cache` created in `store.New` (`store/store.go`); user entries use that cache’s **10-minute** `DefaultTTL`.

`userCache` is `cache.New(cacheConfig)` with `DefaultTTL: 10 * time.Minute` (`store/store.go:40-52`). `Store` user writes call `userCache.Set` (`store/user.go`), which applies `DefaultTTL` (`store/cache/cache.go:94`). Nothing in the repo configures or imports Redis.
