`getUserByUsername` — `server/router/fileserver/fileserver.go`

`DB.ListUsers` — `store/db/sqlite/user.go` (same method in `store/db/mysql/user.go`, `store/db/postgres/user.go`)

The browser hits `GET /file/users/:identifier/avatar` (`RegisterRoutes` in `server/router/fileserver/fileserver.go`). `convertUserFromStore` in `server/router/api/v1/user_service_converters.go` sets that URL for stored data-URI avatars. The lookup is by username, so `GetUser` skips the ID cache and loads via `ListUsers`, which selects `avatar_url`. `serveUserAvatar` then decodes that column with `parseDataURI`.
