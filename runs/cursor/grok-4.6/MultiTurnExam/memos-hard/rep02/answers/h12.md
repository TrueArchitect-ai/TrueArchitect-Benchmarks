sqlite.DB.CreateMemo — store/db/sqlite/memo.go; default driver is sqlite, selected by NewDBDriver

With no DB flags, `viper.SetDefault("driver", "sqlite")` in `cmd/memos/main.go` is what `NewDBDriver` sees (`store/db/db.go`), so it constructs `sqlite.NewDB`. Saving a memo goes `store.Store.CreateMemo` → `driver.CreateMemo`. MySQL and Postgres each have their own `CreateMemo` with an `INSERT`; only the SQLite one runs by default — the one that builds `INSERT INTO \`memo\` ...` in `store/db/sqlite/memo.go`.
