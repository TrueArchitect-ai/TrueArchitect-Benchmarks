The browser loads `/file/users/{username}/avatar` (set in `convertUserFromStore` in `server/router/api/v1/user_service_converters.go`). `RegisterRoutes` in `server/router/fileserver/fileserver.go` maps that to `serveUserAvatar`, which looks up the other user by URL identifier, reads `avatar_url` from the `user` row, then `parseDataURI` in the same fileserver file decodes the stored data URI into image bytes.
