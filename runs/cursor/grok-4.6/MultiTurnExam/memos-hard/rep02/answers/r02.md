There is no per-user API rate-limiting middleware and no request limits of that kind.

Server middleware is only recover and CORS (`server/server.go`). Auth is handled by the gRPC-Gateway / Connect authorizer (`server/router/api/v1/v1.go`, `authz.go`), not a rate limiter. The only “rate limit” mention is a comment in `internal/email/doc.go` about sending email, not HTTP API quotas.
