There is no Redis connection. Caching is an in-process memory cache (`store/cache.Cache`); user entries use the store’s default TTL of **10 minutes**.

`store.New` in `store/store.go` builds `userCache` with `cache.Config{DefaultTTL: 10 * time.Minute, ...}` (same as `cache.DefaultConfig` in `store/cache/cache.go`). User reads/writes go through `s.userCache.Set` / `Get` in `store/user.go`, and `Set` applies `DefaultTTL`. Nothing in the repo configures or imports Redis.
