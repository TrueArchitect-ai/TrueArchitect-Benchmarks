h02.
Post — internal/webhook/webhook.go; safeDialContext — internal/webhook/webhook.go

Outbound webhook HTTP POSTs run in `Post` (`internal/webhook/webhook.go`), using `safeClient`. That client’s `DialContext` is `safeDialContext` in the same file: it resolves the host and refuses reserved/private IPs (loopback, RFC-1918, link-local/IMDS, IPv6 ULA) so the request cannot be aimed at internal addresses, including after DNS rebinding. The CIDR list and `isReservedIP` live in `internal/webhook/validate.go`; `ValidateURL` applies the same check when a webhook URL is saved.
