6; store.Store — server/server.go (Server.Shutdown); SSEHub — server/server.go (Server.closeLongLivedConnections)

Six production `Close` methods: `store.Store` (`store/store.go`), `cache.Cache` (`store/cache/cache.go`), `sqlite.DB` / `mysql.DB` / `postgres.DB` (`store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, `store/db/postgres/postgres.go`), and `SSEHub` (`server/router/api/v1/sse_hub.go`). The `store.Driver` interface also lists `Close()` (`store/driver.go`). Two more exist only in tests (`MemoFilterTestContext` and `AttachmentFilterTestContext` in `store/test/filter_helpers_test.go`).

Non-test server code calls only `Store.Close` and `SSEHub.Close`. `Store.Close` then calls `Cache.Close` and `driver.Close()` (`store/store.go`); `http.Server.Close` in `shutdownHTTPServer` is the standard library, not a repo declaration.
