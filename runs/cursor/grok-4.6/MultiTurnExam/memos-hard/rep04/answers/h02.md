Post — internal/webhook/webhook.go; safeDialContext (reserved-CIDR / isReservedIP SSRF guard) — internal/webhook/webhook.go and internal/webhook/validate.go

Outbound HTTP delivery runs in `Post` via `safeClient`. That client’s `Transport` uses `safeDialContext`, which resolves the host and refuses reserved/private ranges listed in `reservedCIDRs` (`isReservedIP`). `ValidateURL` applies the same check when a webhook URL is configured.
