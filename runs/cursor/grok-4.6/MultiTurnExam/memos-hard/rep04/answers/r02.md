There is no per-user API rate-limiting middleware and no request-limit configuration. Echo only uses recover/CORS (`server/server.go`); auth is in Connect/gRPC interceptors (`server/router/api/v1/connect_interceptors.go`, `authz.go`). The only “rate limit” mention is a suggested email-sending limiter in `internal/email/README.md`, not registered API middleware. Semaphores on thumbnail/image work (`server/router/api/v1/v1.go`) cap concurrency, not per-user request rates.
