There is no GraphQL schema. The public API is protobuf gRPC (AIP-style) under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, and the other `*_service.proto` files). Generated Connect and gRPC-Gateway handlers expose Connect/gRPC plus REST (`server/router/api/v1/`, `proto/gen/api/v1/`). The README calls this REST and gRPC, not GraphQL.
