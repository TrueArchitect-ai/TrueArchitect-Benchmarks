A browser loads `/file/users/:identifier/avatar` (from `convertUserFromStore` rewriting stored data URIs). `serveUserAvatar` looks up the other user, then `GetUser` (username, so no ID cache hit) calls `ListUsers`, which runs the driver query that selects `avatar_url`. The handler then decodes that data URI via `parseDataURI`.
