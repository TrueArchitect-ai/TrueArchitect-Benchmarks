sqlite.DB.CreateMemo — store/db/sqlite/memo.go; default `--driver`/`viper` is `"sqlite"` (cmd/memos/main.go), NewDBDriver selects sqlite.NewDB (store/db/db.go), Store.CreateMemo delegates to driver.CreateMemo (store/memo.go)

MySQL and Postgres also implement `CreateMemo` with their own `INSERT`s. A default install never constructs those drivers, so the SQLite method is the one that runs `INSERT INTO memo`.
