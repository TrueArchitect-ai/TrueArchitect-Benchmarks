There is no GraphQL schema. The public API is protobuf `api.v1` services under `proto/api/v1/` (for example `memo_service.proto`, `user_service.proto`, `auth_service.proto`). Those RPCs are served as gRPC-Gateway HTTP/JSON and Connect handlers, registered in `server/router/api/v1/v1.go`. Extra HTTP surfaces (fileserver, RSS, frontend) are not GraphQL either.
