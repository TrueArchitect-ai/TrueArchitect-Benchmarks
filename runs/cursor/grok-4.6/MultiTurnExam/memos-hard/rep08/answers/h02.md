h02.
Post — internal/webhook/webhook.go; safeDialContext / isReservedIP — internal/webhook/webhook.go and internal/webhook/validate.go

Outbound HTTP delivery runs in `Post` (`internal/webhook/webhook.go`). `PostAsync` only enqueues; workers call `Post`, which POSTs via `safeClient`. That client’s `safeDialContext` resolves the host at dial time and rejects reserved/private IPs through `isReservedIP` and `reservedCIDRs` in `internal/webhook/validate.go` (SSRF / DNS-rebinding). `ValidateURL` in the same file applies the same check when a webhook URL is configured.
