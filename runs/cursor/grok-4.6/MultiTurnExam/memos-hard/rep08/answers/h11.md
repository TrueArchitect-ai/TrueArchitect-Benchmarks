1st: User (~7 packages); 2nd: Memo (~6 packages)

Persistent entities live in `store/` (`User`, `Memo`, `Attachment`, and so on). Outside that tree, `store.User` appears in `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, and `server/router/rss`. `store.Memo` appears in `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, and `server/runner/memopayload`. Next is `Attachment` (~4). Excluding the test package, User is still first (~6) and Memo second (~5).
