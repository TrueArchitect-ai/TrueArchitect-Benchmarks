markdown.service — NewAPIV1Service via markdown.NewService (server/router/api/v1/v1.go); holders: APIV1Service, RSSService, memopayload.Runner

The interface is `markdown.Service` in `internal/markdown/markdown.go`. The only implementation is the unexported `service` returned by `NewService`. Production builds it in `NewAPIV1Service` with `WithTagExtension` and `WithMentionExtension`. That instance is stored on `APIV1Service.MarkdownService`, passed into `RSSService` from `server/server.go`, and accepted by `memopayload.Runner` / `RebuildMemoPayload` (the API uses the same field). There is no second runtime impl.
