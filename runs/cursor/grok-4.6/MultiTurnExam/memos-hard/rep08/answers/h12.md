sqlite.DB.CreateMemo — store/db/sqlite/memo.go; default driver is sqlite (cmd/memos/main.go), selected by NewDBDriver (store/db/db.go)

With no DB flags, `viper.SetDefault("driver", "sqlite")` and the `--driver` default are both `"sqlite"` (`cmd/memos/main.go`). `db.NewDBDriver` then constructs `sqlite.NewDB`. `Store.CreateMemo` (`store/memo.go`) calls `s.driver.CreateMemo`, so the INSERT that runs is `func (d *DB) CreateMemo` in `store/db/sqlite/memo.go` (`INSERT INTO \`memo\``). MySQL and Postgres have the same method, but they are not selected on a default install.
