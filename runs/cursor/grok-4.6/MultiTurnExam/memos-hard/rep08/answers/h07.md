The browser hits `GET /file/users/:identifier/avatar` (API user proto rewrites stored data-URI avatars to that path in `server/router/api/v1/user_service_converters.go`). The handler loads the target user by username, then `GetUser` → `ListUsers` → the driver `SELECT` of `avatar_url` from `user`. Bytes are decoded from that column via `parseDataURI` in `fileserver.go`, not a separate blob table.
