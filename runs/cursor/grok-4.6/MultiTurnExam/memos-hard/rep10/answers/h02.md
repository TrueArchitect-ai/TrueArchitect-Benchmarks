h02.
`webhook.Post` — `internal/webhook/webhook.go`; `safeDialContext` — `internal/webhook/webhook.go`

Outbound webhook POSTs run in `Post` via `safeClient`. That client’s `DialContext` is `safeDialContext`, which resolves the host and refuses reserved/private IPs (loopback, RFC-1918, link-local/IMDS, and IPv6 equivalents in `internal/webhook/validate.go`) so delivery cannot be aimed at the internal network, including after DNS rebinding. `ValidateURL` applies the same reserved-IP check when a webhook URL is stored.
