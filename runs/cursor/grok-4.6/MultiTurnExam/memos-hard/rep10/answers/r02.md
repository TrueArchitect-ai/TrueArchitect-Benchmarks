There is no per-user API rate-limiting middleware and no request-rate limits. Echo only registers recover and CORS (`server/server.go`); API auth is the gateway/Connect authorizer (`server/router/api/v1/v1.go`). Semaphores cap concurrent thumbnail/image work, not request rate. Email docs mention rate limiting as future work (`internal/email/README.md`), not an implemented limiter.
