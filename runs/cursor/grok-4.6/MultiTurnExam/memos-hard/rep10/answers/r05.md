There is no GraphQL schema. The public API is protobuf AIP services under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, and the rest). Those are served as Connect (`/memos.api.v1.*`) and gRPC-Gateway HTTP from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`). Extra HTTP surfaces are the file server (`server/router/fileserver`) and RSS (`server/router/rss`).
