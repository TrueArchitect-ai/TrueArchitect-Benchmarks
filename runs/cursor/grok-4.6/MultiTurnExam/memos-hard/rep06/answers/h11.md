1st: User (~7 packages); 2nd: Memo (~6 packages)

Persistent entities are the `store` structs (`Memo`, `User`, `Attachment`, and so on). Counting `store.Type` mentions outside `store/` and `proto/gen`, **User** shows up in seven packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`. **Memo** is next with six: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`. Dropping `_test.go` files still ranks User first (~6) then Memo (~4). Attachment is third (~3–4).
