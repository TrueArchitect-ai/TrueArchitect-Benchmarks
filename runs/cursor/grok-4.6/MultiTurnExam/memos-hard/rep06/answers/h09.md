There are eight `func (…) Close` declarations in backend Go: `SSEHub` (`server/router/api/v1/sse_hub.go`), `store.Store` (`store/store.go`), `cache.Cache` (`store/cache/cache.go`), `sqlite.DB` / `mysql.DB` / `postgres.DB`, plus test-only `MemoFilterTestContext` and `AttachmentFilterTestContext` (`store/test/filter_helpers_test.go`). Non-test server code calls two of those: `Server.closeLongLivedConnections` → `sseHub.Close()`, and `Server.Shutdown` → `Store.Close()`. `Store.Close` then calls `Cache.Close` on the three caches and `driver.Close()` (the selected DB driver). The test helpers are never used from the server.
