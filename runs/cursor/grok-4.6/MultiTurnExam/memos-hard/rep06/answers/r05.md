There is no GraphQL schema. The public API is protobuf RPC (Connect + gRPC-Gateway).

Services are defined under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, and the rest). `APIV1Service.RegisterGateway` in `server/router/api/v1/v1.go` mounts gRPC-Gateway and Connect handlers at `/memos.api.v1.*`. Extra HTTP surfaces are the file server (`/file/...`), RSS, and the frontend—not GraphQL.
