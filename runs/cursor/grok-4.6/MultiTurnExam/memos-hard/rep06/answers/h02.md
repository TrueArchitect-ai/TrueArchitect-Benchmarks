Post — internal/webhook/webhook.go; safeDialContext (reserved/private IP block via isReservedIP) — internal/webhook/webhook.go

Outbound HTTP delivery runs in `Post` in `internal/webhook/webhook.go` (`safeClient.Do`). `PostAsync` only queues work; workers still call `Post`. Connections go through `safeDialContext` in the same file, which resolves the host and refuses reserved/private IPs using `isReservedIP` / `reservedCIDRs` in `internal/webhook/validate.go` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA). That dial-time check is the SSRF guard, including against DNS rebinding. `ValidateURL` in `internal/webhook/validate.go` applies the same private-IP rule when a webhook URL is configured.
