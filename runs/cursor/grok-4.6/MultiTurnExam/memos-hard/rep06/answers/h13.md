markdown.service (*service via NewService) — NewAPIV1Service (server/router/api/v1/v1.go:48) — APIV1Service, RSSService

The interface is `markdown.Service` in `internal/markdown/markdown.go`. The only implementation is the unexported `service` (goldmark plus tag/mention extensions). Production builds it in `NewAPIV1Service` with `markdown.NewService(WithTagExtension(), WithMentionExtension())` and stores it on `APIV1Service.MarkdownService`. `Server.NewServer` passes that same instance into `rss.NewRSSService` (`server/server.go:85`), so `RSSService` holds the interface too. `memopayload.Runner` also has a `markdown.Service` field, but `NewRunner` is not used at runtime; memo create/update just call `RebuildMemoPayload` with `s.MarkdownService`.
