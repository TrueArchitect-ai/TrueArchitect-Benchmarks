There is no nightly database-cleanup cron job, so no scheduled time.

`internal/scheduler` is a reusable cron library. Its package docs (`internal/scheduler/doc.go`) only show a sample `"daily-cleanup"` at `"0 2 * * *"` (2 AM). Production never calls `scheduler.New` or `Register`. `Server.startBackgroundRunners` (`server/server.go`) starts only the S3 presign runner on a 12-hour ticker, not a DB cleanup job. Cache “cleanup” is expired-entry eviction every 5 minutes (`store/store.go`, `store/cache/cache.go`), not a nightly database sweep.
