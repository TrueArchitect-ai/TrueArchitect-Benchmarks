There is no Redis cache connection. Caching is an in-process memory `store/cache.Cache`; user entries use a 10-minute default TTL.

Nothing in the repo configures Redis (no client, DSN, or cache-backend flag). `store.New` in `store/store.go` builds `cache.Config{DefaultTTL: 10 * time.Minute, ...}` and `userCache: cache.New(cacheConfig)`. `store.Cache` is documented as a thread-safe in-memory cache (`store/cache/cache.go`). User writes go through `userCache.Set`, which applies `DefaultTTL` (`cache.go:92-94`). There is no user-specific TTL override.
