A browser loads `/file/users/{username}/avatar` (the URL the API substitutes for stored data-URI avatars in `server/router/api/v1/user_service_converters.go`). Echo routes that to `FileServerService.serveUserAvatar` (`server/router/fileserver/fileserver.go:124`, `:168`). The handler looks up the other user via `getUserByUsername` → `Store.GetUser` with `FindUser.Username`. Username lookups skip the ID cache, so `GetUser` calls `Store.ListUsers` → `driver.ListUsers`, which `SELECT`s `avatar_url` from `user` (`store/db/sqlite/user.go:151-165`; same in `store/db/mysql/user.go` and `store/db/postgres/user.go`). The handler then decodes that column with `parseDataURI` and returns the bytes.
