Visibility is not only in `GetMemo`. Single-memo API reads go through `checkMemoReadAccess`; list/related-memo queries add `VisibilityList` / CEL `visibility` filters. Linked attachments are gated again on the API (`checkAttachmentAccess`) and on `/file` (`checkAttachmentPermission`). RSS and the sitemap only load `store.Public` memos. Live SSE delivery uses `canReceive` (private events only to the creator/admin). Outbound email uses `canViewerAccessMemo`. Reactions, comments, and `ListMemoAttachments` repeat the same private/public rules inline in those handlers.
