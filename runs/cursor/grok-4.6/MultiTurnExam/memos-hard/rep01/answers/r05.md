There is no GraphQL schema. The public API is protobuf-defined gRPC/Connect plus REST via gRPC-Gateway.

Service contracts live in `proto/api/v1/*.proto` (AIP-style). The server registers them in `server/router/api/v1/v1.go` as gRPC-Gateway HTTP routes and Connect handlers for browsers. The README calls this “full REST and gRPC APIs.”
