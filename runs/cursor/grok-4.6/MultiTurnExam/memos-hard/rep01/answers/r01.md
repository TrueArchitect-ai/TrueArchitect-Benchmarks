There is no Redis connection. The cache is an in-process `store/cache.Cache` (`sync.Map` + TTL) created in `store.New` (`store/store.go`); user entries use the default TTL of **10 minutes** (`userCache.Set` → `SetWithTTL` with `DefaultTTL`).

`store/cache/cache.go` documents this as “thread-safe in-memory cache.” `userCache` is built with `DefaultTTL: 10 * time.Minute` and `CleanupInterval: 5 * time.Minute`. User writes go through `s.userCache.Set` in `store/user.go`, which applies that default TTL—no per-user override and no Redis config.
