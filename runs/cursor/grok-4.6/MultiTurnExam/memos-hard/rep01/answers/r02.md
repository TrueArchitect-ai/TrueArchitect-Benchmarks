There is no per-user API rate-limiting middleware, so there are no request limits to report.

Registered server middleware is Echo `Recover` and CORS (`server/server.go`, `server/cors.go`). Connect interceptors are metadata, logging, panic recovery, and auth (`server/router/api/v1/v1.go`). Rate limiting appears only as an unimplemented suggestion in `internal/email/README.md` / `internal/email/doc.go`.
