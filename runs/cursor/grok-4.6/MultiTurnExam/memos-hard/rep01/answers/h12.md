(*sqlite.DB).CreateMemo — store/db/sqlite/memo.go; default driver is sqlite (`cmd/memos/main.go` viper/flag default), selected by `db.NewDBDriver` (`store/db/db.go`)

With no `--driver`/`--dsn`, `viper.SetDefault("driver", "sqlite")` and the `--driver` flag default both pick SQLite. `NewDBDriver` then calls `sqlite.NewDB`. Saving a memo goes `Store.CreateMemo` → `driver.CreateMemo`; only the SQLite method runs the `INSERT INTO memo`. MySQL and Postgres have the same method name but are not constructed on that path.
