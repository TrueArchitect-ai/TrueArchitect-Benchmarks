`server/runner/s3presign/runner.go` refreshes S3 presigned attachment URLs (`CheckAndPresign`) so external object links stay valid. It ticks every 12 hours (`runnerInterval = time.Hour * 12`). `Server.Start` wires it in by calling `startBackgroundRunners`, which constructs the runner, runs it once, then starts `Run` in a background goroutine.
