DB.ListUsers — store/db/sqlite/user.go (also store/db/mysql/user.go, store/db/postgres/user.go)

A browser hits `GET /file/users/:identifier/avatar`. `serveUserAvatar` loads the other user via `getUserByUsername` → `Store.GetUser` → `Store.ListUsers` → driver `ListUsers`, which reads `avatar_url` from the `user` table. The image bytes are that stored data URI, decoded by `parseDataURI` in the same fileserver file.
