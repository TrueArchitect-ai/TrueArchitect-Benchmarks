`*markdown.service` — `markdown.NewService` in `NewAPIV1Service` (`server/router/api/v1/v1.go`) — `APIV1Service`, `RSSService` (`server/router/rss/rss.go`); also `memopayload.Runner`

`markdown.Service` (`internal/markdown/markdown.go`) has one implementation: unexported `*service`, built by `NewService` with `WithTagExtension` and `WithMentionExtension`. Production construction is `NewAPIV1Service` (`server/router/api/v1/v1.go:48–56`); tests do the same in `server/router/api/v1/test/test_helper.go`. That instance is stored on `APIV1Service.MarkdownService` and passed to `rss.NewRSSService` (`server/server.go:85`). `memopayload.Runner` also holds `markdown.Service`, but `NewRunner` is not started with the server; memo create/update call `RebuildMemoPayload` with the API service’s instance.
