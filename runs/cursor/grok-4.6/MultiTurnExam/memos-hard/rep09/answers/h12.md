`sqlite.DB.CreateMemo` — `store/db/sqlite/memo.go`; default `driver` is `"sqlite"` in `cmd/memos/main.go`, selected by `NewDBDriver` in `store/db/db.go`

With no database flags, `viper.SetDefault("driver", "sqlite")` and `--driver` default to `"sqlite"` (`cmd/memos/main.go:122`, `:130`). `db.NewDBDriver` then calls `sqlite.NewDB` (`store/db/db.go:18–20`). Saving a memo goes `Store.CreateMemo` → `s.driver.CreateMemo` (`store/memo.go:109–113`). MySQL and Postgres also implement `CreateMemo`, but they are not constructed on that default path, so the INSERT that runs is `sqlite.DB.CreateMemo` (`INSERT INTO \`memo\` …` at `store/db/sqlite/memo.go:16–51`).
