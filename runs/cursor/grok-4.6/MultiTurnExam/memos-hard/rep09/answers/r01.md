There is no Redis cache. Users live in an in-process `store/cache.Cache` with a **10-minute** default TTL (`store/store.go`, `store/cache/cache.go`).

`Store.New` builds `userCache` with `DefaultTTL: 10 * time.Minute` (same as `cache.DefaultConfig`). User writes go through `userCache.Set` (`store/user.go`), which calls `SetWithTTL(..., DefaultTTL)`. Nothing in the repo configures a Redis connection or a user-specific TTL.
