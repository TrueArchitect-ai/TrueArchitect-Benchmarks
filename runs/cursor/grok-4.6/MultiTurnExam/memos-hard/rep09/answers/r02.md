There is no per-user API rate-limiting middleware and no request limits for it.

The Echo stack only registers `Recover` and CORS (`server/server.go`). Auth is an authorizer/interceptor (`server/router/api/v1/v1.go`), not a rate limiter. The only “rate limit” mention is a comment in `internal/email/doc.go` about sending email, not HTTP APIs.
