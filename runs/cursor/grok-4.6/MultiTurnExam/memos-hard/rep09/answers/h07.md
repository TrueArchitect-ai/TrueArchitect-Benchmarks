`serveUserAvatar` — `server/router/fileserver/fileserver.go`  
`getUserByUsername` — `server/router/fileserver/fileserver.go`  
`Store.GetUser` — `store/user.go`  
`Store.ListUsers` — `store/user.go`  
`DB.ListUsers` — `store/db/sqlite/user.go` (also `store/db/mysql/user.go`, `store/db/postgres/user.go`)

The browser loads `/file/users/:identifier/avatar` (set on `User.avatar_url` in `server/router/api/v1/user_service_converters.go`). `serveUserAvatar` looks up the target user via `getUserByUsername` → `Store.GetUser` (by username, so no ID cache hit) → `Store.ListUsers` → driver `ListUsers`, which SELECTs `avatar_url` from `user`. The handler then decodes that data URI with `parseDataURI` and returns the bytes.
