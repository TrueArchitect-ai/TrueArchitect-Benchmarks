There is no nightly database-cleanup cron job, so no scheduled time.

`internal/scheduler` is a cron library (`ParseCronExpression`, `Scheduler.Register`/`Start`) and is not imported or started by the server (`cmd/memos/main.go`, `server/server.go`). The only background job is the S3 presign runner on a 12-hour ticker (`server/runner/s3presign/runner.go`). Cache “cleanup” is an in-memory TTL sweep every 5 minutes (`store/cache/cache.go`), not a database job.
