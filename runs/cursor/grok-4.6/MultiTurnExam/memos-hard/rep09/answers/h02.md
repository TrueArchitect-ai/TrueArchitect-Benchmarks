h02.
`Post` — `internal/webhook/webhook.go`; `safeDialContext` — `internal/webhook/webhook.go`

Outbound HTTP notifications are webhooks. `Post` (`internal/webhook/webhook.go`) is the function that actually POSTs the payload via `safeClient`. `PostAsync` only enqueues work; the workers still call `Post`.

SSRF protection is `safeDialContext` on that client: it resolves the host at dial time and rejects reserved/private addresses (loopback, RFC-1918, link-local/IMDS, IPv6 ULA). The CIDR list and `isReservedIP` live in `internal/webhook/validate.go`. `ValidateURL` in the same file applies the same check when a webhook URL is configured.
