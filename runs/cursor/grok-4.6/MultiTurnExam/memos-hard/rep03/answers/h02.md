h02.
`Post` — `internal/webhook/webhook.go`; `safeDialContext` — `internal/webhook/webhook.go`

Outbound webhook HTTP POSTs run in `Post` (`internal/webhook/webhook.go`), which is what the async workers call. Delivery uses `safeClient`, whose `DialContext` is `safeDialContext`: it resolves the host and refuses reserved/private ranges (`isReservedIP` / `reservedCIDRs` in `internal/webhook/validate.go`), so the target cannot be an internal address (including DNS rebinding). `ValidateURL` in the same file applies the same check when a webhook URL is configured.
