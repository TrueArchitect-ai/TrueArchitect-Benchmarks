`serveUserAvatar` — `server/router/fileserver/fileserver.go`  
`getUserByUsername` — `server/router/fileserver/fileserver.go`  
`Store.GetUser` — `store/user.go`  
`Store.ListUsers` — `store/user.go`  
`DB.ListUsers` — `store/db/sqlite/user.go` (same in `store/db/mysql/user.go`, `store/db/postgres/user.go`)

The browser hits `GET /file/users/:identifier/avatar` (`RegisterRoutes` in `server/router/fileserver/fileserver.go`). The converter turns stored data-URI avatars into that path (`server/router/api/v1/user_service_converters.go`). `serveUserAvatar` loads the user via `getUserByUsername` → `Store.GetUser` (username lookup skips the ID cache) → `ListUsers` → driver SQL on `user.avatar_url`. The handler then decodes that field with `parseDataURI`.
