`*markdown.service` — `markdown.NewService` in `NewAPIV1Service` (`server/router/api/v1/v1.go`); holders: `APIV1Service.MarkdownService`, `RSSService.MarkdownService`

`markdown.Service` (`internal/markdown/markdown.go`) is implemented only by unexported `service`. Production builds it once in `NewAPIV1Service` with `WithTagExtension` and `WithMentionExtension`. `Server` passes that same instance into `rss.NewRSSService` (`server/server.go`). Memo payload rebuilds use `s.MarkdownService` via `RebuildMemoPayload`; `memopayload.Runner` can hold the interface but is never constructed in production. Tests call `NewService` themselves.
