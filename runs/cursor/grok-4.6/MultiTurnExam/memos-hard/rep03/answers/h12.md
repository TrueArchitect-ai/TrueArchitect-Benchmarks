`(*sqlite.DB).CreateMemo` — `store/db/sqlite/memo.go`; default `driver` is `"sqlite"` (`cmd/memos/main.go` viper/flag), factory `NewDBDriver` selects `sqlite.NewDB` (`store/db/db.go`), and `Store.CreateMemo` calls `driver.CreateMemo`

With no database flags, `viper.SetDefault("driver", "sqlite")` and the `--driver` default are both sqlite. Startup builds the driver via `db.NewDBDriver` (`case "sqlite"`). Saving a memo goes `Store.CreateMemo` → that driver’s `CreateMemo`, which runs `INSERT INTO memo ...` in `store/db/sqlite/memo.go`. The mysql/postgres `CreateMemo` methods are unused on a default install.
