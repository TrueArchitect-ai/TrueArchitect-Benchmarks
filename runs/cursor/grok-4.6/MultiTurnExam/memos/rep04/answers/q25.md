CEL (cel-go) + internal/filter; CEL is compiled to a dialect-agnostic IR, then `CompileToStatement`/`AppendConditions` render SQL fragments and placeholders for sqlite, mysql, or postgres.

`ListMemos` puts the filter string on `FindMemo.Filters` (`server/router/api/v1/memo_service.go`). Each dialect’s `ListMemos` (`store/db/{sqlite,mysql,postgres}/memo.go`) calls `filter.DefaultEngine()` and `filter.AppendConditions` with `DialectSQLite`, `DialectMySQL`, or `DialectPostgres`. Pipeline: parse (`parser.go` / cel-go) → IR (`ir.go`) → render (`render.go`). Schema is in `internal/filter/schema.go`.
