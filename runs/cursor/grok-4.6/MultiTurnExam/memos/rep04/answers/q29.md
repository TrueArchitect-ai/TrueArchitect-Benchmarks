web/src/connect.ts; access token (Bearer) and refresh token (cookie); server/auth

`authInterceptor` in `web/src/connect.ts` sets `Authorization: Bearer` from `web/src/auth-state.ts` and refreshes via `AuthService.refreshToken` with `credentials: "include"`. The backend validates those in `server/auth` (`Authenticator`: access-token JWT, refresh-token cookie, and PAT for non-browser clients). Connect/gateway attach that via `NewAuthInterceptor` / gateway middleware in `server/router/api/v1/v1.go`.
