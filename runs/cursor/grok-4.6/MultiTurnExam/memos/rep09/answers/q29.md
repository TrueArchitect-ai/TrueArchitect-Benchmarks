web/src/connect.ts; access token (Bearer JWT) and refresh token (HttpOnly cookie); server/auth

`authInterceptor` in `web/src/connect.ts` attaches `Authorization: Bearer <access token>` (from `web/src/auth-state.ts`) and uses `credentials: "include"` so the `memos_refresh` cookie is sent. On 401 it calls `AuthService.RefreshToken` and retries. The backend validates those tokens in `server/auth` (`Authenticator.AuthenticateByAccessTokenV2` / `AuthenticateByRefreshToken`); that package also accepts PATs, which the frontend interceptor does not issue.
