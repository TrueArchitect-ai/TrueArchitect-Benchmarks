q16.
memo_relation records (as source or target), attachments

`Store.DeleteMemo` in `store/memo.go` deletes `memo_relation` rows where the memo is `memo_id` or `related_memo_id`, then deletes linked attachments via `DeleteAttachment`, then deletes the memo row. The API handler in `server/router/api/v1/memo_service.go` deletes comment memos first, but that happens above the store cleanup.
