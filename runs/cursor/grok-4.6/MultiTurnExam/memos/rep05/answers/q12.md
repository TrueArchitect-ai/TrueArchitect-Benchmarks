`useInfiniteMemos` in `web/src/hooks/useMemoQueries.ts` calls `memoServiceClient.listMemos`, created in `web/src/connect.ts`. That maps to `rpc ListMemos` on `MemoService` in `proto/api/v1/memo_service.proto`. `APIV1Service.ListMemos` in `server/router/api/v1/memo_service.go` calls `Store.ListMemos` in `store/memo.go`, which delegates to a dialect driver such as `DB.ListMemos` in `store/db/sqlite/memo.go` (postgres and mysql have the same method too). The same hook file also exports `useMemos`, which is unused in production UI.
