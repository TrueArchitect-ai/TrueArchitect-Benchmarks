CEL (cel-go) — internal/filter; each dialect calls `filter.AppendConditions` with `DialectSQLite`/`DialectMySQL`/`DialectPostgres`, which compiles the CEL string to a dialect-agnostic IR then renders a parameterized SQL fragment.

`ListMemos` in `server/router/api/v1/memo_service.go` puts `request.Filter` on `FindMemo.Filters`. The engine in `internal/filter` (entry `engine.go`, parse `parser.go`, IR `ir.go`, SQL `render.go`) uses `cel-go` to parse standard CEL against the memo schema. Drivers in `store/db/{sqlite,postgres,mysql}/memo.go` convert those filters to `WHERE` clauses via `CompileToStatement`.
