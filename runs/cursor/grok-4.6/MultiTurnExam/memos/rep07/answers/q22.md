`CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which loads the creator's hooks and posts via `webhook.PostAsync`. `internal/webhook/webhook.go` delivers the HTTP request and, when a secret is set, signs the body with HMAC-SHA256 using Standard Webhooks headers (`webhook-id`, `webhook-timestamp`, `webhook-signature: v1,...`).
