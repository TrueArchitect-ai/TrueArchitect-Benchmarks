memo_relation (source and target), attachments

`Store.DeleteMemo` in `store/memo.go` first calls `DeleteMemoRelation` for `MemoID` and `RelatedMemoID`, then deletes linked attachments via `ListAttachments` / `DeleteAttachment`, and only then `driver.DeleteMemo` (the `memo` row). The API handler in `server/router/api/v1/memo_service.go` additionally deletes comment memos first; that is not store-layer cleanup of the memo row itself.
