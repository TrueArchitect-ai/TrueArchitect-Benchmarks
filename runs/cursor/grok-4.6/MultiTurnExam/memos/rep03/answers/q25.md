CEL (`google/cel-go`) — internal/filter; each dialect’s `ListMemos` calls `filter.AppendConditions`, which compiles the CEL string to a condition tree and renders dialect-specific SQL (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`) into the query `WHERE` clause.

The API validates the filter with `validateFilter` in `server/router/api/v1/shortcut_service.go` (used from `ListMemos` in `memo_service.go`). Rendering is in `internal/filter/render.go` and `helpers.go`; dialect call sites are `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, and `store/db/postgres/memo.go`.
