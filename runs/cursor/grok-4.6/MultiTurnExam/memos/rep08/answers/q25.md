CEL (`cel-go`) — internal/filter; each dialect’s `ListMemos` calls `filter.DefaultEngine()` then `filter.AppendConditions` with `DialectSQLite` / `DialectMySQL` / `DialectPostgres`, which compiles the CEL AST to IR and renders a parameterized SQL `WHERE` fragment.

`ListMemos` validates the filter in `server/router/api/v1/shortcut_service.go` (`validateFilter`) and stores it on `FindMemo.Filters`. The engine pipeline is described in `internal/filter/README.md` (`engine.go`, `parser.go`, `render.go`). SQLite wiring is in `store/db/sqlite/memo.go` (same pattern in the MySQL and Postgres `memo.go` drivers).
