There is no Redis connection: the cache layer is an in-process memory cache, not Redis. `store/store.go` builds `userCache` in `New()` with `cache.Config{DefaultTTL: 10 * time.Minute, CleanupInterval: 5 * time.Minute, MaxItems: 1000}` and `cache.New(cacheConfig)` from `store/cache/cache.go`. User writes in `store/user.go` call `s.userCache.Set()`, which applies that default TTL, so user entries expire after **10 minutes**.
