There is no GraphQL schema in this repository. The public API is a Protocol Buffers / AIP-style surface in `proto/api/v1/`, served as REST (`google.api.http` + gRPC-Gateway), gRPC, and Connect RPC, with generated OpenAPI at `proto/gen/openapi.yaml`.

**Actual API surface** (`proto/api/v1/`):

- `memo_service.proto` — `MemoService` (`/api/v1/memos`)
- `user_service.proto` — `UserService` (`/api/v1/users`)
- `auth_service.proto` — `AuthService` (`/api/v1/auth/*`)
- `attachment_service.proto` — `AttachmentService` (`/api/v1/attachments`)
- `instance_service.proto` — `InstanceService` (`/api/v1/instance/*`)
- `shortcut_service.proto` — `ShortcutService` (`/api/v1/users/*/shortcuts`)
- `idp_service.proto` — `IdentityProviderService` (`/api/v1/identity-providers`)
- `ai_service.proto` — `AIService` (`/api/v1/ai:transcribe`)
- `common.proto` — shared enums/messages (`State`, `Direction`, `PageToken`)

Handlers live in `server/router/api/v1/`; Buf codegen is configured in `proto/buf.gen.yaml`.
