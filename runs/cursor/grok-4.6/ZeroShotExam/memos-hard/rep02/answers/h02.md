h02.
Post — internal/webhook/webhook.go; isReservedIP — internal/webhook/validate.go

Outbound webhook HTTP delivery runs in `Post` (`internal/webhook/webhook.go`), which POSTs through `safeClient`. Callers such as `dispatchMemoRelatedWebhook` only enqueue via `PostAsync`; workers then call `Post`.

Internal targets are blocked by `isReservedIP` (`internal/webhook/validate.go`), which rejects reserved/private CIDRs (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local). Delivery uses that check in `safeDialContext` at dial time (also defeating DNS rebinding). `ValidateURL` in the same file applies the same check when a webhook URL is stored.
