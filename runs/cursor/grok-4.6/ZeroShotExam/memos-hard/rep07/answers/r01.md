There is no Redis connection for the cache layer; the repo never mentions Redis. Caching is an in-process in-memory store (`store/cache/cache.go`) constructed in `store/store.go` (`New`) with `DefaultTTL: 10 * time.Minute`. User rows use that same config via `userCache` and `Set` in `store/user.go`, so user entries expire after 10 minutes.
