`*markdown.service` — `markdown.NewService` inside `apiv1.NewAPIV1Service` — `APIV1Service`, `RSSService` (and unused `memopayload.Runner`)

Markdown work is behind `markdown.Service` in `internal/markdown/markdown.go`. The only concrete type is the unexported `service` struct in that file; `NewService` returns it (with `WithTagExtension` and `WithMentionExtension` in production).

The production constructor is `NewAPIV1Service` in `server/router/api/v1/v1.go`. `server.NewServer` in `server/server.go` then passes that same instance into `rss.NewRSSService`.

The interface is held as a `MarkdownService` field on `APIV1Service` (`server/router/api/v1/v1.go`) and `RSSService` (`server/router/rss/rss.go`). `memopayload.Runner` in `server/runner/memopayload/runner.go` also declares the field, but `NewRunner` is never called on the production path.
