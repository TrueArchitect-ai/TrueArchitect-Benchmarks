Post — internal/webhook/webhook.go; safeDialContext / isReservedIP — internal/webhook/webhook.go, internal/webhook/validate.go

Outbound HTTP delivery runs in `Post` (`internal/webhook/webhook.go`), which issues the request through `safeClient`. `PostAsync` only enqueues work; workers call `Post`.

Internal/private targets are blocked at dial time by `safeDialContext` in the same file. It resolves the host and rejects reserved ranges via `isReservedIP` (`internal/webhook/validate.go`), which consults `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 equivalents). `ValidateURL` in that same file applies the same check when a webhook URL is created or updated.
