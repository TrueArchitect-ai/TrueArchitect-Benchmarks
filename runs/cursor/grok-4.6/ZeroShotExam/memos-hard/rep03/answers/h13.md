`*markdown.service` — `v1.NewAPIV1Service` via `markdown.NewService` (same instance passed to `rss.NewRSSService` from `server.NewServer`) — `APIV1Service`, `RSSService` (`memopayload.Runner` also holds `markdown.Service`, but `NewRunner` is never called at startup)

Markdown work is behind `markdown.Service` in `internal/markdown/markdown.go`. The only runtime impl is the unexported `service` returned by `markdown.NewService`. `NewAPIV1Service` in `server/router/api/v1/v1.go` constructs it with `WithTagExtension()` and `WithMentionExtension()` and stores it on `APIV1Service`. `server/server.go` then hands that same value to `rss.NewRSSService`, so `RSSService` in `server/router/rss/rss.go` holds it too. `memopayload.Runner` in `server/runner/memopayload/runner.go` has the same field type, but production code only calls `RebuildMemoPayload` with the `APIV1Service` instance.
