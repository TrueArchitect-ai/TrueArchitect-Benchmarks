There is no Redis connection for the cache layer. Caching is an in-process memory store (`sync.Map` plus a cleanup goroutine) in `store/cache/cache.go`, wired in `store/store.go` `New()` as `userCache: cache.New(cacheConfig)` with `DefaultTTL: 10 * time.Minute`. User writes go through `s.userCache.Set(...)` in `store/user.go`, which always uses that default TTL, so user entries expire after 10 minutes.
