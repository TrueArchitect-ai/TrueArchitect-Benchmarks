Post — `internal/webhook/webhook.go`; safeDialContext / isReservedIP — `internal/webhook/webhook.go`; `internal/webhook/validate.go`

`Post` is the function that actually sends the HTTP POST (`safeClient.Do`). Callers enqueue via `PostAsync`, and workers then invoke `Post`.

SSRF protection is `safeDialContext` on that client’s transport: it resolves the host at dial time and rejects reserved/private addresses via `isReservedIP` and `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local). `ValidateURL` in the same validate file applies the same check when a webhook URL is configured.
