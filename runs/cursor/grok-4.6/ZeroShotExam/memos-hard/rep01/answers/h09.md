8; Store (`server/server.go`), SSEHub (`server/server.go`)

The eight `Close` method declarations (`func (T) Close`) in the backend are:

- `*SSEHub` — `server/router/api/v1/sse_hub.go`
- `*cache.Cache` — `store/cache/cache.go`
- `*store.Store` — `store/store.go`
- `*sqlite.DB` — `store/db/sqlite/sqlite.go`
- `*postgres.DB` — `store/db/postgres/postgres.go`
- `*mysql.DB` — `store/db/mysql/mysql.go`
- `*MemoFilterTestContext` — `store/test/filter_helpers_test.go`
- `*AttachmentFilterTestContext` — `store/test/filter_helpers_test.go`

Non-test server code only invokes two of those:

- `*store.Store.Close` from `server/server.go` (`s.Store.Close()` in `Shutdown`)
- `*SSEHub.Close` from `server/server.go` (`s.sseHub.Close()` in `closeLongLivedConnections`)

Other `.Close()` calls in `server/` are stdlib types (`net.Listener`, `http.Server`, `os.File`, `io.ReadCloser`), not these declarers. `Cache.Close` and the DB-driver `Close` methods run only from `store.Store.Close`, not from server code. `server/router/api/v1/test/test_helper.go` also calls `Store.Close`, but that is test helper code.
