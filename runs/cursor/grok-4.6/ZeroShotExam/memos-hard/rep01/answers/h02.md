h02.
Post — internal/webhook/webhook.go; isReservedIP (via safeDialContext) — internal/webhook/validate.go

Outbound HTTP runs in `Post` (`safeClient.Do`). `PostAsync` only queues work; workers then call `Post`. Delivery uses a custom `DialContext` (`safeDialContext` in the same file) that resolves the host and rejects reserved/private IPs through `isReservedIP` and `reservedCIDRs` in `internal/webhook/validate.go` (loopback, RFC-1918, link-local/IMDS, and IPv6 equivalents), which also stops DNS rebinding. `ValidateURL` in that file applies the same check when a webhook URL is saved.
