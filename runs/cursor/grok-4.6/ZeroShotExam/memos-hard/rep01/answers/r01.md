There is no Redis connection in this repository. The cache layer is an in-process, in-memory `sync.Map` cache, not a Redis client.

Configuration lives in `store/store.go`: `store.New` builds a shared `cache.Config` (`DefaultTTL` 10 minutes, `CleanupInterval` 5 minutes, `MaxItems` 1000) and constructs `userCache` with `cache.New(cacheConfig)`. The implementation is `store/cache/cache.go` (`DefaultConfig` matches those values). User rows are written with `s.userCache.Set` in `store/user.go`, which uses that default TTL, so user entries expire after **10 minutes**.
