There is no GraphQL schema. The public API is Protocol Buffers (Connect RPC / gRPC-Gateway / OpenAPI), defined in `proto/api/v1/` (`*.proto` service files such as `memo_service.proto`, `user_service.proto`, `auth_service.proto`). Generated outputs live in `proto/gen/` and `web/src/types/proto/`; handlers are in `server/router/api/v1/`.
