h02.
`Post` — `internal/webhook/webhook.go`; `safeDialContext` — `internal/webhook/webhook.go`

Outbound HTTP delivery runs in `Post` (`safeClient.Do`). `PostAsync` only queues work; workers call `Post`. `safeDialContext` is the client’s `DialContext`: it resolves the host and refuses reserved/private IPs via `isReservedIP` / `reservedCIDRs` in `internal/webhook/validate.go`, so the request cannot be aimed at internal addresses (including after DNS rebinding). `ValidateURL` in the same file applies that check when a webhook URL is saved.
