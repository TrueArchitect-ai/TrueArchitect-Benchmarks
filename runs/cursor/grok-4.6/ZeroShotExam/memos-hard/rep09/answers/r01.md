There is no Redis connection: the cache layer is a process-local in-memory map, not a Redis client. `store/store.go` builds `userCache` (along with instance-setting and user-setting caches) in `New()` with `cache.Config{DefaultTTL: 10 * time.Minute, CleanupInterval: 5 * time.Minute, MaxItems: 1000}`, and `store/user.go` writes users via `userCache.Set`, which applies that default TTL. The implementation lives in `store/cache/cache.go`.
