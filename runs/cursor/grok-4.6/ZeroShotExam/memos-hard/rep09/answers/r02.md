The premise is wrong: this repo does not register per-user API rate-limiting middleware, so there are no per-user request limits.

HTTP middleware in `server/server.go` is only `middleware.Recover()` and CORS (`newCORSMiddleware`). API registration in `server/router/api/v1/v1.go` adds auth (`gatewayAuthMiddleware` / `NewAuthInterceptor`) plus Connect metadata, logging, and recovery interceptors. The only numeric API bound there is a **256 MiB request-body** cap (`maxAPIRequestBytes`), not a request-rate quota.

The only rate-limit text is an email-sending example in `internal/email/README.md` (10 emails per second via `golang.org/x/time/rate`), not wired as API middleware.
