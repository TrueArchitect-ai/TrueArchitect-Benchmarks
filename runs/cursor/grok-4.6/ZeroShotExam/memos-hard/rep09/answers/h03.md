h03.
`internal/idp`; `internal/idp/oauth2`

The provider abstraction lives in `internal/idp` (`idp.go` defines `IdentityProviderUserInfo`). The only shipped protocol implementation is OAuth2 in `internal/idp/oauth2` (`oauth2.go` implements token exchange and user-info mapping). Store/API types in `proto/store/idp.proto` and `proto/api/v1/idp_service.proto` also only list `OAUTH2`.
