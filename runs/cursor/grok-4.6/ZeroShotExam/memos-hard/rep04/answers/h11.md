h11.
1st: User; 2nd: Memo (~7 vs ~6 packages)

Persistent models live in the `store/` data layer (`store/driver.go`, plus `store/user.go`, `store/memo.go`, and the other `store/*.go` entity files). Counting Go packages **outside** `store/` that name the entity type itself (`store.User`, `store.Memo`, …):

- **User** (~7): `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **Memo** (~6): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

If Find/Update/Delete query types are counted as references too, Memo also reaches 7 (via `store.FindMemo` in `server/router/fileserver`); User still leads on direct entity-type use. Next is Attachment (~4).
