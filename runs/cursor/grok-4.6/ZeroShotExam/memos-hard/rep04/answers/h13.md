`*markdown.service` — `markdown.NewService` inside `apiv1.NewAPIV1Service` — `APIV1Service`, `RSSService`, `memopayload.Runner`

The interface is `markdown.Service` in `internal/markdown/markdown.go`. The only implementation is the unexported `service` struct in that same file. Production construction happens in `server/router/api/v1/v1.go`: `NewAPIV1Service` calls `markdown.NewService(WithTagExtension(), WithMentionExtension())`. `server/server.go` then passes that same instance into `rss.NewRSSService`. The three structs that store the interface are `APIV1Service` (`server/router/api/v1/v1.go`), `RSSService` (`server/router/rss/rss.go`), and `memopayload.Runner` (`server/runner/memopayload/runner.go`). `memopayload.NewRunner` is never called at startup; memo paths use `RebuildMemoPayload` with the `APIV1Service`-held service instead.
