There is no per-user API rate-limiting middleware in this repository, so it is not registered anywhere and has no request-count limits.

HTTP middleware actually registered in `server/server.go` is Echo `Recover` and CORS (`newCORSMiddleware`). API registration in `server/router/api/v1/v1.go` adds gateway auth (`gatewayAuthMiddleware`), Connect interceptors (metadata, logging, recovery, auth), and a **request-body size** cap (`maxAPIRequestBytes = 256 << 20`, 256 MiB) via `http.MaxBytesHandler` — not a per-user request-rate limit.

The only “rate limit” text is an unimplemented email-sending suggestion in `internal/email/README.md` and `internal/email/doc.go`, not API middleware.
