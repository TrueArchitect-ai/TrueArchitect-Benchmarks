There is no Redis connection: the cache layer is an in-process in-memory `sync.Map` cache (`store/cache/cache.go`), not Redis. `store.New` in `store/store.go` builds a shared `cache.Config` (`DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`) and constructs `userCache` with `cache.New(cacheConfig)`. User writes in `store/user.go` call `s.userCache.Set(...)`, which applies that default TTL, so user entries expire after **10 minutes**.
