There is no Redis connection for the cache layer. User entries live in an in-process in-memory cache created in `store/store.go` (`New`) via `cache.New(cacheConfig)` on `userCache`, using the hardcoded `cache.Config` (`DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`). The implementation is `store/cache/cache.go`; `store/user.go` writes users with `userCache.Set`, which applies that 10-minute default TTL.
