`GET /file/users/:identifier/avatar` is handled by `serveUserAvatar`. It loads the target user via `getUserByUsername` → `Store.GetUser` (username lookup skips the ID cache) → `Store.ListUsers` → the active driver’s `ListUsers`, which reads `avatar_url` from the `user` table. The image bytes are that column’s data URI, decoded in-handler by `parseDataURI`.
