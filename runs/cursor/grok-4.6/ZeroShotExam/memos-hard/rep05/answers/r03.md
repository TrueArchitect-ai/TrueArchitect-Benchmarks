There is no nightly database-cleanup job in the cron scheduler. `internal/scheduler` is a reusable cron library and is never imported or started by the server; production background work is only the S3 presign runner in `server/server.go` / `server/runner/s3presign/runner.go` (a 12-hour ticker, not cron). A 2 AM `cleanup` job appears only as sample code in `internal/scheduler/example_test.go`, `internal/scheduler/doc.go`, and `internal/scheduler/README.md`.
