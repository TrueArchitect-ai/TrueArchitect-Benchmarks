h02.
Post — internal/webhook/webhook.go; safeDialContext (isReservedIP / reservedCIDRs) — internal/webhook/webhook.go, internal/webhook/validate.go

`Post` is the function that actually issues the HTTP POST (`safeClient.Do`). `PostAsync` only enqueues work; workers then call `Post`.

Delivery is bound to `safeClient`, whose transport uses `safeDialContext` to resolve the host and refuse reserved/private IPs at dial time (SSRF / DNS-rebinding). The ranges live in `reservedCIDRs` and are checked by `isReservedIP` in `internal/webhook/validate.go`. `ValidateURL` in that same file applies the same check when a webhook URL is configured.
