h11.
1st: User (~7 packages); 2nd: Memo (~6 packages)

Persistent entities live in the `store/` data layer (`store/user.go`, `store/memo.go`, and the other model files wired through `store/driver.go`). Counting Go packages **outside** `store/` that mention `store.User` vs `store.Memo`:

- **User** (~7): `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **Memo** (~6): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Next are Attachment (~4) and then Inbox / MemoRelation / MemoShare (~3 each). Proto store payloads (`storepb.*`) are used more narrowly and do not outrank User or Memo.
