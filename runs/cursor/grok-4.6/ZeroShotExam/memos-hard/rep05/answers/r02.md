r02.
There is no per-user API rate-limiting middleware in this repository, so it is not registered anywhere and has no request limits.

The HTTP stack in `server/server.go` only installs Echo `Recover` and CORS. API registration in `server/router/api/v1/v1.go` adds gRPC-Gateway auth middleware plus Connect interceptors for metadata, logging, recovery, and auth. Those paths cap request size at `maxAPIRequestBytes` (256 MiB); they do not count or throttle requests per user.

The only nearby “rate limit” text is a documentation example in `internal/email/README.md` (10 emails per second). That is not implemented API middleware. Concurrent thumbnail/image work is separately capped with semaphores in `server/router/api/v1/v1.go` (3 and 2), which is not per-user request rate limiting.
