8; Store (`server/server.go`), SSEHub (`server/server.go`)

There are **8** distinct `Close` method declarations in the Go backend:

| Type | Declaration |
| --- | --- |
| `*SSEHub` | `server/router/api/v1/sse_hub.go` |
| `*cache.Cache` | `store/cache/cache.go` |
| `*MemoFilterTestContext` | `store/test/filter_helpers_test.go` |
| `*AttachmentFilterTestContext` | `store/test/filter_helpers_test.go` |
| `*store.Store` | `store/store.go` |
| `*sqlite.DB` | `store/db/sqlite/sqlite.go` |
| `*postgres.DB` | `store/db/postgres/postgres.go` |
| `*mysql.DB` | `store/db/mysql/mysql.go` |

(The `Close()` specs on `store.Driver` and `cache.Interface` are interface methods, not extra method declarations.)

Non-test `server/` code only calls two of those:

- `*store.Store.Close` from `Server.Shutdown` in `server/server.go`
- `*SSEHub.Close` from `Server.closeLongLivedConnections` in `server/server.go`

(`*cache.Cache.Close` and the three `*DB.Close` implementations run only from `store.Store.Close` in `store/store.go`, not from server code. The two test-context `Close` methods are test-only.)
