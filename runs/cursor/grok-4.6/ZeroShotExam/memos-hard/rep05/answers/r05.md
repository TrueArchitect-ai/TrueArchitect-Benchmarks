There is no GraphQL schema in this repository. The public API is Protocol Buffer service definitions under `proto/api/v1/` (for example `memo_service.proto`, `user_service.proto`, `auth_service.proto`), which generate REST via gRPC-Gateway, gRPC, Connect RPC, and OpenAPI (`proto/gen/openapi.yaml`). `AGENTS.md` maps that directory as the public API surface; `README.md` describes REST and gRPC, not GraphQL.
