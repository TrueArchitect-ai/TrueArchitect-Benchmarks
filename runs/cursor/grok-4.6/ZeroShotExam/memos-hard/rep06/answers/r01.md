There is no Redis connection for the cache layer; the premise is wrong. The cache is an in-process in-memory store (`store/cache/cache.go`) wired in `store/store.go` (`New`), where `userCache` is created with `DefaultTTL: 10 * time.Minute`. User writes go through `userCache.Set` in `store/user.go`, which uses that default TTL (no per-user override).
