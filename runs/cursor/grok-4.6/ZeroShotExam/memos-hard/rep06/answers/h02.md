h02.
`Post` — `internal/webhook/webhook.go`; `safeDialContext` / `isReservedIP` — `internal/webhook/webhook.go` / `internal/webhook/validate.go`

Outbound webhook HTTP POSTs run in `Post` (`internal/webhook/webhook.go`) via `safeClient`. Destinations are blocked from reserved/private ranges at dial time by `safeDialContext`, which calls `isReservedIP` (`internal/webhook/validate.go`) against `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local). `ValidateURL` in the same file applies the same check when a webhook URL is configured.
