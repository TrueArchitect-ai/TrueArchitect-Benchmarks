The question assumes this repo registers per-user API rate-limiting middleware with numeric request limits. It does not.

`server/server.go` only registers Echo `Recover` and CORS. API request middleware in `server/router/api/v1/v1.go` is auth (`gatewayAuthMiddleware` / `NewAuthInterceptor`), plus Connect metadata, logging, and recovery interceptors. There is no rate-limiter, no per-user quota, and no request-count window.

The only rate-limit text in the tree is an email-sending example in `internal/email/README.md` (`10` emails per second). That is not registered as HTTP/API middleware. Nearby limits are size/concurrency, not request rates: `maxAPIRequestBytes` (`256 << 20`) in `server/router/api/v1/v1.go`, and image-processing/thumbnail semaphores.
