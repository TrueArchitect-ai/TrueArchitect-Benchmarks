User deletion runs a transaction that issues `DELETE FROM reaction WHERE creator_id = …` (the deleted user’s own reactions) and `DELETE FROM reaction WHERE content_id IN …` (reactions on that user’s memos). The `reaction` table has no foreign key or `ON DELETE` rule, so this is application-level cleanup, not a database cascade.
