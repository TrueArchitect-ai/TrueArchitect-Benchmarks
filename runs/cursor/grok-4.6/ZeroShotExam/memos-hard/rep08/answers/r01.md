There is no Redis connection for the cache layer; this repo never mentions or configures Redis. Caching is a process-local in-memory store (`store/cache/cache.go`) wired in `store/store.go` `New()`, where `userCache` is created from a shared `cache.Config` with **DefaultTTL of 10 minutes**. User writes in `store/user.go` call `userCache.Set()`, which applies that default TTL (not a per-entry override).
