The question assumes this repo registers per-user API rate-limiting middleware with specific request limits. That is incorrect.

There is no per-user API rate-limiting middleware and no request-count limits. HTTP middleware in `server/server.go` is only Echo `Recover` and CORS. API wrappers in `server/router/api/v1/v1.go` are auth (gRPC-Gateway), plus Connect interceptors for metadata, logging, panic recovery, and auth. Those paths also cap request **size** (`maxAPIRequestBytes` = 256 MiB), not request rate.

The only rate-limit text is a **recommendation** for email sending in `internal/email/README.md` and `internal/email/doc.go` (example: 10 emails/second). That is not implemented or registered as API middleware.
