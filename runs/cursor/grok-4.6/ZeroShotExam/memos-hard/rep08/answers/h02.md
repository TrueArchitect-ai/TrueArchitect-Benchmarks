Post — internal/webhook/webhook.go; safeDialContext / isReservedIP — internal/webhook/webhook.go and internal/webhook/validate.go

Outbound HTTP delivery runs in `Post`, which issues the request through `safeClient`. `PostAsync` only enqueues work; workers call `Post`. SSRF protection is `safeDialContext` on that client: it resolves the host at dial time and rejects reserved/private IPs via `isReservedIP` and `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA). `ValidateURL` applies the same check when a webhook URL is configured.
