`*service` (`internal/markdown/markdown.go`) — `markdown.NewService` called from `NewAPIV1Service` (`server/router/api/v1/v1.go`); `server.NewServer` (`server/server.go`) reuses that instance for RSS — `APIV1Service`, `RSSService`, `memopayload.Runner`

The only runtime impl is the unexported `service` (tags + mentions enabled). Production construction is `markdown.NewService(WithTagExtension(), WithMentionExtension())` inside `NewAPIV1Service`; `server.go` then passes `apiV1Service.MarkdownService` into `rss.NewRSSService`. The interface is stored on `APIV1Service.MarkdownService`, `RSSService.MarkdownService`, and `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go`). `NewRunner` is not used in production; memo create/update calls `RebuildMemoPayload` with the API service’s instance.
