h02.
Post — `internal/webhook/webhook.go`; safeDialContext / isReservedIP — `internal/webhook/webhook.go` / `internal/webhook/validate.go`

Outbound HTTP delivery runs in `Post` (`internal/webhook/webhook.go`), which POSTs via `safeClient`. That client’s `DialContext` is `safeDialContext` in the same file: it resolves the host at dial time and rejects reserved/private IPs (SSRF / DNS rebinding). The check is `isReservedIP` in `internal/webhook/validate.go`, using `reservedCIDRs` (loopback, RFC-1918, link-local/IMDS, IPv6 ULA). `ValidateURL` in that same file applies the same rule when a webhook URL is created or updated.
