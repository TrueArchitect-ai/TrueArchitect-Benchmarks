There is no GraphQL schema. The public API is Protocol Buffers under `proto/api/v1/` (`*_service.proto` plus `common.proto`), served as Connect RPC / gRPC and REST via gRPC-Gateway (`google.api.http` annotations). Generated OpenAPI is `proto/gen/openapi.yaml` (embedded by `proto/openapi_embed.go`); handlers live in `server/router/api/v1/`.
