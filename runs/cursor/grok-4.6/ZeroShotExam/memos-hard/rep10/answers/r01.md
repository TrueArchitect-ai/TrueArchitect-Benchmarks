There is no Redis connection for the cache layer. Caching is an in-process in-memory map in `store/cache/cache.go`, wired in `store/store.go` (`New` builds `userCache` with `cache.Config{DefaultTTL: 10 * time.Minute, CleanupInterval: 5 * time.Minute, MaxItems: 1000}`). User writes go through `userCache.Set` in `store/user.go`, which uses that default TTL, so user entries expire after 10 minutes.
