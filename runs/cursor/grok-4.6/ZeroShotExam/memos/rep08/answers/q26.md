`memo`, `memo_relation`, `attachment`

`store.DeleteMemo` in `store/memo.go` deletes `memo_relation` rows (source and related), then linked `attachment` rows via `DeleteAttachment`, then the `memo` row. The API `DeleteMemo` in `server/router/api/v1/memo_service.go` uses that same path for comments and the memo itself. `memo_share` is not deleted in this code (only a schema `ON DELETE CASCADE`, and SQLite foreign keys are off).
