When a user is deleted, reactions are removed by explicit SQL issued from Go inside each driver’s `DeleteUser` transaction — not by a database-level cascade on the `reaction` table.

In `deleteUserTargetsTx`, the code does two things:

1. **`deleteReactionsByContentIDsTx`** — deletes reactions whose `content_id` matches deleted memos (`memos/{uid}`).
2. **`deleteReactionsByCreatorTx`** — deletes reactions where `creator_id` equals the deleted user (including reactions on other users’ memos).
