Other surfaces re-implement or filter by visibility independently:

- **HTTP file serving** — `checkAttachmentPermission` checks memo visibility (and share tokens) before serving attachment bytes (`server/router/fileserver/fileserver.go:649–703`).
- **gRPC attachment APIs** — `checkAttachmentAccess` in `attachment_service.go`; inline checks in `ListMemoAttachments`.
- **Reactions** — inline checks in `ListMemoReactions` and `UpsertMemoReaction`.

- **RSS / sitemap** — only `PUBLIC` memos (`rss.go:90`, `rss.go:141`; `frontend.go:150`).
- **SSE** — `canReceive` hides `PRIVATE` events from non-creators (`sse_hub.go:134–143`).
