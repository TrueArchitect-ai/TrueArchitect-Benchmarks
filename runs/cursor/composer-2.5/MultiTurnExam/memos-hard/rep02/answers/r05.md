**Premise correction:** There is no GraphQL schema for the public API. A repo-wide search finds no GraphQL files, gqlgen usage, or `.graphql` definitions.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, and related service protos). Services use `google.api.http` annotations for REST mapping:

```17:25:proto/api/v1/memo_service.proto
service MemoService {
  // CreateMemo creates a memo. ...
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
```

That schema is exposed at runtime through:

1. **gRPC-Gateway (REST/JSON)** — registered in `server/router/api/v1/v1.go` on `/api/v1/*` and `/file/*`
2. **Connect RPC** — registered in the same file on `/memos.api.v1.*`

An **OpenAPI** spec is generated and embedded as `proto/gen/openapi.yaml`, exposed via `proto/openapi_embed.go` (`OpenAPIYAML()`). The MCP server also builds tools from that OpenAPI surface (`server/router/mcp/catalog.go`).

So the contract is **Protobuf + generated OpenAPI**, not GraphQL.
