**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only shipped concrete protocol implementation is OAuth2 in `internal/idp/oauth2`. That package provides `IdentityProvider` with `ExchangeToken` and `UserInfo`, and is wired in at login time when the stored provider type is `OAUTH2`:

```1:2:internal/idp/oauth2/oauth2.go
// Package oauth2 implements the OAuth2 identity provider integration.
package oauth2
```

Under `internal/idp/`, only `idp.go` and the `oauth2/` subdirectory exist — no other protocol implementations ship in this repository.
