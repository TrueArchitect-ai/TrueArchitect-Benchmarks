Derived metadata lives in `MemoPayload` (```7:22:proto/store/memo.proto```), described there as calculated from memo content. It is rebuilt in:

```74:87:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	// ...
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	// ...
	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

The markdown pass is implemented in `ExtractAll` (```355:421:internal/markdown/markdown.go```), which walks the goldmark AST and collects:

- **Tags** — `#tag` nodes (via custom tag extension)
- **Property.title** — text of the first top-level H1 heading
- **Property.has_link** — any link node
- **Property.has_code** — code block / fenced block / inline code
- **Property.has_task_list** / **has_incomplete_tasks** — GFM task checkboxes

`RebuildMemoPayload` persists only `Tags` and `Property`; mentions are also parsed in `ExtractAll` but are not written into `memo.Payload` (they are used separately for notifications in `memo_mention_helpers.go`).

**Operations that trigger recomputation (production):**

1. **`CreateMemo`** — ```108:108:server/router/api/v1/memo_service.go``` before `Store.CreateMemo`
2. **`UpdateMemo`** — when `"content"` is in the update mask: ```436:451:server/router/api/v1/memo_service.go```
3. **`CreateMemoComment`** — indirectly, by calling `CreateMemo` (```56:59:server/router/api/v1/memo_service_comments.go```)

`memopayload.Runner.RunOnce` can batch-rebuild all memos (```27:71:server/runner/memopayload/runner.go```) but is not wired into server startup, so it is not a normal runtime trigger.

**Not content-derived:** `payload.location` is set from the API request in `CreateMemo` (```111:113:server/router/api/v1/memo_service.go```), not by `RebuildMemoPayload`.
