**Handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` (all in `server/router/api/v1/`); **convergence function:** `PostAsync` — `internal/webhook/webhook.go`

These RPC handlers can transitively trigger outbound HTTP to user-configured webhook URLs (`hook.Url` from user webhook settings):

| Handler | Path to webhook dispatch |
|---|---|
| `CreateMemo` | ```157:157:server/router/api/v1/memo_service.go``` → `DispatchMemoCreatedWebhook` |
| `UpdateMemo` | ```513:513:server/router/api/v1/memo_service.go``` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |
| `DeleteMemo` | ```562:562:server/router/api/v1/memo_service.go``` → `DispatchMemoDeletedWebhook` |
| `CreateMemoComment` | ```119:119:server/router/api/v1/memo_service_comments.go``` → `DispatchMemoCommentCreatedWebhook` |
| `SetMemoAttachments` | ```48:48:server/router/api/v1/memo_attachment_service.go``` → `dispatchMemoUpdatedSideEffects` |
| `SetMemoRelations` | ```48:48:server/router/api/v1/memo_relation_service.go``` → `dispatchMemoUpdatedSideEffects` |

Those dispatch helpers set `payload.URL = hook.Url` and call `webhook.PostAsync` in ```43:43:server/router/api/v1/memo_service_webhooks.go``` and ```71:71:server/router/api/v1/memo_service_webhooks.go```. Every webhook path converges on **`PostAsync`** in ```184:196:internal/webhook/webhook.go``` before delivery; background workers then call `Post`, which performs the HTTP POST via `safeClient.Do` at ```152:152:internal/webhook/webhook.go```.

Note: `GetLinkMetadata` / `BatchGetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go`) also fetch user-supplied URLs, but via `fetchHTMLMeta`, not the webhook pipeline. The single convergence point for user-configured **webhook** URLs is `PostAsync`.
