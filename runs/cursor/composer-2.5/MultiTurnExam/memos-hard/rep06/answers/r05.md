**Premise correction:** There is no GraphQL schema for the public API in this repository. Searches for GraphQL, `.graphql`/`.gql` files, and common GraphQL tooling return nothing.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, and related service protos). Those definitions are exposed over HTTP as:

- **gRPC-Gateway** (REST/JSON mapped from proto `google.api.http` annotations) — registered in ```64:65:server/router/api/v1/v1.go``` and wired at startup in ```88:88:server/server.go```
- **Connect RPC** handlers — in `server/router/api/v1/connect_handler.go` and `connect_services.go`

Additional non-gRPC HTTP routes include the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), SSE, and MCP — none of which use GraphQL.
