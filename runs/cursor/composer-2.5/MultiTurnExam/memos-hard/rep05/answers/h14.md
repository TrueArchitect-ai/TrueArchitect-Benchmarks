**computation site:** `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-87`) → `markdownService.ExtractAll` (`internal/markdown/markdown.go:356-421`); **triggers:** `CreateMemo` (`server/router/api/v1/memo_service.go:108`), `UpdateMemo` when `content` is in the update mask (`server/router/api/v1/memo_service.go:436-451`), and indirectly `CreateMemoComment` (calls `CreateMemo` internally); **extracted properties:** `#tags` → `MemoPayload.tags`; content-derived booleans/title → `MemoPayload.property` (`has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks`, `title` from first H1)

Derived metadata lives in `MemoPayload` (`proto/store/memo.proto:7-22`), persisted on the memo and exposed in API responses via `convertMemoFromStore` (`server/router/api/v1/memo_service_converter.go:47-50`).

**Computation flow**

1. `RebuildMemoPayload` calls `markdownService.ExtractAll([]byte(memo.Content))` and writes:
   - `memo.Payload.Tags = data.Tags`
   - `memo.Payload.Property = data.Property`  
   (`server/runner/memopayload/runner.go:80-86`)

2. `ExtractAll` parses markdown once and walks the AST to collect:
   - **Tags** — `#tag` nodes (`internal/markdown/markdown.go:376-378`)
   - **Property.title** — text of the first top-level H1 (`internal/markdown/markdown.go:383-388`)
   - **Property.has_link** — link nodes (`internal/markdown/markdown.go:393-394`)
   - **Property.has_code** — code blocks/spans (`internal/markdown/markdown.go:396-397`)
   - **Property.has_task_list** / **has_incomplete_tasks** — task checkboxes (`internal/markdown/markdown.go:399-405`)

   It also collects **mentions** (`internal/markdown/markdown.go:379-380`), but `RebuildMemoPayload` does not persist them; mentions are read on demand in `memo_mention_helpers.go:32`.

**What triggers recomputation**

| Operation | Path |
|---|---|
| **Create memo** | `CreateMemo` → `RebuildMemoPayload` before `Store.CreateMemo` (`memo_service.go:108-115`) |
| **Update memo content** | `UpdateMemo` when update mask includes `"content"` (`memo_service.go:436-451`) |
| **Create comment** | `CreateMemoComment` → internal `CreateMemo` → same rebuild path |

**Not content-derived:** `Payload.location` is set from the request on create (`memo_service.go:111-112`), not from markdown parsing.

**Note:** `memopayload.Runner.RunOnce` can batch-rebuild all memos (`server/runner/memopayload/runner.go:27-71`) but is not wired into server startup, so it does not run in normal operation. `GenerateSnippet` (`memo_service_webhooks.go:85`) builds preview text for webhooks at dispatch time and is not stored in `MemoPayload`.
