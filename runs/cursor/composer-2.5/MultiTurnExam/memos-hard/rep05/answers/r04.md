**Premise correction:** Webhook delivery does not use NATS or RabbitMQ (or any external message broker). A repo-wide search finds no references to those systems.

**Actual mechanism:** Delivery uses an in-process buffered Go channel and fixed worker pool in `internal/webhook/webhook.go`:

- **Queue:** `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`)
- **Workers:** four goroutines started in `init()` that read from that channel and call `Post(payload)` (`internal/webhook/webhook.go:42-54`)
- **Enqueue:** `PostAsync` sends payloads to the channel (or drops them if full) (`internal/webhook/webhook.go:184-195`)
- **HTTP delivery:** `Post` executes the outbound request via `safeClient.Do` (`internal/webhook/webhook.go:120-152`)

Callers such as `server/router/api/v1/memo_service_webhooks.go` enqueue via `webhook.PostAsync`; there is no external broker queue declaration.
