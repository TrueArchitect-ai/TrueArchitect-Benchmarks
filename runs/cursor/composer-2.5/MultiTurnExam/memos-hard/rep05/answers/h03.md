**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows (`internal/idp/idp.go`).

The only shipped concrete protocol implementation is OAuth2 in `internal/idp/oauth2`, whose `IdentityProvider` type implements token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`). It is wired into SSO auth handling via imports in `server/router/api/v1/auth_service_sso.go`. No other protocol packages exist under `internal/idp/`.
