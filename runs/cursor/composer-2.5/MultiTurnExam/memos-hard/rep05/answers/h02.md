**Post** — `internal/webhook/webhook.go`; **isReservedIP / reservedCIDRs SSRF checks** (also enforced at dial time by `safeDialContext`) — `internal/webhook/validate.go`

Outbound HTTP delivery runs in `webhook.Post`, which sends the request via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). Callers such as `dispatchMemoRelatedWebhook` only enqueue work with `webhook.PostAsync`; background workers in `init()` dequeue those payloads and call `Post` (`internal/webhook/webhook.go:42-54`).

Internal-address protection is implemented by resolving the target hostname and rejecting reserved/private IPs (`127.0.0.0/8`, RFC 1918 ranges, link-local/IMDS, and IPv6 equivalents) in `isReservedIP` using `reservedCIDRs` (`internal/webhook/validate.go:11-54`). That check runs when webhook URLs are validated at registration (`ValidateURL`, `internal/webhook/validate.go:56-83`) and again at delivery time in `safeDialContext` on the webhook HTTP transport (`internal/webhook/webhook.go:57-77`), which blocks DNS rebinding to internal addresses. It can be disabled with the `AllowPrivateIPs` flag (`internal/webhook/validate.go:38-41`, set from `--allow-private-webhooks` in `cmd/memos/main.go:49`).
