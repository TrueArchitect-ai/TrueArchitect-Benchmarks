**Premise correction:** There is no GraphQL schema for the public API in this repository (no `.graphql` files, GraphQL libraries, or schema definitions).

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, and related service protos). It is exposed over HTTP via:

- **gRPC-Gateway** — registered in `server/router/api/v1/v1.go` (`RegisterGateway`, routes under `/api/v1/*`)
- **Connect RPC** — registered in the same file (routes matching `/memos.api.v1.*`)

Generated artifacts live under `proto/gen/` (including `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`). Handlers are implemented on `APIV1Service` in `server/router/api/v1/`.
