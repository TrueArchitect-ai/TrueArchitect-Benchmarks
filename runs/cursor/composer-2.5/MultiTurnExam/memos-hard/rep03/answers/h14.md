**Extracted properties (persisted)**

From `ExtractAll`, stored in payload by `RebuildMemoPayload`:

- **Tags:** `#tag` tokens (`MemoPayload.tags`)
- **Property** (`MemoPayload.property`, per `proto/store/memo.proto`):
  - `title` — text of the first top-level H1
  - `has_link` — contains links
  - `has_code` — contains code blocks/spans
  - `has_task_list` — contains task-list checkboxes
  - `has_incomplete_tasks` — has unchecked tasks

These feed lists/previews via `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:47-49`) and user stats (`server/router/api/v1/user_service_stats.go`).

**Note:** `ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` does not persist them; mentions are read at notification time via a separate `ExtractAll` call in `memo_mention_helpers.go`.
