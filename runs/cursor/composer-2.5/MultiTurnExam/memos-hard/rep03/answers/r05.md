**Premise correction:** This repository does not define a GraphQL schema for the public API. Searches turn up no `.graphql`/`.gql` files, no GraphQL libraries in dependencies, and no GraphQL server code.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/common.proto`

Services declare RPCs with `google.api.http` annotations (REST paths like `/api/v1/memos`), as in `proto/api/v1/memo_service.proto`.

Code generation is configured in `proto/buf.gen.yaml` (`buf generate`), producing gRPC stubs, Connect handlers, gRPC-Gateway mappings, TypeScript types, and an OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).

The server exposes that API in `server/router/api/v1/v1.go`:

- **REST (gRPC-Gateway):** `/api/v1/*` and `/file/*`
- **Connect RPC:** `/memos.api.v1.*` for browser clients

Implementation lives in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`).

Related non-GraphQL endpoints include the native file server (`server/router/fileserver/`), RSS (`server/router/rss/`), SSE (`server/router/api/v1/sse_handler.go`), and an OpenAPI-driven MCP service (`server/router/mcp/service.go` using `proto/openapi_embed.go`).
