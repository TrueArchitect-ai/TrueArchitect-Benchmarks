**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

Persistent entity types live in the `store/` data layer (e.g. `User` in `store/user.go`, `Memo` in `store/memo.go`). To rank them, I counted distinct Go package directories **outside `store/`** that import `github.com/usememos/memos/store` and reference each type (e.g. `store.User`, `*store.Memo`).

**Top two**

| Rank | Type | Defined in | Approx. external packages |
|------|------|------------|---------------------------|
| 1st | `store.User` | `store/user.go` | **~7** |
| 2nd | `store.Memo` | `store/memo.go` | **~6** |

Excluding the dedicated test package `server/router/api/v1/test` drops the totals by about one each (~6 for `User`, ~5 for `Memo`).
