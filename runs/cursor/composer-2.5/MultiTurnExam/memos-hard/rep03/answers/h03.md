**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared user-info type used across SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only concrete protocol implementation in the repo is OAuth2 in `internal/idp/oauth2`. Its `IdentityProvider` type handles token exchange and user-info retrieval, returning `*idp.IdentityProviderUserInfo`:

```1:2:internal/idp/oauth2/oauth2.go
// Package oauth2 implements the OAuth2 identity provider integration.
package oauth2
```

That implementation is wired into SSO auth in `server/router/api/v1/auth_service_sso.go`, and the API/proto layer exposes only OAuth2 as a provider type (`OAUTH2 = 1` in `proto/api/v1/idp_service.proto`). No other protocol packages (OIDC, SAML, etc.) exist under `internal/idp/`.
