**Premise correction:** This repository does not schedule a nightly database-cleanup job in a cron scheduler.

`internal/scheduler/` is a cron scheduler library (see `internal/scheduler/scheduler.go`, `internal/scheduler/job.go`, `internal/scheduler/parser.go`), but it is not wired into the running server. The only imports are in `internal/scheduler/example_test.go` and `internal/scheduler/integration_test.go`; nothing under `server/` or `cmd/` creates or starts a `scheduler.Scheduler`.

The `"daily-cleanup"` job at `"0 2 * * *"` (2:00 AM) appears only as **documentation example code** in `internal/scheduler/doc.go`, not as a registered production job:

```14:20:internal/scheduler/doc.go
//	s.Register(&scheduler.Job{
//		Name:     "daily-cleanup",
//		Schedule: "0 2 * * *", // 2 AM daily
//		Handler: func(ctx context.Context) error {
//			// Your cleanup logic here
//			return nil
//		},
//	})
```

Production background work in `server/server.go` is limited to the S3 presign runner (`server/runner/s3presign/runner.go`), which uses a **12-hour ticker** (`runnerInterval = time.Hour * 12`), not cron and not database cleanup. There is no nightly DB cleanup job or schedule to report.
