**Premise correction:** This repository has no nightly database-cleanup job registered in the cron scheduler, so there is no scheduled run time for one.

The cron scheduler lives in `internal/scheduler/` (`scheduler.go`, `job.go`, `parser.go`) but is only used in tests and examples under that package (`example_test.go`, `integration_test.go`, `scheduler_test.go`). Nothing in `cmd/memos/main.go`, `server/server.go`, or elsewhere imports or starts it in production.

The only “daily-cleanup” reference is example documentation in `internal/scheduler/doc.go`, which shows a hypothetical job at `"0 2 * * *"` (2:00 AM daily). That is not registered or executed by the running server.

Background work that does run at startup includes the S3 presign runner in `server/server.go` (`s3presignRunner.RunOnce` / `Run`), which is unrelated to database cleanup and not cron-scheduled nightly.
