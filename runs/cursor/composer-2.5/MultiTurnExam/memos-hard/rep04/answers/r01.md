**Premise correction:** This repo does not configure a Redis connection for caching. A repo-wide search finds no Redis references.

**Actual mechanism:** The cache layer is an **in-process, in-memory TTL cache** in `store/cache/cache.go`. It is created in `store.New` (`store/store.go`) with `cache.New(cacheConfig)` — no external connection string or Redis client.

User entries live in `userCache` and are stored via `userCache.Set` in `store/user.go`, which uses the cache-wide default TTL of **10 minutes**:

```39:53:store/store.go
	cacheConfig := cache.Config{
		DefaultTTL:      10 * time.Minute,
		CleanupInterval: 5 * time.Minute,
		MaxItems:        1000,
		OnEviction:      nil,
	}
	// ...
		userCache:            cache.New(cacheConfig),
```

```92:95:store/cache/cache.go
func (c *Cache) Set(ctx context.Context, key string, value any) {
	c.SetWithTTL(ctx, key, value, c.config.DefaultTTL)
}
```

There is no user-specific TTL override; `SetWithTTL` is only used in tests (`store/cache/cache_test.go`), not for user cache entries in production code.
