**Premise correction:** There is no GraphQL schema for the public API. A repo-wide search finds no GraphQL, gqlgen, or `.graphql` files.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, and related files). Generated code lives in `proto/gen/api/v1/`.

It is exposed at runtime through:

1. **Connect RPC** — registered in `RegisterGateway` in `server/router/api/v1/v1.go`, with handlers in `server/router/api/v1/connect_services.go` on routes like `/memos.api.v1.*`.

2. **REST/JSON via gRPC-Gateway** — also wired in `RegisterGateway` (`server/router/api/v1/v1.go`), mapping HTTP paths such as `/api/v1/...` to the same protobuf services.

Startup registration is in `server/server.go`:

```87:89:server/server.go
	// Register gRPC gateway as api v1 (includes SSE endpoint on CORS-enabled group).
```

Additional non-GraphQL HTTP surfaces include the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), MCP (`server/router/mcp/`), and SSE — none use GraphQL.
