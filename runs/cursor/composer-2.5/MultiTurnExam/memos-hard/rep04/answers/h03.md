**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only concrete protocol implementation in the repo is OAuth2 in `internal/idp/oauth2`. Its `IdentityProvider` type implements token exchange and user-info retrieval, returning `*idp.IdentityProviderUserInfo`. SSO login in `server/router/api/v1/auth_service_sso.go` wires it up when the stored provider type is `IdentityProvider_OAUTH2`:

```119:134:server/router/api/v1/auth_service_sso.go
	var userInfo *idp.IdentityProviderUserInfo
	if identityProvider.Type == storepb.IdentityProvider_OAUTH2 {
		oauth2IdentityProvider, err := oauth2.NewIdentityProvider(identityProvider.Config.GetOauth2Config())
		if err != nil {
			return nil, nil, status.Errorf(codes.Internal, "failed to create oauth2 identity provider, error: %v", err)
		}
		// Pass code_verifier for PKCE support (empty string if not provided for backward compatibility)
		token, err := oauth2IdentityProvider.ExchangeToken(ctx, redirectURI, code, codeVerifier)
		if err != nil {
			return nil, nil, status.Errorf(codes.Internal, "failed to exchange token, error: %v", err)
		}
		userInfo, err = oauth2IdentityProvider.UserInfo(ctx, token)
		if err != nil {
			return nil, nil, status.Errorf(codes.Internal, "failed to get user info, error: %v", err)
		}
	}
```

No other protocol packages (e.g. SAML, OIDC-specific) exist under `internal/idp`.
