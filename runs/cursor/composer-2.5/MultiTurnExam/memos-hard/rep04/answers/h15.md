Memo visibility is not enforced in one place. The shared helper **`checkMemoReadAccess`** in `memo_service.go` gates single-memo reads (e.g. `GetMemo` at line 356). **List endpoints** apply visibility at query time in `ListMemos` (lines 218–226) and similar handlers. **Attachments** are gated separately in the gRPC **`checkAttachmentAccess`** path and the HTTP file server’s **`checkAttachmentPermission`**. **Live updates** use **`SSEClient.canReceive`** to filter events by visibility. **RSS** only loads public memos via `VisibilityList`. **Notifications/email** use **`canViewerAccessMemo`** so private/protected content is not exposed to the wrong recipient.
