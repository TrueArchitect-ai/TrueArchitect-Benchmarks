**Use in lists/previews**

Stored payload fields are exposed on API memos in `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:47-50`) as `Tags` and `Property`, and used for stats/filtering (e.g. `server/router/api/v1/user_service_stats.go`). **Snippets** for previews are computed at read time via `GenerateSnippet` (`memo_service_converter.go:76-80`), not stored in `payload`.
