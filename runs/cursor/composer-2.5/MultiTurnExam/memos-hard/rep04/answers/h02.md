h02.
**Post** — `internal/webhook/webhook.go`; **safeDialContext** (reserved/private IP SSRF guard via `isReservedIP`) — `internal/webhook/webhook.go`

Memo change handlers in `server/router/api/v1/memo_service_webhooks.go` enqueue work with `webhook.PostAsync`, and background workers in `internal/webhook/webhook.go` call **`Post`** to perform the actual HTTP POST via `safeClient.Do(req)`.

At dial time, **`safeDialContext`** resolves the target hostname and rejects any address in a reserved/private range using **`isReservedIP`** (defined in `internal/webhook/validate.go` against `reservedCIDRs`). That blocks connections to internal addresses even if DNS rebinding occurs after URL validation.

There is also a registration-time check: **`ValidateURL`** in `internal/webhook/validate.go` rejects webhook URLs that resolve to reserved/private IPs when webhooks are created or updated in `server/router/api/v1/user_service_webhooks.go`. Both checks honor the `AllowPrivateIPs` flag set from `--allow-private-webhooks` in `cmd/memos/main.go`.
