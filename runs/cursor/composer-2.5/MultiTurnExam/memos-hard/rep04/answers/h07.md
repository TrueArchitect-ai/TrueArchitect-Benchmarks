Browser loads another user's avatar when the profile API returns a URL like `/file/users/{username}/avatar` (set in `convertUserFromStore` when the stored value is a base64 data URI). The `<img>` request then follows this path to the `user.avatar_url` column:

RegisterRoutes — `server/router/fileserver/fileserver.go`
serveUserAvatar — `server/router/fileserver/fileserver.go`
getUserByUsername — `server/router/fileserver/fileserver.go`
GetUser — `store/user.go`
ListUsers — `store/user.go`
ListUsers — `store/db/sqlite/user.go`
parseDataURI — `server/router/fileserver/fileserver.go`

**Details:**

1. **Route** — `GET /file/users/:identifier/avatar` is registered in `RegisterRoutes`:

```121:125:server/router/fileserver/fileserver.go
func (s *FileServerService) RegisterRoutes(echoServer *echo.Echo) {
	fileGroup := echoServer.Group("/file")
	fileGroup.GET("/attachments/:uid/:filename", s.serveAttachmentFile)
	fileGroup.GET("/users/:identifier/avatar", s.serveUserAvatar)
}
```

2. **Handler** — `serveUserAvatar` resolves the username from `:identifier`, loads the user, reads `user.AvatarURL`, decodes the data URI, and returns the image bytes:

```183:209:server/router/fileserver/fileserver.go

```

3. **User lookup** — `getUserByUsername` calls the store layer:

```714:717:server/router/fileserver/fileserver.go

	return s.Store.GetUser(ctx, &store.FindUser{Username: &identifier})
}
```

5. **Driver / SQL** — `ListUsers` selects `avatar_url` from the `user` table (same pattern in `store/db/mysql/user.go` and `store/db/postgres/user.go`):

```151:165:store/db/sqlite/user.go
	query := `
		SELECT 
			id,
			username,

			email,
			nickname,
			password_hash,
			avatar_url,
			description,
			created_ts,
			updated_ts,
			row_status
		FROM user
		WHERE ` + strings.Join(where, " AND ") + ` ORDER BY ` + strings.Join(orderBy, ", ")
```

6. **Stored data** — Avatars uploaded as images are stored as base64 data URIs in `user.avatar_url` (`store/migration/sqlite/LATEST.sql`). `parseDataURI` decodes that string into raw image bytes for the HTTP response.

**Note:** If `avatar_url` is an external URL (not a data URI), `convertUserFromStore` in `server/router/api/v1/user_service_converters.go` returns it unchanged and the browser loads it directly, bypassing `serveUserAvatar`.
