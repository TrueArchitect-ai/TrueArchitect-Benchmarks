The factory is `NewDBDriver` in `store/db/db.go`, which selects the MySQL driver with `mysql.NewDB(profile)`:

```13:31:store/db/db.go
// NewDBDriver creates new db driver based on profile.
func NewDBDriver(profile *profile.Profile) (store.Driver, error) {
	var driver store.Driver
	var err error

	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
	case "postgres":
		driver, err = postgres.NewDB(profile)
	default:
		return nil, errors.New("unknown db driver")
	}
	// ...
}
```

A repo-wide search for `mysql.NewDB` and `store/db/mysql` finds those references only in `store/db/db.go`. Callers always go through the factory, including:

- `cmd/memos/main.go` — `db.NewDBDriver(instanceProfile)`
- `store/test/store.go` — `db.NewDBDriver(profile)` in both `NewTestingStore` and `NewTestingStoreWithDSN`

There are no other imports of `store/db/mysql` and no direct uses of `mysql.DB` outside that package.

Note: `store/test/containers.go` does call `sql.Open("mysql", dsn)` for test-container database setup, but that opens a raw `database/sql` connection for provisioning test databases; it does not construct the Memos `store/db/mysql` driver type.
