**Premise correction:** There is no GraphQL schema for the public API. A repo-wide search finds no GraphQL, gqlgen, or `.graphql`/`.gql` files.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared types in `common.proto`). Buf config is in `proto/buf.yaml`.

Those `.proto` files drive:

1. **HTTP JSON (gRPC-Gateway)** — routes like `/api/v1/memos` from `google.api.http` annotations in the protos; registered in `server/router/api/v1/v1.go` via `Register*ServiceHandlerServer` and mounted at `/api/v1/*` and `/file/*`.
2. **Connect RPC** — handlers registered in the same file at `/memos.api.v1.*` (see `connect_handler.go` / `RegisterConnectHandlers`).
3. **OpenAPI spec** — generated as `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` (`OpenAPIYAML()`). Used by the MCP layer in `server/router/mcp/service.go`.

Example of how HTTP paths are declared in proto:

```17:30:proto/api/v1/memo_service.proto
service MemoService {
  // CreateMemo creates a memo. The request body is a Memo; set its content
  // (Markdown) and visibility (PRIVATE | PROTECTED | PUBLIC, default PRIVATE).
  // The memo is owned by the authenticated user; requires authentication.
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
    option (google.api.method_signature) = "memo";
  }
  // ListMemos lists memos with pagination and filter.
  rpc ListMemos(ListMemosRequest) returns (ListMemosResponse) {
    option (google.api.http) = {get: "/api/v1/memos"};
```

So the API contract lives in **`proto/api/v1/*.proto`**, not in a GraphQL schema.
