The factory is `NewDBDriver` in `store/db/db.go`, which selects the backend and constructs the MySQL store driver:

```18:22:store/db/db.go
	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
```

A repo-wide search shows `mysql.NewDB` appears only at that call site, and `github.com/usememos/memos/store/db/mysql` is imported only in `store/db/db.go`. Every other construction path uses the factory:

- `cmd/memos/main.go` — `db.NewDBDriver(instanceProfile)`
- `store/test/store.go` — `db.NewDBDriver(profile)` (lines 28 and 50)
- `server/router/api/v1/test/memo_service_benchmark_test.go` — `db.NewDBDriver(testProfile)`

`store/test/containers.go` does call `sql.Open("mysql", dsn)` (line 145), but that opens a raw `database/sql` connection for testcontainer database setup; it does not construct the Memos store driver (`store/db/mysql.DB` via `mysql.NewDB`).
