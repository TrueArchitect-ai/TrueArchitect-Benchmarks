Memo visibility is enforced in multiple server surfaces. Distinct enforcement sites:

**checkMemoReadAccess** — `server/router/api/v1/memo_service.go` (used by `GetMemo`, `ListMemoComments`)

**ListMemos visibility filtering** — `server/router/api/v1/memo_service.go` (`VisibilityList` / CEL filter in `ListMemos`)

**checkAttachmentAccess** — `server/router/api/v1/attachment_service.go` (attachment RPCs, e.g. `GetAttachment`)

**ListMemoAttachments visibility check** — `server/router/api/v1/memo_attachment_service.go`

**Reaction RPC visibility checks** — `server/router/api/v1/reaction_service.go` (`ListMemoReactions`, `UpsertMemoReaction`, `DeleteMemoReaction`)

**CreateMemoComment visibility check** — `server/router/api/v1/memo_service_comments.go`

**ListMemoRelations memoFilter** — `server/router/api/v1/memo_relation_service.go` (filters related memos by visibility)

**checkAttachmentPermission** — `server/router/fileserver/fileserver.go` (HTTP `/file/attachments/...`)

**SSEClient.canReceive** — `server/router/api/v1/sse_hub.go` (live event delivery)

**RSS VisibilityList (public only)** — `server/router/rss/rss.go` (`GetExploreRSS`, `GetUserRSS`)

**Frontend sitemap VisibilityList (public only)** — `server/router/frontend/frontend.go` (`getSitemapXML`)

**User stats visibility filtering** — `server/router/api/v1/user_service_stats.go` (`ListAllUserStats`, `GetUserStats`)

Shared pattern: **PUBLIC** is open (with instance anonymous-access rules on file serving); **PROTECTED** requires authentication; **PRIVATE** is limited to the creator (admins where noted). List/stats/RSS/sitemap enforce at query time; RPC handlers and the file server enforce per request.
