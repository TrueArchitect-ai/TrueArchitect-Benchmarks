**Premise correction:** This repository does not register a nightly database-cleanup job in the cron scheduler for production. `internal/scheduler` is a standalone cron library (see `internal/scheduler/scheduler.go`, `internal/scheduler/job.go`), but nothing under `cmd/` or `server/` imports it or calls `scheduler.New()`, `Register()`, or `Start()`. Scheduler usage appears only in tests and docs (`internal/scheduler/*_test.go`, `internal/scheduler/example_test.go`).

The only “daily-cleanup” entry is example/documentation code, not a database job:

```33:39:internal/scheduler/README.md
    s.Register(&scheduler.Job{
        Name:     "daily-cleanup",
        Schedule: "0 2 * * *", // 2 AM daily
        Handler: func(ctx context.Context) error {
            fmt.Println("Running cleanup...")
            return nil
        },
```

That example runs at **02:00** in the scheduler’s default timezone (UTC per `internal/scheduler/doc.go`), but it is illustrative only — there is no wired nightly database cleanup.

**Actual background scheduling:** The server starts background runners in `server/server.go` (`startBackgroundRunners`), currently the S3 presign runner on a **12-hour ticker** (`server/runner/s3presign/runner.go`, `runnerInterval = time.Hour * 12`), not a cron-based database cleanup.

So there is no answer for “when the nightly database-cleanup job runs” — that job is not implemented or scheduled in this codebase.
