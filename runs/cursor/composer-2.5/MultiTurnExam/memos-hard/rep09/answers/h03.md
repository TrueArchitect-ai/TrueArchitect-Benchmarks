**internal/idp; internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used by SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only shipped concrete protocol implementation is OAuth2 in `internal/idp/oauth2`. Its `IdentityProvider` type handles token exchange and userinfo fetching, returning `*idp.IdentityProviderUserInfo`:

```1:2:internal/idp/oauth2/oauth2.go
// Package oauth2 implements the OAuth2 identity provider integration.
package oauth2
```

That matches the store model: `proto/store/idp.proto` defines only one provider type (`OAUTH2 = 1`), and `server/router/api/v1/auth_service_sso.go` instantiates `oauth2.NewIdentityProvider(...)` when resolving SSO identity. No other protocol packages exist under `internal/idp/`.
