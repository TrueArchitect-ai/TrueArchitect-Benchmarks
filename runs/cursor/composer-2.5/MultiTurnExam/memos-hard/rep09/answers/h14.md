**Computation site**

`RebuildMemoPayload` calls `ExtractAll` and writes into the memo payload:

```74:87:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	// ...
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	// ...
	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

`ExtractAll` parses markdown once and walks the AST (`internal/markdown/markdown.go:356-421`).

`memopayload.Runner.RunOnce` also rebuilds all memos in batches (`server/runner/memopayload/runner.go:27-71`), but it is not started from `server/server.go`, so it is not part of normal runtime.

Updates to visibility, location, attachments, etc. do not re-run `RebuildMemoPayload` unless `content` changes.

**Extracted properties**

From `ExtractAll` (`internal/markdown/markdown.go`), persisted via `RebuildMemoPayload`:

- **`payload.tags`** — `#tag` tokens (custom tag extension; deduplicated)
- **`payload.property`** (`proto/store/memo.proto:15-22`):
  - `has_link` — any link node
  - `has_code` — code block, fenced block, or inline code
  - `has_task_list` — task checkbox nodes
  - `has_incomplete_tasks` — unchecked task checkbox
  - `title` — text of the first top-level H1 heading

`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` does not store them in the payload; mentions are used at notification time via `resolveMentionTargets` (`server/router/api/v1/memo_mention_helpers.go:32`).
