**Premise correction:** Webhook delivery workers do not consume from NATS or RabbitMQ. A repo-wide search finds no references to either broker in Go code.

**Actual mechanism:** Delivery uses an in-process buffered Go channel, `asyncPostQueue`, declared in `internal/webhook/webhook.go:39` as `make(chan *WebhookRequestPayload, 128)`. Four worker goroutines are started in `init()` (`internal/webhook/webhook.go:42-54`) and read from that channel, calling `Post` for each payload. Producers enqueue via `PostAsync` (`internal/webhook/webhook.go:184-196`), called from memo webhook handlers such as `server/router/api/v1/memo_service_webhooks.go:43` and `:71`. HTTP is sent by `Post` via `safeClient.Do` (`internal/webhook/webhook.go:152`).
