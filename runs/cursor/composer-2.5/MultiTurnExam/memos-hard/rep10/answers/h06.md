**handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`; **convergence function:** `PostAsync` — `internal/webhook/webhook.go`

User-configured webhook URLs are stored per user (`server/router/api/v1/user_service_webhooks.go`) and sent only through the memo webhook dispatch path. These RPC handlers can reach that path transitively:

| Handler | Path |
|---|---|
| `CreateMemo` | `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service.go:157`) → `dispatchMemoRelatedWebhook` |
| `UpdateMemo` | `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_service.go:513`) → `DispatchMemoUpdatedWebhook` |
| `DeleteMemo` | `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service.go:562`) |
| `CreateMemoComment` | `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_comments.go:119`); also calls `CreateMemo` (`:56`), which can fire `memos.memo.created` to the comment author’s webhooks |
| `SetMemoAttachments` | `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_attachment_service.go:48`) |
| `SetMemoRelations` | `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_relation_service.go:48`) |

All of those eventually call `webhook.PostAsync` — from `dispatchMemoRelatedWebhook` at `server/router/api/v1/memo_service_webhooks.go:71` and from `DispatchMemoCommentCreatedWebhook` at `:43`. That is the single convergence point before outbound HTTP: workers in `internal/webhook/webhook.go:42-54` dequeue and call `Post` (`:120`), which performs `safeClient.Do(req)` (`:152`) to the user-configured URL.

No other non-test call sites invoke `PostAsync` or `Post` (repo-wide grep). Webhook URL validation at create/update time is separate (`internal/webhook/validate.go`); it does not send HTTP.
