**Post — internal/webhook/webhook.go; safeDialContext — internal/webhook/webhook.go**

Outbound HTTP delivery runs in `Post` (`internal/webhook/webhook.go`), which issues the POST via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). Callers enqueue work with `PostAsync` (e.g. `server/router/api/v1/memo_service_webhooks.go:71`); background workers in `init()` drain that queue and call `Post` (`internal/webhook/webhook.go:42-54`).

Protection against internal/reserved addresses is enforced at connection time by `safeDialContext`, wired into `safeClient`’s `http.Transport` (`internal/webhook/webhook.go:32-36`, `57-77`). It resolves the target host and rejects any IP in reserved/private ranges via `isReservedIP` (`internal/webhook/validate.go:43-54`), which checks against `reservedCIDRs` (`internal/webhook/validate.go:14-23`). URLs are also validated at create/update time with `ValidateURL` (`internal/webhook/validate.go:56-83`), and that check can be bypassed with the `allow-private-webhooks` flag (`internal/webhook/validate.go:38-41`, set in `cmd/memos/main.go:49`).
