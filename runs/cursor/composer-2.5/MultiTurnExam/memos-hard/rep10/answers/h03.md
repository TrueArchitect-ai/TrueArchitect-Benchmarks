**internal/idp; internal/idp/oauth2**

The shared IdP layer lives in `internal/idp`, which defines the common user-info type `IdentityProviderUserInfo` (`internal/idp/idp.go`). SSO code uses that type when resolving and linking users (`server/router/api/v1/auth_service_sso.go`).

The only shipped protocol implementation is OAuth2 in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), with `IdentityProvider` providing `ExchangeToken` and `UserInfo`. It is wired when `identityProvider.Type == storepb.IdentityProvider_OAUTH2` (`server/router/api/v1/auth_service_sso.go:120-133`). The store proto only defines `OAUTH2` as an IdP type (`proto/store/idp.proto`), and no other IdP packages exist under `internal/idp/`.
