Derived metadata lives in `MemoPayload` on each memo. `RebuildMemoPayload` parses markdown once via `ExtractAll` and writes only `Tags` and `Property` into the memo before persistence.

`payload.location` is not content-derived; it is set explicitly on create/update (`server/router/api/v1/memo_service.go:111-112`, `:481-484`).

`ExtractAll` also collects `@mentions` (`internal/markdown/markdown.go:379-381`), but `RebuildMemoPayload` does not store them on the payload. Mentions are resolved at notification time via a separate `ExtractAll` call in `resolveMentionTargets` (`server/router/api/v1/memo_mention_helpers.go:32`).
