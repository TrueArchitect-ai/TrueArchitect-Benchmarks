**Why sqlite runs (not mysql/postgres)**

- Default driver is `"sqlite"`: `viper.SetDefault("driver", "sqlite")` and the `--driver` flag default in `cmd/memos/main.go:122-130`.
- With no `--driver` / `MEMOS_DRIVER`, that default is used.
- `db.NewDBDriver` switches on `profile.Driver` and picks `sqlite.NewDB` for `"sqlite"` (`store/db/db.go:18-20`); `mysql` and `postgres` branches are the other candidates (`store/db/db.go:21-24`).
- Startup wires this via `db.NewDBDriver(instanceProfile)` in `cmd/memos/main.go:57`.
