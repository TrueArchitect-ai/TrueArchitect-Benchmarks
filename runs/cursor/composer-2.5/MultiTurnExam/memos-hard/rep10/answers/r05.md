**Premise correction:** There is no GraphQL schema for the public API. Searches for `graphql`, `GraphQL`, `gqlgen`, and `.graphql`/`.gql` files return nothing in this repository.

**Actual API surface:** The public API is defined in Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, and the other `*_service.proto` files in that directory). Generated code lives under `proto/gen/api/v1/`.

It is exposed over HTTP as:

- **REST/JSON** via gRPC-Gateway — handlers registered in `server/router/api/v1/v1.go` (`RegisterGateway`, e.g. `:99-113`), wired at startup in `server/server.go:88`
- **Connect RPC** — registered in the same `RegisterGateway` flow in `server/router/api/v1/v1.go`

Public vs authenticated routes are configured in `server/router/api/v1/acl_config.go`, not in a GraphQL layer.
