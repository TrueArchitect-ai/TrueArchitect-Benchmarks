**Premise correction:** This repository does not configure a Redis connection for caching. A repo-wide search finds no Redis references in Go or config files.

**Actual mechanism:** Caching is in-process memory via `store/cache.Cache` (`store/cache/cache.go`). It is wired in `store.New` (`store/store.go:38-53`), which creates `userCache` with shared `cache.Config{DefaultTTL: 10 * time.Minute, ...}`. User entries are stored with `s.userCache.Set(...)` in `store/user.go` (e.g. `:98`, `:167`), and `Set` applies `DefaultTTL` (`store/cache/cache.go:92-94`). So user cache TTL is **10 minutes**, with cleanup every **5 minutes** (`store/store.go:41-42`, `store/cache/cache.go:46-47`).
