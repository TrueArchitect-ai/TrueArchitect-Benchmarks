**internal/idp**; **internal/idp/oauth2**

The abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only concrete protocol implementation in the repo is OAuth2 in `internal/idp/oauth2`. Its `IdentityProvider` type handles token exchange and user-info retrieval, returning `*idp.IdentityProviderUserInfo`:

```1:2:internal/idp/oauth2/oauth2.go
// Package oauth2 implements the OAuth2 identity provider integration.
package oauth2
```

It is wired into SSO auth in `server/router/api/v1/auth_service_sso.go` via `oauth2.NewIdentityProvider(...)`. The protos (`proto/api/v1/idp_service.proto`, `proto/store/idp.proto`) also define only an `OAuth2Config` variant — no other IDP protocol packages exist under `internal/idp/`.
