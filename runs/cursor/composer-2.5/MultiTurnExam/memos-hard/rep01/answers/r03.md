**Premise correction:** There is no nightly database-cleanup job scheduled in this repository, and the cron scheduler is not wired into the running server.

`internal/scheduler/` is a standalone cron library (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`). It is only referenced in its own package docs and examples (`internal/scheduler/doc.go`, `internal/scheduler/README.md`), which show a hypothetical `"daily-cleanup"` job at `"0 2 * * *"` (2:00 AM) as sample code. Nothing in `cmd/` or `server/` imports or starts that scheduler.

Production background work in `server/server.go` starts only the S3 presign runner (`server/runner/s3presign/runner.go`), on a 12-hour ticker (`runnerInterval = time.Hour * 12`), not a nightly cron database cleanup.

So there is no scheduled time for a nightly database-cleanup job to report.
