**Premise correction:** There is no GraphQL schema for the public API. A repository-wide search finds no `.graphql`/`.gql` files, no GraphQL libraries, and no GraphQL server or handler code.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared types in `common.proto`). Code generation is configured in `proto/buf.gen.yaml`.

From those protos, the repo generates:

- **gRPC / Connect** stubs in `proto/gen/api/v1/`
- **OpenAPI** at `proto/gen/openapi.yaml` (via the gnostic-openapi plugin in `proto/buf.gen.yaml`)

HTTP exposure is wired in `server/router/api/v1/v1.go`:

- **gRPC-Gateway (REST/JSON):** `/api/v1/*` and `/file/*`
- **Connect RPC:** `/memos.api.v1.*`

Additional non-GraphQL surfaces include MCP (`server/router/mcp/service.go`, driven by `proto/gen/openapi.yaml`), RSS (`server/router/rss/`), and the file server (`server/router/fileserver/`).
