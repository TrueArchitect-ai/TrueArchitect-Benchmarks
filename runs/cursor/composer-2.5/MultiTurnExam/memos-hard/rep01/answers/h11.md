**h11.**  
**1st: `User` (~5–6 packages); 2nd: `Memo` (~4 packages)**

Persistent entity types live in the root `store/` package (e.g. `User` in `store/user.go`, `Memo` in `store/memo.go`, plus `Attachment`, `Reaction`, `Inbox`, etc.). I counted distinct Go package directories outside `store/` that reference each type as `store.TypeName` in non-test production code (unless noted).

**1st: `store.User` — ~5–6 packages**

| Package | Example files |
|---|---|
| `server/auth` | `server/auth/authenticator.go`, `server/auth/context.go` |
| `server/notification` | `server/notification/email.go` |
| `server/router/api/v1` | `server/router/api/v1/user_service.go`, `server/router/api/v1/auth_service.go`, … |
| `server/router/fileserver` | `server/router/fileserver/fileserver.go` |
| `server/router/rss` | `server/router/rss/rss.go` |
| `server/router/api/v1/test` *(optional)* | `server/router/api/v1/test/test_helper.go` |

That is **5** production packages, **6** if test packages count.

**2nd: `store.Memo` — ~4 packages**

No references to `store.User` or `store.Memo` turned up under `cmd/` or `internal/`; usage is concentrated in `server/` packages above.
