Derived metadata lives in the memo’s stored `Payload` (`store/memo.go`, serialized in the DB `payload` column). The content-derived parts are `Tags` and `Property` — not `Location`, which is set explicitly from the API request (`memo_service.go:111-112`).

**Computation chain**

```74:87:server/runner/memopayload/runner.go
func RebuildMemoPayload(_ context.Context, memo *store.Memo, markdownService markdown.Service) error {
	// ...
	data, err := markdownService.ExtractAll([]byte(memo.Content))
	// ...
	memo.Payload.Tags = data.Tags
	memo.Payload.Property = data.Property
	return nil
}
```

`ExtractAll` parses markdown once and walks the AST (`internal/markdown/markdown.go:355-421`):

- **Tags:** `#tag` nodes → `Payload.Tags`
- **Property:**
  - `has_link` — any link node
  - `has_code` — code block, fenced code block, or inline code
  - `has_task_list` / `has_incomplete_tasks` — GFM task checkboxes
  - `title` — text of the first top-level H1 heading

(`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` does not persist them into `Payload`.)
