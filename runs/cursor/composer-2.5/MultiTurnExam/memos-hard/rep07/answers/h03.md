**internal/idp**; **internal/idp/oauth2**

The shared provider abstraction lives in `internal/idp`, which defines `IdentityProviderUserInfo` in `internal/idp/idp.go`. Concrete protocol implementations return that type (for example, `UserInfo` in `internal/idp/oauth2/oauth2.go` returns `*idp.IdentityProviderUserInfo`).

The only shipped concrete implementation is **OAuth2** in `internal/idp/oauth2`, with `IdentityProvider` providing `ExchangeToken` and `UserInfo`. SSO wiring uses it when the stored provider type is `OAUTH2` (`proto/store/idp.proto:11-14`), via `oauth2.NewIdentityProvider(...)` in `server/router/api/v1/auth_service_sso.go:120-133`. No other protocol packages exist under `internal/idp/`.
