**Handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` (all on `APIV1Service` in `server/router/api/v1/`)

**Convergence function:** `PostAsync` — `internal/webhook/webhook.go`

These RPC handlers can transitively trigger outbound HTTP to user-configured webhook URLs:

| Handler | File | Webhook trigger |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go:157` | `DispatchMemoCreatedWebhook` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go:513` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go:562` | `DispatchMemoDeletedWebhook` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go:119` | `DispatchMemoCommentCreatedWebhook` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go:48` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go:48` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |

All of those dispatch paths call `webhook.PostAsync(payload)` in `server/router/api/v1/memo_service_webhooks.go:43,71`. That is the single convergence point before delivery: it enqueues the payload for background workers, which then call `Post` (`internal/webhook/webhook.go:46,119`) to perform the HTTP POST via `safeClient.Do`.
