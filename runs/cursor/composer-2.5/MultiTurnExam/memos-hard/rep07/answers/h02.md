**Post** — `internal/webhook/webhook.go`; **safeDialContext** (via `safeClient`’s `http.Transport`) — `internal/webhook/webhook.go`

Outbound delivery is triggered from `server/router/api/v1/memo_service_webhooks.go`, which enqueues payloads with `webhook.PostAsync()`. Workers started in `init()` drain that queue and call **`Post`**, which performs the HTTP POST via `safeClient.Do(req)` (`internal/webhook/webhook.go:119-152`).

SSRF protection at delivery time is **`safeDialContext`**: it resolves the target hostname and rejects any address in a reserved/private range via **`isReservedIP`**, using the blocklist in `internal/webhook/validate.go` (`reservedCIDRs`). URLs are also checked at create/update time by **`ValidateURL`** in the same file. That protection can be disabled with **`AllowPrivateIPs`** (wired from `--allow-private-webhooks` in `cmd/memos/main.go:49`).
