**Premise correction:** This repository does not implement or register per-user API rate-limiting middleware. Searches for `rate limit`, `ratelimit`, `throttle`, and related terms across the codebase return no matches.

What is registered instead:

- **Echo global middleware:** `middleware.Recover()` and CORS (`server/server.go:51-52`, `server/cors.go:13-14`)
- **Frontend:** static file and SPA fallback middleware (`server/router/frontend/frontend.go:54-59`)
- **API auth (not rate limiting):** gRPC-Gateway auth middleware and Connect interceptors for metadata, logging, and authorization (`server/router/api/v1/v1.go:69-97`, `server/router/api/v1/connect_interceptors.go`, `server/router/api/v1/authz.go`)

There are other limits (e.g. `maxAPIRequestBytes` at `server/router/api/v1/v1.go:20`, content-length checks, thumbnail semaphores), but no per-user request-rate middleware or configured request limits for that purpose.
