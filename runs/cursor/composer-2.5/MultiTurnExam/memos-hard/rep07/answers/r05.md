**Premise correction:** There is no GraphQL schema for the public API in this repository. Searches for GraphQL, `.graphql` files, and common GraphQL tooling return no matches.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`). It is exposed via:

- **Connect RPC** handlers registered at `/memos.api.v1.*` (`server/router/api/v1/v1.go:131-144`, `server/router/api/v1/connect_handler.go`)
- **gRPC-Gateway** for HTTP/JSON mapping (`server/router/api/v1/v1.go:64-97`)
- A generated **OpenAPI** spec embedded from `proto/gen/openapi.yaml` (`proto/openapi_embed.go:5-10`), used by the MCP layer (`server/router/mcp/`)

Additional non-gRPC HTTP routes (file serving, RSS, SSE) exist alongside this, but none use GraphQL.
