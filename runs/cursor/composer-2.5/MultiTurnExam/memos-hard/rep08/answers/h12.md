### How I ruled out the other candidates

There are three driver-level `CreateMemo` implementations, each with its own `INSERT INTO memo`:

| Candidate | Path |
|---|---|
| SQLite | `store/db/sqlite/memo.go` |
| MySQL | `store/db/mysql/memo.go` |
| Postgres | `store/db/postgres/memo.go` |

All implement `store.Driver.CreateMemo` (`store/driver.go:29`). At runtime only one driver instance is created via `db.NewDBDriver` based on `profile.Driver`.

With no database flags, `driver` stays `"sqlite"` (Viper default + flag default in `cmd/memos/main.go`). `profile.Validate()` then sets a SQLite file DSN when `DSN` is empty (`internal/profile/profile.go:110-116`). So `mysql.NewDB` and `postgres.NewDB` are never called, and their `CreateMemo` methods never run on a default install.
