**Premise correction:** This repository does not register per-user API rate-limiting middleware. There is no Echo rate-limiter, token-bucket, or per-user request quota middleware in the server stack.

**What is actually registered:** Global Echo middleware in `server/server.go` is only `middleware.Recover()` and `newCORSMiddleware` from `server/cors.go`. API traffic is wired in `server/router/api/v1/v1.go` with:

- **`gatewayAuthMiddleware`** — authentication and anonymous-access checks via `Authorizer` (not rate limiting)
- **`http.MaxBytesHandler(..., maxAPIRequestBytes)`** — a **256 MiB** request body cap (`maxAPIRequestBytes = 256 << 20`), not a per-user request rate
- **Connect interceptors** in `server/router/api/v1/connect_interceptors.go`: `MetadataInterceptor`, `LoggingInterceptor`, `RecoveryInterceptor`, `AuthInterceptor` — again, no rate limiting
