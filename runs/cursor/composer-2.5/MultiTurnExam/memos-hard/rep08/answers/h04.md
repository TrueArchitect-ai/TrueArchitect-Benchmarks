**no**; **`mysql.NewDB` is only invoked from the driver-selection factory** in `store/db/db.go`, and **`store/db/mysql` is only imported there**.

The factory is `NewDBDriver` in `store/db/db.go`, which is the sole caller of `mysql.NewDB`:

```18:24:store/db/db.go
	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
	case "postgres":
		driver, err = postgres.NewDB(profile)
```

A repo-wide search shows only that one `mysql.NewDB(...)` call, and only `store/db/db.go` imports `github.com/usememos/memos/store/db/mysql`.

All production and test store setup goes through the factory via `db.NewDBDriver(...)`, including:
- `cmd/memos/main.go`
- `store/test/store.go`
- `server/router/api/v1/test/memo_service_benchmark_test.go`

**Note:** `store/test/containers.go` does call `sql.Open("mysql", dsn)` (lines 145 and 176) for test-container setup (waiting for MySQL and creating per-test databases). That opens a raw `database/sql` connection to the go-sql-driver MySQL driver; it does **not** construct the Memos store MySQL driver (`store/db/mysql.NewDB`).
