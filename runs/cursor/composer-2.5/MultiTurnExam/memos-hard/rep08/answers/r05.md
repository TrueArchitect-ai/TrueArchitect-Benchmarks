**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no `.graphql`/`.gql` files and no GraphQL server, client, or code-generation tooling anywhere in the repo.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/`, with eight service files plus shared types in `common.proto`:

- `proto/api/v1/auth_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`

Each service declares RPCs with HTTP mappings via `google.api.http` annotations (REST paths like `/api/v1/memos`), as in `proto/api/v1/memo_service.proto`:

```17:26:proto/api/v1/memo_service.proto
service MemoService {
  // CreateMemo creates a memo. The request body is a Memo; set its content
  // (Markdown) and visibility (PRIVATE | PROTECTED | PUBLIC, default PRIVATE).
  // The memo is owned by the authenticated user; requires authentication.
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
```

Those protos are generated with Buf (`proto/README.md`, `proto/buf.gen.yaml`) into Go stubs under `proto/gen/api/v1/`. The server exposes them in `server/router/api/v1/v1.go` via:

1. **gRPC-Gateway REST** at `/api/v1/*` and `/file/*`
2. **Connect RPC** at `/memos.api.v1.*`

An **OpenAPI** spec is also generated and embedded as `proto/gen/openapi.yaml`, exposed through `proto/openapi_embed.go` (used by the MCP layer in `server/router/mcp/`). That is the machine-readable API contract here — not GraphQL.
