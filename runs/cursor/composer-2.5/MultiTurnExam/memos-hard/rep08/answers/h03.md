**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows:

```1:8:internal/idp/idp.go
package idp

type IdentityProviderUserInfo struct {
	Identifier  string
	DisplayName string
	Email       string
	AvatarURL   string
}
```

The only concrete protocol implementation shipped is OAuth2 in `internal/idp/oauth2`. Its `IdentityProvider` type implements token exchange and user-info retrieval, returning `*idp.IdentityProviderUserInfo`:

```1:2:internal/idp/oauth2/oauth2.go
// Package oauth2 implements the OAuth2 identity provider integration.
package oauth2
```

That matches the proto enum, which defines only `OAUTH2` as a provider type (`proto/store/idp.proto`), and the SSO auth path in `server/router/api/v1/auth_service_sso.go`, which instantiates `oauth2.NewIdentityProvider` when `identityProvider.Type == storepb.IdentityProvider_OAUTH2`.
