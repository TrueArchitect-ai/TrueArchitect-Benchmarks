### Extracted properties

From `proto/store/memo.proto` and `ExtractAll`:

| Stored field | Extracted from content |
|---|---|
| `payload.tags` | `#tag` tokens (deduplicated, case preserved) |
| `payload.property.has_link` | Any link node |
| `payload.property.has_code` | Code block, fenced code block, or inline code |
| `payload.property.has_task_list` | GFM task checkbox |
| `payload.property.has_incomplete_tasks` | Unchecked task checkbox |
| `payload.property.title` | Text of the first top-level H1 heading |

These support list filtering (tags/properties in the filter engine) and previews (e.g. title, snippet generation uses separate `GenerateSnippet` in webhooks, not payload rebuild).
