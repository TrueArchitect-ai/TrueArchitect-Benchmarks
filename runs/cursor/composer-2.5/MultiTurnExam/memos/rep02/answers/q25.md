**Details**

- **Syntax:** CEL filter expressions (documented on shortcuts as reusable CEL filters in `proto/api/v1/shortcut_service.proto`).
- **Engine location:** `internal/filter/` — `Engine` compiles CEL via `cel-go` (`internal/filter/engine.go`), AST → condition tree (`internal/filter/parser.go`), SQL rendering (`internal/filter/render.go`), memo field schema (`internal/filter/schema.go`).
- **API validation:** `ListMemos` calls `validateFilter`, which uses `DefaultEngine()` and `CompileToStatement` with the active DB dialect (`server/router/api/v1/shortcut_service.go` lines 336–359).
- **SQL generation:** `AppendConditions` (`internal/filter/helpers.go`) loops filters, calls `CompileToStatement`, and appends `(SQL)` plus args to the driver’s `where` slice; dialect drivers pass `filter.DialectSQLite`, `filter.DialectMySQL`, or `filter.DialectPostgres` respectively.
