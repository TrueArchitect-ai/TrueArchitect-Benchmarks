**mysql, postgres, sqlite**

Migrations live under `store/migration/`, with one subdirectory per dialect:

- `store/migration/mysql/`
- `store/migration/postgres/`
- `store/migration/sqlite/`

Each directory holds versioned SQL files (for example `0.22/00__resource_storage_type.sql`) and a `LATEST.sql` full schema. The migrator documents this layout in `store/migrator.go`:

```38:39:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
```

At runtime it picks the dialect from the configured driver via `getMigrationBasePath()` (`migration/{driver}/` in `store/migrator.go`).
