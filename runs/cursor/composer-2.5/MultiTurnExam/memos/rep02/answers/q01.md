**POST /api/v1/memos**

The `CreateMemo` RPC is mapped via a `google.api.http` annotation in `proto/api/v1/memo_service.proto`:

```21:25:proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
```

That annotation is what the gRPC-REST gateway (generated code in `proto/gen/api/v1/memo_service.pb.gw.go`) uses to expose the RPC as a REST endpoint.
