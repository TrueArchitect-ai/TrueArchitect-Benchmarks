In production the compiled React app is embedded and served by the Go binary:

1. **`go:embed dist/*`** — build output is baked into the binary (`server/router/frontend/frontend.go`).
2. **Echo `middleware.StaticWithConfig`** — serves files from that embedded FS.
3. **`spaFallbackMiddleware`** — on 404 for non-API paths, returns embedded `index.html` for client-side routing.
