**memo_relation**

Links between memos are stored in the `memo_relation` table. It has `memo_id`, `related_memo_id`, and `type` (for example `REFERENCE` or `COMMENT`):

```1:7:store/migration/sqlite/LATEST.sql
-- memo_relation
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The same table name is used in the driver code, e.g. `store/db/sqlite/memo_relation.go` and `store/db/postgres/memo_relation.go`.
