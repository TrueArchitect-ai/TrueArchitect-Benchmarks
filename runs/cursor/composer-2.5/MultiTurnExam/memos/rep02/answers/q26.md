**memo_relation, attachment, memo**

`Store.DeleteMemo` in `store/memo.go` explicitly cascades before deleting the memo row:

```140:158:store/memo.go
func (s *Store) DeleteMemo(ctx context.Context, delete *DeleteMemo) error {
	// Clean up memo_relation records where this memo is either the source or target.
	if err := s.driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{MemoID: &delete.ID}); err != nil {
		return err
	}
	if err := s.driver.DeleteMemoRelation(ctx, &DeleteMemoRelation{RelatedMemoID: &delete.ID}); err != nil {
		return err
	}
	// Clean up attachments linked to this memo.
	attachments, err := s.ListAttachments(ctx, &FindAttachment{MemoID: &delete.ID})
	// ...
	for _, attachment := range attachments {
		if err := s.DeleteAttachment(ctx, &DeleteAttachment{ID: attachment.ID}); err != nil {
			return err
		}
	}
	return s.driver.DeleteMemo(ctx, delete)
}
```

That maps to these tables:

| Table | How |
|---|---|
| **memo_relation** | `DELETE FROM memo_relation` in `store/db/sqlite/memo_relation.go` (and mysql/postgres equivalents) |
| **attachment** | `DELETE FROM attachment` via `DeleteAttachment` in `store/attachment.go` / `store/db/sqlite/attachment.go` |
| **memo** | `DELETE FROM memo` in `store/db/sqlite/memo.go` |

The API handler in `server/router/api/v1/memo_service.go` also recursively calls `Store.DeleteMemo` on comment memos first; that removes more rows from the same three tables, not additional tables.

**Not** deleted by `DeleteMemo`: `reaction`, `memo_share`, `inbox`, and other tables (those are cleaned up elsewhere, e.g. `store/db/sqlite/user_delete.go` on user delete).
