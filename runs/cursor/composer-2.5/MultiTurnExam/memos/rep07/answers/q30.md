memos.memo.created: DispatchMemoCreatedWebhook  
memos.memo.updated: DispatchMemoUpdatedWebhook  
memos.memo.deleted: DispatchMemoDeletedWebhook  
memos.memo.comment.created: DispatchMemoCommentCreatedWebhook  

Delivery converges at **`webhook.PostAsync`** in **`internal/webhook/webhook.go`** (queued workers then call **`Post`** for the HTTP POST).

Defined in `server/router/api/v1/memo_service_webhooks.go`:

- **Created, updated, deleted** — public dispatchers delegate to `dispatchMemoRelatedWebhook`, which loads the memo creator’s webhooks and calls `webhook.PostAsync` for each hook.
- **Comment created** — `DispatchMemoCommentCreatedWebhook` loads the **parent memo owner’s** webhooks and calls `webhook.PostAsync` directly (same delivery path, different recipient).

Call sites:

- `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service.go` (`CreateMemo`)
- `DispatchMemoUpdatedWebhook` — `server/router/api/v1/memo_update_helpers.go` (`dispatchMemoUpdatedSideEffects`)
- `DispatchMemoDeletedWebhook` — `server/router/api/v1/memo_service.go` (`DeleteMemo`)
- `DispatchMemoCommentCreatedWebhook` — `server/router/api/v1/memo_service_comments.go` (`CreateMemoComment`)
