SSE (Server-Sent Events); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction

Browsers connect to `/api/v1/sse` for live updates. That endpoint is registered in `server/router/api/v1/sse_handler.go`, and connections are managed by `SSEHub` in `server/router/api/v1/sse_hub.go`.

**Memo handlers that broadcast:**

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `UpsertMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.upserted` |
| `DeleteMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.deleted` |

The frontend listens via `EventSource` in `web/src/hooks/useLiveMemoRefresh.ts`.
