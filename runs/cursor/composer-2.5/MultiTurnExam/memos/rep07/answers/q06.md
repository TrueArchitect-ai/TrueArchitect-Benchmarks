**memo_relation**

Links between one memo and another related memo are stored in the `memo_relation` table. Its schema in `store/migration/sqlite/LATEST.sql` is:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The same table name appears in the PostgreSQL and MySQL migrations (for example `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`), and seed data in `store/seed/sqlite/01__dump.sql` inserts rows with relation types such as `COMMENT` and `REFERENCE`.
