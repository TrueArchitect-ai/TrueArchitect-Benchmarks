NewDBDriver — store/db/db.go

Each driver package exposes a `NewDB` function that returns a `store.Driver` (for example `DB` in `store/db/postgres/postgres.go`). `NewDBDriver` in `store/db/db.go` selects among them with a switch on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`). At startup, `cmd/memos/main.go` calls `db.NewDBDriver(instanceProfile)` to create the driver.
