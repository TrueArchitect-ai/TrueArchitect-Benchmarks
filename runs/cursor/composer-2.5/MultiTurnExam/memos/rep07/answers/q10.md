**store/migration/sqlite/LATEST.sql**

For a fresh SQLite install, the migrator applies the embedded `LATEST.sql` file when the database is not yet initialized. `store/migrator.go` documents that `LATEST.sql` holds the full schema for new installations, and `preMigrate` loads it from `migration/{driver}/LATEST.sql` — for SQLite, that resolves to `store/migration/sqlite/LATEST.sql`.
