The main memo list UI (`web/src/components/PagedMemoList/PagedMemoList.tsx`) calls `useInfiniteMemos`, which invokes `memoServiceClient.listMemos(...)` from `web/src/connect.ts`. That client is created with `createClient(MemoService, transport)` in the same file.

The RPC is defined as `MemoService.ListMemos` in `proto/api/v1/memo_service.proto`. On the backend, `APIV1Service.ListMemos` in `server/router/api/v1/memo_service.go` handles the request and calls `s.Store.ListMemos(...)`.

`Store.ListMemos` in `store/memo.go` delegates to the driver interface, and the SQLite implementation in `store/db/sqlite/memo.go` builds and runs the SQL query against the `memo` table via `d.db.QueryContext(...)`.
