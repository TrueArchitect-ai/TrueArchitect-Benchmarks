gRPC-Gateway — server/router/api/v1/v1.go  
Connect — server/router/api/v1/connect_handler.go  

`MemoService` is exposed over **gRPC-Gateway (REST/HTTP JSON)** and **Connect RPC**.

**gRPC-Gateway** — registered in `server/router/api/v1/v1.go` via `RegisterMemoServiceHandlerServer`, which maps HTTP routes (for example `GET /api/v1/memos`) to the gRPC-style handlers. Generated gateway code lives in `proto/gen/api/v1/memo_service.pb.gw.go`.

**Connect** — registered in `server/router/api/v1/connect_handler.go` via `apiv1connect.NewMemoServiceHandler(s, opts...)`. Connect handler methods that wrap/delegate to `APIV1Service` are in `server/router/api/v1/connect_services.go` (for example `ConnectServiceHandler.ListMemos` → `APIV1Service.ListMemos`).

Both are wired up in `RegisterGateway` in `server/router/api/v1/v1.go`: gRPC-Gateway on `/api/v1/*`, Connect on `/memos.api.v1.*`.
