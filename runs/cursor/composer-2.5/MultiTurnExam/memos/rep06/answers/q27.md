Embedded static files via Echo `Static` middleware with SPA fallback; server/server.go

In production, the compiled React app under `dist/` is embedded into the Go binary with `//go:embed dist/*` in `server/router/frontend/frontend.go`. `FrontendService.Serve` serves those files through Echo’s `middleware.StaticWithConfig`, and `spaFallbackMiddleware` returns `index.html` for non-API routes that would otherwise 404.

That is wired in `server/server.go`:

```71:72:server/server.go
	// Serve frontend static files.
	frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)
```
