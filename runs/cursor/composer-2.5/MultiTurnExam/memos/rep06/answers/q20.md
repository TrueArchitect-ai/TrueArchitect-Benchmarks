SSE (Server-Sent Events); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction

Live updates use **Server-Sent Events (SSE)**. Clients connect to `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go`), which sets `Content-Type: text/event-stream` and subscribes clients to the hub.

The hub is **`SSEHub`** in `server/router/api/v1/sse_hub.go` — it manages subscriptions and `Broadcast`s events to connected clients.

**Memo handlers that broadcast:**

| Handler | Event | File |
|---|---|---|
| `CreateMemo` | `memo.created` | `server/router/api/v1/memo_service.go` |
| `UpdateMemo` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) | `server/router/api/v1/memo_service.go` |
| `DeleteMemo` | `memo.deleted` | `server/router/api/v1/memo_service.go` |
| `CreateMemoComment` | `memo.comment.created` | `server/router/api/v1/memo_service_comments.go` |
| `SetMemoAttachments` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) | `server/router/api/v1/memo_attachment_service.go` |
| `SetMemoRelations` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) | `server/router/api/v1/memo_relation_service.go` |
| `UpsertMemoReaction` | `reaction.upserted` | `server/router/api/v1/reaction_service.go` |
| `DeleteMemoReaction` | `reaction.deleted` | `server/router/api/v1/reaction_service.go` |

The shared `memo.updated` broadcast lives in `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go`. The frontend consumes these events via `useLiveMemoRefresh` in `web/src/hooks/useLiveMemoRefresh.ts`.
