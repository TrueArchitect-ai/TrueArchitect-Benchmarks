This project ships migrations for **mysql, postgres, sqlite**.

They live under `store/migration/` in three dialect-specific directories:

- `store/migration/mysql/`
- `store/migration/postgres/`
- `store/migration/sqlite/`

Each has a full schema file (`LATEST.sql`) and versioned incremental migrations (for example `store/migration/mysql/0.27/`, `store/migration/postgres/0.27/`, `store/migration/sqlite/0.27/`).

The migrator loads them by driver name via `store/migration/{driver}/`, as documented in `store/migrator.go`:

```38:39:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
```

```254:256:store/migrator.go
func (s *Store) getMigrationBasePath() string {
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
}
```

Those three drivers match the database backends under `store/db/` (`mysql`, `postgres`, `sqlite`).
