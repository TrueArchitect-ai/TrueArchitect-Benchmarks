**Delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go` (HTTP POST via `Post`)

Create, update, and delete go through `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`, which loads the creator’s webhooks and calls `webhook.PostAsync`. Comment-created webhooks call `webhook.PostAsync` directly in `DispatchMemoCommentCreatedWebhook` (same file).

All paths enqueue to `asyncPostQueue`; worker goroutines from `init()` in `internal/webhook/webhook.go` call `Post` for the actual HTTP delivery.
