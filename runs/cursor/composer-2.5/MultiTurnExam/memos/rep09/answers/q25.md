**CEL (Common Expression Language) via google/cel-go in `internal/filter`**

Each filter string is compiled by `filter.Engine` (`internal/filter/engine.go`) into a dialect-agnostic condition tree from the memo schema (`internal/filter/schema.go`), then rendered to parameterized SQL for the target dialect (`sqlite`, `mysql`, or `postgres`) by `Program.Render` in `internal/filter/render.go`; dialect drivers call `filter.AppendConditions` (`internal/filter/helpers.go`) during `ListMemos` to append those fragments to the `WHERE` clause (e.g. `store/db/sqlite/memo.go` with `filter.DialectSQLite`).

The API validates filters the same way in `validateFilter` (`server/router/api/v1/shortcut_service.go`), using `filter.DefaultEngine()` and `CompileToStatement` before `ListMemos` stores the filter on `memoFind.Filters` (`server/router/api/v1/memo_service.go`).
