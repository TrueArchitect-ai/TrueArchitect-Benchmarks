**sqlite, mysql, postgres**

Migrations live under `store/migration/`, with one subdirectory per dialect:

- `store/migration/sqlite/`
- `store/migration/mysql/`
- `store/migration/postgres/`

Each dialect has versioned migration files and a `LATEST.sql` full schema. The migrator documents the layout in `store/migrator.go`:

```38:42:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
// - Naming: NN is zero-padded patch number, description is human-readable
// - Ordering: Files sorted lexicographically and applied in order
// - LATEST.sql: Full schema for new installations (faster than incremental migrations)
```

`AGENTS.md` also states that schema changes require migrations for all three drivers plus `LATEST.sql` updates. No other migration dialect directories exist under `store/migration/`.
