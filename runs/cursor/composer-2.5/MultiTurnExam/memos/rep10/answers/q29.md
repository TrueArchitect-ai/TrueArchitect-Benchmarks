**Tokens:**

- **Access token** — stored in memory/localStorage via `web/src/auth-state.ts`, sent as `Authorization: Bearer <token>`.
- **Refresh token** — HttpOnly cookie (`memos_refresh`); requests use `credentials: "include"` and `refreshAuthClient.refreshToken()` to obtain a new access token when needed.

**Backend validation:** `server/auth` (`Authenticator` in `server/auth/authenticator.go`) validates JWT access tokens and personal access tokens (PATs). Connect requests go through `NewAuthInterceptor` in `server/router/api/v1/connect_interceptors.go`, which uses `Authorizer` in `server/router/api/v1/authz.go` and delegates to `auth.NewAuthenticator`.
