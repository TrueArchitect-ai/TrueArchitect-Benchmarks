**memo_relation**

The `memo_relation` table stores links between memos, with `memo_id`, `related_memo_id`, and `type` columns. It is defined in `store/migration/sqlite/LATEST.sql` (and mirrored in the postgres/mysql `LATEST.sql` files):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The original migration is in `store/migration/sqlite/0.13/00__memo_relation.sql`.
