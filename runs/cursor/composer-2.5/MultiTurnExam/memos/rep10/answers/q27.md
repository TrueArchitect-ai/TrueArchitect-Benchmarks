In production, the compiled React app is embedded into the Go binary and served by Echo:

1. **`//go:embed dist/*`** — the Vite build output is embedded at compile time (`server/router/frontend/frontend.go`).

3. **`spaFallbackMiddleware`** — on 404 for non-API paths, returns `index.html` for client-side routing.
