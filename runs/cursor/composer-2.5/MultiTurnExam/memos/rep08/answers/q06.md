**memo_relation**

Links between one memo and another are stored in the `memo_relation` table. It has `memo_id`, `related_memo_id`, and `type` (for example `REFERENCE` or `COMMENT`), as defined in `store/migration/sqlite/LATEST.sql`:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The same table name appears in seed data (`store/seed/sqlite/01__dump.sql`) and in store tests (`store/test/memo_relation_test.go`).
