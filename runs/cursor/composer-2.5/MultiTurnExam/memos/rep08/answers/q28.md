s3presign — immediate `RunOnce` at startup, then a 12-hour `time.Ticker` loop (`server/server.go` `startBackgroundRunners`, `server/runner/s3presign/runner.go`)

**Unused infrastructure:** The server starts only the **s3presign** runner in `startBackgroundRunners` (`server/server.go`). It does **not** start `server/runner/memopayload/` as a background worker; that package is used synchronously via `memopayload.RebuildMemoPayload` from memo handlers (`server/router/api/v1/memo_service.go`). The **`internal/scheduler`** cron scheduler (`internal/scheduler/`) is present in the repo but is **not imported or used** by the server (only its own tests/docs reference it).

**Note:** Webhook delivery uses four background goroutines started in `init()` in `internal/webhook/webhook.go` (fed by `PostAsync`), but that is separate from the explicit `server/runner/` background runners above.
