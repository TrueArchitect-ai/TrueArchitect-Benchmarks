**mysql, postgres, sqlite**

Migrations live under `store/migration/`, with one subdirectory per dialect:

- `store/migration/mysql/`
- `store/migration/postgres/`
- `store/migration/sqlite/`

Each dialect has versioned migration SQL files (for example `0.30/00__user_tag_setting.sql`) and a `LATEST.sql` full schema for new installs. The migrator documents this layout in `store/migrator.go` (`store/migration/{driver}/{version}/NN__description.sql`) and selects the path from the configured driver via `s.profile.Driver`. Those three drivers are the only ones supported in `store/db/db.go` (`sqlite`, `mysql`, `postgres`).
