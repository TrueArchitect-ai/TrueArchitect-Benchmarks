**store/migration/sqlite/LATEST.sql**

For a fresh SQLite install, the migrator applies `LATEST.sql` when the database is not initialized. That file holds the full current schema. It is documented in `store/migrator.go` (`LATEST.sql: Full schema for new installations`) and loaded from `migration/{driver}/LATEST.sql`, which for SQLite is `store/migration/sqlite/LATEST.sql`.
