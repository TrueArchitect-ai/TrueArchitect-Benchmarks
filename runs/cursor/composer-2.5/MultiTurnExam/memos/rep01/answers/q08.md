**Driver — store/driver.go**

All database backends implement the `Driver` interface, defined in `store/driver.go`:

```8:10:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
```

`store/db/db.go` wires up the three backends (`sqlite`, `mysql`, `postgres`) and returns each as a `store.Driver` from `NewDBDriver`. Each backend’s `NewDB` (for example in `store/db/postgres/postgres.go`, `store/db/mysql/mysql.go`, and `store/db/sqlite/sqlite.go`) constructs its concrete type and returns it as `store.Driver`.
