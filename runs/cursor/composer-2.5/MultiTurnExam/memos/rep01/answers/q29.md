The Connect **`authInterceptor`** in `web/src/connect.ts` attaches auth to every API request:

It uses **`getRequestToken()`** to read/refresh the **access token** from `web/src/auth-state.ts` (localStorage key `memos_access_token`) and sets `Authorization: Bearer <token>`. Requests use **`credentials: "include"`** so the **refresh token** HttpOnly cookie is sent on refresh calls (`refreshAuthClient.refreshToken`). On `Unauthenticated`, it refreshes and retries once.

The backend **`server/auth`** package validates credentials via **`Authenticator`** (`server/auth/authenticator.go`): JWT access tokens (`AuthenticateByAccessTokenV2`), refresh tokens in cookies (`AuthenticateByRefreshToken`), and PATs (`AuthenticateByPAT`). Connect requests go through **`AuthInterceptor`** in `server/router/api/v1/connect_interceptors.go`, which delegates to **`Authorizer`** in `server/router/api/v1/authz.go`.
