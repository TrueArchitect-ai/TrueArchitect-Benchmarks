**memo_relation**

Links between memos are stored in the `memo_relation` table. It was introduced in `store/migration/sqlite/0.13/00__memo_relation.sql` and appears in the current schema in `store/migration/sqlite/LATEST.sql` (and the equivalent files for postgres and mysql):

```47:52:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Each row ties a memo (`memo_id`) to a related memo (`related_memo_id`), with a relation `type` such as `REFERENCE` or `COMMENT` (see seed data in `store/seed/sqlite/01__dump.sql`).
