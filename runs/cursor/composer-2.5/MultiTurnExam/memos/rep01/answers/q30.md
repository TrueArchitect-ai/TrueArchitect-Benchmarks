memos.memo.created: DispatchMemoCreatedWebhook  
memos.memo.updated: DispatchMemoUpdatedWebhook  
memos.memo.deleted: DispatchMemoDeletedWebhook  
memos.memo.comment.created: DispatchMemoCommentCreatedWebhook  

**Delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go` (background workers call `Post` for the HTTP POST)

All four dispatch functions are defined in `server/router/api/v1/memo_service_webhooks.go`:

- **Created / updated / deleted** go through `dispatchMemoRelatedWebhook`, which loads the memo creator’s webhooks and calls `webhook.PostAsync` with activity types `memos.memo.created`, `memos.memo.updated`, or `memos.memo.deleted`.
- **Comment created** uses `DispatchMemoCommentCreatedWebhook`, which loads the parent memo owner’s webhooks and also calls `webhook.PostAsync` with `memos.memo.comment.created`.

Handlers that trigger them:

| Event | Caller |
|---|---|
| created | `CreateMemo` in `server/router/api/v1/memo_service.go` |
| updated | `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go` |
| deleted | `DeleteMemo` in `server/router/api/v1/memo_service.go` |
| comment created | `CreateMemoComment` in `server/router/api/v1/memo_service_comments.go` |

Everything converges on `webhook.PostAsync` in `internal/webhook/webhook.go`, which enqueues to `asyncPostQueue`; four `init()` goroutines drain the queue and run `Post` for the actual HTTP delivery.
