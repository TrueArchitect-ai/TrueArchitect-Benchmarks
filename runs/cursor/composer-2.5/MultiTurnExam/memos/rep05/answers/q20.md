SSE (Server-Sent Events); server/router/api/v1/sse_hub.go; CreateMemo, DeleteMemo, UpdateMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations

Live updates use **Server-Sent Events** (`Content-Type: text/event-stream`). Clients connect at `/api/v1/sse` via `RegisterSSERoutes` in `server/router/api/v1/sse_handler.go`, which subscribes clients to the hub.

The hub is implemented in `server/router/api/v1/sse_hub.go` — `SSEHub` manages subscribers and `Broadcast` sends events to connected clients.

**Memo handlers that broadcast:**

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |

`dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go` performs the `SSEHub.Broadcast` for update-style events. `CreateMemo` skips broadcast when called from `CreateMemoComment` (suppressed via `withSuppressSSE`).
