**mysql, postgres, sqlite**

Migrations live under `store/migration/` in one subdirectory per dialect: `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/`. Each contains versioned SQL files and a `LATEST.sql` full schema.

`store/migrator.go` documents and uses that layout:

```38:39:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
```

It resolves the path from the configured driver via `getMigrationBasePath()`:

```254:256:store/migrator.go
func (s *Store) getMigrationBasePath() string {
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
}
```

Those three drivers are the only ones supported in `store/db/db.go` (`sqlite`, `mysql`, `postgres`).
