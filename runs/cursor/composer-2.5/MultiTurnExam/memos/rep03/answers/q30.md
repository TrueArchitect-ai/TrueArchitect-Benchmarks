memos.memo.created: DispatchMemoCreatedWebhook  
memos.memo.updated: DispatchMemoUpdatedWebhook  
memos.memo.deleted: DispatchMemoDeletedWebhook  
memos.memo.comment.created: DispatchMemoCommentCreatedWebhook  

webhook.PostAsync — internal/webhook/webhook.go

All four are defined in `server/router/api/v1/memo_service_webhooks.go`. Create, update, and delete go through `dispatchMemoRelatedWebhook`, which loads the memo creator’s webhooks and calls `webhook.PostAsync`. Comment-created webhooks call `webhook.PostAsync` directly for the related memo owner (activity type `memos.memo.comment.created`).

Handlers that trigger them:

- `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service.go` (CreateMemo)
- `DispatchMemoUpdatedWebhook` — `server/router/api/v1/memo_update_helpers.go` (via `dispatchMemoUpdatedSideEffects`)
- `DispatchMemoDeletedWebhook` — `server/router/api/v1/memo_service.go` (DeleteMemo)
- `DispatchMemoCommentCreatedWebhook` — `server/router/api/v1/memo_service_comments.go` (CreateMemoComment)

Delivery converges in `internal/webhook/webhook.go`: `PostAsync` enqueues to a channel; background workers call `Post` for the HTTP POST with optional Standard Webhooks signing.
