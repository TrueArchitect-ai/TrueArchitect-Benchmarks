**mysql, postgres, sqlite**

Migrations live under `store/migration/`, with one subdirectory per dialect:

- `store/migration/mysql/`
- `store/migration/postgres/`
- `store/migration/sqlite/`

Each dialect has its own `LATEST.sql` and versioned migration scripts. The migrator embeds that tree and selects the path from the configured driver:

```38:39:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
```

```254:256:store/migrator.go
func (s *Store) getMigrationBasePath() string {
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
}
```

Those three drivers are also wired up in `store/db/db.go` and exercised in tests via `store/test/main_test.go`.
