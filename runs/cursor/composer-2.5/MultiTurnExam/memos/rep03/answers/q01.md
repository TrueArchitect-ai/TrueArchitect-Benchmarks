**POST /api/v1/memos**

```21:27:proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"

    option (google.api.method_signature) = "memo";
  }
```

That mapping is generated into the gateway code in `proto/gen/api/v1/memo_service.pb.gw.go`, and the gateway is registered in `server/router/api/v1/v1.go` and `server/server.go`.
