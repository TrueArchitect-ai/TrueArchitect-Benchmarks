**memo_relation**

Links between memos are stored in the `memo_relation` table, defined in `store/migration/sqlite/LATEST.sql` (and the equivalent migrations for MySQL and PostgreSQL):

```46:52:store/migration/sqlite/LATEST.sql
-- memo_relation
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Each row ties one memo (`memo_id`) to another (`related_memo_id`) with a relation `type` (e.g. `REFERENCE` or `COMMENT`). The table was introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`, and the store layer uses it via `store/db/postgres/memo_relation.go` and related code.
