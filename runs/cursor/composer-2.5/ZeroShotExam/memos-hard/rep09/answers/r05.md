**Premise correction:** This repository does not define a GraphQL schema for the public API. A search of the codebase finds no GraphQL schema files or GraphQL server usage (only unrelated hash strings in `web/pnpm-lock.yaml`). The README describes the API as “REST and gRPC APIs,” not GraphQL (`README.md`).

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/`:

- `proto/api/v1/auth_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared messages)

Those `.proto` files are the source of truth. `AGENTS.md` documents this as “Public API service definitions” in `proto/api/v1/`. Running `buf generate` (see `proto/README.md`) produces:

- Go/gRPC/Connect code in `proto/gen/api/v1/`
- An OpenAPI spec at `proto/gen/openapi.yaml`

Services are exposed over HTTP as Connect RPC and gRPC-Gateway REST routes (e.g. `/api/v1/memos` in `proto/api/v1/memo_service.proto`), wired in `server/router/api/v1/` (`v1.go`, `connect_handler.go`, `connect_services.go`). Public (unauthenticated) endpoints are listed in `server/router/api/v1/acl_config.go`.
