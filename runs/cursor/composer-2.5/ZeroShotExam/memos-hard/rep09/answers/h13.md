**Impl:** The only runtime implementation of `markdown.Service` is the unexported goldmark-backed `service` struct in `internal/markdown/markdown.go` (returned by `markdown.NewService()`). There are no alternate or mock implementations wired in production.

**Construction:** `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` is called inside `apiv1.NewAPIV1Service()` in `server/router/api/v1/v1.go`. `server/server.go` then passes that same instance into `rss.NewRSSService(..., apiV1Service.MarkdownService)`.

**Holders:** Components that store a `markdown.Service` field and use it at runtime:

- **`APIV1Service`** — `MarkdownService` field in `server/router/api/v1/v1.go`; used from `memo_service.go`, `memo_mention_helpers.go`, and `memo_service_webhooks.go` (and passed into `memopayload.RebuildMemoPayload`).
- **`RSSService`** — `MarkdownService` field in `server/router/rss/rss.go`; used for `RenderHTML` when building RSS feeds.

`memopayload.Runner` in `server/runner/memopayload/runner.go` also declares a `MarkdownService` field, but `memopayload.NewRunner` is never called in production startup — only the free function `RebuildMemoPayload(..., markdownService markdown.Service)` receives the service from `APIV1Service`.
