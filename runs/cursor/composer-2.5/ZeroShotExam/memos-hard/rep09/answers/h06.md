**Handlers (≥3):** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` — all on `APIV1Service` under `server/router/api/v1/`.

**Convergence function:** `Post` — `internal/webhook/webhook.go`

These RPC handlers can transitively POST to user-configured webhook URLs (`hook.Url` from `Store.GetUserWebhooks`). The webhook CRUD handlers in `server/router/api/v1/user_service_webhooks.go` only store URLs; they do not send HTTP.

| Handler | File | Webhook dispatch path |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoCreatedWebhook` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoDeletedWebhook` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | calls `CreateMemo` (created webhook) + `DispatchMemoCommentCreatedWebhook` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` |

Shared dispatch logic lives in `server/router/api/v1/memo_service_webhooks.go`: `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook` load webhooks, set `payload.URL = hook.Url`, and call `webhook.PostAsync`. Workers in `internal/webhook/webhook.go` drain the queue and all call `Post`, which performs the outbound request via `safeClient.Do(req)` at line 152. That is the single convergence point before HTTP delivery.
