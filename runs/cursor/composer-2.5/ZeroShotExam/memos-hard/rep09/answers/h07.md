user.avatar_url (base64 data URI in the `user` table) — database  

The browser gets `avatarUrl` as `/file/users/{username}/avatar` from the user API (`convertUserFromStore` in server/router/api/v1/user_service_converters.go), then the `<img>` issues `GET /file/users/{username}/avatar`. The handler loads that user’s row, reads `avatar_url` from the DB, decodes it with `parseDataURI`, and returns the image bytes via `c.Blob` — avatars are stored inline in the DB, not as separate files on disk.
