`safeClient` uses a custom transport whose `DialContext` is `safeDialContext`. That function resolves the target hostname and refuses to connect if any resolved address is in a reserved/private range (via `isReservedIP` in `internal/webhook/validate.go`), guarding against SSRF and DNS rebinding at dial time:

```29:36:internal/webhook/webhook.go
	// safeClient is the shared HTTP client used for all webhook dispatches.
	// Its Transport guards against SSRF by blocking connections to reserved/private
	// IP addresses at dial time, which also defeats DNS rebinding attacks.
	safeClient = &http.Client{
		Timeout: timeout,
		Transport: &http.Transport{
			DialContext: safeDialContext,
		},
	}
```

There is also registration-time validation in `ValidateURL` (`internal/webhook/validate.go`), which rejects webhook URLs that resolve to private/reserved IPs when they are created or updated. The runtime guard on the delivery path itself is `safeDialContext`.
