The data layer is the `store/` package (see `AGENTS.md` and `store/store.go`). Persistent entity types are the domain structs declared there, such as `User` in `store/user.go`, `Memo` in `store/memo.go`, and the rest enumerated on the `Driver` interface in `store/driver.go` (`Attachment`, `MemoRelation`, `InstanceSetting`, `UserSetting`, `IdentityProvider`, `Inbox`, `Reaction`, `MemoShare`, `UserIdentity`).

Counting Go packages **outside** `store/` that reference each entity type as `store.<Type>` (including test packages like `server/router/api/v1/test`):

| Entity | External packages |
|---|---|
| **User** | 7 |
| **Memo** | 6 |
| Attachment | 4 |
| Inbox, MemoRelation, MemoShare | 3 each |
| Reaction, UserIdentity | 2 each |
| InstanceSetting, UserSetting, IdentityProvider | 0 |

**1st: User (~7 packages); 2nd: Memo (~6 packages)**

**User** (~7): `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` — e.g. `*store.User` in `server/auth/authenticator.go` and `server/router/api/v1/common.go`.

**Memo** (~6): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` — e.g. `*store.Memo` in `server/runner/memopayload/runner.go` and `server/router/api/v1/memo_service.go`.

Note: `InstanceSetting`, `UserSetting`, and `IdentityProvider` are defined in `store/` (`store/instance_setting.go`, `store/user_setting.go`, `store/idp.go`) but external code typically uses the protobuf types from `proto/gen/store` rather than the raw `store.*` structs, so they rank lower by this metric.
