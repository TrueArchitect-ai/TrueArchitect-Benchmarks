**Post** — `internal/webhook/webhook.go`; **safeDialContext** (with **isReservedIP** / **reservedCIDRs**) — `internal/webhook/webhook.go` and `internal/webhook/validate.go`

When memo content changes, dispatch is queued from `server/router/api/v1/memo_service_webhooks.go` via `webhook.PostAsync`. Worker goroutines started in `init()` in `internal/webhook/webhook.go` dequeue those payloads and call **`Post`**, which performs the outbound HTTP POST through `safeClient.Do(req)`.

SSRF protection is layered:

1. **At delivery time** — `safeClient` uses a custom `DialContext` (`safeDialContext`) that resolves the hostname and refuses to connect if any resolved address is in a reserved/private range, checked via `isReservedIP` (see comments around lines 29–31 and 57–74 in `internal/webhook/webhook.go`).

2. **At URL registration time** — `ValidateURL` in `internal/webhook/validate.go` rejects webhook URLs whose hostnames resolve to those same ranges, using the `reservedCIDRs` list (loopback, RFC 1918, link-local/IMDS, IPv6 ULA/link-local) parsed into `reservedNetworks` and checked by `isReservedIP`.
