**Premise correction:** This repository does not define a GraphQL schema for the public API. A repo-wide search finds no `.graphql`/`.gql` files and no GraphQL server or client usage in application code (only unrelated hash strings in `web/pnpm-lock.yaml`). Memos exposes its public API through Protocol Buffers, Connect RPC, and gRPC-Gateway REST, as documented in `AGENTS.md` and `README.md`.

**Actual API surface:** The public API is defined in Protocol Buffer sources under `proto/api/v1/`:

- `proto/api/v1/auth_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Those `.proto` files are the source of truth. `proto/buf.gen.yaml` drives code generation into:

- Go / Connect / gRPC-Gateway: `proto/gen/api/v1/`
- OpenAPI (REST contract): `proto/gen/openapi.yaml`

Implementation and routing live under `server/router/api/v1/`. Which endpoints are public (no auth) is configured in `server/router/api/v1/acl_config.go` via the `PublicMethods` map.
