**Backend (`markdown.Service` in `internal/markdown/markdown.go`)**

- **impl** — The only runtime concrete type is the unexported `service` struct (`internal/markdown/markdown.go`), returned by `NewService`. It wraps a goldmark parser; `RenderMarkdown` / `RenameTag` also call the concrete `renderer.MarkdownRenderer` (`internal/markdown/renderer/markdown_renderer.go`), but that renderer is not behind its own interface.
- **construction** — `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` inside `NewAPIV1Service` (`server/router/api/v1/v1.go`). `server/server.go` passes that same instance into `rss.NewRSSService(..., apiV1Service.MarkdownService)`.
- **holders** — `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go`); `RSSService.MarkdownService` (`server/router/rss/rss.go`); `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go`, field on the type — `NewRunner` is not wired in `server/server.go`, but memo APIs call `memopayload.RebuildMemoPayload(..., s.MarkdownService)` from `server/router/api/v1/memo_service.go`).

**Frontend (separate “markdown through an interface” contract: `EditorController` in `web/src/components/MemoEditor/types/editorController.ts`)**

- **impl** — The object returned by `createController()` (`web/src/components/MemoEditor/Editor/controller.ts`), backed by CodeMirror’s `EditorView`.
- **construction** — `createController(view, createFormattingController(...))` in a `useLayoutEffect` inside `web/src/components/MemoEditor/Editor/index.tsx`.
- **holders** — `EditorController` refs held by `EditorContent`, parent `Editor`, `FormattingToolbar`, and hooks such as `useEditorActiveState` / `useMemoInit` (all under `web/src/components/MemoEditor/`).
