**(*DB).CreateMemo** — `store/db/sqlite/memo.go`; **determination:** default install sets `driver` to `"sqlite"` in `cmd/memos/main.go` (`viper.SetDefault("driver", "sqlite")`), `store/db/db.go`’s `NewDBDriver` switches on `profile.Driver` and picks `sqlite.NewDB` for that value, and memo creation delegates `APIV1Service.CreateMemo` → `store.Store.CreateMemo` (`store/memo.go`) → the `Driver` interface. Three driver implementations each contain an `INSERT INTO memo` (`store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`); only the SQLite one runs with no database flags. The actual INSERT is issued inside `(*DB).CreateMemo` via `d.db.QueryRowContext(ctx, stmt, args...)` (line 42 in `store/db/sqlite/memo.go`). Updating an existing memo uses `UpdateMemo` and runs `UPDATE`, not `INSERT`.
