h03.
**internal/idp**; **internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used when resolving SSO users (`internal/idp/idp.go`). The only shipped protocol implementation is OAuth2 in `internal/idp/oauth2`, which implements token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`). That wiring is used in SSO auth at `server/router/api/v1/auth_service_sso.go`, and the store/API layer only defines `OAUTH2` as a concrete IdP type (`proto/store/idp.proto`).
