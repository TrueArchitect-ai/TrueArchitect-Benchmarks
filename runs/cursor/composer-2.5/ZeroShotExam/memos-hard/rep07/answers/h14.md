**Computation site:** Core extraction is in `internal/markdown/markdown.go` — a goldmark AST walk in `ExtractAll` (also `ExtractProperties`) computes persisted derived fields, and `GenerateSnippet` builds plain-text previews. Those results are written to the memo by `RebuildMemoPayload` in `server/runner/memopayload/runner.go`, which sets `memo.Payload.Tags` and `memo.Payload.Property`. Snippets are computed at read time via `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go`, called from `server/router/api/v1/memo_service_converter.go` when building API `Memo` responses. The schema is defined in `proto/store/memo.proto` (`MemoPayload`) and exposed as OUTPUT_ONLY fields in `proto/api/v1/memo_service.proto` (`tags`, `property`, `snippet`).

**Triggers:** Persisted payload (tags + property) is recomputed on `CreateMemo` (`server/router/api/v1/memo_service.go`, always, including when `CreateMemoComment` delegates to it) and on `UpdateMemo` only when the update mask includes `"content"`. The batch maintenance path `memopayload.Runner.RunOnce` in `server/runner/memopayload/runner.go` rebuilds all memo payloads. Snippets are not stored; they are regenerated whenever a memo is converted for API output (list/get/relations).

**Extracted properties:** From content markdown, `ExtractAll` extracts: **`tags`** — `#tag` tokens (deduplicated, skipping tags inside links/images); **`property.has_link`** — any link node; **`property.has_task_list`** — any GFM task checkbox; **`property.has_code`** — code blocks or inline code; **`property.has_incomplete_tasks`** — any unchecked task checkbox; **`property.title`** — plain text of the first block-level H1 heading. Separately, **`snippet`** — a truncated plain-text summary (64 characters on API responses) via `GenerateSnippet`, used for list/preview display but not persisted in the payload.
