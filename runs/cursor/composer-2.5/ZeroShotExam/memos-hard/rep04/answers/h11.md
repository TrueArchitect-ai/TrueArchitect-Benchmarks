1st: **User** (~7 packages); 2nd: **Memo** (~6 packages)

The data layer is `store/` (see `AGENTS.md`). Persistent entity types are the model structs wired through `store/driver.go` — e.g. `User` in `store/user.go` and `Memo` in `store/memo.go`, alongside `Attachment`, `IdentityProvider`, `Inbox`, `InstanceSetting`, `MemoRelation`, `MemoShare`, `Reaction`, `UserIdentity`, and `UserSetting`.

Counting Go packages outside `store/` that reference each type as `store.<Type>`:

| Entity | Packages (count) |
|---|---|
| **User** | `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` (**7**) |
| **Memo** | `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` (**6**) |
| Attachment | 4 |
| Inbox, MemoRelation, MemoShare | 3 each |
| Reaction, UserIdentity | 2 each |
| IdentityProvider, InstanceSetting, UserSetting, AuthenticationConfigState | 0 |

`User` leads because it is used across auth (`server/auth/authenticator.go`), notifications, API handlers, file serving, frontend routing, and RSS. `Memo` is next, with broad use in API, notifications, RSS, frontend, and the memo payload runner (`server/runner/memopayload/`). No other persistent entity type is referenced from as many external packages.
