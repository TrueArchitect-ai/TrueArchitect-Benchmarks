**Premise correction:** This repository does not define a GraphQL schema for the public API. A repo-wide search finds zero references to GraphQL, `.graphql`/`.gql` files, or GraphQL tooling.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/`, as documented in `AGENTS.md` (“Public API service definitions”) and `proto/api/v1/README.md`. Those `.proto` files are the source of truth; `buf generate` (see `proto/buf.gen.yaml`) produces:

- Go Connect/gRPC code in `proto/gen/`
- TypeScript clients in `web/src/types/proto/`
- REST/OpenAPI spec in `proto/gen/openapi.yaml`

The eight public services are declared in:

- `proto/api/v1/ai_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/user_service.proto`

They are served via **Connect RPC** and **gRPC-Gateway REST** from `server/router/api/v1/` (e.g. REST paths like `/api/v1/...` in `proto/gen/openapi.yaml`). The frontend uses Connect clients in `web/src/connect.ts`, not GraphQL.

Unauthenticated (“public”) endpoints are listed separately in `server/router/api/v1/acl_config.go` (`PublicMethods`), but that file configures ACL, not the API schema itself.
