h02.
Post — `internal/webhook/webhook.go`; safeDialContext — `internal/webhook/webhook.go`

Content-change handlers enqueue work with `webhook.PostAsync` (for example in `server/router/api/v1/memo_service_webhooks.go`), but the actual outbound HTTP POST runs in `Post`, which four background goroutines in the same file call from `asyncPostQueue` via `safeClient.Do(req)`.

SSRF protection on that connection is enforced at dial time by `safeDialContext`, wired as the `DialContext` on `safeClient`'s transport. It resolves the hostname and rejects any address in a reserved/private range using `isReservedIP` (defined in `internal/webhook/validate.go` against `reservedCIDRs`). Webhook URLs are also checked at create/update time by `ValidateURL` in `internal/webhook/validate.go`.
