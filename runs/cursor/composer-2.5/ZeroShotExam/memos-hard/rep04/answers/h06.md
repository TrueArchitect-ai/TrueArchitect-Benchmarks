**CreateMemo**, **UpdateMemo**, **DeleteMemo**, **CreateMemoComment**, **SetMemoAttachments**, **SetMemoRelations**; **`webhook.PostAsync`** — `internal/webhook/webhook.go`

These RPC handlers on `APIV1Service` can transitively POST to webhook URLs stored in user settings (configured via `CreateUserWebhook` / `UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`):

| Handler | Trigger path |
|---|---|
| `CreateMemo` | `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` (`server/router/api/v1/memo_service.go:157`, `memo_service_webhooks.go:15-17,48-72`) |
| `UpdateMemo` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `webhook.PostAsync` (`memo_service.go:513`, `memo_update_helpers.go:66-68`, `memo_service_webhooks.go:19-22,48-72`) |
| `DeleteMemo` | `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` (`memo_service.go:562`, `memo_service_webhooks.go:24-27,48-72`) |
| `CreateMemoComment` | `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync` (`memo_service_comments.go:119`, `memo_service_webhooks.go:30-45`) |
| `SetMemoAttachments` | `dispatchMemoUpdatedSideEffects` → `webhook.PostAsync` (`memo_attachment_service.go:48`, `memo_update_helpers.go:66-68`) |
| `SetMemoRelations` | `dispatchMemoUpdatedSideEffects` → `webhook.PostAsync` (`memo_relation_service.go:48`, `memo_update_helpers.go:66-68`) |

All of those paths load the user’s configured webhook URLs via `s.Store.GetUserWebhooks` in `memo_service_webhooks.go` and set `payload.URL = hook.Url` before enqueueing.

They converge at **`webhook.PostAsync`** in `internal/webhook/webhook.go` (lines 182–196), which enqueues payloads for background workers; those workers call **`webhook.Post`** (line 120), which performs the outbound HTTP via `safeClient.Do(req)` (line 152).
