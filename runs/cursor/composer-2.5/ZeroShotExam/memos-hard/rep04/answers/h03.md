h03.
internal/idp; internal/idp/oauth2

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type in `internal/idp/idp.go`. The only concrete protocol implementation shipped is OAuth 2 in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), wired from SSO auth in `server/router/api/v1/auth_service_sso.go` when the stored provider type is `OAUTH2` (`proto/store/idp.proto`). No other IdP protocol packages exist under `internal/idp/`.
