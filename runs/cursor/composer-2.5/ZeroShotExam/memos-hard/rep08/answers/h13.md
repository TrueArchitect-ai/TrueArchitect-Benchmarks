**impl — construction — holders**

- **impl:** The only concrete runtime implementation is the unexported `service` struct in `internal/markdown/markdown.go`, returned by `markdown.NewService(...)`. There are no other production types implementing `markdown.Service` (tests call the same factory).

- **construction:** `markdown.NewService` in `internal/markdown/markdown.go` builds the goldmark-backed `service`. At server startup, `NewAPIV1Service` in `server/router/api/v1/v1.go` constructs it with `WithTagExtension()` and `WithMentionExtension()`. `server/server.go` then passes that same instance into `rss.NewRSSService(..., apiV1Service.MarkdownService)`.

- **holders:** Components that store `markdown.Service`:
  - `APIV1Service.MarkdownService` in `server/router/api/v1/v1.go` (primary holder; used from `memo_service.go`, `memo_mention_helpers.go`, `memo_service_webhooks.go`)
  - `RSSService.MarkdownService` in `server/router/rss/rss.go` (injected copy of the API v1 instance)
  - `memopayload.Runner.MarkdownService` in `server/runner/memopayload/runner.go` (field exists, but `NewRunner` is never wired in production; memo payload rebuild receives the interface via `memopayload.RebuildMemoPayload(..., s.MarkdownService)` from `server/router/api/v1/memo_service.go`)
