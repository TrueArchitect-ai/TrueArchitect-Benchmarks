The provider abstraction lives in **`internal/idp`**, which defines the shared `IdentityProviderUserInfo` type used across SSO flows (`internal/idp/idp.go`).

The only shipped concrete protocol implementation is **`internal/idp/oauth2`**, which implements OAuth2 token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`). SSO wiring selects it when the stored provider type is OAuth2 (`server/router/api/v1/auth_service_sso.go`), and `proto/store/idp.proto` defines only `OAUTH2` as a provider type.

**Answer:** `internal/idp`; `internal/idp/oauth2`
