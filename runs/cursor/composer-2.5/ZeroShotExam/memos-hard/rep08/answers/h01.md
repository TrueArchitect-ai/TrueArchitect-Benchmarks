**s3presign.Runner** — **every 12 hours** — **server/server.go:129**

The `s3presign` background runner (`server/runner/s3presign/runner.go`) keeps S3 attachment external links from expiring. It lists S3-stored attachments, and for any whose presigned URL is no longer valid for the next 4 days (URLs are issued with a 5-day lifetime), it calls `CheckAndPresign` to generate a new presigned URL and updates `attachment.Reference` — the field exposed as `ExternalLink` for externally stored attachments (`server/router/api/v1/attachment_service_storage.go:39-40`).

The schedule is defined as `runnerInterval = time.Hour * 12` in `server/runner/s3presign/runner.go:27`, and `Run()` uses a ticker on that interval (`server/runner/s3presign/runner.go:29-40`).

Startup wiring is in `Server.Start()`, which calls `startBackgroundRunners(ctx)` at `server/server.go:129`. That function creates the runner, runs it once immediately via `RunOnce(ctx)` at line 163, then starts the periodic loop in a goroutine at lines 166–169 (`server/server.go:153-174`).
