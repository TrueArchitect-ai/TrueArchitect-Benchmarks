**Premise correction:** This repository does not define a GraphQL schema for the public API. A search across the codebase finds no GraphQL schema files, GraphQL server code, or GraphQL-related dependencies. The README and `AGENTS.md` describe REST and gRPC/Connect RPC APIs instead.

**Actual API surface:** The public API contract is defined in **Protocol Buffers** under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Those `.proto` files are the source of truth. Running `buf generate` (configured in `proto/buf.gen.yaml`) produces:

- **OpenAPI 3 spec:** `proto/gen/openapi.yaml` (embedded for serving via `proto/openapi_embed.go`)
- **Go stubs:** `proto/gen/api/v1/` (Connect, gRPC, gRPC-Gateway)
- **TypeScript types:** `web/src/types/proto/`

The server exposes the API as Connect RPC and REST (gRPC-Gateway) at `/api/v1/...`, wired in `server/router/api/v1/v1.go`. Public/unauthenticated route policy lives in `server/router/api/v1/acl_config.go`.
