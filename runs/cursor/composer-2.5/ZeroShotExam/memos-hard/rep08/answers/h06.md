**handlers (≥3):** `CreateMemo`, `UpdateMemo`, `DeleteMemo` — also `SetMemoAttachments`, `SetMemoRelations`, and `CreateMemoComment`

**convergence function — path:** `Post` — `internal/webhook/webhook.go`

User-configured URLs are stored as per-user webhooks (`WebhooksUserSetting_Webhook.Url`), created via `CreateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`. Memo-related RPC handlers load those URLs and enqueue delivery through `webhook.PostAsync`, which workers drain into the single delivery function `Post`:

| RPC handler | File | Path to `Post` |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `Post` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `Post` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `Post` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | same update path as `UpdateMemo` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | same update path as `UpdateMemo` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync` → `Post` (plus nested `CreateMemo`, which fires its own create webhook) |

The shared dispatch layer is in `server/router/api/v1/memo_service_webhooks.go`, where `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook` set `payload.URL = hook.Url` and call `webhook.PostAsync`. All outbound HTTP to those configured URLs converges in `Post`, which issues the POST via `safeClient.Do(req)`:
