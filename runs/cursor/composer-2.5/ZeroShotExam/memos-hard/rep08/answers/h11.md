**1st: `User`; 2nd: `Memo` (~7 and ~6 packages outside `store/`)**

Persistent entity types live in the `store/` data layer as struct types backed by DB tables. They are declared in files such as `store/user.go`, `store/memo.go`, and `store/attachment.go`, and are enumerated in the `Driver` interface in `store/driver.go` (e.g. “User model related methods”, “Memo model related methods”).

Counting distinct Go packages outside `store/` that reference each entity type via `store.<Type>`:

| Entity type | Packages outside `store/` |
|---|---|
| **`User`** | **7** — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` |
| **`Memo`** | **6** — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` |
| `Attachment` | 4 — `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss` |

Next tier: `Inbox`, `MemoRelation`, `MemoShare`, and `Visibility` at ~3 packages each; `Reaction` and `UserIdentity` at ~2.
