**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no GraphQL schema files or GraphQL server dependencies anywhere in the codebase.

**Actual API surface:** The public API is defined as **Protocol Buffers** under `proto/api/v1/`, with one `.proto` file per service:

- `proto/api/v1/ai_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/common.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/user_service.proto`

Those `.proto` files are the source of truth. Running `buf generate` (configured in `proto/buf.gen.yaml`) produces:

- Go, gRPC, Connect RPC, and gRPC-Gateway code in `proto/gen/`
- OpenAPI 3 spec in `proto/gen/openapi.yaml`
- TypeScript types in `web/src/types/proto/`

The server implements those services under `server/router/api/v1/` (e.g. `connect_handler.go`, `connect_services.go`, and per-service `*_service.go` files). REST paths are declared via `google.api.http` annotations in the proto files (for example, `GET /api/v1/memos` in `proto/api/v1/memo_service.proto`).

Which endpoints are publicly accessible without authentication is configured separately in `server/router/api/v1/acl_config.go` — not in a GraphQL schema.
