h03. `internal/idp`; `internal/idp/oauth2`

The provider abstraction lives in `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) used by SSO sign-in in `server/router/api/v1/auth_service_sso.go`.

The only concrete protocol implementation shipped is OAuth 2 in `internal/idp/oauth2/oauth2.go` (package comment: “implements the OAuth2 identity provider integration”). `resolveSSOIdentity` in `auth_service_sso.go` instantiates it when the stored provider type is `OAUTH2`; the proto definitions in `proto/store/idp.proto` and `proto/api/v1/idp_service.proto` list no other IdP type.
