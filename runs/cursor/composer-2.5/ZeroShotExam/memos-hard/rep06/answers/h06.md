**Handlers (≥3):** `CreateMemo`, `UpdateMemo`, `DeleteMemo` (also `CreateMemoComment`); **convergence function — path:** `Post` — `internal/webhook/webhook.go`

These are RPC methods on `MemoService` in `proto/api/v1/memo_service.proto`, implemented in `server/router/api/v1/memo_service.go` and `server/router/api/v1/memo_service_comments.go`. Each can transitively POST to a user-configured webhook URL stored via `CreateUserWebhook` / `UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`.

| Handler | Implementation | Webhook dispatch |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `DispatchMemoCommentCreatedWebhook`; also calls internal `CreateMemo`, which triggers `DispatchMemoCreatedWebhook` |

Shared dispatch logic lives in `server/router/api/v1/memo_service_webhooks.go`: `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook` load webhooks with `s.Store.GetUserWebhooks`, set `payload.URL = hook.Url`, and call `webhook.PostAsync(payload)`.

All paths converge at **`Post`** in `internal/webhook/webhook.go` — async workers started in `init()` dequeue from `asyncPostQueue` and call `Post`, which builds the HTTP request to `requestPayload.URL` and sends it via `safeClient.Do(req)`:
