**Premise correction:** This repository does not define or schedule a nightly **database-cleanup** job in the cron scheduler, so there is no run time to report.

Evidence:

1. **No such job exists.** A search of the repo finds no job named `database-cleanup` (or similar). The only cleanup-related cron examples in the scheduler package use generic names like `"cleanup"` and `"daily-cleanup"` in documentation and tests, not a database-cleanup job — see `internal/scheduler/example_test.go`, `internal/scheduler/README.md`, and `internal/scheduler/doc.go`.

2. **The cron scheduler is not wired into the running app.** `internal/scheduler/` is a standalone library. It is only imported from its own test files (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`). Neither `cmd/memos/main.go` nor `server/server.go` creates or starts a scheduler or registers any cron jobs.

3. **Background work uses runners, not cron.** The server starts background runners in `server/server.go` (e.g. the S3 presign runner in `server/runner/s3presign/runner.go`, which runs on a 12-hour `time.Ticker`, not a cron expression). That is separate from `internal/scheduler/`.

The closest scheduler examples are illustrative `"cleanup"` / `"daily-cleanup"` jobs with schedule `"0 2 * * *"` (2:00 AM in the scheduler’s default UTC timezone) in `internal/scheduler/example_test.go` and `internal/scheduler/doc.go`, but those are example code only and are not a production database-cleanup job.
