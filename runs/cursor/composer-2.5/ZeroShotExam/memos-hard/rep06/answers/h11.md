1st: **User** (~7 packages); 2nd: **Memo** (~6 packages)

The data layer is `store/` (see `AGENTS.md`). Its persistent entity types are the model structs in files such as `store/user.go`, `store/memo.go`, `store/attachment.go`, and the other `*struct` types wired through the `Driver` interface in `store/driver.go` (`User`, `Memo`, `Attachment`, `IdentityProvider`, `Inbox`, `InstanceSetting`, `MemoRelation`, `MemoShare`, `Reaction`, `UserIdentity`, `UserSetting`).

Counting Go packages outside `store/` that reference each type as `store.<Type>`:

| Rank | Type | Packages (rough count) |
|------|------|------------------------|
| 1 | `User` | ~7 |
| 2 | `Memo` | ~6 |
| 3 | `Attachment` | ~4 |

**User** (~7 packages): `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`

**Memo** (~6 packages): `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Several other entity types (`IdentityProvider`, `InstanceSetting`, `UserSetting`) are not referenced as `store.<Type>` outside the data layer; callers use proto messages from `proto/gen/store/` or go through store methods instead.
