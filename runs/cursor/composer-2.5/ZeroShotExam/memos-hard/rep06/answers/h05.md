**Mechanism:** explicit Go code (not a database-level rule, and not left in place).

When a user is deleted, the store layer runs two explicit `DELETE FROM reaction` steps inside `deleteUserTargetsTx`:
1. **`deleteReactionsByContentIDsTx`** — removes all reactions on that user’s memos (`content_id IN (...)` for `memos/{uid}`).
2. **`deleteReactionsByCreatorTx`** — removes all reactions that user created on other content (`creator_id = userID`).

This is implemented the same way for SQLite, Postgres, and MySQL.
