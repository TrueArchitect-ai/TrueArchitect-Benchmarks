h02.
Post — `internal/webhook/webhook.go`; safeDialContext — `internal/webhook/webhook.go`

Outbound HTTP delivery runs in `Post`, which builds the POST request and sends it via `safeClient.Do(req)`. Content-change handlers (for example in `server/router/api/v1/memo_service_webhooks.go`) enqueue work with `PostAsync`, and worker goroutines started in `init()` drain that queue and call `Post`.

SSRF protection at delivery time is enforced by `safeDialContext`, registered as the `DialContext` on `safeClient`'s transport. Before connecting, it resolves the hostname and rejects any address that falls in a reserved/private range via `isReservedIP` (defined in `internal/webhook/validate.go`). There is also config-time blocking in `ValidateURL` (`internal/webhook/validate.go`) when webhook URLs are created or updated.
