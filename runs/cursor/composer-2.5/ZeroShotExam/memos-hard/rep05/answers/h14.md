**Computation site:** Content is parsed once with goldmark in `internal/markdown/markdown.go` (`ExtractAll`; same logic also exists as `ExtractTags` and `ExtractProperties`). Results are written to the stored `MemoPayload` in `server/runner/memopayload/runner.go` via `RebuildMemoPayload`, which calls `markdownService.ExtractAll` and sets `memo.Payload.Tags` and `memo.Payload.Property`. List/preview **snippets** are derived separately at API conversion time in `server/router/api/v1/memo_service_webhooks.go` (`getMemoContentSnippet` → `MarkdownService.GenerateSnippet` in `internal/markdown/markdown.go`), used from `server/router/api/v1/memo_service_converter.go`.

**Triggers:** `memopayload.RebuildMemoPayload` runs on **CreateMemo** (`server/router/api/v1/memo_service.go`, before persist) and on **UpdateMemo** only when the update mask includes `"content"` (same file). **CreateMemoComment** triggers it indirectly by calling `CreateMemo`. `memopayload.Runner.RunOnce` in `server/runner/memopayload/runner.go` can batch-rebuild all memos; it is not started from `server/server.go` in this repo.

**Extracted properties:** Stored on `MemoPayload` (`proto/store/memo.proto`, exposed as API `Memo.tags` / `Memo.property` in `proto/api/v1/memo_service.proto`):

- **`tags`:** `#tag` tokens from the custom tag extension (`internal/markdown/parser/tag.go`), excluding tags inside links/images, deduplicated with case preserved.
- **`property`:** `has_link` (link nodes), `has_code` (code block / fenced block / inline code), `has_task_list` (GFM task checkboxes), `has_incomplete_tasks` (unchecked tasks), `title` (plain text of the first document-level H1 heading, if any).

`MemoPayload.location` is user-supplied on create/update, not content-derived. **`snippet`** (plain-text summary for previews) is computed from content on read, not stored in `MemoPayload`.
