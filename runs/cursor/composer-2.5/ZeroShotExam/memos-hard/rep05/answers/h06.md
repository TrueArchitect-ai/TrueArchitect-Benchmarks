**handlers (≥3); convergence function — path**

**Handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo` (also `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`)

**Convergence function:** `Post` — `/bench/repo/internal/webhook/webhook.go`

**Paths:**

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go`) → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go`) → loads user webhooks via `Store.GetUserWebhooks`, sets `payload.URL = hook.Url` → `webhook.PostAsync` → worker goroutine → **`Post`** → `http.NewRequest("POST", requestPayload.URL, ...)` + `safeClient.Do(req)`

2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go`) → `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go`) → `DispatchMemoUpdatedWebhook` → same `dispatchMemoRelatedWebhook` → `PostAsync` → **`Post`**

3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go`) → `DispatchMemoDeletedWebhook` → same `dispatchMemoRelatedWebhook` → `PostAsync` → **`Post`**

User-configured URLs are stored per user (via `UserService` webhook RPCs in `server/router/api/v1/user_service_webhooks.go`) and read at dispatch time in `memo_service_webhooks.go`. All webhook paths enqueue through `PostAsync` (`internal/webhook/webhook.go:184`) and converge in **`Post`** (`internal/webhook/webhook.go:120`), which performs the outbound HTTP POST to `requestPayload.URL`.
