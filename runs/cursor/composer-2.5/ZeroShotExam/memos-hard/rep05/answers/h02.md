h02.
Post — `internal/webhook/webhook.go`; safeDialContext — `internal/webhook/webhook.go`

When memo content changes, handlers in `server/router/api/v1/memo_service_webhooks.go` enqueue payloads via `webhook.PostAsync`. Background workers started in `init()` dequeue those payloads and call `Post`, which performs the outbound HTTP POST through `safeClient.Do(req)`.

`safeDialContext` is wired into that client’s `Transport.DialContext`. Before connecting, it resolves the hostname and rejects any address in reserved/private ranges (loopback, RFC 1918, link-local/IMDS, etc.) via `isReservedIP`, blocking SSRF and DNS rebinding at dial time. Webhook URLs are also checked at create/update time by `ValidateURL` in `internal/webhook/validate.go`, which uses the same `isReservedIP` logic.
