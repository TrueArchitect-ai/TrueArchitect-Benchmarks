**Premise correction:** This repository does not define a GraphQL schema for the public API. A repo-wide search finds no GraphQL references; `README.md` describes REST and gRPC APIs, and `AGENTS.md` documents Connect RPC, gRPC-Gateway, and Protocol Buffers — not GraphQL.

**Actual API surface:** The public API is defined as Protocol Buffer services under `proto/api/v1/`:

- `auth_service.proto`
- `user_service.proto`
- `memo_service.proto`
- `attachment_service.proto`
- `instance_service.proto`
- `ai_service.proto`
- `shortcut_service.proto`
- `idp_service.proto`
- `common.proto`

Those `.proto` files are the source of truth. `cd proto && buf generate` (configured in `proto/buf.gen.yaml`) produces:

- Go stubs and gateway code in `proto/gen/api/v1/`
- TypeScript types in `web/src/types/proto/`
- An OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)

The services are implemented in `server/router/api/v1/` and registered in `server/router/api/v1/v1.go` as Connect RPC and gRPC-Gateway REST handlers under `/api/v1/*`.
