h03. internal/idp; internal/idp/oauth2

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type used across IdP integrations (`internal/idp/idp.go`). The only concrete protocol implementation shipped is OAuth2 in `internal/idp/oauth2`, whose package comment states it “implements the OAuth2 identity provider integration” (`internal/idp/oauth2/oauth2.go`). SSO auth wires that implementation in when the stored provider type is `OAUTH2` (`server/router/api/v1/auth_service_sso.go`), and `proto/store/idp.proto` lists OAuth2 as the sole supported IdP type.
