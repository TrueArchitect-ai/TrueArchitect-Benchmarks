h11.

The data layer is the `store/` package (see `AGENTS.md`). Its persistent entity types are the row structs wired through the `Driver` interface in `store/driver.go`: `Attachment`, `Memo`, `MemoRelation`, `InstanceSetting`, `User`, `UserSetting`, `IdentityProvider`, `Inbox`, `Reaction`, `MemoShare`, and `UserIdentity`. They correspond to the tables in `store/migration/sqlite/LATEST.sql` (`user`, `memo`, `attachment`, etc.).

Counting Go packages **outside** `store/` that reference each type as `store.<Type>`:

| Entity | Packages outside `store/` |
|---|---|
| **User** | ~7 |
| **Memo** | ~6 |
| Attachment | ~4 |
| Inbox, MemoRelation, MemoShare | ~3 each |
| Reaction, UserIdentity | ~2 each |
| IdentityProvider, InstanceSetting, UserSetting | 0 |

**1st: User (~7 packages); 2nd: Memo (~6 packages)**

`User` is defined in `store/user.go` and referenced from seven non-store packages, including `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, and `server/router/rss` (e.g. `*store.User` in `server/router/api/v1/instance_service.go`).

`Memo` is defined in `store/memo.go` and referenced from six non-store packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, and `server/runner/memopayload`.

Several other entity types (`IdentityProvider`, `InstanceSetting`, `UserSetting`) are defined in the data layer (`store/idp.go`, `store/instance_setting.go`, `store/user_setting.go`) but are exposed to outer layers mainly as protobuf types (`storepb.*`), so they do not appear as `store.<Type>` references outside `store/`.
