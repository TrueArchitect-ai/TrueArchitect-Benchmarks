**Computation site:** `internal/markdown/markdown.go` — goldmark parses memo markdown and walks the AST in `ExtractProperties` / `ExtractAll` to populate `storepb.MemoPayload_Property`. That value is written to the memo payload by `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go` (which calls `ExtractAll`).

**Triggers:** Recomputation runs when `memopayload.RebuildMemoPayload` is called from `server/router/api/v1/memo_service.go` on **CreateMemo** (line 108, including comments created via `CreateMemoComment`, which delegates to `CreateMemo`) and on **UpdateMemo** only when the update mask includes `"content"` (line 447). There is also a batch utility `memopayload.Runner.RunOnce` in `server/runner/memopayload/runner.go` that rebuilds payloads for all memos, but it is not wired into server startup in this repo.

**Extracted properties** (defined in `proto/store/memo.proto` as `MemoPayload.Property`, exposed as output-only `Memo.property` in `proto/api/v1/memo_service.proto`):

| Property | Source in markdown AST |
|---|---|
| `has_link` | Any link node (`KindLink`) |
| `has_code` | Code block, fenced code block, or inline code span |
| `has_task_list` | GFM task checkbox node |
| `has_incomplete_tasks` | Unchecked task checkbox |
| `title` | Plain text of the first block-level H1 heading, if present |
