**Mechanism:** explicit Go code (not database-level rules).

When a user is deleted, emoji reactions are removed in application code inside the `DeleteUser` transaction, via two helpers in each DB driver:

1. **`deleteReactionsByContentIDsTx`** — `DELETE FROM reaction WHERE content_id IN (...)` for all memos owned by the deleted user (removes every reaction on those memos, including from other users).
2. **`deleteReactionsByCreatorTx`** — `DELETE FROM reaction WHERE creator_id = ?` (removes all reactions the deleted user placed on any memo, including others’ memos).
