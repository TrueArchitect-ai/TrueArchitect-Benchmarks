**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no `.graphql` files and no GraphQL references in the codebase. Memos exposes its public API through Protocol Buffers, not GraphQL.

**Actual API surface:** The public API is defined in **`proto/api/v1/`** as `.proto` service files:

- `proto/api/v1/ai_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/common.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/user_service.proto`

`AGENTS.md` identifies `proto/api/v1/` as the public API service definitions. Running `buf generate` (configured in `proto/buf.gen.yaml`) produces:

- Go, gRPC, Connect, and gRPC-Gateway code under `proto/gen/api/v1/`
- An OpenAPI 3 spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)
- TypeScript types under `web/src/types/proto/`

Those protos are served by Connect RPC and gRPC-Gateway REST handlers in `server/router/api/v1/` (e.g. `connect_handler.go`). REST paths come from `google.api.http` annotations in the proto files (e.g. `POST /api/v1/memos` in `proto/api/v1/memo_service.proto`).

Which endpoints are publicly reachable without authentication is configured separately in `server/router/api/v1/acl_config.go` via the `PublicMethods` map — not in a GraphQL schema.
