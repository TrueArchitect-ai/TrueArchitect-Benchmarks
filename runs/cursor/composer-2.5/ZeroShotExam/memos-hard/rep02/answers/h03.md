h03.
`internal/idp`; `internal/idp/oauth2`

The provider abstraction lives in `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows. The only shipped concrete protocol implementation is `internal/idp/oauth2`, whose package comment and `IdentityProvider` type implement OAuth2 token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`). SSO wiring in `server/router/api/v1/auth_service_sso.go` imports both packages and handles only the `OAUTH2` provider type via `oauth2.NewIdentityProvider`.
