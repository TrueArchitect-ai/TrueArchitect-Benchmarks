**impl — construction — holders**

- **impl:** The unexported `service` struct in `internal/markdown/markdown.go` is the sole concrete type implementing `markdown.Service`; it wraps a goldmark parser/renderer configured with GFM plus optional tag/mention extensions.
- **construction:** At runtime it is created once by `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` inside `NewAPIV1Service` in `server/router/api/v1/v1.go` (called from `server/server.go`).
- **holders:** The live instance is stored on `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go`) and passed into `RSSService.MarkdownService` via `rss.NewRSSService(..., apiV1Service.MarkdownService)` in `server/server.go` / `server/router/rss/rss.go`. Other call sites (`server/router/api/v1/memo_service.go`, `memo_mention_helpers.go`, `memo_service_webhooks.go`, and `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go`) take the interface as a parameter from `APIV1Service` rather than holding their own copy. `memopayload.Runner` declares a `MarkdownService` field but `NewRunner` is not invoked in production startup code. Tests construct a separate instance in `server/router/api/v1/test/test_helper.go`.
