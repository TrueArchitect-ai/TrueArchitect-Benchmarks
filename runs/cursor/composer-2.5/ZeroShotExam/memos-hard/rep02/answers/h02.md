**Post** — `/bench/repo/internal/webhook/webhook.go`; **safeDialContext** (via `isReservedIP` / `reservedCIDRs`) — `/bench/repo/internal/webhook/webhook.go` and `/bench/repo/internal/webhook/validate.go`

When memo content changes, dispatch is triggered from `/bench/repo/server/router/api/v1/memo_service_webhooks.go`, which enqueues payloads with `webhook.PostAsync`. Background workers in `init()` drain that queue and call **`Post`**, which performs the outbound HTTP POST via `safeClient.Do(req)` in `/bench/repo/internal/webhook/webhook.go`.

SSRF protection against internal/reserved addresses happens in two places:

1. **At delivery time:** `safeClient` uses a custom `http.Transport` whose `DialContext` is **`safeDialContext`**. It resolves the target host and rejects any address in a reserved/private range via **`isReservedIP`**, which checks against **`reservedCIDRs`** (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local) in `/bench/repo/internal/webhook/validate.go`. That dial-time check also mitigates DNS rebinding.

2. **At URL registration:** **`ValidateURL`** in `/bench/repo/internal/webhook/validate.go` applies the same `isReservedIP` check when webhook URLs are created or updated (called from `/bench/repo/server/router/api/v1/user_service_webhooks.go`).

Both checks honor the `AllowPrivateIPs` flag (set from `--allow-private-webhooks` in `/bench/repo/cmd/memos/main.go`), which disables SSRF blocking for self-hosted setups.
