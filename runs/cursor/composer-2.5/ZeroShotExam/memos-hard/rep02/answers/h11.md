The data layer is the `store/` package (`store/*.go`), which defines 11 table-backed persistent entity types (`User`, `UserSetting`, `UserIdentity`, `Memo`, `MemoRelation`, `MemoShare`, `Attachment`, `Reaction`, `Inbox`, `IdentityProvider`, `InstanceSetting`).

Counting distinct Go packages outside `store/` that import `github.com/usememos/memos/store` and reference each entity type (e.g. `store.Memo`, `*store.User`, `store.FindMemo`, …):

**1st: Memo; 2nd: User (~7 external packages each)**

They tie for the most references. Packages that reference each:

| Entity | External packages (~count) |
|---|---|
| **Memo** | `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` (**7**) |
| **User** | `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` (**7**) |

Next is **Attachment** at ~5 packages (`server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`, `server/runner/s3presign`).

Entity definitions live in files such as `store/memo.go` and `store/user.go`; the layer is documented in `AGENTS.md` under the `store/` code map entry.
