**Handlers (≥3):** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` (all on `APIV1Service` in `server/router/api/v1/`, exposed via `ConnectServiceHandler` in `server/router/api/v1/connect_services.go`)

**Convergence function:** `webhook.PostAsync` — `internal/webhook/webhook.go`

These handlers load user webhook URLs from settings (`hook.Url` via `Store.GetUserWebhooks`) and enqueue outbound POSTs. The call chains are:

| Handler | Path to convergence |
|---|---|
| `CreateMemo` | `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` (`server/router/api/v1/memo_service.go` → `memo_service_webhooks.go`) |
| `UpdateMemo` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` (`memo_update_helpers.go` → `memo_service_webhooks.go`) |
| `DeleteMemo` | `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` (`memo_service.go` → `memo_service_webhooks.go`) |
| `CreateMemoComment` | `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync` (`memo_service_comments.go` → `memo_service_webhooks.go`) |
| `SetMemoAttachments` | `dispatchMemoUpdatedSideEffects` → … → `webhook.PostAsync` (`memo_attachment_service.go`) |
| `SetMemoRelations` | `dispatchMemoUpdatedSideEffects` → … → `webhook.PostAsync` (`memo_relation_service.go`) |

In `internal/webhook/webhook.go`, `PostAsync` is the single entry point where all handler paths merge; worker goroutines then call `Post`, which performs the actual outbound HTTP request via `safeClient.Do(req)` to the user-configured webhook URL.
