**internal/idp; internal/idp/oauth2**

The provider abstraction lives in `internal/idp`, which defines the shared `IdentityProviderUserInfo` type in `internal/idp/idp.go`. The only concrete protocol implementation shipped is OAuth2 in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go` implements token exchange and userinfo retrieval).

That wiring is used at sign-in time in `server/router/api/v1/auth_service_sso.go`, which dispatches on `IdentityProvider_OAUTH2` and calls `oauth2.NewIdentityProvider(...)`. The proto schema in `proto/store/idp.proto` also defines only `OAUTH2` as a provider type, with no other implementations under `internal/idp/`.
