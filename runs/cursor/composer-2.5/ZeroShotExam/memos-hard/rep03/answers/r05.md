**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no `.graphql`/`.gql` files and no GraphQL references anywhere in the codebase.

**Actual API surface:** The public API is defined as Protocol Buffers in `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`). Those `.proto` files are the source of truth; `proto/buf.gen.yaml` drives code generation into Go, Connect RPC handlers, gRPC-Gateway REST mappings, TypeScript types, and an OpenAPI document.

The generated REST/OpenAPI contract lives at `proto/gen/openapi.yaml` (embedded at runtime via `proto/openapi_embed.go`). HTTP handlers are wired in `server/router/api/v1/` — notably `connect_handler.go` (Connect RPC) and `v1.go` (`RegisterGateway` for gRPC-Gateway REST under `/api/v1/*`). The server registers that gateway in `server/server.go`. The MCP layer in `server/router/mcp/` also consumes the generated OpenAPI spec, not GraphQL.
