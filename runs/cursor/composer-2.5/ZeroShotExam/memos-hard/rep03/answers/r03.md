There is no nightly **database-cleanup** job scheduled in this repository’s cron scheduler.

The cron scheduler lives in `internal/scheduler/` (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`), but nothing in the application startup path registers or starts it:

- `cmd/memos/main.go` starts the server and does not import or initialize `internal/scheduler`.
- `server/server.go` only starts the S3 presign background runner in `startBackgroundRunners()`; it does not create a `scheduler.New()` instance or register any cron jobs.

A repo-wide search finds no job named `database-cleanup` (or similar) registered with `scheduler.Register`. The only cleanup-related cron examples are illustrative, not production wiring:

- `internal/scheduler/doc.go` and `internal/scheduler/README.md` show a generic `"daily-cleanup"` example with schedule `"0 2 * * *"` (2:00 AM).
- `internal/scheduler/example_test.go` registers a test job named `"cleanup"` with the same `"0 2 * * *"` schedule.

Those are documentation/test examples, not a deployed nightly database-cleanup job.
