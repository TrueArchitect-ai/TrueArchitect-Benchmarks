**Handlers (≥3):** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` — all on `APIV1Service` in `server/router/api/v1/`.

**Convergence function — path:** `webhook.Post` — `internal/webhook/webhook.go`

These RPC handlers trigger memo webhook dispatch, which loads user-configured webhook URLs from settings (`Store.GetUserWebhooks`, `hook.Url` in `server/router/api/v1/memo_service_webhooks.go`) and enqueues them via `webhook.PostAsync`. Background workers in `internal/webhook/webhook.go` drain that queue and all paths converge in `webhook.Post`, which builds the POST to `requestPayload.URL` and sends it with `safeClient.Do(req)`.

| Handler | File | Chain to convergence |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `webhook.PostAsync` → `webhook.Post` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | (via internal `CreateMemo`) + `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync` → `webhook.Post` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `dispatchMemoUpdatedSideEffects` → … → `webhook.Post` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `dispatchMemoUpdatedSideEffects` → … → `webhook.Post` |

Webhook CRUD handlers in `server/router/api/v1/user_service_webhooks.go` only store or validate URLs; they do not perform outbound HTTP to them.
