h03.
internal/idp; internal/idp/oauth2

The provider abstraction lives in [`internal/idp/idp.go`](internal/idp/idp.go), which defines the shared `IdentityProviderUserInfo` type used by protocol-specific integrations. The only shipped concrete protocol implementation is OAuth2 in [`internal/idp/oauth2/oauth2.go`](internal/idp/oauth2/oauth2.go), which implements token exchange and user-info retrieval and is wired into SSO sign-in in [`server/router/api/v1/auth_service_sso.go`](server/router/api/v1/auth_service_sso.go) when the IdP type is `OAUTH2` (the sole non-unspecified type in [`proto/store/idp.proto`](proto/store/idp.proto)).
