**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no `.graphql` files and no GraphQL references anywhere in the codebase. The question assumes GraphQL, but Memos does not use it.

**Actual API surface:** The public API is defined as **Protocol Buffers** under `proto/api/v1/`, in files such as:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

`AGENTS.md` identifies `proto/api/v1/` as the public API service definitions. Running `buf generate` (configured in `proto/buf.gen.yaml`) produces Go clients/servers, Connect RPC bindings, gRPC-Gateway REST mappings, and an OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).

The HTTP/RPC handlers that implement those services live in `server/router/api/v1/`. Which endpoints are callable without authentication is configured separately in `server/router/api/v1/acl_config.go` — that file lists public methods, but it is not where the API schema itself is defined.
