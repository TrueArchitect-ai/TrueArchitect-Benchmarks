**Premise correction:** This repository does not define or schedule a nightly job named `database-cleanup` in the cron scheduler.

The cron scheduler lives in `internal/scheduler/`, but nothing in the running app registers or starts it. `server/server.go` only starts the S3 presign background runner (`server/runner/s3presign/`); `cmd/memos/main.go` does not import or use `internal/scheduler` at all. A repo-wide search finds no job named `database-cleanup` (or `database_cleanup` / `DatabaseCleanup`).

The only cleanup-related cron schedules are **documentation and test examples**, not production jobs:

- `internal/scheduler/README.md` and `internal/scheduler/doc.go` show an example job named `daily-cleanup` with schedule `0 2 * * *` (2:00 AM daily, UTC by default).
- `internal/scheduler/example_test.go` registers an example job named `cleanup` with the same `0 2 * * *` schedule.

So there is no answer to “what time is the nightly database-cleanup job scheduled?” because that job does not exist in this codebase. The closest related material is the illustrative `daily-cleanup` / `cleanup` examples at **2:00 AM** (`0 2 * * *`) in those scheduler docs and examples.
