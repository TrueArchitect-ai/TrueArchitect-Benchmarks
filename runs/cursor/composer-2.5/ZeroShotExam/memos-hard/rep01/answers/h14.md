**Computation site:** Derived memo metadata is built in `server/runner/memopayload/runner.go` (`RebuildMemoPayload`), which calls `internal/markdown/markdown.go` (`ExtractAll`) to walk the goldmark AST in one pass and write results into `store.Memo.Payload` (`proto/store/memo.proto`).

**Triggers:** Recomputation runs on `CreateMemo` (always, before persist) and on `UpdateMemo` only when the update mask includes `"content"` — both in `server/router/api/v1/memo_service.go`. `memopayload.Runner.RunOnce` in `server/runner/memopayload/runner.go` can batch-rebuild all memos, but it is not wired into server startup in this repo.

**Extracted properties:** `MemoPayload.tags` (`#tag` tokens, excluding tags inside links/images) and `MemoPayload.property` (`has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks`, and `title` from the first block-level H1). These are exposed as output-only API fields in `proto/api/v1/memo_service.proto` (`tags`, `property`).

**Note:** `snippet` (plain-text preview, max 64 chars via `GenerateSnippet` in `server/router/api/v1/memo_service_webhooks.go`) is also content-derived for lists/previews, but it is computed at read/convert time in `server/router/api/v1/memo_service_converter.go`, not stored in `MemoPayload` or rebuilt by `RebuildMemoPayload`.
