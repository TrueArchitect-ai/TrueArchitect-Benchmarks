**Premise correction:** This repository does not configure a Redis connection for the cache layer. There are no Redis references in the codebase or in `go.mod`; caching is entirely in-process memory.

**Actual mechanism:** The store cache is wired in `store/store.go` when `New()` builds three `cache.Cache` instances (including `userCache`) from a shared `cache.Config`:
