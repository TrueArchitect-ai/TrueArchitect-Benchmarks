**Post** — `internal/webhook/webhook.go`; **safeDialContext** — `internal/webhook/webhook.go`

When content changes, dispatch is queued from `server/router/api/v1/memo_service_webhooks.go` via `webhook.PostAsync`, but the actual outbound HTTP POST runs in **`Post`**, which sends the request with `safeClient.Do(req)` (`internal/webhook/webhook.go`).

That client’s transport uses **`safeDialContext`**, which resolves the target host and rejects any address in a reserved/private range via **`isReservedIP`** (defined in `internal/webhook/validate.go`). That blocks SSRF and DNS rebinding at dial time. Webhook URLs are also checked at registration time by **`ValidateURL`** in `internal/webhook/validate.go`.
