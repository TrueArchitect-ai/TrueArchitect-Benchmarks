**CreateMemo**, **UpdateMemo**, **DeleteMemo**, **CreateMemoComment**, **SetMemoAttachments**, and **SetMemoRelations** can all transitively trigger outbound HTTP to a user-configured webhook URL (stored via `CreateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`):

- `CreateMemo` → `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service.go` → `server/router/api/v1/memo_service_webhooks.go`)
- `UpdateMemo`, `SetMemoAttachments`, `SetMemoRelations` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go`, `server/router/api/v1/memo_attachment_service.go`, `server/router/api/v1/memo_relation_service.go`)
- `DeleteMemo` → `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service.go`)
- `CreateMemoComment` → `DispatchMemoCommentCreatedWebhook` (and also `CreateMemo` internally, which can fire `DispatchMemoCreatedWebhook`) (`server/router/api/v1/memo_service_comments.go`)

**Convergence:** `webhook.PostAsync` — `internal/webhook/webhook.go` (all dispatch paths set `payload.URL` from the user’s stored webhook and call `PostAsync`; worker goroutines in the same file then call `Post`, which performs the HTTP POST).
