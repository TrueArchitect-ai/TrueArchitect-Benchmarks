h02.
Post — `internal/webhook/webhook.go`; safeDialContext — `internal/webhook/webhook.go`

When content changes (memo create/update/delete/comment), dispatch code in `server/router/api/v1/memo_service_webhooks.go` enqueues payloads via `webhook.PostAsync`. Background workers started in `init()` dequeue those payloads and call `Post`, which performs the outbound HTTP POST through `safeClient.Do(req)`.

SSRF protection at delivery time is in `safeDialContext`, the custom `DialContext` on `safeClient`'s transport. Before connecting, it resolves the target hostname and rejects any address in a reserved/private range via `isReservedIP` (defined in `internal/webhook/validate.go` against `reservedCIDRs` such as loopback, RFC 1918, and link-local). That blocks internal targets even if DNS changes after the webhook URL was registered.

Webhook URLs are also checked at registration time by `ValidateURL` in `internal/webhook/validate.go`, but the dial-time guard in `safeDialContext` is what protects the actual outbound request.
