**Premise correction:** This repository does not define a GraphQL schema for the public API. There are no `.graphql` files and no GraphQL server or client usage in the codebase; the README and `AGENTS.md` describe the backend as Connect RPC, gRPC-Gateway, and Protocol Buffers, not GraphQL.

**Actual API surface:** The public API contract is defined in Protocol Buffer service files under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`). Those `.proto` files are the source of truth; they are generated via `buf generate` (`proto/buf.gen.yaml`) into:

- **REST/OpenAPI schema:** `proto/gen/openapi.yaml` (generated by `protoc-gen-openapi`)
- **Go gRPC/Connect/gRPC-Gateway stubs:** `proto/gen/api/v1/`
- **TypeScript types:** `web/src/types/proto/`

The generated OpenAPI spec is embedded at runtime in `proto/openapi_embed.go` (which embeds `proto/gen/openapi.yaml`), and HTTP handlers for the public API live in `server/router/api/v1/` (with unauthenticated routes listed in `server/router/api/v1/acl_config.go`).
