The data layer is `store/` (see `AGENTS.md`). Persistent entity types are Go structs defined there, e.g. `User` in `store/user.go` and `Memo` in `store/memo.go`. Other primary entities include `Attachment`, `Inbox`, `MemoRelation`, `MemoShare`, `Reaction`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`, and `UserSetting` in their respective `store/*.go` files.

Counting distinct Go packages outside `store/` that reference each type as `store.<Type>`:

**1st: `User`; 2nd: `Memo` (~7 and ~6 packages)**
