h03.
`github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`

The provider abstraction lives in `internal/idp/idp.go`, which defines the shared `IdentityProviderUserInfo` type used across SSO flows (for example in `server/router/api/v1/auth_service_sso.go`).

The only shipped protocol implementation is OAuth2 in `internal/idp/oauth2/oauth2.go` (package comment: “implements the OAuth2 identity provider integration”). That matches the proto model in `proto/store/idp.proto`, where `IdentityProvider.Type` only defines `OAUTH2` (value `1`), and SSO resolution in `auth_service_sso.go` instantiates `oauth2.NewIdentityProvider` when the provider type is OAuth2.
