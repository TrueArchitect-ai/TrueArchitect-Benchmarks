**Premise correction:** This repository does **not** register any per-user API rate-limiting middleware, and there are no per-user API request limits defined in the codebase.

What is registered instead:

- **Global Echo middleware** in `server/server.go`: `middleware.Recover()` and CORS via `newCORSMiddleware()` (`server/cors.go`).
- **API auth middleware** (not rate limiting) in `server/router/api/v1/v1.go`:
  - `gatewayAuthMiddleware` on the gRPC-Gateway mux
  - Connect interceptors: `MetadataInterceptor`, `LoggingInterceptor`, `RecoveryInterceptor`, and `AuthInterceptor` (`server/router/api/v1/connect_interceptors.go`)
- **Request body size cap** (not a rate limit): `http.MaxBytesHandler(..., maxAPIRequestBytes)` with `maxAPIRequestBytes = 256 << 20` (256 MiB) in `server/router/api/v1/v1.go`.

The only rate-limiting reference is a **suggested** email-sending limit in `internal/email/README.md` (10 emails/second via `golang.org/x/time/rate`); it is documentation only and is not wired into the API stack.
