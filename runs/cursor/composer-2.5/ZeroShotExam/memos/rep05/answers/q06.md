**memo_relation**

Links between memos are stored in the `memo_relation` table, defined in `store/migration/sqlite/LATEST.sql` (and the equivalent Postgres/MySQL migrations). It has `memo_id`, `related_memo_id`, and `type` columns:

```46:52:store/migration/sqlite/LATEST.sql
-- memo_relation
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The Go store layer in `store/memo_relation.go` models these links with types such as `REFERENCE` and `COMMENT`.
