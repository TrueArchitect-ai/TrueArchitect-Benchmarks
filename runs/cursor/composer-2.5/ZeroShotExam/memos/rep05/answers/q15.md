- user: User — store/user.go
- attachment: Attachment — store/attachment.go
- reaction: Reaction — store/reaction.go

These are the domain structs in the `store` package. The database drivers (`store/db/sqlite`, `store/db/postgres`, `store/db/mysql`) read and write them with raw SQL against the `user`, `attachment`, and `reaction` tables. There are no separate ORM model structs for those tables elsewhere in the repo.
