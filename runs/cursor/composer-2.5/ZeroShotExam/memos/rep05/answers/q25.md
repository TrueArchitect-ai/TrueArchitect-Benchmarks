CEL (Common Expression Language, parsed via `github.com/google/cel-go/cel`) + `internal/filter/` (engine: `internal/filter/engine.go`; parser: `internal/filter/parser.go`; SQL renderer: `internal/filter/render.go`; schema: `internal/filter/schema.go`; invoked from each dialect’s memo store, e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go` via `filter.AppendConditions`); `Compile` uses cel-go to parse/compile the filter string into a CEL AST, `parser.go` lowers that AST into a dialect-agnostic condition IR, and `render.go` walks the IR with the target dialect (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`) to emit parameterized SQL fragments that are appended to the query’s WHERE clause.
