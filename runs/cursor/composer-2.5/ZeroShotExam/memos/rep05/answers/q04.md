**APIV1Service.SignIn** — `server/router/api/v1/auth_service.go`

The `AuthService.SignIn` RPC is implemented on `APIV1Service` at line 51 of that file. It performs password and SSO authentication and returns tokens.

There is also a thin Connect wrapper, `ConnectServiceHandler.SignIn`, in `server/router/api/v1/connect_services.go` (lines 78–81), but it only delegates to `APIV1Service.SignIn` and does not contain the sign-in logic itself.
