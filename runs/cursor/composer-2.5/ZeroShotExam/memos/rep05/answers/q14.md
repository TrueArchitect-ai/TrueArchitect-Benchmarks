`ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` with five RPCs. All are implemented on `APIV1Service` in `server/router/api/v1/shortcut_service.go`:

| RPC | Implementing file |
|-----|-------------------|
| `ListShortcuts` | `server/router/api/v1/shortcut_service.go` |
| `GetShortcut` | `server/router/api/v1/shortcut_service.go` |
| `CreateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `UpdateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `DeleteShortcut` | `server/router/api/v1/shortcut_service.go` |

The RPC definitions are in `proto/api/v1/shortcut_service.proto` (lines 14–51). The handler methods are in `server/router/api/v1/shortcut_service.go` (e.g. `ListShortcuts` at line 49, `GetShortcut` at line 95, `CreateShortcut` at line 135, `UpdateShortcut` at line 211, `DeleteShortcut` at line 284).

`server/router/api/v1/connect_services.go` also has Connect wrappers for these RPCs, but they only delegate to `APIV1Service`; the actual backend logic lives in `shortcut_service.go`.
