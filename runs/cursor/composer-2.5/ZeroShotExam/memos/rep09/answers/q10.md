store/migration/sqlite/LATEST.sql

For an uninitialized SQLite database, the migrator applies this single file via `preMigrate` in `store/migrator.go`, which reads `migration/sqlite/LATEST.sql` (embedded as `store/migration/sqlite/LATEST.sql`) instead of running incremental migrations. The file contains the full current schema (CREATE TABLE statements, indexes, etc.). `store/seed/sqlite/01__dump.sql` is demo seed data only, not the schema.
