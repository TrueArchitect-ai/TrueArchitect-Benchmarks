memos.memo.updated: DispatchMemoUpdatedWebhook  
memos.memo.deleted: DispatchMemoDeletedWebhook  
memos.memo.comment.created: DispatchMemoCommentCreatedWebhook  

Delivery convergence: all four call `webhook.PostAsync` in `internal/webhook/webhook.go`, which enqueues payloads; worker goroutines in that file’s `init()` then call `webhook.Post` for the actual HTTP delivery.

**Sources**

- Dispatch functions and activity types: `server/router/api/v1/memo_service_webhooks.go`
- Created: `CreateMemo` → `DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service.go`
- Updated: `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` in `server/router/api/v1/memo_update_helpers.go` (also from attachment/relation updates)
- Deleted: `DeleteMemo` → `DispatchMemoDeletedWebhook` in `server/router/api/v1/memo_service.go`
- Comment created: `CreateMemoComment` → `DispatchMemoCommentCreatedWebhook` in `server/router/api/v1/memo_service_comments.go`
- Delivery: `PostAsync` / `Post` in `internal/webhook/webhook.go`
