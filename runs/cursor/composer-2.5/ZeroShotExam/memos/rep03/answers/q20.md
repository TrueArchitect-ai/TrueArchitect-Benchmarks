**SSE (Server-Sent Events)**; **`server/router/api/v1/sse_hub.go`**; **CreateMemo, UpdateMemo, DeleteMemo, SetMemoAttachments, SetMemoRelations, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction**

The server uses **Server-Sent Events**: clients connect to `/api/v1/sse` (registered in `server/router/api/v1/sse_handler.go`), which streams `text/event-stream` payloads. The pub/sub hub is the `SSEHub` type in `server/router/api/v1/sse_hub.go`; it subscribes clients and broadcasts JSON `SSEEvent` objects via `SSEHub.Broadcast`.

MemoService handlers that broadcast through it:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go`) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `UpsertMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.upserted` |
| `DeleteMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.deleted` |

The browser client consumes these events in `web/src/hooks/useLiveMemoRefresh.ts`.
