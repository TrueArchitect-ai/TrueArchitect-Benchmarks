**Driver** — `store/driver.go`

The `Driver` interface is the contract every database backend must satisfy. It is declared in `store/driver.go` with the comment that it “contains all methods that store database driver should implement.” The MySQL, PostgreSQL, and SQLite backends in `store/db/mysql`, `store/db/postgres`, and `store/db/sqlite` all return `store.Driver` from their `NewDB` functions, and `store/db/db.go` selects among them via `NewDBDriver`.
