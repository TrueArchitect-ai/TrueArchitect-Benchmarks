**Runners/workers the server process starts**

- **S3 presign runner** (`server/runner/s3presign/runner.go`) — immediate `RunOnce` at startup, then a **12-hour `time.NewTicker`** loop; started from `Server.startBackgroundRunners()` in `server/server.go`
- **Webhook async workers (×4)** (`internal/webhook/webhook.go`) — **channel queue consumer** on `asyncPostQueue`; work is enqueued by `webhook.PostAsync()` when memo webhooks are dispatched (`server/router/api/v1/memo_service_webhooks.go`); goroutines start in package `init()`, triggered because `cmd/memos/main.go` imports `internal/webhook`
- **Email async workers (×2)** (`internal/email/email.go`) — **channel queue consumer** on `asyncEmailQueue`; work is enqueued by `email.SendAsync()` (default sender in `server/notification/email.go`) when inbox email notifications are dispatched (`server/router/api/v1/notification_email.go`); goroutines start in package `init()` via the import chain `server` → `server/router/api/v1` → `server/notification` → `internal/email`
- **Store cache cleanup loops (×3)** (`store/cache/cache.go`, one per cache in `store/store.go`) — **5-minute `time.NewTicker`** per cache (instance settings, users, user settings); started in `cache.New()` during `store.New()` in `cmd/memos/main.go`

**Unused scheduling infrastructure**

- **`internal/scheduler`** — full cron-based job scheduler (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`); **not imported or started** by `cmd/` or `server/` (only referenced from its own tests: `internal/scheduler/example_test.go`, `integration_test.go`)
- **`server/runner/memopayload` batch runner** — `Runner.RunOnce()` exists (`server/runner/memopayload/runner.go`) but **`NewRunner` is never called**; memo payload rebuild runs **synchronously** in API handlers via `memopayload.RebuildMemoPayload()` (`server/router/api/v1/memo_service.go`), not as a scheduled background runner
