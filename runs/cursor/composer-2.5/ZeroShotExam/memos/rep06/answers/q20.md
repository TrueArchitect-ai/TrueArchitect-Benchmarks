SSE (Server-Sent Events); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment

The server exposes a long-lived SSE stream at `/api/v1/sse` (`server/router/api/v1/sse_handler.go`). Connected browsers subscribe through `SSEHub` in `server/router/api/v1/sse_hub.go`, which fans out `SSEEvent` payloads via `Broadcast`.

These memo API handlers call `SSEHub.Broadcast`:

- **CreateMemo** — `memo.created` (`server/router/api/v1/memo_service.go`)
- **UpdateMemo** — `memo.updated` via `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_service.go`, `server/router/api/v1/memo_update_helpers.go`)
- **DeleteMemo** — `memo.deleted` (`server/router/api/v1/memo_service.go`)
- **CreateMemoComment** — `memo.comment.created` (`server/router/api/v1/memo_service_comments.go`)

The client consumes this in `web/src/hooks/useLiveMemoRefresh.ts`. Reaction handlers in `server/router/api/v1/reaction_service.go` also broadcast through the same hub, but they are not memo handlers.
