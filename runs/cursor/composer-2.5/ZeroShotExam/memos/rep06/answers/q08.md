**Driver** — `store/driver.go`

The `Driver` interface is defined in `store/driver.go` and is documented as the interface that all store database drivers must implement. The SQLite, PostgreSQL, and MySQL backends all return `store.Driver` from their constructors in `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`.
