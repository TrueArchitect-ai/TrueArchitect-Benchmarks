**POST /api/v1/memos**

The `CreateMemo` RPC is mapped via a `google.api.http` annotation in `proto/api/v1/memo_service.proto`:

```21:27:proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
    option (google.api.method_signature) = "memo";
  }
```

That annotation is used by `protoc-gen-grpc-gateway` to generate the REST handler in `proto/gen/api/v1/memo_service.pb.gw.go`, which registers `http.MethodPost` on the `/api/v1/memos` path pattern. The gateway is wired up in `server/router/api/v1/v1.go` via `RegisterMemoServiceHandlerServer`.
