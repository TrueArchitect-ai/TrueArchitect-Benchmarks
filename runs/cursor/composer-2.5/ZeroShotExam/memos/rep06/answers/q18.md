NewDBDriver — `store/db/db.go`

The `store.Driver` interface is defined in `store/driver.go`. Each backend implements it via a `DB` type and `NewDB` constructor in its entry file above. At startup, `NewDBDriver` in `store/db/db.go` switches on `profile.Driver` (`"sqlite"`, `"mysql"`, or `"postgres"`) and returns the matching implementation; it is invoked from `cmd/memos/main.go`.
