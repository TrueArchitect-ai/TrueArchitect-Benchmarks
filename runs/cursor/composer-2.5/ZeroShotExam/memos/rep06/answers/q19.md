MemoService is wired up in two places inside `RegisterGateway`:

1. **gRPC-Gateway** — `RegisterMemoServiceHandlerServer` mounts REST/JSON routes under `/api/v1/*` (`server/router/api/v1/v1.go`, around line 108).
2. **Connect** — `NewMemoServiceHandler` registers the Connect handler on the mux (`server/router/api/v1/connect_handler.go`, around line 40), and `ConnectServiceHandler` methods in `server/router/api/v1/connect_services.go` wrap the shared gRPC-style implementations for Connect request/response types.

There is no separate native gRPC server registration for MemoService; the server serves HTTP only (`server/server.go`).
