`ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` with five RPCs. All are implemented in `server/router/api/v1/shortcut_service.go` on `APIV1Service`:

| RPC | Implementing file |
|-----|-------------------|
| `ListShortcuts` | `server/router/api/v1/shortcut_service.go` |
| `GetShortcut` | `server/router/api/v1/shortcut_service.go` |
| `CreateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `UpdateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `DeleteShortcut` | `server/router/api/v1/shortcut_service.go` |

Note: `server/router/api/v1/connect_services.go` also defines Connect handlers for these RPCs, but they only delegate to `APIV1Service` methods in `shortcut_service.go`; the business logic lives there.
