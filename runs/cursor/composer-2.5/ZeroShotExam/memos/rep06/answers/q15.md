user: User — store/user.go  
attachment: Attachment — store/attachment.go  
reaction: Reaction — store/reaction.go  

These are the domain structs in the `store` package. The database drivers under `store/db/` (sqlite, postgres, mysql) read and write them against the `user`, `attachment`, and `reaction` tables — for example, `store/db/sqlite/user.go` inserts into `user` using `*store.User`, and `store/db/sqlite/reaction.go` inserts into `reaction` using `*store.Reaction`.

There are also API-layer structs named `User`, `Attachment`, and `Reaction` in `proto/gen/api/v1/`, but those are protobuf message types for the HTTP/gRPC API, not the database table mappings.
