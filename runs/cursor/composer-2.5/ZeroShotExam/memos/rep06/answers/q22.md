`DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`; `internal/webhook`; Standard Webhooks (HMAC-SHA256)

When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, defined in `server/router/api/v1/memo_service_webhooks.go`. That function delegates to `dispatchMemoRelatedWebhook`, which loads the creator’s registered webhooks via `s.Store.GetUserWebhooks`, builds a payload with activity type `memos.memo.created`, and enqueues delivery with `webhook.PostAsync`.

HTTP delivery is handled by the `internal/webhook` package (`internal/webhook/webhook.go`): `PostAsync` puts payloads on a background queue, worker goroutines call `Post`, and `Post` sends the request with the standard library `net/http` client (`safeClient.Do`).

If a signing secret is set, requests are signed using the Standard Webhooks scheme: HMAC-SHA256 over `{webhook-id}.{webhook-timestamp}.{body}`, with `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`) headers. Secrets prefixed with `whsec_` are base64-decoded before signing.
