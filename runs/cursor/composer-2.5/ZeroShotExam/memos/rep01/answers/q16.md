When a memo is deleted through the API, the store layer’s `DeleteMemo` in `store/memo.go` removes these other record kinds **before** deleting the memo row itself:

- **memo_relation** — rows where the memo is the source (`memo_id`) or the target (`related_memo_id`)
- **attachment** — rows linked to the memo via `memo_id`

The API handler in `server/router/api/v1/memo_service.go` calls `Store.DeleteMemo` for comment memos first, then for the main memo; each call runs the same cleanup in `store/memo.go` (relations and attachments, then the memo row). The store layer does not delete reactions, memo shares, or inbox records as part of `DeleteMemo`.
