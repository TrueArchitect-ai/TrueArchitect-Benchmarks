store/migration/sqlite/LATEST.sql

For a fresh SQLite database, the migrator applies this file in `preMigrate()` when the database is not yet initialized (`store/migrator.go`). It holds the full current schema (all `CREATE TABLE` and index statements), not incremental migration scripts or seed data. `store/seed/sqlite/01__dump.sql` is demo seed data only and runs separately in demo mode.
