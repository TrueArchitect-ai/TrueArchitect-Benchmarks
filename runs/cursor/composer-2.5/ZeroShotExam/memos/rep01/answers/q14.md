`ShortcutService` defines five RPCs in [`proto/api/v1/shortcut_service.proto`](proto/api/v1/shortcut_service.proto). All of them are implemented on `APIV1Service` in [`server/router/api/v1/shortcut_service.go`](server/router/api/v1/shortcut_service.go):

| RPC | Implementing file |
|---|---|
| `ListShortcuts` | `server/router/api/v1/shortcut_service.go` |
| `GetShortcut` | `server/router/api/v1/shortcut_service.go` |
| `CreateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `UpdateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `DeleteShortcut` | `server/router/api/v1/shortcut_service.go` |

Connect wrappers in [`server/router/api/v1/connect_services.go`](server/router/api/v1/connect_services.go) delegate to those same `APIV1Service` methods; the business logic lives in `shortcut_service.go`.
