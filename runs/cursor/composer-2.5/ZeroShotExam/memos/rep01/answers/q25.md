**CEL (Common Expression Language) via `github.com/google/cel-go`** + `internal/filter/` (`engine.go`, `parser.go`, `schema.go`, `render.go`, `helpers.go`); the filter string is compiled by cel-go against the memo schema in `internal/filter/schema.go`, converted from the CEL AST into a dialect-agnostic condition tree in `internal/filter/parser.go`, then rendered to parameterized SQL in `internal/filter/render.go` with per-dialect branches for SQLite, MySQL, and Postgres (JSON operators, placeholders, LIKE/ILIKE, etc.), and finally appended to the query WHERE clause by `filter.AppendConditions` from each store driver (`store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`) after `ListMemos` passes the raw filter through `validateFilter` in `server/router/api/v1/shortcut_service.go` (`server/router/api/v1/memo_service.go`).
