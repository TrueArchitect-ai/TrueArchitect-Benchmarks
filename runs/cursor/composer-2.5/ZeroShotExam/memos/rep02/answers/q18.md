NewDBDriver — `store/db/db.go`

The `Driver` interface is defined in `store/driver.go`. Each backend implements it via a `DB` type and `NewDB` constructor in its entry file (e.g. `sqlite.NewDB` returns `store.Driver` in `store/db/sqlite/sqlite.go`).

`NewDBDriver` in `store/db/db.go` switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) and calls the matching `NewDB`. It is invoked at startup from `cmd/memos/main.go` (line 57: `db.NewDBDriver(instanceProfile)`).
