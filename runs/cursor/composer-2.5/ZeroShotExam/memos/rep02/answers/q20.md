SSE (Server-Sent Events); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction

The server exposes a long-lived HTTP stream at `/api/v1/sse` with `Content-Type: text/event-stream` in `server/router/api/v1/sse_handler.go`. Clients connect via fetch with `Accept: text/event-stream` (see `web/src/hooks/useLiveMemoRefresh.ts`). The `SSEHub` in `server/router/api/v1/sse_hub.go` manages subscribers and calls `Broadcast` to push JSON events.

MemoService handlers that broadcast through `SSEHub`:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` (direct) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` (direct) |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` (direct) |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via helper) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via helper) |
| `UpsertMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.upserted` (direct) |
| `DeleteMemoReaction` | `server/router/api/v1/reaction_service.go` | `reaction.deleted` (direct) |

`UpdateMemo`, `SetMemoAttachments`, and `SetMemoRelations` share the broadcast path through `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go`.
