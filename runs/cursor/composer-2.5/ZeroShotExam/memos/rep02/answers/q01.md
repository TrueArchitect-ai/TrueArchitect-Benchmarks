**POST /api/v1/memos**

The `CreateMemo` RPC is mapped via a `google.api.http` annotation in `proto/api/v1/memo_service.proto`:

```21:27:proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
    option (google.api.method_signature) = "memo";
  }
```

That annotation is what the REST gateway uses. The generated gateway registers it as `http.MethodPost` on `/api/v1/memos` in `proto/gen/api/v1/memo_service.pb.gw.go` (e.g. `mux.Handle(http.MethodPost, pattern_MemoService_CreateMemo_0, ...)` with `pattern_MemoService_CreateMemo_0` resolving to `/api/v1/memos`). The same mapping appears in `proto/gen/openapi.yaml` under `/api/v1/memos` with `operationId: MemoService_CreateMemo`.
