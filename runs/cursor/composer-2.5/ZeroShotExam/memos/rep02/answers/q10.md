store/migration/sqlite/LATEST.sql

For a fresh SQLite database, `preMigrate` in `store/migrator.go` applies this file when the DB is uninitialized. The file holds the full current schema (all tables and indexes) in one place, instead of running incremental migrations from scratch. `store/test/migrator_test.go` (`TestFreshInstall`) verifies that behavior.
