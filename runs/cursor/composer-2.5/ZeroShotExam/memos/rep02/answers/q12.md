`useInfiniteMemos` (also `useMemos` in the same file) calls `memoServiceClient.listMemos` from `web/src/connect.ts`, which invokes the `ListMemos` RPC defined in `proto/api/v1/memo_service.proto`. The backend handler `ListMemos` in `server/router/api/v1/memo_service.go` calls `s.Store.ListMemos`, which delegates from `store/memo.go` to the dialect driver; `store/db/postgres/memo.go` builds and runs the SQL query (SQLite and MySQL equivalents live under `store/db/sqlite/memo.go` and `store/db/mysql/memo.go`).
