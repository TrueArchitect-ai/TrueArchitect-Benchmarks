| user | `User` — `store/user.go` |
| attachment | `Attachment` — `store/attachment.go` |

These are the store-layer domain structs used by the database drivers (e.g. `store/db/sqlite/user.go`, `store/db/postgres/attachment.go`, `store/db/mysql/reaction.go`) for `INSERT`/`SELECT` against the `user`, `attachment`, and `reaction` tables. The protobuf API types in `proto/gen/api/v1/` (`User`, `Attachment`, `Reaction`) are separate and are not the table-mapping structs.
