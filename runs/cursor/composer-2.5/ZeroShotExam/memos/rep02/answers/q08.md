**Driver** — `store/driver.go`

All database backends implement the `Driver` interface defined in that file. The comment there states it is “an interface for store driver” and lists the methods each backend must implement. `store/db/db.go` wires this up by having `NewDBDriver` return a `store.Driver`, and the SQLite, MySQL, and Postgres packages each provide a `NewDB` that returns `store.Driver`.
