q27. go:embed with Echo Static middleware; server/server.go

In production, the React build is compiled into `server/router/frontend/dist` (via `pnpm release` in `web/`), then baked into the Go binary with `go:embed`:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

Those embedded files are served at runtime by Echo’s `middleware.StaticWithConfig`, with an SPA fallback to `index.html`:

```53:59:server/router/frontend/frontend.go
	// Route to serve the frontend static assets.
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		Skipper:    skipper,
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
```

That serving logic is hooked into the production HTTP server in `server/server.go`:

```71:72:server/server.go
	// Serve frontend static files.
	frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)
```
