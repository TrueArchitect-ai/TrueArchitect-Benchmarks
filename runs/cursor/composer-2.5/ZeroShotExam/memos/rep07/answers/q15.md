| table | Struct — path |
|---|---|
| user | `User` — `store/user.go` |
| attachment | `Attachment` — `store/attachment.go` |
| reaction | `Reaction` — `store/reaction.go` |

These are the domain structs in the `store` package. The database drivers (`store/db/sqlite/`, `store/db/postgres/`, `store/db/mysql/`) use them when reading and writing the `user`, `attachment`, and `reaction` tables (for example, `store/db/sqlite/user.go` inserts into `user` with `*store.User`).

There are also protobuf API types named `User`, `Attachment`, and `Reaction` under `proto/gen/api/v1/`, but those are API-layer messages, not the table-mapping structs.
