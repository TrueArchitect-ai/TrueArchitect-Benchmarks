**CEL (via `google/cel-go`) + `internal/filter/`** (`engine.go`, `parser.go`, `render.go`, `schema.go`); the RPC passes the filter string into each dialect’s `ListMemos` (`store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`), which calls `filter.AppendConditions` → `Engine.CompileToStatement`: `cel-go` compiles the CEL expression, `parser.go` walks the CEL AST into a dialect-agnostic condition IR, and `render.go` walks that IR to emit parameterized SQL fragments (with `$n` on Postgres, `?` on SQLite/MySQL) using per-dialect helpers for JSON, timestamps, LIKE/ILIKE, etc., which are appended to the query `WHERE` clause.
