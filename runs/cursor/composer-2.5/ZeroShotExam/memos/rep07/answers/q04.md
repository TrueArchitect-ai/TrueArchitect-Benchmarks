**APIV1Service.SignIn — server/router/api/v1/auth_service.go**

The `SignIn` RPC is defined on `AuthService` in `proto/api/v1/auth_service.proto`. The backend implementation is the method on `APIV1Service` in `server/router/api/v1/auth_service.go` (starting around line 51). That method handles password and SSO authentication and returns tokens.

`APIV1Service` is registered for both the gRPC-Gateway HTTP path (`RegisterAuthServiceHandlerServer` in `server/router/api/v1/v1.go`) and, indirectly, Connect: `ConnectServiceHandler.SignIn` in `server/router/api/v1/connect_services.go` delegates to `APIV1Service.SignIn`. The actual sign-in logic lives in `auth_service.go`, not in the Connect wrapper.
