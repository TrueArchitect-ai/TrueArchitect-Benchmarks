Delivery: `webhook.PostAsync` in `server/router/api/v1/memo_service_webhooks.go`, which enqueues payloads for async workers that call `webhook.Post` in `internal/webhook/webhook.go`.

The four dispatch functions are defined in `server/router/api/v1/memo_service_webhooks.go`:

- `DispatchMemoCreatedWebhook` → activity type `memos.memo.created` (via `dispatchMemoRelatedWebhook`)
- `DispatchMemoUpdatedWebhook` → activity type `memos.memo.updated` (via `dispatchMemoRelatedWebhook`)
- `DispatchMemoDeletedWebhook` → activity type `memos.memo.deleted` (via `dispatchMemoRelatedWebhook`)
- `DispatchMemoCommentCreatedWebhook` → activity type `memos.memo.comment.created`

They are invoked from:

- `server/router/api/v1/memo_service.go` (create, delete)
- `server/router/api/v1/memo_update_helpers.go` (update)
- `server/router/api/v1/memo_service_comments.go` (comment create)

All paths call `webhook.PostAsync(payload)` (`memo_service_webhooks.go` lines 43 and 71). That function in `internal/webhook/webhook.go` pushes to `asyncPostQueue`; four worker goroutines started in `init()` dequeue and call `Post()` for the actual HTTP POST.
