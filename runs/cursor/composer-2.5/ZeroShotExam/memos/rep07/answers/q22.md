q22. DispatchMemoCreatedWebhook — `server/router/api/v1/memo_service_webhooks.go`; `internal/webhook`; Standard Webhooks (HMAC-SHA256)

When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`. That function loads the creator’s user webhooks from the store, builds a payload, and enqueues delivery via `webhook.PostAsync` for each hook.

HTTP delivery is handled by the `internal/webhook` package (`internal/webhook/webhook.go`): worker goroutines drain the async queue and call `Post`, which sends a POST with `net/http` through an SSRF-safe client.

If a webhook has a signing secret, requests are signed using the Standard Webhooks scheme: HMAC-SHA256 over `msgID + "." + timestamp + "." + body`, with `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`) headers. Secrets in `whsec_<base64>` form are base64-decoded before signing.
