For an uninitialized SQLite database, the migrator applies this file in `preMigrate()` rather than running incremental migrations. That behavior is documented in `store/migrator.go` (lines 27, 42, and 55–56) and exercised by `TestFreshInstall` in `store/test/migrator_test.go`. The file itself contains the full current schema as `CREATE TABLE` statements.
