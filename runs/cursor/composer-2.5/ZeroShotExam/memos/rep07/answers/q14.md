`ShortcutService` defines five RPCs in [`proto/api/v1/shortcut_service.proto`](proto/api/v1/shortcut_service.proto). Each is implemented in [`server/router/api/v1/shortcut_service.go`](server/router/api/v1/shortcut_service.go):

| RPC | Implementing file |
|---|---|
| `ListShortcuts` | `server/router/api/v1/shortcut_service.go` |
| `GetShortcut` | `server/router/api/v1/shortcut_service.go` |
| `CreateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `UpdateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `DeleteShortcut` | `server/router/api/v1/shortcut_service.go` |

Those methods live on `APIV1Service` in that file. [`server/router/api/v1/connect_services.go`](server/router/api/v1/connect_services.go) only wraps them for Connect/gRPC transport and delegates to the same implementations.
