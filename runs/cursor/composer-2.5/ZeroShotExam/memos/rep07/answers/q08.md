**Driver** — `store/driver.go`

The `Driver` interface is defined in the `store` package with a comment stating it "contains all methods that store database driver should implement." The three backends (SQLite, MySQL, and PostgreSQL) are wired through `NewDBDriver` in `store/db/db.go`, which returns a `store.Driver` and selects among `sqlite.NewDB`, `mysql.NewDB`, and `postgres.NewDB`.
