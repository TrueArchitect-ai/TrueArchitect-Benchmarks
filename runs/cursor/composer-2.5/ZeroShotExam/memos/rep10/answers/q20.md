SSE (Server-Sent Events); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations

Browsers connect to `/api/v1/sse` over HTTP with `Content-Type: text/event-stream` (`server/router/api/v1/sse_handler.go`). The `SSEHub` type in `server/router/api/v1/sse_hub.go` manages subscribed clients and broadcasts JSON events via `Broadcast()`.

Memo handlers that broadcast through it:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |

`UpdateMemo`, `SetMemoAttachments`, and `SetMemoRelations` call `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go`, which performs the actual `SSEHub.Broadcast`.

Note: `UpsertMemoReaction` and `DeleteMemoReaction` in `server/router/api/v1/reaction_service.go` also broadcast through the same hub, but they are reaction handlers, not memo handlers.
