`store/migration/sqlite/LATEST.sql`

For a fresh SQLite install, the migrator applies this file via `preMigrate` when the database is not yet initialized. That is documented in `store/migrator.go` (lines 27, 42, 54–56, 210–231), where `LatestSchemaFileName = "LATEST.sql"` is described as the full schema for new installations. The file itself contains the complete current schema (`CREATE TABLE` statements for all tables). Demo seed data lives separately in `store/seed/sqlite/01__dump.sql`.
