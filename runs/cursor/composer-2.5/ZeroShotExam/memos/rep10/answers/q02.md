mysql, postgres, sqlite

Migrations live under `store/migration/` in three dialect-specific directories: `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/`. Each contains versioned migration files and a `LATEST.sql` schema snapshot. `store/migrator.go` documents the layout as `store/migration/{driver}/{version}/NN__description.sql` and embeds the whole `migration` tree via `//go:embed migration`.
