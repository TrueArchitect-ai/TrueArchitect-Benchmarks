`ShortcutService` defines five RPCs in `proto/api/v1/shortcut_service.proto`:

| RPC | Implementing backend file |
|---|---|
| `ListShortcuts` | `server/router/api/v1/shortcut_service.go` |
| `GetShortcut` | `server/router/api/v1/shortcut_service.go` |
| `CreateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `UpdateShortcut` | `server/router/api/v1/shortcut_service.go` |
| `DeleteShortcut` | `server/router/api/v1/shortcut_service.go` |

All five are implemented as methods on `*APIV1Service` in `server/router/api/v1/shortcut_service.go` (e.g. `ListShortcuts` at line 49, `GetShortcut` at line 95, `CreateShortcut` at line 135, `UpdateShortcut` at line 211, `DeleteShortcut` at line 284).

`server/router/api/v1/connect_services.go` also exposes the same RPC names on `*ConnectServiceHandler`, but only as thin Connect adapters that delegate to `s.APIV1Service`; the business logic lives in `shortcut_service.go`.
