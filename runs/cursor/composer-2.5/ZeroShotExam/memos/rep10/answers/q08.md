**Driver** — `store/driver.go`

The `Driver` interface is defined in `store/driver.go` with the comment that it "contains all methods that store database driver should implement." SQLite, Postgres, and MySQL backends all return `store.Driver` from their `NewDB` constructors (see `store/db/db.go`, `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`).
