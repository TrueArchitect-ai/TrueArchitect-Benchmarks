Go `embed.FS` served by Echo `middleware.StaticWithConfig` with SPA fallback middleware; `server/router/frontend/frontend.go`

In production, the React app is built into `server/router/frontend/dist` (`web/package.json` `release` script), then embedded into the Go binary with `//go:embed dist/*` in `server/router/frontend/frontend.go`. `FrontendService.Serve` wires Echo’s static middleware to that filesystem and adds SPA fallback so client routes get `index.html`. That service is registered from `server/server.go` (line 72).
