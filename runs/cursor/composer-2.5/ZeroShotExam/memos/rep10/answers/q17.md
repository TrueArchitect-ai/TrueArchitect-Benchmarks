web/src/hooks/useMemoQueries.ts; memoServiceClient

The memo CRUD React Query hooks live in `web/src/hooks/useMemoQueries.ts`: `useMemos` / `useInfiniteMemos` (list), `useMemo` (read), `useCreateMemo`, `useUpdateMemo`, and `useDeleteMemo`. They all call `memoServiceClient`, imported from `@/connect` (`web/src/connect.ts`), which is a Connect RPC client created from the generated `MemoService` in `web/src/types/proto/api/v1/memo_service_pb.ts`.
