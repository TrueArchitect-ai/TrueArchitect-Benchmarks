**DispatchMemoCreatedWebhook** — `server/router/api/v1/memo_service_webhooks.go`; **internal/webhook**; **HMAC-SHA256 (Standard Webhooks)**

When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)`. That function (in `server/router/api/v1/memo_service_webhooks.go`) loads the creator’s webhooks via `GetUserWebhooks`, builds a payload, and enqueues delivery with `webhook.PostAsync(payload)` from `internal/webhook/webhook.go`. Workers in that package call `Post`, which performs the HTTP POST via Go’s `net/http` client (`safeClient.Do`). If a signing secret is set, requests are signed with HMAC-SHA256 using the Standard Webhooks scheme: headers `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`), signing `msgID + "." + timestamp + "." + body`.
