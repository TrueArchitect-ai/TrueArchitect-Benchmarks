q10.
store/migration/sqlite/LATEST.sql

For a fresh SQLite install, `preMigrate` in `store/migrator.go` detects an uninitialized database and applies this file as the full schema instead of running incremental migrations. The file is named `LATEST.sql` and lives under `migration/sqlite/` for the SQLite driver. `store/test/migrator_test.go` (`TestFreshInstall`) confirms that behavior. `AGENTS.md` also notes that fresh-install SQL and incremental migrations must stay equivalent, and that each driver’s `LATEST.sql` must be updated when the schema changes.
