When a memo is deleted through the API, the handler in `server/router/api/v1/memo_service.go` calls `Store.DeleteMemo`. In `store/memo.go`, that method deletes these other record kinds before the memo row itself:

- **memo_relation** — rows where the memo is the source (`MemoID`) or the target (`RelatedMemoID`)
- **attachment** — rows linked to the memo (`MemoID`)

The API may also delete comment memos first (separate `Store.DeleteMemo` calls in `server/router/api/v1/memo_service.go`), but those are memo rows, not a different record kind. The store layer does not delete reactions, memo shares, or inbox records as part of `DeleteMemo`.
