**CEL (Common Expression Language) via `github.com/google/cel-go`** in `internal/filter/` (`engine.go`, `parser.go`, `schema.go`, `render.go`).

The filter string is compiled by cel-go into an AST, converted in `internal/filter/parser.go` into a dialect-agnostic condition tree, then rendered to SQL in `internal/filter/render.go` by walking that tree with a `RenderOptions.Dialect` of `sqlite`, `postgres`, or `mysql`—each dialect branch emits different SQL (placeholders, JSON operators, timestamp functions, etc.) that `internal/filter/helpers.go` appends to the store query via `filter.AppendConditions` in `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, and `store/db/mysql/memo.go`.
