**SSE (Server-Sent Events)**; **`server/router/api/v1/sse_hub.go`**; **CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations**

The server exposes an SSE stream at `/api/v1/sse` in `server/router/api/v1/sse_handler.go`, which sets `Content-Type: text/event-stream` and writes `data: …` frames to connected browsers. Client connections are managed by `SSEHub` in `server/router/api/v1/sse_hub.go`, which subscribes clients and fans out events via `Broadcast`.

Memo-related handlers that call `SSEHub.Broadcast`:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go`) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |

Reaction handlers in `server/router/api/v1/reaction_service.go` also broadcast through the same hub, but they are not memo handlers.
