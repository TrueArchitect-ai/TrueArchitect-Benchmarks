When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which is defined in `server/router/api/v1/memo_service_webhooks.go`. That function loads the creator’s configured webhooks, builds a payload, and enqueues delivery via `webhook.PostAsync` from the `internal/webhook` package (`/bench/repo/internal/webhook/webhook.go`). Workers dequeue those payloads and perform the actual HTTP POST in `Post`, using Go’s `net/http` client. Requests are signed with **Standard Webhooks** (HMAC-SHA256): headers `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`), signing `msgID + "." + timestamp + "." + body` with the user’s signing secret (including `whsec_`-prefixed base64 secrets).

**Answer:** `DispatchMemoCreatedWebhook — server/router/api/v1/memo_service_webhooks.go`; `internal/webhook`; Standard Webhooks (HMAC-SHA256)
