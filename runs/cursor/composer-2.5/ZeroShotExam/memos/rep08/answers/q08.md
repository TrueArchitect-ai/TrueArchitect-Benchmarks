**Driver** — `store/driver.go`

All database backends (SQLite, MySQL, and PostgreSQL) implement this interface. It is declared in `store/driver.go` with the comment that it “contains all methods that store database driver should implement,” and each backend’s constructor returns `store.Driver` (for example, `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go` via `store/db/db.go`).
