These are the domain structs in the `store` package. The database drivers (e.g. `store/db/sqlite/user.go`, `store/db/sqlite/attachment.go`, `store/db/sqlite/reaction.go`) use them in SQL against the corresponding tables (`user`, `attachment`, `reaction`). There are also protobuf API types named `User`, `Attachment`, and `Reaction` under `proto/gen/api/v1/`, but those are not the table-mapping structs.
