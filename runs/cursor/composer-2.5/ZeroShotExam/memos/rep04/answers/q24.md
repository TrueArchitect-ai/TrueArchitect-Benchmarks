**Notes on the chain:**

1. **Frontend hook** — `useCreateMemo()` in `useMemoQueries.ts` is a React Query `useMutation` whose `mutationFn` calls `memoServiceClient.createMemo({ memo: memoToCreate })`.

2. **Client** — `connect.ts` exports `memoServiceClient`, created via `createClient(MemoService, transport)` from the generated `MemoService` descriptor.

3. **Proto RPC** — `memo_service.proto` defines `rpc CreateMemo(CreateMemoRequest) returns (Memo)` (HTTP `POST /api/v1/memos`).

4. **Handler** — `APIV1Service.CreateMemo` in `memo_service.go` handles auth, validation, payload building, and calls `s.Store.CreateMemo(ctx, create)`. (Connect requests first hit `ConnectServiceHandler.CreateMemo` in `connect_services.go`, which immediately delegates here.)

5. **Store method** — `Store.CreateMemo` in `store/memo.go` validates the UID and delegates to `s.driver.CreateMemo`.

6. **Dialect driver** — `DB.CreateMemo` in `store/db/sqlite/memo.go` executes the `INSERT INTO memo ...` statement. Postgres and MySQL have equivalent implementations in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`.
