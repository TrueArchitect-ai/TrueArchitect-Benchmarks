q20. Server-Sent Events (SSE); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations

The server pushes live updates over an SSE stream at `/api/v1/sse`, registered in `server/router/api/v1/sse_handler.go` with `Content-Type: text/event-stream`. Connected clients subscribe through `SSEHub` in `server/router/api/v1/sse_hub.go`, which fans out `SSEEvent` payloads via `Broadcast`.

Memo handlers that emit through the hub:

| Handler | File | Event |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go` | `memo.created` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go`) |
| `DeleteMemo` | `server/router/api/v1/memo_service.go` | `memo.deleted` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go` | `memo.comment.created` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go` | `memo.updated` (via `dispatchMemoUpdatedSideEffects`) |

The browser client consumes this stream in `web/src/hooks/useLiveMemoRefresh.ts`. Reaction handlers in `server/router/api/v1/reaction_service.go` also broadcast through the same hub, but those are not memo handlers.
