This project ships migrations for **sqlite, postgres, mysql**.

They live under `store/migration/` in three dialect-specific directories:

- `store/migration/sqlite/`
- `store/migration/postgres/`
- `store/migration/mysql/`

`store/migrator.go` documents the layout as `store/migration/{driver}/{version}/NN__description.sql`, and each dialect has its own `LATEST.sql` full-schema file (for example `store/migration/sqlite/LATEST.sql`, `store/migration/postgres/LATEST.sql`, `store/migration/mysql/LATEST.sql`). `AGENTS.md` also states that schema changes require SQLite, MySQL, and PostgreSQL migrations.
