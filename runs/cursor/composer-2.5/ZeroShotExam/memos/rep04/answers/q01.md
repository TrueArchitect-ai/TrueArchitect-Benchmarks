q01. POST /api/v1/memos

The `CreateMemo` RPC is mapped via a `google.api.http` annotation on the protobuf service definition:

```21:27:/bench/repo/proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
    option (google.api.method_signature) = "memo";
  }
```

That annotation is what the REST gateway (gRPC-Gateway / Google API HTTP transcoding) uses to expose the RPC as `POST /api/v1/memos`, with the request body taken from the `memo` field. The same mapping appears in the generated code at `/bench/repo/proto/gen/api/v1/memo_service.pb.go`.
