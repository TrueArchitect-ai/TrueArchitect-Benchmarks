`store/migration/sqlite/LATEST.sql`

For an uninitialized SQLite database, the migrator applies this file as the full current schema instead of running incremental migrations. That behavior is documented in `store/migrator.go` (see the `preMigrate` step and `LatestSchemaFileName = "LATEST.sql"`) and exercised by `store/test/migrator_test.go` (`TestFreshInstall`). The file itself contains the complete set of `CREATE TABLE` / index definitions for the current schema.
