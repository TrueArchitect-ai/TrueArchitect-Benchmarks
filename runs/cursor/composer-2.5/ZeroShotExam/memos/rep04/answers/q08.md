**Driver** — `store/driver.go`

The `Driver` interface is defined in `store/driver.go` and is documented as the interface for the store driver, with methods that every store database driver must implement. All backends (SQLite, MySQL, and PostgreSQL) return `store.Driver` from their `NewDB` functions, and `store/db/db.go` selects among them via `NewDBDriver`.
