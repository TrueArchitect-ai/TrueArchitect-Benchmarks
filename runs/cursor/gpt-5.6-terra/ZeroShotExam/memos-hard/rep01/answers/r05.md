Premise correction: this repository does not define a public GraphQL schema.

Actual API surface: the public API is defined as protobuf services in `proto/api/v1/*.proto`, with REST mappings via `google.api.http` annotations (for example, `proto/api/v1/memo_service.proto`). It generates and embeds an OpenAPI specification at `proto/gen/openapi.yaml` via `proto/openapi_embed.go`; routes are served under `/api/v1/*` by `server/router/api/v1/v1.go`.
