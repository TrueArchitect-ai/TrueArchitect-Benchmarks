Premise correction: this repository does not define a GraphQL public API schema.

Actual API surface: the public API is defined as Protocol Buffer services in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`) with HTTP annotations that expose REST endpoints under `/api/v1`. Buf generates gRPC/Connect, gRPC-Gateway, and OpenAPI artifacts via `proto/buf.gen.yaml`; the generated OpenAPI spec is embedded from `proto/gen/openapi.yaml` by `proto/openapi_embed.go`. The server registers that gateway in `server/server.go`.
