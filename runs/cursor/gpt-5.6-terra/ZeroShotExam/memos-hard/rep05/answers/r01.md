Premise correction: Redis is not configured for this cache layer—there is no Redis client/dependency. The cache is process-local, using `sync.Map` in [store/cache/cache.go](store/cache/cache.go).

Actual mechanism: `Store.New` creates `userCache` with an in-memory `cache.Config`; its default TTL is 10 minutes in [store/store.go](store/store.go). User records are written via `userCache.Set`, which applies that default TTL in [store/user.go](store/user.go).
