Premise correction: this repository does not define a GraphQL schema.

Actual API surface: the public API contract is Protocol Buffers in `proto/api/v1/*.proto`; REST routes are generated from their HTTP annotations and served via gRPC-Gateway in `server/router/api/v1/v1.go`. The browser-facing RPC surface is Connect RPC, registered in `server/router/api/v1/connect_handler.go`. Generated REST documentation is `proto/gen/openapi.yaml`.
