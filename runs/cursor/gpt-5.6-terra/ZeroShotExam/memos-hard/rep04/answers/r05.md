Premise correction: this repository does not define a GraphQL schema or expose a GraphQL public API.

Actual API surface: the public API is defined as Protocol Buffers in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`) and generated into Connect RPC, gRPC, gRPC-Gateway REST/OpenAPI, and TypeScript clients via `proto/buf.gen.yaml`. REST routes are declared with `google.api.http` annotations, e.g. `/api/v1/memos` in `proto/api/v1/memo_service.proto`.
