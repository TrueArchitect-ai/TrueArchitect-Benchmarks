Premise correction: Redis is not configured or used for this cache layer—there is no Redis client dependency or connection setting.

Actual mechanism: `store.New` creates an in-process, `sync.Map`-backed cache for users in `store/store.go`. User writes use the cache’s default TTL via `Set` in `store/user.go`; that TTL is 10 minutes, configured in `store/store.go` (also the cache default in `store/cache/cache.go`).
