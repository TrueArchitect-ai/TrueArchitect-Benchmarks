Premise correction: this repository does not define a GraphQL public API schema.

Actual API surface: the public API is defined as Protocol Buffers in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`) and generated into gRPC, Connect, and OpenAPI surfaces by `proto/buf.gen.yaml`. Connect handlers are registered in `server/router/api/v1/connect_handler.go`.
