Premise correction: this repository does not configure a Redis cache connection. It uses an in-process, `sync.Map`-backed cache.

Actual mechanism: `Store.New` creates `userCache` with `cache.New`; its default TTL is 10 minutes in `store/store.go`. User objects are populated through `userCache.Set` in `store/user.go`, which applies that default TTL.
