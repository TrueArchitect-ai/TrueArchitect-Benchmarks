Premise correction: this repository does not define a GraphQL public API schema.

Actual API surface: the public API is defined as protobuf services in `proto/api/v1/*.proto`, with HTTP/REST mappings via `google.api.http` annotations (for example, `proto/api/v1/memo_service.proto`). It generates gRPC, Connect RPC, gateway, and OpenAPI artifacts per `proto/buf.gen.yaml`; the generated OpenAPI spec is embedded from `proto/gen/openapi.yaml` by `proto/openapi_embed.go`.
