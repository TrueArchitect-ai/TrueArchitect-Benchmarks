Premise correction: Redis is not configured or used for the cache layer.

Actual mechanism: `store.New` creates in-process `cache.Cache` instances, including `userCache`, with a 10-minute default TTL in `store/store.go`. User records are added via `userCache.Set`, so they receive that default 10-minute TTL (`store/user.go`; `store/cache/cache.go`).
