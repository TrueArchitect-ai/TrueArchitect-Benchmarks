Premise correction: this repository does not define a public GraphQL schema.

Actual API surface: the public API is defined as Protocol Buffers services in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`) with REST mappings via `google.api.http` annotations. The generated OpenAPI specification is `proto/gen/openapi.yaml`, embedded by `proto/openapi_embed.go`.
