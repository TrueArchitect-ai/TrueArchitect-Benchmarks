Premise correction: Redis is not configured or used for this cache layer.

Actual mechanism: the application creates an in-memory `cache.Cache` in [`store/store.go`](store/store.go) and assigns it to `userCache`. User entries use `Set`, which applies the cache’s default TTL of **10 minutes**. The TTL is configured in [`store/store.go`](store/store.go) (and the cache default is defined in [`store/cache/cache.go`](store/cache/cache.go)).
