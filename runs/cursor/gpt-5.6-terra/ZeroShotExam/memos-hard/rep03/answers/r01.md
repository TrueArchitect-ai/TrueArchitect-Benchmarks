Premise correction: the cache layer does not configure a Redis connection; it is an in-memory cache.

Actual mechanism: `store/store.go` creates `userCache` with a default TTL of 10 minutes. User entries use that default via `userCache.Set(...)` in `store/user.go`; `Set` applies `Config.DefaultTTL` in `store/cache/cache.go`.
