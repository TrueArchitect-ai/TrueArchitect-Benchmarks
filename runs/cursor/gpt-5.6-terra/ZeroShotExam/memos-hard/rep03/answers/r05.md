Premise correction: this repository does not define a GraphQL public API schema.

Actual API surface: the public API is protobuf-defined in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`), with HTTP REST mappings under `/api/v1/...`. Those definitions generate the OpenAPI spec at `proto/gen/openapi.yaml` and are mounted via the gRPC gateway in `server/router/api/v1/v1.go`; Connect RPC handlers are also exposed under `/memos.api.v1.*`.
