Premise correction: there is no GraphQL schema. The public API is defined as protobuf services in `proto/api/v1/*.proto`, with REST routes declared through `google.api.http` annotations—for example `proto/api/v1/memo_service.proto` and `proto/api/v1/auth_service.proto`.

These definitions generate gRPC/Connect, REST gateway, and OpenAPI surfaces via `proto/buf.gen.yaml`; the generated OpenAPI document is embedded by `proto/openapi_embed.go`.
