Premise correction: There is no GraphQL schema or GraphQL public API.

Actual API surface: REST and gRPC APIs are defined by Protocol Buffers in `proto/api/v1/*.proto`, with REST routes declared through `google.api.http` annotations. The generated OpenAPI specification is `proto/gen/openapi.yaml`, and server registration is in `server/router/api/v1/v1.go`.
