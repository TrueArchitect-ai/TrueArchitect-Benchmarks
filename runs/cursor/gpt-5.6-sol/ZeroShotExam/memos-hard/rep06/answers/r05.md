Premise correction: There is no GraphQL public API or GraphQL schema.

Actual API surface: The public REST and Connect/gRPC API is defined with Protocol Buffers in `proto/api/v1/*.proto`. HTTP routes use `google.api.http` annotations, e.g. `proto/api/v1/memo_service.proto`. Generated OpenAPI documentation is at `proto/gen/openapi.yaml`, and runtime registration is in `server/router/api/v1/v1.go`.
