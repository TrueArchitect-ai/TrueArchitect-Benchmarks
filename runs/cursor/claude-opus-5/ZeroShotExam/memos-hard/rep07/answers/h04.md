- `store/db/db.go` is the only file in the repo that imports `github.com/usememos/memos/store/db/mysql` (grep for that import path returns exactly one hit, line 8). - The one direct construction of the driver struct outside the factory path is a zero-value literal in the package's own test, bypassing `NewDB` because the function under test needs no live connection:

```11:16:/bench/repo/store/db/mysql/auth_config_test.go

A repo-wide search for `DB{` turns up no other MySQL cases; the other hits belong to the sqlite and postgres packages (`store/db/sqlite/sqlite.go:58`, `store/db/postgres/postgres.go:33`, and postgres tests, which follow the same test-only pattern).
