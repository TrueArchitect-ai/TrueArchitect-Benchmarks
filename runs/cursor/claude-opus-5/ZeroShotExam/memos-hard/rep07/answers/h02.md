How it fits together:

The API layer never sends the HTTP request itself. `server/router/api/v1/memo_service_webhooks.go` looks up the creator's registered webhooks on memo create/update/delete and comment-created, builds a `WebhookRequestPayload`, and calls `webhook.PostAsync` (lines 43 and 71). `PostAsync` only enqueues onto a buffered channel `asyncPostQueue` (capacity 128, dropping with a warning when full). The actual outbound delivery happens in `Post`, which is run by four worker goroutines started in the package `init()` of `internal/webhook/webhook.go`. `Post` marshals the JSON body, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), issues the POST via `safeClient.Do`, and validates the status code and response body.

The SSRF protection lives on the client's transport rather than in the request path:

```32:37:/bench/repo/internal/webhook/webhook.go
	safeClient = &http.Client{
		Timeout: timeout,
		Transport: &http.Transport{
			DialContext: safeDialContext,
		},
	}
```

`safeDialContext` (lines 59–77) splits host/port, resolves the hostname with `net.DefaultResolver.LookupHost`, and refuses to dial if any resolved address matches a reserved range. Because the check runs at dial time on the addresses actually being connected to, it also defeats DNS rebinding — the URL can't pass validation at registration and then resolve to loopback later.

The range list and predicate are in `internal/webhook/validate.go`: `reservedCIDRs` covers IPv4 loopback, all three RFC-1918 blocks, link-local `169.254.0.0/16` (explicitly noted as covering the cloud IMDS address `169.254.169.254`), plus IPv6 loopback, unique-local, and link-local. These are parsed once into `reservedNetworks` at init, and `isReservedIP` tests membership.

Two supporting pieces worth knowing:

- A second, earlier layer of defense: `webhook.ValidateURL` (validate.go lines 62–83) is called when webhooks are created or updated in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182). It enforces an absolute `http`/`https` URL and rejects hostnames resolving into reserved ranges, returning a gRPC `InvalidArgument`. This is validation-time only, which is why the dial-time check is the real guard.
- The protection is defeatable by the operator on purpose: `AllowPrivateIPs` (validate.go line 41) short-circuits `isReservedIP` to `false`, and it's wired to the `allow-private-webhooks` flag in `cmd/memos/main.go` line 49 — intended for self-hosted setups whose webhook targets are on the LAN.
