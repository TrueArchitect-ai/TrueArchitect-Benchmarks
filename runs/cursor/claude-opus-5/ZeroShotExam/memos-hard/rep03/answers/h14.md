**Answer: `RebuildMemoPayload` in `server/runner/memopayload/runner.go` (delegating to `Service.ExtractAll` in `internal/markdown/markdown.go`); triggered on memo create, on update when `content` is in the update mask, and by the batch `Runner.RunOnce` rebuild; it extracts the deduplicated `#tags` list plus the boolean/derived properties `has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks`, and `title` (text of a leading H1).**

Details:

**Computation site.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags` and `memo.Payload.Property`. The actual parsing lives in `ExtractAll` in `internal/markdown/markdown.go`, which does a single goldmark AST walk (there is an equivalent standalone `ExtractProperties` in the same file, but the payload path uses `ExtractAll`).

**Triggers.**
- Create: `CreateMemo` calls it on the new memo before `Store.CreateMemo` (`server/router/api/v1/memo_service.go:108`). Comments go through this same path, since `CreateMemoComment` calls `s.CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
- Update: only when the update mask contains `content` — `UpdateMemo` sets the new content, rebuilds, and puts the result into `update.Payload` (`server/router/api/v1/memo_service.go:447-451`). Other mask paths don't recompute; the `location` path writes `payload.Location` onto the existing payload without touching derived fields (`server/router/api/v1/memo_service.go:481-484`).
- Bulk backfill: `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) pages through all memos in batches of 100, rebuilding and persisting each payload. Note that this runner is not currently wired into startup — `server/server.go:163` only invokes the s3presign runner — so in practice recomputation happens on create/content-update.

**What is extracted.** From `ExtractAll`:
- `Tags`: text of every `TagNode` not nested inside a link or image (`asMemoTagNode`), deduplicated with case preserved.
- `Property.Title`: plain text of the document's first block-level child when it is an H1 heading.
- `Property.HasLink`: any `KindLink` node.
- `Property.HasCode`: any code block, fenced code block, or inline code span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks`: any task checkbox, and whether at least one is unchecked.

`ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` discards it; mentions are consumed separately in `server/router/api/v1/memo_mention_helpers.go:32`. The shape of the stored payload is defined in `proto/store/memo.proto` (`MemoPayload.Property`, commented "The calculated properties from the memo content").

One related but distinct piece: the preview `snippet` returned in API responses is *not* stored in the payload. It's generated per-read by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `GenerateSnippet(content, 64)` and is used in the memo converter (`server/router/api/v1/memo_service_converter.go:76`), relations, and notifications.
