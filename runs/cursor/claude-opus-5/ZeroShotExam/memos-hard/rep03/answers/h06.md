**Handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations` (all in `server/router/api/v1/`); **convergence function** — `webhook.Post` in `internal/webhook/webhook.go`

The user-configured URLs are the per-user webhook endpoints registered through `CreateUserWebhook`/`UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go` and stored per user, so every one of these paths ends up POSTing to an address the user chose.

How each handler reaches delivery:

- `CreateMemo` (`server/router/api/v1/memo_service.go:157`) calls `DispatchMemoCreatedWebhook`.
- `DeleteMemo` (`server/router/api/v1/memo_service.go:562`) calls `DispatchMemoDeletedWebhook`.
- `UpdateMemo` (`server/router/api/v1/memo_service.go:513`), `SetMemoAttachments` (`server/router/api/v1/memo_attachment_service.go:48`), and `SetMemoRelations` (`server/router/api/v1/memo_relation_service.go:48`) all go through the shared helper `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66`), which calls `DispatchMemoUpdatedWebhook`.
- `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:119`) calls `DispatchMemoCommentCreatedWebhook`, which dispatches to the *parent* memo owner's webhooks.

Those four `Dispatch*` methods live in `server/router/api/v1/memo_service_webhooks.go`; each loads the owner's webhooks via `s.Store.GetUserWebhooks`, fills in `payload.URL`/`payload.SigningSecret`, and hands the payload to `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` only enqueues onto a bounded channel; the four worker goroutines started in that package's `init` (`internal/webhook/webhook.go:42`) drain the queue and call `webhook.Post` (`internal/webhook/webhook.go:120`), which is the single place the outbound `http.Client.Do` actually happens, including HMAC signing and the SSRF-guarding dialer.

So if you want one chokepoint for auditing or policy enforcement on outbound webhook traffic, `webhook.Post` is it; `webhook.PostAsync` is the equivalent chokepoint on the enqueue side.

One nearby path worth distinguishing: `GetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:46`) also makes an outbound request via `httpgetter.GetHTMLMeta`, but the URL comes directly from the RPC request rather than from stored user configuration, and it does not go through `webhook.Post`.
