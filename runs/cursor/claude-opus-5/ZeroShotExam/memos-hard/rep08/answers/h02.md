**delivery function** — `Post` in `internal/webhook/webhook.go` (line 120); **protection mechanism** — dial-time SSRF guard `safeDialContext`/`safeClient` in `internal/webhook/webhook.go` (lines 32–77), backed by the reserved-CIDR check `isReservedIP` in `internal/webhook/validate.go`

How it fits together:

The actual outbound HTTP POST happens in `Post`, which marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and calls `safeClient.Do(req)`. Callers in `server/router/api/v1/memo_service_webhooks.go` never call `Post` directly — they use `PostAsync`, which enqueues onto a bounded 128-slot channel drained by four goroutines started in `init()`, so delivery executes on those background workers rather than on the request path.

There are two layers of SSRF protection:

1. **At delivery time (the real guard).** `safeClient` uses a custom `Transport.DialContext` = `safeDialContext`, which resolves the host itself and refuses to dial if *any* resolved address falls in a reserved range. Because the check happens at dial time rather than at URL-parse time, it also defeats DNS rebinding. The blocklist lives in `reservedCIDRs` in `internal/webhook/validate.go` and covers IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (cloud instance metadata), and the IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10`.

2. **At configuration time (defense in depth).** `ValidateURL` in `internal/webhook/validate.go` rejects non-`http`/`https` schemes and hostnames resolving to reserved IPs, returning a gRPC `InvalidArgument`. It's called when webhooks are created or updated in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182).

One caveat worth knowing: both layers can be turned off wholesale. `isReservedIP` returns `false` unconditionally when the package-level `webhook.AllowPrivateIPs` is set, which is wired to the `allow-private-webhooks` flag in `cmd/memos/main.go` line 49 — intended for self-hosted deployments targeting LAN services.
