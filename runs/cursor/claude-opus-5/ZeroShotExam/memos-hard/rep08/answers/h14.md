The derived metadata is the memo's stored `payload` (tags + calculated `Property`), built by `memopayload.RebuildMemoPayload`, which delegates to the goldmark-based markdown service's single-pass `ExtractAll`.

**Computation site**

- `server/runner/memopayload/runner.go` (lines 74–88): `RebuildMemoPayload` calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns `memo.Payload.Tags` and `memo.Payload.Property`.
- The actual extraction lives in `internal/markdown/markdown.go` in `service.ExtractAll` (lines 356–422), which parses the content to a goldmark AST and walks it once. `ExtractProperties` (lines 192–241) contains the same property logic for standalone use.

**Triggers**

- Memo creation: `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
- Memo update, only when the update mask includes the `content` path: `server/router/api/v1/memo_service.go:447`, after `memo.Content` is replaced; the rebuilt payload is written along with the content via `update.Payload`.
- A bulk backfill: `Runner.RunOnce` in `server/runner/memopayload/runner.go` (lines 27–72) pages through all memos in batches of 100, rebuilds each payload, and persists it with `UpdateMemo`. Note this runner is not currently wired into `server/server.go` (only the s3presign runner is started there), so in practice creation and content updates are the live triggers.

**Extracted properties**

From `ExtractAll` / `MemoPayload.Property` (defined in `proto/store/memo.proto` lines 14–22):

- `Tags`: every `#tag` node not nested inside a link or image, deduplicated with original case preserved (`uniquePreserveCase`).
- `Title`: text of the first block-level child of the document if it is an H1 heading.
- `HasLink`: any link node present.
- `HasCode`: any code block, fenced code block, or inline code span.
- `HasTaskList`: any GFM task checkbox present.
- `HasIncompleteTasks`: any task checkbox that is unchecked.
- `Mentions` are also collected by `ExtractAll` (lowercased, deduplicated), but `RebuildMemoPayload` does not persist them into the payload.

Separately, the short preview text shown in lists and relations is *not* stored: `Memo.Snippet` is generated on the fly at conversion time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `MarkdownService.GenerateSnippet(content, 64)` — plain text with code blocks skipped, truncated at a word boundary.
