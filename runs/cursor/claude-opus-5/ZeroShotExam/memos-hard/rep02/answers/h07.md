The browser never fetches raw image bytes from the user RPC — the API rewrites a stored base64 data URI into the URL `/file/users/{username}/avatar`, and a native Echo handler in the file server resolves that back to the `user.avatar_url` column.

Main hop chain (serving request):

`UserAvatar` (`<img src={avatarUrl}>`) — web/src/components/UserAvatar.tsx
`RegisterRoutes` (`GET /file/users/:identifier/avatar`) — server/router/fileserver/fileserver.go:124
`FileServerService.serveUserAvatar` — server/router/fileserver/fileserver.go:168
`FileServerService.getCurrentUser` → `Authenticator.AuthenticateToUser` (only when `Profile.AllowAnonymous()` is false) — server/router/fileserver/fileserver.go:708, server/auth/authenticator.go:190
`FileServerService.getUserByUsername` (builds `store.FindUser{Username}`) — server/router/fileserver/fileserver.go:715
`Store.GetUser` (userCache is consulted only for `find.ID`, so a username lookup always falls through) — store/user.go:148
`Store.ListUsers` (caches results by user ID) — store/user.go:136
`Driver.ListUsers` (interface) — store/driver.go:47
`NewDBDriver` (picks the concrete driver) — store/db/db.go:14
`DB.ListUsers` (`SELECT ... avatar_url ... FROM user WHERE username = ?`) — store/db/sqlite/user.go:88, with equivalents in store/db/postgres/user.go and store/db/mysql/user.go
`user.avatar_url` column — store/migration/sqlite/LATEST.sql:20 (added in store/migration/sqlite/0.11/00__user_avatar.sql)

Back in the handler, `FileServerService.parseDataURI` (server/router/fileserver/fileserver.go:737) splits the stored `data:image/...;base64,...` string, the MIME type is checked against `avatarAllowedTypes` (fileserver.go:75), and the decoded bytes go out via `c.Blob` with `Cache-Control: public, max-age=3600`.

How the URL got to the browser in the first place: `convertUserFromStore` — server/router/api/v1/user_service_converters.go:16. If `user.AvatarURL` parses as base64 image data it replaces the field with `/file/{userpb.Name}/avatar` (line 36, where `Name` is `users/{username}` from `BuildUserName` in server/router/api/v1/user_resource_name.go:13); otherwise the stored external URL is passed through unchanged and the browser fetches it directly, bypassing everything above.
