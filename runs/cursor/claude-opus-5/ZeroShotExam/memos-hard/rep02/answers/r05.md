There is no GraphQL schema in this repository — the premise is incorrect. A case-insensitive search for "graphql" across the entire tree returns zero matches, and there are no `.graphql`, `.gql`, or `.graphqls` files anywhere. There is no schema-definition-language file, no resolver layer, and no GraphQL server dependency in `go.mod`/`go.sum`.

This is Memos, a Go application whose public API is defined in Protocol Buffers and exposed as REST + gRPC (the `README.md` advertises "full REST and gRPC APIs").

**Where the API surface is actually defined**

The source of truth is the set of `.proto` files in `proto/api/v1/`, one per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared messages in `common.proto`. Each RPC carries a `google.api.http` annotation that defines its REST mapping — for example, `CreateMemo` is annotated `post: "/api/v1/memos"` and `GetMemo` is `get: "/api/v1/{name=memos/*}"` in `proto/api/v1/memo_service.proto`. The design follows Google's API Improvement Proposals, as stated in `proto/api/v1/README.md`.

**How it is generated and served**

`proto/buf.gen.yaml` drives `buf generate`, which emits Go protobuf/gRPC/Connect/grpc-gateway code into `proto/gen/api/v1/` (including `proto/gen/api/v1/apiv1connect/`), TypeScript clients into `web/src/types/proto/`, and an OpenAPI 3.0 document at `proto/gen/openapi.yaml` (~4,000 lines, embedded into the binary by `proto/openapi_embed.go`). That OpenAPI file is the closest analogue to the "schema" you were asking about.

At runtime, `server/server.go` calls `apiV1Service.RegisterGateway`, implemented at `server/router/api/v1/v1.go:65`, which mounts both a grpc-gateway mux for the REST routes and the Connect RPC handlers registered in `server/router/api/v1/connect_handler.go`. Business logic lives in the per-service files under `server/router/api/v1/` such as `memo_service.go` and `user_service.go`, and unauthenticated/public routes are allow-listed in `server/router/api/v1/acl_config.go`.

Two additional non-GraphQL surfaces exist alongside it: an RSS router (`server/router/rss/`) and an MCP server (`server/router/mcp/`).
