**Mechanism: explicit Go code.** Emoji reactions are removed by hand-written `DELETE FROM reaction` statements executed inside the delete-user transaction in each database driver. There is no database-level cascade, foreign key, or trigger that would do it.

Two separate deletes run, covering both directions of the relationship:

- Reactions *on* the deleted user's memos (regardless of who reacted), matched by `content_id`, which is built as `"memos/" + memo.UID` from the recursive memo tree (the user's memos plus comment descendants).
- Reactions *by* the deleted user on anyone's content, matched by `creator_id`.
