**`s3presign.Runner` (`server/runner/s3presign/runner.go`) — once immediately at startup, then on a 12-hour ticker — wired in `server/server.go:162` (inside `startBackgroundRunners`, which `Start` calls at `server/server.go:129`).**

How it works:

- The runner re-signs S3 presigned GET URLs for attachments so the stored `reference` link doesn't expire. It's defined in `server/runner/s3presign/runner.go`, with the interval declared as `runnerInterval = time.Hour * 12` (line 27) and consumed by a `time.Ticker` in `Run` (lines 29–41).
- `RunOnce` → `CheckAndPresign` pages through attachments with `StorageType == AttachmentStorageType_S3` in batches of 100, skips any whose `LastPresignedTime` is under 4 days old (URLs are issued with a 5-day expiry, so it refreshes with a day of slack), calls `s3.NewClient(...).PresignGetObject(...)`, and writes the new URL back via `store.UpdateAttachment` along with an updated `LastPresignedTime`.
- Startup wiring in `server/server.go`: `startBackgroundRunners` creates a cancelable child context (line 156), constructs the runner (line 162), does an immediate synchronous `RunOnce(ctx)` (line 163) so links are fresh right after boot, then launches `Run(s3Context)` in a tracked goroutine (lines 166–171). Shutdown cancels that context via `stopBackgroundRunners` (line 176) and waits on the WaitGroup in `waitBackgroundRunners` (line 184).
