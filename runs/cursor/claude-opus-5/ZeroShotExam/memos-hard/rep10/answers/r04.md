**Premise correction:** Neither. This repository (memos) has no message broker at all — there is no NATS, RabbitMQ, AMQP, Kafka, or Redis dependency anywhere in `go.mod`/`go.sum`, and no broker client code. The "workers" and "queue" are entirely in-process Go constructs.

**Actual mechanism:** Webhook delivery uses a buffered Go channel drained by a fixed pool of goroutines, all inside a single `memos` process.

The queue is a package-level channel with capacity 128, declared in `internal/webhook/webhook.go`:

```39:40:/bench/repo/internal/webhook/webhook.go
	asyncPostQueue = make(chan *WebhookRequestPayload, 128)
)
```

Four consumer goroutines are launched from that package's `init()`, each looping over the channel and performing the HTTP POST directly:

```42:55:/bench/repo/internal/webhook/webhook.go
func init() {
	for range 4 {
		go func() {
			for payload := range asyncPostQueue {
				if err := Post(payload); err != nil {
					slog.Warn("Failed to dispatch webhook asynchronously",
						slog.String("url", payload.URL),
						slog.String("activityType", payload.ActivityType),
						slog.Any("err", err))
				}
			}
		}()
	}
}
```

Producers call `webhook.PostAsync`, which does a non-blocking send with a `default` branch — so when the buffer is full the payload is **dropped** with a warning rather than queued or retried (`internal/webhook/webhook.go` lines 184-196). There is no persistence, no acknowledgement, and no redelivery: an in-flight or buffered webhook is lost on process restart.

Call sites that feed the queue are in `server/router/api/v1/memo_service_webhooks.go` (memo created/updated/deleted and comment-created events, lines 43 and 71), which fetch each user's webhook targets via `s.Store.GetUserWebhooks` — webhook registrations themselves are stored as user settings (`store/user_setting.go`, `proto/store/user_setting.proto`), not in any broker.

The actual delivery work — HMAC-SHA256 signing per the Standard Webhooks spec and the SSRF-guarded HTTP client — happens in `Post` in the same file (lines 120-180).
