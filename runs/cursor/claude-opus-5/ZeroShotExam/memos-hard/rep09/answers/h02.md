**delivery function — `Post` in `internal/webhook/webhook.go` (line 120); protection mechanism — `safeDialContext`/`isReservedIP` dial-time IP blocking in `internal/webhook/webhook.go` (line 59) backed by `internal/webhook/validate.go`**

How it fits together:

**Delivery.** `webhook.Post` (`internal/webhook/webhook.go:120`) is where the outbound HTTP call actually happens: it marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and calls `safeClient.Do(req)` at line 152. Callers never invoke it directly — the API layer calls `webhook.PostAsync` (line 184), which enqueues onto a bounded 128-slot channel drained by four goroutines started in `init()` (lines 42–55); those workers are what call `Post`. The triggers are in `server/router/api/v1/memo_service_webhooks.go`, where `dispatchMemoRelatedWebhook` and `DispatchMemoCommentCreatedWebhook` fan out over each user's registered webhooks for memo created/updated/deleted and comment-created events.

**Protection.** The primary defense is at dial time, not URL-parse time. The shared `safeClient` (`internal/webhook/webhook.go:32`) installs a custom `http.Transport` whose `DialContext` is `safeDialContext` (line 59). That function splits the host/port, resolves the hostname via `net.DefaultResolver.LookupHost`, and rejects the connection if any resolved address satisfies `isReservedIP`. Because the check runs on the address that is about to be connected to, it also defeats DNS rebinding, which a validate-once-at-registration check would miss.

`isReservedIP` and the blocklist live in `internal/webhook/validate.go`: `reservedCIDRs` (lines 14–23) covers IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (which includes the cloud metadata endpoint `169.254.169.254`), and the IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10`, parsed once at startup into `reservedNetworks`.

Two things worth knowing:

- There's a second, earlier layer: `webhook.ValidateURL` (`internal/webhook/validate.go:62`) runs when a user registers or updates a webhook, enforcing an absolute http/https URL that doesn't resolve to a reserved IP. It's called from `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182). This is defense-in-depth and user-facing error reporting; the dial-time check is what actually protects delivery.
- The protection is globally defeatable by design. `AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` to `false`, disabling both layers. It's wired to the `allow-private-webhooks` config flag in `cmd/memos/main.go:49` for self-hosted setups that legitimately target LAN services.
