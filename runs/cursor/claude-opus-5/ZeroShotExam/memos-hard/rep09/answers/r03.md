The premise is incorrect: there is no nightly database-cleanup job in this repository. The cron scheduler in `internal/scheduler` is a standalone, zero-dependency library package that the application never uses — the only Go files importing `github.com/usememos/memos/internal/scheduler` are its own tests (`internal/scheduler/example_test.go` and `internal/scheduler/integration_test.go`). No job is registered anywhere in `cmd/`, `server/`, or `store/`.

The background work that actually runs is wired up in `server/server.go` through `startBackgroundRunners` (line 153), and it is interval-based rather than cron-scheduled: the S3 presign refresh runner in `server/runner/s3presign/runner.go` runs once at startup and then every 12 hours via a `time.Ticker`, and the in-memory store cache in `store/cache/cache.go` sweeps expired entries every 5 minutes (`CleanupInterval` default set in `store/store.go` line 42). Neither is a nightly database cleanup.
