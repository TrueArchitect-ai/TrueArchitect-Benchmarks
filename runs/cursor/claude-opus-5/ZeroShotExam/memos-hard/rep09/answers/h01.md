**S3 presign background runner — every 12 hours (plus one immediate pass at startup) — `server/server.go:162-171`, launched from `startBackgroundRunners`, which itself is called at `server/server.go:129`**

The component is `s3presign.Runner`, defined in `server/runner/s3presign/runner.go`. Attachments stored in S3 are served through presigned URLs, which expire (the code notes a 5-day expiration), so the runner keeps them fresh.

How it works, from `server/runner/s3presign/runner.go`:

- `runnerInterval = time.Hour * 12` (line 27) drives a `time.Ticker` in `Run`, which calls `RunOnce` on each tick.
- `CheckAndPresign` pages through attachments with `StorageType: S3` in batches of 100, and for each one whose `LastPresignedTime` is older than 4 days (i.e. within a day of the 5-day expiry) it creates an S3 client, calls `PresignGetObject`, and writes the new URL back via `store.UpdateAttachment` along with an updated `LastPresignedTime`. Attachments still valid for more than 4 days are skipped, so most passes do little work.
