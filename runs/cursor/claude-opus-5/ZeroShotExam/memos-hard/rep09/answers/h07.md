**Origin of the URL (why the browser requests it):** the API returns `avatarUrl` as a relative path `/file/users/{username}/avatar` (built from `BuildUserName`) whenever the stored avatar is a base64 data URI, and `web/src/components/UserAvatar.tsx` renders it as an `<img src>`. So another user's profile image is a plain HTTP GET, not an RPC — the `/memos.api.v1.UserService/GetUserAvatar` entry in `server/router/api/v1/acl_config.go` is a leftover with no corresponding RPC implementation.
