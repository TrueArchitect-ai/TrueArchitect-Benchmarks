**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

The data layer is the Go `store` package tree, where the persistent entity structs are declared: `store.User` (`store/user.go:29`), `store.Memo` (`store/memo.go:35`), plus `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `UserIdentity`, `UserSetting`, `InstanceSetting`, and `IdentityProvider`.

Counting distinct Go packages outside the `store/` tree that reference each type:

| Entity type | Packages outside `store/` |
|---|---|
| `store.User` | 7 |
| `store.Memo` | 6 |
| `store.Attachment` | 4 |
| `store.Inbox` / `MemoRelation` / `MemoShare` | 3 each |
| `store.Reaction` / `UserIdentity` | 2 each |

`store.User` is referenced from `server/auth` (`server/auth/authenticator.go`, `server/auth/context.go`), `server/notification` (`server/notification/email.go`), `server/router/api/v1` (many files including `user_service.go`, `auth_service_sso.go`, `memo_service_converter.go`), `server/router/api/v1/test`, `server/router/fileserver` (`fileserver.go`), `server/router/frontend`, and `server/router/rss` (`rss.go`).

`store.Memo` reaches one fewer package: it appears in `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, and `server/runner/memopayload` (`server/runner/memopayload/runner.go`), but not in `server/auth` or `server/router/fileserver`.

One caveat on methodology: `IdentityProvider`, `InstanceSetting`, and `UserSetting` initially looked like they had external references, but those hits were all protobuf full-name string literals in generated code under `proto/gen/store/` (e.g. `memos.store.UserSetting.Key` in `proto/gen/store/user_setting.pb.go`), not Go type references. Server code handles those concepts through the `storepb` protobuf types instead, so their true external package count is zero. Test packages are counted as separate packages from their non-test siblings; if you exclude test packages, the counts drop to 6 for `User` and 5 for `Memo`, but the ranking is unchanged.
