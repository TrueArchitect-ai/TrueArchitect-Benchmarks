**Premise correction: there is no GraphQL schema in this repository.** An exhaustive case-insensitive search for `graphql`, `gqlgen`, and `apollo` across all source (excluding `.git`, `node_modules`, and lockfiles) returns zero matches, and there are no `.graphql`, `.gql`, or `.graphqls` files anywhere. This is Memos, a self-hosted note-taking app whose public API is defined with Protocol Buffers, not GraphQL. `README.md` advertises "full REST and gRPC APIs," and `AGENTS.md` lists the backend stack as "Echo v5, Connect RPC, gRPC-Gateway, Protocol Buffers."

## The actual API surface

**Source of truth: `.proto` files in `proto/api/v1/`.** Eight services are defined there, one per file:

| File | Service |
| --- | --- |
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto` | `AIService` |

Shared messages live in `proto/api/v1/common.proto`; internal storage messages (not part of the public API) are in `proto/store/`.

Each RPC carries a `google.api.http` annotation that defines its REST binding, so the REST routes are declared inline alongside the RPCs rather than in a separate spec:

```17:33:proto/api/v1/memo_service.proto
service MemoService {
  // CreateMemo creates a memo. The request body is a Memo; set its content
  // (Markdown) and visibility (PRIVATE | PROTECTED | PUBLIC, default PRIVATE).
  // The memo is owned by the authenticated user; requires authentication.
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = {
      post: "/api/v1/memos"
      body: "memo"
    };
    option (google.api.method_signature) = "memo";
  }
  // ListMemos lists memos with pagination and filter.
  rpc ListMemos(ListMemosRequest) returns (ListMemosResponse) {
    option (google.api.http) = {get: "/api/v1/memos"};
    option (google.api.method_signature) = "";
  }
```

**Code generation is driven by `proto/buf.gen.yaml`** (run via `cd proto && buf generate`). It emits Go protobuf/gRPC/Connect/gateway stubs plus a gnostic OpenAPI document into `proto/gen/`, and TypeScript clients into `web/src/types/proto/`. Per `AGENTS.md`, generated outputs must never be hand-edited.

**The closest analogue to "a schema document for the public API" is the generated OpenAPI spec at `proto/gen/openapi.yaml`.** It is compiled into the binary by `proto/openapi_embed.go` via `//go:embed gen/openapi.yaml`, exposed as `proto.OpenAPIYAML()`, and consumed by the MCP service at `server/router/mcp/service.go:78` to build its tool catalog.

**Serving.** `server/server.go:88` calls `apiV1Service.RegisterGateway`, implemented at `server/router/api/v1/v1.go:65`. That mounts three route families:

- REST/JSON through gRPC-Gateway at `/api/v1/*` and `/file/*` (`v1.go:128-129`)
- Connect RPC at `/memos.api.v1.*` (`v1.go:144`), with handlers registered in `server/router/api/v1/connect_handler.go` via `apiv1connect.New*ServiceHandler`
- Server-sent events on the same CORS group as `/api/v1`

Service implementations are the Go files in `server/router/api/v1/` (`memo_service.go`, `user_service.go`, etc.); `connect_services.go` is a thin adapter that delegates each Connect method to the corresponding gRPC implementation. Authentication and anonymous-access policy are centralized in `server/router/api/v1/acl_config.go`, which `AGENTS.md` names as the required place to register public unauthenticated endpoints.

**Non-proto HTTP surfaces** also exist outside `/api/v1`: `server/router/rss/` (RSS feeds), `server/router/fileserver/` (native file serving with range requests), `server/router/mcp/` (Model Context Protocol), `server/router/frontend/` (SPA static assets), and a plain `/healthz` endpoint at `server/server.go:67`.
