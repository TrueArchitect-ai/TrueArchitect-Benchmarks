### Why this one, out of three candidates

There are three `CreateMemo` implementations that all issue a memo INSERT, and the store layer is driver-agnostic, so the file you're reading can't tell you which runs:

- `store/db/sqlite/memo.go:16`
- `store/db/mysql/memo.go:16`
- `store/db/postgres/memo.go:16`

The save path itself is fixed and has no branching: the API handler `APIV1Service.CreateMemo` calls `s.Store.CreateMemo` (`server/router/api/v1/memo_service.go:115`), which validates the UID and then delegates straight to the interface (`store/memo.go:113`, `return s.driver.CreateMemo(ctx, create)`). `CreateMemo` is declared on the `store.Driver` interface at `store/driver.go:29`, and `store.New` stores the driver value as-is with no caching or decorating wrapper around it (`store/store.go`), so the concrete type of that one field decides everything.

With no database flags, `profile.Driver` is `"sqlite"`: it comes from `viper.GetString("driver")` (`cmd/memos/main.go:43`), whose default is set twice as `sqlite` — `viper.SetDefault("driver", "sqlite")` (line 122) and the flag default on line 130. `sqlite.NewDB` returns `*sqlite.DB` (`store/db/sqlite/sqlite.go`), so `s.driver.CreateMemo` resolves to the SQLite method.

I also ruled out the deployment layer silently overriding the default: the published image sets only `TZ` and `MEMOS_PORT` (`scripts/Dockerfile:51-52`), and the entrypoint only massages `MEMOS_DSN` via the `_FILE` secret helper — neither sets `MEMOS_DRIVER` (`scripts/entrypoint.sh`). A note on the likely mix-up: the MySQL implementation is the easiest to confuse with the SQLite one, since both quote identifiers with backticks and share nearly identical field-building code. They diverge in the parts that matter — SQLite binds timestamps as plain `?` and reads the generated row back with `RETURNING` + `QueryRowContext`, whereas MySQL wraps them in `FROM_UNIXTIME(?)` and uses `ExecContext` plus `LastInsertId` (`store/db/mysql/memo.go:29-45`). Postgres uses `$n` placeholders (`store/db/postgres/memo.go:38`).
