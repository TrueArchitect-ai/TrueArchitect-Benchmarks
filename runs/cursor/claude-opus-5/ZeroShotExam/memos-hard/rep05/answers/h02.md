**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120); **protection mechanism** — the SSRF-blocking dialer `safeDialContext` in the same file (line 59), backed by `isReservedIP` and the `reservedCIDRs` list in `internal/webhook/validate.go`.

How it fits together:

Webhook dispatch is triggered from `server/router/api/v1/memo_service_webhooks.go`, which calls `webhook.PostAsync` (lines 43 and 71). That function only enqueues the payload onto a bounded 128-slot channel; the actual HTTP request is made by `Post`, run on four background worker goroutines started in the package `init` in `internal/webhook/webhook.go`. `Post` marshals the payload, optionally attaches Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and sends it via the shared `safeClient`.

The protection is enforced at dial time rather than only at URL-parse time. `safeClient`'s transport uses `safeDialContext`, which resolves the hostname itself and rejects the connection if any resolved address falls in a reserved range. Doing the check at dial time is what defeats DNS rebinding, since a name that passed validation earlier can't later point at loopback. The blocked ranges in `internal/webhook/validate.go` are IPv4 loopback, the three RFC-1918 blocks, link-local `169.254.0.0/16` (which covers the cloud metadata endpoint at 169.254.169.254), and the IPv6 equivalents `::1/128`, `fc00::/7`, and `fe80::/10`.

There is a second, earlier layer: `webhook.ValidateURL` is called when a user creates or updates a webhook, in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182). It requires an absolute http/https URL and rejects hostnames that resolve into the same reserved ranges, returning a gRPC `InvalidArgument`.

Both layers share the `isReservedIP` helper, so both are disabled together by the package-level `AllowPrivateIPs` flag, which is set from the `allow-private-webhooks` config value in `cmd/memos/main.go` (line 49) for self-hosted setups that legitimately target LAN services.
