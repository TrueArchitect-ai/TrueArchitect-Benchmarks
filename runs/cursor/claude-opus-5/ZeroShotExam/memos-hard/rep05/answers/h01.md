**`s3presign.Runner` (the S3 presign background runner, `server/runner/s3presign/runner.go`) — runs once synchronously at startup, then on a ticker every 12 hours — wired in `server/server.go:162-171` (called from `startBackgroundRunners` at `server/server.go:129`).**

How it works:

- The runner is defined in `server/runner/s3presign/runner.go`. Its interval is a package constant:

```26:27:server/runner/s3presign/runner.go
// Schedule runner every 12 hours.
const runnerInterval = time.Hour * 12
```

- `Run` loops on a `time.Ticker` of that interval and calls `RunOnce` → `CheckAndPresign` (lines 29–45). `CheckAndPresign` pages through attachments with `StorageType = AttachmentStorageType_S3` in batches of 100, and for each one re-generates a presigned GET URL via `s3.NewClient(...).PresignGetObject(ctx, key)`, then writes the new URL into the attachment's `Reference` field along with an updated `LastPresignedTime`.
- The staleness guard is the 4-day/5-day window: it skips any attachment whose presigned URL is still valid for the next 4 days, since presigned URLs are issued with a 5-day expiration (lines 85–91). That's what keeps the stored links from expiring.

- Wiring at startup: `Server.Start` calls `s.startBackgroundRunners(ctx)` at `server/server.go:129`, and that function constructs the runner, does an immediate synchronous pass, then launches the periodic loop on its own cancellable context:

```161:171:server/server.go
	// Create and start S3 presign runner
	s3presignRunner := s3presign.NewRunner(s.Store)
	s3presignRunner.RunOnce(ctx)

	// Start continuous S3 presign runner
	s.backgroundRunnerWG.Add(1)
	go func() {
		defer s.backgroundRunnerWG.Done()
		s3presignRunner.Run(s3Context)
		slog.Info("s3presign runner stopped")
	}()
```

The cancel func stored at `server/server.go:159` is what `stopBackgroundRunners` uses during shutdown to stop the loop.
