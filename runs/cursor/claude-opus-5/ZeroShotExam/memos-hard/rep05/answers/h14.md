**Answer (computation site; triggers; extracted properties)**

**Computation site.** `RebuildMemoPayload` in `server/runner/memopayload/runner.go` (lines 74–88) is the single place the derived payload is built. It ensures `memo.Payload` exists and then delegates the actual analysis to the markdown service's `ExtractAll`, implemented with a single goldmark AST walk in `internal/markdown/markdown.go` (lines 356–422). The result is assigned to `memo.Payload.Tags` and `memo.Payload.Property`, whose schema is `MemoPayload.Property` in `proto/store/memo.proto` (lines 7–22, commented "The calculated properties from the memo content").

**Triggers.** Only two call sites in production code, both in `server/router/api/v1/memo_service.go`:
- Memo creation, line 108, before `CreateMemo` writes the row.
- Memo update, line 447, but only inside the `path == "content"` branch of the update mask loop; the rebuilt payload is then attached via `update.Payload = memo.Payload` (line 451). Other update paths do not recompute it — the `location` branch at lines 481–484 mutates `Payload.Location` (user-supplied, not derived) and writes it back, and paths like visibility/pinned/state leave the payload untouched.

There is also a batch backfill, `Runner.RunOnce` in `server/runner/memopayload/runner.go` (lines 27–72), which pages through all memos 100 at a time and rewrites each payload. Note that nothing currently constructs it: `memopayload.NewRunner` has no callers (`server/server.go` only wires `s3presign.NewRunner`), so in the current code it is dormant.

**Extracted properties.** From `ExtractAll`:
- `Tags` — every `#tag` node not nested inside a link or image (`asMemoTagNode`, lines 134–140), deduplicated with original case preserved by `uniquePreserveCase`.
- `Property.Title` — the text of the first block-level document child if it is an H1 heading (lines 384–389, via `extractHeadingText`).
- `Property.HasLink` — any link node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any GFM task checkbox.
- `Property.HasIncompleteTasks` — at least one checkbox that is unchecked.

`ExtractAll` also collects `Mentions` (lowercased `@username`), but `RebuildMemoPayload` discards that field since the payload has no place for it. `ExtractProperties` (lines 193–241) duplicates the property logic standalone.

**Separate from this:** the list/preview `snippet` is *not* stored in the payload. It is generated per-response at conversion time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go` line 83), calling `GenerateSnippet(content, 64)` (`internal/markdown/markdown.go` lines 264–346), which flattens the AST to plain text, skips fenced/indented code blocks, and truncates at a word boundary. It is used in `memo_service_converter.go` (lines 76–80, 225, 248), `memo_relation_service.go`, and `user_service_notifications.go`.
