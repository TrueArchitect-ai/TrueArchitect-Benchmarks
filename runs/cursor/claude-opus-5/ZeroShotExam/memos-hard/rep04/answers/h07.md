The browser hits `GET /file/users/{username}/avatar` (that path comes from `convertUserFromStore`, which rewrites a base64 avatar into `/file/users/{username}/avatar` so the JSON payload stays small; the React `UserAvatar` component just puts it in an `<img src>`). The image bytes themselves are not files on disk — they live in the `user.avatar_url` column as a `data:` URI, which the handler decodes into a blob at request time.

Hops:

- `UserAvatar` (`<img src={avatarUrl}>`) — `web/src/components/UserAvatar.tsx`
- `convertUserFromStore` (mints `/file/{users/username}/avatar` for base64 avatars) — `server/router/api/v1/user_service_converters.go`
- `FileServerService.RegisterRoutes` (`fileGroup.GET("/users/:identifier/avatar", ...)`) — `server/router/fileserver/fileserver.go`
- `FileServerService.serveUserAvatar` (serving handler) — `server/router/fileserver/fileserver.go`
- `FileServerService.getCurrentUser` → `Authenticator.AuthenticateToUser` (only when `Profile.AllowAnonymous()` is false) — `server/router/fileserver/fileserver.go`, `server/auth/authenticator.go`
- `FileServerService.getUserByUsername` — `server/router/fileserver/fileserver.go`
- `Store.GetUser` (`&store.FindUser{Username: &identifier}`; the `userCache` fast path is keyed by ID only, so a username lookup always falls through) — `store/user.go`
- `Store.ListUsers` — `store/user.go`
- `Driver.ListUsers` (interface) — `store/driver.go`
- `DB.ListUsers` (`SELECT ... avatar_url ... FROM user WHERE username = ?`, scanned into `store.User.AvatarURL`) — `store/db/sqlite/user.go`, `store/db/postgres/user.go`, `store/db/mysql/user.go`
- `FileServerService.parseDataURI` (base64-decodes `AvatarURL` into image bytes) — `server/router/fileserver/fileserver.go`
- `c.Blob` (after `avatarAllowedTypes` MIME check, `setSecurityHeaders`, and `Cache-Control: public, max-age=3600`) — `server/router/fileserver/fileserver.go`

Route ordering matters here: `fileServerService.RegisterRoutes(echoServer)` is deliberately called before the gRPC-Gateway registration in `server/server.go`.
