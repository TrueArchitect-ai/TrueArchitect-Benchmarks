**handlers:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`; **convergence function** — `PostAsync` → `Post` in `internal/webhook/webhook.go` (`Post` is where the HTTP request is actually issued)

All six are gRPC handlers on `APIV1Service` in `server/router/api/v1/`, and the user-configured URL comes from a user's stored webhooks (`s.Store.GetUserWebhooks`, target `hook.Url`).

How each handler reaches the dispatcher:

- `CreateMemo` (`server/router/api/v1/memo_service.go:70`) calls `DispatchMemoCreatedWebhook` at line 157.
- `DeleteMemo` (`server/router/api/v1/memo_service.go:518`) calls `DispatchMemoDeletedWebhook` at line 562.
- `UpdateMemo` (`server/router/api/v1/memo_service.go:401`) calls `dispatchMemoUpdatedSideEffects` at line 513, which calls `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go:67`).
- `SetMemoAttachments` (`server/router/api/v1/memo_attachment_service.go:16`) and `SetMemoRelations` (`server/router/api/v1/memo_relation_service.go:16`) both reach the same `dispatchMemoUpdatedSideEffects` helper at line 48 of their files.
- `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:20`) calls `DispatchMemoCommentCreatedWebhook` at line 119 (and also triggers the created-memo webhook through its internal memo creation).

The three memo dispatchers funnel into `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), while the comment case builds its payload inline (line 30). Both then call `webhook.PostAsync` (lines 71 and 43), which is the sole call-graph convergence point: it enqueues onto `asyncPostQueue`, and four worker goroutines started in `init()` drain that queue into `Post` (`internal/webhook/webhook.go:120`), the only place an `http.Client.Do` against the configured URL happens.

Note on SSRF handling: the URL is validated at configuration time in `internal/webhook/validate.go` (scheme check plus DNS resolution against reserved CIDRs, bypassable via the `allow-private-webhooks` flag wired in `cmd/memos/main.go:49`), and again at dial time by `safeDialContext` on the shared `safeClient`.
