How it works:

- The runner is defined in `server/runner/s3presign/runner.go`. Its interval is a package constant, `runnerInterval = time.Hour * 12` (line 27), and `Run` drives a `time.Ticker` on that interval, calling `RunOnce` → `CheckAndPresign` each tick until its context is cancelled.
- `CheckAndPresign` pages through attachments whose storage type is S3 in batches of 100, re-signs each object's GET URL via `s3.NewClient(...).PresignGetObject(...)`, and writes the new URL back to the attachment's `Reference` field along with an updated `LastPresignedTime`.
