**Where delivery executes**

The actual HTTP request is built and sent by `Post` in `internal/webhook/webhook.go`. It marshals the `WebhookRequestPayload` to JSON, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and issues the request via the package-level `safeClient`:

Callers in the memo API don't call `Post` directly — they call `PostAsync` (`server/router/api/v1/memo_service_webhooks.go`, lines 43 and 71), which enqueues onto a buffered channel (`asyncPostQueue`, capacity 128, dropping with a warning when full). Four worker goroutines started in `init()` drain that queue and invoke `Post`, so delivery physically executes on those workers.

**What protects it from internal addresses**

Two layers, both driven by the same reserved-range list:

1. **Dial-time SSRF guard (the real protection).** `safeClient`'s `http.Transport` uses `safeDialContext` (`internal/webhook/webhook.go`, lines 57–77), which resolves the hostname itself and rejects the connection if *any* resolved IP is in a reserved range. Because the check happens at dial time rather than at save time, it also defeats DNS rebinding.

2. **Validation at configuration time.** `ValidateURL` in `internal/webhook/validate.go` (lines 62–83) requires an absolute `http`/`https` URL and rejects hostnames resolving to reserved IPs, returning a gRPC `InvalidArgument`. It's called when webhooks are created/updated in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182).

The blocklist itself is `reservedCIDRs` in `internal/webhook/validate.go` (lines 14–23): IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (covering the cloud IMDS endpoint `169.254.169.254`), plus IPv6 `::1/128`, `fc00::/7`, and `fe80::/10`. These are parsed once at startup into `reservedNetworks`, and `isReservedIP` does the containment test.

**One important caveat:** the guard is globally defeatable. `isReservedIP` returns `false` immediately when the package variable `webhook.AllowPrivateIPs` is set, which is wired to the `allow-private-webhooks` config flag in `cmd/memos/main.go` (line 49) — an intentional escape hatch for self-hosted deployments targeting LAN services. Also note that other reserved ranges are *not* covered: `0.0.0.0/8`, carrier-grade NAT `100.64.0.0/10`, and IPv4-mapped IPv6 forms like `::ffff:127.0.0.1` would pass, since `net.ParseIP` yields a 16-byte representation that `network.Contains` won't match against the 4-byte IPv4 CIDRs.
