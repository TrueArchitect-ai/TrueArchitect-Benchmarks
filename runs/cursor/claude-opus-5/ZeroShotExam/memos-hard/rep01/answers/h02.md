The outbound HTTP request is actually built and sent by `Post`, which marshals the payload, adds the Standard Webhooks HMAC-SHA256 signature headers when a signing secret is configured, and calls `safeClient.Do(req)`:

Callers never invoke `Post` directly. The API layer calls `webhook.PostAsync` (`internal/webhook/webhook.go`), which enqueues onto a bounded 128-slot channel drained by four worker goroutines started in `init()`; those workers are what run `Post`. The memo lifecycle triggers live in `server/router/api/v1/memo_service_webhooks.go` (`DispatchMemoCreatedWebhook`, `...Updated`, `...Deleted`, and `DispatchMemoCommentCreatedWebhook`).

Two layers guard against internal addresses:

The primary, load-bearing one is at dial time. The shared `safeClient` uses a `Transport` whose `DialContext` is `safeDialContext`, which resolves the hostname itself and refuses the connection if any resolved address falls in a reserved range. Because the check happens on the resolved IP at connection time rather than on the stored URL, it also defeats DNS rebinding.

```59:77:internal/webhook/webhook.go
func safeDialContext(ctx context.Context, network, addr string) (net.Conn, error) {
	host, port, err := net.SplitHostPort(addr)
	ips, err := net.DefaultResolver.LookupHost(ctx, host)
	for _, ipStr := range ips {
		if ip := net.ParseIP(ipStr); ip != nil && isReservedIP(ip) {
			return nil, errors.Errorf("webhook: connection to reserved/private IP address is not allowed")
		}
	}
	return (&net.Dialer{}).DialContext(ctx, network, net.JoinHostPort(host, port))
}
```

The secondary layer is validation at configuration time: `webhook.ValidateURL` in `internal/webhook/validate.go` requires an absolute `http`/`https` URL that does not resolve to a reserved IP, and it is called when users create or update webhooks in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182), returning a gRPC `InvalidArgument` error.

Both layers share `isReservedIP`, which tests against `reservedNetworks` parsed from `reservedCIDRs` — IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (covering the cloud metadata endpoint at 169.254.169.254), plus the IPv6 loopback, unique-local, and link-local equivalents (`internal/webhook/validate.go` lines 14–23).

One caveat worth flagging: the whole mechanism can be switched off. `isReservedIP` returns `false` unconditionally when the package-level `AllowPrivateIPs` flag is set, which is bound to the `--allow-private-webhooks` CLI flag (default `false`) in `cmd/memos/main.go` at lines 49, 133, and 160. Note also that `safeDialContext` does not cover redirects to a *different* host in a way separate from dialing — but since redirects go through the same client and therefore the same dialer, redirect targets are checked too.
