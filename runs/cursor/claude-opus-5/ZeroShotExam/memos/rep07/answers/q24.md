How each hop connects:

- `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` (line 178) wraps a TanStack `useMutation` whose `mutationFn` calls `memoServiceClient.createMemo({ memo: memoToCreate })` and then invalidates memo lists/user stats. (`web/src/components/MemoEditor/services/memoService.ts` is an alternate entry that calls the same client method.)
- `web/src/connect.ts` — `memoServiceClient = createClient(MemoService, transport)` (line 197) over a Connect-web binary transport with the auth/refresh interceptor. The generated stub types come from `web/src/types/proto/api/v1/memo_service_pb.ts`.
- `proto/api/v1/memo_service.proto` — `rpc CreateMemo(CreateMemoRequest) returns (Memo)` with HTTP mapping `POST /api/v1/memos`, body `memo` (line 21).
- `server/router/api/v1/connect_services.go` — `ConnectServiceHandler.CreateMemo` (line 306) unwraps `req.Msg` and delegates to the API service. Generated Connect plumbing is in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.
- `server/router/api/v1/memo_service.go` — `APIV1Service.CreateMemo` (line 70) authenticates the user, validates/generates the UID, builds a `store.Memo`, enforces the content-length limit, rebuilds the memo payload, then calls `s.Store.CreateMemo(ctx, create)`.
- `store/memo.go` — `Store.CreateMemo` (line 109) validates the UID against `base.UIDMatcher` and forwards to `s.driver.CreateMemo`.
- `store/db/sqlite/memo.go` — `DB.CreateMemo` (line 16) assembles the field/placeholder lists and runs `INSERT INTO memo (...) VALUES (...) RETURNING id, created_ts, updated_ts, row_status`. Equivalent drivers exist at `store/db/mysql/memo.go` and `store/db/postgres/memo.go`.
