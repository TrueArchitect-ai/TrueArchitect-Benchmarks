**Go `embed` of the built SPA (`//go:embed dist/*`), served by Echo's static middleware with an SPA `index.html` fallback; `server/router/frontend/frontend.go`**

How it fits together:

- `web/package.json` builds the React app with Vite straight into the Go package directory: `"release": "vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir"` (`web/package.json:11`).
- That directory is compiled into the binary via the embed directive, so no separate web server or asset directory is needed at runtime:

```20:22:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

- `FrontendService.Serve` wraps the embedded FS (`fs.Sub(embeddedFiles, "dist")`) in `middleware.StaticWithConfig`, plus `spaFallbackMiddleware`, which returns `index.html` on 404s for extension-less client-side routes. A skipper excludes `/api`, `/file`, Connect RPC paths (`/memos.api.v1.*`), `robots.txt`, `sitemap.xml`, and `rss.xml` so those fall through to their real handlers. Cache headers are set here too: `no-store` for HTML, `immutable` for hashed `/assets/*`.
- It is wired into the HTTP server at `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.

The checked-in `server/router/frontend/dist/` contains only a placeholder `index.html`; CI builds the real assets and uploads/downloads them into that path before the Go build (`.github/workflows/release.yml`, `.github/workflows/build-canary-image.yml`).
