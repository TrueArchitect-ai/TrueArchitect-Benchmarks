**`postgres.DB` — `store/db/postgres/postgres.go`**

The struct is declared as plain `DB` inside the `postgres` package, so it's referred to as `postgres.DB` from outside:

```16:19:store/db/postgres/postgres.go
type DB struct {
	db      *sql.DB
	profile *profile.Profile
}
```

It satisfies the `store.Driver` interface (declared in `store/driver.go`), and `NewDB` in the same file explicitly assigns it to that interface type before returning. The rest of the interface's methods are spread across the sibling files in `store/db/postgres/` — for example `memo.go`, `user.go`, and `attachment.go` — all with `*DB` receivers.

The driver gets selected at runtime in `store/db/db.go`, where `NewDBDriver` calls `postgres.NewDB(profile)` when `profile.Driver` is `"postgres"`. This parallels the `mysql.DB` and `sqlite.DB` structs in the neighboring packages, which use the same naming pattern.
