`web/src/connect.ts`

All ConnectRPC service clients are created there. The file builds a `createConnectTransport` pointed at `window.location.origin` with a binary format and an auth interceptor, then exports one `createClient(...)` per service: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (`web/src/connect.ts` lines 184–203). It also creates a separate `refreshAuthClient` on an interceptor-free transport so token refresh doesn't recurse through the auth interceptor.
