**Mechanism:** Server-Sent Events (SSE) over a plain HTTP streaming endpoint at `GET /api/v1/sse`, authenticated with a Bearer token, with `text/event-stream` responses, `: heartbeat` comments every 30 seconds, and per-client buffered channels that drop events for slow consumers. No WebSockets are involved. The browser side is a hand-rolled `fetch` + `ReadableStream` reader (not `EventSource`, since it needs the `Authorization` header) in `web/src/hooks/useLiveMemoRefresh.ts`, which reconnects with exponential backoff and invalidates React Query caches on each event.

**Hub path:** `server/router/api/v1/sse_hub.go` — the `SSEHub` type with `Subscribe`, `Unsubscribe`, `Broadcast`, and `Close`. It's a mutex-guarded set of `*SSEClient`, created in `server/router/api/v1/v1.go` (line 57) and closed on shutdown from `server/server.go` (line 206). The HTTP handler that subscribes to it lives in `server/router/api/v1/sse_handler.go`. Delivery is filtered per client by `canReceive`: private-memo events only reach the creator or an admin.
