**SQLite, MySQL, PostgreSQL**

The migrations live under `store/migration/`, which has exactly three dialect subdirectories: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/` (58, 29, and 23 `.sql` files respectively, organized into versioned folders like `0.30/`).

These are embedded into the binary and selected at runtime by driver name:

```39:45:/bench/repo/store/migrator.go
// - Location: store/migration/{driver}/{version}/NN__description.sql

//go:embed migration
var migrationFS embed.FS
```

The path is resolved from the configured driver in `getMigrationBasePath()` (`store/migrator.go:255`), which formats `migration/%s/` using `s.profile.Driver`. The corresponding driver dispatch in `store/db/db.go` accepts the same three values — `"sqlite"`, `"mysql"`, and `"postgres"` — each backed by a package under `store/db/`.

Note that seed data is narrower than migrations: `store/seed/` only contains a `sqlite/` directory, so seeds ship for SQLite alone.
