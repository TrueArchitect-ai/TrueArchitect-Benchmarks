HTTP delivery lives in the `internal/webhook` package (`internal/webhook/webhook.go`). `PostAsync` enqueues onto a bounded 128-slot channel drained by four worker goroutines that call `Post`; if the queue is full the dispatch is dropped with a warning. `Post` marshals the payload to JSON and sends it with a shared `http.Client` whose transport uses `safeDialContext` to reject reserved/private IPs (SSRF and DNS-rebinding protection).

Signing follows the Standard Webhooks spec. Secrets in `whsec_<base64>` form are base64-decoded to raw key bytes by `resolveSigningKey` (other secrets are used literally), then HMAC-SHA256 is computed over `msg_<uuid>` + `.` + unix timestamp + `.` + the JSON body:

```139:149:internal/webhook/webhook.go
		msgID := "msg_" + uuid.New().String()
		timestamp := strconv.FormatInt(time.Now().Unix(), 10)

		mac := hmac.New(sha256.New, key)
		mac.Write([]byte(msgID + "." + timestamp + "."))
		mac.Write(body)
		signature := base64.StdEncoding.EncodeToString(mac.Sum(nil))

		req.Header.Set("webhook-id", msgID)
		req.Header.Set("webhook-timestamp", timestamp)
		req.Header.Set("webhook-signature", "v1,"+signature)
```

Signing is skipped entirely when the hook has no signing secret. Secrets themselves are generated by `GenerateSigningSecret` from 32 random bytes.
