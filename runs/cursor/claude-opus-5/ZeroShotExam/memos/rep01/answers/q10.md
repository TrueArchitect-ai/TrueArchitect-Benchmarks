`store/migration/sqlite/LATEST.sql`

This file holds the full current schema (11 `CREATE TABLE` statements plus indexes) and is what a fresh SQLite install gets. In `store/migrator.go`, `preMigrate` checks `driver.IsInitialized`, and when the database is not yet initialized it reads `getMigrationBasePath() + LatestSchemaFileName`, which resolves to `migration/sqlite/LATEST.sql` since `getMigrationBasePath` formats the path as `migration/{driver}/` and `LatestSchemaFileName` is `"LATEST.sql"`. The file is embedded via `//go:embed migration`. The comment at line 42 states it directly: "LATEST.sql: Full schema for new installations (faster than incremental migrations)". The versioned directories under `store/migration/sqlite/0.x/` are incremental upgrade scripts that fresh installs skip.
