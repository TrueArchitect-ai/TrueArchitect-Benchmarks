This module holds all the memo CRUD hooks built on TanStack Query: `useCreateMemo`, `useUpdateMemo` (with optimistic cache patching and rollback), `useDeleteMemo`, plus the read side (`useMemos`, `useInfiniteMemos`, `useMemo`, `useMemoComments`, `useInfiniteMemoComments`, `useLinkMetadata`) and the `memoKeys` query-key factory.

Every call goes through `memoServiceClient`, imported from `@/connect`, where it is created as a Connect-RPC client over the generated `MemoService` descriptor:
