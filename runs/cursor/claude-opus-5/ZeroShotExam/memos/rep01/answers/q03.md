`DB` — `store/db/postgres/postgres.go`

The PostgreSQL implementation of the `store.Driver` interface is the struct `DB` in package `postgres`, declared at the top of `store/db/postgres/postgres.go`:

type DB struct {

A couple of notes that make this unambiguous:

- `NewDB` in the same file returns it as a `store.Driver` (`var driver store.Driver = &DB{...}`) after opening a connection with the `github.com/lib/pq` driver registered under the name `"postgres"`.
- The dispatcher in `store/db/db.go` selects it for the `"postgres"` driver value, alongside sibling implementations that use the same `DB` struct name in their own packages (`store/db/sqlite`, `store/db/mysql`), so the package qualifier `postgres.DB` is what distinguishes it.
- The rest of the interface methods are spread across the other files in `store/db/postgres/` (for example `memo.go`, `user.go`, `attachment.go`), all defined on the `*DB` receiver.
