**`store.Driver` — `store/driver.go`**

The interface is declared at `store/driver.go` line 10 as `type Driver interface`, described in its doc comment as containing "all methods that store database driver should implement." It covers connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus the full CRUD surface for every model (attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, user identities).

Three backends implement it, each in its own package under `store/db/`: `sqlite`, `mysql`, and `postgres`. The selection happens in `NewDBDriver` at `store/db/db.go`, which switches on `profile.Driver` and returns the chosen implementation as a `store.Driver`.
