`web/src/connect.ts`

All ConnectRPC service clients are created in that single file. It builds a shared transport with `createConnectTransport` (base URL `window.location.origin`, binary format, credentialed fetch, and an auth interceptor) and then exports one client per service via `createClient`:

```184:203:repo/web/src/connect.ts
const transport = createConnectTransport({
  baseUrl: window.location.origin,
  useBinaryFormat: true,
  fetch: fetchWithCredentials,
  interceptors: [authInterceptor],
});

// Core service clients
export const instanceServiceClient = createClient(InstanceService, transport);
export const authServiceClient = createClient(AuthService, transport);
export const userServiceClient = createClient(UserService, transport);
// ... memo, attachment, ai, shortcut, identityProvider clients ...
```

The same file also creates a separate `refreshAuthClient` on its own interceptor-free transport (around lines 65–72) so token refresh calls don't recurse through the auth interceptor.
