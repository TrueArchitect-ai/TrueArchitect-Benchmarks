`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This module holds all the memo CRUD hooks built on TanStack Query — `useMemos`/`useInfiniteMemos` (list), `useMemo` (get), `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, plus comment and link-metadata queries — along with the `memoKeys` cache-key factory. Every call goes through the `memoServiceClient` imported from `@/connect`, which is the generated Connect-RPC client created in `web/src/connect.ts` from `MemoService` in `web/src/types/proto/api/v1/memo_service_pb`.
