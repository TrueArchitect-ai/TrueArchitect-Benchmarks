**Go `embed.FS` (compiled-in static assets served by Echo's static middleware with SPA fallback); `server/router/frontend/frontend.go`**

The details:

- `server/router/frontend/frontend.go` declares `//go:embed dist/*` into `embeddedFiles`, so the built frontend is baked into the Go binary at compile time. `getFileSystem("dist")` takes an `fs.Sub` of it, and `Serve` registers `middleware.StaticWithConfig` with that filesystem, plus `spaFallbackMiddleware`, which serves `index.html` for any extension-less 404 path so client-side routes work.
- The same file also sets cache headers (`no-cache` for HTML, `max-age=3600, immutable` for hashed `/assets/*`) and skips `/api`, `/file`, gRPC-web `/memos.api.v1*`, `robots.txt`, and `sitemap.xml` paths.
- It's wired into the server at `server/server.go:72` via `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
- The `dist` directory is produced by the web build: `web/package.json` has `"release": "vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir"`, which writes Vite's output into the directory that the embed directive picks up.
