Delivery happens entirely in `internal/webhook/webhook.go`. `PostAsync` enqueues the payload onto a buffered channel of size 128 and drops it with a warning if the queue is full; four goroutines started in `init` drain that queue and call `Post`, which does the actual `http.Client` POST. The client is a package-level `safeClient` whose transport uses `safeDialContext` to reject connections that resolve to reserved or private IP addresses, guarding against SSRF and DNS rebinding.

For signing, `Post` only signs when the hook has a secret. It derives the key with `resolveSigningKey`, which base64-decodes secrets in the Standard Webhooks `whsec_<base64>` form (produced by `GenerateSigningSecret` from 32 random bytes) and otherwise uses the secret bytes as-is. It then computes HMAC-SHA256 over `msgID + "." + timestamp + "."` concatenated with the JSON body and emits the three Standard Webhooks headers:
