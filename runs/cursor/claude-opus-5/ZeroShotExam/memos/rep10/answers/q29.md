`web/src/connect.ts`; short-lived JWT access tokens (localStorage, sent as `Authorization: Bearer`) plus an HTTP-only refresh-token cookie (and Personal Access Tokens accepted on the same header); `server/auth`

**Frontend interceptor** — `authInterceptor` in `web/src/connect.ts` is attached to the Connect-RPC transport that every generated service client uses (`memoServiceClient`, `userServiceClient`, etc.). On each request it calls `getRequestToken()` and sets `Authorization: Bearer <token>`; if the response comes back `Code.Unauthenticated` it refreshes once, replays the request with an `X-Retry: true` marker, and on a second failure calls `redirectOnAuthFailure()` (`web/src/utils/auth-redirect.ts`). Refreshes go through a separate transport with no interceptors (`refreshTransport`) so the refresh call can't recurse, and a `tokenRefreshManager` dedupes concurrent refreshes.

**Tokens managed client-side** — `web/src/auth-state.ts` holds the access token in memory and mirrors it to `localStorage` under `memos_access_token` / `memos_token_expires_at`, broadcasting new tokens to other tabs over a `memos_token_sync` BroadcastChannel. The refresh token itself is never touched by JS: it rides as a cookie, which is why both transports use `fetch` with `credentials: "include"`. `web/src/hooks/useTokenRefreshOnFocus.ts` refreshes proactively on tab focus.

**Backend validation** — `server/auth` (package `auth`). `Authenticator.Authenticate` in `server/auth/authenticator.go` extracts the bearer token and either validates a stateless JWT access token (`AuthenticateByAccessTokenV2`) or, when the token carries the `memos_pat_` prefix, looks up a hashed Personal Access Token in the store (`AuthenticateByPAT`). Refresh tokens are parsed by `ParseRefreshToken` and checked against the database in `AuthenticateByRefreshToken`; token constants and lifetimes live in `server/auth/token.go` (access token 15 minutes, refresh token 30 days, cookie `memos_refresh`). The transport hook is `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go`, which delegates to `Authorizer` (`server/router/api/v1/authz.go`) wrapping `auth.NewAuthenticator`.
