**`memo_relation`**

The table stores a link from one memo to another with a relation type:

```47:52:repo/store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The same table is defined for the other supported backends in `repo/store/migration/postgres/LATEST.sql` and `repo/store/migration/mysql/LATEST.sql`, and it was introduced in `repo/store/migration/sqlite/0.13/00__memo_relation.sql`. Access code lives in `repo/store/db/sqlite/memo_relation.go`, `repo/store/db/postgres/memo_relation.go`, and `repo/store/db/mysql/memo_relation.go`.
