`store/migration/sqlite/LATEST.sql`

On a fresh install, `preMigrate` in `store/migrator.go` (lines 210–228) detects that the database is not initialized and reads the single file at `getMigrationBasePath() + LatestSchemaFileName`, which resolves to `migration/sqlite/LATEST.sql` for the SQLite driver, applying the whole current schema in one transaction rather than replaying the incremental migrations under `store/migration/sqlite/0.x/`. The convention is documented in `AGENTS.md` ("Schema changes require SQLite, MySQL, and PostgreSQL migrations plus `LATEST.sql` updates") and exercised by `TestFreshInstall` in `store/test/migrator_test.go`.
