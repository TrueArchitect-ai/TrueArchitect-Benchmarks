`web/src/connect.ts`

All ConnectRPC service clients are created in `web/src/connect.ts`. That file builds the shared `createConnectTransport` (binary format, `window.location.origin` base URL, credentialed fetch, auth interceptor) and then exports the clients via `createClient` — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. It also creates one extra client, `refreshAuthClient`, on a separate interceptor-free transport so token refresh can't recurse through the auth interceptor.
