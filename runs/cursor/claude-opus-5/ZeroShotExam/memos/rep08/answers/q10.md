`store/migration/sqlite/LATEST.sql`

This is the single file that holds the complete current schema for a fresh SQLite install. The migrator's `preMigrate` step detects an uninitialized database and applies exactly this one file inside a transaction, rather than replaying the incremental version directories:

The path is assembled from `LatestSchemaFileName = "LATEST.sql"` and `getMigrationBasePath()`, which returns `migration/<driver>/` — so `migration/sqlite/` when the profile driver is SQLite (`store/migrator.go:56` and `store/migrator.go:254-256`). The directory is embedded via `//go:embed migration`, so the file ships in the binary. The equivalent files for the other backends are `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, and `AGENTS.md:20` confirms the convention that every schema change must update each driver's `LATEST.sql`. A fresh-install test covering this lives at `store/test/migrator_test.go:18`.
