**Answer: Go `embed` (`//go:embed dist/*`) served via Echo's static middleware with SPA fallback; `server/router/frontend/frontend.go`**

How it works:

- The Vite production build writes into the Go package directory: `web/package.json` defines `"release": "vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir"`.
- That directory is compiled into the binary with `//go:embed dist/*` into `embeddedFiles embed.FS`, and exposed as an `fs.FS` rooted at `dist` via `fs.Sub` in `getFileSystem` (`server/router/frontend/frontend.go` lines 20–21, 115–121).
- `FrontendService.Serve` registers `middleware.StaticWithConfig` over that filesystem, plus a `spaFallbackMiddleware` that returns `index.html` for extension-less/404 routes so client-side routing works. A skipper excludes `/api`, `/file`, Connect RPC paths (`/memos.api.v1...`), `robots.txt`, `sitemap.xml`, and `*/rss.xml`, and cache headers are set (no-cache for HTML, `max-age=3600, immutable` for hashed `/assets/`).
- It's wired into the server at `server/server.go:72` with `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
