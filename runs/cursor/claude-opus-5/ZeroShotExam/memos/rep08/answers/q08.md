**Driver — `store/driver.go`**

The interface is `store.Driver`, declared at the top of `store/driver.go`:

```8:11:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
```

It's a large interface (about 80 lines) covering connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD methods for every model: attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, and user identities.

The three backends that implement it each live in their own package under `store/db/`, and each exposes a `NewDB` constructor returning `store.Driver`:

- `store/db/sqlite/sqlite.go` (line 24)
- `store/db/mysql/mysql.go` (line 20)
- `store/db/postgres/postgres.go` (line 21)

Backend selection happens in `store/db/db.go`, where `NewDBDriver` switches on `profile.Driver` for the strings `"sqlite"`, `"mysql"`, and `"postgres"`. The repo's own `AGENTS.md` corroborates this layout, describing `store/` as holding the "driver interface" and `store/db/{sqlite,mysql,postgres}/` as the "database-specific drivers and SQL."
