- It's wired up in the driver factory at `store/db/db.go`, where `profile.Driver == "postgres"` dispatches to `postgres.NewDB`. The sibling implementations follow the same pattern in `store/db/sqlite` and `store/db/mysql`, so each package has its own struct also named `DB`.
- The remaining methods of the `store.Driver` interface for PostgreSQL are spread across the other files in `store/db/postgres/` (for example `memo.go`, `user.go`, and `attachment.go`), all defined as methods on this same `*DB` receiver.
