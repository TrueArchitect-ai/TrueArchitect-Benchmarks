**Engine:** Google CEL (`cel-go`), wrapped by the in-repo memo filter engine at `internal/filter/` — entry point `filter.DefaultEngine()` in `internal/filter/engine.go`.

**Mechanism (one sentence):** `Engine.Compile` type-checks the CEL string against a memo-specific `cel.Env` built from the field declarations in `internal/filter/schema.go`, `internal/filter/parser.go` walks the resulting CEL AST into a dialect-agnostic condition IR (`internal/filter/ir.go`), and `internal/filter/render.go` walks that IR to emit a dialect-specific SQL fragment plus placeholder args, which each driver appends to its `WHERE` clause via `filter.AppendConditions` (`internal/filter/helpers.go`).

**How it flows through ListMemos:**

- `ListMemos` in `server/router/api/v1/memo_service.go` (lines 211–216) validates `request.Filter` via `validateFilter` and pushes the raw string onto `memoFind.Filters` (it also appends a synthesized visibility filter using the same CEL syntax at line 222). `validateFilter` (`server/router/api/v1/shortcut_service.go:336`) compiles the expression up front against the driver's dialect so bad filters return `InvalidArgument` rather than a SQL error.
- Each store driver then compiles the accumulated filters with its own dialect constant: `store/db/sqlite/memo.go:57-61` (`filter.DialectSQLite`), `store/db/postgres/memo.go:54-58` (`filter.DialectPostgres`), `store/db/mysql/memo.go:65-69` (`filter.DialectMySQL`).
- `RenderOptions.PlaceholderOffset` lets the renderer emit `?` for SQLite/MySQL and correctly numbered `$n` for Postgres alongside pre-existing query args.

Dialect differences live entirely in the renderer: JSON access (`json_extract` vs `->>` vs `JSON_EXTRACT`), tag membership (`LIKE` patterns on SQLite, `JSON_CONTAINS` on MySQL, `@>` on Postgres), `LIKE` vs `ILIKE`, regex (`REGEXP` vs `~`, with SQLite's `regexp` provided by a Go function in `store/db/sqlite/functions.go`), and timestamp part extraction (`strftime` / `EXTRACT` / `YEAR`). Time expressions such as `now - duration("24h")` are constant-folded to epoch seconds at compile time, with `now` frozen once per compile (see `internal/filter/engine.go:17-20` and `internal/filter/README.md`).
