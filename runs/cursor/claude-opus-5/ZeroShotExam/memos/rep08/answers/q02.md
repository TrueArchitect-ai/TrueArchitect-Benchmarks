**SQLite, MySQL, PostgreSQL**

The embedded migration tree at `store/migration/` has exactly three dialect subdirectories — `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/` — each holding versioned `NN__description.sql` files plus a `LATEST.sql` full-schema file. This matches the layout documented in `store/migrator.go`, which describes migration files as living at `store/migration/{driver}/{version}/NN__description.sql` and embeds the whole tree via `//go:embed migration`. The same three drivers have implementations under `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`.

One asymmetry worth noting: seed data is SQLite-only (`store/seed/sqlite/`), and SQLite's migration history reaches back to `0.2` while MySQL starts at `0.17` and Postgres at `0.19`.
