The table is **`memo_relation`**.

Its schema is defined identically across all three supported database engines, for example in the SQLite schema:

```47:52:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Each row links a source memo (`memo_id`) to a related memo (`related_memo_id`), with a `type` column distinguishing the kind of link (for instance a reference versus a comment).
