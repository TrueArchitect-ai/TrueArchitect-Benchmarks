**Answer: Server-Sent Events (SSE); `server/router/api/v1/sse_hub.go` (endpoint in `server/router/api/v1/sse_handler.go`); `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`, `UpsertMemoReaction`, `DeleteMemoReaction`.**

**Mechanism.** Live events go out over SSE, not WebSockets. `handleSSE` sets `Content-Type: text/event-stream`, disables caching and nginx buffering, writes an initial `: connected` comment, then loops writing `data: ...` frames with a 30-second `: heartbeat` keepalive (`server/router/api/v1/sse_handler.go`). The endpoint is `GET /api/v1/sse`, registered by `RegisterSSERoutes` and wired up in `server/router/api/v1/v1.go:125`. Authentication is a Bearer token in the `Authorization` header. The browser side consumes it in `web/src/hooks/useLiveMemoRefresh.ts`.

**Hub.** `SSEHub` lives in `server/router/api/v1/sse_hub.go`. It is a mutex-guarded set of `*SSEClient`, each holding a 32-event buffered channel plus the subscriber's user ID and role. `Broadcast` marshals the event once and does a non-blocking send to every client, dropping events for slow consumers rather than blocking. Per-client filtering happens in `canReceive`: private-visibility events only reach the creator or an admin. The hub is created once per `APIV1Service` (`server/router/api/v1/v1.go:57`) and held by the server at `server/server.go:38`.

**Broadcasting handlers.** Three broadcast inline:

- `CreateMemo` emits `memo.created` (`server/router/api/v1/memo_service.go:163`), guarded by `isSSESuppressed(ctx)` so the comment path doesn't double-fire.
- `DeleteMemo` emits `memo.deleted` (`server/router/api/v1/memo_service.go:585`).
- `CreateMemoComment` emits `memo.comment.created` against the parent memo (`server/router/api/v1/memo_service_comments.go:126`).

Three more go through the shared helper `dispatchMemoUpdatedSideEffects`, which emits `memo.updated` (`server/router/api/v1/memo_update_helpers.go:71`): `UpdateMemo` (`memo_service.go:513`), `SetMemoAttachments` (`memo_attachment_service.go:48`), and `SetMemoRelations` (`memo_relation_service.go:48`).

Reactions also broadcast, via `buildMemoReactionSSEEvent`: `UpsertMemoReaction` sends `reaction.upserted` and `DeleteMemoReaction` sends `reaction.deleted` (`server/router/api/v1/reaction_service.go:106` and `:161`), both naming the affected memo.
