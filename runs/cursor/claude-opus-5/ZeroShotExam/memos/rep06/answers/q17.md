q17. `web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

That module holds the whole memo CRUD data layer built on TanStack Query: queries `useMemos`, `useInfiniteMemos`, `useMemo`, `useMemoComments`, `useInfiniteMemoComments`, `useLinkMetadata`, and mutations `useCreateMemo`, `useUpdateMemo` (with optimistic cache patching and rollback), `useDeleteMemo`, plus the `memoKeys` query-key factory.

Every call goes through `memoServiceClient`, imported from `@/connect`. That client is a Connect-RPC client created in `web/src/connect.ts` (line 197) via `createClient(MemoService, transport)`, where `MemoService` comes from the generated code at `web/src/types/proto/api/v1/memo_service_pb.ts` and the transport carries the auth/token-refresh interceptor.
