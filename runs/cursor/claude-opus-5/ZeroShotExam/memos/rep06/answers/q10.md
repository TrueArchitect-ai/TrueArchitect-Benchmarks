`store/migration/sqlite/LATEST.sql`

This is the full current schema applied to any uninitialized SQLite database. The migrator checks whether the database is initialized and, if not, reads `LATEST.sql` from the driver-specific migration directory and executes it in one transaction, then stamps the current schema version:

```217:222:/bench/repo/store/migrator.go
	if !initialized {
		filePath := s.getMigrationBasePath() + LatestSchemaFileName
		bytes, err := migrationFS.ReadFile(filePath)
		if err != nil {
			return errors.Errorf("failed to read latest schema file: %s", err)
		}
```

The base path is built from the configured driver (`migration/sqlite/` for SQLite) in `getMigrationBasePath`, and `LatestSchemaFileName` is the constant `"LATEST.sql"`. The file itself contains the complete `CREATE TABLE` set (`system_setting`, `user`, `memo`, and so on), so the versioned directories like `store/migration/sqlite/0.30/` are only used for incremental upgrades of existing databases, never on a fresh install.
