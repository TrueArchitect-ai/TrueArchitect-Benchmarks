**`store.Driver` — `store/driver.go`**

The interface is declared as `type Driver interface` in `store/driver.go` (line 10), documented as "an interface for store driver... all methods that store database driver should implement." It covers `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, plus CRUD methods for every model (memo, user, attachment, inbox, reaction, identity provider, and so on).

The three backends that implement it each live in their own subpackage: `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go`. `store/db/db.go` is the factory that selects one based on the configured driver, and `store.Store` (in `store/store.go`) holds a `Driver` field that the rest of the server talks to.
