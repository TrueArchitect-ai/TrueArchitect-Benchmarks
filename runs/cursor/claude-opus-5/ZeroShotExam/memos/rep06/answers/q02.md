**SQLite, MySQL, PostgreSQL**

The migration SQL files live under `store/migration/{driver}/`, embedded into the binary via `//go:embed migration` in `store/migrator.go`, and there are exactly three driver subdirectories:

- `store/migration/sqlite/` — versions 0.2 through 0.30, plus `LATEST.sql`
- `store/migration/mysql/` — versions 0.17 through 0.30, plus `LATEST.sql`
- `store/migration/postgres/` — versions 0.19 through 0.30, plus `LATEST.sql`

This matches the driver selection in `store/db/db.go`, which switches on `profile.Driver` over `"sqlite"`, `"mysql"`, and `"postgres"`, with corresponding driver packages in `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres`. Note that SQLite carries the longest migration history; MySQL and Postgres support was added later, so their earliest incremental migrations start at 0.17 and 0.19 respectively (new installs use `LATEST.sql` instead).
