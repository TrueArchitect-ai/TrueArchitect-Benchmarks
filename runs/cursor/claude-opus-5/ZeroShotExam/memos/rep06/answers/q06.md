**`memo_relation`**

This table stores links between one memo and another related memo. Its schema is identical in both database drivers:

```46:52:repo/store/migration/sqlite/LATEST.sql
-- memo_relation
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The `memo_id` column points at the source memo, `related_memo_id` at the target memo, and `type` records the kind of relation (for example a reference versus a comment).
