The `store.Driver` interface is defined in `store/driver.go`, and it has three implementations, each in its own package under `store/db/`:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

Each of these entry files defines a `DB` struct plus a `NewDB(profile *profile.Profile) (store.Driver, error)` constructor, with the rest of the per-dialect query code split across sibling files in the same package (`memo.go`, `user.go`, and so on).

The factory that picks among them is:

`NewDBDriver` — `store/db/db.go`

It switches on `profile.Driver` (the string `"sqlite"`, `"mysql"`, or `"postgres"`) and returns an error for anything else:

```18:27:store/db/db.go
	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
	case "postgres":
		driver, err = postgres.NewDB(profile)
	default:
		return nil, errors.New("unknown db driver")
	}
```

At startup it's called from `cmd/memos/main.go` (line 57); the test helpers in `store/test/store.go` and the benchmark in `server/router/api/v1/test/memo_service_benchmark_test.go` use the same factory.
