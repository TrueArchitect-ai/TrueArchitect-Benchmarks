**Database-level cascade caveat**

`memo_share` is the only table with a declared `ON DELETE CASCADE` on `memo(id)` (`store/migration/sqlite/LATEST.sql:109`, `store/migration/postgres/LATEST.sql:108`, `store/migration/mysql/LATEST.sql:108`). On MySQL/Postgres those rows disappear with the memo, but the SQLite driver opens the database with foreign keys turned off, so shares are left orphaned there:
