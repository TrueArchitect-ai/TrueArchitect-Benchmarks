**`DB` (i.e. `postgres.DB`) — `store/db/postgres/postgres.go`**

The struct is declared in `store/db/postgres/postgres.go` and holds the `*sql.DB` connection plus the app profile:

```16:19:store/db/postgres/postgres.go
type DB struct {
	db      *sql.DB
	profile *profile.Profile
}
```

It satisfies the `store.Driver` interface — the constructor `postgres.NewDB` opens a connection with the `lib/pq` driver (`_ "github.com/lib/pq"`, `sql.Open("postgres", profile.DSN)`) and explicitly assigns `&DB{...}` to a `store.Driver` variable before returning it. The interface methods are split across that file (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) and the sibling files in the same package (`memo.go`, `user.go`, `attachment.go`, and so on), which carry the per-entity CRUD methods on `*DB`.

It's selected at runtime in `store/db/db.go`, where `NewDBDriver` switches on `profile.Driver` and calls `postgres.NewDB(profile)` for the `"postgres"` case, alongside the parallel `sqlite.DB` and `mysql.DB` implementations.
