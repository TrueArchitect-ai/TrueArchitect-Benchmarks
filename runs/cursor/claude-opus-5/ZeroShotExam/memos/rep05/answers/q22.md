`CreateMemo` fires webhooks through `APIV1Service.DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`, which hands off to the `internal/webhook` package for delivery, and requests are signed with an HMAC-SHA256 signature following the Standard Webhooks scheme.

**Details of the flow**

The handler in `server/router/api/v1/memo_service.go` calls the dispatcher right after converting the stored memo, and treats failure as non-fatal (it only logs a warning):

```156:159:server/router/api/v1/memo_service.go
	// Try to dispatch webhook when memo is created.
	if err := s.DispatchMemoCreatedWebhook(ctx, memoMessage); err != nil {
		slog.Warn("Failed to dispatch memo created webhook", slog.Any("err", err))
	}
```

`DispatchMemoCreatedWebhook` is a thin wrapper over `dispatchMemoRelatedWebhook` with activity type `memos.memo.created`. That helper resolves the memo's creator, loads that user's webhooks via `s.Store.GetUserWebhooks`, and for each one builds a payload carrying the memo, URL, and the hook's signing secret before calling `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go`, lines 15–17 and 48–74).

Delivery happens in the `github.com/usememos/memos/internal/webhook` package (`internal/webhook/webhook.go`). `PostAsync` enqueues onto a bounded channel of 128 payloads drained by four worker goroutines, dropping the event with a warning if the queue is full; each worker calls `Post`, which does the actual `http.POST` using a shared client with a 30-second timeout and an SSRF-guarding dialer that rejects reserved/private IPs.

For signing, when a hook has a non-empty `SigningSecret`, `Post` derives the key via `resolveSigningKey` (base64-decoding a `whsec_`-prefixed secret, otherwise using the raw bytes), then computes `HMAC-SHA256` over `msgID + "." + timestamp + "." + body` and sets the Standard Webhooks headers `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64>` (`internal/webhook/webhook.go`, lines 133–150). Secrets themselves are generated by `GenerateSigningSecret` as `whsec_` plus 32 random base64-encoded bytes.
