`store/migration/sqlite/LATEST.sql`

This is the full-schema bootstrap file for fresh SQLite installations. The migrator only ever applies it when the database isn't yet initialized:

```217:222:/bench/repo/store/migrator.go
	if !initialized {
		filePath := s.getMigrationBasePath() + LatestSchemaFileName
		bytes, err := migrationFS.ReadFile(filePath)
		if err != nil {
			return errors.Errorf("failed to read latest schema file: %s", err)
		}
```

The path is assembled from `getMigrationBasePath()`, which is `migration/{driver}/` (so `migration/sqlite/` when `profile.Driver` is `sqlite`), plus the `LatestSchemaFileName` constant `"LATEST.sql"` (`store/migrator.go` lines 54-56 and 254-256). The embedded FS root is the `store/migration` directory, hence the on-disk path above. The header comment in the same file states this directly: "LATEST.sql: Full schema for new installations (faster than incremental migrations)".

After applying it, `preMigrate` records the computed current schema version, so the per-version files under `store/migration/sqlite/0.x/` are skipped entirely on a fresh install.
