The `store.Driver` interface is declared in `store/driver.go`, and it has three implementations, each with its own package entry file that defines the `DB` struct plus a `NewDB` constructor:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

`NewDBDriver` — `store/db/db.go`

The factory switches on `profile.Driver` (values `sqlite`, `mysql`, `postgres`) and returns an error for anything else. It's invoked at startup from `cmd/memos/main.go:57`, and also by the test helper in `store/test/store.go`.
