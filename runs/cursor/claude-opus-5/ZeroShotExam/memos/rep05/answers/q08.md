**Driver — `store/driver.go`**

The interface is declared as `Driver` in package `store`:

```8:10:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
```

It defines the full set of methods every backend must provide — connection handling (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD operations for every model (memos, users, attachments, reactions, inboxes, identity providers, and so on).

The three concrete backends live under `store/db/` — `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres` — and are selected at runtime in `store/db/db.go`, whose `NewDBDriver` function returns a `store.Driver` based on `profile.Driver`.
