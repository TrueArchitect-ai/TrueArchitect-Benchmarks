**SQLite, MySQL, PostgreSQL**

The migration SQL files are embedded from `store/migration`, which contains exactly three dialect subdirectories:

- `store/migration/sqlite/` — versions 0.2 through 0.30, plus `LATEST.sql`
- `store/migration/mysql/` — versions 0.17 through 0.30, plus `LATEST.sql`
- `store/migration/postgres/` — versions 0.19 through 0.30, plus `LATEST.sql`

These are loaded by the migrator via `//go:embed migration` in `store/migrator.go` (line 44), which documents the layout as `store/migration/{driver}/{version}/NN__description.sql`. The same three dialects have corresponding driver implementations in `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres`.
