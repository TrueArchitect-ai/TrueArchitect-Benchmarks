q25.

**Engine:** Google CEL (Common Expression Language), via `github.com/google/cel-go` v0.28.1 (`go.mod`), wrapped by the in-repo filter engine at `internal/filter/` — `engine.go` (entry point `filter.DefaultEngine()`), `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`, documented in `internal/filter/README.md`.

**Mechanism:** `Engine.CompileToStatement` compiles the CEL string against a memo-specific CEL environment declared in `internal/filter/schema.go` (variables like `content`, `tags`, `visibility`, `created_ts`, `now`, plus `ext.Sets()` and `cel.ValidateRegexLiterals()`), `internal/filter/parser.go` normalizes the CEL AST into a dialect-agnostic IR of conditions (`internal/filter/ir.go`) while enforcing schema/operator rules and constant-folding time expressions against a per-compile frozen `now`, and `internal/filter/render.go` walks that IR to emit a SQL fragment plus placeholder args for the target dialect (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`).

**Where it's wired in for ListMemos:**
- `server/router/api/v1/memo_service.go:211-215` validates `request.Filter` (via `validateFilter` in `server/router/api/v1/shortcut_service.go:336`, which compiles it against the driver's dialect) and appends it to `memoFind.Filters`. The visibility/ownership rule is itself injected as another CEL string (`creator_id == N || visibility in ["PUBLIC","PROTECTED"]`).
- Each driver's `ListMemos` then calls `filter.AppendConditions` (`internal/filter/helpers.go:9`), which compiles each filter with the driver's dialect and a `PlaceholderOffset` equal to the current arg count, then appends `(fragment)` to the `WHERE` list: `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`.

Dialect differences are contained in the renderer and schema: `?` vs `$n` placeholders, JSON access (`json_extract` / `->>` / `JSON_CONTAINS` / `@>`), `LIKE` vs `ILIKE`, regex `REGEXP` vs `~` (SQLite's `regexp` is a Go function registered in `store/db/sqlite/functions.go`), and per-dialect column expressions such as `UNIX_TIMESTAMP(%s)` for MySQL timestamps (`internal/filter/schema.go:105-148`).
