**Answer: Go `embed.FS` (compile-time embedding of `dist/*`) served via Echo's static-file middleware with an SPA `index.html` fallback; wired in `server/router/frontend/frontend.go`.**

How it works:

- `server/router/frontend/frontend.go` declares `//go:embed dist/*` into `embeddedFiles embed.FS`, then `getFileSystem("dist")` takes an `fs.Sub` of it so the built assets are rooted at `/`.

```20:21:server/router/frontend/frontend.go

```

- `FrontendService.Serve` registers that filesystem with `middleware.StaticWithConfig`, plus `spaFallbackMiddleware`, which turns any 404 on an extensionless (client-route) path into `index.html` so React Router URLs work on refresh. A skipper excludes `/api`, `/file`, gRPC-web `/memos.api.v1*`, `robots.txt`, `sitemap.xml`, and `rss.xml` paths, and cache headers are set (no-cache for HTML, `immutable` for hashed `/assets/`).

```41:61:server/router/frontend/frontend.go
func (s *FrontendService) Serve(_ context.Context, e *echo.Echo) {
	frontendFS := getFileSystem("dist")
	// ...
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		Skipper:    skipper,
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
	s.registerRoutes(e)
}
```
