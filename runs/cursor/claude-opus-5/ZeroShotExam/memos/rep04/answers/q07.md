`web/src/connect.ts`

That file builds the shared Connect transport with `createConnectTransport` (pointed at `window.location.origin`, binary format, with an auth interceptor) and then exports every service client created from it — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (`web/src/connect.ts` lines 184–203). It also creates a separate `refreshAuthClient` on its own transport around line 65–72, used for token refresh so it bypasses the auth interceptor.
