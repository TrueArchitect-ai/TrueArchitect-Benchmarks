**SQLite, MySQL, PostgreSQL**

The migrations live under `store/migration/`, which contains exactly three dialect directories: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/`. Each holds per-version incremental migrations (e.g. `store/migration/postgres/0.28/00__user_identity.sql`) plus a `LATEST.sql` full-schema file for fresh installs.

This matches the driver dispatch in `store/db/db.go`, which switches on `"sqlite"`, `"mysql"`, and `"postgres"`, and the layout documented in `store/migrator.go` (`store/migration/{driver}/{version}/NN__description.sql`, embedded via `//go:embed migration`).

One asymmetry worth noting: the seed data at `store/seed/` is SQLite-only, so demo-mode seeding doesn't cover MySQL or PostgreSQL.
