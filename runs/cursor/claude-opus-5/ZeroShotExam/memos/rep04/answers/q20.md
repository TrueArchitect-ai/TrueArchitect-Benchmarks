**Server-Sent Events (SSE) over a plain `GET /api/v1/sse` stream; hub at `server/router/api/v1/sse_hub.go`; broadcasting handlers: `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`, `UpsertMemoReaction`, `DeleteMemoReaction`.**

Details:

**Mechanism.** It's SSE, not WebSockets. `server/router/api/v1/sse_handler.go` registers `GET /api/v1/sse` on the Echo gateway group, authenticates via a Bearer token in the `Authorization` header, sets `Content-Type: text/event-stream` plus `X-Accel-Buffering: no`, then writes `data: <json>\n\n` frames and a `: heartbeat` comment every 30 seconds. The browser side is `web/src/hooks/useLiveMemoRefresh.ts`, which uses `fetch` with a streaming reader (rather than `EventSource`, since it needs the auth header) and invalidates React Query caches per event type, reconnecting with exponential backoff.

**Hub.** `server/router/api/v1/sse_hub.go` defines `SSEHub`, a mutex-guarded `map[*SSEClient]struct{}` with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`. Each client gets a 32-event buffered channel and events are dropped rather than blocking when a client is slow. `Broadcast` filters per client via `canReceive`, so `store.Private` memos only reach the creator or an admin. It's constructed in `server/router/api/v1/v1.go` (`NewSSEHub()`) and closed on shutdown in `server/server.go`.

**Handlers that broadcast.** Direct `s.SSEHub.Broadcast` calls:

- `CreateMemo` — `memo.created` (`server/router/api/v1/memo_service.go:163`, skipped when invoked from `CreateMemoComment`)
- `DeleteMemo` — `memo.deleted` (`server/router/api/v1/memo_service.go:585`)
- `CreateMemoComment` — `memo.comment.created` for the parent memo (`server/router/api/v1/memo_service_comments.go:126`)
- `UpsertMemoReaction` — `reaction.upserted` (`server/router/api/v1/reaction_service.go:106`)
- `DeleteMemoReaction` — `reaction.deleted` (`server/router/api/v1/reaction_service.go:161`)

Plus the shared helper `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go:71`, which emits `memo.updated` and is called by `UpdateMemo` (`memo_service.go:513`), `SetMemoAttachments` (`memo_attachment_service.go:48`), and `SetMemoRelations` (`memo_relation_service.go:48`).
