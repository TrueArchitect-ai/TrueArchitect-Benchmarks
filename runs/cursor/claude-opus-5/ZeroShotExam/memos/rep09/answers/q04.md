`APIV1Service.SignIn` — `server/router/api/v1/auth_service.go` (line 51)

That's where the actual sign-in logic lives. It handles both password credentials (looks up the user, compares the bcrypt hash, and rejects the request if `DisallowPasswordAuth` is set for regular users) and SSO credentials (via `resolveSSOIdentity` and `resolveSSOUser`), then issues the access token by calling `doSignIn`:
