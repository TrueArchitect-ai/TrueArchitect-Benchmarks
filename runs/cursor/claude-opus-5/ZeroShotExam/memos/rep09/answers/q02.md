**SQLite, MySQL, PostgreSQL**

The migration files live under `store/migration/`, which contains exactly three dialect subdirectories: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/`. Each holds versioned migration folders plus a `LATEST.sql` schema file (SQLite has the longest history, going back to version 0.2, while MySQL starts at 0.17 and Postgres at 0.19).

This matches the driver selection in `store/db/db.go`, where `NewDBDriver` switches on the configured driver name and only accepts `"sqlite"`, `"mysql"`, and `"postgres"`, returning an "unknown db driver" error otherwise. The corresponding implementations are in `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`.

One thing worth noting: seed data is not equally covered. `store/seed/` only has a `sqlite` subdirectory, so seeding is SQLite-only even though migrations ship for all three.
