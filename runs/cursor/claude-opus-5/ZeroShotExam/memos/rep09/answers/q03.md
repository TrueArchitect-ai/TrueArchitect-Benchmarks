`DB` — `store/db/postgres/postgres.go`

The PostgreSQL implementation of the `store.Driver` interface is the struct `DB` in package `postgres`:

```16:19:store/db/postgres/postgres.go
type DB struct {
	db      *sql.DB
	profile *profile.Profile
}
```

It's constructed by `postgres.NewDB`, which opens a `database/sql` connection using the `github.com/lib/pq` driver and returns the struct as a `store.Driver`. The rest of the interface methods (memo, user, attachment, inbox, etc.) are implemented as methods on this same `*DB` across the other files in `store/db/postgres/` (for example `store/db/postgres/memo.go` and `store/db/postgres/user.go`).

Driver selection happens in `store/db/db.go`, where `profile.Driver == "postgres"` dispatches to `postgres.NewDB`. The sibling implementations follow the same pattern, each defining its own `DB` struct: `store/db/mysql/mysql.go` and `store/db/sqlite/sqlite.go`.
