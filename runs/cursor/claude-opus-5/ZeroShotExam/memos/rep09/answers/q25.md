**Engine:** Google CEL (Common Expression Language), parsed with `cel-go` (`github.com/google/cel-go/cel`), wrapped by the in-repo filter engine at `internal/filter/` — `engine.go` (entry point `filter.DefaultEngine()`), `schema.go` (allowed fields + CEL env), `parser.go` (CEL AST → IR), `ir.go` (dialect-agnostic condition tree), `render.go` (IR → SQL), `helpers.go` (store glue). The package's design is documented in `internal/filter/README.md`.

**Mechanism (one sentence):** `ListMemos` validates `request.Filter` and pushes it into `memoFind.Filters` (`server/router/api/v1/memo_service.go:211-216`, validation via `validateFilter` in `server/router/api/v1/shortcut_service.go:336`), then each store driver (`store/db/sqlite/memo.go:57`, `store/db/postgres/memo.go:54`, `store/db/mysql/memo.go:65`) calls `filter.AppendConditions` with its own `DialectName`, which runs `Engine.CompileToStatement` — `cel-go` compiles the string against the memo schema environment, `buildCondition` normalizes the CEL AST into the IR (constant-folding `now`, `timestamp()`, `duration()`, and desugaring `ext.Sets()` calls), and the dialect-aware renderer walks the IR to emit a parameterized SQL fragment plus args that get appended to the query's `WHERE` clause.

**Per-dialect divergence** happens entirely inside `render.go`, where a `switch r.dialect` on `DialectSQLite` / `DialectMySQL` / `DialectPostgres` selects placeholder style (`?` vs `$n`, offset-tracked via `RenderOptions.PlaceholderOffset`), JSON access (`json_extract` vs `->>` vs `JSON_EXTRACT`), tag membership (`LIKE` vs `JSON_CONTAINS` vs `@>`), regex (`REGEXP` vs `~`, with SQLite's `regexp` supplied by `store/db/sqlite/functions.go`), string length, and date-part extraction (`strftime` vs `EXTRACT` vs `YEAR`/`MONTH`).

Notable details: the schema restricts identifiers to a declared set (`content`, `tags`, `visibility`, `created_ts`, `has_task_list`, etc. — `internal/filter/schema.go:233-248`), regex literals are validated at compile time via `cel.ValidateRegexLiterals()`, and `now` is frozen once per compile so a single filter observes one instant.
