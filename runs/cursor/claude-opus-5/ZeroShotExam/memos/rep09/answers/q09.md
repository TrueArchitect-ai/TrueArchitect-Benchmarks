**AIService**

It's the only service that declares the `Transcribe` RPC, defined in `proto/api/v1/ai_service.proto` (package `memos.api.v1`):

```11:20:repo/proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

The RPC takes a `TranscribeRequest` (containing a `TranscriptionAudio`) and returns a `TranscribeResponse` with the transcribed text, and it is exposed over HTTP as `POST /api/v1/ai:transcribe`.
