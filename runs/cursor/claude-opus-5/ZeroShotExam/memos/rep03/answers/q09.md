**AIService**

It's the only proto service with a `Transcribe` RPC, defined in `proto/api/v1/ai_service.proto`:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

The service lives in package `memos.api.v1`, so its fully qualified name is `memos.api.v1.AIService`, and the RPC is exposed over HTTP as `POST /api/v1/ai:transcribe`.
