**`postgres.DB` — `store/db/postgres/postgres.go`**

The struct is declared as plain `DB` inside `package postgres`, so it's referred to as `postgres.DB` from outside:

```16:19:store/db/postgres/postgres.go
type DB struct {
	db      *sql.DB
	profile *profile.Profile
}
```

A few supporting details:

- `NewDB` in the same file opens a `database/sql` connection with the `postgres` driver name (backed by the blank-imported `github.com/lib/pq`) and returns `*DB` as a `store.Driver`.
- It is selected in `NewDBDriver` in `store/db/db.go` when `profile.Driver == "postgres"`, alongside the sibling `sqlite` and `mysql` implementations, which each define their own `DB` struct in `store/db/sqlite/sqlite.go` and `store/db/mysql/mysql.go`.
- The rest of the `store.Driver` interface is implemented across the other files in `store/db/postgres/` (for example `memo.go`, `user.go`, `attachment.go`), all as methods on this same `*DB` receiver.
