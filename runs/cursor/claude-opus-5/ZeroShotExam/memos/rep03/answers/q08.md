**`store.Driver` — `store/driver.go`**

The interface is declared as `Driver` in package `store`:

```8:11:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
```

It spans lines 10–86 of `store/driver.go` and covers connection handling (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus all per-model CRUD operations (attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, user identities).

Three backends implement it, each with a `NewDB` constructor returning a `store.Driver`:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

Selection happens at runtime in `store/db/db.go`, where `NewDBDriver` switches on `profile.Driver` and returns the matching `store.Driver`. The `Store` type in `store/store.go` then holds that interface value rather than a concrete backend.
