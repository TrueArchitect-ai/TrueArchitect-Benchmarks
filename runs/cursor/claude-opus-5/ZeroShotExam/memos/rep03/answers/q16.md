Before deleting the memo row, `Store.DeleteMemo` removes two kinds of records:

1. **Memo relation records, in both directions** — first the rows where the memo is the source (`MemoID`), then the rows where it is the target (`RelatedMemoID`).
2. **Attachments linked to the memo** — it lists attachments by `MemoID` and deletes each one individually via `Store.DeleteAttachment`, which also removes the underlying stored file (local disk or S3 object) before deleting the attachment row.

Only after both cleanups does it call `s.driver.DeleteMemo` to delete the memo itself.
