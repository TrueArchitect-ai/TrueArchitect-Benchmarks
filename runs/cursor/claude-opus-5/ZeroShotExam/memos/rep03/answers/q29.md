**`web/src/connect.ts` (the `authInterceptor`, with token storage in `web/src/auth-state.ts`); short-lived JWT access tokens (Bearer header, ~15 min) plus the long-lived `memos_refresh` HttpOnly refresh-token cookie, and Personal Access Tokens (`memos_pat_…`) as an alternate Bearer credential; validated by `server/auth`.**

How it works:

- **Frontend interceptor** — `authInterceptor` in `web/src/connect.ts` is attached to the single Connect-Web transport (`createConnectTransport({ interceptors: [authInterceptor] })`) that backs every service client (`memoServiceClient`, `userServiceClient`, etc.). On each request it calls `getRequestToken()`, sets `Authorization: Bearer <token>`, and on a `Code.Unauthenticated` response it refreshes once, re-sends with an `X-Retry: true` marker, and calls `redirectOnAuthFailure()` if the refresh fails.

- **Tokens it manages** — the access token lives in `web/src/auth-state.ts`, cached in memory and mirrored into `localStorage` under `memos_access_token` / `memos_token_expires_at`, with a `BroadcastChannel` (`memos_token_sync`) so sibling tabs adopt a freshly refreshed token instead of racing. Expiry is checked with a buffer (30s for requests, 2min on tab focus) so a preflight refresh happens before the token goes stale. The refresh token itself is never touched by JS — it rides along as a cookie because `fetchWithCredentials` sets `credentials: "include"`, and refreshes go through a separate transport with no interceptors to avoid recursion.

- **Backend validation** — `server/auth` holds it all: `token.go` defines the JWT constants and the `ParseAccessTokenV2` / `ParseRefreshToken` verifiers (HS256, issuer `memos`, `kid` `v1`, audience `user.access-token` / `user.refresh-token`), `extract.go` pulls the bearer token and the `memos_refresh` cookie, and `authenticator.go` resolves a bearer into a user — stateless for access tokens, a database revocation lookup for refresh tokens, and a SHA-256 hash lookup for PATs. The Connect handler side plugs this in via `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go`, which authenticates the header and stores the result on the context with `auth.ApplyToContext`.
