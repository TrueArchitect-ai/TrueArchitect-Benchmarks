**SQLite, MySQL, PostgreSQL**

The migration files live under `store/migration/`, which contains exactly three driver subdirectories: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/`. Each holds a `LATEST.sql` full-schema file for fresh installs plus versioned incremental migration folders (SQLite goes back furthest, from `0.2` through `0.30`; MySQL starts at `0.17`; Postgres starts at `0.19`).

This directory layout is documented and consumed in `store/migrator.go`, which embeds the whole tree with `//go:embed migration` and resolves paths as `store/migration/{driver}/{version}/NN__description.sql`. The same three dialects have matching driver implementations in `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`.
