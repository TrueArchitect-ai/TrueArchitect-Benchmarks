**Engine + path:** The filter is a **CEL (Common Expression Language) expression**, parsed by Google's `cel-go` (`github.com/google/cel-go v0.28.1`, see `go.mod` line 13) inside the repo's own memo filter engine at **`internal/filter/`** — `engine.go` (entry point `filter.DefaultEngine()`), `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`, documented in `internal/filter/README.md`.

**Mechanism (one sentence):** `ListMemos` validates the filter string by compiling it (`server/router/api/v1/memo_service.go:211-215` calling `validateFilter` in `server/router/api/v1/shortcut_service.go:336-356`) and stashes it in `store.FindMemo.Filters` (`store/memo.go:72`); each dialect driver then calls `filter.AppendConditions(ctx, engine, find.Filters, <dialect>, &where, &args)` (`store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go:54-58`, `store/db/mysql/memo.go:65-69`), which runs the three-phase pipeline — `cel-go` compiles the expression against a memo-specific CEL environment of declared variables (`content`, `tags`, `visibility`, `created_ts`, `now`, `has_task_list`, plus `ext.Sets()`; `internal/filter/schema.go:233-254`), `parser.go`'s `buildCondition` normalizes the CEL AST into a dialect-agnostic IR condition tree, and `render.go`'s renderer walks that IR emitting a parameterized SQL fragment plus args for `DialectSQLite`/`DialectMySQL`/`DialectPostgres`, which is appended as an `AND`-ed `WHERE` clause.

A few details worth knowing about the rendering step:

- **Placeholders** differ per dialect: `?` for SQLite/MySQL, `$n` for Postgres (`internal/filter/render.go:846`), with `RenderOptions.PlaceholderOffset` keeping numbering consistent when composing with pre-existing query args.
- **Dialect-specific translations** are encapsulated in renderer helpers: tag membership becomes `LIKE` patterns on SQLite, `JSON_CONTAINS` on MySQL, and `@>` on Postgres; string `contains`/`startsWith`/`endsWith` become `LIKE` vs `ILIKE`; `matches()` becomes `REGEXP` vs `~` (SQLite relies on a Go-backed `regexp` function registered in `store/db/sqlite/functions.go`).
- **Time expressions** (`now`, `duration("24h")`, `timestamp(...)`) and arithmetic constant-fold at compile time to epoch seconds, with `now` frozen once per compile via the engine's injectable `nowFunc` (`internal/filter/engine.go:17-20, 62`).
- A separate `DefaultAttachmentEngine()` with its own schema serves attachment filters (`internal/filter/engine.go:119-124`).
