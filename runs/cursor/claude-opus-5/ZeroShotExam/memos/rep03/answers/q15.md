There's no ORM or `TableName()` method in this repo — the mapping is done by hand-written SQL in the per-database drivers, which is how I confirmed each pairing:

- `user`: `INSERT INTO user (...)` in `store/db/sqlite/user.go` (line 17), plus equivalents in `store/db/postgres/user.go` and `store/db/mysql/user.go` (line 18), all scanning into `store.User`.

One thing worth flagging so you don't grab the wrong type: there are identically named `User`, `Attachment`, and `Reaction` structs in the generated protobuf API layer (`proto/gen/api/v1/user_service.pb.go`, `proto/gen/api/v1/attachment_service.pb.go`, `proto/gen/api/v1/memo_service.pb.go`). Those are wire/API types, not table models.
