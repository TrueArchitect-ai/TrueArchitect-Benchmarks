`web/src/connect.ts`

That single file builds the shared `createConnectTransport` (binary format, credentialed fetch, auth interceptor) and then exports every service client created from it — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (`web/src/connect.ts` lines 184–203). It also creates a separate `refreshAuthClient` on its own transport at lines 65–72 for token refresh, so it doesn't recurse through the auth interceptor.
