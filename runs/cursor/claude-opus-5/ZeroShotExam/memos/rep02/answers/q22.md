`DispatchMemoCreatedWebhook` is a thin wrapper that delegates to `dispatchMemoRelatedWebhook` with the activity type `memos.memo.created`. That helper resolves the memo's creator, loads that user's webhooks via `Store.GetUserWebhooks` (which reads the `UserSetting_WEBHOOKS` user setting, `store/user_setting.go`), and for each hook builds a payload carrying the URL, activity type, creator, memo, and the hook's signing secret, then hands it to `webhook.PostAsync`:

Delivery happens in the `internal/webhook` package. `PostAsync` enqueues onto a buffered channel of capacity 128 (dropping with a warning if full), and four worker goroutines started in `init()` drain it into `Post`, which does the actual `net/http` POST through a shared client with a 30-second timeout and an SSRF-guarding `DialContext` that rejects reserved/private IPs after resolution.

Signing is HMAC-SHA256 in the Standard Webhooks style, applied only when the hook has a signing secret. Secrets stored in the `whsec_<base64>` form are base64-decoded to raw key bytes (`resolveSigningKey`, and `GenerateSigningSecret` mints 32 random bytes in that form); the signed message is `msgID + "." + timestamp + "."` followed by the JSON body:
