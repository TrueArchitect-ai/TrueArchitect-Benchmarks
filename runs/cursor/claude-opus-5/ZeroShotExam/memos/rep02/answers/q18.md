The `store.Driver` interface is declared in `store/driver.go`, and it has three implementations, each a package whose entry file defines the `DB` struct plus its `NewDB` constructor:

- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

`NewDBDriver` — `store/db/db.go`

It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) and returns an error for anything else. At startup it's called from `cmd/memos/main.go:57`; the test helpers in `store/test/store.go` and `server/router/api/v1/test/memo_service_benchmark_test.go` use the same factory.
