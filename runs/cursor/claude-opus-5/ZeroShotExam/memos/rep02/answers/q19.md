The actual wrapping of each gRPC method into Connect request/response types is in `connect_services.go` under the `// MemoService` section (starting line 304), e.g. `CreateMemo`, `ListMemos`, `GetMemo`, each delegating to `s.APIV1Service` and converting errors via `convertGRPCError`. The generated client/handler constructors are in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.

Both protocols share one implementation: `APIV1Service` embeds `v1pb.UnimplementedMemoServiceServer` (`server/router/api/v1/v1.go` line 26), and the `ConnectServiceHandler` simply embeds `*APIV1Service`. Note there is no standalone `grpc.NewServer` listener in this repo — the gRPC service definition is served through the gateway and Connect only. (The MCP router in `server/router/mcp` is a further layer that calls the REST surface, not a separate registration of MemoService.)
