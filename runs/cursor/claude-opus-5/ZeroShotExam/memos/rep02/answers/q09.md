`AIService`

It's defined in `proto/api/v1/ai_service.proto`, which declares a single RPC:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

The RPC takes a `TranscribeRequest` (containing `TranscriptionAudio`) and returns a `TranscribeResponse` with the transcribed text, exposed over HTTP as `POST /api/v1/ai:transcribe`.
