**SQLite, MySQL, PostgreSQL**

The migration files are embedded from `store/migration`, which has one subdirectory per dialect (`store/migration/sqlite`, `store/migration/mysql`, `store/migration/postgres`), each containing a `LATEST.sql` full-schema file plus per-version incremental migration folders. The migrator resolves the directory at runtime from the configured driver name:

```253:256:/bench/repo/store/migrator.go
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
```

This matches the three driver implementations under `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres`. Note that seed data (`store/seed`) exists only for SQLite.
