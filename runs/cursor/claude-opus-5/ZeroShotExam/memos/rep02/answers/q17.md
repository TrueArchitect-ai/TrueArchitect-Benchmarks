`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

That module holds the whole memo CRUD surface as TanStack Query hooks: `useMemos` / `useInfiniteMemos` (list), `useMemo` (get), `useCreateMemo`, `useUpdateMemo` (with optimistic cache patching and rollback), `useDeleteMemo`, plus comment and link-metadata queries, all keyed off the `memoKeys` factory.

Every call goes through `memoServiceClient`, imported from `@/connect`. That client is created in `web/src/connect.ts` at line 197 via `createClient(MemoService, transport)`, where `MemoService` comes from the generated protobuf code in `web/src/types/proto/api/v1/memo_service_pb.ts`.
