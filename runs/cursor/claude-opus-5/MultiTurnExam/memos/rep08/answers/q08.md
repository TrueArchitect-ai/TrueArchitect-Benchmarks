**`Driver` (i.e. `store.Driver`) — `store/driver.go`**

It's declared at line 10 and enumerates every method a backend must provide:

```8:19:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)

	// GetDatabaseSize returns the database size in bytes, or -1 if unavailable.
	// A non-nil error indicates a hard failure; -1 with nil error means the
	// driver cannot report a size from the underlying database.
	GetDatabaseSize(ctx context.Context) (int64, error)
```

Beyond connection management, it groups CRUD methods per model — attachments, memos, memo relations, instance settings, users, and so on. The three implementations are the `DB` structs in `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go`; each package's `NewDB` returns `store.Driver` rather than the concrete type, and `store/db/db.go` picks the implementation based on the configured driver name.
