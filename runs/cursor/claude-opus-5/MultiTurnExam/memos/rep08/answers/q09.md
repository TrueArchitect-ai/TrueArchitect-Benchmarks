**`AIService`**

It's the only RPC on that service, defined in `proto/api/v1/ai_service.proto`:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It takes a `TranscribeRequest` containing a required `TranscriptionAudio` field and returns a `TranscribeResponse`. Over REST it maps to `POST /api/v1/ai:transcribe`, and the generated Connect client lives in `proto/gen/api/v1/ai_service.connect.go`.
