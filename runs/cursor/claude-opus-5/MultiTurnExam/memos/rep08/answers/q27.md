**Mechanism: the built assets are compiled into the Go binary with `//go:embed` and served by Echo's static middleware, plus an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

The Vite build output is committed/copied to `server/router/frontend/dist` and embedded at compile time:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` (line 41) wires two middlewares onto the Echo instance: `middleware.StaticWithConfig` backed by the embedded filesystem, and `spaFallbackMiddleware`, which converts a 404 from the static handler into `index.html` so client-side routes resolve. A skipper excludes paths that belong to the backend — anything under `/api` or `/file`, the Connect routes matching `/memos.api.v1.*`, and `/robots.txt`, `/sitemap.xml`, and `*/rss.xml`, which are handled by `registerRoutes` in the same package.

Caching is differentiated by asset type via `setFrontendCacheHeaders`: HTML is `no-cache, no-store, must-revalidate`, plain static files get `public, max-age=3600`, and hash-named build artifacts get the `immutable` variant. Because everything is embedded, there is no external web server or separate static directory to deploy.
