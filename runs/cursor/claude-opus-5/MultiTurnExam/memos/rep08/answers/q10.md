**`store/migration/sqlite/LATEST.sql`**

The migrator's `preMigrate` path checks whether the database is initialized and, if not, applies the single `LATEST.sql` file for the configured driver in one transaction rather than replaying the incremental version folders:

```212:222:store/migrator.go
	initialized, err := s.driver.IsInitialized(ctx)
	if err != nil {
		return errors.Wrap(err, "failed to check if database is initialized")
	}

	if !initialized {
		filePath := s.getMigrationBasePath() + LatestSchemaFileName
		bytes, err := migrationFS.ReadFile(filePath)
		if err != nil {
			return errors.Errorf("failed to read latest schema file: %s", err)
		}
```

The path is composed from `getMigrationBasePath()`, which returns `migration/{driver}/` (line 255), plus the `LatestSchemaFileName` constant `"LATEST.sql"` (line 56) — so with `driver = sqlite` it resolves to the file above. Migration files are embedded via `//go:embed migration` in the same file, and MySQL and PostgreSQL have their own `LATEST.sql` alongside.
