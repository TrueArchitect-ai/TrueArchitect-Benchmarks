**`NewDBDriver` — `store/db/db.go`**

Each entry file declares a `DB` struct implementing `store.Driver` (defined in `store/driver.go`) and exposes a package-level `NewDB(profile)` constructor; the rest of each package's methods live in sibling files like `memo.go` and `user.go`. The factory dispatches on the configured driver name:

```18:27:store/db/db.go
	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
	case "postgres":
		driver, err = postgres.NewDB(profile)
	default:
		return nil, errors.New("unknown db driver")
	}
```

`profile.Driver` comes from `internal/profile`, and the same string also selects the migration directory (`migration/{driver}/`) in `store/migrator.go`, so the three driver packages and the three migration folders stay in one-to-one correspondence.
