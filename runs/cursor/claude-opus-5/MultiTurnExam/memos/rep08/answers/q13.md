Two things worth flagging for the review. The `Payload` field is `*storepb.MemoPayload`, a protobuf type generated from `proto/store/memo.proto` and stored as a serialized column, so a change touching it also implies a proto change and likely a migration under `store/migration/{sqlite,mysql,postgres}/`. And if you add or remove a persisted column, the schema files `store/migration/*/LATEST.sql` need a matching update alongside a new versioned migration, even though they don't reference the Go type directly.
