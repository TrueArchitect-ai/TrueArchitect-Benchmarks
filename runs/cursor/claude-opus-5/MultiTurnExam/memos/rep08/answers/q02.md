**SQLite, MySQL, PostgreSQL**

The migrations live under `repo/store/migration/`, which contains exactly three driver subdirectories: `sqlite/`, `mysql/`, and `postgres/`. Each holds versioned migration folders (for example `repo/store/migration/mysql/0.30/00__user_tag_setting.sql`) plus a `LATEST.sql` schema file.

This matches how the migrator resolves paths — it embeds the whole `migration` directory and selects the subdirectory by the configured driver name:

```253:256:repo/store/migrator.go
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
```

The corresponding driver implementations are in `repo/store/db/sqlite`, `repo/store/db/mysql`, and `repo/store/db/postgres`. Note that SQLite has the longest history (versions 0.2 through 0.30), MySQL starts at 0.17, and PostgreSQL starts at 0.19.
