`Serve` roots a sub-filesystem at `dist` and installs two middlewares — the static file server and the fallback:

```41:61:repo/server/router/frontend/frontend.go
func (s *FrontendService) Serve(_ context.Context, e *echo.Echo) {
	frontendFS := getFileSystem("dist")
	skipper := func(c *echo.Context) bool {
		requestPath := c.Request().URL.Path
		if shouldSkipFrontendStatic(requestPath) {
			return true
		}

		setFrontendCacheHeaders(c, requestPath)
		return false
	}

	// Route to serve the frontend static assets.
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		Skipper:    skipper,
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
	s.registerRoutes(e)
}
```

Client-side routing works because `spaFallbackMiddleware` (line 63) intercepts 404s for extensionless paths and returns `index.html` instead. The skipper keeps the static handler away from backend routes — anything under `/api`, `/file`, the Connect prefix `/memos.api.v1.*`, plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` (the first two are served by `registerRoutes` at line 123).

Caching is tiered in `setFrontendCacheHeaders` (line 92): HTML is `no-cache, no-store, must-revalidate`, hashed assets under `/assets/` get `max-age=3600, immutable`, and other static files get plain `max-age=3600`.
