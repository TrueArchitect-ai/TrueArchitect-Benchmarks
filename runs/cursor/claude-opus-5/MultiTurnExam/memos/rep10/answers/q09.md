**AIService**

`Transcribe` is the only RPC on that service, defined in `repo/proto/api/v1/ai_service.proto`:

```11:20:repo/proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It takes audio input and transcribes it via the configured instance AI provider, and over REST it maps to `POST /api/v1/ai:transcribe` using the custom-method colon syntax rather than a resource-style path. The generated bindings are at `repo/proto/gen/api/v1/apiv1connect/ai_service.connect.go`, and the frontend consumes it through `aiServiceClient` in `repo/web/src/connect.ts:199`.
