**`store/migration/sqlite/LATEST.sql`**

On startup, `preMigrate` checks whether the database is initialized; if not, it reads `LATEST.sql` from the driver-specific migration directory and applies the whole thing in a single transaction, skipping the incremental migrations entirely:


The base path is `fmt.Sprintf("migration/%s/", s.profile.Driver)` (line 255 of the same file), so for the `sqlite` driver it resolves to `migration/sqlite/LATEST.sql` inside the embedded FS. The design intent is stated in the file's header comment: "LATEST.sql: Full schema for new installations (faster than incremental migrations)".
