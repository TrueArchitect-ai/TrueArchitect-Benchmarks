**`AIService`**

It's the only RPC on that service, declared in `proto/api/v1/ai_service.proto`:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It takes a `TranscribeRequest` wrapping a `TranscriptionAudio` (a `oneof` that accepts either inline bytes or another source), and over REST it maps to `POST /api/v1/ai:transcribe`.
