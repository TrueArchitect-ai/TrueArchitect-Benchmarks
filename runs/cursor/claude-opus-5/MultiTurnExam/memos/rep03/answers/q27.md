**Mechanism: the Vite build output is compiled into the Go binary with `go:embed` and served as static files by Echo middleware, with an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

The whole `dist` tree is embedded at build time:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` (line 41) roots that FS at `dist` via `fs.Sub`, registers `middleware.StaticWithConfig` to serve the assets, and then adds `spaFallbackMiddleware`, which converts a 404 on any extension-less path into `index.html` so client-side routing works:

```76:77:server/router/frontend/frontend.go
			setFrontendCacheHeaders(c, requestPath)
			return c.FileFS("index.html", frontendFS)
```

A `skipper` keeps the static handler away from backend routes — anything under `/api` or `/file`, the Connect paths (`/memos.api.v1.*`), plus `robots.txt`, `sitemap.xml`, and `*/rss.xml`, which the same file registers as real routes. Cache headers differ by asset type: HTML is `no-cache, no-store, must-revalidate`, hashed files under `/assets/` get `max-age=3600, immutable`, and other static files get plain `max-age=3600`.
