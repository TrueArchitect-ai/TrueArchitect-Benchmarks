**`Driver` (i.e. `store.Driver`) — `store/driver.go`**

Declared at line 10, it's the single interface covering every database operation the app needs, grouped by model:

```8:19:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)

	// GetDatabaseSize returns the database size in bytes, or -1 if unavailable.
	// A non-nil error indicates a hard failure; -1 with nil error means the
	// driver cannot report a size from the underlying database.
	GetDatabaseSize(ctx context.Context) (int64, error)
```

Beyond connection handling, it declares the CRUD methods for attachments, memos, memo relations, instance settings, and the other models.

The three backends in `store/db/` each satisfy it with their own `DB` struct — for instance `store/db/postgres/postgres.go` returns it explicitly from its constructor:

```33:36:store/db/postgres/postgres.go
	var driver store.Driver = &DB{
		db:      db,
		profile: profile,
	}
```

`store/db/mysql/mysql.go` and `store/db/sqlite/sqlite.go` follow the same pattern, and `store/db/db.go` picks the implementation based on the configured driver name.
