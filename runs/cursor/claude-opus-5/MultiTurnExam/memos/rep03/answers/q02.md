**sqlite, mysql, postgres**

Migrations live under `repo/store/migration/`, which has exactly three dialect subdirectories: `sqlite/`, `mysql/`, and `postgres/`. They are selected at runtime by driver name — `repo/store/migrator.go` embeds the whole `migration` tree and resolves the path per driver:

```255:255:repo/store/migrator.go
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
```

This lines up with the three database driver implementations in `repo/store/db/` (`sqlite/`, `mysql/`, `postgres/`). Note the migration history differs by dialect: sqlite goes back to `0.2`, mysql starts at `0.17`, and postgres starts at `0.19`, with all three converging up to `0.30`.
