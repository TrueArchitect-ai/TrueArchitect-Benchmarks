**`memo_relation`**

It's a join table keyed on the pair of memo IDs plus a relation type, defined identically across all three dialects — for example:

```46:51:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The `memo_id` → `related_memo_id` columns are the two sides of the link, and `type` distinguishes the kind of relation (this is what backs both memo references and comment threading). The `UNIQUE` constraint prevents duplicate links of the same type.

The equivalent definitions are in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, and the table was introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`. Query and mutation logic lives in the per-dialect `memo_relation.go` files, e.g. `store/db/postgres/memo_relation.go`.
