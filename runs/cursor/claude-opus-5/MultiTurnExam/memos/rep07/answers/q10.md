**`store/migration/sqlite/LATEST.sql`**

`preMigrate` in `store/migrator.go` checks whether the database is already initialized and, if not, applies that single file in one transaction rather than replaying the incremental per-version migrations:

```217:222:store/migrator.go

		filePath := s.getMigrationBasePath() + LatestSchemaFileName

		}
```

The filename comes from the `LatestSchemaFileName = "LATEST.sql"` constant at line 56, and `getMigrationBasePath()` resolves the dialect directory — so for SQLite the path is `migration/sqlite/LATEST.sql` within the embedded filesystem. The comment block at line 42 states the intent directly: "LATEST.sql: Full schema for new installations (faster than incremental migrations)."

After applying it, the migrator stamps the database with the current schema version so subsequent upgrades pick up from the right point. The file itself contains the `CREATE TABLE` statements for all eleven tables (`user`, `memo`, `memo_relation`, `attachment`, `idp`, `inbox`, `reaction`, `memo_share`, `user_identity`, `user_setting`, `system_setting`).
