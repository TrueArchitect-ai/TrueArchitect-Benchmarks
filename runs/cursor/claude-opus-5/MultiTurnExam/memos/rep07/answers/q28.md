**Unused infrastructure note:** the `memopayload` runner at `server/runner/memopayload/runner.go` is never started. It defines `NewRunner` (line 19) and `RunOnce` (line 27), but nothing outside the package calls either — a repo-wide search finds only calls to its standalone `RebuildMemoPayload` function, invoked synchronously from the memo handlers at `server/router/api/v1/memo_service.go:108` and `:447`. So the runner type and its backfill entry point are dead code as far as the server is concerned, while the payload-rebuilding logic it wraps is used on the request path.

There is no cron library in the project — `go.mod` has no cron/scheduler dependency, so all scheduling is hand-rolled with `time.Ticker`.
