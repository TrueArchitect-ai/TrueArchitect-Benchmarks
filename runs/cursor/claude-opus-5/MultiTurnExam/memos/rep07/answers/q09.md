**AIService**

It's defined in `proto/api/v1/ai_service.proto`, where `Transcribe` is the service's only RPC:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It transcribes an audio file using an instance-configured AI provider, and maps to `POST /api/v1/ai:transcribe` in the REST gateway with the whole message as the request body.
