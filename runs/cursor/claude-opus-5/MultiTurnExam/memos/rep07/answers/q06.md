**`memo_relation`**

```47:52:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It's a join table with no surrogate key: `memo_id` points at the source memo, `related_memo_id` at the target, and `type` distinguishes the kind of link (for example a plain reference versus a comment). The uniqueness constraint spans all three columns, so the same pair of memos can be linked more than once under different types.
