**Go `embed` — the built assets are compiled into the binary and served as static files by Echo middleware, with SPA fallback; wired in `server/router/frontend/frontend.go`**

The build output is embedded at compile time:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` then mounts it:

```41:61:server/router/frontend/frontend.go
func (s *FrontendService) Serve(_ context.Context, e *echo.Echo) {
	frontendFS := getFileSystem("dist")
	skipper := func(c *echo.Context) bool {
		requestPath := c.Request().URL.Path
		if shouldSkipFrontendStatic(requestPath) {
			return true
		}

		setFrontendCacheHeaders(c, requestPath)
		return false
	}

	// Route to serve the frontend static assets.
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		Skipper:    skipper,
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
	s.registerRoutes(e)
}
```

A few details that matter in production. `fs.Sub(embeddedFiles, "dist")` strips the directory prefix so URLs map to asset paths directly. The `skipper` excludes API-ish paths from static handling (so `/api/v1/*` still reaches the gateway) and sets cache headers per asset class — `no-cache, no-store, must-revalidate` for HTML versus `max-age=3600, immutable` for content-hashed assets. `spaFallbackMiddleware` catches 404s from the static handler on HTML-ish routes and serves the SPA entry document instead, which is what makes client-side routes like `/memos/123` work on a hard refresh.

Because `dist` must exist for the package to compile, the web app is built before the Go binary; `server/router/frontend/dist` is the directory the Vite output lands in.
