Translation between the layers is explicit rather than automatic: the dialect files (`store/db/sqlite/memo.go` and siblings) map columns to the store struct, and `server/router/api/v1/memo_service_converter.go` maps the store struct to the proto message.

One layer that's easy to miss: the memo's semi-structured JSON `payload` column has its own schema in `proto/store/memo.proto` (`message MemoPayload` at line 7), surfaced in Go as the `Payload *storepb.MemoPayload` field on the store struct. So a field living inside the payload is defined there, not in the `LATEST.sql` table definition or the API proto.
