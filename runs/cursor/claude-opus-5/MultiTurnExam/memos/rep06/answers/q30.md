All four dispatchers are defined in `server/router/api/v1/memo_service_webhooks.go` (lines 15, 20, 25, 30). The first three are one-line wrappers around the shared helper `dispatchMemoRelatedWebhook` (line 48), which resolves the memo's creator, loads that user's hooks via `Store.GetUserWebhooks`, and enqueues each payload with `webhook.PostAsync` (line 71). `DispatchMemoCommentCreatedWebhook` is structured slightly differently: it targets the *parent* memo's creator (`relatedMemoCreatorID`) rather than the comment author, but ends at the same `webhook.PostAsync` call (line 43).
