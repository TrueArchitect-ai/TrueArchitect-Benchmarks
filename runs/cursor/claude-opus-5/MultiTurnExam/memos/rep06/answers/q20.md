**Mechanism:** Server-Sent Events (SSE), exposed at `GET /api/v1/sse`
**Hub path:** `server/router/api/v1/sse_hub.go` (endpoint handler in `server/router/api/v1/sse_handler.go`, event constructors in `server/router/api/v1/sse_event_helpers.go`)
**Handlers that broadcast:** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`, `UpsertMemoReaction`, `DeleteMemoReaction`

The hub is `SSEHub` in `sse_hub.go`, with `Subscribe`, `Unsubscribe`, `Broadcast`, and `Close`, plus a per-client `canReceive` filter so private memos only reach permitted users. Event types are enumerated there:

```15:20:server/router/api/v1/sse_hub.go
	SSEEventMemoCreated        SSEEventType = "memo.created"
	SSEEventMemoUpdated        SSEEventType = "memo.updated"
	SSEEventMemoDeleted        SSEEventType = "memo.deleted"
	SSEEventMemoCommentCreated SSEEventType = "memo.comment.created"
	SSEEventReactionUpserted   SSEEventType = "reaction.upserted"
	SSEEventReactionDeleted    SSEEventType = "reaction.deleted"
```

The route is registered by `RegisterSSERoutes` (line 25 of `sse_handler.go`), which is wired into the Echo group in `server/router/api/v1/v1.go` (line 125).

Where each broadcast happens:

- `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126`, emitting `memo.comment.created` for the parent
- `UpsertMemoReaction` / `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:106` and `:161`
