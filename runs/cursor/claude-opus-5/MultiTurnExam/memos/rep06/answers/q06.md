**`memo_relation`**

The table is defined in each dialect's schema, e.g. `store/migration/sqlite/LATEST.sql`:

```47:52:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It links a source memo (`memo_id`) to a target memo (`related_memo_id`) with a relation `type` (for example reference vs. comment). The corresponding Go store code lives in `store/memo_relation.go` with per-dialect implementations in `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
