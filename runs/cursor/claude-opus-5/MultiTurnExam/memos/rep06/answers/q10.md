**`store/migration/sqlite/LATEST.sql`**

On startup, `Store.preMigrate` checks whether the database is initialized; if it isn't, it applies the full current schema from `LATEST.sql` rather than replaying incremental migrations:

```218:218:store/migrator.go
		filePath := s.getMigrationBasePath() + LatestSchemaFileName
```

The base path is dialect-specific, `migration/<driver>/` (line 255), so with `Driver = "sqlite"` it resolves to `migration/sqlite/LATEST.sql` inside the embedded `migrationFS` (`//go:embed migration` at line 44) — that is `store/migration/sqlite/LATEST.sql` on disk. This behavior is also what `store/test/migrator_test.go` exercises in its fresh-install test.
