**AIService**

`Transcribe` is the sole RPC on `AIService`, defined in `proto/api/v1/ai_service.proto`:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It takes audio input and is exposed over REST as `POST /api/v1/ai:transcribe`.
