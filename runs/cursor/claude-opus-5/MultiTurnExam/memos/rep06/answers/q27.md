**Mechanism: the built assets are embedded into the Go binary with `//go:embed dist/*` and served by Echo static middleware plus an SPA fallback; `server/router/frontend/frontend.go`**

The embed directive and filesystem are at the top of that file:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` (line 41) mounts `dist` through `middleware.StaticWithConfig` and then installs `spaFallbackMiddleware`, which turns 404s on non-API paths into the SPA's `index.html` so client-side routing works. Cache headers are set per asset kind — `no-cache` for HTML, one hour for static assets, and one hour `immutable` for hashed filenames (lines 24–26).

So in production the Vite build output from `web/` is copied to `server/router/frontend/dist` at build time and compiled into the binary; there is no separate web server or filesystem dependency at runtime.
