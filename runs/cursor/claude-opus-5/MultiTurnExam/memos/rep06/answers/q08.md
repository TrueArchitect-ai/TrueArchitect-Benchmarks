**Driver — `store/driver.go`**

`store.Driver` is declared at line 10 of `store/driver.go` and covers everything a backend must provide: connection handling (`GetDB`, `Close`), `IsInitialized`, `GetDatabaseSize`, plus CRUD methods for each model (attachment, memo, memo relation, instance setting, user, and so on).

```8:19:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)

	// GetDatabaseSize returns the database size in bytes, or -1 if unavailable.
	// A non-nil error indicates a hard failure; -1 with nil error means the
	// driver cannot report a size from the underlying database.
	GetDatabaseSize(ctx context.Context) (int64, error)
```

The three implementations are the `DB` structs in `store/db/sqlite/`, `store/db/postgres/`, and `store/db/mysql/`; their `NewDB` constructors return `store.Driver`, and `store/db/db.go` picks one based on the configured driver.
