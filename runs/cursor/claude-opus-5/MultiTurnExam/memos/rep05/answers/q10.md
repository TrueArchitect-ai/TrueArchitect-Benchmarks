**`store/migration/sqlite/LATEST.sql`**

That's the full current schema applied to a fresh SQLite database instead of replaying the incremental migrations. `store/migrator.go` documents it as "LATEST.sql: Full schema for new installations (faster than incremental migrations)" (line 42) and defines the constant `LatestSchemaFileName = "LATEST.sql"` (line 56).

In `preMigrate`, when the driver reports the database isn't initialized, it reads that file from the embedded FS and applies it in a single transaction:

```217:222:/bench/repo/store/migrator.go

		filePath := s.getMigrationBasePath() + LatestSchemaFileName
```

The dialect comes from `getMigrationBasePath()`, which builds `migration/{driver}/`, so the SQLite install resolves to the path above. After applying it, the schema version is stamped into `system_setting` directly (`getSchemaVersionOfMigrateScript` returns the current version for this file), so no incremental migrations run afterward.
