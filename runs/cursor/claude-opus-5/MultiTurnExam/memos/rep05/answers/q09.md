**`AIService`**

It's defined in `proto/api/v1/ai_service.proto`, and `Transcribe` is the service's only RPC:

```11:20:/bench/repo/proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

It transcribes audio through an instance-configured AI provider, taking a `TranscribeRequest` whose required `audio` field is a `TranscriptionAudio` with a `oneof source` (inline bytes or an alternative source). Over REST it maps to `POST /api/v1/ai:transcribe` with the whole message as the body.
