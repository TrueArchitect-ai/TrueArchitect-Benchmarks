**`memo_relation`**

The table is defined identically across all three dialects, for example in `store/migration/sqlite/LATEST.sql` (line 47) and `store/migration/postgres/LATEST.sql` (line 46):

```47:52:/bench/repo/store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It's a join table keyed on the pair `memo_id` (the source memo) and `related_memo_id` (the target), with a `type` column distinguishing the kind of link, such as a plain reference versus a comment. The uniqueness constraint covers all three columns, so the same two memos can be linked more than once under different types. The corresponding store code lives in `store/db/postgres/memo_relation.go` and its MySQL and SQLite counterparts.
