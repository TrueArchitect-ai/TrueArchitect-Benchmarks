**Mechanism: the Vite build output is embedded into the Go binary with `go:embed` and served as static files by Echo middleware, with SPA fallback to `index.html`; wired in `server/router/frontend/frontend.go`**

The build artifacts are compiled into the binary at line 20, so production needs no separate web server or asset directory:

```20:21:/bench/repo/server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` (line 41) takes an `fs.Sub` of that embedded tree via `getFileSystem("dist")`, registers `middleware.StaticWithConfig` against it, and then adds `spaFallbackMiddleware`, which catches the not-found error from the static handler and returns `index.html` so client-side routes resolve. A skipper excludes non-frontend paths (API routes and similar) and sets cache headers on the rest: `no-cache` for HTML, `max-age=3600` for plain static assets, and `max-age=3600, immutable` for hash-named assets.

The `dist` directory being embedded is `server/router/frontend/dist`, which is where the web build is placed; the frontend source itself lives in `web/`.
