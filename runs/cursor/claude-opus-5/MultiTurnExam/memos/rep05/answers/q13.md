Two caveats on scope. This list comes from matching the `store.Memo` qualifier (plus unqualified `*Memo` inside the `store` package), so code that only touches related types like `FindMemo`, `UpdateMemo`, or `MemoRelation` isn't included even though a schema-level change would often ripple there.
