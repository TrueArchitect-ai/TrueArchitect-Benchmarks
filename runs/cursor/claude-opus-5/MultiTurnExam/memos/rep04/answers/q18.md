**NewDBDriver — `store/db/db.go`**

Each dialect package declares its own `DB` struct implementing the `store.Driver` interface from q08 (the Postgres one is shown in q03), with the rest of the interface methods spread across per-model files in the same package.

The factory switches on the configured driver string and returns the matching implementation as a `store.Driver`:

```18:27:/bench/repo/store/db/db.go
	switch profile.Driver {
	case "sqlite":
		driver, err = sqlite.NewDB(profile)
	case "mysql":
		driver, err = mysql.NewDB(profile)
	case "postgres":
		driver, err = postgres.NewDB(profile)
	default:
		return nil, errors.New("unknown db driver")
	}
```

The same `profile.Driver` string is what `Store.getMigrationBasePath()` interpolates to pick the migration directory (q02, q10), so the driver selection and the schema selection stay in sync off one config value.
