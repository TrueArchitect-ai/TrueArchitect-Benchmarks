All ConnectRPC clients are created and exported from this single file. It builds one shared transport (`createConnectTransport` with `baseUrl: window.location.origin`, binary format, credentialed fetch, and an auth interceptor) at line 184, then instantiates a client per service on lines 192–203:

export const instanceServiceClient = createClient(InstanceService, transport);
export const authServiceClient = createClient(AuthService, transport);
export const userServiceClient = createClient(UserService, transport);

// Content service clients

export const attachmentServiceClient = createClient(AttachmentService, transport);

// Configuration service clients

That's a client for each of the eight services from q05. The file also defines a second, separate transport at line 65 with its own `refreshAuthClient` — deliberately kept off the interceptor chain so that token-refresh calls don't recurse through the auth interceptor that triggers them.
