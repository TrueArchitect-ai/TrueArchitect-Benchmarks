**mysql, postgres, sqlite**

Migrations live under `store/migration/`, which has exactly three dialect subdirectories: `store/migration/mysql`, `store/migration/postgres`, and `store/migration/sqlite`.

The directory name is the dialect selector at runtime. `store/migrator.go` builds the embedded-FS path from the configured driver:

```255:255:repo/store/migrator.go
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
```

This matches the three driver implementations in `store/db/` (`mysql`, `postgres`, `sqlite`). Note the dialects differ in migration history depth: SQLite goes back to `0.2` while MySQL starts at `0.17` and Postgres at `0.19`, but all three are current through `0.30`.
