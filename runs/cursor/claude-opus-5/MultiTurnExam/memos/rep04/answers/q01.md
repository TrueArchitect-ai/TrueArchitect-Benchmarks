The mapping is declared with a `google.api.http` annotation on the RPC in `proto/api/v1/memo_service.proto`:

```21:27:repo/proto/api/v1/memo_service.proto
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {

      body: "memo"

    option (google.api.method_signature) = "memo";
```

The `body: "memo"` means the request body is the `Memo` message itself rather than the full `CreateMemoRequest` wrapper. This is confirmed by the generated gateway code in `proto/gen/api/v1/memo_service.pb.gw.go`, which registers the handler with the HTTP path pattern `/api/v1/memos` (lines 968 and 1406).
