**memo_relation**

Defined in `store/migration/sqlite/LATEST.sql` (lines 46–52), and originally introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`:

```47:52:/bench/repo/store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It's a join table: `memo_id` is the source memo, `related_memo_id` the target, and `type` distinguishes the kind of link (this is what lets a comment be modeled as a relation back to its parent memo). The uniqueness constraint spans all three columns, so the same pair of memos can be linked more than once under different types. Access code lives in `store/db/postgres/memo_relation.go` and the equivalent files for the other dialects.
