```8:19:/bench/repo/store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)

	// GetDatabaseSize returns the database size in bytes, or -1 if unavailable.
	// A non-nil error indicates a hard failure; -1 with nil error means the
	// driver cannot report a size from the underlying database.
	GetDatabaseSize(ctx context.Context) (int64, error)
}
```

It's a wide interface rather than a thin connection abstraction: beyond lifecycle methods (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) it declares full CRUD for every model — attachments, memos, memo relations, instance settings, users, and more — grouped by model in the source. Each dialect package implements the whole set on its own `DB` struct, which is why `store/db/postgres/` (and its MySQL/SQLite siblings) contains one file per model. This is the interface that `postgres.NewDB` returns, as seen in q03.
