**Mechanism: Server-Sent Events (SSE)**

**Hub: `/bench/repo/server/router/api/v1/sse_hub.go`**

**Handlers that broadcast: `CreateMemo`, `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, `DeleteMemoReaction`, plus memo updates via the shared helper `dispatchMemoUpdatedSideEffects`**

The hub is a mutex-guarded set of connected clients, each holding a buffered channel plus the subscriber's user ID and role:


Six event types are defined at lines 15–20: `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, and `reaction.deleted`. The `SSEEvent` payload carries `Type`, `Name`, and optional `Parent` over the wire, while `Visibility` and `CreatorID` are marked `json:"-"` because they exist purely for server-side delivery filtering — that's how private memos aren't leaked to other subscribers.
