**sqlite, mysql, postgres**

The migrations live in `/bench/repo/store/migration/`, which contains exactly three subdirectories — `sqlite/`, `mysql/`, and `postgres/` — each with per-version SQL files (for example `/bench/repo/store/migration/postgres/0.30/00__user_tag_setting.sql`) plus a `LATEST.sql` full-schema file.

The directory name is the driver key: the whole tree is embedded into the binary and the path is selected at runtime from the configured driver.

```254:256:/bench/repo/store/migrator.go
func (s *Store) getMigrationBasePath() string {
	return fmt.Sprintf("migration/%s/", s.profile.Driver)
}
```

A comment in the same file documents the layout as `store/migration/{driver}/{version}/NN__description.sql`. Note that the three dialects don't share the same history depth — SQLite has migrations going back to 0.10, MySQL starts at 0.17, and Postgres starts at 0.19 — but all three are shipped and maintained through the current version (0.30).
