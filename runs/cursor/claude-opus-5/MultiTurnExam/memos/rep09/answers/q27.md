The static handler serves real files; `spaFallbackMiddleware` (line 63) catches downstream 404s and returns `index.html` instead, so client-side routes deep-link correctly. It's careful to only do that for paths that should render HTML.

The skipper at line 82 excludes paths that must not be swallowed by the frontend: anything under `/api` or `/file`, the Connect RPC prefixes (`/memos.api.v1` and `/memos.api.v1.*`), plus `/robots.txt`, `/sitemap.xml`, and any `*/rss.xml` — those last three are handled by `registerRoutes` (line 60) so they can be generated dynamically from store data.

Caching is differentiated by asset type via the three constants at lines 24–26: HTML is `no-cache, no-store, must-revalidate`, plain static assets get one hour, and content-hashed assets get one hour plus `immutable`.

The committed build output lives at `/bench/repo/server/router/frontend/dist`, which is where the `web/` Vite build is placed so `go:embed` can pick it up at compile time.
