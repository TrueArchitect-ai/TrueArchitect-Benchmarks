**AIService**

It's defined in `proto/api/v1/ai_service.proto`, where `Transcribe` is the service's only RPC — it takes audio input and transcribes it using an instance AI provider:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

Over REST it maps to `POST /api/v1/ai:transcribe` with the whole request as the body. The generated Connect binding is at `proto/gen/api/v1/apiv1connect/ai_service.connect.go`, and the frontend consumes it through `aiServiceClient` in `web/src/connect.ts`.
