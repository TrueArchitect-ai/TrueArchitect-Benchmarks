**Go `embed` — the built `web/dist` output is compiled into the binary and served by Echo static middleware with an SPA fallback; wired in `server/router/frontend/frontend.go`**

The whole `dist` tree is embedded at compile time:

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

`FrontendService.Serve` mounts that filesystem as Echo static middleware, then adds a fallback so any unmatched non-API route returns `index.html` and lets client-side routing take over:

```54:60:server/router/frontend/frontend.go
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		Skipper:    skipper,
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
	s.registerRoutes(e)
```

The service is constructed and invoked from `server/server.go`. Cache-control differs by asset type: `no-cache` for HTML, one hour for plain static files, and one hour `immutable` for hash-named build assets (constants at lines 24-26). The skipper is what keeps `/api/v1/*` and similar paths from being swallowed by the static handler or the fallback.

Note that `server/router/frontend/dist` must exist at build time for the embed to compile, which is why the frontend build runs before the Go build in the Docker image.
