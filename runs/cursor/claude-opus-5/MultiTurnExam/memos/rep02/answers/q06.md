**memo_relation**

It's a join table with three columns and no surrogate key — `memo_id`, `related_memo_id`, and `type` — with a uniqueness constraint across all three, so the same pair can be linked more than once under different relation types:

```47:52:store/migration/sqlite/LATEST.sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The table is defined identically in all three dialects (`store/migration/postgres/LATEST.sql` line 46, `store/migration/mysql/LATEST.sql` line 46), and maps to the `MemoRelation` model in `store/memo_relation.go`, with per-dialect queries in `store/db/{sqlite,postgres,mysql}/memo_relation.go`. The `type` column holds values like reference vs. comment (see `MemoRelationType` in `store/memo_relation.go`), which is how comments on a memo are modeled as relations.
