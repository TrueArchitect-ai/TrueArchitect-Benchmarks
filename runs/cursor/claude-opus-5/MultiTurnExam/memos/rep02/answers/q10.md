**`store/migration/sqlite/LATEST.sql`**

On a fresh install, `preMigrate` detects the database isn't initialized and applies the full current schema from this one file rather than replaying the incremental migrations, then records the schema version immediately:

```38:42:store/migrator.go
// Migration Files:
// - Location: store/migration/{driver}/{version}/NN__description.sql
// - Naming: NN is zero-padded patch number, description is human-readable
// - Ordering: Files sorted lexicographically and applied in order
// - LATEST.sql: Full schema for new installations (faster than incremental migrations)
```

The filename comes from the `LatestSchemaFileName` constant (line 56 of `store/migrator.go`), and the path is resolved per driver — so `sqlite` here, with parallel files for the other two dialects. The whole `migration` directory is compiled into the binary via `//go:embed migration` (line 44), so the file ships inside the executable.
