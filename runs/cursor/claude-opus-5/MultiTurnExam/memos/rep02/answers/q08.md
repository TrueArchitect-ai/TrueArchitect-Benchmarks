**Driver — `store/driver.go`**

`store.Driver` is the single interface each backend satisfies, declared at line 10. It starts with connection-level and lifecycle methods, then groups CRUD methods per model:

```10:19:store/driver.go
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)

	// GetDatabaseSize returns the database size in bytes, or -1 if unavailable.
	// A non-nil error indicates a hard failure; -1 with nil error means the
	// driver cannot report a size from the underlying database.
	GetDatabaseSize(ctx context.Context) (int64, error)
```

The three implementations are the `DB` structs in `store/db/sqlite/`, `store/db/postgres/`, and `store/db/mysql/`, each selected by `NewDBDriver` in `store/db/db.go`, which returns the concrete type as a `store.Driver`. The `Store` type wraps this interface and delegates to it (visible in `store/memo_relation.go`, where `s.driver.UpsertMemoRelation` is called).
