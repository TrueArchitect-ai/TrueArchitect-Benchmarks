If you're prioritizing, the three dialect files are mandatory for any field change since they hand-write the column lists and `rows.Scan` targets, and a new field silently missing there produces zero-valued memos rather than a compile error. `memo_service_converter.go` is the other must-review file — it's the single translation point between the store struct and the proto `Memo`. Adding a field to the SQL layer also means touching `store/migration/{sqlite,postgres,mysql}/LATEST.sql` plus a new versioned migration directory, which the Go grep above won't surface.
