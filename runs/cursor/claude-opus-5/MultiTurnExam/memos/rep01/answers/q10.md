**`store/migration/sqlite/LATEST.sql`**

On an uninitialized database the migrator skips the incremental migrations entirely and executes the dialect's `LATEST.sql` in one transaction:

```217:222:store/migrator.go

		filePath := s.getMigrationBasePath() + LatestSchemaFileName

		if err != nil {

```

`getMigrationBasePath()` resolves to `migration/sqlite/` for the SQLite driver, and `LatestSchemaFileName` is `"LATEST.sql"` (`store/migrator.go`, lines 54-56). The file itself is embedded via the `//go:embed migration` directive.
