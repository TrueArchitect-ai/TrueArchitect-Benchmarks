```14:16:server/router/api/v1/memo_service_webhooks.go
// DispatchMemoCreatedWebhook dispatches a webhook when a memo is created.
func (s *APIV1Service) DispatchMemoCreatedWebhook(ctx context.Context, memo *v1pb.Memo) error {
	return s.dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.created")
```

`dispatchMemoRelatedWebhook` loads the creator's hooks via `Store.GetUserWebhooks`, converts the memo with `convertMemoToWebhookPayload`, and calls `webhook.PostAsync(payload)` for each one, so delivery happens off the request path.

HTTP delivery lives in `internal/webhook/webhook.go` (`Post`/`PostAsync`, using a hardened `safeClient`; URL vetting is in `internal/webhook/validate.go`). When the hook has a signing secret, the body is signed over `msgID + "." + timestamp + "."` plus the payload and sent as the `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`) headers:

```142:149:internal/webhook/webhook.go
		mac := hmac.New(sha256.New, key)
		mac.Write([]byte(msgID + "." + timestamp + "."))
		mac.Write(body)
		signature := base64.StdEncoding.EncodeToString(mac.Sum(nil))

		req.Header.Set("webhook-timestamp", timestamp)
		req.Header.Set("webhook-signature", "v1,"+signature)
```

Secrets are generated as `whsec_<base64 of 32 random bytes>` by `GenerateSigningSecret` and base64-decoded by `resolveSigningKey` before use.
