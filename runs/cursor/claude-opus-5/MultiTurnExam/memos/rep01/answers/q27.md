**Mechanism: the Vite build output is embedded into the Go binary with `//go:embed` and served by Echo static middleware, with an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

```20:21:server/router/frontend/frontend.go
//go:embed dist/*
var embeddedFiles embed.FS
```

The compiled assets live in `server/router/frontend/dist`, are exposed as a sub-filesystem by `getFileSystem("dist")`, and registered as middleware:

```54:59:server/router/frontend/frontend.go
	e.Use(middleware.StaticWithConfig(middleware.StaticConfig{
		Filesystem: frontendFS,
		...
	}))

	e.Use(spaFallbackMiddleware(frontendFS))
```

`spaFallbackMiddleware` turns a 404 for a non-asset path into `index.html` so client-side routing works, `shouldSkipFrontendStatic` keeps API/file routes out of the static handler, and static assets get `Cache-Control: public, max-age=3600`.
