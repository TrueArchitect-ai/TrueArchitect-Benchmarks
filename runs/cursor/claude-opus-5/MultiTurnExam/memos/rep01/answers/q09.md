**`AIService`**

It's the only RPC in that service, defined in `proto/api/v1/ai_service.proto`, and it transcribes audio via the instance's configured AI provider:

```11:20:proto/api/v1/ai_service.proto
service AIService {
  // Transcribe transcribes an audio file using an instance AI provider.
  rpc Transcribe(TranscribeRequest) returns (TranscribeResponse) {
    option (google.api.http) = {
      post: "/api/v1/ai:transcribe"
      body: "*"
    };
    option (google.api.method_signature) = "audio";
  }
}
```

Fully qualified, that's `memos.api.v1.AIService`, reachable over REST at `POST /api/v1/ai:transcribe`.
