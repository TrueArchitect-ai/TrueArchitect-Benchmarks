**`store.Driver` — `store/driver.go`**

```8:14:store/driver.go
// Driver is an interface for store driver.
// It contains all methods that store database driver should implement.
type Driver interface {
	GetDB() *sql.DB
	Close() error

	IsInitialized(ctx context.Context) (bool, error)
```

It covers connection lifecycle plus CRUD for every model (attachments, memos, users, relations, and so on). The three backends implement it as `*DB` structs in `store/db/sqlite`, `store/db/postgres`, and `store/db/mysql`; for example `postgres.NewDB` returns `store.Driver` in `store/db/postgres/postgres.go`, and the driver is selected in `store/db/db.go`.
