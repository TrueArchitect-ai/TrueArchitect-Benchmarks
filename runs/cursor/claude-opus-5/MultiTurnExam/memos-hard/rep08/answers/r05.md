**Premise correction: there is no GraphQL in this repository.** Searching all Go, TypeScript, JSON, and module files for `graphql`, `gqlgen`, or `.graphql` returns zero matches, and a filesystem search for `*.graphql`/`*.gql` files finds none. There is no schema file, no resolver layer, and no GraphQL dependency.

**Actual API surface: Protocol Buffers / gRPC service definitions, exposed over three transports plus a generated OpenAPI document.**

The schema of record is nine `.proto` files under `proto/api/v1/`: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, and `user_service.proto`. A parallel set under `proto/store/` (`attachment.proto`, `idp.proto`, `inbox.proto`, `instance_setting.proto`, `memo.proto`, `user_setting.proto`) defines internal persistence payloads rather than public API messages. Code generation is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`), emitting into `proto/gen/`.

Three ways clients reach those services, all implemented by the same `APIV1Service`:

- **gRPC** — generated servers such as `proto/gen/api/v1/memo_service_grpc.pb.go`.
- **Connect RPC** — handlers in `proto/gen/api/v1/apiv1connect/`, wired up through `server/router/api/v1/connect_services.go` and registered in `RegisterGateway` (`server/router/api/v1/v1.go:64`).
- **REST via gRPC-Gateway** — generated `*.pb.gw.go` files, giving the HTTP/JSON surface the web frontend uses.

For documentation and machine-readable description, the closest analogue to a GraphQL schema is the generated OpenAPI spec at `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go` and returned by `proto.OpenAPIYAML()`. That spec is also consumed programmatically by the MCP router, which parses it to build its tool registry (`loadOpenAPISpec` and `buildOperationRegistry` in `server/router/mcp/openapi.go:57,73`).

Alongside the RPC surface there are a few hand-written Echo HTTP routes that aren't proto-defined: the file server under `/file` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), the sitemap and `robots.txt` (`server/router/frontend/frontend.go`), and `/healthz` (`server/server.go:67`).
