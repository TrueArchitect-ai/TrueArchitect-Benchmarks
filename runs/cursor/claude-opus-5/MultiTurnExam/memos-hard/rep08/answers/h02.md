**`webhook.Post` — `internal/webhook/webhook.go:120` (the actual `safeClient.Do(req)` call is at line 152); protection is the SSRF-guarded dialer `safeDialContext` on the shared client's transport — `internal/webhook/webhook.go:59` (with `isReservedIP` / `reservedCIDRs` in `internal/webhook/validate.go:14-54`).**

Details on each half:

**Where delivery executes.** `Post` marshals the `WebhookRequestPayload` to JSON, builds the POST request, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and issues the request through the package-level `safeClient` at `internal/webhook/webhook.go:152`. Response handling requires a 2xx status and a JSON body with `code == 0`.

In practice the memo hooks don't call `Post` directly — `server/router/api/v1/memo_service_webhooks.go:43` and `:71` call `webhook.PostAsync`, which just enqueues onto the buffered `asyncPostQueue` (capacity 128) and drops the dispatch with a warning if it's full. Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`, so the network I/O always ends up in `Post`.

**What protects it.** Two layers, both keyed off `isReservedIP`:

- The enforcing layer is `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the `DialContext` of `safeClient`'s transport. At dial time it resolves the hostname and refuses the connection if *any* returned address falls in a reserved range. Because the check happens on every dial rather than once at configuration time, it also defeats DNS rebinding — the comment at lines 30–31 says as much.
- An earlier, friendlier layer is `webhook.ValidateURL` (`internal/webhook/validate.go:62`), called when a user creates or updates a webhook (`server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`). It requires an absolute `http`/`https` URL that doesn't resolve to a reserved IP, and returns a gRPC `InvalidArgument` so bad URLs are rejected at the API boundary.

The blocked ranges are IPv4 loopback, all three RFC-1918 blocks, link-local `169.254.0.0/16` (explicitly covering cloud IMDS at 169.254.169.254), plus the IPv6 equivalents `::1/128`, `fc00::/7`, and `fe80::/10` (`internal/webhook/validate.go:14-23`). The whole guard can be turned off for self-hosted setups via the `AllowPrivateIPs` global, set from the `allow-private-webhooks` config flag at `cmd/memos/main.go:49`; when true, `isReservedIP` returns `false` for everything and both layers become no-ops.
