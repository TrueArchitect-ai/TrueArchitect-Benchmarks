**Premise correction: there is no nightly database-cleanup job, and the cron scheduler is never used by the server.** Nothing is scheduled, so there is no time to report.

Two separate corrections are bundled in that:

**The cron scheduler exists but has zero production consumers.** `internal/scheduler` is a complete, tested cron package — `Scheduler` with `Register`/`Start`/`Stop`, a cron expression parser (`internal/scheduler/parser.go`), job definitions (`internal/scheduler/job.go`), and middleware (`internal/scheduler/middleware.go`). But grepping for imports of `github.com/usememos/memos/internal/scheduler` across the repo returns only two files, both tests: `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. No server, command, or runner code imports it, so `Scheduler.Register` is never called outside tests and no cron expression is ever registered.

**There is no database-cleanup job to schedule.** The only "daily-cleanup" string in the repo is illustrative documentation inside a code comment showing how to use the package (`internal/scheduler/doc.go:15-18`) — a sample job named `daily-cleanup` with "Your cleanup logic here" as the body. It's a doc example, not a registered job. Searching for `vacuum`, `prune`, `purge`, and `retention` finds no such job either.

What actually does periodic background work is the runner mechanism described earlier, which uses a plain `time.Ticker` rather than cron: the S3 presign runner started at `server/server.go:162-171`, running `RunOnce` immediately at boot and then every 12 hours (`server/runner/s3presign/runner.go:27`). Its schedule is a fixed interval, not a wall-clock time, so it has no "nightly at HH:MM" semantics.

The other recurring cleanup in the process is in-memory rather than in the database: each `cache.Cache` runs a `cleanupLoop` goroutine that sweeps expired entries every 5 minutes (`store/store.go:42`, `store/cache/cache.go:200-215`).

Cleanup of database rows does happen, but it's event-driven, not scheduled — for example, the delete-user transaction that removes memos, reactions, attachments, and related rows (`store/db/sqlite/user_delete.go:92`), and attachment/relation cleanup during memo deletion (`server/router/api/v1/memo_service.go:579`).
