**`s3presign.Runner` (`server/runner/s3presign/runner.go`) — runs once immediately at startup, then every 12 hours — wired in `server/server.go:162` (created/kicked off inside `startBackgroundRunners`, which is itself called from `Server.Start` at `server/server.go:129`).**

Details:

- **What it does:** S3-backed attachments store their content externally, and the database keeps a presigned GET URL in the attachment's `Reference` field. Presigned URLs expire, so this runner re-signs them before they go stale. It pages through attachments with `StorageType == AttachmentStorageType_S3` in batches of 100, skips any whose `LastPresignedTime` is less than 4 days old (URLs are minted with a 5-day expiration, giving a one-day safety margin), and otherwise calls `s3Client.PresignGetObject` and writes the new URL plus an updated `LastPresignedTime` back via `store.UpdateAttachment`.

```26:41:server/runner/s3presign/runner.go
// Schedule runner every 12 hours.
const runnerInterval = time.Hour * 12

func (r *Runner) Run(ctx context.Context) {
	ticker := time.NewTicker(runnerInterval)
	defer ticker.Stop()

	for {
		select {
		case <-ticker.C:
			r.RunOnce(ctx)
		case <-ctx.Done():
			return
		}
	}
}
```

- **Schedule:** one synchronous `RunOnce(ctx)` at boot (so stale links are fixed without waiting half a day), then a `time.Ticker` firing every 12 hours in a background goroutine.

- **Wiring:** `startBackgroundRunners` gives the runner its own cancellable context, registers the cancel func and a `WaitGroup` entry so `Shutdown` can stop and wait for it cleanly.
