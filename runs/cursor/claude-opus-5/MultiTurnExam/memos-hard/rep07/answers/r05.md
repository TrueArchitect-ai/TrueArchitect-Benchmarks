**Premise correction: there is no GraphQL anywhere in this repository. A case-insensitive search for "graphql" across the entire tree (excluding `node_modules` and `.git`) returns zero matches, and there are no `.graphql`, `.gql`, or `.graphqls` schema files. No GraphQL server library appears in `go.mod`, and no resolver or schema definition exists to point to.**

**The actual API surface is Protobuf-defined and served three ways over HTTP.**

**Schema definitions** live in `proto/api/v1/` as `.proto` files, one per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. A parallel set of internal persistence messages lives in `proto/store/` (for example `proto/store/memo.proto`, `proto/store/idp.proto`). Code generation is driven by `proto/buf.gen.yaml` and `proto/buf.yaml`, with output committed under `proto/gen/`.

**Generated artifacts** in `proto/gen/api/v1/` come in three flavors per service, which correspond to the three ways the API is exposed:

- `*_grpc.pb.go` — gRPC service interfaces, implemented by `APIV1Service` in `server/router/api/v1/`.
- `*.pb.gw.go` — grpc-gateway handlers that map JSON/REST requests onto those methods, registered via `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`).
- `apiv1connect/*.connect.go` — Connect protocol handlers, wired through `ConnectServiceHandler` (`server/router/api/v1/connect_services.go`) with the interceptors in `server/router/api/v1/connect_interceptors.go`.

**The closest thing to a published schema document** is OpenAPI, not GraphQL: `proto/gen/openapi.yaml` is generated from the same protos and embedded into the binary at `proto/openapi_embed.go`, exposed through `proto.OpenAPIYAML()`. The MCP server consumes exactly that spec (`server/router/mcp/service.go:78`).

**Non-Protobuf HTTP surfaces** exist alongside the API and are registered directly on Echo in `server/server.go`: the file server for attachments and avatars (`server/router/fileserver/`, routes at `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/`), the MCP endpoint (`server/router/mcp/`), and the frontend static/SSR handlers including `robots.txt` and `sitemap.xml` (`server/router/frontend/frontend.go`).
