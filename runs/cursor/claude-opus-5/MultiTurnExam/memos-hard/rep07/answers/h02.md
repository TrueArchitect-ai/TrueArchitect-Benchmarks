How it fits together:

- **Trigger:** memo changes call `webhook.PostAsync` from `server/router/api/v1/memo_service_webhooks.go:43` and `:71`. That enqueues onto a bounded 128-slot channel drained by four goroutines started in `init()` (`internal/webhook/webhook.go:39-55`); the queue drops (with a warning) rather than blocking when full.

- **Actual delivery:** `Post` marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and issues the request through `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. The response body is read through `io.LimitReader(resp.Body, 1<<20)`, and the client has a 30-second timeout.

- **Protection:** the guard is at *dial* time rather than only at URL-parse time, which is what defeats DNS rebinding — the address is re-resolved and checked immediately before connecting.

```59:77:internal/webhook/webhook.go
func safeDialContext(ctx context.Context, network, addr string) (net.Conn, error) {
	host, port, err := net.SplitHostPort(addr)
	if err != nil {
		return nil, errors.Errorf("webhook: invalid address %q", addr)
	}

	ips, err := net.DefaultResolver.LookupHost(ctx, host)
	...
	for _, ipStr := range ips {
		if ip := net.ParseIP(ipStr); ip != nil && isReservedIP(ip) {
			return nil, errors.Errorf("webhook: connection to reserved/private IP address is not allowed")
		}
	}
	return (&net.Dialer{}).DialContext(ctx, network, net.JoinHostPort(host, port))
}
```

The blocked ranges are loopback, RFC-1918 private, link-local (which covers the cloud metadata endpoint `169.254.169.254`), and the IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10` (`internal/webhook/validate.go:14-23`).

- **Second layer, at configuration time:** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http/https schemes and reserved-resolving hostnames when a user saves a webhook, called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, and `:182`.

- **Escape hatch:** the whole IP check is disabled when `webhook.AllowPrivateIPs` is true, set from the `allow-private-webhooks` config flag at `cmd/memos/main.go:49`, for self-hosters targeting LAN services.
