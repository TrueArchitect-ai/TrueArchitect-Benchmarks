**Premise correction: this project has no GraphQL API. There is no `.graphql`/`.gql` file, no `gqlgen` or other GraphQL dependency, and no occurrence of "graphql" anywhere in the Go, TypeScript, or config sources. The public API is defined by Protocol Buffers and served as REST (via grpc-gateway) plus Connect RPC.**

The actual API surface:

- **Schema source of truth:** eight proto service definitions under `proto/api/v1/` — `AIService` (`ai_service.proto:11`), `AttachmentService` (`attachment_service.proto:15`), `AuthService` (`auth_service.proto:13`), `IdentityProviderService` (`idp_service.proto:14`), `InstanceService` (`instance_service.proto:17`), `MemoService` (`memo_service.proto:17`), `ShortcutService` (`shortcut_service.proto:14`), and `UserService` (`user_service.proto:17`). Persistence-side messages live in `proto/store/`.
- **Code generation** is driven by `proto/buf.gen.yaml`, which runs protobuf-go, gRPC, Connect, grpc-gateway, and a gnostic OpenAPI plugin into `proto/gen`, plus protobuf-es into `web/src/types/proto` for the frontend. So the "schema" you'd hand to a client is the generated OpenAPI document (embedded via `proto/openapi_embed.go`), not a GraphQL SDL.
- **Runtime surfaces**, all registered in `server/router/api/v1/v1.go`:
  - REST/JSON under `/api/v1/*` through the grpc-gateway mux, with the eight `Register*HandlerServer` calls at `server/router/api/v1/v1.go:99-122` and the route bound at `:128`.
  - Connect RPC for browser clients under `/memos.api.v1.*` (`server/router/api/v1/v1.go:139-144`).
  - Server-sent events for live updates, registered at `server/router/api/v1/v1.go:125`.
  - Non-RPC HTTP routes outside the proto surface: file serving at `/file/*` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), the frontend/sitemap handlers (`server/router/frontend/frontend.go`), and an MCP endpoint that proxies the OpenAPI operations in-process (`server/router/mcp/service.go:26-52`).

All eight services are implemented by the single `APIV1Service` type, which embeds the generated `Unimplemented*Server` structs (`server/router/api/v1/v1.go:22-30`).
