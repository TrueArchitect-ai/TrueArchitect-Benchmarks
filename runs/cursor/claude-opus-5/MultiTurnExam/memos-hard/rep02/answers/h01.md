The S3 presign runner keeps S3-backed attachment links fresh by re-signing their presigned URLs.

**`s3presign.Runner` (`server/runner/s3presign/runner.go`) — once immediately at startup, then every 12 hours (re-signing only attachments whose last presign is older than 4 days, since URLs expire at 5 days) — wired in `server/server.go:162-171`, reached from `Server.Start` at `server/server.go:129`.**

Details:

- The runner is defined in `server/runner/s3presign/runner.go`. Its interval is a package constant:

```26:27:server/runner/s3presign/runner.go
// Schedule runner every 12 hours.
const runnerInterval = time.Hour * 12
```

- `Run` is a plain ticker loop that calls `RunOnce` → `CheckAndPresign`, which pages through attachments with `StorageType = AttachmentStorageType_S3` in batches of 100, skips any whose `LastPresignedTime` is within the last 4 days, then calls `s3Client.PresignGetObject` and writes the new URL back via `store.UpdateAttachment` (updating `Reference` and `LastPresignedTime`).

- Wiring happens in `Server.startBackgroundRunners`, which does a synchronous `RunOnce` first so links are fresh before traffic is served, then launches the ticker loop on a cancellable context tracked for graceful shutdown:

```161:171:server/server.go
	// Create and start S3 presign runner
	s3presignRunner := s3presign.NewRunner(s.Store)
	s3presignRunner.RunOnce(ctx)

	// Start continuous S3 presign runner
	s.backgroundRunnerWG.Add(1)
	go func() {
		defer s.backgroundRunnerWG.Done()
		s3presignRunner.Run(s3Context)
		slog.Info("s3presign runner stopped")
	}()
```

`startBackgroundRunners` is invoked at the end of `Server.Start` (`server/server.go:129`), just after the HTTP server begins serving, and the corresponding cancel is invoked from `stopBackgroundRunners` during `Shutdown`.
