**r05.**

There is no GraphQL in this project. Searching the entire repository (excluding `node_modules` and `.git`) for "graphql"/"gqlgen" returns zero matches, there are no `.graphql` or `.gql` files, and `go.mod` has no GraphQL dependency. So there is no GraphQL schema to locate — the premise is false.

**Actual API surface: Protobuf/gRPC service definitions, exposed over HTTP three ways.**

The schema of record is the `.proto` files in `proto/api/v1/`:

| File | Service |
| --- | --- |
| `proto/api/v1/memo_service.proto` | MemoService |
| `proto/api/v1/user_service.proto` | UserService |
| `proto/api/v1/attachment_service.proto` | AttachmentService |
| `proto/api/v1/auth_service.proto` | AuthService |
| `proto/api/v1/instance_service.proto` | InstanceService |
| `proto/api/v1/idp_service.proto` | IdentityProviderService |
| `proto/api/v1/shortcut_service.proto` | ShortcutService |
| `proto/api/v1/ai_service.proto` | AIService |
| `proto/api/v1/common.proto` | shared types |

Code generation is driven by buf (`proto/buf.gen.yaml`) into `proto/gen/`, producing Go protobuf, gRPC, Connect, and grpc-gateway stubs plus TypeScript types for the web client.

The three HTTP surfaces are all registered in `RegisterGateway` (`server/router/api/v1/v1.go:65`):

1. **REST via grpc-gateway** — all eight services are registered on a `runtime.NewServeMux` (`server/router/api/v1/v1.go:96-122`) and mounted at `/api/v1/*` (`v1.go:128`). This is the closest thing to the "public API."
2. **Connect RPC** for browser clients (replacing grpc-web), mounted at `/memos.api.v1.*` (`v1.go:143`).
3. **Server-Sent Events** for push, registered alongside at `v1.go:124`.

Instead of a GraphQL schema, the machine-readable API description is an **OpenAPI spec** generated from the protos by the gnostic-openapi plugin into `proto/gen/openapi.yaml` and embedded in the binary via `proto/openapi_embed.go:5-11`. It's consumed at runtime by the MCP service, which unmarshals it to build its tool catalog (`server/router/mcp/service.go:78`).

Non-gRPC HTTP surfaces also exist outside the proto definitions: the file server at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), the SPA/static frontend (`server/router/frontend/frontend.go`), MCP (`server/router/mcp/service.go`), and `/healthz` (`server/server.go:67`).
