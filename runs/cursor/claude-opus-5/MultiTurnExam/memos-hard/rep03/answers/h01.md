The S3 presign runner (`s3presign.Runner`, defined in `server/runner/s3presign/runner.go`) keeps S3-backed attachment links fresh by re-presigning their GET URLs. It runs once immediately at startup and then every 12 hours, and it's wired up in `Server.startBackgroundRunners`, which `Server.Start` calls after the HTTP server goroutine begins serving.

// Schedule runner every 12 hours.
const runnerInterval = time.Hour * 12

func (r *Runner) Run(ctx context.Context) {
	ticker := time.NewTicker(runnerInterval)
	defer ticker.Stop()

	for {
		select {
		case <-ticker.C:
			r.RunOnce(ctx)
		case <-ctx.Done():
			return
		}
	}
}

- Why 12 hours works: presigned URLs are issued with a 5-day expiration (`internal/storage/s3/s3.go:71-84`), and each pass skips any attachment whose `LastPresignedTime` is still within 4 days, so URLs are refreshed with roughly a day of margin (`server/runner/s3presign/runner.go:85-91`). Refreshed URLs are written back to the attachment's `Reference` field along with the new `LastPresignedTime` (`server/runner/s3presign/runner.go:114-123`). The runner walks S3-storage attachments in batches of 100 (`server/runner/s3presign/runner.go:55-65`).
