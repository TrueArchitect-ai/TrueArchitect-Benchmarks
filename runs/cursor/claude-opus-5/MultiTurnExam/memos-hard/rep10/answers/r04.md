**Premise correction: neither. There is no message broker in this codebase — no NATS, no RabbitMQ, no AMQP, Kafka, or any other queue system.** A case-insensitive search across all Go sources and `go.mod` for `nats`, `rabbitmq`, `amqp`, `kafka`, `pubsub`, and `sqs` returns zero hits. There is no queue declaration to point at, because nothing external is involved.

**The actual mechanism: an in-process buffered Go channel with a fixed worker pool.** It lives entirely in `internal/webhook/webhook.go`.

The "queue" is a package-level channel with 128 slots:

```39:39:internal/webhook/webhook.go
	asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

The "workers" are four goroutines started in the package's `init()`, each looping over that channel and calling `Post`, logging a warning on failure:

```42:55:internal/webhook/webhook.go
func init() {
	for range 4 {
		go func() {
			for payload := range asyncPostQueue {
				if err := Post(payload); err != nil {
					slog.Warn("Failed to dispatch webhook asynchronously",
						slog.String("url", payload.URL),
						slog.String("activityType", payload.ActivityType),
						slog.Any("err", err))
				}
			}
		}()
	}
}
```

Producers call `PostAsync` (`internal/webhook/webhook.go:184`), which is a non-blocking enqueue: a `select` with a `default` branch that **drops the payload** and logs a warning when the buffer is full. Callers are the memo webhook dispatchers at `server/router/api/v1/memo_service_webhooks.go:43` and `:71`.

Some consequences worth being explicit about, since they differ sharply from broker-backed delivery:

- **No durability.** The queue is process memory. A restart or crash loses everything still buffered, and there is no acknowledgement or redelivery.
- **No retries.** `Post` returns an error and the worker only logs it; a failed webhook is simply gone.
- **Backpressure is loss, not blocking.** Exceeding 128 queued payloads silently discards new ones.
- **Not shared across instances.** Each server process has its own channel and its own four workers, created by `init()` whenever the package is linked in.
