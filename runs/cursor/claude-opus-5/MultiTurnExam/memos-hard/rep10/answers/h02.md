Details:

- **Delivery path.** Memo create/update/delete events call `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43` and `:71`), which just enqueues onto a bounded 128-slot channel drained by four worker goroutines started in `init()` (`internal/webhook/webhook.go:39-55`). Those workers call `Post`, so `Post` is where the outbound request is built (JSON body, optional Standard Webhooks HMAC-SHA256 headers) and executed:

```152:156:internal/webhook/webhook.go
	resp, err := safeClient.Do(req)
	if err != nil {

```

- **Primary protection (dial time).** All dispatches share `safeClient`, whose `Transport.DialContext` is `safeDialContext`. It resolves the hostname itself and refuses to dial if any resolved address is in a reserved range, which is what makes it resistant to DNS rebinding — the check happens on the same resolution path as the connection, not earlier:

```70:76:internal/webhook/webhook.go
	for _, ipStr := range ips {
		if ip := net.ParseIP(ipStr); ip != nil && isReservedIP(ip) {
			return nil, errors.Errorf("webhook: connection to reserved/private IP address is not allowed")
		}
	}

	return (&net.Dialer{}).DialContext(ctx, network, net.JoinHostPort(host, port))
```

- **Blocklist.** `isReservedIP` tests against `reservedNetworks`, parsed once at startup from `reservedCIDRs` in `internal/webhook/validate.go:14-23`: IPv4 loopback, the three RFC-1918 ranges, link-local `169.254.0.0/16` (explicitly covering the cloud metadata endpoint `169.254.169.254`), plus IPv6 `::1/128`, `fc00::/7`, and `fe80::/10`.

- **Secondary check at configuration time.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and reserved-IP targets when a user saves a webhook, called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, and `:182`. This is a usability guard that gives an `InvalidArgument` error early; the dialer is what actually enforces it at send time.

- **Escape hatch.** The whole thing can be disabled for self-hosted setups via the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`), which short-circuits `isReservedIP`. It is set from the `allow-private-webhooks` config option in `cmd/memos/main.go:49`.
