**Premise correction: this project has no GraphQL. There is no schema file, no resolver code, and no GraphQL dependency** — a search across the Go sources, `go.mod`, and any `.graphql` files returns zero hits.

**The actual API surface is Protobuf-defined gRPC, exposed over three HTTP-facing layers plus a few native handlers.**

The schema of record is the `.proto` files in `proto/api/v1/`, which declare eight services:

| Service | File |
| --- | --- |
| `AIService` | `proto/api/v1/ai_service.proto:11` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `UserService` | `proto/api/v1/user_service.proto:17` |

Code generation is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`), emitting Go types, gRPC stubs, gRPC-Gateway bindings, and Connect handlers into `proto/gen/api/v1/` (including `proto/gen/api/v1/apiv1connect/`). A companion `proto/gen/apidocs.swagger.yaml`-style artifact exists as `proto/gen/openapi.yaml`, embedded into the binary via `proto/openapi_embed.go`.

All of these are implemented by a single `APIV1Service` (`server/router/api/v1/v1.go:26`), which is wired into Echo by `RegisterGateway` (`server/router/api/v1/v1.go:65`), called from `server/server.go:88`. That gives clients REST-style JSON via the gRPC-Gateway and Connect-protocol endpoints via `ConnectServiceHandler` (`server/router/api/v1/connect_services.go`).

Alongside the generated API there are hand-written HTTP surfaces that are not part of the proto schema:

- Binary file serving at `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`)
- RSS feeds (`server/router/rss/rss.go`, registered at `server/server.go:85`)
- Server-sent events via the SSE hub, registered as part of `RegisterGateway`
- The frontend static file server (`server/router/frontend/frontend.go`) and `/healthz` (`server/server.go:67`)
- An MCP endpoint (`server/router/mcp/`, created at `server/server.go:92`) that re-exposes the same API to model clients using the embedded OpenAPI document
