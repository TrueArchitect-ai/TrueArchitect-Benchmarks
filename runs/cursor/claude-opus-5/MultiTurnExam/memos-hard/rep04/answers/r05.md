**Premise correction: there is no GraphQL in this repository. No `.graphql`/`.gql` schema files exist, no GraphQL library appears in `go.mod`, and searching the Go, TypeScript, and JSON sources for "graphql" returns zero matches. There is no GraphQL schema to locate.**

The actual public API surface is Protobuf-defined gRPC, exposed over HTTP:

- **Schema of record: `.proto` files in `proto/api/v1/`** — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, and `common.proto`. Each RPC carries a `google.api.http` annotation that defines its REST binding, e.g. `CreateMemo` maps to `POST /api/v1/memos` and `ListMemos` to `GET /api/v1/memos` (`proto/api/v1/memo_service.proto:17`–`30`).
- **Generated Go bindings** live in `proto/gen/api/v1/` (including the `*.pb.gw.go` gRPC-Gateway files), produced via buf (`proto/buf.gen.yaml`).
- **HTTP exposure** is set up by `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`), called from `NewServer` at `server/server.go:88`. Both a gRPC-Gateway mux and Connect handlers are registered (`server/router/api/v1/connect_handler.go`, `connect_services.go`), so clients can use REST/JSON or Connect/gRPC against the same service definitions.
- **The machine-readable spec is OpenAPI, not a GraphQL SDL**: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go:5` and served through `proto.OpenAPIYAML()`.
- Additional non-gRPC surfaces exist alongside it: raw HTTP file serving at `/file/...` (`server/router/fileserver/fileserver.go:121`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/service.go`), and a `/healthz` check (`server/server.go:67`).
