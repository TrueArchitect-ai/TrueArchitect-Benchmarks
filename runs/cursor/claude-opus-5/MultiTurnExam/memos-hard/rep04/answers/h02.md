**`webhook.Post` — `internal/webhook/webhook.go:120` (the actual `safeClient.Do(req)` at `internal/webhook/webhook.go:152`); protection is dial-time SSRF blocking via `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`.**

How it fits together:

- Memo create/update/delete and comment-created events call `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43` and `:71`), which just enqueues onto a bounded 128-slot channel. Four worker goroutines started in `init()` drain that queue and call `Post` (`internal/webhook/webhook.go:39`–`55`), so `Post` is where the outbound HTTP request actually executes: it marshals the JSON body, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), then does `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.
- The primary protection is at the transport layer: `safeClient` is an `http.Client` whose `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32`–`37`). `safeDialContext` resolves the hostname itself and refuses to dial if *any* resolved address is in a reserved range, which is what makes it resistant to DNS rebinding — the check happens at connect time, not just at save time (`internal/webhook/webhook.go:59`–`77`).
- The blocklist lives in `internal/webhook/validate.go:14`–`23`: IPv4 loopback, the three RFC-1918 ranges, `169.254.0.0/16` (covers cloud IMDS at 169.254.169.254), plus IPv6 `::1/128`, `fc00::/7`, and `fe80::/10`. These are parsed once into `reservedNetworks` in an `init()` that panics on a bad CIDR.
- There's a second, earlier layer at the API boundary: `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and hostnames resolving to reserved IPs when a user creates or updates a webhook, called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, and `:182`.
- Both layers share an escape hatch: `webhook.AllowPrivateIPs` short-circuits `isReservedIP` to `false`, and it's set from the `allow-private-webhooks` config flag at `cmd/memos/main.go:49` for self-hosted setups targeting LAN services.
