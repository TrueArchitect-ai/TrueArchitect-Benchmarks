**Delivery function: `webhook.Post` — `internal/webhook/webhook.go:120`; protection: an SSRF-blocking dialer, `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`.**

Where delivery executes: `Post` marshals the payload, builds the POST request, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and issues the request via `safeClient.Do` at `internal/webhook/webhook.go:152`. Callers don't invoke it directly in the request path — `memo_service_webhooks.go:43` and `:71` call `webhook.PostAsync`, which enqueues onto a bounded 128-slot channel (`internal/webhook/webhook.go:184`) drained by four worker goroutines started in `init` (lines 42-55); those workers are what actually call `Post`.

What protects it: the shared `safeClient` (`internal/webhook/webhook.go:32`) installs `safeDialContext` as its `Transport.DialContext`. On every dial it resolves the hostname itself and rejects the connection if any resolved address falls in a reserved range. Doing the check at dial time rather than only at configuration time is what defeats DNS rebinding, since a hostname that passed validation earlier is re-resolved and re-checked on each request. The blocked ranges are the `reservedCIDRs` list in `internal/webhook/validate.go:14-23`: IPv4 loopback, the three RFC-1918 blocks, link-local `169.254.0.0/16` (which covers the cloud metadata endpoint at 169.254.169.254), and the IPv6 loopback, unique-local, and link-local equivalents.

Two related notes: there's a second, earlier layer — `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and reserved-IP targets when a user saves a webhook, called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, and `:182`. And the whole protection can be intentionally switched off by the `AllowPrivateIPs` global (`internal/webhook/validate.go:41`), which short-circuits `isReservedIP`; it's set from the `allow-private-webhooks` config option at `cmd/memos/main.go:49` for self-hosted setups that need to reach services on their own network.
