This is the placeholder-binding helper in the CEL-filter-to-SQL renderer: it appends a value to `r.args`, bumps the placeholder counter, and returns the dialect-appropriate placeholder token (`$N` for Postgres, `?` otherwise). Essentially every branch of the renderer that emits a bound value has to route through it, which is why the fan-in is so concentrated.
