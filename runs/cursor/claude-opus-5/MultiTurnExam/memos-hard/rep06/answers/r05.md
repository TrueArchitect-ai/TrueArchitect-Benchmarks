**Premise correction: there is no GraphQL in this repository.** Searches for `graphql`, `gqlgen`, `graphiql`, and `apollo` across Go sources return nothing; there are no `.graphql`/`.gql`/`.graphqls` files; `go.mod` has no GraphQL dependency; and `web/package.json` contains no GraphQL client (no Apollo, urql, or Relay). So there is no schema file to point to.

**Actual API surface: Protocol Buffers definitions compiled into a Connect RPC + gRPC-Gateway (REST) pair.** The schema equivalent is the `.proto` files in `proto/api/v1`: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, and `user_service.proto`. Storage-side messages live in `proto/store`, code generation is driven by `proto/buf.gen.yaml` and `proto/buf.yaml`, and the generated Go lands in `proto/gen` (including Connect stubs under `proto/gen/api/v1/apiv1connect`).

The same service implementations are exposed over two protocols, both wired in `RegisterGateway` (`server/router/api/v1/v1.go`):

- **REST/JSON via gRPC-Gateway**, mounted at `/api/v1/*` and `/file/*` (lines 128-129), with handlers registered per service at lines 111-122 and a body cap applied through `http.MaxBytesHandler`.
- **Connect RPC** for browser clients, replacing grpc-web, mounted on the path prefix `/memos.api.v1.*` (line 144) with interceptors for metadata, logging, recovery, and auth (lines 133-138).

There is also an OpenAPI artifact (`proto/openapi_embed.go`) generated from the same protos, which is the closest analogue to a queryable schema document.

Beyond the RPC surface, the server exposes several non-RPC HTTP surfaces registered in `server/server.go`: static file serving for attachments and avatars under `/file` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), server-side-rendered frontend routes (`server/router/frontend`), Server-Sent Events for live updates (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`), an MCP endpoint (`server/router/mcp`), and a `/healthz` check (`server/server.go:67`).
