**`webhook.Post` — `internal/webhook/webhook.go:120`; a custom `DialContext` hook (`safeDialContext`) on the shared HTTP client that rejects reserved/private IPs, backed by `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`**

Delivery: the actual outbound HTTP request is issued by `Post` in `internal/webhook/webhook.go`, which marshals the payload to JSON, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`), and calls `safeClient.Do(req)` at line 152. Callers normally go through `PostAsync` (line 184), which enqueues onto a 128-slot buffered channel drained by 4 worker goroutines started in `init` (lines 42-55); those workers are what invoke `Post`. The API-layer triggers are in `server/router/api/v1/memo_service_webhooks.go`, which fans out per registered user webhook on memo created/updated/deleted and comment-created events (lines 43 and 71).

Protection: there are two layers, and the load-bearing one is at dial time.

- The enforcing layer is `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the `DialContext` of the package-level `safeClient` transport (lines 32-37). It splits host/port, resolves the hostname via `net.DefaultResolver.LookupHost`, and fails the connection if *any* resolved address satisfies `isReservedIP`. Because the check happens on the resolved IP at connection time rather than on the URL string, it also defeats DNS rebinding — a hostname that passed validation at registration but later resolves to an internal address still gets refused.
- The advisory layer is `webhook.ValidateURL` (`internal/webhook/validate.go:62`), called when a user creates or updates a webhook in `server/router/api/v1/user_service_webhooks.go` (lines 74, 161, 182). It requires an absolute `http`/`https` URL and rejects hostnames resolving into reserved ranges, returning a gRPC `InvalidArgument` so bad URLs are caught up front.

The blocklist itself is `reservedCIDRs` in `internal/webhook/validate.go:14-23`: IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (explicitly covering the cloud metadata endpoint at `169.254.169.254`), plus IPv6 `::1/128`, `fc00::/7`, and `fe80::/10`. These are parsed once into `reservedNetworks` in an `init` that panics on a malformed entry.

One caveat worth flagging: the whole mechanism is defeatable by configuration. `isReservedIP` returns `false` immediately when the package-level `AllowPrivateIPs` flag is set (`internal/webhook/validate.go:45-47`), and that flag is bound to the `allow-private-webhooks` option at `cmd/memos/main.go:49`. Enabling it disables both the dial-time guard and the registration-time validation, which is intended for self-hosted setups targeting LAN services.
