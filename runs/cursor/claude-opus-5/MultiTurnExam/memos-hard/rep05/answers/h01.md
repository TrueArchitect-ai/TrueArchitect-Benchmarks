The S3 presign runner (`s3presign.Runner`, defined in `server/runner/s3presign/runner.go`) is what keeps S3-backed attachment links fresh. It re-presigns GET URLs for every attachment whose storage type is S3 and writes the new URL back into the attachment's `Reference` field, stamping `LastPresignedTime` in the payload. It walks attachments in batches of 100 and skips any whose presigned URL is still valid for at least the next 4 days (URLs are issued with a 5-day expiration), so each pass only refreshes what's close to going stale.
