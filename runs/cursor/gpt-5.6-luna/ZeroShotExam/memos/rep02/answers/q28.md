s3presign runner — started by `Server.Start`; runs immediately once, then on a 12-hour `time.Ticker` (`server/server.go`, `server/runner/s3presign/runner.go`).

Unused scheduling infrastructure — `internal/scheduler` provides cron scheduling, but the server never constructs, registers, or starts a `scheduler.Scheduler`. The `memopayload` runner is also not background-started; it is invoked synchronously by memo API operations (`server/router/api/v1/memo_service.go`).
