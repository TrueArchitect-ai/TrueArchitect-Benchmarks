s3presign runner — starts in `server/server.go`; runs once immediately, then every 12 hours via a `time.Ticker` in `server/runner/s3presign/runner.go`. Cancellation is driven by server shutdown.

Unused infrastructure — `internal/scheduler` provides cron scheduling but is never instantiated or started by the server. `server/runner/memopayload` is also not started as a background runner; its payload rebuild function is invoked synchronously by API requests (`server/router/api/v1/memo_service.go`).
