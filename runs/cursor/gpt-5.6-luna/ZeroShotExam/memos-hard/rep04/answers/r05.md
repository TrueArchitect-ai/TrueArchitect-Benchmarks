Premise correction: There is no GraphQL schema; this repository’s public API is defined with Protocol Buffers.

Actual API surface: service definitions and HTTP routes are in `proto/api/v1/*.proto` (for example, `memo_service.proto`), with the generated REST/OpenAPI surface in `proto/gen/openapi.yaml`. Implementations are registered under `server/router/api/v1/`, including Connect services in `connect_handler.go`.
