Premise correction: This repository does not define a GraphQL schema; it has no GraphQL API surface.

Actual API surface: The public API is defined as Protocol Buffer services in `proto/api/v1/` (for example, `memo_service.proto` and `instance_service.proto`). It is exposed through gRPC-Gateway/REST and Connect handlers in `server/router/api/v1/v1.go` and `server/router/api/v1/connect_handler.go`. The generated REST schema is `proto/gen/openapi.yaml`.
