Premise correction: This repository has no GraphQL schema. Its documented API is REST and gRPC (`README.md`).

Actual API surface: The source of truth is the Protocol Buffers definitions in `proto/api/v1/*.proto`, which generate:
- REST endpoints under `/api/v1/*` via gRPC-Gateway (`server/router/api/v1/v1.go`)
- gRPC/Connect services under `/memos.api.v1.*` (`server/router/api/v1/v1.go`)
- OpenAPI specification at `proto/gen/openapi.yaml`, generated by `proto/buf.gen.yaml`
