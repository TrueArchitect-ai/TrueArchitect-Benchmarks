Premise correction: no per-user API rate-limiting middleware is registered in this repository. `server/server.go` registers only recovery and CORS middleware, while `server/router/api/v1/v1.go` registers authentication middleware.

Therefore, there are no per-user request limits. The API only has a 256 MiB body-size limit in `server/router/api/v1/v1.go` (`maxAPIRequestBytes`), which is not rate limiting.
