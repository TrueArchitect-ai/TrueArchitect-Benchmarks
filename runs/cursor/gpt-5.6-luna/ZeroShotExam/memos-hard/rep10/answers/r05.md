Premise correction: This repository has no GraphQL schema. Its public API is defined in Protocol Buffers under `proto/api/v1/`, including service files such as `memo_service.proto` and `auth_service.proto`.

Actual API surface: The `.proto` files define Connect RPC/gRPC services and REST routes via `google.api.http` annotations; the gateway is registered in `server/server.go`. OpenAPI and TypeScript clients are generated from these definitions using `proto/buf.gen.yaml`.
