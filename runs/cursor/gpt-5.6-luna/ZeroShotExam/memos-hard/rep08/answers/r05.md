Premise correction: No GraphQL schema is defined in this repository. The public API uses Protocol Buffers with Connect/gRPC and REST mappings.

Actual API surface: Source definitions are in `proto/api/v1/*.proto`, with HTTP routes declared via `google.api.http` options, e.g. `proto/api/v1/memo_service.proto:17-147` and `proto/api/v1/user_service.proto:17-201`. The generated REST/OpenAPI surface is `proto/gen/openapi.yaml`; handlers are wired under `server/router/api/v1/`.
