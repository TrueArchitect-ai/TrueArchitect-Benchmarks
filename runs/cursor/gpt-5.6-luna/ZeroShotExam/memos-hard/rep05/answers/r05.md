Premise correction: This repository does not define a GraphQL schema. Its public API is defined as Protocol Buffers in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto`).

Actual API surface: Those service definitions expose gRPC/Connect endpoints and REST routes via HTTP annotations; the generated REST specification is `proto/gen/openapi.yaml`, embedded by `proto/openapi_embed.go`. Handlers are under `server/router/api/v1/`.
