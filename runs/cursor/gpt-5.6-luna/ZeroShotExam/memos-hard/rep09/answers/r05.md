Premise correction: There is no GraphQL schema in this repository. The public API is defined as Protocol Buffers under `proto/api/v1/*.proto`, with services such as `MemoService` in `proto/api/v1/memo_service.proto`.

Actual API surface: those protobuf definitions generate and expose:
- REST/JSON endpoints under `/api/v1/*` via gRPC-Gateway (`server/router/api/v1/v1.go`)
- Connect RPC endpoints under `/memos.api.v1.*` (`server/router/api/v1/connect_handler.go`)
- Anonymous/public method access controlled by `server/router/api/v1/acl_config.go`
