q25.

The ListMemos RPC accepts a CEL (Common Expression Language) filter expression.

**Engine + Path:** `cel-go` (from `github.com/google/cel-go/cel`); lives in `/bench/repo/internal/filter/engine.go`

**Mechanism in one sentence:** The CEL filter is parsed by `cel-go` into a language-agnostic intermediate representation (condition tree) in `parser.go`, then the `renderer` in `render.go` converts that tree into dialect-specific SQL (SQLite, PostgreSQL, or MySQL) using the appropriate operators and functions for each database.

**Details:**
- Proto definition with CEL syntax: `/bench/repo/proto/api/v1/memo_service.proto` lines 326-339
- Parser: `/bench/repo/internal/filter/parser.go` - converts CEL AST to condition objects
- Renderer: `/bench/repo/internal/filter/render.go` - renders conditions to dialect-specific SQL for DialectSQLite, DialectPostgres, DialectMySQL
- Helper that applies filters: `/bench/repo/internal/filter/helpers.go` - `AppendConditions()` function
- Usage in ListMemos: `/bench/repo/server/router/api/v1/memo_service.go`
