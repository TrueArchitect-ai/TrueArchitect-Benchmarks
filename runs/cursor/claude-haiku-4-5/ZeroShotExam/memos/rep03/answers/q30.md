**Where They Converge:**

All four dispatch functions converge at the `webhook.PostAsync()` function located in `/bench/repo/internal/webhook/webhook.go` (lines 183-196). This is the single delivery function where all memo-related webhook payloads are enqueued for asynchronous dispatch to registered webhook endpoints.

The dispatch flow:
- Each event handler calls its respective `DispatchMemo*Webhook` function
- Those functions call `dispatchMemoRelatedWebhook()` or directly create payloads for comment webhooks
- All payloads are queued via `webhook.PostAsync()` which enqueues them into a bounded asynchronous queue
- Four background goroutines process the queue and call `webhook.Post()` to deliver the webhooks
