The ConnectRPC service clients are created in **`web/src/connect.ts`**. This file uses the `createClient` function from `@connectrpc/connect` (imported on line 2) to create multiple service clients, including:

- `instanceServiceClient` (line 192)
- `authServiceClient` (line 193)
- `userServiceClient` (line 194)
- `memoServiceClient` (line 197)
- `attachmentServiceClient` (line 198)
- `aiServiceClient` (line 199)
- `shortcutServiceClient` (line 200)
- `identityProviderServiceClient` (line 203)

All these clients are created with a shared `transport` that's configured with authentication interceptor support.
