Based on the repository structure, this project ships migrations for the following SQL dialects:

**MySQL, PostgreSQL, SQLite**

These are located in `/bench/repo/store/migration/` with separate subdirectories for each dialect:
- `/bench/repo/store/migration/mysql/`
- `/bench/repo/store/migration/postgres/`
- `/bench/repo/store/migration/sqlite/`

Each dialect directory contains version-specific migration files (e.g., 0.17, 0.18, 0.19, etc.).
