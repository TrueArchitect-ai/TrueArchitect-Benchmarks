**Token kinds:** The system manages three token types:
1. **Access tokens** (short-lived, 15 minutes) - used for API requests, sent in `Authorization` header as Bearer tokens
2. **Refresh tokens** (long-lived, 30 days) - stored in cookies, used to obtain new access tokens
3. **Personal Access Tokens (PATs)** (long-lived) - for programmatic access

The auth package (`server/auth`) validates tokens through multiple authentication methods:
- `AuthenticateByAccessTokenV2()` for access tokens (stateless JWT validation)
- `AuthenticateByRefreshToken()` for refresh tokens (with database revocation checking)
- `AuthenticateByPersonalAccessToken()` for PAT tokens (database lookup)
