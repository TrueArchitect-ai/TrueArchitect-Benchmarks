When a memo is deleted through the API, the store layer deletes the following kinds of records before the memo row itself (as shown in `/bench/repo/store/memo.go` lines 140-159):

1. **Memo relations** (where the memo is the source) - deleted via `DeleteMemoRelation(ctx, &DeleteMemoRelation{MemoID: &delete.ID})`
2. **Memo relations** (where the memo is the target) - deleted via `DeleteMemoRelation(ctx, &DeleteMemoRelation{RelatedMemoID: &delete.ID})`
3. **Attachments** - deleted via iterating through attachments found by `ListAttachments(ctx, &FindAttachment{MemoID: &delete.ID})` and calling `DeleteAttachment` for each

Finally, the memo row itself is deleted via `s.driver.DeleteMemo(ctx, delete)`.
