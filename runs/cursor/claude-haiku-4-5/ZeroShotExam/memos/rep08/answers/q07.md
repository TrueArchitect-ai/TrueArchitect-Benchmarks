**`web/src/connect.ts`**

This file contains all the ConnectRPC service client creation calls. It imports `createClient` from `@connectrpc/connect` and creates multiple service clients including `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`.
