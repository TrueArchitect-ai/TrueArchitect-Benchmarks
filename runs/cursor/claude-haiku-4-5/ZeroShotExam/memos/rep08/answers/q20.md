q20.

The server uses **Server-Sent Events (SSE)** to push live events to browsers.

**Hub implementation path:** `/bench/repo/server/router/api/v1/sse_hub.go`

**Memo handlers that broadcast through the SSEHub:**

1. `CreateMemo` - broadcasts `SSEEventMemoCreated` event
2. `UpdateMemo` - calls `dispatchMemoUpdatedSideEffects()` which broadcasts `SSEEventMemoUpdated` event
3. `DeleteMemo` - broadcasts `SSEEventMemoDeleted` event  
4. `CreateMemoComment` - broadcasts `SSEEventMemoCommentCreated` event
5. `UpsertMemoReaction` - broadcasts `SSEEventReactionUpserted` event
6. `DeleteMemoReaction` - broadcasts `SSEEventReactionDeleted` event
