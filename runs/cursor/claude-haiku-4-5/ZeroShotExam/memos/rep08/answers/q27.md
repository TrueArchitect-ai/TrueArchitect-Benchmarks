**Answer:**

**Mechanism:** Go embed directive with Echo static middleware

**Path:** `/bench/repo/server/router/frontend/frontend.go`

**Explanation:** The compiled React frontend gets served in production using Go's embed package. At line 20 of `frontend.go`, the directive `//go:embed dist/*` embeds all compiled frontend files from the `dist` directory into the binary. The `FrontendService.Serve` method (line 41) then registers this embedded filesystem with Echo's static middleware (lines 54-57) to serve the frontend files. The service is wired in `/bench/repo/server/server.go` at line 72 where `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` is called during server initialization.
