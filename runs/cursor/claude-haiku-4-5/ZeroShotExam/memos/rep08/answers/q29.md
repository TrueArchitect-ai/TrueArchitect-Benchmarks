q29.

**Interceptor path:** `web/src/connect.ts` (contains the `authInterceptor`)

**Token kinds:** 
1. Access Token (JWT V2) - short-lived tokens (15 minutes) managed as bearer tokens
2. Refresh Token - long-lived tokens (30 days) stored as HTTP-only cookies

**Backend package path:** `server/auth`

The auth interceptor in `web/src/connect.ts` (lines 156-178) validates and manages both access tokens and refresh tokens. It automatically includes the access token in the `Authorization: Bearer {token}` header for API requests, and handles token refresh when 401 responses occur. The backend `server/auth` package (specifically `authenticator.go`) validates these tokens via the `AuthenticateByAccessTokenV2` method and can also validate Personal Access Tokens (PAT) and refresh tokens.
