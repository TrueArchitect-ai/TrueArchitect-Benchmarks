The database table that stores links between one memo and another related memo is **`memo_relation`**.

This table is defined in `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql` and contains the following structure:
- `memo_id`: the ID of the memo
- `related_memo_id`: the ID of the related memo
- `type`: the type of relationship
- A unique constraint on the combination of all three columns to prevent duplicate relations
