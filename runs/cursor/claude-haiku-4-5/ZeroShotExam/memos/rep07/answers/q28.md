q28.

The server starts only one background worker/runner:

**s3presign runner** — Ticker-based scheduling: runs every 12 hours (time.Hour * 12), triggered by `time.NewTicker()`. Also runs once at startup via `RunOnce()`.

**Unused scheduling infrastructure:** The codebase contains a `scheduler` package (`/bench/repo/internal/scheduler/`) that provides a GitHub Actions-inspired cron job scheduler with support for 5-field and 6-field cron expressions, timezone-aware scheduling, middleware patterns, and graceful shutdown. However, this scheduler is NOT used by the server.
