The memo lifecycle events that dispatch webhooks and their dispatch function names are:

**Event: Dispatch Function**
- created: DispatchMemoCreatedWebhook
- updated: DispatchMemoUpdatedWebhook
- deleted: DispatchMemoDeletedWebhook
- comment.created: DispatchMemoCommentCreatedWebhook

**Delivery Convergence:**

All webhook dispatches converge at the `webhook.PostAsync()` function for asynchronous delivery. This function:
1. Enqueues the webhook payload into a bounded async queue (`asyncPostQueue`)
2. Four goroutines (spawned in `init()`) consume from this queue and call `Post()` for actual HTTP delivery

The delivery chain is:
- `webhook.PostAsync()` → enqueues to `asyncPostQueue` 
- Goroutines process queue → call `Post()`
- `Post()` performs the actual HTTP POST request with signature headers

**File locations:**
- Dispatch functions: `/bench/repo/server/router/api/v1/memo_service_webhooks.go` (lines 14-46)
- Delivery functions: `/bench/repo/internal/webhook/webhook.go` (PostAsync at lines 184-196, Post at lines 120-180)
