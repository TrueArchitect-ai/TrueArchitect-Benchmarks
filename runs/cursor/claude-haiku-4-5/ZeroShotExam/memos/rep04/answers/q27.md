**Mechanism:** Go's `embed` filesystem with Echo's `StaticWithConfig` middleware

**Path:** `server/router/frontend/frontend.go`

The compiled React frontend is served in production using Go's native `embed` package (line 20: `//go:embed dist/*`), which embeds the compiled frontend files built during the release process. The embedding happens in `server/router/frontend/frontend.go`, where the `FrontendService.Serve()` method registers the embedded filesystem with Echo's `StaticWithConfig` middleware (lines 54-57) to serve static assets and handle SPA routing with a fallback middleware that serves `index.html` for unknown routes.

The build process outputs the compiled React frontend to `../server/router/frontend/dist` (as specified in `web/package.json` line 11), which is then embedded at compile time and served by the Echo HTTP server in production.
