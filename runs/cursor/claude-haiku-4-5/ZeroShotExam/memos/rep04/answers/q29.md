**Interceptor path:** `/bench/repo/web/src/connect.ts` (defined as `authInterceptor` at lines 156-178)

**Token kinds:** 
- Access tokens (JWT, short-lived, 15 minutes)
- Refresh tokens (JWT, long-lived, 30 days)
- Personal Access Tokens (PAT) (for programmatic access)

**Backend package path:** `/bench/repo/server/auth` (the Authenticator package with token validation logic in `authenticator.go`, `token.go`, and `extract.go`)

The frontend auth interceptor in `connect.ts` sets Bearer tokens in the Authorization header using `Bearer ${token}` format. The backend `server/auth` package validates these tokens:
- **Access Token V2:** Validated stateless via signature in `ParseAccessTokenV2()` and `AuthenticateByAccessTokenV2()`
- **Refresh Token:** Validated against the database for revocation in `ParseRefreshToken()` and `AuthenticateByRefreshToken()`
- **Personal Access Token (PAT):** Validated against the database hash in `AuthenticateByPAT()`
