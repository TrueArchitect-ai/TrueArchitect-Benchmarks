For a fresh SQLite install, the single file that provides the complete current schema is:

`store/migration/sqlite/LATEST.sql`

This file contains all the CREATE TABLE statements and indexes needed to build the complete database schema from scratch. It includes definitions for all tables (system_setting, user, user_setting, memo, memo_relation, attachment, idp, inbox, reaction, memo_share, user_identity) and their associated indexes.
