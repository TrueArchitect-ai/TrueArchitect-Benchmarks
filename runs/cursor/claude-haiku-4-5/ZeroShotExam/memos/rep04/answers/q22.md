When a memo is created, user webhooks are notified through the following components:

**Dispatcher function and file:** `DispatchMemoCreatedWebhook` — `/bench/repo/server/router/api/v1/memo_service_webhooks.go` (called from the `CreateMemo` handler in `/bench/repo/server/router/api/v1/memo_service.go` at line 157)

**Delivery package:** `github.com/usememos/memos/internal/webhook` (specifically uses the `PostAsync` function for asynchronous dispatch)

**Request-signing mechanism:** HMAC-SHA256 with Standard Webhooks format - the signing secret is resolved, a message ID and timestamp are generated, and the signature is computed as base64-encoded HMAC-SHA256 of the concatenated msgID, timestamp, and request body, then sent in the `webhook-signature` header as `v1,<signature>` along with `webhook-id` and `webhook-timestamp` headers
