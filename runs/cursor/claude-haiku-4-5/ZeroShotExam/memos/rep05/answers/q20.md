The server uses **Server-Sent Events (SSE)** to push live events to browsers.

- **Mechanism**: Server-Sent Events (SSE) with text/event-stream protocol
- **Hub path**: `server/router/api/v1/sse_hub.go`
- **Handler names** (memo handlers that broadcast through the hub):
  - `CreateMemo`
  - `UpdateMemo`
  - `DeleteMemo`
  - `CreateMemoComment`
  - `UpsertMemoReaction`
  - `DeleteMemoReaction`

The SSEHub is implemented in `server/router/api/v1/sse_hub.go` and manages client connections via the `Subscribe` and `Unsubscribe` methods. Events are broadcast via the `Broadcast()` method which sends SSE events to all connected clients with visibility filtering (Private, Public, Protected). The SSE endpoint is registered at `/api/v1/sse` in `sse_handler.go` and uses Bearer token authentication.
