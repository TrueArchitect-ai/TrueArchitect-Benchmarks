The single file that provides the complete current schema for a fresh SQLite install is:

**`store/migration/sqlite/LATEST.sql`**

This file contains all the CREATE TABLE statements and indexes needed to set up a fresh SQLite database with the complete current schema, including tables for system_setting, user, user_setting, memo, memo_relation, attachment, idp, inbox, reaction, memo_share, and user_identity.
