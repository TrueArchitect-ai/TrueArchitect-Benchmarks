The frontend module that contains the memo CRUD mutations/queries is `web/src/hooks/useMemoQueries.ts`, and it uses the `MemoService` generated service client (created from the proto definition at `web/src/types/proto/api/v1/memo_service_pb.ts`).

The specific hooks exported include:
- `useMemos()` - query for listing memos
- `useInfiniteMemos()` - infinite query for memos
- `useMemo()` - query for getting a single memo
- `useCreateMemo()` - mutation for creating a memo
- `useUpdateMemo()` - mutation for updating a memo
- `useDeleteMemo()` - mutation for deleting a memo
- `useMemoComments()` and `useInfiniteMemoComments()` - queries for memo comments

All these use the `memoServiceClient` which is created from the `MemoService` class imported from `web/src/types/proto/api/v1/memo_service_pb.ts`.

**Answer:** `web/src/hooks/useMemoQueries.ts`; `MemoService`
