**Mechanism**: Go's `embed` directive combined with Echo's static file serving middleware

**Path**: `/bench/repo/server/router/frontend/frontend.go`

The mechanism works as follows:
1. The compiled React frontend (built assets from the `web/` directory) is embedded into the Go binary using the `//go:embed dist/*` directive at line 20 of `frontend.go`
2. This creates an `embed.FS` variable named `embeddedFiles` that contains all the compiled frontend files
3. In the `Serve` method (line 41), the embedded filesystem is served using Echo's `middleware.StaticWithConfig` middleware (line 54), which handles static asset serving
4. A SPA fallback middleware (line 59) ensures that unmatched routes serve `index.html`, allowing client-side routing to work properly
