The ListMemos RPC filter expression uses **CEL (Common Expression Language)** parsed by the `cel-go` library. The filter engine lives in `/bench/repo/internal/filter/` and converts CEL expressions into a dialect-agnostic intermediate representation (IR) which is then rendered into SQL fragments for each dialect (SQLite, MySQL, or Postgres) using `engine.CompileToStatement()` with the appropriate `filter.RenderOptions{Dialect}` parameter, which is invoked via the `filter.AppendConditions()` helper function in each database driver's `ListMemos` implementation.

**Engine + path:** CEL (Common Expression Language) parsed by `cel-go`; `/bench/repo/internal/filter/`

**Mechanism:** The filter is compiled to an intermediate representation (ir.go) by the parser, then rendered to SQL by the renderer (render.go) which handles dialect-specific syntax for each database.
