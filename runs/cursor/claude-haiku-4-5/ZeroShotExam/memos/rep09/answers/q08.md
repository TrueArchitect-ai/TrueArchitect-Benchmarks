q08. Driver — store/driver.go

The Go interface that all database backends implement is named `Driver`, and it is defined in `/bench/repo/store/driver.go`. All three database backends (SQLite, PostgreSQL, and MySQL) implement this interface, which contains methods for operations on attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, and user identities.
