q27. **Go embed with Echo's Static middleware**; `server/router/frontend/frontend.go`

The compiled React frontend gets served in production using **Go's `embed` package** combined with **Echo's `StaticWithConfig` middleware**.

Here's how it works:

1. **Build process**: The React frontend is compiled via the build script in `web/package.json` (line 11) which outputs to `../server/router/frontend/dist`

2. **Embedding mechanism**: In `server/router/frontend/frontend.go` (lines 20-21), the `dist` directory is embedded into the binary:
   ```
   //go:embed dist/*
   var embeddedFiles embed.FS
   ```

3. **Serving mechanism**: The `FrontendService.Serve()` method (lines 41-61) uses Echo's static middleware with the embedded filesystem:
   - Line 54-57: Configures `middleware.StaticWithConfig` to serve static assets from the embedded `dist` folder
   - Line 59: Adds a SPA fallback middleware that serves `index.html` for client-side routes

This allows the entire compiled React frontend to be embedded directly into the Go binary, eliminating the need for separate file serving in production.
