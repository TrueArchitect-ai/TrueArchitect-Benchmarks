q10.

The single file that provides the complete current schema for a fresh SQLite install is:

`store/migration/sqlite/LATEST.sql`

This file contains all the `CREATE TABLE` and `CREATE INDEX` statements needed to initialize a fresh SQLite database with the current schema. According to the codebase documentation and code comments in `store/migrator.go`, the migration flow explicitly states: "preMigrate: Check if DB is initialized. If not, apply LATEST.sql" and describes LATEST.sql as "Full schema for new installations (faster than incremental migrations)."
