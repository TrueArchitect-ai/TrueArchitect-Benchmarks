The ConnectRPC service clients are created in `/bench/repo/web/src/connect.ts`. 

The file uses `createClient()` from the `@connectrpc/connect` library to create service clients for various services including `InstanceService`, `AuthService`, `UserService`, `MemoService`, `AttachmentService`, `AIService`, `ShortcutService`, and `IdentityProviderService`. These clients are exported for use throughout the frontend application.
