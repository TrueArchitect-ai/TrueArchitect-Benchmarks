**Interceptor path:** `/bench/repo/web/src/connect.ts` (lines 156-178, specifically the `authInterceptor` constant)

**Token kinds:** The authentication interceptor manages two token types:
1. **Access tokens** (JWT) - Short-lived tokens (15 minutes) for API requests
2. **Refresh tokens** (JWT) - Long-lived tokens (30 days) for obtaining new access tokens via cookies

**Backend package path:** `/bench/repo/server/auth`

The backend auth package validates tokens through the `Authenticator` struct which provides:
- `AuthenticateByAccessTokenV2()` - validates short-lived access tokens (stateless JWT validation)
- `AuthenticateByRefreshToken()` - validates refresh tokens against the database for revocation checking
- `AuthenticateByPAT()` - validates Personal Access Tokens (additional third token type)

The interceptor uses `Bearer {token}` format in the Authorization header, which is extracted and validated by the backend's `ExtractBearerToken()` function in `/bench/repo/server/auth/extract.go`.
