q20.

**Mechanism:** Server-Sent Events (SSE)

**Hub Path:** `/bench/repo/server/router/api/v1/sse_hub.go`

**Memo Handler Names that Broadcast:**
1. `CreateMemo` (broadcasts `SSEEventMemoCreated`)
2. `UpdateMemo` via `dispatchMemoUpdatedSideEffects` (broadcasts `SSEEventMemoUpdated`)
3. `DeleteMemo` (broadcasts `SSEEventMemoDeleted`)
4. `CreateMemoComment` (broadcasts `SSEEventMemoCommentCreated`)
5. `UpsertMemoReaction` (broadcasts `SSEEventReactionUpserted`)
6. `DeleteMemoReaction` (broadcasts `SSEEventReactionDeleted`)

The hub is implemented as `SSEHub` in `/bench/repo/server/router/api/v1/sse_hub.go` and managed through the `APIV1Service` structure. The `Broadcast()` method sends events to all connected SSE clients, filtering based on visibility permissions (Private events only go to the creator or admins, while Public and Protected events are visible to all connected clients).
