The database table that stores links between one memo and another related memo is **`memo_relation`**.

This is defined in `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql`, which creates a table with columns for `memo_id`, `related_memo_id`, and `type`, allowing memos to be linked to each other with different relationship types.
