The memo lifecycle events that dispatch webhooks are:

- memo created: `DispatchMemoCreatedWebhook` (in `server/router/api/v1/memo_service_webhooks.go`)
- memo updated: `DispatchMemoUpdatedWebhook` (in `server/router/api/v1/memo_service_webhooks.go`)
- memo deleted: `DispatchMemoDeletedWebhook` (in `server/router/api/v1/memo_service_webhooks.go`)
- memo comment created: `DispatchMemoCommentCreatedWebhook` (in `server/router/api/v1/memo_service_webhooks.go`)

All of them converge for delivery at the `PostAsync` function in `internal/webhook/webhook.go`. This function enqueues webhook payloads to a channel-based async queue that is processed by 4 background goroutines, which call the `Post` function to actually deliver the webhook to the target URL.
