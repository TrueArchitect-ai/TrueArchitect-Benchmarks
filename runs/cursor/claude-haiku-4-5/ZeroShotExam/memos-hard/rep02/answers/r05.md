**Premise Correction:** The public API for this repository is not GraphQL—it is **gRPC and REST**.

**Actual API Surface:**

The public API schemas are defined in:

1. **Protobuf Definitions** (gRPC Service Definitions) - Located at `/bench/repo/proto/api/v1/`:
   - `memo_service.proto`
   - `user_service.proto`
   - `attachment_service.proto`
   - `auth_service.proto`
   - `instance_service.proto`
   - `ai_service.proto`
   - `idp_service.proto`
   - `shortcut_service.proto`
   - `common.proto`

2. **OpenAPI Specification** (REST API Gateway) - Generated from protobuf at `/bench/repo/proto/gen/openapi.yaml`
   - This is the authoritative specification for the REST gateway operations generated from protobuf definitions
   - Includes operation IDs, descriptions, parameters, request schemas, and response schemas

The README states the API provides "full REST and gRPC APIs for integration." The REST gateway is automatically generated from the protobuf definitions using the Google API annotations (`google.api.http`), which map gRPC services to HTTP endpoints.
