The `s3presign.Runner` component keeps presigned S3 attachment links fresh by refreshing them before they expire. It runs a `CheckAndPresign()` operation that:
- Lists all S3-stored attachments in batches of 100
- Checks if the last presigned time is more than 1 day old (given a 5-day presign expiration, it refreshes if less than 4 days remain)
- Regenerates presigned URLs for attachments that need refreshing
- Updates the attachment reference with the new presigned URL and timestamp
