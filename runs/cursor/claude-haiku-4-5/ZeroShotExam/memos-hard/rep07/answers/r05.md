**Premise correction:** This repository does not use GraphQL for its public API. The codebase uses gRPC/Connect RPC with Protocol Buffers, not GraphQL.

**Actual API surface:** The public API is defined through Protocol Buffer service definitions in `/bench/repo/proto/api/v1/`. The main service files are:

- `/bench/repo/proto/api/v1/memo_service.proto` - Memo operations
- `/bench/repo/proto/api/v1/user_service.proto` - User operations
- `/bench/repo/proto/api/v1/attachment_service.proto` - Attachment operations
- `/bench/repo/proto/api/v1/auth_service.proto` - Authentication services
- `/bench/repo/proto/api/v1/instance_service.proto` - Instance configuration
- `/bench/repo/proto/api/v1/ai_service.proto` - AI operations
- `/bench/repo/proto/api/v1/idp_service.proto` - Identity provider operations
- `/bench/repo/proto/api/v1/shortcut_service.proto` - Shortcut operations

These proto files are compiled to generate Go bindings, OpenAPI schema (`/bench/repo/proto/gen/openapi.yaml`), and TypeScript types. The API is served via Connect RPC and gRPC-Gateway, which provides a REST interface for the services.
