**Premise correction:** This repository does not have a GraphQL schema. The codebase does not use GraphQL for its public API.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with OpenAPI generation. The schema files are:

- **Proto schema files** (source definitions): `/bench/repo/proto/api/v1/` — Contains multiple `.proto` files including:
  - `memo_service.proto`
  - `attachment_service.proto`
  - `user_service.proto`
  - `auth_service.proto`
  - `ai_service.proto`
  - `idp_service.proto`
  - `shortcut_service.proto`
  - `instance_service.proto`
  - `common.proto`

- **Generated OpenAPI specification**: `/bench/repo/proto/gen/openapi.yaml` — Auto-generated from the proto files using `protoc-gen-openapi`, which provides a REST API specification.

The proto files use Google API annotations to define HTTP mappings (e.g., `post: "/api/v1/memos"`) that are converted to both gRPC and REST endpoints.
