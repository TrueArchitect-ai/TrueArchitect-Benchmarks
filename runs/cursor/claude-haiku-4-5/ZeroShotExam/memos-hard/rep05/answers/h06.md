**RPC Handlers** (3+ that can transitively cause outbound HTTP requests to user-configured URLs):

1. **`CreateMemo`** — calls `DispatchMemoCreatedWebhook` → `webhook.PostAsync` to user-configured webhook URLs
2. **`UpdateMemo`** — calls `DispatchMemoUpdatedWebhook` → `webhook.PostAsync` to user-configured webhook URLs  
3. **`DeleteMemo`** — calls `DispatchMemoDeletedWebhook` → `webhook.PostAsync` to user-configured webhook URLs
4. **`CreateMemoComment`** — triggers both internal `CreateMemo` webhook dispatch and `DispatchMemoCommentCreatedWebhook` → `webhook.PostAsync`

**Convergence Function** — `Post` in `internal/webhook/webhook.go`

This is the single function where all webhook dispatch paths converge. All four RPC handlers transitively call `webhook.PostAsync()`, which queues the request to an async worker pool. The workers invoke **`Post()`** which performs the actual HTTP POST to `requestPayload.URL` (the user-configured webhook URL) via `safeClient.Do(req)`.

**File paths:**
- Handler implementations: `server/router/api/v1/memo_service.go`, `server/router/api/v1/memo_service_comments.go`
- Webhook dispatch logic: `server/router/api/v1/memo_service_webhooks.go`
- Convergence function: `internal/webhook/webhook.go` (lines 119–152 for the `Post` function)
