**Premise correction:** There is no Redis connection for the cache layer. The cache layer does not use Redis.

**Actual mechanism:** The cache layer uses an in-memory cache implementation configured in `store/store.go`. User entries are cached using a dedicated `userCache` instance (an in-memory `*cache.Cache` object) defined at `store/store.go:28`. The TTL that applies to user entries is **10 minutes** (600 seconds), as configured via the `DefaultTTL` setting in the cache configuration at `store/store.go:41`.

Specifically, the user cache is initialized at `store/store.go:52` with:
```go
userCache: cache.New(cacheConfig)
```

where `cacheConfig` is defined at `store/store.go:40-45` with `DefaultTTL: 10 * time.Minute`.
