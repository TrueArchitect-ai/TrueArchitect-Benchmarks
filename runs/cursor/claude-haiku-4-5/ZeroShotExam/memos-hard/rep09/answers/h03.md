Based on my analysis of the repository, users can authenticate through third-party identity providers using an abstraction pattern:

**Abstraction package:** `github.com/usememos/memos/internal/idp` 
- Defines `IdentityProviderUserInfo` struct in `/bench/repo/internal/idp/idp.go`, which provides the common interface for user information returned by any identity provider

**Implementation package:** `github.com/usememos/memos/internal/idp/oauth2`
- Implements OAuth2 protocol support in `/bench/repo/internal/idp/oauth2/oauth2.go` with the `IdentityProvider` type that handles OAuth2 token exchange and user info retrieval

The OAuth2 implementation imports the abstraction package (`github.com/usememos/memos/internal/idp`) and uses the shared `IdentityProviderUserInfo` data structure.
