**Actual Mechanism:**

The webhook delivery system does not use an external message broker like NATS or RabbitMQ. Instead, it uses an in-process Go channel as the queue for asynchronous webhook delivery.


The implementation spawns 4 goroutine workers during package initialization (`init()` function, lines 42-55 in the same file) that consume from this channel. When `PostAsync()` is called to dispatch a webhook, it enqueues the payload to this in-process channel, which is then picked up by one of these 4 worker goroutines for delivery.
