**Answer:**

There is **no GraphQL schema** for the public API in this repository. The Memos project does not use GraphQL.

**Premise Correction:** The assumption that there is a GraphQL schema is incorrect. This repository defines its public API using **Protocol Buffers (protobuf)** and **gRPC**, not GraphQL.

**Actual API Surface:** The public API is defined across multiple `.proto` files in `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto`
- `attachment_service.proto`
- `user_service.proto`
- `auth_service.proto`
- `instance_service.proto`
- `ai_service.proto`
- `idp_service.proto`
- `shortcut_service.proto`
- `common.proto`

These protobuf definitions are used to generate:
1. **Go gRPC and Connect RPC bindings** in `/bench/repo/proto/gen/`
2. **REST/OpenAPI gateway** specification at `/bench/repo/proto/gen/openapi.yaml` (generated by `buf.build/community/google-gnostic-openapi`)
3. **TypeScript types** in `/bench/repo/web/src/types/proto/`

The canonical public API surface is documented in `/bench/repo/proto/gen/openapi.yaml`, which is automatically generated from the protobuf definitions using the `buf generate` command (configured in `/bench/repo/proto/buf.gen.yaml`).
