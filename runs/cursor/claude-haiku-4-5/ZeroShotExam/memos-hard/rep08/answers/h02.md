The `Post` function executes the actual HTTP delivery using a `safeClient` that has a custom `DialContext` function (`safeDialContext`). This custom dialer intercepts all connection attempts and validates that the resolved IP addresses are not in reserved/private ranges using the `isReservedIP` function. The reserved IP ranges are defined in `validate.go` and include loopback, RFC-1918 private addresses, link-local ranges, and their IPv6 equivalents. This SSRF protection works at dial-time, defeating both direct private IP targeting and DNS rebinding attacks.
