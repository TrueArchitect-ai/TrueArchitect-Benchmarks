**Computation site:** Derived metadata is computed in two layers:

**Extracted properties:** The computation extracts the following properties stored in `MemoPayload` (defined in `proto/store/memo.proto`, lines 7-29):

- `tags` (string array) - `#tag` nodes extracted and deduplicated while preserving case
- `property.has_link` (boolean) - presence of any Link node
- `property.has_code` (boolean) - presence of CodeBlock, FencedCodeBlock, or CodeSpan nodes
- `property.has_task_list` (boolean) - presence of any GFM task checkbox
- `property.has_incomplete_tasks` (boolean) - presence of any unchecked task checkbox
- `property.title` (string) - plain text from the first H1 heading, if present

Additionally, mentions (`@username`) are extracted in `ExtractAll` but are not stored in `MemoPayload`; they are used separately for notification logic. Snippets are computed on-read (not stored) via `GenerateSnippet` for list/preview display.
