**Premise correction:** This repository does not have a GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL.

**Actual API surface:** 

The public API is defined in proto files located in `/bench/repo/proto/api/v1/`:
- `memo_service.proto`
- `attachment_service.proto`
- `user_service.proto`
- `auth_service.proto`
- `shortcut_service.proto`
- `instance_service.proto`
- `ai_service.proto`
- `idp_service.proto`
- `common.proto`

These protobuf definitions are compiled into an **OpenAPI 3.0.3 specification** located at `/bench/repo/proto/gen/openapi.yaml`, which represents the RESTful HTTP API surface. The proto files use gRPC HTTP annotations to define REST endpoints (e.g., `post: "/api/v1/memos"`), and the `protoc-gen-openapi` tool generates the OpenAPI documentation from these proto files.
