This repository does not have a GraphQL schema for the public API. The public API is defined using **Protocol Buffers (protobuf)** with a **REST gateway**, not GraphQL.

**Premise Correction:** The question assumes the existence of a GraphQL schema, but this project does not use GraphQL for its public API.

**Actual API Surface:**

The public API schema is defined in:
- **Proto definitions**: `proto/api/v1/*.proto` files (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, etc.)
- **OpenAPI specification**: `proto/gen/openapi.yaml` — This is the generated OpenAPI 3.0.3 specification that describes the REST gateway operations

The API uses:
1. **Protocol Buffers** as the primary API definition language (`proto/api/v1/` directory)
2. **gRPC-Gateway** to expose REST endpoints at `/api/v1/*`
3. **OpenAPI** as the generated specification for REST operations

The OpenAPI document is generated from the protobuf definitions and serves as the authoritative contract for the public REST API surface.
