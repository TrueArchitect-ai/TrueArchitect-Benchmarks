**Protection mechanism — path:** `safeDialContext` function at `internal/webhook/webhook.go` (lines 57-77) combined with `isReservedIP` function at `internal/webhook/validate.go` (lines 43-54)

The delivery executes via the `Post` function which uses a `safeClient` HTTP client configured with a custom `DialContext` (the `safeDialContext` function). This protection works by resolving the target hostname and checking each resolved IP address against reserved/private IP ranges using the `isReservedIP` function. If any IP falls within reserved ranges (loopback, RFC-1918 private ranges, link-local, IPv6 equivalents), the connection is rejected before being attempted, preventing SSRF attacks and DNS rebinding attacks. The reserved IP ranges are defined in `validate.go` and can be optionally disabled via the `AllowPrivateIPs` flag for self-hosted deployments.
