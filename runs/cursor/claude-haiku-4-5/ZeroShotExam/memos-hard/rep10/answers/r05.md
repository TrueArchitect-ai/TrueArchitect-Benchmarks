   - `attachment_service.proto` – Attachment operations

3. **OpenAPI Specification** at `/bench/repo/proto/gen/openapi.yaml`:
   - Auto-generated from proto definitions

The API uses **gRPC-Gateway** to provide both gRPC and HTTP/JSON interfaces from the same proto definitions.
