**Premise Correction:** There is no GraphQL schema for a public API in this repository. This is a common misconception because Memos is often discussed in contexts that might include GraphQL APIs, but this particular project does not use GraphQL.

**Actual API Surface:**

Memos exposes two primary public APIs as documented in `README.md`:

1. **REST API** - Implemented via gRPC-Gateway, defined in protobuf files located in `/bench/repo/proto/api/v1/`:
   - `memo_service.proto`
   - `attachment_service.proto`
   - `auth_service.proto`
   - `user_service.proto`
   - `instance_service.proto`
   - `ai_service.proto`
   - `shortcut_service.proto`
   - `idp_service.proto`

2. **gRPC API** - Connect-based gRPC handlers for browser clients, registered in `server/router/api/v1/v1.go` (lines 131-144)

The services are registered and exposed via:
- **gRPC-Gateway** at `/api/v1/*` endpoint (line 128 of `server/router/api/v1/v1.go`)
- **Connect protocol** at `/memos.api.v1.*` endpoint (line 144 of `server/router/api/v1/v1.go`)

The OpenAPI specification for these APIs is generated and located at `/bench/repo/proto/gen/openapi.yaml`.
