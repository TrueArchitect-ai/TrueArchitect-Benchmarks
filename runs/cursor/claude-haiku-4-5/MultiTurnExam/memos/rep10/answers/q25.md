The ListMemos RPC filter uses:
1. **Syntax/Engine**: CEL (Common Expression Language) via the `google/cel-go` library, implemented in `/bench/repo/internal/filter/engine.go`
2. **How it works**: The `Engine.CompileToStatement()` method (line 73-79 in engine.go) parses the CEL filter string into a dialect-agnostic condition tree, then the `Renderer` (implemented in `/bench/repo/internal/filter/render.go`) converts this condition tree into dialect-specific SQL WHERE clauses. Each database driver (postgres/mysql/sqlite) calls `filter.AppendConditions()` (in `/bench/repo/internal/filter/helpers.go`) passing its dialect identifier, which generates the appropriate SQL with parameterized placeholders for that specific database system.
