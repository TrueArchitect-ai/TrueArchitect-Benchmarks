q27. Embedded in the binary via Go's `embed` package; server/router/frontend/frontend.go

The compiled React frontend is served as static files embedded in the Go binary at compile time using Go's `//go:embed` directive. The embedding and serving are wired up in `server/router/frontend/frontend.go`, which serves the files through Echo's static-file middleware with SPA fallback routing to `index.html` for client-side navigation. The frontend is built to `server/router/frontend/dist/` by the `pnpm release` command in `web/package.json`.
