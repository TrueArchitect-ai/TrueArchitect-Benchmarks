q16. memo_relation (as source), memo_relation (as target), attachment

When a memo is deleted through the API, the store layer deletes related records in this order before deleting the memo row itself:
1. `memo_relation` records where the deleted memo is the source (`memo_id`)
2. `memo_relation` records where the deleted memo is the target (`related_memo_id`)
3. `attachment` records linked to the memo

Additionally, at the API handler level, any comment memos are recursively deleted first (each with their own full cascade) before the parent memo's deletion cascade runs.
