q20. Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction

The server pushes live events to browsers using **Server-Sent Events (SSE)**. The hub is implemented in `server/router/api/v1/sse_hub.go` as the `SSEHub` struct. The following memo handlers broadcast events through it: CreateMemo (memo.created), UpdateMemo (memo.updated), DeleteMemo (memo.deleted), CreateMemoComment (memo.comment.created), SetMemoAttachments (memo.updated), SetMemoRelations (memo.updated), UpsertMemoReaction (reaction.upserted), and DeleteMemoReaction (reaction.deleted).
