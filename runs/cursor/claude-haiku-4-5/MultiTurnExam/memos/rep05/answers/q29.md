q29. web/src/connect.ts; access token (JWT, ~15 min, sent as Bearer header) and refresh token (JWT, ~30 days, HttpOnly cookie); server/auth/

The frontend auth interceptor lives in `web/src/connect.ts` (with token state helpers in `web/src/auth-state.ts`). It manages two token types: **access tokens** (short-lived JWTs sent as `Authorization: Bearer` headers) and **refresh tokens** (long-lived JWTs stored as HttpOnly cookies for secure refresh). The backend token validation is handled by the `server/auth/` package, which validates access tokens via stateless JWT verification and refresh tokens via JWT verification plus database revocation checks.
