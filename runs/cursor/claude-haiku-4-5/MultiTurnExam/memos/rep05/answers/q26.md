q26. attachment, memo, memo_relation, memo_share

When DeleteMemo runs, four tables are affected:
- `memo_relation` — explicitly deleted (rows where the memo is source or target)
- `attachment` — explicitly deleted (via DeleteAttachment for each linked attachment)
- `memo` — explicitly deleted (the memo row itself)
- `memo_share` — cascaded by the database via `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE`
