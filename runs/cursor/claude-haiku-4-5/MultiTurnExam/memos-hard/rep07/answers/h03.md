h03.

**internal/idp** (package idp); **internal/idp/oauth2** (package oauth2)

The provider abstraction is defined in the `internal/idp` package, which exports the `IdentityProviderUserInfo` struct that represents user information from any identity provider. The concrete OAuth2 protocol implementation is in the `internal/idp/oauth2` package, which provides the `IdentityProvider` struct that implements OAuth2 token exchange and user information retrieval.
