**Premise correction**: The codebase does not have a GraphQL schema. GraphQL is not used.

**Actual API surface**: The API is defined using **Protocol Buffers (protobuf)**, not GraphQL. The public API schema is defined in the `proto/api/v1/` directory in `.proto` files, including:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto`

The API is exposed through both gRPC and gRPC-Gateway (HTTP/JSON), not GraphQL.
