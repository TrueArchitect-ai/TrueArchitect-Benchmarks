**Premise correction**: The question assumes Redis is used for the cache layer, but the codebase does not use Redis at all.

**Actual mechanism**: The cache layer uses an in-memory cache with TTL management, configured in store/store.go:40-45. The user cache (userCache) is a *cache.Cache instance created at store/store.go:52 with a configuration that includes:
- **DefaultTTL: 10 minutes** (for user entries) — store/store.go:41
- CleanupInterval: 5 minutes
- MaxItems: 1000

The cache implementation is located at store/cache/cache.go and uses Go's sync.Map with manual TTL and cleanup logic, not Redis. Each cache entry (including users) expires after 10 minutes unless specifically set with a different TTL via SetWithTTL.
