**Premise correction:** There is no GraphQL schema for the public API. The system does not use GraphQL.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** following Google API Improvement Proposals (AIPs):

- **Schema location**: `/bench/repo/proto/api/v1/` directory containing multiple `.proto` files
- **Main service schemas**:
  - `/bench/repo/proto/api/v1/memo_service.proto` — Memo operations
  - `/bench/repo/proto/api/v1/user_service.proto` — User operations
  - `/bench/repo/proto/api/v1/attachment_service.proto` — Attachment operations
  - `/bench/repo/proto/api/v1/auth_service.proto` — Authentication
  - `/bench/repo/proto/api/v1/idp_service.proto` — Identity provider
  - `/bench/repo/proto/api/v1/instance_service.proto` — Instance management
  - `/bench/repo/proto/api/v1/ai_service.proto` — AI features
  - `/bench/repo/proto/api/v1/shortcut_service.proto` — Shortcuts
  - `/bench/repo/proto/api/v1/common.proto` — Common definitions

The API is served via **gRPC-Gateway** (which translates protobuf services to HTTP/JSON) at `/bench/repo/server/router/api/v1/v1.go:88-130`.
