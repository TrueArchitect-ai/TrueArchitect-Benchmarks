The data flow is:
- Request enters `serveUserAvatar` handler (line 168)
- Handler calls `getUserByUsername` (line 715) to fetch user by username from the store
- Store calls the database driver's `GetUser` method to retrieve the user record containing the `AvatarURL` field
- The `AvatarURL` is stored as a data URI string in the user record
- `parseDataURI` (line 737) decodes the base64-encoded image data from the stored data URI
- The decoded image is streamed back to the browser via `c.Blob` (line 209)
