**Premise correction**: There is no GraphQL schema. The API is not GraphQL-based.

**Actual API surface**: gRPC with gRPC-Gateway (REST fallback) and Connect/Connect-RPC

**Schema definition locations** (Protocol Buffer definitions):
- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/attachment_service.proto` — Attachment handling
- `proto/api/v1/auth_service.proto` — Authentication/session management
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI/ML features
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — Shortcut management
- `proto/api/v1/common.proto` — Shared message types

The API is defined using Protocol Buffers v3 (`proto/api/v1/`) with:
- gRPC service definitions compiled to Go code (`proto/gen/api/v1/`)
- gRPC-Gateway for automatic REST endpoint generation (`server/router/api/v1/v1.go:88`)
- Connect protocol support for browser clients (`server/router/api/v1/v1.go:140`)
