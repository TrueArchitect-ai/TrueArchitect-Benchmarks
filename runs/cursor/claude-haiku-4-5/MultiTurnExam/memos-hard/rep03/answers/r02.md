**Premise correction**: There is no per-user API rate-limiting middleware registered in the codebase. The repository does not implement rate-limiting middleware.

**What exists instead**: The server implements batch operation limits (not per-user rate limits):
- `maxAPIRequestBytes = 256 << 20` (256 MB request size limit) — `server/router/api/v1/v1.go:20`
- `maxBatchGetLinkMetadata = 10` — `server/router/api/v1/memo_service.go:26`
- `maxBatchDeleteAttachments = 100` — `server/router/api/v1/attachment_service.go:35`
- `maxBatchGetInstanceSettings = 100` — `server/router/api/v1/instance_service.go:22`
- `maxBatchGetUsers = 100` — `server/router/api/v1/user_service.go:23`

These are per-operation batch size limits, not per-user rate limits. There is no middleware that enforces requests-per-second or requests-per-minute limits on a per-user basis.
