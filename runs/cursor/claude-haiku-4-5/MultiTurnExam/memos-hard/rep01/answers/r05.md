**Premise Correction:** There is **no GraphQL schema** defined for the public API. The API is not GraphQL-based.

**Actual API Surface:**
- The public API is defined using **Protocol Buffers (proto3)** specifications at `proto/api/v1/`
- API definition files:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/common.proto`

- The API is exposed through two transport layers (both serving the same proto definitions):
  1. **gRPC-Gateway** (REST over HTTP/1.1) — registered at `server/router/api/v1/v1.go:95-128`
  2. **Connect Protocol** (RPC over HTTP/1.1 and HTTP/2) — registered at `server/router/api/v1/v1.go:131-144`

The protobuf definitions are compiled to Go code in `proto/gen/api/v1/` and exposed through both REST and Connect RPC transports, not GraphQL.
