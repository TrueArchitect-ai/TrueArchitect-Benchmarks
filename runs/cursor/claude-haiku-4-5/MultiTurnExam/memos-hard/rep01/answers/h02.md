The `Post` function executes the actual HTTP delivery to webhooks. It uses a shared `safeClient` HTTP client (line 32-37) configured with a custom `safeDialContext` dialer that validates hostnames before connecting. The `safeDialContext` function (line 59) resolves the target hostname and checks each resolved IP address against a set of reserved/private IP ranges using the `isReservedIP` function (validate.go:44). This prevents SSRF attacks by blocking connections to loopback, RFC-1918 private addresses, link-local addresses, and IPv6 equivalents, unless explicitly overridden via the `AllowPrivateIPs` configuration flag (validate.go:41).
