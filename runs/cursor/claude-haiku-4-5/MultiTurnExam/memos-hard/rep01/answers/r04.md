**Premise Correction:** There is **no external message broker** (neither NATS nor RabbitMQ) used for webhook delivery.

**Actual Mechanism:** 
- Webhook delivery uses an **in-process Go channel** queue, not an external message broker
- The queue is declared at `internal/webhook/webhook.go:39` as:
  ```
  asyncPostQueue = make(chan *WebhookRequestPayload, 128)
  ```
- This is a buffered Go channel with a capacity of 128 messages
- 4 worker goroutines are launched in the `init()` function at `internal/webhook/webhook.go:42-54` that consume from this queue
- Each worker calls `Post(payload)` to deliver the webhook payload to the target URL
- `PostAsync()` enqueues payloads to this channel (lines 184-196)

There are no external message brokers (NATS, RabbitMQ, Kafka, etc.) in the webhook delivery architecture. It's purely an in-process buffered channel with bounded concurrency (4 workers).
