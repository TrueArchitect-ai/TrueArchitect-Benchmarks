h03.

**Abstraction package:** `internal/idp`

**Implementation package:** `internal/idp/oauth2`

The `internal/idp` package defines the provider abstraction via the `IdentityProviderUserInfo` struct (idp.go). The concrete OAuth2 protocol implementation ships in the `internal/idp/oauth2` package, which provides an `IdentityProvider` type that implements OAuth2 token exchange and user info retrieval (oauth2.go).
