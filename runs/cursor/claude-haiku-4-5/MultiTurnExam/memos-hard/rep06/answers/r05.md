**Premise correction:** There is no GraphQL schema in this repository. The question assumes GraphQL is used, but the API is actually defined using **Protocol Buffers (protobuf)** with gRPC.

**Actual API surface:** The public API is defined in Protocol Buffer service definitions located in `/bench/repo/proto/api/v1/` directory, which includes:

- `memo_service.proto` - Memo CRUD and management operations
- `user_service.proto` - User management and authentication  
- `attachment_service.proto` - Attachment upload and retrieval
- `auth_service.proto` - Authentication and authorization
- `instance_service.proto` - Instance-level configuration
- `ai_service.proto` - AI integration services
- `idp_service.proto` - Identity provider management
- `shortcut_service.proto` - Shortcut management
- `common.proto` - Common types and definitions

These `.proto` files are compiled to generate Go code in `/bench/repo/proto/gen/api/v1/`, which is then used by the server's gRPC-Gateway to expose both gRPC and HTTP/REST endpoints. The API is not GraphQL-based.
