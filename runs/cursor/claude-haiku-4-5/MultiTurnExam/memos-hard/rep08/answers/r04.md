**Premise correction**: Neither NATS nor RabbitMQ is used. There is no external message broker.

**Actual mechanism**: The webhook delivery system uses an in-memory Go channel for asynchronous dispatch. The queue is declared at internal/webhook/webhook.go:39 as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`, which is a buffered channel with capacity 128. Four worker goroutines are spawned in the init() function (internal/webhook/webhook.go:42-54) that consume from this channel and deliver webhooks via the Post() function. When PostAsync() is called (internal/webhook/webhook.go:184-196), it attempts to send the payload to this in-memory channel. If the channel is full, the webhook dispatch is dropped with a warning rather than being queued to an external broker.
