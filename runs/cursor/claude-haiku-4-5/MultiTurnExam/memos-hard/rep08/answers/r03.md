**Premise correction**: There is no nightly database-cleanup job scheduled in the cron scheduler. The internal/scheduler package is implemented as a generic cron job scheduler framework but is never instantiated or used in the actual server code. It exists only as infrastructure with documentation and test examples (internal/scheduler/doc.go, internal/scheduler/example_test.go, internal/scheduler/integration_test.go). The server does not register or run any scheduled jobs using this scheduler. The only periodic background task that runs is the S3 presign renewal (every 12 hours in server/runner/s3presign/runner.go), which uses a simple time.Ticker, not the scheduler framework.
