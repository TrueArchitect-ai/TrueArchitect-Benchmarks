**Premise correction**: There is no GraphQL schema. GraphQL is not used in this project.

**Actual API surface**: The public API is defined using **Protocol Buffers (protobuf)** with gRPC and HTTP/REST support. The API schema is defined in proto files located at:

- proto/api/v1/memo_service.proto (MemoService)
- proto/api/v1/attachment_service.proto (AttachmentService)
- proto/api/v1/auth_service.proto (AuthService)
- proto/api/v1/user_service.proto (UserService)
- proto/api/v1/instance_service.proto (InstanceService)
- proto/api/v1/ai_service.proto (AIService)
- proto/api/v1/idp_service.proto (IdentityProviderService)
- proto/api/v1/shortcut_service.proto (ShortcutService)

The API uses Google API annotations (google.api.http) to map RPC methods to HTTP REST endpoints (proto/api/v1/memo_service.proto:22-25, etc.). The generated protobuf files are compiled to Go code and served via a gRPC-Gateway that handles both gRPC and HTTP/JSON requests (server/router/api/v1/v1.go:96-98).
