**Abstraction package** — internal/idp

**Implementation package** — internal/idp/oauth2

The `internal/idp` package defines the provider abstraction with the `IdentityProviderUserInfo` struct (internal/idp/idp.go). The `internal/idp/oauth2` package provides the concrete OAuth2 protocol implementation with the `IdentityProvider` type that implements OAuth2 token exchange and user info retrieval.
