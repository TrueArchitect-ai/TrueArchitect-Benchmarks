**Premise correction:** There is no per-user API rate-limiting middleware registered in this repository. The codebase does not implement per-user rate limiting at all.

What the codebase **does** implement are:
- **Request size limits**: `maxAPIRequestBytes = 256 << 20` (256 MB) at `/bench/repo/server/router/api/v1/v1.go:20`
- **Batch operation limits** (not per-user rate limiting):
  - `maxBatchGetUsers = 100` users per request
  - `maxBatchDeleteAttachments = 100` attachments per request
  - `maxBatchGetInstanceSettings = 100` settings per request
  - `maxBatchGetLinkMetadata = 10` URLs per request
  - Resource concurrency limits (semaphores): 3 concurrent thumbnail generations, 2 concurrent image processing operations

But there is **no middleware implementing per-user request-rate limiting** (e.g., requests per second/minute per user). The authentication is handled at the middleware level, but rate limiting is not applied.
