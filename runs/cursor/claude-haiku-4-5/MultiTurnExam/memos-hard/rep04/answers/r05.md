**Premise correction:** The API is not defined using GraphQL. There is no GraphQL schema in this repository.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** service definitions. The schema is defined in proto files located in `/bench/repo/proto/api/v1/`:

- `/bench/repo/proto/api/v1/memo_service.proto` - Memo operations (CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo, etc.)
- `/bench/repo/proto/api/v1/user_service.proto` - User operations
- `/bench/repo/proto/api/v1/attachment_service.proto` - Attachment operations
- `/bench/repo/proto/api/v1/auth_service.proto` - Authentication operations
- `/bench/repo/proto/api/v1/instance_service.proto` - Instance settings and management
- `/bench/repo/proto/api/v1/shortcut_service.proto` - Shortcut operations
- `/bench/repo/proto/api/v1/idp_service.proto` - Identity provider operations
- `/bench/repo/proto/api/v1/ai_service.proto` - AI/LLM operations

The proto definitions include HTTP mappings (via `google.api.http` annotations) that are compiled to gRPC-Gateway endpoints (serving HTTP/REST), and also support gRPC and Connect RPC protocols. This is NOT GraphQL—it's a polyglot gRPC-based API with HTTP bindings.
