**Premise correction:** There is no GraphQL schema. The API is not GraphQL-based.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) with gRPC and gRPC-Gateway (HTTP REST bindings). The API schema is defined across multiple proto files in `/bench/repo/proto/api/v1/`:

1. **MemoService** — `/bench/repo/proto/api/v1/memo_service.proto` — Memo CRUD operations (create, read, list, update, delete)

2. **UserService** — `/bench/repo/proto/api/v1/user_service.proto` — User management, settings, webhooks, access tokens

3. **AuthService** — `/bench/repo/proto/api/v1/auth_service.proto` — Authentication (sign-in, sign-up, sign-out, SSO)

4. **InstanceService** — `/bench/repo/proto/api/v1/instance_service.proto` — Instance configuration and settings

5. **AttachmentService** — `/bench/repo/proto/api/v1/attachment_service.proto` — Attachment upload/download

6. **IdentityProviderService** — `/bench/repo/proto/api/v1/idp_service.proto` — Identity provider configuration

7. **ShortcutService** — `/bench/repo/proto/api/v1/shortcut_service.proto` — User shortcuts management

8. **AIService** — `/bench/repo/proto/api/v1/ai_service.proto` — AI-related operations

9. **Common types** — `/bench/repo/proto/api/v1/common.proto` — Shared message definitions

The proto files are compiled to Go code via protoc and registered with gRPC-Gateway to provide HTTP REST endpoints at `/api/v1/` with automatic OpenAPI documentation generation.
