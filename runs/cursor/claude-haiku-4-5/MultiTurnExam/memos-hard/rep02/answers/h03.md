h03.

**Abstraction package:** `github.com/usememos/memos/internal/idp`

**Implementation package:** `github.com/usememos/memos/internal/idp/oauth2`

The `internal/idp` package defines the abstraction with the `IdentityProviderUserInfo` struct that represents user information from identity providers. The `internal/idp/oauth2` package provides the concrete OAuth2 protocol implementation with the `IdentityProvider` type that implements the OAuth2 authentication flow.
