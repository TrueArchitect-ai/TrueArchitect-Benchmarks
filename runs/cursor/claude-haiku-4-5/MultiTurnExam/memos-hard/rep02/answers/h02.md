**Protection mechanism:** `isReservedIP` — `internal/webhook/validate.go:44`

The `Post` function performs the actual outbound HTTP delivery to webhook endpoints using a `safeClient` that has a custom `safeDialContext` function. This custom dialer resolves the target hostname and checks each resolved IP address against the `isReservedIP` function, which blocks connections to reserved/private IP ranges (loopback, RFC-1918, link-local, and their IPv6 equivalents) unless explicitly allowed via the `AllowPrivateIPs` configuration flag.
