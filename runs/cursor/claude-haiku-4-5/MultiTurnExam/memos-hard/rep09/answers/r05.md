**Premise correction:** There is no GraphQL schema for the public API. The API does not use GraphQL.

**Actual API surface:**
The public API is defined using **Protocol Buffers (protobuf)** with **gRPC-Gateway and Connect**, not GraphQL.

The API schema is defined across multiple `.proto` files in `/bench/repo/proto/api/v1/`:
- `memo_service.proto` 
- `user_service.proto`
- `attachment_service.proto`
- `auth_service.proto`
- `instance_service.proto`
- `ai_service.proto`
- `idp_service.proto` 
- `shortcut_service.proto`
- `common.proto`

These proto files define RPC services that are compiled using `protoc-gen-openapi` to generate an **OpenAPI 3.0.3 specification** at `proto/gen/openapi.yaml`. The proto files use Google API annotations (`google.api.http`) to define REST endpoint mappings, and are processed by gRPC-Gateway to generate REST handlers alongside native gRPC/Connect support.

This is a multi-protocol API offering REST, gRPC, and Connect transports, all derived from the same protobuf service definitions.
