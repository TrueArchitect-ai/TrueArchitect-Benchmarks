**Premise correction:** There is no GraphQL schema. The public API is not GraphQL-based.

**Actual API surface:**
The API is defined using **Protocol Buffers (proto3)** with gRPC and gRPC-Gateway HTTP mapping:

- **API Definition Location:** `proto/api/v1/` directory
  - `proto/api/v1/memo_service.proto` — Memo operations
  - `proto/api/v1/attachment_service.proto` — Attachment operations
  - `proto/api/v1/user_service.proto` — User operations
  - `proto/api/v1/auth_service.proto` — Authentication
  - `proto/api/v1/instance_service.proto` — Instance configuration
  - And others for shortcuts, AI, identity providers, etc.

- **HTTP Routing:** gRPC-Gateway provides REST mappings (e.g., `POST /api/v1/memos`, `GET /api/v1/memos/{name}`)
- **RPC Implementation:** The service implementations are in `server/router/api/v1/` (e.g., `memo_service.go`, `user_service.go`)
- **Transport:** Both Connect RPC and gRPC-Gateway transports are supported for the same service definitions

The API is a **gRPC+REST hybrid API**, not GraphQL.
