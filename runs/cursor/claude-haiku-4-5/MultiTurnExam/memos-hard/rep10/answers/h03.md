**Abstraction package:** `github.com/usememos/memos/internal/idp`

**Implementation package:** `github.com/usememos/memos/internal/idp/oauth2`

The abstraction is defined in `internal/idp/idp.go` which exports the `IdentityProviderUserInfo` struct that represents the user information returned by any identity provider. The concrete OAuth2 protocol implementation is shipped in `internal/idp/oauth2/oauth2.go`, which implements an `IdentityProvider` type that handles OAuth2 token exchange and user information retrieval according to the OAuth2 specification.
