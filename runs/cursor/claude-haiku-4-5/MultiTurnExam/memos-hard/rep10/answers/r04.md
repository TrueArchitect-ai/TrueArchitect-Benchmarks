**Premise correction:** Neither NATS nor RabbitMQ is used. Webhook delivery workers do not consume from any message broker.

**Actual mechanism:**
Webhook delivery uses an **in-memory Go channel queue** for async job distribution:
- **Queue declaration:** `internal/webhook/webhook.go:39` — `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` 
- **Workers:** Four background goroutines are spawned in `internal/webhook/webhook.go:42-55` that consume from this channel
- **Dispatch:** `PostAsync()` function (`internal/webhook/webhook.go:184`) enqueues payloads to the channel
- **Actual delivery:** Worker goroutines consume payloads and call `Post()` to make the HTTP requests

This is a simple, in-process async pattern using Go channels with no external message broker dependency.
