**Premise correction:** There is no nightly database-cleanup job scheduled in this codebase. 

A comprehensive search reveals that:
1. The internal scheduler package (`internal/scheduler/`) exists as a general-purpose cron job scheduler library (with example documentation showing "daily-cleanup" at 2 AM)
2. However, the scheduler is **never instantiated or used** in the application
3. There is **no background database cleanup job registered** or executed anywhere in the production code
4. Database cleanup only happens as a side-effect of explicit operations (user deletion, memo deletion, attachment cleanup during these deletions)

The codebase does have cache cleanup (in `store/cache/cache.go`) which runs on a configurable interval (default 5 minutes), but this is in-memory cache cleanup, not database cleanup, and it's not a scheduled job—it runs as a background goroutine within the Cache itself.
