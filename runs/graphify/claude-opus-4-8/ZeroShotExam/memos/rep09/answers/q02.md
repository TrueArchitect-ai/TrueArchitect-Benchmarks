The migrations directory contains three dialect subdirectories.

q02.
SQLite, MySQL, PostgreSQL

The project ships migrations under `store/migration/`, which contains three dialect-specific subdirectories: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/` (each with a `LATEST.sql` plus versioned migration folders, e.g. `store/migration/postgres/LATEST.sql`, `store/migration/sqlite/LATEST.sql`, `store/migration/mysql/LATEST.sql`).
