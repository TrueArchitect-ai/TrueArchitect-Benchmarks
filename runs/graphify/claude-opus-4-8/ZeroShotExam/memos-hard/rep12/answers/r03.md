The premise is incorrect: this repository (the **memos** project) has **no cron scheduler and no nightly database-cleanup job**.

There is no cron/scheduling library in the project at all — `go.mod` contains no `cron`, `gocron`, `quartz`, or similar dependency, and there is no cron scheduler package in the codebase.

The only background/periodic jobs are two runners under `server/runner/`, and neither is a database-cleanup job nor cron-scheduled to a specific time:

- `server/runner/s3presign/runner.go` — refreshes S3 presigned links. It uses a `time.Ticker`, not cron, and runs on a fixed interval of every 12 hours (`server/runner/s3presign/runner.go:27`: `const runnerInterval = time.Hour * 12`), not at a nightly clock time.
- `server/runner/memopayload/` — rebuilds memo payloads; not a scheduled cleanup job.

So there is no "nightly database-cleanup job" and no cron scheduler to assign it a time. If you're looking for the closest thing to a recurring maintenance task, it's the S3 presign runner, which runs every 12 hours via a ticker rather than at a set time.
