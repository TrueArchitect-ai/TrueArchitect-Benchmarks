**1st: `store.User` (~7 external packages); 2nd: `store.Memo` (~6 external packages)**

The data layer is the `store/` package (module `github.com/usememos/memos`), which defines the persistent entity types in `store/*.go`: `Memo` (`store/memo.go`), `User` (`store/user.go`), `Attachment`, `Inbox`, `Reaction`, `IdentityProvider`, `MemoRelation`, `MemoShare`, `UserIdentity`, `UserSetting`, `InstanceSetting`.

Counting distinct packages **outside** the `store/` tree that reference each type (`store.<Type>`):

- **`store.User` — 1st (~7 packages):** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.
- **`store.Memo` — 2nd (~6 packages):** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.

The ranking is the same whether or not the in-layer store subpackages (`store/db/{sqlite,postgres,mysql}`, `store/test`) are included — User leads Memo in both cases (11 vs 10 with them, 7 vs 6 without). All other entity types trail well behind (Attachment is next at ~4).
