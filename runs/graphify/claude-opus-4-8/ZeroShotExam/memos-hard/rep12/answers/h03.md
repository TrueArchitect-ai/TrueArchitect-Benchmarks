The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type used across identity providers. The only concrete protocol implementation that ships is the OAuth2 provider in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`), whose file comment reads "Package oauth2 implements the OAuth2 identity provider integration" and provides `NewIdentityProvider` driven by `storepb.OAuth2Config`.
