**Computation site**

The derived metadata is a memo's `Payload` — specifically `Payload.Property` (plus `Payload.Tags`) — computed from the memo's markdown `Content`, not set by the user. The actual computation lives in the markdown service at `internal/markdown/markdown.go`:
- `ExtractAll(content)` (`internal/markdown/markdown.go:355`) — the single-pass extractor used in production; it fills `ExtractedData{Tags, Mentions, Property}` (struct at `internal/markdown/markdown.go:19`).
- `ExtractProperties(content)` (`internal/markdown/markdown.go:192`) — the equivalent property-only pass (interface at `internal/markdown/markdown.go:39`).

The glue that attaches the result to a memo is `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which calls `ExtractAll` and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:84-85`).

**Triggers (recomputation)**

`RebuildMemoPayload` is invoked whenever memo content changes or is (re)built:
- **Create memo** — `server/router/api/v1/memo_service.go:107` (in `CreateMemo`).
- **Update memo, when the `content` field is in the update mask** — `server/router/api/v1/memo_service.go:447` (the `if path == "content"` branch of `UpdateMemo`); other field updates like visibility do not recompute it.
- **Background/batch rebuild runner** — `server/runner/memopayload/runner.go:52`, which loops over memos calling `RebuildMemoPayload` then `Store.UpdateMemo` (migration/backfill of payloads).

**Extracted properties**

Walking the goldmark AST, it extracts into `storepb.MemoPayload_Property` (`proto/gen/store/memo.pb.go:85`):
- `Title` — text of the first block if it is an H1 heading (`markdown.go:387` / `:216`)
- `HasLink` — presence of any link (`markdown.go:394`)
- `HasCode` — presence of a code block, fenced code block, or code span (`markdown.go:397`)
- `HasTaskList` — presence of any task-list checkbox (`markdown.go:400`)
- `HasIncompleteTasks` — a task checkbox that is unchecked (`markdown.go:403`)

Plus, from the same `ExtractAll` pass, `Payload.Tags` — the list of `#tags` found in the content. These feed list/preview and stats surfaces (e.g. `server/router/api/v1/user_service_stats.go:141+` reads `Payload.Property.HasLink/HasCode/HasTaskList/HasIncompleteTasks`).
