**Premise correction:** This repository (the Memos project) has **no GraphQL schema and no GraphQL API**. A search for `graphql`/`.graphql`/`.gql` across Go, TypeScript, and proto files returns nothing. The only node named `Schema` in the graph is `internal/filter/schema.go:60` — that's a CEL/filter expression schema for memo filtering, entirely unrelated to a public API surface.

**Actual API surface:** The public API is defined with **Protocol Buffers → gRPC + gRPC-gateway (REST)**, not GraphQL:

- **Schema/IDL source of truth:** `proto/api/v1/*.proto` — one file per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`.
- **Generated code:** `proto/gen/api/v1/` — gRPC stubs (`*_grpc.pb.go`, e.g. `memo_service_grpc.pb.go`) and REST gateway handlers (`*.pb.gw.go`, e.g. `RegisterMemoServiceHandlerServer()` in `memo_service.pb.gw.go`).
- **Server wiring:** `server/router/api/v1/v1.go` — `APIV1Service` (struct at `:22`, constructed by `NewAPIV1Service()` at `:47`), which registers the gRPC-gateway via `.RegisterGateway()` at `:65` to expose the proto services as HTTP/REST.

So if you're looking for "the schema," it lives in the `.proto` files under `proto/api/v1/`, and the wire API is gRPC with a RESTful gateway — there is no GraphQL layer to point to.
