**How I determined which of the three candidates actually runs:**

Three drivers each implement `CreateMemo` with a memo INSERT: `store/db/sqlite/memo.go`, `store/db/postgres/memo.go:38`, and `store/db/mysql/memo.go`. I traced the runtime dispatch to see which one is selected:

1. Saving a memo calls the store facade `(*Store).CreateMemo` (`store/memo.go:109`), which delegates to `s.driver.CreateMemo` (`store/memo.go:113`).
2. `s.driver` is constructed by `NewDBDriver` (`store/db/db.go`), which `switch`es on `profile.Driver`: `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`.
3. The value of `profile.Driver` on a default install comes from the CLI/config default, which is hard-coded to `"sqlite"`: `viper.SetDefault("driver", "sqlite")` and `rootCmd.PersistentFlags().String("driver", "sqlite", "database driver")` in `cmd/memos/main.go:122` and `:130`.
