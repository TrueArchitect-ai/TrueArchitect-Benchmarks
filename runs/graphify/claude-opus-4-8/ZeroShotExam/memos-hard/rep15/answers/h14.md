**Computation site.** The derived metadata lives on `Memo.Payload` (`store/memo.go:51`) — specifically `Payload.Property` and `Payload.Tags`. It is computed by `RebuildMemoPayload(ctx, memo, markdownService)` in `server/runner/memopayload/runner.go:74`, which calls the goldmark-backed markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:355`) and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:85-86`). The core property walk is `ExtractAll` (mirrored by the standalone `ExtractProperties` at `internal/markdown/markdown.go:193`), which parses the content to a markdown AST and walks it.

**Triggers (recomputation).** `RebuildMemoPayload` runs whenever a memo's content is created or changed, plus a bulk backfill pass:
- Memo create — `server/router/api/v1/memo_service.go:108`
- Memo update on the `content` field — `server/router/api/v1/memo_service.go:447`
- Bulk rebuild of all memos in batches of 100 via the runner's `RunOnce` (`server/runner/memopayload/runner.go:27-52`), which re-derives and persists each memo's payload.

**Extracted properties** (from the AST walk, `internal/markdown/markdown.go:376-405`, stored per `proto/gen/store/memo.pb.go:85-92`):
- `Tags` — collected from memo tag nodes (`[]string` on the payload)
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one
- `Property.HasLink` — true if any link node is present
- `Property.HasCode` — true for any code block, fenced code block, or inline code span
- `Property.HasTaskList` — true if any task checkbox exists
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked

(Mentions are also gathered by `ExtractAll` but `RebuildMemoPayload` only writes `Tags` and `Property` onto the payload.)
