**`internal/idp`; `internal/idp/oauth2`**

The provider abstraction lives in the `idp` package at `internal/idp/idp.go`, which defines the provider-neutral `IdentityProviderUserInfo` struct (the shared contract every provider maps its user data into). The only concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2/oauth2.go` — its package comment reads `Package oauth2 implements the OAuth2 identity provider integration`, and it imports `github.com/usememos/memos/internal/idp`. `internal/idp/` contains just `idp.go` and the `oauth2/` subpackage, so OAuth2 is the sole shipped protocol.
