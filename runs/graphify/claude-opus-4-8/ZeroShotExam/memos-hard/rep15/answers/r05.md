**Premise correction:** This repository (`usememos/memos`) has **no GraphQL schema** — there is no GraphQL API anywhere in the codebase. A search for "graphql" across the tree (excluding `graphify-out/`) returns zero matches. The README explicitly describes the project's public API as "full REST and gRPC APIs" (`README.md:22`), not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC + REST)**, not GraphQL. The schema lives in:

- **`proto/api/v1/`** — the hand-written `.proto` source of truth. Each service is one file, all containing gRPC `service` definitions with REST bindings via `google.api.http` annotations (grpc-gateway):
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/common.proto` (shared types)
- **`proto/gen/api/v1/`** — generated Go code (including `*.pb.gw.go` grpc-gateway REST handlers and OpenAPI output) produced from those `.proto` files.
- **`proto/store/`** / **`proto/gen/store/`** — internal storage protos (not the public API surface).

So the answer to "where is the schema defined" is `proto/api/v1/*.proto`, and the transport is gRPC with a REST/HTTP gateway — there is no GraphQL layer to point to.
