**Computation site:** `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which calls the goldmark markdown service's `ExtractAll()` in `internal/markdown/markdown.go` (the single-pass AST walk beginning at L360; the standalone `ExtractProperties()` at `internal/markdown/markdown.go:193` computes the same property set). `RebuildMemoPayload` writes the result into `memo.Payload.Property` and `memo.Payload.Tags` (`runner.go:85-86`).

**Triggers (recomputation on content change):**
- **Create** — `CreateMemo` calls `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Update** — `UpdateMemo` calls it at `server/router/api/v1/memo_service.go:447`, but only inside the branch where the update mask path is `"content"` (`memo_service.go:436-449`), so it re-derives only when the content actually changes.
- **Backfill/migration** — the background runner `server/runner/memopayload/runner.go:52` rebuilds the payload for every existing memo in batches, then persists via `UpdateMemo`.

**Extracted properties** (`storepb.MemoPayload_Property`, from the AST walk):
- `Title` — text of the first block-level child if it's an H1 heading (`markdown.go:383-388`).
- `HasLink` — a link node exists (`KindLink`).
- `HasCode` — any code block/fenced code/inline code span.
- `HasTaskList` — a task checkbox exists.
- `HasIncompleteTasks` — a task checkbox that is unchecked.

Plus `Tags` (from `#tag` nodes) — also derived from content in the same `ExtractAll` pass and stored on the payload alongside `Property`. These derived properties are what feed list/preview and stats views (e.g. `server/router/api/v1/user_service_stats.go:141-151`).
