**No.** The MySQL driver is constructed only inside the driver-selection factory.

Evidence:
- The MySQL driver constructor is `mysql.NewDB` at `store/db/mysql/mysql.go:20`, which builds the driver struct (`driver := DB{profile: profile}` at `store/db/mysql/mysql.go:29`).
- A codebase-wide search for callers of `mysql.NewDB` finds exactly one: the factory `NewDBDriver` in `store/db/db.go:22` (inside the `switch profile.Driver` on `case "mysql"`).
- No other Go file references the `mysql` driver package's constructor or its `DB` struct. The only other uses of a `mysql.` prefix outside the package are in `store/test/containers.go:101-105` (`mysql.Run`, `mysql.WithDatabase`, etc.), which refer to the unrelated testcontainers-go MySQL module used to spin up a Docker container for tests — not the memos MySQL driver. The sibling constructors `sqlite.NewDB`/`postgres.NewDB` are likewise called from the factory (and, for sqlite, from a couple of tests), but never `mysql.NewDB`.

So outside `NewDBDriver` in `store/db/db.go`, the MySQL driver is never constructed directly.
