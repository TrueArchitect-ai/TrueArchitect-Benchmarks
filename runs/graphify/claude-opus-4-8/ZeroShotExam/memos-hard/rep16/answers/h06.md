**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`.**

`PostAsync` (`internal/webhook/webhook.go:173`) only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` each call `Post`, so every dispatch path funnels through the single `Post` function, which marshals the payload, builds the `POST` request to `requestPayload.URL`, HMAC-signs it, and delivers it via `safeClient.Do(req)` (the shared SSRF-guarded HTTP client).
