**abstraction package: `internal/idp` — implementation package: `internal/idp/oauth2`**

The provider abstraction lives in `internal/idp/idp.go` (package `idp`), which defines the shared `IdentityProviderUserInfo` type used across identity providers. The one concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2/oauth2.go` — its package comment reads `// Package oauth2 implements the OAuth2 identity provider integration.`, and it imports `github.com/usememos/memos/internal/idp` while providing `NewIdentityProvider`, `ExchangeToken`, etc.

No other protocol (OIDC/SAML/LDAP) implementation exists under `internal/idp/` — `oauth2` is the sole concrete provider.
