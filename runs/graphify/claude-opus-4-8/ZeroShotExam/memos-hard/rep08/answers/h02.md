**delivery function** — `Post` in `internal/webhook/webhook.go:120` (it marshals the payload, signs it, and actually sends the request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`). Deliveries are enqueued and dispatched by the async worker goroutines in `init` (`internal/webhook/webhook.go:42-55`) fed by `PostAsync`, but the outbound HTTP call itself executes in `Post`.

**protection mechanism** — `safeDialContext`, the custom `http.Transport.DialContext` on the shared `safeClient` (`internal/webhook/webhook.go:32-77`). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP`/`reservedCIDRs` in `internal/webhook/validate.go:14-54`. Because the check runs at connection time on the resolved IPs, it also defeats DNS-rebinding. This is backed up by an up-front `ValidateURL` check (`internal/webhook/validate.go:62-83`) applied when the webhook URL is configured, and both can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments.
