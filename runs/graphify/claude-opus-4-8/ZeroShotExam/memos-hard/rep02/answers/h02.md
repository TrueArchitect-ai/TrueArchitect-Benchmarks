**Delivery function** — `Post` in `internal/webhook/webhook.go:120` is where the outbound HTTP request is actually built and sent (`safeClient.Do(req)` at line 152). It runs in the background dispatch workers started in `init` (line 42–55) via `PostAsync` → the `asyncPostQueue`.

**Protection mechanism** — At delivery time, SSRF is blocked by the custom transport dialer `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient` (lines 32–37). It resolves the target host and rejects any address in a reserved/private range via `isReservedIP` — defined in `internal/webhook/validate.go:44`, backed by the `reservedCIDRs`/`reservedNetworks` list (loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents). Because the check happens at dial time on the actually-resolved IP, it also defeats DNS-rebinding. (A complementary up-front check, `ValidateURL` at `internal/webhook/validate.go:62`, runs when the webhook URL is configured, and both can be bypassed by the `AllowPrivateIPs` flag for self-hosted local-network use.)

Concise form:
- delivery function — `Post`, `internal/webhook/webhook.go`
- protection mechanism — `safeDialContext`/`safeClient` + `isReservedIP`, `internal/webhook/webhook.go` and `internal/webhook/validate.go`
