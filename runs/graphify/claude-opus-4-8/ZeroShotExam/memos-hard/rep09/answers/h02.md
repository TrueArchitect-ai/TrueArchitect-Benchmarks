**Delivery function** — `Post` in `internal/webhook/webhook.go` (webhooks are dispatched here via `safeClient.Do(req)`; `PostAsync` in the same file enqueues onto a bounded worker queue that ultimately calls `Post`).

**Protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go`, wired into `safeClient`'s `http.Transport`. It resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (with the CIDR list and check defined in `internal/webhook/validate.go`). Because the check happens at dial time on the actually-resolved IPs, it also defeats DNS-rebinding. A secondary, up-front check exists in `ValidateURL` (`internal/webhook/validate.go`), called when the webhook URL is configured, and both can be disabled via the `AllowPrivateIPs` flag in `internal/webhook/validate.go` for self-hosted local-network use.
