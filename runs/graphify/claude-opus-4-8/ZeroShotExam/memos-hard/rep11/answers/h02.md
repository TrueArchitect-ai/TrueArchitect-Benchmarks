**Delivery function — `Post` at `internal/webhook/webhook.go:120`** (the actual HTTP send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`). The async path (`PostAsync` → queue → workers, lines 42–55/184–196) ultimately calls this same `Post`.

**Protection mechanism — `safeDialContext` at `internal/webhook/webhook.go:59`**, wired into `safeClient`'s `http.Transport.DialContext` (lines 32–37). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), which matches against `reservedCIDRs` (`internal/webhook/validate.go:14` — loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents). Because the check runs on the IP actually being dialed, it also defeats DNS-rebinding.

Notes:
- There's an additional up-front check, `ValidateURL` (`internal/webhook/validate.go:62`), run when a webhook URL is configured — but the guarantee at actual delivery time is the dial-time `safeDialContext` check, since a TOCTOU/rebind could bypass validation-only.
- The protection can be globally disabled via `AllowPrivateIPs` (`internal/webhook/validate.go:41`), intended for self-hosted deployments targeting local services.
