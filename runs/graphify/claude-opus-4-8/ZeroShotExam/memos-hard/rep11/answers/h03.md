**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider-agnostic abstraction package `idp`, holding the shared `IdentityProviderUserInfo` struct (the common user-info shape any provider returns).
- `internal/idp/oauth2/oauth2.go` is the one concrete protocol implementation that ships — its header reads `// Package oauth2 implements the OAuth2 identity provider integration`, with `type IdentityProvider struct` and `NewIdentityProvider(config *storepb.OAuth2Config)` built on `golang.org/x/oauth2`. It is the only subpackage under `internal/idp/` (no SAML/OIDC siblings exist).
