**Computation site**
- The core extraction lives in `internal/markdown/markdown.go` — `(*service).ExtractProperties` (`internal/markdown/markdown.go:193`), which parses the memo content into a goldmark AST and walks it. It's invoked (together with tag extraction) via `ExtractAll`, which is called from `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74` (line 80/86). That function assigns the result to `memo.Payload.Property` — the derived, content-computed metadata (distinct from user-set payload fields).

**Triggers (what calls `RebuildMemoPayload`)**
- Memo creation: `server/router/api/v1/memo_service.go:108` (CreateMemo).
- Memo update when content changes: `server/router/api/v1/memo_service.go:447` (UpdateMemo).
- Bulk backfill: the payload runner's `RunOnce` at `server/runner/memopayload/runner.go:52`, which rebuilds every memo's payload in batches.

**Extracted properties** (`storepb.MemoPayload_Property`, filled in `ExtractProperties`, `internal/markdown/markdown.go:199-240`)
- `Title` — text of a leading H1 heading if the first block-level child of the document is an H1 (`markdown.go:208-212`).
- `HasLink` — true if any link node exists (`KindLink`).
- `HasCode` — true if any code block, fenced code block, or inline code span exists.
- `HasTaskList` — true if any task checkbox exists (`east.KindTaskCheckBox`).
- `HasIncompleteTasks` — true if any task checkbox is unchecked.

These booleans back the list/preview/filter surface (e.g., the filter schema at `internal/filter/schema.go:191-224` maps to `property.hasTaskList/hasLink/hasCode/hasIncompleteTasks`).
