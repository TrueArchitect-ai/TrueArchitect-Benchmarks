**Premise correction:** There is no GraphQL schema in this repository. The project (Memos) does not expose a GraphQL API at all — a search for "graphql" across `.go`, `.proto`, `.mod`, and `.md` files returns zero hits, and the README explicitly advertises "full REST and gRPC APIs" (`README.md:23`), not GraphQL.

**Actual API surface:** The public API is defined with **Protocol Buffers (gRPC)**, with REST exposed via grpc-gateway transcoding.

- **Schema source of truth** — the `.proto` service definitions in `proto/api/v1/`, e.g.:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, `common.proto`
- **Store-layer protos** (internal persistence models, not the public API): `proto/store/*.proto`
- **Generated code** — Go stubs, gRPC servers, and REST gateway handlers under `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`).
- **REST/OpenAPI description** — generated from the protos at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- **Build config** — `proto/buf.yaml` and `proto/buf.gen.yaml` drive codegen (buf).

So the closest thing to a "public API schema" is the protobuf definitions in `proto/api/v1/`, surfaced as gRPC + REST (OpenAPI at `proto/gen/openapi.yaml`) — there is no GraphQL layer.
