**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store/` package (`store/user.go`, `store/memo.go`, etc.), where the persistent entity structs are defined — `Memo`, `User`, `Attachment`, `Reaction`, `MemoRelation`, `MemoShare`, `IdentityProvider`, `UserIdentity`, `Inbox`, `InstanceSetting`, `UserSetting`.

Counting distinct packages **outside** the `store/` tree that reference each type (`store.<Type>`):

| Type | External packages |
|------|-------------------|
| **`store.User`** (`store/user.go:*`) | **7** — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` |
| **`store.Memo`** (`store/memo.go:*`) | **6** — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` |

`User` edges out `Memo` mainly because it's also pulled into `server/auth` and `server/router/fileserver`. The ranking is stable even if you count the in-tree DB driver packages (`store/db/{mysql,postgres,sqlite}`, `store/test`) as "outside": User = 11, Memo = 10.

Answer: **1st: User; 2nd: Memo (roughly 7 vs 6 external packages).**
