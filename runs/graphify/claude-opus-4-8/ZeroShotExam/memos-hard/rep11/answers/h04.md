**No.** Outside the driver-selection factory, the MySQL driver is never constructed directly.

Evidence:
- The factory is `NewDBDriver` in `store/db/db.go:14-32`. It switches on `profile.Driver` and calls `mysql.NewDB(profile)` at `store/db/db.go:22`.
- The MySQL driver's constructor is `func NewDB(profile *profile.Profile) (store.Driver, error)` at `store/db/mysql/mysql.go:20`.
- A repo-wide search for `mysql.NewDB` returns exactly one hit: `store/db/db.go:22` (the factory).
- A repo-wide search for imports of the `github.com/usememos/memos/store/db/mysql` package outside the package itself returns exactly one file: `store/db/db.go:8`. Since no other package imports `store/db/mysql`, no other code can reference its exported constructor (or its `DB` type) to build the driver directly.

Together, the sole importer and sole caller both being the factory means the MySQL driver is constructed nowhere else.
