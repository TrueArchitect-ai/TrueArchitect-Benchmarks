**RPC handler methods that can transitively cause an outbound HTTP request to a user-configured webhook URL** (the URL comes from `hook.Url`, set by users via the `CreateUserWebhook` RPC in `server/router/api/v1/user_service_webhooks.go`):

1. `CreateMemo` — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. `DeleteMemo` — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
3. `UpdateMemo` — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
4. `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects`
5. `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects`
6. `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`

**Convergence path:** All of these build a `WebhookRequestPayload` (with `URL = hook.Url`) and hand it to `webhook.PostAsync` in `server/router/api/v1/memo_service_webhooks.go` (the intermediate `dispatchMemoRelatedWebhook` helper covers create/update/delete). `PostAsync` enqueues onto `asyncPostQueue`, whose worker goroutines call the single delivery function.

**Convergence function — `webhook.Post` in `internal/webhook/webhook.go:120`** (`safeClient.Do(req)` at line 152 is the actual outbound request). Every path — sync or async — funnels through `Post` before the HTTP request leaves.
