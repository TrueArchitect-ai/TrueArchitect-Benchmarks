**Premise correction:** There is no Redis connection anywhere in this project, and there is no Redis-specific TTL for user entries. The premise that the cache layer is backed by Redis is incorrect — I searched the entire codebase (`grep -rli "redis"` over all `.go` files and `go.mod`) and found zero references. The cache is a custom, thread-safe **in-memory** cache, not an external store.

**Actual mechanism:**

- The cache implementation lives in `store/cache/cache.go`. It's an in-process `Cache` struct built on `sync.Map` with an `atomic.Int64` item counter and a background cleanup goroutine (`cleanupLoop`) — no network, no connection string, nothing to configure like a Redis host/port.
- The cache is instantiated and configured in `store/store.go:38-53`. The `Store.New` constructor builds one `cache.Config` and creates three separate in-memory caches from it: `instanceSettingCache`, `userCache`, and `userSettingCache` (`store/store.go:51-53`).
- User entries specifically are stored in `userCache`, written via `s.userCache.Set(...)` in `store/user.go` (e.g. lines 98, 122, 132, 143, 167) keyed by `userCacheKey(userID)` (`store/user.go:88`), read at `store/user.go:150`, and invalidated on delete at `store/user_delete.go:40`.
- **TTL for user entries: 10 minutes.** Those writes all use `Set`, which applies the cache's `DefaultTTL` (`store/cache/cache.go:93-95`). That default is set to `10 * time.Minute` in the `cacheConfig` in `store/store.go:41` (the same value also appears in the package's `DefaultConfig()` at `store/cache/cache.go:57-64`). There is no per-user `SetWithTTL` override, so user entries expire 10 minutes after write. Expired entries are removed lazily on `Get` (`cache.go:135-144`) and swept by the cleanup goroutine every `CleanupInterval` = 5 minutes (`store/store.go:42`); the cache also caps at `MaxItems: 1000` with oldest-item eviction.

So: no Redis and no Redis-configured TTL — it's an in-memory `sync.Map`-based cache configured in `store/store.go`, with user entries expiring on the shared 10-minute `DefaultTTL`.
