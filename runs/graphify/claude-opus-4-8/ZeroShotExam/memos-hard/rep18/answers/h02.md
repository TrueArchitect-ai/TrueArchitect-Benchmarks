**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120). This is where the outbound HTTP POST actually executes, via `safeClient.Do(req)` at line 152. (The async workers started in `init()` and drained by `PostAsync`/`asyncPostQueue` all funnel through `Post`.)

**Protection mechanism** — a custom `DialContext` guard, `safeDialContext` in `internal/webhook/webhook.go` (line 59), wired into the shared `safeClient`'s `http.Transport` (lines 32–37). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` → `reservedNetworks`/`reservedCIDRs` in `internal/webhook/validate.go` (lines 14–54). Because the check happens at connection time on the resolved IP, it also defeats DNS-rebinding. (A configure-time check, `ValidateURL` in `internal/webhook/validate.go:62`, exists too, but it can be bypassed by rebinding; the dial-time block is the real protection. Both can be disabled via the `AllowPrivateIPs` flag for local-network self-hosted use.)
