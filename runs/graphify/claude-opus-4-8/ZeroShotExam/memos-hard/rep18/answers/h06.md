**Handlers (all in `server/router/api/v1/`, service `APIV1Service`) that transitively fire an outbound HTTP request to a user-configured webhook URL:**

1. `CreateMemo` — `memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. `UpdateMemo` — `memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`)
3. `DeleteMemo` — `memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. `CreateMemoComment` — `memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
5. `SetMemoRelations` — `memo_relation_service.go:48` → same update side-effect path → `DispatchMemoUpdatedWebhook`
6. `SetMemoAttachments` — `memo_attachment_service.go:48` → same path → `DispatchMemoUpdatedWebhook`

The "user-configured URL" is each user's stored webhook endpoint (`hook.Url` from `s.Store.GetUserWebhooks`, registered via the `CreateUserWebhook` handler); the dispatch helpers set `payload.URL = hook.Url` and call `webhook.PostAsync` (`memo_service_webhooks.go:43,71`).

**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`.** Every path funnels here before delivery: `PostAsync` (line 184) enqueues onto `asyncPostQueue`, and the drain worker calls `Post(payload)` (line 46). `Post` builds the request to `requestPayload.URL` (`http.NewRequest("POST", requestPayload.URL, …)`, line 126) and sends it via `safeClient.Do(req)` (line 152) — the single point where the outbound HTTP request to the user-configured URL is actually issued.

(Note: `internal/httpgetter/image.go:21` and `GetLinkMetadata` also make outbound requests, but those URLs come per-request from memo content, not from user *configuration* — the webhook path is the one matching "user-configured URL.")
