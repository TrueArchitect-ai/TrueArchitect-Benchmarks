**1st: `store.User` (~6 external packages); 2nd: `store.Memo` (~4 external packages)**

The data layer is the `store/` package (`store/*.go`), which defines the persistent entity types: `Memo`, `User`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `IdentityProvider`, `UserIdentity`, `UserSetting`, `InstanceSetting` (each defined as a struct in files like `store/user.go:29`, `store/memo.go:35`, `store/attachment.go:16`, etc.).

Counting distinct Go packages **outside** the `store/` tree (excluding the `store/db/{sqlite,postgres,mysql}` drivers, which are part of the data layer) that reference each type as `store.<Type>`:

- **`store.User` — 6 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`
- **`store.Memo` — 4 packages:** `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`

Third place (`store.Attachment`) trails at ~3 packages, so `User` and `Memo` are the clear top two — `User` being the most widely referenced entity across the server layer.
