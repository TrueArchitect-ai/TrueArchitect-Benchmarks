**Premise correction:** This repository (Memos) has **no GraphQL schema at all**. There are zero occurrences of "graphql" in any `.go`/`.ts`/`.tsx`/`.proto` source, and no `.graphql`/`.gql` schema files exist anywhere in the tree. The public API is **not** GraphQL. (The lone `Schema` node graphify surfaces — `internal/filter/schema.go:60` — is a CEL-style *filter-expression* schema for query filtering, not an API schema.)

**Actual API surface — Protocol Buffers / gRPC:**

- **Schema definitions (source of truth):** `proto/api/v1/*.proto` — one `.proto` per service:
  - `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`.
  - Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`.
- **Generated code:** `proto/gen/api/v1/` — e.g. `memo_service_grpc.pb.go`, `user_service_grpc.pb.go`, and the gRPC-gateway `*.pb.gw.go` files (e.g. `memo_service.pb.gw.go:961`).
- **Server implementation / wiring:** `server/router/api/v1/` — service handlers (`memo_service.go`, `auth_service.go`, etc.) registered on `APIV1Service` in `server/router/api/v1/v1.go:22`, with `NewAPIV1Service()` at `v1.go:47` and `.RegisterGateway()` at `v1.go:65`.
- **HTTP exposure:** REST is served via the **gRPC-gateway** (the `*.pb.gw.go` handlers) plus **Connect** handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`); an OpenAPI document is embedded via `proto/openapi_embed.go`.

So the "public API schema" lives in `proto/api/v1/*.proto`, generated into `proto/gen/api/v1/` and served over gRPC + Connect + gRPC-gateway (REST/OpenAPI) — there is no GraphQL layer.
