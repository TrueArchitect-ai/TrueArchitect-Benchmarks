The outbound HTTP POST actually executes in `Post`, where the request is built and sent via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). It's driven asynchronously by four goroutine workers started in `init()` that drain `asyncPostQueue`, which `PostAsync` feeds.

**protection mechanism — `internal/webhook/webhook.go` (`safeDialContext`, lines 57–77) backed by `isReservedIP` at `internal/webhook/validate.go:44`**

SSRF protection is enforced at dial time. The shared `safeClient` uses a custom `Transport.DialContext = safeDialContext` (`webhook.go:32–37`). `safeDialContext` resolves the target hostname itself (`net.DefaultResolver.LookupHost`) and rejects the connection if *any* resolved IP satisfies `isReservedIP` — a reserved/private/loopback/link-local range. Because it checks the resolved IPs at connection time rather than the URL string, it also defeats DNS-rebinding attacks that would otherwise point the webhook at internal network addresses. The reserved-range classification logic lives in `isReservedIP` in `internal/webhook/validate.go:44`.
