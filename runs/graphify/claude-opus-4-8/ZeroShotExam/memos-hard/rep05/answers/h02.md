The webhook system (used by Memos to notify external URLs when memos change) delivers over HTTP as follows:

- **Delivery function** — `Post` at `internal/webhook/webhook.go:120`. This is where the outbound HTTP request is actually built and executed: it marshals the payload, constructs the `POST` request, optionally adds an HMAC-SHA256 signature, and fires it via `safeClient.Do(req)` (`webhook.go:152`). Enqueued dispatches from `PostAsync`/the async worker pool all funnel through this same `Post`.

- **Protection mechanism** — `safeDialContext` at `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (`webhook.go:32-37`). At dial time it resolves the target hostname and rejects the connection if any resolved IP satisfies `isReservedIP` (`internal/webhook/validate.go:44`), which blocks reserved/private/internal ranges. Because the check runs on the actually-resolved IPs at connection time, it also defeats DNS-rebinding attempts.

**Answer:** delivery function — `Post`, `internal/webhook/webhook.go:120`; protection mechanism — `safeDialContext` (backed by `isReservedIP`), `internal/webhook/webhook.go:59` (and `internal/webhook/validate.go:44`).
