## h14.

**Computation site**

The derived metadata is the memo's `Payload.Property` (plus `Payload.Tags`), computed — not user-set — in `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74-88`. That function delegates the actual content parsing to the goldmark markdown service's `ExtractAll`, implemented at `internal/markdown/markdown.go:355-422`, which does a single AST walk over the memo content. The results are exposed to clients (lists/previews) via `convertMemoPropertyFromStore` at `server/router/api/v1/memo_service_converter.go:315-325`.

**Triggers (what causes recomputation)**

- **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` on the new memo (`server/router/api/v1/memo_service.go:107`).
- **Content update** — `UpdateMemo` recomputes only when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:446-449`).
- **Bulk rebuild** — the background `Runner.RunOnce` re-derives the payload of *all* memos in batches of 100, calling `RebuildMemoPayload` then persisting via `UpdateMemo` (`server/runner/memopayload/runner.go:27-72`).

**Extracted properties** (`internal/markdown/markdown.go:383-408`)

- `Title` — text of an H1 heading, only if it is the document's first block-level child (`markdown.go:384-388`).
- `HasLink` — true if any `KindLink` node exists (`:393-394`).
- `HasCode` — true for any code block, fenced code block, or code span (`:396-397`).
- `HasTaskList` — true if any task checkbox is present (`:399-400`).
- `HasIncompleteTasks` — true if any task checkbox is unchecked (`:401-404`).
- Alongside the property struct, `ExtractAll` also collects deduplicated `Tags` (`#tags`), which `RebuildMemoPayload` assigns to `memo.Payload.Tags` (`runner.go:85`).
