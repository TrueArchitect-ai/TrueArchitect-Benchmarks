**Premise correction:** This repository (the *memos* project) has **no GraphQL schema and no GraphQL API at all.** A search for `graphql` across all `.go`, `.ts`, and `.proto` files returns zero matches. **Actual API surface:** The public API is defined with **Protocol Buffers (gRPC) plus a gRPC-Gateway REST layer**, not GraphQL:

- **Schema/IDL source** — `proto/api/v1/*.proto`, one file per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`. - **Service wiring** — `server/router/api/v1/v1.go`: `APIV1Service` (line 22), constructed by `NewAPIV1Service()` (line 47), which exposes the REST/JSON surface via `.RegisterGateway()` (line 65).
