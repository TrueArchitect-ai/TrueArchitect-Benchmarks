**Markdown processing sits behind the `markdown.Service` interface** (`internal/markdown/markdown.go:31-55`), which defines `ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, and `RenameTag`.

**impl** — There is exactly one concrete implementation: the unexported struct `service` (`internal/markdown/markdown.go:58-60`), which wraps a `goldmark.Markdown` and executes at runtime. It is only ever returned as the interface type `Service` from `NewService` (`markdown.go:85-113`). (Internally its `RenderMarkdown`/`RenameTag` methods also spin up a concrete `renderer.NewMarkdownRenderer()` at `markdown.go:250,451`, but that renderer is not itself behind the `Service` interface.)

**construction** — `markdown.NewService(...)` is the sole factory. In the running server it's called once, inside `NewAPIV1Service` (`server/router/api/v1/v1.go:48-51`), enabling `WithTagExtension()` and `WithMentionExtension()`; that single instance is stored on the API service (`v1.go:56`). `NewAPIV1Service` itself is invoked from `server/server.go:76`. (Tests construct their own via `server/router/api/v1/test/test_helper.go:44`, `server/router/rss/rss_test.go:54`, `server/router/fileserver/fileserver_test.go:427`.)

**holders** — Components that hold the `markdown.Service` interface:
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — the owner that constructs it.
- `rss.RSSService.MarkdownService` (`server/router/rss/rss.go:45`), given the API service's instance via `NewRSSService(..., apiV1Service.MarkdownService)` at `server/server.go:85`.
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`, ctor `NewRunner` at :19), and the package-level `RebuildMemoPayload(..., markdownService markdown.Service)` (`runner.go:74`), which receives `s.MarkdownService` from the memo service at `server/router/api/v1/memo_service.go:108` and `:447`.

So the same instance created in `NewAPIV1Service` flows to the RSS service and to the memopayload rebuild path.
