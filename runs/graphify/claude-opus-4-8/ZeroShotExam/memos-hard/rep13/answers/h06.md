**Answer**

At least six RPC handler methods can transitively trigger an outbound HTTP request to a user-configured webhook URL. All of them dispatch webhooks whose destination is `hook.Url` (fetched via `Store.GetUserWebhooks`, i.e. user-configured):

**RPC handlers (all in `server/router/api/v1/`):**
1. `CreateMemo` — `memo_service.go:70` → `DispatchMemoCreatedWebhook` (`memo_service.go:157`)
2. `UpdateMemo` — `memo_service.go:401` → `dispatchMemoUpdatedSideEffects` (`memo_service.go:513`) → `DispatchMemoUpdatedWebhook`
3. `DeleteMemo` — `memo_service.go:518` → `DispatchMemoDeletedWebhook` (`memo_service.go:562`)
4. `CreateMemoComment` — `memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)
5. `SetMemoRelations` — `memo_relation_service.go:16` → `dispatchMemoUpdatedSideEffects` (`memo_relation_service.go:48`)
6. `SetMemoAttachments` — `memo_attachment_service.go:16` → `dispatchMemoUpdatedSideEffects` (`memo_attachment_service.go:48`)

The three memo-related dispatch helpers (`DispatchMemoCreated/Updated/DeletedWebhook`) all funnel through `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), and along with `DispatchMemoCommentCreatedWebhook` they all call `webhook.PostAsync`, which enqueues onto `asyncPostQueue`. The queue workers then invoke the actual sender.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`

That is the single function where every path converges before delivery: it builds the request (`http.NewRequest("POST", requestPayload.URL, …)`, line 126) and performs the outbound call `safeClient.Do(req)` (line 152) to the user-configured URL. The async workers call it at `internal/webhook/webhook.go:46` (`Post(payload)`).
