**Computation site**

- The extraction logic lives in `internal/markdown/markdown.go`, in the goldmark `service.ExtractAll(content)` method (`markdown.go:355`), which walks the parsed markdown AST in a single pass and populates an `ExtractedData{Tags, Mentions, Property}`. (The dedicated `ExtractProperties` at `markdown.go:193` does the same property extraction; `ExtractAll` is the combined single-parse path actually used.)
- It is invoked through the wrapper `RebuildMemoPayload(ctx, memo, markdownService)` at `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns the results onto the memo: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:85-86`). The property struct itself is defined at `store/memo.go:87-90`.

**Triggers (what causes recomputation)**

- **Memo creation** — `APIV1Service.CreateMemo` calls `RebuildMemoPayload` on the new memo (`server/router/api/v1/memo_service.go:108`).
- **Memo content update** — `APIV1Service.UpdateMemo` calls `RebuildMemoPayload` only when the update mask includes the `content` path (`memo_service.go:436-449`); non-content updates (e.g. visibility) do not recompute it.
- **Batch rebuild** — `memopayload.Runner.RunOnce` (`runner.go:27-72`) iterates all memos in batches of 100, calling `RebuildMemoPayload` then `UpdateMemo` for each, to regenerate the derived payload across the whole store.

**Extracted properties**

Computed from the content's markdown AST and stored in `memo.Payload`:
- `Tags` — all `#tags` found (via `asMemoTagNode`), plus `Mentions` (`@username`) collected in the same walk.
- `Property.Title` — text of the document's first block if it is an H1 heading (`markdown.go:384-388`).
- `Property.HasLink` — true if any link node exists (`KindLink`).
- `Property.HasCode` — true for code block / fenced code / code span nodes.
- `Property.HasTaskList` — true if any task checkbox exists (`east.KindTaskCheckBox`).
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (`!checkBox.IsChecked`) (`markdown.go:392-405`; fields declared at `store/memo.go:87-90`).

These booleans/tags drive list filtering (`store/test/memo_filter_test.go`) and user stats (`server/router/api/v1/user_service_stats.go:141-151`).
