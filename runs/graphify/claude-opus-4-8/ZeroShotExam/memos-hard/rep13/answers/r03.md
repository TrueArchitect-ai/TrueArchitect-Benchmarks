**Premise correction:** There is no cron scheduler in this repository, and no nightly database-cleanup job exists — so there is no scheduled time to report.

What the codebase actually has:

- Background work is started in `server/server.go:153` (`startBackgroundRunners`). The only runner wired up there is the S3 presign runner (`server/server.go:162-170`).
- These runners are driven by a Go `time.NewTicker`, **not** a cron scheduler. In `server/runner/s3presign/runner.go:27` the interval is `runnerInterval = time.Hour * 12` (every 12 hours), used at `runner.go:30`. This is a fixed relative interval, not a wall-clock time like "nightly at 2:00 AM."
- There is no cron/scheduler dependency (e.g. `robfig/cron` or `gocron`) in `go.mod`, and no runner performs database cleanup.

So both the "cron scheduler" and the "nightly database-cleanup job" in the question are false premises — neither exists in this repo.
