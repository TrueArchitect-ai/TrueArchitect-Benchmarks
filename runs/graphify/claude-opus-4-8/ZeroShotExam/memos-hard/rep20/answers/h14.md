**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark markdown service `(*service).ExtractAll` in `internal/markdown/markdown.go:355`. The result is stored into `memo.Payload.Property` (and `memo.Payload.Tags`) at `runner.go:85-86`. This derived data is not user-set — it's parsed from the memo's markdown content in a single AST walk.

**Triggers (operations that recompute it):**
- **Create memo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before insert.
- **Update memo** — `server/router/api/v1/memo_service.go:447` calls it when content changes.
- **Batch rebuild of all memos** — `Runner.RunOnce` iterates every memo in batches and calls `RebuildMemoPayload` + `UpdateMemo` (`server/runner/memopayload/runner.go:27-72`), e.g. a migration/backfill pass.

**Extracted properties** (the `storepb.MemoPayload_Property`, built in `ExtractAll`, `markdown.go:391-408`, plus title):
- `Title` — text of a leading H1 heading if the document's first block is one (`markdown.go:384-388`).
- `HasLink` — true if any link node exists (`KindLink`).
- `HasCode` — true for any code block/fenced code/code span.
- `HasTaskList` — true if any task checkbox is present (`east.KindTaskCheckBox`).
- `HasIncompleteTasks` — true if any task checkbox is unchecked.

(Alongside these, `ExtractAll` also collects `Tags` and `Mentions`, stored separately; the `Property` struct is the derived preview/list metadata. These fields are surfaced to the API via `convertMemoPropertyFromStore` in `server/router/api/v1/memo_service_converter.go:315` and used in list filtering/stats, e.g. `internal/filter/schema.go:191,224` and `server/router/api/v1/user_service_stats.go`.)
