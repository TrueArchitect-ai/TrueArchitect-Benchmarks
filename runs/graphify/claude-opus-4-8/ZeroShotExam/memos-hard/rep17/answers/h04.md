Evidence:

- The driver-selection factory is `NewDBDriver` in `store/db/db.go:14`, which calls `mysql.NewDB(profile)` at `store/db/db.go:22`. This is the *only* call to `mysql.NewDB` anywhere in the codebase (grep for `mysql.NewDB` returns just this one line).
- The MySQL driver type is the `DB` struct. `NewDB` itself builds it at `store/db/mysql/mysql.go:29` (`driver := DB{profile: profile}`).
- Outside the factory, the `DB` struct is constructed directly in one place: `store/db/mysql/auth_config_test.go:12` — `db := &DB{}` — an empty in-package instance used to test the `IsRetryableAuthenticationMutationError` helper. This bypasses `NewDB` entirely (no profile, no DB connection).

So in production/non-test code the MySQL driver is constructed only through `mysql.NewDB` inside the factory; the single direct construction is a unit test creating a zero-value `&DB{}`.
