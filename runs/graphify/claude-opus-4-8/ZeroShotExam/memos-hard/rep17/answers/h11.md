h11.

**1st: `store.User`; 2nd: `store.Memo`**

Of the persistent entity types defined in the data layer (the `store` package — `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/reaction.go`, `store/inbox.go`, etc.), **`User`** is referenced from the most external packages, followed by **`Memo`**.

Rough package counts (distinct Go packages outside the `store/` tree that reference `store.<Type>`):

| Type | External packages |
|------|------|
| **User** | ~7 |
| **Memo** | ~6 |
| Attachment | 4 |

The external packages referencing `store.User` are: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`. `store.Memo` is used by the same set minus `server/auth`/`fileserver` but adds `server/runner/memopayload`.

The ranking holds regardless of whether the `store/db/{sqlite,postgres,mysql}` driver subpackages and `store/test` are counted as inside or outside the layer: including them the counts are User 11 / Memo 10; excluding the whole `store/` tree they are User 7 / Memo 6. Either way `User` is 1st and `Memo` is 2nd.

Evidence: type definitions in `store/user.go` (`type User struct`) and `store/memo.go` (`type Memo struct`); references such as `server/auth/authenticator.go`, `server/router/api/v1/user_service.go`, `server/router/rss/rss.go`, and `server/runner/memopayload/`.
