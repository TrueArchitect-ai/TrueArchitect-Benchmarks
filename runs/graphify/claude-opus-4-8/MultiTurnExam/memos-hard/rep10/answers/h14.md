**Extracted (derived) properties** written to the memo payload:
- `Tags` — the `#tags` parsed from content (`ExtractedData.Tags`, markdown.go:22, assigned at runner.go:85).
- `Property` (`storepb.MemoPayload_Property`, assembled in markdown.go:199-240):
  - `Title` — text of a leading H1 heading, if the first block is one (markdown.go:210-212)
  - `HasLink` — content contains a link (markdown.go:216-217)
  - `HasCode` — content has a code block/fenced block/inline code span (markdown.go:219-220)
  - `HasTaskList` — content has task-list checkboxes (markdown.go:222-223)
  - `HasIncompleteTasks` — at least one unchecked task checkbox (markdown.go:224-227)

These are computed from content (not user-set) and used for list/preview features like filtering and snippets.
