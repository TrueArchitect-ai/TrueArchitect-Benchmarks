**1st: `store.User` — 2nd: `store.Memo`.**

Data layer = the `store` package (entity structs defined in `store/*.go`, e.g. `store/user.go`, `store/memo.go`). Counting distinct *packages outside the data layer* that reference each persistent entity type:

- **`User` (1st)** — referenced from ~6 external packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` (plus the `server/router/api/v1/test` helper). It's the most widely-referenced entity.
- **`Memo` (2nd)** — referenced from ~4 external packages: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

(If the three DB-driver subpackages `store/db/{sqlite,mysql,postgres}` are counted as "outside" rather than as part of the data layer, the totals rise to 9 for `User` and 7 for `Memo`, but the ranking is unchanged.) Next behind them are `Attachment` (~6 incl. drivers) and `Inbox`/`MemoShare` (~5 incl. drivers).
