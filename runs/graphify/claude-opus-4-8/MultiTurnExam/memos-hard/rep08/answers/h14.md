**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll([]byte(memo.Content))` and writes the result onto `memo.Payload`: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (lines 85-86). The actual parsing/extraction lives in the markdown service: `(*service).ExtractAll` — `internal/markdown/markdown.go:356`, which does a single goldmark AST walk.

**Triggers (operations that recompute it):**
- **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` before insert.
- **UpdateMemo** — `server/router/api/v1/memo_service.go:447` (inside `UpdateMemo`) recomputes it when the memo's content is changed.
- (Also a bulk backfill path exists: `memopayload.Runner.RunOnce` at `server/runner/memopayload/runner.go:27` rebuilds every memo's payload in batches — but per the codebase this runner isn't wired into startup, so in practice recomputation happens on create/update.)

**What the computation extracts** (into `MemoPayload`, `proto/gen/store/memo.pb.go`):
- **`Tags`** — the list of `#tags` found in the content (collected from tag AST nodes).
- **`Property`** (`MemoPayload_Property`), derived by walking the AST (`internal/markdown/markdown.go:387-226`):
  - `Title` — text of a leading level-1 (`#`) heading if the first block is an H1.
  - `HasLink` — content contains a link.
  - `HasCode` — content contains a code block/fenced code/inline code span.
  - `HasTaskList` — content contains a task checkbox.
  - `HasIncompleteTasks` — content has at least one unchecked task item.

(Note: `ExtractAll` also gathers `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` to the memo's derived payload.)
