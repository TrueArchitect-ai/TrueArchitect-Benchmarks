**RPC handler methods that can transitively trigger an outbound HTTP request to a user-configured webhook URL** (≥3):

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`.
2. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`.
3. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:67`) → `DispatchMemoUpdatedWebhook`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`.
5. (Also **`SetMemoRelations`** at `memo_relation_service.go:48` and **`SetMemoAttachments`** at `memo_attachment_service.go:48`, which both go through `dispatchMemoUpdatedSideEffects`.)

Each `Dispatch*` helper loads the memo owner's configured webhooks (`GetUserWebhooks`), fills in `payload.URL = hook.Url`, and hands off to delivery.

**Convergence function:** `webhook.PostAsync` — `internal/webhook/webhook.go:184`. Every dispatch path funnels through this single enqueue function (the memo-related paths via `dispatchMemoRelatedWebhook` at `memo_service_webhooks.go:70`, and the comment path directly at `memo_service_webhooks.go:41`), which queues the payload for the worker pool that calls `Post` → `safeClient.Do` for the actual outbound HTTP request.
