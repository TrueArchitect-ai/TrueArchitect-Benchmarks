**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the outbound HTTP POST actually executes at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`). `PostAsync` (line 184) just enqueues onto a bounded channel whose worker goroutines call `Post` (init loop, lines 42-55).

**Protection mechanism:** SSRF protection via `safeDialContext` — `internal/webhook/webhook.go:59`, installed as the `DialContext` of the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` — `internal/webhook/validate.go:44` (checked against `reservedNetworks`/`reservedCIDRs`, `internal/webhook/validate.go:11-36`). Because the check happens at connection dial time on the resolved IPs, it also defeats DNS-rebinding. There is additionally an up-front `ValidateURL` (`internal/webhook/validate.go:62`) that enforces http/https scheme and the same reserved-IP rejection when a webhook URL is registered, and an `AllowPrivateIPs` escape hatch (`internal/webhook/validate.go:41`) that disables the guard for local-network deployments.
