Details:

- **Provider abstraction** — the `idp` package at `internal/idp/idp.go` defines the provider-agnostic contract, `IdentityProviderUserInfo` (identifier, display name, email, avatar URL), the normalized shape every identity provider returns.
- **Concrete protocol implementation** — the `oauth2` subpackage at `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration"). It provides `IdentityProvider` backed by a `storepb.OAuth2Config` (`oauth2.go:19-21`), constructed via `NewIdentityProvider` (`oauth2.go:27`), with `ExchangeToken` (`oauth2.go:45`) and `UserInfo` (`oauth2.go:82`) returning the abstraction's `idp.IdentityProviderUserInfo`. OAuth2 is the only concrete protocol that ships.
