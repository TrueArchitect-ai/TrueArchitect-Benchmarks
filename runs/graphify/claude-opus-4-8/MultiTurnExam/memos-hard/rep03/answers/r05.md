**Premise correction: there is no GraphQL schema — the public API is not GraphQL.** Searching the Go sources, `go.mod`, and the tree for any GraphQL artifact (`graphql`, `gqlgen`, `graphene`, `*.graphql`, `schema.graphql`) returns nothing. No GraphQL server, resolver, or schema file exists.

**Actual API surface:** The public API is defined in **Protocol Buffers** and served over **gRPC / Connect + gRPC-Gateway (REST/JSON)**:

- The schema (service + message definitions) lives in `.proto` files under `proto/api/v1/`, one per service: `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. Each declares a gRPC `service` (e.g. `service MemoService {` at proto/api/v1/memo_service.proto:17, `service UserService {` at proto/api/v1/user_service.proto:17).
- Generated Go bindings are in `proto/gen/api/v1/` (including the Connect handlers under `proto/gen/api/v1/apiv1connect/`).
- These are wired up and served in `server/router/api/v1/v1.go` — the Connect handlers with interceptors (`v1.go:133-141`) and a gRPC-Gateway mux exposing REST at `/api/v1/...` and `/file/*` (`v1.go:95-129`).
- There is additionally an MCP endpoint (`server/router/mcp/`) that re-exposes curated operations from the same OpenAPI/proto surface — but again, no GraphQL.

So the "GraphQL schema for the public API" doesn't exist; the API contract is the set of protobuf definitions in `proto/api/v1/*.proto`, served via gRPC/Connect and a REST gateway.
