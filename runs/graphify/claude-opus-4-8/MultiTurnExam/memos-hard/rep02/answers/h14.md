**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll([]byte(memo.Content))` and writes the results onto the memo's derived payload: `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The actual extraction logic lives in the goldmark-backed `service.ExtractAll` — `internal/markdown/markdown.go` (the `ExtractAll` method), which walks the parsed AST in a single pass. (There's also a bulk backfill path, `memopayload.Runner.RunOnce` at `server/runner/memopayload/runner.go:27`, which re-runs `RebuildMemoPayload` over every memo — though it's not wired into startup.)

**Triggers (operations that recompute it):**
- `CreateMemo` — always, when a memo is created: `server/router/api/v1/memo_service.go:108`.
- `UpdateMemo` — only when the `content` field is in the update mask (i.e., the content actually changed): guarded by `if path == "content"` (`server/router/api/v1/memo_service.go:435-436`) leading to `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:447`.

**What the computation extracts** (from the content markdown, into `MemoPayload`):
- `Tags` — all `#tags` found in the content.
- `Property.Title` — text of a leading H1 heading, if the document's first block is a level-1 heading.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block/fenced code/inline code span is present.
- `Property.HasTaskList` — true if any task-list checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(Mentions are also collected during the same walk but are not stored into the memo payload by `RebuildMemoPayload`.)
