**Abstraction package:** `internal/idp` — `internal/idp/idp.go` defines the provider-neutral abstraction (e.g. the `IdentityProviderUserInfo` struct that any provider maps its user data into).

**Implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go`, which implements the OAuth2 identity provider integration (`IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`). It's the only concrete protocol implementation that ships under `internal/idp/`.

Answer: `internal/idp` (abstraction) — `internal/idp/idp.go`; `internal/idp/oauth2` (implementation) — `internal/idp/oauth2/oauth2.go`.
