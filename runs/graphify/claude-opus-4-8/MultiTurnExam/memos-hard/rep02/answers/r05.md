**Premise correction:** There is no GraphQL API or GraphQL schema in this repository. A search for `graphql`/`gqlgen`/`.graphql` across the codebase returns nothing, and there is no GraphQL dependency in `go.mod`. So there is no GraphQL schema file to point to.

**Actual API surface:** The public API is defined with **Protocol Buffers (gRPC)**, served over Connect-RPC and a gRPC-Gateway (JSON/REST) transcoder — not GraphQL. The schema/service definitions live in `proto/api/v1/*.proto`:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- plus shared types in `proto/api/v1/common.proto`

These compile to Go stubs under `proto/gen/api/v1/`, and the server wires them up (Connect interceptors + gRPC-Gateway mux) in `server/router/api/v1/v1.go:95-141`. Storage-side message types are separately defined in `proto/store/*.proto`.

Answer: premise is wrong (no GraphQL exists); the public API is a Protobuf/gRPC surface defined in `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`), exposed via Connect + gRPC-Gateway and wired in `server/router/api/v1/v1.go`.
