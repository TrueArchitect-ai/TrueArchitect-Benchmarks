**Premise correction:** There is no GraphQL schema in this repository. No `.go` file references `graphql`/`gqlgen`/`graph-gophers`, `go.mod` declares no GraphQL library, and there are no `.graphql`/`.gql` schema files. So there is no GraphQL API to point to.

**Actual API surface:** The public API is a **Protocol Buffers / gRPC** API, exposed over HTTP via Connect and gRPC-Gateway (REST/JSON):
- The API contracts (the real "schema") are the `.proto` service definitions in `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, plus `common.proto`.
- These generate Go stubs under `proto/gen/api/v1/` (including `*.pb.go`, gRPC-gateway `*.pb.gw.go`, and Connect `apiv1connect/*.connect.go`).
- Handlers implementing them live in `server/router/api/v1/` (e.g. `memo_service.go`), registered with Connect interceptors and the gRPC-gateway in `server/router/api/v1/v1.go`.

So the API is defined by protobuf service definitions served through gRPC/Connect + a REST gateway — not GraphQL.
