**Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider abstraction, the `IdentityProviderUserInfo` struct that all providers return (`Identifier`, `DisplayName`, `Email`, `AvatarURL`).

**Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the one concrete protocol implementation that ships — an OAuth2 `IdentityProvider` (with PKCE support) that does `ExchangeToken` and user-info retrieval, driven by `storepb.OAuth2Config`.
