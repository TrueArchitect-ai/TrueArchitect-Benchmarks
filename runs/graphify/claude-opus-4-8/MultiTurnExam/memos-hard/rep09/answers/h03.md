The provider abstraction is defined in the **`idp`** package at `internal/idp/idp.go` (declares `IdentityProviderUserInfo`, the common user-info shape identity providers return). The one concrete protocol implementation that ships is the **`oauth2`** package at `internal/idp/oauth2/oauth2.go` (`// Package oauth2 implements the OAuth2 identity provider integration`, with `IdentityProvider`, `NewIdentityProvider`, and `UserInfo`).

Answer: **`internal/idp` (abstraction); `internal/idp/oauth2` (implementation)**
