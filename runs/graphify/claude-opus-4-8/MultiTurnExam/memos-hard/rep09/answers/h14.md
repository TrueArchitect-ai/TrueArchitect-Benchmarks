The derived metadata is the memo's **payload** (`storepb.MemoPayload` — its `Tags` list and `Property` flags), computed from `memo.Content`.

**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:356`) and assigns `memo.Payload.Tags` / `memo.Payload.Property`. The underlying extraction logic lives in the goldmark-backed `service` (`internal/markdown/markdown.go`, e.g. `ExtractProperties` at `:193` and `ExtractAll` at `:356`).

**Triggers (recomputation)** — three production call sites of `RebuildMemoPayload`:
- **Memo create** — `server/router/api/v1/memo_service.go:108` (`CreateMemo`).
- **Memo update (content changed)** — `server/router/api/v1/memo_service.go:447` (`UpdateMemo`).
- **Bulk backfill/rebuild** — `server/runner/memopayload/runner.go:52` (the `Runner.RunOnce` batch job that rebuilds all memos' payloads; note this runner isn't wired into startup in production).

**Extracted properties** — from the content's parsed markdown AST:
- `Tags` — the list of `#tags` (via `ExtractAll`/`ExtractTags`).
- `Property.HasLink` — content contains a link (`markdown.go:394`/`:217`).
- `Property.HasCode` — contains code (inline/code block) (`markdown.go:397`/`:220`).
- `Property.HasTaskList` — contains a task list (`markdown.go:400`/`:223`).
- `Property.HasIncompleteTasks` — has at least one unchecked task item (`markdown.go:403`/`:226`).
