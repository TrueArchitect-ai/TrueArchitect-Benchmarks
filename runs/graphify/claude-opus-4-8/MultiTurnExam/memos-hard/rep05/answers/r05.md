**Premise correction: there is no GraphQL API in this repository, so there is no GraphQL schema to locate.** A repo-wide search for `graphql`, `gqlgen`, or `.graphql` schema files in the Go code returns nothing.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC) service definitions** compiled with `buf`, exposed at runtime over both **Connect RPC and gRPC-Gateway (JSON/REST)** — not GraphQL.

- The schema/IDL lives in `.proto` files under `proto/api/v1/`: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, plus `common.proto` (with shared store messages under `proto/store/`).
- Codegen is driven by `buf` (`proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`), producing the Go stubs in `proto/gen/api/v1/`.
- The generated services are served via gRPC-Gateway and Connect handlers, registered in `RegisterGateway` at `server/router/api/v1/v1.go:64`, with a shared ACL/authorizer used by both the Connect interceptor and the gRPC-Gateway middleware (`server/router/api/v1/authz.go`, `connect_interceptors.go`, `acl_config.go`).

So the "schema for the public API" is the protobuf definitions in `proto/api/v1/`, served over gRPC/Connect + REST, and there is no GraphQL layer.
