**delivery function** — `Post` (which sends the HTTP POST via `safeClient.Do(req)`) — `internal/webhook/webhook.go:120` (the actual dispatch call at `internal/webhook/webhook.go:152`). Async dispatch is enqueued by `PostAsync` and drained by worker goroutines in `init()` that call `Post`.

**protection mechanism** — `safeDialContext`, the custom `DialContext` on the shared `safeClient`'s `http.Transport` — `internal/webhook/webhook.go:59`. At dial time it resolves the target hostname (`internal/webhook/webhook.go:65`) and rejects any resolved address in a reserved/private range via `isReservedIP` (`internal/webhook/webhook.go:71`), returning "connection to reserved/private IP address is not allowed". Because the check happens on the actually-resolved IPs at dial time, it also defeats DNS-rebinding attempts to reach internal network addresses.
