**computation site:** The derived metadata is the memo's `Payload` (tags + boolean `Property`). It is assembled by `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates the actual content parsing to the goldmark-backed markdown service `(*service).ExtractAll` at `internal/markdown/markdown.go:356`. `RebuildMemoPayload` copies the result into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:85-86`).

**triggers (operations that cause recomputation):**
- `CreateMemo` — always, at `server/router/api/v1/memo_service.go:108`.
- `UpdateMemo` — only when the content field is being changed; the call is inside the `content` update branch after `memo.Content = request.Memo.Content` at `server/router/api/v1/memo_service.go:447` (guarded block starting ~`:446`).
- (Also `memopayload.Runner.RunOnce`/`Run` calls it in a batch rebuild loop at `server/runner/memopayload/runner.go:52`, but per h08 that `Runner` is never constructed in production, so it doesn't run at runtime.)

**extracted properties** (from `ExtractAll`, a single goldmark AST walk — `internal/markdown/markdown.go:356`):
- `Tags` — the list of `#tags` (from memo-tag AST nodes).
- `Property.Title` — text of a leading H1 heading, if the document's first block is an H1.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block / fenced code / inline code span is present.
- `Property.HasTaskList` — true if any task checkbox exists; and `Property.HasIncompleteTasks` — true if any checkbox is unchecked.

(`Mentions` are also collected in the same walk, but `RebuildMemoPayload` only persists `Tags` and `Property` into the payload.) These are content-derived, not user-set, and back list/preview rendering.
