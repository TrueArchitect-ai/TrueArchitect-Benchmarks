**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:356`) on `memo.Content` and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:85-86`). The actual AST walk that derives the metadata lives in `service.ExtractAll` (`internal/markdown/markdown.go:356-420`).

**Triggers (operations that recompute it):**
- `CreateMemo` — every memo creation (`server/router/api/v1/memo_service.go:108`).
- `UpdateMemo` — when the memo's content is changed (the `content` update branch, after `memo.Content = request.Memo.Content`) at `server/router/api/v1/memo_service.go:446-447`.
- (Also a bulk backfill path exists via `memopayload.Runner.RunOnce`/`Run` at `server/runner/memopayload/runner.go:27,74`, but that runner is not constructed/invoked in production code, so it isn't a live trigger.)

**Extracted properties** (from `ExtractAll`, stored in the memo's `MemoPayload`, `proto/gen/store/memo.pb.go:85-92`):
- `Tags` — the set of `#tags` in the content, deduplicated (`memo.Payload.Tags`).
- `Property.Title` — text of a leading H1 heading, if the document's first block is an H1.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains a code block/fenced block/inline code span.
- `Property.HasTaskList` — content contains a task-list checkbox.
- `Property.HasIncompleteTasks` — at least one task checkbox is unchecked.

(Note: `ExtractAll` also computes `Mentions` — lowercased `@username`s — but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload; mentions are used elsewhere, not stored in this derived metadata.)
