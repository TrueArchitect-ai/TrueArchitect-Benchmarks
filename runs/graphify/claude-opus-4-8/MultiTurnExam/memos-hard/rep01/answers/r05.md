**Premise correction:** There is no GraphQL API in this repository. A search for `graphql`/`gqlgen`/`.graphql`/`.gql` finds nothing in the Go source or `go.mod` — no GraphQL schema is defined anywhere.

**Actual API surface:** The public API is defined with **Protocol Buffers**, served over **gRPC / Connect (with a REST/HTTP gateway)**:
- The schema/service definitions live in `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`.
- Generated Go code lives in `proto/gen/api/v1/` (e.g. `*_grpc.pb.go`, and REST-gateway stubs `*.pb.gw.go`).
- The server implements these services in `server/router/api/v1/` (the `APIV1Service` handlers) and exposes them via Connect handlers (`server/router/api/v1/connect_services.go`, `connect_interceptors.go`).

So the API is proto-defined and reachable as gRPC/Connect RPCs and their HTTP/REST gateway mappings — not GraphQL.
