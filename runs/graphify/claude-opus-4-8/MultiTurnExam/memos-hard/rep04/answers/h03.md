**Abstraction package — `internal/idp` (`internal/idp/idp.go`); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

- The `internal/idp` package defines the provider abstraction: `internal/idp/idp.go` declares `IdentityProviderUserInfo`, the common user-info shape that any identity provider returns.
- The one concrete protocol implementation that ships is `internal/idp/oauth2`, whose `IdentityProvider` struct and `NewIdentityProvider(config *storepb.OAuth2Config)` constructor (`internal/idp/oauth2/oauth2.go:20`, `oauth2.go:27`) implement OAuth2 authentication. It is the only subpackage under `internal/idp`.
