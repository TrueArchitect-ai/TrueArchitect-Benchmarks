**1st: `User` (~6 packages); 2nd: `Memo` (~4 packages)**

Both are persistent entity types defined in the data layer (`store/user.go` `type User struct`, `store/memo.go` `type Memo struct`). Counting distinct packages *outside* the data layer (i.e. excluding `store/` and its subpackages such as the `store/db/{sqlite,postgres,mysql}` drivers, and excluding `_test.go` files) that reference each type:

- **`store.User` — 6 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`.
- **`store.Memo` — 4 packages:** `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

Next closest is `store.Attachment` at ~3 packages, so `User` and `Memo` are the clear top two. (Counts are approximate — they reflect distinct package directories referencing `store.<Type>` in non-test Go files; including the in-tree data-layer driver packages would add the same three to each and not change the ranking.)
