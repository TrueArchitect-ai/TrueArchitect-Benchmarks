**Premise correction:** There is no GraphQL schema anywhere in this repository. A search across Go sources, module files, and `*.graphql` files for `graphql`/`gqlgen`/`schema.graphql` returns nothing — the public API is not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC) services**, served over both Connect and a gRPC-Gateway REST/JSON bridge.

- **Schema definitions:** the `.proto` files in `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, plus shared `common.proto`. Each declares a gRPC `service` with RPC methods and HTTP annotations (for the REST gateway). Generated Go code lives under `proto/gen/api/v1/`.
- **How it's served:** the API is wired up in `server/router/api/v1/v1.go` — a Connect handler chain with interceptors (`connectHandler.RegisterConnectHandlers(...)`, `v1.go:133-141`) and a gRPC-Gateway mux exposing the same services as REST/JSON with an auth middleware (`v1.go:69-97`). The concrete RPC handlers are implemented on `APIV1Service` in `server/router/api/v1/*.go` (e.g. `memo_service.go`, `user_service.go`).

So instead of a GraphQL schema, the public API contract is the set of protobuf service definitions in `proto/api/v1/*.proto`, consumed via gRPC/Connect and gRPC-Gateway REST.
