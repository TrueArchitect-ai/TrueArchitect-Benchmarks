The `CreateMemo` RPC maps to **POST /api/v1/memos** in the REST gateway.

This is defined by the `google.api.http` annotation on the RPC in `proto/api/v1/memo_service.proto:21-25`:

```proto
rpc CreateMemo(CreateMemoRequest) returns (Memo) {
  option (google.api.http) = {
    post: "/api/v1/memos"
    body: "memo"
  };
```
