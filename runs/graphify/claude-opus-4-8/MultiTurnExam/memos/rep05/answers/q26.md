By explicit cascade code in `Store.DeleteMemo` (`store/memo.go:140`):

- **memo_relation** — deleted where the memo is source and where it is target (`store/memo.go:142-146`)
- **attachment** — each attachment linked to the memo is deleted via `Store.DeleteAttachment` (`store/memo.go:149-157`; that method affects only the `attachment` row plus external storage, no further DB tables)
- **memo** — the memo row itself, deleted last (`store/memo.go:158`)

So: **memo_relation, attachment, memo**. (Other memo-related tables like `memo_organizer`, `memo_share`, and `reaction` are not touched by DeleteMemo's cascade code.)
