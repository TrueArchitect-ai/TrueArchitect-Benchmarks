- **interceptor path**: web/src/connect.ts — the `authInterceptor` (defined ~line 156), which attaches `Authorization: Bearer <token>` and does reactive refresh on 401 (token state helpers in `web/src/auth-state.ts`).
- **token kinds**: a short-lived **access token** (JWT, held in memory, sent as the `Bearer` header) and a **refresh token** (sent as an HTTP-only cookie via `credentials: "include"`, used by `refreshToken()` to mint new access tokens). The backend additionally accepts **Personal Access Tokens (PAT)**, though the frontend interceptor only manages access/refresh.
- **backend package path**: server/auth (`server/auth/authenticator.go` — `Authenticator` with `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`), invoked from the Connect `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go`.
