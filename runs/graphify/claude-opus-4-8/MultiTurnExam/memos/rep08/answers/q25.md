- **engine + path**: Google CEL (Common Expression Language), via `github.com/google/cel-go`, wrapped in the project's own filter engine at `internal/filter/` (parser at `internal/filter/parser.go`, engine at `internal/filter/engine.go`, SQL rendering at `internal/filter/render.go`).
- **mechanism**: The CEL filter string is parsed and compiled into a dialect-agnostic intermediate representation, then rendered to SQL by `render.go` for the requested `DialectName` (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`) — each dialect's memo driver (e.g. `store/db/sqlite/memo.go:61`) calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect…, &where, &args)` to append the generated `WHERE` conditions and bound arguments to its query.
