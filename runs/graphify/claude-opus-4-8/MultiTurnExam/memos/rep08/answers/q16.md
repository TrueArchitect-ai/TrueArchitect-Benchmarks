Per `store.DeleteMemo` in `store/memo.go:140-158`, before deleting the memo row itself the store layer deletes:

- **memo_relation** records where the memo is the source (`MemoID`)

(Separately, the API handler `DeleteMemo` in `server/router/api/v1/memo_service.go:567-577` first recursively deletes comment memos before calling the store delete for the memo itself; each of those recursive calls also runs the relation/attachment cleanup above.)
