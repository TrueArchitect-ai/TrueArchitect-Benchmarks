**Interceptor path:** web/src/connect.ts — the Connect `Interceptor` sets the `Authorization: Bearer <token>` header, backed by the token store in `web/src/auth-state.ts` and a refresh manager (`createTokenRefreshManager` / `doRefreshAccessToken`); requests also send `credentials: "include"` so the refresh cookie flows.

**Token kinds it manages:** a short-lived **access token** (JWT, held in memory / auth-state, attached as the Bearer header) and a **refresh token** (delivered via HTTP-only cookie, used to mint new access tokens); the backend additionally accepts **Personal Access Tokens (PAT)** as Bearer tokens.

**Backend validation package:** server/auth (`server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`, `AuthenticateToUser`; Bearer parsing in `server/auth/extract.go`, JWT logic in `server/auth/token.go`).
