In `Store.DeleteMemo` (`store/memo.go`), before deleting the memo row itself the store layer deletes:

- **memo_relation records where the memo is the source** (`MemoID` = this memo)
- **memo_relation records where the memo is the target** (`RelatedMemoID` = this memo)
- **attachments linked to the memo** (looked up via `ListAttachments` by `MemoID`, then each deleted with `DeleteAttachment`)

It then calls `driver.DeleteMemo` to remove the memo row last.

(Separately, at the API layer in `server/router/api/v1/memo_service.go:518`, comment memos are deleted first — each recursing back into `Store.DeleteMemo` — but within the store layer itself the records deleted before the memo row are memo relations and attachments.)
