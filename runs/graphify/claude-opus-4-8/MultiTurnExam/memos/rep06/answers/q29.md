**Interceptor path:** `web/src/connect.ts` — the ConnectRPC auth `Interceptor` sets `Authorization: Bearer <token>` (`setAuthorizationHeader`, line 97-99) and reactively refreshes on 401; token state helpers live in `web/src/auth-state.ts`. A separate refresh transport uses `credentials: "include"` (line 60/65) to send the refresh cookie.

**Token kinds:**
- **Access token** — short-lived JWT, held client-side (via `getAccessToken`/`setAccessToken`) and sent as a `Bearer` header.
- **Refresh token** — sent as an httpOnly cookie (`credentials: "include"`), exchanged via `AuthService.refreshToken`.
- **Personal Access Token (PAT)** — also accepted as a `Bearer` token for programmatic access.

**Backend package:** `server/auth` — the `Authenticator` validates each kind: `AuthenticateByAccessTokenV2` / `ParseAccessTokenV2`, `AuthenticateByRefreshToken` (validated against the DB), and `AuthenticateByPAT` (`server/auth/authenticator.go`, with token parsing in `server/auth/token.go`).
