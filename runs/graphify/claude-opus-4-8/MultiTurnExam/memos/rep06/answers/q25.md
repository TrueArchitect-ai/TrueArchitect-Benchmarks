**Engine:** Google CEL (Common Expression Language, via `github.com/google/cel-go`) — the filter engine lives in `internal/filter/` (env/parse in `internal/filter/engine.go`, e.g. `cel.NewEnv` at line 25; SQL rendering in `internal/filter/render.go`).

**Mechanism:** The CEL filter string is parsed into an AST/IR by the `internal/filter` engine, then each dialect driver calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)` (`store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`), which renders the expression into a dialect-specific SQL `WHERE` clause with bound args based on the `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) branches in `render.go`.
