Events → dispatch functions (all in `server/router/api/v1/memo_service_webhooks.go`):
- memo created (`memos.memo.created`): `DispatchMemoCreatedWebhook`
- memo updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook`
- memo deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook`
- comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook`

The first three funnel through the helper `dispatchMemoRelatedWebhook`; all four ultimately converge on **`webhook.PostAsync`** in `internal/webhook/webhook.go` (which calls `Post` for HTTP delivery).
