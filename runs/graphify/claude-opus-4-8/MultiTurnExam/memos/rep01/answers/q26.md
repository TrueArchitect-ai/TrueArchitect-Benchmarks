`memo`, `memo_relation`, `attachment`

When `DeleteMemo` runs, `store.DeleteMemo` (`store/memo.go:140-158`) explicitly deletes `memo_relation` rows (both directions) and the memo's `attachment` rows, then the `memo` row itself. The API handler (`server/router/api/v1/memo_service.go:518+`) additionally deletes comment memos via `store.DeleteMemo`, which recurses through the same three tables. (Reactions are only listed for the webhook payload, not deleted, and attachment deletion only removes `attachment` rows plus the backing storage file — no other table.)
