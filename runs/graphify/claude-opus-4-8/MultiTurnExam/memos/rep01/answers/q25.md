**Engine:** Google CEL (Common Expression Language, via `github.com/google/cel-go`), wrapped by the `internal/filter` package — `internal/filter/engine.go` (parser at `internal/filter/parser.go`, SQL rendering at `internal/filter/render.go`).

**Mechanism:** The CEL `Engine` parses each filter string into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`) and then `render.go` compiles it to dialect-specific SQL + args (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`); each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`) calls `filter.DefaultEngine()` + `filter.AppendConditions(...)` to append the generated WHERE clauses to its query.
