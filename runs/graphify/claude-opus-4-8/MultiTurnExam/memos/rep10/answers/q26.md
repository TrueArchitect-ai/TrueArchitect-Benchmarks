**memo, memo_relation, attachment**

`Store.DeleteMemo` (`store/memo.go:140-158`) explicitly deletes `memo_relation` rows (both `memo_id` and `related_memo_id` directions) and each linked `attachment` (via `DeleteAttachment`), then the `memo` row itself. The API handler additionally recurses into comment memos (`server/router/api/v1/memo_service.go:573-577`), but those touch the same three tables. Reactions are not removed by explicit cascade code in this path.
