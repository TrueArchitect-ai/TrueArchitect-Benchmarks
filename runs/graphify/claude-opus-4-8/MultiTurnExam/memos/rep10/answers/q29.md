- **Interceptor path:** `web/src/connect.ts` — a ConnectRPC `Interceptor` that attaches `Authorization: Bearer <token>` (helper `setAuthorizationHeader`), with proactive refresh-on-focus and reactive refresh-on-401 logic. Token storage lives in `web/src/auth-state.ts` (access token in `localStorage`).

- **Token kinds it manages:** short-lived **access tokens** (JWT, held in localStorage, sent as `Authorization: Bearer`) and **refresh tokens** (sent via credentialed cookie — `credentials: "include"` — and exchanged through `AuthService.refreshToken` to rotate the access token). The backend additionally supports **personal access tokens (PAT)**.

- **Backend validation package:** `server/auth` (the `Authenticator` in `server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`; token parsing in `server/auth/token.go`).
