Within the store layer (`store/memo.go:140-158`), `Store.DeleteMemo` deletes, before removing the memo row itself:

- **memo_relation records where the memo is the source** (`MemoID`)
- **memo_relation records where the memo is the target** (`RelatedMemoID`)
- **attachments linked to the memo** (each removed via `DeleteAttachment`)

Then it deletes the memo row via `driver.DeleteMemo`.

(Note: at the API layer, `server/router/api/v1/memo_service.go:567-577` additionally deletes the memo's comment memos first — each of which recurses through this same store cleanup — but the store layer itself deletes relations and attachments before the memo row.)
