**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (lines 156-178), backed by token helpers in `web/src/auth-state.ts`.

**Token kinds it manages:** short-lived **access tokens** (sent as `Authorization: Bearer <token>`) and **refresh tokens** (sent via cookie with `credentials: "include"`, used to obtain new access tokens on 401/expiry). Personal Access Tokens (PATs) are also a supported bearer credential on the backend.

**Backend package that validates them:** `server/auth` — the `Authenticator` (`server/auth/authenticator.go`) with `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT`.
