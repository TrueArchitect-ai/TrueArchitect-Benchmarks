Server-Sent Events (SSE); SSEHub implemented in /bench/home/work/server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment broadcast through it

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The hub is implemented in `/bench/home/work/server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through the SSE hub are:
- **CreateMemo** (broadcasts memo.created event)
- **UpdateMemo** (broadcasts memo.updated event via dispatchMemoUpdatedSideEffects)
- **DeleteMemo** (broadcasts memo.deleted event)
- **CreateMemoComment** (broadcasts memo.comment.created event)
