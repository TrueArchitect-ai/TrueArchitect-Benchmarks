The frontend's `authInterceptor` (defined in `/bench/home/work/web/src/connect.ts` lines 156-178) manages:
1. **Access Tokens** — short-lived JWT tokens from auth-state for immediate API calls
2. **Refresh Tokens** — long-lived JWT tokens stored in cookies, used to obtain new access tokens when they expire
3. **Personal Access Tokens (PAT)** — alternative tokens prefixed with "memos_pat_" for programmatic access

The backend validation is handled by the `server/auth` package (files: `/bench/home/work/server/auth/authenticator.go`, `/bench/home/work/server/auth/token.go`), which validates these tokens via the `AuthInterceptor` in `/bench/home/work/server/router/api/v1/connect_interceptors.go`.
