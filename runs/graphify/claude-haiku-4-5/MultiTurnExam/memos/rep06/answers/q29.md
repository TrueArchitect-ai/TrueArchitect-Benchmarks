Frontend authInterceptor (web/src/connect.ts:156-178) extracts tokens and manages their lifecycle via getRequestToken() and setAccessToken(). It sends access tokens in Authorization headers and refresh tokens via credentials cookies. Backend server/auth/authenticator.go validates tokens via AuthenticateByAccessTokenV2 (JWT), AuthenticateByRefreshToken (cookie), and AuthenticateByPAT (programmatic access). The server-side AuthInterceptor (server/router/api/v1/connect_interceptors.go:205) calls Authorizer.Authenticate(), which delegates to the authenticator package for validation. Failed auth (401) triggers automatic frontend token refresh via refreshAccessToken().
