CEL (Common Expression Language) — /bench/home/work/internal/filter/engine.go; The filter engine parses CEL expressions into a dialect-agnostic condition tree using `google/cel-go`, then renders it to dialect-specific SQL via the `Render` method with `DialectSQLite`, `DialectMySQL`, or `DialectPostgres` options passed at database query time.

The ListMemos RPC accepts filter expressions in **CEL (Common Expression Language)** syntax. The parsing engine lives in `/bench/home/work/internal/filter/engine.go` (using the `google/cel-go` library). The filter becomes SQL through a two-step process: (1) the CEL expression is compiled into a dialect-agnostic condition tree, and (2) at database query time in each dialect driver (sqlite/mysql/postgres), `filter.AppendConditions()` calls `engine.CompileToStatement()` with the appropriate `DialectSQLite`, `DialectMySQL`, or `DialectPostgres` option to render the condition tree into dialect-specific SQL WHERE clauses.
