Frontend API requests are authenticated via the **auth interceptor** in `/bench/home/work/web/src/connect.ts` (line 156). The interceptor manages two token kinds:
1. **Access token** (short-lived, 15 minutes) — used for API requests via the Authorization header
2. **Refresh token** (long-lived, 30 days) — stored in cookies and used to obtain new access tokens

Token validation and management on the backend happens in the **github.com/usememos/memos/server/auth** package (located at `/bench/home/work/server/auth/`), which provides JWT token parsing, validation, and generation using the `golang-jwt/jwt/v5` library.
