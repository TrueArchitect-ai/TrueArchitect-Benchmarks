CEL (Common Expression Language) — /bench/home/work/internal/filter/; The filter engine parses CEL expressions into a dialect-agnostic condition tree, then the renderer converts it to SQL for each dialect by substituting dialect-specific column expressions and functions.

The ListMemos RPC accepts filter expressions in **CEL (Common Expression Language)** syntax, defined in `/bench/home/work/internal/filter/`. The `Engine` (in `engine.go`) parses CEL expressions into a dialect-agnostic condition tree (via `parser.go`), and the `renderer.go` converts the condition tree into dialect-specific SQL by substituting dialect-appropriate column expressions, functions, and string concatenation operators (e.g., `||` for PostgreSQL/SQLite vs. `CONCAT()` for MySQL) defined in the Schema's `Expressions` map for each `DialectName`.
