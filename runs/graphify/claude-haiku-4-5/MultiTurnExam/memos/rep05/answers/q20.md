Server-Sent Events (SSE); /bench/home/work/server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment

The mechanism used is **Server-Sent Events (SSE)**, which allows the server to push live events to connected browsers. The hub is implemented in `/bench/home/work/server/router/api/v1/sse_hub.go` as the `SSEHub` type. The following memo handlers broadcast events through it:
1. **CreateMemo** - broadcasts `SSEEventMemoCreated`
2. **UpdateMemo** - broadcasts `SSEEventMemoUpdated` (via `dispatchMemoUpdatedSideEffects`)
3. **DeleteMemo** - broadcasts `SSEEventMemoDeleted`
4. **CreateMemoComment** - broadcasts `SSEEventMemoCommentCreated`
