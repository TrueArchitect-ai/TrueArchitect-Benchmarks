When DeleteMemo runs, the following tables are affected:
- **memo**: explicitly deleted via s.driver.DeleteMemo
- **memo_relation**: explicitly deleted via s.driver.DeleteMemoRelation (both as source and target)
- **attachment**: explicitly deleted via s.DeleteAttachment (for all attachments linked to the memo)
- **memo_share**: cascade-deleted via the FOREIGN KEY constraint with ON DELETE CASCADE (memo_share.memo_id → memo.id)
