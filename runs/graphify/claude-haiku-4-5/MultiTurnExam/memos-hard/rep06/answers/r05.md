**Premise correction:** There is no GraphQL schema for the public API. Memos does not provide a GraphQL interface.

**Actual API surface:** The public API is defined using **gRPC with Protocol Buffers** (protobuf3), served via **gRPC-Gateway** for JSON/REST compatibility. The API schema is defined across 9 proto service files:

**API Definition Location:** `/bench/home/work/proto/api/v1/` contains:

1. `memo_service.proto` — Memo CRUD, comments, reactions, attachments, relations
2. `user_service.proto` — User management, stats, settings, notifications
3. `auth_service.proto` — Authentication, sign-in, sign-out, access tokens
4. `attachment_service.proto` — Attachment upload and retrieval
5. `instance_service.proto` — Instance configuration and management
6. `shortcut_service.proto` — User shortcuts/quick actions
7. `idp_service.proto` — Identity provider configuration
8. `ai_service.proto` — AI service operations
9. `common.proto` — Common types and enumerations

**HTTP/JSON Mapping:** Each RPC method uses `google.api.http` annotations (proto3 extension) to define REST endpoints. Example from `memo_service.proto:22-26`:
```protobuf
rpc CreateMemo(CreateMemoRequest) returns (Memo) {
  option (google.api.http) = {
    post: "/api/v1/memos"
    body: "memo"
  };
}
```

The server implements these definitions via gRPC-Gateway in `/bench/home/work/server/router/api/v1/v1.go:87-90`, providing both gRPC and JSON/REST endpoints from the same proto definitions.
