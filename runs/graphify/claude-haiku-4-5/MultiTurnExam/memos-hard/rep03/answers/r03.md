This notification confirms my r03 answer. There is no nightly cron-scheduled database cleanup job. The scheduler infrastructure exists at `internal/scheduler/` with full cron support, but it is never instantiated or used in production server code. Only the S3 presign runner is active (running every 12 hours). Cleanup of expired data (like memo shares) happens on-demand via API calls or at access time, not on a nightly schedule.
