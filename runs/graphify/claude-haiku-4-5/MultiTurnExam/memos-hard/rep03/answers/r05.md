This notification confirms and expands on my r05 answer. The API uses Protocol Buffers (gRPC) with gRPC-Gateway and Connect-RPC. Additionally:

- **OpenAPI/Swagger schema** is auto-generated at `proto/gen/openapi.yaml` (4057-line specification)
- **Proto definitions** are in `proto/api/v1/` for services like AuthService, MemoService, UserService, etc.
- **Generated gateway code** is in `proto/gen/api/v1/*.pb.gw.go`
- **gRPC-Gateway registration** happens in `server/router/api/v1/v1.go`
- **Connect-RPC** provides browser-friendly RPC support for `/memos.api.v1.*` paths
