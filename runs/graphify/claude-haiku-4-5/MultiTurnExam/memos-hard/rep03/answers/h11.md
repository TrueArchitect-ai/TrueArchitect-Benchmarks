1st: User (6 external packages); 2nd: Memo (5 external packages)

User, defined in `store/user.go`, is referenced from the largest number of packages outside the data layer (6 distinct external packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`). Memo, defined in `store/memo.go`, ranks second, referenced from 5 distinct external packages (`server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss`, `server/runner/memopayload`).
