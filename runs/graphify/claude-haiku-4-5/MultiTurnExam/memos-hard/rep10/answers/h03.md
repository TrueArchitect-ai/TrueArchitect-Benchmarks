**Abstraction package — `internal/idp`; Implementation package — `internal/idp/oauth2`**

The `internal/idp` package defines the provider abstraction via the `IdentityProviderUserInfo` struct in `/bench/home/work/internal/idp/idp.go`, which specifies the output data structure (Identifier, DisplayName, Email, AvatarURL) that any identity provider must produce.

The concrete OAuth2 protocol implementation ships in `internal/idp/oauth2`, with the main implementation at `/bench/home/work/internal/idp/oauth2/oauth2.go`. This provides the `IdentityProvider` type with `ExchangeToken()` and `UserInfo()` methods, supporting configurable field mapping and PKCE. Currently OAuth2 is the only shipped protocol implementation, though the proto schema at `/bench/home/work/proto/store/idp.proto` is designed to support future protocol extensions.
