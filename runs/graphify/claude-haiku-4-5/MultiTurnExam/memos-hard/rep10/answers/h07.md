The browser requests `/file/users/{username}/avatar`, which routes to `serveUserAvatar()`. This calls `getUserByUsername()` to look up the user via the store layer, which queries the database for the user record. The database driver executes a SQL query on the `user` table filtering by username and returns the `avatar_url` column (stored as a base64-encoded data URI). Back in the fileserver, `parseDataURI()` decodes the data URI to extract the binary image data, which is then returned to the browser with appropriate Content-Type headers.
