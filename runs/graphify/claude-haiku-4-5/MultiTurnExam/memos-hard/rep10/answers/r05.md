The API uses a hybrid architecture: **gRPC + gRPC-Gateway (REST)** for `/api/v1/*` endpoints, and **Connect RPC** for browser-based `/memos.api.v1.*` endpoints. An auto-generated OpenAPI specification is available at `/bench/home/work/proto/gen/openapi.yaml`. The server implements these via Echo at `/bench/home/work/server/server.go` and `/bench/home/work/server/router/api/v1/v1.go`.
