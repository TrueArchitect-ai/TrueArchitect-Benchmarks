**Premise correction**: There is no per-user API rate-limiting middleware registered in this codebase. The server does not implement request rate limiting. The only concurrency/resource limiting mechanisms present are:

1. Thumbnail generation semaphore (limits concurrent thumbnail creation to 3 simultaneous operations) — `server/router/fileserver/fileserver.go:46`
2. Image processing semaphore (limits concurrent image processing to 2 simultaneous operations) — `server/router/api/v1/v1.go:60`
3. Async webhook queue with fixed size (128 pending webhooks) — `internal/webhook/webhook.go:39`

These are resource-based constraints, not user-based API rate limiting.
