**Premise correction**: There is no nightly database-cleanup job scheduled in this codebase. While there is a scheduler package defined at `internal/scheduler/` with cron expression parsing capabilities, it is not instantiated or used anywhere in the running application. The codebase performs no scheduled database maintenance or cleanup operations. The only scheduled maintenance that runs is the S3 presigner runner (`server/runner/s3presign/runner.go`) which refreshes S3 attachment URLs every 12 hours, and the cache cleanup loops which run at configurable intervals but are not database-level operations.
