**Premise correction**: There is no GraphQL schema for the public API. The API is not GraphQL-based.

**Actual API surface**: The public API is defined using Protocol Buffers (protobuf) in the `/proto/api/v1/` directory. The main service definitions are:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachment operations
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — Shortcut management

The API uses gRPC and gRPC-Gateway (HTTP/REST transcoding) as specified by the `google.api.http` annotations in the proto files (e.g., `proto/api/v1/memo_service.proto:22-25`). The generated Go code from these protos is at `proto/gen/api/v1/`.
