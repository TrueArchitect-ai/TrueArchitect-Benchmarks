**Premise correction:** There is no GraphQL schema for the public API. GraphQL is not used.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) with gRPC and HTTP annotations. The service definitions are in `/bench/home/work/proto/api/v1/` directory with individual `.proto` files for each service:
- `/bench/home/work/proto/api/v1/memo_service.proto` (MemoService)
- `/bench/home/work/proto/api/v1/user_service.proto` (UserService)
- `/bench/home/work/proto/api/v1/auth_service.proto` (AuthService)
- `/bench/home/work/proto/api/v1/attachment_service.proto` (AttachmentService)
- `/bench/home/work/proto/api/v1/instance_service.proto` (InstanceService)
- `/bench/home/work/proto/api/v1/idp_service.proto` (IdentityProviderService)
- `/bench/home/work/proto/api/v1/ai_service.proto` (AIService)
- `/bench/home/work/proto/api/v1/shortcut_service.proto` (ShortcutService)

These are compiled to Go code and served via gRPC-Gateway (REST) and Connect handlers, not GraphQL.
