r05. Premise correction: There is no GraphQL schema for the public API. Actual API surface: The public API is defined using Protocol Buffers (protobuf) in gRPC and Connect RPC services. The schema files are located in /bench/home/work/proto/api/v1/ and include:
- memo_service.proto (MemoService)
- user_service.proto (UserService)
- auth_service.proto (AuthService)
- attachment_service.proto (AttachmentService)
- instance_service.proto (InstanceService)
- ai_service.proto (AIService)
- idp_service.proto (IdentityProviderService)
- shortcut_service.proto (ShortcutService)
- common.proto (shared types)

The services are exposed via both native gRPC and HTTP+JSON through the Connect RPC protocol (google.api.http annotations in the proto files define REST endpoints).
