r02. **Premise correction**: There is no per-user API rate-limiting middleware registered in this codebase. 

The only request size limits enforced are:
- Global maximum API request body size: 256 MB (256 << 20 bytes) defined at `server/router/api/v1/v1.go:20`, applied uniformly to all requests via `http.MaxBytesHandler()` (line 126, 141, 144)

The server registers only two middleware globally (`server/server.go:51-52`):
1. `middleware.Recover()` — panic recovery
2. `newCORSMiddleware()` — CORS handling

There is no per-user rate limiting, request throttling, or API quota enforcement implemented in this codebase. Request handling is unlimited by request count; only request body size is constrained.
