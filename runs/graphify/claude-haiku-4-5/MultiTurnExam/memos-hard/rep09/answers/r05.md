r05. **Premise correction**: There is no GraphQL schema defined in this codebase. The public API does not use GraphQL.

**Actual API surface**: The API is defined using Protocol Buffers (protobuf) with gRPC and gRPC-Gateway HTTP support. The API definitions are located in:
- `proto/api/v1/` directory containing `.proto` files
- Key service definitions:
  - `proto/api/v1/memo_service.proto` — memo operations
  - `proto/api/v1/user_service.proto` — user management
  - `proto/api/v1/auth_service.proto` — authentication
  - `proto/api/v1/attachment_service.proto` — attachments
  - `proto/api/v1/instance_service.proto` — instance settings
  - And others (ai_service, idp_service, shortcut_service)

The generated Go code from these protobuf definitions is in `proto/gen/api/v1/` and exposed via both gRPC (Connect protocol) and REST (gRPC-Gateway) endpoints in `server/router/api/v1/`.
