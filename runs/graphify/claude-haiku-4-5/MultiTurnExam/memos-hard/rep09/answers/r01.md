r01. **Premise correction**: The cache layer does not use Redis; it uses an in-memory cache instead.

**Actual mechanism**: The cache is configured in `store/store.go:40-45` where a `cache.Config` is created with:
- **DefaultTTL: 10 minutes** (applies to user entries and all other cached data)
- CleanupInterval: 5 minutes
- MaxItems: 1000

The user cache instance is created at `store/store.go:52` via `cache.New(cacheConfig)`. The cache implementation is thread-safe in-memory storage (store/cache/cache.go:66-85) using `sync.Map` with TTL-based expiration. The default TTL of 10 minutes applies uniformly to all cache entries, including user cache entries stored via `userCache.Set()` or `userCache.SetWithTTL()` calls.
