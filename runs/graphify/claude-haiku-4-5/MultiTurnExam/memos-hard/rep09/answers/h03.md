h03. `github.com/usememos/memos/internal/idp`; `github.com/usememos/memos/internal/idp/oauth2`

The abstraction is defined in the `idp` package (`internal/idp/idp.go`), which defines `IdentityProviderUserInfo` struct containing the standardized user information fields (Identifier, DisplayName, Email, AvatarURL). 

The concrete implementation shipped is OAuth2, located in `internal/idp/oauth2/oauth2.go`, which implements the `IdentityProvider` type with methods for `ExchangeToken()` (converts authorization code to access token with PKCE support) and `UserInfo()` (fetches and maps user information from the OAuth2 provider's userinfo endpoint).
