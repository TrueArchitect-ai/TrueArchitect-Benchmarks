**Premise correction:** There is no GraphQL schema in this codebase. The public API is not GraphQL-based.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC and gRPC-Gateway. The API schema is defined in `.proto` files located at `/bench/home/work/proto/api/v1/`:

- `/bench/home/work/proto/api/v1/auth_service.proto` - Authentication service
- `/bench/home/work/proto/api/v1/user_service.proto` - User management
- `/bench/home/work/proto/api/v1/memo_service.proto` - Memo management  
- `/bench/home/work/proto/api/v1/attachment_service.proto` - Attachments
- `/bench/home/work/proto/api/v1/instance_service.proto` - Instance/server settings
- `/bench/home/work/proto/api/v1/ai_service.proto` - AI features
- `/bench/home/work/proto/api/v1/idp_service.proto` - Identity provider configuration
- `/bench/home/work/proto/api/v1/shortcut_service.proto` - Shortcuts
- `/bench/home/work/proto/api/v1/common.proto` - Common types

The server exposes both gRPC endpoints and REST/HTTP endpoints via gRPC-Gateway (registered in `/bench/home/work/server/router/api/v1/v1.go:88-98`).
