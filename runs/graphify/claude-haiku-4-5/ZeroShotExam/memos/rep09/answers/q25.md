**Engine + Path:** CEL (Common Expression Language) via `github.com/google/cel-go`; implemented in `/bench/home/work/internal/filter/engine.go`

**Mechanism:** The Engine (filter/engine.go:Engine) parses CEL filter strings to a dialect-agnostic condition tree via cel-go (Compile → buildCondition), then a renderer (filter/render.go) converts that condition tree to dialect-specific SQL (SQLite, MySQL, PostgreSQL) with parameterized placeholders, applied via AppendConditions (filter/helpers.go:9) in each backend's ListMemos (e.g., store/db/sqlite/memo.go:61).
