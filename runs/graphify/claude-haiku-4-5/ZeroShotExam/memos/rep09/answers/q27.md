**Mechanism**: Go's `embed` package embedding compiled static files into the binary and serving them via Echo middleware's `StaticWithConfig`.

**File**: `/bench/home/work/server/router/frontend/frontend.go`

The compiled React frontend files are embedded into the Go binary at build time using the `//go:embed dist/*` directive (line 20-21), and then served in production through Echo's static file middleware (line 54-57) which serves the embedded `dist` directory. The frontend assets (HTML, CSS, JS) are built into the binary itself, so no separate file serving is needed—the entire application ships as a single Go executable.
