**Mechanism:** Server-Sent Events (SSE)

**Hub path:** `/bench/home/work/server/router/api/v1/sse_hub.go`

**Handler names:** `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`

These are the event type names broadcast through the SSEHub from service handlers in `memo_service.go`, `memo_update_helpers.go`, `memo_service_comments.go`, and `reaction_service.go`. The hub is initialized in `/bench/home/work/server/router/api/v1/v1.go` as part of the APIV1Service and manages subscriptions via the `/api/v1/sse` HTTP endpoint.

Note: There are no "memo handlers" in the React useMemo sense that broadcast events. Instead, the client uses React Query cache invalidation triggered by SSE events received through `useLiveMemoRefresh.ts`.
