For a fresh SQLite install, the single file that provides the complete current schema is:

**store/migration/sqlite/LATEST.sql**

This file contains all the CREATE TABLE statements and indexes needed to set up a complete SQLite database from scratch, including: system_setting, user, user_setting, memo, memo_relation, attachment, idp, inbox, reaction, tag, memo_tag, memo_share, and user_identity tables, along with their indexes.
