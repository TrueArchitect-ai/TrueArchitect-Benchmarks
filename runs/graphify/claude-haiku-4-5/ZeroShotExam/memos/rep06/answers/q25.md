**Engine + Path**: CEL (Common Expression Language) via `github.com/google/cel-go`; engine implementation at `internal/filter/engine.go`.

**Mechanism in one sentence**: The engine parses CEL expressions into a dialect-agnostic intermediate representation (IR) of Condition objects, then the renderer in `render.go` walks that IR and emits SQL fragments with dialect-specific syntax (SQLite `?` placeholders, PostgreSQL `$n`, handling JSON/timestamp conversions per dialect), which are composed by `filter.AppendConditions()` and executed via prepared statements in each database driver (`store/db/{sqlite,mysql,postgres}/memo.go`).
