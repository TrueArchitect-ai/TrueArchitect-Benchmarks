**Mechanism:** Go's `embed` filesystem (Go's standard `embed` package)

**File:** `/bench/home/work/server/router/frontend/frontend.go`

The compiled React frontend is embedded directly into the Go binary at compile time using the `//go:embed dist/*` directive (line 20). This embeds all files from the `dist/` folder (built by Vite) into the binary. The `FrontendService.Serve()` method (line 41) then uses Echo's `StaticWithConfig` middleware to serve these embedded files as static assets, with an SPA fallback that routes unmatched paths to `index.html` for client-side routing.
