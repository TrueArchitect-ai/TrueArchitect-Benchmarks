**Mechanism:** Go's `//go:embed` directive embedding compiled frontend assets into the binary

**File:** `/bench/home/work/server/router/frontend/frontend.go`

The mechanism works as follows:

1. The React frontend is built via Vite (line 11 of `/bench/home/work/web/package.json`): `vite build --mode release --outDir=../server/router/frontend/dist`
2. The built assets are placed in `/bench/home/work/server/router/frontend/dist/`
3. In `/bench/home/work/server/router/frontend/frontend.go` line 20-21, the Go embed directive embeds all files from the `dist/` directory:
   ```go
   //go:embed dist/*
   var embeddedFiles embed.FS
   ```
4. The `FrontendService.Serve()` method (line 41) uses this embedded filesystem via Echo's static middleware to serve the compiled frontend
5. The compiled Go binary is built in the Docker build process, embedding these files directly into the executable
