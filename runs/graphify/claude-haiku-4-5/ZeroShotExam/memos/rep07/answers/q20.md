**Server-Sent Events (SSE)**; `/bench/home/work/server/router/api/v1/sse_hub.go`; `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`

The server uses **Server-Sent Events** to push live updates to browsers. The **SSEHub** is implemented in `server/router/api/v1/sse_hub.go` as a thread-safe hub that manages client connections and broadcasts events. The hub is exposed via the `/api/v1/sse` HTTP endpoint and filters events based on user permissions.

The following **memo handler broadcasts** occur:
- `memo.created` (memo_service.go:163)
- `memo.updated` (memo_update_helpers.go:71)
- `memo.deleted` (memo_service.go:585)
- `memo.comment.created` (memo_service_comments.go:126)
- `reaction.upserted` and `reaction.deleted` (reaction_service.go)

On the client side, the `useLiveMemoRefresh` hook in `web/src/hooks/useLiveMemoRefresh.ts` connects to this SSE stream and invalidates React Query caches in response to these events.
