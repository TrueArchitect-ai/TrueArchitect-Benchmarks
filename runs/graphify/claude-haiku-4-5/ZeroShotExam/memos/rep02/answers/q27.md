**Answer: Go `embed.FS`; `/bench/home/work/server/router/frontend/frontend.go`**

The compiled React frontend is served in production using Go's `embed.FS` (embedded filesystem). The mechanism is defined in `/bench/home/work/server/router/frontend/frontend.go` where:

1. The compiled frontend files from `dist/` are embedded into the binary using the `//go:embed dist/*` directive (line 20)
2. The `FrontendService.Serve()` method (line 41) uses Echo's `StaticWithConfig` middleware to serve these embedded files
3. An SPA fallback middleware (line 63) redirects non-existent paths to `index.html` to support client-side routing

The build process (in `/bench/home/work/web/package.json` line 11) outputs the compiled frontend to `../server/router/frontend/dist` where it gets embedded.
