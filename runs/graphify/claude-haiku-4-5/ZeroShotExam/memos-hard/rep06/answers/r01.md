**Premise Correction:** There is no Redis connection in this repository. The cache layer does not use Redis.

**Actual Mechanism:** The cache layer is implemented as an in-memory cache in Go with the following configuration:

- **Cache Configuration:** `/bench/home/work/store/cache/cache.go` (lines 41-64)
- **Store Cache Initialization:** `/bench/home/work/store/store.go` (lines 40-45)

**User Entry TTL:** **10 minutes** (`DefaultTTL: 10 * time.Minute` defined at `/bench/home/work/store/cache/cache.go:59`)

The cache maintains three separate in-memory stores for different data types (userCache, userSettingCache, instanceSettingCache), all using the same 10-minute default TTL. A background cleanup routine runs every 5 minutes to remove expired entries, and the cache enforces a maximum capacity of 1000 items.
