h03.

**Abstraction package:** `internal/idp` (defines `IdentityProviderUserInfo` abstraction in `/bench/home/work/internal/idp/idp.go`)

**Implementation package:** `internal/idp/oauth2` (concrete OAuth2 provider implementation in `/bench/home/work/internal/idp/oauth2/oauth2.go`)

The repository uses `golang.org/x/oauth2` as the underlying protocol library for the OAuth2 implementation. The concrete `IdentityProvider` type in the oauth2 package handles token exchange and user info mapping according to the `storepb.OAuth2Config` configuration defined in protobuf (`/bench/home/work/proto/store/idp.proto`).
