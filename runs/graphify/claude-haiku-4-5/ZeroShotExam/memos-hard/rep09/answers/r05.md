**Premise correction**: This repository does not have a GraphQL schema. The public API is defined using Protocol Buffers (gRPC), not GraphQL.

**Actual API surface**: The API is defined in Protocol Buffer service definitions located at `/bench/home/work/proto/api/v1/`. The main services include:
- `/bench/home/work/proto/api/v1/memo_service.proto` (MemoService)
- `/bench/home/work/proto/api/v1/user_service.proto` (UserService)
- `/bench/home/work/proto/api/v1/auth_service.proto` (AuthService)
- `/bench/home/work/proto/api/v1/instance_service.proto` (InstanceService)
- `/bench/home/work/proto/api/v1/attachment_service.proto` (AttachmentService)
- `/bench/home/work/proto/api/v1/ai_service.proto` (AIService)
- `/bench/home/work/proto/api/v1/idp_service.proto` (IDPService)
- `/bench/home/work/proto/api/v1/shortcut_service.proto` (ShortcutService)

The API follows Google API Improvement Proposals (AIPs) and is exposed as both gRPC and REST endpoints (e.g., `/api/v1/memos`).
