**Premise correction:** This repository uses a **protobuf-based API (gRPC/REST)**, not GraphQL.

**Actual API surface:**

The GraphQL schema for the public API is **not applicable** — the public API is defined using **Protocol Buffers**.

**Where the public API schema is defined:**

1. **Source of truth:** `/bench/home/work/proto/api/v1/` — contains protobuf definitions:
   - `memo_service.proto` — Memo CRUD, comments, shares, reactions
   - `user_service.proto` — User management, settings, webhooks, access tokens
   - `auth_service.proto` — Authentication endpoints
   - `instance_service.proto` — Instance configuration
   - `attachment_service.proto` — File attachments
   - `ai_service.proto` — AI transcription
   - `idp_service.proto` — Identity provider/SSO
   - `shortcut_service.proto` — User shortcuts
   - `common.proto` — Shared types and enums

2. **Generated OpenAPI schema:** `/bench/home/work/proto/gen/openapi.yaml` (auto-generated from protobuf, 4,057 lines)

3. **Public method access control:** `/bench/home/work/server/router/api/v1/acl_config.go` — defines which endpoints are publicly accessible

The API uses **gRPC with Connect** (browser-compatible RPC framework) and supports both gRPC-Gateway (REST) and Connect clients.
