**Premise correction**: This repository does not define a GraphQL schema. Instead, it uses a **Protocol Buffers (Proto3) + gRPC architecture** for the public API.

**Actual API surface**:

The public API is defined by:

1. **Proto service definitions** in `/bench/home/work/proto/api/v1/`:
   - `memo_service.proto`
   - `user_service.proto`
   - `attachment_service.proto`
   - `auth_service.proto`
   - `instance_service.proto`
   - `ai_service.proto`
   - `idp_service.proto`
   - `shortcut_service.proto`
   - `common.proto`

2. **Generated OpenAPI specification** in `/bench/home/work/proto/gen/openapi.yaml` — this is the transpiled OpenAPI 3.0.3 spec generated from the proto definitions using `buf.build` and `protoc-gen-openapi`

3. **Embedded Go code** at `/bench/home/work/proto/openapi_embed.go`

The API is exposed as a **REST API** at `/api/v1/` with JSON payloads, implemented by Go service handlers in `/bench/home/work/server/router/api/v1/`.
