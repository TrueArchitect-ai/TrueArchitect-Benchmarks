**Premise Correction:** This repository does not use GraphQL for its public API. It is not a GraphQL-based system.

**Actual API Surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC/REST service definitions. The schema files are located in `/bench/home/work/proto/api/v1/` directory, including:

- `/bench/home/work/proto/api/v1/ai_service.proto`
- `/bench/home/work/proto/api/v1/auth_service.proto`
- `/bench/home/work/proto/api/v1/user_service.proto`
- `/bench/home/work/proto/api/v1/memo_service.proto`
- And other service definition files

The API uses Google API annotations (as seen in the proto files) to expose gRPC services as REST endpoints (e.g., `post: "/api/v1/ai:transcribe"`). The README confirms this is a "REST and gRPC" API architecture, not GraphQL.
