This repository does **not** have a GraphQL schema. The premise of the question is incorrect.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** and gRPC, not GraphQL. The API schema is defined in:

- **Location:** `proto/api/v1/` directory
- **Files:** Service definitions in `.proto` format:
  - `auth_service.proto` — authentication
  - `user_service.proto` — user management
  - `memo_service.proto` — memo operations
  - `attachment_service.proto` — attachment handling
  - `ai_service.proto` — AI features
  - `idp_service.proto` — identity provider
  - `instance_service.proto` — instance configuration
  - `shortcut_service.proto` — shortcuts
  - `common.proto` — shared types

The API also exposes an **OpenAPI** specification for HTTP/REST access, as referenced in `server/router/mcp/README.md`, which mentions the same Echo server serves both the public API and OpenAPI definitions.
