Memo visibility (who may view a memo) is enforced in these distinct server surfaces:

1. Memo service — ./server/router/api/v1/memo_service.go (checkMemoReadAccess function)
2. Reaction service — ./server/router/api/v1/reaction_service.go (ListMemoReactions and UpsertMemoReaction methods)
3. Memo comments service — ./server/router/api/v1/memo_service_comments.go (CreateMemoComment method)
4. Memo attachment service — ./server/router/api/v1/memo_attachment_service.go (ListMemoAttachments method)
5. Attachment service — ./server/router/api/v1/attachment_service.go (checkAttachmentAccess function)
6. File server — ./server/router/fileserver/fileserver.go (attachment permission handler)
7. SSE hub — ./server/router/api/v1/sse_hub.go (canReceive method)
