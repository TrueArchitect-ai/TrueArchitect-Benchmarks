**Computation site:** `/bench/home/work/internal/markdown/markdown.go` contains the core extraction logic (`ExtractAll`, `ExtractProperties`, `ExtractTags`, `GenerateSnippet`). The orchestration happens in `/bench/home/work/server/router/api/v1/memo_service.go` and the conversion/formatting in `/bench/home/work/server/router/api/v1/memo_service_converter.go`.

**Triggers:** 
- **Create**: Immediately after validation in `CreateMemo` (line 108 of memo_service.go) via `memopayload.RebuildMemoPayload()`
- **Update**: When `content` field is in the update mask in `UpdateMemo` (line 447 of memo_service.go)
- **Batch rebuild**: Background job in `/bench/home/work/server/runner/memopayload/runner.go` processing in chunks of 100
- **Retrieval**: Snippet is recomputed on-the-fly during `convertMemoFromStore` (line 76 of memo_service_converter.go)

**Extracted properties:**
- `has_link` (boolean) - detects markdown links
- `has_task_list` (boolean) - detects checkboxes/task items  
- `has_code` (boolean) - detects code blocks or inline code
- `has_incomplete_tasks` (boolean) - detects unchecked tasks
- `title` (string) - extracted from first H1 heading if it's the first block element
- `snippet` (string) - plain text summary (max 64 chars, computed at retrieval)
- `tags` (array) - extracted hashtags, deduplicated while preserving case
