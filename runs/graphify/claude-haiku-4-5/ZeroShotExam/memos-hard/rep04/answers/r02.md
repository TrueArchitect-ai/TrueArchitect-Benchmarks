**Premise correction:** There is no per-user API rate-limiting middleware currently registered in this repository.

The codebase contains only global request limits and batch operation limits:
- **API Request Size Limit**: 256 MiB (`/bench/home/work/server/router/api/v1/v1.go:20`) - global
- **Pagination Limits**: 50 default, 1000 maximum items (`/bench/home/work/server/router/api/v1/common.go:14-17`) - applies to all users equally
- **Batch Operation Limits**: 100 items max for batch get/delete operations (`/bench/home/work/server/router/api/v1/user_service.go:23`, `instance_service.go:22`, `attachment_service.go:35`) - applies to all users equally
- **Concurrency Limits**: 3 thumbnail generations, 2 image processing operations (`/bench/home/work/server/router/api/v1/v1.go:59-60`) - global semaphores, not per-user

None of the middleware registered in `/bench/home/work/server/router/api/v1/connect_interceptors.go` (MetadataInterceptor, LoggingInterceptor, RecoveryInterceptor, AuthInterceptor) implement per-user rate limiting.
