**Mechanism: Explicit Go code**

When a user is deleted, their emoji reactions are removed by **explicit Go code**, not by database-level foreign key rules. The deletion happens in two ways:

1. **Reactions by content (memos)**: Lines 96-98 in the delete flow call `deleteReactionsByContentIDsTx`, which deletes all reactions on the user's memos
2. **Reactions by creator**: Lines 102-104 call `deleteReactionsByCreatorTx`, which deletes all reactions created by the user
