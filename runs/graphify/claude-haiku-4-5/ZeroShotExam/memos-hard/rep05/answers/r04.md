**Premise Correction**: The webhook delivery workers do not consume from either NATS or RabbitMQ.

**Actual Mechanism**: The webhook delivery system uses **in-process Go channels** for asynchronous message queuing, not an external message broker.

**Queue Declaration Location**: `/bench/home/work/internal/webhook/webhook.go`

The channel is declared as:
```go
var asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

This buffered channel has a capacity of 128 messages and is consumed by a hardcoded pool of 4 concurrent goroutines that process webhook deliveries via HTTP POST requests.
