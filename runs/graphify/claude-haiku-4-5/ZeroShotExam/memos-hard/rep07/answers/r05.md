**Premise Correction:** This repository does not use GraphQL for its public API. Instead, it uses **Protocol Buffers (Protobuf)** with Connect RPC and gRPC-Gateway.

**Actual API Surface:**

The public API schema is defined in **Protocol Buffer files** located in `/bench/home/work/proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — File attachments
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI provider operations
- `proto/api/v1/idp_service.proto` — Identity provider operations
- `proto/api/v1/shortcut_service.proto` — Keyboard shortcuts
- `proto/api/v1/common.proto` — Shared data types

The generated **OpenAPI 3.0.3 specification** is at `proto/gen/openapi.yaml` (4057 lines), which serves as the source of truth for REST/HTTP gateway operations and documentation.
