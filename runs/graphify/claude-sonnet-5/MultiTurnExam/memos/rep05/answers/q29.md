q29. Interceptor: `web/src/connect.ts` (`authInterceptor`, line 156) — attaches the bearer token to every request and reactively refreshes on `401 Unauthenticated`, backed by `web/src/auth-state.ts` for token storage/expiry tracking.

Token kinds: a short-lived **access token** (JWT, held in memory + `localStorage`, sent as `Authorization: Bearer <token>`) and a **refresh token** (kept in an HTTP-only cookie, not accessible to JS — retrieved automatically via `credentials: "include"` and exchanged through `AuthService.RefreshToken`). Personal Access Tokens (PATs) are also supported as a separate long-lived credential.

Backend package: `server/auth` (`server/auth/authenticator.go`, `token.go`, `extract.go`) — `Authenticator.AuthenticateToUser` validates the bearer access token / refresh-token cookie / PAT and resolves the requesting `store.User`.
