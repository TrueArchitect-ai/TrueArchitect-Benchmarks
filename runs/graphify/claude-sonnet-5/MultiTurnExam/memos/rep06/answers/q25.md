q25. Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/` (`engine.go` for compiling filter strings into an intermediate condition tree, `render.go` for SQL generation)

Mechanism: `internal/filter/engine.go` compiles the CEL filter string into a dialect-agnostic `Condition` tree (`Engine.Compile`), and `internal/filter/render.go`'s `renderer.Render` walks that tree to emit parameterized SQL, switching on a `DialectName` (SQLite/Postgres/MySQL) per-node (e.g. `strftime` vs native functions) so the same parsed filter produces correct SQL for each store dialect.
