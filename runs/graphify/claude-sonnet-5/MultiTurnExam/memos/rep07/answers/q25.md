q25. Engine: **CEL (Common Expression Language)**, implemented in `internal/filter/` (`internal/filter/engine.go`, using `cel-go` — see `Engine.Compile`/`CompileToStatement` in `engine.go`, with the CEL AST converted to an internal `Condition`/IR tree in `ir.go` and `parser.go`).

Mechanism: `Engine.CompileToStatement` (`internal/filter/engine.go:74`) compiles the CEL filter string into a condition tree, then a dialect-aware `renderer` (`internal/filter/render.go`, keyed by `DialectName` — `DialectSQLite`/`DialectPostgres`/`DialectMySQL`) walks that tree and emits parameterized SQL fragments, using per-dialect column/JSON/date-part expressions (e.g. `qualifyColumn`, `jsonExtractExpr`, `timestampAccessorExpr`) so the same filter produces correct SQL for each of the three supported databases.
