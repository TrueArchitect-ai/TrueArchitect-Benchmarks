q25.

**Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`) parsed/compiled by the custom filter engine at `internal/filter/` (engine.go, parser.go, ir.go, render.go, schema.go).

**Mechanism:** The ListMemos filter string is compiled by `internal/filter.Engine.Compile` (engine.go) into an intermediate `Condition`/IR tree (ir.go), which is then converted to a dialect-specific SQL WHERE clause by `internal/filter/render.go`'s `renderer`, which switches on `DialectName` (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`) to emit the appropriate SQL syntax (e.g., JSON functions, regex operators) for each backend.
