At the store layer (`store.Store.DeleteMemo`, store/memo.go:140-158), before deleting the memo row itself:
- **memo_relation** records (both where the memo is the source and where it's the related/target memo) — via `DeleteMemoRelation`
- **attachment** records linked to the memo — via `DeleteAttachment` for each attachment found

Additionally, at the API handler layer (`server/router/api/v1/memo_service.go:518` `DeleteMemo`), memo **comments** (child memos linked via a `MemoRelationComment` relation) are deleted first — each via a recursive `store.DeleteMemo` call — before the parent memo is deleted.
