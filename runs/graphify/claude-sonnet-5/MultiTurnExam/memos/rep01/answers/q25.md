q25. Engine: CEL (Common Expression Language, via `github.com/google/cel-go`) — internal/filter/ (engine.go, parser.go, ir.go, render.go, schema.go).

Mechanism: `filter.Engine.Compile` parses the CEL filter string into an intermediate `Condition`/IR tree (parser.go, ir.go), and `internal/filter/render.go`'s `renderer` (parameterized by a `DialectName` — `DialectPostgres`/`DialectMySQL`/`DialectSQLite`) walks that IR to emit dialect-specific SQL fragments (e.g. different JSON/regex/`LIKE` syntax per dialect), which `store.ListMemos` then splices into the `WHERE` clause for each database driver.
