q29. Interceptor: `authInterceptor` in `web/src/connect.ts` (lines 156-178), attached to the ConnectRPC transport.

Token kinds: a short-lived **access token** (JWT bearer token, kept in memory/sessionStorage and sent as an `Authorization: Bearer` header — see `web/src/auth-state.ts`) and a **refresh token** (kept as an httpOnly cookie, exchanged via the `AuthService.RefreshToken` RPC when the access token is missing/expired or a request comes back `Unauthenticated`).

Backend validation package: `server/auth` (`authenticator.go`, `token.go`, `extract.go`, `context.go`) — e.g. `server/auth/authenticator.go` looks up the user via `store.GetUser` after validating the token claims.
