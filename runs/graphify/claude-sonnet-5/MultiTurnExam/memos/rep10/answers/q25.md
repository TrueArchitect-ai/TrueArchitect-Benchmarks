q25. Engine: CEL (Common Expression Language, via `google/cel-go`) — implemented in `internal/filter/` (`engine.go` defines `Engine`/`NewEngine` wrapping a `cel.Env`; `parser.go` walks the compiled CEL AST into a dialect-agnostic `Condition` tree; `ir.go` defines that IR).

Mechanism: The RPC's `filter` string is compiled by `Engine.Compile`/`CompileToStatement` into a dialect-agnostic `Condition` IR (with `now`/duration values frozen at compile time), then rendered per-dialect (`filter.DialectPostgres`/`DialectSQLite`/`DialectMySQL`) into SQL WHERE fragments and bound args via `filter.AppendConditions` (`internal/filter/helpers.go`), which each store driver (e.g. `store/db/postgres/memo.go:58`) calls before running its query.
