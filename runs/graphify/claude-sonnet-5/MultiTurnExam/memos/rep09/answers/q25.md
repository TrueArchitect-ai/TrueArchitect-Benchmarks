q25. **CEL (Common Expression Language)**, via `google/cel-go`, implemented in `internal/filter/` (`engine.go` parses/compiles the AIP-160-style filter string with `cel.NewEnv`/`cel.AstToParsedExpr`; `schema.go` defines the memo filter's variables/fields; `ir.go` turns the parsed CEL expression into an intermediate `Condition` tree).

Mechanism: `internal/filter/render.go`'s `renderer.Render` walks that IR and emits dialect-specific SQL fragments (branching on a `DialectName` of `DialectSQLite`/`DialectPostgres`/`DialectMySQL`, e.g. different timestamp extraction and string-length expressions per dialect), and the store/dialect driver code (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) appends the rendered `WHERE` clause fragments to the `ListMemos` query.
