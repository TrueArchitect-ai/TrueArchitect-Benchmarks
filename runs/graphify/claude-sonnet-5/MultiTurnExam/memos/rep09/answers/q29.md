q29. `web/src/connect.ts` (`authInterceptor`, lines 156-178, registered on the Connect `transport` at line 188).

It manages: a short-lived in-memory **access token** (Bearer, attached via `Authorization` header, tracked in `web/src/auth-state`) which is proactively/reactively renewed using a **refresh token** (an httpOnly cookie, refreshed via `doRefreshAccessToken`, connect.ts:74-90).

Backend validation package: `server/auth/` (see `server/auth/authenticator.go`), which validates the bearer token and looks up the user via `Store.GetUser`.
