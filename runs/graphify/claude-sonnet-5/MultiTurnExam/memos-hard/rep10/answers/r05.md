**Premise correction** — there is no GraphQL schema in this repository; a search for "graphql" (case-insensitive) across all Go files, and for `.graphql`/`.gql` files, returns nothing. This project doesn't expose a GraphQL API at all.

**Actual API surface** — the public API is defined as Protocol Buffer service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to Go (`proto/gen/api/v1/`) and served over gRPC/Connect-RPC and a grpc-gateway REST/JSON bridge, registered in `server/router/api/v1/v1.go` (`APIV1Service.RegisterGateway`).
