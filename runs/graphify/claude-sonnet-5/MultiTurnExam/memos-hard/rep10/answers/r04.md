**Premise correction** — neither NATS nor RabbitMQ is used anywhere in this codebase; a repo-wide search for "nats", "rabbitmq", and "amqp" returns zero matches. There is no external message broker at all.

**Actual mechanism** — webhook delivery is queued via an in-process, buffered Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`, declared at `internal/webhook/webhook.go:39`. `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto it (non-blocking, dropping the payload with a warning log if the channel is full), and 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-54`) range over that same channel, each calling `Post` to perform the actual HTTP delivery.
