**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(memo.Content)` (the `markdown.Service` implementation from `internal/markdown/markdown.go:356`) and writes the result into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers** — invoked from two RPC code paths in `server/router/api/v1/memo_service.go`:
- `CreateMemo` — `memo_service.go:108`, run on every new memo before it's persisted.
- `UpdateMemo` — `memo_service.go:447`, run only when the update mask includes the `content` field path (`memo_service.go:436-437`), i.e. whenever a memo's content is edited. Comment creation goes through the same `CreateMemo` path, so it's covered too, not a distinct trigger.

**Extracted properties** — via `internal/markdown/markdown.go:356` (`ExtractAll`, a single AST walk):
- `Tags` — all `#tag` occurrences (excluding ones inside links/images), deduplicated case-preserving.
- `Property.Title` — text of a leading H1 heading, if the first block in the document is one.
- `Property.HasLink` — whether the content contains a link node.
- `Property.HasCode` — whether it contains a code block/fenced block/code span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether it contains task-list checkboxes, and whether any are unchecked.

(`ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property` into the stored payload.)
