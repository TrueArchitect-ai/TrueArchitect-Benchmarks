**Delivery function** — `Post` in `internal/webhook/webhook.go:120` (executes the actual outbound HTTP POST via `safeClient.Do(req)` at `webhook.go:152`; async callers enqueue through `PostAsync`, `webhook.go:184`, which is drained by worker goroutines that call `Post`, `webhook.go:42-54`).

**Protection mechanism** — the shared `safeClient`'s custom `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-37`), which resolves the target hostname and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go`, blocking loopback, RFC-1918 private, link-local/cloud IMDS `169.254.169.254`, etc., per `validate.go:12-20`) — checking IPs at dial time (post-DNS-resolution) defeats DNS-rebinding SSRF attacks. This can be disabled via `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:38-45`), presumably for testing.
