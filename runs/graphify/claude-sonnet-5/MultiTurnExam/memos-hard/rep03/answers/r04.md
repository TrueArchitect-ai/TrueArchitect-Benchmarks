Premise correction — the webhook delivery workers don't consume from any external message broker; there is no NATS or RabbitMQ dependency anywhere in this repo (no import, no `go.mod` entry, no client/connection code). Actual mechanism — delivery uses a plain in-process, buffered Go channel: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`, declared in `internal/webhook/webhook.go:39`. `PostAsync` enqueues onto it (`internal/webhook/webhook.go:190`), and fixed worker goroutines spawned in `init()` range over that channel (`internal/webhook/webhook.go:45`) and call `Post` to perform the actual delivery. It's an in-memory queue local to the server process, not a message broker.
