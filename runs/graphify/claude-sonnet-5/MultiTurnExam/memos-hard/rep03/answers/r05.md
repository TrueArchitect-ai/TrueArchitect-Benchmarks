Premise correction — this project has no GraphQL API; there's no GraphQL dependency in `go.mod`, no `.graphql`/`.gql` schema file, and no GraphQL-related code anywhere in the repo. Actual API surface — the public API is defined as Protocol Buffer service definitions under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), configured via `proto/buf.yaml`/`proto/buf.gen.yaml`. These generate gRPC/Connect service code plus a gRPC-gateway REST/JSON transcoding layer (`proto/gen/api/v1/*.pb.gw.go`) and an embedded OpenAPI spec (`proto/openapi_embed.go`), which the server implements in `server/router/api/v1/*.go`.
