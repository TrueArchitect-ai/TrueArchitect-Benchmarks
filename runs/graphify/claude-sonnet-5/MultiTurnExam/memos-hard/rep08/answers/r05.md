**Premise correction:** There is no GraphQL schema in this repository. A search for `graphql` (case-insensitive) across all `.go` and `.proto` files, and for `.graphql`/`schema.gql*` files, returns nothing.

**Actual API surface:** The public API is defined as Protocol Buffers services under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`. These are compiled to generated Go code under `proto/gen/api/v1/` and served two ways from the same handlers: as gRPC/Connect RPCs, and as a REST/JSON surface via grpc-gateway (the `*.pb.gw.go` files, e.g. `proto/gen/api/v1/memo_service.pb.gw.go`), wired up in `server/router/api/v1/v1.go` (`APIV1Service.RegisterGateway`) and mounted in `server/server.go:88`.
