**Premise correction:** There is no nightly (or any) database-cleanup job scheduled anywhere in this codebase. The repo does contain a general-purpose cron-style scheduler package, `internal/scheduler` (`internal/scheduler/scheduler.go`, `parser.go`, `job.go`, `middleware.go`), but it is never instantiated or used in production — `scheduler.New(...)` and `scheduler.Register(...)` appear only in that package's own doc comments (`internal/scheduler/doc.go:12,28`) and its test suite (`internal/scheduler/*_test.go`); no other package in the repo imports `internal/scheduler` at all.

The only thing resembling "cleanup" in the codebase is unrelated to the database: `store/cache/cache.go`'s in-process `Cache` type runs a periodic `cleanupLoop` goroutine (`store/cache/cache.go:200`, ticking every `CleanupInterval` — default 5 minutes, set in `store/store.go:42`) that evicts expired in-memory cache entries — not a database table/row cleanup job, and not on a "nightly"/fixed-time cron schedule at all, just a recurring interval.

The only genuine "scheduled" background job in production is the S3 presign refresher covered in h01 (`server/runner/s3presign`, every 12 hours via `time.Ticker`), which is unrelated to database cleanup.
