Premise correction: there is no GraphQL schema or API anywhere in this codebase — a repo-wide case-insensitive grep for "graphql", a check of `go.mod`, and a search for `.graphql`/`.gql` files all came up empty.

Actual API surface: the public API is defined as **Protocol Buffers / gRPC**, with a REST surface generated via grpc-gateway. Service definitions live under `proto/api/v1/*.proto`, generated Go code lands in `proto/gen/api/v1/` (including `*.pb.gw.go` gateway files like `user_service.pb.gw.go`, `memo_service.pb.gw.go`, etc.), and an OpenAPI spec is embedded via `proto/api/openapi_embed.go`. This is compiled via `buf` (`proto/api/buf.gen.yaml`, `buf.yaml`, `buf.lock`).
