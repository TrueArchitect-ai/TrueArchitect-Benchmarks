Premise correction: there is no nightly database-cleanup job in this codebase — the question's premise is false.

`server/server.go`'s `startBackgroundRunners` (server.go:153-174) wires up exactly one background job: the `s3presign` runner (`server/runner/s3presign/runner.go`), a 12-hour ticker that refreshes S3 presigned URLs, not a cleanup job and not cron/nightly-scheduled.

The repo does contain a cron-capable `internal/scheduler` package (with `ParseCronExpression`/`Scheduler`), but `scheduler.New(` is only ever called inside `internal/scheduler`'s own tests and examples (including a `"daily-cleanup"` string that appears solely in `internal/scheduler/doc.go` as illustrative godoc, not real code) — no file outside that package even imports it. Similarly, `server/runner/memopayload.Runner`/`NewRunner` exist but have zero callers anywhere; only its unrelated helper `RebuildMemoPayload` is invoked synchronously from per-request memo create/update handlers. No cron expression, scheduled time, or database-row-purging logic exists anywhere in `cmd/`, `server/`, or `store/`.
