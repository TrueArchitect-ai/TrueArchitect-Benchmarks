Premise correction: there is no GraphQL schema anywhere in this repository — a repo-wide search for "graphql" (source files, schema files, `.graphql`/`.gql` extensions) returns zero matches.

Actual API surface: the public API is defined via Protocol Buffers under `proto/` (service definitions like `MemoService`, `UserService`, `AttachmentService`, etc.), served as gRPC plus a gRPC-Gateway/Connect-RPC HTTP surface. Generated Go bindings live under `proto/gen/api/v1/` (e.g. `memo_service.pb.go`, `memo_service_grpc.pb.go`), and the handlers are implemented in `server/router/api/v1/*.go` (e.g. `memo_service.go`), registered in `server/router/api/v1/v1.go`.
