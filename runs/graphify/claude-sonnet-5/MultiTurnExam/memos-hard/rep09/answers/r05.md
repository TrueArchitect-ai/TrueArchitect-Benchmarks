**Premise correction:** There is no GraphQL schema in this repository. No `.graphql`/`.gql` files exist, and there's no `graphql`/`gqlgen` dependency anywhere in the code or `go.mod`.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), compiled into generated Go code in `proto/gen/api/v1/`. These service definitions are served two ways at once, both wired up in `server/router/api/v1/v1.go:65` (`APIV1Service.RegisterGateway`):
- **Connect RPC** handlers, registered directly against the same proto-generated service interfaces.
- A **gRPC-Gateway** REST/JSON transcoding layer (`runtime.NewServeMux`, `server/router/api/v1/v1.go:96`, using `github.com/grpc-ecosystem/grpc-gateway/v2/runtime`), which maps the proto RPCs onto conventional HTTP/JSON endpoints.

There's also an embedded OpenAPI spec (`proto/openapi_embed.go`) describing that REST surface. So the API is proto/gRPC (+ gRPC-Gateway REST) based, not GraphQL.
