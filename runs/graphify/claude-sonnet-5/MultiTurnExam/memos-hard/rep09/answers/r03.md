**Premise correction:** There is no nightly database-cleanup job registered in this repository. `internal/scheduler` (`internal/scheduler/scheduler.go`) is a generic, cron-expression-based job scheduler library, but it is never wired into server startup — `scheduler.New(...)` is called only from its own package tests (`internal/scheduler/integration_test.go`, `internal/scheduler/example_test.go`) and its doc comment (`internal/scheduler/doc.go`). A repo-wide search finds no call to `scheduler.New` anywhere in `server/` or `cmd/`.

The "2 AM daily cleanup" you may be thinking of is only a **documentation example** in `internal/scheduler/doc.go:12-21`:
```go
s.Register(&scheduler.Job{
    Name:     "daily-cleanup",
    Schedule: "0 2 * * *", // 2 AM daily
    ...
})
```
This is illustrative sample code in a doc comment, not a job actually registered or run anywhere.

The only real background job started at server startup is the S3 presign refresh runner (`server/server.go:153-174`, `startBackgroundRunners`), which runs on a fixed 12-hour interval — it is unrelated to database cleanup and isn't scheduled via `internal/scheduler` or any cron expression. There is no nightly DB-cleanup job in the running server at all.
