**Delivery function:** `Post` — `internal/webhook/webhook.go:120-180` (sends the request via `safeClient.Do(req)` at line 152); invoked asynchronously through `PostAsync` (`internal/webhook/webhook.go:184`) by worker goroutines, which is called on content changes from `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`.

**Protection mechanism:** the shared `safeClient`'s `http.Transport.DialContext` is overridden with `safeDialContext` (`internal/webhook/webhook.go:32-37, 59-77`), which resolves the target host at actual dial time and rejects any resolved IP that is reserved/private via `isReservedIP` (`internal/webhook/validate.go:44-54`), checked against `reservedCIDRs` covering loopback, RFC1918 private ranges, and link-local/metadata addresses (`internal/webhook/validate.go:14-23`). A separate, earlier check — `ValidateURL` (`internal/webhook/validate.go:62-83`) — validates webhook URLs at registration time in `server/router/api/v1/user_service_webhooks.go`, but the dial-time `safeDialContext` check is what actually guards the outbound delivery path against SSRF/DNS-rebinding.
