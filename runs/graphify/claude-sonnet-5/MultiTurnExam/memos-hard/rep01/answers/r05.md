**Premise correction:** There is no GraphQL schema in this codebase — a repo-wide search for "graphql" (and for `.graphql`/`.gql` files) turns up nothing.

**Actual API surface:** The public API is defined with Protocol Buffers under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), compiled via `buf` (`proto/buf.gen.yaml`, `buf.yaml`, `buf.lock`) into generated Go/TS code under `proto/gen/`. It's served as gRPC/Connect RPC (see the generated `apiv1connect` package and `Unimplemented*ServiceServer` embeds in `server/router/api/v1/v1.go`), with an OpenAPI/REST gateway also generated (`proto/openapi_embed.go` and the `*.pb.gw.go` gateway files under `proto/gen/api/v1/`) — not GraphQL.
