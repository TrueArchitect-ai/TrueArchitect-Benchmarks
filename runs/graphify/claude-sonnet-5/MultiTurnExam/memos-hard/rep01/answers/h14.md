h14.

**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which calls `markdownService.ExtractAll(memo.Content)` → `(*markdown.service).ExtractAll` (`internal/markdown/markdown.go:356`, a single Goldmark AST walk).

**Triggers** — invoked whenever memo content is set/changed: `CreateMemo` (`server/router/api/v1/memo_service.go:108`) and `UpdateMemo` only when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:447`). There's also a standalone backfill path, `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`), which batches through all memos and rebuilds their payload — though this `Runner` type is never constructed/wired into server startup, so in practice it's dead code and recomputation only happens on create/content-update.

**Extracted properties** — written into `memo.Payload.Tags`, `memo.Payload.Property` (a `storepb.MemoPayload_Property`): `Tags` (deduplicated `#tag` occurrences) and `Mentions` (`@username` mentions, lowercased/deduplicated, internal to `ExtractedData` though not assigned back into `Payload` by `RebuildMemoPayload`), plus on `Property`: `Title` (text of a leading H1 heading), `HasLink`, `HasCode` (from code blocks/spans), `HasTaskList`, and `HasIncompleteTasks` (from unchecked task checkboxes).
