**Premise correction:** There is no GraphQL API in this repository — no `.graphql`/`.gql` schema files, and no GraphQL library appears in `go.mod` or anywhere in the code.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), compiled with `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`) into generated Go gRPC/Connect code under `proto/gen/`. These services are exposed over gRPC and Connect (JSON/HTTP-compatible RPC), implemented by handlers in `server/router/api/v1/`. An OpenAPI spec is also generated and embedded for the HTTP surface, served via `proto/openapi_embed.go` (embedding `proto/gen/openapi.yaml`).
