**Premise correction:** There is no nightly database-cleanup job registered in this repository. The `internal/scheduler` package (`internal/scheduler/scheduler.go`, `parser.go`, etc.) implements a generic cron scheduler, but a repo-wide search confirms it has zero call sites in production code — `scheduler.New()`, `.Register()`, and `.Start()` are never invoked anywhere in `server/` or `cmd/`. The only place `"daily-cleanup"` and `"0 2 * * *"` (2 AM) appear is as an illustrative example in the package's doc comment (`internal/scheduler/doc.go:14-21`), not an actual configured job. There's also no unrelated cleanup mechanism it could be confused with — the only real periodic background jobs in the server are the `s3presign` runner (every 12 hours, `server/runner/s3presign/runner.go:27`) and the in-memory cache's expiry sweep (`store/cache/cache.go:200-215`, every 5 minutes by default), neither of which is a database-cleanup job nor scheduled via `internal/scheduler`.
