**Triggers (recomputation):**

- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the update mask includes the `content` path (`if path == "content" { ... memopayload.RebuildMemoPayload(...) }`, `memo_service.go:436-447`) — editing visibility, tags-only via other means, pinning, etc. does not retrigger it.

**Extracted properties** (via a single AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-419`):
- `Tags []string` — all `#tag` nodes found in content (deduplicated, case preserved)
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one
- `Property.HasLink` — set when a Markdown link node is present
- `Property.HasCode` — set when a code block/fenced code block/code span is present
- `Property.HasTaskList` — set when a task checkbox is present
- `Property.HasIncompleteTasks` — set when an unchecked task checkbox is present
(`Mentions` is also extracted by `ExtractAll` but is not persisted into `memo.Payload` by `RebuildMemoPayload` — only `Tags` and `Property` are written.)
