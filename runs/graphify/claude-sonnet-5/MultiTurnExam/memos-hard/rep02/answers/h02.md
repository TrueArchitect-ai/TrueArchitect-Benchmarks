**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`, used as the custom `DialContext` on the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any resolved IP for which `isReservedIP` (`internal/webhook/validate.go:44`) returns true, blocking connections to reserved/private network ranges at dial time (also guarding against DNS rebinding, since the check runs on the resolved IP, not the original request URL).
