**Premise correction:** There is no GraphQL schema in this repository — a repo-wide search for "graphql" across `.go` and `.proto` files returns nothing.

**Actual API surface:** The public API is defined as Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `common.proto`). These are compiled to generated Go bindings in `proto/gen/api/v1/`, and served over gRPC plus a grpc-gateway/Connect-RPC REST/JSON bridge, registered in `server/router/api/v1/v1.go` (`RegisterGateway`, `v1.go:65`).
