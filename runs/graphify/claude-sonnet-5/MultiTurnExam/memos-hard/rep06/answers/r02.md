**Premise correction:** No per-user API rate-limiting middleware exists in this codebase. A repo-wide search for "ratelimit"/"rate limit"/"limiter" turns up exactly one hit — a doc comment in `internal/email/doc.go:86` that merely *recommends* rate-limiting email sending as a best practice; it is not implemented anywhere. **Actual mechanism:** The only middleware registered on the Echo server is `middleware.Recover()` (panic recovery) and a custom CORS middleware, both wired at `server/server.go:51-52`; the frontend router additionally registers static-file and SPA-fallback middleware (`server/router/frontend/frontend.go:54-59`). None of these perform request-rate limiting. If throttling is a requirement, it would need to be added — there is currently nothing to point to.
