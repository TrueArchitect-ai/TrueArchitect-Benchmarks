**Premise correction:** There is no GraphQL schema in this codebase — a full search for "graphql" across all Go files returns zero hits, and there's no GraphQL server library, resolver, or `.graphql`/`.gql` schema file anywhere in the repo.

**Actual API surface:** The public API is defined via Protocol Buffers and served over gRPC/Connect/gRPC-Gateway. Service and message definitions live under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, etc.), generated Go code lands in `proto/gen/api/v1/` (including Connect-RPC bindings in `proto/gen/api/v1/apiv1connect/` and REST gateway bindings in `*.pb.gw.go`), and internal storage-layer messages are defined separately under `proto/store/` / `proto/gen/store/`. The handlers implementing these RPCs live in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`), registered via Connect/gRPC-Gateway in `server/router/api/v1/v1.go` and `connect_services.go`.
