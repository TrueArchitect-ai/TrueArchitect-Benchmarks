**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual HTTP dispatch via `safeClient.Do(req)`; async callers enqueue through `PostAsync`, `internal/webhook/webhook.go:184`, which is drained by worker goroutines calling `Post`, `internal/webhook/webhook.go:42-55`).

**Protection mechanism:** SSRF/DNS-rebinding guard via a custom `DialContext` — `safeDialContext`, `internal/webhook/webhook.go:59-77`, wired into the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host at dial time and rejects any resolved IP inside a reserved/private range, checked with `isReservedIP` — `internal/webhook/validate.go:44-54` (blocks loopback, RFC-1918 private ranges, and link-local/cloud-metadata `169.254.0.0/16`, plus IPv6 equivalents, per `reservedCIDRs` at `internal/webhook/validate.go:14-23`). A companion pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), performs the same resolved-IP check at webhook-registration time.
