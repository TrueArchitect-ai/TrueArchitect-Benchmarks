`Driver` — `store/driver.go`

The `Driver` interface (defined in `store/driver.go:10`) specifies all methods a database backend must implement (attachments, memos, users, settings, identity providers, etc.). It's implemented by each backend driver, confirmed via `store.Driver` references in `store/db/postgres/postgres.go`, `store/db/sqlite/sqlite.go`, and `store/db/mysql/mysql.go`.
