**Engine + path:** A custom CEL-based filter engine at `internal/filter/` (`engine.go`, `parser.go`/`ir.go`, `render.go`, `schema.go`) — built on `github.com/google/cel-go` — is the process-wide `filter.DefaultEngine()` used by `ListMemos` in `server/router/api/v1/memo_service.go:211-216` (validated via `validateFilter` in `server/router/api/v1/shortcut_service.go:336`).

**Mechanism:** The raw `request.Filter` string is compiled by CEL's `cel.Env.Compile` into a CEL AST (`Engine.Compile` in `internal/filter/engine.go:48-71`), converted into a dialect-agnostic `Condition` tree (`buildCondition` in `internal/filter/ir.go`), and then a per-dialect `renderer` (`internal/filter/render.go`, switching on `filter.DialectSQLite`/`DialectMySQL`/`DialectPostgres`) walks that tree to emit a parameterized SQL `WHERE` fragment plus args (`Program.Render` → `renderer.Render`), which `store/db/{sqlite,mysql,postgres}/memo.go` appends to the query via `filter.AppendConditions` (`internal/filter/helpers.go:9-25`).
