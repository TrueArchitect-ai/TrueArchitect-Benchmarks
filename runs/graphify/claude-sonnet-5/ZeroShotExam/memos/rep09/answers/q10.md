**`store/migration/sqlite/LATEST.sql`**

This file contains the complete current schema (`CREATE TABLE` statements for all tables) and is applied directly for new/fresh installations, rather than replaying the full incremental migration history. This is confirmed in `store/migrator.go:27,42,56`, which documents that `preMigrate` applies `LATEST.sql` when the DB is uninitialized, and defines `LatestSchemaFileName = "LATEST.sql"` — described as "Full schema for new installations (faster than incremental migrations)".
