q06. `memo_relation`

Confirmed in `store/migration/sqlite/LATEST.sql` (and equivalently in `store/migration/postgres/LATEST.sql` / `store/migration/mysql/LATEST.sql`), which defines:

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

This table links `memo_id` to `related_memo_id`, and is accessed via `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
