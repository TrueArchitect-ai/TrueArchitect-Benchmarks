q27. mechanism; path

The compiled React frontend (built into `server/router/frontend/dist/`) is embedded into the Go binary via Go's `embed.FS` (`//go:embed dist/*`) and served through an Echo static-file middleware (`middleware.StaticWithConfig`) plus a SPA-fallback middleware that serves `index.html` on 404s for non-API routes; `server/router/frontend/frontend.go:20-59` is where this is wired (the `FrontendService.Serve` method).
