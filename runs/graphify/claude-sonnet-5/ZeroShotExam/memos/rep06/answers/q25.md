**Engine + path:** CEL (Common Expression Language, via `google/cel-go`), implemented in `internal/filter/` (`engine.go`, `parser.go`, `schema.go`, `render.go`, `ir.go`, `helpers.go`).

**Mechanism (one sentence):** The `ListMemos` RPC's filter string (`MemoFilter`) is compiled by a process-wide `*filter.Engine` (`internal/filter/engine.go`) using `cel-go`'s `env.Compile` to produce a CEL AST, which `buildCondition` (`internal/filter/parser.go`) walks against a `Schema` (`internal/filter/schema.go`, mapping CEL field names to DB columns) to build a dialect-agnostic `Condition` tree; each store backend (`store/db/{sqlite,mysql,postgres}/memo.go` / `memo_relation.go`) then calls `engine.CompileToStatement(ctx, filter, RenderOptions{Dialect: ...})`, whose `renderer` in `internal/filter/render.go` walks that condition tree and emits dialect-specific SQL text + args (e.g. per-`DialectName` branches for JSON extraction, timestamp/epoch conversion, string length, and regex operators for `sqlite`/`mysql`/`postgres`).
