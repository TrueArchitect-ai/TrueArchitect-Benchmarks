**Driver** — `store/driver.go`

The `Driver` interface is defined in `store/driver.go:10-86`, declaring all the CRUD methods that a database backend must implement (attachments, memos, users, settings, identity providers, inbox, reactions, memo shares, user identities, etc.). It's implemented by each database backend package: `store/db/mysql/mysql.go`, `store/db/postgres/postgres.go`, and `store/db/sqlite/sqlite.go`, and referenced/wired up in `store/db/db.go`.
