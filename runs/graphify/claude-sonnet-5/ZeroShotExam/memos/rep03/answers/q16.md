Before deleting the memo row itself, `Store.DeleteMemo` (store/memo.go:140-158) deletes:
- **Memo relation records** — where the memo is the source (`DeleteMemoRelation{MemoID: &delete.ID}`, store/memo.go:142) and where it is the target/related memo (`DeleteMemoRelation{RelatedMemoID: &delete.ID}`, store/memo.go:145)
- **Attachment records** — all attachments linked to the memo, fetched via `ListAttachments{MemoID: &delete.ID}` and removed one by one with `DeleteAttachment` (store/memo.go:149-157)

Note: comment-type memo relations and reactions are handled separately, one level up in the API handler (`server/router/api/v1/memo_service.go:565-575` recursively deletes comment memos; reactions are only listed there for the webhook payload, not deleted by the store layer), and memo shares are deleted via a distinct `Store.DeleteMemoShare` call not invoked from `Store.DeleteMemo`.
