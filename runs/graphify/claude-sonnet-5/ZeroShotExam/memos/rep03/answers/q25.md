**Engine + path:** A custom CEL-based filter engine in `internal/filter/` (`engine.go`, `parser.go`/`ir.go`, `render.go`, `schema.go`), built on `github.com/google/cel-go`.

**Mechanism:** `ListMemos` (server/router/api/v1/memo_service.go:211-216) validates and appends the raw `request.Filter` string to `store.FindMemo.Filters`; each dialect-specific store implementation (`store/db/{sqlite,postgres,mysql}/memo.go`) calls `filter.AppendConditions`, which uses `filter.Engine.CompileToStatement` (internal/filter/engine.go) to compile the filter via `cel-go`'s parser into an AST, convert it into a dialect-agnostic `Condition` tree (internal/filter/ir.go), and then have a `renderer` (internal/filter/render.go) walk that tree to emit dialect-specific SQL/placeholders (e.g. `$N` positional args + `->>`/`EXTRACT` for Postgres, `?`/`JSON_EXTRACT`/`STRFTIME` for SQLite, `?`/`JSON_TABLE`/date functions for MySQL).
