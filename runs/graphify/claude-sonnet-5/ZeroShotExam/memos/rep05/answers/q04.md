q04. `APIV1Service.SignIn` — `server/router/api/v1/auth_service.go` (line 51)

This is the actual gRPC service implementation of the `SignIn` RPC defined in `proto/api/v1/auth_service.proto` (served via `UserService`/`AuthService`). Note there's also a thin Connect-RPC wrapper `ConnectServiceHandler.SignIn` in `server/router/api/v1/connect_services.go:78`, which just adapts the request/response and delegates to `APIV1Service.SignIn` for the actual auth logic (password check via bcrypt, SSO handling, and token issuance via `doSignIn` in `auth_service_session.go`).
