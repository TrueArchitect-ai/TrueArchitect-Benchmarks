**Engine + path:** A Google CEL (Common Expression Language, `github.com/google/cel-go`) based filter engine that lives in `internal/filter/` (`engine.go`, `parser.go`/`ir.go`, `render.go`, `schema.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) stores the raw filter string and validates it via `validateFilter` (`server/router/api/v1/shortcut_service.go:336`), which calls `filter.DefaultEngine()`; the `Engine.Compile` method (`internal/filter/engine.go:46`) uses the CEL environment to parse the expression into a CEL AST, then `buildCondition` walks that AST into a dialect-agnostic `Condition` IR tree (defined in `internal/filter/ir.go`), and finally `Program.Render`/the `renderer` in `internal/filter/render.go` walks that IR tree emitting SQL fragments and placeholders with per-`DialectName` branches (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`) for things like placeholder syntax, JSON/date functions, and casts, selected in `shortcut_service.go` based on `s.Profile.Driver`.
