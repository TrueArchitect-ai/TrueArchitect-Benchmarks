**Engine + path:** CEL (Common Expression Language, `google/cel-go`) via a custom wrapper package at `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:178`) takes `request.Filter`, validates it through `validateFilter` (`server/router/api/v1/shortcut_service.go:336`), which compiles the filter string with a `cel.Env` built from field declarations in `schema.go` (`internal/filter/engine.go:23,47`), converts the parsed CEL AST into an internal `Condition` IR (`internal/filter/parser.go`), and then `render.go`'s dialect-aware renderer walks that IR — with `switch`/`case DialectSQLite/DialectMySQL/DialectPostgres` branches per node type — to emit dialect-specific SQL (e.g., Postgres `~`/JSONB operators vs. SQLite/MySQL `LIKE`/`REGEXP`/`json_each`); the store layer invokes this via `filter.AppendConditions` from `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, and `store/db/postgres/memo.go`.
