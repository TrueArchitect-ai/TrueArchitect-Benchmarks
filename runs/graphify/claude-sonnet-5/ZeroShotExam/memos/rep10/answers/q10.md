`store/migration/sqlite/LATEST.sql`

For a fresh SQLite install, `Store.preMigrate` (store/migrator.go:210-252) checks `IsInitialized`; if the database is not yet initialized, it reads `migration/{driver}/LATEST.sql` (store/migrator.go:218, `LatestSchemaFileName` constant at store/migrator.go:56) via the embedded `migrationFS` and executes it in a single transaction to create the complete current schema — bypassing the incremental per-version migration files under `store/migration/sqlite/0.x/`.
