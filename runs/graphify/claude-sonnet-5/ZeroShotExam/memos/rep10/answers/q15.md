table: Struct — path
- `user` → `User` — `store/user.go` (rows scanned/queried against `FROM user` in `store/db/sqlite/user.go`, `store/db/mysql/user.go`)
- `attachment` → `Attachment` — `store/attachment.go` (queried against `` FROM `attachment` `` in `store/db/sqlite/attachment.go`)

This project (memos) doesn't use ORM struct tags (e.g. gorm); instead each domain struct in `store/*.go` is a plain Go struct that driver-specific code in `store/db/{sqlite,mysql,postgres}/*.go` manually scans to/from the corresponding table via hand-written SQL.
