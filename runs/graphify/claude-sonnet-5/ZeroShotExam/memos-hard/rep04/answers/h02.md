**Delivery function** — `Post` (called via `PostAsync`, which queues to worker goroutines) in `internal/webhook/webhook.go:120` (async wrapper at `webhook.go:184`). It performs the actual outbound `http.Client.Do` request via the package's `safeClient` (`webhook.go:32`).

**Protection mechanism** — Two layers, both in `internal/webhook/`:
- `safeDialContext` (`webhook.go:59`) is installed as the `http.Transport.DialContext` for `safeClient`, so every dial resolves the hostname and rejects any resolved IP that is reserved/private — this also blocks DNS-rebinding, since the check happens against the IP actually dialed, not just the URL's hostname.
- `isReservedIP` / `reservedNetworks` in `internal/webhook/validate.go:14-54` define the blocked ranges (loopback, RFC-1918 private space, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents). The same check is also applied up front at webhook-URL registration time via `ValidateURL` (`validate.go:62`).

(Note: an `AllowPrivateIPs` package flag in `validate.go:41` can disable this protection for self-hosted deployments that intentionally target local-network webhook receivers.)
