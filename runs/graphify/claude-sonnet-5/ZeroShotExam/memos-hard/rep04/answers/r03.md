r03. Premise correction: there is no nightly database-cleanup job registered anywhere in this repo's cron scheduler.

The only cron-related code is the standalone `internal/scheduler` package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, etc.), which is a generic, reusable cron-job library. It is never imported or wired up anywhere else in the codebase — `grep -rl "usememos/memos/internal/scheduler"` outside that package itself returns nothing, so no job (database-cleanup or otherwise) is actually registered with it.

The `"daily-cleanup"` (`0 2 * * *`) and `"stale-session-cleanup"` (`0 3 * * *`) schedules you may be thinking of appear only as illustrative code snippets in `internal/scheduler/README.md` — they're documentation examples for how a consumer *could* use the package, not an actual registered job with a real schedule.
