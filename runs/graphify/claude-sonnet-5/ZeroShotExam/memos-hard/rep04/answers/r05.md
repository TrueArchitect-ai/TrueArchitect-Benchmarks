**Premise correction:** This repository doesn't have a GraphQL API — there's no `graphql` reference anywhere in the codebase (verified via grep across `.go`/`.ts`/`.tsx`/`.md` and the graphify knowledge graph, which surfaced zero GraphQL-related nodes for this query).

**Actual API surface:** The public API is defined via **Protocol Buffers**, served over gRPC and exposed to HTTP/JSON clients through **grpc-gateway**:

- Schema source: `.proto` files under `proto/api/v1/` (e.g. `user_service.proto`, `memo_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), plus internal storage messages in `proto/store/*.proto`.
- Generated code lives in `proto/gen/api/v1/` — includes the gRPC service stubs (e.g. `user_service_grpc.pb.go`, `memo_service_grpc.pb.go`) and the REST gateway handlers (`*.pb.gw.go`, e.g. `user_service.pb.gw.go`, `memo_service.pb.gw.go`) that translate HTTP/JSON to gRPC calls.
- These services are registered and wired up in `server/router/api/v1/v1.go` (`APIV1Service`, `.RegisterGateway()`).

So if you're looking to modify or extend the public API's schema, the source of truth is the `.proto` files in `proto/api/v1/`, not a GraphQL schema.
