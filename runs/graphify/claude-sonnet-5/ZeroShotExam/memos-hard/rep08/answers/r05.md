**Premise correction:** This repository (usememos/memos, a Go backend + web frontend) does not have a GraphQL API. There is no `.graphql`/`.gql` schema file anywhere in the tree, and the README explicitly describes the public API as "full REST and gRPC APIs" — not GraphQL.

**Actual API surface:**
- The API is defined via **Protocol Buffers**, under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `attachment_service.proto`, plus shared types in `common.proto`).
- These are compiled (via `buf`, configured in `proto/buf.yaml` / `proto/buf.gen.yaml`) into generated gRPC/Go bindings in `proto/gen/api/v1/*.pb.go` and `*_grpc.pb.go`.
- A REST surface is derived from the same proto definitions via grpc-gateway/OpenAPI, with the generated spec checked in at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).
- Server-side routing/registration of these services lives under `server/router/api`.

So if you're looking for "the schema," the proto files in `proto/api/v1/` are the source of truth, not any GraphQL SDL file.
