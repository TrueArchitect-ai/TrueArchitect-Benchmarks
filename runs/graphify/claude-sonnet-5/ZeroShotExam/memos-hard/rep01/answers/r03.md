Premise correction: there is no actual nightly database-cleanup job running in this repository. The `internal/scheduler` package (`internal/scheduler/scheduler.go`) is a generic, standalone cron-scheduling library — it is never instantiated or wired up anywhere in `cmd/` or `server/`, so no job is actually scheduled to run in this application.

The "0 2 * * *" (2 AM) schedule you may be thinking of only appears as example/documentation code, not a live job:
- `internal/scheduler/example_test.go:97-101` — an `Example_multipleJobs` test registering a job named `"cleanup"` with schedule `"0 2 * * *"`
- `internal/scheduler/doc.go:14-21` — a doc comment showing a `"daily-cleanup"` job with schedule `"0 2 * * *"` as a usage illustration

Neither of these is invoked by the actual application (this repo is memos, a note-taking service); they exist solely to demonstrate/test the scheduler package's API. So there's no real nightly database-cleanup job configured — if you want one, it would need to be registered against `scheduler.New()` somewhere in `cmd/` or `server/`, which doesn't currently happen.
