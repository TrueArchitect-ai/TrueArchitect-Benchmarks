**Premise correction:** There is no GraphQL schema in this repository — it doesn't use GraphQL at all. There's no `.graphql`/`.gql` file, no GraphQL server dependency, and no schema-first GraphQL tooling anywhere in the tree.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + gRPC-Gateway/REST), under `proto/api/v1/`, e.g.:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Build config: `proto/buf.yaml` and `proto/buf.gen.yaml` (using `buf`), with generated Go/OpenAPI code in `proto/gen/` and `proto/openapi_embed.go`, and generated TypeScript client types in `web/src/types/proto/` (per `AGENTS.md`). So the "schema" equivalent for this public API is these `.proto` service definitions, which also generate an OpenAPI spec — not a GraphQL schema.
