Memo visibility is checked independently in at least these distinct server surfaces (each a separately-registered router package in `server/server.go`):

enforcement site — server/router/api/v1/memo_service.go (`checkMemoReadAccess`, lines 39-68; used by `GetMemo` and memo comment reads)
enforcement site — server/router/api/v1/attachment_service.go (lines 445-451, memo-visibility check before serving an attachment via the API service)
enforcement site — server/router/api/v1/memo_attachment_service.go (lines 214-222, duplicate visibility check for listing/serving memo attachments)
enforcement site — server/router/api/v1/reaction_service.go (lines 30-38, 83, gating who can view/react based on memo visibility)
enforcement site — server/router/api/v1/memo_service_comments.go (line 41, visibility check before allowing access to a memo's comments)
enforcement site — server/router/api/v1/memo_mention_helpers.go (lines 62-84, private-memo mention notification filtering)
enforcement site — server/router/api/v1/user_service_notifications.go (lines 309-312, visibility-based notification content redaction)
enforcement site — server/router/api/v1/sse_hub.go (lines 136-138, filters which connected clients receive a real-time SSE broadcast for a memo based on its visibility)
enforcement site — server/router/rss/rss.go (`GetExploreRSS`/`GetUserRSS`, lines 90 and 141, hardcoded to only include `store.Public` memos in RSS feeds)
enforcement site — server/router/fileserver/fileserver.go (`checkAttachmentPermission`, lines 649-704, independent visibility/permission check for serving attachment files over HTTP)
enforcement site — server/router/frontend/frontend.go (`getSitemapXML`, line 150, hardcoded to only include `store.Public` memos in the sitemap)

Note: the MCP server (server/router/mcp/) does not implement its own visibility check — it dispatches to the same gRPC/Connect `MemoService` methods (e.g. `GetMemo`) in api/v1, so it reuses the memo_service.go enforcement rather than being a separate site (server/router/mcp/catalog.go:12-25).
