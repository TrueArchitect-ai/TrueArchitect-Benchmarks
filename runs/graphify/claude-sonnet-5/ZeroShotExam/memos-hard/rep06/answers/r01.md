**Actual mechanism:** Caching is done with a custom in-process, thread-safe memory cache (`sync.Map`-backed) defined in `store/cache/cache.go`. It's instantiated per `Store` in `store/store.go:37-58`, which creates three separate cache instances — `instanceSettingCache`, `userCache`, and `userSettingCache` — all sharing one `cache.Config`:

```go
cacheConfig := cache.Config{
    DefaultTTL:      10 * time.Minute,
    CleanupInterval: 5 * time.Minute,
    MaxItems:        1000,
    OnEviction:      nil,
}
```

So user entries (`userCache`, populated/read in `store/user.go:151`) get a **10-minute TTL**, with a background cleanup sweep every 5 minutes and a 1000-item eviction cap (`store/cache/cache.go:60-66` for `DefaultConfig`, which matches the values set explicitly in `store/store.go`).
