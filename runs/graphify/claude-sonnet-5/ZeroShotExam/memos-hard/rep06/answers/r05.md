**Premise correction:** There is no GraphQL schema in this repository. This is the [memos](https://github.com/usememos/memos) codebase, and its public API is defined via **Protocol Buffers**, not GraphQL — there are zero `.graphql`/`.gql` files anywhere in the repo.

**Actual API surface:**
- Schema source of truth: `.proto` files under `proto/api/v1/` (e.g. `user_service.proto`, `memo_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`) plus internal storage messages in `proto/store/*.proto`.
- These are compiled to generated Go bindings in `proto/gen/api/v1/` — gRPC service stubs (`*_grpc.pb.go`, e.g. `proto/gen/api/v1/user_service_grpc.pb.go`) and a **gRPC-Gateway** layer (`*.pb.gw.go`, e.g. `proto/gen/api/v1/user_service.pb.gw.go`) that exposes the gRPC services as a REST/JSON HTTP API.
- The gateway is wired up in `server/router/api/v1/v1.go` (`APIV1Service`, `.RegisterGateway()` at `server/router/api/v1/v1.go:65`), which is what the public HTTP API actually serves.

So the correct pointer for "public API schema" is `proto/api/v1/*.proto`, not any GraphQL schema — the project doesn't use GraphQL at all.
