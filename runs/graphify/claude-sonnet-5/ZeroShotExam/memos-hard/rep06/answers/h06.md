**Handlers (RPC methods) that transitively trigger an outbound HTTP request to a user-configured URL:**

1. `.CreateMemo()` — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook` (`memo_service_webhooks.go:15`) → `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`) → `webhook.PostAsync`.
2. `.UpdateMemo()` — `server/router/api/v1/memo_update_helpers.go:67` calls `DispatchMemoUpdatedWebhook` (`memo_service_webhooks.go:20`) → same `dispatchMemoRelatedWebhook` path.
3. `.DeleteMemo()` — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook` (`memo_service_webhooks.go:25`) → same `dispatchMemoRelatedWebhook` path.
4. `.CreateMemoComment()` — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:30`), which also feeds `webhook.PostAsync`.

Each of these dispatches a `WebhookRequestPayload` whose `URL` is the admin/user-configured webhook endpoint stored via `.CreateUserWebhook()`/`.UpdateUserWebhook()` (`connect_services.go`).

**Convergence function:** `Post` in `internal/webhook/webhook.go:120` — every path above enqueues through `PostAsync` (`internal/webhook/webhook.go:184`) onto `asyncPostQueue`, which is drained by worker goroutines that all call `Post`. `Post` is the single place that actually constructs and sends the outbound `http.Request` (`safeClient.Do(req)`, `internal/webhook/webhook.go:163`) to the user-supplied URL.

(Separately, `.GetLinkMetadata()`/`.BatchGetLinkMetadata()` in `memo_service_link_metadata.go` reach `httpgetter.GetHTMLMeta` directly, and `.SignIn()` reaches `oauth2.IdentityProvider.ExchangeToken`/`.UserInfo()` in `internal/idp/oauth2/oauth2.go` — these are legitimate additional outbound-HTTP paths but each has its own delivery function, not shared with the webhook path above.)
