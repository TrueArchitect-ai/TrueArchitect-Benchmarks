`h11.`

The persistent entity types live in the Go `store/` package (`store/*.go` — the data-access layer for the `memos` app), e.g. `Memo`, `User`, `Attachment`, `Inbox`, `IdentityProvider`, `MemoRelation`, `MemoShare`, `Reaction`, `UserIdentity`, `UserSetting`, `InstanceSetting` (defined in files like `store/memo.go:35`, `store/user.go:29`, `store/attachment.go:16`, etc.).

Counting distinct packages outside `store/` (and its `store/db/*`, `store/test` subpackages) that reference `store.<Type>`:

- `User`: 7 packages — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- `Memo`: 6 packages — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- `Attachment`: 4, `Inbox`/`MemoRelation`/`MemoShare`: 3 each, `Reaction`/`UserIdentity`: 2, `IdentityProvider`/`InstanceSetting`/`UserSetting`: 1 each

**1st: `User`; 2nd: `Memo`** (~7 packages vs ~6 packages outside the `store` data layer). `User` edges out `Memo` mainly via `server/auth` and `server/router/fileserver`, which touch user identity/auth but don't need the `Memo` type directly.
