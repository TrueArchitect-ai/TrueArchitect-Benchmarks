**Premise correction:** This repository (usememos/memos) has no GraphQL API — there is no GraphQL schema anywhere in the codebase (no `.graphql`/`.gql` files, no `graphql` references in Go, TS, or proto sources).

**Actual API surface:** The public API is defined via **Protocol Buffers**, not GraphQL, under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). Code generation is driven by `proto/buf.gen.yaml` using `buf`, which produces:

- Go gRPC/Connect-RPC server code into `proto/gen/api/...`
- A gRPC-Gateway REST/JSON transcoding layer
- An OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)
- TypeScript client types into `web/src/types/proto` (via the `bufbuild/es` plugin)

So external clients interact with the API either through gRPC/Connect-RPC directly, or through the auto-generated REST/OpenAPI gateway — there is no GraphQL layer to point to.
