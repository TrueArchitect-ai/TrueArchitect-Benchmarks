**Addendum to h14:**

- **Computation site:** `internal/markdown/markdown.go:264` (`GenerateSnippet`), invoked via `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-90`.
- **Trigger:** recomputed on *every* read/response conversion (not stored in the DB) — called from `convertMemoFromStoreWithCreators` (`memo_service_converter.go:76`) on every `GetMemo`/`ListMemos`/`CreateMemo`/`UpdateMemo` response, plus `batchConvertMemoRelations` and notification previews (`user_service_notifications.go:323`).
- **Extracted property:** `snippet` (string) — plain-text excerpt, max 64 chars, truncated at a word boundary, skipping code blocks (`api/v1/memo_service.proto` field `snippet`).

So the full picture for "derived metadata used for lists/previews" spans two computations:
1. **Persisted** `Payload.Property`/`tags` — computed by `ExtractAll` in `internal/markdown/markdown.go:356`, triggered only on create/content-update via `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`).
2. **Ephemeral** `snippet` — computed by `GenerateSnippet` in `internal/markdown/markdown.go:264`, triggered on every API read/conversion, not stored.
