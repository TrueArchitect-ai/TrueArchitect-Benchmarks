h14. computation site; triggers; extracted properties

**Computation site:** `internal/markdown/markdown.go:356` — `(*service).ExtractAll(content []byte)`. It parses the memo's markdown into a goldmark AST and does a single walk, backed by two component methods also defined in that file: `ExtractTags` (`internal/markdown/markdown.go:143`) and `ExtractProperties` (`internal/markdown/markdown.go:193`, which handles the H1-title/link/code/tasklist logic that `ExtractAll` inlines).

`ExtractAll` is invoked from `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which copies the result onto the memo's stored payload:
```go
data, err := markdownService.ExtractAll([]byte(memo.Content))
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every new memo, before it's persisted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when `content` is in the request's update mask (`server/router/api/v1/memo_service.go:439-447`); updating other fields like visibility does not recompute it.
- A batch job, `Runner.RunOnce` in `server/runner/memopayload/runner.go:27`, pages through all memos and calls `RebuildMemoPayload` for each — but this runner is not currently wired into server startup (`server/server.go`'s `startBackgroundRunners` only registers the `s3presign` runner), so today it's dead/manual-use code, not an automatic trigger.

**Extracted properties** (`ExtractedData` struct, `internal/markdown/markdown.go:21-25`, persisted into `MemoPayload.Tags` / `MemoPayload.Property`):
- `Tags []string` — all `#tag` nodes found via the AST (excluding tags inside links/images).
- `Mentions []string` — `@username` mentions (lowercased), collected but not currently written into `Payload` by `RebuildMemoPayload`.
- `Property.Title` — text of the first H1 heading, if it's the document's first block-level child.
- `Property.HasLink` — set if any `Link` AST node is present.
- `Property.HasCode` — set if any code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set from task-list checkbox nodes (`east.KindTaskCheckBox`), with `HasIncompleteTasks` true if any checkbox is unchecked.

(`MemoPayload_Property` proto fields: `has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks`, `title` — `proto/gen/store/memo.pb.go:85-95`.)
