Each of these calls a `Dispatch*Webhook` helper in `server/router/api/v1/memo_service_webhooks.go`, which builds a `webhook.WebhookRequestPayload` (with `URL` set from the user's stored webhook config, `store.GetUserWebhooks`) and calls `webhook.PostAsync(payload)` (`internal/webhook/webhook.go:184`). That enqueues onto `asyncPostQueue`, which is drained by worker goroutines that all call the same function.

**Convergence function** — `Post` in `internal/webhook/webhook.go:120`. This is the single point where every one of these handler paths lands before the actual outbound request goes out: it marshals the payload, builds the `http.Request` to `requestPayload.URL` (the user-configured webhook URL), optionally HMAC-signs it, and executes it via the shared SSRF-guarded `safeClient.Do(req)` (`internal/webhook/webhook.go:152`).

(Separately, `GetLinkMetadata`/`BatchGetLinkMetadata` converge into `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go:136`, wired via `fetchHTMLMeta` in `memo_service.go:28`) for fetching arbitrary URLs, but that's a distinct convergence point from the webhook one above.)
