The persistent entity structs live in the `store` package (`store/*.go`, e.g. `store/user.go`, `store/memo.go`, `store/attachment.go`, etc. — the DB-record types like `store.User`, `store.Memo`, `store.Attachment`, `store.IdentityProvider`, `store.Inbox`, `store.MemoShare`, `store.MemoRelation`, `store.Reaction`, `store.UserSetting`, `store.UserIdentity`, `store.InstanceSetting`).

Counting distinct Go packages (directories) outside `store/` (and its subpackages `store/db/*`, `store/test`) that reference each type via `store.<Type>`:

- `store.User`: 7 packages — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- `store.Memo`: 6 packages — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Next closest: `store.Attachment` (4 packages).

**1st: User (~7 packages); 2nd: Memo (~6 packages)**

Both are used across auth, notification, the main API service, frontend routing, RSS, fileserver/attachment-payload processing, and their respective test packages — `User` edges out `Memo` mainly via `server/auth` and `server/router/fileserver`.
