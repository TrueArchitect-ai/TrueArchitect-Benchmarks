Premise correction: this repository has no GraphQL schema — there's no `.graphql`/`.gql` file and no `graphql` reference anywhere in the codebase (checked Go, TypeScript, and Markdown sources).

Actual API surface: the public API is defined via **Protocol Buffers / gRPC (with gRPC-Gateway for REST/JSON)**, in `proto/api/v1/*.proto` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. Internal storage-layer protobufs live separately under `proto/store/*.proto`. Generated code is output to `proto/gen`.
