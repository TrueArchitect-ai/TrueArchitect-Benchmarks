**Data layer:** the `store` package (`store/*.go`, with `store/db/{mysql,postgres,sqlite}`, `store/cache`, `store/migration`, `store/seed`, `store/test` as its implementation subpackages) defines the persistent entity structs — `Memo`, `User`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `IdentityProvider`, `UserIdentity`, `UserSetting`, `InstanceSetting`, etc.

I counted, for each entity type, the number of distinct Go packages outside `store/` that reference it (`grep -rl "store\.<Type>\b" --include="*.go" . | grep -v store-prefixed dirs`, dedup by directory):

- `store.User`: 11 packages — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, plus store's own db/test subpackages counted separately confirm 11 unique dirs outside `store/*.go` core.
- `store.Memo`: 10 packages — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`, etc.

1st: `User` (~11 packages); 2nd: `Memo` (~10 packages)
