The data layer here is the Go `store` package (`store/*.go`), which defines the persistent entity types (`Memo`, `User`, `Attachment`, `Reaction`, `MemoRelation`, `MemoShare`, `Inbox`, `IdentityProvider`, `InstanceSetting`, `UserIdentity`, `UserSetting` — e.g. `store/user.go:29`, `store/memo.go:35`). Counting distinct Go packages outside `store/` (and outside `store/db/*`, `store/test`, which are part of the data layer itself) that reference each type via `store.<Type>`:

- `User`: 7 packages — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- `Memo`: 6 packages — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
