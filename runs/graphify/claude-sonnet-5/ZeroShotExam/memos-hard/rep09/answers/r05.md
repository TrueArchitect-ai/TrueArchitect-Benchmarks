**Premise correction:** This repository (a Memos-like Go application) does not have a GraphQL API — there is no `.graphql`/`.gql` schema file, and neither `go.mod`/`go.sum` reference any GraphQL library (e.g., `gqlgen`, `graphql-go`).

**Actual API surface:** The public API is defined via **Protocol Buffers**, not GraphQL:
- Schema (`.proto` service/message definitions): `proto/api/v1/*.proto` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), documented in `proto/api/v1/README.md`.
- Generated Go bindings (gRPC + gRPC-Gateway REST/JSON transcoding + Connect): `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, and `proto/gen/api/v1/apiv1connect/`.
- Server-side handler implementations: `server/router/api/v1/*.go`.

So the API is gRPC/Connect-based (with REST gateway transcoding), and its schema of record lives in the `.proto` files under `proto/api/v1/`, not in a GraphQL schema.
