- **Delivery function** — `Post` in `internal/webhook/webhook.go:120` (invoked synchronously or queued via `PostAsync` at `internal/webhook/webhook.go:184`, backed by a 4-worker async queue). It builds the HTTP request and sends it via a package-level `safeClient` (`internal/webhook/webhook.go:32`).
- **SSRF protection** — Two layers, both in `internal/webhook/`:
  - `safeDialContext` (`internal/webhook/webhook.go:59`) is installed as the `http.Transport.DialContext` for `safeClient`; it resolves the target host at *dial time* and rejects the connection if any resolved IP is in `isReservedIP` (`internal/webhook/validate.go:44`), which blocks loopback, RFC-1918 private ranges, link-local/cloud-metadata (`169.254.0.0/16`), and IPv6 equivalents — this dial-time check also defeats DNS-rebinding.
  - `ValidateURL` (`internal/webhook/validate.go:62`) performs an earlier, request-time check (scheme + DNS resolution against the same reserved-IP list) when a webhook URL is registered/saved.
