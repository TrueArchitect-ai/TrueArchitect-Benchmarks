**Premise correction:** This repo has no GraphQL schema — there's no GraphQL API anywhere in the codebase (confirmed via search for `.graphql`/`.gql` files and "graphql" references across `.go`, `.proto`, `.md`, `.yaml` files: no matches).

**Actual API surface:** The public API is defined as **Protocol Buffers**, served over gRPC and exposed as REST/OpenAPI via a gRPC-gateway:
- Proto service/message definitions: `proto/api/**/*.proto` (e.g. `proto/api/v1/`)
- Buf tooling config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`
- Generated Go code: `proto/gen/`
- Embedded OpenAPI spec (generated from the same proto definitions, for the REST surface): `proto/openapi_embed.go`

The README itself describes it as "full REST and gRPC APIs," consistent with a proto-first design rather than GraphQL.
