h03. `internal/idp`; `internal/idp/oauth2`

The abstraction lives in `internal/idp` (package `idp`), defining the shared `IdentityProviderUserInfo` type used by all provider implementations (`internal/idp/idp.go`). The concrete protocol implementation is `internal/idp/oauth2` (package `oauth2`), which implements OAuth2 token exchange and user-info retrieval against that abstraction, using `golang.org/x/oauth2` (`internal/idp/oauth2/oauth2.go`).
