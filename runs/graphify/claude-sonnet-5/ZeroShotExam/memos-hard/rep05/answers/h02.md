- **Protection mechanism** — SSRF protection is enforced at two layers in `internal/webhook/`:
  - `validate.go` (`ValidateURL()`, `internal/webhook/validate.go:62`) rejects webhook URLs at registration/edit time if the hostname resolves to a reserved/private IP (checked via `isReservedIP()` against `reservedCIDRs`, `internal/webhook/validate.go:14-54`).
  - `webhook.go` (`safeDialContext()`, `internal/webhook/webhook.go:59`) is wired in as the `DialContext` of the shared `safeClient` HTTP transport (`webhook.go:32-37`), so every actual outbound dial re-resolves the host and blocks reserved/private IPs at connection time — closing the TOCTOU/DNS-rebinding gap that a one-time URL check alone would leave open.
