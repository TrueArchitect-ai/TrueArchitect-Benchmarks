**Premise correction:** There is no GraphQL schema in this repository — Memos does not expose a GraphQL API. The premise of the question is incorrect.

**Actual API surface:** The public API is defined via Protocol Buffers (gRPC + REST, generated with buf/grpc-gateway):

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Internal storage-layer protos: `proto/store/*.proto`
- Generated Go bindings (including the gRPC-gateway REST shim and OpenAPI descriptor): `proto/gen/api/v1/*.pb.go` and `proto/gen/openapi.yaml`
- Codegen config: `proto/buf.yaml` / `proto/buf.gen.yaml`
- Server wiring for these routes: `server/router/api`

So instead of a GraphQL schema, look at `proto/api/v1/*.proto` for the actual public API contract, with `proto/gen/openapi.yaml` as the REST/OpenAPI representation of the same surface.
