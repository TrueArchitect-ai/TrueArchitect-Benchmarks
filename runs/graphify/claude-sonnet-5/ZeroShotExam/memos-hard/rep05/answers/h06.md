**Convergence function — path:** `Post(requestPayload *WebhookRequestPayload) error` — `internal/webhook/webhook.go:127`

`webhook.PostAsync` (same file, line ~198) only enqueues onto `asyncPostQueue`; the 4 worker goroutines started in `init()` drain that queue and all call `Post()`, which builds the `http.Request` to `requestPayload.URL` and issues it via the SSRF-guarded `safeClient` (`http.Client` with `safeDialContext`). Every webhook-triggering RPC path funnels through this one function before the outbound request is actually sent.
