— False premise: there is no GraphQL schema/API. The public API surface is Protobuf-defined gRPC/Connect services under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`), served via Connect handlers (`server/router/api/v1/connect_services.go`); no `graphql`/`gqlgen` code exists in the repo.
