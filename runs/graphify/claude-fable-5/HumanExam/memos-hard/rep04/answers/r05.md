False premise — there is **no GraphQL API**. The public API is protobuf-defined gRPC services (proto/api/v1/*.proto, e.g. memo_service.proto, user_service.proto) served via Connect RPC handlers (server/router/api/v1/connect_handler.go:31-38) and an HTTP/JSON gRPC-Gateway registered at server/server.go:88, plus auxiliary REST-ish surfaces (file server, RSS, MCP).
