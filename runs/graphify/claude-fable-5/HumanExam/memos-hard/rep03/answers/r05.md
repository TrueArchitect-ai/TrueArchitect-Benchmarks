— False premise: there is **no GraphQL** anywhere in the codebase. The public API is **Connect/gRPC** (protobuf services under `server/router/api/v1/`, registered via `connectrpc.com/connect`) exposed as REST/JSON through the **grpc-gateway** (`server/router/api/v1/v1.go`), with auxiliary Echo routes for the fileserver, RSS, and an OpenAPI-driven MCP surface. No GraphQL schema is defined.
