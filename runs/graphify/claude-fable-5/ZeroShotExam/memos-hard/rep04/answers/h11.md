**1st: `User` (~7 external packages); 2nd: `Memo` (~6 external packages)**

The data layer here is the `store` package, which defines the persistent entity structs in files like `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/idp.go`, `store/reaction.go`, etc. Counting distinct Go packages outside the `store/` tree that reference each type (`store.<Type>`):

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Runners-up: `Attachment` (4), then `Inbox`, `MemoRelation`, `MemoShare` (3 each).

The ranking is stable under alternative counting rules: including the driver sub-packages inside the layer (`store/db/mysql`, `store/db/postgres`, `store/db/sqlite`, `store/test`) gives User 11 vs Memo 10, and excluding test packages gives User 6 vs Memo 5 — `User` leads and `Memo` is second either way.
