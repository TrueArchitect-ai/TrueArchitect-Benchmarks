**Premise correction:** This repository (memos) has no GraphQL API and no GraphQL schema anywhere. A repo-wide search for "graphql", gqlgen, or Apollo turns up nothing in the Go module, the web app's dependencies, or the source tree.

**Actual API surface:** The public API is defined with Protocol Buffers as gRPC services, served over Connect RPC and a grpc-gateway HTTP/JSON layer:

- **Schema definitions:** `proto/api/v1/*.proto` — one file per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. Code generation is managed with buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).
- **Generated code:** Go stubs in `proto/gen/api/v1/` (e.g. `user_service_grpc.pb.go`) and TypeScript clients for the web frontend in `web/src/types/proto/api/v1/` (e.g. `user_service_pb.ts`).
- **Server implementation:** `server/router/api/v1/v1.go` — `APIV1Service` embeds the `Unimplemented*ServiceServer` types and registers both the Connect RPC handlers and the grpc-gateway (`.RegisterGateway()` at `server/router/api/v1/v1.go:65`), which is what exposes the REST/JSON surface. An OpenAPI description is also embedded via `proto/openapi_embed.go`.

So if you're looking for the API contract, edit the `.proto` files in `proto/api/v1/` — that's the source of truth, not a GraphQL schema.
