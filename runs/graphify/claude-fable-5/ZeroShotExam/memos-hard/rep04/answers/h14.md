**Computation site:** `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`. It delegates the actual parsing to the goldmark-based markdown service — `ExtractAll()` in `internal/markdown/markdown.go:356` (with the equivalent single-purpose `ExtractProperties()` at `internal/markdown/markdown.go:193`) — which does one AST walk over the memo content and fills `memo.Payload` (a `storepb.MemoPayload`) with `data.Tags` and `data.Property`.

**Triggers for recomputation:**
- **Memo creation** — `CreateMemo` in `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` before persisting.
- **Memo update, only when the `content` field is in the update mask** — `UpdateMemo` in `server/router/api/v1/memo_service.go:447` rebuilds the payload after swapping in the new content (other field updates like visibility/pinned don't recompute it).
- **Bulk rebuild of all memos** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` pages through every memo in batches of 100, rebuilds each payload, and writes it back via `Store.UpdateMemo` (a migration/repair pass over existing data).

**Extracted properties:** from the single markdown parse:
- `Tags` — all `#tag` nodes, deduplicated case-preservingly.
- `Property.Title` — plain text of an H1 heading if it's the document's first block.
- `Property.HasLink` — any link node present.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any task checkbox; `Property.HasIncompleteTasks` — at least one unchecked checkbox.

(`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` stores only `Tags` and `Property`; `Payload.Location` is set separately from the request, not derived from content.)
