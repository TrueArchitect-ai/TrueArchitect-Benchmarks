**RPC handler methods** (all in `server/router/api/v1/`, exposed via `ConnectServiceHandler` in `connect_services.go`, implemented on `APIV1Service`) that can transitively fire an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `memo_service.go:70`, calls `DispatchMemoCreatedWebhook` at `memo_service.go:157`.
2. **`UpdateMemo`** — `memo_service.go:401`, dispatches via `memo_update_helpers.go:67` (`DispatchMemoUpdatedWebhook`).
3. **`DeleteMemo`** — `memo_service.go:518`, calls `DispatchMemoDeletedWebhook` at `memo_service.go:562`.
4. **`CreateMemoComment`** — `memo_service_comments.go:20`, calls `DispatchMemoCommentCreatedWebhook` at `memo_service_comments.go:119`.

Each dispatcher (`server/router/api/v1/memo_service_webhooks.go`) loads the creator's webhooks from the store (`GetUserWebhooks`), sets `payload.URL = hook.Url` (the URL the user registered via `CreateUserWebhook`/`UpdateUserWebhook`), and enqueues through `webhook.PostAsync`.

**Convergence function — `webhook.Post` at `internal/webhook/webhook.go:117`.** Both the synchronous helper and the async queue drain into it (the four background workers started in `init()` each call `Post`, and `PostAsync` at `internal/webhook/webhook.go:186` just enqueues to it). `Post` is where the paths converge before delivery: it marshals the payload, builds the `http.NewRequest("POST", requestPayload.URL, …)`, signs it, and sends it via the shared `safeClient.Do(req)` — the single actual outbound HTTP call.
