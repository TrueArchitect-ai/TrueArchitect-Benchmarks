**Premise correction: there is no nightly database-cleanup job scheduled in the cron scheduler.** I checked both the knowledge graph (`graphify-out/graph.json`) and the source directly.

The repository does contain a cron scheduler package — `internal/scheduler/` (`scheduler.go`, `parser.go`, `job.go`) — but no production code ever registers a job with it. Its only importers are its own test files (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`); no application code calls `scheduler.New()` or `Scheduler.Register()`.

The closest things to the question's premise, neither of which is a scheduled nightly database cleanup:

- `internal/scheduler/doc.go:14-16` shows a **documentation example** of a hypothetical job named `"daily-cleanup"` with schedule `"0 2 * * *"` (2 AM daily) — illustrative usage only, not a real registered job, and not database-related.
- `store/cache/cache.go` runs a `cleanupLoop()` for the in-memory cache on a ticker (default `CleanupInterval: 5 * time.Minute` per `store/store.go:42`) — a periodic goroutine, not a cron-scheduled job, and it cleans the cache, not the database.

So if the question expects a specific time, the honest answer is that no such job exists; the "0 2 * * *" (2 AM) figure appears only in an example comment in `internal/scheduler/doc.go`.
