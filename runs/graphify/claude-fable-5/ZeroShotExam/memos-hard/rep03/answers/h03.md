**`internal/idp`; `internal/idp/oauth2`**

The `internal/idp` package defines the provider abstraction — `internal/idp/idp.go` declares the shared `IdentityProviderUserInfo` type that any provider returns after authenticating a user. The one concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2/oauth2.go`, whose package comment reads "Package oauth2 implements the OAuth2 identity provider integration"; it wraps `storepb.OAuth2Config` and imports `github.com/usememos/memos/internal/idp` for the shared user-info contract. The knowledge-graph query corroborates this on the frontend side (`web/src/components/IdentityProviderButtons.tsx`, `web/src/utils/oauth.ts` with PKCE/RFC-7636 handling), but the abstraction and implementation themselves live in the two Go packages above.
