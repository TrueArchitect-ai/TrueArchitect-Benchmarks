Each of these resolves the user's stored webhook URLs and calls `webhook.PostAsync` (the async wrapper in `memo_service_webhooks.go`, e.g. lines 43 and 71), which enqueues onto `asyncPostQueue`. The four worker goroutines draining that queue (`internal/webhook/webhook.go:46`) all invoke the same function.

**Convergence function:** `webhook.Post` — `internal/webhook/webhook.go:120`

`Post` is where every path converges before delivery: it marshals the payload, builds the `http.NewRequest("POST", requestPayload.URL, …)`, signs it, and fires the actual request via `safeClient.Do(req)` (line 152). The URL comes straight from the user-configured webhook (`WebhookRequestPayload.URL`), and `safeClient`'s `safeDialContext` is the SSRF guard that blocks reserved/private IPs at dial time.
