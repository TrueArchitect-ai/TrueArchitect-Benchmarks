**Premise correction:** This repository has no GraphQL schema — the public API is not GraphQL. A repo-wide search for "graphql" turns up nothing (in Go, TypeScript, proto, or docs), and the knowledge graph for the codebase confirms no GraphQL-related nodes exist.

**Actual API surface:** The public API is defined as Protocol Buffers (gRPC), with the schema living in `proto/api/v1/` — one `.proto` file per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. Code is generated from these with `buf generate` (see `proto/README.md`) into `proto/gen/api/v1/` (Go stubs) and `web/src/types/proto/api/v1/` (TypeScript for the web client).

That schema is exposed over HTTP in two ways, wired up in `server/router/api/v1/v1.go`:
- **grpc-gateway** (`RegisterGateway()` at `server/router/api/v1/v1.go:65`), which serves RESTful JSON translations of the gRPC methods via the generated `*.pb.gw.go` files.
- **Connect RPC** handlers for browser clients (`server/router/api/v1/connect_handler.go`, mounted at `/memos.api.v1.*` around `server/router/api/v1/v1.go:141`), which replaced grpc-web.

So if you're looking for "the schema of the public API," the files to edit are the `.proto` definitions under `proto/api/v1/`, not a GraphQL SDL file.
