**Computation site.** The derived metadata is the memo's payload — `memo.Payload.Tags` and `memo.Payload.Property` — computed by `memopayload.RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`. It delegates to the goldmark-based `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356`), which parses the memo's markdown content once and walks the AST in a single pass.

**Triggers for recomputation.**
- **Memo creation**: `CreateMemo` calls `RebuildMemoPayload` before inserting (`server/router/api/v1/memo_service.go:108`). This also covers comments, since `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go`) goes through `CreateMemo` internally.
- **Memo update, only when the update mask includes `content`**: `UpdateMemo` rebuilds the payload after swapping in the new content (`server/router/api/v1/memo_service.go:447`). Updates to visibility, pinned, state, etc. do not recompute it.
- **Bulk maintenance rebuild**: `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives the payload for every memo in batches of 100 and persists via `Store.UpdateMemo`.

**What it extracts** (`ExtractAll`, `internal/markdown/markdown.go:356-423`):
- **Tags** — from custom memo-tag AST nodes, deduplicated case-preservingly (stored as `Payload.Tags`).
- **Property** (`storepb.MemoPayload_Property`, stored as `Payload.Property`, fields in `store/memo.go:87-90`):
  - `Title` — plain text of a level-1 heading when it is the document's first block
  - `HasLink` — any markdown link node
  - `HasCode` — code block, fenced code block, or inline code span
  - `HasTaskList` — any task checkbox
  - `HasIncompleteTasks` — any unchecked task checkbox
- (`ExtractAll` also collects lowercased `@mentions`, but only Tags and Property are written to the stored payload by `RebuildMemoPayload`.)

These stored properties feed list views and stats (e.g. `server/router/api/v1/memo_service_converter.go:315-323`, `user_service_stats.go`). One related preview field, the content `Snippet`, is *not* stored — it's derived on the fly at response-conversion time via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`).
