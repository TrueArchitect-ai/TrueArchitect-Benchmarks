**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package (`store/*.go`), whose persistent entity types are the structs `Memo` (`store/memo.go`), `User` (`store/user.go`), `Attachment` (`store/attachment.go`), `Inbox`, `IdentityProvider`, `Reaction`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, and `InstanceSetting`.

Counting distinct Go packages outside `store/` (and its `store/db` drivers) that reference each type as `store.<Type>`:

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

The rest trail well behind: `Attachment` (4), then `Inbox`/`MemoRelation`/`MemoShare` (3 each), `Reaction`/`UserIdentity` (2), and `IdentityProvider`/`UserSetting`/`InstanceSetting` (0 — used only inside the store layer itself). If you exclude the test package, the ranking is unchanged (User 6, Memo 5).
