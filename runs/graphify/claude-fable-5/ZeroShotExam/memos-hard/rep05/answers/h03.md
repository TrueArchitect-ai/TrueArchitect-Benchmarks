The abstraction lives in `internal/idp` and the shipped protocol implementation is `internal/idp/oauth2`.

- **Abstraction package:** `internal/idp` — `internal/idp/idp.go` defines the provider-agnostic types (e.g. `IdentityProviderUserInfo`, the normalized user info a provider must return).
- **Implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration") provides the concrete `IdentityProvider` type with `NewIdentityProvider`, `ExchangeToken` (including PKCE support), and user-info fetching, configured via `storepb.OAuth2Config`. It is the only protocol subpackage under `internal/idp`.

**Answer:** `internal/idp`; `internal/idp/oauth2`
