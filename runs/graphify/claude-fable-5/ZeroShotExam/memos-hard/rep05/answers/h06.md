**RPC handlers that transitively trigger an outbound HTTP request to a user-configured URL** (all are memo-service methods exposed through `ConnectServiceHandler` in `server/router/api/v1/connect_services.go`, delegating to `APIV1Service`):

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`
2. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`
3. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects`
6. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects`

Each `Dispatch*` helper (in `server/router/api/v1/memo_service_webhooks.go`) loads the user's registered webhook records and builds a `WebhookRequestPayload` whose `URL` comes from the user-configured webhook (set via `CreateUserWebhook`/`UpdateUserWebhook`), then calls `webhook.PostAsync`. `PostAsync` enqueues onto `asyncPostQueue`, whose worker goroutines all call `Post`.

**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**, where the actual outbound POST is issued by `safeClient.Do(req)` at line 152. Both the async path (`PostAsync` → queue workers) and any direct call funnel through this single function before delivery.

(For contrast, `CreateUserWebhook`/`UpdateUserWebhook` are where the URL is *configured*, not where the outbound request is made.)
