**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for "graphql" across Go, TypeScript, proto, markdown, and config files (excluding `node_modules`) returns zero hits — this project (memos) does not expose a GraphQL API.

**Actual API surface:** The public API is defined as **gRPC services in Protocol Buffer files**, served over gRPC/Connect with a REST mapping via grpc-gateway:

- **Schema definitions (the source of truth):** `proto/api/v1/*.proto` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. Codegen is configured with buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).
- **Generated code:** `proto/gen/api/v1/` (e.g. `memo_service_grpc.pb.go`, `memo_service.pb.gw.go` for the grpc-gateway REST handlers).
- **Server implementation:** `server/router/api/v1/v1.go` — `APIV1Service` (line 22) embeds the generated `Unimplemented*ServiceServer` types and registers both the gRPC services and the HTTP gateway (`RegisterGateway()` around line 65), using `connectrpc.com/connect` and `grpc-gateway`.
- **REST/OpenAPI description:** the generated `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.

So if you're looking for "the API schema," edit the `.proto` files under `proto/api/v1/` and regenerate with buf — there is no `.graphql`/SDL file to find.
