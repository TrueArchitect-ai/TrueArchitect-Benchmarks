The abstraction lives in **`internal/idp`** and the shipped protocol implementation is **`internal/idp/oauth2`**.

- `internal/idp/idp.go` (package `idp`) defines the provider-neutral abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any identity provider must produce.
- `internal/idp/oauth2/oauth2.go` (package `oauth2`) is the one concrete protocol implementation that ships: "Package oauth2 implements the OAuth2 identity provider integration." Its `IdentityProvider` type wraps a `storepb.OAuth2Config` and implements token exchange (including PKCE) and user-info retrieval, returning the `idp` package's user-info struct. It has tests in `internal/idp/oauth2/oauth2_test.go`, and the web UI counterparts (e.g. `web/src/components/IdentityProviderButtons.tsx`, `web/src/utils/oauth.ts`) drive the same OAuth2 flow.

Answer: `internal/idp`; `internal/idp/oauth2`
