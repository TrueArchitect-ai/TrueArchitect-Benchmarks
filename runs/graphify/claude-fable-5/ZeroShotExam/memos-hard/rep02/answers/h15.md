h15.

Memo visibility is enforced independently at each server surface that can expose a memo (or content derived from one). The distinct enforcement sites are:

- gRPC memo API — read access check (`checkMemoReadAccess`, `server/router/api/v1/memo_service.go:39-68`; public/protected/private + archived-only-to-creator rules) and list-query scoping (`ListMemos` restricts `VisibilityList`/filters by viewer, `server/router/api/v1/memo_service.go:217-226`) — `server/router/api/v1/memo_service.go`
- Memo comments API — `CreateMemoComment` denies commenting on another user's private memo — `server/router/api/v1/memo_service_comments.go` (line 41)
- Reactions API — `ListMemoReactions` and `UpsertMemoReaction` gate on the memo's visibility — `server/router/api/v1/reaction_service.go` (lines 30–39, 83–84)
- Attachment metadata API — attachment access is gated by the owning memo's visibility — `server/router/api/v1/attachment_service.go` (lines 445–451)
- Memo-attachment listing API — `ListMemoAttachments` applies the same public/protected/private rules — `server/router/api/v1/memo_attachment_service.go` (lines 214–223)
- File server (attachment binary serving) — checks memo visibility, anonymous-access policy, and share-token fallback before serving the file — `server/router/fileserver/fileserver.go` (lines ~665–703)
- SSE real-time event delivery — `SSEClient.canReceive` filters memo events per subscriber (private events only to creator or admin) — `server/router/api/v1/sse_hub.go` (lines 134–144)
- RSS feeds — feed queries hard-restrict to `store.Public` memos — `server/router/rss/rss.go` (lines 90, 141)
- Frontend router (sitemap/share pages) — sitemap generation lists only public memos — `server/router/frontend/frontend.go` (line 150)
- User stats API — memo stats are computed over only the visibilities the viewer may see — `server/router/api/v1/user_service_stats.go` (lines 84–90, 218–220)

The first six are direct per-request access checks; the SSE hub enforces it at event-delivery time, and the RSS/frontend/stats surfaces enforce it by constraining the store query to public (or public+protected) visibility.
