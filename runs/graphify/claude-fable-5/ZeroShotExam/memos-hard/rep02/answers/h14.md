**Computation site.** The derived metadata is the memo's payload — tags plus a `Property` block — rebuilt from the markdown content by `memopayload.RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356`), which does a single goldmark AST walk over the content; the same property logic also exists standalone as `ExtractProperties()` at `internal/markdown/markdown.go:193`. The results are stored on `memo.Payload` (`storepb.MemoPayload_Property`) and surfaced to the API via `convertMemoPropertyFromStore()` in `server/router/api/v1/memo_service_converter.go:315`.

**Triggers.** Recomputation happens on:
- **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` before persisting (`server/router/api/v1/memo_service.go:108`).
- **Memo content update** — `UpdateMemo` calls it whenever the update mask includes the `content` path (`server/router/api/v1/memo_service.go:447`).
- **Bulk rebuild** — the `memopayload.Runner.RunOnce` batch job re-derives payloads for all memos in batches of 100 and writes them back with `Store.UpdateMemo` (`server/runner/memopayload/runner.go:27`). (This runner is defined but not currently wired into the startup sequence in `server/server.go`, which only invokes the s3presign runner.)

**Extracted properties.** From the single AST walk:
- `Tags` — all `#tag` nodes in the content (stored as `Payload.Tags`)
- `Property.Title` — the plain text of the first block-level element if it's an H1 heading
- `Property.HasLink` — any markdown link node
- `Property.HasCode` — any code block, fenced code block, or inline code span
- `Property.HasTaskList` — any task checkbox
- `Property.HasIncompleteTasks` — any unchecked task checkbox

(`ExtractAll` also collects `@mentions`, but those feed relation handling in `server/router/api/v1/memo_mention_helpers.go:32` rather than the stored payload.)
