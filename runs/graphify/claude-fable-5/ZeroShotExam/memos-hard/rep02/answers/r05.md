**Premise correction:** This repository (Memos, the self-hosted note-taking app) has no GraphQL API at all — a case-insensitive search for "graphql" across the repo returns zero matches, so there is no GraphQL schema anywhere.

**Actual API surface:** The public API is defined as gRPC services in Protocol Buffer files under `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus services for instances, shortcuts, identity providers, and AI. Code is generated with `buf` (`proto/buf.gen.yaml`, per `proto/README.md`) into `proto/gen/`, which includes both the gRPC stubs (`*.pb.go`) and grpc-gateway REST bindings (`*.pb.gw.go`), so the same definitions are also served as an HTTP/JSON REST API. A generated OpenAPI description of that REST surface lives at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`), and the services are wired up in `server/router/api/`. Internal storage messages are separately defined in `proto/store/`.
