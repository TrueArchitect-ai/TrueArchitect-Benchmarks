h07.

The browser requests another user's avatar via the URL `/file/{user-resource-name}/avatar` — the frontend `UserAvatar` renders `<img src={avatarUrl}>`, and that `avatarUrl` is rewritten by the API's user converter to point at the fileserver endpoint (rather than embedding the raw base64), so the `<img>` fetch lands on the Go fileserver route. From there it walks down through the store into the SQL driver, which reads the `avatar_url` column; the handler then base64-decodes that stored data URI and writes the image bytes back.
