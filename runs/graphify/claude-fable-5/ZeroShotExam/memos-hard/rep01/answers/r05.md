**Premise correction:** This repository has no GraphQL API at all — a grep for "graphql" across Go, TypeScript, proto, and config files returns zero matches, so there is no GraphQL schema to point to.

**Actual API surface:** The public API is a gRPC/Protobuf API (this is the `usememos/memos` project). Its schema equivalent is the set of Protocol Buffer service definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`

Generated Go stubs live in `proto/gen/api/v1/` (e.g. `proto/gen/api/v1/user_service_grpc.pb.go`). The services are implemented by `APIV1Service` in `server/router/api/v1/v1.go:22`, which embeds each `Unimplemented*ServiceServer` and exposes everything over HTTP/JSON via **gRPC-Gateway** and **Connect** (connectrpc.com) handlers registered in `RegisterGateway()` at `server/router/api/v1/v1.go:65`. So REST-style HTTP access exists, but it's transcoded from the proto definitions — the `.proto` files are the single source of truth for the public API, not a GraphQL schema.
