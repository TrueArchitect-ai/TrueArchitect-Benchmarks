**Handlers that can transitively trigger an outbound webhook HTTP request to a user-configured URL:**

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`.
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:67`) → `DispatchMemoUpdatedWebhook`.
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`.
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`.
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.
6. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`.

Each dispatcher loads the creator's/owner's stored webhooks (`Store.GetUserWebhooks`), sets `payload.URL = hook.Url` (the user-configured URL from `CreateUserWebhook`/`UpdateUserWebhook`), and hands off to `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43,71`). `PostAsync` enqueues onto `asyncPostQueue`, and the background worker goroutines call the delivery function.

**Convergence function — delivery:** `webhook.Post` — `internal/webhook/webhook.go` (line 118). This is the single point where every path converges: it builds the request to `requestPayload.URL` and issues the actual network call via `safeClient.Do(req)` (line ~158). `PostAsync` merely enqueues; the queue workers (`init()` in the same file) all funnel into `Post`.

(For completeness, a separate outbound-HTTP-to-user-URL path exists via `internal/httpgetter` for link-preview/image fetching, but that is a different pipeline and does not converge on `webhook.Post`.)
