MySQL, PostgreSQL, SQLite

The project ships SQL migrations for three dialects, one directory per database driver under `store/migration/` — `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/`. These are embedded into the binary via `//go:embed migration` in `store/migrator.go:44` and resolved per driver through the `store/migration/{driver}/{version}/NN__description.sql` layout described in `store/migrator.go:39`. The matching driver implementations live in `store/db/mysql/`, `store/db/postgres/`, and `store/db/sqlite/`.
