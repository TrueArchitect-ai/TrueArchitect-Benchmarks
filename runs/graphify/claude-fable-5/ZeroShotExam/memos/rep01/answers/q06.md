**`memo_relation`**

This table links one memo to another via `memo_id` and `related_memo_id` columns (plus a relation `type`). It's defined in the schema migrations, e.g. `store/migration/mysql/LATEST.sql:46`, and accessed by the driver-specific store code in `store/db/sqlite/memo_relation.go`, `store/db/mysql/memo_relation.go`, and `store/db/postgres/memo_relation.go`.
