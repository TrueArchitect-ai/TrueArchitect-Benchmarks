`store/migration/sqlite/LATEST.sql`

On a fresh (uninitialized) database, the migrator applies this single file as the complete current schema instead of running incremental migrations — see the comments in `store/migrator.go:27` ("Check if DB is initialized. If not, apply LATEST.sql") and `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"), with `LatestSchemaFileName = "LATEST.sql"` defined at `store/migrator.go:56`. The behavior is verified by `store/test/migrator_test.go:18` (`TestFreshInstall`). The versioned directories under `store/migration/sqlite/0.x/` are only for upgrading existing installs.
