`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) SQLite database, the migrator applies this single file containing the full current schema instead of replaying the incremental version-folder migrations. This is confirmed in `store/migrator.go`, which defines `LatestSchemaFileName = "LATEST.sql"` (line 56) and documents it as "Full schema for new installations (faster than incremental migrations)" (line 42), applied by `preMigrate` when the DB is not initialized (line 27).
