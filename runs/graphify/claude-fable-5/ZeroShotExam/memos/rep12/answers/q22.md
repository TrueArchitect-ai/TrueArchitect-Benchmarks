- **Dispatch from the handler:** `CreateMemo` in `server/router/api/v1/memo_service.go:157` calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)`, which delegates to the shared dispatcher `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`) with activity type `"memos.memo.created"`. - **Delivery package:** `github.com/usememos/memos/internal/webhook` (`internal/webhook/webhook.go`). `PostAsync` pushes the payload onto a bounded async queue drained by 4 worker goroutines that call `Post`, which sends the JSON payload over an SSRF-guarded `http.Client`.
- **Signing mechanism:** Standard Webhooks-style HMAC-SHA256. If the hook has a signing secret (`whsec_<base64>` secrets are base64-decoded to raw key bytes), `Post` computes `HMAC-SHA256(key, "<msgID>.<timestamp>." + body)` and sets the `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 MAC>` headers (`internal/webhook/webhook.go:133-150`).
