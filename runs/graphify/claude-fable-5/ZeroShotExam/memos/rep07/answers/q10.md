**`store/migration/sqlite/LATEST.sql`**

On a fresh (uninitialized) database, the migrator applies this file directly instead of replaying incremental migrations. This is confirmed in `store/migrator.go`: the comments state "preMigrate: Check if DB is initialized. If not, apply LATEST.sql" and "LATEST.sql: Full schema for new installations (faster than incremental migrations)", with the constant `LatestSchemaFileName = "LATEST.sql"` at `store/migrator.go:56`. The versioned directories under `store/migration/sqlite/0.x/` hold only incremental migrations for upgrading existing installs.
