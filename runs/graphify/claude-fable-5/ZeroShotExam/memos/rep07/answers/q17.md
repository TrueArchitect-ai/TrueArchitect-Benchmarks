**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

The module `web/src/hooks/useMemoQueries.ts` holds the memo CRUD operations built on TanStack Query — `useQuery` hooks for listing/getting memos and comments, plus `useMutation` hooks that call `createMemo`, `updateMemo`, and `deleteMemo`. All of these go through the generated Connect service client `memoServiceClient`, which it imports from `web/src/connect.ts` (line 5: `import { memoServiceClient } from "@/connect"`), with request/response types coming from the generated protobuf module `web/src/types/proto/api/v1/memo_service_pb.ts`.
