**Driver — store/driver.go**

The `Driver` interface is defined at `store/driver.go:10` in package `store`. Its doc comment says it "contains all methods that store database driver should implement" — `GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`, plus CRUD methods for every model (attachments, memos, users, etc.).

All three database backends implement it: the SQLite, MySQL, and Postgres drivers each return a `store.Driver` from their `NewDB` constructors (`store/db/sqlite/sqlite.go:24`, `store/db/mysql/mysql.go:20`, `store/db/postgres/postgres.go:21`), and `store/db/db.go:14` (`NewDBDriver`) selects among them based on the configured profile.
