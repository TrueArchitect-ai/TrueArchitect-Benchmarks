The three implementations of the `store.Driver` interface (defined in `store/driver.go`) each live in their own package under `store/db/`, with these entry files:

- `store/db/sqlite/sqlite.go` — SQLite driver (`sqlite.NewDB`)
- `store/db/mysql/mysql.go` — MySQL driver (`mysql.NewDB`)
- `store/db/postgres/postgres.go` — PostgreSQL driver (`postgres.NewDB`)

The factory that selects between them at startup is **`NewDBDriver`** in `store/db/db.go` (line 14), which switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and returns the matching `store.Driver`, erroring on any unknown value.
