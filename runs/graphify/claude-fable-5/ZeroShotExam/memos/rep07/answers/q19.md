MemoService is served over **gRPC-Gateway (REST/HTTP JSON)** and **Connect RPC**, both registered inside `APIV1Service.RegisterGateway`:

1. **gRPC-Gateway (RESTful HTTP/JSON)** — `server/router/api/v1/v1.go`. `RegisterGateway` builds a `runtime.NewServeMux` and calls `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (v1.go:108), mounting it on Echo at `/api/v1/*`. The generated gateway code itself lives in `proto/gen/api/v1/memo_service.pb.gw.go`.

2. **Connect RPC (connectrpc.com, for browser clients — replaces grpc-web)** — `server/router/api/v1/connect_handler.go`, where `RegisterConnectHandlers` wraps `apiv1connect.NewMemoServiceHandler(s, opts...)` (line 40) onto an `http.ServeMux`. The per-method Connect→gRPC adapter shims for MemoService (`CreateMemo`, `ListMemos`, …) are in `server/router/api/v1/connect_services.go` (starting around line 304).

Answer format as requested:
- gRPC-Gateway (HTTP/JSON REST) — `server/router/api/v1/v1.go` (generated handlers in `proto/gen/api/v1/memo_service.pb.gw.go`)
- Connect RPC — `server/router/api/v1/connect_handler.go` (method wrapping in `server/router/api/v1/connect_services.go`)
