**SQLite, MySQL, PostgreSQL**

The project ships versioned SQL migrations under `store/migration/`, with one subdirectory per dialect: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/`. Each contains versioned migration folders (e.g. `0.17`–`0.30`) plus a `LATEST.sql`, and they're applied by `store/migrator.go` via the corresponding drivers (e.g. `store/db/sqlite/sqlite.go`).
