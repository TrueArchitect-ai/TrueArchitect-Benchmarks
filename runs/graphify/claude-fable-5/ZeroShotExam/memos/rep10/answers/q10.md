`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies this single file rather than running incremental migrations. This is documented in `store/migrator.go`: the `preMigrate` step checks if the DB is initialized and, if not, applies `LATEST.sql`, described as the "Full schema for new installations (faster than incremental migrations)" (see `store/migrator.go:27`, `:42`, and the `LatestSchemaFileName = "LATEST.sql"` constant at `:56`). The versioned directories alongside it (`store/migration/sqlite/0.2/` … `0.30/`) are only used to upgrade existing installs.
