The domain structs in the `store` package are the ones the database drivers read from and write to for these tables (confirmed by the `INSERT INTO user` / `INSERT INTO attachment` / `INSERT INTO reaction` statements in `store/db/sqlite/user.go:17`, `store/db/sqlite/attachment.go:34`, and `store/db/sqlite/reaction.go:16`):

- `attachment`: **Attachment** — `store/attachment.go:16`
- `reaction`: **Reaction** — `store/reaction.go:7`

(Note: `proto/gen/api/v1/user_service.pb.go` also defines a `User` struct, but that is the generated API message, not the database-table mapping.)
