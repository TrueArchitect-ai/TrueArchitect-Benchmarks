Server-Sent Events (SSE); hub at `server/router/api/v1/sse_hub.go`; broadcasting memo handlers: **CreateMemo**, **UpdateMemo**, **DeleteMemo**, **CreateMemoComment**.

Details:

- **Mechanism:** SSE. The hub defines `SSEHub` with a `Broadcast()` method (`server/router/api/v1/sse_hub.go:56`, `:115`), and the HTTP endpoint is wired up in `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes`/`handleSSE` on an Echo router), registered from `server/router/api/v1/v1.go:125`. The browser side consumes it via hooks like `web/src/hooks/useLiveMemoRefresh.ts`.
- **Memo handlers that broadcast through `s.SSEHub.Broadcast(...)`:**
  - `CreateMemo` — emits `memo.created` (`server/router/api/v1/memo_service.go:163`, suppressed when invoked from CreateMemoComment)
  - `UpdateMemo` — emits `memo.updated` via the `dispatchMemoUpdatedSideEffects` helper (`server/router/api/v1/memo_service.go:513` → `server/router/api/v1/memo_update_helpers.go:71`)
  - `DeleteMemo` — emits `memo.deleted` (`server/router/api/v1/memo_service.go:585`)
  - `CreateMemoComment` — emits `memo.comment.created` for the parent memo (`server/router/api/v1/memo_service_comments.go:126`)

Additionally, the reaction handlers `UpsertMemoReaction` and `DeleteMemoReaction` broadcast memo-scoped events (`reaction.upserted`/`reaction.deleted`) through the same hub (`server/router/api/v1/reaction_service.go:106`, `:161`), if you count them among memo-related handlers.
