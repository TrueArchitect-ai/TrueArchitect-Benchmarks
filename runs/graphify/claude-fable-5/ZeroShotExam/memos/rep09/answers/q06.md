**`memo_relation`**

This table stores links between one memo and another related memo. Its schema — `memo_id`, `related_memo_id`, and `type` with a `UNIQUE(memo_id, related_memo_id, type)` constraint — is defined in the migration files for all three supported databases: `store/migration/sqlite/LATEST.sql:47`, `store/migration/postgres/LATEST.sql:46`, and `store/migration/mysql/LATEST.sql:46`. The corresponding data-access code lives in `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
