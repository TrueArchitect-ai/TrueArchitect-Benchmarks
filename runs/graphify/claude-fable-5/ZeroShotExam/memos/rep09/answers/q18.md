The database driver interface is `store.Driver` (defined in `store/driver.go:10`), and it has three implementations, one per database backend:

- `store/db/sqlite/sqlite.go` — SQLite driver (`sqlite.NewDB`)
- `store/db/mysql/mysql.go` — MySQL driver (`mysql.NewDB`)
- `store/db/postgres/postgres.go` — PostgreSQL driver (`postgres.NewDB`)

**NewDBDriver** — `store/db/db.go:14` is the factory that selects between them at startup, switching on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and returning the matching `store.Driver`, or an "unknown db driver" error otherwise.
