**s3presign runner — the only background runner the server starts.** `Server.Start` calls `startBackgroundRunners` (`server/server.go:129`, `server/server.go:153-174`), which runs `s3presign.NewRunner(s.Store)` once immediately (`RunOnce`) and then in a goroutine via `Run`. Its scheduling is driven by a plain `time.Ticker` with a hard-coded 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:26-41`), cancelled through a per-runner `context.CancelFunc` on shutdown.

**Unused scheduling infrastructure:**

- `internal/scheduler/` — a complete cron scheduler package (cron-expression parser, timezone handling, middleware, graceful shutdown; `scheduler.go`, `parser.go`, `job.go`, `middleware.go`, plus a README calling it "production-ready") is **not imported anywhere outside its own package and tests**. The server never uses it; the s3presign runner uses a raw `time.Ticker` instead.
- `server/runner/memopayload/runner.go` also defines a `Runner` with `NewRunner`/`RunOnce`, but it is **never started as a background runner** — only its standalone helper `RebuildMemoPayload` is called synchronously from `server/router/api/v1/memo_service.go:108,447`.
