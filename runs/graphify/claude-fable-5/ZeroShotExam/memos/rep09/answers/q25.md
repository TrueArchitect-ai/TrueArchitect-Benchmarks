**Engine:** CEL (Google Common Expression Language) via `github.com/google/cel-go`, in the `internal/filter` package.

**Mechanism:** Each dialect's `ListMemos` (`store/db/sqlite/memo.go:57`, `store/db/mysql/memo.go:65`, `store/db/postgres/memo.go:54`) gets a `filter.DefaultEngine()` and calls `filter.AppendConditions(...)` (`internal/filter/helpers.go`) with its `DialectName` — the engine compiles the filter string in a CEL environment built from schema-declared variables (`Engine.Compile` in `internal/filter/engine.go`, using `cel.NewEnv` and `cel.AstToParsedExpr`), the parser walks the CEL AST into a dialect-agnostic condition tree (`internal/filter/parser.go`), and a renderer turns that tree into parameterized SQL per dialect (`internal/filter/render.go`), using per-dialect expression templates in the schema (e.g. `DialectSQLite: "('users/' || %s)"` vs `DialectMySQL: "CONCAT('users/', %s)"` in `internal/filter/schema.go:104-135`) plus dialect-specific placeholder/JSON handling.
