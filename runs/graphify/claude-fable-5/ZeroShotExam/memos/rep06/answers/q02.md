**SQLite, MySQL, PostgreSQL**

The project ships versioned SQL migrations for three dialects, one directory per driver under `store/migration/`: `store/migration/sqlite/`, `store/migration/mysql/`, and `store/migration/postgres/` (each containing versioned subdirectories like `0.19/`, `0.20/`, plus a `LATEST.sql`). This layout is documented in `store/migrator.go:39` ("Location: store/migration/{driver}/{version}/NN__description.sql"), and each dialect has a corresponding driver implementation (e.g. `store/db/sqlite/sqlite.go`).
