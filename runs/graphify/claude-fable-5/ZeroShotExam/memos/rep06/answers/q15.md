The store-layer structs in the `store` package are the ones the database drivers (e.g. `store/db/sqlite/user.go:17` with `INSERT INTO user (...)`) read into and write from, so they are the structs that map to these tables:

- `user`: **User** — `store/user.go:29`
- `attachment`: **Attachment** — `store/attachment.go:16`
- `reaction`: **Reaction** — `store/reaction.go:7`

(The `User` type in `proto/gen/api/v1/user_service.pb.go` that the knowledge graph also surfaced is the API/protobuf message, not the database mapping.)
