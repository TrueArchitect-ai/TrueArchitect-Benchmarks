`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from this single file rather than replaying incremental migrations. This is confirmed in `store/migrator.go`, which documents "LATEST.sql: Full schema for new installations (faster than incremental migrations)" and defines `LatestSchemaFileName = "LATEST.sql"` (store/migrator.go:27, store/migrator.go:42, store/migrator.go:56). The incremental version-numbered migrations live alongside it in `store/migration/sqlite/0.10/` through `0.19/` etc., but a fresh install only needs `LATEST.sql`.
