**Driver — store/driver.go**

The `Driver` interface is defined in `store/driver.go:10` ("It contains all methods that store database driver should implement"). All three database backends implement it: SQLite (`store/db/sqlite/sqlite.go:24`), MySQL (`store/db/mysql/mysql.go:20`), and PostgreSQL (`store/db/postgres/postgres.go:21`) each return a `store.Driver` from their `NewDB` constructors, and `store/db/db.go:14` (`NewDBDriver`) selects among them based on the profile.
