When the API handler (`server/router/api/v1/memo_service.go:518` → `s.Store.DeleteMemo`) reaches the store layer, `Store.DeleteMemo` in `store/memo.go:140-158` deletes these other record kinds before issuing the final `driver.DeleteMemo` for the memo row itself:

- **Memo relation records** where the memo is the target (`DeleteMemoRelation{RelatedMemoID: ...}`, `store/memo.go:145`)
