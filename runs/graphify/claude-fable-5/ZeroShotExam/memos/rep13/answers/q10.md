**`store/migration/sqlite/LATEST.sql`**

For a fresh (uninitialized) SQLite database, the migrator applies this single file as the complete current schema instead of replaying incremental migrations. This is confirmed in `store/migrator.go`: line 27 says "Check if DB is initialized. If not, apply LATEST.sql", line 42 documents "LATEST.sql: Full schema for new installations (faster than incremental migrations)", and line 56 defines `LatestSchemaFileName = "LATEST.sql"`. The versioned directories under `store/migration/sqlite/0.x/` hold only incremental migrations for existing installs, and `store/seed/sqlite/01__dump.sql` is seed data, not schema.
