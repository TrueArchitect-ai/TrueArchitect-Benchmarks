**Go `embed` (`//go:embed dist/*`) of the built frontend into the server binary, served via Echo's static middleware with an SPA fallback to `index.html`; `server/router/frontend/frontend.go`**

Details: the compiled React build output is embedded into the Go binary at `server/router/frontend/frontend.go:20-21` (`//go:embed dist/*` into an `embed.FS`). `FrontendService.Serve` (`server/router/frontend/frontend.go:41`) wires it up on the Echo server using `middleware.StaticWithConfig` backed by that embedded filesystem (with cache headers and a skipper for `/api`, `/file`, and gRPC paths), plus `spaFallbackMiddleware` (`server/router/frontend/frontend.go:63`), which serves `index.html` from the embedded FS for 404s on extension-less routes so client-side routing works. The frontend service itself is registered from `NewServer()` in `server/server.go`.
