**Engine:** CEL (Common Expression Language), via `github.com/google/cel-go`. **Path:** `internal/filter/` (engine in `internal/filter/engine.go`, schema/variables in `internal/filter/schema.go`, condition builder in `internal/filter/parser.go`, SQL emitter in `internal/filter/render.go`).

**Mechanism:** The ListMemos handler (`server/router/api/v1/memo_service.go`) validates the filter string and appends it to `FindMemo.Filters`; each store driver (`store/db/sqlite/memo.go:57`, `store/db/mysql/memo.go:65`, `store/db/postgres/memo.go:54`) calls `filter.DefaultEngine()` and `filter.AppendConditions(...)` with its dialect constant. The engine compiles the string in a CEL environment whose variables (`content`, `creator_id`, `pinned`, `tag`, …) are declared in `schema.go`, converts the CEL AST into a dialect-agnostic `Condition` tree (`parser.go`), and then `render.go` renders that tree into a parameterized SQL fragment, switching on `DialectSQLite` / `DialectMySQL` / `DialectPostgres` for dialect-specific bits like placeholders and JSON-extraction functions. The resulting WHERE clause and args are appended to the store's query.
