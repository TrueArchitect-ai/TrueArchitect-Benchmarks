Go `embed` (`//go:embed dist/*` compiles the built React `dist/` output into the server binary as an `embed.FS`, served via Echo's static middleware with an SPA fallback to `index.html`); wired in `server/router/frontend/frontend.go`.

Details: `server/router/frontend/frontend.go:20-21` declares `//go:embed dist/*` into `embeddedFiles embed.FS`. `FrontendService.Serve` (`frontend.go:41-61`) mounts it with `middleware.StaticWithConfig` on the Echo server (skipping `/api`, `/file`, gRPC-web, robots/sitemap paths), and `spaFallbackMiddleware` (`frontend.go:63-80`) serves `index.html` from the embedded FS for client-side routes that 404. So in production there is no separate web server — the compiled frontend ships inside the Go binary.
