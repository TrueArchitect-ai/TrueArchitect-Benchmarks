`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The memo CRUD lives in `web/src/hooks/useMemoQueries.ts`, which wraps TanStack Query hooks (`useQuery`/`useMutation`) around calls like `listMemos`, `getMemo`, `createMemo`, `updateMemo`, and `deleteMemo`. All of those go through `memoServiceClient`, the generated Connect client created in `web/src/connect.ts:197` via `createClient(MemoService, transport)` (with the `MemoService` definition generated into `web/src/types/proto/api/v1/memo_service_pb.ts`).
