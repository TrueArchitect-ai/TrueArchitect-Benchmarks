**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10`, documented as "an interface for store driver" containing "all methods that store database driver should implement" (e.g. `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`).

All three database backends implement it and return `store.Driver` from their constructors:
- SQLite: `store/db/sqlite/sqlite.go:24`
- MySQL: `store/db/mysql/mysql.go:20`
- PostgreSQL: `store/db/postgres/postgres.go:21`

with `store/db/db.go:14` (`NewDBDriver`) selecting the backend at runtime.
