`web/src/connect.ts`

This file imports `createClient` from `@connectrpc/connect`, sets up the Connect transport (with an auth interceptor), and creates all the service clients — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (see `web/src/connect.ts:192-203`). It's the only frontend source file where ConnectRPC clients are instantiated.
