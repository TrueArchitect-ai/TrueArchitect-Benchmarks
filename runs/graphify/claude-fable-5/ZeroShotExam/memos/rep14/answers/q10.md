`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) SQLite database, the migrator applies this single file as the complete current schema instead of replaying incremental migrations. This is documented in `store/migrator.go` — the pre-migrate step "Check if DB is initialized. If not, apply LATEST.sql" (`store/migrator.go:27`), with the comment "LATEST.sql: Full schema for new installations (faster than incremental migrations)" (`store/migrator.go:42`) and the constant `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`). The versioned directories under `store/migration/sqlite/` (e.g. `0.21/`, `0.22/`) hold only incremental migrations for existing installs.
