Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- memo created (`memos.memo.created`): `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15`)
- memo updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:20`)
- memo deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook` (`server/router/api/v1/memo_service_webhooks.go:25`)
- memo comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:30`)

Delivery convergence: the created/updated/deleted dispatchers all funnel through the shared helper `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), while the comment dispatcher builds its payload inline — but all four ultimately converge on `webhook.PostAsync` in `internal/webhook/webhook.go:184`, which enqueues the payload onto `asyncPostQueue` for asynchronous delivery by `Post` (`internal/webhook/webhook.go:120`).
