**Driver — store/driver.go**

The `Driver` interface is defined at `store/driver.go:10`, documented as "an interface for store driver. It contains all methods that store database driver should implement." All three database backends implement it: SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql/mysql.go`), and PostgreSQL (`store/db/postgres/postgres.go`), with the backend selected in `store/db/db.go`. The interface covers connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD methods for each model (Attachment, Memo, etc.).
