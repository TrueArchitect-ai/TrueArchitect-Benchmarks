MemoService is served over **Connect (Connect RPC)** and **HTTP/JSON REST via gRPC-Gateway**:

- **Connect RPC** — `server/router/api/v1/connect_handler.go` (line 40): `RegisterConnectHandlers` wraps `apiv1connect.NewMemoServiceHandler(s, opts...)` and mounts it on the HTTP mux (generated handler in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`).
- **REST (gRPC-Gateway)** — `server/router/api/v1/v1.go` (line 108): `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` registers the service on a `runtime.NewServeMux` gateway, exposed under `/api/v1/*` via Echo (generated gateway in `proto/gen/api/v1/memo_service.pb.gw.go`).

Notably, there is no standalone `grpc.NewServer` registration in the server — the same `APIV1Service` implementation backs both protocols, with the gateway using the in-process `RegisterMemoServiceHandlerServer` variant rather than dialing a gRPC server.
