The server starts exactly one background runner (memos codebase, `server/server.go:153` `startBackgroundRunners`):

- **S3 presign runner** (`server/runner/s3presign/runner.go`) — started in `Server.Start` via `startBackgroundRunners` (`server/server.go:162-171`): it first executes `RunOnce(ctx)` immediately at startup, then runs `Run(ctx)` in a goroutine driven by a `time.NewTicker` with a fixed 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-40`), stopping on context cancellation.

Unused scheduling infrastructure:

- **`internal/scheduler`** — a full GitHub-Actions-style cron scheduler (cron expression parser, timezone support, middleware, graceful shutdown; `internal/scheduler/scheduler.go`, `parser.go`, `job.go`, `middleware.go`, `doc.go`) is present but **never imported by the server or any other package** outside its own directory and tests. The only ticker-based s3presign runner does not use it.
- Additionally, `server/runner/memopayload` (`server/runner/memopayload/runner.go`) defines a `NewRunner`/`RunOnce` runner shape but is never started as a background runner — only its standalone helper `RebuildMemoPayload` is called synchronously from `server/router/api/v1/memo_service.go` (lines 108, 447).
