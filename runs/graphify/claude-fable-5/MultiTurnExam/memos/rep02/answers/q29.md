**Interceptor: `web/src/connect.ts`** — the `authInterceptor` (line 156) is a ConnectRPC `Interceptor` attached to the transport. It sets an `Authorization: Bearer <token>` header on each request (lines 97-99, 159), does a preflight refresh if the access token is expired, and on a 401 reactively refreshes and retries (with a dedup manager so concurrent refreshes coalesce). Token storage/expiry helpers live in `web/src/auth-state.ts`.

**Token kinds:** two JWTs — a **short-lived access token** (~15 minutes, sent as a Bearer header) and a **long-lived refresh token** (~30 days, held in an HTTP-only cookie and exchanged via the `AuthService.RefreshToken` RPC) (`server/auth/token.go:8-9`).

**Backend validation package: `server/auth`** — `Authenticator` (`server/auth/authenticator.go`) validates the JWTs (signed/parsed with `github.com/golang-jwt/jwt/v5` in `server/auth/token.go`), with header/cookie extraction helpers in `server/auth/extract.go` and request-context plumbing in `server/auth/context.go`.
