**web/src/hooks/useMemoQueries.ts; memoServiceClient**

The memo CRUD queries and mutations (`useMemos`, `useInfiniteMemos`, plus create/update/delete mutations calling `createMemo`, `updateMemo`, `deleteMemo`, `listMemoComments`, etc.) live in `web/src/hooks/useMemoQueries.ts`. That module uses `memoServiceClient` — the ConnectRPC client for the generated `MemoService` (from `web/src/types/proto/api/v1/memo_service_pb.ts`) — which is created with `createClient` in `web/src/connect.ts`.
