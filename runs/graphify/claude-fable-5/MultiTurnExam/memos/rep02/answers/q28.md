**Runners the server actually starts:**

- **s3presign runner — driven by a `time.Ticker` with a 12-hour interval.** Started in `Server.startBackgroundRunners` (`server/server.go:153-174`): it calls `RunOnce` immediately at startup, then runs `Run` in a goroutine, which loops on `time.NewTicker(runnerInterval)` with `runnerInterval = time.Hour * 12` (`server/runner/s3presign/runner.go:27-36`).

That is the only background runner the server launches.

**Present but NOT started by the server:**

- **memopayload runner** (`server/runner/memopayload/runner.go`) — it has a `Runner` with `RunOnce`, but the server never constructs or schedules it; only its standalone helper `RebuildMemoPayload` is called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108` and `:447`).
- **`internal/scheduler` package** (`internal/scheduler/scheduler.go`, with cron parsing, jobs, middleware, tests, and a README) — a complete cron-style scheduling library that nothing outside its own package imports; the server's only recurring work uses a plain `time.Ticker` instead. This scheduling infrastructure is entirely unused by the server.
