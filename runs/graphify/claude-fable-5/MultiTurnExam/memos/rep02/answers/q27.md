**Mechanism: the compiled frontend is embedded into the Go binary with `go:embed` and served as static files by Echo (with an SPA fallback); wired in `server/router/frontend/frontend.go`.**

The built web app lives in `server/router/frontend/dist/`, embedded via `//go:embed dist/*` into an `embed.FS` (`server/router/frontend/frontend.go:20-21`). `FrontendService.Serve` (line 40) mounts it with Echo's `middleware.StaticWithConfig` over the embedded filesystem, sets cache headers, and adds `spaFallbackMiddleware` so unmatched routes fall back to `index.html` for client-side routing.
