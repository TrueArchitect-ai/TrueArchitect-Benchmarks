**Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`) — the engine lives in `internal/filter/` (`internal/filter/engine.go` defines `Engine`, which "parses CEL filters into a dialect-agnostic condition tree"; parsing in `parser.go`, intermediate representation in `ir.go`).

**Mechanism:** The engine compiles the CEL expression into a dialect-agnostic `Condition` tree (`internal/filter/ir.go`), and each database driver renders it to SQL for its own dialect via a renderer that switches on `DialectSQLite` / `DialectPostgres` / `DialectMySQL` to emit dialect-specific SQL fragments and placeholder args (`internal/filter/render.go`) — e.g. `store/db/sqlite/memo.go:57-61` calls `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` to append WHERE clauses, with the ListMemos handler passing the request's filter down via `server/router/api/v1/memo_service.go`.
