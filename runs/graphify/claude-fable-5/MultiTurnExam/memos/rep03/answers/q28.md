The server starts exactly one background runner (`Server.startBackgroundRunners`, `server/server.go:153`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`, `server/server.go:163`), then continuously on a `time.Ticker` every **12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-36`). It re-presigns S3 attachment URLs.

**Unused scheduling infrastructure:** the **memopayload runner** (`server/runner/memopayload/runner.go`) defines `NewRunner`/`RunOnce` (rebuilds all memo payloads in batches), but the server never starts it — `server/server.go` neither constructs nor schedules it. Only its helper function `memopayload.RebuildMemoPayload` is used, called synchronously from the API handlers on memo create/update (`server/router/api/v1/memo_service.go:108,447`). There is no cron library in `go.mod`; the only scheduling mechanism actually in use is the s3presign ticker.
