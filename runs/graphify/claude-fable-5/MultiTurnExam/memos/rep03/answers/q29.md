**Interceptor:** `web/src/connect.ts` — `authInterceptor` (line 156), attached to the shared Connect transport (line 188). It attaches the access token as a Bearer `Authorization` header, does a preflight refresh when the token is near expiry, and reactively refreshes-and-retries on 401 (deduplicated via a token-refresh manager; token storage/cross-tab sync lives in `web/src/auth-state.ts`).

**Token kinds:** short-lived JWT **access tokens** (~15 minutes, kept in localStorage) and long-lived **refresh tokens** (~30 days, obtained via `AuthService.RefreshToken`); the backend additionally supports **Personal Access Tokens (PAT)** for programmatic access.

**Backend package:** `server/auth/` — `server/auth/authenticator.go` validates them (`AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, plus PAT handling), with JWT parsing/signing in `server/auth/token.go` (`github.com/golang-jwt/jwt/v5`); it's wired into both the gRPC-Gateway middleware and the Connect interceptor through the shared authorizer in `server/router/api/v1/authz.go` (`server/router/api/v1/v1.go`).
