- **Interceptor:** `web/src/connect.ts` — a ConnectRPC `Interceptor` that sets the `Authorization: Bearer <token>` header on every request (`setAuthorizationHeader`, line 97) and, on auth failure/expiry, reactively refreshes the access token via the AuthService `refreshToken` RPC (with a dedicated `refreshTransport`/`refreshAuthClient` and a dedup manager to prevent concurrent refreshes). Token storage/sync across tabs lives in `web/src/auth-state.ts` (localStorage + BroadcastChannel).
- **Token kinds:** short-lived **access tokens** (Bearer JWT held in localStorage) and **refresh tokens** (sent via cookie to the `RefreshToken` RPC to mint new access tokens). The backend additionally accepts **personal access tokens** (PATs) as Bearer credentials.
- **Backend package:** `server/auth` — `server/auth/authenticator.go` validates them (`resolveBearer` for access tokens/PATs including `GetUserByPATHash` lookup, and `AuthenticateByRefreshToken` for refresh tokens).
