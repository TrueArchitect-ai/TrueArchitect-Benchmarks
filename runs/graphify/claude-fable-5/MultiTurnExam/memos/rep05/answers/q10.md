**store/migration/sqlite/LATEST.sql**

Each dialect ships a `LATEST.sql` containing the complete current schema for a fresh install (seen earlier: it holds all `CREATE TABLE` statements — `system_setting`, `user`, `memo`, `memo_relation`, `attachment`, etc.). For SQLite that file is `store/migration/sqlite/LATEST.sql`, applied by the migrator in `store/migrator.go`.
