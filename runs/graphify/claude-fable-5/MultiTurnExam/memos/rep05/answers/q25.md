**Engine: CEL (Common Expression Language) via `github.com/google/cel-go` — internal/filter/** (`internal/filter/engine.go`, plus `parser.go`, `ir.go`, `render.go`, `schema.go`).

**Mechanism:** The filter string is parsed by a CEL environment (`Engine` in `internal/filter/engine.go`) into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`), and each dialect driver — e.g. `store/db/sqlite/memo.go:57-61` calling `filter.DefaultEngine()` and `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` — has that tree rendered into parameterized SQL WHERE clauses by the renderer in `internal/filter/render.go`, which branches on `DialectSQLite`/`DialectMySQL`/`DialectPostgres` for dialect-specific SQL (e.g. JSON access and string-length expressions) while appending the bound arguments.
