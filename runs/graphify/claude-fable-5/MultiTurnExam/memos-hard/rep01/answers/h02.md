**Delivery function:** `Post()` — `internal/webhook/webhook.go:120`. This is where the outbound HTTP POST actually executes (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`). Callers such as `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go` don't call it directly — they call `PostAsync()` (`internal/webhook/webhook.go:184`), which enqueues the payload on a bounded channel; four worker goroutines started in the package `init()` (`internal/webhook/webhook.go:42`) drain the queue and invoke `Post()`.

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`, backed by `isReservedIP` in `internal/webhook/validate.go:44`. All webhook requests go through the shared `safeClient`, whose `http.Transport` uses `safeDialContext` as its dialer. At dial time it resolves the target hostname and rejects any address in a reserved/private range (loopback, RFC-1918, link-local including the cloud metadata address 169.254.169.254, etc.). Because the check happens at connection time on the resolved IPs, it also defeats DNS-rebinding tricks. There is additionally an input-time guard, `ValidateURL` in `internal/webhook/validate.go:62`, which rejects webhook URLs that resolve to reserved/private IPs when a webhook is created, with an `AllowPrivateIPs` escape hatch (`internal/webhook/validate.go:38`) for self-hosted setups.
