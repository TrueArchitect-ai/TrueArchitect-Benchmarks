**Abstraction package:** `internal/idp` — the file `internal/idp/idp.go` defines the provider-neutral abstraction, notably the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation must produce.

**Implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go` ships the one concrete protocol implementation: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, endpoints, user-info mapping) and returning `idp.IdentityProviderUserInfo` from the provider's user-info endpoint. It's the only subpackage under `internal/idp/`, so OAuth2 is the sole protocol shipped.
