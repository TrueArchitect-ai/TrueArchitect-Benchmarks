**Premise correction: there is no GraphQL API in this repository.** No `.graphql` schema files, no GraphQL server library, and no resolver code exist anywhere in the backend or frontend sources.

**Actual API surface:** the public API is **gRPC/Protobuf-defined**, exposed over HTTP in two ways:

- **Schema definition:** Protocol Buffer service definitions under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto` — with generated Go code in `proto/gen/api/v1/`.
- **REST-style JSON API:** the same services are served as HTTP/JSON via gRPC-Gateway, registered in `server/router/api/v1/v1.go:95-127` and mounted at `/api/v1/*` (`v1.go:127`).
- **Connect RPC for browser clients:** Connect handlers (replacing grpc-web) mounted at `/memos.api.v1.*` — `server/router/api/v1/v1.go:132-144`.

Additional non-RPC surfaces are the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), MCP (`server/router/mcp/`), and SSE (`RegisterSSERoutes`, `server/router/api/v1/v1.go:114`) — still no GraphQL anywhere.
