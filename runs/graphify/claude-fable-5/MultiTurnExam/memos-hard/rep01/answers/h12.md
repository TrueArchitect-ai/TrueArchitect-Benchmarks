**Determination method:** there are three candidates implementing the same `store.Driver` interface method — `store/db/sqlite/memo.go:16`, `store/db/mysql/memo.go:16`, `store/db/postgres/memo.go:16`. 3. The save path then dispatches through the interface: `(*Store).CreateMemo` at `store/memo.go:109` calls `s.driver.CreateMemo(ctx, create)` (`store/memo.go:113`), and since `s.driver` is the SQLite `*DB` in a default install, the SQLite implementation executes the INSERT.
