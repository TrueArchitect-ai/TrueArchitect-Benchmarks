**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`).**

- `internal/idp/idp.go` defines the provider abstraction — the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar URL) that any provider maps its user data into.
- `internal/idp/oauth2` is the single concrete protocol implementation that ships: an OAuth 2.0 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` and returning `idp.IdentityProviderUserInfo` after exchanging the code and fetching the user-info endpoint (tests in `internal/idp/oauth2/oauth2_test.go`).
