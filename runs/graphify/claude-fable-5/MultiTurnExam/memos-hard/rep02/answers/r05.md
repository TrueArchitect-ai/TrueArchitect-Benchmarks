**Premise correction: this project has no GraphQL API — there is no GraphQL schema, library, or endpoint anywhere in the codebase** (no `.graphql` files, no GraphQL dependency in `go.mod`, no GraphQL code under `server/`).

Actual API surface: the public API is **gRPC-defined via Protocol Buffers, served over HTTP as both a gRPC-Gateway REST API and Connect RPC**:

- **Schema definitions**: the protobuf service definitions in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated code under `proto/gen/`.
- **Serving**: `APIV1Service.RegisterGateway` in `server/router/api/v1/v1.go` mounts the gRPC-Gateway mux (RESTful JSON over `/api/v1/...`) and Connect handlers (`server/router/api/v1/connect_services.go`) onto the Echo server (`server/server.go`).
- Additional non-RPC surfaces: the file server (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), an MCP endpoint (`server/router/mcp/`), and the static frontend (`server/router/frontend/`).

So the closest analogue to "the schema for the public API" is the proto files in `proto/api/v1/`, not a GraphQL schema.
