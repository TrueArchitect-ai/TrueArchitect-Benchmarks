**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages).**

Counting Go packages outside the data layer (i.e. excluding `store/` and its driver/test subpackages) that reference each persistent entity type defined in the store package (`store/user.go`, `store/memo.go`, etc.):

- **`store.User` — 7 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages**: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Rest of the field for context: `store.Attachment` 4, `store.Inbox` 3, `store.MemoRelation` 3, `store.Reaction` 2, `store.UserSetting` / `store.InstanceSetting` / `store.IdentityProvider` 1 each. (Within the data layer itself, all types are additionally referenced by `store/db/sqlite`, `store/db/mysql`, `store/db/postgres`, and `store/test`, but those were excluded as part of the layer.)
