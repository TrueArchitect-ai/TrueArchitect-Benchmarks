**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

Counting distinct packages outside the data layer (i.e., excluding the `store/` tree — `store`, `store/db/*`, `store/test`) that reference each persistent entity type defined in the store package:

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

For context, the rest trail well behind: `store.Attachment` is used by 4 outside packages (`api/v1`, `api/v1/test`, `fileserver`, `rss`), and types like `Reaction`, `Inbox`, `MemoRelation`, `MemoShare` are each used by roughly 2–3 outside packages. (If test packages are excluded, the ranking is unchanged: User 6, Memo 5.) The entity type definitions live in the store package, e.g. `store/user.go`, `store/memo.go`.
