**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `MarkdownService.ExtractAll` (goldmark single-pass extraction, `internal/markdown/markdown.go:356`) on the memo content and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (the `MemoPayload` message defined in `proto/store/memo.proto`).

**Triggers:**

- **Memo creation** — `CreateMemo` calls it before persisting, at `server/router/api/v1/memo_service.go:108`. This also covers comments, since `CreateMemoComment` creates the comment through `CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
- **Content update** — `UpdateMemo` recomputes it whenever the `content` field is in the update mask, at `server/router/api/v1/memo_service.go:447`.
- **Batch backfill** — `memopayload.Runner.RunOnce` rebuilds payloads for all memos in batches (`server/runner/memopayload/runner.go:52`), though this runner is not currently wired into server startup (no production caller of `NewRunner`/`RunOnce`).

**Extracted properties:** from `ExtractedData` (`internal/markdown/markdown.go:21`) into the payload:

- `tags` — all `#tag`s in the content
- `property.has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks` — boolean content flags
- `property.title` — the first H1 heading, if present (`proto/store/memo.proto:15-22`)

(User-set payload data like `location` is not touched by this computation.)
