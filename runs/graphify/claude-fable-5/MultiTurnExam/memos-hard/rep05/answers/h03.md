**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

- `internal/idp/idp.go` defines the provider abstraction — the `idp` package with the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar) that any provider yields after authentication.
- `internal/idp/oauth2/oauth2.go` is the one concrete protocol implementation that ships: an OAuth 2.0 `IdentityProvider` built on `golang.org/x/oauth2`, configured from `storepb.OAuth2Config` (client ID/secret, endpoints), which exchanges the auth code and fetches user info to produce an `idp.IdentityProviderUserInfo`.
