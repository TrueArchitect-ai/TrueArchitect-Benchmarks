**Premise correction: there is no GraphQL in this codebase** — a repo-wide search for "graphql" across Go, TypeScript, schema, and dependency files returns nothing.

**Actual API surface:** the public API is defined with **Protocol Buffers / gRPC**, with HTTP access provided via gRPC-Gateway (REST/JSON) and Connect:

- **Schema definitions:** `proto/api/v1/*.proto` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, with shared types in `common.proto`. Generated Go code lives in `proto/gen/api/v1/`, and generated TypeScript client types in `web/src/types/proto/api/v1/`.
- **Server implementation:** the service handlers are in `server/router/api/v1/` (`APIV1Service`), registered through the gRPC-Gateway and Connect handlers in `RegisterGateway` (`server/router/api/v1/v1.go`), wired into the Echo server in `server/server.go:87-89`.
- Additional non-gRPC surfaces are plain HTTP: the file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and an MCP endpoint (`server/router/mcp/`).
