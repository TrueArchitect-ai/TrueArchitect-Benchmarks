**Premise correction: there is no GraphQL schema — this project does not use GraphQL.** No `.graphql` files, no GraphQL server library, resolvers, or schema definitions exist anywhere in the repo.

**Actual API surface:** the public API is **gRPC-based, defined in Protocol Buffers**, and exposed over HTTP in two ways:

- **Schema definitions:** `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, `common.proto` — with generated Go stubs under `proto/gen/api/v1/` (and TypeScript equivalents under `web/src/types/proto/api/v1/`).
- **Serving layer:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`) wires the same service into both:
  - **grpc-gateway** (`github.com/grpc-ecosystem/grpc-gateway/v2`, `server/router/api/v1/v1.go:8`) — RESTful JSON/HTTP transcoding of the proto RPCs, and
  - **Connect RPC** (`connectrpc.com/connect`, `server/router/api/v1/v1.go:7,133-140`) — the Connect/gRPC-Web protocol handler used by the web frontend.

Additionally there are non-RPC HTTP surfaces (file server at `server/router/fileserver/`, RSS at `server/router/rss/`), but the structured public API is entirely protobuf/gRPC — nothing GraphQL.
