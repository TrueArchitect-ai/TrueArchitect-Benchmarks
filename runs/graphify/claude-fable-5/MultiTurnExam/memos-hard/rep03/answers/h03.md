**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

The `internal/idp` package defines the provider abstraction — the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar URL) that any provider must produce (`internal/idp/idp.go:3-8`). The only concrete protocol implementation that ships is OAuth2: `internal/idp/oauth2` implements `IdentityProvider` around a `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) with token exchange and user-info fetching (`internal/idp/oauth2/oauth2.go`), returning the `idp.IdentityProviderUserInfo` struct.
