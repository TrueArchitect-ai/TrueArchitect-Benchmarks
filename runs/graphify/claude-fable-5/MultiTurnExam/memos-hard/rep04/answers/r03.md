**Premise correction: there is no nightly database-cleanup job, and the cron scheduler isn't wired into the server at all.**

- The repo does contain a cron scheduler package (`internal/scheduler/` — `scheduler.go`, `parser.go`, `job.go`, etc.), but the only importers of it anywhere in the codebase are its own tests (`internal/scheduler/integration_test.go`, `internal/scheduler/example_test.go`). No production code (server, cmd, store) creates a scheduler or registers any job.
- The "daily-cleanup" that a search surfaces is just an illustrative example in the package documentation (`internal/scheduler/doc.go:15-18`), not real code.
- No database-cleanup/vacuum/purge job exists elsewhere either. The background work the server actually runs uses plain `time.Ticker` goroutines, not cron: the S3 presign refresher every 12 hours (`server/runner/s3presign/runner.go:26`, started in `server/server.go:153-170`) and the in-memory cache's own cleanup sweep every 5 minutes (`store/cache/cache.go`, config in `store/store.go:42`). Neither cleans the database, and neither is scheduled at a clock time.

So there is no scheduled time to report — the premise (a nightly DB-cleanup cron job) doesn't match the codebase.
