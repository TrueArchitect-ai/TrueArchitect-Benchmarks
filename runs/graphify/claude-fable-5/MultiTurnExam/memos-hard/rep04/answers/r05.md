**Premise correction: this project has no GraphQL API and no GraphQL schema.** A repo-wide search for "graphql" across Go, TypeScript, and config files finds nothing, and there is no GraphQL dependency in `go.mod` or the web app.

**Actual API surface:** the public API is **gRPC-based, defined in Protocol Buffers** and exposed over HTTP two ways:

- **Schema definition:** `.proto` files under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), with generated code in `proto/gen/`.
- **Serving:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`) registers both a **gRPC-Gateway** REST/JSON transcoding layer (`grpc-ecosystem/grpc-gateway`, `v1.go:8,97`) and **Connect RPC** handlers for browser clients ("replaces grpc-web", `v1.go:131-141`; `connectrpc.com/connect` in `go.mod:6`).
- Additional non-RPC surfaces are plain HTTP routes: file serving (`server/router/fileserver`), RSS (`server/router/rss`), MCP (`server/router/mcp`), and the frontend (`server/router/frontend`).
