The following tables are affected when `DeleteMemo` runs:

- **`memo_relation`** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:142-146`) for both `memo_id` and `related_memo_id` sides
- **`attachment`** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:149-157`) via `Store.DeleteAttachment`
- **`memo`** — the memo row itself is deleted (`store/memo.go:158`), plus any comment memos are recursively deleted from the API layer (`server/router/api/v1/memo_service.go:573-576`), each triggering the same cascade on their own relations and attachments
