Before deleting the memo row itself, the store layer (`store/memo.go:140-158`) deletes:

1. **Memo relations** — `memo_relation` records where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **memo comments** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo, and each comment deletion triggers the same store-layer cleanup of its own relations and attachments.
