Engine: **CEL (Common Expression Language)** via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

The CEL `Engine` compiles the filter string into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) converts that condition tree into SQL with dialect-specific placeholder syntax, selected by the `DialectName` parameter (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`). Each dialect driver calls `filter.AppendConditions()` passing its dialect constant (e.g., `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`), which compiles the CEL expression, renders it to SQL with the appropriate placeholder style, and appends the resulting WHERE clauses and arguments.
