The server uses **Server-Sent Events (SSE)** to push live events to browsers.

The hub is implemented in **`server/router/api/v1/sse_hub.go`** (the `SSEHub` struct), with the HTTP handler in `server/router/api/v1/sse_handler.go`.

The memo handlers that broadcast through it:

- **CreateMemo** — `server/router/api/v1/memo_service.go`
- **DeleteMemo** — `server/router/api/v1/memo_service.go`
- **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go`
- **dispatchMemoUpdatedSideEffects** (called from UpdateMemo) — `server/router/api/v1/memo_update_helpers.go`

Additionally, **CreateReaction** and **DeleteReaction** in `server/router/api/v1/reaction_service.go` also broadcast memo-related reaction events through the hub.
