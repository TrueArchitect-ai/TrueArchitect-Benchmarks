When a memo is created, the handler calls `DispatchMemoCreatedWebhook` which delegates to `dispatchMemoRelatedWebhook` in **`server/router/api/v1/memo_service_webhooks.go`**. This function iterates over the creator's webhooks and calls `webhook.PostAsync()` for each.

The HTTP delivery is performed by the **`internal/webhook`** package (`internal/webhook/webhook.go`), which uses `Post()` to make HTTP POST requests via a safe HTTP client.

The signing mechanism is **HMAC-SHA256** following the Standard Webhooks spec: a message ID (`webhook-id`), Unix timestamp (`webhook-timestamp`), and the request body are concatenated and signed with the webhook's signing secret (supporting `whsec_<base64>` format). The resulting signature is sent in the `webhook-signature` header as `v1,<base64-signature>`.
