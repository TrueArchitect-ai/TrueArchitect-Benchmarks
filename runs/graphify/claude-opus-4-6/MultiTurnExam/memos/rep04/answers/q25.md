The filter expression uses **CEL (Common Expression Language)**, parsed by the `google/cel-go` library. The filter engine lives in **`internal/filter/`** — specifically `internal/filter/engine.go` defines the `Engine` struct that compiles CEL expressions into a dialect-agnostic condition tree, and `internal/filter/render.go` renders that tree into SQL.

Each dialect driver (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (defined in `internal/filter/helpers.go`), passing a `DialectName` constant (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`), which causes the engine to compile the CEL filter and then render it into dialect-specific SQL WHERE clauses with the appropriate quoting, placeholder syntax, and function mappings for each database.
