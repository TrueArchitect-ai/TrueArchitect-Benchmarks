When a memo is deleted, the store layer (`store/memo.go:140-159`) deletes the following records before the memo row itself:

1. **Memo relations** — where the memo is the source (`MemoID`) or target (`RelatedMemoID`) in the `memo_relation` table
2. **Attachments** — all attachments linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (child memos related via `MemoRelationComment`) are recursively deleted before the parent memo's `Store.DeleteMemo` is called, which in turn cleans up their own relations and attachments.
