**Interceptor:** The auth interceptor lives in `web/src/connect.ts` (the `authInterceptor` constant, line 156), with token state management in `web/src/auth-state.ts` (imported at line 4).

**Token kinds:** It manages two token types:
- **Access tokens** (short-lived JWTs, sent as `Bearer` tokens in the `Authorization` header)
- **Refresh tokens** (used via `refreshToken` RPC with cookies/credentials to obtain new access tokens)

Additionally, the backend supports **Personal Access Tokens (PATs)** as an alternative authentication method.

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`), which validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`).
