**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go` (the `Engine` struct, constructed by `NewEngine`/`DefaultEngine`).

**Mechanism:** Each dialect driver (e.g., `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`), passing the CEL filter strings and a dialect identifier (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL` from `internal/filter/schema.go`). The engine parses the filter expression into a CEL AST (`internal/filter/engine.go`), then the renderer (`internal/filter/render.go`) walks the AST and emits dialect-specific SQL WHERE clauses with parameterized arguments, branching on the dialect name for syntax differences (e.g., JSON operators, string functions).
