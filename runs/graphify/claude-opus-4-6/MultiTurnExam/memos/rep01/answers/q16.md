When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`)
2. **Attachments** — all `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **memo comments** (memos related via a `Comment`-type relation) are recursively deleted (each via `Store.DeleteMemo`, which in turn cleans up their own relations and attachments) before the parent memo is deleted.
