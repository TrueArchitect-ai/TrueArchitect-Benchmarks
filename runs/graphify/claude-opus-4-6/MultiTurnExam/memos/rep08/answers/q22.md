**Dispatcher:** `DispatchMemoCreatedWebhook` (which delegates to `dispatchMemoRelatedWebhook`) — `server/router/api/v1/memo_service_webhooks.go`

**Delivery package:** `internal/webhook` — the `Post` / `PostAsync` functions in `internal/webhook/webhook.go` perform the HTTP POST delivery asynchronously via a buffered worker pool.

**Signing mechanism:** HMAC-SHA256 following the [Standard Webhooks](https://www.standardwebhooks.com/) convention. The signing secret (optionally `whsec_`-prefixed base64) is used as the HMAC key. The signature is computed over `msgID + "." + timestamp + "." + body` and sent in the `webhook-signature` header as `v1,<base64>`, alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:133-149`).
