When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes these records before the memo row itself:

1. **Memo relations** — where the memo is the source (`MemoID`) via `DeleteMemoRelation`
2. **Memo relations** — where the memo is the target (`RelatedMemoID`) via `DeleteMemoRelation`
3. **Attachments** — linked to the memo, via `DeleteAttachment` for each

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (child memos linked by a `Comment` relation) are recursively deleted before the parent memo itself, each going through the same store-level cleanup.
