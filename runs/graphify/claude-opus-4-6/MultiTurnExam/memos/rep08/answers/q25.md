**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`, wrapped in a custom filter engine at `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile` method parses the filter string into a CEL AST, then converts it into a dialect-agnostic condition tree (`internal/filter/ir.go`). Each database driver (e.g., `store/db/postgres/memo.go:54-58`) calls `filter.AppendConditions` with its dialect identifier (`DialectPostgres`, `DialectSQLite`, `DialectMySQL`), which renders the condition tree into dialect-specific SQL WHERE clauses with parameterized arguments via the renderer in `internal/filter/render.go`.
