The following tables are affected when `DeleteMemo` runs:

- **memo_relation** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:142-146`)
- **attachment** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:149-156`)
- **memo** — the memo row itself is deleted by the driver (`store/memo.go:158`)
- **memo_share** — cascade-deleted via `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/postgres/LATEST.sql:108`)
- **memo** (comment rows) — at the API layer, child comment memos are recursively deleted before the parent (`server/router/api/v1/memo_service.go:567-577`), each triggering the same cascade on the tables above
