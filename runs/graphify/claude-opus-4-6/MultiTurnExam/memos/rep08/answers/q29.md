**Interceptor:** `web/src/connect.ts` — the `authInterceptor` (line 156) attaches a `Bearer` access token to every request via the `Authorization` header, with automatic refresh-on-401 retry logic. Token state is managed in `web/src/auth-state.ts`.

**Token kinds managed:**
- **Access token** (short-lived JWT, stored in localStorage, sent as `Bearer` header)
- **Refresh token** (sent via HTTP-only cookie with `credentials: "include"`, used to obtain new access tokens)
- **Personal Access Token (PAT)** (also accepted as a `Bearer` token)

**Backend validation package:** `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and personal access tokens (`AuthenticateByPAT`).
