When `DeleteMemo` runs, the following tables are affected:

1. **memo_relation** — relations where the memo is source (`MemoID`) or target (`RelatedMemoID`) are explicitly deleted (`store/memo.go:142-146`)
2. **attachment** — attachments linked to the memo are explicitly deleted (`store/memo.go:149-156`)
3. **memo** — the memo row itself is deleted (`store/memo.go:158`)

Additionally, at the API handler level (`server/router/api/v1/memo_service.go:567-577`), comment memos (related via `memo_relation` with type `Comment`) are recursively deleted via `Store.DeleteMemo`, which in turn cascades through the same tables for each comment. So the full list of directly affected tables is:

**memo**, **memo_relation**, **attachment**
