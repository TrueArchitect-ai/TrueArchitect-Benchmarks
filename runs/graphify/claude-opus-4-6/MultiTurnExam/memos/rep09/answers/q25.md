Engine: **CEL (Common Expression Language)** via the `google/cel-go` library, wrapped in a custom `Engine` in `internal/filter/engine.go`. The filter parsing and compilation pipeline lives in the `internal/filter` package (key files: `engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`, `helpers.go`).

Mechanism: Each dialect driver (e.g., `store/db/postgres/memo.go`, `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`), which compiles the CEL filter string into a dialect-agnostic condition tree (IR), then the renderer (`internal/filter/render.go`) translates that tree into SQL WHERE clauses using per-dialect placeholder styles and SQL expressions defined in the schema's `Expressions` map (`internal/filter/schema.go`), keyed by `DialectSQLite`, `DialectMySQL`, or `DialectPostgres`.
