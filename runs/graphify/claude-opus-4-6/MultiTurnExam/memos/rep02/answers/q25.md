Engine: **CEL (Common Expression Language)** via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`

The filter string is parsed by the CEL `Engine` into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), then `internal/filter/render.go` renders that tree into SQL with dialect-specific placeholder syntax. Each dialect driver calls `filter.AppendConditions()` passing its dialect name (`filter.DialectSQLite`, `filter.DialectPostgres`, or `filter.DialectMySQL`), which compiles the CEL expression, renders it to a SQL WHERE clause with the appropriate parameter placeholders, and appends the clause and arguments to the query builder (e.g., `store/db/postgres/memo.go:58`, `store/db/sqlite/memo.go:61`, `store/db/mysql/memo.go:69`).
