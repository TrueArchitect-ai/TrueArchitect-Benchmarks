Interceptor: `web/src/connect.ts` (the `authInterceptor` at line 156, which attaches a `Bearer` access token to every request and handles automatic refresh on 401)

Token kinds: **access tokens** (short-lived JWTs stored in localStorage, sent as `Authorization: Bearer` header) and **refresh tokens** (used via the `AuthService.RefreshToken` RPC to obtain new access tokens, sent as an HTTP-only cookie via `credentials: include`). The backend also supports **personal access tokens (PATs)**.

Backend validation package: `server/auth/` (`server/auth/authenticator.go`) — the `Authenticator` struct provides `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT` methods.
