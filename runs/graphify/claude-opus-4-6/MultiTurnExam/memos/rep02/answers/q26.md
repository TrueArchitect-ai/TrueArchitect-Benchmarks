The tables directly affected when `DeleteMemo` runs:

- **`memo_relation`** — deleted where the memo is either `memo_id` or `related_memo_id` (`store/memo.go:142–146`)
- **`attachment`** — all attachments linked to the memo are deleted (`store/memo.go:149–156`)
- **`memo`** — the memo row itself is deleted last (`store/memo.go:158`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), comment memos are recursively deleted via `Store.DeleteMemo`, so each comment's `memo_relation`, `attachment`, and `memo` rows are also removed through the same cascade code.
