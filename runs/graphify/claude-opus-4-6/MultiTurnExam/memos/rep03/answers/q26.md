The following tables are affected when DeleteMemo runs:

- `memo_relation` — explicit cleanup of relations where the memo is source or target (`store/memo.go:142-146`)
- `attachment` — explicit cleanup of attachments linked to the memo (`store/memo.go:148-157`)
- `memo` — the memo row itself is deleted (`store/memo.go:158`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), comment memos are recursively deleted first (each comment's deletion triggers the same cascade on `memo_relation`, `attachment`, and `memo`).
