CEL (Common Expression Language) engine — `internal/filter/engine.go` (using `github.com/google/cel-go/cel`).

The filter string is parsed and compiled by the CEL `Engine` into a dialect-agnostic condition tree (`internal/filter/ir.go`), which is then rendered into dialect-specific SQL by `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect name (`DialectSQLite`, `DialectMySQL`, or `DialectPostgres`), which renders the condition tree into the appropriate SQL syntax with correct placeholder style for that database (e.g., `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`).
