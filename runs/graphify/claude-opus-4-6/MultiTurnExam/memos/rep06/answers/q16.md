When a memo is deleted, the store layer (`store/memo.go:140`) deletes the following records before the memo row itself:

1. **Memo relations** — deletes `memo_relation` rows where the memo is the source (`MemoID`)
2. **Memo relations (reverse)** — deletes `memo_relation` rows where the memo is the target (`RelatedMemoID`)
3. **Attachments** — deletes all `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo, and each of those deletions triggers the same store-level cleanup of relations and attachments.
