Engine: CEL (Common Expression Language) via the `cel-go` library, implemented in `internal/filter/engine.go` (the `Engine` struct wraps a `cel.Env`).

The filter string is parsed by the CEL environment into a checked AST, then `internal/filter/parser.go` converts the CEL AST into a dialect-agnostic intermediate condition tree (`Condition` types in `internal/filter/ir.go`). At query time, each dialect driver (e.g., `store/db/postgres/memo.go`, `store/db/mysql/memo.go`, `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` passing its dialect name (`DialectPostgres`, `DialectMySQL`, or `DialectSQLite`), and the renderer in `internal/filter/render.go` translates the condition tree into dialect-appropriate SQL WHERE clauses with properly formatted placeholders and arguments.
