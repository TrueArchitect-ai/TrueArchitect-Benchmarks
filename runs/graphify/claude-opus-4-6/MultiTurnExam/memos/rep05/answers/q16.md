When a memo is deleted, the store layer (`store/memo.go:140-159`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` rows where the memo is the source (`MemoID`) or the target (`RelatedMemoID`), via `DeleteMemoRelation`
2. **Attachments** — `attachment` rows linked to the memo, via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (memos related via a `Comment`-type relation) are recursively deleted before the parent memo itself, and each of those comment deletions triggers the same store-level cleanup of relations and attachments.
