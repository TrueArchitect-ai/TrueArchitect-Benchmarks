Engine: **CEL (Common Expression Language)** via `github.com/google/cel-go`, implemented in `internal/filter/` (parser in `internal/filter/parser.go`, engine in `internal/filter/engine.go`, IR in `internal/filter/ir.go`).

Mechanism: Each dialect driver (e.g., `store/db/postgres/memo.go`, `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`) with a dialect name (`DialectPostgres`, `DialectSQLite`, `DialectMySQL`), which compiles the CEL filter expression into a dialect-agnostic condition tree (IR), then the renderer (`internal/filter/render.go`) translates that tree into dialect-specific SQL WHERE clauses with the appropriate placeholder syntax and function names for each database.
