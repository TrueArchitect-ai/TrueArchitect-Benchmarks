Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`

The filter string is parsed and compiled by the CEL engine (`Engine.Compile` in `internal/filter/engine.go`) into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), which is then rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`. Each dialect driver calls `filter.AppendConditions` with its dialect constant (`DialectPostgres`, `DialectSQLite`, or `DialectMySQL`), which compiles the CEL expression and renders it into the appropriate SQL parameterized WHERE clause with dialect-aware placeholders (e.g., `store/db/postgres/memo.go:58`, `store/db/sqlite/memo.go:61`, `store/db/mysql/memo.go:69`).
