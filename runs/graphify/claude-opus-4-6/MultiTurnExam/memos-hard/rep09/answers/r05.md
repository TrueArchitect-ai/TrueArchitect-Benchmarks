There is no GraphQL schema in this codebase. The public API is defined using Protocol Buffers and gRPC, with HTTP/JSON access via gRPC-Gateway. The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), and the generated Go code is in `proto/gen/api/v1/`. The gRPC services are implemented in `server/router/api/v1/`. Additionally, native HTTP routes are registered for file serving (`server/router/fileserver/`) and RSS feeds (`server/router/rss/`).
