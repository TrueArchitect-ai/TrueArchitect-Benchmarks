There is no Redis connection in this codebase. The cache layer does not use Redis at all.

The cache is an in-memory implementation using `store/cache/cache.go`, which provides a generic `Cache` struct with expiration-based eviction. User entries are cached via `s.userCache` initialized in `store/store.go`. The TTL is configured at construction time — looking at `store/store.go`, user cache entries are set with a duration passed to `cache.New()`.

There is no external cache store (Redis, Memcached, etc.) anywhere in the repository. All caching is process-local and in-memory.
