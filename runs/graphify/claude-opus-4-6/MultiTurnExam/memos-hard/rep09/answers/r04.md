Neither NATS nor RabbitMQ is used. There is no external message broker in this codebase.

The webhook delivery workers consume from a plain Go buffered channel. In `internal/webhook/webhook.go`, `asyncPostQueue` is declared as a `chan *WebhookRequestPayload` with a capacity of 128 (line 39). Four goroutines are started in `init()` (lines 42–55) that drain this channel and call `Post()` for each payload. The `PostAsync` function (line 184) simply sends the payload into this in-memory channel. There is no external queue, broker, or message bus involved.
