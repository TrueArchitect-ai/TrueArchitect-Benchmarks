The question's premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed cache with TTL support in `store/cache/cache.go:66`. There is no external cache service (Redis or otherwise) anywhere in the codebase.

User entries are cached by `store.Store.userCache` (`store/store.go:28`), which is constructed at `store/store.go:52` with a shared `cacheConfig` defined at line 40. The **default TTL for user entries is 10 minutes** (`DefaultTTL: 10 * time.Minute`), with cleanup running every 5 minutes and a max of 1000 items.
