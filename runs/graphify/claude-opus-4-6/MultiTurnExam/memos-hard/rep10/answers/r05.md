The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers / gRPC** with an HTTP/JSON gateway.

The API surface is defined in `.proto` files under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The gRPC services are exposed over HTTP via grpc-gateway, registered in `server/router/api/v1/v1.go` (the `RegisterGateway` method). Additionally, there are native HTTP endpoints for file serving (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and frontend/sitemap serving (`server/router/frontend/frontend.go`).
