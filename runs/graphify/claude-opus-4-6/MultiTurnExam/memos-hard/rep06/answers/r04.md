The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. Webhook delivery uses a simple in-memory Go buffered channel, not an external message queue.

The "queue" is declared at `internal/webhook/webhook.go:39` as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` — a buffered channel with capacity 128. Four goroutines are spawned in `init()` (`internal/webhook/webhook.go:42-54`) to drain this channel, each calling `Post()` for every payload received. Callers enqueue work via `PostAsync()` (`internal/webhook/webhook.go:184`), which simply sends the payload into the channel. The entire mechanism is process-local with no external broker dependency.
