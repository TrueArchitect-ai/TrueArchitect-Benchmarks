The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using Protocol Buffers (protobuf) and served over gRPC with a gRPC-Gateway for REST/HTTP access.

The API surface is defined in proto files under `proto/api/v1/`, including services like `MemoService` (`proto/api/v1/memo_service.proto`), `UserService` (`proto/api/v1/user_service.proto`), `IdentityProviderService` (`proto/api/v1/idp_service.proto`), etc. Generated Go code lives in `proto/gen/api/v1/`. The gRPC services are registered via Connect handlers in `server/router/api/v1/connect_services.go`, and REST gateway routes are registered on the Echo HTTP server in `server/server.go`.
