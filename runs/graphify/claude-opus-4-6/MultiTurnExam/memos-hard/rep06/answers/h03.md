Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` struct that every provider must produce.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol implementation that ships, providing `ExchangeToken` and `UserInfo` methods wrapping the OAuth2 authorization-code flow (with PKCE support).
