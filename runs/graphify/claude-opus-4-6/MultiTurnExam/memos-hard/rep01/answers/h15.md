Memo visibility is enforced across many server surfaces. Here are the distinct enforcement sites:

**API — single-memo access gate:**
- `checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39` (rejects non-PUBLIC for unauthenticated, PRIVATE for non-creator; called from `GetMemo`, `ListMemoComments`)

**API — list-level query filtering:**
- `ListMemos` — `server/router/api/v1/memo_service.go:218–225` (restricts `VisibilityList` based on viewer)
- `ListMemoComments` — `server/router/api/v1/memo_service_comments.go:157–160` (filters comment visibility)
- `ListMemoRelations` — `server/router/api/v1/memo_relation_service.go:107–112` (filters related memos)
- `batchConvertMemoRelations` — `server/router/api/v1/memo_service_converter.go:182–187` (same filter during batch conversion)
- `ListAllUserStats` / `GetUserStats` — `server/router/api/v1/user_service_stats.go:83–91, 217–221`

**API — sub-resource access checks:**
- `ListMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:213–224`
- `ListMemoReactions` / `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:29–41, 82–85`
- `checkAttachmentAccess` — `server/router/api/v1/attachment_service.go:422–455`
- `CreateMemoComment` (PRIVATE parent gate) — `server/router/api/v1/memo_service_comments.go:41`

**File server:**
- `checkAttachmentPermission` — `server/router/fileserver/fileserver.go:650–704` (enforces memo visibility for served files, including share-token fallback)

**SSE delivery:**
- `SSEClient.canReceive` — `server/router/api/v1/sse_hub.go:134–144` (PRIVATE events only sent to creator/admin)

**RSS feeds:**
- `GetExploreRSS` — `server/router/rss/rss.go:90` (PUBLIC only)
- `GetUserRSS` — `server/router/rss/rss.go:141` (PUBLIC only)

**Sitemap:**
- `getSitemapXML` — `server/router/frontend/frontend.go:150` (PUBLIC only)

**Notification suppression:**
- `canViewerAccessMemo` — `server/router/api/v1/user_service_notifications.go:302–316` (hides inbox payloads)
- `canViewerAccessMemo` — `server/notification/email.go:306–320` (suppresses email notifications)
- `canUserAccessMentionContext` / `shouldSkipMentionInbox` — `server/router/api/v1/memo_mention_helpers.go:56–89` (suppresses mention notifications for inaccessible memos)
