The question's premise is incorrect. There is no Redis connection in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-based cache with TTL support in `store/cache/cache.go`. No Redis client, Redis configuration, or Redis dependency exists anywhere in the project (confirmed by a codebase-wide search).

User entries use the **default cache configuration** (`store/cache/cache.go:57–64`): a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`), with cleanup every 5 minutes and a max of 1000 items. The user cache is instantiated via `cache.New(cache.DefaultConfig())` in the `Store` constructor (`store/store.go`).
