The question's premise is incorrect. There is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC and REST (via gRPC-Gateway). The service definitions live under `proto/api/v1/` — e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, etc. Generated Go code (gRPC stubs and gateway bindings) is in `proto/gen/api/v1/`. The API is served via Connect (gRPC-compatible) handlers registered in `server/router/api/v1/v1.go`.
