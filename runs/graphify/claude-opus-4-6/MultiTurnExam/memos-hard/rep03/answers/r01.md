The question's premise is incorrect — there is no Redis connection in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed struct in `store/cache/cache.go`. There are zero references to Redis anywhere in the project.

The user cache is created with the default configuration (`cache.DefaultConfig()` at `store/cache/cache.go:57-64`), which sets a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`), a 5-minute cleanup interval, and a max of 1000 items. The `Store` struct instantiates it as `userCache` in `store/store.go`. No external cache service (Redis, Memcached, etc.) is involved.
