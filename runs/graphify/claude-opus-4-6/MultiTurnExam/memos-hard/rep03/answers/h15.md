Memo visibility is enforced at these distinct sites:

1. **`checkMemoReadAccess`** (single-memo gate) — `server/router/api/v1/memo_service.go:39` — reused by `GetMemo` and `ListMemoComments`
2. **`ListMemos` query filtering** — `server/router/api/v1/memo_service.go:219-226` — applies `VisibilityList` or CEL filter depending on auth state
3. **`CreateMemoComment` parent-memo check** — `server/router/api/v1/memo_service_comments.go:41` — blocks commenting on PRIVATE memos by non-creators
4. **`ListMemoComments` visibility filter** — `server/router/api/v1/memo_service_comments.go:157-160` — CEL visibility filter on comment queries
5. **RSS feeds** — `server/router/rss/rss.go:90,141` — both explore and user feeds restrict to PUBLIC only
6. **File server attachment permission** (`checkAttachmentPermission`) — `server/router/fileserver/fileserver.go:650-704` — checks memo visibility (+ share tokens) before serving attachment files
7. **gRPC `ListMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:213-225` — visibility check on the parent memo
8. **gRPC `checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go:422-455` — visibility check on the linked memo
9. **`ListMemoReactions`** — `server/router/api/v1/reaction_service.go:30-41` — blocks listing reactions on non-PUBLIC memos for unauthenticated/non-creator users
10. **`UpsertMemoReaction`** — `server/router/api/v1/reaction_service.go:83` — PRIVATE check before allowing reaction
11. **`ListMemoRelations`** — `server/router/api/v1/memo_relation_service.go:108-111` — CEL visibility filter on related memos
12. **Batch relation loading** — `server/router/api/v1/memo_service_converter.go:183-186` — visibility filter when loading related memos
13. **User stats** — `server/router/api/v1/user_service_stats.go:84-90,218-220` — visibility filtering in stat queries
14. **SSE event delivery** (`canReceive`) — `server/router/api/v1/sse_hub.go:134-144` — PRIVATE events only delivered to creator/admin clients
15. **Sitemap** — `server/router/frontend/frontend.go:150` — only PUBLIC memos included
16. **Mention/notification suppression** (`canUserAccessMentionContext`) — `server/router/api/v1/memo_mention_helpers.go:56-72` — suppresses mention inbox for PRIVATE memos
17. **Notification rendering** (`canViewerAccessMemo`) — `server/router/api/v1/user_service_notifications.go:302-316` and `server/notification/email.go:306-320` — controls whether memo content appears in notifications/emails
