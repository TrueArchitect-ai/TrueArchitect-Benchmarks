The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), not an external message queue.

In `internal/webhook/webhook.go`, the queue is declared as a buffered channel at line ~32 (`asyncPostQueue = make(chan *WebhookRequestPayload, 128)`). The `init()` function (line ~42) spawns 4 goroutines that drain this channel, each calling `Post()` for every payload received. `PostAsync()` (line ~184) enqueues payloads by sending them into this channel. The entire mechanism is in-process with no external broker dependency.
