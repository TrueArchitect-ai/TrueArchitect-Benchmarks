The question's premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, plus a REST/JSON gateway.

The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The gRPC services are implemented in `server/router/api/v1/` and exposed over HTTP/JSON via the grpc-gateway (`server/router/api/v1/v1.go:97`, using `runtime.NewServeMux`). There is no GraphQL layer anywhere in the project.
