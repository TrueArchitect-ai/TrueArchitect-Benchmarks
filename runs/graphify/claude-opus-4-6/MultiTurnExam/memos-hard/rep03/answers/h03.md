**Abstraction package:** `internal/idp` — defines the shared `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that all provider implementations return.

**Implementation package:** `internal/idp/oauth2` — the only concrete protocol implementation that ships (`internal/idp/oauth2/oauth2.go`). It implements OAuth2 token exchange (with PKCE support) and user-info retrieval, mapping the response via configurable field mappings. No OIDC, SAML, or LDAP implementations exist; the protobuf enum (`proto/store/idp.proto`) only defines `OAUTH2 = 1`.
