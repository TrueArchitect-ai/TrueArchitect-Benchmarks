The premise is incorrect — there is no GraphQL schema or API. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed via both gRPC (Connect) and REST (gRPC-Gateway).

The protobuf service definitions live under `proto/api/v1/`, e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, etc. Generated Go code (including gRPC stubs and Connect handlers) is in `proto/gen/api/v1/`. The services are wired into the server in `server/router/api/v1/v1.go`, which registers both a gRPC-Gateway REST mux and Connect RPC handlers on the Echo HTTP server (`server/server.go:70-84`). There is also an RSS feed surface (`server/router/rss/rss.go`) and a file-serving HTTP surface (`server/router/fileserver/fileserver.go`), but none of these use GraphQL.
