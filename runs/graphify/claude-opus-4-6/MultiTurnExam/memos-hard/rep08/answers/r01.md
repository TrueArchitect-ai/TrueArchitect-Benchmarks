The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map` with TTL-based expiration in `store/cache/cache.go`. There is no external cache service involved anywhere in the codebase (no Redis, Memcached, or similar references exist).

The user cache is created at `store/store.go:52` using a `cache.Config` with a **10-minute default TTL** (line 41). User entries are stored and retrieved via `Store.userCache` (a `*cache.Cache` field at `store/store.go:28`), with expiration checked on read (`cache.go:135`) and expired items cleaned up every 5 minutes by a background goroutine (`cache.go:200`). The cache holds up to 1000 items before evicting the oldest.
