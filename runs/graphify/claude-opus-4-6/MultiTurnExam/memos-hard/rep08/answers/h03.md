**Abstraction package:** `internal/idp` — defines the common `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that any provider must return, establishing the shared data contract.

**Implementation package:** `internal/idp/oauth2` — the sole concrete protocol implementation (`internal/idp/oauth2/oauth2.go`), providing OAuth2 authorization-code exchange (with optional PKCE) and userinfo fetching. No other protocol (SAML, LDAP, OIDC-specific) ships.
