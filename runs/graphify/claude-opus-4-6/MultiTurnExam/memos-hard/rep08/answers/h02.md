**Protection mechanism** — Two-layer SSRF guard:

1. **Registration-time URL validation** — `ValidateURL()` at `internal/webhook/validate.go:62`. When a webhook is created or updated, it parses the URL, rejects non-HTTP(S) schemes, DNS-resolves the hostname, and checks every resolved IP against a blocklist of reserved CIDRs (loopback, RFC-1918, link-local, IPv6 ULA/link-local) defined at `internal/webhook/validate.go:14-23`.

2. **Dial-time re-check (anti-DNS-rebinding)** — `safeDialContext()` at `internal/webhook/webhook.go:59`. The `safeClient` HTTP client uses a custom `Transport` with this dialer, which re-resolves the hostname at connection time and rejects any IP in a reserved range, preventing TOCTOU/DNS-rebinding attacks that could bypass the registration-time check.
