**Delivery function** — `Post` in `internal/webhook/webhook.go` (lines 120–179). It JSON-encodes the payload, builds an HTTP POST request to the target URL, optionally signs it with HMAC-SHA256 (Standard Webhooks headers), and dispatches it via a `safeClient`. An async variant `PostAsync` (line 184) queues payloads onto a buffered channel drained by background goroutines that call `Post`.

**Protection mechanism** — A two-layer SSRF guard prevents webhooks from reaching internal network addresses:

1. **Registration-time validation** — `ValidateURL` in `internal/webhook/validate.go` (lines 62–83) resolves the hostname and checks every resulting IP against `isReservedIP` (same file, lines 44–54), which tests against a list of reserved CIDRs (loopback, RFC-1918, link-local, IPv6 ULA/link-local) defined at lines 14–23.

2. **Dial-time guard** (defeats DNS rebinding) — `safeDialContext` in `internal/webhook/webhook.go` (lines 57–77) is wired as the custom `DialContext` on the `safeClient`'s transport. It re-resolves the hostname at the moment of connection and re-checks every resolved IP against `isReservedIP`, blocking the dial if any IP falls within a reserved range.

A CLI flag `--allow-private-webhooks` (`cmd/memos/main.go:133`, wired at line 49) can opt out of the protection for self-hosted deployments that need local-network webhooks.
