The premise is incorrect — there is no nightly database-cleanup cron job in this codebase. While the project includes an `internal/scheduler` package with cron-parsing capabilities, it is not used to schedule any database cleanup task. The only scheduled background runner is the S3 presign runner (`server/runner/s3presign/runner.go`), which refreshes presigned URLs every 12 hours. The in-memory cache (`store/cache/cache.go`) has its own periodic cleanup loop for expired entries, but that is not a database cleanup job and does not use cron scheduling.
