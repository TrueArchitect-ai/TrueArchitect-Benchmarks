The premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)** with both **gRPC** and **Connect** (gRPC-compatible HTTP) as the transport.

The API surface is defined in `.proto` files under `proto/api/v1/`, including services like `MemoService` (`proto/api/v1/memo_service.proto`), `AuthService` (`proto/api/v1/auth_service.proto`), `UserService` (`proto/api/v1/user_service.proto`), `IdentityProviderService` (`proto/api/v1/idp_service.proto`), and others. Generated Go code lives in `proto/gen/api/v1/` (gRPC stubs) and `proto/gen/api/v1/apiv1connect/` (Connect handlers). The Connect handlers are registered in `server/router/api/v1/v1.go` and served over HTTP, while gRPC-gateway reverse proxies are also generated (`.pb.gw.go` files) for REST-style access.
