The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel**.

The queue is declared in `internal/webhook/webhook.go` as `asyncPostQueue`, a `chan *WebhookRequestPayload` with a capacity of 128. Four goroutines are started in an `init()` function in the same file to drain this channel, each calling `Post()` to execute the outbound HTTP request. Callers enqueue payloads via `PostAsync()` (`internal/webhook/webhook.go:184`), which performs a non-blocking send on the channel (dropping the event if the channel is full).
