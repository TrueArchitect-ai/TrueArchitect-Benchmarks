Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` struct that every provider must return.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol that ships, providing a generic **OAuth2** implementation with `ExchangeToken` and `UserInfo` methods. It is generic enough to work with any OAuth2-compatible provider (GitHub, Google, etc.) via configurable URLs and field mappings.
