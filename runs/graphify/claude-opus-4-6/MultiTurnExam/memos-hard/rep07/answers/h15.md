1. **`checkMemoReadAccess`** (gRPC `GetMemo` and `ListMemoComments`) — `server/router/api/v1/memo_service.go:39–67` — point-read guard: denies unauthenticated access to non-public memos, denies private memos to non-creators.

2. **`ListMemos` visibility filtering** — `server/router/api/v1/memo_service.go:218–227` — query-level enforcement: anonymous users see only `PUBLIC`; authenticated users viewing others' memos see only `PUBLIC` + `PROTECTED`; own memos are unfiltered.

3. **`CreateMemoComment` visibility check** — `server/router/api/v1/memo_service_comments.go:33–43` — blocks commenting on a private memo unless the requester is the creator or a super-user.

4. **`ListReactions` / `UpsertReaction` visibility check** — `server/router/api/v1/reaction_service.go:29–38` and `server/router/api/v1/reaction_service.go:82–84` — blocks reactions on private memos by non-creators.

5. **`ListMemoAttachments` visibility check** — `server/router/api/v1/memo_attachment_service.go:213–222` — blocks listing attachments of private memos by non-creators.

6. **File server attachment permission** (`checkAttachmentPermission`) — `server/router/fileserver/fileserver.go:674–703` — enforces visibility when serving attachment binary content over HTTP, including share-token fallback.

7. **SSE event delivery filtering** (`canReceive`) — `server/router/api/v1/sse_hub.go:134–144` — private memo events are only delivered to the creator or admins.

8. **RSS feed** — `server/router/rss/rss.go:90` — hardcodes `VisibilityList: []store.Visibility{store.Public}`, exposing only public memos.

9. **`ListMemoComments` / `ListMemoRelations` visibility filtering** — `server/router/api/v1/memo_service_comments.go:157–161` and `server/router/api/v1/memo_relation_service.go:109–111` — filters returned comments/relations by visibility based on the caller's identity.
