The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). Webhook delivery uses a simple in-memory Go buffered channel.

The "queue" is declared in `internal/webhook/webhook.go:39` as `asyncPostQueue`, a buffered channel with capacity 128. Four goroutines are spawned in the package's `init()` function (lines 42–55) to drain this channel, each calling `Post()` directly. Callers enqueue payloads via `PostAsync` (line 184), which sends to the channel. There is no external message broker involved.
