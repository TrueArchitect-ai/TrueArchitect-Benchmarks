The premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)** with gRPC and REST (via gRPC-Gateway).

The API service definitions live in `proto/api/v1/` — for example, `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/idp_service.proto`, etc. These proto files define gRPC services with `google.api.http` annotations that expose REST endpoints (e.g., `GET /api/v1/memos`). Generated Go code (gRPC stubs, gateway handlers, and Connect handlers) is output to `proto/gen/api/v1/`.
