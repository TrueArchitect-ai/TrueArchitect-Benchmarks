**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356`) to parse the memo content in a single AST walk, then writes the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (3):**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` — when a new memo is created
2. **UpdateMemo** (content change) — `server/router/api/v1/memo_service.go:447` — when memo content is updated
3. **RunOnce** (batch rebuild) — `server/runner/memopayload/runner.go:27` — bulk recomputation of all memos (e.g. on migration/upgrade)

**Extracted properties:**
- **Tags** — all `#tag` occurrences in the markdown (`memo.Payload.Tags`)
- **Property.Title** — text of the first H1 heading, if present
- **Property.HasLink** — whether the content contains any links
- **Property.HasCode** — whether the content contains code blocks or inline code
- **Property.HasTaskList** — whether the content contains task list checkboxes
- **Property.HasIncompleteTasks** — whether any task checkboxes are unchecked

Additionally, a **snippet** (plain-text summary, max 64 chars) is computed on-the-fly at read time via `getMemoContentSnippet` → `markdownService.GenerateSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), but this is not persisted — it's generated during memo-to-message conversion (`memo_service_converter.go:76`).
