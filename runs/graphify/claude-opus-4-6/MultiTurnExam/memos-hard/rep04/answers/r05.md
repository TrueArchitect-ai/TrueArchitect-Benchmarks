The premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using Protocol Buffers (protobuf) and exposed via both gRPC and Connect RPC (with REST gateway support).

The proto definitions live under `proto/api/v1/` (e.g., `user_service.proto`, `memo_service.proto`, `auth_service.proto`, etc.). Generated Go code is in `proto/gen/api/v1/` (gRPC stubs in `*_grpc.pb.go`, REST gateway in `*.pb.gw.go`) and `proto/gen/api/v1/apiv1connect/` (Connect RPC bindings in `*.connect.go`). The services are registered on the server's HTTP router in `server/server.go` via both the Connect handler and the gRPC-Gateway.
