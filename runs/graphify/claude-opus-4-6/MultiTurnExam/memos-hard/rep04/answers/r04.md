The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain in-memory Go buffered channel, not an external message queue.

The "queue" is declared as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` in `internal/webhook/webhook.go:39`. Four goroutine workers are started in the package's `init()` function (lines 42–54) to drain this channel, each calling `Post()` (line 46) to execute the outbound HTTP request. `PostAsync` (line 184) enqueues payloads into this channel. The entire mechanism is process-local — if the server restarts, any undelivered payloads in the channel are lost.
