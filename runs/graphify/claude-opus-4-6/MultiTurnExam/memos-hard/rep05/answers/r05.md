The premise is incorrect — there is no GraphQL schema or API. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **gRPC-Gateway** for REST/HTTP access. The proto definitions live under `proto/api/v1/` (e.g., `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/idp_service.proto`, etc.), and generated Go code is in `proto/gen/api/v1/`. The gRPC services are wired up via Connect and gRPC-Gateway in `server/router/api/v1/v1.go`.
