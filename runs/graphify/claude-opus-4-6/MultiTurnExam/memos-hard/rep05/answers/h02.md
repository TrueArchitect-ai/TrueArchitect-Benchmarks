Delivery function — `Post` in `internal/webhook/webhook.go:120` (production callers use `PostAsync` at line 183, which feeds a buffered channel drained by worker goroutines started in `init`).

Protection mechanism — a two-layer **reserved-IP check** that blocks private/internal addresses:

1. **Registration-time validation**: `ValidateURL` (`internal/webhook/validate.go:56`) resolves the hostname and checks every IP against `reservedCIDRs` (loopback, RFC-1918, link-local, IPv6 ULA/link-local — defined at `validate.go:14-23`).
2. **Connection-time dial guard**: `safeDialContext` (`internal/webhook/webhook.go:57`) re-resolves the host on every outbound connection and re-checks against the same reserved ranges, defeating DNS-rebinding attacks. It is wired as the `DialContext` on the `http.Transport` backing `safeClient` (`webhook.go:32-37`), which `Post` uses to send requests.
