The premise is incorrect — there is no nightly database-cleanup job. While a cron scheduler package exists (`internal/scheduler/`), it is never used in production server code: no jobs are registered via `scheduler.Register` anywhere in `server/` or `cmd/`. The scheduler package's only usage examples are in its own documentation (`internal/scheduler/doc.go`).
