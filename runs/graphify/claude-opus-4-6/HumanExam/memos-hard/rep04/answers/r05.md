— False premise. There is no GraphQL API. The public API is defined using Protocol Buffers / gRPC with a gRPC-Gateway REST layer. Proto definitions are in `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`), with generated code in `proto/gen/api/v1/`. An OpenAPI spec is also generated and embedded (`proto/openapi_embed.go`).
