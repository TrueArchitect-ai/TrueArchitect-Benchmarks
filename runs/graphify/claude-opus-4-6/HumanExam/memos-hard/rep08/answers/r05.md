False premise. There is no GraphQL schema. The public API is defined using Protocol Buffers (gRPC) with gRPC-Gateway for REST. Proto definitions are in `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`). The server also uses Connect-Go as an alternative gRPC transport, and an OpenAPI spec is embedded via `proto/openapi_embed.go`.
