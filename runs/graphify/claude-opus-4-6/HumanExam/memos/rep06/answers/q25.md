Engine: CEL (Google Common Expression Language) via `cel-go`, in `internal/filter/engine.go`
Mechanism: The engine compiles CEL filter strings into a dialect-agnostic IR condition tree (parser.go), then renders the IR into dialect-specific SQL fragments (render.go) using per-dialect helpers (SQLite/MySQL/PostgreSQL). Each database driver calls `filter.AppendConditions()` in its `ListMemos`, which compiles each filter and appends the rendered SQL WHERE clause and arguments.
