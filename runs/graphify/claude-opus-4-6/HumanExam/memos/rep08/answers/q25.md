CEL (Common Expression Language) via `cel-go`; engine lives at `internal/filter/engine.go`. The filter expression is compiled by `Engine.Compile` into a dialect-agnostic condition tree (IR), then `Render` converts it to a SQL fragment using a `renderer` with dialect-specific placeholders and syntax for each dialect (SQLite, MySQL, PostgreSQL) via `RenderOptions{Dialect: ...}`. Each DB driver calls `filter.AppendConditions()` or `engine.CompileToStatement()` with its own `DialectName` to produce the WHERE clause.
