CEL (Common Expression Language) via `github.com/google/cel-go`, engine at `internal/filter/engine.go`; the filter string is compiled to a CEL AST, converted to a dialect-agnostic `Condition` tree via `buildCondition()`, then rendered into dialect-specific SQL (SQLite/Postgres/MySQL) by `renderer.Render()` in `internal/filter/render.go`, which handles differences like `JSON_EXTRACT` vs `->>`/`->`, `LIKE` vs `ILIKE`, and `?` vs `$N` placeholders.
