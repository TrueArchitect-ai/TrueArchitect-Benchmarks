CEL (Common Expression Language) engine in `internal/filter/` (core: `internal/filter/engine.go`). The engine compiles the CEL filter string to a dialect-agnostic IR condition tree (`internal/filter/parser.go` + `internal/filter/ir.go`), then a renderer (`internal/filter/render.go`) switches on dialect (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) to produce dialect-specific SQL fragments (e.g., `JSON_EXTRACT` vs `->>`; `LIKE` vs `ILIKE`), appended to the WHERE clause via `filter.AppendConditions` in each driver's `ListMemos`.
