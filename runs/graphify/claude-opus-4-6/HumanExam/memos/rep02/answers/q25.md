Engine: CEL (Common Expression Language) via `cel-go`, in package `internal/filter/`; core file is `internal/filter/engine.go` (`Engine` struct, line 14).
Mechanism: The CEL filter string is compiled into a dialect-agnostic IR condition tree (`parser.go`), then rendered into dialect-specific SQL via `render.go`, which switches on `DialectSQLite`/`DialectMySQL`/`DialectPostgres` for placeholders, JSON extraction, text matching, timestamps, and regex operators. Each DB driver calls `filter.AppendConditions()` (`helpers.go`) to compile filters and append the resulting SQL WHERE clauses and args.
