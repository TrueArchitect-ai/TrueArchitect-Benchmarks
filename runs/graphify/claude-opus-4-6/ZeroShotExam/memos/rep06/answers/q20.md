**Mechanism:** Server-Sent Events (SSE) — the server writes `text/event-stream` responses via the `GET /api/v1/sse` endpoint (`server/router/api/v1/sse_handler.go`), and the browser consumes the stream with `fetch` + `ReadableStream` in `web/src/hooks/useLiveMemoRefresh.ts`.

**Hub path:** `server/router/api/v1/sse_hub.go` — the `SSEHub` struct manages a mutex-protected map of `SSEClient` connections, with `Subscribe`, `Unsubscribe`, and `Broadcast` methods. It filters events by memo visibility (private events only go to the creator or admins).
