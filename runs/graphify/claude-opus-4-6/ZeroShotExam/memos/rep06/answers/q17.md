`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD operations as React Query hooks (e.g., `useCreateMemo`, `useMemo`, `useMemos`, `useUpdateMemo`, `useDeleteMemo`). Each hook calls methods on `memoServiceClient`, which is imported from `@/connect` (`web/src/connect.ts`) and created via `createClient(MemoService, transport)` using `@connectrpc/connect`.
