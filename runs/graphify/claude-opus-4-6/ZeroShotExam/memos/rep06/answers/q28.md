**Runners the server actually starts:**

- **S3 Presign Runner** — `time.NewTicker(12h)` in a goroutine; also runs once synchronously at startup. Re-signs expiring S3 attachment URLs. Started in `server/server.go:162–171`, defined in `server/runner/s3presign/runner.go`.
- **Async Email Workers (×2)** — 2 goroutines consuming from a buffered channel (size 128), started via `init()` in `internal/email/email.go:17`. Triggered on-demand when `SendAsync()` enqueues an email.
- **Async Webhook Workers (×4)** — 4 goroutines consuming from a buffered channel (size 128), started via `init()` in `internal/webhook/webhook.go:42`. Triggered on-demand when `PostAsync()` enqueues a webhook payload.
- **Cache Cleanup (×3)** — one goroutine per cache instance (`instanceSettingCache`, `userCache`, `userSettingCache`), each using `time.NewTicker(5m)` to evict expired entries. Created in `store/store.go:51–53`, cleanup loop in `store/cache/cache.go:200`.
- **SSE Heartbeat (per-connection)** — `time.NewTicker(30s)` per connected SSE client, sending keepalive pings. Created in `server/router/api/v1/sse_handler.go:64`.

**Unused scheduling infrastructure:**

- **`internal/scheduler/`** — A complete cron-based job scheduler (cron parser, per-job goroutines with `time.NewTimer`, middleware for recovery/logging/timeout) that is **not imported or used anywhere** outside its own package. No other file in the codebase references it.
- **Memo Payload Runner** (`server/runner/memopayload/runner.go`) — A `Runner` wrapper with `NewRunner()`/`Run()` that is **never instantiated** by the server. The underlying `RebuildMemoPayload()` function from the same package *is* called inline in request handlers (`server/router/api/v1/memo_service.go:108,447`), but the runner/batch-loop scaffolding around it is dormant.
