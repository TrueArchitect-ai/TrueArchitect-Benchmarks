The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built frontend assets (from `web/` via `pnpm release`) directly into the Go binary. This is wired in `server/router/frontend/frontend.go`, where `//go:embed dist/*` bakes the Vite build output into an `embed.FS`, and Echo's static middleware plus an SPA fallback middleware serve those files at runtime.
