When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook`, which delegates to `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`. That function iterates over the creator's webhooks and calls `webhook.PostAsync` to enqueue each payload.

The actual HTTP delivery is performed by the `internal/webhook` package (`internal/webhook/webhook.go`), which uses a worker-pool of goroutines consuming from an async channel, each calling `Post()` to send an HTTP POST request.

The request-signing mechanism follows the **Standard Webhooks** spec: an **HMAC-SHA256** signature is computed over `msgID + "." + timestamp + "." + body` using a key derived from the `SigningSecret` (optionally `whsec_`-prefixed and base64-decoded), and delivered via `webhook-id`, `webhook-timestamp`, and `webhook-signature` headers.
