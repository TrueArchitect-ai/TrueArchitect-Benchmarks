Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to a shared helper `dispatchMemoRelatedWebhook` in the same file. All four ultimately call **`webhook.PostAsync`** (`internal/webhook/webhook.go`), which enqueues payloads into a buffered channel. Worker goroutines drain that channel and converge on **`webhook.Post`** (`internal/webhook/webhook.go`) for actual HTTP delivery (JSON POST with optional HMAC-SHA256 signing).
