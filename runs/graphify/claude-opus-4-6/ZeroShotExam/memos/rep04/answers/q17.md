`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD operations as React Query hooks (e.g., `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`). They all call methods on `memoServiceClient`, which is instantiated in `web/src/connect.ts` via `createClient(MemoService, transport)` using `@connectrpc/connect`.
