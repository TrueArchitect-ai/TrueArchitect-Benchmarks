MemoService is served over two protocols: **gRPC-Gateway** (REST/HTTP) and **Connect**.

1. **gRPC-Gateway (REST/HTTP)** — `server/router/api/v1/v1.go`
   - Registration happens at line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)`, which uses the generated gateway code in `proto/gen/api/v1/memo_service.pb.gw.go` to translate RESTful HTTP requests into gRPC service calls.

2. **Connect** — `server/router/api/v1/connect_handler.go`
   - Registration happens at line 40: `apiv1connect.NewMemoServiceHandler(s, opts...)`, inside `RegisterConnectHandlers`. The Connect-protocol method wrappers that delegate to the underlying gRPC implementation live in `server/router/api/v1/connect_services.go` (lines 304–464).
