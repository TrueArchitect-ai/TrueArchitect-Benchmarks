Here is the complete call chain for creating a memo, one hop per line:

1. **Frontend mutation hook:** `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` wraps a TanStack Query `useMutation` calling `memoServiceClient.createMemo()`
2. **Connect-RPC client:** `web/src/connect.ts` — `memoServiceClient = createClient(MemoService, transport)` sends the request over Connect protocol
3. **Proto RPC definition:** `proto/api/v1/memo_service.proto` — defines `rpc CreateMemo(CreateMemoRequest) returns (Memo)` on `MemoService`
4. **Connect handler (bridge):** `server/router/api/v1/connect_services.go` — `ConnectServiceHandler.CreateMemo` unpacks the Connect request and delegates to `s.APIV1Service.CreateMemo(ctx, req.Msg)`
5. **API service handler:** `server/router/api/v1/memo_service.go` — `APIV1Service.CreateMemo` validates, builds a `store.Memo`, and calls `s.Store.CreateMemo(ctx, create)`
6. **Store method:** `store/memo.go` — `Store.CreateMemo` validates the UID then delegates to `s.driver.CreateMemo(ctx, create)`
7. **Dialect driver (e.g. SQLite):** `store/db/sqlite/memo.go` — executes `INSERT INTO memo (uid, creator_id, content, visibility, payload, ...) VALUES (?, ?, ?, ?, ?, ...) RETURNING id, created_ts, updated_ts, row_status`

(Alternate dialect drivers: `store/db/postgres/memo.go` and `store/db/mysql/memo.go`)
