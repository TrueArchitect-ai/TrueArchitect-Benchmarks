**Engine:** CEL (Common Expression Language) via `google/cel-go`, living in `internal/filter/` (entry point `internal/filter/engine.go`).

**Mechanism:** The `Engine.Compile` method parses the filter string through a `cel.Env`, converts the CEL AST into a dialect-agnostic `Condition` tree (`internal/filter/ir.go`), and then `Program.Render` walks that tree with a `renderer` (`internal/filter/render.go`) that switches on a `DialectName` (`DialectSQLite`, `DialectMySQL`, `DialectPostgres` — defined in `internal/filter/schema.go:11-16`) to emit dialect-specific SQL fragments (placeholders, function names like `CONCAT` vs `||`, JSON extraction syntax, etc.) for each condition node.
