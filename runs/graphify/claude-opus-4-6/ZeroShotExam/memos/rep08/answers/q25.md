The engine is **Google CEL (Common Expression Language)**, implemented via `github.com/google/cel-go` and wrapped in a custom package at **`internal/filter/`** — `engine.go` compiles the CEL string into a checked AST, `parser.go` walks that AST to build a dialect-agnostic intermediate representation (defined in `ir.go`), and `render.go` renders that IR tree into SQL for each dialect (`sqlite`, `mysql`, `postgres`) by switching on `DialectName` to emit dialect-specific column expressions, placeholder styles, JSON operators, timestamp functions, and text-matching patterns.
