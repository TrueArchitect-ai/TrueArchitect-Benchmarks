Four memo lifecycle events dispatch webhooks, all orchestrated from `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to the private method `dispatchMemoRelatedWebhook` (same file, line 48), which resolves the memo creator's webhooks and builds the payload. The comment-created variant inlines similar logic but resolves webhooks for the related memo's creator rather than the comment author.

All four converge for delivery at **`webhook.Post`** in `internal/webhook/webhook.go`. Specifically, each dispatch calls **`webhook.PostAsync`** (line 184), which enqueues the payload onto a buffered channel. Worker goroutines drain that channel and call **`Post`** (line 120), which JSON-serializes the payload, computes Standard Webhooks HMAC-SHA256 signatures if a signing secret is configured, and sends the HTTP POST request via an SSRF-safe client.
