When a memo is deleted through the store layer (`store/memo.go:140–158`), the following kinds of records are deleted before the memo row itself:

1. **Memo relations** where the memo is the source (`MemoID`) — via `DeleteMemoRelation`
2. **Memo relations** where the memo is the target (`RelatedMemoID`) — via `DeleteMemoRelation`
3. **Attachments** linked to the memo — found via `ListAttachments` with the memo's ID, then each deleted via `DeleteAttachment`
