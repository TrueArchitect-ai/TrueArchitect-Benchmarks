The database tables affected when `DeleteMemo` runs are:

1. **`memo`** — the memo row itself is deleted (`store/db/sqlite/memo.go:239`)
2. **`memo_relation`** — all relation records where the memo is either `memo_id` or `related_memo_id` are deleted (`store/memo.go:142-146`, `store/db/sqlite/memo_relation.go:148-150`)
3. **`attachment`** — all attachments linked to the memo are deleted (`store/memo.go:149-156`, `store/db/sqlite/attachment.go:212`)

The service layer (`server/router/api/v1/memo_service.go:567-577`) also cascades into **comment memos**: it finds all `memo_relation` records of type `Comment` pointing to the memo being deleted, then calls `Store.DeleteMemo` for each comment memo — which in turn deletes that comment's `memo_relation`, `attachment`, and `memo` rows using the same logic.
