The mechanism is **Server-Sent Events (SSE)**, served at `GET /api/v1/sse` (`server/router/api/v1/sse_handler.go`).

The hub is implemented in **`server/router/api/v1/sse_hub.go`** as the `SSEHub` struct, which maintains a mutex-protected set of `SSEClient` connections and exposes `Subscribe`, `Unsubscribe`, and `Broadcast` methods. It is instantiated once in `NewAPIV1Service` (`server/router/api/v1/v1.go`).

The memo handlers that broadcast through the hub are:

- **`CreateMemo`** — broadcasts `memo.created` (`memo_service.go`)
- **`UpdateMemo`** — broadcasts `memo.updated` via `dispatchMemoUpdatedSideEffects` (`memo_service.go` → `memo_update_helpers.go`)
- **`DeleteMemo`** — broadcasts `memo.deleted` (`memo_service.go`)
- **`CreateMemoComment`** — broadcasts `memo.comment.created` (`memo_service_comments.go`)
- **`SetMemoRelations`** — broadcasts `memo.updated` via `dispatchMemoUpdatedSideEffects` (`memo_relation_service.go`)
- **`SetMemoAttachments`** — broadcasts `memo.updated` via `dispatchMemoUpdatedSideEffects` (`memo_attachment_service.go`)
- **`UpsertMemoReaction`** — broadcasts `reaction.upserted` (`reaction_service.go`)
- **`DeleteMemoReaction`** — broadcasts `reaction.deleted` (`reaction_service.go`)
