Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to a shared helper `dispatchMemoRelatedWebhook` (same file), while `DispatchMemoCommentCreatedWebhook` has its own implementation (it targets the related memo's creator rather than the memo's own creator).

All four converge for delivery through **`webhook.Post`** in `internal/webhook/webhook.go`. Specifically, each dispatch function calls **`webhook.PostAsync`** (line 184), which enqueues the payload onto a buffered channel. Worker goroutines drain that channel and call **`webhook.Post`** (line 120), which performs the actual HTTP POST delivery (including HMAC-SHA256 signing and SSRF-safe dialing).
