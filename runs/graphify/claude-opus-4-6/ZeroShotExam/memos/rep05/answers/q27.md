The compiled React frontend is served via Go's `//go:embed` directive, which embeds the `dist/` directory into the Go binary at compile time. The embedded filesystem is then served using Echo's `StaticDirectoryHandler` with an SPA fallback middleware.

This is wired in `server/router/frontend/frontend.go`, where `//go:embed dist/*` embeds the built frontend assets into the `embeddedFiles` variable, and the `Serve` method sets up the static file handler and SPA fallback on the Echo server.
