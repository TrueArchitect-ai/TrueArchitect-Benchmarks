`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD operations as React Query hooks — `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo` for mutations, and `useMemos`/`useMemo` for queries. It imports `memoServiceClient` from `@/connect` (`web/src/connect.ts`), which is created via `createClient(MemoService, transport)` using the `@connectrpc/connect` library and the generated `MemoService` descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
