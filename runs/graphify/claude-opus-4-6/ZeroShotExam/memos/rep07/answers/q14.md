The `ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` with five RPCs:

1. **ListShortcuts**
2. **GetShortcut**
3. **CreateShortcut**
4. **UpdateShortcut**
5. **DeleteShortcut**

The backend implementation file is **`server/router/api/v1/shortcut_service.go`**, where each RPC is implemented as a method on `APIV1Service` (lines 49, 95, 135, 211, 284 respectively).

There is also a Connect (gRPC-compatible) handler layer in `server/router/api/v1/connect_services.go` (lines 528–560) that delegates to the core implementations via `ConnectServiceHandler`.
