The compiled React frontend is served via Go's `//go:embed` directive, which embeds the `dist/` directory into the binary at compile time. The embedded files are then served through Echo's static middleware and an SPA fallback middleware.

**Mechanism:** `//go:embed` (Go embed) combined with Echo `StaticWithConfig` middleware  
**File:** `server/router/frontend/frontend.go`

In that file, `//go:embed dist/*` (line ~20) bakes the Vite build output into the binary, and `NewFrontendService(...).Serve(...)` registers the static-file and SPA-fallback middleware on the Echo server. The service is wired into the HTTP server in `server/server.go` (line ~71).
