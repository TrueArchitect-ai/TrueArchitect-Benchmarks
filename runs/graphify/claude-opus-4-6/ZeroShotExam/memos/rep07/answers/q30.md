Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memos.memo.created**: `DispatchMemoCreatedWebhook`
- **memos.memo.updated**: `DispatchMemoUpdatedWebhook`
- **memos.memo.deleted**: `DispatchMemoDeletedWebhook`
- **memos.memo.comment.created**: `DispatchMemoCommentCreatedWebhook`

The first three delegate to the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), which resolves the memo creator, fetches their webhooks, and builds the payload.

All four converge for delivery at **`webhook.Post`** in `internal/webhook/webhook.go` (line 120). The dispatch functions call `webhook.PostAsync` (line 184), which enqueues the payload onto an async channel (`asyncPostQueue`). A pool of worker goroutines drains that channel and calls `Post`, which performs the actual HTTP POST with HMAC-SHA256 signing and SSRF-safe delivery.
