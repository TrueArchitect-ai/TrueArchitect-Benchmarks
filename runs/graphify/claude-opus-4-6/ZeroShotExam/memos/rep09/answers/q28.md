**Background workers the server actually starts:**

- **S3 Presign Runner** — `time.NewTicker` at 12-hour intervals (plus one synchronous run at startup). Refreshes S3 presigned URLs nearing expiration. Started explicitly in `server/server.go:153` via `startBackgroundRunners()`. (`server/runner/s3presign/runner.go`)

- **Webhook async dispatch workers (×4)** — driven by a buffered channel (`asyncPostQueue`, cap 128); goroutines launched in package `init()` and consume enqueued webhook payloads as they arrive. (`internal/webhook/webhook.go`)

- **Email async dispatch workers (×2)** — driven by a buffered channel (`asyncEmailQueue`, cap 128); goroutines launched in package `init()` and consume enqueued emails as they arrive. (`internal/email/email.go`)

- **Cache cleanup goroutines (×3)** — `time.NewTicker` at 5-minute intervals per cache instance (`instanceSettingCache`, `userCache`, `userSettingCache`). Started when the store is created in `store/store.go:51-53`; evict expired entries each tick. (`store/cache/cache.go`)

- **SSE Hub heartbeat (per-client)** — `time.NewTicker` at 30-second intervals per connected SSE client, keeping the connection alive. Created per-connection in the SSE handler. (`server/router/api/v1/sse_handler.go`)

**Unused scheduling infrastructure:**

- `internal/scheduler/` — A fully-featured cron-expression job scheduler (supports 5/6-field cron, timezone-aware scheduling, middleware chain with recovery/logging/timeout). It is **never imported or used** anywhere outside its own package and test files.

- `server/runner/memopayload/` — The `memopayload.Runner` struct and `NewRunner()` constructor are **never instantiated** by any code. Only the standalone utility function `RebuildMemoPayload()` from the same package is used (inline during memo create/update in `memo_service.go`), not as a background runner.
