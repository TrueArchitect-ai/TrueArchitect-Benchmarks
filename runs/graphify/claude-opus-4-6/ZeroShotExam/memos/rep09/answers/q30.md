Four memo lifecycle events dispatch webhooks, all with dispatch functions defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook`
- **memo updated**: `DispatchMemoUpdatedWebhook`
- **memo deleted**: `DispatchMemoDeletedWebhook`
- **memo comment created**: `DispatchMemoCommentCreatedWebhook`

The first three share a private helper `dispatchMemoRelatedWebhook` (same file, line 48) that looks up the memo creator's webhooks. `DispatchMemoCommentCreatedWebhook` has its own lookup logic (it finds webhooks for the *parent memo's* owner rather than the comment author).

All four converge on **`webhook.Post`** in `internal/webhook/webhook.go` (line 120) for actual HTTP delivery. The dispatch functions call **`webhook.PostAsync`** (same file, line 184), which enqueues the payload onto a buffered channel; worker goroutines dequeue and call `Post`, which marshals the payload to JSON, signs it with HMAC-SHA256 if a secret is configured, and sends the HTTP POST request.
