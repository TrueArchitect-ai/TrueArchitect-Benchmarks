**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`, wrapped in a project-specific filter engine at `internal/filter/` — the `Engine` type in `internal/filter/engine.go` calls `cel.Env.Compile()` to parse the filter string, `internal/filter/parser.go` walks the CEL protobuf AST to build an intermediate representation (IR defined in `internal/filter/ir.go`), and `internal/filter/render.go` renders that IR tree into dialect-specific SQL (SQLite/MySQL/PostgreSQL) by switching on a `DialectName` constant passed from each store driver (e.g., `store/db/sqlite/memo.go` passes `filter.DialectSQLite`, `store/db/postgres/memo.go` passes `filter.DialectPostgres`), handling per-dialect differences in placeholder style (`?` vs `$N`), JSON operators, timestamp functions, regex syntax, and quoting.
