`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file defines all memo CRUD hooks (`useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemo`, `useMemos`, etc.) using `@tanstack/react-query`. Each hook calls methods on `memoServiceClient`, which is imported from `@/connect` (`web/src/connect.ts`). That client is created via `createClient(MemoService, transport)` from `@connectrpc/connect`, where `MemoService` is the protobuf-generated service descriptor from `@/types/proto/api/v1/memo_service_pb`.
