MemoService is served over two protocols:

1. **gRPC-Gateway (REST/HTTP)** — `server/router/api/v1/v1.go` (line 108), where `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` registers MemoService onto the gRPC-Gateway mux, which translates HTTP/JSON requests into gRPC calls. The generated gateway code lives in `proto/gen/api/v1/memo_service.pb.gw.go`.

2. **Connect (ConnectRPC)** — `server/router/api/v1/connect_handler.go` (line 40), where `apiv1connect.NewMemoServiceHandler(s, opts...)` registers MemoService as a Connect handler on an `http.ServeMux`. The generated Connect code lives in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.
