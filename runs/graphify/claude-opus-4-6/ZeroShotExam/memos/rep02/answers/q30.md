**Memo lifecycle events that dispatch webhooks, and their dispatch function names:**

1. `memos.memo.created`: `DispatchMemoCreatedWebhook`
2. `memos.memo.updated`: `DispatchMemoUpdatedWebhook`
3. `memos.memo.deleted`: `DispatchMemoDeletedWebhook`
4. `memos.memo.comment.created`: `DispatchMemoCommentCreatedWebhook`

All four are methods on `*APIV1Service`, defined in `server/router/api/v1/memo_service_webhooks.go`. The first three delegate to a shared private helper `dispatchMemoRelatedWebhook` (same file); the comment variant has its own loop (it targets the *parent memo owner's* webhooks).

**Delivery convergence point:**

All four dispatch functions call `webhook.PostAsync` in `internal/webhook/webhook.go`. This enqueues payloads onto a buffered channel (`asyncPostQueue`), which is drained by worker goroutines that call `webhook.Post` — the single synchronous HTTP delivery function that marshals the payload, signs it (HMAC-SHA256 if a signing secret is configured), and sends it via an SSRF-safe HTTP client.
