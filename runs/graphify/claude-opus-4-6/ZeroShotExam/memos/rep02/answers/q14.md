The `ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` with **5 RPCs**:

1. **ListShortcuts**
2. **GetShortcut**
3. **CreateShortcut**
4. **UpdateShortcut**
5. **DeleteShortcut**

The backend implementation file is **`server/router/api/v1/shortcut_service.go`**, where the `APIV1Service` struct implements all five methods (lines 49, 95, 135, 211, 284).

(There is also a thin Connect-protocol adapter layer in `server/router/api/v1/connect_services.go` that delegates to the same `APIV1Service` methods.)
