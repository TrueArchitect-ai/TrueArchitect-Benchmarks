**Background workers/runners the server actually starts:**

- **S3 presign runner** — `time.NewTicker(12 * time.Hour)` interval; started explicitly by `Server.startBackgroundRunners()` in `server/server.go:153-171`. Refreshes expiring presigned S3 URLs for attachments.
- **Webhook async workers (x4)** — channel-driven (`asyncPostQueue`, capacity 128); started by package `init()` in `internal/webhook/webhook.go:42-55` when the package is imported. Drain the queue and POST each webhook payload.
- **Email async workers (x2)** — channel-driven (`asyncEmailQueue`, capacity 128); started by package `init()` in `internal/email/email.go:16-36` when the package is imported. Drain the queue and send each email via SMTP.
- **Cache cleanup goroutines (x3)** — `time.NewTicker(5 * time.Minute)` interval; started by `cache.New()` in `store/cache/cache.go:76` for each of the three caches (`instanceSettingCache`, `userCache`, `userSettingCache`) created in `store/store.go:51-53`. Evict expired entries.

**Unused scheduling infrastructure:** The `internal/scheduler/` package is a fully implemented cron scheduler (with cron expression parser, job registration, middleware, and a comprehensive test suite) that is **never imported by any production code** — only by its own test files (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`). It is not wired into the server startup or used anywhere outside the package itself.
