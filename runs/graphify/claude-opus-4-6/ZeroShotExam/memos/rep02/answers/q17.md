`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This file contains memo CRUD hooks (`useCreateMemo`, `useMemo`, `useMemos`, `useUpdateMemo`, `useDeleteMemo`) built on `@tanstack/react-query`. It imports `memoServiceClient` from `web/src/connect.ts`, which is created via `createClient(MemoService, transport)` using the `@connectrpc/connect` library against the generated `MemoService` descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
