The filter engine uses **CEL (Common Expression Language)** via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`. The `Engine.Compile` method parses the CEL filter string into a CEL AST, then `buildCondition` (`internal/filter/parser.go`) walks that AST to produce a dialect-agnostic IR (condition tree), and `renderer.Render` (`internal/filter/render.go`) translates the IR into SQL by switching on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) to emit dialect-specific SQL fragments, placeholders, and JSON operators for each condition node.
