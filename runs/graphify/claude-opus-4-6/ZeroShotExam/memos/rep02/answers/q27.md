The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built `dist/` directory directly into the Go binary. This is wired in `server/router/frontend/frontend.go`, where `//go:embed dist/*` bundles the assets and the `Serve` method registers Echo's `StaticWithConfig` middleware (plus an SPA fallback) to serve them at runtime.

**Mechanism:** `go:embed` (with Echo static middleware); **File:** `server/router/frontend/frontend.go`
