`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The file `web/src/hooks/useMemoQueries.ts` contains the memo CRUD mutations and queries (hooks like `useCreateMemo`, `useMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, etc.) built on `@tanstack/react-query`. It uses the generated service client `memoServiceClient`, which is instantiated in `web/src/connect.ts` via `createClient(MemoService, transport)` from `@connectrpc/connect`, where `MemoService` is the protobuf-generated service descriptor from `web/src/types/proto/api/v1/memo_service_pb.ts`.
