**Engine:** Google CEL (Common Expression Language) via `github.com/google/cel-go/cel`; **Path:** `internal/filter/engine.go` (with parser in `internal/filter/parser.go` and renderer in `internal/filter/render.go`).

**Mechanism:** `Engine.Compile()` parses the CEL filter string into a CEL AST, then `buildCondition()` in `parser.go` walks the AST to produce a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`), and `Program.Render()` passes that tree to a `renderer` (`internal/filter/render.go`) that switches on `DialectName` (`sqlite`, `postgres`, `mysql` — defined in `internal/filter/schema.go:14-16`) to emit dialect-specific SQL fragments (e.g., `strftime` for SQLite, `EXTRACT` for Postgres, native functions for MySQL).
