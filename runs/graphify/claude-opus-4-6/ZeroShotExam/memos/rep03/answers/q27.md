The compiled React frontend is served via Go's `//go:embed` directive, which embeds the built assets (from `web/` compiled into `server/router/frontend/dist/`) directly into the Go binary. This is wired in `server/router/frontend/frontend.go`, where `embeddedFiles embed.FS` holds the assets and the `Serve` method registers Echo static-file middleware plus an SPA fallback to serve them at runtime.

**`go:embed`; `server/router/frontend/frontend.go`**
