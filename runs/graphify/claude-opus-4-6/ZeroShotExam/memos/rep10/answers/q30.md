Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
- **memo updated**: `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
- **memo deleted**: `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
- **memo comment created**: `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)

The first three delegate through a shared helper `dispatchMemoRelatedWebhook` (same file, line 48). All four ultimately call **`webhook.Post`** via **`webhook.PostAsync`** in `internal/webhook/webhook.go` (lines 120 and 184 respectively). `PostAsync` enqueues payloads into a buffered channel (`asyncPostQueue`), consumed by worker goroutines that call `Post` — the single convergence point where every webhook is JSON-serialized, optionally HMAC-signed, and delivered as an HTTP POST.
