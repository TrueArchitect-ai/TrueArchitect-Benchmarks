The compiled React frontend is served via Go's **`embed` package** (`//go:embed dist/*`), which bakes the built assets directly into the Go binary at compile time. The serving logic—including Echo's `StaticWithConfig` middleware and an SPA fallback—is wired in **`server/router/frontend/frontend.go`**.

Specifically, `embeddedFiles embed.FS` (line ~21) embeds the Vite build output from `dist/`, and the `Serve` method registers static file middleware plus a fallback that serves `index.html` for client-side routes. The frontend service itself is mounted onto the Echo server in `server/server.go` (line 72).

**Answer:** `go:embed`; `server/router/frontend/frontend.go`
