The `ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` with these five RPCs:

1. **ListShortcuts**
2. **GetShortcut**
3. **CreateShortcut**
4. **UpdateShortcut**
5. **DeleteShortcut**

The backend implementation is in **`server/router/api/v1/shortcut_service.go`**, where each RPC is implemented as a method on `APIV1Service`. There is also a thin Connect-protocol adapter layer in `server/router/api/v1/connect_services.go` (the `ConnectServiceHandler` methods delegate to the corresponding `APIV1Service` methods), but the actual business logic lives in `shortcut_service.go`.
