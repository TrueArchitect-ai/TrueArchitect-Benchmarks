**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (ConnectRPC interceptor) attaches an `Authorization: Bearer <token>` header to every outgoing request and handles transparent retry/refresh on `Unauthenticated` errors.

**Token kinds:**
1. **Access token** — a short-lived (15 min) HS256 JWT stored in `localStorage` (`memos_access_token`), sent as `Bearer` in the `Authorization` header.
2. **Refresh token** — a long-lived (30 day) JWT stored as an `HttpOnly` cookie named `memos_refresh`, used to obtain new access tokens via `AuthService.RefreshToken`.
3. **Personal access token (PAT)** — prefixed `memos_pat_`, stored as a SHA-256 hash in the database, also sent as a `Bearer` token.

**Backend package path:** `server/auth/` — specifically `server/auth/authenticator.go` (the `Authenticator` struct with `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT` methods) and `server/auth/token.go` (JWT generation/parsing). The server-side interceptor that calls into this package lives at `server/router/api/v1/connect_interceptors.go` (`AuthInterceptor`).
