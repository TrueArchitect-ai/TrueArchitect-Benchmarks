`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The file `web/src/hooks/useMemoQueries.ts` contains all the memo CRUD mutations and queries as React Query hooks (`useCreateMemo`, `useMemo`, `useMemos`, `useUpdateMemo`, `useDeleteMemo`, etc.). It imports and uses `memoServiceClient`, which is a ConnectRPC client created in `web/src/connect.ts` via `createClient(MemoService, transport)`.
