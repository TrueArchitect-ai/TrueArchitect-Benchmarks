**Computation site:** `server/runner/memopayload/runner.go` — the `RebuildMemoPayload` function calls `markdownService.ExtractAll()` (defined in `internal/markdown/markdown.go:356`) to parse the memo content's AST and extract derived metadata. The snippet is computed separately on-the-fly via `getMemoContentSnippet()` in `server/router/api/v1/memo_service_converter.go:76`, which calls `markdownService.GenerateSnippet()` (`internal/markdown/markdown.go:264`).

**Triggers:** Recomputation is triggered on **memo creation** (`server/router/api/v1/memo_service.go:108`) and on **memo content update** (`server/router/api/v1/memo_service.go:447`, when `content` is in the update field mask). There is also a batch `RunOnce` method (`server/runner/memopayload/runner.go:27`) that rebuilds payload metadata for all memos (used for migrations/reindexing).

**Extracted properties:**
- **`HasLink`** (bool) — whether the content contains markdown links
- **`HasTaskList`** (bool) — whether the content contains GFM task checkboxes
- **`HasCode`** (bool) — whether the content contains code blocks or code spans
- **`HasIncompleteTasks`** (bool) — whether any task checkboxes are unchecked
- **`Title`** (string) — extracted from the first `# H1` heading if it is the first block-level element
- **Tags** (string list) — all `#tag` nodes found in the content (deduplicated)
- **Snippet** (string, not persisted) — a plain-text summary truncated to 64 characters at a word boundary, generated at response time for list/preview display

Tags and properties are persisted in `memo.Payload` (proto defined in `proto/store/memo.proto`); the snippet is computed on every read in `convertMemoFromStoreWithCreators()`.
