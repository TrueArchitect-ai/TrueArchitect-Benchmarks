Every distinct server-side enforcement site for memo visibility:

1. `checkMemoReadAccess` (single-memo gate for GetMemo, ListMemoComments) — `server/router/api/v1/memo_service.go`
2. `ListMemos` query-level VisibilityList / CEL filter — `server/router/api/v1/memo_service.go`
3. `ListMemoComments` query-level visibility filter — `server/router/api/v1/memo_service_comments.go`
4. `CreateMemoComment` parent-memo visibility check — `server/router/api/v1/memo_service_comments.go`
5. `UpdateMemo` comment visibility coercion to parent — `server/router/api/v1/memo_service.go`
6. `ListMemoRelations` query-level memo filter — `server/router/api/v1/memo_relation_service.go`
7. `batchConvertMemoRelations` memo filter on relation queries — `server/router/api/v1/memo_service_converter.go`
8. `ListMemoReactions` visibility check — `server/router/api/v1/reaction_service.go`
9. `UpsertMemoReaction` visibility check — `server/router/api/v1/reaction_service.go`
10. `ListMemoAttachments` visibility check — `server/router/api/v1/memo_attachment_service.go`
11. `checkAttachmentAccess` (for GetAttachment API) — `server/router/api/v1/attachment_service.go`
12. `checkAttachmentPermission` (file server endpoint) — `server/router/fileserver/fileserver.go`
13. `GetMemoByShare` share-token bypass (no visibility check, token validation instead) — `server/router/api/v1/memo_share_service.go`
14. `canReceive` SSE event delivery filter — `server/router/api/v1/sse_hub.go`
15. `canViewerAccessMemo` in notification payloads — `server/router/api/v1/user_service_notifications.go`
16. `canViewerAccessMemo` in email notifications — `server/notification/email.go`
17. `canUserAccessMentionContext` / `shouldSkipMentionInbox` mention guards — `server/router/api/v1/memo_mention_helpers.go`
18. `GetUserStats` / `ListAllUserStats` VisibilityList filtering — `server/router/api/v1/user_service_stats.go`
19. RSS feed public-only filter — `server/router/rss/rss.go`
20. Sitemap public-only filter — `server/router/frontend/frontend.go`
21. ACL config + Authorizer (instance-level anonymous access gate) — `server/router/api/v1/acl_config.go` and `server/router/api/v1/authz.go`
