**Premise correction:** This repository does not use GraphQL at all. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined as **gRPC services using Protocol Buffers (protobuf)**, with HTTP/JSON transcoding via `google.api.http` annotations. The schema definitions live in `proto/api/v1/*.proto`:

- `proto/api/v1/memo_service.proto` — Memo CRUD
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/common.proto` — Shared types

These `.proto` files are compiled (via Buf, configured in `proto/buf.yaml` / `proto/buf.gen.yaml`) into Go code under `proto/gen/api/v1/`. The server exposes them over both native gRPC and the [Connect protocol](https://connectrpc.com) (which adds HTTP/1.1+JSON support) via the handler registrations in `server/router/api/v1/connect_handler.go`. The `google.api.http` annotations on each RPC (e.g., `post: "/api/v1/memos"`, `get: "/api/v1/{name=memos/*}"`) define the RESTful HTTP mappings.
