The provider abstraction is defined in the `internal/idp` package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all identity provider implementations must return. The concrete protocol implementation that ships is in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`), which implements the OAuth2 protocol.

**Answer:** `internal/idp`; `internal/idp/oauth2`
