**Delivery function** — `Post` in `internal/webhook/webhook.go` (line 120) performs the actual outbound HTTP POST. For async use, `PostAsync` (line 184) enqueues payloads onto a buffered channel drained by background goroutines that each call `Post`. The dispatch-layer callers live in `server/router/api/v1/memo_service_webhooks.go`.

**Protection mechanism** — SSRF protection is implemented in `internal/webhook/validate.go` via two layers:

1. **Registration-time:** `ValidateURL` (validate.go:62) resolves the webhook URL's hostname and checks every result against `isReservedIP` (validate.go:44), which blocks RFC-1918 ranges, loopback, link-local (including the cloud metadata `169.254.0.0/16`), and IPv6 equivalents.
2. **Delivery-time (anti-DNS-rebinding):** `safeDialContext` in `internal/webhook/webhook.go` (line 59) is wired as a custom `DialContext` on the HTTP transport. It re-resolves the hostname at connection time and rejects the dial if any resolved IP falls in a reserved range, preventing a hostname from passing validation with a public IP but resolving to a private IP at delivery time.

**Summary format:**  
Delivery function — `Post`, `internal/webhook/webhook.go`; protection mechanism — `ValidateURL` + `isReservedIP` in `internal/webhook/validate.go` and `safeDialContext` in `internal/webhook/webhook.go`.
