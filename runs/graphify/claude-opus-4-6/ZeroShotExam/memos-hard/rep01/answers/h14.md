**Computation site:** `memopayload.RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` in `internal/markdown/markdown.go:356`. `ExtractAll` does a single AST walk over the parsed markdown content to extract all metadata in one pass.

**Triggers:**
1. **Memo creation** — called at `server/router/api/v1/memo_service.go:108` before the memo is persisted.
2. **Memo update (content field)** — called at `server/router/api/v1/memo_service.go:447`, only when `"content"` is in the update mask.
3. **Batch rebuild** — `Runner.RunOnce()` at `server/runner/memopayload/runner.go:27` iterates all memos in batches of 100 and rebuilds each payload (available for manual/migration use).

**Extracted properties** (stored in `memo.Payload`):
- **`tags`** (`[]string`) — `#tag` nodes found in the AST, deduplicated preserving case.
- **`property.title`** (`string`) — plain text of the first block-level child if it is an H1 heading.
- **`property.has_link`** (`bool`) — whether the content contains a markdown link.
- **`property.has_code`** (`bool`) — whether it contains a code block, fenced code block, or code span.
- **`property.has_task_list`** (`bool`) — whether it contains task checkboxes.
- **`property.has_incomplete_tasks`** (`bool`) — whether any task checkbox is unchecked.

Additionally, a **snippet** (plain-text preview, max 64 chars) is computed at read time (not persisted) via `GenerateSnippet()` at `internal/markdown/markdown.go:264`, called during API response conversion in `server/router/api/v1/memo_service_converter.go:76–80`.
