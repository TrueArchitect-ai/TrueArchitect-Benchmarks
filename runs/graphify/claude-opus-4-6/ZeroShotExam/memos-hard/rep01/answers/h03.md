The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` struct that all identity provider implementations must return. The concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements the OAuth2 flow (token exchange via `ExchangeToken` and user info retrieval via `UserInfo`).

**Answer:** `internal/idp`; `internal/idp/oauth2`
