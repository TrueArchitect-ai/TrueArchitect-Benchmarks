**Premise correction:** This repository (Memos) does not have a GraphQL API. There is no GraphQL schema anywhere in the codebase.

**Actual API surface:** The public API is defined as **gRPC + gRPC-Gateway (REST)** using **Protocol Buffers**. The service definitions live in `proto/api/v1/*.proto`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Code generation is driven by `proto/buf.gen.yaml`, which uses Buf plugins to produce Go gRPC stubs, Connect-RPC stubs, gRPC-Gateway reverse proxies, and an OpenAPI spec (`proto/gen/openapi.yaml`). TypeScript types are also generated into `web/src/types/proto` for the frontend. The generated Go code lives under `proto/gen/api/v1/`.
