**Premise correction:** This repository does not use GraphQL at all. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with a **gRPC + gRPC-Gateway + ConnectRPC** stack. The schema files are:

- **`proto/api/v1/*.proto`** — the protobuf service definitions that constitute the API schema. Key files include:
  - `proto/api/v1/memo_service.proto` — memo CRUD operations
  - `proto/api/v1/user_service.proto` — user management
  - `proto/api/v1/auth_service.proto` — authentication
  - `proto/api/v1/instance_service.proto` — instance configuration
  - `proto/api/v1/attachment_service.proto` — file attachments
  - `proto/api/v1/shortcut_service.proto` — shortcuts
  - `proto/api/v1/ai_service.proto` — AI features
  - `proto/api/v1/idp_service.proto` — identity providers
  - `proto/api/v1/common.proto` — shared types

- **`proto/buf.gen.yaml`** — the Buf code generation config, which generates Go gRPC stubs, gRPC-Gateway reverse proxies (for REST/JSON over HTTP), ConnectRPC handlers, an OpenAPI spec (`proto/gen/openapi.yaml`), and TypeScript types for the web frontend (`web/src/types/proto`).

- **`server/router/api/v1/`** — the Go implementation layer, where `connect_handler.go` and `connect_services.go` wire up ConnectRPC handlers that delegate to the gRPC service implementations.

The proto files define HTTP/JSON mappings via `google.api.http` annotations (e.g., `POST /api/v1/memos`), so the API is accessible as both gRPC and RESTful HTTP endpoints.
