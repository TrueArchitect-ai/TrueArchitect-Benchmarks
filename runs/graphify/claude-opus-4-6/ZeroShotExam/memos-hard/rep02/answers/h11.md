The data layer is the `store/` package (entity structs defined in `store/*.go`, with DB drivers in `store/db/`). Counting distinct Go packages outside `store/` (and `proto/`) that reference each entity type:

1. **`User`** — referenced from **~7 packages** (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)
2. **`Memo`** — referenced from **~6 packages** (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

These are defined in `store/user.go` and `store/memo.go` respectively. `User` edges ahead because it is needed in authentication (`server/auth`) and the file server (`server/router/fileserver`) — contexts where `Memo` isn't directly used.
