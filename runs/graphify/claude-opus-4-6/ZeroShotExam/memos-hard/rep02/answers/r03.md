The premise of the question is incorrect. There is no "nightly database-cleanup job" in this codebase. The `internal/scheduler/` package is a **general-purpose cron scheduling library** — it does not configure or register any actual application jobs itself.

The references to "cleanup" appear only in **documentation examples and test fixtures**, not as real scheduled jobs:

- `internal/scheduler/doc.go:15–18` shows a `"daily-cleanup"` example with schedule `"0 2 * * *"` in a doc comment illustrating how to use the API.
- `internal/scheduler/example_test.go:97–106` registers a `"cleanup"` job with schedule `"0 2 * * *"` as a test example demonstrating multiple jobs.

Neither of these is an actual database-cleanup job wired into the application. They are illustrative code samples for the scheduler library. No production code in this repository registers a database-cleanup cron job.
