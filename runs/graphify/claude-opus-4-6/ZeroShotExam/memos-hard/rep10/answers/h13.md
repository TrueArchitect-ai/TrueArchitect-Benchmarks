**`markdown.Service`** is the interface, defined in `internal/markdown/markdown.go`. It declares methods like `ExtractAll`, `RenderHTML`, `GenerateSnippet`, etc.

**impl** — The single concrete implementation is the unexported `service` struct in the same file (`internal/markdown/markdown.go`), which wraps the `goldmark` library.

**construction** — It is built by the factory function `markdown.NewService()` (also in `internal/markdown/markdown.go`). At runtime, the main construction site is `server/router/api/v1/v1.go` inside `NewAPIV1Service()`, which calls `markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())`. The resulting instance is then passed to `rss.NewRSSService()` in `server/server.go`.

**holders** — Two components hold the `markdown.Service` interface at runtime:

1. **`APIV1Service`** (`server/router/api/v1/v1.go`, field `MarkdownService`) — uses it for memo create/update payload rebuilding, webhook snippet generation, and @mention extraction.
2. **`RSSService`** (`server/router/rss/rss.go`, field `MarkdownService`) — uses it to call `RenderHTML()` for RSS feed item descriptions.

(A third struct, `memopayload.Runner` in `server/runner/memopayload/runner.go`, declares the field but its constructor is never called in production; the standalone `RebuildMemoPayload()` function receives the service as a parameter instead.)
