The following RPC handler methods can transitively cause an outbound HTTP POST to a user-configured webhook URL:

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go:157`) — calls `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go:513`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go:562`) — calls `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:119`) — calls `DispatchMemoCommentCreatedWebhook` (and also triggers `CreateMemo`'s webhook path)
5. **`SetMemoRelations`** (`server/router/api/v1/memo_relation_service.go:48`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. **`SetMemoAttachments`** (`server/router/api/v1/memo_attachment_service.go:48`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

All of these paths converge in the single function **`dispatchMemoRelatedWebhook`** at `server/router/api/v1/memo_service_webhooks.go:48`. That function looks up the memo creator's registered webhooks from the store, builds a `WebhookRequestPayload` for each, and hands them off to `webhook.PostAsync` → `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual `safeClient.Do(req)` HTTP POST to the user-configured URL.

**Handlers (≥3): `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoRelations`, `SetMemoAttachments`; convergence function — `dispatchMemoRelatedWebhook`** (`server/router/api/v1/memo_service_webhooks.go:48`).
