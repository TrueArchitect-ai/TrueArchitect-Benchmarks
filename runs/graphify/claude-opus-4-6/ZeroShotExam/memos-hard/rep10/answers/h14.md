**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdownService.ExtractAll()` implemented in `internal/markdown/markdown.go`. A separate derived field — `snippet` — is computed on-the-fly (never stored) via `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-90`, called from `convertMemoFromStoreWithCreators` in `server/router/api/v1/memo_service_converter.go:76-80`.

**Triggers:**
1. **CreateMemo** — `RebuildMemoPayload` is called before persisting (`server/router/api/v1/memo_service.go:108`).
2. **UpdateMemo** — `RebuildMemoPayload` is called when the `content` field is in the update mask (`server/router/api/v1/memo_service.go:447`).
3. **Batch rebuild** — `Runner.RunOnce()` iterates all memos in batches of 100 and rebuilds each payload (`server/runner/memopayload/runner.go:27-72`), for migration/repair use.
4. **Every API read** — the `snippet` is recomputed each time a memo is returned through `convertMemoFromStoreWithCreators`.

**Extracted properties** (persisted in `MemoPayload`, defined in `proto/store/memo.proto:7-22`):
- **`tags`** (`[]string`) — all `#tag` occurrences parsed from content, deduplicated.
- **`property.has_link`** (`bool`) — whether the content contains any markdown link.
- **`property.has_task_list`** (`bool`) — whether the content contains any GFM task checkbox.
- **`property.has_code`** (`bool`) — whether the content contains any code block or inline code span.
- **`property.has_incomplete_tasks`** (`bool`) — whether any unchecked `[ ]` task exists.
- **`property.title`** (`string`) — plain text of the first H1 heading, if it is the first block-level element.
- **`snippet`** (`string`, not persisted, `OUTPUT_ONLY`) — a plain-text summary truncated to 64 characters at a word boundary, computed by `GenerateSnippet` in `internal/markdown/markdown.go`.
