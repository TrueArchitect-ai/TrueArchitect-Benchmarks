The premise of this question is incorrect. This repository does **not** have any per-user API rate-limiting middleware. There is no rate-limiting middleware registered anywhere in the codebase.

The server (`server/server.go`) registers only a `middleware.Recover()` middleware via the Echo framework — no rate limiter is configured. The `go.mod` file contains no rate-limiting dependencies (e.g., `golang.org/x/time/rate` or any third-party rate-limiting package). The only mention of rate limiting in the entire repository is in `internal/email/README.md`, which is a documentation example suggesting a *future* implementation of email sending rate limits — it is not implemented code, nor is it API request rate limiting.
