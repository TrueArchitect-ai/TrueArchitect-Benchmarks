h02.

delivery function — `Post` in `internal/webhook/webhook.go`; protection mechanism — `ValidateURL` and `isReservedIP` in `internal/webhook/validate.go`

The `Post` function (line ~120 in `internal/webhook/webhook.go`) builds and executes the outbound HTTP POST, including optional HMAC-SHA256 signing. An async variant `PostAsync` enqueues payloads onto a buffered channel drained by background goroutines that call `Post`.

SSRF protection is two-layered, both using a shared `reservedCIDRs` list (loopback, RFC-1918, link-local, IPv6 ULA/link-local) and the `isReservedIP` function in `internal/webhook/validate.go`:

1. **Registration-time** — `ValidateURL` (`internal/webhook/validate.go`) resolves the hostname and rejects any URL whose IPs fall in reserved ranges before the webhook is saved.
2. **Dial-time** — `safeDialContext` (`internal/webhook/webhook.go`) re-resolves the hostname at connection time inside a custom `http.Transport`, blocking private IPs again to defeat DNS rebinding attacks.
