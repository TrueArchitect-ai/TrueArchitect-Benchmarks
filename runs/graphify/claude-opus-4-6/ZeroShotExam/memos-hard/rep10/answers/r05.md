The premise of the question is incorrect — there is no GraphQL schema in this repository. Memos does not use GraphQL for its public API.

The actual API surface is **gRPC + REST (via grpc-gateway)**, defined as **Protocol Buffer (`.proto`) files** in `proto/api/v1/`. The key service definitions are:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`

These `.proto` files are compiled (via `buf`, configured in `proto/buf.gen.yaml`) into:

1. **gRPC stubs** — Go code in `proto/gen/api/v1/*.pb.go` and `*_grpc.pb.go`
2. **REST/HTTP gateway handlers** — `*_grpc.pb.gw.go` files (grpc-gateway reverse proxy)
3. **OpenAPI spec** — `proto/gen/openapi.yaml`

The README confirms this: *"MIT-licensed with full REST and gRPC APIs for integration."* No GraphQL dependency exists anywhere in the codebase.
