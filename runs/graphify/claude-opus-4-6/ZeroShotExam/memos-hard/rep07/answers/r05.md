**Premise correction:** This repository (usememos/memos) does not have a GraphQL API. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined as **gRPC services using Protocol Buffers**, with the schema files located in `proto/api/v1/`. The key `.proto` files are:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These protobuf definitions are used to generate multiple outputs via Buf (`proto/buf.gen.yaml`):

1. **Go gRPC server/client stubs** (protocolbuffers/go, grpc/go)
2. **ConnectRPC handlers** (connectrpc/go)
3. **gRPC-Gateway REST proxies** (grpc-ecosystem/gateway) — exposing the API as RESTful HTTP endpoints under `/api/v1/`
4. **OpenAPI 3.0 spec** — auto-generated at `proto/gen/openapi.yaml`
5. **TypeScript types** — generated into `web/src/types/proto` for the frontend

The REST/HTTP API is the primary public-facing surface, served through gRPC-Gateway, with the OpenAPI spec documenting it. No GraphQL layer exists.
