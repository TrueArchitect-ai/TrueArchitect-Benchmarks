The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/doc.go`) is a general-purpose cron scheduling library — it does not define any specific jobs itself. The example code in `internal/scheduler/example_test.go` shows a `"cleanup"` job scheduled at `"0 2 * * *"` (2 AM daily) and a `"daily-cleanup"` example in `doc.go` also at `"0 2 * * *"`, but these are illustrative examples in test/doc files, not actual scheduled jobs wired into the application. No production code in this repository registers a "database-cleanup" job with the scheduler.
