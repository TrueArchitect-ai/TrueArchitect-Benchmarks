Every distinct server-side enforcement site for memo visibility:

1. **GetMemo / checkMemoReadAccess (single-memo guard)** — `server/router/api/v1/memo_service.go`
2. **ListMemos (list-level visibility filtering)** — `server/router/api/v1/memo_service.go`
3. **ListMemoComments / CreateMemoComment (comment access)** — `server/router/api/v1/memo_service_comments.go`
4. **ListMemoRelations (relation filtering via MemoFilter)** — `server/router/api/v1/memo_relation_service.go`
5. **ListMemoReactions / UpsertMemoReaction (reaction access)** — `server/router/api/v1/reaction_service.go`
6. **GetAttachment / checkAttachmentAccess (API-level attachment access)** — `server/router/api/v1/attachment_service.go`
7. **File server / checkAttachmentPermission (HTTP binary serving)** — `server/router/fileserver/fileserver.go`
8. **SSE hub / canReceive (server-sent event delivery filtering)** — `server/router/api/v1/sse_hub.go`
9. **RSS feeds (explore + per-user, PUBLIC-only filter)** — `server/router/rss/rss.go`
10. **GetUserStats / ListAllUserStats (stats visibility scoping)** — `server/router/api/v1/user_service_stats.go`
11. **Mention/inbox notification guard (shouldSkipMentionInbox / canUserAccessMentionContext)** — `server/router/api/v1/memo_mention_helpers.go`
12. **Email notification guard (canViewerAccessMemo)** — `server/notification/email.go`
13. **Store-level SQL WHERE clause (VisibilityList / MemoFilter compiled to SQL)** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
