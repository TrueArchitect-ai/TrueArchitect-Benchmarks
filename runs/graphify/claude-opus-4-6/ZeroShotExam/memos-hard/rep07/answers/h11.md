The persistent entity types are defined in the `store/` package (the data layer), in files like `store/user.go`, `store/memo.go`, `store/attachment.go`, etc.

**1st: `User`** — referenced from ~7 packages outside `store/`: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.

**2nd: `Memo`** — referenced from ~6 packages outside `store/`: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.
