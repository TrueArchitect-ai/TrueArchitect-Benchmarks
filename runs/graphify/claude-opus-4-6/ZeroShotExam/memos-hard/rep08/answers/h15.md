Every distinct server-side enforcement site for memo visibility:

1. **`checkMemoReadAccess` (per-memo gate)** — `server/router/api/v1/memo_service.go`
2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go`
3. **`ListMemoComments` / `CreateMemoComment` visibility checks** — `server/router/api/v1/memo_service_comments.go`
4. **`ListMemoRelations` visibility filter** — `server/router/api/v1/memo_relation_service.go`
5. **Reaction endpoints (`ListMemoReactions`, `UpsertMemoReaction`)** — `server/router/api/v1/reaction_service.go`
6. **`checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go`
7. **`ListMemoAttachments` visibility check** — `server/router/api/v1/memo_attachment_service.go`
8. **`checkAttachmentPermission` (HTTP file serving)** — `server/router/fileserver/fileserver.go`
9. **SSE hub `canReceive`** — `server/router/api/v1/sse_hub.go`
10. **User stats endpoints (`ListAllUserStats`, `GetUserStats`)** — `server/router/api/v1/user_service_stats.go`
11. **RSS feed generation** — `server/router/rss/rss.go`
12. **Sitemap generation** — `server/router/frontend/frontend.go`
13. **Notification payloads `canViewerAccessMemo`** — `server/router/api/v1/user_service_notifications.go`
14. **Email notification `canViewerAccessMemo`** — `server/notification/email.go`
15. **Mention notification `canUserAccessMentionContext`** — `server/router/api/v1/memo_mention_helpers.go`
16. **Share link bypass (`GetMemoByShare`)** — `server/router/api/v1/memo_share_service.go`
17. **Private instance gate (`CheckAccess`)** — `server/router/api/v1/authz.go`
18. **Database-level `VisibilityList` SQL filter** — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`
