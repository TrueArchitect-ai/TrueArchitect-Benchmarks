The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook` (and also triggers `DispatchMemoCreatedWebhook` via its internal `CreateMemo` call)
5. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

**Convergence function:** `dispatchMemoRelatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:48`

This is where all paths (created/updated/deleted) converge. It resolves the memo creator, fetches their webhooks via `s.Store.GetUserWebhooks()`, and calls `webhook.PostAsync()` for each, which enqueues the payload onto an async channel drained by workers that call `webhook.Post()` (`internal/webhook/webhook.go:120`), which performs the actual `HTTP POST` to the user-configured URL using an SSRF-safe `http.Client`.
