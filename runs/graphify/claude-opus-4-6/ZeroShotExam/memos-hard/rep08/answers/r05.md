**Premise correction:** This repository does not have a GraphQL API. The question's premise is incorrect.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (REST/HTTP transcoding), not GraphQL. The schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto` (shared types)

These proto definitions are compiled (via `buf` — see `proto/buf.gen.yaml`) into:

- **gRPC Go stubs** (`proto/gen/api/v1/*_grpc.pb.go`)
- **gRPC-Gateway reverse proxies** (`proto/gen/api/v1/*.pb.gw.go`) that expose the gRPC services as a RESTful JSON API
- **An OpenAPI spec** (`proto/gen/openapi.yaml`)

The Go server handlers that implement these services live in `server/router/api/v1/`.
