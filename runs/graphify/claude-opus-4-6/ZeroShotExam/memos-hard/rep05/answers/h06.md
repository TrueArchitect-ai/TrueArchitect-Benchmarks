The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` → `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` → `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` → two paths: internally calls `CreateMemo` (triggering `memos.memo.created`) and directly calls `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:16` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:16` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

**Convergence function: `webhook.Post`** — `internal/webhook/webhook.go:120`

All paths funnel through `webhook.PostAsync` (line 184), which enqueues onto a buffered channel drained by goroutines that each call `Post`. `Post` is the single point where the outbound `http.NewRequest("POST", requestPayload.URL, ...)` is constructed (line 126) and executed via `safeClient.Do(req)` (line 152). Every webhook delivery in the system passes through this function before any HTTP request leaves the process.
