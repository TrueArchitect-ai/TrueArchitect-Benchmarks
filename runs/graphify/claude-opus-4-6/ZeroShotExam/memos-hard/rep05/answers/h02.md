**Delivery function** — `Post` in `internal/webhook/webhook.go` (with `PostAsync` enqueueing into a buffered channel for background dispatch by worker goroutines that call `Post`).

**Protection mechanism** — SSRF protection lives in `internal/webhook/validate.go` and `internal/webhook/webhook.go`, implemented as two complementary layers:

1. **Input-time validation:** `ValidateURL` (`internal/webhook/validate.go`) resolves the webhook URL's hostname and checks every resolved IP against `isReservedIP`, which matches against a list of reserved CIDRs (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, IPv6 equivalents). This runs when a webhook is created or updated.

2. **Dial-time enforcement:** `safeDialContext` (`internal/webhook/webhook.go`) is wired into the HTTP transport's `DialContext`. It resolves the hostname at connect time and rejects any connection whose resolved IP falls in the same reserved ranges — defeating DNS rebinding attacks where a name resolves to a safe IP at validation time but a private IP at request time.

Both layers share the `isReservedIP` function (`internal/webhook/validate.go`), and an `AllowPrivateIPs` escape hatch exists for self-hosted deployments that intentionally target local-network services.
