The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in this codebase's cron scheduler. The scheduler package (`internal/scheduler/`) is a general-purpose cron scheduling library with no pre-configured jobs. The only cleanup-related references are illustrative examples in documentation and tests:

- `internal/scheduler/doc.go:15` — a doc comment example showing a `"daily-cleanup"` job with schedule `"0 2 * * *"` (2 AM daily)
- `internal/scheduler/example_test.go:98-106` — a test example showing a `"cleanup"` job with schedule `"0 2 * * *"` described as "Cleanup old data every night at 2 AM"

These are documentation/test examples only, not actual scheduled jobs. No production code registers a "database-cleanup" or any other cleanup job with the scheduler.
