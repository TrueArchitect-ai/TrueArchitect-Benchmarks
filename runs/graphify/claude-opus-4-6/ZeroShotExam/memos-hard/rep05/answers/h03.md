The package `internal/idp` defines the provider abstraction — it declares the shared `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that every identity-provider backend must return. The concrete protocol implementation that ships is in `internal/idp/oauth2`, which implements the OAuth2 token exchange and user-info retrieval (`internal/idp/oauth2/oauth2.go`).

**Answer:** `internal/idp`; `internal/idp/oauth2`
