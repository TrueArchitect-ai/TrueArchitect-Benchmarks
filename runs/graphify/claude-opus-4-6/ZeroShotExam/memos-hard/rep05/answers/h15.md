Every distinct server-side enforcement site for memo visibility:

1. **`checkMemoReadAccess` (single-memo gate)** — `server/router/api/v1/memo_service.go` (used by `GetMemo`, `ListMemoComments`)
2. **`ListMemos` query-level visibility filter** — `server/router/api/v1/memo_service.go`
3. **`ListMemoComments` comment visibility filter** — `server/router/api/v1/memo_service_comments.go`
4. **`CreateMemoComment` private-parent check** — `server/router/api/v1/memo_service_comments.go`
5. **`UpdateMemo` comment visibility override** — `server/router/api/v1/memo_service.go`
6. **`ListMemoReactions` visibility check** — `server/router/api/v1/reaction_service.go`
7. **`UpsertMemoReaction` visibility check** — `server/router/api/v1/reaction_service.go`
8. **`ListMemoAttachments` visibility check** — `server/router/api/v1/memo_attachment_service.go`
9. **`checkAttachmentAccess` (linked-attachment gate)** — `server/router/api/v1/attachment_service.go`
10. **`checkAttachmentPermission` (HTTP file server)** — `server/router/fileserver/fileserver.go`
11. **`ListMemoRelations` visibility filter** — `server/router/api/v1/memo_relation_service.go`
12. **`batchConvertMemoRelations` visibility filter** — `server/router/api/v1/memo_service_converter.go`
13. **SSE event delivery (`canReceive`)** — `server/router/api/v1/sse_hub.go`
14. **`GetUserStats` / `ListAllUserStats` visibility filter** — `server/router/api/v1/user_service_stats.go`
15. **RSS feed (public only)** — `server/router/rss/rss.go`
16. **Sitemap (public only)** — `server/router/frontend/frontend.go`
17. **`GetMemoByShare` share-token bypass** — `server/router/api/v1/memo_share_service.go`
18. **Mention notification gating (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go`
19. **Notification payload gating (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go`
20. **Email notification gating (`canViewerAccessMemo`)** — `server/notification/email.go`
21. **ACL config (public method list)** — `server/router/api/v1/acl_config.go`
22. **SQL-level `VisibilityList` / `MemoFilter` enforcement** — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`
