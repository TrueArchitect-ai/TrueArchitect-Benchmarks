**Premise correction:** This repository does not have a GraphQL API. There is no GraphQL schema anywhere in the codebase.

**Actual API surface:** The public API is defined as **gRPC services using Protocol Buffers**, with schemas in `proto/api/v1/*.proto`. The service definitions include:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/common.proto`

These `.proto` files are compiled via `buf` (`proto/buf.gen.yaml`) into multiple targets: native Go gRPC stubs, **ConnectRPC** handlers (for browser-compatible HTTP), **gRPC-Gateway** for REST-style HTTP/JSON access, OpenAPI specs (via `google-gnostic-openapi`), and TypeScript types for the web frontend. The server exposes these through both a gRPC-Gateway (`server/server.go:88`) and ConnectRPC service handlers (`server/router/api/v1/connect_handler.go`).
