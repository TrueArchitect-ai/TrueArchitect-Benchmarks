**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` defined in `internal/markdown/markdown.go:356`. The snippet is computed separately by `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83`, which calls `markdownService.GenerateSnippet()` (`internal/markdown/markdown.go:264`).

**Triggers:** Recomputation is triggered on **memo create** (`server/router/api/v1/memo_service.go:108`) and **memo content update** (`server/router/api/v1/memo_service.go:447`) — both call `RebuildMemoPayload`. A batch backfill path (`RunOnce` at `server/runner/memopayload/runner.go:27`) rebuilds all memos. The `snippet` is computed on-the-fly at API response time (in `memo_service_converter.go:76`) rather than persisted.

**Extracted properties:** `ExtractAll` walks the markdown AST in a single pass and extracts:
- **`tags`** (`[]string`) — all `#tag` nodes, deduplicated and case-preserving
- **`property.Title`** (`string`) — plain text of the first H1 heading, only if it is the first block-level child of the document
- **`property.HasLink`** (`bool`) — whether any markdown link node exists
- **`property.HasCode`** (`bool`) — whether any code block, fenced code block, or code span exists
- **`property.HasTaskList`** (`bool`) — whether any GFM task checkbox exists
- **`property.HasIncompleteTasks`** (`bool`) — whether any unchecked task checkbox exists

Additionally, `GenerateSnippet` produces a plain-text **snippet** (max 64 characters, truncated at word boundary with ` ...`) used in list views, relation cards, and notifications — but this is computed at response time, not persisted in the payload.
