The **`internal/idp`** package defines the provider abstraction — it declares the shared `IdentityProviderUserInfo` struct (`internal/idp/idp.go`) that every identity-provider implementation must return.

The **`internal/idp/oauth2`** package ships as the sole concrete protocol implementation (`internal/idp/oauth2/oauth2.go`), providing `ExchangeToken` and `UserInfo` methods backed by OAuth2.

**Answer:** `internal/idp`; `internal/idp/oauth2`
