Every distinct server-side enforcement site for memo visibility:

1. **GetMemo / single-memo read gate** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`: archived→creator-only, private→creator-only, protected→authenticated, public→all)
2. **ListMemos query-level filter** — `server/router/api/v1/memo_service.go` (injects `VisibilityList` / CEL filter so unauthenticated sees only PUBLIC, other-user sees PUBLIC+PROTECTED, self sees all)
3. **ListMemoComments** — `server/router/api/v1/memo_service_comments.go` (calls `checkMemoReadAccess` on parent, then applies visibility filter on comment relations)
4. **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (private memos: only creator/admin may comment; comment visibility forced to match parent)
5. **ListMemoRelations** — `server/router/api/v1/memo_relation_service.go` (visibility filter on both source and related memo via `MemoFilter`)
6. **batchConvertMemoRelations** — `server/router/api/v1/memo_service_converter.go` (constructs per-user visibility filter for relation subqueries)
7. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (inline visibility check: non-public→authenticated, private→creator/admin)
8. **GetAttachment (gRPC)** — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess`: follows linked memo's visibility)
9. **File server attachment access** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission`: HTTP-layer memo visibility gate with share-token fallback)
10. **ListMemoReactions** — `server/router/api/v1/reaction_service.go` (non-public→authenticated, private→creator/admin)
11. **UpsertMemoReaction** — `server/router/api/v1/reaction_service.go` (private→creator/admin only)
12. **SSE event delivery** — `server/router/api/v1/sse_hub.go` (`canReceive`: private events delivered only to creator/admin clients)
13. **GetUserStats** — `server/router/api/v1/user_service_stats.go` (visibility filter on memo counts per user)
14. **ListAllUserStats** — `server/router/api/v1/user_service_stats.go` (visibility filter on aggregated stats)
15. **GetMemoByShare (share-token bypass)** — `server/router/api/v1/memo_share_service.go` (valid share token bypasses normal visibility; archived still hidden)
16. **Database query builder** — `store/db/sqlite/memo.go` (and `postgres/`, `mysql/` equivalents): translates `VisibilityList` to SQL `WHERE` clause
17. **Database relation query** — `store/db/sqlite/memo_relation.go` (and equivalents): `MemoFilter` compiled to subquery on `memo_id`/`related_memo_id`
18. **Gateway-level auth** — `server/router/api/v1/authz.go` (`CheckAccess`: rejects anonymous callers for non-public methods)
19. **ACL config** — `server/router/api/v1/acl_config.go` (defines which memo endpoints are publicly accessible vs require auth)
