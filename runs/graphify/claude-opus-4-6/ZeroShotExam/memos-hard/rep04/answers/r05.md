**Premise correction:** This repository does not have a GraphQL API. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL. The `.proto` service definitions live in `proto/api/v1/` — e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, and `common.proto`.

These protobuf definitions are used to generate:

1. **gRPC-Gateway** handlers (REST over HTTP, served at `/api/v1/*`) — registered via `grpc-gateway/v2` in `server/router/api/v1/v1.go`.
2. **ConnectRPC** handlers (for browser clients, served at `/memos.api.v1.*`) — registered via `connectrpc.com/connect` in the same file.

The generated Go code from these proto files is output to `proto/gen/api/v1/` and imported as `v1pb`. The buf toolchain (`proto/buf.yaml`, `proto/buf.gen.yaml`) manages code generation.
