The premise of the question is incorrect. This repository does not contain any per-user API rate-limiting middleware. There is no rate limiter, throttling middleware, or request-limit configuration anywhere in the codebase.

The server setup (`server/server.go`) registers CORS middleware and authentication/authorization middleware (`server/router/api/v1/v1.go`, `server/router/api/v1/authz.go`), but no rate-limiting middleware exists. The only concurrency-limiting mechanism present is a thumbnail generation semaphore (`server/router/api/v1/v1.go:39`), which limits concurrent thumbnail operations to prevent memory exhaustion — this is not a per-user API rate limiter.
