The outbound delivery executes in the **`Post`** function at **`internal/webhook/webhook.go`** (lines ~120–179), which marshals the payload, builds the HTTP request, signs it, and sends it via a safe HTTP client. Async callers go through `PostAsync` (same file, lines ~183–196), which queues work onto a buffered channel drained by background goroutines.

SSRF protection is a two-layer defence, both using the reserved-CIDR list in **`internal/webhook/validate.go`**:

1. **Registration-time URL validation** — `ValidateURL` in **`internal/webhook/validate.go`** (lines ~56–83) resolves the hostname and rejects any URL whose IPs fall in private/reserved CIDRs (loopback, RFC-1918, link-local/IMDS, IPv6 ULA/link-local, defined at lines ~14–23).
2. **Dial-time blocking** — `safeDialContext` in **`internal/webhook/webhook.go`** (lines ~57–77) re-resolves the hostname at connection time and checks the IPs against the same `isReservedIP` function, defeating DNS-rebinding attacks that could pass the registration check but resolve differently later.

**Delivery function** — `Post` in `internal/webhook/webhook.go`; **protection mechanism** — `isReservedIP`/`ValidateURL` in `internal/webhook/validate.go` (+ `safeDialContext` in `internal/webhook/webhook.go`).
