The RPC handler methods on `APIV1Service` that can transitively fire outbound HTTP requests to user-configured webhook URLs are:

1. **`CreateMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.created` via `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.updated` via `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** (`server/router/api/v1/memo_service.go`) — dispatches `memos.memo.deleted` via `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go`) — dispatches both `memos.memo.created` (via internal `CreateMemo` call) and `memos.memo.comment.created` via `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoRelations`** (`server/router/api/v1/memo_relation_service.go`) — dispatches `memos.memo.updated` via `dispatchMemoUpdatedSideEffects`
6. **`SetMemoAttachments`** (`server/router/api/v1/memo_attachment_service.go`) — dispatches `memos.memo.updated` via `dispatchMemoUpdatedSideEffects`

**Convergence function — `webhook.Post`** in `internal/webhook/webhook.go`

All paths converge on this single function before delivery. The call chain is: each handler calls a dispatch helper in `server/router/api/v1/memo_service_webhooks.go` (e.g., `dispatchMemoRelatedWebhook`), which calls `webhook.PostAsync`. `PostAsync` enqueues the payload onto an async channel (`asyncPostQueue`), which is drained by worker goroutines that each call `webhook.Post` — the sole function that serializes the payload, constructs the HTTP request to the user-configured URL, optionally signs it (HMAC-SHA256), and executes it via a safe HTTP client with SSRF protections.
