The **S3 presign `Runner`** (`server/runner/s3presign/runner.go`) keeps S3 attachment presigned URLs from going stale. It iterates over all S3-stored attachments in batches, checks whether each presigned URL will remain valid for the next 4 days (URLs are generated with a 5-day expiry), and regenerates any that are close to expiration.

**Schedule:** every **12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`), via a `time.Ticker`. An immediate one-shot run also fires at startup.

**Wiring into server startup:** `server/server.go:153` — the method `startBackgroundRunners` instantiates the runner at line 162 (`s3presign.NewRunner(s.Store)`), calls `RunOnce` at line 163, and launches the continuous ticker loop in a goroutine at line 169 (`s3presignRunner.Run(s3Context)`).
