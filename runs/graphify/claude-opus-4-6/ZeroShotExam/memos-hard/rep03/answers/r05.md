**Premise correction:** This repository (Memos) does not have a GraphQL API. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined as **gRPC services with Protocol Buffers**, with an HTTP/JSON layer generated via **grpc-gateway**. The schema lives in `.proto` files under `proto/api/v1/`:

- `memo_service.proto` — Memo CRUD
- `user_service.proto` — User management
- `auth_service.proto` — Authentication
- `attachment_service.proto` — Attachments
- `instance_service.proto` — Instance settings
- `idp_service.proto` — Identity providers
- `shortcut_service.proto` — Shortcuts
- `ai_service.proto` — AI features
- `common.proto` — Shared types

Each service uses `google.api.http` annotations to expose RESTful HTTP endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). Code generation is driven by `proto/buf.gen.yaml`, which produces Go gRPC/Connect stubs, grpc-gateway reverse proxies, an OpenAPI spec (`proto/gen/openapi.yaml`), and TypeScript types for the web frontend.
