The premise of this question is incorrect. This repository (usememos/memos) does not contain any per-user API rate-limiting middleware. There is no rate limiter registered in the server setup (`server/server.go`), no rate-limiting library in `go.mod`, and no rate-limit-related code anywhere in the codebase. The only middleware registered on the Echo server is `middleware.Recover()` (for panic recovery) and a custom CORS middleware (`server/cors.go`). Authentication and authorization exist (`server/auth/`, `server/router/api/v1/authz.go`), but there is no request-rate throttling or per-user request limits implemented.
