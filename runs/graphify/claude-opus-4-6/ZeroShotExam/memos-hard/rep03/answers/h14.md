The derived metadata is computed primarily in two places: **`server/runner/memopayload/runner.go`** (`RebuildMemoPayload`) for persisted payload properties, and **`server/router/api/v1/memo_service_converter.go`** / **`memo_service_webhooks.go`** for the on-the-fly snippet.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go` calls `MarkdownService.ExtractAll()` (defined in `internal/markdown/markdown.go`) to parse the memo's markdown content into an AST and walk it to extract metadata. The snippet is computed separately via `GenerateSnippet()` in `internal/markdown/markdown.go`, invoked at API response time through `convertMemoFromStore` in `server/router/api/v1/memo_service_converter.go`.

**Triggers for recomputation:**
- **CreateMemo** — `RebuildMemoPayload` is called before persisting (`memo_service.go`, ~line 108).
- **UpdateMemo** — `RebuildMemoPayload` is called only when `"content"` is in the `UpdateMask.Paths` (`memo_service.go`, ~line 447); other field updates (visibility, pinned, etc.) do not trigger it.
- **Every API read** — The `snippet` field is computed on-the-fly each time a memo is serialized for an API response.
- **Batch rebuild** — `RunOnce` in `memopayload/runner.go` iterates all memos in batches of 100 and rebuilds each payload (for migrations/repair).

**Extracted properties (persisted in `MemoPayload`):**
- **`property.title`** (`string`) — plain text of the first block element if it is an H1 heading; empty otherwise.
- **`property.has_link`** (`bool`) — whether any link node exists in the AST.
- **`property.has_code`** (`bool`) — whether any code block, fenced code block, or code span exists.
- **`property.has_task_list`** (`bool`) — whether any GFM task checkbox exists.
- **`property.has_incomplete_tasks`** (`bool`) — whether any unchecked task checkbox exists.
- **`tags`** (`[]string`) — all `#tag` nodes (excluding those inside links/images), deduplicated.

**Extracted on-the-fly:**
- **`snippet`** (`string`) — plain-text extraction from the markdown AST (code blocks stripped, inline code kept), truncated at 64 characters on a word boundary with `" ..."` appended if truncated. Marked `OUTPUT_ONLY` in the API proto (`proto/api/v1/memo_service.proto:265`).
