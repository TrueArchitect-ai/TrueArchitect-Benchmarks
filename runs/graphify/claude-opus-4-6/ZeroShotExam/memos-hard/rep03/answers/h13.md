**`*service`** (wrapping goldmark) — **`NewAPIV1Service`** — **`APIV1Service`, `Runner`, `RSSService`**

The interface is `markdown.Service` defined in `internal/markdown/markdown.go` with eight methods (`ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, `RenameTag`).

- **Concrete implementation:** A single unexported `service` struct in the same file (`internal/markdown/markdown.go`), which wraps a `goldmark.Markdown` instance. It is the only runtime implementation.

- **Construction:** `markdown.NewService(opts ...Option)` is called in production inside `apiv1.NewAPIV1Service()` at `server/router/api/v1/v1.go:48-51`, with both `WithTagExtension()` and `WithMentionExtension()` enabled. The resulting instance is then shared onward — `server/server.go:85` passes `apiV1Service.MarkdownService` to `rss.NewRSSService(...)`.

- **Holders of the interface:**
  - `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — used for memo creation/update payload rebuilds, mention extraction, and webhook snippet generation.
  - `Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) — background batch rebuild of memo payloads.
  - `RSSService.MarkdownService` (`server/router/rss/rss.go:45`) — converts memo markdown to HTML for RSS feed items.
