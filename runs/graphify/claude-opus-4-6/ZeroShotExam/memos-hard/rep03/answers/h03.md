The provider abstraction is defined in `internal/idp` (which declares the shared `IdentityProviderUserInfo` struct in `internal/idp/idp.go` that all concrete providers must return), and the concrete protocol implementation that ships is `internal/idp/oauth2` (an OAuth2 implementation in `internal/idp/oauth2/oauth2.go`).
