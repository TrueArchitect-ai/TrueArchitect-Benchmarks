Here are all distinct memo visibility enforcement sites on the server:

1. **`checkMemoReadAccess` (point access check for single memo)** — `server/router/api/v1/memo_service.go`
2. **`ListMemos` query-time visibility filtering** — `server/router/api/v1/memo_service.go`
3. **`ListMemoComments` visibility filtering** — `server/router/api/v1/memo_service_comments.go`
4. **`CreateMemoComment` parent memo visibility check** — `server/router/api/v1/memo_service_comments.go`
5. **`ListMemoRelations` visibility filtering** — `server/router/api/v1/memo_relation_service.go`
6. **`batchConvertMemoRelations` visibility filtering** — `server/router/api/v1/memo_service_converter.go`
7. **`ListMemoReactions` / `UpsertMemoReaction` visibility checks** — `server/router/api/v1/reaction_service.go`
8. **`ListMemoAttachments` visibility check** — `server/router/api/v1/memo_attachment_service.go`
9. **`checkAttachmentAccess` (gRPC attachment access)** — `server/router/api/v1/attachment_service.go`
10. **`checkAttachmentPermission` (HTTP file server)** — `server/router/fileserver/fileserver.go`
11. **`GetMemoByShare` (share token access)** — `server/router/api/v1/memo_share_service.go`
12. **SSE `canReceive` (real-time event delivery)** — `server/router/api/v1/sse_hub.go`
13. **`GetUserStats` visibility filtering** — `server/router/api/v1/user_service_stats.go`
14. **`ListAllUserStats` visibility filtering** — `server/router/api/v1/user_service_stats.go`
15. **`canViewerAccessMemo` (notification payload suppression)** — `server/router/api/v1/user_service_notifications.go`
16. **`canViewerAccessMemo` (email notification suppression)** — `server/notification/email.go`
17. **`canUserAccessMentionContext` (mention notification guard)** — `server/router/api/v1/memo_mention_helpers.go`
18. **RSS feed public-only filtering** — `server/router/rss/rss.go`
19. **Sitemap public-only filtering** — `server/router/frontend/frontend.go`
20. **Method-level ACL gate (anonymous method allowlist)** — `server/router/api/v1/acl_config.go`
21. **Store-layer SQL `VisibilityList` / CEL filter enforcement** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
