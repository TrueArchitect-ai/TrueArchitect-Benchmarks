**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll()` (`internal/markdown/markdown.go:356-422`) — a single-pass goldmark AST walk over the memo's markdown content. Additionally, the `snippet` is computed on-the-fly at read time via `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83-90`), which calls `markdownService.GenerateSnippet(content, 64)`.

**Triggers:** (1) Memo creation (`server/router/api/v1/memo_service.go:108`), (2) memo content update (`server/router/api/v1/memo_service.go:447`), and (3) batch rebuild of all memos via `Runner.RunOnce()` (`server/runner/memopayload/runner.go:27-72`). The snippet is recomputed on every API read (in `convertMemoFromStoreWithCreators` at `server/router/api/v1/memo_service_converter.go:76`).

**Extracted properties** (persisted in `MemoPayload`, defined in `proto/store/memo.proto:15-22`):
- **`tags`** — all `#tag` nodes found in the content (deduplicated, case-preserved)
- **`has_link`** — whether the content contains markdown links
- **`has_task_list`** — whether the content has GFM task checkboxes
- **`has_code`** — whether the content has code blocks, fenced code blocks, or code spans
- **`has_incomplete_tasks`** — whether any task checkbox is unchecked
- **`title`** — text of the first H1 heading, if the first block-level element is one
- **`snippet`** (ephemeral, not persisted) — a plain-text summary truncated to 64 characters at a word boundary, generated from the AST with code blocks stripped
