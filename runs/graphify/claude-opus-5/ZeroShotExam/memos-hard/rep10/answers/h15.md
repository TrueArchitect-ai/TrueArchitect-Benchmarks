Memo visibility is enforced in many places — there is no single chokepoint. The distinct enforcement sites:

**Core memo read gate (gRPC/Connect API)**
- `checkMemoReadAccess` — the shared single-memo gate (public → open; protected → any authenticated user; private → creator only; archived → creator only) — `server/router/api/v1/memo_service.go:39-68`, called by `GetMemo` (`:356`, and again for the parent memo of a comment at `:367`) and by `ListMemoComments` (`server/router/api/v1/memo_service_comments.go:148`)
- ListMemos query-level filter (anonymous → `VisibilityList = [PUBLIC]`; authed → CEL filter `creator_id == N || visibility in ["PUBLIC","PROTECTED"]`; archived → creator only) — `server/router/api/v1/memo_service.go:188-227`
- CreateMemoComment guard on a private parent memo — `server/router/api/v1/memo_service_comments.go:41`

**Related/derived memo listings (separate filters, not the gate above)**
- Comment listing filter applied to relations — `server/router/api/v1/memo_service_comments.go:155-161`
- Batch relation conversion filter (used by ListMemos and share links) — `server/router/api/v1/memo_service_converter.go:180-186`
- ListMemoRelations filter — `server/router/api/v1/memo_relation_service.go:105-112`
- User stats aggregation filters — `server/router/api/v1/user_service_stats.go:76-92` and `:217-221`

**Attachments**
- Attachment access check (API) — `server/router/api/v1/attachment_service.go:437-454`
- ListMemoAttachments check — `server/router/api/v1/memo_attachment_service.go:213-226`
- Raw blob/thumbnail HTTP serving, including the anonymous-instance rule and the `share_token` bypass — `server/router/fileserver/fileserver.go:650-704`

**Reactions**
- Reaction read/upsert visibility check — `server/router/api/v1/reaction_service.go:29-41` and `:83`

**Realtime (SSE) fan-out**
- Per-client delivery filter `canReceive` (private events only to creator or admin) — `server/router/api/v1/sse_hub.go:134-144`, with the event's visibility/creator stamped in `server/router/api/v1/sse_event_helpers.go:11-38`

**Unauthenticated public surfaces**
- RSS feeds restricted to `VisibilityList = [PUBLIC]` — `server/router/rss/rss.go:90` and `:141`
- Sitemap restricted to public memos — `server/router/frontend/frontend.go:143-155`

**Share links (deliberate bypass, token is the authz)**
- `GetMemoByShare` resolves a token and returns the memo without a visibility check (only archived/missing are rejected); creation/listing/deletion of shares is creator-or-admin only — `server/router/api/v1/memo_share_service.go:23-207`

**Notification/mention content redaction**
- Mention notifications skipped for private memos not owned by the target — `server/router/api/v1/memo_mention_helpers.go:62-68`
- Notification payload content withheld/limited by visibility — `server/router/api/v1/user_service_notifications.go:309-314` and `server/notification/email.go:313-316`

**Store layer that materializes the filters**
- `FindMemo.VisibilityList` → SQL predicate — `store/memo.go:69`, `store/db/sqlite/memo.go:96`, `store/db/postgres/memo.go:89`, `store/db/mysql/memo.go:104`
