**Computation site; triggers; extracted properties**

**Computation site**

- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` is the single entry point. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (lines 80–87).
- The actual extraction lives in `internal/markdown/markdown.go:356` — `service.ExtractAll`, a single goldmark AST parse + walk (there's also a standalone `ExtractProperties` at `internal/markdown/markdown.go:193` implementing the same property logic, plus `GenerateSnippet` at line 264 used separately for webhook payloads at `server/router/api/v1/memo_service_webhooks.go:85`).
- Storage type: `storepb.MemoPayload_Property` (`proto/gen/store/memo.pb.go`); surfaced to the API by `convertMemoPropertyFromStore` at `server/router/api/v1/memo_service_converter.go:315`, attached to each memo in `convertMemoFromStoreWithCreators` (`memo_service_converter.go:49`).

**Triggers**

- Memo creation — `server/router/api/v1/memo_service.go:108` (`CreateMemo`, before the store write).
- Memo update, only when the update mask contains `content` — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written via `update.Payload = memo.Payload`.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) walks all memos in batches of 100, rebuilding and re-saving each payload. Note this runner is not currently wired into `server/server.go:153` (`startBackgroundRunners` only starts the s3presign runner), so today it's effectively dormant.

Nothing else recomputes it — visibility/pinned/state/timestamp updates leave the existing property untouched.

**Extracted properties** (`internal/markdown/markdown.go:383–408`)

- `Title` — plain text of the document's first block-level child, only if it is an H1 heading (`extractHeadingText`, line 173).
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any GFM `east.KindTaskCheckBox`.
- `HasIncompleteTasks` — any task checkbox with `IsChecked == false`.

The same walk also collects deduplicated `Tags` (and `Mentions`, which `RebuildMemoPayload` ignores). Consumers of these flags include memo filtering (`store/test/memo_filter_test.go:523+`) and user stats aggregation (`server/router/api/v1/user_service_stats.go:141–151, 257–267`).
