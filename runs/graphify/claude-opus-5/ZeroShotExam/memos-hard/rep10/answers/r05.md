**Premise correction:** There is no GraphQL anywhere in this repository. A case-insensitive search for `graphql` across the tree (excluding `node_modules/` and `graphify-out/`) returns zero hits — no `.graphql`/`.gql` files, no schema-first SDL, no resolvers, no Apollo/gqlgen/urql dependencies. This is **Memos** (`github.com/usememos/memos`, `go.mod:1`), and its public API is **Protocol Buffers over Connect RPC / gRPC-Gateway**, per `AGENTS.md:10` ("Backend: Go 1.26.2, Echo v5, Connect RPC, gRPC-Gateway, Protocol Buffers").

**Actual API surface — where the schema lives:**

- **Canonical definition: `proto/api/v1/*.proto`** — one file per service, eight services total:
  - `proto/api/v1/instance_service.proto:17` — `InstanceService`
  - `proto/api/v1/auth_service.proto:13` — `AuthService`
  - `proto/api/v1/user_service.proto:17` — `UserService`
  - `proto/api/v1/memo_service.proto:17` — `MemoService`
  - `proto/api/v1/attachment_service.proto:15` — `AttachmentService`
  - `proto/api/v1/ai_service.proto:11` — `AIService`
  - `proto/api/v1/shortcut_service.proto:14` — `ShortcutService`
  - `proto/api/v1/idp_service.proto:14` — `IdentityProviderService`
  - Shared types in `proto/api/v1/common.proto`. Design conventions follow Google AIPs (`proto/api/v1/README.md`).
  - Separate from these, `proto/store/*.proto` defines internal persistence payloads (not public API).

- **Codegen (`proto/buf.gen.yaml`)** fans the same `.proto` out to: Go structs + gRPC + Connect + grpc-gateway stubs into `proto/gen/`, an OpenAPI 3.0.3 document at `proto/gen/openapi.yaml` (via protoc-gen-openapi), and TypeScript clients into `web/src/types/proto`. The OpenAPI file is the closest thing to a "schema document" for HTTP consumers; it's embedded into the binary by `proto/openapi_embed.go:5` and consumed by the MCP server at `server/router/mcp/service.go:78`.

- **Serving:** Connect handlers are registered in `server/router/api/v1/connect_handler.go:31` (`RegisterConnectHandlers`), and the REST/JSON transcoding gateway in `server/router/api/v1/v1.go:65` (`RegisterGateway`), wired up from `server/server.go:76`. Business logic lives in `server/router/api/v1/*_service.go`.

So: to change the public API surface, edit the `.proto` files under `proto/api/v1/` and regenerate — there is no GraphQL schema to find. Non-RPC extras exist alongside it (`server/router/rss`, `server/router/mcp`, `server/router/fileserver`), but they're built on the same services.
