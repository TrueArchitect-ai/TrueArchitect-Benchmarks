**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` — the abstraction package. It defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every identity provider must produce.
- `internal/idp/oauth2/oauth2.go` — the only concrete protocol implementation that ships. Its package comment says "implements the OAuth2 identity provider integration"; it defines `IdentityProvider` over `storepb.OAuth2Config`, plus `NewIdentityProvider`, `ExchangeToken` (with optional PKCE code verifier), and user-info retrieval mapped through the configured field mapping.

Wiring: `server/router/api/v1/auth_service_sso.go:12-13` is the sole consumer, importing both `internal/idp` and `internal/idp/oauth2`. Related storage lives in `store/idp.go` and `store/user_identity.go`. No SAML or dedicated OIDC package exists — OIDC-style providers are handled through the generic OAuth2 implementation.
