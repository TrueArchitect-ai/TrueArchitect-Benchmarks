No Go toolchain is present in this environment, so I did a static text analysis instead of a real call graph: I collected every `func` / method declared in non-test files under `internal/`, then counted call sites repo-wide (excluding `web/` and `graphify-out/`), restricting each search to files in the same package or files that actually import the declaring package.
