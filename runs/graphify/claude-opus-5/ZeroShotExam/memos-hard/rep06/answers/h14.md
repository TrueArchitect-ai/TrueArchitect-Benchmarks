**Computation site; triggers; extracted properties**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` is the single entry point. It ensures `memo.Payload` exists, calls the markdown service once, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:79-87`).
- The actual parsing lives in `internal/markdown/markdown.go:356` — `service.ExtractAll(content)`, a single goldmark AST walk. (`ExtractProperties` at `internal/markdown/markdown.go:193` is the standalone equivalent; `ExtractTags` at `:143`.)

**Triggers (recomputation)**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert (user-supplied `location` is then merged onto the rebuilt payload at `:112`).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is written via `update.Payload = memo.Payload` (`:450`). Other mask paths (visibility, pinned, state, times) don't recompute.
- Backfill for all existing memos — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27`, which pages through memos in batches of 100 and rewrites each payload. Note: this runner is defined but not currently invoked from `server/server.go` (only `s3presign.NewRunner`/`RunOnce` is wired at `server/server.go:162-163`), so it's effectively a dormant/migration path.

**What is extracted** (shape in `proto/store/memo.proto:7-22`)
- `tags` — `#tag` nodes collected from the AST, deduplicated preserving original case (`markdown.go:376-378`, `:418`, `uniquePreserveCase` at `:456`).
- `property.has_link` — any `KindLink` node.
- `property.has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `property.has_task_list` — any `TaskCheckBox` node; `property.has_incomplete_tasks` — a task checkbox with `IsChecked == false` (`markdown.go:392-405`).
- `property.title` — text of the document's first block-level child only if it is an H1 heading (`markdown.go:383-389`, `extractHeadingText` at `:173`).
- `ExtractAll` also returns `Mentions` (lowercased `@user` nodes, `markdown.go:379-381`), but `RebuildMemoPayload` does not persist those into the payload — they're used elsewhere for mention handling.

One related thing that is *not* stored: the list preview `snippet` is derived per-response at read time, not persisted — `convertMemoFromStore` calls `getMemoContentSnippet` (`server/router/api/v1/memo_service_converter.go:76-80`), which calls `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-90`; implementation at `internal/markdown/markdown.go:264`, which flattens the AST to plain text, skips fenced/indented code blocks, and truncates at a word boundary).
