**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`**

The chain: each handler calls a `Dispatch*Webhook` method in `server/router/api/v1/memo_service_webhooks.go`, which loads the user's configured hooks via `s.Store.GetUserWebhooks`, sets `payload.URL = hook.Url`, and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`webhook.go:41-52`) drain it and call `Post`. `Post` is the sole place the request is built (`http.NewRequest("POST", requestPayload.URL, …)`, `webhook.go:126`), HMAC-signed, and sent through `safeClient.Do` (`webhook.go:152`) — whose transport uses `safeDialContext` (`webhook.go:59`) for SSRF/DNS-rebinding protection.

Two other outbound-HTTP paths exist but do not target a *user-configured* URL in the same sense: `internal/httpgetter/image.go:21` (`http.Get` on a URL supplied per-request, reached from link-metadata/attachment handlers) and `internal/idp/oauth2/oauth2.go:85-91` (admin-configured IdP `UserInfoUrl`).
