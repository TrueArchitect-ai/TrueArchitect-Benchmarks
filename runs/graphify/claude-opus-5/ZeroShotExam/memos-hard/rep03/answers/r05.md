**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across the entire tree returns zero hits, and there are no `.graphql`, `.gql`, or `.graphqls` files. This is the Memos project (Go backend), and its public API is **Protobuf/gRPC**, not GraphQL.

## Actual API surface

**Schema source of truth — `proto/api/v1/*.proto`** (9 files):

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |

| `proto/api/v1/ai_service.proto` | `AIService` |
| `proto/api/v1/common.proto` | shared types |

Internal storage-layer messages live separately in `proto/store/*.proto`. The design convention is documented in `proto/api/v1/README.md` (follows Google AIPs).

**Three protocols served from one schema.** Each RPC carries a `google.api.http` annotation that defines its REST binding — e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and line 35 maps `GetMemo` to `GET /api/v1/{name=memos/*}`. Wiring is in `server/router/api/v1/v1.go`:

- **REST/JSON** — gRPC-Gateway mux at `v1.go:96`, with the eight services registered at `v1.go:99-121`, served under `/api/v1`.
- **Connect RPC** — `v1.go:139-144`, routed at `/memos.api.v1.*`.
- **gRPC** — generated `*_grpc.pb.go` stubs in `proto/gen/api/v1/`.

**Codegen** — `proto/buf.gen.yaml` drives it all: Go structs, gRPC stubs, Connect handlers, and gateway code into `proto/gen/`, plus TypeScript clients into `web/src/types/proto` for the frontend.

**Closest thing to a "public API schema document"** — `proto/gen/openapi.yaml`, an OpenAPI 3.0.3 spec generated from the protos via `protoc-gen-openapi`, embedded into the binary by `proto/openapi_embed.go`.

The README confirms this at line 23: *"MIT-licensed with full REST and gRPC APIs for integration."*
