**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction:** `internal/idp/idp.go` — package `idp` defines the provider-neutral contract, the `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any IdP implementation must return.
- **Implementation:** `internal/idp/oauth2/oauth2.go` — package `oauth2`, documented as "implements the OAuth2 identity provider integration." It provides `IdentityProvider` built from `storepb.OAuth2Config` via `NewIdentityProvider` (validating `clientId`, `clientSecret`, `tokenUrl`, `userInfoUrl`, `fieldMapping.identifier`), plus `ExchangeToken` (with optional PKCE `codeVerifier`) and user-info retrieval mapped into `idp.IdentityProviderUserInfo`.

OAuth2 is the only concrete protocol that ships — `internal/idp/` contains just the `oauth2` subpackage, no SAML/LDAP/OIDC-specific implementations. The consumer is the SSO endpoint at `server/router/api/v1/auth_service_sso.go:12-13`, which imports both packages.
