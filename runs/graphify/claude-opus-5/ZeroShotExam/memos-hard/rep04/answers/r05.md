**Premise correction:** There is no GraphQL anywhere in this repository. A case-insensitive search for `graphql` across the whole tree (Go, TS/TSX, proto, Markdown, JSON/YAML, config) returns zero hits — no schema files, no resolvers, no `gqlgen`/`graphql-go`/Apollo dependency in `go.mod` or `web/package.json`. Memos is a **Protobuf/gRPC-first** project.

**Actual API surface**

*Schema definition (the real answer):* the public API contract lives in Protobuf under `proto/api/v1/`, package `memos.api.v1`:

- `proto/api/v1/memo_service.proto` — `MemoService` (memos, comments, reactions, relations, attachments, shares, link metadata)
- `proto/api/v1/user_service.proto` — `UserService` (users, settings, PATs, webhooks, linked identities, notifications)
- `proto/api/v1/auth_service.proto` — `AuthService` (`SignIn`, `SignOut`, `RefreshToken`, `GetCurrentUser`)
- `proto/api/v1/attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`
- Internal storage-only messages are separate, in `proto/store/*.proto`
- Design convention: Google AIP-style resource naming (`proto/api/v1/README.md`)

*Code generation:* `proto/buf.gen.yaml` drives `buf generate`, emitting Go protobuf + gRPC + Connect + grpc-gateway stubs into `proto/gen/api/v1/`, TypeScript clients into `web/src/types/proto/`, and an OpenAPI 3.0 document at `proto/gen/openapi.yaml` (embedded into the binary via `proto/openapi_embed.go`).

*Exposed transports* — all three are projections of the same `.proto` files, wired in `server/router/api/v1/v1.go:65` (`RegisterGateway`) and mounted from `server/server.go:86`:

1. **REST/JSON** — grpc-gateway mux serving `/api/v1/*` and `/file/*`; the HTTP verbs/paths come from `google.api.http` annotations inside each `.proto` (e.g. `post: "/api/v1/memos"` at `proto/api/v1/memo_service.proto:23`).
2. **Connect RPC** — mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:144`), implemented in `server/router/api/v1/connect_services.go` / `connect_handler.go`; this is what the web client uses (replaced grpc-web).
3. **gRPC service implementations** — `APIV1Service` in `server/router/api/v1/v1.go:22` embeds the generated `Unimplemented*Server` types.

*Non-proto HTTP endpoints:* `/healthz` (`server/server.go:67`), RSS (`server/router/rss/rss.go`), file serving (`server/router/fileserver/`), SSE (`RegisterSSERoutes`, `server/router/api/v1/sse_hub.go`), and an MCP endpoint that is generated from the embedded OpenAPI spec (`server/router/mcp/service.go:76`).
