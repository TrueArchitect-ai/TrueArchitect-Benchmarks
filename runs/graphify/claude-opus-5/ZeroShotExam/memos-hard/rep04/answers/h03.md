**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every IdP integration normalizes to.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the only concrete protocol implementation. It provides `IdentityProvider` wrapping `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (via `golang.org/x/oauth2`, with PKCE `code_verifier` support), and `UserInfo` returning `*idp.IdentityProviderUserInfo`.

Wiring: `server/router/api/v1/auth_service_sso.go:104` (`resolveSSOIdentity`) branches on `identityProvider.Type == storepb.IdentityProvider_OAUTH2` — OAuth2 is the sole branch — then applies the `IdentifierFilter` regex. Config protos live in `proto/gen/store/idp.pb.go`, persistence in `store/idp.go`.
