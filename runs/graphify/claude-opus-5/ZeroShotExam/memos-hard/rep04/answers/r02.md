**Premise correction: this repository (usememos/memos) has no per-user API rate-limiting middleware.** There is nothing to register and no request limits to report — no rate-limiter is registered on either the Echo HTTP chain or the Connect/gRPC interceptor chain, and no rate-limiting library is in `go.mod` (no `golang.org/x/time/rate`, `tollbooth`, `ulule/limiter`, etc.).

**What is actually registered**

- Echo middleware — `server/server.go:51-52`: only `middleware.Recover()` and `newCORSMiddleware(profile)`.
- Connect RPC interceptors — `server/router/api/v1/v1.go:133-137`: `MetadataInterceptor`, `LoggingInterceptor`, `RecoveryInterceptor`, `AuthInterceptor` (defined in `server/router/api/v1/connect_interceptors.go`). Auth and authorization only; no throttling.
- `internal/scheduler/middleware.go` is middleware for *background jobs* (Recovery, Logging, Timeout), not HTTP requests.

**The only request limits that do exist** (none are per-user or time-windowed)

- Request body size cap: `maxAPIRequestBytes = 256 << 20` (256 MiB), applied via `http.MaxBytesHandler` to `/api/v1/*`, `/file/*`, and the Connect mux, plus `connect.WithReadMaxBytes` — `server/router/api/v1/v1.go:20,126-144`.
- Global concurrency semaphores (process-wide, not per user): `thumbnailSemaphore` = 3 concurrent, `imageProcessingSemaphore` = 2 concurrent — `server/router/api/v1/v1.go:39-60`. Exhaustion of the image one returns `ResourceExhausted "too many image processing requests"` (`server/router/api/v1/attachment_service.go:158-160`, acquire logic in `server/router/api/v1/attachment_service_image.go:68-75`). This is a queue-depth guard against memory exhaustion, not a rate limit.

**Where rate limiting is only discussed, not implemented**: `internal/email/doc.go:86` lists it as a future consideration, and `internal/email/README.md:286-295` shows an illustrative `golang.org/x/time/rate` snippet for email sending — sample docs, not wired into any route.

There is also no login-attempt throttling or account lockout in the auth path (`server/auth/`, `server/router/api/v1/auth_service*.go`).
