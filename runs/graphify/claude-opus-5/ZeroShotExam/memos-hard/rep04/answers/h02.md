**Delivery function — `Post` in `internal/webhook/webhook.go:120`** (with `PostAsync`, `internal/webhook/webhook.go:184`, enqueueing onto a 128-slot channel drained by 4 worker goroutines started in `init()`, `internal/webhook/webhook.go:42-55`). The actual HTTP POST is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`. Callers are the memo lifecycle dispatchers in `server/router/api/v1/memo_service_webhooks.go:43,71`.

**Protection mechanism — two layers:**

1. **Dial-time SSRF guard (the real enforcement)** — `safeDialContext`, `internal/webhook/webhook.go:59-77`, installed as the `Transport.DialContext` of the shared `safeClient` (`internal/webhook/webhook.go:32-37`). It splits host/port, resolves the hostname itself, and refuses to dial if *any* resolved address is reserved. Because the check happens at connect time on every dial (including redirects), it also defeats DNS rebinding, which a URL-time-only check would miss.
2. **Admission-time validation** — `ValidateURL`, `internal/webhook/validate.go:62-83`, called when a user creates/updates a webhook (`server/router/api/v1/user_service_webhooks.go:74,161,182`). It enforces http/https scheme and rejects hostnames resolving to reserved ranges, returning a gRPC `InvalidArgument`.

Both share the range table: `isReservedIP` / `reservedNetworks` parsed from `reservedCIDRs` in `internal/webhook/validate.go:14-54` — IPv4 loopback, RFC-1918 (10/8, 172.16/12, 192.168/16), link-local 169.254/16 (cloud IMDS), plus `::1/128`, `fc00::/7`, `fe80::/10`.

Two things worth flagging:

- `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global kill switch that disables *both* layers when true, but it is never assigned anywhere outside tests — no flag, env var, or config wires it up, so in production it is always `false`.
- The IPv4 list omits `0.0.0.0/8`, `100.64.0.0/10` (CGNAT), and IPv4-mapped IPv6 (`::ffff:127.0.0.1` parses to a 4-byte-comparable IP so `Contains` does catch that one, but `64:ff9b::/96` NAT64 is not covered).
