**Where the URL comes from (before the request):** the API converter rewrites a base64 avatar into a path — `convertUserFromStore` — `server/router/api/v1/user_service_converters.go:31-38` builds `/file/users/{username}/avatar`, which the browser renders via `UserAvatar` — `web/src/components/UserAvatar.tsx:12` (`<img src={avatarUrl}>`).

**Request path, hop per line:**

- `FileServerService.RegisterRoutes` (route `GET /file/users/:identifier/avatar`) — `server/router/fileserver/fileserver.go:121-124`
- `FileServerService.serveUserAvatar` (serving handler) — `server/router/fileserver/fileserver.go:168`
- `FileServerService.getCurrentUser` → `Authenticator.AuthenticateToUser` (only when `Profile.AllowAnonymous()` is false) — `server/router/fileserver/fileserver.go:708` → `server/auth/authenticator.go:190`
- `FileServerService.getUserByUsername` (`store.FindUser{Username: &identifier}`) — `server/router/fileserver/fileserver.go:715`
- `Store.GetUser` (user cache checked only when `find.ID != nil`, so a username lookup always falls through) — `store/user.go:148`
- `Store.ListUsers` — `store/user.go:136`
- `Driver.ListUsers` (interface) — `store/driver.go:47`
- `DB.ListUsers` — `store/db/sqlite/user.go:88` (also `store/db/mysql/user.go:84`, `store/db/postgres/user.go:87`); driver picked by `NewDBDriver` — `store/db/db.go:14`
- SQL `SELECT ... avatar_url ... FROM user WHERE username = ?` → scanned into `User.AvatarURL` — `store/db/sqlite/user.go:151-197`

**Back out:** `FileServerService.parseDataURI` decodes the stored `data:<mime>;base64,...` value (`server/router/fileserver/fileserver.go:737`), the MIME type is checked against `avatarAllowedTypes` (`fileserver.go:72-80`), and the bytes go out via `c.Blob` with `nosniff`/`DENY`/CSP headers and `public, max-age=3600` (`fileserver.go:193-198`).

Note the data layer here is the `user.avatar_url` column itself — avatars are stored inline as base64 data URIs, not as files or attachment blobs, so there is no filesystem/S3 hop (unlike `serveAttachmentFile`, which branches on `AttachmentStorageType`).
