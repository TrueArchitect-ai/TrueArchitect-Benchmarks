**Computation site; triggers; extracted properties**

**Computation site:** `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates the actual work to the goldmark-based markdown service `(*service).ExtractAll` (`internal/markdown/markdown.go:194-420`). `ExtractAll` parses the content once and walks the AST, filling `storepb.MemoPayload_Property`; `RebuildMemoPayload` then assigns `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). An equivalent standalone path exists as `(*service).ExtractProperties` (`internal/markdown/markdown.go:193`). The stored shape is defined in `proto/store/memo.proto:15-22` ("The calculated properties from the memo content") and is exposed read-only to the API via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`), mapped onto the `OUTPUT_ONLY` `Memo.property` field (`proto/api/v1/memo_service.proto:256`).

**Triggers:**
- Memo creation — `CreateMemo` calls it before persisting (`server/router/api/v1/memo_service.go:108`).
- Memo update, but only when the update mask includes `content` (`server/router/api/v1/memo_service.go:436-450`); the recomputed payload is written along with the new content. Other mask paths (visibility, pinned, state, timestamps) do not recompute it. Note `location` is set on the payload *after* the rebuild in create (`memo_service.go:111-113`), since it's user-set, not derived.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) re-derives the payload for every memo in batches of 100 and persists each via `Store.UpdateMemo`. This runner is defined but is not currently wired into `startBackgroundRunners` in `server/server.go:153-173` (only the s3presign runner is started there), so in practice it's an available maintenance/backfill entry point rather than a live trigger.

**Extracted properties** (`internal/markdown/markdown.go:383-407`, `proto/store/memo.proto:16-21`):
- `has_link` — true if any `gast.KindLink` node is present.
- `has_code` — true for `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — true if any `east.KindTaskCheckBox` node exists.
- `has_incomplete_tasks` — true if any task checkbox has `IsChecked == false`.
- `title` — text of the first block-level child of the document when it is an H1 heading, via `extractHeadingText` (guarded by `firstBlockChecked`, so a later H1 doesn't count).

In the same pass `ExtractAll` also collects `Tags` (from memo tag nodes, deduplicated case-preserving) and `Mentions`, and `Tags` is likewise stored on the payload — but only `Property` is the "calculated properties" block surfaced as `Memo.property`, used by the web filters (`web/src/contexts/MemoFilterContext.tsx:11-13`, `web/src/hooks/useMemoFilters.ts:73-77`) and stats (`server/router/api/v1/user_service_stats.go:141-151`).
