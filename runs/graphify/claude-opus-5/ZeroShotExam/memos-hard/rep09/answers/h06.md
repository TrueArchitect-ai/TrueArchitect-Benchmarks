**Convergence function: `webhook.Post` — `internal/webhook/webhook.go:120`**

**The path:** each handler's dispatcher lives in `server/router/api/v1/memo_service_webhooks.go`, which loads the creator's configured endpoints with `s.Store.GetUserWebhooks(...)`, sets `payload.URL = hook.Url` / `payload.SigningSecret = hook.SigningSecret`, and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` only enqueues onto the 128-slot `asyncPostQueue`; four goroutines started in `init()` (`internal/webhook/webhook.go:41-52`) drain it and call `Post`, which is the sole place the request is built and sent (`http.NewRequest("POST", requestPayload.URL, ...)` at `:126`, `safeClient.Do(req)` at `:151`). The URL originates from user configuration written by `CreateUserWebhook`/`UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`.

Two notes:
- SSRF defense is layered — `webhook.ValidateURL` (`internal/webhook/validate.go:64`) at config time, plus `safeDialContext` (`internal/webhook/webhook.go:59`) on the shared `safeClient` transport at dial time, which is what defeats DNS rebinding. Both are bypassable by the operator flag `webhook.AllowPrivateIPs`.
- A *separate* outbound-HTTP path exists for per-request (not user-configured) URLs: `GetLinkMetadata`/`BatchGetLinkMetadata` in `server/router/api/v1/memo_service_link_metadata.go:14,19` → `httpgetter.GetHTMLMeta`. It does not converge on `webhook.Post`.
