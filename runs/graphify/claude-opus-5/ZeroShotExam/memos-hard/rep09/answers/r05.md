**Premise correction:** This repository (Memos, a Go + React note-taking app) has **no GraphQL schema and no GraphQL API at all.** There are no `.graphql`/`.gql` files, no GraphQL server library in `go.mod`, and no GraphQL client in `web/package.json`. (A `grep` for "graphql"/"gql" matches only base64 integrity hashes inside `web/pnpm-lock.yaml` — false positives.)

**The actual public API surface — Protocol Buffers:**

The schema of record is the set of `.proto` files in `proto/api/v1/`, all in package `memos.api.v1`:

| File | Service |
| --- | --- |
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto` | `AIService` |
| `proto/api/v1/common.proto` | shared enums/messages |

(`proto/store/*.proto` is internal storage state, not public API.)

**How it's exposed** — three surfaces generated from those protos via `buf generate` (`proto/buf.gen.yaml`):

- **REST/JSON** over gRPC-Gateway at `/api/v1/*` and `/file/*` — registered in `server/router/api/v1/v1.go:99-126`.
- **Connect RPC** at `/memos.api.v1.*` (used by the browser client) — `server/router/api/v1/v1.go:140-144`, handlers in `server/router/api/v1/connect_handler.go` / `connect_services.go`.
- **gRPC** stubs in `proto/gen/api/v1/*_grpc.pb.go`.

**Generated artifacts** (do not hand-edit; per `AGENTS.md`): Go in `proto/gen/`, TypeScript in `web/src/types/proto/`, and an OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml` — embedded into the binary by `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/service.go:78`.

Auth policy for these endpoints lives in `server/router/api/v1/acl_config.go`, which lists unauthenticated methods by their gRPC procedure path (e.g. `/memos.api.v1.MemoService/ListMemos`).
