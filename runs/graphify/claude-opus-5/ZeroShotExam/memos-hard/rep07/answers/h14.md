**Answer: `RebuildMemoPayload` (backed by `markdown.Service.ExtractAll`); triggered on memo create, on update when `content` is in the update mask, and by the memopayload batch runner; extracts tags (deduped, case-preserved) plus the calculated `Property` — `title` (leading H1 text), `has_link`, `has_code`, `has_task_list`, `has_incomplete_tasks`.**

Details:

**Computation site**
- `server/runner/memopayload/runner.go:75` — `RebuildMemoPayload(ctx, memo, markdownService)` ensures `memo.Payload` exists, calls `ExtractAll` on the content, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:80-91`).
- The actual parse lives in `internal/markdown/markdown.go:356` (`service.ExtractAll`) — a single goldmark AST walk. `ExtractProperties` (`markdown.go:180`) is the standalone equivalent.
- Storage shape: `proto/store/memo.proto:7-23` (`MemoPayload.Property`, commented "The calculated properties from the memo content"). Surfaced to the API as OUTPUT_ONLY in `proto/api/v1/memo_service.proto:256` via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`).

**Triggers**
1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`). Other mask paths (visibility, pinned, state, …) do not recompute.
3. Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) pages through all memos in batches of 100, rebuilding and persisting each payload. Note this runner is defined but not currently wired into `server/server.go` (only `s3presignRunner.RunOnce` is called there, `server.go:163`), so in practice recomputation happens at create/content-update.

**What is extracted** (`markdown.go:356-420`)
- `Tags` — `#tag` nodes, skipping tags nested in links/images (`asMemoTagNode`, `markdown.go:135`), deduped preserving case.
- `Mentions` — `@username` nodes, lowercased (returned by `ExtractAll` but *not* stored in the payload; used by `resolveMentionTargets`, `server/router/api/v1/memo_mention_helpers.go:32`).
- `Property.Title` — text of the document's first block-level child if it's an H1.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — any GFM task checkbox; incomplete if any checkbox is unchecked.

Related but distinct: the list/preview **snippet** is *not* stored — it's derived per-response at conversion time via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet` (`server/router/api/v1/memo_service_converter.go:76` and `:225`/`:248` for related memos; `markdown.go:264` skips code blocks and truncates at a word boundary).
