**delivery function — `internal/webhook/webhook.go`; protection mechanism — `internal/webhook/validate.go` (+ the dialer in `internal/webhook/webhook.go`)**

**Where delivery executes**

- `webhook.Post(*WebhookRequestPayload)` — `internal/webhook/webhook.go:120` — is the function that actually builds and sends the outbound `POST` (JSON body, optional Standard-Webhooks HMAC-SHA256 headers `webhook-id` / `webhook-timestamp` / `webhook-signature`, response read via `io.LimitReader` at 1 MiB).
- Callers don't invoke it directly on the request path: `webhook.PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto a buffered channel (`asyncPostQueue`, cap 128, drops + logs when full), and 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) call `Post` off that queue.
- Triggers are in `server/router/api/v1/memo_service_webhooks.go` — `dispatchMemoRelatedWebhook` (line 48, for `memos.memo.created/updated/deleted`) and `DispatchMemoCommentCreatedWebhook` (line 30), both fanning out over `s.Store.GetUserWebhooks(...)`.

**What protects it from internal addresses** — two layers, both keyed on `isReservedIP` (`internal/webhook/validate.go:44`):

1. **Dial-time block (the real defense).** All dispatches share `safeClient` (`internal/webhook/webhook.go:32`) whose `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:59`). It resolves the host itself and refuses the connection if *any* resolved IP is reserved. Because the check happens at dial time rather than at save time, it also defeats DNS rebinding.
2. **Admission-time validation.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) enforces absolute URL + `http`/`https` scheme + non-reserved resolution when a webhook is created/updated, called from `server/router/api/v1/user_service_webhooks.go:74,161,182`.

The blocked ranges are `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 blocks, `169.254.0.0/16` (cloud IMDS), plus `::1/128`, `fc00::/7`, `fe80::/10`.

One caveat worth knowing: `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global kill switch that disables both layers, and grepping the Go sources shows nothing ever assigns it — it's declared and read only within that file, so it's currently pinned at `false` with no flag or config wired up to it.
