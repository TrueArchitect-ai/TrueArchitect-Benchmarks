**1st: `store.User` (~7 packages outside `store/`); 2nd: `store.Memo` (~6 packages)**

**The data layer** is the `store` package (`store/store.go:13`), which defines the persistent entity types: `User` (`store/user.go:29`), `Memo` (`store/memo.go:35`), `Attachment` (`store/attachment.go:16`), `Reaction` (`store/reaction.go:7`), `Inbox` (`store/inbox.go:24`), `MemoRelation` (`store/memo_relation.go:16`), `MemoShare` (`store/memo_share.go:6`), `UserIdentity` (`store/user_identity.go:8`), `UserSetting` (`store/user_setting.go:13`), `IdentityProvider` (`store/idp.go:12`), `InstanceSetting` (`store/instance_setting.go:14`).

Counting distinct Go packages *outside* `store/` (i.e. excluding `store/db/{sqlite,mysql,postgres}` and `store/test`, which are part of the data layer itself):

| **`Memo`** | **6** — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` |

Representative citations:

Note the ordering flips if you rank by raw reference count rather than package count: `Memo` has ~162 references outside `store/` vs. ~128 for `User`. `Memo` is used more *heavily*, but `User` is used more *widely* — it reaches the auth and fileserver packages that never touch `Memo`.
