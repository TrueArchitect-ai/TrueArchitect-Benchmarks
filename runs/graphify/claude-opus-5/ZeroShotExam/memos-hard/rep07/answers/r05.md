**Premise correction: this repository has no GraphQL.** There is no GraphQL schema, no `.graphql`/`.gql` files, no schema-definition language, and no GraphQL server library. A case-insensitive search for "graphql" across the whole tree (excluding `graphify-out/`) returns zero matches. This is Memos (`github.com/usememos/memos`), a Go backend whose public API is defined in **Protocol Buffers**, served as gRPC / Connect / REST — not GraphQL.

## The actual API surface

**Schema of record: `.proto` files in `proto/api/v1/`**

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto`
- Package `memos.api.v1`. Internal storage-only messages live separately in `proto/store/*.proto` and are not part of the public API.
- REST mapping is declared inline via `google.api.http` annotations — e.g. `proto/api/v1/memo_service.proto:22` maps `CreateMemo` to `POST /api/v1/memos`, and `ListMemos` to `GET /api/v1/memos`.
- Design follows Google's AIPs (`proto/api/v1/README.md:1`).

**Code generation: `proto/buf.gen.yaml`** (run with `buf generate`, `proto/README.md:9`) fans one schema out to five targets:
- Go message types + gRPC servers + Connect handlers + grpc-gateway REST shims → `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*_connect.go`, `*.pb.gw.go`
- An **OpenAPI spec** → `proto/gen/openapi.yaml`, embedded into the binary at `proto/openapi_embed.go:5` and exposed via `OpenAPIYAML()`
- TypeScript clients for the web app → `web/src/types/proto/api/v1/*_pb.ts` (`proto/buf.gen.yaml:26-30`)

Lint/breaking-change rules for the schema are in `proto/buf.yaml`.

**Runtime wiring: `server/router/api/v1/v1.go`**
- `APIV1Service` (`v1.go:22`) embeds the generated `Unimplemented*ServiceServer` stubs for all eight services.
- `RegisterGateway` (`v1.go:65`) registers grpc-gateway handlers and mounts REST at `/api/v1/*` and `/file/*` (`v1.go:128-129`), plus Connect-RPC handlers at `/memos.api.v1.*` for browser clients (`v1.go:144`). SSE routes are registered at `v1.go:125`.

**Possible source of the confusion:** there is a file named `internal/filter/schema.go`, but it defines the **CEL filter expression schema** (allowed fields/aliases for `filter=` query params, `Schema`/`Field` types at `internal/filter/schema.go:47-89`), not an API schema.
