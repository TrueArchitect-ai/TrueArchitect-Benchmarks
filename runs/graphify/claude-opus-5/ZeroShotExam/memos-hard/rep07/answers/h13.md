**Short answer:** `*markdown.service` (the single unexported goldmark-backed struct) — constructed via `markdown.NewService(...)` in `NewAPIV1Service` (with the tag + mention extensions), then passed by hand into RSS — held by `APIV1Service`, `RSSService`, and `memopayload.Runner`.

## The interface

`markdown.Service` in `internal/markdown/markdown.go:31-54` — eight methods: `ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, `RenameTag`.

## Implementations

There is exactly **one** concrete implementation: the unexported `service` struct (`internal/markdown/markdown.go:57-59`), which wraps a `goldmark.Markdown` instance. No mocks, fakes, or alternate backends exist anywhere in the repo — tests use the real thing.

What varies is not the type but its *configuration*, via functional options (`internal/markdown/markdown.go:62-105`):
- `WithTagExtension()` → `extensions.TagExtension` (`internal/markdown/extensions/tag.go`) for `#tag` parsing
- `WithMentionExtension()` → `extensions.MentionExtension` (`internal/markdown/extensions/mention.go`) for `@mention` parsing
- GFM is always on.

`RenderMarkdown`/`RenameTag` delegate to a second concrete type, `renderer.MarkdownRenderer` (`internal/markdown/renderer/markdown_renderer.go:15`), constructed inline per call at `markdown.go:243` and `markdown.go:420`. It is a plain struct behind no interface.

## Construction

The only production construction site is `NewAPIV1Service` (`server/router/api/v1/v1.go:48-51`), with **both** extensions enabled. `server/server.go:76` calls it, then at `server/server.go:85` reaches into the result and hands `apiV1Service.MarkdownService` to `rss.NewRSSService` — so the API layer and RSS share one instance. There is no DI container; the API service is the de facto owner.

Test-only construction sites:
- `server/router/api/v1/test/test_helper.go:44-47` — mirrors production (both extensions)
- `server/router/fileserver/fileserver_test.go:427` — tags only
- `server/router/rss/rss_test.go:54` — `markdown.NewService()` with **no** options, so `#tags`/`@mentions` are inert in that test's fixtures
