**Premise correction:** There is no GraphQL in this repository. A case-insensitive search for `graphql` across the whole tree (excluding `node_modules`/`.git`) returns zero hits — no `.graphql`/`.gql` files, no schema definition, no server library, no client. Memos is a Go + React app whose public API is **Protobuf/gRPC-defined**, not GraphQL.

**Actual API surface**

*Schema source of truth* — Protobuf files under `proto/api/v1/`, all in package `memos.api.v1`:
- `proto/api/v1/memo_service.proto` — `MemoService` (memos, comments, relations, reactions, attachments)
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared enums/messages

Internal storage-only protos live separately in `proto/store/`.

*Code generation* — `proto/buf.gen.yaml` (run via `buf generate`, see `proto/README.md`) fans the schema out to:
- Go types + gRPC + Connect + grpc-gateway stubs → `proto/gen/api/v1/` (Connect handlers in `proto/gen/api/v1/apiv1connect/`)
- An OpenAPI document → `proto/gen/openapi.yaml`, embedded into the binary by `proto/openapi_embed.go`
- TypeScript client types for the frontend → `web/src/types/proto/`

*Exposed protocols* — one service implementation serves three wire formats:
- REST/JSON under `/api/v1/...` via grpc-gateway, from `google.api.http` annotations on each RPC (e.g. `proto/api/v1/memo_service.proto:23,30,35`)
- Connect RPC, registered in `server/router/api/v1/connect_handler.go`
- Native gRPC

All of it is wired up in `server/router/api/v1/v1.go:65` (`RegisterGateway`), called from `server/server.go:88`. There is also an MCP server (`server/router/mcp/`) built on the same OpenAPI catalog, and an RSS route (`server/router/rss/rss.go`).
