**Premise correction:** There is no nightly database-cleanup job scheduled in this repository's cron scheduler. The premise assumes a registered production job that doesn't exist.

What actually exists:

- `internal/scheduler/` is a **standalone, general-purpose cron library** (GitHub Actions-inspired, zero external dependencies) — see `internal/scheduler/doc.go:1-33`. It provides `Job` registration, cron parsing, timezone support, and middleware.
- **Nothing in the application registers any job with it.** The only files importing `github.com/usememos/memos/internal/scheduler` are its own tests: `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. No `server/`, `store/`, or `cmd/` code calls `scheduler.New()` or `Register(...)`.

The "2 AM" figure the question likely refers to comes only from **documentation and example code**, not a live schedule:

- `internal/scheduler/doc.go:14-16` — package doc snippet: `Name: "daily-cleanup"`, `Schedule: "0 2 * * *"` (2 AM daily)

- `internal/scheduler/example_test.go:97-100` — `Example_multipleJobs`, a Go example test: `"cleanup"` at `"0 2 * * *"`
