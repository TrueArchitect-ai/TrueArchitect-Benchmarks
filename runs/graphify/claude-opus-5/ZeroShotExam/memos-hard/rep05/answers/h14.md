**Computation site; triggers; extracted properties**

**Computation site**

- `internal/markdown/markdown.go:355` — `service.ExtractAll(content)` (goldmark AST walk) is the single-pass extractor that fills `ExtractedData.Property`; `internal/markdown/markdown.go:193` `ExtractProperties` is the standalone equivalent (same switch, separate parse).
- `server/runner/memopayload/runner.go:73` — `RebuildMemoPayload(ctx, memo, markdownService)` is the wrapper every write path calls. It ensures `memo.Payload` is non-nil, calls `ExtractAll([]byte(memo.Content))`, and assigns both `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property`.
- Stored on the memo row as `MemoPayload.Property` (`proto/store/memo.proto:13-21`), and surfaced to the API via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`) into `Memo.Property` (`proto/api/v1/memo_service.proto:272-279`), alongside the separately-computed `snippet`.

**Triggers (recomputation)**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`. (Location is set on the payload *after* the rebuild, at line 111, so it isn't clobbered.)
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the payload then rides along on `update.Payload`. Other mask paths (visibility, pinned, state, timestamps) do not recompute.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives the payload for every memo in batches of 100. Note this runner is defined but not wired up anywhere: `memopayload` is imported only by `memo_service.go`, and `server/server.go` starts only the s3presign runner.

**Extracted properties** (`storepb.MemoPayload_Property`)

- `has_link` — any `gast.KindLink` node.
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — any `east.KindTaskCheckBox`.
- `has_incomplete_tasks` — a task checkbox with `IsChecked == false`.
- `title` — text of the document's **first block-level child** only, and only if it's an H1 (`extractHeadingText`); an H1 lower down does not count.

The same walk also collects `Tags` and `Mentions` into the payload/mention path, but those are separate fields from `Property`.
