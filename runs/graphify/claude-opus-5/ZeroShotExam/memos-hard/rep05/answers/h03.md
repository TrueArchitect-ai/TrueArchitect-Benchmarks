**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package: `internal/idp`** — `internal/idp/idp.go` defines the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any provider implementation must produce. It's the only type in the package; there is no Go interface, just this common result shape.
- **Implementation package: `internal/idp/oauth2`** — `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration") provides `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (PKCE-capable), and `UserInfo`.

OAuth2 is the only concrete protocol that ships: `server/router/api/v1/auth_service_sso.go:120` branches solely on `storepb.IdentityProvider_OAUTH2`, and the store proto (`proto/gen/store/idp.pb.go`) carries only an `OAuth2Config`. No OIDC-specific or SAML implementation exists in the tree.
