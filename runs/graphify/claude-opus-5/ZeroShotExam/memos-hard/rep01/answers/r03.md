**Premise correction: there is no nightly database-cleanup job in this repository's cron scheduler.** The scheduler exists, but nothing registers a database-cleanup job with it.

What's actually there:

- `internal/scheduler/` is a self-contained, general-purpose cron library (`scheduler.go`, `job.go`, `parser.go`, `middleware.go`). Its `Register` method (`internal/scheduler/scheduler.go:70`) is only ever called from its own tests and examples — grepping for `internal/scheduler` across the repo returns only `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. The server (`server/server.go`, `cmd/memos`) never imports or starts it.
- The "2 AM daily" cleanup you may be thinking of is **documentation/example code, not a live job**:
  - `internal/scheduler/README.md:33-40` — Quick Start example, `Name: "daily-cleanup"`, `Schedule: "0 2 * * *"`
  - `internal/scheduler/doc.go:15-16` — same example in the package doc
  - `internal/scheduler/example_test.go:99-100` — `Name: "cleanup"`, `Schedule: "0 2 * * *"` in a middleware example
  - `internal/scheduler/README.md:240-246` — a `"stale-session-cleanup"` at `"0 3 * * *"` in the Best Practices section
- The only real periodic background work in the codebase doesn't use the cron scheduler at all:
  - `server/runner/s3presign/runner.go:26-30` — a `time.Ticker` running every 12 hours
  - `store/cache/cache.go:199-218` with `store/store.go:42` — an in-memory cache cleanup loop on a 5-minute interval

So if you're looking for a scheduled DB cleanup, it would need to be written and registered — the plumbing is available but unused.
