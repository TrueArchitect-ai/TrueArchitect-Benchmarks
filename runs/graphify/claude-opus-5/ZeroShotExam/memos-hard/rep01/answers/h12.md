stmt := "INSERT INTO `memo` (" + strings.Join(fields, ", ") + ") VALUES (" +

Base columns are `uid, creator_id, content, visibility, payload`, with `created_ts`/`updated_ts` appended only when non-zero. It uses `QueryRowContext` (not `Exec`) because of the `RETURNING` clause, scanning the generated id and timestamps back into the passed-in `*store.Memo`.

## How I determined it among the three candidates

There are exactly three implementations of the same method, one per dialect — `store/db/sqlite/memo.go:16`, `store/db/mysql/memo.go:16`, `store/db/postgres/memo.go:16` — all satisfying the `CreateMemo` entry of the `store.Driver` interface (`store/driver.go:29`). Selection is runtime, not build-tag, so I traced the value that drives it:

1. **Default flag value** — `cmd/memos/main.go:122` sets `viper.SetDefault("driver", "sqlite")` and `cmd/memos/main.go:130` registers `--driver` with default `"sqlite"`. With no flags/env, `profile.Driver == "sqlite"`.
2. **Profile construction** — `cmd/memos/main.go:43` reads that into `Profile.Driver`; `internal/profile/profile.go` then defaults the DSN to `<data>/memos_prod.db` only in the `sqlite` branch, confirming sqlite is the intended default.
3. **Driver switch** — `store/db/db.go` `NewDBDriver` switches on `profile.Driver`; `"sqlite"` → `sqlite.NewDB(profile)`, which returns `*sqlite.DB` (`store/db/sqlite/sqlite.go`, opening `sql.Open("sqlite", ...)` on modernc.org/sqlite). The other two branches are unreachable in a default install.
4. **Single, unwrapped dispatch** — `cmd/memos/main.go:60` passes that driver into `store.New(dbDriver, instanceProfile)`, and `store.Store.CreateMemo` (`store/memo.go:109`) only validates the UID before delegating straight to `s.driver.CreateMemo`. I checked `store/store.go` for any decorator: the caches there cover instance settings, users, and user settings only — nothing wraps or intercepts the memo path.

The API entry point is `server/router/api/v1/memo_service.go:115` (`s.Store.CreateMemo`), which comments also route through via `CreateMemoComment` calling the same service method.
