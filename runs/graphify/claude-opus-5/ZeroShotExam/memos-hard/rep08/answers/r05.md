**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive grep for `graphql` across the entire tree (excluding `.git`/`node_modules`) returns zero hits — no `.graphql`/`.gql` files, no schema-definition code, no GraphQL server or client dependency in `go.mod` or `web/package.json`. Memos' public API is **Protocol Buffers / gRPC**, exposed over Connect RPC and a gRPC-Gateway REST layer.

**Actual API surface**

Schema definition (source of truth):
- `proto/api/v1/*.proto` — one file per service: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`. Package `memos.api.v1`.
- REST routes are declared inline on each RPC via `google.api.http` annotations — e.g. `MemoService.ListMemos` → `get: "/api/v1/memos"`, `CreateMemo` → `post: "/api/v1/memos"` (`proto/api/v1/memo_service.proto:17-35`). Design follows Google AIPs (`proto/api/v1/README.md`).
- `proto/store/` holds internal storage-only messages (not public API).

Code generation (`proto/buf.gen.yaml`, run with `cd proto && buf generate`):
- Go messages, gRPC, Connect, and gRPC-Gateway stubs → `proto/gen/api/v1/` (incl. `apiv1connect/`).
- OpenAPI 3.0 spec → `proto/gen/openapi.yaml`, embedded into the binary by `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/service.go:78`.
- TypeScript client types → `web/src/types/proto/`.

Serving:
- `server/router/api/v1/v1.go:64` `RegisterGateway` wires the gRPC-Gateway mux (`RegisterXServiceHandlerServer` for each service) plus the Connect handlers; called from `server/server.go:87`.
- Handler implementations: `server/router/api/v1/*_service.go` on `APIV1Service` (`server/router/api/v1/v1.go:22`).
- Unauthenticated endpoints are listed in `server/router/api/v1/acl_config.go` (`PublicMethods`), described there as the single source of truth for public methods.

Generated files under `proto/gen/` and `web/src/types/proto/` must not be hand-edited — change the `.proto` and regenerate (`AGENTS.md`).
