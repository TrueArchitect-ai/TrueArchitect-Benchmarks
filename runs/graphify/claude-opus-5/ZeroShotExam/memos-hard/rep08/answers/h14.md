**Computation site; triggers; extracted properties**

**Computation site** — `memopayload.RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-based markdown service `ExtractAll()` in `internal/markdown/markdown.go:356` (single AST walk). The result is written back onto the memo as `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`), persisted in the `MemoPayload` proto (`proto/store/memo.proto:8-22`).

**Triggers** — recomputation happens on content-writing operations only:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store write.
- `UpdateMemo`, only when the update mask contains `content` — `server/router/api/v1/memo_service.go:446-449`; the rebuilt payload is put in `update.Payload` alongside the new content. Other mask paths (visibility, pinned, state, create_time…) do not recompute.
- Bulk backfill: `memopayload.Runner.RunOnce()` (`server/runner/memopayload/runner.go:26-71`) walks all memos in batches of 100, rebuilding and re-saving each payload. Note this Runner type is currently not wired up anywhere in `server/server.go` (only `s3presign` is invoked there) — the live paths are the two API handlers.

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go:370-420`):
- `Tags` — all memo tag nodes, deduplicated preserving case; and `Mentions` (lowercased usernames) are also returned but only mentions are consumed separately (`server/router/api/v1/memo_mention_helpers.go:32`); `RebuildMemoPayload` stores only `Tags` and `Property`.
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any task checkbox node.
- `Property.HasIncompleteTasks` — any task checkbox that is unchecked.

These stored properties back the list/filter features: filter fields `property.hasLink` etc. (`internal/filter/schema.go:224`, `store/memo.go:84-90`), stats (`server/router/api/v1/user_service_stats.go:151,267`), and the API `Memo.Property` (`server/router/api/v1/memo_service_converter.go:323`). A standalone `ExtractProperties()` (`internal/markdown/markdown.go:193`) computes the same property set but is unused outside tests. Separately, the list `snippet` is *not* stored — it is derived per-request at conversion time via `getMemoContentSnippet` (`server/router/api/v1/memo_service_converter.go:76`).
