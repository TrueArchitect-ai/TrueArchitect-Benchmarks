**Premise correction:** There is no GraphQL in this repository. A repo-wide search for `graphql`/`gql` (excluding `.git` and `graphify-out`) returns only one hit — a base64 integrity hash in `web/pnpm-lock.yaml:734` — i.e. no schema, no resolvers, no client. Memos has no GraphQL API surface at all.

**Actual API surface:** the public API is defined in **Protocol Buffers** under `proto/api/v1/`, one `.proto` file per service:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Design conventions follow Google AIPs (`proto/api/v1/README.md`). Each RPC carries a `google.api.http` annotation that defines its REST mapping — e.g. `CreateMemo` → `POST /api/v1/memos`, `ListMemos` → `GET /api/v1/memos` (`proto/api/v1/memo_service.proto:17-31`).

Code generation is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/` — protobuf Go types, gRPC stubs, Connect handlers, grpc-gateway, an OpenAPI spec (`proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`), and TypeScript clients emitted to `web/src/types/proto`.

Three protocols are served off that one schema, wired in `server/router/api/v1/v1.go:64-145`:
- **REST/JSON** via grpc-gateway at `/api/v1/*` and `/file/*`
- **Connect/gRPC** at `/memos.api.v1.*` (handlers registered in `server/router/api/v1/connect_handler.go:31-50`)
- plus an SSE endpoint registered alongside the gateway group

Non-proto side routes exist too: RSS (`server/router/rss`) and MCP (`server/router/mcp`), registered in `server/server.go:85-96`. The README describes the public surface as "full REST and gRPC APIs."
