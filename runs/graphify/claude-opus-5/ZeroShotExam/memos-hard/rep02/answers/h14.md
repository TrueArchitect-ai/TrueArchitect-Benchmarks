**Computation site**

`memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` is the single entry point. It delegates the actual parsing to the goldmark-based markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (a sibling `ExtractProperties`, `internal/markdown/markdown.go:193`, computes the same properties in isolation). `RebuildMemoPayload` assigns both `memo.Payload.Tags` and `memo.Payload.Property` from a single AST walk (`runner.go:82-83`).

**Triggers**

- **Create memo** — `server/router/api/v1/memo_service.go:108`, in `CreateMemo` before `Store.CreateMemo`.
- **Update memo, only when `content` is in the update mask** — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written via `update.Payload = memo.Payload` (`memo_service.go:451`). Other mask paths (visibility, pinned, …) do not recompute it.
- **Bulk backfill** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` rebuilds payloads for every memo in batches of 100. Note this runner type is not currently wired into `server/server.go` (only `s3presign`'s runner is, at `server/server.go:163`); the only live call sites today are the two in `memo_service.go`.

**Extracted properties**

From the walk in `internal/markdown/markdown.go:383-407` (mirrored at `:205-227`), stored as `MemoPayload.Property` (`proto/store/memo.proto:15-22`) and exposed OUTPUT_ONLY as `Memo.property` (`proto/api/v1/memo_service.proto:256, 272-279`) via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`):

- `title` — text of the first block-level child of the document if it is an H1 heading (`markdown.go:387`, via `extractHeadingText`).
- `has_link` — any `KindLink` node.
- `has_code` — any code block, fenced code block, or inline code span.
- `has_task_list` — any task checkbox node.
- `has_incomplete_tasks` — a task checkbox with `IsChecked == false`.

The same walk also collects `Tags` and `Mentions` (`markdown.go:377-382`); tags land in the payload alongside the property, while mentions are used by `server/router/api/v1/memo_mention_helpers.go:32`. The boolean flags are consumed for user stats in `server/router/api/v1/user_service_stats.go:141-151` and `:257-267`.
