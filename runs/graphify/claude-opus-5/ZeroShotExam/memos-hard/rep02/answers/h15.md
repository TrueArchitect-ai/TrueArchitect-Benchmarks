Memo visibility is enforced at many independent server surfaces — the Connect/gRPC API is only one of them. Distinct enforcement sites:

**Core API — single-memo read guard**
- `checkMemoReadAccess` (archived → creator only; non-public → auth required; private → creator only), called by `GetMemo`, the parent-memo check, and `ListMemoComments` — `server/router/api/v1/memo_service.go:39-67` (call sites `:356`, `:367`; `server/router/api/v1/memo_service_comments.go:148`)

**Core API — list/query-level filtering**
- `ListMemos` visibility narrowing (anon → `PUBLIC`; authed → `creator_id == me || visibility in ["PUBLIC","PROTECTED"]`) — `server/router/api/v1/memo_service.go:218-227`
- `ListMemoComments` comment filter — `server/router/api/v1/memo_service_comments.go:157-161`
- `batchConvertMemoRelations` relation/backlink filter — `server/router/api/v1/memo_service_converter.go:180-187`
- User stats (`ListAllUserStats`, `GetUserStats`) — `server/router/api/v1/user_service_stats.go:83-92`, `:217-221`

**Attachment surfaces (visibility inherited from linked memo)**
- `checkAttachmentAccess`, used by `GetAttachment` — `server/router/api/v1/attachment_service.go:421-459`
- `ListMemoAttachments` inline check — `server/router/api/v1/memo_attachment_service.go:213-226`
- Raw file serving over HTTP, incl. anonymous-instance rule and `share_token` fallback — `server/router/fileserver/fileserver.go:677-701`

**Reactions & comments (write paths)**
- `ListMemoReactions` / `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:29-41`, `:82-85`
- `CreateMemoComment` (private parent → creator/admin only; comment inherits parent visibility) — `server/router/api/v1/memo_service_comments.go:33-52`

**Realtime delivery**
- `SSEClient.canReceive` — per-client broadcast filter, denies unknown visibilities — `server/router/api/v1/sse_hub.go:134-144` (visibility stamped onto events in `server/router/api/v1/sse_event_helpers.go:29-37`)

**Notifications**
- Email dispatch `canViewerAccessMemo` — `server/notification/email.go:306-320`
- Mention notifications/inbox `canUserAccessMentionContext` / `shouldSkipMentionInbox` — `server/router/api/v1/memo_mention_helpers.go:52-89`

**Unauthenticated/public surfaces (hardcoded to `PUBLIC`)**
- RSS feeds (instance + per-user) — `server/router/rss/rss.go:90`, `:141`
- Sitemap XML — `server/router/frontend/frontend.go:150`

**Deliberate bypass (share links)**
- `GetMemoByShare` returns a memo regardless of visibility once a valid, non-expired token resolves; only archived/missing are hidden — `server/router/api/v1/memo_share_service.go:153-192` (token validity in `getActiveMemoShare` `:199`)

**Underlying mechanism (not a policy decision, but where it's applied)**
- `FindMemo.VisibilityList` / `Filters` → SQL `WHERE visibility IN (...)` — `store/db/sqlite/memo.go:96-102`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`
