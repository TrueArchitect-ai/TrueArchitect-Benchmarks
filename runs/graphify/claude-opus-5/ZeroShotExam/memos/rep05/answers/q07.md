**`web/src/connect.ts`**

All ConnectRPC service clients are created there. The file builds a single `createConnectTransport` (binary format, `window.location.origin` base URL, credentials-aware fetch, auth interceptor) at `web/src/connect.ts:184`, then exports the clients via `createClient(...)`:

- `instanceServiceClient`, `authServiceClient`, `userServiceClient` — `web/src/connect.ts:192-194`
- `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient` — `web/src/connect.ts:197-200`
- `identityProviderServiceClient` — `web/src/connect.ts:203`

It also creates a separate `refreshAuthClient` on its own interceptor-free transport for token refresh (`web/src/connect.ts:65-72`), avoiding recursion in the auth interceptor.
