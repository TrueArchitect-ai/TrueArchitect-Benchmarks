**`store.Driver` — `store/driver.go`**

The interface is declared at `store/driver.go:9` as `type Driver interface { ... }`, documented as "an interface for store driver. It contains all methods that store database driver should implement." It covers `GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`, plus CRUD methods for every model (Attachment, Memo, MemoRelation, InstanceSetting, User, UserSetting, IdentityProvider, Inbox, Reaction, MemoShare, UserIdentity).

Three backends implement it, each returning `store.Driver` from its `NewDB` constructor:
- `store/db/sqlite/sqlite.go:24`
- `store/db/mysql/mysql.go:20`
- `store/db/postgres/postgres.go:21`

They're selected at runtime by `NewDBDriver` in `store/db/db.go:14`, which switches on `profile.Driver` (`sqlite`/`mysql`/`postgres`). The `Store` type in `store/store.go` holds one such `Driver` and delegates to it.
