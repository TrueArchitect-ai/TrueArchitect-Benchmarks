**Tables affected: `memo`, `memo_relation`, `attachment`, and `memo_share` (DB-level cascade, Postgres/MySQL only).**

**Call chain:** `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`) → `Store.DeleteMemo` (`store/memo.go:140`) → driver `DeleteMemo`.

| Table | How it's affected |
|---|---|
| `memo` | The memo row itself: `DELETE FROM memo WHERE id = ?` (`store/db/sqlite/memo.go:237`, `store/db/postgres/memo.go:244`, `store/db/mysql/memo.go:259`). Also **comment memos** — the API first lists `MemoRelationComment` relations pointing at the memo and calls `Store.DeleteMemo` on each child (`server/router/api/v1/memo_service.go:567-577`), so multiple `memo` rows can be removed. |
| `memo_relation` | Explicit cascade code in `store/memo.go:142-147`: two `DeleteMemoRelation` calls, one on `memo_id` and one on `related_memo_id`, so both directions are cleaned (`store/db/sqlite/memo_relation.go:137`). |
| `attachment` | Explicit cascade code in `store/memo.go:149-157`: lists attachments by `MemoID` and calls `Store.DeleteAttachment` per row (`store/attachment.go:132`), which also removes the backing local/S3 object before the row delete (`store/db/sqlite/attachment.go:211`). |
| `memo_share` | Not touched by any code path; relies on the schema FK `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/postgres/LATEST.sql:108`, `store/migration/mysql/LATEST.sql:108`, `store/migration/sqlite/LATEST.sql:109`). |

Two caveats worth flagging:

- **SQLite does not get the `memo_share` cascade.** The connection is opened with `_pragma=foreign_keys(0)` (`store/db/sqlite/sqlite.go:53`), so the FK is inert and `memo_share` rows are left orphaned on SQLite deployments. Postgres/MySQL enforce it.
- **`reaction` is not cleaned up.** `DeleteMemo` only *reads* reactions to build the webhook payload (`server/router/api/v1/memo_service.go:545-550`); there is no `DeleteReaction` call, and `reaction` links by `content_id` (memo name string) with no FK (`store/migration/*/LATEST.sql`, `reaction` table). Reaction rows survive the memo.
