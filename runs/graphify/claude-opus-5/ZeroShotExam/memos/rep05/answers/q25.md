**Mechanism (one sentence):** `MemoService.ListMemos` (`server/router/api/v1/memo_service.go:210-215`) validates `request.Filter` with `validateFilter` (`server/router/api/v1/shortcut_service.go:336`) and stashes it in `store.FindMemo.Filters`; each dialect driver then calls `filter.DefaultEngine()` + `filter.AppendConditions(..., filter.DialectSQLite|MySQL|Postgres, &where, &args)` (`store/db/sqlite/memo.go:57-63`, `store/db/mysql/memo.go:65-71`, `store/db/postgres/memo.go:54-60`), which runs the three-phase pipeline — `cel-go` compiles the string against the memo-specific CEL env in `internal/filter/schema.go`, `internal/filter/parser.go` lowers the AST into a dialect-agnostic condition IR (`internal/filter/ir.go`), and `internal/filter/render.go` walks that IR emitting a dialect-specific SQL fragment plus placeholder args that get appended to the query's `WHERE` clause.

Supporting details:

- Entry point / glue: `Engine.Compile` → `Engine.CompileToStatement` → `Program.Render` in `internal/filter/engine.go:47-95`; `DefaultEngine()` is a lazily-built process-wide singleton (`internal/filter/engine.go:108`), with a parallel `DefaultAttachmentEngine()` for attachment filters.
- Dialect enum: `DialectSQLite` / `DialectMySQL` / `DialectPostgres` in `internal/filter/schema.go:10-16`.
- Dialect divergence lives entirely in the renderer: `?` vs `$n` placeholders (offset-tracked via `RenderOptions.PlaceholderOffset` so fragments compose with pre-existing args, `internal/filter/helpers.go:9-24`), JSON access on `memo.payload` (`json_extract` / `JSON_EXTRACT` / `->>`), tag membership (`LIKE` vs `JSON_CONTAINS` vs `@>`), `LIKE` vs `ILIKE`, regex `REGEXP` vs `~`, and per-element iteration for `all()`/`exists_one()` (`json_each` / `JSON_TABLE` / `jsonb_array_elements_text`) — see `internal/filter/render.go:231-800` and the per-dialect tests in `internal/filter/engine_test.go:93-167`.
- Timestamps (`now`, `duration(...)`, `timestamp(...)`) constant-fold to epoch seconds at compile time, with `now` frozen once per compile (`internal/filter/engine.go:15-20`, `internal/filter/parser.go:11-16`).
- ListMemos also appends a synthesized CEL filter for visibility/ACL (`creator_id == N || visibility in ["PUBLIC","PROTECTED"]`, `server/router/api/v1/memo_service.go:224`), so the same engine handles both user-supplied and internal predicates.
