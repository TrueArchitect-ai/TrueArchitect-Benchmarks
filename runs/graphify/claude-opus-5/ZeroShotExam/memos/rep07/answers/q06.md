**`memo_relation`**

The table stores links between a memo and another related memo, with a relation type:

- `store/migration/sqlite/LATEST.sql:47-52` — `CREATE TABLE memo_relation (memo_id, related_memo_id, type, UNIQUE(memo_id, related_memo_id, type))`
- Equivalent definitions exist for the other drivers in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`
- Store layer: `store/memo_relation.go`, with driver implementations in `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, `store/db/mysql/memo_relation.go`
- API layer: `server/router/api/v1/memo_relation_service.go`

The `type` column distinguishes relation kinds (e.g. `REFERENCE` vs `COMMENT`), so comment threading is also stored here.
