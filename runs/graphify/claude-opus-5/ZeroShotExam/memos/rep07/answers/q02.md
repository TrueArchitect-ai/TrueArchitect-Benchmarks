- `store/migration/` contains exactly three dialect subdirectories: `sqlite/`, `mysql/`, `postgres/` — each with versioned folders (e.g. `0.2` … `0.30`) plus a `LATEST.sql`.
- `store/migrator.go:44-45` embeds the whole `migration` tree via `//go:embed migration`, and `store/migrator.go:254-256` selects the dialect directory at runtime with `fmt.Sprintf("migration/%s/", s.profile.Driver)`.
