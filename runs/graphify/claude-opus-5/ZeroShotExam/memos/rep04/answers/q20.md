**Mechanism:** Server-Sent Events (SSE) over plain HTTP — a GET `/api/v1/sse` endpoint that writes `Content-Type: text/event-stream` (plus `Cache-Control: no-cache`, `Connection: keep-alive`, `X-Accel-Buffering: no`), authenticated by Bearer token, with a 30s heartbeat (`server/router/api/v1/sse_handler.go`). The browser side consumes it in `web/src/hooks/useLiveMemoRefresh.ts` (fetch-based stream against `/api/v1/sse`, not the native `EventSource`).

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`, a mutex-guarded client set, and 32-event buffered channels per client so slow readers don't block broadcasting. It is created in `server/router/api/v1/v1.go:57` (`SSEHub: NewSSEHub()`), routed at `v1.go:125` via `RegisterSSERoutes`, and closed on shutdown in `server/server.go:205-206`. Event types: `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`.

**Handlers that broadcast:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`; suppressed via a context key when invoked from `CreateMemoComment`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created` on the parent memo)
- `UpdateMemo` — `server/router/api/v1/memo_service.go:513`, via the shared helper
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48`, via the shared helper
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48`, via the shared helper
- `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:106` (`reaction.upserted`)
- `DeleteMemoReaction` — `server/router/api/v1/reaction_service.go:161` (`reaction.deleted`)

The last three memo mutations funnel through `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66-79`), which fires the memo-updated webhook and then `SSEHub.Broadcast` with `memo.updated`. Each event carries `Visibility` and `CreatorID` (JSON-excluded) for server-side per-client delivery filtering.
