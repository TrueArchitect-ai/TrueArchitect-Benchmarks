**`store.Driver` — `store/driver.go`**

The interface is declared at `store/driver.go:9` as `type Driver interface` ("an interface for store driver. It contains all methods that store database driver should implement"). It covers connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD methods for every model — Attachment, Memo, MemoRelation, InstanceSetting, User, UserSetting, IdentityProvider, Inbox, Reaction, MemoShare, and UserIdentity.

Three backends implement it, each constructed via `NewDB(profile)`:
- `store/db/sqlite/` (`sqlite.go`)
- `store/db/mysql/` (`mysql.go`)
- `store/db/postgres/` (`postgres.go`)

The selection happens in `store/db/db.go` — `NewDBDriver(profile *profile.Profile) (store.Driver, error)` switches on `profile.Driver` and returns the matching implementation.
