**Go `embed.FS` (compile-time embedding) served via Echo static middleware + SPA fallback; `server/router/frontend/frontend.go`**

How it's wired:

- `server/router/frontend/frontend.go:22-23` — `//go:embed dist/*` embeds `server/router/frontend/dist` into the binary as `embeddedFiles`, exposed as an `fs.FS` via `getFileSystem("dist")`.
- `FrontendService.Serve` registers `middleware.StaticWithConfig` with that filesystem, plus `spaFallbackMiddleware`, which serves `index.html` on any 404 for extension-less/`/` paths so client-side routing works. A skipper excludes `/api`, `/file`, `/memos.api.v1*`, `/robots.txt`, `/sitemap.xml`, and `*/rss.xml`, and sets cache headers (`no-cache` for HTML, `max-age=3600` for static, `immutable` for `/assets/`).
- `server/server.go:71-72` — `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` hooks it into the server.
- The compiled assets get there via `web/package.json:11` — `"release": "vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir"`, which must run before the Go build (`scripts/Dockerfile` notes "Please build frontend first"). The checked-in `server/router/frontend/dist/index.html` is a placeholder reading "No embeddable frontend found."
