- `web/package.json:11` — `pnpm release` runs `vite build --outDir=../server/router/frontend/dist --emptyOutDir`, so the compiled React app lands in `server/router/frontend/dist`.
- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` embeds that directory into `embeddedFiles embed.FS`; `getFileSystem("dist")` (line 115) re-roots it via `fs.Sub`.
- `server/router/frontend/frontend.go:54-57` — `middleware.StaticWithConfig` serves the embedded FS, with cache headers set per path (`no-store` for HTML, `max-age=3600, immutable` for `/assets/*`).
- `server/router/frontend/frontend.go:63-80` — `spaFallbackMiddleware` catches 404s on extension-less paths and returns `index.html` so client-side routing works. API paths (`/api`, `/file`, `/memos.api.v1*`) plus `robots.txt`/`sitemap.xml`/`rss.xml` are skipped (line 82).
- `server/server.go:72` — `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` registers it on the Echo server.
