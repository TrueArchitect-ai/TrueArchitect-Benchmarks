Two notes on scope:

- MCP (`server/router/mcp/`) exposes `MemoService_*` operation IDs as tools (`server/router/mcp/catalog.go:12-25`), but it is **not a third transport for the service** — per `server/router/mcp/README.md`, tool calls are translated into `/api/v1/...` HTTP requests replayed against the same Echo server, i.e. it rides on top of the gRPC-Gateway REST protocol.
