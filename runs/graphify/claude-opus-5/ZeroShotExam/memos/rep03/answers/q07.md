**`web/src/connect.ts`**

All ConnectRPC service clients are created there via `createClient(...)` against a shared `createConnectTransport` (`web/src/connect.ts:170`):

- Transport: `createConnectTransport({ baseUrl: window.location.origin, useBinaryFormat: true, ... interceptors: [authInterceptor] })`
- Exported clients: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient`
- Plus a separate `refreshAuthClient` on an interceptor-free transport (`web/src/connect.ts:63-70`) used for token refresh to avoid recursion.

It is the only file in the repo referencing `createClient`/`createConnectTransport`.
