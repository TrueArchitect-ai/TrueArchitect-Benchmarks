**`Driver` — `store/driver.go`**

The interface is declared as `type Driver interface` at `store/driver.go:10`, documented as "an interface for store driver. It contains all methods that store database driver should implement." It spans ~75 methods: connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD sets per model (Attachment, Memo, MemoRelation, InstanceSetting, User, UserSetting, IdentityProvider, Inbox, Reaction, MemoShare, UserIdentity).

Three backends implement it, each with a `*DB` struct in its own package:
- `store/db/sqlite/sqlite.go:24` — `sqlite.NewDB`
- `store/db/mysql/mysql.go:20` — `mysql.NewDB`
- `store/db/postgres/postgres.go:21` — `postgres.NewDB`

Selection happens in `NewDBDriver` at `store/db/db.go:14`, which switches on `profile.Driver` and returns the chosen backend as a `store.Driver`. The `Store` struct then holds this interface value rather than any concrete backend (`store/store.go`).
