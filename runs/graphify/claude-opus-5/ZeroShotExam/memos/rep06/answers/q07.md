**`web/src/connect.ts`**

This is the single module where all ConnectRPC service clients are created. It sets up the transport via `createConnectTransport` (`web/src/connect.ts:184`) with an auth interceptor, then exports the clients created with `createClient` (`web/src/connect.ts:192-203`):

- `instanceServiceClient`, `authServiceClient`, `userServiceClient`
- `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`
- `identityProviderServiceClient`

It also creates a separate interceptor-free transport and `refreshAuthClient` (`web/src/connect.ts:65-72`) used only for token refresh, to avoid recursion through the auth interceptor.
