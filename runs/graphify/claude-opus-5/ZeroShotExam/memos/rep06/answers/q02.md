Evidence:

- `store/migration/` contains exactly three dialect directories: `store/migration/sqlite/`, `store/migration/mysql/`, `store/migration/postgres/` — each with versioned subdirectories (e.g. `0.19` … `0.30`) plus a `LATEST.sql` schema snapshot.
- `store/migrator.go:44-45` embeds the whole `migration` tree via `//go:embed migration`, and `store/migrator.go:141` globs `<driver>*/*.sql` using a driver-derived base path, so the shipped dialects are precisely those three directories.
