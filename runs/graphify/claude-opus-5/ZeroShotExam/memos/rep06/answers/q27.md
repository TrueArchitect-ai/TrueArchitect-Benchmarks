**Go `embed.FS` (compile-time embedding) + Echo static middleware with SPA fallback; `server/router/frontend/frontend.go`**

How it works:

- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` embeds the built frontend into the binary as `embeddedFiles embed.FS`. The build pipeline copies Vite's output into `server/router/frontend/dist` (see `.github/workflows/release.yml:108`, `:146`, `:275` and `.github/workflows/build-canary-image.yml:48`, `:78`, which download the `web` build artifact to that path). Only a placeholder `index.html` is checked in.
- `getFileSystem("dist")` (`frontend.go:115-121`) sub-roots the embedded FS, and `Serve` registers `middleware.StaticWithConfig` over it (`frontend.go:41-57`), with a skipper that bypasses `/api`, `/file`, gRPC-web `/memos.api.v1*`, plus `robots.txt`/`sitemap.xml`/`rss.xml`, and sets cache headers (`no-cache` for HTML, `max-age=3600, immutable` for `/assets/`).
- `spaFallbackMiddleware` (`frontend.go:63-80`) catches 404s on extension-less paths and serves `index.html` from the embedded FS, which is what makes client-side routing work.
- Wired into the server at `server/server.go:71-72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
