**Convergence for delivery:**

The first three funnel through the shared private helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator and their webhooks. `DispatchMemoCommentCreatedWebhook` does not use that helper — it looks up the *related memo owner's* webhooks directly — but both paths build the payload with `convertMemoToWebhookPayload` (`memo_service_webhooks.go:76`) and call `webhook.PostAsync` (`internal/webhook/webhook.go:184`).

`PostAsync` enqueues onto the buffered `asyncPostQueue` (capacity 128, dropping with a warning if full), drained by 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`), which all call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single point where the HTTP POST, HMAC-SHA256 Standard Webhooks signing, and SSRF-guarded delivery via `safeClient` actually happen.
