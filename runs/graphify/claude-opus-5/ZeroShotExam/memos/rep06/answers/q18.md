The `store.Driver` interface is defined in `store/driver.go`. Its three implementations, one per database backend (entry file = the file with the `NewDB` constructor and connection setup):

- `store/db/sqlite/sqlite.go` — package `sqlite`, `sqlite.NewDB`
- `store/db/mysql/mysql.go` — package `mysql`, `mysql.NewDB`
- `store/db/postgres/postgres.go` — package `postgres`, `postgres.NewDB`

Selector:

**NewDBDriver** — `store/db/db.go:14` — switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`, else `errors.New("unknown db driver")`) and returns a `store.Driver`. It's called at startup from `cmd/memos/main.go:57`, and also by test helpers in `store/test/store.go:28,50`.
