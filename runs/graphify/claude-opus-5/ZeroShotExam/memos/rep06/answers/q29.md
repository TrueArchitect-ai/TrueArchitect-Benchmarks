**`web/src/connect.ts`; JWT access token (in-memory + localStorage) and refresh token (HttpOnly cookie), plus PATs server-side; `server/auth`**

**Frontend interceptor** — `web/src/connect.ts:156` defines `authInterceptor`, a Connect-RPC `Interceptor` attached to the single shared transport at `web/src/connect.ts:184-189`. Every service client (memo, user, attachment, AI, shortcut, IdP, instance, auth) is created from that transport, so all API traffic passes through it. It:
- sets `Authorization: Bearer <token>` (`connect.ts:97`),
- preflight-refreshes when the token is within 30s of expiry (`getRequestToken`, `connect.ts:124-150`),
- on a `Code.Unauthenticated` response, refreshes once, replays the request with an `X-Retry` header, and calls `redirectOnAuthFailure()` if that fails (`connect.ts:161-177`).

**Tokens managed** — `web/src/auth-state.ts` holds the short-lived **access token** in memory backed by `localStorage` (`memos_access_token` / `memos_token_expires_at`), synced across tabs via a `BroadcastChannel`. The **refresh token** is never touched by JS — it rides as an HttpOnly cookie, which is why the transport uses `credentials: "include"` (`connect.ts:57-62`) and why refreshes go through a separate interceptor-free transport (`connect.ts:65-72`) to avoid recursion. Concurrent refreshes are deduped by `tokenRefreshManager` (`connect.ts:30-51`), shared with `web/src/hooks/useTokenRefreshOnFocus.ts`.

**Backend validation** — package `server/auth` (`server/auth/token.go`, `authenticator.go`, `extract.go`). It defines the JWT scheme (issuer `memos`, 15-min access tokens with audience `user.access-token`, 30-day refresh tokens in the `memos_refresh` cookie, and `memos_pat_`-prefixed personal access tokens), extracts the bearer token (`extract.go:ExtractBearerToken`), and validates it via `Authenticator.AuthenticateByAccessTokenV2` (stateless JWT parse) or `AuthenticateByRefreshToken` (parse + DB revocation check). It's consumed by the API interceptor in `server/router/api/v1/authz.go` and by `server/router/fileserver/fileserver.go`.
