**Driver — `store/driver.go`**

The interface is `store.Driver`, defined at `store/driver.go:10` ("Driver is an interface for store driver. It contains all methods that store database driver should implement.").

Details:
- It bundles connection methods (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus all per-model CRUD methods (attachment, memo, memo relation, instance setting, user, user setting, identity provider, etc.).
- Three backends implement it, each constructed via `NewDB(profile)`: `store/db/sqlite/`, `store/db/mysql/` (see `store/db/mysql/mysql.go`), and `store/db/postgres/`.
- The dispatch point is `NewDBDriver` in `store/db/db.go`, which returns a `store.Driver` selected by `profile.Driver`.
