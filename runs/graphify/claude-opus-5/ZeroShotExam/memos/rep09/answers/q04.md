**`APIV1Service.SignIn` — `server/router/api/v1/auth_service.go`** (line 51)

The Connect RPC entry point is a thin wrapper that delegates to it:
- `ConnectServiceHandler.SignIn` — `server/router/api/v1/connect_services.go:78`, which wraps the call in `connectWithHeaderCarrier` so the service can set response headers (e.g. the session cookie) protocol-agnostically.
