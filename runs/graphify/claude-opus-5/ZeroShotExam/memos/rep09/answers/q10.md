`store/migration/sqlite/LATEST.sql`

For an uninitialized database, `preMigrate` in `store/migrator.go:210-219` builds the path `s.getMigrationBasePath() + LatestSchemaFileName` (`LatestSchemaFileName = "LATEST.sql"`, `store/migrator.go:56`) and executes that single embedded file as the complete schema, skipping the incremental per-version migrations. For the SQLite driver the base path resolves to `migration/sqlite/`, so the file is `store/migration/sqlite/LATEST.sql` — it contains the full `CREATE TABLE`/index set (system_setting, user, memo, etc.). This is also what `store/test/migrator_test.go:18-25` (`TestFreshInstall`) exercises.
