There is no ORM tag/`TableName()` mapping in this repo — the store layer hand-writes SQL, so the mapping comes from the driver files that reference each table.

| table | Struct — path |

The sibling `Find*`/`Update*`/`Delete*` structs in those same files are query-parameter types, not row mappings.
