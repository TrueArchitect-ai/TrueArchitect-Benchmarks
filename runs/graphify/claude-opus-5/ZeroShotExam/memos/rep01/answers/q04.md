**`APIV1Service.SignIn` — `server/router/api/v1/auth_service.go`**

Defined at `server/router/api/v1/auth_service.go:51`. It handles both auth paths in the `SignInRequest`:

- **Password credentials** — looks up the user by username, verifies with `bcrypt.CompareHashAndPassword`, and rejects if `DisallowPasswordAuth` is set for `RoleUser`.
- **SSO credentials** — delegates to `resolveSSOIdentity` / `resolveSSOUser` in `server/router/api/v1/auth_service_sso.go`.

After rejecting archived users, it calls the helper `APIV1Service.doSignIn` (`server/router/api/v1/auth_service_session.go:24`) to mint the access token and set the refresh-token cookie.

It's wired up as the Connect/gRPC handler via `server/router/api/v1/connect_services.go`, against the service definition generated in `proto/gen/api/v1/apiv1connect/auth_service.connect.go`.
