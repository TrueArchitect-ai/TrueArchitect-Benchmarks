**Answer:** `web/src/connect.ts` (the `authInterceptor`); access token (short-lived JWT, in-memory + localStorage) + refresh token (HttpOnly cookie), plus PATs supported server-side; validated by `server/auth`.

**Frontend — interceptor**
- `web/src/connect.ts:145` defines `const authInterceptor: Interceptor`, registered on the Connect-Web transport (`createConnectTransport({ ..., interceptors: [authInterceptor] })`) that backs every service client (`memoServiceClient`, `userServiceClient`, etc.). It sets `Authorization: Bearer <token>` on each request, and on a `Code.Unauthenticated` response it refreshes once and replays the request with an `X-Retry: true` header; a second failure calls `redirectOnAuthFailure()`.
- A separate `refreshTransport` with `interceptors: []` calls `AuthService.refreshToken` to avoid recursion, and all refreshes funnel through `tokenRefreshManager` so concurrent 401s and focus-triggered refreshes de-duplicate into one request.
- `fetchWithCredentials` sets `credentials: "include"` so the refresh cookie rides along.

**Tokens it manages**
- **Access token** — JWT held in memory and mirrored to `localStorage` (`memos_access_token` / `memos_token_expires_at`) by `web/src/auth-state.ts`; sent as the Bearer header. It's preflight-refreshed when within `REQUEST_TOKEN_EXPIRY_BUFFER_MS` (30s) of expiry, and tabs share fresh tokens over a `BroadcastChannel` (`memos_token_sync`).
- **Refresh token** — never touched by JS; it's the HttpOnly `memos_refresh` cookie (`server/auth/token.go:47`), exchanged via `refreshToken({})`. `web/src/hooks/useTokenRefreshOnFocus.ts` also refreshes proactively on tab focus with a 2-minute buffer.

**Backend validation**
- Package `server/auth` — `authenticator.go` (`AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT`, `Authenticate`), `token.go` (JWT issuing/claims: 15-min access, 30-day refresh, `memos_pat_` PAT prefix), `extract.go` (`ExtractBearerToken`, `ExtractRefreshTokenFromCookie`).
- It's invoked from `server/router/api/v1/connect_interceptors.go:213` (`AuthInterceptor`), which delegates to the shared `Authorizer` in `server/router/api/v1/authz.go` for method-level access checks.
