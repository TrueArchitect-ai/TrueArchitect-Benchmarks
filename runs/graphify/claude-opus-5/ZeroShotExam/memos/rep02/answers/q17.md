**`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`**

- `web/src/hooks/useMemoQueries.ts` holds the memo CRUD React Query hooks: `useMemos` / `useInfiniteMemos` (`listMemos`), `useMemo` (`getMemo`), `useCreateMemo` (`createMemo`), `useUpdateMemo` (`updateMemo`), `useDeleteMemo` (`deleteMemo`), plus `useMemoComments` / `useInfiniteMemoComments` (`listMemoComments`) and `useLinkMetadata` — along with the `memoKeys` query-key factory and optimistic cache patching.
- It imports `memoServiceClient` from `@/connect` (`web/src/connect.ts:5` in the hook; defined at `web/src/connect.ts:197` as `createClient(MemoService, transport)`), where `MemoService` is the generated Connect-ES service from `web/src/types/proto/api/v1/memo_service_pb`.

Related memo-facing hooks that use the same client live in `web/src/hooks/useMemoShareQueries.ts` and `web/src/components/MemoEditor/services/memoService.ts`, but the core CRUD set is in `useMemoQueries.ts`.
