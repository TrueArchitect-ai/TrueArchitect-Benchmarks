**SQLite, MySQL, PostgreSQL**

Evidence:

- `store/migration/` contains exactly three dialect directories: `store/migration/sqlite/`, `store/migration/mysql/`, `store/migration/postgres/`, each with per-version subdirectories (e.g. `0.2` … `0.30` for SQLite; `0.17`–`0.30` for MySQL; `0.19`–`0.30` for Postgres) plus `LATEST.sql` full-schema files.
- `store/migrator.go:39` documents the layout as `store/migration/{driver}/{version}/NN__description.sql`, and `store/migrator.go:44` embeds the whole `migration` tree via `//go:embed migration`, resolving the driver-specific base path at runtime.
- The same three drivers back the data layer: `store/db/sqlite/`, `store/db/mysql/`, `store/db/postgres/`.

Note: seed data (`store/seed/`) is SQLite-only — only migrations ship for all three dialects.
