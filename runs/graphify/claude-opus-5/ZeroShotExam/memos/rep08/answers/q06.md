**`memo_relation`**

Schema (`store/migration/postgres/LATEST.sql:45-51`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It links a source memo (`memo_id`) to a related memo (`related_memo_id`), with `type` distinguishing the kind of link (e.g. `REFERENCE` vs `COMMENT`).
