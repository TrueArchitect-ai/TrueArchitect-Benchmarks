**Convergence for delivery:**

The first three are thin wrappers over the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator, loads their webhooks via `Store.GetUserWebhooks`, builds a payload with `convertMemoToWebhookPayload`, and calls `webhook.PostAsync`. The comment event does the same work inline (it targets the *related* memo's owner rather than the comment creator), so it bypasses the helper but ends at the same call.

All four converge on **`webhook.PostAsync`** → **`webhook.Post`** in `internal/webhook/webhook.go:184` and `:120`. `PostAsync` enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning when full); four worker goroutines started in `init()` (`webhook.go:42`) drain it and invoke `Post`, which marshals the JSON body, adds Standard Webhooks HMAC-SHA256 headers when a signing secret is set, and issues the HTTP POST through `safeClient` — whose `safeDialContext` blocks reserved/private IPs as SSRF protection.
