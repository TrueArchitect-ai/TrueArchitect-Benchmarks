— Premise is wrong: there is no GraphQL schema or GraphQL server in this repo (no match for `graphql` in any Go, TS, proto, or manifest file). The public API is Protobuf-defined and served three ways from `server/router/api/v1/v1.go:65-144`: Connect RPC handlers mounted at `/memos.api.v1.*` (`v1.go:139-144`, implementations in `server/router/api/v1/connect_services.go`), a grpc-gateway REST/JSON mux registering InstanceService, AuthService, UserService, MemoService, AttachmentService, AIService, ShortcutService, IdentityProviderService (`v1.go:99-121`), plus an SSE stream endpoint (`v1.go:125`). Schemas live in `proto/api/v1/*.proto` (generated Go in `proto/gen/api/v1`). Non-gRPC surfaces: the HTTP file server (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), MCP (`server/router/mcp`), and `/healthz` (`server/server.go:66`).
