— Premise is wrong: **there is no GraphQL schema or GraphQL server anywhere** in this codebase (grep for `graphql` in Go sources and `go.mod` returns zero hits). The public API is **Protobuf/gRPC-defined**, with schemas in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1/`. It is exposed over three transports, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`): a **gRPC-Gateway REST/JSON** surface, and **Connect-RPC** handlers mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:131-144`). Additional non-gRPC surfaces are the HTTP file server under `/file` (`server/router/fileserver/fileserver.go:121-124`), RSS (`server/router/rss/rss.go`), and MCP (`server/router/mcp`, wired at `server/server.go:92-96`). API documentation is an embedded OpenAPI spec, not a GraphQL SDL — `proto/openapi_embed.go:5` (`//go:embed gen/openapi.yaml`).
