Delivery function: `webhook.Post` — `internal/webhook/webhook.go:120` (the actual `safeClient.Do(req)` at `internal/webhook/webhook.go:152`); enqueued asynchronously via `webhook.PostAsync` (`internal/webhook/webhook.go:184`) onto a 128-slot channel drained by 4 goroutines (`internal/webhook/webhook.go:39-55`).
Protection: SSRF guard at dial time — `safeDialContext` (`internal/webhook/webhook.go:59-77`) resolves the host and rejects reserved/private IPs via `isReservedIP` (`internal/webhook/validate.go:44-54`) against `reservedCIDRs` (`internal/webhook/validate.go:14-23`, loopback/RFC-1918/link-local incl. 169.254.169.254, IPv6 equivalents). Because the check happens at dial, it also defeats DNS rebinding. A second, up-front check is `webhook.ValidateURL` (`internal/webhook/validate.go:62`), called when a user saves a webhook (`server/router/api/v1/user_service_webhooks.go:74,161,182`). Escape hatch: `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`).
