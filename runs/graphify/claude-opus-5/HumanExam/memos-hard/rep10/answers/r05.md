Premise is wrong — **there is no GraphQL schema or GraphQL server in this project.** No `.graphql`/`.gql` files exist, no GraphQL library is in `go.mod`, and no GraphQL identifiers appear in the Go or frontend sources.
Actual public API surface:
- **Protobuf/gRPC service definitions** — `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto`), generated into `proto/gen/api/v1`.
- Served over HTTP as **Connect RPC + grpc-gateway REST**, registered in `APIV1Service.RegisterGateway` — `server/router/api/v1/v1.go:64+`, wired at `server/server.go:88`.
- Plus non-RPC surfaces: HTTP file server `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/service.go`, tool catalog at `server/router/mcp/catalog.go`), and `/healthz` (`server/server.go:67`).
