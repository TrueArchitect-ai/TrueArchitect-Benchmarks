— False premise: there is no Redis and no Redis configuration anywhere in the repo (`grep -rni redis` over Go/mod/config files returns nothing; `go.mod` has no Redis client). The cache layer is a process-local in-memory cache: `store/cache/cache.go` (`Cache` backed by `sync.Map`, `:65-71`; `New` starts a cleanup goroutine `:73-83`). Three caches are created in `store.New` — `instanceSettingCache`, `userCache`, `userSettingCache` — with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000` (`store/store.go:38-51`; identical `cache.DefaultConfig` at `store/cache/cache.go:56-63`). So user entries expire after **10 minutes**, set via `Set`→`SetWithTTL` (`store/cache/cache.go:89-118`) from `store/user.go:143,167`, and are invalidated explicitly on update/delete (`store/user_delete.go:39-47`).
