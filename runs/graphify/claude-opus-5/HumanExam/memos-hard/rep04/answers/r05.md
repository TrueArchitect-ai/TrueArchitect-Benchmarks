— False premise: there is no GraphQL schema, server, or dependency anywhere in the repo (no `graphql` match in Go sources or `go.mod`). The public API surface is protobuf-defined and served three ways from `server/router/api/v1`: Connect/gRPC handlers and a gRPC-Gateway REST/JSON transcoding layer registered by `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64+`, schemas in `proto/api/v1/*.proto`, generated code in `proto/gen/api/v1/`), plus SSE for live events (`server/router/api/v1/sse_hub.go`). Alongside it: an HTTP file server (`server/router/fileserver/fileserver.go:122-125`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/service.go`, registered `server/server.go:88-93`), and `/healthz` (`server/server.go:64`). An OpenAPI description is generated for MCP at `server/router/mcp/openapi.go`.
