— Premise is wrong: there is no Redis anywhere in the repo (no client dependency, no config). The cache is a process-local in-memory cache: `store/cache/cache.go` (`Cache` struct `:66`, `sync.Map` + TTL sweeper). Three instances are created in `store.New` — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:51-53`) — all with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000` (`store/store.go:40-45`; same defaults in `cache.DefaultConfig()` `store/cache/cache.go:57-63`). So user entries expire 10 minutes after being set (`store/user.go:141-143,147-168`); they are also refreshed on update (`store/user.go:126-133`) and invalidated on delete (`store/user_delete.go:39`).
