— Premise is wrong: there is no GraphQL schema or GraphQL server anywhere (no `graphql` reference in Go, TS, `go.mod`, or `package.json`). The public API is Protobuf-defined RPC exposed three ways: Connect-RPC over `/memos.api.v1.*` (`server/router/api/v1/v1.go:139-144`), gRPC-Gateway REST (`APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65`), and MCP (`server/router/mcp`). Schemas live in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`) with generated code in `proto/gen/api/v1`. Non-RPC HTTP surfaces: `/file/*` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), and `/healthz` (`server/server.go:67`).
