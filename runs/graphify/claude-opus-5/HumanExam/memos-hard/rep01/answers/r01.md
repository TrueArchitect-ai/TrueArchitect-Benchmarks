**Premise is wrong — there is no Redis anywhere in this repo.** No `redis` dependency in `go.mod`/`go.sum` and no Redis reference in any Go file. The cache layer is a **process-local in-memory map** with a background janitor: `store/cache/cache.go` (`Cache` type, `Set` :93, `SetWithTTL` :98, `Close` :187). It is configured in Go, not by connection string — `store.New` at `store/store.go:38-44`: `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`. There are three instances, one of which is `userCache` (`store/store.go:50`), so **user entries use the same 10-minute default TTL** (`Set` → `SetWithTTL(..., c.config.DefaultTTL)`, `store/cache/cache.go:93-94`); user entries are written in `Store.ListUsers`/`GetUser` (`store/user.go:143`, `:167`) and explicitly invalidated on delete (`store/user.go:179`).
