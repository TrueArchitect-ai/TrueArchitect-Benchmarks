— **Delivery function:** `webhook.Post` — `internal/webhook/webhook.go:120-180` (the `safeClient.Do(req)` at `:152`); it is fed asynchronously by `webhook.PostAsync` → `asyncPostQueue` → 4 worker goroutines (`internal/webhook/webhook.go:39-55, 184-196`). — **Protection:** dial-time SSRF guard — `safeClient`'s custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`), which resolves the host and rejects reserved/private IPs (`internal/webhook/webhook.go:59-77`) using `isReservedIP` over `reservedCIDRs` (loopback, RFC-1918, 169.254.0.0/16 IMDS, IPv6 equivalents) — `internal/webhook/validate.go:14-54`. Because the check happens at dial time it also defeats DNS rebinding. A second, config-time check is `webhook.ValidateURL` (`internal/webhook/validate.go:62-83`), used by `CreateUserWebhook`/`UpdateUserWebhook` (`server/router/api/v1/user_service_webhooks.go:74,161,182`). The escape hatch `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) is never set in non-test code, so it defaults to false.
