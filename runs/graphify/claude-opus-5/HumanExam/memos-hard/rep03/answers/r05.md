— **Premise is wrong: there is no GraphQL schema or GraphQL endpoint.** No `.graphql`/`.gql` files exist, and neither `go.mod` nor `web/package.json` contains any GraphQL dependency.
Actual public API surface: **Protocol Buffers / gRPC service definitions** in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), with generated code in `proto/gen/api/v1/`. These are exposed three ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`): a **grpc-gateway REST/JSON mux** mounted at `/api/v1/*` and `/file/*` (`v1.go:95-130`), **Connect RPC handlers** for browser clients (`v1.go:132-140`), and an **SSE** endpoint (`v1.go:124`). Alongside those: plain HTTP file serving under `/file` (`server/router/fileserver/fileserver.go:121-124`), RSS feeds (`server/router/rss/rss.go`), and an MCP endpoint (`server/server.go:92-96`).
