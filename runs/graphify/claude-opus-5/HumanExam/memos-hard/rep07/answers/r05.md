— Premise is wrong: there is no GraphQL schema, server, or dependency. `grep -rni "graphql|gqlgen"` over the Go sources and `go.mod` returns zero hits.
The actual public API surface is Protobuf/gRPC-defined and served three ways:
- Schema of record: `.proto` files in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`; generated Go in `proto/gen/api/v1/`.
- REST/JSON via grpc-gateway, registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65-125`), plus Connect RPC handlers and an SSE endpoint (`server/router/api/v1/v1.go:123-125`).
- Non-gRPC HTTP surfaces: file server `/file/...` (`server/router/fileserver/fileserver.go:122-124`), RSS (`server/router/rss/rss.go:67`), MCP (`server/router/mcp/`, registered `server/server.go:92-96`), and `/healthz` (`server/server.go:64`).
