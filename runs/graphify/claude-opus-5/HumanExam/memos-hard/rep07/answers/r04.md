Actual mechanism: an in-process buffered Go channel. `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:39`) is drained by 4 goroutines started in the package `init()` (`internal/webhook/webhook.go:42-55`), each calling `webhook.Post` (`:120`). Producers use `PostAsync` (`:184-196`), which does a non-blocking send and **drops** the delivery with a warning when the buffer is full (`:189-195`). There is no persistence, no retry, and no cross-process fan-out — the queue dies with the process.
