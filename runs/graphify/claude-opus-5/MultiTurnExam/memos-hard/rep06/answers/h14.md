**Extracted properties.** `RebuildMemoPayload` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns exactly two fields — `Payload.Tags` and `Payload.Property` (`server/runner/memopayload/runner.go:85-86`). A single goldmark AST walk (`internal/markdown/markdown.go:369-411`) produces:

- **`Tags`** — every `#tag` node, deduplicated with case preserved via `uniquePreserveCase` (`internal/markdown/markdown.go:417`)
- **`Property.Title`** — text of the H1 heading, only when it is the document's first block-level child (`internal/markdown/markdown.go:383-389`)
- **`Property.HasLink`** — any `KindLink` node (`:394`)
- **`Property.HasCode`** — any code block, fenced code block, or code span (`:397`)
- **`Property.HasTaskList`** — any task checkbox (`:400`)
- **`Property.HasIncompleteTasks`** — a task checkbox that is unchecked (`:402-404`)

These map to `storepb.MemoPayload.Tags` and `storepb.MemoPayload_Property` (`proto/gen/store/memo.pb.go:28` and `:85-92`), persisted as the JSON `payload` column (marshalled in the driver INSERT, e.g. `store/db/sqlite/memo.go:21-25`).

Two things `ExtractAll` computes that are *not* stored in the payload: `Mentions` (returned in `ExtractedData` and used for mention notifications via `server/router/api/v1/memo_mention_helpers.go:32`, but never assigned to the payload) and `Location`, which is user-supplied rather than derived and is set separately at `server/router/api/v1/memo_service.go:112`. The list/preview snippet is likewise generated on read via `GenerateSnippet` rather than stored.
