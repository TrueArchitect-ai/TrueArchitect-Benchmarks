**Premise correction: this project has no GraphQL. There is no schema, no resolver layer, and no GraphQL dependency** — searching for `graphql`, `gqlgen`, and `.graphqls` across Go sources, `go.mod`, `package.json`, and the TypeScript frontend returns zero hits.

**Actual API surface — Protobuf/gRPC service definitions, exposed over three transports:**

- **Schema of record:** `.proto` files in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus `common.proto`. Code generation is driven by `proto/buf.gen.yaml`, emitting Go stubs into `proto/gen/api/v1/` (message/gRPC/gateway code) and Connect clients into `proto/gen/api/v1/apiv1connect/`.
- **Transport 1 — REST via gRPC-Gateway.** Eight services are registered onto a `runtime.NewServeMux` in `RegisterGateway` (`server/router/api/v1/v1.go:95-120`), mounted at `/api/v1/*` and `/file/*` (`server/router/api/v1/v1.go:127-129`) with a shared auth middleware and a `maxAPIRequestBytes` cap.
- **Transport 2 — Connect RPC** for browser clients (replacing grpc-web): handlers registered on a dedicated mux at `server/router/api/v1/v1.go:139-141` and mounted on the `/memos.api.v1.*` path prefix (`:144`), wrapped by the metadata, logging, and recovery interceptors (`:133-137`).
- **Transport 3 — SSE** for live updates, registered on the same CORS group at `server/router/api/v1/v1.go:124`.

**The closest thing to a "public API schema document"** is the generated OpenAPI spec, not GraphQL: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` at `proto/openapi_embed.go:5-6` and exposed through `proto.OpenAPIYAML()`. It's consumed at runtime by the MCP service, which parses it to build its tool catalog (`server/router/mcp/service.go:78`, with the spec types in `server/router/mcp/openapi.go:14`).

Beyond the RPC surface there are a few plain HTTP endpoints outside the proto definitions: file serving (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), and frontend/SSR routes including `robots.txt` and the sitemap (`server/router/frontend/frontend.go`).
