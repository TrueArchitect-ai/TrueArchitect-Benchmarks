**Premise correction: there is no GraphQL anywhere in this repository.** No `.graphql`/`.gql` files exist, no `gqlgen`/`graphql-go`/Apollo dependency appears in `go.mod`, and a case-insensitive grep for `graphql` across Go, TS/TSX, and JSON sources returns zero hits. The public API is defined in **Protocol Buffers**, not a GraphQL SDL.

**Actual API surface:**

- **Schema source of truth — Protobuf service definitions** in `proto/api/v1/`: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Each declares a gRPC service with RPCs annotated with HTTP bindings — e.g. `service MemoService` at `proto/api/v1/memo_service.proto:17`, with `CreateMemo`, `ListMemos`, `GetMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, `GetMemoByShare`, etc. Codegen is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`) into `proto/gen/`.
- **Three protocols served from that one schema**, wired in `RegisterGateway` (`server/router/api/v1/v1.go:64`):
  1. **gRPC-Gateway REST/JSON** — a `runtime.ServeMux` (`server/router/api/v1/v1.go:95`) exposing the `google.api.http` bindings from the `.proto` files.
  2. **Connect RPC** — for browser clients, replacing grpc-web; handlers registered on a mux mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:139-144`, generated stubs in `proto/gen/api/v1/apiv1connect/`).
  3. **gRPC** proper, via the generated `*_grpc.pb.go` servers that `APIV1Service` embeds.
- **OpenAPI, not GraphQL, is the published spec**: generated into `proto/gen/openapi.yaml` and embedded in the binary via `//go:embed` at `proto/openapi_embed.go:5`, exposed by `proto.OpenAPIYAML()`.
- **Non-RPC surfaces alongside it**: raw file serving under `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go:67`), the SPA/static frontend plus `robots.txt` and `sitemap.xml` (`server/router/frontend/frontend.go`), and a streamable-HTTP **MCP** endpoint (`server/router/mcp/service.go:107-108`) — which has its own OpenAPI-derived tool catalog (`server/router/mcp/openapi.go`, `catalog.go`).
