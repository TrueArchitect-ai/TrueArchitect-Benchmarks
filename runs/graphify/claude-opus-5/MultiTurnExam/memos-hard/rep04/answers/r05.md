**Premise correction: there is no GraphQL anywhere in this repository.** No `.graphql`/`.gql`/`.graphqls` files exist, and a case-insensitive search for `graphql`, `gqlgen`, or `apollo` across all Go sources, `go.mod`, TypeScript/TSX, and `package.json` returns zero hits. There is no schema to point you at.

**Actual API surface: Protocol Buffers, defined in `proto/api/v1/*.proto`, exposed over three transports.**

**Schema definition.** Eight services in `proto/api/v1/`:

| Service | File |
|---|---|
| `AIService` | `proto/api/v1/ai_service.proto:11` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |

Generated Go lands in `proto/gen/api/v1/`, driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`). Persistence-layer messages live separately in `proto/store/*.proto`.

**Transports**, all wired in `RegisterGateway` (`server/router/api/v1/v1.go:65`):

1. **REST/JSON via grpc-gateway** — each service registered onto `gwMux` (`server/router/api/v1/v1.go:98-124`), served at `/api/v1/*` and `/file/*` (`:127-128`). This is the closest analogue to what you'd query with GraphQL, but it's resource-oriented REST with AIP-style paths, not a single query endpoint.
2. **Connect-RPC** for browser clients — mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:141-144`), with metadata/logging/recovery/auth interceptors (`:133-138`).
3. **Server-Sent Events** for push — `RegisterSSERoutes` (`server/router/api/v1/v1.go:125`).

**Schema discovery for clients** is OpenAPI, not introspection: `proto/gen/openapi.yaml` is generated from the protos and embedded into the binary via `//go:embed` (`proto/openapi_embed.go:4-11`).

Non-proto HTTP surfaces exist alongside these — the file server (`/file/attachments/...`, `/file/users/:identifier/avatar`, `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), and an MCP endpoint (`server/router/mcp/`).
