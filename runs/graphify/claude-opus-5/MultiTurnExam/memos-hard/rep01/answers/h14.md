**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88` — which delegates the parse to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356-422`.

**Triggers (the only two production call sites of `RebuildMemoPayload`):**
1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the row is inserted. This also covers **`CreateMemoComment`**, which delegates to `CreateMemo` at `server/router/api/v1/memo_service_comments.go:55`.
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but *only* inside the `if path == "content"` branch of the update-mask loop (`memo_service.go:436-452`). Other mask paths (`visibility`, `pinned`, etc.) do not recompute; `update.Payload = memo.Payload` is assigned only on that branch.

**What the computation extracts** — `RebuildMemoPayload` writes two fields onto `memo.Payload` (allocating an empty `storepb.MemoPayload` first if nil):
- `Payload.Tags` — every `#tag` node, deduplicated with original case preserved (`internal/markdown/markdown.go:417`).
- `Payload.Property` — the `MemoPayload.Property` message (`proto/store/memo.proto:15-22`):
  - `Title` — text of the first H1 heading, only if it is the document's first block-level child (`markdown.go:383-388`)
  - `HasLink` — any `KindLink` node
  - `HasCode` — any code block, fenced code block, or code span
  - `HasTaskList` — any task checkbox
  - `HasIncompleteTasks` — any unchecked task checkbox

`ExtractAll` does this in a single `gast.Walk` over the goldmark AST. It also collects `Mentions`, but `RebuildMemoPayload` deliberately copies only `Tags` and `Property` onto the payload (`runner.go:85-86`) — mentions are used separately for notifications (`server/router/api/v1/memo_mention_helpers.go:32`).

Two things worth noting:

- **`Location` is not derived** — it is user-supplied and assigned *after* the rebuild (`server/router/api/v1/memo_service.go:112-113`), which matters because `RebuildMemoPayload` preserves the existing payload rather than replacing it.
- **The preview snippet is not part of this stored metadata.** It is computed on read at conversion time via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-85`, called from `server/router/api/v1/memo_service_converter.go:76` and `server/router/api/v1/memo_relation_service.go:154,162`), so it never goes stale but costs a parse per response.
- There is also a batch backfill, `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`), which would rebuild every memo's payload — but nothing constructs that runner, so it never executes.
