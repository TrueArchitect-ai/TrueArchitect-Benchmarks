**`(*sqlite.DB).CreateMemo` — `store/db/sqlite/memo.go:16` (the `INSERT INTO \`memo\` ... RETURNING id, created_ts, updated_ts, row_status` is built and executed at `store/db/sqlite/memo.go:41-49`); determined by resolving the runtime value of `profile.Driver` from the CLI defaults through the factory `switch`, since the call site is an interface dispatch with three implementations**

The three candidates are identical in signature — `store/db/sqlite/memo.go:16`, `store/db/postgres/memo.go:16`, `store/db/mysql/memo.go:16` — all satisfying `CreateMemo` on the `store.Driver` interface (`store/driver.go:29`). Static reading of the call chain can't pick among them, so I traced the configuration instead:

1. **Handler → store.** `CreateMemo` RPC calls `s.Store.CreateMemo` (`server/router/api/v1/memo_service.go:114`).
2. **Store → interface.** `Store.CreateMemo` validates the UID then delegates: `return s.driver.CreateMemo(ctx, create)` (`store/memo.go:109-114`). `s.driver` is typed `store.Driver`, so this is where the three candidates diverge.
3. **What fills `s.driver`.** `main` builds it once: `db.NewDBDriver(instanceProfile)` (`cmd/memos/main.go:57`), passed to `store.New` at `:64`.
4. **The factory switch.** `NewDBDriver` branches on `profile.Driver` (`store/db/db.go:18-27`): `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB`, anything else → error.
5. **Default value of `profile.Driver`.** With no flags, `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the flag default `rootCmd.PersistentFlags().String("driver", "sqlite", ...)` (`:130`) both yield `"sqlite"`; the profile field is populated from `viper.GetString("driver")` (`:43`). Corroborating evidence that sqlite is the default path: `profile.Validate` synthesizes a DSN only for sqlite — `if p.Driver == "sqlite" && p.DSN == ""` → `<data>/memos_prod.db` (`internal/profile/profile.go:110-116`) — whereas `sqlite.NewDB` errors out if the DSN is empty (`store/db/sqlite/sqlite.go:26-28`). Postgres/MySQL have no such fallback, so they can't run without an explicit `--dsn`.

So the switch takes the `"sqlite"` arm, `s.driver` holds a `*sqlite.DB`, and the interface call lands in `store/db/sqlite/memo.go:16`. The `postgres` and `mysql` versions are compiled in but unreachable in a default install.

Note `MEMOS_DRIVER` (env, via `viper.SetEnvPrefix("memos")` + `AutomaticEnv` at `cmd/memos/main.go:167-169`) or `--driver` would change this; the question specifies neither is set.
