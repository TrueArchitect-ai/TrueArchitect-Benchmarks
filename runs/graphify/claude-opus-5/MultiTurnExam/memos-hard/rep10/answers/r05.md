**Premise correction: there is no GraphQL anywhere in this repository — no schema files (`*.graphql`/`*.gql`), no gqlgen/Apollo/graphql-go dependency, and no occurrence of the string "graphql" in any Go, TS, JSON, or module file. The public API is Protobuf/gRPC-defined and exposed as REST-ish JSON, Connect, and MCP.**

Actual API surface:

- **Schema source of truth: Protobuf.** Service and message definitions live in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Persistence-side messages are in `proto/store/`. Codegen is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`) into `proto/gen/`.
- **HTTP/JSON via grpc-gateway.** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`) builds a `runtime.NewServeMux` with an auth middleware and registers all eight service handlers (`v1.go:98-121`), then mounts it on Echo at `/api/v1/*` and `/file/*` (`v1.go:128-129`), wrapped in a max-body limit.
- **Connect-RPC for browser clients** (the replacement for grpc-web): handlers in `server/router/api/v1/connect_services.go`, registered onto a `http.ServeMux` with metadata/logging/recovery/auth interceptors and mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:131-144`). Generated Connect stubs live in `proto/gen/api/v1/apiv1connect/`.
- **OpenAPI, not GraphQL, is the published schema artifact.** `proto/gen/openapi.yaml` is generated from the protos and embedded into the binary via `//go:embed gen/openapi.yaml` (`proto/openapi_embed.go:5`).
- **Non-gRPC HTTP surfaces alongside it:** the file server (`/file/attachments/:uid/:filename`, `/file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), SSE streaming (`RegisterSSERoutes`, `server/router/api/v1/v1.go:124`), and an MCP server (`server/router/mcp/`) that adapts the same v1 services for model-context clients.

If you're looking for the machine-readable contract to hand to a client, that's `proto/api/v1/*.proto` or the generated `proto/gen/openapi.yaml` — there is no schema-first GraphQL layer to find.
