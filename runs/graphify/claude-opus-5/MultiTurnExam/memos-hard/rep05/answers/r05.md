**Premise correction: there is no GraphQL anywhere in this repository — no schema files, no `.graphql`/`.gqls` documents, no `gqlgen`/`graphql-go` dependency, and no GraphQL resolvers or client code. A case-insensitive grep for `graphql|gqlgen|\.graphql` across Go, `go.mod`, JSON, and TS/TSX sources returns zero hits. The public API is defined with Protocol Buffers, not a GraphQL SDL.**

**Actual API surface:**

- **Schema source of truth**: `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and shared `common.proto`. Storage-layer messages live separately in `proto/store/`. Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`).

- **Generated Go bindings**: `proto/gen/api/v1/` — for each service, a `*.pb.go` (messages), `*_grpc.pb.go` (gRPC server/client), and `*.pb.gw.go` (grpc-gateway REST transcoding), plus Connect handlers under `proto/gen/api/v1/apiv1connect/`.

- **Three transports are served from one implementation**, wired in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):
  1. **gRPC-Gateway REST/JSON** — the gateway mux wrapped and mounted at `server/router/api/v1/v1.go:126`.
  2. **Connect RPC** — `NewConnectServiceHandler(s)` registered at `v1.go:140-141` and mounted on the path prefix `/memos.api.v1.*` at `v1.go:144`.
  3. **gRPC proper**, via the generated service servers that `APIV1Service` embeds (`server/router/api/v1/v1.go:20-32`, the `Unimplemented*ServiceServer` embeds).

  Both muxes are size-capped with `http.MaxBytesHandler(..., maxAPIRequestBytes)` (`v1.go:126`, `:144`).

- **The published API description is OpenAPI, not a GraphQL schema**: `proto/gen/openapi.yaml`, generated from the protos and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-11`.

- **Non-RPC HTTP surfaces** exist alongside it and are also not GraphQL: raw file serving at `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), the MCP endpoint (`server/router/mcp/`), and the frontend/static routes (`server/router/frontend/frontend.go`).
