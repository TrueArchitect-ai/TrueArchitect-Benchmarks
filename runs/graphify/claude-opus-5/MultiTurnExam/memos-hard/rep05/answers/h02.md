**`webhook.Post` — `internal/webhook/webhook.go:120` (the actual HTTP send is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`); SSRF protection is the `safeDialContext` dialer + reserved-CIDR check — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44` (`isReservedIP`).**

How it fits together:

**Delivery path**
- Callers dispatch via `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a bounded 128-slot channel `asyncPostQueue` (`webhook.go:39`) and drops the event with a warning if full (`webhook.go:191-195`).
- Four worker goroutines started in `init()` (`webhook.go:42-55`) drain the queue and call `Post`.
- `Post` marshals the payload, adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`) when a signing secret is set (`webhook.go:133-150`), then executes the request through `safeClient` and caps the response read at 1 MiB (`webhook.go:158`).
- Trigger sites are the memo lifecycle dispatchers in `server/router/api/v1/memo_service_webhooks.go` — created/updated/deleted (`memo_service_webhooks.go:15-27`, `:47-72`) and comment-created (`:29-45`).

**Protection**
- Primary, at connection time: `safeClient`'s `Transport.DialContext` is `safeDialContext` (`webhook.go:32-37`, defined at `webhook.go:59-77`). It resolves the hostname itself, rejects the dial if *any* resolved address is reserved, and only then dials. Because the check happens at dial time on every request, it also defeats DNS rebinding — a URL that passed validation but later resolves to an internal IP still fails.
- The blocklist is `reservedCIDRs` in `internal/webhook/validate.go:14-23`: IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (covers cloud IMDS at 169.254.169.254), plus IPv6 `::1/128`, `fc00::/7`, `fe80::/10`. Parsed once into `reservedNetworks` at package init (`validate.go:28-36`).
- Secondary, at configuration time: `webhook.ValidateURL` (`validate.go:62`) enforces http/https scheme and the same reserved-IP check when a user creates or updates a webhook — called from `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. This is a UX guard, not the real boundary; the dialer is.
- Escape hatch: the package-level `AllowPrivateIPs` flag (`validate.go:41`) short-circuits `isReservedIP` for self-hosted deployments targeting LAN services. Note that in the current tree nothing outside the package sets it — it's referenced only by `internal/webhook/webhook_test.go:90-92` and `:141-143`, so there's no CLI flag or env var wiring it up; it defaults to `false` and protection is always on in production.
