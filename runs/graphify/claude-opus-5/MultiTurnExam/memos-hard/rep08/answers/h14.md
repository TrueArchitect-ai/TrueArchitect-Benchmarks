**Computation.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-87`) lazily initializes `memo.Payload`, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns the two derived fields:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

`ExtractAll` (`internal/markdown/markdown.go:356-420`) parses once with goldmark and does a **single AST walk** collecting everything (the comment notes this is the efficient single-pass variant):

- **`Tags`** — every `*ast.TagNode` (from the custom `TagExtension`), deduplicated preserving original case via `uniquePreserveCase`.
- **`Property.Title`** — text of the first block-level child *only if* it is an H1 heading (`markdown.go:383-389`); an H1 further down does not count.
- **`Property.HasLink`** — any `gast.KindLink`.
- **`Property.HasCode`** — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- **`Property.HasTaskList`** — any `east.KindTaskCheckBox`; **`HasIncompleteTasks`** additionally when a checkbox has `!IsChecked`.

(`Mentions` are also gathered in the same walk, lowercased, but `RebuildMemoPayload` doesn't persist them — they drive mention notifications instead.) The persisted shape is `storepb.MemoPayload_Property` (`proto/gen/store/memo.pb.go:85-95`), stored in the memo's `payload` JSON column.

**Triggers.**

1. `CreateMemo` — `server/router/api/v1/memo_service.go:107-109`, before `s.Store.CreateMemo`.
2. `UpdateMemo` — only inside the `if path == "content"` branch of the update-mask loop (`server/router/api/v1/memo_service.go:437-451`); the recomputed payload is assigned to `update.Payload`. Changing visibility, pinning, etc. does not recompute.
3. `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:55` calls `s.CreateMemo` internally, so comments get the same treatment.
4. Not live: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) would rebuild payloads for all memos in batches of 100, but nothing constructs that runner — see the dead-code finding for `RunOnce`.
