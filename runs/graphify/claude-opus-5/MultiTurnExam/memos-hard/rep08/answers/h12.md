**`(*sqlite.DB).CreateMemo` — `store/db/sqlite/memo.go:16`** (the `INSERT INTO \`memo\` ...` statement is built at line 41 and executed via `d.db.QueryRowContext` at line 42).

**Determination method** — I followed the driver value from process start down to the statement, rather than guessing among the three implementations:

1. **The default is `sqlite`, from two independent places.** `cmd/memos/main.go:130` registers the flag with default `"sqlite"` (`PersistentFlags().String("driver", "sqlite", ...)`), and `cmd/memos/main.go:122` sets `viper.SetDefault("driver", "sqlite")`. With no `--driver` flag and no `MEMOS_DRIVER` env var (`viper.SetEnvPrefix("memos")` + `AutomaticEnv()`, `main.go:167-169`), both resolve to `sqlite`. Corroborating: `internal/profile/profile.go:110` has a `sqlite`-specific branch that fabricates the DSN as `<data>/memos_prod.db` when `DSN == ""` — the only driver given that treatment, which is what makes a flagless install work at all.
2. **The profile carries it into the factory.** `main.go:43` reads `Driver: viper.GetString("driver")` into `profile.Profile`, and `main.go:57` calls `db.NewDBDriver(instanceProfile)`.
3. **The factory picks the implementation.** `store/db/db.go:14-27` switches on `profile.Driver`; `case "sqlite":` → `sqlite.NewDB(profile)` (`store/db/db.go:20`). This is the *only* construction site for any of the three drivers — a repo-wide grep for the `store/db/{mysql,postgres,sqlite}` import paths returns hits solely in `store/db/db.go`. So the choice is made exactly once, at startup.
4. **The store is a thin pass-through.** `store.New(dbDriver, instanceProfile)` (`main.go:64`) stores it as `s.driver`; `Store.CreateMemo` (`store/memo.go:109-114`) validates the UID against `base.UIDMatcher` and immediately delegates to `s.driver.CreateMemo`. Since `s.driver` is the concrete `*sqlite.DB` from step 3, the interface dispatch on `store.Driver` (`store/driver.go`) lands in the sqlite package.
5. **The API entry point** is `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:70`), which calls `s.Store.CreateMemo` after `memopayload.RebuildMemoPayload` (`memo_service.go:108`).

The two candidates that do *not* run on a default install are `(*mysql.DB).CreateMemo` in `store/db/mysql/memo.go` and `(*postgres.DB).CreateMemo` in `store/db/postgres/memo.go`. A tell that the sqlite one is the live path for the default config: it uses `?` placeholders and backtick quoting with a `RETURNING` clause (`store/db/sqlite/memo.go:41`), whereas the Postgres implementation uses `$N` placeholders.
