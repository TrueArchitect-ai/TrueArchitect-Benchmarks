**Premise correction: there is no GraphQL anywhere in this repository.** A case-insensitive search for `graphql`, `gqlgen`, and `.graphql` across all Go, TypeScript, JSON, and module files (excluding `node_modules`) returns zero hits. No schema file, no resolvers, no GraphQL dependency in `go.mod` or the frontend package manifest. There is nothing to point at.

**Actual API surface — Protocol Buffers, served three ways from one definition:**

- **Source of truth**: `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Persistence-layer messages live separately in `proto/store/`.
- **Codegen** is driven by buf (`proto/buf.gen.yaml`), which runs six plugins into `proto/gen/`: protobuf-go messages, gRPC stubs, **Connect** handlers, **grpc-gateway** (REST/JSON transcoding), a **gnostic OpenAPI** generator, and `bufbuild/es` emitting TypeScript clients straight into `web/src/types/proto` for the frontend.
- **Served surfaces**:
  1. **Connect RPC** — registered in `server/router/api/v1/connect_handler.go` / `connect_services.go`.
  2. **REST via grpc-gateway** — `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`), wired at `server/server.go:88`.
  3. **Plain HTTP file routes** outside the proto surface, for binary content: `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), plus RSS (`server/router/rss/rss.go`) and the SPA/sitemap handlers (`server/router/frontend/frontend.go`).
- **The machine-readable API description is OpenAPI, not a GraphQL SDL**: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go`. That same spec drives the MCP endpoint — `NewMCPService` loads it and builds tools that proxy in-process to the REST routes (`server/router/mcp/service.go:26-50`).

So if you're looking for "the schema for the public API," the closest equivalents are `proto/api/v1/*.proto` (authoritative) and the generated `proto/gen/openapi.yaml` (published description).
