What it is: the SQL placeholder allocator for the filter-expression compiler. Each call appends a value to `r.args`, bumps `placeholderCounter`, and returns the dialect-correct placeholder — `$N` for Postgres, `?` for MySQL/SQLite (`internal/filter/render.go:842-849`). Because every literal that enters a generated `WHERE` clause must be parameterized, essentially every render path calls it: `renderScalarComparison`, `renderScalarInCondition`, `renderTagEquals`, `renderTagInList`, `renderTagStartsWith`, `renderRegex`, `renderAccessorComparison`, `renderFunctionComparison`, `renderJSONBoolComparison`, `renderElementInCondition`, `elementPredicateSQL`, `foldedLike`, `buildJSONArrayLike`, and `addBoolArg`.
