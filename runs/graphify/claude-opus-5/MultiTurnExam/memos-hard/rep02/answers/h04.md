2. **Only one call site.** A repo-wide grep for `mysql.NewDB` returns a single hit: `store/db/db.go:22`, inside the `case "mysql":` arm of `NewDBDriver` (`store/db/db.go:14-27`) — the driver-selection factory itself, alongside the parallel `sqlite.NewDB` and `postgres.NewDB` arms.

3. **Only one importer.** Grepping for the import path `github.com/usememos/memos/store/db/mysql` across all `.go` files (tests included) yields exactly one line: `store/db/db.go:8`. Since Go requires an import to reference a package's exported identifiers, no other file in the repo — production or test — can construct the driver at all.

The one apparent exception isn't one: `store/db/mysql/auth_config_test.go:12` does `db := &DB{}`, but that's an in-package test (`package mysql`) building a zero-value struct to exercise `IsRetryableAuthenticationMutationError`, not an external construction of a working driver.
