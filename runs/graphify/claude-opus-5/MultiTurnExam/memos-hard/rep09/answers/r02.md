**Premise correction: there is no rate-limiting middleware in this codebase — per-user or otherwise. No registration site and no request limits exist to report.**

Evidence:

- A repo-wide case-insensitive search for `rate limit`, `ratelimit`, `throttl`, `golang.org/x/time/rate`, and `tollbooth` across all `.go` files returns exactly one hit, and it's aspirational prose in a doc comment: "Rate limit email sending to prevent abuse" — `internal/email/doc.go:86`. No implementation follows it.
- `go.mod` declares no rate-limiter dependency (no `golang.org/x/time`, no Echo rate-limit contrib).
- The complete set of Echo middleware registered anywhere is four entries: `middleware.Recover()` and `newCORSMiddleware(profile)` at `server/server.go:51-52`, and the static-file + SPA-fallback handlers at `server/router/frontend/frontend.go:54,59`. Echo ships a `middleware.RateLimiter`, but it is never used.
- The Connect/gRPC side has exactly four interceptors, none of them limiting: `NewMetadataInterceptor` (`server/router/api/v1/connect_interceptors.go:25`), `NewLoggingInterceptor` (`:103`), `NewRecoveryInterceptor` (`:170`), and `NewAuthInterceptor` (`:213`).

**What does exist** — and may be what the question has in mind — are *concurrency* limits, not request-rate limits. These are process-wide semaphores, not per-user, and they make excess requests wait rather than rejecting them:

- `thumbnailSemaphore` — 3 concurrent thumbnail generations, `server/router/api/v1/v1.go:59`; the file server has its own at `server/router/fileserver/fileserver.go:116` via `maxConcurrentThumbnails = 3` (`fileserver.go:46`)
- `imageProcessingSemaphore` — 2 concurrent image operations, `server/router/api/v1/v1.go:60`

There are also unrelated bounded resources that limit throughput incidentally: the 128-slot webhook dispatch queue with 4 workers (`internal/webhook/webhook.go:39,42`), and the SSE hub's non-blocking per-client sends that drop events for slow clients (`server/router/api/v1/sse_hub.go:126-130`). None of these key off user identity.
