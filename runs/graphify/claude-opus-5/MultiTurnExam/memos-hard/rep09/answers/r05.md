**Premise correction: there is no GraphQL in this repository.** Searching for `graphql`, `gqlgen`, `.graphql`, and `.gql` across Go, TypeScript, `go.mod`, and JSON files returns zero hits, and `find` locates no schema files. There is no GraphQL server, resolver, or schema to point to.

**Actual API surface — Protobuf/gRPC as the source of truth, exposed over several transports:**

- **Schema definition:** `.proto` files in `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Persistence-layer messages live separately in `proto/store/`. Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`.

- **Transports**, all registered in `Server.NewServer` (`server/server.go`):
  - **Connect RPC + gRPC-Gateway REST** — `apiV1Service.RegisterGateway(ctx, echoServer)` at `server/server.go:88`; handlers implemented on `APIV1Service` in `server/router/api/v1/`, with generated gateway code in `proto/gen/api/v1/*.pb.gw.go` and Connect stubs in `proto/gen/api/v1/apiv1connect/`.
  - **Native HTTP file server** — `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar`, registered at `server/server.go:82` → `server/router/fileserver/fileserver.go:122-124` (bypasses gRPC for range requests).
  - **RSS feeds** — `server/server.go:85` → `server/router/rss/rss.go`.
  - **MCP (Model Context Protocol)** — `server/server.go:92-96` → `server/router/mcp/service.go`, which builds its tool catalog by parsing the OpenAPI spec at `server/router/mcp/service.go:78`.
  - **SSE** event stream — `server/router/api/v1/sse_handler.go`, on the CORS-enabled group.
  - **Static frontend + `/healthz`** — `server/server.go:67,72`.

- **The generated REST description** is OpenAPI, not GraphQL: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` at `proto/openapi_embed.go:4-5` and exposed through `proto.OpenAPIYAML()`.
