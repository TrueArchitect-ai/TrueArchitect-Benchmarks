**store.Driver — `store/driver.go`** (declared at line 10)

It's the single interface every backend implements, covering connection management (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD for each model — attachments, memos, memo relations, instance settings, users, user settings, identity providers, inboxes, reactions, memo shares, and user identities.

Implementations: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, `store/db/mysql/mysql.go` — each `NewDB` returns `store.Driver`.
