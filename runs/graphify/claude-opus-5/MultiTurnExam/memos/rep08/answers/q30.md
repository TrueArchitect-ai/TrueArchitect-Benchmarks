Both paths then build a payload via `convertMemoToWebhookPayload` and call `webhook.PostAsync(payload)` (lines 43 and 71).

`PostAsync` (`/bench/home/work/internal/webhook/webhook.go:184`) is non-blocking: it pushes onto a buffered channel of 128 and drops with a warning if full. Four worker goroutines started in `init()` (lines 42-54) drain the queue and call `Post`, which signs the request (HMAC-SHA256, Standard Webhooks headers) and sends it through `safeClient` — an HTTP client whose dialer rejects reserved/private IPs to block SSRF and DNS rebinding (lines 28-36).
