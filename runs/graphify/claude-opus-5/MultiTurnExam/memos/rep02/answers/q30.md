**Convergence for delivery:** the three memo-level events funnel through the shared helper `APIV1Service.dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:47`), which resolves the memo creator, loads `Store.GetUserWebhooks`, and enqueues each hook. The comment event skips that helper (it targets the *parent* memo's owner, not the comment's creator) but builds the same payload.

All four then land on **`webhook.PostAsync` — `internal/webhook/webhook.go:184`**, which pushes onto a 128-slot buffered channel drained by 4 worker goroutines started in `init()` (`:42-54`); each worker calls **`webhook.Post` — `internal/webhook/webhook.go:120`**, the function that actually issues the signed HTTP POST.
