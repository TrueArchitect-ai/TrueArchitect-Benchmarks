**store/migration/sqlite/LATEST.sql**

`preMigrate` detects an uninitialized database and applies `getMigrationBasePath() + LatestSchemaFileName` in a single transaction — `store/migrator.go:217-219`, where the base path is `migration/{driver}/` (`store/migrator.go:254-256`) and the constant is `"LATEST.sql"` (`store/migrator.go:56`). For `driver=sqlite` that resolves to the embedded `store/migration/sqlite/LATEST.sql`, which holds the full current schema (all `CREATE TABLE`/index statements, e.g. `memo_relation` at lines 47-52). Incremental migrations under `store/migration/sqlite/0.x/` are skipped for fresh installs; the schema version is stamped directly into `system_setting`.
