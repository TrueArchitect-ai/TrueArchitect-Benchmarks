**web/src/connect.ts**

It's the only file in the frontend that calls `createClient`/`createConnectTransport`. It builds the shared `createConnectTransport` (binary format, `credentials: "include"`, auth interceptor) at `web/src/connect.ts:184` and exports one client per service at lines 192–203: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient`.

The same file also defines a second, interceptor-free transport and `refreshAuthClient` (`web/src/connect.ts:65-72`) used solely for token refresh, to avoid recursion through the auth interceptor.
