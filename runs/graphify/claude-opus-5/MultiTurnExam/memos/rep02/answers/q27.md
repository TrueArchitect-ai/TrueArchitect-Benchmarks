**Mechanism: the Vite build output is embedded into the Go binary with `//go:embed` and served as static files (with SPA fallback) by Echo middleware; path: `server/router/frontend/frontend.go`**

How it fits together:

- `web/package.json:11` — the `release` script runs `vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir`, so the compiled React app lands in `server/router/frontend/dist`.
- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` bakes that directory into `embeddedFiles`, making the binary self-contained (no external asset directory at runtime).
- `FrontendService.Serve` (`server/router/frontend/frontend.go:41-60`) mounts `middleware.StaticWithConfig` over `fs.Sub(embeddedFiles, "dist")`, with a skipper that bypasses API/file paths and sets cache headers — `no-cache` for HTML, `max-age=3600` for static assets, `immutable` for hash-named assets (constants at `:23-27`).
- `spaFallbackMiddleware` (`:62`) serves `index.html` when a route doesn't match a real file, so client-side routing works on deep links; `registerRoutes` adds the remaining frontend-specific routes (e.g. SEO/metadata).
- Wired at startup in `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
