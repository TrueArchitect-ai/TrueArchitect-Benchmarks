**Mechanism: the Vite build output is embedded into the Go binary with `//go:embed` and served as static files by Echo middleware, with an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

Details:

- `//go:embed dist/*` binds the compiled bundle into `embeddedFiles` (`server/router/frontend/frontend.go:20-21`); `getFileSystem("dist")` exposes it as an `fs.FS` via `fs.Sub` (:115-121).
- `FrontendService.Serve` (:41) registers `middleware.StaticWithConfig` over that filesystem (:53-56), plus `spaFallbackMiddleware` (:58, defined :62) which turns 404s on HTML routes into `index.html` so client-side routing works. A skipper excludes API/file paths and sets cache headers (`public, max-age=3600`, and `immutable` for hashed assets — :24-26).
- It also registers `/robots.txt` and `/sitemap.xml` (`registerRoutes`, :123).
- Wired at startup by `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
