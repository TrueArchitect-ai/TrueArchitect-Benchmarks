**store.Driver — `store/driver.go`**

Declared at `store/driver.go:10`. It covers connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus the CRUD methods for every model (attachment, memo, user, inbox, reaction, etc.).

It's implemented by the `DB` struct in each backend package — `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go` (see q03), and `store/db/mysql/mysql.go` — whose `NewDB` constructors return `store.Driver`.
