**MySQL, PostgreSQL, SQLite**

The migration files live in `store/migration/`, which contains exactly three dialect subdirectories — `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/` — each with per-version migration folders (0.17 … 0.30) plus a `LATEST.sql`. This matches the three driver packages under `store/db/` (`store/db/mysql`, `store/db/postgres`, `store/db/sqlite`).

Note: seed data (`store/seed/`) is provided for SQLite only.
