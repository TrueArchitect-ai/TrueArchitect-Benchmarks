**MySQL, PostgreSQL, SQLite**

The migration files live under `store/migration/`, which has exactly three dialect subdirectories — `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/` — each with per-version SQL (e.g. `store/migration/mysql/0.30/00__user_tag_setting.sql`) plus a `LATEST.sql` schema. These match the three driver packages in `store/db/` (`mysql`, `postgres`, `sqlite`).

Note that seed data is SQLite-only (`store/seed/sqlite/01__dump.sql`).
