**CEL (Common Expression Language) via `github.com/google/cel-go` — `internal/filter/`** (entry point `filter.DefaultEngine()` in `internal/filter/engine.go:111`; `go.mod:13` pins `cel-go v0.28.1`)

**Mechanism:** a three-phase pipeline — `cel.NewEnv`/`cel.AstToParsedExpr` parse and type-check the expression against the memo field schema (`internal/filter/schema.go`, `internal/filter/parser.go`), the AST is normalized into a dialect-agnostic IR (`internal/filter/ir.go`), and the renderer (`internal/filter/render.go`) walks that IR to emit a dialect-specific SQL fragment plus bound placeholder args, branching on `DialectSQLite` / `DialectPostgres` / `DialectMySQL` for JSON access, boolean semantics, placeholder style, `LIKE` vs `ILIKE`, and string-length/timestamp functions.

Each driver plugs this into its `ListMemos` query via `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect…, &where, &args)` — e.g. `store/db/sqlite/memo.go:57-61`, with the same pattern in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`. Design notes are in `internal/filter/README.md` and `internal/filter/MAINTENANCE.md`.
