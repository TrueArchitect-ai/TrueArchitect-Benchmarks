**s3presign.Runner — a `time.Ticker` on a 12-hour interval, plus one immediate `RunOnce` at startup**

That is the only background runner the server starts. `Server.startBackgroundRunners` (`server/server.go:153-174`) constructs it with `s3presign.NewRunner(s.Store)`, calls `RunOnce(ctx)` synchronously (line 163), then runs `Run(s3Context)` in a goroutine (lines 166-171). The loop is `time.NewTicker(runnerInterval)` with `runnerInterval = 12 * time.Hour` (`server/runner/s3presign/runner.go:26-30`); it re-presigns S3 object URLs whose last presign is older than ~4 days (line 88). Shutdown cancels its context and waits on the WaitGroup (`server/server.go:176-201`).

Unused scheduling infrastructure — two pieces:

- **`server/runner/memopayload.Runner`** — `NewRunner`/`RunOnce` (`server/runner/memopayload/runner.go:19,27`) are never invoked anywhere. Only the package-level helper `RebuildMemoPayload` (line 74) is used, called inline from the API on memo create and update (`server/router/api/v1/memo_service.go:108` and `:447`), not on any schedule.
