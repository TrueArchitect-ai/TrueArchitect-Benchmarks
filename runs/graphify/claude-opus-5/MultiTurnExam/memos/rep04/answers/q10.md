**store/migration/sqlite/LATEST.sql**

`Store.preMigrate` detects an uninitialized database and applies `getMigrationBasePath() + LatestSchemaFileName` in a single transaction (`store/migrator.go:211-224`). `getMigrationBasePath()` returns `migration/<driver>/` (`store/migrator.go:254-256`) and `LatestSchemaFileName` is `"LATEST.sql"` (`store/migrator.go:56`), so for the `sqlite` driver that resolves to the embedded `migration/sqlite/LATEST.sql` — i.e. `store/migration/sqlite/LATEST.sql` in the repo.
