**`web/src/connect.ts` (state in `web/src/auth-state.ts`); short-lived JWT access token + HTTP-only refresh-token cookie + Personal Access Tokens; `server/auth/`**

How it works:

- **Interceptor:** `authInterceptor` at `web/src/connect.ts:155`, installed on the shared Connect transport (`:187-190`). It attaches `Authorization: Bearer <token>` (`:96`), and on a `Code.Unauthenticated` response refreshes once and replays the request with an `X-Retry` marker, redirecting to login if the refresh fails (`:163-177`). A separate interceptor-free `refreshTransport`/`refreshAuthClient` avoids recursion during refresh (`:64-72`), and `fetchWithCredentials` sets `credentials: "include"` so the refresh cookie is sent (`:57-62`).
- **Tokens managed:**
  1. *Access token* (JWT) — held in memory/localStorage by `web/src/auth-state.ts` (`memos_access_token`), with preflight refresh when within `REQUEST_TOKEN_EXPIRY_BUFFER_MS` (30 s) and a wider 2-minute buffer on tab focus (`auth-state.ts:18-19`); refreshes are deduplicated by `tokenRefreshManager` (`connect.ts:30-88`) and shared across tabs via a `BroadcastChannel` (`auth-state.ts:13, 28-48`).
  2. *Refresh token* — an HTTP-only cookie the browser never reads; exchanged via `AuthService.RefreshToken` (`connect.ts:74`).
  3. *Personal Access Tokens* — same `Authorization: Bearer` header, used by API clients rather than the web UI.
- **Backend validation:** package `server/auth/` — `Authenticator.AuthenticateToUser` (`server/auth/authenticator.go:190`) tries the Authorization header first (access token via `AuthenticateByAccessTokenV2` `:41`, then PAT via `AuthenticateByPAT` `:102`) and falls back to the refresh-token cookie (`AuthenticateByRefreshToken` `:61`, which also checks DB revocation/expiry). JWT parsing/minting is in `server/auth/token.go`, header/cookie extraction in `extract.go`, context propagation in `context.go`. It is wired into the gateway as `gatewayAuthMiddleware` (`server/router/api/v1/v1.go:~75-95`) and used by the SSE endpoint (`server/router/api/v1/sse_handler.go:26`).
