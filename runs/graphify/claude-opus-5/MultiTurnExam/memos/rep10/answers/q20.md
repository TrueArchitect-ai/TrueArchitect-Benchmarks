**Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, SetMemoAttachments, SetMemoRelations, UpsertMemoReaction, DeleteMemoReaction**

**Mechanism.** SSE over the same `/api/v1` group — `RegisterSSERoutes(gwGroup, s.SSEHub, s.Store, s.Secret)` at `server/router/api/v1/v1.go:124`, with the streaming endpoint in `server/router/api/v1/sse_handler.go`.

**Hub.** `SSEHub` in `server/router/api/v1/sse_hub.go:56`, with `NewSSEHub` (:63), `Subscribe` (:71), `Unsubscribe` (:89), `Close` (:99), and `Broadcast` (:115). Per-client filtering is `SSEClient.canReceive` (:134), which gates events by user ID and role so private/protected memos aren't leaked. Event types and payload live in the same file (`SSEEventType` :12, `SSEEvent` :24); helpers for building events are in `server/router/api/v1/sse_event_helpers.go`.
