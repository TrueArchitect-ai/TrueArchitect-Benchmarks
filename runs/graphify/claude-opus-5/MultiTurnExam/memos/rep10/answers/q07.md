**web/src/connect.ts**

All eight service clients are instantiated there from a shared `transport` (`web/src/connect.ts:192-203`): `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. The same file also defines a separate `refreshAuthClient` on its own `refreshTransport` (`web/src/connect.ts:72`), used for token refresh so it bypasses the auth interceptor.
