**web/src/connect.ts**

All the exported service clients are created there (`web/src/connect.ts:192-203`) via `createClient(<Service>, transport)` — one per proto service: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient`.

The same file also builds the shared `transport` with its interceptors, plus a separate `refreshAuthClient` on its own `refreshTransport` (`web/src/connect.ts:72`) — kept distinct so token-refresh calls don't recurse through the auth interceptor.
