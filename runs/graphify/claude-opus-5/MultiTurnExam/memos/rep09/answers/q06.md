**memo_relation**

Defined at `store/migration/sqlite/LATEST.sql:47-52`:
```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It's a join table keyed on the `(memo_id, related_memo_id, type)` triple, so the same pair of memos can be linked under more than one relation type (e.g. reference vs. comment). Equivalent definitions exist in `store/migration/mysql/LATEST.sql` and `store/migration/postgres/LATEST.sql`, with per-dialect access code in `store/db/{sqlite,mysql,postgres}/memo_relation.go` and the store-level model in `store/memo_relation.go`.
