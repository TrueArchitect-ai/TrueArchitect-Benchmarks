**Go `embed.FS` — the built `web/dist` output is compiled into the binary and served by Echo static middleware with an SPA fallback; server/router/frontend/frontend.go**

- `//go:embed dist/*` embeds the build output into `embeddedFiles` (`frontend.go:20-21`); `getFileSystem("dist")` unwraps it with `fs.Sub` (`:115-116`).
- `FrontendService.Serve` mounts it via `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` (`:54-57`), then chains `spaFallbackMiddleware` (`:59`), which serves `index.html` on a 404 for extensionless paths so client-side routes resolve (`:63-78`).
- The skipper sets cache headers per request type (`:92-105`): `no-cache` for HTML, `max-age=3600` for static assets, `immutable` for hash-named ones, and it bypasses static handling entirely for API paths (`shouldSkipFrontendStatic`, `:82`).
- `registerRoutes` (`:123`) adds the dynamic `robots.txt` and `sitemap.xml` endpoints alongside the embedded assets.

The `dist` directory is populated by the frontend build before `go build`; the checked-in `server/router/frontend/dist/` is what the embed directive reads.
