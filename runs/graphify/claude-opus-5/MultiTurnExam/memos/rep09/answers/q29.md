**web/src/connect.ts (authInterceptor, :156); short-lived JWT access token + HTTP-only refresh-token cookie (plus Personal Access Tokens for programmatic clients); server/auth**

**Interceptor** — `authInterceptor` at `web/src/connect.ts:156-178`, installed on the shared Connect transport (`:188`). Per request it fetches a token via `getRequestToken()` and sets `Authorization: Bearer <token>` (`:97-100`). On a `Code.Unauthenticated` response it refreshes once, retries with an `X-Retry: true` marker to prevent loops, and on repeat failure calls `redirectOnAuthFailure()` (`:164-176`).

**Tokens managed:**
- **Access token** — short-lived JWT held in memory/`auth-state`, sent as a bearer header. Refreshed both reactively (on 401) and preflight when `isTokenExpired(REQUEST_TOKEN_EXPIRY_BUFFER_MS)` — the comment at `:136-139` notes this matters for public endpoints like `ListMemos`, where an expired token would silently yield guest-scoped data instead of a 401.
- **Refresh token** — never touched by JS; it rides as an HTTP-only cookie via `fetchWithCredentials` (`credentials: "include"`, `:57-62`). Redemption goes through `refreshAuthClient` on a separate interceptor-free `refreshTransport` (`:65-72`) to avoid recursion, and all callers funnel through `tokenRefreshManager` so concurrent refreshes dedupe against server-side token rotation (`:85-91`).
- **Personal Access Tokens** — not used by the web client, but accepted on the same `Authorization: Bearer` header for API clients.

**Backend validation** — `server/auth`, principally `server/auth/authenticator.go`: `resolveBearer` (:149) branches on the `PersonalAccessTokenPrefix` — no prefix means `AuthenticateByAccessTokenV2` (:41, JWT via `ParseAccessTokenV2`), prefix means `AuthenticateByPAT` (:102, SHA-hash lookup through `GetUserByPATHash` with expiry check). `AuthenticateByRefreshToken` (:61) validates the cookie's token against the DB. Supporting files: `token.go` (parsing/signing), `extract.go` (header/cookie extraction), `context.go` (identity into `context.Context`). It's wired into REST through `gatewayAuthMiddleware` (`server/router/api/v1/v1.go:96-98`) and into Connect through handler options.
