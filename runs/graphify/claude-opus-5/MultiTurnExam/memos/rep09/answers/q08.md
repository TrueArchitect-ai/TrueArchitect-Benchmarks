**Driver — store/driver.go**

Defined at `store/driver.go:10`, with the doc comment "Driver is an interface for store driver. It contains all methods that store database driver should implement."

It covers connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus per-model CRUD groups (attachment, memo, user, etc.). The three implementations are the `DB` structs in `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go` — each `NewDB` returns `store.Driver` rather than the concrete type.
