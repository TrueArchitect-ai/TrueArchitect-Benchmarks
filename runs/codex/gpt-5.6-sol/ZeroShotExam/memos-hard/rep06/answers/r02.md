Premise correction: this repository does not register any per-user API rate-limiting middleware, so there are no per-user request limits to report. The server registers only Echo recovery and CORS middleware in [server/server.go](/bench/repo/server/server.go:50-53). API requests use authentication middleware/interceptors—`gatewayAuthMiddleware` for the gRPC-Gateway and `NewAuthInterceptor` for Connect—in [server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:64-98,131-144), with a 256 MiB body-size cap (`maxAPIRequestBytes`), not a request-rate limit.
