Premise correction: this repository does not define a GraphQL schema; there are no GraphQL/`.graphql` schema files.

Actual API surface: the public API is defined by Protocol Buffer service specifications under [`proto/api/v1/`]( /bench/repo/proto/api/v1 ), including HTTP endpoint annotations such as those in [`proto/api/v1/user_service.proto`](/bench/repo/proto/api/v1/user_service.proto). These generate the REST/OpenAPI surface in [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml), which is embedded by [`proto/openapi_embed.go`](/bench/repo/proto/openapi_embed.go).
