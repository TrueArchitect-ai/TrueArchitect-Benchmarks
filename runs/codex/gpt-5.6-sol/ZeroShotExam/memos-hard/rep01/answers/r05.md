Premise correction: This repository does not define a GraphQL schema; there are no GraphQL schema files or GraphQL server components.

Actual API surface: The public API is defined by Protocol Buffer service definitions in [`proto/api/v1/`]( /bench/repo/proto/api/v1/), including [`memo_service.proto`](/bench/repo/proto/api/v1/memo_service.proto). Those definitions generate the REST/OpenAPI contract at [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml), while Connect handlers are registered in [`server/router/api/v1/connect_handler.go`](/bench/repo/server/router/api/v1/connect_handler.go:30) and REST gateway handlers in [`server/router/api/v1/v1.go`](/bench/repo/server/router/api/v1/v1.go:99).
