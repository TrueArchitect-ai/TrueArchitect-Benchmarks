Premise correction: this repository does not register any per-user API rate-limiting middleware, so it defines no per-user request limits. The server-wide Echo middleware is only recovery and CORS ([server/server.go](/bench/repo/server/server.go:50-52)); the API gateway registers authentication/authorization middleware ([server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:69-98)). The `maxAPIRequestBytes` wrapper is a 256 MiB request-size limit, not a rate limit ([server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:23), [server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:126-129)).
