Premise correction: This repository does not define a GraphQL schema for its public API; no GraphQL schema files or GraphQL server surface are present.

Actual API surface: The public API is defined as Protocol Buffer services and HTTP annotations under [`proto/api/v1/`]( /bench/repo/proto/api/v1), such as [`memo_service.proto`](/bench/repo/proto/api/v1/memo_service.proto). These definitions generate the REST/OpenAPI contract at [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml), with generation configured in [`proto/buf.gen.yaml`](/bench/repo/proto/buf.gen.yaml).
