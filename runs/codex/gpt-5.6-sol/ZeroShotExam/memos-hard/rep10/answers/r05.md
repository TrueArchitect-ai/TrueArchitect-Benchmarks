Premise correction: This repository does not define a GraphQL schema for its public API; no `.graphql`/`.gql` schema files or GraphQL service are present.

Actual API surface: The public API is defined as protobuf services in [`proto/api/v1/`]( /bench/repo/proto/api/v1 ), including services such as `UserService` and `MemoService` with REST mappings like `/api/v1/users` and `/api/v1/memos` (see [`user_service.proto:17-42`]( /bench/repo/proto/api/v1/user_service.proto:17 ) and [`memo_service.proto:17-30`]( /bench/repo/proto/api/v1/memo_service.proto:17 )). These definitions generate the REST/OpenAPI contract at [`proto/gen/openapi.yaml`]( /bench/repo/proto/gen/openapi.yaml ), which is embedded/exposed by [`proto/openapi_embed.go:5-10`]( /bench/repo/proto/openapi_embed.go:5 ).
