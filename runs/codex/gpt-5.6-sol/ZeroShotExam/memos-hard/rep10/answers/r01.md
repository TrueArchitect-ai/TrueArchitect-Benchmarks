Premise correction: no Redis connection is configured for the cache layer; the repository contains no Redis configuration or dependency.

Actual mechanism: the cache is an in-process, thread-safe memory cache (`store/cache/cache.go`). `store/store.go` creates the user cache with `DefaultTTL: 10 * time.Minute` and assigns it via `cache.New(cacheConfig)`. User records are inserted with `s.userCache.Set(...)` in `store/user.go`, so user entries use that 10-minute TTL.
