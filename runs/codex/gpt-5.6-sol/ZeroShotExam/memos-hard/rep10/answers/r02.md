Premise correction: this repository does not register any per-user API rate-limiting middleware, so there are no per-user request-rate limits to report. The server registers only Echo’s recovery and CORS middleware in [server/server.go:50-52](/bench/repo/server/server.go:50), while the API gateway registers authentication middleware in [server/router/api/v1/v1.go:66-98](/bench/repo/server/router/api/v1/v1.go:66). The API does impose a 256 MiB request-body size cap (`maxAPIRequestBytes`), but that is not rate limiting ([v1.go:23](/bench/repo/server/router/api/v1/v1.go:23)).
