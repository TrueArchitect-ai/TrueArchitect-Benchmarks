Premise correction: The cache layer does not use Redis; there is no Redis connection configuration in the repository. It uses a process-local, thread-safe in-memory cache (`sync.Map`) implemented in [`store/cache/cache.go`](/bench/repo/store/cache/cache.go:66).

Actual mechanism: `Store.New` configures all caches—including `userCache`—with `DefaultTTL: 10 * time.Minute` and constructs them via `cache.New(cacheConfig)` in [`store/store.go`](/bench/repo/store/store.go:38). User entries are written with the default TTL through `userCache.Set` in [`store/user.go`](/bench/repo/store/user.go:92), so they expire after 10 minutes (unless explicitly deleted).
