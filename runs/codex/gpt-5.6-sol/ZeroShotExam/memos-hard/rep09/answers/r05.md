Premise correction: This repository does not define a GraphQL schema; there are no GraphQL schema files or GraphQL API implementation. The public API is protobuf-based, with service and HTTP contracts defined in [`proto/api/v1/*.proto`](/bench/repo/proto/api/v1/user_service.proto:1) (for example, `UserService` HTTP routes at lines 17–21).

Actual API surface: The protobuf services are exposed through gRPC-Gateway REST endpoints under `/api/v1/*` and Connect endpoints under `/memos.api.v1.*`, registered in [`server/router/api/v1/v1.go`](/bench/repo/server/router/api/v1/v1.go:95). The generated REST contract is [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml:1), embedded for use by [`proto/openapi_embed.go`](/bench/repo/proto/openapi_embed.go:5).
