Premise correction: This repository does not define a GraphQL schema; no GraphQL schema files or `type Query` surface are present.

Actual API surface: The public API is defined in Protocol Buffer service files under [`proto/api/v1/`]( /bench/repo/proto/api/v1/), with HTTP routes specified via `google.api.http` options (for example, [`user_service.proto`]( /bench/repo/proto/api/v1/user_service.proto:20)). These definitions generate the REST/OpenAPI contract at [`proto/gen/openapi.yaml`]( /bench/repo/proto/gen/openapi.yaml:1), as configured by [`proto/buf.gen.yaml`]( /bench/repo/proto/buf.gen.yaml:20).
