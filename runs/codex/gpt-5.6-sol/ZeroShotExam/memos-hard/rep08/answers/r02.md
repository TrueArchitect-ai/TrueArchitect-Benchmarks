Premise correction: this repository does not register any per-user API rate-limiting middleware, so there are no per-user request-rate limits to report. The Echo server registers only recovery and CORS middleware in [server/server.go](/bench/repo/server/server.go:50-52). API requests use authentication/authorization middleware (not rate limiting) via the gRPC-Gateway mux in [server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:64-98) and Connect auth interceptors in [server/router/api/v1/v1.go](/bench/repo/server/router/api/v1/v1.go:131-144). There is a 256 MiB request-body limit (`maxAPIRequestBytes`), not a request-count limit ([v1.go](/bench/repo/server/router/api/v1/v1.go:20), [v1.go](/bench/repo/server/router/api/v1/v1.go:126-144)).
