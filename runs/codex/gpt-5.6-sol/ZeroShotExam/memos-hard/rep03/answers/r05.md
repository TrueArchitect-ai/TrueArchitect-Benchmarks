Premise correction: There is no GraphQL schema in this repository (no `.graphql`/`.gql` files or GraphQL implementation). The public API is not GraphQL.

Actual API surface: It is defined as versioned Protocol Buffer services in [`proto/api/v1/`]( /bench/repo/proto/api/v1 ), with HTTP REST routes declared via `google.api.http` annotations—for example, [`memo_service.proto`]( /bench/repo/proto/api/v1/memo_service.proto:17 ). The generated REST/OpenAPI surface is [`proto/gen/openapi.yaml`]( /bench/repo/proto/gen/openapi.yaml ), embedded by [`proto/openapi_embed.go`]( /bench/repo/proto/openapi_embed.go:5 ), and handlers are registered through [`server/server.go`]( /bench/repo/server/server.go:88 ).
