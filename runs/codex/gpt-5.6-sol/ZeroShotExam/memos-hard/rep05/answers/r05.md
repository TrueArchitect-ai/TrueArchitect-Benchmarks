Premise correction: This repository does not define a GraphQL schema—there are no GraphQL files or GraphQL dependencies. The public API is defined as Protocol Buffer services under [`proto/api/v1/`]( /bench/repo/proto/api/v1/), such as [`memo_service.proto`](/bench/repo/proto/api/v1/memo_service.proto:17) and the other `*_service.proto` files.

Actual API surface: Those protobuf definitions generate both the REST/gRPC-Gateway and Connect APIs. They are registered in [`server/router/api/v1/v1.go`](/bench/repo/server/router/api/v1/v1.go:64), with REST routes under `/api/v1/*` and Connect routes under `/memos.api.v1.*` ([lines 128–145](/bench/repo/server/router/api/v1/v1.go:128)). The generated REST specification is [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml:1), embedded by [`proto/openapi_embed.go`](/bench/repo/proto/openapi_embed.go:5).
