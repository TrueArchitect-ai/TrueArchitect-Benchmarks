Premise correction: There is no GraphQL schema in this repository.

Actual API surface: the public API is defined as Protocol Buffer services under [`proto/api/v1/`]( /bench/repo/proto/api/v1/), such as `MemoService` and its REST HTTP annotations in [`memo_service.proto`]( /bench/repo/proto/api/v1/memo_service.proto:17). These definitions generate the REST/OpenAPI document [`proto/gen/openapi.yaml`]( /bench/repo/proto/gen/openapi.yaml:1) and are exposed through gRPC-Gateway and Connect handlers in [`server/router/api/v1/v1.go`]( /bench/repo/server/router/api/v1/v1.go:64).
