Premise correction: there is no GraphQL schema. The public API is defined with Protocol Buffers in `proto/api/v1/*.proto` (`AGENTS.md:67`), using Connect RPC/gRPC-Gateway (`AGENTS.md:10`).

Actual API surface: services such as `MemoService` and their REST mappings (e.g. `/api/v1/memos`) are declared in [`proto/api/v1/memo_service.proto:17-30`]( /bench/repo/proto/api/v1/memo_service.proto:17).
