Premise correction: There is no GraphQL schema in this repository. The API design is protobuf-based, documented in [`proto/api/v1/README.md`](/bench/repo/proto/api/v1/README.md:1).

Actual API surface: Service and message definitions live in [`proto/api/v1/*.proto`](/bench/repo/proto/api/v1/memo_service.proto:17), with REST paths specified via `google.api.http` annotations. They are exposed through gRPC-Gateway at `/api/v1/*` and Connect at `/memos.api.v1.*`, as registered in [`server/router/api/v1/v1.go`](/bench/repo/server/router/api/v1/v1.go:95). The generated OpenAPI artifact is [`proto/gen/openapi.yaml`](/bench/repo/proto/openapi_embed.go:5).
