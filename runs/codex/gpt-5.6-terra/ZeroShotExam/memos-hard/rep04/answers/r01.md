Premise correction: No Redis connection is configured; the cache layer is process-local in-memory.

Actual mechanism: `store.New` creates `userCache` with `DefaultTTL: 10 * time.Minute` ([store/store.go:40-53](/bench/repo/store/store.go:40)). The cache uses a thread-safe `sync.Map` ([store/cache/cache.go:66-70](/bench/repo/store/cache/cache.go:66)), and user writes call `Set`, which applies that default TTL ([store/cache/cache.go:92-95](/bench/repo/store/cache/cache.go:92); [store/user.go:98](/bench/repo/store/user.go:98)). Thus user entries expire after 10 minutes.
