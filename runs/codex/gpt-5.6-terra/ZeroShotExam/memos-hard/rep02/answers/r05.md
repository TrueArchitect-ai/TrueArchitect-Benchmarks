Premise correction: No GraphQL schema is defined in this repository; the project documents its public API as REST and gRPC ([README.md](/bench/repo/README.md:22)).

Actual API surface: The source contract is Protocol Buffers in [`proto/api/v1/*.proto`](/bench/repo/proto/api/v1/memo_service.proto:1), with HTTP routes declared via `google.api.http` (for example, `/api/v1/memos` at [memo_service.proto](/bench/repo/proto/api/v1/memo_service.proto:28-35)). Buf generates the gRPC, Connect, gateway, and OpenAPI surfaces ([buf.gen.yaml](/bench/repo/proto/buf.gen.yaml:10-25)); the generated REST schema is [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml:1-18), embedded by [`proto/openapi_embed.go`](/bench/repo/proto/openapi_embed.go:5-10).
