Premise correction: No per-user API rate-limiting middleware is registered, so there are no per-user request limits. The API registers authentication middleware on the gRPC-Gateway mux in [server/router/api/v1/v1.go:69-98](/bench/repo/server/router/api/v1/v1.go:69), while the server-wide middleware is recovery and CORS ([server/server.go:50-52](/bench/repo/server/server.go:50)). It does impose a 256 MiB request-size cap, not a rate limit ([server/router/api/v1/v1.go:20](/bench/repo/server/router/api/v1/v1.go:20), [server/router/api/v1/v1.go:126-129](/bench/repo/server/router/api/v1/v1.go:126)).
