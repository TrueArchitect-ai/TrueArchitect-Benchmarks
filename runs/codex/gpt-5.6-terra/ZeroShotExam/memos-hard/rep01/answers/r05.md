Premise correction: There is no GraphQL schema or GraphQL API in this repository.

Actual API surface: The public contract is defined by protobuf services in `proto/api/v1/*.proto` (for example, `proto/api/v1/memo_service.proto:17-45`) with HTTP annotations. Buf generates the REST/OpenAPI description at `proto/gen/openapi.yaml` (`proto/buf.gen.yaml:20-25`). Runtime routes are the gRPC-Gateway REST API under `/api/v1/*` and Connect handlers under `/memos.api.v1.*` (`server/router/api/v1/v1.go:95-145`).
