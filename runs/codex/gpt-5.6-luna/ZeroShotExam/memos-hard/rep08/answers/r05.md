Premise correction: This repository does not define a GraphQL schema; it has no GraphQL schema files or server surface.

Actual API surface: The public API is defined by Protocol Buffer services and HTTP annotations in [`proto/api/v1/`]( /bench/repo/proto/api/v1 ), with the generated REST/OpenAPI contract at [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml). The OpenAPI document is embedded and exposed via [`proto/openapi_embed.go`](/bench/repo/proto/openapi_embed.go).
