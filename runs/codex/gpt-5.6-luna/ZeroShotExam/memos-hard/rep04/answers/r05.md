Premise correction: There is no GraphQL schema in this repository.

Actual API surface: The public API is defined as Protocol Buffer RPC services under [`proto/api/v1/`]( /bench/repo/proto/api/v1/instance_service.proto:1), with REST mappings via `google.api.http` annotations (for example, `/api/v1/memos` in [`memo_service.proto`](/bench/repo/proto/api/v1/memo_service.proto:21)). It is exposed through gRPC-Gateway and Connect handlers in [`server/router/api/v1/v1.go`](/bench/repo/server/router/api/v1/v1.go:64), and its generated REST description is [`proto/gen/openapi.yaml`](/bench/repo/proto/gen/openapi.yaml:1).
