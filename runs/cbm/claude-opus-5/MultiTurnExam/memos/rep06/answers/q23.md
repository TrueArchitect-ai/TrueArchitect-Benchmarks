Two adjacent files worth knowing when changing the shape:

- The SQL layer is per-dialect — the same table is also defined in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`, plus a versioned migration under `store/migration/{dialect}/{version}/`.
- The `payload` column is itself a proto: `MemoPayload` in `proto/store/memo.proto:7`, generated into `proto/gen/store/` and embedded as `Memo.Payload` in `store/memo.go`.

Conversion between the store model and the API message happens in `server/router/api/v1/memo_service_converter.go`.
