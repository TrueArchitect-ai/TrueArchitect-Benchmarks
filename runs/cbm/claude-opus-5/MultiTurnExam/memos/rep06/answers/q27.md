**Mechanism: the Vite build output is compiled into the Go binary via `go:embed` and served as static files by Echo middleware, with an SPA fallback to `index.html`; path: `server/router/frontend/frontend.go`**

- `//go:embed dist/*` embeds `server/router/frontend/dist` into `embeddedFiles` (`server/router/frontend/frontend.go:20-21`); `getFileSystem("dist")` exposes it as an `fs.FS` via `fs.Sub` (`:115-116`).
- `FrontendService.Serve` installs `middleware.StaticWithConfig{Filesystem: frontendFS}` (`:54-57`), then `spaFallbackMiddleware`, which turns a 404 on a non-API path into `c.FileFS("index.html", frontendFS)` so client-side routes resolve (`:59`, `:63-77`).
- Cache policy differs per asset class — `no-store` for HTML, `max-age=3600` for plain static, `immutable` for hash-named assets (`:23-27`, applied in `setFrontendCacheHeaders` at `:100`). API/file paths are excluded by `shouldSkipFrontendStatic` (`:82`).

The `dist` directory is produced by the frontend build in `web/` and copied in before `go build` — see the Dockerfile/build scripts at the repo root.
