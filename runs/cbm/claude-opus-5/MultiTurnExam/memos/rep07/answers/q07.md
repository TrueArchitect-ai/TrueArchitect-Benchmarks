**web/src/connect.ts**

All eight service clients are created there from a shared `createConnectTransport` (`web/src/connect.ts:184-203`) — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. The same file also defines the auth interceptor and a separate `refreshAuthClient` on an interceptor-free transport (`web/src/connect.ts:65-72`) to avoid recursion during token refresh.
