**mysql, postgres, sqlite**

- `store/migration/` contains exactly three dialect subdirectories: `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/`, each with versioned folders plus a `LATEST.sql`.
- They're embedded and selected at runtime in `store/migrator.go:44-45` (`//go:embed migration`) via `getMigrationBasePath()`, which keys off the configured driver.
