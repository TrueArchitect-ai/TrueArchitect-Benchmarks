All four dispatchers are defined in `server/router/api/v1/memo_service_webhooks.go`:

```
memos.memo.created:          DispatchMemoCreatedWebhook          (:15)
memos.memo.updated:          DispatchMemoUpdatedWebhook          (:20)
memos.memo.deleted:          DispatchMemoDeletedWebhook          (:25)
memos.memo.comment.created:  DispatchMemoCommentCreatedWebhook   (:30)
```

Call sites:

- created — `APIV1Service.CreateMemo`, `server/router/api/v1/memo_service.go:157`
- updated — `APIV1Service.dispatchMemoUpdatedSideEffects`, `server/router/api/v1/memo_update_helpers.go:67`, reached from `UpdateMemo` (`memo_service.go:513`), `SetMemoRelations` (`memo_relation_service.go:48`), and `SetMemoAttachments` (`memo_attachment_service.go:48`)
- deleted — `APIV1Service.DeleteMemo`, `server/router/api/v1/memo_service.go:562`
- comment created — `APIV1Service.CreateMemoComment`, `server/router/api/v1/memo_service_comments.go:119` (sent to the *parent* memo's creator)

**Convergence:** the first three funnel through the shared helper `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`), which resolves the creator, loads their hooks via `Store.GetUserWebhooks`, and per hook calls `webhook.PostAsync(payload)` (`:71`). The comment dispatcher builds the same payload and calls `webhook.PostAsync` directly (`:43`).

**Delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go:184` — enqueues onto a bounded channel drained by four worker goroutines started in `init()` (`:42-54`), each calling `webhook.Post` (`internal/webhook/webhook.go:120`), which does the signed HTTP POST over the SSRF-guarded client.
