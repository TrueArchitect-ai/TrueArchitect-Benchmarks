**Engine: Google CEL (Common Expression Language) via `github.com/google/cel-go` — `internal/filter/` (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`)**

**Mechanism:** the filter string is compiled once by a shared CEL environment into a dialect-agnostic condition tree (IR), which is then rendered per-dialect into a parameterized SQL `WHERE` fragment plus args, and appended to the query the driver is building.

Concretely:

- `Engine.Compile` (`internal/filter/engine.go:47`) runs `env.Compile(filter)` against the CEL env built from the memo schema, then `buildCondition` turns the parsed AST into the IR (`internal/filter/ir.go`, `parser.go`). Allowed variables — `content`, `creator`, `creator_id`, `created_ts`, `pinned`, `tag`/`tags`, `visibility`, `has_task_list`, etc. — are declared in `internal/filter/schema.go:232-250`.
- `Program.Render` / `CompileToStatement` (`internal/filter/engine.go:71-97`) emit a `Statement{SQL, Args}` for a given `RenderOptions{Dialect, PlaceholderOffset}`; the renderer is `internal/filter/render.go`. Dialect differences are table-driven in `internal/filter/schema.go` — e.g. string concat is `('users/' || %s)` for SQLite/Postgres but `CONCAT('users/', %s)` for MySQL (`:104-107`), and timestamps wrap in `UNIX_TIMESTAMP(%s)` only for MySQL (`:130-148`). Dialect constants are at `internal/filter/schema.go:14-16`.
- Each driver calls the shared helper `filter.AppendConditions` (`internal/filter/helpers.go:9`) with its own dialect and the accumulated arg count as `PlaceholderOffset` (so Postgres `$N` numbering stays correct): `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`. The engine itself is a process-wide singleton via `DefaultEngine()` (`internal/filter/engine.go:108`).
- On the API side, `server/router/api/v1/memo_service_filter.go` handles the RPC's filter argument before it reaches the store; the same machinery backs attachment filters (`DefaultAttachmentEngine`) and user filters (`server/router/api/v1/user_service_filter.go`).
