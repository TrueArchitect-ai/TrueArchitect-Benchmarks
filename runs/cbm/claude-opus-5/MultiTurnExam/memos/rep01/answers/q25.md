**Engine:** CEL (Google Common Expression Language, `github.com/google/cel-go` v0.28.1 per `go.mod:13`) — implemented in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`, `helpers.go`).

**Mechanism (one sentence):** `Engine.Compile` parses the CEL string into a dialect-agnostic condition tree (IR), then `Program.Render` walks that tree with a dialect-specific renderer to emit a parameterized SQL `WHERE` fragment plus args, which each driver splices into its query.

Detail:

- `Engine` wraps a `cel.Env` built from a `Schema` (`internal/filter/engine.go:14,24`); `Compile` (line 48) runs `env.Compile` and converts the AST into the condition tree in `internal/filter/ir.go` / `parser.go`. A frozen `nowFunc` (line 17) makes `now`-relative filters see a single instant.
- `Schema` (`internal/filter/schema.go:60`, memo fields via `NewSchema()` at line 89) declares which fields are filterable and their column mappings; `Field.columnExpr` (line 321) picks a per-dialect SQL expression when one is registered in `Field.Expressions`.
- Dialects are the enum `DialectSQLite` / `DialectMySQL` / `DialectPostgres` (`internal/filter/schema.go:13-17`). The renderer (`internal/filter/render.go:24`) branches on it for things like JSON access, string-length functions (`stringLengthExpr`, line 297), timestamp accessors (line 222), and placeholder style (`$N` for Postgres vs `?` elsewhere) using a `placeholderOffset` so args line up with pre-existing ones.
- Drivers call the shared helper: e.g. `store/db/sqlite/memo.go:57,61` does `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)`; `AppendConditions` (`internal/filter/helpers.go:9`) compiles each filter to a `Statement` and appends `(<sql>)` to the WHERE list with its args. `store/db/postgres/memo.go` and `store/db/mysql/memo.go` do the same with their own `DialectName`.

Values always travel as bound parameters rather than string interpolation, so the filter can't inject SQL. `internal/filter/README.md` and `MAINTENANCE.md` document the supported grammar.
