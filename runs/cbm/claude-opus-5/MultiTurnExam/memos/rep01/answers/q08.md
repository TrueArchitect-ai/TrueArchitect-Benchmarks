**Driver — store/driver.go**

`store.Driver` is defined at `store/driver.go:10`, described in the doc comment as "an interface for store driver... all methods that store database driver should implement." It covers connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus per-model CRUD groups for attachments, memos, memo relations, instance settings, users, and so on.

The three implementations are the `DB` structs in `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`; each package's `NewDB` returns `store.Driver`, and `store/db/db.go` selects among them based on the configured driver.
