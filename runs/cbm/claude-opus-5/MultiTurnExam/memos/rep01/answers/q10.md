**store/migration/sqlite/LATEST.sql**

`store/migrator.go` documents it directly: "LATEST.sql: Full schema for new installations (faster than incremental migrations)" (`store/migrator.go:42`), and `preMigrate` checks whether the DB is initialized — if not, it applies `LATEST.sql` (`store/migrator.go:27`).

The path is assembled from `getMigrationBasePath()` (`store/migrator.go:254`, which returns `migration/<driver>/`) plus the `LatestSchemaFileName` constant (`store/migrator.go:56`), used at `store/migrator.go:218` — so with `driver = sqlite` it resolves to `migration/sqlite/LATEST.sql` inside the embedded FS.
