**store/migration/sqlite/LATEST.sql**

On a fresh install, `preMigrate` in `/bench/repo/store/migrator.go:211` checks `driver.IsInitialized`; when false it reads `getMigrationBasePath() + LatestSchemaFileName` — i.e. `migration/<driver>/LATEST.sql` (lines 218, 254–256, with `LatestSchemaFileName = "LATEST.sql"` at line 56) — from the embedded FS and executes it in a single transaction. For the `sqlite` driver that resolves to `/bench/repo/store/migration/sqlite/LATEST.sql`.

The incremental per-version files (`0.17/…` through `0.30/…`) are only applied to existing databases, so a new install skips them entirely and just gets the schema version stamped afterward.
