Two adjacent files are worth knowing about when changing the shape:

- `/bench/repo/proto/store/memo.proto` defines `MemoPayload` — the structured blob stored in the memo row's `payload` column and carried on `store.Memo.Payload`.
- `/bench/repo/server/router/api/v1/memo_service_converter.go` is the single mapping point between the Go store model and the proto message, so it must move in step with any field change.

The SQL layer is really three files — `store/migration/{sqlite,postgres,mysql}/LATEST.sql` plus a new versioned migration per dialect — since each dialect keeps its own schema.
