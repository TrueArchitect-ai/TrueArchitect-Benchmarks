**memo_relation**

Defined at `/bench/repo/store/migration/sqlite/LATEST.sql:47` (with equivalents in `/bench/repo/store/migration/postgres/LATEST.sql` and `/bench/repo/store/migration/mysql/LATEST.sql`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It joins a memo to a related memo via `memo_id` → `related_memo_id`, with `type` distinguishing the relation kind (e.g. reference vs. comment). Store-layer access lives in `/bench/repo/store/memo_relation.go` and the per-dialect implementations at `/bench/repo/store/db/{sqlite,postgres,mysql}/memo_relation.go`.
