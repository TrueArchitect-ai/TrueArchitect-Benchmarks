**store/migration/sqlite/LATEST.sql**

On a fresh install, `Store.preMigrate` sees `IsInitialized` return false and applies a single file: `getMigrationBasePath() + LatestSchemaFileName`, i.e. `migration/<driver>/LATEST.sql` → `/bench/repo/store/migration/sqlite/LATEST.sql` for SQLite (`store/migrator.go:211-235`, with the path helper at `store/migrator.go:254-256` and the constant at line 56). It's embedded via `//go:embed migration` (line 44), executed in one transaction, and then the current schema version is recorded — the incremental `0.x/` directories are skipped entirely for new databases.
