**store/migration/sqlite/LATEST.sql**

On a fresh install, `preMigrate` detects an uninitialized DB and applies `<migration base path>/LATEST.sql` in a single transaction (`store/migrator.go:217-228`), where the base path is `migration/<driver>/` (`store/migrator.go:255`) — so `migration/sqlite/LATEST.sql` for SQLite. The file name constant is at `store/migrator.go:56`, and the behavior is documented at `store/migrator.go:27,42`.
