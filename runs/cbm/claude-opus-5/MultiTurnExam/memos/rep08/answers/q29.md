**web/src/connect.ts; short-lived access token (JWT, Bearer) + refresh token (httpOnly cookie) — with PATs as a third kind the backend accepts; server/auth**

**Interceptor** — `authInterceptor` at `web/src/connect.ts:156-178`, installed on the shared Connect transport (line 184). Per request it fetches a token via `getRequestToken()` (line 124), sets `Authorization: Bearer <token>`, and on a `Code.Unauthenticated` response refreshes once and retries with an `X-Retry` marker; a second failure triggers `redirectOnAuthFailure()`. Token state lives in `web/src/auth-state.ts` (localStorage + in-memory, cross-tab sync over `BroadcastChannel`), and refresh calls go through a separate interceptor-free transport/client (`web/src/connect.ts:65,72`) to avoid recursion, deduplicated by `tokenRefreshManager` (line 30).

**Token kinds:**
- **Access token (V2 JWT)** — short-lived, sent as `Authorization: Bearer`, proactively refreshed 30 s before expiry (`REQUEST_TOKEN_EXPIRY_BUFFER_MS`, `web/src/auth-state.ts:18`) or 2 min on tab focus.
- **Refresh token** — httpOnly cookie, never touched by JS; carried because the transport sets `credentials: "include"` (`web/src/connect.ts:57-62`). Exchanged via `AuthService.RefreshToken`.
- **Personal Access Token (PAT)** — not used by the web client, but accepted on the same `Authorization: Bearer` header for programmatic access.

**Backend validation** — `server/auth`: `Authenticator.AuthenticateByAccessTokenV2` (`server/auth/authenticator.go:41`), `AuthenticateByRefreshToken` (line 61, checked against the DB via `GetUserRefreshTokenByID`), `AuthenticateByPAT` (line 102, prefix-checked and hash-looked-up via `GetUserByPATHash`, with expiry check). `resolveBearer` (line 149) dispatches between JWT and PAT by prefix; `AuthenticateToUser` (line 190) tries the header first and falls back to the refresh cookie. Parsing/hashing helpers are in `server/auth/token.go` and `server/auth/extract.go`. It's wired into the request path by the Connect interceptors (`server/router/api/v1/connect_interceptors.go`), the gateway middleware (`server/router/api/v1/v1.go:69`), and the ACL/authz rules in `server/router/api/v1/acl_config.go` / `authz.go`.
