**store/migration/sqlite/LATEST.sql**

On a fresh install, `preMigrate` (`/bench/repo/store/migrator.go:211-236`) sees `IsInitialized` return false and applies `getMigrationBasePath() + LatestSchemaFileName` in a single transaction — which resolves to `migration/<driver>/LATEST.sql` (`migrator.go:254-256`, `LatestSchemaFileName = "LATEST.sql"` at line 56), i.e. `/bench/repo/store/migration/sqlite/LATEST.sql` for SQLite. It then stamps the current schema version rather than replaying the incremental `0.x/` migrations.
