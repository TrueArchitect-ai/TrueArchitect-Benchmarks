**Engine: Google CEL (cel-go) — /bench/repo/internal/filter/ (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go`)**

**Mechanism:** The CEL environment defined by the filter `Schema` compiles the expression into a dialect-agnostic condition tree (IR), which a per-dialect renderer then turns into a parameterized SQL `WHERE` fragment plus bound args — so each driver produces its own SQL from the same parsed filter.

Details:

- `filter.Engine` wraps a `cel.Env` built from `schema.EnvOptions` (`/bench/repo/internal/filter/engine.go:24-33`); `Compile` runs `env.Compile(filter)` and converts the AST into the IR condition tree (`engine.go:48`, with `parser.go`/`ir.go`). A frozen `nowFunc` makes `now` a single instant per compile.
- `Engine.CompileToStatement` / `Program.Render` (`engine.go:74`, `:96`) render that tree for a given `DialectName` — `DialectSQLite`, `DialectMySQL`, `DialectPostgres` (`/bench/repo/internal/filter/schema.go:11-17`). Dialect divergence is isolated in `render.go` helpers such as `stringLengthExpr` (297), `qualifyColumn` (919), `jsonExtractExpr` (932), `jsonArrayExpr` (944), `jsonArrayLengthExpr` (956), and `Field.columnExpr` (`schema.go:321`) — this is where JSON payload access and placeholder style (`?` vs `$N`) differ.
- Each driver calls it while building its query: `filter.DefaultEngine()` then `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` at `/bench/repo/store/db/sqlite/memo.go:57-61`, with the same two lines in `/bench/repo/store/db/postgres/memo.go` and `/bench/repo/store/db/mysql/memo.go` passing their own dialect constant. `AppendConditions` is defined at `/bench/repo/internal/filter/helpers.go:9`.
- Filter fields exposed to users for memos are declared in the schema used by `DefaultEngine` (`engine.go:111`); attachments have their own via `DefaultAttachmentEngine` (`engine.go:119`). The API-side glue is `/bench/repo/server/router/api/v1/memo_service_filter.go`; `/bench/repo/internal/filter/README.md` and `MAINTENANCE.md` document the supported syntax.
