**sqlite, mysql, postgres**

Migrations live under `store/migration/{driver}/`, with one directory per dialect:
- `store/migration/sqlite/` (`LATEST.sql` + versioned dirs like `0.28/00__user_identity.sql`)
- `store/migration/mysql/`
- `store/migration/postgres/`

The whole tree is embedded in `store/migrator.go:44-45` (`//go:embed migration`), and the driver-specific path is selected at runtime via `getMigrationBasePath()` (`store/migrator.go:141`). The same three dialects have driver implementations under `store/db/` (`sqlite`, `mysql`, `postgres`).
