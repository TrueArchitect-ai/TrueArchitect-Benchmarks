**Unused scheduling infrastructure:**

`server/runner/memopayload/runner.go` defines a `Runner` with `NewRunner` (L19) and `RunOnce` (L27) — a full backfill pass that rebuilds every memo's payload — but **nothing in the server ever constructs or calls it**. Grep for `memopayload.NewRunner` / `memopayload.Runner` across the repo returns no hits. Only the package's free function `RebuildMemoPayload` (L74) is used, and it's called inline from the API handlers on create and update (`server/router/api/v1/memo_service.go:108`, `:447`). So the memopayload *runner* is dead scheduling infrastructure; the memopayload *logic* is very much live.

There is no cron library in use anywhere — all periodic work is plain `time.NewTicker`.
