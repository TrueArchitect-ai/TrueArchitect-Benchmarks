**Go `embed.FS` — the built `web/dist` output is compiled into the binary and served by an Echo static middleware with SPA fallback; wired in `server/router/frontend/frontend.go`**

Specifics:

- `//go:embed dist/*` + `var embeddedFiles embed.FS` at `server/router/frontend/frontend.go:20-21` bakes `server/router/frontend/dist/` (the copied Vite build output) into the binary.
- `FrontendService.Serve` (`:40`) derives a sub-filesystem via `getFileSystem("dist")` (`:115-121`) and registers `middleware.StaticWithConfig` over it (`:52-56`), with a skipper that bypasses API/file paths and sets cache headers.
- `spaFallbackMiddleware(frontendFS)` (`:58`) serves `index.html` for client-side routes — `shouldServeFrontendHTML` (`:107`) treats `/`, `/index.html`, and any extension-less path as an app route.
- Caching differs by asset class (`:22-26`, `:96-105`): HTML is `no-cache, no-store, must-revalidate`; content-hashed files under `/assets/` get `max-age=3600, immutable`; other statics get plain `max-age=3600`.
- `registerRoutes` (`:123`) additionally serves `/robots.txt` and `/sitemap.xml` dynamically from the instance URL.

There's a second, unrelated embed for the OpenAPI docs at `proto/openapi_embed.go`.
