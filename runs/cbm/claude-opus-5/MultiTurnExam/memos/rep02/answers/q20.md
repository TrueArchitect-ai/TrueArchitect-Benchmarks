**Mechanism:** Server-Sent Events (SSE) — an in-process fan-out hub over `text/event-stream`, not WebSockets.

**Hub path:** `server/router/api/v1/sse_hub.go` (`SSEHub` at L56, `NewSSEHub` L63, `Subscribe` L71, `Unsubscribe` L89, `Broadcast` L115). The HTTP endpoint that upgrades a request into a stream is `server/router/api/v1/sse_handler.go` (`RegisterSSERoutes` L25, `handleSSE` L34, `Content-Type: text/event-stream` at L48), mounted alongside the gateway routes in `server/router/api/v1/v1.go:124`. Event shaping helpers are in `server/router/api/v1/sse_event_helpers.go`.

**Memo handlers that broadcast:**

| Handler | Event type | Broadcast site |
|---|---|---|
| `APIV1Service.CreateMemo` | `memo.created` | `memo_service.go:163` (skipped when `isSSESuppressed`) |
| `APIV1Service.DeleteMemo` | `memo.deleted` | `memo_service.go:585` |
| `APIV1Service.UpdateMemo` | `memo.updated` | via `dispatchMemoUpdatedSideEffects`, called at `memo_service.go:513` |
| `APIV1Service.SetMemoRelations` | `memo.updated` | same helper, `memo_relation_service.go:48` |
| `APIV1Service.SetMemoAttachments` | `memo.updated` | same helper, `memo_attachment_service.go:48` |
| `APIV1Service.CreateMemoComment` | `memo.comment.created` | `memo_service_comments.go:126` (broadcast names the *parent* memo) |
| `APIV1Service.UpsertMemoReaction` | `reaction.upserted` | `reaction_service.go:106` |
| `APIV1Service.DeleteMemoReaction` | `reaction.deleted` | `reaction_service.go:161` |

The shared `memo.updated` emitter is `dispatchMemoUpdatedSideEffects` (`server/router/api/v1/memo_update_helpers.go:66-79`), which also fires the corresponding webhook. Event types are defined in `sse_hub.go:15-20`, and `Broadcast` filters per subscriber by memo visibility and creator so private memos aren't leaked to other users' streams.
