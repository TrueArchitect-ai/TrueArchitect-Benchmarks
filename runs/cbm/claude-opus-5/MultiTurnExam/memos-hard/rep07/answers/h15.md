Visibility is enforced in eight distinct surfaces. Grouped by kind:

**1. Single-memo read gate (gRPC API)**
- `APIV1Service.checkMemoReadAccess` — `server/router/api/v1/memo_service.go:39-67` — non-public memos require an authenticated user; `Private` requires being the creator. Also gates archived memos to their creator. Used by `GetMemo` and other single-memo reads.

**2. List-query filtering (gRPC API)** — visibility is pushed into the store query rather than checked per row:
- `ListMemos` — `server/router/api/v1/memo_service.go:219-225` (anonymous → `VisibilityList = [PUBLIC]`; authenticated → CEL filter `creator_id == N || visibility in ["PUBLIC","PROTECTED"]`)
- `ListMemoComments` — `server/router/api/v1/memo_service_comments.go:158-160`
- memo-relation loading — `server/router/api/v1/memo_service_converter.go:184-186` and `server/router/api/v1/memo_relation_service.go:109-111`
- user stats — `server/router/api/v1/user_service_stats.go:84-90` and `:218-220`

**3. Write/interaction gates on a memo's children (gRPC API)** — each re-checks the parent memo:
- reactions — `server/router/api/v1/reaction_service.go:30-38` (upsert) and `:83` (delete)
- comment creation — `server/router/api/v1/memo_service_comments.go:41`
- memo attachments listing — `server/router/api/v1/memo_attachment_service.go:214-222`
- attachment access — `server/router/api/v1/attachment_service.go:445-451`

**4. Binary file serving (Echo, outside gRPC)**
- `FileServerService.checkAttachmentPermission` — `server/router/fileserver/fileserver.go:650-704` — public + anonymous-allowed instance passes; otherwise falls back to a valid non-expired `share_token` for that memo (`:684-689`), then requires an authenticated user, and denies `Private` to non-creator non-admins (`:699`).

**5. Live event fan-out (SSE)**
- `SSEClient.canReceive` — `server/router/api/v1/sse_hub.go:134-143` — `Private` events only reach the creator or an admin; `Public`/`Protected`/unset reach everyone; unknown values deny. Event visibility is stamped in `server/router/api/v1/sse_event_helpers.go:29-37`.

**6. Public feeds and SSR (public-only by construction)**
- RSS — `server/router/rss/rss.go:90` and `:141` (`VisibilityList: [Public]`)
- frontend sitemap — `server/router/frontend/frontend.go:150`

**7. Share-token path (bypass, gated by token validity + ownership)**
- `getActiveMemoShare` — `server/router/api/v1/memo_share_service.go:~200` — a valid, unexpired share token grants read regardless of visibility; creating/revoking a share requires being the memo creator or a superuser (`server/router/api/v1/memo_share_service.go:133-144`).

**8. Notification/mention delivery**
- mention targeting — `server/router/api/v1/memo_mention_helpers.go:62-84` — no inbox/notification for a `Private` memo unless the target is the creator.
- email notification content — `server/notification/email.go:313-316` and `server/router/api/v1/user_service_notifications.go:309-312` — `Private`/`Protected` memos suppress or reduce the emailed content.
