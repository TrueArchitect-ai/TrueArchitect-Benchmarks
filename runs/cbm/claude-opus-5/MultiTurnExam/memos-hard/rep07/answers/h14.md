**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `markdown.service.ExtractAll` — `internal/markdown/markdown.go`; Triggers: `CreateMemo` and `UpdateMemo` (only when the `content` field is in the update mask); Extracted: `Payload.Tags` (deduplicated `#tags`) and `Payload.Property` — `has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks`, `title`**

**Where it's computed.** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`) initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, then assigns exactly two fields: `memo.Payload.Tags = data.Tags` (`:85`) and `memo.Payload.Property = data.Property` (`:86`). The actual extraction is a single goldmark AST walk in `(*service).ExtractAll` (`internal/markdown/markdown.go`), which is why it's one pass rather than separate `ExtractTags`/`ExtractProperties` calls. The payload is persisted as JSON in the memo row and read back for list responses.

**Triggers** (all callers of `RebuildMemoPayload`):

1. `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before `s.Store.CreateMemo`; note `Payload.Location` is set *after* the rebuild (`:110-112`) so user-supplied location survives.
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the field-mask loop, reached only on `path == "content"`; the recomputed payload is then written via `update.Payload = memo.Payload` (`:451`). Other update paths (`visibility`, pinned, etc.) do not recompute.
3. `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:52` — a batch rebuild over all memos, but nothing constructs or invokes that runner in production code, so it never fires at runtime.

**What gets extracted** (`internal/markdown/markdown.go`, `ExtractAll`):

- **Tags** — `#tag` nodes from the custom tag extension, deduplicated case-preservingly via `uniquePreserveCase`.
- **`Property.Title`** — text of the first block-level child of the document when it is an H1 heading.
- **`Property.HasLink`** — any `gast.KindLink` node.
- **`Property.HasCode`** — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- **`Property.HasTaskList`** — any `east.KindTaskCheckBox`; **`Property.HasIncompleteTasks`** when such a checkbox is unchecked.

These match the proto definition `MemoPayload.Property` at `proto/store/memo.proto:15-22`. `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` deliberately doesn't store them — mentions are consumed separately for notifications via `s.MarkdownService.ExtractAll` in `server/router/api/v1/memo_mention_helpers.go:32`.

**Consumers** — `Payload.Tags` surfaces on the API memo as `memoMessage.Tags` (`server/router/api/v1/memo_service_converter.go:48`) and drives tag stats (`server/router/api/v1/user_service_stats.go:138`, `:254`).

One related-but-distinct piece: the list/preview **`Snippet`** is *not* part of this stored payload — it's generated per response at conversion time by `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_converter.go:76-80`, `:225`, `:248`; helper at `server/router/api/v1/memo_service_webhooks.go:83`).
