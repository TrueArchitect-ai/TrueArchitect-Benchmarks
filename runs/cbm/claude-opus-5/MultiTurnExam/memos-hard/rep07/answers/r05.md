**Premise correction: there is no GraphQL in this project — zero hits for `graphql`, `gqlgen`, `.graphql`, or `apollo` across Go sources, `go.mod`, TypeScript/TSX, and JSON files (excluding `node_modules`). The public API is defined in Protocol Buffers and exposed as REST/JSON and Connect RPC.**

**Actual API surface.**

**Schema definition** — nine `.proto` files under `proto/api/v1/`: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and shared `common.proto`. Store-side messages live in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`). Generated Go lands in `proto/gen/api/v1` (with Connect stubs in `proto/gen/api/v1/apiv1connect/`) and `proto/gen/store`.

**Two transports, both served by the same `APIV1Service`, registered in `RegisterGateway` (`server/router/api/v1/v1.go:65`):**

1. **REST/JSON via grpc-gateway** — a `runtime.NewServeMux` with all eight services registered (`server/router/api/v1/v1.go:96-121`), mounted on Echo at `gwGroup.Any("/api/v1/*", handler)` and `"/file/*"` (`v1.go:128-129`), wrapped in a request-size cap via `http.MaxBytesHandler(gwMux, maxAPIRequestBytes)` (`v1.go:126`). HTTP paths and verbs come from `google.api.http` annotations in the `.proto` files.

2. **Connect RPC** — handlers for browser clients (replacing grpc-web), implemented in `server/router/api/v1/connect_services.go` as `ConnectServiceHandler` methods (`GetInstanceProfile`, `SignIn`, `ListUsers`, `GetMemo`, …) and registered with the interceptor chain built at `server/router/api/v1/v1.go:131+`.

**Auth** is enforced uniformly across both by a shared `Authorizer` (`server/router/api/v1/v1.go:68`) — as gateway middleware (`v1.go:69-92`) and as the Connect `AuthInterceptor` (`server/router/api/v1/connect_interceptors.go:205`), with the per-method policy table in `server/router/api/v1/acl_config.go`.

**Non-RPC HTTP surfaces** alongside the API: file serving at `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), SSE (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/`), and the frontend/SSR routes (`server/router/frontend/frontend.go`).
