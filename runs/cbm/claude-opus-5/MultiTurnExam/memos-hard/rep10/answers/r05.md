**Premise correction: there is no GraphQL in this repository. Searching all Go, TypeScript, and module files for `graphql`, `gqlgen`, `.graphql`, and `resolver` yields no GraphQL anything — the two `resolver` hits are `net.DefaultResolver` DNS lookups (`internal/webhook/webhook.go:65`, `internal/httpgetter/html_meta.go:23`). There is no schema file, no resolver layer, and no GraphQL endpoint.**

The actual API surface is **Protocol Buffers / gRPC**, defined in `proto/api/v1/` and exposed over three transports:

**Schema definition** — `.proto` files under `proto/api/v1/`, one per service: `instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared `common.proto`. Codegen is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`) into `proto/gen/`. A separate `proto/store/` tree defines internal persistence messages, not the public API.

**Transports** (all registered in `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go`):

1. **REST/JSON via gRPC-Gateway** — eight `Register*HandlerServer` calls at `server/router/api/v1/v1.go:98-121`, mounted at `/api/v1/*` (`:127`). This is the "public API" a REST client would use; route mappings come from `google.api.http` annotations in the `.proto` files, and an OpenAPI document is embedded via `proto/openapi_embed.go`.
2. **Connect protocol** — for browser clients, replacing grpc-web. Handlers registered at `server/router/api/v1/v1.go:141` behind the interceptor chain (`:133-138`), mounted at `/memos.api.v1.*` (`:144`).
3. **Server-Sent Events** — `RegisterSSERoutes` (`server/router/api/v1/v1.go:124`) for push updates, outside the protobuf RPC model.

Non-gRPC HTTP surfaces also exist alongside: the file server at `/file/*` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), an MCP endpoint (`server/router/mcp/`), and the frontend/sitemap routes (`server/router/frontend/frontend.go`).
