**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`**

**Triggers (recomputation happens on):**

1. **Memo creation** — `APIV1Service.CreateMemo`, `server/router/api/v1/memo_service.go:108`, run after the content-length check and before `s.Store.CreateMemo`. This also covers **comment creation**, since `CreateMemoComment` delegates to `s.CreateMemo` internally (`server/router/api/v1/memo_service_comments.go:56`).
2. **Memo update, only when `content` is in the update mask** — `server/router/api/v1/memo_service.go:437-451`. The `else if path == "visibility"` and other mask branches do not recompute, so changing visibility/pinned/etc. leaves the derived metadata untouched (correctly — it depends only on content).

Those are the only two live triggers: a repo-wide grep for `RebuildMemoPayload` returns just these plus its declaration and the call inside `memopayload.Runner.RunOnce` (`runner.go:52`), and that runner is never constructed anywhere, so the bulk-rebuild path is dead code. There is no tag-rename or tag-delete RPC that would need to re-derive it.

**What gets extracted.** `RebuildMemoPayload` initializes `memo.Payload` if nil, calls `ExtractAll`, and writes back exactly two fields — `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). `Payload.Location` is user-set and deliberately preserved (assigned separately at `memo_service.go:111`).

`ExtractAll` does a single goldmark AST walk (`internal/markdown/markdown.go:356-421`) producing:

- **`Tags`** — every `#tag` node, deduplicated with original case preserved via `uniquePreserveCase`.
- **`Property.Title`** — text of the first block-level child if it's an H1 heading (`markdown.go:384-390`).
- **`Property.HasLink`** — any `gast.KindLink` node.
- **`Property.HasCode`** — any code block, fenced code block, or code span.
- **`Property.HasTaskList`** — any `TaskCheckBox` node; plus **`Property.HasIncompleteTasks`** when at least one checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` discards that field — mentions are consumed separately by `memo_mention_helpers.go:32` for notifications.)

The proto shape backing this is `MemoPayload.Property` in `proto/store/memo.proto:15-22` (`has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks`, `title`) with `repeated string tags = 3`. Consumers on the read side include the API converter (`server/router/api/v1/memo_service_converter.go:48`) and user tag stats (`server/router/api/v1/user_service_stats.go:138,254`), which is what makes this the list/preview metadata.
