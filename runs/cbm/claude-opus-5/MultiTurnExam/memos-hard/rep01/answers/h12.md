2. **Found the single place the interface is bound to a concrete type** — the factory `db.NewDBDriver`, which switches on `profile.Driver`: `"sqlite"` → `sqlite.NewDB`, `"mysql"` → `mysql.NewDB`, `"postgres"` → `postgres.NewDB` (`store/db/db.go:14-27`). So whatever this switch returns is the only implementation the process will ever use.

3. **Resolved `profile.Driver` for a default install.** `Driver` comes from `viper.GetString("driver")` (`cmd/memos/main.go:43`), and the default is registered twice as `"sqlite"` — `viper.SetDefault("driver", "sqlite")` (`cmd/memos/main.go:122`) and the flag default `rootCmd.PersistentFlags().String("driver", "sqlite", ...)` (`cmd/memos/main.go:130`). With no flags and no `MEMOS_DRIVER` env var, the switch takes the `"sqlite"` branch.
