From there the URL is user-configured (registered via `UpdateUserWebhook`/etc. in `server/router/api/v1/user_service_webhooks.go`, validated by `webhook.ValidateURL` at `:74`, `:161`, `:182`). `PostAsync` enqueues onto a 128-slot channel; four workers started in `init()` (`internal/webhook/webhook.go:42-55`) call `Post`, where the outbound request is actually issued via `safeClient.Do` (`internal/webhook/webhook.go:152`).

Note the transitive path is *asynchronous* — the handler returns before the HTTP request is made, and a full queue silently drops the dispatch (`internal/webhook/webhook.go:191-195`).
