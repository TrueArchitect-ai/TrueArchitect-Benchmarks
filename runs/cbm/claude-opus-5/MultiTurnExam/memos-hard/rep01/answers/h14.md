**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which delegates the actual parse to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`.**

**Triggers (production):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:107-109` (before the store insert)
- `CreateMemoComment` — transitively, since it calls `s.CreateMemo` at `server/router/api/v1/memo_service_comments.go:56`
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but **only** when the update mask contains `content` (`:440-441`); the recomputed payload is then written via `update.Payload = memo.Payload` (`:452`). Updating visibility, pinned state, etc. does not recompute.
- Not triggered: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) would rebuild every memo in 100-row batches, but nothing constructs that runner — `NewRunner` has no callers, so it never runs.

**Extracted properties** — `RebuildMemoPayload` writes two fields onto `memo.Payload` (`server/runner/memopayload/runner.go:85-86`):

1. **`Tags []string`** — every `#tag` node, deduplicated with original case preserved (`internal/markdown/markdown.go:377`, `:417`).
2. **`Property`** (`storepb.MemoPayload_Property`, defined at `proto/store/memo.proto:15-22`), a single AST walk setting:
   - `HasLink` — any link node (`markdown.go:393-394`)
   - `HasCode` — code block, fenced code block, or inline code span (`:396-397`)
   - `HasTaskList` — any task checkbox (`:399-400`)
   - `HasIncompleteTasks` — at least one unchecked checkbox (`:401-404`)
   - `Title` — text of the first block-level H1 heading, if the document starts with one (`:384-388`)

Note `ExtractAll` also returns `Mentions`, but `RebuildMemoPayload` deliberately drops it — mentions are consumed separately for notifications (`server/router/api/v1/memo_mention_helpers.go:32`). Likewise `Payload.Location` is user-supplied, not derived, and is set after the rebuild (`memo_service.go:110-112`).

**Consumption (the "lists/previews" part):** `memo.Payload.Tags` is copied onto the API response in `server/router/api/v1/memo_service_converter.go:48` and aggregated for user stats at `server/router/api/v1/user_service_stats.go:138` and `:254`. Because it's persisted in the `memo.payload` column, list queries read it without re-parsing markdown.
