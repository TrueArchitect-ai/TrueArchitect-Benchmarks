**Premise correction: there is no GraphQL in this repository.** A case-insensitive grep for `graphql`, `gqlgen`, and `.graphql` across the entire tree (excluding `.git`, `node_modules`, `dist`) returns zero files. There is no schema, no resolvers, and no GraphQL dependency in `go.mod` or the web package.

**Actual API surface — Protobuf/gRPC, exposed three ways plus two plain-HTTP surfaces:**

**1. Schema of record: `.proto` files in `proto/api/v1/`** — nine service definitions:
- `memo_service.proto` (e.g. `service MemoService` at `:17`, with `CreateMemo`/`ListMemos`/`GetMemo`/`UpdateMemo`/`DeleteMemo`/`SetMemoAttachments`/… )
- `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`

Persistence-side messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`).

**2. Codegen via buf** — `proto/buf.gen.yaml` runs five backend plugins plus one frontend plugin, which tells you exactly what the surface is:
- `protocolbuffers/go` + `grpc/go` → Go types and gRPC stubs in `proto/gen/`
- `connectrpc/go` → Connect handlers (`proto/gen/api/v1/apiv1connect/`)
- `grpc-ecosystem/gateway` → REST/JSON transcoding (`*.pb.gw.go`)
- `community/google-gnostic-openapi` → **OpenAPI** spec (this is the "public API schema" analogue, embedded via `proto/openapi_embed.go`)
- `bufbuild/es` → TypeScript clients emitted into `web/src/types/proto`

**3. Runtime registration** — `server/router/api/v1/v1.go`: the gRPC-Gateway mux is built at `:95` and wrapped at `:126`; Connect handlers are registered at `:141` and mounted on `/memos.api.v1.*` at `:144`; both share the interceptor chain at `:133-138`. So a browser talks REST/JSON or Connect, not GraphQL.

**4. Two non-proto HTTP surfaces**, registered directly on Echo in `server/server.go`:
- File serving — `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`, wired at `server/server.go:81-82`)
- RSS feeds (`server/router/rss/rss.go:67`, wired at `server/server.go:85`) and an MCP endpoint (`server/router/mcp/service.go:108`, wired at `server/server.go:96`)
