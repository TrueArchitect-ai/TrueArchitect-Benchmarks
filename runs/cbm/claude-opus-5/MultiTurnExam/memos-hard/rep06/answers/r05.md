**Premise correction: this project has no GraphQL API. There is no `.graphql`/`.gql`/`.graphqls` file, no gqlgen/Apollo dependency, and not a single occurrence of the string "graphql" anywhere in the Go, TypeScript, JSON, or module files.**

**Actual API surface — Protobuf/gRPC service definitions, exposed over three HTTP transports:**

**Schema of record.** The API is defined in Protobuf under `proto/api/v1/`: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and `common.proto`. Code generation is driven by `proto/buf.gen.yaml` / `proto/buf.yaml`, with output in `proto/gen/api/v1` (plus `proto/gen/store` for the persistence messages). A generated OpenAPI document — the closest analogue to a public schema artifact — lives at `proto/gen/openapi.yaml` and is embedded into the binary via `//go:embed` at `proto/openapi_embed.go:4-10`.

**Transports**, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):

1. **REST via gRPC-Gateway** — nine `Register*ServiceHandlerServer` calls (`server/router/api/v1/v1.go:98-121`) populate a `runtime.ServeMux`, mounted on `/api/v1/*` and `/file/*` at `server/router/api/v1/v1.go:128-129`. Auth runs as gateway middleware at `v1.go:69-93`.
2. **Connect RPC** (for browser clients, replacing grpc-web) — handler built at `server/router/api/v1/v1.go:140-141` and mounted at the `/memos.api.v1.*` path prefix (`v1.go:144`), with four interceptors registered at `v1.go:133-138`.
3. **Server-Sent Events** for push — `RegisterSSERoutes` at `server/router/api/v1/v1.go:124`.

Adjacent non-RPC surfaces: static file serving at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), RSS feeds (`server/router/rss/rss.go`), and an MCP endpoint whose tool catalog whitelists existing RPC methods (`server/router/mcp/catalog.go`).
