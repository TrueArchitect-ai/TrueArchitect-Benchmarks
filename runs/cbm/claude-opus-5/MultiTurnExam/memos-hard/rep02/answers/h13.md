**`*markdown.service` (the only implementation) — constructed once by `NewAPIV1Service`, then shared — held by `APIV1Service` and `RSSService` (plus the unused `memopayload.Runner`)**

**Implementation.** `internal/markdown.Service` is the interface (`internal/markdown/markdown.go:31`), with a single unexported concrete type `service` wrapping a `goldmark.Markdown` (`internal/markdown/markdown.go:57-59`). It's the only implementer in the repo — a search for `ExtractAll` method definitions returns exactly one hit, `internal/markdown/markdown.go:356`, and there are no mock or alternate implementations, including in tests.

**Construction.** The factory is `markdown.NewService(opts ...Option) Service` (`internal/markdown/markdown.go:85`). In production it is called exactly once, in `NewAPIV1Service` (`server/router/api/v1/v1.go:48-51`), with both custom extensions enabled:

```go
markdownService := markdown.NewService(
    markdown.WithTagExtension(),
    markdown.WithMentionExtension(),
)
```

That single instance is stored on the service at `server/router/api/v1/v1.go:56`. (The only other `NewService` calls are in test setup: `server/router/api/v1/test/test_helper.go:44`, `server/router/rss/rss_test.go:54`, `server/router/fileserver/fileserver_test.go:427` — note the latter two configure fewer extensions than production.)
