**Premise correction: this project has no GraphQL API. There is no GraphQL schema, no `.graphql`/`.graphqls` file, no gqlgen or graphql-go dependency, and no GraphQL client on the frontend** — a case-insensitive search for `graphql`/`gqlgen` across Go, `go.mod`, JSON, and TypeScript sources (excluding `node_modules`) returns zero hits.

**Actual API surface: Protocol Buffers, from which gRPC, Connect, REST, and OpenAPI are all generated.**

- **Schema of record — `.proto` files in `proto/api/v1/`:** `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`. Persistence-side messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`).

- **REST mapping is declared inline in the protos** via `google.api.http` annotations — e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and `:35` maps `GetMemo` to `GET /api/v1/{name=memos/*}`. These follow AIP resource-name conventions rather than GraphQL-style field selection.

- **Code generation** is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`: gRPC servers/stubs (`proto/gen/api/v1/*_grpc.pb.go`), gRPC-Gateway REST handlers (`*.pb.gw.go`), and Connect handlers (`proto/gen/api/v1/apiv1connect/`).

- **Server wiring:** the handlers are implemented by `APIV1Service` in `server/router/api/v1/` and registered through `RegisterGateway` (`server/router/api/v1/v1.go:65`), called from `server/server.go:87`. Connect services are registered in `server/router/api/v1/connect_services.go`.

- **Machine-readable spec:** an OpenAPI document is generated to `proto/gen/openapi.yaml` and embedded into the binary via `proto/openapi_embed.go:5-11`. The MCP service consumes exactly that spec (`server/router/mcp/service.go:78`) to expose the same REST surface as tools — so MCP is a wrapper over the REST API, not a separate schema.

- **Non-proto HTTP surfaces**, served directly by Echo rather than generated: the file server (`GET /file/attachments/:uid/:filename`, `GET /file/users/:identifier/avatar` — `server/router/fileserver/fileserver.go:123-124`), RSS feeds (`server/router/rss/rss.go`), SSE streaming (`server/router/api/v1/sse_hub.go`), `/healthz` (`server/server.go:67`), and the frontend static/SSR routes (`server/router/frontend/frontend.go`).
