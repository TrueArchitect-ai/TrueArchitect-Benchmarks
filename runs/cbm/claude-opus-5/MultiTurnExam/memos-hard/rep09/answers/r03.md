**Premise correction: there is no nightly database-cleanup job, and the cron scheduler is not wired into the running server at all.** No schedule exists to report a time for.

Two separate things are wrong with the premise:

**1. No database-cleanup job exists.** Searching for `cleanup|vacuum|purge|prune|nightly` across the Go sources turns up no scheduled maintenance task. The hits are all unrelated: inline cleanup during user deletion (`server/router/api/v1/user_service.go:421-450`), S3 object cleanup on attachment delete (`store/attachment.go:171`, `:262`), and test teardown helpers. The one literal `"daily-cleanup"` string in the repo is a **documentation example**, not a registration — `internal/scheduler/doc.go:15-18` shows a sample job whose body is the comment "Your cleanup logic here".

**2. The cron scheduler is dead code.** `internal/scheduler` is a complete, self-contained cron implementation — `scheduler.go`, `parser.go` (5-field cron expressions with wildcard/exact/range/list/step matchers), `job.go`, `middleware.go`, plus a README. But `grep -rn "internal/scheduler"` returns exactly two importers, both tests: `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. Nothing in `cmd/` or `server/` imports it, so `scheduler.New` (`internal/scheduler/scheduler.go:54`) is never called in production and no cron expression is ever registered or parsed at runtime.

**What actually runs on a schedule.** The server has exactly one background timer, and it isn't cron-based:

- **`s3presign.Runner`** — refreshes S3 presigned attachment URLs on a `time.Ticker` every **12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`), plus one immediate run at boot. Wired at `server/server.go:162-171`. Being interval-based from process start, it has no wall-clock time-of-day — it fires 12h after launch, not at a fixed hour.

Two other periodic behaviors exist, also interval-based rather than scheduled: the in-memory cache sweeps expired entries every **5 minutes** (`CleanupInterval`, `store/store.go:42` and `store/cache/cache.go:60`), and `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) is a batch rebuild that is never invoked.
