**Premise correction: there is no GraphQL in this repository.** A case-insensitive search for `graphql|gqlgen` across all `.go`, `.ts`, `.tsx`, `.json`, and `go.mod` files returns zero matches, and `find` for `*.graphql` / `*.gql` finds no files. There is no schema, no resolver layer, and no GraphQL dependency.

**Actual API surface: Protocol Buffers / gRPC, exposed over three transports**

**Schema definition** — `proto/api/v1/`, nine `.proto` files: `instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared `common.proto`. Persistence-layer messages live separately in `proto/store/`.

**Code generation** — driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`). The plugin list at `proto/buf.gen.yaml:9-30` emits: Go message types, gRPC stubs, Connect handlers, and gRPC-Gateway shims into `proto/gen/`, an OpenAPI spec via `google-gnostic-openapi`, and TypeScript types into `web/src/types/proto` via `bufbuild/es` — so the frontend consumes the same schema.

**Runtime registration** — all in `server/router/api/v1/v1.go`, inside `RegisterGateway`:
- **REST/JSON via gRPC-Gateway** — a `runtime.NewServeMux` with auth middleware (`:95-97`); the eight services are registered at `:98-121`; mounted on `/api/v1/*` and `/file/*` at `:127-128`.
- **Connect RPC** (replaces grpc-web for browser clients) — handlers registered at `:139-141` with the interceptor chain at `:133-138`, mounted on `/memos.api.v1.*` at `:144`.
- **SSE** — `RegisterSSERoutes` at `:124`, sharing the API's CORS group.

**Published spec** — an OpenAPI document, not a GraphQL SDL: generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-11`.

Additional non-gRPC HTTP surfaces exist alongside this: the static file server at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`) and RSS feeds (`server/router/rss/rss.go`).
