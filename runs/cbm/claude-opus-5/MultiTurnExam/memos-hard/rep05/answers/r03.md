**Premise correction: there is no nightly database-cleanup job, and the cron scheduler is never started by the server — so no such schedule exists.**

Two separate corrections:

**1. The cron scheduler is dead code in production.** `internal/scheduler` is a complete, well-tested cron package (`scheduler.go`, `parser.go`, `job.go`, `middleware.go`, plus a README and `doc.go`), but nothing outside the package imports it. Grepping for `github.com/usememos/memos/internal/scheduler` yields exactly two hits, both test files inside the package itself: `internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`. Likewise, every call to `Scheduler.Register` is in a test (`integration_test.go:50`, `:61`, `:132`, `:233`, `:273`, `:311`, `:321`, `:331`; `scheduler_test.go:36`, `:41`). No job of any kind — cleanup or otherwise — is registered by server code, and `Scheduler.Start` is never called outside tests.

**2. No database-cleanup job exists anywhere**, cron-scheduled or not. Searching for `cleanup|vacuum|purge|prune` across `server/`, `store/`, and `cmd/` turns up only unrelated things: in-request cleanup after user deletion (`server/router/api/v1/user_service.go:421-450`), S3 object cleanup on attachment delete (`store/attachment.go:171`, `:262`), and the in-memory cache's expiry sweep (`store/cache/cache.go:83`). There is no VACUUM, no old-row purge, and no retention job.

**What actually runs on a schedule.** The server has exactly one recurring background task, and it does not use the cron package. It is the S3 presign runner: `Runner.Run` drives a plain `time.Ticker` at `runnerInterval = 12 * time.Hour` (`server/runner/s3presign/runner.go:27`, loop at `:29-41`), wired into startup at `server/server.go:162-171` with one immediate run at `:163`. Because it is an interval ticker anchored to process start rather than a cron expression, it has no wall-clock time of day — it fires 12 hours after boot and every 12 hours thereafter. The only other periodic work is the cache cleanup goroutine, every 5 minutes (`store/store.go:42`, `store/cache/cache.go:83`).
