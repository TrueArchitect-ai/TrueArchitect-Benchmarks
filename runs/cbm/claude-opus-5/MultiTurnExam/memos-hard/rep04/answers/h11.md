Two notes on the boundary I drew. I excluded the whole `store/` tree as "the data layer," which removes the three driver packages (`store/db/sqlite`, `store/db/postgres`, `store/db/mysql`) and `store/test` — every entity type is referenced by all three drivers, so including them would add a flat +3–4 to each row and leave the ranking unchanged. Also, `store.Memo` has by far the heaviest usage inside `store/test` (72 sites), so if test fixtures inside the data layer counted, Memo would close much of the gap on raw site count — but User still leads on package spread.
