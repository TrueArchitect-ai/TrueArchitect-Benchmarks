**Premise correction: there is no GraphQL in this repository.** A case-insensitive search for `graphql`/`gqlgen` across Go, TypeScript, JSON, and `go.mod`, plus a filesystem search for `*.graphql`/`*.gql`, returns zero matches. No schema, no resolvers, no dependency.

**Actual API surface: Protocol Buffers–defined gRPC services, exposed over three transports.**

**Schema definition.** The contract lives in `.proto` files under `proto/api/v1/`: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`. Persistence-side messages are separate, in `proto/store/` (e.g. `proto/store/memo.proto`, `proto/store/idp.proto`). Code generation is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`) into `proto/gen/` — Go structs, gRPC stubs, gRPC-Gateway shims (`proto/gen/api/v1/*.pb.gw.go`), and Connect handlers (`proto/gen/api/v1/apiv1connect/`).

**Transports**, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`):

1. **REST/JSON via gRPC-Gateway** — mounted on `/api/v1/*` and `/file/*` (`server/router/api/v1/v1.go:128-129`), body-capped at 256 MiB (`:126`).
2. **Connect RPC** for browser clients — `/memos.api.v1.*` (`server/router/api/v1/v1.go:141-144`), with the interceptor chain at `:133-138`. Handler methods are the `ConnectServiceHandler` wrappers in `server/router/api/v1/connect_services.go`, delegating to `APIV1Service`.
3. **Plain HTTP file routes** outside the proto surface — `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), plus RSS (`server/router/rss/rss.go`) and the SPA/sitemap routes (`server/router/frontend/frontend.go`).

**The nearest thing to a queryable schema document** is OpenAPI, not GraphQL: a spec is generated to `proto/gen/openapi.yaml` and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-11`. Its only consumer is the MCP router, which unmarshals it at `server/router/mcp/service.go:78` to build its tool catalog.
