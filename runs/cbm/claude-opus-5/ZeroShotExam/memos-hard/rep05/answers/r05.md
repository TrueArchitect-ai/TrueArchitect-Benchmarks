**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive sweep for `graphql`/`gqlgen`/`.graphql`/`.gql` across the entire repo (excluding `.git` and `node_modules`) returns zero hits — no schema files, no resolvers, no server library dependency. Memos (the project here) has never exposed a GraphQL API.

**Actual API surface:** the public API is defined in **Protocol Buffers**, not GraphQL.

**Schema definitions — `proto/api/v1/*.proto`**

Eight services, all in package `memos.api.v1`:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto:17` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto:13` | `AuthService` |
| `proto/api/v1/attachment_service.proto:15` | `AttachmentService` |
| `proto/api/v1/instance_service.proto:17` | `InstanceService` |

`proto/api/v1/common.proto` holds shared types. Separately, `proto/store/*.proto` defines internal persistence types — not part of the public API.

**Design convention:** `proto/api/v1/README.md` states the API follows the [Google API Improvement Proposals](https://google.aip.dev/) — hence the resource-name/`List*`/`BatchGet*` style you see instead of GraphQL-style queries.

**Three wire protocols, one schema.** Each RPC carries a `google.api.http` annotation, so `proto/buf.gen.yaml` generates all transports from the same `.proto` files:

- **gRPC** — `buf.build/grpc/go` → `proto/gen/api/v1/*_grpc.pb.go`
- **REST/JSON** via grpc-gateway — `*.pb.gw.go`, registered in `server/router/api/v1/v1.go:99-122` under `/api/v1`
- **Connect RPC** — mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:140-144`)

**Generated artifacts (do not hand-edit; regenerate with `buf generate` per `proto/README.md`):**

- `proto/gen/openapi.yaml` — OpenAPI 3.0.3 spec, generated by the gnostic plugin. This is the closest thing to a "schema for the public API" in a single browsable document. It's embedded into the binary via `proto/openapi_embed.go` and consumed at `server/router/mcp/service.go:78` to build the MCP tool catalog.
- `web/src/types/proto/` — TypeScript client types, generated by `buf.build/bufbuild/es` for the frontend.

**Non-proto HTTP endpoints** live alongside as separate routers: `server/router/rss/`, `server/router/fileserver/`, `server/router/frontend/`, plus SSE (`RegisterSSERoutes`, `server/router/api/v1/v1.go:125`).

So if you're looking for the file to edit to change the public API, it's the relevant `proto/api/v1/*_service.proto`, followed by `buf generate` and implementing the method in `server/router/api/v1/`.
