**h14.**

**Computation site**

- `RebuildMemoPayload(ctx, memo, markdownService)` — `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, then calls the markdown service once and assigns `Payload.Tags` and `Payload.Property`.
- The actual extraction is `(*service).ExtractAll` in `internal/markdown/markdown.go:356` — a single goldmark AST parse + walk (there are also standalone `ExtractTags` at `:143` and `ExtractProperties` at `:193`, but `ExtractAll` is what the rebuild path uses).

**Triggers**

- **CreateMemo** — `server/router/api/v1/memo_service.go:108`, after the content-length check, before `Store.CreateMemo`.
- **UpdateMemo** — `server/router/api/v1/memo_service.go:447`, only when the update mask contains the `content` path; the rebuilt `memo.Payload` is put on `update.Payload`.
- **Batch backfill** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` walks all memos in batches of 100 and rewrites each payload via `Store.UpdateMemo`. Note this runner is not wired into `server/server.go` in the current tree (only the s3presign runner's `RunOnce` is called there, `server/server.go:163`), so it's a rebuild entry point that nothing currently invokes at startup.

Other payload fields are *not* derived: `Payload.Location` is set from the request right after the rebuild (`memo_service.go:112`), so it must be re-applied because rebuild only touches `Tags` and `Property`.

**Extracted properties**

Into `MemoPayload.Tags` (`proto/store/memo.proto`):
- all `#tag` nodes found in the AST, deduplicated with original case preserved (`uniquePreserveCase`, `markdown.go:417`).

Into `MemoPayload.Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any `east.KindTaskCheckBox`.
- `HasIncompleteTasks` — a task checkbox with `IsChecked == false`.
- `Title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`, `markdown.go:172`); otherwise empty.

`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` discards them — mentions are consumed separately in `server/router/api/v1/memo_mention_helpers.go:32`.

These land on the API as `Memo.Property` via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`, called at `:49`) and drive the web filter chips `property.hasLink` / `property.hasTaskList` / `property.hasCode` (`web/src/hooks/useMemoFilters.ts:73-77`). The list preview text itself is a separate, non-persisted derivation — `getMemoContentSnippet` at conversion time (`memo_service_converter.go:76`).
