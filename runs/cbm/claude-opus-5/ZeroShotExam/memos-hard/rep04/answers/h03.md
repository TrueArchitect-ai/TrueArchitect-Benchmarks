**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package: `internal/idp`** — `internal/idp/idp.go` is the whole package: it declares the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any IdP implementation must produce. Note it's a shared data contract, not a Go interface — there is no `IdentityProvider` interface type.
- **Implementation package: `internal/idp/oauth2`** — `internal/idp/oauth2/oauth2.go` (`// Package oauth2 implements the OAuth2 identity provider integration.`) defines `IdentityProvider` over `storepb.OAuth2Config` with `NewIdentityProvider`, `ExchangeToken` (with PKCE `code_verifier` support), and `UserInfo`, which returns `*idp.IdentityProviderUserInfo`.

OAuth2 is the only protocol that ships: the store enum in `proto/gen/store/idp.pb.go:26-29` has just `TYPE_UNSPECIFIED` and `OAUTH2`, and the login path in `server/router/api/v1/auth_service_sso.go:104-135` branches on `storepb.IdentityProvider_OAUTH2` alone (no SAML/OIDC-specific package).
