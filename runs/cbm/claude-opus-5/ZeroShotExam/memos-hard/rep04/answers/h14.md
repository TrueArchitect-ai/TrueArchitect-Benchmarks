**computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parse to the goldmark-based markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356`. The result is stored in the memo's `payload` column as `MemoPayload.property` / `MemoPayload.tags` (`proto/store/memo.proto`), and surfaced on the API via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`, mapped to `Memo.property`, an OUTPUT_ONLY field — `proto/api/v1/memo_service.proto:256,272-279`).

**triggers**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the row is written.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when `content` appears in the update mask; the fresh payload is then put on `update.Payload` (line 451). Other mask paths (visibility, pinned, state, location…) do not recompute it.
- Bulk backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:29`, which pages all memos in batches of 100, rebuilds each payload and writes it back with `UpdateMemo`. Note this runner is not currently wired into startup: `server/server.go:153-173` only starts the s3presign runner, so it's an available migration/repair path rather than an active one.

**extracted properties** — one AST walk over the memo content yields:
- `tags` — all memo tag nodes, deduplicated while preserving original case (`uniquePreserveCase`).
- `property.has_link` — any `KindLink` node.
- `property.has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `property.has_task_list` — any `TaskCheckBox` node.
- `property.has_incomplete_tasks` — any `TaskCheckBox` with `IsChecked == false`.
- `property.title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`), otherwise empty.

`ExtractAll` also returns `mentions` (lowercased `@username`s), but `RebuildMemoPayload` discards them — mentions are consumed separately for inbox notifications (`server/router/api/v1/memo_mention_helpers.go:32`). Separately, `Memo.snippet` is *not* part of this payload; it's computed per-response at conversion time via `getMemoContentSnippet` (`memo_service_converter.go:76,225`).
