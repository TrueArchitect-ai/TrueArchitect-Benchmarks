**Premise correction:** This repository (Memos, `github.com/usememos/memos`) has **no GraphQL schema at all**. There is no `.graphql`/`.gql` file, no schema-definition file, no gqlgen/Apollo dependency, and no occurrence of the string "graphql" in any tracked file. I verified with `git grep -il "graphql"`, `git grep -il "gqlgen\|apollo\|\.graphql"`, and a grep of `web/package.json` — all three returned exit code 1 (no matches).

**Actual API surface: Protocol Buffers → gRPC + Connect + REST, with a generated OpenAPI spec.**

**Schema source of truth — `proto/api/v1/*.proto`** (package `memos.api.v1`). Eight services:

| Service | File |
|---|---|
| `MemoService` | `proto/api/v1/memo_service.proto:17` |
| `UserService` | `proto/api/v1/user_service.proto:17` |
| `InstanceService` | `proto/api/v1/instance_service.proto:17` |
| `AttachmentService` | `proto/api/v1/attachment_service.proto:15` |
| `AuthService` | `proto/api/v1/auth_service.proto:13` |
| `IdentityProviderService` | `proto/api/v1/idp_service.proto:14` |
| `ShortcutService` | `proto/api/v1/shortcut_service.proto:14` |
| `AIService` | `proto/api/v1/ai_service.proto:11` |

Shared types live in `proto/api/v1/common.proto`. A separate `proto/store/*.proto` set defines internal persistence messages — not part of the public API.

REST is expressed as `google.api.http` annotations on each RPC rather than a separate schema, e.g. `proto/api/v1/memo_service.proto:21-27`:

```proto
rpc CreateMemo(CreateMemoRequest) returns (Memo) {
  option (google.api.http) = { post: "/api/v1/memos" body: "memo" };
  option (google.api.method_signature) = "memo";
}
```

The design follows Google's AIPs (`proto/api/v1/README.md`).

**Code generation** — `proto/buf.gen.yaml` runs five plugins over the protos: protobuf-go, grpc-go, connect-go, grpc-gateway, and gnostic-openapi (all into `proto/gen/`), plus `bufbuild/es` emitting TypeScript clients into `web/src/types/proto`. Regenerate with `buf generate` (`proto/README.md`).

**Serving** — three transports over the same handler:
- **Connect/gRPC** — `server/router/api/v1/connect_handler.go:31-44` registers all eight services on an `http.ServeMux`.
- **REST via grpc-gateway** — `server/router/api/v1/v1.go:65-125` (`RegisterGateway`), wired from `server/server.go:88`, with shared auth middleware at `v1.go:69-93`.
- **OpenAPI 3.0.3 spec** — generated to `proto/gen/openapi.yaml` (4,057 lines, paths under `/api/v1/...`) and embedded into the binary via `proto/openapi_embed.go`. It also drives the MCP endpoint's tool definitions (`server/router/mcp/openapi.go`).

If you're looking for the closest analogue to "the schema for the public API," it's `proto/api/v1/*.proto` as the authored source, with `proto/gen/openapi.yaml` as the generated, consumable description.
