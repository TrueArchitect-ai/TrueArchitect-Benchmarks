**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark-based `markdownService.ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk). The result is assigned to `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`) and persisted in the memo row's `payload` column (decoded back at e.g. `store/db/sqlite/memo.go:180`).

**Triggers:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only on the `content` field of the update mask; the fresh payload goes into `update.Payload` (line 451). Other mask paths (visibility, pinned, location, …) don't recompute — the `location` path at line 482 mutates the existing payload in place.
- Bulk backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds every memo in batches of 100 and writes each back via `UpdateMemo`. Note this runner is currently not wired up anywhere: the only non-test references to the `memopayload` package are the two `memo_service.go` call sites.

Because the rebuild only overwrites `Tags` and `Property`, user-set payload fields on the same struct (notably `Location`) survive.

**Extracted properties** (`internal/markdown/markdown.go:371-419`, mirrored in `ExtractProperties` at :193):
- `Tags` — all `#tag` nodes not nested inside a link/image (`asMemoTagNode`, :134), deduplicated case-preserving.
- `Property.Title` — text of the first block-level child if it's an H1 heading.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any GFM task checkbox.
- `Property.HasIncompleteTasks` — any unchecked task checkbox.

(`ExtractAll` also collects lowercase `Mentions`, but `RebuildMemoPayload` ignores them — mentions are used separately in `server/router/api/v1/memo_mention_helpers.go:32`.)

Related but distinct: the list/preview `snippet` is *not* stored — it's regenerated per response by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`, 64-char limit) via `GenerateSnippet` (`internal/markdown/markdown.go:264`), and attached during conversion at `server/router/api/v1/memo_service_converter.go:76-80`.
