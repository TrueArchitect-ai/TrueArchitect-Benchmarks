**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package: `internal/idp`** — `internal/idp/idp.go` defines the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any identity provider implementation normalizes to.
- **Implementation package: `internal/idp/oauth2`** — `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration") provides `IdentityProvider` with `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with PKCE support), and user-info retrieval via field mapping.

OAuth2 is the only concrete protocol that ships: `proto/store/idp.proto:22-23` declares a `oneof config` with a single variant, `OAuth2Config`, and the sole consumer `server/router/api/v1/auth_service_sso.go:12-13` imports exactly those two packages.
