**1st: `store.User` (~6–7 packages outside `store/`); 2nd: `store.Memo` (~4–6 packages)**

**The data layer** is the `store/` package (`store/store.go`, `store/driver.go`), which defines the persistent entity types: `User` (`store/user.go:29`), `Memo` (`store/memo.go:35`), `Attachment` (`store/attachment.go:16`), `Inbox` (`store/inbox.go:24`), `Reaction` (`store/reaction.go:7`), `MemoRelation` (`store/memo_relation.go:16`), `MemoShare` (`store/memo_share.go:6`), `UserIdentity` (`store/user_identity.go:8`), `UserSetting` (`store/user_setting.go:13`), `IdentityProvider` (`store/idp.go:12`), `InstanceSetting` (`store/instance_setting.go:14`).

Counting distinct Go packages outside the `store/` tree that reference each type (`store.<Type>`, excluding `store/db/*` and `store/test` which are part of the layer itself):

| Type | Packages | Where |
|---|---|---|
| **User** | **7** | `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss` |
| **Memo** | **6** | `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload` |
| Attachment | 4 | `server/router/api/v1`, `.../test`, `server/router/fileserver`, `server/router/rss` |

`User` is the widest-reaching because it's the identity carried through the auth path — `server/auth/authenticator.go:61,102,128,190` returns and stores `*store.User` in request context (`server/auth/context.go:55`), so every request-handling package touches it. `Memo` is second: it's the core content entity, reaching the API layer, RSS feed, notifications, and the `memopayload` background runner.

Notes on the ranking's robustness:
- Excluding `_test.go` files, User = 6 packages vs. Memo = 4 (`server/router/frontend` and `server/router/fileserver` reference Memo only in tests).
- Widening to each type's whole query-struct family (`FindX`/`UpdateX`/`DeleteX`) ties them at 7 each, since `store.FindMemo` appears in `server/router/fileserver`. So User's lead is real but narrow — Memo is essentially co-equal by that measure.
