**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction package — `internal/idp`** (`internal/idp/idp.go`): defines the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that any provider implementation returns.
- **Implementation package — `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`): the only concrete protocol implementation. It provides `IdentityProvider` backed by `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (authorization code + optional PKCE `code_verifier`, via `golang.org/x/oauth2`), and `UserInfo` (bearer-token call to the configured userinfo URL, mapped through `FieldMapping`).

Supporting evidence:
- `server/router/api/v1/auth_service_sso.go:104-130` — `resolveSSOIdentity` switches on the provider type and constructs `oauth2.NewIdentityProvider(identityProvider.Config.GetOauth2Config())`, then exchanges the code and fetches user info.
- `proto/gen/store/idp.pb.go:27-28` — the `IdentityProvider_Type` enum only has `TYPE_UNSPECIFIED` and `OAUTH2`, confirming OAuth2 is the sole shipped protocol (no SAML/OIDC-specific implementation).
- Persistence lives in `store/idp.go` and identity links in `store/user_identity.go`.
