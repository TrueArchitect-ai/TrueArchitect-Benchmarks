**Computation site**

`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` is the single place memo metadata is derived. It delegates to the markdown service's single-pass AST walk, `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (the same extraction also exists standalone as `ExtractProperties`, `internal/markdown/markdown.go:193`), and assigns the result onto the memo's stored payload:

```go
memo.Payload.Tags = data.Tags
memo.Payload.Property = data.Property
```

The shape is defined in `proto/store/memo.proto` (`MemoPayload.Property`, commented "The calculated properties from the memo content") and surfaced to the API as `OUTPUT_ONLY` fields (`proto/api/v1/memo_service.proto:256`) via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`, called at `:48-49`).

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check, before `Store.CreateMemo`.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when `"content"` is in the update mask; the rebuilt payload is written along with the new content (`update.Payload = memo.Payload`).
- Bulk backfill — `(*Runner).RunOnce` in `server/runner/memopayload/runner.go:27` walks all memos in batches of 100, rebuilding and re-saving each payload. Note this runner is never constructed anywhere (`memopayload.NewRunner` has no callers; `server/server.go:162` only wires the s3presign runner), so today it's a dormant/manual entry point.

**Extracted properties**

From one goldmark AST walk over the content:

- `Title` — plain text of the first block-level child of the document if it's an H1 heading (`extractHeadingText`, `internal/markdown/markdown.go:168`).
- `HasLink` — any `KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any GFM `TaskCheckBox`.
- `HasIncompleteTasks` — a `TaskCheckBox` with `IsChecked == false`.
- Alongside these, `Payload.Tags` — `#tag` nodes (excluding tags nested inside links/images, `asMemoTagNode`), deduplicated preserving case. (`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` doesn't persist them.)

One related-but-separate derived field: `Memo.snippet` is *not* stored — it's computed per response at conversion time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`), which calls `MarkdownService.GenerateSnippet(content, 64)`.
