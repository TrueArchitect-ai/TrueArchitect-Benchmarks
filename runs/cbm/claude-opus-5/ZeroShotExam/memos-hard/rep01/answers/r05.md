**Premise correction:** There is no GraphQL schema in this repository. Memos (`github.com/usememos/memos`) has no GraphQL server, schema files, or client anywhere:

- `grep -ril "graphql"` across the whole repo returns **zero** matches
- No `*.graphql` / `*.gql` / `*.graphqls` files exist
- `go.mod` has no GraphQL library (no gqlgen, graphql-go, etc.)
- `web/package.json` has no `graphql`, `apollo`, `urql`, or `relay` dependency

## Actual API surface: Protobuf/gRPC, served three ways

The schema of record is **Protocol Buffers** in `proto/api/v1/`:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto:17` | `MemoService` (memos, comments, reactions, relations, shares, link metadata) |
| `proto/api/v1/user_service.proto:17` | `UserService` (users, settings, PATs, webhooks, notifications, linked identities) |
| `proto/api/v1/auth_service.proto:13` | `AuthService` (sign in/out, refresh token) |
| `proto/api/v1/attachment_service.proto:15` | `AttachmentService` |
| `proto/api/v1/instance_service.proto:17` | `InstanceService` (profile, settings, stats) |
| `proto/api/v1/shortcut_service.proto:14` | `ShortcutService` |
| `proto/api/v1/idp_service.proto:14` | `IdentityProviderService` |
| `proto/api/v1/ai_service.proto:11` | `AIService` (transcribe) |
| `proto/api/v1/common.proto` | shared types |

Design convention is documented in `proto/api/v1/README.md`: Google AIP resource-oriented style (`memos/*`, `users/*` resource names).

**Codegen** (`proto/buf.gen.yaml`) fans one schema out to four targets: Go structs + gRPC stubs + Connect handlers + grpc-gateway into `proto/gen/`, plus TypeScript clients into `web/src/types/proto`.

**Three wire protocols, one schema** — registered in `server/router/api/v1/v1.go:65` (`RegisterGateway`), wired up at `server/server.go:88`:
1. **REST/JSON** via grpc-gateway at `/api/v1/...`, from `google.api.http` annotations in the protos (e.g. `post: "/api/v1/memos"` at `proto/api/v1/memo_service.proto:23`)
2. **Connect RPC** at `/memos.api.v1.*` (`v1.go:144`)
3. **gRPC** proper, from the same service definitions

**The closest thing to a "public API schema document"** is the generated OpenAPI 3.0.3 spec at `proto/gen/openapi.yaml` (4,057 lines), embedded into the binary via `proto/openapi_embed.go` and consumed by the MCP server at `server/router/mcp/openapi.go`.

Other non-proto HTTP surfaces: RSS (`server/router/rss/rss.go`), file serving (`server/router/fileserver/fileserver.go`), MCP (`server/router/mcp/service.go`), and SSE (`RegisterSSERoutes`, `v1.go:125`).
