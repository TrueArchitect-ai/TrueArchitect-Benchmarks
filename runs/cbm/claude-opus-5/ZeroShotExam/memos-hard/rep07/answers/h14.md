**Computation site; triggers; extracted properties**

**Computation site**

- `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (lines 80–86).
- The actual extraction is `(*service).ExtractAll` in `internal/markdown/markdown.go:356` — one goldmark parse plus a single AST walk that collects everything at once (there's also a standalone `ExtractProperties` at `markdown.go:193` doing just the property half, used in tests/benchmarks).
- The payload shape is `storepb.MemoPayload` / `MemoPayload_Property` (`proto/gen/store/memo.pb.go:24,85`), stored as the memo's JSON payload column; it's surfaced to the API in `server/router/api/v1/memo_service_converter.go:48-50` (`memoMessage.Tags`, `memoMessage.Property`).

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the memo is inserted.
- `UpdateMemo`, only when the update mask contains `content` — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written along with the content via `update.Payload = memo.Payload` (line 450). Other mask paths (visibility, pinned, state, timestamps) do not recompute.
- Bulk backfill: `(*Runner).RunOnce` — `server/runner/memopayload/runner.go:27`, which pages through all memos in batches of 100 and re-derives + persists each payload. Note this runner is not currently wired up anywhere — `server/server.go:162` only constructs the `s3presign` runner — so it's effectively a dormant/manual backfill path.

**What it extracts**

From `ExtractAll` (`internal/markdown/markdown.go:371-419`):

- `Tags` — `#tag` nodes (custom `mast.TagNode`), skipping tags nested inside links/images (`asMemoTagNode`, `markdown.go:134`), deduplicated preserving case.
- `Mentions` — `@username` nodes, lowercased and deduplicated (computed but *not* persisted into the payload by `RebuildMemoPayload`; consumed elsewhere by the caller of `ExtractAll`).
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (`extractHeadingText`, `markdown.go:173`).
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any GFM task checkbox.
- `Property.HasIncompleteTasks` — any task checkbox with `IsChecked == false`.

These property flags are what the memo filters query (`store/test/memo_filter_test.go:523-610`) and what user stats aggregate (`server/router/api/v1/user_service_stats.go:141-151`).

Separately, the list/preview `snippet` is *not* stored in the payload — it's derived on each read at conversion time: `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83`, called from `memo_service_converter.go:76` and for relations at `memo_service_converter.go:225,248`), which walks the AST for plain text, skips code blocks, and truncates at a word boundary (`internal/markdown/markdown.go:264,472`).
