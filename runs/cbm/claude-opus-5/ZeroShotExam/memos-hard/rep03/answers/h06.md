**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

The dispatch helpers in `server/router/api/v1/memo_service_webhooks.go` (`dispatchMemoRelatedWebhook` :48 and `DispatchMemoCommentCreatedWebhook` :30) load the user's configured endpoints via `s.Store.GetUserWebhooks`, set `payload.URL = hook.Url`, and hand off to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`. The four queue-worker goroutines started in `init()` (:42-55) call `Post`, which is the sole place the outbound request is built and issued (`safeClient.Do(req)` at :152). So `PostAsync` is the common enqueue point and `Post` is the single function where every path converges immediately before delivery.

The URL is user-configured through `CreateUserWebhook` / `UpdateUserWebhook` in `server/router/api/v1/user_service_webhooks.go`, which validate it with `webhook.ValidateURL` (`internal/webhook/validate.go:62`); `Post` additionally guards at dial time via `safeDialContext` (`internal/webhook/webhook.go:59`) against reserved/private IPs unless `webhook.AllowPrivateIPs` is set.
