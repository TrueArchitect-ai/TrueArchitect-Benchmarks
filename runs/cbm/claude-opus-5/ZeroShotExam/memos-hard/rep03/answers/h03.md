**`internal/idp`; `internal/idp/oauth2`**

- **Abstraction:** `internal/idp/idp.go` — package `idp` defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every SSO provider must produce.
- **Implementation:** `internal/idp/oauth2/oauth2.go` — package `oauth2` ("implements the OAuth2 identity provider integration") with `IdentityProvider`, `NewIdentityProvider(*storepb.OAuth2Config)`, exchange + userinfo fetch mapped through `storepb.FieldMapping`.

OAuth2 is the only concrete protocol: `proto/store/idp.proto:11-23` declares a single enum value `OAUTH2 = 1` and a single `oauth2_config` in the config oneof, and the SSO login path in `server/router/api/v1/auth_service_sso.go:119-121` switches to `oauth2.NewIdentityProvider(...)` as its only branch.
