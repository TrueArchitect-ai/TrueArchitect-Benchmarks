**Computation site**

- `internal/markdown/markdown.go` — `(*service).ExtractAll` (`internal/markdown/markdown.go:356`) does a single goldmark AST walk and fills `ExtractedData.Property` (`*storepb.MemoPayload_Property`). A standalone `(*service).ExtractProperties` (`internal/markdown/markdown.go:193`) contains the same walk for property-only use.
- The wrapper that actually attaches it to a memo is `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which sets `memo.Payload.Tags` and `memo.Payload.Property` from the extraction result. The result is persisted in the memo's `payload` JSON (`proto/store/memo.proto:8,15`) and surfaced to the API via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`).

**Triggers (recomputation)**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every memo creation (before the store write, after content-length validation).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes `content`; the new payload is written via `update.Payload`. Other mask paths do not recompute — notably the `location` path (`server/router/api/v1/memo_service.go:481-484`) reuses the existing `memo.Payload` and only overwrites `Location`.
- Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) walks all memos in batches of 100, calls `RebuildMemoPayload` on each, and persists via `store.UpdateMemo`. Note this runner is defined but not wired into startup — `server/server.go:163` only invokes the `s3presign` runner — so it's currently a manual/unused migration path.

**Extracted properties** (`proto/store/memo.proto:15-23`, computed in the AST walk at `internal/markdown/markdown.go:381-404`)

- `has_link` — true if any `gast.KindLink` node is present.
- `has_code` — true for `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `has_task_list` — true if any GFM `TaskCheckBox` node exists.
- `has_incomplete_tasks` — true if any task checkbox has `IsChecked == false`.
- `title` — plain text of the document's first block-level child, only if it is an H1 heading (`extractHeadingText`, `internal/markdown/markdown.go:167`).

Alongside the property, the same pass derives `payload.tags` (deduplicated `#tags`, case preserved) and `mentions`. The list/preview `snippet` is *not* stored in the payload — it's generated per request by `GenerateSnippet` (`internal/markdown/markdown.go:264`) during API conversion (`server/router/api/v1/memo_service_converter.go:76,225`).
