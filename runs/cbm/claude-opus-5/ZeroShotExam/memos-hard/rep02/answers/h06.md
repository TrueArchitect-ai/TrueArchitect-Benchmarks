**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

Every dispatcher funnels into `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`:42-55`) then call `Post`, which is the single place the outbound request is built and sent (`http.NewRequest("POST", requestPayload.URL, …)` at `:126`, `safeClient.Do(req)` at `:152`). If you count only synchronous call edges, `PostAsync` is the last shared caller; `Post` is the function that actually performs delivery.

Notes on the guardrails on that path: URLs are validated at configuration time by `webhook.ValidateURL` (`internal/webhook/validate.go`), and `safeClient`'s transport uses `safeDialContext` (`internal/webhook/webhook.go:59`) to reject reserved/private IPs at dial time.

A separate, non-webhook outbound path exists: `GetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:46`) → `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go:141`). It fetches a URL supplied in the request rather than a stored user configuration, and it does not go through `webhook.Post`.
