h15.

Memo visibility is enforced at many independent server sites — there is no single chokepoint. The store layer (`store/memo.go`) only *supports* filtering (`FindMemo.VisibilityList`, `Filters`); it applies nothing on its own, so every surface below re-implements the rule.

**Core gRPC memo reads**
- `checkMemoReadAccess` (single-memo read gate: archived→creator-only, non-public→auth required, private→creator only) — `server/router/api/v1/memo_service.go:39-68` (called from `GetMemo` :356, parent memo :367, and `ListMemoComments`)
- `ListMemos` query-level visibility filter (anon → PUBLIC; else `creator_id == N || visibility in ["PUBLIC","PROTECTED"]`) — `server/router/api/v1/memo_service.go:218-227`
- `ListMemoComments` — gate on parent via `checkMemoReadAccess`, then per-comment visibility filter — `server/router/api/v1/memo_service_comments.go:148-165`
- `CreateMemoComment` private-parent gate — `server/router/api/v1/memo_service_comments.go:41`

**Attachments / binary serving**
- `FileServerService.checkAttachmentPermission` (public+anonymous-allowed, share-token fallback, private→creator/admin) — `server/router/fileserver/fileserver.go:650-705`
- Attachment binary/read access check — `server/router/api/v1/attachment_service.go:436-454`
- `ListMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:213-227`

**Reactions**
- `ListMemoReactions` / `UpsertMemoReaction` visibility checks — `server/router/api/v1/reaction_service.go:29-41` and `:82-85`

**Live/push delivery**
- SSE per-client delivery filter `SSEClient.canReceive` (private → creator or admin; unknown visibility → deny) — `server/router/api/v1/sse_hub.go:134-144`

**Notifications / inbox**
- `canViewerAccessMemo` for user notifications — `server/router/api/v1/user_service_notifications.go:307-317`
- `canUserAccessMentionContext` / `shouldSkipMentionInbox` for @-mention inbox items — `server/router/api/v1/memo_mention_helpers.go:61-89`

**Aggregates and public/unauthenticated surfaces**
- User stats (`ListAllUserStats`, per-user stats) visibility filters — `server/router/api/v1/user_service_stats.go:76-92` and `:217-221`
- RSS feeds — public-only find (`VisibilityList: []store.Visibility{store.Public}`) — `server/router/rss/rss.go:90` (explore) and `:141` (per-user)
- Sitemap XML — public-only memo list — `server/router/frontend/frontend.go:149-151`

**Share-token bypass path**
- `GetMemoByShare` / `getActiveMemoShare` — deliberately bypasses visibility; enforcement is token validity, expiry, and archived-state instead — `server/router/api/v1/memo_share_service.go:153-208` (share create/delete owner checks at `:43`, `:92`, `:132`)
