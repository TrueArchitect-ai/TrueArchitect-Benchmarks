**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for "graphql" across the entire tree (`grep -ril "graphql" .`) returns zero matches, and there are no `.graphql`/`.gql`/`.graphqls` files. Memos has never exposed a GraphQL API — the README describes it as offering "full REST and gRPC APIs."

**Actual public API surface — Protocol Buffers, in `proto/api/v1/`:**

The schema of record is a set of `.proto` service definitions:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`
- `proto/api/v1/README.md` — states the API follows the [Google AIP](https://google.aip.dev/) guidelines

REST is not hand-written; it's derived from `google.api.http` annotations on each RPC (e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`).

**Code generation** (`proto/buf.gen.yaml`) fans the protos out into four surfaces:
1. Go protobuf + gRPC stubs → `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`
2. Connect RPC handlers → `proto/gen/api/v1/apiv1connect/`
3. grpc-gateway REST shims → `proto/gen/api/v1/*.pb.gw.go`
4. OpenAPI spec → `proto/gen/openapi.yaml`, embedded into the binary via `proto/openapi_embed.go`
5. TypeScript clients for the web app → `web/src/types/proto/`

**Server wiring** — `server/router/api/v1/v1.go`:
- Lines 96–120: `runtime.NewServeMux()` + `Register*ServiceHandlerServer` mount the REST/gRPC-gateway routes under `/api/v1/...`
- Lines 139–144: a Connect RPC mux served at `/memos.api.v1.*`
- Registered from `server/server.go:87` via `apiV1Service.RegisterGateway(ctx, echoServer)`

Non-RPC HTTP surfaces also exist: `server/router/rss`, `server/router/fileserver`, and an MCP endpoint (`server/router/mcp`).

So if you're looking for "the schema for the public API," the answer is `proto/api/v1/*.proto`; if you want a browsable spec artifact, it's the generated `proto/gen/openapi.yaml`.
