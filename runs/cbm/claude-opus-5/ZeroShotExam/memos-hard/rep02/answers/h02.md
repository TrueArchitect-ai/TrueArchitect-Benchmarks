**Where delivery executes**

- Call sites are in `server/router/api/v1/memo_service_webhooks.go` — `dispatchMemoRelatedWebhook` (created/updated/deleted, line 48) and `DispatchMemoCommentCreatedWebhook` (line 30). Both call `webhook.PostAsync`.
- `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto a bounded 128-slot channel `asyncPostQueue` and drops the payload with a warning if full.
- The actual outbound HTTP request happens in `Post` (`internal/webhook/webhook.go:120`), executed by one of 4 background worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`). `Post` marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`), and issues `safeClient.Do(req)` at line 152.

**SSRF protection**

Two layers, both keyed on `isReservedIP` (`internal/webhook/validate.go:44`), which checks against a parsed CIDR list covering IPv4 loopback, RFC-1918 ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 `::1/128`, `fc00::/7`, `fe80::/10` (`internal/webhook/validate.go:14-23`):

1. **At configuration time** — `webhook.ValidateURL` (`internal/webhook/validate.go:62`) enforces http/https scheme and rejects hostnames resolving to reserved IPs. Called when a user sets webhooks in `server/router/api/v1/user_service_webhooks.go:74, 161, 182`.
2. **At dial time (the real guard)** — `safeClient`'s Transport uses `safeDialContext` (`internal/webhook/webhook.go:59`), which re-resolves the host and refuses the connection if any resolved address is reserved. This is what defeats DNS rebinding / TOCTOU between validation and delivery.

Escape hatch: `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP`, disabling both layers. It's set from the `--allow-private-webhooks` flag at `cmd/memos/main.go:49` (flag defined at line 133), default false.
