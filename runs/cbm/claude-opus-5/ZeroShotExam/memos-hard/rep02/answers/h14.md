**Triggers** — exactly two call sites, both content-driven:

Other mask paths (visibility, pinned, location, etc.) do not recompute it — the `location` branch at `:481-484` reuses the existing payload.

Note it is never wired up — `grep` finds no `memopayload.NewRunner` caller (unlike `s3presignRunner.RunOnce` at `server/server.go:163`), so today it's dead/manual-use code.

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go:362-419`), mirrored by the standalone `ExtractTags` (`:143`) and `ExtractProperties` (`:193`):
- `Tags` — `#tag` nodes, skipping tags nested inside links/images (`asMemoTagNode`, `:134`), deduplicated case-preserving via `uniquePreserveCase`.

- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `Property.HasTaskList` — any `TaskCheckBox` node; and `Property.HasIncompleteTasks` when such a checkbox is unchecked.
