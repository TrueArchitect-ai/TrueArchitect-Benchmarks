**Computation site.** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates the actual work to the goldmark-based markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356-422` (a single AST parse + walk). `RebuildMemoPayload` writes only `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85-86); user-set fields like `Payload.Location` are left alone and assigned separately (`server/router/api/v1/memo_service.go:111-113`). The stored shape is `MemoPayload.Property`, documented in `proto/store/memo.proto:14-22` as "The calculated properties from the memo content."

**Triggers.**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every memo creation (after the content-length check, before `Store.CreateMemo`).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the recomputed payload is written along with the new content (`update.Payload = memo.Payload`, line 452). Updating visibility, pinned state, etc. does not recompute.
- A batch backfill path exists: `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72` re-runs `RebuildMemoPayload` over all memos in batches of 100. Note it is currently not wired up anywhere — `grep` for `memopayload.` finds only the two `memo_service.go` call sites, so nothing constructs this runner today.

**Extracted properties.** From `ExtractAll` (`internal/markdown/markdown.go:376-408`):
- `Tags` — `#tag` nodes, skipping tags nested inside links/images (`asMemoTagNode`, markdown.go:134-140), deduplicated preserving original case (line 418).
- `Property.Title` — text of the first block-level child of the document if it is an H1 heading (lines 384-389, via `extractHeadingText`).
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any GFM task checkbox.
- `Property.HasIncompleteTasks` — any task checkbox with `IsChecked == false`.

`ExtractAll` also collects `Mentions` (lowercased `@username` nodes, line 379-381), but `RebuildMemoPayload` discards them — they are not part of the persisted payload.

**Consumers (the "lists/previews" use).** `Property` is converted to the API type in `server/router/api/v1/memo_service_converter.go:49,315` and aggregated in `server/router/api/v1/user_service_stats.go:141-152,257-268`; it is also filterable in the store (`store/test/memo_filter_test.go:523-610`). Separately and *not* stored, the list/preview `snippet` is generated on the fly at conversion time by `GenerateSnippet` (`internal/markdown/markdown.go:264-346`) via `getMemoContentSnippet` (`memo_service_converter.go:76-80`, `memo_relation_service.go:154-173`, `user_service_notifications.go:318-323`).
