**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

Every handler funnels through `dispatchMemoRelatedWebhook`/`DispatchMemoCommentCreatedWebhook`, which are the only two callers of `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` merely enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`webhook.go:42-55`) all call `Post`, which builds the `POST` and issues it via `safeClient.Do` (`webhook.go:152`). So `Post` is the single point where any of these paths actually leave the process — if you count the enqueue point rather than the send, that's `PostAsync`, but delivery itself happens only in `Post`.

Note SSRF guarding sits on that same choke point: `safeClient`'s transport uses `safeDialContext` (`webhook.go:59`), which resolves the host and rejects reserved/private IPs, with URL-level validation in `internal/webhook/validate.go` (bypassable via the `AllowPrivateIPs` flag).
