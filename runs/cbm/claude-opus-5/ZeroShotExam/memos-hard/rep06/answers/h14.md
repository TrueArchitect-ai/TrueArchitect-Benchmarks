**Computation site; triggers; extracted properties**

**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates the actual parse to the goldmark-backed markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:355-421` (a single AST walk). The result is stored on the memo's `MemoPayload` (schema: `proto/store/memo.proto`, `MemoPayload.Property` / `MemoPayload.Tags`).

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (before the store insert; user-supplied `Location` is applied after, so it isn't clobbered).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask contains `content`; the rebuilt payload is written via `update.Payload`.
- Batch backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72`, which pages all memos in batches of 100 and rewrites each payload. Note: this runner is only defined; nothing in `cmd/` or `server/server.go` currently constructs or calls it, unlike the s3presign runner (`server/server.go:163`).

**Extracted properties:** `MemoPayload.Property` (`proto/store/memo.proto:12-19`):
- `has_link` — any `KindLink` node
- `has_code` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`
- `has_task_list` — any `TaskCheckBox` node
- `has_incomplete_tasks` — a `TaskCheckBox` with `IsChecked == false`
- `title` — text of the first block-level child of the document if it's an H1 heading (`extractHeadingText`)

The same pass also fills `MemoPayload.Tags` (deduped `#tag` nodes, case preserved) and collects mentions (used for mention notifications, not persisted in the payload). Exposed to the API through `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315-326`) as `Memo.property` / `Memo.tags`.

Related but *not* stored: `Memo.snippet` is derived per-response at conversion time via `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-90`, called from `memo_service_converter.go:76` and the batch relation path at :225/:248).
