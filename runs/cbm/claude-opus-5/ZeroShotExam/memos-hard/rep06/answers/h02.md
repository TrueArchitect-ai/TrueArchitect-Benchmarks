### How it works

**Where delivery executes.** Memo events call `webhook.PostAsync(payload)` from `server/router/api/v1/memo_service_webhooks.go:43,71` (create/update/delete via `dispatchMemoRelatedWebhook`, plus comment-created). `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto a bounded 128-slot channel and drops with a warning if full. Four goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`, which is where the request is actually marshalled, optionally HMAC-signed (Standard Webhooks `webhook-id`/`webhook-timestamp`/`webhook-signature` headers), and sent.

**Two layers of SSRF protection:**

1. **Dial-time blocking (the real guard).** `safeClient` (`internal/webhook/webhook.go:32-37`) uses a `Transport` with `DialContext: safeDialContext`. `safeDialContext` (`internal/webhook/webhook.go:59-77`) splits the address, resolves the host itself, and rejects the connection if *any* resolved IP is reserved. Because this runs at connect time rather than at save time, it also defeats DNS rebinding — a hostname that passed validation but later resolves to `127.0.0.1` still fails.

2. **Admission-time validation.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is called when a user registers or updates a webhook — `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. It enforces a parseable absolute URL, an `http`/`https` scheme, and that the hostname doesn't resolve to a reserved range, returning a gRPC `InvalidArgument`.

Both layers share `isReservedIP` (`internal/webhook/validate.go:44`), which tests against `reservedNetworks` — CIDRs parsed once at startup from `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (explicitly covering the cloud IMDS address `169.254.169.254`), and the IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10`.

One caveat worth flagging: the escape hatch `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` to `false`, disabling both layers. It is declared but never assigned anywhere in the non-test code — no flag, env var, or config wires it up — so it is effectively hardcoded to `false` today.
