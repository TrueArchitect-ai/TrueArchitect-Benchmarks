## Notes on the count

- The `store` package is imported unaliased everywhere (only `import "github.com/usememos/memos/store"` appears), so a `\bstore\.<Type>\b` match is a reliable proxy for a reference.
- Word-boundary matching keeps `MemoRelation` and `MemoShare` counted as their own entities rather than folded into `Memo`.
- Apparent hits for `IdentityProvider`, `UserSetting`, and `InstanceSetting` in `proto/gen/store` are false positives — protobuf descriptor strings like `memos.store.IdentityProvider` in `proto/gen/store/idp.pb.go:432`, not Go references to the store package. Those three entity types are used only within the data layer itself; callers outside it go through the protobuf `storepb` equivalents instead.
- `User` edges out `Memo` mainly because of `server/auth`, which handles authentication and so touches `store.User` without needing memos. The ranking holds whether or not test packages are included (non-test only: User 5, Memo 4).
