**h14.**

**Computation site**

`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` is the single entry point. It ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns both `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85-86).

The actual extraction is `(*service).ExtractAll` in `internal/markdown/markdown.go:356` — one goldmark parse + single `gast.Walk` over the AST (there's also a standalone `ExtractProperties` at markdown.go:193, but the payload path uses `ExtractAll` for the single-pass efficiency).

**Triggers (recomputation)**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert (location is layered on afterwards, at :112-114).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is then written via `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, timestamps) don't recompute.
- Bulk backfill — `(*Runner).RunOnce` in `server/runner/memopayload/runner.go:27` walks all memos in batches of 100 and rewrites each payload. Note this runner is defined but not wired into startup — nothing constructs `memopayload.NewRunner` (unlike `s3presignRunner.RunOnce` at `server/server.go:163`), so in practice only create/update recompute.

**Extracted properties**

Per `proto/store/memo.proto` (`MemoPayload.Property`, fields 1-5) and the walk in markdown.go:371-411:

- `has_link` — any `gast.KindLink` node
- `has_code` — `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`
- `has_task_list` — any `east.KindTaskCheckBox`
- `has_incomplete_tasks` — a task checkbox with `IsChecked == false`
- `title` — plain text of the document's first block-level child if it is an H1 heading (`extractHeadingText`, markdown.go:173)

Alongside these, `ExtractAll` also returns `Tags` (deduped, case-preserving via `uniquePreserveCase`, markdown.go:418) which `RebuildMemoPayload` stores as `Payload.Tags`; `Mentions` is extracted too but not persisted in the payload.

**Consumers:** surfaced to the API by `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`, called at :49), aggregated in `server/router/api/v1/user_service_stats.go:141-152`, and used by the web filters `property.hasLink` / `property.hasCode` (`web/src/hooks/useMemoFilters.ts:73-77`). The list *snippet* itself is separate — computed on the fly by `getMemoContentSnippet` (converter.go:76), not stored in the payload.
