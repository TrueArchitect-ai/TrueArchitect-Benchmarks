**delivery function** — `webhook.Post` in `internal/webhook/webhook.go:120` (lines 120–180). It marshals the payload, builds the POST, optionally adds Standard Webhooks HMAC-SHA256 headers, and executes the request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**protection mechanism** — two layers:

1. **Dial-time SSRF guard (the real enforcement):** `safeClient` is constructed with a custom `Transport.DialContext` = `safeDialContext` (`internal/webhook/webhook.go:29-37`, `internal/webhook/webhook.go:59-77`). On every connection it re-resolves the hostname with `net.DefaultResolver.LookupHost` and refuses to dial if any resolved address is reserved/private — so it also defeats DNS rebinding, since the check happens at connect time rather than at save time.
2. **Reserved-range predicate + save-time validation:** `isReservedIP` and `ValidateURL` in `internal/webhook/validate.go` (`isReservedIP` at line 44, `ValidateURL` at line 62). `ValidateURL` enforces http/https scheme and rejects hostnames resolving into the blocklist; it's called when a user creates/updates a webhook in `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. The blocked ranges are `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, RFC-1918 (10/8, 172.16/12, 192.168/16), link-local 169.254/16 (cloud IMDS), plus IPv6 `::1/128`, `fc00::/7`, `fe80::/10`.

Dispatch is enqueued asynchronously via `webhook.PostAsync` (`internal/webhook/webhook.go:184`) from `server/router/api/v1/memo_service_webhooks.go:43,71`; four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain the 128-slot queue and call `Post`.

Two caveats worth noting:

- `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global kill-switch that disables both layers when true, but nothing in `cmd/`, `internal/profile/`, or the server wires it — it is only ever set in `internal/webhook/webhook_test.go:91,142`. In production it stays `false`, so the guard is always on and there is currently no supported way for self-hosters to opt out despite the doc comment.
- `safeDialContext` resolves the host itself, checks all returned IPs, then hands the *hostname* back to `net.Dialer.DialContext` (`internal/webhook/webhook.go:76`), which resolves a second time. The check and the connect use separate lookups, so a narrow TOCTOU window remains; dialing the already-vetted IP would close it.
