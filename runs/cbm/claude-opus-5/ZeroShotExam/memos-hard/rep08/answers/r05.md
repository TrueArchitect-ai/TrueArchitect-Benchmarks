**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across the entire repo (excluding `.git`/`node_modules`) returns zero matches — no `.graphql`/`.gql` files, no resolvers, no GraphQL server or client dependency. Memos (this is `usememos/memos`) has never exposed a GraphQL API.

**The actual public API surface: Protobuf/gRPC, with REST and Connect transports generated from it.**

The single source of truth is the `.proto` files in `proto/api/v1/` (package `memos.api.v1`):

- `proto/api/v1/memo_service.proto` — `MemoService` (memos, comments, reactions, relations, attachments, shares, link metadata)
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared types

Separately, `proto/store/*.proto` defines internal persistence messages (not a public API surface).

**Codegen and transports** — driven by `proto/buf.gen.yaml`:
- Go message/gRPC/Connect/grpc-gateway stubs → `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, `*_connect*`, `*.pb.gw.go`
- OpenAPI 3.0.3 spec (via gnostic) → `proto/gen/openapi.yaml` (~4,000 lines), embedded into the binary by `proto/openapi_embed.go`
- TypeScript client types → `web/src/types/proto` (buf `es` plugin)

**Serving** — `server/router/api/v1/v1.go:65` (`RegisterGateway`) mounts the grpc-gateway handlers for each service under `/api/v1` (lines 99–121), registers SSE routes (line 125), and registers Connect handlers (line 141). This is wired up from `server/server.go:88`. Service implementations live alongside in `server/router/api/v1/*.go` (e.g. `memo_service.go`, `auth_service.go`).

Regeneration is via `buf generate` from `proto/` (`proto/README.md`), and the API follows Google AIP conventions (`proto/api/v1/README.md`).
