The repo uses hand-written SQL (no ORM tags/`TableName()`), so the mapping is between the store-layer structs and the table names used in the `store/db/{sqlite,mysql,postgres}` drivers.

| table | Struct — path |
|---|---|
| `user` | `User` — `/bench/repo/store/user.go:29` (SQL: `store/db/sqlite/user.go:17,164`, `store/db/mysql/user.go:18`, `store/db/postgres/user.go:61,155` — quoted `"user"` in Postgres since it's a reserved word) |
| `attachment` | `Attachment` — `/bench/repo/store/attachment.go:16` (SQL: `store/db/sqlite/attachment.go`, and `store/db/sqlite/user_delete.go:180,393`) |
| `reaction` | `Reaction` — `/bench/repo/store/reaction.go:7` (SQL: `store/db/sqlite/reaction.go:60,113`) |

Each is defined once in `store/` and shared by all three DB drivers; the per-driver files only hold the column lists and statements.
