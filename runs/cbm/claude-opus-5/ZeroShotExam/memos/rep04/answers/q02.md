**sqlite, mysql, postgres**

Migrations live under `store/migration/`, one directory per dialect:
- `store/migration/sqlite/` (e.g. `LATEST.sql`, `0.22/00__resource_storage_type.sql`)
- `store/migration/mysql/` (e.g. `LATEST.sql`, `0.24/00__memo.sql`)
- `store/migration/postgres/` (e.g. `LATEST.sql`, `0.28/00__user_identity.sql`)

The directory is embedded and selected at runtime by driver name in `store/migrator.go:44` (`//go:embed migration`) and `store/migrator.go:254-256`, which builds the path as `migration/<profile.Driver>/`. This matches the three driver implementations in `store/db/` (`sqlite`, `mysql`, `postgres`). Note that only sqlite has a seed directory (`store/seed/sqlite/`).
