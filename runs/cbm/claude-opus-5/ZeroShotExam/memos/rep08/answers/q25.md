**Engine:** Google CEL (`github.com/google/cel-go`, go.mod:13), wrapped by the in-repo memo filter engine at **`internal/filter/`** (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, documented in `internal/filter/README.md`).

**Mechanism (one sentence):** `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) validates `request.Filter` via `validateFilter` (`server/router/api/v1/shortcut_service.go:336`) and appends it to `store.FindMemo.Filters`; each dialect driver then calls `filter.DefaultEngine()` + `filter.AppendConditions(...)` (`store/db/sqlite/memo.go:57-61`, `store/db/mysql/memo.go:65-69`, `store/db/postgres/memo.go:54-58`), which runs a three-phase pipeline — cel-go compiles the expression against the memo-specific CEL env declared in `internal/filter/schema.go` (allowed variables `content`, `tag`/`tags`, `visibility`, `created_ts`, `has_task_list`, `now`, …), `internal/filter/parser.go` normalizes the CEL AST into the dialect-agnostic condition IR of `internal/filter/ir.go`, and `internal/filter/render.go` walks that IR to emit a dialect-specific SQL fragment plus placeholder args (`Statement{SQL, Args}`), which `AppendConditions` (`internal/filter/helpers.go:9`) appends to the query's `WHERE` list.

Dialect handling details:
- Dialect enum `DialectSQLite`/`DialectMySQL`/`DialectPostgres` in `internal/filter/schema.go:10-16`; per-field column expressions are keyed by dialect in `Field.Expressions` (e.g. `creator` → `('users/' || %s)` on SQLite/Postgres vs `CONCAT(...)` on MySQL, `internal/filter/schema.go:104-107`), resolved by `Field.columnExpr` (`schema.go:321`).
- The renderer encapsulates the rest: `?` vs `$n` placeholders (with `PlaceholderOffset` so fragments compose with pre-existing args), JSON payload access (`json_extract` / `->>` ), tags (`LIKE` on SQLite, `JSON_CONTAINS` on MySQL, `@>` on Postgres), `LIKE` vs `ILIKE`, and regex (`REGEXP` vs `~`, with SQLite's `regexp` implemented in Go at `store/db/sqlite/functions.go`).

Note there is a second, separate CEL filter path for users (`server/router/api/v1/user_service_filter.go`) and a parallel attachment schema/engine (`filter.DefaultAttachmentEngine()`, `internal/filter/schema.go:303`) — neither is used by `ListMemos`.
