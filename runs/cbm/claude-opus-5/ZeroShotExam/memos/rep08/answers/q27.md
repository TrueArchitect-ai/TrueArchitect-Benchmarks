**Answer: Go `embed.FS` (compiled into the binary, served as static files by an Echo middleware with SPA fallback); `server/router/frontend/frontend.go`**

How it works:

1. **Build step** — `web/package.json:14` defines `"release": "vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir"`, so the Vite production build emits into `server/router/frontend/dist`.

2. **Embedding** — `server/router/frontend/frontend.go:20-21`:
   ```go
   //go:embed dist/*
   var embeddedFiles embed.FS
   ```
   The `dist` directory is compiled into the Go binary. (In the repo, `server/router/frontend/dist/` contains only a placeholder `index.html`; CI/Docker runs the `release` script to populate it.)

3. **Serving** — `FrontendService.Serve` (`server/router/frontend/frontend.go:41`) calls `getFileSystem("dist")` (`fs.Sub` on the embedded FS) and registers `middleware.StaticWithConfig` with that filesystem, plus `spaFallbackMiddleware` (`frontend.go:62`) which serves `index.html` on 404s for extension-less paths so client-side routing works. A `Skipper` excludes `/api`, `/file`, gRPC-web `/memos.api.v1*`, `robots.txt`, `sitemap.xml`, and `rss.xml`, and sets cache headers (no-cache for HTML, `max-age=3600, immutable` for `/assets/`).

4. **Wiring into the server** — `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
