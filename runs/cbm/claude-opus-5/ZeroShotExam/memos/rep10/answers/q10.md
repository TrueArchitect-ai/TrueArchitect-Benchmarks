**`store/migration/sqlite/LATEST.sql`**

For a fresh install, the migrator skips the incremental version migrations and applies this single full-schema file:

- `store/migrator.go:56` — `LatestSchemaFileName = "LATEST.sql"`
- `store/migrator.go:42` — documents it as "Full schema for new installations (faster than incremental migrations)"
- `store/migrator.go:27` — `preMigrate` checks whether the DB is initialized and, if not, applies `LATEST.sql`
- `store/test/migrator_test.go:18` — `TestFreshInstall` verifies `LATEST.sql` applies correctly on a fresh database

The per-version files under `store/migration/sqlite/0.x/` are only used to upgrade existing databases. (Equivalent files exist for the other drivers, e.g. `store/migration/mysql/LATEST.sql` and `store/migration/postgres/LATEST.sql`.)
