How it fits together:

- `web/package.json:11` — the `release` script runs `vite build --mode release --outDir=../server/router/frontend/dist --emptyOutDir`, so the compiled React bundle lands in `server/router/frontend/dist`.
- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` embeds that directory into `embeddedFiles`, and `getFileSystem("dist")` (`frontend.go:115-121`) exposes it as a sub-`fs.FS`. No files are read from disk at runtime.
- `server/router/frontend/frontend.go:54-57` — `middleware.StaticWithConfig` serves those assets, with a skipper that bypasses `/api`, `/file`, gRPC-web `/memos.api.v1*` paths, and `robots.txt`/`sitemap.xml`/`rss.xml` (`frontend.go:82-90`).

- `server/server.go:72` — wired in via `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
