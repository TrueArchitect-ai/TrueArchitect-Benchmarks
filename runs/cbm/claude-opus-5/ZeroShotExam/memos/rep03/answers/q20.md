**Mechanism:** Server-Sent Events (SSE) over plain HTTP — a single `GET /api/v1/sse` streaming endpoint (`Content-Type: text/event-stream`, Bearer-token auth, 30s heartbeat comments). No WebSockets. The browser consumes it with `fetch()` rather than `EventSource` (so it can send the `Authorization` header) in `web/src/hooks/useLiveMemoRefresh.ts:202`, and turns each event into TanStack Query cache invalidations.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`, 32-event buffered per-client channel, drops events for slow clients) with `NewSSEHub`/`Subscribe`/`Unsubscribe`/`Broadcast`/`Close`. Per-client delivery filtering by visibility/creator lives in `SSEClient.canReceive` (`sse_hub.go:134`). The connection handler is `server/router/api/v1/sse_handler.go`, registered at `server/router/api/v1/v1.go:125`; the hub is owned by `APIV1Service` (`v1.go:36,57`) and closed on shutdown in `server/server.go:205`.
