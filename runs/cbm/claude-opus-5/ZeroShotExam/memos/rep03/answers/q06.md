**`memo_relation`**

The table stores links between a memo and another related memo:

- `/bench/repo/store/migration/sqlite/LATEST.sql:47-52` — `CREATE TABLE memo_relation (memo_id INTEGER NOT NULL, related_memo_id INTEGER NOT NULL, type TEXT NOT NULL, UNIQUE(memo_id, related_memo_id, type))`
- Originally introduced in `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql`
- Equivalent definitions exist for the other drivers in `/bench/repo/store/migration/postgres/LATEST.sql` and `/bench/repo/store/migration/mysql/LATEST.sql`

The `type` column distinguishes the kind of link (e.g. reference vs. comment).
