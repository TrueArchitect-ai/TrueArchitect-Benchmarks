There are no ORM tags or `TableName()` methods in this repo — the mapping is hand-written SQL in the per-dialect driver packages, which is where each struct is bound to its table:

- `store.User` → `user`: `store/db/sqlite/user.go:17` (`INSERT INTO user ...`), `store/db/postgres/user.go:16` (`INSERT INTO "user" ...`, quoted since `user` is a reserved word in Postgres), plus a MySQL equivalent under `store/db/mysql/user.go`.
- `store.Attachment` → `attachment`: `store/db/sqlite/attachment.go:34`, `store/db/postgres/attachment.go:33`.
- `store.Reaction` → `reaction`: `store/db/sqlite/reaction.go:16`, and the Postgres counterpart in `store/db/postgres/reaction.go`.

Note the related-but-distinct structs in the same files (`FindUser`, `UpdateAttachment`, `DeleteReaction`, etc.) are query/mutation parameter types, not row types.
