**Engine:** Google CEL (`github.com/google/cel-go`, go.mod:13) driving a custom in-house filter engine at `internal/filter/` — `engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`, `helpers.go` (documented in `internal/filter/README.md`).

**Mechanism (one sentence):** `ListMemos` validates the filter string via `s.validateFilter` (`server/router/api/v1/memo_service.go:211-216` → `server/router/api/v1/shortcut_service.go:336`) and passes it through to `store.FindMemo.Filters`, where each store driver calls `filter.DefaultEngine()` + `filter.AppendConditions(...)` (`store/db/sqlite/memo.go:57-63`, `store/db/mysql/memo.go:65-71`, `store/db/postgres/memo.go:54-60`) which compiles the CEL text against the memo schema's CEL env (`Engine.Compile`, `internal/filter/engine.go:125`), normalizes the CEL AST into a dialect-agnostic condition IR (`parser.go` / `ir.go`), then renders that IR into a dialect-specific SQL `WHERE` fragment plus bound args (`render.go`, via `Program.Render`/`CompileToStatement`) which is appended to the query's where-clause list.

Details worth noting:

- **Schema-gated identifiers** — only fields declared in `NewSchema()` (`internal/filter/schema.go:88+`: `content`, `creator`, `creator_id`, `created_ts`, `updated_ts`, `pinned`, `tag`/`tags`, `visibility`, `has_task_list`, `has_link`, `has_code`, `has_incomplete_tasks`, `now`) are exposed as CEL variables, along with `ext.Sets()` (`schema.go:233-247`). Each field carries backing column, kind (scalar / bool column / JSON bool / JSON list / virtual alias) and per-dialect expression templates.
- **Per-dialect divergence lives in the renderer**, keyed on `DialectName` (`sqlite`/`mysql`/`postgres`, `schema.go:11-18`): placeholders are `?` for SQLite/MySQL and `$n` for Postgres with an offset so args compose with the rest of the query (`render.go:842-849`); tag membership is `LIKE` (SQLite) vs `JSON_CONTAINS` (MySQL) vs `@> jsonb_build_array` (Postgres) (`render.go:501-513`); timestamps use `UNIX_TIMESTAMP(%s)` on MySQL vs raw epoch BIGINT elsewhere (`schema.go:123-146`); booleans bind as 1/0 on SQLite (`render.go:851-864`).
- **Compile-time folding** — `now`, `duration(...)`, and `timestamp(...)` are evaluated during parsing to epoch seconds, with `now` frozen once per `Compile` (`engine.go:16-20`, `parser.go:517-706`).
- **Engine reuse** — `DefaultEngine()` / `DefaultAttachmentEngine()` are `sync.Once` singletons (`engine.go:101-123`); the same machinery serves attachments, shortcuts, memo relations, and user stats.
