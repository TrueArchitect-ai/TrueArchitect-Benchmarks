`web/src/connect.ts`

All ConnectRPC service clients are created in `/bench/repo/web/src/connect.ts`. The file builds the transport with `createConnectTransport` (`web/src/connect.ts:184`) using an auth interceptor, then exports the clients via `createClient` (`web/src/connect.ts:192-203`): `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. It also creates a separate interceptor-free transport and `refreshAuthClient` (`web/src/connect.ts:65-72`) to avoid recursion during token refresh.
