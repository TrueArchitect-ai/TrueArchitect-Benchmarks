**`store.Driver` — `/bench/repo/store/driver.go`** (declared at `store/driver.go:10`, package `store`).

It's the interface "for store driver... contains all methods that store database driver should implement" — `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, plus CRUD methods for every model (Attachment, Memo, MemoRelation, InstanceSetting, User, UserSetting, IdentityProvider, Inbox, Reaction, MemoShare, UserIdentity).

The three backends implementing it live under `store/db/`:
- `store/db/sqlite/sqlite.go`
- `store/db/mysql/mysql.go`
- `store/db/postgres/postgres.go`

They're selected at runtime by `NewDBDriver` in `store/db/db.go:14`, which returns a `store.Driver` based on `profile.Driver`.
