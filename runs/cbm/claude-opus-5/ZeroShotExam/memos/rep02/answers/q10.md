`store/migration/sqlite/LATEST.sql`

This is the file applied verbatim when the database isn't yet initialized. In `store/migrator.go`:
- `LatestSchemaFileName = "LATEST.sql"` (store/migrator.go:56), described as "Full schema for new installations (faster than incremental migrations)" (store/migrator.go:42)
- `preMigrate` reads `getMigrationBasePath() + LatestSchemaFileName` and executes it in one transaction when `IsInitialized` is false (store/migrator.go:211-236)
- `getMigrationBasePath()` returns `migration/<driver>/` (store/migrator.go:254-256), so for the SQLite driver it resolves to `migration/sqlite/LATEST.sql` in the embedded FS — i.e. `/bench/repo/store/migration/sqlite/LATEST.sql`.
