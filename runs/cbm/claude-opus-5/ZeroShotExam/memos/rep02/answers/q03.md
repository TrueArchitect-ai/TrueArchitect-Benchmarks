**DB — `store/db/postgres/postgres.go`**

The `postgres.DB` struct (`store/db/postgres/postgres.go:16`) implements the `store.Driver` interface for PostgreSQL. It holds a `*sql.DB` and the profile, and is constructed by `NewDB` (`store/db/postgres/postgres.go:21`), which opens the connection via the `github.com/lib/pq` driver and returns it as a `store.Driver`.

The rest of the interface methods are spread across sibling files in the same package (e.g. `store/db/postgres/memo.go`, `user.go`, `attachment.go`), all with receiver `(d *DB)`. It's selected by driver name in `store/db/db.go`.
