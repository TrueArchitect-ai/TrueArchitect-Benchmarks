`store/migration/sqlite/LATEST.sql`

This file holds the full current schema (all `CREATE TABLE` / index statements) applied to a fresh SQLite database.

- `store/migrator.go:56` defines `LatestSchemaFileName = "LATEST.sql"`, and the comments at `store/migrator.go:27,42` state that `preMigrate` checks whether the DB is initialized and, if not, applies `LATEST.sql` — "Full schema for new installations (faster than incremental migrations)".
- `store/test/migrator_test.go:18` confirms this in `TestFreshInstall`.

The versioned files under `store/migration/sqlite/<version>/` are incremental migrations for existing installs, not used for a fresh one. (Postgres and MySQL have their own equivalents at `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`.)
