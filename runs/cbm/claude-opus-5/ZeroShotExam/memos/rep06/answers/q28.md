**Runners the server actually starts**

- **s3presign runner (`server/runner/s3presign/runner.go`)** — the only thing registered in `startBackgroundRunners` (`server/server.go:153-174`). Trigger: one synchronous `RunOnce(ctx)` at startup (`server/server.go:163`), then a goroutine running `Run(s3Context)` driven by a plain `time.NewTicker(12h)` loop (`runner.go:27-41`), cancelled via the stored `context.CancelFunc` on shutdown (`server/server.go:156-159`, `176-182`). Inside each pass, actual re-presigning is data-triggered: an attachment is skipped unless its `LastPresignedTime` is older than 4 days (5-day URL expiry) (`runner.go:85-91`).
- **HTTP server goroutine (`server/server.go:124-128`)** — `httpServer.Serve(listener)`; trigger: `Server.Start`, stopped by `Shutdown`.
- **3 cache janitor goroutines (`store/cache/cache.go:83`, `cleanupLoop` at `:199-213`)** — started implicitly by `cache.New` for `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:38-53`). Trigger: `time.NewTicker(CleanupInterval = 5m)`; stopped by `Store.Close` (`store/store.go:72-79`).
- **4 webhook dispatch workers (`internal/webhook/webhook.go:42-55`)** — started by `init()`, not by the server. Trigger: messages on the buffered `asyncPostQueue` channel (event-driven, no timer).
- **2 email sender workers (`internal/email/email.go:16-35`)** — also started by package `init()`. Trigger: messages on `asyncEmailQueue`.
- **Per-connection SSE heartbeat (`server/router/api/v1/sse_handler.go:64`)** — one `time.NewTicker(30s)` per open SSE request, not a server-wide runner; torn down with the request / `SSEHub.Close()` (`server/server.go:203-208`).
- **Fire-and-forget PAT usage update (`server/auth/authenticator.go:178-184`)** — a one-shot goroutine per authenticated PAT request; request-triggered, unsupervised (not in the WaitGroup).
- **Signal watcher (`cmd/memos/main.go:99-103`)** — goroutine waiting on SIGINT/SIGTERM to call `s.Shutdown`.

**Scheduling infrastructure present but NOT used by the server**

- **`internal/scheduler/` — a full cron scheduler package (5/6-field cron parser, timezone support, middleware, graceful stop) is entirely unused in production code.** Its only importers are its own tests (`internal/scheduler/example_test.go:10`, `internal/scheduler/integration_test.go:13`); nothing in `server/`, `cmd/`, or `store/` references it. The one runner that is scheduled (s3presign) uses a hand-rolled `time.Ticker`, not this package.
- **`server/runner/memopayload` Runner is never started.** The server only calls the standalone `memopayload.RebuildMemoPayload` helper inline during memo create/update (`server/router/api/v1/memo_service.go:108`, `:447`); `Runner.RunOnce` (the full backfill over all memos, `server/runner/memopayload/runner.go:27`) has no non-test caller.
