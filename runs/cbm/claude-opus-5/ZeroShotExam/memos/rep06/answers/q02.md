**q02.**

MySQL, PostgreSQL, SQLite

The project ships migrations for three SQL dialects, each with its own directory under `store/migration/`:

- `store/migration/mysql/` — e.g. `store/migration/mysql/LATEST.sql`, `store/migration/mysql/0.30/00__user_tag_setting.sql`
- `store/migration/postgres/` — e.g. `store/migration/postgres/LATEST.sql`, `store/migration/postgres/0.28/00__user_identity.sql`
- `store/migration/sqlite/` — e.g. `store/migration/sqlite/LATEST.sql`

This matches the driver implementations under `store/db/` (`mysql`, `postgres`, `sqlite`). Note that seed data (`store/seed/`) is SQLite-only.
