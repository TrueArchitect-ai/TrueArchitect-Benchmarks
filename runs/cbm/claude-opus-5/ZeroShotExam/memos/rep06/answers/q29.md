**`web/src/connect.ts`; JWT access token (Bearer, localStorage) + refresh token (HttpOnly cookie), plus PATs on the backend; `server/auth/`**

**Interceptor** — `authInterceptor` in `web/src/connect.ts:145` is attached to the Connect-RPC transport (`web/src/connect.ts:170-175`) that backs every service client (memo, user, auth, attachment, etc.). Per request it:
1. Calls `getRequestToken()` and sets `Authorization: Bearer <token>`.
2. Preflight-refreshes if the token is within 30s of expiry (`REQUEST_TOKEN_EXPIRY_BUFFER_MS`).
3. On a `Code.Unauthenticated` response, refreshes once, replays the request with an `X-Retry: true` header to prevent loops, and on failure calls `redirectOnAuthFailure()` (`web/src/utils/auth-redirect.ts`).

**Tokens managed**
- **Access token** — short-lived JWT held in memory + `localStorage` (`memos_access_token` / `memos_token_expires_at`) in `web/src/auth-state.ts`, synced across tabs via a `BroadcastChannel` (`memos_token_sync`).
- **Refresh token** — never touched by JS; it's an HttpOnly cookie `memos_refresh` sent because the transport uses `credentials: "include"` (`web/src/connect.ts:57-63`). Refresh goes through a separate interceptor-free transport (`refreshTransport`) calling `AuthService.RefreshToken`, deduplicated by `tokenRefreshManager` so the focus-refresh hook (`web/src/hooks/useTokenRefreshOnFocus.ts`) and the 401 path can't race.

**Backend validation** — package `server/auth` (`server/auth/token.go`, `authenticator.go`, `extract.go`, `context.go`). `Authenticator.Authenticate` (`server/auth/authenticator.go:213`) is invoked from the Connect interceptor at `server/router/api/v1/connect_interceptors.go:222`, and resolves the bearer as either a stateless JWT access token (`AuthenticateByAccessTokenV2`, signature-only) or a `memos_pat_`-prefixed Personal Access Token checked against the store. Refresh tokens are validated separately by `AuthenticateByRefreshToken`, which also does a DB revocation lookup; constants (`AccessTokenDuration` 15m, `RefreshTokenDuration` 30d, `RefreshTokenCookieName`) live in `server/auth/token.go`.
