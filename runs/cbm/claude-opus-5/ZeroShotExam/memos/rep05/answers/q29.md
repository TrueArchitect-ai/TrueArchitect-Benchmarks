q29.

**`web/src/connect.ts`; JWT access token (localStorage, sent as `Authorization: Bearer`) + refresh token (HttpOnly `memos_refresh` cookie), plus PATs accepted on the same header; `server/auth/`**

Details:

**Interceptor** — `authInterceptor` in `web/src/connect.ts` is attached to the Connect-RPC transport (`createConnectTransport(..., interceptors: [authInterceptor])`) that backs every service client (memo, user, auth, attachment, etc.). It:
- calls `getRequestToken()` to fetch the access token, pre-emptively refreshing if it's within `REQUEST_TOKEN_EXPIRY_BUFFER_MS` (30s) of expiry, then sets `Authorization: Bearer <token>`;
- on a `Code.Unauthenticated` response, refreshes once and replays the request with an `X-Retry: true` header (guards against retry loops), redirecting via `redirectOnAuthFailure()` if the refresh fails;
- refreshes through a *separate* transport with no interceptors (`refreshTransport`/`refreshAuthClient`) to avoid recursion, with `credentials: "include"` so the refresh cookie is sent.

**Tokens** — `web/src/auth-state.ts` stores the access token in `localStorage` (`memos_access_token` / `memos_token_expires_at`) and syncs freshly-refreshed tokens across tabs via a `BroadcastChannel` (`memos_token_sync`). The refresh token itself is never in JS — it's the `memos_refresh` cookie (`server/auth/token.go:49`). Backend token kinds: 15-minute JWT access tokens, 30-day refresh tokens, and long-lived personal access tokens prefixed `memos_pat_` (`server/auth/token.go:35-52`).

**Backend validation** — `server/auth/`: `extract.go` pulls the bearer token / refresh cookie, `token.go` generates and parses the JWTs (audiences `user.access-token` / `user.refresh-token`) and hashes PATs, and `authenticator.go` exposes `Authenticate()` (`server/auth/authenticator.go:213`) with `AuthenticateByAccessTokenV2` (stateless), `AuthenticateByRefreshToken` (DB revocation + expiry check), and `AuthenticateByPAT` (hash lookup). It's invoked from the Connect interceptor at `server/router/api/v1/connect_interceptors.go:222`, the gRPC path in `server/router/api/v1/v1.go:78`, and the SSE handler at `server/router/api/v1/sse_handler.go:37`, wrapped by `Authorizer` in `server/router/api/v1/authz.go:44`.
