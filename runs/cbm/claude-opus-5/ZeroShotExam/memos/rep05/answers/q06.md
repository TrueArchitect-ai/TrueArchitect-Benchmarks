Schema (`/bench/repo/store/migration/sqlite/LATEST.sql:47-52`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It links a memo (`memo_id`) to another memo (`related_memo_id`) with a relation `type` (e.g. reference/comment).
