**Runners the server actually starts (`server/server.go:153` `startBackgroundRunners`):**

- **s3presign runner** (`server/runner/s3presign/runner.go`) — the only thing registered in `startBackgroundRunners`. Driven by a `time.Ticker` at a hardcoded `runnerInterval = 12h` (`runner.go:27,30`), plus one immediate synchronous `RunOnce(ctx)` at startup (`server/server.go:163`). It gets its own cancellable context whose cancel func is stored in `backgroundRunnerCancels`, and it's tracked by `backgroundRunnerWG` for graceful shutdown (`server/server.go:156-171`, `176-201`).

**Other long-lived goroutines started as a side effect of normal wiring (not part of the runner registry):**

- **HTTP server goroutine** — `go s.httpServer.Serve(listener)` (`server/server.go:124`); triggered once by `Server.Start`.
- **Store cache janitors ×3** — `cache.New` spawns `go c.cleanupLoop()` (`store/cache/cache.go:83,199-213`), ticking every `CleanupInterval = 5m` set in `store.New` (`store/store.go:40-53`); one each for `instanceSettingCache`, `userCache`, `userSettingCache`. Not tied to the server's shutdown WaitGroup.
- **Webhook dispatch pool (4 workers)** — `internal/webhook/webhook.go:41-54`, started in `init()`; queue-driven off the 128-buffered `asyncPostQueue`, fed by `webhook.PostAsync` (`webhook.go:182-190`, called from `server/router/api/v1/memo_service_webhooks.go:43,71`).
- **Email send pool (2 workers)** — `internal/email/email.go:16-35`, started in `init()`; queue-driven off `asyncEmailQueue`, fed by `email.SendAsync` (`email.go:52-57`, wired at `server/notification/email.go:30`).
- **Per-connection SSE heartbeat** — `time.NewTicker(sseHeartbeatInterval = 30s)` inside each SSE request handler (`server/router/api/v1/sse_handler.go:16-17,64`); lives for the request, cancelled by client disconnect or `SSEHub.Close()` on shutdown (`server/server.go:203-208`).
- **PAT last-used writer** — one-shot `go func` per authenticated PAT request (`server/auth/authenticator.go:178-184`); request-triggered, fire-and-forget.
- **Signal-handler goroutine** — waits on SIGINT/SIGTERM then calls `s.Shutdown` (`cmd/memos/main.go:99`).

**Unused scheduling infrastructure:**

- **`internal/scheduler`** — a full cron scheduler (5/6-field cron parser, timezone support, middleware chain with `Recovery`/`Logging`/`Timeout`, graceful shutdown) documented in `internal/scheduler/README.md` and `internal/scheduler/doc.go`. **Nothing in the server imports it** — the only importers are its own tests (`internal/scheduler/example_test.go:10`, `internal/scheduler/integration_test.go:13`). The one scheduled job that exists (s3presign) uses a plain ticker instead.
- **`memopayload.Runner`** (`server/runner/memopayload/runner.go`) — a runner type with `NewRunner`/`RunOnce` that rebuilds all memo payloads in batches, but `startBackgroundRunners` never constructs it. Only the free function `memopayload.RebuildMemoPayload` is used, called inline on the request path (`server/router/api/v1/memo_service.go:108,447`). So the `Runner` struct in that package is effectively dead code.
