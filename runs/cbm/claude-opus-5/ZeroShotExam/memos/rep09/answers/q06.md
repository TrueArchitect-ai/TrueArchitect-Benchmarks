q06. **`memo_relation`**

The table is defined identically across all three drivers:

- `store/migration/sqlite/LATEST.sql` (and its origin migration `store/migration/sqlite/0.13/00__memo_relation.sql`)
- `store/migration/postgres/LATEST.sql`
- `store/migration/mysql/LATEST.sql`

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

The `memo_id` → `related_memo_id` pair links a memo to another memo, with `type` describing the kind of link (e.g. reference vs. comment). Store-layer access lives in `store/memo_relation.go`, with per-driver implementations in `store/db/sqlite/memo_relation.go`, `store/db/postgres/memo_relation.go`, and `store/db/mysql/memo_relation.go`.
