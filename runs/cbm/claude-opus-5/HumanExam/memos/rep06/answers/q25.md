Engine: CEL (Google Common Expression Language) parsed with `cel-go`, in `internal/filter` (`internal/filter/engine.go`, entry point `filter.DefaultEngine()`; schema in `schema.go`, IR in `ir.go`, parser in `parser.go`, SQL renderer in `render.go`). Mechanism: the CEL AST is normalized into a dialect-agnostic IR, then `Engine.CompileToStatement` with `RenderOptions{Dialect: …}` renders a dialect-specific SQL fragment + args that each driver appends to its WHERE clause via `filter.AppendConditions` (`internal/filter/helpers.go:9`) — `store/db/sqlite/memo.go:57-61` (`DialectSQLite`), `store/db/postgres/memo.go:54-58` (`DialectPostgres`), `store/db/mysql/memo.go:65-69` (`DialectMySQL`), which is where `?` vs `$n`, `LIKE` vs `ILIKE`, and JSON access differences are handled.
