In `Store.DeleteMemo` (`store/memo.go:140-158`), before the memo row:
- `memo_relation` rows where the memo is the source (`MemoID`)
- `memo_relation` rows where the memo is the target (`RelatedMemoID`)
- all `attachment` rows linked to the memo (plus their backing local/S3 storage, via `Store.DeleteAttachment`, `store/attachment.go:132`)

Additionally, at the API layer `APIV1Service.DeleteMemo` deletes the memo's comment memos first (`server/router/api/v1/memo_service.go:570-578`).
