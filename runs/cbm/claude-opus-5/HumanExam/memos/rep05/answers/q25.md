Engine: CEL (`github.com/google/cel-go`) wrapped by the in-repo `filter` package — `internal/filter/engine.go` (`Engine`, `NewEngine`, `Compile`), schema in `internal/filter/schema.go`, IR in `internal/filter/ir.go`. Mechanism: the CEL expression is compiled into a dialect-agnostic `Condition` tree, then `internal/filter/render.go` renders it to a parameterized SQL `WHERE` fragment for the requested `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`), which each driver appends via `filter.AppendConditions` (`internal/filter/helpers.go:9`) in `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`. API-level validation lives in `server/router/api/v1/memo_service_filter.go`.
