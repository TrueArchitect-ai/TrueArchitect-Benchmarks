`Store.DeleteMemo` (`store/memo.go:140-166`) deletes, before the memo row:
1. `memo_relation` rows where the memo is the source (`MemoID`)
2. `memo_relation` rows where the memo is the target (`RelatedMemoID`)
3. all attachments linked to the memo (`attachment` rows + their stored blobs/files, via `Store.DeleteAttachment`, `store/attachment.go:132`)

Additionally, the API handler first deletes comment memos (`server/router/api/v1/memo_service.go:568-576`).
