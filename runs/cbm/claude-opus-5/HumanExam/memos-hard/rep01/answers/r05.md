— Premise is wrong: there is no GraphQL schema or GraphQL server anywhere (no `graphql` string in go.mod or any Go file). The actual public API surface is gRPC/Protobuf-defined: service and message definitions in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1`), exposed over HTTP two ways by `APIV1Service.RegisterGateway` — grpc-gateway REST transcoding and Connect RPC handlers (server/router/api/v1/v1.go:64+, server/router/api/v1/connect_handler.go, connect_services.go), registered at server/server.go:76, :88. Alongside it are plain Echo HTTP surfaces: `/healthz` (server/server.go:67), the file server `/file/attachments/...` and `/file/users/:identifier/avatar` (server/router/fileserver/fileserver.go:121-125), RSS feeds (server/router/rss/rss.go), an SSE endpoint (server/router/api/v1/sse_handler.go), and an MCP endpoint (server/router/mcp, wired at server/server.go:92-96).
