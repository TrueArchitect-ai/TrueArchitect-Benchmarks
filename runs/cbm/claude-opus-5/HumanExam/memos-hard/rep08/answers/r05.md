Premise is wrong: **there is no GraphQL API.** No GraphQL library, schema file, or resolver exists anywhere in the repo. The actual public API surface is Protobuf/gRPC-defined and served three ways:
- Service definitions: `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1/`.
- REST/JSON via grpc-gateway under `/api/v1` — `(*APIV1Service).RegisterGateway`, `server/router/api/v1/v1.go:65`, mounted at `server/server.go:88`.
- Connect-RPC handlers — `server/router/api/v1/connect_services.go` / `connect_handler.go`.
Plus non-RPC HTTP surfaces: file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), MCP (`server/router/mcp`), and `/healthz` (`server/server.go:67`).
