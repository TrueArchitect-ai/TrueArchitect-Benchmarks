— **Premise is wrong: there is no GraphQL schema or GraphQL server in this repo.** A case-insensitive search for `graphql` across Go sources and `go.mod` returns zero hits. The actual public API surface is **Protobuf/gRPC-defined**, in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1/`), exposed three ways over the single Echo HTTP server:
- **Connect-RPC** handlers — `server/router/api/v1/v1.go:133-141`, `server/router/api/v1/connect_services.go`
- **REST/JSON via gRPC-Gateway** (`google.api.http` annotations) — `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65-120`
- **MCP** (Model Context Protocol) + an OpenAPI document — `server/router/mcp/` (`openapi.go`), registered at `server/server.go:92-96`; embedded spec at `proto/openapi_embed.go`

Plus non-RPC HTTP surfaces: the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE, and `/healthz` (`server/server.go:67`).
