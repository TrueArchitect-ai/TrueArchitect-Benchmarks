Premise is wrong: there is **no Redis anywhere** in this repo — a repo-wide grep for "redis" over Go/TS/config files and `go.mod` returns zero hits. The cache layer is a hand-rolled **in-process, in-memory** cache: `store/cache/cache.go` (`Interface` at `cache.go:10`, `Cache` with a mutex map + background cleanup goroutine). There is no per-entity TTL for users specifically — all three caches (`instanceSettingCache`, `userCache`, `userSettingCache`) share one config created in `store.New`: `DefaultTTL = 10 * time.Minute`, `CleanupInterval = 5 * time.Minute`, `MaxItems = 1000` — `store/store.go:38-53` (defaults mirrored in `store/cache/cache.go:56-60`). User entries are set at `store/user.go:143,167` and invalidated on update/delete (`store/user_delete.go:39-46`).
