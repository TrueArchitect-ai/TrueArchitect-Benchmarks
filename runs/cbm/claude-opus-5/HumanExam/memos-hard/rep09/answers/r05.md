Premise is wrong: **there is no GraphQL schema or GraphQL server in this project** — grepping Go sources and `go.mod` for "graphql" returns nothing. The public API is defined in **Protocol Buffers** under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), served as **Connect RPC + gRPC-Gateway REST** — handlers registered in `server/router/api/v1/v1.go:133-141` and `RegisterGateway` at `server/server.go:88`. Additional non-gRPC surfaces: the HTTP file server `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`, registered `server/server.go:85`), SSE, and an MCP endpoint (`server/router/mcp`, registered `server/server.go:92-96`).
