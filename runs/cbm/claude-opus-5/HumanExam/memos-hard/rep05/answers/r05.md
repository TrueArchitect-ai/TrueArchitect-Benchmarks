Premise is wrong: **there is no GraphQL schema or server** — zero "graphql" matches across `.go`, `.proto`, and `go.mod`. Actual API surface:
- **Protobuf/gRPC + Connect** as the source of truth — service definitions under `proto/api/v1/`, generated into `proto/gen/api/v1/`; handlers implemented by `APIV1Service` (`server/router/api/v1/v1.go:29`).
- **REST/JSON via grpc-gateway**, registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`), mounted in `server/server.go:88`.
- **Plain HTTP file routes** — `/file/attachments/:uid/:filename`, `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:122-125`).
- **SSE** at `/api/v1/sse`, **RSS** feeds (`server/router/rss/rss.go`), `robots.txt`/`sitemap.xml` (`server/router/frontend/frontend.go:129-130`), `/healthz` (`server/server.go:66`), and an **MCP** endpoint that proxies the same REST API via a generated OpenAPI catalog (`server/router/mcp/adapter.go:27`, `server/router/mcp/openapi.go`).
