- **Delivery function:** `webhook.Post` — `internal/webhook/webhook.go:120`; the actual outbound call is `safeClient.Do(req)` at `internal/webhook/webhook.go:155`. Callers enqueue via `webhook.PostAsync` (`webhook.go:184`) onto a 128-slot channel drained by 4 goroutines (`webhook.go:37`, `webhook.go:41-52`).
- **Protection (two layers):**
  1. Dial-time SSRF guard: `safeClient`'s transport uses `safeDialContext` (`internal/webhook/webhook.go:32-37`, `webhook.go:59`), which resolves the host and rejects any reserved/private IP via `isReservedIP` (`internal/webhook/validate.go:44`) against `reservedCIDRs` (`internal/webhook/validate.go:14-23`, incl. loopback, RFC-1918, 169.254/16 IMDS, IPv6 equivalents). Doing this at dial time also defeats DNS rebinding.
  2. Config-time validation: `webhook.ValidateURL` (`internal/webhook/validate.go:62`) — scheme must be http/https and must not resolve to a reserved IP — invoked when users set webhooks at `server/router/api/v1/user_service_webhooks.go:74,161,182`.
  - Escape hatch: `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`), set from the `--allow-private-webhooks` flag (`cmd/memos/main.go:46,132`).
