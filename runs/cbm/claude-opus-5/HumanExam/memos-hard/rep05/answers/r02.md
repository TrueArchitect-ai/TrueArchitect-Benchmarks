Premise is wrong: **no rate-limiting middleware exists** — no "ratelimit"/"limiter"/"throttle" symbols anywhere in Go source, and no such dependency in `go.mod`. Only four middlewares are registered in total: `middleware.Recover()` and `newCORSMiddleware` (`server/server.go:51-52`), plus static-file and SPA-fallback middleware on the frontend router (`server/router/frontend/frontend.go:54,59`). The only per-request throttling of any kind is concurrency limiting on image work via `semaphore.Weighted` (`server/router/api/v1/v1.go:63-64`, `server/router/fileserver/fileserver.go:107`), which caps concurrency, not request rate.
