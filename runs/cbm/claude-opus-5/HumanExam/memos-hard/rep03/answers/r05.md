**Premise is wrong: there is no GraphQL in this project** — no `.graphql`/`.gql` files, no `gqlgen`/`graphql-go` dependency, and zero case-insensitive matches for `graphql` in Go or TS sources. The public API is **Protobuf-defined RPC**: service definitions live in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1/`. They are served two ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`): **Connect RPC** handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`) and a **gRPC-Gateway REST/JSON** mapping (`proto/gen/api/v1/*.pb.gw.go`). Alongside that sit plain Echo HTTP surfaces — the file server (`/file/...`, `server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), SSE (`server/router/api/v1/sse_handler.go`), `/healthz` (`server/server.go:64`), and an MCP endpoint (`server/router/mcp/service.go`, registered at `server/server.go:97`).
