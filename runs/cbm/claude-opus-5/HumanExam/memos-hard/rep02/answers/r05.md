— Premise is wrong: there is no GraphQL schema or GraphQL server in this codebase (zero matches for "graphql" in Go sources or `go.mod`). The public API is Protobuf/gRPC-defined, exposed over two HTTP transports plus several plain-HTTP routers:
- Service definitions: `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/api/v1`.
- Transports: gRPC-Gateway REST mux and Connect RPC handlers, both registered in `(*APIV1Service).RegisterGateway` — `server/router/api/v1/v1.go:65` onward; Connect handlers in `server/router/api/v1/connect_services.go`.
- Additional surfaces: SSE hub (`server/router/api/v1/sse_hub.go`), HTTP file server at `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go`), MCP (`server/router/mcp`, `server/server.go:92-96`), frontend static/sitemap (`server/router/frontend`), and `/healthz` (`server/server.go:67`).
