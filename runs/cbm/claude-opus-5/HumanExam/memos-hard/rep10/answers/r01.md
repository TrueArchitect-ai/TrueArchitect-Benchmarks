Premise is wrong: there is no Redis anywhere in the repo (no `redis` import, no Redis config; grep over `*.go` + `go.mod` returns nothing). Caching is a **hand-rolled in-process map cache**: `store/cache/cache.go` (`Cache` at `:187` for `Close`, `Interface` at `:11`). `Store` holds three instances — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:26-29`), all built with one `cache.Config` at `store/store.go:39-44`: `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000`. So **user entries expire after 10 minutes** (set via `s.userCache.Set` at `store/user.go:143,167`, which uses the default TTL); they are also invalidated explicitly on delete (`store/user_delete.go:39-46`). The cache is per-process and dies with it (`Store.Close` → `store/store.go:74-76`).
