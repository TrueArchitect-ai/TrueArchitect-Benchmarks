Premise is wrong: **there is no GraphQL in this project** (no schema files, no `gqlgen`/`graphql` dependency or import — grep over `*.go`, `*.proto`, `go.mod` returns nothing). The public API is **protobuf/gRPC-defined**, exposed three ways from one set of service definitions in `proto/api/v1/*.proto` (generated into `proto/gen/api/v1/`):
- REST/JSON via grpc-gateway under `/api/v1/*` — registered in `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:96-128`
- Connect RPC under `/memos.api.v1.*` for browser clients — `server/router/api/v1/v1.go:139-144`
- plus non-RPC HTTP surfaces: file serving `/file/*` (`server/router/fileserver/fileserver.go:121-125`), SSE (`server/router/api/v1/v1.go:125`), RSS (`server/server.go:85`), MCP (`server/server.go:92-96`), and `/healthz` (`server/server.go:67`).
An OpenAPI document is embedded for the REST surface (`proto/openapi_embed.go`).
