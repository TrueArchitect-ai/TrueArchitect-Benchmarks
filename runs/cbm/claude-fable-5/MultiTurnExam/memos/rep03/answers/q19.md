MemoService is served over:

1. **ConnectRPC (Connect protocol)** — `server/router/api/v1/connect_handler.go`: `RegisterConnectHandlers` mounts `apiv1connect.NewMemoServiceHandler(s, ...)` on the HTTP mux (line 40), with the per-RPC wrapping in `server/router/api/v1/connect_services.go` (e.g. `ConnectServiceHandler.CreateMemo` delegating to `APIV1Service`).

2. **REST via grpc-gateway (HTTP/JSON)** — `server/router/api/v1/v1.go`: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (line 108) registers the service on a grpc-gateway `runtime.ServeMux`, exposing the `google.api.http` REST mappings like `POST /api/v1/memos`.

There is no native gRPC server registration (`RegisterMemoServiceServer` / `grpc.NewServer` appear nowhere in `server/`).
