**Dispatcher:** `APIV1Service.dispatchMemoRelatedWebhook` — `server/router/api/v1/memo_service_webhooks.go` (called via the public wrapper `DispatchMemoCreatedWebhook`, which passes activity type `"memos.memo.created"`; it looks up the creator's webhooks with `Store.GetUserWebhooks` and hands each payload off).

**Delivery package:** `internal/webhook` (`github.com/usememos/memos/internal/webhook`) — delivery is asynchronous via `webhook.PostAsync(payload)`, with the HTTP POST logic in `internal/webhook/webhook.go`.

**Signing mechanism:** HMAC-SHA256 in the Standard Webhooks format — the secret (a `whsec_`-prefixed base64 key, see `GenerateSigningSecret` and `resolveSigningKey` in `internal/webhook/webhook.go`) is used to compute an HMAC-SHA256 over the request, sent base64-encoded in the `webhook-signature: v1,<signature>` header (`internal/webhook/webhook.go:142-149`).
