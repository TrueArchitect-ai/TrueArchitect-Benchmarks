The server starts exactly **one** background runner, in `Server.startBackgroundRunners` (`server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`, `server/server.go:163`), then continuously in a goroutine driven by a `time.Ticker` with a 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-35`), cancelled via a per-runner context on shutdown.

**Unused scheduling infrastructure:** the **memopayload runner** (`server/runner/memopayload/runner.go`) defines `NewRunner`/`RunOnce` scheduling machinery, but the server never instantiates or starts it — no call to `memopayload.NewRunner` exists outside the package. Only its stateless helper `memopayload.RebuildMemoPayload` is used, called inline from the memo handlers (`server/router/api/v1/memo_service.go:108` and `:447`) during memo create/update rather than on any schedule.
