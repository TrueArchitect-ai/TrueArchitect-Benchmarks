web/src/hooks/useMemoQueries.ts; memoServiceClient

The memo CRUD queries and mutations (list, get, create, update, delete, comments) live in `web/src/hooks/useMemoQueries.ts` using TanStack React Query. They all go through `memoServiceClient`, imported from `web/src/connect.ts`, where it's created with ConnectRPC's `createClient` from the generated `MemoService` definition (`web/src/types/proto/api/v1/memo_service_pb.ts`).
