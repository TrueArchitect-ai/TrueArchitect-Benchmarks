Memo lifecycle events that dispatch webhooks (all defined in `server/router/api/v1/memo_service_webhooks.go`):

- memo created (`memos.memo.created`): `DispatchMemoCreatedWebhook`
- memo updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook`
- memo deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook`
- comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook`

The first three are thin wrappers over the shared internal helper `dispatchMemoRelatedWebhook` (same file), which looks up the creator's webhooks; the comment variant looks up the parent memo owner's webhooks directly.

**Delivery convergence:** all paths converge on `webhook.PostAsync(payload)` in `internal/webhook/webhook.go:184`, which asynchronously wraps the synchronous `Post` (line 120) — the function that performs the actual HTTP POST with the HMAC-SHA256 `webhook-signature` header.
