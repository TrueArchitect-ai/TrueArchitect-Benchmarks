q25.

Engine: **CEL (Common Expression Language), parsed with `cel-go`** — the memo filter engine lives in **internal/filter/** (`engine.go`, `schema.go`, `parser.go`, `ir.go`, `render.go`; documented in `internal/filter/README.md`).

Mechanism: the filter string is parsed and schema-validated as a CEL expression (`internal/filter/engine.go` via `cel.NewEnv`), normalized into a dialect-agnostic IR (`internal/filter/ir.go`, `parser.go`), and then rendered by `internal/filter/render.go` into a SQL WHERE fragment plus placeholder args tailored to the target dialect (`DialectSQLite`/`DialectMySQL`/`DialectPostgres` — handling `?` vs `$n` placeholders, JSON access via `json_extract` vs `->>`, LIKE vs ILIKE, etc.); each driver invokes it when building the ListMemos query, e.g. `filter.DefaultEngine()` + `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` at `store/db/sqlite/memo.go:57-61` (similarly in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`).
