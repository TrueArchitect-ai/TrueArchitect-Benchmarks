**Engine:** Google CEL (Common Expression Language) via `github.com/google/cel-go` (go.mod:13), wrapped in the project's own filter package at `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`).

**Mechanism:** The filter string is parsed/checked as a CEL expression (`internal/filter/parser.go`, `engine.go`), lowered into an internal IR (`internal/filter/ir.go`), and then rendered by `internal/filter/render.go` into a parameterized SQL WHERE clause using a per-dialect renderer (`DialectSQLite` / `DialectMySQL` / `DialectPostgres`, which emit dialect-specific expressions like `strftime` vs. MySQL/Postgres date functions) — each dialect driver (e.g. `store/db/sqlite/memo.go`, which imports `internal/filter`) invokes this rendering when building the ListMemos query.
