store/migration/sqlite/LATEST.sql

For a fresh SQLite install the complete current schema is applied from `store/migration/sqlite/LATEST.sql` — it contains all `CREATE TABLE` statements (system_setting, user, memo, memo_relation, attachment, etc.), while the versioned subdirectories (`store/migration/sqlite/0.2` … `0.30`) hold incremental migrations for existing installs.
