**Runner actually started by the server:**

- s3presign runner (`server/runner/s3presign/runner.go`) — started in `Server.startBackgroundRunners` (`server/server.go:153-169`): it does one immediate `RunOnce` at startup, then loops on a plain `time.Ticker` with a 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-36`), cancelled via context on shutdown.

That is the only background runner the server starts.

**Unused / not-started infrastructure:**

- `internal/scheduler/` — a full cron-style job scheduler package (`scheduler.go`, `job.go`, `parser.go`, `middleware.go`) that is not imported by the server (or anything outside its own package/tests). The s3presign runner uses a raw `time.Ticker` instead of it.
- `server/runner/memopayload` (`runner.go`) defines a `Runner` with `NewRunner`/`RunOnce`, but no code ever constructs it — only its standalone helper `RebuildMemoPayload` is used, called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108,447`), not as a background worker.
