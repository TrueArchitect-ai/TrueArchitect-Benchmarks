- **Interceptor:** `web/src/connect.ts` — it defines a ConnectRPC `Interceptor` that sets `Authorization: Bearer <token>` on each request, does a preflight refresh when the access token is near expiry, and reactively refreshes-and-retries on 401 (with a dedicated refresh transport/client and a dedup manager). Token storage/sync lives in `web/src/auth-state.ts` (localStorage + BroadcastChannel across tabs).
- **Token kinds:** short-lived JWT **access tokens** (~15 min, sent as Bearer headers) and **refresh tokens** used against the `RefreshToken` RPC to mint new access tokens; the backend additionally supports long-lived **Personal Access Tokens (PATs)** for programmatic access.
- **Backend package:** `server/auth` (`server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`; JWT parsing in `server/auth/token.go`).
