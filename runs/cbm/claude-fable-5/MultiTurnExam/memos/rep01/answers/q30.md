Memo lifecycle events that dispatch webhooks (all in `server/router/api/v1/memo_service_webhooks.go`):

- created (`memos.memo.created`): `DispatchMemoCreatedWebhook`
- updated (`memos.memo.updated`): `DispatchMemoUpdatedWebhook`
- deleted (`memos.memo.deleted`): `DispatchMemoDeletedWebhook`
- comment created (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook`

The first three converge through the shared helper `dispatchMemoRelatedWebhook` (same file), and **all four** ultimately deliver via `webhook.PostAsync` in `internal/webhook/webhook.go`, which wraps the synchronous `Post` function that signs (HMAC-SHA256, Standard Webhooks headers) and HTTP-POSTs the JSON payload to each of the user's registered webhook URLs.
