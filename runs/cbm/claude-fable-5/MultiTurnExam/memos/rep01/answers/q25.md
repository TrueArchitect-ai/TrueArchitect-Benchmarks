**Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`) — the engine lives in `internal/filter/` (`internal/filter/engine.go`, with `parser.go`, `ir.go`, `render.go`, `schema.go`).

**Mechanism:** The `Engine` compiles the CEL filter expression into a dialect-agnostic condition tree (IR), and each database driver calls `filter.AppendConditions(...)` with its dialect constant — `filter.DialectSQLite` at `store/db/sqlite/memo.go:61`, `filter.DialectMySQL` at `store/db/mysql/memo.go:69`, `filter.DialectPostgres` at `store/db/postgres/memo.go:58` — which renders the tree into parameterized SQL WHERE clauses (with dialect-specific placeholder and JSON-function handling in `internal/filter/render.go`) appended to the query's `where`/`args`.
