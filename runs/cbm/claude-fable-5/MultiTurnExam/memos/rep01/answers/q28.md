The server starts exactly **one** background runner, in `Server.startBackgroundRunners` (`server/server.go:153`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`, `server/server.go:163`), then continuously on a `time.Ticker` with a 12-hour interval (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-30`), refreshing S3 presigned URLs; stopped via per-runner context cancellation on shutdown.

**Unused scheduling infrastructure:** the `memopayload` runner (`server/runner/memopayload/runner.go`) defines a full runner with `NewRunner` and `RunOnce`, but the server never constructs or starts it — no call to `memopayload.NewRunner` exists anywhere. Only its standalone helper function `RebuildMemoPayload` is used, called synchronously from the memo handlers (`server/router/api/v1/memo_service.go:108` and `:447`), not as a scheduled background job.
