The derived metadata is the memo **payload** (`MemoPayload.Tags` + `MemoPayload.Property`, `proto/store/memo.proto:15-22`), computed from the markdown content.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates the actual parsing to the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:365-410`, walking the goldmark AST).

**Triggers:**
- Memo creation — `CreateMemo` calls it before saving (`server/router/api/v1/memo_service.go:108`); comment creation also flows through this since `CreateMemoComment` calls `CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`).
- Content update — `UpdateMemo` recomputes it whenever the `content` field is in the update mask (`server/router/api/v1/memo_service.go:447`).
- Bulk rebuild — `memopayload.Runner.RunOnce` can recompute payloads for all memos in batches (`server/runner/memopayload/runner.go:27-72`), though nothing in production code currently invokes that runner.

**Extracted properties:**
- `Tags` — all `#tag`s found in the content (via the tag extension).
- `Property.Title` — text of the first H1 heading, if present (`internal/markdown/markdown.go:387`, `proto/store/memo.proto:20-21`).
- `Property.HasLink` — links/auto-links present (`markdown.go:394`).
- `Property.HasCode` — code blocks, fenced code, or code spans (`markdown.go:396-397`).
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — task checkboxes, and whether any are unchecked (`markdown.go:399-404`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` persists only `Tags` and `Property` — `runner.go:85-86`.)
