**Abstraction package: `internal/idp` (`github.com/usememos/memos/internal/idp`); implementation package: `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`) — OAuth2 is the one concrete protocol shipped.**

Details:

- `internal/idp/idp.go` defines the provider abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider implementation must produce from a third-party identity.
- `internal/idp/oauth2/oauth2.go` is the only concrete implementation in the tree: an `IdentityProvider` built from a `storepb.OAuth2Config`, with `ExchangeToken` (including PKCE support) and user-info retrieval mapped through configurable field mappings.
- The server consumes it during SSO sign-in in `server/router/api/v1/auth_service_sso.go:13`.
