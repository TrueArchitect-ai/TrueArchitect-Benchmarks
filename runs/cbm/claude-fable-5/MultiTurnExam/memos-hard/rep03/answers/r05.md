**Premise correction: there is no GraphQL schema — this project doesn't expose a GraphQL API.** A repo-wide search for GraphQL (Go sources, `.graphql` files, frontend TypeScript) finds no schema, resolvers, or client library.

**Actual API surface:** the public API is gRPC-based, defined with Protocol Buffers and exposed over HTTP in two ways:

- **Schema definitions:** protobuf service definitions under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`. Generated code lives under `proto/gen/api/v1/`.
- **REST-style JSON access** via grpc-gateway: the gateway is registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`, using `github.com/grpc-ecosystem/grpc-gateway/v2/runtime`), mapping the proto `google.api.http` annotations to HTTP routes.
- **Connect RPC handlers** for browser clients (replacing grpc-web): registered on a mux via `NewConnectServiceHandler(...).RegisterConnectHandlers(...)` (`server/router/api/v1/v1.go:131-141`), with generated Connect stubs in `proto/gen/api/v1/apiv1connect/`.

Non-RPC HTTP surfaces (RSS at `server/router/rss/`, file/avatar serving at `server/router/fileserver/`) are plain Echo routes — still no GraphQL anywhere.
