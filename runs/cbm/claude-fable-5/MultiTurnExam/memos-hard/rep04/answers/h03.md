**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

- `internal/idp` defines the provider-neutral abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider must produce (`internal/idp/idp.go:3-8`).
- `internal/idp/oauth2` is the only concrete protocol implementation that ships: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, with `NewIdentityProvider`, `ExchangeToken`, and `UserInfo` methods (`internal/idp/oauth2/oauth2.go`).
- The SSO login flow wires them together in `server/router/api/v1/auth_service_sso.go:119-130` — it checks `identityProvider.Type == storepb.IdentityProvider_OAUTH2`, exchanges the code for a token, and maps the response into `idp.IdentityProviderUserInfo`.
