**Premise correction: there is no nightly database-cleanup job — no such job is registered, and the cron scheduler package isn't even wired into the server.**

What I found:

- The repo does contain a cron scheduler package, `internal/scheduler` (`internal/scheduler/scheduler.go`, `parser.go`, `job.go`), but no production code imports it — a repo-wide search for imports of `internal/scheduler` outside the package itself returns nothing. It's an unused library within this codebase.
- The likely source of the premise: the package's documentation shows an *example* job named "daily-cleanup" scheduled at `"0 2 * * *"` (2 AM daily) in `internal/scheduler/doc.go:14-21` — but that's illustrative sample code in a doc comment, not a registered job.
- The background work that actually runs is different in both mechanism and purpose: the S3 presign runner uses a plain `time.Ticker` every 12 hours (`server/runner/s3presign/runner.go:26-27`, started from `server/server.go:153-171`), and the in-memory caches run an eviction sweep every 5 minutes (`store/store.go:42`, `store/cache/cache.go:83`). Neither performs database cleanup, and nothing anywhere vacuums, purges, or cleans the database on a schedule.
