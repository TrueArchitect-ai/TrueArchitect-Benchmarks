**Premise correction: this project has no GraphQL API — no schema files, resolvers, or GraphQL libraries exist anywhere in the codebase** (a repo-wide search for "graphql" outside `node_modules` returns nothing).

The actual public API surface is protobuf-defined gRPC services exposed over HTTP two ways:

- **Schema definition:** Protocol Buffers in `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with generated code in `proto/gen/api/v1/`.
- **Connect protocol endpoints** for browser and RPC clients: registered on `/memos.api.v1.*` via `RegisterConnectHandlers` with metadata/logging/recovery/auth interceptors (`server/router/api/v1/v1.go:130-145`, handlers in `server/router/api/v1/connect_handler.go`).
- **REST/JSON gateway** (grpc-gateway): a `runtime.NewServeMux` with `Register*ServiceHandlerServer` calls maps the same services to RESTful HTTP+JSON routes (`server/router/api/v1/v1.go:96-108`, generated gateways in `proto/gen/api/v1/*.pb.gw.go`).

Alongside the API there are non-RPC HTTP surfaces — the file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and the static frontend (`server/router/frontend/frontend.go`) — all registered in `server/server.go:71-85`, but nothing GraphQL-shaped anywhere.
