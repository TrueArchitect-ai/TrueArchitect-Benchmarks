**Premise correction: this project has no GraphQL API — no GraphQL schema, resolvers, or dependencies exist anywhere** (a repo-wide search for graphql/gql across Go, TypeScript, and schema files returns nothing).

**Actual API surface:** the public API is defined with **Protocol Buffers** and served as gRPC/Connect RPC plus a REST-style HTTP mapping:

- Schema definitions: the `.proto` files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` (generated code in `proto/gen/`).
- Serving: `server/router/api/v1/v1.go` wires a Connect RPC handler (`RegisterConnectHandlers` on paths `/memos.api.v1.*`, lines 139-144) and a grpc-gateway runtime mux for the RESTful HTTP/JSON mapping of the same services (via `github.com/grpc-ecosystem/grpc-gateway`), with handler registration in `server/router/api/v1/connect_services.go`.
- Additional non-RPC surfaces are plain HTTP: file serving (`server/router/fileserver/fileserver.go`), RSS (`server/router/rss/rss.go`), and SSE events (`server/router/api/v1/sse_hub.go`).
