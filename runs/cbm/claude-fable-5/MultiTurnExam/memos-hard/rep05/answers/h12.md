**Determination method: static dispatch tracing through the driver-selection factory, resolved with the default configuration values.** The call chain is: the API handler calls `Store.CreateMemo` (`store/memo.go`), which delegates to the `store.Driver` interface field — an interface with three concrete implementations (`store/db/sqlite/memo.go:16`, `store/db/mysql/memo.go:16`, `store/db/postgres/memo.go:16`). Which one is bound is decided once, at startup, in the factory `NewDBDriver` (`store/db/db.go:18-27`), which switches on `profile.Driver`. With no database flags, that value is `"sqlite"`: the CLI declares the flag default `rootCmd.PersistentFlags().String("driver", "sqlite", ...)` and `viper.SetDefault("driver", "sqlite")` in `cmd/memos/main.go:122,130`, and `internal/profile/profile.go:110` likewise assumes sqlite when deriving the default DSN. So the `case "sqlite"` branch runs, the driver is `sqlite.NewDB(...)`, and every subsequent `driver.CreateMemo` interface call dispatches to the SQLite implementation — the other two candidates are never constructed in a default install.
