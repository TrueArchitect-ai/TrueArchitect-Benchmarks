**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to `markdownService.ExtractAll` — implemented in `internal/markdown/markdown.go:356` as a single goldmark AST walk over the memo content. The results are stored on the memo's `Payload` (`memo.Payload.Tags`, `memo.Payload.Property` — protobuf `MemoPayload` persisted with the memo row).

**Triggers for recomputation:**
- **Memo creation:** `CreateMemo` calls `memopayload.RebuildMemoPayload` before saving — `server/router/api/v1/memo_service.go:108` (this also covers comments, which are created as memos).
- **Content update:** `UpdateMemo`, only when the update mask includes the `"content"` path — `server/router/api/v1/memo_service.go:447`, storing the fresh payload alongside the new content.
- **Bulk rebuild:** `memopayload.Runner.RunOnce` re-derives the payload for every memo in batches of 100 — `server/runner/memopayload/runner.go:27` (a maintenance/backfill path; it is not wired into server startup in production code).

**Extracted properties** (from `internal/markdown/markdown.go:356-420`):
- `Tags` — all `#tag` occurrences, deduplicated case-preservingly.
- (`Mentions` — `@username` list, lowercased; returned by `ExtractAll` though only tags/property are persisted by `RebuildMemoPayload`.)
- `Property.Title` — text of the document's first block if it's an H1 heading.
- `Property.HasLink` — any link node present.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` and `Property.HasIncompleteTasks` — task checkboxes present / any unchecked ones.

These payload fields are what list views and previews filter and render on without reparsing the markdown.
