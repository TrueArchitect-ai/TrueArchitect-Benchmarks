**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages).**

Method: the persistent entity structs live in the data layer package `store` (`store/user.go`, `store/memo.go`, `store/attachment.go`, etc.). I grepped for `store.<Type>` references per Go package (directory) outside the entire `store/` tree (excluding the driver packages `store/db/*` and `store/test`, which are part of the layer itself).

Counts of referencing packages outside the data layer:

- **`User` — 7:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`Memo` — 6:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Next: `Attachment` — 4 (`api/v1`, `api/v1/test`, `fileserver`, `rss`); `Inbox`, `MemoShare`, `MemoRelation` — 3 each; `Reaction` — 2.

So `User` is the most widely referenced entity outside the data layer, with `Memo` a close second.
