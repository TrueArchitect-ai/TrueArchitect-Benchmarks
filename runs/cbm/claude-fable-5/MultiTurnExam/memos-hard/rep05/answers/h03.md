**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2` (OAuth 2.0).**

- `internal/idp/idp.go` defines the provider abstraction — the shared `IdentityProviderUserInfo` type (identifier, display name, email, avatar URL) that any provider normalizes third-party user data into.
- `internal/idp/oauth2/oauth2.go` is the only concrete protocol implementation shipped: an OAuth2 `IdentityProvider` built on `golang.org/x/oauth2`, configured via `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping).
- It's consumed during SSO sign-in in `server/router/api/v1/auth_service_sso.go` and managed via `server/router/api/v1/idp_service.go`.
