- More conclusively, a search for any import of the driver package `github.com/usememos/memos/store/db/mysql` across the entire codebase returns exactly one importer: `store/db/db.go:8`. Since Go code cannot construct `mysql.DB` without importing that package, no other file (including tests) can be constructing it directly. The only other construction is the internal `&DB{...}` literal inside the package's own `NewDB` in `store/db/mysql/mysql.go`, which is the constructor itself, not an external direct construction.
