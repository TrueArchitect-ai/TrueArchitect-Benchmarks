**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`)**

The `internal/idp` package defines the provider-agnostic abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider must produce (`internal/idp/idp.go`). The single concrete protocol implementation that ships is OAuth2: `internal/idp/oauth2` provides `IdentityProvider`, configured from a `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and built on `golang.org/x/oauth2` (`internal/idp/oauth2/oauth2.go`, with tests in `oauth2_test.go`).
