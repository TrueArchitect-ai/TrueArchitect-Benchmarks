**Premise correction: this project has no GraphQL API — there is no GraphQL schema anywhere in the repository.** Searches for GraphQL across Go sources, `.graphql` files, and frontend code find no schema, resolvers, or GraphQL libraries.

**Actual API surface:** the public API is defined with **Protocol Buffers** and served as gRPC plus HTTP:

- **Schema definitions:** proto files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `common.proto` — with generated code in `proto/gen/api/v1/` (including ConnectRPC bindings in `proto/gen/api/v1/apiv1connect/`).
- **Serving layer:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`) wires the handlers into the Echo server two ways: a **gRPC-Gateway** (`grpc-ecosystem/grpc-gateway/v2`) exposing RESTful JSON/HTTP endpoints, and **ConnectRPC** (`connectrpc.com/connect`) handlers speaking Connect/gRPC-Web — the web frontend consumes this via `web/src/connect.ts` and generated types in `web/src/types/proto/`.
- Other HTTP surfaces (`server/router/rss`, `server/router/fileserver`, `server/router/frontend`, `server/router/mcp`) are conventional REST/HTML endpoints, not GraphQL.
