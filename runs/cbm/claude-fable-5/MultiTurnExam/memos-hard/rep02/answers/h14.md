**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It delegates the actual parsing to the markdown service's single-pass extractor `(*service).ExtractAll` / `ExtractProperties` in `internal/markdown/markdown.go` (goldmark AST walk), and writes the result into the memo's `Payload` (`memo.Payload.Tags`, `memo.Payload.Property`), which is persisted alongside the memo.

**Triggers (operations that recompute it):**

- **Memo creation** — `CreateMemo` handler calls `RebuildMemoPayload` before saving (`server/router/api/v1/memo_service.go:108`); comment creation flows through the same creation path.
- **Content edits** — `UpdateMemo` recomputes it whenever the `content` field is updated (`server/router/api/v1/memo_service.go:447`).
- **Bulk rebuild** — `memopayload.Runner.RunOnce` can rebuild payloads for all memos in batches of 100 (`server/runner/memopayload/runner.go:27`), though as established earlier this runner currently has no production caller.

**Extracted properties** (into `storepb.MemoPayload`):

- `Tags` — all `#tag` occurrences (via the custom tag extension).
- (`ExtractAll` also collects `@mention` usernames, lowercased.)
- `Property` (`MemoPayload_Property`, `internal/markdown/markdown.go:193-241`):
  - `Title` — text of an H1 heading only if it is the document's first block
  - `HasLink` — any markdown link node
  - `HasCode` — code block, fenced code block, or inline code span
  - `HasTaskList` — any task checkbox
  - `HasIncompleteTasks` — at least one unchecked checkbox

These fields power list filtering and previews without reparsing content on every read.
