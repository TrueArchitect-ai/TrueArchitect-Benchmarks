Handlers whose RPC paths can transitively fire an outbound HTTP POST to a user-configured webhook URL:

- **`CreateMemo`** — `server/router/api/v1/memo_service.go:70`, calls `DispatchMemoCreatedWebhook` at `memo_service.go:157`.
- **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401`, via `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook` (`memo_update_helpers.go:67`).
- **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518`, calls `DispatchMemoDeletedWebhook` at `memo_service.go:562`.
- **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20`, calls `DispatchMemoCommentCreatedWebhook` at `memo_service_comments.go:119`.

Each `Dispatch*` helper resolves the user's configured webhook URLs and calls `webhook.PostAsync` (`memo_service_webhooks.go:43` and `:71`), which enqueues onto the async queue drained by worker goroutines.

**Convergence function:** all of these paths funnel into `webhook.Post` — `internal/webhook/webhook.go:120` — the single function that constructs and executes the HTTP request via `safeClient.Do` before delivery. (The common enqueue entry point just above it is `webhook.PostAsync` at `internal/webhook/webhook.go:184`, whose workers invoke `Post`.)
