— False premise: neither NATS nor RabbitMQ — no message broker at all (no broker dependency in `go.mod`). Webhook delivery uses an in-process buffered Go channel `asyncPostQueue` of capacity 128 (`internal/webhook/webhook.go:39`) drained by 4 worker goroutines started in package `init` (`webhook.go:42-55`); producers enqueue non-blocking and silently drop on overflow (`webhook.go:189-195`).
