**`Driver` — `store/driver.go`**

The interface is defined at `store/driver.go:10` in the `store` package, documented as "an interface for store driver. It contains all methods that store database driver should implement." It includes methods like `GetDB()`, `Close()`, `IsInitialized()`, plus CRUD methods for each model (attachments, memos, users, etc.). The three database backends — SQLite, MySQL, and PostgreSQL, located in `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/` — each implement this interface, and `store/db/db.go` selects among them.
