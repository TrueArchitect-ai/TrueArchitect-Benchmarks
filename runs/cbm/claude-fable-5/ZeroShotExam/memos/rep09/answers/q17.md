`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The memo CRUD operations live in `web/src/hooks/useMemoQueries.ts`, which defines TanStack Query hooks (`useQuery`/`useMutation`) for listing, getting, creating (`memoServiceClient.createMemo`), updating (`updateMemo`), and deleting (`deleteMemo`) memos. It uses the `memoServiceClient`, imported from `web/src/connect.ts`, where it's created via `createClient(MemoService, transport)` (line 197) from the generated Connect-RPC `MemoService` definition in `web/src/types/proto/api/v1/memo_service_pb.ts`.
