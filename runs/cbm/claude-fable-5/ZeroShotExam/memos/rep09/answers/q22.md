When `CreateMemo` finishes creating the memo, the handler calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)` (`server/router/api/v1/memo_service.go:157`). That dispatcher lives in `server/router/api/v1/memo_service_webhooks.go` — it looks up the creator's webhooks via `s.Store.GetUserWebhooks`, builds a payload with activity type `memos.memo.created`, and fires each one asynchronously with `webhook.PostAsync(payload)`.

- **Dispatcher** — `DispatchMemoCreatedWebhook` (delegating to `dispatchMemoRelatedWebhook`) in `server/router/api/v1/memo_service_webhooks.go`
- **Delivery package** — `github.com/usememos/memos/internal/webhook` (`internal/webhook/webhook.go`), whose `PostAsync`/`Post` send the JSON POST using a hardened `http.Client` (`safeClient`, with SSRF guards in `internal/webhook/validate.go`)
- **Signing mechanism** — Standard Webhooks-style HMAC-SHA256: the secret (a `whsec_`-prefixed base64 key, see `GenerateSigningSecret`) keys an HMAC over `msgID.timestamp.body`; the base64 signature is sent as `webhook-signature: v1,<sig>` alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:139-149`)
