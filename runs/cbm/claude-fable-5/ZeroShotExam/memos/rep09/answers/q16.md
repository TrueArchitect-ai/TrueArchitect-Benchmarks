When `Store.DeleteMemo` runs (the store method called by the API when deleting a memo), it deletes these records before removing the memo row itself (`store/memo.go:140-159`):

- **Memo relation records where the memo is the source** — `DeleteMemoRelation` with `MemoID` set to the memo's ID (`store/memo.go:142`, implemented in `store/memo_relation.go`)
- **Memo relation records where the memo is the target** — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (`store/memo.go:145`)
- **Attachments linked to the memo** — it lists attachments with `FindAttachment{MemoID: ...}` and deletes each via `DeleteAttachment` (`store/memo.go:149-157`)

Only after those cleanups does it call `s.driver.DeleteMemo` to delete the memo row itself (`store/memo.go:158`).
