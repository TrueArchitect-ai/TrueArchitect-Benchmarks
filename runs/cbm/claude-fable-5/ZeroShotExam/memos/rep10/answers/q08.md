**`Driver` — `store/driver.go`**

All database backends implement the `Driver` interface, defined at `store/driver.go:10`. The doc comment states it "contains all methods that store database driver should implement" — connection management (`GetDB`, `Close`), initialization checks, and CRUD methods for every model (memos, users, attachments, etc.). The concrete backend implementations live under `store/db/` (e.g. SQLite, MySQL, PostgreSQL drivers).
