`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies this single full-schema file instead of running incremental migrations. This is documented and implemented in `store/migrator.go` — the comment at line 42 says "LATEST.sql: Full schema for new installations (faster than incremental migrations)", `LatestSchemaFileName = "LATEST.sql"` is defined at line 56, and `preMigrate` (line 210) applies it when the database is not yet initialized. The driver-specific copy for SQLite lives at `store/migration/sqlite/LATEST.sql`.
