MemoService is served over both **Connect RPC** and **HTTP/JSON REST (grpc-gateway)**:

- **Connect RPC** — `server/router/api/v1/connect_handler.go`: `RegisterConnectHandlers` mounts `apiv1connect.NewMemoServiceHandler(s, opts...)` on an `http.ServeMux` (line 40). The Connect wrapper methods themselves live in `server/router/api/v1/connect_services.go` (MemoService section around line 304), which adapts the gRPC-style implementations to Connect's request/response types.
- **HTTP/JSON REST via grpc-gateway** — `server/router/api/v1/v1.go`: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` (line 108) registers the service on the grpc-gateway `runtime.ServeMux`, which is then mounted on Echo at `/api/v1/*` (the generated gateway code is `proto/gen/api/v1/memo_service.pb.gw.go`).

As the comment in `connect_handler.go` notes, both routes share a single `APIV1Service` implementation — the Connect handler is a thin wrapper, and the gateway serves the same methods as RESTful JSON endpoints.
