The memo CRUD mutations and queries live in `web/src/hooks/useMemoQueries.ts`. This module defines the TanStack Query hooks (query key factory `memoKeys`, `useQuery`/`useInfiniteQuery` hooks for listing and fetching memos, and `useMutation` hooks that call `createMemo`, `updateMemo`, and `deleteMemo`). All RPCs go through the generated Connect service client `memoServiceClient`, imported from `@/connect` (i.e. `web/src/connect`), which is built from the generated `MemoService` protobuf definitions in `web/src/types/proto/api/v1/memo_service_pb.ts`.
