The `store.Driver` interface (defined in `store/driver.go`) has three implementations, each with an entry file that defines the driver struct and its `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

The factory that selects between them at startup is:

**NewDBDriver — store/db/db.go** (`store/db/db.go:14`), which switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and calls the corresponding package's `NewDB(profile)`.
