`store/migration/sqlite/LATEST.sql`

On a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` instead of running incremental migrations — see `/bench/repo/store/migrator.go:27` ("preMigrate: Check if DB is initialized. If not, apply LATEST.sql") and the comment at `store/migrator.go:42` ("LATEST.sql: Full schema for new installations"). For the SQLite driver specifically, that file is `store/migration/sqlite/LATEST.sql` (parallel files exist for postgres and mysql). This behavior is also verified by `store/test/migrator_test.go` (`TestFreshInstall`).
