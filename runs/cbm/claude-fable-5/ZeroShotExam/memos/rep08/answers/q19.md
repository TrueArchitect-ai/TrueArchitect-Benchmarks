MemoService is exposed over two protocols:

1. **HTTP/JSON REST via gRPC-Gateway** — registered in `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)`), mounted on the Echo server under `/api/v1/*`.

2. **Connect (ConnectRPC)** — wrapped and registered in `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, ...))` inside `RegisterConnectHandlers`), serving browser clients on the `/memos.api.v1.*` route. The per-method Connect adapter wrappers for MemoService live in `server/router/api/v1/connect_services.go` (the `// MemoService` section around line 304).

Both protocols share the same underlying implementation, `APIV1Service` in `server/router/api/v1/v1.go`, which embeds `v1pb.UnimplementedMemoServiceServer`; the comment in `connect_handler.go` confirms the design intent ("Support both native gRPC and Connect protocols" via generated code in `proto/gen/api/v1/memo_service.pb.gw.go` and `proto/gen/api/v1/apiv1connect/memo_service.connect.go`).
