The SignIn RPC is handled by **`APIV1Service.SignIn`** — `server/router/api/v1/auth_service.go` (defined at line 51).

This is the function containing the actual sign-in logic (password verification, session creation). Note there is also a thin Connect-protocol adapter, `ConnectServiceHandler.SignIn` in `server/router/api/v1/connect_services.go:78`, but it simply wraps the request and delegates to `APIV1Service.SignIn`.
