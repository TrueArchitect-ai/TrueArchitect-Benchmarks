**Driver — store/driver.go**

The `Driver` interface is defined at `store/driver.go:10` and contains all the methods a database backend must implement (attachment, memo, user, settings CRUD, etc.). All three backends — SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql`), and PostgreSQL (`store/db/postgres/postgres.go`) — implement it, and `store/db/db.go:14` (`NewDBDriver`) selects the appropriate implementation based on the configured database profile.
