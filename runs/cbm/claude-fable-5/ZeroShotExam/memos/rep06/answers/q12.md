The ListMemos request flows through these six hops:

- Frontend hook — `web/src/hooks/useMemoQueries.ts` (`useMemos` / `useInfiniteMemos` call `memoServiceClient.listMemos`)
- Client file — `web/src/connect.ts` (defines `memoServiceClient` via Connect RPC transport)
- Proto RPC — `proto/api/v1/memo_service.proto` (`rpc ListMemos(ListMemosRequest) returns (ListMemosResponse)`, line 29)
- Backend handler file — `server/router/api/v1/memo_service.go` (the `ListMemos` handler implementation)
- Store method file — `store/memo.go` (`ListMemos` store method)
- Dialect implementation file — `store/db/sqlite/memo.go` (SQLite implementation; equivalents exist in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`)
