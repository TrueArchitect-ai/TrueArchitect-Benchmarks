Server-Sent Events (SSE); hub at `server/router/api/v1/sse_hub.go`; broadcasting memo handlers: `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`

Details:

- **Mechanism**: Server-Sent Events — the HTTP handler in `server/router/api/v1/sse_handler.go` sets `Content-Type: text/event-stream` and streams events to browsers.
- **Hub**: `server/router/api/v1/sse_hub.go` implements `SSEHub` with `Subscribe`/`Unsubscribe`/`Broadcast`/`Close`, per-client buffered channels (dropping events for slow clients), and visibility-based delivery filtering (`canReceive`). Event types include `memo.created`, `memo.updated`, `memo.deleted`, `memo.comment.created`, `reaction.upserted`, `reaction.deleted`.
- **Memo handlers that broadcast**:
  - `CreateMemo` — `server/router/api/v1/memo_service.go:163` (`memo.created`; skipped when suppressed via `withSuppressSSE`)
  - `UpdateMemo` — via `dispatchMemoUpdatedSideEffects` in `server/router/api/v1/memo_update_helpers.go:71` (`memo.updated`), called from `memo_service.go:513`
  - `DeleteMemo` — `server/router/api/v1/memo_service.go:585` (`memo.deleted`)
  - `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (`memo.comment.created` for the parent memo)

The same `dispatchMemoUpdatedSideEffects` helper also makes `SetMemoAttachments` (`memo_attachment_service.go:48`) and `SetMemoRelations` (`memo_relation_service.go:48`) broadcast `memo.updated`, and the reaction handlers `UpsertMemoReaction`/`DeleteMemoReaction` (`reaction_service.go:106`, `reaction_service.go:161`) broadcast reaction events through the same hub.
