When the API's `DeleteMemo` handler (`server/router/api/v1/memo_service.go:518`) calls into the store, `Store.DeleteMemo` in `store/memo.go:140-159` deletes the following before removing the memo row itself:

- **Memo relation records** where the memo is the source (`DeleteMemoRelation{MemoID: ...}`)
- **Memo relation records** where the memo is the target/related memo (`DeleteMemoRelation{RelatedMemoID: ...}`)
- **Attachments** linked to the memo (listed via `ListAttachments{MemoID: ...}`, then each deleted with `DeleteAttachment`)

Only after those cleanups does it call `s.driver.DeleteMemo` to delete the memo row.
