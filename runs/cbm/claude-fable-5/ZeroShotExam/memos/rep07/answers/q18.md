The `store.Driver` interface (defined in `store/driver.go`) has three implementations, one per supported database, each with its entry file containing the driver struct and constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

The factory that selects between them at startup is:

**NewDBDriver — `store/db/db.go`**

It switches on `profile.Driver` ("sqlite", "mysql", or "postgres") and calls the matching package's `NewDB(profile)` constructor, returning an error for unknown drivers (`store/db/db.go:14-32`).
