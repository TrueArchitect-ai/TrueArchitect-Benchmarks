**Driver — store/driver.go**

The `Driver` interface is defined in `store/driver.go` (line 10) in the `store` package. It declares all methods a database backend must implement (attachment, memo, user, settings, etc. CRUD operations). The three backends — SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql`), and PostgreSQL (`store/db/postgres/postgres.go`) — each implement it, and `store/db/db.go`'s `NewDBDriver` returns the appropriate `store.Driver` based on the configured database type.
