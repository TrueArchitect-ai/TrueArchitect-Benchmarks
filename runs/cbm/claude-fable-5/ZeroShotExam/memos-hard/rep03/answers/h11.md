**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

The data layer is the `store` package (`store/`), whose persistent entity structs are defined in files like `store/user.go:29` (`User`), `store/memo.go:35` (`Memo`), `store/attachment.go:16` (`Attachment`), plus `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `UserSetting`, `InstanceSetting`, `IdentityProvider`, and `UserIdentity`.

Counting distinct Go packages outside `store/` (i.e., excluding the `store/db/*` drivers and `store/test`) that reference each type as `store.<Type>`:

- **`User` — 7 packages**: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`Memo` — 6 packages**: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Next: `Attachment` at 4; `Inbox`, `MemoRelation`, `MemoShare` at 3 each; the rest at 1–2.

The ranking holds even if you exclude the test package (`server/router/api/v1/test`): User 6 vs. Memo 5.
