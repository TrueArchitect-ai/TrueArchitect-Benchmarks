A browser requesting another user's avatar hits `GET /file/users/:identifier/avatar`. The image is not a separate file — it's stored inline as a data URI in the `avatar_url` column of the `user` table, so the "data layer" is a user-table read. The store dispatches through the driver interface (SQLite shown; Postgres/MySQL have parallel `ListUsers` implementations).
