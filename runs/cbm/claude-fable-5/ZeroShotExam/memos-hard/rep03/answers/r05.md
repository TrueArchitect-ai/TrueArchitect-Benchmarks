**Premise correction:** There is no GraphQL schema anywhere in this repository — a repo-wide search for "graphql"/"apollo" returns zero matches. The public API is not GraphQL.

**Actual API surface:** The public API is a gRPC API defined in Protocol Buffers, served over both native gRPC and HTTP/JSON:

- **Schema definitions:** `proto/api/v1/*.proto` — one file per service, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus `common.proto` and services for AI, IdP, instance, and shortcuts. Internal storage messages live separately under `proto/store/`.
- **Code generation:** managed with buf (`proto/buf.yaml`, `proto/buf.gen.yaml`), with generated code in `proto/gen/` (see `proto/README.md` for the `buf generate` workflow).
- **Transport:** the server exposes these services via Connect RPC (`connectrpc.com/connect`) and grpc-gateway (`github.com/grpc-ecosystem/grpc-gateway/v2` in `go.mod`) for RESTful HTTP/JSON access, wired up under `server/router/api/`. An OpenAPI spec derived from the protos is embedded via `proto/openapi_embed.go`.

So if you're looking for the API contract, the `.proto` files in `proto/api/v1/` are the equivalent of what a GraphQL schema would be.
