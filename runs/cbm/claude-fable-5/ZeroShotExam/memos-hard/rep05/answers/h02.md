Delivery function — `Post` in `internal/webhook/webhook.go` (line 120), with the asynchronous entry point `PostAsync` enqueueing payloads that worker goroutines drain into `Post`. Memo-change events feed into it via `server/router/api/v1/memo_service_webhooks.go`.

Protection mechanism — SSRF guarding in the same package, in two layers:

1. **Dial-time blocking** — `internal/webhook/webhook.go`: the shared `safeClient` uses `safeDialContext` (line 59) as its transport dialer, which resolves the target hostname and refuses to connect if any resolved address falls in a reserved/private range. Because the check happens at dial time (after DNS resolution), it also defeats DNS-rebinding attacks.
2. **Registration-time validation** — `internal/webhook/validate.go`: `ValidateURL` (line 62) rejects webhook URLs that aren't http/https or that resolve to a reserved IP, and `isReservedIP` (line 44) checks against the `reservedCIDRs` list (loopback, RFC-1918 ranges, link-local/cloud-IMDS 169.254.0.0/16, and IPv6 equivalents). The `AllowPrivateIPs` flag can disable this for self-hosted deployments targeting local-network services.
