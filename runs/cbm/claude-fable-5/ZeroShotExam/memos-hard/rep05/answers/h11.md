**1st: User (~7 packages); 2nd: Memo (~6 packages)**

The data layer is the `store` package (`store/user.go`, `store/memo.go`, etc.), with its DB drivers under `store/db/` and tests under `store/test/` belonging to the same layer. Counting distinct Go packages outside `store/` that reference each entity type via `store.<Type>`:

- **`store.User`** — 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo`** — 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

For comparison, the next entities trail well behind: `Attachment` (4 packages), then `Inbox`, `MemoRelation`, and `MemoShare` (3 each). The ranking holds even if test packages are excluded (User 6, Memo 5).
