Each dispatcher pulls the destination from `s.Store.GetUserWebhooks(...)` and sets `payload.URL = hook.Url` (the user-configured webhook URL), then calls `webhook.PostAsync`.

**Convergence function — `webhook.Post`, at `internal/webhook/webhook.go:120`.**

Every path calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` all drain that queue by calling `Post`. `Post` is the single function that actually issues the outbound request — it marshals the payload, builds the `POST`, optionally HMAC-signs it, and fires it via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). (`safeClient`'s transport uses `safeDialContext` to block SSRF to reserved/private IPs before the request goes out.)
