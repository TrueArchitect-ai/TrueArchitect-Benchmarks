**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

All of the above route through the dispatch helpers in `server/router/api/v1/memo_service_webhooks.go` (`dispatchMemoRelatedWebhook` / `DispatchMemoCommentCreatedWebhook`), which read the user's stored webhook URL via `s.Store.GetUserWebhooks` and set `payload.URL = hook.Url`. They all call `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the four background workers started in `init()` (line 42) each call `webhook.Post` (line 120). `Post` is the single point where the request is built and delivered — `http.NewRequest("POST", requestPayload.URL, …)` and `safeClient.Do(req)` (lines 126, 152) — so every handler's path converges there before the network send.

(The URL itself is user-configured through the `CreateUserWebhook` / `UpdateUserWebhook` RPCs in `server/router/api/v1/user_service_webhooks.go`.)
