The data layer is the `store` package (root Go package at `store/`, with driver implementations in `store/db/{sqlite,mysql,postgres}`). Its persistent entity structs are defined in files like `store/memo.go` (`Memo`), `store/user.go` (`User`), `store/attachment.go` (`Attachment`), `store/inbox.go` (`Inbox`), `store/reaction.go` (`Reaction`), `store/memo_relation.go`, `store/memo_share.go`, `store/idp.go`, `store/user_setting.go`, etc.

Counting distinct Go packages *outside* the store layer (i.e., excluding `store/`, `store/db/*`, `store/test`, and generated proto) that reference each `store.<Type>`:

1st: **User** — ~7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`

2nd: **Memo** — ~6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

(If test packages are excluded, the counts are 6 vs. 5 — the ranking is unchanged.) For comparison, the next entities trail well behind: `Attachment` (~4 packages), then `Inbox`, `MemoRelation`, and `MemoShare` (~3 each).

**Answer — 1st: User (~7 external packages); 2nd: Memo (~6 external packages).**
