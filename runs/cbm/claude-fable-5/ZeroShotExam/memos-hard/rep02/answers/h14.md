**Computation site:** The derived metadata is the memo's `Payload` (`Tags` + `Property`), rebuilt by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It delegates the actual extraction to the goldmark-based markdown service's `ExtractAll` in `internal/markdown/markdown.go:356`, which parses the content once and walks the AST collecting everything in a single pass. The payload shape is the `MemoPayload` / `MemoPayload_Property` message defined in the store proto (`proto/gen/store`).

**Triggers:**
- **Memo creation** — `CreateMemo` calls `memopayload.RebuildMemoPayload` before inserting (`server/router/api/v1/memo_service.go:108`).
- **Memo update, but only when the update mask includes `content`** — `UpdateMemo` rebuilds the payload and writes `update.Payload` alongside the new content (`server/router/api/v1/memo_service.go:447-451`). Other update paths (visibility, pinned, state, location, etc.) don't recompute it; the `location` path only patches `payload.Location`.
- **Bulk rebuild** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` re-derives the payload for all memos in batches of 100. (Note: grepping `server/` and `cmd/`, this runner isn't currently wired into `server/server.go`'s startup — only the `s3presign` runner is — so it exists as a batch-rebuild utility rather than a scheduled job.)

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:362-421`):
- `Tags` — all `#tag` nodes, deduplicated case-preservingly.
- `Property.Title` — the text of an H1 heading, only if it is the first block-level child of the document.
- `Property.HasLink` — any link node present.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox present.
- `Property.HasIncompleteTasks` — at least one unchecked task checkbox.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` stores only `Tags` and `Property`; mentions are used separately for notifications via `server/router/api/v1/memo_mention_helpers.go`.) These payload fields are what list/preview surfaces read, e.g. `memo.Payload.Tags` in `server/router/api/v1/memo_service_converter.go:48` and the tag stats in `server/router/api/v1/user_service_stats.go`.
