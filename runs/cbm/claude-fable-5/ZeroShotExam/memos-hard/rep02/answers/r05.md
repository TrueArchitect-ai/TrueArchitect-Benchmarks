**Premise correction:** This repository (Memos, a self-hosted note-taking app) has no GraphQL API at all — there are no `.graphql`/`.gql` files and no GraphQL references anywhere in the codebase, so there is no GraphQL schema to point to.

**Actual API surface:** The public API is defined as gRPC services in Protocol Buffer files:

- **Schema definitions:** `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`), compiled with `buf` per `proto/buf.gen.yaml` and `proto/README.md`.
- **REST exposure:** the same proto definitions are also served as a REST/HTTP API via grpc-gateway (configured in `proto/buf.gen.yaml`, wired up in `server/router/api/v1/v1.go`), matching the README's claim of "full REST and gRPC APIs."
- **Generated artifacts:** Go stubs live in `proto/gen/api/`, and an OpenAPI spec for the REST surface is generated at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`).
- **Server implementation:** the service handlers are in `server/router/api/v1/` (e.g. `memo_service.go` — one file per proto service).
