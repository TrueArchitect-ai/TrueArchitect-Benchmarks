The abstraction lives in `internal/idp`; the only concrete protocol implementation shipped is `internal/idp/oauth2`.

- **Abstraction package:** `internal/idp` — `internal/idp/idp.go` defines the shared identity-provider types (e.g. `IdentityProviderUserInfo` with `Identifier`, `DisplayName`, `Email`, `AvatarURL`).
- **Implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go` ("Package oauth2 implements the OAuth2 identity provider integration") provides the concrete `IdentityProvider` built from a `storepb.OAuth2Config`, with `ExchangeToken` (including PKCE support) and user-info fetching that maps into the `idp` abstraction's user-info struct.

Answer: `internal/idp`; `internal/idp/oauth2`
