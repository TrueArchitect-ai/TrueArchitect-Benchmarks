**Premise correction:** There is no GraphQL schema in this repository — Memos does not expose a GraphQL API. A repo-wide search for "graphql" returns zero matches.

**Actual API surface:** The public API is defined as gRPC services in Protocol Buffers, with a REST layer generated from the same definitions:

- **Schema source:** `proto/api/v1/*.proto` — one file per service (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`), managed with Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).
- **REST mapping:** each RPC carries `google.api.http` annotations (e.g. `GET /api/v1/memos` in `proto/api/v1/memo_service.proto`), so grpc-gateway serves the same services as a REST/JSON API.
- **Generated code:** `proto/gen/api/v1/` contains the gRPC stubs (`*_grpc.pb.go`), gateway handlers (`*.pb.gw.go`), and Connect bindings (`apiv1connect/`).
- **OpenAPI spec:** a generated `proto/gen/openapi.yaml` is embedded into the binary via `proto/openapi_embed.go`.
- **Server implementation:** the services are implemented and wired up under `server/router/api/v1/`.
