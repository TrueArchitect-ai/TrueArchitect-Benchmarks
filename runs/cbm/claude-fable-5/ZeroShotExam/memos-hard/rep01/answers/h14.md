**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the markdown service's `ExtractAll` in `internal/markdown/markdown.go:356` — a single goldmark AST walk over the memo's content that fills `memo.Payload` (the `MemoPayload` proto with its `Property` sub-message).

**Triggers:**
- **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` before storing (`server/router/api/v1/memo_service.go:108`).
- **Memo content update** — `UpdateMemo` calls it only when `"content"` is in the update mask, then writes the new payload alongside the content (`server/router/api/v1/memo_service.go:447-451`).
- **Bulk rebuild** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` re-derives the payload for every memo in batches of 100 (a migration/backfill runner; note that unlike the s3presign runner, it isn't currently wired up in `server/server.go`).

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Payload.Tags` — all `#tag` nodes, deduplicated case-preservingly.
- `Payload.Property.Title` — the heading text if the first block-level child of the document is an H1.
- `Payload.Property.HasLink` — true if any link node exists.
- `Payload.Property.HasCode` — true for code blocks, fenced code blocks, or inline code spans.
- `Payload.Property.HasTaskList` — true if any task checkbox exists.
- `Payload.Property.HasIncompleteTasks` — true if any checkbox is unchecked.

(`ExtractAll` also collects @mentions, but `RebuildMemoPayload` stores only `Tags` and `Property` into the payload; the user separately can set `Payload.Location`, which is not derived.)
