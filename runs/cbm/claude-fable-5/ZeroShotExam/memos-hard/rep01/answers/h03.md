The abstraction lives in the `idp` package at `internal/idp` (`internal/idp/idp.go`), which defines the provider-neutral `IdentityProviderUserInfo` type that concrete providers return. The only concrete protocol implementation shipped is the OAuth 2.0 provider in the `oauth2` package at `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type handles token exchange (including PKCE) and user-info fetching, configured via `storepb.OAuth2Config`.

Answer: `internal/idp` (abstraction); `internal/idp/oauth2` (OAuth2 implementation).
