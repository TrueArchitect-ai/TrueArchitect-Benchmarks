Delivery function — `Post()` in `internal/webhook/webhook.go` (lines 119–180), which builds and sends the HTTP POST (optionally signed with an HMAC-SHA256 Standard Webhooks signature). Asynchronous dispatches enter via `PostAsync()`/the `asyncPostQueue` worker goroutines in the same file, but the actual outbound request happens in `Post()` through the shared `safeClient` (`internal/webhook/webhook.go:32`).

Protection mechanism — a dial-time SSRF guard: `safeClient`'s transport uses `safeDialContext()` (`internal/webhook/webhook.go:59`), which resolves the target hostname at connection time and refuses any address matching `isReservedIP()` against the `reservedCIDRs` list in `internal/webhook/validate.go` (loopback, RFC-1918 ranges, link-local/cloud-IMDS 169.254.0.0/16, and IPv6 equivalents). Checking at dial time also defeats DNS-rebinding tricks. There's a second, earlier layer: `ValidateURL()` in `internal/webhook/validate.go:62` rejects webhook URLs at registration time if they aren't http/https or resolve to a reserved IP. Both layers can be intentionally disabled for self-hosted setups via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
