The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type that any provider returns for an authenticated user. The one concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type wraps a `storepb.OAuth2Config` and implements the OAuth2 token-exchange/user-info flow, consumed by the SSO sign-in handler in `server/router/api/v1/auth_service_sso.go`.

Answer: `internal/idp`; `internal/idp/oauth2`
