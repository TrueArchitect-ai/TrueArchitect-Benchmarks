**Premise correction:** This repository has no GraphQL schema — there are no GraphQL references anywhere in the codebase (no `.graphql` files, no resolvers, no GraphQL dependencies in `go.mod`). The question's premise is incorrect.

**Actual API surface:** The public API is defined with Protocol Buffers, not GraphQL. The service and message definitions live in `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, and others). From those, `proto/buf.gen.yaml` generates:

- gRPC and Connect RPC Go stubs (`proto/gen/`),
- a REST/JSON facade via grpc-gateway (HTTP annotations on the same protos),
- an OpenAPI spec (embedded via `proto/openapi_embed.go`),
- TypeScript client types for the frontend (`web/src/types/proto`).

The generated services are served by the API router in `server/router/api/v1/`. So the closest analogue to "the schema for the public API" is the set of `.proto` files under `proto/api/v1/`.
