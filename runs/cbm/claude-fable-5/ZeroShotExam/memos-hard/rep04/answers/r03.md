**Premise correction:** there is no nightly database-cleanup job scheduled in this repository. The cron scheduler package (`internal/scheduler/`) exists, but nothing in the application ever registers a cleanup job with it — the package is imported only by its own tests (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`), not by any server or cmd code.

The "cleanup" jobs you may have seen are only documentation/example code, not scheduled jobs:

- `internal/scheduler/doc.go` — a usage example registering a `"daily-cleanup"` job at `"0 2 * * *"` (2 AM daily)
- `internal/scheduler/example_test.go:97-99` — an example test with a `"cleanup"` job "every night at 2 AM"
- `internal/scheduler/README.md` — similar illustrative snippets (`daily-cleanup`, `stale-session-cleanup`)

The only real periodically-running background task in the codebase is the S3 presign runner (`server/runner/s3presign/runner.go:26`), which uses a plain `time.Ticker` every 12 hours — it is not a database cleanup and doesn't use the cron scheduler.
