q25. **Engine + path:** Google's CEL (Common Expression Language), via `github.com/google/cel-go`, wrapped by a custom filter engine at `internal/filter/engine.go` (`Engine.Compile` parses the CEL filter string into a `Program`, per `internal/filter/schema.go` and `internal/filter/parser.go`).

**Mechanism:** The CEL expression is parsed into an intermediate condition tree (`internal/filter/ir.go`), then `Program.Render` (internal/filter/render.go) walks that tree and emits a dialect-specific SQL WHERE fragment + args by switching on a `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`), translating CEL operations (string length, regex matching, timestamp extraction, LIKE escaping, etc.) into each database's equivalent SQL syntax.
