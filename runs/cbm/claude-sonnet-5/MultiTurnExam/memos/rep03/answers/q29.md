**Token kinds:**
- **Access token** — short-lived JWT, kept in memory/app state (managed via web/src/auth-state.ts: `getAccessToken`/`setAccessToken`), sent as `Authorization: Bearer <token>`
- **Refresh token** — sent automatically via an HTTP-only cookie, used only to mint new access tokens through `refreshAuthClient.refreshToken({})` (connect.ts:75)

**Backend package that validates them:** `server/auth` (server/auth/authenticator.go) — `AuthenticateByAccessTokenV2` validates the JWT access token (via `ParseAccessTokenV2`), and `AuthenticateByRefreshToken` validates the refresh-token cookie against the database (via `ParseRefreshToken` + `store.GetUserRefreshTokenByID`).
