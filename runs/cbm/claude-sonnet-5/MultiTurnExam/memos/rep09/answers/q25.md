q25. Engine + path: CEL (Common Expression Language, via `github.com/google/cel-go`), implemented in `internal/filter/` (`engine.go` compiles the CEL expression into a dialect-agnostic `Condition` tree via `internal/filter/ir.go`/`parser.go`).

Mechanism: The CEL filter string is compiled once into an abstract `Condition` IR, then `internal/filter/render.go`'s `renderer.Render` walks that IR and emits dialect-specific SQL fragments/args by switching on `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`) for things like timestamp casts, JSON boolean checks, and IN-list rendering, which the per-driver `ListMemos` implementations (e.g. `store/db/sqlite/memo.go`) splice into their queries.
