q29. Interceptor path: `web/src/connect.ts` (the `authInterceptor` at `web/src/connect.ts:161-177`, attached to the shared Connect transport).

Token kinds: a short-lived access token (attached as `Authorization: Bearer <token>` via `setAuthorizationHeader`) plus a refresh token, which is stored server-side/cookie-based and exchanged via `AuthService.refreshToken` (`web/src/connect.ts:78-84`) when the access token is missing, expired, or a request comes back `Unauthenticated`.

Backend package: `server/auth` (`server/auth/authenticator.go`), which validates the bearer token/session and loads the user via `Store.GetUser`.
