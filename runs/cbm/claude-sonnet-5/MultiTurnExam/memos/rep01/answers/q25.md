**Engine:** CEL (Common Expression Language), via `github.com/google/cel-go`, implemented in `internal/filter/` (parsing in `internal/filter/parser.go` and `internal/filter/schema.go`, AST/IR in `internal/filter/ir.go`, SQL generation in `internal/filter/render.go`).

**Mechanism:** The filter string from `ListMemosRequest.filter` is parsed and type-checked into a CEL AST against a fixed variable schema (content, creator, tags, visibility, etc. in `internal/filter/schema.go`), converted to an internal IR, then `internal/filter/render.go` walks that IR and emits dialect-specific SQL fragments (switching on a `DialectName` of `DialectSQLite`/`DialectMySQL`/`DialectPostgres` to handle differences like timestamp extraction, string length, and regex/LIKE operators) that get appended as a `WHERE` clause by each driver's `ListMemos` implementation.
