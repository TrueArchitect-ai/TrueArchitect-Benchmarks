q25. Engine: CEL (Common Expression Language) via `google/cel-go`, wrapped by this repo's own engine at `internal/filter/engine.go` (schema in `internal/filter/schema.go`).

Mechanism: the raw filter string from `ListMemosRequest.filter` is compiled by `Engine.Compile` into a CEL AST/`Program`, then `Program.Render(RenderOptions{Dialect: ...})` walks that AST and emits a dialect-specific SQL WHERE-clause fragment (plus bound args) selected by the `DialectName` passed in, so the same parsed expression is rendered differently for sqlite/mysql/postgres.
