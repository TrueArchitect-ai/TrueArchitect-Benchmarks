q25. engine + path: CEL (Common Expression Language, via `google.golang.org/cel-go`) implemented in `internal/filter/engine.go` (`Engine.Compile`, condition tree) alongside `internal/filter/schema.go`.

mechanism: The CEL filter string is compiled into a dialect-agnostic AST/condition tree (`Engine.Compile`), then `Program.Render`/`CompileToStatement` walks that tree with a `RenderOptions`/`Schema` that maps each logical field to a per-`DialectName` (`sqlite`, `mysql`, `postgres`) SQL column expression (e.g. string concatenation as `||` for SQLite/Postgres vs `CONCAT(...)` for MySQL in `schema.go`), producing the final SQL `WHERE` clause text/args for that dialect.
