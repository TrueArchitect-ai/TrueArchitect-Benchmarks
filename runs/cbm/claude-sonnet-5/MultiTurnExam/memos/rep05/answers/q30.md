q30. Memo lifecycle events that dispatch webhooks (all in server/router/api/v1/memo_service_webhooks.go):

- memo created: `DispatchMemoCreatedWebhook`
- memo updated: `DispatchMemoUpdatedWebhook`
- memo deleted: `DispatchMemoDeletedWebhook`
- memo comment created: `DispatchMemoCommentCreatedWebhook`

All four converge on `webhook.PostAsync` (internal/webhook/webhook.go) for delivery — each dispatch function builds a `webhook.WebhookRequestPayload` per user webhook and calls `webhook.PostAsync(payload)`.
