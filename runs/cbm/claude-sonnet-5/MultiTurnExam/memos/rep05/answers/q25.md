q25. Engine: CEL (Common Expression Language, via `google/cel-go`) — internal/filter/ (engine.go parses/compiles the filter string into a CEL AST using `cel.NewEnv`, ir.go/parser.go build an intermediate representation, render.go renders it to SQL).

Mechanism: `ListMemos` passes `request.Filter` into `store.FindMemo.Filters`, and the SQLite/MySQL/Postgres drivers (e.g. `store/db/sqlite/memo.go:61`) call `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite/DialectMySQL/DialectPostgres, &where, &args)`, which walks the parsed CEL expression and emits dialect-specific WHERE-clause SQL and bound args (per-dialect branches throughout `internal/filter/render.go`).
