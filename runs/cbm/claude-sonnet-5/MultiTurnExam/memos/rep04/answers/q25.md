q25. **Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`), implemented in internal/filter/engine.go (`filter.Engine`, `filter.DefaultEngine`)

**Mechanism:** Each dialect driver (e.g. store/db/sqlite/memo.go:57-61) compiles the request's filter strings with `filter.DefaultEngine()` and calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)`, which parses each CEL expression into a dialect-agnostic condition tree (internal/filter/schema.go defines the field schema/column mappings) and then internal/filter/render.go walks that tree, switching on `DialectSQLite`/`DialectMySQL`/`DialectPostgres` at each node to emit dialect-specific SQL fragments (e.g. JSON extraction, string concat, timestamp functions) and bound arguments that get appended to the `WHERE` clause.
