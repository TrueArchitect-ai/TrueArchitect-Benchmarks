**Premise correction:** there is no nightly database-cleanup job in this codebase, and no cron scheduler is actually wired into the running server. A generic cron-like scheduler package does exist at `internal/scheduler/`, but it is never imported by any production code — the only references to it are from its own test files (`internal/scheduler/example_test.go:10` and `internal/scheduler/integration_test.go:13`). It registers no jobs and is never constructed in `server/server.go` or anywhere else.

The only actual scheduled/recurring background work in the server is the S3 presign refresher (`server/runner/s3presign/runner.go`), which runs every 12 hours starting from server boot (not at a fixed nightly clock time) — see `server/server.go:162-171`. There's no "database cleanup" job of any kind, scheduled or otherwise.
