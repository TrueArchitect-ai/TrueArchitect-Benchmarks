**Delivery function:** `Post` in `internal/webhook/webhook.go:120` performs the actual outbound HTTP dispatch (constructs and sends the POST request via `safeClient.Do(req)`, webhook.go:152). It's invoked synchronously or queued for async delivery via `PostAsync` (webhook.go:184), which is drained by worker goroutines in `init()` (webhook.go:42-55) that call `Post`.

**Protection mechanism:** SSRF protection lives in `internal/webhook/webhook.go` and `internal/webhook/validate.go`:
- The shared `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (webhook.go:32-37), which resolves the target host and rejects any IP in a reserved/private range at actual dial time (webhook.go:59-77) — this is what prevents DNS-rebinding bypasses, since it re-checks the resolved IP right before connecting, not just at validation time.
- `isReservedIP`/`reservedCIDRs` in `internal/webhook/validate.go:14-54` define the blocked ranges (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents), reused by `safeDialContext`.
- `ValidateURL` (validate.go:62-83) additionally does an upfront check when a webhook URL is registered/saved, rejecting non-http(s) schemes or hostnames resolving to reserved IPs.
