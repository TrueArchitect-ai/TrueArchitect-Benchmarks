**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll([]byte(memo.Content))` (a single-pass AST walk implemented in `(*service).ExtractAll` — `internal/markdown/markdown.go:356-421`), then assigns the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation):**
- `CreateMemo` RPC handler — `server/router/api/v1/memo_service.go:108` — always rebuilt on memo creation.
- `UpdateMemo` RPC handler — `server/router/api/v1/memo_service.go:447` — rebuilt only when the update mask includes the `content` field (memo_service.go:436-449).
- (Bulk/backfill path also exists in `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27-72`, which calls the same function per-memo, but per h08 that `Runner` is never actually constructed/invoked in production.)

**Extracted properties** (via the goldmark AST walk in `ExtractAll`):
- `Tags` — `#tag` nodes found in the content (deduplicated, case preserved).
- `Mentions` — `@username` mentions (lowercased, deduplicated) — extracted but not persisted into `Payload` by `RebuildMemoPayload` (only `Tags`/`Property` are copied).
- `Property.Title` — text of a leading H1 heading, if the first top-level block is one.
- `Property.HasLink` — set when a link node is present.
- `Property.HasCode` — set when a code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set when task-list checkboxes exist, and whether any are unchecked.
