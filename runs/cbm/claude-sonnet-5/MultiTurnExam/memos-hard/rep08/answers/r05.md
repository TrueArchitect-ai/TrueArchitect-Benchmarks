**Premise correction:** there is no GraphQL schema in this repository — a search for "graphql" across the codebase (Go and web frontend) returns no matches, and no `.graphql`/schema files exist.

**Actual API surface:** the public API is defined as Protobuf service definitions under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled into generated Go code under `proto/gen/api/v1/` and served over gRPC, gRPC-Gateway (REST/JSON transcoding), and Connect — wired up in `server/router/api/v1/v1.go` (`RegisterGateway`) and `server/router/api/v1/connect_services.go`.
