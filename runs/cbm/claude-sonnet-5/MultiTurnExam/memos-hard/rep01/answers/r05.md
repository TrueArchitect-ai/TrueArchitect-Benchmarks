**Premise correction:** There is no GraphQL schema in this codebase — I searched for `graphql`/`GraphQL` and `.graphql`/`.gql` files across the whole repo and found nothing.

**Actual API surface:** The public API is defined via **Protocol Buffers**, under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `ai_service.proto`, `idp_service.proto`, `shortcut_service.proto`, and shared types in `common.proto`. These `.proto` definitions are compiled to generated Go code under `proto/gen/api/v1/` and served three ways simultaneously: native gRPC, a gRPC-Gateway JSON/REST transcoding layer, and Connect (`apiv1connect`) — all registered together in `server/router/api/v1/v1.go` (see `RegisterGateway`, referenced in earlier answers).
