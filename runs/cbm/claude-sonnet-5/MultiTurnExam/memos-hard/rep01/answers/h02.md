**Delivery function:** `Post` in `internal/webhook/webhook.go:120` (and its non-blocking wrapper `PostAsync`, `internal/webhook/webhook.go:184`, which enqueues onto `asyncPostQueue` — a 4-worker pool started in `init()` at `internal/webhook/webhook.go:42-55` also calls `Post`). The actual HTTP request is dispatched via the package-level `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**SSRF protection:** The shared `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:35,59-77`), which resolves the target host and rejects any resolved IP that falls in a reserved/private range — this defeats DNS-rebinding since the check happens at actual dial time, not just at URL-validation time. The reserved-range check itself (`isReservedIP`) and the CIDR list (loopback, RFC-1918, link-local/cloud IMDS 169.254.169.254, and IPv6 equivalents) live in `internal/webhook/validate.go:14-54`, and a pre-flight version of the same check (`ValidateURL`) runs at webhook-registration time in `internal/webhook/validate.go:62-83`.
