**Handlers** (all in `server/router/api/v1/`), each of which can trigger a webhook to a user-configured URL:
- `CreateMemo` (`memo_service.go:70`) → `DispatchMemoCreatedWebhook` (`memo_service_webhooks.go:15`)
- `UpdateMemo` (`memo_service.go:401`) → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook`
- `DeleteMemo` (`memo_service.go:518`) → `DispatchMemoDeletedWebhook` (`memo_service.go:562`)
- `CreateMemoComment` (`memo_service_comments.go:20`) → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)

(Also `UploadAttachment`/relation-update paths hit `dispatchMemoUpdatedSideEffects` via `memo_attachment_service.go:48` and `memo_relation_service.go:48`, if a broader list is wanted.)

Each of these looks up the target user's webhook rows (`s.Store.GetUserWebhooks`), builds a `webhook.WebhookRequestPayload` with `payload.URL = hook.Url` (a user-configured URL), and calls `webhook.PostAsync(payload)`.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120`. `PostAsync` (`internal/webhook/webhook.go:184`) is the shared entry point every handler calls, but it only enqueues onto `asyncPostQueue`; the fixed pool of background workers (spawned in `webhook.go`'s `init()`) dequeues and calls `Post`, which is the single function that actually constructs and executes the outbound HTTP request via `safeClient.Do(req)` — the true delivery point where all paths converge.
