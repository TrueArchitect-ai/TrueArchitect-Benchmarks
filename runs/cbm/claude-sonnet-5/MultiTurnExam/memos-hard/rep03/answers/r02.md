**Premise correction:** There is no per-user API rate-limiting middleware in this repository. A repo-wide search (case-insensitive) for `rate limit`, `ratelimit`, `throttle`, and `x/time/rate` across all Go files, and a check of `go.mod` for any rate-limiting dependency, returns zero matches. **Actual mechanism:** None exists. The closest related concept in the codebase is a fixed-size *semaphore* used to bound concurrency for specific expensive operations — e.g. `thumbnailSemaphore`/`imageProcessingSemaphore` in `server/router/api/v1/v1.go:39-41` and `thumbnailSemaphore` in `server/router/fileserver/fileserver.go:107` — but these limit concurrent in-flight work (thumbnail/image generation), not per-user request rates, and are not registered as HTTP middleware. If rate limiting is desired, it would need to be added (e.g., at the Echo middleware layer or via a reverse proxy in front of the server).
