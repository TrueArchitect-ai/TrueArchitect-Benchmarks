**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared `IdentityProviderUserInfo` type used across all identity provider implementations.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete protocol implementation, self-documented as "Package oauth2 implements the OAuth2 identity provider integration," providing `IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, etc. It's consumed by SSO login handling in `server/router/api/v1/auth_service_sso.go`.
