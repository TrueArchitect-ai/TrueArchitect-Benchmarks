**Premise correction:** There is no GraphQL schema anywhere in this repository — a search for `graphql` (case-insensitive) across all Go, TypeScript, and TSX files, and in `go.mod`, returns zero matches. This project doesn't use GraphQL.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (`memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`). These are compiled to Go (`proto/gen/api/v1/`) and served two ways simultaneously: as Connect-RPC handlers and via a grpc-gateway REST/JSON transcoding layer, both registered in `server/router/api/v1/v1.go` (e.g. `RegisterGateway`, `RegisterInstanceServiceHandlerServer`, etc.).
