**Delivery function:** `Post` in `internal/webhook/webhook.go:120` performs the actual outbound HTTP dispatch (builds the request, optionally HMAC-signs it, and sends it via `safeClient.Do(req)`). It's invoked directly or queued for background delivery via `PostAsync` (`internal/webhook/webhook.go:184`), which feeds a worker pool that calls `Post`.

**Protection mechanism:** SSRF protection happens at dial time, not just URL-string validation. The shared `safeClient` (`internal/webhook/webhook.go:32`) uses an `http.Transport` whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:59`) — it resolves the hostname, then checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`, backed by the `reservedCIDRs`/`reservedNetworks` list covering loopback, RFC-1918 private ranges, and link-local/cloud-IMDS addresses) and refuses to dial if any resolved address is reserved/private. Doing the check at dial-time (rather than only on the original URL) also defeats DNS-rebinding attacks. There's also a separate pre-flight `ValidateURL` (`internal/webhook/validate.go`) used when webhooks are configured, but the actual enforcement that protects live delivery is `safeDialContext`.
