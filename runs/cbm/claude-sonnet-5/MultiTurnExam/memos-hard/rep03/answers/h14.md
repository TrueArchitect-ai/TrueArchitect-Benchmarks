**Triggers (recomputation):**

- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:437-447`); other field-only updates (visibility, pinned, etc.) don't recompute it.

**Extracted properties** (via a single AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-421`):
- `Tags` — all `#tag` occurrences, deduplicated case-preserving.
- `Mentions` — all `@mention` occurrences (lower-cased, deduplicated) — collected in `ExtractedData` but not persisted onto `MemoPayload` by `RebuildMemoPayload` (only `Tags`/`Property` are assigned).
- `Property.Title` — text of a leading H1 heading, if the document's first block is one.
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true if any code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — true if a task checkbox exists / if any checkbox is unchecked.
