**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the generic `IdentityProviderUserInfo` type used across identity-provider implementations.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — implements the OAuth2 protocol identity provider (`IdentityProvider` struct wrapping `*storepb.OAuth2Config`, built on `golang.org/x/oauth2`). It's the only concrete protocol implementation shipped under `internal/idp/`.
