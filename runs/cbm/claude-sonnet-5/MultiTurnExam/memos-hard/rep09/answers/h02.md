**Delivery function:** `Post` (and its queued wrapper `PostAsync`, backed by 4 worker goroutines draining `asyncPostQueue`) — `internal/webhook/webhook.go:120` (`PostAsync` at line 184). **Protection mechanism:** The `safeClient`'s `http.Transport` uses a custom `DialContext: safeDialContext` (`internal/webhook/webhook.go:32-37`), which resolves the target host and rejects any IP falling within a reserved/private range at actual dial time — defeating DNS-rebinding TOCTOU bypasses (`internal/webhook/webhook.go:59-77`). The reserved-range check itself (`isReservedIP`, covering loopback, RFC-1918 private ranges, link-local/cloud-IMDS 169.254.0.0/16, and IPv6 equivalents) lives in `internal/webhook/validate.go:14-54`, and the same check is also applied upfront when a webhook URL is registered via `ValidateURL` (`internal/webhook/validate.go:62-83`).
