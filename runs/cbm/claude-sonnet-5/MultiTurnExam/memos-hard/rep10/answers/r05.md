**Premise correction:** There is no GraphQL schema in this codebase — a search for `graphql` (case-insensitive, including `.graphql`/`.gql` files) across the whole repo returns zero hits.

**Actual API surface:** The public API is defined via Protocol Buffers, under `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), plus internal storage messages in `proto/store/*.proto`. These generate Go bindings under `proto/gen/`, served over gRPC, gRPC-Gateway (REST/JSON), and Connect (`server/router/api/v1/connect_services.go`, `connect_handler.go`), wired up in `server/router/api/v1/v1.go`.
