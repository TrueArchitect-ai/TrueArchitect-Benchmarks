**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll(memo.Content)` (backed by `(*service).ExtractAll` in `internal/markdown/markdown.go:356`) and writes the result into `memo.Payload.Tags` and `memo.Payload.Property` (`server/runner/memopayload/runner.go:83-84`).

**Triggers (recomputation):**
- `APIV1Service.CreateMemo` — every new memo, at `server/router/api/v1/memo_service.go:108`.
- `APIV1Service.UpdateMemo` — only when the update mask includes the `content` field, at `server/router/api/v1/memo_service.go:436-449` (`if path == "content" { ... memopayload.RebuildMemoPayload(...) }`), so editing visibility/pin/etc. alone does not recompute it.
- (Also reachable via `memopayload.Runner.RunOnce`, `server/runner/memopayload/runner.go:27-72`, which batch-rebuilds every memo's payload — but as established earlier that `Runner` is never constructed/invoked in production code, so this path is currently dead in practice.)

**Extracted properties** (from `markdown.ExtractedData`, `internal/markdown/markdown.go:20-25`, produced by `ExtractAll`):
- `Tags` — all `#tag` occurrences found in the content (excluding tags inside links/images).
- `Property.Title` — text of the content's leading H1 heading, if the document starts with one.
- `Property.HasLink` — whether the content contains a markdown link.
- `Property.HasCode` — whether it contains a code block/span.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether it contains task-list checkboxes, and whether any are unchecked.
- (`Mentions` is also part of `ExtractedData` but `RebuildMemoPayload` currently only persists `Tags` and `Property`, not `Mentions`.)
