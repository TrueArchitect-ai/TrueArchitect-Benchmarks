**Delivery function:** `Post` (and its async wrapper `PostAsync`, backed by a 4-worker queue) in `internal/webhook/webhook.go:120` (async entry at `internal/webhook/webhook.go:184`) — it builds the HTTP request and sends it via the package-level `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

**Protection mechanism:** SSRF protection happens at two layers:
- Dial-time enforcement: `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-77`), which resolves the hostname and rejects any resolved IP in a reserved/private range at connection time (defeats DNS rebinding, since re-resolution happens right before dialing).
- Pre-flight validation: `ValidateURL` in `internal/webhook/validate.go:62-83`, which checks scheme is http/https and that resolved IPs aren't reserved, called when webhook URLs are configured.

Both rely on `isReservedIP`/`reservedNetworks` (`internal/webhook/validate.go:14-54`), checking against loopback, RFC-1918 private ranges, link-local/cloud IMDS (169.254.169.254), and IPv6 equivalents — toggleable off via `AllowPrivateIPs` (`internal/webhook/validate.go:41`) for self-hosted deployments.
