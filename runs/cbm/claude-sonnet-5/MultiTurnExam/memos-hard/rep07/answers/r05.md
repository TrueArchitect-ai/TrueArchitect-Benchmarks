**Premise correction:** There is no GraphQL API in this codebase — no `graphql` references anywhere in the Go source, and no `.graphql` schema files exist.

**Actual API surface:** The public API is defined with **Protocol Buffers**, in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `common.proto`). These are compiled (via `buf`, see `proto/buf.gen.yaml`/`buf.yaml`) into generated Go code under `proto/gen/api/v1/`, and served over two protocols simultaneously: **Connect RPC** and **gRPC-Gateway** (REST/JSON), wired up in `server/router/api/v1/v1.go` (`RegisterGateway`). An OpenAPI/REST description is also embedded via `proto/openapi_embed.go` for the gateway surface.
