**Extracted properties** (written into `memo.Payload.Tags` and `memo.Payload.Property`, a `storepb.MemoPayload_Property`), all derived from a single AST walk over the parsed markdown (`internal/markdown/markdown.go:371-411`):

- `Property.HasCode` — true if any code block/span is present
