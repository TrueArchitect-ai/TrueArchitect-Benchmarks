**Delivery function:** `Post` (and its async wrapper `PostAsync`, dispatched via `asyncPostQueue` worker goroutines started in `init()`) — `internal/webhook/webhook.go:120` (POST executes at `webhook.go:152` via `safeClient.Do(req)`).

**Protection mechanism:** The outbound HTTP client (`safeClient`) uses a custom `Transport.DialContext` set to `safeDialContext`, which resolves the target hostname and rejects connections to any resolved IP falling in a reserved/private range (via `isReservedIP`) — defined in `internal/webhook/webhook.go:32-77`, with the reserved-range logic (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) in `internal/webhook/validate.go:14-54`. This dial-time check defeats DNS-rebinding TOCTOU issues since it's re-resolved at connection time rather than relying solely on the separate pre-flight `ValidateURL` check (`internal/webhook/validate.go:62-83`) used at webhook-registration time.
