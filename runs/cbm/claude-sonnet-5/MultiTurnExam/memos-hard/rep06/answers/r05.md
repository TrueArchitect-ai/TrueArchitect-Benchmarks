**Premise correction:** There is no GraphQL schema in this repository — a search for `graphql` across all Go files, `go.mod`, and for `.graphql` schema files returns nothing. GraphQL is not part of this project's API surface.

**Actual API surface:** The public API is defined as Protocol Buffers / gRPC service definitions under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are served both as gRPC and, via `grpc-ecosystem/grpc-gateway` (imported in `server/router/api/v1/v1.go:8`), as a REST/JSON HTTP API — the handlers live in `server/router/api/v1/*.go` (e.g. `memo_service.go`, `user_service.go`). There is also an MCP (Model Context Protocol) surface under `server/router/mcp/`.
