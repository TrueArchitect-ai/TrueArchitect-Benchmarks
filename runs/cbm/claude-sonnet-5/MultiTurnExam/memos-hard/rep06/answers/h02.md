**Delivery function:** `Post` in `internal/webhook/webhook.go:120` — it marshals the payload, builds the HTTP request, optionally HMAC-signs it, and sends it via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). (`PostAsync`, `internal/webhook/webhook.go:184`, just enqueues onto `asyncPostQueue` for worker goroutines that call `Post`.)

**Protection mechanism:** The shared `safeClient`'s `http.Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:32-37, 59-77`), which resolves the target host via `net.DefaultResolver.LookupHost` and rejects the dial if any resolved IP is a reserved/private address per `isReservedIP` (`internal/webhook/validate.go:44`) — this guards against SSRF at connection time (including DNS-rebinding), on top of the upfront `ValidateURL` check (`internal/webhook/validate.go:62`) used when webhooks are configured.
