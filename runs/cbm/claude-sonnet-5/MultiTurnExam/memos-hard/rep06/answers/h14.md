**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(memo.Content)` (implemented by the goldmark-backed `service.ExtractAll` in `internal/markdown/markdown.go:356-422`) and writes the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, on every new memo.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes the `content` field (i.e., the memo's text actually changed).

**Extracted properties** (via a single AST walk of the parsed markdown, `internal/markdown/markdown.go:371-411`):
- `Tags` — collected from `#tag` nodes (deduplicated case-preserving).
- `Mentions` — collected from `@mention` nodes (lower-cased, deduplicated) — used transiently for notification logic, not persisted as its own payload field.
- `Property.Title` — set from the content's leading H1 heading, if the first block is one.
- `Property.HasLink` — set if any Markdown link node is present.
- `Property.HasCode` — set if any code block/fenced code block/code span is present.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set from task checkbox nodes, the latter when any checkbox is unchecked.
