**Delivery function:** `Post` — `internal/webhook/webhook.go:120-180` (invoked synchronously, or asynchronously via `PostAsync`/`asyncPostQueue`, `internal/webhook/webhook.go:184-196`). It builds the HTTP request and sends it via the package-level `safeClient` (`internal/webhook/webhook.go:32-37`).

**Protection mechanism:** SSRF protection is enforced at dial time by `safeDialContext` — `internal/webhook/webhook.go:59-77`, which is installed as the `http.Transport.DialContext` on `safeClient`. It resolves the target hostname and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, checking against `reservedNetworks`/`reservedCIDRs` covering loopback, RFC-1918 private ranges, and link-local/cloud-IMDS addresses, `internal/webhook/validate.go:14-23`). Dialing at resolution time (rather than checking the URL string) also defeats DNS-rebinding. A separate pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62-83`), applies the same `isReservedIP` logic when a webhook URL is first saved/validated.
