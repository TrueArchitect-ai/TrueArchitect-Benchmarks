**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356-...`), derived from a single AST walk of the memo's markdown content:
- `Tags` — all `#tag` occurrences
- `Mentions` — all `@mention` usernames (lower-cased)
- `Property.Title` — text of a leading H1 heading, if the first top-level block is one
- `Property.HasLink` — whether the content contains a link
- `Property.HasCode` — whether it contains a code block/span
- `Property.HasTaskList` — whether it contains a task list
- `Property.HasIncompleteTasks` — whether any task-list item is unchecked
