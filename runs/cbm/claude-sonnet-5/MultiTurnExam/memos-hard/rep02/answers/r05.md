**Premise correction:** There is no GraphQL API in this repository — a search for "graphql" (case-insensitive) across all Go files, `.proto` files, and `go.mod` returns zero matches.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into Go/Connect code under `proto/gen/api/v1/` and `proto/gen/api/v1/apiv1connect/`. It's served as gRPC plus gRPC-Gateway/Connect (REST/JSON + gRPC-Web) endpoints, wired up in `server/router/api/v1/connect_services.go` and `server/router/api/v1/connect_handler.go`, with an OpenAPI description generated at `proto/gen/openapi.yaml`.
