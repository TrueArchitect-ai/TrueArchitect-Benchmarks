**Component:** `s3presign.Runner` (`server/runner/s3presign/runner.go`) — periodically re-presigns S3 object URLs for attachments stored externally (S3-compatible storage), refreshing `s3ObjectPayload.LastPresignedTime` and the attachment's `Reference` URL before the previously issued presigned URL (5-day expiry) goes stale — it skips any attachment whose presigned URL is still valid for the next 4 days (`server/runner/s3presign/runner.go:85-91`).

**Schedule:** runs once immediately, then on a ticker every 12 hours (`const runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27,29-41`).

**Wiring site:** `server/server.go:162-171`, inside `Server.startBackgroundRunners` — `s3presignRunner := s3presign.NewRunner(s.Store)` runs once synchronously (`server/server.go:163`) and then is launched in a goroutine calling `s3presignRunner.Run(s3Context)` (`server/server.go:169`), which is itself invoked during server startup.
