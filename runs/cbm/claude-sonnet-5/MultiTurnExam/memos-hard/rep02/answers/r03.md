**Premise correction:** There is no nightly database-cleanup job in this repository. It does have a cron-style scheduler package at `internal/scheduler/` (with `ParseCronExpression`, `New`, `Register`, etc.), but that package is only referenced from its own tests (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`) — a repo-wide search found no import of `internal/scheduler` anywhere under `server/`, `cmd/`, or any other production code, so it is never wired into server startup.

The only actual scheduled background jobs in the server are the two runners started in `server.go`'s `startBackgroundRunners` (`server/server.go:153-174`): the S3 presign runner (`server/runner/s3presign/runner.go`, every 12 hours) and — not currently invoked — the memo-payload rebuild runner. Neither is a "database-cleanup" job, and neither is scheduled at a fixed nightly clock time; both use a simple `time.Ticker` interval, not a cron expression, so there is no "nightly" time to report. "Cleanup" occurs only inline, as part of request handling (e.g., attachment/relation cleanup during memo/user deletion in `memo_service.go` and `user_service.go`), not as a scheduled job.
