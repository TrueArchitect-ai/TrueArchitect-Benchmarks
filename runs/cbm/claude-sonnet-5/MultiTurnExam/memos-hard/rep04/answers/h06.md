**Handlers (RPC methods) that can transitively trigger an outbound HTTP request to a user-configured URL:**
- `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:70`) → calls `DispatchMemoCreatedWebhook` (`memo_service.go:157`)
- `APIV1Service.UpdateMemo` (`server/router/api/v1/memo_service.go:401`) → via `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_update_helpers.go:67`)
- `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`) → calls `DispatchMemoDeletedWebhook` (`memo_service.go:562`)
- `APIV1Service.CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:20`) → calls `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)

Each `Dispatch*Webhook` helper (`server/router/api/v1/memo_service_webhooks.go`) loads the target user's webhooks (with their user-configured `Url`) via `s.Store.GetUserWebhooks` and calls `webhook.PostAsync`.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120` (all `PostAsync` calls enqueue onto `asyncPostQueue`, drained by worker goroutines that invoke `Post`, which builds the request and performs the actual outbound call via `safeClient.Do(req)`).
