**Component:** `s3presign.Runner` (`server/runner/s3presign/runner.go`) — a background runner that re-presigns S3-backed attachment URLs before their signed links expire.

**Schedule:** Runs once immediately at startup, then on a ticker every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`). Each run scans attachments with `StorageType == S3` and re-presigns any whose `LastPresignedTime` is older than 4 days (the presigned URL is issued with a 5-day expiration), so links never go stale (`server/runner/s3presign/runner.go:85-91`).

**Wiring into server startup:** `server/server.go:161-171`, inside `(*Server).startBackgroundRunners`, which is itself invoked from the server's `Start` method at `server/server.go:129`. It creates the runner (`s3presignRunner := s3presign.NewRunner(s.Store)`), does a synchronous `RunOnce(ctx)` pass, then launches `s3presignRunner.Run(s3Context)` in a goroutine tracked by `s.backgroundRunnerWG` for graceful shutdown.
