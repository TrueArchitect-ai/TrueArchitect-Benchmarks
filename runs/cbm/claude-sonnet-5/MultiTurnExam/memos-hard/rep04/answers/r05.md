**Premise correction:** There is no GraphQL schema or GraphQL API in this repository — a search for "graphql" across the codebase returns zero matches.

**Actual API surface:** The public API is defined with Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), generated into Go code in `proto/gen/api/v1/`. It's served three ways from the same service definitions: gRPC, a grpc-gateway REST/JSON transcoding layer (the `*.pb.gw.go` files in `proto/gen/api/v1/`), and Connect (via `connectrpc.com/connect`, wired up in `server/router/api/v1/v1.go`). So the schema/contract equivalent to "the GraphQL schema" here is the `.proto` files in `proto/api/v1/`.
