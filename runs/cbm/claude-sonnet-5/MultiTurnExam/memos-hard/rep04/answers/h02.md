**Delivery function:** `Post` in `internal/webhook/webhook.go:120-180` performs the actual outbound HTTP dispatch (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`). It's invoked either directly or asynchronously via `PostAsync` (`internal/webhook/webhook.go:184-196`), which enqueues onto `asyncPostQueue`, drained by 4 worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`).

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59-77` — installed as the custom `DialContext` on the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host at dial time and rejects the connection if any resolved IP is reserved/private, per `isReservedIP` in `internal/webhook/validate.go:44-60`. This blocks SSRF against internal addresses and also defeats DNS-rebinding, since the check runs on the actual dial-time resolved IP rather than a pre-check of the URL string.
