**Premise correction:** There is no GraphQL schema in this codebase — no `.graphql` files, no GraphQL library in `go.mod`, and no hits for "graphql" anywhere in the repo.

**Actual API surface:** The public API is defined via Protocol Buffers, not GraphQL. Service contracts live under `proto/api/v1/*.proto` (`attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to Go bindings under `proto/gen/api/v1/`, exposed over gRPC/Connect (`proto/gen/api/v1/apiv1connect/`) as well as a REST/JSON gateway (`proto/gen/api/v1/*_service.pb.gw.go`, with an OpenAPI description at `proto/gen/openapi.yaml`). Handlers implementing these services live in `server/router/api/v1/`.
