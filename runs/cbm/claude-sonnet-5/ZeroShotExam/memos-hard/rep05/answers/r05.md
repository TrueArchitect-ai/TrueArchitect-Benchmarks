**Premise correction:** There is no GraphQL schema in this repository — I found no `.graphql`/`.gql` files and no `graphql`/`apollo` references anywhere in the codebase (checked `package.json` files, source, and docs).

**Actual API surface:** memos exposes its public API via **Protocol Buffers + Connect RPC / gRPC-Gateway**, not GraphQL:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Generated OpenAPI spec (REST view of the same API): `proto/gen/openapi.yaml`
- Generated Go server stubs: `proto/gen/api/v1/` (via `proto/gen/store/*.pb.go` for internal storage messages)
- Generated TypeScript client types: `web/src/types/proto/`
- Route wiring / ACL for public endpoints: `server/router/api/v1/acl_config.go`
- Build tooling: `proto/buf.yaml`, `proto/buf.gen.yaml` (`buf generate` regenerates Go, TypeScript, and OpenAPI outputs from the `.proto` sources)

So "the GraphQL schema" doesn't exist — the equivalent contract-defining source of truth is `proto/api/v1/*.proto`.
