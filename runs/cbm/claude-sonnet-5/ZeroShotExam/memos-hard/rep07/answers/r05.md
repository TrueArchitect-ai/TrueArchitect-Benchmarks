r05. Premise correction: there is no GraphQL schema in this repository — the public API is defined via Protocol Buffers, not GraphQL.

Actual API surface:
- Proto service/message definitions: `proto/api/` (source `.proto` files)
- Generated Go code and gateway bindings: `proto/gen/api/`
- Generated OpenAPI/Swagger spec (REST surface derived from the proto via grpc-gateway): `proto/gen/openapi.yaml`
- OpenAPI spec embedding for serving: `proto/openapi_embed.go`
- HTTP/REST route registration: `server/router/api/`

So if you're looking for "the schema," the proto files under `proto/api/` are the source of truth, and `proto/gen/openapi.yaml` is the REST/OpenAPI equivalent — there is no GraphQL layer anywhere in this repo.
