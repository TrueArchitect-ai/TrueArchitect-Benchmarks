**Premise correction:** There is no GraphQL schema in this repository — it doesn't use GraphQL at all. A repo-wide search for `graphql`, `.gql`, and `*schema*.graphql` files turns up nothing.

**Actual API surface:** The public API is defined via Protobuf/gRPC service definitions, with a generated OpenAPI (REST) spec:

- Protobuf service/message definitions: `proto/api/v1/*.proto` (e.g. `AIService`, etc.)
- Generated Go server/client code: `proto/gen/api/`
- Generated OpenAPI 3.0 REST spec (via `protoc-gen-openapi`): `proto/gen/openapi.yaml`
- Embedded OpenAPI spec for serving: `proto/openapi_embed.go`
- REST route wiring: `server/router/api/`

So instead of a GraphQL schema, the source of truth for the public API is the `.proto` files under `proto/api/v1/`, from which the OpenAPI/REST spec and gRPC bindings are generated.
