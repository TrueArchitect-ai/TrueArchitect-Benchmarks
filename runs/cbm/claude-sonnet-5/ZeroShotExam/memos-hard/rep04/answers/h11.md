The persistent entity types are the exported structs defined in the `store` package (the data layer), e.g. `User` (store/user.go), `Memo` (store/memo.go), `Attachment` (store/attachment.go), `Reaction` (store/reaction.go), `Inbox` (store/inbox.go), `MemoRelation` (store/memo_relation.go), `MemoShare` (store/memo_share.go), `UserIdentity` (store/user_identity.go), `UserSetting`, `InstanceSetting`, `IdentityProvider`, `AuthenticationConfigState`.

Counting distinct Go packages outside `store/**` that reference each type (via `store.<Type>`), out of the 10 outside packages that import `store` at all (`server`, `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`, `server/runner/s3presign`):

- `store.User` → 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- `store.Memo` → 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Other types trail well behind (`Attachment` 4, `MemoRelation`/`MemoShare` 3, `Inbox` 3, `UserIdentity`/`Reaction` 2).

**1st: `store.User` (~7 packages); 2nd: `store.Memo` (~6 packages)**

Sources: `store/user.go`, `store/memo.go`, and usages across `server/auth/context.go`, `server/router/rss/rss.go`, `server/router/api/v1/common.go`, `server/router/frontend/frontend_test.go`, `server/runner/memopayload/memopayload.go`, etc.
