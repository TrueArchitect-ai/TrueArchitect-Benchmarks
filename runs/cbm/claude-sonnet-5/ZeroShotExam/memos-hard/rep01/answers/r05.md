**Premise correction:** There is no GraphQL schema in this repository — I found no `.graphql`/`.gql` files and no `graphql`-related dependencies or code anywhere (checked `web/package.json`, all `*.go` files, and the full tree).

**Actual API surface:** The public API is defined via **Protocol Buffers / gRPC**, using [buf](https://buf.build) for codegen:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`)
- Internal storage messages: `proto/store/*.proto`
- Codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`
- The gRPC services are additionally exposed as a REST/JSON API via **grpc-gateway**, with an embedded OpenAPI spec at `proto/api/openapi_embed.go` (generated output lives under `proto/gen`).

So if you're looking to understand or extend the public API contract, `proto/api/v1/*.proto` is the source of truth, not a GraphQL schema.
