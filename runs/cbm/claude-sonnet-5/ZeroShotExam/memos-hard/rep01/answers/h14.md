h14.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(content)` (implemented in `internal/markdown/markdown.go:355-422`). The extracted `Tags` and `Property` are written onto `memo.Payload.Tags` / `memo.Payload.Property` (a `storepb.MemoPayload_Property`, defined in `proto/store/memo.proto` / `proto/gen/store/memo.pb.go`).

**Triggers (recomputation):**
- Memo creation — `CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, ...)` before persisting (`server/router/api/v1/memo_service.go:108`).
- Memo update, but only when the update mask includes the `content` field — `UpdateMemo` calls `RebuildMemoPayload` inside the `path == "content"` branch (`server/router/api/v1/memo_service.go:436-451`); updating other fields (visibility, pin, etc.) does not recompute it.
- Bulk backfill — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) paginates through all memos and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each, for rebuilding payloads en masse (e.g., after a markdown-extraction logic change); it is not wired to an automatic scheduled runner in the current server startup (`server/server.go`), unlike the S3-presign runner.

**Extracted properties (single goldmark AST walk, `internal/markdown/markdown.go:356-422`):**
- `Tags` — all `#tag` nodes (deduplicated, case preserved).
- `Mentions` — all `@username` mention nodes (lowercased, deduplicated) — used internally by `ExtractAll` but not stored in `Property`.
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one.
- `Property.HasLink` — whether any link node exists.
- `Property.HasCode` — whether any code block/fenced code block/code span exists.
- `Property.HasTaskList` — whether any task checkbox exists.
- `Property.HasIncompleteTasks` — whether any unchecked task checkbox exists.
