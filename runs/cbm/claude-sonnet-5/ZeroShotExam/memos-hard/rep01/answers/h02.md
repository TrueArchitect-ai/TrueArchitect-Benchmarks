- **Delivery function**: `Post` (and its async wrapper `PostAsync`, which enqueues to `asyncPostQueue` and is dispatched by worker goroutines started in `init()`) — `internal/webhook/webhook.go:120` (`PostAsync` at `internal/webhook/webhook.go:184`). It builds and sends the outbound HTTP request via `safeClient.Do(req)` at `internal/webhook/webhook.go:152`.

- **Protection mechanism**: SSRF protection is enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59`), which is wired into `safeClient`'s `http.Transport.DialContext` (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any resolved IP for which `isReservedIP` (`internal/webhook/validate.go:44`) returns true — this blocks loopback, RFC-1918 private ranges, link-local/cloud-metadata (169.254.0.0/16), and their IPv6 equivalents, per `reservedCIDRs` in `internal/webhook/validate.go:14-23`. Because the check runs at actual connection time (not just at URL-save time), it also defeats DNS-rebinding attacks. There's also a pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62`), used when webhook URLs are created/updated, which performs the same reserved-IP check against a one-time DNS lookup (belt-and-suspenders, but not what protects the actual delivery call). Both checks can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments.
