**Determination method:**

1. `store.Store.CreateMemo` (`/bench/repo/store/memo.go:109-114`) is a thin wrapper that validates the UID and delegates to `s.driver.CreateMemo(ctx, create)` — `store.Driver` is an interface implemented separately by three packages: `store/db/sqlite`, `store/db/mysql`, `store/db/postgres` (each has its own `memo.go` with a `CreateMemo` that issues its own dialect-specific `INSERT`). So the interface alone doesn't tell you which one runs.
2. The concrete driver is selected at startup in `store/db/db.go:14-32` (`NewDBDriver`), a `switch profile.Driver { case "sqlite": ... case "mysql": ... case "postgres": ... }`.
3. `profile.Driver` is populated from the `--driver` CLI flag / `MEMOS_DRIVER` env var via Viper in `cmd/memos/main.go`, where the default is explicitly set twice: `viper.SetDefault("driver", "sqlite")` (line 122) and the flag definition `rootCmd.PersistentFlags().String("driver", "sqlite", "database driver")` (line 130).
4. Since a "default installation" supplies no `--driver`/`MEMOS_DRIVER` override, `profile.Driver == "sqlite"`, so `NewDBDriver` constructs a `sqlite.DB`, meaning `store.driver` is a `*sqlite.DB`, and `(*sqlite.DB).CreateMemo` is the code that actually executes the `INSERT`.
