**Convergence function:** `Post` — `internal/webhook/webhook.go:120`

`PostAsync` (`internal/webhook/webhook.go:184`) only enqueues the payload onto `asyncPostQueue`; the worker goroutines started in `init()` (`webhook.go:42-53`) dequeue and call `Post`, which builds the request and performs `safeClient.Do(req)` (`webhook.go:152`) — the single point where the outbound HTTP request to the user-supplied `requestPayload.URL` is actually sent (through the SSRF-guarding `safeClient`/`safeDialContext`).
