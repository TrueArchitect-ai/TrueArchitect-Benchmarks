**Computation site:** `internal/markdown/markdown.go` — `(*service).ExtractAll` (`server/runner/memopayload/runner.go:74`, `RebuildMemoPayload`, is the wrapper that invokes it and writes the result into `memo.Payload`). `ExtractAll` does a single goldmark AST walk over the memo's markdown content and populates an `ExtractedData` struct; `RebuildMemoPayload` copies `data.Tags` and `data.Property` onto `store.Memo.Payload` (`storepb.MemoPayload`, defined in `proto/store/memo.proto:7-22`).

**Triggers (recomputation):**
- Memo creation: `server/router/api/v1/memo_service.go:108` — `CreateMemo` calls `memopayload.RebuildMemoPayload` before persisting.
- Memo content update: `server/router/api/v1/memo_service.go:447` — `UpdateMemo`, only when the update mask includes the `content` path (edits to visibility/pin/etc. do not trigger recomputation).
- Bulk/background rebuild: `server/runner/memopayload/runner.go` `Runner.RunOnce` iterates all memos in batches and calls `RebuildMemoPayload` for each (note: this batch runner is not currently wired into `Server.startBackgroundRunners` in `server/server.go`, which only starts the S3 presign runner — so today it's only reachable via the two API-triggered paths above, not on a schedule).

**Extracted properties** (`internal/markdown/markdown.go:356-416`, stored in `MemoPayload.tags` and `MemoPayload.property` per `proto/store/memo.proto:7-22`):
- `Tags` — all `#tag` nodes found in the content (deduplicated, case preserved).
- `Property.title` — text of the first H1 heading, only if it's the very first block in the document.
- `Property.has_link` — true if any Markdown link node exists.
- `Property.has_code` — true if any code block, fenced code block, or code span exists.
- `Property.has_task_list` — true if any task checkbox exists.
- `Property.has_incomplete_tasks` — true if any task checkbox is unchecked.
- (Also extracts `Mentions` from `@mention` nodes into `ExtractedData.Mentions`, but `RebuildMemoPayload` does not currently persist this field onto the memo payload.)
