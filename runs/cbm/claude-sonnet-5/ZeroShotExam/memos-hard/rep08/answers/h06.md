**Handlers (RPC methods on `APIV1Service`, `server/router/api/v1/connect_services.go`):**

- `UpdateMemo` — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook`

Each of these dispatch functions loads the current user's configured webhooks (`s.Store.GetUserWebhooks`), sets `payload.URL = hook.Url` (a user-configured URL), and enqueues via `webhook.PostAsync(payload)` (`internal/webhook/webhook.go:184`), which pushes onto `asyncPostQueue`; four background goroutines (started in `init()`, `internal/webhook/webhook.go:42-55`) pull from that queue and call `Post`.

**Convergence function:** `Post` — `internal/webhook/webhook.go:120` (issues the actual `http.NewRequest`/`safeClient.Do` outbound POST to `requestPayload.URL`; all six handler paths above funnel through here, either directly for synchronous callers or via the `PostAsync` queue for async dispatch).
