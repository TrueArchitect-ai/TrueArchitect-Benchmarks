Delivery function — `Post` in `internal/webhook/webhook.go:120` (dispatched synchronously; `PostAsync`, same file line 184, queues calls to it via a worker pool). It executes the outbound HTTP request through `safeClient` (`internal/webhook/webhook.go:32`).

Protection mechanism — the SSRF guard lives in `internal/webhook/webhook.go` and `internal/webhook/validate.go`:
- `safeDialContext` (`internal/webhook/webhook.go:59`) is installed as the `http.Transport.DialContext` on `safeClient`; it resolves the target host at dial time and rejects any resolved IP that is reserved/private (blocking DNS-rebinding bypasses of a pre-request check).
- `isReservedIP`/`reservedNetworks` (`internal/webhook/validate.go:14-54`) define the blocked ranges (loopback, RFC-1918 private space, link-local incl. `169.254.169.254` cloud metadata, and IPv6 equivalents), used both by `safeDialContext` and by `ValidateURL` (`internal/webhook/validate.go:62`), which performs an upfront resolve-and-check when a webhook URL is registered/edited.
- `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is an operator-controlled escape hatch that disables the check for self-hosted deployments targeting internal services.
