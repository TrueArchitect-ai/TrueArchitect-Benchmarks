**Premise correction:** There is no per-user API rate-limiting middleware in this repository. This is the Memos server (Go, `github.com/usememos/memos`), and no code, config, or dependency implements rate limiting — a search for `ratelimit`, `rate_limit`, `rate-limit`, and `throttle` across the entire codebase returns zero matches.

The actual request-handling middleware/interceptor chain, registered in `server/router/api/v1/v1.go:133-137`, consists only of:
1. `NewMetadataInterceptor()` — converts HTTP headers to gRPC metadata
2. `NewLoggingInterceptor(logStacktraces)`
3. `NewRecoveryInterceptor(logStacktraces)`
4. `NewAuthInterceptor(authorizer)`

There's also request-size limiting (`connect.WithReadMaxBytes(maxAPIRequestBytes)` at `server/router/api/v1/v1.go:141`) and CORS handling (`server/cors.go`), but neither of these is rate limiting. If you're thinking of a different service or a reverse-proxy/gateway layer (e.g., nginx) that sits in front of this app, that isn't part of this repo.
