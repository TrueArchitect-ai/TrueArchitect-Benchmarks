**Premise correction:** This repository has no GraphQL API — there is no `.graphql`/`.gql` schema file, no `type Query`/`type Mutation` definitions, and no GraphQL server library (Apollo, graphql-yoga, etc.) anywhere in the codebase.

**Actual API surface:** This is the [usememos/memos](/bench/repo/README.md) project, and per its README it exposes "full REST and gRPC APIs" instead. The API is defined via Protocol Buffers:

- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `shortcut_service.proto`, `attachment_service.proto`, `instance_service.proto`, and others in that directory)
- Internal storage messages: `proto/store/*.proto` (e.g. `memo.proto`, `inbox.proto`, `idp.proto`)
- Generated Go bindings: `proto/gen/api/v1/` and `proto/gen/store/`
- A REST surface is derived from the same proto definitions via `grpc-gateway`/OpenAPI annotations, with the generated OpenAPI spec at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)
- Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`

So "the GraphQL schema for the public API" doesn't exist here — the equivalent, schema-defining source of truth is the `.proto` files under `proto/api/v1/`.
