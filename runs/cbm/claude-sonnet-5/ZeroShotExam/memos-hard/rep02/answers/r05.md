**Premise correction:** This repository (usememos/memos) does not have a GraphQL API — there is no `.graphql`/`.gql` schema file and no `graphql` dependency anywhere in the codebase (verified via full-repo grep for "graphql", zero hits outside `.git`).

**Actual API surface:** The public API is defined via Protocol Buffers and exposed as gRPC + a REST gateway (with OpenAPI docs generated from the same proto definitions):
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`)
- Generated Go bindings: `proto/gen/api/v1/`
- Generated OpenAPI (REST) spec: `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`
- Codegen config: `proto/buf.yaml` / `proto/buf.gen.yaml`

This matches the README's stated API surface: "full REST and gRPC APIs for integration" — no GraphQL.
