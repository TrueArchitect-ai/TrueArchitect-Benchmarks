**Handlers** — all are `APIV1Service` RPC methods in `server/router/api/v1/`, each of which dispatches a webhook to a URL the user configured via `CreateUserWebhook`/`UpdateUserWebhook` (stored as `WebhooksUserSetting_Webhook.Url`):

1. `CreateMemo` — `server/router/api/v1/memo_service.go:70` → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook`
2. `UpdateMemo` — `server/router/api/v1/memo_service.go:401` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook`
3. `DeleteMemo` — `server/router/api/v1/memo_service.go:518` → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook`
4. `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook`
5. `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:16` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:16` → same path

All of these call `webhook.PostAsync` (defined in `server/router/api/v1/memo_service_webhooks.go`, using `hook.Url` fetched from `s.Store.GetUserWebhooks`), which enqueues onto `asyncPostQueue`; four worker goroutines started in `internal/webhook/webhook.go`'s `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`.

**Convergence function** — `Post` in `internal/webhook/webhook.go:120` (`func Post(requestPayload *WebhookRequestPayload) error`). This is the single place that builds the `http.Request` and calls `safeClient.Do(req)` against the user-supplied `requestPayload.URL`, for every one of the handlers above (both the synchronous `Post` path and the async `PostAsync`/queue path funnel through it).

Note: there is a second, unrelated outbound-URL path — `GetLinkMetadata`/`BatchGetLinkMetadata` (`server/router/api/v1/memo_service_link_metadata.go:14,19`) — which fetches a user-supplied URL directly via `httpgetter.GetHTMLMeta` (`internal/httpgetter/html_meta.go:136`), but it does not converge with the webhook handlers; it has its own separate HTTP client/convergence point.
