h14.

**Computation site:** `internal/markdown/markdown.go` — the `service.ExtractAll` method (`internal/markdown/markdown.go:356-422`), which does a single goldmark AST walk over the memo's markdown content. It's invoked via the wrapper `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which assigns the results onto `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`, defined in `proto/store/memo.proto:15-21`).

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` on every new memo before it's persisted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when the update mask includes the `content` path (i.e., only when the memo body actually changes).
- Bulk/offline recomputation via `Runner.RunOnce` in `server/runner/memopayload/runner.go:28-70`, which pages through all memos (`store.ListMemos`) and calls `RebuildMemoPayload` + `store.UpdateMemo` for each — intended as a backfill/migration path (note: it is not currently wired into `server/server.go`'s scheduled runners the way `s3presign.NewRunner` is, so in this codebase revision it runs only if invoked directly, not on an automatic cron).

**Extracted properties** (`storepb.MemoPayload_Property`, populated during the AST walk in `ExtractAll`/`ExtractProperties`):
- `Title` — text of the first block-level child if it's an H1 heading (`extractHeadingText`, markdown.go:210-213 / 386-389)
- `HasLink` — true if any `Link` AST node is present (markdown.go:393-394)
- `HasCode` — true if any code block, fenced code block, or code span is present (markdown.go:396-397)
- `HasTaskList` — true if any task checkbox node is present (markdown.go:399-400)
- `HasIncompleteTasks` — true if any task checkbox is unchecked (markdown.go:401-404)

Additionally, `ExtractAll` collects `Tags` (from `#tag` AST nodes, deduped case-preserving) and `Mentions` (from `@mention` AST nodes, lowercased/deduped) in the same pass; tags are stored on `memo.Payload.Tags`.
