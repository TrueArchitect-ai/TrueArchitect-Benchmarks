**Premise correction:** There is no GraphQL schema in this repository — the premise of the question is false. This project (memos) does not use GraphQL anywhere; a repo-wide search for "graphql" (case-insensitive, excluding `node_modules`) returns zero matches, and there are no `.graphql`/`.gql` files.

**Actual API surface:** The public API is defined via **Protocol Buffers / gRPC**, not GraphQL:
- Proto service/message definitions live under `/bench/repo/proto/api` (the public API contracts) and `/bench/repo/proto/store` (internal storage-layer protos).
- Generated code from these definitions is in `/bench/repo/proto/gen`.
- The server wiring for these gRPC/HTTP-gateway services is under `/bench/repo/server/router`.

If you're looking for something GraphQL-like, this codebase doesn't have it — it's a gRPC (with grpc-gateway for REST/JSON) API defined in `.proto` files under `proto/api`.
