h06.
Handlers (RPC methods on `APIV1Service`, in `server/router/api/v1/`) that transitively trigger an outbound request to a webhook URL the user configured (`store.Webhook.Url`, set via the WebhookService):

- `CreateMemo` (`memo_service.go:157`) → `DispatchMemoCreatedWebhook`
- `UpdateMemo` (`memo_service.go:513`, via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook`
- `DeleteMemo` (`memo_service.go:562`) → `DispatchMemoDeletedWebhook`
- `CreateMemoComment` (`memo_service_comments.go:119`) → `DispatchMemoCommentCreatedWebhook`
- Also `SetMemoAttachments` (`memo_attachment_service.go:48`) and `SetMemoRelations` (`memo_relation_service.go:48`), both of which call `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

All of these dispatch functions (defined in `server/router/api/v1/memo_service_webhooks.go`) build a `webhook.WebhookRequestPayload{URL: hook.Url, ...}` from a user-stored webhook URL and hand it to `webhook.PostAsync`, which enqueues onto `asyncPostQueue` (`internal/webhook/webhook.go:39,184`) — a fixed pool of 4 worker goroutines (`webhook.go:42-55`) all call the same delivery function.

Convergence function — `Post` in `internal/webhook/webhook.go:120` (the actual outbound call is `safeClient.Do(req)` at `internal/webhook/webhook.go:152`).
