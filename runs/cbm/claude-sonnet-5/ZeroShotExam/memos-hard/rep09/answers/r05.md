**Premise correction:** There is no GraphQL schema in this repository — this is `usememos/memos`, and its README explicitly advertises "full REST and gRPC APIs," not GraphQL. A repo-wide search for `.graphql`/`.gql` files and any `graphql` references in source or config turns up nothing.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), which is compiled with `buf` (`proto/buf.gen.yaml`, `proto/buf.yaml`) into generated gRPC/gRPC-Gateway code in `proto/gen/`, and exposed as REST via a gRPC-Gateway/OpenAPI layer (`proto/openapi_embed.go`). Server implementations of these services live under `server/`.
