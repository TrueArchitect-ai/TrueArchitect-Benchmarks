h02.

- Delivery function — `Post` (and its async wrapper `PostAsync`) in `internal/webhook/webhook.go` (lines 120–196). `Post` builds and sends the outbound HTTP request via `safeClient.Do(req)`; `PostAsync` queues payloads onto `asyncPostQueue`, consumed by worker goroutines that call `Post`.

- Protection mechanism — the shared `safeClient`'s custom `Transport.DialContext`, implemented as `safeDialContext` in `internal/webhook/webhook.go` (lines 57–77), combined with `isReservedIP`/`reservedNetworks` in `internal/webhook/validate.go` (lines 14–54). `safeDialContext` resolves the target hostname at dial time and rejects any resolved IP that falls in a reserved/private CIDR (loopback, RFC-1918 private ranges, link-local incl. `169.254.169.254` cloud metadata, and IPv6 equivalents) — since it checks at the dial (post-DNS-resolution) step rather than just the original URL, it also defeats DNS-rebinding attacks. There's also a separate pre-flight check, `ValidateURL` in `internal/webhook/validate.go` (lines 62–83), used when webhooks are created/updated to reject unsafe URLs up front, but the actual runtime enforcement for every dispatch is the dialer guard. Both can be disabled per-deployment via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
