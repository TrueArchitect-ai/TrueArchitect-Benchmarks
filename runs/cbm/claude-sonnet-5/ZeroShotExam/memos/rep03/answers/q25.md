**Engine + path:** Google's CEL (Common Expression Language), via `google/cel-go`, wrapped by an in-house engine at `internal/filter/` (`engine.go`, `schema.go`, `ir.go`, `parser.go`, `render.go`).

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) validates `request.Filter` and stores it as a string on `store.FindMemo.Filters`; the `filter.Engine` (`internal/filter/engine.go`) compiles that CEL string with `cel.NewEnv`/`env.Compile` into a CEL AST, `buildCondition` (`internal/filter/parser.go`/`ir.go`) lowers the AST into a dialect-agnostic `Condition` tree, and then a `renderer` (`internal/filter/render.go`) walks that tree to emit dialect-specific SQL fragments + args (e.g. `LIKE`/`ILIKE`/`REGEXP`, `json_each`/`jsonb_array_elements_text`/`JSON_TABLE`, backtick vs. `$N` placeholders) for SQLite, MySQL, and Postgres respectively — invoked per-store via `filter.AppendConditions` in `store/db/{sqlite,mysql,postgres}/memo.go`.
