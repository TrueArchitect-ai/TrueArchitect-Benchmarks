The `store.Driver` interface is defined in `store/driver.go`.

Three implementations (entry files):
- `store/db/sqlite/sqlite.go`
- `store/db/postgres/postgres.go`
- `store/db/mysql/mysql.go`

Each exposes a `NewDB(profile *profile.Profile) (store.Driver, error)` constructor.

Factory function that selects between them at startup:
`NewDBDriver` — `store/db/db.go` (switches on `profile.Driver` value `"sqlite"` / `"mysql"` / `"postgres"`)
