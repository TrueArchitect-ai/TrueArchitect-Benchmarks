q25.

**Engine + path:** A custom in-house filter engine built on Google's [CEL](https://github.com/google/cel-go) (`cel-go`), living in `internal/filter/` (`engine.go`, `schema.go`, `ir.go`, `parser.go`, `render.go`, `helpers.go`).

**Mechanism:** `request.Filter` (a CEL/AIP-160-style filter string, e.g. from `ListMemos`) is compiled by `filter.Engine.Compile` (`internal/filter/engine.go:47`) via `cel-go`'s `env.Compile`, converted to a dialect-agnostic `Condition` tree (`buildCondition`, `internal/filter/ir.go`) against a field `Schema` (`internal/filter/schema.go`), and then `Program.Render`/`renderer.renderCondition` (`internal/filter/render.go`) walks that tree to emit dialect-specific SQL/args (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`), which is invoked from the store layer (e.g. `store/db/sqlite/memo.go:57-61`, `store/db/mysql/memo.go:65-69`, `store/db/postgres/memo.go:54-58` via `filter.AppendConditions`/`CompileToStatement`) to build the `WHERE` clause for each database backend.
