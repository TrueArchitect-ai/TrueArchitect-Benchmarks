q20. Server-Sent Events (SSE) over a `/api/v1/sse` endpoint (frontend consumes it via `EventSource` in `web/src/hooks/useLiveMemoRefresh.ts`).

- Mechanism: Server-Sent Events (SSE), implemented with an in-memory `SSEHub` broadcasting JSON `SSEEvent`s to per-client buffered channels (`server/router/api/v1/sse_handler.go` registers the `/sse` route via `RegisterSSERoutes`).
- Hub path: `server/router/api/v1/sse_hub.go` (`SSEHub` type, `Broadcast`/`Subscribe`/`Unsubscribe` methods), wired up in `server/router/api/v1/v1.go`.
- Handlers that broadcast through it (all in `server/router/api/v1/`):
  - `CreateMemo` (memo_service.go) — memo.created
  - `DeleteMemo` (memo_service.go) — memo.deleted
  - `dispatchMemoUpdatedSideEffects` (memo_update_helpers.go) — memo.updated, called from `UpdateMemo` (memo_service.go), `SetMemoAttachments`/attachment update path (memo_attachment_service.go), and the memo relation update path (memo_relation_service.go)
  - `CreateMemoComment` (memo_service_comments.go) — memo.comment.created
  - `UpsertMemoReaction` (reaction_service.go) — reaction.upserted
  - `DeleteMemoReaction` (reaction_service.go) — reaction.deleted
