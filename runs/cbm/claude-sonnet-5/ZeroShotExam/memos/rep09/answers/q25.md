Engine + path: `internal/filter` (`internal/filter/engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`) — a CEL (Common Expression Language, via `github.com/google/cel-go/cel`) based filter engine. `ListMemos` (server/router/api/v1/memo_service.go:211-223) validates/collects the raw `request.Filter` string into `memoFind.Filters`.

Mechanism: `filter.Engine.Compile` (internal/filter/engine.go:48) uses a CEL `cel.Env` built from a `Schema` (internal/filter/schema.go, field/function definitions for memo attributes like `content`, `tags`, `created_ts`, etc.) to parse and type-check the CEL expression into an AST, which `buildCondition` (internal/filter/parser.go/ir.go) converts into a dialect-agnostic `Condition` tree (IR); then `Program.Render`/`renderer` (internal/filter/render.go) walks that IR and emits dialect-specific SQL fragments + placeholder args by switching on `RenderOptions.Dialect` (`DialectSQLite`/`DialectMySQL`/`DialectPostgres`, defined in schema.go), which the per-dialect store code (e.g. `store/db/sqlite/memo.go:57-61` calling `filter.AppendConditions`) appends into the `WHERE` clause.
