- **Mechanism**: Server-Sent Events (SSE) — a persistent HTTP stream pushed from server to browser, implemented via `SSEHub.Broadcast` fanning out to per-client buffered channels (`server/router/api/v1/sse_handler.go` handles the HTTP handshake/streaming).
- **Hub path**: `server/router/api/v1/sse_hub.go` (`SSEHub` type, with `Subscribe`/`Unsubscribe`/`Broadcast`), supported by event-construction helpers in `server/router/api/v1/sse_event_helpers.go`.
- **Handlers that broadcast through it**:
  - `CreateMemo` (`memo_service.go:163`) — memo.created
  - `UpdateMemo` (`memo_service.go:513`, via `dispatchMemoUpdatedSideEffects` in `memo_update_helpers.go:71`) — memo.updated
  - `DeleteMemo` (`memo_service.go:585`) — memo.deleted
  - `CreateMemoComment` (`memo_service_comments.go:126`) — memo.comment.created
  - `UpsertMemoReaction` (`reaction_service.go:106`) — reaction.upserted
  - `DeleteMemoReaction` (`reaction_service.go:161`) — reaction.deleted
  - Also `dispatchMemoUpdatedSideEffects` is additionally invoked from `SetMemoAttachments`-style handler in `memo_attachment_service.go:48` and a relation-update handler in `memo_relation_service.go:48`, which broadcast memo.updated indirectly.
