`web/src/hooks/useMemoQueries.ts`; uses the `memoServiceClient` (created via `createClient(MemoService, transport)` in `web/src/connect.ts`, backed by the generated `MemoService` client from `web/src/types/proto/api/v1/memo_service_pb.ts`).

This module defines the React Query hooks (`useListMemos`, `useGetMemo`, `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useListMemoComments`, etc.) that call `memoServiceClient.{listMemos,getMemo,createMemo,updateMemo,deleteMemo,listMemoComments}`.
