**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (Connect-RPC client interceptor, ~lines 156–178) attached to the shared transport, backed by token storage in `web/src/auth-state.ts`.

**Token kinds:** an access token (short-lived JWT, "Access Token V2") kept in-memory + `localStorage` (`memos_access_token`/`memos_token_expires_at`) and sent as `Authorization: Bearer <token>`; plus a refresh token that lives in an HttpOnly cookie (never touched by JS) sent automatically via `credentials: "include"`. Backend additionally accepts long-lived Personal Access Tokens (PATs) via the same Bearer header, though those aren't managed client-side.

**Backend validation package:** `server/auth` (Go) — `server/auth/authenticator.go` (`Authenticator.Authenticate`, `AuthenticateByAccessTokenV2`, `AuthenticateByPAT`, `AuthenticateByRefreshToken`) and `server/auth/extract.go` (`ExtractBearerToken`, `ExtractRefreshTokenFromCookie`), wired into requests by the server-side `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go`.
