q08. `Driver` — `store/driver.go` (lines 8-10, package `store`)

The `Driver` interface defines all the store methods a database backend must implement (attachments, memos, users, settings, etc.). It's satisfied by the SQLite, Postgres, and MySQL backends: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, and selected at runtime via `store/db/db.go`.
