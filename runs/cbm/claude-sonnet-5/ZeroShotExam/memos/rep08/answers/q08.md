`Driver` — `store/driver.go` (package `store`)

The `Driver` interface (store/driver.go:10) defines all methods a database backend must implement (attachments, memos, users, settings, inbox, reactions, etc.). It's implemented by the concrete backends in `store/db/sqlite/sqlite.go`, `store/db/mysql/mysql.go`, and `store/db/postgres/postgres.go`, each returning a `store.Driver` per `store/db/db.go`.
