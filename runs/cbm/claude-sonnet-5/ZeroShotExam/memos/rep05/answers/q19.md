MemoService is served over two protocols:

1. **gRPC-Gateway (REST/JSON over HTTP)** — registered via `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` in `server/router/api/v1/v1.go:108`, using the generated gateway code in `proto/gen/api/v1/memo_service.pb.gw.go`.

2. **Connect protocol (Connect/gRPC/gRPC-Web over HTTP)** — the `ConnectServiceHandler` implements MemoService's Connect methods (e.g., `CreateMemo`, `ListMemos`) in `server/router/api/v1/connect_services.go:304` onward, and is wired up/mounted via `apiv1connect.NewMemoServiceHandler(s, opts...)` in `server/router/api/v1/connect_handler.go:40`, using the generated Connect code in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.
