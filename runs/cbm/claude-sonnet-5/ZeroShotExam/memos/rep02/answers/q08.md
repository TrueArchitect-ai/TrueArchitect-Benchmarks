`Driver` — `store/driver.go`

The `Driver` interface (`/bench/repo/store/driver.go:10`) defines all methods a store database driver must implement (attachments, memos, users, settings, inbox, reactions, etc.). It's implemented by each backend package: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, and referenced generically in `store/db/db.go`.
