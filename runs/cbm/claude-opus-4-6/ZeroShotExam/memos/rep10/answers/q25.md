**Engine:** [CEL (Common Expression Language)](https://github.com/google/cel-go) via `cel-go`, wrapped in a custom `Engine` at `internal/filter/engine.go`.

**Mechanism:** The `Engine.Compile` method parses the filter string using the CEL environment (`cel.Env.Compile`), converts the resulting AST into a dialect-agnostic IR condition tree (`internal/filter/ir.go` defines the `Condition` types, `internal/filter/parser.go` builds them from the CEL AST), and then `Program.Render` hands that tree to a `renderer` (`internal/filter/render.go`) which walks the IR and emits dialect-specific SQL fragments — switching on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) at each node to produce the correct placeholder style, JSON operators, case-folding, date-part extraction, etc.
