When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` (line 157) calls `DispatchMemoCreatedWebhook`, which in turn calls the helper `dispatchMemoRelatedWebhook` — both defined in `server/router/api/v1/memo_service_webhooks.go`. This helper looks up the creator's webhooks, builds a payload, and calls `webhook.PostAsync` to enqueue it. The actual HTTP delivery is performed by the `Post` function in the `internal/webhook` package (`internal/webhook/webhook.go`), which uses Go's standard `net/http` client. Requests are signed using **HMAC-SHA256** following the Standard Webhooks convention: the message ID, timestamp, and body are signed with the secret (resolved via `resolveSigningKey`, supporting `whsec_`-prefixed base64 secrets), and the signature is sent in `webhook-id`, `webhook-timestamp`, and `webhook-signature` (`v1,<base64>`) headers.
