The filter engine uses **CEL (Common Expression Language)** via `github.com/google/cel-go`, implemented in `internal/filter/engine.go`. The `Engine.Compile` method parses the CEL filter string into a dialect-agnostic IR condition tree (`internal/filter/parser.go` builds it from the CEL AST), and then `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) which walks each condition node and emits dialect-specific SQL (with per-dialect branches for SQLite, MySQL, and PostgreSQL) using the field metadata and expression overrides defined in the `Schema` (`internal/filter/schema.go`).
