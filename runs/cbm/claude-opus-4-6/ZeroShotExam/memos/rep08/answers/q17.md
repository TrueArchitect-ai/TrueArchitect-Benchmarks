`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The file `web/src/hooks/useMemoQueries.ts` contains all memo CRUD mutations and queries — `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, `useMemo`, plus comment and link-metadata queries. It imports `memoServiceClient` from `@/connect` (defined at `web/src/connect.ts`), which is created via `createClient(MemoService, transport)` using the generated `MemoService` protobuf service definition.
