Here is the complete call chain for creating a memo, one hop per line:

1. `web/src/hooks/useMemoQueries.ts` — `useCreateMemo()` mutation hook calls `memoServiceClient.createMemo()`
2. `web/src/connect.ts` — `memoServiceClient` (created via `createClient(MemoService, transport)`) sends the Connect/gRPC-Web request
3. `proto/api/v1/memo_service.proto` — `rpc CreateMemo(CreateMemoRequest) returns (Memo)` defines the RPC
4. `server/router/api/v1/connect_services.go` — `ConnectServiceHandler.CreateMemo()` receives the request and delegates to `s.APIV1Service.CreateMemo()`
5. `server/router/api/v1/memo_service.go` — `APIV1Service.CreateMemo()` builds the `store.Memo` struct and calls `s.Store.CreateMemo()`
6. `store/memo.go` — `Store.CreateMemo()` delegates to `s.driver.CreateMemo()`
7. `store/db/sqlite/memo.go` — `DB.CreateMemo()` executes the SQL `INSERT INTO memo ...` (the SQLite dialect driver; Postgres and MySQL equivalents are at `store/db/postgres/memo.go` and `store/db/mysql/memo.go`)
