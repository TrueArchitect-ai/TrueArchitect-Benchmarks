The following database tables are affected when `DeleteMemo` runs:

1. **`memo`** — the memo row itself is deleted (`store/db/sqlite/memo.go:239`), plus any comment memos are recursively deleted (`server/router/api/v1/memo_service.go:574`)
2. **`memo_relation`** — explicitly deleted for both `memo_id` and `related_memo_id` matching the memo (`store/memo.go:142-146`)
3. **`attachment`** — all attachments linked to the memo are explicitly deleted (`store/memo.go:149-157`)
4. **`memo_share`** — deleted via `ON DELETE CASCADE` foreign key on `memo(id)` (`store/migration/sqlite/LATEST.sql:109`)
