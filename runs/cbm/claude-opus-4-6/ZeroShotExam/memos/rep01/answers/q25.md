**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`; **path:** `internal/filter/` (engine in `internal/filter/engine.go`, parser in `internal/filter/parser.go`, dialect renderer in `internal/filter/render.go`, schema in `internal/filter/schema.go`).

**Mechanism:** The `Engine.Compile` method parses the filter string with `cel-go` into an AST, then `buildCondition()` (`parser.go`) converts that AST into a dialect-agnostic IR condition tree (`ir.go`), and `Program.Render()` walks that condition tree through a `renderer` (`render.go`) that switches on `DialectName` (one of `DialectSQLite`, `DialectMySQL`, `DialectPostgres`) to emit dialect-specific SQL fragments (placeholders, function names, quoting, JSON operators, timestamp extraction, regex, etc.) for each condition node.
