For a fresh SQLite install, the complete current schema is provided by `store/seed/sqlite/01__dump.sql`.

This is the seed file used to initialize a brand-new SQLite database with the full schema, as opposed to the incremental migration files under `store/migration/sqlite/` which are applied to upgrade existing databases. The `LATEST.sql` file at `store/migration/sqlite/LATEST.sql` tracks the latest migration version, but the seed dump is the single file that provides the complete schema for a fresh install.
