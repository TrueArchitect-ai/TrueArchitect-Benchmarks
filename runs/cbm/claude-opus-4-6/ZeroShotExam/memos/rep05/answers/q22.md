When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` (line 157) calls **`DispatchMemoCreatedWebhook`** defined in `server/router/api/v1/memo_service_webhooks.go`. This function delegates to `dispatchMemoRelatedWebhook` (same file), which looks up the creator's webhooks and calls `webhook.PostAsync` to enqueue each payload.

The HTTP delivery is performed by the **`net/http`** standard library package (via a custom `safeClient` in `internal/webhook/webhook.go`).

The request-signing mechanism is **HMAC-SHA256** following the Standard Webhooks convention: the payload is signed by computing `HMAC-SHA256(msgID + "." + timestamp + "." + body)` using the user's signing secret (which may use the `whsec_<base64>` format), and the signature is sent in a `webhook-signature` header as `v1,<base64-signature>` alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:133–149`).
