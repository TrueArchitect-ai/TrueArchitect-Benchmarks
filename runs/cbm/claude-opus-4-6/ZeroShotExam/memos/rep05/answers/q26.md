The following database tables are affected when `DeleteMemo` runs:

1. **`memo`** — the memo row itself is deleted (`store/db/sqlite/memo.go:239`)
2. **`memo_relation`** — all relation rows where the memo is either `memo_id` or `related_memo_id` are explicitly deleted in `store/memo.go:142-146`
3. **`attachment`** — all attachments linked to the memo are deleted in `store/memo.go:149-157` (via `store/db/sqlite/attachment.go:212`)
4. **`memo_share`** — deleted via `ON DELETE CASCADE` foreign key constraint on `memo_id` referencing `memo(id)` (`store/migration/sqlite/LATEST.sql:109`)

Additionally, the service layer in `server/router/api/v1/memo_service.go:567-577` recursively deletes **comment memos** (memos related via `MemoRelationComment`), which triggers the same cascade for each comment — affecting the same four tables for every child comment memo.
