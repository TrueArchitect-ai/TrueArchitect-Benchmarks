- **Webhook Async Workers (×4)** — event-driven via a buffered channel (`make(chan ..., 128)`); goroutines consume from the queue on each `PostAsync()` call. Started by package `init()` in `internal/webhook/webhook.go:42-55`.

- **Email Async Workers (×2)** — event-driven via a buffered channel (`make(chan ..., 128)`); goroutines consume from the queue on each `SendAsync()` call. Started by package `init()` in `internal/email/email.go:17-36`.

- **Cache Cleanup Goroutines (×3)** — `time.NewTicker` every 5 minutes; one each for the instance-setting, user, and user-setting caches. Started by `cache.New()` in `store/cache/cache.go:83`, created at `store/store.go:51-53`.

- **PAT Usage Recording** — fire-and-forget `go func()` spawned on each PAT-authenticated request. Triggered in `server/auth/authenticator.go:179-185`.
