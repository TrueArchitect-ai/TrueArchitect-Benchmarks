**CEL (Common Expression Language)** via `github.com/google/cel-go/cel`; engine at `internal/filter/engine.go`.

The `Engine.Compile` method parses the filter string with CEL, walks the resulting protobuf AST (`parser.go`) to build a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`), and then `renderer.Render` (`internal/filter/render.go`) pattern-matches each IR node and emits dialect-specific SQL fragments by switching on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) for every construct (JSON access, LIKE folding, placeholder style, date extraction, etc.).
