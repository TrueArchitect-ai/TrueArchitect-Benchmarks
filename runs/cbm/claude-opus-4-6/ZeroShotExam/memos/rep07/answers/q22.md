When a memo is created, the `CreateMemo` handler in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook` (defined at `server/router/api/v1/memo_service_webhooks.go:15`). The actual HTTP delivery is performed by the `internal/webhook` package (`internal/webhook/webhook.go`) using Go's standard `net/http` client. Requests are signed using **HMAC-SHA256** following the Standard Webhooks convention: the payload is signed with `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)`, and the signature is sent in `webhook-signature` / `webhook-id` / `webhook-timestamp` headers.
