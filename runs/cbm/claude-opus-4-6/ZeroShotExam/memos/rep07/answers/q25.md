**Mechanism:** The `Engine.Compile` method parses the CEL filter string into an AST using `cel-go`, converts it into a dialect-agnostic IR condition tree (`internal/filter/parser.go:buildCondition`), and then `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) which walks it and emits dialect-specific SQL fragments by switching on the `DialectName` (`DialectSQLite`, `DialectMySQL`, `DialectPostgres`) — using per-dialect SQL expressions for JSON access, timestamp extraction, string functions, and placeholder styles — producing a `Statement` with a SQL string and bound args that callers like `store/db/sqlite/memo.go:61` inject into their queries via `filter.AppendConditions`.
