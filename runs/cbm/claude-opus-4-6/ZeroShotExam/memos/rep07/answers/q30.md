Four memo lifecycle events dispatch webhooks:

- **created**: `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
- **updated**: `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
- **deleted**: `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
- **comment created**: `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)

All defined in `server/router/api/v1/memo_service_webhooks.go`.

The first three converge through the private helper `dispatchMemoRelatedWebhook` (same file, line 48), which resolves the memo creator, fetches their webhooks, and calls `webhook.PostAsync`. The comment event (`DispatchMemoCommentCreatedWebhook`) calls `webhook.PostAsync` directly (line 43) but follows the same pattern.

All four ultimately converge for delivery at **`webhook.PostAsync`** (`internal/webhook/webhook.go:184`), which enqueues the payload onto a buffered channel (`asyncPostQueue`). Worker goroutines (spawned in `init()`, line 42) drain the channel and call **`webhook.Post`** (`internal/webhook/webhook.go:120`), which performs the actual HTTP POST delivery.
