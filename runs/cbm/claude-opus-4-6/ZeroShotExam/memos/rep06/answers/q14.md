The `ShortcutService` is defined in `proto/api/v1/shortcut_service.proto` and declares these five RPCs:

1. **ListShortcuts**
2. **GetShortcut**
3. **CreateShortcut**
4. **UpdateShortcut**
5. **DeleteShortcut**

All five are implemented in the backend file **`server/router/api/v1/shortcut_service.go`** as methods on `APIV1Service`.
