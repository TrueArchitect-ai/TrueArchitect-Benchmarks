When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls `DispatchMemoCreatedWebhook` (defined in `server/router/api/v1/memo_service_webhooks.go`). This function resolves the memo creator's webhooks and, for each one, calls `webhook.PostAsync` which enqueues the payload onto an async channel. Worker goroutines dequeue and call `webhook.Post` in the `internal/webhook` package (`internal/webhook/webhook.go`), which performs the actual HTTP POST using `net/http`. The request is signed using **HMAC-SHA256** following the Standard Webhooks convention: headers `webhook-id`, `webhook-timestamp`, and `webhook-signature` (with a `v1,` prefix) are set, where the signature is computed as `HMAC-SHA256(key, msgID + "." + timestamp + "." + body)` and the key is derived from a `whsec_`-prefixed base64-encoded secret.
