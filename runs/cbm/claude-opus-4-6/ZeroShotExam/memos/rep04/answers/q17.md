The frontend module containing memo CRUD mutations/queries is `web/src/hooks/useMemoQueries.ts`. It exports hooks like `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, `useMemos`, and `useMemo` (get). It uses the generated service client `memoServiceClient`, which is created in `web/src/connect.ts` via `createClient(MemoService, transport)`.
