The following RPC handler methods can transitively cause an outbound HTTP POST to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go` — dispatches `"memos.memo.created"` via `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go` — dispatches `"memos.memo.updated"` via `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go` — dispatches `"memos.memo.deleted"` via `DispatchMemoDeletedWebhook`
4. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go` — dispatches `"memos.memo.updated"` via `DispatchMemoUpdatedWebhook`
5. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go` — dispatches `"memos.memo.updated"` via `DispatchMemoUpdatedWebhook`
6. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go` — dispatches `"memos.memo.comment.created"` via `DispatchMemoCommentCreatedWebhook` (and also transitively calls `CreateMemo`, triggering `"memos.memo.created"`)

**Convergence function:** All of the created/updated/deleted paths converge through **`dispatchMemoRelatedWebhook`** in `server/router/api/v1/memo_service_webhooks.go:48`. This function resolves the memo creator, fetches configured webhooks from the store via `s.Store.GetUserWebhooks()`, builds a `WebhookRequestPayload` (including the user-configured `hook.Url`), and hands it off to `webhook.PostAsync()` (`internal/webhook/webhook.go:184`), which enqueues it for async delivery by `webhook.Post()` (`internal/webhook/webhook.go:120`) — the function that actually performs the `http.NewRequest("POST", requestPayload.URL, ...)` and `safeClient.Do(req)`.
