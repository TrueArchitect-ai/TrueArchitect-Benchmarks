The premise needs correction: **this repository does not have a GraphQL API**. There is no GraphQL schema defined anywhere in the codebase.

The actual public API surface is defined using **Protocol Buffers (gRPC) with gRPC-Gateway for REST/HTTP transcoding**:

- **Protobuf service definitions** are in `proto/api/v1/*.proto` — these are the source-of-truth for the API. The service files include:
  - `memo_service.proto`
  - `user_service.proto`
  - `auth_service.proto`
  - `attachment_service.proto`
  - `instance_service.proto`
  - `idp_service.proto`
  - `ai_service.proto`
  - `shortcut_service.proto`
  - `common.proto` (shared types)

- **Generated Go gRPC/gateway code** lives in `proto/gen/api/v1/` (e.g., `*.pb.go`, `*.pb.gw.go`, `*_grpc.pb.go`).

- **Generated OpenAPI spec** is at `proto/gen/openapi.yaml`, produced by `protoc-gen-openapi` from those same proto definitions.

- **Buf** manages the protobuf toolchain, configured via `proto/buf.yaml` and `proto/buf.gen.yaml`.
