Here are all the distinct memo visibility enforcement sites:

1. **GetMemo / checkMemoReadAccess** — `server/router/api/v1/memo_service.go` (line 39–67). Central access-check helper: denies unauthenticated users for non-public memos, denies non-owners for private memos. Called by `GetMemo` and `ListMemoComments`.

2. **ListMemos** — `server/router/api/v1/memo_service.go` (lines 218–226). Filters the query: anonymous users see only `PUBLIC`; authenticated users viewing others' memos see `PUBLIC` + `PROTECTED`; own memos are unfiltered.

3. **CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (line 41). Blocks commenting on a private memo unless the requester is the owner or a super-user.

4. **ListMemoComments** — `server/router/api/v1/memo_service_comments.go` (lines 148, 157–161). After checking the parent memo via `checkMemoReadAccess`, applies a visibility filter to the returned comment memos themselves.

5. **ListReactions / CreateReaction** — `server/router/api/v1/reaction_service.go` (lines 30–38, 82–83). Both RPCs independently check the linked memo's visibility before listing or creating a reaction.

6. **GetAttachmentBinary (linked attachment access)** — `server/router/api/v1/attachment_service.go` (lines 436–451). When an attachment is linked to a memo, access follows the memo's visibility rules.

7. **SSE event delivery (canReceive)** — `server/router/api/v1/sse_hub.go` (lines 134–143). Filters real-time SSE events: private-visibility events are delivered only to the creator or admins.

8. **RSS feeds** — `server/router/rss/rss.go` (lines 90, 141). Both the global and per-user RSS feeds restrict the query to `VisibilityList: []store.Visibility{store.Public}`.

9. **Sitemap generation** — `server/router/frontend/frontend.go` (line 150). Only `PUBLIC` memos are included in the sitemap XML.

10. **GetMemoAttachment** — `server/router/api/v1/memo_attachment_service.go` (lines 213–222). Checks the memo's visibility before serving an attachment through the memo-attachment endpoint.

11. **Fileserver (static file serving)** — `server/router/fileserver/fileserver.go` (lines 677, 699). Enforces visibility when serving attachment files: public-visibility memos are served anonymously only when allowed; private memos restrict access to the owner or admin.

12. **User stats (GetUserStats / GetUserHeatmap)** — `server/router/api/v1/user_service_stats.go` (lines 84–90, 218–220). Applies visibility filters when computing per-user memo statistics and heatmap data.

13. **ListMemoRelations** — `server/router/api/v1/memo_relation_service.go` (lines 109–111). Filters related memos by visibility when listing memo relations.
