**Computation site:** `server/runner/memopayload/runner.go:74` — the function `RebuildMemoPayload` calls `markdownService.ExtractAll()` (implemented in `internal/markdown/markdown.go:356`), which parses the memo's markdown content via goldmark in a single AST walk. **Triggers:** Three operations trigger `RebuildMemoPayload`:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls it before persisting a new memo.
2. **UpdateMemo** — `server/router/api/v1/memo_service.go:447` calls it when the `content` field is in the update mask.
3. **RunOnce (batch rebuild)** — `server/runner/memopayload/runner.go:27` iterates all memos in batches of 100, rebuilding every payload (used for migration/repair).

The `snippet` field is not persisted — it is recomputed every time a memo is converted to its API response (`convertMemoFromStoreWithCreators`).

**Extracted properties** (defined in `proto/api/v1/memo_service.proto:272–279` as `Memo.Property`):
- **`has_link`** — whether the content contains any markdown link
- **`has_task_list`** — whether the content contains any GFM task checkbox
- **`has_code`** — whether the content contains a code block, fenced code block, or code span
- **`has_incomplete_tasks`** — whether any task checkbox is unchecked
- **`title`** — text extracted from the first block-level H1 heading, if present
- **`tags`** — deduplicated list of `#tag` tokens (stored in `Payload.Tags`, not inside `Property`)
- **`snippet`** — a plain-text summary of the content truncated to 64 characters at a word boundary (computed at read time, not stored in the payload)
