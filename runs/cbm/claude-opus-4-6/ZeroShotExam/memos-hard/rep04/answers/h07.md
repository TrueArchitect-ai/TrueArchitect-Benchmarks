`GET /file/users/:identifier/avatar` — the avatar is stored as a base64 data-URI in the `avatar_url` column of the `user` table; the handler decodes it and streams the raw bytes.

`serveUserAvatar` — `server/router/fileserver/fileserver.go`
`getUserByUsername` — `server/router/fileserver/fileserver.go`
`Store.GetUser` — `store/user.go`
`Store.ListUsers` — `store/user.go`
`Driver.ListUsers` (interface) — `store/driver.go`
`(*DB).ListUsers` (sqlite impl) — `store/db/sqlite/user.go`  (queries `SELECT … avatar_url … FROM user WHERE username = ?`)
`parseDataURI` — `server/router/fileserver/fileserver.go`  (regex-extracts MIME type, base64-decodes the image bytes)
`c.Blob` (echo response) — `server/router/fileserver/fileserver.go`  (writes decoded bytes to the HTTP response)
