The question's premise is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`) is a general-purpose cron scheduling library, but it is not used anywhere in the application code to register a database-cleanup job. The only references to "cleanup" in that package are illustrative examples in documentation (`internal/scheduler/doc.go`, `internal/scheduler/example_test.go`, `internal/scheduler/README.md`), not actual registered jobs. The sole real cron schedule in the repository is the GitHub Actions stale-issues workflow in `.github/workflows/stale.yml`, which runs every 8 hours (`0 */8 * * *`) to close stale issues and PRs — unrelated to database cleanup.
