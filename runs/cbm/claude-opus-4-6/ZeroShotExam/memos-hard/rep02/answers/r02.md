The premise of the question is incorrect. This repository (Memos) does not have a per-user API rate-limiting middleware. There is no rate limiter, throttle, token-bucket, or request-quota mechanism anywhere in the codebase. A search across all Go server code (`server/`, `internal/`, `cmd/`) and the `go.mod` dependency file yields zero hits for `ratelimit`, `rate_limit`, `rate-limit`, `throttle`, `limiter`, or related rate-limiting libraries. The middleware that does exist handles CORS (`server/cors.go`), authentication/authorization (`server/auth/`, `server/router/api/v1/authz.go`), and frontend routing (`server/router/frontend/frontend.go`) — but none of these implement request rate limiting.
