Memo visibility is enforced at these distinct server surfaces:

1. **GetMemo (single-memo fetch)** — `server/router/api/v1/memo_service.go` (line ~55–66, the `getMemoDisplayCheck` helper rejects non-public memos for unauthenticated users and private memos for non-owners)

2. **ListMemos (memo listing/query)** — `server/router/api/v1/memo_service.go` (line ~218–227, filters `VisibilityList` so anonymous users see only PUBLIC, other users see PUBLIC+PROTECTED unless viewing their own)

3. **ListMemoReactions / UpsertMemoReaction (reactions)** — `server/router/api/v1/reaction_service.go` (lines ~30–41 and ~83, checks visibility before listing or upserting a reaction on a memo)

4. **ListMemoAttachments (memo attachment listing via gRPC)** — `server/router/api/v1/memo_attachment_service.go` (lines ~214–225, checks visibility before returning attachments linked to a memo)

5. **GetAttachment (attachment download via gRPC)** — `server/router/api/v1/attachment_service.go` (lines ~445–453, `checkMemoVisibilityForAttachment` checks memo visibility for linked attachments)

6. **File server (attachment serving via HTTP)** — `server/router/fileserver/fileserver.go` (lines ~677–701, checks memo visibility with public/anonymous and private/creator guards plus share-token fallback)

7. **CreateMemoComment (commenting)** — `server/router/api/v1/memo_service_comments.go` (line ~41, blocks commenting on a private memo by non-owner/non-admin)

8. **SSE event delivery** — `server/router/api/v1/sse_hub.go` (lines ~135–143, `canReceive` filters private-visibility events to the creator or admins only)

9. **RSS feed generation** — `server/router/rss/rss.go` (lines ~90 and ~141, both `GetSystemRSS` and `GetUserRSS` restrict to `store.Public` only)

10. **Sitemap generation** — `server/router/frontend/frontend.go` (line ~150, `getSitemapXML` lists only `store.Public` memos)

11. **User stats (ListAllUserStats / GetUserStats)** — `server/router/api/v1/user_service_stats.go` (lines ~84–91 and ~217–221, scopes memo counts by visibility based on the requesting user)

12. **Mention/inbox notification filtering** — `server/router/api/v1/memo_mention_helpers.go` (lines ~56–72, `canUserAccessMentionContext` suppresses mention notifications for private memos the target user cannot see)
