**Premise correction:** This project does not use GraphQL. There is no GraphQL schema anywhere in the repository.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with a **gRPC + REST (gRPC-Gateway)** architecture. The service definitions live in `proto/api/v1/*.proto` — specifically:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto` (shared types)

These `.proto` files are the source of truth. From them, code generation (configured in `proto/buf.gen.yaml`) produces:

1. **Go gRPC server/client stubs** used by the Go backend in `server/`
2. **An OpenAPI 3.0 spec** at `proto/gen/openapi.yaml` (generated via `protoc-gen-openapi`), which documents the RESTful HTTP surface (e.g. `/api/v1/...` endpoints)
3. **TypeScript protobuf types** in `web/src/types/proto/api/v1/` for the frontend
