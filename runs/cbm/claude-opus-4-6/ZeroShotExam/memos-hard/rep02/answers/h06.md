The outbound HTTP requests go to **user-configured webhook URLs**. The RPC handler methods that transitively trigger these are:

- **`CreateMemo`** (`server/router/api/v1/memo_service.go:157`) — calls `DispatchMemoCreatedWebhook`
- **`UpdateMemo`** (`server/router/api/v1/memo_service.go:513`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- **`DeleteMemo`** (`server/router/api/v1/memo_service.go:562`) — calls `DispatchMemoDeletedWebhook`
- **`SetMemoRelations`** (`server/router/api/v1/memo_relation_service.go:48`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- **`SetMemoAttachments`** (`server/router/api/v1/memo_attachment_service.go:48`) — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- **`CreateMemoComment`** (`server/router/api/v1/memo_service_comments.go:119`) — calls `DispatchMemoCommentCreatedWebhook`

All of these paths converge at the single function **`dispatchMemoRelatedWebhook`** (`server/router/api/v1/memo_service_webhooks.go:48`). This function resolves the memo creator's configured webhooks, builds a `WebhookRequestPayload` for each, and hands them off to `webhook.PostAsync()` (`internal/webhook/webhook.go:184`), which asynchronously calls `webhook.Post()` — the function that actually issues the outbound `http.POST` to the user-configured URL via a safe (SSRF-protected) HTTP client.

**Handlers (6):** `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `SetMemoRelations`, `SetMemoAttachments`, `CreateMemoComment`; **convergence function** — `dispatchMemoRelatedWebhook` in `server/router/api/v1/memo_service_webhooks.go:48`.
