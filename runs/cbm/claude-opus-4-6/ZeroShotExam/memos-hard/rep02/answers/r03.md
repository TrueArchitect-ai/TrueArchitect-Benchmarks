The premise of the question is incorrect. There is no "nightly database-cleanup job" scheduled in this repository's cron scheduler. The `internal/scheduler/` package (`internal/scheduler/README.md`) is a general-purpose cron job scheduling library, but its README only shows a `"daily-cleanup"` example in a documentation code snippet (line 34–38) with the schedule `"0 2 * * *"` — this is illustrative sample code, not an actual registered job. No production code in the repository registers a database-cleanup job with the scheduler.
