The persistent entity types are defined in the `store/` package (the data layer). Counting how many distinct Go packages **outside** `store/` reference each entity type via `store.<Type>`:

1. **`User`** — referenced from **7 packages** (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)
2. **`Memo`** — referenced from **6 packages** (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

**1st: User (~7 packages); 2nd: Memo (~6 packages)**

The `User` struct (`store/user.go`) is the most widely referenced entity outside the data layer, appearing in auth, notification, API, file serving, frontend, and RSS packages. `Memo` (`store/memo.go`) is second, referenced across notification, API, frontend, RSS, and the memo-payload runner.
