The premise of this question is incorrect. This repository (Memos) does not contain any per-user API rate-limiting middleware. There is no rate limiter, throttle, or request-limit mechanism anywhere in the codebase. The server middleware registered in `server/server.go` and `server/cors.go` covers CORS handling, and there is a task scheduler middleware in `internal/scheduler/middleware.go`, but neither implements API rate limiting. No Go or TypeScript file in the repository references rate limiting, request quotas, or throttling for API endpoints.
