The premise is incorrect — this project does **not** have a GraphQL API. There is no GraphQL schema anywhere in the repository.

The actual public API surface is defined as **gRPC services with REST/HTTP transcoding via grpc-gateway**. The API is specified using **Protocol Buffer (`.proto`) files** located in `proto/api/v1/`:

- `memo_service.proto` — Memo CRUD and listing
- `user_service.proto` — User management
- `auth_service.proto` — Authentication
- `attachment_service.proto` — File attachments
- `instance_service.proto` — Instance/server settings
- `idp_service.proto` — Identity providers
- `shortcut_service.proto` — Shortcuts
- `ai_service.proto` — AI features
- `common.proto` — Shared types

Each service uses `google.api.http` annotations (e.g., `post: "/api/v1/memos"`) to expose RESTful HTTP endpoints alongside gRPC, powered by `grpc-gateway/v2` (`go.mod`). The generated Go code lives in `proto/gen/`, and an OpenAPI spec is embedded via `proto/openapi_embed.go`. The HTTP server itself is wired up in `server/` using the Echo framework (`labstack/echo/v5`).
