h06.

The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`

All four dispatch methods (`DispatchMemo{Created,Updated,Deleted}Webhook` via `dispatchMemoRelatedWebhook`, and `DispatchMemoCommentCreatedWebhook` directly) converge on **`webhook.Post`** (`internal/webhook/webhook.go:120`). This is the single function where all paths converge before delivery — it constructs the HTTP request, optionally signs it with HMAC-SHA256, and executes it via `safeClient.Do`. The async variants go through `PostAsync` (`internal/webhook/webhook.go:183`), which enqueues to a channel drained by goroutines that call `Post`.
