**s3presign Runner** — every **12 hours** — wired into server startup at `server/server.go:162`

The `s3presign.Runner` (`server/runner/s3presign/runner.go`) refreshes S3 presigned URLs for externally-stored attachments. It iterates over all S3-type attachments in batches, checks whether each presigned URL will expire within the next day (presigned URLs have a 5-day lifetime; it re-signs if fewer than 4 days remain), and updates the stored reference with a fresh presigned URL.

The runner is created and kicked off in `Server.startBackgroundRunners` (`server/server.go:153`). At line 162 it instantiates the runner (`s3presign.NewRunner(s.Store)`), runs it once synchronously (line 163), then launches the continuous 12-hour ticker loop in a goroutine (line 169). `startBackgroundRunners` itself is called from `Server.Start` at `server/server.go:129`.
