Here are the distinct memo visibility enforcement sites:

1. **GetMemo / checkMemoReadAccess** — `server/router/api/v1/memo_service.go` (line 39–66: shared helper that gates single-memo reads; checks Public/Protected/Private and denies non-owners for Private)
2. **ListMemos** — `server/router/api/v1/memo_service.go` (line 218–227: applies `VisibilityList` / filter so unauthenticated users see only Public, authenticated non-owners see Public+Protected)
3. **ListMemoComments / CreateMemoComment** — `server/router/api/v1/memo_service_comments.go` (line 41 for comment creation, line 157–160 for listing comments; both enforce visibility)
4. **ListMemoReactions / UpsertMemoReaction** — `server/router/api/v1/reaction_service.go` (lines 30–41 and 82–85: checks memo visibility before allowing reaction listing or creation)
5. **ListMemoAttachments** — `server/router/api/v1/memo_attachment_service.go` (lines 213–224: checks memo visibility before listing a memo's attachments)
6. **checkAttachmentAccess (GetAttachment/DeleteAttachment)** — `server/router/api/v1/attachment_service.go` (lines 422–455: for linked attachments, delegates to memo visibility rules)
7. **ListMemoRelations** — `server/router/api/v1/memo_relation_service.go` (lines 108–112: applies a visibility filter on related memos so only permitted ones are returned)
8. **SSE event delivery (canReceive)** — `server/router/api/v1/sse_hub.go` (lines 134–143: Private events are only delivered to the creator or admin)
9. **User stats (ListAllUserStats)** — `server/router/api/v1/user_service_stats.go` (lines 84–91: applies VisibilityList/filter when aggregating memo stats)
10. **File server (attachment download)** — `server/router/fileserver/fileserver.go` (lines 674–701: enforces memo visibility when serving attachment files over HTTP, including share-token fallback)
11. **RSS feed** — `server/router/rss/rss.go` (lines 90, 141: restricts feed to `store.Public` memos only)
12. **Sitemap generation** — `server/router/frontend/frontend.go` (line 150: only Public memos appear in the sitemap)
