**Explicit Go code**; emoji reactions are removed by two dedicated functions in the user-deletion transaction.

When a user is deleted, `deleteUserTargetsTx()` in `store/db/sqlite/user_delete.go` explicitly issues two separate reaction-deletion steps:

1. **`deleteReactionsByContentIDsTx()`** (line 96, defined at line 380) — deletes all reactions whose `content_id` matches any of the deleted user's memos (`DELETE FROM reaction WHERE content_id IN ...`). This removes reactions that *other* users left on the deleted user's content.

2. **`deleteReactionsByCreatorTx()`** (line 102, defined at line 400) — deletes all reactions where `creator_id` equals the deleted user's ID (`DELETE FROM reaction WHERE creator_id = ?`). This removes reactions the deleted user left on *anyone else's* content.

Both run inside the same database transaction (lines 31–53) before the user row itself is deleted (line 123).
