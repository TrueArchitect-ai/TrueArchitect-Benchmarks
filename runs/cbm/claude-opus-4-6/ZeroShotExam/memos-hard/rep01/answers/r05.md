**Premise correction:** There is no GraphQL schema in this repository. The project (Memos) does not use GraphQL at all.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC and gRPC-Gateway, providing both gRPC and REST endpoints. The relevant files are:

- **Protobuf service definitions** in `proto/api/v1/*.proto` — these are the source-of-truth schemas for the API. Key services include:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/common.proto`

- **Generated Go gRPC/gateway code** in `proto/gen/api/v1/` (`.pb.go`, `_grpc.pb.go`, `.pb.gw.go` files).

- **Generated OpenAPI 3.0 spec** at `proto/gen/openapi.yaml`, produced by `protoc-gen-openapi` from the proto definitions.

- **Generated TypeScript types** output to `web/src/types/proto/` for the frontend.

Code generation is configured in `proto/buf.gen.yaml`, which uses Buf plugins for Go protobuf, gRPC, Connect, gRPC-Gateway, OpenAPI, and TypeScript ES generation.
