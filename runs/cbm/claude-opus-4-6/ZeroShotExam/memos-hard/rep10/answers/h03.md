The provider abstraction is defined in `internal/idp` (`internal/idp/idp.go`), which declares the `IdentityProviderUserInfo` struct used as the common return type. The concrete protocol implementation that ships is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements an OAuth 2 identity provider.
