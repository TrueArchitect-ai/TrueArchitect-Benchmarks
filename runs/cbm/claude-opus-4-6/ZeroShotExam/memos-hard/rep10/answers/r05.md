**Premise correction:** There is no GraphQL schema in this repository. The project (Memos) does not use GraphQL at all.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC, gRPC-Gateway (for REST/HTTP transcoding), and ConnectRPC. The schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Code generation is configured in `proto/buf.gen.yaml`, which produces:
1. **Go gRPC stubs** (`protoc-gen-go-grpc`)
2. **ConnectRPC stubs** (`connectrpc/go`)
3. **gRPC-Gateway** reverse-proxy stubs for REST endpoints (`grpc-ecosystem/gateway`)
4. **OpenAPI 3.0 spec** generated into `proto/gen/openapi.yaml` (via `google-gnostic-openapi`)
5. **TypeScript types** for the web frontend (via `bufbuild/es` into `web/src/types/proto`)
