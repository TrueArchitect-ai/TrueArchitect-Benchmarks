The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this repository's cron scheduler. The `internal/scheduler/` package (`/bench/repo/internal/scheduler/`) is a general-purpose cron job scheduling library — it provides infrastructure for defining and running cron jobs (parsing cron expressions, validating jobs, etc.), but it does not itself define a "database-cleanup" job.

The references to cleanup jobs that do exist in that package are only illustrative examples in documentation and tests:

- `/bench/repo/internal/scheduler/example_test.go` — a test example with a `"cleanup"` job scheduled at 2 AM, but this is example/test code, not a real scheduled job.
- `/bench/repo/internal/scheduler/README.md` — documentation examples showing jobs named `"daily-cleanup"` and `"stale-session-cleanup"`, again purely illustrative.
- `/bench/repo/internal/scheduler/doc.go` — a doc comment example with `"daily-cleanup"`.

No actual database-cleanup job is registered or scheduled anywhere in the production code.
