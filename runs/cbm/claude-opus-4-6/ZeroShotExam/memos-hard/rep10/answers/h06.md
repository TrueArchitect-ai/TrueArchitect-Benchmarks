The following RPC handler methods can transitively cause an outbound HTTP POST to a user-configured webhook URL:

1. **`CreateMemo`** — calls `DispatchMemoCreatedWebhook` directly (`server/router/api/v1/memo_service.go:157`)
2. **`UpdateMemo`** — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_service.go:513` → `memo_update_helpers.go:67`)
3. **`DeleteMemo`** — calls `DispatchMemoDeletedWebhook` directly (`server/router/api/v1/memo_service.go:562`)
4. **`CreateMemoComment`** — calls `DispatchMemoCommentCreatedWebhook` (`server/router/api/v1/memo_service_comments.go:119`)
5. **`SetMemoRelations`** — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_relation_service.go:48`)
6. **`SetMemoAttachments`** — calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` (`server/router/api/v1/memo_attachment_service.go:48`)

All of these paths converge into the single function **`webhook.PostAsync`** (`internal/webhook/webhook.go:184`), which enqueues the payload for asynchronous delivery. The actual outbound HTTP request is made by **`webhook.Post`** (`internal/webhook/webhook.go:120`), which `PostAsync`'s background goroutines call.

More precisely, the dispatch-layer convergence point — where all handler-specific webhook methods (Created/Updated/Deleted/CommentCreated) merge before reaching `PostAsync` — is **`dispatchMemoRelatedWebhook`** (`server/router/api/v1/memo_service_webhooks.go:48`). Three of the four webhook types (`DispatchMemoCreatedWebhook`, `DispatchMemoUpdatedWebhook`, `DispatchMemoDeletedWebhook`) delegate to this single function, which iterates the user's webhooks and calls `webhook.PostAsync` for each. `DispatchMemoCommentCreatedWebhook` has its own loop but also converges on `PostAsync`.

**Handlers (≥3): `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoRelations`, `SetMemoAttachments`; convergence function — `webhook.Post`** (`internal/webhook/webhook.go:120`), where all paths converge into the single outbound `http.Client.Do` call that delivers the request to the user-configured URL.
