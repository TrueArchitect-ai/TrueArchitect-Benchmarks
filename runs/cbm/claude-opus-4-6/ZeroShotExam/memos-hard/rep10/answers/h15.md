Every distinct server-side enforcement site for memo visibility:

1. **GetMemo / single-memo access check** — `server/router/api/v1/memo_service.go` (lines 55–66, the `canAccessMemo` gate: public allows anonymous, protected requires auth, private requires creator or admin)
2. **ListMemos query filtering** — `server/router/api/v1/memo_service.go` (lines 218–227, applies `VisibilityList` / filter expressions to restrict which memos are returned in listings)
3. **CreateMemoComment visibility check** — `server/router/api/v1/memo_service_comments.go` (line 41, blocks commenting on a private memo the user doesn't own)
4. **ListMemoComments visibility filtering** — `server/router/api/v1/memo_service_comments.go` (lines 158–160, filters returned comments by visibility based on caller identity)
5. **ListMemoReactions / UpsertMemoReaction visibility check** — `server/router/api/v1/reaction_service.go` (lines 30–41 and 83, checks memo visibility before listing or creating a reaction)
6. **ListMemoAttachments visibility check** — `server/router/api/v1/memo_attachment_service.go` (lines 214–224, checks memo visibility before listing a memo's attachments)
7. **checkAttachmentAccess (GetAttachment / download)** — `server/router/api/v1/attachment_service.go` (lines 422–455, for linked attachments delegates to memo visibility rules)
8. **ListMemoRelations visibility filtering** — `server/router/api/v1/memo_relation_service.go` (lines 108–112, applies a visibility filter when listing related memos)
9. **Memo converter — relation enrichment filtering** — `server/router/api/v1/memo_service_converter.go` (lines 183–187, filters related memos by visibility when converting memos for API responses)
10. **SSE event delivery (`canReceive`)** — `server/router/api/v1/sse_hub.go` (lines 134–144, private memo events are only delivered to the creator or admins)
11. **File server attachment access** — `server/router/fileserver/fileserver.go` (lines 674–701, enforces memo visibility when serving attachment files over HTTP, including share-token fallback)
12. **RSS feed** — `server/router/rss/rss.go` (lines 90 and 141, only fetches `store.Public` memos for both the global and per-user RSS feeds)
13. **Sitemap generation** — `server/router/frontend/frontend.go` (line 150, only includes `store.Public` memos in the sitemap)
14. **User stats visibility filtering** — `server/router/api/v1/user_service_stats.go` (lines 84–90 and 218–220, restricts memo counts/stats by visibility based on the requesting user)
