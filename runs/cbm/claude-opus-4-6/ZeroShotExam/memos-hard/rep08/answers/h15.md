Here are the distinct memo visibility enforcement sites:

1. **GetMemo / checkMemoReadAccess** (shared access-check helper used by GetMemo and other single-memo RPCs) — `server/router/api/v1/memo_service.go`
2. **ListMemos** (filters `VisibilityList` / `Filters` based on caller identity) — `server/router/api/v1/memo_service.go`
3. **CreateMemoComment** (checks parent memo visibility before allowing a comment) — `server/router/api/v1/memo_service_comments.go`
4. **ListMemoComments** (applies visibility filter when listing comments) — `server/router/api/v1/memo_service_comments.go`
5. **ListMemoReactions / UpsertMemoReaction** (inline visibility check on the memo before listing or upserting a reaction) — `server/router/api/v1/reaction_service.go`
6. **ListMemoAttachments** (checks memo visibility before returning attachments) — `server/router/api/v1/memo_attachment_service.go`
7. **checkAttachmentAccess** (enforces linked memo's visibility when accessing an attachment via the gRPC attachment service) — `server/router/api/v1/attachment_service.go`
8. **File server / attachment download** (enforces memo visibility for attachment file serving over HTTP, including share-token fallback) — `server/router/fileserver/fileserver.go`
9. **ListMemoRelations** (applies a `visibility` filter string so related memos respect the caller's access) — `server/router/api/v1/memo_relation_service.go`
10. **Batch relation conversion in memo converter** (same visibility filter for bulk relation loading) — `server/router/api/v1/memo_service_converter.go`
11. **SSE hub delivery filtering / canReceive** (filters real-time events by visibility so private memo events only reach the creator or admin) — `server/router/api/v1/sse_hub.go`
12. **ListAllUserStats** (filters memos by visibility when computing user statistics) — `server/router/api/v1/user_service_stats.go`
13. **RSS feed** (only includes `Public` memos in the feed) — `server/router/rss/rss.go`
14. **Sitemap generation** (only includes `Public` memos) — `server/router/frontend/frontend.go`
