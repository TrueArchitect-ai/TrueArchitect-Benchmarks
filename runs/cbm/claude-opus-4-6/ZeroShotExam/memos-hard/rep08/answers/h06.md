The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` calls `DispatchMemoCreatedWebhook`
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` calls `DispatchMemoDeletedWebhook`
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` calls `DispatchMemoCommentCreatedWebhook`
5. **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` calls `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

All of these paths converge at **`dispatchMemoRelatedWebhook`** in `server/router/api/v1/memo_service_webhooks.go:48`. This function resolves the memo's creator, fetches their configured webhooks from the store (`GetUserWebhooks`), builds a `WebhookRequestPayload` with each webhook's user-configured URL, and hands it off to `webhook.PostAsync()` which queues it for the final HTTP POST via `webhook.Post()` (`internal/webhook/webhook.go:120`).
