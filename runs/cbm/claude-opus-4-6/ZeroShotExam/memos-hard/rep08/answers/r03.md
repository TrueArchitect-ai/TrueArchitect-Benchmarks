The premise of the question is incorrect. There is no nightly database-cleanup job scheduled in a cron scheduler in this repository. The codebase contains no such scheduled task.

The only cron schedule in the repository is in `.github/workflows/stale.yml`, which runs every 8 hours (`0 */8 * * *`) to close stale GitHub issues and pull requests — not a database cleanup.

The Go backend has no cron scheduler or database-cleanup job. The `store/cache/cache.go` file has an in-memory cache cleanup loop (using a Go ticker, not a cron schedule), and `server/runner/s3presign/runner.go` has a periodic runner for S3 presigned URL refreshes, but neither is a "nightly database-cleanup job."
