The persistent entity types defined in the data layer (`store/` package) include `User`, `Memo`, `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, `MemoShare`, `IdentityProvider`, `InstanceSetting`, `UserSetting`, and `UserIdentity`.

Ranked by the number of packages outside the `store/` layer that reference them:

1. **1st: User** — referenced from ~7 packages (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)
2. **2nd: Memo** — referenced from ~6 packages (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

`User` edges ahead because it's needed in the `server/auth` package (for authentication logic) where `Memo` is not, and `Memo` picks up the `server/runner/memopayload` package that `User` doesn't reach. The next closest is `Attachment` at ~4–5 packages.
