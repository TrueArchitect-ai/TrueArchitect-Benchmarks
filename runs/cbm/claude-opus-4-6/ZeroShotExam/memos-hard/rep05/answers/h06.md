All four paths converge on the same delivery function:

**`webhook.Post`** — `internal/webhook/webhook.go:120`

Every dispatch method calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto `asyncPostQueue`. Background goroutines (started in `init()`, line 42) drain that channel by calling `Post` (line 46), which is the single function that constructs the `http.Request`, signs it (if a signing secret is configured), and executes it via `safeClient.Do` (line 152) — the sole point where the outbound HTTP request to the user-configured URL is actually made.
