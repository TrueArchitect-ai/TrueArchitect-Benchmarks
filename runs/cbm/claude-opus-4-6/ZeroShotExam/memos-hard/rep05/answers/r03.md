The premise of this question is incorrect. There is no "nightly database-cleanup job" in this repository's cron scheduler. The repository contains a single scheduled GitHub Actions workflow (`.github/workflows/stale.yml`), which runs every 8 hours (`0 */8 * * *`) to mark and close stale issues and pull requests — it has nothing to do with database cleanup.
