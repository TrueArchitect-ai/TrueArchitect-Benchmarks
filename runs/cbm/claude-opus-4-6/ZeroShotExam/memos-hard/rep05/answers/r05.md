**Premise correction:** There is no GraphQL schema in this repository. The project does not use GraphQL at all.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with **gRPC + gRPC-Gateway + Connect** as the transport layer. The API schema is defined as `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/instance_service.proto` — Instance/server settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/common.proto` — Shared types

Code is generated from these `.proto` files into `proto/gen/api/v1/`, producing three flavors per service: `*.pb.go` (protobuf messages), `*_grpc.pb.go` (gRPC stubs), `*.pb.gw.go` (gRPC-Gateway for REST/JSON), and Connect handlers in `proto/gen/api/v1/apiv1connect/`. An OpenAPI spec is also generated at `proto/gen/openapi.yaml`. The code generation is orchestrated by Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`).
