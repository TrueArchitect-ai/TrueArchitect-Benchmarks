Memo visibility is enforced at these distinct server surfaces:

1. **GetMemo / UpdateMemo (single-memo read-access gate)** — `server/router/api/v1/memo_service.go` (the `checkMemoReadAccess` method at line 39, called for GetMemo at line 356 and UpdateMemo at line 367)
2. **ListMemos (list-query visibility filter)** — `server/router/api/v1/memo_service.go` (lines 218–227, restricts `VisibilityList` / appends filter based on current user)
3. **CreateMemoComment / ListMemoComments (comment visibility gate)** — `server/router/api/v1/memo_service_comments.go` (line 41 checks Private visibility before allowing a comment; line 148 calls `checkMemoReadAccess`; lines 158–160 filter comments by visibility)
4. **ListMemoRelations (relation visibility filter)** — `server/router/api/v1/memo_relation_service.go` (lines 108–111, applies a `memoFilter` restricting related memos by visibility)
5. **ListMemoReactions / UpsertMemoReaction (reaction visibility gate)** — `server/router/api/v1/reaction_service.go` (lines 29–41 for listing, lines 82–85 for upserting — both check memo visibility before proceeding)
6. **ListMemoAttachments (memo-attachment visibility gate)** — `server/router/api/v1/memo_attachment_service.go` (lines 213–225, checks memo visibility before returning attachments)
7. **Attachment file serving (fileserver visibility gate)** — `server/router/fileserver/fileserver.go` (lines 674–701, `checkAttachmentAccess` enforces the linked memo's visibility when serving file bytes, including share-token fallback)
8. **Attachment gRPC access (attachment service visibility gate)** — `server/router/api/v1/attachment_service.go` (lines 436–454, `checkAttachmentAccess` enforces memo visibility for linked attachments)
9. **SSE event delivery (server-sent events visibility filter)** — `server/router/api/v1/sse_hub.go` (lines 134–144, `canReceive` checks `event.Visibility` — Private events are delivered only to the creator or admins)
10. **RSS feed (public-only filter)** — `server/router/rss/rss.go` (lines 90 and 141, `VisibilityList` is hardcoded to `{store.Public}` so only public memos appear in feeds)
11. **Sitemap (public-only filter)** — `server/router/frontend/frontend.go` (line 150, restricts sitemap generation to `store.Public` memos)
12. **User stats (stats visibility filter)** — `server/router/api/v1/user_service_stats.go` (lines 84–91 and 217–221, restricts which memos are counted in stats based on the requesting user's identity)
