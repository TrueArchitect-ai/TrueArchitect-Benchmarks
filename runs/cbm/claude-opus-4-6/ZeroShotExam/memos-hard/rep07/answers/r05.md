The premise is incorrect — there is no GraphQL schema. Memos does not use GraphQL at all.

The public API is defined as **gRPC/Connect services using Protocol Buffers**. The source-of-truth schema files are the `.proto` definitions in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto` (shared types)

These protos are compiled (via `buf`, configured in `proto/buf.yaml` / `proto/buf.gen.yaml`) into:

- **Go gRPC/Connect stubs** in `proto/gen/api/v1/`
- **TypeScript Connect-ES clients** in `web/src/types/proto/api/v1/`
- **An OpenAPI spec** at `proto/gen/openapi.yaml` (which also powers a REST-style JSON gateway and the MCP endpoint)

The actual API surface is gRPC + gRPC-Gateway REST, not GraphQL.
