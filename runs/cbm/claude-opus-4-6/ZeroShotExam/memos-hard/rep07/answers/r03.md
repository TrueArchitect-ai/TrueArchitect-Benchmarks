The premise of the question is incorrect — there is no "nightly database-cleanup job" scheduled in the cron scheduler in this repository. The `internal/scheduler` package (`internal/scheduler/doc.go`, `internal/scheduler/example_test.go`) is a general-purpose cron scheduler library, and its documentation and examples use a `"daily-cleanup"` job scheduled at `"0 2 * * *"` (2 AM daily) purely as **illustrative example code** — not as an actual registered production job. There is no real database-cleanup job configured anywhere in the codebase. The only actual cron schedule in the repository is in `.github/workflows/stale.yml`, which runs every 8 hours (`"0 */8 * * *"`) to manage stale GitHub issues — unrelated to database cleanup.
