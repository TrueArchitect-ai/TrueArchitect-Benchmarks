**Computation site:** `memopayload.RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdown.Service.ExtractAll()` in `internal/markdown/markdown.go:356-422`. The snippet is computed separately by `getMemoContentSnippet()` in `server/router/api/v1/memo_service_webhooks.go:83-90`, which calls `markdown.Service.GenerateSnippet()` (`internal/markdown/markdown.go:264-346`). Both parse the memo's markdown content via goldmark AST walking.

**Triggers:**
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting a new memo.
2. **UpdateMemo** (when the `"content"` path is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when content changes.
3. **RunOnce** batch rebuild — `server/runner/memopayload/runner.go:27-72` iterates all memos in batches of 100 and rebuilds every payload (a migration/maintenance path).
4. **Snippet** is computed at read time during `convertMemoFromStoreWithCreators` (`server/router/api/v1/memo_service_converter.go:76-80`), not persisted — it is regenerated every time a memo is serialized to the API response.

**Extracted properties** (the `MemoPayload_Property` struct, defined in `proto/gen/store/memo.pb.go:85`):
- **`HasLink`** — true if the content contains a markdown link (`gast.KindLink`)
- **`HasTaskList`** — true if the content contains a GFM task checkbox (`east.KindTaskCheckBox`)
- **`HasCode`** — true if the content contains a code block or inline code span (`gast.KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
- **`HasIncompleteTasks`** — true if any task checkbox is unchecked (`!checkBox.IsChecked`)
- **`Title`** — the plain text of the first block-level element if it is an H1 heading

Additionally, `ExtractAll` also extracts **Tags** (deduplicated `#tag` nodes) and **Mentions** (`@mention` nodes), which are stored in `memo.Payload.Tags` (`runner.go:85`). The **snippet** (a plain-text summary truncated to 64 characters at a word boundary) is computed on the fly at response time, not persisted in the payload.
