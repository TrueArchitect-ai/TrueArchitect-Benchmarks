CEL (Common Expression Language) via `github.com/google/cel-go/cel`. The engine lives at `internal/filter/engine.go` (`Engine` struct, `Compile` method). CEL expressions are parsed into an AST, walked by `internal/filter/parser.go` (`buildCondition`) into a dialect-agnostic IR (`internal/filter/ir.go`), then rendered to SQL by `internal/filter/render.go` which switches on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` for each SQL construct (placeholders, JSON operators, LIKE semantics, regex, timestamp extraction, etc.).
