Google CEL (Common Expression Language) via `github.com/google/cel-go/cel`. The engine lives in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`). CEL expressions are compiled to an AST, converted to a dialect-agnostic IR, then rendered to dialect-specific SQL (with appropriate placeholder styles, JSON operators, and function mappings) per `DialectSQLite`/`DialectMySQL`/`DialectPostgres`. Each store driver calls `filter.AppendConditions()` with its dialect to inject the SQL WHERE clause.
