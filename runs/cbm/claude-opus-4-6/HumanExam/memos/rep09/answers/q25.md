Google CEL (Common Expression Language) engine at `internal/filter/engine.go`; the CEL filter string is compiled into an IR condition tree (`internal/filter/parser.go`), then rendered to dialect-specific SQL by `internal/filter/render.go` using `RenderOptions.DialectName` (sqlite/postgres/mysql), and appended to the WHERE clause via `filter.AppendConditions` called from each driver's `ListMemos`.
