Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, wrapped in `internal/filter/engine.go` (`Engine` struct).
The CEL expression is compiled into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then rendered to dialect-specific SQL by `internal/filter/render.go` which switches on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` for placeholder style, JSON access syntax, and function names. Each store driver calls `filter.AppendConditions()` passing its dialect constant, which compiles and renders each filter string into a WHERE clause fragment.
