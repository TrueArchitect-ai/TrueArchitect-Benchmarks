Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140-158`) deletes:
- Memo relations (where memo is source) — `memo_relation` table
- Memo relations (where memo is target) — `memo_relation` table
- Attachments linked to the memo — `attachment` table

At the API handler level (`server/router/api/v1/memo_service.go:567-577`), comment memos (child memos linked via `MemoRelationComment`) are also recursively deleted first.
