The filter engine uses **CEL (Common Expression Language)** via `github.com/google/cel-go/cel`. It lives in `internal/filter/` (engine at `internal/filter/engine.go`). The CEL expression is compiled to an AST, then transformed into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), which is then rendered into dialect-specific SQL via `internal/filter/render.go`. Each store dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`) with its dialect name (DialectSQLite, DialectPostgres, DialectMySQL), and the rendered SQL fragments are appended to the WHERE clause.
