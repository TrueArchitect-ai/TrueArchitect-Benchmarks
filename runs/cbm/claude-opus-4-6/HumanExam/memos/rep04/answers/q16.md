Before deleting the memo row, the store layer deletes:
1. Memo relations (where memo is source) — `memo_relation` rows with `memo_id`
2. Memo relations (where memo is target) — `memo_relation` rows with `related_memo_id`
3. Attachments linked to the memo — `attachment` rows with matching `memo_id`

(store/memo.go:140–158). Additionally, the API handler deletes comment memos first (server/router/api/v1/memo_service.go:567–577).
