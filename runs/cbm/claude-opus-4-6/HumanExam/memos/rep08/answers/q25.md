The ListMemos RPC accepts a filter expression. What syntax/engine parses it, where does that engine live, and how does the filter become SQL for each dialect?

CEL (Common Expression Language) engine at internal/filter/engine.go; the engine compiles the CEL filter string into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then renders it to dialect-specific SQL (SQLite/PostgreSQL/MySQL) with parameterized placeholders via the renderer at `internal/filter/render.go`. Each store driver calls `filter.AppendConditions()` with its dialect name to inject the resulting SQL WHERE clauses and args into the query.
