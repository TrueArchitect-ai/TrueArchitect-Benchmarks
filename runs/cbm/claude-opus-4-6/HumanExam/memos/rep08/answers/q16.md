When a memo is deleted through the API, which other kinds of records does the store layer delete before the memo row itself?

memo_relation (both directions: memo as source and as target), attachment (each one individually), and memo_share (via ON DELETE CASCADE foreign key on the memo_id column). Additionally, the API handler (`DeleteMemo` in `memo_service.go:567-577`) first deletes comment memos (child memos linked via memo_relation of type COMMENT).
