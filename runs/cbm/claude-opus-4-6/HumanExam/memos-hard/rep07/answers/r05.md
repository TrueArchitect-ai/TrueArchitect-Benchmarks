False premise. There is no GraphQL in this codebase. The public API is defined using Protocol Buffers (`.proto` files in `proto/api/v1/`) and served via two transports: gRPC-Gateway (REST/JSON, registered at `server/router/api/v1/v1.go:96-128` under `/api/v1/*`) and Connect protocol (browser-friendly gRPC, registered at `v1.go:132-144` under `/memos.api.v1.*`).
