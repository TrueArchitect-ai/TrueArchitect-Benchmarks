False premise. There is no message broker (no NATS, no RabbitMQ, no "amqp" in the codebase). Webhook delivery uses a simple in-process Go buffered channel (`asyncPostQueue = make(chan *WebhookRequestPayload, 128)` at `internal/webhook/webhook.go:39`) drained by 4 goroutines spawned in `init()` (line 42), each calling `Post()` to deliver HTTP requests directly.
