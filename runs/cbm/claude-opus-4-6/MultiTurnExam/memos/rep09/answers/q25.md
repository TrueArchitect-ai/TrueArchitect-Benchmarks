CEL (Common Expression Language) engine — `internal/filter/engine.go`; the engine parses filter strings into a dialect-agnostic condition tree using `cel-go` (`internal/filter/parser.go`/`engine.go`), then each dialect driver (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect name (`DialectSQLite`, `DialectMySQL`, or `DialectPostgres`), which renders the IR into dialect-specific SQL WHERE clauses with appropriate placeholders and expressions via `internal/filter/render.go`.
