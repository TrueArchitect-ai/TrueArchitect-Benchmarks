When a memo is deleted, the following records are deleted before the memo row itself:

1. **Memo comments** — the API layer (`server/router/api/v1/memo_service.go:567-577`) first deletes any child memos that are comments (via `MemoRelationComment` relations), each of which recursively triggers the store-level cleanup below.
2. **Memo relations** — the store layer (`store/memo.go:142-146`) deletes `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`).
3. **Attachments** — the store layer (`store/memo.go:149-157`) lists and deletes all `attachment` records linked to the memo.
