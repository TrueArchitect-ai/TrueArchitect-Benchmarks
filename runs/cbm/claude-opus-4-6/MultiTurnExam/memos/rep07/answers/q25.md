CEL (Common Expression Language) engine — `internal/filter/engine.go` (uses `github.com/google/cel-go/cel`), with the parser in `internal/filter/parser.go`.

The engine compiles each CEL filter expression into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), then the renderer in `internal/filter/render.go` translates that tree into SQL for each dialect (SQLite, PostgreSQL, MySQL) using dialect-specific branches; each driver calls `filter.AppendConditions()` (from `internal/filter/helpers.go`) with its dialect name (e.g., `filter.DialectSQLite`) to append the generated SQL WHERE clauses and bind args to its query.
