The tables affected when `DeleteMemo` runs are:

- **memo_relation** — deleted via `Store.DeleteMemo` in `store/memo.go` (both as source and target)
- **attachment** — deleted via `Store.DeleteAttachment` called from `store/memo.go`
- **memo** — the memo row itself, deleted last in `store/memo.go`

Additionally, at the API layer (`server/router/api/v1/memo_service.go`), comment memos are recursively deleted first (each triggering the same cascade), so their **memo**, **memo_relation**, and **attachment** rows are also affected.
