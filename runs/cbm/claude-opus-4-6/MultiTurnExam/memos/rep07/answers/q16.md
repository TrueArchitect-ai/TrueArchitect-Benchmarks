When a memo is deleted, the store layer (`store/memo.go:140–158`) deletes the following records before the memo row itself:

1. **Memo relations** — where the memo is the source (`MemoID`) or target (`RelatedMemoID`) via `DeleteMemoRelation`
2. **Attachments** — linked to the memo, via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **memo comments** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo — each comment deletion itself triggers the same store-level cleanup of its own relations and attachments.
