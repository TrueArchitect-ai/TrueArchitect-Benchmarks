Before deleting the memo row itself, the store layer (`store/memo.go:140–158`) deletes:

1. **Memo relations** — `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`), via `DeleteMemoRelation`
2. **Attachments** — `attachment` records linked to the memo, via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos linked via `MemoRelationComment`) are recursively deleted (each through `Store.DeleteMemo`, which in turn cleans up their own relations and attachments) before the parent memo is deleted.
