CEL (Common Expression Language) via `github.com/google/cel-go` — `internal/filter/engine.go`; the `Engine` parses the filter string into a CEL AST, compiles it into a dialect-agnostic condition IR (`internal/filter/ir.go`), and then a renderer (`internal/filter/render.go`) translates each condition into dialect-specific SQL fragments (using `DialectSQLite`, `DialectPostgres`, or `DialectMySQL`), which are appended as WHERE clauses via `filter.AppendConditions` (`internal/filter/helpers.go`) in each driver's `ListMemos` implementation (e.g., `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`).
