When a memo is deleted, the store layer (`store/memo.go:140-158`) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` records where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-577`), **comment memos** (child memos linked via a `Comment` relation) are recursively deleted before the parent memo, and each of those deletions triggers the same store-level cleanup of their own relations and attachments.
