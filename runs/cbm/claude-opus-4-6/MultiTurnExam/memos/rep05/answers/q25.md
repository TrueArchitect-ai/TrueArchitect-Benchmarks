Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/engine.go` (parser) with the rendering layer in `internal/filter/render.go`.

Each dialect driver (e.g., `store/db/postgres/memo.go`, `store/db/mysql/memo.go`, `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect identifier (e.g., `filter.DialectPostgres`); the engine parses the CEL filter string into a dialect-agnostic IR (`internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) walks the IR and emits dialect-specific SQL WHERE clauses with the appropriate placeholder syntax and function names for each backend.
