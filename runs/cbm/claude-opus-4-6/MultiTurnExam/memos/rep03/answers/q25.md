**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/engine.go`.

**Mechanism:** Each dialect driver (e.g. `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`), passing the filter strings and a dialect identifier (`filter.DialectSQLite`, `filter.DialectPostgres`, or `filter.DialectMySQL`). The engine parses the CEL expression into a dialect-agnostic condition tree (IR defined in `internal/filter/ir.go`), and the renderer (`internal/filter/render.go`) translates each condition node into dialect-specific SQL WHERE clauses and parameterized arguments, which are appended to the query.
