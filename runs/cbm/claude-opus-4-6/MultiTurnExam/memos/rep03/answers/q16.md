When a memo is deleted, the store layer (`store/memo.go:140–158`) deletes the following records before the memo row itself:

1. **Memo relations** — where the memo is the source (`MemoID`) or the target (`RelatedMemoID`) in the `memo_relation` table
2. **Attachments** — all attachments linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos linked via `MemoRelationComment` relations) are recursively deleted before the parent memo, and each of those deletions triggers the same store-level cleanup of relations and attachments.
