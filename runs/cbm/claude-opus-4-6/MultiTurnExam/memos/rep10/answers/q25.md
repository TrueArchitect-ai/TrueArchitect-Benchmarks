CEL (Common Expression Language) via `github.com/google/cel-go` — engine lives in `internal/filter/engine.go`.

The filter string is parsed into a CEL AST by the `Engine`, then `AppendConditions` (`internal/filter/helpers.go`) walks the AST and renders it into dialect-specific SQL fragments using the `Dialect` parameter (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`) with per-dialect SQL rendering logic in `internal/filter/render.go`. Each dialect driver (e.g., `store/db/sqlite/memo.go:57–61`) calls `filter.DefaultEngine()` and `filter.AppendConditions(...)` with its own dialect constant to produce the appropriate SQL WHERE clauses.
