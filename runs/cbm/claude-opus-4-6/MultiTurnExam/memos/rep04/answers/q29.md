Interceptor: `web/src/connect.ts` — the `authInterceptor` (line 156) attaches the access token as a Bearer header on every ConnectRPC request and handles automatic refresh on 401 responses.

Token kinds: JWT access tokens (short-lived, 15 minutes), JWT refresh tokens (long-lived, 30 days, stored as an HTTP cookie `memos_refresh`), and Personal Access Tokens (PATs, prefixed `memos_pat_`).

Backend validation package: `server/auth/` — specifically `server/auth/authenticator.go` validates tokens and `server/auth/token.go` defines the JWT claims, signing, and token types.
