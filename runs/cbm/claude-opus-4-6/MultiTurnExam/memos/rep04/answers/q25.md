Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/` (engine at `internal/filter/engine.go`, parser at `internal/filter/parser.go`).

The CEL engine compiles filter strings into a dialect-agnostic condition tree (IR in `internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) translates that tree into SQL WHERE clauses for the target dialect (SQLite, MySQL, or PostgreSQL), with each dialect's driver passing its `DialectName` constant (e.g., `filter.DialectSQLite`) to `filter.AppendConditions()` — as seen in `store/db/sqlite/memo.go` line 61 — which compiles the filters and renders dialect-specific SQL with properly parameterized placeholders.
