Before deleting the memo row itself, the store layer (`store/memo.go:140–158`) deletes:

1. **Memo relations** — removes `memo_relation` records where the memo is the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — removes all `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos linked via a `Comment`-type relation) are recursively deleted before the parent memo, which in turn triggers the same relation and attachment cleanup for each comment.
