When a memo is deleted, the store layer (`store/memo.go:140–159`) deletes the following records before the memo row itself:

1. **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID`
2. **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID`
3. **Attachments** linked to the memo — each attachment is individually deleted via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **memo comments** (memos related via `MemoRelationComment`) are recursively deleted before the parent memo's `Store.DeleteMemo` is called.
