Engine: **CEL (Common Expression Language)** via `github.com/google/cel-go/cel`, implemented in `internal/filter/engine.go`.

Each dialect driver (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.DefaultEngine()` to obtain the shared CEL engine, then passes the filter strings along with a dialect identifier (e.g., `filter.DialectSQLite`) to `filter.AppendConditions()` (`internal/filter/helpers.go`), which parses each CEL expression into an intermediate representation and renders it into dialect-specific SQL WHERE clauses via the dialect-aware renderer in `internal/filter/render.go`, using per-dialect SQL expression templates defined in `internal/filter/schema.go`.
