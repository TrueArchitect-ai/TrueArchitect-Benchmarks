Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go` (the `Engine` struct, using `cel.NewEnv` to parse filter strings).

The filter string is parsed by the CEL engine into an AST (`internal/filter/parser.go` builds a dialect-agnostic IR condition tree from CEL's `exprv1.Expr`), then the renderer (`internal/filter/render.go`) translates that condition tree into SQL fragments with dialect-specific placeholder styles. Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) passing its dialect name (`DialectSQLite`, `DialectPostgres`, or `DialectMySQL`), which compiles the CEL filter, renders it to SQL WHERE clauses with the appropriate parameter placeholders, and appends them to the query's conditions and args (e.g., `store/db/sqlite/memo.go:61`, `store/db/postgres/memo.go:58`, `store/db/mysql/memo.go:69`).
