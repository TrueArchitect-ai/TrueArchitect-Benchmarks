Before deleting the memo row itself, `Store.DeleteMemo` (in `store/memo.go`, lines 140–158) deletes:

1. **Memo relations** — where the memo is the source (`MemoID`) or target (`RelatedMemoID`), via `DeleteMemoRelation`
2. **Attachments** — all attachments linked to the memo, via `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go`, lines 567–577), **memo comments** (child memos that are related via `MemoRelationComment`) are recursively deleted before the parent memo itself is deleted.

The schema also cascade-deletes **memo shares** via `ON DELETE CASCADE` on the foreign key in the `memo_share` table (`store/migration/sqlite/LATEST.sql`).
