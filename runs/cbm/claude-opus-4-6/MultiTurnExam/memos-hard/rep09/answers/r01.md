The premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed cache in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, or otherwise) configured or used.

User entries use the **default cache configuration** (`store/cache/cache.go:57–64`), which applies a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`), with cleanup every 5 minutes and a maximum of 1000 items. The `Store` creates its `userCache` (along with `userSettingCache` and `instanceSettingCache`) using `cache.NewDefault()` in `store/store.go`, which calls `DefaultConfig()`.
