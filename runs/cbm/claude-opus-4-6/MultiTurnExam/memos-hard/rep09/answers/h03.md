**Abstraction package: `internal/idp`** (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct that all providers return.

**Implementation package: `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`) — the sole concrete implementation that ships, providing an OAuth2 identity provider with token exchange (including PKCE support) and user-info retrieval via configurable field mappings.
