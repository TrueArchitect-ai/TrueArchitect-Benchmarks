The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed through two transport surfaces:

1. **gRPC-Gateway** (REST/JSON over HTTP) — registered in `server/router/api/v1/v1.go:65–115`, where services like `MemoService`, `UserService`, `AuthService`, etc. are registered as gRPC-Gateway handlers on an Echo HTTP server.

2. **Connect (connect-go)** — an alternative RPC transport also registered in the same file, via `ConnectServiceHandler` (`server/router/api/v1/connect_services.go`).

The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`), with generated Go code in `proto/gen/api/v1/`.
