The premise is incorrect — there is no nightly database-cleanup job in this codebase. While the repository contains a general-purpose cron scheduler package (`internal/scheduler/`), it is never imported or used by any server code. No scheduled database cleanup job is registered anywhere. The only background runners are the S3 presign runner (every 12 hours, `server/runner/s3presign/`) and the in-memory cache's self-cleanup loop (every 5 minutes, `store/cache/cache.go`), neither of which performs database cleanup.
