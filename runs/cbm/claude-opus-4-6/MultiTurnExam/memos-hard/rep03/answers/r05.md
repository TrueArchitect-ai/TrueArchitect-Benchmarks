The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API surface is **gRPC + gRPC-Gateway (REST)**, defined via Protocol Buffer files. The protobuf service definitions live under `proto/` (e.g., `proto/gen/api/v1/` contains the generated Go code for services like `memo_service.pb.go`, `user_service.pb.go`, `attachment_service.pb.go`, etc.). The gRPC-Gateway generates corresponding REST endpoints (`.pb.gw.go` files). These are registered in `server/router/api/v1/v1.go` via `RegisterGateway`. Additionally, there is a Connect-based API surface (`proto/gen/api/v1/apiv1connect/`). No GraphQL layer exists anywhere in the project.
