The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-based cache in `store/cache/cache.go`. It uses no external service like Redis.

User entries use the **default cache configuration** (`cache.DefaultConfig()` at `store/cache/cache.go:57–64`), which sets a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`). The user cache is created via `cache.NewDefault()` in the `Store` constructor (`store/store.go`), inheriting this default. Entries are set with `Set()` (`store/cache/cache.go:93`), which delegates to `SetWithTTL` using the default TTL.
