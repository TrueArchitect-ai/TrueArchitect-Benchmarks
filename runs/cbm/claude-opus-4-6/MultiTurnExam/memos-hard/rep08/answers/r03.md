The question's premise is incorrect — there is no nightly database-cleanup cron job. While an `internal/scheduler` package exists, it is never imported or used by any production code. The only background runner in the server is the S3 presign runner (`server/runner/s3presign/runner.go`), which refreshes presigned URLs every 12 hours — it is not a database-cleanup job and does not use cron scheduling. No database cleanup, vacuum, or pruning task is scheduled anywhere in the codebase.
