The question's premise is incorrect — there is no Redis connection. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed structure in `store/cache/cache.go`. There is no Redis dependency anywhere in the codebase (zero references to "redis" exist in any Go source file).

The `Store` creates its caches using `cache.NewDefault()` or `cache.New(config)` in `store/store.go`. The default TTL for all cache entries (including user entries) is **10 minutes**, set by `DefaultConfig()` at `store/cache/cache.go:59`. Cleanup runs every 5 minutes (`store/cache/cache.go:60`), and the cache holds a maximum of 1000 items (`store/cache/cache.go:61`).
