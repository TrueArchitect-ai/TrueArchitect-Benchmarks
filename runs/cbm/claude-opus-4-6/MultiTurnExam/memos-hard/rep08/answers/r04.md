The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four worker goroutines are spawned in `init()` at `internal/webhook/webhook.go:43–55`, each reading from this channel and calling `Post()` to deliver the webhook. Callers enqueue payloads via `PostAsync()` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the payload if the channel is full. The entire mechanism is in-process with no external message broker involved.
