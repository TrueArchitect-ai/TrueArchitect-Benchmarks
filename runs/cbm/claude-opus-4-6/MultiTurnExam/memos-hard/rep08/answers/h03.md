Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct used as the common return type across providers.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the only concrete protocol implementation that ships, providing a generic OAuth2 identity provider with token exchange (including PKCE support) and user-info retrieval via configurable field mappings.
