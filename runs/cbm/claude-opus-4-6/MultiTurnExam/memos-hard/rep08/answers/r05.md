The question's premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is built on **gRPC with gRPC-Gateway** (HTTP/JSON transcoding). The API surface is defined via **Protocol Buffer** (`.proto`) files, with generated Go code under `proto/gen/api/v1/`. The gRPC services are registered and the gRPC-Gateway is wired up in `server/router/api/v1/v1.go` (via `RegisterGateway`), and the gateway is mounted onto the Echo HTTP server in `server/server.go:88`. The proto-generated service stubs (e.g., `proto/gen/api/v1/memo_service_grpc.pb.go`, `proto/gen/api/v1/attachment_service_grpc.pb.go`) define the RPC methods, and the gateway files (`*.pb.gw.go`) provide the REST/JSON translation layer.
