The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **gRPC-Gateway** REST/JSON translation layer.

The protobuf service definitions live under `proto/`, with generated Go code in `proto/gen/api/v1/` (e.g., `memo_service.pb.go`, `user_service.pb.go`, etc.) and corresponding gRPC-Gateway files (`*.pb.gw.go`). The gRPC services are registered and served via Connect protocol handlers wired in `server/router/api/v1/v1.go` and `server/router/api/v1/connect_services.go`. The HTTP/JSON surface is provided by the gRPC-Gateway reverse proxy registered in `server/server.go`.
