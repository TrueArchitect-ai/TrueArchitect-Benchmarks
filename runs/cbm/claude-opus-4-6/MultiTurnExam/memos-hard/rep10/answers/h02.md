**Delivery function** — `Post` — `internal/webhook/webhook.go:120`

The `Post` function marshals the payload to JSON, constructs an HTTP POST request (optionally adding HMAC-SHA256 signatures), and sends it via the package-level `safeClient`. Asynchronous dispatch goes through `PostAsync` (line 184), which enqueues onto a buffered channel consumed by 4 worker goroutines (lines 42–55).

**Protection mechanism** — SSRF guard via `safeDialContext` — `internal/webhook/webhook.go:59`

The `safeClient` uses a custom `Transport` whose `DialContext` is `safeDialContext` (line 35). Before connecting, this function resolves the target hostname to IP addresses and checks each against `isReservedIP` (`internal/webhook/validate.go:44`), which tests membership in a compiled list of reserved/private CIDRs (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents — `internal/webhook/validate.go:14–23`). This blocks connections to internal network addresses at dial time, which also defeats DNS-rebinding attacks. A second layer of protection exists at webhook creation time via `ValidateURL` (`internal/webhook/validate.go:62`), which performs the same reserved-IP check when the URL is first registered.
