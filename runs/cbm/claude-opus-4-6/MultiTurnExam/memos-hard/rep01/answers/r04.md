The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutines are spawned in an `init()` function (`internal/webhook/webhook.go:42-55`) that range over this channel and call `Post()` for each payload. Webhooks are enqueued via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send to the channel (dropping the payload with a warning if the buffer is full). No external message broker is involved.
