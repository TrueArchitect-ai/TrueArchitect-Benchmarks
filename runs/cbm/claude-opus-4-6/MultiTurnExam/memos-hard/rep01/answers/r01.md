The question's premise is incorrect — there is no Redis connection in this codebase. The cache layer is purely **in-memory**, implemented as a `sync.Map`-backed cache in `store/cache/cache.go`. It uses no external store like Redis.

User entries are cached via `Store.userCache` (created in `store/store.go`) using the default `cache.Config` which applies a **10-minute TTL** (`store/cache/cache.go:59`, `DefaultTTL: 10 * time.Minute`). The cache is a simple in-process Go struct (`cache.Cache`) with a background cleanup goroutine — no network connections, no Redis, no external dependencies.
