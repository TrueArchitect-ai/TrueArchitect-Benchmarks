The question's premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (for REST/HTTP access).

The protobuf service definitions live under `proto/`, with generated Go code in `proto/gen/api/v1/` (e.g., `memo_service.pb.go`, `user_service.pb.go`, `auth_service.pb.go`). The API is exposed via two transports:

1. **Connect (gRPC-compatible)** — registered in `server/router/api/v1/connect_handler.go` using generated Connect service handlers from `proto/gen/api/v1/apiv1connect/`.
2. **gRPC-Gateway (REST/JSON)** — registered in `server/router/api/v1/v1.go` using generated gateway handlers from `proto/gen/api/v1/*.pb.gw.go`.

Additionally, a native **HTTP file server** (`server/router/fileserver/fileserver.go`) serves attachments and avatars outside the protobuf API surface.
