The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (REST). The proto definitions live under `proto/` (e.g., `proto/gen/api/v1/` contains the generated Go code for services like `memo_service.pb.go`, `user_service.pb.go`, `attachment_service.pb.go`, etc.). The gRPC-Gateway generates REST endpoints from the same proto definitions (`.pb.gw.go` files). The API is registered via `apiV1Service.RegisterGateway` at `server/server.go:88`, and the service implementations are in `server/router/api/v1/`.
