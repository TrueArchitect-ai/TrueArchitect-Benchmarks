The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) involved in webhook delivery. The webhook workers consume from a plain **Go buffered channel** declared in `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are started in an `init()` function (same file, lines 42–55) that range over this channel and call `webhook.Post` for each payload. Callers enqueue work via `webhook.PostAsync` (line 184), which performs a non-blocking send to the channel (dropping the event if the buffer is full). There is no external message broker anywhere in the codebase.
