The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain in-memory Go buffered channel, not an external message queue.

The "queue" is declared as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` in `internal/webhook/webhook.go:39`. Four goroutine workers are spawned in the package's `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel and call `Post()` for each payload. Producers enqueue work via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send on the channel and drops the payload with a warning log if the buffer is full. There is no external broker, no persistent queue, and no inter-process messaging involved.
