The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using Protocol Buffers (protobuf) and served via Connect/gRPC.

The protobuf service definitions live under `proto/`, with generated Go code in `proto/gen/api/v1/` (e.g., `memo_service.pb.go`, `user_service.pb.go`, `auth_service.pb.go`, etc.). The RPC services are registered as Connect handlers in `server/router/api/v1/connect_services.go` and wired into the HTTP server in `server/server.go`. Additionally, a traditional REST-style HTTP file server exists at `server/router/fileserver/fileserver.go` for serving attachments and avatars, and an RSS feed endpoint at `server/router/rss/rss.go`.
