**S3 Presign Runner** (`server/runner/s3presign/runner.go`) — this component keeps S3 presigned URLs for externally-stored attachments from going stale by periodically re-signing them.

- **Component:** `s3presign.Runner` — iterates over all S3-type attachments in batches, checks whether each presigned URL will expire within the next day (URLs are valid for 5 days; re-signing triggers when 4 days have elapsed), and generates a fresh presigned URL via `s3Client.PresignGetObject` (`server/runner/s3presign/runner.go:108`).
- **Schedule:** Every **12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`), plus one immediate run at startup (`RunOnce` at line 163).
- **Wiring site:** `server/server.go:153` — the method `startBackgroundRunners` creates the runner and launches it in a goroutine. This method is called during server startup at `server/server.go:129`.
