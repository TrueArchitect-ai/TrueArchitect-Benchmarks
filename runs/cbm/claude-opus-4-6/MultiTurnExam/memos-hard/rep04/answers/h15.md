Here are the distinct enforcement sites where memo visibility is checked/enforced:

1. **`checkMemoReadAccess`** (centralized access check for GetMemo/parent lookups) — `server/router/api/v1/memo_service.go:39` — enforces PRIVATE (creator-only) and non-PUBLIC (auth required) for `GetMemo` (line 356), parent memo access (line 367), and `ListMemoComments` (line 148 in `memo_service_comments.go`)

2. **`ListMemos` query-level visibility filter** — `server/router/api/v1/memo_service.go:218–226` — unauthenticated users see only PUBLIC; authenticated users see PUBLIC + PROTECTED + own; restricts at the SQL query level via `VisibilityList` and filter expressions

3. **`checkAttachmentAccess`** (file server attachment serving) — `server/router/fileserver/fileserver.go:674–701` — enforces visibility when serving attachment files: PUBLIC allowed only if instance allows anonymous access, PRIVATE restricted to creator or admin, with share-token fallback

4. **`ListMemoReactions` inline check** — `server/router/api/v1/reaction_service.go:30–41` — replicates visibility check: non-PUBLIC requires auth, PRIVATE restricted to creator or superuser

5. **`ListMemoAttachments` inline check** — `server/router/api/v1/memo_attachment_service.go:213–225` — same pattern: non-PUBLIC requires auth, PRIVATE restricted to creator or superuser

6. **`ListMemoRelations` query-level filter** — `server/router/api/v1/memo_relation_service.go:107–112` — filters related memos by visibility via SQL filter expression (PUBLIC only for anonymous, PUBLIC+PROTECTED+own for authenticated)

7. **`ListMemoComments` query-level filter** — `server/router/api/v1/memo_service_comments.go:157–161` — same query-level visibility filtering for comment listing

8. **RSS feed** — `server/router/rss/rss.go:90,141` — restricts feeds to `store.Public` memos only

9. **Frontend meta/SEO** — `server/router/frontend/frontend.go:150` — only renders Open Graph metadata for `store.Public` memos

10. **`CreateMemoComment` inline check** — `server/router/api/v1/memo_service_comments.go:41` — blocks commenting on PRIVATE memos unless the user is the creator or superuser
