The question's premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed via **gRPC-Gateway** (REST/JSON) and **Connect** protocol handlers.

The protobuf service definitions live under `proto/` (e.g., `proto/api/v1/` contains `.proto` files defining the API services), with generated Go code in `proto/gen/api/v1/`. The gRPC service implementations are in `server/router/api/v1/`. The gRPC-Gateway and Connect handlers are registered in `server/router/api/v1/v1.go` (the `RegisterGateway` method), providing HTTP/JSON access to the same API surface. Additionally, a native HTTP file-serving surface is registered in `server/router/fileserver/fileserver.go`, and an RSS feed is served from `server/router/rss/rss.go`.
