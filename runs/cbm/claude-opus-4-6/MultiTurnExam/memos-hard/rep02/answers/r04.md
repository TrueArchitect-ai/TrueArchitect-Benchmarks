The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel**, not an external message queue.

The queue is declared as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` at `internal/webhook/webhook.go:39`. Four goroutine workers are started in the package's `init()` function (`internal/webhook/webhook.go:42-55`) that range over this channel and call `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the payload with a warning if the channel is full.
