The question's premise is incorrect — there is no per-user API rate-limiting middleware in this codebase. A search for "rate limit," "ratelimit," "throttle," and "quota" across the entire server code yields no results. The server registers authentication/authorization middleware (`server/router/api/v1/authz.go`), CORS middleware (`server/cors.go`), and uses concurrency-limiting semaphores for resource-intensive operations like thumbnail generation (`server/router/fileserver/fileserver.go`), but no request rate limiting of any kind is implemented.
