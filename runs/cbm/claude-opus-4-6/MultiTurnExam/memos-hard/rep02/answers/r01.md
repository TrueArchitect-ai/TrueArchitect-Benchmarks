The question's premise is incorrect — there is no Redis connection in this codebase. The cache layer is entirely **in-memory**, implemented as a `sync.Map`-backed cache in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, or otherwise) anywhere in the project.

User entries use the **default cache configuration** (`store/cache/cache.go:57-64`), which sets a TTL of **10 minutes** (`DefaultTTL: 10 * time.Minute`). The user cache is created via `cache.NewDefault()` in `store/store.go`, and entries are set with `Set()` (`store/cache/cache.go:93`) which applies the default TTL. Cache entries expire passively on read (line 135) and are actively cleaned up every 5 minutes by a background goroutine (`CleanupInterval: 5 * time.Minute`, line 200).
