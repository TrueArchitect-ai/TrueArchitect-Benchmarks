Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct that all providers return.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete implementation, providing an OAuth 2 identity provider that handles token exchange (with optional PKCE) and user-info retrieval via configurable field mappings.
