**S3 Presign Runner** — every **12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27`) — wired into server startup at **`server/server.go:162`**

The `s3presign.Runner` periodically re-presigns S3 attachment URLs before they expire. It iterates over all S3-stored attachments in batches, checks whether each presigned URL will expire within the next day (presigned URLs last 5 days; it refreshes any older than 4 days), generates a fresh presigned URL via `s3Client.PresignGetObject`, and writes the new URL and timestamp back to the store (`server/runner/s3presign/runner.go:47-131`).

At startup (`server/server.go:162-171`), the server creates the runner, runs it once immediately (`RunOnce`), then launches it in a background goroutine where it ticks every 12 hours.
