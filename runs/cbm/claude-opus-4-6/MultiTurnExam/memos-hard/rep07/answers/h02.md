**Delivery function:** `Post` — `internal/webhook/webhook.go:120`. This is the function that marshals the payload, constructs the HTTP POST request, signs it (if a signing secret is configured), and sends it via `safeClient.Do`. Asynchronous dispatch goes through `PostAsync` (line 184), which enqueues onto a buffered channel consumed by 4 worker goroutines (lines 42–55).

**Protection mechanism:** SSRF protection via `safeDialContext` — `internal/webhook/webhook.go:59`. The `safeClient` HTTP client uses a custom `Transport` whose `DialContext` is `safeDialContext`. This function resolves the target hostname's DNS records and checks every resolved IP against `isReservedIP` (`internal/webhook/validate.go:44`), which matches against a list of reserved/private CIDRs (`internal/webhook/validate.go:14–23`) covering loopback, RFC-1918, link-local (including cloud IMDS 169.254.x.x), and IPv6 equivalents. This check happens at **dial time**, defeating DNS rebinding attacks. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same reserved-IP check at **webhook registration time** (called from `CreateUserWebhook` at `server/router/api/v1/user_service_webhooks.go:74`).
