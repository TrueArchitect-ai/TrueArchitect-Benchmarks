The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel**, declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four worker goroutines are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel, calling `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`) using a non-blocking `select` that drops the payload if the channel is full. The entire mechanism is in-process with no external message broker involved.
