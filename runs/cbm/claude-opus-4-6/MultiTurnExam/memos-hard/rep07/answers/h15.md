Memo visibility is enforced in at least these distinct sites:

1. **`checkMemoReadAccess`** (single-memo gRPC access guard) — `server/router/api/v1/memo_service.go:39` — blocks unauthenticated users from non-public memos and non-owners from private memos (used by `GetMemo`, `UpdateMemo`, `DeleteMemo`, etc.)

2. **`ListMemos` query-level filtering** — `server/router/api/v1/memo_service.go:218–226` — restricts the `VisibilityList` on the DB query: anonymous users see only `Public`; authenticated users viewing others' memos see `Public` + `Protected`; only the owner sees their own `Private` memos.

3. **`SSEClient.canReceive`** (SSE event delivery filter) — `server/router/api/v1/sse_hub.go:134` — private memo events are delivered only to the creator or admin.

4. **`checkAttachmentPermission`** (file server attachment access) — `server/router/fileserver/fileserver.go:650` — checks `memo.Visibility` at lines 677 and 699 to gate attachment downloads.

5. **`ListReactions` / `UpsertReaction`** (reaction service) — `server/router/api/v1/reaction_service.go:30–41` and `reaction_service.go:83` — checks memo visibility before allowing reactions.

6. **`ListMemoAttachments`** (memo attachment service) — `server/router/api/v1/memo_attachment_service.go:214–222` — enforces visibility before listing a memo's attachments.

7. **RSS feed** — `server/router/rss/rss.go:90,141` — queries only `Public` memos for feed generation.

8. **Frontend meta/SEO** — `server/router/frontend/frontend.go:150` — queries only `Public` memos for OpenGraph metadata.

9. **User stats** — `server/router/api/v1/user_service_stats.go:84,90,218,220` — filters visible memos by caller identity when computing stats.

10. **Attachment listing** — `server/router/api/v1/attachment_service.go:445,451` — enforces visibility when listing attachments.
