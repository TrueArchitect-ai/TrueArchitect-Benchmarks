The premise is incorrect — there is no Redis connection. The cache layer is entirely **in-process / in-memory**, implemented as `cache.Cache` in `store/cache/cache.go`. It uses a `sync.Map` with TTL-based expiration (lines 68–73), not Redis or any external store.

User entries use the **default cache configuration** (`cache.DefaultConfig()` at `store/cache/cache.go:57–64`), which sets a **10-minute TTL** (`DefaultTTL: 10 * time.Minute`), a 5-minute cleanup interval, and a 1000-item cap. The user cache is created via `cache.NewDefault()` in the `Store` constructor at `store/store.go`.
