The premise is incorrect — there is no nightly database-cleanup cron job. The `internal/scheduler` package exists but is never used by the server to schedule any database cleanup task. The only periodic background jobs that run are the S3 presign runner (every 12 hours, `server/runner/s3presign/runner.go`) and the in-memory cache cleanup (every 5 minutes, `store/cache/cache.go:59`). Neither is a database-cleanup job, and neither uses the cron scheduler. No scheduled database vacuuming, purging, or cleanup of any kind is configured.
