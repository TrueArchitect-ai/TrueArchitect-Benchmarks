The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **gRPC-Gateway** REST layer. The generated service definitions live under `proto/gen/api/v1/` (e.g., `proto/gen/api/v1/memo_service.pb.go`, `proto/gen/api/v1/memo_service_grpc.pb.go`, `proto/gen/api/v1/memo_service.pb.gw.go`). The RPC handlers are implemented in `server/router/api/v1/` (e.g., `server/router/api/v1/memo_service.go`, `server/router/api/v1/user_service.go`), and services are registered onto a Connect/gRPC mux in `server/router/api/v1/v1.go`.
