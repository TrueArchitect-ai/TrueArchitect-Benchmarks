There is no nightly database-cleanup cron job. The only scheduled background runner is the S3 presign runner (`server/runner/s3presign/runner.go`), which runs every 12 hours to refresh presigned URLs — not a database cleanup task. The only "cleanup" logic in the codebase is the in-memory cache eviction loop in `store/cache/cache.go` (which purges expired cache entries every 5 minutes), which is not a database operation.
