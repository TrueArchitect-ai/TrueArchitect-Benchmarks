The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase.

The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (for REST/HTTP). The `.proto` definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, etc.), and the generated Go code is in `proto/gen/api/v1/`. The gRPC-Gateway layer auto-generates REST endpoints from the proto service definitions (the `*.pb.gw.go` files), and Connect-RPC bindings are also generated (`proto/gen/api/v1/apiv1connect/`). The RPC handlers are implemented in `server/router/api/v1/`.
