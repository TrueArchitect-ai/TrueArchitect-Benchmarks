**web/src/connect.ts**

This file contains the ConnectRPC service client creation. The file imports `createClient` from `@connectrpc/connect` and uses it to create multiple service clients including:
- `instanceServiceClient`
- `authServiceClient`
- `userServiceClient`
- `memoServiceClient`
- `attachmentServiceClient`
- `aiServiceClient`
- `shortcutServiceClient`
- `identityProviderServiceClient`

All these clients are created using `createClient()` with a transport that has been configured with authentication interceptors and credentials.
