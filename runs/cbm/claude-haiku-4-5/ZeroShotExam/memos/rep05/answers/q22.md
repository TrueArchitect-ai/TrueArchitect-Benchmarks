When a memo is created, user webhooks are notified as follows:

**Dispatcher:** `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`

**Delivery Package:** `internal/webhook` (the `PostAsync` function enqueues the webhook for asynchronous delivery via the `Post` function)

**Signing Mechanism:** HMAC-SHA256 with base64 encoding. The signature scheme uses:
- A message ID (`webhook-id` header): `msg_` + UUID
- A Unix timestamp (`webhook-timestamp` header)
- An HMAC-SHA256 signature computed over `msgID.timestamp.` + request body JSON
- Signature sent in `webhook-signature` header as `v1,` + base64-encoded signature
