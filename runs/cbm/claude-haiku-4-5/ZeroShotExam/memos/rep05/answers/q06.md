**memo_relation**

This table stores links between one memo and another related memo. The schema shows it contains:
- `memo_id`: the ID of the source memo
- `related_memo_id`: the ID of the related memo
- `type`: the type of relation

The table is defined in `/bench/repo/store/migration/sqlite/0.13/00__memo_relation.sql` and also exists in the latest versions for PostgreSQL, MySQL, and SQLite.
