**Mechanism:** Go `embed.FS` (file embedding); **Path:** server/router/frontend/frontend.go (line 20-21)

The compiled React frontend from the `dist/` directory is embedded into the binary at compile time using the `//go:embed dist/*` directive (line 20), creating an `embed.FS` variable named `embeddedFiles`. This embedded filesystem is then served by the `Serve` method (line 41-61) using Echo's `middleware.Static` with the filesystem, and includes a SPA fallback middleware to route non-existent paths to `index.html` for client-side routing.
