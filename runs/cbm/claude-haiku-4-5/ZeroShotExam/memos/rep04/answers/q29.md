q29.

**Interceptor path:** `web/src/connect.ts:156-178` (`authInterceptor`)

**Token kinds:** Access tokens (JWT, short-lived 15 minutes), refresh tokens (JWT, long-lived 30 days, stored in cookies), and Personal Access Tokens (PATs, long-lived for programmatic access)

**Backend package path:** `server/auth` (specifically `server/auth/authenticator.go` contains the `Authenticator` type that validates tokens via `Authenticate()` method, which is invoked by the `AuthInterceptor` in `server/router/api/v1/connect_interceptors.go:213-215`)

The frontend `authInterceptor` extracts the access token via `getRequestToken()` and sets it as a Bearer token in the `Authorization` header using `setAuthorizationHeader()`. The backend validates these tokens through the `Authorizer.Authenticate()` method (from `server/router/api/v1/authz.go:44-46`), which delegates to the `Authenticator` package to validate access tokens (stateless), PATs (lookup + expiry check), or refresh tokens (database revocation check).
