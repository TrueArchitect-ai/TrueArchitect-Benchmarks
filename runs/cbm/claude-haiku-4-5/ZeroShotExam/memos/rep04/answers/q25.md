q25. **Engine**: CEL (Common Expression Language) engine via `cel-go` library
**Path**: `internal/filter/engine.go` (with supporting files: `render.go`, `schema.go`, `parser.go`, `helpers.go`)

**Mechanism**: Filter expressions are parsed as CEL syntax and validated against the memo schema in `schema.go`, normalized into a dialect-agnostic intermediate representation (IR) in `ir.go`, then rendered by `render.go` to SQL fragments with placeholder arguments tailored to each dialect (MySQL uses `?`, Postgres uses `$n`), which are appended to the WHERE clause via `filter.AppendConditions()` helper called by each database driver (mysql/postgres/sqlite memo.go:ListMemos).
