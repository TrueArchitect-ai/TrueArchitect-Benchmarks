The server uses **Server-Sent Events (SSE)** to push live events to browsers. The hub is implemented in **server/router/api/v1/sse_hub.go**, and the memo handlers that broadcast through it are:

1. **CreateMemo** - broadcasts SSEEventMemoCreated
2. **UpdateMemo** (via dispatchMemoUpdatedSideEffects) - broadcasts SSEEventMemoUpdated
3. **DeleteMemo** - broadcasts SSEEventMemoDeleted
4. **CreateMemoComment** - broadcasts SSEEventMemoCommentCreated
5. **UpsertMemoReaction** - broadcasts SSEEventReactionUpserted
6. **DeleteMemoReaction** - broadcasts SSEEventReactionDeleted

**Answer format:** SSE (Server-Sent Events); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment, UpsertMemoReaction, DeleteMemoReaction
