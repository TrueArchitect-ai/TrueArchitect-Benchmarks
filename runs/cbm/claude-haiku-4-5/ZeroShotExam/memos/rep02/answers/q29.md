**Interceptor path:** `web/src/connect.ts:156-178` (the `authInterceptor` function)

**Token kinds managed:** 
1. Access tokens (JWT, 15-minute lifetime) - stateless, validated by signature
2. Refresh tokens (JWT, 30-day lifetime, stored in `memos_refresh` cookie) - validated against database for revocation
3. Personal Access Tokens (PAT) - long-lived tokens for programmatic access

**Backend package path:** `server/auth` 

The backend validation happens in the `NewAuthInterceptor` at `server/router/api/v1/connect_interceptors.go:213-215`, which delegates to the `Authorizer.Authenticate()` method. The core token parsing and validation logic is in `server/auth/token.go` (which handles JWT parsing with `ParseAccessTokenV2` and `ParseRefreshToken`), and `server/auth/authenticator.go` (which provides the `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT` methods that validate tokens).
