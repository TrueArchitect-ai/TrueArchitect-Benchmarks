When a memo is created, user webhooks are notified through the following chain:

1. **Dispatcher function and file:** `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`
   - This function calls `dispatchMemoRelatedWebhook`, which retrieves user webhooks and dispatches them via `webhook.PostAsync()`

2. **Delivery package:** `internal/webhook` (specifically the `Post` and `PostAsync` functions)
   - The `PostAsync` function enqueues the webhook payload for asynchronous delivery by 4 concurrent workers

3. **Request-signing mechanism:** HMAC-SHA256 with Standard Webhooks format
   - Uses HMAC-SHA256 with the webhook's signing secret as the key
   - Creates headers: `webhook-id` (msg_<uuid>), `webhook-timestamp` (Unix timestamp), and `webhook-signature` (v1,<base64-encoded-signature>)
   - The signature is computed over the message ID, timestamp, and the JSON body, following the Standard Webhooks specification
