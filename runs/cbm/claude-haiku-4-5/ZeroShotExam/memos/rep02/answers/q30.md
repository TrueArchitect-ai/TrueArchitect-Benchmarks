**Memo lifecycle events that dispatch webhooks:**

- memos.memo.created: `DispatchMemoCreatedWebhook`
- memos.memo.updated: `DispatchMemoUpdatedWebhook`
- memos.memo.deleted: `DispatchMemoDeletedWebhook`
- memos.memo.comment.created: `DispatchMemoCommentCreatedWebhook`

**Delivery convergence:**

All webhook dispatches converge at `webhook.PostAsync()` (server/router/api/v1/memo_service_webhooks.go:71, 43), which enqueues payloads into an async queue. The queue is processed by 4 goroutines initialized in `webhook.init()` (internal/webhook/webhook.go:42-55), which call `webhook.Post()` (internal/webhook/webhook.go:120-180) for actual HTTP delivery.
