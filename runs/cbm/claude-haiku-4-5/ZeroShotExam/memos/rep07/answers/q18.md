The three implementations of the database driver interface are:

1. `store/db/sqlite/sqlite.go` — DB struct implementing the Driver interface via NewDB function
2. `store/db/mysql/mysql.go` — DB struct implementing the Driver interface via NewDB function
3. `store/db/postgres/postgres.go` — DB struct implementing the Driver interface via NewDB function

The factory function that selects between them at startup is:

**NewDBDriver** — `store/db/db.go`

This function takes a `profile.Profile` parameter and switches on `profile.Driver` to instantiate the appropriate database driver (sqlite, mysql, or postgres).
