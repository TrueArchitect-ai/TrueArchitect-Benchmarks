When a memo is created, user webhooks are notified through the following flow:

- **Dispatcher function and file**: `dispatchMemoRelatedWebhook()` — `server/router/api/v1/memo_service_webhooks.go` (line 48). This is called from `DispatchMemoCreatedWebhook()` (line 15-16) which is invoked from the handler `CreateMemo()` in `server/router/api/v1/memo_service.go` (line 157).

- **Delivery package**: `internal/webhook` — provides the `Post()` and `PostAsync()` functions that perform HTTP delivery (webhook.go, lines 120 and 184)

- **Request-signing mechanism**: HMAC-SHA256 with Standard Webhooks format (`whsec_` prefix). The signature is computed using the signing secret and included in request headers: `webhook-id`, `webhook-timestamp`, and `webhook-signature` (webhook.go, lines 133-150). The secret uses base64 encoding if prefixed with `whsec_`, otherwise used as raw bytes.
