**CEL (Common Expression Language)** parses the ListMemos filter expressions. The engine is implemented in **`internal/filter/engine.go`**. 

The mechanism: The filter string is compiled via CEL's parser into an AST, then converted to a dialect-agnostic condition tree (intermediate representation), and finally rendered to SQL by a dialect-aware renderer that produces parameterized statements for each of the three supported dialects (SQLite, MySQL, PostgreSQL).

Key files:
- **`internal/filter/engine.go:48-71`** — `Compile()` method parses CEL filter strings via `cel.Env.Compile()`
- **`internal/filter/parser.go`** — `buildCondition()` converts the CEL AST to an intermediate condition tree
- **`internal/filter/render.go:24-99`** — `renderer.Render()` converts conditions to dialect-specific SQL (DialectSQLite, DialectMySQL, DialectPostgres)
- **`internal/filter/schema.go:10-17`** — DialectName enum defining the three SQL dialects
- **`internal/filter/helpers.go:9-25`** — `AppendConditions()` called from store layer (e.g., `store/db/mysql/memo.go:71`) compiles filters and appends SQL fragments with placeholder-aware argument binding
