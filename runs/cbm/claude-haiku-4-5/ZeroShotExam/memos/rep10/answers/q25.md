**Engine + Path:** CEL (Common Expression Language) + `internal/filter/engine.go`

**Mechanism:** The filter expression is parsed by the CEL compiler (`github.com/google/cel-go/cel`) into an AST which is converted to a dialect-agnostic condition tree via `buildCondition()`, then rendered to dialect-specific SQL by the `renderer` type in `internal/filter/render.go` which handles MySQL, PostgreSQL, and SQLite differences through the `Dialect` parameter in `RenderOptions`.
