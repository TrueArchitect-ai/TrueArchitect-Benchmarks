**Mechanism:** Go's `embed` package with Echo middleware (`middleware.StaticWithConfig`)

**Path:** `server/router/frontend/frontend.go`

The compiled React frontend is served in production using:
1. **`embed` directive** (line 20): `//go:embed dist/*` embeds the compiled frontend files into the binary
2. **Echo static middleware** (line 54-57): `middleware.StaticWithConfig()` serves the embedded files with cache control headers
3. **SPA fallback** (line 59): A custom middleware that catches 404s and serves `index.html` for client-side routing

The frontend files are compiled into the `/server/router/frontend/dist/` directory and embedded directly into the Go binary at build time, eliminating the need for separate file serving infrastructure.
