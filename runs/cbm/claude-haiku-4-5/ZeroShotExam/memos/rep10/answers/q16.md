When a memo is deleted through the API, the store layer (`store/memo.go:140-159`) deletes the following records **before** deleting the memo row itself:

1. **memo_relation** records (where the memo is the source) - deleted via `DeleteMemoRelation(MemoID: &delete.ID)`
2. **memo_relation** records (where the memo is the target/related) - deleted via `DeleteMemoRelation(RelatedMemoID: &delete.ID)`
3. **attachments** - deleted via iterating through attachments linked to the memo and calling `DeleteAttachment()` for each one

After these cleanup operations complete, the memo row itself is deleted via `s.driver.DeleteMemo()`.
