**web/src/connect.ts**

This file contains all the ConnectRPC service clients created using the `createClient()` function from `@connectrpc/connect`. The clients are created for the following services:
- InstanceService
- AuthService  
- UserService
- MemoService
- AttachmentService
- AIService
- ShortcutService
- IdentityProviderService

All are exported and created with the same transport that includes authentication interceptors.
