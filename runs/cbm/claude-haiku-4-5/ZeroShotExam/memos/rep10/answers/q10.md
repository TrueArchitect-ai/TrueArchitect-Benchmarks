For a fresh SQLite install, the single file that provides the complete current schema is:

**store/migration/sqlite/LATEST.sql**

This file is used during the pre-migration phase (as shown in the `preMigrate` function at store/migrator.go:211-252) to initialize a new database with the complete schema in one transaction, which is faster than applying incremental migrations. The migration system comment at store/migrator.go:42 explicitly states: "LATEST.sql: Full schema for new installations (faster than incremental migrations)."
