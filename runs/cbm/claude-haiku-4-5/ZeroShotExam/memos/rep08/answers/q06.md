**memo_relation**

The `memo_relation` table stores links between one memo and another related memo. It has columns for `memo_id`, `related_memo_id`, and `type`. This can be seen in multiple database migration files:

- `store/migration/mysql/LATEST.sql` (lines 46-51)
- `store/migration/postgres/LATEST.sql` (lines 46-51)
- `store/migration/sqlite/LATEST.sql` (lines 46-51)
- `store/migration/sqlite/0.13/00__memo_relation.sql`

The table uses a composite unique constraint on `(memo_id, related_memo_id, type)` to ensure each relationship is stored only once.
