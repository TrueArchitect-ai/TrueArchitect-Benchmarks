When a memo is created, user webhooks are notified through the following flow:

1. **Dispatch function and handler file**: `DispatchMemoCreatedWebhook` — `/bench/repo/server/router/api/v1/memo_service_webhooks.go` (called from `CreateMemo` at line 157 in `memo_service.go`)

2. **Delivery package**: `internal/webhook` (specifically the `PostAsync` function in `/bench/repo/internal/webhook/webhook.go`)

3. **Request-signing mechanism**: HMAC-SHA256 with HTTP headers (`webhook-id`, `webhook-timestamp`, `webhook-signature`). The signature uses HMAC-SHA256 over a message constructed as `msgID.timestamp.` concatenated with the JSON body, encoded in base64, and sent as the header value `v1,<signature>`.
