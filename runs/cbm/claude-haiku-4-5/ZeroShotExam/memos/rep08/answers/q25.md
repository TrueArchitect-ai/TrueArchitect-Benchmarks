**Engine**: CEL (Common Expression Language) via `google/cel-go` library.

**Path**: `internal/filter/engine.go` and `internal/filter/render.go`

**Mechanism**: The filter expression is parsed by `Engine.Compile()` which uses the CEL environment to compile the filter string into an AST, then `buildCondition()` converts it to a dialect-agnostic condition tree; `Program.Render()` then generates dialect-specific SQL through `newRenderer()` which produces different SQL for each dialect (SQLite/PostgreSQL/MySQL) with appropriate placeholder handling and dialect-specific functions (e.g., `JSON_EXTRACT` vs PostgreSQL JSON operators, `strftime` vs `EXTRACT`, etc.).
