**Directly (database CASCADE delete):**

- `memo_relation` — explicitly deleted via `DeleteMemoRelation` calls for both `MemoID` and `RelatedMemoID` 
- `attachment` — explicitly deleted via `DeleteAttachment` for each attachment linked to the memo

**Directly via simple DELETE:**
- `memo` — the memo record itself is deleted

The primary deletion happens through the `Store.DeleteMemo()` wrapper function in store/memo.go, which:
1. Deletes all memo_relation records where the memo is either source or target
2. Deletes all attachments linked to the memo
3. Calls the driver's DeleteMemo to delete the memo row (which then triggers CASCADE delete for memo_share)
