The server uses Server-Sent Events (SSE) to push live events to browsers. The hub is implemented in `server/router/api/v1/sse_hub.go` with the `SSEHub` struct that manages client connections and broadcasts events. The memo handlers that call `SSEHub.Broadcast()` are: `CreateMemo`, `UpdateMemo` (indirectly through `dispatchMemoUpdatedSideEffects`), `DeleteMemo`, `CreateMemoComment`, `UpsertMemoReaction`, and `DeleteMemoReaction`.
