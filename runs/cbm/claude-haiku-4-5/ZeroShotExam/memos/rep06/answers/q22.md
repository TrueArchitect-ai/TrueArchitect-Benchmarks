When a memo is created, user webhooks are notified through the following chain:

1. **Dispatcher function and file**: `DispatchMemoCreatedWebhook` — called from the `CreateMemo` handler at `server/router/api/v1/memo_service.go:157`

2. **Delivery package**: `internal/webhook` — specifically the `PostAsync` function in `internal/webhook/webhook.go:184-196`

3. **Signing mechanism**: HMAC-SHA256 with Standard Webhooks format — uses `crypto/hmac` and `crypto/sha256` to create a signature. The signing follows the Standard Webhooks specification with headers:
   - `webhook-id`: A unique message ID (`msg_` + UUID)
   - `webhook-timestamp`: Unix timestamp
   - `webhook-signature`: `v1,` + base64-encoded HMAC-SHA256 signature

The signing key is resolved from a `whsec_<base64>` formatted signing secret using base64 decoding (or the raw secret if not in that format), as implemented in `resolveSigningKey` at `internal/webhook/webhook.go:97-106`.
