The server starts **1 background worker**:

- **s3presign runner** — time.Ticker every 12 hours (configured by `runnerInterval = time.Hour * 12` in server/runner/s3presign/runner.go:27). The runner also executes once on startup before entering the ticker loop (server/server.go:163).

**Unused scheduling infrastructure:**

The codebase contains a complete cron job scheduler implementation in `internal/scheduler/` (scheduler.go, parser.go, job.go, middleware.go) that supports GitHub Actions-style cron expressions, timezone-aware scheduling, and middleware patterns. This scheduler package is **never imported or used** by the server; it contains no integration with the actual background workers that run.
