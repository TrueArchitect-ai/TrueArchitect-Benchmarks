**Mechanism:** Go's `embed.FS` (embedding compiled React frontend files at build time) served via Echo middleware's `StaticWithConfig`

**Path:** `server/router/frontend/frontend.go`

The mechanism works as follows:
- Line 20-21: `//go:embed dist/*` directive embeds all files from the `dist/` directory (compiled React frontend) into the binary at build time as `embeddedFiles`
- Line 54-57: The `Serve` method uses Echo's `middleware.StaticWithConfig` with the embedded filesystem to serve static assets
- Line 72 in `server/server.go`: The `FrontendService` is instantiated and its `Serve` method is called to register the middleware that serves the embedded frontend files
