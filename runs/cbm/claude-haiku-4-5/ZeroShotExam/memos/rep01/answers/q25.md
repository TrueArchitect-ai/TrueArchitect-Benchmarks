**Engine + Path:** CEL (Common Expression Language) via `github.com/google/cel-go` in `/bench/repo/internal/filter/engine.go`

**Mechanism:** The Engine.Compile() method parses the filter string through CEL's environment to produce an AST, converts it to a proto expr, and builds a dialect-agnostic condition tree; the Engine.Render() method then traverses this tree through a renderer that outputs dialect-specific SQL fragments by calling AppendConditions(), which compiles each filter string via CompileToStatement() and accumulates SQL and parameterized args for MySQL, PostgreSQL, or SQLite.
