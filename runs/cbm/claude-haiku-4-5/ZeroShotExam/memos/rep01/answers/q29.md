**Token kinds managed:**
1. **Access Token** - Short-lived JWT (15 minutes) - sent in `Authorization: Bearer <token>` header for API requests
2. **Refresh Token** - Long-lived JWT (30 days) - stored in HTTP-only cookie (`memos_refresh`), used to obtain new access tokens
3. **Personal Access Token (PAT)** - Long-lived token with prefix `memos_pat_` for programmatic access

**Backend validation package:** `server/auth/` 

The backend `server/auth/token.go` package validates these tokens using JWT parsing functions like `ParseAccessTokenV2()` (lines 220-233) and `ParseRefreshToken()`. The package defines the token structures (`AccessTokenClaims`, `RefreshTokenClaims`) and validates them with issuer/audience claims and signature verification.
