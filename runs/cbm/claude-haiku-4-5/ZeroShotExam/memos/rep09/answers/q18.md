The three implementations of the database driver interface are:

1. **store/db/mysql/mysql.go** — implements DB struct (MySQL driver)
2. **store/db/postgres/postgres.go** — implements DB struct (PostgreSQL driver)
3. **store/db/sqlite/sqlite.go** — implements DB struct (SQLite driver)

The factory function that selects between them at startup is:

**NewDBDriver — store/db/db.go**

This function (lines 13-32 in store/db/db.go) uses a switch statement on `profile.Driver` to instantiate the appropriate driver implementation (sqlite.NewDB, mysql.NewDB, or postgres.NewDB).
