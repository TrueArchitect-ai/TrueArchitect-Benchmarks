When a memo is created, user webhooks are notified through the following mechanism:

- **Dispatcher function and file**: `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`
- **Delivery package**: `internal/webhook` (using the `PostAsync` function defined in `internal/webhook/webhook.go`)
- **Signing mechanism**: HMAC-SHA256 using the Standard Webhooks format with headers:
  - `webhook-id`: Message ID (format: `msg_<uuid>`)
  - `webhook-timestamp`: Unix timestamp
  - `webhook-signature`: Format `v1,<base64-encoded-signature>`

The signing key is derived from the signing secret using the Standard Webhooks convention (`whsec_<base64>` prefix is base64-decoded; otherwise used as-is).
