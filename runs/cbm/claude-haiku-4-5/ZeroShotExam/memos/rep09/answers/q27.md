**Mechanism:** Go `embed` package with `//go:embed` directive; **Path:** server/router/frontend/frontend.go

The compiled React frontend is embedded directly into the Go binary using Go's standard `embed` package. At line 20-21 of `server/router/frontend/frontend.go`, the `//go:embed dist/*` directive embeds all files from the `dist/` directory (where the compiled React build output lives) into the `embeddedFiles` variable. This embedded filesystem is then served through the Echo web framework via the `Serve` method, which uses Echo's `StaticWithConfig` middleware to serve the static assets and provides SPA fallback handling via the `spaFallbackMiddleware` function.
