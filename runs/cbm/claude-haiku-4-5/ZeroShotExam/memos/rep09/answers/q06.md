The table is **memo_relation**.

This table (defined in `/bench/repo/store/migration/postgres/LATEST.sql` at lines 45-51) stores the relationships between memos with the following schema:
- `memo_id`: the ID of the memo
- `related_memo_id`: the ID of the related/linked memo
- `type`: the type of relationship
- A unique constraint on (memo_id, related_memo_id, type)
