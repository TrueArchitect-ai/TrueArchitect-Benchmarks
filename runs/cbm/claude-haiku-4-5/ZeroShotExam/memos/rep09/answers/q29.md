**Interceptor path:** `web/src/connect.ts:156-178` — The `authInterceptor` function

**Token kinds:** Access tokens (short-lived JWT, 15 minutes expiry) and Personal Access Tokens (PATs) for programmatic access

**Backend package path:** `server/auth/` — Contains the `Authenticator` struct that validates tokens via `Authenticate()` method, `AuthenticateByAccessTokenV2()` for JWT validation, and `AuthenticateByPAT()` for PAT validation

The interceptor works by:
1. Calling `getRequestToken()` to get a valid access token from local state
2. Setting it as a Bearer token in the `Authorization` header
3. On 401 response, refreshing the token via `refreshAndGetAccessToken()` and retrying
4. The backend's `Authenticator.Authenticate()` method (server/auth/authenticator.go:213) extracts the Bearer token and validates it using either stateless JWT parsing (`AuthenticateByAccessTokenV2`) or database lookup for PATs.
