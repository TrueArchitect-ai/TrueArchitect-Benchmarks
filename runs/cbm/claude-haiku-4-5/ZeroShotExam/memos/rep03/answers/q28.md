The server starts ONE background worker:

s3presign runner — time.Ticker (every 12 hours)

Unused scheduling infrastructure:
The `internal/scheduler` package provides a GitHub Actions-inspired cron job scheduler with support for cron expressions, timezone awareness, middleware, and graceful shutdown, but it is not used by the server. The server only uses a simple time.Ticker for the s3presign runner's scheduling instead.
