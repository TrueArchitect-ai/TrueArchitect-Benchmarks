**Interceptor path:** `web/src/connect.ts` (frontend), `server/router/api/v1/connect_interceptors.go` (backend)

**Token kinds:** The authentication system manages three types of tokens:
1. **JWT Access Tokens** - Short-lived tokens (15 minutes) stored in memory for API access, identified by audience claim `user.access-token` 
2. **JWT Refresh Tokens** - Long-lived tokens (30 days) stored as HTTP-only cookies (name: `memos_refresh`) for obtaining new access tokens, identified by audience claim `user.refresh-token`
3. **Personal Access Tokens (PAT)** - Long-lived tokens for programmatic access with prefix `memos_pat_`

**Backend package path:** `server/auth/` (specifically: `authenticator.go` for validation, `token.go` for token parsing/generation, and supporting files)

The frontend auth interceptor (`web/src/connect.ts:156-178`) extracts and sets the Authorization header with Bearer tokens before each request. The backend interceptor (`server/router/api/v1/connect_interceptors.go:217-230`) validates tokens via the shared `Authorizer` which uses the `server/auth` package to parse and verify JWT tokens.
