**Actual mechanism:** The webhook delivery system uses a simple in-memory Go channel queue declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

This channel has a buffer size of 128. The init function (lines 42-55) spawns 4 worker goroutines that consume from this channel and dispatch webhooks via the `Post()` function. When `PostAsync()` is called (line 184), it attempts to send the payload to this channel, or drops the message if the queue is full.
