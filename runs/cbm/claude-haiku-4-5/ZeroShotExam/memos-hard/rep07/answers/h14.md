h14.

**Computation site:** `internal/markdown/markdown.go` - properties are extracted via `ExtractAll()` (which includes `ExtractProperties()` and `GenerateSnippet()`), and then populated into `store.Memo.Payload` via `server/runner/memopayload/runner.go:RebuildMemoPayload()`. The snippet is derived separately in `server/router/api/v1/memo_service_converter.go` during memo conversion for API responses.

**Triggers:** Metadata is recomputed on three operations:
1. **Memo creation** - `CreateMemo()` at `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload()`
2. **Memo update** - `UpdateMemo()` calls `RebuildMemoPayload()` 
3. **Background rebuild** - `RunOnce()` in `server/runner/memopayload/runner.go` batch-processes all memos (via a background runner) to rebuild their payloads
4. **Memo comment creation** - `CreateMemoComment()` triggers recomputation for the parent memo

**Extracted properties:** 
- `HasLink` (bool) - presence of links in content
- `HasTaskList` (bool) - presence of task checkboxes
- `HasCode` (bool) - presence of code blocks or code spans
- `HasIncompleteTasks` (bool) - presence of unchecked task checkboxes
- `Title` (string) - text extracted from first H1 heading if present
- `Snippet` (string) - plain text excerpt (max 64 chars) generated from content for preview display
- `Tags` (list) - tag references extracted from content (deduplicated, case-preserving)
