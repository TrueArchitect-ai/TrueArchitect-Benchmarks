**Premise correction:** This repository does not have a GraphQL schema. There is no GraphQL public API defined.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) with gRPC-Gateway. The main API schema files are located in:

- **`proto/api/v1/*.proto`** — The primary API definitions, including:
  - `memo_service.proto` — Memo CRUD operations
  - `user_service.proto` — User management
  - `attachment_service.proto` — Attachment handling
  - `auth_service.proto` — Authentication
  - `instance_service.proto` — Instance configuration
  - And others (ai_service, idp_service, shortcut_service)

- **`proto/gen/openapi.yaml`** — Generated OpenAPI 3.0 specification from the protobuf definitions

The API uses Protocol Buffers for schema definition and gRPC-Gateway for HTTP/REST exposure on `/api/v1/*` endpoints. This is not GraphQL—it's a protobuf-based RPC API with RESTful HTTP bindings as specified in the proto files themselves.
