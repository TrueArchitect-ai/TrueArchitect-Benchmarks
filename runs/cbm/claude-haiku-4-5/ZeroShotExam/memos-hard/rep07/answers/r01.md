**Premise correction:** There is no Redis connection for the cache layer. The system uses an in-memory cache, not Redis.

**Actual mechanism:** The cache layer is configured in `store/store.go:38-45` and `store/cache/cache.go`. The in-memory cache is initialized with:
- **User entries TTL:** `10 * time.Minute` (DefaultTTL set at store/store.go:41)
- **Cache configuration location:** `store/store.go:40-45` where `cacheConfig` is defined with:
  - DefaultTTL: 10 minutes
  - CleanupInterval: 5 minutes
  - MaxItems: 1000

The `userCache` instance (`store/store.go:52`) stores user entries and uses this default TTL. The cache implementation (`store/cache/cache.go:57-64`) defines the same defaults in `DefaultConfig()`.
