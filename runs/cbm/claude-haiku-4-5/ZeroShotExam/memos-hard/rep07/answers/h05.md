**Explicit Go code; two mechanisms:**

1. **Reactions on user's own memos** — Deleted by explicit Go code via `deleteReactionsByContentIDsTx()`: When a user is deleted, their memos are identified and their associated emoji reactions are removed by a SQL `DELETE FROM reaction WHERE content_id IN (...)` statement targeting the content IDs of those memos.

2. **Reactions created by the deleted user** — Deleted by explicit Go code via `deleteReactionsByCreatorTx()`: Any emoji reactions the deleted user created (on any memo) are removed by a SQL `DELETE FROM reaction WHERE creator_id = ?` statement.
