**Premise correction:** The repository does not have a GraphQL schema for a public API. The public API is defined using **Protocol Buffers (gRPC)**, not GraphQL.

**Actual API surface:** The public API is defined in `/bench/repo/proto/api/v1/` using Protocol Buffer files (`.proto`), with the following main service definitions:
- `memo_service.proto` — Memo operations
- `user_service.proto` — User operations
- `attachment_service.proto` — Attachment operations
- `instance_service.proto` — Instance configuration
- `auth_service.proto` — Authentication
- `idp_service.proto` — Identity provider
- `ai_service.proto` — AI operations
- `shortcut_service.proto` — Shortcuts
- `common.proto` — Common types

The generated Go code from these proto definitions is located in `/bench/repo/proto/gen/api/v1/`.
