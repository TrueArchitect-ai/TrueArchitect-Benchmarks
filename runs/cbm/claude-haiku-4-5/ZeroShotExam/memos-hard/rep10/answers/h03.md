The **abstraction package is `github.com/usememos/memos/internal/idp`** and the **concrete protocol implementation package is `github.com/usememos/memos/internal/idp/oauth2`**.

The abstraction is defined in `internal/idp/idp.go` (internal/idp package), which exports the `IdentityProviderUserInfo` struct. The concrete OAuth2 implementation is in `internal/idp/oauth2/oauth2.go`, which implements the `IdentityProvider` type with `ExchangeToken` and `UserInfo` methods that handle the OAuth2 protocol (visible in auth_service_sso.go:19-20 where it's used to authenticate third-party identity providers).
