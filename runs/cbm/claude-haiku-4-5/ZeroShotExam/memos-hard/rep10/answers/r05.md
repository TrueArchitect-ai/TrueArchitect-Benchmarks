**Premise correction:** This repository does not use GraphQL for its public API. Instead, it uses **Protocol Buffers (gRPC)**.

**Actual API surface:** The public API schema is defined in Protocol Buffer proto files located in `/bench/repo/proto/api/v1/`:

- `memo_service.proto` — Memo operations
- `user_service.proto` — User operations
- `attachment_service.proto` — Attachment operations
- `auth_service.proto` — Authentication
- `instance_service.proto` — Instance settings
- `shortcut_service.proto` — Shortcuts
- `idp_service.proto` — Identity providers
- `ai_service.proto` — AI services
- `common.proto` — Shared types

The API is built on gRPC/Connect-RPC, not GraphQL.
