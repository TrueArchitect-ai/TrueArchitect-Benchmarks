r05. There is no GraphQL schema in this repository for a public API. The public API is defined using Protocol Buffers (protobuf), not GraphQL.

**Premise correction:** This repository does not use GraphQL for its public API.

**Actual API surface:** The public API is defined in Protocol Buffer files located in `/bench/repo/proto/api/v1/` directory, which includes:
- `memo_service.proto` — Memo operations
- `user_service.proto` — User management  
- `auth_service.proto` — Authentication
- `attachment_service.proto` — Attachment handling
- `instance_service.proto` — Instance configuration
- `idp_service.proto` — Identity provider management
- `ai_service.proto` — AI integrations
- `shortcut_service.proto` — Shortcut management
- `common.proto` — Shared types

These proto files are compiled to generated gRPC/HTTP handlers (visible in `proto/gen/` and `server/router/api/v1/`).
