**Premise correction:** This repository does not have a GraphQL API. The public API is defined using **Protocol Buffers (gRPC/REST)**, not GraphQL.

**Actual API surface:** The public API schema is defined in Protocol Buffer files located in `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto`
- `user_service.proto`
- `auth_service.proto`
- `attachment_service.proto`
- `shortcut_service.proto`
- `instance_service.proto`
- `idp_service.proto`

These `.proto` files define the API contract using gRPC service definitions with REST endpoint mappings (via `google.api.http` annotations). The generated Go code from these proto definitions is in `proto/gen/api/v1/`.
