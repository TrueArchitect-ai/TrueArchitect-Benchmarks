**Delivery function:** The outbound HTTP delivery executes in the `Post` function at `internal/webhook/webhook.go:120-180`. This function marshals the webhook payload to JSON, creates an HTTP POST request, signs it with HMAC-SHA256 if a signing secret is configured, and sends it using a shared `safeClient` HTTP client.

**Protection mechanism:** The protection against internal network addresses is implemented through two layers:

1. **Runtime dial-time check:** `safeDialContext` function in `internal/webhook/webhook.go:59-77` intercepts all network connections. It resolves the hostname, checks each resolved IP address against `isReservedIP`, and blocks any connection to private/reserved IP ranges. This also defeats DNS rebinding attacks.

2. **Validation-time check:** `ValidateURL` function in `internal/webhook/validate.go:62-83` validates webhook URLs when they are created/updated. It resolves the hostname and verifies that no resolved IP falls within reserved/private ranges using the same `isReservedIP` helper function (defined at `internal/webhook/validate.go:44-54`).

The reserved IP ranges are checked via the `isReservedIP` function which iterates through a `reservedNetworks` list to determine if an IP falls within any reserved/private range (localhost, private subnets, link-local, multicast, etc.).
