**Premise correction:** This repository does not use GraphQL. The public API is defined using **Protocol Buffers (protobuf)**, not GraphQL.

**Actual API surface:** The GraphQL schema for the public API is not defined anywhere in this repository. Instead, the public API uses **Protocol Buffers (proto3)** organized in the `proto/api/v1/` directory:

- **Location:** `/bench/repo/proto/api/v1/`
- **Files:** 
  - `memo_service.proto` — Memo CRUD operations
  - `auth_service.proto` — Authentication services
  - `user_service.proto` — User management
  - `attachment_service.proto` — Attachment operations
  - `instance_service.proto` — Instance configuration
  - `ai_service.proto` — AI features
  - `idp_service.proto` — Identity provider operations
  - `shortcut_service.proto` — Shortcut management
  - `common.proto` — Shared enums and messages (State, Direction, PageToken)

The API is implemented using **Connect RPC** (a modern gRPC-compatible framework) with HTTP endpoints defined via Google API annotations (e.g., `option (google.api.http) = {post: "/api/v1/memos"}`).
