The webhook delivery workers consume from **neither NATS nor RabbitMQ**. Instead, they use an **in-memory Go channel**.

The queue is declared at line 39 in `/bench/repo/internal/webhook/webhook.go`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

The workers are spawned in the `init()` function (lines 42-55) of the same file, where 4 goroutines are created to consume from this channel and dispatch webhooks synchronously via HTTP POST. When `PostAsync()` is called, the webhook payload is enqueued to `asyncPostQueue` (line 190), and if the channel is full, the dispatch is dropped with a warning (lines 191-194).
