**This repository does not have a GraphQL schema for a public API.** The Memos project uses a **REST API and gRPC API** instead (as stated in the README: "full REST and gRPC APIs for integration").

The public API surface is defined in:
- **gRPC service definitions**: `/bench/repo/proto/api/v1/*.proto` files (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, etc.)
- **OpenAPI/REST specification**: `/bench/repo/proto/gen/openapi.yaml`

The proto files define the API service contracts using Protocol Buffers, not GraphQL. There is no GraphQL schema in this codebase.
