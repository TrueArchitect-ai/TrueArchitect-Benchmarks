**Premise correction:** This project does not use GraphQL for its public API. Instead, it uses Protocol Buffers (protobuf) with gRPC and REST bindings.

**Actual API surface:** The public API schema is defined in Protocol Buffer `.proto` files located in `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto` — Memo CRUD and relations operations
- `user_service.proto` — User and identity operations
- `attachment_service.proto` — File attachment operations
- `instance_service.proto` — Instance configuration
- `auth_service.proto` — Authentication operations
- `ai_service.proto` — AI transcription services
- `idp_service.proto` — Identity provider configuration
- `shortcut_service.proto` — Shortcut management
- `common.proto` — Shared message types

These proto files define services using the Google API Improvement Proposals (AIPs) guidelines, with HTTP REST bindings via `google.api.http` annotations (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`).
