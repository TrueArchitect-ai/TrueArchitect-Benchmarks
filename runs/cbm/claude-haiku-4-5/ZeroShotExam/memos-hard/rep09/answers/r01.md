**Premise correction:** The codebase does not use Redis for the cache layer. There is no Redis connection configured anywhere in the repository.

**Actual mechanism:** The cache layer is implemented as an in-memory cache using Go's `sync.Map` with TTL support. User entries are cached in `store/cache/cache.go` and configured in `store/store.go:38-61`.

**TTL for user entries:** User entries are cached with a default TTL of **10 minutes** (`DefaultTTL: 10 * time.Minute`), configured at `store/store.go:41`. This TTL applies to all three cache instances used by the Store:
- `userCache` (for user objects, accessed via `store.GetUser()` at `store/user.go:148-169`)
- `userSettingCache` (for user settings)
- `instanceSettingCache` (for instance settings)

The cache cleanup runs every 5 minutes to remove expired entries.
