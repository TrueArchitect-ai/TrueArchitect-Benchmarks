**This repository does not have a GraphQL schema.** The public API is defined using **Protocol Buffers (Proto)**, not GraphQL.

**Premise correction:** The question assumes GraphQL is used, but this project uses gRPC with Protocol Buffers.

**Actual API surface:** The public API schema is defined in Protocol Buffer files located in `/bench/repo/proto/api/v1/`, including:
- `memo_service.proto` — memo operations
- `user_service.proto` — user operations  
- `attachment_service.proto` — attachment operations
- `auth_service.proto` — authentication
- `instance_service.proto` — instance settings
- `idp_service.proto` — identity provider configuration
- `ai_service.proto` — AI service operations
- `shortcut_service.proto` — shortcut management

The API routes detected in the knowledge graph show gRPC services (e.g., `bench-repo.proto.gen.api.v1.MemoService/CreateMemoComment`), and HTTP routes like `/api/v1/memos` that are wired to these gRPC service handlers via Connect (a gRPC-HTTP bridge).
