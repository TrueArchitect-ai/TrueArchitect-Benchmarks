**Premise correction**: This repository does not use Redis for the cache layer. It uses an in-memory cache implementation.

**Actual mechanism**: The cache layer is configured in `store/store.go:38-61` in the `New()` function. The cache configuration for all caches (including the `userCache` for user entries) is defined as:

- **DefaultTTL**: 10 minutes
- **CleanupInterval**: 5 minutes  
- **MaxItems**: 1000

User entries specifically are cached using the in-memory `cache.Cache` implementation (defined in `store/cache/cache.go`). When users are created, updated, or retrieved, they are stored in `s.userCache` with the default TTL of **10 minutes** (as seen in `store/user.go:98`, `132`, `143`, `167`).

The actual TTL setting originates from `store/cache/cache.go:59` where `DefaultConfig()` returns `DefaultTTL: 10 * time.Minute`.
