**q27.** Go embed.FS (embedded filesystem); server/router/frontend/frontend.go

The compiled React frontend is embedded at build time using Go's `//go:embed dist/*` directive (line 20 in frontend.go), which embeds the built frontend files directly into the binary. The FrontendService then serves these embedded files via Echo middleware at runtime, with SPA fallback routing (index.html for unmapped paths) and proper cache headers.
