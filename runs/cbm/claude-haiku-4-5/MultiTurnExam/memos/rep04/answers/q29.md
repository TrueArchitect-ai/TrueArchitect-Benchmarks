**q29.** web/src/connect.ts; access token, refresh token; server/auth

The frontend auth interceptor (`authInterceptor` in web/src/connect.ts lines 156-178) manages:
1. **Access tokens** (stored in memory/localStorage, sent in Authorization header)
2. **Refresh tokens** (stored in HTTP cookies, used to get new access tokens)

The backend validates them via the `server/auth` package, specifically the `Authenticator` class in `server/auth/authenticator.go` which is used by the `Authorizer` in `server/router/api/v1/authz.go`.
