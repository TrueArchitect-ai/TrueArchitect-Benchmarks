The frontend authentication flow:
- **Interceptor**: `authInterceptor` in `/bench/repo/web/src/connect.ts` (line 156)
- **Token types managed**: 
  - **Access tokens** (JWT, 15-minute lifetime) - sent in Authorization header
  - **Refresh tokens** (JWT, 30-day lifetime) - stored as HTTP cookie `memos_refresh`
  - **Personal Access Tokens (PATs)** - long-lived tokens for programmatic access
- **Backend validation**: `server/auth` package (primarily `/bench/repo/server/auth/token.go` and `/bench/repo/server/auth/authenticator.go`)

The interceptor handles token refresh on 401 errors and retries the request with a new access token obtained from the refresh token.
