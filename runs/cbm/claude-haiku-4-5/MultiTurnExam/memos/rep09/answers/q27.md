Embedded filesystem (Go embed); server/router/frontend/frontend.go

The compiled React frontend is served in production using Go's `embed` package (line 20 in frontend.go: `//go:embed dist/*`), which embeds the pre-built frontend assets (HTML, CSS, JavaScript, etc.) directly into the binary at compile time. The `FrontendService.Serve()` method (lines 41-61) then uses Echo's `StaticWithConfig` middleware and a custom SPA fallback middleware to serve these embedded files as static assets, with appropriate cache headers for HTML files (no-cache) and hashed assets (max-age=3600, immutable). The service is wired into the main server at line 72 of `/bench/repo/server/server.go`.
