The mechanism is **Server-Sent Events (SSE)** - a push protocol that allows the server to send real-time updates to connected browsers via HTTP.

The SSE hub is implemented in `/bench/repo/server/router/api/v1/sse_hub.go` (lines 56-67), which manages client connections and broadcasts events to all subscribed clients.

The memo handlers that broadcast through the SSE hub are:

- **UpdateMemo** (indirectly via dispatchMemoUpdatedSideEffects in memo_update_helpers.go:71) - broadcasts SSEEventMemoUpdated
