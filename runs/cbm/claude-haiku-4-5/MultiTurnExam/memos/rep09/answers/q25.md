CEL (Common Expression Language) — internal/filter/engine.go; The filter engine parses CEL expressions into a dialect-agnostic intermediate representation (IR) and then renders it to SQL fragments with dialect-specific handling (SQLite uses `?` placeholders and `JSON_EXTRACT`, MySQL uses `$n` for Postgres, etc.) in render.go.

The complete architecture:
1. **Engine**: CEL (Common Expression Language) using `cel-go` library
2. **Location**: `internal/filter/` (README.md, engine.go, parser.go, ir.go, render.go)
3. **Mechanism**: Three-phase pipeline:
   - **Parsing** (parser.go): CEL expressions validated against memo schema (schema.go)
   - **Normalization** (ir.go): Converts CEL AST to dialect-agnostic IR
   - **Rendering** (render.go): Walks IR and produces SQL fragments tailored to target dialect (SQLite, MySQL, Postgres) with dialect-specific syntax (placeholders, JSON operators, time functions, etc.)
