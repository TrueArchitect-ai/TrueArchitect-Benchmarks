All three databases have the schema in their LATEST.sql files. Let me cite the SQLite one as it's the most portable and self-contained:

q23.
SQL schema: store/migration/sqlite/LATEST.sql
Go store model: store/memo.go
API proto message: proto/api/v1/memo_service.proto

The memo entity's shape is defined at:
- **SQL schema layer**: `store/migration/sqlite/LATEST.sql` (the `CREATE TABLE memo` definition is also in `store/migration/postgres/LATEST.sql` and similar files for other dialects)
- **Go store model layer**: `store/memo.go` (the `Memo` struct at line 29)
- **API proto message layer**: `proto/api/v1/memo_service.proto` (the `message Memo` at line 198)
- **Generated frontend types layer**: `web/src/types/proto/api/v1/memo_service_pb.ts` (TypeScript types generated from the proto definition)
