q27.
Go embed with Echo static middleware; server/server.go

In production, the compiled React frontend is served using:
- **Mechanism**: Go's `embed` package (line 20-21 of `server/router/frontend/frontend.go`) to embed the compiled `dist/` directory at compile time, then served via Echo's `middleware.StaticWithConfig()` static file middleware with SPA fallback routing (serving `index.html` for routes with no file extension)
- **Wiring file**: `server/server.go` (line 72) where `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` is called to register the frontend service with the Echo HTTP server
