CEL (Common Expression Language) — internal/filter/; The filter engine parses CEL expressions into an intermediate representation (IR) and renders it to dialect-specific SQL with proper placeholder handling for SQLite, MySQL, and PostgreSQL.

The ListMemos RPC filter uses:
- **Engine**: CEL (Common Expression Language) via the `cel-go` library
- **Location**: `internal/filter/` package (files: `engine.go`, `parser.go`, `render.go`, `schema.go`)
- **Mechanism**: A three-phase pipeline (parsing via `cel-go` → normalization to intermediate representation → rendering to dialect-specific SQL) that converts CEL expressions like `content.contains("hello")` into SQL WHERE clauses with appropriate placeholders (`?` for SQLite/MySQL, `$n` for PostgreSQL) and handles dialect-specific features like JSON access and boolean coercion.
