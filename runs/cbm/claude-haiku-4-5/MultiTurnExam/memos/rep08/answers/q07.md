web/src/connect.ts

The ConnectRPC service clients are created in `web/src/connect.ts`. This file imports all the service definitions and uses `createClient()` to instantiate clients for each service (instanceServiceClient, authServiceClient, userServiceClient, memoServiceClient, attachmentServiceClient, aiServiceClient, shortcutServiceClient, and identityProviderServiceClient) using a configured transport with authentication interceptors.
