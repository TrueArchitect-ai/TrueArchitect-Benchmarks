The frontend module `web/src/hooks/useMemoQueries.ts` contains all the memo CRUD mutations and queries (useMemos, useInfiniteMemos, useMemo, useCreateMemo, useUpdateMemo, useDeleteMemo, etc.) and uses the `memoServiceClient` service client, which is created from the `MemoService` in `web/src/connect.ts`.
