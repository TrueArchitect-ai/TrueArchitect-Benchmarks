q14.
Memo comments

When a memo is deleted through the API, the store layer (via the API handler) deletes **memo comments** before the memo row itself. Memo comments are memos that have a `MemoRelationComment` relation to the parent memo. The API handler explicitly iterates through all related memos with type `MemoRelationComment` (lines 569-577 in server/router/api/v1/memo_service.go) and calls `Store.DeleteMemo` for each one before deleting the parent memo itself. The remaining related records (attachments, memo_shares, reactions, etc.) are either handled through database CASCADE constraints or cleaned up implicitly through the recursive deletion of comments.
