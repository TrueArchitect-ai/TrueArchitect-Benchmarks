store/migration/sqlite/LATEST.sql

For a fresh SQLite install, the `LATEST.sql` file provides the complete current schema. This is documented in `/bench/repo/store/migrator.go:39` and used in the `preMigrate()` function at lines 210-246. When a database is not initialized, the system reads and applies the LATEST.sql file to set up the complete schema in one step, which is faster than applying incremental migrations.
