q06.
memo_relation

The table that stores links between one memo and another related memo is `memo_relation`, defined in `/bench/repo/store/migration/sqlite/LATEST.sql:47-52` (and similarly in the MySQL and PostgreSQL migration files). It contains:
- `memo_id` - the primary memo ID
- `related_memo_id` - the related memo ID
- `type` - the type of relation (e.g., REFERENCE, COMMENT)
