Go embed (//go:embed directive); server/router/frontend/frontend.go

The compiled React frontend is served in production using **Go's embed package** (`//go:embed dist/*` directive at line 20 in server/router/frontend/frontend.go). The compiled frontend files from the `dist/` directory are embedded directly into the binary at build time. 

The mechanism is wired in `server/router/frontend/frontend.go:41-61` where:
1. Embedded files are accessed via `embeddedFiles` 
2. Echo middleware is configured to serve static files from the embedded filesystem (line 54-57)
3. An SPA fallback middleware (line 59) serves `index.html` for client-side routing, ensuring all non-API routes return the HTML shell for the React app to handle

This approach eliminates the need to serve separate frontend files and includes the entire UI directly in the binary.
