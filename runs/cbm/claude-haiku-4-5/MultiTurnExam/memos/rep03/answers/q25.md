The ListMemos RPC filter expression uses:
1. **Engine**: CEL-Go (Google's Common Expression Language) - `internal/filter/engine.go:14-34`
2. **Mechanism**: The CEL filter string is parsed by the filter Engine into a dialect-agnostic condition tree (Condition), then the `CompileToStatement()` method (engine.go) renders it to dialect-specific SQL using `RenderOptions` with the appropriate `DialectName` (SQLite, MySQL, PostgreSQL), and finally `AppendConditions()` (helpers.go:9-25) applies the dialect-specific rendering to generate parametrized SQL with proper placeholder handling for each database driver.
