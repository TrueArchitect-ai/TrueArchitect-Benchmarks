The three implementations of the database driver interface are:
1. SQLite implementation in `store/db/sqlite/sqlite.go`
2. MySQL implementation in `store/db/mysql/mysql.go`
3. PostgreSQL implementation in `store/db/postgres/postgres.go`

The factory function `NewDBDriver` in `store/db/db.go` (lines 14-32) uses a switch statement on `profile.Driver` to select between the three implementations at startup, calling the appropriate `NewDB` function for each driver type.
