Frontend API requests are authenticated through:
1. **Auth Interceptor** - `web/src/connect.ts:156-178` - The `authInterceptor` intercepts all requests to add authorization headers
2. **Token Management** - Manages:
   - JWT access tokens (short-lived, 15 minutes) via `getAccessToken()` in `web/src/auth-state.ts`
   - Refresh tokens (long-lived, 30 days, stored in cookies) via refresh flow in `web/src/connect.ts:74-91`
   - Personal Access Tokens (PAT) for programmatic access
3. **Backend Validation** - `server/auth` package validates tokens:
   - `AuthenticateByAccessTokenV2()` for JWT access tokens (server/auth/authenticator.go:39-50)
   - `AuthenticateByPersonalAccessToken()` for PAT tokens
   - Token types defined in `server/auth/token.go:1-53`
