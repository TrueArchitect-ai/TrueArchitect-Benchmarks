q27.

Go `embed` package with static middleware; server/router/frontend/frontend.go

The compiled React frontend is served using Go's built-in `embed` package (`//go:embed dist/*` directive at line 20 of `server/router/frontend/frontend.go`), which embeds the pre-built frontend files at compile time. The FrontendService then serves these embedded files via Echo's StaticWithConfig middleware (line 54-57), with SPA fallback routing to index.html (line 59, 63-79), and is wired in `server/server.go` at line 72.
