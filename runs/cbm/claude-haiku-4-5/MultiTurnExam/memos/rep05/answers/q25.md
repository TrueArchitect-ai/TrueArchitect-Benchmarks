CEL (Common Expression Language) with cel-go engine — internal/filter/engine.go; Each dialect calls filter.AppendConditions() with its DialectName (DialectSQLite, DialectPostgres, DialectMySQL) to render the CEL AST into SQL WHERE clauses and args, with dialect-specific SQL rendering.

The ListMemos RPC's filter expression uses:
- **Engine**: CEL (Common Expression Language) parsed by Google's `cel-go` library
- **Location**: `internal/filter/engine.go` (houses the Engine that parses CEL into a dialect-agnostic condition tree)
- **SQL conversion mechanism**: Each dialect driver (store/db/{sqlite,postgres,mysql}/memo.go) calls `filter.AppendConditions()` with its specific `DialectName` parameter, which renders the condition tree into SQL WHERE clauses and bound arguments via `internal/filter/render.go`
