Frontend API requests are authenticated through:
- **Frontend auth interceptor**: `web/src/connect.ts` (line 156) — the `authInterceptor` implements token management for Connect requests
- **Token kinds managed**: access tokens (short-lived, 15 minutes), refresh tokens (long-lived, 30 days), and Personal Access Tokens/PAT (long-lived for programmatic access), as documented in `server/auth/token.go` (lines 8-10)
- **Backend validation package**: `server/auth` — provides JWT token generation, validation, and authentication via the Authenticator class
