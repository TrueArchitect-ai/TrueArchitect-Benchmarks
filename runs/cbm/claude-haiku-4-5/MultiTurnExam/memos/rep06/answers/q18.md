The three implementations of the database driver interface are:
1. **SQLite** — `/bench/repo/store/db/sqlite/sqlite.go`
2. **MySQL** — `/bench/repo/store/db/mysql/mysql.go`
3. **PostgreSQL** — `/bench/repo/store/db/postgres/postgres.go`

The factory function that selects between them at startup is `NewDBDriver` in `/bench/repo/store/db/db.go` (lines 14-32), which uses the `profile.Driver` field to determine which implementation to instantiate.
