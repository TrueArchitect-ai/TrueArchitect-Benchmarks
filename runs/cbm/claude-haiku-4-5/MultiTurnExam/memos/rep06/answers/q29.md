q29. web/src/connect.ts; access token, refresh token (also supports Personal Access Tokens in backend); server/auth

Frontend API requests get authenticated through:
1. **Interceptor location**: `web/src/connect.ts` (line 156: `const authInterceptor: Interceptor`)
2. **Token kinds managed**: 
   - Access token (JWT, short-lived, 15 minutes)
   - Refresh token (JWT, long-lived, 30 days)
   - Also supports Personal Access Tokens (PATs) on backend
3. **Backend validation package**: `server/auth` (server/auth/token.go documents the token types and server/auth/authenticator.go validates them)

The frontend manages tokens in `web/src/auth-state.ts` and applies them via the Connect interceptor in `web/src/connect.ts`, which sets the Authorization header and handles token refresh on 401 responses. The backend validates these tokens in the `server/auth` package.
