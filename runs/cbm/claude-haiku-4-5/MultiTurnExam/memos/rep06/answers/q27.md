q27. Go embed filesystem (`//go:embed dist/*`); server/router/frontend/frontend.go

The compiled React frontend is served in production using **Go's embed filesystem** mechanism:
- The frontend static files are embedded at compile time via the `//go:embed dist/*` directive in `/bench/repo/server/router/frontend/frontend.go` (line 20)
- The `FrontendService.Serve()` method uses Echo's StaticWithConfig middleware to serve the embedded files from the `dist/` directory
- It includes SPA fallback middleware to route non-existent paths to `index.html` for client-side routing
- The service is wired up in `/bench/repo/server/server.go` (line 72) where it's instantiated and serves to the Echo server
