The reaction table stores content_id as TEXT, which would be the memo name like "memos/123", so it's not a foreign key relationship with cascade delete. Reactions are NOT automatically deleted when a memo is deleted.

So the tables directly affected are:

1. **memo** - the memo itself is deleted
2. **memo_relation** - explicitly deleted (both as source and target)
3. **attachment** - explicitly deleted for all linked attachments
4. **memo_share** - deleted via CASCADE constraint on memo_id
