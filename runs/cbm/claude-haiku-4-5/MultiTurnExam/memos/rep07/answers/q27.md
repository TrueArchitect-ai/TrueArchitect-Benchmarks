The compiled React frontend is served in production using Go's **embed directive** (`//go:embed dist/*`) which embeds the precompiled frontend files (in `server/router/frontend/dist/`) into the binary at compile time. The embedded files are then served via Echo middleware using `middleware.StaticWithConfig` and a SPA fallback handler that serves `index.html` for client-side routing.
