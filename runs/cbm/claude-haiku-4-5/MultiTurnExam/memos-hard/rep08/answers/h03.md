**Abstraction package:** `internal/idp`; **Implementation package:** `internal/idp/oauth2`

The `internal/idp` package defines the provider abstraction through the `IdentityProviderUserInfo` struct (internal/idp/idp.go). The concrete implementation is `internal/idp/oauth2`, which provides the `IdentityProvider` type (internal/idp/oauth2/oauth2.go:19) that implements OAuth2 authentication with methods for token exchange (`ExchangeToken`) and user information retrieval (`UserInfo`).
