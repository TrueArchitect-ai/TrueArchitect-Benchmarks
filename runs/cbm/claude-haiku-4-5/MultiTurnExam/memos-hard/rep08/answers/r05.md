**Premise correction:** There is no GraphQL schema for a public API. The repository does not use GraphQL.

**Actual API surface:** The public API is built on **gRPC** with **Connect** protocol handlers and **gRPC-Gateway** (HTTP/JSON bridge), defined in:

1. **Proto definitions** — proto/api/v1/*.proto files defining the service interfaces:
   - proto/api/v1/memo_service.proto
   - proto/api/v1/user_service.proto
   - proto/api/v1/attachment_service.proto
   - proto/api/v1/instance_service.proto
   - proto/api/v1/auth_service.proto
   - proto/api/v1/ai_service.proto
   - proto/api/v1/idp_service.proto
   - proto/api/v1/shortcut_service.proto

2. **Service implementation** — server/router/api/v1/v1.go and associated service files

3. **API gateway registration** — server/router/api/v1/v1.go:64-90 (RegisterGateway method) which sets up both Connect handlers (connectrpc.com/connect) and gRPC-Gateway (grpc-ecosystem) for HTTP/JSON access to the underlying gRPC services.
