**Premise correction**: There is no nightly database-cleanup job scheduled in the cron scheduler. The question assumes a scheduled cleanup job exists, but it does not.

**Actual mechanism**: While the codebase includes a scheduler package (`internal/scheduler/`) with full support for cron-based job scheduling, no actual scheduled jobs are registered in the running server. The scheduler package provides the infrastructure for scheduling jobs (as documented in internal/scheduler/doc.go and demonstrated in internal/scheduler/example_test.go), but it is never instantiated or used in the server's startup code (server/server.go) or main function (cmd/memos/main.go).

There are only background runners that are started:
- S3 presign runner (server/runner/s3presign/runner.go) scheduled every 12 hours
- No cron-based scheduler jobs

Therefore, there is no nightly database cleanup or any other scheduled database maintenance job running on a cron schedule.
