**Premise correction**: There is no GraphQL schema for the public API. The question assumes GraphQL is used, but it is not.

**Actual API surface**: The public API is defined using gRPC protocol buffers (protobuf), which are compiled to both gRPC and REST/HTTP endpoints via gRPC-Gateway:

- **Location**: proto/api/v1/ directory contains all service definitions
- **Services defined**:
  - MemoService (proto/api/v1/memo_service.proto)
  - UserService (proto/api/v1/user_service.proto)
  - AttachmentService (proto/api/v1/attachment_service.proto)
  - AuthService (proto/api/v1/auth_service.proto)
  - InstanceService (proto/api/v1/instance_service.proto)
  - ShortcutService (proto/api/v1/shortcut_service.proto)
  - IdentityProviderService (proto/api/v1/idp_service.proto)
  - AIService (proto/api/v1/ai_service.proto)
  - Common types (proto/api/v1/common.proto)

The proto files use `google.api.http` annotations to define REST endpoints (e.g., proto/api/v1/memo_service.proto:22-26 defines `POST /api/v1/memos` for CreateMemo), making them accessible as both gRPC and JSON/REST APIs via gRPC-Gateway (registered at server/router/api/v1/v1.go:88-90).
