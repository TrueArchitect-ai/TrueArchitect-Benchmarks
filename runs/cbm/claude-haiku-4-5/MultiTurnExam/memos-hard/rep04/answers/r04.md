**Premise correction:** Neither NATS nor RabbitMQ is used. The webhook delivery workers do not consume from a message broker.

**Actual mechanism:** Webhook delivery uses an in-memory unbuffered channel queue (`internal/webhook/webhook.go:39`):

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in `init()` (`internal/webhook/webhook.go:42-55`) that consume from this channel. When `PostAsync()` is called, it enqueues the payload to this channel. If the queue is full (128 items), the dispatch is dropped with a warning rather than blocking.

The queue is declared in the same file where the workers run: `internal/webhook/webhook.go:39`.
