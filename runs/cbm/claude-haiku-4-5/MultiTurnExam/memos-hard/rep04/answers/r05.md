**Premise correction:** There is no GraphQL schema. The public API is not built with GraphQL.

**Actual API surface:** The public API is defined using Protocol Buffers (protobuf) with gRPC-Gateway HTTP bindings. The schema files are located in:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/ai_service.proto` — AI integrations
- `proto/api/v1/common.proto` — Shared types

These `.proto` files define RPC services with gRPC-Gateway HTTP method options (e.g., `option (google.api.http) = {post: "/api/v1/memos"}`), which expose the gRPC services as REST endpoints at `/api/v1/*`. The API is served via gRPC-Gateway, not GraphQL.
