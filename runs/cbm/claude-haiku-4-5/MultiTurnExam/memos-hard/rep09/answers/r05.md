**Premise correction:** The question assumes a GraphQL schema exists for the public API. It does not.

**Actual API surface:** The public API is defined using **Protocol Buffers (gRPC + gRPC-Gateway)**, not GraphQL. The service definitions are in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD and operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication (including SSO)
- `proto/api/v1/attachment_service.proto` — Attachment handling
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI/LLM integrations
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — Keyboard shortcuts
- `proto/api/v1/common.proto` — Shared types

The `.proto` files are compiled to Go code and exposed via gRPC-Gateway as REST/JSON endpoints. No GraphQL schema exists anywhere in the codebase.
