h03.

The provider abstraction is defined in the **`internal/idp`** package, which exports the `IdentityProviderUserInfo` struct that represents the user information returned by any identity provider.

The concrete protocol implementation that ships is **OAuth2**, implemented in the **`internal/idp/oauth2`** package, which provides the `IdentityProvider` type with methods for `ExchangeToken` and `UserInfo` operations. This is the only identity provider type currently supported in the server (see `auth_service_sso.go:120` where the type is checked against `storepb.IdentityProvider_OAUTH2`).

**Abstraction package:** `internal/idp`

**Implementation package:** `internal/idp/oauth2`
