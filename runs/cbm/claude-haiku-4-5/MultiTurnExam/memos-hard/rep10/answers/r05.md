**Premise correction:** There is no GraphQL schema for the public API. The repository does not use GraphQL.

**Actual API surface:** 
The public API is defined using **Protocol Buffers (protobuf)** with **gRPC and gRPC-Gateway (HTTP REST)**. The API schema is defined in the `proto/api/v1/` directory:

- `proto/api/v1/auth_service.proto` — Authentication and session management
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/memo_service.proto` — Memo/note operations
- `proto/api/v1/attachment_service.proto` — Attachment handling
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI/transcription services
- `proto/api/v1/shortcut_service.proto` — Shortcut management
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/common.proto` — Common message types

The gRPC services are exposed as REST endpoints via gRPC-Gateway (configured in `server/router/api/v1/v1.go:88-89`), allowing HTTP access to the gRPC API surface.
