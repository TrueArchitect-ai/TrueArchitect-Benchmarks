**Premise correction:** There is no Redis connection. The cache layer does not use Redis.

**Actual mechanism:** The cache layer uses an in-memory cache implemented in **store/cache/cache.go**. User entries are cached using `userCache` created in **store/store.go:52** with a default TTL of **10 minutes** (configured in **store/store.go:41**). The cache is initialized with `cache.Config{DefaultTTL: 10 * time.Minute, ...}` where all user data is stored in a thread-safe in-memory map with automatic TTL-based expiration and LRU eviction when the cache reaches its `MaxItems` limit of 1000.
