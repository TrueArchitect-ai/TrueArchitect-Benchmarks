**Premise correction + actual API surface:** There is no GraphQL schema for the public API. The Memos API is defined using Protocol Buffers (.proto files) located in **proto/api/v1/**, not GraphQL. The public API is exposed through two interfaces: (1) gRPC-Gateway HTTP handlers serving JSON+REST (generated from .proto definitions), and (2) Connect RPC handlers for browser clients. The service definitions are in **proto/api/v1/** with files like **proto/api/v1/memo_service.proto**, **proto/api/v1/user_service.proto**, **proto/api/v1/auth_service.proto**, etc. Generated outputs are created in **proto/gen/api/v1/** (Go) and **web/src/types/proto/** (TypeScript) when `buf generate` is run (**AGENTS.md:49**).
