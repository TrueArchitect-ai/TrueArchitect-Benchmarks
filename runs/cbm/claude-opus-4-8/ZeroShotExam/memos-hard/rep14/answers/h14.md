**Computation site**

The derived metadata is the memo's `Payload.Property` (plus `Payload.Tags`), computed in `RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`. That function delegates the actual extraction to the markdown service's single-pass `ExtractAll`, implemented at `internal/markdown/markdown.go:356` (which walks the goldmark AST). `RebuildMemoPayload` copies `data.Tags` and `data.Property` onto `memo.Payload` (`runner.go:85-86`).

**Triggers (what causes recomputation)**

- **Memo creation** — `CreateMemo` calls it at `server/router/api/v1/memo_service.go:108`.
- **Memo update** — `UpdateMemo` calls it at `server/router/api/v1/memo_service.go:447` (when the content is updated).
- **Batch rebuild for all memos** — the background runner's `RunOnce` iterates memos in batches of 100, calling `RebuildMemoPayload` then persisting via `UpdateMemo` (`server/runner/memopayload/runner.go:52-59`).

**Extracted properties**

From `ExtractAll` (`internal/markdown/markdown.go:356-421`), stored on `MemoPayload`:
- `Tags` — deduplicated `#tags` collected from tag nodes (`markdown.go:376-377`, deduped at `418`).
- `Property.Title` — text of the first block if it is an H1 heading (`markdown.go:383-388`).
- `Property.HasLink` — true if any link node is present (`markdown.go:393-394`).
- `Property.HasCode` — true for any code block, fenced code block, or inline code span (`markdown.go:396-397`).
- `Property.HasTaskList` — true if any task checkbox exists; `Property.HasIncompleteTasks` — true if any checkbox is unchecked (`markdown.go:399-405`).

(`ExtractAll` also gathers `Mentions`, but that field is not written into the memo payload by `RebuildMemoPayload`.)
