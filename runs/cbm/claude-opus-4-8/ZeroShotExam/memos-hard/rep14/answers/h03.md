The provider abstraction lives in the **`internal/idp`** package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type used across identity providers. The only concrete protocol implementation that ships is the **`internal/idp/oauth2`** package (`internal/idp/oauth2/oauth2.go`), whose header comment reads "Package oauth2 implements the OAuth2 identity provider integration" and which provides the `IdentityProvider` type built around `storepb.OAuth2Config`. It's also the sole subpackage under `internal/idp/`.

**Answer:** `internal/idp` (abstraction); `internal/idp/oauth2` (implementation)
