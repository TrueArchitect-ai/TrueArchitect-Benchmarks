   This is a `daily-cleanup` demonstrating the API — not a database-cleanup job, and not actually registered or run anywhere.

So if the intended reference is that doc example, its schedule string is `0 2 * * *` (2 AM daily) — but it is a hypothetical snippet in a comment, not an active scheduled job in the running system.
