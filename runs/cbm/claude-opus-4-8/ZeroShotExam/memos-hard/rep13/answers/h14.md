**Computation site**

The derived metadata is `Memo.Payload` (`MemoPayload.Tags` + `MemoPayload.Property`), computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual extraction to the goldmark markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`). `RebuildMemoPayload` walks nothing itself — it calls `markdownService.ExtractAll([]byte(memo.Content))` and copies `data.Tags` and `data.Property` onto the memo (`runner.go:80-87`).

**Triggers (operations that recompute it)**

1. **Memo creation** — `RebuildMemoPayload` on the new memo in `CreateMemo` (`server/router/api/v1/memo_service.go:108`).
2. **Memo content update** — in `UpdateMemo`, only in the `content` field branch, after assigning the new content (`server/router/api/v1/memo_service.go:447`). Other field updates (e.g. visibility) don't recompute it.
3. **Bulk rebuild-all** — the `Runner.RunOnce` migration/maintenance pass iterates every memo in batches of 100, rebuilds each payload, and persists via `UpdateMemo` (`server/runner/memopayload/runner.go:27-72`).

**Extracted properties** (from `ExtractAll`, a single AST walk — `internal/markdown/markdown.go:371-418`)

- `Payload.Tags` — deduplicated `#tag` nodes (case preserved).
- `Payload.Property.Title` — text of the first block-level child if it's an H1 heading (`markdown.go:384-388`).
- `Payload.Property.HasLink` — a link node exists (`markdown.go:393-394`).
- `Payload.Property.HasCode` — a code block, fenced code block, or code span exists (`markdown.go:396-397`).
- `Payload.Property.HasTaskList` — a task checkbox exists; and `HasIncompleteTasks` — true if any checkbox is unchecked (`markdown.go:399-405`).

(The service also has a separate `GenerateSnippet` at `markdown.go:264` used for list previews, but that's generated on read/conversion rather than stored in the payload.)
