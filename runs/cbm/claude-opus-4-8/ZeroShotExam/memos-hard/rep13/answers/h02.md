**delivery function** — `Post` in `internal/webhook/webhook.go:120` (the actual HTTP dispatch happens at `safeClient.Do(req)`, `webhook.go:152`). Callers reach it via `PostAsync`, which drains onto worker goroutines that call `Post`.

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, installed as the `DialContext` of the shared `safeClient` transport (`webhook.go:32-37`). It resolves the target host at dial time and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), which checks against the `reservedCIDRs` list (loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents — `validate.go:14-23`). Because the check runs at dial time on the actually-resolved IP, it also defeats DNS-rebinding.

Two supporting notes:
- A separate up-front check, `ValidateURL` (`internal/webhook/validate.go:62`), rejects bad URLs when a webhook is created/updated, but the dial-time guard is what protects the *delivery* itself.
- Both are bypassable by the `AllowPrivateIPs` toggle (`validate.go:41`), intended for self-hosted deployments targeting local services.
