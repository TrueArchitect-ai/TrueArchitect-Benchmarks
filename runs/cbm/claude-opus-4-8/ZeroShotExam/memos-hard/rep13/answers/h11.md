**1st: User (~6 packages); 2nd: Memo (~4 packages)**

The data layer is the `store` package (`store/`), where persistent entity types are defined as Go structs — `Memo` (`store/memo.go`), `User` (`store/user.go`), `Attachment`, `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `UserSetting`, `UserIdentity`, `IdentityProvider`, `InstanceSetting`.

Counting distinct Go packages **outside** the `store/` layer that reference each type (e.g. `store.User`, `store.Memo`, excluding the `store/db/*` drivers, which are part of the data layer):

- **`store.User`** — 6 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss` (5 if you drop the test package).
- **`store.Memo`** — 4 packages: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

All other entity types are referenced from at most ~3 outside packages (`Attachment` = 3; the rest ≤ 2). So `store.User` is the most widely referenced persistent entity type outside the data layer, followed by `store.Memo`.
