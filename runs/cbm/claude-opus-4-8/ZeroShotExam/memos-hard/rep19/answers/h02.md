**delivery function** — `Post` in `internal/webhook/webhook.go:120` (the actual HTTP request fires at `safeClient.Do(req)`, `webhook.go:152`; `PostAsync`/the queue workers at `webhook.go:184` and `webhook.go:42` just enqueue and call `Post`).

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (`webhook.go:32`). At dial time it resolves the host and rejects any address inside a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), whose blocklist (`reservedCIDRs`, `validate.go:14` — loopback, RFC-1918, link-local/IMDS `169.254.169.254`, and IPv6 equivalents) is the guard. Because the check happens at connection time on the resolved IP, it also defeats DNS-rebinding.

Note: there's also an earlier, best-effort check `ValidateURL` (`internal/webhook/validate.go:62`) run when a webhook URL is configured, but the dial-time `safeDialContext` is what actually protects each outbound delivery. Both can be disabled by the `AllowPrivateIPs` flag (`validate.go:41`) for local-network deployments.
