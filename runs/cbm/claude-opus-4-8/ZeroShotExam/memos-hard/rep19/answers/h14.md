**Extracted properties** (into `MemoPayload_Property`, `internal/markdown/markdown.go:383-405`):
- `Title` — text of the first block if it's an H1 heading (`extractHeadingText`).
- `HasLink` — true if any `KindLink` node exists.
- `HasCode` — true for any code block / fenced code block / code span.
- `HasTaskList` — true if any task checkbox is present.
- `HasIncompleteTasks` — true if any task checkbox is unchecked.
