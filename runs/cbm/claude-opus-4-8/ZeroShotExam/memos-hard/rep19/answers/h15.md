Memo view-visibility is enforced at several independent server surfaces. The distinct enforcement sites:

**Single-memo read access (gRPC/Connect API)** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`, lines 39–68; non-public memos require an authenticated user, and `PRIVATE` requires the caller to be the creator). Reused by `GetMemo` (line 356) and `ListMemoComments` (`server/router/api/v1/memo_service_comments.go:148`).

**Memo-list query filter (gRPC/Connect API)** — `server/router/api/v1/memo_service.go:218–227` (in `ListMemos`, anonymous callers get `VisibilityList = [PUBLIC]`; authenticated callers get their own memos plus `PUBLIC`/`PROTECTED`). The same list-scoping pattern is applied in `server/router/api/v1/user_service_stats.go:84–90, 218–220`.

**Store SQL layer (`VisibilityList` → WHERE clause)** — `store/db/sqlite/memo.go:96`, `store/db/postgres/memo.go:89`, `store/db/mysql/memo.go:104` (backs every list-based filter above).

**RSS feeds** — `server/router/rss/rss.go:90` (instance feed) and `:141` (per-user feed), both hard-restricted to `[PUBLIC]`.

**Frontend sitemap (SSR)** — `server/router/frontend/frontend.go:150`, restricted to `[PUBLIC]`.

**Attachment / file server** — `server/router/fileserver/fileserver.go:677–701` (serves an attachment only if its parent memo is `PUBLIC` + anonymous-allowed, a valid share token is presented, or the authenticated user is the creator/admin for `PRIVATE`).

Additional per-action surfaces that re-check the same memo-visibility rule before returning memo-derived data:
- **Reactions** — `server/router/api/v1/reaction_service.go:30,38,83`
- **Attachment listing/binding** — `server/router/api/v1/attachment_service.go:445,451` and `server/router/api/v1/memo_attachment_service.go:214,222`

The three primary/core view-enforcement sites are the API single-read check (`memo_service.go`), the API/store list-visibility filter (`memo_service.go` + `store/db/*/memo.go`), and the RSS feeds (`rss.go`), with the fileserver and sitemap as further independent surfaces.
