h03. `internal/idp` (Go import path `github.com/usememos/memos/internal/idp`); `internal/idp/oauth2` (`github.com/usememos/memos/internal/idp/oauth2`)

The `internal/idp` package defines the provider abstraction — `internal/idp/idp.go` declares the shared `IdentityProviderUserInfo` type consumed across implementations. The only concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2/oauth2.go`, whose doc comment reads "Package oauth2 implements the OAuth2 identity provider integration" and whose `IdentityProvider` type imports and depends on `internal/idp`.
