At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` — `internal/webhook/validate.go:44`, which checks the CIDR list in `internal/webhook/validate.go:14-23`. Because the check happens at connect time on the resolved IP, it also defeats DNS-rebinding.

Notes:
- There is an additional up-front, admission-time check `ValidateURL` — `internal/webhook/validate.go:62` — used when a webhook URL is configured/saved, but the guarantee at actual delivery is the dial-time guard in `safeDialContext`.
- Both protections can be disabled by the `AllowPrivateIPs` toggle (`internal/webhook/validate.go:41,45`) for self-hosted setups that intentionally target local services.
