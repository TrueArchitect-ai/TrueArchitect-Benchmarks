The **S3 presign runner** keeps attachment links from going stale. When an attachment is stored in external S3 storage, the `reference` field holds a presigned GET URL that expires (5-day expiration). The runner re-presigns these URLs before they expire so the links never go dead.

**Component** — `s3presign.Runner` (`server/runner/s3presign/runner.go`). Its `CheckAndPresign` loops over all S3-backed attachments and re-issues a presigned URL for any whose `LastPresignedTime` is older than 4 days (`server/runner/s3presign/runner.go:47-132`), updating the attachment's `Reference` (`runner.go:108-123`).

**Schedule** — every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:26-27`), driven by a `time.Ticker` in `Run` (`runner.go:29-41`). It also runs once immediately at startup via `RunOnce`.

**Wiring site** — `server/server.go:162-171`, inside `startBackgroundRunners`, which is itself invoked during server startup at `server/server.go:129`. It calls `RunOnce(ctx)` once eagerly, then launches `Run(s3Context)` in a background goroutine (with a cancelable context for clean shutdown).

**Answer:** `s3presign.Runner` (server/runner/s3presign/runner.go) — every 12 hours (plus one run at startup) — wired in `startBackgroundRunners` at server/server.go:162 (goroutine at server/server.go:169), which is called from server startup at server/server.go:129.
