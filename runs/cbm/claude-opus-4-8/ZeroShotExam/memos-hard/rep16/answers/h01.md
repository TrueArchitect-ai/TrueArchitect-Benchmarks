**S3 presign runner — every 12 hours (with an immediate run at boot) — wired at `server/server.go:162-169` (invoked from `Server.Start` via `startBackgroundRunners` at `server/server.go:129`).**

Details:

- **Component:** `s3presign.Runner`, defined in `server/runner/s3presign/runner.go`. Its `CheckAndPresign` method walks all attachments whose storage type is S3 (in batches of 100), regenerates a presigned GET URL via `s3Client.PresignGetObject`, and writes the fresh URL back with `Store.UpdateAttachment` (`server/runner/s3presign/runner.go:47-132`). Because S3 presigned URLs expire (set to 5 days), this is what keeps the stored links to externally-stored (S3) attachment content from going stale. It skips any attachment whose URL is still valid for the next 4 days (`runner.go:85-91`).

- **Schedule:** a `time.Ticker` at `runnerInterval = time.Hour * 12` — i.e. every 12 hours (`server/runner/s3presign/runner.go:27-41`). Additionally `RunOnce` is called synchronously once at startup so links are refreshed immediately (`server/server.go:163`).

- **Wiring site:** `server/server.go:162` constructs the runner and `server/server.go:169` launches the continuous loop in a background goroutine; this is inside `startBackgroundRunners`, which is called from `Server.Start` at `server/server.go:129`. Each runner gets its own cancelable context so it can be shut down independently (`server/server.go:156-159`).
