Details:

- **Outbound delivery executes** in `Post` (`internal/webhook/webhook.go:120`), where the actual HTTP send happens at `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). Delivery is triggered on content change via `PostAsync` (line 184), which enqueues onto `asyncPostQueue`; four worker goroutines started in `init` (lines 42–55) drain the queue and call `Post`.

- **SSRF protection** is the reserved/private-IP guard enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59`), which is wired into the shared `safeClient`'s `Transport.DialContext` (lines 32–37). It resolves the target host and rejects any address matched by `isReservedIP` (`internal/webhook/validate.go:44`), which checks against `reservedCIDRs` (loopback, RFC-1918 private, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents). Because the check runs on the resolved IP at connection time, it also defeats DNS-rebinding. There's also a pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62`), applied when a webhook URL is registered. Note the guard can be globally disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted setups.
