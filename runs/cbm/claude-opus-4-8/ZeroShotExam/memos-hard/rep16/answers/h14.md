**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates to the goldmark markdown service's `ExtractAll` method (`internal/markdown/markdown.go:356`). `ExtractAll` parses the memo content into an AST and does a single walk to populate `memo.Payload.Property` (and `Tags`). The runner assigns the result at `runner.go:85-86`.

**Triggers (recomputation):**
1. **Memo creation** — `CreateMemo` calls `RebuildMemoPayload` on the new memo (`server/router/api/v1/memo_service.go:108`).
2. **Memo content update** — in `UpdateMemo`, when the `content` field is updated, it reassigns `memo.Content` then calls `RebuildMemoPayload` (`server/router/api/v1/memo_service.go:446-447`).
3. **Batch rebuild of all memos** — the `Runner.RunOnce` job iterates memos in batches of 100 and calls `RebuildMemoPayload` + `UpdateMemo` on each (`server/runner/memopayload/runner.go:27-72`).

**Extracted properties** (into `MemoPayload_Property`, from the AST walk in `ExtractAll`, `markdown.go:383-408`):
- `Title` — text of the first block-level child if it is an H1 heading.
- `HasLink` — true if any `KindLink` node is present.
- `HasCode` — true if any code block, fenced code block, or code span is present.
- `HasTaskList` — true if any task checkbox is present.
- `HasIncompleteTasks` — true if any task checkbox is unchecked.

(The same pass also collects `Tags` and `Mentions`, but the derived per-memo `Property` metadata used for lists/previews is the set above.)
