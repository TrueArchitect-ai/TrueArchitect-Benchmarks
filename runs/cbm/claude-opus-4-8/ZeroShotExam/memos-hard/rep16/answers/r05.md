**Premise correction:** Memos does not have a GraphQL API, and there is no GraphQL schema anywhere in the repository. A full-repo search for `graphql`/`gql`/`apollo` returns zero matches. The premise of the question is incorrect.

**Actual API surface:** Memos exposes a **gRPC API with a REST/HTTP gateway**, defined via **Protocol Buffers (protobuf)**, not GraphQL.

- **Schema location:** The public API is defined in `.proto` files under `proto/api/v1/`:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - `proto/api/v1/shortcut_service.proto`
  - `proto/api/v1/instance_service.proto`
  - `proto/api/v1/idp_service.proto`
  - `proto/api/v1/ai_service.proto`
  - `proto/api/v1/common.proto`
- **Storage-layer protos** (internal, not the public API) live in `proto/store/`.
- **Generated code** is emitted to `proto/gen/api/v1/` and `proto/gen/store/`, configured by `proto/buf.yaml` and `proto/buf.gen.yaml`.
- **REST exposure:** Each RPC carries `google.api.http` annotations (e.g. `post: "/api/v1/memos"`, `get: "/api/v1/{name=memos/*}"` in `proto/api/v1/memo_service.proto`), and the repo depends on `github.com/grpc-ecosystem/grpc-gateway/v2` (`go.mod:17`) to serve those as a REST/JSON gateway over the `/api/v1/...` paths.

This matches the README, which advertises "full REST and gRPC APIs" — no GraphQL.
