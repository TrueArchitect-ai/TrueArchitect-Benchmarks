**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which sets `memo.Payload.Tags` and `memo.Payload.Property` by delegating to the markdown service's single-pass `ExtractAll` (`internal/markdown/markdown.go:356`). **Triggers (operations that recompute it):**
- Create — `server/router/api/v1/memo_service.go:108` (in `CreateMemo`, after the content-length check).
- Update — `server/router/api/v1/memo_service.go:447` (in the memo-update path, when `memo.Content` is being changed).
- Full backfill — `Runner.RunOnce` at `server/runner/memopayload/runner.go:27`, which batches through all memos (100 at a time) calling `RebuildMemoPayload` + `UpdateMemo` to rebuild every memo's payload (migration/rebuild).

**Extracted properties (from `ExtractAll`, `internal/markdown/markdown.go:356–420`):** a single AST walk collects:
- `Tags` — all `#tag` nodes, deduplicated with original case preserved (`uniquePreserveCase`).
- `Property.Title` — text of the H1 heading only if it is the document's first block-level child.
- `Property.HasLink` — true if any link node exists.
- `Property.HasCode` — true for any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(Note: `Mentions` is also gathered in `ExtractAll`, but `RebuildMemoPayload` only copies `Tags` and `Property` into the memo payload. The plain-text `GenerateSnippet` used for previews is a separate helper — `internal/markdown/markdown.go:264` — computed at read/convert time rather than stored in the payload.)
