Details:

- **Component:** `s3presign.Runner` in `server/runner/s3presign/runner.go`. Its `CheckAndPresign` walks attachments backed by S3, and for any whose presigned URL is nearing expiry it re-presigns and updates the stored reference. It skips objects whose `LastPresignedTime` is still valid for the next 4 days (`server/runner/s3presign/runner.go:85-88`) and regenerates via `s3Client.PresignGetObject` (`runner.go:108`), stamping a fresh `LastPresignedTime` (`runner.go:115-118`). This keeps the links to externally (S3) stored attachment content from going stale.

- **Schedule:** every 12 hours, defined by `const runnerInterval = time.Hour * 12` and driven by a `time.NewTicker` loop in `Run` (`server/runner/s3presign/runner.go:26-41`). It also runs once immediately at boot via `RunOnce`.

- **Wiring site:** `server/server.go:162` creates the runner (`s3presign.NewRunner(s.Store)`), `server/server.go:163` runs it once synchronously at startup, and `server/server.go:166-171` launches the continuous `Run` loop in a background goroutine (tracked by `s.backgroundRunnerWG`, cancellable via the S3 context set up just above).
