**Handlers (all `APIV1Service` gRPC methods) that can transitively trigger an outbound HTTP request to a user-configured webhook URL:**

- `CreateMemo` — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
- `DeleteMemo` — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
- `UpdateMemo` — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

Each `Dispatch…Webhook` method loads the target's webhooks via `s.Store.GetUserWebhooks(...)` and sets `payload.URL = hook.Url` — the URL a user configured through `CreateUserWebhook` (`server/router/api/v1/user_service_webhooks.go:53`, field validated at `:71`). It then calls `webhook.PostAsync`, which enqueues onto `asyncPostQueue`; four worker goroutines drain that queue and call `Post`.

**Convergence function — delivery:** `webhook.Post` at `internal/webhook/webhook.go:120`. This is the single point where every path converges before the actual outbound request is sent (`safeClient.Do(req)` at `internal/webhook/webhook.go:152`). (The common synchronous fan-in just upstream is `webhook.PostAsync` at `internal/webhook/webhook.go:184`, which merely enqueues; `Post` performs the delivery.)
