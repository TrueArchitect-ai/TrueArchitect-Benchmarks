**Computation site**

- `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` is the entry point. It calls `markdownService.ExtractAll([]byte(memo.Content))` and assigns the results to the memo's payload: `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`runner.go:85-86`).
- The actual extraction happens in the goldmark-based markdown service: `service.ExtractAll` in `internal/markdown/markdown.go:356`, which parses the content into an AST and does a single `gast.Walk` over it (`markdown.go:371-411`).

**Triggers (recomputation)**

- **Memo create:** `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` on the create object before `CreateMemo`.
- **Memo update, when the `content` field is in the update mask:** `server/router/api/v1/memo_service.go:436-451` — on `path == "content"` it sets `memo.Content`, calls `RebuildMemoPayload` (line 447), and writes `update.Payload = memo.Payload`.
- **Backfill/migration runner:** `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` walks all memos in batches of 100 and rebuilds the payload for each (`runner.go:52-62`), used to recompute payloads across the whole store.

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go`, into `ExtractedData` / `storepb.MemoPayload_Property`):

- `Tags` — all `#tag` nodes, deduplicated preserving case (`markdown.go:377,418`).
- `Property.Title` — text of the first block-level child if it is an H1 heading (`markdown.go:384-388`).
- `Property.HasLink` — true if any link node is present (`markdown.go:393-394`).
- `Property.HasCode` — true for code block/fenced code/code span (`markdown.go:396-397`).
- `Property.HasTaskList` — true if any task checkbox exists (`markdown.go:399-400`).
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked (`markdown.go:401-404`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only copies `Tags` and `Property` into the memo payload.)
