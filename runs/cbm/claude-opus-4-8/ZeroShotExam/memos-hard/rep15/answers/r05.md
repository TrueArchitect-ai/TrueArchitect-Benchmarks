**Premise correction:** This repository (Memos) has **no GraphQL schema and no GraphQL API**. A repo-wide search for `graphql` (case-insensitive, across `.ts/.js/.go/.py/.json/.graphql`) returns zero matches. The README itself states the project exposes "full REST and gRPC APIs" — there is no GraphQL layer to point to.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC)**, with REST exposed via gRPC-gateway and an embedded OpenAPI document — not GraphQL. The service/schema definitions live in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto`

Supporting build/config: `proto/buf.yaml`, `proto/buf.gen.yaml`, generated code under `proto/gen/`, and an embedded OpenAPI/REST descriptor via `proto/openapi_embed.go`. So the closest equivalent to "the public API schema" is the set of `.proto` files in `proto/api/v1/`, consumed as gRPC + REST — not GraphQL.
