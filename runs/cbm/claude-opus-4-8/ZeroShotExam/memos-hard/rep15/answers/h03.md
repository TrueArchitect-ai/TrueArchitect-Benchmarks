The `internal/idp` package defines the identity-provider abstraction, and the only concrete protocol implementation that ships is `internal/idp/oauth2` (OAuth2).

- `internal/idp/idp.go` — defines the provider abstraction, the shared `IdentityProviderUserInfo` struct returned by any provider.
- `internal/idp/oauth2/oauth2.go` — the sole concrete implementation ("Package oauth2 implements the OAuth2 identity provider integration"), with `IdentityProvider` built from a `storepb.OAuth2Config`. It is the only subpackage under `internal/idp`.

Answer: `internal/idp`; `internal/idp/oauth2`
