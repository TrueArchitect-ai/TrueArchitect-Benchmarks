h13. impl — construction — holders

**Interface:** `markdown.Service` — defined at `internal/markdown/markdown.go:31`.

**impl:** A single concrete implementation, the unexported `*service` struct (`internal/markdown/markdown.go:57-60`), which wraps a `goldmark.Markdown`. Its methods delegate: `RenderHTML` uses goldmark's built-in HTML converter (`markdown.go:255-261`), while `RenderMarkdown`/`RenameTag` delegate to `renderer.MarkdownRenderer` (constructed inline via `renderer.NewMarkdownRenderer()`, `markdown.go:250-251, 451-452`). The rest walk the goldmark AST directly.

**construction:** Built by the factory `markdown.NewService(...)` (`internal/markdown/markdown.go:85`). At runtime it's constructed once in `NewAPIV1Service` with the tag + mention extensions enabled:
```go
markdownService := markdown.NewService(
    markdown.WithTagExtension(),
    markdown.WithMentionExtension(),
)
```
`server/router/api/v1/v1.go:48-51`. (Tests construct it separately at `server/router/api/v1/test/test_helper.go:44`.)
