**1st: `store.User`; 2nd: `store.Memo`** (User ≈7 external packages, Memo ≈6).

The data layer is the `store` package (`/bench/repo/store/`), where the persistent entity types are defined (`store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, etc.). Counting distinct Go packages *outside* `store/` that reference each `store.<Type>`:

**`User`** (7 packages) — `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`

**`Memo`** (6 packages) — `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

The ranking is stable regardless of whether the in-layer DB-driver subpackages (`store/db/mysql`, `store/db/postgres`, `store/db/sqlite`, `store/test`) are counted: including them the totals are User = 11 and Memo = 10, still User first and Memo second. Every other entity type (`Attachment` next at ~4) trails well behind.
