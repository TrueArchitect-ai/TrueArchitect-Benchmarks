h03.

Users authenticate through third-party identity providers via the `internal/idp` package, which defines the provider abstraction, and the only concrete protocol implementation that ships is OAuth2 in `internal/idp/oauth2`.

- `internal/idp/idp.go` defines the shared abstraction — the `idp.IdentityProviderUserInfo` type (identifier, display name, email, avatar URL) that all providers normalize user info into.
- `internal/idp/oauth2/oauth2.go` is the single concrete implementation. Its package comment reads `// Package oauth2 implements the OAuth2 identity provider integration.`, and it provides `NewIdentityProvider(config *storepb.OAuth2Config)` — the only subpackage under `internal/idp`.

Answer: `internal/idp` (abstraction package); `internal/idp/oauth2` (implementation package)
