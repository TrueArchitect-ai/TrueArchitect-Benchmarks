**delivery function** — `Post` in `internal/webhook/webhook.go:120` (line 152 `safeClient.Do(req)` is where the HTTP POST is actually sent). Async dispatch flows through `PostAsync` → the `asyncPostQueue` worker goroutines (`internal/webhook/webhook.go:184` and `:42`), which call `Post`.

**protection mechanism** — `safeDialContext`, installed as the `DialContext` of the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37` and `:59-77`). It resolves the target host and rejects any resolved address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`, using the `reservedCIDRs`/`reservedNetworks` list at `internal/webhook/validate.go:14`). Because the check happens at dial time on the actually-resolved IPs, it also defeats DNS-rebinding.

Notes:
- There is also an up-front check, `ValidateURL` (`internal/webhook/validate.go:62`), run when a webhook URL is created/updated, but the dial-time guard is what protects the outbound delivery itself.
- The guard can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`, short-circuits `isReservedIP`), intended for self-hosted deployments targeting local services.
