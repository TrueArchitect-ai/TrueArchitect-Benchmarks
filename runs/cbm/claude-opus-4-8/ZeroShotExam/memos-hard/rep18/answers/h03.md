h03.

Users authenticate through third-party identity providers via the `internal/idp` package, which defines the provider abstraction, and the concrete implementation that ships is the OAuth2 provider in `internal/idp/oauth2`.

- `internal/idp/idp.go` — the abstraction package `idp`, defining the shared `IdentityProviderUserInfo` struct used across identity providers.
- `internal/idp/oauth2/oauth2.go` — the only concrete implementation (`// Package oauth2 implements the OAuth2 identity provider integration.`), providing `IdentityProvider` backed by `golang.org/x/oauth2` and `storepb.OAuth2Config`. It's the sole subpackage under `internal/idp`.

Answer: `internal/idp` (package `idp`); `internal/idp/oauth2` (package `oauth2`)
