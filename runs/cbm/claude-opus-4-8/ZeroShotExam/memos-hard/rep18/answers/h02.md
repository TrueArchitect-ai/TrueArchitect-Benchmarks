**delivery function** — `Post` in `internal/webhook/webhook.go:120` (the actual `safeClient.Do(req)` HTTP send is at `internal/webhook/webhook.go:152`). It's driven by `PostAsync` → a bounded async queue whose workers call `Post` (`internal/webhook/webhook.go:184`, `:42`).

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (`internal/webhook/webhook.go:32`). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), checking against the `reservedCIDRs` list — loopback, RFC-1918, link-local/IMDS 169.254.0.0/16, and IPv6 equivalents (`internal/webhook/validate.go:14`). Because the check runs at connection time (post-DNS-resolution), it also defeats DNS-rebinding.

Note two supporting details:
- A pre-flight `ValidateURL` (`internal/webhook/validate.go:62`) also blocks private/reserved IPs when a webhook URL is first configured, but that's a TOCTOU-safe secondary layer — the dial-time guard is what actually protects each delivery.
- The guard can be globally disabled via `AllowPrivateIPs` (`internal/webhook/validate.go:41`) for self-hosted deployments targeting local services.
