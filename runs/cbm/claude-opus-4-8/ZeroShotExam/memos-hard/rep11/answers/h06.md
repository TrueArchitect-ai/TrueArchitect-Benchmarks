**Handlers (RPC methods) that can transitively trigger an outbound HTTP request to a user-configured webhook URL:**

- `CreateMemo` — `server/router/api/v1/memo_service.go:70` → `DispatchMemoCreatedWebhook` (`memo_service.go:157`)
- `DeleteMemo` — `server/router/api/v1/memo_service.go:518` → `DispatchMemoDeletedWebhook` (`memo_service.go:562`)
- `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:20` → `DispatchMemoCommentCreatedWebhook` (`memo_service_comments.go:119`)
- `UpdateMemo` — `server/router/api/v1/memo_service.go` → `dispatchMemoUpdatedSideEffects` (`memo_update_helpers.go:66`) → `DispatchMemoUpdatedWebhook`
- `SetMemoRelations` — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- `SetMemoAttachments` — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

Each `Dispatch*` function loads the user's registered webhooks via `s.Store.GetUserWebhooks(...)` and sets `payload.URL = hook.Url` (the user-configured URL), then calls `webhook.PostAsync`.

**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`.**

All handler paths funnel into `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the background worker goroutines (started in `init`) then call `Post`, which builds the request and performs the actual outbound delivery via `safeClient.Do(req)` (`webhook.go:152`). So `Post` is the single point where every path converges immediately before the HTTP request is sent (with `PostAsync` being the shared synchronous entry point just upstream).
