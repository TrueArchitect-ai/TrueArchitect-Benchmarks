Searching all non-test Go files for imports of `internal/scheduler`, calls to `scheduler.New`, `.Register(&scheduler.Job{...})`, etc. returns nothing outside the package itself and its tests. The server (`server/server.go`) never instantiates or starts a scheduler, so no jobs — cleanup or otherwise — are actually scheduled.

Where the "nightly database-cleanup" idea likely comes from:

- The package's doc comment contains an **illustrative example** of a job named `"daily-cleanup"` with schedule `"0 2 * * *"` (i.e., 2 AM daily) — see `internal/scheduler/doc.go:15-21`. This is documentation sample code, not a real registered job, and its handler is an empty stub (`// Your cleanup logic here`). It does not touch the database.

So if the intended answer is a time, the only "cleanup" schedule anywhere in the tree is the **2 AM (`0 2 * * *`) example in the scheduler's docs** — but it is not a live job, not nightly-wired, and not database-related.
