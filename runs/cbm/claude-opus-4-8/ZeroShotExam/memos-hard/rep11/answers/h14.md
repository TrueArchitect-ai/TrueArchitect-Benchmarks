**Computation site**

The derived metadata lives in each memo's `Payload` (`store.Memo.Payload *storepb.MemoPayload`, `store/memo.go:51`). It is computed by:

- `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` — the orchestrator, which sets `memo.Payload.Tags` and `memo.Payload.Property` from the result of...
- `markdown.service.ExtractAll` in `internal/markdown/markdown.go:356` — the actual extractor, which does a single goldmark AST walk over the memo content. (`ExtractProperties` at `internal/markdown/markdown.go:193` implements the same property logic and is available separately.)

**Triggers (what causes recomputation)**

1. **Create** — `CreateMemo` calls `RebuildMemoPayload` before persisting (`server/router/api/v1/memo_service.go:108`).
2. **Update** — `UpdateMemo` calls it, but only when the `content` field is being changed (`server/router/api/v1/memo_service.go:446-451`).
3. **Bulk backfill** — the `memopayload.Runner.RunOnce` batch job re-derives the payload for every memo in the store, 100 at a time (`server/runner/memopayload/runner.go:27-72`).

**Extracted properties**

`ExtractAll` returns an `ExtractedData` (`internal/markdown/markdown.go:20-25`); `RebuildMemoPayload` copies two of its fields into the payload:

- `Tags` — deduplicated (case-preserving) list of `#tags` found in the content (`markdown.go:377`, `418`).
- `Property` (`storepb.MemoPayload_Property`, populated at `markdown.go:383-408`):
  - `Title` — text of the H1 heading, if the first block-level node is a level-1 heading.
  - `HasLink` — true if any link node is present.
  - `HasCode` — true for any code block / fenced code block / inline code span.
  - `HasTaskList` — true if any task checkbox exists.
  - `HasIncompleteTasks` — true if any task checkbox is unchecked.

(Note: `ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` only assigns `Tags` and `Property` into the memo payload.)
