The provider abstraction is defined in the **`internal/idp`** package (`internal/idp/idp.go`), which declares the shared `IdentityProviderUserInfo` type used by all identity-provider integrations. The only concrete protocol implementation that ships is **`internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`), whose package doc reads "implements the OAuth2 identity provider integration" and provides the `IdentityProvider` type with `NewIdentityProvider`, `ExchangeToken`, and `UserInfo`. It's the sole subpackage under `internal/idp`.

Answer: `internal/idp` (abstraction); `internal/idp/oauth2` (OAuth2 implementation)
