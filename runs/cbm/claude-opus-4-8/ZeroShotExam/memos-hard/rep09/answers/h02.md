**delivery function** — `Post` in `internal/webhook/webhook.go:120` (the actual outbound HTTP send happens at `safeClient.Do(req)`, line 152; `PostAsync` at line 184 just enqueues onto a worker pool that calls `Post`).

**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (lines 32–37). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`, backed by `reservedCIDRs` at `validate.go:14`). Because the check runs at dial time on the actually-resolved IP, it also defeats DNS-rebinding attacks.

Notes:
- A secondary, create-time guard exists: `ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and hostnames resolving to reserved IPs when a webhook is registered — but the enforcing protection on every delivery is `safeDialContext`.
- Both checks can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted local-network use.
