This project ships migrations for three SQL dialects, found as subdirectories under `store/migration/`:

**mysql, postgres, sqlite**

Evidence: `store/migration/mysql/`, `store/migration/postgres/`, and `store/migration/sqlite/` each contain versioned `.sql` migration files (e.g. `store/migration/postgres/0.27/00__migrate_storage_setting.sql`).
