**Convergence function — `Post` at `internal/webhook/webhook.go:119`.**

All of the above funnel their dispatch through `webhook.PostAsync` (the enqueue funnel, `internal/webhook/webhook.go:185`), whose background workers each call `webhook.Post`. `Post` is the single function where every path converges before delivery — it builds the request, signs it, and performs the actual outbound send via `safeClient.Do(req)` at `internal/webhook/webhook.go:157`. The target URL comes from the user's configured webhook (`hook.Url`, from `Store.GetUserWebhooks`).
