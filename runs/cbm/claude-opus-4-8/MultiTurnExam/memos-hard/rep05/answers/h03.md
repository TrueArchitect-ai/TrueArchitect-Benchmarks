**Abstraction package — `internal/idp` (`internal/idp/idp.go`), which defines the provider-neutral `IdentityProviderUserInfo` abstraction shared across identity providers.**

**Implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), the concrete OAuth2 protocol implementation (its `IdentityProvider` type consuming `storepb.OAuth2Config`).**

OAuth2 is the only concrete protocol implementation that ships under `internal/idp/` — it's the single subpackage there.
