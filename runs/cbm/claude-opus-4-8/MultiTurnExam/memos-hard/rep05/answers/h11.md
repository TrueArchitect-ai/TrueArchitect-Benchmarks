**1st: User (~6 external packages); 2nd: Memo (~4 external packages).**

Method: I treated the persistent entity types as the structs defined in the `store` data layer (`store.User`, `store.Memo`, `store.Attachment`, `store.Reaction`, `store.Inbox`, etc.) and counted distinct packages that reference each one *outside* the data layer (excluding everything under `store/`, including the `store/db/{sqlite,postgres,mysql}` drivers).

- **`store.User`** — referenced from 6 non-data-layer packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`.
- **`store.Memo`** — referenced from 4: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

Next were `store.Attachment` (~3) and `store.MemoShare` / `store.Inbox` (~2 each), so `User` and `Memo` are clearly the top two. (Counts are approximate — e.g. `server/router/api/v1/test` is a test-helper package; dropping it makes `User` ~5 — but the ranking is unchanged.)
