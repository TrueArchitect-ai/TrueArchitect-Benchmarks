Determination method:
- There are three candidate `CreateMemo` implementations, one per driver: `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`. The store facade `Store.CreateMemo` (`store/memo.go`) just delegates to `s.driver.CreateMemo`, so the concrete one that runs depends on which driver the factory selected.
- The driver is chosen in `NewDBDriver` (`store/db/db.go:14`) by `switch profile.Driver`. The value comes from `profile.Driver`, populated from the `driver` config key at `cmd/memos/main.go:43`.
- With a default installation (no flags), that key defaults to `"sqlite"`: `viper.SetDefault("driver", "sqlite")` at `cmd/memos/main.go:122` and the flag default at `cmd/memos/main.go:130`. So `NewDBDriver`'s `case "sqlite"` picks `sqlite.NewDB`, and `s.driver.CreateMemo` resolves to the SQLite `(*DB).CreateMemo` above.

Thus the Postgres and MySQL `CreateMemo` methods exist but do not execute in a default install; the SQLite one does.
