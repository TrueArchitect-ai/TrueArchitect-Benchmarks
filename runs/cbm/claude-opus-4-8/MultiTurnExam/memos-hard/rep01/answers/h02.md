**Delivery function:** `webhook.Post` in `internal/webhook/webhook.go:120` — the actual outbound HTTP delivery executes at `safeClient.Do(req)` on `internal/webhook/webhook.go:152`. (Dispatches are enqueued via `PostAsync` → the `asyncPostQueue` worker pool at `internal/webhook/webhook.go:184`/`:42`, which calls `Post`.)

**Protection mechanism:** The dial-time SSRF guard `safeDialContext` in `internal/webhook/webhook.go:59`, installed as the `DialContext` of the `safeClient` transport (`internal/webhook/webhook.go:32-37`). On every connection it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), whose blocklist of CIDRs — loopback, RFC-1918, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents — is defined in `internal/webhook/validate.go:14-23`. Because the check happens at dial time on the resolved IP, it also defeats DNS-rebinding. (A secondary, creation-time check `ValidateURL` at `internal/webhook/validate.go:62` rejects private-resolving URLs when webhooks are configured, e.g. `server/router/api/v1/user_service_webhooks.go:74`, but the enforced protection on the actual delivery path is `safeDialContext`.) Note both can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
