**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It runs the memo's `Content` through the markdown service in a single pass (`markdownService.ExtractAll`, `runner.go:80`) and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The extraction logic itself lives in `internal/markdown/markdown.go:356` (`(*service).ExtractAll`).

**Triggers (operations that recompute it):**
- **Create memo** — `CreateMemo` calls `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` at `server/router/api/v1/memo_service.go:108`, before the row is inserted.
- **Update memo (content changed)** — `UpdateMemo` recomputes only inside the `"content"` update-mask branch, at `server/router/api/v1/memo_service.go:446-451` (`memo.Content = request.Memo.Content` → `RebuildMemoPayload` → `update.Payload = memo.Payload`). Editing other fields (visibility, pinned, etc.) does not recompute it.
- (There is also a batch reprocessor `(*memopayload.Runner).RunOnce` at `server/runner/memopayload/runner.go:27` that rebuilds every memo's payload, but it is not wired into server startup / any production caller, so at runtime only create and content-update paths trigger recomputation.)

**Extracted properties** (from `ExtractAll`, stored in `MemoPayload`):
- `Tags` — all `#tags` found in the content (deduplicated, case preserved).
- `Property.Title` — text of a leading H1 heading, if the first block is one.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains a code block or inline code span.
- `Property.HasTaskList` — content contains a task checkbox, and `Property.HasIncompleteTasks` — at least one unchecked task.

(Note: `ExtractAll` also derives `Mentions`, but `RebuildMemoPayload` only stores `Tags` and `Property`; mentions are handled separately via `memo_mention_helpers.go`.)
