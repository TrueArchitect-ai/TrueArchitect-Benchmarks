**Premise correction:** There is no GraphQL schema anywhere in this repository. A search for `graphql`/`gqlgen`/`.graphql` in the Go code returns nothing, and there is no GraphQL dependency in `go.mod`. The public API is not GraphQL.

**Actual API surface:** The public API is defined as **Protobuf/gRPC services**, served over **Connect** and **gRPC-Gateway (REST/JSON)**:
- Schema/IDL lives in `.proto` files under `proto/api/v1/` — one `service` per file, e.g. `MemoService` (`proto/api/v1/memo_service.proto:17`), `UserService` (`proto/api/v1/user_service.proto:17`), `AuthService`, `AttachmentService`, `ShortcutService`, `InstanceService`, `IdentityProviderService`, `AIService` (`proto/api/v1/*.proto`). Shared messages are in `proto/api/v1/common.proto`. Generated Go code is in `proto/gen/`.
- These are wired up at runtime via Connect interceptors and a gRPC-Gateway mux in `server/router/api/v1/v1.go` (Connect handlers registered at `v1.go:141`, routed under `/memos.api.v1.*` at `v1.go:144`; gateway mux at `v1.go:95-97`). Dependencies: `connectrpc.com/connect` and `grpc-ecosystem/grpc-gateway/v2` (`go.mod:6`, `go.mod:17`).

So the "schema" for the public API is the set of Protobuf service definitions in `proto/api/v1/*.proto`, not a GraphQL schema.
