**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It ensures a `MemoPayload` exists, calls the markdown service's single-pass `ExtractAll` over `memo.Content` (`runner.go:80`), and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The actual parsing/extraction lives in the goldmark-backed markdown service: `service.ExtractAll` (`internal/markdown/markdown.go:356`), mirroring `service.ExtractProperties` (`internal/markdown/markdown.go:193`).

**Triggers (recomputation sites, non-test):**
- **Memo creation** — `CreateMemo` at `server/router/api/v1/memo_service.go:108`.
- **Memo update, on content change** — `UpdateMemo` at `server/router/api/v1/memo_service.go:447` (invoked in the branch that assigns `memo.Content = request.Memo.Content`, i.e. only when the content field is being updated).
- **Bulk backfill** — the `memopayload.Runner.RunOnce` batch job re-derives payloads for all memos (`server/runner/memopayload/runner.go:52`). (Note: this Runner is not wired into server startup — see the runner having no production caller — so in practice recomputation happens on create/update.)

**Extracted properties** (into `store.Memo.Payload`, a `storepb.MemoPayload`):
- **`Tags`** — the list of `#tags` found in the content (`ExtractedData.Tags`).
- **`Property`** — a `MemoPayload_Property` (`proto/gen/store/memo.pb.go:87-90`) with:
  - `HasLink` (content contains a link)
  - `HasTaskList` (contains a task/checkbox list)
  - `HasCode` (contains code)
  - `HasIncompleteTasks` (has unchecked task items)
  - plus `Property.Title` (first heading text), set in `ExtractAll` at `internal/markdown/markdown.go:387`.

These are derived from the markdown content (not user-set) and used for list/preview rendering and filtering.
