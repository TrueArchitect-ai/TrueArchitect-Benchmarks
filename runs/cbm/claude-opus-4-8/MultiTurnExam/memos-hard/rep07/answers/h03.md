**Abstraction package — `internal/idp` (`internal/idp/idp.go`, defining the provider-agnostic `IdentityProviderUserInfo` type); implementation package — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`, the OAuth2 `IdentityProvider`).**

The `internal/idp` package defines the provider abstraction — the common `IdentityProviderUserInfo` struct that any identity provider maps its user data into (`internal/idp/idp.go:3-8`). The one concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2`, whose `IdentityProvider` wraps a `storepb.OAuth2Config` and exchanges tokens / fetches user info (`internal/idp/oauth2/oauth2.go:18-25`).
