**Computation site** — `memopayload.RebuildMemoPayload` at `server/runner/memopayload/runner.go:74`, which delegates to the markdown service's single-pass `(*service).ExtractAll` (`internal/markdown/markdown.go`). `RebuildMemoPayload` parses `memo.Content`, then writes `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). This derived data lives in the memo's `Payload` (the `MemoPayload.Property` / `Tags` fields), computed from content rather than user-set.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (on every memo creation).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the content actually changes (it's inside the content-update branch that sets `memo.Content = request.Memo.Content`).
- Bulk backfill via `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`), which re-derives the payload for every memo in batches — though note this `Runner` isn't wired into production startup (only `RebuildMemoPayload` is invoked directly from the two RPC handlers).

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go`), stored into the payload:
- `Tags` — all `#tags` (deduplicated, original case preserved; tags inside links/images excluded).
- `Property.Title` — text of a leading level-1 (`H1`) heading, if the document's first block is one.
- `Property.HasLink` — content contains a link.
- `Property.HasCode` — content contains a code block/fenced code/inline code span.
- `Property.HasTaskList` — content contains a task checkbox.
- `Property.HasIncompleteTasks` — at least one unchecked task checkbox.

(`Mentions` — lowercased `@usernames` — are also extracted by `ExtractAll`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload.)
