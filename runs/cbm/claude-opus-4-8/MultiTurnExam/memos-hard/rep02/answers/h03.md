**Abstraction package: `internal/idp` (`internal/idp/idp.go`, defining the `IdentityProviderUserInfo` type used across provider implementations); Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go` — the OAuth2 `IdentityProvider`).**

The `internal/idp` package defines the shared provider abstraction (the `IdentityProviderUserInfo` struct returned by any provider), and the only concrete protocol implementation that ships is `internal/idp/oauth2`, which implements OAuth2 (`NewIdentityProvider` takes a `storepb.OAuth2Config` and exchanges tokens / fetches user info via the configured endpoints).
