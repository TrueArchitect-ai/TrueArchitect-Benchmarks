Method: the data layer is the `store` package plus its driver sub-packages (`store/db/{sqlite,postgres,mysql}`). Excluding those (and `_test.go` files), I counted the distinct non-store packages that reference each persistent entity type (`store.User`, `store.Memo`, `store.Attachment`, `store.Inbox`, `store.Reaction`, `store.MemoRelation`, `store.UserSetting`, `store.IdentityProvider`).

- **`store.User` (1st, ~6):** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`. (5 if the `.../api/v1/test` helper package is excluded as test scaffolding.)
- **`store.Memo` (2nd, ~4):** `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`.

Next after those: `store.Attachment` (~3: `server/router/api/v1`, `server/router/fileserver`, `server/runner/s3presign`), then `store.Inbox` (~2). So `User` is the most widely referenced entity, `Memo` second.
