**Abstraction package: `internal/idp` (`internal/idp/idp.go`, defining the `IdentityProviderUserInfo` type shared across providers); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`, the OAuth2 `IdentityProvider`).**

The `internal/idp` package defines the provider-agnostic abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar) that any provider returns (`internal/idp/idp.go:3`). The only concrete protocol implementation that ships is `internal/idp/oauth2`, an OAuth2 identity provider that exchanges the code, fetches the user-info endpoint, and maps configured fields into `idp.IdentityProviderUserInfo` (`internal/idp/oauth2/oauth2.go:1`, `:19-40`).
