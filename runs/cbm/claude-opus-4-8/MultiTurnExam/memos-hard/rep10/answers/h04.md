**No.** The MySQL driver is only constructed through the factory.

Evidence:
- The MySQL driver's constructor is `mysql.NewDB` (`store/db/mysql/mysql.go:20`, returning `store.Driver`).
- A codebase-wide grep for `mysql.NewDB(` yields exactly one call site: `store/db/db.go:22`, inside the `NewDBDriver` selection factory's `switch profile.Driver` (the `"mysql"` case).
- The `store/db/mysql` package is imported from only one place in the whole tree — `store/db/db.go:8` (the factory). No other package imports it, so no other package can construct the driver.
- The only other direct instantiation is a bare struct literal `db := &DB{}` in `store/db/mysql/auth_config_test.go:12` — an in-package unit test that builds an empty, connectionless `DB` to exercise a single method. That is not a functional driver construction and lives inside the driver package itself, not an external caller.
