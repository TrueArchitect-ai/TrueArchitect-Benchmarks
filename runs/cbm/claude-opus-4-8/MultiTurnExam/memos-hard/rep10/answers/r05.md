**Premise correction: there is no GraphQL schema or GraphQL API in this project.** A repo-wide search for `graphql`, `gqlgen`, and `.graphql` files across the codebase returns zero matches.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **gRPC / Connect (with a gRPC-Gateway REST/JSON mapping)** — not GraphQL:
- The schema/contract lives in `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`.
- Generated Go stubs (gRPC + gRPC-Gateway) are under `proto/gen/api/v1/` (e.g. `*_service.pb.go`, `*.pb.gw.go`).
- The server registers these as Connect handlers plus a gRPC-Gateway mux in `server/router/api/v1/v1.go` (Connect interceptors at `:133-141`, gateway mux at `:95-97`), with the concrete handlers in `server/router/api/v1/` (e.g. `memo_service.go`, `connect_services.go`).

So the "public API" is a protobuf-defined gRPC/Connect + REST-gateway surface; there is no GraphQL schema to point to.
