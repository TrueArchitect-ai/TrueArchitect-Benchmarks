**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74` (which delegates to `markdown.service.ExtractAll`, `internal/markdown/markdown.go`).**

**Triggers (recomputation):**
- `CreateMemo` — always, when a memo is saved — `server/router/api/v1/memo_service.go:108`.
- `UpdateMemo` — only when the content field is being changed (inside the `"content"` update-mask case, right after `memo.Content = request.Memo.Content`) — `server/router/api/v1/memo_service.go:447`.
- Bulk backfill: `memopayload.Runner.RunOnce` re-runs it over all memos in batches (`server/runner/memopayload/runner.go:52`) — though, per h08, that runner isn't wired into startup, so at runtime the two API paths are what fire.

**Extracted / stored properties:** `RebuildMemoPayload` calls `ExtractAll` (single goldmark AST walk) and writes two fields onto `memo.Payload` (`server/runner/memopayload/runner.go:85-86`):
- `Payload.Tags` — the list of `#tags` found in the content.
- `Payload.Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`) — boolean/derived flags computed in `ExtractAll` (`internal/markdown/markdown.go`): `HasLink`, `HasCode`, `HasTaskList`, `HasIncompleteTasks` (set when an unchecked task checkbox is present), plus `Title` (text of a leading H1 heading).

Note: `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` persists only `Tags` and `Property` into the stored payload; that payload is the derived metadata used for list/preview rendering.
