**Premise correction:** There is no GraphQL schema anywhere in this repository, so there is no location to point to. A search for `graphql`/`gqlgen`/`schema.graphql` returns zero matches in Go source, and `go.mod` declares no GraphQL library. The public API is not GraphQL.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **Connect/gRPC (with a REST/HTTP gateway)**.
- The API contract lives in `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus `common.proto`.
- These compile to generated Go under `proto/gen/api/v1/` — including gRPC stubs (`*_grpc.pb.go`), the Connect handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`), and the grpc-gateway REST bindings (`*.pb.gw.go`).
- The server implements these as Connect handlers (e.g. `ConnectServiceHandler` in `server/router/api/v1/connect_services.go`, and the per-service implementations like `server/router/api/v1/memo_service.go`), wired up in `server/router/api/v1/v1.go` with the interceptor chain (`v1.go:133`).

So the "schema" for the public API is the set of protobuf service definitions in `proto/api/v1/*.proto`, exposed via gRPC/Connect + a REST gateway — not GraphQL.
