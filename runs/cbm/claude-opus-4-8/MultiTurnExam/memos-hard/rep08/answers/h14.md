**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `MarkdownService.ExtractAll(memo.Content)` (the goldmark single-pass extractor, `internal/markdown/markdown.go:356`) and writes the result into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). This is server-derived metadata (not user-set), used for list/preview rendering.

**Triggers (recomputation):**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108` (on every memo creation).
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:447` (on update, in the branch that handles a content change).
- (There is also a bulk `Runner.RunOnce` batch rebuild over all memos at `server/runner/memopayload/runner.go:27`, but that `Runner` is not wired into production startup — see the two API handlers above for the live triggers.)

**Extracted properties** (from `ExtractAll` → `ExtractedData` / `MemoPayload_Property`):
- **`Tags`** — the list of distinct `#tags` in the content (`markdown.go:376-378`, `418`).
- **`Property.Title`** — text of a leading H1 heading, if present (`markdown.go:384-388`).
- **`Property.HasLink`** — content contains a link (`markdown.go:393-394`).
- **`Property.HasCode`** — content contains code (block/fenced/inline span) (`markdown.go:396-397`).
- **`Property.HasTaskList`** — content contains task-list checkboxes (`markdown.go:399-400`).
- **`Property.HasIncompleteTasks`** — at least one unchecked task (`markdown.go:401-404`).

(`ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` only persists `Tags` + `Property` into the payload; mentions are consumed separately by the mention/notification path.) The `Property` field definitions are in `proto/gen/store/memo.pb.go:87-92`.
