**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual outbound HTTP dispatch happens at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`). `PostAsync` (`webhook.go:184`) just enqueues onto a bounded channel whose worker goroutines call `Post`.

**Protection mechanism:** SSRF guard at dial time via `safeDialContext` — `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (`webhook.go:32-37`). It resolves the target host and rejects any address in a reserved/private range using `isReservedIP` (`internal/webhook/validate.go:44`) against `reservedCIDRs` (loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents; `internal/webhook/validate.go:14-23`). Because the check runs on the resolved IP at connect time, it also defeats DNS-rebinding. (There is additionally an up-front `ValidateURL` check at `internal/webhook/validate.go:62` when webhooks are configured, but the enforcement that protects the actual delivery is `safeDialContext`. Both can be bypassed by the opt-in `AllowPrivateIPs` flag, `validate.go:41`.)
