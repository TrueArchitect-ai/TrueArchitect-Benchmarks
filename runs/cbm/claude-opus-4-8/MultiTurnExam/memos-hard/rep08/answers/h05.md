**Mechanism:** Explicit Go code (not a DB-level rule, and not "not at all"). Reactions are removed by two explicit `DELETE FROM reaction ...` statements executed within the delete-user transaction: one keyed by `content_id` (removing reactions *on* the deleted user's memos) and one keyed by `creator_id` (removing reactions the deleted user *authored*). This is implemented identically across all three DB drivers.
