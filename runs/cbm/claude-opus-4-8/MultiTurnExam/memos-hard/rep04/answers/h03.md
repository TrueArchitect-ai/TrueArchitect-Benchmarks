h03.

Users authenticate through third-party identity providers via the `idp` subsystem.

**abstraction package;** `github.com/usememos/memos/internal/idp` (`internal/idp/idp.go`) — defines the provider abstraction, notably the shared `IdentityProviderUserInfo` struct (Identifier, DisplayName, Email, AvatarURL) that all providers normalize their user data into.

**implementation package:** `github.com/usememos/memos/internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the one concrete protocol implementation that ships, an OAuth2 `IdentityProvider` (`NewIdentityProvider`, `oauth2.go:27`) built on `golang.org/x/oauth2`, exchanging the auth code and fetching user info from the configured `UserInfoUrl` with field mapping.
