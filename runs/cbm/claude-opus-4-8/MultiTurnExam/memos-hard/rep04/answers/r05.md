**Premise correction:** There is no GraphQL schema in this repository, and no GraphQL API. A repo-wide search for `graphql`, `gqlgen`, and `graph-gophers` in Go source returns nothing, and `go.mod` pulls in no GraphQL library. The premise is false.

**Actual API surface:** The public API is defined with **Protocol Buffers**, served over **Connect/gRPC** with an HTTP/REST + OpenAPI gateway:

- **Schema definition:** `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. These are the canonical service/message definitions. Generated Go code lives in `proto/gen/` (build configured by `proto/buf.gen.yaml`, `proto/buf.yaml`).
- **Transport/serving:** The services are wired up over `connectrpc.com/connect` (see the imports and handler registration in `server/router/api/v1/connect_services.go`), backed by `google.golang.org/grpc` and exposed as REST via `grpc-ecosystem/grpc-gateway/v2` (both in `go.mod`).
- **REST/HTTP documentation:** an OpenAPI spec is embedded via `proto/openapi_embed.go` — this is the closest analog to a "schema for the public API," but it's OpenAPI (for the gRPC-gateway REST surface), not GraphQL.

So the public API is a Protobuf-defined, Connect/gRPC + REST service; there is no GraphQL schema to point to.
