**Computation site.** The derived metadata is computed in **`memopayload.RebuildMemoPayload`** — `server/runner/memopayload/runner.go:74`. It calls the markdown service's single-pass extractor **`(*service).ExtractAll`** — `internal/markdown/markdown.go` — and writes the results onto `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The heavy lifting (goldmark AST walk) is in `ExtractAll`.

**Triggers (recomputation).** Two RPC operations call `RebuildMemoPayload`:
- **Create** — `CreateMemo`, unconditionally on the new content, `server/router/api/v1/memo_service.go:108`.
- **Update** — `UpdateMemo`, but only inside the branch that runs when the content field is being changed (it sets `memo.Content = request.Memo.Content` then rebuilds), `server/router/api/v1/memo_service.go:447`.

(There is also a bulk `memopayload.Runner.RunOnce` that would rebuild every memo's payload, but that Runner is never constructed in production, so it doesn't run.)

**What the computation extracts** (from `ExtractAll`, `internal/markdown/markdown.go`):
- **Tags** — all `#tag` nodes, deduplicated while preserving case → `Payload.Tags`.
- **Property** (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`) → `Payload.Property`:
  - `HasLink` — content contains a link,
  - `HasCode` — contains a code block / fenced code / inline code span,
  - `HasTaskList` — contains a task checkbox,
  - `HasIncompleteTasks` — has at least one unchecked task,
  - `Title` — text of a first-block-level H1 heading, if present.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` stores only `Tags` and `Property`.)

Answer: **computation site — `memopayload.RebuildMemoPayload` (server/runner/memopayload/runner.go:74) via `markdown.(*service).ExtractAll` (internal/markdown/markdown.go); triggers — `CreateMemo` (memo_service.go:108) and content-changing `UpdateMemo` (memo_service.go:447); extracted — deduped `#tags` plus a `Property` of `HasLink`, `HasCode`, `HasTaskList`, `HasIncompleteTasks`, and first-H1 `Title` (stored on `memo.Payload.Tags` / `.Property`).**
