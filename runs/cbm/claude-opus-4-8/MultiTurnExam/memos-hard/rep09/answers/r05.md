**Premise correction:** There is no GraphQL schema in this repository. A search for `graphql`/`gqlgen`/`*.graphql` across the codebase returns zero hits, and `go.mod` declares no GraphQL library. The public API is not GraphQL.

**Actual API surface:** The API is defined with **Protocol Buffers**, served over **gRPC / Connect** with a **gRPC-Gateway** REST/JSON transcoding layer:
- Schema (service + message definitions) lives in the `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`.
- Generated Go bindings are under `proto/gen/` (imported as `v1pb "github.com/usememos/memos/proto/gen/api/v1"`).
- The server implements these services in `server/router/api/v1/` and registers them via Connect handlers and the gRPC-Gateway in `NewAPIV1Service` / `RegisterGateway` (`server/router/api/v1/v1.go`, `server/router/api/v1/connect_services.go`). Dependencies: `connectrpc.com/connect`, `github.com/grpc-ecosystem/grpc-gateway/v2`, `google.golang.org/grpc` (per `go.mod`).

Answer: **No GraphQL exists. The public API is a Protobuf-defined gRPC/Connect API with gRPC-Gateway REST transcoding; the schema is the `.proto` files in `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`), generated into `proto/gen/` and served from `server/router/api/v1/`.**
