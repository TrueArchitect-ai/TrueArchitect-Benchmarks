The provider abstraction lives in the **`internal/idp`** package (`internal/idp/idp.go`), which defines the provider-agnostic `IdentityProviderUserInfo` type used across implementations.

The one concrete protocol implementation that ships is **`internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`), an OAuth2 identity provider (`IdentityProvider` built from a `storepb.OAuth2Config`). OIDC is supported as a configuration variant layered on the same OAuth2 flow rather than as a separate package.

Answer: **`internal/idp` (abstraction); `internal/idp/oauth2` (implementation).**
