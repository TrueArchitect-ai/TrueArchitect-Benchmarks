**Delivery function** — `webhook.Post` in `internal/webhook/webhook.go:120` actually executes the outbound HTTP POST via `safeClient.Do(req)` (`internal/webhook/webhook.go:152`). Content-change events are enqueued through `PostAsync` (`internal/webhook/webhook.go:184`) and dispatched by a pool of 4 worker goroutines started in `init` (`internal/webhook/webhook.go:42-55`), each of which calls `Post`.

**Protection mechanism** — SSRF protection enforced at dial time. The shared `safeClient` uses a custom transport whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:32-37`, `59-77`). `safeDialContext` resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), which checks against `reservedCIDRs`/`reservedNetworks` (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents — `internal/webhook/validate.go:14-36`). Because the check happens at dial time on the actually-resolved IPs, it also defeats DNS-rebinding. There's an additional up-front `ValidateURL` check (`internal/webhook/validate.go:62`) when webhook URLs are registered, and the whole guard can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41-47`).
