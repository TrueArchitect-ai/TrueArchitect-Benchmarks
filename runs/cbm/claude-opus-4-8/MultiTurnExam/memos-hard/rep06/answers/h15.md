RSS feed — restricts feed to Public memos — server/router/rss/rss.go:90, :141
Frontend SSR — Public-only listing for server-rendered pages — server/router/frontend/frontend.go:150

### Note
These fall into two enforcement styles, both present:
- **Query-time filtering** (never fetch what the viewer can't see): ListMemos, comments/relations lists, user stats, RSS, frontend — all set `VisibilityList`/a `visibility in [...]` filter based on the authenticated user.
- **Post-fetch access checks** (fetch one memo, then authorize): GetMemo, the attachment/reaction API services, the file server's `checkMemoAccess`, and the SSE hub's `canReceive` — each applies the same rule (Public → open; Protected → any authenticated user; Private → creator or admin/super-user), with the file server additionally honoring a valid `share_token`.
