**Premise correction: There is no GraphQL API in this repository — no schema, no GraphQL server, no GraphQL library.** A search across all Go files and `go.mod` for `graphql`, `gqlgen`, and `.graphql` schema files returns nothing.

**Actual API surface: a Protocol-Buffers–defined gRPC / Connect API, with a REST (gRPC-Gateway) mapping.** The public API "schema" is the set of `.proto` service definitions under `proto/api/v1/`:
- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared `common.proto`.

These compile to Go in `proto/gen/api/v1/` (message/service stubs, the gRPC-Gateway `*.pb.gw.go` files, and Connect handlers). At runtime the services are exposed via Connect handlers registered in `server/router/api/v1/connect_handler.go` (e.g. `apiv1connect.NewIdentityProviderServiceHandler`, `NewMemoServiceHandler`, etc.), and the REST/HTTP surface is wired through the gRPC-Gateway mux set up in `server/router/api/v1/v1.go:95` (`RegisterGateway`). Store-side message shapes live in `proto/store/*.proto` → `proto/gen/store/`.

So the "schema" you'd look for is Protobuf/Connect, defined in `proto/api/v1/*.proto`, not a GraphQL SDL.
