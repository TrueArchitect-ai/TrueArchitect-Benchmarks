interceptor path: `web/src/connect.ts` — the `authInterceptor` (defined at line 156, attached to the main transport's `interceptors: [authInterceptor]` at line 188). It sets `Authorization: Bearer <token>` and reactively refreshes on 401; token storage/expiry helpers live in `web/src/auth-state.ts`.

token kinds:
- **JWT access token** — short-lived (~15 min), held in memory and sent as `Authorization: Bearer`.
- **Refresh token** — long-lived, delivered/sent via an httpOnly cookie (`credentials: "include"`), used by `AuthService.refreshToken` to mint new access tokens.
- (The backend also accepts **personal access tokens (PATs)** on the same Bearer path.)

backend package path: `server/auth` (`server/auth/authenticator.go` — `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and token parsing/validation).
