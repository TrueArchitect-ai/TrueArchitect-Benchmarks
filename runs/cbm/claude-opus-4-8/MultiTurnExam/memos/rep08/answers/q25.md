- **Engine:** Google **CEL** (Common Expression Language, via `github.com/google/cel-go`), wrapped by the project's own filter engine in `internal/filter/` — chiefly `internal/filter/engine.go` (with schema/env in `internal/filter/schema.go` and helpers in `internal/filter/helpers.go`).
- **Mechanism:** Each dialect driver (e.g. `store/db/sqlite/memo.go:57-61`) obtains `filter.DefaultEngine()` and calls `filter.AppendConditions(ctx, engine, find.Filters, filter.Dialect<X>, &where, &args)`, which parses the CEL filter string into an AST and renders it to a dialect-specific SQL `WHERE` clause plus bound args — emitting different SQL per `DialectName` (`DialectSQLite`/`DialectPostgres`/`DialectMySQL`), e.g. `strftime` for SQLite vs `EXTRACT` for Postgres vs `YEAR()`/`CHAR_LENGTH()` for MySQL.
