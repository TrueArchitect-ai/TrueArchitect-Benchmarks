- **Interceptor path:** `web/src/connect.ts` (`authInterceptor`, lines 156-188), with token storage helpers in `web/src/auth-state.ts`.
- **Token kinds:** a short-lived **JWT access token** — held client-side (via `getAccessToken`/`setAccessToken`) and attached as an `Authorization: Bearer <token>` header on every request; and a **refresh token** — kept in an HTTP-only cookie and used to mint new access tokens (the interceptor does preflight/reactive refresh on expiry or 401 via `AuthService.RefreshToken`).
- **Backend validation package:** `server/auth` — the `Authenticator` (`server/auth/authenticator.go`) validates the JWT access token and the refresh token (JWT/signing logic in `server/auth/token.go`, refresh-cookie extraction in `server/auth/extract.go`).
