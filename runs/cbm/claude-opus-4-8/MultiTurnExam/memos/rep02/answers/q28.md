**s3presign runner** — runs once at startup (`RunOnce`), then on a 12-hour `time.Ticker` (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-35`); started in `server/server.go:162-170` (`startBackgroundRunners`).

That is the only actual background runner the server starts. Notes:

- **memopayload** (`server/runner/memopayload`) is not a scheduled/background runner despite living under `server/runner/` — it's a helper invoked synchronously from memo create/update handlers (`server/router/api/v1/memo_service.go:108,447`).

**Unused scheduling infra:** `internal/scheduler` is a complete, GitHub-Actions-style cron scheduler package (`internal/scheduler/scheduler.go`, `parser.go`, `job.go`, etc., supporting 5/6-field cron expressions, timezones, middleware), but nothing outside the package or its tests imports it — the server does not use it.
