**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` (defined at line 156, registered on the main transport at line 188). It attaches an `Authorization: Bearer <token>` header, refreshes on expiry/401, and calls the `AuthService.refreshToken` RPC (with `credentials: "include"` so the refresh-token cookie is sent). Token state lives in `web/src/auth-state.ts`.

**Token kinds:** short-lived JWT access tokens (Bearer, ~15 min, held in memory) and long-lived refresh tokens (delivered/sent via cookie, validated against the DB). The backend also supports Personal Access Tokens (PAT) for programmatic clients.

**Backend validation package:** `server/auth/` (the `Authenticator` in `server/auth/authenticator.go`, e.g. `AuthenticateByAccessTokenV2`/`AuthenticateByRefreshToken`, with parsing in `server/auth/token.go`).
