Memo lifecycle events that dispatch webhooks (all in `server/router/api/v1/memo_service_webhooks.go`):

- created: `DispatchMemoCreatedWebhook` (activity `memos.memo.created`)
- updated: `DispatchMemoUpdatedWebhook` (activity `memos.memo.updated`)
- deleted: `DispatchMemoDeletedWebhook` (activity `memos.memo.deleted`)
- comment created: `DispatchMemoCommentCreatedWebhook` (activity `memos.memo.comment.created`)

Convergence for delivery: the created/updated/deleted dispatchers funnel through the private helper `dispatchMemoRelatedWebhook` (same file); all four ultimately call `webhook.PostAsync(payload)` in the `internal/webhook` package (`internal/webhook/webhook.go`), which enqueues to the async worker queue that runs `webhook.Post` for the actual HTTP delivery.
