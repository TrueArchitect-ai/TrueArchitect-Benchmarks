Interceptor path: web/src/connect.ts (the auth `Interceptor` that sets the `Authorization: Bearer <token>` header and reactively refreshes on 401)

Token kinds: short-lived JWT **access tokens** (set via `setAccessToken`, sent as `Bearer`), refreshed using a **refresh token** through `AuthService.refreshToken`; the backend also accepts long-lived **Personal Access Tokens (PATs)**.

Backend package path: server/auth (e.g. `Authenticator.AuthenticateByAccessTokenV2` / `AuthenticateByRefreshToken` in server/auth/authenticator.go, token parsing in server/auth/token.go)
