**Engine:** Google CEL (cel-go), in `internal/filter/` — parsed/compiled by `internal/filter/engine.go` (via `cel.NewEnv` / `Compile`).

**Mechanism:** The CEL filter string is compiled into a dialect-agnostic condition/IR tree (engine.go, ir.go), then a per-dialect renderer (`internal/filter/render.go`, driven by `DialectName` = SQLite/Postgres/MySQL) walks that tree to emit the correct SQL fragment and bound placeholders for each backend (e.g. `strftime(...)` for SQLite vs. the Postgres/MySQL equivalents).
