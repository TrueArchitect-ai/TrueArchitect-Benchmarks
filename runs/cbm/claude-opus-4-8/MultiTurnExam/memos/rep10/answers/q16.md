Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140-158`) deletes:

- **memo_relation records where this memo is the source** (`DeleteMemoRelation{MemoID}`)
- **memo_relation records where this memo is the target/related memo** (`DeleteMemoRelation{RelatedMemoID}`)
- **attachments linked to this memo** (each removed via `DeleteAttachment`)

Then it calls `driver.DeleteMemo` to remove the memo row.

(Note: at the API layer in `server/router/api/v1/memo_service.go:567-577`, comment memos are also deleted first — each recursing through `Store.DeleteMemo` — but the store layer's own per-memo cleanup is the three kinds above.)
