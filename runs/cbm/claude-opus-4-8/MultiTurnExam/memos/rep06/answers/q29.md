Interceptor path: `web/src/connect.ts` — `authInterceptor` (line 156), registered on the transport (line 188). It attaches `Authorization: Bearer <token>` (line 97-99) and reactively refreshes on 401.

Token kinds it manages:
- **Access token** — short-lived JWT held in-memory via `web/src/auth-state.ts` (`getAccessToken`/`setAccessToken`), sent as the `Authorization: Bearer` header.
- **Refresh token** — sent via HTTP-only cookie (`credentials: "include"`, line 60); used to mint new access tokens through the `AuthService.RefreshToken` RPC (line 75).
- (The backend also accepts **Personal Access Tokens** for API clients.)

Backend validation package: `server/auth` — `Authenticator` validates access tokens (`AuthenticateByAccessTokenV2`), refresh tokens (`AuthenticateByRefreshToken`), and PATs (`AuthenticateByPAT`) in `server/auth/authenticator.go`, using JWTs (`golang-jwt/jwt/v5`) in `server/auth/token.go`.
