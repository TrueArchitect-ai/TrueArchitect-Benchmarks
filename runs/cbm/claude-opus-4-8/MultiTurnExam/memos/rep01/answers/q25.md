**Engine:** Google CEL (cel-go) — the filter engine lives in `internal/filter/` (`internal/filter/engine.go` builds the `cel.Env` and parses the expression; `internal/filter/schema.go` defines the allowed fields/functions).

**Mechanism:** The CEL filter string is parsed by the `filter.Engine` into a dialect-agnostic condition/IR tree (`internal/filter/ir.go`, `parser.go`), and `internal/filter/render.go` walks that tree with a `renderer` configured for the target `Dialect` (SQLite/Postgres/MySQL) to emit dialect-specific SQL fragments plus bind args, which each store dialect driver (`store/db/{sqlite,postgres,mysql}/memo.go`) splices into the memo `WHERE` clause.
