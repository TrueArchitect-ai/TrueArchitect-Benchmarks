- **Interceptor path:** `web/src/connect.ts` — the ConnectRPC auth `Interceptor` sets the `Authorization: Bearer <token>` header and, on a 401/expired token, calls `refreshAccessToken` (via the deduplicating `tokenRefreshManager`, which calls `AuthService.refreshToken`). Token storage helpers live in `web/src/auth-state.ts`.
- **Token kinds:** a short-lived **access token** (JWT, sent in the `Authorization` Bearer header) and a **refresh token** (used by the `RefreshToken` RPC to mint new access tokens; the refresh call sends an empty body, the refresh credential being carried out-of-band/cookie).
- **Backend package:** `server/auth/` (the `authenticator.go` authenticator extracts and validates the bearer token — see `extract.go`/`token.go` — resolving it to a user via `Store.GetUser`).
