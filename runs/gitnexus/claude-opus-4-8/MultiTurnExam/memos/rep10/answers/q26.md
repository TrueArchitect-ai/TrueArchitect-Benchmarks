When `DeleteMemo` runs (`store/memo.go:140`, driven from `APIV1Service.DeleteMemo` in `server/router/api/v1/memo_service.go:518`), the tables affected by explicit code are:

- **memo_relation** — rows where the memo is the source (`MemoID`) or the target (`RelatedMemoID`) (`store/memo.go:142,145`)
