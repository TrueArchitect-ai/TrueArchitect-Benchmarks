**web/src/hooks/useMemoQueries.ts; memoServiceClient**

This module contains the memo CRUD queries/mutations (e.g. `useMemos`, `useMemo`, `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`) and uses the generated `memoServiceClient` (imported from `web/src/connect.ts`) for all calls such as `memoServiceClient.listMemos(...)`.
