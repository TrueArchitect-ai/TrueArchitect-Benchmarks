**memo, memo_relation, attachment**

`Store.DeleteMemo` (`store/memo.go:140`) explicitly deletes `memo_relation` rows (both `memo_id` and `related_memo_id` directions) and `attachment` rows before deleting the `memo` row. The API handler additionally recurses into comment memos (same three tables again). Note: reactions are only *listed* (for the deletion webhook payload) but are **not** deleted by explicit cascade code, so the `reaction` table is not affected.
