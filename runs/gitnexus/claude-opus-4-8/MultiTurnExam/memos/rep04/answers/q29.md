**Interceptor path:** `web/src/connect.ts` (`authInterceptor`, defined at line 156 and registered at line 188; helper token logic uses `web/src/auth-state.ts`).

**Token kinds it manages:**
- A short-lived **access token** — held in memory and attached as `Authorization: Bearer <token>` on each request.
- A **refresh token** — an HTTP-only cookie sent via `credentials: "include"`, used by `refreshToken` (AuthService) to mint new access tokens.

**Backend validation package:** `server/auth` (the `Authenticator` in `server/auth/authenticator.go`, with token parsing/validation in `server/auth/token.go` and `extract.go`).
