Engine: Google CEL (cel-go) — `internal/filter/engine.go` (the `Engine` wraps `cel.NewEnv`; supporting files `parser.go`, `ir.go`, `render.go`, `schema.go` in `internal/filter/`)

Mechanism: The CEL filter string is compiled to a CEL AST and lowered into a dialect-independent condition/IR tree, then `render.go` walks that IR and emits parameterized SQL selected by `RenderOptions.Dialect` (one of `sqlite`, `postgres`, `mysql`), which the store layer splices into the `ListMemos` query for the active driver.
