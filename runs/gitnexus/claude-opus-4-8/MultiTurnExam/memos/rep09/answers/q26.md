`Store.DeleteMemo` (`store/memo.go:140-158`) explicitly deletes `memo_relation` rows (both `MemoID` and `RelatedMemoID` directions) and the memo's linked `attachment` rows before deleting the `memo` row itself. At the API layer, `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:567-582`) also deletes comment memos, which are additional `memo` rows run through the same cascade.

Note: reactions are only *listed* (for the webhook payload) in the API handler — there is no explicit reaction-deletion code in this path, so `reaction` is not affected by explicit cascade code here (`server/router/api/v1/memo_service.go:545-550`).
