**Background workers actually started by the server:**
- **s3presign runner** — driven by a `time.Ticker` at a 12-hour interval (`runnerInterval = time.Hour * 12`). It runs once synchronously at startup (`RunOnce`) then loops on the ticker. Wired in `server/server.go:162-169`; scheduling in `server/runner/s3presign/runner.go:27-33`.

That is the only background runner the server launches (`startBackgroundRunners`, `server/server.go:153`).

**Notes:**
- The other package under `server/runner/` — **memopayload** — is *not* a scheduled/background runner. `memopayload.RebuildMemoPayload` is invoked inline inside the memo create/update handlers (`server/router/api/v1/memo_service.go:108,447`), driven by request flow, not a timer.
- **Unused scheduling infra:** `internal/scheduler` is a full GitHub-Actions-style cron job scheduler (cron expressions, timezones, middleware — see `internal/scheduler/doc.go`), but nothing in production code imports it (no references outside the package itself and its tests). It is present but not wired into the server.
