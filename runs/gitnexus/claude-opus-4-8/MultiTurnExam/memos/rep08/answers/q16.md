In `Store.DeleteMemo` (`store/memo.go`), before deleting the `memo` row itself, it deletes:

- **memo_relation records** where the memo is the source (`MemoID`)
- **memo_relation records** where the memo is the target (`RelatedMemoID`)
- **attachment records** linked to the memo (via `ListAttachments` + `DeleteAttachment`)

Then it calls `driver.DeleteMemo` to remove the memo row (`store/db/sqlite/memo.go`, which only issues `DELETE FROM memo`).
