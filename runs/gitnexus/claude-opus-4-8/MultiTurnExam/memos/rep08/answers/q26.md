**memo, memo_relation, attachment**

When `DeleteMemo` runs (`server/router/api/v1/memo_service.go` handler → `Store.DeleteMemo` in `store/memo.go`):

- **memo** — the memo row itself, plus its comment memos (deleted recursively via the same path).
- **memo_relation** — deleted where the memo is either source (`MemoID`) or target (`RelatedMemoID`).
- **attachment** — every attachment linked to the memo is deleted (`Store.DeleteAttachment`, which also removes backing storage).

Note: `reaction` records are *read* (only to build the webhook payload) but there is no explicit cascade code deleting them in the delete path, so `reaction` is not affected by application code.
