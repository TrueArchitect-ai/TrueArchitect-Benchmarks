**Engine:** Google CEL (google/cel-go, Common Expression Language) — `internal/filter/` (env/parse in `internal/filter/engine.go`, schema in `schema.go`, IR in `ir.go`, SQL rendering in `render.go`/`parser.go`).

**Mechanism:** Each dialect's memo query (e.g. `store/db/sqlite/memo.go:57-61`) builds a `filter.DefaultEngine()` and calls `filter.AppendConditions(...)` with a dialect selector (`filter.DialectSQLite` / `DialectPostgres` / `DialectMySQL`), which parses the CEL filter into an intermediate representation and renders it into dialect-specific SQL `WHERE` clauses plus bound arguments.
