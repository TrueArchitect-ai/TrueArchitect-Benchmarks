Engine: Google CEL (`github.com/google/cel-go`), wrapped in the `internal/filter` package (`internal/filter/engine.go` parses via `cel.NewEnv`/`cel.AstToParsedExpr`).

Mechanism: `internal/filter/engine.go` compiles the CEL filter string into an AST, `parser.go` lowers it into a dialect-neutral IR of Conditions (`ir.go`), and `render.go`'s `renderer` walks that IR emitting parameterized SQL specialized per `DialectName` (sqlite/postgres/mysql) — e.g. dialect-specific column quoting and timestamp-accessor expressions — which the ListMemos store query then appends to its WHERE clause.
