Interceptor path: web/src/connect.ts (the `authInterceptor` sets the `Authorization: Bearer <token>` header via `setAuthorizationHeader`, and reactively refreshes on 401; a `refreshTransport`/`refreshAuthClient` handles token renewal).

Token kinds: a short-lived **access token** (JWT, sent as `Authorization: Bearer`, managed in `web/src/auth-state.ts`) and a **refresh token** (server-rotated, sent via httpOnly cookie, exchanged through `AuthService.RefreshToken`).

Backend package path: server/auth (`Authenticator.AuthenticateByAccessTokenV2` / `AuthenticateByRefreshToken` in `server/auth/authenticator.go`, parsing in `server/auth/token.go`; refresh tokens validated against the store via `GetUserRefreshTokenByID`).
