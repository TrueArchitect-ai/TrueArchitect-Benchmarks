**Runners the server actually starts** (in `Server.startBackgroundRunners`, `server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — runs once at startup via `RunOnce(ctx)` (`server.go:163`), then repeats on a `time.Ticker` set to `runnerInterval = 12 hours` (`s3presign/runner.go:27-35`). It re-presigns S3 attachment URLs older than the refresh window.

That is the **only** background runner started.

**Unused-infra note:** The `server/runner/memopayload` package also defines a `Runner` with `NewRunner`/`RunOnce` (a loop over all memos, `memopayload/runner.go:19-33`), but the server never instantiates it — no `memopayload.NewRunner`/`RunOnce` call exists outside the package itself. Instead, only its standalone `RebuildMemoPayload` function is invoked inline (synchronously) from the memo handlers during create/update (`server/router/api/v1/memo_service.go:108` and `:447`). So the memopayload *runner/scheduling* infrastructure is present but not run as a background worker.
