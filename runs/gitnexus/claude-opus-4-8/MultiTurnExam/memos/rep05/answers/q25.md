**Engine:** Google CEL (Common Expression Language), via `github.com/google/cel-go`, living in the `internal/filter` package — CEL environment/schema in `internal/filter/schema.go`, parsing into an intermediate representation in `internal/filter/parser.go`/`internal/filter/ir.go`, and SQL rendering in `internal/filter/render.go`.

**Mechanism (one sentence):** The CEL filter string is parsed/type-checked against the memo filter schema into a dialect-neutral IR of `Condition`s, which a dialect-aware `renderer` (`newRenderer` with `DialectName` ∈ {DialectSQLite, DialectPostgres, DialectMySQL}) then converts into a parameterized SQL `WHERE` fragment — emitting per-dialect placeholders, column qualification, and date/JSON functions (e.g. `strftime` for SQLite vs. the Postgres/MySQL equivalents) that the store driver splices into the `ListMemos` query.
