The provider abstraction lives in the **`internal/idp`** package (`internal/idp/idp.go`), which defines the shared `IdentityProviderUserInfo` type used across all providers. The single concrete protocol implementation that ships is the **`internal/idp/oauth2`** package (`internal/idp/oauth2/oauth2.go` — "Package oauth2 implements the OAuth2 identity provider integration"), whose `IdentityProvider` is built from a `storepb.OAuth2Config`.

Answer: **`internal/idp` (abstraction); `internal/idp/oauth2` (OAuth2 implementation)**
