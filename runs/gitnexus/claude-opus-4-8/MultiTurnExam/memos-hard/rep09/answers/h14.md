**Computation site.** The derived metadata is the memo's `Payload` (`storepb.MemoPayload`), computed by **`memopayload.RebuildMemoPayload`** — `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll([]byte(memo.Content))` and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`). The actual extraction logic lives in the markdown service's `ExtractAll` — `internal/markdown/markdown.go:356-422`.

**Triggers (production recomputation).**
- **`CreateMemo`** — always recomputes on save: `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)` at `server/router/api/v1/memo_service.go:108`.
- **`UpdateMemo`** — recomputes only when the content field changes (inside the `content` update-mask branch, right after `memo.Content = request.Memo.Content`): `server/router/api/v1/memo_service.go:447`.
- **`memopayload.Runner.RunOnce`** — a batch backfill that rebuilds the payload of all memos (`server/runner/memopayload/runner.go:27-72`); note this `Runner` isn't wired into startup in production (see h08), so it's not an active runtime trigger.

**Extracted properties.** `ExtractAll` parses the content with goldmark and returns `ExtractedData{Tags, Mentions, Property}` (`internal/markdown/markdown.go:20-25`). `RebuildMemoPayload` persists two of these into the payload:
- **`Tags`** — all `#tags` in the content, deduplicated (`markdown.go:376-378, 418`) → `Payload.Tags`.
- **`Property`** (`storepb.MemoPayload_Property`) → `Payload.Property`, containing: **`Title`** (text of a leading H1 heading), **`HasLink`**, **`HasCode`** (code block/span), **`HasTaskList`**, and **`HasIncompleteTasks`** (unchecked task boxes) — computed at `markdown.go:383-408`.

(`Mentions` — `@username` references — is also extracted by `ExtractAll` but is not written into the payload by `RebuildMemoPayload`.)
