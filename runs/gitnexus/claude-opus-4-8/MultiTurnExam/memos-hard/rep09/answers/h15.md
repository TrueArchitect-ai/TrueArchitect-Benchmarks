h15. Memo view-visibility is enforced at many distinct server surfaces:

- **Single-memo read authorization (gRPC `GetMemo`)** — `checkMemoReadAccess` (public → open; protected → must be authenticated; private → owner only) — `server/router/api/v1/memo_service.go:47-66`
- **Memo list query filtering (gRPC `ListMemos`)** — constrains `VisibilityList` to Public (anonymous) or Public+Protected (authenticated), owner sees own — `server/router/api/v1/memo_service.go:219-225`

- **Attachment access via gRPC API** — visibility gate on the owning memo — `server/router/api/v1/attachment_service.go:445-451`
- **Memo attachment listing (gRPC)** — `server/router/api/v1/memo_attachment_service.go:214-222`
- **Reaction listing/creation (gRPC)** — visibility gate on the memo — `server/router/api/v1/reaction_service.go:30-38,83`
