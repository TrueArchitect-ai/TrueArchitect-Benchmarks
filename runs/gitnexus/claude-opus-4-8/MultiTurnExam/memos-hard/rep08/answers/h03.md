**Abstraction package**: `internal/idp` (`internal/idp/idp.go`) — defines the shared, protocol-agnostic `IdentityProviderUserInfo` type that every provider returns. (Note: the abstraction is expressed via this shared return type plus the proto `IdentityProvider_Type` enum rather than a declared Go `interface`.)

**Implementation package**: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the OAuth2 identity provider, the sole concrete protocol implementation that ships. It exposes `NewIdentityProvider`, `ExchangeToken` (with PKCE support), and `UserInfo`. Confirmed as the only one: `internal/idp/` has just the `oauth2/` subpackage, and the store enum has only `TYPE_UNSPECIFIED` and `OAUTH2`.
