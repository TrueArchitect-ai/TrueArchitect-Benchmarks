**Premise correction:** There is no GraphQL schema in this project. A repo-wide search finds zero references to `graphql`, `gqlgen`, or any `.graphql`/`schema.graphql` file, and no GraphQL dependency in `go.mod`. The public API is not GraphQL.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served as gRPC / Connect RPC with a gRPC-Gateway REST/JSON transcoding layer. The schema lives in the `.proto` files under `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and `common.proto`.

These proto definitions are compiled into the generated Go stubs in `proto/gen/api/v1/` (including the `*.pb.gw.go` gRPC-Gateway REST handlers). At runtime the services are registered with Connect interceptors and a gRPC-Gateway mux in `server/router/api/v1/v1.go` (e.g. `RegisterConnectHandlers` at `v1.go:141`). There are also internal store-shape protos under `proto/store/`. So the API "schema" is the protobuf service definitions in `proto/api/v1/`, not a GraphQL schema.
