h11.

Measuring how many distinct packages *outside* the data layer (`store/` and its `store/db/*` drivers) reference each persistent entity type as `store.<Type>`:

**1st: `User` (store.User) — ~5–6 packages**
Referenced from `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` (plus the test-support pkg `server/router/api/v1/test`). Declared in `store/user.go`.

**2nd: `Memo` (store.Memo) — ~4 packages**
Referenced from `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`. Declared in `store/memo.go`.

(Third is `Attachment` at ~3 packages; all other entity types — `MemoShare`, `Inbox`, `Reaction`, `UserSetting`, etc. — sit at 1–2.) Counts are static references via the `store.<Type>` qualified name, excluding tests and the data-layer packages themselves.
