**Premise correction:** There is no nightly database-cleanup job scheduled in a cron scheduler — neither the "nightly cleanup job" nor a running cron scheduler exists in this codebase, so there is no scheduled time to report.

Details:
- A cron scheduler package does exist (`internal/scheduler/`, a "GitHub Actions-inspired cron job scheduler" per `internal/scheduler/doc.go:1`), but it is **never used in production**: there are no `scheduler.New(...)` or `scheduler.Job{...}`/`Register(...)` call sites anywhere outside the package, and nothing imports `usememos/memos/internal/scheduler`. The package is effectively dead code.
- The `"0 2 * * *"` "2 AM daily" `daily-cleanup` you may have seen is only an illustrative **example inside a doc comment** (`internal/scheduler/doc.go:14-18`), not a registered job.
- The only actual background jobs run on `time.Ticker`, not cron, and none is a nightly DB cleanup: the S3 presign runner every 12 hours (`server/runner/s3presign/runner.go:26`, wired at `server/server.go:169`) and the in-memory cache cleanup every 5 minutes (`store/cache/cache.go:60,200`). Database record deletion happens inline in request handlers (e.g. `store.DeleteMemo`, `store.DeleteUser`), not on any schedule.
