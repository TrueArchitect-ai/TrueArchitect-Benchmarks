**Protection mechanism**: SSRF protection in two layers:
- **Dial-time guard (the effective protection, defeats DNS rebinding)**: `safeDialContext` — `internal/webhook/webhook.go:59`, installed as the `DialContext` of `safeClient`'s transport. It resolves the host and refuses to connect if any resolved IP is reserved/private (`webhook.go:70-74`).
- **Pre-flight URL validation**: `ValidateURL` — `internal/webhook/validate.go:62`, which rejects non-http(s) schemes and reserved IPs at configuration time.

Both rely on `isReservedIP` (`internal/webhook/validate.go:44`) checking against the reserved CIDR set (`validate.go:14-23`: loopback, RFC-1918 private, link-local/IMDS `169.254.0.0/16`, and IPv6 `::1`/`fc00::/7`/`fe80::/10`). There is an `AllowPrivateIPs` escape hatch (`validate.go:41`) that disables the check for self-hosted setups.
