Memo view-visibility is enforced across multiple server surfaces. Distinct enforcement sites:

- `checkMemoReadAccess` (canonical single-memo view gate; PUBLIC/PROTECTED/PRIVATE + creator) — `server/router/api/v1/memo_service.go:39` (used by `GetMemo` at `memo_service.go:341` and `ListMemoComments`)
- `ListMemos` (builds the visibility filter for list queries — anonymous→PUBLIC, self→creator-or-PUBLIC/PROTECTED, other user→PUBLIC/PROTECTED) — `server/router/api/v1/memo_service.go:178`
- `ListMemoComments` (per-comment visibility filter, gated on parent) — `server/router/api/v1/memo_service_comments.go:136`
- `ListMemoRelations` (visibility filter for related memos) — `server/router/api/v1/memo_relation_service.go:93`
- `batchConvertMemoRelations` (filters related memos a viewer can't see; shared by ListMemos/comments/share) — `server/router/api/v1/memo_service_converter.go:173`
- `ListMemoReactions` (re-checks memo visibility before returning reactions) — `server/router/api/v1/reaction_service.go:15`
- `ListMemoAttachments` (visibility check before listing a memo's attachments) — `server/router/api/v1/memo_attachment_service.go:200`
- `checkAttachmentAccess` (API `GetAttachment` enforces parent memo's visibility) — `server/router/api/v1/attachment_service.go:422`
- `checkAttachmentPermission` (file server enforces linked memo's visibility, incl. share-token path, before serving bytes) — `server/router/fileserver/fileserver.go:650`
- `GetExploreRSS` (hardcodes PUBLIC-only) — `server/router/rss/rss.go:72` (filter at `rss.go:90`)
- `GetUserRSS` (hardcodes PUBLIC-only) — `server/router/rss/rss.go:111` (filter at `rss.go:141`)
- `ListAllUserStats` / `GetUserStats` (same visibility filter for stat aggregates) — `server/router/api/v1/user_service_stats.go`

The three surfaces called out in the question are at minimum: the API v1 memo service (`checkMemoReadAccess`/`ListMemos`), the RSS feed service (`server/router/rss/rss.go`), and the file server (`server/router/fileserver/fileserver.go:650`). Note enforcement is duplicated across these rather than centralized in one helper.
