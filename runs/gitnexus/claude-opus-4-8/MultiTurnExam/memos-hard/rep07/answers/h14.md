**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which calls the markdown service's `ExtractAll` — `internal/markdown/markdown.go` (single goldmark AST walk). It writes results into `memo.Payload.Tags` and `memo.Payload.Property` (`storepb.MemoPayload_Property`, proto/gen/store/memo.pb.go:85).

**Triggers (production):** memo creation and update — `CreateMemo` (`server/router/api/v1/memo_service.go:108`) and `UpdateMemo` (`server/router/api/v1/memo_service.go:447`), both calling `memopayload.RebuildMemoPayload`. (A whole-DB batch recompute also exists in `memopayload.Runner.RunOnce`, runner.go:27, but as established earlier that method has no production caller.)

**Extracted properties:** From the content's markdown AST:
- `Tags` — deduplicated `#tags` (memo.Payload.Tags).
- `Property.Title` — text of a leading H1 heading, if the first block is one.
- `Property.HasLink` — any link node present.
- `Property.HasCode` — any code block/fenced block/inline code span.
- `Property.HasTaskList` — any task checkbox present.
- `Property.HasIncompleteTasks` — a task checkbox that is unchecked.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the payload; mentions are consumed separately.)
