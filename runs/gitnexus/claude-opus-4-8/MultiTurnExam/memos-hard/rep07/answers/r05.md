**Premise correction:** There is no GraphQL schema — the project does not use GraphQL at all. A repo-wide search for `graphql`, `gqlgen`, or `schema.graphql` across all Go files and `go.mod` returns zero matches.

**Actual API surface:** The public API is defined with **Protocol Buffers** and served over **gRPC / Connect** (with an HTTP/JSON gateway). The schema lives in the `.proto` files under `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto` (proto/api/v1/).
- These generate Go code under `proto/gen/api/v1/` (e.g. `memo_service_grpc.pb.go`, Connect handlers).
- The generated services are wired up and served in `server/router/api/v1/v1.go` (Connect handlers registered at `v1.go:141` with the interceptor stack), with the service implementations in `server/router/api/v1/*.go`.

So to view or change the "schema," you edit the protobuf definitions in `proto/api/v1/` (regenerated via buf), not a GraphQL SDL file.
