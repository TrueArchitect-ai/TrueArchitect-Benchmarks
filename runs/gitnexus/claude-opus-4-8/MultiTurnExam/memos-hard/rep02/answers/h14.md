**Extracted properties (from parsing the content markdown):**
- **Tags** — collected from memo-tag nodes, deduplicated preserving case (`markdown.go` `uniquePreserveCase`).
- **Property.Title** — text of a leading H1 heading, if the document's first block is one.
- **Property.HasLink** — content contains a link.
- **Property.HasCode** — content contains a code block/fenced code/inline code span.
- **Property.HasTaskList** — content contains a task checkbox.
- **Property.HasIncompleteTasks** — at least one unchecked task checkbox.

(`ExtractAll` also gathers mentions, but `RebuildMemoPayload` only writes `Tags` and `Property` into the persisted payload; mentions are not stored there.)
