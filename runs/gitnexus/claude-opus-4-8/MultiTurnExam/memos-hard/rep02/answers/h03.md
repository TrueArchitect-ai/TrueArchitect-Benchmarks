**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the shared provider contract, the normalized `IdentityProviderUserInfo` type that every provider returns.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the concrete **OAuth2** implementation (authorization-code exchange with optional PKCE, user-info fetch), and the only protocol that ships. Its `IdentityProvider` struct wraps a `storepb.OAuth2Config` and produces `idp.IdentityProviderUserInfo`.
