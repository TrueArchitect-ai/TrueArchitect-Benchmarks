**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual network POST fires at `webhook.go:152`, `safeClient.Do(req)`). `PostAsync` (`webhook.go:184`) merely enqueues onto a channel; worker goroutines started in `init()` (`webhook.go:42`) call `Post` to do the real delivery.

**Protection mechanism:** `safeDialContext` — `internal/webhook/webhook.go:59`. It is installed as the `DialContext` of the shared `safeClient`'s transport (`webhook.go:32`), so on every connection it re-resolves the host and rejects any resolved address in a reserved range (via `isReservedIP`), which also defeats DNS-rebinding since the check runs against the actual dialed IP.

Supporting/secondary layer: `ValidateURL` + `isReservedIP` (`internal/webhook/validate.go:62` and `validate.go:44`), enforced at URL registration time, with the reserved-range blocklist `reservedCIDRs` at `internal/webhook/validate.go:14` (loopback, RFC-1918, link-local incl. `169.254.169.254`, IPv6 loopback/ULA/link-local). It can be globally disabled via the `AllowPrivateIPs` flag (`validate.go:41`) for self-hosted deployments.
