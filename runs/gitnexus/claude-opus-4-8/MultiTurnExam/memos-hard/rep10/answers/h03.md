h03.
**`internal/idp` (abstraction); `internal/idp/oauth2` (implementation)**

Details:

- **Abstraction package** — `internal/idp` (`internal/idp/idp.go`). It defines the protocol-agnostic `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider returns. Note: memos doesn't declare a formal Go `interface` here — the provider contract is structural (each implementation exposes `NewIdentityProvider`, `ExchangeToken`, and `UserInfo(ctx, token) (*idp.IdentityProviderUserInfo, error)`).

- **Implementation package** — `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), the `oauth2.IdentityProvider` struct wrapping `*storepb.OAuth2Config`. OAuth2 is the only concrete protocol that ships; the `internal/idp` tree contains just `idp.go` and the `oauth2/` subdirectory.

It's wired in `server/router/api/v1/auth_service_sso.go` (`resolveSSOIdentity`), which dispatches on the `storepb.IdentityProvider_OAUTH2` enum rather than through an interface.

(The path is `internal/idp`, not `plugin/idp`.)
