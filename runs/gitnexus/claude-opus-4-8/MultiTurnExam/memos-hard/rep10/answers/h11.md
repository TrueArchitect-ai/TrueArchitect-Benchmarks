**1st: `store.User` (~7 external packages); 2nd: `store.Memo` (~6 external packages)**

Method: I took the persistent entity structs defined in the data layer (`store/*.go` — `User`, `Memo`, `Attachment`, `Reaction`, `MemoRelation`, `Inbox`, `IdentityProvider`, `UserSetting`, `UserIdentity`, `MemoShare`, `InstanceSetting`) and counted the distinct packages *outside* the `store/` tree (i.e. excluding `store` itself and its `store/db/*` drivers and `store/test`) that reference each via `store.<Type>`.

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

Next-highest is `store.Attachment` at ~4 packages, so `User` and `Memo` clearly lead. (Counts are approximate — `.../api/v1` and `.../api/v1/test` are counted as separate package directories; collapsing them would make it roughly 6 vs 5, but `User` still ranks first.)
