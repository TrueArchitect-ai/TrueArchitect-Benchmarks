**Handlers (all reach outbound webhook delivery): `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `SetMemoRelations`, `SetMemoAttachments`, `CreateMemoComment`. Single convergence function before delivery: `webhook.PostAsync` — `internal/webhook/webhook.go` (which hands off to `Post`, the actual HTTP sender).**

Details:

The six RPC handlers on `APIV1Service` that can transitively cause an outbound HTTP request to a user-configured webhook URL:

| Handler | Dispatch call site | Chain |
|---|---|---|
| `CreateMemo` | `server/router/api/v1/memo_service.go:157` | → `DispatchMemoCreatedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync` |
| `DeleteMemo` | `server/router/api/v1/memo_service.go:562` | → `DispatchMemoDeletedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync` |
| `UpdateMemo` | `server/router/api/v1/memo_service.go:513` | → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook` → `dispatchMemoRelatedWebhook` → `PostAsync` |
| `SetMemoRelations` | `server/router/api/v1/memo_relation_service.go:48` | → `dispatchMemoUpdatedSideEffects` → … → `PostAsync` |
| `SetMemoAttachments` | `server/router/api/v1/memo_attachment_service.go:48` | → `dispatchMemoUpdatedSideEffects` → … → `PostAsync` |
| `CreateMemoComment` | `server/router/api/v1/memo_service_comments.go:119` | → `DispatchMemoCommentCreatedWebhook` → `PostAsync` (direct) |

**Convergence.** All paths funnel into `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues to the worker pool that calls `Post` — the single function performing the actual HTTP delivery to the user-configured `hook.Url`.

Note there are two *app-level* fan-in helpers just above that point, both in `server/router/api/v1/memo_service_webhooks.go`: `dispatchMemoRelatedWebhook` (line 48) for created/updated/deleted, and `DispatchMemoCommentCreatedWebhook` (line 30) for comments (which uses the parent memo owner's webhooks). The comment path bypasses `dispatchMemoRelatedWebhook`, so the *only* function where every path truly converges before delivery is `webhook.PostAsync`/`Post`.

I checked `UpsertMemoReaction` and the webhook-CRUD handlers (`CreateUserWebhook`, etc.) — none dispatch a webhook.
