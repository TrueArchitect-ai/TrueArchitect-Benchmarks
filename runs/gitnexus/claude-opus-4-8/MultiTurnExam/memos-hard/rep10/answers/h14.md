Details:

- **Where computed** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) writes derived metadata into `memo.Payload` (`storepb.MemoPayload`). It does the extraction in a single markdown parse via `markdownService.ExtractAll` (`internal/markdown/markdown.go:356`), which walks the goldmark AST. This is metadata derived from content, not user-set, and it's stored in the memo `payload` column for list/preview use.

- **Triggers (recomputation)** — three call sites (`grep RebuildMemoPayload`):
  - `CreateMemo` — `server/router/api/v1/memo_service.go:108` (every new memo)
  - `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the branch that assigns `memo.Content = request.Memo.Content` (i.e. only when the content is being updated)
  - `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:52`, a batch pass that rebuilds every memo's payload (note: this runner/`RunOnce` isn't wired into production startup, so in practice it's the create/update handlers that drive live recomputation).

- **What it extracts** — from `ExtractAll`, assigned at `runner.go:85-86`:
  - `Payload.Tags` — the set of `#tags` found in the content, deduplicated preserving case.
  - `Payload.Property` (`storepb.MemoPayload_Property`, `proto/gen/store/memo.pb.go:85`):
    - `HasLink` — content contains a link (`internal/markdown/markdown.go`, `KindLink`)
    - `HasCode` — contains a code block/fence/inline code span
    - `HasTaskList` — contains a task checkbox
    - `HasIncompleteTasks` — contains at least one unchecked task
    - `Title` — text of a leading H1 heading, if the first block is one

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property`.)
