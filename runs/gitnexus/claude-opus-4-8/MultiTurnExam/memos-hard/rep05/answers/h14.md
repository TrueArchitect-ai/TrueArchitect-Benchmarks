**Computation site:** The derived metadata is the memo's `Payload` (a `storepb.MemoPayload` with `Tags` and `Property`). It's computed by `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, which calls the markdown service's `ExtractAll` (`internal/markdown/markdown.go:356`) to parse the content's goldmark AST in a single walk and writes the results onto `memo.Payload.Tags` / `memo.Payload.Property` (`runner.go:85-86`).

**Triggers (recomputation):** Both memo write RPCs invoke it after setting content:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (on the new memo).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but only when the content field is being changed (inside the `content` update-mask branch, right after `memo.Content = request.Memo.Content` at `:446`).

So it's recomputed whenever a memo is created or its content is updated (not for non-content updates like visibility/pin).

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:356-421`):
- `Tags` — the set of `#tags` in the content, deduplicated (case-preserving).
- `Property.Title` — text of the first block if it's an H1 heading (`:386-387`).
- `Property.HasLink` — a link node is present (`:394`).
- `Property.HasCode` — a code block / fenced code / code span is present (`:397`).
- `Property.HasTaskList` — contains a task checkbox (`:400`).
- `Property.HasIncompleteTasks` — contains at least one unchecked task checkbox (`:403`).

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload; mentions are used elsewhere for notifications.)
