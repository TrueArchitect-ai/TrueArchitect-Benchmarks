**Premise correction:** There is **no GraphQL schema** in this repository — the public API is not GraphQL. A repo-wide grep for `graphql` / `gqlgen` / `.graphql` across the sources and modules returns nothing, so there is no GraphQL schema file to point to.

**Actual API surface:** The public API is a **Protocol Buffers–defined gRPC / Connect (buf/connect-go) API**, version `v1`. The schema is defined in `.proto` files under `proto/api/v1/`, including:
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

These are compiled into Go under `proto/gen/api/v1/` and served over HTTP via Connect handlers — the RPC methods are implemented in `server/router/api/v1/` (e.g. `connect_services.go`), registered onto an HTTP mux and mounted at the `/memos.api.v1.*` route in `server/router/api/v1/v1.go:141-144`. So the API is request/response RPC methods (with a REST/JSON-over-HTTP mapping via Connect), not a GraphQL schema with types/queries/resolvers. (There is also a small non-API HTTP surface: an RSS feed under `server/router/rss/` and static frontend serving, but the programmatic "public API" is the proto-defined v1 services.)
