**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual HTTP POST executes at `webhook.go:152` via `safeClient.Do(req)`). Asynchronous dispatch is funneled through `PostAsync` (`webhook.go:184`) → a bounded queue → worker goroutines that also call `Post`.

**Protection mechanism:** SSRF guarding at dial time via `safeDialContext`, wired into the shared `safeClient`'s `http.Transport.DialContext` — `internal/webhook/webhook.go:59` (client defined at `webhook.go:32-37`). It resolves the target hostname and rejects any address in a reserved/private range using `isReservedIP` against `reservedNetworks` (loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents) — `internal/webhook/validate.go:44` / `validate.go:14-23`. Because the check runs at connection time on the resolved IP, it also defeats DNS-rebinding. There's an additional up-front check, `ValidateURL` (`internal/webhook/validate.go:62`), applied when webhook URLs are configured, and the guard can be disabled via the `AllowPrivateIPs` flag (`validate.go:41`) for local-network deployments.
