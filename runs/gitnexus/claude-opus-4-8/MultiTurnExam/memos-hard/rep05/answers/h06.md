**Convergence function before delivery:** `webhook.PostAsync` — `internal/webhook/webhook.go:184`. (If you want the point where the socket write happens rather than the enqueue point, that's `Post`; the single function where all the handler paths converge before hand-off to delivery is `PostAsync`.)
