- **Where delivery executes:** `Post` (`internal/webhook/webhook.go:120`) marshals the payload, builds the `POST` request, optionally adds an HMAC-SHA256 signature, and sends it via `safeClient.Do(req)` (line 152). (`PostAsync` at line 184 enqueues onto a bounded channel serviced by background workers that also call `Post`.)

- **What protects it from internal addresses (SSRF):** The `safeClient` uses a custom `http.Transport` whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:59`). At dial time it resolves the host and rejects the connection if any resolved IP matches `isReservedIP` — checking the *resolved* IPs rather than the URL string, so it also defeats DNS-rebinding. The core check `isReservedIP` and its `reservedCIDRs` list (loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, and IPv6 equivalents) live in `/bench/home/work/internal/webhook/validate.go` (line 44). There's also an up-front `ValidateURL` (`internal/webhook/validate.go:62`) used at webhook-registration time, and a global `AllowPrivateIPs` escape hatch for self-hosted deployments.
