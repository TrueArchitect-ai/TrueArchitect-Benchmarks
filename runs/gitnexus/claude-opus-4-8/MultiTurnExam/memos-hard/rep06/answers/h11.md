**1st: `User` (~6–9 packages); 2nd: `Memo` (~4–7 packages).**

Counting distinct non-test packages that reference each store-defined entity type (via `store.<Type>`):

- **`User`** is referenced from the most packages outside the data layer: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` (5 non-test server packages; 6 if including the v1 test helper package) — plus the three `store/db/*` drivers if those are counted as outside the `store` root.
- **`Memo`** is second: `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload` (4 server packages) — plus the three `store/db/*` drivers.

So regardless of whether the `store/db/{sqlite,postgres,mysql}` drivers are treated as inside or outside the data layer, the ranking holds: `User` first, `Memo` second. (Entity types like `Attachment`, `MemoShare`, and `Inbox` trail behind, each referenced from ~3–4 external packages.)
