**No.** The MySQL driver is never constructed directly outside the driver-selection factory.

Evidence:
- The MySQL constructor is `NewDB` at `store/db/mysql/mysql.go:20` (`func NewDB(profile *profile.Profile) (store.Driver, error)`).
- The driver-selection factory is `NewDBDriver` in `store/db/db.go:14`, which switches on `profile.Driver`.
- A repo-wide grep for `mysql.NewDB` returns exactly one call site: `store/db/db.go:22`, inside the `NewDBDriver` switch. There are no other call sites anywhere, including test files.

(For contrast, the sqlite constructor `sqlite.NewDB` *is* called directly in some tests, but the mysql constructor is not — its only caller is the factory.)
