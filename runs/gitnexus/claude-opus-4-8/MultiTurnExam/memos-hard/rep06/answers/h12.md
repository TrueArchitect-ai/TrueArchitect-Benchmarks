1. **Default driver = sqlite.** In `cmd/memos/main.go`, the `driver` config defaults to `"sqlite"` both via `viper.SetDefault("driver", "sqlite")` (line 122) and the persistent flag default `String("driver", "sqlite", ...)` (line 130). 3. **Concrete INSERT.** When a memo is saved, `Store.CreateMemo` delegates to `s.driver.CreateMemo`, which — given the sqlite driver — dispatches to `(*DB).CreateMemo` at `store/db/sqlite/memo.go:16`. That method builds and executes `INSERT INTO \`memo\` (...) VALUES (...) RETURNING ...` (line 41).

The mysql and postgres `CreateMemo` implementations exist but are unreachable on a default install because the factory never constructs those drivers.
