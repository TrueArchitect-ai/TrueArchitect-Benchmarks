**Premise correction: there is no GraphQL schema (or GraphQL API) in this repository.** Searching all `.go` files, `go.mod`, and the tree for `graphql` / `gqlgen` / `schema.graphql` returns zero matches — the project has no GraphQL surface at all.

**Actual API surface:** The public API is defined with **Protocol Buffers**, served over **gRPC / Connect** with a **gRPC-Gateway** REST/JSON transcoding layer. The schema lives in `.proto` files under `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, plus `common.proto`.

These are compiled to Go under `proto/gen/api/v1/`, and the handlers are registered in `server/router/api/v1/v1.go` — both the gRPC-Gateway mux (`RegisterMemoServiceHandlerServer`, etc., `v1.go:99-120`) and the Connect handlers (`RegisterConnectHandlers`, `v1.go:141`). So the "schema" for the public API is the protobuf service definitions in `proto/api/v1/*.proto`, not a GraphQL schema.
