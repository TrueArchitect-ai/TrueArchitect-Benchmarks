Distinct memo-visibility view-enforcement sites (each gates who may see a memo or its content), grouped by server surface:

**gRPC API v1 (`server/router/api/v1/`):**
- `checkMemoReadAccess` (central ACL helper: denies non-public to anon, `Private` to non-creators) — `server/router/api/v1/memo_service.go:39` (called from `GetMemo` :356/:367 and `CreateMemoComment` `memo_service_comments.go:148`)
- `ListMemos` (builds per-user `VisibilityList`/`creator_id` filter) — `server/router/api/v1/memo_service.go:218`
- `ListMemoRelations` (filters related memos by visibility) — `server/router/api/v1/memo_relation_service.go:107`
- `ListAllUserStats` / `GetUserStats` (visibility filter on stats aggregation) — `server/router/api/v1/user_service_stats.go:83` and `:216`
- `ListMemoReactions` (inline visibility gate) — `server/router/api/v1/reaction_service.go:29`; `UpsertMemoReaction` — `server/router/api/v1/reaction_service.go:83`
- `ListMemoAttachments` (visibility gate) — `server/router/api/v1/memo_attachment_service.go:214`
- `checkAttachmentAccess` (gates attachment binary by owning memo's visibility) — `server/router/api/v1/attachment_service.go:422` (from `GetAttachmentBinary` :256)
- `SSEClient.canReceive` (real-time delivery gate: `Private` events only to creator/admin) — `server/router/api/v1/sse_hub.go:134`

**RSS (`server/router/rss/`):**
- `GetRSS` / `GetUserRSS` (restrict feed to `VisibilityList = [Public]`) — `server/router/rss/rss.go:88` and `:138`

**File server (`server/router/fileserver/`):**
- `checkAttachmentPermission` (serving raw attachments: `Private` denied to non-creator/non-admin, else share-token/auth) — `server/router/fileserver/fileserver.go:650` (from the attachment handler :149)

**Frontend SSR (`server/router/frontend/`):**
- `frontend.go` (server-rendered/robots pages list only `VisibilityList = [Public]`) — `server/router/frontend/frontend.go:150`

The three headline surfaces are the gRPC API v1 (`checkMemoReadAccess` + `ListMemos` filtering in `memo_service.go`), the RSS service (`rss/rss.go`), and the file server (`checkAttachmentPermission` in `fileserver/fileserver.go`); the remaining sites above are the additional distinct enforcement points. (Excluded: mention/notification suppression for `Private` memos in `memo_mention_helpers.go` and share/relation *mutation* ownership checks — those aren't view-access enforcement.)
