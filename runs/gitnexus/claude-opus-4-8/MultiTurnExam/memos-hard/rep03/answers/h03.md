**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic `IdentityProviderUserInfo` type that any identity provider returns.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete protocol implementation that ships, an `IdentityProvider` backed by OAuth2 (`golang.org/x/oauth2`, configured via `storepb.OAuth2Config`). It's the only subpackage under `internal/idp/`.
