**Premise correction:** There is no GraphQL API in this codebase. There is no `.graphql`/`.gqls` schema file anywhere, no `gqlgen` or other GraphQL dependency in `go.mod`, and no GraphQL server, schema, or resolvers in the Go source. (The two `grep` hits for the substring were incidental — `LookupHost`/`LookupIPAddr` calls — not GraphQL.)

**Actual API surface:** The public API is defined as **Protocol Buffers gRPC services**, exposed over both gRPC and REST via **grpc-gateway**:
- Schema/definitions: `proto/api/v1/*.proto` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto` (with shared `common.proto`).
- Generated Go code: `proto/gen/api/v1/` (`*.pb.go`, gRPC `*_grpc.pb.go`, and gateway `*.pb.gw.go` for the REST mapping).
- Server wiring: the gRPC services and the grpc-gateway HTTP mux are registered in `server/router/api/v1/v1.go` (gateway middleware at `v1.go:69`, `RegisterHandler`/`WithMiddlewares` at `v1.go:97`). Additional non-gRPC HTTP surfaces are the file server (`server/router/fileserver/`), RSS (`server/router/rss/`), MCP (`server/router/mcp/`), and the frontend SPA (`server/router/frontend/`).
- Access-control for these RPCs is declared in `server/router/api/v1/acl_config.go`.

So the "public API" is a protobuf-defined gRPC + REST (grpc-gateway) surface, not GraphQL.
