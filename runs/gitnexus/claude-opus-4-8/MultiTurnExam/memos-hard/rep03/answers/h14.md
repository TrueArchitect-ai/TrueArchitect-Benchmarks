**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It runs the memo's content through `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`) in a single goldmark AST walk and writes the results into `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85-86). This payload is server-derived from content, not user-set, and is what lists/previews read.

**Triggers (operations that recompute):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (on every new memo).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447` (recomputed when content changes).
- Batch backfill `Runner.RunOnce` — `server/runner/memopayload/runner.go:52` (rebuilds the payload of all memos, e.g. a migration/reindex pass).

**Extracted properties** (from `ExtractAll` → `ExtractedData`, stored in `MemoPayload_Property`, `proto/gen/store/memo.pb.go:85-95`):
- `Tags` — the list of `#tag` tokens found in the content (runner.go:85).
- `Property.HasLink` — content contains a link.
- `Property.HasTaskList` — content contains a task list.
- `Property.HasCode` — content contains code.
- `Property.HasIncompleteTasks` — content has unchecked task items.
- `Property.Title` — the title taken from the first block-level H1 heading, if present (`internal/markdown/markdown.go:383-386`).

(Note: `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists `Tags` and `Property` into the memo payload.)
