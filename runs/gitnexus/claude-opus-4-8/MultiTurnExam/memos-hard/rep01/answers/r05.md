**Premise correction:** There is no GraphQL schema in this project. A repo-wide search for `graphql`, `gqlgen`, and `*.graphql`/`schema.graphql` files returns zero matches — the public API is not GraphQL.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC services** under `proto/api/v1/`, one `.proto` per service, e.g.:
- `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/ai_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/common.proto` (plus internal storage messages in `proto/store/*.proto`).

Code is generated from these via `buf` (`proto/buf.yaml`, `proto/buf.gen.yaml`) into `proto/gen/`. At runtime the schema is exposed over three compatible transports, wired in `server/router/api/v1/v1.go`:
- **Connect-RPC / gRPC** handlers with interceptors — `server/router/api/v1/v1.go:133-141`
- **gRPC-Gateway** providing a RESTful/JSON HTTP mapping — `server/router/api/v1/v1.go:95-97`
- An embedded **OpenAPI** document for the REST surface — `proto/openapi_embed.go`

So the "schema" for the public API lives in the `.proto` files under `proto/api/v1/`, served as Connect/gRPC + REST (gRPC-Gateway) with OpenAPI docs — not GraphQL.
