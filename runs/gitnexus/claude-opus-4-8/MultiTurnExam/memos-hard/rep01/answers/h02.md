**Delivery function** — `Post` in `internal/webhook/webhook.go` (the outbound HTTP POST actually executes at `internal/webhook/webhook.go:152`, `resp, err := safeClient.Do(req)`; `PostAsync` at line 184 just enqueues onto a bounded channel drained by 4 worker goroutines that all call `Post`).

**Protection mechanism** — dial-time SSRF guard `safeDialContext` in `internal/webhook/webhook.go:59-77`, installed as the `DialContext` of the shared `safeClient` transport (`internal/webhook/webhook.go:32-37`). It resolves the target host and rejects any address in a reserved/private range via `isReservedIP` in `internal/webhook/validate.go:44-54` (CIDR list at `internal/webhook/validate.go:14-23` — loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents). Because the check happens at dial time on the resolved IP, it also defeats DNS-rebinding. 

A secondary, up-front check exists in `ValidateURL` (`internal/webhook/validate.go:62-83`), run when a webhook URL is registered, but the runtime protection on actual delivery is `safeDialContext`. Both can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41,45-47`) for self-hosted setups.
