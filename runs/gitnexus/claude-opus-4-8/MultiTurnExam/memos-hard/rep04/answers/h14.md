**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`), which delegates the actual content parsing to the goldmark-backed `service.ExtractAll` (`internal/markdown/markdown.go`). It writes the results onto `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`, defined in `proto/gen/store/memo.pb.go:85`). This metadata is derived from the memo's markdown content, not supplied by the user.

**Triggers (recomputation)** — three call sites invoke `RebuildMemoPayload`:
- **Memo creation** — `APIV1Service.CreateMemo`, `server/router/api/v1/memo_service.go:108`.
- **Memo content update** — `APIV1Service.UpdateMemo`, `server/router/api/v1/memo_service.go:447`, but only inside the `content_url`/content-change branch (it runs after `memo.Content = request.Memo.Content`), so it recomputes only when the content field is actually being updated.
- **Bulk backfill** — `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) re-derives it for every memo in batches (a maintenance/rebuild pass; note this `Runner` type is not itself wired into startup).

**Extracted properties** — a single AST walk in `ExtractAll` produces:
- `Tags` — the set of `#tags` found in the content, deduplicated (case preserved). (`ExtractedData.Tags` → `Payload.Tags`.)
- `Property.HasLink` — true if any markdown link node is present.
- `Property.HasCode` — true if any code block, fenced code block, or inline code span is present.
- `Property.HasTaskList` — true if any task-list checkbox is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
- `Property.Title` — the text of the document's first block if it is an H1 heading.

(`ExtractAll` also collects `Mentions` from `@username` nodes, but `RebuildMemoPayload` only persists `Tags` and `Property` onto the payload.)
