**No.** The MySQL store driver is constructed only inside the driver-selection factory, nowhere else.

Evidence:
- The factory `NewDBDriver` in `store/db/db.go:22` is the sole call site of `mysql.NewDB(profile)` (a repo-wide `grep` for `mysql.NewDB` returns exactly that one line).
- `store/db/db.go` is the only file that imports the `store/db/mysql` package (`grep` for `store/db/mysql"` yields only `store/db/db.go`), so no other file can reference its constructor.
- The MySQL driver's only public constructor is `mysql.NewDB` (`store/db/mysql/mysql.go:20`), and its `DB` struct (`store/db/mysql/mysql.go:14`) is never instantiated via a struct literal anywhere — a search for `mysql.DB`/`mysql.New` across the codebase (excluding `node_modules`) surfaces only the single factory line.

(Note: this concerns the memos `store.Driver` MySQL implementation; the underlying `go-sql-driver/mysql` SQL driver is registered separately via its database/sql import and is a different layer.)
