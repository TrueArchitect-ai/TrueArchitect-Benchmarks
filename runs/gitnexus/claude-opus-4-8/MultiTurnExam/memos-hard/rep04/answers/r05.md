**Premise correction:** There is no GraphQL API in this project. A repo-wide search for `graphql`/`GraphQL`/`gqlgen` and for `*.graphql`/`*.gql` files returns nothing — no schema, no resolvers, no GraphQL server. So there is no GraphQL schema to locate.

**Actual API surface:** The public API is defined with **Protocol Buffers**, served over gRPC / Connect with a gRPC-Gateway REST bridge. The service and message definitions (the actual "schema") live in `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`.

These are compiled into Go under `proto/gen/api/v1/` (message/gRPC stubs `*.pb.go`, gRPC-Gateway REST bindings `*.pb.gw.go`, and Connect handlers under `proto/gen/api/v1/apiv1connect/`). The server wires them up in `server/router/api/v1/v1.go` (Connect handlers registered at server/router/api/v1/v1.go:141, and the gRPC-Gateway/REST gateway registered in the same file). So the API is defined by the `.proto` files in `proto/api/v1/`, not a GraphQL schema.
