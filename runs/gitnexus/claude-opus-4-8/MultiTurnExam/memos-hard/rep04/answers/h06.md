**RPC handler methods that can transitively trigger an outbound HTTP request to a user-configured webhook URL** (all in `server/router/api/v1/`):

1. `CreateMemo` — `memo_service.go:157` → `DispatchMemoCreatedWebhook`
2. `UpdateMemo` — `memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
3. `DeleteMemo` — `memo_service.go:562` → `DispatchMemoDeletedWebhook`
4. `CreateMemoComment` — `memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
5. `SetMemoRelations` — `memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
6. `SetMemoAttachments` — `memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

**Convergence function — `webhook.PostAsync`, `internal/webhook/webhook.go:184`.** Every one of the above paths ends at a `webhook.PostAsync(payload)` call — the memo create/update/delete/relation/attachment paths reach it via `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:71`), and the comment path reaches it directly from `DispatchMemoCommentCreatedWebhook` (`memo_service_webhooks.go:43`). `PostAsync` enqueues onto the shared async queue, whose workers invoke `Post` (`internal/webhook/webhook.go:120`), where `safeClient.Do(req)` (`webhook.go:152`) performs the actual outbound delivery.

(If "before delivery" is read as the last function *before the HTTP send itself* rather than the last shared enqueue point, that is `webhook.Post` at `internal/webhook/webhook.go:120`. All handler paths pass through both `PostAsync` and then `Post`; `PostAsync` is the single point where the handler-side paths first converge.)
