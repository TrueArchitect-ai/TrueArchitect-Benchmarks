This project ships migrations for three SQL dialects, organized as subdirectories under `store/migration/`:

**postgres, sqlite, mysql**

Evidence — each dialect has its own migration tree with a `LATEST.sql` and versioned directories:
- `store/migration/postgres/LATEST.sql`
- `store/migration/sqlite/LATEST.sql`
- `store/migration/mysql/LATEST.sql`
