**delivery function** — `Post` (and its async variant `PostAsync`) in `internal/webhook/webhook.go`. `Post` builds the `POST http.NewRequest` to the configured webhook URL and sends it via the shared `safeClient` (`safeClient.Do(req)`). It's fed by the `DispatchMemo*Webhook` functions in `server/router/api/v1/memo_service_webhooks.go` when a memo is created/updated/commented.

**protection mechanism** — SSRF protection via reserved/private-IP blocking keyed on `isReservedIP`, in two layers:
- Dial-time enforcement: `safeDialContext` in `internal/webhook/webhook.go`, installed as the `safeClient` transport's `DialContext`. It resolves the target host at connection time and refuses to dial any reserved/private IP (this also defeats DNS rebinding).
- Config/validation-time: `ValidateURL` (backed by `isReservedIP`) in `internal/webhook/validate.go`, which enforces http/https and rejects URLs resolving to loopback/RFC-1918/link-local/IPv6 private ranges.

Note there's an escape hatch: `AllowPrivateIPs` in `internal/webhook/validate.go`, which when true makes `isReservedIP` always return false, disabling both layers (intended for self-hosted local-network use).

Summary line:
delivery function — `internal/webhook/webhook.go` (`Post`/`PostAsync`, sent through `safeClient`); protection mechanism — `internal/webhook/webhook.go` (`safeDialContext` dial-time block) and `internal/webhook/validate.go` (`ValidateURL`/`isReservedIP`)
