**No.** The MySQL driver is only ever constructed inside the driver-selection factory.

Evidence:
- The MySQL driver type is `DB` in `store/db/mysql/mysql.go:14`, and its sole exported constructor is `func NewDB(...)` at `store/db/mysql/mysql.go:20`.
- The driver-selection factory is `NewDBDriver` in `store/db/db.go:14`, which switches on `profile.Driver` and calls `mysql.NewDB(profile)` at `store/db/db.go:22`.
- Grepping the whole repo for `mysql.NewDB` returns exactly one hit — that same line (`store/db/db.go:22`). No other call site exists.
- The test harness does not construct it directly either: `store/test/store.go:28` and `:50` both go through `db.NewDBDriver(profile)`. (The `mysql.Run` / `mysql.With...` calls in `store/test/containers.go` are from the testcontainers-go `modules/mysql` package spinning up a MySQL container, not the memos MySQL driver.)

So outside `NewDBDriver`, the MySQL driver is never constructed directly.
