h11.

The persistent entity types live in the data layer package `store/` (e.g. `store.User` in `store/user.go`, `store.Memo` in `store/memo.go`, plus `Attachment`, `Inbox`, `Reaction`, `MemoRelation`, etc.). Counting distinct Go packages *outside* `store/` that reference each type:

**1st: `User` (~7 packages)** — referenced from `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.

**2nd: `Memo` (~6 packages)** — referenced from `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.

(For reference, the next tier drops off sharply: `Attachment` ~4 packages, then `Inbox`/`MemoRelation`/`MemoShare` ~3 each.)

Cited: `store/user.go`, `store/memo.go` (type definitions); reference packages under `server/`.
