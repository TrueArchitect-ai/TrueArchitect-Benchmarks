**Delivery function — `Post` at `internal/webhook/webhook.go:120` (the actual outbound request fires at `safeClient.Do(req)`, line 152; workers pull from the async queue via `PostAsync`/the `init` goroutines).**

**Protection mechanism — `safeDialContext` at `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (lines 32–37).** On every dial it re-resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), whose ranges come from `reservedCIDRs`/`reservedNetworks` (`internal/webhook/validate.go:14`). Because the check happens at *dial* time on the resolved IP — not just on the string URL — it also defeats DNS-rebinding.

Notes:
- There is a second, earlier guard, `ValidateURL` (`internal/webhook/validate.go:62`), used when a webhook URL is registered — it validates scheme and that the hostname doesn't resolve to a reserved IP. But the guard that protects the *actual delivery* is `safeDialContext`.
- Both checks can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`), intended for self-hosted deployments targeting local-network services.
