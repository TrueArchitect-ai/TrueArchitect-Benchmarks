**Which RPC handlers can transitively trigger an outbound HTTP request to a user-configured URL**

The user-configured URLs are webhook endpoints stored per-user (`hook.Url` from `s.Store.GetUserWebhooks`). All memo mutation RPCs on `APIV1Service` fan out into `Dispatch*Webhook` helpers (`server/router/api/v1/memo_service_webhooks.go`), which enqueue the URL for delivery:

- **`CreateMemo`** — `server/router/api/v1/memo_service.go:157` → `DispatchMemoCreatedWebhook`
- **`DeleteMemo`** — `server/router/api/v1/memo_service.go:562` → `DispatchMemoDeletedWebhook`
- **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:119` → `DispatchMemoCommentCreatedWebhook`
- **`UpdateMemo`** — `server/router/api/v1/memo_service.go:513` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- **`SetMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`
- **`SetMemoRelations`** — `server/router/api/v1/memo_relation_service.go:48` → `dispatchMemoUpdatedSideEffects` → `DispatchMemoUpdatedWebhook`

(That's six handlers; any three of the above satisfy the ask, e.g. `CreateMemo`, `DeleteMemo`, `CreateMemoComment`.)

**Convergence function**

Every dispatch helper calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the queue's worker goroutines (and any synchronous path) all call **`webhook.Post`** — `internal/webhook/webhook.go:120`. `Post` is the single function where all these paths converge: it marshals the payload, HMAC-signs it, and issues the actual request via `safeClient.Do(req)` to `requestPayload.URL`.

So: **handlers** = `CreateMemo`, `UpdateMemo`, `DeleteMemo`, `CreateMemoComment`, `SetMemoAttachments`, `SetMemoRelations`; **convergence function** = `webhook.Post` — `internal/webhook/webhook.go:120`.
