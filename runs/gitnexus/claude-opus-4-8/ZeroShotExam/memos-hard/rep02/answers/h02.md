**Delivery function** — `Post` in `internal/webhook/webhook.go` (≈lines 119–180). It marshals the `WebhookRequestPayload` to JSON, builds the HTTP POST to the webhook URL, adds optional HMAC-SHA256 signature headers, and sends it via the shared `safeClient` (`safeClient.Do(req)`). The fire-and-forget path is `PostAsync`, which enqueues onto a bounded channel drained by 4 worker goroutines that each call `Post`. Callers live in `server/router/api/v1/memo_service_webhooks.go` (`DispatchMemoCreatedWebhook`, etc.).

**Protection mechanism** — SSRF protection against internal addresses, in two layers keyed on `isReservedIP`:

- **Dial-time IP blocking (primary defense)** — `internal/webhook/webhook.go`: the `safeClient`'s transport uses a custom `safeDialContext` (≈lines 59–77) that resolves the target host and refuses to connect if any resolved address is a reserved/private IP. Because the check runs on the same resolution used to dial, it also defeats DNS-rebinding (TOCTOU).
- **Registration-time URL validation** — `internal/webhook/validate.go`: `ValidateURL` (≈lines 62–83) rejects non-http(s) schemes and URLs resolving to reserved IPs when a webhook is created/updated. The blocklist (`reservedCIDRs` / `isReservedIP`, lines 11–54) covers IPv4 loopback, RFC-1918 ranges, link-local `169.254.0.0/16` (cloud IMDS), and IPv6 `::1`, `fc00::/7`, `fe80::/10`.

Caveat: a global `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` to always return false, disabling *both* layers — an intentional escape hatch for self-hosted setups targeting local services.
