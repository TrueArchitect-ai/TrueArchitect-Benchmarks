**Delivery function** — `Post` in `internal/webhook/webhook.go` (lines ~119–180). This builds the request (`http.NewRequest("POST", requestPayload.URL, ...)`, line 126) and executes the outbound delivery via `safeClient.Do(req)` (line 152). `PostAsync` and a worker pool feed into it, but `Post` is where the HTTP request actually goes out.

**Protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go` (lines ~59–77), wired into `safeClient`'s `http.Transport.DialContext` (lines 32–37). Because it runs at *dial time* on every connection, it resolves the host and rejects any IP that `isReservedIP` flags (loopback, RFC-1918 private ranges, `169.254.0.0/16` link-local/IMDS, and IPv6 equivalents), which also defeats DNS-rebinding. A second, up-front layer, `ValidateURL` in `internal/webhook/validate.go` (lines ~62–83), applies the same `isReservedIP` check (blocklist `reservedCIDRs`, lines 14–23) when a webhook URL is created/configured.

Caveat: both layers funnel through `isReservedIP`, which is globally disabled when the package-level `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) is set to `true`.
