**Yes.** The MySQL driver is constructed directly outside the driver-selection factory — in exactly one place: a unit test.

Evidence:

- **Factory:** `store/db/db.go` — `NewDBDriver` switches on `profile.Driver` and, for the `"mysql"` case, calls `mysql.NewDB(profile)` (`store/db/db.go:22`). The canonical constructor lives at `store/db/mysql/mysql.go:29` (`driver := DB{profile: profile}` → returns `&driver`). This is the only `mysql.NewDB` call in the repo.

- **Construction outside the factory:** `store/db/mysql/auth_config_test.go:12` builds a zero-value driver directly:
  ```go
  db := &DB{}
  require.True(t, db.IsRetryableAuthenticationMutationError(...))
  ```
  It bypasses `mysql.NewDB` because it only exercises the pure `IsRetryableAuthenticationMutationError` method (error-code classification), which needs no live connection or profile.

No other direct construction of the MySQL driver (`store/db/mysql.DB`) exists — not in migration tooling (`store/migration/`), CLI (`cmd/`), or elsewhere. The only non-factory site is that test.
