**Computation site**

- `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74` sets `memo.Payload.Tags` and `memo.Payload.Property` from a single markdown parse.
- The actual extraction is `service.ExtractAll` in `internal/markdown/markdown.go:356` (one goldmark AST walk).

**Triggers (recomputation)**

- On memo create — `server/router/api/v1/memo_service.go:108` (in `CreateMemo`).
- On memo content update — `server/router/api/v1/memo_service.go:447` (the `content` update path; the payload is only rebuilt when content changes, and the new payload is written via `update.Payload`).
- Bulk backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` rebuilds the payload for *all* memos in batches of 100, persisting each via `UpdateMemo`.

(Note: the `location` update path at `memo_service.go:482` mutates `Payload.Location` directly but does not re-run the content extraction, since location isn't content-derived.)

**Extracted properties**

Into `MemoPayload` (`proto/gen/store/memo.pb.go`):
- `Tags` — deduplicated `#tag` list (case preserved).
- `Property.HasLink` — a markdown link is present.
- `Property.HasCode` — a code block/fenced block/inline code span is present.
- `Property.HasTaskList` — a task checkbox is present.
- `Property.HasIncompleteTasks` — an unchecked task checkbox is present.
- `Property.Title` — text of a leading level-1 (H1) heading, if the document's first block is one.

(`ExtractAll` also collects `Mentions`, but that field is not copied into the payload by `RebuildMemoPayload`.)
