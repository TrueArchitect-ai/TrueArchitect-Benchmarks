Memo visibility (who may view a memo) is enforced independently across many server surfaces — there is no single interceptor; each RPC/endpoint re-checks `memo.Visibility` + `CreatorID`. The distinct enforcement sites:

Single-memo read access (GetMemo, comment reads) — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`, lines 39–67)
List-memo visibility scoping — `server/router/api/v1/memo_service.go` (`ListMemos`, lines 218–227)
Attachment file/blob stream endpoint — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission`, lines 649–703)
GetAttachment RPC binary access — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess`, lines 422–455)
ListMemoAttachments RPC — `server/router/api/v1/memo_attachment_service.go` (`ListMemoAttachments`, visibility check lines 213–224)
RSS feeds (Public-only scoping) — `server/router/rss/rss.go` (`GetExploreRSS` line 90, `GetUserRSS` line 141)
Frontend sitemap (Public-only scoping) — `server/router/frontend/frontend.go` (`getSitemapXML`, line ~150)
Memo reactions — `server/router/api/v1/reaction_service.go` (`ListMemoReactions` lines 29–40, `UpsertMemoReaction` lines 83–85)
Memo comments — `server/router/api/v1/memo_service_comments.go` (`CreateMemoComment` line 41; `ListMemoComments` → `checkMemoReadAccess`)
User stats aggregates (VisibilityList clamping) — `server/router/api/v1/user_service_stats.go` (`ListAllUserStats` line 84, `GetUserStats` line 218)
SSE real-time event delivery — `server/router/api/v1/sse_hub.go` (`SSEClient.canReceive`, lines 133–144)

The three most central "who may view a memo" surfaces are the first three (core memo read, attachment blob serving, and RSS/sitemap feeds); the remainder extend the same visibility rule to memo-derived data (attachments, reactions, comments, stats, live events). The `store.Private && CreatorID != user.ID && !isSuperUser(user)` pattern is duplicated at each — a decentralized design where all sites must be kept in sync. Not view-gating (creator-only writes / notification routing, excluded): `memo_mention_helpers.go`, `user_service_notifications.go`, `notification/email.go`, `memo_share_service.go`, `memo_relation_service.go`.
