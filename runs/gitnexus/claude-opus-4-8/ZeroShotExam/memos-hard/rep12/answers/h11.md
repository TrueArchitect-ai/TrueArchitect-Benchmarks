**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package (`store/`), which defines the persistent entity types (`User`, `Memo`, `Attachment`, `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, `IdentityProvider`, `UserIdentity`, `UserSetting`, `InstanceSetting` — all in files like `store/user.go`, `store/memo.go`).

Counting distinct Go packages *outside* the `store/` subtree (excluding the `store/db/*` drivers and `store/test`, which are part of the data layer itself) that reference each type via `store.<Type>`:

**`store.User` — 7 packages** (top):
- `server/auth`
- `server/notification`
- `server/router/api/v1`
- `server/router/api/v1/test`
- `server/router/fileserver`
- `server/router/frontend`
- `server/router/rss`

**`store.Memo` — 6 packages** (runner-up):
- `server/notification`
- `server/router/api/v1`
- `server/router/api/v1/test`
- `server/router/frontend`
- `server/router/rss`
- `server/runner/memopayload`

The next-closest is `store.Attachment` at 4 packages, so `User` and `Memo` are clearly the top two. `User` edges out `Memo` mainly because it's additionally referenced by the auth and fileserver packages (session/permission handling and per-user file serving).
