h03.
`internal/idp` (package `idp`, in `internal/idp/idp.go`); `internal/idp/oauth2` (package `oauth2`, in `internal/idp/oauth2/oauth2.go`)

The `internal/idp` package defines the provider abstraction — `internal/idp/idp.go` declares the shared `IdentityProviderUserInfo` type that every provider must return. The only concrete protocol implementation that ships is the OAuth2 one in `internal/idp/oauth2/oauth2.go` (file header: "Package oauth2 implements the OAuth2 identity provider integration"), which builds an `IdentityProvider` from a `storepb.OAuth2Config`.
