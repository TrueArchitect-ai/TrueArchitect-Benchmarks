The S3 presign runner is exactly this. It refreshes S3 presigned URLs (the `Reference` field / external link for S3-backed attachments) before they expire, re-presigning any whose `LastPresignedTime` is older than ~4 days.

h01.
**`s3presign.Runner`** (`server/runner/s3presign/runner.go`) — runs **once immediately at startup, then every 12 hours** (`runnerInterval = time.Hour * 12`, `runner.go:27`; the ticker loop in `Run`, `runner.go:29-41`) — wired in **`server/server.go:162-169`** inside `Server.startBackgroundRunners` (`RunOnce` at `server/server.go:163`, continuous `Run` goroutine at `server/server.go:169`).

How it works: `CheckAndPresign` (`runner.go:47`) lists S3-storage attachments and, for any whose presigned URL is within its validity window (skips those still good for the next 4 days, `runner.go:86-88`), regenerates the presigned URL via `PresignGetObject` and updates the attachment's `Reference` plus `LastPresignedTime` (`runner.go:108-124`). That `Reference` is what surfaces as the attachment's `ExternalLink` (`server/router/api/v1/attachment_service_storage.go:40`), so refreshing it keeps those external links from going stale.
