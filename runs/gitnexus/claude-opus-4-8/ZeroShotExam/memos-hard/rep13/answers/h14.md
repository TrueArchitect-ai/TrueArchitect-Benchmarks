**Extracted properties:** derived by a single goldmark AST walk in `ExtractAll` (`internal/markdown/markdown.go:383-408`):
- `HasLink` — a link node exists (`gast.KindLink`).
- `HasCode` — any code block/fenced code/inline code span exists.
- `HasTaskList` — a task checkbox exists.
- `HasIncompleteTasks` — a task checkbox that is unchecked exists.
- `Title` — text of the document's first block-level child if it is an H1 heading.

(The same walk also derives `Payload.Tags`, deduplicated with case preserved; `Mentions` are extracted too but not stored in `Property`.)
