**Answer:** `internal/idp` (abstraction); `internal/idp/oauth2` (implementation)

- **Abstraction package:** `internal/idp` — `internal/idp/idp.go` defines the provider-agnostic `IdentityProviderUserInfo` struct (the normalized user-info shape every identity provider must produce).
- **Concrete implementation package:** `internal/idp/oauth2` — `internal/idp/oauth2/oauth2.go` is the only shipped protocol implementation. Its header comment reads "Package oauth2 implements the OAuth2 identity provider integration," and it provides `IdentityProvider` / `NewIdentityProvider` built on `golang.org/x/oauth2`, importing the `internal/idp` abstraction.

OAuth2 is the sole concrete provider that ships under `internal/idp/` (no sibling `oidc`/`saml` package exists).
