**delivery function** — `Post` at `internal/webhook/webhook.go:120` (it does the actual `safeClient.Do(req)` at line 152). It's invoked by the 4 background worker goroutines that drain `asyncPostQueue`, fed via `PostAsync` (`internal/webhook/webhook.go:184`) when memo content changes.

**protection mechanism** — `safeDialContext` at `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (lines 32–37). At connection (dial) time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), backed by the `reservedCIDRs` list (loopback, RFC-1918, `169.254.0.0/16` cloud IMDS, and IPv6 equivalents) in `internal/webhook/validate.go:14`. Because the check happens at dial time against the freshly-resolved IP, it also defeats DNS-rebinding.

Supporting (config-time, not the delivery-time guard): `ValidateURL` at `internal/webhook/validate.go:62` rejects non-http(s) schemes and reserved-IP hostnames when a webhook URL is first registered. Note both guards can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted local-network targets.
