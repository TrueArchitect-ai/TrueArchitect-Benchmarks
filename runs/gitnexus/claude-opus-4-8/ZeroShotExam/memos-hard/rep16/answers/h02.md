Delivery function — `Post` in `/bench/home/work/internal/webhook/webhook.go` (lines ~119–180) is where the outbound webhook actually executes: it builds the `POST` request to the external URL and fires it via `safeClient.Do(req)`. Delivery is fanned out through `PostAsync`/worker goroutines, but every request ultimately runs through `Post` using the shared `safeClient`.

Protection mechanism — SSRF protection is enforced at dial time by `safeDialContext` in `/bench/home/work/internal/webhook/webhook.go` (lines ~57–77), which is wired into `safeClient.Transport.DialContext`. It resolves the target host and rejects any connection whose resolved IP falls in a reserved/private range, using `isReservedIP` in `/bench/home/work/internal/webhook/validate.go` (lines ~44–54, matching the `reservedCIDRs` covering loopback, RFC-1918, link-local/IMDS `169.254.0.0/16`, IPv6 ULA/link-local, etc.). Because the check runs on the actual dialed IP, it also defeats DNS-rebinding. A secondary admission-time check, `ValidateURL` (`validate.go`, ~62–83), applies the same predicate when a webhook URL is created/updated. (A package flag `AllowPrivateIPs` can disable this for self-hosted setups.)
