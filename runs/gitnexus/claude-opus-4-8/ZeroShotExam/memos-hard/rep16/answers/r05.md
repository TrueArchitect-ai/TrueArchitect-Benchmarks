**Premise correction:** There is no GraphQL schema in this repository. Memos does not expose a GraphQL API at all. The premise that the public API is defined in GraphQL is incorrect.

**Actual API surface:** The public API is defined as **Protocol Buffers (gRPC)**, with a REST/HTTP layer generated on top via grpc-gateway and OpenAPI.

- The `.proto` service/message definitions live in **`proto/api/v1/`**, e.g.:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - plus `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, and shared types in `common.proto`
- Store-layer protos: `proto/store/`
- Build config for codegen: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`
- Generated Go stubs: `proto/gen/`
- REST/OpenAPI: `proto/openapi_embed.go` (the OpenAPI spec is embedded), reflecting the grpc-gateway REST surface.

The README confirms this: Memos provides "full **REST and gRPC APIs**" (README.md, Features section) — no GraphQL.
