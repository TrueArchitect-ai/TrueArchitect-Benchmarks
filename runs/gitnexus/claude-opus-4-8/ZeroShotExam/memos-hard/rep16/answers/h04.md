**yes** — but only in test code, not in production.

- The driver-selection factory is `NewDBDriver` at `store/db/db.go:14`; its MySQL branch calls `mysql.NewDB(profile)` at `store/db/db.go:22`.
- The MySQL driver is the `store/db/mysql.DB` struct, and its normal constructor `mysql.NewDB` (`store/db/mysql/mysql.go:20`) builds it internally at `store/db/mysql/mysql.go:29` (`driver := DB{profile: profile}`). This is the code path the factory invokes.
- **Outside** that factory/constructor path, the MySQL driver struct is constructed directly exactly once: in a unit test at `store/db/mysql/auth_config_test.go:12` — `db := &DB{}` — a bare struct literal created purely to call a method (`TestIsRetryableAuthenticationMutationError`), with no DB connection.

So in production code the MySQL driver is only ever built through the factory (via `mysql.NewDB`); the sole direct-construction outside it is that one test.
