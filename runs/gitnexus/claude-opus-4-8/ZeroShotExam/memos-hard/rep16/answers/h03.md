The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the provider-agnostic `IdentityProviderUserInfo` type shared across identity providers. The only concrete protocol implementation that ships is OAuth2, in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`), whose doc comment reads *"Package oauth2 implements the OAuth2 identity provider integration."*

**Answer:** `internal/idp`; `internal/idp/oauth2`
