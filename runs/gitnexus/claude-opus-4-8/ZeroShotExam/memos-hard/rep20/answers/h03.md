The single concrete protocol implementation that ships is **`internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`) — its package doc comment reads "Package oauth2 implements the OAuth2 identity provider integration," and it defines an `IdentityProvider` backed by `storepb.OAuth2Config`.
