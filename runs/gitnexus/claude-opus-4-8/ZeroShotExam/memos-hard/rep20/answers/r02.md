**Premise correction: memos has no per-user API rate-limiting middleware at all — none is registered anywhere, so there are no request limits to report.**

I searched the entire Go backend for any rate limiter (`rate`, `ratelimit`, `throttle`, `limiter`, `429`/`TooManyRequests`, `golang.org/x/time/rate`, `tollbooth`, etc.) and found none. `golang.org/x/time` is present in `go.mod` only as an `// indirect` transitive dependency; no source file imports `golang.org/x/time/rate`. The only textual match is an aspirational doc comment ("Rate limit email sending to prevent abuse") at `internal/email/doc.go:86`, which is not implemented.

**What request middleware/interceptors actually exist (none throttle by rate):**

- **Echo HTTP server** — `server/server.go:51-52`: `middleware.Recover()` and `newCORSMiddleware` (CORS defined in `server/cors.go:13`).
- **gRPC-Gateway (REST `/api/v1/*`)** — `server/router/api/v1/v1.go:69-97`: `gatewayAuthMiddleware` does authentication/access-policy only (401, never 429).
- **Connect RPC interceptors** — `server/router/api/v1/connect_interceptors.go`, chained at `v1.go:133-138`: metadata, logging, recovery, and auth interceptors. Again, no throttling.

**The only numeric "limits" in the request path are not rate limits:**

- **Request body size cap: 256 MiB** — `maxAPIRequestBytes = 256 << 20` (`server/router/api/v1/v1.go:20`), enforced via `http.MaxBytesHandler` (`v1.go:126,144`) and `connect.WithReadMaxBytes` (`v1.go:141`). This bounds payload size, not request frequency.
- **Concurrency semaphores** — `thumbnailSemaphore = semaphore.NewWeighted(3)` and `imageProcessingSemaphore = semaphore.NewWeighted(2)` (`v1.go:59-60`). These cap *concurrent* internal image work; they are neither per-user nor time-windowed.

So there is nothing per-user, per-IP, or global limiting request rate, and no configured limits/windows exist. If per-user rate limiting were needed, the natural insertion point would be a new Connect interceptor placed after `NewAuthInterceptor` in the chain at `v1.go:133-138` (where the authenticated principal is available).
