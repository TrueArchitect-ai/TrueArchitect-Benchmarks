**delivery function** — `Post` in `internal/webhook/webhook.go:119` (the actual outbound HTTP dispatch happens at `safeClient.Do(req)`, `internal/webhook/webhook.go:152`; `PostAsync`/the queue workers at `webhook.go:183`/`webhook.go:46` route to this same function).

**protection mechanism** — the dial-time SSRF guard `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `Transport.DialContext` (`webhook.go:32-37`). It re-resolves the hostname and rejects any address in a reserved/private range via `isReservedIP` → `reservedCIDRs`/`reservedNetworks` in `internal/webhook/validate.go:44` / `validate.go:14`. Because the check runs at dial time on the resolved IP, it also defeats DNS-rebinding. A secondary config-time check, `ValidateURL` (`internal/webhook/validate.go:62`), rejects private-resolving URLs when a webhook is registered. Both can be disabled by the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted local-network use.
