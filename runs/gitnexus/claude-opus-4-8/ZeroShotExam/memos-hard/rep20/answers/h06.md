**Convergence function — `Post` — `internal/webhook/webhook.go:120`**

All paths funnel through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the single async worker goroutine drains that queue and calls `Post` (`internal/webhook/webhook.go:46`). `Post` is the sole place the outbound request is built (`http.NewRequest("POST", requestPayload.URL, …)`) and delivered (`safeClient.Do(req)`, line 152). So every handler's path converges at `internal/webhook/webhook.go:Post` immediately before delivery (with `PostAsync` as the shared enqueue entry point).
