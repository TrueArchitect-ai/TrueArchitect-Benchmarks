**Premise correction:** There is no nightly *database-cleanup* job scheduled in this repository, so no run time can be cited for one.

What actually exists:

- `internal/scheduler/` is a **standalone, generic cron-scheduler library** ("GitHub Actions-inspired… Zero external dependencies", `internal/scheduler/doc.go:1-8`). It defines `Job`, `Scheduler`, a cron parser, and middleware, but the application never wires it up — a search for any `scheduler.Job{}` registration outside the package itself and its tests turns up nothing (the app is started in `server/server.go` with no scheduler involved).

- The only "cleanup" schedule anywhere is an **illustrative doc comment**, not a real job: `internal/scheduler/doc.go:14-21` shows an example `Job` named `"daily-cleanup"` with `Schedule: "0 2 * * *" // 2 AM daily` and a placeholder `// Your cleanup logic here` handler. It is a usage example for the library, references no database, and is never registered or run.

So the closest match — the `"0 2 * * *"` / 2 AM figure — comes from documentation for a generic `daily-cleanup` example, not from an actual scheduled database-cleanup job in the running system.
