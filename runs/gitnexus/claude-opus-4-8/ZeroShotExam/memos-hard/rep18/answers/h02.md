**protection mechanism** — `safeDialContext` in `internal/webhook/webhook.go:59`, wired into the shared `safeClient`'s `http.Transport.DialContext` (lines 32-37). At dial time it resolves the target host and rejects any address in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), which checks against the reserved CIDR list at `internal/webhook/validate.go:14` (loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, and IPv6 equivalents). Because the check runs at dial time, it also defeats DNS-rebinding. This is complemented by up-front validation in `ValidateURL` (`internal/webhook/validate.go:62`) when a webhook URL is configured. Both can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`).
