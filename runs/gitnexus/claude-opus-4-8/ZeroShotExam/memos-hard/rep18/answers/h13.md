## Interface: `markdown.Service`

Defined at `internal/markdown/markdown.go:31` — a Go interface for backend markdown processing (tag/property/mention extraction, snippet generation, and HTML/markdown rendering via goldmark). (Frontend HTML rendering uses markdown-it and is *not* behind this interface — there's no matching TS interface.)

## impl — construction — holders

**impl —** A single concrete implementation runs at runtime: the unexported struct `service` (`internal/markdown/markdown.go:58`), which wraps a `goldmark.Markdown` parser. All interface methods are defined on `*service`. (Internally, `RenderMarkdown`/`RenameTag` delegate to a separate helper type `renderer.MarkdownRenderer` via `renderer.NewMarkdownRenderer()` at `internal/markdown/renderer/markdown_renderer.go`, but that helper is not itself behind the `Service` interface.)

**construction —** `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) is the only constructor; it returns `&service{md: goldmark.New(...)}`. In production it is called exactly once, in `NewAPIV1Service` at `server/router/api/v1/v1.go:48-51`, with `WithTagExtension()` and `WithMentionExtension()` enabled. That single instance is then shared to the other holders. (Tests build their own via `server/router/api/v1/test/test_helper.go:44`.)

**holders —** Three components declare a `markdown.Service` field:
- `APIV1Service.MarkdownService` — `server/router/api/v1/v1.go:35`. The owner/constructor; used across `memo_service.go`, `memo_mention_helpers.go`, and `memo_service_webhooks.go`.
- `rss.RSSService.MarkdownService` — `server/router/rss/rss.go:45`. Wired the *shared* instance at `server/server.go:85` (`rss.NewRSSService(..., apiV1Service.MarkdownService)`); uses `RenderHTML` for feeds (`rss.go:339`).
- `memopayload.Runner.MarkdownService` — `server/runner/memopayload/runner.go:16`. Note: `memopayload.NewRunner` is **never called in production** (only `s3presign.NewRunner` is wired in `server.go:162`), so this holder is currently dormant. Instead the package function `memopayload.RebuildMemoPayload(ctx, memo, s.MarkdownService)` receives the API service's instance directly (`memo_service.go:108,447`).

So at runtime: one `*service` instance, constructed in `NewAPIV1Service`, held by `APIV1Service` and passed to `RSSService` (and passed as a parameter into `RebuildMemoPayload`).
