**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`**

Every one of the `Dispatch…Webhook` methods above sets `payload.URL = hook.Url` (the user-configured URL) and calls the shared enqueue funnel `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which hands the payload to the async worker pool. Those workers all call the single delivery function `webhook.Post`, where the request is marshaled and actually sent via `safeClient.Do(req)` to `requestPayload.URL` (line 152). That is the one point where all handler paths converge before the request leaves the process. (`PostAsync` at line 184 is the earlier enqueue funnel if you want the pre-queue convergence point; `Post` is the sole point of actual delivery.)

Note: the outbound client (`safeClient`) guards against SSRF/DNS-rebinding by rejecting reserved/private IPs at dial time (`safeDialContext`, `internal/webhook/webhook.go:59`).
