**Premise correction:** This repository (`usememos/memos`) does **not** have a GraphQL API, so there is no GraphQL schema to point to. A search for `graphql`/`gqlgen`/`apollo` across the entire tree returns zero matches.

**Actual API surface:** The public API is defined as **gRPC / Protocol Buffers**, with a REST/HTTP interface generated via gRPC-Gateway and an accompanying OpenAPI spec.

- The API schema lives in the Protobuf service definitions under `proto/api/v1/*.proto`, e.g.:
  - `proto/api/v1/memo_service.proto`
  - `proto/api/v1/user_service.proto`
  - `proto/api/v1/auth_service.proto`
  - `proto/api/v1/attachment_service.proto`
  - plus `ai_service`, `instance_service`, `shortcut_service`, `idp_service`, and shared `common.proto`.
- Build/codegen config: `proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`.
- Generated code lives in `proto/gen/`, and the OpenAPI document is embedded via `proto/openapi_embed.go`.
- Backing store message types are in `proto/store/*.proto`.

So the "GraphQL schema for the public API" doesn't exist here — the equivalent artifact is the Protobuf API definition in `proto/api/v1/`.
