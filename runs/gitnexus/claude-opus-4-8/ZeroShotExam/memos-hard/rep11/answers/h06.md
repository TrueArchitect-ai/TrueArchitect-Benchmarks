**Convergence function — `webhook.Post` at `internal/webhook/webhook.go:120`**

All of the above funnel through the per-hook dispatch helper `dispatchMemoRelatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:48`) → `webhook.PostAsync` (`internal/webhook/webhook.go:184`, which just enqueues). Whether async (drained by the `init()` goroutines) or the comment path, every delivery ultimately converges on `Post`, which builds and fires the signed HTTP POST to the user-configured URL via `safeClient.Do(req)` (`webhook.go:152`).

Note: the webhook-CRUD RPCs (e.g. `CreateUserWebhook`) only persist config and never reach `Post`.
