**`internal/idp`; `internal/idp/oauth2`**

The provider abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the `IdentityProviderUserInfo` type shared across providers. The only concrete protocol implementation that ships is the OAuth2 provider in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go`), whose doc comment states: "Package oauth2 implements the OAuth2 identity provider integration." Its `IdentityProvider` struct is constructed via `NewIdentityProvider` and driven by a `storepb.OAuth2Config`.
