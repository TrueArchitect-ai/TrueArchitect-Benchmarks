**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls the markdown service's `ExtractAll` (`internal/markdown/markdown.go`) — the boolean-property portion is computed by `Service.ExtractProperties` (`internal/markdown/markdown.go:193-241`). The results are written into `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`), i.e. the memo's derived `MemoPayload_Property` (`proto/gen/store/memo.pb.go`).

**Triggers (recomputation):**
- **Create memo** — `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:108`.
- **Update memo content** — when the `content` field is updated, `RebuildMemoPayload` at `server/router/api/v1/memo_service.go:447` (only in the `content` update branch, guarded by content change).
- **Backfill runner** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) rebuilds the payload of *all* memos in batches of 100, calling `RebuildMemoPayload` per memo (`runner.go:52`).

**Extracted properties:** From `ExtractProperties` (`internal/markdown/markdown.go:199-240`), by walking the goldmark AST:
- `Title` — text of the first block-level child if it is an H1 heading (`markdown.go:208-212`)
- `HasLink` — a link node exists (`KindLink`)
- `HasCode` — a code block/fenced code/code span exists (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
- `HasTaskList` — a task-checkbox exists (`east.KindTaskCheckBox`)
- `HasIncompleteTasks` — an unchecked task checkbox exists

Additionally `ExtractAll` populates `Payload.Tags` alongside `Property` (`runner.go:85`). These `Property` booleans are consumed for stats/lists (e.g. `server/router/api/v1/user_service_stats.go:141-151`).
