h11.

**1st: User; 2nd: Memo**

Of the persistent entity types defined in the data layer (the `store` package — e.g. `User`, `Memo`, `Attachment`, `Inbox`, `Reaction`, `IdentityProvider`, `MemoRelation`, `MemoShare`, `InstanceSetting`, `UserIdentity`, `UserSetting`), the two most widely referenced from packages **outside** the store layer are:

- **1st: `store.User`** — referenced from **7** external packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`.
- **2nd: `store.Memo`** — referenced from **6** external packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`.

(Next closest is `store.Attachment` at ~4 packages.)

Type defined in `store/user.go` and `store/memo.go` respectively; counts based on `store.<Type>` references across `.go` files, excluding the `store/` package and its subpackages (db drivers, seed, test helpers).
