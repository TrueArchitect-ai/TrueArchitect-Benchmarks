**Premise correction:** This repository (Memos) does **not** have a GraphQL schema, and there is no GraphQL API surface anywhere in the codebase. A search for `graphql` across all Go/TypeScript sources returns zero hits. The public API is not GraphQL — it is a **Protocol Buffers / gRPC** API (also exposed as REST via gRPC-gateway and documented via OpenAPI).

**Actual API surface:** The public API is defined in **Protocol Buffer (`.proto`) files under `proto/api/v1/`**:

- `proto/api/v1/auth_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/memo_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto`

Supporting configuration lives at `proto/buf.yaml` and `proto/buf.gen.yaml` (code is generated with [buf](https://buf.build)), with backing store message definitions in `proto/store/*.proto`. There is also `proto/api/v1/openapi_embed.go`, indicating the gRPC services are surfaced as a REST/OpenAPI HTTP API — not GraphQL.

So the "GraphQL schema" doesn't exist; the equivalent artifact you're likely looking for is the set of protobuf service definitions in `proto/api/v1/`.
