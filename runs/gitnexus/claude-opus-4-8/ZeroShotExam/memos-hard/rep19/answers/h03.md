The identity-provider abstraction is defined in the `internal/idp` package (`internal/idp/idp.go`, which declares the shared `IdentityProviderUserInfo` type consumed by concrete providers). The only concrete protocol implementation that ships is OAuth2, in the `internal/idp/oauth2` package (`internal/idp/oauth2/oauth2.go` — "Package oauth2 implements the OAuth2 identity provider integration").

**Answer:** `internal/idp`; `internal/idp/oauth2`
