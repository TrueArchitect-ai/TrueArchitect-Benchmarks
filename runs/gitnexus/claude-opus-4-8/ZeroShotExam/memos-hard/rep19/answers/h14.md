**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual content parsing to the markdown service — `(*service).ExtractAll` in `internal/markdown/markdown.go` (lines ~355–406), a goldmark AST walk. It writes the result onto `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`).

**Triggers (recomputation):**
- **CreateMemo** — `server/router/api/v1/memo_service.go:108` (before the memo is stored).
- **UpdateMemo** — `server/router/api/v1/memo_service.go:447`, but only when the update mask includes the `content` field (the `contentUpdated` branch); the recomputed payload is written via `update.Payload`.
- **Batch rebuild/migration** — `(*Runner).RunOnce` at `server/runner/memopayload/runner.go:52`, which iterates all memos in batches and re-stamps each payload. (This runner exists as an on-demand rebuild-all mechanism.)

**Extracted properties** (into `MemoPayload`):
- `Tags` — `[]string` of `#tags`.
- `Property.Title` — text of the document's first block-level child, if it is an H1 heading.
- `Property.HasLink` — any link node present.
- `Property.HasCode` — any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox present.
- `Property.HasIncompleteTasks` — any unchecked task checkbox.

These are surfaced to list/preview API responses via `convertMemoPropertyFromStore` in `server/router/api/v1/memo_service_converter.go:314`.
