Memo visibility (who may view a memo) is enforced at multiple distinct server surfaces. The distinct enforcement sites:

Central single-memo read gate `checkMemoReadAccess` (GetMemo + comments) — server/router/api/v1/memo_service.go
ListMemos in-service visibility/creator filter — server/router/api/v1/memo_service.go
Store-level SQL `visibility IN (...)` WHERE builder (all three drivers) — store/db/sqlite/memo.go, store/db/postgres/memo.go, store/db/mysql/memo.go
Memo comment listing/creation visibility filter & check — server/router/api/v1/memo_service_comments.go
Memo relations listing visibility filter — server/router/api/v1/memo_relation_service.go
Reaction access visibility checks (list/upsert + delete) — server/router/api/v1/reaction_service.go
Per-memo attachment access check — server/router/api/v1/memo_attachment_service.go
Attachment service memo-linked access check — server/router/api/v1/attachment_service.go
File server raw blob serving `checkAttachmentPermission` — server/router/fileserver/fileserver.go
RSS feed listing (PUBLIC-only) — server/router/rss/rss.go
Frontend sitemap generation (PUBLIC-only) — server/router/frontend/frontend.go
Share-token bypass path `GetMemoByShare` (visibility-bypassing surface, still blocks archived/missing) — server/router/api/v1/memo_share_service.go
SSE real-time event delivery filter `SSEClient.canReceive` — server/router/api/v1/sse_hub.go

The two recurring idioms are: (1) single-object check — `if memo.Visibility == store.Private && memo.CreatorID != user.ID && !isSuperUser(user)` with PROTECTED requiring any authenticated user; and (2) list/SQL filter injecting `creator_id == N || visibility in ["PUBLIC","PROTECTED"]` (authenticated) or `["PUBLIC"]` (anonymous), ultimately enforced by the store WHERE builder.

Note one inconsistency worth flagging: `checkMemoReadAccess` (GetMemo) omits the `!isSuperUser` bypass that the reaction/comment/attachment/fileserver sites include, so an admin can reach a private memo's attachments/reactions but `GetMemo` itself would return PermissionDenied for that admin.
