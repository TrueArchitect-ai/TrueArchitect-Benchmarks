## Details

When a memo changes, `memo_service_webhooks.go:dispatchMemoRelatedWebhook` → `webhook.PostAsync` enqueues the payload, and a goroutine pool drains it into `webhook.Post`, which builds the `POST` request and dispatches it with `safeClient.Do(req)`.

The SSRF protection is layered, both keyed off `isReservedIP` (and the reserved-CIDR list in `/bench/home/work/internal/webhook/validate.go`):

- **Primary/effective guard — dial-time:** `safeClient`'s custom `Transport.DialContext` is `safeDialContext` (`internal/webhook/webhook.go:57`). It resolves the target host at connection time and refuses to dial if any resolved IP falls in a reserved range (loopback, RFC-1918, `169.254.0.0/16` link-local/IMDS, IPv6 ULA/link-local). Checking at dial time is what defeats DNS-rebinding TOCTOU.
- **Registration-time validation:** `ValidateURL` (`internal/webhook/validate.go:56`) rejects non-absolute/non-HTTP URLs and hosts that resolve to reserved IPs when a webhook is created/updated.

Both layers share `isReservedIP`/`reservedCIDRs` in `internal/webhook/validate.go`, and both can be disabled via the package-level `AllowPrivateIPs` flag (intended for self-hosted LAN deployments).

(Note: `internal/httpgetter/html_meta.go`'s `isInternalIP` is a separate SSRF guard for link-preview HTML fetching — not the memo webhook path.)
