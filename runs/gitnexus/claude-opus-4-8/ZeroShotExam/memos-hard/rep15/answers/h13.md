**Markdown processing behind the `markdown.Service` interface** (`internal/markdown/markdown.go:31-55`).

**impl** — There is exactly one concrete implementation: the unexported `service` struct (`internal/markdown/markdown.go:58-60`), holding a `goldmark.Markdown`. All interface methods (`ExtractAll`, `ExtractTags`, `ExtractProperties`, `RenderMarkdown`, `RenderHTML`, `GenerateSnippet`, `ValidateContent`, `RenameTag`) are pointer-receiver methods on `*service`, and `NewService` returns `&service{...}` — so `*service` is what runs at runtime.

*(Note: inside `service.RenderMarkdown`/`RenameTag`, a `renderer.MarkdownRenderer` — `internal/markdown/renderer/markdown_renderer.go` — does the AST→markdown rendering, but it's a concrete type built via `NewMarkdownRenderer()`, not itself behind an interface.)*

**construction** — Built once by `markdown.NewService(...)` (`internal/markdown/markdown.go:85-113`), called in `NewAPIV1Service` with tag + mention extensions enabled:
`markdown.NewService(markdown.WithTagExtension(), markdown.WithMentionExtension())` (`server/router/api/v1/v1.go:48-51`). A separate instance is built the same way in tests (`server/router/api/v1/test/test_helper.go:44`).

**holders** — Three components hold the `markdown.Service` interface as a field; all share the single instance created in `NewAPIV1Service`:
- `APIV1Service.MarkdownService` — the owner (`server/router/api/v1/v1.go:35`, set at v1.go:56).
- `rss.RSSService.MarkdownService` (`server/router/rss/rss.go:45`), injected via `NewRSSService(..., apiV1Service.MarkdownService)` (`server/server.go:85`).
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`); the memopayload package also receives it directly as a parameter to `RebuildMemoPayload(ctx, memo, s.MarkdownService)` (`server/router/api/v1/memo_service.go:108,447`).

**impl** (`*service`, sole implementation) **— construction** (`markdown.NewService(WithTagExtension, WithMentionExtension)` in `NewAPIV1Service`, v1.go:48) **— holders** (`APIV1Service`, `rss.RSSService`, `memopayload.Runner`, all sharing the one instance).
