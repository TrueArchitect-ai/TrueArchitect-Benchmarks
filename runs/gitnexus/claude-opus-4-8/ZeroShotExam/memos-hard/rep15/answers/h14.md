**Computation site**

The derived metadata lives in `MemoPayload` (fields `Tags` + `Property`) and is computed by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which calls into `markdown.Service.ExtractAll` (`internal/markdown/markdown.go:356`). `ExtractAll` does a single AST walk of the memo's markdown `Content` and assigns the results to `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85-86). This is content-derived, not user-set.

**Triggers (recomputation)**

1. **Create** — `CreateMemo` calls `memopayload.RebuildMemoPayload` on the new memo (`server/router/api/v1/memo_service.go:108`).
2. **Update, only when content changes** — `UpdateMemo` rebuilds the payload inside the `path == "content"` branch of the update mask (`server/router/api/v1/memo_service.go:446-451`). Other field updates (e.g. visibility) do not recompute it.
3. **Batch backfill** — the `memopayload.Runner.RunOnce` job rebuilds the payload for *all* memos in batches of 100 (`server/runner/memopayload/runner.go:27-72`), used to regenerate metadata across the store.

**Extracted properties**

From the single markdown walk in `ExtractAll` (`internal/markdown/markdown.go:362-421`):

- `Tags` — hashtag tags collected from `MemoTagNode`s, deduplicated while preserving case (`uniquePreserveCase`).
- `Property.Title` — text of the document's first block-level child *if* it is an H1 heading (markdown.go:383-389).
- `Property.HasLink` — true if any link node is present.
- `Property.HasCode` — true for any code block, fenced code block, or inline code span.
- `Property.HasTaskList` — true if any task checkbox exists.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.

(It also extracts `Mentions`, but that is not stored into the payload's derived metadata here.)
