**1st: `User` (~7 packages); 2nd: `Memo` (~6 packages)**

The data layer is the `store` package (`store/*.go`), where persistent entity types are defined as Go structs — `User` (`store/user.go`), `Memo` (`store/memo.go`), `Attachment`, `Reaction`, `Inbox`, `MemoRelation`, `MemoShare`, etc.

Counting distinct packages *outside* `store/` (excluding the in-layer DB drivers `store/db/{sqlite,mysql,postgres}` and `store/test`) that reference each type via `store.<Type>`:

- **`store.User` — 7 external packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 external packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

All other entities trail well behind (`Attachment` 4; `Inbox`, `MemoRelation`, `MemoShare` 3 each).

So `User` is the most widely referenced persistent entity across packages, with `Memo` a close second.
