False premise — there is no GraphQL schema. The public API is built on gRPC with ConnectRPC, defined via Protocol Buffers in `proto/api/v1/`. Generated Go stubs are in `proto/gen/api/v1/` and ConnectRPC handlers in `proto/gen/api/v1/apiv1connect/`. An OpenAPI spec is also generated at `proto/gen/openapi.yaml`.
