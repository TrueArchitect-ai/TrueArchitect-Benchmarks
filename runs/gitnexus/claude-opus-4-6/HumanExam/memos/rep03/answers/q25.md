Engine: CEL (Common Expression Language) via `google/cel-go`, in `internal/filter/engine.go` (Engine struct, line 14). The engine compiles the CEL filter string into an AST, walks it into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then the renderer (`internal/filter/render.go`) produces dialect-specific SQL (SQLite, MySQL, PostgreSQL) with appropriate JSON extraction, timestamp functions, LIKE/ILIKE operators, and placeholder styles. Each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`) to integrate the generated SQL WHERE clauses.
