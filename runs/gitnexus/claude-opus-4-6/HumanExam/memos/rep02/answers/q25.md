- Engine: CEL (Common Expression Language) via `google/cel-go`; engine at `internal/filter/engine.go` (`Engine` struct, line 13)
- Mechanism: The filter string is parsed as CEL into an AST, converted to a dialect-agnostic Condition IR tree (`internal/filter/parser.go`), then rendered into dialect-specific SQL with parameterized placeholders (`internal/filter/render.go`). Each DB driver calls `filter.AppendConditions()` (`internal/filter/helpers.go`) in its `ListMemos` to compile filters to SQL fragments with proper dialect (SQLite uses `?` placeholders, Postgres uses `$N`, MySQL uses `?`; JSON extraction, regex, and LIKE differ per dialect).
