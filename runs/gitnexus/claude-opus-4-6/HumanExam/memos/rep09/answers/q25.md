CEL (Common Expression Language) via `github.com/google/cel-go`; engine at `internal/filter/engine.go`. CEL expressions are compiled into a dialect-agnostic condition IR (`internal/filter/parser.go` / `ir.go`), then rendered to dialect-specific SQL (`internal/filter/render.go`). Each driver calls `filter.AppendConditions` with its dialect constant (DialectSQLite/DialectPostgres/DialectMySQL), which handles placeholder style, JSON operators, LIKE/ILIKE, date extraction, etc. per dialect.
