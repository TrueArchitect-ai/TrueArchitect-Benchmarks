The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed via both a gRPC server (Connect) and a gRPC-Gateway REST proxy. The proto service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The gRPC-Gateway and Connect handlers are registered in `server/router/api/v1/v1.go`.
