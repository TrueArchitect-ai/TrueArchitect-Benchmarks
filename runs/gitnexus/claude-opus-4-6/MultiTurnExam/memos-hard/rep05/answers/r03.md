The premise is incorrect — there is no nightly database-cleanup cron job in this codebase. The server has no scheduled database maintenance, vacuum, or purge task. The only periodic background runners are the S3 presign runner (every 12 hours, `server/runner/s3presign/runner.go`) and the in-memory cache cleanup (every 5 minutes, `store/cache/cache.go:60`). The `internal/scheduler` package exists but implements a general-purpose cron scheduler for user-facing features, not a database cleanup job.
