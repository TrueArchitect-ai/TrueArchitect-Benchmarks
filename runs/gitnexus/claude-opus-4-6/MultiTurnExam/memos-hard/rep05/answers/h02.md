**Delivery function** — `Post` — `internal/webhook/webhook.go:120`

**Protection mechanism** — `safeDialContext` combined with `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`

The `Post` function (`internal/webhook/webhook.go:120`) performs the actual outbound HTTP delivery, using a shared `safeClient` (`internal/webhook/webhook.go:32`). That client's transport is configured with `safeDialContext` (`internal/webhook/webhook.go:59`), which resolves the target hostname via DNS and then checks every resolved IP against a list of reserved/private CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) defined in `internal/webhook/validate.go:14-23`. If any resolved IP falls within a reserved range, the dial is rejected — this defeats both direct private-IP targeting and DNS rebinding attacks. The same check is also applied at webhook creation time via `ValidateURL` (`internal/webhook/validate.go:62`), providing defense in depth at both registration and delivery.
