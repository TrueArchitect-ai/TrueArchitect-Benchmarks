The premise is incorrect — there is no Redis connection. The cache layer is purely **in-memory**, implemented as a `sync.Map` with TTL-based expiration in `store/cache/cache.go`. It uses no external store.

The user cache is created via `cache.NewDefault()` or `cache.New(config)` in `store/store.go`. The default TTL for all entries (including user entries) is **10 minutes** (`store/cache/cache.go:59`, `DefaultConfig()`), with a cleanup sweep every 5 minutes and a max of 1000 items. There is no Redis, Memcached, or any other external caching infrastructure anywhere in the codebase.
