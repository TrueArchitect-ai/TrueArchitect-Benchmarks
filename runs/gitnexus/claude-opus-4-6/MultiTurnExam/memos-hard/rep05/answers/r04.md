The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain Go buffered channel declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in an `init()` function (`internal/webhook/webhook.go:42-55`) that range over this channel and call `Post()` for each payload. Enqueueing happens via `PostAsync` (`internal/webhook/webhook.go:184`), which performs a non-blocking send on the channel and drops the payload with a warning log if the buffer is full. The entire mechanism is in-process with no external messaging infrastructure.
