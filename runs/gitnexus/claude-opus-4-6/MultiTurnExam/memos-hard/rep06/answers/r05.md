The question's premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC**, exposed via three surfaces:

1. **Protobuf service definitions** — `proto/api/v1/*.proto` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc.) define the API schema as gRPC services with RPC methods and message types.

2. **gRPC-Gateway (REST/JSON)** — The gRPC services are exposed as a REST API via gRPC-Gateway, registered at `server/router/api/v1/v1.go:99-120` (e.g., `v1pb.RegisterMemoServiceHandlerServer`).

3. **Connect-RPC** — An additional HTTP API surface using Connect protocol, registered at `server/router/api/v1/v1.go:141` via `connectHandler.RegisterConnectHandlers`.

The generated Go code from the proto definitions lives in `proto/gen/api/v1/` and `proto/gen/store/`.
