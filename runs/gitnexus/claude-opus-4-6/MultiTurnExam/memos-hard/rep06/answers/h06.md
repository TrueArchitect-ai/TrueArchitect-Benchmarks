The following RPC handler methods can transitively cause an outbound HTTP request to a user-configured webhook URL:

1. **`CreateMemo`** — `server/router/api/v1/memo_service.go:70` (calls `DispatchMemoCreatedWebhook` at line 157)
2. **`UpdateMemo`** — `server/router/api/v1/memo_service.go:401` (calls `dispatchMemoUpdatedSideEffects` which calls `DispatchMemoUpdatedWebhook` at `server/router/api/v1/memo_update_helpers.go:67`)
3. **`DeleteMemo`** — `server/router/api/v1/memo_service.go:518` (calls `DispatchMemoDeletedWebhook` at line 562)
4. **`CreateMemoComment`** — `server/router/api/v1/memo_service_comments.go:20` (calls `DispatchMemoCommentCreatedWebhook` at line 119)

All four paths converge at a single function before delivery:

**`webhook.PostAsync`** — `internal/webhook/webhook.go:184`

Every dispatch method (`DispatchMemoCreatedWebhook`, `DispatchMemoUpdatedWebhook`, `DispatchMemoDeletedWebhook`, `DispatchMemoCommentCreatedWebhook`) enqueues the payload via `webhook.PostAsync`, which feeds an async channel consumed by background goroutines that call `webhook.Post` (`internal/webhook/webhook.go:120`) to perform the actual outbound HTTP request.
