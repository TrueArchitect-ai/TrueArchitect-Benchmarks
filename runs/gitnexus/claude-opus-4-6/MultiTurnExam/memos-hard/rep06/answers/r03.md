The question's premise is incorrect — there is no nightly database-cleanup job in this codebase. While a general-purpose cron scheduler package exists at `internal/scheduler/scheduler.go`, it is never imported or used by the server or any production code (`cmd/`, `server/`). No scheduled database cleanup, vacuum, or purge job is registered anywhere. The only background runners are the S3 presign runner (`server/runner/s3presign/runner.go`, every 12 hours) and the in-memory cache cleanup (`store/cache/cache.go:200`, every 5 minutes) — neither performs database cleanup.
