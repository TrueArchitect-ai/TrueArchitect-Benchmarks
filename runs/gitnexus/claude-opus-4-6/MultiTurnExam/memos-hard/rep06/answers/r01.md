The question's premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is entirely **in-process / in-memory**, implemented in `store/cache/cache.go` as a `sync.Map`-based cache with TTL-driven expiration.

The user cache is constructed at `store/store.go:52` using a shared `cache.Config` defined at `store/store.go:40-45`:

- **DefaultTTL:** 10 minutes
- **CleanupInterval:** 5 minutes
- **MaxItems:** 1000

All three caches (instance settings, users, user settings) share the same configuration. There is no external cache service (Redis, Memcached, or otherwise) — no Redis client library is imported or referenced anywhere in the project.
