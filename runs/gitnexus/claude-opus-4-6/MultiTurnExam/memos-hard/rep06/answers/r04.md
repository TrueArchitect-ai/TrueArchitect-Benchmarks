The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel**, not an external message queue.

The "queue" is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package's `init()` function (`internal/webhook/webhook.go:42-55`) to drain this channel and call `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send and drops the event if the 128-slot buffer is full. The entire mechanism is in-process with no external dependencies.
