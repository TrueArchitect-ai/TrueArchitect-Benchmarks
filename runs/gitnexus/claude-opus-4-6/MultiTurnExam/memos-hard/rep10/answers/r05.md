The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (HTTP/JSON transcoding), plus **Connect** (ConnectRPC).

The API surface is defined in protobuf files under `proto/api/v1/` (e.g., `memo_service.proto`, `auth_service.proto`, `user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/` (gRPC stubs) and `proto/gen/api/v1/apiv1connect/` (Connect handlers). The RPC service implementations live in `server/router/api/v1/`. Additionally, a native HTTP file-serving surface is registered via `server/router/fileserver/fileserver.go`, and an RSS feed is served from `server/router/rss/rss.go`.
