Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines the `IdentityProviderUserInfo` struct that all providers return.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the concrete OAuth2 protocol implementation, which exchanges authorization codes for tokens, fetches user info, and maps fields back to `IdentityProviderUserInfo`.
