**Delivery function** — `Post` — `internal/webhook/webhook.go:120`. It serializes the payload as JSON, optionally signs it with HMAC-SHA256 (Standard Webhooks), and sends the HTTP POST using `safeClient`. Asynchronous dispatch goes through `PostAsync` (same file, line 184), which enqueues onto a buffered channel consumed by 4 background goroutines.

**Protection mechanism** — SSRF guard via `safeDialContext` (`internal/webhook/webhook.go:59`) and `isReservedIP` / `ValidateURL` (`internal/webhook/validate.go:44` / `validate.go:62`). The `safeClient` HTTP transport replaces the default dialer with `safeDialContext`, which resolves the target hostname and checks every resolved IP against a list of reserved/private CIDR ranges (`reservedCIDRs`, `internal/webhook/validate.go:14`—loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents). This blocks connections at dial time, defeating both direct private-IP targets and DNS rebinding. A parallel check in `ValidateURL` rejects URLs at creation/update time as well, providing defense in depth.
