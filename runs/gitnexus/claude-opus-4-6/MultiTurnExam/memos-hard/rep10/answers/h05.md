Explicit Go code. When a user is deleted, their emoji reactions are removed by direct `DELETE` SQL statements in the per-driver `user_delete.go` files, inside a transaction. Two deletions happen:

1. **Reactions on the user's memos** (by `content_id`):
   - `store/db/sqlite/user_delete.go:383`
   - `store/db/mysql/user_delete.go:420`
   - `store/db/postgres/user_delete.go:383`

2. **Reactions created by the user** (by `creator_id`):
   - `store/db/sqlite/user_delete.go:401`
   - `store/db/mysql/user_delete.go:438`
   - `store/db/postgres/user_delete.go:401`

This is not a database-level cascade — it's explicit Go code issuing `DELETE FROM reaction WHERE ...` statements within the delete-user transaction in each driver.
