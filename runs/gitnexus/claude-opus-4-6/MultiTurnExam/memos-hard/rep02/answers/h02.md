**Delivery function** — `Post` in `internal/webhook/webhook.go:120`. It marshals the payload to JSON, constructs an HTTP POST request (optionally HMAC-signing it), and sends it via `safeClient.Do()`. Asynchronous dispatch goes through `PostAsync` (same file, line 184), which enqueues onto a buffered channel consumed by 4 goroutine workers (lines 42–55).

**Protection mechanism** — SSRF guard via `safeDialContext` in `internal/webhook/webhook.go:59`. The custom `DialContext` on the shared `safeClient` transport resolves the target hostname and checks every resulting IP against a blocklist of reserved/private CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) defined in `internal/webhook/validate.go:14–23` and enforced by `isReservedIP` (`internal/webhook/validate.go:44`). This blocks connections at dial time, defeating both direct private-IP targeting and DNS rebinding. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same reserved-IP check at webhook creation/update time so invalid URLs are rejected up front.
