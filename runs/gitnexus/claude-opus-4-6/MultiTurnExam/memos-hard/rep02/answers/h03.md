Abstraction package: `internal/idp` (`internal/idp/idp.go`) — defines `IdentityProviderUserInfo`, the common struct all providers return.

Implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the sole concrete implementation, providing an OAuth 2 identity provider with token exchange (including PKCE support) and user-info retrieval via configurable field mappings.
