The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (REST). The `.proto` service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`), with generated Go code in `proto/gen/api/v1/`. The server registers both gRPC-Gateway (REST/JSON) handlers and Connect-protocol handlers in `server/router/api/v1/v1.go:64–97`, mounted onto an Echo HTTP server (`server/server.go`).
