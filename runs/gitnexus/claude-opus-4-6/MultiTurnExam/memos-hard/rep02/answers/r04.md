The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **in-process Go buffered channel** (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel and call `Post()` for each payload. Producers enqueue via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send that drops the payload if the 128-slot buffer is full. No external messaging infrastructure is involved.
