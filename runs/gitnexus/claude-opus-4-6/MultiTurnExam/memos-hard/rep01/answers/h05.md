h05.
Explicit Go code. When a user is deleted, reactions are removed by two explicit SQL `DELETE` statements executed within the user-deletion transaction:

1. **`deleteReactionsByContentIDsTx`** — deletes reactions on the user's content (memos), e.g. `store/db/sqlite/user_delete.go:380`, `store/db/mysql/user_delete.go:417`, `store/db/postgres/user_delete.go:380`.
2. **`deleteReactionsByCreatorTx`** — deletes reactions created by the user themselves, e.g. `store/db/sqlite/user_delete.go:400`, `store/db/mysql/user_delete.go:437`, `store/db/postgres/user_delete.go:400`.

Both are called from the main delete-user transaction in each driver (e.g. `store/db/sqlite/user_delete.go:96,102`, `store/db/mysql/user_delete.go:96,102`, `store/db/postgres/user_delete.go:96,102`). This is application-level Go code issuing explicit `DELETE FROM reaction` SQL, not a database-level cascade or foreign-key rule.
