**Delivery function** — `Post` in `internal/webhook/webhook.go:120`. It marshals the payload to JSON, constructs an HTTP POST request (optionally HMAC-signing it), and executes it via `safeClient.Do`. Async delivery goes through `PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto a buffered channel consumed by 4 background goroutines that each call `Post`.

**Protection mechanism** — SSRF guard via `safeDialContext` (`internal/webhook/webhook.go:59`) and `ValidateURL` (`internal/webhook/validate.go:62`).

Two layers prevent targeting internal network addresses:

1. **At registration time**: `ValidateURL` (`internal/webhook/validate.go:62`) resolves the webhook URL's hostname and rejects it if any resolved IP falls within a reserved/private CIDR range (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents — defined in `internal/webhook/validate.go:14–23`).

2. **At delivery time**: the `safeClient` HTTP client (`internal/webhook/webhook.go:32`) uses a custom `Transport` whose `DialContext` is `safeDialContext` (`internal/webhook/webhook.go:59`). This re-resolves the hostname at connection time and rejects any reserved/private IP, which also defeats DNS rebinding attacks (where a hostname resolves to a public IP at validation time but a private IP at request time).

**Answer format:** `Post` — `internal/webhook/webhook.go:120`; `safeDialContext` + `ValidateURL` (reserved-IP CIDR check at dial time and at URL registration time) — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:62`
