The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain **Go buffered channel** (`asyncPostQueue`), declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutines are spawned in the package `init()` function (`internal/webhook/webhook.go:42–55`) to drain this channel and call `Post` for each payload. Producers enqueue via `PostAsync` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the payload if the channel is full. There is no external message broker involved.
