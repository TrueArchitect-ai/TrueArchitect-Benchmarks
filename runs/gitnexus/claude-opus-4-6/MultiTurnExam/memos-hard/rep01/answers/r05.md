The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **Connect** (gRPC-compatible HTTP) gateway.

The protobuf service definitions live under `proto/` (e.g., `proto/gen/api/v1/memo_service_grpc.pb.go`, `proto/gen/api/v1/user_service_grpc.pb.go`, etc.), and the Connect-based HTTP handlers are registered in `server/router/api/v1/v1.go`. The gateway that bridges gRPC to REST-style HTTP is set up via `server/router/api/v1/connect_services.go`. Additionally, a file-serving HTTP surface is registered through Echo routes in `server/router/fileserver/fileserver.go`.
