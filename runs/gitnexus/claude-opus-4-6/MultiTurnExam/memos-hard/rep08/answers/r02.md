The premise is incorrect — there is no per-user API rate-limiting middleware in this codebase. A search for "rate limit," "ratelimit," "throttle," and related terms across all Go source files returns no matches. The server does not implement any request rate limiting. The only request-constraining mechanisms are content-length limits (for memo content), pagination limits (for list queries), and concurrency controls like the thumbnail generation semaphore (`server/router/fileserver/fileserver.go`), but none of these constitute per-user API rate limiting.
