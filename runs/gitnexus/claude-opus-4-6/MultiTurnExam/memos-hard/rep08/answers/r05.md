The premise is incorrect — there is no GraphQL schema in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and served over HTTP via a **gRPC-Gateway** and **Connect** (ConnectRPC).

The API surface is defined in `.proto` files under `proto/api/v1/`, with generated Go code in `proto/gen/api/v1/` (gRPC service stubs, e.g. `proto/gen/api/v1/memo_service_grpc.pb.go`) and `proto/gen/api/v1/apiv1connect/` (Connect handlers, e.g. `proto/gen/api/v1/apiv1connect/memo_service.connect.go`). The gateway is registered via `APIV1Service.RegisterGateway` (called at `server/server.go:88`), and Connect service handlers are registered alongside it in `server/router/api/v1/connect_services.go`. The services include `MemoService`, `AuthService`, `UserService`, `AttachmentService`, `InstanceService`, `IdentityProviderService`, `ShortcutService`, and `AIService`.
