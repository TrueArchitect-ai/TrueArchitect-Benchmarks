The premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is a purely **in-memory implementation** using Go's `sync.Map`, defined in `store/cache/cache.go`. There is no external cache service (Redis, Memcached, or otherwise).

User entries use the **default TTL of 10 minutes**, as the `Store` constructs its `userCache` with `cache.NewDefault()` (or equivalent default config). The `DefaultConfig()` at `store/cache/cache.go:57–64` sets `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, and `MaxItems: 1000`. Cache entries are stored as in-process structs with an expiration timestamp, and a background goroutine (`cleanupLoop`, line 200) sweeps expired items every 5 minutes.
