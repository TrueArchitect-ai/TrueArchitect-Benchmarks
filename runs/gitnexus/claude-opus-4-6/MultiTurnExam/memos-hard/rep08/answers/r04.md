The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **Go buffered channel**, not an external message queue.

The "queue" is declared as `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` at `internal/webhook/webhook.go:39`. Four goroutine workers are spawned in the package's `init()` function (`internal/webhook/webhook.go:42–55`) to drain this channel, each calling `Post()` for the actual HTTP delivery. Producers enqueue payloads via `PostAsync()` (`internal/webhook/webhook.go:184`), which performs a non-blocking send and drops the event with a warning log if the channel is full (lines 189–195). Everything is in-process with no external dependencies.
