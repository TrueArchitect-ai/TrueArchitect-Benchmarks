The question's premise is incorrect — there is no per-user API rate-limiting middleware in this codebase. The server registers only two middleware layers at `server/server.go:51-52`: a panic recovery middleware (`middleware.Recover()`) and a CORS middleware (`newCORSMiddleware`, defined in `server/cors.go:13`). Authentication/authorization is handled via a gRPC-Gateway middleware and Connect interceptor (`server/router/api/v1/v1.go:69-97` and `server/router/api/v1/authz.go`), but none of these implement rate limiting. No rate-limiting package is imported anywhere in the codebase.
