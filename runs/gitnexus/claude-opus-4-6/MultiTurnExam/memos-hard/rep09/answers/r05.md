The question's premise is incorrect — there is no GraphQL schema or API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** and served over two transports:

1. **gRPC-Gateway** (REST/JSON) — proto service definitions are in `proto/api/v1/`, with generated Go code in `proto/gen/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, etc.). The gateway is registered in `server/router/api/v1/v1.go:95-97`.

2. **Connect (gRPC-compatible)** — Connect services are registered alongside the gateway in `server/router/api/v1/connect_services.go`.

The server implementations live under `server/router/api/v1/` (e.g., `memo_service.go`, `user_service.go`). There is no GraphQL dependency or schema anywhere in the project.
