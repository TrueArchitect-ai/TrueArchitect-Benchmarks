The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) involved in webhook delivery. The webhook workers consume from a plain **in-memory Go buffered channel** declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutines are spawned in `init()` (`internal/webhook/webhook.go:42-55`) that range over this channel, calling `Post()` for each payload. Callers enqueue work via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send and drops the payload if the 128-slot buffer is full. There is no external queue or broker anywhere in the codebase.
