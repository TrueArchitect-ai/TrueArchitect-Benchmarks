The question's premise is incorrect — there is no nightly database-cleanup cron job in this codebase. While an `internal/scheduler` package exists (`internal/scheduler/scheduler.go`), it is never wired into the server or command entrypoint. The only scheduled background tasks are the S3 presign runner (every 12 hours, `server/runner/s3presign/runner.go`) and in-memory cache cleanup (every 5 minutes, `store/cache/cache.go:60`). Neither performs database cleanup, and neither uses cron scheduling — they use simple Go `time.Ticker` loops.
