**Delivery function** — `Post` — `internal/webhook/webhook.go:120`

**Protection mechanism** — SSRF guard via `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`

The `Post` function (`internal/webhook/webhook.go:120`) performs the actual outbound HTTP delivery. It uses a custom `safeClient` (`internal/webhook/webhook.go:32`) whose transport replaces the default dialer with `safeDialContext` (`internal/webhook/webhook.go:59`). This dialer resolves the target hostname via DNS and then checks every resolved IP against a list of reserved/private CIDR ranges (`isReservedIP` at `internal/webhook/validate.go:44`, populated from `reservedCIDRs` at `internal/webhook/validate.go:14`). This blocks connections to loopback, RFC-1918, link-local (including cloud IMDS 169.254.x.x), and IPv6 equivalents — defeating both direct internal-address targeting and DNS rebinding attacks. Additionally, `ValidateURL` (`internal/webhook/validate.go:62`) performs the same IP check at URL registration time, providing defense in depth.
