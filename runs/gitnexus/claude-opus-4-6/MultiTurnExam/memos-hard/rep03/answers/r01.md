The premise is incorrect — there is no Redis connection anywhere in this codebase. The cache layer is purely **in-memory**, implemented as a `sync.Map`-based cache in `store/cache/cache.go`. There is zero Redis dependency (grep for "redis" returns nothing).

User entries are cached via `Store.userCache` (`store/store.go`) which is created with `cache.DefaultConfig()` (`store/cache/cache.go:57`), giving a **default TTL of 10 minutes** (line 59: `DefaultTTL: 10 * time.Minute`). Entries are stored and retrieved using `Cache.Set` / `Cache.Get`, with expiration checked on read (line 135) and cleaned up periodically every 5 minutes by a background goroutine (line 60: `CleanupInterval: 5 * time.Minute`).
