The premise is incorrect — there is no message broker (neither NATS nor RabbitMQ) in this codebase. The webhook delivery workers consume from a plain **in-memory Go channel**, not an external message queue.

The "queue" is declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

It is a buffered channel with capacity 128. Four worker goroutines are spawned in an `init()` function (`internal/webhook/webhook.go:42-55`) that range over this channel and call `Post()` for each payload. Callers enqueue work via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send and drops the payload with a warning log if the channel is full.
