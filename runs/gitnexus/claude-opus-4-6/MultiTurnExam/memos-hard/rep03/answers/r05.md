The premise is incorrect — there is no GraphQL schema in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and a **gRPC-Gateway** REST proxy, plus a **Connect** (connect-go) endpoint.

The API surface is defined in `.proto` files under `proto/api/v1/` (e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The gRPC services are registered as gateway handlers in `server/router/api/v1/v1.go:99-120`, and Connect handlers are registered at `server/router/api/v1/v1.go:141`. An additional HTTP surface is provided by the Echo fileserver (`server/router/fileserver/fileserver.go`) and RSS routes (`server/router/rss/rss.go`).
