Memo visibility is enforced at these distinct sites:

1. **`checkMemoReadAccess`** — `server/router/api/v1/memo_service.go:39` — central gRPC-layer guard used by `GetMemo` (line 356), `ListMemoComments` (line 148 of `memo_service_comments.go`), and `CreateMemoComment` (line 33 of `memo_service_comments.go`)

2. **`ListMemos` visibility filtering** — `server/router/api/v1/memo_service.go:218-227` — applies `VisibilityList` / filter predicates to the query based on whether the caller is anonymous, viewing their own memos, or viewing others'

3. **`checkAttachmentPermission`** (fileserver) — `server/router/fileserver/fileserver.go:650` — enforces memo visibility when serving attachment files over HTTP, including share-token fallback (line 684)

4. **`checkAttachmentAccess`** (gRPC attachment service) — `server/router/api/v1/attachment_service.go:422` — enforces memo visibility when accessing attachments via the gRPC API

5. **`ListMemoReactions` / `UpsertMemoReaction`** inline checks — `server/router/api/v1/reaction_service.go:30` and `:83` — check memo visibility before listing or creating reactions

6. **RSS feed** — `server/router/rss/rss.go:90` — restricts to `store.Public` only

7. **`GetUserMemoStats` / `GetUserHeatmap`** visibility filtering — `server/router/api/v1/user_service_stats.go:84-90` and `:218-220` — applies visibility constraints when computing stats for other users

8. **`ListMemoRelations`** — `server/router/api/v1/memo_relation_service.go:109-111` — filters related memos by visibility
