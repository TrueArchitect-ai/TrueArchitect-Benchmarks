The premise is incorrect — there is no GraphQL schema or GraphQL API in this codebase. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **Connect** (gRPC-compatible HTTP).

The protobuf service definitions live under `proto/api/v1/` (e.g., `memo_service.proto`, `auth_service.proto`, `user_service.proto`, etc.), with generated Go code in `proto/gen/api/v1/`. The Connect-based HTTP handlers are generated in `proto/gen/api/v1/apiv1connect/` and registered in `server/router/api/v1/v1.go`. The server exposes this API surface via Connect RPC over HTTP, registered through Echo in `server/server.go`.
