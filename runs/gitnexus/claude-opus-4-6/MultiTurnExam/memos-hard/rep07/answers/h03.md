**Abstraction package:** `internal/idp` — defines the `IdentityProviderUserInfo` struct that all providers return (`internal/idp/idp.go`).

**Implementation package:** `internal/idp/oauth2` — the sole concrete implementation, providing an OAuth2 identity provider (`internal/idp/oauth2/oauth2.go`). It handles token exchange (with PKCE support), user info retrieval via bearer token, and field mapping from arbitrary OAuth2 claims to the common `IdentityProviderUserInfo` structure.
