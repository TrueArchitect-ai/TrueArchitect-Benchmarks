The question's premise is incorrect — there is no nightly database-cleanup job. The `internal/scheduler` package exists but is never imported or used by any production code (server, cmd, or store). The only background runners in the server are the S3 presign runner (every 12 hours, `server/runner/s3presign/runner.go`) and the memo payload rebuilder (`server/runner/memopayload/runner.go`), neither of which performs database cleanup. No cron-scheduled database cleanup job exists in this codebase.
