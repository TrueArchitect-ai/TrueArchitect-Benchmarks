**Protection mechanism:** SSRF guard via `safeDialContext` — `internal/webhook/webhook.go:59`. The custom `DialContext` on the shared `safeClient` transport resolves the target hostname and checks every resolved IP against a list of reserved/private CIDR ranges (`isReservedIP` in `internal/webhook/validate.go:44`). The blocked ranges (loopback, RFC-1918, link-local/cloud IMDS, IPv6 equivalents) are defined at `internal/webhook/validate.go:14–23` and parsed once at init time (line 28). This check runs at dial time, which also defeats DNS rebinding. A second layer applies at URL registration time: `ValidateURL` (`internal/webhook/validate.go:62`) performs the same reserved-IP check when the webhook URL is first saved, rejecting it with a gRPC error before it ever reaches the delivery path.
