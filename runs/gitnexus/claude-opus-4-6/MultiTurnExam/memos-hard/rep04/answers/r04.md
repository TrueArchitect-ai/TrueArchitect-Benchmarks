The question's premise is incorrect — there is no message broker (neither NATS nor RabbitMQ). The webhook delivery workers consume from a plain in-memory Go channel: `asyncPostQueue`, declared as a buffered channel of capacity 128 at `internal/webhook/webhook.go:39`. Four goroutine workers are spawned in the package's `init()` function (`internal/webhook/webhook.go:42–55`) to read from this channel and call `Post()`. Callers enqueue payloads via `PostAsync()` (`internal/webhook/webhook.go:184`), which does a non-blocking send to the channel and drops the event if the buffer is full. There is no external message broker involved.
