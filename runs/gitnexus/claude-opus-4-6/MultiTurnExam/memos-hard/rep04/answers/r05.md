The question's premise is incorrect — there is no GraphQL schema. The public API is defined using **Protocol Buffers (protobuf)** with gRPC, exposed via two transports:

1. **Protobuf service definitions** in `proto/api/v1/` — e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, etc. These define the RPC methods and message types.

2. **gRPC-Gateway** — the generated Go code in `proto/gen/api/v1/` provides a REST/JSON HTTP gateway alongside native gRPC. The gateway is registered in `server/router/api/v1/v1.go` via `runtime.NewServeMux` with middleware.

3. **Connect (ConnectRPC)** — an additional HTTP-based RPC surface registered in `server/router/api/v1/connect_handler.go` and `connect_services.go`.

There is no GraphQL layer anywhere in the codebase.
