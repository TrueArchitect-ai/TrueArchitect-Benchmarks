The following tables are affected when `DeleteMemo` runs:

- `memo_relation` — explicitly deleted in `store/memo.go` (both as source and target)
- `attachment` — explicitly deleted in `store/memo.go`
- `memo` — the memo row itself, plus comment memos recursively deleted from the API layer (`server/router/api/v1/memo_service.go`)
- `memo_share` — via SQL `ON DELETE CASCADE` foreign key referencing `memo(id)` (defined in `store/migration/sqlite/LATEST.sql`)
