Engine: CEL (Common Expression Language) via `github.com/google/cel-go`, implemented in `internal/filter/` (parser in `internal/filter/engine.go`, SQL rendering in `internal/filter/render.go`).

The CEL filter string is parsed into a dialect-agnostic IR (condition tree), then `filter.AppendConditions()` renders it into SQL WHERE clauses using a dialect flag (`DialectSQLite`, `DialectPostgres`, `DialectMySQL`) — each driver passes its own dialect constant (e.g., `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`), and the renderer in `internal/filter/render.go` switches on that dialect to emit the correct SQL syntax for each database.
