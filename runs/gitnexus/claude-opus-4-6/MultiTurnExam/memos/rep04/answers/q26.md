The tables affected when `DeleteMemo` runs:

3. **`memo_share`** — cascaded via `ON DELETE CASCADE` foreign key on `memo_id` (see `store/migration/postgres/LATEST.sql`)
4. **`memo`** — the memo row itself, deleted last in `store/memo.go:158`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567-574`), any **comment memos** (child memos) are deleted first, each triggering the same cascade on their own `memo`, `memo_relation`, `attachment`, and `memo_share` rows.
