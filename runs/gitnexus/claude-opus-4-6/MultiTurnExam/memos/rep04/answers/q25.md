The filter syntax is **CEL (Common Expression Language)**, parsed by the `cel-go` library. The engine lives in `internal/filter/` — specifically, `internal/filter/engine.go` defines the `Engine` struct that compiles CEL expressions into a dialect-agnostic condition tree (`internal/filter/ir.go`), and `internal/filter/render.go` renders that tree into dialect-specific SQL.

Each dialect driver (e.g., `store/db/postgres/memo.go`, `store/db/mysql/memo.go`, `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` from `internal/filter/helpers.go`, passing its dialect constant (`DialectPostgres`, `DialectMySQL`, `DialectSQLite`), which compiles the CEL filter into an IR condition tree and then renders it into the appropriate SQL WHERE clauses with bound parameters for that dialect.
