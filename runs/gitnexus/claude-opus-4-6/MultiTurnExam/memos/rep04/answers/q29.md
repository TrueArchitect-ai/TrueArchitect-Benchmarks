Token kinds: **JWT access tokens** (short-lived, 15 minutes, sent as `Bearer` in the `Authorization` header) and **JWT refresh tokens** (long-lived, 30 days, stored in a cookie named `memos_refresh`). The interceptor attaches the access token to requests, and on `Unauthenticated` errors (or pre-flight expiry detection), it refreshes via `AuthService.RefreshToken` using the refresh token cookie.
