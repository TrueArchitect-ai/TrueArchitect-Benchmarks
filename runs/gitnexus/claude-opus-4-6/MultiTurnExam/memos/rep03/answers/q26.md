The following tables are affected when `DeleteMemo` runs:

1. **`memo_relation`** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:142-146`), removing rows where the memo is either source or target
2. **`attachment`** — explicitly deleted in `Store.DeleteMemo` (`store/memo.go:149-157`)
3. **`memo`** — the memo row itself is deleted by the driver (`store/memo.go:158`)

Additionally, at the API handler layer (`server/router/api/v1/memo_service.go:567-577`), comment memos are recursively deleted first, which triggers the same cascade on their own `memo_relation`, `attachment`, and `memo` rows.
