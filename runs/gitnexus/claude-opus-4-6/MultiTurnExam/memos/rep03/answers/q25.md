Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/engine.go`

The CEL engine parses the filter string into a dialect-agnostic condition tree (IR in `internal/filter/ir.go`), then `internal/filter/render.go` renders that tree into dialect-specific SQL (SQLite, PostgreSQL, MySQL) via `AppendConditions`, which each dialect driver calls with its own `DialectName` constant (e.g., `filter.DialectSQLite` in `store/db/sqlite/memo.go`, `filter.DialectPostgres` in `store/db/postgres/memo.go`, `filter.DialectMySQL` in `store/db/mysql/memo.go`).
