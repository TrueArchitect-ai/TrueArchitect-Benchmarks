Engine: CEL (Common Expression Language) via `google/cel-go` — `internal/filter/` (engine in `internal/filter/engine.go`, parser in `internal/filter/parser.go`, SQL renderer in `internal/filter/render.go`).

The CEL filter expression is parsed into a dialect-agnostic IR condition tree (`internal/filter/parser.go`), then the renderer (`internal/filter/render.go`) translates that IR into parameterized SQL using a `DialectName` discriminator (e.g., `DialectPostgres`, `DialectSQLite`), which each dialect driver passes when calling `filter.AppendConditions()` in its `ListMemos` implementation (e.g., `store/db/postgres/memo.go:58`, `store/db/sqlite/attachment.go:85`).
