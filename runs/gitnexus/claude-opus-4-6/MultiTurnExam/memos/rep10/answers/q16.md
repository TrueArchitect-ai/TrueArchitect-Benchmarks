When a memo is deleted, the store layer (`Store.DeleteMemo` in `store/memo.go`, lines 140–159) deletes the following records before the memo row itself:

1. **Memo relations** — `memo_relation` records where the memo is either the source (`MemoID`) or the target (`RelatedMemoID`)
2. **Attachments** — all `attachment` records linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go`, lines 567–577), **comment memos** (child memos linked via `MemoRelationComment`) are recursively deleted before the parent memo, and each of those deletions triggers the same relation and attachment cleanup.
