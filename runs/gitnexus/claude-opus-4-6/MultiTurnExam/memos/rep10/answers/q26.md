The following tables are affected when DeleteMemo runs:

- **memo_relation** — explicitly deleted in `Store.DeleteMemo` (store/memo.go:142–146)

- **memo** — the memo row itself is deleted last (store/memo.go:158), and at the API layer, comment memos are recursively deleted first (server/router/api/v1/memo_service.go:573–576)
