The filter engine uses **CEL (Common Expression Language)** via `google/cel-go`, implemented in `internal/filter/` (parser in `internal/filter/parser.go`, engine in `internal/filter/engine.go`).

The CEL expression is parsed into a dialect-agnostic intermediate condition tree (`internal/filter/ir.go`), then the renderer (`internal/filter/render.go`) translates that tree into SQL using a per-dialect placeholder style and column mappings. Each dialect driver (e.g. `store/db/postgres/memo.go`, `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`) calls `filter.AppendConditions()` passing its dialect constant (`filter.DialectPostgres`, `filter.DialectSQLite`, `filter.DialectMySQL`), which compiles the CEL filter and renders it into a SQL WHERE clause with the appropriate placeholder syntax for that dialect.
