Interceptor: `web/src/connect.ts` — the `authInterceptor` (line 156) is a ConnectRPC interceptor that attaches a `Bearer` access token to each request and handles automatic refresh on 401.

Token kinds: **access token** (short-lived JWT sent as `Authorization: Bearer` header) and **refresh token** (sent as an HTTP-only cookie via `credentials: "include"`, used to obtain new access tokens via `AuthService.RefreshToken`).

Backend validation package: `server/auth/` — `authenticator.go` validates the access token and `token.go` handles token generation/verification.
