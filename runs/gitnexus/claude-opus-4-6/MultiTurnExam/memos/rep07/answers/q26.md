The following tables are affected when `DeleteMemo` runs:

- **memo_relation** — explicitly deleted in `store/memo.go:142–146` (both as source and target)
- **attachment** — explicitly deleted in `store/memo.go:149–156`
- **memo** — the memo row itself, deleted in `store/memo.go:158`
- **memo_share** — cascade-deleted via `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (defined in `store/migration/sqlite/LATEST.sql` and `store/migration/postgres/LATEST.sql`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), comment memos (related via `memo_relation` with type `Comment`) are recursively deleted, which triggers the same cascade for each comment memo.
