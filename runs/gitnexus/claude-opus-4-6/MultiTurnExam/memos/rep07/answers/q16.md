Before deleting the memo row itself, the store layer (`store/memo.go:140–159`) deletes:

1. **Memo relations** (where the memo is the source `MemoID`)
2. **Memo relations** (where the memo is the target `RelatedMemoID`)

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos related via `MemoRelationComment`) are recursively deleted before the parent memo's `Store.DeleteMemo` is called.
