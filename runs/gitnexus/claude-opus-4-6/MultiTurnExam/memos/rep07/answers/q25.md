Engine: CEL (Common Expression Language) via `cel-go`, implemented in `internal/filter/engine.go`

The filter string is parsed by the CEL environment into an AST, which is then converted into a dialect-agnostic condition tree (`internal/filter/parser.go`). That condition tree is rendered into dialect-specific SQL by the renderer in `internal/filter/render.go`, which accepts a `DialectName` parameter (SQLite, PostgreSQL, or MySQL). Each dialect's `ListMemos` implementation calls `filter.AppendConditions()` with its dialect constant (e.g., `filter.DialectSQLite` in `store/db/sqlite/memo.go`, `filter.DialectPostgres` in `store/db/postgres/memo.go`, `filter.DialectMySQL` in `store/db/mysql/memo.go`), which compiles the CEL expression and renders the appropriate SQL WHERE clause with dialect-correct placeholders.
