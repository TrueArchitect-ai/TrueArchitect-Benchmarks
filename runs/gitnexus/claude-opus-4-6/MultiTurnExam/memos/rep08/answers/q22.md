The `CreateMemo` handler calls `DispatchMemoCreatedWebhook` (line 15 of `memo_service_webhooks.go`), which resolves the memo creator's webhooks and calls `webhook.PostAsync`. The `internal/webhook` package (`internal/webhook/webhook.go`) performs the HTTP POST delivery. Requests are signed using **HMAC-SHA256** following the Standard Webhooks convention: the signing secret (optionally `whsec_<base64>`) is used to compute an HMAC over `msgID + "." + timestamp + "." + body`, and the signature is sent in the `webhook-signature` header as `v1,<base64>` (lines 133–149).
