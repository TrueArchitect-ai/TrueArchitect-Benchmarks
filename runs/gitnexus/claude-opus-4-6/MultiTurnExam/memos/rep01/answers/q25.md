Engine: CEL (Common Expression Language) via `cel-go`, implemented in `internal/filter/engine.go` (the `Engine` struct wraps a `cel.Env`).

The filter string is parsed by the CEL engine into a dialect-agnostic condition tree (`internal/filter/ir.go`), then each dialect's driver (e.g. `store/db/postgres/memo.go`, `store/db/mysql/memo.go`, `store/db/sqlite/memo.go`) calls `filter.AppendConditions()` passing its dialect constant (`DialectPostgres`, `DialectMySQL`, or `DialectSQLite`), which invokes the SQL renderer in `internal/filter/render.go` to translate the parsed condition tree into dialect-specific SQL WHERE clauses with parameterized arguments.
