When a memo is deleted, the store layer (in `store/memo.go:140–158`) deletes these records before the memo row itself:

1. **Memo relations** — deletes all `memo_relation` rows where the memo is either the source (`MemoID`) or target (`RelatedMemoID`)
2. **Attachments** — deletes all `attachment` rows linked to the memo

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **comment memos** (child memos linked via a `Comment`-type relation) are recursively deleted via `Store.DeleteMemo` before the parent memo itself is deleted, which in turn triggers the same relation and attachment cleanup for each comment.
