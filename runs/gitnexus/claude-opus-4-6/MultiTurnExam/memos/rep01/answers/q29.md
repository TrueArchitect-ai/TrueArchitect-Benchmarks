Interceptor: `authInterceptor` in `web/src/connect.ts` (line 156) — it attaches a `Bearer` access token via the `Authorization` header, and transparently refreshes it when expired or on `Unauthenticated` errors. Token state is managed in `web/src/auth-state.ts`.

Token kinds: **access tokens** (short-lived JWTs), **refresh tokens** (used to obtain new access tokens via `RefreshToken` RPC), and **Personal Access Tokens (PATs)** (long-lived, `pat_`-prefixed tokens for programmatic access).

Backend validation package: `server/auth` (`server/auth/authenticator.go`) — the `Authenticator` struct validates all three token types via `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT`.
