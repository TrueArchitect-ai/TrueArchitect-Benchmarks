Before deleting the memo row itself, the store layer (`store/memo.go:140–159`) deletes:

1. **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID`
2. **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID`
3. **Attachments** linked to the memo — each attachment found via `ListAttachments` is individually deleted with `DeleteAttachment`

Additionally, at the API layer (`server/router/api/v1/memo_service.go:567–577`), **memo comments** (memos related via `MemoRelationComment`) are deleted before the parent memo — and each comment deletion in turn triggers the same store-level cascade of relations and attachments.
