Engine: CEL (Common Expression Language) via `google/cel-go`, implemented in `internal/filter/` (engine in `internal/filter/engine.go`, parser in `internal/filter/parser.go`).

The filter string is parsed into a dialect-agnostic IR condition tree by the CEL engine (`internal/filter/engine.go`), then each dialect driver calls `filter.AppendConditions()` (`internal/filter/helpers.go:9`) passing its dialect name (e.g., `filter.DialectPostgres`, `filter.DialectMySQL`, `filter.DialectSQLite`), which renders the IR into dialect-specific SQL WHERE clauses with proper placeholder syntax via `internal/filter/render.go`.
