The premise is incorrect — there is no GraphQL schema in this project. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** services that are also exposed as RESTful HTTP endpoints via `google.api.http` annotations.

The API schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — File attachments
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/common.proto` — Shared types

Each service uses `google.api.http` annotations to map gRPC RPCs to REST paths (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). The Go server implementations live under `server/router/api/v1/`, and generated TypeScript protobuf types are consumed by the frontend from `web/src/types/proto/api/v1/`. Code generation is configured via `proto/buf.gen.yaml`.
