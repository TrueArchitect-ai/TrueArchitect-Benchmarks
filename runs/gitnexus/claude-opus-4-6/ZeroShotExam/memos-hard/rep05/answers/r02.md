The premise of this question is incorrect. This repository (Memos) does **not** have a per-user API rate-limiting middleware. 

The server middleware registered in `server/server.go` consists only of:
- `middleware.Recover()` — the Echo framework's panic recovery middleware
- `newCORSMiddleware(profile)` — a custom CORS middleware defined in `server/cors.go`

There is no rate-limiting middleware, no request-per-user throttling, no token bucket or sliding window rate limiter anywhere in the codebase. The only mention of "rate limit" is a comment in `internal/email/doc.go` describing a hypothetical best practice for email sending, not an implemented feature.
