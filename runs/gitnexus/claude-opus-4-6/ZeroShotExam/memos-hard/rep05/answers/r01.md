The premise is incorrect — there is no Redis connection. The cache layer is an **in-memory cache**, not Redis-backed. It is implemented as a custom Go `sync.Map`-based cache in `store/cache/cache.go`.

The cache is configured in `store/store.go:38-45`, where the `Store.New()` constructor creates a `cache.Config` with:

- **DefaultTTL: 10 minutes** (`10 * time.Minute`) — this applies uniformly to all caches, including the `userCache` and `userSettingCache`
- CleanupInterval: 5 minutes
- MaxItems: 1000

The `Store` struct (`store/store.go:13-30`) holds three separate cache instances — `instanceSettingCache`, `userCache`, and `userSettingCache` — all initialized with the same config and the same 10-minute TTL. Individual entries can override the TTL via `SetWithTTL()` (`store/cache/cache.go:98`), but the default for user entries is 10 minutes.
