The `Runner.RunOnce` exists but isn't wired into server startup — it's a standalone batch rebuilder. The two live call sites are in `CreateMemo` and `UpdateMemo`.

h14.

**Computation site:** `server/runner/memopayload/runner.go:74` — the `RebuildMemoPayload` function, which calls `markdownService.ExtractAll()` (defined at `internal/markdown/markdown.go:356`). `ExtractAll` parses the memo's markdown content via goldmark and walks the AST in a single pass to extract all derived metadata.

**Triggers:** Three operations trigger recomputation:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting a new memo.
2. **UpdateMemo** (content path) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `"content"` field is in the update mask.
3. **RunOnce batch rebuild** — `server/runner/memopayload/runner.go:27` iterates all memos in batches of 100, calling `RebuildMemoPayload` on each and writing back to the store. (This is not wired into server startup but exists as a standalone batch reprocessor.)

**Extracted properties** (stored in `Payload.Property` as `MemoPayload_Property`, plus `Payload.Tags`):
- **`Tags`** (`[]string`) — all `#tag` nodes found in the markdown (deduplicated, case-preserving).
- **`Title`** (`string`) — plain text of the first block-level element if it is an H1 heading.
- **`HasLink`** (`bool`) — whether the content contains any markdown link node.
- **`HasCode`** (`bool`) — whether the content contains a code block, fenced code block, or inline code span.
- **`HasTaskList`** (`bool`) — whether the content contains any GFM task checkbox.
- **`HasIncompleteTasks`** (`bool`) — whether any task checkbox is unchecked.

Additionally, a **`Snippet`** (plain-text summary, max 64 characters, truncated at word boundary) is computed on-the-fly at read time by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`) via `GenerateSnippet` (`internal/markdown/markdown.go:264`) — this is not persisted in the payload but derived during memo conversion for API responses (`server/router/api/v1/memo_service_converter.go:76-80`).
