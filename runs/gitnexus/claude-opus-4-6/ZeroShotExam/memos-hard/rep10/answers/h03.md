The package `internal/idp` (`internal/idp/idp.go`) defines the provider abstraction — the `IdentityProviderUserInfo` struct that all providers return. The concrete protocol implementation is `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements an OAuth2 identity provider.
