The premise of the question is incorrect. There is no "nightly database-cleanup job" configured in this codebase. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`) is a general-purpose cron scheduler library, but it has no production job registrations — no code outside of tests and documentation examples calls `scheduler.Register()` or `scheduler.New()`.

The only references to "cleanup" in the scheduler package are illustrative examples in `internal/scheduler/doc.go` (a `"daily-cleanup"` example with schedule `"0 2 * * *"`) and `internal/scheduler/example_test.go` (a `"cleanup"` job also at `"0 2 * * *"`). These are documentation/test fixtures, not an actual scheduled database-cleanup job running in production.
