The premise is incorrect — this repository (Memos) does not use GraphQL. There is no GraphQL schema anywhere in the codebase.

The public API is defined using **Protocol Buffers (protobuf)** with **gRPC-Gateway** for REST transcoding. The service definitions live in `proto/api/v1/*.proto`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto` (shared types)

These `.proto` files are compiled into Go code under `proto/gen/api/v1/` — including `*.pb.go` (message types), `*_grpc.pb.go` (gRPC stubs), and `*.pb.gw.go` (gRPC-Gateway HTTP reverse proxies). The generated gateway code (e.g., `RegisterMemoServiceHandlerClient` in `proto/gen/api/v1/memo_service.pb.gw.go`) maps HTTP/JSON endpoints to the underlying gRPC services, giving the API a RESTful surface without GraphQL.
