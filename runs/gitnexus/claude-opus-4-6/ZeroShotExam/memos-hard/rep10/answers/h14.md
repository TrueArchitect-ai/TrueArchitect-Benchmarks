**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356-422`. `ExtractAll` parses the memo's markdown content with goldmark and walks the AST in a single pass.

**Triggers:** Two operations call `RebuildMemoPayload`:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108`, invoked before persisting a new memo.
2. **UpdateMemo** — `server/router/api/v1/memo_service.go:447`, invoked when the `content` field path is updated.

Additionally, `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) can batch-rebuild payloads for all memos (migration/repair path).

**Extracted properties** (defined in `proto/store/memo.proto:15-22` as `MemoPayload.Property`):
- **`has_link`** — true if the content contains a markdown link (`gast.KindLink`)
- **`has_code`** — true if the content contains code blocks or code spans (`KindCodeBlock`, `KindFencedCodeBlock`, `KindCodeSpan`)
- **`has_task_list`** — true if the content contains GFM task checkboxes (`east.KindTaskCheckBox`)
- **`has_incomplete_tasks`** — true if any task checkbox is unchecked
- **`title`** — plain text of the first block-level H1 heading, if the first block child of the document is an `# H1`

The same `ExtractAll` pass also extracts **`tags`** (deduplicated `#tag` nodes) and **`mentions`** (`@username` nodes), which are stored in `MemoPayload.Tags` alongside the `Property` struct (`runner.go:85-86`).
