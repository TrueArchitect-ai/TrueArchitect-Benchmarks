The premise of the question is incorrect. This repository (Memos) does not have a per-user API rate-limiting middleware. There is no rate-limiting middleware registered anywhere in the codebase.

The server middleware stack (visible in `server/server.go` and `server/cors.go`) includes CORS handling and authentication/authorization (`server/router/api/v1/authz.go`), but no request rate limiting of any kind — neither per-user nor global.

The only concurrency-limiting mechanism in the codebase is a `thumbnailSemaphore` in `server/router/api/v1/v1.go` (line ~39), which caps concurrent thumbnail generation to 3 using a weighted semaphore. This is a resource-protection measure for memory, not an API rate limiter.

There is also a comment in `internal/email/doc.go` mentioning rate-limiting email sending as a future concern, but it is not implemented.
