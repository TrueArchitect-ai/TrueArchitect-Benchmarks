**Computation site:** `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356-422`. `ExtractAll` parses the memo's markdown content into a goldmark AST and walks it in a single pass to collect the derived metadata.

**Triggers:** Three operations trigger recomputation:
1. **CreateMemo** — called at `server/router/api/v1/memo_service.go:108` before persisting a new memo.
2. **UpdateMemo** — called at `server/router/api/v1/memo_service.go:447` when the `"content"` field is in the update mask.
3. **Runner.RunOnce** — a batch rebuild of all memos (`server/runner/memopayload/runner.go:27-72`), which iterates every memo in paginated batches and calls `RebuildMemoPayload` + `Store.UpdateMemo` on each.

**Extracted properties** (stored in `memo.Payload.Tags` and `memo.Payload.Property`):
- **Tags** (`[]string`) — deduplicated `#tag` values found in the content (excluding tags inside links/images).
- **Property.HasLink** (`bool`) — whether the content contains any markdown link.
- **Property.HasCode** (`bool`) — whether the content contains a code block, fenced code block, or code span.
- **Property.HasTaskList** (`bool`) — whether the content contains any GFM task checkbox.
- **Property.HasIncompleteTasks** (`bool`) — whether any task checkbox is unchecked.
- **Property.Title** (`string`) — the text of the first block-level element if it is an H1 heading.
