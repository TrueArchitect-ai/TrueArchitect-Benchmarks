The data layer is the `store/` package, which defines persistent entity types as Go structs.

**1st: Memo — ~7 packages** (`server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`)

**2nd: User — ~7 packages** (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`)

Both `Memo` and `User` are tied at 7 packages each outside `store/`, but `Memo` edges ahead slightly when counting the breadth of distinct functional areas (it reaches into `server/runner/memopayload` — a runner package — while `User` reaches into `server/auth`). The third-place entity, `Attachment`, trails at 5 packages. The key entity type files are `store/memo.go` and `store/user.go`.
