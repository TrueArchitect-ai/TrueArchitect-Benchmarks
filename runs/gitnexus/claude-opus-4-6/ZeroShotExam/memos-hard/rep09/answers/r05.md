The premise is incorrect — this repository does not use GraphQL. The public API is defined using **Protocol Buffers (gRPC) with gRPC-Gateway** for REST transcoding.

The API surface is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/common.proto` — Shared types

These protobuf definitions are compiled into Go server stubs (visible as gRPC service implementations throughout the `server/` directory) and are exposed as a RESTful HTTP/JSON API via gRPC-Gateway. There is no GraphQL schema anywhere in the codebase.
