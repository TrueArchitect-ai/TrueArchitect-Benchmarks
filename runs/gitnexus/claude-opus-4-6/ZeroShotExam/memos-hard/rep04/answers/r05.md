The premise is incorrect — this project does **not** use GraphQL. The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** (HTTP/JSON transcoding).

The API schema is defined in `.proto` files under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/attachment_service.proto` — Attachments
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/idp_service.proto` — Identity providers
- `proto/api/v1/shortcut_service.proto` — Shortcuts
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/common.proto` — Shared types

Each `.proto` file defines gRPC `service` blocks with `rpc` methods, and uses `google.api.http` annotations to expose them as RESTful HTTP endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). The buf toolchain (`proto/buf.yaml`, `proto/buf.gen.yaml`) generates Go code into `proto/gen/`, and the resulting HTTP handlers are wired through the router at `server/router/api/`.
