The premise is incorrect — the webhook delivery workers use **neither NATS nor RabbitMQ**. There is no external message broker at all.

Webhook delivery uses a **plain Go buffered channel** as an in-process async queue, declared at `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four goroutine workers are spawned in the package's `init()` function (`internal/webhook/webhook.go:42–55`) that range over this channel and call `Post()` to deliver each webhook via HTTP. The public entry point for async dispatch is `PostAsync()` (`internal/webhook/webhook.go:183–196`), which does a non-blocking send into the channel (dropping the payload with a warning if the buffer is full).

No external broker (NATS, RabbitMQ, or otherwise) is involved anywhere in the codebase for webhook delivery.
