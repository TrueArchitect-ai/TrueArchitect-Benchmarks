Memo visibility is enforced across many distinct server surfaces. Here is every enforcement site:

1. **Core memo read-access gate** — `server/router/api/v1/memo_service.go` (`checkMemoReadAccess`, called by `GetMemo` and `ListMemoComments`)
2. **ListMemos query-time filtering** — `server/router/api/v1/memo_service.go` (`ListMemos` restricts `VisibilityList` and CEL filters by auth/creator)
3. **GetMemo single-memo check** — `server/router/api/v1/memo_service.go` (`GetMemo` calls `checkMemoReadAccess` on memo and parent)
4. **CreateMemoComment visibility gate** — `server/router/api/v1/memo_service_comments.go` (blocks commenting on private memos for non-creators)
5. **ListMemoComments visibility filtering** — `server/router/api/v1/memo_service_comments.go` (CEL filter on comment visibility)
6. **ListMemoReactions visibility check** — `server/router/api/v1/reaction_service.go` (denies private memo access to non-creator)
7. **UpsertMemoReaction visibility check** — `server/router/api/v1/reaction_service.go` (blocks reacting to private memos)
8. **ListMemoRelations visibility filtering** — `server/router/api/v1/memo_relation_service.go` (CEL filter on related memos)
9. **ListMemoAttachments visibility check** — `server/router/api/v1/memo_attachment_service.go` (same pattern as `checkMemoReadAccess`)
10. **GetAttachment (gRPC) via memo visibility** — `server/router/api/v1/attachment_service.go` (`checkAttachmentAccess`)
11. **File server attachment serving** — `server/router/fileserver/fileserver.go` (`checkAttachmentPermission`)
12. **SSE hub event delivery filtering** — `server/router/api/v1/sse_hub.go` (`canReceive` filters live events by visibility)
13. **RSS feed (explore)** — `server/router/rss/rss.go` (`GetExploreRSS` forces `VisibilityList: [Public]`)
14. **RSS feed (per-user)** — `server/router/rss/rss.go` (`GetUserRSS` forces `VisibilityList: [Public]`)
15. **Sitemap** — `server/router/frontend/frontend.go` (`getSitemapXML` forces `VisibilityList: [Public]`)
16. **ListAllUserStats** — `server/router/api/v1/user_service_stats.go` (visibility-scoped memo counts)
17. **GetUserStats** — `server/router/api/v1/user_service_stats.go` (visibility-scoped memo counts)
18. **Mention/notification helpers** — `server/router/api/v1/memo_mention_helpers.go` (`canUserAccessMentionContext`, `shouldSkipMentionInbox`)
19. **Notification API conversion** — `server/router/api/v1/user_service_notifications.go` (`canViewerAccessMemo`, suppresses comment/mention notifications for invisible memos)
20. **Email notification dispatch** — `server/notification/email.go` (`canViewerAccessMemo`, suppresses email for invisible memos)
21. **Store layer SQL filtering** — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go` (translate `VisibilityList` into SQL `WHERE memo.visibility IN (...)` clauses)
