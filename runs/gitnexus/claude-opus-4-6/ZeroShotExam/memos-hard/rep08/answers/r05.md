The premise is incorrect — this repository does **not** use GraphQL. The public API is defined using **gRPC/Protocol Buffers (protobuf)**, with schema definitions located in `proto/api/v1/`. The service `.proto` files include:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto`

These protobuf definitions are served via a gRPC gateway (see `server/router/api/`), which exposes them as a RESTful HTTP API as well. There are no `.graphql`/`.gql` files or any GraphQL dependencies anywhere in the codebase.
