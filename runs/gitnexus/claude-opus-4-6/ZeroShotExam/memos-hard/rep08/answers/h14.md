**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `MarkdownService.ExtractAll()` implemented in `internal/markdown/markdown.go:356-422`. The extraction parses the memo's markdown content into a goldmark AST and walks it in a single pass.

**Triggers:** Three operations trigger recomputation:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting a new memo.
2. **UpdateMemo** — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` when the `content` field is in the update mask.
3. **Batch rebuild (`RunOnce`)** — `server/runner/memopayload/runner.go:27-71` iterates all memos in batches of 100, rebuilding every payload (used for bulk re-derivation at startup or migration).

**Extracted properties** (stored as `MemoPayload.Property`, defined in `proto/store/memo.proto`):
- **`has_link`** (bool) — true if the content contains any markdown link node
- **`has_task_list`** (bool) — true if the content contains a GFM task checkbox
- **`has_code`** (bool) — true if the content contains a code block, fenced code block, or inline code span
- **`has_incomplete_tasks`** (bool) — true if any task checkbox is unchecked
- **`title`** (string) — plain text of the first H1 heading, if the first block-level child of the document is an `# H1`

In addition to these `Property` fields, `ExtractAll` also derives `tags` (deduplicated `#tag` nodes) and `mentions` (`@mention` nodes), which are stored in `MemoPayload.Tags` alongside the property — all computed from the same single AST walk.
