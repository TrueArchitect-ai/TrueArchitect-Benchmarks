The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this codebase. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`, `internal/scheduler/parser.go`) is a general-purpose cron job scheduling library, but it is never used to register an actual database-cleanup job anywhere in the application code. The "daily-cleanup" and "stale-session-cleanup" examples that appear in the documentation (`internal/scheduler/README.md`, `internal/scheduler/doc.go`) and test files (`internal/scheduler/example_test.go`) are illustrative samples showing how to use the scheduler API — they are not real, deployed jobs. No production code in this repository registers any job with the scheduler.
