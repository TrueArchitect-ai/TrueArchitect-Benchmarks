h03.
`internal/idp`; `internal/idp/oauth2`

The provider abstraction is defined in package `internal/idp` (`internal/idp/idp.go`), which declares the `IdentityProviderUserInfo` struct used as the common return type. The concrete protocol implementation that ships is package `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), which implements an OAuth2 identity provider with token exchange and user-info retrieval.
