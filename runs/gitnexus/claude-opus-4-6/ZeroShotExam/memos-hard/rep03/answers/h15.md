Memo visibility is enforced across many server surfaces. Here are all distinct enforcement sites:

1. **`checkMemoReadAccess` (central gate for single-memo reads)** — `server/router/api/v1/memo_service.go`
2. **`GetMemo` (calls checkMemoReadAccess on memo and parent)** — `server/router/api/v1/memo_service.go`
3. **`ListMemos` (query-time visibility filter via VisibilityList/filter strings)** — `server/router/api/v1/memo_service.go`
4. **`CreateMemoComment` (inline private-memo check before allowing comment)** — `server/router/api/v1/memo_service_comments.go`
5. **`ListMemoComments` (checkMemoReadAccess + per-comment visibility filter)** — `server/router/api/v1/memo_service_comments.go`
6. **`ListMemoReactions` (inline visibility check)** — `server/router/api/v1/reaction_service.go`
7. **`UpsertMemoReaction` (inline private-memo check)** — `server/router/api/v1/reaction_service.go`
8. **`ListMemoAttachments` (inline visibility check)** — `server/router/api/v1/memo_attachment_service.go`
9. **`checkAttachmentAccess` / `GetAttachment` (resolves linked memo, enforces visibility)** — `server/router/api/v1/attachment_service.go`
10. **`checkAttachmentPermission` (HTTP file-serving layer with share-token fallback)** — `server/router/fileserver/fileserver.go`
11. **`canReceive` on SSEClient (filters live-push events by visibility)** — `server/router/api/v1/sse_hub.go`
12. **`canViewerAccessMemo` (notification payload visibility gate)** — `server/router/api/v1/user_service_notifications.go`
13. **`convertMemoCommentNotificationPayload` (suppresses inaccessible comment notifications)** — `server/router/api/v1/user_service_notifications.go`
14. **`convertMemoMentionNotificationPayload` (suppresses inaccessible mention notifications)** — `server/router/api/v1/user_service_notifications.go`
15. **`canViewerAccessMemo` (duplicate implementation for email dispatch)** — `server/notification/email.go`
16. **`buildMemoCommentEmailMessage` (suppresses email if viewer can't access)** — `server/notification/email.go`
17. **`buildMemoMentionEmailMessage` (suppresses email if viewer can't access)** — `server/notification/email.go`
18. **`canUserAccessMentionContext` / `shouldSkipMentionInbox` (mention inbox visibility guard)** — `server/router/api/v1/memo_mention_helpers.go`
19. **`GetExploreRSS` (restricts feed to public-only memos)** — `server/router/rss/rss.go`
20. **`GetUserRSS` (restricts feed to public-only memos)** — `server/router/rss/rss.go`
21. **`getSitemapXML` (restricts sitemap to public-only memos)** — `server/router/frontend/frontend.go`
22. **`ListAllUserStats` (visibility-filtered memo counts)** — `server/router/api/v1/user_service_stats.go`
23. **`GetUserStats` (visibility-filtered per-user stats)** — `server/router/api/v1/user_service_stats.go`
24. **`batchConvertMemoRelations` (filters related memos by visibility)** — `server/router/api/v1/memo_service_converter.go`
25. **Store-layer `VisibilityList` SQL filter (shared by all DB drivers)** — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`
