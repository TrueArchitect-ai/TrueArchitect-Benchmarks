The outbound webhook delivery executes in the `Post` function at `internal/webhook/webhook.go:120-179`. It serializes the payload as JSON, constructs an HTTP POST request, optionally signs it with HMAC-SHA256 (Standard Webhooks format), and sends it via a shared `safeClient`. Asynchronous dispatch goes through `PostAsync` (line 184), which enqueues payloads onto a buffered channel consumed by 4 goroutine workers (initialized in `init`, line 42-55), each calling `Post`.

SSRF protection is a two-layer defense, both in `internal/webhook/`:

1. **Registration-time validation** — `ValidateURL` (`internal/webhook/validate.go:62-83`) resolves the hostname and checks every resulting IP against `reservedCIDRs` (loopback, RFC-1918 private ranges, link-local/cloud IMDS `169.254.0.0/16`, and IPv6 equivalents) via `isReservedIP`. This blocks saving a webhook URL that points at internal addresses.

2. **Dial-time enforcement** — `safeDialContext` (`internal/webhook/webhook.go:59-77`) is wired into the `safeClient`'s transport as a custom `DialContext`. It re-resolves the hostname at connection time and rejects any IP in a reserved range, defeating DNS rebinding attacks where a hostname resolves to a public IP at validation time but a private IP at request time.

Both layers share the same `isReservedIP` / `reservedNetworks` check. A toggle `AllowPrivateIPs` (`validate.go:41`) disables both checks for self-hosted deployments that legitimately target local services.

**delivery function** — `Post` at `internal/webhook/webhook.go`; **protection mechanism** — `safeDialContext` + `ValidateURL` (reserved-IP blocklist checked at both dial time and registration time) at `internal/webhook/webhook.go` and `internal/webhook/validate.go`
