The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this codebase. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, etc.) is a general-purpose cron scheduling library, but it is not used anywhere in the application server code to register a database-cleanup job. The only references to "cleanup" within the scheduler package are in documentation and test examples (`internal/scheduler/example_test.go`, `internal/scheduler/doc.go`, `internal/scheduler/README.md`), which illustrate how the scheduler *could* be used — they are not actual scheduled jobs that run in production. No Go file outside the scheduler package imports or uses it to schedule any job.
