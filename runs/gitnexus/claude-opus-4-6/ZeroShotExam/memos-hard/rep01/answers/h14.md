**Computation site:** `internal/markdown/markdown.go` — the `ExtractProperties` method (lines 193–241) and the combined `ExtractAll` method (lines 356–422) on the markdown `Service`. These parse the memo content into a goldmark AST and walk it to populate a `storepb.MemoPayload_Property` struct. The actual wiring that persists the result into the memo payload lives in `server/runner/memopayload/runner.go` in the `RebuildMemoPayload` function (line 74), which calls `ExtractAll` and assigns `data.Property` back to `memo.Payload.Property` (line 86).

**Triggers:** Recomputation is triggered by three operations:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `memopayload.RebuildMemoPayload` before persisting a new memo.
2. **UpdateMemo** (when the `"content"` field is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload` after the content changes.
3. **Batch rebuild** — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` iterates all memos in batches of 100 and rebuilds every payload (used for bulk re-derivation, though not currently invoked at server startup).

**Extracted properties** (defined in `proto/gen/store/memo.pb.go` as `MemoPayload_Property`):
- `HasLink` (bool) — whether the content contains any markdown link node
- `HasTaskList` (bool) — whether the content contains any GFM task checkbox
- `HasCode` (bool) — whether the content contains a code block, fenced code block, or inline code span
- `HasIncompleteTasks` (bool) — whether any task checkbox is unchecked
- `Title` (string) — plain text of the first H1 heading if the first block-level child of the document is an `# H1`

Additionally, `ExtractAll` also extracts `Tags` (deduplicated `#tag` values) and `Mentions` (`@username` values) which are stored in `memo.Payload.Tags` alongside the `Property` struct (`runner.go:85–86`).
