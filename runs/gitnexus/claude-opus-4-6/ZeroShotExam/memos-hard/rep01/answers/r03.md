The premise of this question is incorrect. There is no "nightly database-cleanup job" configured in this codebase. The `internal/scheduler/` package is a **general-purpose cron scheduler library** — it provides the machinery to register and run scheduled jobs (`scheduler.go`, `parser.go`, `job.go`), but no actual database-cleanup job is registered or scheduled anywhere in the application code.

The only references to "cleanup" jobs appear in **documentation and examples** — not in production code:

- `internal/scheduler/doc.go` — a doc comment example with `"daily-cleanup"`
- `internal/scheduler/example_test.go` — a test example noting "Cleanup old data every night at 2 AM" with job name `"cleanup"`
- `internal/scheduler/README.md` — documentation examples like `"daily-cleanup"`, `"stale-session-cleanup"`, and `"user-cleanup-job"`

The server startup code in `server/server.go` does not import or use the scheduler package at all, and no scheduled jobs (database-cleanup or otherwise) are registered in any non-test, non-documentation Go file.
