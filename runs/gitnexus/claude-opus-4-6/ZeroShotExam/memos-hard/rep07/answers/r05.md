**Premise correction:** This repository does not use GraphQL. There is no GraphQL schema defined anywhere in the codebase.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **REST** (via gRPC-Gateway/OpenAPI). The API definition files are:

- **Protobuf service definitions:** `proto/api/v1/*.proto` — including `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, and `common.proto`.
- **Generated OpenAPI spec:** `proto/gen/openapi.yaml` — the REST-facing schema generated from the protobuf definitions.
- **Buf configuration:** `proto/buf.yaml` and `proto/buf.gen.yaml` — govern code generation from the `.proto` files.

The `README.md` confirms this: the project exposes "full REST and gRPC APIs for integration." The Go server routes the API via `server/router/api/v1/`.
