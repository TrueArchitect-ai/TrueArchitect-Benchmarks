**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which delegates to `markdownService.ExtractAll()` implemented in `internal/markdown/markdown.go:356-422`. The snippet is computed separately by `getMemoContentSnippet` in `server/router/api/v1/memo_service_webhooks.go:83-90` (calling `markdownService.GenerateSnippet`).

**Triggers:** Three operations trigger recomputation:
1. **CreateMemo** — `server/router/api/v1/memo_service.go:108` calls `RebuildMemoPayload` before persisting.
2. **UpdateMemo** (when `content` is in the update mask) — `server/router/api/v1/memo_service.go:447` calls `RebuildMemoPayload`.
3. **Runner.RunOnce** batch rebuild — `server/runner/memopayload/runner.go:27-72` iterates all memos in batches of 100 and calls `RebuildMemoPayload` + `Store.UpdateMemo` on each, rebuilding the entire database's payload.

The snippet (`GenerateSnippet`) is computed on-the-fly at read time during memo conversion (`memo_service_converter.go:76-80`) rather than being stored.

**Extracted properties** (from `ExtractAll` → stored in `MemoPayload`):
- **Tags** — deduplicated `#tag` nodes extracted from the AST (`markdown.go:377`)
- **Property.HasLink** — `true` if content contains a markdown link (`markdown.go:394`)
- **Property.HasCode** — `true` if content contains a code block, fenced code block, or code span (`markdown.go:396`)
- **Property.HasTaskList** — `true` if content contains a GFM task checkbox (`markdown.go:400`)
- **Property.HasIncompleteTasks** — `true` if any task checkbox is unchecked (`markdown.go:402-403`)
- **Property.Title** — plain text of the first block-level element if it is an H1 heading (`markdown.go:384-388`)
- **Snippet** (computed at read time, not stored) — plain-text summary truncated to 64 characters at a word boundary (`markdown.go:264-346`)
