The premise of the question is incorrect. There is no "nightly database-cleanup job" in this codebase. The only "cleanup" reference is in an **example test** (`internal/scheduler/example_test.go:97-105`), which illustrates how to use the scheduler API with a hypothetical cleanup job scheduled at `0 2 * * *` (2 AM).
