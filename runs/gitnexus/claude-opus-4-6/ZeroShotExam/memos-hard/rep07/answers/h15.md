Memo visibility is enforced at numerous distinct server-side sites. Here is every enforcement location:

1. **checkMemoReadAccess (central gate for GetMemo, ListMemoComments)** — `server/router/api/v1/memo_service.go`
2. **ListMemos query-level visibility filtering** — `server/router/api/v1/memo_service.go`
3. **UpdateMemo (forces comment visibility to inherit parent)** — `server/router/api/v1/memo_service.go`
4. **CreateMemoComment (private memo gating + forced visibility inheritance)** — `server/router/api/v1/memo_service_comments.go`
5. **ListMemoComments visibility filtering** — `server/router/api/v1/memo_service_comments.go`
6. **batchConvertMemoRelations visibility filtering** — `server/router/api/v1/memo_service_converter.go`
7. **ListMemoRelations visibility filtering** — `server/router/api/v1/memo_relation_service.go`
8. **ListMemoAttachments inline visibility check** — `server/router/api/v1/memo_attachment_service.go`
9. **checkAttachmentAccess (gRPC attachment access via memo visibility)** — `server/router/api/v1/attachment_service.go`
10. **checkAttachmentPermission (HTTP file server, includes share-token fallback)** — `server/router/fileserver/fileserver.go`
11. **ListMemoReactions visibility check** — `server/router/api/v1/reaction_service.go`
12. **UpsertMemoReaction visibility check** — `server/router/api/v1/reaction_service.go`
13. **SSE event delivery filtering (canReceive)** — `server/router/api/v1/sse_hub.go`
14. **SSE event visibility propagation (buildMemoReactionSSEEvent)** — `server/router/api/v1/sse_event_helpers.go`
15. **canUserAccessMentionContext / shouldSkipMentionInbox** — `server/router/api/v1/memo_mention_helpers.go`
16. **canViewerAccessMemo for notification payloads** — `server/router/api/v1/user_service_notifications.go`
17. **canViewerAccessMemo for email notifications** — `server/notification/email.go`
18. **GetUserStats / ListAllUserStats visibility filtering** — `server/router/api/v1/user_service_stats.go`
19. **RSS feed (global + per-user) restricted to Public** — `server/router/rss/rss.go`
20. **Sitemap restricted to Public memos** — `server/router/frontend/frontend.go`
21. **Database-level VisibilityList SQL filtering** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`
