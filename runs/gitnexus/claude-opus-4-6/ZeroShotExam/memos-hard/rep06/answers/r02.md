The premise of the question is incorrect. This repository (Memos) does not implement per-user API rate-limiting middleware. There is no rate limiter, throttle, or per-user request quota registered anywhere in the server code.

The server (`server/server.go`) registers middleware for CORS (`server/cors.go`), authentication/authorization (`server/router/api/v1/authz.go`, `server/router/api/v1/acl_config.go`), and frontend serving (`server/router/frontend/frontend.go`), but none of these involve rate limiting. The only mention of "rate limit" in the entire codebase is a documentation comment in `internal/email/doc.go` describing a hypothetical goal for the email subsystem, not an actual implementation.
