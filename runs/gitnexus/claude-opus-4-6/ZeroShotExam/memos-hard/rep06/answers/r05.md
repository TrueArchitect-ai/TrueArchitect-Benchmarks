**Premise correction:** There is no GraphQL schema in this repository. The project does not use GraphQL at all.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with a **gRPC / Connect** dual-protocol setup:

- **Protobuf service definitions** are in `proto/api/v1/` — e.g., `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, etc.
- **Generated TypeScript clients** are in `web/src/types/proto/api/v1/` (e.g., `memo_service_pb.ts`).
- **Go server implementations** are in `server/router/api/v1/` — the `ConnectServiceHandler` in `server/router/api/v1/connect_handler.go` wraps the gRPC service implementations to support both native gRPC and the [Connect](https://connectrpc.com/) protocol (HTTP/JSON-compatible RPC) via a single codebase.
