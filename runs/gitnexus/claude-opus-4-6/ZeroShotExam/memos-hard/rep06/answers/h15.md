Memo visibility is enforced across many server surfaces. Here are the distinct enforcement sites:

1. **GetMemo single-memo read gate (`checkMemoReadAccess`)** — `server/router/api/v1/memo_service.go`
2. **ListMemos query-level visibility filtering** — `server/router/api/v1/memo_service.go`
3. **UpdateMemo comment visibility inheritance** (forces comment visibility to match parent) — `server/router/api/v1/memo_service.go`
4. **CreateMemoComment / ListMemoComments visibility checks** — `server/router/api/v1/memo_service_comments.go`
5. **ListMemoReactions / UpsertMemoReaction visibility checks** — `server/router/api/v1/reaction_service.go`
6. **ListMemoAttachments visibility check** — `server/router/api/v1/memo_attachment_service.go`
7. **checkAttachmentAccess (API layer attachment access via memo visibility)** — `server/router/api/v1/attachment_service.go`
8. **checkAttachmentPermission (file-serving layer, includes share-token fallback)** — `server/router/fileserver/fileserver.go`
9. **ListMemoRelations visibility filter on related memos** — `server/router/api/v1/memo_relation_service.go`
10. **batchConvertMemoRelations batch visibility filter** — `server/router/api/v1/memo_service_converter.go`
11. **GetUserStats / ListAllUserStats visibility filtering** — `server/router/api/v1/user_service_stats.go`
12. **SSE hub event delivery filtering (`canReceive`)** — `server/router/api/v1/sse_hub.go`
13. **RSS feed (PUBLIC-only)** — `server/router/rss/rss.go`
14. **Sitemap generation (PUBLIC-only)** — `server/router/frontend/frontend.go`
15. **Mention notification guards (`canUserAccessMentionContext` / `shouldSkipMentionInbox`)** — `server/router/api/v1/memo_mention_helpers.go`
16. **GetMemoByShare (share-token access bypass)** — `server/router/api/v1/memo_share_service.go`
17. **Database store drivers (SQL `WHERE visibility IN (...)`)** — `store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`
