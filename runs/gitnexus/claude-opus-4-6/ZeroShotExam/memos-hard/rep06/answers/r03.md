The premise of the question is incorrect. There is no "nightly database-cleanup job" scheduled in this codebase. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`, `internal/scheduler/parser.go`) is a general-purpose cron job scheduler library, but it is not imported or used by any production code outside of its own package — no files outside `internal/scheduler/` reference it (only test and example files within the package do).

The "cleanup" job running at `0 2 * * *` (2:00 AM) exists only in `internal/scheduler/example_test.go:97-106` as an illustrative example (`Example_multipleJobs`) demonstrating how to register multiple jobs. It is not a real scheduled database-cleanup job — it's a test example that prints `"Cleaning up old data..."` and has no database interaction.
