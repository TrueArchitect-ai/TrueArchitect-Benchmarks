The premise of this question is incorrect. There is no nightly database-cleanup job configured in this codebase. The `internal/scheduler/` package (`internal/scheduler/scheduler.go`, `internal/scheduler/job.go`, etc.) is a general-purpose cron job scheduler library, but it is not used anywhere in production code — no `scheduler.Register()` calls exist outside of examples, tests, and documentation. The "daily-cleanup" and "cleanup" jobs that appear in `internal/scheduler/doc.go`, `internal/scheduler/README.md`, and `internal/scheduler/example_test.go` are illustrative examples only (e.g., `Schedule: "0 2 * * *"` with the comment "2 AM daily"), not actual scheduled jobs. The scheduler package itself is never imported by the server or command entrypoints.
