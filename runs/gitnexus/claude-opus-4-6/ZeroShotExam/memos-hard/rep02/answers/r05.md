The premise is incorrect — this repository has **no GraphQL schema**. The public API is not defined using GraphQL.

The actual API surface is a **gRPC + REST (gRPC-Gateway) API** defined via **Protocol Buffers**. The `.proto` service definitions live in `proto/api/v1/` and include:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/common.proto`

Generated code (Go stubs and an OpenAPI spec) is output to `proto/gen/`, with the OpenAPI definition at `proto/gen/openapi.yaml`. The HTTP routes are registered via the gRPC-Gateway router under `server/router/api/v1/`.
