The agent's thorough search found the following distinct server-side enforcement sites for memo visibility:

1. **`checkMemoReadAccess` (central gate)** — `server/router/api/v1/memo_service.go` (used by `GetMemo` and `ListMemoComments`)
2. **`ListMemos` query-time filtering** — `server/router/api/v1/memo_service.go` (sets `VisibilityList` / CEL filter per caller context)
3. **`ListMemoComments` comment filtering** — `server/router/api/v1/memo_service_comments.go` (filters comment visibility after parent check)
4. **`CreateMemoComment` parent-memo check** — `server/router/api/v1/memo_service_comments.go` (blocks commenting on private memos)
5. **`ListMemoReactions` / `UpsertMemoReaction`** — `server/router/api/v1/reaction_service.go` (inline visibility check before reaction ops)
6. **`ListMemoAttachments`** — `server/router/api/v1/memo_attachment_service.go` (non-PUBLIC requires auth; PRIVATE = creator/admin)
7. **`checkAttachmentAccess`** — `server/router/api/v1/attachment_service.go` (linked attachment inherits memo visibility)
8. **`checkAttachmentPermission` (HTTP file server)** — `server/router/fileserver/fileserver.go` (memo visibility + share-token fallback)
9. **`ListAllUserStats` / `GetUserStats`** — `server/router/api/v1/user_service_stats.go` (visibility-filtered memo counting)
10. **RSS feeds (PUBLIC-only)** — `server/router/rss/rss.go` (both `GetSystemRSS` and `GetUserRSS`)
11. **Sitemap (PUBLIC-only)** — `server/router/frontend/frontend.go` (`getSitemapXML`)
12. **SSE event delivery (`canReceive`)** — `server/router/api/v1/sse_hub.go` (PRIVATE events only sent to creator/admin)
13. **Notification suppression (`canViewerAccessMemo`)** — `server/router/api/v1/user_service_notifications.go` (in-app notifications)
14. **Email notification suppression (`canViewerAccessMemo`)** — `server/notification/email.go` (duplicate of same logic for email path)
15. **Mention inbox gating (`canUserAccessMentionContext`)** — `server/router/api/v1/memo_mention_helpers.go` (prevents inbox items for inaccessible memos)
16. **Share-token bypass path** — `server/router/api/v1/memo_share_service.go` (`GetMemoByShare` grants access via valid share token)
17. **Store-level SQL filtering** — `store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go` (translate `VisibilityList` into `WHERE visibility IN (...)`)
