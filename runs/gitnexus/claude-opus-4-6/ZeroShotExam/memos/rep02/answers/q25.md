**Engine:** Google CEL (Common Expression Language) via `github.com/google/cel-go`; **Path:** `internal/filter/engine.go` (the `Engine` type and `Compile` method).

**Mechanism:** `Engine.Compile` parses the filter string through a `cel.Env`, converts the resulting CEL AST into a dialect-agnostic IR condition tree (`internal/filter/parser.go:buildCondition`), and then `Program.Render` walks that IR tree through a `renderer` (`internal/filter/render.go`) that switches on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) to emit dialect-specific SQL fragments with the appropriate placeholder style, JSON operators, and case-folding functions for each backend.
