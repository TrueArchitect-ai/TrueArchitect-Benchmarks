When a memo is deleted through the API, the store layer (`store/memo.go:140-159`) deletes the following records before the memo row itself:

1. **Memo relations** (where the memo is the **source**) — `DeleteMemoRelation` with `MemoID` set to the memo's ID (line 142)
2. **Memo relations** (where the memo is the **target**) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (line 145)
3. **Attachments** — all attachments linked to the memo are listed via `ListAttachments` and then individually deleted via `DeleteAttachment` (lines 149–156)

After these three cleanup steps, the memo row itself is deleted by calling `s.driver.DeleteMemo()` (line 158).
