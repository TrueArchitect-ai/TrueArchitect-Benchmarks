The following database tables are affected when `DeleteMemo` runs:

1. **`memo`** — the memo row itself is deleted (`store/db/sqlite/memo.go:239`, `DELETE FROM memo`)
2. **`memo_relation`** — relations where the memo is either source or target are explicitly deleted in `store/memo.go:142-146` (`DELETE FROM memo_relation`)
3. **`attachment`** — attachments linked to the memo are explicitly deleted in `store/memo.go:149-156` (`DELETE FROM attachment`)
4. **`memo_share`** — cascade-deleted via `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` defined in `store/migration/sqlite/LATEST.sql:109`

Additionally, the service layer at `server/router/api/v1/memo_service.go:567-577` recursively calls `Store.DeleteMemo` for any **comment memos** (related via `MemoRelationComment`), so the same four tables are affected for each comment memo as well.
