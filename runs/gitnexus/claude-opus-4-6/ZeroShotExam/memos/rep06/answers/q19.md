MemoService is served over two protocols:

1. **gRPC-Gateway (REST/HTTP)** — `server/router/api/v1/v1.go` (line 108), where `RegisterMemoServiceHandlerServer` registers MemoService into the gRPC-Gateway mux, which translates RESTful HTTP requests into gRPC calls. The generated gateway code lives in `proto/gen/api/v1/memo_service.pb.gw.go`.

2. **Connect (ConnectRPC)** — `server/router/api/v1/connect_handler.go` (line 40), where `apiv1connect.NewMemoServiceHandler` registers MemoService as a Connect handler via `RegisterConnectHandlers`. The generated Connect service definition lives in `proto/gen/api/v1/apiv1connect/memo_service.connect.go`.

Both registrations happen in `server/router/api/v1/v1.go:RegisterGateway` (lines 108 and 140–141), which wires up the gRPC-Gateway mux and then creates a `ConnectServiceHandler` that delegates to the same underlying `APIV1Service`.
