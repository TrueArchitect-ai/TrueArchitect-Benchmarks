Four memo lifecycle events dispatch webhooks, each with its own dispatch function in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created**: `DispatchMemoCreatedWebhook` (activity type `memos.memo.created`)
- **memo updated**: `DispatchMemoUpdatedWebhook` (activity type `memos.memo.updated`)
- **memo deleted**: `DispatchMemoDeletedWebhook` (activity type `memos.memo.deleted`)
- **memo comment created**: `DispatchMemoCommentCreatedWebhook` (activity type `memos.memo.comment.created`)

The first three converge through the private helper `dispatchMemoRelatedWebhook` (same file, line 48), while `DispatchMemoCommentCreatedWebhook` (line 30) inlines similar logic directly.

All four ultimately converge for delivery at `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto a buffered channel (`asyncPostQueue`). Four goroutines (started in `init()`, line 42) drain that channel and call `webhook.Post` (`internal/webhook/webhook.go:120`) to perform the actual HTTP POST delivery.
