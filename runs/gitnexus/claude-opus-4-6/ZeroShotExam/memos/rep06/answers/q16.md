When a memo is deleted through the API, the store layer (`store/memo.go:140-158`) deletes the following kinds of records before the memo row itself:

- **Memo relations** (where the memo is the **source**) — `DeleteMemoRelation` with `MemoID` set to the memo's ID
- **Memo relations** (where the memo is the **target**) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID
- **Attachments** — all attachments linked to the memo are listed via `ListAttachments` and individually deleted via `DeleteAttachment`
