The compiled React frontend is served via Go's `//go:embed` directive. The Vite build outputs assets into `server/router/frontend/dist/`, and in `server/router/frontend/frontend.go` (line 20–21) those files are embedded into the Go binary with `//go:embed dist/*`. The same file wires Echo's `StaticWithConfig` middleware to serve the embedded filesystem, plus a custom SPA fallback middleware that returns `index.html` for non-API 404s.
