**CEL (Common Expression Language)** engine via `github.com/google/cel-go/cel`, located at `internal/filter/engine.go`.

The `Engine.Compile` method parses the filter string using `cel.Env.Compile()`, converts the resulting AST into a dialect-agnostic IR condition tree (`buildCondition` in `internal/filter/parser.go`), and then `Program.Render` passes that condition tree to a `renderer` (`internal/filter/render.go`) which walks each IR node and emits dialect-specific SQL fragments (switching on `DialectSQLite`, `DialectPostgres`, or `DialectMySQL` for placeholders, JSON operators, case folding, timestamp extraction, etc.).
