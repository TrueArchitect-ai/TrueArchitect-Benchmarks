When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` (line 157) calls **`DispatchMemoCreatedWebhook`** defined in `server/router/api/v1/memo_service_webhooks.go`. This delegates to `dispatchMemoRelatedWebhook`, which retrieves the user's webhooks from the store, builds a payload, and calls `webhook.PostAsync` to enqueue it.

The HTTP delivery is performed by the **`net/http`** standard library package (via a custom `safeClient` in `internal/webhook/webhook.go`).

The signing mechanism is **HMAC-SHA256** following the Standard Webhooks convention: the payload is signed with `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, and the signature is sent as a `webhook-signature: v1,<base64>` header alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:139-149`).
