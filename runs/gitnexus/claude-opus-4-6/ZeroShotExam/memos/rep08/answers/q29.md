**Interceptor path:** `web/src/connect.ts` — defines `authInterceptor` (a ConnectRPC `Interceptor`) that attaches a `Bearer <accessToken>` header to every outgoing request, handles automatic refresh on `Unauthenticated` errors, and retries once.

**Token kinds managed:**
- **Access token** (short-lived JWT, ~15 min) — stored in-memory and in `localStorage` (`memos_access_token`); managed by `web/src/auth-state.ts`.
- **Refresh token** (long-lived JWT, ~30 days) — stored in an HTTP-only cookie (`memos_refresh`), sent automatically via `credentials: "include"` on a dedicated `refreshTransport` (no interceptor, to avoid recursion).
- **Personal Access Token (PAT)** — prefixed `memos_pat_`, validated via SHA-256 hash lookup in the database (programmatic use, not browser-managed).

**Backend validation package:** `server/auth/` — specifically `server/auth/authenticator.go` (`Authenticator` struct with `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, `AuthenticateByPAT` methods). The server-side ConnectRPC interceptor that invokes this authenticator lives at `server/router/api/v1/connect_interceptors.go`.
