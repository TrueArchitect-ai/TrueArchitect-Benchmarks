When a memo is deleted through the API, the store layer (`store/memo.go:140-158`) deletes these records before the memo row itself:

1. **Memo relations** (where the memo is the **source**) — `DeleteMemoRelation` with `MemoID` set to the memo's ID
2. **Memo relations** (where the memo is the **related/target**) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID
3. **Attachments** — all attachments linked to the memo are listed via `ListAttachments` and each is deleted individually via `DeleteAttachment`
