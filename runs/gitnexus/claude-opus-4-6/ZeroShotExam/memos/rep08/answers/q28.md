**Unused scheduling infrastructure:**

The `internal/scheduler/` package (`scheduler.go`, `job.go`, `parser.go`, `middleware.go`) implements a full cron-expression-based job scheduler with middleware support (recovery, logging, timeout). It is **never imported or used** by the server or any production code — grep for `scheduler.` outside `internal/scheduler/` returns zero hits. All actual background scheduling uses ad-hoc `time.NewTicker` loops or `init()`-spawned channel consumers instead.
