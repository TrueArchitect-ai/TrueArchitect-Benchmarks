**CEL (Common Expression Language)** via `github.com/google/cel-go/cel`; the engine lives at `internal/filter/engine.go`.

The `Engine.Compile` method (`internal/filter/engine.go:48`) parses the filter string with `cel.Env.Compile`, converts the resulting AST into a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`, built by `buildCondition` in `internal/filter/parser.go`), and then `Program.Render` (`internal/filter/engine.go:96`) passes that condition tree to a `renderer` (`internal/filter/render.go`) which switches on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) to emit dialect-specific SQL fragments with appropriate placeholders, JSON functions, and operators for each backend.
