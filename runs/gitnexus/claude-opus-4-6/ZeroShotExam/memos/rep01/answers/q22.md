When a memo is created, the handler calls `DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`. This delegates to `dispatchMemoRelatedWebhook` (same file), which retrieves the creator's webhooks and calls `webhook.PostAsync` for each one.

HTTP delivery is performed by Go's standard library `net/http` package (via a custom `safeClient` in `internal/webhook/webhook.go`).

The request-signing mechanism is **HMAC-SHA256** following the Standard Webhooks spec: the payload is signed with `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, and the signature is sent as a `webhook-signature: v1,<base64>` header alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:139-149`).
