**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`; **path:** `internal/filter/engine.go`.

The `Engine.Compile` method parses the filter string with `cel.Env.Compile`, converts the resulting CEL AST into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), and then `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) which switches on `RenderOptions.Dialect` (SQLite, Postgres, MySQL) to emit dialect-specific SQL fragments — placeholder style, JSON operators, case-folding functions, date-part extraction, etc. — per condition node.
