When a memo is created, the `CreateMemo` handler calls `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15`), which delegates to `dispatchMemoRelatedWebhook` (same file, line 48). That method iterates over the user's webhooks and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`) to enqueue each delivery asynchronously. The actual HTTP POST is performed by `webhook.Post` (same file, line 120) using Go's standard `net/http` package (via a custom `safeClient`). Requests are signed with **HMAC-SHA256** following the Standard Webhooks convention: the payload is signed with `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, and the signature is sent as `v1,<base64>` in the `webhook-signature` header (lines 142–149).
