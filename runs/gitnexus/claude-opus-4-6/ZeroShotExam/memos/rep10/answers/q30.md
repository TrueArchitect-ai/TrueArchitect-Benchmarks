Four memo lifecycle events dispatch webhooks:

- **memo created**: `DispatchMemoCreatedWebhook` (event `memos.memo.created`)
- **memo updated**: `DispatchMemoUpdatedWebhook` (event `memos.memo.updated`)
- **memo deleted**: `DispatchMemoDeletedWebhook` (event `memos.memo.deleted`)
- **memo comment created**: `DispatchMemoCommentCreatedWebhook` (event `memos.memo.comment.created`)

All four are defined in `server/router/api/v1/memo_service_webhooks.go`.

The first three delegate to the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), while `DispatchMemoCommentCreatedWebhook` inlines its own loop but uses the same delivery call.

All of them converge on `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues the payload onto a buffered channel (`asyncPostQueue`). Four goroutines (started in `init`, line 42) drain that channel and call `webhook.Post` (`internal/webhook/webhook.go:120`) for the actual HTTP delivery. So the single delivery convergence point is `Post` in `internal/webhook/webhook.go`.
