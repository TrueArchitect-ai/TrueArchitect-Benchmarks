The engine is **CEL (Common Expression Language)** via the `github.com/google/cel-go/cel` library, implemented in `internal/filter/engine.go`. The `Engine.Compile()` method parses the filter string into a CEL AST, then `buildCondition()` (in `internal/filter/parser.go`) converts that AST into a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`); `Program.Render()` then walks that condition tree through a `renderer` (in `internal/filter/render.go`) that emits dialect-specific SQL fragments — branching on `DialectName` (`sqlite`, `mysql`, `postgres` defined in `internal/filter/schema.go`) for placeholders (`?` vs `$N`), column expressions, JSON access, timestamp accessors, and string-length functions.

**Engine + path:** CEL (`cel-go`) in `internal/filter/engine.go`; **mechanism:** CEL parses the filter into an AST, `buildCondition` lowers it to a dialect-neutral condition IR, and `renderer.Render` emits SQL per dialect by switching on `DialectName` for placeholder style, JSON operators, and date-part functions.
