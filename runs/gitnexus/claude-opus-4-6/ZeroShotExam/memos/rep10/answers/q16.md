When a memo is deleted through the API, the store layer (`store/memo.go:140-158`) deletes the following kinds of records before the memo row itself:

1. **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID` matching the memo's ID (line 142)
2. **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID` matching the memo's ID (line 145)
3. **Attachments** — all attachments linked to the memo are listed via `ListAttachments` and each is deleted via `DeleteAttachment` (lines 149–156)
