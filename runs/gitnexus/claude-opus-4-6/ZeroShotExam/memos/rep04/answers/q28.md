**Runners the server actually starts:**

- **S3 presign runner** — 12-hour `time.NewTicker` (plus one synchronous `RunOnce` at startup). Refreshes expiring presigned URLs for S3-stored attachments. Started in `server/server.go:153-171` via `startBackgroundRunners`; runner lives in `server/runner/s3presign/runner.go:26`.
- **Cache cleanup (x3 goroutines)** — 5-minute `time.NewTicker` per cache instance. Evicts expired entries from `instanceSettingCache`, `userCache`, and `userSettingCache`. Each launched by `go c.cleanupLoop()` inside `store/cache/cache.go:83` when the store is created at `store/store.go:51-53`.
- **Async email workers (x2 goroutines)** — channel-driven (buffered channel of 128). Consume from `asyncEmailQueue` and send SMTP mail. Started via `init()` in `internal/email/email.go:16-35`.
- **Async webhook workers (x4 goroutines)** — channel-driven (buffered channel of 128). Consume from `asyncPostQueue` and POST webhook payloads. Started via `init()` in `internal/webhook/webhook.go:42-55`.
