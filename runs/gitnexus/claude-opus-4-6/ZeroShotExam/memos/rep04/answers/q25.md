**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`; **Path:** `internal/filter/engine.go`.

The `Engine.Compile` method parses the filter string using `cel.Env.Compile`, converts the resulting CEL AST into a dialect-agnostic IR condition tree (defined in `internal/filter/ir.go`), then `Program.Render` dispatches each IR node through a `renderer` (`internal/filter/render.go`) that switches on `DialectName` (SQLite, Postgres, MySQL) to emit dialect-specific SQL fragments with proper placeholders, JSON accessors, case-folding, and date-part extraction for each backend.
