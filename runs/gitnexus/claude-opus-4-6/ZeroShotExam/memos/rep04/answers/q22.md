When a memo is created, the handler calls `DispatchMemoCreatedWebhook` in `server/router/api/v1/memo_service_webhooks.go`. This delegates to `dispatchMemoRelatedWebhook`, which looks up the creator's webhooks and calls `webhook.PostAsync` to enqueue each payload for async delivery.

HTTP delivery is performed by Go's standard library `net/http` package (via a custom `safeClient` with SSRF protections) in `internal/webhook/webhook.go`.

The signing mechanism is **HMAC-SHA256** following the **Standard Webhooks** convention: the payload is signed by computing `HMAC-SHA256(msgID + "." + timestamp + "." + body)` using the user's signing secret (which may use the `whsec_<base64>` format). The signature is sent in the `webhook-signature` header as `v1,<base64-signature>`, alongside `webhook-id` and `webhook-timestamp` headers (`internal/webhook/webhook.go:139-149`).
