When a memo is deleted through the API, the store layer (`store/memo.go:140-159`) deletes these records before the memo row itself:

1. **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID` set to the memo's ID (`store/memo.go:142`)
2. **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (`store/memo.go:145`)
3. **Attachments** — lists all attachments linked to the memo via `ListAttachments`, then deletes each one with `DeleteAttachment` (`store/memo.go:149-157`)

In summary: **memo relations** and **attachments** are deleted before the memo row itself.
