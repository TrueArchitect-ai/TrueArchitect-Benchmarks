When a memo is deleted via `Store.DeleteMemo` (`store/memo.go:140–159`), the store layer deletes the following records before the memo row itself:

1. **Memo relations** (where the memo is the source) — `DeleteMemoRelation` with `MemoID` set to the memo's ID (line 142)
2. **Memo relations** (where the memo is the target) — `DeleteMemoRelation` with `RelatedMemoID` set to the memo's ID (line 145)
3. **Attachments** — all attachments linked to the memo are listed and individually deleted via `DeleteAttachment` (lines 149–157)
