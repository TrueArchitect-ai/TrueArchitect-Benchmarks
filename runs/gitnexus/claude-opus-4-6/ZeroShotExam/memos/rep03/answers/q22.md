When a memo is created, `CreateMemo` in `server/router/api/v1/memo_service.go` calls **`DispatchMemoCreatedWebhook`** in `server/router/api/v1/memo_service_webhooks.go`. This delegates to `dispatchMemoRelatedWebhook`, which looks up the creator's webhooks and calls `webhook.PostAsync` to enqueue each payload for async delivery.

The HTTP delivery is performed by the **`net/http`** standard library package (via a custom `safeClient` in `internal/webhook/webhook.go`).

The request-signing mechanism is **HMAC-SHA256** following the Standard Webhooks convention: the payload is signed with `hmac.New(sha256.New, key)` over `msgID + "." + timestamp + "." + body`, and the signature is sent as `v1,<base64>` in the `webhook-signature` header (with companion `webhook-id` and `webhook-timestamp` headers). Secrets use the `whsec_<base64>` format.
