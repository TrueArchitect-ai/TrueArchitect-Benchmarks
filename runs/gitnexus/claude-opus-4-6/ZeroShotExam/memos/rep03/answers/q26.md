The following database tables are affected when `DeleteMemo` runs:

1. **`memo`** — the memo row itself is deleted (`DELETE FROM memo WHERE id = ?` in `store/db/sqlite/memo.go:239`)

3. **`attachment`** — all attachments linked to the memo are individually deleted in `store/memo.go:149-156`, executing `DELETE FROM attachment WHERE id = ?` in `store/db/sqlite/attachment.go:212`
