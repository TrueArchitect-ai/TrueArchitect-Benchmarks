**Engine:** Google CEL (Common Expression Language), via `github.com/google/cel-go/cel`.

**Path:** `internal/filter/engine.go` (the `Engine` type) with schema definitions in `internal/filter/schema.go` and SQL rendering in `internal/filter/render.go`.

**Mechanism:** The `Engine.Compile` method parses the filter string using a `cel.Env` (configured per-schema with typed variables), converts the CEL AST into a dialect-agnostic `Condition` IR tree (`internal/filter/ir.go`), and then `Program.Render` passes that tree to a `renderer` (`internal/filter/render.go`) which walks it and emits dialect-specific SQL fragments (placeholders, JSON operators, date-part functions, etc.) by switching on the `DialectName` — one of `sqlite`, `postgres`, or `mysql` (`internal/filter/schema.go:14-16`).
