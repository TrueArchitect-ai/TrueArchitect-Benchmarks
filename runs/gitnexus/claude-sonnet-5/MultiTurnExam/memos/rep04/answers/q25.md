q25. Engine: CEL (Common Expression Language, via `google/cel-go`), implemented in `internal/filter/` — `engine.go` (`Engine`/`Program`, using `cel.NewEnv`), `parser.go`, `ir.go`, and `render.go`.

Mechanism: the CEL filter string is compiled by `Engine.Compile` into a dialect-agnostic `Condition` intermediate-representation tree (`internal/filter/ir.go`), which a `renderer` (`internal/filter/render.go`) then walks per dialect (`DialectName`: postgres/mysql/sqlite) to emit dialect-specific SQL text plus positional/placeholder args that the store's memo query builder appends to its `WHERE` clause.
