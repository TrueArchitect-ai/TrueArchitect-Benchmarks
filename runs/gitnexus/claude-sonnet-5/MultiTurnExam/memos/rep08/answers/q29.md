**Interceptor:** `web/src/connect.ts` (`authInterceptor`, line 156), which sets `Authorization: Bearer <token>` on outgoing requests and reactively refreshes on `401 Unauthenticated` (`shouldHandleUnauthenticatedRetry`).

**Token kinds it manages:** a short-lived **access token** (JWT, kept in memory via `web/src/auth-state.ts` helpers like `getAccessToken`/`setAccessToken`, sent as a Bearer header) and a long-lived **refresh token** (stored in an httpOnly cookie `memos_refresh`, exchanged via the `refreshAuthClient.refreshToken({})` RPC to mint a new access token, connect.ts:75-82). There's also a **Personal Access Token (PAT)** kind (`memos_pat_` prefix) supported on the backend for non-interactive auth.

**Backend validation package:** `server/auth/` (`server/auth/token.go` for JWT generation/claims — `AccessTokenClaims`, `RefreshTokenClaims`, HS256 signing; `server/auth/authenticator.go` and `server/auth/extract.go`/`server/auth/context.go` for extracting and validating tokens per request).
