q26. When `DeleteMemo` runs, the following tables are affected:

- **`memo_relation`** — deleted explicitly in `Store.DeleteMemo` (`store/memo.go:142,145`) for rows where the memo is either `memo_id` or `related_memo_id`
- **`attachment`** — deleted explicitly in `Store.DeleteMemo` (`store/memo.go:149-157`), each attachment linked via `memo_id` is fetched and deleted individually
- **`memo_share`** — removed via DB-level `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (schema, all three dialects, e.g. `store/migration/postgres/LATEST.sql:108`), not explicit app code
