q25. Engine: **CEL (Common Expression Language)**, via `google/cel-go`, in the custom filter engine at `internal/filter/` (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`). Mechanism: the `ListMemos` filter string is parsed by `cel-go` against the memo schema (`internal/filter/schema.go`), converted into a dialect-agnostic intermediate representation (`internal/filter/parser.go` → `internal/filter/ir.go`), and then `internal/filter/render.go` renders that IR into a dialect-specific SQL fragment + args (handling `?` vs `$n` placeholders, JSON extraction syntax, and boolean/LIKE differences for sqlite/mysql/postgres).
