**Engine:** a custom CEL-like filter engine at `internal/filter/` (`internal/filter/engine.go` — `Engine.Compile`/`CompileToStatement`, `internal/filter/parser.go`, `internal/filter/render.go`).

**Mechanism:** each dialect driver (e.g. `store/db/postgres/memo.go:54-58`, and equivalents in `store/db/sqlite/memo.go` and `store/db/mysql/memo.go`) calls `filter.DefaultEngine()` to get the shared `Engine`, then `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectPostgres/DialectSQLite/DialectMySQL, &where, &args)`, which parses the filter string into an IR/condition tree and renders it into dialect-specific SQL `WHERE` fragments and bound args (dialect differences handled in `internal/filter/render.go`, e.g. `strftime` for SQLite vs. native date functions for Postgres/MySQL).
