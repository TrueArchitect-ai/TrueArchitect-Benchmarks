Based on `APIV1Service.DeleteMemo` (server/router/api/v1/memo_service.go:518-582) and `Store.DeleteMemo` (store/memo.go:140-159), deleting a memo directly/explicitly affects:

- **memo** — the memo row itself, and recursively any comment memos related to it (comments are memo rows too, deleted via the same `store.DeleteMemo` recursion, memo_service.go:567-577)
- **memo_relation** — rows deleted where the memo is either `memo_id` or `related_memo_id`
- **attachment** — attachments linked to the memo are deleted (row + underlying storage file)

Note: `reaction` rows tied to the memo are only *read* (`ListReactions`) to build the webhook payload before deletion — not explicitly deleted in this code path.
