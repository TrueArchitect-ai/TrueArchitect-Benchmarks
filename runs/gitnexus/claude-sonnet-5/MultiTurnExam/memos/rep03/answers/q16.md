Per `store/memo.go:140-158` (`Store.DeleteMemo`), before deleting the memo row itself the store layer explicitly deletes:

1. **memo_relation** records where the memo is the source (`MemoID`)
2. **memo_relation** records where the memo is the target (`RelatedMemoID`)
3. **attachment** records linked to the memo (via `ListAttachments` + `DeleteAttachment` for each)

(Note: `memo_share` rows are removed separately via an `ON DELETE CASCADE` foreign key at the database schema level — `store/migration/postgres/LATEST.sql:108` — rather than by explicit store-layer code.)
