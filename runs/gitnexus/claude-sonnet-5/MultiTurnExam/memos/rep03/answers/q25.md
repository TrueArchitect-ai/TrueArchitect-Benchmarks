q25. Engine: CEL (Common Expression Language, via `google/cel-go`'s AST) at `internal/filter/` (`parser.go` compiles/builds the condition tree, `engine.go`/`schema.go` define the schema, `ir.go` the intermediate representation).

Mechanism: the filter string is parsed into a CEL expression AST which `internal/filter/parser.go` walks into a dialect-agnostic `Condition` IR, and `internal/filter/render.go` then renders that IR into dialect-specific SQL fragments (branching on a `DialectName` of `sqlite`/`postgres`/`mysql` for things like JSON extraction, string length, and timestamp/date-part functions) that get embedded in the `WHERE` clause built by the store's `ListMemos`/`FindMemo` query.
