q25. **Engine:** Google's `cel-go` (CEL — Common Expression Language), wrapped by the project's own filter engine at **`internal/filter/`** (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`)

**Mechanism:** `ListMemos` passes `request.Filter` into a three-phase pipeline — `parser.go` parses the CEL expression with `cel-go` and validates it against the memo schema (`schema.go`), `ir.go` normalizes the AST into a dialect-agnostic intermediate representation, and `render.go` walks that IR to emit dialect-specific SQL fragments + args (via `filter.DefaultEngine().CompileToStatement(...)`, selecting `DialectSqlite`/`DialectMysql`/`DialectPostgres` to handle differences like placeholders (`?` vs `$n`), JSON payload access, and `LIKE`/`JSON_CONTAINS`/`@>` for tag membership).
