q29. **Interceptor:** `web/src/connect.ts` — the `authInterceptor` (lines 156-178), attached to the main Connect transport (line 188)

**Token kinds it manages:**
- **Access token** (short-lived, Bearer JWT — "Access Token V2") — held in memory/state via `web/src/auth-state.ts` (`getAccessToken`/`setAccessToken`), attached as an `Authorization: Bearer <token>` header, proactively refreshed when near expiry and reactively refreshed on a `Code.Unauthenticated` (401) response with one retry
- **Refresh token** — an httpOnly cookie (not touched directly by JS; sent automatically via `credentials: "include"` to the `AuthService.RefreshToken` RPC through a separate un-intercepted `refreshTransport`)

**Backend package that validates them:** `server/auth` — the `Authenticator` type (`server/auth/authenticator.go`), with methods like `AuthenticateByAccessTokenV2`, `AuthenticateByRefreshToken`, and `AuthenticateByPAT`.
