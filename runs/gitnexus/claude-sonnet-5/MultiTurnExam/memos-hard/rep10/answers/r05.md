**Premise correction:** There is no GraphQL API in this codebase. A repo-wide search for "graphql" (case-insensitive, in Go source and for `.graphql`/schema files) returns nothing.

**Actual API surface:** The public API is defined via Protobuf and served as gRPC + gRPC-Gateway (REST/JSON) + Connect. Service definitions live under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, etc., per `proto/buf.yaml`/`buf.gen.yaml`), generated code lands in `proto/gen/` (`proto/gen/api/v1/*.pb.go`, `proto/gen/api/v1/apiv1connect/*.connect.go`), and an OpenAPI/Swagger spec is embedded for the REST surface via `proto/openapi_embed.go`. RPCs are registered and exposed at runtime through `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65+`), which wires up both the gRPC-Gateway HTTP mux and the Connect handlers — no GraphQL schema or resolver layer exists anywhere.
