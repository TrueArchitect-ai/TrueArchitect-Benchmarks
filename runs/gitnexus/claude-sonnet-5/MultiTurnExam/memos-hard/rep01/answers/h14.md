**Computation site** — `memopayload.RebuildMemoPayload` (`server/runner/memopayload/runner.go:74-88`), which calls `markdownService.ExtractAll` (the goldmark-backed implementation at `internal/markdown/markdown.go:356-422`) and assigns the result onto `memo.Payload.Tags`/`Property`.

**Triggers** — recomputed whenever a memo's `content` is set or changed:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`
- `UpdateMemo`, specifically when the `content` field is present in the update mask — `server/router/api/v1/memo_service.go:447`

(There's also a standalone `memopayload.Runner.RunOnce` batch-rebuild path at `server/runner/memopayload/runner.go:27-72`, but per earlier analysis it's never constructed/invoked in production — only the two call sites above run in practice.)

**Extracted properties** (`ExtractedData` / `storepb.MemoPayload`):
- `Tags` — `#tag` occurrences parsed from the markdown AST (excluding tags inside links/images)
- `Mentions` — `@mention` occurrences (extracted but not persisted onto `MemoPayload`, which has no mentions field)
- `Property.Title` — text of the leading H1 heading, if the document's first block is one
- `Property.HasLink` — whether the content contains a link
- `Property.HasCode` — whether it contains a code block/span
- `Property.HasTaskList` — whether it contains a task checkbox
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked
