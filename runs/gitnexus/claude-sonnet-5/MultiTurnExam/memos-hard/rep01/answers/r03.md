**Premise correction** — there is no nightly database-cleanup job scheduled anywhere in this codebase. There *is* an `internal/scheduler` package (a cron-expression scheduler: `internal/scheduler/scheduler.go`, `job.go`, `parser.go`) with its own tests and doc comment, but it is never imported or wired up by any other package — a repo-wide search for `internal/scheduler` outside that directory itself returns nothing. It's unused/unconnected library code, not an active job runner.

The only actual scheduled background work in the server is the two runners under `server/runner/`:
- `s3presign.Runner` — runs once at startup, then every 12 hours (not nightly, no fixed time-of-day) — `server/runner/s3presign/runner.go:27-41`, wired at `server/server.go:162-171`.
- `memopayload.Runner` — has a `RunOnce`/batch-rebuild method but, as established earlier, is never constructed or invoked anywhere in production.

Neither performs "database cleanup," and neither runs on a fixed nightly clock time.
