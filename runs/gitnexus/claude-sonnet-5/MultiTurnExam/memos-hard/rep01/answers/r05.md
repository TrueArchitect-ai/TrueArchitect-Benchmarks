**Premise correction** — this repo has no GraphQL schema; there's no GraphQL dependency anywhere in the Go source or `go.mod`, and no `.graphql`/schema files exist.

**Actual API surface** — the public API is defined as **Protocol Buffers**, under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, `shortcut_service.proto`, plus shared types in `common.proto`), with persisted-entity payloads in `proto/store/*.proto`. These compile to generated gRPC service code in `proto/gen/api/v1/` (server/client stubs, gRPC-Gateway REST mux, and Connect handlers under `proto/gen/api/v1/apiv1connect/`), which is what's actually served — gRPC, a gRPC-Gateway JSON/REST bridge, and Connect — not GraphQL.
