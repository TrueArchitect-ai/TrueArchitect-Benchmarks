**Delivery function:** `Post` in `internal/webhook/webhook.go:120-180` (invoked synchronously, or asynchronously via `PostAsync`/`asyncPostQueue` at `internal/webhook/webhook.go:184-196`) — it marshals the payload, builds the HTTP request, and sends it via the package's shared `safeClient`.

**Protection mechanism:** SSRF protection is enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59-77`), which is wired in as the `http.Transport.DialContext` of `safeClient` (`internal/webhook/webhook.go:32-37`). It resolves the target hostname and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, ranges defined in `reservedCIDRs` at `internal/webhook/validate.go:14-23`) — this protects the actual outbound connection (defeating DNS-rebinding, since it checks the IP actually dialed, not just the pre-resolved hostname). There's also an upfront `ValidateURL` check (`internal/webhook/validate.go:62-83`) used at webhook-registration time, but the dial-time guard in `safeDialContext` is what actually protects the delivery call itself.
