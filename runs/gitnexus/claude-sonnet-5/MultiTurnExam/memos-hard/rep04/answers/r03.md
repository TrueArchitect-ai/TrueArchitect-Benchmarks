**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this codebase. The only cron-style scheduling primitive in the repo, `internal/scheduler`, is never imported by any production code — the only files referencing it are its own package tests (`internal/scheduler/integration_test.go`, `internal/scheduler/example_test.go`). The one recurring background job that does run in production is the S3-presign refresher (`server/runner/s3presign/runner.go`, ticking every 12 hours per the earlier h01 answer), which re-signs attachment URLs, not a database-cleanup task.
