**Premise correction:** There is no GraphQL schema in this codebase — no `.graphql`/`.gql` files and no GraphQL library dependency exist anywhere in the repo.

**Actual API surface:** The public API is defined via **Protocol Buffers**, as gRPC services exposed over Connect/gRPC-Gateway. Service definitions live in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), and generated Go bindings are in `proto/gen/api/v1/`. These are served/wired up via `RegisterGateway` in `server/router/api/v1/v1.go:65` (gRPC-Gateway + Connect handlers), giving both native gRPC/Connect access and a JSON/REST-style HTTP surface — not GraphQL.
