**Abstraction package:** `internal/idp` (`internal/idp/idp.go`) — defines the provider-agnostic `IdentityProviderUserInfo` type used as the common return shape for identity providers.

**Implementation package:** `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — the concrete OAuth2 protocol implementation, providing `IdentityProvider` with `NewIdentityProvider`, `ExchangeToken`, and `UserInfo`, which fulfills the `idp` abstraction (currently the only concrete protocol implementation shipped).
