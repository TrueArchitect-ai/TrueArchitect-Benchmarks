**Premise correction:** There's no GraphQL in this codebase — no `.graphql` schema files and no `graphql` reference anywhere in the Go or TypeScript source.

**Actual API surface:** The public API is defined via Protocol Buffers and served as gRPC + gRPC-Gateway (REST/JSON) + Connect. Service/message definitions live under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, etc.), generated Go code lands in `proto/gen/api/v1/`, and generated TS/web client types in `web/src/types/proto/api/v1/`. Handlers register these services via `RegisterGateway` in `server/router/api/v1/v1.go`, wiring both the gRPC-Gateway and Connect interceptor paths (as seen in `v1.go:62` onward from the earlier read).
