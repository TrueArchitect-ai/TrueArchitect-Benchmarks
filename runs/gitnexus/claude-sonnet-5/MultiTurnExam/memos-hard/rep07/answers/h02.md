**Delivery function:** `Post` in `internal/webhook/webhook.go:129` (invoked via the async worker pool `PostAsync`/`asyncPostQueue`, `internal/webhook/webhook.go:105-183` and `:186-198`) — it builds the HTTP POST request and sends it via `safeClient.Do(req)`.

**Protection mechanism:** `safeDialContext` in `internal/webhook/webhook.go:58-75`, set as the `DialContext` on the shared `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:29-35`). At actual dial time it re-resolves the hostname and rejects any resolved IP falling within a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44-54`, checked against `reservedCIDRs`/`reservedNetworks` covering loopback, RFC-1918, and link-local/cloud-IMDS ranges, `internal/webhook/validate.go:12-38`). This dial-time check (rather than a one-time URL check) is what defeats DNS-rebinding SSRF. A separate `ValidateURL` in `internal/webhook/validate.go:60-81` performs the same reserved-IP check earlier, at webhook-URL configuration time.
