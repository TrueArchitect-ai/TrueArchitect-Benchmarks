**Premise correction:** There is no nightly database-cleanup job scheduled anywhere in this codebase. A `internal/scheduler` package does exist (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, `middleware.go` — a generic cron-style job scheduler), but it is never imported or wired up by any production code — the only files that reference `internal/scheduler` are its own tests, `internal/scheduler/integration_test.go` and `internal/scheduler/example_test.go`. Neither `server/` nor `cmd/` construct or register any job with it.

The only actual scheduled background work in the server is the two runners under `server/runner/` wired in `server.go` (`s3presign`, refreshing S3 presigned URLs every 12 hours) — neither of which is a database-cleanup job, and neither uses the `internal/scheduler` package (they use plain `time.Ticker` loops). There is no "database cleanup" job of any kind, nightly or otherwise, in the repository.
