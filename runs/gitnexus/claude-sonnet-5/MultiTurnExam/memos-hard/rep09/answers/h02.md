**Delivery function** — `Post` (with async wrapper `PostAsync`, which enqueues onto `asyncPostQueue` and is drained by worker goroutines that call `Post`) in `internal/webhook/webhook.go:120` (async entry at `internal/webhook/webhook.go:184`). It builds and signs the HTTP request and sends it via the package's `safeClient` (`internal/webhook/webhook.go:32`).

**Protection mechanism** — SSRF protection is enforced at dial time by `safeDialContext` (`internal/webhook/webhook.go:59`), which is installed as `safeClient`'s `Transport.DialContext`. It resolves the target host and rejects any resolved IP that `isReservedIP` (`internal/webhook/validate.go:44`) flags as loopback/RFC-1918/link-local/IMDS/IPv6-equivalent (`reservedCIDRs`, `internal/webhook/validate.go:14`) — this dial-time check also defeats DNS-rebinding, since re-resolution happens at connection time rather than trusting an earlier check. There's also an upfront `ValidateURL` check (`internal/webhook/validate.go:62`) used when webhook URLs are created/updated, doing the same reserved-IP resolution check before the URL is even saved. Both are bypassable per-deployment via `AllowPrivateIPs` (`internal/webhook/validate.go:41`).
