**Premise correction** — There is no GraphQL schema in this codebase. A repo-wide search for `graphql` (any case) across Go and web source returns zero results.

**Actual API surface** — The public API is defined via **Protocol Buffers / gRPC**, in `.proto` files under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, etc.), which are compiled into generated Go code under `proto/gen/api/v1/`. Each service ships three flavors of generated bindings:
- `*_grpc.pb.go` — native gRPC server/client stubs
- `*.pb.gw.go` — a grpc-gateway REST/JSON transcoding layer
- `apiv1connect/*.connect.go` — Connect-protocol handlers (used for the browser-facing HTTP API)

The concrete request handlers live in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`), implementing the generated service interfaces — this is the actual "public API" surface, not GraphQL.
