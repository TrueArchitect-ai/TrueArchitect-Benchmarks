**Extracted properties** — a single goldmark AST walk (`ExtractAll`, `internal/markdown/markdown.go:356`) extracts:
- `Tags` — all `#tag` occurrences in the content (deduplicated, case-preserved)
- `Property.Title` — text of a leading H1 heading, if the first block is one
- `Property.HasLink` — whether the content contains a link
- `Property.HasCode` — whether it contains a code block/span
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — whether it contains task-list checkboxes, and whether any are unchecked

(Mentions are also extracted by the same pass but stored separately, not into `memo.Payload`.)
