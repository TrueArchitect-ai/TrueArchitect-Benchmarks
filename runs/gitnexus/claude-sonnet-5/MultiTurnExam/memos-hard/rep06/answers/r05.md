**Premise correction** — There is no GraphQL schema anywhere in this repo. A search for `graphql` across all Go files, `go.mod`, and for `.graphql`/`.gql` schema files returns nothing — no GraphQL dependency, server, or schema exists.

**Actual API surface** — The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), with internal persistence types in `proto/store/*.proto`. These are compiled to Go (`proto/gen/api/v1/...`) and served as gRPC plus a Connect/gRPC-Gateway REST-JSON bridge — registered via `RegisterGateway` in `server/router/api/v1/v1.go:65` and wired into the server in `server/server.go`.
