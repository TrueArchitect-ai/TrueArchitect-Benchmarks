**Computation site** — `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`, which calls `markdownService.ExtractAll(memo.Content)` (implemented in `internal/markdown/markdown.go:356-422`) and writes the result onto `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers** — recomputed whenever memo content is (re)written:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, called before the memo is persisted.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, called only when the update mask includes the `content` path (line 436).
- (There's also an unused batch `memopayload.Runner.RunOnce` that would rebuild payloads for *all* memos, but per earlier analysis it has no caller and doesn't run in production.)

**Extracted properties** (from `Service.ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — all `#tag` occurrences in the content (deduplicated, case-preserved).
- `Property.Title` — text of a leading H1 heading, if the first block is one.
- `Property.HasLink` — whether the content contains a markdown link.
- `Property.HasCode` — whether it contains a code block/span.
- `Property.HasTaskList` — whether it contains a task checkbox.
- `Property.HasIncompleteTasks` — whether any task checkbox is unchecked.
- (Mentions are also extracted into `ExtractedData.Mentions` by the same pass, though `RebuildMemoPayload` only persists `Tags`/`Property` onto the memo payload.)
