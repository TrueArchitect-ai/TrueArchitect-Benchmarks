**Delivery function** — `Post` in `internal/webhook/webhook.go:120-180` (invoked directly, or asynchronously via `PostAsync`/`asyncPostQueue`, `internal/webhook/webhook.go:184-196` and `39-55`). It builds the HTTP request and sends it through the package-level `safeClient` (`internal/webhook/webhook.go:32-37`).

**Protection mechanism** — SSRF protection is enforced at dial time by `safeDialContext` in `internal/webhook/webhook.go:59-77`, which is installed as the `http.Transport.DialContext` for `safeClient`. It resolves the target host and rejects any resolved IP that is "reserved" per `isReservedIP` in `internal/webhook/validate.go:44-54` (checked against `reservedCIDRs`/`reservedNetworks`, `internal/webhook/validate.go:14-36`, covering loopback, RFC-1918 private ranges, link-local/cloud IMDS, and IPv6 equivalents). This dial-time check guards against DNS-rebinding, and is complemented by an upfront `ValidateURL` check (`internal/webhook/validate.go:62-83`) run when a webhook URL is registered. Both can be disabled per-deployment via `AllowPrivateIPs` (`internal/webhook/validate.go:41`).
