**Premise correction:** there's no GraphQL schema in this codebase — a search for `graphql`/`.graphql` files across the repo (Go source, `go.mod`) returns nothing.

**Actual API surface:** the public API is defined via Protobuf, under `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`). These are compiled (via `buf`, configured in `proto/buf.gen.yaml`/`proto/buf.yaml`) into generated Go code under `proto/gen/api/v1`, which is served three ways:
- gRPC (Connect-RPC) handlers, registered from `server/router/api/v1/*.go` (e.g. `NewAPIV1Service` in `server/router/api/v1/v1.go`).
- A gRPC-Gateway REST/JSON translation layer (`proto/gen/api/v1/*.pb.gw.go`), wired up via `RegisterGateway` (`server/router/api/v1/v1.go:65`).
- An OpenAPI spec generated to `proto/gen/openapi.yaml` and embedded via `proto/openapi_embed.go` for API documentation/tooling.
