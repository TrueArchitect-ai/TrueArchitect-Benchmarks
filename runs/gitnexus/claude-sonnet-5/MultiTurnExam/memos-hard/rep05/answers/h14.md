**Computation site:** `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll(memo.Content)` (the `markdown.Service` implementation, `internal/markdown/markdown.go:356-422`) and assigns the results onto `memo.Payload.Tags` / `memo.Payload.Property`.

**Triggers (recomputation call sites):**
- `APIV1Service.CreateMemo` — `server/router/api/v1/memo_service.go:108`, called unconditionally on every new memo (after `memopayload.RebuildMemoPayload(ctx, create, s.MarkdownService)`).
- `APIV1Service.UpdateMemo` — `server/router/api/v1/memo_service.go:447`, called only when the update mask includes the `content` field (`path == "content"`, `memo_service.go:436-449`).
- `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27-73`, a batch job that walks all memos and recomputes/persists payload for each; per h08, this runner is not wired into production server startup (no `NewRunner` call site outside its own package), so it exists as an available maintenance path rather than an active trigger.

**Extracted properties** (via `Service.ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — all `#tag` occurrences found in the content (deduplicated, case-preserved), stored as `Payload.Tags`.
- `Property` (`storepb.MemoPayload_Property`), stored as `Payload.Property`:
  - `Title` — text of a leading H1 heading, if the first block is one.
  - `HasLink` — whether the content contains a markdown link.
  - `HasCode` — whether it contains a code block/span.
  - `HasTaskList` — whether it contains a task checkbox.
  - `HasIncompleteTasks` — whether any task checkbox is unchecked.

(`ExtractAll` also computes `Mentions`, but `RebuildMemoPayload` doesn't persist that field to `Payload` — mentions are extracted separately elsewhere, e.g. `memo_mention_helpers.go`, for notification dispatch.)
