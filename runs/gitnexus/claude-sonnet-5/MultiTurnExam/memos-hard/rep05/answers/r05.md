**Premise correction:** There is no GraphQL schema anywhere in this repository — a search for `graphql` and `.graphql`/`.gql` files turns up nothing. This project doesn't expose a GraphQL API.

**Actual API surface:** The public API is defined via **Protocol Buffers / gRPC** (with a REST/JSON gateway and Connect protocol support). Service definitions live under `proto/` (e.g. `proto/api/v1/*.proto` sources, generated into `proto/gen/api/v1/*.pb.go`, `*_grpc.pb.go`, and `proto/gen/api/v1/apiv1connect/*.connect.go`), covering services like `MemoService`, `UserService`, `AuthService`, `IdentityProviderService`, etc. These are wired up as gRPC handlers plus a grpc-gateway REST mux in `server/router/api/v1/v1.go` and `server/server.go`, giving clients gRPC, Connect, and RESTful JSON access to the same schema — not GraphQL.
