**Component:** `s3presign.Runner` (`server/runner/s3presign/runner.go`) — a background job that re-presigns S3-stored attachment URLs. It lists all attachments with `StorageType == S3`, and for any whose `LastPresignedTime` is more than 4 days old (URLs expire after 5 days), it generates a fresh presigned GET URL via `s3Client.PresignGetObject` and updates the attachment's `Reference`/`Payload` in the store (`server/runner/s3presign/runner.go:47-131`).

**Schedule:** Runs once immediately on startup, then on a `time.Ticker` every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-40`); each run refreshes URLs nearing their 5-day expiry.

**Wiring into startup:** `server/server.go:161-171`, inside `startBackgroundRunners`. It constructs the runner (`s3presign.NewRunner(s.Store)` at line 162), calls `RunOnce(ctx)` immediately (line 163), then launches `s3presignRunner.Run(s3Context)` in a goroutine (line 169) using a cancellable child context so it can be shut down independently during server teardown.
