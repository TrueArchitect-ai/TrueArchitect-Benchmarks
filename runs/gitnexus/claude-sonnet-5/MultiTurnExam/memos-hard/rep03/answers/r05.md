**Premise correction:** There is no GraphQL API in this codebase — a search for "graphql" across all Go/TS/TSX sources and `go.mod`/`package.json` returns nothing.

**Actual API surface:** The public API is defined as Protocol Buffers service definitions (gRPC) under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`. These are compiled into generated Go bindings under `proto/gen/api/v1/` (including grpc-gateway REST transcoding, `*_grpc.pb.go`/`*.pb.gw.go`, and Connect handlers in `proto/gen/api/v1/apiv1connect/`). The concrete RPC handlers implementing these services live in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`), registered via `APIV1Service` (`server/router/api/v1/v1.go`) and served over gRPC, gRPC-Gateway (HTTP/JSON), and Connect protocols — not GraphQL.
