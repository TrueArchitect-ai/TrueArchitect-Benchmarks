**Computation site:** `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`. It calls `markdownService.ExtractAll([]byte(memo.Content))` (the `Service.ExtractAll` implementation in `internal/markdown/markdown.go:356`, a single goldmark AST walk) and writes the result into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (recomputation call sites):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` — runs unconditionally on every new memo.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447` — runs only when the update mask includes the `content` path (i.e., the memo's text actually changed).

(Note: `memopayload.Runner.RunOnce`, a batch job that would recompute payloads for all memos, exists in the same package but — per earlier analysis — is never constructed/invoked from production code, so it is not an active trigger.)

**Extracted properties** (via `ExtractedData` / `MemoPayload_Property`, computed in a single AST walk in `internal/markdown/markdown.go:ExtractAll`):
- `Tags` — all `#tag` occurrences (excluding those inside links/images)
- `Property.Title` — text of a leading H1 heading, if the document starts with one
- `Property.HasLink` — whether any link node is present
- `Property.HasCode` — whether any code block/fenced code block/code span is present
- `Property.HasTaskList` — whether any task checkbox is present
- `Property.HasIncompleteTasks` — whether any unchecked task checkbox is present
- (Mentions are also extracted into `ExtractedData.Mentions`, though this field isn't part of `MemoPayload_Property`.)
