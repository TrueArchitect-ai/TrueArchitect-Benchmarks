**Delivery function:** `Post` — `internal/webhook/webhook.go:120` (the actual HTTP dispatch via `safeClient.Do(req)`), fed by `PostAsync` — `internal/webhook/webhook.go:184` (bounded async queue, 4 worker goroutines started in `init()` at `internal/webhook/webhook.go:42`).

**Protection mechanism:** SSRF/private-IP guard enforced at dial time by `safeDialContext` — `internal/webhook/webhook.go:59` (installed as the `http.Transport.DialContext` on the shared `safeClient`, `internal/webhook/webhook.go:32-37`), which resolves the target host and rejects any resolved IP matching `isReservedIP` — `internal/webhook/validate.go:44` (checks against `reservedCIDRs`/`reservedNetworks` covering loopback, RFC-1918 private ranges, and link-local/cloud-IMDS addresses, `internal/webhook/validate.go:14-23`). This also defeats DNS-rebinding since the check runs against the actual dial-time resolution rather than a URL parsed earlier. A second-layer check, `ValidateURL` — `internal/webhook/validate.go:62`, performs the same reserved-IP validation at webhook-creation time (e.g. in `server/router/api/v1/user_service_webhooks.go`) before a webhook URL is even persisted. Both checks can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments targeting local-network services.
