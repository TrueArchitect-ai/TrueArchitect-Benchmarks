**Protection mechanism** — the outbound `http.Client` (`safeClient`, `internal/webhook/webhook.go:32`) uses a custom `Transport.DialContext` set to `safeDialContext` (`internal/webhook/webhook.go:59-77`), which resolves the target host and rejects any resolved IP that falls in a reserved/private range via `isReservedIP` — `internal/webhook/validate.go:44-54` (reserved CIDRs, including loopback, RFC-1918, and the cloud metadata link-local range, defined at `internal/webhook/validate.go:14-23`). This dial-time check blocks SSRF and defeats DNS-rebinding, and is complemented by `ValidateURL` (`internal/webhook/validate.go:62-83`), which performs the same reserved-IP check up front when a webhook URL is created/updated. Protection can be disabled per-deployment via `AllowPrivateIPs` (`internal/webhook/validate.go:41`).
