**Premise correction**: There is no GraphQL API in this codebase — no `.graphql`/`.gql` schema files, no GraphQL library dependency, and zero mentions of "graphql" anywhere in the Go source or `go.mod`.

**Actual API surface**: The public API is defined via **Protobuf/gRPC**, in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`). These are compiled to generated Go code under `proto/gen/api/v1/`, and exposed over the wire two ways:
- native gRPC / Connect-RPC (handlers implemented in `server/router/api/v1/*.go`, e.g. `APIV1Service`)
- a REST/JSON facade via grpc-gateway (`proto/gen/api/v1/*.pb.gw.go`), registered in `server/server.go`

So "the schema for the public API" in this project is the `.proto` files under `proto/api/v1/`, not GraphQL SDL.
