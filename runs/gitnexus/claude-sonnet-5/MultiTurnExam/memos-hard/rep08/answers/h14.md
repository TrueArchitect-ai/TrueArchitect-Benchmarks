**Extracted properties** (via `ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — all `#tag` occurrences (deduplicated, case-preserved)
- `Mentions` — all `@mention` occurrences (lowercased, deduplicated) — used elsewhere for notifications but not persisted onto `Payload` by `RebuildMemoPayload` itself (only `Tags`/`Property` are copied — see `server/runner/memopayload/runner.go:85-86`)
- `Property.Title` — text of a leading H1 heading, if the first block is one
- `Property.HasLink` — whether the content contains a markdown link
- `Property.HasCode` — whether it contains a code block/span
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — presence of task-list checkboxes and any unchecked ones
