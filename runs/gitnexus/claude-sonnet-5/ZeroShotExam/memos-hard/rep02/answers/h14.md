**Computation site:** `internal/markdown/markdown.go:356` (`Service.ExtractAll`) does a single goldmark AST walk over `memo.Content` and returns `ExtractedData{Tags, Mentions, Property}`. This is invoked from `server/runner/memopayload/runner.go:74` (`RebuildMemoPayload`), which writes `data.Tags`/`data.Property` onto `memo.Payload.Tags` / `memo.Payload.Property` (runner.go:85-86). Separately, list/preview snippets are computed on-demand (not persisted) by `Service.GenerateSnippet` (`internal/markdown/markdown.go:264`), invoked via `getMemoContentSnippet` in `server/router/api/v1/memo_service_converter.go:76,225,248` when building `Memo`/`MemoRelation` API responses.

**Triggers (recomputation):**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, runs `RebuildMemoPayload` before persisting the new memo.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only when `"content"` is in `request.UpdateMask.Paths` (checked at line 434-437); rebuilt payload is written via `store.UpdateMemo`.
- Batch backfill — `Runner.RunOnce` (`server/runner/memopayload/runner.go:26-71`) pages through all memos and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each. Note: unlike other runners (e.g. `s3presign`, wired in `server/server.go`), this runner isn't referenced/scheduled anywhere else in the codebase — it exists as a standalone/manual backfill path, not an automatic trigger.
- Snippet regeneration for previews happens on every read (list/get response conversion), not stored — so it's always fresh, computed straight from `memo.Content` on each request.

**Extracted properties:**
- `Tags []string` — `#tag` nodes from the AST.
- `Property.Title` — text of a leading H1 heading (if the doc's first block child is `Heading{Level:1}`).
- `Property.HasLink` — presence of any `KindLink` node.
- `Property.HasCode` — presence of code block/fenced block/code span nodes.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — from `TaskCheckBox` nodes (incomplete = any unchecked box).
- `Mentions []string` — `@username` nodes, lowercased (extracted by `ExtractAll` but currently not persisted onto `memo.Payload` in `RebuildMemoPayload`).
- `Snippet` (string, not stored) — plain-text summary/excerpt generated on demand from content for list/preview responses.
