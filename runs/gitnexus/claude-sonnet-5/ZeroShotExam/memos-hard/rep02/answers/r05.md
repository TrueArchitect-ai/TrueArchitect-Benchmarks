**Premise correction:** There is no GraphQL schema in this codebase — memos doesn't expose a GraphQL API at all, so no such file exists to point to (verified via repo-wide search for `.graphql`/`.gql` files and "graphql" string matches, both empty).

**Actual API surface:** The public API is defined with Protocol Buffers under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto`), with internal storage messages in `proto/store/*.proto`. These `.proto` definitions are compiled to gRPC services and exposed over REST via a gRPC-gateway, not GraphQL.
