**Premise correction:** There is no GraphQL schema in this repository. This project (indexed by GitNexus as "memos") does not use GraphQL at all — a repo-wide search for `graphql`/`apollo` returns zero hits.

**Actual API surface:** The public API is defined via Protocol Buffers and exposed as gRPC + REST (through grpc-gateway), plus a separate MCP tool surface:

- **Proto service definitions** (source of truth for the API contract): `proto/api/v1/*.proto`, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`, with shared types in `proto/api/v1/common.proto`.
- **Generated code**: `proto/gen/api/v1/` (Go stubs for gRPC/gateway).
- **Generated OpenAPI spec** (REST surface derived from the same proto definitions via grpc-gateway/buf): `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- **HTTP router wiring**: `server/router/api/v1/`.
- **MCP tool surface** (separate from the REST/gRPC API): `server/router/mcp/` (`catalog.go`, `service.go`, `adapter.go`, `openapi.go`), documented in `server/router/mcp/README.md`.

So if the intent was "where do I look to see/modify the public API contract," the answer is the `.proto` files under `proto/api/v1/`, not any GraphQL schema.
