**Component**: `s3presign.Runner` (`server/runner/s3presign/runner.go`) — a background job that re-presigns S3 object URLs for attachments stored externally, refreshing `LastPresignedTime`/`Reference` before the presigned URL expires.

**Schedule**: Runs once immediately on startup, then on a `time.NewTicker(runnerInterval)` loop where `runnerInterval = 12 hours` (`server/runner/s3presign/runner.go:27`). Each run skips any attachment whose presigned URL was refreshed within the last 4 days, since presigned URLs are issued with a 5-day expiration (`server/runner/s3presign/runner.go:85-91`).

**Wiring into server startup**: `server/server.go:153-174` (`Server.startBackgroundRunners`), which constructs the runner (`s3presign.NewRunner(s.Store)` at line 162), does an initial synchronous `RunOnce` (line 163), then launches `s3presignRunner.Run(s3Context)` in a goroutine (line 169). `startBackgroundRunners` itself is invoked from `Server.Start`/startup at `server/server.go:129`.
