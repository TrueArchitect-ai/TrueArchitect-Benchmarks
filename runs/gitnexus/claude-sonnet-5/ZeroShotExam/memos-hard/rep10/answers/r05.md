**Premise correction:** There is no GraphQL schema in this repository — memos does not expose a GraphQL API. A search for `.graphql` files and `graphql` references across the codebase turns up nothing.

**Actual API surface:** The public API is defined via **Protocol Buffers** under `proto/api/v1/` (e.g. `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, plus shared types in `proto/api/v1/common.proto`), with internal storage messages in `proto/store/`. These `.proto` files define gRPC services that are also exposed as REST/JSON via grpc-gateway annotations, and generated code is consumed by both the Go backend (`server/`) and the web frontend (`web/`).
