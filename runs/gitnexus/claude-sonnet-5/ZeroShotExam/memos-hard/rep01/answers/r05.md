**Premise correction:** There is no GraphQL schema in this repository — GitNexus's own index (`gitnexus://repo/memos/context`) records zero GraphQL processes, and a repo-wide search for `graphql` (across `.go`, `.ts`, `.proto`, `.json`) returns no hits.

**Actual API surface:** memos exposes its public API as **gRPC services defined via Protocol Buffers**, generated with the standard gRPC + `google.api.http` annotations (grpc-gateway/Connect-style REST transcoding) rather than GraphQL:

- Service definitions live under `proto/api/v1/*.proto`, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/ai_service.proto`, and shared types in `proto/api/v1/common.proto`.
- Each `rpc` method carries a `google.api.http` option mapping it to a REST path, e.g. in `proto/api/v1/memo_service.proto:29-31`:
  ```
  rpc ListMemos(ListMemosRequest) returns (ListMemosResponse) {
    option (google.api.http) = {get: "/api/v1/memos"};
  ```
- Persistence-layer message types (separate from the public API) live in `proto/store/*.proto` (e.g. `memo.proto`, `attachment.proto`, `inbox.proto`).

So "the GraphQL schema" doesn't exist to point to — the equivalent artifact (the public API's interface contract) is the set of `.proto` files under `proto/api/v1/`.
