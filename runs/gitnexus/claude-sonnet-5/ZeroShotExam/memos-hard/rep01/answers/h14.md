h14.
computation site: `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74`, which calls `markdownService.ExtractAll()` (implemented in `internal/markdown/markdown.go:356`, a single Goldmark AST walk) and stores the result into `memo.Payload.Tags` / `memo.Payload.Property` (a `storepb.MemoPayload`).

triggers: (1) `CreateMemo` in `server/router/api/v1/memo_service.go:108` — on every new memo creation; (2) `UpdateMemo` in `server/router/api/v1/memo_service.go:447` — only when the update mask includes the `content` path (i.e., content was actually edited); (3) the periodic `memopayload.Runner.RunOnce()` (`server/runner/memopayload/runner.go:27`) which batch-rebuilds the payload for *all* memos (used for backfills/migrations, e.g. after markdown-parsing logic changes).

extracted properties: from a single AST walk over the memo's markdown content — `Tags` (dedup, case-preserving list of `#tag` nodes) and a `Property` struct containing `Title` (text of a leading H1 heading, if the first block is one), `HasLink` (any `KindLink` node), `HasCode` (any code block/fenced code block/code span), `HasTaskList` (presence of a task checkbox), and `HasIncompleteTasks` (an unchecked task checkbox). (Mentions are also extracted by the same `ExtractAll` call but are used for mention/notification handling in `memo_mention_helpers.go`, not stored as part of the memo payload.)
