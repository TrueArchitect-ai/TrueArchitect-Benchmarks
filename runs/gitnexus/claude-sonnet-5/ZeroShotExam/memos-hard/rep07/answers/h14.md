**Extracted properties** (defined in `proto/store/memo.proto`, `MemoPayload.Property`, populated by `ExtractAll`):
- `Tags []string` — `#tag` nodes (dedup, skips tags nested in links/images)
- `Property.Title` — text of the first block if it's an H1 heading
- `Property.HasLink` — set when a markdown link node is present
- `Property.HasCode` — set when a code block/fenced code block/code span is present
- `Property.HasTaskList` — set when a GFM task checkbox is present
- `Property.HasIncompleteTasks` — set when a task checkbox exists with `IsChecked == false`

`MemoPayload.Location` is explicitly user-set, not derived, and is preserved/excluded during rebuild.
