**Premise correction:** there is no GraphQL schema in this codebase — memos doesn't expose a GraphQL API. A repo-wide search turns up zero `.graphql`/`.gql` files and no GraphQL library usage.

**Actual API surface:** the public API is defined via **Protocol Buffers** and exposed as gRPC + a REST/JSON gateway (grpc-gateway) plus an MCP tool layer:

- Proto definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `common.proto`), with shared storage types in `proto/store/*.proto`.
- Generated Go bindings live in `proto/gen/api/v1` and `proto/gen/store`.
- A generated **OpenAPI** description (derived from the proto, not GraphQL) is at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- The HTTP-facing router code lives under `server/router/api/v1`.
- There's also an MCP (Model Context Protocol) tool surface with its own JSON-schema definitions in `server/router/mcp/openapi.go` and `server/router/mcp/catalog.go` — but this is MCP tool schema, not GraphQL either.

If you're looking for something GraphQL specifically, it doesn't exist here — the closest analog (typed API schema + generated docs) is the `.proto` files plus the generated `openapi.yaml`.
