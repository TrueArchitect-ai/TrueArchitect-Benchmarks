Ranking based on the `store.*` persistent entity structs defined in the data-access layer (`store/*.go`, e.g. `store/user.go`, `store/memo.go`) and counting distinct non-test packages outside `store/` (excluding the `store/db/{mysql,postgres,sqlite}` driver implementations, which are part of the same data layer) that reference each type:

1st: **User** (`store.User`, defined in `store/user.go`) — referenced from ~5 packages: `server/router/api/v1`, `server/auth`, `server/notification`, `server/router/fileserver`, `server/router/rss`

2nd: **Memo** (`store.Memo`, defined in `store/memo.go`) — referenced from ~4 packages: `server/router/api/v1`, `server/router/rss`, `server/notification`, `server/runner/memopayload`

Other entities trail well behind (e.g. `Attachment` ~3, `Inbox`/`MemoShare` ~2, `Reaction`/`MemoRelation`/`UserIdentity` ~1), since `User` and `Memo` are the two core domain objects threaded through auth, notification, RSS export, and payload-processing code, whereas the others are mostly consumed only inside `server/router/api/v1`.
