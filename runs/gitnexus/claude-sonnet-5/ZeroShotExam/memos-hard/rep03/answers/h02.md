This confirms both the delivery function and the SSRF protection mechanism.

h02.

- **Delivery function** — `Post` (and its async wrapper `PostAsync`, which enqueues to `asyncPostQueue` consumed by worker goroutines that call `Post`) in `internal/webhook/webhook.go:120` (async entry at `internal/webhook/webhook.go:184`). `Post` builds the HTTP request and sends it via the package-level `safeClient` (`internal/webhook/webhook.go:32`).
- **Protection mechanism** — the outbound `http.Client`'s `Transport.DialContext` is set to `safeDialContext` (`internal/webhook/webhook.go:59`), which resolves the destination host and rejects any IP falling in a reserved/private range via `isReservedIP` (`internal/webhook/validate.go:44`), checked against `reservedCIDRs`/`reservedNetworks` (loopback, RFC-1918, link-local/cloud IMDS `169.254.169.254`, IPv6 equivalents) defined in `internal/webhook/validate.go:14-26`. Blocking at dial time (post-DNS-resolution) rather than only at URL-validation time (`ValidateURL`, `internal/webhook/validate.go:62`) also defeats DNS-rebinding attacks. A deployment-level escape hatch, `AllowPrivateIPs` (`internal/webhook/validate.go:41`), can disable this check for self-hosted setups.
