**Premise correction:** There is no GraphQL schema in this repository — it doesn't use GraphQL at all. This is Memos, whose public API is defined with **Protocol Buffers** and served as gRPC + gRPC-Gateway (REST/JSON).

**Actual API surface:**
- Service definitions live in `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `instance_service.proto`, `ai_service.proto`, `common.proto`), with internal storage messages in `proto/store/*.proto`.
- Generated server/client code is emitted into `proto/gen/`.
- Route wiring/handlers are under `server/router/` (e.g. gRPC-Gateway registration exposing the REST surface derived from these `.proto` files).

No `.graphql`/`.gql` files or GraphQL libraries (Apollo, graphql-go, gqlgen, etc.) were found anywhere in the repo.
