- delivery function — `Post` in `internal/webhook/webhook.go:119-180` (invoked async via `PostAsync`/`asyncPostQueue`), which builds and sends the outbound HTTP request through the package's `safeClient`.
- protection mechanism — SSRF protection lives in two layers: `safeDialContext` (`internal/webhook/webhook.go:59-77`), installed as the `http.Transport.DialContext` on `safeClient`, resolves the target host at dial time and rejects any IP in a reserved/private range (defeating DNS-rebinding since the check happens on the resolved dial address, not just the URL); it delegates to `isReservedIP`/`reservedNetworks` defined in `internal/webhook/validate.go:14-54`, which blocks loopback, RFC-1918 private ranges, and link-local/cloud-IMDS (169.254.169.254) addresses (and IPv6 equivalents). A second, earlier check, `ValidateURL` in `internal/webhook/validate.go:62-83`, performs the same reserved-IP check at webhook-URL registration time (e.g. in `UpdateUserWebhook`, `server/router/api/v1/user_service_webhooks.go`).
