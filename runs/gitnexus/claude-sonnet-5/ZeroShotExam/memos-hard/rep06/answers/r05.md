**Premise correction:** There is no GraphQL schema in this repository — this is the `memos` project (note-taking app), and it doesn't use GraphQL at all. A repo-wide search (`*.graphql`, and any file content mentioning "graphql") turns up zero results.

**Actual API surface:** The public API is defined via **Protocol Buffers**, served over gRPC/gRPC-Gateway (REST-transcoded), under `proto/api/v1/`:

- `proto/api/v1/memo_service.proto`
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` (shared types)

Internal storage-layer messages live separately in `proto/store/*.proto`. Generated code (Go stubs, TS clients, gateway) lands in `proto/gen/`, and the Go service implementations that back these definitions live under `server/router`.
