**Data layer** = `store/` (the top-level `store` package plus its DB driver subpackages `store/db/{mysql,postgres,sqlite}`, which together implement persistence). The persistent entity types are defined in files like `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/memo_share.go`, `store/memo_relation.go`, `store/user_identity.go`, `store/user_setting.go`, `store/idp.go`, `store/instance_setting.go`.

Grepping for `store.<Type>` usages outside the `store/` tree (across `server/*`, `proto/gen/store`, etc.) and counting distinct Go packages that reference each type:

- `store.User` → referenced from `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss` (6 packages)
- `store.Memo` → referenced from `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload` (4 packages)
- `store.Attachment` → 3 packages; `store.Inbox`/`store.MemoShare` → 2 packages each; the rest (`Reaction`, `MemoRelation`, `UserIdentity`, `UserSetting`, `IdentityProvider`, `InstanceSetting`) → 1 package each.

**Answer:**
1st: `User` (store/user.go) — referenced from ~6 packages outside `store` (`server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/rss`)
2nd: `Memo` (store/memo.go) — referenced from ~4 packages outside `store` (`server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload`)
