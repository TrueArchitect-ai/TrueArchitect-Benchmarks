**Premise correction:** memos has no GraphQL schema — a repo-wide search for `graphql` turns up nothing, and there's no `.graphql` file anywhere in the tree.

**Actual API surface:** The public API is defined via Protocol Buffers under `proto/api/v1/` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`), which describe gRPC services exposed over gRPC-Gateway/REST. Internal storage messages live separately under `proto/store/` (e.g. `memo.proto`, `attachment.proto`, `idp.proto`, `inbox.proto`, `instance_setting.proto`, `user_setting.proto`).
