h14.

**Computation site:** `internal/markdown/markdown.go:356` (`service.ExtractAll`), invoked through `server/runner/memopayload/runner.go:74` (`RebuildMemoPayload`), which stores the result into `memo.Payload.Tags` and `memo.Payload.Property` (`storepb.MemoPayload_Property`, defined in `proto/gen/store/memo.pb.go`). `ExtractAll` does a single goldmark AST walk over the memo's markdown content to derive this data, as opposed to user-set fields like visibility, pinned, location, etc.

**Triggers (recomputation):**
- `CreateMemo` — always runs `memopayload.RebuildMemoPayload` on new content (`server/router/api/v1/memo_service.go:108`).
- `UpdateMemo` — runs `RebuildMemoPayload` only when the update mask includes the `"content"` path, i.e. the memo body actually changed (`server/router/api/v1/memo_service.go:446-451`).
- A batch/background path also exists: `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives the payload for every memo in the store in pages of 100 and persists it via `Store.UpdateMemo`. However, unlike the `s3presign` runner, this one is not wired into `Server.startBackgroundRunners` (`server/server.go:153-175`) or anywhere else in `cmd`/`server` — it exists as a reusable rebuild routine (e.g., for a future migration/maintenance task or CLI) but isn't currently scheduled at runtime.

**Extracted properties:**
- `Tags []string` — memo `#tag` nodes (deduped, case preserved), skipping tags inside links.
- `Mentions []string` — `@mention` nodes (lowercased, deduped) — collected in `ExtractedData` but not persisted into `Payload` by `RebuildMemoPayload` (only `Tags`/`Property` are assigned).
- `Property.Title` — text of the first block-level H1 heading, if present.
- `Property.HasLink` — set if any link node exists.
- `Property.HasCode` — set if any code block/fenced code block/code span exists.
- `Property.HasTaskList` — set if any task checkbox exists.
- `Property.HasIncompleteTasks` — set if any task checkbox is unchecked.

These `Tags`/`Property` fields (plus a separately generated `Snippet` via `Service.GenerateSnippet`) back memo list previews and filtering (`internal/filter/schema.go` exposes `hasTaskList`, `hasLink`, `hasCode`, `hasIncompleteTasks` as filterable properties).
