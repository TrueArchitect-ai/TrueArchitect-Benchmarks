**Premise correction:** This repo (memos) has no GraphQL schema — it doesn't use GraphQL anywhere. There are no `.graphql`/`.gql` files and no `graphql` dependencies in the codebase.

**Actual API surface:** The public API is defined via **Protocol Buffers** with gRPC + grpc-gateway (REST) generated from the same definitions:
- Service definitions: `proto/api/v1/*.proto` (e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`)
- Internal storage types: `proto/store/*.proto`
- README confirms: "Open & Extensible — MIT-licensed with full REST and gRPC APIs for integration" (`README.md`)

So instead of a GraphQL schema, look at `proto/api/v1/*.proto` for the API contract — REST endpoints are generated from these via grpc-gateway annotations.
