**Triggers (recomputation):**

**Extracted properties** (from the single goldmark AST walk in `ExtractAll`, `internal/markdown/markdown.go:356-422`):
- `Tags` — collected from `MemoTagNode`s in the content, deduplicated case-preserving.
- `Property.Title` — text of the first block child if it's an H1 heading.
- `Property.HasLink` — true if any `Link` node is present.
- `Property.HasCode` — true if any code block/fenced code block/code span is present.
- `Property.HasTaskList` — true if any task checkbox node is present.
- `Property.HasIncompleteTasks` — true if any task checkbox is unchecked.
- (Also `Mentions` are extracted in the same pass, though stored separately from `Payload`, not part of the `Tags`/`Property` metadata written back to the memo.)
