- **delivery function** — `Post()` in `internal/webhook/webhook.go:120` (invoked asynchronously via `PostAsync()`/`asyncPostQueue`, `internal/webhook/webhook.go:184`), which builds the signed HTTP request and sends it through the package-level `safeClient`.
