h14.

**Computation site:** `RebuildMemoPayload()` in `server/runner/memopayload/runner.go:74-88`, which delegates the actual content parsing to `(s *service) ExtractAll()` in `internal/markdown/markdown.go:356-422`. `ExtractAll` does a single goldmark AST walk over `memo.Content` and returns an `ExtractedData{Tags, Mentions, Property}` struct (defined at `internal/markdown/markdown.go:21-25`); `RebuildMemoPayload` then copies `data.Tags` and `data.Property` onto `memo.Payload` (a `storepb.MemoPayload`).

**Triggers:**
- `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:108`) — always, on every new memo.
- `APIV1Service.UpdateMemo` (`server/router/api/v1/memo_service.go:447`) — only when the update mask includes the `content` field path (i.e., content actually changed; edits to visibility/pin/etc. don't retrigger it).
- `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) — a batch backfill that pages through all memos and calls `RebuildMemoPayload` + `Store.UpdateMemo` for each. Note: unlike the `s3presign` runner (wired into `server/server.go:163`), this runner is **not** invoked anywhere in production startup code — it exists as a standalone/migration utility, not a scheduled job.

**Extracted properties** (stored on `store.Memo.Payload`, proto `storepb.MemoPayload`):
- `Tags []string` — deduplicated `#tag` occurrences (tags inside links/images excluded)
- `Property.Title` — text of the first H1 heading, only if it's the document's first block-level child
- `Property.HasLink` — content contains a markdown link
- `Property.HasCode` — content contains a code block/fenced block/code span
- `Property.HasTaskList` — content contains a task-list checkbox
- `Property.HasIncompleteTasks` — any task-list checkbox is unchecked

(Not persisted by this pass: `Mentions`, extracted by `ExtractAll` but discarded by `RebuildMemoPayload`; and snippet text, generated ad hoc elsewhere via `GenerateSnippet`, e.g. for notification previews, not stored on the memo payload.)
