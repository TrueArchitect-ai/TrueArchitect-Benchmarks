- protection mechanism — `safeDialContext` in `internal/webhook/webhook.go:59`, used as the `DialContext` of `safeClient`'s `http.Transport` (`internal/webhook/webhook.go:32-37`). It resolves the target host at dial time and rejects any resolved IP matching `isReservedIP` (`internal/webhook/validate.go:44`), which checks against the reserved/private CIDR ranges (loopback, RFC-1918, link-local/cloud IMDS, and IPv6 equivalents) defined in `internal/webhook/validate.go:14-23`. This dial-time check (not just pre-validation) also defeats DNS-rebinding attacks. A complementary pre-flight check, `ValidateURL` (`internal/webhook/validate.go:62`), performs the same reserved-IP check when a webhook URL is first registered/saved. Both checks can be disabled via the `AllowPrivateIPs` flag (`internal/webhook/validate.go:41`) for self-hosted deployments.
