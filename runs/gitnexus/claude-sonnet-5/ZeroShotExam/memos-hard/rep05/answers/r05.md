**Premise correction:** There is no GraphQL schema in this repository — I found zero `.graphql`/`.gql` files, no `graphql` string references anywhere in the codebase, and no `graphql` dependency in any `package.json`. GitNexus's `route_map` and `tool_map` also return no REST/tool endpoints indexed, consistent with this API surface being gRPC rather than HTTP-route-based. This project (`memos`) doesn't expose a GraphQL API at all.

**Actual API surface:** The public API is defined with **Protocol Buffers**, generating a gRPC service (with REST exposed via grpc-gateway/gRPC-Web). Service definitions live under `proto/api/v1/`, e.g.:
- `proto/api/v1/memo_service.proto` — memo CRUD
- `proto/api/v1/user_service.proto` — user management
- `proto/api/v1/auth_service.proto` — authentication
- `proto/api/v1/attachment_service.proto`, `shortcut_service.proto`, `instance_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`

Internal storage-layer messages (not the public API) are separately defined under `proto/store/` (e.g. `memo.proto`, `attachment.proto`, `inbox.proto`, `idp.proto`, `user_setting.proto`, `instance_setting.proto`).
