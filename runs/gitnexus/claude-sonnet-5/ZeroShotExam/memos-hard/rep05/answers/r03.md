Premise correction: there is no nightly database-cleanup job configured in this codebase's cron scheduler.

`internal/scheduler` (`internal/scheduler/README.md`) is a standalone, generic cron-scheduler *library* — it isn't wired into the Memos server at all. It's only imported by its own tests (`internal/scheduler/example_test.go`, `internal/scheduler/integration_test.go`); nothing in `main.go` or the server bootstrap code calls `scheduler.New()`/`Register()`. The README's `"daily-cleanup"` job at `0 2 * * *` and the "best practices" example `"stale-session-cleanup"` at `0 3 * * *` are illustrative documentation snippets, not an actual registered job.

So there's no real answer to "what time does it run" — no such job exists in this repo.
