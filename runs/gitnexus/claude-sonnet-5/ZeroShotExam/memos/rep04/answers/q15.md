- `user` table: **`User`** struct — `store/user.go` (fields match rows produced by e.g. `INSERT INTO "user" (...)` in `store/db/postgres/user.go`)

These are `usememos/memos` domain structs used with hand-written SQL (no ORM struct tags); each DB driver package (`store/db/postgres/`, `store/db/sqlite/`, `store/db/mysql/`) scans/writes rows for the corresponding table into these structs — e.g. `store/db/postgres/user.go` runs `INSERT INTO "user" (...)` and scans results into `store.User`.
