**Driver** — `store/driver.go`

The `Driver` interface (store/driver.go:10) declares all database operations (attachments, memos, users, settings, etc.). It's implemented by each backend in `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, and referenced/wired up in `store/db/db.go`.
