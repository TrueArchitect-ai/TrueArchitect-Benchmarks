**Memo lifecycle events → dispatch functions** (`server/router/api/v1/memo_service_webhooks.go`):
- `memos.memo.created`: `APIV1Service.DispatchMemoCreatedWebhook`
- `memos.memo.updated`: `APIV1Service.DispatchMemoUpdatedWebhook`
- `memos.memo.deleted`: `APIV1Service.DispatchMemoDeletedWebhook`
- `memos.memo.comment.created`: `APIV1Service.DispatchMemoCommentCreatedWebhook`

The first three all route through the shared helper `APIV1Service.dispatchMemoRelatedWebhook` (memo_service_webhooks.go:48), while `DispatchMemoCommentCreatedWebhook` builds its payload inline; all four ultimately call `webhook.PostAsync` (`internal/webhook/webhook.go:184`).

**Convergence point for delivery:** `webhook.PostAsync` enqueues onto `asyncPostQueue`, which is drained by 4 worker goroutines (started in `init()`, `internal/webhook/webhook.go:42-55`) that call `webhook.Post` (`internal/webhook/webhook.go:120`) — the actual HTTP POST to the webhook URL. So all memo webhook events converge at `internal/webhook/webhook.go:Post`.
