Confirmed via SQL statements that `user`, `attachment`, `reaction` tables map to these structs in `store/*.go`.

q15.

- `user`: `User` — `store/user.go`
- `attachment`: `Attachment` — `store/attachment.go`
- `reaction`: `Reaction` — `store/reaction.go`

These are the domain structs in the `store` package; there's no ORM tag mapping — the mapping is established by the hand-written SQL in the driver packages (e.g. `store/db/sqlite/user.go`, `INSERT INTO user ...` / `FROM user`), which build/scan rows into these exact structs.
