**Engine + path**: [CEL](https://github.com/google/cel-go) (`google/cel-go`), wrapped by GitNexus's own filter engine in `internal/filter/` (`engine.go`, `ir.go`, `parser.go`, `schema.go`, `render.go`).

**Mechanism**: `ListMemos`'s `request.Filter` string is validated via `s.validateFilter` (`server/router/api/v1/memo_service.go:212`), which uses `filter.DefaultEngine()` (`internal/filter/engine.go:111`) — a CEL `cel.Env` built from `NewSchema()`'s `EnvOptions` (`internal/filter/schema.go:232`) — to `Compile` the filter string into a CEL AST (`engine.go:53`), convert that AST into a dialect-agnostic `Condition` IR tree via `buildCondition` (`internal/filter/parser.go`/`ir.go`), and then `Program.Render(opts)` walks that IR with a `renderer` (`internal/filter/render.go`) that switches on `opts.Dialect` (sqlite/mysql/postgres) to emit dialect-specific SQL fragments and args, which `store/db/{sqlite,mysql,postgres}/memo.go`'s `ListMemos` methods splice into the final query.
