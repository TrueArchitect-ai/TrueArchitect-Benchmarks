1. **Memo relation records** (`memo_relation` table) — deleted twice via `driver.DeleteMemoRelation`: once where the memo is the source (`MemoID`), and once where it's the target (`RelatedMemoID`) (store/memo.go:142-147).
2. **Attachment records** linked to the memo — fetched via `ListAttachments` and removed one-by-one via `DeleteAttachment` (which also deletes the underlying attachment storage/blob) (store/memo.go:148-157).

Note: comment-relation cleanup (deleting child memos that are comments) and reaction/webhook handling happen one layer up, in the API handler (`server/router/api/v1/memo_service.go:545-577`), not inside the store's `DeleteMemo` itself.
