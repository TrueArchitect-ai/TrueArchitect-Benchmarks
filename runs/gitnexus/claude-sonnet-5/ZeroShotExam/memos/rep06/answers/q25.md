**Engine + path:** A custom CEL (Common Expression Language) filter engine built on `github.com/google/cel-go/cel`, living in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`). `filter.DefaultEngine()` (`internal/filter/engine.go:111`) provides the process-wide instance used for `ListMemos`' `filter` field.

**Mechanism:** The filter string is parsed/type-checked by `cel-go` against a memo-specific schema/environment (`schema.go`) into a CEL AST, `parser.go`'s `buildCondition` normalizes that AST into a dialect-agnostic IR condition tree (`ir.go`), and `render.go`'s renderer walks that IR to emit dialect-specific SQL (SQLite/MySQL/Postgres, chosen via `RenderOptions.Dialect`) with placeholder args, appended to the store's `WHERE` clause via `Program.Render`/`Engine.CompileToStatement`.
