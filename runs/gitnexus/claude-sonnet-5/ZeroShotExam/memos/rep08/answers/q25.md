**Engine + path:** A custom CEL-based filter engine at `internal/filter/` (built on Google's `cel-go`), entry point `filter.DefaultEngine()` in `internal/filter/engine.go`.

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go:211-216`) validates and appends the raw filter string to `store.FindMemo.Filters`; each dialect-specific store driver (`store/db/{sqlite,postgres,mysql}/memo.go`) then calls `filter.DefaultEngine()` and `filter.AppendConditions(...)`, which parses the CEL expression against the memo schema (`internal/filter/schema.go`), normalizes it into a dialect-agnostic IR (`internal/filter/ir.go` via `internal/filter/parser.go`), and renders that IR into a SQL fragment + placeholder args tailored to the target dialect (`internal/filter/render.go`, e.g. `?` placeholders for SQLite/MySQL vs `$n` for Postgres, `LIKE`/`ILIKE`, JSON operators, etc.).
