**Engine + path:** A custom CEL-based filter engine in `internal/filter/` (`engine.go`, `parser.go`, `ir.go`, `render.go`, `schema.go`), exposed via `filter.DefaultEngine()`.

**Mechanism:** `ListMemos` (`server/router/api/v1/memo_service.go`) takes the request's `Filter` string and, after validation, stores it on `store.FindMemo.Filters`; each dialect-specific store package (e.g. `store/db/sqlite/memo.go:57-61`, and the equivalent mysql/postgres files) then calls `filter.AppendConditions` → `Engine.CompileToStatement`, which parses the expression as standard CEL syntax via `cel-go` against the memo/attachment schema (`schema.go`), normalizes it into a dialect-agnostic IR (`ir.go`), and finally renders that IR (`render.go`) into a SQL fragment + placeholder args tailored to the target `Dialect` (`sqlite`, `mysql`, or `postgres`).
