**Premise correction:** There is NO GraphQL schema for the public API. The API is NOT built on GraphQL.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)**, with the service definitions in the `proto/api/v1/` directory:

- `proto/api/v1/auth_service.proto` — Authentication service
- `proto/api/v1/user_service.proto` — User management  
- `proto/api/v1/memo_service.proto` — Memo operations
- `proto/api/v1/attachment_service.proto` — Attachment management
- `proto/api/v1/shortcut_service.proto` — Shortcut management
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI features
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/common.proto` — Common types

The API is exposed via:
1. **Connect RPC** (generated from `.connect.go` files using connectrpc.com)
2. **gRPC-Gateway** (generated from `.pb.gw.go` files for HTTP/JSON REST endpoints)
