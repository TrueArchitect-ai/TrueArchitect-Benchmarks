**Premise correction:** The webhook delivery workers do NOT consume from a message broker like NATS or RabbitMQ. There is no external message broker.

**Actual mechanism:** Webhook delivery uses a simple in-memory Go channel queue. The queue is declared as a package-level variable in `internal/webhook/webhook.go:39`:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

In the `init()` function (`internal/webhook/webhook.go:42-54`), four worker goroutines are spawned that continuously consume from this channel and execute the webhook delivery via the `Post()` function. When a webhook is dispatched, `PostAsync()` (`internal/webhook/webhook.go:184-196`) enqueues the payload onto this channel. If the queue is full (128 items), the dispatch is dropped with a warning log.
