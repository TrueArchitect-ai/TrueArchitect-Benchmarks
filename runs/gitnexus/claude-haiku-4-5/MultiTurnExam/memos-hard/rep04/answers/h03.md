The identity provider abstraction is defined in the **`internal/idp`** package (file: `internal/idp/idp.go`), which defines the `IdentityProviderUserInfo` struct and the protocol interface. The concrete OAuth2 protocol implementation shipped is in the **`internal/idp/oauth2`** package (file: `internal/idp/oauth2/oauth2.go`), which implements the `IdentityProvider` type that handles OAuth2 token exchange and user information retrieval.
