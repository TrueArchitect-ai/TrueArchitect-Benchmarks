**Premise correction:** The cache layer does NOT use Redis. It uses an in-memory cache implementation.

**Actual mechanism:** The cache is configured in-memory in `store/store.go:40-45` within the `New()` function. All three cache instances (instanceSettingCache, userCache, userSettingCache) use the same `cacheConfig` with:
- **DefaultTTL: 10 minutes** (applies to user entries and all cached data)
- CleanupInterval: 5 minutes
- MaxItems: 1000

The cache implementation is in `store/cache/cache.go` and provides a thread-safe in-memory cache with TTL support, background cleanup, and memory management through eviction policies.
