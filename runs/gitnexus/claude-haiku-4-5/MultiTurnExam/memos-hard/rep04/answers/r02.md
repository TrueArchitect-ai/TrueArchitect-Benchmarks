**Premise correction:** There is no per-user API rate-limiting middleware registered in this repository. The codebase does not implement API rate limiting for user requests. 

The only rate/concurrency limiting present is for internal resource management (e.g., thumbnail generation limited to 3 concurrent operations and image processing to 2 concurrent operations via semaphores in server/router/api/v1/v1.go and server/router/fileserver/fileserver.go), but this is not user-facing API rate limiting.
