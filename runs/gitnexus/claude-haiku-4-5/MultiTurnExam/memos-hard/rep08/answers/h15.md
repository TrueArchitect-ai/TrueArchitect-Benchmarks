Distinct memo visibility enforcement sites:

1. Memo service RPC handlers — `server/router/api/v1/memo_service.go:39` (checkMemoReadAccess function enforces visibility for GetMemo, ListMemoComments, and related handlers)

2. Reaction service RPC handlers — `server/router/api/v1/reaction_service.go:30` (inline visibility checks for ListMemoReactions, UpsertMemoReaction, DeleteMemoReaction)

3. Memo attachment service RPC handler — `server/router/api/v1/memo_attachment_service.go:214` (inline visibility checks for ListMemoAttachments)

4. Attachment service RPC handler — `server/router/api/v1/attachment_service.go:436` (inline visibility checks for attachment access related to memos)

5. File server HTTP handler — `server/router/fileserver/fileserver.go:677` (visibility enforcement for attachment/avatar downloads via HTTP)

6. RSS feed generator — `server/router/rss/rss.go:90` (VisibilityList filter enforces only Public memos appear in RSS feeds)

Each site independently checks `memo.Visibility` and enforces access control: Public memos are accessible to all, Protected/Private memos require authentication and ownership/admin verification.
