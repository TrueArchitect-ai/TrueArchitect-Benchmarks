**Premise correction:** There is no GraphQL schema for the public API.

**Actual API surface:** The Memos public API uses Protocol Buffers (protobuf) with gRPC-Gateway + Connect RPC:

- **Protocol Buffer service definitions:** Located in `/bench/home/work/proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `instance_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, and `idp_service.proto`
- **Example:** `proto/api/v1/memo_service.proto:17-50` defines the `MemoService` with RPCs like `CreateMemo`, `ListMemos`, `GetMemo`, `UpdateMemo`, `DeleteMemo` each annotated with HTTP route mappings (e.g., `post: "/api/v1/memos"`)
- **Gateway registration:** `server/router/api/v1/v1.go:88-122` registers all service handlers with gRPC-Gateway using `v1pb.RegisterMemoServiceHandlerServer`, `v1pb.RegisterUserServiceHandlerServer`, etc.
- **Connect RPC:** Also supported via Connect handlers at `server/router/api/v1/v1.go:139-144` for browser clients (replaces grpc-web) on routes like `/memos.api.v1.*`
- **Code generation:** Protobuf definitions compile to Go code in `proto/gen/api/v1/` with handlers implemented in `server/router/api/v1/*_service.go` files

The API is REST-like HTTP (via gRPC-Gateway) plus Connect RPC, not GraphQL.
