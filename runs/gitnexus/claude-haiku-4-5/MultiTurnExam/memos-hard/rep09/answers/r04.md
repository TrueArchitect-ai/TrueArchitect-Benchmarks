**Premise correction:** This repository does NOT use NATS or RabbitMQ for webhook delivery. There is no external message broker at all.

**Actual mechanism:** Webhook delivery workers consume from an in-process Go channel, not an external message broker. The implementation is:

1. **Queue declaration:** An unbuffered Go channel is declared as a package-level variable in `internal/webhook/webhook.go:39`:
   ```go
   asyncPostQueue = make(chan *WebhookRequestPayload, 128)
   ```
   This is a buffered channel with capacity of 128 webhook payloads.

2. **Worker pool:** In the `init()` function (`internal/webhook/webhook.go:42-55`), 4 goroutine workers are spawned that consume from this channel and call `Post()` to deliver the webhooks:
   ```go
   for range 4 {
       go func() {
           for payload := range asyncPostQueue {
               if err := Post(payload); err != nil {
                   // log error
               }
           }
       }()
   }
   ```

3. **Enqueueing:** Webhooks are enqueued via `PostAsync()` function (`internal/webhook/webhook.go:184-196`) which sends payloads to the channel with a non-blocking select to drop if the queue is full.

This is a simple in-memory, single-process webhook delivery system with no external message broker.
