**Premise correction:** This repository does NOT use GraphQL for its public API. There is no GraphQL schema defined anywhere.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with **gRPC** and **gRPC-Gateway** HTTP bridge:

1. **Schema location:** API schema is defined in `.proto` files under `proto/api/v1/`:
   - `proto/api/v1/memo_service.proto` – Memo CRUD and operations
   - `proto/api/v1/auth_service.proto` – Authentication
   - `proto/api/v1/user_service.proto` – User management
   - `proto/api/v1/attachment_service.proto` – Attachments
   - `proto/api/v1/idp_service.proto` – Identity providers
   - `proto/api/v1/instance_service.proto` – Instance settings
   - `proto/api/v1/ai_service.proto` – AI operations
   - `proto/api/v1/shortcut_service.proto` – Shortcuts
   - `proto/api/v1/common.proto` – Shared enums and messages

2. **Generated code:** Protobuf compiler generates both:
   - gRPC Go stubs in `proto/gen/api/v1/*_grpc.pb.go`
   - gRPC-Gateway HTTP gateway bindings in `proto/gen/api/v1/*_pb.gw.go`

3. **HTTP mapping:** gRPC-Gateway uses the `google.api.http` option in `.proto` files to map RPC methods to HTTP endpoints. For example, `MemoService.CreateMemo` maps to `POST /api/v1/memos`.

4. **Transport registration:** HTTP API is registered in `server/router/api/v1/v1.go` via the `RegisterGateway()` method called from `server/server.go:88`.
