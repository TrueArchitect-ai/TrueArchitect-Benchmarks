**Premise correction:** There is no GraphQL schema. The public API is defined using Protocol Buffers (gRPC), not GraphQL.

**Actual API surface:**
The API is defined using Protocol Buffer service definitions located in `/bench/home/work/proto/api/v1/`. The main service files include:

- `/bench/home/work/proto/api/v1/memo_service.proto` — MemoService with CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo RPC methods
- `/bench/home/work/proto/api/v1/user_service.proto` — UserService
- `/bench/home/work/proto/api/v1/auth_service.proto` — AuthService
- `/bench/home/work/proto/api/v1/instance_service.proto` — InstanceService
- `/bench/home/work/proto/api/v1/attachment_service.proto` — AttachmentService
- `/bench/home/work/proto/api/v1/ai_service.proto` — AIService
- `/bench/home/work/proto/api/v1/shortcut_service.proto` — ShortcutService
- `/bench/home/work/proto/api/v1/idp_service.proto` — IdentityProviderService

These proto files define RPC methods with HTTP routing using `google.api.annotations.proto`. The API is exposed via two mechanisms:
1. **gRPC-Gateway** (server/router/api/v1/v1.go:99-111) — for REST clients
2. **Connect** (server/router/api/v1/v1.go:131-134) — for browser clients, replacing grpc-web

The generated Go code is located in `proto/gen/api/v1/` and the service implementations are in `server/router/api/v1/*_service.go` files.
