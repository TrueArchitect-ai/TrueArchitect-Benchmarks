**Premise correction:** There is no GraphQL schema for the public API. The repository does not use GraphQL.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC and HTTP REST bindings. The API schemas are defined in proto files:

- `proto/api/v1/memo_service.proto` - Memo CRUD operations
- `proto/api/v1/user_service.proto` - User management
- `proto/api/v1/auth_service.proto` - Authentication
- `proto/api/v1/attachment_service.proto` - Attachments
- `proto/api/v1/instance_service.proto` - Instance configuration
- `proto/api/v1/idp_service.proto` - Identity providers
- `proto/api/v1/ai_service.proto` - AI integration
- `proto/api/v1/shortcut_service.proto` - Shortcuts

Each service is exposed as:
1. **gRPC** - Native protobuf RPC over HTTP/2
2. **REST/HTTP** - Via gRPC-Gateway (google.api.http annotations), served at `/api/v1/` endpoints

The proto definitions use `google.api.http` annotations to map RPC methods to HTTP verbs and paths (e.g., `post: "/api/v1/memos"` for CreateMemo).
