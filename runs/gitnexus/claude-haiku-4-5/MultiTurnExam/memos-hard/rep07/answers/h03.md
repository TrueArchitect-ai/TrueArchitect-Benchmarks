h03.

**Abstraction package:** `internal/idp`; **implementation package:** `internal/idp/oauth2`

The `internal/idp` package defines the common output type `IdentityProviderUserInfo` that represents the abstraction contract. The `internal/idp/oauth2` package provides the concrete OAuth2 protocol implementation through its `IdentityProvider` type, which implements the methods `ExchangeToken` and `UserInfo`.
