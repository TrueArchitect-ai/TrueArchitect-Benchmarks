**Premise correction:** The repository does not use Redis. There is no Redis connection configuration.

**Actual mechanism:** User cache entries are managed by an in-memory thread-safe cache (`store/cache/cache.go`) configured in `store/store.go:38-60`. The cache is initialized with:
- **DefaultTTL:** 10 minutes (line 41)
- **CleanupInterval:** 5 minutes (line 42)  
- **MaxItems:** 1000 (line 43)

The user cache is instantiated at line 52: `userCache: cache.New(cacheConfig)` and uses the same configuration as the instance settings cache and user settings cache. User entries expire after 10 minutes of being set, after which they are automatically cleaned up by the background cleanup loop that runs every 5 minutes (store/cache/cache.go:199-215).
