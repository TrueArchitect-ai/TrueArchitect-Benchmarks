**Handlers: CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment**; **Convergence function — Post — internal/webhook/webhook.go:120**

All four RPC handlers can transitively cause an outbound HTTP request to a user-configured webhook URL. The `CreateMemo`, `UpdateMemo`, and `DeleteMemo` handlers call `DispatchMemoCreatedWebhook`, `DispatchMemoUpdatedWebhook`, and `DispatchMemoDeletedWebhook` respectively, which all converge to `dispatchMemoRelatedWebhook` (server/router/api/v1/memo_service_webhooks.go:48-74). The `CreateMemoComment` handler calls `DispatchMemoCommentCreatedWebhook` (server/router/api/v1/memo_service_webhooks.go:30-46). Both dispatch functions call `webhook.PostAsync`, which enqueues the payload to be consumed by goroutines that call the single convergence function `webhook.Post` (internal/webhook/webhook.go:120), which executes the actual outbound HTTP request using the `safeClient` (internal/webhook/webhook.go:32-37).
