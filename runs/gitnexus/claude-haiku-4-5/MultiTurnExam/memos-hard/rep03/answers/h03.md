h03.

**abstraction package — internal/idp**; **implementation package — internal/idp/oauth2**

The `internal/idp` package defines the provider abstraction through the `IdentityProviderUserInfo` struct (internal/idp/idp.go:3-8), which represents the common user information returned by any identity provider. The concrete OAuth2 implementation is in `internal/idp/oauth2` (internal/idp/oauth2/oauth2.go:1-2), which implements the `ExchangeToken` and `UserInfo` methods to handle OAuth2 authentication flows.
