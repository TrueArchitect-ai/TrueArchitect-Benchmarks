**Premise correction:** There is no Redis connection. The cache layer is not backed by Redis. **Actual mechanism:** The cache is an in-memory, thread-safe cache implemented in `store/cache/cache.go` with configuration set in `store/store.go:40-45`. User entries (and all cached entries) use a TTL of **10 minutes** (store/store.go:41: `DefaultTTL: 10 * time.Minute`). The cache runs a cleanup goroutine every 5 minutes (store/cache/cache.go:60: `CleanupInterval: 5 * time.Minute`) to evict expired entries, with a maximum capacity of 1000 items.
