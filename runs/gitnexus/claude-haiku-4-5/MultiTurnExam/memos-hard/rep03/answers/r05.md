**Premise correction:** There is no GraphQL schema. The public API does not use GraphQL. **Actual API surface:** The API is defined using Protocol Buffers (protobuf). The service definitions are in `/bench/home/work/proto/api/v1/` with the following main services:

- `memo_service.proto` — Memo CRUD and listing operations
- `user_service.proto` — User management, webhooks, and access tokens
- `attachment_service.proto` — Attachment management
- `auth_service.proto` — Authentication (sign-in, sign-out, refresh tokens)
- `instance_service.proto` — Instance configuration and settings
- `ai_service.proto` — AI/LLM integration
- `shortcut_service.proto` — Keyboard shortcuts
- `idp_service.proto` — Identity provider management
- `common.proto` — Common message types

The API is served via gRPC-Gateway (which translates HTTP/JSON to gRPC) and also via Connect-RPC, both of which use these proto definitions as their contract. The generated code is in `proto/gen/api/v1/`.
