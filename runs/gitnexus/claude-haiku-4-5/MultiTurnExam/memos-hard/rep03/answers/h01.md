The `s3presign.Runner` is started in the `startBackgroundRunners` method and runs continuously on a 12-hour interval (`runnerInterval = time.Hour * 12` at server/runner/s3presign/runner.go:27). It:
1. Queries all S3 attachments (and maintains presigned URLs)
2. Checks if presigned URLs are expiring within 4 days (they're set to 5-day expiration)
3. Regenerates presigned URLs before they go stale
4. Updates attachment references with fresh presigned URLs

This prevents S3 attachment links from going stale by refreshing them proactively on the 12-hour schedule.
