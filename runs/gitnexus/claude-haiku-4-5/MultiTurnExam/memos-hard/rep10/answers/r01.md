**Premise correction:** The question assumes Redis is used for caching, but this is incorrect. The cache layer is NOT Redis.

**Actual mechanism:** The cache layer is an in-memory cache implemented in `store/cache/cache.go:66`. User entries (and all other cache entries) use a **default TTL of 10 minutes** (store/store.go:41). The user cache is instantiated at store/store.go:52 as `cache.New(cacheConfig)` where `cacheConfig` defines `DefaultTTL: 10 * time.Minute` (store/store.go:40-45). The in-memory cache is thread-safe using `sync.Map` and runs a cleanup loop every 5 minutes to evict expired entries (store/cache/cache.go:59-60, 83).
