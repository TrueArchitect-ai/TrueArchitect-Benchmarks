**Abstraction package:** `internal/idp`; **implementation package:** `internal/idp/oauth2`

The abstraction package `internal/idp` (internal/idp/idp.go) defines the `IdentityProviderUserInfo` struct that represents user information returned by identity providers. The concrete OAuth2 protocol implementation is provided by the `internal/idp/oauth2` package (internal/idp/oauth2/oauth2.go), which implements an `IdentityProvider` type with methods for `ExchangeToken` and `UserInfo` that handle the OAuth2 flow for third-party authentication.
