**Premise correction:** There is no GraphQL schema for the public API. This is not a GraphQL-based API.

**Actual API surface:** The public API is defined using **Protocol Buffers (protobuf)** with gRPC-Gateway. The service definitions are located in `/bench/home/work/proto/api/v1/` with multiple service proto files:

- `proto/api/v1/memo_service.proto` — Memo operations (CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo)
- `proto/api/v1/auth_service.proto` — Authentication (GetAuthStatus, Login, Logout)
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/attachment_service.proto` — Attachment handling
- `proto/api/v1/instance_service.proto` — Instance settings
- `proto/api/v1/idp_service.proto` — Identity provider configuration
- `proto/api/v1/ai_service.proto` — AI service
- `proto/api/v1/shortcut_service.proto` — Shortcut management
- `proto/api/v1/common.proto` — Common types

Each service uses `google.api.http` annotations to define REST endpoint mappings (e.g., `post: "/api/v1/memos"` for CreateMemo). The gRPC-Gateway transpiles these protobuf definitions into HTTP REST endpoints, which are registered in `server/router/api/v1/v1.go`.
