**Premise correction**: There is no GraphQL schema for the public API. This repository does not use GraphQL.

**Actual API surface**: The public API is defined using Protocol Buffers (protobuf) and gRPC with HTTP transcoding via google.api.http annotations:

API definition files (proto/api/v1/):
- ai_service.proto
- attachment_service.proto
- auth_service.proto
- idp_service.proto
- instance_service.proto
- memo_service.proto
- shortcut_service.proto
- user_service.proto
- common.proto

The API surface uses:
- gRPC services defined in .proto files
- HTTP REST endpoints generated via google.api.http annotations (e.g., `post: "/api/v1/auth:signin"`)
- gRPC-Gateway for JSON-over-HTTP transcoding
- Connect RPC protocol support

The compiled protobuf definitions are generated to proto/gen/api/v1/ during the build process.
