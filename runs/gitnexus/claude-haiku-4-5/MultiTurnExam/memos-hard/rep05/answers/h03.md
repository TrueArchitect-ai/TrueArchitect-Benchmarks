h03.

The provider abstraction is defined in **internal/idp** package (internal/idp/idp.go), which defines the `IdentityProviderUserInfo` struct as the common data model that all providers return. The abstraction for the provider interface itself is implicit (methods defined by each concrete implementation).

The concrete protocol implementation that ships is **internal/idp/oauth2** (internal/idp/oauth2/oauth2.go), which implements the OAuth2 identity provider with methods for exchanging authorization codes and retrieving user information via bearer token authentication.

Abstraction package — **internal/idp**; Implementation package — **internal/idp/oauth2**
