**Premise correction**: There is no Redis connection for the cache layer. This repository does not use Redis for caching.

**Actual mechanism**: The cache layer uses an in-memory cache implementation. Configuration and TTL details:

- Cache implementation: store/cache/cache.go (in-memory cache)
- Cache configuration: store/store.go:40-45 (New function configures all caches)
- Default TTL for all cache entries (including user cache): **10 minutes** (store/store.go:41: `DefaultTTL: 10 * time.Minute`)
- Cache cleanup interval: 5 minutes
- Max items per cache: 1000

The three caches created with this configuration are:
- instanceSettingCache (store/store.go:51)
- userCache (store/store.go:52) 
- userSettingCache (store/store.go:53)

All three use the same 10-minute TTL applied uniformly at cache.New(cacheConfig).
