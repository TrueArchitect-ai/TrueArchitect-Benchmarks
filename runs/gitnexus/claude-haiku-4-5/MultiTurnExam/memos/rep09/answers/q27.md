**q27.**
Go embed directive (//go:embed dist/*); server/router/frontend/frontend.go

The compiled React frontend is served in production using **Go's embed directive** (line 20 in server/router/frontend/frontend.go). The built frontend files from the `dist/` directory are embedded into the binary at compile time via `//go:embed dist/*` (which creates an `embed.FS`), and then served by the FrontendService (lines 41-61) through Echo's middleware using `middleware.StaticWithConfig` for static assets and an SPA fallback middleware (line 59) that serves `index.html` for unmatched routes, enabling client-side routing.
