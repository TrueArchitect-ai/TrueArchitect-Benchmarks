Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment

The server uses **Server-Sent Events (SSE)** to push live events to browsers. The SSE hub is implemented in `server/router/api/v1/sse_hub.go`. The memo handlers that broadcast through it are:
1. `CreateMemo` (line 163 in memo_service.go) — broadcasts SSEEventMemoCreated
2. `UpdateMemo` (line 71 in memo_update_helpers.go via dispatchMemoUpdatedSideEffects) — broadcasts SSEEventMemoUpdated
3. `DeleteMemo` (line 585 in memo_service.go) — broadcasts SSEEventMemoDeleted
4. `CreateMemoComment` (line 126 in memo_service_comments.go) — broadcasts SSEEventMemoCommentCreated
