web/src/connect.ts; access tokens, refresh tokens (JWT); server/auth

Frontend API requests get authenticated through:

1. **Auth interceptor**: `authInterceptor` in `web/src/connect.ts` (line 156) — Manages access token attachment to request headers, automatic token refresh on 401 errors, and refresh token storage via cookies (set with `credentials: "include"`)

2. **Token kinds managed**: 
   - Access tokens (short-lived JWT, 15 minutes)
   - Refresh tokens (long-lived JWT, 30 days, stored in cookies)

3. **Backend validation package**: `server/auth` — The Authenticator struct (server/auth/authenticator.go) validates both access tokens via `AuthenticateByAccessTokenV2()` and refresh tokens via `AuthenticateByRefreshToken()`. Token parsing uses JWT library with the server's secret key (server/auth/token.go).
