CEL (Common Expression Language) — internal/filter/engine.go; The filter string is parsed to a CEL AST by the Engine (line 53), converted to a dialect-agnostic condition tree (line 62), and then rendered to dialect-specific SQL with placeholder arguments by the renderer (lines 96-99).

The ListMemos filter syntax uses **CEL (Common Expression Language)** defined and parsed by the **Engine** in `internal/filter/engine.go`. The mechanism works in three steps: (1) the Engine compiles the CEL filter string to an AST via `cel.NewEnv().Compile()` (line 53), (2) builds a dialect-agnostic condition tree from the AST (line 62), and (3) the `Renderer` in `internal/filter/render.go` converts that condition tree to dialect-specific SQL (via `RenderOptions.Dialect`: DialectSQLite, DialectMySQL, DialectPostgres) with properly parameterized placeholders for injection-safe execution in `store/db/{dialect}/memo.go`.
