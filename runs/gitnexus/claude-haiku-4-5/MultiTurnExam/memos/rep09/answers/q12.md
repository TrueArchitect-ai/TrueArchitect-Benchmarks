The ListMemos request path flows through:
1. `useMemos` hook in `web/src/hooks/useMemoQueries.ts` calls `memoServiceClient.listMemos()`
2. `memoServiceClient` is created in `web/src/connect.ts` via `createClient(MemoService, transport)`
3. `ListMemos` RPC is defined in `proto/api/v1/memo_service.proto`
4. Backend handler `APIV1Service.ListMemos` in `server/router/api/v1/memo_service.go` calls `s.Store.ListMemos()`
5. Store method `Store.ListMemos` in `store/memo.go` delegates to the driver
6. SQLite implementation `DB.ListMemos` in `store/db/sqlite/memo.go` executes the SQL query
