CEL (Common Expression Language) using google/cel-go; internal/filter/engine.go
The Engine parses CEL filter expressions into a dialect-agnostic condition tree, then the Renderer in internal/filter/render.go translates this tree into dialect-specific SQL using PostgreSQL operators (EXTRACT, @>), MySQL functions (JSON_TABLE, DAYOFMONTH), and SQLite functions (strftime, json_each), each with appropriate placeholder formats ($N for Postgres, ? for MySQL/SQLite).
