CEL (Common Expression Language) — /bench/home/work/internal/filter/engine.go; The CEL engine compiles filter expressions into a dialect-agnostic condition tree, which is then rendered to dialect-specific SQL by a renderer configured with the appropriate dialect (MySQL, PostgreSQL, SQLite) during database query execution.

The filter parsing flow is: CEL parses the filter string → compiled to a condition tree via `Engine.Compile()` → rendered to SQL via `Program.Render(RenderOptions)` with dialect specified → applied to the query in each dialect driver (e.g., PostgreSQL driver at `/bench/home/work/store/db/postgres/memo.go:58` calls `filter.AppendConditions()` with `filter.DialectPostgres`).
