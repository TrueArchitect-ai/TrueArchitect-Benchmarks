/bench/home/work/web/src/connect.ts; JWT access tokens, JWT refresh tokens (in cookies), Personal Access Tokens; /bench/home/work/server/auth

Frontend API requests are authenticated via the `authInterceptor` defined in `/bench/home/work/web/src/connect.ts` (lines 156-178), which manages three token kinds:
1. JWT access tokens (short-lived, 15 minutes)
2. JWT refresh tokens (long-lived, 30 days, stored in cookies)
3. Personal Access Tokens (programmatic access)

The backend validates these tokens via the `/bench/home/work/server/auth` package, which provides `Authenticator` (authenticator.go) methods for stateless access token validation and database-backed refresh token/PAT validation.
