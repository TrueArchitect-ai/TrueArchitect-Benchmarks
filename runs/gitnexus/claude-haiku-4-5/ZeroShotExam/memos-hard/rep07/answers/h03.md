h03.

The provider abstraction is defined in the **`internal/idp`** package, which defines the `IdentityProviderUserInfo` type and the common interface for identity providers (internal/idp/idp.go). The concrete protocol implementation that ships is **OAuth2** via the **`internal/idp/oauth2`** package (internal/idp/oauth2/oauth2.go).

The abstraction is reinforced at the proto level in **`proto/store`** (proto/store/idp.proto) which defines the `IdentityProvider` message with a Type enum that includes `OAUTH2` as the concrete implementation, and an `IdentityProviderConfig` oneof that currently contains only `OAuth2Config`.

**Answer: `internal/idp`; `internal/idp/oauth2`**
