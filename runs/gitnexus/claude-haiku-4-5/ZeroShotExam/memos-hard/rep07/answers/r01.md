The repository does **not use Redis** for caching. The premise of the question contains a factual error.

**Actual mechanism:** The cache layer is configured in `/bench/home/work/store/store.go` (lines 38-61) and `/bench/home/work/store/cache/cache.go`. It is an **in-memory cache** using Go's `sync.Map`, not Redis. The cache is initialized in the `Store.New()` function with:

- **DefaultTTL for user entries: 10 minutes** (line 41: `DefaultTTL: 10 * time.Minute`)
- User cache instance: `userCache *cache.Cache` (line 28)
- CleanupInterval: 5 minutes
- MaxItems: 1000

The configuration is defined in the `cache.Config` struct at `/bench/home/work/store/cache/cache.go:41-54` with the default TTL applied at line 59.
