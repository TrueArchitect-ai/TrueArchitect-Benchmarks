**Premise Correction:** This project does not use GraphQL for its public API. Instead, it uses Protocol Buffers (protobuf) to define its API schema.

**Actual API Surface:**

The public API schema is defined in Protocol Buffer files located at:
- `/bench/home/work/proto/api/v1/` — Contains the primary service definitions

Key schema files:
- `memo_service.proto` — Memo management operations
- `user_service.proto` — User management and authentication
- `instance_service.proto` — Instance configuration
- `attachment_service.proto` — Attachment handling
- `auth_service.proto` — Authentication services
- `idp_service.proto` — Identity provider configuration
- `ai_service.proto` — AI capabilities
- `shortcut_service.proto` — Shortcut management
- `common.proto` — Common types and messages

The proto files are compiled to generate multiple API implementations (gRPC, REST/HTTP via gRPC-JSON transcoding). An OpenAPI 3.0.3 specification is generated at `/bench/home/work/proto/gen/openapi.yaml` from these proto definitions.
