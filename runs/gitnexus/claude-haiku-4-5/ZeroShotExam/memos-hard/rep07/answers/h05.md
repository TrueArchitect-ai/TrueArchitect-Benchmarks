**Mechanism: Explicit Go code**

When a user is deleted, emoji reactions are removed by explicit Go code executing two targeted DELETE statements, not by database-level cascade rules.

**Evidence locations:**

1. **Deletion orchestration** (`store/db/mysql/user_delete.go:92-104`): The `deleteUserTargetsTx` function explicitly calls two reaction deletion functions in sequence:

   - Line 102: `deleteReactionsByCreatorTx(ctx, tx, userID)` — deletes reactions created by the user
