Neither NATS nor RabbitMQ — the webhook delivery workers consume from an **in-process Go channel-based queue** instead. The queue is declared at line 39 of `internal/webhook/webhook.go` as:

```go
asyncPostQueue = make(chan *WebhookRequestPayload, 128)
```

Four worker goroutines are spawned in the `init()` function (lines 43–54) at module initialization that consume messages from this channel and dispatch webhooks using the synchronous `Post()` function. When `PostAsync()` is called (line 184), webhook payloads are sent to this bounded channel; if the channel is full, the webhook dispatch is dropped with a warning log.
