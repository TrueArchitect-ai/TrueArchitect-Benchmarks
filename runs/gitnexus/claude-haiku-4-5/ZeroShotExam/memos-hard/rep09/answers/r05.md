**Premise correction:** This repository does not use GraphQL. It uses **gRPC with Protocol Buffers (protobuf)** for its API definitions.

**Actual API surface:** The public API schema is defined in `.proto` files located in `/proto/api/v1/`:

- **memo_service.proto** — Memo CRUD operations, attachments, relations, comments, reactions, sharing, link metadata
- **user_service.proto** — User management, stats, settings, linked identities (SSO), personal access tokens, webhooks, notifications
- **auth_service.proto** — Authentication (SignIn, SignOut, RefreshToken, GetCurrentUser)
- **instance_service.proto** — Instance configuration and settings
- **attachment_service.proto** — Attachment operations and preview generation
- **ai_service.proto** — AI transcription service
- **idp_service.proto** — Identity provider management
- **shortcut_service.proto** — Keyboard shortcuts management
- **common.proto** — Shared enums and common message types

All files use `syntax = "proto3"` with the `memos.api.v1` package namespace. HTTP mappings (RESTful endpoints) are defined using Google API annotations.
