Emoji reactions are removed by **explicit Go code**.

**Mechanism:**
When a user is deleted, the deletion process executes two explicit SQL DELETE operations to remove emoji reactions:

1. **Delete reactions on deleted user's memos** (by content_id):
   - `deleteReactionsByContentIDsTx()` removes all reactions on memos created by the user
   - Deletes from the `reaction` table where `content_id IN (list of memo UIDs)`

2. **Delete reactions created by the deleted user** (by creator_id):
   - `deleteReactionsByCreatorTx()` removes all emoji reactions the user created
   - Deletes from the `reaction` table where `creator_id = userID`

**Evidence locations:**

- **MySQL**: `store/db/mysql/user_delete.go:417-425` — `deleteReactionsByContentIDsTx()` at line 417 and `deleteReactionsByCreatorTx()` at line 437
- **SQLite**: `store/db/sqlite/user_delete.go:380-403` — `deleteReactionsByContentIDsTx()` at line 380 and `deleteReactionsByCreatorTx()` at line 400
- **Postgres**: `store/db/postgres/user_delete.go:400-403` — `deleteReactionsByCreatorTx()` at line 400
- **Orchestration**: `store/db/mysql/user_delete.go:92-127` — `deleteUserTargetsTx()` calls both deletion functions at lines 96 and 102 within the transaction

The deletions happen explicitly in Go code via `tx.ExecContext()` SQL statements within a database transaction, not via foreign key constraints or database triggers.
