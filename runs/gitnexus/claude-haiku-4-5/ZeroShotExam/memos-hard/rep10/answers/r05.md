**Premise correction:** This repository does not use GraphQL for its public API. Instead, it uses **Protocol Buffers (protobuf)** with gRPC services.

**Actual API surface:** The public API schema is defined in Protocol Buffer `.proto` files located in `/bench/home/work/proto/api/v1/`, including:
- `/bench/home/work/proto/api/v1/memo_service.proto`
- `/bench/home/work/proto/api/v1/user_service.proto`
- `/bench/home/work/proto/api/v1/auth_service.proto`
- `/bench/home/work/proto/api/v1/ai_service.proto`
- `/bench/home/work/proto/api/v1/attachment_service.proto`
- `/bench/home/work/proto/api/v1/idp_service.proto`
- `/bench/home/work/proto/api/v1/instance_service.proto`
- `/bench/home/work/proto/api/v1/shortcut_service.proto`
- `/bench/home/work/proto/api/v1/common.proto`

These protobuf definitions are managed via [Buf](https://buf.build) (configured in `/bench/home/work/proto/buf.yaml`) and code is generated to `/bench/home/work/proto/gen/`.
