**Premise correction:** This repository does not use GraphQL. The project uses **Protocol Buffers (protobuf)** and **gRPC** as the primary API framework, not GraphQL.

**Actual API surface:** The public API schemas are defined in Protocol Buffer files located in:
- **`proto/api/v1/`** — Contains the main service definitions:
  - `memo_service.proto` (core memo operations)
  - `user_service.proto` (user management)
  - `auth_service.proto` (authentication)
  - `instance_service.proto` (instance configuration)
  - `attachment_service.proto` (file attachments)
  - `ai_service.proto` (AI features)
  - `idp_service.proto` (identity provider)
  - `shortcut_service.proto` (shortcuts)
  - `common.proto` (shared types)

The README (line 22) explicitly states the project offers "full REST and gRPC APIs," which are generated from these `.proto` files, not GraphQL.
