**Protection mechanism:** `safeDialContext()` — `internal/webhook/webhook.go:57`

The `Post()` function executes the outbound HTTP delivery by creating an HTTP request and executing it through `safeClient` (line 152), which uses `safeDialContext` as its custom dialer. The `safeDialContext` function (lines 57-77) blocks outbound connections to reserved/private IP ranges by:

1. Splitting the target address and resolving the hostname (lines 60-68)
2. Checking each resolved IP against the `isReservedIP()` check (lines 70-74), which consults `reservedNetworks` built from the CIDR blocks defined in `internal/webhook/validate.go:14-23` (loopback, RFC-1918 ranges, link-local including cloud IMDS at 169.254.169.254, and IPv6 equivalents)
3. Refusing the connection if any IP is reserved/private (line 72)

This dual-layer protection validates URLs at registration time (`ValidateURL` in `validate.go:62`) and enforces the same restrictions at dial time to defeat DNS rebinding attacks.
