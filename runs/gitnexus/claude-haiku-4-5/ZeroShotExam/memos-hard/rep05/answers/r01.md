r01. This repository does not use Redis for its cache layer. There is no Redis configuration in the codebase.

**Actual mechanism:**
- Cache layer is configured in **store/store.go:37-61** (the `New` function) and **store/cache/cache.go** (the cache implementation)
- The cache is an in-memory implementation using Go's `sync.Map` with TTL support, not Redis
- User entries (stored in `userCache`) use the default TTL of **10 minutes** (set in store/cache/cache.go:59 and store/store.go:41)
- The cache configuration is defined in **store/cache/cache.go:42-64** with:
  - DefaultTTL: 10 minutes
  - CleanupInterval: 5 minutes (expired entries removed periodically)
  - MaxItems: 1000 (maximum cache entries)
