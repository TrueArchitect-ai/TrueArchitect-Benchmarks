**Premise Correction:** This repository does not define a GraphQL schema. The public API is built using **Protocol Buffers (protobuf)**, not GraphQL.

**Actual API Surface:**

The public API schema is defined in protobuf `.proto` files located in `/bench/home/work/proto/api/v1/`:

- `memo_service.proto` — Memo service API
- `user_service.proto` — User service API
- `auth_service.proto` — Authentication service API
- `attachment_service.proto` — Attachment service API
- `ai_service.proto` — AI service API
- `idp_service.proto` — Identity provider service API
- `instance_service.proto` — Instance service API
- `shortcut_service.proto` — Shortcut service API
- `common.proto` — Common types and enums

The protobuf schema is compiled to an **OpenAPI 3.0.3 specification** at `/bench/home/work/proto/gen/openapi.yaml` (4057 lines), which serves as the REST API documentation. The schema processing logic is in `/bench/home/work/server/router/mcp/openapi.go`.
