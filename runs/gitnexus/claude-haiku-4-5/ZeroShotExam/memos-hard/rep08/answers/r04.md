**r04.**

Premise correction: There is no external message broker (neither NATS nor RabbitMQ) used for webhook delivery workers.

Actual mechanism: Webhook delivery uses an in-memory Go channel (`asyncPostQueue`) declared at `internal/webhook/webhook.go:39`. The queue is a buffered channel with capacity of 128 payloads (`make(chan *WebhookRequestPayload, 128)`). Four goroutine workers are spawned in the `init()` function (`internal/webhook/webhook.go:42-55`) that consume from this channel and dispatch webhooks synchronously via HTTP.
