**Premise correction:** This repository does not use GraphQL; it uses **Protocol Buffers (protobuf)** with gRPC and REST API support via Google API annotations.

**Actual API surface:** The public API schema is defined in **proto files** located at:

- **Primary services:** `/bench/home/work/proto/api/v1/` directory containing:
  - `memo_service.proto` — Memo service (create, list, get, update, delete memos)
  - `user_service.proto` — User service
  - `attachment_service.proto` — Attachment service
  - `auth_service.proto` — Authentication service
  - `instance_service.proto` — Instance service
  - `ai_service.proto` — AI service
  - `idp_service.proto` — Identity provider service
  - `shortcut_service.proto` — Shortcut service

- **Generated OpenAPI spec:** `/bench/home/work/proto/gen/openapi.yaml` — Auto-generated OpenAPI 3.0.3 specification from the protobuf definitions (via `protoc-gen-openapi`)

The services are defined using protobuf `service` definitions with `rpc` methods, and the REST API endpoints are configured using Google API annotations (e.g., `google.api.http` options) that map gRPC methods to HTTP endpoints like `POST /api/v1/memos`, `GET /api/v1/memos`, etc.
