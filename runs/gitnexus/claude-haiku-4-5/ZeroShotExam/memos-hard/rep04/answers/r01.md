**Premise correction:** There is no Redis cache layer in this repository.

**Actual mechanism:** The cache layer is implemented as an in-memory cache using Go's `sync.Map`, not Redis. The configuration is located in `store/store.go:38-61`, where the Store struct initializes three in-memory caches (`userCache`, `instanceSettingCache`, and `userSettingCache`) using the `cache.New()` function from `store/cache/cache.go:76`.

**User entries TTL:** User cache entries have a default TTL of **10 minutes**, as defined in `store/cache/cache.go:59` where `DefaultTTL: 10 * time.Minute` is set, and this configuration is applied to all three caches at instantiation in `store/store.go:40-45`.
