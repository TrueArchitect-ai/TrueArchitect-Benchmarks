The outbound webhook delivery executes in the `Post` function at `internal/webhook/webhook.go:119-180`. This function constructs an HTTP POST request and sends it using a shared `safeClient` HTTP client.

The protection against SSRF attacks is implemented through a custom dial function `safeDialContext` at `internal/webhook/webhook.go:57-77`, which:

1. Resolves the target hostname to IP addresses
2. Checks each IP against a reserved/private IP range list using `isReservedIP`
3. Blocks any connection to reserved addresses (loopback, RFC-1918 private ranges, link-local, IPv6 equivalents)

This dial function is configured on the `safeClient`'s Transport at `internal/webhook/webhook.go:34-36`. The reserved IP ranges and blocking logic are defined in `internal/webhook/validate.go:11-54`.

**Delivery function** — `internal/webhook/webhook.go:119` (Post function)  
**Protection mechanism** — `internal/webhook/webhook.go:57-77` (safeDialContext function with isReservedIP checks)
