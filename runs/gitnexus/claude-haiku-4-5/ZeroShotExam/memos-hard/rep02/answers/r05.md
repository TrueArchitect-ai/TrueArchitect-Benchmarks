**Premise correction:** The repository does not use GraphQL for its public API schema. Instead, it uses **Protocol Buffers (protobuf)** with gRPC and REST HTTP bindings.

**Actual API surface:** The public API schema is defined in protobuf files located in `/bench/home/work/proto/api/v1/`. The main service definitions include:

- `proto/api/v1/memo_service.proto` — Memo CRUD operations, comments, reactions, shares, and link metadata
- `proto/api/v1/user_service.proto` — User management
- `proto/api/v1/attachment_service.proto` — Attachment operations
- `proto/api/v1/auth_service.proto` — Authentication
- `proto/api/v1/instance_service.proto` — Instance configuration
- `proto/api/v1/ai_service.proto` — AI integrations
- `proto/api/v1/idp_service.proto` — Identity provider management
- `proto/api/v1/shortcut_service.proto` — Shortcut management
- `proto/api/v1/common.proto` — Shared message types

The proto files define RPC services with `google.api.http` annotations that map to REST endpoints (e.g., `POST /api/v1/memos`, `GET /api/v1/memos`). The generated OpenAPI spec is stored in `proto/gen/openapi.yaml`.
