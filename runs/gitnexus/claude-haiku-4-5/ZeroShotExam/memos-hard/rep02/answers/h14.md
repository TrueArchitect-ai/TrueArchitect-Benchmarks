**Computation site:** `internal/markdown/markdown.go` — the `Service` interface provides `ExtractAll()`, `ExtractTags()`, and `ExtractProperties()` methods that parse markdown using goldmark and extract metadata. The concrete implementation walks the AST to derive properties.

**Triggers:** Metadata is recomputed in two scenarios:
1. **On memo creation:** `server/router/api/v1/memo_service.go` calls `memopayload.RebuildMemoPayload()` when `CreateMemo` is invoked
2. **On memo update (content field):** `server/router/api/v1/memo_service.go` calls `memopayload.RebuildMemoPayload()` when the content is updated in `UpdateMemo`
3. **Batch rebuild:** `server/runner/memopayload/runner.go` provides `RunOnce()` to rebuild payloads for all memos in batches

**Extracted properties** (stored in `storepb.MemoPayload_Property`):
- `Title`: text extracted from the first H1 heading if present
- `HasLink`: boolean, true if markdown contains any links
- `HasCode`: boolean, true if markdown contains code blocks or inline code spans
- `HasTaskList`: boolean, true if markdown contains task list checkboxes
- `HasIncompleteTasks`: boolean, true if markdown contains unchecked task items

Additionally, `ExtractAll()` also extracts:
- `Tags`: all `#tags` found in content (deduplicated while preserving case)
- `Mentions`: all `@mentions` found in content (deduplicated, lowercased)
