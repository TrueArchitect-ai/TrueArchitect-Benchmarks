- **`/bench/home/work/proto/api/v1/`** — Contains the service definitions:
  - `memo_service.proto` — Memo operations
  - `user_service.proto` — User operations
  - `attachment_service.proto` — Attachment operations
  - `auth_service.proto` — Authentication operations
  - `ai_service.proto` — AI/transcription operations
  - `idp_service.proto` — IDP operations
  - `instance_service.proto` — Instance operations
  - `shortcut_service.proto` — Shortcut operations
  - `common.proto` — Common types

An **OpenAPI 3.0.3 schema** is generated from these protobuf definitions and is available at:
- **`/bench/home/work/proto/gen/openapi.yaml`** — Auto-generated OpenAPI/Swagger documentation from protobuf

The API uses **gRPC** (with HTTP transcoding via `google.api.http` annotations in the protobuf files), not GraphQL.
