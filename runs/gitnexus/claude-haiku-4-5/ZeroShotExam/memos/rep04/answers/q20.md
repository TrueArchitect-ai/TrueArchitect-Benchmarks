**Server-Sent Events (SSE); server/router/api/v1/sse_hub.go; CreateMemo, DeleteMemo, CreateMemoComment, dispatchMemoUpdatedSideEffects, UpsertMemoReaction, DeleteMemoReaction**

The mechanism is **Server-Sent Events (SSE)**, which allows the server to push live events to connected browsers. The hub is implemented in `server/router/api/v1/sse_hub.go` as the `SSEHub` struct (lines 55-59), which manages client connections via a `Broadcast()` method that sends events to all subscribed clients with visibility filtering.

The memo handlers that broadcast through it are:
- `CreateMemo` (server/router/api/v1/memo_service.go)
- `DeleteMemo` (server/router/api/v1/memo_service.go)
- `CreateMemoComment` (server/router/api/v1/memo_service_comments.go)
- `dispatchMemoUpdatedSideEffects` (server/router/api/v1/memo_update_helpers.go)
- `UpsertMemoReaction` (server/router/api/v1/reaction_service.go)
- `DeleteMemoReaction` (server/router/api/v1/reaction_service.go)
