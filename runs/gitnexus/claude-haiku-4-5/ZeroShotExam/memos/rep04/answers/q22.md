When a memo is created, user webhooks are notified through the following:

1. **Dispatcher function and file**: `DispatchMemoCreatedWebhook()` — `server/router/api/v1/memo_service_webhooks.go` (called from the `CreateMemo` handler at line 157 of `server/router/api/v1/memo_service.go`)

2. **Delivery package**: `net/http` (Go's standard library; `safeClient` is a custom `*http.Client` at `internal/webhook/webhook.go:32-37`, which wraps the standard HTTP client with SSRF protection via a custom `DialContext`)

3. **Request-signing mechanism**: HMAC-SHA256 using the Standard Webhooks specification format, implemented in `internal/webhook/webhook.go:119-180`. The signature is generated as:
   - Generate a message ID (`msg_<UUID>`)
   - Get current Unix timestamp
   - Create HMAC-SHA256 signature of `msgID.timestamp.` + body
   - Set headers: `webhook-id`, `webhook-timestamp`, and `webhook-signature` (format: `v1,<base64-encoded-signature>`)
   - Secrets using the `whsec_` prefix are base64-decoded; others are used as-is
