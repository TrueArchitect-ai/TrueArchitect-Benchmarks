The three implementations of the database driver interface are:

1. **store/db/sqlite/sqlite.go** — `DB` struct with `NewDB()` factory function
2. **store/db/mysql/mysql.go** — `DB` struct with `NewDB()` factory function  
3. **store/db/postgres/postgres.go** — `DB` struct with `NewDB()` factory function

The factory function that selects between them at startup:

**NewDBDriver** — **store/db/db.go**

The `NewDBDriver` function (lines 14–32 in store/db/db.go) switches on `profile.Driver` to instantiate the appropriate driver (`sqlite.NewDB`, `mysql.NewDB`, or `postgres.NewDB`).
