q25.

**Engine:** CEL (Common Expression Language) via `github.com/google/cel-go/cel`

**Path:** `internal/filter/engine.go` (lines 9, 25, 53)

**Mechanism:** The filter string is compiled by the CEL environment (`cel.NewEnv()` with schema-provided options), which parses the expression into an AST. This AST is converted to a `ParsedExpr` via `cel.AstToParsedExpr()`, then transformed into a dialect-agnostic condition tree by `buildCondition()` in `internal/filter/parser.go`. The `Program.Render()` method then converts the condition tree to SQL by instantiating a `renderer` (in `internal/filter/render.go`) that dispatches to dialect-specific SQL generation based on `DialectName` (SQLite, Postgres, MySQL), with per-dialect timestamp accessor expressions, JSON extraction functions, and operator translations handled in `render.go` lines 176-299.
