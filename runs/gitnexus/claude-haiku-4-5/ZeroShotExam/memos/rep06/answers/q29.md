The frontend API auth interceptor is located at **web/src/connect.ts** (lines 156–178, the `authInterceptor` constant).

**Token kinds managed:**
- **Access Token V2** (short-lived JWT, 15 minutes) — used via Bearer token in Authorization header
- **Refresh Token** (long-lived JWT, 30 days) — sent as HTTP-only cookie and exchanged to get new access tokens

The interceptor also supports **Personal Access Tokens (PAT)** for programmatic access, though frontend management is primarily via access tokens.

**Backend validation package:** **server/auth** — specifically:
- `server/auth/authenticator.go`: `Authenticator` struct with methods `AuthenticateByAccessTokenV2()`, `AuthenticateByRefreshToken()`, and `AuthenticateByPAT()`
- `server/auth/token.go`: token generation and parsing functions (`ParseAccessTokenV2()`, `ParseRefreshToken()`, etc.)
