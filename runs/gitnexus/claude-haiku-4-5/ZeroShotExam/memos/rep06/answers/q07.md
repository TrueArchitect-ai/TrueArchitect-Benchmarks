**web/src/connect.ts**

This is the frontend source file where ConnectRPC service clients are created. The file exports eight service clients (instanceServiceClient, authServiceClient, userServiceClient, memoServiceClient, attachmentServiceClient, aiServiceClient, shortcutServiceClient, and identityProviderServiceClient), all instantiated using the `createClient` function from `@connectrpc/connect` with a configured transport that includes auth interceptors.
