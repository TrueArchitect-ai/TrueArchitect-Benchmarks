**Engine + Path:** CEL (Common Expression Language) via `github.com/google/cel-go/cel` — engine lives in `internal/filter/engine.go:Engine`

**Mechanism:** The CEL environment compiles the filter string into an AST, which is converted to a ParsedExpr and then walked into a dialect-agnostic condition tree (via `parser.go:buildCondition` consuming `google.golang.org/genproto/googleapis/api/expr/v1alpha1` protobuf expressions), and finally rendered into dialect-specific SQL using a per-dialect renderer (`render.go:renderer`) that dispatches condition types (LogicalCondition, ComparisonCondition, TextMatchCondition, etc.) and emits appropriate SQL with placeholder-based argument binding per dialect (PostgreSQL `$1/$2`, SQLite/MySQL `?`).
