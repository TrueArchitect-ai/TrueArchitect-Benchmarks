**web/src/connect.ts**

This is the frontend source file where ConnectRPC service clients are created. The file uses `createClient` from `@connectrpc/connect` to instantiate service clients (lines 192-203), including:
- Core service clients: `instanceServiceClient`, `authServiceClient`, `userServiceClient`
- Content service clients: `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`
- Configuration service clients: `identityProviderServiceClient`

All clients are created with a shared `transport` that's configured with authentication interceptors and credentials.
