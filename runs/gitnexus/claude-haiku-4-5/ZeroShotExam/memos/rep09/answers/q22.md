The dispatch function for webhook notifications when a memo is created is **`DispatchMemoCreatedWebhook`** in **`server/router/api/v1/memo_service_webhooks.go`** (line 15). This function calls `dispatchMemoRelatedWebhook`, which retrieves the webhooks and calls **`webhook.PostAsync`** from the **`internal/webhook`** package.

The HTTP delivery is performed by the standard Go **`net/http`** package (used in the `Post` function in `internal/webhook/webhook.go`).

The request-signing mechanism is **HMAC-SHA256** with the Standard Webhooks format: it generates a message ID (`msg_` + UUID), uses the current Unix timestamp, and creates an HMAC-SHA256 signature over the concatenated string `msgID.timestamp.` plus the request body, then sends it as `webhook-signature` header with the format `v1,<base64-encoded-signature>` (see `webhook.go` lines 139-149).
