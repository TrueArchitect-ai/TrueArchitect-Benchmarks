**Mechanism:** Go's `embed` directive with Echo's `StaticWithConfig` middleware and SPA fallback middleware.

**Path:** `/bench/home/work/server/router/frontend/frontend.go`

The compiled React frontend (located in `dist/` directory) is embedded directly into the Go binary using the `//go:embed dist/*` directive (line 20), which creates an embedded filesystem. This is then served in production using Echo's static middleware (line 54) with a custom SPA fallback that routes unmatched paths to `index.html` for client-side routing (line 77).
