The ConnectRPC service clients are created in **`web/src/connect.ts`**.

This file is the central configuration file where all ConnectRPC service clients (`instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`) are instantiated using the `createClient` function from the `@connectrpc/connect` library.
