The memo lifecycle events that dispatch webhooks are:

- **created**: `DispatchMemoCreatedWebhook`
- **updated**: `DispatchMemoUpdatedWebhook`
- **deleted**: `DispatchMemoDeletedWebhook`

Additionally, there is:
- **comment.created**: `DispatchMemoCommentCreatedWebhook`

All webhook dispatches converge at `webhook.PostAsync()` (server/router/api/v1/memo_service_webhooks.go:71 and :43, server/internal/webhook/webhook.go:184), which enqueues the payload into a bounded async queue (`asyncPostQueue`, internal/webhook/webhook.go:39). Four goroutines (initialized in internal/webhook/webhook.go:42-55) consume from this queue and call `webhook.Post()` (internal/webhook/webhook.go:120) for actual HTTP delivery.
