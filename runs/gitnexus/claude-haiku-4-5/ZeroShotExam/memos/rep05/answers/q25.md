**Engine + Path:** CEL (Common Expression Language) from `google.golang.org/cel-go/cel`; parser engine lives in `internal/filter/engine.go`.

**Mechanism:** The Engine parses CEL filter strings into a dialect-agnostic condition tree via `buildCondition()` in `internal/filter/parser.go`, then the renderer (`internal/filter/render.go`) walks that tree and emits SQL for each dialect (SQLite, Postgres, MySQL) using `qualifyColumn()` and dialect-specific expressions (e.g., `EXTRACT()` for Postgres, `strftime()` for SQLite, `DATE_FORMAT()` for MySQL).
