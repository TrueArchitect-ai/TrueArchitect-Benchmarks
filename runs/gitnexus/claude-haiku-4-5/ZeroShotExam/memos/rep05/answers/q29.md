**Interceptor path:** `web/src/connect.ts` — the `authInterceptor` constant (lines 156-178)

**Token kinds managed:**
- Access Token V2 (short-lived JWT, ~15 minutes)
- Refresh Token (long-lived, stored in httpOnly cookie, used to refresh access tokens)
- Personal Access Token (PAT) (long-lived token for programmatic access)

**Backend package:** `server/auth/` (the Authenticator struct in `server/auth/authenticator.go`)

The frontend interceptor at `web/src/connect.ts:authInterceptor` sets the `Authorization: Bearer {token}` header (line 99) with an access token fetched via `getRequestToken()`. It handles token refresh on 401 responses by calling `refreshAccessToken()` which uses a refresh cookie. The backend `server/auth` package validates these tokens via the `Authenticator` struct methods: `AuthenticateByAccessTokenV2()` (stateless JWT validation), `AuthenticateByRefreshToken()` (validates refresh token + checks revocation in database), and `AuthenticateByPAT()` (validates personal access tokens).
