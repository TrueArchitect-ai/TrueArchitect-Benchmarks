**Mechanism**: Go embedded files served via Echo static middleware with SPA fallback

**Path**: `/bench/home/work/server/router/frontend/frontend.go`

The compiled React frontend (built by Vite into `/server/router/frontend/dist`) is embedded directly into the Go server binary using Go's `//go:embed` directive. It's then served through Echo's `StaticWithConfig()` middleware, which handles cache headers and falls back to `index.html` for non-existent routes to enable client-side routing. The frontend service is wired into the server startup in `/bench/home/work/server/server.go` (line 72).
