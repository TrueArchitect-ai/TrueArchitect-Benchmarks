**Convergence point for delivery:**

All dispatch functions call either `dispatchMemoRelatedWebhook()` (for created/updated/deleted) or directly use `webhook.PostAsync()` (for comment created). Both paths ultimately call `webhook.PostAsync()` (internal/webhook/webhook.go:184), which enqueues payloads to an async queue that is consumed by 4 worker goroutines initialized in `init()` (internal/webhook/webhook.go:42-55). The actual delivery happens via `webhook.Post()` (internal/webhook/webhook.go:120), which performs the HTTP POST with HMAC-SHA256 signing.
