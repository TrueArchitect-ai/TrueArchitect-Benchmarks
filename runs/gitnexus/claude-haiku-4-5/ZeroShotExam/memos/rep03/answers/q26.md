**q26.**

The tables affected when DeleteMemo runs are:

1. **memo** — directly deleted via store/db/sqlite/memo.go (and similar in postgres/mysql)
2. **memo_relation** — explicitly deleted via store/memo.go lines 142-146 (both as source and target)
3. **attachment** — explicitly deleted via store/memo.go lines 149-157 (for all attachments linked to the memo)

When deleting memo comments (which are also memos), the same tables are affected recursively for each comment memo.

The reaction table is NOT affected by DeleteMemo — reactions are listed in the code (line 545-550) for webhook purposes but are never explicitly deleted, leaving orphaned reaction records in the database.
