**Go embed directive; server/router/frontend/frontend.go**

The compiled React frontend is served in production using Go's `embed` package. At line 20-21 of `/bench/home/work/server/router/frontend/frontend.go`, the frontend build output is embedded directly into the Go binary:

```go
//go:embed dist/*
var embeddedFiles embed.FS
```

This embeds all files from the `dist/` directory (the Vite build output from the React app) into the binary. The `FrontendService.Serve()` method (line 41) then uses this embedded filesystem with Echo's `middleware.StaticWithConfig` to serve the static files and handle SPA routing with a fallback to `index.html` (line 77).
