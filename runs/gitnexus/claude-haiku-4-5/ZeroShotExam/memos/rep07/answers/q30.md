The memo lifecycle events that dispatch webhooks are:

**Events and Dispatch Functions:**
- memo.created: `DispatchMemoCreatedWebhook` (server/router/api/v1/memo_service_webhooks.go:15)
- memo.updated: `DispatchMemoUpdatedWebhook` (server/router/api/v1/memo_service_webhooks.go:20)
- memo.deleted: `DispatchMemoDeletedWebhook` (server/router/api/v1/memo_service_webhooks.go:25)
- memo.comment.created: `DispatchMemoCommentCreatedWebhook` (server/router/api/v1/memo_service_webhooks.go:30)

**Delivery Convergence:**

All webhook dispatches converge through two functions:

1. **`webhook.PostAsync()`** (internal/webhook/webhook.go:184) — enqueues payloads to an async queue for non-blocking dispatch
2. **`webhook.Post()`** (internal/webhook/webhook.go:120) — the actual delivery function that constructs HTTP POST requests with optional HMAC-SHA256 signing and sends them to the configured webhook URLs

The first three events route through `dispatchMemoRelatedWebhook()` helper, while the comment event has its own path, but all four converge at `webhook.PostAsync()` for delivery.
