**APIV1Service.SignIn** — `server/router/api/v1/auth_service.go`

This is the backend RPC handler that handles SignIn requests. It supports both password-based authentication and SSO/OAuth2 authentication, and returns a SignInResponse with user information, access token, and token expiry time.
