**web/src/connect.ts**

This file creates all ConnectRPC service clients using the `createClient` function from `@connectrpc/connect`. The clients are exported as constants (lines 192-203) for services like `InstanceService`, `AuthService`, `UserService`, `MemoService`, `AttachmentService`, `AIService`, `ShortcutService`, and `IdentityProviderService`. They all share a common `transport` object created with `createConnectTransport` (lines 184-189) that includes authentication interceptors.
