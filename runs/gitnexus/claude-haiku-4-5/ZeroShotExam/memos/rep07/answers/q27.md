q27. Go embed (go:embed directive); server/router/frontend/frontend.go

The compiled React frontend is served via Go's **embed** mechanism (`go:embed` directive), which embeds the frontend distribution files at compile time. The files in `/server/router/frontend/dist` are embedded using the `//go:embed dist/*` directive and served through the Echo web server via middleware and file system routing. The wiring is in **`server/router/frontend/frontend.go`** where `FrontendService.Serve()` registers the static file middleware and SPA fallback handler that serves the React app.
