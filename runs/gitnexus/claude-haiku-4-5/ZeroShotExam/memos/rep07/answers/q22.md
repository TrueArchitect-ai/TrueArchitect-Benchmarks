When a memo is created, user webhooks are notified as follows:

**Dispatcher — path:** `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:14-16`

**Delivery package:** `net/http` (via the `safeClient` HTTP client in `internal/webhook/webhook.go`)

**Signing mechanism:** HMAC-SHA256 with Standard Webhooks format (as implemented in `internal/webhook/webhook.go:133-150`). The signing includes a message ID (`msg_` prefixed UUID), Unix timestamp, and HMAC-SHA256 signature of the request body, sent as `webhook-id`, `webhook-timestamp`, and `webhook-signature` headers.
