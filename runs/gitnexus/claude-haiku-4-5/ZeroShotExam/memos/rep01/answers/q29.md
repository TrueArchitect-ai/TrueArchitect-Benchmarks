**Interceptor path:** `web/src/connect.ts:authInterceptor` (lines 156–178)

**Token kinds managed:**
1. **Access Token V2** — Short-lived JWT tokens (15 minutes) for API access
2. **Refresh Token** — Long-lived JWT token (30 days) stored in the `memos_refresh` cookie for obtaining new access tokens
3. **Personal Access Token (PAT)** — Long-lived tokens for programmatic access (prefix: `memos_pat_`)

**Backend validation package:** `server/auth` (specifically `server/auth/authenticator.go` and `server/auth/token.go`)

The interceptor adds tokens to requests via `Authorization: Bearer {token}` headers and handles token refresh on 401 responses. The backend package validates access tokens stateless via JWT signature verification (`ParseAccessTokenV2`), validates refresh tokens against the database for revocation, and validates PATs via SHA-256 hash lookup.
