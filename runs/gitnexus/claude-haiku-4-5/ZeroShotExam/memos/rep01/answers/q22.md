When a memo is created, user webhooks are notified through the following flow:

**Dispatcher function and file:** `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:14-16`

This function calls `dispatchMemoRelatedWebhook()` (same file), which retrieves user webhooks and dispatches them via `webhook.PostAsync()` (lines 61-71).

**HTTP delivery package:** `internal/webhook` package — specifically the `Post()` function (lines 120-180 in `internal/webhook/webhook.go`) which uses Go's standard `net/http` library with a custom `safeClient` that includes SSRF protection.

**Request-signing mechanism:** HMAC-SHA256 with Standard Webhooks format. The signing is implemented in the `Post()` function (lines 133-150):
- Secrets follow the "whsec_<base64>" Standard Webhooks format
- Each request includes three headers:
  - `webhook-id`: A unique message ID (`msg_` + UUID)
  - `webhook-timestamp`: Unix timestamp
  - `webhook-signature`: HMAC-SHA256 signature in format `v1,<base64-encoded-mac>`
