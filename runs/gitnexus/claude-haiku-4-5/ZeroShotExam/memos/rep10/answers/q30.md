**Delivery convergence:**

All webhooks converge at `PostAsync` (internal/webhook/webhook.go:184), which enqueues payloads to a bounded async queue (`asyncPostQueue`). The init function (internal/webhook/webhook.go:42-54) spawns 4 goroutines that consume from this queue and call `Post` (internal/webhook/webhook.go:120) for actual HTTP delivery. The `Post` function handles HMAC-SHA256 signing, constructs the HTTP request, validates response codes, and communicates with webhook endpoints.
