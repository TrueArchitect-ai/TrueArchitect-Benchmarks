When a memo is deleted through the API, the store layer deletes the following records before the memo row itself:

1. **memo_relation** records (as the source - where the memo is the source of a relation)
2. **memo_relation** records (as the target - where the memo is the related/target memo)
3. **attachments** linked to the memo

The flow is:
1. Delete memo relations where this memo is the source (`MemoID`)
2. Delete memo relations where this memo is the target (`RelatedMemoID`)
3. Delete all attachments associated with this memo
4. Finally, delete the memo row itself
