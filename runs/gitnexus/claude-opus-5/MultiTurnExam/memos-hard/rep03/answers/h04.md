**No — `mysql.NewDB` is called from exactly one place, the factory `NewDBDriver` in `store/db/db.go:22`.**

Evidence:

1. **Constructor call sites.** Grepping `NewDB(` across all non-generated Go files, the only reference to the MySQL package's constructor is `driver, err = mysql.NewDB(profile)` at `store/db/db.go:22`, inside the `switch profile.Driver` in `NewDBDriver` (`store/db/db.go:14-32`). By contrast, `sqlite.NewDB` *does* have direct callers outside the factory — `store/deployment_config_test.go:416` and `store/demo_seed_test.go:24` — so the grep is demonstrably capable of finding out-of-factory construction; it just finds none for MySQL.

2. **Package imports.** `github.com/usememos/memos/store/db/mysql` is imported by exactly one file: `store/db/db.go:8`. Nothing else in the repo imports it.

3. **The apparent counterexample isn't one.** `store/test/containers.go` contains `mysql.Run(...)`, `mysql.WithDatabase(...)` etc. (lines 101-105), but its import block (`store/test/containers.go:20`) resolves `mysql` to `github.com/testcontainers/testcontainers-go/modules/mysql` — the Docker testcontainer module, not the memos driver. The raw SQL driver is imported there separately as `mysqldriver "github.com/go-sql-driver/mysql"` (`containers.go:16`).

4. **Tests go through the factory too.** MySQL-backed store tests select the driver by name string (`store/test/main_test.go:25` iterates `{"sqlite", "mysql", "postgres"}`; `store/test/store.go:88` switches on `"mysql"` only to build a DSN) and then call `db.NewDBDriver(profile)` at `store/test/store.go:28` and `:50`. Likewise the benchmark at `server/router/api/v1/test/memo_service_benchmark_test.go:70`.

One nuance worth stating, since it's construction of the driver struct rather than a call to its constructor: `store/db/mysql/auth_config_test.go:12` does `db := &DB{}` — a zero-valued struct built in-package purely to invoke a pure method under test, with no connection, profile, or config. That's an in-package unit-test fixture, not the driver being wired up outside the factory.
