**Premise correction: this project has no GraphQL. There is no schema file, no resolver layer, and no GraphQL library.** `find . -name "*.graphql"` returns nothing outside `node_modules`, and a case-insensitive search for `graphql|gqlgen` across Go, TypeScript, `go.mod`, and `package.json` returns zero hits. Nothing to point at.

**Actual API surface — Protobuf/gRPC definitions served over Connect and gRPC-Gateway:**

- **Schema definitions** live in `proto/api/v1/` as `.proto` files, one per service: `instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus `common.proto`. Internal persistence messages are in `proto/store/`. Codegen is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`) into `proto/gen/`.
- **Eight services are registered**, via `apiv1connect.New*ServiceHandler` calls in `server/router/api/v1/connect_handler.go:37-44`, mounted onto a `http.ServeMux` at `:48`.
- **Two transports expose the same services.** Connect/gRPC-style RPCs are mounted at the protobuf package path `/memos.api.v1.*` (`server/router/api/v1/v1.go:144`), with interceptors for metadata, logging, recovery, and auth (`:133-137`). A gRPC-Gateway REST/JSON translation is mounted at `/api/v1/*` and `/file/*` (`server/router/api/v1/v1.go:126-129`). Both cap request bodies at `maxAPIRequestBytes` = 256 MiB (`server/router/api/v1/v1.go:20`).
- **REST documentation** is a generated OpenAPI spec, embedded at `proto/openapi_embed.go` (`//go:embed gen/openapi.yaml`) — that file is the closest analogue to "the schema for the public API" in the sense the question intends.
- **Two non-Connect HTTP surfaces** exist alongside it: the raw file server at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), and RSS feeds (`server/router/rss/rss.go`). There is also an MCP tool surface under `server/router/mcp/` that adapts the same API (`server/router/mcp/openapi.go`, `catalog.go`).
