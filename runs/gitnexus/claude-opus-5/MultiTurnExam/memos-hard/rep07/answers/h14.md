**Computation site: `memopayload.RebuildMemoPayload` — `server/runner/memopayload/runner.go:74`, delegating the parse to `(*markdown.service).ExtractAll` — `internal/markdown/markdown.go:356`. Triggers: memo create and memo content-update. Extracted: tags + five boolean/string content properties.**

**Where it's computed.** `RebuildMemoPayload` initializes `memo.Payload` if nil, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (`server/runner/memopayload/runner.go:74-88`). The real work is a single goldmark AST walk in `ExtractAll` (`internal/markdown/markdown.go:356-421`). The result is persisted in the memo's `payload` column — the SQLite INSERT marshals it with protojson at `store/db/sqlite/memo.go:19-27`.

**Triggers** (all non-test callers of `RebuildMemoPayload`):
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before the row is written.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, but *only* inside the `content` branch of the field-mask loop; the recomputed payload is then attached to the update at `:451`. Updating `visibility`, pinned state, etc. does not recompute.
- `CreateMemoComment` inherits the create path — it calls `s.CreateMemo(...)` at `server/router/api/v1/memo_service_comments.go:56`.
- `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:52`) would rebuild every memo in batches of 100, but it is dead code: `NewRunner` has no callers and the runner is not wired into `startBackgroundRunners`.

**What's extracted** — into `storepb.MemoPayload` (`proto/store/memo.proto:15-22`):
- **`Tags`** — every `#tag` node, deduplicated with original case preserved via `uniquePreserveCase` (`internal/markdown/markdown.go:417`).
- **`Property.Title`** — text of the first H1 heading, only if it is the document's first block-level child (`markdown.go:383-389`).
- **`Property.HasLink`** — any `KindLink` node.
- **`Property.HasCode`** — any code block, fenced code block, or code span.
- **`Property.HasTaskList`** — any task checkbox.
- **`Property.HasIncompleteTasks`** — a task checkbox that is unchecked (`markdown.go:400-404`).

One clarification, since "used for lists/previews" could point at two different things: `ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` discards that field — mentions are used elsewhere for notifications, not stored on the payload. And the memo **snippet** shown in list views is *not* part of this stored payload; it is derived on read by `getMemoContentSnippet` during conversion (`server/router/api/v1/memo_service_converter.go:76-80`, and the batch path at `:225`/`:248`), backed by `GenerateSnippet` (`internal/markdown/markdown.go:264`). Both `tags`/`property` and `snippet` are declared `OUTPUT_ONLY` in `proto/api/v1/memo_service.proto:241`, `:256`, `:266` — user-supplied values are ignored.
