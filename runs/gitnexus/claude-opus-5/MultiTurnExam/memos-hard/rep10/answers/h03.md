h03.

**`internal/idp` (abstraction); `internal/idp/oauth2` (implementation — OAuth 2.0, the only concrete provider that ships).**

Details:

- **Abstraction**: `internal/idp/idp.go` is the shared package — it defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every implementation normalizes into. Note it's a data contract rather than a Go `interface`; there is no `IdentityProvider` interface type in this package.
- **Implementation**: `internal/idp/oauth2/oauth2.go` — package comment reads "implements the OAuth2 identity provider integration." It provides `NewIdentityProvider(*storepb.OAuth2Config)` (validates required fields: `clientId`, `clientSecret`, `tokenUrl`, `userInfoUrl`, `fieldMapping.identifier`), `ExchangeToken` (authorization-code exchange with optional PKCE `code_verifier`, via `golang.org/x/oauth2`), and `UserInfo` (bearer GET against `userInfoUrl`, mapping claims through the configured field mapping).
- **Only one provider ships**: the store enum has just `TYPE_UNSPECIFIED` and `OAUTH2` (`proto/gen/store/idp.pb.go:27-28`), and the sole consumer imports only these two packages — `server/router/api/v1/auth_service_sso.go:12-13`. OIDC/Google/GitHub etc. are configured as OAuth2 providers rather than separate implementations.
