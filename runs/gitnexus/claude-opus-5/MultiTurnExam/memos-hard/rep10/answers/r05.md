**Premise correction: there is no GraphQL in this repository. The public API is defined by Protocol Buffers and served as gRPC / Connect / REST-via-gateway.**

Verification: zero hits for `graphql` (case-insensitive) across `.go`, `.ts`, `.tsx`, `.json`, and `.md` files; no `.graphql`/`.gql` schema files anywhere; no GraphQL dependency in `go.mod`. There is no resolver layer, schema-stitching, or GraphQL endpoint.

**The actual API surface — protobuf service definitions in `proto/api/v1/`:**

- `instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, plus shared types in `common.proto`. Build config: `proto/buf.yaml`, `proto/buf.gen.yaml`.
- Generated Go lands in `proto/gen/api/v1/` — message/gRPC stubs (`*.pb.go`, `*_grpc.pb.go`), REST gateway stubs (`*.pb.gw.go`), and Connect handlers (`proto/gen/api/v1/apiv1connect/*.connect.go`).

**How it's exposed at runtime** (all in `APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65`):

1. **Connect/gRPC** — `ConnectServiceHandler.RegisterConnectHandlers` (`server/router/api/v1/connect_handler.go:31`) mounts the eight services (`:37-44`), registered at `server/router/api/v1/v1.go:141` with a request-size cap.
2. **REST/JSON** — grpc-gateway `runtime.NewServeMux` at `server/router/api/v1/v1.go:96`, using the generated `*.pb.gw.go` handlers, with auth applied by the gateway middleware at `:69-93`.
3. **Implementations** — the hand-written handlers on `APIV1Service` in `server/router/api/v1/` (`memo_service.go`, `user_service.go`, etc.).

**The closest thing to a queryable schema document** is the generated OpenAPI spec: `proto/gen/openapi.yaml`, embedded via `//go:embed` in `proto/openapi_embed.go` and exposed through `proto.OpenAPIYAML()`. It's consumed at runtime by the MCP service (`server/router/mcp/service.go:78`) to build its tool catalog.

Also worth noting, since they're sometimes conflated with a GraphQL layer: there are non-protobuf HTTP surfaces too — file serving under `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS feeds (`server/router/rss/rss.go`), and the sitemap (`server/router/frontend/frontend.go:143`).
