**Premise correction: there is no GraphQL in this repository.** Searching all `.go`, `.mod`, `.ts`/`.tsx`, `.json`, and any `.graphql`/`.gql` files (excluding `node_modules`) for `graphql` returns zero hits — no schema file, no server library, no client. There is nothing to point at.

**The actual public API surface is Protocol Buffers / gRPC, exposed over HTTP three ways.**

**Schema definition** — `proto/api/v1/`, nine `.proto` files: `ai_service.proto`, `attachment_service.proto`, `auth_service.proto`, `common.proto`, `idp_service.proto`, `instance_service.proto`, `memo_service.proto`, `shortcut_service.proto`, `user_service.proto`. Persistence-layer messages live separately in `proto/store/`. Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`.

**The three runtime surfaces**, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):

1. **REST/JSON via gRPC-Gateway** — services registered onto a `runtime.NewServeMux` (`v1.go:95-110`), mounted at `gwGroup.Any("/api/v1/*", handler)` and `/file/*` (`v1.go:128-129`), wrapped in `http.MaxBytesHandler` with `maxAPIRequestBytes`. Auth runs in `gatewayAuthMiddleware` (`v1.go:69`), which delegates to the shared `Authorizer`.
2. **Connect RPC** — for browser clients, replacing grpc-web. Handlers registered at `v1.go:139-141` with four interceptors (metadata, logging, recovery, auth) and mounted at `connectGroup.Any("/memos.api.v1.*", …)` (`v1.go:144`). Generated stubs are in `proto/gen/api/v1/apiv1connect/`.
3. **Server-Sent Events** — `RegisterSSERoutes(gwGroup, s.SSEHub, …)` at `v1.go:125`, for live memo updates.

**The generated API description is OpenAPI, not a GraphQL SDL** — `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` in `proto/openapi_embed.go` and exposed through `proto.OpenAPIYAML()`. Its one consumer is the MCP service, which parses it to build a tool catalog (`server/router/mcp/service.go:78`, schema types in `server/router/mcp/openapi.go`).

Non-RPC HTTP surfaces registered alongside, in `server/server.go`: the file server (`:82`), RSS feeds (`:85`), MCP (`:96`), and the frontend/SPA handler.
