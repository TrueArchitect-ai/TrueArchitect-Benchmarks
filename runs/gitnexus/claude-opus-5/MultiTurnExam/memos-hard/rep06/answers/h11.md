**1st: `store.User` (~7 packages, 5 of them non-test); 2nd: `store.Memo` (~6 packages, 4 non-test)**

Method: for each persistent entity struct declared in `store/*.go` (`Attachment`, `IdentityProvider`, `Inbox`, `InstanceSetting`, `Memo`, `MemoRelation`, `MemoShare`, `Reaction`, `User`, `UserIdentity`, `UserSetting`), I counted distinct directories outside the data layer — excluding `store/`, `store/db/*`, `store/test/`, and generated `proto/` — that contain a `store.<Type>` reference.

Full ranking (packages incl. test packages / non-test only):

| Type | Pkgs | Non-test | Packages |
|---|---|---|---|
| `store.User` | 7 | 5 | `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` (+ `server/router/frontend`, `server/router/api/v1/test` — test-only) |
| `store.Memo` | 6 | 4 | `server/notification`, `server/router/api/v1`, `server/router/rss`, `server/runner/memopayload` (+ `server/router/frontend`, `server/router/api/v1/test`) |
| `store.Attachment` | 4 | 3 | `server/router/api/v1`, `server/router/fileserver`, `server/router/rss` |
| `store.MemoShare` | 3 | 2 | `server/router/api/v1`, `server/router/fileserver` |
| `store.MemoRelation` | 3 | 2 | `server/router/api/v1`, `server/router/rss` |
| `store.Inbox` | 3 | 2 | `server/notification`, `server/router/api/v1` |
| `store.Reaction`, `store.UserIdentity` | 2 | 1 | `server/router/api/v1` |
| `store.UserSetting`, `store.InstanceSetting`, `store.IdentityProvider` | 0 | 0 | — (consumers use the protobuf `storepb` forms instead) |

The ordering holds under either counting rule. `store.User` is the only entity reaching the auth layer (`server/auth/authenticator.go`, `server/auth/context.go`) and the file server (`server/router/fileserver/fileserver.go`), which is what puts it ahead. `store.Memo` is denser *within* `server/router/api/v1` (15+ files) but spreads across fewer packages; its one distinctive reach outside the API package is `server/runner/memopayload/runner.go`.

Caveat: `server/router/frontend` counts for both types only via `server/router/frontend/frontend_test.go:183,190,198`, and `server/router/api/v1/test` is a test-helper package — hence the two figures per row.
