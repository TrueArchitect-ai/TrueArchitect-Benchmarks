**Premise correction: there is no GraphQL in this repository.** Searching all Go, TypeScript, and JSON sources for `graphql`, `gqlgen`, `.graphql`, and `.gql` returns zero hits; no `*.graphql`/`*.gql` schema files exist; and neither `go.mod` nor `web/package.json` declares any GraphQL dependency. There is no schema, resolver layer, or `/graphql` endpoint to point to.

**Actual API surface: Protocol Buffers → gRPC, exposed over HTTP three ways.**

**Schema definition** — nine `.proto` files under `proto/api/v1/`:
`instance_service.proto`, `auth_service.proto`, `user_service.proto`, `memo_service.proto`, `attachment_service.proto`, `ai_service.proto`, `shortcut_service.proto`, `idp_service.proto`, and shared `common.proto`. Storage-layer messages live separately in `proto/store/` (e.g. `proto/store/memo.proto`). Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/`.

**Three transports, all registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65`):**

1. **REST via gRPC-Gateway** — a `runtime.NewServeMux` (`v1.go:96`) with all eight services registered (`v1.go:99-122`), mounted on `/api/v1/*` and `/file/*` (`v1.go:128-129`), wrapped in `http.MaxBytesHandler(..., maxAPIRequestBytes)`. HTTP-path annotations come from the `google.api.http` options in the protos.
2. **Connect protocol** — for browser clients, replacing grpc-web (`v1.go:131-144`), served under `/memos.api.v1.*` with interceptors for metadata, logging, recovery, and auth.
3. **SSE** — `RegisterSSERoutes` (`v1.go:125`) for live refresh events, sharing the API's CORS group.

**Generated API documentation** is OpenAPI, not a GraphQL introspection schema: `proto/gen/openapi.yaml`, embedded into the binary via `//go:embed` at `proto/openapi_embed.go:4-5`.

Two adjacent HTTP surfaces sit outside this stack: the plain-Echo file server at `/file/attachments/...` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:121-125`), and the MCP endpoint (`server/router/mcp/service.go:107`), which allowlists a subset of the same RPC methods (`server/router/mcp/catalog.go`).
