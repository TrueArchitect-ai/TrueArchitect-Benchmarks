**Premise correction: there is no GraphQL in this repository.** A case-insensitive grep for `graphql`, `gqlgen`, `.graphql`, and `apollo` across all Go, TypeScript, and manifest files (excluding `node_modules`) returns zero matches. No schema file, no resolver layer, no client library.

**Actual API surface: Protocol Buffers / gRPC, exposed over three transports.**

**Schema definition — `proto/api/v1/`,** nine `.proto` files, one service each:
- `memo_service.proto` (`service MemoService` at `:17`, with `CreateMemo`, `ListMemos`, `GetMemo`, `UpdateMemo`, `DeleteMemo`, comments, reactions, relations, attachments…)
- `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`

A parallel `proto/store/` tree defines the persistence-layer messages (e.g. `MemoPayload` in `proto/store/memo.proto`), which are not part of the public API.

**Code generation — buf, configured at `proto/buf.gen.yaml`.** Five server-side plugins emit into `proto/gen/`: protobuf Go types, gRPC stubs, **Connect** handlers, **grpc-gateway** (REST/JSON transcoding), and **gnostic-openapi** (an OpenAPI document). A sixth plugin, `bufbuild/es`, generates TypeScript clients directly into `web/src/types/proto`, which is how the frontend talks to the backend.

**Runtime transports** — all three are wired in `server/router/api/v1/v1.go`:
1. **REST/JSON** via grpc-gateway, mounted at `/api/v1/*` (`v1.go:128`) — the closest thing to a conventional public HTTP API; paths come from the `google.api.http` annotations in each `.proto`.
2. **Connect RPC** at `/memos.api.v1.*` (`v1.go:144`), used by the browser client.
3. **Plain HTTP file routes** outside the proto surface: `/file/attachments/:uid/:filename` and `/file/users/:identifier/avatar` (`server/router/fileserver/fileserver.go:123-124`), plus RSS (`server/router/rss/`) and an MCP endpoint (`server/router/mcp/`).

If you're after a browsable schema document, the generated OpenAPI spec is the analogue of what you'd want from GraphQL introspection — produced by the gnostic-openapi plugin into `proto/gen/` and embedded via `proto/openapi_embed.go`.
