The URL the browser requests is minted server-side: `convertUserToProto` rewrites a base64 avatar into `/file/{userpb.Name}/avatar` (i.e. `/file/users/{username}/avatar`) at `server/router/api/v1/user_service_converters.go:36`. That request then travels:

**Route registration — `FileServerService.RegisterRoutes` — `server/router/fileserver/fileserver.go:121` (registers `GET /file/users/:identifier/avatar` at `:124`; wired at `server/server.go:81-82`)**

Hops from handler to stored data:

- `FileServerService.serveUserAvatar` — `server/router/fileserver/fileserver.go:168`
- `FileServerService.getUserByUsername` — `server/router/fileserver/fileserver.go:715`
- `Store.GetUser` — `store/user.go:148`
- `Store.ListUsers` — `store/user.go:136`
- `DB.ListUsers` (driver, e.g. SQLite) — `store/db/sqlite/user.go:88` — issues `SELECT ... avatar_url ... FROM user WHERE username = ?` (`store/db/sqlite/user.go:151-172`) and scans into `store.User.AvatarURL` (`:187`). Parallel implementations: `store/db/postgres/user.go`, `store/db/mysql/user.go`.

What the handler does on the way back down:

1. **Anonymous gate.** If `s.Profile.AllowAnonymous()` is false (private instance, no `InstanceURL`), it resolves the viewer via `getCurrentUser` and 401s if there is none (`fileserver.go:173-181`). On an open instance, avatars are served anonymously.
2. **Lookup** by the `:identifier` path param, 404 if the user or their `AvatarURL` is missing (`fileserver.go:183-194`).
3. **Decode.** The avatar is not a separate blob row — it's stored inline on the `user.avatar_url` column as a data URI, which `parseDataURI` splits into MIME type and bytes (`fileserver.go:196`).
4. **MIME allowlist.** `avatarAllowedTypes` (`fileserver.go:75`) rejects anything outside the safe image set, then security + cache headers are set and the bytes are written with `c.Blob` (`fileserver.go:201-209`).

One note: `acl_config.go:25` lists a public method `/memos.api.v1.UserService/GetUserAvatar`, but no such RPC exists anywhere in the repo or protos — it's a stale ACL entry, not a second serving path.
