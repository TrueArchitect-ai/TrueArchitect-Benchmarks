**Premise correction: there is no GraphQL in this project.** A case-insensitive search for `graphql|gqlgen|apollo|.graphql` across all Go, TypeScript, JSON, and module files (excluding `node_modules`) returns zero hits. No schema file, no resolvers, no GraphQL dependency.

## The actual API surface: Protocol Buffers → Connect + gRPC-Gateway REST

The schema of record is **protobuf**, under `proto/api/v1/`:

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | memos, comments, reactions, attachments-on-memos |
| `proto/api/v1/user_service.proto` | users, settings, webhooks, stats |
| `proto/api/v1/auth_service.proto` | sign-in/out, sessions, SSO |
| `proto/api/v1/attachment_service.proto` | attachments |
| `proto/api/v1/instance_service.proto` | instance profile/settings/stats |
| `proto/api/v1/idp_service.proto` | identity providers |
| `proto/api/v1/shortcut_service.proto` | shortcuts |
| `proto/api/v1/ai_service.proto` | AI features |
| `proto/api/v1/common.proto` | shared types |

Codegen is driven by buf (`proto/buf.gen.yaml`, `proto/buf.yaml`) into `proto/gen/api/v1/` (Go types) and `proto/gen/store/` (persistence messages).

**Three wire protocols, one implementation.** All handlers live on `APIV1Service` in `server/router/api/v1/`, exposed through `RegisterGateway` (`server/router/api/v1/v1.go:65`):

1. **Connect RPC** — `NewConnectServiceHandler(s)` mounts a `http.ServeMux` (`v1.go:139-141`) routed via Echo at the path prefix `/memos.api.v1.*` (`v1.go:144`). The handler methods are thin wrappers that delegate to the gRPC implementation and translate errors — see `server/router/api/v1/connect_services.go` (e.g. `GetInstanceProfile` at `:18`).
2. **REST via gRPC-Gateway** — a `runtime.ServeMux` with auth middleware (`v1.go:69-93`), giving conventional HTTP+JSON routes generated from the `google.api.http` annotations in the `.proto` files.
3. **Non-RPC HTTP routers** alongside them: the file server (`server/router/fileserver/fileserver.go:121`), RSS feeds (`server/router/rss/rss.go`), and the frontend/SPA router (`server/router/frontend/frontend.go`).

**The closest thing to a published schema document** is OpenAPI, not GraphQL: `proto/gen/openapi.yaml`, generated from the protos and embedded into the binary via `//go:embed` in `proto/openapi_embed.go:4-5`, exposed through `proto.OpenAPIYAML()`.

Interceptors — metadata, logging, recovery, and auth — are applied at `v1.go:133-137` from `server/router/api/v1/connect_interceptors.go`. So if you're looking for "where the public API is defined," the answer is the `.proto` files; if you're looking for the served contract, it's `proto/gen/openapi.yaml`.
