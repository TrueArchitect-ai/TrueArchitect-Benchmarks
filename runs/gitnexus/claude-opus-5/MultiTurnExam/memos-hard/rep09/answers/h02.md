## Where delivery executes

Memo change events call `webhook.PostAsync` (`server/router/api/v1/memo_service_webhooks.go:43` and `:71`), which only enqueues onto a bounded 128-slot channel (`internal/webhook/webhook.go:39`, `:184-196`) and drops the event with a warning when full. Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`, which is where the actual outbound HTTP happens:

- builds the JSON POST (`webhook.go:121-131`)
- optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook.go:133-150`)
- issues the request via `safeClient.Do(req)` — `internal/webhook/webhook.go:152`

## What protects it

Two layers, and only the first is on the delivery path:

1. **Dial-time SSRF guard (the real protection).** `safeClient` (`webhook.go:32-37`) uses a custom `Transport.DialContext = safeDialContext`. `safeDialContext` (`webhook.go:59-77`) resolves the hostname itself, rejects the connection if *any* resolved address is in a reserved range, and only then dials. Because the check happens at dial time rather than at save time, it also defeats DNS rebinding — the comment at `webhook.go:29-31` says so explicitly. Blocked ranges are in `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 blocks, link-local `169.254.0.0/16` (covers the cloud IMDS endpoint), plus IPv6 loopback, ULA, and link-local. They're parsed once at startup (`validate.go:28-36`) and matched by `isReservedIP` (`validate.go:44`).

2. **Registration-time validation.** `webhook.ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http/https schemes and hostnames resolving to reserved IPs when a webhook is created or updated — called at `server/router/api/v1/user_service_webhooks.go:74`, `:161`, and `:182`.

The response is also read through `io.LimitReader(resp.Body, 1<<20)` (`webhook.go:158`) and the client has a 30s timeout (`webhook.go:27`), bounding what a hostile endpoint can do.

One thing worth flagging: the escape hatch `webhook.AllowPrivateIPs` (`internal/webhook/validate.go:41`) short-circuits `isReservedIP` for self-hosted setups, but grepping the non-test Go sources shows nothing outside `validate.go` ever assigns it — there's no flag or env wiring, so it's currently always `false`.
