**Premise correction: there is no GraphQL in this repository.** A repo-wide search (Go, TypeScript, `go.mod`, and any `.graphql`/`.gql` files, excluding `node_modules` and lockfiles) for `graphql`, `gqlgen`, or `apollo` returns zero hits. There is no schema file, no resolver layer, and no `/graphql` endpoint.

**Actual API surface: Protocol Buffers / gRPC, exposed over HTTP three ways.**

**Schema definition** — `.proto` files under `proto/api/v1/`:

| file | service |
|---|---|
| `proto/api/v1/memo_service.proto` | memos, comments, relations, attachments |
| `proto/api/v1/user_service.proto` | users, settings, webhooks, access tokens |
| `proto/api/v1/auth_service.proto` | sessions, SSO |
| `proto/api/v1/attachment_service.proto` | attachments |
| `proto/api/v1/instance_service.proto` | instance settings/stats |
| `proto/api/v1/shortcut_service.proto` | shortcuts |
| `proto/api/v1/idp_service.proto` | identity providers |
| `proto/api/v1/ai_service.proto` | AI features |
| `proto/api/v1/common.proto` | shared types |

Plus internal persistence messages in `proto/store/`. Codegen is driven by buf (`proto/buf.yaml`, `proto/buf.gen.yaml`, `proto/buf.lock`) into `proto/gen/api/v1/*.pb.go` and `proto/gen/store/*.pb.go`.

**Three runtime surfaces**, all wired in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`):

1. **REST via gRPC-Gateway** — eight `Register*HandlerServer` calls at `server/router/api/v1/v1.go:98-121` populate a `runtime.NewServeMux` (`:95`) with auth middleware, mounted on `/api/v1/*` and `/file/*` (`:127-128`). This is the closest analogue to the "public API".
2. **Connect RPC** — for browser clients, replacing grpc-web: handlers registered at `:141` behind the metadata/logging/recovery/auth interceptor chain (`:133-138`), mounted at `/memos.api.v1.*` (`:144`). Method wrappers live in `server/router/api/v1/connect_services.go`.
3. **SSE** — `RegisterSSERoutes(gwGroup, s.SSEHub, ...)` at `server/router/api/v1/v1.go:124` for push updates.

**API documentation** is OpenAPI, not a GraphQL schema: `proto/gen/openapi.yaml`, generated from the protos and embedded into the binary via `//go:embed gen/openapi.yaml` in `proto/openapi_embed.go`, exposed through `proto.OpenAPIYAML()`.

Non-gRPC HTTP surfaces exist alongside these — the file server (`server/router/fileserver/fileserver.go:121`), RSS (`server/router/rss/rss.go:67`), and MCP (`server/router/mcp/service.go:108`) — but none of them is GraphQL either.
