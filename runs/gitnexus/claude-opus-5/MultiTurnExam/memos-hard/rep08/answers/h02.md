**`webhook.Post` — `internal/webhook/webhook.go:120` (the actual `safeClient.Do` at `internal/webhook/webhook.go:152`); protection: dial-time reserved-IP blocking via `safeDialContext` + `isReservedIP` — `internal/webhook/webhook.go:59` and `internal/webhook/validate.go:44`**

Details:

**Delivery path.** Memo changes call `webhook.PostAsync` (`internal/webhook/webhook.go:184`) from `server/router/api/v1/memo_service_webhooks.go:43` and `:71`. `PostAsync` only enqueues onto a bounded 128-slot channel (`webhook.go:39`), dropping with a warning when full. The real HTTP work happens in `Post` (`webhook.go:120`), run by four worker goroutines started in `init` (`webhook.go:42-55`): it marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook.go:133-150`), and issues the request via `safeClient.Do(req)` at `webhook.go:152`.

**SSRF protection — two layers:**

1. **Dial time (the load-bearing one).** `safeClient` (`webhook.go:32-37`) is an `http.Client` whose `Transport.DialContext` is `safeDialContext` (`webhook.go:59-77`). On every connection it resolves the host itself and rejects the dial if *any* resolved address is reserved, before handing off to the real dialer. Because this runs per-connection rather than at config time, it also defeats DNS rebinding — noted in the comment at `webhook.go:30-31`. The ranges are in `reservedCIDRs` (`internal/webhook/validate.go:14-23`): IPv4 loopback, all three RFC-1918 blocks, 169.254.0.0/16 (cloud IMDS), and the IPv6 equivalents, parsed once at startup (`validate.go:28-36`) and matched by `isReservedIP` (`validate.go:44`).

2. **Config time.** `webhook.ValidateURL` (`validate.go:62`) rejects non-http(s) schemes and reserved-resolving hostnames when a user creates or updates a webhook — `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`.

**Escape hatch:** the package-level `webhook.AllowPrivateIPs` flag (`validate.go:41`) short-circuits `isReservedIP`, disabling both layers for self-hosted deployments targeting LAN services. Outside of tests, nothing in the repo sets it, so it defaults to `false` (protection on).
