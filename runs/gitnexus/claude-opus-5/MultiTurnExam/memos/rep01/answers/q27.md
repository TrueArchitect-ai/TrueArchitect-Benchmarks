**Compiled assets are embedded into the Go binary with `//go:embed` and served by Echo's static middleware with an SPA fallback to `index.html`; server/router/frontend/frontend.go**

Details:

- `//go:embed dist/*` compiles `server/router/frontend/dist/` into the binary as `embeddedFiles` (`server/router/frontend/frontend.go:20-21`); `getFileSystem("dist")` exposes it as an `fs.FS`.
- `FrontendService.Serve` registers `middleware.StaticWithConfig` over that FS, plus `spaFallbackMiddleware`, which turns a 404 on an HTML-ish route into `index.html` so client-side routing works (`server/router/frontend/frontend.go:40-78`). A skipper excludes `/api`, `/file`, the Connect prefix `/memos.api.v1.*`, and `robots.txt`/`sitemap.xml`/`rss.xml` (lines 80-88). Cache headers differ for HTML vs. hashed assets (lines 23-26).
- Wired up at startup in `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
- The `dist/` directory is populated by the Vite build (`web/vite.config.mts`) before the Go build — CI downloads the web build artifact into `server/router/frontend/dist` (`.github/workflows/release.yml:108,146,275`; `.github/workflows/build-canary-image.yml:48,78`). In the checked-out tree only a placeholder `index.html` is present.
