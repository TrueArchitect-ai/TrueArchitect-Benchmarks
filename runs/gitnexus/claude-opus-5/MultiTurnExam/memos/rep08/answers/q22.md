**`APIV1Service.DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`; `internal/webhook`; HMAC-SHA256 signature in Standard Webhooks–style headers (`webhook-id` / `webhook-timestamp` / `webhook-signature: v1,<base64>`)**

**Call from the handler.** `APIV1Service.CreateMemo` calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)` at `server/router/api/v1/memo_service.go:157`, logging a warning on failure rather than failing the RPC.

**Dispatcher.** Defined at `server/router/api/v1/memo_service_webhooks.go:15`, it delegates to the shared `dispatchMemoRelatedWebhook(ctx, memo, "memos.memo.created")` (line 49). That helper resolves the memo's creator via `ResolveUserByName`, loads the creator's hooks with `s.Store.GetUserWebhooks(ctx, creatorID)`, and for each hook builds a payload (`convertMemoToWebhookPayload`), stamps `ActivityType`, `URL`, and `SigningSecret`, then calls `webhook.PostAsync(payload)`. Siblings in the same file handle `memos.memo.updated`, `memos.memo.deleted`, and `memos.memo.comment.created` (the last one targets the *parent* memo's owner).

**Delivery package.** `internal/webhook` (`internal/webhook/webhook.go`). `PostAsync` (line 184) enqueues onto a bounded `asyncPostQueue` and drops with a warning if it's full — so delivery is fire-and-forget and never blocks memo creation. `Post` (line 120) does the actual `POST` with `Content-Type: application/json`, using a hardened `safeClient` whose `safeDialContext` (line 59) guards outbound targets (SSRF protection; validation helpers live in `internal/webhook/validate.go`). Responses are read under a 1 MiB limit and the receiver's JSON `code` must be `0`.

**Signing.** Only when the hook has a `SigningSecret` (`internal/webhook/webhook.go:133-150`): the key is derived by `resolveSigningKey`, then `hmac.New(sha256.New, key)` is fed `msgID + "." + timestamp + "."` followed by the raw JSON body, and the digest is base64-encoded. Three headers go out — `webhook-id` (`msg_<uuid>`), `webhook-timestamp` (Unix seconds), and `webhook-signature` set to `"v1," + signature`. Secrets are generated by `GenerateSigningSecret` (line 111) and deliberately omitted from API responses (`convertUserWebhookFromUserSetting` in `server/router/api/v1/user_service_webhooks.go`, covered by `TestConvertUserWebhookFromUserSettingOmitsSigningSecret`).
