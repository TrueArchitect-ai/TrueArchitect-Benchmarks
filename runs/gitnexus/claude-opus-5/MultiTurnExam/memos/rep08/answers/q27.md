**Mechanism: the built Vite bundle is compiled into the Go binary with `//go:embed`, then served by Echo's static middleware with an SPA `index.html` fallback; path: `server/router/frontend/frontend.go`**

How it's wired:

- **Embedding.** `//go:embed dist/*` → `var embeddedFiles embed.FS` at `server/router/frontend/frontend.go:20-21`. `getFileSystem("dist")` (line 116) takes an `fs.Sub` of it, so no external asset directory ships alongside the binary. The checked-in `server/router/frontend/dist/` holds only a placeholder `index.html`; the real bundle is written there by the frontend build before `go build`.
- **Serving.** `FrontendService.Serve` (line 40) installs `middleware.StaticWithConfig{Filesystem: frontendFS, Skipper: skipper}` at line 54, registered from `server/server.go:72` via `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
- **SPA fallback.** `spaFallbackMiddleware` (line 63) catches a 404 from the static handler and returns `index.html` instead — but only for extension-less paths, `/` or `/index.html` (`shouldServeFrontendHTML`, line 107), so client-side routes resolve while missing assets still 404.
- **What's excluded.** `shouldSkipFrontendStatic` (line 82) bypasses the frontend for `/api/*`, `/file/*`, the Connect RPC prefixes (`/memos.api.v1`, `/memos.api.v1.*`), plus `robots.txt`, `sitemap.xml`, and `*/rss.xml` — the last three are served by `registerRoutes` in the same file.
- **Caching.** `setFrontendCacheHeaders` (line 91): HTML is `no-cache, no-store, must-revalidate`; hashed files under `/assets/` get `public, max-age=3600, immutable`; everything else `public, max-age=3600`.

One ordering note from `server/server.go:79` — the fileserver routes are registered before the gRPC-Gateway deliberately, "to ensure proper range request handling for Safari."
