**`web/src/connect.ts`**

All eight service clients are created and exported there (`web/src/connect.ts:192-203`) from a single shared transport built at `web/src/connect.ts:184-189` (`baseUrl: window.location.origin`, binary format, credentialed fetch, plus an `authInterceptor`):

- `instanceServiceClient`, `authServiceClient`, `userServiceClient`
- `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`
- `identityProviderServiceClient`

The file also holds a separate `refreshAuthClient` on its own transport (`web/src/connect.ts:72`), kept off the interceptor chain so token refresh doesn't recurse.
