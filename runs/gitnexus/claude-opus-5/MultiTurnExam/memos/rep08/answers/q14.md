Two notes on where the data actually lives: a `Shortcut` is a named, reusable CEL filter whose `filter` string can be passed straight to `ListMemos` (per the proto comment at `shortcut_service.proto:15-17`), and shortcuts aren't a dedicated table — they're persisted as a user setting (`ShortcutsUserSetting` / `UserSetting_Shortcuts`, exercised in `store/test/user_setting_test.go`). As with the other services, `server/router/api/v1/connect_services.go` provides the thin Connect transport adapters.
