**`store/migration/sqlite/LATEST.sql`**

This is the only `.sql` file at the root of `store/migration/sqlite/` — the per-version directories (`0.2/` … `0.30/`) hold only incremental migrations for upgrading existing installs.

The migrator confirms it's the fresh-install path. In `preMigrate` (`store/migrator.go:217-230`), when `IsInitialized` reports the DB is empty it reads `s.getMigrationBasePath() + LatestSchemaFileName` and applies it in a single transaction, logging `"initializing new database with latest schema"`. `LatestSchemaFileName = "LATEST.sql"` (`store/migrator.go:56`) and `getMigrationBasePath()` returns `migration/{profile.Driver}/` (`store/migrator.go:255`), so for `driver=sqlite` the resolved embedded path is `migration/sqlite/LATEST.sql`. The comment at `store/migrator.go:42` states the intent directly: full schema for new installations, faster than replaying incremental migrations. Afterward `getSchemaVersionOfMigrateScript` (`store/migrator.go:326-328`) stamps it with the current schema version so no incremental migrations re-run.
