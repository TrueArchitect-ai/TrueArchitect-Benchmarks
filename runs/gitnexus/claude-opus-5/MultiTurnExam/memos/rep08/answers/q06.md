**memo_relation**

Schema (`store/migration/sqlite/LATEST.sql:47-52`, identical shape in `store/migration/postgres/LATEST.sql:46-51` and the MySQL equivalent):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

It's a join table pairing `memo_id` → `related_memo_id`, with `type` distinguishing the kind of link (e.g. reference vs. comment) and a uniqueness constraint over all three columns. Introduced in `store/migration/sqlite/0.13/00__memo_relation.sql`; the Go access layer lives in `store/db/postgres/memo_relation.go` (and the sqlite/mysql siblings).
