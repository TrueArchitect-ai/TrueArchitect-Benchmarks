**Go `embed` of the Vite build output (`dist/`), served as static files through Echo middleware with SPA fallback; server/router/frontend/frontend.go**

How it's wired:

- `//go:embed dist/*` → `var embeddedFiles embed.FS` at `server/router/frontend/frontend.go:20-21`, so the compiled React bundle is baked into the binary at build time (the build copies `web/dist` into `server/router/frontend/dist`).
- `FrontendService.Serve` (`:40`) roots the FS at `dist` via `getFileSystem("dist")` (`:114`) and registers `middleware.StaticWithConfig` (`:53`).
- `spaFallbackMiddleware` (`:62`) catches 404s on extension-less paths and serves `index.html`, so client-side routes work on hard refresh.
- A skipper excludes non-frontend paths — `/api/*`, `/file/*`, Connect's `/memos.api.v1.*`, plus `/robots.txt`, `/sitemap.xml`, `*/rss.xml` (`:80`).
- Cache headers differ by asset type: `no-cache` for HTML, `max-age=3600` for static, and `immutable` for hashed `/assets/*` (`:23-26`, `:90`).

`robots.txt` and `sitemap.xml` are generated dynamically by the same service (`registerRoutes`, `:120`).
