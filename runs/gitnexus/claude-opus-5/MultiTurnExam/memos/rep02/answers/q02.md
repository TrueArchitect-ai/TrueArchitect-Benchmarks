**MySQL, PostgreSQL, SQLite**

Migrations live under `store/migration/{driver}/{version}/NN__description.sql`, with one directory per dialect:

- `store/migration/mysql/` (versions 0.17–0.30 + `LATEST.sql`)
- `store/migration/postgres/` (versions 0.19–0.30 + `LATEST.sql`)
- `store/migration/sqlite/` (versions 0.2–0.30 + `LATEST.sql`)

The whole tree is embedded into the binary via `//go:embed migration` in `store/migrator.go:44`, and the path is selected at runtime from the configured driver (`store/migrator.go:255`). The matching driver implementations are in `store/db/mysql/`, `store/db/postgres/`, and `store/db/sqlite/`.
