**web/src/connect.ts**

It's the only file in `web/src` that calls `createClient`/`createConnectTransport`. It builds the shared transport with an auth interceptor (`web/src/connect.ts:184-189`) and exports one client per service — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient` (`web/src/connect.ts:192-203`) — plus a separate interceptor-free `refreshTransport`/`refreshAuthClient` for token refresh (`web/src/connect.ts:65-72`).
