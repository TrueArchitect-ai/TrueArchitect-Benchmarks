**Driver — store/driver.go**

Defined at `store/driver.go:10`, `store.Driver` is the interface every backend implements — connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus the CRUD methods for each model (attachment, memo, memo relation, instance setting, user, etc.).

Implemented by the `DB` struct in each of the three driver packages: `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, and `store/db/mysql/mysql.go`, with the driver chosen in `store/db/db.go`.
