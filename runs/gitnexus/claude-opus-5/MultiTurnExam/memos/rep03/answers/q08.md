**Driver — store/driver.go**

`store.Driver` is declared at `store/driver.go:10`. It covers connection lifecycle (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus per-model CRUD methods (attachment, memo, memo relation, instance setting, user, etc.).

The three backends each implement it with a package-local `DB` struct — `store/db/sqlite/sqlite.go`, `store/db/postgres/postgres.go`, `store/db/mysql/mysql.go` — and their `NewDB` constructors return `store.Driver`. The backend is selected in `store/db/db.go`.
