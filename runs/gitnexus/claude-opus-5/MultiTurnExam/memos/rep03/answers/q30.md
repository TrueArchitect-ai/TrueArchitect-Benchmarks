Both resolve the target user's hooks via `Store.GetUserWebhooks`, build a `webhook.WebhookRequestPayload`, and call:

**`webhook.PostAsync` — `internal/webhook/webhook.go:184`**, which enqueues onto a buffered channel (`asyncPostQueue`, capacity 128, line 39) drained by 4 worker goroutines started in `init()` (line 42). Each worker calls `webhook.Post` (line 120) for the actual HTTP delivery — JSON body, HMAC-SHA256 Standard Webhooks signature headers, and an SSRF-hardened `safeClient` that rejects reserved/private IPs at dial time (lines 32-37, `internal/webhook/validate.go`). If the queue is full the dispatch is dropped with a warning rather than blocking the request (lines 191-195).
