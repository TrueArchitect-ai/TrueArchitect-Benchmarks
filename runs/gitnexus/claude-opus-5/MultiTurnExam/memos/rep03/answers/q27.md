**Go `embed.FS` — the built Vite bundle is compiled into the binary and served by Echo static middleware with SPA fallback; server/router/frontend/frontend.go**

How it's wired:

- `//go:embed dist/*` embeds `server/router/frontend/dist/` (the copied output of the `web/` Vite build) into `embeddedFiles` (`server/router/frontend/frontend.go:20-21`).
- `FrontendService.Serve` (line 41) roots the FS at `dist` via `fs.Sub` (`getFileSystem`, line 115) and installs `middleware.StaticWithConfig` over it (line 54).
- A skipper (line 43) excludes API paths — `/api/*`, `/file/*`, `/memos.api.v1.*` — plus `/robots.txt`, `/sitemap.xml`, and `*/rss.xml`, which have their own handlers registered at line 123.
- `spaFallbackMiddleware` (line 63) turns a 404 on an extensionless path into `index.html` so client-side routes deep-link correctly (line 77).
- Cache headers are set per asset class (line 92): no-store for HTML, `max-age=3600` for static files, and `immutable` for hashed `/assets/*`.
