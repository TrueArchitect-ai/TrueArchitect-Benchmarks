**store/migration/sqlite/LATEST.sql**

On a fresh database the migrator skips the versioned migration directories entirely and applies this one file: `store/migrator.go:218` builds the path as `getMigrationBasePath() + LatestSchemaFileName`, i.e. `migration/sqlite/` + `LATEST.sql` (the constant is defined at `store/migrator.go:56`), reads it from the embedded FS, and executes it in a single transaction. It's also the only `.sql` file sitting directly in `store/migration/sqlite/` — everything else there is under a version subdirectory.
