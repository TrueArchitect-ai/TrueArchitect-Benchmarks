Connect (ConnectRPC over HTTP) — server/router/api/v1/connect_handler.go

- **Connect**: `RegisterConnectHandlers` mounts `apiv1connect.NewMemoServiceHandler(s, opts...)` on the `http.ServeMux` (`server/router/api/v1/connect_handler.go:40`). The `s` here is the `ConnectServiceHandler` from `server/router/api/v1/connect_services.go`, which wraps each RPC (e.g. `CreateMemo` at :306) and delegates to `APIV1Service`. This is what the web client in `web/src/connect.ts` talks to.
- **REST/JSON**: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` registers the service directly (in-process, no gRPC dial) on a grpc-gateway `runtime.ServeMux` (`server/router/api/v1/v1.go:108`), which is then mounted on the Echo server. This serves the `google.api.http` paths declared in `proto/api/v1/memo_service.proto`, using the generated gateway code in `proto/gen/api/v1/memo_service.pb.gw.go`.

Both paths bottom out in the same `APIV1Service` methods in `server/router/api/v1/memo_service.go`.
