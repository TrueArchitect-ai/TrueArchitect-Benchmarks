**Runners the server actually starts** — all in `Server.startBackgroundRunners` (`server/server.go:152-173`):

```
s3presign.Runner — one immediate RunOnce at startup, then a 12-hour time.Ticker loop
```

That's the only entry: `s3presignRunner.RunOnce(ctx)` at `server/server.go:163`, then `go s3presignRunner.Run(s3Context)` at :167. `Run` drives a `time.NewTicker(runnerInterval)` with `runnerInterval = 12 * time.Hour` (`server/runner/s3presign/runner.go:27-41`), calling `CheckAndPresign` each tick. It gets its own cancelable context so `Shutdown` can stop it independently (`server/server.go:155-158`, `stopBackgroundRunners`).
