**sqlite, mysql, postgres**

The migrations are embedded from `store/migration` (`store/migrator.go:44-45`, `//go:embed migration`), and the dialect is selected at runtime by the configured driver: `getMigrationBasePath()` returns `migration/<driver>/` (`store/migrator.go:254-255`). That directory contains exactly three dialect subtrees:

- `store/migration/sqlite/` (versions 0.2 → 0.30, plus `LATEST.sql`)
- `store/migration/mysql/` (versions 0.17 → 0.30)
- `store/migration/postgres/` (versions 0.19 → 0.30)

The matching driver implementations live alongside them in `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`.
