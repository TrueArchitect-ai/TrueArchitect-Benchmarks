**Go `embed` — the Vite build output is compiled into the binary and served by an Echo static-file middleware with SPA fallback; server/router/frontend/frontend.go**

Specifics:
- `//go:embed dist/*` embeds `server/router/frontend/dist` (the copied `web` build) into `embeddedFiles` (`server/router/frontend/frontend.go:20-21`).
- `FrontendService.Serve` mounts it via `middleware.StaticWithConfig{Filesystem: getFileSystem("dist")}` and adds `spaFallbackMiddleware`, which serves `index.html` for any non-API 404 so client-side routes resolve (`server/router/frontend/frontend.go:40-79`).
- Cache headers differ per asset class — `no-cache` for HTML, `max-age=3600` for static, `immutable` for hash-named assets (lines 23-26).

`FrontendService` is constructed and `Serve`d from the server setup in `server/server.go`.
