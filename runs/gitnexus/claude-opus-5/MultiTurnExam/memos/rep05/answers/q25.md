**CEL (Google Common Expression Language), via cel-go — `internal/filter/` (engine at `internal/filter/engine.go`); the CEL expression is compiled once into a dialect-agnostic condition tree, then rendered per-dialect into a parameterized SQL `WHERE` fragment plus args, which the driver appends to its query.**

The detail:

- **Parse.** `Engine.Compile` (`internal/filter/engine.go:47`) runs the filter string through a `cel.Env` built from `schema.EnvOptions` (`engine.go:25`), converts the AST via `cel.AstToParsedExpr`, and lowers it into an internal `Condition` tree with `buildCondition` (`internal/filter/parser.go`, tree types in `internal/filter/ir.go`). The available variables — `content`, `creator`, `creator_id`, `created_ts`, `updated_ts`, etc. — are declared in `internal/filter/schema.go:232`.

- **Render.** `Program.Render` (`engine.go:96`) hands the tree to the renderer in `internal/filter/render.go`, which takes `RenderOptions{Dialect, PlaceholderOffset, DisableNullChecks}` (`engine.go:83`) and emits a `Statement{SQL, Args}`. Dialect differences are handled two ways: per-field column expressions in the schema (`Field.Expressions`, e.g. `('users/' || %s)` for SQLite/Postgres vs `CONCAT('users/', %s)` for MySQL, `schema.go:104-107`), and explicit switches in the renderer for things like timestamp extraction (`render.go:231-241`) and placeholder style (`?` vs `$N`). Supported dialects are `DialectSQLite`, `DialectMySQL`, `DialectPostgres` (`schema.go:14-16`).

- **Wiring into the query.** Each driver calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite, &where, &args)` (`internal/filter/helpers.go:9`) at the top of `ListMemos` — see `store/db/sqlite/memo.go:58-63`, and the same in `store/db/postgres/memo.go` and `store/db/mysql/memo.go`. It wraps each rendered fragment in parentheses, appends it to the `WHERE` slice, and threads `PlaceholderOffset` from the current arg count so numbered placeholders stay correct.

The API side sets `find.Filters` from `ListMemosRequest.filter` in `server/router/api/v1/memo_service_filter.go`. Shortcuts reuse the same syntax — a `Shortcut.filter` string is just a saved CEL filter passed to `ListMemos` (`proto/api/v1/shortcut_service.proto:15-17`).
