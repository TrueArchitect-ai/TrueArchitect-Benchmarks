**Go `embed.FS` — the built Vite output is compiled into the binary and served by Echo static middleware with an SPA fallback; server/router/frontend/frontend.go**

How it's wired:

- `//go:embed dist/*` at `server/router/frontend/frontend.go:20` bakes `server/router/frontend/dist/` (the compiled React bundle; the checked-in tree holds a placeholder `index.html` that the build replaces) into `embeddedFiles`.
- `FrontendService.Serve` (`frontend.go:40`) mounts it via `middleware.StaticWithConfig` over `getFileSystem("dist")`, with a skipper that passes through `/api`, `/file`, `/memos.api.v1.*`, `/robots.txt`, `/sitemap.xml`, and `*/rss.xml` so backend routes aren't shadowed.
- `spaFallbackMiddleware` (`frontend.go:62`) catches 404s on HTML-ish paths and serves `index.html` instead, so client-side routes deep-link correctly.
- Cache headers differ per asset class — `no-cache` for HTML, `max-age=3600` for static, `immutable` for hash-named assets (`frontend.go:23-26`).

Startup wiring is a single line: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)` at `server/server.go:72`.
