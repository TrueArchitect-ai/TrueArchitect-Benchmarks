**Convergence.** The first three are one-line wrappers over the shared helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo's creator, loads their hooks via `Store.GetUserWebhooks`, and enqueues one payload per hook. The comment variant (`:30`) is structurally the same but targets the *parent* memo's creator, so it duplicates the loop rather than reusing the helper.

Every path then converges on `webhook.PostAsync` (`internal/webhook/webhook.go:184`) — a bounded channel drained by four worker goroutines — with the actual HTTP POST and HMAC-SHA256 signing done in `webhook.Post` (`internal/webhook/webhook.go:120`).
