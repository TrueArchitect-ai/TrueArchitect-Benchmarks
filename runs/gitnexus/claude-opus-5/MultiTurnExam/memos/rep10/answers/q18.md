**NewDBDriver — store/db/db.go**

Each entry file defines a package-local `DB` struct plus `NewDB(profile)` returning a `store.Driver` (e.g. `store/db/postgres/postgres.go:16,21`); the rest of the interface is spread across sibling files in each package. `NewDBDriver` switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) and errors with "unknown db driver" otherwise.
