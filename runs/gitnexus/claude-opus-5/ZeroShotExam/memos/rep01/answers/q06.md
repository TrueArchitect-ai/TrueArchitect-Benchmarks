**`memo_relation`**

Schema (`store/migration/sqlite/LATEST.sql:47-52`, mirrored in `store/migration/postgres/LATEST.sql` and `store/migration/mysql/LATEST.sql`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

Each row links a source memo (`memo_id`) to a related memo (`related_memo_id`) with a relation `type` (e.g. reference vs. comment). Related code: `store/memo_relation.go`, `server/router/api/v1/memo_relation_service.go`, tests in `store/test/memo_relation_test.go`.
