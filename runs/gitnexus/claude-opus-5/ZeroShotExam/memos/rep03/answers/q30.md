### Details

All four dispatchers live in `server/router/api/v1/memo_service_webhooks.go`:

| Event (activity type) | Function | Def | Called from |
|---|---|---|---|
| `memos.memo.created` | `DispatchMemoCreatedWebhook` | `memo_service_webhooks.go:15` | `memo_service.go:157` (CreateMemo) |
| `memos.memo.updated` | `DispatchMemoUpdatedWebhook` | `memo_service_webhooks.go:20` | `memo_update_helpers.go:67` |
| `memos.memo.deleted` | `DispatchMemoDeletedWebhook` | `memo_service_webhooks.go:25` | `memo_service.go:562` (DeleteMemo) |
| `memos.memo.comment.created` | `DispatchMemoCommentCreatedWebhook` | `memo_service_webhooks.go:30` | `memo_service_comments.go:119` |

**Convergence.** The three core lifecycle events (created/updated/deleted) are one-line wrappers that all delegate to the shared unexported helper `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`), which resolves the memo creator, loads their webhooks via `s.Store.GetUserWebhooks`, builds a payload with `convertMemoToWebhookPayload`, and calls `webhook.PostAsync` per hook (`memo_service_webhooks.go:71`).

The comment webhook does *not* go through `dispatchMemoRelatedWebhook` — it resolves hooks from the *related memo's* owner ID instead of the comment creator — but it converges at the same delivery call: `webhook.PostAsync` (`memo_service_webhooks.go:43`).

From there, `PostAsync` (`internal/webhook/webhook.go:184`) enqueues onto the buffered `asyncPostQueue` (cap 128, dropping with a warning if full); four worker goroutines started in `init()` (`internal/webhook/webhook.go:41-54`) drain the queue and call `Post` (`internal/webhook/webhook.go:119`), which marshals the JSON, adds Standard Webhooks HMAC headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`) when a signing secret is set, and POSTs via the SSRF-guarded `safeClient`.

One stray note: `server/router/api/v1/memo_service.go:603` has a leftover orphan comment `// DispatchMemoCreatedWebhook dispatches webhook when memo is created.` at end of file with no function under it — the implementation moved to `memo_service_webhooks.go`.
