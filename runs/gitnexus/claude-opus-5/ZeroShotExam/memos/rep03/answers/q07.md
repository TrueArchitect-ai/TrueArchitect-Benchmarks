`web/src/connect.ts`

All ConnectRPC service clients are created there via `createClient(...)` over a shared `createConnectTransport` instance (`web/src/connect.ts:184-203`), including `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. The file also defines a separate `refreshAuthClient` on its own transport (`web/src/connect.ts:65-72`) used for token refresh, so it can bypass the auth interceptor.
