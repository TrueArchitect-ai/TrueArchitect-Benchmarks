**DB — `store/db/postgres/postgres.go`**

The `postgres.DB` struct (`store/db/postgres/postgres.go:16`) implements the `store.Driver` interface (`store/driver.go`) for PostgreSQL. It holds a `*sql.DB` and a `*profile.Profile`, and is constructed by `NewDB` (`store/db/postgres/postgres.go:21`), which opens a connection with the `github.com/lib/pq` driver and returns it as a `store.Driver`.

The rest of the interface methods are implemented across sibling files in the same package (`memo.go`, `user.go`, `attachment.go`, `idp.go`, etc.), all with receiver `(d *DB)`. The SQLite counterpart is an identically-named `DB` struct in `store/db/sqlite/sqlite.go`.
