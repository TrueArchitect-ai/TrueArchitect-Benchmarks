`web/src/connect.ts`

That file (`/bench/home/work/web/src/connect.ts`) is the single place where the ConnectRPC transport and service clients are created:

- Transports via `createConnectTransport` — `refreshTransport` (no auth interceptor, to avoid recursion) at line 65 and the main `transport` with `authInterceptor` at line 184.
- Exported clients via `createClient(...)` at lines 192–203: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, `identityProviderServiceClient` — plus an internal `refreshAuthClient` (line 72) used only for token refresh.

A repo-wide grep for `createClient`/`createConnectTransport` in `.ts/.tsx/.js` returns only this file, so no other frontend file constructs clients.
