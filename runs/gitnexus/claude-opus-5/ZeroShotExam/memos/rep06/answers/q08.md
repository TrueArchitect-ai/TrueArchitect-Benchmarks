**Driver — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10`, in package `store`. Its doc comment reads: "Driver is an interface for store driver. It contains all methods that store database driver should implement."

It declares the full data-access surface — `GetDB()`, `Close()`, `IsInitialized()`, `GetDatabaseSize()`, plus CRUD methods for every model (Attachment, Memo, MemoRelation, InstanceSetting, User, UserSetting, IdentityProvider, Inbox, Reaction, MemoShare, UserIdentity).

Three backends implement it, one per subdirectory of `store/db/`:
- `store/db/sqlite/`
- `store/db/mysql/`
- `store/db/postgres/`

`store/db/db.go` is the factory that selects among them and returns a `store.Driver`.
