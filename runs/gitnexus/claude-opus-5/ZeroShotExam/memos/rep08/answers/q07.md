`web/src/connect.ts`

That single file (`/bench/home/work/web/src/connect.ts`) is where all ConnectRPC service clients are created:

- It builds the transport with `createConnectTransport({ baseUrl: window.location.origin, useBinaryFormat: true, ... })` — one with the auth interceptor (`web/src/connect.ts:184`) and a separate interceptor-free `refreshTransport` used only for token refresh (`web/src/connect.ts:65`).
- It exports the clients via `createClient(...)`: `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (`web/src/connect.ts:192-203`).
