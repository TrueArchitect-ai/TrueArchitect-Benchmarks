**Go `embed.FS` (`//go:embed dist/*`) served by an Echo static middleware + SPA fallback; `server/router/frontend/frontend.go`**

How it's wired:

- `server/router/frontend/frontend.go:20-21` — `//go:embed dist/*` compiles the built frontend into the binary as `embeddedFiles`; `getFileSystem("dist")` (line ~114) sub-roots it.
- `FrontendService.Serve` (same file, line ~40) registers `middleware.StaticWithConfig` over that FS, plus `spaFallbackMiddleware`, which on a 404 for an extension-less path serves `index.html` so client-side routes work. A skipper excludes `/api`, `/file`, `/memos.api.v1*`, `/robots.txt`, `/sitemap.xml`, `*/rss.xml`. Cache headers: `no-cache` for HTML, `max-age=3600` for static, `immutable` for `/assets/`.
- Wired into the server at `server/server.go:72`: `frontend.NewFrontendService(profile, store).Serve(ctx, echoServer)`.
- The `dist` directory is produced by `pnpm release` in `web/package.json` (`vite build --mode release --outDir=../server/router/frontend/dist`), which must run before `go build` — noted in `scripts/Dockerfile` ("Please build frontend first, so that the static files are available").
