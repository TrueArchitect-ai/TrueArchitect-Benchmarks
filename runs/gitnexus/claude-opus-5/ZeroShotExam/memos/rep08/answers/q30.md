**Memo lifecycle events that dispatch webhooks** — all defined in `server/router/api/v1/memo_service_webhooks.go`:

```
memos.memo.created: DispatchMemoCreatedWebhook (memo_service_webhooks.go:15)
memos.memo.updated: DispatchMemoUpdatedWebhook (memo_service_webhooks.go:20)
memos.memo.deleted: DispatchMemoDeletedWebhook (memo_service_webhooks.go:25)
memos.memo.comment.created: DispatchMemoCommentCreatedWebhook (memo_service_webhooks.go:30)
```

**Convergence for delivery**

The three core lifecycle dispatchers are one-line wrappers that funnel into the shared unexported helper `dispatchMemoRelatedWebhook(ctx, memo, activityType)` (`server/router/api/v1/memo_service_webhooks.go:48`), which resolves the memo creator, loads their webhooks via `Store.GetUserWebhooks`, builds a payload with `convertMemoToWebhookPayload`, and stamps `ActivityType`/`URL`/`SigningSecret`.

`DispatchMemoCommentCreatedWebhook` does *not* go through that helper — it looks up webhooks for the *related memo's* owner instead of the comment creator (`memo_service_webhooks.go:31`) — but it builds the same payload and ends at the same place.

All four converge on **`webhook.PostAsync`** (`internal/webhook/webhook.go:184`), which enqueues onto the bounded `asyncPostQueue` (cap 128, dropped with a warning when full). Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call **`webhook.Post`** (`internal/webhook/webhook.go:120`), the actual HTTP delivery — JSON marshal, optional Standard Webhooks HMAC-SHA256 signing headers, then `safeClient.Do` over an SSRF-guarded transport (`safeDialContext`, line 59).

Call sites:
- create → `server/router/api/v1/memo_service.go:157`
- update → `server/router/api/v1/memo_update_helpers.go:67` (inside `dispatchMemoUpdatedSideEffects`)
- delete → `server/router/api/v1/memo_service.go:562`
- comment created → `server/router/api/v1/memo_service_comments.go:119`

Each call site logs and swallows the error (`slog.Warn`), so webhook failures never fail the memo operation.
