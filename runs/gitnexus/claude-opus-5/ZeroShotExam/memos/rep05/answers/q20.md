**Mechanism:** Server-Sent Events (SSE) — plain HTTP `text/event-stream`, not WebSockets. One `GET /api/v1/sse` endpoint, Bearer-token authenticated, with 30s heartbeat comments (`server/router/api/v1/sse_handler.go:34`). The browser consumes it with `fetch` + a stream reader (not `EventSource`, since it needs the auth header) in `web/src/hooks/useLiveMemoRefresh.ts:202`, invalidating React Query caches per event.

**Hub path:** `server/router/api/v1/sse_hub.go` — `SSEHub` (line 56), a mutex-guarded `map[*SSEClient]struct{}` with `Subscribe`/`Unsubscribe`/`Close`/`Broadcast`. Each client gets a 32-slot buffered channel; events for a full buffer are dropped rather than blocking the broadcaster (line 126). `Broadcast` filters per-client via `canReceive` — private memos only reach the creator or an admin (line 134). Constructed in `server/router/api/v1/v1.go:57` and routed at `v1.go:125`.
