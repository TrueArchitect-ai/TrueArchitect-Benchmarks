3. **Delivery package** — `internal/webhook` (`internal/webhook/webhook.go`). `PostAsync` (line 184) enqueues onto a bounded 128-slot channel drained by 4 goroutines started in `init()` (line 42); each calls `Post` (line 120), which does the actual `POST` with a shared `safeClient` — an `http.Client` with a 30s timeout and a `safeDialContext` transport that rejects reserved/private IPs to block SSRF and DNS rebinding. 4. **Signing** — when the hook has a `SigningSecret`, `Post` follows the Standard Webhooks spec (lines 133–150): the secret is resolved by `resolveSigningKey` (a `whsec_<base64>` secret is base64-decoded to raw key bytes; anything else is used verbatim), then HMAC-SHA256 is computed over `"{msgID}.{timestamp}."` concatenated with the JSON body. The result is base64-encoded and sent as headers `webhook-id` (`msg_<uuid>`), `webhook-timestamp` (unix seconds), and `webhook-signature` (`v1,<sig>`). Secrets are generated by `GenerateSigningSecret` (line 111) from 32 random bytes.
