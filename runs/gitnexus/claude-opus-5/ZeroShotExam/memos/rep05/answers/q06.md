**`memo_relation`**

Schema (`store/migration/sqlite/LATEST.sql:46-52`):

```sql
CREATE TABLE memo_relation (
  memo_id INTEGER NOT NULL,
  related_memo_id INTEGER NOT NULL,
  type TEXT NOT NULL,
  UNIQUE(memo_id, related_memo_id, type)
);
```

- `memo_id` → the source memo, `related_memo_id` → the linked memo, `type` distinguishes the relation kind (e.g. reference vs. comment).
- Same table is defined for the other drivers: `store/migration/postgres/LATEST.sql`, `store/migration/mysql/LATEST.sql`; originally added in `store/migration/sqlite/0.13/00__memo_relation.sql`.
- Store layer: `store/memo_relation.go`; API layer: `server/router/api/v1/memo_relation_service.go`.
