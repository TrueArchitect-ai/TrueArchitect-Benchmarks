**Tables affected: `memo`, `memo_relation`, `attachment` — plus `memo_share` only via DB-level FK cascade (Postgres/MySQL, not SQLite). `reaction` is *not* touched.**

**Trace**

`APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`):
- Lists comment relations (`RelatedMemoID = memo.ID`, type `COMMENT`) and calls `Store.DeleteMemo` on each comment memo (`memo_service.go:569-577`), then deletes the memo itself (`memo_service.go:580`).

`Store.DeleteMemo` (`store/memo.go:140-159`) — the explicit cascade code:
1. **`memo_relation`** — two deletes, `MemoID = id` and `RelatedMemoID = id` (`store/memo.go:142-147` → `store/db/sqlite/memo_relation.go:137`).
2. **`attachment`** — lists attachments with `MemoID = id` and calls `Store.DeleteAttachment` per row (`store/memo.go:149-157`); that also removes the underlying blob/local/S3 file via `DeleteAttachmentStorage` (`store/attachment.go:132-149`) before the row delete (`store/db/sqlite/attachment.go:211`).
3. **`memo`** — `DELETE FROM memo WHERE id = ?` (`store/db/sqlite/memo.go:237`, `store/db/postgres/memo.go:244`, `store/db/mysql/memo.go:259`).

**`memo_share`** — no explicit code in the delete path; it relies on `FOREIGN KEY (memo_id) REFERENCES memo(id) ON DELETE CASCADE` (`store/migration/postgres/LATEST.sql:108`, `store/migration/mysql/LATEST.sql:108`, `store/migration/sqlite/LATEST.sql:109`). On SQLite that cascade does **not** fire — the connection is opened with `_pragma=foreign_keys(0)` (`store/db/sqlite/sqlite.go:53`), so share rows are left orphaned there. (Explicit `memo_share` cleanup exists only in the user-deletion path, `store/db/sqlite/user_delete.go:405-411`.)

**`reaction`** — reactions are read at `memo_service.go:545-550` purely to build the webhook payload; nothing deletes them, and the table has no FK to `memo` (`content_id` is a text name). Reaction rows for a deleted memo are orphaned.

Also note: comment deletion is a single level — a comment's own comments are not recursed, since `Store.DeleteMemo` only clears relations, not nested comment memos.
