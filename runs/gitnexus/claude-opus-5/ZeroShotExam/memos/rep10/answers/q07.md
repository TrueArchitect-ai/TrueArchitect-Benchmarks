`web/src/connect.ts`

This is the only frontend file that calls `createClient`. It builds a `createConnectTransport` with an auth interceptor (`web/src/connect.ts:184`) and exports all the service clients from it (`web/src/connect.ts:192-203`): `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient`. It also creates a separate interceptor-free transport and `refreshAuthClient` for token refresh (`web/src/connect.ts:65-72`) to avoid recursion.
