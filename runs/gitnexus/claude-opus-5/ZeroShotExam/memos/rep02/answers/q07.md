`web/src/connect.ts`

This is the single file where all ConnectRPC service clients are created (`web/src/connect.ts:184-203`). It builds a `createConnectTransport` against `window.location.origin` with binary format, credentialed fetch, and an auth interceptor, then exports one client per service:

- `instanceServiceClient`, `authServiceClient`, `userServiceClient` (`web/src/connect.ts:192-194`)
- `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient` (`web/src/connect.ts:197-200`)
- `identityProviderServiceClient` (`web/src/connect.ts:203`)

The same file also creates a separate interceptor-free `refreshTransport` and its `refreshAuthClient` (`web/src/connect.ts:65-72`) to avoid recursion during token refresh.
