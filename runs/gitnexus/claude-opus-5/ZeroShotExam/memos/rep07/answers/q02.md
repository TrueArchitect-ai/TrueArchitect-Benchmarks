**sqlite, mysql, postgres**

The migrations live under `store/migration/`, with one directory per dialect:

- `store/migration/sqlite/` — versions 0.2 through 0.30, plus `LATEST.sql`
- `store/migration/mysql/` — versions 0.17 through 0.30, plus `LATEST.sql`
- `store/migration/postgres/` — versions 0.19 through 0.30, plus `LATEST.sql`

The whole tree is embedded via `//go:embed migration` in `store/migrator.go:44`, and the dialect subdirectory is selected at runtime by the configured driver name in `getMigrationBasePath()` (`store/migrator.go:254-256`), which formats `migration/%s/` from `profile.Driver`. The same three driver names are the only ones accepted in `NewDBDriver` at `store/db/db.go:18-27`.
