**Mechanism:** Server-Sent Events (SSE) over a plain HTTP `GET /api/v1/sse` endpoint (`Content-Type: text/event-stream`, `X-Accel-Buffering: no`, 30s `: heartbeat` comment pings), not WebSockets.

**Hub:** `server/router/api/v1/sse_hub.go` — `SSEHub` (mutex-guarded `map[*SSEClient]struct{}`) with `NewSSEHub`/`Subscribe`/`Unsubscribe`/`Broadcast`/`Close`. Each client gets a 32-event buffered channel; events are dropped rather than blocking a slow client, and `canReceive` (sse_hub.go:134) filters `Private` memos to the creator or admins.

- Transport handler: `server/router/api/v1/sse_handler.go` — `RegisterSSERoutes` + `handleSSE` (Bearer-token auth via `auth.Authenticator`).
- Wiring: created in `server/router/api/v1/v1.go:57`, route registered at v1.go:125; shut down via `Server.closeLongLivedConnections` (`server/server.go:202`).
- Browser side: `web/src/hooks/useLiveMemoRefresh.ts:203`.
