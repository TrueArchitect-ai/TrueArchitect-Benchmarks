2. **The `store/db/mysql` package has exactly one importer.** `grep -rn "store/db/mysql" --include=*.go` returns a single line: the import in `store/db/db.go:8`. No other package can construct the driver, since `DB` and `NewDB` are only reachable through that package.

3. **The only `DB` struct literals** are `driver := DB{profile: profile}` inside `NewDB` itself (`store/db/mysql/mysql.go:29`), and one in-package test at `store/db/mysql/auth_config_test.go:12` — `db := &DB{}`, a zero-value struct (nil `*sql.DB`, nil profile) used solely to invoke the pure method `IsRetryableAuthenticationMutationError`. That's not a constructed driver, and it's not reachable outside the package's own tests.

4. **All driver consumers go through the factory.** `NewDBDriver` callers are `store/test/store.go:28`, `store/test/store.go:50`, and `server/router/api/v1/test/memo_service_benchmark_test.go:70` — including the test harness, which selects MySQL via profile rather than importing the package.
