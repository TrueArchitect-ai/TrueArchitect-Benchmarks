**Computation site** — `memopayload.RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual parsing to the goldmark-backed markdown service: `(*service).ExtractAll` in `internal/markdown/markdown.go:356` (single AST walk). The result is written onto `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:85-86`), persisted as the memo's `payload` column (`storepb.MemoPayload`, schema in `proto/store/memo.proto:7-27`).

**Triggers** — recomputation happens exactly where content is written:
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` (rebuilt on the `create` struct before `Store.CreateMemo`).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the new payload is put on `update.Payload` alongside `update.Content`. Other mask paths (visibility, pinned, location, …) do not rebuild it.
- Bulk backfill — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72` walks all memos in batches of 100, rebuilding and `UpdateMemo`-ing each. Note this runner is currently not wired up: `memopayload.NewRunner` has no callers (`server/server.go` only starts the s3presign runner at `server.go:163`), so it's dormant backfill code.

**Extracted properties** — from `ExtractAll` (`internal/markdown/markdown.go:356-421`), mirrored by the single-purpose `ExtractProperties` (`markdown.go:193`):
- `Tags` — every `#tag` node, deduplicated with original case preserved (`uniquePreserveCase`).
- `Property.Title` — text of the first block-level child if it is an H1 heading.
- `Property.HasLink` — any `KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any task checkbox; and `Property.HasIncompleteTasks` when a checkbox is unchecked.
- (`ExtractedData.Mentions` is also collected in the same pass but is not stored in the payload — it's used for mention notifications.)

These feed list filtering (`store.FindMemoPayload` with `TagSearch`/`HasLink`/`HasTaskList`/`HasCode`/`HasIncompleteTasks`, `store/memo.go:84-91`), user stats (`server/router/api/v1/user_service_stats.go:148-151`), and the API response via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:47-49, 315-325`).

One distinct thing, in case it's what you mean by "previews": the memo's `snippet` is *not* stored in the payload — it is regenerated per response by `getMemoContentSnippet` → `MarkdownService.GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-91`), applied in `memo_service_converter.go:76-80` and for relation previews at `memo_service_converter.go:221-273` / `memo_relation_service.go:154-173`.
