**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` is the abstraction package: it defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation must return. It has no provider-specific code and no other files.
- `internal/idp/oauth2/oauth2.go` is the only concrete protocol implementation ("Package oauth2 implements the OAuth2 identity provider integration"). It exposes `NewIdentityProvider(*storepb.OAuth2Config)`, `ExchangeToken` (with PKCE `code_verifier` support), and `UserInfo`, mapping raw provider JSON into `idp.IdentityProviderUserInfo` via the configured field mapping.

Supporting evidence that OAuth2 is the sole shipped protocol:
- `server/router/api/v1/auth_service_sso.go:119-121` dispatches on `storepb.IdentityProvider_OAUTH2` and constructs `oauth2.NewIdentityProvider(...)`; there is no branch for any other type.
- `proto/gen/store/idp.pb.go:154-218` — `IdentityProviderConfig` is a `oneof` whose only variant is `Oauth2Config`, and the `IdentityProvider_Type` enum has just `TYPE_UNSPECIFIED` and `OAUTH2`. No SAML/OIDC-specific types exist.
