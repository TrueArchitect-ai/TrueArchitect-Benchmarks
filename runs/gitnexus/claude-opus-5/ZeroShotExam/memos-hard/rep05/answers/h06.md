**Convergence function — `webhook.Post` — `internal/webhook/webhook.go:120`** (the actual `safeClient.Do(req)` at line 152). Every path reaches it identically: the dispatch helpers call `webhook.PostAsync` (`webhook.go:184`), which enqueues onto `asyncPostQueue`; four worker goroutines started in `init()` (`webhook.go:42`) drain the queue and call `Post`. So `PostAsync` is the single enqueue funnel and `Post` is the single function that builds, signs (HMAC-SHA256, Standard Webhooks headers), and sends the outbound request.

Note: the outbound request is SSRF-guarded at dial time by `safeDialContext` (`internal/webhook/webhook.go:58`), which rejects reserved/private IPs after resolution, plus URL validation in `internal/webhook/validate.go`.
