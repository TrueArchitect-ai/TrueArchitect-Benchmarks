### The delivery path

1. Memo mutations call `DispatchMemoCreatedWebhook` / `DispatchMemoUpdatedWebhook` / `DispatchMemoDeletedWebhook` / `DispatchMemoCommentCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go:15-46`. These load the creator's configured webhooks and build a `WebhookRequestPayload`.
2. Each payload goes to `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which just enqueues onto a bounded 128-slot channel and drops (with a warning) if full.
3. Four goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain the queue and call `Post` (`internal/webhook/webhook.go:120`) — this is where the outbound request is actually built, optionally HMAC-signed (Standard Webhooks `webhook-id`/`-timestamp`/`-signature` headers), and executed via `safeClient.Do(req)` at line 152.

### The SSRF protection

Two layers, both keyed on `isReservedIP` (`internal/webhook/validate.go:44`), which tests against the parsed `reservedCIDRs` list at `internal/webhook/validate.go:14-23` (loopback, RFC-1918, link-local incl. `169.254.169.254` IMDS, and IPv6 `::1`/`fc00::/7`/`fe80::/10`):

- **Dial-time (the real enforcement):** `safeClient` is constructed with a custom `Transport.DialContext = safeDialContext` (`internal/webhook/webhook.go:32-37`). `safeDialContext` (`internal/webhook/webhook.go:59`) re-resolves the host and refuses the connection if *any* resolved IP is reserved. Because this happens at dial time rather than at save time, it also defeats DNS rebinding — a hostname that passed validation but later resolves to `127.0.0.1` still fails.
- **Save-time (input validation):** `ValidateURL` (`internal/webhook/validate.go:62`) is called when a user creates or updates a webhook — `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. It enforces absolute URL, http/https scheme only, and resolvable non-reserved IPs, returning a gRPC `InvalidArgument` for a clean API error.

### One thing worth flagging

`AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global kill switch — when true, `isReservedIP` returns false unconditionally and *both* layers are disabled. Its stated purpose is self-hosted deployments targeting LAN services, but grep across all non-test Go files shows nothing ever assigns it: no CLI flag, env var, or profile field wires it up. It is effectively dead as a user-facing option today (defaults to `false`, so the protection is always on), but anything that sets it disables the dial-time guard globally, not just for the intended webhook.
