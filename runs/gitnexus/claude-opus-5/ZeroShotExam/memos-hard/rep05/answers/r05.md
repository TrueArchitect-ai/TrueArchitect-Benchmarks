**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across the entire tree (excluding `node_modules`/`.git`) returns zero hits — no `.graphql`/`.gql` files, no schema-first SDL, no resolver layer, and no GraphQL server dependency in `go.mod`. Memos has never exposed a GraphQL endpoint.

**Actual API surface: Protobuf-defined gRPC / Connect, with a REST (gRPC-Gateway) transcoding layer.**

**1. Schema source of truth — `proto/api/v1/*.proto`**

The public API is defined as Protobuf service definitions:

- `proto/api/v1/memo_service.proto` — `service MemoService` (`CreateMemo`, `ListMemos`, `GetMemo`, `UpdateMemo`, `DeleteMemo`, memo attachments/relations/comments/reactions/shares, `GetLinkMetadata`)
- `proto/api/v1/user_service.proto`
- `proto/api/v1/auth_service.proto`
- `proto/api/v1/attachment_service.proto`
- `proto/api/v1/instance_service.proto`
- `proto/api/v1/shortcut_service.proto`
- `proto/api/v1/idp_service.proto`
- `proto/api/v1/ai_service.proto`
- `proto/api/v1/common.proto` — shared enums/messages

Each `rpc` carries `google.api.http` annotations that define its REST binding (e.g. `/api/v1/ai:transcribe`). Internal persistence messages live separately under `proto/store/*.proto` and are not part of the public surface.

**2. Code generation — `proto/buf.gen.yaml`**

`buf generate` fans the protos out to: Go structs + gRPC + **ConnectRPC** + **grpc-gateway** stubs into `proto/gen/`, a gnostic-generated OpenAPI document, and TypeScript clients into `web/src/types/proto`.

**3. Generated HTTP contract — `proto/gen/openapi.yaml`**

This is the closest analogue to "the schema for the public API" as a single browsable document: an OpenAPI 3.0.3 spec generated by `protoc-gen-openapi`, listing every `/api/v1/...` path and request/response schema. It is embedded into the binary via `proto/openapi_embed.go` (`//go:embed gen/openapi.yaml`, exposed by `OpenAPIYAML()`).

**4. Server implementations — `server/router/api/v1/`**

Go handlers implementing the generated interfaces: `memo_service.go`, `user_service.go`, `auth_service.go`, `attachment_service.go`, `instance_service.go`, etc., wired up in `connect_services.go` / `connect_handler.go`, with auth in `authz.go` and `acl_config.go`. The gateway is mounted in `server/server.go:88` (`apiV1Service.RegisterGateway`).

**5. Non-proto HTTP endpoints** (also public, defined outside the protos): `server/router/rss` (RSS feeds), `server/router/mcp` (Model Context Protocol), `server/router/fileserver` (attachment serving), and a `healthz` endpoint registered at `server/server.go:66`.

So if you're looking for where to add or change a public API operation, edit the relevant `proto/api/v1/*_service.proto`, run `buf generate` (per `proto/README.md`), then implement in `server/router/api/v1/`.
