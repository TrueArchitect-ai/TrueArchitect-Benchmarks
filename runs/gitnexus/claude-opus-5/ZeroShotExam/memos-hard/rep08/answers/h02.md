## How it fits together

**Trigger → dispatch:** memo create/update/delete/comment events call `DispatchMemo*Webhook` in `server/router/api/v1/memo_service_webhooks.go:15-46`, which loads the creator's registered webhooks and calls `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto a bounded 128-slot channel, dropping with a warning when full; four worker goroutines started in `init()` (`webhook.go:42-55`) drain that queue and call `Post`.

**Where the outbound request actually executes:** `Post` (`internal/webhook/webhook.go:120-180`) marshals the payload, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`), and issues the POST via the shared `safeClient` at `webhook.go:152`.

**SSRF protection — two layers:**

1. *Dial-time (the load-bearing one).* `safeClient` (`webhook.go:32-37`) is built with a custom `Transport.DialContext = safeDialContext`. `safeDialContext` (`webhook.go:59-77`) splits host/port, resolves the host itself via `net.DefaultResolver.LookupHost`, and rejects the connection if **any** resolved IP is reserved. Because the check happens at dial time on every request, it also defeats DNS rebinding — a name that passed validation at registration cannot later resolve to an internal address at delivery time.

2. *Registration-time.* `webhook.ValidateURL` (`internal/webhook/validate.go:62`) is called when a user creates or updates a webhook (`server/router/api/v1/user_service_webhooks.go:74,161,182`). It enforces a parseable absolute URL, an `http`/`https` scheme, and that the hostname doesn't resolve to a reserved IP — returning a gRPC `InvalidArgument` so bad URLs are rejected up front rather than failing silently later.

Both layers share `isReservedIP` (`internal/webhook/validate.go:44`), which tests against `reservedCIDRs` (`validate.go:14-23`): IPv4 loopback, all three RFC-1918 ranges, link-local `169.254.0.0/16` (explicitly covering the cloud IMDS address `169.254.169.254`), plus IPv6 `::1/128`, `fc00::/7`, and `fe80::/10`. These are parsed once at startup in `init()` (`validate.go:28-36`).

**One caveat worth flagging:** `AllowPrivateIPs` (`internal/webhook/validate.go:41`) is a global escape hatch — when true, `isReservedIP` returns false unconditionally and **both** layers of SSRF protection are disabled. Grepping the non-test Go sources, nothing outside `validate.go` ever assigns it, so it's currently a package-level var with no CLI flag, env var, or config wiring; it defaults to `false` (protection on) and is only flipped by tests.

Secondary hardening in the same path: a 30s client timeout (`webhook.go:27`), and the response body is read through `io.LimitReader(resp.Body, 1<<20)` (`webhook.go:158`) so a hostile endpoint can't exhaust memory.
