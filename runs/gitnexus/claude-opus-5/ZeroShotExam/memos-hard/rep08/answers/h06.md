**Convergence function — `Post`, `internal/webhook/webhook.go:120`**

The chain: each `Dispatch*Webhook` method funnels through `dispatchMemoRelatedWebhook` (`memo_service_webhooks.go:48`, except the comment variant which inlines the same loop at `:30`), loads the owner's stored webhooks via `s.Store.GetUserWebhooks`, sets `payload.URL = hook.Url` (the user-configured URL, registered through `CreateUserWebhook`/`UpdateUserWebhook` in `user_service_webhooks.go:53`/`:106`), and calls `webhook.PostAsync` (`webhook.go:184`). `PostAsync` only enqueues onto `asyncPostQueue`; the four worker goroutines started in `init()` (`webhook.go:42-55`) call `Post`, which is the sole place the outbound request is built and issued — `safeClient.Do(req)` at `webhook.go:152`.

So `PostAsync` is the single entry point the handlers converge on, and `Post` is the single function that performs delivery.

Two guards sit on this path: `ValidateURL` (`internal/webhook/validate.go:62`) rejects non-http(s) schemes and hostnames resolving to reserved/private IPs at registration time, and `safeDialContext` (`webhook.go:59`) re-checks at dial time to defeat DNS rebinding.
