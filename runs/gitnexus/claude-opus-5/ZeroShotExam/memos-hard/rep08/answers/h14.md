**Computation site**

- `RebuildMemoPayload` — `server/runner/memopayload/runner.go:74` — the single entry point. It ensures `memo.Payload` exists, calls the markdown service, and assigns `memo.Payload.Tags` and `memo.Payload.Property` (runner.go:85-86).
- The actual extraction is `(*service).ExtractAll` — `internal/markdown/markdown.go:356` — one goldmark parse + one `gast.Walk` over the AST. (`ExtractProperties` at `internal/markdown/markdown.go:193` and `ExtractTags` at :141 are the equivalent single-purpose variants; the rebuild path uses `ExtractAll` for the single-pass version.)
- Stored shape: `storepb.MemoPayload` / `MemoPayload_Property` (`proto/gen/store/memo.pb.go:25-27`, `:85`), persisted in the memo's `payload` column — so it's derived, not user-set.

**Triggers**

- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before `Store.CreateMemo`. This also covers comment creation, which routes through `CreateMemo` (`memo_service_comments.go:56`).
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, only inside the `path == "content"` branch of the update mask; the rebuilt payload is put on `update.Payload` alongside the new content (`:449-450`). Updates to visibility/pinned/state/timestamps do not recompute it.
- Bulk backfill: `Runner.RunOnce` — `server/runner/memopayload/runner.go:27` — pages through all memos in batches of 100, rebuilds each payload and writes it back. Note this runner is currently defined but not wired up anywhere; `server/server.go:163` only invokes the s3presign runner, and `memopayload` is imported only by `memo_service.go`.

**What the computation extracts**

From the AST walk (`markdown.go:370-405`):
- `Tags` — `#tag` nodes (`mast.TagNode`), skipping tags nested inside links/images (`asMemoTagNode`, `markdown.go:133`); deduped case-preserving in `ExtractTags`.
- `Property.Title` — plain text of the document's *first* block child only if it's an H1 heading (`extractHeadingText`, `markdown.go:178`).
- `Property.HasLink` — any `gast.KindLink`.
- `Property.HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `Property.HasTaskList` — any `east.KindTaskCheckBox`; and `Property.HasIncompleteTasks` when such a checkbox is unchecked.
- `Mentions` (`@user`, lowercased) is also collected by `ExtractAll`, but `RebuildMemoPayload` discards it — mentions are consumed separately for notifications (`server/router/api/v1/memo_mention_helpers.go:32`).

These properties are what the store filters on (`store/test/memo_filter_test.go:523-610`) and what the API exposes as `Memo.Property` via `convertMemoPropertyFromStore` (`server/router/api/v1/memo_service_converter.go:315`).

One related field is *not* stored: the preview `Snippet` is generated on every read in the converter (`memo_service_converter.go:76` → `getMemoContentSnippet` → `GenerateSnippet(content, 64)`, `memo_service_webhooks.go:83`), so it never needs a rebuild trigger.
