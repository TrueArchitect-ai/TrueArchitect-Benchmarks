**No** — the MySQL driver is never constructed directly outside the factory in production code. The only literal `DB{}` outside `NewDB` is a zero-value in a same-package unit test.

**Evidence:**

1. **The factory is the sole construction site.** `store/db/db.go:22` — `NewDBDriver` switches on `profile.Driver` and calls `mysql.NewDB(profile)` for the `"mysql"` case. The actual struct is built inside that constructor at `store/db/mysql/mysql.go:29` (`driver := DB{profile: profile}`).

2. **No other package imports `store/db/mysql`.** Grepping every Go importer of `usememos/memos/store/db/...` yields exactly one hit for the mysql subpackage — `store/db/db.go:8`. The other importers (`store/test/store.go:18`, `server/router/api/v1/test/memo_service_benchmark_test.go:15`) import the parent `store/db` package and go through `NewDBDriver` (`store/test/store.go:28`, `:50`; `memo_service_benchmark_test.go:70`). `store/deployment_config_test.go:19` and `store/demo_seed_test.go:13` import only `store/db/sqlite`. Since `DB` and `NewDB` are only reachable via that import path, no external direct construction is possible.

3. **Within the mysql package**, `grep "DB{" store/db/mysql/*.go` returns just two lines: `mysql.go:29` (inside `NewDB`) and `store/db/mysql/auth_config_test.go:12` (`db := &DB{}`) — a zero-valued struct with no `*sql.DB` or config, used purely as a receiver to test `IsRetryableAuthenticationMutationError` against synthetic `mysqldriver.MySQLError` values (`auth_config_test.go:13-15`). That's a test fixture, not a driver instantiation.

4. **Related mysql references are not driver construction.** `store/test/containers.go:363` uses `mysqldriver.ParseDSN` for testcontainer DSN rewriting; `store/db/mysql/auth_config.go:15` type-asserts `*mysqldriver.MySQLError`. Both use the upstream `go-sql-driver/mysql` package, not the memos `DB` type.

For contrast, the postgres driver does the same thing at `store/db/postgres/postgres.go:33` (`var driver store.Driver = &DB{...}` inside its own `NewDB`), so the pattern is consistent across drivers.
