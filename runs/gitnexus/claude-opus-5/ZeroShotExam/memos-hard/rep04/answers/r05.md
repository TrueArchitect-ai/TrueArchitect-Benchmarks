**Premise correction:** There is no GraphQL schema in this repository. A repo-wide search for `graphql`/`gqlgen`/`apollo`/`urql`/`relay` returns zero hits in Go sources, TypeScript sources, `go.mod`, and `web/package.json`. Memos does not expose a GraphQL API at all.

**Actual API surface: Protobuf/gRPC, defined in `proto/api/v1/`**

The schema of record is a set of `.proto` files:

- `proto/api/v1/memo_service.proto` — `MemoService` (CreateMemo, ListMemos, GetMemo, UpdateMemo, DeleteMemo, comments, relations, reactions, shares, …)
- `proto/api/v1/user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`
- `proto/api/v1/common.proto` — shared types
- `proto/api/v1/README.md` — states the API follows the [Google AIP](https://google.aip.dev/) guidelines

**Code generation** is driven by Buf (`proto/buf.yaml`, `proto/buf.gen.yaml`). From the single proto source, `buf.gen.yaml` emits five artifacts:

| Plugin | Output |
|---|---|
| `protocolbuffers/go`, `grpc/go` | Go message + gRPC stubs → `proto/gen/` |
| `connectrpc/go` | Connect handlers (used by the browser client, replacing grpc-web) |
| `grpc-ecosystem/gateway` | gRPC-Gateway → the REST/JSON `/api/v1/*` surface |
| `community/google-gnostic-openapi` | `proto/gen/openapi.yaml` — the REST spec |
| `bufbuild/es` | TypeScript types → `web/src/types/proto` |

**Runtime wiring:** `server/router/api/v1/v1.go` — `APIV1Service` embeds each `Unimplemented*ServiceServer` (v1.go:22-31) and `RegisterGateway` (v1.go:64) mounts the gateway mux at `/api/v1/*` and `/file/*`, plus a Connect mux for browser clients.

So the closest analogue to "the public API schema" is twofold: the `.proto` files in `proto/api/v1/` (source of truth) and the generated `proto/gen/openapi.yaml` (OpenAPI 3.0.3 description of the public REST surface), which is embedded into the binary via `proto/openapi_embed.go` and consumed by the MCP router at `server/router/mcp/openapi.go`.
