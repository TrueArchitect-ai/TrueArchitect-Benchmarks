**Delivery function — `Post` at `internal/webhook/webhook.go:120`** (executed on background goroutines); **protection mechanism — `safeDialContext` at `internal/webhook/webhook.go:59`, backed by `isReservedIP`/`reservedCIDRs` in `internal/webhook/validate.go:14-54`.**

**The outbound path**

1. Memo mutations call `DispatchMemoCreatedWebhook` / `Updated` / `Deleted` / `CommentCreated` in `server/router/api/v1/memo_service_webhooks.go:15-46`, which loads the user's webhooks and calls `webhook.PostAsync(payload)` (`memo_service_webhooks.go:43`, `:71`).
2. `PostAsync` (`internal/webhook/webhook.go:184`) only enqueues onto a bounded 128-slot channel `asyncPostQueue`, dropping with a warning if full.
3. Four worker goroutines started in `init()` (`internal/webhook/webhook.go:42-55`) drain that queue and call `Post`. **`Post` (`internal/webhook/webhook.go:120-180`) is where delivery actually executes** — it marshals the JSON body, optionally adds Standard Webhooks HMAC-SHA256 headers (`webhook-id`/`webhook-timestamp`/`webhook-signature`), and issues `safeClient.Do(req)` at `webhook.go:152`.

**The SSRF protection**

- The real guard is at dial time: `safeClient` (`internal/webhook/webhook.go:32-37`) is an `http.Client` whose `Transport.DialContext` is `safeDialContext`. That function (`webhook.go:59-77`) resolves the host itself and rejects the connection if *any* resolved IP satisfies `isReservedIP`. Because the check happens on each dial rather than at save time, it also defeats DNS rebinding and redirect-based bypasses.
- `isReservedIP` (`internal/webhook/validate.go:44`) tests against `reservedNetworks`, parsed once at startup from `reservedCIDRs` (`validate.go:14-23`): loopback, RFC-1918 ranges, 169.254.0.0/16 (cloud IMDS), and the IPv6 equivalents `::1/128`, `fc00::/7`, `fe80::/10`.
- A second, earlier layer is `webhook.ValidateURL` (`internal/webhook/validate.go:62`), called when a user creates or updates a webhook in `server/router/api/v1/user_service_webhooks.go:74`, `:161`, `:182`. It enforces http/https scheme and the same reserved-IP check, returning gRPC `InvalidArgument`. This is a UX/early-rejection layer only — it's TOCTOU-vulnerable on its own, which is why the dialer check exists.
- Both layers are globally disabled by the `AllowPrivateIPs` bool (`internal/webhook/validate.go:41`), an intentional escape hatch for self-hosted deployments, exposed as the `--allow-private-webhooks` flag (per `CHANGELOG.md:121`).
