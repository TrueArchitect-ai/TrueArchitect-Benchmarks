**`RebuildMemoPayload` → `markdown.Service.ExtractAll`; memo create + content update (plus the batch backfill runner); tags + the five calculated `Property` fields (title, has_link, has_code, has_task_list, has_incomplete_tasks).**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` ensures `memo.Payload` exists, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns `memo.Payload.Tags = data.Tags` and `memo.Payload.Property = data.Property` (runner.go:80-86).
- The actual extraction is `internal/markdown/markdown.go:356` — `(*service).ExtractAll`, a single goldmark AST walk (`gast.Walk`) over the parsed content.
- Shape is defined in `proto/store/memo.proto:15` (`MemoPayload.Property`, commented "The calculated properties from the memo content"), generated at `proto/gen/store/memo.pb.go:84`.

**Triggers (recomputation)**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108`, before the store insert.
- `UpdateMemo`, only when the update mask includes `content` — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written via `update.Payload = memo.Payload` (line 451).
- Bulk backfill: `memopayload.Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) rebuilds every memo's payload in batches of 100 and persists via `store.UpdateMemo`. Note: this runner is defined but not currently wired up anywhere — `server/server.go:163` only invokes the s3presign runner, and `grep memopayload` shows no `NewRunner` call site. So in practice only create and content-update recompute.

**What the computation extracts** (`internal/markdown/markdown.go:356-421`)
- `Tags` — from memo tag nodes, deduplicated case-preserving via `uniquePreserveCase` (also collects `Mentions`, used separately by `server/router/api/v1/memo_mention_helpers.go:32`, not stored in the payload).
- `Property.Title` — text of the first block-level child of the document when it is an H1 heading (`extractHeadingText`).
- `Property.HasLink` — any `gast.KindLink` node.
- `Property.HasCode` — any code block, fenced code block, or code span.
- `Property.HasTaskList` — any `east.KindTaskCheckBox`.
- `Property.HasIncompleteTasks` — a task checkbox with `IsChecked == false`.

**Consumption:** surfaced to the API in `server/router/api/v1/memo_service_converter.go:48-50` (`memoMessage.Tags` / `Property` via `convertMemoPropertyFromStore`, line 315) alongside the separately-generated `Snippet` (line 76), and used as filter factors in the web client (e.g. `property.hasTaskList` in `web/src/hooks/useMemoFilters.ts:75`).
