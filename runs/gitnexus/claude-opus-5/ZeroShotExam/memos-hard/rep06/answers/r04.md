**Premise correction:** Neither. There is no message broker in this repository at all — no NATS, no RabbitMQ, no AMQP/Kafka/Redis-queue dependency. A case-insensitive grep for `nats|rabbitmq|amqp|kafka|celery|sidekiq` across the Go/TS/YAML/TOML sources returns nothing, and `go.mod` has no broker client. There is also no "worker" process or queue declaration to point at — webhook delivery runs inside the memos server process.

**Actual mechanism:** an in-process buffered Go channel with a fixed goroutine pool, all in `internal/webhook/webhook.go`:

- `internal/webhook/webhook.go:39` — the "queue" is `asyncPostQueue = make(chan *WebhookRequestPayload, 128)`, a package-level channel with capacity 128. That line is the closest thing to a queue declaration.
- `internal/webhook/webhook.go:42-55` — an `init()` function spawns 4 goroutines, each ranging over `asyncPostQueue` and calling `Post(payload)`. These are the "workers."
- `internal/webhook/webhook.go:184-196` — `PostAsync` is the producer. It does a non-blocking `select` send: if the buffer is full, the payload is **dropped** with a `slog.Warn`, not retried or persisted.
- `internal/webhook/webhook.go:120-180` — `Post` does the actual HTTP POST, with Standard Webhooks HMAC-SHA256 signing (`webhook-id` / `webhook-timestamp` / `webhook-signature` headers) and a 30s timeout via `safeClient`, whose dialer rejects reserved/private IPs (`safeDialContext`, line 59) to block SSRF.

Producers are the API-layer dispatchers in `server/router/api/v1/memo_service_webhooks.go` (`DispatchMemoCreatedWebhook`, `...Updated`, `...Deleted`, `DispatchMemoCommentCreatedWebhook`), which look up per-user webhook targets via `s.Store.GetUserWebhooks` and call `webhook.PostAsync` per hook.

Practical consequences of this being a channel rather than a broker: delivery is best-effort and in-memory only — nothing survives a process restart, there is no retry on failure (a non-2xx just logs a warning at line 47), no dead-letter path, and no cross-instance coordination if memos is run replicated.
