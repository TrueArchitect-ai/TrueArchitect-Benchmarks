Evidence:

1. **The factory is the sole construction site in non-test code.** `mysql.NewDB(profile)` is called exactly once, in `store/db/db.go:22`, inside `NewDBDriver` (`store/db/db.go:14`), which switches on `profile.Driver`.

2. **Nothing else imports the package.** `grep -rn "store/db/mysql" --include=*.go .` returns a single hit: the import in `store/db/db.go:8`. No other package — server, cmd, migrator, or test harness — can construct it, since `DB` is only reachable through that package.

3. **All callers go through the factory.** The only `NewDBDriver` call sites are `store/test/store.go:28`, `store/test/store.go:50`, and `server/router/api/v1/test/memo_service_benchmark_test.go:70`; the MySQL integration test setup in `store/test/containers.go` only builds a DSN (it imports `go-sql-driver/mysql` for DSN parsing, not the memos driver).

4. **The one direct construction is intra-package and inert.** `store/db/mysql/auth_config_test.go:12` does `db := &DB{}` to call the pure helper `IsRetryableAuthenticationMutationError`. It's in `package mysql` itself, has nil `db`/`profile`/`config` fields, and opens no connection — so it isn't a real driver instantiation, and it is not "outside" the package.
