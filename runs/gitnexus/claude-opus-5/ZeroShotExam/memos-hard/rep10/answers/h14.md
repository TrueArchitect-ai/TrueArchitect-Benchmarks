**Computation site; triggers; extracted properties**

**Computation site**
- `server/runner/memopayload/runner.go:74` — `RebuildMemoPayload(ctx, memo, markdownService)` is the single entry point. It ensures `memo.Payload` exists, calls the markdown service once, and assigns `memo.Payload.Tags` and `memo.Payload.Property` (`runner.go:80-87`).
- The actual extraction is `(*service).ExtractAll` in `internal/markdown/markdown.go:355` — a single goldmark parse + one `gast.Walk` over the AST. (`ExtractProperties`, `internal/markdown/markdown.go:193`, is the standalone properties-only variant of the same walk.)
- The stored shape is `MemoPayload.Property`, defined in `proto/store/memo.proto:15-22` ("The calculated properties from the memo content"), and surfaced to the API by `convertMemoPropertyFromStore` in `server/router/api/v1/memo_service_converter.go:314-325` (set on the API memo at `memo_service_converter.go:50-51`).

**Triggers (recomputation)**
1. **Memo creation** — `CreateMemo` calls it after the content-length check: `server/router/api/v1/memo_service.go:108`.
2. **Memo update, only when `content` is in the update mask** — `server/router/api/v1/memo_service.go:447`; the rebuilt payload is written via `update.Payload = memo.Payload` (`:452`). Other mask paths (visibility, pinned, state, timestamps) do not recompute.
3. **Bulk backfill** — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27-72`) rebuilds every memo in batches of 100 and persists via `Store.UpdateMemo`. Note this runner is not currently wired up anywhere — `memopayload.NewRunner` has no callers in the tree, so only paths 1 and 2 fire in practice.

**Extracted properties**
From the AST walk (`markdown.go:369-410`, mirrored in `ExtractProperties` `markdown.go:202-234`):
- `Title` — text of the first H1 heading, only if it is the document's first block-level child (`extractHeadingText`).
- `HasLink` — any `gast.KindLink` node.
- `HasCode` — any `KindCodeBlock`, `KindFencedCodeBlock`, or `KindCodeSpan`.
- `HasTaskList` — any `east.KindTaskCheckBox`.
- `HasIncompleteTasks` — a task checkbox with `IsChecked == false`.
- Alongside `Property`, the same pass fills `Payload.Tags` (`#tag` nodes) and `Mentions` (lowercased `@user`), though `RebuildMemoPayload` only persists `Tags` and `Property`.

One adjacent thing worth separating out: the list/preview **`snippet`** is *not* part of this payload — it's computed per-response at read time by `getMemoContentSnippet` → `GenerateSnippet(content, 64)` (`server/router/api/v1/memo_service_webhooks.go:83-85`, used at `memo_service_converter.go:76-80`), so it is never stored or triggered by the rebuild.
