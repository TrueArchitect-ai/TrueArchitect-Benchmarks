**No — in production code.** The only construction of the MySQL driver outside the factory is a zero-value struct literal in a unit test.

**Evidence:**

1. **The factory is the sole caller of the constructor.** `mysql.NewDB(profile)` is called exactly once in the entire repo, at `store/db/db.go:22`, inside `NewDBDriver`'s `switch profile.Driver` (alongside `sqlite.NewDB` at :20 and `postgres.NewDB` at :24). A repo-wide grep for `mysql.NewDB(` returns that single hit.

2. **The package is imported exactly once.** `grep -rn "usememos/memos/store/db/mysql"` over all `*.go` files returns one result: `store/db/db.go:8`. No other Go file in the codebase imports `store/db/mysql`, so no external package can name the `mysql.DB` type at all — the only external construction path would have to be through the factory.

3. **All factory consumers go through `NewDBDriver`.** Its callers are `store/test/store.go:28`, `store/test/store.go:50`, and `server/router/api/v1/test/memo_service_benchmark_test.go:70` — all pass a `profile` and receive the `store.Driver` interface, never the concrete type.

4. **The one direct construction is in-package and test-only.** `store/db/mysql/auth_config_test.go:12` does `db := &DB{}` — a zero-value literal (nil `db`, `profile`, `config`) built to call the pure error-classification helper `IsRetryableAuthenticationMutationError` (`store/db/mysql/auth_config.go:15-19`), which only inspects the error argument and never touches the struct fields. Being in `package mysql` (same package, not `mysql_test`), it can reference the unexported `DB` type directly. Note this bypasses `NewDB` entirely, so it is a direct construction in the literal sense — it just never produces a usable driver.

For contrast, the Postgres package does the same thing more extensively: `store/db/postgres/auth_config_test.go:12` and three sites in `store/db/postgres/user_setting_test.go` (:36, :194, :257, the latter injecting a `*sql.DB`). MySQL has only the one.

**Summary:** no non-test code constructs the MySQL driver outside `NewDBDriver`; the sole direct construction is the throwaway `&DB{}` at `store/db/mysql/auth_config_test.go:12`.
