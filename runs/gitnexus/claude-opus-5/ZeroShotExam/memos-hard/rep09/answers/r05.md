**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for "graphql" across all Go, TypeScript, JSON, proto, and Markdown sources returns zero hits. Memos does not expose a GraphQL API.

**Actual API surface:** The public API is defined in **Protocol Buffers** under `proto/api/v1/`, and served as gRPC + Connect + a REST/JSON gateway.

**Schema definitions** — `proto/api/v1/`:
- `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, `common.proto`

REST paths are declared inline on each RPC via `google.api.http` annotations — e.g. `proto/api/v1/memo_service.proto:30` maps `ListMemos` to `GET /api/v1/memos`, and `:35` maps `GetMemo` to `GET /api/v1/{name=memos/*}`. The design follows Google's AIP guidelines (`proto/api/v1/README.md`).

Internal persistence messages live separately in `proto/store/` (`memo.proto`, `user_setting.proto`, etc.) — those are not part of the public surface.

**Code generation** — `proto/buf.gen.yaml` runs `buf generate` with plugins for protobuf-go, gRPC, Connect, grpc-gateway, and gnostic-openapi into `proto/gen/`, plus TypeScript clients into `web/src/types/proto/`.

**Serving** — `server/router/api/v1/v1.go`:
- `RegisterGateway` (`:65`) mounts the grpc-gateway mux at `/api/v1/*` and `/file/*` (`:128-129`) — this is the REST/JSON surface.
- Connect-RPC handlers for browser clients are mounted at `/memos.api.v1.*` (`:144`).
- `APIV1Service` (`:22`) implements all eight services.

**Discoverability** — the nearest analogue to a GraphQL introspection schema is the generated OpenAPI spec at `proto/gen/openapi.yaml`, embedded into the binary via `proto/openapi_embed.go` and consumed by the MCP router (`server/router/mcp/openapi.go`) to build its tool catalog.
