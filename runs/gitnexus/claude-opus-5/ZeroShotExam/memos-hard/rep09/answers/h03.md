`internal/idp`; `internal/idp/oauth2`

- **Abstraction: `internal/idp`** (`internal/idp/idp.go`) — a minimal package defining the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that all providers normalize to.
- **Implementation: `internal/idp/oauth2`** (`internal/idp/oauth2/oauth2.go`) — "Package oauth2 implements the OAuth2 identity provider integration": `IdentityProvider` wrapping `storepb.OAuth2Config`, with `NewIdentityProvider`, `ExchangeToken` (incl. PKCE code verifier), and user-info fetching via configurable field mapping.

OAuth2 is the only concrete protocol shipped — no SAML/LDAP package exists. The wiring is in `server/router/api/v1/auth_service_sso.go:121`, which calls `oauth2.NewIdentityProvider(identityProvider.Config.GetOauth2Config())` and returns an `*idp.IdentityProviderUserInfo`; the stored config type is a oneof in the store proto, with `OAuth2Config` as the sole variant.
