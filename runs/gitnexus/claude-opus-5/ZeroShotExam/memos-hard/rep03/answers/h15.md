Memo visibility is not centralized — each server surface re-implements it. Distinct enforcement sites:

**Single-memo read gate (Connect/gRPC API)** — `server/router/api/v1/memo_service.go:39` (`checkMemoReadAccess`; called by `GetMemo` at :356/:367 for the memo and its parent, and by `ListMemoComments` at `memo_service_comments.go:148`)

**List query visibility filter (Connect/gRPC API)** — `server/router/api/v1/memo_service.go:218-228` (`ListMemos` injects `VisibilityList=[PUBLIC]` for anonymous, or a `creator_id == N || visibility in ["PUBLIC","PROTECTED"]` store filter)

**Comment list filter** — `server/router/api/v1/memo_service_comments.go:157-162` (separate `memoFilter` string built for `ListMemoRelations`); comment creation also gates on the parent memo at `memo_service_comments.go:41`

**Attachment access via API** — `server/router/api/v1/attachment_service.go:422-455` (`checkAttachmentAccess`) and `server/router/api/v1/memo_attachment_service.go:213-225` (`ListMemoAttachments`)

**Attachment/blob serving via HTTP fileserver** — `server/router/fileserver/fileserver.go:650-703` (`checkAttachmentPermission`; own rules including `AllowAnonymous()` and the `share_token` query-param bypass)

**Reactions** — `server/router/api/v1/reaction_service.go:29-40` (`ListMemoReactions`) and `:83` (`UpsertMemoReaction`)

**SSE real-time delivery filter** — `server/router/api/v1/sse_hub.go:133-143` (`SSEClient.canReceive`), fed by `sse_event_helpers.go:29-37`

**User stats aggregation** — `server/router/api/v1/user_service_stats.go:83-92` (`ListAllUserStats`) and `:217-221` (`GetUserStats`)

**In-app notifications** — `server/router/api/v1/user_service_notifications.go:302-316` (`canViewerAccessMemo`)

**Email notifications** — `server/notification/email.go:306-320` (a second, near-duplicate `canViewerAccessMemo` using `store.RoleAdmin` directly instead of `isSuperUser`)

**Mention notification targeting** — `server/router/api/v1/memo_mention_helpers.go:56-72` (`canUserAccessMentionContext`, plus `shouldSkipMentionInbox` at :84)

**RSS feeds** — `server/router/rss/rss.go:90` and `:141` (hard-coded `VisibilityList: [PUBLIC]`)

**Sitemap** — `server/router/frontend/frontend.go:150` (hard-coded `VisibilityList: [PUBLIC]`)
