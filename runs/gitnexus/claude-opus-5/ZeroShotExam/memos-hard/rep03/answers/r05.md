**Premise correction:** There is no GraphQL in this repository. A search for `graphql` across Go, TypeScript, JSON, and Markdown files returns zero hits, and there is no `graphql` dependency in `web/package.json`. Memos' public API is **Protobuf/gRPC-defined**, exposed over REST (via grpc-gateway) and Connect RPC.

**Actual API surface — where it's defined:**

- **Source of truth: `proto/api/v1/*.proto`** — the public v1 API, package `memos.api.v1`:
  - `proto/api/v1/memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `idp_service.proto`, `ai_service.proto`, and shared types in `common.proto`.
  - REST mapping lives inline in each RPC via `google.api.http` annotations — e.g. `proto/api/v1/memo_service.proto:22` maps `CreateMemo` to `POST /api/v1/memos`, and `GetMemo` to `GET /api/v1/{name=memos/*}`.
  - `proto/store/*.proto` is a separate, internal persistence schema — not the public API.

- **Codegen: `proto/buf.gen.yaml`** (run with `buf generate`, see `proto/README.md`) emits:
  - Go message/gRPC/Connect/gateway stubs into `proto/gen/api/v1/` (`*.pb.go`, `*_grpc.pb.go`, `*.pb.gw.go`, `apiv1connect/`),
  - an **OpenAPI document at `proto/gen/openapi.yaml`** (embedded via `proto/openapi_embed.go`) — this is the closest thing to a published schema document for the public API,
  - TypeScript clients into `web/src/types/proto/`.

- **Serving/wiring: `server/router/api/v1/v1.go`** — `RegisterGateway` (line 65) registers every service handler on a grpc-gateway mux served at `/api/v1/*` and `/file/*`, plus Connect handlers served at `/memos.api.v1.*` for the web client (which uses `@connectrpc/connect-web`, `web/package.json:27`). Service implementations are the other files in `server/router/api/v1/`.

- Adjacent non-gRPC surfaces, for completeness: `server/router/rss`, `server/router/mcp`, `server/router/fileserver`, and the SSE endpoint registered in the same `RegisterGateway` function.
