The image URL the browser requests is not an attachment — it's `GET /file/users/{username}/avatar`, and the bytes live in the `user.avatar_url` column as a base64 data URI.

**Where the URL comes from (context):**

- `convertUserFromStore` — `server/router/api/v1/user_service_converters.go:31-38` (rewrites base64 `avatar_url` to `/file/users/{username}/avatar`)
- `UserAvatar` — `web/src/components/UserAvatar.tsx:8` (renders it as `<img src=...>`)

**Serving path (hop per line):**

- `FileServerService.RegisterRoutes` — `server/router/fileserver/fileserver.go:121` (route `GET /file/users/:identifier/avatar` at :124)
- `FileServerService.serveUserAvatar` — `server/router/fileserver/fileserver.go:168` (handler)
- `FileServerService.getCurrentUser` — `server/router/fileserver/fileserver.go:708` (only when `!s.Profile.AllowAnonymous()`; private instances require a viewer)
- `Authenticator.AuthenticateToUser` — `server/auth/authenticator.go:190` (same auth-gate branch)
- `FileServerService.getUserByUsername` — `server/router/fileserver/fileserver.go:715` (builds `store.FindUser{Username: &identifier}`)
- `Store.GetUser` — `store/user.go:148` (ID-keyed cache is skipped here since the lookup is by username)
- `Store.ListUsers` — `store/user.go:136`
- `Driver.ListUsers` — `store/driver.go:47` (interface dispatch)
- `DB.ListUsers` — `store/db/sqlite/user.go:88` / `store/db/mysql/user.go:84` / `store/db/postgres/user.go:87` (`SELECT id, username, …, avatar_url, … FROM user WHERE username = ?`)

**Back out of the data layer:**

- `FileServerService.parseDataURI` — `server/router/fileserver/fileserver.go:737` (splits `data:image/png;base64,…` into MIME type + decoded bytes)
- `avatarAllowedTypes` check + `setSecurityHeaders` + `c.Blob` — `server/router/fileserver/fileserver.go:201-209`

Two things worth noting: the avatar blob never touches local disk or S3 (unlike attachments — no `resolveLocalPath`/S3 branch on this path), and if `avatar_url` is an external URL rather than base64, the converter passes it through unchanged (`user_service_converters.go:39`) so the browser never hits this handler at all.
