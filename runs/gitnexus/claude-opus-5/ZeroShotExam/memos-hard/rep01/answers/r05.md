**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across the whole tree (excluding `node_modules`/`.git`) returns zero hits, and there is no GraphQL dependency in `go.mod` or the web `package.json`. Memos' public API is **Protobuf/gRPC-defined**, exposed over three wire protocols.

**Actual API surface**

Schema definitions (the source of truth) — `proto/api/v1/`:
- `proto/api/v1/memo_service.proto` — `MemoService` (CreateMemo, ListMemos, GetMemo, UpdateMemo, …)
- `proto/api/v1/user_service.proto` — `UserService`
- `proto/api/v1/auth_service.proto` — `AuthService`
- `proto/api/v1/attachment_service.proto` — `AttachmentService`
- `proto/api/v1/instance_service.proto` — `InstanceService`
- `proto/api/v1/shortcut_service.proto` — `ShortcutService`
- `proto/api/v1/idp_service.proto` — `IdentityProviderService`
- `proto/api/v1/ai_service.proto` — `AIService`
- `proto/api/v1/common.proto` — shared enums/messages

All are package `memos.api.v1`. REST paths are declared inline via `google.api.http` annotations (e.g. `post: "/api/v1/memos"`, `get: "/api/v1/{name=memos/*}"` in `proto/api/v1/memo_service.proto:17-35`). A separate `proto/store/` tree holds internal persistence messages — not public API.

Codegen — `proto/buf.gen.yaml` runs buf with plugins for Go structs, gRPC, Connect, grpc-gateway, gnostic-openapi, and TypeScript (`bufbuild/es`). Outputs:
- `proto/gen/api/v1/` — Go types + gRPC/Connect/gateway stubs
- `proto/gen/openapi.yaml` — generated OpenAPI 3.0.3 spec, embedded into the binary by `proto/openapi_embed.go`
- `web/src/types/proto/api/v1/*_pb.ts` — TypeScript client types

Server wiring — `server/router/api/v1/`:
- `server/router/api/v1/v1.go:96-126` registers the grpc-gateway mux, serving the REST/JSON surface at `/api/v1/...`
- `server/router/api/v1/v1.go:139-144` mounts the Connect RPC surface at `/memos.api.v1.*`, with handlers registered in `server/router/api/v1/connect_handler.go:31-44`
- Service implementations live alongside, e.g. `server/router/api/v1/memo_service.go`, `user_service.go`

Non-gRPC routes also exist under `server/router/`: `rss/`, `fileserver/`, `mcp/`, and SSE (`server/router/api/v1/sse_handler.go`).
