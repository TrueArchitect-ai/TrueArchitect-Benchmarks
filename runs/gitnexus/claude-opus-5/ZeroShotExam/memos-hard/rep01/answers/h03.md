**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` is the abstraction package — it defines the provider-neutral `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation must return. It contains nothing else, so the "interface" is really this shared result type plus the implicit `NewIdentityProvider` / `ExchangeToken` / `UserInfo` shape.
- `internal/idp/oauth2/oauth2.go` is the only concrete protocol implementation that ships: an OAuth2 `IdentityProvider` backed by `golang.org/x/oauth2`, with PKCE support (`code_verifier`) in `ExchangeToken` and claim-to-field mapping in `UserInfo`.

Corroborating evidence:
- `server/router/api/v1/auth_service_sso.go:104-134` — `resolveSSOIdentity` switches on provider type and has exactly one branch, `storepb.IdentityProvider_OAUTH2`, constructing `oauth2.NewIdentityProvider(...)`.
- `proto/store/idp.proto:11-14` — the `IdentityProvider.Type` enum has only `TYPE_UNSPECIFIED = 0` and `OAUTH2 = 1`; no SAML/OIDC/LDAP variants exist.
- These two files are the only non-test importers of `internal/idp` in the repo.
