**`RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, delegating to `markdown.Service.ExtractAll` in `internal/markdown/markdown.go:356`; triggered on memo create, on update when `content` is in the update mask, and by the batch backfill `Runner.RunOnce`; it extracts the tag list plus the calculated `Property` (title, has_link, has_code, has_task_list, has_incomplete_tasks).**

Detail:

- **What it is** — `store.Memo.Payload` (`store/memo.go:51`), i.e. `MemoPayload` from `proto/store/memo.proto`: `tags` and `Property { has_link, has_task_list, has_code, has_incomplete_tasks, title }`, documented there as "The calculated properties from the memo content."

- **Computation site** — `RebuildMemoPayload(ctx, memo, markdownService)` at `server/runner/memopayload/runner.go:74`. It lazily allocates `memo.Payload`, calls `markdownService.ExtractAll([]byte(memo.Content))`, and assigns only `Payload.Tags` and `Payload.Property` — user-set `Payload.Location` is deliberately left intact (it's set separately at `server/router/api/v1/memo_service.go:110`).

- **Triggers**
  - `CreateMemo` — `server/router/api/v1/memo_service.go:108`, after the content-length check and before `Store.CreateMemo`.
  - `UpdateMemo` — `server/router/api/v1/memo_service.go:447`, inside the update-mask loop only for the `content` path; the rebuilt payload is written via `update.Payload = memo.Payload`. Other mask paths (visibility, pinned, state, timestamps) do not recompute it.
  - `memopayload.Runner.RunOnce` — `server/runner/memopayload/runner.go:27`, a backfill that pages all memos in batches of 100 and rewrites each payload via `Store.UpdateMemo`. Note this runner is currently not wired into startup: `server/server.go:163` only invokes the s3presign runner, and `memopayload` is imported only by `memo_service.go`.

- **What `ExtractAll` extracts** (`internal/markdown/markdown.go:356-416`) — one goldmark AST walk collecting:
  - `Tags` from `mast.TagNode`, skipping tags inside links/images (`asMemoTagNode`, line 104) and deduped case-preserving.
  - `Mentions` from `mast.MentionNode`, lowercased (populated in `ExtractedData` but *not* stored into the payload by `RebuildMemoPayload`).
  - `Property.Title` — text of the document's first block child if it is an H1 (`extractHeadingText`, line 172).
  - `Property.HasLink` (`KindLink`), `Property.HasCode` (code block / fenced code / code span), `Property.HasTaskList` and `Property.HasIncompleteTasks` (`east.KindTaskCheckBox`, the latter when a checkbox is unchecked).

  These properties back the memo filter surface (e.g. `TestMemoFilterHasLink`, `TestMemoFilterHasIncompleteTasks` in `store/test/memo_filter_test.go`).

- **Related but different** — the list/preview `snippet` is *not* stored: it's derived per response by `getMemoContentSnippet` (`server/router/api/v1/memo_service_webhooks.go:83`) calling `GenerateSnippet(content, 64)` (`internal/markdown/markdown.go:264`, plain text, code blocks skipped), applied at conversion time in `server/router/api/v1/memo_service_converter.go:76` and for relations at lines 225/248.
