**Premise correction:** There is no GraphQL schema in this repository. A case-insensitive search for `graphql` across all Go, TypeScript, JSON, Markdown, and proto sources returns zero hits. Memos does not expose a GraphQL API — there is no schema file, no resolver layer, and no GraphQL server dependency.

## The actual public API surface

The public API is defined in **Protocol Buffers**, served over **Connect RPC + gRPC-Gateway** (REST/JSON), with an auto-generated OpenAPI document.

**Schema definitions — `proto/api/v1/`:**

| File | Service |
|---|---|
| `proto/api/v1/memo_service.proto` | `MemoService` |
| `proto/api/v1/user_service.proto` | `UserService` |
| `proto/api/v1/auth_service.proto` | `AuthService` |
| `proto/api/v1/instance_service.proto` | `InstanceService` |
| `proto/api/v1/attachment_service.proto` | `AttachmentService` |
| `proto/api/v1/idp_service.proto` | `IdentityProviderService` |
| `proto/api/v1/shortcut_service.proto` | `ShortcutService` |
| `proto/api/v1/ai_service.proto` | `AIService` |
| `proto/api/v1/common.proto` | shared enums/messages |

Internal storage messages (not part of the public API) live in `proto/store/`.

**REST mapping.** Each RPC carries a `google.api.http` annotation that defines its HTTP route. From `proto/api/v1/memo_service.proto:17-40`:

```protobuf
service MemoService {
  rpc CreateMemo(CreateMemoRequest) returns (Memo) {
    option (google.api.http) = { post: "/api/v1/memos", body: "memo" };
  }
  rpc ListMemos(ListMemosRequest) returns (ListMemosResponse) {
    option (google.api.http) = {get: "/api/v1/memos"};
  }
  rpc GetMemo(GetMemoRequest) returns (Memo) {
    option (google.api.http) = {get: "/api/v1/{name=memos/*}"};
  }
```

**Generation.** `proto/buf.gen.yaml` drives `buf generate`, emitting:
- Go types, gRPC, Connect, and gateway stubs → `proto/gen/api/v1/`
- OpenAPI spec → `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`)
- TypeScript clients → `web/src/types/proto/`

Per `AGENTS.md`, generated outputs must never be hand-edited — change the `.proto` and re-run `buf generate`.

**Server implementations:** `server/router/api/v1/` — e.g. `memo_service.go`, `user_service.go`, `auth_service.go`, with Connect wiring in `connect_handler.go` and `connect_services.go`.

**Auth surface:** `server/router/api/v1/acl_config.go` is the single source of truth for unauthenticated endpoints, keyed by gRPC procedure path (e.g. `/memos.api.v1.AuthService/SignIn`). Both the Connect interceptor and the gRPC-Gateway interceptor read this map, and `AGENTS.md` requires new public endpoints be registered there.

There is also an MCP surface (`server/router/mcp/openapi.go`) that derives tools from the generated OpenAPI spec, and an SSE streaming handler (`server/router/api/v1/sse_handler.go`) — but again, no GraphQL anywhere.
