**`internal/idp`; `internal/idp/oauth2`**

- `internal/idp/idp.go` — the provider abstraction package. It declares the shared `IdentityProviderUserInfo` struct (`Identifier`, `DisplayName`, `Email`, `AvatarURL`) that every provider implementation normalizes third-party user data into.
- `internal/idp/oauth2/oauth2.go` — the only concrete protocol implementation that ships ("Package oauth2 implements the OAuth2 identity provider integration"). It defines `IdentityProvider` over `storepb.OAuth2Config` with `NewIdentityProvider`, `ExchangeToken` (including PKCE support via `codeVerifier`), and user-info retrieval.

Corroborating evidence:
- `proto/store/idp.proto` — the `IdentityProvider.Type` enum has exactly one non-unspecified value, `OAUTH2`, and the `IdentityProviderConfig` oneof only carries `oauth2_config`.
- `server/router/api/v1/auth_service_sso.go:12-13` is the sole non-test consumer, importing both `internal/idp` and `internal/idp/oauth2`.
