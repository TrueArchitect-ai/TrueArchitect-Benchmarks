**Convergence function — `webhook.Post`, `internal/webhook/webhook.go:120`**

The chain: each handler calls a `Dispatch*Webhook` helper in `server/router/api/v1/memo_service_webhooks.go`, which loads the owner's webhooks (`s.Store.GetUserWebhooks`), copies `hook.Url` into `WebhookRequestPayload.URL`, and calls `webhook.PostAsync` (`webhook.go:184`). `PostAsync` only enqueues onto `asyncPostQueue`; four worker goroutines started in `init()` (`webhook.go:42-55`) drain that queue and call `Post`, which is the only place an outbound `http.Client.Do` happens (`webhook.go:152`).

Supporting detail:
- The URL is user-configured through the `CreateUserWebhook` / `UpdateUserWebhook` RPCs (`server/router/api/v1/user_service_webhooks.go`), validated by `webhook.ValidateURL` (`internal/webhook/validate.go:61`).
- SSRF is guarded at dial time by `safeDialContext` (`webhook.go:59`) on the shared `safeClient`, which rejects reserved/private IPs post-resolution.
- `internal/webhook/webhook.go` also holds `PostAsync` as an intermediate convergence point, but it performs no I/O — `Post` is the single delivery point.
