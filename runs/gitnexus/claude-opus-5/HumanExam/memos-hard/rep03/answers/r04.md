— **Premise is wrong: neither. There is no message broker** — zero references to NATS, RabbitMQ, or AMQP in the Go sources or `go.mod`, and no queue is declared anywhere. Webhook delivery uses an **in-process buffered Go channel**: `asyncPostQueue = make(chan *WebhookRequestPayload, 128)` (`internal/webhook/webhook.go:41`), drained by **4 goroutines started in `init()`** (`internal/webhook/webhook.go:44-53`), each calling `Post` (`:119`). Producers use `PostAsync` (`:184`), which drops the payload with a warning when the buffer is full (`:191-196`) — so delivery is best-effort and does not survive a restart.
