— Premise is wrong: there is no Redis and no external cache anywhere in the repo (no `redis` reference in Go, TS, or `go.mod`). The cache layer is a process-local in-memory cache: `store/cache/cache.go` (`Cache`, `sync.Map` + TTL sweeper). Three instances are created in `store.New` — `instanceSettingCache`, `userCache`, `userSettingCache` — all with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000` (`store/store.go:40-53`). So user entries expire after **10 minutes**; they are also explicitly invalidated on delete (`store/user_delete.go:39-47`). Cache writes/reads for users: `store/user.go:136-168`.
