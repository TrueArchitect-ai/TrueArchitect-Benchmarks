**Premise is wrong — there is no GraphQL schema or GraphQL server anywhere** (no `graphql` reference in Go, TS, `go.mod`, or `package.json`). The public API is defined in **Protocol Buffers** under `proto/api/v1/*.proto`, generated into `proto/gen/api/v1`, and served three ways from `server/router/api/v1/v1.go`: Connect RPC handlers (`v1.go:133-141`) and a grpc-gateway REST/JSON transcoding mux at `/api/v1` (`v1.go:95-130`, registered from `server/server.go:88`). Additional non-gRPC surfaces: the HTTP file server (`server/router/fileserver/fileserver.go:121`), RSS (`server/router/rss/rss.go:67`), and an MCP endpoint (`server/router/mcp`, wired at `server/server.go:92-96`).
