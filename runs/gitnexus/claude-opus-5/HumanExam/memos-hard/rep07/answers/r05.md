Premise wrong: there is no GraphQL schema or GraphQL server — zero occurrences of `graphql` in Go, TS, or TSX sources. The public API surface is:
- **gRPC / Connect + gRPC-Gateway REST**, defined by protobuf under `proto/api/v1/` (generated into `proto/gen/api/v1/`), implemented by `APIV1Service` in `server/router/api/v1/` and registered at `server/router/api/v1/v1.go:64` (`RegisterGateway`) / `connect_handler.go`, wired at `server/server.go:70-87`
- **MCP** (Model Context Protocol) endpoint — `server/router/mcp/service.go`, registered at `server/server.go:89-93`
- **HTTP file server** — `server/router/fileserver/fileserver.go:120-125`
- **RSS feeds** — `server/router/rss/rss.go`, registered at `server/server.go:83`
- **`/healthz`** — `server/server.go:63`

An OpenAPI document is generated from the protos (`proto/openapi_embed.go`, consumed by `server/router/mcp/openapi.go`) — that, not GraphQL, is the schema for the public API.
