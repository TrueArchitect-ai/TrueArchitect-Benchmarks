Premise wrong: **there is no Redis and no external cache layer.** The cache is a process-local in-memory implementation, `store/cache/cache.go` (`Cache` struct `:66`, `New` `:74`, `sync.Map`-backed). Three instances are created in `store.New` — `instanceSettingCache`, `userCache`, `userSettingCache` — from a hardcoded `cache.Config` at `store/store.go:38-43`: **`DefaultTTL: 10 * time.Minute`**, `CleanupInterval: 5m`, `MaxItems: 1000`. So user entries expire after 10 minutes (same as everything else); they're also invalidated explicitly on user delete (`store/user_delete.go:39-40`). No connection string, host, or port exists anywhere.
