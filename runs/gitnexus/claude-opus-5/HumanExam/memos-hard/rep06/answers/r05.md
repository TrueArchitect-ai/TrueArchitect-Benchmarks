Premise wrong: **there is no GraphQL in this project** (zero matches for "graphql" in Go, TS, proto, or package manifests). The public API is defined in **Protocol Buffers** under `proto/api/v1/*.proto` (`memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto`), generated into `proto/gen/` (Go + OpenAPI) and `web/src/types/proto/` (TypeScript) via `buf generate`. It is served two ways from the same service implementations in `server/router/api/v1/`: **Connect RPC** (`connect_handler.go`, `connect_services.go`) and **gRPC-Gateway REST** (`APIV1Service.RegisterGateway`, `server/router/api/v1/v1.go:65`). Additional non-RPC surfaces: `/file/...` (`server/router/fileserver/fileserver.go:122-125`), RSS (`server/router/rss/rss.go:67-70`), SSE, and an MCP endpoint (`server/router/mcp/`).
