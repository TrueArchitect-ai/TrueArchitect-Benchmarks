Premise is wrong: **there is no GraphQL schema or GraphQL server in this repo** (no `graphql` dependency in `go.mod`, no `.graphql`/`.gql` files, no resolver code). The public API surface is Protobuf-defined RPC: `.proto` files under `proto/` generating `proto/gen/` (Go + OpenAPI) and `web/src/types/proto/` (TypeScript), served two ways from one service implementation — Connect RPC handlers and a gRPC-Gateway REST/JSON mux, both registered in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:65-110`, e.g. `RegisterMemoServiceHandlerServer` at `:107`), wired at `server/server.go:88`. Additional non-RPC surfaces: HTTP file server `/file/...` (`server/router/fileserver/fileserver.go:121-125`), RSS (`server/router/rss/rss.go:67`), MCP (`server/server.go:92-96`), and `/healthz` (`server/server.go:67`). Endpoint access policy lives in `server/router/api/v1/acl_config.go`, not a schema.
