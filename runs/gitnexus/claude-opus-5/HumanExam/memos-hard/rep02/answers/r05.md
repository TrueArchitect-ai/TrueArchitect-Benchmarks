— Premise is wrong: there is no GraphQL schema, server, or dependency in this codebase (no `.graphql` files, no resolver code, no GraphQL library in `go.mod`). Actual public API surface: Protobuf-defined gRPC services exposed over **Connect RPC** and a **gRPC-Gateway** REST/JSON mapping. Schemas live in `proto/api/v1/*.proto` — `memo_service.proto`, `user_service.proto`, `attachment_service.proto`, `auth_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated Go in `proto/gen/api/v1/`. Registration happens in `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`) plus `server/router/api/v1/connect_handler.go` and `connect_services.go`. Non-RPC HTTP surfaces are the file server (`server/router/fileserver/fileserver.go:124`), RSS (`server/router/rss/rss.go:66-68`), and MCP (`server/router/mcp/`).
