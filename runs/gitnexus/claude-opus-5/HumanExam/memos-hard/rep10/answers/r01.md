— Premise is wrong: there is no Redis anywhere in the repo (a case-insensitive `redis` grep over Go/TS/YAML/Markdown returns nothing; no Redis client in `go.mod`). The cache layer is a **process-local in-memory cache**: `store/cache/cache.go` (`Cache` struct at `:67`, backed by `sync.Map`, with a cleanup goroutine). Three caches are created in `store.New` — `instanceSettingCache`, `userCache`, `userSettingCache` (`store/store.go:47-53`) — all sharing one `cache.Config` with **`DefaultTTL = 10 minutes`**, `CleanupInterval = 5 minutes`, `MaxItems = 1000` (`store/store.go:40-45`). User entries use that default TTL: writes go through `Set` (`store/user.go:98,122,132,143,167`), which calls `SetWithTTL(..., c.config.DefaultTTL)` (`store/cache/cache.go:94`). Entries are also explicitly invalidated on delete (`store/user_delete.go:40`). There is no Redis connection to configure.
