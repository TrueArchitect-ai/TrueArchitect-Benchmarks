— Premise is wrong: there is no GraphQL anywhere (a case-insensitive `graphql` grep over the Go tree returns nothing; no GraphQL dependency in `go.mod`). The public API is **Protobuf/gRPC-based**, defined in `proto/api/v1/*.proto` and generated into `proto/gen/api/v1/`, exposed three ways from `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go:64`): a gRPC-Gateway REST/JSON surface, Connect RPC handlers (`server/router/api/v1/connect_handler.go`, `connect_services.go`), and an MCP tool surface (`server/router/mcp/`, catalog at `server/router/mcp/catalog.go:12-25`). Additional non-gRPC surfaces are the file server (`server/router/fileserver/fileserver.go:121`), RSS (`server/router/rss/rss.go`), and the frontend static/SSR routes (`server/router/frontend/frontend.go`).
