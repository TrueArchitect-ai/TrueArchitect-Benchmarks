Engine: CEL (Google `cel-go v0.28.1`, `go.mod:13`) via the in-repo memo filter engine at `internal/filter/` (entry `filter.DefaultEngine()`, `internal/filter/engine.go`; schema `schema.go`, CEL→IR `parser.go`/`ir.go`, SQL rendering `render.go`, docs `README.md`). Mechanism: the handler validates the filter (`server/router/api/v1/memo_service_filter.go`) and passes it as `FindMemo.Filters`; each dialect driver calls `filter.AppendConditions(ctx, engine, find.Filters, filter.DialectSQLite|DialectMySQL|DialectPostgres, &where, &args)` (`internal/filter/helpers.go:9`, `store/db/sqlite/memo.go:57-61`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`), which compiles the CEL AST to a dialect-specific parameterized SQL fragment (`render.go` handles JSON access, placeholders, `LIKE`/`ILIKE`) that is appended to the WHERE clause.
