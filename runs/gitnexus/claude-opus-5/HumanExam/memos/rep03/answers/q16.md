In `Store.DeleteMemo` (`store/memo.go:140-159`), before the memo row: (1) `memo_relation` rows where the memo is the source (`MemoID`), (2) `memo_relation` rows where it is the target (`RelatedMemoID`), (3) all `attachment` rows linked to the memo (each via `Store.DeleteAttachment`, which also removes the blob from local/S3 storage). At the API layer (`server/router/api/v1/memo_service.go:567-577`), comment memos are deleted first via the same path.
