Asynchronous delivery goes through `PostAsync` (line 184), which enqueues onto `asyncPostQueue`; four worker goroutines started in the package `init()` (line 42) drain the queue by calling `Post`.

**Protection mechanism** — two layers of SSRF defense:

1. **At delivery time:** the `safeClient` HTTP client (`internal/webhook/webhook.go:32-35`) uses `safeDialContext` (`internal/webhook/webhook.go:59`) as its transport dialer. It re-resolves the target hostname at connection time and refuses to dial if any resolved address falls in a reserved/private range — this catches DNS-rebinding tricks, not just obviously-internal URLs.
2. **At registration time:** `ValidateURL` (`internal/webhook/validate.go:62`) rejects webhook URLs up front if they aren't absolute http/https URLs or resolve to a reserved IP.

Both layers share `isReservedIP` (`internal/webhook/validate.go:44`), whose block list (`internal/webhook/validate.go:15-26`) covers loopback, RFC-1918 private ranges, link-local (including the cloud metadata address 169.254.169.254), and their IPv6 equivalents. An `AllowPrivateIPs` escape hatch (`internal/webhook/validate.go:41`) disables the checks for self-hosted setups that legitimately target internal endpoints.
