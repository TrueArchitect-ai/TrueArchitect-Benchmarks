**Convergence function** — `webhook.PostAsync` — `internal/webhook/webhook.go:184`. Every path funnels through it (called from `memo_service_webhooks.go:43` and `:71`); it enqueues onto `asyncPostQueue`, and the worker goroutines then call `webhook.Post` (`internal/webhook/webhook.go:120`), which performs the actual HTTP delivery. If you want the single function where the request is actually *sent* rather than enqueued, that is `webhook.Post`; the single function where all handler paths converge before delivery is `webhook.PostAsync`.
