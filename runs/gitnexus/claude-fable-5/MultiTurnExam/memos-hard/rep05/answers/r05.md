**Premise correction: this project has no GraphQL API.** There is no GraphQL schema, no `.graphql` files, and no GraphQL library referenced anywhere in the backend or web frontend — a repo-wide search for "graphql" comes up empty.

**Actual API surface:** the public API is gRPC-based, defined with Protocol Buffers and exposed over HTTP in two ways:

- **Schema definition:** the proto files under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, `common.proto` — with generated code in `proto/gen/`.
- **Serving:** the services are implemented by `APIV1Service` (`server/router/api/v1/v1.go`) and mounted two ways: a ConnectRPC handler serving `/memos.api.v1.*` (`server/router/api/v1/v1.go:139-144`, handlers registered in `server/router/api/v1/connect_services.go`), and a gRPC-Gateway mux that translates RESTful HTTP/JSON to the same gRPC methods (`server/router/api/v1/v1.go:95-97`, with an auth middleware at lines 67-93).

Beyond that, the only other HTTP surfaces are the plain-HTTP file server (`server/router/fileserver/fileserver.go`), RSS feeds (`server/router/rss/rss.go`), and the frontend static routes (`server/router/frontend/frontend.go`) — none of them GraphQL.
