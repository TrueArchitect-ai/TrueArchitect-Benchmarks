**Determination method** — resolving the interface dispatch by tracing the configuration default:

1. Saving a memo goes through `Store.CreateMemo` (`store/memo.go:109`), which delegates to `s.driver.CreateMemo(...)` (`store/memo.go:113`) — `driver` is the `store.Driver` interface, so there are three candidate implementations (`store/db/sqlite/memo.go`, `store/db/mysql/memo.go`, `store/db/postgres/memo.go`).
2. The concrete driver is chosen once at startup by the factory `NewDBDriver` (`store/db/db.go:14`), which switches on `profile.Driver`.
3. With no database flags, `profile.Driver` is `"sqlite"`: the CLI declares the flag with default `"sqlite"` and also `viper.SetDefault("driver", "sqlite")` — `cmd/memos/main.go:122` and `cmd/memos/main.go:130`. (`internal/profile/profile.go:110` further confirms the sqlite default path by synthesizing a DSN when `Driver == "sqlite"` and no DSN is given.)
4. Therefore the `"sqlite"` arm of the factory runs (`store/db/db.go:19-20`), the driver bound to the interface is the sqlite `DB`, and the `INSERT` for a saved memo executes in sqlite's `CreateMemo`.
