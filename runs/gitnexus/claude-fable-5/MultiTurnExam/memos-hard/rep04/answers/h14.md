The derived metadata is the memo **payload** (`memo.Payload` — tags plus content-derived boolean properties and title, stored on the memo row and used for list rendering/filtering/previews).

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It runs the memo's markdown content through `markdownService.ExtractAll` (implemented at `internal/markdown/markdown.go:356`, single goldmark parse) and writes the results into `memo.Payload.Tags` and `memo.Payload.Property`.

**Triggers (callers):**
1. **Memo creation** — `CreateMemo` handler calls it before persisting: `server/router/api/v1/memo_service.go:108` (this also covers comments, which are created as memos).
2. **Memo update** — `UpdateMemo`'s content-update path recomputes it: `server/router/api/v1/memo_service.go:447`.
3. **Bulk rebuild** — the `memopayload.Runner.RunOnce` batch job re-derives payloads for all memos: `server/runner/memopayload/runner.go:52` (defined but not currently wired into server startup).

**What it extracts** (`ExtractedData`, `internal/markdown/markdown.go:21-25`, and `MemoPayload.Property`, `proto/store/memo.proto:15-22`):
- `Tags` — all `#tag` occurrences (via the custom tag extension).
- `Property.has_link`, `has_task_list`, `has_code`, `has_incomplete_tasks` — boolean flags about the content.
- `Property.title` — the text of the first H1 heading, if present.
- (`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` only persists Tags and Property.)

In requested format: computation site — `RebuildMemoPayload`, `server/runner/memopayload/runner.go:74` (delegating to `markdown.Service.ExtractAll`, `internal/markdown/markdown.go:356`); triggers — memo create (`memo_service.go:108`), memo content update (`memo_service.go:447`), bulk rebuild runner (`runner.go:52`); extracted — `#tags`, has_link / has_task_list / has_code / has_incomplete_tasks flags, and title from the first H1.
