**Premise correction: there is no GraphQL API in this codebase — no GraphQL schema, library, or endpoint exists.** A case-insensitive grep for "graphql" across Go, TypeScript, and module files returns nothing.

Actual API surface: the public API is **gRPC/Protobuf-defined**, exposed two ways over HTTP:

- **Schema definition**: Protocol Buffer service definitions under `proto/api/v1/` — `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus `common.proto`. Generated Go stubs live in `proto/gen/api/v1/`.
- **REST-style JSON access** via gRPC-Gateway: the gateway mux is mounted at `/api/v1/*` and `/file/*` (`server/router/api/v1/v1.go:128-129`), translating HTTP/JSON to the gRPC handlers using the `google.api.http` annotations in the protos.
- **Connect protocol** for the web frontend (replacing grpc-web): Connect handlers are registered on their own mux and mounted at `/memos.api.v1.*` (`server/router/api/v1/v1.go:131-144`), with metadata/logging/recovery/auth interceptors.

The handlers behind both surfaces are the `APIV1Service` methods in `server/router/api/v1/` (e.g. `memo_service.go`, `user_service.go`). Additional non-gRPC surfaces are the file server (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), and SSE events — but nothing GraphQL.
