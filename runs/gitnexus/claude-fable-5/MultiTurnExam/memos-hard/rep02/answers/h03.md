**Abstraction package: `internal/idp` (`internal/idp/idp.go`); implementation package: `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`) — OAuth2 is the one protocol that ships.**

Details:

- `internal/idp/idp.go` defines the provider-neutral abstraction: the `IdentityProviderUserInfo` struct (Identifier, DisplayName, Email, AvatarURL) that any concrete provider must produce after authenticating a user.
- The only concrete implementation in the tree is the OAuth2 one in `internal/idp/oauth2/oauth2.go`: its `IdentityProvider` type wraps a `storepb.OAuth2Config`, exchanges the authorization code for a token via `ExchangeToken` (with PKCE support), then fetches and maps the user-info endpoint response into `idp.IdentityProviderUserInfo`. There is no OIDC/SAML/LDAP sibling package under `internal/idp/`.
