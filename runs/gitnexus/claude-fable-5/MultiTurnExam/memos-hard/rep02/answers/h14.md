**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`, which delegates the actual content analysis to the markdown service's single-pass AST walk `ExtractAll` in `internal/markdown/markdown.go:356`. The results are stored on the memo's `Payload` (`memo.Payload.Tags`, `memo.Payload.Property` — `runner.go:85-86`), persisted with the memo row.

**Triggers:**
- **Memo creation** — `CreateMemo` calls it before inserting (`server/router/api/v1/memo_service.go:108`). Since `CreateMemoComment` creates comments through `s.CreateMemo` (`server/router/api/v1/memo_service_comments.go:56`), comment creation triggers it too.
- **Content update** — `UpdateMemo` recomputes it when the `content` field is in the update mask (`server/router/api/v1/memo_service.go:447`).
- **Bulk backfill** — `memopayload.Runner.RunOnce` (`runner.go:27`) rebuilds payloads for all memos in batches of 100; note this runner isn't wired into server startup in the current code, so in practice only the create/update paths run.

**Extracted properties** (from `ExtractAll`, `internal/markdown/markdown.go:362-421`):
- `Tags` — all `#tag` occurrences, deduplicated case-preservingly
- `Mentions` — all `@username` mentions, lowercased and deduplicated (returned by the extractor; the payload rebuild persists Tags and Property)
- `Property.Title` — text of a leading H1 heading, if the document starts with one
- `Property.HasLink` — any link node present
- `Property.HasCode` — any code block, fenced code block, or inline code span
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — task checkboxes present / at least one unchecked

These flags and tags are what list views and previews filter/badge on without re-parsing memo content.
