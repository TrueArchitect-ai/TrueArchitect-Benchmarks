**No.** The MySQL driver (`mysql.NewDB` in `store/db/mysql/mysql.go:20`) is constructed in exactly one place: the driver-selection factory `store/db/db.go:22`, inside `NewDBDriver`, which switches on the configured database type.

Evidence:

- A repo-wide grep for imports of `github.com/usememos/memos/store/db/mysql` finds only one importer: `store/db/db.go:8`. Since `NewDB` can only be called through that import path, no other file can construct the driver.
- A grep for `mysql.NewDB(` likewise matches only `store/db/db.go:22` (plus the definition itself).
- The other `mysql.*` references in the codebase are unrelated packages, not the driver: `store/test/containers.go` imports `github.com/testcontainers/testcontainers-go/modules/mysql` (to spin up a MySQL container for tests) and `github.com/go-sql-driver/mysql` (the low-level SQL driver, aliased `mysqldriver`) — test infrastructure that builds a DSN, not a construction of the repo's `store/db/mysql` driver type. Tests get a driver through the same factory path rather than instantiating it directly.
