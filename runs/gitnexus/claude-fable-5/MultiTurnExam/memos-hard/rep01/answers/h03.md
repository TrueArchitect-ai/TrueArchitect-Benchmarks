**Abstraction package: `internal/idp`; implementation package: `internal/idp/oauth2`**

The `internal/idp` package (`internal/idp/idp.go`) defines the provider abstraction — the `IdentityProviderUserInfo` struct (identifier, display name, email, avatar URL) that any provider must produce after authenticating a user. The only concrete protocol implementation that ships is OAuth2, in `internal/idp/oauth2/oauth2.go`: its `IdentityProvider` type wraps a `storepb.OAuth2Config` (client ID/secret, token URL, user-info URL, field mapping) and exchanges the authorization code, then fetches and maps user info into the `idp.IdentityProviderUserInfo` shape. There is no other protocol package (e.g., no SAML or LDAP) under `internal/idp`.
