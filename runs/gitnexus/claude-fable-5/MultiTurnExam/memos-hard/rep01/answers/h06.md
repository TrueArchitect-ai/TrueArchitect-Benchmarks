**Convergence function: `webhook.Post` — `internal/webhook/webhook.go:120`**

All of these handlers resolve the target user's registered webhooks (`GetUserWebhooks`) and call one of the `Dispatch*Webhook` methods in `server/router/api/v1/memo_service_webhooks.go`, which build a payload (setting `URL = hook.Url`) and hand it to `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` enqueues onto the bounded `asyncPostQueue`, and the worker goroutines started in `init()` drain that queue by calling `webhook.Post` — the single function where every path converges and the actual `POST` to the user-configured URL is executed.
