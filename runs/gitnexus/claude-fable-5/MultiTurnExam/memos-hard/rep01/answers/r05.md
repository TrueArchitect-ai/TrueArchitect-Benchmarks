**Premise correction: there is no GraphQL API in this project — no schema, resolvers, or GraphQL dependency exists** (a repo-wide search for "graphql" matches nothing in the Go or web sources).

**Actual API surface:** the public API is defined with Protocol Buffers and served as gRPC plus HTTP mappings:

- **Schema definitions:** `.proto` files under `proto/api/v1/` — e.g. `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `instance_service.proto`, `idp_service.proto`, `shortcut_service.proto`, `ai_service.proto`. These are the source of truth for the API's types and methods (with `google.api.http` annotations for REST-style paths).
- **Generated code:** under `proto/gen/api/v1/` — gRPC stubs (`*_grpc.pb.go`), grpc-gateway reverse-proxy handlers (`*.pb.gw.go`), and ConnectRPC handlers (`proto/gen/api/v1/apiv1connect/`).
- **Serving:** `APIV1Service.RegisterGateway` (`server/router/api/v1/v1.go`) wires the grpc-gateway and Connect handlers into the Echo HTTP server, invoked from `server/server.go:88`. So clients reach the API either as gRPC/ConnectRPC or as JSON-over-HTTP through the gateway — never GraphQL.

Non-gRPC HTTP surfaces are limited to the file server (`server/router/fileserver/`), RSS feeds (`server/router/rss/`), and the frontend/sitemap routes (`server/router/frontend/`).
