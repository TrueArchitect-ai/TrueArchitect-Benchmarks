The server starts exactly **one** background runner, in `Server.startBackgroundRunners` (`server/server.go:153`, called from `Start` at line 129):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — two triggers: an immediate `RunOnce(ctx)` at startup (`server/server.go:163`), then a continuous `Run` loop driven by a `time.NewTicker` with a 12-hour interval (`runnerInterval = time.Hour * 12`, `s3presign/runner.go:27-30`). It re-presigns S3 object URLs older than the refresh threshold.

**Unused scheduling infrastructure:** the **memopayload runner** (`server/runner/memopayload/runner.go`) has the same runner shape — a `Runner` struct with `NewRunner` and a `RunOnce` method for rebuilding all memo payloads — but the server never instantiates or schedules it. Only its standalone helper function `RebuildMemoPayload` is used, called synchronously from the API handlers on memo create/update (`server/router/api/v1/memo_service.go:108, 447`). There is no cron library or other scheduler in the server; scheduling is just the one ticker.
