MemoService is served over two protocols:

1. **REST via gRPC-Gateway** — `server/router/api/v1/v1.go` (line 108): `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` registers the service on a `runtime.NewServeMux` gateway mux, mounted under `/api/v1/*`, translating the HTTP annotations (e.g. `POST /api/v1/memos`) into handler calls.

2. **ConnectRPC (Connect protocol)** — `server/router/api/v1/connect_handler.go` (line 40): `apiv1connect.NewMemoServiceHandler(s, opts...)` is registered by `RegisterConnectHandlers`, with the wrapping type `ConnectServiceHandler` adapting the same `APIV1Service` implementation (the per-RPC wrappers live in `server/router/api/v1/connect_services.go`, e.g. `SignIn`/`CreateMemo` wrappers).

Both protocols share the single business-logic implementation in `APIV1Service` (`server/router/api/v1/memo_service.go`).
