Before deleting the memo row itself, `Store.DeleteMemo` (`store/memo.go:140-159`) deletes:

- **memo_relation records** — both directions: relations where the memo is the source (`MemoID`) and where it is the target (`RelatedMemoID`)
- **attachments** linked to the memo (listed via `ListAttachments`, then each removed with `DeleteAttachment`)

Additionally, when the deletion comes through the API, the handler `APIV1Service.DeleteMemo` (`server/router/api/v1/memo_service.go:518`) first deletes all **comment memos** (memos related with type `MemoRelationComment`) by calling `Store.DeleteMemo` on each — which recursively cleans up those comments' own relations and attachments — before deleting the target memo.
