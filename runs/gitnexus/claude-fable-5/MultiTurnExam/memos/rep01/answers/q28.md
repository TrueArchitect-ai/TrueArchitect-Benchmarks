**s3presign runner** — the only background worker the server actually starts. `Server.startBackgroundRunners` (`server/server.go:153`) runs it once immediately at startup, then `Runner.Run` (`server/runner/s3presign/runner.go:29`) loops on a plain `time.Ticker` with a hard-coded 12-hour interval (`runnerInterval = time.Hour * 12`, line 27) to refresh S3 presigned attachment URLs.

**memopayload** (`server/runner/memopayload/runner.go`) — despite living under `server/runner/`, it is not started as a background worker; its `RebuildMemoPayload` is called synchronously from the API handlers (`server/router/api/v1/memo_service.go:108` and `:447`) during memo create/update.

**Unused infrastructure:** the cron-style scheduling package `internal/scheduler/` (scheduler.go, job.go, parser.go, middleware.go, plus its own README) is imported by nothing outside its own directory — no server code uses it. The server's only scheduling driver is the raw `time.Ticker` in the s3presign runner.
