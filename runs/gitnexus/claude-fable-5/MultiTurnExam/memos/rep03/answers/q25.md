Engine: CEL (Google's Common Expression Language, parsed with `cel-go`) — internal/filter (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`).

Mechanism: the engine runs a three-phase pipeline — CEL parsing/validation against the memo schema (`internal/filter/schema.go`, `internal/filter/parser.go`), normalization into a dialect-agnostic IR condition tree (`internal/filter/ir.go`), then rendering (`internal/filter/render.go`) which walks the IR and emits a SQL fragment plus placeholder args tailored to the target dialect (`DialectSQLite`/`DialectMySQL`/`DialectPostgres` — handling `?` vs `$n` placeholders, JSON access via `json_extract` vs `->>`, `LIKE` vs `JSON_CONTAINS` vs `@>` for tags, etc.); each dialect driver invokes it when building the ListMemos query, e.g. `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` in `store/db/sqlite/memo.go:57-61` (likewise in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`). The pipeline is documented in `internal/filter/README.md`.
