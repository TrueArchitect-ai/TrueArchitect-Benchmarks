s3presign runner — the only background worker the server starts. In `startBackgroundRunners` (`server/server.go:153-174`) it runs `s3presignRunner.RunOnce(ctx)` immediately at startup, then a goroutine calls `Run`, which is driven by a `time.Ticker` firing every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-30`) to refresh S3 presigned URLs.

Notes on infrastructure that exists but is NOT started by the server:

- **memopayload runner** (`server/runner/memopayload/runner.go`) defines `NewRunner`/`RunOnce`, but the server never launches it as a background worker — its `RebuildMemoPayload` function is only called inline from API handlers (`server/router/api/v1/memo_service.go:108, 447`).
- **internal/scheduler** — a full cron-style scheduling package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, etc.) is present in the codebase but is imported by no production code at all (a repo-wide grep for `internal/scheduler` finds no importers); the server's only scheduling is the plain `time.Ticker` above.
