- memo created (`memos.memo.created`): DispatchMemoCreatedWebhook
- memo updated (`memos.memo.updated`): DispatchMemoUpdatedWebhook
- memo deleted (`memos.memo.deleted`): DispatchMemoDeletedWebhook
- memo comment created (`memos.memo.comment.created`): DispatchMemoCommentCreatedWebhook

All four are defined in `server/router/api/v1/memo_service_webhooks.go`. The first three funnel through the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), which looks up the creator's webhooks; the comment variant looks up the parent memo owner's webhooks itself. All of them converge on `webhook.PostAsync` for delivery — implemented in `internal/webhook/webhook.go`, which asynchronously POSTs the JSON payload and signs it with HMAC-SHA256 (`webhook-id`/`webhook-timestamp`/`webhook-signature` headers) when a signing secret is set.
