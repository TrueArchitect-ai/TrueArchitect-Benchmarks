Memo lifecycle events that dispatch webhooks (all defined in `server/router/api/v1/memo_service_webhooks.go`):

- memo created (`memos.memo.created`): **DispatchMemoCreatedWebhook**
- memo updated (`memos.memo.updated`): **DispatchMemoUpdatedWebhook**
- memo deleted (`memos.memo.deleted`): **DispatchMemoDeletedWebhook**
- comment created (`memos.memo.comment.created`): **DispatchMemoCommentCreatedWebhook**

The first three funnel through the shared helper `dispatchMemoRelatedWebhook` (same file, line 48). All four converge on **`webhook.PostAsync`** in `internal/webhook/webhook.go:184`, which asynchronously calls `Post` (line 120) — the single delivery function that builds the signed HTTP POST (HMAC-SHA256, `webhook-id`/`webhook-timestamp`/`webhook-signature` headers) to the user's webhook URL.
