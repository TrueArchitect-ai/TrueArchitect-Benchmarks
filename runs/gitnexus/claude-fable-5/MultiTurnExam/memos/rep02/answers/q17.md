**web/src/hooks/useMemoQueries.ts; memoServiceClient**

That module holds the TanStack Query hooks for memo CRUD — `listMemos`/`getMemo` queries and `createMemo`/`updateMemo`/`deleteMemo` mutations — all going through `memoServiceClient`, which is imported from `web/src/connect.ts` and created there from the generated `MemoService` definition (`web/src/types/proto/api/v1/memo_service_pb`).
