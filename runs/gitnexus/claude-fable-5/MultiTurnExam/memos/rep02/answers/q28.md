Runners the server actually starts (`Server.startBackgroundRunners`, `server/server.go:153-174`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — run once immediately at startup (`RunOnce`), then continuously on a **`time.Ticker` every 12 hours** (`runnerInterval = time.Hour * 12`, `runner.go:27-41`), in a goroutine with its own cancelable context. It refreshes S3 presigned URLs.

That is the only background runner the server starts. Two pieces of related infrastructure exist but are **not** started as background workers:

- **memopayload runner** (`server/runner/memopayload/runner.go`) — its `RunOnce` (rebuild all memo payloads) is never invoked by the server; the package is only used synchronously from the memo handlers via `memopayload.RebuildMemoPayload` (`server/router/api/v1/memo_service.go:108, 447`).
- **`internal/scheduler`** — a full cron-style scheduler package (`internal/scheduler/scheduler.go`, `job.go`, `parser.go`, etc.) that no server code imports; the s3presign runner uses a plain `time.Ticker` instead. This scheduling infrastructure is present in the codebase but unused by the server.
