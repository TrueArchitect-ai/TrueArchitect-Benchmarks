**Engine:** CEL (Common Expression Language, via `github.com/google/cel-go`) — the filter engine lives in `internal/filter/` (entry point `filter.DefaultEngine()` in `internal/filter/engine.go`).

**Mechanism:** The filter string is parsed by cel-go and validated against the memo-specific schema (`internal/filter/schema.go`), normalized into a dialect-agnostic intermediate representation (`internal/filter/parser.go`, `internal/filter/ir.go`), and then rendered into a SQL fragment plus placeholder args for the target dialect — sqlite, mysql, or postgres, each handling differences like JSON access, placeholders, and LIKE/ILIKE — by `internal/filter/render.go`; each dialect driver invokes this via `filter.AppendConditions(..., filter.DialectSQLite, &where, &args)` when building the ListMemos query (e.g. `store/db/sqlite/memo.go:57-61`).
