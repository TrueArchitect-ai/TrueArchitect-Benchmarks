**Engine:** CEL (Common Expression Language), parsed with `cel-go` — the engine lives in **`internal/filter/`** (entry point `filter.DefaultEngine()` in `internal/filter/engine.go:111`; the package is documented in `internal/filter/README.md`).

**Mechanism:** The filter string is parsed by cel-go against a memo-specific schema (`internal/filter/schema.go`), the CEL AST is normalized into a dialect-agnostic intermediate representation (`internal/filter/parser.go`, `internal/filter/ir.go`), and the renderer in `internal/filter/render.go` walks that IR to emit a SQL WHERE fragment plus placeholder args tailored to the target dialect (`DialectSQLite` / `DialectMySQL` / `DialectPostgres` — handling differences like JSON access, placeholders, and LIKE vs ILIKE); each dialect driver invokes this via `filter.AppendConditions(...)` in its `ListMemos`, e.g. `store/db/sqlite/memo.go:57-61`.
