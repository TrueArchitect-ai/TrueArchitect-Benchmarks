Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- **memo created** (`memos.memo.created`): `DispatchMemoCreatedWebhook` — called from `CreateMemo` (`server/router/api/v1/memo_service.go:157`)
- **memo updated** (`memos.memo.updated`): `DispatchMemoUpdatedWebhook` — called from the update side-effects helper (`server/router/api/v1/memo_update_helpers.go:67`)
- **memo deleted** (`memos.memo.deleted`): `DispatchMemoDeletedWebhook` — called from `DeleteMemo` (`server/router/api/v1/memo_service.go:562`)
- **comment created** (`memos.memo.comment.created`): `DispatchMemoCommentCreatedWebhook` — called from `CreateMemoComment` (`server/router/api/v1/memo_service_comments.go:119`)

**Convergence point:** the first three funnel through the shared helper `dispatchMemoRelatedWebhook` (same file), and all four ultimately deliver via **`webhook.PostAsync(payload)`** in the **`internal/webhook`** package (`internal/webhook/webhook.go`), which performs the asynchronous, HMAC-SHA256-signed HTTP POST.
