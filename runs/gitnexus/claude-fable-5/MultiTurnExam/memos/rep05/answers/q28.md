**Runners actually started by the server** (`Server.startBackgroundRunners`, `server/server.go:153`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — the only background runner the server starts. It runs `RunOnce` immediately at startup (`server/server.go:163`), then a continuous `Run` loop in a goroutine driven by a **`time.Ticker` firing every 12 hours** (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-36`). It re-presigns S3 object URLs older than ~4 days.

**Unused scheduling infrastructure:** The **memopayload runner** (`server/runner/memopayload/runner.go`) defines a full runner (`NewRunner` / `RunOnce` for rebuilding all memo payloads) but is **never started by the server** — no caller of `memopayload.NewRunner` or its `RunOnce` exists anywhere. Only the package's plain helper function `RebuildMemoPayload` is used, called synchronously from the API handlers (`server/router/api/v1/memo_service.go:108` and `:447`). There is no cron library in the project; scheduling is limited to the single ticker above.
