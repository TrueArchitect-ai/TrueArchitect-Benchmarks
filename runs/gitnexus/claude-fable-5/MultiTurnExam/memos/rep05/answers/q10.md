**store/migration/sqlite/LATEST.sql**

For a fresh SQLite database, the complete current schema is applied from the single `LATEST.sql` file in `store/migration/sqlite/` (the versioned subdirectories like `0.30/` hold only incremental migrations for upgrades). It contains all the `CREATE TABLE` statements — `user`, `memo`, `memo_relation`, `attachment`, etc.
