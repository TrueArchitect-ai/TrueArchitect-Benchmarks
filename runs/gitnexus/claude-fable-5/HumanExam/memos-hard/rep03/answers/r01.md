False premise — there is no Redis anywhere (no hits for "redis" in go.mod or any .go file). The cache layer is an in-process, thread-safe in-memory cache with TTL (store/cache/cache.go:66); the user cache is built in `store.New` with `DefaultTTL: 10 * time.Minute`, `CleanupInterval: 5 * time.Minute`, `MaxItems: 1000` (store/store.go:40-52), so user entries do expire after 10 minutes — but from an in-memory map, not Redis.
