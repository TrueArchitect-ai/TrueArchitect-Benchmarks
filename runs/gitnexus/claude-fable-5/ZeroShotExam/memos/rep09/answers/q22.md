When `CreateMemo` finishes creating the memo, the handler (`server/router/api/v1/memo_service.go:157`) calls `DispatchMemoCreatedWebhook`, defined in `server/router/api/v1/memo_service_webhooks.go`. That function looks up the creator's webhooks via `Store.GetUserWebhooks`, builds a payload with activity type `memos.memo.created` plus the hook's URL and signing secret, and fires each one asynchronously with `webhook.PostAsync`.

- **Dispatcher** — `DispatchMemoCreatedWebhook` (delegating to `dispatchMemoRelatedWebhook`) in `server/router/api/v1/memo_service_webhooks.go`
- **Delivery package** — `internal/webhook` (`github.com/usememos/memos/internal/webhook`); its `Post`/`PostAsync` send the JSON POST using Go's standard `net/http` client (an SSRF-hardened `safeClient`)
- **Signing mechanism** — HMAC-SHA256 in the Standard Webhooks style: when a signing secret is set, `Post` computes an HMAC-SHA256 over `msgID.timestamp.body` with a key derived from the secret (`resolveSigningKey`), and sets the `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 mac>` headers (`internal/webhook/webhook.go:120-150`)
