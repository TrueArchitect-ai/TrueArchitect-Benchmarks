The compiled React frontend is embedded directly into the Go binary with Go's `embed` directive — `//go:embed dist/*` populates an `embed.FS` (`embeddedFiles`) with the built `web` output copied into `server/router/frontend/dist/`. It is then served over HTTP by the Echo web server via `middleware.StaticWithConfig` (with an SPA fallback middleware that serves `index.html` for unmatched extension-less routes), all wired in `FrontendService.Serve`.

Mechanism: Go `//go:embed` of the `dist/` build output served through Echo static middleware + SPA `index.html` fallback; path: `server/router/frontend/frontend.go`
