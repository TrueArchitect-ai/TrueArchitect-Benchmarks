`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from a single `LATEST.sql` file rather than replaying incremental migrations — `store/migrator.go:27` documents this ("Check if DB is initialized. If not, apply LATEST.sql") and `store/migrator.go:56` defines `LatestSchemaFileName = "LATEST.sql"`. For the SQLite driver, that file is `store/migration/sqlite/LATEST.sql`; the versioned directories like `store/migration/sqlite/0.24/` are only used to upgrade existing installations.
