**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10`, documented as "an interface for store driver" containing all methods a database driver must implement (attachment, memo, user CRUD, etc.). The three backends — SQLite, MySQL, and Postgres, living under `store/db/sqlite`, `store/db/mysql`, and `store/db/postgres` — all implement it, and `NewDBDriver` in `store/db/db.go:14` selects and returns one as a `store.Driver` based on the configured profile.
