The ListMemos request flows through these six hops:

- frontend hook — `useMemos` (and `useInfiniteMemos`) in `web/src/hooks/useMemoQueries.ts`
- client file — `memoServiceClient` in `web/src/connect.ts`
- proto RPC — `rpc ListMemos` in `proto/api/v1/memo_service.proto`
- backend handler — `func (s *APIV1Service) ListMemos` in `server/router/api/v1/memo_service.go`
- store method — `func (s *Store) ListMemos` in `store/memo.go`
- dialect implementation — `store/db/sqlite/memo.go` (equivalents exist in `store/db/mysql/memo.go` and `store/db/postgres/memo.go`)

In short: the React Query hook `useMemos` calls `memoServiceClient.listMemos(...)`, a Connect client created from the generated `MemoService` definition; the gRPC service handler in `memo_service.go` translates the request into a `store.FindMemo` lookup via `Store.ListMemos`, which delegates to the active driver's dialect file to build and execute the SQL.
