When the API's `DeleteMemo` handler calls into the store, `Store.DeleteMemo` in `store/memo.go:140-159` cleans up these record types before deleting the memo row itself:

- **Memo relation records** (`memo_relation`) where the memo is the **source** — `DeleteMemoRelation{MemoID: ...}` (`store/memo.go:142`)
- **Memo relation records** where the memo is the **target** of a relation — `DeleteMemoRelation{RelatedMemoID: ...}` (`store/memo.go:145`)
- **Attachment records** linked to the memo — it lists them with `ListAttachments{MemoID: ...}` and deletes each via `DeleteAttachment` (`store/memo.go:149-157`)

Only after that does it call `s.driver.DeleteMemo`, which executes the plain `DELETE FROM memo WHERE id = ?` (e.g. `store/db/sqlite/memo.go:237`). So the store layer deletes: memo relations (in both directions) and attachments.
