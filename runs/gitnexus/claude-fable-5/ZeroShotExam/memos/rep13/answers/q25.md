**Engine:** Google CEL (Common Expression Language, via `github.com/google/cel-go`) · **Path:** `internal/filter/` (engine in `internal/filter/engine.go`, CEL→IR conversion in `internal/filter/parser.go` with the IR in `internal/filter/ir.go`, SQL emission in `internal/filter/render.go`, memo variable/function declarations in `internal/filter/schema.go`).

**Mechanism:** The ListMemos handler passes the filter string down to the store, where each driver (`store/db/sqlite/memo.go`, `store/db/postgres/memo.go`, `store/db/mysql/memo.go`) calls `filter.DefaultEngine()` and `filter.AppendConditions(...)` with its `DialectName` — the engine compiles the CEL expression against the schema's environment into a dialect-agnostic `Condition` tree (with `now` frozen per compile), and a per-dialect `renderer` walks that tree to emit WHERE-clause SQL fragments plus bound args, switching on `DialectSQLite`/`DialectPostgres`/`DialectMySQL` for dialect-specific constructs (placeholders, string-length/LIKE expressions, timestamp accessors).
