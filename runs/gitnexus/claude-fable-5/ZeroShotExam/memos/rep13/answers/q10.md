`store/migration/sqlite/LATEST.sql`

For a fresh (uninitialized) database, the migrator applies the full current schema from a single file rather than replaying incremental migrations — `store/migrator.go` documents this ("LATEST.sql: Full schema for new installations") and defines `LatestSchemaFileName = "LATEST.sql"` (store/migrator.go:27,42,56). For SQLite that file is `store/migration/sqlite/LATEST.sql`.
