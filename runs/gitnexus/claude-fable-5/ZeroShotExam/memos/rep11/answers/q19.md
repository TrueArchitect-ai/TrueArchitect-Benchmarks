MemoService is served over gRPC-Gateway (HTTP/JSON REST) and Connect RPC:

- **HTTP/JSON via gRPC-Gateway** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` inside `RegisterGateway`, using the generated handlers from `proto/gen/api/v1/memo_service.pb.gw.go`).
- **Connect RPC** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` inside `RegisterConnectHandlers`, using the generated handler from `proto/gen/api/v1/apiv1connect/memo_service.connect.go`; the service methods are adapted in `server/router/api/v1/connect_services.go`).

Both registrations are mounted onto the same Echo server in `RegisterGateway` (`v1.go`), which calls `RegisterConnectHandlers` at line 141. Notably there is no standalone `grpc.Server` registration — the gateway path serves the implementation directly (`HandlerServer` variant), and Connect provides the gRPC/gRPC-Web/Connect wire protocols.
