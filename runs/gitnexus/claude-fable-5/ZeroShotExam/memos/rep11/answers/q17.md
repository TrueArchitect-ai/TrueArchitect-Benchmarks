**Answer:** `web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

The frontend module `web/src/hooks/useMemoQueries.ts` contains the memo CRUD operations as TanStack Query hooks — queries (`listMemos`, `getMemo`, `listMemoComments`, `getLinkMetadata`) and mutations (`createMemo`, `updateMemo`, `deleteMemo`). It uses the generated `memoServiceClient`, imported from `@/connect` (`web/src/connect.ts:197`), where it's created via Connect-RPC with `createClient(MemoService, transport)` from the protobuf-generated `MemoService` definition (`web/src/types/proto/api/v1/memo_service_pb.ts`).
