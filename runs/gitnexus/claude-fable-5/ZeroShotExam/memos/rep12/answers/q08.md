**`Driver` — `store/driver.go`**

The `Driver` interface is defined at `store/driver.go:10` in the `store` package, described as containing "all methods that store database driver should implement" (e.g. `GetDB`, `Close`, `IsInitialized`, plus CRUD methods for memos, attachments, etc.). All three database backends implement it: SQLite (`store/db/sqlite/sqlite.go`), MySQL (`store/db/mysql/mysql.go`), and PostgreSQL (`store/db/postgres/postgres.go`), with `store/db/db.go`'s `NewDBDriver` returning a `store.Driver` for whichever backend the profile selects.
