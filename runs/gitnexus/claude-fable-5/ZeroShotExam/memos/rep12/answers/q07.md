The ConnectRPC service clients are created in **`web/src/connect.ts`**.

That file builds a Connect transport with `createConnectTransport` from `@connectrpc/connect-web` (with an auth interceptor for token refresh), then instantiates all service clients via `createClient` — `instanceServiceClient`, `authServiceClient`, `userServiceClient`, `memoServiceClient`, `attachmentServiceClient`, `aiServiceClient`, `shortcutServiceClient`, and `identityProviderServiceClient` (web/src/connect.ts:192-203).
