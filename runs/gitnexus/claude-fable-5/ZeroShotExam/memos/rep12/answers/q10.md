`store/migration/sqlite/LATEST.sql`

On a fresh (uninitialized) database, the migrator applies this single file containing the full current schema instead of replaying incremental migrations — see `store/migrator.go:27` and `store/migrator.go:42-56`, which document that `LATEST.sql` is the "Full schema for new installations" applied during `preMigrate` when the DB is not yet initialized. The versioned directories under `store/migration/sqlite/` (e.g. `0.24/`, `0.30/`) are only for upgrading existing installations.
