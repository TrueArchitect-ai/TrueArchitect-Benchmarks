When a memo is deleted, the API handler calls `Store.DeleteMemo` in `store/memo.go:140`, which cleans up two other kinds of records before deleting the memo row itself:

- **Memo relation records** (`memo_relation`) — deleted in both directions: rows where the memo is the source (`MemoID`) and rows where it is the target (`RelatedMemoID`) (`store/memo.go:142-147`)
- **Attachment records** linked to the memo — listed via `ListAttachments` with the memo's ID and deleted one by one with `DeleteAttachment` (`store/memo.go:148-157`)

Only after those cleanups does it delete the memo row via `s.driver.DeleteMemo` (`store/memo.go:158`).
