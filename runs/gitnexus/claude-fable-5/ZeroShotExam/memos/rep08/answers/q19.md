MemoService is exposed both through the gRPC-Gateway (REST/HTTP JSON) and through ConnectRPC (which speaks the Connect/gRPC/gRPC-Web wire protocols over HTTP):

- **REST / HTTP JSON via gRPC-Gateway** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` mounts the generated handlers from `proto/gen/api/v1/memo_service.pb.gw.go` onto the gateway mux).
- **ConnectRPC (Connect/gRPC/gRPC-Web)** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` inside `RegisterConnectHandlers`; that mux is then mounted at `/memos.api.v1.*` in `server/router/api/v1/v1.go` lines 139–144).

Both protocols are backed by the same `APIV1Service` implementation (`s`), so each RPC is registered once per transport rather than implemented twice.
