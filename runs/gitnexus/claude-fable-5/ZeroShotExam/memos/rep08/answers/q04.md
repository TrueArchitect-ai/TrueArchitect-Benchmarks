**APIV1Service.SignIn — server/router/api/v1/auth_service.go** (lines 50–107).

This method is the actual backend business-logic handler for the SignIn RPC: it reads the password or SSO credentials from the `SignInRequest`, looks up the user via the store, and returns a `SignInResponse`. It's invoked through the generated Connect/gRPC plumbing — `ConnectServiceHandler.SignIn` in `server/router/api/v1/connect_services.go` delegates to it, and the generated dispatch stub `_AuthService_SignIn_Handler` lives in `proto/gen/api/v1/auth_service_grpc.pb.go`.
