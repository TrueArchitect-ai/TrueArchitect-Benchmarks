The three implementations of the `store.Driver` interface (defined in `store/driver.go`) each have an entry file that provides a `NewDB` constructor:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

**NewDBDriver** — `store/db/db.go` is the factory that selects between them at startup: it switches on `profile.Driver` ("sqlite" / "mysql" / "postgres") and returns the matching driver, erroring on anything else (`store/db/db.go:14-32`).
