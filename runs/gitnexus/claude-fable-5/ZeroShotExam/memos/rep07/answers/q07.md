`web/src/connect.ts`

This file imports `createClient` from `@connectrpc/connect` and `createConnectTransport` from `@connectrpc/connect-web`, and creates the clients for all the generated services (AuthService, MemoService, UserService, AttachmentService, InstanceService, ShortcutService, IdentityProviderService, AIService) along with auth/retry interceptors. It's the only file under `web/src` that calls `createClient`.
