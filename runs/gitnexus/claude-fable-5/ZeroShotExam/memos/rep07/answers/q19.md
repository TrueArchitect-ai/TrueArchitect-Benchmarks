MemoService is served over **gRPC-Gateway (REST/JSON over HTTP)** and **Connect RPC** (the connectrpc.com protocol, which replaced grpc-web for browser clients).

- gRPC-Gateway (HTTP/REST) — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)`, mounted under `/api/v1/*`)
- Connect RPC — `server/router/api/v1/connect_handler.go` (line 40: `apiv1connect.NewMemoServiceHandler(s, opts...)` inside `RegisterConnectHandlers`, mounted under `/memos.api.v1.*` from `v1.go:141-144`)

Both are wired onto the Echo server in `RegisterGateway` in `server/router/api/v1/v1.go`; there is no standalone gRPC server — the gateway handler is registered in-process.
