Details:

- The gRPC handler `APIV1Service.CreateMemo` (`server/router/api/v1/memo_service.go:157`) calls `s.DispatchMemoCreatedWebhook(ctx, memoMessage)`, defined in `server/router/api/v1/memo_service_webhooks.go:15`. That delegates to `dispatchMemoRelatedWebhook` with activity type `"memos.memo.created"`, which loads the creator's webhooks via `s.Store.GetUserWebhooks` and enqueues a payload per hook with `webhook.PostAsync(payload)`.
- HTTP delivery is performed by the `internal/webhook` package (`internal/webhook/webhook.go`): `PostAsync` enqueues onto a bounded channel drained by 4 worker goroutines that call `Post`, which POSTs JSON using a shared `net/http` client with an SSRF-guarded dialer (blocks reserved/private IPs).
- Signing (in `Post`, `internal/webhook/webhook.go:133-150`): if the hook has a signing secret, the request is signed per the Standard Webhooks scheme — an HMAC-SHA256 over `"<msgID>.<timestamp>." + body` using the secret (a `whsec_`-prefixed base64 secret is decoded to raw key bytes by `resolveSigningKey`), sent as `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 MAC>` headers.
