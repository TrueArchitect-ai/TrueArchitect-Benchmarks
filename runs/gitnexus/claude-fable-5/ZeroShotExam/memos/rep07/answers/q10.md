`store/migration/sqlite/LATEST.sql`

On a fresh (uninitialized) database, the migrator applies this single full-schema file instead of replaying incremental migrations — see `store/migrator.go:27` ("Check if DB is initialized. If not, apply LATEST.sql") and the `LatestSchemaFileName = "LATEST.sql"` constant at `store/migrator.go:56`. The incremental version-directory files under `store/migration/sqlite/` (e.g. `0.24/00__memo.sql`) are only used to upgrade existing installs.
