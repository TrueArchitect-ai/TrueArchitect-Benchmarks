The server starts exactly one background runner, in `startBackgroundRunners` (`server/server.go:153-174`), called from `Server.Start` (`server/server.go:129`):

- **s3presign runner** (`server/runner/s3presign/runner.go`) — trigger: run once immediately at startup (`RunOnce` at `server/server.go:163`), then continuously via a `time.NewTicker` firing every 12 hours (`runnerInterval = time.Hour * 12`, `server/runner/s3presign/runner.go:27-40`), until its per-runner context is cancelled on shutdown.

Not a background runner, for clarity:

- **memopayload runner** (`server/runner/memopayload/runner.go`) — the `Runner` type and its `RunOnce` exist but are never constructed or started by the server (`memopayload.NewRunner` has no call sites outside the package). Only the package-level helper `RebuildMemoPayload` is invoked, synchronously inside API request handling (`server/router/api/v1/memo_service.go:108` and `:447`), so nothing schedules it.

Unused scheduling infrastructure:

- **`internal/scheduler`** — a full GitHub-Actions-style cron job scheduler (cron-expression parser in `internal/scheduler/parser.go`, job model in `internal/scheduler/job.go`, scheduler loop in `internal/scheduler/scheduler.go`) is present but **not used by the server at all**: no file outside the package (and its tests) imports it. The only scheduling actually in effect is the plain `time.Ticker` in the s3presign runner.
