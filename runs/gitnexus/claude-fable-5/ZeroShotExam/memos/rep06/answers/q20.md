**Server-Sent Events (SSE); `server/router/api/v1/sse_hub.go`; CreateMemo, UpdateMemo, DeleteMemo, CreateMemoComment**

Details:

- **Mechanism:** Server-Sent Events. The HTTP endpoint that streams `text/event-stream` to browsers is in `server/router/api/v1/sse_handler.go`.
- **Hub:** `SSEHub` in `server/router/api/v1/sse_hub.go` manages connected clients and exposes `Broadcast()` (line 115), with per-client buffered channels so a slow client doesn't block broadcasting. Event payload helpers live in `server/router/api/v1/sse_event_helpers.go`.
- **Memo handlers that broadcast:**
  - `CreateMemo` — `server/router/api/v1/memo_service.go:163` (skipped via a `suppressSSE` context key when invoked from CreateMemoComment)
  - `UpdateMemo` — broadcasts indirectly through `dispatchMemoUpdatedSideEffects` at `server/router/api/v1/memo_update_helpers.go:71` (called from `memo_service.go:513`)
  - `DeleteMemo` — `server/router/api/v1/memo_service.go:585`
  - `CreateMemoComment` — `server/router/api/v1/memo_service_comments.go:126` (broadcasts a `memo.comment.created` event for the parent memo)

Additionally (beyond memo handlers proper), the reaction handlers `UpsertMemoReaction` and `DeleteMemoReaction` in `server/router/api/v1/reaction_service.go` (lines 106 and 161) also broadcast memo-related events through the same hub.
