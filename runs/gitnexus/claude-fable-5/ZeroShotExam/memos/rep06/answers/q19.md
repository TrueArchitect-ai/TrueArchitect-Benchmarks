MemoService is exposed over **Connect RPC** and **HTTP/REST via gRPC-Gateway** (there is no raw `grpc.NewServer` in this codebase — Connect handles the gRPC-compatible wire protocols).

- **Connect RPC** — `server/router/api/v1/connect_handler.go` (line 40: `wrap(apiv1connect.NewMemoServiceHandler(s, opts...))` inside `RegisterConnectHandlers`, which mounts all Connect handlers on an `http.ServeMux`)
- **REST/HTTP (gRPC-Gateway)** — `server/router/api/v1/v1.go` (line 108: `v1pb.RegisterMemoServiceHandlerServer(ctx, gwMux, s)` inside `RegisterGateway`, which attaches the gateway mux to the Echo server)

Both registrations dispatch to the same `APIV1Service` implementation; the generated plumbing for each protocol lives in `proto/gen/api/v1/apiv1connect/` and `proto/gen/api/v1/memo_service.pb.gw.go` respectively.
