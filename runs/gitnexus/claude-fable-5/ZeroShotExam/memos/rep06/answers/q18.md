The `store.Driver` interface has three implementations, each with its entry file defining `NewDB`:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

**NewDBDriver — `store/db/db.go`** is the factory that selects between them at startup: it switches on `profile.Driver` (`"sqlite"` / `"mysql"` / `"postgres"`) and returns the matching `NewDB(profile)` result (`store/db/db.go:14-32`).
