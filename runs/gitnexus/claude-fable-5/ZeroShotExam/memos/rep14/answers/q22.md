**Answer:** `DispatchMemoCreatedWebhook` — `server/router/api/v1/memo_service_webhooks.go`; delivery package `internal/webhook` (`github.com/usememos/memos/internal/webhook`); signing mechanism: Standard Webhooks-style HMAC-SHA256 signature.

Details:

- The `CreateMemo` handler (`server/router/api/v1/memo_service.go:157`) calls `DispatchMemoCreatedWebhook` (`server/router/api/v1/memo_service_webhooks.go:15`), which delegates to `dispatchMemoRelatedWebhook` with activity type `memos.memo.created`. That fetches the creator's webhooks via `s.Store.GetUserWebhooks` and enqueues each payload with `webhook.PostAsync`.
- HTTP delivery is done by the `internal/webhook` package: `PostAsync` feeds a bounded queue drained by worker goroutines that call `Post` (`internal/webhook/webhook.go`), which POSTs the JSON payload using a shared SSRF-guarded `http.Client`.
- Signing: when the hook has a `SigningSecret`, `Post` computes an HMAC-SHA256 over `msgID + "." + timestamp + "." + body` (Standard Webhooks scheme; secrets are `whsec_<base64>`-encoded, generated by `GenerateSigningSecret`) and sends it as `webhook-id`, `webhook-timestamp`, and `webhook-signature: v1,<base64 mac>` headers (`internal/webhook/webhook.go:133-150`).
