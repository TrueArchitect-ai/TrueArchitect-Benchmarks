`Driver` — `store/driver.go`

The `Driver` interface is defined at `store/driver.go:10` in the `store` package. Its doc comment states it "contains all methods that store database driver should implement" — covering DB access (`GetDB`, `Close`, `IsInitialized`, `GetDatabaseSize`) plus CRUD methods for each model (attachments, memos, etc.). The three database backends that implement it live in `store/db/sqlite/`, `store/db/mysql/`, and `store/db/postgres/`, selected via the factory in `store/db/db.go`.
