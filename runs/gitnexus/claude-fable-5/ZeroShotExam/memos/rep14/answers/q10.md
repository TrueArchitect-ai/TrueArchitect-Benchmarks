For a fresh (uninitialized) database, the migrator applies the full current schema from `LATEST.sql` in the driver-specific migration directory instead of running incremental migrations — see `store/migrator.go:27` and `store/migrator.go:56` (`LatestSchemaFileName = "LATEST.sql"`), verified by `store/test/migrator_test.go` (TestFreshInstall).
