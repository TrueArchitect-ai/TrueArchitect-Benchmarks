`web/src/hooks/useMemoQueries.ts`; `memoServiceClient`

This module contains the memo CRUD hooks — `useCreateMemo`, `useUpdateMemo`, `useDeleteMemo`, plus list/get queries (`listMemos`, `getMemo`, `listMemoComments`) built on TanStack Query's `useQuery`/`useMutation`. It imports `memoServiceClient` from `web/src/connect.ts`, where it is created with `createClient(MemoService, transport)` — a Connect-RPC client for the generated `MemoService` (types from `web/src/types/proto/api/v1/memo_service_pb.ts`).
