Four memo lifecycle events dispatch webhooks, all defined in `server/router/api/v1/memo_service_webhooks.go`:

- `memos.memo.created`: `DispatchMemoCreatedWebhook` (line 15)
- `memos.memo.updated`: `DispatchMemoUpdatedWebhook` (line 20)
- `memos.memo.deleted`: `DispatchMemoDeletedWebhook` (line 25)
- `memos.memo.comment.created`: `DispatchMemoCommentCreatedWebhook` (line 30)

Delivery convergence: the created/updated/deleted dispatchers are thin wrappers over the shared helper `dispatchMemoRelatedWebhook` (same file, line 48), which looks up the creator's webhooks and enqueues each payload; the comment dispatcher enqueues directly. All four ultimately converge on `webhook.PostAsync` in `internal/webhook/webhook.go:184`, which pushes the payload onto a bounded queue drained by worker goroutines that call `webhook.Post` (`internal/webhook/webhook.go:120`) — the single function that signs and performs the actual HTTP POST to the webhook endpoint.
