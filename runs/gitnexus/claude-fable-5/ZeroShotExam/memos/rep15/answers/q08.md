**`Driver` — `store/driver.go`** (defined at `store/driver.go:10`).

The `Driver` interface declares all methods a database backend must implement — connection management (`GetDB`, `Close`), initialization checks, and CRUD methods for each model (attachments, memos, memo relations, instance settings, etc.). The concrete backends (SQLite, MySQL, PostgreSQL) live under `store/db/` and each implements this interface.
