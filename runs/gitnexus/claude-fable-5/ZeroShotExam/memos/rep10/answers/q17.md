The memo CRUD mutations and queries live in `web/src/hooks/useMemoQueries.ts`. It defines TanStack Query hooks such as `useCreateMemo`, `useUpdateMemo`, and `useDeleteMemo` (plus list/get queries), all of which call the generated service client `memoServiceClient` — imported from `web/src/connect.ts`, where it is created with `createClient(MemoService, transport)` from the Connect-RPC generated `MemoService` definition.
