The three implementations of the `store.Driver` interface each live in their own package under `store/db/`, with the driver struct and its `NewDB` constructor defined in these entry files:

- `store/db/sqlite/sqlite.go` — SQLite driver
- `store/db/mysql/mysql.go` — MySQL driver
- `store/db/postgres/postgres.go` — PostgreSQL driver

The factory that selects between them at startup is **`NewDBDriver`** — `store/db/db.go` (lines 14–32). It switches on `profile.Driver` (`"sqlite"`, `"mysql"`, `"postgres"`) and returns the matching driver via each package's `NewDB(profile)`, erroring on any unknown driver name.
