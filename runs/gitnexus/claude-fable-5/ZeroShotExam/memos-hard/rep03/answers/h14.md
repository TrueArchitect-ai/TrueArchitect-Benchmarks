The derived metadata is the memo's **payload** (`Payload.Tags` and `Payload.Property`), rebuilt from the markdown content by `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`. It delegates the actual parsing to `service.ExtractAll` in `internal/markdown/markdown.go:355-422`, which does a single goldmark AST walk over the content.

**Computation site:** `RebuildMemoPayload` (`server/runner/memopayload/runner.go:74`) → `markdownService.ExtractAll` (`internal/markdown/markdown.go:356`), storing the result into `storepb.MemoPayload` (`proto/gen/store/memo.pb.go`).

**Triggers:**
- Memo creation — `CreateMemo` calls it before insert (`server/router/api/v1/memo_service.go:108`).
- Memo update, specifically when the `content` field is in the update mask — `UpdateMemo` calls it after assigning the new content (`server/router/api/v1/memo_service.go:447`).
- Bulk rebuild — `Runner.RunOnce` (`server/runner/memopayload/runner.go:27`) re-derives the payload for all memos in batches of 100 and persists each via `Store.UpdateMemo`. Note this runner is defined but I found no call site wiring it into server startup in the current tree, so it appears to be an on-demand/maintenance path.

**Extracted properties:** from the single AST walk in `ExtractAll`:
- `Tags` — every `#tag` node, deduplicated case-preservingly.
- `Property.Title` — text of the first block-level H1 heading, if the document starts with one.
- `Property.HasLink` — presence of any link node.
- `Property.HasCode` — presence of code blocks, fenced code blocks, or inline code spans.
- `Property.HasTaskList` — presence of task checkboxes, and `Property.HasIncompleteTasks` when any checkbox is unchecked.

(`ExtractAll` also collects `Mentions`, but only `Tags` and `Property` are written into the memo payload at `runner.go:85-86`.) These payload fields are what list/filter features consume — e.g. the `has_link`/`has_code`/`has_incomplete_tasks` memo filters tested in `store/test/memo_filter_test.go` and the tag stats in `server/router/api/v1/user_service_stats.go`.
