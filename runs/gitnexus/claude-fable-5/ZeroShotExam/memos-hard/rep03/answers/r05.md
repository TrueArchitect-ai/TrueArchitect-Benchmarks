**Premise correction:** This repository (memos) has no GraphQL API at all — a repo-wide search for "graphql" turns up zero matches in Go, TypeScript, or proto files. There is no GraphQL schema to point to.

**Actual API surface:** The public API is defined with Protocol Buffers, not GraphQL. The service definitions live in `proto/api/v1/*.proto` (e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/idp_service.proto`). Code generation is configured in `proto/buf.gen.yaml`, which produces gRPC/ConnectRPC Go code plus a grpc-ecosystem gateway, so the same proto definitions are exposed both as gRPC and as a RESTful HTTP/JSON API (with an embedded OpenAPI spec — see `proto/openapi_embed.go`). Generated code lands under `proto/gen`, and the server wires these services up in `server/router/api`. There are also auxiliary surfaces (`server/router/rss`, `server/router/mcp`), but the primary public API is the proto-defined gRPC + REST gateway, not GraphQL.
