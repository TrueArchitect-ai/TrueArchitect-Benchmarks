The derived metadata is the memo's **payload** (`memo.Payload.Tags` and `memo.Payload.Property`), rebuilt from the markdown content.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It delegates the actual parsing to the markdown service's `ExtractAll` in `internal/markdown/markdown.go:356`, which does a single goldmark AST walk over the content and fills `memo.Payload.Tags` and `memo.Payload.Property` (a `storepb.MemoPayload_Property`).

**Triggers:**
- **Memo creation** — `CreateMemo` calls `memopayload.RebuildMemoPayload` before storing the memo (`server/router/api/v1/memo_service.go:108`).
- **Memo content update** — in `UpdateMemo`, when the update mask includes the `content` path, the payload is rebuilt from the new content and written along with it (`server/router/api/v1/memo_service.go:447`).
- **Bulk rebuild** — the background runner's `RunOnce` (`server/runner/memopayload/runner.go:27`) pages through all memos in batches of 100 and rebuilds/persists each payload. (This runner exists as a rebuild mechanism; the wired-up startup runner in `server/server.go` currently only invokes the `s3presign` runner, so create/update are the routine triggers.)

**Extracted properties** (from the single AST walk in `ExtractAll`):
- `Tags` — all `#tag` nodes, deduplicated case-preservingly (skipping tags inside links).
- `Property.Title` — the text of the document's first block if it is a level-1 heading.
- `Property.HasLink` — set when a link node is present.
- `Property.HasCode` — set on code blocks, fenced code blocks, or inline code spans.
- `Property.HasTaskList` / `Property.HasIncompleteTasks` — set when task checkboxes exist / when any checkbox is unchecked.

(`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` only stores `Tags` and `Property` into the payload.) These payload fields are what memo lists/filters use, e.g. filtering by tag or "has link / has task list".
