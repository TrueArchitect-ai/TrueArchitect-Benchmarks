Memo visibility is enforced independently at these server surfaces (all in the `memos` Go server):

- Per-memo read gate in the gRPC/Connect API (`checkMemoReadAccess`: non-public requires auth, private only for creator; used by `GetMemo`, parent-memo expansion, and `ListMemoComments`) — `server/router/api/v1/memo_service.go:39`
- List-level scoping in `ListMemos` (anonymous callers forced to `VisibilityList = [Public]`; authenticated callers get a `creator_id == X || visibility in ["PUBLIC","PROTECTED"]` filter pushed into the store query) — `server/router/api/v1/memo_service.go:218-227`
- Attachment/blob HTTP serving (`checkAttachmentPermission`: public memo + anonymous-allowed instance passes, share-token fallback, otherwise auth required and private memos limited to creator/admin) — `server/router/fileserver/fileserver.go:650-704`
- Attachment listing API (`ListMemoAttachments` re-checks memo visibility before returning attachments) — `server/router/api/v1/memo_attachment_service.go:214-226`
- Reaction listing API (`ListMemoReactions` checks the memo's visibility before listing reactions) — `server/router/api/v1/reaction_service.go:29-41`
- Comment creation (`CreateMemoComment` denies commenting on another user's private memo) — `server/router/api/v1/memo_service_comments.go:41`
- Frontend sitemap generation (`getSitemapXML` queries only `store.Public` memos, so non-public memos never appear in the crawler-facing surface) — `server/router/frontend/frontend.go:150`

The first three are the core enforcement sites (single-memo read, list scoping, and file serving); the attachment, reaction, and comment services each duplicate the check for their own sub-resources rather than delegating, and the frontend sitemap enforces it by construction of the store query. A related but distinct path is the share-token flow (`server/router/api/v1/memo_share_service.go`, `GetMemoByShare`), which grants access to a non-public memo only via a valid, unexpired share token — the same mechanism the fileserver honors as its fallback.
