**1st: `User` (~7 external packages); 2nd: `Memo` (~6 external packages).**

The data layer is the `store` package, whose persistent entities are defined in `store/user.go`, `store/memo.go`, `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/user_identity.go`, `store/user_setting.go`, `store/idp.go`, and `store/instance_setting.go`. Counting distinct Go packages outside the `store/` tree that reference each entity type (e.g. `store.User`, `store.Memo`):

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Next closest is `store.Attachment` at 4 (`server/router/api/v1`, its test package, `server/router/fileserver`, `server/router/rss`).

The ranking is stable regardless of whether you also count the store-internal driver subpackages (`store/db/sqlite|mysql|postgres`, `store/test`) — there User leads Memo 11 to 10.
