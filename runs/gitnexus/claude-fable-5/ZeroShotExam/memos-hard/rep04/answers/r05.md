**Premise correction:** This repository (memos) has no GraphQL API at all — a search for "graphql" across the codebase returns zero hits. There is no GraphQL schema to point to.

**Actual API surface:** The public API is defined as **Protocol Buffers / gRPC**, served over both gRPC (via Connect) and REST through grpc-gateway:

- **Schema definitions:** `.proto` files in `proto/api/v1/` — one per service, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, `proto/api/v1/instance_service.proto`, `proto/api/v1/idp_service.proto`, `proto/api/v1/shortcut_service.proto`, `proto/api/v1/ai_service.proto`, plus shared types in `proto/api/v1/common.proto`. (Internal storage-layer messages live separately in `proto/store/`.)
- **Generated code:** `proto/gen/api/v1/` contains the generated Go stubs (`*.pb.go`) and grpc-gateway REST handlers (`*.pb.gw.go`), generated with `buf` per `proto/buf.gen.yaml` (see `proto/README.md`).
- **REST/OpenAPI view:** an OpenAPI spec is also generated at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`), which is the closest thing to a browsable public API schema.
- **Server implementation:** the services are wired up in `server/router/api/v1/v1.go`, where `APIV1Service` implements the generated `InstanceService`, `AuthService`, `UserService`, `MemoService`, `AttachmentService`, `AIService`, `ShortcutService`, and `IdentityProviderService` servers.
