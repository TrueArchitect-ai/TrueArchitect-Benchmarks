**Convergence function — `Post` at `internal/webhook/webhook.go:120`.**

All paths funnel through `webhook.PostAsync` (`internal/webhook/webhook.go:184`), which enqueues onto `asyncPostQueue`; the `init` worker goroutines (`:42`) drain that queue and call `Post`, which is the single function that actually performs the outbound request via `safeClient.Do(req)` (`:152`) to `requestPayload.URL`.
