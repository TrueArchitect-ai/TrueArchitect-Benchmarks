The premise doesn't hold: there is no nightly database-cleanup job actually scheduled in this repository. The cron scheduler package at `internal/scheduler/` (scheduler.go, job.go, parser.go) is a library that exists in the codebase, but no production code imports or uses it — grepping for imports of `internal/scheduler` outside the package itself returns nothing, so no jobs of any kind are registered by the server.

The "cleanup" jobs you may have seen are only illustrative examples in the package's own documentation and example tests, all using the cron expression `0 2 * * *` (2 AM daily):

- `internal/scheduler/example_test.go:97-105` — an example job named "cleanup" ("Cleanup old data every night at 2 AM")
- `internal/scheduler/doc.go:15-16` — a "daily-cleanup" usage example
- `internal/scheduler/README.md:34-35` — the same "daily-cleanup" example

So if the question means "what does the example cleanup job in the scheduler docs use," the answer is 2:00 AM daily — but no real nightly database-cleanup job is scheduled anywhere in the application.
