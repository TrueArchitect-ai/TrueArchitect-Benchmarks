**Premise correction: there is no GraphQL API in this repository.** A search across the entire codebase (Go, TypeScript, proto, and config files) finds zero GraphQL references — no schema files, no resolvers, no GraphQL dependencies.

**Actual API surface:** memos exposes a gRPC API defined with Protocol Buffers, served both natively and as REST via grpc-gateway:

- **API contract (the analog of a "schema"):** Protobuf service definitions in `proto/api/v1/` — e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, `proto/api/v1/attachment_service.proto`, plus shared types in `proto/api/v1/common.proto`. Code generation is configured in `proto/buf.gen.yaml` (Buf toolchain).
- **Generated code:** `proto/gen/api/v1/` contains the gRPC stubs (`*_grpc.pb.go`), grpc-gateway REST bindings (`*.pb.gw.go`), and Connect handlers (`apiv1connect/`).
- **Server implementation:** the handlers live under `server/router/api/v1/`, wired up in `server/server.go`.
- **REST/HTTP documentation:** an OpenAPI spec is generated from the same protos at `proto/gen/openapi.yaml` (embedded via `proto/openapi_embed.go`), so the public HTTP API is described by OpenAPI, not GraphQL.

So if you're looking for the public API's type definitions, `proto/api/v1/*.proto` is the place to edit — the gateway, Connect, and OpenAPI artifacts are all regenerated from those files.
