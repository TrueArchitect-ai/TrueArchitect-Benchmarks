**1st: User (~7 packages); 2nd: Memo (~6 packages)**

The data layer is the `store` package, which defines the persistent entities in files like `store/user.go` (`store.User`), `store/memo.go` (`store.Memo`), `store/attachment.go`, `store/reaction.go`, `store/inbox.go`, etc. Counting the distinct Go packages outside `store/` that reference each type:

- **`store.User`** — 7 packages: `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo`** — 6 packages: `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`
- Runners-up for context: `store.Attachment` (4), `store.MemoRelation` / `store.Inbox` / `store.MemoShare` (3 each)

If you exclude the test package (`server/router/api/v1/test`), the ranking is unchanged: User 6, Memo 5.
