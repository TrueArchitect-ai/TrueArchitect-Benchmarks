h03.

`internal/idp`; `internal/idp/oauth2`

The abstraction lives in the `internal/idp` package (`internal/idp/idp.go`), which defines the provider-agnostic `IdentityProviderUserInfo` type consumed by sign-in flows. The single concrete protocol implementation that ships is the OAuth2 provider in `internal/idp/oauth2` (`internal/idp/oauth2/oauth2.go`), whose `IdentityProvider` type wraps a `storepb.OAuth2Config` and implements token exchange (including PKCE) and user-info retrieval.
