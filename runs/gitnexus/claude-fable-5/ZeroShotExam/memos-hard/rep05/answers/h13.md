**Impl — construction — holders:**

- **Impl:** The single concrete implementation of the `markdown.Service` interface (`internal/markdown/markdown.go:31`) is the unexported `service` struct (`internal/markdown/markdown.go:57`), which wraps a `goldmark.Markdown` instance configured with GFM plus the custom `TagExtension` and `MentionExtension` (`internal/markdown/extensions/tag.go`, `internal/markdown/extensions/mention.go`). For markdown-to-markdown output, its `RenderMarkdown`/`RenameTag` methods internally use `renderer.MarkdownRenderer` (`internal/markdown/renderer/markdown_renderer.go`), but that is a helper behind the impl, not an alternate implementation of the interface.

- **Construction:** The factory is `markdown.NewService(opts...)` (`internal/markdown/markdown.go:85`). The only production call site is `NewAPIV1Service` in `server/router/api/v1/v1.go:48`, which builds it with `WithTagExtension()` and `WithMentionExtension()`. (Tests construct their own instances in `server/router/api/v1/test/test_helper.go` and elsewhere.)

- **Holders:** Three components hold the interface:
  1. `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — used for snippets, mention extraction, and payload rebuilds (`memo_service.go`, `memo_service_webhooks.go`, `memo_mention_helpers.go`).
  2. `RSSService.MarkdownService` (`server/router/rss/rss.go:45`) — receives the same instance from `server/server.go:85` (`rss.NewRSSService(..., apiV1Service.MarkdownService)`) and uses it for `RenderHTML` in RSS feeds.
  3. `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) — declares the field, though at runtime `memopayload.NewRunner` is never invoked; the package is exercised via the standalone `RebuildMemoPayload(ctx, memo, markdownService)` function, which takes the interface as a parameter from `APIV1Service`.

So at runtime exactly one `service` instance exists, created once in `NewAPIV1Service` and shared by the API v1 service, the RSS service, and (as a parameter) the memopayload rebuild logic.
