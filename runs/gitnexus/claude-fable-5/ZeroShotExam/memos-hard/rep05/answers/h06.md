**Convergence function — `Post` — `internal/webhook/webhook.go:119`**

Every dispatch method builds a `WebhookRequestPayload` (setting `payload.URL = hook.Url`) and calls `webhook.PostAsync` (`memo_service_webhooks.go:43,71`). `PostAsync` enqueues onto `asyncPostQueue`, and the four worker goroutines started in `init` (`webhook.go:42-55`) drain that queue by calling `Post`. `Post` is where all paths converge before delivery — it constructs the `http.POST` to `requestPayload.URL` and issues the actual network call at `safeClient.Do(req)` (`webhook.go:152`). (Note: `safeDialContext` at `webhook.go:59` blocks reserved/private IPs as an SSRF guard, but the outbound request to the user's URL still originates in `Post`.)
