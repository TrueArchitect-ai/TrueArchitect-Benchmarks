The derived metadata is the memo **payload** (`memo.Payload.Tags` and `memo.Payload.Property`), computed from the memo's markdown content.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74`. It delegates the actual parsing to the goldmark-based markdown service's `ExtractAll` in `internal/markdown/markdown.go:356`, which walks the AST in a single pass and fills a `MemoPayload` (defined in `proto/store/memo.proto`, `Property` message at lines 15–22).

**Triggers:**
- Memo creation — `CreateMemo` calls `memopayload.RebuildMemoPayload` before inserting (`server/router/api/v1/memo_service.go:108`).
- Memo content update — `UpdateMemo` calls it when the update mask includes the `content` path (`server/router/api/v1/memo_service.go:447`).
- Bulk rebuild — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27` re-derives the payload for all memos in batches of 100 (e.g., after the extraction logic changes). Note this runner is defined but has no caller wired up in the current tree (nothing in `server/server.go` or `cmd/` invokes it).

**Extracted properties:**
- `tags` — all `#tag` nodes in the content, deduplicated case-preservingly (`markdown.go:376-378`, `418`).
- `property.title` — text of the first block-level H1 heading, if the document starts with one (`markdown.go:383-389`).
- `property.has_link` — any markdown link node (`markdown.go:393-394`).
- `property.has_code` — any code block, fenced code block, or inline code span (`markdown.go:396-397`).
- `property.has_task_list` / `property.has_incomplete_tasks` — task checkboxes present, and whether any is unchecked (`markdown.go:399-405`).

`ExtractAll` also collects `@mentions`, but `RebuildMemoPayload` only stores `Tags` and `Property` into the payload (`runner.go:85-86`); mentions are not part of the persisted derived metadata.
