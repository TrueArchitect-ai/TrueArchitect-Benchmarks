There is no nightly database-cleanup job actually scheduled in this repository — the premise doesn't hold. The repo contains a cron scheduler package at `internal/scheduler/` (`scheduler.go`, `job.go`, `parser.go`), but nothing in the application ever imports or uses it: grepping for imports of `internal/scheduler` outside the package itself returns no results, so no jobs of any kind are registered in production code (`server/`, `store/`, `cmd/`).

The "cleanup at 2 AM" that might suggest such a job appears only in the package's own documentation and examples:

- `internal/scheduler/doc.go` (lines ~15–17) — a usage example registering a `"daily-cleanup"` job with schedule `"0 2 * * *"` ("2 AM daily")
- `internal/scheduler/example_test.go` (lines ~97–100) — an example `"cleanup"` job, also `"0 2 * * *"` ("every night at 2 AM")
- `internal/scheduler/README.md` — the same `"daily-cleanup"` example

So the correct statement is: the scheduler's *example/documentation* cleanup job runs at 2:00 AM daily (`0 2 * * *`), but no real nightly database-cleanup job is configured anywhere in the codebase. (The only periodic cleanup that actually runs is the in-memory cache eviction loop in `store/cache/cache.go`, which ticks every 5 minutes and is not a cron job or database cleanup.)
