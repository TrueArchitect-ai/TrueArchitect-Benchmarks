**Premise correction: this repository has no GraphQL API.** A repo-wide search for "graphql" returns zero hits — there is no GraphQL schema, resolvers, or gateway anywhere in the codebase.

**The actual public API surface is gRPC/Connect defined in Protocol Buffers:**

- The API contract lives in `proto/api/v1/*.proto` — one service definition per domain: `memo_service.proto`, `user_service.proto`, `auth_service.proto`, `attachment_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, `ai_service.proto`, plus shared types in `common.proto`.
- Code generation is configured in `proto/buf.gen.yaml` (buf v2). It generates Go gRPC + ConnectRPC servers and a grpc-gateway into `proto/gen/`, an OpenAPI spec (`proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go` for REST-style consumers), and TypeScript client types into `web/src/types/proto` for the frontend.
- The server-side implementations of those services are in `server/router/api/v1/`.

So if you're looking for "the schema," the proto files under `proto/api/v1/` are the source of truth; the HTTP/JSON surface is the grpc-gateway/OpenAPI projection of those same definitions, not a separate GraphQL layer.
