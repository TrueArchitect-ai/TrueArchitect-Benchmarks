The derived metadata is the memo's **payload** (`memo.Payload.Tags` and `memo.Payload.Property`), computed from the memo's markdown content.

**Computation site:** `RebuildMemoPayload` in `server/runner/memopayload/runner.go:74-88`. It calls `markdownService.ExtractAll` (`internal/markdown/markdown.go:356-423`), which parses the content with goldmark and walks the AST in a single pass, then assigns `data.Tags` and `data.Property` onto the memo's `storepb.MemoPayload`.

**Triggers:**
- `CreateMemo` — `server/router/api/v1/memo_service.go:108` rebuilds the payload before storing a new memo.
- `UpdateMemo` — `server/router/api/v1/memo_service.go:447` rebuilds it when the update mask includes the `content` path (other field updates like visibility/pinned don't recompute it).
- Bulk rebuild — `Runner.RunOnce` in `server/runner/memopayload/runner.go:27-72` re-derives the payload for all memos in batches of 100 and persists each via `UpdateMemo`. (The runner type exists for maintenance/migration-style rebuilds; in this tree only the two API paths reference the package.)

**Extracted properties** (from the AST walk in `ExtractAll`):
- `Tags` — from memo tag nodes, deduplicated case-preservingly.
- `Property.Title` — text of an H1 heading if it's the first block-level element of the document.
- `Property.HasLink` — any link node.
- `Property.HasCode` — code block, fenced code block, or inline code span.
- `Property.HasTaskList` — any task checkbox; `Property.HasIncompleteTasks` — any unchecked checkbox.

(`ExtractAll` also collects `Mentions`, but `RebuildMemoPayload` stores only Tags and Property.) These stored properties back list filtering/previews, e.g. `has_link`/`has_code` memo filters (`store/test/memo_filter_test.go`) and the API's `Memo_Property` conversion in `server/router/api/v1/memo_service_converter.go:314`.
