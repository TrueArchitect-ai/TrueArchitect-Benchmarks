**impl** — The interface is `markdown.Service` (`internal/markdown/markdown.go:31`). Exactly one concrete implementation executes at runtime: the unexported `service` struct (`internal/markdown/markdown.go:57-60`), which wraps a `goldmark.Markdown` instance built with the GFM extension plus the project's custom `TagExtension` and `MentionExtension` (`internal/markdown/extensions/tag.go`, `internal/markdown/extensions/mention.go`). (The `MarkdownRenderer` in `internal/markdown/renderer/markdown_renderer.go` is an internal helper the service creates on the fly for AST→markdown rendering; it is not an implementation of the `Service` interface.)

**construction** — `markdown.NewService(...)` (`internal/markdown/markdown.go:85`) is the factory. At runtime it is called once, in `NewAPIV1Service` (`server/router/api/v1/v1.go:47-51`) with `WithTagExtension()` and `WithMentionExtension()`; `NewAPIV1Service` itself is invoked from `server/server.go:76`. The only other caller is test scaffolding (`server/router/api/v1/test/test_helper.go:44`).

**holders** — Three components declare a `markdown.Service` field/parameter:
- `APIV1Service.MarkdownService` (`server/router/api/v1/v1.go:35`) — the original holder.
- `RSSService.MarkdownService` (`server/router/rss/rss.go:45`, set via `NewRSSService`) — handed the *same* instance from the API service at `server/server.go:85` (`rss.NewRSSService(s.Profile, s.Store, apiV1Service.MarkdownService)`), used for server-side HTML rendering of RSS feeds.
- `memopayload.Runner.MarkdownService` (`server/runner/memopayload/runner.go:16`) — declared as a holder, but `memopayload.NewRunner` is never called in production code; at runtime the package's standalone `RebuildMemoPayload(ctx, memo, s.MarkdownService)` function is invoked directly with the API service's instance (`server/router/api/v1/memo_service.go:108` and `:447`).

So a single `service` instance (goldmark-backed), constructed once by `NewAPIV1Service` via `markdown.NewService`, is shared by the API v1 service, the RSS service, and the memopayload rebuild logic.
