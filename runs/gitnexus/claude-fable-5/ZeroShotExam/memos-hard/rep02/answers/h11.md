**1st: `User` (~7 outside packages); 2nd: `Memo` (~6 outside packages)**

The data layer is the `store` package, whose persistent entity structs are defined in files like `store/user.go` (`User`), `store/memo.go` (`Memo`), `store/attachment.go`, `store/inbox.go`, `store/reaction.go`, `store/memo_relation.go`, `store/memo_share.go`, `store/user_identity.go`, `store/idp.go`, etc.

Counting distinct Go packages outside the data layer (i.e., excluding `store/`, its driver packages `store/db/{sqlite,mysql,postgres}`, `store/test`, and the generated `proto/gen/store`) that reference each `store.<Type>`:

- **`store.User` — 7 packages:** `server/auth`, `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/fileserver`, `server/router/frontend`, `server/router/rss`
- **`store.Memo` — 6 packages:** `server/notification`, `server/router/api/v1`, `server/router/api/v1/test`, `server/router/frontend`, `server/router/rss`, `server/runner/memopayload`

For comparison, the next closest is `store.Attachment` at 4 packages (`server/router/api/v1`, its test package, `server/router/fileserver`, `server/router/rss`); everything else (Inbox, Reaction, MemoRelation, MemoShare, UserIdentity) sits at 2–3. The ranking holds even if you exclude the test package (User 6, Memo 5).
