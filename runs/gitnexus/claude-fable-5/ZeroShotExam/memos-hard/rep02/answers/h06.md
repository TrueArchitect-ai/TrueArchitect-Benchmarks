**Convergence function — `Post` at `internal/webhook/webhook.go:120`**

Every handler's path funnels the user-configured URL into a `WebhookRequestPayload` (with `payload.URL = hook.Url`, from `s.Store.GetUserWebhooks`) and calls `webhook.PostAsync` (`internal/webhook/webhook.go:184`). `PostAsync` only enqueues onto `asyncPostQueue`; the background workers started in `init` (line 42–55) drain that queue and call **`Post`**, which is the single point that actually builds the HTTP request (`http.NewRequest("POST", requestPayload.URL, …)`) and executes delivery via `safeClient.Do(req)` (line 152).

So `PostAsync` is the shared enqueue point and `Post` is the single function where all paths converge immediately before the outbound request is made.
