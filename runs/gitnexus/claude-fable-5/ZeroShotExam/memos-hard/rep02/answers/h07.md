Notes:
- The serving handler reads the stored value from `user.AvatarURL` and decodes it via `parseDataURI` (server/router/fileserver/fileserver.go:196, 737) — the stored data is the `avatar_url` column (a `data:<type>;base64,...` URI) in the `user` table, not a blob on disk or in the attachment table.
- Access to *another* user's avatar is gated first: on a private instance (`!s.Profile.AllowAnonymous()`), `serveUserAvatar` calls `getCurrentUser` → `authenticator.AuthenticateToUser` before the lookup (fileserver.go:173–181).
