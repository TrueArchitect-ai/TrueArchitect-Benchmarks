It resolves the target hostname at dial time and refuses the connection if any resolved IP falls in a reserved/private range — this also defeats DNS-rebinding, since the check happens on the same resolution used to connect.

- **At registration time (defense in depth):** `ValidateURL()` in `internal/webhook/validate.go:62` rejects webhook URLs that aren't http/https or that resolve to a reserved IP when a webhook is created/updated.
