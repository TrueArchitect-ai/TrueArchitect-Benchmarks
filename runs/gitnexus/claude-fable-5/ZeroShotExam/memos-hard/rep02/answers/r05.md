**Premise correction: this repository has no GraphQL API.** A search across the whole codebase turns up no GraphQL schema files, resolvers, or library references — the premise of the question doesn't match the project.

**Actual API surface:** memos exposes a gRPC / Connect RPC API defined in Protocol Buffers, with a REST layer generated via grpc-gateway:

- **Schema definitions:** `proto/api/v1/*.proto` — one service per domain, e.g. `proto/api/v1/memo_service.proto`, `proto/api/v1/user_service.proto`, `proto/api/v1/auth_service.proto`, plus `attachment_service.proto`, `ai_service.proto`, `idp_service.proto`, `instance_service.proto`, `shortcut_service.proto`, and shared types in `common.proto`.
- **Code generation:** configured in `proto/buf.gen.yaml` (buf v2), which generates Go gRPC stubs, Connect RPC handlers, grpc-gateway REST bindings, and an OpenAPI spec into `proto/gen/`, and TypeScript client types into `web/src/types/proto`.
- **REST/OpenAPI surface:** the generated `proto/gen/apidocs.swagger.yaml`-style spec lives at `proto/gen/openapi.yaml`, embedded via `proto/openapi_embed.go`.
- **Server wiring:** the API is served from `server/router/api` (alongside `mcp`, `rss`, `frontend`, and `fileserver` routers).

So if you're looking for the API contract, the `.proto` files under `proto/api/v1/` are the equivalent of what a GraphQL schema would be in another project.
